# 点注释

您可以在地图的指定位置添加点注释以标识位置、商家、建筑等，并可以通过信息窗口展示详细信息。点注释支持功能：

* 支持设置文字、图标碰撞规则。
* 支持设置标题动画、图标动画。
* 支持添加点击事件。

## 添加点注释

调用HuaweiMapEx的addPointAnnotation方法在地图上添加点注释。

示例代码如下：

```java
"Java"
private Title title = new Title();
private PointAnnotationOptions pointAnnotationOptions;
// 定义图标的锚点
pointAnnotationOptions = new PointAnnotationOptions().anchor(0.5f, 0.5f).position(new LatLng(47.893478, 2.334595)).zIndex(5);
// 设置图标
pointAnnotationOptions.icon(BitmapDescriptorFactory.fromResource(R.drawable.avocado));
// 设置碰撞的方式，默认碰撞方式为FONT(仅文字碰撞)
pointAnnotationOptions.isCollision(pointAnnotationOptions.ALL);
// 设置最大显示层级
pointAnnotationOptions.maxZoom(15);
// 设置最小显示层级
pointAnnotationOptions.minZoom(0);
// 设置显示层级
pointAnnotationOptions.zoom(0.0f, 15.0f);
// 设置压盖关系
pointAnnotationOptions.zIndex(1);
// 设置碰撞优先级，值越大优先级越低
pointAnnotationOptions.priority(3f);
// 设置标题
title.setContent("point");
pointAnnotationOptions.title(title);
// 设置是否可见
pointAnnotationOptions.visible(true);

// 添加点注释
hMapEx.addPointAnnotation(pointAnnotationOptions);
```

## 点注释事件

可通过HuaweiMapEx.OnPointAnnotationClickListener来侦听点注释上的点击事件。要在地图上设置此侦听器，请调用HuaweiMapEx对象的setOnPointAnnotationClickListener方法。

示例代码如下：

```java
"Java"
// 添加点注释的点击监听事件
hMapEx.setOnPointAnnotationClickListener(new HuaweiMapEx.OnPointAnnotationClickListener() {
    @Override
    public void onPointAnnotationClick(PointAnnotation pointAnnotation) {
        Toast.makeText(getApplicationContext(), "onPointAnnotationClick", Toast.LENGTH_SHORT).show();
    }
});
```

```java
"Kotlin"
// 添加点注释的点击监听事件
hMapEx.setOnPointAnnotationClickListener { Toast.makeText(applicationContext, "onPointAnnotationClick", Toast.LENGTH_SHORT).show() }
```

## 点注释动画

点注释支持设置标题动画和图标动画效果，标题支持设置字体大小动画（FontSizeAnimation），图标支持设置透明度动画（[AlphaAnimation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/alphaanimation-0000001050764853)）、缩放动画（[ScaleAnimation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scaleanimation-0000001050764855)），通过PointAnnotation的setTitleAnimation/setIconAnimation方法设置，再调用startTitleAnimation/startIconAnimation开启动画。

示例代码如下：

```java
"Java"
private FontSizeAnimation fontSizeAnimation;
private PointAnnotation mPoint;
// 新建缩放动画
fontSizeAnimation = new FontSizeAnimation(10, 80);
// 完成模式
fontSizeAnimation.setFillMode(1);
// 重复模式
fontSizeAnimation.setRepeatMode(1);
// 重复次数
fontSizeAnimation.setRepeatCount(1);
// 持续时间
fontSizeAnimation.setDuration(1000);
// 监听
Animation.AnimationListener listener = new Animation.AnimationListener() {
    @Override
    public void onAnimationStart() {
        Toast.makeText(getApplicationContext(), "FontSizeAnimation start", Toast.LENGTH_SHORT).show();
    }
    @Override
    public void onAnimationEnd() {
        Toast.makeText(getApplicationContext(), "FontSizeAnimation end", Toast.LENGTH_SHORT).show();
    }
};
fontSizeAnimation.setAnimationListener(listener);
// 给点注释设置标题动画效果
mPoint.setTitleAnimation(fontSizeAnimation);
// 启动标题设置的动画
mPoint.startTitleAnimation();
```

```java
"Kotlin"
var fontSizeAnimation : FontSizeAnimation
var mPoint : PointAnnotation
// 新建缩放动画
fontSizeAnimation = FontSizeAnimation(10f, 80f)
// 完成模式
fontSizeAnimation.fillMode = 1
// 重复模式
fontSizeAnimation.repeatMode = 1
// 重复次数
fontSizeAnimation.repeatCount = 1
// 持续时间
fontSizeAnimation.duration = 1000
// 监听
val listener: Animation.AnimationListener = object : Animation.AnimationListener {
    override fun onAnimationStart() {
        Toast.makeText(applicationContext, "FontSizeAnimation start", Toast.LENGTH_SHORT).show()
    }
    override fun onAnimationEnd() {
        Toast.makeText(applicationContext, "FontSizeAnimation end", Toast.LENGTH_SHORT).show()
    }
}
fontSizeAnimation.setAnimationListener(listener)
// 给点注释设置标题动画效果
mPoint.setTitleAnimation(fontSizeAnimation)
// 启动标题设置的动画
mPoint.startTitleAnimation()
```
