# 退出帐号

#### 场景介绍

帐号退出是指应用向用户提供可以退出当前帐号登录的入口，用户退出登录后应用需要通知帐号SDK清除本地当前已经登录的帐号信息。  

#### 支持的设备

|设备类型|OS版本|HMS Core（APK）版本|
|:-------------|:-------------------------|:--------------|
|手机、平板、华为智慧屏、车机|EMUI 3.0及以上、Android 4.4及以上|4.0.0.300及以上|

#### 业务流程

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230626155608.42853179869650601125676214275956:50001231000000:2800:0028CA20770FE1822DCFB2A670EB4F810E35A1D31050EB77B8F962FB5F558DBE.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

整体流程：

1. 用户已经登录应用，在应用中执行退出操作。
2. 应用客户端调用[AccountAuthService.signOut](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section1170815179335)方法向帐号SDK请求退出帐号。
3. 帐号SDK清除帐号登录信息后，向应用客户端返回退出结果。  

#### 开发步骤

帐号退出功能涉及应用的关键开发步骤如下：

1. 使用帐号登录授权时创建的[AccountAuthService](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395)实例调用[signOut](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section1170815179335)接口。  

   ```
   "Java"
   Task<Void> signOutTask = service.signOut();
   ```

   ```
   "Kotlin"
   val signOutTask = service.signOut()
   ```

2. [signOut](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section1170815179335)完成后的处理。  

   ```
   "Java"
   signOutTask.addOnCompleteListener(new OnCompleteListener<Void>() {
       @Override
       public void onComplete(Task<Void> task) {
           //完成退出后的处理
           Log.i(TAG, "signOut complete");
       }
   });
   ```

   ```
   "Kotlin"
   signOutTask.addOnCompleteListener { it ->
       //完成退出后的处理
       Log.i(TAG, "signOut complete")
   }
   ```
