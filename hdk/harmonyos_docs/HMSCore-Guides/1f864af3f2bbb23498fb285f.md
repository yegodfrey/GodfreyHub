# 睡眠呼吸暂停

## 睡眠呼吸暂停

此数据记录用户在睡眠期间产生的睡眠呼吸暂停检测结果。

目前仅支持部分开发者使用，如有需要，可[提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)或者发送邮件至[hihealth@huawei.com](mailto:hihealth@huawei.com)进行咨询。

## OAuth权限

联盟卡片申请的权限名称：健康数据 > 肺功能数据

* 读权限：https://www.huawei.com/healthkit/pulmonary.read
* 写权限：https://www.huawei.com/healthkit/pulmonary.write

## 原子采样明细数据类型

* 名称：com.huawei.obstructive_sleep_apnea

|**字段**列表|字段描述|**类型**|可选/必选|单位|取值范围|
|:-------|:---|:-----|:----|:-|:---------------------------|
|osaLevel|风险等级|int|M|-|1：正常 2：疑似低风险 3：疑似中风险 4：疑似高风险|
