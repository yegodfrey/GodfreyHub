# 跑步

## 跑步

运动记录类型如下：

|**活动类型常量**|**描述**|数据来源|
|:-------------------------|:-----|:-------|
|HiHealthActivities.RUNNING|跑步|手机、手表、手环|

### 专业运动特征统计数据

暂无

### 关联的采样统计数据类型说明

作为ActivityRecord概要数据的一部分，统一使用运动记录权限，无需每种关联的采样统计数据类型使用单独OAuth权限。

|**采样统计数据类型**|**描述**|可选/必选|备注|
|:---------------------------------------------------|:-----|:----|:-----------------|
|com.huawei.continuous.distance.total|距离统计|M|-|
|com.huawei.continuous.speed.statistics|速度统计|M|-|
|com.huawei.continuous.calories.burnt.total|卡路里统计|M|-|
|com.huawei.continuous.exercise_heart_rate.statistics|运动心率统计|O|用户佩戴华为手表/手环时会包含该数据|
|com.huawei.continuous.steps.total|步数统计|O|-|
|com.huawei.continuous.steps.rate.statistics|步频统计|O|-|
|com.huawei.continuous.run.posture.statistics|跑步姿势统计|O|支持跑姿监测的华为手环|
|com.huawei.continuous.altitude.statistics|海拔统计|O|-|

### 关联的原子采样数据说明

关联的原子采样数据权限请参见[OAuth权限说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/activity-type-constants-0000001135051290#section27171294263)。

|**原子采样数据类型**|**描述**|可选/必选|备注|
|:-------------------------------------------|:-----|:----|:-----------------------|
|com.huawei.instantaneous.steps.rate|步频详情|O|一般手机、手环和手表等产生的跑步数据都有步频详情|
|com.huawei.instantaneous.speed|速度详情|O|-|
|com.huawei.instantaneous.exercise_heart_rate|运动心率详情|O|用户佩戴华为手表和手环时会包含该数据|
|com.huawei.instantaneous.location.sample|GPS详情|O|手机支持GPS，部分手环和手表支持GPS|
|com.huawei.instantaneous.altitude|海拔详情|O|手机支持GPS，部分手环和手表支持GPS|
|com.huawei.continuous.run.posture|跑步姿势详情|O|支持跑姿监测的华为手环|

### 关联的分段数据说明

作为ActivityRecord概要数据的一部分，统一使用运动记录权限，无需每种关联的采样统计数据类型使用单独OAuth权限。

|**采样统计数据类型**|**描述**|可选/必选|备注|
|:---------------------------------------------------|:-----|:----|:-------------------------------------------------------------------------------------------------------------|
|com.huawei.continuous.distance.total|距离统计|O|读取运动健康运动分段数据仅支持distance字段|
|com.huawei.continuous.speed.statistics|速度统计|O|读取运动健康运动分段数据仅支持avg字段|
|com.huawei.continuous.exercise_heart_rate.statistics|运动心率统计|O|读取运动健康运动分段数据仅支持avg字段|
|com.huawei.continuous.steps.rate.statistics|步频统计|O|读取运动健康运动分段数据仅支持avg字段|
|com.huawei.continuous.altitude.statistics|海拔统计|O|读取运动健康运动分段数据仅支持ascent_total、descent_total字段|
|com.huawei.continuous.run.posture.statistics|跑步姿势统计|O|读取运动健康运动分段数据仅支持avg_ground_contact_time、avg_ground_impact_acceleration、avg_swing_angle、avg_eversion_excursion字段|
