# 配置AppGallery Connect

## 注册成为开发者

在开发应用前需要在[华为开发者联盟](https://developer.huawei.com/consumer/cn)网站上注册成为开发者并完成实名认证。具体方法请参见[帐号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"。
2. 在项目列表中点击您的项目。

3. 选择"项目设置 > 常规"，点击"添加应用"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/54/v3/4OFjzQJaSmmDa7Tob54_jQ/zh-cn_image_0000001258491175.png?HW-CC-KV=V1&HW-CC-Date=20260922T085431Z&HW-CC-Expire=31536000000&HW-CC-Sign=F7E3A2E7155E8AC1661924CBF39991D1C7F7AE0C6FAFC691472AB394F83EBD6F "点击放大")

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8d/v3/vTkCfHY7TdybBskzmYXvcw/zh-cn_image_0000001258491487.png?HW-CC-KV=V1&HW-CC-Date=20260922T085431Z&HW-CC-Expire=31536000000&HW-CC-Sign=7AB575346635298CAA9FD108CA8E0A09EFB6F2E2D08EBB27F1B10EBE807162B3 "点击放大")

## 生成签名证书指纹

签名证书指纹用于在应用通过HMS Core SDK访问HMS Core服务时校验应用的真实性。在使用HMS Core服务之前，您必须在本地生成签名证书指纹并将其配置到AppGallery Connect。

请确保您的计算机上已安装JDK。

### 生成签名文件

> 说明
>
> 如果您已经有签名文件，请跳过本节，参阅从签名文件中获取SHA256指纹。

执行以下步骤：

1. 执行cmd命令打开命令行工具，执行cd命令进入keytool.exe所在目录，即JDK的bin目录。在以下示例中，Java程序安装在C盘的Program Files目录中。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/41/v3/pCDI3w9OQHGis43zI4z-qA/zh-cn_image_0000001208268212.gif?HW-CC-KV=V1&HW-CC-Date=20260922T085431Z&HW-CC-Expire=31536000000&HW-CC-Sign=4F3A493767DBA2BA924BF8DC7CF74F2DDF2D239A890AFCB413B329465A6810FA)

2. 运行**keytool -genkey -keystore** *<keystore-file>* **-storepass** *<keystore-pass>* **-alias** *<key-alias>* **-keypass** *<key-pass>* **-dname** *<dname>* **-keysize 2048** **-keyalg RSA** **-validity** *<validity-period>*命令。

   在上述命令中：
   * *<keystore-file>*是应用签名文件的完整路径。文件后缀必须为.jks或.keystore。例如，D:\Android\mykeystore.jks。
   * *<keystore-pass>*是密钥库的密码。密码包含至少为6个字符。例如，123456。
   * *<key-alias>*是密钥的别名。例如，mapshowcase。
   * *<key-pass>*是密钥的密码。密码包含至少为6个字符。例如，123456。
   * *<dname>*是应用在密钥库中的唯一标识符。例如，"o=Huawei"。
   * *<validity-period>*是密钥的有效期，单位为天。例如，36500。

   命令示例：

   ```screen
   keytool -genkey -keystore D:\Android\mykeystore.jks -storepass 123456 -alias mapshowcase -keypass 123456 -dname "o=Huawei" -keysize 2048 -keyalg RSA -validity 36500
   ```

### 从签名文件中获取SHA256指纹

执行以下步骤：

1. 执行cmd命令打开命令行工具，执行cd命令进入keytool.exe所在目录，即JDK的bin目录。在以下示例中，Java程序安装在C盘的Program Files目录中。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bd/v3/9hOMOxoMTQGP5XDRAlnDFw/zh-cn_image_0000001208428186.gif?HW-CC-KV=V1&HW-CC-Date=20260922T085431Z&HW-CC-Expire=31536000000&HW-CC-Sign=D8811C4F4184F9E12AA23F10855FE5A12AB090AB808A9ABFA471357EB5181D9F)

2. 执行**keytool -v -list -keystore** *<keystore-file>*命令。

   其中，*<keystore-file>*是应用签名文件的完整路径。例如，D:\Android\mykeystore.jks。

   命令示例：

   ```screen
   keytool -v -list -keystore D:\Android\mykeystore.jks
   ```

3. 根据提示输入密钥库密码。
4. 从结果中获取SHA256指纹。结果示例如下：

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d7/v3/TfcpGCaNQTaVDvg0TJBsrg/zh-cn_image_0000001208268214.gif?HW-CC-KV=V1&HW-CC-Date=20260922T085431Z&HW-CC-Expire=31536000000&HW-CC-Sign=4AADB167AE0CB302A0FBB538E86E2F45BE00735FBF9F1BAE5A550E0BB0BBE27A)

## 配置签名证书指纹

1. 选择"项目设置 > 常规"，在"应用"区域，单击"添加证书指纹"，输入获取的SHA256证书指纹。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/47/v3/pH45XovASuC5yVHp9HmaGw/zh-cn_image_0000001258252353.png?HW-CC-KV=V1&HW-CC-Date=20260922T085431Z&HW-CC-Expire=31536000000&HW-CC-Sign=01DD784861A5814FADB5573ED4B8E81CBD8B17F3E664E4D9AC61E75E380D043C "点击放大")

2. 配置完成后，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bf/v3/wmoEaskCTweDKYfN9kL0Lg/zh-cn_image_0000001252428203.gif?HW-CC-KV=V1&HW-CC-Date=20260922T085431Z&HW-CC-Expire=31536000000&HW-CC-Sign=413DA493A1219A0DB14B8BCD4932E0DBE1FCD9D5DFE35FAB67EDE571431F5A55)。

## 开启地图服务

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"，在弹出的页面中，单击需要开通服务的项目。
2. 进入"项目设置 > API管理"页面。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7a/v3/u0awShn1TSu8KvgdCeQ1Rw/zh-cn_image_0000001258492623.png?HW-CC-KV=V1&HW-CC-Date=20260922T085431Z&HW-CC-Expire=31536000000&HW-CC-Sign=329A60C2C09FB25C6EC3A5E7665EA2D692B649AFC5B6F08D5533651D4A4FA568 "点击放大")

3. 打开"地图服务"开关。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c0/v3/P0ZOsvd2QCyziZSNTZif9Q/zh-cn_image_0000001213212940.png?HW-CC-KV=V1&HW-CC-Date=20260922T085431Z&HW-CC-Expire=31536000000&HW-CC-Sign=FCAEB77D1E95DA8DCCD4BB52CAFF04F52BF7FD70D46766889A8A1478E0C41679 "点击放大")
