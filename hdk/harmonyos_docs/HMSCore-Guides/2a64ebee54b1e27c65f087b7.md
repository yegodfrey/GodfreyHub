# 配置AppGallery Connect

#### 注册成为开发者

在开发应用前需要在[华为开发者联盟](https://developer.huawei.com/consumer/cn)网站上注册成为开发者并完成实名认证。具体方法请参见[帐号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。  

#### 创建应用

您需要在AppGallery Connect中您的项目下创建应用，以便与华为服务通信。执行如下步骤创建应用：

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"。
2. 在项目列表中点击您的项目。

   <br />

   ![](https://media:301772613560162546 "点击放大")

   <br />

3. 选择"项目设置 \> 常规"，点击"添加应用"。

   <br />

   ![](https://media:301772613560188547 "点击放大")

   如果项目中存在应用，且您需要添加新的应用，展开页面顶部的应用选择区域并点击"添加应用"。

   ![](https://media:301772613560217548 "点击放大")

   <br />

4. 在"添加应用"页面，输入应用信息，点击"确认"。

   <br />

   ![](https://media:301772613560247549 "点击放大")

   <br />

#### 生成签名证书指纹

签名证书指纹用于在应用通过HMS Core SDK访问HMS Core服务时校验应用的真实性。在使用HMS Core服务之前，您必须在本地生成签名证书指纹并将其配置到AppGallery Connect。

请确保您的计算机上已安装JDK。  

#### 生成签名文件

![](https://media:301772613560276550)  
如果您已经有签名文件，请跳过本节，参阅从签名文件中获取SHA256指纹。

执行以下步骤：

1. 执行cmd命令打开命令行工具，执行cd命令进入keytool.exe所在目录，即JDK的bin目录。在以下示例中，Java程序安装在C盘的Program Files目录中。

   <br />

   ![](https://media:301772613560513551)

   <br />

2. 运行keytool -genkey -keystore \<keystore-file\> -storepass \<keystore-pass\> -alias \<key-alias\> -keypass \<key-pass\> -dname \<dname\> -keysize 2048 -keyalg RSA -validity \<validity-period\>命令。

   <br />

   在上述命令中：
   * \<keystore-file\>是应用签名文件的完整路径。文件后缀必须为.jks或.keystore。例如，D:\\Android\\mykeystore.jks。
   * \<keystore-pass\>是密钥库的密码。密码包含至少为6个字符。例如，123456。
   * \<key-alias\>是密钥的别名。例如，mapshowcase。
   * \<key-pass\>是密钥的密码。密码包含至少为6个字符。例如，123456。
   * \<dname\>是应用在密钥库中的唯一标识符。例如，"o=Huawei"。
   * \<validity-period\>是密钥的有效期，单位为天。例如，36500。

   命令示例：

   ```
   keytool -genkey -keystore D:\Android\mykeystore.jks -storepass 123456 -alias mapshowcase -keypass 123456 -dname "o=Huawei" -keysize 2048 -keyalg RSA -validity 36500
   ```

   <br />

#### 从签名文件中获取SHA256指纹

执行以下步骤：

1. 执行cmd命令打开命令行工具，执行cd命令进入keytool.exe所在目录，即JDK的bin目录。在以下示例中，Java程序安装在C盘的Program Files目录中。

   <br />

   ![](https://media:301772613560733552)

   <br />

2. 执行keytool -v -list -keystore \<keystore-file\>命令。

   <br />

   其中，\<keystore-file\>是应用签名文件的完整路径。例如，D:\\Android\\mykeystore.jks。

   命令示例：

   ```
   keytool -v -list -keystore D:\Android\mykeystore.jks
   ```

   <br />

3. 根据提示输入密钥库密码。
4. 从结果中获取SHA256指纹。结果示例如下：

   <br />

   ![](https://media:301772613560904553)

   <br />

#### 配置签名证书指纹

1. 选择"项目设置 \> 常规"，在"应用"区域，单击"添加证书指纹"，输入获取的SHA256证书指纹。

   <br />

   ![](https://media:301772613560939554 "点击放大")

   <br />

2. 配置完成后，点击![](https://media:301772613561125555)。  

#### 开启地图服务

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"，在弹出的页面中，单击需要开通服务的项目。
2. 进入"项目设置 \> API管理"页面。

   <br />

   ![](https://media:301772613561155556 "点击放大")

   <br />

3. 打开"地图服务"开关。

   <br />

   ![](https://media:301772613561185557 "点击放大")

   <br />
