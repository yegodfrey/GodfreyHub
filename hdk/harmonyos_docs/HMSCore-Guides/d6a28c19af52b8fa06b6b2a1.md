# 车轮转速

此数据类型记录用户在一小段时间内骑行活动内的车轮转速。  

#### OAuth权限

联盟卡片申请的权限名称：锻炼记录 \> 锻炼记录详情数据

* 读权限：Scopes.HEALTHKIT_ACTIVITY_READ
* 写权限：Scopes.HEALTHKIT_ACTIVITY_WRITE  

#### 原子采样明细数据类型

* 名称：com.huawei.instantaneous.wheel_rotation
* Android SDK类型常量：DataType.DT_INSTANTANEOUS_WHEEL_ROTATION

|字段列表|描述|Android SDK常量|类型|可选/必选|单位|取值范围|
|:---|:---|:--------------|:-----|:----|:---|:---|
|rpm|车轮转速|Field.FIELD_RPM|double|M|转/分钟|-|

|开放API|查询及时性|数据源|
|:----------------------------------------------------------------------------------------------------------------------------------------|:----|:---------------|
