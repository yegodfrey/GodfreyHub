# 地图事件

* 地图点击事件：

  ```screen
  function handleClick() {
      map.zoomIn();
  }
  map.on('click', handleClick);
  ```

* 地图中心点改变事件：

  ```screen
  map.onCenterChanged(centerChangePost);

  function centerChangePost() {
      var center = map.getCenter();
      alert( 'Lng:'+map.getCenter().lng+'\n'+'Lat:'+map.getCenter().lat);
  }
  ```

* 地图方向改变事件：

  ```screen
  map.onHeadingChanged(headingChangePost);

  function headingChangePost() {
      alert('Heading Changed!')
  }
  ```

* 地图缩放级别改变事件：

  ```screen
  map.onZoomChanged(zoomChangePost);

  function zoomChangePost() {
      alert('Zoom Changed!')
  }
  ```

关于地图事件，如下表所示，具体请参见[HWMap事件](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwmap-0000001050990165#section11830153617166)。

|**事件**|**含义**|**使用方式**|
|:---------------|:-------|:------------------------------------------------|
|click|鼠标左键点击。|map.on('click', callback), 参数callback为回调函数。|
|singleclick|鼠标左键点击。|map.on('singleclick', callback), 参数callback为回调函数。|
|dblclick|鼠标左键双击。|map.on('dblclick', callback), 参数callback为回调函数。|
|contextmenu|鼠标右键点击。|map.on('contextmenu', callback), 参数callback为回调函数。|
|pointermove|鼠标移动。|map.on('pointermove', callback), 参数callback为回调函数。|
|pointerdown|鼠标键按下。|map.on('pointerdown', callback), 参数callback为回调函数。|
|pointerup|鼠标键松开。|map.on('pointerup', callback), 参数callback为回调函数。|
|pointerdrag|地图拖动。|map.on('pointerdrag', callback), 参数callback为回调函数。|
|movestart|地图开始移动。|map.on('movestart', callback), 参数callback为回调函数。|
|moveend|地图结束移动。|map.on('moveend', callback), 参数callback为回调函数。|
|onCenterChanged|地图中心点改变。|map.onCenterChanged(callback), 参数callback为回调函数。|
|onHeadingChanged|方向改变。|map.onHeadingChanged(callback), 参数callback为回调函数。|
|onZoomChanged|缩放级别改变。|map.onZoomChanged(callback), 参数callback为回调函数。|
