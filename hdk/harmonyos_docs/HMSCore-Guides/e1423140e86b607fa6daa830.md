# 自动采集事件

自动采集事件无需埋点，只需开启采集系统事件的开关（初始化时自动开启），即可实现此类事件的自动采集。

自动采集事件的事件ID是分析服务的保留字段，不能被复用。

事件ID | 说明  
---|---  
APPFIRSTOPEN | 用户首次打开快应用时，上报该事件。  
JOINABTASK | 当用户参与到某个A/B测试时，触发此事件。 说明：  上报此事件，您需要集成[A/B测试](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-abtest-introduction-0000001058210679)。  
LAUNCHAPP | 用户打开应用时，上报此事件。  
STOPANALYTICSCOLLECTION | 用户关闭采集事件时，上报此事件。 说明：  此事件为您设置[setAnalyticsEnabled](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/quickapp-api-analytics-0000001077322170#section1644555762111)为false时或者[setRestrictionEnabled](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/quickapp-api-analytics-0000001077322170#section069215373517)为true时SDK触发上报。该事件不会用于洞察报告。  
ADDQUICKAPP | 用户将应用添加到桌面时，上报此事件。
