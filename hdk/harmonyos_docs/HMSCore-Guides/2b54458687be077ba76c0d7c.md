# Customized View Mode

Customized View支持您自定义扫码界面，扫码过程和相机控制将由Scan Kit完成。您可以参考我们提供的[示例代码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Examples/ios-sample-code-0000001050694354)快速构建扫码界面UI。  

#### 业务流程

使用Customized View Mode的主要业务流程如下：  
![](https://media:301775707693959572 "点击放大")

1. 用户打开App发起扫码请求。
2. 校验是否有相机权限和相册读取权限。
3. 初始化应用定制的view，构建扫码界面，开始扫码。
4. 如果扫码成功，华为统一扫码SDK回调应用的"CustomizedScanDelegate"代理传递扫码结果。
5. App封装扫码结果返回给用户。  

#### 开发步骤

1. 初始化全局[HmsCustomScanViewController](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmscustomscanviewcontroller-0000001050187740)，并将Customized View加入到您的Controller布局中。

   <br />

   ```
   self.hmsCustomScanViewController = [[HmsCustomScanViewController alloc] init];
   self.hmsCustomScanViewController.customizedScanDelegate = self;
   // 返回按钮，若需要隐藏赋值为true
   self.hmsCustomScanViewController.backButtonHidden = false;
   // 赋值true为持续扫码，默认为false非持续扫码
   self.hmsCustomScanViewController.continuouslyScan = true;
   [self.view addSubview:self.hmsCustomScanViewController.view];
   [self addChildViewController:self.hmsCustomScanViewController];
   [self didMoveToParentViewController:self.hmsCustomScanViewController];
   self.navigationController.navigationBarHidden = YES;
   ```

   <br />

2. 实现Customized View的代理方法。

   <br />

   ```
   - (void)customizedScanDelegateForResult:(NSDictionary *)resultDic{
      dispatch_asyns(dispatch_get_main_queue(), ^{
        // 在主线程内处理数据
      });
   }
   ```

   <br />

3. 如果您需要增加从图片文件中扫码的功能，可使用Bitmap Mode实现。

   <br />

   1. 设定导入图片扫码的按钮。
   2. 参考Bitmap Mode[图片扫码场景](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-bitmap-images-0000001050414347)。
