# 通知栏消息语言本地化

通知栏消息本地化可以理解为国际化多语言展示，指消息可以根据终端设备本地语言变化展示对应语言的标题和内容。多语言展示效果图如下：

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231103095825.78246082343377215465103262465709:50001231000000:2800:A7705CAEC332831CEF569D9C002E6802E39AD4AC2D5FCEEA3E48BAB098F30754.jpg?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")

您可以通过以下方式实现通知栏消息本地化。

方式一

通过推送服务端REST API接口实现，您需要配置[title_loc_key](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p183191486230)、[body_loc_key](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p2319118192313)和[multi_lang_key](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p123194819235)字段，配置消息体示例如下。

```
{
    "title_loc_key": "title_key",
    "body_loc_key": "body_key",
    "body_loc_args": [
        "Jack",
        "Shanghai"
    ],
    "multi_lang_key": {
        "title_key": {
            "en": "New Friend Request",
            "zh": "添加好友请求",
            "ru": "Запрос нового друга"
        },
        "body_key": {
            "en": "My name is %s, I am from %s.",
            "zh": "我叫%s，来自%s。",
            "ru": "Меня зовут% s, я из% s."
        }
    }
}
```

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231103095825.61910677832748452425142438796711:50001231000000:2800:BB029DE8BC8B2B9C2A175FB655B11575D17DEBD659CFEC95C4BD1A9ED3014628.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
* "multi_lang_key"的字段的值表示对象，对象的名称必须与"title_loc_key"、"body_loc_key"字段的值一致。
* "body_key"和"title_key"字段的值表示对象，对象中适配国际化多语言，目前标题和消息内容最多支持配置三种语言。
* 如果您需要指定[title](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p1031808192312)和[body](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p133199817236)字段是变化的，请同步配置[title_loc_args](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p031913819233)和[body_loc_args](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p1531948132318)字段，以上述消息体为例："en"字段的值是一个格式化字符串，"%s"代表字符串类型占位符。"body_loc_args"字段的值是一个可变的字符串数组，用于填充"en"字段的值中对应的占位符"%s"，您可以根据自己的业务进行设置。

方式二

通过推送服务端REST API接口与应用本地的字符串资源文件"strings.xml"配合实现，与方式一相比不需要配置[multi_lang_key](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p123194819235)字段。

1. 推送服务端参数的配置参考如下。如果您需要指定[title](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p1031808192312)和[body](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p133199817236)字段是变化的，请同步配置[title_loc_args](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p031913819233)和[body_loc_args](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p1531948132318)字段。

   ```
   {
       "title_loc_key": "title_key",
       "body_loc_key": "body_key",
       "body_loc_args": ["Jack", "Shanghai"]
   }
   ```

2. Android资源文件"/res/values/strings.xml"中字符串资源定义如下，"%{num}$s"用于替换body_loc_args中的内容，{num}表示body_loc_args中的序号，"$s"表示替换的字符串类型。

   ```
   <string name="title_key">New Friend Request</string>
   <string name="body_key">My name is %1$s, I am from %2$s.</string>
   ```

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231103095825.66984607616917128332075599869749:50001231000000:2800:0950A997E38E52901B4590C16DEF23F048AC7BA15641278D8C23A066C90B4FAE.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
   * 您可以在"res"目录下进行多语言适配，例如使用"/res/values-en-rGB/strings.xml"进行英语（英国）本地化适配。
   * "body_loc_key"和"title_loc_key"字段的值要与本地"strings.xml"里定义的"body_key"和"title_key"要一致，"body_loc_args"中可变字符串值用于替换"strings.xml"中"%{num}$s"，因此可变数组的长度要保证不小于"strings.xml"中对应的节点中占位符的个数。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231103095825.44331988483723385105735468450319:50001231000000:2800:7431C59F1882ED95FE6E3888A3E7F07D49563D90CF2578A1230849CCAC4FEA85.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
如果您同时指定了[multi_lang_key](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p123194819235)字段与本地字符串资源文件，推送服务优先使用[multi_lang_key](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p123194819235)字段，若该字段读取失败，则读取应用本地字符串资源文件。
