# 相机动画

HuaweiMapEx提供了相机动画功能，通过setMarkerAndLineWithAnimateCamera方法设置，支持相机和标记随路线运动。

示例代码如下：

```java
"Java"
private CameraUpdate cameraUpdate;
private RouteLine routeLine;
private MarkerEx mMaker;
private int index =0;
try{
    // 设置路线
    routeLine = hMapEx.addRouteLine(new RouteLineOptions()
        .add(new LatLng(45.002506,2.332645),new LatLng(45.00490506,2.332645),new LatLng(45.00490506,2.3334685),new LatLng(45.002506,2.3334685))
        .color(android.graphics.Color.GREEN).strokeColor(android.graphics.Color.RED).jointType(0).width(10));
    // 添加标记
    mMaker = hMapEx.addMarker(new MarkerOptionsEx().position(new LatLng(48.8129154,2.3364656)));
    // 更新相机定位
    hMapEx.moveCamera(CameraUpdateFactory.newLatLng(new LatLng(48.8129154, 2.3364656)));
    // 设置相机移动结束时的监听
    hMapEx.setOnCameraIdleListener(() -> {
        if(index == 0){
            Log.i(TAG, "onCameraIdle: start" + index);
            // CameraUpdate对象，用于改变地图状态
            cameraUpdate = CameraUpdateFactory.newCameraPosition(CameraPosition.builder().target(new LatLng(45.00490506,2.332645)).zoom(5).build());
            // 更新标记和路线
            hMapEx.setMarkerAndLineWithAnimateCamera(cameraUpdate,3000,mMaker,routeLine,index);
            index++;
        }else if(index ==1){
            // 设置自动导航缩放路口机动点
            hMapEx.setAutoZoomCrossingPointsWithType(1,new LatLng(45.00490506,2.332645),1);
            hMapEx.setAutoZoomCrossingPointsWithType(0,new LatLng(45.00490506,2.3334685),1);
            // CameraUpdate对象，用于改变地图状态
            cameraUpdate = CameraUpdateFactory.newCameraPosition(CameraPosition.builder().target(new LatLng(45.00490506,2.3334685)).zoom(5).bearing(270).build());
            // 更新标记和路线
            hMapEx.setMarkerAndLineWithAnimateCamera(cameraUpdate,3000,mMaker,routeLine,index);
            index++;
        }
        else if(index ==2){
            hMapEx.setAutoZoomCrossingPointsWithType(1,new LatLng(45.00490506,2.3334685),1);
            hMapEx.setAutoZoomCrossingPointsWithType(0,new LatLng(45.002506,2.3334685),1);
            cameraUpdate = CameraUpdateFactory.newCameraPosition(CameraPosition.builder().target(new LatLng(45.002506,2.3334685)).zoom(5).bearing(180).build());
            hMapEx.setMarkerAndLineWithAnimateCamera(cameraUpdate,3000,mMaker,routeLine,index);
            index++;
        }
    });
}catch (Exception e){
    e.printStackTrace();
}
```
