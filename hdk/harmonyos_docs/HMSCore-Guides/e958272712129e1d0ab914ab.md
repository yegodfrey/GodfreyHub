# 业务介绍

在获取用户签约授权的前提下，商户可以向用户的华为支付账户发起支付扣款，无需用户输入支付密码就可以优先使用签约的支付方式完成扣款。

## 应用场景

免密代扣是华为支付为用户提供的一种在交易场景外完成交易的能力。

* 周期性业务：周期性或多次扣款行为的扣款模式，减少用户重复支付操作。示例场景：会员按月付费等。
* 先用后付：基于用户行为，商户先提供服务，然后发起扣款的后付费模式。示例场景：乘车码。
