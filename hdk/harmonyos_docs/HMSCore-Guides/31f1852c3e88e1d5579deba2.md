# 使用入门

#### 开发环境

* 华为快应用 [IDE v3.1.1](https://developer.huawei.com/consumer/cn/doc/development/quickApp-Guides/quickapp-installtool-0000001126543467)及以上。

<!-- -->

* 包管理工具npm，运行环境[Node.js](https://nodejs.org/en/download/)。
* 测试应用的设备：华为手机Android 4.4及以上或者HarmonyOS 2.0及以上的华为手机。  

#### 开发流程

|序号|步骤|说明|
|:-|:--------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/base-payment-android-agc-config-0000001710624188)|在开发应用前，需要在AppGallery Connect中配置相关信息。包括： * [注册成为开发者](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/base-payment-android-agc-config-0000001710624188#section1464519554325) * [创建应用](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/base-payment-android-agc-config-0000001710624188#section15850522183317) * [生成签名证书指纹](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/base-payment-android-agc-config-0000001710624188#section859813591012) * [配置签名证书指纹](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/base-payment-android-agc-config-0000001710624188#section1782102181419) * [开通华为支付服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/base-payment-android-agc-config-0000001710624188#section3901928826)|
|2|[证书准备](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/certificate-preparation-0000001596094962)|商户成功登录商户平台后，须在证书管理中上传商户证书；上传完商户证书后商户方可进行交易；证书必须与商户号相匹配且是有效的。|
|3|[集成SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/pay-propose-sign-quick-app-pre-dev-0000001827755616#section5718925115217)|在开发应用前，开发者需要将华为支付服务 JS SDK集成到开发者的开发环境中。|
|4|[快速接入](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/pay-propose-sign-quick-app-dev-0000001704348946)|开发者根据文档完成华为支付服务能力的接入。|
