# 业务简介

定位服务通过HTTPS形式为开发者提供了一套易于开发的简易API接口，当前定位服务主要包含两个功能：网络定位（API）和IP定位（API）。您可以根据自己的诉求调用相应能力。  

#### 场景介绍

Location Kit通过提供如下能力，帮助您快速构建基于定位服务的产品，满足用户的需求。

* 网络定位（API）：提供了定位请求功能，包含了室内定位和室外定位。

* IP定位（API）：提供了可以通过指定IP获取IP所在城市信息的功能。  

#### 功能使用限制

|功能|使用限制说明|
|:--------|:-----|
|网络定位（API）|不受限|
|IP定位（API）|仅支持中国区|
