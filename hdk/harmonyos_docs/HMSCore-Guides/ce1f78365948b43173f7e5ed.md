# FAQ

如果您在下面没有找到需要的问题，请加入[Stack Overflow](https://stackoverflow.com/questions/tagged/huawei-mobile-services?tab=Frequent)社区参与讨论。

## 通过什么方式可以快速的接入引用华为UI Engine多态控件能力？

建议开发者使用HUAWEI DevEco IDE工具进行应用界面开发，其内部集成了华为UI Engine开发套件，可以通过拖拽的方式直接引用多态控件，IDE会自动完成Gradle Maven依赖配置，并从Maven服务器下载最新的多态控件AAR包。

## 华为UI Engine多态控件可以支持哪些设备应用界面的开发？

根据不同的屏幕类型划分，多态控件可以支持手机、车机等设备的应用界面开发，对于暂时没有适配对应设备的控件，在使用中默认继承手机设备的UI风格。

## 华为UI Engine多态控件使用上有哪些限制？

不同的多态控件对各种设备的支持程度不同，控件的默认显示效果在部分设备上需要进行参数上的调整适配以达到应用UX设计的定制效果。华为UI Engine会在后续迭代版本中不断完善控件自适应效果，不断提高开发者界面开发效率。
