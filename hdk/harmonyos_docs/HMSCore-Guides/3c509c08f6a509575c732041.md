# 概述

华为分析服务为您提供丰富的行业分析报告，支持细分游戏行业分析报告（如卡牌、MMO、通用）、教育类行业分析报告（如职业与成人、语言培训）、电商行业分析报告（如商城购物）、运动健康行业分析报告、房产行业分析报告（如租房买房）、汽车行业分析报告（如养车）、金融理财行业分析报告（如证券）以及出行旅游行业分析报告（如出行旅游），您可以根据业务需要使用对应的行业分析服务。

* [卡牌](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/card-industry-analysis-0000001105087808)：针对游戏细分行业提供卡牌类游戏分析报告，从数据概览、付费分析、玩家分析、虚拟消费、战斗分析、区服分析和卡牌分析多维度呈现用户的行为。通过卡牌类游戏分析报告，您可以清晰洞察卡牌类应用的关键指标数值并制定精准的运营策略，从而提升卡牌类游戏的用户体验，实现获客增长和受益增长。查看卡牌分析报告前需要配置"卡牌"埋点方案模板，配置模板方法详情请参见[埋点开发](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/tracing-point-development-0000001078556280)。
* [MMO](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/mmo-industry-analysis-0000001105736206)：针对游戏细分行业提供MMO类游戏分析报告，从数据概览、付费分析、玩家分析、虚拟消费、战斗分析、区服分析、养成系统、副本任务多维度呈现用户的行为。通过MMO类游戏分析报告，您可以清晰洞察MMO类应用的关键指标数值并制定精准的运营策略，从而提升MMO类游戏的用户体验，实现获客增长和受益增长。查看MMO分析报告前需要配置"MMO"埋点方案模板，配置模板方法详情请参见[埋点开发](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/tracing-point-development-0000001078556280)。
* [通用](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/game-general-0000001383244957)：针对游戏行业提供通用游戏分析报告，从数据概览、付费分析、玩家分析、虚拟消费、战斗分析、区服分析多维度呈现用户的行为。通过通用游戏分析报告，您可以清晰洞察通用游戏类应用的关键指标数值并制定精准的运营策略，从而提升通用类游戏的用户体验，实现获客增长和受益增长。查看通用游戏分析报告前需要配置游戏下"通用"埋点方案模板，配置模板方法详情请参见[埋点开发](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/tracing-point-development-0000001078556280)。
* [职业与成人](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/careers-industry-analysis-0000001123086880)：您可以清晰洞察职业与成人类应用的关键指标数值，从数据概览、付费转化、学习与考试和活动运营多维度了解用户的行为，并制定精准的运营策略，实现获客增长。查看职业与成人分析报告前需要配置"职业与成人"埋点方案模板，配置模板方法详情请参见[埋点开发](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/tracing-point-development-0000001078556280)。
