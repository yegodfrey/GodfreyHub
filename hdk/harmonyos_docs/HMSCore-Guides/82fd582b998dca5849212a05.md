# 服务商

* 华为支付商户与华为支付之间的连接者，为商户提供开户申请、支付接入、技术开发等综合解决方案机构。
* 服务商需在中国支付清算协会备案，由服务商推荐在华为支付入网的商户即为特约商户。
* 服务商自身无法直接发起交易，其发起交易必须传入相关特约商户商户号的参数信息。
* 服务商可自行前往[华为支付商户平台](https://petalpay-merchant.cloud.huawei.com/) ，合作身份选择"服务商"，填写信息后提交入网申请；特约商户的入网指导[请点击这里](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-xinzengteyueshanghu-0000001768008749)查阅。
