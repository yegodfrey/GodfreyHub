# 业务简介

普通商户分账，主要用于普通商户完成订单收款后的资金分配。根据普通商户请求的分账规则，将订单款分给分账接收方。

## 场景介绍

**分账给合作伙伴**

在与合作方（如：导流平台、物流合作商）合作的业务背景下，可将合作方添加为分账接收方，按照合作协议约定，将资金分给合作方。

## 名词解释

**分账方**：指支付交易的收单方、分账交易的实际出资方。

**分账接收方** ：指资金分账的收款方, 商户管理员可在[华为支付商户平台](https://petalpay-merchant.cloud.huawei.com/)上添加管理对应的分账接收方。
