# 取消订阅

在收到用户申诉不希望对订阅续期后，您的服务器可以调用华为应用内支付服务器提供的取消订阅接口停止续期，商品在当前订阅周期结束前仍然有效，但后续的续期会终止。当前订阅周期结束后，取消的订阅型商品会处于失效期。失效的订阅具有保留期（保留期详见以下说明）。在保留期内，用户可以随时恢复订阅。
> 说明
>
> 失效订阅的保留期：
>
> * 中国大陆：180天
> * 其他国家或地区：30天

具体实现请参见[取消订阅](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-cancel-subscription-0000001050746115)。
