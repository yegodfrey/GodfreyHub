# （可选）iTunes Connect配置

DTM SDK支持采集IDFA。

若您使用了IDFA，理论上需要集成任意一家的广告服务。若您的App使用了IDFA，但未使用任何广告，需要在iTunes Connect中进行如下配置，否则，跳过此章节。

        1. 在iTunes Connect中提交新版本审核时，在“Advertising Identifier”选项中，点击选择“Does this app use the Advertising Identifier(IDFA)?”后的“Yes”。
        2. 在“Advertising Identifier”下的子选项中，进行如下配置。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8b/v3/X_tf1DhxS_ahOtcrvT8_NQ/zh-cn_image_0000001070863915.png?HW-CC-KV=V1&HW-CC-Date=20261005T043043Z&HW-CC-Expire=86400&HW-CC-Sign=AA414256E632D19910F300D19B6C4E072773D4B4A93E184958D7A2B906D62E3C)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c3/v3/2_NQHzPmSfiC27XNhXRqDQ/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043043Z&HW-CC-Expire=86400&HW-CC-Sign=A54949110435B8508DBEB9C3C01744AC61C11FB91F0BD8F6A8135FA4F2172D1E)

           1. Serve advertisements within the app

服务应用中提供广告。若您的应用中集成了广告，需要勾选这一项；否则，不勾选。

           2. Attribute this app installation to a previously served advertisement

此应用程序将跟踪广告带来的安装。需要勾选。

           3. Attribute an action taken within this app to a previously served advertisement

此应用程序将跟踪广告带来的用户的后续行为。需要勾选。

           4. Limit Ad Tracking setting in iOS

将在iOS系统中设置广告跟踪的限制。需要勾选。
