# 版本更新说明  
  
#### 6.6.0-300（2022-07-07）

本次HarmonyOS（JavaScript）版本特性变更如下： **修改特性**
                * 优化接口空值传参问题，当接口参数传入无效值时，将会使用默认值。 
                  * [getInstance](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-api-hianalytics-instance-0000001204763599#section14289539163414)接口routePolicy参数。 
                  * [pageStart](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-api-hianalytics-instance-0000001204763599#section111581350115113)接口pageClassOverride参数。 
                  * [enableLog](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-api-hianalytics-instance-0000001204763599#section15775410448)接口level参数。 
                * SDK包名由“hmscore/analytics-sdk-harmony”修改为“hw-hmscore/analytics-sdk-harmony”。
