# 接入说明

#### 功能说明

GameTurbo Engine提供API接口，帮助开发者快速实现游戏App与系统的交互。开发者通过GameTurbo Engine，可以完成向系统发送游戏数据以及从系统获取设备状态信息两大动作。  

#### 场景介绍

GameTurbo Engine服务于游戏场景优化。其特点是可以通过游戏场景和运行状态的不同，使用不同策略调度系统资源以达到更精细化的优化效果。  

#### 使用说明

1. 获取能力对象。

   <br />

   ```
   private GameManager mGameManager = GameManager.getGameManager();
   ```

   <br />

2. 向设备注册应用。

   <br />

   如果不需要监听设备信息变化，可以使用以下方式注册：

   ```
   boolean isSuccess = mGameManager.registerGame(packageName, null);
   ```

   如果需要监听设备信息变化，可以通过注册时传入[GameCallBack](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/gamecallback-0000001050121692)对象来实现监听：

   ```
   private GameCallBack gameSdkCallBack = new GameCallBack() {
       @Override
       public void onPhoneInfoUpdated(String info) {
           Log.i(TAG, "onPhoneInfoUpdated: " + info);
       }
   };
   boolean isSuccess = mGameManager.registerGame(packageName, gameSdkCallBack);
   ```

   如果需要更换回调接口，可以再次调用[registerGame](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/gamemanager-0000001050123643#section1374617317199)方法并传入新的回调接口。更换后，之前注册的回调接口不再生效。

   <br />

3. 向设备发送消息。

   <br />

   ```
   JSONObject jsonObject = new JSONObject();
   try {
       jsonObject.put("MessageType", 3);
       jsonObject.put("SceneID", 1);
       jsonObject.put("Description", "Game Start");
       jsonObject.put("ImportantLevel", 2);
       jsonObject.put("Status", 1);
       jsonObject.put("RecommendFps", 60);
       jsonObject.put("KeyThread", "net|6001");
       String message = jsonObject.toString();
       mGameManager.updateGameAppInfo(message);
   } catch (JSONException e) {
       // Process exception
   }
   ```

   <br />

4. 主动获取设备信息。

   <br />

   ```
   String phoneInfo = mGameManager.getPhoneInfo();
   ```

   <br />
