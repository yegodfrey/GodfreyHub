# 业务介绍

## 业务简介

随着用户设备类型的不断增加，手机、平板、大屏、车载等设备对应用UI界面开发提出了更加多样化的诉求，这就需要应用开发者在开发应用界面的时候考虑多种设备场景，从而导致维护代码增加，甚至需要维护多个工程来适配不同设备。华为UI Engine是华为提供的一套UI开发能力集合，其中的智能界面开发包旨在帮助应用开发者快速开发UI界面，自动的适配多种不同的屏幕形态，以达到一次开发多设备自动适配运行的目的。

## 业务特点

智能界面开发包是华为UI Engine的一个重要组成部分，是提供给应用开发者进行多设备UI开发的解决方案套餐，其提炼了最常见的多端UI设计思路，最大限度地提炼其中的公共能力，尽可能覆盖TOP频率的需求，协助完成界面的布局、交互、元素拼装等工作。

华为UI Engine提供的能力：

* 多态控件：对外表述一致，内部实现多态，不同的设备下有符合该设备特征的实现。
* 动态布局：提供基于栅格化设计理念的边距自适应能力，以及其他信息结构布局能力，可以使界面布局具备屏幕自适应特性。
* 工程模板：DevEco IDE提供了多种UI Engine工程模板，开发者可以通过引用模板创建工程快速了解、接入华为UI Engine能力。

## 场景介绍

华为UI Engine智能界面开发包提供用来处理信息结构（界面描述）的能力，其提供不同颗粒度的组件，组件本身完成了各设备下的差异实现，可以协助开发者实现一次开发多个设备下自适应布局的能力。其覆盖的主要内容有单体/复合控件，动态布局等。
