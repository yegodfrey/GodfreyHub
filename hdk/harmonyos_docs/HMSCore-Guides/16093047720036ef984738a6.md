# A/B测试

使用A/B测试，可以让科学的实验数据来帮助您优化应用体验、提升关键转化及增长指标。您可以为不同的用户群体创建一组或多组对比实验，通过实验得出关键对比数据，选择更符合用户需求的应用界面、文案、产品功能或营销活动，从而根据用户反馈做出方案选择，提高决策准确率，降低决策风险。

创建A/B测试详情请参见[创建推送通知类实验](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-abtest-notification-0000001058890688)。
