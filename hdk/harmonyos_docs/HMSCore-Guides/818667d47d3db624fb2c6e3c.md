# 业务介绍

地图服务（Map Kit）提供强大而便捷的地图服务能力，助力全球开发者实现个性化地图呈现与交互，轻松完成地图构建工作。

* [Android](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-brief-introduction-0000001061991343)：地图Android SDK是一套地图开发调用接口，您可以轻松地在自己的Android应用中加入地图相关的功能，包括：地图呈现、地图交互、在地图上绘制、自定义地图样式等功能。
* [HarmonyOS（Java）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-sdk-introduction-0000001147819099)：地图HarmonyOS Java SDK是一套地图开发调用接口，您可以轻松地在自己的HarmonyOS应用中加入地图相关的功能，包括：地图呈现、地图交互、在地图上绘制等功能。
* [iOS（Objective-C）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-introduction-0000001197914654)：地图iOS SDK是一套地图开发调用接口，您可以轻松地在自己的iOS应用中加入地图相关的功能，包括：地图呈现、地图交互、在地图上绘制、自定义地图样式等功能。
* [PetalMaps Intents for Android](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/petal-maps-introduction-0000001059189679)：地图提供Intent方式拉起花瓣地图App，调用周边搜索、关键字搜索、路径规划和导航等功能。
* [JavaScript API](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/javascript-api-introduction-0000001050164063)：地图JavaScript API是一套由JavaScript语言编写的应用程序接口，提供了地图呈现、地图交互、自定义地图样式、路线规划、地理编码等功能，可帮助您在网站中构建功能丰富、交互性强的地图应用，支持PC端和移动端基于浏览器的地图应用开发。
* [REST API](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-api-introduction-0000001081130437)：地图REST API提供HTTP/HTTPS接口，您可以通过HTTP/HTTPS形式发起请求，获取返回JSON格式的数据。
* [Flutter Plugin](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/flutter-plugin-introduction-0000001252701459)：Flutter地图插件可实现HMS Core Map SDK与Flutter平台之间的通信。通过此插件，您可以轻松地将地图相关功能集成到您的应用中。
