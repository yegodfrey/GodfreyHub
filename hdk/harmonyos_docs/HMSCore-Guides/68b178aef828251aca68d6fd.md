# 接入华为帐号获取凭证

#### 接入华为帐号

用户选择"华为帐号"来进行登录，应用处理该按钮的点击事件，拼接OAuth服务请求授权的链接，把用户浏览器重定向到该请求链接，跳转访问OAuth服务。

示例如下

```
<html>
<head>
    <title>Demo</title>
    <meta http-equiv="Content-Type" content="text/html; charset=UTF-8" />
    <meta name="client_id" content="APP ID" />
    <meta name="redirect_uri" content="应用的回调地址" />
    <meta name="scope" content="openid+profile" />
</head>
<body>
    <p> <button id="hwlogin" onclick=redirect()>HUAWEIID login</button></p>
</body>
<script type="text/javascript">
         var client_id ='',redirect_uri='',scope='';
         for(var metas=document.getElementsByTagName("meta"),i=0;i<metas.length;++i){
                   switch(metas[i].name) {
              case 'client_id':
                 client_id = metas[i].content;
                 break;
              case 'redirect_uri':
                  redirect_uri = metas[i].content;
                 break;
              case 'scope':
                 scope = metas[i].content;
                 break;
              default:break
                   }
         }
         var redirectUrl='https://oauth-login.cloud.huawei.com/oauth2/v3/authorize?'+
 'response_type=code&access_type=offline&state=state_parameter_passthrough_value&client_id='+client_id +'&redirect_uri='+ redirect_uri +'&scope='+ scope;
 
function redirect() {
         window.location.href=redirectUrl;
}
</script>
</html>
```

跳转链接地址如下

```
https://oauth-login.cloud.huawei.com/oauth2/v3/authorize?
response_type=code&
access_type=offline&
state=state_parameter_passthrough_value&
client_id=APP ID&
redirect_uri=应用的回调地址&
scope=openid+profile
```

|参数名称|是否必选|参数说明|
|:------------|:---|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|response_type|是|填写为"code"，表示为[授权码模式](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-oauth-0000001053629189#section1022911426469)。|
|client_id|是|在[开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/web-preparations-0000001050050891)中创建的服务器应用的App ID。|
|redirect_uri|是|授权后要回调的地址URL，即应用接收授权码code的URL。如回调地址为：https://www.thirdwebdemo.com/redirect_url，与[开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/web-preparations-0000001050050891)中所配置的回调地址一致。在此地址后可添加单个其他参数为：https://www.thirdwebdemo.com/redirect_url?somearg=XXXXXX。|
|scope|是|一个字符串数组，以空格分开（URL编码后空格变为加号+），必须包含字符串"openid"。|
|access_type|否|枚举值，确定响应是否包含Refresh Token，Refresh Token用于刷新Access Token。 * 为offline时，返回响应包含Refresh Token。 * 为online或不传该值时，返回响应不包含Refresh Token。|
|state|否|推荐使用高品质随机数生成器构造的字符串，或者使用保存在后端的密钥对部分会话状态变量进行签名从而生成的哈希串；满足正则匹配"\^\[0-9a-zA-Z:/\\.\]+$"，建议长度在100字符以内，授权服务器在回调时（重定向用户浏览器到"redirect_uri"时），会在uri中原样回传该参数。OAuth2.0标准协议建议，利用state参数来防止CSRF攻击。|

#### 用户登录并授权

当请求跳转到OAuth服务，OAuth服务会引导用户进行授权，弹出授权页面给用户，显示应用的名称和图标，以及该应用所申请授权的scope权限列表，输入华为帐号及密码完成登录授权。

#### 服务响应

OAuth服务将响应值通过回调地址redirect_uri回调给应用。

* 如果用户同意授权，则回调请求中带有授权码code。

  ```
  https://www.thirdwebdemo.com/redirect_url?
  code=<返回的授权码code>&
  state=state_parameter_passthrough_value
  ```

* 如果用户不同意授权，则回调请求中包含错误消息。

  ```
  https://www.thirdwebdemo.com/redirect_url #error=1107&error_description=access+denied
  ```

#### 应用换取凭证

应用在获取到授权码code后，再次请求OAuth服务，调用https://oauth-login.cloud.huawei.com/oauth2/v3/token，通过授权码code换取Access Token、Refresh Token以及ID Token。

请求参数  

|参数名称|是否必选|参数说明|
|:------------|:---|:-------------------------------------------------------------------------------------------------------------------------------------------|
|grant_type|是|OAuth 2.0规范定义的字段，必须为"authorization_code"。|
|code|是|与[OAuth服务的响应](#section151118514311)中返回的授权码code一致。|
|client_id|是|[开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/web-preparations-0000001050050891)中创建的服务器应用的APP ID。|
|client_secret|是|[开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/web-preparations-0000001050050891)中给创建服务器应用ID分配的密钥APP SECRET。|
|redirect_uri|是|与[接入华为帐号](#section1139031473110)传入的回调地址一致。|

请求示例

请通过POST方式调用，示例如下：

```
POST /oauth2/v3/token HTTP/1.1
Host: oauth-login.cloud.huawei.com
Content-Type: application/x-www-form-urlencoded
 
grant_type=authorization_code&
code=<返回的授权码code>&
client_id=<APP ID>&
client_secret=<APP SECRET>&
redirect_uri=<应用的回调地址>
```

响应参数  

|参数名称|是否必选|参数说明|
|:------------|:---|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|access_token|是|用户的鉴权凭证（Access Token）。|
|expires_in|是|Access Token的剩余有效期，单位：秒。|
|scope|是|生成的Access Token中包含的scope。|
|token_type|是|固定返回Bearer，标识返回Access Token的类型。|
|id_token|是|返回[JWT格式数据](https://jwt.io/introduction/)。如果[接入华为帐号](#section1139031473110)的入参scope中包含权限profile、email，应用在本地完成ID Token校验后（请参见[ID Token本地验证签名](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-oauth-0000001053629189#section1991115414569)），可直接解析JWT数据得到用户基本帐号信息、用户邮箱信息，无需再次请求华为用户信息服务器进行获取（解析后字段请参见[ID Token字段解析](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-oauth-0000001053629189#section4534101916407)）。|
|refresh_token|否|如[接入华为帐号](#section1139031473110)的入参中包含access_type=offline，则会返回此参数，该参数用于刷新Access Token。|

响应示例

```
HTTP/1.1 200 OK
Content-Type: text/json ; charset=UTF-8
Cache-Control: no-store
 
{
  "access_token": "<返回的Access Token>",
  "refresh_token": "<返回的Refresh Token>",
  "expires_in": 3600,
  "scope": "profile openid",
  "token_type": "Bearer",
  "id_token": "<返回的JWT格式的ID Token>"
}
```
