# 申请权限

基于安全考虑，服务侧对GameTurbo Engine开放的接口做了权限保护处理，使用相关接口需要向华为方申请对应权限。权限申请需提供开发者联盟网站创建应用时生成的应用ID，且指纹信息已配置。权限申请请联系[devConnect@huawei.com](mailto:devConnect@huawei.com)，主题标明GameTurbo Engine权限申请。

以下权限不需要在代码中声明，但在使用GameTurbo Engine时需要根据需求申请对应的权限。GameTurbo Engine相关的权限如下：

1. GameTurbo Engine基础权限，使用GameTurbo Engine必须要申请。

   ```
   com.huawei.game.kitserver.permission.register
   ```

2. 游戏获取GameTurbo Engine上报数据的权限，如需使用GameTurbo Engine上报数据能力，则需要申请该权限。

   ```
   com.huawei.game.kitserver.permission.report
   ```
