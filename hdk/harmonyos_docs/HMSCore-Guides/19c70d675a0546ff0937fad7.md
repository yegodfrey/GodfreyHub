# 通用  
  
#### 事件参数列表

      * REGISTERACCOUNT

用户注册帐号时，上报此事件。可以分析用户来源，有针对性的优化运营策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
REGISTMETHOD | 注册方式 | String | 可选 | 用户的注册方式，如：邮箱、手机号、微信等。  
ACOUNTTYPE | 帐号类型 | String | 可选 | 用户帐号类型，如：邮箱、手机号、微信等。  
TASKID | 任务ID | String | 可选 | 营销任务ID。  
  
      * REGISTERFAILED

用户注册帐号失败时，上报此事件。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
REGISTMETHOD | 注册方式 | String | 可选 | 用户的注册方式，如：邮箱、手机号、微信等。  
ACOUNTTYPE | 帐号类型 | String | 可选 | 用户帐号类型，如：邮箱、手机号、微信等。  
TASKID | 任务ID | String | 可选 | 营销任务ID。  
  
      * BINDACCOUNT

用户绑定其他类型帐号时上报此事件。分析用户的登录习惯，有针对性地制定运营策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
ACOUNTTYPE | 帐号类型 | String | 可选 | 用户绑定的帐号类型，如：邮箱、手机号、微信等。  
TASKID | 任务ID | String | 可选 | 营销任务ID。  
  
      * COMPLETEPURCHASE

用户支付完成后，上报此事件。可以用于分析用户对哪些商品或内容更感兴趣，优化运营策略。

华为应用内支付服务（In-App Purchases，IAP）渠道发生的支付，不需要上报COMPLETEPURCHASE事件。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
PRODUCTID | 商品ID | String | 必选 | 被添加到购物车中的商品ID。  
PRODUCTNAME | 商品名称 | String | 必选 | 被添加到购物车中的商品名称。  
QUANTITY | 购买数量 | Long | 必选 | 用户准备购买的数量。  
CURRNAME | 货币类型 | String | 可选 | 标识收入的货币类型。与REVENUE一起使用。  
REVENUE | 收入 | Double | 可选 | 本次交易给您带来的收入。必须与CURRNAME同时使用。  
PLACE | 位置ID | String | 可选 | 商品所在地标识。  
BRAND | 商品品牌 | String | 可选 | 关联的商品品牌。  
CATEGORY | 商品分类 | String | 可选 | 关联的商品分类。  
TASKID | 任务ID | String | 可选 | 营销任务ID。  
  
      * CANCELCHECKOUT

用户已经下单，并开始支付，支付过程中，取消支付时，上报此事件。可用于分析用户流失原因。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
REASON | 取消支付原因 | String | 必选 | 用户取消支付的原因。  
STEP | 结算步骤数 | String | 必选 | 标识用户当前处于结算过程中的第几个步骤。  
REVENUE | 收入 | Double | 可选 | 本次交易给您带来的收入。必须与CURRNAME同时使用。  
CURRNAME | 货币类型 | String | 可选 | 标识收入的货币类型。与REVENUE一起使用。  
TASKID | 任务ID | String | 可选 | 营销任务ID。  
  
      * VIPCLICK

用户点击开通会员时，上报此事件。用于分析用户开通会员的场景。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
VIPLOCATION | 点击位置 | String | 可选 | 用户开通会员点击按钮的位置，如：我的页面、内容页面、活动页面。  
USERID | 用户ID | String | 可选 | 触发事件用户的ID。  
USERLEVEL | 用户等级 | String | 可选 | 触发事件用户的等级。  
TASKID | 任务ID | String | 可选 | 营销任务ID。  
  
      * VIPFAILED

用户开通会员失败时，上报此事件。用于分析用户开通失败的原因。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
VIPFAILED | 失败原因 | String | 可选 | 用户会员开通失败的原因。  
USERID | 用户ID | String | 可选 | 触发事件用户的ID。  
USERLEVEL | 用户等级 | String | 可选 | 触发事件用户的等级。  
TASKID | 任务ID | String | 可选 | 营销任务ID。  
  
      * VIPSUC

用户开通会员成功时，上报此事件。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---

VIPEXPIREDATE | VIP到期时间 | String | 可选 | 用户本次开通会员后的会员到期时间。  
USERID | 用户ID | String | 可选 | 触发事件用户的ID。  
USERLEVEL | 用户等级 | String | 可选 | 触发事件用户的等级。  
VIPMONEY | VIP金额 | Long | 可选 | 用户会员开通的付费金额。  
TASKID | 任务ID | String | 可选 | 营销任务ID。

      * PERMISSIONAPPLICATION

向用户申请某项权限，或者用户同意、拒绝某项权限时上报该事件。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---
