# 静默登录

## 场景介绍

用户首次使用帐号登录应用后，再次登录时，无需重复授权。

静默登录与普通登录的区别如下：

|登录方式|未登录，未授权|未登录，已授权|已登录，已授权|已登录，未授权|
|:---|:---------------------------|:------------------|:----------|:--------------|
|普通登录|先展示登录页，输入帐号、密码，登录成功后再展示授权页面。|展示登录页，输入帐号、密码，登录成功。|用户无感知，登录成功。|展示授权页面，授权后登录成功。|
|静默登录|立刻感知，并抛异常。|立刻感知，并抛异常。|用户无感知，登录成功。|立刻感知，并抛异常。|

> 说明
>
> 对于静默登录抛异常的场景，应用可以调用[getSignInIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section76155516411)方法授权登录，获取用户信息。
>
> 此外，如果切换了用户，且新用户已经授权过，那么会收到新的授权信息，应用可以根据ID判断出用户发生了变化。

## 业务流程

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230626155608.64878402873487146662895531783776:50001231000000:2800:12AACD7EC8438C8D00683746F18C50DF0BF1C2E16FD8193737AC23A64745FBE9.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

整体流程：

1. 用户进行了触发静默登录的场景，根据应用实际场景由您自行设定。
2. 应用客户端调用[AccountAuthParamsHelper](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthparamshelper-0000001050438849)的默认构造方法配置鉴权参数。
3. 帐号SDK向应用客户端返回包含授权参数的[AccountAuthParams](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthparams-0000001050196616)对象。
4. 应用客户端调用[AccountAuthManager.getService](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hms-support-account-accountauthmanager-0000001050193690#section1354442711181)方法初始化[AccountAuthService](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395)对象。
5. 帐号SDK向应用客户端返回[AccountAuthService](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395)对象。
6. 应用客户端调用[AccountAuthService.silentSignIn](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section782995853116)方法向帐号SDK发起静默登录请求。
7. 帐号SDK检查用户是否符合静默登录的授权，并向应用客户端返回授权结果。
8. 应用客户端根据授权结果自行确定后续处理。

## 开发步骤

静默登录功能涉及应用的关键开发步骤如下：

1. 调用[AccountAuthParamsHelper](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthparamshelper-0000001050438849)的默认构造方法配置授权参数。

   ```screen
   "Java"
   AccountAuthParams authParams = new AccountAuthParamsHelper(AccountAuthParams.DEFAULT_AUTH_REQUEST_PARAM).createParams();
   ```

   ```javascript
   "Kotlin"
   val authParams : AccountAuthParams = AccountAuthParamsHelper(AccountAuthParams.DEFAULT_AUTH_REQUEST_PARAM).createParams()
   ```

2. 调用[AccountAuthManager](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hms-support-account-accountauthmanager-0000001050193690)的[getService](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hms-support-account-accountauthmanager-0000001050193690#section1354442711181)方法初始化[AccountAuthService](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395)对象。

   ```screen
   "Java"
   AccountAuthService service = AccountAuthManager.getService(MainActivity.this, authParams);
   ```

   ```javascript
   "Kotlin"
   val service : AccountAuthService = AccountAuthManager.getService(this@MainActivity, authParams)
   ```

3. 调用[AccountAuthService.silentSignIn](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section782995853116)方法发起静默登录请求。

   ```screen
   "Java"
   Task<AuthAccount> task = service.silentSignIn();
   ```

   ```javascript
   "Kotlin"
   val task : Task<AuthAccount> = service.silentSignIn()
   ```

4. 处理授权结果。

   如果授权成功，可获取用户的帐号信息，允许用户登录。

   应用可根据[authAccount.getAccountFlag](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/authaccount-0000001050315810#section155944155317)的结果判断当前登录帐号的渠道类型。
   > 说明
   >
   > authAccount.getAccountFlag返回当前登录帐号的渠道类型。
   > * 0：代表华为帐号，调用服务端接口请用此URL：https://oauth-login.cloud.huawei.com/xxx。
   > * 1：代表AppTouch帐号，调用服务端接口请用此URL：https://oauth-login-at.cloud.huawei.com/xxx。

   ```screen
   "Java"
   task.addOnSuccessListener(new OnSuccessListener<AuthAccount>() {
       @Override
       public void onSuccess(AuthAccount authAccount) {
           //获取帐号信息
           Log.i(TAG, "displayName:" + authAccount.getDisplayName());
           //获取帐号类型，0表示华为帐号、1表示AppTouch帐号
           Log.i(TAG, "accountFlag:" + authAccount.getAccountFlag());
       }
   });
   ```

   ```javascript
   "Kotlin"
   task.addOnSuccessListener { authAccount ->
       //获取帐号信息
       Log.i(TAG, "displayName:" + authAccount.displayName)
       //获取帐号类型，0表示华为帐号、1表示AppTouch帐号
       Log.i(TAG, "accountFlag:" + authAccount.accountFlag);
   }
   ```

   如果授权失败，可能是用户之前未进行过登录授权，应用可自行确认是否需要调用[AccountAuthService](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395)的[getSignInIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section76155516411)方法显式展示登录授权页面。

   ```screen
   "Java"
   task.addOnFailureListener(new OnFailureListener() {
       @Override
       public void onFailure(Exception e) {
           //登录失败，您可以尝试使用getSignInIntent()方法显式登录
           if (e instanceof ApiException) {
               ApiException apiException = (ApiException) e;
               Log.i(TAG, "sign failed status:" + apiException.getStatusCode());
           }
       }
   });
   ```

   ```javascript
   "Kotlin"
   task.addOnFailureListener { e ->
       //登录失败，您可以尝试使用getSignInIntent()方法显式登录
       if (e is ApiException) {
           Log.i(TAG, "sign failed status:" + e.statusCode)
       }
   }
   ```
