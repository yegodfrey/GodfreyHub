# 准备开发环境

要使用地图服务Flutter插件，您需要在计算机上设置Flutter开发环境。使用Flutter进行开发的详细要求，请参见[Flutter安装指南](https://flutter.dev/docs/get-started/install)。

1. 在电脑上成功安装Flutter后，请在命令行运行flutter doctor命令，以确保开发环境运行一切正常。

   命令执行完后查看回显信息。

## 安装HMS Core（APK）

要使用地图服务的接口，您需要在设备上下载并安装最新版本的HMS Core（APK）。

## 安装Android SDK

执行如下操作：

1. 下载Android SDK 10.0（API level 29）和9.0（API level 28）： 选择"Settings > Android SDK > SDK Platforms"，选中Android 10.0和Android 9.0，点击OK。Android Studio将自动下载并安装Android SDK 10.0（API level 29）和9.0（API level 28）。

2. 设置环境变量ANDROID_HOME： 打开Windows中的控制面板，选择"System and Security > System > Change settings > Advanced > Environment Variables > New"，创建一个指向Android SDK目录的系统或用户变量ANDROID_HOME。

   > 说明
   > * 默认情况下，Android SDK安装在"C:\Users\Your_Username\AppData\Local\Android\Sdk"目录中。请注意，根据您的首选项设置，AppData文件夹可能会隐藏。
   > * 要查看Android SDK的位置，打开Android Studio，选择"File > Settings"。然后，选择"Appearance & Behavior > System Settings > Android SDK"，在右侧窗格中单击"Android SDK Location"。
3. 将Path添加至platform-tools目录： 打开Windows中的控制面板，选择"System and Security > System > Change settings > Advanced > Environment Variables"，选择Path变量，点击Edit。然后，单击New，将platform-tools目录添加到列表中。

   > 说明
   >
   > platform-tools目录在Android SDK目录下。设置环境变量ANDROID_HOME后，将"%ANDROID_HOME%\platform-tools"添加到Path变量中。
