# 使用入门

## 快速上手

在您正式开发应用之前，可以通过[Codelab](https://github.com/huaweicodelabs/ScanKit)快速体验一个应用的开发过程。

## 开发环境

* 安装[Android Studio](https://developer.android.com/studio) 3.X及以上
* [JDK](https://www.oracle.com/java/technologies/javase-downloads.html) 1.8.211及以上
* 您的应用应满足以下条件：
  * minSdkVersion 21及以上
  * targetSdkVersion 35（推荐）
  * compileSdkVersion 33（推荐）
  * Gradle 4.6及以上（推荐）
* SDK Platform 21及以上

## 开发流程

您需要按照流程来完成应用的开发工作，完整的开发流程如下。

|序号|步骤|说明|
|:-|:------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-config-agc-0000001050043955)|在开发应用前，需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中配置相关信息。包括：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-config-agc-0000001050043955#section14236151634819)、[创建应用](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-config-agc-0000001050043955#section89308574495)。|
|2|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-integrating-sdk-0000001050042006)|在开发应用前，您需要将华为统一扫码SDK集成到您的开发环境中。|
|3|[配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-config-obfuscation-scripts-0000001050043957)|编译APK前需要配置混淆配置文件，避免混淆华为统一扫码SDK导致功能异常。|
|4|[添加权限](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-assighing-permissions-0000001050043959)|在"AndroidManifest.xml"文件中配置应用所需权限。|
|5|[构建扫码功能](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-overview-0000001050282308)|Scan Kit提供了单码能力[Default View Mode](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-default-view-0000001050043961)方式扫码、多码能力[MultiProcessor Mode](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-synchronous-mode-0000001050043967)同步条码检测方法、图片解码能力[Bitmap](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-bitmap-camera-0000001050042014)方式解码和支持您自定义扫码界面的[Customized View Mode](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-customized-view-0000001050042012)。建议您先阅读[扫码模式选择](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-overview-0000001050282308)再进行选择。|
|6|[构建码生成功能](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/scan-generate-barcode-0000001050995005)|Scan Kit支持将字符串转换为一维码或二维码，目前已支持的码制式为EAN-8、EAN-13、UPC-A、UPC-E、Codabar、Code 39、Code 93、Code 128、ITF14、QR、DataMatrix、PDF417、Aztec。|
|7|[码值解析](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-parsing-result-codes-0000001050043969)|您可能需要对码在输入图片中的坐标、码的原始数据、码的制式、结构化数据、zoomValue等信息的解析。|
|8|[开发后自检](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/pre-release-check-0000001050042026)|华为提供对应用自动检查的能力。|
|9|[上架申请](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/app-release-0000001050755407)|开发完成后需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中将应用信息补充完整并提交上架申请。|

华为还为您提供了高效的集成开发工具[HMS Toolkit](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/overview-0000001050060881)，该工具提供了包括开发接入、免费真机调测、版本发布等端到端的接入HMS Core的工具链，助力您以更高的开发效率和更低的开发成本集成HMS Core服务，并打造出色的应用。

点击[这里](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/scan-toolkit-integration-0000001150185733)了解HMS Toolkit集成该Kit最佳实践。
