# 游戏登录

#### 场景介绍

游戏登录是指用户使用自己的华为帐号登录游戏。游戏启动并完成系统权限授权后，为了实现华为游戏SDK提供的登录功能，需要先进行SDK初始化，初始化过程中，游戏服务会向用户弹出华为联运隐私协议弹框。用户同意联运隐私协议后即可进入游戏登录页面，体验过程如下。

#### 实名认证说明

发布地为中国大陆的游戏必须进行实名认证。按照国家新闻出版署规定，所有网络游戏必须接入国家新闻出版署网络游戏防沉迷实名验证系统。华为游戏服务提供了华为帐号登录时的实名认证功能，您只需向当地的新闻出版局申请接入网络游戏防沉迷实名认证系统，并获取"bizID（游戏备案识别码）"，再将bizID配置到AppGallery Connect，华为将为您的游戏自动对接国家新闻出版署的实名认证系统并开启强制实名认证，无需您进行额外的开发。具体操作请参见[版署实名认证申请](https://developer.huawei.com/consumer/cn/doc/app/game-center-identification-applyfor-0000001193982458)。  

#### 前提条件

* 实现游戏初始化前，必须已经完成AppGallery Connect的配置准备，参见[AGC控制台准备](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-agc-0000001281025916)。

* 已完成[集成SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/integrate-as-sdk-0000001050435953)和[配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-obfuscation-scripts-0000001050166287)。  

#### 注意事项

* 如果玩家拒绝登录，不要重复调用登录接口，避免玩家在开始游戏时反复拒绝登录。

* 游戏必须在调用[PlayersClient.getGamePlayer](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/playersclient-0000001050121668#section42128343142)成功后才能允许用户进入游戏，否则会导致审核被驳回。
* 发布地为中国大陆的游戏不允许跳过帐号登录或者在游戏内登录。

1. 在Application的onCreate方法中添加如下代码，用于注册Activity的回调监听。

   ```
   public class MyApplication extends Application{ 
       @Override
       public void onCreate(){
           super.onCreate();
           HuaweiMobileServicesUtil.setApplication(this);
       }
   }
   ```

   编译前请确认应用的Manifest文件中application已经配置了Application类的名称，例如"android:name=".MyApplication""。
2. 调用[JosApps.getJosAppsClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/josapps-0000001050123631#section162141030162218)方法初始化[JosAppsClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/josappsclient-0000001050121680)对象，并调用[JosAppsClient.init(AppParams appParams)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/josappsclient-0000001050121680#section12941311162615)方法进行游戏服务SDK初始化。
   * 设置防沉迷回调：发布中国大陆地区的游戏需要设置[AntiAddictionCallback](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/antiaddictioncallback-0000001161473738)防沉迷回调，当满足以下条件时游戏会将结果回调给您。
     * 已实名的未成年人在非规定游戏时间内登录游戏，游戏服务会弹框提示用户不允许游戏，玩家点击"确定"。
     * 已实名的未成年人在规定时间内登录游戏，当游戏进行到国家规定的防沉迷截止时间时，游戏服务会弹框提示玩家已到游戏时间，玩家点击"知道了"。

您需要在onExit方法中实现触发防沉迷后的游戏保存、退出游戏等功能。  

#### 华为帐号授权

在游戏登录前，游戏需要调用华为帐号SDK提供的[silentSignIn](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section782995853116)接口进行华为帐号的静默授权。

* 如果静默授权成功，直接跳转到[游戏登录](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/app-dev-tv-login-0000001461311313#section79001559173318)进行游戏登录。
* 如果静默授权失败，再调用显式授权接口[getSignInIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section76155516411)，显式拉起华为帐号授权页面进行授权。授权成功后，继续参考[游戏登录](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/app-dev-tv-login-0000001461311313#section79001559173318)进行游戏登录，否则禁止进入游戏。

```
public AccountAuthParams getHuaweiIdParams() {
    return new AccountAuthParamsHelper(AccountAuthParams.DEFAULT_AUTH_REQUEST_PARAM_GAME).createParams();
}
```

```
public void signIn() {
    // 必须在init成功后，才可以继续调用华为帐号静默授权接口
    Task<AuthAccount> authAccountTask = AccountAuthManager.getService(this, getHuaweiIdParams()).silentSignIn();
    authAccountTask.addOnSuccessListener(
        new OnSuccessListener<AuthAccount>() {
            @Override
            public void onSuccess(AuthAccount authAccount) {
                // 获取AuthorizationCode
                authorizationCode = authAccount.getAuthorizationCode();
                showLog("Authentication succeeded.");
                getGamePlayer();   // 调用游戏登录接口
        }
     })
    .addOnFailureListener(
        new OnFailureListener() {
            @Override
            public void onFailure(Exception e) {
                if (e instanceof ApiException) {
                    ApiException apiException = (ApiException) e;
                    showLog("signIn failed:" + apiException.getStatusCode());
                    showLog("start getSignInIntent");
                    // 在此处实现华为帐号显式授权
                    Intent intent = AccountAuthManager.getService(MainActivity.this,getHuaweiIdParams()).getSignInIntent();
                    startActivityForResult(intent, SIGN_IN_INTENT);
            }
        }
    });
}
@Override
protected void onActivityResult(int requestCode, int resultCode, Intent data) {
	super.onActivityResult(requestCode, resultCode, data);
	if (SIGN_IN_INTENT == requestCode) {
		if (null == data) {
			showLog("signIn intent is null");
			return;
		}
		String jsonSignInResult = data.getStringExtra("HUAWEIID_SIGNIN_RESULT");
		if (TextUtils.isEmpty(jsonSignInResult)) {
			showLog("SignIn result is empty");
			return;
		}
		try {
			AccountAuthResult signInResult = new AccountAuthResult().fromJson(jsonSignInResult);
			if (0 == signInResult.getStatus().getStatusCode()) {
				showLog("Sign in success.");
				showLog("Sign in result: " + signInResult.toJson());
				// 获取AuthorizationCode
                                authorizationCode = signInResult.getAccount().getAuthorizationCode();
				getGamePlayer();
			} else {
				showLog("Sign in failed: " + signInResult.getStatus().getStatusCode());
			}
		} catch (JSONException var7) {
			showLog("Failed to convert json from signInResult.");
		}
	} else {
		showLog("unknown requestCode in onActivityResult");
	}
}
```

#### 游戏登录

华为帐号授权成功后，调用[Games.getPlayersClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/games-0000001050121658#section023114101465)方法初始化[PlayersClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/playersclient-0000001050121668)实例，并调用[PlayersClient.getGamePlayer](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/playersclient-0000001050121668#section42128343142)方法进行游戏登录，从返回的[Player](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/player-0000001050121666)对象获取玩家信息和用于服务器认证的Access Token。  
[Player](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/player-0000001050121666)对象中只有[getOpenId](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/player-0000001050121666#section8861615201313)、[getUnionId](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/player-0000001050121666#section7615821121417)有值，其他方法返回空。用户头像和昵称建议从华为帐号授权成功后返回的[AuthAccount](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/authaccount-0000001050315810)获取。

```
public void getGamePlayer() {
    // 调用getPlayersClient方法初始化
    PlayersClient client = Games.getPlayersClient(this);
    // 执行游戏登录
    Task<Player> task = client.getGamePlayer();
    task.addOnSuccessListener(new OnSuccessListener<Player>() {
        @Override
        public void onSuccess(Player player) {
            String unionId = player.getUnionId();
            String openId = player.getOpenId();
            // 获取玩家信息成功，校验服务器端的玩家信息，校验通过后允许进入游戏
        }
    }).addOnFailureListener(new OnFailureListener() {
        @Override
        public void onFailure(Exception e) {
            if (e instanceof ApiException) {
                String result = "rtnCode:" + ((ApiException) e).getStatusCode();

                }
            }
        }
    });
}
```

#### 通过AuthorizationCode获取Access Token

华为帐号授权成功并获取AuthorizationCode后，请参考[获取凭证Access Token](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/account-obtain-token_hms_reference-0000001050048618)使用AuthorizationCode获取Access Token。  

#### 校验用户标识

为了保证用户标识的安全性，游戏可以调用华为游戏服务的[获取用户标识](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/gettokeninfo-0000001343252157)接口，根据[通过AuthorizationCode获取Access Token](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/game-login-0000001050121526#section163812617171)获取的Access Token向华为游戏服务器请求获取服务器端的用户标识，再与[PlayersClient.getGamePlayer](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/playersclient-0000001050121668#section42128343142)方法获取的用户标识进行比对，完成用户标识的校验。

* 为了保证安全性，如果您有自己的服务器，强烈建议您在服务器端验证用户标识。
