# 设计二维码

从[下载中心](https://developer.huawei.com/consumer/cn/doc/HMSCore-Library/sport-device-sdk-0000001051809026)的开发套件中获取"一碰联二维码样例及说明"。  

#### 设计标签

图1 二维码标签   
![](https://media:901788166630216666)

* 二维码大小：19mm \* 24mm；
* 二维码内容：https://url.cloud.huawei.com/1Lfn1eswP6?a=c\&t=262\&n=Huawei-xxxx\&p=2
  * 参数t：跳绳 -- 262
  * 参数n：更换成被连接设备的蓝牙广播名称
  * 其他参数：不变
* 使用在线二维码生成工具生成二维码。  

#### 部署标签

1. 从[下载中心](https://developer.huawei.com/consumer/cn/doc/HMSCore-Library/sport-device-sdk-0000001051809026)的开发套件中获取部署工具 sporthealthdeploytool_tool.apk，并安装在手机上。
2. 从开发套件中获取部署工具使用指南，根据使用指南和 sporthealthdeploytool_tool 将蓝牙模块信息写入写入二维码/NFC标签。

<!-- -->

3. 将标签粘贴在设备上。
