# 集成HMS Core SDK

## 配置HMS Core SDK的Maven仓地址

Android Studio的代码库配置在Gradle插件7.0以下版本、7.0版本和7.1及以上版本有所不同。请根据您当前的Gradle插件版本，选择对应的配置过程。

|-------------------------------------------------------------------------------------|------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------|
|[7.0以下版本](#ZH-CN_TOPIC_0000002516359028__zh-cn_topic_0000001050041594_li547444421611)|[7.0版本](#ZH-CN_TOPIC_0000002516359028__zh-cn_topic_0000001050041594_li1796424071918)|[7.1及以上版本](#ZH-CN_TOPIC_0000002516359028__zh-cn_topic_0000001050041594_li1345452582116)|

> 说明
>
> Maven仓地址无法直接在浏览器中打开访问，只能在IDE中配置。如需添加多个Maven代码库，请将华为公司的Maven仓地址配置在最后。

* **7.0以下版本**
  1. 打开Android Studio项目级"build.gradle"文件。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/70/v3/fYrWPq2HSJG7gTKk2f6DLw/zh-cn_image_0000002516359392.png?HW-CC-KV=V1&HW-CC-Date=20260909T150623Z&HW-CC-Expire=31536000000&HW-CC-Sign=9598597B8C9012856C84093E59097478C946F5D7747E2B3FB0CC66A3058E1C22)
  2. 添加Maven代码库。
     * 在"buildscript > repositories"中配置HMS Core SDK的Maven仓地址。
     * 在"allprojects > repositories"中配置HMS Core SDK的Maven仓地址。

     ```screen
     buildscript {
         repositories {
             google()
             jcenter()
             // 配置HMS Core SDK的Maven仓地址。
             maven {url 'https://developer.huawei.com/repo/'}
         }
     }

     allprojects {
         repositories {
             google()
             jcenter()
             // 配置HMS Core SDK的Maven仓地址。
             maven {url 'https://developer.huawei.com/repo/'}
         }
     } 
     ```

* **7.0版本**
  1. 打开Android Studio项目级"build.gradle"文件。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b6/v3/pNDjCAbKTM2qfJ-3ihYs7g/zh-cn_image_0000002516359384.png?HW-CC-KV=V1&HW-CC-Date=20260909T150623Z&HW-CC-Expire=31536000000&HW-CC-Sign=287F8378E45C639CFC20E902C6FAAB53ED1036190A11ACB9C9626243EABC6BCA)
  2. 添加Maven代码库。

     在"buildscript > repositories"中配置HMS Core SDK的Maven仓地址。

     ```screen
     buildscript {
         repositories {
             google()
             jcenter()
             // 配置HMS Core SDK的Maven仓地址。
             maven {url 'https://developer.huawei.com/repo/'}
         }
     }
     ```

  3. 打开项目级"settings.gradle"文件，配置HMS Core SDK的Maven仓地址。

     ```screen
     dependencyResolutionManagement {
         ...
         repositories {
             google()
             jcenter() 
             // 配置HMS Core SDK的Maven仓地址。
             maven {url 'https://developer.huawei.com/repo/'}
         }
     }
     ```

* **7.1及以上版本**

  打开项目级"settings.gradle"文件，配置HMS Core SDK的Maven仓地址。

  ```screen
  pluginManagement {
      repositories {
          gradlePluginPortal()
          google()
          mavenCentral()
          // 配置HMS Core SDK的Maven仓地址。
          maven { url 'https://developer.huawei.com/repo/' }
      }
  }
  dependencyResolutionManagement {
      ...
      repositories {
          google()
          mavenCentral()
          // 配置HMS Core SDK的Maven仓地址。
          maven { url 'https://developer.huawei.com/repo/' }
      }
  }
  ```

## 添加编译依赖

1. 打开应用级的**build.gradle**文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/13/v3/JhFJ1v12ROSP8biFrfwc-w/zh-cn_image_0000002516359396.png?HW-CC-KV=V1&HW-CC-Date=20260909T150623Z&HW-CC-Expire=31536000000&HW-CC-Sign=3D956EE6CAEFD65ED0C652DB9366E526F5C0AEE27EAC149A031575294AF2A24E)


2. 在"dependencies "中添加如下编译依赖。

   ```screen
   dependencies {
      ...
      implementation 'com.huawei.hms:health:{version}'
   }
   ```

   > 说明
   >
   > *{version}* 替换为实际的SDK版本号：com.huawei.hms:health:6.11.0.300。建议集成最新的SDK版本，版本号详见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/version-change-history-0000001057072287)。

3. （可选）如果您集成了Health Service Kit SDK 6.9.0.300及以上版本，可在"dependencies"中添加HMS Core Installer SDK编译依赖，自动引导用户下载HMS Core APK。

   > 注意
   >
   > 如果您的应用上架其他应用市场（例如：Google Play），请跳过该配置。

   ```screen
   dependencies {
       implementation 'com.huawei.hms:hmscoreinstaller:6.6.0.300'
   }
   ```

4. 重新打开修改完的"build.gradle"文件，右上方出现**Sync Now**链接。单击"Sync Now"等待同步完成。

   > 说明
   >
   > 如果出现错误，请检查网络连接是否正常，以及检查gradle文件是否正确。

## 添加APP ID信息

1. 打开"AndroidManifest.xml"文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c8/v3/sYwH7fjjQaW_DMBlScDcow/zh-cn_image_0000002548039189.png?HW-CC-KV=V1&HW-CC-Date=20260909T150623Z&HW-CC-Expire=31536000000&HW-CC-Sign=AEF5E1A6FA158887BD8CC2F3B8CFD635FB99FAC49D1DDD691922170E527001B2 "点击放大")

2. 在"application"中添加开发者联盟创建应用时生成的App ID信息。

   **value="APP ID"** ，此处的APP ID请修改为"[申请账号服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/apply-id-0000001050069756)"过程中创建应用生成的APP ID值。

   ```screen
   <meta-data
       android:name="com.huawei.hms.client.appid"
       android:value="APP ID"/>
   ```

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5a/v3/JndKAb0-Tluh4dkgCTEW0g/zh-cn_image_0000002548039183.png?HW-CC-KV=V1&HW-CC-Date=20260909T150623Z&HW-CC-Expire=31536000000&HW-CC-Sign=BA31E90EB8BD272783975F182D3C34E40E772149D3D78D5ED71935AD996342DF)


3. 修改完成后，单击右上角"Sync Now"。

## 多语言设置

* 如果您的应用不需要设置只支持某些特定语言，则请忽略本步骤。应用将默认支持所有[HMS Core SDK支持的语言](https://developer.huawei.com/consumer/cn/doc/hmscore-common-Guides/support-language-0000001050040564)。
* 如果您的应用需要设置只支持某些特定语言，则可通过本步骤配置。

1. 打开App下应用级根目录的"build.gradle"文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/76/v3/yBJpbSa-SMaoQ_Mci7BqPQ/zh-cn_image_0000002548039185.png?HW-CC-KV=V1&HW-CC-Date=20260909T150623Z&HW-CC-Expire=31536000000&HW-CC-Sign=DD339A419EA56E9FD8400FA69CB89D1EF37309EF795BBFE74E63CB5BBE6BFFAF)

2. 在**"** android > defaultConfig"中新增**resConfigs** 配置，**en** （英语） 和**zh-rCN**（简体中文）为必须配置的语种，配置格式如下：

   ```screen
   resConfigs "en", "zh-rCN","需要支持的其他语言" 
   ```
