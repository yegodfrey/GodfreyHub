# 添加权限

调用地图服务能力，您的应用需添加以下权限：

1. 在"config.json"文件中的"module"中添加下列权限：

   ```
   <!--允许程序使用地图服务桥接能力-->
   "allowClassMap": true
   ```

2. 在"config.json"文件中的"reqPermissions"字段中添加下列[权限](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/security-permissions-guidelines-0000000000029886)：

   ```
   <!--允许使用网络socket-->
   ohos.permission.INTERNET
   <!--允许应用获取数据网络信息-->
   ohos.permission.GET_NETWORK_INFO
   ```

示例代码如下：

```
{
    "module": {
        "allowClassMap": true,
        "reqPermissions": [
            {
                "name": "ohos.permission.INTERNET",
                "reason": "access internet",
                "usedScene": {
                    "ability": [
                        "com.mycamera.MainAbility"
                    ],
                    "when": "always"
                }
            },
            {
                "name": "ohos.permission.GET_NETWORK_INFO",
                "reason": "GET_NETWORK_INFO",
                "usedScene": {
                    "ability": [
                        "com.mycamera.MainAbility"
                    ],
                    "when": "always"
                }
            }
        ]
    }
}
```
