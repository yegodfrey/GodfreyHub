# 使用入门

您需要按照流程来完成应用的开发工作。

|序号|步骤|说明|
|:-|:---------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|开发准备|1. [集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/integrating-sdk-0000001050069724)：在开发应用前，请将Health Service Kit基础能力服务的SDK通过本地或远程方式集成到您的开发环境中。 2. [配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-obfuscation-scripts-0000001050071675)：编译APK前需要配置混淆配置文件，避免混淆HMS Core SDK导致功能异常。 3. [导入证书指纹、修改包名、配置JDK编译版本](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/change-0000001050170085)：将Keystore文件导入应用工程，如应用包名与[申请帐号服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/apply-id-0000001050069756)的包名不一致需修改包名，以及配置JDK编译版本。|
|2|[应用开发](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/add-permissions-0000001050069726)|使用Android Studio开发环境，根据指导手册，完成应用接入Health Service Kit免登录授权能力相关功能的开发。|
|3|[申请验证](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/verification-0000001211587947)|应用开发完成后，提交申请验证，以获得Health Service Kit正式权限。|
|4|应用上架|1. [上架前自检](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/pre-release-check-0000001050714942)：使用华为自检工具在线对应用进行自检，并按照华为提供的自检Checklist进行开发自检。 2. [上架申请](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/app-release-0000001051074910)：将完成的应用提交华为方进行审核，审核时间一般为1~2个工作日。|
