# 通用  
  
#### 事件参数列表

                * STARTCHECKOUT

用户下单后，点击结算按钮时，触发此事件。可以与VIEWPRODUCT、COMPLETEPURCHASE等事件结合使用，用于分析电商购买漏斗转化情况。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
REVENUE | 收入 | Double | 可选 | 会给您带来的收入。必须与CURRNAME同时使用。  
CURRNAME | 货币类型 | String | 可选 | 标识收入的货币类型。与REVENUE一起使用。  
ROLENAME | 用户角色 | String | 可选 | 针对游戏场景，标识购买商品的游戏角色。  
  
                * WINVIRTUALCOIN

用户获取到虚拟币时，上报此事件。可以用于分析用户获取虚拟币的难易程度，优化产品设计。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
ROLENAME | 用户角色 | String | 可选 | 标识用户的角色。  
WINREASON | 获取原因 | String | 可选 | 获取虚拟币的原因。  
VIRTUALCURRNAME | 虚拟币类型名称 | String | 必选 | 标识用户获取到的虚拟币类型。  
REVENUE | 虚拟币数量 | Long or Double | 必选 | 用户获取到的虚拟币数量。  
LEVEL | 关卡 | String | 可选 | 获取虚拟币的关卡。  
ENTRY | 入口 | String | 可选 | 获取虚拟币的入口。  
BALANCE | 虚拟币余额 | Long or Double | 可选 | 用户获取虚拟币后虚拟币余额。  
  
                * COMPLETEPURCHASE

用户支付完成后，上报此事件。可以用于分析用户对哪些商品或内容更感兴趣，优化运营策略。

华为应用内支付服务（In-App Purchases，IAP）渠道发生的支付，不需要上报COMPLETEPURCHASE事件。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
PRODUCTID | 商品ID | String | 必选 | 被添加到购物车中的商品ID。  
PRODUCTNAME | 商品名称 | String | 必选 | 被添加到购物车中的商品名称。  
QUANTITY | 购买数量 | Long | 必选 | 用户准备购买的数量。  
CURRNAME | 货币类型 | String | 可选 | 标识收入的货币类型。与REVENUE一起使用。  
REVENUE | 收入 | Double | 可选 | 本次交易给您带来的收入。必须与CURRNAME同时使用。  
TAXFEE | 税费 | Double | 可选 | 本次交易产生的税费。  
LEVEL | 关卡 | String | 可选 | 获取虚拟币的关卡。  
ENTRY | 入口 | String | 可选 | 获取虚拟币的入口。  
ROLENAME | 用户角色 | String | 可选 | 针对游戏场景，标识购买商品的游戏角色。  
DISCOUNT | 折扣 | Double | 可选 | 本次交易折扣金额。  
FIRSTPAY | 是否首次支付 | String | 可选 | 标识用户是否首次购买此商品。
                  * 0：表示非首次购买。
                  * 1：表示首次购买。  
PAYTYPE | 支付方式 | String | 可选 | 用户选择的支付方式。  
  
                * UPGRADELEVEL

游戏应用中用户升级时，上报此事件。分析产品的用户等级设置是否合理，有针对性地制定优化策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
LEVELID | 用户等级 | Long | 必选 | 标识用户提升后的等级。  
ROLENAME | 用户角色 | String | 可选 | 标识用户的角色。  
ROLECOMBAT | 角色战力 | String | 可选 | 角色战力。  
LEVELBEFORE | 提升前用户等级 | Long | 可选 | 标识角色提升前的等级。  
ISTOPLEVEL | 是否达到满级 | String | 可选 | 用户升级后等级是否达到满级。
                  * 0：没有达到满级
                  * 1：达到满级  
  
                * REGISTERACCOUNT

用户注册帐号时，上报此事件。可以分析用户来源，有针对性的优化运营策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
REGISTMETHOD | 用户来源 | String | 可选 | 用户来源。  
ACOUNTTYPE | 帐号类型 | String | 可选 | 用户帐号类型，如：邮箱、手机号、微信等。  
INVITER | 邀请人 | String | 可选 | 邀请该用户进行注册的用户。  
  
                * CONSUMEVIRTUALCOIN

用户消费虚拟币时，上报此事件。可以用于分析用户对哪些产品更感兴趣。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
ROLENAME | 用户角色 | String | 可选 | 标识用户的角色。  
PRODUCTNAME | 商品名称 | String | 必选 | 用户购买的商品名称。  
QUANTITY | 购买数量 | Long | 可选 | 用户购买该商品的数量。  
VIRTUALCURRNAME | 虚拟币类型名称 | String | 必选 | 用户使用的虚拟币的货币单位。  
REVENUE | 消费虚拟币金额 | Long or Double | 必选 | 用户消费的虚拟币数量。  
LEVEL | 关卡 | String | 可选 | 用户使用虚拟币的关卡。  
ENTRY | 入口 | String | 可选 | 用户使用虚拟币的入口。  
BALANCE | 虚拟币余额 | Long or Double | 可选 | 用户消费虚拟币后虚拟币余额。  
  
                * VIEWPRODUCT

用户浏览商品时，上报此事件。可以分析用户对哪些商品感兴趣，也可以和其他事件组合完成漏斗分析。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
PRODUCTID | 商品ID | String | 必选 | 用户浏览商品的ID。  
PRODUCTNAME | 商品名称 | String | 必选 | 用户浏览商品的名称。  
PRODUCTFEATURE | 商品特征 | String | 可选 | 用户浏览商品的特征。  
CATEGORY | 商品分类 | String | 必选 | 用户浏览商品的分类。  
BRAND | 商品品牌 | String | 可选 | 用户浏览的商品品牌。  
POSITIONID | 商品索引 | String | 可选 | 用户浏览的商品在商品列表中的索引。  
PRODUCTLIST | 商品列表 | String | 可选 | 用户浏览的商品列表。  
PRICE | 商品价格 | Double | 可选 | 商品的价格。  
QUANTITY | 数量 | Long | 可选 | 用户准备购买的数量。  
REVENUE | 收入 | Double | 可选 | 用户购买此商品，预计会给您带来的收入。必须与CURRNAME同时使用。  
CURRNAME | 货币类型 | String | 可选 | 标识收入的货币类型。与REVENUE一起使用。  
ROLENAME | 用户角色 | String | 可选 | 针对游戏场景，查看商品的游戏角色。  
  
                * CREATEROLE

创建新角色成功时上报此事件，上报此事件。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述

                  * 0：非首次创建

                * SIGNINROLE

用户选择角色进入游戏时，上报此事件。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
ROLENAME | 用户角色 | String | 必选 | 标识用户的角色。  
LEVELID | 角色等级 | Long | 可选 | 用户使用的角色等级。  
ROLECLASS | 角色职业 | String | 可选 | 用户创建的角色职业。

FIRSTSIGNIN | 是否首次登录角色 | String | 可选 | 标识该用户是否首次登录该角色。

                * SUBMITSCORE

游戏/教育类应用中，用户提交分数时，上报此事件。用于分析产品内容的难易程度，有针对性得制定优化策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
SCORE | 分数 | String | 可选 | 标识用户得分。  
LEVELID | 用户等级 | Long | 可选 | 用户当前所处级别。  
ROLENAME | 用户角色 | String | 必选 | 标识用户的角色。  
  
                * STARTBATTLE

用户开始战斗或开启关卡时，上报此事件。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
ROLENAME | 用户角色 | String | 可选 | 标识用户的角色。  
LEVELID | 角色等级 | Long | 可选 | 用户使用的角色等级。  
ROLECLASS | 角色职业 | String | 可选 | 用户创建的角色职业。  
BATTLETYPE | 战斗类型 | String | 可选 | 战斗类型。
                  * 0：其他
                  * 1：PvP
                  * 2：PvE  
BATTLENAME | 战斗名称 | String | 必选 | 战斗名称。  
NUMBEROFCARDS | 出战卡牌数量 | Long | 可选 | 本次战斗出战卡牌数量。  
CARDLIST | 出战卡牌列表 | String | 可选 | 本次战斗出战卡牌列表。卡牌间以逗号分隔。  
PARTICIPANTS | 出战角色数 | String | 可选 | 本次战斗出战角色数。  
DIFFICULTY | 游戏难度 | String | 可选 | 本次战斗游戏难度。  
  
                * ENDBATTLE

用户结束战斗或结束关卡时，上报此事件。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
ROLENAME | 用户角色 | String | 可选 | 标识用户的角色。  
LEVELID | 角色等级 | Long | 可选 | 用户使用的角色等级。  
ROLECLASS | 角色职业 | String | 可选 | 用户创建的角色职业。  
BATTLETYPE | 战斗类型 | String | 可选 | 战斗类型。
                  * 0：其他
                  * 1：PvP
                  * 2：PvE  
BATTLENAME | 战斗名称 | String | 必选 | 战斗名称。  
MVP | MVP | String | 可选 | 本次战斗MVP玩家或者卡牌。  
NUMBEROFCARDS | 出战卡牌数量 | Long | 可选 | 本次战斗出战卡牌数量。  
CARDLIST | 出战卡牌列表 | String | 可选 | 本次战斗出战卡牌列表。卡牌间以逗号分隔。  
PARTICIPANTS | 出战角色数 | String | 可选 | 本次战斗出战角色数。  
DAMAGE | 战斗伤害 | String | 可选 | 本次战斗各出战单位输出的伤害值。  
RANKING | 排名 | String | 可选 | 战斗结束后用户排名。  
RESULT | 游戏结果 | String | 必选 | 游戏结果胜利或失败。
                  * 0：失败
                  * 1：胜利  
DURATION | 游戏时长 | Long | 可选 | 游戏结束时统计游戏时长。 单位：秒。  
DIFFICULTY | 游戏难度 | String | 可选 | 本次战斗游戏难度。
