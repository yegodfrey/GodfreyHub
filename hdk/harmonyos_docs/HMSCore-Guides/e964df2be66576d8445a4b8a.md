# 上架申请

#### 了解上架规则

您完成集成服务，提交应用上架前，请先了解如下上架规则和审核常见问题：
      * [华为应用市场审核指南](https://developer.huawei.com/consumer/cn/doc/distribution/app/50104)
      * [应用审核FAQ](https://developer.huawei.com/consumer/cn/doc/distribution/app/50106)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/37/v3/L0RRZE8VRUeenonECR-YCw/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T042955Z&HW-CC-Expire=86400&HW-CC-Sign=81794CAC2BDF77721A3D07708150AF1B26D954FE04DB077DA021E7ECD4487991)

按照应用市场的[隐私政策](https://developer.huawei.com/consumer/cn/doc/app/50104-07#h3-1683701612940-0)，所有上架App只要集成了第三方SDK，都需要在App的隐私政策中逐一明示SDK收集个人信息的目的、方式和范围，不然可能会导致上架不通过。本SDK的明示信息请参见开发指南“SDK隐私声明”章节。

#### 提交上架申请

开发完成后需要在AppGallery Connect中将应用信息补充完整并提交上架申请，具体操作请参见[发布应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-releaseapkrpk-0000001106463276)。
