# 使用入门

#### 快速上手

在您正式开发应用之前，可以通过[codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/HMSMapKit-HarmonyOS)快速体验一个应用的开发过程。  

#### 开发流程

您需要按照如下流程完成应用的开发工作。  

|序号|步骤|说明|
|:-|:------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[准备开发环境](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-sdk-development-environment-0000001197883613)|安装及配置HUAWEI DevEco Studio。|
|2|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-sdk-config-agc-0000001101459188)|在开发应用前，需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中配置相关信息。包括：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-sdk-config-agc-0000001101459188#section4668165217444)、[创建应用](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-sdk-config-agc-0000001101459188#section137141014538)、[打开相关服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-sdk-config-agc-0000001101459188#section5865mcpsimp)、[配置应用签名信息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-sdk-config-agc-0000001101459188#section1854717537114)、[手动生成签名证书指纹](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-sdk-config-agc-0000001101459188#section819817413167)、[配置签名证书指纹](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-sdk-config-agc-0000001101459188#section5655152361716)。|
|3|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-sdk-integrating-sdk-0000001101419182)|在开发应用前，您需要将HMS Core SDK集成到您的开发环境中。|
|4|[配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-sdk-config-obfuscation-scripts-0000001147819101)|编译APK前需要配置混淆配置文件，避免混淆HMS Core SDK导致功能异常。|
|5|[添加权限](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-sdk-adding-permissions-0000001101099392)|调用地图服务能力，您需要在应用中添加权限。|
|6|[创建地图](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-sdk-map-creation-overview-0000001101259202)|使用地图容器快速地获得地图对象，并改变地图类型、设置地图属性，以及开启地图的精简模式等。|
|6|[地图交互](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-sdk-map-interaction-overview-0000001101259204)|通过控制地图手势开关以及内置UI控件的可见性，自定义用户与地图交互方式。|
|6|[在地图上绘制](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-sdk-drawing-map-overview-0000001147819105)|在地图上绘制标记、覆盖物以及形状等。|
|7|[应用发布](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-sdk-app-release-0000001151765416)|开发完成后您需要将应用打包成APP，发布到华为应用市场。|
