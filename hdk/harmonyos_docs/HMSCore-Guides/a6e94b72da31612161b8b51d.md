# 金融理财  
  
#### 事件参数列表

    * REGISTERACCOUNT

用户注册帐号时，上报此事件。可以分析用户来源，有针对性的优化运营策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
REGISTMETHOD | 用户来源 | String | 可选 | 用户来源。  
ACOUNTTYPE | 帐号类型 | String | 可选 | 用户帐号类型，如：邮箱、手机号、微信等。  
INVITER | 邀请人 | String | 可选 | 邀请该用户进行注册的用户。  
  
    * BINDACCOUNT

用户绑定其他类的型帐号时上报此事件。分析用户的登录习惯，有针对性地制定运营策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
ACOUNTTYPE | 帐号类型 | String | 可选 | 用户帐号类型，如：邮箱、手机号、微信等。  
  
    * ENTERACCOUNTOPENING

用户开户过程中身份证扫描结果返回时触发。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
SOURCEPAGE | 来源页面 | String | 可选 | 页面的上一级页面。  
CHANNEL | 渠道 | String | 可选 | 来源渠道。  
MULTIPLEACCOUNTS | 是否一人多户 | String | 可选 | 是否是一人多户。
      * 0：不是
      * 1：是  
  
    * SUBMITACCOUNTOPENING

提交开户时触发。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
ACCOUNTTYPE | 开户类型 | String | 可选 | 用户开户类型，如：普通、信用、港美、期货、基金。  
EVTRESULT | 是否成功 | String | 可选 | 用户开户结果。
      * 0：失败
      * 1：成功  
FAILUREREASON | 失败原因 | String | 可选 | 用户开户失败原因，如：网络原因，其他原因。  
AUTHORITY | 权限 | String | 可选 | 主板交易权限、创业板交易权限等。  
  
    * BANDCARD

用户绑卡完成时触发。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
CARDTYPE | 卡类型 | String | 可选 | 用户绑卡时的卡类型，如：储蓄卡。  
ISSUEBANK | 发卡行 | String | 可选 | 用户绑卡时的发卡行，如：中国银行，农业银行，工商银行，建设银行等。  
EVTRESULT | 是否成功 | String | 必选 | 用户绑卡结果。
      * 0：失败
      * 1：成功  
FAILUREREASON | 失败原因 | String | 可选 | 用户绑卡失败原因，如：网络原因，其他原因。
