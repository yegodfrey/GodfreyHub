# 响应式ListView

## Maven方式引入aar包

使用前需在build.gradle的dependencies中添加所引用控件的依赖。

```screen
implementation "com.huawei.ui.rspuikit:hwrsplistview-androidn:{version}"
```

> 说明
>
> *{version}*需替换为实际的版本号，具体版本号请参见版本更新说明章节。例如:implementation '"com.huawei.ui.rspuikit:hwrsplistview-androidn:1.0.0.8'。

## 布局XML接入方式

xml配置示例:原ListView调整为响应式控件（原代码不需要修改）。

```screen
<com.huawei.rspuikit.androidn.hwrsplistview.widget.HwRspListView
        android:id="@+id/listview_example"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:scrollbars="vertical"
        app:rspEnable="true" />
```

## 代码接入方式

1. 导入控件包。

   ```screen
   import com.huawei.rspuikit.androidn.hwrsplistview.widget.HwRspListView
   ```

2. 创建自定义控件类,调整原控件继承关系。

   ```screen
   public class MyHwListView extends HwRspListView 
   ```

3. 代码使用示例。

   ```screen
   @Override
   protected void onCreate(Bundle savedInstanceState) {
       super.onCreate(savedInstanceState);
       setContentView(R.layout.activity_listview);
       HwRspListView exampleListView = findViewById(R.id.hwexamplelistview);
       exampleListView.setEnable(true);
       // 设置展开态列数
       exampleListView.setRspColNum(2);
       // 设置展开态列间距
       exampleListView.setRspItemSpace(20);
   }
   ```

## 接口能力

响应式控件扩展并兼容原生ListView控件接口，扩展控件接口及说明如下表。

|接口函数|对应属性|输入|输出|返回值|
|:--------------|:-----------|:---------------|:-----------|:---|
|setEnable|rspEnable|boolean isEnable|设置控件特性开关|void|
|setRspColNum|rspColNum|int count|设置展开态列数，默认2列|void|
|setRspItemSpace|rspItemSpace|int space|设置展开态每列元素间距|void|

> 说明
>
> 控制展开态是否生效的接口是setEnable，只有设置为true时展开态才会响应式调整，若设置为false生效效果与谷歌原生控件一致。
>
> 应用可根据自己需要只在展开态显示有问题界面使能。
