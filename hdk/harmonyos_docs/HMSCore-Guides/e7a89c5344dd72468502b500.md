# 气泡

您可以通过气泡在道路上指定位置显示测速、拥堵情况。气泡支持功能：

* 支持设置四个方向的图标（传入的图标宽高需要相同）。
* 支持设置图标碰撞规则。
* 支持设置当前气泡的候选坐标段，通过计算使气泡在最佳的线段位置上。
* 支持设置图标动画。
* 支持添加点击事件。

## 添加气泡

调用HuaweiMapEx的addBubble方法在地图上添加气泡。

示例代码如下：

```java
"Java"
private BubbleOptions bubbleOptions = new BubbleOptions();
private HuaweiMapEx hMapEx;
// 设置图标，必须提供4个方向的图标
if (bubbleOptions.getIcon().size() == 0 ){
    bubbleOptions.icons(BitmapDescriptorFactory.fromResource(R.drawable.speed_limit_10),
        BitmapDescriptorFactory.fromResource(R.drawable.speed_limit_20),
        BitmapDescriptorFactory.fromResource(R.drawable.speed_limit_30),
        BitmapDescriptorFactory.fromResource(R.drawable.speed_limit_40));
}
// 设置碰撞规则
bubbleOptions.isCollision(true);
// 设置最大显示层级
bubbleOptions.maxZoom(15);
// 设置最小显示层级
bubbleOptions.minZoom(0);
// 设置显示层级
bubbleOptions.zoom(0.0f, 15.0f);
// 设置压盖关系
bubbleOptions.zIndex(1);
// 设置位置
bubbleOptions.position(new LatLng(50.8388866, 2.2661504));
// 设置碰撞优先级，值越大优先级越低
bubbleOptions.priority(15);
// 是否可见
bubbleOptions.visible(true);

// 添加气泡
hMapEx.addBubble(bubbleOptions);
```

## 气泡事件

可通过HuaweiMapEx.OnBubbleClickListener来侦听气泡上的点击事件。要在地图上设置此侦听器，请调用HuaweiMapEx对象的setOnBubbleClickListener方法。

示例代码如下：

```java
"Java"
// 添加气泡的点击监听事件
hMapEx.setOnBubbleClickListener(new HuaweiMapEx.OnBubbleClickListener() {
    @Override
    public void onBubbleClick(Bubble bubble) {
        Toast.makeText(getApplicationContext(), "onBubbleClick", Toast.LENGTH_SHORT).show();
    }
});
```

```java
"Kotlin"
// 添加气泡的点击监听事件
hMapEx.setOnBubbleClickListener { Toast.makeText(applicationContext, "onBubbleClick", Toast.LENGTH_SHORT).show() }
```

## 气泡动画

气泡支持设置的图标动画效果包括：透明度动画（[AlphaAnimation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/alphaanimation-0000001050764853)）、缩放动画（[ScaleAnimation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scaleanimation-0000001050764855)），通过Bubble的setAnimation方法设置，再调用startAnimation开启动画。

示例代码如下：

```java
"Java"
private Bubble mBubble;
private AlphaAnimation alphaAnimation;
if (mBubble == null){
    return;
}
// 新建透明度动画
alphaAnimation = new AlphaAnimation(1,0);
// 完成模式
alphaAnimation.setFillMode(1);
// 重复模式
alphaAnimation.setRepeatMode(1);
// 重复次数
alphaAnimation.setRepeatCount(1);
// 持续时间
alphaAnimation.setDuration(1000);
// 监听
ScaleAnimation.AnimationListener listener = new ScaleAnimation.AnimationListener() {
    @Override
    public void onAnimationStart() {
        Toast.makeText(getApplicationContext(), "AlphaAnimation start", Toast.LENGTH_SHORT).show();
    }
    @Override
    public void onAnimationEnd() {
        Toast.makeText(getApplicationContext(), "AlphaAnimation end", Toast.LENGTH_SHORT).show();
    }
};
alphaAnimation.setAnimationListener(listener);
// 给气泡设置图标透明度动画效果
mBubble.setAnimation(alphaAnimation);
// 启动图标设置的动画
mBubble.startAnimation();
```

```java
"Kotlin"
var mBubble : Bubble? = null
var alphaAnimation : AlphaAnimation
if (mBubble == null) {
    return
}
// 新建透明度动画
alphaAnimation = AlphaAnimation(1f, 0f)
// 完成模式
alphaAnimation.fillMode = 1
// 重复模式
alphaAnimation.repeatMode = 1
// 重复次数
alphaAnimation.repeatCount = 1
// 持续时间
alphaAnimation.duration = 1000
// 监听
val listener : Animation.AnimationListener =   object : Animation.AnimationListener {
    override fun onAnimationStart() {
        Toast.makeText(applicationContext, "AlphaAnimation start", Toast.LENGTH_SHORT).show()
    }
    override fun onAnimationEnd() {
        Toast.makeText(applicationContext, "AlphaAnimation end", Toast.LENGTH_SHORT).show()
    }
}
alphaAnimation.setAnimationListener(listener)
// 给气泡设置图标透明度动画效果
mBubble.setAnimation(alphaAnimation)
// 启动图标设置的动画
mBubble.startAnimation()
```
