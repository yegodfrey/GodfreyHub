# 使用入门

## 前置条件

商户需要以**平台类商户** 模式接入华为支付并为入网后的平台类商户申请配置支持营销补差能力（合作咨询可[点击此处](https://developer.huawei.com/consumer/cn/consultation?source=SC000002&location=101002&title=华为开发者联盟-智能终端能力开放,共建开发者生态)）。

## 开发流程

|序号|步骤|说明|
|:-|:--------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[商户入网](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-jieruliucheng-0000001251448455)|开发者需要在华为支付商户平台入网。商户入网成功后，需要为[商户号绑定AppID](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/binding-appid-to-merc-0000001889931817#section2082462310406)。 商户模型详细内容请参见[接入模式](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-hezuoshenfen-0000001725918617)。|
|2|[证书准备](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/certificate-preparation-0000001596094962#section1557292604420)|商户成功登录商户平台后，须在证书管理中上传商户证书，证书必须与商户号相匹配且是有效的，上传完商户证书后商户方可进行交易。|
|3|[API接入](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-specification-0000001538214720#section10361174218353)|需要接入华为支付服务器接口服务，按照华为支付服务器API接入规范联调开发。|

API接入步骤如下：

1. 调用华为支付开放的预下单API接口时添加最大补差金额"subsidyAmount"及延时分账"allocationType=DELAY_ORDER_ALLOCATION"入参。

   > 说明
   >
   > 营销补差场景下预下单接口totalAmount入参支持传递0。

2. 调用华为支付开放的[营销补差API接口](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/partner-compensation-api-0000001968081552)完成营销补差操作。
