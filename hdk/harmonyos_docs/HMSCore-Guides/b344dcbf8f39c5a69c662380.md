# 华为开发者大会NFC Tag

#### NFC Tag 在华为开发者大会上的应用

2019年8月9日-8月11日，华为开发者大会在东莞松山湖欧洲小镇举办。本次大会除了使用纸质门票入场之外，华为钱包也提供了NFC TAG入场的全新体验方式，供开发者们方便的使用手机碰一碰领取电子门票进入主会场和各分论坛，并且能够快捷地获取会议信息和资料。

![](https://media:101782807009467577)

![](https://media:101782807009500578)  

#### 实现方式

* 通过Wallet Kit服务对接功能开发。
* 制作NFC TAG物料。
* 用户手机解锁碰一碰，不打开APP即可到达落地页。

![](https://media:101782807009528579)  

#### 产品价值

入场更便捷，仅需使用手机贴近检票设备过闸 。

会场全覆盖，演讲议题，会务安排等相关资讯随手可得。

NFC TAG制作便捷，易于读写，适用于各类会场布置及展示。
