# 仅申请OpenID或UnionID的应用接入华为帐号快捷登录

## 场景介绍

当应用仅申请[OpenID](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/authaccount-0000001050315810#section149223326304)或[UnionID](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/authaccount-0000001050315810#section17246250182619)时，可快捷登录应用。
> 说明
>
> 仅支持注册地为中国的用户。

使用快速接入华为帐号、ID Token模式接入华为帐号或Authorization Code模式接入华为帐号，当您调用静默登录接口[silentSignIn](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section782995853116)或者前台登录接口[getSignInIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section76155516411)进行登录时，如果配置登录请求参数[AccountAuthParams](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthparams-0000001050196616)只包括请求用户的ID(OpenID、UnionID)，则可快捷登录。

## 构造请求参数示例

* 快速接入华为帐号

  ```screen
  AccountAuthParams mAuthParam = new AccountAuthParamsHelper()
          .setId()
          .createParams();
  ```

* ID Token模式接入华为帐号

  ```screen
  AccountAuthParams mAuthParam = new AccountAuthParamsHelper()
          .setIdToken()
          .setId()
          .createParams();
  ```

* Authorization Code模式接入华为帐号

  ```screen
  AccountAuthParams mAuthParam = new AccountAuthParamsHelper()
          .setAuthorizationCode()
          .setId()
          .createParams();
  ```

该部分需要您根据应用设计自己开发，如气泡提示、华为帐号快捷登录按钮等，下图仅为示例。
