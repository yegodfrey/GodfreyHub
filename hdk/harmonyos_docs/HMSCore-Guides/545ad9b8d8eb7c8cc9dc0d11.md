# 配置AppGallery Connect

#### 操作步骤

      1. 如果没有[华为开发者联盟](https://developer.huawei.com/consumer/cn/)帐号，需要先注册帐号并通过实名认证。详细操作请参见[ _帐号注册认证_](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。
      2. 参见[创建项目](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createproject-0000001100334664)和在[项目中添加应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createapp-0000001146718717)完成应用的创建。
      3. 开通华为分析服务：
         1. 登录[ _AppGallery Connect_](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击“我的项目”图标。 
         2. 选择已创建完成的应用。 
         3. 点击“华为分析”下的任意菜单，并点击“启动分析服务”可开通分析服务。（注：需拥有产品管理权限才可开通服务。）

         4. 进入“项目接入设置”页面，设置数据处理位置、设置用户数据留存时间、设置自然周定义后，点击“完成”，即完成Analytics Kit服务开通。

请打开[ _AppGallery Connect_](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，选择“我的项目”，在项目列表中找到您要打开的项目并点击，在AppGallery Connect界面选择“项目设置  > API管理”查看是否开启华为分析。

#### 配置应用签名信息

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115314.36538848311149203770449406938451:50001231000000:2800:2B56043F3882622479AA61DA8742D864EADD64315A028EFA963D49C88A2DE1B1.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

      * 若您在模拟器上进行调试并查看运行效果，则无需完成本章节以下步骤，具体操作请参见[使用模拟器运行应用](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/run_simulator-0000001053303709)和[使用模拟器进行调试](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/ide_debug_emulator-0000001115721921)。 
      * 若您在真机上进行调试并查看运行效果，请继续完成本章节以下步骤。 

为确保HarmonyOS应用的完整性，HarmonyOS通过数字证书和Profile文件来对应用进行管控，只有签名过的HAP才允许安装到设备上运行。因此，为了保证应用能够安装到调试设备上，您需要提前申请相应的调试证书与调试Profile文件。

具体操作请参见[通过DevEco Studio自动化签名方式对应用签名](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/ide_debug_device-0000001053822404#section677893315228)。
