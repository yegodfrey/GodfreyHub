# 热力图

热力图是一种自定义图层，用于展示数据的分布情况。通过热力图功能，将业务数据用不同颜色的区块在地图上展示，可以直观地描述在地图上某个区域内人群或车辆的密度和分布状况。

## 添加一个简单的热力图

1. 准备热力图数据集，创建一个population_density.geojson文件，在population_density.geojson文件中添加数据分布坐标。热力图每个点的权重可通过geojson里的mag属性设置，如果不设置，权重默认为1。
2. 创建[HeatMapOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/heatmapoptions-0000001193744269)对象，设置热力图数据集及其属性。
3. 调用[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)对象的[addHeatMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757#section164941913272)方法，将热力图添加到地图中。

示例代码如下：

```java
"Java"
// 创建HeatMapOptions对象，设置热力图属性
HeatMapOptions heatMapOptions = new HeatMapOptions();
heatMapOptions.intensity(2f);
// 设置热力图数据集
heatMapOptions.dataSet(R.raw.population_density);
// 将热力图添加到地图上
HeatMap heatMap = hMap.addHeatMap("id", heatMapOptions);
```

```java
"Kotlin"
// 创建HeatMapOptions对象，设置热力图属性
val heatMapOptions = HeatMapOptions()
heatMapOptions.intensity(2f)
// 设置热力图数据集
heatMapOptions.dataSet(R.raw.population_density)
private var heatMap: HeatMap? = null
// 将热力图添加到地图上
val heatMap = hMap.addHeatMap("id", heatMapOptions)
```

## 自定义热力图

我们提供一些自定义样式属性，用于定制您的热力图效果，您可以通过[HeatMapOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/heatmapoptions-0000001193744269)中提供的属性重新配置新的热力图层。

|方法|功能|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------|
|[color](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/heatmapoptions-0000001193744269#section13963185519361)(Map<Float, Integer> color)|热力图颜色。 * Key：数据密度。 * Value：热力图颜色。|
|[intensity(float intensity)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/heatmapoptions-0000001193744269#section6149164594)|热力图强度，控制所有层级强度。取值范围：大于0，默认为1.0。|
|[intensity(Map<Float, Float> intensity)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/heatmapoptions-0000001193744269#section39411655101218)|热力图强度，按层级控制强度。 * Key：层级。指定单个层级时，全局生效；指定多个层级时，则分层级控制强度。 * Value：热力图强度。|
|[opacity(float opacity)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/heatmapoptions-0000001193744269#section5789651171612)|热力图透明度，控制所有层级透明度。取值范围：[0, 1]。 * 0：完全不透明。 * 1：完全透明。 值越大透明度越高，默认为完全不透明。|
|[opacity(Map<Float, Float> opacitys)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/heatmapoptions-0000001193744269#section10401141317187)|热力图透明度，按层级控制透明度。 * Key：层级。指定单个层级时，全局生效；指定多个层级时，则分层级控制透明度。 * Value：热力图透明度。|
|[radius(float radius)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/heatmapoptions-0000001193744269#section1210472432015)|热力图半径，控制所有层级半径。单位：[RadiusUnit](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/radiusunit-0000001148196122)。取值范围：大于等于1，默认为10。|
|[radius(Map<Float, Float> radius)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/heatmapoptions-0000001193744269#section137642594207)|热力图半径，按层级控制半径。 * Key：层级。指定单个层级时，全局生效；指定多个层级时，则分层级控制半径。 * Value：热力图半径。|
|[radiusUnit](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/heatmapoptions-0000001193744269#section1353210509233)([HeatMapOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/heatmapoptions-0000001193744269).[RadiusUnit](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/radiusunit-0000001148196122) unit)|热力图半径单位。取值包括： * PIXEL：像素 * METER：米 默认为PIXEL。|
|[visible](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/heatmapoptions-0000001193744269#section38605315354)(boolean visible)|热力图可见性。 * true：可见 * false：不可见 默认值为true。|

## 修改热力图

将热力图成功添加到地图后，会返回[HeatMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/heatmap-0000001147944462)对象，用于修改热力图的属性。

示例代码如下：

```java
"Java"
// 修改热力图颜色
Map<Float, Integer> map = new HashMap<>();
map.put(1.0f, 158777);
heatMap.setColor(map);
// 修改热力图强度
heatMap.setIntensity(10f);
// 修改热力图透明度
heatMap.setOpacity(0.5f);
// 修改热力图半径
heatMap.setRadius(10f);
```

```java
"Kotlin"
// 修改热力图颜色
val map: Map<Float, Int> = HashMap()
map.put(1.0f, 158777)
heatMap?.setColor(map)
// 修改热力图强度
heatMap?.setIntensity(10f)
// 修改热力图透明度
heatMap?.setOpacity(0.5f)
// 修改热力图半径
heatMap?.setRadius(10f)
```

## 移除热力图

当不需要热力图图层时，您可以调用以下方法移除图层。

示例代码如下：

```screen
"Java"
heatMap.remove();
```

```screen
"Kotlin"
heatMap?.remove()
```
