# 功能概述

|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|-|
|本视频介绍了用户生命周期模型的功能使用，包含应用场景、自定义用户生命周期阶段、应用各阶段的转化预测与流失人群预测等。 什么是用户生命周期？ 以移动应用为例，当用户首次打开App，便开始了其用户生命周期旅程，直到用户最后一次使用App的这段期间，称之为用户生命周期。尽可能延长这个周期的时间，并提升用户的生命周期价值，是企业的共同目标。| |

华为分析服务的用户生命周期模型可从以下三个层面帮助企业实现数据驱动的用户生命周期价值提升。

* 划分用户生命周期，方便分层运营

用户生命周期模型按照用户使用App的深度，将用户分为新手期、成长期、成熟期、沉默期、流失期，且支持自定义用户生命周期，帮助进行贴合业务实际的用户分层管理。

* 一键创建分层用户群，进行精准触达

用户生命周期各阶段的用户、新增用户、高潜力用户、高风险用户均支持一键存为受众，可通过Push或应用内消息等多渠道进行触达，以促进用户活跃与转化。

* 提供预测能力，防流失、促转化

新手期、成长期、成熟期、沉默期、流失期均提供了基于机器学习算法预测的流失风险用户与转化潜力用户，且支持一键存为受众，可提前制定差异化策略，以防范流失、促进转化。

#### 典型应用场景

* 了解各用户生命周期阶段的用户数变化与相互转化情况。
* 对比活动前后成长期、成熟期用户提升，衡量运营活动效果。
* 分析不同设备品牌、不同渠道的成熟用户占比及变化趋势，调整拉新方向。
* 设计运营活动，引导转化潜力用户完成关键行为转化。
* 针对流失风险用户发放产品福利，提升活跃度，降低流失率。

#### 案例

一款电商App，希望引导新手期用户尽快完成首次付费，成为成熟期用户。  

#### 操作流程

1. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"图标。
2. 选择需要查看分析数据的应用。
3. 选择"华为分析 ＞ 用户生命周期"进入用户生命周期报告页面。
4. 自定义生命周期。

   选择"概览 ＞ 生命周期设置"设置贴合业务需求的新手期、成熟期用户定义。
5. 在新手期报告页的潜力预测卡片点击"高潜力用户数"，将新手期高潜力用户存为受众。
