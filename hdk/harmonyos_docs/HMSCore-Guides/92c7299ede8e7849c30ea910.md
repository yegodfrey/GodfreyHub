# 女性生理周期记录

#### 读取女性生理周期数据

通过HealthRecord读取用户已创建的生理周期记录列表，用户可以设置查询条件，如开始时间、结束时间、关联原子数据类型等。

HTTP请求，请参见[数据类型健康记录查询](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/get-health-record-by-datatype-0000001142843917#section9701181322219)接口

```
GET 
https://health-api.cloud.huawei.com/healthkit/v2/healthRecords?startTime=***&endTime=***&dataType=***&subDataType=***
```

请求示例

```
GET 
https://health-api.cloud.huawei.com/healthkit/v2/healthRecords?startTime=1618472295000000000&endTime=1618479495000000000&dataType=com.huawei.health.record.menstrual_cycle&subDataType=com.huawei.continuous.menstrual_flow&subDataType=com.huawei.dysmenorrhoea
```

请求头

```
Content-Type: application/json
Authorization: Bearer ***
x-client-id: ***
x-version: ***
x-caller-trace-id: ***
```
