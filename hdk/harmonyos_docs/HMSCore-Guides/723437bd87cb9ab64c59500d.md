# 写入篮球运动记录

用户可以调用[addActivityRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityrecordscontroller-0000001050091295#section1781411218216)方法插入篮球运动记录，使用步骤如下：

1. 使用[篮球](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/basketball-0000001181170625)数据类型，在[ActivitySummary](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activity-summary-0000001055215648)结构中添加篮球活动的特征数据结构ActivityFeature。
2. 创建一个指定时间段和其他必要信息的[ActivityRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityrecord_class-0000001050161730)，设置activityType名称为篮球，名称取值参见[HiHealthActivities](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthactivities-0000001050089540)。
3. 使用[ActivityRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityrecord_class-0000001050161730)和可选的采样集或聚合采样点数据，创建一个[ActivityRecordInsertOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ario_class-0000001050091110)。
4. 使用[ActivityRecordsController](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityrecordscontroller-0000001050091295).[addActivityRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityrecordscontroller-0000001050091295#section1781411218216)插入篮球运动记录数据到Health Service Kit。

   <br />

   ```
   // 请注意此处的this为Activity对象
   final ActivityRecordsController activityRecordsController = HuaweiHiHealth.getActivityRecordsController(this);

   // 1. 构造请求对象的时间区间：开始和结束时间
   // 请注意此处设置的开始时间和结束时间均需大于2014年1月1号对应的UNIX时间戳
   Calendar cal = Calendar.getInstance();
   Date now = new Date();
   cal.setTime(now);
   long endTime = cal.getTimeInMillis();
   cal.add(Calendar.HOUR_OF_DAY, -1);
   long startTime = cal.getTimeInMillis();

   // 2.根据篮球活动，构造篮球活动的特征数据结构ActivityFeature,并将其添加至ActivitySummary结构中
   SamplePoint activityFeature = new SamplePoint.Builder(DataType.DT_ACTIVITY_FEATURE_BASKETBALL).build();
   activityFeature.setTimeInterval(startTime + 1L, startTime + 300000L, TimeUnit.MILLISECONDS);
   activityFeature.getFieldValue(Field.OVERALL_SCORE).setIntValue(85);
   activityFeature.getFieldValue(Field.BURST_SCORE).setIntValue(82);
   activityFeature.getFieldValue(Field.JUMP_SCORE).setIntValue(82);
   activityFeature.getFieldValue(Field.RUN_SCORE).setIntValue(83);
   activityFeature.getFieldValue(Field.BREAKTHROUGH_SCORE).setIntValue(81);
   activityFeature.getFieldValue(Field.SPORT_INTENSITY_SCORE).setIntValue(81);
   ActivitySummary activitySummary = new ActivitySummary();
   activitySummary.setActivityFeature(activityFeature);

   // 3 创建一个跳跃统计数据采集点
   SamplePoint samplePointJump = new SamplePoint.Builder(DataType.DT_CONTINUOUS_JUMP_STATISTICS).build();
   samplePointJump.setTimeInterval(startTime + 1L, startTime + 300000L, TimeUnit.MILLISECONDS);
   samplePointJump.getFieldValue(Field.FIELD_JUMP_TIMES).setIntValue(50);
   samplePointJump.getFieldValue(Field.FIELD_MIN_JUMP_HEIGHT).setDoubleValue(0.68d);
   samplePointJump.getFieldValue(Field.FIELD_AVG_JUMP_HEIGHT).setDoubleValue(0.78d);
   samplePointJump.getFieldValue(Field.FIELD_MAX_JUMP_HEIGHT).setDoubleValue(0.88d);
   samplePointJump.getFieldValue(Field.FIELD_MIN_PASSAGE_DURATION).setIntValue(352);
   samplePointJump.getFieldValue(Field.FIELD_AVG_PASSAGE_DURATION).setIntValue(452);
   samplePointJump.getFieldValue(Field.FIELD_MAX_PASSAGE_DURATION).setIntValue(552);

   // 4. 根据统计数据采集器，构造统计数据样本点，并添加至DataSummary对象
   List<SamplePoint> samplePointList = new ArrayList<>();
   samplePointList.add(samplePointJump);
   activitySummary.setDataSummary(samplePointList);

   // 5. 构造运动记录，设置统计数据ActivitySummary对象，与ActivityTypeId
   ActivityRecord activityRecord = new ActivityRecord.Builder()
       .setName("AddActivityRecord")
       .setDesc("This is ActivityRecord add test!")
       .setId("MyAddActivityRecordId")
       .setActivityTypeId(HiHealthActivities.BASKETBALL)
       .setStartTime(startTime, TimeUnit.MILLISECONDS)
       .setEndTime(endTime, TimeUnit.MILLISECONDS)
       .setActivitySummary(activitySummary)
       .setTimeZone("+0800")
       .build();


   // 6.1 创建一个跳跃明细数据采集器
   DataCollector dataCollectorJumpDetail = new com.huawei.hms.hihealth.data.DataCollector.Builder()
       .setDataType(DataType.DT_CONTINUOUS_JUMP)
       .setDataGenerateType(DataCollector.DATA_TYPE_RAW)
       .setPackageName(getApplicationContext())
       .setDataCollectorName("AddActivityRecord")
       .build();

   // 6.2 根据跳跃明细数据采集器，构造数采样集
   SampleSet sampleSetJumpDetail = SampleSet.create(dataCollectorJumpDetail);

   // 6.3 构造跳跃明细（DT_CONTINUOUS_JUMP）采样点对象，添加到明细数据采样集
   SamplePoint samplePointJumpDetail = sampleSetJumpDetail.createSamplePoint().setTimeInterval(startTime,endTime,TimeUnit.MILLISECONDS);
   samplePointJumpDetail.getFieldValue(Field.FIELD_JUMP_HEIGHT).setDoubleValue(0.88d);
   samplePointJumpDetail.getFieldValue(Field.FIELD_PASSAGE_DURATION).setIntValue(1024);
   sampleSetJumpDetail.addSample(samplePointJumpDetail);

   // 7. 构造运动记录请求，设置运动记录activityRecord对象与其关联的明细数据采样集
   ActivityRecordInsertOptions insertOption = new ActivityRecordInsertOptions.Builder()
       .setActivityRecord(activityRecord).addSampleSet(sampleSetJumpDetail).build();

   // 8. 调用addActivityRecord接口添加运动记录
   Task<Void> addTask = activityRecordsController.addActivityRecord(insertOption);
   addTask.addOnSuccessListener(new OnSuccessListener<Void>() {
       @Override
       public void onSuccess(Void aVoid) {
           Log.i("ActivityRecords","ActivityRecord add was successful!");
       }
   }).addOnFailureListener(new OnFailureListener() {
       @Override
       public void onFailure(Exception e) {
           Log.i("ActivityRecords", "Failed to add ActivityRecord" + e.getMessage());
       }
   });
   ```
