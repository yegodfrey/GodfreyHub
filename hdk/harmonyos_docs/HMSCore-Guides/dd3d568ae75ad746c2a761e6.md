# 使用入门

## 开发流程

您需要按照如下流程完成应用的开发工作。

|序号|步骤|说明|
|:-|:-----------------|:--------------------------------------------------------------------------------------------------------------------------------|
|1|创建服务器应用|在开发应用前，需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中完成服务器应用创建与配置。包括：创建应用、设置回调地址。|
|2|获取Access Token|应用接入华为帐号，得到用户确认授权后，获取到Access Token。|
|3|调用华为API（可选）|应用在得到用户授权后的Access Token后，可请求对应华为API接口及资源。|
|4|刷新Access Token（可选）|应用可根据Refresh Token获取新的Access Token。|
|5|取消授权（可选）|应用可传入Access Token取消此授权。|
