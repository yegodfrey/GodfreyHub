# 配置AppGallery Connect

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115333.34416955310144039985151100348617:50001231000000:2800:D620D0F3607FBF4C174C6BD3FFCFD5B82314EE9AE6F2D75A12E061E7298269F5.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

在项目中添加应用时，平台选择“Web”。

#### 操作步骤

                1. 如果没有[华为开发者联盟](https://developer.huawei.com/consumer/cn/)帐号，需要先注册帐号并通过实名认证。详细操作请参见[ _帐号注册认证_](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。
                2. 参见[创建项目](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createproject-0000001100334664)和在[项目中添加应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createapp-0000001146718717)完成应用的创建。
                3. 开通华为分析服务：
                   1. 登录[ _AppGallery Connect_](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击“我的项目”图标。 
                   2. 选择已创建完成的应用。 
                   3. 点击“华为分析”下的任意菜单，并点击“启动分析服务”可开通分析服务。（注：需拥有产品管理权限才可开通服务。）

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115334.50568615333508935243048824480978:50001231000000:2800:547944CA87629D1CC5A457247FAFD94C8DF03B06016637EDB00DFB4CDC25607E.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

                   4. 进入“项目接入设置”页面，设置数据处理位置、设置用户数据留存时间、设置自然周定义后，点击“完成”，即完成Analytics Kit服务开通。 

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115334.72608172146596365842485779442744:50001231000000:2800:3FD6C05405B41635B32A9FDE42B63E5D36CD0C61D1DF99D9261CD965C7DBDB62.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

如果您的应用发布到全球多个国家，建议您启用多数据处理位置，使用[InitSettings.routePolicy](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/miniprogram-api-initsettings-0000001152333370)初始化SDK，按照用户实际使用区域指定数据上报位置。

请打开[ _AppGallery Connect_](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，选择“我的项目”，在项目列表中找到您要打开的项目并点击，在AppGallery Connect界面选择“项目设置  > API管理”查看是否开启华为分析。
