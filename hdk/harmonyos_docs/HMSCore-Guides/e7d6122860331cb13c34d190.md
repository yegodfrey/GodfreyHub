# 旅行路上，Awareness与你风雨"同程"

#### 背景介绍

同程艺龙是中国在线旅行行业的创新者和领先者。2020年4月22日，同程艺龙推出了全新的服务品牌"同程旅行"，致力于让旅行更简单、更快乐，持续创新，为用户创造简单、快捷、智能的出行服务。  

#### 面临挑战

旅行行业竞争激烈，如何第一时间洞悉客户的需求，往往成为留住客户形成商业闭环的关键。怎样才能及时甚至提前洞悉用户需求，提供最适合的选择，是同程旅游面临的业务挑战：

* 如何根据特定用户的特定情景，如所处的位置、节假日信息、天气情况等，提供刚刚好的服务。
* 如何实现一次集成获取各种情景感知能力，并且能够组合运用，免于对算法、架构、隐私等专业人员的需求。
* 如何实现一次开发，支持华为手机，覆盖所有机型，同时也支持在非华为手机上使用。

#### 解决方案

情景感知服务（Awareness Kit）提供获取用户情景状态的组合能力，如用户所处位置、当前时间是或否节假日、天气情况等感知能力。调用这些能力，可以更高效地洞悉用户当前所处的情景，为用户提供更加智慧和贴心的旅行体验。

同程旅行通过调用HMS Core情景感服务，注册地理围栏、查询天气情况等，实现了"千人千面"的定制化服务。比如，当用户到达非常驻地的机场时触发围栏，询问用户是否需要预定机场附近的酒店，从而第一时间洞悉用户潜在需求。还可以在用户即将到达旅行目的地时，通知用户该地的天气情况、穿衣指数等信息，让用户享受同程更加贴心和人性化的服务。

#### 合作收益

* To同程旅游： 一次集成即可获取多种能力，无需另外投入研发人力，节省建设成本。

  第一时间洞悉用户需求，提升用户下订单的概率。
* To同程用户： 享受更加贴近需求的个人服务，简单、快捷、智能地出行。
