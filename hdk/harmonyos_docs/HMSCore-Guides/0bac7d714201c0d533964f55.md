# 操作流程

#### 新建条件

                1. 在“条件”页面，点击“新建”按钮。
                2. 在“新建条件”页面中输入条件名称，选择条件类型并输入对应的参数。
                3. 如果您选定条件类型后并设置触发条件为“部分xx”，此时您需要依次选择触发条件的变量和操作符，并填写触发条件需要的属性值。如果您需要填写多个触发条件，点击“添加”按钮可增加条件输入框。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/34/v3/17zH3b16TqyqeugCNlMnUA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043135Z&HW-CC-Expire=86400&HW-CC-Sign=6764F7F50867019DB6F8AE5CE9456344B21EDB8044755B615A9D11B9F1A7B827)

在设置触发条件时，可通过下拉框选择已创建的变量。

若您所需的变量还未创建，可通过点击“配置”，配置预设变量；或通过点击“新建”，新建自定义变量。

“此条件的触发条件”的“部分xx”最多可添加100条，若达到100条，则无“添加”按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6f/v3/DC6YHkwHT9e-urDoPuTq5w/zh-cn_image_0000001077624262.png?HW-CC-KV=V1&HW-CC-Date=20261005T043135Z&HW-CC-Expire=86400&HW-CC-Sign=C14DDE1F861435D627D66AFEA08A3D66A2C683FADBBED66DBD57731FA2677447)

                4. 填写完成后，点击“保存”。
                5. 创建成功后，您可以在“条件”页面中查看到已创建的条件。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f2/v3/C8W8wCQtQDakqsiaagbziA/zh-cn_image_0000001091226329.png?HW-CC-KV=V1&HW-CC-Date=20261005T043135Z&HW-CC-Expire=86400&HW-CC-Sign=F2A63E6B02AB9971EABFDFC14F57BA1983770E17F3405EA6DC7BC304E758C130)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/01/v3/0G64BqOYQq2dmxyLphcfIQ/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043135Z&HW-CC-Expire=86400&HW-CC-Sign=C00872DFB70B7DC69038E6E114F669B69BCFC0E25CEEDE97F656858981626EAB)

当一个条件中配置了多条触发条件，必须要同时满足才会触发。

#### 修改条件

                1. 在“条件”页面，点击已创建条件的名称。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c9/v3/UX8w_k7DR4qDDuSQc9z7JA/zh-cn_image_0000001077781730.png?HW-CC-KV=V1&HW-CC-Date=20261005T043135Z&HW-CC-Expire=86400&HW-CC-Sign=FBEE06978ACF0747B7B563FC13177730E22C3B9976C62BC834C5CA7E3B1FA969)

                2. 在“修改条件”页面可以对条件名称、条件类型及触发条件等进行修改。修改完成后，点击“保存”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2a/v3/BR4E0yUrT2KxXJ50cFIwMg/zh-cn_image_0000001090899991.png?HW-CC-KV=V1&HW-CC-Date=20261005T043135Z&HW-CC-Expire=86400&HW-CC-Sign=D865833C752B4A9DE953A06DA2FBE5BCF3783DF049F494266028CC08D0291399)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/07/v3/TIH8mD1FTQqwKQ1oGG74_Q/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043135Z&HW-CC-Expire=86400&HW-CC-Sign=8E4EC57B8B3DF4492DBF277815B948CD134409C1C9C053E13D32BA5B8E983E5D)

在“修改条件”页面，可查看引用该条件的代码。

若该条件被引用，则在修改完成后，重新[发布版本](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-version-management-operation-procedure-0000001091319145#section109431345124612)，才能生效。

#### 复制条件

                1. 在“条件”页面，点击右侧的“复制”按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b9/v3/2zp6P_o3T7CQRlbvxu6-rw/zh-cn_image_0000001091319153.png?HW-CC-KV=V1&HW-CC-Date=20261005T043135Z&HW-CC-Expire=86400&HW-CC-Sign=7B704E1E2EC057EDDD46CA8EC93DD3E3F1F3D85EAADCEA7609E6DFDEA6CB397D)

                2. 在“复制条件”页面可以对条件名称、条件类型及触发条件等进行编辑。编辑完成后，点击“保存”按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/17/v3/wuSyJp4dTJ27XQnzOIBjvQ/zh-cn_image_0000001091200305.png?HW-CC-KV=V1&HW-CC-Date=20261005T043135Z&HW-CC-Expire=86400&HW-CC-Sign=5CC29357AF540A44815FA3BBEB200E1D960342F47161E51D66214A37AB7BF76A)

                3. 复制完成后，您可以在“条件”页面，查看复制的条件信息。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/15/v3/3QjXImsGSv2AUeEvo5A_Mg/zh-cn_image_0000001171189943.png?HW-CC-KV=V1&HW-CC-Date=20261005T043135Z&HW-CC-Expire=86400&HW-CC-Sign=E8A9E3F5E2474A46F8E230AC947F40B6ADA0F09450EF0932C28C5C29CAB08265)

#### 删除条件

**方法一：单个删除。** 在“条件”页面，点击已创建条件右侧的“删除”，确认对话框中的提示信息后点击“确定”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b8/v3/4wduABwGQ4mpJ86itKY3FA/zh-cn_image_0000001091043943.png?HW-CC-KV=V1&HW-CC-Date=20261005T043135Z&HW-CC-Expire=86400&HW-CC-Sign=63DBD79D7224A12B772C4BC5BDCC335DA767A2D41012272F4AD46D8363CF963F)

**方法二：批量删除。** 若您需要删除多个条件，也可以通过批量删除功能实现。勾选待删除条件前的方框，点击页面右上方的“删除”按钮，确认对话框中的提示信息后点击“确定”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3d/v3/u7FrJiseRjaIpwOlS9Ns8g/zh-cn_image_0000001083297358.png?HW-CC-KV=V1&HW-CC-Date=20261005T043135Z&HW-CC-Expire=86400&HW-CC-Sign=912C31168568F63FF516CBD1ED9F46CD08E82DC61FDC5E8AB30C558999641332)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3c/v3/naQIVRIRRE65Q3pu5eNyog/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043135Z&HW-CC-Expire=86400&HW-CC-Sign=DBB810C70E4E03CF0C491BC3B689141B3F90A1541D39C4EC0177EF01C4764908)

如果条件已经被其他代码引用，则无法删除，需要移除引用关系后再执行删除。
