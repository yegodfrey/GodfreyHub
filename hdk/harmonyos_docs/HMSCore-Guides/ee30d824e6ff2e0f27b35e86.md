# 开发准备

## 开发环境构建

开发者需要在本地安装如下软件：

* Node.js。参见[Node.js环境构建](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/appendices-node-env-0000001943620470)。
* HUAWEI DevEco Studio。参见[HUAWEI DevEco Studio安装及配置](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/appendices-deveco-config-0000001943797454)。

## 集成SDK

在开发前，开发者需要将HMS Core SDK集成到开发者的开发环境中。

SDK版本参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/appendices-sdk-update-0000001970804041)。

### 添加编译依赖

1. 打开项目级"build.gradle"文件，添加agconnect服务依赖。项目级"build.gradle"文件已自动添加Maven代码库地址，开发者无需额外配置。

   ```screen
   buildscript { 
       dependencies { 
           classpath 'com.huawei.ohos:hap:2.4.4.2' 
           // 添加agconnect服务依赖 
           classpath 'com.huawei.agconnect:agcp-harmony:1.3.1.300'
       } 
   } 
   ```

2. 打开"entry"应用级根目录的"build.gradle"文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/25/v3/ARh3of7BS-qEqpEqU8TOQA/zh-cn_image_0000002512199947.jpg?HW-CC-KV=V1&HW-CC-Date=20260910T132631Z&HW-CC-Expire=31536000000&HW-CC-Sign=36420C8D18D8154EAE4D172B5C91BAB98832BA6373F1036A3CDF74E0100B7BAD)

3. 在"dependencies"中添加如下编译依赖。

   ```screen
   dependencies {
       implementation 'com.huawei.hms:jsb-ohos-adapter:5.3.0.303'
   }
   ```

4. 在"dependencies"中添加agconnect的编译依赖。

   ```screen
   dependencies { 
       // agconnect依赖组件
       implementation 'com.huawei.agconnect:agconnect-core-harmony:1.3.1.300'
   }
   ```

5. 添加agcp插件配置。在文件头部声明下一行添加如下配置。

   ```screen
   apply plugin: 'com.huawei.agconnect'
   ```

6. 在config.json文件添加如下配置。

   ```screen
   "deviceConfig": {
       "default": {
           "allowComponentsProxy": true
       }
   }
   ```

   > 说明
   >
   > allowComponentsProxy配置只能配置在entry模块中，并且entry模块中config.json里bundleName和package名称必须相同。

### 下载SDK

1. 执行CMD命令打开命令行工具，执行**cd** 命令进入HarmonyOS应用"entry"目录。
2. 执行NPM命令下载Base SDK。

   ```screen
   npm install @hw-hmscore/hms-js-base
   ```

   > 说明
   >
   > **npm install @hw-hmscore/hms-js-base**表示下载最新版本SDK。
   >
   > 如需下载指定版本SDK，可使用**npm install @hw-hmscore/hms-js-base@6.8.0-300**。

   出现如下提示，说明下载成功：

   ```screen
   npm WARN testtest@1.0.0 No description
   npm WARN testtest@1.0.0 No repository field.

   + @hw-hmscore/hms-js-base@6.8.0-300
   updated 1 package in 3.486s
   ```

3. 执行NPM命令下载华为支付服务 JS SDK。

   ```screen
   npm install @hw-hmscore/hms-payment
   ```


4. 在HarmonyOS应用"entry/src/main/config.json"的**module** 节点增加如下属性配置，其中"value"的值为开发者的OAuth 2.0客户端ID（在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站点击"我的项目"，在项目列表中找到开发者的项目，在"项目设置 > 常规"页面的"应用"区域获取"OAuth 2.0客户端ID（凭据）：Client ID"的值）。

   ```screen
   "module":{
       "package": "com.example.myapplication",
       "name": ".MyApplication",
       "mainAbility": "com.example.myapplication.MainAbility",
       "deviceType": [...],
       "distro": {...},
       "abilities": [...],
       "js": [...],
       "metaData": {
             "customizeData": [
               {
                 "name": "com.huawei.hms.client.appid",
                 "value": "{OAuth Client ID}"  // 这里需要把{OAuth Client ID}替换为OAuth 2.0客户端ID
               }
           ]
       }
   }
   ```

## 初始化模块

1. 在应用的MyApplication的onInitialize方法初始化JSB，在onEnd方法结束JSB模块的使用。

   ```screen
   import com.huawei.hms.jsb.adapter.har.bridge.HmsBridge;
   import ohos.aafwk.ability.AbilityPackage;

   public class MyApplication extends AbilityPackage {
       private HmsBridge mHmsBridge;
       @Override
       public void onInitialize() {
           // 初始化JSB
           mHmsBridge = HmsBridge.getInstance();
           mHmsBridge.initBridge(this);
           super.onInitialize();
       }
       @Override
       public void onEnd() {
           // 结束JSB
           mHmsBridge.destoryBridge();
           super.onEnd();
       }
   }
   ```

2. 在HarmonyOS应用"entry/src/main/js/default/app.js"文件中添加如下代码。

   ```screen
   import {hmsjsb} from '@hw-hmscore/hms-js-base'
   export default {
       hmsData: {
           eventCallbackMap: {}
       },
       onCreate() {
           console.info('AceApplication onCreate');
           hmsjsb.init(this.hmsData.eventCallbackMap);
       },
       onDestroy() {
           console.info('AceApplication onDestroy');
       }
   }
   ```

## 同步工程

在完成以上的配置后，点击右上角"Sync Now"，完成"build.gradle"文件的同步，将相关依赖下载到本地。 说明
>
> 如果出现错误，请检查网络连接是否正常，以及检查"build.gradle"文件是否正确。
