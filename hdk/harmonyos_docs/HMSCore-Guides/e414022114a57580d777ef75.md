# 集成HVR SDK

华为VR支付是专门为VR应用提供的支付服务，需要您的应用首先集成VR SDK，快速搭建基于华为VR眼镜和华为手机的VR场景平台，集成HVR SDK的开发指南参见[HUAWEI VR开发](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/introduction-0000001144238265 )。
