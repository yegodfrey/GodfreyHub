# 集成HMS Core SDK

针对HUAWEI DevEco Studio开发环境，华为提供了Maven仓集成方式的HMS Core SDK包。在开始开发前，您需要将HMS Core SDK集成到您的HUAWEI DevEco Studio开发环境中。  

#### 添加当前应用的AppGallery Connect配置文件

如果在AppGallery Connect中开通了相关服务则需要将"agconnect-services.json"文件添加到您的App中。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"。
2. 在项目列表中找到您的项目，在项目中点击需要集成HMS Core SDK的应用。
3. 在"项目设置 \> 常规"页面的"应用"区域，点击"agconnect-services.json"下载配置文件。

如果您在"项目设置"模块进行过任何修改动作，包括但不限于：设置数据处理位置、开启或管理某些API等。您需要下载最新的"agconnect-services.json"，来替换之前的文件。  

#### 添加编译依赖

1. 打开项目级"build.gradle"文件，添加hap服务依赖（版本号固定）和agconnect服务依赖（版本信息可参见[文档说明](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-sdk-changenotes-0000001058732550)）。项目级"build.gradle"文件已自动添加Maven代码库地址，您无需额外配置。

   ```
   buildscript { 
       dependencies { 
           // 添加打包hap服务依赖
           classpath 'com.huawei.ohos:hap:2.4.4.2' 
           // 添加agconnect服务依赖。
           classpath 'com.huawei.agconnect:agcp-harmony:1.3.0.300'
       } 
   } 
   ```

2. 打开"entry"应用级根目录的"build.gradle"文件。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231103095834.95015992792165210945216029789387:50001231000000:2800:5D8A0BEF3BB5F35B97A25024FBBD21F30DFFA1069AC7FB90F808C3F271051036.jpg?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)
3. 在"dependencies"中添加push sdk编译依赖，最新版本可参见[文档说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmony-java-version-0000001225790169)。

   ```
   dependencies {
       implementation 'com.huawei.hms:push-ohos:5.2.0.306'
   }
   ```

#### 配置config.json文件

您需要在"entry/src/main/config.json"文件的"module"标签下注册您自己的"service"，用于[获取Token](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmony-java-devguides-0000001199425951#section1663211917216)。该"service"继承[HmsMessageService](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-push-ohos-hmsmessageservice-0000001153713354)类并实现其中的方法，此处以"DemoHmsMessageServiceAbility"为例（类名由您自定义）。

```
{
    "module": {
        "abilities": [
            {
                ...
                "skills": [
                    {
                        "actions": [
                            "com.huawei.push.action.MESSAGING_EVENT"
                        ]
                    }
                ],
                "name": ".DemoHmsMessageServiceAbility",
                "icon": "$media:icon",
                "description": "$string:demohmsmessageserviceability_description",
                "type": "service",
                "visible": false,
                "permissions": []
            }
        ]
   }
}
```
