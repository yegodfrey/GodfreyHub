# 形状

华为地图SDK支持为地图添加形状，主要包括三种形状：折线、多边形、圆。

## 折线

[Polyline](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-polyline-0000001147992569)由若干个[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-latlng-0000001148112535)对象连接形成的折线。创建折线对象，如[图1](#ZH-CN_TOPIC_0000001101259206__fig1524891885920)所示。

```java
// 初始化Polyline对象
Polyline mPolyline = new Polyline(this);

// 如果mHuaweiMap为null，程序停止执行
if (null == mHuaweiMap) {
    return;
}

// 如果mPolyline不为null，则先从地图上移除，再置为null
if (null != mPolyline) {
    mPolyline.remove();
    mPolyline = null;
}

// 在地图上添加一条折线
mPolyline = mHuaweiMap.addPolyline(new PolylineOptions()
    // 折线坐标
    .add(new LatLng(47.893478, 2.334595), new LatLng(48.993478, 3.434595),
        new LatLng(48.693478, 2.134595), new LatLng(48.793478, 2.334595))
            // 折线颜色
            .color(Color.BLUE.getValue())
            // 折线宽度
            .width(3));
```

## 多边形

[Polygon](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-polygon-0000001148112537)对象与[Polyline](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-polyline-0000001147992569)对象类似，因为它们都是由一系列有序坐标组成，但是不同的是，多边形是内部填充的封闭形状。创建多边形对象，如[图2](#ZH-CN_TOPIC_0000001101259206__fig11476046605)所示。

```java
// 初始化Polygon对象
Polygon mPolygon = new Polygon(this);
if (null == mHuaweiMap) {
    return;
}
if (null != mPolygon) {
    mPolygon.remove();
    mPolygon = null;
}

LatLng center = new LatLng(48.893478, 2.334595);
double halfHeight = 0.1;
double halfWidth = 0.1;

mPolygon = mHuaweiMap
    .addPolygon(new PolygonOptions().add(
        new LatLng(center.mLatitude - halfHeight, center.mLongitude - halfWidth),
        new LatLng(center.mLatitude - halfHeight, center.mLongitude + halfWidth),
        new LatLng(center.mLatitude + halfHeight, center.mLongitude + halfWidth),
        new LatLng(center.mLatitude + halfHeight, center.mLongitude - halfWidth))
        .fillColor(Color.GREEN.getValue())
        .strokeColor(Color.BLACK.getValue()));
```

## 圆

圆包括两种情况，一种是实心圆，一种是空心圆。默认是空心圆，可以用[Circle](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-circle-0000001101152764)属性进行控制。

1. 创建圆对象，如[图3](#ZH-CN_TOPIC_0000001101259206__fig7415114010118)所示。如果您需要在添加圆后更改[Circle](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-circle-0000001101152764)的属性，可以调用[Circle](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-circle-0000001101152764)对象的[setCenter](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-circle-0000001101152764#section1187515316454)()、[setRadius](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-circle-0000001101152764#section1594183211467)()等方法进行重新设置。

   ```screen
   if (null == mHuaweiMap) {
       return;
   }
   if (null != mCircle) {
       mCircle.remove();
       mCircle = null;
   }

   mCircle = mHuaweiMap.addCircle(new CircleOptions()
           .center(new LatLng(48.893478, 2.334595))
           .radius(500)
           .fillColor(Color.GREEN.getValue()));
   ```

2. 设置空心圆。

   ```java
   // 设置圆的填充色为透明色
   mCircle.setFillColor(Color.TRANSPARENT.getValue());  
   // 设置圆的边缘颜色
   mCircle.setStrokeColor(Color.RED.getValue());  
   // 设置圆的边缘宽度
   mCircle.setStrokeWidth(15.0f);
   ```

## 修改外观

### 线条颜色

华为地图SDK中支持设置[Polyline](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-polyline-0000001147992569)、[Polygon](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-polygon-0000001148112537)、[Circle](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-circle-0000001101152764)的颜色。

* 多边形

  ```java
  // 在地图上添加一个多边形mPolygon
  Polygon mPolygon = mHuaweiMap.addPolygon(new PolygonOptions().add(new LatLng(48.793478, 2.234595), new LatLng(48.793478, 2.434595), new LatLng(48.993478, 2.434595), new LatLng(48.993478, 2.234595)));
  // 设置多边形mPolygon的边框颜色为红色
  mPolygon.setStrokeColor(Color.RED.getValue());
  ```

  ```java

      .center(new LatLng(48.893478, 2.334595))

  // 设置圆mCircle的边框颜色为红色
  mCircle.setStrokeColor(Color.RED.getValue());
  ```

