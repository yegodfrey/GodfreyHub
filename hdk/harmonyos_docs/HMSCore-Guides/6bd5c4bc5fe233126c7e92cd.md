# 技术支持

当您集成推送服务遇到问题时：

* 先仔细阅读集成文档，部分功能对终端设备系统有所限制，请查看[受限说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/restrictions-0000001050040064)。
* 查阅[FAQ](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/faq-0000001050042183)及[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/commonerror-0000001059816656)内容。
* 通过[Push自助分析](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/self-service-analysis-0000001404574041)功能，输入"requestId"和"token"查询消息具体发送情况。
* 通过[在线工单系统](https://developer.huawei.com/consumer/cn/support/feedback/#/add/13?level2=111)与技术支持人员取得联系。

您也可以通过以下平台与我们进行互动：

* 登录[Stack Overflow社区](https://stackoverflow.com/questions/tagged/huawei-mobile-services?tab=Newest)和[华为开发者论坛](https://developer.huawei.com/consumer/cn/forum/block/hms-core?topicClassId=0601169076025040001&pageIndex=1)参与问题讨论。

> 说明
>
> 如果您对华为推送服务有任何疑问或者建议，请发送邮件至[hwpush@huawei.com](mailto:hwpush@huawei.com)与我们取得联系。
