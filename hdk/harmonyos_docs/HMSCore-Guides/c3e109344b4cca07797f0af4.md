# 设置地图属性

```
// 设置指南针是否可见，默认不可见
self.mapView.showsCompass = YES;
// 设置是否允许手势拖拽
self.mapView.scrollEnabled = YES;
// 设置缩放控件是否可见，默认不可见
self.mapView.showsZoomControl = YES;
// 设置是否允许缩放
self.mapView.zoomEnabled = YES;
// 设置是否允许手势旋转
self.mapView.rotateEnabled = YES;
// 设置是否支持倾斜手势
self.mapView.overlookingEnabled = YES;
// 设置最小最大缩放级别, 范围：3 <= minZoomLevel <= maxZoomLevel <= 20
[self.mapView setMinZoomLevel:3 maxZoomLevel:20];
```
