# 术语

#### 常用术语

* 用户：所有使用过App的人，采用AAID（Anonymous Application Identifier）作为用户标识。
* 新用户：历史上首次安装并使用App的用户，卸载后重装的用户也是新用户，但升级用户除外。
* 活跃用户：指定日期或时间段内使用了App的用户。
* 沉默用户：曾经使用过App，但一段时间内没有再使用App的用户。
* 回访用户：X天前使用过App且今日又使用了App的用户。
* 留存用户：曾经使用过App，经过一段时间后，又继续使用该App的用户。
* 会话：用户每次启动App，到停止使用App是一次会话。用户最后一个动作结束后停止活动超过30分钟，则记为新的会话。
* 会话时长：每次会话从开始到结束之间的时间差。
* 事件：是对用户使用产品过程中的行为的描述，例如新用户注册、播放视频、分享歌曲等。  

#### 基础指标

* 新用户数：统计日当日，首次使用App的去重用户数。
* 日活跃用户数：统计日当日，使用App的去重用户数。
* 事件数：统计日当日，用户使用App的事件总数。
* 会话数：统计日当日，用户使用App的会话次数。
* 受众群组用户数：受众群组中的成员数量。
* 受众群组事件数：受众群组成员产生的事件数。
* 自定义参数计数：针对字符型自定义参数，用户访问事件的参数值计数。
* 自定义参数求和：针对数字型自定义参数，用户访问事件的参数值求和。
* 自定义参数用户数：用户访问事件中，基于自定义参数值统计的日去重用户数。
* 活跃间隔天数：统计日日活用户上一次活跃时间距离统计日的间隔天数。
* 7天回访用户数：统计日前1-7天使用过App，且统计日使用了App的去重用户数。
* 8-30天回访用户数：统计日前8-30天使用过App，且统计日前1-7天未使用过App，且统计日使用了App的去重用户数。
* 31-90天回访用户数：统计日前31-90天使用过App，且统计日前1-30天未使用过App，且统计日使用了App的去重用户数。
* 91-180天回访用户数：统计日前91-180天使用过App，且统计日前1-90天未使用过App，且统计日使用了App的去重用户数。
* 历史回访用户数：历史上使用过App，且统计日前1-180天未使用过App，且统计日使用了App的去重用户数。
* 新增X日留存用户数：X天前的当天首次使用App，且统计日又使用App的去重用户数。
* 新增X周留存用户数：X周前首次使用App，且统计周又使用App的去重用户数。
* 新增X月留存用户数：X个月前首次使用App，且统计月又使用App的去重用户数。
* 活跃X日留存用户数：X天前的当天使用了App，且统计日又使用App的去重用户数。
* 活跃X周留存用户数：X周前使用了App，且统计周又使用App的去重用户数。
* 活跃X月留存用户数：X个月前使用了App，且统计月又使用App的去重用户数。
* 首次互动时间：用户与应用首次互动的时间，且只有APPFIRSTOPEN、DISPLAYNOTIFICATION和JOINABTASK这3个事件算为"互动"。
* 最后一次互动时间：用户与应用最后一次互动的时间，且只有APPFIRSTOPEN、DISPLAYNOTIFICATION和JOINABTASK这3个事件算为"互动"。  

#### 复合指标

* 新用户占比：新用户数/统计日日活用户数。
* 人均会话事件数：SUM(事件数)/会话数。
* 人均会话时长：SUM(会话时长)/会话数。
* 人均事件数：SUM(事件数)/统计日日活用户数。
* 访问时长：统计日日活用户会话总时长。  

#### 自定义指标

* 用户数：统计符合条件的去重用户数。
* 用户占比：统计符合条件的去重用户数/指定时间段内总去重用户数。
* 累计求和：符合条件所有事件中，取指定字段求和。
* 累计平均：累计求和/用户数。
