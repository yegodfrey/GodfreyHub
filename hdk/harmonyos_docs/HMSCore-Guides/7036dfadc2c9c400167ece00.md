# 响应式LinearLayout

应用直接使用原生LinearLayout，接入HwRspLinearLayout可通过在Xml接入方式和代码接入两种方式。  

#### Maven方式引入aar包

使用前需在build.gradle的dependencies中添加所引用控件的依赖。

```
implementation "com.huawei.ui.rspuikit:hwrsplinearlayout-androidn:{version}"
```

{version}需替换为实际的版本号，具体版本号请参见版本更新说明章节。例如:implementation 'com.huawei.ui.rspuikit:hwrsplinearlayout-androidn:1.0.0.8'。  

#### 布局XML接入方式

xml配置示例

```
<com.huawei.rspuikit.androidn.hwrsplinearlayout.widget.HwRspLinearLayout
    xmlns:android="http://schemas.android.com/apk/res/android"
    xmlns:app="http://schemas.android.com/apk/res-auto"
    xmlns:tools="http://schemas.android.com/tools"
    android:id="@+id/hw_rsp_linearlayout"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical"
    app:rspcolNum="4"
    app:rspItemSpace="10dp"
    app:rspEnable="true"
    android:paddingLeft="5dp"
    android:paddingRight="5dp">
```

#### 代码接入方式

动态创建：本方法可以在逻辑代码中直接生成相关的控件。

1. 导入控件包。

   ```
   import com.huawei.rspuikit.androidn.hwrsplinearlayout.widget.HwRspLinearLayout
   ```

2. 代码由继承LinearLayout改为继承HwRspLinearLayout或者通过new HwRspLinearLayout直接使用，代码使用方式示例如下。

   ```
   @Override
   protected void onCreate(Bundle savedInstanceState) {
           super.onCreate(savedInstanceState);
           setContentView(R.layout.activity_hwrsplinearlayout);
           HwRspLinearLayout mMainLayout = findViewById(R.id.hw_rsp_linearlayout);
           mMainLayout.setOrientation(LinearLayout.VERTICAL);
           mMainLayout.setRspEnable(true);
           mMainLayout.setRspItemSpace(10);
           // 设置展开态列数
           mMainLayout.setRspColNum(4);
       }
   ```

#### 接口能力

响应式控件扩展并兼容原生LinearLayout控件接口，扩展控件接口及说明如下表。  

|接口函数|输入|输出|返回值|接口具体描述|接口范围|
|:--------------|:------------------|:-|:---|:--------------|:------------------------------------------------------------------|
|setRspColNum|int rspColNum|无|void|响应式控件列数设置|HwRsplinearlayout控件使用，不配置默认2|
|setRspEnable|boolean isRspEnable|无|void|使能响应式能力配置|HwRsplinearlayout控件使用，不配置默认false|
|setRspItemSpace|int|无|void|响应式控件每列元素之间间距设置|HwRsplinearlayout控件使用，不配置默认0（如果不设置，元素间距使用用户设置的margin，设置后则元素间距使用设置值）|

控制展开态是否生效的接口是setRspEnable，只有设置为true时展开态才会响应式调整，若设置为false生效效果与谷歌原生控件一致。

应用可根据自己需要只在展开态显示有问题界面使能。
