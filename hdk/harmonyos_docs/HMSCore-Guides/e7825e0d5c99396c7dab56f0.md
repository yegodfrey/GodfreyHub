# 开通服务

    1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击“我的项目”图标。
    2. 选择需要查看动态标签管理数据的应用。
    3. 选择“增长 > 动态标签管理”进入开通服务页面。

       * 开通服务需要您首先点击“开启分析服务”按钮，开通分析服务。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4c/v3/74Nytc8qQj6vvOSkKSPkBQ/zh-cn_image_0000001080334715.png?HW-CC-KV=V1&HW-CC-Date=20261005T042945Z&HW-CC-Expire=86400&HW-CC-Sign=446A41D32431C4FBBD3B638E8F4ACCC0CECC7BE5ECB5F499F4D7724F55D75F31)

       * 如果您已经开通分析服务，那么您可以直接点击“开通服务”按钮来开通DTM服务。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/65/v3/pDxtJK8MSL22OCZrleECTw/zh-cn_image_0000001076524394.png?HW-CC-KV=V1&HW-CC-Date=20261005T042945Z&HW-CC-Expire=86400&HW-CC-Sign=A5D16D79104468A235D91FF60E06E452D3B966CBB4831A2F6D5CA60BB0510B71)

    4. 您可以在“开通服务”窗口设置配置名称，修改操作记录的保存时间。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3/v3/T6UdfesYQ72MoAeYi5lKFA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T042945Z&HW-CC-Expire=86400&HW-CC-Sign=E3A744703ECAE9E7B2EC9D6A698E184D560B166C50DB45AE5A54C30876156E32)

集成DTM必须先集成Analytics Kit，因此从DTM5.2.0版本开始，取消“上报设置”选项，所有事件将默认上报到HUAWEI Analytics平台。

若您需要对上报事件进行修改，可以通过在DTM页面配置HUAWEI Analytics代码来增加、修改相关事件参数的值，或者阻塞某些事件，详情请参见[如何修改或阻塞上报给Analytics Kit的事件](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/faq-0000001050169001#section1189724312588)。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/88/v3/vr8AB2MoQlqieQu8aFWI9Q/zh-cn_image_0000001076739726.png?HW-CC-KV=V1&HW-CC-Date=20261005T042945Z&HW-CC-Expire=86400&HW-CC-Sign=BC524ED2650CDE04E790468939AC5AC0D98E4E564910C932360544A0DACE6EA8)

    5. 点击“确定”按钮，会进入“配置”页面，您可以看到相关配置信息，并可以进行导入、导出、编辑操作和关闭服务。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c4/v3/uqW30TZXRj-xITZpIrKzCQ/zh-cn_image_0000001076325228.png?HW-CC-KV=V1&HW-CC-Date=20261005T042945Z&HW-CC-Expire=86400&HW-CC-Sign=166CFE9E447E19FEBD582208A5F69DA60880F09FD3948C4A4E1AADFE8C5DA4C2)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/43/v3/zSVFFI94QE-5BzVAKHIJxw/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T042945Z&HW-CC-Expire=86400&HW-CC-Sign=AB45498C4F8EC36CDDDFB3B8047A61768DD0B18567241C440BA6D4C9F3CFE2DB)

    * [团队帐号持有者](https://developer.huawei.com/consumer/cn/doc/start/team-account-guides-0000001053785552)和管理员拥有开通服务的权限。
    * 应用包名与创建应用时填写的包名一致，DTM会根据您的应用自动关联，创建配置时不允许修改。
    * 一个应用只允许创建一个配置，如果您已经完成配置创建，则无需再次创建。
