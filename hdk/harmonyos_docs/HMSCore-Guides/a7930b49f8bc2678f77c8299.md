# 集成SDK  
  
#### 在Xcode项目中集成SDK（Cocoapods方式集成）

        1. 在Xcode开发环境中添加当前应用的AppGallery Connect配置文件。
           1. 登录[ _AppGallery Connect 网站_](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) ，选择“我的项目”。
           2. 在项目列表中找到您的项目，在项目列表中点击需要集成SDK的应用。
           3. 在“项目设置”页面中，点击“应用”栏下的“agconnect-services.plist”下载配置文件。
           4. 将“agconnect-services.plist”文件拷贝到应用级根目录下。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115317.19129842621118480588321535703151:50001231000000:2800:4B2DF16A921378DA057E04AF6CA5F64B110AFDB0ECE24776003FC4B0D92871B2.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

              1. 在获取“agconnect-services.plist”文件前，请确保已经完成分析服务的开通（开通步骤参见[开通华为分析服务](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/ios-config-agc-0000001050166522#section16141910204411)）。
              2. 如果您在“开发”模块进行过任何修改动作，包括但不限于：设置数据处理位置、开启或管理某些API等。您需要下载最新的“agconnect-services.plist”，并替换iOS项目根目录下已有的文件。

        2. 编辑Podfile文件。
           * 如果需要采集IDFA (Identifier for Advertising，广告标识符)，增加pod依赖'HiAnalyticsExtended'，Podfile示例如下：
                 
                 # Uncomment the next line to define a global platform for your project
                 # platform :ios, '9.0'
                 
                 target 'HiAnalyticsPodDemo' do
                   # Comment the next line if you don't want to use dynamic frameworks
                   use_frameworks!
                 
                   # Pods for HiAnalyticsPodDemo
                    **pod 'HiAnalyticsExtended'**
                 
                   target 'HiAnalyticsPodDemoUITests' do
                     # Pods for testing
                   end
                 
                 end

           * 如果不需要采集IDFA，增加pod依赖'HiAnalytics'，Podfile示例如下：
                 
                 # Uncomment the next line to define a global platform for your project
                 # platform :iOS, '9.0'
                 
                 target 'HiAnalyticsPodDemo' do
                   # Comment the next line if you don't want to use dynamic frameworks
                   use_frameworks!
                 
                   # Pods for HiAnalyticsPodDemo
                    **pod 'HiAnalytics'**
                 
                   target 'HiAnalyticsPodDemoUITests' do
                     # Pods for testing
                   end
                 
                 end

        3. 执行**pod install** ，完成pod的安装。
               
               $ pod install

#### 在Xcode项目中集成SDK（手动方式集成）

#### [h2]下载SDK（采集IDFA）

        1. 请下载**HiAnalyticsExtended** SDK及其依赖的SDK包，并解压压缩包。下载地址请参见：[SDK下载（手动方式集成）](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Library/ios-sdk-download-0000001050414801)。

           1. 右键工程，选择“Add Files to 工程名”，随后左键去选择要导入的“framework”文件。

#### [h2]添加资源文件依赖和项目参数

        1. 如果您集成了采集IDFA的SDK，需配置“Info.plist”文件，向用户申请权限。

在“Info.plist”文件中添加参数“Privacy - Tracking Usage Description”和对应的value值，value值的描述可参照下图红框中的文案或者自行定义。获取用户授权后方可跟踪广告标识符（IDFA）信息，同时请在您应用的隐私声明中增加采集IDFA的相关说明。

#### APP Store上架指引（采集了IDFA）

**HiAnalyticsExtended** SDK支持采集IDFA(Identifier for Advertising，广告标识符)。苹果Appstore对应用的审核较为严格，禁止没有使用广告服务而采集IDFA的应用上架。若您使用了IDFA，理论上需要集成任意一家的广告服务，但如果您未集成任何广告服务，为防止应用因获取IDFA被AppStore拒绝，需要在iTunes Connect中进行如下配置：

        1. 在iTunes Connect中提交新版本审核时，在“Advertising Identifier”选项中，点击选择“Does this app use the Advertising Identifier(IDFA)?”后的“Yes”。
        2. 在“Advertising Identifier”下的子选项中，进行如下配置。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115318.38877100670012427201366701083510:50001231000000:2800:18951B5A78E5A588CD03FD8870A2B665B35FCF21EBBA46E423A7D8BE7C3BB9E1.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115318.35128408823491433693601860612432:50001231000000:2800:1D6711184B9E603D73D0A5F18A4AC3C886C2DE35781205DD08AD5F2A13992B2F.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

           1. Serve advertisements within the app

服务应用中提供广告。若您的应用中集成了广告，需要勾选这一项；否则，不勾选。

           2. Attribute this app installation to a previously served advertisement

此应用程序将跟踪广告带来的安装。需要勾选。

           3. Attribute an action taken within this app to a previously served advertisement

此应用程序将跟踪广告带来的用户的后续行为。需要勾选。

           4. Limit Ad Tracking setting in iOS

将在iOS系统中设置广告跟踪的限制。需要勾选。
