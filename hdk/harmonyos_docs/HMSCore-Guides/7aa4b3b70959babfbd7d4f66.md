# 版本更新说明

## 1.1.0.306（2023-04-21）

|------------------------------------------------|
|本次iOS版本特性变更如下： **修改特性** 更新了Scan Kit的打包方式，功能不受影响。|

## 历史版本

### 1.1.0.305（2022-11-04）

|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|本次iOS版本特性变更如下： **新增特性** Customized View提供暂停连续扫码和恢复连续扫码功能：新增[pauseContinuouslyScan](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmscustomscanviewcontroller-0000001050187740#section1255214122122)和[resumeContinuouslyScan](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmscustomscanviewcontroller-0000001050187740#section1569991317123)方法。 **修改特性** * 修复无法识别部分二维码问题。 * 修复Customized View设置扫码有效区域失效的问题。 * SDK收集的个人信息的补充说明。|

### 1.1.0.304（2022-08-05）

|------------------------------------------------------------------------------------|
|本次iOS版本特性变更如下： **修改特性** 修复多码识别中心点坐标位置不准确的问题。 **优化特性** 增加Default View Mode黑暗环境下闪光灯效果。|

### 1.1.0.303（2022-06-17）

|-------------------------------------------------------|
|本次iOS版本特性变更如下： **修改特性** 解决您在苹果商店上传集成了Scan SDK的App报错的问题。|

### 1.1.0.302（2022-05-07）

|---------------------------------------------------------------------------|
|本次iOS版本特性变更如下： **修改特性** * 解决pods集成问题。 * 解决CustomScanView中自定义控件无法加入到view的问题。|

### 1.1.0.301（2022-04-19）

|---------------------------------------|
|本次iOS版本特性变更如下： **修改特性** 解决曝光问题，提升扫码识别率。|

### 1.1.0.300（2022-03-21）

|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|本次iOS版本特性变更如下： **新增特性** Bitmap Mode新增多码识别能力：[multiDecodeBitMapForImage: withOptions:](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsbitmap-0000001050429949#section1820212819529)和[multiDecodeBitMapForSampleBuffer: withOptions:](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsbitmap-0000001050429949#section15174182316537)。|

### 1.0.2.300（2020-10-27）

|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|本次iOS版本特性变更如下： **新增特性** Bitmap Mode新增相机扫码接口方法：[multiDecodeBitMapForSampleBuffer: withOptions:](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsbitmap-0000001050429949#section15174182316537)。 **修改特性** Customized View Mode增加属性continuouslyScan，是否持续扫码由您可自行调用。默认为false不持续扫码，赋值true为持续扫码。 **优化特性** * 调节相机曝光，提升扫码识别率。 * 增加线程调用安全，您需要在主线程内处理扫码结果，解决了因同时调用扫码算法产生的冲突问题。|

### 1.0.1.300（2020-07-27）

|---------------------------------------------------------------|
|本次iOS版本特性变更如下： **优化特性** * 引入深度学习算法，增强扫码识别能力。 * 通过优化依赖关系降低SDK大小。|

### 1.0.0.300（2020-06-15）

|-------------------------|
|首次发布，支持iOS系统集成，欢迎广大开发者接入。|
