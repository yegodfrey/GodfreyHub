# 集成SDK

针对Xcode开发环境，华为提供了CocoaPods工具和手动方式集成SDK包。在开始开发前，您需要将SDK集成到您的Xcode开发环境中。

#### 添加当前应用的AppGallery Connect配置文件

              1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击“我的项目”。
              2. 在项目列表中找到您的项目，在项目中点击需要集成HMS Core SDK的应用。
              3. 在“项目设置 > 常规”页面的应用区域，点击“agconnect-services.plist”下载配置文件。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/28/v3/R-a3MZykReOiq_pqHALTRQ/zh-cn_image_0000001071703846.png?HW-CC-KV=V1&HW-CC-Date=20261005T043046Z&HW-CC-Expire=86400&HW-CC-Sign=44324A968AF0756ACD6B5C7096D8B9BBC8D3B64CA05F009EEFFC9096E105DA3F)

              4. 将“agconnect-services.plist”文件拷贝到应用级根目录下。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cc/v3/sZ1KMdFESruX1tWulfLj-g/zh-cn_image_0000001070863921.png?HW-CC-KV=V1&HW-CC-Date=20261005T043046Z&HW-CC-Expire=86400&HW-CC-Sign=A9BF2FFE5E5937DEB48ADD591D930D82C5DC2726770625DE736415845C6850B3)

#### 添加SDK

#### [h2]CocoaPods工具集成（推荐）

              1. 安装CocoaPods工具。

                 1. （可选）打开“Terminal”，执行如下命令，切换gem默认的源到国内，并确保只有国内的源。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/27/v3/DVbTWRSjR_iy5ccP_NDg0w/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043046Z&HW-CC-Expire=86400&HW-CC-Sign=4A342197D5D7D0F6E47030261A7863072CD52DE2ECAC25A6736BD5994A11CBB7)

若您在中国大陆，需要执行此步骤；否则，不需要执行此步骤。
                        
                        gem sources –add https://gems.ruby-china.com/ --remove https://rubygems.org/
                        gem sources -1

                 2. 进入Xcode工程的“xxx.xcodeproj”文件所在目录，执行如下命令，进行安装。
                        
                        sudo gem install cocoapods

                 3. 执行如下命令，校验是否安装成功，如果成功则显示pod的版本。
                        
                        pod --version

                 4. 执行如下命令，初始化CocoaPods环境。
                        
                        pod setup

              2. 添加相关依赖到CocoaPods中。

                 1. 进入Xcode工程的“xxx.xcodeproj”文件所在目录，执行如下命令，生成podfile文件。
                        
                        pod init

                 2. 在podfile文件中，加入代码。
                        
                        pod 'DTMSDK'
                        pod 'HiAnalytics'

                 3. 执行如下命令，CocoaPods会自动安装SDK。
                        
                        pod install

#### 配置白名单

              1. 在“Info”页签下，配置URL Scheme白名单，可以使用扫码链接启动应用进行版本预览及可视化连接。即进行如下配置：

                 * 版本预览配置：dtm.configuration.$(PRODUCT_BUNDLE_IDENTIFIER)
                 * 可视化连接配置：dtm.visual.$(PRODUCT_BUNDLE_IDENTIFIER)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0a/v3/l5mFCudbToe2F_SwkRawKA/zh-cn_image_0000001144751081.png?HW-CC-KV=V1&HW-CC-Date=20261005T043046Z&HW-CC-Expire=86400&HW-CC-Sign=EFF5C9B0981E30E4DA6083D4591078213822B56ED4CE765C401E724A636C2636)

              2. 通过扫码打开预览或者建立可视化连接时，您需要在“AppDelegate.m”中配置相关代码。

                 * iOS 9及之后版本openUrl的方法
                       
                       - (BOOL)application:(UIApplication *)app openURL:(NSURL *)url options:(NSDictionary<UIApplicationOpenURLOptionsKey, id> *)options{    
                       [DynamicTagManager dtmHandleOpenUrl:url];    [1] 
                       return YES;
                       }

                 * iOS 9之前版本openUrl的方法
                       
                       - (BOOL)application:(UIApplication *)application openURL:(NSURL *)url sourceApplication:(nullable NSString *)sourceApplication annotation:(id)annotation{    
                       [DynamicTagManager dtmHandleOpenUrl:url];    
                       return YES;
                       }

              3. （可选）若您的应用支持了iOS 13 UIScene多窗口功能，需要在如下两个函数中调用DTM接口。
                     
                     - (void)scene:(UIScene *)scene willConnectToSession:(UISceneSession *)session options:(UISceneConnectionOptions *)connectionOptions {[1] 
                           // 调用DTM接口
                           NSSet *openUrlSet = [connectionOptions URLContexts];
                           UIOpenURLContext *openURLContext = [openUrlSet.allObjects firstObject];
                           [DynamicTagManager dtmHandleOpenUrl:openURLContext.URL];
                       }
                     
                     - (void)scene:(UIScene *)scene openURLContexts:(NSSet<UIOpenURLContext *> *)URLContexts {
                           // 调用DTM接口
                           UIOpenURLContext *openURLContext = [URLContexts.allObjects firstObject];
                           [DynamicTagManager dtmHandleOpenUrl:openURLContext.URL];
                       }

#### 权限申请

              1. iOS 10及之后版本，需要在“Info.plist”文件中添加权限“Allow Arbitrary Loads”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c3/v3/EJzHpza0Sjyl6aLjf-3u6Q/zh-cn_image_0000001098151134.png?HW-CC-KV=V1&HW-CC-Date=20261005T043046Z&HW-CC-Expire=86400&HW-CC-Sign=BD3F5DF3F03792B795B89F1A8F8017B71F7B756E419E64B07E5E04012E9D5041)

              2. iOS 14及之后版本，需要在“Info.plist”文件中添加的权限“NSUserTrackingUsageDescription”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/45/v3/lG6Gt2xlQxC5xq29QypLGQ/zh-cn_image_0000001098351124.png?HW-CC-KV=V1&HW-CC-Date=20261005T043046Z&HW-CC-Expire=86400&HW-CC-Sign=97F606A4CF3661CA1B1C47CB2E43F9A67C219B3268D71766B5D26D2899F95A39)

              3. iOS 14及之后版本，在“AppDelegate.m”文件中导入“AppTrackingTransparency”头文件。
                     
                     #import <AppTrackingTransparency/AppTrackingTransparency.h>

              4. iOS 14及之后版本，在“AppDelegate.m”文件的“- (BOOL)application:(UIApplication *)application didFinishLaunchingWithOptions:(NSDictionary *)launchOptions”方法内添加如下代码实现。
                     
                     if (@available(iOS 14, *)) {
                             // iOS 14及以上版本需要先请求权限
                             [ATTrackingManager requestTrackingAuthorizationWithCompletionHandler:^(ATTrackingManagerAuthorizationStatus status) {
                             }];
                         }
