# 集成SDK  
  
#### 采用npm方式集成SDK

                1. 如果项目中没有“package.json”文件，可以在项目的根目录下，使用以下命令来创建：
                       
                       npm init

                2. 通过运行以下npm命令，安装SDK软件包。
                       
                       npm install --save @hw-hmscore/analytics-web

#### 采用umd方式集成SDK

                1. 下载umd版本的SDK，下载链接请参见[Web SDK下载](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Library/javascript-sdk-download-nmp-0000001050825675)。 
                2. 将下载的SDK包中的“hw-hmscore-analytics-web-_6.x.x-300_.umd.js”文件放到您的工程中。
