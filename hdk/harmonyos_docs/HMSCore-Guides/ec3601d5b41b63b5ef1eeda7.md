# 活动热量

活动热量指进行身体活动时消耗的热量，包括专门或零星进行的体育活动、家务活动和其他活动等。

此数据记录用户在一小段时间内的卡路里值，每一条数据都代表该时间段（开始时间-结束时间）内的卡路里。每条数据不能存在交叉，后一条数据的开始时间应该大于或等于前一条数据的结束时间。  

#### OAuth权限

联盟卡片申请的权限名称：日常活动\> 热量数据

* 读权限：https://www.huawei.com/healthkit/calories.read
* 写权限：https://www.huawei.com/healthkit/calories.write  

#### 原子采样明细数据类型

* 名称：com.huawei.continuous.calories.burnt

|字段列表|字段描述|类型|可选/必选|单位|取值范围|
|:-------|:---|:----|:----|:-|:-------------------------------------------------------------------------|
|calories|卡路里|float|M|千卡|1秒区间：(0, 0.555555555555556) 1分钟区间：(0, 33.333333333333333) 1小时区间：(0, 2000\]|
