# 我的位置

您可以开启"我的位置"功能向用户展示他们在地图上的当前位置，在使用该功能之前，请先确保您已申请定位权限。

1. 需要在Info.plist文件中，根据需要申请以下权限。

   * "NSLocationWhenInUseUsageDescription"：表示应用在前台的时候可以获取到位置信息。
   * （可选）iOS 14系统，精准定位功能，需要申请"NSLocationTemporaryUsageDescriptionDictionary"，并配置键值对，如"purposeKey"及描述。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/53/v3/UMmkb8EyTUG96umr0DVaJg/zh-cn_image_0000001242965855.png?HW-CC-KV=V1&HW-CC-Date=20260922T085431Z&HW-CC-Expire=31536000000&HW-CC-Sign=2A6FB82632E540C54DFA29E05E5D0B797A3531E9DA83E4BC0477C32D442F7E1D "点击放大")

2. （可选）iOS 14系统，通过代码申请精准定位权限：

   ```screen
   if (@available(iOS 14.0, *)) {
       if (self.mapView.accuracyAuthorization == CLAccuracyAuthorizationReducedAccuracy) {
           // 申请精细定位权限
           [self.mapView requestTempPrecisedLocation:self.mapView purposeKey:@"purposeKey" completion:^(NSError *error) {
           if (error) {
               NSLog(@"%@", error);
           }
       }];
   }
   ```

3. 调用[HMapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hmapview-0000001191938980)对象的showsUserLocation方法以启用定位当前位置功能。

   ```screen
   self.mapView.showsUserLocation = true;
   ```

4. 调用[HMapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hmapview-0000001191938980)对象的showsLocationButton方法以启用我的位置功能。

   ```screen
   self.mapView.showsLocationButton = true;
   ```

在开启该功能后，"我的位置"按钮默认显示在地图的右下角，用户的定位会以蓝色圆点的形式呈现（[图1](#ZH-CN_TOPIC_0000001198234636__fig19358164316)）。 当用户点击该按钮时，如果获取到用户的位置，将会在屏幕中心显示当前定位（[图2](#ZH-CN_TOPIC_0000001198234636__fig1899411311013)）。
