# 游戏升级

## 场景介绍

在应用启动完成后或用户在应用中主动检查应用新版本时，应用需要调用HMS Core SDK的升级接口检测华为应用市场是否有新版本应用。如果需要升级，HMS Core SDK将拉起升级提示框提示用户在华为应用市场升级应用。

您在调用[AppUpdateClient.showUpdateDialog](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/appupdateclient-0000001050123641#section1113567144514)方法时传入强制更新按钮参数mustBtnOne的取值不同会带来不同的用户体验。

* 当mustBtnOne参数传入true时：若您在AppGallery Connect中[升级应用的版本](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-update-version-0000001146436549)时选择了强制升级，用户只能选择立即更新。

  若不选择强制升级，用户可以不立即更新应用而继续使用老版本的应用。

  ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250926150008.08434158822737132970850860062772:50001231000000:2800:D6F696398C8CC361C49D7FCB48DFAC356A8CD7F9F383D5695D9988A1B29474AB.png)
* 当mustBtnOne参数传入false时：若您在AppGallery Connect中[升级应用的版本](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-update-version-0000001146436549)时选择了强制升级，用户可以选择立即更新或者选择退出应用。若不选择强制升级，用户可以不立即更新应用而继续使用老版本的应用。

  ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250926150008.13493622728557896492912387957348:50001231000000:2800:E75CBF0DFCBCFB83ABB50E4F095A5C83256E76FAB455CEA7DF3F97DEFAB45403.png)
  > 说明
  >
  > 请务必保证您的客户端中补充"退出应用"按钮的逻辑处理，否则会导致强制更新失效。

## 前提条件

必须在[JosAppsClient.init(AppParams appParams)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/josappsclient-0000001050121680#section12941311162615)方法调用成功后再实现游戏升级功能，init方法调用请参考[游戏初始化](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/game-start-0000001050123475)。

## 注意事项

发布地区为中国大陆的游戏，要求必须集成游戏升级功能。

## 开发步骤

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250926150008.00178652562076010230633089327022:50001231000000:2800:8ABE8F2027AECC5F902A7C7B465D521D35FFA99816BFB1D57C58FE8F0B0DA8D0.png)

本功能涉及的关键开发步骤如下：

1. 调用[JosApps.getAppUpdateClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/josapps-0000001050123631#section92204310917)方法初始化[AppUpdateClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/appupdateclient-0000001050123641)对象，并调用[AppUpdateClient.checkAppUpdate](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/appupdateclient-0000001050123641#section15712187193218)方法请求检查应用是否有更新。

   ```screen
   public void checkUpdate() {
       AppUpdateClient client = JosApps.getAppUpdateClient(this);
       client.checkAppUpdate(this, callback);
   }
   ```


2. SDK通过回调方式将检查结果返回给应用，应用从回调结果中onUpdateInfo方法返回的[ApkUpgradeInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/apkupgradeinfo-0000001050121688#section772111184216)实例确认应用是否有更新。如果有新版本，则调[AppUpdateClient.showUpdateDialog](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/appupdateclient-0000001050123641#section1113567144514)方法请求拉起升级提示页面。

   ```screen
   private static class Callback implements CheckUpdateCallBack {
       private WeakReference<Context> mContextWeakReference;
       public Callback(Context context) {
           mContextWeakReference = new WeakReference<>(context);
       }
       @Override
       public void onUpdateInfo(Intent intent) {
           if (intent != null) {
               // 更新状态信息
               int status = intent.getIntExtra(UpdateKey.STATUS, -99);
               Log.i(TAG, "check update status is:" + status);
               // 返回错误码
               int rtnCode = intent.getIntExtra(UpdateKey.FAIL_CODE, -99);
               // 返回失败信息
               String rtnMessage = intent.getStringExtra(UpdateKey.FAIL_REASON);
               // 强制更新应用时，弹出对话框后用户是否点击"退出应用"按钮
               boolean isExit = intent.getBooleanExtra(UpdateKey.MUST_UPDATE, false);
               Log.i(TAG, "rtnCode = " + rtnCode + "rtnMessage = " + rtnMessage);

               Serializable info = intent.getSerializableExtra(UpdateKey.INFO);
               // 如果info属于ApkUpgradeInfo类型，则拉起更新弹框
               if (info instanceof ApkUpgradeInfo) {
                   Context context = mContextWeakReference.get();
                   if (context != null) {
                       // showUpdateDialog接口中最后一个字段传入不同取值会带来不同的用户体验，具体请参考本文档的场景描述，此处以false为例
                       JosApps.getAppUpdateClient(context).showUpdateDialog(context,(ApkUpgradeInfo) info,false);
                   }
                   Log.i(TAG, "check update success and there is a new update");
               }
               Log.i(TAG, "check update isExit=" + isExit);
               if (isExit) {
                   // 是强制更新应用，用户在弹出的升级提示框中选择了"退出应用"，处理逻辑由您自行控制，这里只是个例子
                   System.exit(0);
               }
           }
       }

       @Override
       public void onMarketInstallInfo(Intent intent) {

       }

       @Override
       public void onMarketStoreError(int i) {

       }

       @Override
       public void onUpdateStoreError(int i) {

       }
   }
   ```
