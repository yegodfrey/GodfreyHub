# 使用入门

## 开发环境

* 安装Xcode 10.1或更高版本。为保证兼容性，要求最低兼容iOS 10。

* 安装CocoaPods 1.4.0或更高版本。
* 请准备一台用于测试的iPhone设备。
* 支持arm64编译环境。

## 支持的设备

|设备类型|OS版本|
|:-----|:--------|
|iPhone|iOS 10及以上|

## 开发流程

您需要按照如下流程完成应用的开发工作。

|开发步骤|说明|
|:---------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[创建应用](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-dev-prepare-0000001062940204#section113157170295)|在开发应用前，需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中配置相关信息，包括：注册成为开发者、创建应用和设置数据处理位置。|
|[准备iOS推送消息凭证](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-dev-prepare-0000001062940204#section16293938144810)|指导您[生成APNs身份验证密钥](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-dev-prepare-0000001062940204#section1870915174228)、[生成APNs证书](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-dev-prepare-0000001062940204#section255544822319)，如果您已有凭证则忽略本步骤。|
|[配置iOS推送代理权益](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-dev-prepare-0000001062940204#section11756194516409)|在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中配置iOS推送代理权益。|
|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-dev-prepare-0000001062940204#section920419487370)|在Xcode开发环境中添加配置文件，以Cocoapods方式或手动方式集成SDK。|
|[获取Token](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-dev-guides-0000001062462396#section5191122383410)|获取接入推送服务的Token。|
|[发送消息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-dev-guides-0000001062462396#section451411814133)|您可以通过[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)或通过服务端API向IOS应用推送消息。|
|[上报消息到达事件（可选）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-dev-guides-0000001062462396#section1462395934919)|您可以通过调用上报消息事件的方法，在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)上查看数据上报详情。|
