# 发送内部认证指令

读卡设备发送随机数到Applet并且验证返回的卡片私钥签名。

1. 读卡设备生成任意小于64字节的随机数random。

   发送内部认证指令，"00880082"+ 随机数字节长度 +"random"。例如：

   ```screen
   00880082102D0FBA74ED07F23FF3C30A2F905076B7
   ```

2. 读取内部认证指令响应报文，该响应报文由applet计算生成，计算过程见[PBOC数字签名流程](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/guide-appendix-read-authentication-pboc-0000001051671371#section18153267171)。
