# 操作流程

#### 创建代码

                1. 在“代码”页面，点击“新建”按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b0/v3/WA_Mt7RjSxm7TgKqajvqpA/zh-cn_image_0000001090900011.png?HW-CC-KV=V1&HW-CC-Date=20261005T043141Z&HW-CC-Expire=86400&HW-CC-Sign=C4BB7B49464D2BC1D4CB1E0C08DF421A136DE4081601B391A4EEF59DF7A54698)

                2. 在“新建代码”页面的“配置”区域输入代码名称，选择代码扩展类型并输入对应的参数。
                3. 在“新建代码”页面的“条件”区域设置代码的“触发条件”和“例外条件”。

                   * “触发条件”满足时将上报事件至分析平台。
                   * “例外条件”满足时将阻止事件上报。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2b/v3/WT-h4956QWuudtNP9cHC1A/zh-cn_image_0000001091319183.png?HW-CC-KV=V1&HW-CC-Date=20261005T043141Z&HW-CC-Expire=86400&HW-CC-Sign=C3A35AEDB068A296E44D0330DA2D39738F235AE6D468A10D2DDC4F06C11307FE)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bc/v3/80fDqfeJRJWBabnZrA0l6g/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043141Z&HW-CC-Expire=86400&HW-CC-Sign=A2B1490D24E2CC3074B6020170025721A4F4C5437CE9F3B0702079E113791619)

                   * 配置代码参数时，若输入框右侧有引用符号![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/69/v3/7XZnLI9LQzS02BPA9v1uEA/zh-cn_image_0000001090021417.png?HW-CC-KV=V1&HW-CC-Date=20261005T043141Z&HW-CC-Expire=86400&HW-CC-Sign=3DA8A6835F848913721E9DB8B5F846A7E0E19F6346D40EB972DE4B52A65C2871)，点击该符号可以对已创建变量进行引用。对于引用变量，页面中使用“{{}}”进行标注。

若您所需的变量还未创建，可通过点击“配置”按钮，配置预设变量；或通过点击“新建”按钮，新建自定义变量。

                   * 代码配置应至少包含一个触发条件，若同时配置了触发条件和例外条件，优先触发例外条件。

                4. 设置完成后，点击“保存”。

#### 编辑代码

                1. 在“代码”页面，点击已创建代码的名称。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/19/v3/I_EOV77JSK-PnUHXNKQCSw/zh-cn_image_0000001130488293.png?HW-CC-KV=V1&HW-CC-Date=20261005T043141Z&HW-CC-Expire=86400&HW-CC-Sign=9090AFBE25BB69873EC9ABB434169FCBE8BC7879CE72EF218A442734DBA69552)

                2. 在“编辑代码”页面可以对代码的配置和条件进行修改。修改完成后，点击“保存”按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b0/v3/g0IXiNqPTMKOQ8GnJw8U2Q/zh-cn_image_0000001130325871.png?HW-CC-KV=V1&HW-CC-Date=20261005T043141Z&HW-CC-Expire=86400&HW-CC-Sign=3DDEDEFBA80AFDBE0D55CC2FDC429B0A7752CACCA8C3015D4CBE41F08E0C84CF)

#### 复制代码

                1. 在“代码”页面，点击已创建代码右侧的“复制”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ba/v3/iL0VfYZzQ1CWwxwLZPHQrg/zh-cn_image_0000001083469280.png?HW-CC-KV=V1&HW-CC-Date=20261005T043141Z&HW-CC-Expire=86400&HW-CC-Sign=8F1E64AF607152BACAD5AFB091A62FAC91A148FCE437D2C25C1517FD514863CD)

                2. 在“复制代码”页面可以对代码的配置和条件进行修改。修改完成后，点击“保存”按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/09/v3/5CL4Nq89QWKe1CYvjd5_eA/zh-cn_image_0000001130325979.png?HW-CC-KV=V1&HW-CC-Date=20261005T043141Z&HW-CC-Expire=86400&HW-CC-Sign=D48FB5117E2CEC34B4BCCE1B2771BB0E2158A00C6CFC54D4CA107EF18210A24D)

                3. 复制完成后，您可以在“代码”页面，查看复制的代码信息。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/58/v3/agnR8_Z5T1W9WRRJvQBmCw/zh-cn_image_0000001171230723.png?HW-CC-KV=V1&HW-CC-Date=20261005T043141Z&HW-CC-Expire=86400&HW-CC-Sign=A7DE3CC7C9A26396CE36BED48A71DA99E533FD1301B2ED727669B4398C8E66C4)

#### 暂停/执行代码

                1. 在“代码”页面，点击已创建代码右侧的“暂停”，确认“暂停代码”对话框中的提示信息后点击“确定”。

暂停成功后，系统提示“代码已暂停”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d4/v3/XgtEki3VQMySPJshDzdS8A/zh-cn_image_0000001130627201.png?HW-CC-KV=V1&HW-CC-Date=20261005T043141Z&HW-CC-Expire=86400&HW-CC-Sign=54C2D8E61C19006A3BD49CF3A9DBA411C0CF51E99FBB25326C6C989877D2A0DA)

若您需要暂停多个代码，也可以通过批量暂停功能实现。勾选待暂停代码前的方框，点击页面右上方的“暂停”按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/59/v3/P1_2pJVZTcSvKakgAp5zBQ/zh-cn_image_0000001083470274.png?HW-CC-KV=V1&HW-CC-Date=20261005T043141Z&HW-CC-Expire=86400&HW-CC-Sign=352347F37D9B0A883B45081D9BAE7A673E44129CDB9809161F6CE9B95CB91BDA)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/26/v3/3qdqodTnSzym7irZzNoTSQ/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043141Z&HW-CC-Expire=86400&HW-CC-Sign=7C77608A7FA60CE978B82505A116058F533D1F4081EA55BC5BCB636DA1FC4A3C)

代码置为暂停状态后，代码名称前会出现暂停标识，暂停状态下的代码在后续创建的版本中不会触发事件上报。

                2. 点击已暂停代码右侧的“执行”，代码恢复为可执行状态。代码恢复后，代码名称前的暂停标识会自动取消，在后续创建的版本中将正常触发事件上报。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e7/v3/9V1KHdnKSLangeJ8TYuqmQ/zh-cn_image_0000001083310352.png?HW-CC-KV=V1&HW-CC-Date=20261005T043141Z&HW-CC-Expire=86400&HW-CC-Sign=E864D9C632CF37FCB045F0B69E0C62444B5AA9AA9368A4E5BAD51C9AAD889813)

若您需要执行多个代码，也可以通过批量执行功能实现。勾选待执行代码前的方框，点击页面右上方的“执行”按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1a/v3/AgJFtmSTRr-WCjbnbgekqg/zh-cn_image_0000001083629946.png?HW-CC-KV=V1&HW-CC-Date=20261005T043141Z&HW-CC-Expire=86400&HW-CC-Sign=238D3B3E2B3A86B492F27E15BE9E6C3A12504045DE6C6ECFF562F82DB0344770)

#### 删除代码

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6b/v3/XL8zPLY6TzufTL6s3YZHEA/caution_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043141Z&HW-CC-Expire=86400&HW-CC-Sign=EDD594C20A5F4456F9A4A2DA4634B4DD29B14E343F7145CA7D980679EB5C59BC)

代码删除后将不可恢复，删除前请确认代码已不再使用。如果您只是暂时不使用该代码，您可以暂停代码。

**方法一：单个删除。** 在“代码”页面，点击已创建代码右侧的“删除”，确认对话框中的提示信息后点击“确定”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/88/v3/z_zcf4d1T1ybjjzT2BRUUA/zh-cn_image_0000001083310484.png?HW-CC-KV=V1&HW-CC-Date=20261005T043141Z&HW-CC-Expire=86400&HW-CC-Sign=BF13380F6492AE33DF84FBA92B5E636D65A02516791A904243F9646F3DE210FB)

**方法二：批量删除。** 若您需要删除多个代码，也可以通过批量删除功能实现。勾选待删除代码前的方框，点击页面右上方的“删除”按钮，确认对话框中的提示信息后点击“确定”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/99/v3/cEfp4YiRT3GJraRgZIdpyw/zh-cn_image_0000001123526338.png?HW-CC-KV=V1&HW-CC-Date=20261005T043141Z&HW-CC-Expire=86400&HW-CC-Sign=080ACAE0474E6ABB6C1B00DD4489F8BFBDCE2894EF78BB72ED764A8638A2372A)
