# 样式参考

自定义地图样式JSON文件通过下列4个元素来定义地图样式：

* mapFeature：地图要素
* options：元素选项
  * geometry.fill：几何填充
  * geometry.stroke：几何边框
  * geometry.icon：几何图标
  * labels.text.fill：文本填充
  * labels.text.stroke：文本
* paint：绘制属性
  * color：颜色，16进制颜色，例如"#FFFF00"
  * icon-type：图标类型，目前支持night/simple/standard
* visibility：可见属性，默认为可见
  * true：可见
  * false：不可见
