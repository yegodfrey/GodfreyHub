# 免登录授权开发

三方应用云侧接入SDK支持Health Service Kit免登录授权提供两种方案。

[方案一](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/cloud-free-auth-login-overview-0000002054076576#section172541133124513)通过调用类中[HWAuthLoginApi](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/lite-sdk-ios-class-hwauthloginapi-0000002063451924)的接口[authLoginAction](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/lite-sdk-ios-class-hwauthloginapi-0000002063451924#section20396113015526)来实现，[方案二](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/cloud-free-auth-login-overview-0000002054076576#section2569123718475)通过调用[HWAuthLoginApi](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/lite-sdk-ios-class-hwauthloginapi-0000002063451924)类中的接口[authLoginActionWithSportHealthApp](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/lite-sdk-ios-class-hwauthloginapi-0000002063451924#section16579173915020)来实现，两种方案接口入参一致，参数说明如下。

三方应用集成了AuthLoginSDK.framework后，通过调用HWAuthLoginApi类中的接口来支持三方应用云侧接入支持Healthkit生态免登录授权。如果账号已登录的情况下，再次请求授权，无需重复登录可直接跳到授权界面，由用户授权相应的数据访问权限。用户可以自主选择授权的数据类型，可以只授权部分数据权限。应用所能操作的用户数据，是用户授权和Health Service Kit服务审批通过的数据权限的交集。  

#### 开发参数说明

调用免登录授权接口共需要准备以下5个参数：scopes，state，clientId，deepLinkUrl，signature：

* scopes是申请授权的Scope字符串数组，一个字符串数组，以空格分开（URL编码后空格变为加号+），必须包含字符串"openid" ，更多权限请参见[OAuth权限](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/steps-0000001177343435#section165119447225)。
* state是随机串，用于防CSRF，在返回授权码Code时原封不动返回。

* clientId是三方在[申请账号服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/apply-id-0000001050747587)过程中创建应用生成的APP ID值，可在应用详情里服务信息中应用 ID查看该参数clientId的值。

  ![](https://media:901788166646601050 "点击放大")
* deepLinkUrl是三方应用deeplink拉起授权页授权后可以把授权结果返回给三方应用的Scheme地址，可在应用详情里Scheme信息中的应用Scheme地址查看该参数deepLinkUrl的值。 ![](https://media:901788166646656053 "点击放大")

* signature是申请Scheme地址时云端分配的secret，可在应用详情里Scheme信息中的Scheme Secret查看该参数signature内容。 ![](https://media:901788166646710054)

#### 方案一操作步骤

1. 在LoginViewController.m的viewDidLoad方法中调用初始化单例方法[sharedInstance](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/lite-sdk-ios-class-list-0000002054177106#ZH-CN_TOPIC_0000002547959335__zh-cn_topic_0000001993939074_section1177142134312)，并调用[registerApp](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/lite-sdk-ios-class-list-0000002054177106#ZH-CN_TOPIC_0000002547959335__zh-cn_topic_0000001993939074_section593316567515)方法并传入相关参数(这些参数都是在开发平台注册的相关参数)。

   <br />

   ```
    **
   *初始化单例对象
   */
   + (instancetype)sharedInstance；

   /*! @brief 注册第三方应用。
    *
    * 需要在每次启动第三方应用程序时调用。
    * @attention 请保证在主线程中调用此函数
    * @param clientId 华为开发者ID
    * @param redirectUri 授权后要回调的URI，即接收Authorization Code的URI
     * @param signature 三方应用的签名
    * @param state 校验码
    */
   - (void)registerApp:(NSString *)clientId
           scope:(NSArray *)scope
           redirectUri:(NSString *)redirectUri
           signature:(NSString *)signature
           state:(NSString *)state;
   ```

   <br />

2. 在需要调用授权的地方调用[authLoginAction](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/lite-sdk-ios-class-hwauthloginapi-0000002063451924#section20396113015526)方法：

   <br />

   ![](https://media:901788166646739055)  
   若宿主工程存在SceneDelegate类，在SceneDelegate.m类中，通过"-(void)scene:(UIScene \*)scene openURLContexts:(NSSet\<UIOpenURLContext \*\> \*)URLContexts"方法解析获取到的url链接查看授权结果；若宿主工程不存在SceneDelegate类，则在AppDelegate中通过"-(BOOL)application:(UIApplication \*)application openURL:(NSURL \* _Nonnull)url options:(NSDictionary\<UIApplicationOpenURLOptionsKey,id\> \* _Nonnull)options"方法解析获取到的url链接查看授权结果。  

   ```
   /**
    授权登录
    授权结果从sceneDelegate的“- (void)scene:(UIScene *)scene openURLContexts:(NSSet<UIOpenURLContext *> *)URLContexts”
    或者
    从Appdelegate的“- (BOOL)application:(UIApplication *)app openURL:(NSURL *)url options:(NSDictionary<UIApplicationOpenURLOptionsKey, id> *)options”
    方法里取
    */
   -(void)authLoginAction;
   ```

   示例代码如下：

   ```
   /**
   *初始化注册三方应用
   不同的Scope对应不同的权限，开发者可以根据自己的业务需要申请对应权限，然后将申请的scope传入。
   */

   //添加需要申请的权限，这里只是举例说明，开发者需要根据实际情况添加所需要的权限
   NSArray *scopes = @[@"https://www.huawei.com/healthkit/step.read",@"https://www.huawei.com/healthkit/step.write"];
   //获取注册应用时获取的AppID
   NSString *appID = @"xxx";
   //开发者申请免登录授权时设置的schema信息，即授权完成后接收授权码的deeplink url
   NSString *deepLinkUrl = @"xxx";
   //根据appid和应用注册回调链接的 `scheme secret`
   NSString *signature = @"xxx";
   //随机码，和授权码一起返回
   NSString *state = @"xxx";
   //调用注册应用api方法
   [[HWAuthLoginApi sharedInstance] registerApp:appID scope:scopes redirectUri:deepLinkUrl signature:signature state:state];

   /**
   *调用授权方法
   */
   [[HWAuthLoginApi sharedInstance] authLoginAction];


   /**
   授权结果通过下列方法拿到
   */
   如果存在SceneDelegate
   - (void)scene:(UIScene *)scene openURLContexts:(NSSet<UIOpenURLContext *> *)URLContexts {
       NSEnumerator *enumerator = [URLContexts objectEnumerator];
       if (@available(iOS 13.0, *)) {
           UIOpenURLContext *context;
           while (context = [enumerator nextObject]) {
               if ([context.URL.absoluteString hasPrefix:@"test://"]) {
                   NSLog(@"---url:%@",context.URL.absoluteString);
                   //拿到url链接获取授权结果进行后续业务处理
               }
           }
       }
   }

   如果不存在SceneDelegate
   - (BOOL)application:(UIApplication *)app openURL:(NSURL *)url options:(NSDictionary<UIApplicationOpenURLOptionsKey, id> *)options {
       if([url.absoluteString hasPrefix:@"test://"]) {
           NSLog(@"---url:%@",url.absoluteString);
           //拿到url链接获取授权结果进行后续业务处理
       }
       return YES;
   }
   ```

   <br />

3. 拿到授权结果进行后续的业务处理，获取的url链接里如果能取到code，则表明授权成功；如果链接没有code，则看授权code定位原因。（授权结果码详见：[授权码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/cloud-free-auth-login-ios-errcode-0000001986191806)）。
