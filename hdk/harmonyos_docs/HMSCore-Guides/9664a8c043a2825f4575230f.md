# 接收订单/订阅关键事件通知

如果您的应用接入了华为IAP订单/订阅功能，建议您在开发者联盟[配置订单/订阅通知地址](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-agc-0000001050033072#section15820113193119)，用于接收华为应用内支付服务器发送的关键事件通知。华为应用内支付关键事件通知支持v1（只支持订阅）和v2（支持订单和订阅）两个版本，当您选择通知版本为v1时具体使用请参见[关键事件通知版本v1](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-notifications-about-subscription-events-0000001050706084)接口说明。当您选择通知版本为v2时具体使用请参见[关键事件通知版本v2](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-notifications-about-subscription-events-v2-0000001385268541)接口说明。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135213.38608829503729488268136848387062:50001231000000:2800:FB9D2161A506431D4A9D18E951E15D66F796C96D3F7C81B22DB40F42CFBEA6C1.png)  
建议所有提供一次性商品和订阅型商品的App均配置该通知地址，以便接收关键事件通知，为顾客提供更好、更及时的服务。另外，通知地址必须基于HTTPS并且配置有商业域名机构颁发的证书。  

#### 订单关键事件通知处理建议

1. 您在收到IAP服务器的订单关键事件通知（下文简称订单通知）时，建议您根据通知内容中的购买Token，请求IAP服务器校验购买Token，并根据验证结果决定您是否需要发放商品。
2. 订单通知仅作为订单状态发生变化的一个事件通知，由于网络延迟等导致您服务器收到通知事件有延迟，订单通知中携带的订单信息可能与IAP服务器的最新的订单状态不一致，建议不要根据订单通知来决定是否发放商品。
3. 您可以使用订单通知类型进行报表处理。
4. 您在收到支付成功(1)通知类型后，建议根据如下订单通知处理流程进行业务逻辑处理。

订单关键事件通知处理流程建议如下：

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135213.99198837518583243018757270816482:50001231000000:2800:2531873AE10865C1D04FB442E9BC1A8E5F090ACE234AF20CE7AA76D6B9CE0209.png)

1. IAP服务器发送订单关键事件通知。
2. 应用服务器收到通知请求后，从通知中获取购买Token。
3. 调用华为IAP服务器提供的[Order服务验证购买Token](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/order-verify-purchase-token-0000001050033078)接口，查询购买数据及签名数据。
4. IAP服务器返回购买数据及签名数据。为避免资金损失，您在验签成功后，必须校验InAppPurchaseData中的productId、price、currency等信息的一致性。验证方法和公钥获取方式可参见[验证InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/verifying-inapppurchasedata-0000001494212281)。
5. 验证结果成功，处理发货，并记录购买商品的Token。请根据[Order服务验证购买Token](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/order-verify-purchase-token-0000001050033078)接口响应中[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)的purchaseState字段决定是否发货。若purchaseState为0，则执行发货操作。
6. 调用华为IAP服务器提供的[Order服务确认购买](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/purchase-confirm-for-order-service-0000001050035031)接口确认购买（即消耗）。
7. IAP服务器返回确认购买结果。
8. 应用服务器返回通知响应给IAP服务器。  

#### 订阅关键事件通知处理建议

1. 您在收到IAP服务器的订阅关键事件通知（下文简称订阅通知）时，建议您根据通知内容中的购买Token，请求IAP服务器校验购买Token获取当前购买Token关联订阅的最新状态，并根据订阅最新状态决定您是否需要提供商品服务。
2. 订阅通知仅作为订阅状态发生变化的一个事件通知，由于网络延迟等导致您服务器收到通知事件有延迟，订阅通知中携带的订阅信息可能与IAP服务器的最新的订阅状态不一致，建议不要根据订阅通知来决定是否提供商品服务。
3. 您可以使用订阅通知类型进行报表处理。
4. 您在收到INITIAL_BUY(0)、RENEWAL(2)、INTERACTIVE_RENEWAL(3)、RENEWAL_RECURRING(7)通知类型后，建议根据如下订阅通知处理流程进行业务逻辑处理，提供商品服务。

订阅关键事件通知处理流程建议如下：

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135213.14031913891854133157662756047287:50001231000000:2800:A84101EF8F7EE2172A8FD7E94E2299CEBEBCEE8E4F1C888068DADA1D3C4766B7.png)

1. IAP服务器发送订阅关键事件通知。
2. 应用服务器收到通知请求后，从通知中获取购买Token。
3. 调用华为IAP服务器提供的[Subscription服务验证购买Token](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/subscription-verify-purchase-token-0000001050035029)接口，查询购买数据及其签名数据。
4. IAP服务器返回购买数据及其签名数据。为避免资金损失，您在验签成功后，必须校验InAppPurchaseData中的productId、price、currency等信息的一致性。验证方法和公钥获取方式可参见[验证InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/verifying-inapppurchasedata-0000001494212281)。
5. 校验订阅状态提供商品服务。请根据[Subscription服务验证购买Token](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/subscription-verify-purchase-token-0000001050035029)接口响应中[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)的subIsvalid字段决定是否发货。若subIsvalid为true，则执行发货操作。
6. 应用服务器返回通知响应给IAP服务器。
