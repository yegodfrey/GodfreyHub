# 操作流程

#### 创建版本

                1. 选择“工作区”页签，点击“创建版本”按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ba/v3/_ZN5jhRoTo2pZxEGqwpKNQ/zh-cn_image_0000001131511380.png?HW-CC-KV=V1&HW-CC-Date=20261005T043138Z&HW-CC-Expire=86400&HW-CC-Sign=462DB2D6EBDFD389E9FED9E02A5AA463D5685D9A936AB28070DAF50FDBE3A5A2)

                2. 在“创建版本”页面输入版本名称和描述后，选择“创建版本”或“创建并发布此版本”，点击“确定”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2b/v3/5R941H76Sp2qe0t_uXPf_Q/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043138Z&HW-CC-Expire=86400&HW-CC-Sign=F10FA127019C6E93C607DB24BFC1E1B61B27A92DB7A661A296875D884123E842)

若您需要在创建版本的同时，发布该版本，请选择“创建并发布此版本”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fc/v3/U4J9mjbpRZSt5TICMCpVrw/zh-cn_image_0000001177510893.png?HW-CC-KV=V1&HW-CC-Date=20261005T043138Z&HW-CC-Expire=86400&HW-CC-Sign=8FC424A70DB7E2CD859CE7BAB83661D79A1DB8E36DFB62FA13F98FC674C1C428)

                3. 若您选择“创建版本”，则系统跳转至“版本详情”页面，您可以查看已创建的版本详情。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/87/v3/U4BadOWPTEiYGYRc9nOZpQ/zh-cn_image_0000001177550797.png?HW-CC-KV=V1&HW-CC-Date=20261005T043138Z&HW-CC-Expire=86400&HW-CC-Sign=72DE986EABE15AA451DCD6D884AABFD1CDFD53939D45A1DC5740678FE9673909)

                4. 若您选择“创建并发布此版本”，则系统跳转至“版本详情”页面，且提示版本发布成功，您可以查看已创建的版本详情。

#### 预览草稿版本

在可视化埋点、代码、条件、变量或是分组中进行新建、修改或是删除操作后，您可以在“工作区”页面，点击“预览”，查看实时的配置信息，详情请参见[预览版本](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-version-management-operation-procedure-0000001091319145#section35141828537)。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/48/v3/vrV-28DNTJyLm1QLrY3JbA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043138Z&HW-CC-Expire=86400&HW-CC-Sign=0CA920530E17D6B78E2D1E88CB224001E396EA692F238773086295C3AEC10A79)

通过“工作区 > 预览”与“版本 > 版本详情 > 预览”的功能差异如下：

                * “工作区 > 预览”：您可以预览当前的草稿版本，即当前工作区内实时的配置信息。
                * “版本 > 版本详情 > 预览”：您可以预览当前创建的正式版本，预览内容仅为指定版本的配置信息。

若您的预览的网页中有跳转页面，且需要支持跳转页面的预览，请安装Chrome扩展，详情请参见[安装Chrome扩展](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/install-chrome-0000001111756056)。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/82/v3/bw8kNeW9T_2FkOLK5CAmrw/zh-cn_image_0000001177557361.png?HW-CC-KV=V1&HW-CC-Date=20261005T043138Z&HW-CC-Expire=86400&HW-CC-Sign=F1ABAD1CAD3ADB741FF81FDBA90AA94580DE13676E4EDC4BA3EB246CE0CD2AD9)

#### 变更

#### [h2]变更详情

                1. 在可视化埋点、代码、条件或变量中进行新建、修改或是删除操作后，您可以在“概览”页面中，看到变更记录。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7e/v3/UZx-yI6KQ96aUTIQUnJe0A/zh-cn_image_0000001077090008.png?HW-CC-KV=V1&HW-CC-Date=20261005T043138Z&HW-CC-Expire=86400&HW-CC-Sign=401040CF5EA2A04484943B9D67263E376A9E97875BE81731AF5CB9AE21D8EF05)

                2. 点击“变更”栏下变更类型的名称进入“查看详情”页面，查看当前状态。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/27/v3/DT7jzS55QYuV4C4XT8cgZA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043138Z&HW-CC-Expire=86400&HW-CC-Sign=D6BB1F4B00E50418EE07D355F6AFE60E73718D09399E2E5CA96E020308913087)

若“更改”类型为“删除”，则不可点击。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ad/v3/5DQPxRreSEWPyjfyV19ndw/zh-cn_image_0000001091043931.png?HW-CC-KV=V1&HW-CC-Date=20261005T043138Z&HW-CC-Expire=86400&HW-CC-Sign=F12D144A27A2127180B299B6013996DA9614A71CF7825EC89AEEACD6508358AA)

#### [h2]查看变更

通过点击“查看变更”查看历史修改记录，即当前版本与当前草稿中变量、条件或是代码的差异性对比。

                1. 在“版本”中，点击“创建版本”，设置“版本名称”和“版本描述”，点击“保存”。
                2. 在“版本”中，选择所需版本，在“版本详情”页面，点击“发布”。
                3. 对已发布版本中，存在的可视化埋点、代码、条件或变量进行修改操作，修改完毕后选择“工作区 > 概览”，在该可视化埋点、代码、条件或变量名称的右边点击“查看变更”。
                4. 进入“查看变更”页面，可以看到哪些内容进行了更改。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a8/v3/QFIOVM-rRfurZu7EpBsgFw/zh-cn_image_0000001077783404.png?HW-CC-KV=V1&HW-CC-Date=20261005T043138Z&HW-CC-Expire=86400&HW-CC-Sign=FE9DF5AFF370A35B5D9C26629D5A0661185D80B719F4333448F6A60AC1A25CB0)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5e/v3/418ZsT0gRCO7V4shkuAEZg/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043138Z&HW-CC-Expire=86400&HW-CC-Sign=37D1EE53D76FC9E40FF9C9D647252EC131659EE996ABA6B811179F00001025A2)

若“更改”类型为“新增”或“删除”的预设变量，则没有查看变更的功能。

#### 操作记录

在可视化埋点、代码、条件、变量或是分组中进行新建、修改或是删除操作，然后点击“概览”页面，滑至操作记录，可以看到具体时间的操作行为。此外，您还可以将操作记录导出为Excel文件。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bb/v3/i5SNTp7oQp2XWdMNkLN63w/zh-cn_image_0000001077462144.png?HW-CC-KV=V1&HW-CC-Date=20261005T043138Z&HW-CC-Expire=86400&HW-CC-Sign=5D253E7C7B0882BDF042271F6396E6AE5B05FD37F9AAFC266EA557D193310FCA)
