# 配置AppGallery Connect

## 注册成为开发者

在开发应用前需要在[华为开发者联盟](https://developer.huawei.com/consumer/cn)网站上注册成为开发者并完成实名认证，具体方法请参见[帐号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。

## 创建应用

参见[创建项目](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createproject-0000001100334664)和[创建应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createapp-0000001146718717)完成应用的创建。

在"添加应用"页面填写应用信息时，支持设备选项，选择"VR"或者"手机"，如下图所示：

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135210.03737236275756967261399608813780:50001231000000:2800:8725212C7855B4BBD80C1628735A411B83C931BA20788DA287CB5E6A5A162893.png "点击放大")

## 生成签名证书指纹

签名证书指纹用于校验应用的真实性，您需要根据签名证书在本地生成签名证书指纹，并在应用上架前将签名证书指纹配置到AppGallery Connect。

在生成签名证书指纹前需要满足以下两个条件：

* 已创建应用程序的签名证书，签名证书创建请参见[生成签名证书](https://developer.huawei.com/consumer/cn/codelab/HMSPreparation/index.html#2)。
* 当前PC已经安装[JDK](https://www.oracle.com/java/technologies/javase-downloads.html)。

操作步骤如下：

* Windows
  1. 执行CMD命令打开命令行工具，执行**cd** 命令进入keytool.exe所在的目录（以下样例为JDK安装在C盘的Program Files目录）。

     ```screen
     cd C:\Program Files\Java\jdk\bin
     ```

  2. 执行命令**keytool -list -v -keystore** *<keystore-file>* ，按命令行提示进行操作。*<keystore-file>* 为应用签名证书的完整路径。

     例如：

     ```screen
     keytool -list -v -keystore C:\TestApp.jks
     ```

  3. 根据结果获取对应的SHA256指纹。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135210.96394055422285829201954262540823:50001231000000:2800:7CD088B89621C453276B6BEDEF4440EC19E0B8921C8778036F8FCD711FD5BC0E.png "点击放大")

* macOS
  1. 打开Terminal终端。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135210.97165717398607978899804439299685:50001231000000:2800:0D151AC0045E2DB3E96550D986DD935A0F81F3714BF57935BA9F0E64ED6997C6.png)

  2. 执行命令**keytool -list -v -keystore** *<keystore-file>* ，按命令行提示进行操作。*<keystore-file>* 为应用签名证书的完整路径。

     例如：

     ```screen
     keytool -list -v -keystore /Users/admin/Downloads/HmsDemo.jks
     ```

  3. 根据结果获取对应的SHA256指纹。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135210.20851810116202456551871109696932:50001231000000:2800:9C9149C7FCB357BEC4C772D2CA5803F451B12FF39A62280796DA590C02FABBD1.png)

## 配置签名证书指纹

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"。
2. 在项目列表中找到您的项目，在项目中点击需要配置签名证书指纹的应用。
3. 在"项目设置 > 常规"页面的"应用"区域，点击"SHA256证书指纹"后的"添加证书指纹"，输入生成的SHA256指纹。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135210.04604672242177711531357503245560:50001231000000:2800:583DBA621E919E13606266B2474128A69BBC15E913AB712A45EAEA09D6293ADF.png)
   > 说明
   >
   > 在"项目设置"页面的"应用"区域，点击"Client Secret"后面的![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135210.66650282936813782054504547933111:50001231000000:2800:491CECD3995EADF494D01C3B0F09D399CE3A6EF8C9E13018A887100814100CD2.png)即可复制Client Secret。

4. 配置完成后，点击"保存"。

## 开通支付服务

您如果接入华为支付服务，需要在开发者联盟网站创建应用并开通支付服务，本章节指导您如何创建应用并完成支付服务的开通。

1. 以华为开发者帐号登录"[华为开发者联盟](https://developer.huawei.com/consumer/cn/)"，点击右上角"管理中心"，进入管理中心。

   选择"应用服务 > 开发服务 > 支付"，如下图所示。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135210.88144077875023977953759116054661:50001231000000:2800:F1EC3F3086C0FE4B5482AED1F9735FDCEB0AB4106415B0047A51B9B3FA88A1B2.png "点击放大")

2. 点击"支付"，进入支付管理页面，点击"申请支付服务"。如下图所示。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135210.36201326064957214634343363709763:50001231000000:2800:906A4C6EB33538D3FAE7DCDD665AA6674B772BDC2A9545091E72ADB013B289B7.png "点击放大")

3. 设置应用类型，选择"华为VR应用"。如下图所示。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135210.95412112298414192920944880157553:50001231000000:2800:D9954087D34E0DC2EB528EA0D5688ACEE5AB5D939B149CB1E9EF102E9F2A77A7.png "点击放大")

4. 完善应用信息，如下图所示。

   * 产品选择：上一章节已经创建的产品。
   * **应用包名必须和APK包名保持一致，且不可更改，请谨慎填写**。
   * 回调地址是应用开发者侧配置的服务器地址，用于在支付成功后接收华为支付服务器的回调订单信息，如果您接入的应用是没有应用服务器的单机应用，可以不配置。此内容配置后可修改。
   * SHA256证书指纹：配置应用签名获取的指纹信息（通常只要配置一个，如果该应用存在多个证书指纹，必须配置多个）。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135211.94546084066537105502022596582362:50001231000000:2800:A126FA8C18F082CFBEF2DD0D75EB4436B97C8C7A34422E2BB5677147603D8500.png "点击放大")

5. 点击"提交"后，您已经完成为这个应用申请支付服务的操作。
6. 获取支付服务参数。

   您为"示例支付服务"App开通支付服务后，开发者联盟会分配服务参数，包括APP ID和APP SECRET，用于您集成HMS Core SDK时使用。获取服务参数如下：

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135211.12252188339240866141827174177759:50001231000000:2800:11A17683E7B3D7D4F0D2BD9B6B6ADFE8DB1DF08ABFB803AE328AE121021623BA.png "点击放大")

   页面各参数含义如下表所示。

   |参数名|对应HMS Core SDK参数|说明|
   |:---------|:---------------|:---------------------------------------------|
   |APP ID|applicationID|华为开发者联盟为App分配的唯一标识。|
   |APP SECRET|应用密钥|华为开发者联盟为App分配的唯一密钥。|
   |支付ID|merchantId|华为开发者联盟为每个商户分配的唯一标识。|
   |CPID|merchantId|华为开发者联盟为每个商户分配的唯一标识。|
   |支付私钥|无|RSA私钥，用于您的App调用HMS Core SDK支付接口时，对请求参数进行签名。|
   |支付公钥|无|RSA公钥，用于您的App收到HMS Core SDK返回的支付结果时，对响应参数进行验签。|
