# 集成HMS Core SDK

在开发前，您需要将华为统一扫码SDK集成到您的Xcode开发环境中，SDK只支持iOS 9.0及以上版本。  

#### 手动导入SDK

1. 下载华为统一扫码SDK，并解压zip包。

   <br />

   下载地址：[华为统一扫码SDK下载（iOS版）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Library/ios-sdk-download-0000001059671299)（推荐手动方式集成）。

   <br />

2. 将解压的文件"ScanKitFrameWork.framework"和"ScanKitFrameWorkBundle.bundle"放入Xcode工程中。

   <br />

   ![](https://media:301775707693013562 "点击放大")

   <br />

3. 在"Choose options for adding these files"弹框的"Destination"选项里勾选"Copy items if needed"。

   <br />

   ![](https://media:301775707693087563 "点击放大")

   <br />

4. 在TARGETS里配置华为统一扫码SDK的依赖。

   <br />

   选择"Build Phases"，点击"+"，再点击"New Copy Files Phase"，在新建的"Copy Files"中增加"ScanKitFrameWork.framework"，在"Destination"中选择"Frameworks"：

   ![](https://media:301775707693136564 "点击放大")

   <br />

5. 设置"Validate WorkSpace"设置为"true"。

   <br />

   操作路径："TARGET \> Build Setting \> Build Options \> Validate WorkSpace"。

   <br />

6. 关闭"Bitcode"。选择"Build Setting"，搜索"Enable Bitcode"，设置为"NO"。

   <br />

   操作路径："TARGET \> Build Setting \> Build Options \> Enable Bitcode"。

   <br />
