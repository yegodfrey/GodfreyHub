# 集成HMS Core SDK

在开发前，您需要将华为统一扫码SDK集成到您的Xcode开发环境中，**SDK只支持iOS 9.0及以上版本**。

## 手动导入SDK

1. 下载华为统一扫码SDK，并解压zip包。

   下载地址：[华为统一扫码SDK下载（iOS版）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Library/ios-sdk-download-0000001059671299)（推荐手动方式集成）。

2. 将解压的文件"ScanKitFrameWork.framework"和"ScanKitFrameWorkBundle.bundle"放入Xcode工程中。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/49/v3/B5pZ1qWwSQy3Vx-E8gPNZg/zh-cn_image_0000001539301174.png?HW-CC-KV=V1&HW-CC-Date=20260909T144149Z&HW-CC-Expire=31536000000&HW-CC-Sign=42B013ECC2FC1DA3565907ED9165693E74001B15618681C3F479D0BC126F61A8 "点击放大")

3. 在"Choose options for adding these files"弹框的"Destination"选项里勾选"Copy items if needed"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c1/v3/zcpHTzZQSKaEBCWzZ3SFPg/zh-cn_image_0000001051065080.png?HW-CC-KV=V1&HW-CC-Date=20260909T144149Z&HW-CC-Expire=31536000000&HW-CC-Sign=AC5D5F14A6395628756050ABEBF6F3665CB6D6A224439C4CD1C5D65200B7CE9F "点击放大")

4. 在TARGETS里配置华为统一扫码SDK的依赖。

   选择"Build Phases"，点击"+"，再点击"New Copy Files Phase"，在新建的"Copy Files"中增加"ScanKitFrameWork.framework"，在"Destination"中选择"Frameworks"：

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/de/v3/yQpYEq6QSS2ioZRfnb3SuA/zh-cn_image_0000001589581197.png?HW-CC-KV=V1&HW-CC-Date=20260909T144149Z&HW-CC-Expire=31536000000&HW-CC-Sign=3D097C785C8FF714FFA390396CE383DA707B8195E33B81E650DCD0A4FDC0D43F "点击放大")

5. 设置"Validate WorkSpace"设置为"true"。

   操作路径："TARGET > Build Setting > Build Options > Validate WorkSpace"。

6. 关闭"Bitcode"。选择"Build Setting"，搜索"Enable Bitcode"，设置为"NO"。

   操作路径："TARGET > Build Setting > Build Options > Enable Bitcode"。
