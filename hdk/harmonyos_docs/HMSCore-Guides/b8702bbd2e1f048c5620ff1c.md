# 版本更新说明

#### 1.0.0.2（2022-04-01）

|-------------------------------------------------------------------------------------------------------------|
|新增特性 首次发布，提供WebUI自适应重排能力。欢迎广大开发者接入。 当前支持重排的布局类型有：单行元素（包含轮播图等特殊类型）、列表元素（包含瀑布流、侧边栏、宫格列表等特殊列表）、大图元素、大弹窗、大字体、通知栏。|
