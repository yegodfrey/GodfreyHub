# 导入证书指纹、修改包名、配置JDK编译版本

## 导入Keystore文件

将[创建应用的Keystore文件](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/application-certificate-guide-0000001530080540#section1222773391512)生成的Keystore文件导入到应用中。

1. 在菜单栏，单击"File > Project Structure..."

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/49/v3/opkimTN4Q_SBJQUHQ6HCQw/zh-cn_image_0000002516519334.png?HW-CC-KV=V1&HW-CC-Date=20261008T190701Z&HW-CC-Expire=31536000000&HW-CC-Sign=E88AD62C1BE3BA44D81F17A4ACDACF33C115B0982E0A1FAB34D74EB6289C4856)

2. 在左侧列表单击"Modules"，选择"Signing Configs"，单击"Store File"栏的![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1b/v3/ufTBOCrkRxSe4_IW6daaaQ/zh-cn_image_0000002516359418.png?HW-CC-KV=V1&HW-CC-Date=20261008T190701Z&HW-CC-Expire=31536000000&HW-CC-Sign=CC3F8FB7892351C68FB886D4BFBA315999838016270D165EA5AC83D00E6D069B)，选择D盘中的key.keystore文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3b/v3/90uRdpxmQy2rcQBCYCgxsg/zh-cn_image_0000002547959223.png?HW-CC-KV=V1&HW-CC-Date=20261008T190701Z&HW-CC-Expire=31536000000&HW-CC-Sign=90B5F6C1B333F45137C85CFA1AC6318E6D29A21964D5C8F0DBF3F960A2AD56A7 "点击放大")

3. 输入此前创建签名时设置的密码和别名，单击"OK"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ea/v3/Hhh04eMFQQWbLnHL8DKOzQ/zh-cn_image_0000002548039221.png?HW-CC-KV=V1&HW-CC-Date=20261008T190701Z&HW-CC-Expire=31536000000&HW-CC-Sign=7D2D6942D09DAC33E300453CC820244ED4AE7EF1F96D22043A00DFC3B9912076 "点击放大")

   导入后，打开应用级的"build.gradle"文件，可以看到导入的结果。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/63/v3/mdlID_bISIyfwldSzNKPtA/zh-cn_image_0000002516359420.png?HW-CC-KV=V1&HW-CC-Date=20261008T190701Z&HW-CC-Expire=31536000000&HW-CC-Sign=79433F3B61791E21DE9BB1A971DBD89608209F173B95DDBCF2AF12D4671F87D9 "点击放大")

## 修改应用包名

如果您的应用包名与"[申请账号服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/apply-id-0000001050069756)"中填写的包名不一致，请参见"[修改应用包名](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/application-package-name-0000001580840241#section18355123714179)"修改为一致。

## 配置JDK编译版本

1. 打开App下应用级根目录的"build.gradle"文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ec/v3/WJZKNMSoQaiDCI_PYOkeLg/zh-cn_image_0000002548039219.png?HW-CC-KV=V1&HW-CC-Date=20261008T190701Z&HW-CC-Expire=31536000000&HW-CC-Sign=999BDD15BED8BAE19C8932830DFDF7D9F732A2A25E1BDDB58192315965F3CA84 "点击放大")

2. 在**"** android**"**中新增compileOptions配置，配置格式如下：

   ```screen
   compileOptions {
       sourceCompatibility = '1.8'
       targetCompatibility = '1.8'
   }
   ```

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7f/v3/BI5J52Z4TE2x2IROVMYzHQ/zh-cn_image_0000002547959225.png?HW-CC-KV=V1&HW-CC-Date=20261008T190701Z&HW-CC-Expire=31536000000&HW-CC-Sign=847A3028EAF56B9387AEB66E8D593BD831B42F8CD76BE2DD1EC9B00158DAB5F8)
