# 导入证书指纹、修改包名、配置JDK编译版本

## 导入Keystore文件

将[创建应用的Keystore文件](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/application-certificate-guide-0000001530080540#section1222773391512)生成的Keystore文件导入到应用中。

1. 在菜单栏，单击"File > Project Structure..."

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/49/v3/opkimTN4Q_SBJQUHQ6HCQw/zh-cn_image_0000002516519334.png?HW-CC-KV=V1&HW-CC-Date=20260909T180442Z&HW-CC-Expire=31536000000&HW-CC-Sign=408FC2069C61DF55B1E96F9A86FA97A9565FD3BADE416B7C200E39CCBFB6CF83)

2. 在左侧列表单击"Modules"，选择"Signing Configs"，单击"Store File"栏的![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1b/v3/ufTBOCrkRxSe4_IW6daaaQ/zh-cn_image_0000002516359418.png?HW-CC-KV=V1&HW-CC-Date=20260909T180442Z&HW-CC-Expire=31536000000&HW-CC-Sign=19CB96FF77BAA4D098D595ECA2A46E206C01070FBADA8EA14941F262A21B7ED7)，选择D盘中的key.keystore文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3b/v3/90uRdpxmQy2rcQBCYCgxsg/zh-cn_image_0000002547959223.png?HW-CC-KV=V1&HW-CC-Date=20260909T180442Z&HW-CC-Expire=31536000000&HW-CC-Sign=E6BEAA8FD20AC378C59E4365F4B14B9C51715F60F60B6BB779BA23F4466251E7 "点击放大")

3. 输入此前创建签名时设置的密码和别名，单击"OK"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ea/v3/Hhh04eMFQQWbLnHL8DKOzQ/zh-cn_image_0000002548039221.png?HW-CC-KV=V1&HW-CC-Date=20260909T180442Z&HW-CC-Expire=31536000000&HW-CC-Sign=0227E7B3ACA820938E55698B4ED918E80CB5A8A6BDFFD7F336BF90516FD89EAC "点击放大")

   导入后，打开应用级的"build.gradle"文件，可以看到导入的结果。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/63/v3/mdlID_bISIyfwldSzNKPtA/zh-cn_image_0000002516359420.png?HW-CC-KV=V1&HW-CC-Date=20260909T180442Z&HW-CC-Expire=31536000000&HW-CC-Sign=D7121F570A91589C23CB799A311600E4C17792402ED5FCD882E172829546FEB7 "点击放大")

## 修改应用包名

如果您的应用包名与"[申请账号服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/apply-id-0000001050069756)"中填写的包名不一致，请参见"[修改应用包名](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/application-package-name-0000001580840241#section18355123714179)"修改为一致。

## 配置JDK编译版本

1. 打开App下应用级根目录的"build.gradle"文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ec/v3/WJZKNMSoQaiDCI_PYOkeLg/zh-cn_image_0000002548039219.png?HW-CC-KV=V1&HW-CC-Date=20260909T180442Z&HW-CC-Expire=31536000000&HW-CC-Sign=05180EC6A17C56F6C36C1FDD24BE020B70173226669FBBF5678298F089F6624A "点击放大")

2. 在**"** android**"**中新增compileOptions配置，配置格式如下：

   ```screen
   compileOptions {
       sourceCompatibility = '1.8'
       targetCompatibility = '1.8'
   }
   ```

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7f/v3/BI5J52Z4TE2x2IROVMYzHQ/zh-cn_image_0000002547959225.png?HW-CC-KV=V1&HW-CC-Date=20260909T180442Z&HW-CC-Expire=31536000000&HW-CC-Sign=FFCED72FA5A3E433940B76A0FD8C99D16D16E860750E5374465CBCA4EC103F94)
