# 广播包 Service Data AD Type

|**字段**|**类型**|**大小**|**说明**|
|:---------------------------|:------|:---------|:------------------------------------------|
|Service Data AD Type|Uint8|1|-|
|Fitness Machine Service UUID|Uint16|2|-|
|Flags|Bit0|-|Fitness Machine Available: 0: False 1: True|
|Flags|Bit1-7|-|保留|

|Fitness Machine Type|Bit2|根据产品实际能力填写|Step Climber Supported|
|Fitness Machine Type|Bit3|根据产品实际能力填写|Stair Climber Supported|
|Fitness Machine Type|Bit4|根据产品实际能力填写|Rower Supported|
|Fitness Machine Type|Bit5|根据产品实际能力填写|Indoor Bike Supported|
|Fitness Machine Type|Bit6-15|根据产品实际能力填写|保留|
