# 获取用户授权

应用拉起华为账号登录和授权界面，由用户授权相应的数据访问权限。用户可以自主选择授权的数据类型，可以只授权部分数据权限。应用所能操作的用户数据，是用户授权和Health Service Kit服务审批通过的数据权限的交集。  

#### 开发步骤

1. 声明已申请的Scope权限，参考[申请Health Service Kit服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-apply-kitservice-0000001194699502)中的需要申请的权限。
2. 调用HuaweiIdAuthParamsHelper对象提供的方法构造账号登录参数。
3. 调用[HuaweiIdAuthManager.getAuthApi().getSignInIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-huaweiidauth-0000001063960185#section169782218282)方法拉起华为账号登录授权页面，处理登录结果。

   <br />

   ```
   import {HuaweiIdAuthParamsHelper, HuaweiIdAuthManager} from '@hmscore/hms-jsb-account'
   import {HMSHealthKitScope} from '@hw-hmscore/hms-js-health'
   // 步骤1：声明需要申请的Scope权限
   let scopeList = [
       // 查看HUAWEI Health Service Kit中的步数
       {
           mScopeUri: HMSHealthKitScope.HEALTHKIT_STEP_READ,
       },
       // 查看HUAWEI Health Service Kit中的心率数据
       {
           mScopeUri: HMSHealthKitScope.HEALTHKIT_HEARTRATE_READ,
       }];
   // 步骤2：构造登录参数
   var signInOption = new HuaweiIdAuthParamsHelper().setId().setProfile().setScopeList(scopeList).build();
   // 步骤3：拉起授权页面及处理登录结果
   // HuaweiIdAuthManager.getAuthApi方法返回huaweiIdAuth对象，调用huaweiIdAuth.getSignInIntent方法，拉起登录授权界面
   HuaweiIdAuthManager.getAuthApi().getSignInIntent(signInOption).then((result) => {
       // 登录成功，获取用户的华为账号信息
       console.info("signIn success");
       console.info(JSON.stringify(result));
   }).catch((error) => {
       // 登录失败
       console.error("signIn fail");
       console.error(JSON.stringify(error));
   });
   ```

   <br />

4. 调用[checkHealthAppAuthorization](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-manage-authorisation-0000001206472504#section102198342110)接口，在弹出的界面，引导用户开启运动健康App对Health Service Kit的关联服务。

   <br />

   ![](https://media:901788166619175514)  
   * 若开发手表应用，请忽略此步骤。如果需要获取智能表数据，请在步骤3，申请HMSHealthKitScope.HEALTHKIT_HUAWEIHEALTH_LINK权限，支持的数据开放范围请参见[智能表数据获取](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/obtain-smart-watch-data-0000001365189921)。
   * 若开发手机应用，且应用不需要访问华为运动健康App的数据，请忽略此步骤。
   * 开发者可以调用以下接口，引导用户开启运动健康App对Health Service Kit的关联服务。也可以引导用户打开"华为运动健康 \> 我的 \> 隐私管理 \> 华为运动健康服务"开关，提示用户在运动健康App上打开隐私开关。  

   ```
   import {HMSHealthKit} from '@hw-hmscore/hms-js-health'
   // 调用checkHealthAppAuthorization接口引导用户开启运动健康App对Health Service Kit的关联服务
   HMSHealthKit.checkHealthAppAuthorization().then((result) => {
       // 调用成功
       console.info("checkHealthAppAuthorization success: " + JSON.stringify(result))
   }).catch((error) => {
       // 调用失败
       console.error("checkHealthAppAuthorization Error: " + JSON.stringify(error));
   });
   ```
