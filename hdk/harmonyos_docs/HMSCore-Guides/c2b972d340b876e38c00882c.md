# 商户微信小程序唤起花瓣支付微信小程序

#### 接入流程

![](https://media:801773305070055588 "点击放大")

1. 商户小程序请求商户服务器创建订单。
2. 商户服务器调用华为支付服务提供的[直连商户H5预下单](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-h5-pre-pay-order-0000001538376420)接口获取预下单号（prepayId）组装[extraData](#section69241417182710)返回给商户小程序。
3. 商户小程序使用extraData通过微信小程序提供的[wx.navigateToMiniProgram(Object object)](#section7761553175914)接口唤起花瓣支付小程序。
4. 花瓣支付小程序拉起华为支付收银台，用户完成支付。
5. 花瓣支付小程序展示支付结果页，用户关闭支付结果页，返回商户小程序。
6. 支付成功后，华为支付服务器会调用回调接口返回支付结果信息给商户服务器。支付失败场景可能不会有支付结果回调通知。
7. 商户服务器收到支付结果回调响应后，使用SM2验签方式对支付结果进行验签，参见[验签规则](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-signature-rule-0000001538533912#section395172634813)。  

#### 接口说明

接口：wx.navigateToMiniProgram(Object object)

描述：详细说明[参见这里](https://developers.weixin.qq.com/miniprogram/dev/api/navigate/wx.navigateToMiniProgram.html)

接口参数Object需传递字段如下：  

|字段|值|说明|
|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------|
|appId|wx5f6d733a6719afa8|讯联支付主体的微信小程序appId。|
|path|``` pages/pay/launch ```|小程序打开的页面路径，如果为空则打开首页。|
|extraData|``` {"orderstr":"{\"app_id\":\"***\",\"merc_no\":\"***\",\"prepay_id\":\"xxx\",\"timestamp\":\"1680259863114\",\"noncestr\":\"1487b8a60ed9f9ecc0ba759fbec23f4f\",\"sign\":\"****\",\"auth_id\":\"***\"}"} ```|需要传递给目标小程序的数据。|
|envVersion|release或trial|要打开的小程序版本。仅在当前小程序为开发版或体验版时此参数有效。如果当前小程序是正式版，则打开的小程序必定是正式版。 * develop：开发版 * trial：体验版 * release：正式版|

#### extraData

orderstr内容相关字段说明如下：  

|参数|参数类型|是否必填|描述|
|:--------|:-----|:---|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
|app_id|String|否|应用ID。获取方式请参见[AppID管理及关联](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-appidguanli-0000001757041165)。|
|merc_no|String|是|商户号。获取商户号请参见[查询商户号信息](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-shanghuhao-0000001725982508)。|
|prepay_id|String|是|预下单ID，使用预下单请求生成，有效期10分钟。|
|timestamp|String|是|当前时间戳，标准北京时间，时区为东八区，自1970年1月1日 0点0分0秒以来的毫秒数，13位。示例值：1666230721315。|
|noncestr|String|是|随机字符串，不长于32位。推荐随机数生成算法。 每笔订单都需要重新生成。|
|sign|String|是|签名，使用除了sign字段以外的其他字段计算签名值。可参考[签名规则](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-signature-rule-0000001538533912#section272163402611)。|
|auth_id|String|是|开放平台分配的鉴权id，一个商户可配置多套证书，请妥善保管。获取authId参见[证书准备](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/certificate-preparation-0000001596094962)。|
