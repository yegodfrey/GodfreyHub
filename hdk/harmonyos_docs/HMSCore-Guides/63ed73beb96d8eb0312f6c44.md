# 创建地图实例

#### 地图容器

目前地图SDK支持的地图容器为[MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-mapview-0000001101552562)：

[MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-mapview-0000001101552562)是HarmonyOS TextureComponentEx类的子类，允许您将地图放置在HarmonyOS视图中。通过[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-huaweimap-0000001101312582)对象展示核心地图功能。在常规地图交互模式下调用API时，[MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-mapview-0000001101552562)类的使用者必须在对应的MapViewDemo的方法中调用以下方法：onStart()、onActive()、onInactive()、onBackground()、onForeground()和onStop()，具体参见[MapViewDemo.java](https://github.com/HMS-Core/hms-mapkit-demo/blob/master/harmonyos/entry/src/main/java/com/huawei/harmony/hms/maps/demo/slice/MapViewDemo.java)。

下面以[MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-mapview-0000001101552562)为例简单介绍创建Map实例的步骤。

1. 在MapViewDemo的onStart(Intent intent)方法中加载[MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-mapview-0000001101552562)，并调用[getMapAsync](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-mapview-0000001101552562#section18155143712405)()来注册回调。在onMapReady回调中获取[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-huaweimap-0000001101312582)对象。创建[MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-mapview-0000001101552562)对象前，先调用"CommonContext.setContext(this);"保存Ability，以便初始化地图功能。

   <br />

   ```
   // 声明MapView
   private MapView mMapView;

   @Override
   public void onStart(Intent intent) {
       super.onStart(intent);
       CommonContext.setContext(this);

       // 初始化MapView
       mMapView = new MapView(this);

       // 创建MapView
       mMapView.onCreate();

       // 获取HuaweiMap对象
       mMapView.getMapAsync(new OnMapReadyCallback() {
           @Override
           public void onMapReady(HuaweiMap huaweiMap) {
               HuaweiMap mHuaweiMap = huaweiMap;
               mHuaweiMap.setOnMapClickListener(new  OnMapClickListener() {
                   @Override
                   public void onMapClick(LatLng latLng) {
                       new ToastDialog(CommonContext.getContext()).setText("onMapClick ").show();
                   }
               });
           }
       });

       // 创建Layout
       ComponentContainer.LayoutConfig config = new ComponentContainer.LayoutConfig(ComponentContainer.LayoutConfig.MATCH_PARENT, ComponentContainer.LayoutConfig.MATCH_PARENT);
       PositionLayout myLayout = new PositionLayout(this);
       myLayout.setLayoutConfig(config);
       ShapeElement element = new ShapeElement();
       element.setShape(ShapeElement.RECTANGLE);
       element.setRgbColor(new RgbColor(255, 255, 255));

       // 加载MapView
       myLayout.addComponent(mMapView);
       super.setUIContent(myLayout);
   }
   ```

   <br />

2. 在MapViewDemo的onStart()、onActive()、onInactive()、onBackground()、onForeground()和onStop()方法中调用[MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-mapview-0000001101552562)对应的方法。

   <br />

   ```
   @Override
   protected void onActive() {
       super.onActive();
       if (mMapView != null) {
           mMapView.onResume();
       }
   }

   @Override
   protected void onInactive() {
       super.onInactive();
       if (mMapView != null) {
           mMapView.onPause();
       }
   }

   @Override
   protected void onBackground() {
       super.onBackground();
       if (mMapView != null) {
           mMapView.onStop();
       }
   }

   @Override
   protected void onForeground(Intent intent) {
       super.onForeground(intent);
       if (mMapView != null) {
           mMapView.onStart();
       }
   }

   @Override
   protected void onStop() {
       super.onStop();
       if (mMapView != null) {
           mMapView.onDestroy();
       }
   }
   ```

   <br />
