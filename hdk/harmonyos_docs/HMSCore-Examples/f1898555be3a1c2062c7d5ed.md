# 快游戏示例代码

在这个Demo中，您将使用已经创建好的Demo工程实现对分析服务开放能力的API调用，通过Demo您可以体验到：

* 如何高效的集成HUAWEI Analytics Kit。
* 如何正确使用HUAWEI Analytics Kit的各个接口。

您需要完成以下操作后才可以运行示例代码：

1. 下载Codelab的[demo](https://github.com/HMS-Core/hms-analytics-demo-quickgame)工程，获取"Analytics.js"文件，并将其放入"assets/Script"目录。注意请勿将"Analytics.js"文件设置为"导入为插件"。
2. 在所有场景文件的根对象（通常为Canvas对象）上绑定Analytics脚本。
3. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"我的项目"，在项目中找到需要集成SDK的应用，然后切换到"项目设置"页面，下载"agconnect-services.json"文件。将文件内容赋值给"Analytics.js"文件中的变量aGConnectServicesConfig，完成SDK的初始化。
4. 启动示例工程：

   1. 将手机连接到电脑，并确保手机处于调试模式。
   2. 点击工具栏中的"项目 \> 构建发布... "按钮，打开"构建发布..."弹窗界面。
   3. 若您发布Runtime快游戏，请做如下操作：
      1. 在"发布平台"选择"华为快游戏"，点击"构建"按钮，待构建完成后，点击"运行"按钮，打开"快游戏调试工具"弹窗界面。
      2. 在"快游戏调试工具"弹窗界面点击代表运行的▶按钮，运行工程。
   4. 若您发布H5快游戏，请做如下操作：
      1. 在"发布平台"选择"Web Mobile"，点击"构建"按钮，待构建完成后，点击"运行"按钮，启动H5页面。
      2. 启动成功后，使用快应用IDE打开H5快游戏项目，运行工程。
      3. 运行时提示ssl error，请参考[使用SSL证书注意事项](https://developer.huawei.com/consumer/cn/doc/development/quickApp-Guides/quickgame-faq-0000001112830270#section17687135516406)进行排查。
   5. 启动成功后，在手机界面上会看到答题功能的Demo。
