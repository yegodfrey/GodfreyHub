# Android

#### 场景介绍

在Android Studio开发环境使用华为应用布局优化完成UI界面开发。  

#### 使用方式

对于使用华为响应式控件的开发者可以使用以下方式引用自适应控件（以HwRspRecyclerview为例）：

在build.gradle文件的dependencies中添加依赖：

```
implementation 'com.huawei.ui.rspuikit:hwrsprecyclerview-androidsupx:1.0.0.8'
```

#### 使用HwRspRecyclerView示例

* 直接编辑xml文件创建。

  ```
   <com.huawei.rspuikit.androidsupx.hwrsprecyclerview.wiget.HwRspRecyclerView
          android:background="@color/white"
          android:layout_width="match_parent"
          android:layout_height="match_parent"
          android:paddingStart="5dp"
          android:paddingEnd="5dp"
          android:id="@+id/myRecyclerView"
          app:expandStateSpanCount="3"
          app:expandStateEnableRsp="true"
          />
  ```

* 动态创建HwRspRecyclerView。
  1. 需要手动导入控件包。

     ```
     import com.huawei.rspuikit.androidsupx.hwrsprecyclerview.wiget.HwRspRecyclerView;
     ```

  2. 在build.gradle文件的dependencies中添加依赖：

     ```
     dependencies {
         implementation 'com.huawei.ui.rspuikit:hwrsprecyclerview-androidsupx:1.0.0.8'
     }
     ```

  3. 代码中创建HwRspRecyclerview，根据实际需要修改相关参数。

     ```
     @Override
     protected void onCreate(@Nullable Bundle savedInstanceState) {
          super.onCreate(savedInstanceState);
          setContentView(R.layout.recycler_view);
          HwRspRecyclerView myRecyclerView = findViewById(R.id.myRecyclerView);
          // 设置首行top值
          myRecyclerView.setFirstRowTop(10);
          // 设置item的bottom值
          myRecyclerView.setItemBottom(20);
          // 设置item间距类型
          myRecyclerView.setExpandStateGapType(1);
          // 设置扩展态间距
          myRecyclerView.setExpandStateItemGap(80);
          // 设置响应式控件生效
          myRecyclerView.setRspEnable(true);
          // 设置扩展态列数
          myRecyclerView.setExpandStateSpanCount(3);
          StaggeredGridLayoutManager layoutManager = new StaggeredGridLayoutManager(2, 
              StaggeredGridLayoutManager.VERTICAL);
          myRecyclerView.setLayoutManager(layoutManager);
      }
     ```
