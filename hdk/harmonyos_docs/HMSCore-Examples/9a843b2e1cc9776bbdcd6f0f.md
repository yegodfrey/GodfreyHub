# Web示例代码

在这个Demo中，您将使用已经创建好的Demo工程实现对分析服务开放能力的API调用，通过Demo您可以体验到：

* 如何高效的集成HUAWEI Analytics Kit。
* 如何正确使用HUAWEI Analytics Kit的各个接口。

|名称|Gitee|GitHub|
|:------|:-------------------------------------------------------------|:--------------------------------------------------------------|
|Web示例代码|[链接](https://gitee.com/hms-core/hms-analytics-demo-javascript)|[链接](https://github.com/HMS-Core/hms-analytics-demo-javascript)|

> 说明
>
> 您需要完成以下操作后才可以运行示例代码：
>
> 1. 打开IDE终端，进入hmsanalyticskitdemo，运行命令"npm config set registry https://registry.npmjs.org"设置npm仓库地址。
> 2. 运行npm install安装相应的依赖。
> 3. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，拷贝您的Web应用的配置项，替换示例工程hmsanalyticskitdemo/src目录下的"main.js"文件中的"agConnectConfig"的配置。
