# 客户端示例代码

## Android Studio示例代码

该Android Studio工程包含了Java和Kotlin语言的示例代码，提供了华为帐号登录（Authorization Code和ID Token两种登录模式）和退出的功能。

|名称|**Gitee**|GitHub|
|:---------|:-------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------|
|Java示例代码|[链接](https://gitee.com/hms-core/huawei-account-demo/tree/master/Account-Client-Java-Demo/Account_Demo_AndroidStudio)|[链接](https://github.com/HMS-Core/huawei-account-demo/tree/master/Account-Client-Java-Demo/Account_Demo_AndroidStudio)|
|Kotlin示例代码|[链接](https://gitee.com/hms-core/huawei-account-demo/tree/master/Account-Client-Kotlin-Demo)|[链接](https://github.com/HMS-Core/huawei-account-demo/tree/master/Account-Client-Kotlin-Demo)|

> 说明
>
> 在使用示例代码前请详细阅读示例工程中的"README"文件。您需要完成以下操作后才可以运行示例代码。
>
> 1. 在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站下载自己应用的"agconnect-services.json"文件，拷贝到示例工程的应用级根目录下。
>
> 2. 修改示例工程中应用级"build.gradle"文件中的"applicationId"为您自己的应用包名。

> 说明
>
> 在使用示例代码前请详细阅读示例工程中的"README"文件。您需要完成以下操作后才可以运行示例代码。
>
> 1. 在AppGallery Connect网站下载自己应用的"agconnect-services.json"文件，拷贝到示例工程的entry模块根目录下。
> 2. 修改示例工程中entry模块的"config.json"文件中的"bundleName"为您自己的应用包名。
> 3. 修改示例工程中entry模块的"config.json"文件中"metaData"属性值value为您自己应用的"OAuth 2.0客户端ID（凭据）：Client ID"。
> 4. 参见[配置应用签名信息](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-Guides/harmony-signature-info-0000001167185654)，配置您自己的应用签名。
