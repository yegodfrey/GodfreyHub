# 客户端示例代码

#### Android Studio示例代码

推送服务提供了Java和Kotlin两种语言的示例代码，您可以使用已经创建好的Demo工程实现对推送服务开放能力的API调用，通过Demo您可以体验到：

* 申请AAID，删除AAID
* 申请Token，删除Token
* 主题订阅与退订
* 设置是否显示通知栏消息
* 接收Push Kit服务端推送的通知消息或者透传消息
* 点击通知消息打开应用首页与应用自定义页面

|Android Studio示例代码（包含Java和Kotlin语言）|[链接](https://gitee.com/hms-core/hms-push-clientdemo-android)|[链接](https://github.com/HMS-Core/hms-push-clientdemo-android)|

在使用示例代码前请详细阅读示例工程中的"README"文件。您需要完成以下操作后才可以运行示例代码。

1. 在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站下载自己应用的"agconnect-services.json"文件，拷贝到示例工程的应用级根目录下。

2. 修改示例工程中应用级"build.gradle"文件中的"applicationId"为您自己的应用包名。
