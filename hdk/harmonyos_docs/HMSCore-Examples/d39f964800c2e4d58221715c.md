# iOS示例代码

在这个Demo中，您将使用已经创建好的Demo工程实现对分析服务开放能力的API调用，通过Demo您可以体验到：

* 如何使用Xcode高效的集成HUAWEI Analytics Kit。
* 如何正确使用HUAWEI Analytics Kit的各个接口。

|名称|Gitee|GitHub|
|:------|:------------------------------------------------------|:-------------------------------------------------------|
|iOS示例代码|[链接](https://gitee.com/hms-core/hms-analytics-demo-ios)|[链接](https://github.com/HMS-Core/hms-analytics-demo-ios)|

> 说明
>
> 您需要完成以下操作后才可以运行示例代码。
>
> 1. 打开命令终端并执行：
>    * cd~工程路径
>    * pod install
> 2. 在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站下载自己应用的"agconnect-services.plist"文件，拷贝到示例工程的应用级根目录下。修改bundle id为您自己的应用的bundle id。
