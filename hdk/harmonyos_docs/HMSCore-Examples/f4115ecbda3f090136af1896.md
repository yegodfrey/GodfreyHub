# Android示例代码

在这个Demo中，您将使用已经创建好的Demo工程实现对分析服务开放能力的API调用，通过Demo您可以体验到：

* 如何使用Android Studio高效的集成HUAWEI Analytics Kit。
* 如何正确使用HUAWEI Analytics Kit的各个接口。

|名称|Gitee|GitHub|
|:-----------------|:----------------------------------------------------------|:-----------------------------------------------------------|
|Android Studio示例代码|[链接](https://gitee.com/hms-core/hms-analytics-demo-android)|[链接](https://github.com/HMS-Core/hms-analytics-demo-android)|

> 说明
>
> 在使用示例代码前请详细阅读示例工程中的"README"文件。您需要完成以下操作后才可以运行示例代码。
>
> 1. 在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站下载自己应用的"agconnect-services.json"文件，拷贝到示例工程的应用级根目录下。
>
> 2. 修改示例工程中应用级"build.gradle"文件中的"applicationId"为您自己的应用包名。
