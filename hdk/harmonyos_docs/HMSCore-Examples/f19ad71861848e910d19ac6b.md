# 基础能力服务示例代码

HUAWEI Health Kit 在 Android 客户端提供了几个关键 API 接口的使用示例，实现对运动、健康数据的管理。

* 运动健康数据的增删改查：[DataController](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/datacontroller-0000001050089472)。
* 创建与管理单次运动或者活动：[ActivityRecordsController](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/activityrecordscontroller-0000001050091295)。
* 创建与管理健康记录：[HealthRecordController](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/healthrecordcontroller-0000001165268361)。
* 运动健康数据实时读取：[AutoRecorderController](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/autorecordercontroller-0000001050091345)。
