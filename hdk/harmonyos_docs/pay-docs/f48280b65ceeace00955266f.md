对账单/结算单下载说明  
    1. 调用对账单/结算单查询接口会返回对账单/结算单文件下载信息，下载信息里面有文件下载地址和下载鉴权信息以及HTTP请求方式，发起下载文件请求时下载鉴权信息要放到请求header里面，按返回的HTTP请求方式发起请求，一般都是GET请求。
    2. 调用对账单/结算单查询接口时，如果华为支付没有生成对账单/结算单文件，接口不返回文件下载信息，nspResponse为空。
    3. 对账单/结算单下载文件为zip格式，压缩包里面只有一个csv文件，文件名随机生成，里面内容为对账单/结算单的csv格式文本。
