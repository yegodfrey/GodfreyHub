华为支付平台证书 在您商户入网完成后，可以在：“**商户中心** ”->“**证书管理** ”->“**讯联证书** ”处获取。该证书作为华为支付平台公钥，全平台唯一，用于客户端开发时华为支付服务器返回响应验证签名。文件下载后请打开并选择其中**“****\-----BEGIN CERTIFICATE-----****”和“-----END CERTIFICATE-----****”** 之间的内容作为华为支付平台公钥串。编码时请使用如下格式值作为验签时公钥：
    
    04ACC49011986A99248837EAFB75059EED47F7DB7E08AAE57932A0DA75D28BD4211B23805F3202801281A7233AA4A0ABC129DD445C76AF3731104956F75E62D785
