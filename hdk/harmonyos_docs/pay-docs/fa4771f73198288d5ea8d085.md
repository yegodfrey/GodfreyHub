# 冻结交易查询及下载

## 1.冻结解冻交易查询

您可以在登录华为支付商户平台后，进入【交易中心】->【交易管理】->【冻结交易】页面，根据冻结解冻时间、订单号查询冻结解冻交易明细。

## 2.冻结解冻交易下载

您可以在登录华为支付商户平台后，进入【交易中心】->【交易管理】->【冻结交易】页面，根据冻结解冻时间、冻结状态、订单号查询后下载，前往下载中心将冻结解冻交易明细下载至本地。
