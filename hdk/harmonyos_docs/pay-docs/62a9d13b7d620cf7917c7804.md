# 经营异常名录申请解除

若商户号下存在"经营异常名录"待风险处理通知，您可以登录华为支付商户平台后，按照消息通知提示于"国家信用系统"申请移除"经营异常名录"；

若您已移除该"经营异常名录"请进入【账户中心】->【合规管理】->【风险处理】点击申请解除，系统将自动解除限制

若风险原因已解除，将不在该列表展示。
