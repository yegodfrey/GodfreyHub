# 打款失败，如何处理

若您的入网申请审核通过，但打款失败，在进行账户验证时，会弹出"打款失败，请重新发起打款认证"提示，建议您先按以下步骤自行核实：

**步骤1：检查结算账户信息**

点击 【修改资料】 ，仔细核对结算账户类型与银行账号是否匹配，银行名称与卡号是否匹配。如有误，更新信息后重新提交，系统将再次尝试打款。

**步骤2：联系银行确认**

若您的结算账户信息确认无误，建议联系银行核实以下情况：

* 个人信息是否完整准确（姓名、卡号、身份证号、预留手机号）；
* 是否未预留手机号或身份证已过期未更新；
* 结算卡状态是否正常（如是否被冻结、注销等）。

**步骤3：考虑更换结算账户**

若多次尝试后仍打款失败，为提高入网效率，建议更换其他银行账户作为结算账户。
