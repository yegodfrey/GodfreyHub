签名 华为支付与商户系统通过验证签名来保证请求的真实性和数据的完整性。 **商户向华为支付服务器** 发送的所有请求，必须使用商户生成的私钥签名，未携带签名或者签名验证不通过的请求都不会被执行。建议您在集成时在下图中红色字体对应的**步骤：****3****、15****、21** 按要求完成必要字段的签名。 **商户收到的华为支付服务器** 返回的结果，请务必使用华为支付平台证书公钥签名。建议您在集成时在图中蓝色字体对应的**步骤：****10****、12****、25** 按要求完成返回结果的验签。

    1. 使用场景
**步骤3** ：商户服务器生成签名后的订单参数。 **步骤15** ：商户服务器构建签名后的查询订单状态请求参数。 **步骤21** ：商户服务器构建签名后的退款请求参数。 2\. 自行完成订单签名 如您想要尝试自行完成签名过程，请参考如下步骤；您也可以跳过本小节，[服务端-demo](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220630093007.01536537477595980963343845462729:50530629031039:2800:733E1CB8F4DC6872DB7D9B3ED6687DC4860A5FAEF290F2BAEB829AA309863C57.zip?needInitFileName=true)中签名实现。
    * a). 构造完整的商户订单信息MercOrderApply其中mercOrderApply.sign字段为签名数据，签名完成后进行赋值。 mercOrderApply. signType为签名算法类型，用于华为支付服务对商户参数的验签，需开发者配置，当前请统一使用” SHA256WithRSA/PSS”。商户应保证参与签名的bodySign订单信息字段mercOrderApply与请求body中的严格一致，避免类似header加签时有去空格操作，而请求body参数中的mercOrderApply没有去空格导致验签失败的情况。
    * b). 排序与拼接将上一步获取到的订单信息参数按照变量名的 **ASCII****码递增排序** ，剔除值为空的参数，若遇到相同字符则按照**第二个字符键值的****ASCII****码递增排序** ，并以此类推。将排序好的参数使用”参数=参数值”的形式进行组合，组合后将这些键值对使用”&”进行拼接，即可生成签名字符串。如下为示例拼接字符串：
          
          **"allocationType=NO_ALLOCATION &authId=101610000031&callbackUrl=https://xxx.xxxxx.com/next/indexa.html&mercOrder=appId=123456&bizType=100002&currency=CNY&goodsInfo=goodsDetail=goodsNum=8&goodsPrice=1&goodsShortName=****衣服 ,goodsNum=1&goodsPrice=100&goodsShortName=****裤子 &goodsListCnt=2&goodsSum=9&mercNo=101610000031&mercOrderNo=PayCheckoutDemo_1621842925866&totalAmount=108&tradeSummary=****衣服裤子等商品 &payload=****衣服裤子等商品 &returnUrl=https://xxx.xxxxx.com/next/indexa.html&signType=SHA256WithRSA/PSS"**

    * c). 使用开发平台中获取到的商户私钥对数据进行签名，签名算法使用“**SHA256WithRSA/PSS** ”。
          
          public static String sign(String content, String privateKeyStr) {
              if (StringUtils.isEmpty(content) || StringUtils.isEmpty(privateKeyStr)) {
                  log.error("content or key is null");
                  return null;
              }
              try {
                  KeyFactory keyFactory = KeyFactory.getInstance("RSA");
                  PKCS8EncodedKeySpec keySpec =
                          new PKCS8EncodedKeySpec(Base11.getMimeDecoder().decode(privateKeyStr.getBytes(StandardCharsets.UTF_8)));
                  PrivateKey privateKey = keyFactory.generatePrivate(keySpec);
          
                  Signature signature = Signature.getInstance("SHA256WithRSA/PSS");
                  signature.initSign(privateKey);
                  signature.update(content.getBytes(StandardCharsets.UTF_8));
                  byte[] sign = Base11.getEncoder().encode(signature.sign());
                  return new String(sign, StandardCharsets.UTF_8);
          
              } catch (Exception e) {
                  e.printStackTrace();
              }
          }
