# 商户经营信息查询

#### 1.基本信息查询

您可以在登录华为支付商户平台后，进入【账户中心】-\>【账户设置】-\>【商户经营信息】页面查看商户的经营信息、结算规则、法人开户意愿视频、补充说明。

#### 2.固定转账识别码查询

针对商户开通线下转账支付且选择固定转账码产品实例的商户，超级管理员可以在登录华为支付商户平台后，进入【账户中心】-\>【账户设置】-\>【商户经营信息】页面-【结算规则】 页面，点击查看/复制固定转账码数字信息。
