# 待完善受益所有人信息

根据国家监管要求，请您点击"去处理"补充完整的受益所有人信息。审核通过后，风险事项将自动解除。具体填写指南[请点击这里](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-shanghuruwang-0000001251319139#section41391661443)查阅。
