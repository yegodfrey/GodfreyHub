接入准备 **应用开发** ：本章节主要介绍HarmonyOS应用接入华为支付的场景，在接入华为支付前，请确保已经完成HarmonyOS商户客户端的开发（HarmonyOS应用开发请参考[华为开发者网站](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/develop-overview-0000001071291809)）。 **商户入网** ：为保证后续接入正常进行，请确保您已完成“[开发准备](https://developer.huawei.com/consumer/cn/doc/distribution/pay-docs/petalpay_app_4211_cert_key_use_des-0000001324892569)”的流程。 **接入架构** ：华为支付HarmonyOS sdk目前提供了Java及Js版本sdk，此小节展示java应用接入架构。
