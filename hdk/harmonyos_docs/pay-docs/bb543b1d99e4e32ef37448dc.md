# 服务商佣金确认

第一步：每月初，您可以在登录华为支付商户平台后，进入【商户中心】->【服务商佣金】->【佣金确认】查看下载明细账单，点击一键确认；

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/36/v3/D8JSoS7XQ627PitCr3Y4kQ/zh-cn_image_0000002592952766.png?HW-CC-KV=V1&HW-CC-Date=20261008T141259Z&HW-CC-Expire=31536000000&HW-CC-Sign=DDE344A09B56DA01FD56EA22266B30F5C2D59E6AAFF6DCBA9DC1D5DA98113A01 "点击放大")

第二步：佣金确认后，进入【佣金发放】界面-点击发票上传进行提交

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e3/v3/y6VrASqlRCS6RtfzQ4yCkQ/zh-cn_image_0000002623393189.png?HW-CC-KV=V1&HW-CC-Date=20261008T141259Z&HW-CC-Expire=31536000000&HW-CC-Sign=0DAEB89353E68AA684BF450CF03616D412A5595624962FF752698E2B5E371CB8 "点击放大")

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8e/v3/a5yYO9GFTmy6dShWSnIO5Q/zh-cn_image_0000002623233699.png?HW-CC-KV=V1&HW-CC-Date=20261008T141259Z&HW-CC-Expire=31536000000&HW-CC-Sign=012649BC56E308C2B878698295CEB7859FC1C05825B4103F1F7D8F7B8715A2F6 "点击放大")

第三步：等待花瓣支付发票审批完成并付款；

第四步：佣金明细查询导出，您可进入【佣金明细查询】界面，可进行佣金明细查询及导出。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0/v3/dUYkZL_ORPmCYfQ3amUCYw/zh-cn_image_0000002592957292.png?HW-CC-KV=V1&HW-CC-Date=20261008T141259Z&HW-CC-Expire=31536000000&HW-CC-Sign=71182C6EED15EBED911A9A83798A4D6BAA153E810ACD270590B098AFAE6EAADE "点击放大")
> 注意
>
> 1.系统每月初推送服务商佣金账单至商户站，服务商超级管理员可进行佣金确认；
>
> 2.<佣金账单确认通知>通过站内信、邮件、手机短信进行通知，请及时查看确认。
