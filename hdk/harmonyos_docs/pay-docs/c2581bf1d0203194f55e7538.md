# 特约商户与技术服务商授权委托函

最后更新日期：2026/1/12

**适用场景：** **本协议适用于技术服务商下属的特约商户在入网环节，特约商户须在线签署的协议文件**。

致：花瓣支付（深圳）有限公司

业务运营团队

委托方（特约商户）：xxxx

一、授权委托内容

鉴于特约商户自愿接入使用华为支付服务，现特约商户（"委托方"）授权技术服务商（"受托方"）代为办理接入及使用华为支付商户平台（以下简称"华为支付"）一切手续及相关事宜，并且技术服务商需为特约商户提供与华为支付对接系统的开发、维护和升级技术服务。

二、授权委托权限

1. 特约商户授权技术服务商以特约商户的名义，代为办理接入及使用华为支付系统，包括但不限于根据适用法律法规、华为支付服务相关协议和平台页面提示中要求办理的全部手续及相关事宜。

2. 特约商户授权技术服务商以特约商户的名义，代为对接华为支付系统必要技术操作，按华为支付商户管理标准收集、提交特约商户入驻平台所需证照资料，并授权提交相应的商户注册、功能配置、运营活动、协议传递等申请。

3. 特约商户授权技术服务商以特约商户的名义，对接华为支付系统入网时，代为开通华为支付退款功能；特约商户授权技术服务商代理特约商户通过贵司退款API接口发起退款指令，当技术服务商向贵司发起退款指令时，贵司无需通过特约商户确认，即可直接从特约商户的华为支付商户号中扣划相应资金用于退款。如后续特约商户需解除技术服务商代为发起API退款指令的授权，将自行在华为支付商户平台进行解除授权操作。

4. 技术服务商作为特约商户指定授权代表，负责代表特约商户使用查询、管理入驻华为支付后的商户号以及使用华为支付提供的营销、推广等功能，具体功能以该华为支付实际提供的为准。

5. 技术服务商向华为支付所提供的有关特约商户的资质及资料以及以特约商户名义在华为支付上进行操作，特约商户均予以认可，由此所产生的风险及责任均由特约商户承担。

6. 技术服务商授权范围不包含任何受收单机构委托而承办的收单外包业务，包括但不限于特约商户推荐、受理标识张贴、受理终端布放和维护、聚合支付技术服务等需要按照法律法规进行收单外包业务备案的业务。

7. 技术服务商无权转委托。

三、承诺说明

1. 特约商户确认，其在线点击同意即视为已充分阅读并理解本授权委托函全部条款，且该授权行为不会违反任何其所适用法律法规、签订协议或规则文件等，承诺具备必要的资质、内外部授权和/或许可签发本授权委托函及委托本授权项下内容。

2. 本授权委托函自在线点击同意时起至长期有效，直至特约商户发出变更委托函为止。

3. 本授权委托函的变更应当及时通知华为支付，委托方和受托方应共同承担未及时通知的责任后果。

4. 本授权委托函以华为支付后台留存版本为准。
