# 单笔退款操作

若您需要操作单笔交易退款，您可以在登录华为支付商户平台后，进入【交易中心】-\>【交易管理】-\>【支付交易】页面，根据交易时间、订单号、交易状态、交易类型、订单金额范围等查询交易，点击"详情"，在详情页面点击"发起退款"完成退款操作。[批量退款](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-piliangtuikuan-0000001256971107)。

温馨提示：

1.商户平台预设角色仅超级管理员及财经主管角色有退款权限，[新增自定义角色](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-xinzengjuese-0000001264819165)。

2.为了确保退款顺利进行，请确保待清算资金或支付账户余额大于退款金额。

3.若配置退款审核，所有审核人审核通过后华为支付商户平台开始执行退款操作。请审核人登录华为支付商户平台，进入【商户中心】-\>【审核】-\>【审核记录】选择待审申请进行审核。[配置退款审核](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-peizhishenhe-0000002188151740)。
