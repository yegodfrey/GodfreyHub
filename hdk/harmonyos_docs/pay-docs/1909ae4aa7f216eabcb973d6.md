# 解除分账功能

您可以在【商户中心】->【产品功能】->【产品管理】页面解除已授权的分账功能。解除后您的服务商将无法对您将交易成功的资金，划转分账给您的服务商自己或是您的服务商指定的合作伙伴。服务商会以站内信形式收到特约商户解除分账功能的通知。
