HarmonyOS应用接入时如果要开启混淆，混淆规则需要如何配置 在您开启混淆配置时，需要您在proguard-rules.pro中添加保证请求正常处理。  
      
    -keep class com.huawei.harmonypay.idl.** {*;}
    -keep class com.huawei.paysdk.entities.**{*;}
    -keep class com.huawei.utils.**{*;}
    -keep class com.huawei.harmonypay.publisher.ui.CircleView{*;}

**Tips** : 如您开启混淆后无法正常编译打包，建议您在proguard-rules.pro中添加如下配置：
    
    -dontoptimize
