# 结算单查询及下载

#### 1.结算单查询

您可以在登录华为支付商户平台后，进入【交易中心】-\>【结算管理】-\>【结算查询】页面，选择结算时间范围查询结算单。

您也可以点击结算单右边的"查看"查看结算单详情；

若您想查看结算单关联具体交易详情，点击结算单右边对应的"下载结算明细"进一步查看结算单明细。  
![](https://media:201774595416450598)  
仅支持查询和下载5年内的结算单。

![](https://media:201774595416533599 "点击放大")

<br />

#### 2.结算单字段说明

字段说明：  

|--------|------------------------------------------------------|
|字段信息|说明|
|结算日|根据结算周期进行结算付款的日期 例：结算日为3月2日，结算周期为T+1 则对应结算的是3月1日对账完成的交易|
|结算金额（元）|已扣除过手续费的结算金额（针对手续费先收的商户）|
|手续费金额（元）|在该结算周期清算完成的全部交易收取的手续费总和|

#### 3.结算单下载

您可以在登录华为支付商户平台后，进入【交易中心】-\>【结算管理】-\>【结算查询】页面，选择结算时间范围查询结算单后再点击"下载结算单"进行下载。仅支持下载5年内的结算单。

![](https://media:201774595416603600 "点击放大")
