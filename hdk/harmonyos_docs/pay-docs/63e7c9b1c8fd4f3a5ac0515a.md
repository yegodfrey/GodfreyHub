CST310002错误码 账户状态异常。由于您的账户长期无交易或存在安全隐患，账户支付功能已暂停。如需恢复，请前往钱包App“华为支付>右上角按钮>账户详情”根据提示操作，恢复后可正常使用支付功能(CST310002)。
