# 退款记录查询

您可以在登录华为支付商户平台后，进入【交易中心】-\>【交易管理】-\>【支付交易】页面，根据"原系统交易订单号"查询退款记录或将交易类型筛选为"退款"或者输入具体的"商户订单号"、"系统交易订单号"查看具体的退款记录。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250915110911.18472402672295531762387494025687:50001231000000:2800:B8A83A6134CE0598894D3B4C466632AD3B4CA221133A2908A29E31ACE3095825.png)  
（1）"原系统交易订单号"是指您操作过退款的原收单订单的系统交易订单号；

（2） 请输入"交易类型"为"退款"对应的"商户订单号"或者"系统交易订单号"。
