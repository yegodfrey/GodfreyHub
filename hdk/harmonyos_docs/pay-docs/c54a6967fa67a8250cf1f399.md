# 支付账户长时间无交易处置

根据国家法律法规要求，开立支付账户后若长时间无支付账户动账交易，支付账户将被冻结，您可以登录华为支付商户平台后，进入【账户中心】->【合规管理】->【风险处理】-【申请解除】页面查询原因及处理。

若风险原因已解除，将不在该列表展示。
