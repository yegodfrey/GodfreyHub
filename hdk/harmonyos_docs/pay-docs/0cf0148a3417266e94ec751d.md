支付接口调用 IPayApi接口为开发者提供订单支付功能，在调用支付之前需要实例化该对象，传入上下文信息和是否需要跨设备支付类型标识（本设备支付时传入false），获取IPayApi实例对象。支付行为需要在独立的非Ui线程执行：
    
    IPayApi payApi = new HuaweiPayImpl(HuaweiPayAbilitySlice.this, false);
        getGlobalTaskDispatcher(TaskPriority.DEFAULT).asyncDispatch(() -> {
            PayResult result = payApi.pay(orderDataStr);
            InnerEvent innerEvent = InnerEvent.get();
            innerEvent.object = result;
            handler.sendEvent(innerEvent);
        });
