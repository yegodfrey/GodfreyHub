请求参数 **Method** | **URI** | **Description**  
---|---|---  
POST | /payment/api/merc/v1/transOrder/query | 交易订单查询  
**Name** | **Mandatory** | **Type** | **position** | **Description**  
---|---|---|---|---  
mercNo | M | String | query | 商户号（灰度引流）  
PayMercAuth | M | String | header | 商户鉴权信息  
requestBody | M | QueryOrderRequest | body | 收单交易订单查询请求  
QueryOrderRequest **Name** | **Mandatory** | **Type** | **Description**  
---|---|---|---  
orderType | O | String | 订单类型：0-系统订单号，1-商户订单号  
orderNo | O | String | orderType为0时，orderNo为华为系统订单号，orderType为1时，orderNo为商户订单号
