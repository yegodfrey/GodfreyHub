# 结算明细查询及下载

#### 1.结算明细查询及下载

您可以在登录华为支付商户平台后，进入【交易中心】-\>【结算管理】-\>【结算查询】页面，选择结算时间范围查询结算单后，点击"下载结算明细"查看结算明细。您也可以点击"批量下载结算明细"下载当前页面展示结算单对应的结算明细数据。

#### 2.结算明细字段说明

字段说明：  

|--------|-----------------|-------------|
|字段信息|交易类型对应说明||
|字段信息|收单（COLLECTION）|退款（REFUND）|
|结算金额（元）|已轧差过手续费的结算金额（针对手续费先收的商户）||
|订单金额（元）|实际收单金额（交易金额+优惠金额）|实际操作的退款金额|
|优惠金额（元）|营销账户出资的营销资金|营销账户实际收到的退款金额|
|手续费金额（元）|订单金额\*支付方式对应的手续费率||
|结算日|根据结算周期进行结算的日期例：结算日为3月2日，结算周期为T+1，则对应结算的是3月1日对账完成的交易||
