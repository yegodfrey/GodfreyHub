如果华为支付同一用户重复签约华为支付如何处理的？能否保证同一用户仅能签约一次？ 当前版本华为支付，同一个商户号、使用同一个华为支付账号、使用同一套签约模板时，多次重复签约时会返回同一签约号，需要商户在用户创建签约请求时自行确认是否为重复签约。如果商户不想自行判断是否重复签约，可以使用extInfo字段按照如下规则，传firstSign字段为true，例如：  
      
    "extInfo":"{\"firstSign\":true}"
    /**
    * 是否允许重复签约 默认允许
    */
    @Mask(value = false)private boolean firstSign;
