# 支付交易明细查询及下载

#### 1.支付交易明细查询

支付交易明细：展示该商户号下所有状态的交易记录。

您可以在登录华为支付商户平台后，进入【交易中心】-\>【交易管理】-\>【支付交易】页面，选择您要查询交易时间、订单号、交易类型、交易状态、交易金额范围，点击"查询"支付交易明细，订单查询最长时间范围为31天。

#### 2.支付交易明细部分字段说明

支付交易明细部分字段说明：  

|--------|-----------------|-----------------|
|字段信息|交易类型对应说明||
|字段信息|收单（COLLECTION）|退款（REFUND）|
|订单金额（元）|实际收单金额（交易金额+优惠金额）|实际操作的退款金额|
|手续费金额（元）|订单金额\*支付方式对应的手续费率|订单金额\*支付方式对应的手续费率|
|交易金额（元）|用户实际支付的金额|用户账户实际收到的退款金额|
|优惠金额（元）|营销账户出资的营销资金|营销账户实际收到的退款金额|

例如：

有一笔收单交易，金额为100元，用户实际支付了90元，支付立减券10元，后续商户退款100元。

支付交易明细中会有2笔交易记录。

记录1：交易类型为"收单"，订单金额（元）=100；交易金额（元）=90；优惠金额（元）=10。

记录2：交易类型为"退款"，订单金额（元）=100；交易金额（元）=90；优惠金额（元）=10。

<br />

#### 3.支付交易明细下载

您可以在登录华为支付商户平台后，进入【交易中心】-\>【交易管理】-\>【支付交易】页面，选择您要查询交易时间、订单号、交易类型、交易状态、交易金额范围，查询下载支付交易明细，可在下载中心将支付交易明细保存至本地。。
