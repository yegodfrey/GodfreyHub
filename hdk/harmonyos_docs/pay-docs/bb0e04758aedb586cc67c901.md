# 结算常见问题

#### 1.结算款多久到账

请在结算款付款后的1-3个工作日留意资金到账情况。节假日受央行系统影响，具体到账时间请以银行为准。  

#### 2.结算周期查询

您可以在登录华为支付商户平台后，进入【账户中心】-\>【账户设置】-\>【商户经营信息】页面，点击"结算规则"查看结算周期。

![](https://media:301781572810412544 "点击放大")

<br />

#### 3.手续费计算规则

在交易过程中会产生一定的手续费，结算时扣除相应的手续费再结余下的金额。

具体费率根据您申请的支付方式对应的手续费决定，单笔订单四舍五入，保留小数点后2位。

<br />

#### 4.结算规则

常规结算逻辑是：结算金额=订单金额（收单）-手续费金额（收单）-订单金额（退款）+手续费金额（退款）  
![](https://media:301781572810822545)  
例如： 订单实付80元，手续费2元。

* 正常结算： 您将收到 80 - 2 = 78元。
* 全额退款： 您将支出 80元（退给用户），并收回 2元（退手续费），净支出 78元。与您最初收到的78元抵消，资金归零，符合预期。

您可以在登录华为支付商户平台后，进入【交易中心】-\>【支付交易对账单】或【结算查询】页面获取详细对账指导，参考指导进行核对，具体对账指南指南请[点击这里](https://developer.huawei.com/consumer/cn/doc/hwzf-shanghuduizhangshuomingshu#h1-1660123298299-4)查阅。  

#### 5.电子凭证申请

您可以在登录华为支付商户平台后，进入【交易中心】-\>【结算管理】-\>【凭证申请】申请资产证明；可在【申请记录】页面查看文件生成情况。
