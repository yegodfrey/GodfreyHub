# 批量退款操作

申请批量退款主要分为2步。  

#### 第1步：下载并填写退款模板。

进入【交易中心】-\>【退款管理】-\>【退款申请】页面，点击"[退款模板](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250915110852.71143244553147183990919962182538:50001231000000:2800:280E8B97302FC2F44A80FB47BC118C58FF6E9736ED4670631E3C526A6A8D9ECB.xlsx?needInitFileName=true)"将退款模板下载至本地并填写相关信息，每次至多填写1000条退款申请。

批量退款模板填写说明：

|-----------|--------------------------------------------------------------------------------------------------------------|
|字段|说明|
|系统交易订单号（必填）|指原收单交易的订单号，长度要求46位数字以内|
|商户订单号（选填）|商户订单号与系统交易订单号需为同一笔交易的订单号，长度要求32位数字以内|
|商户退款订单号（选填）|若未填写商户退款订单号，则在退款提交成功后，将由系统自动生成，并返回至退款提交结果页面，长度要求32位数字以内；请务必保存商户退款订单号，您可以在【支付交易】页面，在"商户订单号"中输入"商户退款订单号"来查询退款结果；|
|退款申请金额（必填）|退款金额默认以"元"为单位，保留两位小数。退款申请金额不可超过该笔订单剩余可退金额；|
|退款原因（选填）|长度要求10字以内。|

温馨提示：

针对营销订单的退款，请注意退款时系统会将营销金额按比例退至相应的营销账户。为保证用户收到足够的退款金额，请按以下公式计算需退款的金额。

随机立减比例（A）=营销金额（B）/订单金额（C）；

用户收到的退款金额（Y）=系统输入的退款金额（X）-系统输入的退款金额（X）\*随机立减比例（A）；

即Y=X\*（1-A），即实际在系统中需要输入的退款金额 X=Y/（1-A）。

<br />

#### 第2步：上传退款文件。

进入【交易中心】-\>【退款管理】-\>【退款申请】页面，将填写好的退款模板上传至华为支付商户平台。上传成功后点击"提交退款"。提交成功后点击"刷新"可查看退款状态。

温馨提示：

若配置批量退款审核，所有审核人审核通过后华为支付商户平台开始执行批量退款操作。请审核人登录华为支付商户平台，进入【商户中心】-\>【审核】-\>【审核记录】选择待审申请进行审核。[配置退款审核](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-peizhishenhe-0000002188151740)。
