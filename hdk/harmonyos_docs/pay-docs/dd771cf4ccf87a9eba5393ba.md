手续费发票申请与查询 1.手续费开票申请 您使用华为支付服务，需向华为支付支付交易手续费，华为支付需向您开具手续费发票。 您可以在登录华为支付商户平台后，进入【交易中心】->【结算管理】->【开票管理】页面，可以根据结算单申请开具手续费发票，也可查看开票记录。 当前我司手续费发票已切换为数字化电子发票（增值税专用发票）或数字化电子发票（增值税普通发票），不再提供纸质发票。 申请开具发票主要分为3步。 **第1步：填写发票信息。** 进入【交易中心】->【结算管理】->【开票管理】页面，点击页面上的“发票信息”，在跳转后的页面点击“填写发票信息”填写发票信息。
