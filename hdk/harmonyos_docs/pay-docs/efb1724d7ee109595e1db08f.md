# 平台类商户激励金领取

## 第1步：确认激励金

您可以登录华为支付商户平台后，进入【商户中心】->【活动管理】->【激励金申请】页面，根据结算月份、发放月份、状态查询到待确认激励金，下载并核对激励金明细无误后，点击"确认"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/93/v3/Iukk-pNtQliayjvOehBrIw/zh-cn_image_0000002622003449.png?HW-CC-KV=V1&HW-CC-Date=20261008T171324Z&HW-CC-Expire=31536000000&HW-CC-Sign=20DF0FB770CA89324A3D6293A77FCC5579BE71DBC6245D4D18F0BEB51AEF1DD7 "点击放大")

## 第2步：上传发票

点击"电子发票上传"，进入上传页面，选择发票上传(支持上传多张发票)，点击"提交"等待发票审核。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/87/v3/Ud6cs52QQgC-fMsLeUL6wg/zh-cn_image_0000002592749452.png?HW-CC-KV=V1&HW-CC-Date=20261008T171324Z&HW-CC-Expire=31536000000&HW-CC-Sign=A8E0512E5D46D4EF3F0EB02B1C6767D25C05DC9296BEC960655AAFE1C6CB1D5B "点击放大")

## 第3步：发票审批完成领取激励金

等待发票审批完成后，请再次进入【商户中心】->【活动管理】->【激励金申请】页面，请点击"领取"等待激励金发放，发放成功后，激励金状态更新为已发放
