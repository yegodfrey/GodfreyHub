# 平台类商户激励金领取

#### 第1步：确认激励金

您可以登录华为支付商户平台后，进入【商户中心】-\>【活动管理】-\>【激励金申请】页面，根据结算月份、发放月份、状态查询到待确认激励金，下载并核对激励金明细无误后，点击"确认"。

![](https://media:301781572796520450 "点击放大")

<br />

#### 第2步：上传发票

点击"电子发票上传"，进入上传页面，选择发票上传(支持上传多张发票)，点击"提交"等待发票审核。

![](https://media:301781572796564451 "点击放大")

<br />

#### 第3步：发票审批完成领取激励金

等待发票审批完成后，请再次进入【商户中心】-\>【活动管理】-\>【激励金申请】页面，请点击"领取"等待激励金发放，发放成功后，激励金状态更新为已发放

![](https://media:301781572796623452 "点击放大")

<br />
