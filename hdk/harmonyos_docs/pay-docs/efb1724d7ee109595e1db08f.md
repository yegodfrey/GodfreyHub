# 平台类商户激励金领取

## 第1步：确认激励金

您可以登录华为支付商户平台后，进入【商户中心】->【活动管理】->【激励金申请】页面，根据结算月份、发放月份、状态查询到待确认激励金，下载并核对激励金明细无误后，点击"确认"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/93/v3/Iukk-pNtQliayjvOehBrIw/zh-cn_image_0000002622003449.png?HW-CC-KV=V1&HW-CC-Date=20260924T101900Z&HW-CC-Expire=31536000000&HW-CC-Sign=97B927822B5CEA1E98C177FC2166C59C5E06C6E86291FC0D058AE831DA4DB3C8 "点击放大")

## 第2步：上传发票

点击"电子发票上传"，进入上传页面，选择发票上传(支持上传多张发票)，点击"提交"等待发票审核。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/87/v3/Ud6cs52QQgC-fMsLeUL6wg/zh-cn_image_0000002592749452.png?HW-CC-KV=V1&HW-CC-Date=20260924T101900Z&HW-CC-Expire=31536000000&HW-CC-Sign=991714B62B94911C5F692D15E1EE03A01818040030E9CA9EA394D3265F8E3CA2 "点击放大")

## 第3步：发票审批完成领取激励金

等待发票审批完成后，请再次进入【商户中心】->【活动管理】->【激励金申请】页面，请点击"领取"等待激励金发放，发放成功后，激励金状态更新为已发放
