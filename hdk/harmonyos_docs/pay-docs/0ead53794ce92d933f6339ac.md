# 资金分账申请及承诺函

最后更新日期：2026/1/12

适用场景：本协议适用于服务商邀请特约商户开通分账功能，特约商户须在线签署的协议文件。

<br />

致：花瓣支付（深圳）有限公司（下称"贵司"）

华为支付运营团队

我司xxxx（华为支付商户号为xxxx）向贵司申请开通分账服务，并委托贵司根据我司提供分账规则及/或分账指令，将我司或我司平台下子商户/特约商户的待结算交易款划转至我司指定的分账接收方的结算账户中。

我司向贵司郑重承诺以下事项：

1、我司承诺已获得子商户的明确授权，该授权真实、有效、合法，可提供相关平台协议和资料证明平台服务关系及所进行分账交易的真实性。

2、我司承诺基于合法、合规、真实的分账场景使用华为支付分账服务，严格按照我司与分账接收方的协议约定申请配置分账规则或发送分账指令，因我司使用分账服务导致的纠纷及风险损失，均由我司自行承担，与贵司无关。

3、我司将按照法律、法规、规章和监管规定，积极履行反电信网络诈骗、反洗钱和反恐怖融资、反逃税义务，对业务运营、分账接收方、分账规则等进行审核管理，向贵司报送的任何数据和交易信息均真实、准确、完整，确保贵司符合法律法规及监管要求。

4、贵司有权根据自身营运需求和风险判断，通知我司配合调整分账比例，有权拒绝分账指令或终止提供分账服务。

5、我司承诺遵守《华为支付商户服务协议》及相关规则使用分账服务，如我司需申请关闭分账服务，我司将提前30日按贵司要求出具书面通知书进行申请。

6、如因我司或分账接收方的过错导致贵司发生损失的，我司将承担全部赔偿责任。

7、本承诺函自我司在线点击同意时起至长期有效。

8、本承诺函以华为支付后台留存版本为准。
