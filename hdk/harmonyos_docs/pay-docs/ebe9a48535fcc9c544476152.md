# 华为支付商户号信息查询

您可以在登录华为支付商户平台后，进入【账户中心】->【账户设置】->【商户主体信息】->【商户号设置】页面查看您的商户号信息。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250915110834.30507973112582265639799292960344:50001231000000:2800:E177C574AFD8B80776ED3A88F3C9040C2693AC8AA9A66C84846A1777EE9F3A26.png "点击放大")

若您授权登录华为支付商户平台的华为账号关联多个商户号，您可以在进入商户平台后，通过弹窗页面查看该账号下的商户信息及商户号状态
