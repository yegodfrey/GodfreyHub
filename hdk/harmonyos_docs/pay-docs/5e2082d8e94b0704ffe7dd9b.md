支付结果获取和处理 **同步返回** 调用pay接口后同步返回支付结果PayResult, 通过当前Ability的EventHandler对象发送消息，并在该EventHandler的回调方法中处理支付结果。
    
    **private** EventHandler **handler** = **new** EventHandler(EventRunner._getMainEventRunner_()) {
         @Override
         **protected void** processEvent(InnerEvent event) {
             **if**(event != **null** && event.**object instanceof **PayResult) {
                 PayResult result = (PayResult) event.**object** ;
                 **mPayStatusText**.setText(result.getReturnCode());
                 **mPayResultText**.setText(result.getReturnMsg() + **" "** + result.getTradeInfo());
             } **else**{
                 LogC._e_(**_TAG_** , **"failed, parsing pay result error"** , **false**);
             }
         }
     };

**异步通知** 商户在构建支付请求参数时，传入了一个callbackUrl。在华为支付服务器完成支付后，将以post方式调用callbackUrl，将支付结果返回给商户服务器。
