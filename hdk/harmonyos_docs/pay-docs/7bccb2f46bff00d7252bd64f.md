# 华为支付联合运营承诺函

最后更新日期：2026/3/13

**适用场景：** **本协议适用于APPID的应用开发者与商户主体不同，商户须在线签署的协议文件**。

致：花瓣支付（深圳）有限公司（下称"华为支付"或"贵司"）

业务运营部

我们，**AppID所属公司和华为支付商户号所属公司**，现作为联合运营方达成一致，共同向华为支付申请将关联APP的AppID与华为支付商户号关联绑定，用户能够在该AppID中使用华为支付购买相关商品和服务，

我们向华为支付郑重承诺以下事项：

1) 所有交易款项均由贵司结算至相应的华为支付商户号所属公司指定结算账户；

2) AppID所属公司已对所有关联的华为支付商户号所属公司进行审核，确保通过AppID销售商品和服务合法、合规；

3) 用户因在关联APP中购买商品或服务而遭受损失或发生纠纷的，我们作为联合运营方积极妥善解决客户纠纷，并承诺就用户损失承担连带责任；

4) 贵司可以根据自身营运需要和风险判断，调整、取消AppID与相关华为支付商户号的关联关系。

特此承诺！
