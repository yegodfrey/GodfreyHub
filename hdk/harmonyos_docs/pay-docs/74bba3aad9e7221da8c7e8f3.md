# 员工账号管理页面功能介绍

华为支付商户平台支持除"超级管理员"账号外，自由创建多个其他员工账号，每个员工账号对应的商户平台操作权限不同。

目前可创建的系统角色包括：财经专员、财经主管、运营、技术支持，具体系统角色对应的权限详情，可以进入【账户中心】-\>【账号管理】-\>【角色权限设置】页面查询。

除系统角色外，您也可以根据业务需求[自定义角色新增](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-xinzengjuese-0000001264819165)并赋予角色对应的商户平台操作权限。
