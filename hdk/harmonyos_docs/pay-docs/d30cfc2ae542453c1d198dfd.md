# 子商户入网指引

平台类商户可通过以下2种方式之一操作新增子商户：

方式一：平台商户超级管理员登录华为支付商户平台后，进入【商户中心】->【平台子商户管理】页面选择**直接添加**商户方式，根据页面提示完成子商户新增。

主要分为4步：

申请子商户超级管理员账号->填写并上传子商户信息，提交入网申请->子商户激活超级管理员账户并完成小额打款认证->联系子商户签署协议。

具体操作指南请查看[平台子商户入网指引](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-zishanghuruwang-0000001720049550)。

方式二：平台商户超级管理员登录华为支付商户平台后，进入【商户中心】->【平台子商户管理】页面选择**邀请商户**添加方式，通过链接邀请子商户自行填写资料申请入网。

主要分为4步：

填写商户名生成邀请链接->复制链接并发送子商户->子商户授权登录华为支付商户平台填写资料提交入网申请->完成账户验证签署协议开户。具体操作指南请查看[平台子商户入网指引](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-zishanghuruwang-0000001720049550)
> 注意
>
> 不可用平台类商户管理员的华为账号登录，否则将有报错提示"该华为账号已有商户号，且登记的超管信息与待激活超管信息不一致"。
