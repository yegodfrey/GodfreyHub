# 账户认证失败，如何处理

若您的入网申请审核通过，在进行账户验证时，输入金额错误，会弹出"账户认证失败，请于24小时之后重新发起账户验证"提示，您须等待24小时后，按如下方法操作：

**方法1：重新发起验证**

1. 点击 【重新进行账户验证】
2. 账户信息核验：
   * ✅ 信息正确 → 点击 【核对无误，重新进行账户认证】
   * ✗ 信息错误 → 点击 【修改结算账户】 → 更新后提交
3. 验证流程：
   * 花瓣支付（深圳）有限公司向账户打入随机验证金
   * 需输入精确到分的金额

**方法2：退回修改资料**

1. 点击 【修改资料】 → 系统提示：⚠️ "当前申请将被撤回至草稿箱，修改后需重新提交审核"
2. 更新信息后重新提交
3. 华为支付1-2个工作日内审核（短信+邮件通知）
