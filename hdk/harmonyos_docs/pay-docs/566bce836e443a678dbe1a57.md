# 商户号解冻

若商户号因180天无交易被冻结，您可登录华为支付商户平台，点击页面弹窗"申请解冻"按钮申请解冻；

若商户号因证照信息未更新被冻结，您可登录华为支付商户平台，进入【账户中心】页面，根据冻结邮件提示上传更新证照资料申请解冻；

其他原因冻结解冻，您可联系平台客服进一步咨询。
