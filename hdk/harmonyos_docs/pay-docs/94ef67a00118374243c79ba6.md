# 注册与登录

## 华为账号注册流程

1、访问入口

* 打开**[华为支付商户平台](https://petalpay-merchant.cloud.huawei.com/)**
* 点击【**授权华为账号登录**】
* 选择【**注册** 】

2、注册方式

* **方式①手机号注册**：1个手机号仅可注册1个华为账号
* **方式②邮箱注册** ：1个手机号至多绑定5个华为账号, (作为安全手机)

3、完成注册

* 按页面指引填写信息
* 注册成功后**自动跳转**至商户平台登录页

**常见问题**

|--------|----------------------------------------------------|
|**场景**|**操作路径**|
|**忘记密码**|登录页点击【**忘记密码** 】**->** 按指引验证身份**->**重置密码|
|**修改密码**|登录页点击【**遇到问题** 】**->** 选择"修改密码"**->** 完成安全验证**->**设置|
|**账号解绑**|需联系华为客服处理（原绑定手机/邮箱失效时适用）|

## 密码登录

1. 访问**[华为支付商户平台](https://petalpay-merchant.cloud.huawei.com/)** **->** 点击【**授权华为账号登录**】
2. 输入以下任一凭证: 手机号、邮箱 、华为账号名
3. 输入密码**->** 点击【**授权并登录**】
4. 完成 **短信二次验证**(安全强制步骤)

## 扫码登录

1. 访问**[华为支付商户平台](https://petalpay-merchant.cloud.huawei.com/)** **->** 点击【**授权华为账号登录**】，登录页选择【扫码登录】
2. 华为手机用户操作路径：设置 **->** 华为账号 **->**右上角 【扫一扫】
3. 扫描网页端二维码**->**自动授权登录

## 短信验证码登录

1. 访问**[华为支付商户平台](https://petalpay-merchant.cloud.huawei.com/)->** 点击 【**授权华为账号登录** 】，登录页选择【短信验证码】登录，输入已绑定的手机号**->**点击【获取验证码】
2. 输入验证码**->**点击【授权并登录】
