# API退款授权

## 什么是API退款

华为支付商户平台支持服务商为商户号状态正常特约商户通过API发起退款，特约商户无需自行登录华为支付商户平台进行退款操作，API退款需要获得特约商户的授权。服务商超级管理员可在【商户中心】->【特约商户管理】页面，向特约商户发起API退款授权申请，特约商户签署授权函确认授权后，授权关系建立。

## 如何申请API退款授权

申请API退款授权主要分为2步。

**第1步：服务商向特约商户发起授权申请。**

您可以登录华为支付商户平台后，进入【商户中心】->【特约商户功能管理】页面，根据"商户状态"及"授权状态"查询到商户号状态正常且未授权特约商户列表，选中需要发起授权的特约商户，点击"授权申请"，向该特约商户发起退款授权邀请。

若需对多个特约商户发起退款授权申请，在商户号状态正常且未授权特约商户列表中选中多个特约商户，点击"授权批量申请"，向多个特约商户发起退款授权邀请。

**第2步：特约商户登录华为支付商户平台签署授权函，确认授权。**

特约商户超级管理员登录华为支付商户平台，进入【账户中心】->【产品授权】页面，查看到服务商发起的API退款授权申请，点击"授权"。进入《服务商API退款指令授权函》签署页面，进行授权函签署，回填验证码确认授权。

## 如何解除API退款授权

特约商户超级管理员登录华为支付商户平台，进入【账户中心】->【产品授权】页面，查看到服务商平台退款，点击"解除授权"。

## 如何查询API退款授权状态

华为支付商户平台支持服务商对特约商户API退款授权申请状态进行查询，超级管理员登录华为支付商户平台后，进入【商户中心】->【特约商户管理】页面，在"授权状态"框中勾选具体状态进行查询。

## 为什么无法操作退款授权申请

您可以核实特约商户的商户号状态是否异常，若特约商户的商户号为冻结或注销状态，服务商均无法发起授权申请。
