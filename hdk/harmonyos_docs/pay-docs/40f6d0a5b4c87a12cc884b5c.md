# 功能设置页面功能介绍

您可以在登录华为支付商户平台后，进入【商户中心】->【产品功能】->【功能设置】页面设置"对账单接口获取开关"及"结算单接口获取开关"。

对账单接口获取开关：如您已具备技术对接能力，可开启该功能。开启后，您可通过接口获取支付交易对账单及营销交易对账单。

结算单接口获取开关：如您已具备技术对接能力，可开启该功能。开启后，您可通过接口获取结算单。
