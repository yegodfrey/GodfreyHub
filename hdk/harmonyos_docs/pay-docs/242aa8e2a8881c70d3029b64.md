# 审核流程配置

您可以在登录华为支付商户平台后，进入【商户中心】->【审核】->【审核设置】页面，选择需要设置的业务（单笔退款、批量退款、支付账户、营销账户、手续费账户提现），点击"去设置",根据业务需要及页面提示配置审核流程，审核流程配置完成后，需点击启用，审核流程才生效。

您可根据业务需要设置多级审核，最多可设置3级审核步骤，若设置多级审核，必须完成每一级审核业务才可正常执行，支持超级管理员查看并审核所有电子流。

**温馨提示：**

审核员需先激活成为华为支付商户平台操作员角色后才可被添加审核配置，**[新增操作员角色](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-tianjiayuangongzhanghao-0000001245297313)**。
