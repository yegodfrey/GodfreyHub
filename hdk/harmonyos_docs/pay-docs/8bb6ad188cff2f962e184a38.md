# 特约商户元服务费率管理

第一步：服务商超级管理员登录华为支付商户平台后，进入【商户中心】->【商户管理】->【特约商户费率管理】页面点击新增->上传特约商户模板

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/36/v3/OxBV-VwUR8-yScDlAw_fLw/zh-cn_image_0000002592764556.png?HW-CC-KV=V1&HW-CC-Date=20260924T101901Z&HW-CC-Expire=31536000000&HW-CC-Sign=C219DF0FABF3B5283E9E8730C7852E5884E556880516A58C224EAEA1D6D97695 "点击放大")

第二步：点击下一步，填写元服务费率，上传与特约商户的合同附件

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/34/v3/vxYHUgjBTq-2omehwzAOLQ/zh-cn_image_0000002592765308.png?HW-CC-KV=V1&HW-CC-Date=20260924T101901Z&HW-CC-Expire=31536000000&HW-CC-Sign=706184AB821DD11AD54AA7846BF78578983188D1B0C773EC16EDD648E0696A4D "点击放大")

第三步：点击提交后，该页面显示为待审核状态，待花瓣支付运营人员审核通过后，该特约商户登录华为支付商户平台后，进入【商户中心】->【产品功能】->【费率管理】页面点击确认；

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/44/v3/Z73NicuRQ0mTB1VOEMIdmQ/zh-cn_image_0000002623205341.png?HW-CC-KV=V1&HW-CC-Date=20260924T101901Z&HW-CC-Expire=31536000000&HW-CC-Sign=AB52355836F3CB748136EA1EA2AE493B9189CD6953F670F67B79D983BB871509 "点击放大")

第四步：确认完成后，特约商户可进入【账户中心】->【商户经营信息】->【结算规则】页面查看最新费率生效情况；服务商可进入【商户中心】->【商户管理】->【特约商户费率管理】页面查看申请状态；（特约商户确认后，将于次日0点正式生效）

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ca/v3/-QLjfhh0QbuJHEzc5em_1A/zh-cn_image_0000002623206043.png?HW-CC-KV=V1&HW-CC-Date=20260924T101901Z&HW-CC-Expire=31536000000&HW-CC-Sign=FB14D751EBF81D75BC33BA2DEE9643E2B212C1BFAA05EBD93AD253E8B234D454 "点击放大")

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ec/v3/UPi4P_upQgCBebK2E04Jeg/zh-cn_image_0000002592927044.png?HW-CC-KV=V1&HW-CC-Date=20260924T101901Z&HW-CC-Expire=31536000000&HW-CC-Sign=DD7C3626A4937A72F52675635443783C5B658A541F0BAFA5AECC2C8BD23A1F88 "点击放大")
> 注意
>
> 1. 仅支持服务商修改特约商户的**元服务费率**，其他费率不支持修改；
>
> 2. 每个特约商户每90天允许修改一次；
>
> 3. 费率修改规则：特约商户费率不可低于服务商费率价格；
>
> 4. 特约商户确认后，将于次日0点正式生效。
