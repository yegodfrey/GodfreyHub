# 特约商户元服务费率管理

第一步：服务商超级管理员登录华为支付商户平台后，进入【商户中心】->【商户管理】->【特约商户费率管理】页面点击新增->上传特约商户模板

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/36/v3/OxBV-VwUR8-yScDlAw_fLw/zh-cn_image_0000002592764556.png?HW-CC-KV=V1&HW-CC-Date=20260921T064300Z&HW-CC-Expire=31536000000&HW-CC-Sign=5FEFDD634A3092AB97FEDE42762AD09584A5E1FA2387464B16EE66BEEF426D8C "点击放大")

第二步：点击下一步，填写元服务费率，上传与特约商户的合同附件

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/34/v3/vxYHUgjBTq-2omehwzAOLQ/zh-cn_image_0000002592765308.png?HW-CC-KV=V1&HW-CC-Date=20260921T064300Z&HW-CC-Expire=31536000000&HW-CC-Sign=71D365E95ED7C9C29B3D8F116787CF42FFB05E922418C0D9A231B91165BA2E9E "点击放大")

第三步：点击提交后，该页面显示为待审核状态，待花瓣支付运营人员审核通过后，该特约商户登录华为支付商户平台后，进入【商户中心】->【产品功能】->【费率管理】页面点击确认；

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/44/v3/Z73NicuRQ0mTB1VOEMIdmQ/zh-cn_image_0000002623205341.png?HW-CC-KV=V1&HW-CC-Date=20260921T064300Z&HW-CC-Expire=31536000000&HW-CC-Sign=96231C90C786BC4850D9C331C84EA364219BEBAF4FB465A529E401A8402A7ABC "点击放大")

第四步：确认完成后，特约商户可进入【账户中心】->【商户经营信息】->【结算规则】页面查看最新费率生效情况；服务商可进入【商户中心】->【商户管理】->【特约商户费率管理】页面查看申请状态；（特约商户确认后，将于次日0点正式生效）

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ca/v3/-QLjfhh0QbuJHEzc5em_1A/zh-cn_image_0000002623206043.png?HW-CC-KV=V1&HW-CC-Date=20260921T064300Z&HW-CC-Expire=31536000000&HW-CC-Sign=F546EE98138EDB78B65FD1431148D8EB070B135615B422DACEFDC765BF446C1B "点击放大")

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ec/v3/UPi4P_upQgCBebK2E04Jeg/zh-cn_image_0000002592927044.png?HW-CC-KV=V1&HW-CC-Date=20260921T064300Z&HW-CC-Expire=31536000000&HW-CC-Sign=07EB969630364AFD8F78AC00217D7F4118EF4CA3B7700E874AEFD58A82357C92 "点击放大")
> 注意
>
> 1. 仅支持服务商修改特约商户的**元服务费率**，其他费率不支持修改；
>
> 2. 每个特约商户每90天允许修改一次；
>
> 3. 费率修改规则：特约商户费率不可低于服务商费率价格；
>
> 4. 特约商户确认后，将于次日0点正式生效。
