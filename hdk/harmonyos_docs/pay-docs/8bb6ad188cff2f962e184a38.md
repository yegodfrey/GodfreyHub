# 特约商户元服务费率管理

第一步：服务商超级管理员登录华为支付商户平台后，进入【商户中心】->【商户管理】->【特约商户费率管理】页面点击新增->上传特约商户模板

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/36/v3/OxBV-VwUR8-yScDlAw_fLw/zh-cn_image_0000002592764556.png?HW-CC-KV=V1&HW-CC-Date=20261008T171140Z&HW-CC-Expire=31536000000&HW-CC-Sign=949FB74623448CB4644832CD50C57919C8A17F974074A1C5752DFFC2A93D1FE9 "点击放大")

第二步：点击下一步，填写元服务费率，上传与特约商户的合同附件

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/34/v3/vxYHUgjBTq-2omehwzAOLQ/zh-cn_image_0000002592765308.png?HW-CC-KV=V1&HW-CC-Date=20261008T171140Z&HW-CC-Expire=31536000000&HW-CC-Sign=5D679F5B0AC7B2DCA2D385496F323F13AE0E893B83BB613633D3ADE0FF8F5C83 "点击放大")

第三步：点击提交后，该页面显示为待审核状态，待花瓣支付运营人员审核通过后，该特约商户登录华为支付商户平台后，进入【商户中心】->【产品功能】->【费率管理】页面点击确认；

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/44/v3/Z73NicuRQ0mTB1VOEMIdmQ/zh-cn_image_0000002623205341.png?HW-CC-KV=V1&HW-CC-Date=20261008T171140Z&HW-CC-Expire=31536000000&HW-CC-Sign=365F854A0557E861DF5D3DDBF396C8AA99525BD279D282ADFB02AAEC3F90E9A9 "点击放大")

第四步：确认完成后，特约商户可进入【账户中心】->【商户经营信息】->【结算规则】页面查看最新费率生效情况；服务商可进入【商户中心】->【商户管理】->【特约商户费率管理】页面查看申请状态；（特约商户确认后，将于次日0点正式生效）

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ca/v3/-QLjfhh0QbuJHEzc5em_1A/zh-cn_image_0000002623206043.png?HW-CC-KV=V1&HW-CC-Date=20261008T171140Z&HW-CC-Expire=31536000000&HW-CC-Sign=C44C653F8BB72638484F717B0C554B2F904C9B3898F31009A2CB0B487C2D57D2 "点击放大")

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ec/v3/UPi4P_upQgCBebK2E04Jeg/zh-cn_image_0000002592927044.png?HW-CC-KV=V1&HW-CC-Date=20261008T171140Z&HW-CC-Expire=31536000000&HW-CC-Sign=FB3E3C823F80EAB65CA0B1478D588E494C6F54690C3E4C67DEA4FC6297FE14D7 "点击放大")
> 注意
>
> 1. 仅支持服务商修改特约商户的**元服务费率**，其他费率不支持修改；
>
> 2. 每个特约商户每90天允许修改一次；
>
> 3. 费率修改规则：特约商户费率不可低于服务商费率价格；
>
> 4. 特约商户确认后，将于次日0点正式生效。
