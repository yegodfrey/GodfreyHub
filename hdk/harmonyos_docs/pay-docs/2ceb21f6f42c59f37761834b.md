# 认证次数超限，如何处理

若您已进行多次账户验证，**并弹出【打款或认证次数超限，入网失败】提示**；处理方案如下：

一、**直连商户/开发者自主操作**

|入网渠道|操作路径|
|:-------|:------------------------------------------------------------------------------------------------------------------------------|
|华为支付商户平台|1. 商户超级管理员登录【**[华为支付商户平台](https://petalpay-merchant.cloud.huawei.com/)**】 → 点击 【修改资料】 2. 选择： ✅ 账户无误 → 直接重新提交 ✗ 账户有误 → 修改结算账号后提交|
|开发者联盟官网|1. 访问：开发者联盟 > 商户服务 > 境内收款账号 2. 选择： ✅ 账户无误 → 【重新提交】 ✗ 账户有误 → 修改后 【提交】|

二、**平台商户子商户**

⚠️ 需平台协助处理

1. 联系您的平台商户超级管理员
2. 平台操作路径：平台类商户超级管理员登录【**[华为支付商户平台](https://petalpay-merchant.cloud.huawei.com/)** 】 > 商户管理 >平台子商户管理> 找到申请记录 > 【重新触发验证】

三、**服务商特约商户**

⚠️ 需服务商协助处理

1. 联系您的服务商管理员
2. 服务商操作路径：服务商超级管理员登录【**[华为支付商户平台](https://petalpay-merchant.cloud.huawei.com/)**】 > 商户管理 >特约商户管理> 找到申请记录 > 【重新触发验证】
