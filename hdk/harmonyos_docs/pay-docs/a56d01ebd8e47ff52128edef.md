支付产品概览
    * 签约代扣签约代扣是华为支付针对商户需要用户周期付款场景下推出的功能。开通华为支付帐号的用户，签约代扣协议后，商户会按照约定的代扣规则发起扣款。如用户取消周期付款业务，支持用户解约。
    * 移动支付移动支付是指商户在移动端APP中集成华为支付收银台功能，轻松实现线上收款。开通华为支付帐号的用户，在商户APP消费时，可以跳转至华为支付收银台，支付完成后自动返回商户支付结果页。支持银行卡快捷、支付账户余额等支付工具。
    * 手机网页支付商户手机浏览器网页集成华为手机网页支付（H5）功能后，支付全流程在商户页面内完成，支持银行卡快捷、支付账户余额等支付工具，用户可以轻松便捷的完成付款。 开通华为支付帐号的用户，在商户手机浏览器网页消费时，可以跳转至华为支付H5收银台，支付完成后自动返回商户支付结果页。
    * 电脑网页支付商户电脑端网页接入华为支付Web收银台后，支持银行卡、华为钱包余额、网银支付等多种支付工具，用户可以轻松便捷的完成付款。 开通华为支付帐号的用户，在商户电脑浏览器网页消费时，可以跳转至华为支付Web收银台，支付完成后自动返回商户支付结果页。
    * 协议支付用户在发起支付时，不需开通网银，只需提供银行卡卡号、户名、手机号码等信息，银行验证手机号码正确性后，将动态口令发送到用户的手机上，用户输入正确的手机动态口令，即可完成支付，使用门槛低，操作便捷。 协议支付属于通道类支付产品，适用于所有线上支付场景，适合有开发能力的商户或者服务商。
    * 网银支付用户在商户平台网站上支付时，可以选择付款银行并跳转至网上银行界面，完成后续支付流程。网银支付支持个人网银或者企业网银，适用于商户网站线上支付场景。
