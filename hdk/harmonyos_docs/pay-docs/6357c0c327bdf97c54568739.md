# 支付账户提现

## 1.操作支付账户提现

您可以在登录华为支付商户平台后，进入【交易中心】->【资金管理】->【支付账户】页面点击"提现"，根据页面提示操作将支付账户余额提现至结算账户。

若配置提现申请审核，所有审核人审核通过后华为支付商户平台开始执行提现操作。请审核人登录华为支付商户平台，进入【商户中心】->【审核】->【审核记录】选择待审申请进行审核。[配置提现审核](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-peizhishenhe-0000002188151740)。

## 2.无法操作提现

您可以按以下原因排查：

(1)商户状态是否异常：若商户被冻结，请您先申请[商户号解冻](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-shanghuhaojiedong-0000001902584294)后再操作提现。

(2)提现金额超过当前账户可提现金额：账户可用余额包含可提现余额，支付账户留存金额（仅针对设置支付账户留存金额的商户），仅支持提现可提现余额。

支付账户留存金额可以进入【账户中心】->【账户设置】->【支付账户信息】页面查看。

## 4.下载提现记录

您可以在登录华为支付商户平台后，进入【交易中心】->【资金管理】->【支付账户】或【交易中心】->【交易管理】->【支付交易】页面选择交易时间范围后，选择"交易类型"为"提现"点击"查询"及"下载"，前往下载中心下载支付账户提现记录明细。
> 注意
>
> 目前华为支付商户平台预设角色仅超级管理员拥有支付账户明细下载权限，如需添加该下载权限，[请新增自定义角色](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-xinzengjuese-0000001264819165)。

## 6.支付账户提现常见问题

**（1）支付账户提现多久到账？**

请在提现发起当天1-3个工作日留意资金到账情况，节假日受央行系统影响，具体到账时间请以银行为准。

**（2）提现是否收取手续费** **？**

目前从支付账户提现至结算账户不收取手续费。

**（3）提现是否有限额** **？**

目前从支付账户提现至结算账户没有限额。

**（4）支付账户界面无下载按钮，如何处理？**

请登录华为支付商户平台，进入【账户中心】->【账户设置】->【操作员信息】页面查询您的角色信息，非超级管理员角色无支付账户明细下载权限。如需添加该下载权限，请联系超级管理员[新增自定义角色](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-xinzengjuese-0000001264819165)。
