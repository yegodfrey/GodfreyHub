# 新增特约商户入网指引

若服务商处于业务需求，需要多人登录操作特约商户进件时，您可以在【账户中心】->【账号管理】->【角色权限设置】页面查看系统角色的商户平台对应操作权限，也可新增、编辑自定义角色并赋予该角色对应的华为支付商户平台操作权限，具体操作指南请查看[自定义角色权限新增](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-xinzengjuese-0000001264819165)。（温馨提示：添加员工账号后，员工需要配合完成激活，激活成功后方可使用）

服务商可通过以下3种方式之一操作新增特约商户：

方式一：服务商超级管理员登录华为支付商户平台后，进入【商户中心】->【特约商户管理】页面选择**直接添加**商户方式，根据页面提示完成子商户新增。

主要分为4步：

申请商户管理员账号->填写并上传特约商户信息，提交入网申请->特约商户激活管理员账户并完成小额打款认证->联系特约商户签署协议。

具体操作指南请查看[特约商户入网指引](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-xinzengteyueshanghu-0000001768008749)。

方式二：服务商超级管理员登录华为支付商户平台后，进入【商户中心】->【特约商户管理】页面选择**邀请商户**添加方式，通过链接邀请特约商户自行填写资料申请入网。

主要分为4步：

填写商户名生成邀请链接->复制链接并发送特约商户->特约商户授权登录华为支付商户平台填写资料提交入网申请->完成账户验证签署协议开户。具体操作指南请查看[特约商户入网指引](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-xinzengteyueshanghu-0000001768008749)。

方式三：服务商进行API接口对接，批量传送特约商户信息。

主要分为2步：

填写上传特约商户信息，提交入网申请->华为支付审核通过后，特约商户激活管理员账户并完成账户验证签署协议开户。具体操作指南请查看[特约商户入网指引](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-xinzengteyueshanghu-0000001768008749)
> 注意
>
> 不可用服务商管理员的华为账号登录。否则将有报错提示"该华为账号已有商户号，且登记的超管信息与待激活超管信息不一致"。
