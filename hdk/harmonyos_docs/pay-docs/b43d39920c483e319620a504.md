# 服务商如何提交申请

服务商与特约商户的关系：服务商作为华为支付与特约商户之间的中介。  

#### 一、登录华为支付商户服务平台

1.平台登录

* 登录[华为支付商户平台](https://petalpay-merchant.cloud.huawei.com)。若登录有疑问参见 [注册与登录](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-zhucezhanghao-0000001251128459)

2.管理员创建

* 登录后，根据页面提示完成商户超级管理员注册。该账号拥有以下权限：

  - 服务商号全生命周期管理

  - 服务商日常重要管理信息与资金操作权限（如充值、提现、接收通知、修改服务商信息、代特约商户入网等）

![](https://media:301781572807228524)  
1. 同一个华为账号下，所有商户号的超级管理员实名信息须为同一自然人
2. 超级管理员身份证号和姓名将用于安全验证，请确保信息准确无误。
3. 身份核验：您需具备以下任一身份：
   * 商户法定代表人
   * 授权经办人（须持有[《业务办理授权函》](https://media:301781572810117542)）

若身份不符或需变更超级管理员，请立即：退出当前账户，使用法人或者授权经办人的华为账号重新登录。

|模块|内容说明|

#### 五、签署协议

服务商管理员在银行账户验证成功后，需要完成在线协议签署。只需点击"请签署协议"，然后在弹出的协议窗口中点击"同意签署"即可完成签署。协议签署后，系统将实时开通商户号，并通过短信和邮件发送通知。生效的协议可在【商户中心】-【协议管理】中查看。若拒绝签署相关协议，将导致商户号开通失败，请您务必确认后再进行操作。
