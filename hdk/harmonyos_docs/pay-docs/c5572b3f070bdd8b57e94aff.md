# 华为支付服务商合作协议

<br />

1．关于我们

华为支付服务技术与功能 (以下合称为"华为支付") 由花瓣支付（深圳）有限公司（以下简称"我们"或"华为支付"）提供与运营。

本合作协议为你注册成为华为支付服务商，接受商户的委托为商户接入及使用华为支付达成的有效契约，协议中的"你"与"服务商"均指任何注册成为华为支付服务商的法人或其他组织（商业银行及非银行支付机构除外）。

<br />

2．协议构成、目的及确认方式

本服务商合作协议及附属协议、《[华为账号用户协议](https://id1.cloud.huawei.com/AMW/portal/agreements/userAgreement/zh-cn_userAgreement.html?version=china&countryCode=cn&reqClientType=2088)》、《[华为支付商户服务协议](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-shanghuxieyi-0000001611449133)》、《[华为支付服务商服务及技术管理规范](https://petalpay-merchant.cloud.huawei.com/help/contract#/)》及相应的隐私声明，以及华为支付页面展示的单项协议或规则、操作提示 (以下合称为"本合作协议") 是你注册成为华为支付服务商所依据的条款，不可分割，需同时遵守。

你需认真阅读、充分理解本合作协议各条款，特别是粗体标注的重点提示内容，你应按照本合作协议约定的服务方式、使用规则使用华为支付，并遵守各项风险控制措施及其他重要条款。

你通过页面点击确认同意或其他方式确认同意，即视为你已同意与我们达成具有法律约束力的协议；若你不接受本合作协议，请立即退出并终止后续操作。

各方基于平等自愿原则达成本合作协议。

3．注册资格

你应保证具备符合法律法规的经营、签署及履行本合作协议所需各项授权、证照、批准和资质，并保持你提供的联系方式畅通。

你应充分熟悉华为支付技术方案及商户管理要求，并具备符合法律法规规定的安全规范及信息保护能力，能够为商户生产、维护相关软件和信息系统提供足够的技术支持。

你注册成为华为支付服务商不视为你与华为支付达成任何代理关系，你不得在其任何宣传、市场、销售等活动或资料、文件中声称或误导其他人相信你是华为支付的代理或独家代理。

在注册成为华为支付服务商的同时，你需持有华为账号并签署《华为支付服务商合作协议》，你的华为支付商户号具备正常结算功能，方可通过华为账号及密码登录华为支付服务商平台访问或使用各项内容及功能。

4．定义

华为支付：指我们提供的非银行支付服务，依托计算机信息系统提供的货币资金移转或其他授权服务，包括但不限于余额支付、快捷支付、聚合收银台等。

服务商：指接受商户委托，为商户生产、维护相关软件和信息系统，并帮助商户接入华为支付。

商户：指通过服务商与华为支付进行系统对接，并与华为支付直接签署《华为支付商户服务协议》商品或服务的经营者。

华为支付商户平台（以下简称"商户平台"）：指由我们提供和维护的服务商管理软件系统（https://petalpay-merchant.cloud.huawei.com/agent），你应通过该平台提交相关信息和材料，注册成为服务商；注册成功后可通过该平台访问或使用服务商的各项内容及功能，具体以该平台实际提供的服务为准。你使用商户平台，还应阅读并遵守《华为支付商户服务协议》。

华为支付商户号：指你通过我们的身份认证后，我们根据你的真实意愿为你配置的支付账户，用于记录预付交易资金余额、凭以发起支付指令和反映交易明细信息。华为支付商户号将与你提供的同名合法银行账户绑定，我们根据你的指令及本合作协议约定对你的银行账户做相应资金扣划和归集。你使用华为支付商户号的，还应阅读并遵守《华为支付商户服务协议》。

用户：指使用华为支付向商户购买商品或服务的消费者。

华为支付服务手续费（费率）：指商户通过华为支付产生的实际交易金额或成交笔数而应向华为支付支付的服务手续费（费率）。

佣金：你根据华为支付的技术方案、技术标准，为商户提供接入华为支付系统的开发、技术性升级等技术支持服务，华为支付将按照约定向你的华为支付商户号支付相应的佣金。

5．合作内容

1）服务商应获得商户的合法书面委托及授权，签署相应的服务协议，可向商户提供与华为支付对接系统的开发、维护和升级技术服务。

2）服务商应确保对接系统符合华为支付的技术方案、技术标准和接入技术规范，并提供能确保商户规范、正常使用华为支付的技术服务。

3）服务商按照商户管理规范对商户证照进行预先审核，并按华为支付要求收集商户证照资料，由华为支付对商户证照资料和资质进行最终审核。

4）服务商应协助商户按华为支付商户管理标准提交相应的商户注册、功能配置、运营活动、协议传递等申请，所有申请材料需经华为支付审批后方可开通。

5）基于市场环境变化，我们有权对收取商户的华为支付服务手续费（费率）进行调整，经我们通知商户之日起，按调整后的费率执行。

6）华为支付按照与服务商签订的服务协议约定，向服务商的华为支付商户号结算相应的佣金。服务商需要按照国家法律法规，开具合法有效的增值税专用发票给华为支付，如因发票不合格，造成华为支付不能抵扣或税前列支的税务损失及相关罚款滞纳金等，需要服务商全额赔偿。

3）你可以在商户平台中查看、下载你的账单，包括佣金、账单等。

4）你确认并同意，佣金以商户平台核准记录为准，你与我们的对账数据出现不一致时，以我们系统记录的对账数据为准。

c.对需传输至本公司支付系统的数据进行截留、篡改或破译；

d.从事商户资质审核、受理协议签订、资金结算、收单业务交易处理、风险监测、受理终端（网络支付接口）主密钥生成和管理、差错和争议处理等核心业务；
