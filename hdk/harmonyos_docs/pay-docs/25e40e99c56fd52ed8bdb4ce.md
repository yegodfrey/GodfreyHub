# 子商户入网信息查询

平台类商户超级管理员可登录华为支付商户平台查询其下已成功入网平台子商户信息，进入【商户中心】->【平台子商户管理】，点击"查看详情"按钮查看平台子商户的基本信息、营业信息、法定代表人信息、业务联系人信息、经营信息。
