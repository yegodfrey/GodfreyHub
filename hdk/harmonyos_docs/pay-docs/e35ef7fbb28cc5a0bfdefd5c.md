# 证书及密钥管理

## 什么是商户证书

商户证书是指由商户申请的，包含商户的商户号、公司名称、公钥信息的证书。

[商户证书更多相关信息及操作](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/certificate-preparation-0000001596094962#section1557292604420)。

## 如何上传商户证书

您可以在登录华为支付商户平台后，进入【商户中心】->【证书管理】->【上传商户证书】页面，选择签名方式后，点击"上传商户公钥"上传商户证书。

[关于商户证书生成及使用的详细说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/certificate-preparation-0000001596094962#section1557292604420)。

## 什么是华为支付证书

华为支付证书是指用于校验华为支付给商户业务系统发送的信息，如支付结果信息等。

[华为支付证书更多相关信息及操作查看](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/certificate-preparation-0000001596094962#section1557292604420)。

## 如何下载华为支付证书

您可以在登录华为支付商户平台后，进入【商户中心】->【证书管理】->【华为支付证书】页面，点击"下载"下载华为支付证书。

[更多华为支付证书生成及使用说明详情查看](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/certificate-preparation-0000001596094962#section1557292604420)。
