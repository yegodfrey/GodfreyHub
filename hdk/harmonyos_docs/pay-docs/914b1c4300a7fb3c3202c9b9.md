# 申请流程

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4f/v3/A2WpyRLfT7KP6JCY8MfueA/zh-cn_image_0000002608461363.png?HW-CC-KV=V1&HW-CC-Date=20260923T100700Z&HW-CC-Expire=31536000000&HW-CC-Sign=3C5DD751A76BA656DE653B94D0C957F472CBDEAD53463580D0E94166E538951E "点击放大")

商户申请接入华为支付商户平台主要分为6个步骤：

1. **注册/登录华为账号**

   **访问[华为支付商户平台](https://petalpay-merchant.cloud.huawei.com)**，点击"授权华为账号登录"
   * **未注册用户**：按页面提示完成华为账号注册后，点击"进入商户平台"
   * **已注册用户**：直接输入账号密码登录后点击"进入商户平台"

   **温馨提示：**一个华为账号可以申请多个商户号。

2. **注册超级管理员，提交入网资料** 。

   （1）在线注册超级管理员账号

   （2）选择合作身份（商户/平台类商户/服务商）

   （3）填写并提交以下基本信息：营业执照信息、法人身份证信息、结算账户信息、经营信息等，根据页面提示填写相应的信息。

   （4）等待审核（1-2个工作日），审核结果通过短信、邮件告知超级管理员

   **温馨提示：**
   * 若超级管理员非法人，须提供《业务办理授权函》


   * 合作身份选择指南[请点击这里](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-hezuoshenfen-0000001725918617)查阅。

3. **完成银行账户验证**
   * 资料审核通过后，超级管理员将收到短信/邮件通知
   * 按要求完成银行账户验证，确认账户有效性及开户意愿

   **温馨提示**：若商户的主体类型为"政府事业单位"，无需完成银行账户验证。

4. APPID管理员授权（如适用）
   * **适用场景**：商户/平台类商户/特约商户填写的APPID开发者与商户主体不一致
   * **流程**：资料审核通过后，系统自动向APPID管理员发起商户号关联申请
   * **操作**：管理员在AppGallery Connect平台完成授权

   **温馨提示**："APPID管理员授权"环节，与"银行账户验证"环节并行，不分先后顺序。

5. **签署协议和完成开户** 。
   * 银行验证成功后，超级管理员在线签署协议
   * 系统实时自动完成开户操作
   * 至此商户入网流程全部完成

6. **联调准备** 。

   入网成功后即可进入联调环节，具体操作指南[请点击这里](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-liantiao-0000001774414745)查阅。
