商户证书 商户证书是指由商户申请的，包含商户的**商户号、公司名称、公钥信息** 的证书。 华为支付支持两种证书： 一、商户可以自行生成公私密钥证书，私钥由商户保管，公钥文件为pem格式通过商户平台上传。 二、由证书授权机构 (Certificate Authority，简称CA)签发颁发的证书。 商户将公钥证书提交到商户平台后才能获得证书序列号，证书序列号包含在请求HTTP请求体的authId中。
