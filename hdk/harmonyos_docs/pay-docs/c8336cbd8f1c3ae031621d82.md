# 支付账户开通与查询

#### 1.支付账户介绍

支付账户是指您通过我们的认证后，由我们根据您的真实意愿为您开立的支付账户，用于记录预付交易资金余额、凭以发起支付指令和反映交易明细信息。

<br />

#### 2.开通支付账户

若您在入驻时未开通支付账户，可以登录华为支付商户平台后，进入【账户中心】-\>【账户设置】-\>【支付账户信息】页面，根据页面选择上传法人意愿开户视频或者小额打款认证其中一种方式申请开通支付账户。

#### 3.查询支付账户信息

您可以在登录华为支付商户平台后，进入【账户中心】-\>【账户设置】\>【支付账户信息】页面查看具体支付账户信息。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250915110844.10608948776730561830491899310966:50001231000000:2800:515299EF3FD29EBCEFCE86637C88AA7251B54C35D4D6545C60D958B72D3DC1F6.png "点击放大")

<br />

#### 4.查询支付账户出入金记录

您可以在登录华为支付商户平台后，进入【交易中心】-\>【资金管理】-\>【支付账户】页面，根据交易时间、类型、订单号、收支金额、查询支付账户出入金记录。
