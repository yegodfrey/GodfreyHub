请求参数 **Method** | **URI** | **Description**  
---|---|---  
GET | /payment/api/merc/v1/refundOrder/query/{orderType}/{orderNo} | 查询商户订单状态  
**Name** | **Mandatory** | **Type** | **position** | **Description**  
---|---|---|---|---  
orderType | M | int | path | 订单类型：0-系统订单号（可以交易、退款订单号），1-商户订单号  
orderNo | M | String | path | 当orderType为1时，仅支持查询72小时内的交易  
mercNo | M | String | query | 商户号  
PayMercAuth | M | String | header | 商户鉴权信息
