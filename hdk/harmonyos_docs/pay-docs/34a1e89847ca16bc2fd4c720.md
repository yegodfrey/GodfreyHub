# 华为支付业务收费标准

华为支付是持牌机构花瓣支付（深圳）有限公司为您及您的客户提供的货币资金转移服务，包括余额支付、银行卡支付、手机闪付、云闪付等支付方式 。

按照行业分类，现将支付服务收费标准公布如下：

|-------------------|------|
|**行业**|**费率**|
|网络媒体/计算机服务/游戏等虚拟商品类|单笔1.0%|
|其他类|单笔0.6%|

1.针对公益、民生缴费、公共事业类商户将按照相关行业政策优惠定价。

2.公示的费率仅供参考，具体费率以商家签约为准。
