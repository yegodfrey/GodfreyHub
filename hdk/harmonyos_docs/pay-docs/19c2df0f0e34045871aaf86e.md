# 分账交易查询及下载

#### 1.分账交易明细查询

您可以在登录华为支付商户平台后，进入【交易中心】-\>【交易管理】-\>【分账交易】页面，根据交易时间、订单号、商户号、分账状态查询分账明细。订单查询最长时间为31天。

若为分账分出方，可选择分账分出方明细查询

若为分账分入方，可选择分账分入方明细查询。

#### 2.分账交易明细下载

您可以在登录华为支付商户平台后，进入【交易中心】-\>【交易管理】-\>【分账交易】页面，根据交易时间、订单号、商户号、分账状态查询后下载，前往下载中心将分账交易明细下载至本地。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250915110851.97322287661004281544771198430989:50001231000000:2800:7D813514B890F12B2510000E7307CD595EA70D544D928936B0B8972C34C46FB6.png "点击放大")

<br />

#### 3.分账失败交易查询

您可以在登录华为支付商户平台后，进入【交易中心】-\>【分账管理】-\>【重新分账处理】页面，根据交易时间、商户订单号查找分账失败的记录，订单查询时间段最长为31天。
