# 交易明细及对账管理

华为支付商户平台支持平台商查询子商户支付交易明细，您可以在登录华为支付商户平台后，进入【交易中心】->【交易管理】->【支付交易】页面，选择您要查询子商户号、交易时间、订单号、交易类型、交易状态、交易金额范围、，点击"查询"子商户的支付交易明细。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c5/v3/6hrezilKS2W1dbwXweSv8A/zh-cn_image_0000002526154852.png?HW-CC-KV=V1&HW-CC-Date=20260921T064300Z&HW-CC-Expire=31536000000&HW-CC-Sign=888AE684FF91A914E254DF3F5F5BC217272D162DD66DDFACCCF94D5FF78357CE "点击放大")

华为支付商户平台支持平台商查询子商户支付对账单，您可以在登录华为支付商户平台后，进入【交易中心】->【对账管理】->【支付交易对账单】页面，选择您要查询子商户号及其对账单时间范围，点击"请求对账"，系统会将该段时间的对账单显示在页面下方。可支持对账的时间范围为1天到31天。
