# 商户注销

注销商户要由超级管理员进行注销操作。若您需要注销商户，您可以在登录[华为支付商户平台](https://petalpay-merchant.cloud.huawei.com)后，进入【账户中心】-\>【商户主体信息】-\>【商户号设置】页面，选择"注销商户"，根据页面提示输入短信验证码后进行商户注销操作。

温馨提示：

存在以下情况将无法操作注销账户：

（1）有未完成的交易（如资金在途交易）；

（2）账户内有余额；

（3）商户是否存在客诉问题，客诉处理状态需为已完成；

（4）手续费费用结算，未结清的，需先结清；

（5）涉及账户有冻结款项的，待解决冻结事项后再申请；

如以上情况均已完成后，且经过6个月内无交易观测期限，您可进行注销商户号操作，即注销商户的收单功能和支付账户功能。您提交注销申请后，一般在1-2个工作日内完成审核，审核完成后会发送短信、邮件通知超级管理员。  
![](https://media:201774595417371610)  
注销商户后您将无法使用华为支付服务，同时贵单位和华为支付的合同也会被解除。请您再次确认并核对该商户信息！

若您的商户号处于冻结状态，请先行完成[解冻操作](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-shanghuhaojiedong-0000001902584294)后，再申请注销商户号。
