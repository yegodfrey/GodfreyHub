# 找回华为支付商户号

**第一步：授权华为账号登录**

申请人打开[华为支付商户平台](https://petalpay-merchant.cloud.huawei.com/)，授权华为账号登录，若还没有注册华为账号，可以根据页面指引注册华为账号。注册成功后即可授权登录华为支付商户平台。

**第二步：点击"找回商户号"**

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250915110835.41657592163031098693154087895144:50001231000000:2800:A33FAB77FCA26DA0CBC5FAA2E1839569E30EF2E6752B8A276D9AB7B2C4416CD4.png "点击放大")

**第三步：根据页面提示进行新超级管理员注册申请**

若您授权登录华为支付商户平台华为账号非任何商户号超级管理员角色，您需进行新超级管理员注册。根据页面提示填写相关信息并提供身份证影像证件。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250915110835.33970758421357708293592315673492:50001231000000:2800:39A11D10C8398BE752F35EE5262D135012740949B69B02131CB35B926525B30D.png "点击放大")
> 注意
>
> 新超级管理员信息必须与上传的管理员信息变更函中填写的新超管信息（姓名、身份证号、手机号、邮箱号）保持一致。

**第四步：填写相关信息选择验证方式**

根据页面提示填写需要找回商户号信息及其绑定结算银行账号信息，并选择验证方式后，提交申请。

华为支付商户平台支持通过如下验证方式找回商户号，您可结合自身实际情况选择其中之一操作找回商户号。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250915110835.71661346363750489719288107112589:50001231000000:2800:EAF2EB60CDB609409D05DF7FFD52ADCC092BCDBEB92709291CF3F45E2D4ACDF5.png "点击放大")

**小额打款验证：**

该方式华为支付将向商户号绑定的结算银行账号打款，您需回填打款金额，金额验证通过后，可成功找回商户号

**管理员信息变更函：**

该方式您需上传加盖公章的《管理员信息变更函》，人工审核通过后，可成功找回商户号

管理员信息变更函填写要求：变更函模板可参考[《管理员信息变更函》](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250915110835.83896558598341201161439666745991:50001231000000:2800:23FCE272DA443BA31B1BAB507BEA6C1F372328AEEB74DFB0D103E727A503E0BE.docx?needInitFileName=true)，请打印该变更函填写变更的信息，企业类型请加盖公司公章，个体户类型请经营者签字并加按手印。
