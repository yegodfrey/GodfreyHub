# 平台子商户如何提交申请

平台类商户与平台子商户的关系：

平台类商户是指面向为商品交易或服务提供线上撮合与管理平台的商户，华为支付为其提供的支付与结算解决方案。平台接入华为支付后，平台上的商家作为"平台子商户"入驻华为支付。平台类商户负责子商户的管理，并由平台类商户的超级管理员登录华为支付商户平台，协助平台子商户完成入网。

<br />

平台子商户入网支持通过【平台类商户直接添加】或【平台类商户发送链接邀请子商户】两种方式来提交申请入网，请根据自身情况选择。  

#### 直接添加方式

#### 步骤1：平台登录

* 平台类商户超级管理员登录[华为支付商户平台](https://petalpay-merchant.cloud.huawei.com)。进入【商户中心】-【商户管理】-【平台子商户管理】页面，点击【直接添加商户】，代平台子商户提交入网申请。若登录有疑问参见 [登录常见问题](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-zhucezhanghao-0000001251128459)。

![](https://media:301781572796696453 "点击放大")  

#### 步骤2：申请商户超级管理员账号

平台子商户超级管理员创建

* 进入新增页面后，根据页面提示完成子商户超级管理员注册。该账号拥有以下权限：

  - 商户号全生命周期管理

  - 商户日常重要管理信息与资金操作权限（如充值、提现、接收通知、修改商户信息等）

![](https://media:301781572796724454)  
1. 同一个华为账号下，所有商户号的超级管理员实名信息须为同一自然人
2. 超级管理员身份证号和姓名将用于安全验证，请确保信息准确无误。
3. 身份核验：您需具备以下任一身份：
   * 商户法定代表人
   * 授权经办人（须持有[《业务办理授权函》](https://media:301781572803286499)）

若身份不符或需变更超级管理员，请立即：退出当前账户，使用法人或者授权经办人的华为账号重新登录。

#### 链接邀请

平台类管理员登录[华为支付商户平台](https://petalpay-merchant.cloud.huawei.com)，进入【商户中心】-\>【平台子商户管理】页面选择链接邀请子商户方式，发送链接给子商户自行提交入网申请。具体操作步骤如下：（若登录有疑问参见 [登录常见问题](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-zhucezhanghao-0000001251128459)。）  

#### 步骤1：生成邀请链接

平台类商户管理员登录华为支付商户平台后，进入【商户中心】-\>【平台子商户管理】页面，点击"新增商户"，选择"邀请商户添加"。填写相关信息后，系统将生成链接邀请。

![](https://media:301781572802338490 "点击放大")

![](https://media:301781572802674491 "点击放大")  
![](https://media:301781572802843492)  
商户名用于链接中的备注，最终将以受邀商户填写的真实商户名为准；

请在一个月内点击链接并完成超级管理员信息的填写，否则将会失效。  

#### 步骤2：发送邀请链接子商户

平台类商户管理员进入【商户中心】-\>【平台子商户管理】页面，找到已生成的邀请链接，将其复制并发送给子商户。

![](https://media:301781572802917493 "点击放大")  

#### 步骤3：子商户确认接受邀请

子商户收到邀请链接后，点击链接并授权使用其华为账号登录华为支付商户平台，确认接受平台邀请。  
![](https://media:301781572802977494)  
1.若子商户尚未注册华为账号，点击"授权华为账号登录"，根据页面提示申请华为账号后再点击"进入商户平台"。

2.若子商户已注册华为账号，请登录华为账号后，点击"进入商户平台"。

温馨提示：一个华为账号可以申请多个商户号。

![](https://media:301781572803090495 "点击放大")

![](https://media:301781572803144496 "点击放大")

![](https://media:301781572803210497 "点击放大")

#### 步骤4：子商户自行提交资料申请

子商户接受邀请后，根据系统提示完成子商户管理员注册、子商户申请资料填写并提交、银行账户验证、签署协议完成开户，具体操作指南[请点击这里](#section6562121910312)查阅。  
![](https://media:301781572803240498)
