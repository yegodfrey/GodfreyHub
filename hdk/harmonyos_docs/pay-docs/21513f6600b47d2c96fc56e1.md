# 特约商户如何提交申请

服务商与特约商户的关系：服务商作为华为支付与特约商户之间的中介。

特约商户入网支持通过【服务商直接添加】或【服务商发送链接邀请特约商户】两种方式来提交申请入网，请根据自身情况选择。

## 直接添加方式

### 步骤1：平台登录

服务商超级管理员登录**[华为支付商户平台](https://petalpay-merchant.cloud.huawei.com)，** 进入【商户中心】->【特约商户管理】页面选择**直接添加** 商户方式，代特约商户提交入网申请。若登录有疑问参见 **[登录常见问题](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-zhucezhanghao-0000001251128459)**

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/79/v3/tFC2QvEFQjqNB1LgTC7aXQ/zh-cn_image_0000002608461467.png?HW-CC-KV=V1&HW-CC-Date=20260909T160111Z&HW-CC-Expire=31536000000&HW-CC-Sign=AE34E61DA5986ABAD45933EB31149A9D31DCBA822C57D70B322EE963AE5C6921 "点击放大")

### 步骤2：申请特约商户超级管理员账号

* 进入新增页面后，根据页面提示**完成特约商户超级管理员** 注册。该账号拥有以下权限：

  - 商户号全生命周期管理

  - 商户日常重要管理信息与资金操作权限（如充值、提现、接收通知、修改商户信息等）

> 注意
>
> 1. 同一个华为账号下，所有商户号的超级管理员实名信息须为同一自然人
> 2. 超级管理员身份证号和姓名将用于安全验证，**请确保信息准确无误**。
> 3. **身份核验** ：您需具备以下任一身份：
>    * 商户法定代表人
>    * 授权经办人（须持有**[《业务办理授权函》](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260616092015.12105116489682012765298570740258:50001231000000:2800:18CD4FDDB7EF89D95B4464369DED510CBEFA9D8D20C56926E58D523C715D0FEB.docx?needInitFileName=true)** ）
>
>      若身份不符或需变更超级管理员，请立即：退出当前账户，使用法人或者授权经办人的华为账号重新登录。
