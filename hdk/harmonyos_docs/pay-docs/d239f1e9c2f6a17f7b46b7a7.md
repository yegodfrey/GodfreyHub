响应参数 **Name** | **Mandatory** | **Type** | **Description**  
---|---|---|---  
resultCode | M | String | 结果码（例如：000000，代表成功）  
resultDesc | M | String | 结果描述  
nspResponse | O | NspBaseResponse | 文件下载信息  
NspBaseResponse文件下载信息 **Name** | **Mandatory** | **Type** | **Description**  
---|---|---|---  
headers | M | Map<String, String> | 下载鉴权信息  
method | M | String | 调用方法  
url | M | String | 下载文件URL  
objectId | M | String | 文件objectId
