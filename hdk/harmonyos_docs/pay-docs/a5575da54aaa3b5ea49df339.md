# 法定代表人信息修改

修改法定代表人信息要由华为支付商户平台超级管理员进行修改。

您可以在登录华为支付商户平台后，进入【账户中心】->【账户设置】->【商户主体信息】->【法定代表人信息】页面，点击页面右上角"修改资料"修改法定代表人信息，完成修改后点击"提交"。

修改资料申请提交后，审核结果将通过短信、邮件通知超级管理员。
