# 支付账户余额

## 1.支付账户余额介绍

支付账户余额包含可提现余额，支付账户留存金额（仅针对设置支付账户留存金额的商户）。

可提现余额指支持提现至结算账户的余额。

支付账户留存金额为了保证商户有足够的金额用于退款，商户支付账户设置一定金额的留存金额。如果支付账户余额低于该留存金额，结算款要优先补足留存金额。

## 2.查询支付账户余额

您可以在登录华为支付商户平台后，进入【交易中心】->【资金管理】->【支付账户】页面查看支付账户可用余额。

账户可用余额包含可提现余额、支付账户留存金额。

## 3.支付账户余额提醒功能

商户开通支付账户后，华为支付支持商户根据业务需求（如避免支付账户退款余额不足导致退款失败场景），登录华为支付商户平台设置支付账户提醒余额，当支付账户可用余额低于商户自己设定的提醒金额时，将通过短信、邮件通知超级管理员，以便商户及时完成支付账户充值，保证支付账户余额充足。

## 4.开通支付账户余额提醒

您可以在登录华为支付商户平台后，进入【账户中心】->【账户设置】->【支付账户信息】页面根据业务需求设置余额提醒值，若开通账户余额提醒服务后，当账户余额不足提醒余额时，将发送提醒。
> 注意
>
> 余额提醒金额仅支持整数，每次修改需间隔7天

## 5.查看支付账户留存金额

您可以在登录支付账户留存金额设置金额可以进入【账户中心】->【账户设置】->【支付账户信息】页面查看。

## 6.设置支付账户留存金额阈值

若您开通支付账户后，为了保证有足够金额用于退款，您可以对支付账户设置一定金额的留存金额，此部分不能够用于提现，如果支付账户余额低于该留存金，结算款要优先补足留存金额。

您可以在登录华为支付商户平台后，进入【账户中心】->【账户设置】->【支付账户信息】页面设置支付账户留存金额阈值。
> 注意
>
> 华为支付商户平台仅支持超级管理员修改设置支付账户留存金额阈值。

## 为什么无法修改支付账户留存金额

若您的商户号处于冻结状态，请先解冻商户，才可修改支付账户留存金额。您可以进入【账户中心】->【账户设置】->【商户主体信息】->【商户号设置】去申请解冻。
