# 特约商户AppID绑定

特约商户AppID关联需由服务商发起，AppID关联指引[服务商下特约商户AppID关联](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-appidguanli-0000001757041165#section77111153485)请查看。

特约商户AppID的关联主要分为3步：

第1步：服务商向特约商户发起绑定申请；

第2步：特约商户登录华为支付商户平台确认绑定；

第3步：AppID管理员登录[AppGallery Connect 网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)授权。
