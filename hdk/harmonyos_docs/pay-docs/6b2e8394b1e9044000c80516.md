# 支付交易对账单查询及下载

## 1.支付交易对账单查询

支付交易对账单：仅展示该商户号下成功的交易记录。

您可以在登录华为支付商户平台后，进入【交易中心】->【对账管理】->【支付交易对账单】页面，选择您需要查询的对账单时间范围，点击"请求对账"，系统会将该段时间的对账单显示在页面下方。可支持对账的时间范围为1天到31天。

## 2.支付交易对账单部分字段说明

|------------|------------------|----------------|
|**字段信息**|**交易类型对应说明**||
|**字段信息**|**收单（COLLECTION）**|**退款（REFUND）**|
|**订单金额（元）**|实际收单金额（交易金额+优惠金额）|实际操作的退款金额|
|**交易金额（元）**|用户实际支付的金额|用户账户实际收到的退款金额|
|**优惠金额（元）**|营销账户出资的营销资金|营销账户实际收到的退款金额|
|**手续费金额（元）**|订单金额*支付方式对应的手续费率|订单金额*支付方式对应的手续费率|

## 3.支付交易对账单下载

您可以在登录华为支付商户平台后，进入【交易中心】->【对账管理】->【支付交易对账单】页面，选择您需要下载的对账时间范围，点击"请求对账"，系统会将该段时间的对账单显示在页面下方。点击对账记录右边的"下载"即可将支付交易对账记录保存至本地。可支持对账的时间范围为1天到31天。
