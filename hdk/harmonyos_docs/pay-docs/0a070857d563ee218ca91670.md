# 配置共享经营场所

共享经营场所适用于您希望将您的App/元服务共享给所有特约商户使用的情况下配置。

服务商商户超级管理员登录华为支付商户平台后，进入【账户中心】-\>【商户经营信息】-\>【共享经营场所】页面，配置共享经营场所。

<br />

服务商可通过以下2种方式之一配置共享经营场所：

方式一：点击"去配置"跳转到经营信息修改页面，新增配置共享经营场所。
