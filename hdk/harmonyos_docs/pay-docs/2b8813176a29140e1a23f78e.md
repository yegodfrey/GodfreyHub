# 特约商户的超级管理员激活账户验证

|模块|内容说明|
|:-------------:|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------:|
|**激活特约商户与账户验证**|关键要求与操作指引|
|**① 验证触发**|► 审核通过后，花瓣支付（深圳）有限公司向结算账户打**随机验证金**（精确到分） ► 政府事业单位**豁免验证**|
|**② 验证操作**|收到通知后 **72小时内**： **一、若特约商户为服务商通过直接添加方式申请，账户验证指引如下**： 1.特约商户激活超级管理员有两种方式： （1）方式1：特约超级商户管理员根据邮件通知的链接，登录华为支付商户平台，完成特约商户的激活； （2）方式2：服务商超级管理员登录华为支付商户平台，进入【商户中心】->【特约商户管理】页面，点击"复制链接发送给他人"，将激活链接发送给特约商户的管理员完成激活 2. 登录商户平台，输入**打款金额**。 **二、若特约商户为服务商通过链接邀请方式申请，账户验证指引如下**: 1. 特约商户超级管理员登录商户平台；2. 输入**打款金额** （保留2位小数）；3. 校验账户名：**花瓣支付（深圳）有限公司** ⚠️**温馨提醒** 1.特约商户激活超级管理员，登录华为支付商户平台时，**请用自身的华为账号登录** ，**不可用服务商超级管理员的华为账号登录**。否则将有报错提示"该华为账号已有商户号，且登记的超管信息与待激活超管信息不一致" 2.校验账户名：**花瓣支付（深圳）有限公司**|
|**③ 失败处置**|►每次验证仅提供2次输入验证金额的机会 ► 打款失败：若银行账户有误，可点击**【重新进入账户验证】-【修改结算账户信息】** ，修改账户后，可重新触发验证；若确认银行信息无误，则点击 **【重新进入账户验证】-【核对无误，重新进行账户认证】**触发二次打款|
|**④ 超时后果**|**若在收到通知后72小时内未操作，或两次输入验证金额均错误：** 1.当前验证流程将失败。 2.您需要重新触发验证（在页面提示剩余次数内）或： 3.申请作废当前入网申请，重新提交入网申请（若特约商户为服务商通过直接添加方式申请，则该作废申请，须由服务商登录华为支付商户平台操作）。|

**常见问题** ：特约商户超级管理员激活时报错，提示"登记的超管信息与待激活超管信息不一致"

**解决方法：**请确认登录【华为支付商户平台】的华为账号，必须为特约商户入网申请时所填写的管理员本人账号。切勿用服务商管理员账号登录操作。
