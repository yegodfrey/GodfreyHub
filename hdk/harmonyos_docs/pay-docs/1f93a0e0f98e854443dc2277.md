商户用于请求的authId字段从哪里获取 **“商户中心”- >“证书管理”->“上传商户证书”->“证书ID”**处获取。[参考证书ID](https://developer.huawei.com/consumer/cn/doc/distribution/pay-docs/petalpay_app_432_certificate_id-0000001325212393)
