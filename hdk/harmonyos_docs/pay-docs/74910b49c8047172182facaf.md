# 交易明细及对账单管理

华为支付商户平台支持服务商查询特约商户支付交易明细，您可以在登录华为支付商户平台后，进入【交易中心】->【交易管理】->【支付交易】页面，选择您要查询特约商户商户号、交易时间、订单号、交易类型、交易状态、交易金额范围、特约商户商户号，点击"查询"特约商户的支付交易明细。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250915110835.29881167005350923623130319087710:50001231000000:2800:E7B3DC50EEDD2A11C95A196513C7092BFB93614EB582711EB22F2961BDDF33BA.png "点击放大")

华为支付商户平台支持服务商查询特约商户支付对账单，您可以在登录华为支付商户平台后，进入【交易中心】->【对账管理】->【支付交易对账单】页面，选择您要查询特约商户商户号及对账单时间范围，点击"请求对账"，系统会将该段时间的对账单显示在页面下方。

可支持对账的时间范围为1天到31天。
