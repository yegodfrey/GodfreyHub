# 服务商注销

注销商户要由超级管理员进行注销操作。若您需要注销商户，您可以在登录华为支付商户平台后，进入【账户中心】-\>【商户主体信息】-\>【商户号设置】页面，选择"注销商户"，根据页面提示输入短信验证码后进行商户注销操作。

您和您所管理的特约商户存在以下情况将无法操作注销账户：

（1）存在正在进行中的交易

（2）账户内有余额

（3）存在活动营销费用

（4）涉及账户有冻结款项

如以上情况均已完成后，您可进行注销商户号操作。您提交注销申请后，一般在1-2个工作日内完成审核，审核完成后会发送短信及邮件给超级管理员。
