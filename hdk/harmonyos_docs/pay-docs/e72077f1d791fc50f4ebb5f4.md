# 风险处理

若商户号下存在待处理的风险事项（如信息未更新、证件到期等），您可以登录华为支付商户平台后，进入【账户中心】-\>【合规管理】-\>【风险处理】页面查询原因及处理。

查询列表展示商户号下执行中的功能限制，操作为处理类，表示需要配合处理的事项，请尽快处理。

若逾期未处理，将进一步加强管控。若风险原因已解除，将不在该列表展示。
