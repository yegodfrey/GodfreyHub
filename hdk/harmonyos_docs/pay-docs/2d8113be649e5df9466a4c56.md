支付交易处理：指我们作为非银行支付机构，受您委托依托计算机信息系统为您提供货币资金转移或其他授权服务，包括但不限于代收代付款项、余额支付、快捷支付、华为支付SDK等。

用户：指使用华为支付服务向您购买商品或服务的消费者。

商户：指使用华为支付服务并向用户销售商品或服务的经营者。

结算：指在用户就购买您的商品或服务的最终支付指令确认生效后，我们将交易资金记录至您的商户号，并根据本协议约定和法律法规要求，在一定周期内将交易资金划转至您指定账户的行为。

提现：指根据您的指令或本协议约定，在符合法律法规要求的前提下，我们将您华为支付账户中的资金划转至您商户号绑定银行账户的行为。

退款：指因商品或服务取消交易，将已支付款项退还至用户原付款账户的过程。

异常交易：指用户、商户在使用华为支付过程中发生的异常交易行为，包括但不限于拒付、伪卡、盗卡、伪冒交易等持卡人/支付账户持有人否认、非授权或撤销交易；无真实交易背景、与真实交易背景不相符的虚假交易，涉嫌洗钱、套现、恶意欺诈、信用卡欺诈、涉黄、涉赌等违法违规行为的可疑交易，与交易相关的投诉或纠纷等。

延迟结算/延迟转账：指我们针对您存在异常交易情形采取的风险控制措施，对您相应资金进行延迟结算；已经结算的，我们可以延迟转账到您指定银行账户和华为支付账户。对于延迟结算、延迟转账的资金，直至排除违法违规嫌疑时，我们才恢复该部分资金的结算和转账。

5.2支付服务及功能

5.2.1我们负责华为支付系统的开发、运行和管理，并确保该系统的安全性。我们按照本协议约定向您提供使用华为支付所必需的业务应用、技术接口等，您应确保自身具有足够的技术条件与环境支持与华为支付系统建立有效对接，并承担相应的软、硬件平台搭建的设备费用和通讯费用等。

5.2.2我们的支付服务包括但不限于如下场景及功能，您可以在商户平台中自行选择，您开通的功能及场景以商户平台记录为准：

a)APP/元服务支付：商户在移动端应用APP/元服务中调起华为支付模块完成的支付；

b)PC网站/H5支付：包括JSAPI支付，商户在H5页面通过JSAPI接口调起华为支付模块完成的支付；以及Native支付，商户按本协议生成支付二维码，用户扫码进行支付；

c)API支付：商户通过调用华为支付提供的专属API接口，在支付场景中向华为支付系统发起支付请求完成支付；

d)快应用/快服务支付：商户在移动端的快应用或快服务程序中提供商品或服务交易时，商户可调起华为支付模块完成支付；

e)华为支付SDK：我们为商户提供支付服务的综合支付系统技术接口，商户开通华为支付商户服务后可将华为支付SDK配置在交易页面中；

f)代付款：商户发起委托付款指令，使用华为支付将其商户号中指定金额的款项付款到商户指定的银行账户或华为支付账户；

g)代收款：您委托我们将您指定银行账户的资金划转到您的华为支付账户，或委托我们代为收取第三方向您支付的款项划转到您的华为支付账户；

h)分账服务：指您授权并委托华为支付，按照您提供的您（分账方）与您指定商户（分账接收方）约定分账规则和分账对象收款信息，由华为支付对待结算款项执行分账指令。

i)合单服务：我们依据您发起的合单指令，将多笔交易订单合为一笔，用户一次性完成付款。
