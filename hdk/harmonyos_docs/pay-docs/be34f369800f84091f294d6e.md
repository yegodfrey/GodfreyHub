# 华为支付商户号与AppID授权协议

最后更新日期：2024年6月13日

适用场景：本协议适用于华为支付商户号绑定APPID，商户须在线签署的协议文件

<br />

华为支付商户号与AppID授权绑定协议

一、关于我们

1.1 华为支付商户号与AppID授权绑定服务（以下简称"本服务"），由花瓣支付（深圳）有限公司（以下简称"我们"或"华为支付"）提供。

1.2 本协议为AppID所属主体、华为支付商户、与华为支付就华为支付商户号与AppID授权绑定达成的有效契约，协议中的"AppID所属主体"与"商户"（以下合称"各方"或"联合运营方"）指任何接入及使用华为支付的具有经营行为的自然人、法人或其他组织。

二、本协议范围、目的及确认方式

2.1 本授权绑定协议、《华为支付商户服务协议》及附属协议、单项协议或规则、操作提示(以下合称为"本协议")是各方接入及使用华为支付所依据的条款，不可分割，需同时遵守。

2.2 各方需认真阅读、充分理解本协议各条款，特别是粗体标注的涉及免除、减轻我们义务或对各方的权利限制的重点提示内容，各方应按照本协议的约定使用华为支付，并遵守各项风险控制措施。

2.3 各方通过页面点击确认同意或其他方式确认同意，即视为已完全阅读、准确理解并同意与我们达成具有法律约束力的协议，将承担相应的法律责任及法律后果；若不接受本协议和/或无法准确理解本协议内容，请立即退出并终止后续操作。

2.4 各方基于平等自愿原则达成本协议。

二、定义

2.1 应用程序/APP：指运行在智能终端上，用于销售商品或提供服务的应用软件，包含移动应用、快应用、元服务、HTML5页面等技术载体。

2.2 AppID所属主体：指在[HUAWEI AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)注册登记拥有APP所有权和知识产权的法人、自然人或其他组织。

2.3 AppID：指APP在HUAWEI AppGallery Connect注册审核通过后获取到的唯一识别凭证。

2.4 华为支付商户：指使用华为支付服务并向用户销售商品或服务的经营者。

2.5 华为支付商户号：指华为支付为商户提供的唯一编号，用于记录身份信息、资金余额和反映交易明细信息。商户号将与商户合法银行账户绑定，华为支付根据商户的指令及相关协议约定对的银行/支付账户做相应资金扣划和归集。

2.6 关联APP：指AppID所属主体与华为支付商户就授权AppID与华为支付商户号关联授权绑定，华为支付商户通过授权绑定的APP向用户提供商品或服务。

三、服务内容及使用规范

3.1 服务场景

3.1.1 本服务用于联合运营方建立商户号与关联APP之间的关联关系，商户通过关联APP开展业务时，可以让用户可以在关联APP中通过华为支付服务购买商品和服务，相应的资金按照华为支付与商户签署的《华为支付商户服务协议》进行结算。

3.1.2 联合运营方在关联APP中开展的业务范围应该属于商户在华为支付商户平台申报并经核准的商品或服务，如商户号所属主体与AppID所属主体不一致的，应当事先取得AppID所属主体的授权。

3.2 开通流程

3.2.1 商户通过华为支付商户平台登录账号和密码登录商户平台申请使用本服务，提交需要关联APP的AppID，按照AppID授权管理的流程，向AppID所属主体发起授权请求；AppID所属主体同意该请求并授权后，即视为完成授权绑定。

3.2.2 AppID所属主体收到授权请求后未在华为支付规定的时间内同意授权或者明确表示不同意授权的，即视为授权绑定不成功，所有的责任和后果由联合运营方自行承担。

3.2.3 联合运营方申请开通本服务时，应当提交正确、准确的AppID、商户号信息，华为支付有权审核相应的经营业务范围、技术规范是否符合法律法规及华为支付业务政策，并有权视情况决定是否开通。

3.3 绑定终止

AppID所属主体或华为支付商户，任何一方向华为支付提出终止该授权绑定时，华为支付将在收到终止授权绑定通知后，解除该关联APP的华为支付接口并解除相应华为支付商户号与关联APP的AppID授权绑定关系。

3.4 资金结算

联合运营方知悉并同意，一旦授权绑定成功后，华为支付将按照商户与华为支付签署的《华为支付商户服务协议》将商户通过关联APP开展业务时产生的交易资金结算至商户的华为支付商户号指定结算账户。

四、交易纠纷处理

4.1 对于联合运营方在关联APP中销售商品和服务，与用户产生纠纷的，联合运营方应自行妥善解决该纠纷，华为支付有权因AppID所属主体、关联APP的经营状况、风险程度、异常交易等原因对联合运营方分别或一并采取风险控制措施。

4.2 华为支付有权通过关联APP开展业务时的经营状况、纠纷严重程度等，无需事前通知的情况下暂时或永久关闭关联APP的华为支付接口，以及暂时或永久解除商户号与AppID关联关系。

4.3 联合运营方应配合华为支付提出的查询通知、调单、反洗钱反欺诈尽职调查要求，积极防范异常交易风险，并妥善解决纠纷。

五、其他

5.1 联合运营方保证通过关联APP开展业务符合法律法规的规定，如需取得行政许可、审批或授权等前置条件的，应该保证已经满足该等条件。

5.2 本协议为《华为支付商户服务协议》的补充约定，如与《华为支付商户服务协议》内容相冲突的，以本协议约定的为准；除本协议约定内容外，《华为支付商户服务协议》各条款的内容继续有效。
