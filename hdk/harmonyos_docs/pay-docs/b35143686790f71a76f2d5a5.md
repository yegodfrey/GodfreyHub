# 退款是否会将手续费退回

部分支付方式支持退手续费。

针对符合退手续费的场景：

（1）若您申请的结算规则为按比率收取手续费，发生退款时，手续费会根据退款金额比例返还。

（2）若您申请的结算规则为按每笔交易收取，仅全额退款时才会返还手续费。
