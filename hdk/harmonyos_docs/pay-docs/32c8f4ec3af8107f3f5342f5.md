# 员工账号添加及删除

## 1.添加员工账号

超级管理员可操作添加员工账号。

**第1步：新增员工账号并填写员工信息。**

超级管理员登录华为支付商户平台后，进入【账户中心】->【账号管理】->【员工账号管理】页面，点击"新增"，选择"角色名称"并填写新增员工信息后，点击"确认"。

激活链接生成后将该激活链接发送给员工激活账号。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b9/v3/pUST_Zg5QYS3ouSoSXmS2g/zh-cn_image_0000002525995014.png?HW-CC-KV=V1&HW-CC-Date=20261008T164932Z&HW-CC-Expire=31536000000&HW-CC-Sign=71EFDCE80175A995801473FC7C2EC50D3B50BA0A79A2FC1DC84FD0D11D6E9906 "点击放大")

**第2步：** **点击激活链接，授权华为账号登录华为支付商户平台激活员工账号。**

若该员工已有华为账号，输入华为账号手机号/邮件地址/账号名及对应的密码登录华为支付商户平台；

若该员工尚未注册华为账号，点击页面上的"注册"，注册华为账号后登录华为支付商户平台。

登录后输入"身份证后六位"完成员工账号激活。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/91/v3/UlLDxdJVQDKCDNUXvImvKA/zh-cn_image_0000002525995012.png?HW-CC-KV=V1&HW-CC-Date=20261008T164932Z&HW-CC-Expire=31536000000&HW-CC-Sign=11025C26AF723949B30C4B4D0DB5D7899887C9C10B415083A89D8AC36EBA0339 "点击放大")

> 注意
>
> 员工账号激活时，请确认当前设备下无其他操作员角色在华为支付商户平台登录，如有，请先退出登录并关闭所有平台相关页面，以上动作均确认完成后再打开激活链接，点击"授权华为账号登录"。

## 2.员工账号删除

超级管理员可操作删除员工账号。

超级管理员登录华为支付商户平台后，进入【账户中心】->【账号管理】->【员工账号管理】页面，找到具体需要删除的角色，点击角色右边的"删除"按钮删除该角色。
> 注意
>
> 员工账号删除后将不可使用，请谨慎操作。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3f/v3/B_sSPixWRCSdPC6PyL3iew/zh-cn_image_0000002525995016.png?HW-CC-KV=V1&HW-CC-Date=20261008T164932Z&HW-CC-Expire=31536000000&HW-CC-Sign=5FBB284ACA4E1040CB7C50388C081F3434D2BE3251FF276DE685DE7A7A8972D6 "点击放大")

## 3.员工账号删除，无删除按钮

您可以按以下原因排查：

1.商户状态是否异常：若商户被冻结，请您先[申请解冻商户号](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-shanghuhaojiedong-0000001902584294)后再操作删除。

2.华为支付商户平台仅支持超级管理员操作删除员工账号，请使用超级管理员账号登录华为支付商户平台操作删除。
