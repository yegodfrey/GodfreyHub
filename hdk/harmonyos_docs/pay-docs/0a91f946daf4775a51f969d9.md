# 商户如何提交申请

## 一、登录与超级管理员注册

**1. 平台登录**

* 登录**[华为支付商户平台](https://petalpay-merchant.cloud.huawei.com)** 。若登录有疑问参见 **[注册与登录](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-zhucezhanghao-0000001251128459)**

**2. 超级管** **理员创建**

* 登录后，根据页面提示**完成商户超级管理员** 注册。该账号拥有以下权限：

  - 商户号全生命周期管理

  - 商户日常重要管理信息与资金操作权限（如充值、提现、接收通知、修改商户信息等）

> 注意
>
> 1. 同一个华为账号下，所有商户号的超级管理员实名信息须为同一自然人。
> 2. 超级管理员身份证号和姓名将用于安全验证，**请确保信息准确无误** 。
> 3. **身份核验** ：您需具备以下任一身份：
>    * 商户法定代表人
>    * 授权经办人（须持有**[《业务办理授权函》](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260923180611.37204459881154384074680701959931:50001231000000:2800:96079EE00F5FACE2C85D3F3CAA5443938C66F43731EC521651E9FCE89F7D83F8.docx?needInitFileName=true)** ）
>
>      若身份不符或需变更超级管理员，请立即：退出当前账户，使用法人或者授权经办人的华为账号重新登录。
