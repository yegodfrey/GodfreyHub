在业务接入请求对接说明的通知结果返回一直失败如何解决 返回结果contentType选择application/json，接口返回值请直接参考[服务端-demo](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220630093017.17889838961604490692435835134040:50530629031040:2800:45BEC7F80901CAA4B7614D4B7F1CEE5A553D8E3C3581BB2A8FB866A5AAD7DBC8.zip?needInitFileName=true)中的DemoMerchantController.java文件中的BaseResponse.buildSuccessResp()方法直接返回即可。请勿直接返回Map类型或String类型结果，否则华为支付服务器将无法正常解析。
