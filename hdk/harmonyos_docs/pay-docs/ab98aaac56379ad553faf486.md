# 分账功能介绍及开通指引

#### 分账功能介绍

华为支付系统支付成功后的订单，可由分账发起方按照一定分账比例、周期将订单资金分账给分账接收方商户。

分账方：支付成功订单部分资金分出的一方，这里一般指在华为支付入网成功的直连商户、特约商户、子商户。

分账接收方：接收支付成功订单部分资金的一方，这里一般指在华为支付入网成功的商户（包括：直连商户、服务商、平台类商户、特约商户、子商户）。

分账发起方：对支付成功订单发起分账指令的一方，这里一般指在华为支付入网成功的直连商户、服务商、平台类商户。  

#### 分账功能开通

当前华为支付商品平台入网成功后的商户，系统默认不开通分账能力，若商户因业务需求申请开通分账功能，请联系您的商户对接人协助申请。

#### 分账功能开通查询

若您已开通分账能力，您可以在登录华为支付商户平台后，进入【交易中心】-\>【分账管理】-\>【分账配置】页面查看分账方信息或分账接收方列表信息，查看信息以页面展示为准。

分账协议查询，您可以在登录华为支付商户平台后，进入【商户中心】-\>【产品功能】-\>【产品授权】页面查看  

#### 分账比例上限修改

直连商户模型支持已开通分账能力直连商户，登录华为支付商户平台后，进入【交易中心】-\>【分账管理】-\>【分账配置】页面，修改"分账比例上限"；

服务商模型支持已开通分账能力特约商户，登录华为支付商户平台后，进入【交易中心】-\>【分账管理】-\>【分账配置】页面，修改"分账比例上限"；

平台类商户模型支持平台子商户登录华为支付商户平台后，进入【交易中心】-\>【分账管理】-\>【分账配置】页面，修改"分账比例上限"。  
![](https://media:301781572805988515)  
分账比例上限修改仅支持商户超级管理员操作修改；

分账方单笔订单累计的分账金额不得超过订单金额\*分账比例上限，目前默认最高分账比例为30%

分账接收方分账比例总和不能超过分账比例上限30%
