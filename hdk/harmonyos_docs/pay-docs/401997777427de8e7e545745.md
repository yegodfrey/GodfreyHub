# 特约商户信息查询

服务商超级管理员可登录华为支付商户平台查询其下已成功入网特约商户信息，进入【商户中心】->【特约商户管理】，点击"查看详情"按钮查看特约商户的基本信息、营业信息、法定代表人信息、业务联系人信息、经营信息。
