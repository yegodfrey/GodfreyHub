# 入网申请移动端查看及签署协议指引

商户在PC网页端提交入网申请后，可通过手机端登录华为支付商户平台，完成审核进度查询、账户验证、特约商户分账功能确认、受益所有人信息补充、线上协议签署等操作。

手机端华为支付商户平台入口：【[请点击](https://petalpay-merchant.cloud.huawei.com/h5)】。

温馨提示：手机端仅支持查看、确认及签署类操作，**不支持资料修改**。如需修改申请材料，请登录 PC 网页端进行操作。
