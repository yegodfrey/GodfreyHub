# 修改子商户超管手机号及邮箱

华为支付商户平台支持平台商超级管理员对"资料审核中"、"资料审核失败"、"待签署协议"、"草稿"态子商户的超级管理员有效手机号和邮箱进行修改。

您可以在登录华为支付商户平台之后，进入进入【商户中心】-\>【平台子商户管理】页面页面，查询到需修改子商户，点击"修改管理员"进行超级管理员信息修改。
