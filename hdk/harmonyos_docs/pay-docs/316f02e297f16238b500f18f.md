# 商户简称、经营场景、客服电话修改

修改商户经营信息要由华为支付商户平台超级管理员进行修改。

若您需要修改商户经营信息，您可以在登录华为支付商户平台后，进入【账户中心】->【账户设置】->【商户经营信息】页面，点击页面右上角"修改资料"进行修改。完成修改后点击"提交"。

修改资料申请提交后，审核结果将通过短信、邮件通知超级管理员。

支持修改的信息包括，商户简称、客服电话、经营场景、补充说明。
> 注意
>
> 目前华为支付商户平台暂不支持自行修改经营类目。

> 说明
>
> * 直连商户/平台类商户/服务商：App和元服务场景下，只允许选择商户号已关联的AppID。
> * 平台子商户：经营场所展示其平台商户的经营信息，不可修改经营信息。
> * 特约商户：
>   1. 其服务商尚未成功配置共享经营场所的特约商户：App和元服务场景下，只允许选择商户号已关联的AppID。
>   2. 其服务商共享经营场所的特约商户：不可修改经营信息。
