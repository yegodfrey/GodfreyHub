# 商户/服务商/特约商户的账户验证指引

|模块|内容说明|
|:----:|:----------------------------------------------------------------------------------------------------------------------:|
|账户验证|关键要求与操作指引|
|① 验证触发|► 审核通过后，花瓣支付（深圳）有限公司向结算账户打随机验证金（精确到分） ► 政府事业单位豁免验证|
|② 验证操作|收到通知后 72小时内：1. 登录商户平台；2. 输入打款金额（保留2位小数）；3. 校验账户名：花瓣支付（深圳）有限公司|
|③ 失败处置|►每次验证仅提供2次输入验证金额的机会 ► 打款失败：若银行账户有误，可点击【重新进入账户验证】-【修改结算账户信息】，修改账户后，可重新触发验证；若确认银行信息无误，则点击 【重新进入账户验证】-【核对无误，重新进行账户认证】触发二次打款|
|④ 超时后果|若在收到通知后72小时内未操作，或两次输入验证金额均错误： 1.当前验证流程将失败。 2.您需要根据页面提示时间重新触发验证（在页面提示剩余次数内）或： 3.申请作废当前入网申请，重新提交入网申请。|
