# 鸿蒙生态激励活动

## 1.活动介绍与报名

**活动介绍：**

华为支付激励 鸿蒙生态（实物商品/服务） 活动是华为支付给鸿蒙原生应用/元服务的开发者们提供的专属激励资源，鼓励开发者在鸿蒙原生应用/元服务中接入华为支付，共创鸿蒙生态繁荣未来。

**报名入口：**

您可以登录华为支付商户平台后，进入【商户中心】->【活动管理】->【鸿蒙生态激励报名】页面参与报名。

## 2.活动常见问题

## 活动对象

本激励政策面向在鸿蒙生态的原生应用和元服务中实物商品或服务交易接入华为支付的合作伙伴（包含直连商户、平台商户和服务商）

## 报名入口

您可以登录华为支付商户平台后，进入【商户中心】->【活动管理】->【鸿蒙生态激励报名】页面参与报名。

## 更多活动细则
