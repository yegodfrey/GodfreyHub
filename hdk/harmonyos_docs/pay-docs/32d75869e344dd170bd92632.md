# 直连商户激励金领取

## 1.直连商户未开手续费发票（蓝字发票），支付激励金发放流程

## 第1步：确认激励金

您可以登录华为支付商户平台后，进入【商户中心】->【活动管理】->【激励金申请】页面，根据结算月份、发放月份、状态查询到待确认激励金，下载并核对激励金明细无误后，点击"确认"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/91/v3/UIuqfGn5QHaGWEq1ZOjSGw/zh-cn_image_0000002577941494.png?HW-CC-KV=V1&HW-CC-Date=20261008T152935Z&HW-CC-Expire=31536000000&HW-CC-Sign=F23A6C7A07E3C87606EAD763709E7C524E6D04F044ED3F328E58422FECA30976 "点击放大")

## 第2步：领取激励金

确认激励金后，请点击"领取"等待发放，发放成功后，激励金状态更新为已发放。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/66/v3/RWB_saqiTguytdQdOVo3HA/zh-cn_image_0000002608461377.png?HW-CC-KV=V1&HW-CC-Date=20261008T152935Z&HW-CC-Expire=31536000000&HW-CC-Sign=A0916085283129EA96A56E915A3928EF17734E2A1EBEC45A9CDD0E1F82FE5BBE "点击放大")

## 2.直连商户已开手续费发票（蓝字发票），支付激励金发放流程

## 第1步：确认激励金，开具红字发票

您可以登录华为支付商户平台后，进入【商户中心】->【活动管理】->【激励金申请】页面，根据结算月份、发放月份、状态查询到待确认激励金，点击"确认"后再点击"红字电子发票开具"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ac/v3/yg0g39_uStWUVXGuTH0HaQ/zh-cn_image_0000002621941985.png?HW-CC-KV=V1&HW-CC-Date=20261008T152935Z&HW-CC-Expire=31536000000&HW-CC-Sign=89B3F6B0FB4ED414422567977DC2389DF71EF7DEB9BD7FEDED55C3A3C103A924 "点击放大")

## 第2步： 填写红字确认单号码

进入红字发票开具弹窗页面后，填写红字确认单号码。[获取红字确认单号码](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-hongziquerendanhao-0000002199904428)。

提交红字发票记录请进入【交易中心】->【结算管理】->【开票管理】页面查询。

若仅有单张发票，将红字确认单号填写提交即可；

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/49/v3/3VC7wvmvRXms7MOcZLMKSw/zh-cn_image_0000002608301461.png?HW-CC-KV=V1&HW-CC-Date=20261008T152935Z&HW-CC-Expire=31536000000&HW-CC-Sign=E48B94FCBCE3A86F6D706A32EFE7F3864CC440460652C0781AD54DD94B851046 "点击放大")

若多张发票，请手动输入核对无误红冲金额(金额合计等于激励金额),勾选右边操作框,输入红字确认单号码,点击"提交"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/03/v3/irg-2HfYSVqx3JXLl-CkdQ/zh-cn_image_0000002577781520.png?HW-CC-KV=V1&HW-CC-Date=20261008T152935Z&HW-CC-Expire=31536000000&HW-CC-Sign=3228B59E8E9A35E8A3D0494AADE19C02E858EE55E602A7F3561E104782F19173 "点击放大")

## 第3步：等待红字发票审批完成领取激励金

等待红字发票审批完成后，请再次进入【商户中心】->【活动管理】->【激励金申请】页面，请点击"领取"等待激励金发放，发放成功后，激励金状态更新为已发放。
