# 直连商户激励金领取

## 1.直连商户未开手续费发票（蓝字发票），支付激励金发放流程

## 第1步：确认激励金

您可以登录华为支付商户平台后，进入【商户中心】->【活动管理】->【激励金申请】页面，根据结算月份、发放月份、状态查询到待确认激励金，下载并核对激励金明细无误后，点击"确认"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/91/v3/UIuqfGn5QHaGWEq1ZOjSGw/zh-cn_image_0000002577941494.png?HW-CC-KV=V1&HW-CC-Date=20260921T064300Z&HW-CC-Expire=31536000000&HW-CC-Sign=A0CA3B233845372A522F6E24FEAF6844C025F49A318291A9BEC33F9A1F53F0DD "点击放大")

## 第2步：领取激励金

确认激励金后，请点击"领取"等待发放，发放成功后，激励金状态更新为已发放。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/66/v3/RWB_saqiTguytdQdOVo3HA/zh-cn_image_0000002608461377.png?HW-CC-KV=V1&HW-CC-Date=20260921T064300Z&HW-CC-Expire=31536000000&HW-CC-Sign=3993873C584510C1B50E41DEA8378AC258B3421552859E79D90489ABD03CE068 "点击放大")

## 2.直连商户已开手续费发票（蓝字发票），支付激励金发放流程

## 第1步：确认激励金，开具红字发票

您可以登录华为支付商户平台后，进入【商户中心】->【活动管理】->【激励金申请】页面，根据结算月份、发放月份、状态查询到待确认激励金，点击"确认"后再点击"红字电子发票开具"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ac/v3/yg0g39_uStWUVXGuTH0HaQ/zh-cn_image_0000002621941985.png?HW-CC-KV=V1&HW-CC-Date=20260921T064300Z&HW-CC-Expire=31536000000&HW-CC-Sign=184EE57EC35F6FC74681EF8FA868E9863CECF3D2413FB868EBBD6BAA1B4B3521 "点击放大")

## 第2步： 填写红字确认单号码

进入红字发票开具弹窗页面后，填写红字确认单号码。[获取红字确认单号码](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-hongziquerendanhao-0000002199904428)。

提交红字发票记录请进入【交易中心】->【结算管理】->【开票管理】页面查询。

若仅有单张发票，将红字确认单号填写提交即可；

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/49/v3/3VC7wvmvRXms7MOcZLMKSw/zh-cn_image_0000002608301461.png?HW-CC-KV=V1&HW-CC-Date=20260921T064300Z&HW-CC-Expire=31536000000&HW-CC-Sign=6FDA8185326085DC4B151C33FD30713FA41E65F20AD86F01D6E5BE1EFD485A79 "点击放大")

若多张发票，请手动输入核对无误红冲金额(金额合计等于激励金额),勾选右边操作框,输入红字确认单号码,点击"提交"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/03/v3/irg-2HfYSVqx3JXLl-CkdQ/zh-cn_image_0000002577781520.png?HW-CC-KV=V1&HW-CC-Date=20260921T064300Z&HW-CC-Expire=31536000000&HW-CC-Sign=E9535F749CB807DE2135D7F81DC2B7BC20AB49356C7DE52675AD8BF3F28C8770 "点击放大")

## 第3步：等待红字发票审批完成领取激励金

等待红字发票审批完成后，请再次进入【商户中心】->【活动管理】->【激励金申请】页面，请点击"领取"等待激励金发放，发放成功后，激励金状态更新为已发放。
