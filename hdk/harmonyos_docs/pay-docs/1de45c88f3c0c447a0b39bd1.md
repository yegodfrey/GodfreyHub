    1. 使用场景
验签是指：商户对来自华为支付服务器的信息验证签名信息身份来自华为支付服务器。 **步骤12** ：商户服务器对返回的回调通知请求参数验签。 **步骤25** ：商户服务器对返回的退款通知请求参数验签。
    2. 使用方式确认验证签名的公钥证书、确认参与签名字段将将待签名字段转换为key=value并以&符号拼接、使用验签方法验证签名。
       * 需要获取华为支付公钥，此处公钥对应于[华为支付平台证书](https://developer.huawei.com/consumer/cn/doc/distribution/pay-docs/petalpay_app_433_hw_payment_platform_certificate-0000001274692590)获取的证书。
       * 获取参与签名的字段，转换为map并将map的key-value排序后以&符号拼接。
       * 请调用此方法对处理后的字段完成验签
             
             public static boolean verifySign(String publicKey, String sourceData, String signedData)

    3. 示例代码段
验签部分代码请根据使用场景，可以参考[服务端-demo](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220630093007.17623844833868246485318195387678:50530629031039:2800:96078DEDEDEC5CB4E8A1BF87F55818B8E37896AA862AF766D6F6112BBC49D862.zip?needInitFileName=true)中的DemoMerchantController.java中verify方法。
    
    public boolean verifySign(String sign, String body) { 
        log.info("Start verfy sign"); 
        // 公钥 
        String pubKey = DemoKeys.HW_PAY_PUBLIC_KEY; 
        // 把payServSign字符串转成PetalPaySign对象 
        PetalPaySign paySign = JSONObject.parseObject(sign, PetalPaySign.class); 
        // 获取PetalPaySign对象的bodySign值 
        String bodySign = paySign.getBodySign(); 
        // 把传过来的请求体body转为map 
        Map<?, ?> contentMap = JSONObject.parseObject(body, Map.class); 
        // 把该map用TradeSignToString工具类转成key=velua并以&符号拼接的格式，得到的字符串就是未签名的原数据 
        String datasouce = TradeSignToString.signString(contentMap); 
        log.info("Signed body:" + datasouce); 
        // pubKey公钥，datasouce原数据，bodySign签名后的数据，调用Sm2Utils进行验签，返回值为true，说明验签成功 
        boolean b = Sm2Utils.verifySign(pubKey, datasouce, bodySign); 
        log.info("Verify sign result:" + b); 
        return b; 
    }
