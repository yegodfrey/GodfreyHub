QueryOrderRequest请求对象中orderNo说明--当orderType为1时，仅支持查询72小时内的交易，当使用商户订单号查询订单时候超过72小时会报什么错 若订单超过72小时未支付且订单状态为APLLY，此类订单会在超过72小时后的第一个夜晚凌晨01：00被系统集中清理掉，查询此订单会返回“TRX100010 Order does not exist.”。
