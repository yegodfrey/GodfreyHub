# 超级管理员变更

修改超级管理员信息要由超级管理员进行修改。支持修改的信息包括：姓名、身份证号、有效手机号、邮箱。

**若您的华为账号绑定多个华为支付商户号，除业务办理授权函以外的操作员信息修改将会被同步到其他关联商户号。**

## 1.修改超级管理员有效手机号及邮箱

修改超级管理员手机号及邮箱信息，请进入【账户中心】->【账户设置】->【操作员信息】页面修改。

## 超级管理员为法定代表人

超级管理员为法定代表人时，根据页面提示修改相关信息，点击"提交"，即可完成有效手机号及邮箱信息更新。

## 2.变更超级管理员

**第1** **步：修改资料。**

进入【账户中心】->【账户设置】->【操作员信息】页面，点击页面右上角"修改操作员信息"，点击"变更超管"。

## 变更超管为法定代表人

若将超级管理员变更为法定代表人，请根据页面提示完成新超级管理员身份证人像及国徽照片上传及相关信息修改，点击"提交"并"确认"。

**第2** **步：资料审核通过，完成银行账户验证。**

资料审核通过后，华为支付会向您所填写的结算账户打款。原超级管理员需要在收到打款验证的短信、邮件通知的72小时内，登录华为支付商户平台，进入【账户中心】->【账户认证】->【小额打款认证】页面，点击"去认证"输入收到的金额（精确到小数点后2位），金额一致，即可完成银行账户验证。
> 注意
>
> （1）若主体类型为政府事业单位，无需完成银行账户验证；
>
> （2）每笔账户验证申请，金额有效期为72小时，且每次仅有2次输入金额的机会，请谨慎输入；
>
> （3）若金额失效或2次金额均输入错误，请于24小时后在页面上重新申请账户验证申请；
>
> （4）账户验证申请次数有限，为了不影响业务开展，请及时输入金额完成账户验证。

**第3** **步：新超级管理员激活管理员账号。**

银行账户验证完成后，华为支付会向新超级管理员发送短信、邮件通知新超级管理员激活超管账户。

新超级管理员可以使用已注册华为账号或者新注册华为账号登录[华为支付商户平台](https://petalpay-merchant.cloud.huawei.com)，输入新超管身份证号码后6位以激活新超管账户，超级管理员账号变更完成。
> 注意
>
> （1）新超级管理员在激活链接前，请确认当前设备下所有操作员角色都已在华为支付商户平台退出登录并关闭所有平台相关页面，以上动作均确认完成后再打开激活链接。
>
> （1）变更超级管理员信息时，请勿使用原超级管理员绑定的华为账号激活新超级管理员账号，否则若您的华为账号绑定多个华为支付商户号，修改此商户号超级管理员信息将会同步到其他关联商户号，请您谨慎操作。
>
> （2）若使用现有操作员角色接替超管角色，可使用现有操作员绑定的华为账号激活新超管账号，即原有角色自动被替换成超管。

## 3.原超级管理员已离职或失联，无法登录商户平台，如何处理

若原超级管理员已离职或失联，无法登录商户平台，您可通过[找回商户号方式](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-shanghuhaozhaohui-0000001723653588)重新绑定新超级管理员，使用新超级管理员华为账号登录华为支付商户平台。
