# 服务商激励金领取

#### 第1步：确认激励金

您可以登录华为支付商户平台后，进入【商户中心】-\>【活动管理】-\>【激励金申请】页面，根据结算月份、发放月份、状态查询到待确认激励金，下载并核对激励金明细无误后，点击"确认"。

<br />

#### 第2步：上传发票

点击"发票上传"，进入上传页面，选择发票邮寄或者发票上传(支持上传多张发票)，点击"提交"等待发票审核。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250915110855.52231056424046353351896206564888:50001231000000:2800:7E0B6F3D7FC2A0E61BED8FD41051B2C6B17B23BE98C4868F260F6B7166348E96.png "点击放大")  

#### 第3步：发票审批完成领取激励金

等待发票审批完成后，请再次进入【商户中心】-\>【活动管理】-\>【激励金申请】页面，请点击"领取"等待激励金发放，发放成功后，激励金状态更新为已发放。
