TRX100010 Order does not exist. 这个错误什么时候会返回 订单不存在，没有创建订单，可能创建订单比查询订单晚处理，即创建订单还未落库就发起了查询。当前只要创建退款返回{"resultCode":"000000", resultDesc":"Success", "refundOrderNo":"122***x"}再发起查询就不会出现此问题。
