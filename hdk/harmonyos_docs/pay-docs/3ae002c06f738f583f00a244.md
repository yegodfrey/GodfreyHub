# 风险处理

若商户号下存在待处理的风险事项（如信息未更新、证件到期等），您可以登录华为支付商户平台后，进入【账户中心】->【合规管理】->【风险处理】页面查询原因及处理。

查询列表展示商户号下执行中的功能限制，操作为处理类，表示需要配合处理的事项，请尽快处理。

若逾期未处理，将进一步加强管控。若风险原因已解除，将不在该列表展示。

## App/元服务未上架

若您入网时填写的经营场所勾选了"App"或者"元服务"场景，且所有AppID都未上架，您将被限制单笔单日收款额度。（**单笔收款≤1000元，单日收款≤1000元**）

系统每日会自动监测AppID的上架情况，若监测到AppID已上架会自动解除限制。若您的AppID已上架但收款额度限制未自动解除，您可以通过以下两种方式解除限制：

* 您可以点击"去处理"->"已上架"反馈应用上架情况。审核通过后，限额将自动解除。
