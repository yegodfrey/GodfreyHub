# 自定义角色权限新增

您可以在【账户中心】->【账号管理】->【角色权限设置】页面查看系统角色的商户平台对应操作权限，也可新增、编辑自定义角色并赋予该角色对应的华为支付商户平台操作权限。

超级管理员可新增自定义角色。

**第1步：新建角色并设置权限。**

超级管理员登录华为支付商户平台后，进入【账户中心】->【账号管理】->【角色权限设置】页面，点击"新增角色"，填写"角色名称"并选择相应的权限。
> 注意
>
> 页面标红的权限为高危权限，请谨慎配置。

**第2步：添加自定义角色的员工账号。**

角色权限设置后，进入【账户中心】->【账号管理】->【员工账号管理】页面，点击"新增"，选择自定义角色并填写需要添加的员工信息后，点击"确认"。

激活链接生成后将该激活链接发送给员工激活账号。

**第3步：点击激活链接，授权华为账号登录华为支付商户平台激活员工账号。**

若该员工已有华为账号，输入华为账号手机号/邮件地址/账号名及对应的密码登录华为支付商户平台；

若该员工尚未注册华为账号，点击页面上的"注册"，注册华为账号后登录华为支付商户平台。

登录后输入"身份证后六位"完成员工账号激活。

> 注意
>
> 员工账号激活时，请确认当前设备下无其他操作员角色在华为支付商户平台登录，如有，请先退出登录并关闭所有平台相关页面，以上动作均确认完成后再打开激活链接，点击"授权华为账号登录"。
