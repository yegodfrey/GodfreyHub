# 受益所有人填写指引

根据反洗钱、反恐怖融资等相关法律法规，为落实金融机构客户尽职调查要求，规范受益所有人识别核实工作，我们将根据商户的组织形式和风险状况，收集受益所有人的相关信息，商户应确保所填写的受益所有人信息真实、准确、完整。为便于相关信息填报，现就受益所有人信息收集事项说明如下。若您在提交入网申请过程中收到受益所有人信息填写要求，可参照以下指引完成填写。

一、受益所有人判定与填写说明  

|模块|内容说明| |
|:------------------------------------------------:|:---------------------------------:|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|步骤|内容|说明|
|1、选择受益所有人类型 （根据实际情况选择其一）|选项1：法人是唯一受益所有人|须补充法人地址、手机号码等相关信息|
|1、选择受益所有人类型 （根据实际情况选择其一）|选项2：法人是受益所有人，还有其他受益所有人 选项3：法人非受益所有人|根据页面提示补充其他受益所有人的详细信息，若有多个受益所有人，则须填写所有受益所有人|
|2、临时跳过与后续补充 （如暂时无法完整填写，可先跳过，在后续环节补充） <br />|商户入网信息填写时|【受益所有人\&经营信息】填写页面|
|2、临时跳过与后续补充 （如暂时无法完整填写，可先跳过，在后续环节补充） <br />|协议签署前|商户入网申请审核通过后、签署协议前，系统将再次提醒补充。 温馨提示：若此时仍未补充，商户号成功开通后部分功能将受到限制。|
|2、临时跳过与后续补充 （如暂时无法完整填写，可先跳过，在后续环节补充） <br />|开通后|商户号开通成功后，登录华为支付商户平台会看到"待处理风险事项"提示，点击即可按页面指引完善受益人所有人信息。信息审核通过后，风险提示将自动解除。 [具体操作指引请查看](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-zhilianshanghufxcl-0000001317315737)|
|3、受益所有人判定标准 （根据中国人民银行发行的《受益所有人信息管理办法》规定，受益所有人判定标准）|受益所有人定义|指最终拥有或实际控制市场主体，或者享有市场主体最终受益的自然人。|
|3、受益所有人判定标准 （根据中国人民银行发行的《受益所有人信息管理办法》规定，受益所有人判定标准）|标准①股权/权益控制|直接/间接持有≥25%股权、股份或者合伙权益的自然人。|
|3、受益所有人判定标准 （根据中国人民银行发行的《受益所有人信息管理办法》规定，受益所有人判定标准）|标准②收益/表决权控制|虽未达标准①，但实际享有≥25%收益权或表决权的自然人。|
|3、受益所有人判定标准 （根据中国人民银行发行的《受益所有人信息管理办法》规定，受益所有人判定标准）|标准③ 实际控制|虽未达标准①，但单独或联合对市场主体进行实际控制的自然人。 实际控制包括但不限于：通过协议约定、关系密切的人等方式实施控制，例如决定法定代表人、董事、监事、高级管理人员或者执行事务合伙人的任免，决定重大经营、管理决策的制定或者执行，决定财务收支，长期实际支配使用重要资产或者主要资金等。|
|3、受益所有人判定标准 （根据中国人民银行发行的《受益所有人信息管理办法》规定，受益所有人判定标准）|特殊情形1|若以上条件均不满足，则将负责日常经营管理的自然人视为受益所有人，负责日常经营管理的人员可以是公司的法定代表人、董事长、董事、总经理等|
|3、受益所有人判定标准 （根据中国人民银行发行的《受益所有人信息管理办法》规定，受益所有人判定标准）|特殊情形2|国有独资/控股公司法定代表人直接认定为受益所有人|
|4、受益所有人填写数量|受益所有人的识别须需穿透核查至最终自然人，所有符合上述受益所有人判定标准的自然人，均需填写||

|普通企业 （有限公司、合伙企业、上市公司、国内分公司等）|第一顺序适用|标准①股权持有者|按如下优先级提供： 1、股权架构图 2、公司章程 、股东名册 3、加盖公司公章的股权说明书，或其他可证明股权/合伙权益比例的材|* 完整的主体信息 * 若为股权架构图，则须能与国家企业信用信息公示系统（gsxt.gov.cn）查询的股权信息一致 <!-- --> * 穿透至最后一层均为个人 <!-- --> * 填写的受益所有人需体现直接或间接持股≥25%|
|普通企业 （有限公司、合伙企业、上市公司、国内分公司等）|第一顺序适用|标准②收益权/表决权持有者|按如下优先级提供： 1、公司章程、股东名册 2、出资证明书、股东会会议通知及决议、分红决议，以上任选其一 3、加盖公司公章的收益权/表决权说明书，或其他可证明收益权/表决权比例的材料|* 完整的主体信息 * 材料中应体现收益权/表决权比例、股东信息（姓名、证件号） * 能体现填写的受益所有人且其收益权/表决权≥25%|
|普通企业 （有限公司、合伙企业、上市公司、国内分公司等）|第一顺序适用|标准③ 实际控制|按如下优先级提供： 1、公司章程、股东名册/合伙人名单 2、实控人做出的决议文件（如：股东会决议、董事会决议、公司政策批示文件等） 3、加盖公司公章的控制权说明书，或其他可证明受益所有人控制权的文件 备注：若存在股权代持、股权与收益权分离等特殊控制权安排，需提供相关证明材料（如：股权代持协议等）|* 完整的主体信息 * 材料中应体现实控权、实控人信息（姓名、证件号）|
|普通企业 （有限公司、合伙企业、上市公司、国内分公司等）|第二顺序适用 （若不满足第一顺序的判定标准，则按第二顺序判标准）|负责日常经营管理的自然人|以下任选其一：营业执照、成员登记册、聘任协议、公司授权文件、任命文件或其他可证明其身份的文件|能证明其负责日常经营管理人员身份|
