# 发票信息填写及修改

## 1.发票信息填写

您可以登录华为支付商户平台后，进入【交易中心】->【结算管理】->【开票管理】页面，点击页面右上角的"发票信息"，根据跳转后的页面提示填写发票信息。
> 注意
>
> "开票名称"默认为商户主体信息中的商户名称，若需要变更开票名称需先[变更商户名称](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-xiugaiyingyexinxi-0000001200497458)。
>
> "纳税人识别号"默认为商户主体信息中的营业执照注册号，不支持编辑。

## 2.发票信息修改

您可以在登录华为支付商户平台后，进入【交易中心】->【结算管理】->【开票管理】页面，点击页面右上角的"发票信息"，根据跳转后的发票信息页面提示，点击"变更信息"修改发票信息。
