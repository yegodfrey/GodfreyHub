业务接入请求对接说明 商户接入的请求主要使用Http请求头中的PayMercAuth字段进行鉴权 PayMercAuth **字段名** | **类型** | **是否必选** | **限制** | **含义**  
---|---|---|---|---  
callerId | String | 必选 | maxLength: 40 | 调用方id，填商户号mercNo  
traceId | String | 必选 | maxLength: 32 | 消息流水号，用于定位使用  
time | long | 必选 | 请求时间的long型数据 | （为抵御消息重放攻击，time有效时间为5分钟）  
authId | String | 必选 | maxLength: 256 | 鉴权id  
sessionKey | String | 可选 | maxLength: 400 | 请求消息中的敏感参数加密使用的会话密钥（使用服务侧提供的SM2公钥加密，公钥信息见附件保护sessionKey的公钥中的外部商户接口 sessionkey使用部分）  
bodySign | String | 必选 | maxLength: 256 | 签名值，对http body进行签名，使用商户私钥进行SHA256WithRSA/PSS签名。接口可能会增加字段，建议商户保留可扩展性。  
headerSign | String | 必选 | maxLength: 256 | 消息头签名值，对PayMercAuth内容进行签名（参数以字典序排序后签名，headerSign字段不参与签名，bodySign参与签名），使用商户私钥进行SHA256WithRSA/PSS签名  
sessionKey生成规则：符合会话id的安全随机数至少24位。 authId：商户入网时商户系统分配，商户生成公私钥对，公钥上传，私钥由外部商户系统签名使用，后续华为支付网关拿到此公钥对请求验签；华为支付提供公钥，外部商户对响应进行验签。 具体签名代码参考[签名与验证签名说明](https://developer.huawei.com/consumer/cn/doc/distribution/pay-docs/petalpay_app_4221_sign-0000001325132433)。
