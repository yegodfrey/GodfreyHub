请求参数 **Method** | **URI** | **Description**  
---|---|---  
GET | /payment/api/merc/v2/mercorder/{orderType}/{orderNo} | 查询商户订单状态  
**Name** | **Mandatory** | **Type** | **position** | **Description**  
---|---|---|---|---  
orderType | M | int | path | 订单类型：0-系统订单号（可为交易、退款订单号），1-商户订单号  
orderNo | M | String | path | 当orderType为0时，支持系统订单号查询180天内的交易、退款信息，当orderType为1时，仅支持商户订单号查询72小时内的交易、退款信息  
mercNo | M | String | query | 商户号  
PayMercAuth | M | String | header | 商户鉴权信息
