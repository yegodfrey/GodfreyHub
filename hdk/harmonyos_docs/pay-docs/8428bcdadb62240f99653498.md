# 联调准备及功能设置

您在华为支付入网成功后，即可进行相应的联调准备，关于证书介绍、联调及技术对接文档，请[点击这里](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/base-payment-introduction-0000001536000984)查阅。

签名方式选择、商户证书上传、华为支付证书下载，请登录华为支付商户平台进入【商户中心】-\>【上传商户证书】页面，根据页面提示操作。
