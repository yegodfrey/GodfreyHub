华为支付简介 华为支付是经中国人民银行许可，由深圳市讯联智付网络有限公司提供的支付服务。 华为支付依托华为钱包为管理入口，为个人用户提供余额支付、银行卡支付、红包、充值、提现等服务；并为企业用户快速集成支付能力，提供资金结算、自动分账、营销赋能等服务。 华为支付致力于为用户提供支付相关服务，连接更丰富的数字生活，打造更安全、更便捷的全场景智慧体验。
