# 审核配置功能介绍

华为支付商户平台针对部分涉及资金操作的业务，提供审核流程管理功能，仅支持超级管理员配置及管理审核流程。

若相应业务场景启用审核流程， 操作员提交申请后，需经过对应节点审核人审核，当审核流程全部通过后，系统才会执行相应操作。

支持配置审核流程场景：

通过商户平台发起的单笔退款申请；

通过商户平台发起的批量退款申请；

通过商户平台发起的支付账户、营销账户、手续费账户提现申请；

通过商户平台发起的完成分账申请，配置审核流程。
