支付结果获取和处理 **同步返回** 商户应用通过当前调用支付的Activity的Handler对象，通过Handler机制将结果传递到主线程（UI线程）处理。
    
    final PayApi payApi = Pay.initPay(this); 
    boolean supportPay = payApi.isSupportPay(); 
    if (!supportPay) {
        return; 
    }
    
    new Thread(new Runnable() {
        @Override
        public void run() {
            final PayResult payResult = payApi.pay(ordStr);
            mHandler.post(new Runnable() {
                @Override
                public void run() {
                    dealPayResult(payResult);
                }
            });
        }
    }).start();

**异步通知** 商户在构建支付请求参数时，传入了一个callbackUrl。在华为支付服务器完成支付后，将以post方式调用callbackUrl，将支付结果返回给商户服务器。
