# 华为开发者如何提交申请（开通商户服务）

若您属于以下任意一个国内业务场景，则可开通IAP Kit（应用内支付服务），可按如下操作指引：

（1）若您为华为开发者，且已与华为软件技术有限公司签署联运协议，

（2）若您的业务场景为：数字商品（虚拟商品），包括消耗型商品、非消耗型商品和自动续期订阅商品，

操作指引： 请前往[华为开发者联盟官网](https://developer.huawei.com/consumer/cn/)，点击"管理中心"\>"开发者中心"\>"商户服务"进入商户服务页面，选择"境内收款账户"，完善相应材料申请开通华为支付。具体可参考，[开通商户服务的流程](https://developer.huawei.com/consumer/cn/doc/start/merchant-service-0000001053025967)。

<br />

#### 若华为开发者的商户服务申请被驳回

请根据页面显示的驳回原因，参考商户服务开通要求进行修改后提交，具体可参考[商户服务](https://developer.huawei.com/consumer/cn/doc/start/merchant-service-0000001053025967#section3513222624)
