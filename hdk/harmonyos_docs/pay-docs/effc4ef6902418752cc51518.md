支付接口调用 PayApi为开发者提供订单支付功能，在此之前需调用Pay.initPay方法进行初始化，入参为所在的Activity实例，获取payApi 对象。目前客户端暂不支持非华为（或非荣耀）手机，在发起支付前，建议先调用判断是否支持支付的检查接口isSupportPay，当设备未安装华为钱包或者华为钱包的版本不满足要求时，该接口返回false，其他可以直接发起支付请求的情况，则返回true。开发者可以根据此接口的判断结果，提示用户是否可以使用华为支付完成付款。支付接口orderStr参数参考[API列表](https://developer.huawei.com/consumer/cn/doc/distribution/pay-docs/petalpay_app_5611_request_parameters-0000001274692618#ZH-CN_TOPIC_0000001274692618__table3418mcpsimp)。支付接口同步返回支付结果，为耗时接口，需在新线程中执行，具体实现如下。
    
    final PayApi payApi = Pay.initPay(this); 
    boolean supportPay = payApi.isSupportPay(); 
    if (!supportPay) {
        return; 
    }
    new Thread(new Runnable() {
        @Override
        public void run() {
            final PayResult payResult = payApi.pay(ordStr);
            mHandler.post(new Runnable() {
                @Override
                public void run() {
                    dealPayResult(payResult);
                }
            });
        }
    }).start();
