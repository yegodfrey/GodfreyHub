# 签署协议

商户超级管理员在银行账户验证成功后，需要完成在线协议签署。只需点击"请签署协议"，然后在弹出的协议窗口中点击"同意"即可完成签署。协议签署后，系统将实时开通商户号，并通过短信和邮件发送通知。生效的协议可在【商户中心】-【协议管理】中查看。
