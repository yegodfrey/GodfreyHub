# 商户名称、营业执照证件修改

## 修改商户营业信息

修改商户营业信息要由华为支付商户平台超级管理员进行修改。

支持修改的信息包括：营业执照信息、经营者/法定代表人证件信息。若非三证合一，另外可修改组织机构代码证、税务登记证相关信息。

## 修改营业执照照片、经营者姓名/法定代表人姓名、营业期限

进入【账户中心】->【账户设置】->【商户主体信息】->【营业信息】页面，点击"修改资料"修改商户的营业执照照片、经营者姓名/法定代表人姓名及营业期限，完成修改后点击"提交"。

审核结果将通过短信、邮件通知超级管理员。

## 变更商户名称

**第1** **步：修改资料，等待审核**。

进入【账户中心】->【账户设置】->【商户主体信息】->【营业信息】页面，点击"修改资料"修改商户名称及其他商户营业信息，上传最新版营业执照，完成修改后点击"提交"。

审核结果将通过短信、邮件通知超级管理员。
> 注意
>
> （1）您可以登录国家企业信用信息公示网站查看最新的企业信息（http://www.gsxt.gov.cn/index.html）；
>
> （2）商户名称变更后结算账户的开户名称将会同步进行变更。

**第2** **步：完成银行账户验证。**

修改资料审核通过后，华为支付会向您所填写的结算账户打款。

超级管理员需要在收到打款验证的短信、邮件通知的72小时内，登录华为支付商户平台，进入【账户中心】->【账户认证】->【小额打款认证】页面，点击"去认证"输入收到的金额（精确到小数点后2位），金额一致，即可完成银行账户验证。

银行账户验证通过后，华为支付会通过短信告知超级管理员商户名称变更完成。
> 注意
>
> （1）若主体类型为政府事业单位，无需完成银行账户验证；
>
> （2）每笔账户验证申请，金额有效期为72小时，且每次仅有2次输入金额的机会，请谨慎输入；
>
> （3）若金额失效或2次金额均输入错误，请于24小时后在页面上重新申请账户验证申请；
>
> （4）账户验证申请次数有限，为了不影响业务开展，请及时输入金额完成账户验证。
