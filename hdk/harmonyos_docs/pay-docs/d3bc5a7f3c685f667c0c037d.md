通知结果对接说明 支付完成后，华为支付会把相关支付结果及用户信息通过数据流的形式发送给商户，商户需要接收处理，并按文档规范返回应答。
    1. 同样的通知可能会多次发送给商户系统。商户系统必须能够正确处理重复的通知。
    2. 后台通知交互时，如果华为支付服务器收到商户的应答不符合规范或超时，华为支付服务器会判定本次通知失败，重新发送通知，直到成功为止（在通知一直不成功的情况下，华为支付服务器总共会发起多次通知，通知频率为1min/5min/30min/24h）但不保证通知最终一定能成功。
    3. 在订单状态不明或者没有收到支付结果通知的情况下，建议商户主动调用查询订单接口 确认订单状态。
    4. 商户系统对于支付结果通知的内容一定要做签名验证,并校验返回的订单金额是否与商户侧的订单金额一致，防止数据泄露导致出现“假通知”，造成资金损失。支付系统在发送消息给商户时，会使用内部私钥对消息整体签名，签名结果放在Http请求头的PayServSign对象中，结构定义如下。具体签名方式参考[签名与验证签名说明](https://developer.huawei.com/consumer/cn/doc/distribution/pay-docs/petalpay_app_4221_sign-0000001325132433)。  **字段名** | **类型** | **是否必选** | **限制** | **含义**

signType | String | 必选 | maxLength: 32 | 算法类型（SM3WITHSM2）  
bodySign | String | 必选 |    | 对消息体的签名
