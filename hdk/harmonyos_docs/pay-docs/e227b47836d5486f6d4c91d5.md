# 支付账户充值

## 1.支付账户充值

您可以在登录华为支付商户平台后，进入【交易中心】->【资金管理】->【支付账户】页面点击"充值"，根据页面提示填写充值金额并选择"具体支付银行"，点击"跳转网银并支付"。根据所选银行的企业网银界面提示完成支付操作。

**温馨提示：**

（1）该功能仅支持企业类型商户操作使用；

（2）商户需要有充值页面支持的企业网银账户，且在银行侧开通网银支付的功能，默认均要求同名付款，付款方银行账户名称需为商户全称；

（3）请在72小时内完成充值，否则订单将自动取消。

（4）建议使用IE浏览器进行网上银行操作。

## 2.无法操作充值

您可以按以下原因排查：

（1）商户状态是否异常：若商户被冻结，请您先[申请商户号解冻](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-shanghuhaojiedong-0000001902584294)后再操作充值；

（2）请确认所选择的银行是否在银行侧开通企业网银相关功能；

（3）请核实所使用浏览器及版本，建议使用IE浏览器，以便使用网上银行。

## 3.查询充值记录

您可以在登录华为支付商户平台后，进入【交易中心】->【资金管理】->【支付账户】或【交易中心】->【交易管理】->【支付交易】页面，选择交易时间范围后，筛选"交易类型"为"充值"，查询具体的充值记录。
> 注意
>
> 目前华为支付商户平台预设角色仅超级管理员拥有支付账户明细下载权限，如需添加该权限，[请新增自定义角色](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-xinzengjuese-0000001264819165)。

## 4.下载充值记录

您可以在登录华为支付商户平台后，进入【交易中心】->【资金管理】->【支付账户】或【交易中心】->【资金管理】->【支付交易】页面选择交易时间范围后，筛选"交易类型"为"充值"，查询下载充值记录，可前往下载中心下载支付账户充值记录。
> 注意
>
> 目前华为支付商户平台预设角色仅超级管理员拥有支付账户明细下载权限，如需添加该下载权限，[请新增自定义角色](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-xinzengjuese-0000001264819165)。

## 5.支付账户充值能否开具发票

充值的资金不支持开具发票，商户给自己的账户充值后，该资金用途可用于退款操作，也可提现到结算银行账户中。
