# 对账常见问题

## 1.支付交易对账单和结算单如何核对？

您可将支付流水对账单结合结算明细进一步查看。结算单明细包含在该结算周期清算完成的全部交易信息。您可以在登录华为支付商户平台后，进入【交易中心】->【支付交易对账单】或【结算查询】页面获取对账指导，参考指导进行核对。

[支付交易对账查询及下载](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-zhifujiaoyi-0000001723301690)

[结算明细查询及下载](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-jiesuandanmingxi-0000001200495008)

## 2.账单下载失败如何处理？

(1)请清除缓存后下载；

(2)请更换浏览器操作。

## 3.支付交易对账单和支付交易明细区别

支付交易明细：展示该商户号下全部交易记录，[支付交易明细查询及下载](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-zhifujiaoyi-0000001723301690)。

支付交易对账单：仅展示该商户号下成功的交易记录，[支付交易对账单查询及下载](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-duizhangdan-0000002346156713)。

最终结算结果以结算单为准。

## 4.支付交易明细是否可用于对账

由于支付交易明细存在失败、处理中及冻结交易等，请勿将支付交易明细用作对账使用。

## 5.对账单与结算单金额不一致

请留意当日对账单中是否存在从支付账户进行退款交易、冻结交易未计入结算金额。

您也可以在【交易中心】->【结算管理】->【结算查询】页面，结合结算单明细进一步查看。结算单明细包含在该结算周期清算完成的全部交易信息。

[支付交易对账查询及下载](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-zhifujiaoyi-0000001723301690)

[结算明细查询及下载](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-jiesuandanmingxi-0000001200495008)

## 6.退款出金账户判断

根据**结算明细** 中的"退款来源"判断退款是从**待结算资金** 还是**支付账户余额**扣除

**结算明细获取方式：**登录华为支付商户平台后，进入【交易中心】->【结算管理】->【结算查询】，根据"结算时间"查询并"下载结算明细"。

* 商户平台下载的某日结算明细截取，筛选交易类型为"退款"，根据退款来源字段判断

|TRX3|退款|**-0.3**|50|0|0.3|支付账户|
|TRX4|退款|**9.7**|50|10|0.3|在途资金|

**字段说明：**

|------------|------------------|--------------|
|**字段信息**|**交易类型对应说明**||
|**字段信息**|**收单（COLLECTION）**|**退款（REFUND）**|
|**结算金额（元）**|**已轧差过手续费**的结算金额（针对手续费先收的商户）||
|**订单金额（元）**|实际收单金额（交易金额+优惠金额）|实际操作的退款金额|
|**优惠金额（元）**|营销账户出资的营销资金|营销账户实际收到的退款金额|
|**手续费金额（元）**|订单金额*支付方式对应的手续费率||
|**结算日**|根据**结算周期**进行结算的日期 例：结算日为3月2日，结算周期为T+1 则对应结算的是3月1日对账完成的交易||
|**交易日期**|该结算周期内交易完成的日期||
|**退款来源**|在途资金：**待结算资金扣除** ，支付账户：**支付账户扣除**||
