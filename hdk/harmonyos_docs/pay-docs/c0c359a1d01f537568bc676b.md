# 手续费账户余额查询及提醒

【手续费账户余额查询】：您可以在登录华为支付商户平台后，进入【交易中心】->【资金管理】->【手续费账户】页面，查询手续费账户可用余额。

【手续费账户余额提醒功能设置】：超级管理员可以在登录华为支付商户平台后，进入【交易中心】->【资金管理】->【手续费账户】页面，点击设置余额提醒/关闭余额提醒

> 注意
>
> 1.目前仅支持超级管理员设置手续费余额提醒，修改需间隔7天。
>
> 2.针对已开通手续费余额提醒功能的商户，且商户号状态正常的商户，当商户手续费账户可用余额低于设置的提醒阈值时，触发提醒，8：00-20:00内通知一次。
