# 如何撤销特约商户入网申请

华为支付商户平台支持服务商超级管理员对"草稿"态及资料审核中特约商户撤销入网申请，您可以在登录华为支付商户平台之后，进入【商户中心】->【特约商户管理】->【特约商户管理】页面，根据"申请状态"或"商户名称"查询到草稿态特约商户，点击"撤销申请"进行撤销。

**温馨提示**：

撤销为不可恢复操作，请审慎操作。
