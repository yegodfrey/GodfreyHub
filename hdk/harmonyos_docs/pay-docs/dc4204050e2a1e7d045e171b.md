# 日终账户余额查询

您可以在登录华为支付商户平台后，进入【交易中心】-\>【资金管理】-\>【在途账户】页面，根据交易时间查询商户号日终账户余额。

在途账户余额：指已发生交易但未结算的资金。

冻结金额：已发生交易但未进行分账的资金。

2.日终账户余额仅作商户账户余额参考值统计使用，与结算金额不等同，不可作为对账使用。
