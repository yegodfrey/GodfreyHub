# 如何获取接口对账单及结算单

如您已具备技术对接能力，可以在登录华为支付商户平台后，进入【商户中心】->【产品功能】->【功能设置】页面设置"对账单接口获取开关"及"结算单接口获取开关"。开启后，您可通过接口获取对账单及结算单。

[对账单样例查看](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-query-trade-bill-0000001589055969)，[结算单样例查看](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-query-settle-bill-0000001589121257)
