# 分账交易退款操作

已做分账操作的交易支持退款操作，步骤如下：

**步骤1：发起退款** **交易**

您可以在登录华为支付商户平台后，进入【交易中心】->【交易管理】->【支付交易】页面，先通过交易时间，订单号查询到具体的交易订单，点击"详情"，在详情页面点击"发起退款"。
> 注意
>
> 1.仅交易发起方支持发起退款操作。
>
> 2.若配置退款审核，所有审核人审核通过后华为支付商户平台开始执行退款操作。请审核人登录华为支付商户平台，进入【商户中心】->【审核】->【审核记录】选择待审申请进行审核。[配置退款审核](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-peizhishenhe-0000002188151740)。

**步骤2：确认分账回收金额**

请进入【交易中心】->【交易管理】->【支付交易】页面，先通过交易时间，订单号查询到具体的步骤1发起的退款交易，点击"详情"，在详情页面点击"分账回收"根据订单情况输入回收金额并提交。
> 注意
>
> 1.仅当退款交易状态为成功时，才可进行分账回收确认。
>
> 2.分账回收金额小于等于累计已退款金额。
