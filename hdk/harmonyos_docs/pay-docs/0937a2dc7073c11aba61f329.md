支付流程图
    1. 用户在商户客户端内选择商品下单，选择华为支付。
    2. 进入到华为支付页面，拉起华为支付，展示支付确认界面。
    3. 支付界面中含商品名称信息及待支付金额，点击支付后出现密码验证界面。
    4. 正常输入密码后，华为支付将展示支付结果。
    5. 跳转至商户客户端中，商户可以根据支付返回结果自定义结果内容。
