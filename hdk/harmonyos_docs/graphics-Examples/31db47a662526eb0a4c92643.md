# XRKit示例代码

Android Studio示例代码包含ArSceneView（AR展示场景组件）和ArFaceView（AR人脸场景组件）两种场景的使用实例。

AR展示场景组件，具体功能如下：

* 创建3D场景，提供3D场景的模型呈现。
* 创建AR场景，AR场景真实环境识别与虚拟模型在真实环境的渲染。

AR人脸场景组件，具体功能如下：

提供实时的人脸相关模型呈现，包括表情驱动与人脸贴纸呈现。
