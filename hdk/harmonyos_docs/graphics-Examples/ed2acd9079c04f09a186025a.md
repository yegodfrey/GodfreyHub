# AR Engine示例代码

Android Studio Java/Kotlin示例代码包含Body（人体骨骼追踪）、Face（人脸跟踪）、Hand（人体手部跟踪）、World（平面场景展示）、Health（人脸健康检测）五种特性的使用示例。具体功能如下：

* 人体骨骼追踪，包含人体关节点和骨骼识别能力，可以输出四肢端点、身体姿态、人体骨骼等人体特征。
* 人脸跟踪，并提取人脸跟踪的数据，包含人脸位置、姿态、人脸模型。
* 人体手部跟踪，包含手部骨骼坐标数据、手势识别结果等功能。
* 平面场景展示，包含平面检测、虚拟物体放置、平面语义识别、目标语义识别、3D云识别、2D云识别功能等。
* 人脸健康检测，包含健康检测进度和检测状态、健康检测各项参数等功能。
