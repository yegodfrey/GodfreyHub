# 示例代码

## CG渲染框架

该Android Studio工程包含如下使用示例。

* 基础模型加载和渲染的使用示例，实现了左右滑动模型旋转，上下滑动缩放模型的功能。
* 插件管理框架和超分插件各个接口的使用示例，实现了图片超分的效果。

|名称|**Gitee**|GitHub|
|:-----------------|:-------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------|
|Android Studio示例代码|[链接](https://gitee.com/hms-core/hms-computer-graphics-demo/tree/master/samples/huawei-cg-renderframework-android-cpp-demo)|[链接](https://github.com/HMS-Core/hms-computer-graphics-demo/tree/master/samples/huawei-cg-renderframework-android-cpp-demo)|

> 说明
>
> 您需要完成以下操作才可以运行示例代码：
>
> 1. 生成签名证书，置于示例代码的根目录下，并同步修改示例代码中应用级"build.gradle"中的signingConfigs。
> 2. 修改示例代码中应用级"build.gradle"中的applicationId为自己的应用名。
> 3. 创建模型文件或者选择[已有的模型文件](https://developer.huawei.com/consumer/cn/forum/topicview?tid=0201309841885850221&fid=18)，置于"app/src/main/assets"目录下。
>
>
> 4. 从下载的SDK包中导入头文件和libcgkit.so文件。
>
> 在使用示例代码前请详细阅读示例工程中的"README.md"文件。
