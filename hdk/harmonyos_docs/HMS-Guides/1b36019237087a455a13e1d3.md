# 1 SDK工作方式  


华为全景SDK在应用打包时会被集成进您的应用当中，SDK会随着相关接口的调用而启动和关闭，不会在后台做任何额外动作。全景SDK解码图片只会在运行时留存在内存中，而SDK本身并不对内容做分析，图片内容因为全景服务的原因被截取的风险低。

# 2 SDK权限说明

华为全景SDK需要使用的权限：

读写外部存储的权限：android.permission.WRITE_EXTERNAL_STORAGE，用于读取外部存储上的全景图片。

# 3 SDK数据收集  


华为全景SDK不采集任何用户信息，浏览记录也不会被保存。

# 4 SDK数据安全保护

华为全景SDK不采集任何用户信息，不涉数据安全保护。
