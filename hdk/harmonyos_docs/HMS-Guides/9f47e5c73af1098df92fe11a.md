Scan Kit支持将字符串转换为一维码或二维码，目前已支持的码制式为EAN-8、EAN-13、UPC-A、UPC-E、Codabar、Code 39、Code 93、Code 128、ITF、QR Code、Data Matrix、PDF417、Aztec。开发者只需要提供字符串、码制式和码图尺寸要求，即可获得相应的码图。

# 1\. 业务流程

使用Generate Barcode API来生成码图，主要业务流程如下：

1\. 应用指定码宽度和高度、生成码的字符串和码制式，并初始化“HmsBuildBitmapOptions”对象。

2\. 应用调用HMS SDK中的“buildBitmap”生成码接口。

3\. HMS SDK返回生成的QR码图给应用。

# 2\. 开发步骤

1\. 根据实际需求设置生成码的字符串值，指定生成码图的宽度和高度，指定码制式（支持的码制式参见[Scan Kit支持的码制式](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/scan-code-4)）。
    
    
    复制
      
        1. String content = "QR Code Content";  
        2. int type = HmsScan.QRCODE_SCAN_TYPE; 
        3. int width = 400;  
        4. int height = 400;
    
    

2\. （可选）初始化“HmsBuildBitmapOption”，设置可选参数 。

   开发者可以通过如下方式设置可选参数。当不需要定制如下参数时，可以跳过此步骤。

  * setBitmapBackgroundColor()：设置码图背景色，如果不设置时，默认背景色为白色（Color.WHITE）。

  * setBitmapColor()：设置码图颜色，如果不设置时，默认码图颜色为黑色（Color.BLACK）。

  * setBitmapMargin()：设置码图边框宽度，如果不设置时，默认码图边框宽度为1。



    
    
    复制
      
        1. HmsBuildBitmapOption options = new HmsBuildBitmapOption.Creator().setBitmapBackgroundColor(Color.RED).setBitmapColor(Color.BLUE).setBitmapMargin(3).create();
    
    

3\. 调用“buildBitmap”接口生成码。
    
    
    复制
      
        1. try { 
        2.     //如果未设置HmsBuildBitmapOption对象，生成二维码参数options置null” 
        3.     Bitmap qrBitmap = ScanUtil.buildBitmap(content, type, width, height, options); 
        4. } catch (WriterException e) { 
        5.     Log.w("buildBitmap", e); 
        6. }
    
    

当输入参数不合法时，会抛出异常，需要显式的捕获“WriterException”异常。生成码参数设置请参考[生成码参数建议](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/scan-generation-recommend)。
