# 1 产品介绍

华为位置服务以HTTPS形式为第三方开发者提供了一套API，可用于开发以下位置相关功能。在API被调用时，相关数据通过JSON格式返回。

  * **关键字搜索**

指定了文本搜索字符串和可选的地理范围，查询诸如旅游景点、企业和学校之类的地点。

  * **周边搜索**

搜索指定区域内的地点。开发者可以通过提供关键字或指定要搜索的地点的类型来优化搜索请求。

  * **地址详情**

根据地点的唯一主键地点ID获取地点详情。

  * **输入提示**

可用于在键入时返回建议的查询，从而为基于文本的地理搜索提供查询预测，最多返回5条记录。

  * **正向地理编码**

获取地点对应的经纬度，最多返回10条记录。

  * **逆向地理编码**

获取经纬度对应的地点，最多返回5条记录。

  * **获取时区**

根据经纬度获取地区的时区信息。




注意：

使用以上服务需要开发者在AppGallery Connect上打开Site API权限开关，具体操作步骤请参见[开通服务](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-enable_service)。

# 2 使用限制  


1\. 位置搜索服务使用前，需要获取API KEY。获取API KEY的方式如下：

     a. 登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) 网站，选择“我的应用”。

     b. 点击对应的应用名称，进入应用开发页面。

     c. 在应用区域可以找到“API key”，点击右方的复制按钮即可获取。
