# 1 应用接入获取鉴权凭证Access Token

## 1.1 申请授权码code请求

用户选择“华为帐号”来进行登录，应用处理该按钮的点击事件，拼接OAuth服务请求授权的链接，把用户浏览器重定向到该请求链接，跳转访问OAuth服务。

HTML示例如下：
      
      1. <html>  
         
        2. <head>  
         
        3.     <title>Demo</title>  
         
        4.     <meta http-equiv="Content-Type" content="text/html; charset=UTF-8" />  
         
        5.     <meta name="client_id" content="**< APP ID>**" />  
         
        6.     <meta name="redirect_uri" content="**< 应用的回调地址>**" />  
         
        7.     <meta name="scope" content="openid+profile" />  
         
        8. </head>  
         
        9. <body>  
         
        10.     <p> <button id="hwlogin" onclick=redirect()>HUAWEIID login</button></p>  
         
        11. </body>  
         
        12. <script type="text/javascript">  
         
        13.          var client_id ='',redirect_uri='',scope='';  
         
        14.          for(var metas=document.getElementsByTagName("meta"),i=0;i<metas.length;++i){  
         
        15.                    switch(metas[i].name) {  
         
        16.               case 'client_id':  
         
        17.                  client_id = metas[i].content;  
         
        18.                  break;  
         
        19.               case 'redirect_uri':  
         
        20.                   redirect_uri = metas[i].content;  
         
        21.                  break;  
         
        22.               case 'scope':  
         
        23.                  scope = metas[i].content;  
         
        24.                  break;  
         
        25.               default:break  
         
        26.                    }  
         
        27.          }  
         
        28.          var redirectUrl='https://oauth-login.cloud.huawei.com/oauth2/v3/authorize?'+  
         
        29.          'response_type=code&access_type=offline&state=state_parameter_passthrough_value&client_id='+client_id +'&redirect_uri='+ redirect_uri +'&scope='+ scope;  
         
        30. function redirect() {  
         
        31.          window.location.href=redirectUrl;  
         
        32. }  
         
        33. </script>  
         
        34. </html>  
         
    
    

跳转链接地址如下：
      
      1. https://oauth-login.cloud.huawei.com/oauth2/v3/authorize?  
         
        2. response_type=code&  
         
        3. access_type=offline&  
         
        4. state=state_parameter_passthrough_value&  
         
        5. client_id=**< APP ID>**&  
         
        6. redirect_uri=**< 应用的回调地址>**&  
         
        7. scope=openid+profile 
    
    

参数名称| 必选(M)/可选(O)| 参数说明  
---|---|---  
response_type| M| 填写为code，授权码模式               
client_id| M| 在[应用开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/account-web-preparation)中创建的服务器应用的APP ID               
redirect_uri| M  
                | 授权后要回调的地址URI，即应用接收授权码code的URI。必须跟在[应用开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/account-web-preparation)中所配置的回调地址保持一致。在回调地址后，可附加其他参数，如：                 配置的是回调地址为：                 https://www.thirdwebdemo.com/redirect_url，                 在回调地址后添加其他参数，如：                 https://www.thirdwebdemo.com/redirect_url?somearg=XXXXXX                   
scope| M| 一个字符串数组，以空格分开（url编码后空格变为加号+），必须包含字符串“openid”               
access_type| O| 值设为offline时，可同时生成Refresh Token，用于刷新Access Token               
state| O| 随机串，用于防CSRF，在返回授权码code时原封不动返回

## 1.3 OAuth服务的响应

OAuth服务将响应值通过回调地址redirect_uri回调给应用。

  * 如果用户同意授权，则回调请求中带有授权码code。

  * 如果用户不同意授权，则回调请求中包含错误消息。




示例如下：

  * 带授权码code的回调请求



      
      1. https://www.thirdwebdemo.com/redirect_url?  
         
        2. code=**< 返回的授权码code>**&  
         
        3. state=state_parameter_passthrough_value  
         
    
    

  * 带错误信息的回调请求



      
      1. https://www.thirdwebdemo.com/redirect_url #error=1107&error_description=access+denied  
         
    
    

## 1.4 授权码code换取鉴权凭证Access Token

应用在获取到授权码code后，再次请求OAuth服务，调用接口（https://oauth-login.cloud.huawei.com/oauth2/v3/token），通过授权码code换取鉴权凭证Access Token、Refresh Token以及ID Token。

示例如下：

  * 请求



      
      1. POST /oauth2/v3/token HTTP/1.1  
         
        2. Host: oauth-login.cloud.huawei.com  
         
        3. Content-Type: application/x-www-form-urlencoded  
         
        4. grant_type=authorization_code&  
         
        5. code=**< 返回的授权码code>**&  
         
        6. client_id=**< APP ID>**&  
         
        7. client_secret=**< APP SECRET>**&  
         
        8. redirect_uri=**< 应用的回调地址>**  
         
    
    

参数名称| 必选(M)/可选(O)| 参数说明  
---|---|---  
grant_type| M| OAuth 2.0规范定义的字段，必须为authorization_code               
code| M| 与1.3 OAuth服务的响应中返回的授权码code一致               
client_id| M| [应用开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/account-web-preparation)中创建的服务器应用的APP ID               
client_secret| M| [应用开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/account-web-preparation)中给创建服务器应用ID分配的密钥APP SECRET               
redirect_uri| M| 与1.1申请授权码code请求传入的回调地址一致               
  
  * 响应



      
      1. HTTP/1.1 200 OK  
         
        2. Content-Type: text/json ; charset=UTF-8  
         
        3. Cache-Control: no-store  
         
        4. {  
         
        5.   "access_token": "**< 返回的鉴权凭证Access Token>**",  
         
        6.   "refresh_token": "**< 返回的Refresh Token>**",  
         
        7.   "expires_in": 3600,  
         
        8.   "scope": "profile openid",  
         
        9.   "token_type": "Bearer",  
         
        10.   "id_token": "**< 返回的JWT格式的用户信息ID Token>**"  
         
        11. }  
         
    
    

参数名称| 必选(M)/可选(O)| 参数说明  
---|---|---  
access_token| M| 用户的鉴权凭证Access Token               
expires_in| M| Access Token的剩余有效期，单位：秒               
scope| M| 生成的鉴权凭证Access Token中包含的scope               
token_type| M| 固定返回Bearer，标识返回鉴权凭证Access Token的类型               
id_token| M| 返回[JWT格式数据](https://jwt.io/introduction/)，如果1.1申请授权码code请求的入参scope中包含权限profile、email，应用在本地完成id_token校验后（请参考5.1 本地验证），可直接解析JWT数据得到用户基本帐号信息、用户邮箱信息，无需再次请求华为用户信息服务器进行获取（解析后字段请参考5.2 Id_token解析字段）  
refresh_token| O| 如1.1申请授权码code请求的入参中包含access_type=offline，则会返回此参数，该参数用于刷新Access Token  
  
至此，应用已经完成华为帐号的接入，获得到了用户的基本帐号信息，如需调用华为其他公开的API，请继续阅读后续内容。  


# 2 应用调用华为API

应用调用华为API时，把已获得API调用授权的鉴权凭证Access Token，放在Authorization头部来进行鉴权。

示例：调用/openapi/inner/v1/sports/dailySteps接口，在前面1.1申请授权码code请求时，scope中包含调用此接口的权限项：https://www.huawei.com/health/sport.readonly，则可将获取的鉴权凭证Access Token放在请求头Header中来调用此接口。如下：
      
      1. GET /openapi/inner/v1/sports/dailySteps?startDate=<业务参数1>&endDate=<业务参数2> HTTP/1.1  
         
        2. Host: <XXX>  
         
        3. Content-Type: multipart/form-data; boundary=----WebKitFormBoundary7MA4YWxkTrZu0gW  
         
        4. Accept: application/json  
         
        5. x-huid: <业务参数3>  
         
        6. x-appid: <业务参数4>  
         
        7. x-client-version: <业务参数5>  
         
        8. x-prdPkgName: <业务参数6>  
         
        9. cache-control: no-cache  
         
        10. Authorization: Bearer **< 已经获得的鉴权凭证Access Token>**  
         
    
    

# 3 应用刷新鉴权凭证Access Token（offline access）

鉴权凭证Access Token存在有效期，过期后则不可用，如果继续调用会导致鉴权失败。故建议应用在拼接1.1申请授权码code请求时，增加access_type=offline的入参，如此，则在生成鉴权凭证Access Token的同时，也生成Refresh Token。（注意，二者不可替用）

其中Refresh Token的有效期较长（当前默认有效期180天），在有效期内，应用可直接通过Refresh Token调用Oauth服务的接口（https://oauth-login.cloud.huawei.com/oauth2/v3/token），获取新的鉴权凭证Access Token，避免重新弹出用户授权页面去引导用户再次进行登录授权。

示例如下：

  * 请求         



      
      1. POST /oauth2/v3/token HTTP/1.1  
         
        2. Host: oauth-login.cloud.huawei.com  
         
        3. Content-Type: application/x-www-form-urlencoded  
         
        4. grant_type=refresh_token&  
         
        5. client_id=**< APP ID>**&  
         
        6. client_secret=**< APP SECRET>**&  
         
        7. refresh_token=**< 已经授权拿到的Refresh Token>**  
         
    
    

  


  * 响应         



      
      1. HTTP/1.1 200 OK  
         
        2. Content-Type: text/html;charset=UTF-8  
         
        3. Cache-Control: no-store  
         
        4. {  
         
        5.   "access_token": "**< 新的鉴权凭证Access Token>**",  
         
        6.   "expires_in": 3600,  
         
        7.   "id_token": "**< 返回的JWT格式的用户信息ID Token >**",  
         
        8.   "scope": "profile openid",  
         
        9.   "token_type": "Bearer"  
         
        10. }
    
    

# 4 取消授权

应用可以调用取消授权的接口（https://oauth-login.cloud.huawei.com/oauth2/v3/revoke），对已授权的鉴权凭证Access Token或者Refresh Token进行取消授权。其中，Access Token与Refresh Token为成对关系，取消授权其中一个，另一个也同样失效。

示例如下：

  * 请求         



      
      1. POST /oauth2/v3/revoke HTTP/1.1  
         
        2. Host: oauth-login.cloud.huawei.com  
         
        3. Content-Type: application/x-www-form-urlencoded  
         
        4. token=**< 待取消的鉴权凭证Access Token>**
    
    

  * 响应   



      
      1. HTTP/1.1 200 OK
        2. Cache-Control: no-store
        3. Pragma: no-cache
        4. {}

## 5.1 本地验证

1、从https://oauth-login.cloud.huawei.com/.well-known/openid-configuration的返回值，取获取公钥URI的字段jwks_uri，请求该URI，访问获取公钥（公钥每天更新一次，应用服务器可对公钥的值进行缓存）。
      
      1. //JAVA_Demo示例参考：  
         
        2. getRSAPublicKeyByKid(decoder.getKeyId());  
         
    
    

2、验证签名。ID Token是JWT格式的，验证ID Token的签名可以采用通用的JWT库，例如[jwt.io](https://jwt.io/)。
      
      1. //JAVA_Demo示例参考：  
         
        2. DecodedJWT decoder = JWT.decode(idToken);  
         
        3. Algorithm algorithm = Algorithm.RSA256(getRSAPublicKeyByKid(decoder.getKeyId()) , null);  
         
        4. JWTVerifier verifier = JWT.require(algorithm).build();  
         
        5. //验证签名  
         
        6. verifier.verify(decoder);  
         
    
    

3、验证ID Token中iss字段的值是否等于“https://accounts.huawei.com”。
      
      1. //JAVA_Demo示例参考：  
         
        2. decoder.getIssuer().equals(ID_TOKEN_ISSUE);  
         
    
    

4、验证ID Token中aud字段的值等于应用的client_id。
      
      1. //JAVA_Demo示例参考：  
         
        2. decoder.getAudience().get(0).equals(CLIENT_ID);  
         
    
    

5、验证ID Token中的过期时间（exp字段）是否已过期。
      
      1. //JAVA_Demo示例参考：  
         
        2. verifier.verify(decoder);//过期，会抛出TokenExpiredException异常  
         
    
    

6、如果以上验证均通过，则表示用户ID Token验证通过，应用可直接解析ID Token中的用户信息。
      
      1. //JAVA_Demo示例参考：  
         
        2. JSONObject jsonObject = JSONObject.parseObject(new String(Base64.decodeBase64(decoder.getPayload())));

## 5.2 Id_token解析字段

应用对id_token字段进行签名验证，解析后得到字段映射表与生成id_token的scope包含的权限项openid、email、profile。 

Scope包含权限项 openid 时，解析的字段映射表如下：

参数名称             | 必选(M)/可选(O)             | 类型             | 参数说明               
---|---|---|---  
iss| M| String| 固定值：https://accounts.huawei.com               
sub| M| String| 用户对同一个开发者下的所有应用，此值唯一               
aud| M| String| 应用ID，标识ID Token包含此应用ID的信息               
exp| M| Long| 过期时间               
iat| M| Long| ID Token生成时间               
nonce| O| String| 随机字符串               
at_hash| O| String| Access Token的哈希值               
azp| O| String| 应用ID，标识ID Token由此应用ID生成               
  
  


Scope包含权限项 email 时，解析的字段映射表如下：

参数名称| 必选(M)/可选(O)| 类型| 参数说明  
---|---|---|---  
email_verified| O| Boolean| 用户邮箱是否已验证                 ● true：是                 ● false：否                   
email| O| String| 用户邮箱地址               
  
  


Scope包含权限项 profile 时，解析的字段映射表如下：

参数名称| 必选(M)/可选(O)| 类型| 参数说明  
---|---|---|---  
picture| O| String| 用户头像图片链接               
name| O| String| 用户的全名（姓和名拼在一起）               
locale| O| String| 用户语言偏好，例如"zh-cn"、"en-us"               
family_name| O| String| 姓               
given_name| O| String| 名               
display_name| O| String| 华为帐号对应的昵称
