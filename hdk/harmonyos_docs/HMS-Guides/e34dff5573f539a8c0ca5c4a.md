# Identity Kit 4.0.0版本 (2020-01-15)

最新子版本号：4.0.0.300

华为推出了全新的HMS Identity SDK 4.0.0版本，该SDK中用户身份服务是首次发布，包含地址查询、管理特性，欢迎广大开发者接入。

#### 新增特性  


Identity提供了地址查询接口，开发者仅需三步即可获取用户地址并解析。

1、使用new UserAddressRequest实例化请求对象，调用getUserAddress接口。

2、调用Status的startResolutionForResult方法拉起选择华为用户身份服务的地址选择页面。

3、用户选择地址完成后在页面的onActivityResult中调用UserAddress的parseIntent方法从结果中获取用户选择的地址信息。

# SDK依赖说明

1、最新版本SDK需要用户手机上安装华为移动服务4.0.0.300及以上版本； 如果用户手机没有安装，您的应用调用华为移动服务时，会自动引导用户提示安装。

2、本服务的主要特性都可以在大多数华为终端上支持，部分高级特性依赖于EMUI版本。请参考[部分特性对于EMUI的依赖说明](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/emui_version_dependent_features)。
