# 1\. 场景介绍

成就是激励玩家深入发掘游戏并提高其游戏水平的一种富有趣味的途径。成就既可以代表玩家在游戏中的“丰功伟绩”（例如战胜了众多对手，或闯过了一系列关卡），也可以代表玩家掌握了在游戏开始时不具备的强力技能。您可以定期添加成就，以保持游戏的新鲜感并鼓励玩家持续参与。一个成就包含的基本属性如下：

  * 成就ID：在配置成就时由AppGallery Connect生成，用于唯一标识一个成就。  


  * 成就名称：成就的名称，在配置成就时由开发者自行定义，最大支持100个字符。  


  * 成就说明：对成就的具体描述信息，通常情况下描述如何达成成就，最大支持500个字符。  


  * 成就图标：成就在游戏中解锁后的图标，图标大小必须为512x512 px，图标文件必须为png或jpg文件，图标中建议不要包含任何本地化的文字。HMS SDK将根据此图标自动生成一个灰度版本的图标，作为成就未解锁时的图标。  


  * 成就状态：一个成就在游戏中按照生命周期可分为3种状态。  


 \- 隐藏的成就：意味着有关成就的详细信息对玩家隐藏。隐藏的成就提供了一个描述信息和成就图标，同时处于隐藏状态。如果开发者不想太早揭秘游戏里的剧情，可以在配置成就时将其设置为隐藏状态。待游戏进行到特定场景，再将该成就揭秘给玩家。  
 \- 显示的成就：意味着玩家知道成就，但尚未获得成就。如果开发者需要在玩家开始游戏时就向玩家展示该成就，在配置成就时即可将其设置为显示状态。  
 \- 解锁的成就：意味着玩家已成功获得成就。此状态在配置成就时不可设置，必须由玩家完成成就来达成解锁成就的状态，解锁成就时会在页面顶部展示提示框。目前HMS SDK支持游戏离线解锁成就。当玩家再次登录，HMS SDK会与华为游戏服务同步，以更新成就的解锁状态。  


  * 成就步长：成就可以分为标准成就和分步成就。分步成就是指用户解锁成就之前，需要完成预设步数的成就，此预设的步数即为成就步长。  


  * 列表顺序：当前成就在所有成就中排列的顺序，由开发者在配置成就时指定。




HMS SDK支持应用对成就进行如下操作：  


  * 直接跳转到华为[应用助手](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/application-assistant)的成就列表页面。  


  * 获取当前玩家的成就列表数据后自行向用户展示成就列表页面。  


  * 增长某个分步成就的当前步长，例如某个成就需5步完成，玩家从第2步完成到第3步，则需要将成就的当前步长增加1步。  


  * 直接设置某个分步成就的当前已完成的步长，例如某个成就需5步完成，玩家从第2步直接完成到第5步，可以直接将成就的当前步长设置为5。  


  * 向玩家揭秘某个隐藏的成就。  


  * 为当前玩家解锁某个成就。  





# 2\. 业务流程

**初始化AchievementsClient**

1、玩家登录游戏后开始游戏。

2、应用调用[Games.getAchievementsClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/games-v4#getAchievementsClient)方法请求初始化[AchievementsClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/achievementsclient-v4)实例。

3、 HMS SDK向应用返回[AchievementsClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/achievementsclient-v4)实例。

**展示成就列表页面（自行展示）**

1、玩家进入成就列表页面。

2、应用调用[AchievementsClient.getAchievementList](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/achievementsclient-v4#getAchievementList)方法请求获取当前玩家的成就数据。

3、HMS SDK向应用返回包含当前用户成就数据的[Achievement](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/achievement-v4)对象列表。

4、应用从[Achievement](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/achievement-v4)对象中解析当前玩家的成就数据后向用户展示成就列表。

**展示成就列表页面（直接跳转）**

注意：

只有游戏正式上架后应用助手才能正常展示成就列表，测试阶段无法正常展示。

1、玩家进入成就列表页面。

2、应用调用[AchievementsClient.getShowAchievementListIntent](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/achievementsclient-v4#getShowAchievementListIntent)方法请求获取成就列表页面。

3、HMS SDK以异步方式向应用返回跳转到成就列表页面的Intent对象。

4、应用必须通过调用页面的**startActivityForResult(Intent, int)** 方法向[应用助手](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/application-assistant)拉起成就列表页面。

5、应用助手向用户展示成就列表页面。

**揭秘成就**

1、用户在玩游戏时触发隐藏成就。

2、应用根据实际情况选择调用[AchievementsClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/achievementsclient)的**visualize** 或**visualizeWithResult** 方法请求揭秘指定的隐藏成就。  


  * 如果设备当前无网络或应用无需立即获取操作结果，可选择**visualize** 方法。  





注意：

使用visualize方法提交数据时不能保证立即提交到华为服务器，可能会存在数据的延迟。

  * 如果应用需立即获取操作结果，可选择**visualizeWithResult** 方法。




3、如果应用使用**visualizeWithResult** 方法揭秘成就，HMS SDK将以异步方式返回操作结果。

**增长成就步长**

1、用户完成某个分步成就的步数。

2、应用根据实际情况调用[AchievementsClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/achievementsclient-v4)的**grow** 或**growWithResult** 方法请求增长当前成就的步长。

  * 如果设备当前无网络或应用无需立即获取操作结果，可选择**grow** 方法。  


注意：

使用grow方法提交数据时不能保证立即提交到华为服务器，可能会存在数据的延迟和误差。

  * 如果应用需立即获取操作结果，可选择**growWithResult** 方法。




3、如果应用使用****growWithResult**** 方法增长成就步长，HMS SDK将以异步方式返回操作结果。  


如果成就增长后的步数刚好达到成就的最大步数，HMS SDK将返回7202返回码，表示增长步数后自动触发解锁成就，属于增长成功。

**设****置成就步长**

1、用户完成某个分步成就。

2、应用根据实际情况调用[AchievementsClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/achievementsclient-v4)的**makeSteps** 或**makeStepsWithResult** 方法请求设置成就的当前步长。

  * 如果设备当前无网络或应用无需立即获取操作结果，可选择**makeSteps** 方法。

注意：

使用makeSteps方法提交数据时不能保证立即提交到华为服务器，可能会存在数据的延迟和误差。

  * 如果应用需立即获取操作结果，可选择**makeStepsWithResult** 方法。




3、如果应用使用**makeStepsWithResult** 方法设置成就步长，HMS SDK将以异步方式返回操作结果。

如果设置后的步数刚好达到成就的最大步数，HMS SDK将返回7202返回码，表示增长步数后自动触发解锁成就，属于设置成功。

**解锁成就**

1、用户完成某个成就。

2、应用根据实际情况调用[AchievementsClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/achievementsclient-v4)的**reach** 或**reachWithResult** 方法请求解锁成就。

  * 如果设备当前无网络或应用无需立即获取操作结果，可选择**reach** 方法。

注意：

使用reach方法提交数据时不能保证立即提交到华为服务器，可能会存在数据的延迟和误差。

  * 如果应用需立即获取操作结果，可选择**reachWithResult** 方法。




3、如果应用使用**reachWithResult** 方法解锁成就，HMS SDK将以异步方式返回操作结果。

# 3\. 注意事项

  * 必须已经提前在AppGallery Connect中配置成就信息，参见[配置成就](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/game-preparation-v4#achevements_config)。

  * 调用成就相关接口时，用户的华为帐号必须为已登录状态。  


  * 游戏设备的操作系统必须是EMUI9.0及以上版本，且安装了10.1及以上版本的应用助手，才能支持应用助手展示成就列表的功能。

  * 用户必须打开华为应用市场（10.3及以上版本）中的游戏服务开关才能使用成就功能。如果用户没有开启游戏服务开关，当游戏调用成就相关接口时HMS SDK会自动拉起华为应用市场的游戏服务开关页面引导用户打开开关，如果用户未打开游戏服务开关，将返回7018错误码，游戏需要主动提示用户到华为应用市场“我的-设置-游戏服务”页面中开启游戏服务开关后才能使用成就功能。




说明：

用户打开游戏服务授权后，建议您在游戏中提供取消游戏服务授权的功能，可调用[GamesClient.cancelGameService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/gamesclient-v4#cancelGameService)方法实现。
