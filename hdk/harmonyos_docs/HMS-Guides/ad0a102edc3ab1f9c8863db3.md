# SDK工作方式

IAP SDK提供移动端SDK。移动端SDK需要在应用打包时，加载到您的应用中。SDK会随着应用启动而运行在客户进程中。当用户关闭应用时，SDK会随着客户应用关闭而关闭，不会在后台做额外的操作。

# SDK权限说明

IAP SDK需要使用的权限：

  * 网络访问权限：android.permission.INTERNET

  * 存储权限：android.permission.READ_EXTERNAL_STORAGE

  * Android8.0及以上系统允许安装未知来源应用权限：android.permission.REQUEST_INSTALL_PACKAGES

  * 获取网络状态权限：android.permission.ACCESS_NETWORK_STATE

  * 获取WiFi状态权限：android.permission.ACCESS_WIFI_STATE




# SDK收集数据

SDK不会收集个人数据，但会上报API调用结果到华为服务器。

SDK会使用客户应用的appid、包名和接口调用情况，用于牵引IAP服务能力的持续优化和改进。

# SDK数据安全保护

IAP SDK与IAP端侧之间的数据交换是基于Binder进行传输的，Android系统本身的安全机制保障了基于Binder传输的数据安全。

IAP服务器会对购买详情数据签名，IAP 端侧将购买详情数据及其签名返回给您的应用，通过签名验证保证购买详情数据无法篡改。
