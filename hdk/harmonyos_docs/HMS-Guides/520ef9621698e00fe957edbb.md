# 1.业务简介

      通过华为帐号开放服务，服务器应用可以方便、安全地实现快速登录授权功能，凭借用户授权凭证，应用可快速调用华为提供的公开API。

# 2.服务特点

  * 安全、方便




具备高安全性密码验证和手机号验证双因素认证，可安全方便地实现华为帐号登录。

  * 一站式访问




通过华为帐号，可实现快速访问华为众多的公开API。

# 3.实现流程

  ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200113222141.68470784662196772438879189711000:50510218034934:2800:8AA378153B40CF1EB97A2129B0FF844FB4F8C95788583CA5792E8FD50436E0B7.png)

  1. 用户在WEB服务器中选择 华为帐号 的登录方式；

  2. WEB服务器发送authorize授权请求，用户在登录页面输入华为帐号、密码；

  3.  华为服务器与WEB服务器两次交互，返回用户鉴权凭证token；

  4. WEB服务器可凭借此用户鉴权凭证token，访问华为其他公开API，并将返回结果处理后呈现给用户。
