# 功能简介

可以自定义用户行为漏斗，分析业务中的关键步骤转化率，发现影响体验和转化的关键节点，为产品优化提供依据。

# 功能详述

## 操作流程

1.登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，单击“我的项目”图标。

2.选择需要查看分析数据的应用。

3.单击“分析 > 漏斗分析”进入漏斗分析页面。

## 查看概览

在“漏斗分析”页面，您可以：

查看已经创建的漏斗列表，包括每个漏斗的基本信息，如名称、说明、创建时间等。

单击“漏斗分析”页面右上角的“创建漏斗转化分析”按钮，可以创建新的漏斗，包括三种预定义漏斗和自定义漏斗。新建的漏斗，次日生效。

参数填写说明如下表所示：

**参数**| **填写说明**  
---|---  
漏斗名称| 填写便于您记忆和理解的漏斗名称。  
说明| 填写您创建此漏斗的目的、业务语义等信息。  
转化周期| 选择计算转化事件的方式：按会话或按自然天，区别在于对用户完成漏斗的时间限制不同。按会话：用户在同一个会话中，从第一个步骤，行进到最后一个步骤，即被视为一次成功的转化。按自然天：用户在同一自然天中，从第一个步骤，行进到最后一个步骤，即被视为一次成功的转化。  
选择跟踪的事件| 按照您的业务场景添加合适的追踪事件。至少需要添加两个追踪事件，最多添加十个追踪事件。  
添加参数| 您可以在追踪事件下添加参数，对事件参数进行过滤，满足精细化运营的述求，最多添加十个对应参数。

3）**添加对比分析**

漏斗分析支持针对某个指标进行对比分析，支持应用类型对比、应用对比、用户属性对比、受众对比。比如您可以对比不同设备品牌的漏斗转化率情况，或对用户分类进行下钻分析。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200509183757.51983907877355851351047968479323:50510511080758:2800:2C7FE60BE56BF5596D4D197683249F7B727FC2835AFEB24FACC181112E7FB815.png?needInitFileName=true)

单击上图（1）处选择过滤条件，单击图（2）处添加对比分析条件，则（3）处则出现对比详情，但当前（4）处表格数据不支持展示对比值。单击图（5）处的清除图标，可清除对比条件。

# 规格说明

  * 漏斗名称：长度不超过255个字符。

  * 描述：长度不超过1000个字符。

  * 漏斗个数：一个项目不超过100个。

  * 创建/修改漏斗后，次日生效。
