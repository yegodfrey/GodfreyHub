在开始API开发工作之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-process-4)，同时请确保您的工程中已经[配置HMS Core SDK的maven仓地址](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-maven-4)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-language-sdk-4)。

## 设备侧语种检测

1\. 创建语种检测器。可以通过语种检测器自定义参数类[MLRemoteLangDetectorSetting](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLDetectorSetting-4)创建检测器。
      
      1. // 创建本地语种检测器。
        2. MLLangDetectorFactory factory = MLLangDetectorFactory.getInstance();
        3. MLLocalLangDetectorSetting setting = new MLLocalLangDetectorSetting.Factory()
        4.     // 设置语种检测的最低置信度阈值。
        5.     .setTrustedThreshold(0.01f)
        6.     .create();
        7. MLLocalLangDetector mlLocalLangDetector = factory.getLocalLangDetector(setting);
    
    

2\. 进行语种检测。
      
      1. // 方式1：返回多个语种检测结果，包括语种编码以及置信度，sourceText表示待检测的文本，长度需小于5000个字符。
        2. Task<List<MLDetectedLang>> probabilityDetectTask = mlLocalLangDetector.probabilityDetect(sourceText); // sourceText 是输入的String类型文本信息。
        3.     probabilityDetectTask.addOnSuccessListener(new OnSuccessListener<List<MLDetectedLang>>() {
        4.      @Override
        5.       public void onSuccess(List<MLDetectedLang> mlDetectedLangs) {
        6.              // 语种检测成功回调。
        7.         }
        8.     }).addOnFailureListener(new OnFailureListener() {
        9.         @Override
        10.         public void onFailure(Exception e) {
        11.             // 语种检测失败回调。
        12.      }
        13. });
        14. // 方式2：返回置信度最高的语种编码，sourceText表示待检测的文本，长度需小于5000个字符。
        15. Task<String> firstBestDetectTask = mlLocalLangDetector.firstBestDetect(sourceText);// sourceText 是输入的String类型文本信息。
        16. firstBestDetectTask.addOnSuccessListener(new OnSuccessListener<String>() {
        17.     @Override
        18.     public void onSuccess(String s) {
        19.         // 成功的处理逻辑。
        20.     }
        21. }).addOnFailureListener(new OnFailureListener() {
        22.     @Override
        23.     public void onFailure(Exception e) {
        24.         // 失败的处理逻辑。
        25.     }
        26. });
    
    

3\. 识别完成后，释放资源。
      
      1. if (mlRemoteLangDetector != null) { 
        2.     mlRemoteLangDetector.stop(); 
        3. }
    
    

## 云侧语种检测

1\. 创建语种检测器。可以通过语种检测器自定义参数类[MLRemoteLangDetectorSetting](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLDetectorSetting-4)创建检测器。
      
      1. // 方式1：使用默认的参数配置创建语种检测器。
        2. MLRemoteLangDetector mlRemoteLangDetector = MLLangDetectorFactory.getInstance()
        3.     .getRemoteLangDetector();
        4. // 方式2：使用自定义的参数配置创建语种检测器。
        5. MLRemoteLangDetectorSetting setting = new MLRemoteLangDetectorSetting.Factory()
        6.     // 设置语种检测的最低置信度阈值。
        7.     .setTrustedThreshold(0.01f)
        8.     .create();
        9. MLRemoteLangDetector mlRemoteLangDetector = MLLangDetectorFactory.getInstance()
        10.     .getRemoteLangDetector(setting);
    
    

2\. 进行语种检测。
