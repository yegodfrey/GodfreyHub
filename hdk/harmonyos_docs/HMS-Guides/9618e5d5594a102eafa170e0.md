[问题一]**如何开启模拟位置特性？**

使用模拟位置接口前，必须在设备上开启模拟位置特性。

你可以通过如下菜单来开启模拟位置特性：

设置 -> 系统 -> 开发者选项 -> 选择模拟位置应用 -> 选择应用。

* * *

[问题二]**需要添加什么依赖？**

请参见章节[集成HMS React Native SDK](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/location-preparation-rn)。

* * *

[问题三]**如何获取权限请求的响应?**

您无法获得请求响应。 如需执行需要特定权限的操作，您需要使用合适的hasPermission()函数来手动检查权限状态。

* * *

[问题四]**使用”react-native run-android"命令遇到error：“Task :app:transformNativeLibsWithMergeJniLibsForDebug FAILED“？**

在 android/app/build.gradle 中的android节点下增加：
    
    
    复制
      
        1. packagingOptions {
        2.     pickFirst '**/libjsc.so'
        3.     pickFirst 'lib/x86/libc++_shared.so'
        4.     pickFirst 'lib/x86_64/libjsc.so'
        5.     pickFirst 'lib/arm64-v8a/libjsc.so'
        6.     pickFirst 'lib/arm64-v8a/libc++_shared.so'
        7.     pickFirst 'lib/x86_64/libc++_shared.so'
        8.     pickFirst 'lib/armeabi-v7a/libc++_shared.so'
        9. }
    
    

* * *

[问题五]**使用”react-native run-android"命令，遇到：Failed to load bundle(http://localhost:8081/index.bundle?platform=ios &dev=true&minify=false) with error？**

在命令行中执行以下语句：
    
    
    复制
      
        1. npm uninstall babel-preset-react-native
        2. npm install babel-preset-react-native@2.1.0 -save
