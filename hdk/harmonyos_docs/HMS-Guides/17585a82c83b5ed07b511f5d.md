# 1\. 概述

服务帐号是一种可实现服务器与服务器之间接口鉴权的帐号 ，在华为开发者联盟的[API Console](https://developer.huawei.com/consumer/cn/console#/credentials/projectKey=dev7519896637536769923)上创建服务帐号，开发者可根据返回的公私钥在业务应用中生成鉴权凭证，调用支持此类鉴权的华为公开API。  


# 2\. 生成服务帐号鉴权凭证

服务帐号凭证为JWT（JSON Web Token）格式字符串，JWT数据格式包括三个部分：

Header（头部）

Payload（负载）

Signature（签名）

这三个部分通过"."进行连接，其中Signature为通过SHA256withRSA算法对Header与Payload拼接的字符串签名生成的字符串。

示例：
    
    
    复制
      
        1. eyJraWQiOiJjNjBjMXXX.
        2. eyJhdWQiOiJodHRXXX.
        3. BRNssZfU0r7az5oU7-Zp5g9X2WJVXXX
    
    

更多JWT的相关知识请参考：<https://jwt.io/introduction/>

## 2.2生成JWT Header数据

根据文件中的key_id字段拼接JSON体，对JSON体进行BASE64编码。

示例：

拼接的JSON体
    
    
    复制
      
        1. {
        2.   "kid": "18366af0b4b44dd8bb4a77184d04704f",
        3.   "typ": "JWT",
        4.   "alg": "RS256"
        5. }
    
    

字段名  
| 描述  
---|---  
kid  
| 服务帐号json文件中key_id字段  
typ| 固定为：JWT  
alg| 固定为：RS256  
  
BASE64编码后为
    
    
    复制
      
        1. eyJraWQiOiIxODM2NmFmMGI0YjQ0ZGQ4YmI0YTc3MTg0ZDA0NzA0ZiIsInR5cCI6IkpXVCIsImFsZyI6IlJTMjU2In0
    
    

## 2.3生成JWT Payload数据

根据文件中的sub_account字段拼接JSON体，对JSON体进行BASE64编码。

示例：

拼接的JSON体
    
    
    复制
      
        1. {
        2.   "aud": "https://oauth-login.cloud.huawei.com/oauth2/v3/token",
        3.   "iss": "101783233",
        4.   "exp": 1581410664,
        5.   "iat": 1581407064
        6. }
    
    

字段名| 描述  
---|---  
iss| 服务帐号json文件中sub_account字段  
aud| 固定为：https:// oauth-login.cloud.huawei.com /oauth2/v3/token  
iat| JWT签发UTC时间戳，为自UTC时间1970年1月1日00:00:00的秒数。（开发者的服务器时间需要校准为标准时间）  
exp| JWT到期UTC时间戳，比iat晚3600秒  
  
BASE64编码后为
    
    
    复制
      
        1. eyJhdWQiOiJodHRwczovL29hdXRoLWxvZ2luLmNsb3VkLmh1YXdlaS5jb20vb2F1dGgyL3YzL3Rva2VuIiwiaXNzIjoiMTAxNzgzMjMzIiwiZXhwIjoxNTgyODg1Mjk1LCJpYXQiOjE1ODI4ODE2OTV9

# 3\. 调用华为公开API

应用调用华为公开API时，把已获得服务帐号鉴权凭证，放在Authorization头部来进行鉴权。

示例：
    
    
    复制
      
        1. GET /v1/demo/indexes HTTP/1.1
        2. Authorization: Bearer eyJraWQiOiIx---xxx.eyJhdWQiOiJodHR---xxx.QRodgXa2xeXSt4Gp---xxx
        3. Host: oauth-api.cloud.huawei.com
