# 1\. SDK工作方式

HUAWEI Ads SDK 在应用打包时会被加载在您的应用当中，SDK会随着应用的启动而自动开始进行用户行为数据收集。当用户关闭应用时，SDK会随着应用的关闭而关闭，不会在后台做任何额外动作。

# 2\. SDK权限说明

HUAWEI Ads SDK需要使用的权限：

  * 获取网络状态权限：android.permission.**ACCESS_NETWORK_STATE** ，用于检测当前的网络连接是否有效。

  * 获取WiFi状态权限：android.permission.**ACCESS_WIFI_STATE** ，用于获取当前WiFi接入的状态以及WLAN热点的信息。




# 3\. SDK数据收集

HUAWEI Ads SDK 需要连接网络并收集和处理以下的信息用来标识设备，以便提供定制化的服务或广告：

  * 设备及使用信息：设备标识符、操作系统的设置信息、设备的硬件信息、应用的基本信息及使用信息、网络信息、运营商信息。

  * 广告：用户与本服务投放的广告之间的互动信息。

  * 设备位置信息：如果用户已启用基于位置的广告开关，用户的位置信息可能会用于向用户提供基于地理位置相关的广告，广告平台不会存储设备的精确位置信息。




# 4\. SDK数据安全保护

HUAWEI Ads SDK与服务端采用HTTPS通信，会对服务器的证书进行合法性校验，并对用户信息或敏感信息进行匿名化处理。详细保护措施参见[隐私声明](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ads-sdk-restrictions)。
