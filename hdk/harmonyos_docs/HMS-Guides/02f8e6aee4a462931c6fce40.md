# 1\. 登录注册  


在开发Game Kit前需要保证在AGC中已经注册成为开发者，具体操作请参考[登录注册](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/game-preparation-v4#h2-1577969046442-0)。

# 2\. 创建应用

## 2.1. 创建APP应用

在开发Game Kit前需要保证在AGC中已经创建应用，具体操作请参考[创建应用](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/game-preparation-v4#h2-1577969046442-1)。

## 2.2. 生成并配置签名证书指纹

开发前请确保应用的签名证书指纹已经在AGC中配置，具体操作请参考[生成签名证书指纹](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/game-preparation-v4#h2-1577969046442-2)和[配置签名证书指纹](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/game-preparation-v4#h2-1577969046442-3)。

# 3\. 权限申请

基于安全考虑，服务侧对Game Kit开放的接口做了权限保护处理，使用相关接口需要向华为方申请对应权限。权限申请需提供开发者联盟网站创建应用时生成的appid，且指纹信息已配置。权限申请请联系devConnect@huawei.com，主题标明Game Kit权限申请。

# 4\. 环境准备

(１) DevEco Studio(华为IDE)开发环境：建议用最新的版本。

(２) Android Studio开发环境：建议版本v3.0.1及以上。

(３) 手机开发环境：系统软件版本不低于EMUI10.1。

# 5\. 环境搭建

## 5.1. DevEco Studio接入流程

HUAWEI DevEco Studio目前处于Beta阶段，需要向华为申请试用权限。同时也期待您在使用过程中给我们反馈您宝贵的意见，我们将持续进行优化，提升您的使用体验。在使用HUAWEI DevEco Studio进行应用开发前，您应该提前知道如何“获取Beta权限”和“获取技术支持”通道。

### 5.1.1.获取Beta权限

您可以通过如下方式获取HUAWEI DevEco Studio的Beta权限。

（1）访问[华为开发者联盟官网页面](http://developer.huawei.com/consumer/cn)。

（2）注册华为开发者联盟账号，并点击右上角头像旁边的下拉图标，点击“立即前往实名认证”上传信息进行实名认证。

（3）实名认证后，在开发者联盟网站中选择“开发 > 开发工具 > HUAWEI DevEco Studio”。

### 5.1.3.技术支持

您在使用Huawei DevEco Studio时，如果您有任何的问题或建议，都可以通过如下两种方式与我们取得联系。

在线工单：登录华为开发者联盟，在菜单栏选择“支持 > 技术支持 > 在线提单”，进入在线提单页面提交工单。

邮件反馈：发送邮件至：open@huawei.com，反馈问题。

             }

        }
