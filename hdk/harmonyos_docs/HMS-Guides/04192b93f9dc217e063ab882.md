针对AndroidStudio开发环境，华为提供了maven仓集成方式的HMS SDK包。在开始开发前，您需要将HMS SDK集成到您的AndroidStudio开发环境中。

# 1 添加应用的AppGallery Connect配置文件  


1\. 登录 [AppGallery Connect 网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择“我的应用”。

2\. 在名称列表中找到应用，点击对应的名称。

    ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191230152816.39639340461928399431775421112305:50510613022440:2800:FEC9DF68D0977AAE628ED8053B55ADF86A541698215E09E5140937FA68D5329C.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

3\. 选择“开发 > 概览”。

4\. 单击“应用”栏下的“agconnect-services.json”下载配置文件。

5\. 将agconnect-services.json文件拷贝到模块目录下，如下图的demo模块所示。

    ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191230152817.81976200622423545198480379044979:50510613022440:2800:6A7F6C1C82316EE26852E116091ADEBEBFEF7ED3BBC9A7D8456C739E823BD11D.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

# 2 配置HMS Core SDK的maven仓地址

1\. 打开AndroidStudio项目级build.gradle文件，如下图所示。

    ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191230152817.18461243723664498349394377049503:50510613022440:2800:C621F248619C612FA7B9A6BCEFB89915BBD5758140B6BE1B63DC526B29DCDEA6.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

2\. 添加HUAWEI agcp插件以及Maven代码库。

    在allprojects ->repositories中配置HMS SDK的maven仓地址。

    在buildscript->repositories中配置HMS SDK的maven仓地址。

    在buildscript->dependencies里面增加agcp配置。
      
      1. buildscript {
        2.      repositories {
        3.          google()
        4.          jcenter()
        5.          maven {url 'https://developer.huawei.com/repo/'}
        6.      }
        7.      dependencies {
        8.         classpath 'com.huawei.agconnect:agcp:1.2.1.301'
        9.      }
        10. }
        11. allprojects {
        12.          repositories {
        13.              google()
        14.              jcenter()
        15.              maven {url 'https://developer.huawei.com/repo/'}
        16.          }
        17.      }
    
    

**注意：**

maven仓地址直接在浏览器中打开无法访问，只能在IDE中配置。

# 3 添加编译依赖

1\. 打开模块级的build.gradle文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191230152817.38494223902647643032406948447406:50510613022440:2800:A1CACEA14893EE1C208C7F3C4275E0043C40178B84DEC57D235B9943656CFC09.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

2\. 在“dependencies ”中添加如下编译依赖。
      
      1. dependencies {    
        2.     implementation 'com.huawei.hms:site:{version}'
        3. }
    
    

**注意：**

{version} 替换为实际的SDK版本号，如当前最新版本：implementation 'com.huawei.hms:site:4.0.3.300'

3\. 在文件头添加配置。
      
      1. apply plugin: 'com.huawei.agconnect'
    
    

**注意：**  


apply plugin: 'com.huawei.agconnect' 配置 要在apply plugin: 'com.android.application'之后；

华为位置服务SDK支持的最低 android 版本(minSdkVersion )为19。

4. 在 "android" 中配置签名。将生成证书指纹步骤中生成的签名证书拷贝到app目录下，在build.gradle文件中配置签名。
      
      1. android {
        2.     signingConfigs {
        3.         release {
        4.             //签名证书
        5.             storeFile file("**.**")
        6.             //密钥库口令
        7.             storePassword "******"
        8.             //别名
        9.             keyAlias "******"
        10.             //密钥口令
        11.             keyPassword "******"
        12.             v2SigningEnabled true
        13.         }
        14.     }
        15.     buildTypes {
        16.         release {
        17.             minifyEnabled false
        18.             proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'), 'proguard-rules.pro'
        19.             signingConfig signingConfigs.release
        20.         }
        21.         debug {
        22.             signingConfig signingConfigs.release
        23.         }
        24.     }
        25. }

# 5 配置混淆脚本  


开发者编译APK前需要配置不要混淆HMS SDK，避免功能异常。

1\. 打开应用级的混淆配置文件，Android Studio开发环境里的配置文件是“proguard-rules.pro”。

2\. 加入排除HMS SDK的混淆配置。
      
      1. -ignorewarnings
        2. -keepattributes *Annotation*
        3. -keepattributes Exceptions
        4. -keepattributes InnerClasses 
        5. -keepattributes Signature 
        6. -keepattributes SourceFile,LineNumberTable 
        7. -keep class com.hianalytics.android.**{*;} 
        8. -keep class com.huawei.updatesdk.**{*;} 
        9. -keep class com.huawei.hms.**{*;}
    
    

3.如果开发者使用了AndResGuard，需要在混淆配置文件中加入AndResGuard允许清单。
      
      1. "R.string.agc*",
        2. "R.string.hms*", 
        3. "R.string.connect_server_fail_prompt_toast", 
        4. "R.string.getting_message_fail_prompt_toast",
        5. "R.string.no_available_network_prompt_toast", 
        6. "R.string.third_app_*",
        7. "R.string.upsdk_*", 
        8. "R.layout.hms*", 
        9. "R.layout.upsdk_*", 
        10. "R.drawable.upsdk*",
        11. "R.color.upsdk*",
        12. "R.dimen.upsdk*", 
        13. "R.style.upsdk*"
