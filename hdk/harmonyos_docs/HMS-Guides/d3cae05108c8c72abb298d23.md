# SG BusLeh 简介

SG BusLeh是新加坡一款查询公共汽车到达时间的App，可以查询SBS和SMRT等公交的达到时间。SGBusLeh引入了显示公交车位置、统一搜索和显示公交到达时刻等创新功能，使它成为新加坡最流行、最受推崇的公交应用之一。

业务挑战

  * 缺少通过扫描公交编号获取公交到站时间、公交间隔时间、空座、路线等信息的功能。

  * 使用的其他第三方文本识别服务识别率不高。



# 解决方案

通过集成HMS ML Kit高性能的文本识别服务，SG BusLeh打造出全新便捷服务，只要扫一扫公交路线编号，即可获取公交到站时间、空座、路线等信息。

  * 新增文本识别功能，支持业务场景扩展：扫描公交编号，公交到站时间、公交间隔时间、空座、路线等信息，用户使用更便捷。
  * 支持倾斜、弯曲文本识别：HMS ML Kit支持文本倾斜至30度或弯曲至45度，仍能保证准确识别。
  * 覆盖机型广：HMS ML Kit支持华为及非华为手机，SG BusLeh一次集成，即可覆盖市面上所有安卓系统机型。




# 合作收益

  * SG BusLeh

新增文本识别功能，用户在公交站台扫描公交编号即可获得公交到达时间、间隔时间，是否有空座，公交运行线路等信息，并且支持倾斜以及弯曲文本的识别。

  * SG BusLeh用户

无需输入公交编码，只要拿出手机扫一扫即可获得公交信息，方便快捷。
