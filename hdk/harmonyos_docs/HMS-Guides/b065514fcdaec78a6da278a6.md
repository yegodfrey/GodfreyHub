在开始API开发工作之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-process-4)，同时请确保您的工程中已经[配置HMS Core SDK的maven仓地址](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-maven-4)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-doc-sdk-4)。

1\. 创建文档分析器。推荐使用文档识别自定义参数[MLDocumentSetting](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLDocumentSetting-4)设置需要识别的语种列表，创建分析器，以获取更加精确的文本识别结果。
      
      1. // 方式一：使用自定义参数配置。
        2. // 创建语言集合。
        3. List<String> languageList = new ArrayList();
        4. languageList.add("zh");
        5. languageList.add("en");
        6. // 设置参数。
        7. MLDocumentSetting setting = new MLDocumentSetting.Factory()
        8.     // 设置识别语言列表，使用ISO 639-1标准。
        9.     .setLanguageList(languageList)
        10.     // 设置文本边界框返回格式，
        11.     // MLRemoteTextSetting.NGON：返回四边形的四个顶点坐标。
        12.     // MLRemoteTextSetting.ARC：返回文本排列为弧形的多边形边界的顶点，最多可返回多达72个顶点的坐标。
        13.     .setBorderType(MLRemoteTextSetting.ARC)
        14.     .create();
        15. MLDocumentAnalyzer analyzer = 
        16.          MLAnalyzerFactory.getInstance().getRemoteDocumentAnalyzer(setting);
        17. // 方式二：使用默认参数配置，自动检测语种进行识别，文本框返回格式为：MLRemoteTextSetting.NGON。
        18. MLDocumentAnalyzer analyzer = 
        19.          MLAnalyzerFactory.getInstance().getRemoteDocumentAnalyzer();
    
    

2. 通过android.graphics.Bitmap创建[MLFrame](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLFrame-4)，支持的图片格式包括：jpg/jpeg/png/bmp。
      
      1. // 通过bitmap创建MLFrame，bitmap为输入的Bitmap格式图片数据。 
        2. MLFrame frame = MLFrame.fromBitmap(bitmap);
    
    

3. 将创建的[MLFrame](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLFrame-4)对象传递给“asyncAnalyseFrame”方法进行文档识别。
      
      1. Task<MLDocument> task = analyzer.asyncAnalyseFrame(frame);
        2. task.addOnSuccessListener(new OnSuccessListener<MLDocument>() {
        3.     @Override
        4.     public void onSuccess(MLDocument document) {
        5.         // 识别成功。
        6.     }
        7. }).addOnFailureListener(new OnFailureListener() {
        8.     @Override
        9.     public void onFailure(Exception e) {
        10.         // 识别失败。
        11.         // Recognition failure.
        12.         try {
        13.             MLException mlException = (MLException)e;
        14.             // 获取错误码，开发者可以对错误码进行处理，根据错误码进行差异化的页面提示。错误码信息可参见：[机器学习服务错误码](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLException-4)。
        15.             int errorCode = mlException.getErrCode();
        16.            // 获取报错信息，开发者可以结合错误码，快速定位问题。
        17.            String errorMessage = mlException.getMessage();
        18.        } catch (Exception error) {
        19.            // 转换错误处理。
        20.        }
        21.     }
        22. });
    
    

4. 识别完成，停止分析器，释放识别资源。
      
      1. if (analyzer != null) {
        2.     try {
        3.         analyzer.stop();
        4.     } catch (IOException e) {
        5.          // 异常处理。
        6.     }
        7. }
