# **Analytics Kit 5.0.0版本 （2020-05-25）**  


**Android 最新子版本号：5.0.0.301**

**新增特性：**

Android Studio开发环境中自动添加HUAWEI Analytics SDK必要的混淆配置允许清单。

**变更特性：**

  1. 支持自动绑定/解绑HMS的服务，同时修改regHmsSvcEvent()和unRegHmsSvcEvent()接口状态为“Deprecated”。

  2. 解决使用预置事件参数ORDERID上报失败问题。




**iOS 最新子版本号：5.0.0.300**

**新增特性：**

提供iOS平台采集能力，支持开发者的应用快速集成Huawei Analytics Kit，实现多端统一分析。

# **Analytics Kit 4.0.3版本 （2020-04-10）**

最新子版本号：4.0.3.300

#### 新增特性：

  1. 修改setCurrentActivity ()接口的状态为“Deprecated”，新增pageStart()和pageEnd()接口，支持非Activity页面完整的进入和退出事件采集。详细请参考相关接口描述。

  2. 新增电商领域预置事件。




#### 变更特性：

优化上报机制，如果AGC token为空则不上报事件。

# **Analytics Kit 4.0.2版本 （2020-03-16）**

最新子版本号：4.0.2.300

#### 新增特性：

  1. 支持使用React Native框架开发的移动应用能够集成HA React Native SDK，并使用华为分析服务。

  2. 支持广告和动态链接自动采集事件。

  3. 新增异常场景错误码。




#### 变更特性：

修改setAutoCollectionEnabled()接口的状态为“Deprecated”，初始化时自动开启采集系统事件的开关。

# **Analytics Kit 4.0.1版本 （2020-02-18）**

最新子版本号：4.0.1.300

#### 新增特性：

支持应用内购买自动采集事件。

#### **修改特性：**

优化onEvent()和setUserProfile()接口入参校验规则。

# **Analytics Kit 4.0.0版本 （2020-01-21）**

最新子版本号：4.0.0.303

#### 新增特性：

  1. HUAWEI Analytics SDK支持 Eclipse集成。

  2. 支持华为帐号登录与登出事件自动上报。

新增regHmsSvcEvent()和unRegHmsSvcEvent()接口，用于HiAnalyticsSDK注册和解绑HMS服务。

  3. 支持DTM数据过滤。

  4. 支持AGC A/B Test与HiAnalyticsSDK对接。  
新增getUserProfiles()接口，获取自定义用户属性。

  5. 支持应用每次打开时自动采集LAUNCHAPP事件。




#### 删除特性：

删除HiAnalyticsInstallReceiver和HiAnalyticsReceiver类。

#### **修改特性：**

  1. 修改API接口、预定义事件及常量名称。

  2. 调用setUserId()接口时，如果旧userId不为空字符串且和新userId不同，会重新生成新的session会话。

  3. 安装归因信息通过自动化事件APPFIRSTOPEN上报。

  4. onEvent()的入参eventId进行过滤，如果是SDK预留的事件ID，则不记录此事件。

  5. 当SDK不能获取到AAID和androidId时，将不上报打点数据，而打点到本地。

# **SDK依赖说明**  


1.最新版本SDK需要用户手机上安装HMS Core（APK）4.0.0.300及以上版本； 如果用户手机没有安装，您的应用调用HMS Core（APK）时，会自动引导用户提示安装。

2.本服务的主要特性都可以在大多数华为终端上支持，部分高级特性依赖于EMUI版本。请参考[部分特性对于EMUI的依赖说明](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/emui_version_dependent_features)。

提示：您的应用在华为应用市场上架过程中，如有问题可发送邮件至HMSCore@huawei.com咨询。
