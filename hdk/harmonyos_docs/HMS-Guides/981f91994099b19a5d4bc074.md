# 1 概述

商户注册开发者联盟应用后需要在相应位置配置推广服务，开发者联盟会将产品内容上架至华为钱包App内的内容展示位，用户点击内容展示内可加载出商户添加卡劵入口(商户H5添卡界面)，用户根据引导可以将卡劵添加至华为钱包中。

注：目前这种方式暂时只支持中国大陆区域开放。

![](http://10.116.132.176:8080/idp-edit-service/editor/image/1032914/1_zh-cn_image_0000001050425619.png)

# 2 商户配置推广服务

商户通过申请开发者联盟应用后可配置相应的推广服务 ，可将产品内容上架至华为钱包App内的内容展示位，合作伙伴可触达华为钱包里的优质流量，以提高商品或品牌的曝光度和知名度。

例：通过申请推广服务，合作伙伴可将内容配置到开发者联盟中，图片素材及目的访问URL地址需由合作伙伴提供，华为运营人员审核后发布。

  1. 创建Wallet Kit推广服务。

![](http://10.116.132.176:8080/idp-edit-service/editor/image/1032914/1_zh-cn_image_0000001050202052.png)

  2. 选择推广样式。

![](http://10.116.132.132:8080/idp-edit-service/editor/image/1032914/1_zh-cn_image_0000001050444451.png)

  3. 上传资料。

![](http://10.116.132.132:8080/idp-edit-service/editor/image/1032914/1_zh-cn_image_0000001050329280.png)

  4. 创建推广服务成功。

![](http://10.116.132.176:8080/idp-edit-service/editor/image/1032914/1_zh-cn_image_0000001050204369.png)

推广服务可以让华为钱包用户在访问华为钱包会员卡等栏目时浏览到商户配置的推广服务展示位，用户可以点击配置的展示位跳转到商户相对应的推广H5，此H5推广界面可以是比如用户申领会员卡界面或其他推广内容。

# 4 商户H5集成添卡JS接口

在商户H5界面加入H5添卡接口。

钱包定义接口：window.fp.addPass(String appId, String hwpassData)，返回字符串。

appId为开发者联盟应用ID，hwpassData为签名卡劵包做Base64加密结果值。
      
      1. //调用js
        2. if(window.fp){
        3.     //通过checkPassExist判断当前手机是否已存在卡劵
        4.     if(!window.fp.checkPassExist("服务号")){
        5.         //添加卡劵
        6.         var loginCredential= window.fp.addPass(String appId, String hwpassData)
        7.     }
        8. }
