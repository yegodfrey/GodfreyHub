# 通过 HTTP Restful 接口访问运动健康服务

HTTP Restful 接口 定义如下：

**协议** ：HTTPS

**HTTPS 请求头** ：

Content-type：application/json

Authorization：Bearer ${access_token}，access_token获取请参考[开放平台鉴权](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/30101)-**授权码模式**

**URL 格式** ：

https://health-api.cloud.huawei.com/hihealth/v1/{resourcesSet}/{resourceId}?{param=xxx}

URL 中各部分的说明如下：

字段 | 描述 | 格式  
---|---|---  
Method | HTTP 方法 | POST、PUT、PATCH、GET、DELETE  
resourcesSet | 资源集合 | 例如：dataCollectors（数据采集器集合）  
resourceId | 资源 id | 例如：dataCollectorId（指定的数据采集器标识）  
param | 查询参数 | 例如：limit（单次分页查询长度）  
  
详细的 HTTP Restful接口 请参考 [Health Kit 服务端 API 参考](https://developer.huawei.com/consumer/cn/doc/HMS-References/datacollectors_create-0000001050114852)。
