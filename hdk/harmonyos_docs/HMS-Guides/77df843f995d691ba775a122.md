您可以通过两种方式，集成实时语音识别服务：1、集成实时语音识别服务插件，2、集成实时语音识别服务SDK。推荐集成实时语音识别服务插件，插件提供拾音界面，SDK只提供实时语音识别的基础服务，拾音界面需要自行开发。

集成插件示例代码如下：
      
      1. dependencies{
        2.   // 引入实时语音识别服务插件
        3.   implementation 'com.huawei.hms:ml-computer-voice-asr-plugin:2.0.0.300'
        4. }
    
    

集成SDK示例代码如下：
      
      1. dependencies{
        2.   // 引入实时语音识别服务SDK
        3.   implementation 'com.huawei.hms:ml-computer-voice-asr:2.0.0.300'
        4. }
    
    

# 文件头增加配置

用上述方式集成插件后，在文件头添加配置。
      
      1. apply plugin: 'com.huawei.agconnect'
    
    

注意：

此项配置需要在如下配置项后添加。
      
      1. apply plugin: 'com.android.application'
