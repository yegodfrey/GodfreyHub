本章节将向您介绍通过华为地图API for JavaScript提供的正地理编码和逆地理编码接口。

# 1 正地理编码

获取地址对应的经纬度，最多返回10条记录。

## 1.1 实现步骤

1\. 通过HWMapJsSDK初始化[HWSiteService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-site-service)对象。

2\. 构建请求体request对象，其中address是必选参数，其余可选：

  * address：地点信息。

  * bounds：查询结果偏向的搜索范围。

  * language：搜索结果的语种。如果不传，使用地点的当地语言。语种取值请参考语种映射列表。

  * politicalView：政治观点参数，采用ISO 3166-1-alpha-2规范的2位国家码。




3\. 通过第1步创建的[HWSiteService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-site-service)对象调用geocode接口，传入第2步创建的request对象。

4\. 获取搜索结果。通过第3步geocode接口的回调函数返回搜索结果result和搜索状态status。status参考错误码说明小节，result包含以下对象：

  * sites：返回10条搜索结果[Site](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description#site)[]，[Site](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description#site)描述参考[参数说明](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description)小节。




## 1.2 示例代码
      
      1. var markers = [];
        2. var map;
        3. var mapOptions = {}; 
        4. mapOptions.center = {lat: 48.856613, lng: 2.352222}; 
        5. mapOptions.zoom = 8; 
        6. map = new HWMapJsSDK.HWMap(document.getElementById('map'), mapOptions); 
        7. var siteService 
        8. //初始化HWSiteService对象 
        9. siteService = new HWMapJsSDK.HWSiteService(); 
        10. //初始化请求参数对象 
        11. var request = { 
        12.     address: '57,RUE DU CAPITAINE PICAVET,LEERS,LEERS,NORD,HAUTS-DE-FRANCE,France' 
        13. }; 
        14. //调用正地理编码接口，result为返回结果，status为返回状态 
        15. siteService.geocode(request, function (result, status) { 
        16.     if (status == '0') { 
        17.         var results = "Geocode Results:\n"; 
        18.         //处理搜索结果
        19.         for (var i = 0; i < result.sites.length; i++) { 
        20.             var str = '[' + i + ']\n' 
        21.                 + "Name=" + result.sites[i].name + "\n" 
        22.                 + "SiteID=" + result.sites[i].siteId + "\n"; 
        23.             results = results + str; 
        24.         } 
        25.         //添加标记
        26.         var marker = new HWMapJsSDK.HWMarker({ 
        27.             map: map, 
        28.             position: {lat: result.sites[0].location.lat, lng: result.sites[0].location.lng}, 
        29.             label: result.sites[0].name 
        30.         }); 
        31.         markers.push(marker); 
        32.         //设置地图中心位置 
        33.         map.setCenter({lat: result.sites[0].location.lat, lng: result.sites[0].location.lng}) 
        34.     } 
        35. });
    
    

# 2 逆地理编码

获取经纬度对应的地点，最多返回5条记录。

## 2.1 实现步骤

1\. 通过HWMapJsSDK初始化[HWSiteService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-site-service)对象。

2\. 构建请求体request对象，其中location是必选参数，其余可选：

  * location：经纬度。

  * language：搜索结果的语种。如果不传，使用地点的当地语言。语种取值请参考语种映射列表。

  * politicalView：政治观点参数，采用ISO 3166-1-alpha-2规范的2位国家码。




3\. 通过第1步创建的[HWSiteService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-site-service)对象调用reverseGeocode接口，传入第2步创建的request对象。

4\. 获取搜索结果。通过第3步reverseGeocode接口的回调函数返回搜索结果result和搜索状态status。status参考返回码小节，result包含以下对象：

  * sites：返回5条搜索结果[Site](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description#site)[]，[Site](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description#site)描述参考[参数说明](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description)小节。注意[Site](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description#site)对象不返回POI信息。




## 2.2 示例代码
      
      1. var siteService 
        2. //初始化HWSiteService对象 
        3. siteService = new HWMapJsSDK.HWSiteService(); 
        4. //初始化请求参数对象 
        5. var request = { 
        6.     location: { 
        7.         lat: 18.0527, 
        8.         lng: 77.2155 
        9.     } 
        10. }; 
        11. //调用逆地理编码接口，result为返回结果，status为返回状态 
        12. siteService.reverseGeocode(request, function (result, status) { 
        13.     if (status == '0') { 
        14.         var results = "ReverseGeocode Results:\n"; 
        15.         for (var i = 0; i < result.sites.length; i++) { 
        16.             var str = '[' + i + ']\n' 
        17.                 + "Name=" + result.sites[i].name + "\n" 
        18.                 + "SiteID=" + result.sites[i].siteId + "\n"; 
        19.             results = results + str; 
        20.         } 
        21.     } 
        22. });
