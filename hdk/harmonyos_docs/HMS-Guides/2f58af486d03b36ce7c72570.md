# 1\. 概述

本文适用于希望接入华为帐号的Android应用。华为帐号提供了HMS SDK来快速接入，但是对于某些无法使用HMS（华为移动服务）的场景，还可以通过OAuth 2.0协议的方式在浏览器中进行华为帐号登录。为了方便快速接入OAuth 2.0授权，开发者可以使用AppAuth SDK。  
AppAuth是一个客户端SDK，用于进行OAuth 2.0通信，它按照协议的规范进行请求和响应，同时遵循实现语言的惯用风格。该库还支持对OAuth的PKCE扩展，用于保护客户端中的授权码。

# 2\. 配置要求

  * 接入AppAuth SDK要求应用使用的Android SDK版本在API 16及以上。
  * Android客户端上已经安装浏览器。



# 3\. 开发准备

## 3.1 获取APP ID

在开始开发应用前，需要[创建并管理应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-create_app)，获取产品的APP ID（下文中提及的**client_id** 值传此处APP ID值）。

# 4\. 开发流程

## 4.1 获取示例代码

您可以从[AppAuth-For-Android的官方网站](https://openid.github.io/AppAuth-Android/)中下载示例代码，或通过以下命令克隆代码：  

      
      1. git clone https://github.com/openid/AppAuth-Android.git
    
    

在AndroidStudio中打开该工程。  


## 4.2 配置请求参数

授权过程需要用到**client_id** 、授权地址等参数信息，您可以将这些信息写到配置文件**/res/raw/auth_config.json** 中。使用到的相关配置参数如下：

参数| 是否必需| 示例值| 说明  
---|---|---|---  
client_id| 必需| APPID| 您在华为开发者联盟申请的APP ID，参考[3.1 获取APP ID](httpapp_id)章节  
redirect_uri| 必需| com.huawei.apps.APPID:/oauth2redirect| 固定格式，其中APPID为您在华为开发者联盟申请的APP ID，参考[3.1 获取APP ID](httpapp_id)章节  
authorization_scope| 必需| openid email profile| 用户实际授予的权限列表，其中openid必填，多个Scope通过空格分隔  
discovery_uri| 可选| https://oauth-login.cloud.huawei.com/.well-known/openid-configuration| OpenID授权服务的动态发现地址，配置了该地址则可选配置authorization_endpoint_uri、token_endpoint_uri  
authorization_endpoint_uri| 可选| https://oauth-login.cloud.huawei.com/oauth2/v3/authorize| 授权接入地址，**如果未配置discovery_uri则必填**  
token_endpoint_uri| 可选| https://oauth-login.cloud.huawei.com/oauth2/v3/token| 令牌获取地址，**如果未配置discovery_uri则必填**  
https_required| 必需| true| 是否使用HTTPS请求，在华为帐号登录场景该值为true  
  
## 4.3 配置回调地址

在步骤1获取的示例代码的应用级gradle文件中，找到**appAuthRedirectScheme** 并将其对应的值修改为com.huawei.apps.**_APPID_** ，其中** _APPID_** 应替换为您在华为开发者联盟申请的[App ID](httpapp_id)。  
示例：
      
      1. manifestPlaceholders = [
        2.     'appAuthRedirectScheme': 'com.huawei.apps.{APPID}'
        3. ]
    
    

## 4.4 运行示例代码

按以上步骤配置好请求参数后，您可以运行步骤1获取的示例代码。用户可以在页面中选择要使用的浏览器，并点击“**START AUTHORIZATION** ”，此时会打开浏览器页签并加载授权登录页面。

在浏览器中登录华为帐号并授权成功后，您会拿到ID Token、Access Token等授权信息。

## 4.5 解析ID Token获取用户信息

返回的ID Token是JWT格式的字符串，可以按照JWT格式进行解析，获取用户的Union ID，Email地址，头像等信息。

校验idToken可以参考[验证ID Token有效性](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/account-guide-v4#h3-1-3-2)，idToken解析后的参数可参考[ID Token验证接口](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-verify-id-token)中返回值的参数。
