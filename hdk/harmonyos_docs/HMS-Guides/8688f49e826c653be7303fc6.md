# 1 创建地图

本章节将向您介绍通过华为地图API for JavaScript创建一个简单的网页地图。

1\. 创建一个HTML文件，并在文件头声明以下内容，以支持大多数浏览器。
    
    
    复制
      
        1. <!DOCTYPE html>
    
    

2\. 在head标签对里添加style标签对，来设置容器样式大小。
    
    
    复制
      
        1. <head> 
        2.     <meta charset="UTF-8"> 
        3.     <style> 
        4.         #map { 
        5.             height: 800px; 
        6.             width: 80%; 
        7.             margin: 0 auto; 
        8.         } 
        9.     </style> 
        10. </head>
    
    

3\. 引入华为地图API文件，其中key要经过URL转码。
    
    
    复制
      
        1. <script src="https://mapapi.cloud.huawei.com/mapjs/v1/api/js?callback=initMap&key=API KEY"></script>
    
    

4\. 在body内部创建地图容器元素。
    
    
    复制
      
        1. <body> 
        2. <div id="map"></div> 
        3. </body>
    
    

创建初始化地图的脚本，如下创建了以巴黎为中心，缩放系数为8的地图。
    
    
    复制
      
        1. <script> 
        2.     function initMap() { 
        3.         var mapOptions = {}; 
        4.         mapOptions.center = {lat: 48.856613, lng: 2.352222}; 
        5.         mapOptions.zoom = 8; 
        6.         mapOptions.language='ENG'; 
        7.         var map = new HWMapJsSDK.HWMap(document.getElementById('map'), mapOptions); 
        8.     } 
        9. </script>

# 2 地图属性

地图支持属性自定义修改，如地图的中心点、缩放系数以及地图朝向等。以下代码示例为修改地图中心点：
    
    
    复制
      
        1. <tr> 
        2.     <td>Latitude:</td> 
        3.     <td><input id="latInput" type="text" value="48.95"/></td> 
        4. </tr> 
        5. <tr> 
        6.     <td>Longitude:</td> 
        7.     <td><input id="lngInput" type="text" value="2.35"/></td> 
        8. </tr>
    
    
    
    
    复制
      
        1. var lat = Number(document.getElementById("latInput").value); 
        2. var lng = Number(document.getElementById("lngInput").value); 
        3. map.setCenter({lat: lat, lng: lng});
    
    

地图的以下属性支持自定义：

**属性**| **含义**  
---|---  
setCenter(latlng)| 设置地图中心点坐标。  
setHeading(heading)| 设置地图朝向，即地图与正北方向的夹角。  
setOpacity(opacity)| 设置地图透明度。  
setTitle(title)| 设置地图所在容器的提示信息。  
setZoom(zoom)| 设置地图缩放级别。  
zoomOut()| 地图缩小一个级别。  
zoomIn()| 地图放大一个级别。
