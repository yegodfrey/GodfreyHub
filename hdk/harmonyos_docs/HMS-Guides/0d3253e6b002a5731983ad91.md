如果您的应用不需要设置只支持某些特定语言，则请忽略本步骤。应用将默认支持所有HMS SDK支持的语言。如果您的应用需要设置只支持某些特定语言，则可通过本步骤配置。

1\. 打开项目工程下app目录的build.gradle文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200402152006.72801704072560425646087621260740:50510618111606:2800:6B9FB0A6AF20B940DFE7721D3398C201977B190C87CBB1444AF591FBCE5EB6A4.jpg?needInitFileName=true)

2\. ii. 在“android”->“defaultConfig”中新增resConfigs配置，“en”（英语） 和 “zh-rCN”（简体中文） 为必须配置的语种，配置格式如下：
      
      1. android { 
        2.     defaultConfig{         
        3.         resConfigs "en", "zh-rCN", "需要支持的其他语言" 
        4.     } 
        5.  }
    
    

HMS Core SDK支持的语言列表请参考[HMS SDK支持的语言](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/hmssdk_supported_language)。
