在使用信标相关能力之前，您需要将Beacon设备注册到您的工程下，具体可参见[Beacon管理](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/Nearby-Service-Beacon-Management)。

# 在Manifest指定权限

在调用信标感知能力时，开发者需要先在Manifest中指定相应的权限。
      
      1. <!-- 位置权限，此权限为敏感权限，声明后还需在代码中动态申请 -->
        2. <uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
        3. <!-- 蓝牙权限 -->
        4. <uses-permission android:name="android.permission.BLUETOOTH" />
    
    

# 导入接口类

使用信标状态感知能力，除需要导入情景感知服务的公共能力类外，还需要导入信标状态相关的类。
      
      1. import com.huawei.hmf.tasks.OnFailureListener;
        2. import com.huawei.hmf.tasks.OnSuccessListener;
        3. import com.huawei.hms.kit.awareness.Awareness;
        4. //导入信标快照相关类
        5. import com.huawei.hms.kit.awareness.capture.BeaconStatusResponse;
        6. import com.huawei.hms.kit.awareness.status.BeaconStatus;
        7. //导入信标围栏相关类
        8. import com.huawei.hms.kit.awareness.barrier.AwarenessBarrier;
        9. import com.huawei.hms.kit.awareness.barrier.BarrierStatus;
        10. import com.huawei.hms.kit.awareness.barrier.BeaconBarrier;
        11. import com.huawei.hms.kit.awareness.barrier.BarrierUpdateRequest;
    
    

# 能力开发

## Capture能力开发

1\. 获取Awareness Kit的“Capture Client”。

2\. 通过“Capture Client”调用信标状态查询能力接口查询情景状态。

3\. 监听情景感知服务结果返回，进行应用的业务处理。
      
      1. String namespace = "sample namespace";
        2. String type = "sample type";
        3. byte[] content = new byte[]{'s', 'a', 'm', 'p', 'l', 'e'};
        4. BeaconStatus.Filter filter = BeaconStatus.Filter.match(namespace, type, content);
        5. Awareness.getCaptureClient(this).getBeaconStatus(filter)
        6.         .addOnSuccessListener(new OnSuccessListener<BeaconStatusResponse>() {
        7.             @Override
        8.             public void onSuccess(BeaconStatusResponse beaconStatusResponse) {
        9.                 List<BeaconStatus.BeaconData> beaconDataList = beaconStatusResponse.
        10.                         getBeaconStatus().getBeaconData();
        11.                 if (beaconDataList != null && beaconDataList.size() != 0) {
        12.                     int i = 1;
        13.                     StringBuilder builder = new StringBuilder();
        14.                     for (BeaconStatus.BeaconData beaconData : beaconDataList) {
        15.                         builder.append("Beacon Data ").append(i);
        16.                         builder.append(" namespace:").append(beaconData.getNamespace());
        17.                         builder.append(",type:").append(beaconData.getType());
        18.                         builder.append(",content:").append(Arrays.toString(beaconData.getContent()));
        19.                         builder.append("; ");
        20.                         i++;
        21.                     }
        22.                     Log.i(TAG, builder.toString());
        23.                 } else {
        24.                     Log.i(TAG, "no beacons match filter nearby");
        25.                 }
        26.             }
        27.         })
        28.         .addOnFailureListener(new OnFailureListener() {
        29.             @Override
        30.             public void onFailure(Exception e) {
        31.                 Log.e(TAG, "get beacon status failed", e);
        32.             }
        33.         });
    
    

## Barrier能力开发

以下以开发信标“discover”的Barrier为例（当手机扫描到周围有匹配传入filter的信标设备后触发Barrier）。

1\. 定义Barrier。
      
      1. String namespace = "sample namespace";
        2. String type = "sample type";
        3. byte[] content = new byte[]{'s', 'a', 'm', 'p', 'l', 'e'};
        4. BeaconStatus.Filter filter = BeaconStatus.Filter.match(namespace, type, content);
        5. AwarenessBarrier discoverBeaconBarrier = BeaconBarrier.discover(filter);
    
    

2\. 定义Barrier状态改变时触发的“PendingIntent”，本示例中为发送一个广播，同时新建一个广播接收器用来接收这个广播。
      
      1. final String BARRIER_RECEIVER_ACTION = getApplication().getPackageName() + "BEACON_BARRIER_RECEIVER_ACTION";
        2. Intent intent = new Intent(BARRIER_RECEIVER_ACTION);
        3. PendingIntent pendingIntent = PendingIntent.getBroadcast(this, 1, intent, PendingIntent.FLAG_UPDATE_CURRENT);
        4. BeaconBarrierReceiver barrierReceiver = new BeaconBarrierReceiver();
        5. registerReceiver(barrierReceiver, new IntentFilter(BARRIER_RECEIVER_ACTION));
    
    

3\. 定义Barrier对应的标签Label，然后添加Barrier。
      
      1. String beaconBarrierLabel = "discover beacon barrier";
        2. BarrierUpdateRequest.Builder builder = new BarrierUpdateRequest.Builder();
        3. BarrierUpdateRequest request = builder.addBarrier(beaconBarrierLabel, discoverBeaconBarrier,pendingIntent).build();
        4. Awareness.getBarrierClient(context).updateBarriers(request)
        5.         .addOnSuccessListener(new OnSuccessListener<Void>() {
        6.             @Override
        7.             public void onSuccess(Void aVoid) {
        8.                 Toast.makeText(getApplicationContext(), "add barrier success", Toast.LENGTH_SHORT).show();
        9.             }
        10.         })
        11.         .addOnFailureListener(new OnFailureListener() {
        12.             @Override
        13.             public void onFailure(Exception e) {
        14.                 Toast.makeText(getApplicationContext(), "add barrier failed", Toast.LENGTH_SHORT).show();
        15.                 Log.e(TAG, "add barrier failed", e);
        16.             }
        17.         });
    
    

4\. 定义广播接收器，用于监听Barrier事件，收到事件后进行应用的业务处理。
      
      1. class BeaconBarrierReceiver extends BroadcastReceiver {
        2.     @Override
        3.     public void onReceive(Context context, Intent intent) {
        4.         BarrierStatus barrierStatus = BarrierStatus.extract(intent);
        5.         String label = barrierStatus.getBarrierLabel();
        6.         switch(barrierStatus.getPresentStatus()) {
        7.             case BarrierStatus.TRUE:
        8.                 Log.i(TAG, label + " status:true");
        9.                 break;
        10.             case BarrierStatus.FALSE:
        11.                 Log.i(TAG, label + " status:false");
        12.                 break;
        13.             case BarrierStatus.UNKNOWN:
        14.                 Log.i(TAG, label + " status:unknown");
        15.                 break;
        16.         }
        17.     }
        18. }
