# 1 概览

您可以通过控制内置UI控件的显示以及允许哪些手势来自定义用户与地图交互的方式。

# 2 MapView属性

属性| 类型| 默认值| 描述  
---|---|---|---  
region| Region| <None>| 地图上展示的区域。区域由地图中心点坐标以及坐标跨度来定义。  
initialRegion| Region| <None>| 地图上展示的初始区域。如果您不想控制地图的初始区域以外的视角，请使用该参数而非仅仅使用region参数。容器挂载后再修改该属性，地图区域将保持不变。该属性和文本输入型的initialValue属性相似。  
camera| Camera| <None>| 地图展示的相机视角。如使用该属性，请忽略region属性。  
initialCamera| Camera| <None>| An initial camera view.容器挂载后再修改该属性，地图区域将保持不变。该属性和文本输入型的initialValue属性相似。  
showsCompass| Boolean| true| 如果该属性配置为false，地图上将不展示指南针。  
zoomEnabled| Boolean| true| 如果该属性配置为false，用户将无法缩放地图。  
zoomTapEnabled| Boolean| true| 如果该属性配置为false，用户将无法通过双击来缩放地图。注意：配置为false时会极大地降低点击手势识别的时延。  
zoomControlEnabled| Boolean| true| 如果该属性配置为false，地图右下角的缩放控件将不可见。  
minZoomLevel| Number| 3| 地图的最小缩放值。取值范围是3~20。  
maxZoomLevel| Number| 20| 地图的最大缩放值。取值范围是3~20。  
rotateEnabled| Boolean| true| 如果该属性配置为false，用户将无法旋转地图。  
scrollEnabled| Boolean| true| 如果该属性配置为false，用户将无法修改地图的展示区域。  
pitchEnabled| Boolean| true| 如果该属性配置为false，用户将无法调整相机的角度。  
moveOnMarkerPress| Boolean| true| 如果该属性配置为false，当用户长按标记时，地图不移动。  
  
# 3 MapView容器事件

接入事件数据，需要使用e.nativeEvent。例如，onPress={e => console.log(e.nativeEvent)}会将整个事件对象记录到您的管理台。

事件名称| 返回值| 描述  
---|---|---  
onMapReady| <None>| 地图加在完成时调用的回调。  
onRegionChange| Region| 展示区域变化时持续调用的回调，比如当用户拖动地图时。  
onRegionChangeComplete| Region| 展示区域变化时调用的回调，比如当用户完成地图移动时。  
onPress| { coordinate: LatLng, position: Point }| 用户点击地图时调用的回调。  
onDoublePress| { coordinate: LatLng, position: Point }| 用户双击地图时调用的回调。  
onPanDrag| { coordinate: LatLng, position: Point }| 用户长按并拖动地图时调用的回调。  
onLongPress| { coordinate: LatLng, position: Point }| 用户长按地图时调用的回调。  
onMarkerPress| <None>| 用户点击地图上的标记时调用的回调。  
onCalloutPress| <None>| 用户点击信息窗时调用的回调。  
onMarkerDragStart| { coordinate: LatLng, position: Point }| 用户拖拽（可拖拽的）标记时调用的回调。  
onMarkerDrag| { coordinate: LatLng, position: Point }| 拖动标记时持续调用的回调。  
onMarkerDragEnd| { coordinate: LatLng, position: Point }| 完成标记拖拽时调用的回调。该事件通常是您想重新设置标记在地图上的坐标时调用。  
  
# 4 MapView方法

方法名| 参数| 描述  
---|---|---  
getCamera| <None>| 获取当前相机的配置。  
animateCamera| camera: Camera, { duration: Number }| 将相机移动到新视图。此处可以传入相机对象中的部分属性。为传入的属性将保持不变。  
setCamera| camera: Camera, { duration: Number }| 与animateCamera属性类似。不同的是此处即时设置一个新的视图，不带动画效果。  
getMapBoundaries| Promise<{northEast: LatLng, southWest: LatLng}>| 返回地图边界。  
setMapBoundaries| northEast: LatLng, southWest: LatLng| 边界由地图的中心点坐标来定义，而不是由设备的视角来定义。  
fitToElements| animated: Boolean| 将元素与地图适配。  
fitToSuppliedMarkers| markerIDs: String[], options: { edgePadding: EdgePadding, animated: Boolean }| 如需在ComponentDidMount中使用该方法，确保设置超时间隔，否则可能或导致性能问题。  
fitToCoordinates| coordinates: Array<LatLng>, options: { edgePadding: EdgePadding, animated: Boolean }| 当在android中的ComponentDidMount中调用时会抛出异常。建议在MapView的onLayout事件中调用该方法。  
pointForCoordinate| coordinate: LatLng| 将地图坐标转换为视图坐标（点）。返回Promise<Point>.  
coordinateForPoint| point: Point| 将视图坐标（点）转换为地图坐标。返回Promise<Coordinate>.
