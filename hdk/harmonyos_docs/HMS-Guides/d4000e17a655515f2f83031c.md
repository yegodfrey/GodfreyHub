# 1\. 注册认证开发者联盟

进入http://developer.huawei.com/consumer/cn页面，登录华为开发者联盟，帐号必须实名认证，详见[帐号注册认证](https://developer.huawei.com/consumer/cn/devservice/doc/20300)。

# 2\. 申请银联商户号

Huawei Pay支付是允许用户通过在华为钱包绑定的Huawei Pay银行卡直接在线上或者线下完成支付，本质上还是银行卡的支付，走的支付通道是中国银联支付平台，收单方是银联商务，所以集成Huawei Pay支付方式的商户必须先申请银联的商户号。

银联商户号申请接口人及其联系方式如下：

门户网站：[www.chinapay.com](http://www.chinapay.com/)

# 3\. 接入银联手机支付控件

银联手机支付控件是中国银联推出的手机支付产品，可以通过银行卡进行安全的、便捷的即时支付。用户在银联签约商户的手机客户端、手机网站进行付款时，安全支付控件可以保障用户银行卡信息的安全。具体对接流程以及指导参见：[接入银联手机支付控件指导](https://open.unionpay.com/tjweb/acproduct/list?apiSvcId=450&index=2#2nav5)。

对接商户只需走到如下流程中的1.4，获取订单TN后，后续直接接入Huawei Pay线上支付。

# 4\. WalletPaySDK下载

进入“SDK下载”页面，点击“下载”按钮下载SDK压缩包。

通过SDK接口接入的需要下载此SDK，如果通过JS或者WAP方式接入的可以跳过本章节，直接参考对应接入方式的开发指南。

# 5\. 环境准备

Android Studio开发环境，建议版本v3.0.1及以上。

手机开发环境：EMUI5.0及以上版本。

# 6\. 环境搭建

#### 6.1 创建工程

1\. 新建或者打开已有的Android Studio项目；

2\. 填写应用名称，包名等；

5. 填写文件名称，并点击Finish。

#### 6.2 添加依赖库

1\. 将下载好的WalletPaySDK .jar放在工程中的app/libs下 (version指实际版本号)；

2\. 在工程APP目录中的build.gradle中添加如下代码，将jar包添加至工程中。

 
    
    
    dependencies {  
     ….  
         compile fileTree(include: ['*.jar'], dir: 'libs')  
         compile files('libs/WalletPaySDK1.0.0.301.jar')  
     }
