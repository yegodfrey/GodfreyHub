# 1 概览

本章节将向您介绍如何使用地图容器快速地获得地图对象、改变地图样式以及在地图上绘制形状和标记。详情请参见示例代码工程中的App.js等文件。点击[这里](https://git.huawei.com/hms-core/react-native/react-native-hms-map-demo/)下载示例代码。

# 2 一般用法

创建MapView容器以容纳地图上的各种元素（例如标记、多边形等）。提供一种直观和交互式API来控制地图上的元素。
    
    
    复制
      
        1. import MapView from'react-native-hms-map';
    
    

或者
    
    
    复制
      
        1. var MapView = require('react-native-hms-map');
    
    

# 3 渲染具有初始区域的地图

地图显示的初始区域。如果您不想控制地图的初始区域以外的视角，请使用该参数而非仅仅使用region参数。

容器挂载后再修改该属性，区域将保持不变。
    
    
    复制
      
        1. <MapView
        2.     initialRegion={{
        3.         latitude: 37.78825,
        4.         longitude: -122.4324,
        5.         latitudeDelta: 0.0922,
        6.         longitudeDelta: 0.0421,
        7.     }}
        8. />
    
    

# 4 将区域作为State来控制

如需跟踪地图中心点坐标以及坐标跨度，可以使用state和onRegionChange事件。
    
    
    复制
      
        1. getInitialState() {
        2.     return {
        3.         region: {
        4.             latitude: 37.78825,
        5.             longitude: -122.4324,
        6.             latitudeDelta: 0.0922,
        7.             longitudeDelta: 0.0421,
        8.         },
        9.     };
        10. }
        11. onRegionChange(region)  {
        12.     this.setState({ region });
        13. }
        14. render() {
        15.     return (
        16.     <MapView
        17.         region={this.state.region}
        18.         onRegionChange={this.onRegionChange}
        19.     />
        20.     );
        21. }
