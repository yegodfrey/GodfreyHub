# 1\. 业务介绍

应用升级是指用户启动应用后应用后台主动检查新版本，或用户在应用的检查升级入口主动触发升级检查操作，HMS SDK从华为应用市场请求下载新版本应用并进行升级安装的过程。

具体交互细节如下：

  1. 用户启动应用或在应用内主动触发检查升级操作。

  2. 应用检查到更新后拉起升级确认页面。

  3. 用户确认升级后进入华为应用市场的应用升级页面，执行升级操作。

由于HMS SDK的升级能力集成在游戏服务中，在使用HMS SDK提供的应用升级能力前，需要先集成游戏服务SDK。如果应用已经集成游戏服务SDK，可跳过本章节。

# 3\. 应用升级  


## 3.1 场景介绍  


在应用启动完成后或用户在应用中主动检查应用新版本时，应用需要调用HMS SDK相关接口检测华为应用市场是否有新版本应用。如果需要升级，HMS SDK将拉起升级提示框提示用户在华为应用市场升级应用。

## 3.2 业务流程  


![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200324164710.47022314912257786067223166460721:50510615094910:2800:A5BA018D5C5F4991A8AECFA9E7DC68EF6E9A2D519AF5785426CB63950158FBF8.png?needInitFileName=true?needInitFileName=true)

  1. 用户触发检查升级操作，例如启动应用或主动在检查升级页面检查升级。

  2. 应用调用[JosApps.getAppUpdateClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/josapps-v4#getAppUpdateClient)方法请求初始化AppUpdateClient实例。

  3. HMS SDK向应用返回当前应用的AppUpdateClient实例。

  4. 应用调用[AppUpdateClient.checkAppUpdate](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/appupdateclient#checkAppUpdate)方法请求检查应用是否有更新。

  5. HMS SDK在华为应用市场查询最新的应用版本信息。

  6. 华为应用市场向HMS SDK返回应用版本信息。

  7. HMS SDK通过回调方式将检查结果返回给应用。

  8. 应用从回调结果中onUpdateInfo方法返回的[ApkUpgradeInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/apkupgradeinfo)实例确认应用是否有更新。  
● 如果应用版本有更新则进行下一步。  
● 如果应用版本没有更新，则流程结束。

  9. 应用调用[AppUpdateClient.showUpdateDialog](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/appupdateclient#showUpdateDialog)方法请求拉起升级提示页面。

  10. HMS SDK向用户拉起升级提示页面。

  11. 用户在升级确认页面中选择升级应用。

  12. HMS SDK向华为应用市场请求下载最新的应用安装包。

  13. 华为应用市场向HMS SDK返回应用软件包。

  14. HMS SDK在下载完成后启动应用安装。




## 3.3 开发步骤

涉及应用升级的关键开发步骤如下：

1、调用[JosApps.getAppUpdateClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/josapps-v4#getAppUpdateClient)方法初始化AppUpdateClient对象。
      
      1. AppUpdateClient client = JosApps.getAppUpdateClient(this);
    
    

2、调用[AppUpdateClient.checkAppUpdate](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/appupdateclient#checkAppUpdate)方法检查升级版本。

(1) 调用checkAppUpdate方法。
      
      1. public void checkUpdate() {
        2.     AppUpdateClient client = JosApps.getAppUpdateClient(this);
        3.     client.checkAppUpdate(this, new UpdateCallBack(this));
        4. }
    
    

(2) 定义检查更新的回调方法，从回调结果中获取[ApkUpgradeInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/apkupgradeinfo)对象。
      
      1. private static class UpdateCallBack implements CheckUpdateCallBack {
        2.     private GameApiActivity apiActivity;
        3.     private UpdateCallBack(GameApiActivity apiActivity) {
        4.         this.apiActivity = apiActivity;
        5.     }
        6.     public void onUpdateInfo(Intent intent) {
        7.         if (intent != null) {
        8.             // 获取更新状态码， Default_value为取不到status时默认的返回码，由应用自行决定
        9.             int status = intent.getIntExtra(UpdateKey.STATUS, DEFAULT_VALUE);
        10.             // 错误码，建议打印
        11.             int rtnCode = intent.getIntExtra(UpdateKey.FAIL_CODE, DEFAULT_VALUE);
        12.             // 失败信息，建议打印
        13.             String rtnMessage = intent.getStringExtra(UpdateKey.FAIL_REASON);
        14.             Serializable info = intent.getSerializableExtra(UpdateKey.INFO);
        15.             //可通过获取到的info是否属于ApkUpgradeInfo类型来判断应用是否有更新
        16.             if (info instanceof ApkUpgradeInfo) {
        17.                 // 这里调用showUpdateDialog接口拉起更新弹窗，由于demo有单独拉起弹窗按钮，所以不在此调用，详见checkUpdatePop()方
        18.                 apiActivity.showLog("There is a new update");
        19.                 apiActivity.apkUpgradeInfo = (ApkUpgradeInfo) info;
        20.             }
        21.             apiActivity.showLog("onUpdateInfo status: " + status + ", rtnCode: " + rtnCode + ", rtnMessage: " + rtnMessage);
        22.         }
        23.     }
        24. }
    
    

3、当检查到应用版本有更新时，在checkAppUpdate的回调方法中调用[AppUpdateClient.showUpdateDialog](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/appupdateclient#showUpdateDialog)方法向用户弹出升级提示框。
      
      1. public void checkUpdatePop(boolean forceUpdate) {
        2.     AppUpdateClient client = JosApps.getAppUpdateClient(this);
        3.     client.showUpdateDialog(this, apkUpgradeInfo, forceUpdate);
        4.     Log.i(TAG, "checkUpdatePop success");
        5. }
