# 1 SDK工作方式

WalletKit SDK 在应用集成打包时会被加载在您的应用当中。用户保存卡券到华为钱包时，SDK会直接透传数据给华为服务器，不会收集用户个人数据。

# 2 SDK权限说明

WalletKit SDK不需要额外申请权限，仅透传数据。

# 3 SDK数据收集

WalletKit SDK不会收集用户个人数据，直接透传外部数据给服务器。

# 4 SDK数据安全保护

卡券数据加密及签名后传输，且不涉及敏感信息，服务端会对数据进行合法性校验。
