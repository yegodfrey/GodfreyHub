# 1 注册认证成为开发者  


如果开发者还没有华为开发者帐号，请访问[华为开发者联盟](https://developer.huawei.com/consumer/cn/)进行帐号[注册并认证](https://developer.huawei.com/consumer/cn/doc/20300)。

# 2 准备回调地址

服务器应用需准备回调地址，用于后续接收并解析返回的用户授权码code，以便用授权码code生成用户鉴权凭证Access Token。

# 3 创建服务器应用

注意：

开发者已注册过应用（如：移动应用，智慧屏应用等），且希望同时实现多种场景接入，则无需创建新的，请忽略此章节。

在华为开发者联盟，创建服务器应用，申请帐号服务。步骤如下：

1． 登录[华为开发者联盟](https://developer.huawei.com/consumer/cn/)官网，点击“管理中心”。
