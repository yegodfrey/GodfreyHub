# 应用开发举例

以步数为例，介绍如何通过 HTTP Restful 接口创建一组健康数据。

HTTPS 请求头信息参考[通过 HTTP Restful 接口访问运动健康服务](https://developer.huawei.com/consumer/cn/doc/HMS-Guides/use_restful_api-0000001050071697)。

详细的 HTTP Restful 接口请参考 [Health Kit 服务端 API 参考](https://developer.huawei.com/consumer/cn/doc/HMS-References/datacollectors_create-0000001050114852)。

#### 创建数据采集器

在 HUAWEI Health Kit，采样点是基于数据采集器（dataCollector）收集存储的，因此上传采样点前，必须先创建数据采集器。如下创建了数据类型为 com.huawei.continuous.steps.delta 的数据采集器，用于采集步数信息。

URL 请求：

POST https://health-api.cloud.huawei.com/hihealth/v1/dataCollectors

请求体：
    
    
    {
        "collectorName": "DataCollectorExample",
        "collectorType": "raw",
        "appInfo": {
            "appName": "Example App",
            "desc": "http://huaweiapi.com",
            "appVersion": "1"
        },
        "collectorDataType": {
            "field": [
                {
                    "name": "steps_delta",
                    "format": "integer"
                }
            ],
            "name": "com.huawei.continuous.steps.delta"
        },
        "deviceInfo": {
            "manufacturer": "huawei",
            "modelNum": "ExampleTablet",
            "devType": "Phone",
            "uniqueId": "1000",
            "version": "1.0"
        }
    }

如果数据采集器创建成功，响应码为 200 OK，响应体如下：
    
    
    {
        "collectorId": "raw:com.huawei.continuous.steps.delta:101272135:huawei:ExampleTablet:1000:DataCollectorExample",
        "collectorName": "DataCollectorExample",
        "collectorType": "raw",
        "collectorDataType": {
            "name": "com.huawei.continuous.steps.delta",
            "field": [
                {
                    "name": "steps_delta",
                    "format": "integer"
                }
            ]
        },
        "deviceInfo": {
            "uniqueId": "1000",
            "devType": "Phone",
            "version": "1.0",
            "modelNum": "ExampleTablet",
            "manufacturer": "huawei"
        },
        "appInfo": {
            "appName": "Example App",
            "appVersion": "1",
            "desc": "http://huaweiapi.com",
            "clientId": "101272135"
        }
    }

响应体中返回的 collectorId 在后续上传采样点、查询采样数据等场景均有使用。

URL 请求：

#### 创建活动记录

如果开发者希望给某段时间的活动添加描述、活动类型或者活跃时间等信息，可以创建活动记录（activityRecord）。

URL 请求：

PUT https://health-api.cloud.huawei.com/hihealth/v1/activityRecords/1457896543155

请求体：
    
    
    {
        "activityType": 56,
        "appInfo": {       
    	"appName": "Example App", 
    	"appVersion": "1",
    	"desc": "http://huaweiapi.com",
    	"clientId": "101272135"
        },
        "endTime": 1584626400000,
        "id": "1576221741085",
        "name": "2days",
        "desc": "test",
        "startTime": "1584460800000",
        "activeTime": "7200000"
    }

如果请求成功，响应码为200 OK，响应体如下：
    
    
    {
        "id": "1576221741085",
        "name": "2days",
        "desc": "test",
        "startTime": "1584460800000",
        "endTime": "1584626400000",
        "appInfo": {
            "appName": "Example App",
            "appVersion": "1",
            "desc": "http://huaweiapi.com",
            "clientId": "101272135"
        },
        "activityType": 56,
        "activeTime": "7200000"
    }
