# 业务简介

华为近距离通信服务（Nearby Service），是指使用蓝牙、Wi-Fi等技术，发现附近的设备并与它们通信。包括近距离设备间数据传输（Nearby Connection），和近距离设备间消息订阅（Nearby Message）。

  * **近距离设备间数据传输** ：

无需Internet连接，发现并建立与其他设备的直接通信通道。应用利用该通道，可以传输字节序列、文件和流。支持无缝的近距离互动，例如多人游戏、实时协作、广播资源和分享内容。

  * **近距离设备间消息订阅** ：

基于Internet连接，订阅者（APP）接收到发布者（Beacon或者APP）广播的共享码，根据共享码从云服务中获取对应的消息内容。




# 服务优势

  * 多种技术协同发现，速度快，成功率高。

  * 多通道智能协同极简通信，高效稳定传输。

  * 端端和端云通信使用了加密通道，并进行了双方向的身份认证。Message的消息内容在云侧加密存储。

  * 服务全球[190+地区](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/nearby-service-countrycode)，支持[70+种语言](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/hmssdk_supported_language)。
