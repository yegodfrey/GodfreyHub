在开始开发应用前，请确保已经完成[开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/69407812)动作。

# 1\. 配置文件导入

# 2\. 示例代码

  1. 配置导入成功后，建议在第一个Activity的onCreate中初始化Analytics Kit，获得HiAnalyticsInstance实例。若配置文件不正确，则会返回null，无法进行打点：



      
      1. @Override
        2. protected void onCreate(Bundle savedInstanceState{
        3.     super.onCreate(savedInstanceState);
        4.     setContentView(R.layout.activity_main);
        5.     // 获得HiAnalyticsInstance实例
        6.     HiAnalyticsInstance instance = HiAnalytics.getInstance(this);
        7. }
    
    

    2\. 在代码合适位置插入埋点代码：
      
      1. // 开发者自定义事件打点上报
        2. // 自定义事件名称为"Purchase"
        3. String eventName = "Purchase";
        4. // 自定义事件相关的字段
        5. Bundle bundle = new Bundle();
        6. bundle.putDouble("price", 9.99);
        7. bundle.putLong("quantity", 100L);
        8. bundle.putString("currency", "CNY");
        9. // 进行事件上报
        10. if (instance != null) {
        11.     instance.onEvent(eventName, bundle);
        12. }
    
    

# 3\. 接入调试

在开发过程中可以启动调试模式，实时查看事件的记录情况，观察具体结果并根据需要进行调整。

**开启/停用调试模式**

     1\. 在Android设备上执行如下命令行，开始调试模式：
      
      1. adb shell setprop debug.huawei.hms.analytics.app <package_name>
    
    

        调试模式打开后会保持启用状态，所有事件将实时上报。  


     2\. 您可执行如下命令行，停用调试模式：
      
      1. adb shell setprop debug.huawei.hms.analytics.app .none.
