# 公钥配置

由于业务需要，Analytics SDK需要使用公钥加密，服务器私钥解密的场景；公钥以配置文件的形式存放在SDK发布包的assets目录下，文件名为hianalytics_njjn。

说明：

公钥不需要修改和替换，随着发布包一起发布。

根证书文件(bks)  


发布的包中会自带CA根证书文件（hianalyticscas.bks），此文件用于服务器证书校验。
