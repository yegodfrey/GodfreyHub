完整地使用ML Kit提供的服务需要获取以下权限：

  * CAMERA：在端侧使用相机进行识别或检测，需要申请相机权限。
  * INTERNET：调用云侧接口完成识别检测功能，需要申请网络权限。
  * RECORD_AUDIO：调用语音服务，需要申请录音权限。
  * READ_EXTERNAL_STORAGE：使用音频文件转写服务，通用卡证识别插件，需要申请文件读取权限。
  * WRITE_EXTERNAL_STORAGE：在使用端侧能力时，加入此权限，用于升级算法APK版本。
  * ACCESS_NETWORK_STATE：调用端侧接口完成文本翻译或语种检测服务时，需要获取网络状态。
  * ACCESS_WIFI_STATE：调用实时语音识别服务时，需要获取Wi-Fi状态。




下表中列出的是SDK提供服务所需的最小权限，实际集成时服务可能涉及到其他权限。例如文本识别，若您需要通过拍照的方式进行云侧文本识别，则还需获取相机权限。

具体操作步骤如下

1\. 在AndroidManifest.xml文件中申请权限。
      
      1. <!--相机权限-->
        2. <uses-permission android:name="android.permission.CAMERA" />
        3. <!--使用网络权限-->
        4. <uses-permission android:name="android.permission.INTERNET" />
        5. <!--写权限-->
        6. <uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" />
        7. <!--读权限-->
        8. <uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />
        9. <!--录音权限-->
        10. <uses-permission android:name="android.permission.RECORD_AUDIO" />
        11. <!--获取网络状态权限-->
        12. <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
        13. <!--获取wifi状态权限-->
        14. <uses-permission android:name="android.permission.ACCESS_WIFI_STATE" />
    
    

2\. 在AndroidManifest.xml中添加后，对于Android 6.0及之后的版本，还需要在代码中动态申请一下权限。

您可以根据实际需要自行判断动态权限申请在应用中的位置。本例以在Activity文件中onCreate 方法中申请相机权限举例：
      
      1. private static final int CAMERA_PERMISSION_CODE = 1;
        2. @Override
        3. public void onCreate(Bundle savedInstanceState) {
        4. ...
        5.     // Checking camera permission
        6.     if (ActivityCompat.checkSelfPermission(this, Manifest.permission.CAMERA) == PackageManager.PERMISSION_GRANTED) {
        7.      // Has camera permission
        8.       ...
        9.     } else {
        10.         //request camera permission
        11.         requestCameraPermission();
        12.     }
        13. }
        14. private void requestCameraPermission() {
        15.     final String[] permissions = new String[]{Manifest.permission.CAMERA};
        16.     if (!ActivityCompat.shouldShowRequestPermissionRationale(this,Manifest.permission.CAMERA)) {
        17.         ActivityCompat.requestPermissions(this, permissions, CAMERA_PERMISSION_CODE);
        18.         return;
        19.     }
        20. }
        21. @Override
        22. public void onRequestPermissionsResult(int requestCode, @NonNull String[] permissions,@NonNull int[] grantResults) {
        23.    if (requestCode != CAMERA_PERMISSION_CODE) {
        24.       super.onRequestPermissionsResult(requestCode, permissions, grantResults);
        25.       return;
        26.    }
        27.    if (grantResults.length != 0 && grantResults[0] == PackageManager.PERMISSION_GRANTED) {
        28.       // Add Bussiness code
        29.       return;
        30.    }
        31. }
