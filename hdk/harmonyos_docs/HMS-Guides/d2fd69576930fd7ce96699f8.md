# SDK 数据安全保护

开发者应用通过 SDK 写入 Health Kit 的运动健康数据，会定期同步到服务器。

#### 数据访问控制

  1. 开发者应用需经过签名校验，才能成功调用 SDK 接口。 
  2. 开发者应用需要用户登录并授权数据访问，才能通过 SDK 接口访问相应的数据。 
  3. 开发者应用在手机锁屏下只能写入，不能读取运动健康类数据。 



#### 本地数据加密

在华为 EMUI8.1及之上手机使用时：对运动健康数据采用系统硬件的分级保护机制，保证本地数据安全可靠。

#### 服务器数据保护

  1. 服务器上的运动健康数据，采用用户级秘钥加密保护，加密算法为 AES CBC 128。 
  2. 运动健康数据的加密秘钥使用 KMS 服务器维护，与用户数据隔离存储。
