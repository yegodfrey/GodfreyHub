# Site Kit 4.0.3版本 （2020-04-17）

最新子版本号：4.0.3.300

**修改特性**

AddressDetail 增加了postalCode（邮政编码）字段。

# Site Kit 4.0.2版本（2020-03-31）

最新子版本号：4.0.2.301

#### 修改特性

通过SearchServiceFactory实例化SearchService时候需要传入apiKey参数。  


# Site Kit 4.0.1版本（2020-02-15）  


最新子版本号：4.0.1.300

#### **新增特性**

DetailSearchRequest、NearbySearchRequest、QuerySuggestionRequest、TextSearchRequest 4个类增加政治视角字段。

# Site Kit 4.0.0版本（2020-01-15）

最新子版本号：4.0.0.300

华为位置服务推出了全新的HMS SDK 4.0.0版本，该版本中位置服务是首次发布，包含位置搜索、地址详情获取，地点预测等特性，欢迎广大开发者接入试用。

# SDK依赖说明

1\. 最新版本SDK需要用户手机上安装HMS Core（APK）4.0.0.300及以上版本； 如果用户手机没有安装，您的应用调用HMS Core（APK）时，会自动引导用户提示安装。

2\. 本服务的主要特性都可以在大多数华为终端上支持，部分高级特性依赖于EMUI版本。请参考[部分特性对于EMUI的依赖说明](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/emui_version_dependent_features)。

**提示** ：

您的应用在华为应用市场上架过程中，如有问题可发送邮件至HMSCore@huawei.com咨询。
