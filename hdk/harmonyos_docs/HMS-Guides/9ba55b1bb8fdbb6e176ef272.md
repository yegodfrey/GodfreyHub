# 1 集成HMS SDK

## 1.1 在Android Studio项目中集成HMS SDK

针对AndroidStudio开发环境，华为提供了maven仓集成方式的WalletKit SDK包。在开始开发前，您需要将WalletKit SDK集成到您的AndroidStudio开发环境中：

  * 在AndroidStudio开发环境中添加当前应用的AppGallery Connect配置文件。

  * 配置HMS SDK的maven仓地址。

  * 添加编译依赖。




### 1.1.1 在AndroidStudio开发环境中添加当前应用的AppGallery Connect配置文件

**步骤1：** 登录 [AppGallery Connect 网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择“我的应用”。

**步骤2：** 在名称列表中找到应用所在的产品，点击对应的“Android应用”链接。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200226190151.87468039065070495739098262991919:50510725022935:2800:6E6957AA331D6503EC628F097D7190DDE44E4F2FE317A6C7CEEF80BAEC980C62.png?needInitFileName=true)

**步骤3：** 选择“开发 > 概览”。

**步骤4：** 单击“应用”栏下的“agconnect-service.json”下载配置文件。

**步骤5：** 将agconnect-service.json文件拷贝到项目级根目录下。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200226190205.10305154973033526926556545920988:50510725022935:2800:AB1066C7E78CC818E82A248667FF819B46D689459037AF37C607AF3F25980454.png?needInitFileName=true)

### 1.1.2 配置HMS SDK的maven仓地址

**步骤1：** 打开AndroidStudio项目级build.gradle文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200226190242.77558907676969389497737553344206:50510725022935:2800:03AD7C4BC396C32D86CFF370F50AE274C752D27B12CADEB7DBABF0CF68295981.png?needInitFileName=true)

**步骤2：** 在allprojects ->repositories里面配置HMS SDK的maven仓地址。
      
      1. allprojects { 
        2. repositories { 
        3.  google() 
        4.  jcenter() 
        5.  maven {url 'https://developer.huawei.com/repo/'} 
        6. } 
        7. }
    
    

**步骤3：** 在buildscript->repositories中配置HMS SDK的maven仓地址。
      
      1. buildscript { 
        2.  repositories { 
        3.  google() 
        4.  jcenter() 
        5.  maven {url 'https://developer.huawei.com/repo/'} 
        6.  } 
        7. }
    
    

**步骤4：** 在buildscript -> dependencies里面增加配置。
      
      1. buildscript { 
        2.  dependencies { 
        3.    classpath 'com.huawei.agconnect:agcp:1.2.1.301' 
        4.  } 
        5. }
    
    

*注：maven仓地址直接在浏览器中打开无法访问，只能在IDE中配置。

\----结束

  


### 1.1.3 添加编译依赖

**步骤1：** 打开应用级的build.gradle文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200226190335.58424895049899634278374506454519:50510725022935:2800:1DECDAD21F4583A9E237959168DB8202E237861447E2FD6D4E996DBB47AF8D33.png?needInitFileName=true)

**步骤2：** 在“dependencies” 中添加如下编译依赖。
      
      1. dependencies { 
        2.  implementation 'com.huawei.hms:wallet:{version}' 
        3. }
    
    

*注：{version} 替换为实际的SDK版本号，如：implementation 'com.huawei.hms:wallet:4.0.2.300'。

**步骤3：** 在文件头添加配置。
      
      1. apply plugin: 'com.huawei.agconnect'
    
    

\----结束

###  1.1.5 多语言设置

  * 如果您的应用不需要设置只支持某些特定语言，则请忽略本步骤。应用将默认支持所有HMS SDK支持的语言。

  * 如果您的应用需要设置只支持某些特定语言，则可通过本步骤配置。




打开应用级根目录的“build.gradle”文件。

在“android>defaultConfig”中新增“resConfigs”配置，“en”（英语） 和 “zh-rCN”（简体中文）为必须配置的语种，配置格式如下：
      
      1. android { 
        2.  defaultConfig { 
        3.  ... 
        4.  resConfigs "en", "zh-rCN", "需要支持的其他语言" 
        5.  } 
        6. }
    
    

HMS SDK支持的语言列表请参考[HMS SDK支持的语言](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/hmssdk_supported_language)。

## 1.2 在Eclipse项目中集成HMS SDK

针对Eclipse开发环境，华为提供了下载HMS SDK包本地集成的方式。在开始开发前，您需要将HMS SDK集成到您的Eclipse开发环境中。

### 1.2.1 下载HMS SDK

**步骤1：** 下载HMS Base SDK和WalletKit SDK，并解压zip包。

下载地址请参见：[Eclipse SDK下载](https://developer.huawei.com/consumer/cn/doc/development/HMS-Library/wallet-integratingsdk-exlipse)

**步骤2：** 将所有SDK工程导入到您的工作空间。  


  * 选择菜单“File > Import”，再选择“Android > Existing Android Code Into Workspace”，单击“Next”。




![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200226190826.43858827065828225908027616137336:50510725022935:2800:FC7868D532775FEE466F47D4DA82EB0E7D38E4F57F3466FB3B2402EFB150F4A9.png?needInitFileName=true)

  * 单击“Browse”，选择工程所在的文件夹。在“Projects”下显示待导入的工程，默认全部勾选，单击“Finish”。




*注：待导入的工程必须和工作空间在相同的磁盘空间里，例如都在“D:\”。如果不在，您可以选择“Copy projects into workspace”，将工程文件复制到工作空间。

# 2 配置混淆脚本

开发者编译APK前需要配置不要混淆HMS SDK，避免功能异常。

**步骤1：** 打开Android工程的混淆配置文件。

**步骤2：** 加入排除HMS SDK的混淆配置。
      
      1. -ignorewarning 
        2. -keepattributes *Annotation* 
        3. -keepattributes Exceptions 
        4. -keepattributes InnerClasses 
        5. -keepattributes Signature 
        6. -keepattributes SourceFile,LineNumberTable 
        7. -keep class com.hianalytics.android.**{*;} 
        8. -keep class com.huawei.updatesdk.**{*;} 
        9. -keep class com.huawei.hms.**{*;}
    
    

**步骤3：** 如果开发者使用了AndResGuard，需要在混淆配置文件中加入AndResGuard允许清单。
      
      1. "R.string.hms*", 
        2.  "R.string.connect_server_fail_prompt_toast", 
        3.  "R.string.getting_message_fail_prompt_toast", 
        4.  "R.string.no_available_network_prompt_toast", 
        5.  "R.string.third_app_*", 
        6.  "R.string.upsdk_*", 
        7.  "R.layout.hms*", 
        8.  "R.layout.upsdk_*", 
        9.  "R.drawable.upsdk*", 
        10.  "R.color.upsdk*", 
        11.  "R.dimen.upsdk*", 
        12.  "R.style.upsdk*"
    
    

\----结束
