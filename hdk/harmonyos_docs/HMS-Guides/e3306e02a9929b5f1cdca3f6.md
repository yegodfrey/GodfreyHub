# 1\. AppGallery Connect配置

在开始开发应用前，需要在AppGallery Connect中配置相关信息。

## 1.1 注册成为开发者

在开发应用前需要在华为开发者联盟网站上注册成为开发者并完成实名认证，具体方法可参考[帐号注册认证](https://developer.huawei.com/consumer/cn/doc/20300 "帐号注册认证")。

## 1.2 创建应用

参见[创建项目](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-get-started#createproject)和在[项目中添加应用](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-get-started#createapp)完成应用的创建，特殊配置如下：

  * “选择平台”：必须选择“Android”。

  * “支持设备”：必须选择“手机”。

  * “应用分类”：选择“应用”或“游戏”。




# 2\. 集成Ads Kit SDK

注意：

当您下载或使用HUAWEI Ads Kit组件时，您应当确认同意[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/devservice/doc/20201)、[《华为APIs使用协议》](https://developer.huawei.com/consumer/cn/doc/distribution/app/20209)以及该表格中与您使用的Kits相对应的应当签署的协议，否则您不得下载或使用相应Kits组件。您理解并承诺，您的下载或使用相应Kits的行为，视为您同意前述所有协议，且您将基于这些协议承担相应的法律责任与义务。

开发者接入华为广告服务时，可根据需要集成如下其中1个或2个SDK:

  1. ads-identifier sdk：获取OAID和“限制个性化广告”开关。

  2. ads-installreferrer sdk：获取转化跟踪参数。




开发者可以配置maven仓地址自动下载Ads Kit SDK，不需要手工下载，配置步骤如下：

## 步骤1 配置HUAWEI Ads SDK的maven仓地址

打开AndroidStudio项目级build.gradle文件，在allprojects ->repositories里面配置SDK的maven仓地址。

## 步骤2 配置依赖

打开子工程app下的build.gradle文件，在dependencies新增SDK的依赖。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200304182818.04203473364595757141723843981188:50510508094841:2800:940AD1096C1CEC0E74B9C64E8846E4F65F52F29DF3995CD5DCA29EBE0784B87D.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

将{version} 替换为实际的[SDK版本号](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ads-sdk-version-update-v3)，修改如下：
      
      1. dependencies {
        2.   implementation 'com.huawei.hms:ads-identifier:3.4.28.313'
        3.   implementation 'com.huawei.hms:ads-installreferrer:3.4.28.313'
        4. }
    
    

**说明：**

可以根据需要选择依赖的SDK。

如果需要获取OAID和“限制个性化广告”开关， 仅仅依赖com.huawei.hms:ads-identifier即可。

如果需要获取转化跟踪参数，仅仅依赖com.huawei.hms:ads-installreferrer即可。

# 3\. 配置混淆脚本

开发者编译APK前需要配置不要混淆HUAWEI Ads SDK，避免功能异常。

Android Studio开发环境里的配置文件是“proguard-rules.pro”。

1\. 打开Android工程的混淆配置文件。

2\. 加入排除HMS SDK的混淆配置。
      
      1. -keep class com.huawei.hms.ads.** {*; }
        2. -keep interface com.huawei.hms.ads.** {*; }
