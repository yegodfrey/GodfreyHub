华为机器学习服务提供的最新SDK版本参见：[ML Kit最新版本](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-history)，该版本优化了各个服务的使用体验。

  * 如果您是初次集成华为机器学习服务，请使用最新版本的SDK，不涉及升级，可以参考：[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-agc)。

  * 如果您已经集成了华为机器学习服务SDK的老版本，您需要将您集成的SDK升级至最新版本。新版本在SDK的名称，能力包的集成方法方面有优化，因此建议您在升级前，参照如下内容完成必要的准备工作。




# 1.0.0.xxx升级到2.0.0.xxx

  * 如果您只使用华为机器学习服务提供的云端能力，包括：云端文本识别、文档识别、云端图片分类、地标识别，您只需将集成的SDK基础依赖（com.huawei.hms:ml-computer-vision）修改为：



      
      1. dependencies{
        2.     implementation 'com.huawei.hms:ml-computer-vision-cloud:2.0.0.300'
        3. }
    
    

如果您只使用了云端图片分类、地标识别，您只需将集成的SDK基础依赖（com.huawei.hms:ml-computer-vision）修改为：
      
      1. dependencies{
        2.     implementation 'com.huawei.hms:ml-computer-vision-cloud:1.0.4.300'
        3. }
    
    

  * 如果您使用了端侧能力，第一步，需要将集成的SDK基础依赖（com.huawei.hms:ml-computer-vision）修改为：



      
      1. dependencies{
        2.     // 如果集成多个模块，可以将各个模块一起添加。
        3.     implementation 'com.huawei.hms:ml-computer-vision-ocr:2.0.0.300'
        4.     implementation 'com.huawei.hms:ml-computer-vision-classification:1.0.4.300'
        5.     implementation 'com.huawei.hms:ml-computer-vision-object:1.0.4.300'
        6.     implementation 'com.huawei.hms:ml-computer-vision-face:1.0.4.300'
        7. }
    
    

第二步，如果您使用Full SDK方式集成了人脸检测服务，首先，需要将集成的能力包删除（com.huawei.hms:ml-computer-vision-face-recognition-model），然后，参考如下说明进行升级：

[getFeatures()](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLFace-4#getfeatu)
