# Scan Kit 1.1.3版本（2020-04-24）

最新子版本号1.1.3.301

#### 修改特性  


  1. 生成码接口增加宽、高等统计字段。

  2. 通过优化依赖关系降低SDK大小。

  3. 解码算法优化。




说明：

如果您的项目中引入了[华为机器学习服务（ML Kit）](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-introduction-4)提供的SDK，请按照[ML Kit最新版本](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-history)进行升级，否则可能会出现功能无法使用的错误。

# Scan Kit 1.1.2版本（2020-03-15）  


最新子版本号1.1.2.300

#### 新增特性  


  1. Customized View模式新增暂停扫码、恢复扫码接口




#### 修改特性  


  1. 修改码生成接口，增加对其他12种码制式生成，增加对生成码颜色、背景色、边框的定制。目前支持生成的码制式：EAN-8、EAN-13、UPC-A、UPC-E、Codabar、Code 39、Code 93、Code 128、ITF、QR Code、Data Matrix、PDF417、Aztec

  2. 扫码传感器曝光检测优化。




# Scan Kit 1.1.1版本（2020-02-15）

最新子版本号1.1.1.301

#### 新增特性  


  1. 新增二维码生成接口。




#### 修改特性  


  1. 优化扫码算法，提升识别率和扫码速度。

  2. Default View模式和Customized View模式启动速度优化。




# Scan Kit 1.1.0版本（2020-01-15）

最新子版本号1.1.0.301

#### 新增特性  


  1. 新增MultiProcessor API调用方式，可以配合ML Kit同时检测码和人脸等多个对象。

  2. 支持多场景的码值解析，包括：Wi-Fi、EMAIL、PHONE、ISBN、PRODUCT、SMS、TEXT、URL、CONTACT INFO、GEO、CALENDAR EVENT、DRIVER LICENSE。

  3. 最多支持同时检测5个码。




#### 修改特性  


  1. 扫码算法能力优化，包括减少扫码时延，减少内存占用。

# SDK依赖说明  


本服务可在Android 4.4 (SDK Version 19) 及以上机型使用。当您的手机安装了HMS Core 4.0.0及以上版本时，Scan Kit将优先调用HMS Core内的算法模型实现更好的识别效果。如果未安装HMS Core 4.0.0及以上版本，Scan Kit SDK将使用内置算法模型完成处理，功能不受影响。

**提示** ：您的应用在华为应用市场上架过程中，如有问题可发送邮件至[](http://HMSCore@huawei.com)[HMSCore@huawei.com](mailto:HMSCore@huawei.com)咨询。
