# 1\. 使用场景

广告主APP开发者可通过Ads Kit提供SDK，获得APP转化跟踪参数，广告主可基于转化跟踪参数进行APP推广渠道分析，方便开发者清楚掌握各渠道转化效果分析。

# 2\. 注意事项

获取转化跟踪参数前，确保APP必须已经集成ads-installreferrer SDK，参见[开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/19068235 "开发准备")。

# 4\. 开发步骤

1\. 创建转化跟踪参数状态监听器。

实现[InstallReferrerStateListener](https://developer.huawei.com/consumer/cn/devservice/doc/3030505 "InstallReferrerStateListener")监听器接口的两个方法onInstallReferrerSetupFinished和onInstallReferrerServiceDisconnected，代码示例如下：
    
    
    复制
      
        1. /**
        2.  * Create a listener.
        3.  */
        4. private InstallReferrerStateListener installReferrerStateListener = new InstallReferrerStateListener() {
        5.     @Override
        6.     public void onInstallReferrerSetupFinished(int responseCode) {
        7.         switch (responseCode) {
        8.             case InstallReferrerClient.InstallReferrerResponse.OK:
        9.                 Log.i(TAG, "connect ads kit ok");
        10.                 // Get results
        11.                 try {
        12.                     ReferrerDetails referrerDetails = mReferrerClient.getInstallReferrer();
        13.                 } catch (RemoteException e) {
        14.                     Log.i(TAG, "getInstallReferrer RemoteException: " + e.getMessage());
        15.                 } catch (IOException e) {
        16.                     Log.i(TAG, "getInstallReferrer IOException: " + e.getMessage());
        17.                 }
        18.                 break;
        19.             case InstallReferrerClient.InstallReferrerResponse.FEATURE_NOT_SUPPORTED:
        20.                 Log.i(TAG, "FEATURE_NOT_SUPPORTED");
        21.                 break;
        22.             case InstallReferrerClient.InstallReferrerResponse.SERVICE_UNAVAILABLE:
        23.                 Log.i(TAG, "SERVICE_UNAVAILABLE");
        24.                 break;
        25.             default:
        26.                 Log.i(TAG, "responseCode: " + responseCode);
        27.                 break;
        28.         }
        29.     }
        30.     @Override
        31.     public void onInstallReferrerServiceDisconnected() {
        32.         Log.i(TAG, "onInstallReferrerServiceDisconnected");
        33.     }
        34. };
    
    

2\. 创建[InstallReferrerClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/3030506 "InstallReferrerClient")实例。  


**步骤1** 调用[InstallReferrerClient.newBuilder](https://developer.huawei.com/consumer/cn/devservice/doc/3030507 "InstallReferrerClient.newBuilder")创建一个Builder实例。

**步骤2** 调用[build](https://developer.huawei.com/consumer/cn/devservice/doc/3030507 "build")创建[InstallReferrerClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/3030506)实例。
    
    
    复制
      
        1. mReferrerClient = InstallReferrerClient.newBuilder(this).build();
    
    

3\. 连接转化跟踪参数服务。  


**步骤1** 创建一个子线程。

**步骤2** 设置[startConnection](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/3030506#startConnection "startConnection")的监听器为已创建的[InstallReferrerStateListener](https://developer.huawei.com/consumer/cn/devservice/doc/3030505 "InstallReferrerStateListener") 监听器。
    
    
    复制
      
        1. private Thread connectThread = new Thread() {
        2.      @Override
        3.      public void run() {
        4.         connect();
        5.      }
        6. }
        7. /**
        8. * Connect to the HMS.
        9. */
        10. private void connect() {
        11.     mReferrerClient = InstallReferrerClient.newBuilder(InstallReferrerActivity.this).build();
        12.     mReferrerClient.startConnection(installReferrerStateListener); 
        13. }
    
    

说明：

建立与转化跟踪参数服务的连接，不要在主线程中调用该方法。
