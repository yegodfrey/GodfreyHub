# 集成 HMS Core SDK

Android Studio 开发环境，建议版本 v3.3.2 及以上。

#### 配置 HMS Core SDK 的 maven 仓地址

  1. 打开 AndroidStudio 项目根路径下的 **build.gradle** 文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515184202.33617643522493077161876960316972:50510515105457:2800:5F05071E8000FDB1CDFA669F1B83DD39E6B23E69A82FB36ED97BC8839D0EFA07.png?needInitFileName=true?needInitFileName=true)

  2. 在 “allprojects>repositories” 里面增加 HMS Core SDK 的 maven 仓地址。
         
         maven {url 'https://developer.huawei.com/repo/'} 

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515184202.45467435575010908708648587468330:50510515105457:2800:A1D20E84C5F238BE65BE412BDFEAA525C00D0B1CE5E627EF66B6E0E48388C4B0.png?needInitFileName=true?needInitFileName=true)

  3. 在 “buildscript > repositories” 里面增加 HMS Core SDK 的 maven 仓配置。
         
         maven {url 'https://developer.huawei.com/repo/'}

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515184202.57775248614542954766135957719747:50510515105457:2800:ED763F3F2042D88E191E10A847738F3B7590A5DC0A5CDD8217B3C30403CE4CEC.png?needInitFileName=true?needInitFileName=true)

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515184202.29895505394896615630180390714607:50510515105457:2800:DD701A8DB0297A4A87751E1ED50ED6276EBC5EE3C3FF6DA9BDFCE05CFD279793.png?needInitFileName=true?needInitFileName=true)

maven 仓地址直接在浏览器中打开无法访问，只能在 IDE 中配置。




#### 添加编译依赖

  1. 打开 app 下应用级的 **build.gradle** 文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515184202.53344155815722316141008584040815:50510515105457:2800:248758480489DF0B120CF11FDCEF63A53CDD97F1BF4E045AF0BAADE6BB66A229.png?needInitFileName=true?needInitFileName=true)

  2. 在“dependencies ”中添加如下编译依赖。
         
         implementation 'com.huawei.hms:hihealth-base:{version}'

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515184202.59161441139193445847663968169888:50510515105457:2800:BFC63AE33221AA21F285CF69157A245C8E1A19C334A1D3979515FCBE516C5B06.png?needInitFileName=true?needInitFileName=true)

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515184202.18626297743781096237415932089925:50510515105457:2800:1BEDF2EB99F3246332107CB3EEAE068CD067F8B289A6F103739547AEC912A7BA.png?needInitFileName=true?needInitFileName=true)

以上各依赖包{version} 替换为实际的 SDK 版本号，如：4.0.4.300。建议集成最新的 SDK 版本，版本号详见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/HMS-Guides/version_history-0000001050069718)。

  3. 重新打开修改完的 **build.gradle** 文件，右上方出现**Sync Now** 链接。点击“Sync Now”等待同步完成。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515184202.38711789433954957633737868951844:50510515105457:2800:4BF2A057961850CB027FDD948640D64F4F23B826997027C4C0CBEF12E6AD1A92.png?needInitFileName=true?needInitFileName=true)

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515184202.31735742972364507388225345606493:50510515105457:2800:40F301CC70E3E704EA441EBE9EC992CDC53132456BC3E769062D4E8B7E8E15D5.png?needInitFileName=true?needInitFileName=true)

如果出现错误，请检查网络连接是否正常，以及检查 gradle 文件是否正确。




#### 添加 APP ID 信息

  1. 打开 **AndroidManifest.xml** 文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515184202.55390013086014487853192172057232:50510515105457:2800:F4AF34A664008028002F4FE4DE397CBA55E004A5526A7234CA3F7D4BDA9C8AA6.png?needInitFileName=true?needInitFileName=true)

  2. 在“application”中添加开发者联盟创建应用时生成的 APP ID 信息。

value 的 APP ID ，请使用“[申请帐号服务](https://developer.huawei.com/consumer/cn/doc/HMS-Guides/apply_id-0000001050069756)”过程中创建产品生成的 APP ID。
         
         <meta-data
         android:name="com.huawei.hms.client.appid"
         android:value="APP ID"/>

#### 多语言设置

  * 如果您的应用不需要设置只支持某些特定语言，则请忽略本步骤。应用将默认支持所有 HMS Core SDK 支持的语言。 
  * 如果您的应用需要设置只支持某些特定语言，则可通过本步骤配置。 


  1. 打开 app 下应用级根目录的 **build.gradle** 文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515184202.75884482292742500254627119326158:50510515105457:2800:8B38A59D0F07C24BD5AD3A1D8879464272EC99468404E0B70C073D860A1E2BE5.png?needInitFileName=true?needInitFileName=true)

  2. 在**“** android>defaultConfig**”** 中新增 **resConfigs** 配置，**en** （英语） 和 **zh-rCN** （简体中文）为必须配置的语种，配置格式如下：
         
         resConfigs "en", "zh-rCN"，"需要支持的其他语言" 

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515184202.13470741087181375920837078404368:50510515105457:2800:FB0C355E5ACF9C10AD8C950025A3BF43FACF22251429CBEEA53AE77616200788.png?needInitFileName=true?needInitFileName=true)

HMS Core SDK支持的语言列表请参考[HMS Core SDK支持的语言](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/hmssdk_supported_language)。
