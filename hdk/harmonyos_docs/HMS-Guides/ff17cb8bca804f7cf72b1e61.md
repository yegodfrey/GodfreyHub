# 移动端SDK  


SDK需要在应用打包时，被集成到您的应用当中。SDK会随着应用的启动运行在客户应用的进程空间。当用户关闭应用时，SDK会随着应用的关闭而关闭。

# SDK数据收集

Awareness SDK不会保存任何来自开发者的个人数据，且不会向其他第三方披露个人数据。Awareness SDK只提供能力接口，业务方通过SDK的能力接口按需调用Awareness端侧Service的服务能力。

# SDK数据安全保护

Awareness SDK与Awareness端侧Service之间的数据交换基于Binder传输，Android系统本身的安全机制保障了基于Binder传输的数据安全。
