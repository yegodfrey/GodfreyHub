# 1\. 在AppGallery Connect中配置应用信息

在开始开发应用前，需要在AppGallery Connect中配置相关应用信息。

## 1.1 注册成为开发者

在开发应用前需要在[华为开发者联盟](https://developer.huawei.com/consumer/cn)网站上注册成为开发者并完成实名认证，具体方法可参考[帐号注册认证](https://developer.huawei.com/consumer/cn/devservice/doc/20300)。

## 1.2 创建应用

参见AppGallery Connect帮助中心的[创建应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-create_app)章节创建应用并上传一个临时APK包，特殊配置如下：

  * “软件包类型”：必须选择“APK(Android应用)”

  * “支持设备”：必须选择“手机”。

  * “应用分类”：选择“应用”。




# 2. 准备开发环境

使用React Native，您必须在电脑上安装NodeJs和Android Studio。

注意：JDK版本必须是1.8或以上。

## 2.1 安装华为移动服务（APK）

使用华为定位服务的定位接口，需要在你的设备上下载并安装华为移动服务（APK）4.0.2.301及以上版本。

## 2.2 安装软件包管理器

具体安装和配置方法，请访问[**Node官网**](https://nodejs.org/en/)。

要使用华为定位服务库，必须安装软件包管理器。 （Npm或Yarn等）

安装Node.JS后Npm就默认已安装了。 您可以点击[**这里**](https://nodejs.org/en/download/)来下载并安装Node.JS。

安装完Node.JS后，您就可以在命令行工具中执行如下命令检查安装的Npm版本：
    
    
    复制
      
        1. npm -v
    
    

**react-native** ：如果需要使用原生Android模块的源代码，则该参数必传。  

    
    
    复制
      
        1. npm install -g react-native
    
    

## 2.3 安装Android SDK

具体安装和配置方法，请访问[**React Native官网**](https://reactnative.dev/docs/getting-started/)。

特别注意一下事项：

  * 下载Android SDK 10.0 （API Level 29）和9.0（API Level 28）：

进入**设置 > Android SDK > SDK平台**，选择Android 10.0和Android 9.0，点击“确定”。 Android Studio会自动下载并安装Android SDK 10.0 （API Level 29）及9.0（API Level 28）。

  * 配置环境变量 _ANDROID_HOME_ 。

打开Windows控制面板，进入**System and Security > System > Change settings > Advanced > Environment Variables > New**，创建指向您Android SDK目录的系统或用户变量 _ANDROID_HOME_ 。




说明：

Android SDK默认安装在**C:\Users\Your_Username\AppData\Local\Android\Sdk** 路径下。

如需查看Android SDK所处的路径，您可以打开Android Studio，进入**File > Settings**。 然后进入**Appearance & Behavior > System Settings > Android SDK**，点击右侧窗格中的**Android SDK Location** 。

  * 在Path下添加 _platform-tools_ 目录。

打开Windows控制面板，进入**System and Security**** > ****System**** > ****Change settings**** > Advanced > Environment Variables**。 选择变量“Path”，然后点击“Edit”。 点击“New”并将 _platform-tools_ 目录添加至列表。




说明：

 _platform-tools_ 位于目录 _Android SDK_ 中。 在上一步配置完变量 _ANDROID_HOME_ 后，将 _%ANDROID_HOME%\platform-tools_ 添加到Path变量中。

# 4\. 配置混淆脚本  


开发者编译APK前需要配置不要混淆HMS SDK，避免功能异常。

Android Studio开发环境里的配置文件是“proguard-rules.pro”。

1、打开Android工程的混淆配置文件。

2、加入排除HMS SDK的混淆配置。
    
    
    复制
      
        1. -ignorewarnings
        2. -keepattributes *Annotation*
        3. -keepattributes Exceptions
        4. -keepattributes InnerClasses
        5. -keepattributes Signature
        6. -keepattributes SourceFile,LineNumberTable
        7. -keep class com.hianalytics.android.**{*;}
        8. -keep class com.huawei.updatesdk.**{*;}
        9. -keep class com.huawei.hms.**{*;}
    
    

3、如果开发者使用了AndResGuard，需要在混淆配置文件中加入AndResGuard白名单。
    
    
    复制
      
        1. "R.string.hms*",

        3. "R.string.getting_message_fail_prompt_toast",
        4. "R.string.no_available_network_prompt_toast",
        5. "R.string.third_app_*",
