在开始API开发工作之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-process-4)，同时请确保您的工程中已经[配置HMS Core SDK的maven仓地址](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-maven-4)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-translate-sdk-4)。

## 设备侧文本翻译

1\. 创建文本翻译器。可以通过文本翻译器自定义参数类[MLLocalTranslateSetting](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/mllocaltranslatesetting)创建翻译器。
      
      1. // 创建离线翻译器。
        2. MLLocalTranslateSetting setting = new MLLocalTranslateSetting.Factory()
        3.     // 设置源语言的编码，使用ISO 639-1标准。此设置为必选项，如果不设置，将可能出现问题。
        4.     .setSourceLangCode("zh") 
        5.     // 设置目标语言的编码，使用ISO 639-1标准。此设置为必选项，如果不设置，将可能出现问题。
        6.     .setTargetLangCode("en")
        7.     .create();
        8. final MLLocalTranslator mlLocalTranslator = MLTranslatorFactory.getInstance().getLocalTranslator(setting);
    
    

2\. 下载本地离线翻译所需要的离线模型，我们提供两种方式：

  * 通过[MLLocalModelManager](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/mllocalmodelmanager)手动下载所需模型包.

  * 通过[preparedModel](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/mllocaltranslator)自动下载所需模型包。




您可根据需求自行选择下载方式。

## 云侧文本翻译

1\. 创建文本翻译器。可以通过文本翻译器自定义参数类[MLRemoteTranslateSetting](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLRemoteTranslateSetting-4)创建翻译器。
      
      1. // 使用自定义的参数配置创建文本翻译器。
        2. MLRemoteTranslateSetting setting = new MLRemoteTranslateSetting
        3.     .Factory()
        4.     // 设置源语言的编码，使用ISO 639-1标准。此设置为可选项，如果不设置，将自动检测语种进行翻译。
        5.     .setSourceLangCode("zh")
        6.     // 设置目标语言的编码，使用ISO 639-1标准。
        7.     .setTargetLangCode("en")
        8.     .create();
        9. MLRemoteTranslator mlRemoteTranslator = MLTranslatorFactory.getInstance().getRemoteTranslator(setting);
    
    

2. 进行文本翻译。
      
      1. // sourceText是待翻译的文本，长度需小于5000个字符。
        2. final Task<String> task = mlRemoteTranslator .asyncTranslate(sourceText);
        3. task.addOnSuccessListener(new OnSuccessListener<String>() {
        4.     @Override
        5.      public void onSuccess(String text) {
        6.          // 识别成功的处理逻辑。
        7.    }
        8. }).addOnFailureListener(new OnFailureListener() {
        9.      @Override
        10.      public void onFailure(Exception e) {
        11.          // 识别失败的处理逻辑。
        12.          try {
        13.              MLException mlException = (MLException)e;
        14.              // 获取错误码，开发者可以对错误码进行处理，根据错误码进行差异化的页面提示。错误码信息可参见：[机器学习服务错误码](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLException-4)。
        15.              int errorCode = mlException.getErrCode();
        16.              // 获取报错信息，开发者可以结合错误码，快速定位问题。
        17.              String errorMessage = mlException.getMessage();
        18.          } catch (Exception error) {
        19.            // 转换错误处理。
        20.          }
        21.      }
        22.  });
    
    

3. 翻译完成后，释放资源。
      
      1. if (mlRemoteTranslator!= null) {
        2.     mlRemoteTranslator.stop();
        3. }
