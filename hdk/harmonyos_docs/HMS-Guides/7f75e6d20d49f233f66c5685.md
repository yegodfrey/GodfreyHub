本章节将向您介绍通过华为地图API for JavaScript提供的位置搜索接口。

# 1 关键字搜索

您可以通过指定的关键字和可选的地理范围，查询诸如旅游景点、企业和学校之类的地点。

## 1.1 实现步骤

1\. 通过HWMapJsSDK初始化[HWSiteService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-site-service)对象。

2\. 构建搜索的请求体request对象，其中query是必选参数，其余可选：

  * query：搜索关键字。

  * location：搜索结果偏向的经纬度。

  * radius：搜索半径，单位是米。默认值是50公里，取值范围是1米-50公里。

  * poiType：返回指定POI类型的地点。

  * countryCode：在指定的国家内搜索，采用ISO 3166-1 alpha-2。

  * language：搜索结果的语种。如果不传，使用地点的当地语言。

  * pageSize：每页返回的记录数。默认值是20，取值范围是1-20。

  * pageIndex：当前页数。默认值是1，取值范围是1-60。

  * politicalView：政治观点参数，采用ISO 3166-1-alpha-2规范的2位国家码。




3\. 通过第1步创建的[HWSiteService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-site-service)对象调用searchByText接口，传入第2步创建的request对象。

4\. 获取搜索结果。通过第3步searchByText接口的回调函数返回搜索结果result和搜索状态status。status参考返回码小节，result包含以下对象：

  * sites：搜索结果[Site](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description#site)[]，[Site](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description#site)描述参考[参数说明](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description)小节。

  * totalCount：记录总数。




## 1.2 示例代码
      
      1. var map;
        2. var mapOptions = {};
        3. mapOptions.center = {lat: 48.856613, lng: 2.352222};
        4. mapOptions.zoom = 15;
        5. map = new HWMapJsSDK.HWMap(document.getElementById('map'), mapOptions);
        6. var siteService
        7. //初始化HWSiteService对象
        8. siteService = new HWMapJsSDK.HWSiteService();
        9. //初始化请求参数对象
        10. var request = {
        11.     query: "Paris"
        12. };
        13. //调用搜索接口，result为返回结果，status为返回状态
        14. siteService.searchByText(request, function (result, status) {
        15.     if (status == '0') {
        16.         for (var i = 0; i < result.sites.length; i++) {
        17.             //在地图上添加标记
        18.             var marker = new HWMapJsSDK.HWMarker({
        19.                 map: map,
        20.                 position: {lat: result.sites[i].location.lat, lng: result.sites[i].location.lng},
        21.                 label: result.sites[i].name
        22.             });
        23.         }
        24.         //设置地图的中心点
        25.         map.setCenter({lat: result.sites[0].location.lat, lng: result.sites[0].location.lng})
        26.     }
        27. });
    
    

# 2 周边搜索

通过用户传入自己的位置，可以返回周边地点列表，继而通过获取到的SiteID，可以查询该地点的详细信息。

## 2.1 实现步骤

1\. 通过HWMapJsSDK初始化[HWSiteService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-site-service)对象。

2\. 构建搜索的请求体request对象，其中location是必选参数，其余可选：

  * location：用户当前的位置。

  * radius：可以指定搜索半径。单位是米，默认值是1公里，取值范围是1米-50公里。

  * query：输入搜索关键字。

  * poiType：返回指定POI类型的地点。

  * language：搜索结果的语种。如果不传，使用地点的当地语言。

  * pageSize：每页返回的记录数。默认值是20，取值范围是1-20。

  * pageIndex：当前页数。默认值是1，取值范围是1-60。

  * politicalView：政治观点参数，采用ISO 3166-1-alpha-2规范的2位国家码。




3\. 通过第1步创建的[HWSiteService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-site-service)对象调用nearbySearch接口，传入第2步创建的request对象。

4 .获取搜索结果。通过第3步nearbySearch接口的回调函数返回搜索结果result和搜索状态status。status参考返回码小节，result包含以下对象：

  * sites：搜索结果[Site](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description#site)[]，[Site](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description#site)描述参考[参数说明](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description)小节。

  * totalCount：记录总数。

# 3 地址详情

您可以通过某一地点的SiteID来获取该地点的详细信息，SiteID是地点的唯一标识符。

## 3.1 实现步骤

1\. 通过HWMapJsSDK初始化[HWSiteService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-site-service)对象。

2\. 构建搜索的请求体request对象，传入以下参数：

  * siteId：地址ID，必选项。

  * language：查询结果的语种，可选项。如果不传，使用地点的当地语言。

  * politicalView：政治观点参数，采用ISO 3166-1-alpha-2规范的2位国家码。




3\. 通过第1步创建的[HWSiteService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-site-service)对象调用searchById接口，传入第2步创建的request对象。

4\. 获取搜索结果。通过第3步searchById接口的回调函数返回搜索结果result和搜索状态status。status参考返回码小节，result包含以下对象：

  * site：搜索结果[Site](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description#site)，[Site](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description#site)描述参考[参数说明](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description)小节。




## 3.2 示例代码
      
      1. var map;
        2. var mapOptions = {};
        3. mapOptions.zoom = 15;
        4. map = new HWMapJsSDK.HWMap(document.getElementById('map'), mapOptions);
        5. var siteService
        6. //初始化HWSiteService对象
        7. siteService = new HWMapJsSDK.HWSiteService();
        8. //初始化请求参数对象
        9. var request = {
        10.     siteId: "F45411D2CC51C59156364492A8D13622"
        11. };
        12. siteService.searchById(request, function (result, status) {
        13.     if (status == '0') {
        14.         var marker = new HWMapJsSDK.HWMarker({
        15.             map: map,
        16.             position: {lat: result.site.location.lat, lng: result.site.location.lng},
        17.             label: result.site.name
        18.         });
        19.         map.setCenter({lat: result.site.location.lat, lng: result.site.location.lng})
        20.     }
        21. });
    
    

# 4 地点搜索建议

该功能可用于在用户键入查询内容的时候，实时地返回建议的查询结果，从而实现查询预测效果。

## 4.1 实现步骤

1\. 通过HWMapJsSDK初始化[HWSiteService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-site-service)对象。

2\. 构建搜索的请求体request对象，其中query是必选参数，其余可选：

  * query：搜索关键字。

  * location：搜索结果偏向的经纬度。

  * radius：搜索半径，单位是米，可选项。默认值是50公里，取值范围是1米-50公里。

  * bounds：搜索结果偏向的范围。

  * poiTypes：指定返回指定POI类型的地点。

  * countryCode：在指定的国家内搜索，采用ISO 3166-1 alpha-2。

  * language：搜索结果的语种。如果不传，使用地点的当地语言。

  * politicalView：政治观点参数，采用ISO 3166-1-alpha-2规范的2位国家码。




3\. 通过第1步创建的[HWSiteService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-site-service)对象调用querySuggestion接口，传入第2步创建的request对象。

4\. 获取搜索结果。通过第3步querySuggestion接口的回调函数返回搜索结果result和搜索状态status。status参考返回码小节，result包含以下对象：

## 4.3 搜索控件

华为地图JavaScript API提供自动补全控件，当用户输入地址名称时，自动补全其余内容。

### 4.3.1 实现步骤

1\. 创建html元素input。该元素为搜索框界面，供用户输入文字。

2\. 创建搜索框参数对象acOptions。支持的参数参考4.1 实现步骤的参数部分(除query参数在搜索框输入)。

3\. 通过HWMapJsSDK创建[HWAutocomplete](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-autocomplete)对象，传入第1步创建的input对象和第2步创建的搜索框参数对象acOptions。

4\. 给第3步创建的[HWAutocomplete](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-autocomplete)对象设置监听函数，搜索框每输入一个字符，搜索框会出现下拉框出现5条搜索建议，点击某一条搜索建议，会执行该监听函数。通过该监听函数可获取某一条位置信息。

### 4.3.2 示例代码
      
      1. <div id="searchDiv" style="position: absolute; z-index: 10; top: 15px; left: 50px; height: 30px;width: 400px">
        2.     //创建input元素，该元素嵌在html页面。注意input元素必须是父布局的最后一个元素。
        3.     <input id="searchBox" type="text" style="height: 30px;width: 400px" placeholder="Anything you want!"/>
        4. </div>
        5. var mapOptions = {};
        6. var map = new HWMapJsSDK.HWMap(document.getElementById('map'), mapOptions);
        7. var searchBoxInput = document.getElementById('searchBox');
        8. //创建搜索框参数
        9. var acOptions = {
        10.     location: {
        11.         lat: 48.856613,
        12.         lng: 2.352222
        13.     },
        14.     radius: 10000,
        15. };
        16. var autocomplete;
        17. //获取input元素
        18. var searchBoxInput = document.getElementById('searchBox');
        19. //创建HWAutocomplete对象，并设置监听函数
        20. autocomplete = new HWMapJsSDK.HWAutocomplete(searchBoxInput, acOptions);
        21. autocomplete.addListener('site_changed', printSites);
        22. //监听函数
        23. function printSites() {
        24.     console.log("in print sites...");
        25.     var site = autocomplete.getSite();
        26.     var results = "Autocomplete Results:\n";
        27.     var str = "Name=" + site.name + "\n"
        28.         + "SiteID=" + site.siteId + "\n"
        29.         + "Latitude=" + site.location.lat + "\n"
        30.         + "Longitude=" + site.location.lng + "\n"
        31.         + "Address=" + site.formatAddress + "\n";
        32.     results = results + str;
        33. }
