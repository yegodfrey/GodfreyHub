# 什么是华为游戏服务？

游戏服务是华为向开发者提供的能够快速开发游戏应用的服务。华为游戏服务当前向第三方游戏应用提供了以下能力：

  * 华为帐号登录

  * 实名认证

  * 游戏公告展示

  * 成就

  * 事件上报

  * 排行榜

  * 游戏存档

  * 玩家信息统计




# 华为游戏服务能为开发者带来的好处？

  * 开发者可以允许用户使用华为帐号登录游戏，从而迅速推广游戏，共享华为庞大的用户价值。游戏服务支持的国家和地区请参见[华为帐号支持的国家和地区](https://developer.huawei.com/consumer/cn/doc/HMS-Guides/account-countrycode)。

  * 开发者可以快速实现成就、游戏事件上报等功能，快速低成本的构建游戏基本能力。

  * 开发者可以基于用户和内容的本地化进行深度的游戏运营。




# 游戏联运

游戏联运是指华为应用市场与开发者联合运营游戏，提供面向全球的分发能力、便捷的开发服务、优质的运营资源、多样营销活动，促进业务用户和流水持续增长。如开发者需参与游戏联运，详细介绍可参见[联运服务开发指南](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/appgallerykit-introduction)。
