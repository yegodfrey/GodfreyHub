# 1\. 功能说明

钱包提供的Huawei Pay线上支付有三种对接方式，分别是：

1）APP支付：商户通过在移动端应用APP集成SDK接口形式接入；

2）手机网页支付（WAP支付）：手机WAP支付产品是提供给商户的移动终端客户端或网页用来支付的产品，采用手机网页（包括WAP、WEB手机网页网）方式实现无卡支付的产品；

3）H5支付：商户H5接口通过JS形式接入。

主要提供接口包含查询Huawei Pay状态和调起支付两个接口。

# 2\. 使用场景介绍

Huawei Pay线上支付是手机端的在线支付方式，可以根据需要采用对应的支付方式接入，之后根据目录选择需要的接入方式。

商户使用Huawei Pay线上支付可以和银联对接生成订单，商户把订单信息传给华为钱包，由钱包调起银联插件完成支付，SDK接口和JS接口会直接返回结果给调用方，而WAP调用方式是银联服务器将支付结果通知第三方服务器，第三方WAP页面到第三方服务器查询支付结果。

**错误码（int）**| **含义**| **说明**

##### 3.2.4使用方法

请将下面的jar复制并放入自己的工程中，需要注意Sdk对外的接口都是异步，回调都是通过CallBack来实现，jar包见本文结尾附件。

    HwOpenSdkTask task = new HwOpenSdkTask(this);  
     task.getStatus(“ONLINEPAY”, new IHwResultCallBack()  
     {  
         @Override  
         public void onResult(int resultCode, Bundle data)  
         {  
             Log.e(TAG, "resultCode:" + resultCode);  
       
         }  
     });

    HwOpenSdkTask task = new HwOpenSdkTask(this);  
     task.startHuawei Pay(payInfo, new IHwResultCallBack()  
     {  
         @Override  
         public void onResult(int resultCode, Bundle data)  
         {  
             Log.e(TAG, "resultCode:" + resultCode);  
         }  
     });

#### 3.3手机网页支付（WAP支付）

##### 3.3.1接口定义

第三方Wap页面通过Schema调用钱包APP，将订单信息传给钱包APP，携带订单号、合作伙伴ID、签名信息。

Schema定义如下：

financeclient://com.huawei.wallet/thirdpayservice?action="thirdpayservice"&params={"PartnerID":"xxxx";"TN":"xxxx";"SignData":"xxxx"}

##### 3.3.2入参说明

**名称**| **类型**| **描述**| **可选**  
---|---|---|---  
PartnerID| String| 合作伙伴ID| M  
TN| String| 订单号| M  
SignData| String| 签名信息| M  
  
 

第三方的传入参数的规则为：

签名算法：SHA256WithRSA

SignData签名值生成方法：params内容里除了SignData外其他字段，每一个Key值按ASCII码的增序排序，若遇到相同首字母，则看第二个字母，以此类推。排序完成之后，再把所有数组值以“&”字符连接起来，如： PartnerID=123&TN=234，使用商户RSA私钥将转换后的明文生成签名信息后，将byte[]签名结果按base64编码后设置为SignData的值。

schema中的params值：json串再按照Uri.encode进行编码后赋值为params值。

##### 3.3.3使用方法

第三方WAP通过钱包APP验证服务器的响应信息合法后，调用银联控件进行支付，银联服务器将支付结果通知第三方服务器，第三方WAP页面到第三方服务器查询支付结果。

 

注意：

1）第三方WAP页面发送请求到钱包APP后，钱包APP不会返回结果给第三方WAP页面，如果钱包APP在发送请求给银联之前有异常，比如未打开NFC等，钱包直接给出对应的提示；

2）成功支付的前提条件：钱包账户登录成功、打开NFC开关（仅支持Huawei Pay的手机需要，不支持Huawei Pay手机不需要）、已设置钱包支付密码、有可用银行卡、已安装银联插件等。
