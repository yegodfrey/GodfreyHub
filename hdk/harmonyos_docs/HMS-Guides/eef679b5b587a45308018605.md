# 1\. 注册成为开发者    


在开发应用前需要在[华为开发者联盟](https://developer.huawei.com/consumer/cn/)网站上[注册](https://id1.cloud.huawei.com/CAS/portal/userRegister/regbyemail.html?service=https%3A%2F%2Foauth-login1.cloud.huawei.com%2Foauth2%2Fv2%2Flogin%3Faccess_type%3Doffline%26client_id%3D6099200%26display%3Dpage%26h%3D1578657810.2450%26lang%3Dzh-cn%26redirect_uri%3Dhttps%253A%252F%252Fdeveloper.huawei.com%252Fdevunion%252FopenPlatform%252Frefactor%252FhandleLogin.html%26response_type%3Dcode%26scope%3Dhttps%253A%252F%252Fwww.huawei.com%252Fauth%252Faccount%252Fcountry%2Bhttps%253A%252F%252Fwww.huawei.com%252Fauth%252Faccount%252Fbase.profile%26v%3De92884d4075c042df15ca7073420502391843624f3f12d9bd74663674df3b139&loginUrl=https%3A%2F%2Fid1.cloud.huawei.com%3A443%2FCAS%2Fportal%2FloginAuth.html&clientID=6099200&lang=zh-cn&display=page&loginChannel=89000000&reqClientType=89)成为开发者，并完成实名认证，具体方法可以参考[帐号注册认证](https://developer.huawei.com/consumer/cn/doc/20300)。  

# 2\. 创建应用  

参见[创建项目](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-get-started#createproject)和在[项目中添加应用](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-get-started#createapp)完成应用的创建，特殊配置如下：  

  * “选择平台”：必须选择“Android”。

  * “支持设备”：必须选择“手机”。




说明：

如需集成HMS SDK中的支付能力进行应用内收费，应用包名必须以“.HUAWEI”或者“.huawei”结尾，否则会导致审核不通过。

3. 生成签名证书指纹    


签名证书指纹用于在通过华为HMS SDK调用HMS Core服务时，校验应用的真实性。开发者在使用HMS Core服务前必须将签名证书指纹配置到AppGallery Connect，在配置前需要根据签名证书在本地生成签名证书指纹。

在申请前需要满足以下2个条件：  

  * 已创建应用程序的签名文件，签名证书创建属于通用技术，此处不详细描述。  

  * 当前开发的PC已经安装JDK。  




可以使用JDK自带的keytool工具生成指纹，操作步骤如下：  

1.    打开命令行工具（使用CMD命令），执行cd命令进入keytool.exe所在的目录（图中样例为PC上java程序安装在C盘的Program Files (x86)目录）。  

 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200111171043.30552603685067289706659540376067:50510506004354:2800:9F81A7D299FBDA3434EB22CA4B8E3B906C5DD727068121E03D4ECB5DA7BFF969.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)  

2.    执行命令keytool -genkey -alias <aliasname> -keyalg RSA -keystore <keystore-file>，按命令行提示进行操作。<aliasname>是签名文件的别名；<keystore-file>是应用签名文件的完整路径。例如：
      
      1. C:\Program Files (x86)\Huawei\jdk1.8.0_232\bin>keytool -genkey -alias nearbyDemokey -keyalg RSA -keystore D:\Demo\nearbyDemo.keystore  
         
    
    

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200114094350.84197192604788734006471380891514:50510506004354:2800:3F374B220E8F8DAFDE3D89DF7EC0E19BFC16C0C232B8EE8300754925977DB22C.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)  

3.   执行命令keytool -list -v -keystore<keystore-file>，按命令行提示进行操作。<keystore-file>是应用签名文件的完整路径。例如：

4.   根据结果获取对应的SHA256指纹。

# 4. 配置签名证书指纹  

1.      登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) 网站，选择“我的应用”。  

2.    点击需要配置的应用。

3.    在“开发”页签，在“项目设置”页面的“应用”区域，将“SHA256证书指纹”配置为生成签名证书指纹中生成的SHA256指纹。
