在开始API开发工作之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-process-4)，同时请确保您的工程中已经[配置HMS Core SDK的maven仓地址](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-maven-4)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-gcr-sdk-4)。

开发者可以调用通用卡证识别插件接口，通过回调函数获取识别结果，无需自己实现视频流、拍照、图片选择等场景，具体实现请参考示例代码：

1\. 创建识别结果回调函数，重载onResult， onCanceled， onFailure， onDenied四个方法；onResult表示返回了结果，MLGcrCaptureResult为卡证识别返回的结果，onCanceled 表示用户取消，onFailure 表示识别失败，onDenied 表示相机不可用等场景。
      
      1. private MLGcrCapture.Callback callback = new MLGcrCapture.Callback() {

        3.     // MLGcrCaptureResult.CAPTURE_CONTINUE：表示返回的结果不满足要求（无结果或返回结果有误等），在视频流或拍照模式下，会继续识别。 
        4.     // MLGcrCaptureResult.CAPTURE_STOP：表示返回的结果满足要求，停止识别。 
        5.     @Override

        8.         if (cardResult != null) {// 判断是否有结果返回。

        12.             }

2. 设置识别参数，调用识别器capture接口进行识别，识别结果会通过步骤1的回调函数返回。支持视频流、拍照、相册读取图片三种识别方式。

  * 视频流识别



      
      1. private void startCaptureActivity(Object object, MLGcrCapture.Callback callback) { 
        2.     // 创建通用卡证识别配置器。 
        3.     MLGcrCaptureConfig cardConfig = new MLGcrCaptureConfig.Factory().create(); 
        4.     // 创建通用卡证识别界面配置器。 
        5.     MLGcrCaptureUIConfig uiConfig = new MLGcrCaptureUIConfig.Factory()        
        6.         // 设置扫描框颜色。 
        7.         .setScanBoxCornerColor(Color.GREEN) 
        8.         // 设置扫描框中的提示文字，建议少于30个字符。 
        9.         .setTipText("Recognizing, align edges") 
        10.         // 设置识别界面横竖屏，支持三种模式： 
        11.         // MLGcrCaptureUIConfig.ORIENTATION_AUTO:自动模式，由物理感应器决定显示方向。 
        12.         // MLGcrCaptureUIConfig.ORIENTATION_LANDSCAPE:横屏模式。 
        13.         // MLGcrCaptureUIConfig.ORIENTATION_PORTRAIT:竖屏模式。 
        14.         .setOrientation(MLGcrCaptureUIConfig.ORIENTATION_AUTO) 
        15.         .create(); 
        16.     // 方式一：根据自定义的卡证识别界面配置器，创建通用卡证识别处理器。 
        17.     MLGcrCapture ocrManager = MLGcrCaptureFactory.getInstance().getGcrCapture(cardConfig, uiConfig); 
        18.     // 方式二：使用默认界面，创建通用卡证识别处理器。 
        19.     MLGcrCapture ocrManager = MLGcrCaptureFactory.getInstance().getGcrCapture(cardConfig); 
        20.     // 绑定通用卡证识别处理器和处理结果回调函数。 
        21.     ocrManager.capturePreview(this, object, callback); 
        22. }

  * 相册图片识别



      
      1. private void startLocalImageActivity(Bitmap bitmap, Object object, MLGcrCapture.Callback callback) { 
        2.     // 创建通用卡证识别配置器。 
        3.     MLGcrCaptureConfig config = new MLGcrCaptureConfig.Factory().create(); 
        4.     MLGcrCapture ocrManager = MLGcrCaptureFactory.getInstance().getGcrCapture(config); 
        5.     // bitmap 为需要识别的Bitmap类型卡证图像，支持的图片格式包括：jpg/jpeg/png/bmp。 
        6.     ocrManager.captureImage(bitmap, object, callback); 
        7. }
    
    

3. 在检测按钮的回调中，调用步骤2中定义的方法，实现通用卡证识别。
      
      1. @Override 
        2. public void onClick(View v) { 
        3.     switch (v.getId()) { 
        4.         // 相册图片检测按钮。 
        5.         case R.id.detect_picture: 
        6.             this.startLocalImageActivity(cardImage, null, callback); 
        7.             break; 
        8.         // 视频流检测按钮。 
        9.         case R.id.detect_video: 
        10.             this.startCaptureActivity(null, callback); 
        11.             break; 
        12.         // 拍照检测按钮。

        15.             break; 
        16.         default: 
        17.             break; 
        18.         }
