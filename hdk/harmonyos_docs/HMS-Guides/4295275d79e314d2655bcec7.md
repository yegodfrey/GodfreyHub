# 功能简介

用户的生命周期，是指用户从首次打开应用到离开应用的整个过程。用户生命周期一般分为：新手期、成长期、成熟期、沉默期、流失期。

运营人员可以通过用户生命周期分析，对用户分层，进行精细化运营，以提升用户活跃、留存，降低用户流失。

# 功能详述

1. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，单击“我的项目”图标。

2.选择需要查看分析数据的应用。

3\. 单击“分析 > 用户生命周期”进入报告页面。
