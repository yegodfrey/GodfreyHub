# SDK 收集数据​

Health Kit 不会主动收集处理用户的个人数据，所有的处理都是基于三方应用的调用。在用户授权后，三方应用可以在 Health Kit 读写对应权限的数据，并同步数据到 Health Kit 云。Health Kit 支持的数据类型和授权列表如下，Scope 和权限的对应关系请参考 API 参考中的 [Scopes](https://developer.huawei.com/consumer/cn/doc/HMS-References/scopes-0000001050092713) 类。
