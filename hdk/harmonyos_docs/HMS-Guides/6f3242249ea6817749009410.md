# 1.功能说明

Game kit提供Api接口，帮助开发者快速实现游戏App与系统的交互。开发者通过Game Kit，可以完成向系统发送游戏数据以及从系统获取设备状态信息两大动作。

# 2.场景介绍

Game Kit服务于游戏场景优化。其特点是可以通过游戏场景和运行状态的不同，使用不同策略调度系统资源以达到更精细化的优化效果。

## 3.2 开发步骤

### 3.2.1 获取能力对象
    
    
    复制
      
        1. private GameManager mGameKit = GameManager.getGameManager();
    
    

### 3.2.2 向设备注册应用

有以下两种方式向设备注册应用。

需要通过回调监听设备信息变化：
    
    
    复制
      
        1. private GameCallBack gameSdkCallBack = new GameCallBack() { 
        2.  @Override 
        3.  public void onPhoneInfoUpdated(String info) { 
        4.      Log.i(TAG, "onPhoneInfoUpdated: " + info); 
        5.      } 
        6.  }; 
        7. boolean isSuccess = mGameKit.registerGame(packageName, gameSdkCallBack);
    
    

不需要通过回调监听设备信息变化：
    
    
    复制
      
        1. boolean isSuccess = mGameKit.registerGame(packageName, null);
    
    

### 3.2.3 向设备发送消息
    
    
    复制
      
        1. JSONObject jsonObject = new JSONObject();
        2. try {
        3.     jsonObject.put(“MessageType”, 3);
        4.     jsonObject.put(“SceneID”, 1);
        5.     jsonObject.put(“Description”, “Game Start”);
        6.     jsonObject.put(“ImportantLevel”, 2);
        7.     jsonObject.put(“Status”, 1);
        8.     jsonObject.put(“RecommendFps”, 60);

        10.     String message = jsonObject.toString();
        11.     mGameKit.updateGameAppInfo(message);

        13.     // Process exception

### 3.2.4 主动获取设备信息
    
    
    复制
      
        1. String phoneInfo = mGameKit.getPhoneInfo();
    
    

### 3.2.5 通过回调监听设备信息变化

请参考第3.2.2节，需要通过回调监听设备信息变化部分。

如果需要更换回调接口，可调用registerGame()接口。更换回调接口后，之前注册的监听接口不再生效。

# 5.Game Kit SDK 数据安全说明

## **5.1  ****SDK工作方式**

移动端SDK需要在应用编译打包时，被加载在您的应用当中。

SDK会随着客户应用的调用而启动，不会自动启动，也不会在后台做任何额外动作。

## **5.2 SDK****权限说明**

SDK运行时，不会调用系统权限。

## **5.3  SDK收集数据**

SDK会使用客户应用的appid、包名和接口调用情况，用于牵引Game Kit服务能力的持续优化和改进。

SDK不会收集用户数据。

## **5.4  ****SDK 数据安全保护**

SDK不会收集用户个人数据。
