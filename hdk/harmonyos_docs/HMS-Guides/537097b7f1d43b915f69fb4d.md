# 1 标记

用户可以在地图的指定位置添加标记以标识位置、商家、建筑等，并可以通过信息窗口展示详细信息。

1. 添加标记

用户可以使用HWMapJsSDK.HWMarker([MarkerOptions](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-marker#markerOptions))构造方法创建一个标记添加到地图上，示例代码如下：
      
      1. var map;
        2. var mMarker;
        3. function initMap() { 
        4.     var mapOptions = {}; 
        5.     mapOptions.center = {lat: 48.856613, lng: 2.352222}; 
        6.     mapOptions.zoom = 8; 
        7.     map = new HWMapJsSDK.HWMap(document.getElementById('map'), mapOptions); 
        8.     mMarker = new HWMapJsSDK.HWMarker({ 
        9.         map: map, 
        10.         position: {lat: 48.85, lng: 2.35}, 
        11.         label: 'A', 
        12.         icon: { 
        13.             opacity: 0.5 
        14.         } 
        15.     }); 
        16. }
    
    

以上代码在经纬度为（48.85, 2.35）的位置上添加了一个label为“A”图标透明度为0.5的标记，效果图如下：

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200304173321.38605772314489709944309925725800:50510518030848:2800:213D3ED4AEE0B2AE4D917AB34794D83FDE666C046A92CFDAB95FB74D8C1D546E.png?needInitFileName=true)

图1：标记

关于MarkOptions支持的自定义属性见[MarkerOptions](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-marker#markerOptions)。

2\. 自定义标记

用户可以通过icon设置自定义图标，代码如下：
      
      1. mMarker = new HWMapJsSDK.HWMarker({ 
        2.     map : map, 
        3.     position: {lat: 48.75, lng: 2.33}, 
        4.     //icon可以是本地资源图片路径或者是图片的URL
        5.     icon: 'location-marker.png' 
        6. });
    
    

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200304173751.13879442075377161611270257516869:50510518030848:2800:D8A1C5EC16814EECF4B36FB90BC519CB36A05D1EF743906C30A539E954E633E1.png?needInitFileName=true)

图2：自定义标记

3\. 删除标记

要从地图中删除标记，请调用setMap()方法并将null作为传递参数。
      
      1. mMarker.setMap(null);
    
    

请注意，上述方法不会删除标记，它只是把标记从地图上移除。如果您希望删除标记，则应将其从地图上删除，然后将标记本身置为null即可。
      
      1. mMarker.setMap(null); 
        2. mMarker = null;
    
    

4\. 修改标记

用户可以通过[HWMarker](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-marker)对象的方法对属性进行修改，以下代码示例修改Marker的position：
      
      1. <tr> 
        2.     <td>Marker Lat:</td> 
        3.     <td><input id="markerLatInput" type="text" value="48"/></td> 
        4. </tr> 
        5. <tr> 
        6.     <td>Marker Lng:</td> 
        7.     <td><input id="markerLngInput" type="text" value="1.5"/></td> 
        8. </tr>
    
    
      
      1. var lat = Number(document.getElementById("markerLatInput").value); 
        2. var lng = Number(document.getElementById("markerLngInput").value); 
        3. mMarker.setPosition({lat: lat, lng: lng});
    
    

标记的以下属性支持自定义：

**属性**| **含义**  
---|---  
setIcon(icon)| 设置标记的图标。  
setLabel(label)| 设置标记的标签。  
setPosition(position)| 设置在标记位置。  
  
5\. 标记事件

[HWMarker](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-marker)支持多种事件回调，详细见下表。

**事件**| **含义**  
---|---  
click| 鼠标单击。  
dbclick| 鼠标双击。  
icon_changed| icon改变。  
mousedown| 鼠标按下。  
mouseup| 鼠标放开。  
position_changed| 位置改变。  
  
以下代码示例为鼠标单击事件监听，要在地图上设置此监听器，请调用[HWMarker](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-marker)对象的addListener('click', callback)方法：
      
      1. mMarker.addListener('click', () => { 
        2.     alert("On Marker Click!"); 
        3. });
    
    

# 2 标记聚合

华为地图SDK支持聚合标记功能，该功能可以有效地管理在地图不同缩放级别情况下的多个标记。当用户以高缩放级别查看地图时，各个标记会显示在地图上；当用户缩小时，标记会聚集成集群，从而使标记的呈现更有序。

1\. 添加聚合标记
      
      1. var map;
        2. var markers = []; 
        3. var markerCluster;
        4. var locations =  [ 
        5.     {lat: 51.5145160, lng: -0.1270060}, 
        6.     { lat : 51.5064490, lng : -0.1244260 }, 
        7.     { lat : 51.5097080, lng : -0.1200450 }, 
        8.     { lat : 51.5090680, lng : -0.1421420 }, 
        9.     { lat : 51.4976080, lng : -0.1456320 }, 
        10.     ··· 
        11.     { lat : 51.5061590, lng : -0.140280 }, 
        12.     { lat : 51.5047420, lng : -0.1470490 }, 
        13.     { lat : 51.5126760, lng : -0.1189760 }, 
        14.     { lat : 51.5108480, lng : -0.1208480 } 
        15. ]; 
        16. function initMap() { 
        17.     var mapOptions = {}; 
        18.     mapOptions.center = {lat: 48.856613, lng: 2.352222}; 
        19.     mapOptions.zoom = 3; 
        20.     map = new HWMapJsSDK.HWMap(document.getElementById('map'), mapOptions); 
        21.     generateMarkers(locations); 
        22.     markerCluster = new HWMapJsSDK.HWMarkerCluster(map, markers); 
        23. } 
        24. function generateMarkers(locations) { 
        25.     for (let i = 0; i < locations.length; i++) { 
        26.         var opts = { 
        27.             position: locations[i] 
        28.         }; 
        29.         markers.push(new HWMapJsSDK.HWMarker(opts)); 
        30.     } 
        31. }

# 3 信息窗

华为地图SDK支持在地图上显示信息窗。信息窗分为两种，一种是单独显示文本或图像；另一种是基于Marker在标记上方的弹出窗口中显示文本或图像，为标记提供详细信息。

1\. 创建信息窗
      
      1. var infoWindow;
        2. function initMap() { 
        3.     var mapOptions = {}; 
        4.     mapOptions.center = {lat: 48.856613, lng: 2.352222}; 
        5.     mapOptions.zoom = 8; 
        6.     var map = new HWMapJsSDK.HWMap(document.getElementById('map'), mapOptions); 
        7.     infoWindow = new HWMapJsSDK.HWInfoWindow({ 
        8.         map, 
        9.         position: {lat: 48.856613, lng: 2.352222}, 
        10.         content: 'This is to show mouse event of another marker', 
        11.         offset: [0, -40], 
        12.     }); 
        13. }
    
    

2\. 显示/关闭信息窗
      
      1. //显示信息窗 
        2. function openInfoWindowBtnClick() { 
        3.     infoWindow.open(); 
        4. } 
        5. //关闭信息窗 
        6. function closeInfoWindowBtnClick() { 
        7.     infoWindow.close(); 
        8. }

# 4 覆盖物

地图覆盖物是固定在地图上的图片。

1\. 添加覆盖物

GroundOverlay的构造函数将图像的URL和图像的[LatLngBounds](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description#latLngBounds)以及[GroundOverlayOptions](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-ground-overlay#groundOverlayOptions)作为参数，在给定的限制范围内将图像呈现在地图上。示例代码如下：.
      
      1. var map;
        2. var mGroundOverlay;
        3. function initMap() { 
        4.     var mapOptions = {}; 
        5.     mapOptions.center = {lat: 48.856613, lng: 2.352222}; 
        6.     mapOptions.zoom = 8; 
        7.     map = new HWMapJsSDK.HWMap(document.getElementById('map'), mapOptions); 
        8.     var imageBounds = { 
        9.         north: 49, 
        10.         south: 48.5, 
        11.         east: 2.5, 
        12.         west: 1.5, 
        13.     }; 
        14.     mGroundOverlay = new HWMapJsSDK.HWGroundOverlay(
        15.         //本地资源图片路径或者是图片的URL
        16.         'huawei_logo.png', 
        17.         imageBounds, 
        18.         { 
        19.             map: map, 
        20.             opacity: 1
        21.         } 
        22.     ); 
        23. }
    
    

以上代码添加覆盖物的效果图如下：

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200305082732.04963069649167707347794390624920:50510518030848:2800:EA4630211833FFF5FB1D84CB01D11E6502497A1A1BF9AF539CE8CD9C15FBE702.png?needInitFileName=true)

图8：覆盖物

2\. 删除覆盖物

要从地图中删除覆盖物，请调用setMap()方法并将null作为传递参数。

请注意，上述方法不会删除覆盖物，它只是把覆盖物从地图上移除。如果用户希望删除覆盖物，则应将其从地图上删除，然后将覆盖物本身置为null即可。
      
      1. mGroundOverlay.setMap(null);

3\. 修改覆盖物

用户可以通过[HWGroundOverlay](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-ground-overlay)对象的方法对属性进行修改，以下代码示例修改GroundOverlay的url：

        2.     <td>URL:</td> 
        3.     <td><input id="urlInput" type="text" 
        4.                //value可以是本地资源图片路径或者是图片的URL
        5.                value="huawei_logo.png"/> 
        6.     </td> 
        7. </tr>
    
    
      
      1. var url = document.getElementById("urlInput").value; 
        2. mGroundOverlay.setUrl(url);

**属性**| **含义**  
---|---  
setBounds(bounds)| 设置限制范围。

setMap(map)| 设置地图实例。  
  
# 5 形状

华为地图SDK支持在地图上绘制形状，主要包括三种形状：折线Polyline 、圆Circle、多边形Polygon。

## 5.1 折线

Polyline是由多个经纬度点连接而成的折线。

1\. 添加折线

以下代码将创建一条折线到地图上：
      
      1. var map;
        2. var polyline;
        3. function initMap() { 
        4.     var mapOptions = {}; 
        5.     mapOptions.center = {lat: 48.856613, lng: 2.352222}; 
        6.     mapOptions.zoom = 8; 
        7.     map = new HWMapJsSDK.HWMap(document.getElementById('map'), mapOptions); 
        8.     polyline = new HWMapJsSDK.HWPolyline({ 
        9.         map: map, 
        10.         path: [ 
        11.             {lat: 49, lng: 2}, 
        12.             {lat: 48.5, lng: 2.5}, 
        13.             {lat: 48, lng: 1.5} 
        14.         ], 
        15.         strokeColor: '#112233', 
        16.         strokeWeight: 5, 
        17.     }); 
        18. }
    
    

以上代码添加折线的效果图如下：

## 5.2 多边形

Polygon是由多个经纬度点连接而成的多边形，与Polyline不同的是，它是内部填充的封闭形状。

1\. 添加多边形

      1. var map;
        2. var polygon;
        3. function initMap() {

        8.     polygon = new HWMapJsSDK.HWPolygon({ 
        9.         map : map, 
        10.         paths: [ 
        11.             [ 
        12.                 {lat: 49, lng: 2}, 
        13.                 {lat: 48.5, lng: 2.5}, 
        14.                 {lat: 48, lng: 1.5} 
        15.             ], 
        16.         ], 
        17.         fillColor: '#00ff41', 
        18.         strokeColor: '#ff0000', 
        19.         strokeWeight: 5, 
        20.     }); 
        21. }
