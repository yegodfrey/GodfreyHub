AppTouch ID是基于AppTouch平台开放的帐号服务。AppTouch是指由华为提供技术支持的、由第三方（例如电信运营商）运营的、向最终用户展示、分发或推广应用和内容等产品的平台。

# 1\. AppTouch ID登录（Authorization Code）

## 1.1 场景介绍

AppTouch ID登录（Authorization Code）是指基于[OAuth2.0协议标准](https://oauth.net/2/)和[OpenID Connect协议](https://openid.net/connect/)，第三方应用可以获取AppTouch ID用户的临时授权票据(Authorization Code)，用于用户使用AppTouch ID安全登录第三方应用。Authorization Code模式仅适用于有自己服务器的应用。

本章节主要介绍使用Authorization Code模式登录AppTouch ID的开发步骤。

注意：

AppTouch ID未发布，待发布后此接口可用。

## 1.2 业务流程

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200416140617.37419748486915711314617302516403:50510522083735:2800:9CA7F87D3704A204E8384AD49ED9177397E6490A1116628453C0E4D06F3DDFA9.png?needInitFileName=true)

整体流程：

1、用户选择AppTouch ID登录方式登录应用。

2、应用向Account SDK发起登录请求。

3、AppTouch ID拉起用户登录授权界面，界面上会根据登录请求中携带的授权域(scope)信息， 显式告知用户需要授权的内容。

4、用户确认允许授权后，AppTouch ID返回Authorization Code信息。

5、应用通过Authorization Code换取Access Token，Refresh Token，ID Token信息。

6、应用服务端可以根据Access Token可以从帐号服务器获取用户的openId。

7、如果Access Token或ID Token过期，可以使用Refresh Token获取新的Access Token，ID Token信息。

# 2\. AppTouch ID登录（ID Token）

## 2.1 场景介绍

AppTouch ID登录(ID Token)是指基于[OAuth2.0协议标准](https://oauth.net/2/)和[OpenID Connect协议](https://openid.net/connect/)，第三方应用可以获取AppTouch ID用户身份认证信息(ID Token)，用于用户使用AppTouch ID安全登录第三方应用。ID Token模式同时适合单机应用和有自己服务器的应用。开发者可根据实际情况选择其中一种模式实现。

本章节主要介绍使用ID Token模式登录AppTouch ID的开发步骤。

注意：

AppTouch ID未发布，待发布后此接口可用。

## **2.3.2验证ID Token有效性**

●方式1：本地验证

1、从<https://oauth-login.cloud.huawei.com/.well-known/openid-configuration>中的jwks_uri字段获取公钥URI，访问公钥URI获取公钥。  
公钥每天更新一次，应用服务器可以缓存公钥的值。

2、验证签名。ID Token是JWT格式的，验证ID Token的签名可以采用通用的JWT库，例如[jwt.io](https://jwt.io/)。

3、验证ID Token中iss字段的值是否等于“https://accounts.huawei.com”。

4、验证ID Token中aud字段的值等于应用的client_id。

5、验证ID Token中的过期时间（exp字段）是否已过期。

6、如果以上验证均通过，则表示用户ID Token验证通过，应用可使用登录结果中的用户信息。

●方式2：服务器验证

应用调用[ID Token合法性验证接口](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-verify-id-token)向AppTouch ID服务器发送ID Token验证请求，AppTouch ID服务器向应用直接返回验证结果。

**注意** ：

由于调用“[ID Token合法性验证接口](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-verify-id-token)”会带来耗时，并且受网络状况的影响，所以服务器验证方式只能用于调试目的，在商用环境需要采用本地验证的方式。

# 3\. 静默登录

## 3.1 场景介绍

静默登录是指用户在退出应用时如果用户已经进行过登录授权，当用户再次返回应用界面时，应用不希望拉起任何登录授权界面，在后台直接通过静默方式获取用户登录信息。

注意：

AppTouch ID未发布，待发布后此接口可用。

## 3.2 业务流程

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200416161334.30115587286877923228386369439070:50510522083735:2800:A6B3B68EE86FC80F6565827C435100243A199ABF0114526DE0F6B7CFBE941F9A.png?needInitFileName=true)  


1、用户进行了触发静默登录的场景，根据应用实际场景由开发者自行设定。

2、应用调用[AccountAuthParamsHelper](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-accountauthparamshelper)的默认构造方法配置鉴权参数。

3、Account SDK向应用返回包含授权参数的[AccountAuthParams](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-accountauthparams)对象。

4、应用调用[AccountAuthManager](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-accountauthmanager)的[getService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-accountauthmanager#getService2)方法初始化[AccountAuthService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-accountauthservice)实例。

5、Account SDK向应用返回[AccountAuthService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-accountauthservice)对象。

6、应用调用[AccountAuthService.silentSignIn](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-accountauthservice#silentSignIn)方法向HMS Core SDK发起静默登录请求。

7、Account SDK检查用户是否符合静默登录的授权，并向应用返回授权结果。

8、应用根据授权结果自行确定后续处理。

## 3.3 开发步骤

静默登录功能涉及应用的关键开发步骤如下：

1、调用[AccountAuthParamsHelper](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-accountauthparamshelper)的默认构造方法配置授权参数。
      
      1. AccountAuthParams authParams = new AccountAuthParamsHelper(AccountAuthParams.DEFAULT_AUTH_REQUEST_PARAM).createParams();
    
    

2、调用[AccountAuthManager](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-accountauthmanager)的[getService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-accountauthmanager#getService2)方法初始化[AccountAuthService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-accountauthservice)对象。
      
      1. // int appTouchFlag取值1、华为帐号；2、自适应（如果是从AppTouch下载的应用，登录运营商帐号；如果从AppGallery下载，登录华为帐号）
        2. AccountAuthService service = AccountAuthManager.getService(MainActivity.this, authParams, appTouchFlag)  
         
    
    

3、调用[AccountAuthService.silentSignIn](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-accountauthservice#silentSignIn)方法发起静默登录请求。
      
      1. Task<AuthAccount> task = service.silentSignIn();
    
    

4、处理授权结果。

如果授权成功，可获取用户的帐号信息，允许用户登录。

应用可根据authAccount.getAccountFlag的结果判断当前登录帐号的渠道类型。（0代表华为帐号，1代表运营商帐号。）
      
      1. task.addOnSuccessListener(new OnSuccessListener<AuthAccount>() {
        2.   @Override 
        3.   public void onSuccess(AuthAccount authAccount) {   
        4.     //获取AppTouch ID信息   
        5.     Log.i(TAG, "displayName:" + authAccount.getDisplayName());
        6.     //获取帐号类型，0表示华为帐号、1表示AppTouch ID
        7.      Log.i(TAG, "accountFlag:" + authAccount.getAccountFlag());
        8.   }
        9. });
    
    

如果授权失败，可能是用户之前未进行过登录授权，应用可自行确认是否需要调用[AccountAuthService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-accountauthservice)的[getSignInIntent](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-accountauthservice#getSignInIntent)方法显式拉起登录授权页面。
      
      1. task.addOnFailureListener(new OnFailureListener() {
        2.   @Override
        3.   public void onFailure(Exception e) {   
        4.     //登录失败，您可以尝试使用getSignInIntent()方法显式登录
        5.     if (e instanceof ApiException) {
        6.        ApiException apiException = (ApiException)e;
        7.        Log.i(TAG, "sign failed status:" + apiException.getStatusCode());
        8.     }
        9.   }
        10.  });
    
    

# 4\. 登出AppTouch ID

## 4.1 场景介绍

AppTouch ID登出是指应用向用户提供入口可以退出当前AppTouch ID登录，用户退出登录后应用需要通知Account SDK清除本地当前已经登录的AppTouch ID信息。

注意：

AppTouch ID未发布，待发布后此接口可用。

## 4.2 业务流程

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200420145749.02118562544176669906593668701941:50510522083735:2800:580A498ABAF11DE0036782591A5D7F997812D67F2EE0E61D00D307D6B18161CB.png?needInitFileName=true)  


1、用户在已经登录应用，在应用中执行登出操作。

2、应用调用[AccountAuthService.signOut](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-accountauthservice#signOut)方法向Account SDK请求退出AppTouch ID。

3、Account SDK清理AppTouch ID登录信息后向应用返回登出结果。

## 4.3 开发步骤

AppTouch ID登出功能涉及应用的关键开发步骤如下：

1、使用AppTouch ID登录授权时创建的[AccountAuthService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-accountauthservice)实例调用signOut接口。
      
      1. Task<Void> signOutTask = service.signOut();
    
    

2、signOut完成后的处理。
      
      1. signOutTask.addOnCompleteListener(new OnCompleteListener<Void>() {
        2.   @Override  
        3.   public void onComplete(Task<Void> task) {   
        4.     //完成登出后的处理    
        5.     Log.i(TAG, "signOut complete");
        6.   }
        7. });
    
    

# 5\. AppTouch ID取消授权

## 5.1 场景介绍

取消AppTouch ID授权是用户在应用内取消其在登录时的AppTouch ID授权。取消授权后，当用户再次尝试登录时，应用将要求用户重新进行授权并确认同意所请求的范围。

注意：

AppTouch ID未发布，待发布后此接口可用。

## 5.2 业务流程

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200416163558.36255653867399809372756122482644:50510522083735:2800:1F747F2280DFB85AEA83C00C391BA0BFA8F9986A7CA3521D280A4F6C39D56A6C.png?needInitFileName=true)

1、用户在已经登录应用并授权，在应用中执行取消授权。

2、应用调用[AccountAuthService.cancelAuthorization](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-accountauthservice#cancelAuthorization)方法向Account SDK请求取消授权。

3、Account SDK清理AppTouch ID授权信息后向应用返回取消结果。

## 5.3 开发步骤

AppTouch ID注销授权功能涉及应用的关键开发步骤如下：

1、应用设置取消授权入口，此部分由应用自行开发。

2、应用调用[AccountAuthService.cancelAuthorization](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-accountauthservice#cancelAuthorization)方法，并处理返回结果。

        9.       //异常处理

        11.       if (exception instanceof ApiException){     
        12.         int statusCode = ((ApiException) exception).getStatusCode();
        13.         Log.i(TAG, "onFailure: " + statusCode);
        14.       }
        15.     }
        16.   }
        17. })
