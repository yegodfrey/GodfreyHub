# 华为定位服务SDK数据安全说明

**SDK****工作方式**

Location SDK提供移动端SDK。移动端SDK需要在应用打包时，被加载到您的应用中。SDK会随着应用启动而运行在客户进程中。当用户关闭应用时，SDK会随着客户应用关闭而关闭，不会在后台做额外的操作。

**SDK****权限说明**

Location SDK需要使用的权限：

·粗略的位置权限：android.permission.ACCESS_COARSE_LOCATION。

·精确的位置权限：android.permission.ACCESS_FINE_LOCATION。

· Android Q版本中，如果您需要应用程序在后台执行时也具备持续定位能力，需要权限：android.permission.ACCESS_BACKGROUND_LOCATION 。

· 获取网络状态权限：android.permission.ACCESS_NETWORK_STATE。

· 获取WiFi状态权限：android.permission.ACCESS_WIFI_STATE。

**SDK****数据收集**

SDK不会收集个人数据，但会上报API调用结果到华为服务器。

SDK会使用客户应用的appid、包名和接口调用情况，用于牵引Location服务能力的持续优化和改进。

**SDK****数据安全保护**

Location SDK与HMS Core（APK）之间的数据交换基于Binder传输，Android系统本身的安全机制保障了基于Binder传输的数据安全。
