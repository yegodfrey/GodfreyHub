# 操作步骤  


1.如果没有华为开发者联盟帐号，需要先注册帐号并通过实名认证。详细操作请参见[帐号注册认证](https://developer.huawei.com/consumer/cn/devservice/doc/20300)。

2.参见[创建项目](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-get-started-ios#h1-1587476272328)和在[项目中添加应用](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-get-started-ios#h1-1586419251829)完成应用的创建。

3. 开通高级分析服务：

  * 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，单击“我的项目”图标。

  * 选择需要查看分析数据的应用。

  * 单击“华为分析”下的任意菜单可开通分析服务。

  * 进入“项目接入设置”页面，设置数据存储位置、时区、货币、设置用户数据留存时间、设置自然周定义后，单击“完成”，即完成Analytics Kit服务开通。
