# 1\. AppGallery Connect配置

在开始开发应用前，需要在AppGallery Connect中配置相关信息。

## 1.1 注册成为开发者

在开发应用前需要在[华为开发者联盟](https://developer.huawei.com/consumer/cn)网站上注册成为开发者并完成实名认证，具体方法可参考[帐号注册认证](https://developer.huawei.com/consumer/cn/devservice/doc/20300)。

## 1.2 创建应用

参见[创建项目](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-get-started#createproject)和在[项目中添加应用](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-get-started#createapp)完成应用的创建，游戏应用的特殊配置如下：

  * “选择平台”：必须选择“Android”。

  * “支持设备”：选择“手机”。

  * “应用分类”：选择“游戏”。




注意：

联运游戏的应用包名必须以**.HUAWEI** 或**.huawei** 结尾，否则会导致审核不通过。

## 1.3 生成签名证书指纹  


签名证书指纹用于在通过华为HMS SDK访问HMS Core（APK）的能力时，校验应用的真实性。开发者在使用HMS SDK服务前必须将签名证书指纹配置到华为开发者联盟，在配置前需要根据签名证书在本地生成签名证书指纹。

在申请前需要满足以下2个条件：

  * 已创建应用程序的签名文件，签名证书创建属于通用技术，此处不详细描述。

  * 当前开发的PC已经安装JDK。




操作步骤如下：

1、打开命令行工具（使用CMD命令），执行cd命令进入keytool.exe所在的目录（图中样例为PC上java程序安装在C盘的Program Files (x86)目录）。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191127160217.91750238228687932611910771768141:50510615072316:2800:9017F77194B6EAE0502394DA051C2A55EDC5A47339443D7410683315CFFD7C81.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

2、执行命令**keytool -list -v -keystore**  <keystore-file>，按命令行提示进行操作。  
<keystore-file>为应用签名文件的完整路径。  
例如：  

      
      1. C:\Program Files (x86)\Java\jdk1.7.0_25\bin>keytool -list -v -keystore E:\HMS_SDK_2.5.1.300\Sample\HMSSdkSample_2.5.1.300_AS\HmsSample\android.keystore
    
    

3、根据结果获取对应的SHA256指纹。

## 1.4 配置签名证书指纹

1、登录[ AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) 网站，选择“我的应用”。

2、点击需要配置的应用。

3、选择**“开发”** 页签，在**“项目设置”** 页面的“应用”区域，将“SHA256证书指纹”配置为生成签名证书指纹中生成的SHA256指纹。

## 1.5 打开相关服务

  * 如果应用有帐号体系，必须打开帐号服务。
  * 联运应用和游戏必须打开支付服务。

  * 联运应用和游戏推荐打开分析服务。  


  * 联运游戏必须打开游戏服务。  





具体操作步骤请参见[打开服务开关](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-enable_service#enable-service)。如果首次开通支付服务，需要签署支付协议，操作方法请参见[配置支付服务参数](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-enable_service#set-IAP-param)。

联运服务如果打开了分析服务，还需启动华为高级分析服务，参见[启动华为高级分析服务](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-enable_service#start_HA)。

## 1.6 配置成就  


成就是激励玩家深入发掘游戏并提高其游戏水平的一种富有趣味的途径。如果游戏中设置了成就系统，则开发前需要在AppGallery Connect中配置成就。

  * 新增成就：如果需要新增成就，请参考[新增成就](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-add_achievement)。

  * 测试成就：成就创建后为“可测试”状态，开发者可以通过测试帐号测试成就。

  * 发布成就：待成就测试完成，应用正式上架后，可以发布成就，具体操作请参见[发布成就](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-release_achievement)。应用测试阶段建议不要发布成就。

  * 编辑成就：在成就未发布或正式发布后，均可以编辑成就，修改成就的相关信息，编辑成就操作请参考[编辑成就](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-edit_achievement)。

  * 重置成就进度：尚未发布的成就可以重置成就进度，已经发布的成就无法重置，重置进度后测试帐号的成就数据将被重置，具体操作请参见[重置成就进度](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-reset_achievement)。

  * 删除成就：尚未发布的成就可以删除，已经发布的成就无法删除，具体操作参见[删除成就](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-delete_achievement)。




## 1.7 配置事件  


事件上报为开发者提供了收集玩家在游戏过程中产生的特定数据，上报并存储至华为游戏服务器，随后在AppGallery Connect上进行归纳分析的能力。如果游戏中设置了事件系统，则开发前需要在AppGallery Connect中配置事件。

  * 新增事件：如果需要新增事件，参见[新增事件](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-add_event)。

  * 编辑事件：事件未发布或正式发布后，均可以编辑事件，修改事件相关信息，参见[编辑事件](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-edit_event)。

  * 发布事件：待事件测试完成，应用正式上架后，可以发布事件，参见[发布事件](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-release_event)。

  * 删除事件：尚未发布的事件可以删除，已经发布的事件无法删除，参见[删除事件](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-delete_event)。




## 1.8 配置订阅回调地址

用户购买订阅型商品后，订阅商品发生关键事件时（例如第一次订阅成功、自动续期成功、取消订阅），华为支付服务器可通过提前配置的订阅回调地址向开发者服务器发送订阅商品的关键事件通知，配置的方法参见[配置支付服务参数](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-enable_service#set-IAP-param)。

## 1.9 配置商品信息

如果应用面向全球发布，建议在AppGallery Connect中提前录入商品信息，这样在调用支付接口时即可直接传入商品ID，无需自行管理商品价格。  


  * 如果新增非订阅类商品，请参见[非订阅类商品](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-create_product#non-subscribed)。  


  * 如果新增订阅类商品，请参见[订阅类商品](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-create_product#subscribed)。  


  * 如果为订阅类商品设置促销，请参见[设置促销价格](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-modify_product#set-promotion-price)。




在开发测试阶段，可以通过沙盒测试帐号来测试商品支付，测试帐号处于测试时间段内发起商品购买，华为支付服务器会检测到该用户为测试用户，将跳过实际支付环节，直接支付成功。

## 1.10 配置商品营销信息

如果应用需要支持直接在应用市场或游戏中心应用详情页展示商品并支持购买，则需要参见[商品营销管理](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-product_mkt)配置DeepLink方式或商品直购方式的营销。

# 2\. 集成HMS SDK

      b. 在项目列表中找到您的项目，在项目中点击需要集成HMS SDK的应用。

     c. 在“项目设置”页面中，单击“应用”栏下的“agconnect-services.json”下载配置文件。

## 2.2 在Eclipse项目中集成HMS SDK

针对Eclipse开发环境，华为提供了下载HMS SDK包本地集成的方式。在开始开发前，您需要将HMS SDK集成到您的Eclipse开发环境中。

1. 下载HMS Base SDK、Account SDK、IAP SDK和Game Service SDK。

Eclipse SDK下载地址：[下载SDK](https://developer.huawei.com/consumer/cn/doc/development/HMS-Library/game-sdk-download)

如果还需集成华为分析服务，请参见[在Eclipse项目中集成分析服务SDK](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/Eclipse_IDE)。

### 2.2.5 添加当前应用的AppGallery Connect配置文件
