# 1\. 送达率说明

HUAWEI Push Kit 致力于提供安全可靠的消息发送通道，保障消息成功送达。此外，以下非通道因素也直接影响消息的送达情况，主要影响因素有：

●  终端设备是否在线

如果设备离线，Push平台会缓存消息，待用户上线后，再次将消息投递给用户。Push平台只缓存一次用户的消息，如果用户在线后还发不通，Push平台不再缓存。

●  用户手机上集成Push SDK的应用是否被卸载

●  网络状况是否稳定

●  终端手机的安全控制策略

●  不同厂商终端设备对HMS Core（APK）的支持度

●  透传消息送达依赖应用进程是否存在

# 2\. 支持的终端设备

●  华为Android终端设备（设备出厂自带HMS Core（APK））  


天然支持华为推送能力。

●  非华为Android终端设备（设备出厂非自带HMSCore（APK））

要使用华为推送能力依赖HMSCore（APK），需要用户到华为应用市场下载安装该APK，如果不安装则不支持华为推送能力。即使安装了HMSCore（APK），推送能力也会受到系统限制，可能会影响消息推送的到达率。

●  iOS终端设备

支持通过APNs（Apple Push Notification service）向iOS设备发送消息的能力。

# 3\. Push消息的及时性

HUAWEI Push Kit尽可能保障消息及时送达，设备网络条件良好且不拥堵情况下时延在1s内，该时延时间仅指Push通道推送消息的时延。开发者您在AppGallery Connect网站的控制台创建基于token、主题等的推送任务和通过API创建的基于主题的推送任务，Push系统将先进行推送任务的调度，再通过Push通道推送消息。

# 4\. Push消息大小要求

Push消息支持的Android App包名称最大为128个字节，消息内容最大支持为4K字节（不包括token）。

# 5\. 支持的地区

服务全球[240+国家和地区](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/push-support-region)，支持[70+种语言](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/hmssdk_supported_language)。
