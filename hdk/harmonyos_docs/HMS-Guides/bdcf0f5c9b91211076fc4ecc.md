# **Awareness Kit 1.0.4版本（****2020-04-30****）**

最新子版本号：1.0.4.301  


#### 新增特性

  1. 新增获取各情景感知能力的支持状态能力。
  2. Awareness Kit和HMS Core（APK）升级时，可以选择是否出现弹窗。




# **Awareness Kit 1.0.3版本（****2020-03-27****）**

最新子版本号：1.0.3.300  


#### 新增特性

  1. 新增车载蓝牙音响感知能力。




#### 修改特性  


  1. 时间感知能力新增通过用户IP、国家码、当前年份的时间戳获取时间状态功能。

  2. 天气感知能力增加获取指定位置的天气情况功能。

  3. 活动感知能力提升性能和识别精准度。

  4. 位置感知能力优化算法。




# **Awareness Kit 1.0.2版本（****2020-02-27****）**

最新子版本号：1.0.2.304  


#### 新增特性

  1. 新增Beacon感知能力。




#### 修改特性  


  1. 位置感知能力算法优化。




# ****Awareness Kit 1.0.1版本（******2020-01-23******）****

最新子版本号：1.0.1.300

#### **新增特性**

  1. 新增环境光和天气感知能力。




# **Awareness Kit  ****1.0.0版本****（****2020-01-15****）**

最新子版本号：1.0.0.300

#### **新增特性**  


  1. 第一版发布，提供对用户时间、位置、活动状态和耳机状态的感知能力。




# **SDK依赖说明**

  1. 最新版本SDK需要用户手机上安装HMS Core 4.0.2.300及以上版本； 如果用户手机没有安装，您的应用调用HMS Core时，会自动引导用户提示安装。

  2. 本服务的主要特性都可以在大多数华为终端上支持，部分高级特性依赖于EMUI版本。请参考[部分特性对于EMUI的依赖说明](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/emui_version_dependent_features)。




**提示：** 您的应用在华为应用市场上架过程中，如有问题可发送邮件至[HMSCore@huawei.com](mailto:HMSCore@huawei.com)咨询。
