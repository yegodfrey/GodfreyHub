“HmsScan”对象是Scan Kit返回的统一类，包含码在输入图片中的坐标、码的原始数据、码的制式、结构化数据、zoomValue等信息。

调用模式| 返回对象| 包含内容  
---|---|---  
Default View mode| HmsScan| 原始码值getOriginalValue()| 码制式getScanType()| 结构化数据getScanTypeForm()| 码在图片中的位置getBorderRect()|   
  
Customized View mode| HmsScan| 原始码值getOriginalValue()| 码制式getScanType()| 结构化数据getScanTypeForm()| 码在图片中的位置getBorderRect()|   
  
BitMap mode| HmsScan| 原始码值getOriginalValue()| 码制式getScanType()| 结构化数据getScanTypeForm()| 码在图片中的位置getBorderRect()| 焦距调整倍数getZoomValue()（仅相机扫码模式包含该信息，即Photo mode 为False）  
Multiprocessor mode| HmsScan| 原始码值getOriginalValue()| 码制式getScanType()| 结构化数据getScanTypeForm()| 码在图片中的位置getBorderRect()|   
  
  
1\. zoomValue：焦距调整倍数，开发者需要根据此数值调整相机焦距，具体参考[相机扫码模式](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/scan-bitmap4)。

2\. 结构化数据：从使用特定内容格式编码的二维码、条码中提取的有效信息 。Scan Kit当前已支持结构化提取Wi-Fi、EMAIL、PHONE、ISBN、PRODUCT、SMS、TEXT、URL、CONTACT INFO、GEO、CALENDAR EVENT、DRIVER LICENSE 这12种码中的有效信息并返回给开发者，以便于开发者快速构建对应的服务。详细参考[HmsScan](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scan-hms-scan4)。
