# 1\. SDK工作方式

调用HUAWEI Account Kit接口的步骤如下：

1、在开发联盟网站注册并申请AppId；

2、开发者应用集成HUAWEI Account SDK；

3、开发者应用调用HUAWEI Account SDK登录华为帐号界面和授权界面，由用户授权相应的权限列表；

4、开发者应用调用HUAWEI Account SDK，访问相应权限的接口。

# 2\. SDK权限说明

HUAWEI Account SDK需要使用的权限：

  * 获取网络状态权限：android.permission.ACCESS_NETWORK_STATE，用于检测当前的网络连接是否有效。

  * 获取WiFi状态权限：android.permission.ACCESS_WIFI_STATE，用于获取当前WiFi接入的状态以及WLAN热点的信息。




# 3\. SDK数据收集

HUAWEI Account SDK 需要连接网络并收集和处理以下的信息用来标识设备，以便提供定制化的服务：

  * 设备信息，包括操作系统版本、设备机型。

  * 网络信息，包括网络连接状态、接入网络的方式和类型。




# 4\. SDK数据安全保护

数据访问控制

  * 开发者App需经过签名校验，校验通过的App才能成功调用SDK接口；

  * 开发者App需要用户登录并授权数据访问，才能通过SDK接口访问相应的数据。
