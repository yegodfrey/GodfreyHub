    复制
      
        1. implementation 'com.google.code.gson:gson:2.8.5'
    
    

2. 将HmsScan对象转化为Json字符串。
    
    
    复制
      
        1.   public String hmsScanToGson(HmsScan hmsScan) {
        2.       Gson gson = new Gson();
        3.       String hmsScanStr = gson.toJson(hmsScan);
        4.       return  hmsScanStr;
        5.   }
