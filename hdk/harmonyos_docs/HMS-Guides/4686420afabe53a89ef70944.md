# 1\. 场景介绍

游戏基本信息是指游戏应用的相关信息，例如游戏的应用ID、游戏名称、游戏描述、游戏分类等。当开发者需要在游戏中使用游戏应用的信息时，可以从华为游戏服务器获取游戏基本信息。

# 2\. 注意事项  


用户必须打开华为应用市场（10.3及以上版本）中的游戏服务开关才能使用游戏基本信息功能。如果用户没有开启游戏服务开关，当游戏调用游戏基本信息相关接口时HMS SDK会自动拉起华为应用市场的游戏服务开关页面引导用户打开开关，如果用户未打开游戏服务开关，将返回7018错误码，游戏需要主动提示用户到华为应用市场“我的-设置-游戏服务”页面中开启游戏服务开关。

说明：

用户打开游戏服务授权后，建议您在游戏中提供取消游戏服务授权的功能，可调用[GamesClient.cancelGameService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/gamesclient-v4#cancelGameService)方法实现。

# 3\. 初始化GameSummaryClient

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200109211935.11158434908044074834657977707109:50510416012744:2800:5E6ECF1363F0353AD91C368B09A61385436C78C66E1240BD40BF6A0BA4EBA08D.png)

在使用游戏基本信息接口前都需要先调用[Games.getGameSummaryClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/games-v4#getGameSummaryClient)方法获取[GameSummaryClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/gamesummaryclient)实例。
    
    
    复制
      
        1. GameSummaryClient gamesummayClient = Games.getGameSummaryClient(activity, mAuthHuaweiId);
    
    

接口中传入的mAuthHuaweiId为用户登录游戏时获取的[AuthHuaweiId](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-authhuaweiId)对象，如果未登录可以传null。
