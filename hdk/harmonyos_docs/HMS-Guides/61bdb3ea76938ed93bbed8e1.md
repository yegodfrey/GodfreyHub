# 1 概述

门钥匙，即华为钱包为用户提供的一种可以用华为手机模拟实体门禁卡并用手机开门的功能，您可以使用支持门钥匙功能的华为手机，将实体门禁卡信息复制到华为手机芯片中，手机即可当门钥匙使用。

Wallet Kit提供将门禁卡模拟到华为钱包的能力，商户仅需注册开发者联盟应用后再相应位置配置推广服务，开发者联盟会将产品内容上架至华为钱包App内的内容展示位。用户点击后通过手机NFC功能华为钱包可读取实体门禁卡的NFC卡片信息并将其写入手机芯片中，同时华为钱包会模拟商户进行发卡操作，待NFC卡片信息写入完成后华为钱包中将模拟出此种类型的卡片。

# 3 功能实现

## 3.1 卡劵领取

**商户配置推广服务**

商户通过申请开发者联盟应用后可配置相应的推广服务 ，可将产品内容上架至华为钱包App内的内容展示位，合作伙伴可触达华为钱包里的优质流量，以提高商品或品牌的曝光度和知名度。

例：通过申请推广服务，合作伙伴可将内容配置到开发者联盟中，图片素材及目的访问URL地址需由合作伙伴提供，华为运营人员审核后发布。

  1. 创建Wallet Kit推广服务。

![](http://10.116.132.132:8080/idp-edit-service/editor/image/1032914/1_zh-cn_image_0000001050178469.gif)

  2. 选择推广样式。

![](http://10.116.132.176:8080/idp-edit-service/editor/image/1032914/1_zh-cn_image_0000001050176424.gif)

  3. 上传资料。

![](http://10.116.132.132:8080/idp-edit-service/editor/image/1032914/1_zh-cn_image_0000001050418399.gif)

  4. 创建推广服务成功。

![](http://10.116.132.132:8080/idp-edit-service/editor/image/1032914/1_zh-cn_image_0000001050267112.gif)

推广服务可以让华为钱包用户在访问华为钱包会员卡等栏目时浏览到商户配置的推广服务展示位，用户可以点击配置的展示位跳转到商户相对应的推广H5，此H5推广界面可以是比如用户申领会员卡界面或其他推广内容。




**读取NFC****卡片信息**

用户点击推广服务占位图及进入NFC读卡界面，用户需将待写入门禁卡靠近手机后华为钱包将自动进行读取NFC卡片信息操作。

**华为钱包代替商户进行发卡操作**

华为钱包应用将读取的NFC卡片信息和商户配置在开发者联盟的模板信息一起写入芯片中，待NFC卡片信息写入完毕后用户即可进行刷卡操作。
