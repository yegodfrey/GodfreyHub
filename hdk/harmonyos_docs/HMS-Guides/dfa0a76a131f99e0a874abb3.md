# 1 SDK工作方式 

Map SDK 在应用打包时会被加载在您的应用当中，SDK会随着用户应用的启动而启动。当用户关闭应用时，SDK会随着客户应用的关闭而关闭，不会在后台做任何额外动作。

# 2 SDK权限说明

SDK获取用户当前需要使用的权限，其余功能不需要：

1\. 获取网络状态权限：android.permission.ACCESS_NETWORK_STATE，用于检测当前的网络连接是否有效。

2\. 获取WiFi状态权限：android.permission.ACCESS_WIFI_STATE，用于获取当前WiFi接入的状态以及WLAN热点的信息。

# 3 SDK收集数据

SDK会使用开发者应用的appid、包名和接口调用情况，用于牵引Map服务能力的持续优化和改进。

SDK不会收集用户个人数据。

# 4 SDK数据安全保护

SDK不会收集用户个人数据。
