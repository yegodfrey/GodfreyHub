# 公共数据类型

平台提供的标准数据类型，应用程序可以读取和写入这些类型的数据。

注意：com.huawei.continuous.location.boundary_range，com.huawei.instantaneous.location.sample，com.huawei.instantaneous.location.trace 这三种数据类型只能由写入数据的应用程序读取，其他应用程序无法获取其数据内容。

#### 应用场景

  * 客户端：

在创建数据采集器时需要指定对应的健康数据类型，每种数据类型都拥有对应的1个或多个字段，数据采集器构建可参考 [DataCollector](https://developer.huawei.com/consumer/cn/doc/HMS-References/datacollector-0000001050091767) 下的 [setDataType(DataType dataType)](https://developer.huawei.com/consumer/cn/doc/HMS-References/datacollector_builder-0000001050162310) 方法，具体数据类型可参考 [DataType](https://developer.huawei.com/consumer/cn/doc/HMS-References/datatype-0000001050089916)。



  * 服务端：

在创建数据采集器时需要指定对应的健康数据类型，API 接口可参考 [dataCollectors: create](https://developer.huawei.com/consumer/cn/doc/HMS-References/datacollectors_create-0000001050114852)。
