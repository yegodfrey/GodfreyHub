MultiProcessor Mode适用于需要同时扫描多个码的场景。因为MultiProcessor处理效率低于其他三种调用方式，如果您没有上述需求，建议您使用其他三种调用方式。MultiProcessor Mode提供同步和异步两种模式，可以根据实际需求选择一个合适的模式。

# 1\. 同步方式

**业务流程**

使用MultiProcessor Mode同步方式的主要业务流程如下：

1\. 用户打开应用发起扫码请求。  


2\. 校验是否有相机权限和文件读取权限。  


3. 权限验证通过后，初始化“HmsScanAnalyzer”。

4. 将图像信息转换为“MLFrame”。

5. 调用“HmsScanAnalyzer”的“analyseFrame”扫码接口。

6\. 返回扫码结果。

7. 应用封装扫码结果返回给用户。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200221165739.12589264775755145285563175382874:50510316075850:2800:B0A5CA40C23D9A85C59C7DF97F54E1592ABC2F2534FAB291441D09664F63F467.png)

**开发步骤**

1\. （可选）初始化“HmsScanAnalyzerOptions”并设置支持识别的码制式。

   您可以通过如下方式设置可选参数。不需要定制如下参数时，可跳过此步骤。

  * setHmsScanTypes()：设置码制式，默认识别[Scan Kit支持的码制式](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/scan-code-4)，指定扫码特定的码制式，可以以提高扫码速度。



    
    
    复制
      
        1. //“QRCODE_SCAN_TYPE”和“DATAMATRIX_SCAN_TYPE表示只扫描QR和Data Matrix的码
        2. HmsScanAnalyzerOptions options = new HmsScanAnalyzerOptions.Creator().setHmsScanTypes(HmsScan.QRCODE_SCAN_TYPE, HmsScan.DATAMATRIX_SCAN_TYPE).create();
    
    

2\. 初始化“HmsScanAnalyzer”对象。如果您没有指定只扫描特定的码制式，此处的“options”可以置“null”。
    
    
    复制
      
        1. HmsScanAnalyzer barcodeDetector = new HmsScanAnalyzer(options);
    
    

3\. 将图像信息转换为“MLFrame”, “MLFrame”为ML Kit封装的图像信息类。
    
    
    复制
      
        1. MLFrame image = MLFrame.fromBitmap(bitmap);
    
    

4\. 调用“HmsScanAnalyzer”对象的“analyseFrame”扫码方法发起扫码请求并获取扫码结果。扫码结果为HmsScan数据结构，HmsScan数据结构的信息请参考[码值解析](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/scan-value-4)。
    
    
    复制
      
        1. SparseArray<HmsScan> result = barcodeDetector.analyseFrame(image);
        2. //展示扫码结果
        3. showResult(result);
    
    

# **2\. 异步方式**

**业务流程**

使用MultiProcessor Mode异步方式的主要业务流程如下：

1\. 用户打开应用发起扫码请求。

2\. 校验是否有相机权限和文件读取权限。

3\. 权限验证通过后，初始化“HmsScanAnalyzer”。

4\. 将图像信息转换为“MLFrame”。

5\. 调用“HmsScanAnalyzer”的“analyzInAsyn”异步扫码接口。

6\. HMS SDK回调应用的“onSuccess”或“onFailure”接口传递扫码结果。

7\. 应用封装扫码结果返回给用户。

**开发步骤**

1\. （可选）初始化“HmsScanAnalyzerOptions”对象，并设置支持识别的码制式。

   您可以通过如下方式设置可选参数。不需要定制如下参数时，可跳过此步骤。

  * setHmsScanTypes()：设置码制式，默认识别[Scan Kit支持的码制式](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/scan-code-4)，指定扫码特定的码制式，可以以提高扫码速度。



    
    
    复制
      
        1. //“QRCODE_SCAN_TYPE”和“DATAMATRIX_SCAN_TYPE表示只扫描QR和Data Matrix的码
        2. HmsScanAnalyzerOptions options = new HmsScanAnalyzerOptions.Creator().setHmsScanTypes(HmsScan.QRCODE_SCAN_TYPE,HmsScan.DATAMATRIX_SCAN_TYPE).create();
    
    

2\. 初始化“HmsScanAnalyzer”对象。如果您没有指定只扫描特定的码制式，此处的“options”可以置“null”。
    
    
    复制
      
        1. HmsScanAnalyzer barcodeDetector = new HmsScanAnalyzer(options);
    
    

3\. 将图像信息转换为“MLFrame”，“MLFrame”为ML Kit封装的图像信息类。
    
    
    复制
      
        1. MLFrame image = MLFrame.fromBitmap(bitmap);
    
    

4\. 调用“HmsScanAnalyzer”对象的“analyzInAsyn”扫码方法发起扫码请求，同时订阅扫码结果事件来接收扫码结果。扫码结果为HmsScan数据结构，HmsScan数据结构的信息请参考[码值解析](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/scan-value-4)。
    
    
    复制
      
        1. barcodeDetector.analyzInAsyn(image).addOnSuccessListener(new OnSuccessListener<List<HmsScan>>() {  
        2.     @Override  
        3.     public void onSuccess(List<HmsScan> hmsScans) {  
        4.         if (hmsScans != null && hmsScans.size() > 0) {  
        5.             //展示扫码结果 
        6.             showResult(hmsScans); 
        7.         }  
        8.     }  
        9. }).addOnFailureListener(new OnFailureListener() {  
        10.     @Override  
        11.     public void onFailure(Exception e) {  
        12.         Log.w(TAG, e);  
        13.     }  
        14. });
