# 申请帐号服务

  1. 登录[开发者联盟网站](https://developer.huawei.com/consumer/cn/)，点击进入“管理中心”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515184204.63706263320149381036318995939935:50510515105457:2800:79AFF125AD4E077F9A84A3516A1A38654A91E7EEE0289739B173F231FD90EC5F.png?needInitFileName=true?needInitFileName=true)



  2. 点击“帐号”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515184204.22930321369567725344169826416982:50510515105457:2800:62B72CA3F676D4D897EFEFB68BFB6B47D5790A12C4C021769CAC058C0084D0BA.png?needInitFileName=true?needInitFileName=true)

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515184204.08585479243143098381593386145958:50510515105457:2800:CADC9EB3073E84F170860E3BC7C4E580F14E04CFAADF7015D969491F8F2306BA.png?needInitFileName=true?needInitFileName=true)

如果无“帐号”卡片。请点击右上角“自定义桌面”添加卡片。



  3. 点击“申请帐号服务”，同意协议后，进入产品信息填写页面。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515184204.40869520644076945307798302479428:50510515105457:2800:6E389B265CF2E77C9A374EEC6D157367578602F61246947297DE731D4B6E8EA3.png?needInitFileName=true?needInitFileName=true)

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515184204.81368218159973072063414370110743:50510515105457:2800:558C6E7C89DAC92E8228B158F854BA96DEDE801DB1CF90A217F054B8D74C875B.png?needInitFileName=true?needInitFileName=true)

**项目** | **填写说明**  
---|---  
产品类型 | 
     * 如果是客户端开发，请选择“移动应用”。 
     * 如果是服务器对接，请选“服务器应用”。   
帐号接入方式 （仅中国大陆） | 
     * 如果是移动应用，默认为“SDK接入”。如果同时需要服务端对接，则还需要选择“JS-SDK 接入”。 
     * 如果是服务器应用，默认为“JS-SDK 接入”，无需选择。   
选择产品 | 
     * 如果此前已创建过产品，则从已创建的产品列表里选择产品。 
     * 如果未创建，请点击“创建产品”：![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515184204.79027721897408737278095441065819:50510515105457:2800:B88B0FF0A9AFD7F7D9F412E0025CF04B043063F2749C963E50827BA66F77EC17.png?needInitFileName=true?needInitFileName=true)
     * 创建成功后，生成 APP ID，以及 Secret 信息。用来唯一标识应用。![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515184204.77834461584470796995242457092900:50510515105457:2800:B26528E6CB4A3EC5DC4FE0F529BD43BDD41404F71F9E75964A069B639F8C14E3.png?needInitFileName=true?needInitFileName=true)  
回调地址 | 服务器应用此处必选，由您的技术人员提供。后续可修改。 说明：以 http 或者 https 开头，且是合法的 URL，长度最大255，不能以“/”结尾，，不能包含字符"?"，不能包含 get 参数，支持 IP 地址和端口。必须全路径匹配，有且只有一个回调地址。  
应用访问地址 | 服务器应用此处必选，为三方服务器出口 IP 地址，支持配置多个。由您的技术人员提供。后续可修改。  
应用包名 | 填写[应用包名](https://developer.huawei.com/consumer/cn/doc/HMS-Guides/package_name-0000001050069758)。如“com.huawei.healthdemoanna”，务必与 APK 包名一致，填写后以后不能修改。  
SHA256证书指纹 | 填写[应用证书指纹](https://developer.huawei.com/consumer/cn/doc/HMS-Guides/signing_fingerprint-0000001050071709)。 签名证书指纹用于在通过华为 HMS Core SDK 调用 HMS Core（APK）时，校验应用的真实性。  
  


  4. 点击“提交”，即完成“帐号服务”的开通。
