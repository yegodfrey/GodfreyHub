集成音频文件转写服务SDK示例代码如下：
      
      1. dependencies{
        2.     // 引入音频文件转写服务SDK
        3.     implementation 'com.huawei.hms:ml-computer-voice-aft:2.0.0.300'
        4. }
    
    

# 文件头增加配置

用上述方式集成SDK后，在文件头添加配置。
      
      1. apply plugin: 'com.huawei.agconnect'
    
    

注意：

此项配置需要在如下配置项后添加。
      
      1. apply plugin: 'com.android.application'
