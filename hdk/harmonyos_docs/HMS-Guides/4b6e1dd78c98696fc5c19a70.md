# 1 概览

您可以通过指定的关键字和可选的地理范围，查询诸如旅游景点、企业和学校之类的地点。

# 2 实现步骤

1\. 声明[SearchService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchservice)对象，并通过[SearchServiceFactory](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchservicefactory)创建[SearchService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchservice)实例。

说明：

创建SearchService实例需要传入context和API key参数。context参数建议传入Activity类型，否则需要升级HMS Core（APK）时不会弹出升级界面。API key是开发者在[华为开发者联盟](https://developer.huawei.com/consumer/cn)创建应用时生成的API key，注意需要对API key进行encodeURI编码。

2\. 构建[TextSearchRequest](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-textsearchrequest)对象，它是关键字查询的请求体。其中query是必选参数，其余可选：

  * query：搜索关键字。

  * location：搜索结果偏向的经纬度。

  * radius：搜索半径，单位是米。默认值是50公里，取值范围是1米-50公里。

  * poiType：返回指定POI类型的地点。

  * countryCode：在指定的国家内搜索，采用ISO 3166-1 alpha-2。

  * language：搜索结果的语种，取值范围参考[语种映射](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/hms-site-language)的语种代码。如果不传，使用query字段的语种或者地点的当地语言，query字段的语种优先。

  * politicalView：政治观点参数，采用ISO 3166-1-alpha-2规范的2位国家码。  


  * pageSize：每页返回的记录数。默认值是20，取值范围是1-20。

  * pageIndex：当前页数。默认值是1，取值范围是1-60。




3\. 创建[SearchResultListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchresultlistener)对象，该对象用来监听搜索结果。

4\. 通过第1步创建的[SearchService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchservice)对象调用textSearch()接口，传入第2步创建的[TextSearchRequest](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-textsearchrequest)对象和第3步创建的[SearchResultListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchresultlistener)对象。

5\. 通过第3步创建的[SearchResultListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchresultlistener)对象获取搜索结果[TextSearchResponse](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-textsearchresponse)对象，可从中获[Site](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-site)列表，解析具体的地址信息。

示例代码如下：
      
      1. // 声明SearchService对象
        2. private SearchService searchService;
        3. // 创建SearchService实例
        4. searchService = SearchServiceFactory.create(this, "API key");
        5. // 创建请求体
        6. TextSearchRequest request = new TextSearchRequest();
        7. request.setQuery("Paris");
        8. Coordinate location = new Coordinate(48.893478, 2.334595);
        9. request.setLocation(location);
        10. request.setRadius(1000);
        11. request.setPoiType(LocationType.ADDRESS);
        12. request.setCountryCode("FR");
        13. request.setLanguage("fr");
        14. request.setPageIndex(1);
        15. request.setPageSize(5);
        16. // 创建搜索结果监听器
        17. SearchResultListener<TextSearchResponse> resultListener = new SearchResultListener<TextSearchResponse>() {
        18.     // 正常结果返回
        19.     @Override
        20.     public void onSearchResult(TextSearchResponse results) {
        21.         List<Site> sites = results.getSites();
        22.         if (results == null || results.getTotalCount() <= 0 || sites == null || sites.size() <= 0) {
        23.             return;
        24.         }
        25.         for (Site site : sites) {
        26.             Log.i("TAG", String.format("siteId: '%s', name: %s\r\n", site.getSiteId(), site.getName()));
        27.         }
        28.     }
        29.     // 异常结果返回
        30.     @Override
        31.     public void onSearchError(SearchStatus status) {
        32.         Log.i("TAG", "Error : " + status.getErrorCode() + " " + status.getErrorMessage());
        33.     }
        34. };
        35. // 调用位置搜索接口
        36. searchService.textSearch(request,resultListener);
