此文档针对华为作为最终用户数据处理者，开发者作为最终用户数据控制者的数据处理进行说明，包括：

  * 华为处理的个人数据清单

  * 指导开发者如何帮助最终用户实现对数据的控制




# 华为处理的个人数据清单

**个人数据清单**| **使用目的**| **存留期**  
---|---|---  
AAID(Anonymous  Application ID)| AAID是开放给第三方的匿名设备ID，每个App在同一个设备上会分配不同的AAID，以便针对不同App做统计分析（比如活跃用户数统计），同时做到不同应用App之间的个人数据隔离，保护用户数据隐私安全。| 分析服务会保留统计报告和某些用户级活动数据，不会自动过期。1）分析服务的开发者在分析服务设置中更改保留偏好(开发者开通分析服务时可以选择时间：6个月、9个月、14个月，默认分析服务设置为14个月)，过期后，时间到达后自动删除数据。2）开发者在AGC的控制台上删除产品。  
操作系统设置信息| 提供开发者基于操作系统版本，系统设置语言维度做统计分析。  
应用基本信息| 提供开发者基于应用Pakage Name，App Version，HA SDK Version维度做统计分析。  
设备信息| 提供开发者基于设备制造商，设备类型维度做统计分析。  
用户归属国家| AanlyticsKit基于连接Analytics服务端的网络设备的IP计算使用开发者App的用户归属的国家。  
  
# 指导开发者如何帮助最终用户实现对数据的控制

**如何清除最终用户的数据**

  1. 开发者在分析服务设置中更改保留偏好(开发者开通分析服务时可以选择时间：6个月、9个月、14个月，默认分析服务设置为14个月)，时间到达后自动删除数据。

  2. 开发者在AGC的控制台上删除产品，该产品下所有应用中的高级分析服务数据将被删除。

  3. 开发者可以通过调用**userDeletionRequests** API删除分析服务中的用户数据，单击[这里](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/83409194)查看接口使用的操作指导。




**如何导出最终用户的数据**

开发者可以通过调用**userDataExportRequests** API获取分析服务中的用户数据副本，单击[这里](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/35955031)查看接口使用的操作指导。

**如何打开/关闭华为服务器对开发者上报的最终用户个人数据的接收**

开发者可以通过**setAnalyticsEnabled** API停止收集开发者应用的用户数据。单击[这里](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/HiAnalytics#HiAnalytics_setAnalyticsEnabled)查看接口使用的操作指导。

如果开发者需要分析服务协助来满足开发者最终用户的数据主体权利，开发者可以通过[这里](https://developer.huawei.com/consumer/cn/support/feedback)来申请协助。
