# 1 集成HMS SDK

## 1.1 在Android Studio项目中集成HMS SDK

针对AndroidStudio开发环境，华为提供了maven仓集成方式的WalletKit SDK包。在开始开发前，您需要将WalletKit SDK集成到您的AndroidStudio开发环境中：

  * 在AndroidStudio开发环境中添加当前应用的AppGallery Connect配置文件。

  * 配置HMS SDK的maven仓地址。

  * 添加编译依赖。




### 1.1.1 在AndroidStudio开发环境中添加当前应用的AppGallery Connect配置文件

**步骤1：** 登录[AppGallery Connect 网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择“我的应用”。

**步骤2：** 在名称列表中找到应用所在的产品，点击对应的“Android应用”链接。

**步骤3：** 选择“开发 > 概览”。

**步骤4：** 单击“应用”栏下的“agconnect-service.json”下载配置文件。

**步骤5：** 将agconnect-service.json文件拷贝到项目级根目录下。

### 1.1.5 多语言设置

  * 如果您的应用不需要设置只支持某些特定语言，则请忽略本步骤。应用将默认支持所有HMS SDK支持的语言。

## 3.2 商户服务器生成卡劵包

商户服务器通过证书和私钥来签名卡劵数据，并生成卡劵包文件。

商户需要替换[服务器示例代码](https://developer.huawei.com/consumer/cn/doc/development/HMS-Examples/wallet-sample-code)“src\test\resources\release.config.properties”文件中私钥和证书（证书和私钥请通过[接入准备](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/wallet-preparations-scret)章节操作获取，然后将整个文件做base64转码后得到字符串放入到配置文件中），此证书和私钥用于签名卡劵数据。

卡劵包由home.png, detail.png, signature, hwpass.json, manifest.json, home@2x.png, detail@2x.png七个文件组成，其中signture, manifest.json两个文件在调用服务端demo生成签名卡劵包时会自动生成，不需要商户提供，商户需要按照下方的hwpass.json文件的生成规则生成hwpass.json文件并提供四张图片（图片为可选操作，如果商户不提供则使用钱包内默认底图）。

卡劵包大小应小于150KB，否则无法添加。

卡券包在华为钱包的存储采用文件形式，每个卡劵包都需要遵循相同的格式，整个文件采用zip压缩，文件后缀命名为.hwpass，文件名字字符只允许“a-z”，“A-Z”，“0-9”，“_”。

商户应用向商户服务器请求到卡劵包后将其做Base64加密后，通过SDK的接口推送给华为钱包。

商户App将已签名过的卡劵包推送给华为钱包，钱包会对接收到的卡劵包进行验签操作，验签通过后将卡劵包保存至钱包应用，用户可打开钱包卡包界面进行查看。
      
      1. //createRandomPass()为服务器生成卡劵包接口
        2. String base64ZipData= Base64.encode(createRandomPass(),Base64.NO_WRAP);
        3. // addPass(String base64ZipData)添加卡券包接口
        4. WalletPassApiResponse response = mWalletPassApi.addPass(base64ZipData);
