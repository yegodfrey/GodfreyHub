# 功能简介

留存是项目增长运营的重要核心，留存率的高低代表用户对产品的持续兴趣，是衡量产品核心价值的主要指标之一。通过留存分析，您可以了解您的产品对用户的持续吸引力。

# 功能详述

## 新增用户留存

**操作流程**  


1. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，单击“我的项目”图标。

2. 选择需要查看分析数据的应用。

3.单击“分析 > 留存分析 > 新增用户留存”进入页面。

您可以使用过滤器控件和日期控件（具体使用参考[项目概览](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/3021002#app_overview)）来快速筛选数据。

**3）****添加对比分析**

新增用户留存分析提供针对某个指标进行对比分析的能力，支持应用类型对比、应用对比、用户属性对比、行业对比。比如您可以对比不同设备品牌的新增用户留存趋势，或对行业分类进行下钻分析。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200509184516.48570986114674271075054714139076:50510515014817:2800:D318BBEE2C26D6DEBE432192B413069CE0FC818A13EA4A0826514A5FF8767150.png?needInitFileName=true)

单击上图（1）处选择过滤条件，单击上图（2）处根据“用户属性”或“行业对比”添加对比分析条件，则（3）处的新增用户留存趋势图即出现对比趋势，（4）处表格数据展示对比详情，可下载进行个性化分析。单击图（5）处的清除图标，可清除对比条件。

如果不添加过滤条件，直接添加对比分析条件，则对比趋势图为所有用户和对比条件之间的对比情况。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200509184539.87948967146038680260704416137213:50510515014817:2800:1516D1A0F04B1629E6773E8B68515385E1827459635E493E34400D3907BB61B5.png?needInitFileName=true)

# 规格说明

新增用户留存报告和活跃用户留存报告，两者均按天更新，时间范围可选择最近365天。
