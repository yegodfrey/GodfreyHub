针对AndroidStudio开发环境，华为提供了maven仓集成方式的HMS SDK包。在开始开发前，您需要将HMS SDK集成到您的AndroidStudio开发环境中。

# **1 添加应用的AppGallery Connect配置文件**

1\. 登录[AppGallery Connect 网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择“我的项目”。

2\. 在名称列表中找到应用，点击对应的名称。

3\. 选择“开发 > 概览”。

4\. 单击“应用”栏下的“agconnect-services.json”下载配置文件。

5\. 将agconnect-services.json文件拷贝到模块目录下，如下图的app模块所示。

    ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191219170734.05027704778435647267340359054610:50510613022522:2800:4F804ADDE0721DE8A73315A806DEDF0E02E2733013B783932BBBBA8559829267.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

# **2 配置HMS  Core SDK的maven仓地址**

1\. 打开AndroidStudio项目级build.gradle文件。

    ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191219170758.10870078224087941849395990774628:50510613022522:2800:FBC8F2BDFB9F9E803B7564928ABA66E6D0679A299A990DDC00EE48D8381FA0D4.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

2\. 添加HUAWEI agcp插件以及Maven代码库。

    在allprojects ->repositories中配置HMS SDK的maven仓地址。

    在buildscript->repositories中配置HMS SDK的maven仓地址。

    在buildscript->dependencies里面增加agcp配置。
      
      1. buildscript {
        2.     repositories {
        3.         google()
        4.         jcenter()
        5.         maven {url 'https://developer.huawei.com/repo/'}
        6.     }
        7.     dependencies {
        8.         classpath 'com.huawei.agconnect:agcp:1.2.1.301'
        9.     }
        10. }
        11. allprojects {
        12.     repositories {
        13.         google()
        14.         jcenter()
        15.         maven {url 'https://developer.huawei.com/repo/'}
        16.     }
        17. }
    
    

注意：

maven仓地址直接在浏览器中打开无法访问，只能在IDE中配置。

# **3 添加编译依赖**

1\. 打开模块级的build.gradle文件。

    ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191219170924.15284837145114124098860081642381:50510613022522:2800:53760998587E240E35A12990A0AE252E9C6D636E36759E8EE0F3B8DF313321CC.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

2\. 在“dependencies ”中添加如下编译依赖。
      
      1. dependencies {
        2.     implementation 'com.huawei.hms:maps:{version}'
        3. }
    
    

注意：

{version} 替换为实际的SDK版本号，如最新版本号：implementation 'com.huawei.hms:maps:4.0.1.302'。

  


提示：

如果您使用的华为地图SDK是3.0.2.301或者更新的版本，您需要用'androidx.appcompat:appcompat:{version}'替换'com.android.support:appcompat-{version}' ，例如：implementation 'androidx.appcompat:appcompat:1.0.2'。

  


3\. 在文件头添加配置。
      
      1. apply plugin: 'com.huawei.agconnect'
    
    

注意：

apply plugin: 'com.huawei.agconnect' 配置要在apply plugin: 'com.android.application'之后；

华为地图SDK支持的最低android版本(minSdkVersion )为19。

4\. 在android中配置签名。将“生成签名证书指纹”章节生成的签名文件复制到您工程的app目录下，并在build.gradle文件中配置签名。
      
      1. android {

        5.                 storeFile file("**.**")
        6.                 //密钥库口令

        8.                 //别名
        9.                 keyAlias "******"
        10.                 //密钥口令
        11.                 keyPassword "******"
        12.                 v2SigningEnabled true
        13.             }
        14.         }
        15.         buildTypes {
        16.             release {
        17.                 minifyEnabled false
        18.                 proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'), 'proguard-rules.pro'

# 5 配置混淆脚本

开发者编译APK前需要配置不要混淆HMS SDK，避免功能异常。

1\. 打开应用级的混淆配置文件，Android Studio开发环境里的配置文件是“proguard-rules.pro”。

2\. 加入排除HMS SDK的混淆配置。
      
      1. -ignorewarnings
        2. -keepattributes *Annotation*  
        3. -keepattributes Exceptions  
        4. -keepattributes InnerClasses  
        5. -keepattributes Signature  
        6. -keepattributes SourceFile,LineNumberTable  
        7. -keep class com.hianalytics.android.**{*;}  
        8. -keep class com.huawei.updatesdk.**{*;}  
        9. -keep class com.huawei.hms.**{*;}
    
    

3. 如果开发者使用了AndResGuard，需要在混淆配置文件中加入AndResGuard允许清单。  

      
      1. "R.string.agc*",
        2. "R.string.hms*",  
        3. "R.string.connect_server_fail_prompt_toast",  
        4. "R.string.getting_message_fail_prompt_toast",  
        5. "R.string.no_available_network_prompt_toast",  
        6. "R.string.third_app_*",  
        7. "R.string.upsdk_*",  
        8. "R.layout.hms*",  
        9. "R.layout.upsdk_*",  
        10. "R.drawable.upsdk*",  
        11. "R.color.upsdk*",  
        12. "R.dimen.upsdk*",  
        13. "R.style.upsdk*"
