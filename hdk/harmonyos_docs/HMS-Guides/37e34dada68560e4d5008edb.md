使用视频流检测，继承MLAnalyzer.MLTransactor<T>完成检测处理结果时，如果需要实现检测到特定结果后停止检测，待特定结果处理完后继续检测的功能，可以参考，可以参考对象检测和跟踪模块示例代码，大致流程如下：

1\. 定义一个Handler，用于接受开始或停止消息。
      
      1. Boolean mlsNeedToDetect = true;
        2. final int STOP_PREVIEW = 1;
        3. final int START_PREVIEW = 2;
        4. private Handler mHandler = new Handler() {
        5.     @Override
        6.     public void handleMessage(Message msg) {
        7.         super.handleMessage(msg);
        8.         switch (msg.what) {
        9.             case START_PREVIEW:
        10.                 mlsNeedToDetect = true;
        11.                 // 开始检测相关代码
        12.                 break;
        13.             case STOP_PREVIEW:
        14.                 mlsNeedToDetect = false;
        15.                 // 停止检测相关代码
        16.                 break;
        17.             default:
        18.                 break;
        19.         }
        20.     }
        21. };
    
    

2\. 在结果处理器的transactResult方法中，加入条件判断以及停止检测代码。
      
      1. public class ObjectAnalyzerTransactor implements MLAnalyzer.MLTransactor<MLObject> {
        2.     @Override
        3.     public void transactResult(MLAnalyzer.Result<MLObject> results) {
        4.         if (!mlsNeedToDetect) {
        5.             return;
        6.         }
        7.         SparseArray<MLObject> items = results.getAnalyseList();
        8.         for (int i = 0; i < items.size(); i++) {
        9.             if (items.valueAt(i).getTypeIdentity() == MLObject.TYPE_FOOD) {
        10.                 // 检测到特定内容时，停止检测
        11.                 mlsNeedToDetect = true;
        12.                 mHandler.sendEmptyMessage(STOP_PREVIEW);
        13.             }
        14.         }
        15.     }
        16. }
    
    

3\. 在处理完成后，需要重新检测时，调用开始检测代码。
      
      1. mHandler.sendEmptyMessage(START_PREVIEW);
