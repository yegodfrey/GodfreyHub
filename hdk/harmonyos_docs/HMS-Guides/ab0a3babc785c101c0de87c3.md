# 2\. 隐私声明  


业务集成使用HUAWEI Ads SDK能力，需要先签订《[华为开发者服务协议](https://developer.huawei.com/consumer/cn/devservice/doc/20201)》、《[华为APIs使用协议](https://developer.huawei.com/consumer/cn/doc/20209)》。您理解并承诺您的下载或使用HUAWEI Ads SDK的行为，视为您同意前述所有协议，且您将基于这些协议承担相应的法律责任与义务。

如果您通过 HUAWEI Ads SDK 投放个性化广告，HUAWEI Ads会收集用户的设备及使用信息、广告互动信息及设备位置信息（用户开启基于位置的广告开关），用于创建广告细分组别并向用户提供广告服务。您（开发者）是数据控制者，需要在您的隐私声明或用户协议中根据实际使用情况进行描述并告知用户这些数据将分享给华为广告平台。

您还需要告知用户可使用”广告与隐私”设置页面查看Huawei Ads相关的详细信息，并可以关闭个性化广告和基于位置的广告。

由于不同国家及地区的法律和发布商的界面各不相同，因此我们不提供关于隐私政策的内容的具体建议。
