# 开发准备

  1. [登录注册](https://developer.huawei.com/consumer/cn/doc/20300)：注册成为开发者并完成实名认证。 
  2. [申请帐号服务](https://developer.huawei.com/consumer/cn/doc/HMS-Guides/apply_id-0000001050069756)：开通帐号服务，创建服务器应用（即产品类型选择服务器应用），获取 APP ID。 
  3. [申请 Health Kit 服务](https://developer.huawei.com/consumer/cn/doc/HMS-Guides/apply_kitservice-0000001050071707)：获取 Health Kit 运动健康数据的使用权限。 
  4. 获取Access Token：服务端基于 OAuth2.0 协议为第三方应用提供用户接入服务，必须采用“授权码模式”方式获取 Access Token，详细请参考[开放平台鉴权](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/30101)-**授权码模式** 。
