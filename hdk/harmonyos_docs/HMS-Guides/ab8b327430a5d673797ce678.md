# 1 业务简介

华为应用内支付（In-App Purchases，IAP）服务为应用提供便捷的应用内支付体验，接入流程简便，帮助您快速获取收入。通过应用内支付，使用应用的用户可以在您的应用内购买各种类型的虚拟商品，包括普通一次性商品和订阅商品。

华为应用内支付服务包含商品管理系统（Product Management System，PMS）。您对应用内（含游戏）商品的价格和语言进行管理，只需发布一个应用包，即可在所有 "华为IAP范围覆盖”中的国家和地区推广，实现本地化语言和价格展示。

当前最新版本支持以下功能：

  * 应用（含游戏）发布：一个应用（含游戏）包发布、支持多个国家应用内商品的价格和语言管理。PMS可支持的国家以配置商品价格时的页面提示为准。

  * 币种与语言：华为为每个国家指定一个默认币种和一个默认语言，不支持一个国家配置多种语言。

  * 商品定价：华为根据您设置的汇率换算价格（含税） 和汇率提供已上线华为支付各国参考价，您可自行修改各国价格。

  * 汇率：固定汇率，此汇率非实时汇率，华为将根据此汇率更新货币价格。在您没有修改商品价格的情况下，华为更新汇率不会影响您的商品定价。

  * 使用对象：全球开发者。若您准备将应用（含游戏）发布到多个国家与地区，则需要对应用内商品的价格和语言进行管理以实现本地化语言和价格展示。




# 2 业务特点

  * 接入便捷，沙盒调测更方便

完善的接入流程指导和配套沙盒环境测试，帮助您快速轻松接入华为应用内支付。  


  * 全球发布便捷，本地化语言和货币展示

自动根据用户服务所在国家/地区，应用内购买时商品可展示本地化的语言和货币价格。您只需发布一个应用，就可以轻松实现用本地货币和语言来展示商品。

  * 聚合多种支付通道，提供全球支付服务

支持银行卡、支付宝、微信支付、运营商话费以及华为虚拟币-花币等多种支付方式，其中银行卡支持国内绝大多数主流银行和VISA、Mastercard等海外银行卡组织，话费支付支持多个海外大型运营商。支持将银行卡、手机号码绑定到用户的华为帐号上，支付时用户只需输入其设置的华为支付密码便能完成支付，省去输入银行卡信息、手机号码的麻烦，支付更加简单便捷。

●  安全可靠，监控有保障

采用业界标准的TLS协议加密传输数据，通过RSA算法签名保护用户消息，保证不会被截取和篡改。数据在后台采用加密和匿名化方式存储，保证用户数据存储安全。

后台服务器采用集群部署和冗余设计，7*24小时实时监控系统运行。

# 3 业务场景

华为IAP支持的商品主要分如下几类：

**商品定义**| **描述**| **示例**  
---|---|---  
消耗商品| 仅能使用一次，消耗使用后即刻失效，需再次购买。| 游戏中额外生命、钻石等  
非消耗商品| 一次性购买，永久拥有，无需消耗。| 游戏中额外的游戏关卡或应用中无时限的高级会员  
订阅商品| 用户购买后在一段时间内允许访问增值功能或内容，周期结束后自动续期购买下一期的服务| 应用中有时限的高级会员，如视频月度会员等  
  
以下场景描述华为IAP的潜在使用案例：  


  * 允许用户免费下载体验您的应用后，一次性购买高级服务或功能。

  * 允许用户购买虚拟商品来提升游戏体验，比如游戏代币、额外的游玩机会等。

  * 允许用户订阅您的应用中提供的内容，并灵活地周期性付款，例如月度会员和年度高级功能订阅。




华为应用内支付包含商品管理系统（Product Management System， PMS）。您在华为[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站录入商品的编号和定价之后，即可托管商品。IAP会根据地区和汇率展示本地化的语言和货币价格，从而实现全球发布。

面向中国大陆发布的应用，您也可使用IAP提供的非托管商品支付接口[createPurchaseIntentWithPrice](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapClient-v4#createPurchaseIntentWithPrice)自行完成商品的定价及支付。需要注意，该非PMS支付接口仅支持消耗型和非消耗型商品，若您需要使用订阅服务，请使用[createPurchaseIntent](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapClient-v4#createPurchaseIntent)。

华为IAP为您提供了应用内支付以及订单托管服务，降低您的开发成本，让您可快速接入华为应用内支付服务。同时利用订单托管服务内置的确认机制，大幅降低用户掉单概率，节省您的运营客服成本，给用户提供一套完整的支付体验。

# 4 华为IAP覆盖范围

华为应用内支付（In-App Purchases，IAP）已支持全球多个国家地区的多种支付方式，为当地的消费者和商户提供安全、便捷、高效的支付服务。

**目前IAP在全球共支持 177个国家或地区，其中：**

**1\. 银行卡支付(Credit card/Debit card)**

全球支持**176** 个国家或地区。

**2\. 运营商话费支付 DCB(Direct Carrier Billing)**

全球支持**25** 个国家或地区, **55** 个运营商。

**3\. 花币 (HUAWEI Points)**

全球支持**102** 个国家或地区，币种与银行卡交易币种保持一致。

注意：

科威特因付费业务税务风险暂时关闭。

**4\. 第三方支付（Third-party Payment）**  


全球支持**8** 个国家或地区, **8** 个第三方支付方式。

说明：

不支持小数的币种

由于某些币种在支付平台不支持携带小数，开发者在设置订单参数amount字段时，应设置为整数金额值，如5.00， 不支持5.02。

涉及币种：

BEF、XOF、XAF、XPF、KMF、GRD、GNF、HUF、IDR、JPY、LUF、MGA、MGA、MGF、PYG、PTE、RWF、KRW、ESP、TRL、VND、IQD。
