# 1\. 场景介绍  
  
分析服务开放了服务端接口，允许开发者通过接口方式申请将端侧采集的事件数据进行导出，并导入到开发者自有的BI系统中，进行统一的数据分析。导出接口的处理过程为异步过程，处理完成后会将导出的数据上传到云端存储对象（Object Storage Service）中。导出的结果和数据的存储路径会通过接口回调的方式返回给开发者服务器，开发者需要根据导出结果的状态和文件路径，及时将数据下载到开发者服务器中。为了保证数据安全，下载链接会在2个小时后失效。

目前导出的状态有:

数据下载状态码| 状态码描述| 原因及处理  
---|---|---  
EXPORTED| 成功导出| 及时处理下载链接  
NO_DATA| 没有符合条件的数据| 建议更改数据筛选条件  
EXPORT_FAILED| 导出失败| 服务端异常，建议重试  
TOO_MANY_RECORDS| 一次导出数据量太多| 建议缩小数据导出范围后重新发起请求  
  
**建议:** 开发者服务端对下载链接的处理，采用异步处理方式，及时返回成功状态给分析服务器。

# 2\. 开发准备  


## 2.1 设置回调接口

单击“我的项目”，在“分析>管理>分析设置”页面，勾选配置回调接口可进行相关设置。

1.配置回调接口地址，您的下载地址接收url。

2.配置https证书。

说明：

目前华为分析以HTTPS POST请求回调开发者接口，华为分析会校验开发者HTTPS证书的合法性，请开发者服务器务必使用正式商用的HTTPS证书。

3.单击“测试接口”可以对回调接口进行功能测试，测试通过后单击“提交”完成回调接口的配置。
