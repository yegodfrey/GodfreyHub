ML Kit提供两种集成SDK方式，您可以参见[概述（Full SDK和基础SDK）](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-sdk-overview)，根据您的应用场景选择不同的集成方式。

# 方式一：Full SDK方式集成（推荐使用）

先集成模型包，然后集成银行卡识别插件，模型包和插件信息如下：

**包类型**| **包名**| **SDK****大小**| **坐标名称**  
---|---|---|---  
插件a| ml-computer-card-bcr-plugin| 182K| com.huawei.hms:ml-computer-card-bcr-plugin:2.0.0.300  
模型包+算法包| ml-computer-card-bcr-model| 3.2M| com.huawei.hms:ml-computer-card-bcr-model:2.0.0.300  
  
当前版本的插件、模型包版本号需要保持一致，否则可能会出现功能无法使用的错误，同时，若您的应用同时集成了ML Kit提供的其他服务的较老版本（[ML Kit最新版本列表](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-history)），可能会出现编译问题，您可以参见[概述（注意事项）](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-sdk-overview)进行处理。

Full SDK方式集成的示例代码如下：
      
      1. dependencies{
        2.     // 引入银行卡识别插件包
        3.     implementation 'com.huawei.hms:ml-computer-card-bcr-plugin:2.0.0.300'
        4.     // 引入银行卡识别模型包
        5.     implementation 'com.huawei.hms:ml-computer-card-bcr-model:2.0.0.300'
        6. }
    
    

# 方式二：基础SDK方式集成

示例代码如下：
      
      1. dependencies{
        2.     // 引入银行卡识别plugin包
        3.     implementation 'com.huawei.hms:ml-computer-card-bcr-plugin:2.0.0.300'
        4. }
    
    

# 文件头增加配置

用上述两种方式之一集成SDK后，在文件头添加配置。
      
      1. apply plugin: 'com.huawei.agconnect'
    
    

注意：

此项配置需要在如下配置项后添加。
      
      1. apply plugin: 'com.android.application'
    
    

# 自动更新机器学习模型  


添加如下语句到AndroidManifest.xml文件中，用户从华为应用市场安装您的应用后，将自动更新机器学习模型到设备：
      
      1. <manifest 
        2.     ... 
        3.     <meta-data              
        4.         android:name="com.huawei.hms.ml.DEPENDENCY"   
        5.         android:value= "bcr"/> 
        6.     ... 
        7. </manifest>
