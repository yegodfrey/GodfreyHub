# 1\. 添加开屏广告

## 步骤一：添加SplashView

在XML布局文件中添加[SplashView](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-splashview)。

以下示例代码中展示了如何在XML布局文件中添加[SplashView](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-splashview)。
      
      1. <?xml version="1.0" encoding="utf-8"?>
        2. <RelativeLayout xmlns:android="http://schemas.android.com/apk/res/android"
        3.     xmlns:tools="http://schemas.android.com/tools"
        4.     android:layout_width="match_parent"
        5.     android:layout_height="match_parent"
        6.     tools:context=".SplashActivity">
        7.     <RelativeLayout
        8.         android:id="@+id/logo"
        9.         android:layout_width="fill_parent"
        10.         android:layout_height="100dp"
        11.         android:layout_alignParentBottom="true"
        12.         android:visibility="visible">
        13.         ...
        14.     </RelativeLayout>
        15.     <com.huawei.hms.ads.splash.SplashView
        16.         android:id="@+id/splash_ad_view"
        17.         android:layout_width="match_parent"
        18.         android:layout_height="match_parent"
        19.         android:layout_above="@id/logo" />
        20. </RelativeLayout>
    
    

以下示例代码展示了如何获取[SplashView](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-splashview)。
      
      1. SplashView splashView = findViewById(R.id.splash_ad_view);
    
    

## 步骤二：修改应用默认启动页面

开屏广告是在应用主界面显示之前被展示，所以需修改应用默认启动页面。

修改AndroidManifest.xml, 将默认启动的activity修改为SplashActivity，这样即可在应用主界面加载前展示开屏广告。

修改后的内容示例如下：
      
      1. <?xml version="1.0" encoding="utf-8"?>
        2. <manifest xmlns:android="http://schemas.android.com/apk/res/android"
        3.     package="com.huawei.hms.ads.sdk">
        4.     <application
        5.         android:allowBackup="true"
        6.         android:icon="@mipmap/ic_launcher"
        7.         android:label="@string/app_name"
        8.         android:roundIcon="@mipmap/ic_launcher_round"
        9.         android:supportsRtl="true"
        10.         android:theme="@style/AppTheme">
        11.         <activity
        12.             android:name=".MainActivity"
        13.             android:exported="false"
        14.             android:screenOrientation="portrait">
        15.         </activity>
        16.         <activity
        17.             android:name=".SplashActivity"
        18.             android:exported="false"
        19.             android:screenOrientation="portrait">
        20.             <intent-filter>
        21.                 <action android:name="android.intent.action.MAIN" />
        22.                 <category android:name="android.intent.category.LAUNCHER" />
        23.             </intent-filter>
        24.         </activity>
        25.         ...
        26.     </application>
        27. </manifest>
    
    

创建SplashActivity.java类，用于实现开屏广告获取和展示。
      
      1. ...
        2. import android.os.Build;
        3. import androidx.appcompat.app.AppCompatActivity;
        4. public class SplashActivity extends AppCompatActivity {
        5.     private static final String AD_ID = "testq6zq98hecj";
        6.     /**
        7.      * 暂停标志位。
        8.      * 在开屏广告页面展示时：
        9.      * 按返回键退出应用时需设置为true，以确保应用主界面不被拉起；
        10.      * 切换至其他界面时需设置为false，以确保从其他页面回到开屏广告页面时仍然可以正常跳转至应用主界面；
        11.      */
        12.     private boolean hasPaused = false;
        13.     @Override
        14.     protected void onCreate(Bundle savedInstanceState) {
        15.         super.onCreate(savedInstanceState);
        16.         setContentView(R.layout.activity_splash);
        17.         // 获取并展示开屏广告        
        18.         loadAd();
        19.     }
        20.     /**
        21.      * 广告展示完毕时，从广告界面跳转至App主界面
        22.      */
        23.     private void jump() {
        24.         if (!hasPaused) {
        25.             hasPaused = true;
        26.             startActivity(new Intent(SplashActivity.this, MainActivity.class));
        27.             finish();
        28.         }
        29.     }
        30.     /**
        31.      * 按返回键退出应用时需设置为true，以确保应用主界面不被拉起
        32.      */
        33.     @Override
        34.     protected void onStop() {
        35.         // 移除消息队列中等待的超时消息
        36.         timeoutHandler.removeMessages(MSG_AD_TIMEOUT);
        37.         hasPaused = true;
        38.         super.onStop();
        39.     }
        40.     /**
        41.      * 从其他页面回到开屏页面时调用，进入应用主界面
        42.      */
        43.     @Override
        44.     protected void onRestart() {
        45.         super.onRestart();
        46.         hasPaused = false;
        47.         jump();
        48.     }
        49.     @Override
        50.     protected void onDestroy() {
        51.         super.onDestroy();
        52.     }
        53. }
    
    

## 步骤三：获取广告

[SplashView](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-splashview)创建好之后，通过[SplashView](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-splashview)类的load()方法来获取广告。

示例代码如下：
      
      1. private void loadAd() {
        2.     int orientation = ActivityInfo.SCREEN_ORIENTATION_PORTRAIT;
        3.     AdParam adParam = new AdParam.Builder().build();
        4.     SplashView.SplashAdLoadListener splashAdLoadListener = new SplashView.SplashAdLoadListener() {
        5.         @Override
        6.         public void onAdLoaded() {
        7.             // 广告获取成功时调用
        8.         }
        9.         @Override
        10.         public void onAdFailedToLoad(int errorCode) {
        11.             // 广告获取失败时调用, 跳转至App主界面
        12.             jump();
        13.         }
        14.         @Override
        15.         public void onAdDismissed() {
        16.             // 广告展示完毕时调用, 跳转至App主界面
        17.             jump();
        18.         }
        19.     };
        20.     // 获取SplashView
        21.     SplashView splashView = findViewById(R.id.splash_ad_view);
        22.     // 设置视频类开屏广告的音频焦点类型
        23.     splashView.setAudioFocusType(AudioFocusType.NOT_GAIN_AUDIO_FOCUS_WHEN_MUTE);
        24.     // 获取广告，其中AD_ID为广告位ID
        25.     splashView.load(AD_ID, orientation, adParam, splashAdLoadListener);
        26. }
    
    

## 步骤四：监听广告事件（可选）

通过实现[SplashAdDisplayListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-splashaddisplaylistener)类中的方法来监听广告展示类事件。
      
      1. SplashAdDisplayListener adDisplayListener = new SplashAdDisplayListener() {
        2.     @Override
        3.     public void onAdShowed() {
        4.         // 广告显示时调用
        5.     }
        6.     @Override
        7.     public void onAdClick() {
        8.         // 广告被点击时调用
        9.     }
        10. };
        11. splashView.setAdDisplayListener(adDisplayListener);
    
    

了解详细方法，请参见API文档中的[SplashAdDisplayListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-splashaddisplaylistener)类。

# 2\. 测试开屏广告

测试开屏广告时，需要使用专门的测试广告位ID来获取测试广告，以避免在测试过程中产生无效的广告点击量。测试广告位ID仅作为功能调试使用，不可用于广告变现。开发者需要在应用发布前[申请正式的广告位ID](https://developer.huawei.com/consumer/cn/monetize)，并替换测试广告位ID。

以下表格中提供了开屏广告的专用测试广告位ID:

广告形式| 展示形式| 尺寸| 比例| 测试广告位ID  
---|---|---|---|---  
开屏| 纯图| 1080*1620| 2:3| testq6zq98hecj  
开屏| 视频| 720*1280| 9:16| testd7c5cewoj6
