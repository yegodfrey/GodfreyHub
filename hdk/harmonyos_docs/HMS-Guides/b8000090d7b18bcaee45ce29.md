本章节主要介绍接入华为应用内支付的客户端开发步骤，帮助您快速了解华为支付提供的客户端接口及其使用方法。

# **判断是否支持应用内支付**

在使用应用内支付之前，您的应用需要向华为IAP发送[isEnvReady](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapClient-v4#isEnvReady)请求，以此判断用户当前登录的华为帐号所在的服务地是否在华为IAP支持结算的国家或地区中。

如果您的应用未接入华为帐号的登录接口，您可以通过该接口完成登录操作。

开发步骤如下：

发起[isEnvReady](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapClient-v4#isEnvReady)请求，并设置两个回调监听来接收接口请求的结果。

● 当接口请求成功时，您的应用将获取到一个[IsEnvReadyResult](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IsEnvReadyResult-v4)实例对象，表示用户当前登录的华为帐号所在的服务地支持IAP。

● 当接口请求失败时，IAP会返回一个Exception对象，若该对象为[IapApiException](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapApiException-v4)对象，可使用其getStatusCode()方法获取此次请求的返回码。

当返回帐号未登录（OrderStatusCode. ORDER_HWID_NOT_LOGIN）时，可使用[IapApiException](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapApiException-v4)对象中的status拉起华为帐号登录页面，此后在Activity的onActivityResult方法中获取结果信息。从onActivityResult返回的intent中解析出returnCode，当returnCode = OrderStatusCode.SUCCESS时，则表示当前帐号所在服务地支持IAP，其他则表示此次请求有异常。

# 展示商品信息

若您使用在华为AppGallery Connect网站上配置的商品，则需要在您的应用中使用[obtainProductInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapClient-v4#obtainProductInfo)接口来获取此类商品的详细信息。

开发步骤如下：

1\. 构建请求参数[ProductInfoReq](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-ProductInfoReq-v4)，发起[obtainProductInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapClient-v4#obtainProductInfo)请求并设置OnSuccessListener和OnFailureListener回调监听器以接收接口请求的结果。您需要在[ProductInfoReq](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-ProductInfoReq-v4)中携带您此前已在AGC网站定义并生效的商品ID，并根据实际配置的商品指定其priceType。

注意：

[obtainProductInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapClient-v4#obtainProductInfo)每次只能查询一种类型的商品。

2\. 当接口请求成功时，IAP将返回一个[ProductInfoResult](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-ProductInfoResult-v4)对象，您的应用可通过该对象的getProductInfoList方法获取到包含了单个商品信息的[ProductInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-ProductInfo-v4)对象的列表。您可以使用[ProductInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-ProductInfo-v4)对象包含的商品价格，名称，描述等信息，向用户展示可供购买的商品列表。
      
      1. // Pass in the productId list of products to be queried.
        2. List<String> productIdList = new ArrayList<>();
        3. // The product ID is the same as that set by a developer when configuring product information in AppGallery Connect.
        4. productIdList.add("ConsumeProduct1001");
        5. ProductInfoReq req = new ProductInfoReq();
        6. // priceType: 0: consumable; 1: non-consumable; 2: auto-renewable subscription
        7. req.setPriceType(0);
        8. req.setProductIds(productIdList);
        9. // to call the obtainProductInfo API.
        10. // To get the Activity instance that calls this API.
        11. Activity activity = getActivity();
        12. Task<ProductInfoResult> task = Iap.getIapClient(activity).obtainProductInfo(req);
        13. task.addOnSuccessListener(new OnSuccessListener<ProductInfoResult>() {
        14.     @Override
        15.     public void onSuccess(ProductInfoResult result) {
        16.         // Obtain the result

        18.     }
        19. }).addOnFailureListener(new OnFailureListener() {
        20.     @Override
        21.     public void onFailure(Exception e) {
        22.         if (e instanceof IapApiException) {
        23.             IapApiException apiException = (IapApiException)e;
        24.             int returnCode = apiException.getStatusCode();
        25.         } else {
        26.             // Other external errors
        27.         }
        28.     }
        29. });
    
    

# 发起购买

## 购买托管商品

AppGallery Connect网站支持的商品包括消耗型商品，非消耗型商品和订阅型商品。针对此类商品，您的应用可通过[createPurchaseIntent](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapClient-v4#createPurchaseIntent)接口发起购买请求。

开发步骤如下：

1\. 构建请求参数[PurchaseIntentReq](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-PurchaseIntentReq-v4)，发起[createPurchaseIntent](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapClient-v4#createPurchaseIntent)请求。您需要在[PurchaseIntentReq](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-PurchaseIntentReq-v4)中携带您此前已在AGC网站上定义并生效的商品ID。

当接口请求成功时，您可获取到一个[PurchaseIntentResult](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-PurchaseIntentResult-v4)对象，其getStatus方法返回了一个[Status](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/status)对象，您的应用需要通过[Status](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/status)对象的startResolutionForResult方法来启动华为IAP收银台。

## 购买非托管商品

注意：

IAP SDK将于6月15号废弃createPurchaseIntentWithPrice接口，届时将下架相关资料，不再提供支撑和维护。已集成当前SDK版本的应用可以继续使用，集成新版本时需要替换为createPurchaseIntent接口。请开发者尽快完成替换，以免影响后续版本升级。

若您的应用使用自定义价格的商品，可通过[createPurchaseIntentWithPrice](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapClient-v4#createPurchaseIntentWithPrice)接口发起支付请求。

开发步骤如下：

1\. 构建请求参数[PurchaseIntentWithPriceReq](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-PurchaseIntentWithPriceReq-v4)，发起[createPurchaseIntentWithPrice](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapClient-v4#createPurchaseIntentWithPrice)请求。

● 当接口请求成功时，IAP将返回一个[PurchaseIntentResult](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-PurchaseIntentResult-v4)对象，需要使用支付公钥对其包含的[paymentData](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-PaymentData-v4)进行签名校验，具体请参考[对响应消息验签的方法](https://developer.huawei.com/consumer/cn/doc/iap-verifying-signature-returned-result-v4)。公钥获取方法参考[查询支付服务信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/appgallery_querypaymentinfo)。验签成功之后您的应用可通过[PurchaseResultInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-PurchaseResultInfo-v4)中携带的[Status](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/status)对象来启动华为IAP收银台。

● 当接口请求失败时，您的应用可获取到一个Exception对象。若该异常对象为[IapApiException](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapApiException-v4)实例对象，使用[IapApiException](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapApiException-v4)中的getStatusCode()可获取此次请求的返回码，具体参考异常处理及通用错误码。当返回下面的几种错误时，需要您进行处理：

\- 未登录（OrderStatusCode.ORDER_HWID_NOT_LOGIN）

Iap在IapApiException中携带了一个status实例，可通过其startResolutionForResult方法拉起华为帐号登录页面，结果通过Activity的onActivityResult方法回调。从onActivityResult方法中返回的intent中携带的returnCode字段即为登录的结果。

\- 未同意协议（OrderStatusCode.ORDER_NOT_ACCEPT_AGREEMENT）

可通过返回的IapApiException对象中的status拉起华为支付协议页面，方法同未登录场景。

注意：

该错误场景必须处理，否则无法继续完成购买。

\- 已拥有该商品（OrderStatusCode.ORDER_PRODUCT_OWNED）

如果购买为消耗型商品，说明您的应用此前可能存在掉单的场景，需要触发补单操作，具体参考消耗型商品的补单机制。

如果购买为非消耗型商品，则不能再次进行购买，请确认应用是否已经发货成功。

  


2\. 在您的应用拉起收银台并且当用户完成支付后（成功购买商品或取消购买），华为IAP会通过onActivityResult方式将这次支付结果返回给您的应用。可使用[parsePurchaseResultInfoFromIntent](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapClient-v4#parsePurchaseResultInfoFromIntent)方法获取包含结果信息的[PurchaseResultInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-PurchaseResultInfo-v4)对象。

●  当用户购买成功时，可从[PurchaseResultInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-PurchaseResultInfo-v4)对象中获取到相关的购买数据[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-InAppPurchaseData)及其签名数据，您需要使用在华为AppGallery Connect分配的公钥进行签名验证，验证方法请参考[对响应消息验签的方法](https://developer.huawei.com/consumer/cn/doc/iap-verifying-signature-returned-result-v4)。
