# ****

# **SafetyDetect 4.0.3版本（2020-4-15）**

**最新子版本号：4.0.3.300**

**新增特性**

1、新增恶意WIFI检测接口，提供检测当前连接WiFi是否安全的能力。

# **SafetyDetect 4.0.2版本（2020-3-10）**

**新增特性**

1\. 新增初始化虚假用户检测接口：提供初始化虚假用户检测的能力。

2\. 新增关闭虚假用户检测接口：提供关闭虚假用户检测的能力。

# **SafetyDetect 4.0.0版本（2020-1-15）**

华为安全检测服务推出了全新的HMS SDK 4.0.0版本，此次版本新增了几个API，欢迎广大开发者接入。

**新增特性**

1.  新增SysIntegrity API：系统完整性检测API，开发者通过该API评估其APP所运行的设备环境是否安全（如设备是否被root）。

2.  新增AppsCheck API：恶意应用检测API，开发者可获取恶意应用列表。

3.  新增URLCheck API：提供的恶意网址检测服务。可以使用此API来确定特定URL的威胁类型。

4.  新增UserDetect API：虚假用户检测API，开发者可通过该API判断当前APP的交互对象是否为虚假用户。

  


# **SDK****依赖说明：**

1.    本版本SDK需要用户手机上安装HMS Core 4.0.2.300及以上版本； 如果用户手机没有安装，您的应用调用HMS Core时，会自动引导用户提示安装。

2.    本服务的主要特性都可以在大多数华为终端上支持，部分高级特性依赖于EMUI版本。请参考[部分特性对于EMUI的依赖说明](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/emui_version_dependent_features)。

提示：您的应用在华为应用市场上架过程中，如有问题可发送邮件至HMSCore@huawei.com咨询
