# 1 LinkDevicePass节点设置

商户如需实现NFC刷卡能力，则需要在用户特有信息的对象中包含 _linkDevicePass节点。_

注：通过WalletKit SDK方式添加卡劵暂不支持此能力。
      
      1. HwWalletObject hwWalletObject = new HwWalletObject();
        2. ...
        3. LinkDevicePass linkDevicePass = new LinkDevicePass(); linkDevicePass.setWebServiceURL("http://xxx/passtools");   
         
      
        4. linkDevicePass.setNfcType("1");
      
        5. linkDevicePass.setPassVersion("DevicePass version");   
         
      
        6. linkDevicePass.setSerialNumber("4527809736");   
         
      
        7. linkDevicePass.setSpPublicKey("2353sasxsd");
      
        8. linkDevicePass.setToken("34534314194");   
         
      
        9. hwWalletObject.setLinkDevicePass(linkDevicePass);
    
    
    

  


  * **_LinkDevicePass_ 字段说明：**


**字段名**| **字段描述**| **类型**| **可空**  
---|---|---|---  
webServiceURL| 回调的地址| String| 不可  
token| Token，到SP-Server下载DevicePass时的Token| String| 不可  
serialNumber| 在发卡方的唯一键值| String| 不可  
passVersion| DevicePass版本；SP-Server可以通过更新Pass对象中的此信息通知DevicePass需要更新，端侧会与本地DevicePass中的passVersion进行比对，DevicePass中的值如果与此值不匹配，则触发重新下载；（此部分主要用于动态信息和隐私数据这种，Applet个人化参数不支持更新）| String| 可空  
spPublickey| 由于DevicePass数据是不到WalletServer的，因此需要端侧对获取的数据进行验签，通过此字段端侧对SP返回的签名进行验签，从而保证发卡方是一致的| String| 不可  
nfcType| 标识NFC卡片类型，此部分必须为公开的常量值；会依据此类型找到对应的Applet创建脚本，创建对应的Applet实例；值不在公开范围内以及不填写时均会标识为非NFC卡片；| String| 固定为“1”  
  
# 2 商户服务器实现NFC刷卡能力接口

商户服务器需要实现包括“注册”“申请个人化Token”“获取个人化数据”“取消注册”在内的4个接口供钱包APP调用，用于完成NFC刷卡能力的开通和卡片信息的更新。

接口功能如下：

## 2.2 申请个人化Token  


在调用“获取个人化数据”接口前华为钱包会先到商户服务器取到此Token。调用 “获取个人化数据”接口时会将此Token放入Header中，同时在请求的signature字段中作为其中requestbody一个key参与Hash值计算，建议商户服务器设置此Token时效性。

注：Token放入Header中请对Token先做如下处理"HuaweiPassToken " + Base64.encodeToString(Token.getBytes("UTF-8"), Base64.NO_WRAP)

  * URL

requestPersonalizeToken| POST {webServiceURL}/v1/passes/requestToken/personalize  
---|---  
  * 请求消息体：

---|---|---|---|---

transId| String| 必选| 随机数  
signature| -| String| 必选| Applet的身份私钥对requestBody的Hash值的签名  
certificate| -| Certificate| 必选| Applet证书，SP-Server签发

publickKey| String| 可选| Applet的身份公钥

        50.     System.out.println("Personalize, body=" + passDataStr);
        51.     System.out.println("Personalize, passHashValue=" + passHashValue);
        52.     String signature = DataConvertUtil.signData(passHashValue, Constants.SERVER_SECRET_KEY);
        53.     System.out.println("Personalize, signature=" + signature);
        54.     response.setSignature(signature);
        55.     return response;
        56.   }
