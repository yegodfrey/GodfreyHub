# 应用包名

#### 了解应用包名

当用 Andriod Studio 创建一个新的工程时，我们需要填写应用包名。包名命名应符合业界规范，一般而言，一级为 com，二级为公司或个人域名或邮箱，三级为应用属性名，四级或以上为应用的功能模块名。

创建工程后，可以看到，工程的文件结构与应用包名相匹配。实际上，软件包名称就是由项目目录结构所定义。如下图，包名为：com.huawei.healthdemoanna。

#### 修改应用包名

如需修改包名，改为：com.honor.health。

  1. 先将 huawei 修改为 honor。操作如下。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515184204.32600715329020335325290396081444:50510515105457:2800:978CA21A77915EE30A3BFC95D44D4779DA51936A1AE9C2725AD122F239D7366D.png?needInitFileName=true?needInitFileName=true)



  2. 参考上述步骤，继续将 healthdemoanna 修改为 health。 
  3. 打开 AndroidManifest.xml 文件，修改 package 属性为 com.honor.health。
