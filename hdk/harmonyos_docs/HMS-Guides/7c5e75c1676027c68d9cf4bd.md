# 1 业务简介

WisePlay DRM为合作伙伴提供内容的数字版权保护，包括硬件级与软件级的DRM能力，支持客户端证书在线申请，多种内容加密格式与加密算法，在线与离线播放等多种场景。

第三方应用(SP)使用密钥对内容进行加密，用户播放加密的内容时，需要使用密钥解密后才可以观看对应内容。

  * 产品特点



  1. 免费为合作伙伴提供DRM服务；

  2. 硬件级与软件级完整的DRM解决方案，提供更加安全的“硬件级”DRM能力。




# 2 业务场景

  1. 内容加密：SP的服务获取密钥，在内容转码时对内容进行加密，将加密的内容分发至CDN源站（内容分发网络）；

  2. 内容解密：用户播放内容时，针对加密内容，客户端从SP的服务侧获取密钥，调用DRM能力对内容进行解密后播放。
