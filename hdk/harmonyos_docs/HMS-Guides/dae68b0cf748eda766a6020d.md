在调用Scan Kit时，开发者需要先在Manifest中指定相应的权限。构建相机扫码功能，需要申请“CAMERA”（相机权限）；构建导入图片扫码功能，需要申请“READ_EXTERNAL_STORAGE”（读文件权限）。
    
    
    复制
      
        1. <!--相机权限--> 
        2. <uses-permission android:name="android.permission.CAMERA" /> 
        3. <!--读文件权限--> 
        4. <uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" /> 
        5. <!--使用特性--> 
        6. <uses-feature android:name="android.hardware.camera" /> 
        7. <uses-feature android:name="android.hardware.camera.autofocus" />
    
    

在Manifest中指定权限后，还需要在代码中动态申请一下权限:
    
    
    复制
      
        1. //CAMERA_REQ_CODE为用户自定义，用于接收权限校验结果 
        2. ActivityCompat.requestPermissions(this,new String[]{Manifest.permission.CAMERA, Manifest.permission.READ_EXTERNAL_STORAGE}, CAMERA_REQ_CODE);
    
    

最后，校验是否开启相应的权限，决定是否继续扫码：
    
    
    复制
      
        1. //实现“onRequestPermissionsResult”函数接收校验权限结果 
        2. @Override 
        3. public void onRequestPermissionsResult(int requestCode, String[] permissions, int[] grantResults) { 
        4.     //判断“requestCode”是否为申请权限时设置请求码CAMERA_REQ_CODE，然后校验权限开启状态 
        5.     if (requestCode == CAMERA_REQ_CODE && grantResults.length == 2 && grantResults[0] == PackageManager.PERMISSION_GRANTED && grantResults[0] == PackageManager.PERMISSION_GRANTED) { 
        6.         //调用扫码接口，构建扫码能力，需开发者实现 
        7.         ... 
        8.     } 
        9. }
