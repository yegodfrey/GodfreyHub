# 1 概览

本章节将向您介绍如何使用地图容器快速地获得地图对象，并改变地图类型、在地图上显示“我的位置”，以及开启地图的简洁模式等。参考示例代码工程中的MapViewDemoActivity.java，MapFragmentDemoActivity.java等文件，[示例代码下载](https://developer.huawei.com/consumer/cn/doc/development/HMS-Examples/hms-map-v4-example)。

# 2 创建地图实例

**地图容器**

目前华为地图SDK支持的地图容器有两种，[MapFragment](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapfragment)和[MapView](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapview)：

[MapFragment](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapfragment)是Android Fragment的子类，允许您将地图放置在Fragment中。[MapFragment](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapfragment)可以充当地图的容器，并提供对[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-huaweimap)对象的访问入口。

[MapView](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapview)是Android View类的子类，允许您将地图放置在Android视图中。与[MapFragment](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapfragment)非常相似，[MapView](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapview)充当地图的容器，通过[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-huaweimap)对象展示核心地图功能。在常规地图交互模式下调用API时，[MapView](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapview)类的使用者必须在对应的Activity/Fragment的方法中调用以下方法：onCreate()，onStart()，onResume()，onPause()，onStop()，onDestroy()，onSaveInstanceState(Bundle outState)和onLowMemory()，具体参考MapViewCodeDemoActivity.java。

下面以[MapFragment](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapfragment)为例简单介绍创建Map实例的步骤。

1\. 在Activity的布局文件中添加加一个fragment，并通过XML文件设置地图的属性。
      
      1. <fragment xmlns:android="http://schemas.android.com/apk/res/android"
        2.     xmlns:map="http://schemas.android.com/apk/res-auto"
        3.     android:id="@+id/mapfragment_mapfragmentdemo"
        4.     class="com.huawei.hms.maps.MapFragment"
        5.     android:layout_width="match_parent"
        6.     android:layout_height="match_parent"
        7.     map:cameraTargetLat="48.893478"
        8.     map:cameraTargetLng="2.334595"
        9.     map:cameraZoom="10" />
    
    

2\. 要在应用程序中使用地图，您需要实现[OnMapReadyCallback](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-onmapreadycallback)接口：
      
      1. public class MapFragmentDemoActivity extends AppCompatActivity implements OnMapReadyCallback {
        2.     ...
        3. }
    
    

3\. 在Activity的onCreate()方法中加载[MapFragment](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapfragment)，并调用[getMapAsync](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapfragment#getMapAsync\(OnMapReadyCallback\))()来注册回调。
      
      1. private MapFragment mMapFragment;
        2. mMapFragment = (MapFragment) getFragmentManager().findFragmentById(R.id.mapfragment_mapfragmentdemo);
        3. mMapFragment.getMapAsync(this);
    
    

4\. 在[onMapReady](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-onmapreadycallback#onMapReady\(HuaweiMap\))回调中获取[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-huaweimap)对象。
      
      1. public void onMapReady(HuaweiMap map) {
        2.     Log.d(TAG, "onMapReady: ");
        3.     hMap = map;
        4. }
    
    

5\. 运行您刚完成的工程就可以在您的APP中看到地图了。运行后的效果如下图所示：

# 3 地图类型

[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-huaweimap)目前支持两种地图类型：

  * MAP_TYPE_NORMAL：标准地图。展示道路，建筑物以及河流等重要的自然特征。

  * MAP_TYPE_NONE：没有加载任何数据的空地图。

# 4 我的位置

您可以开启“我的位置”功能向用户展示他们在地图上的当前位置，在使用该功能之前，请先确保您已申请定位权限。Android提供了两种位置权限： ACCESS_COARSE_LOCATION（粗略的位置权限） 和ACCESS_FINE_LOCATION（精确的位置权限）。需要在Manifest文件中申请权限：
      
      1. <uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION"/>
        2. <uses-permission android:name="android.permission.ACCESS_FINE_LOCATION"/>
    
    

在Manifest中添加后，还要在代码中动态申请一下权限(Android 6.0危险权限要求)：
      
      1. if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.M) {
        2.     Log.i(TAG, "sdk >= 23 M");
        3.     if (ActivityCompat.checkSelfPermission(this,
        4.         Manifest.permission.ACCESS_FINE_LOCATION) != PackageManager.PERMISSION_GRANTED
        5.         || ActivityCompat.checkSelfPermission(this,
        6.             Manifest.permission.ACCESS_COARSE_LOCATION) != PackageManager.PERMISSION_GRANTED) {
        7.         String[] strings =
        8.             {Manifest.permission.ACCESS_FINE_LOCATION, Manifest.permission.ACCESS_COARSE_LOCATION};
        9.         ActivityCompat.requestPermissions(this, strings, 1);
        10.     }
        11. }
    
    

调用[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-huaweimap)对象的[setMyLocationEnabled](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-huaweimap#setMyLocationEnabled\(boolean\))(true)方法以启用“我的位置”功能。
      
      1. @RequiresPermission(allOf = {ACCESS_FINE_LOCATION, ACCESS_WIFI_STATE})
        2. @Override
        3. public void onMapReady(HuaweiMap map){
        4.     hMap = map;
        5.     hMap.setMyLocationEnabled(true);//启用我的位置图层
        6.     hMap.getUiSettings().setMyLocationButtonEnabled(true);//启用我的位置按钮
        7.  }
    
    

在开启该功能后，“我的位置”按钮默认显示在地图的右下角，用户的定位会以蓝色圆点的形式呈现（图5）。当用户单击该按钮时，如果获取到用户的位置，将会在屏幕中心显示当前定位（图6）。如果开发者设置了“我的位置”按钮监听器，用户单击“我的位置”按钮时，会通过调用[HuaweiMap.OnMyLocationButtonClickListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-onmylocationbuttonclickl)的[onMyLocationButtonClick](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-onmylocationbuttonclickl#onMyLocationButtonClick\(\))()接口回调。

您也可以通过调用[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-huaweimap)对象的[getUiSettings](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-huaweimap#getUiSettings\(\))().[setMyLocationButtonEnabled](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-uisettings#%20setMyLocationButtonEnabled\(boolean\))(false)来隐藏“我的位置”按钮。

# 5 设置地图属性

您可以通过XML来配置地图的初始属性，也可以在代码中设置地图的初始属性并在之后动态更新其属性。

**XML方式设置**

华为地图SDK为[MapFragment](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapfragment)和[MapView](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapview)定义了一组自定义XML属性，您可以直接在布局文件中使用这些属性来配置地图的初始属性。

在使用这些属性之前，请确保您已经申明了下面的命名空间：
      
      1. xmlns:map="http://schemas.android.com/apk/res-auto"
    
    

接下来，您就可以使用以下属性来配置地图的初始属性了：

  * mapType：设置地图类型，有效值包括none和normal。

  * cameraTargetLat，cameraTargetLng：设置地图中心位置的经纬度。

  * cameraZoom：设置屏幕中心附近的缩放级别。

  * cameraBearing：设置地图的旋转角度，以正北方向为0度，顺时针旋转。

  * cameraTilt：设置相机的倾斜角度，即相机角度与垂直于地球表面直线的夹角。

  * uiZoomControls：设置缩放功能是否可以，默认可用。

  * uiCompass：设置指南针是否可以，默认可用。

  * uiZoomGestures，uiScrollGestures，uiRotateGestures，uiTiltGestures：设置缩放手势、滚动手势、旋转手势、倾斜手势是否可以，默认均可用。

  * zOrderOnTop：设置地图视图的表面是否放置在地图窗口的顶部，默认放置在地图窗口的顶部。

  * useViewLifecycle：仅对[MapFragment](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapfragment)有效，设置是否将地图的生命周期绑定到[MapFragment](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapfragment)的视图上或[MapFragment](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapfragment)本身。默认将地图的生命周期与[MapFragment](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapfragment)绑定在一起。

  * liteMode：设置地图是否为简洁模式。默认为否。

  * cameraMinZoomPreference，cameraMaxZoomPreference：设置偏好最小/最大缩放级别。

  * latLngBoundsSouthWestLatitude，latLngBoundsSouthWestLongitude，latLngBoundsNorthEastLatitude，latLngBoundsNorthEastLongitude：设置一个LatLngBounds来约束相机目标，使用户移动相机时，相机目标不会移出此边界范围。需要注意的是，latLngBoundsNorthEastLatitude不能小于latLngBoundsSouthWestLatitude。



      
      1. <fragment xmlns:android="http://schemas.android.com/apk/res/android"
        2.     xmlns:map="http://schemas.android.com/apk/res-auto"
        3.     android:id="@+id/mapfragment_mapfragmentdemo"
        4.     class="com.huawei.hms.maps.MapFragment"
        5.     android:layout_width="match_parent"
        6.     android:layout_height="match_parent"
        7.     map:cameraBearing="45"
        8.     map:cameraMaxZoomPreference="13"
        9.     map:cameraMinZoomPreference="3"
        10.     map:cameraTargetLat="48.893478"
        11.     map:cameraTargetLng="2.334595"
        12.     map:cameraTilt="20"
        13.     map:cameraZoom="10"
        14.     map:latLngBoundsNorthEastLatitude="49.893478"
        15.     map:latLngBoundsNorthEastLongitude="1.334595"
        16.     map:latLngBoundsSouthWestLatitude="47.893478"
        17.     map:latLngBoundsSouthWestLongitude="3.334595"
        18.     map:liteMode="false"
        19.     map:mapType="normal"
        20.     map:uiCompass="true"
        21.     map:uiRotateGestures="false"
        22.     map:uiScrollGestures="true"
        23.     map:uiTiltGestures="true"
        24.     map:uiZoomControls="false"
        25.     map:uiZoomGestures="true"
        26.     map:useViewLifecycle="true"
        27.     map:zOrderOnTop="true" />
    
    

  


**代码方式设置**

您也可以通过代码方式设置地图的初始属性，并在需要更新相机状态时重新设置这些属性。所以在XML中设置的属性都可以在代码中设置。
      
      1. MapFragment mMapFragment;
        2. CameraPosition cameraPosition = 
        3.     CameraPosition.builder().target(new LatLng(48.893478, 2.334595)).zoom(10).bearing(45).tilt(20).build();
        4. LatLng southwest = new LatLng(47.893478, 3.334595);
        5. LatLng northeast = new LatLng(49.893478, 1.334595);
        6. LatLngBounds latLngBounds = new LatLngBounds(southwest, northeast);
        7. HuaweiMapOptions options = new HuaweiMapOptions();
        8. options.mapType(HuaweiMap.MAP_TYPE_NORMAL)
        9.     .camera(cameraPosition)
        10.     .zoomControlsEnabled(false)
        11.     .compassEnabled(true)
        12.     .zoomGesturesEnabled(true)
        13.     .scrollGesturesEnabled(true)
        14.     .rotateGesturesEnabled(false)
        15.     .tiltGesturesEnabled(true)
        16.     .zOrderOnTop(true)
        17.     .useViewLifecycleInFragment(true)
        18.     .liteMode(false)
        19.     .minZoomPreference(3)
        20.     .maxZoomPreference(13)
        21.     .latLngBoundsForCameraTarget(latLngBounds);
        22. mMapFragment = MapFragment.newInstance(options);
    
    

# 6 简洁模式（暂不支持）  


**概览**

华为地图SDK的简洁模式可以将某一指定缩放级别和指定位置的静态地图图像展示给用户，由于简洁模式显示的是图片，部分常规地图的操作在简洁模式下不支持。简洁模式的应用场景有很多，例如：一个界面显示多个地图、朋友圈分享我的位置地图等。

下表展示了在简洁模式下华为地图SDK支持的功能列表。

**功能**| **支持情况**  
---|---  
[MapFragment](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapfragment)和[MapView](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapview)| 全部支持。  
我的位置| 全部支持。  
交互手势| 不支持。  
地图相机| 部分支持，不支持设置tilt和bearing，不支持动画方式移动地图相机。  
地图事件| 部分支持，仅支持点击和长按事件。  
地图类型| 部分支持，仅支持标准地图类型和空地图类型。

# 7 地图填充

华为地图是通过模拟相机的方式实现的，地图以目标位置为中心填充整个相机区域，地图控件（如指南针、缩放按钮和“我的位置”按钮）和华为标志放置在相机区域的边缘。默认情况下，指南针放置在相机右上角，缩放按钮和“我的位置”按钮放置在相机右下角，华为标志放置在相机左下角。

您可以通过[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-huaweimap).[setPadding](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-huaweimap#setPadding\(int,int,int,int\))(int left, int top, int right, int bottom)方法来设置地图控件和华为标志距离相机边缘的填充距离，具体效果如下：

  * left：设置华为标志距离相机左方边缘的填充距离，以像素为单位。

  * top：设置指南针距离相机上方边缘的填充距离，以像素为单位。

  * right：设置指南针、缩放按钮和“我的位置”按钮距离相机右方边缘的填充距离，以像素为单位。

  * bottom：设置缩放按钮、“我的位置”按钮和华为标志距离相机下方边缘的填充距离，以像素为单位。
