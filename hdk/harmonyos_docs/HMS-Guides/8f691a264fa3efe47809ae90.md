# 1 概览

该功能可用于在用户键入查询内容的时候，实时地返回建议的查询结果，从而实现查询预测效果。

# 2 实现步骤

1\. 声明[SearchService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchservice)对象，并通过[SearchServiceFactory](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchservicefactory)创建[SearchService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchservice)实例。

说明：

创建SearchService实例需要传入context和API key参数。context参数建议传入Activity类型，否则需要升级HMS Core（APK）时不会弹出升级界面。API key是开发者在[华为开发者联盟](https://developer.huawei.com/consumer/cn)创建应用时生成的API key，注意需要对API key进行encodeURI编码。

  


2\. 构建[QuerySuggestionRequest](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-querysuggestionrequest)对象，它是周边搜索的请求体。其中query是必选参数，其余可选：

  * query：搜索关键字。

  * location：搜索结果偏向的经纬度。

  * radius：搜索半径，单位是米，可选项。默认值是50公里，取值范围是1米-50公里。

  * bounds：搜索结果偏向的范围。

  * poiTypes：指定返回指定POI类型的地点。取值包括：    


**字段**| **描述**  
---|---  
GEOCODE| 仅返回地理编码结果（如国家、城市、街道等），而不返回商业结果（如酒店、餐馆、火车站等）。可以使用此类型过滤掉商业数据，消除用户输入中存在的歧义。例如：用户输入中国时，返回中国，不返回中国银行等数据。  
ADDRESS| GEOCODE的子集。仅返回具有精确地址的地理编码结果，不返回商业结果和粗粒度的地理编码结果（如国家、城市等），推荐在搜索完整地址时使用此类型。  
ESTABLISHMENT| GEOCODE的补集。仅返回作为商业结果（如酒店、餐馆、火车站等），不返回地理编码结果（如国家、城市、街道等）。例如：用户输入中国时，返回中国银行等数据，不返回中国。  
REGIONS| GEOCODE的子集，仅返回与以下类型匹配的地点：LOCALITYSUBLOCALITYPOSTAL_CODECOUNTRYADMINISTRATIVE_AREA_LEVEL_1ADMINISTRATIVE_AREA_LEVEL_2  
CITIES| 仅返回LOCALITY或 ADMINISTRATIVE_AREA_LEVEL_3类型的地点。  
  
  * countryCode：在指定的国家内搜索，采用ISO 3166-1 alpha-2。

  * language：搜索结果的语种，取值范围参考[语种映射](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/hms-site-language)的语种代码。如果不传，使用query字段的语种或者地点的当地语言，query字段的语种优先。

  * politicalView：政治观点参数，采用ISO 3166-1-alpha-2规范的2位国家码。  





注意：

如果bounds、location都传入的话，那么bounds优先。

3\. 创建[SearchResultListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchresultlistener)对象，该对象用来监听搜索结果。

4\. 通过第1步创建的[SearchService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchservice)对象调用querySuggestion()接口，传入第2步创建的[QuerySuggestionRequest](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-querysuggestionrequest)对象和第3步创建的[SearchResultListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchresultlistener)对象。

5\. 通过第3步创建的[SearchResultListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchresultlistener)对象获取搜索结果[QuerySuggestionResponse](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-querysuggestionresponse)对象，可从中获[Site](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-site)列表，解析具体的地址信息。

示例代码如下：
      
      1. // 声明SearchService对象 
        2. private SearchService searchService; 
        3. // 创建searchService实例 
        4. searchService = SearchServiceFactory.create(this, "API key"); 
        5. // 创建请求体 
        6. QuerySuggestionRequest request = new QuerySuggestionRequest(); 
        7. request.setQuery("Paris"); 
        8. Coordinate location = new Coordinate(48.893478, 2.334595); 
        9. request.setLocation(location); 
        10. request.setRadius(1000); 
        11. request.setCountryCode("FR"); 
        12. request.setLanguage("fr"); 
        13. // 创建搜索结果监听器 
        14. SearchResultListener<QuerySuggestionResponse> resultListener = new SearchResultListener<QuerySuggestionResponse>() { 
        15.     // 正常结果返回 
        16.     @Override 
        17.     public void onSearchResult(QuerySuggestionResponse results) { 
        18.         List<Site> sites = results.getSites(); 
        19.         if (results == null ||  sites == null || sites.size() <= 0) { 
        20.             return; 
        21.         } 
        22.         for (Site site : sites) { 
        23.             Log.i("TAG", String.format("siteId: '%s', name: %s\r\n", site.getSiteId(), site.getName())); 
        24.         } 
        25.     } 
        26.     //异常结果返回 
        27.     @Override 
        28.     public void onSearchError(SearchStatus status) { 
        29.         Log.i("TAG", "Error : " + status.getErrorCode() + " " + status.getErrorMessage()); 
        30.     } 
        31. }; 
        32. // 调用地点搜索建议接口 
        33. searchService.querySuggestion(request, resultListener);
