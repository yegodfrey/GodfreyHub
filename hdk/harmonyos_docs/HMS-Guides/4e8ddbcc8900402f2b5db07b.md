使用React Native，您必须在电脑上安装Python2.X、Node和Android Studio。

注意：JDK版本必须是1.8或以上。

  * **安装Python 2.X**




React Native要求必须安装Python2.X。

具体的安装和配置方法，请访问[**Python官网**](https://www.python.org/)。

  * **安装Node.JS.**




需要安装Node.JS（以及npm）。您可以从[**NodeJS官网**](https://nodejs.org/en/)下载并安装NodeJS。优先选择TLS版本的NodeJS。

安装NodeJS后，在其中安装如下两个工具：

react-native：如果需要使用原生Android模块的源代码，则需安装该工具。
    
    
    复制
      
        1. npm install -g react-native
    
    

（可选）react-native-create-library：用于生成原生的react-native模块。
    
    
    复制
      
        1. npm install -g react-native-create-library
    
    

  * **安装Android Stuido**




具体的安装和配置方法，请访问[**React Native官网**](https://reactnative.dev/docs/getting-started/)。

请特别注意如下事项：

  * 下载Android SDK 10.0 （API Level 29）和9.0（API Level 28）：

进入**设置 > Android SDK > SDK平台**，选择Android 10.0和Android 9.0，点击“确定”。Android Studio会自动下载并安装Android SDK 10.0 （API Level 29）及9.0（API Level 28）。

  * 配置环境变量 _ANDROID_HOME_ 。

打开Windows控制面板，进入**System and Security > System > Change settings > Advanced > Environment Variables > New**，创建指向您Android SDK目录的系统或用户变量 _ANDROID_HOME_ 。




说明：

  * Android SDK默认安装在 _C:\Users\Your_Username\AppData\Local\Android\Sdk_ 目录下。

  * 如需查看Android SDK所处的路径，您可以打开Android Studio，进入**File > Settings**。然后进入**Appearance & Behavior > System Settings > Android SDK**，点击右侧窗格中的**Android SDK Location** 。




  * 在 _Path_ 下添加 _platform-tools_ 目录。

打开Windows控制面板，进入**System and Security > System > Change settings > Advanced > Environment Variables**。选择变量 _Path_ ，然后点击**Edit** 。点击**New** 并将 _platform-tools_ 目录添加至列表。




说明：

目录 _platform-tools_ 位于目录**Android SDK** 中。在上一步配置完变量 _ANDROID_HOME_ 后，将**%ANDROID_HOME%\platform-tools** 添加到变量**Path** 。
