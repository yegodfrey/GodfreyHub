# **Fido 4.0.3****版本（2020-4-15）**

最新子版本号： 4.0.3.300

#### **新增特性**

1\. 新增FIDO2客户端 API：提供基于WebAuthn标准的FIDO2客户端 API。

2\. 新增BioAuthn版本指纹识别 API：首先进行系统完整性检测，检测通过再进行指纹识别。应用在不兼容AndroidX的场景。

3\. 新增BioAuthn版本3D面容识别 API：首先进行系统完整性检测，检测通过再进行3D面容识别。应用在不兼容AndroidX的场景。

# **Fido 4.0.0****版本（2020-1-15）**

最新子版本号： 4.0.0.300

华为线上身份快速验证服务推出了全新的HMS SDK 4.0.0版本，提供BioAuthn-AndroidX生物特征认证能力，欢迎广大开发者接入。

#### **新增特性**

1\.   新增BioAuthn-AndroidX版本指纹识别 API：首先进行系统完整性检测，检测通过再进行指纹识别。

2\.   新增BioAuthn-AndroidX版本3D面容识别 API：首先进行系统完整性检测，检测通过再进行3D面容识别。

# **SDK****依赖说明：**

1.FIDO2客户端SDK，需要用户设备上安装HMS Core 4.0.3.300及以上版本。如果用户设备没有安装，您的应用调用HMS Core时，会自动引导用户提示安装。

2.本版本BioAuthn SDK，BioAuthn-AndroidX版本需要用户设备上安装HMS Core 4.0.0.300及以上版本；BioAuthn版本需要用户设备上安装HMS Core 4.0.3.300及以上版本。如果用户设备没有安装，您的应用调用HMS Core时，会自动引导用户提示安装。

3.本服务的主要特性都可以在大多数华为终端上支持，部分高级特性依赖于EMUI版本。请参考[部分特性对于EMUI的依赖说明](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/emui_version_dependent_features)。

提示：您的应用在华为应用市场上架过程中，如有问题可发送邮件至HMSCore@huawei.com咨询。
