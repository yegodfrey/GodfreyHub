以下为一些常见的页面元素示例供开发者参考。

  * **自定义标题**




定义文本信息为“title”变量。在layout文件中配置如下示例：
    
    
    复制
      
        1. <TextView  
        2.     android:layout_marginStart="10sp"  
        3.     android:layout_toEndOf="@+id/back_img"  
        4.     android:layout_width="match_parent"  
        5.     android:layout_height="match_parent"  
        6.     android:gravity="center_vertical"  
        7.     android:text="@string/title"  
        8.     android:textAllCaps="false"  
        9.     android:textColor="#FFFFFF"  
        10.     android:textSize="20sp"  
        11.     android:textStyle="bold" />
    
    

  * **自定义返回按钮**




定义id为“back_img”的页面视图，并且绑定点击返回操作。在layout文件中配置如下示例：
    
    
    复制
      
        1. <ImageView  
        2.     android:id="@+id/back_img"  
        3.     android:layout_width="48dp"  
        4.     android:layout_height="48dp"  
        5.     android:padding="12dp"  
        6.     android:layout_alignParentStart="true"  
        7.     android:layout_marginStart="12dp"  
        8.     android:layout_marginTop="4dp"  
        9.     android:gravity="center"  
        10.     android:src="@drawable/back" />
    
    

在自定义的activity中绑定返回操作示例：
    
    
    复制
      
        1. private void setBackOperation() {  
        2.     backBtn = findViewById(R.id.back_img);  
        3.     backBtn.setOnClickListener(new View.OnClickListener() {  
        4.         @Override  
        5.         public void onClick(View v) {  
        6.             DefinedActivity.this.finish();  
        7.         }  
        8.     });  
        9. }
    
    

  * **自定义闪光灯按钮**  





定义闪光灯按钮的页面视图，并且绑定开启关闭操作。在layout文件中配置如下示例：
    
    
    复制
      
        1. <ImageView  
        2.     android:id="@+id/flush_btn"  
        3.     android:layout_width="48dp"  
        4.     android:layout_height="48dp"  
        5.     android:layout_alignParentBottom="true"  
        6.     android:layout_centerHorizontal="true"  
        7.     android:visibility="gone"  
        8.     android:gravity="center"  
        9.     android:src="@drawable/flashlight_off" />
    
    

在自定义的activity中绑定闪光灯按钮操作示例：  

    
    
    复制
      
        1. private void setFlashOperation() {  
        2.     flushBtn.setOnClickListener(new View.OnClickListener() {  
        3.         @Override  
        4.         public void onClick(View v) {  
        5.             if (remoteView.getLightStatus()) {  
        6.                 remoteView.switchLight();  
        7.                 flushBtn.setImageResource(img[1]);  
        8.             } else {  
        9.                 remoteView.switchLight();  
        10.                 flushBtn.setImageResource(img[0]);  
        11.             }  
        12.         }  
        13.     });  
        14. }
    
    

  * **自定义扫码界面**  





绘制扫码框，在layout文件中配置如下示例：
    
    
    复制
      
        1. <RelativeLayout  
        2.     android:layout_width="match_parent"  
        3.     android:layout_height="match_parent">  
        4.     <ImageView  
        5.         android:layout_width="match_parent"  
        6.         android:layout_height="match_parent"  
        7.         android:layout_centerInParent="true"  
        8.         android:layout_centerHorizontal="true"  
        9.         android:background="#FF000000"  
        10.         android:alpha="0.1" />  
        11.     <TextView  
        12.         android:layout_marginTop="225dp"  
        13.         android:layout_centerHorizontal="true"  
        14.         android:text="@string/scan_tip"  
        15.         android:textAllCaps="false"  
        16.         android:textColor="#FFFFFF"  
        17.         android:textSize="15sp"  
        18.         android:textStyle="bold"  
        19.         android:layout_height="20dp"  
        20.         android:layout_width="220dp" />  
        21.     <!-- 设置扫码框-->  
        22.     <ImageView  
        23.         android:layout_width="300dp"  
        24.         android:layout_height="300dp"  
        25.         android:layout_centerInParent="true"  
        26.         android:layout_centerHorizontal="true"  
        27.         android:background="@drawable/cloors" />  
        28. </RelativeLayout>
    
    

实现扫码框边框样式样例：
    
    
    复制
      
        1. <?xml version="1.0" encoding="utf-8"?>

        7.     <solid android:color="#1f00BCD4"/>  
        8.     <!-- 设置圆角 -->  
        9.     <corners android:radius="5dip"/>  
        10.     <!-- 设置内边距 -->  
        11.     <padding  
        12.         android:left="2dp"  
        13.         android:top="2dp"  
        14.         android:right="2dp"  
        15.         android:bottom="2dp" />  
        16. </shape>
