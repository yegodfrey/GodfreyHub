# 1 概述

## 1.1 简介

华为钱包Wallet Kit是集成了终端“芯-端-云”全栈技术的开放能力，可实现卡、证、券、票、钥匙等各类凭证电子化。让用户能够轻松地将或门票、登机牌、会员卡、优惠劵、礼品卡保存在手机中，以便在适当的时间使用，同时app提供通过基于位置的通知、实时动态更新、NFC能力与用户进行互动。

## 1.2 支持的业务场景

  * 会员卡、礼品卡、优惠券




用户将会员卡（Loyalty Cards）、礼品卡(Gift Cards)、优惠券(Coupons)保存在华为钱包后，即可通过钱包及时了解品牌活动、会员权益和积分变化。

  * 航空出行




用户将登机牌（Boarding Passes）保存至华为钱包后，开发者即可在华为钱包设置自动通知和提醒功能，确保乘客及时收到航班的重要信息。

  * 智慧门票




用户将活动门票（Event Tickets）保存至华为钱包后，可在钱包查看已购买的门票活动信息，系统支持给用户发送实时的智能提醒。使用时，无需打开App，通过双击电源键、负一屏等即可轻松调出门票。针对支持NFC技术的商户，基于华为智闪黑科技，给用户带来“熄屏碰一碰”刷开安检闸机的畅快体验。

  * 社区门禁卡




用户将门禁卡模拟到华为钱包，并将该卡片设置为默认卡后，在不打开手机和App的情况下即可享受“熄屏碰一碰”刷卡开门的极致体验。提供NFC白卡开放能力，与社区服务提供商一起快速实现“社区智能卡”功能。

  * 园区一卡通




手机作为园区一卡通载体相比物理卡片更便捷，且基于华为手机“芯-端-云”一体化的安全能力。提供NFC白卡开放能力，与园区服务提供商一起快速实现“园区智能卡”功能。

  * 智能门锁




通过将手机与家用/酒店房门所安装的智能门锁进行配对后，手机可以当做家门钥匙和酒店房卡，通过NFC的方式打开房门。

  * 车钥匙




相比传统车钥匙，使用手机作为车钥匙载体更适用于钥匙分享等新业务场景。结合国内车厂的业界现状，可以快速实现手机车钥匙功能。

## 1.3 优势与亮点

  * 一键添加：提供邮件、短信、APP、浏览器、Webview、SDK等多种接入方式，用户仅需点击按钮或链接一键添加卡片到华为钱包。

  * 快速接入：4步（注册，认证，配置服务，开发应用），少量开发即可上线服务。

  * 精准触达：基于时间、位置、wifi和nearby的精准实时智能提醒 。

  * 便捷使用：支持指纹、双击电源键、设置主屏图标（homescreen icon）、APP图标点击、熄屏刷卡等多种使用方式，并支持基于协议、位置和AI的智闪卡（AI Select）功能。

  * 全球覆盖：全球覆盖170+国家和地区。




# 2 接入流程概述

钱包服务提供两种卡劵接入方式：

  * **方式一： 网页、短信、Email、App应用内领取卡劵**


步骤| 分类| 动作| 用途说明  
---|---|---|---  
1| 开发准备| [配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/wallet-preparations-agc)| 配置申请Wallet Kit相关服务。  
2| [网页、短信、Email、App应用内方式生成安全密钥](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/wallet-preparations-scret)| 使用安全秘钥加密JWE数据。  
3| [服务创建](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/wallet-preparations-server)| 创建Wallet Kit服务。  
4| 卡劵接入| [卡劵接入场景](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/wallet-guide-uistrings-loyaltycard)| 开发者可根据需要选择适合自己的接入形式，当前支持会员卡、礼品卡、优惠券、活动门票、登机牌、交通车票、一卡通。  
5| 开发后自检| [开发后自检](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/wallet-guide-checktool)| 华为提供对应用自动检查的能力。  
6| 上架申请| [上架申请](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/wallet-guide-apprelease)| 开发完成后需要在AppGallery  Connect中将应用信息补充完整并提交上架申请。  
  
  * **方式二：App应用内、快应用、华为钱包CardStore方式领取卡劵**


步骤| 分类| 动作| 用途说明  
---|---|---|---  
1| 接入准备| [配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/wallet-preparations-agc)| 配置申请Wallet  Kit相关服务。  
2| [App应用内、快应用、华为钱包CardStore方式证书申请](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/wallet-preparations-scret)| 通过证书来签名卡劵包。  
3| [服务创建](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/wallet-preparations-server)| 创建Wallet Kit服务。  
4| 卡劵接入| [卡劵接入场景](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/wallet-guide-uistrings-loyaltycard)  
| 开发者可根据需要选择适合自己的接入形式，当前支持会员卡、礼品卡、活动门票、登机牌、电影票、门钥匙、一卡通、车钥匙、酒店、家用门锁。  
5| 开发后自检| [开发后自检](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/wallet-guide-checktool)| 华为提供对应用自动检查的能力。  
6| 上架申请| [上架申请](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/wallet-guide-apprelease)| 开发完成后需要在AppGallery  Connect中将应用信息补充完整并提交上架申请。
