# 1 AppGallery Connect配置

在开始开发应用前，需要在AppGallery Connect中配置相关信息。

## 1.1 注册成为开发者

在开发应用前需要在[华为开发者联盟](https://developer.huawei.com/consumer/cn)网站上注册成为开发者并完成实名认证，当前只有“开发者类型”为“企业开发者”的合作伙伴才能开通WisePlay DRM服务。具体方法可参考“[帐号注册认证](https://developer.huawei.com/consumer/cn/devservice/doc/20300)”。

## 1.2 创建应用

参见AppGallery Connect帮助中心的[创建应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-create_app)章节创建应用，配置如下：

  * “软件包类型”：选择“APK(Android应用)”

  *  “支持设备”：选择“手机”

  *  “应用分类”：选择“应用”                                   




## 1.3 申请集成和开通数字版权服务

如果您希望集成和开通WisePlay DRM服务，请通过如下方式获取技术支持和WisePlay DRM业务开通指导：

**线下申请** ：请直接联系您的线下客户经理或者支持工程师，申请集成和开通WisePlay DRM服务；

**工单申请** ：在线填写工单申请开通，请注明“申请集成和开通WisePlay DRM服务”，工单提交请参考：<https://developer.huawei.com/consumer/cn/support/feedback>；

**邮件申请** ：发送申请集成和开通WisePlay DRM服务 的邮件到华为客服邮箱（邮件主题请注明：WisePlay DRM application），邮箱地址请参考<https://developer.huawei.com/consumer/en/hms>页面下“Contact HUAWEI Developer”的联系方式。

## 1.4 开通数字版权管理服务

查看“开发 > 构建 > 数字版权服务”页面的服务状态，如果服务状态为未开通，请点击“开通”按钮开通华为数字版权服务。
