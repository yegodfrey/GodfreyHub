# 1\. 概述

API key是一种访问华为服务的简单凭证，长期有效（请开发者妥善保管），在华为开发者联盟的[API Console](https://developer.huawei.com/consumer/cn/console#/credentials/projectKey=dev7519896637536769923)上创建生成，开发者可直接通过此凭证调用支持此类鉴权的华为公开API。

# 2\. 获取API密钥

开发者可直接从在华为开发者联盟的[API Console](https://developer.huawei.com/consumer/cn/console#/credentials/projectKey=dev7519896637536769923)上创建生成，具体步骤及支持此类鉴权的公开API类型表，请参考《[API Console操作指南](https://developer.huawei.com/consumer/cn/doc/start/api-console-guide#h2-1582599047826-0)》。

# 3\. 调用华为公开API

应用调用华为公开API时，把生成的API key密钥作为请求参数来进行鉴权。

示例：
    
    
    复制
      
        1. GET /v1/demo/indexes?key=CV3X1%2FJG7mdNZm03l9puvwPAktmfw1aj8XvBb6sm696MqoW57ehnUC 
        2. Host: oauth-api.cloud.huawei.com
