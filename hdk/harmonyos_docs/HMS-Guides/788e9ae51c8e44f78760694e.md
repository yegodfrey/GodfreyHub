# FAQ

#### SDK 集成常见问题

**[问题一］调用DataManager或****DataController read方法进行数据查询的时候，一直返回为空是什么原因？**

  * 在排除查询数据确实为空的情况下，一种可能的原因是用户对APP请求读取的数据类型没有授权，因此无法获取。 
  * 如果依然无法解决问题，请联系华为接口人协助定位。 



**[问题二］scope权限配置正确的情况下，通过BleManager或BleController的beginBleScan方法，扫描不到蓝牙设备，****是什么原因？**

蓝牙设备扫描依赖位置信息，APP须配置位置权限申请，并确认手机打开位置信息。

**[问题三］写入多个时间区间有交集的数据，实际查询的数据不一致是什么原因？**

写入数据点时间区间存在交集时，数据层会对交叉数据做业务逻辑处理；如果差异过大，与预期严重不符，请联系华为接口人协助定位。

**[问题四］调用接口时返回50005错误码“鉴权未知错误”，是什么原因？**

  1. 端侧用户授权操作前，要确保运动健康数据审核申请通过，否则端侧即使用户授权，该三方应用依然无权限操作用户数据。 
  2. 应用所能操作的用户授权的数据，必须包含在运动健康数据审批数据和端侧应用申请数据的交集，否则应用也无权限操作该数据。 
  3. HMS 会对 Scope 权限信息进行缓存，缓存时长为24小时。如果出现此错误，可能是缓存原因导致。 
     1. 在手机“应用管理”里清除“HMS Core”的缓存和数据。 
     2. 在“华为帐号 > 隐私中心 > 控制对您帐号的访问”里取消对 APP 的授权，然后重新打开 APP 登录华为帐号并申请授权**。**
     3. 如果按照以上步骤操作后，调用接口仍然返回50005错误码，请联系华为接口人协助定位。 



**[问题五］基于 Health Kit 的不同三方应用是否共用同一份传感数据，增删改查数据是否相互受影响？**

  1. 不同三方应用读取到的传感数据后，处理产生的数据隔离记录在端侧的数据仓库中，增删改查互不影响。 
  2. 不同三方应用产生的数据会定时自动同步到云端服务器隔离存储，云端对这些三方应用数据进行融合算法进行归约，产生该账户的融合数据，不同端侧应用经用户授权可以查询该融合数据。 
  3. Health Kit 端和云的数据仓库是数据处理者，基于 Health Kit 的三方应用才是数据控制者。 



#### Restful 集成常见问题

**[问题一] 调用接口的时候，报错信息为“Invalid Credentials”，是什么原因？**

此种情况是token无效时调用API接口返回的提示信息，请按以下情况进行排查:

  1. 确认申请token的方式是否采用了[开放平台鉴权](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/30101) \--- **授权码模式。**
  2. 确认申请token时的操作是否与获取的token标准步骤一致。 
  3. 确认该token是否已经过期。 



**[问题二] 调用接口的时候，报错信息为“Insufficient Permission: Request had insufficient authentication scopes.”，该怎么解决？**

Health Kit中的数据进行读写时都需要有对应的权限，该提示信息为操作该接口时scope权限不足，需要先赋予该请求对应的权限才能进行后续操作。比如用户需要创建一个数据类型为com.huawei.instantaneous.steps.rate的数据源，则必须拥有对应的写权限，即至少拥有下列两种类型中的一种：

“https://www.huawei.com/healthkit/step.write”

“https://www.huawei.com/healthkit/step.both”。

**[问题三] 配置正确的情况下，请求的响应为代码为“400”“Bad Request”“invalidArgument”，可能有哪些原因？**

此类型响应说明发送的请求内参数有误，如果URL中包含用户输入的请求参数，请检查相关输入是否符合参数规范，如果请求中存在请求体，还需要检查对应的参数格式及类型是否符合相关的参数要求。

**[问题四］创建数据时，提示“Application package name (xxx) provided by un-trusted source.”，需要如何处理？**

说明此时填入的应用名称未在开发者联盟进行注册，请申请并通过后再使用该应用名称进行相关操作。
