# **1.系统特性**  


检测尝试连接的WIFI及路由器特征，分析当前尝试访问的网络情况，通过聚类分析，实时反馈Wifi检测结果，帮助开发者防范来自恶意Wifi的恶意行为攻击。

# **2.典型场景**

开发者集成WifiDetect接口，当应用获取尝试连接的WIFI存在ARP攻击、中间人攻击、DNS劫持等攻击时，开发者可以阻断操作或者进一步让用户认证确认。

# **3.开发流程**

请参考：[开发流程](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/SafetyDetectDevelopment)

# **4.应用开发**

使用 Safety Detect WifiDetect API 之前，必须确保在用户设备上安装了正确版本的 HMS 服务。如果安装了不正确的版本，则您的应用可能会在调用 API 后停止响应。如果您的应用检测到安装了错误的版本，则应要求用户在其设备上更新 HMS。

要检查已安装的 HMS 版本是否与您使用的Android SDK版本兼容，请调用[ isHuaweiMobileServicesAvailable()](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/huaweiapiavailability) 方法，如以下代码片段所示：
      
      1. if (HuaweiApiAvailability.getInstance().isHuaweiMobileServicesAvailable(context) == ConnectionResult.SUCCESS){
        2. // The SafetyDetect SysIntegrity API is available.
        3. } else {
        4. // Prompt user to update HMS.
        5. }
