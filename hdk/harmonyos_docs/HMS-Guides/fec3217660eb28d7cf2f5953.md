# **Game Service 4.0.0版本（2020-01-15）**

最新子版本号：4.0.0.300

### 新增特性

  1. 增加排行榜接口。

  2. 增加游戏存档相关接口。

  3. 增加玩家信息统计相关接口。

  4. 增加游戏基本信息获取相关接口。




### 修改特性

  1. 原有的浮标接口替换为BuoyClient接口。

  2. 原有的防沉迷接口替换为PlayersClient.submitPlayerEvent和PlayersClient.getPlayerExtraInfo。

# SDK依赖说明

  1. 本版本SDK需要用户手机上安装HMS Core 4.0.0.300及以上版本； 如果用户手机没有安装，您的应用调用HMS Core时，会自动引导用户提示安装。

  2. 本服务的主要特性都可以在大多数华为终端上支持，部分高级特性依赖于EMUI版本。请参考[部分特性对于EMUI的依赖说明](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/emui_version_dependent_features)。

  3. 提示：您的应用在华为应用市场上架过程中，如有问题可发送邮件至[HMSCore@huawei.com](mailto:HMSCore@huawei.com)咨询。
