# 1\. 使用场景

媒体APP、广告平台、三方监测平台等开发者，可集成Ads Kit的SDK获取华为设备上的OAID，开发者可基于OAID进行个性化广告推荐或广告转化归因分析。

# 2\. 注意事项

  1. 获取OAID信息前，确保APP必须已经集成ads-identifier SDK，参见[开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/19068235 "开发准备")。

  2. 调用getAdvertisingIdInfo接口，获取OAID信息，不要在主线程中调用该方法。

  3. 开发者不可以缓存使用OAID信息，以保护用户个人数据的隐私安全。




# 3\. 开发步骤

创建子线程，并调用静态的AdvertisingIdClient.getAdvertisingIdInfo(mContext)方法获取OAID信息，代码示例如下：
    
    
    复制
      
        1. /**
        2.  * 在非UI线程获取设备标识信息
        3.  */

        5.     @Override
        6.     public void run() {
        7.         try {
        8.             AdvertisingIdClient.Info info = AdvertisingIdClient.getAdvertisingIdInfo(mContext);
        9.             if (null != info) {
        10.                 Log.i(TAG, "info id=" + info.getId() +
        11.                         ", isLimitAdTrackingEnabled=" + info.isLimitAdTrackingEnabled());
        12.             }
        13.         } catch (IOException e) {
        14.             Log.i(TAG, "getAdvertisingIdInfo Exception: " + e.toString());
        15.         }
        16.     }
        17. };
