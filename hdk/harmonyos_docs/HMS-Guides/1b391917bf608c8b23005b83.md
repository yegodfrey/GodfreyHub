ML Kit提供两种集成SDK方式，您可以参见[概述（Full SDK和基础SDK）](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-sdk-overview)，根据您的应用场景选择不同的集成方式。

# 方式一：Full SDK方式集成（推荐使用）

先集成SDK基础包，再集成所需的模型包，模型包信息如下：

**包类型**| **包名**| **SDK****大小**| **坐标名称**  
---|---|---|---  
多类别分割模型包| ml-computer-vision-image-segmentation-multiclass-model| 4.5M| com.huawei.hms:ml-computer-vision-image-segmentation-multiclass-model:1.0.4.301  
人像分割模型包| ml-computer-vision-image-segmentation-body-model| 2.9M| com.huawei.hms:ml-computer-vision-image-segmentation-body-model:1.0.4.301  
  
集成图像分割服务的模型包时，集成的包的大小会大于上述表格所示的大小，因为集成图像分割服务的模型包时会同时自动下载图像分割算法包（约3.3M）。如果开发者主要使用人像分割服务，建议引用人像分割模型包。

Full SDK方式集成的示例代码如下：
      
      1. dependencies{   
        2.     // 引入基础SDK  
        3.     implementation 'com.huawei.hms:ml-computer-vision-segmentation:1.0.4.301'     
        4.     // 引入多类别分割模型包  
        5.     implementation 'com.huawei.hms:ml-computer-vision-image-segmentation-multiclass-model:1.0.4.301'  
        6.     // 引入人像分割模型包  
        7.     implementation 'com.huawei.hms:ml-computer-vision-image-segmentation-body-model:1.0.4.301'  
        8. }
    
    

# 方式二：基础SDK方式集成

示例代码如下：
      
      1. dependencies{ 
        2.     implementation 'com.huawei.hms:ml-computer-vision-segmentation:1.0.4.301' 
        3. }
    
    

# 在文件头添加配置

用上述两种方法之一集成SDK后，在文件头添加配置。
      
      1. apply plugin: 'com.huawei.agconnect'
    
    

# 

注意：

此项配置需要在如下配置项后添加。
      
      1. apply plugin: 'com.android.application'
    
    

# 自动更新机器学习模型  


添加如下语句到AndroidManifest.xml文件中，用户从华为应用市场安装您的应用后，将自动更新机器学习模型到设备：
      
      1. <manifest 
        2.     ... 
        3.     <meta-data              
        4.         android:name="com.huawei.hms.ml.DEPENDENCY"   
        5.         android:value= "imgseg"/> 
        6.     ... 
        7. </manifest>
