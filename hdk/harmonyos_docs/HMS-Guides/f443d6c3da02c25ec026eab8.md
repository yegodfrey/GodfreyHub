# 视频内容加密流程介绍

SP服务侧如果不具备MultiDRM能力，可以参考本章节构建自己的MultiDRM，华为开发者联盟提供密钥管理系统（KMS）样例代码可帮助SP快速构建MultiDRM能力。

华为提供KMS的样例代码，样例代码能够提供生成密钥和管理密钥的能力，以及生成WisePlay DRM加密索引信息的逻辑。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200115180419.93721087940419604078794023971967:50510328072808:2800:3125A417A18E055EC9512E9DDDB6DC09FD7A6EDE65F3F53C7CF413CB69B46F96.png)

视频内容加密流程如下：

  1. 视频运营平台向编码器下发创建内容编码任务，传递ContentID和加密类型等参数；

  2. 编码器根据加密类型判断视频是否加密，如果是加密视频则调用getKeyInfo接口向KMS请求获取内容加密key、keyid、pssh box信息；

  3. KMS会生成加密密钥、pssh box信息，建立keyid和ContentID的对应关系，KMS会持久化Key信息，加密保存在数据库；

  4. 编码器从KMS获取密钥后，对内容进行转码和加密，视频分片使用AES-128-CTR/CBC方式加密，将pssh box信息写入到索引文件中；

说明：如果需要支持MutliDRM，则生成不同DRM类型的pssh box信息，并将它们都写到索引文件中。  


  5. 编码器对视频内容转码加密后，视频内容注入到CDN源站。

## 2 编码器支持调用KMS接口获取视频加密信息

编码器需要对一个内容进行编码时，可以调用KMS的getkeyInfo接口，KMS生成内容密钥、keyid、pssh box等信息，同时将内容密钥、keyid等信息存储在KMS的数据库中，然后将KeyInfo、ContentInfo、PSSH Box信息全部返回给编码器。
