# 4\. 配置签名证书指纹  


## 4.1 生成签名证书指纹

签名证书指纹用于在通过华为HMS SDK访问HMS Core的能力时，校验应用的真实性。开发者在使用HMS SDK服务前必须将签名证书指纹配置到华为开发者联盟，在配置前需要根据签名证书在本地生成签名证书指纹。

 在申请前需要满足以下2个条件：

● 已创建应用程序的签名文件，签名证书创建属于通用技术，此处不详细描述。

● 当前开发的PC已经安装JDK。

操作步骤如下：

1. 打开命令行工具（使用CMD命令），执行cd命令进入keytool.exe所在的目录（图中样例为PC上java程序安装在C盘的Program Files (x86)目录）。

 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191213195538.61244464101047463534869198378121:50510721070155:2800:BF2166C3DE7A3C5B8EF1A8946B38D496C0F8BBE82C39B5BE369CB9CC525F6B99.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

2\. 执行命令keytool -genkey -alias _android_test_key_  -keyalg _RSA_  -keystore _< keystore-file>_，按命令提示进行生成签名文件。

-alias **android_test_key** ，这里"**android_test_key** "为别名，可以是任意字符，只要不提示错误即可。

-keyalg **RSA** ，这里"**RSA** "为密钥的算法。

-keystore **< keystore-file>**，这里**< keystore-file>**为应用签名文件的完整路径。
      
      1. keytool -list -v –keystore E:\Android.keystore
    
    

3. 根据结果获取对应的SHA256指纹。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200312103158.97315164508282170026903791006241:50510721070155:2800:D1E0F357932F9A5B83548178B8B473D94EE98042AEEE3F3ADE007CBE5BE12F2A.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

# 6. 集成 HMS SDK

## 6.1 在Android Studio项目集成HMS SDK  


针对AndroidStudio开发环境，华为提供了maven仓集成方式的HMS SDK包。在开始开发前，您需要将HMS SDK集成到您的AndroidStudio开发环境中。

1\. 在AndroidStudio开发环境中添加当前应用的AppGallery Connect配置文件。   


a. 登录[AppGallery Connect 网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择“我的项目”。

b. 在项目列表中找到您的项目，在项目中点击需要集成HMS SDK的应用。

c. 在“项目设置”页面中，单击“应用”栏下的“agconnect-services.json”下载配置文件。

d. 将“agconnect-services.json”文件拷贝到应用级根目录下。

  


![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191213201030.55067726451434484186437836233071:50510721070155:2800:3BA10421EA5ABDCB95CE7E91CE8FDEBA98405D2E225D32615A375634BEBB140E.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

2. 配置HMS SDK的maven仓地址。

    (1). 打开AndroidStudio项目级build.gradle文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191213201112.55344323894685217473051859430942:50510721070155:2800:DD5940361FA1E419C04888147F10D43361858AD373A1EB6D7DF8C21E2225FCA2.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

    (2). 在allprojects ->repositories 里面配置HMS SDK的maven仓地址。
      
      1. allprojects {
        2.     repositories {
        3.         google()
        4.         jcenter()
        5.         maven {url 'https://developer.huawei.com/repo/'}
        6.     }
        7. }
    
    

说明：

maven仓地址直接在浏览器中打开无法访问，只能在IDE中配置。

    (3). 在buildscript->repositories中配置HMS SDK的maven仓地址。  

      
      1. buildscript {
        2.     repositories {
        3.         google()
        4.         jcenter()
        5.         maven {url 'https://developer.huawei.com/repo/'}
        6.     }
        7. }
    
    

    (4). 在buildscript->dependencies中配置AppGallery Connect插件地址。 
      
      1. buildscript {

        3.         classpath 'com.android.tools.build:gradle:3.3.0'
        4.         classpath 'com.huawei.agconnect:agcp:1.2.1.301'
        5.     }
        6. }
    
    

3. 添加编译依赖和AppGallery Connect插件地址。  


    (1). 打开应用级的build.gradle文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191213201136.89767166369257506854327099109552:50510721070155:2800:24516732DB282201753D5C25D61D2E0BA0454BBCA75A1914CB7E1460000DF0D2.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

    (2). 在文件头添加AppGallery Connect插件依赖。
      
      1. apply plugin: 'com.huawei.agconnect'
    
    

    (3). 在“dependencies”中添加如下编译依赖。
      
      1. dependencies {
        2.     implementation 'com.huawei.hms:safetydetect:4.0.3.300'
        3. }
    
    

4. 重新打开修改完的build.gradle文件，右上方出现“Sync Now”链接。点击“Sync Now”等待同步完成。

说明：

如果出现错误，请检查网络连接是否正常，以及检查gradle文件是否正确。

5. 多语言设置。

  * 如果您的应用不需要设置只支持某些特定语言，则请忽略本步骤。应用将默认支持所有HMS SDK支持的语言。

  * 如果您的应用需要设置只支持某些特定语言，则可通过本步骤配置。




打开项目工程下app目录的build.gradle文件。

## 6.2 在Eclipse项目中集成HMS SDK

针对Eclipse开发环境，华为提供了下载HMS SDK包本地集成的方式。在开始开发前，您需要将HMS SDK集成到您的Eclipse开发环境中。

### 6.2.1 下载SDK  


1\. 下载HMS Base SDK和要集成的服务SDK，并解压zip包。

下载地址请参见：[Eclipse SDK下载](https://developer.huawei.com/consumer/cn/doc/development/HMS-Library/SafetyDetectSDK)。

2\. 选择菜单“File > Import”，将所有SDK工程导入到您的工作空间。  


    (1) 选择“Android > Existing Android Code Into Workspace”，单击“Next”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200119195413.45969901945305423414797587926356:50510721070155:2800:0BCEB875439ABB3C1866CFDDD56F016C3A1B96CA062CAF17617F0A45C499ADB8.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

    (2) 单击“Browse”，选择工程所在的文件夹目录。在“Projects”下显示待导入的工程，默认全部勾选，单击“Finish”。

说明：

待导入的工程必须和工作空间在相同的磁盘空间里，例如都在“D:\”。如果不在，您可以选择“Copy projects into workspace”，将工程文件复制到工作空间。

### 6.2.2 添加工程依赖关系  


1\. 右键单击您的工程，选择“Properties”。

2\. 在左侧选择“Android”，单击“Add”，选择已导入空间的工程，单击“Apply and Close”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200119195643.32296807699820175781669097716830:50510721070155:2800:2B006A072072D3342666C0E2058D0F1FA8585F6A3C09AC65B26191E40D13B9BC.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

# 7\. 配置混淆脚本

开发者编译APK前需要配置不要混淆HMS SDK，避免功能异常。

Android Studio开发环境里的配置文件是“proguard-rules.pro”，Eclipse开发环境里的配置文件是“proguard-project.txt”。

1.  打开工程的混淆配置文件，加入排除HMS SDK的混淆配置。
      
      1. -ignorewarnings
        2. -keepattributes *Annotation*
        3. -keepattributes Exceptions
        4. -keepattributes InnerClasses
        5. -keepattributes Signature
        6. -keepattributes SourceFile,LineNumberTable
        7. -keep class com.hianalytics.android.**{*;}
        8. -keep class com.huawei.updatesdk.**{*;}
        9. -keep class com.huawei.hms.**{*;}
    
    

   


2. 如果开发者使用了AndResGuard，需要在混淆配置文件中加入AndResGuard白名单。
      
      1. "R.string.hms*",
        2. "R.string.agc*",
        3. "R.string.connect_server_fail_prompt_toast",
        4. "R.string.getting_message_fail_prompt_toast",
        5. "R.string.no_available_network_prompt_toast",
        6. "R.string.third_app_*",
        7. "R.string.upsdk_*",
        8. "R.layout.hms*",
        9. "R.layout.upsdk_*",
        10. "R.drawable.upsdk*",
        11. "R.color.upsdk*",
        12. "R.dimen.upsdk*",
        13. "R.style.upsdk*

# 9\. 开发后自检

华为提供对应用自动检查的能力。开发者只需填写应用相关信息、上传APK包，平台将自动扫描APK并输出自检报告。开发者可以根据自检报告改进应用，自检通过即可提交应用上架。

自检步骤请参考AppGallery Connect帮助中心的[自检应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-auto_check)。

须知：目前新版自检工具需要在开发者联盟实名认证过的企业或者个人的帐号才可以使用。
