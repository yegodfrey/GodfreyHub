# 1\. UnionId简介

应用接入华为帐号登录（sign-in）可以获取到OpenId（同一个用户，不同应用，OpenId值不同），使用OpenId标识用户，多个应用之间同一个华为帐号用户在开发者系统内会被标识为多个用户。如果开发者希望在多个应用之间标识用户的唯一性，可以使 UnionId（对于同一个用户，同一个开发者帐号下管理的不同应用，UnionId值相同）。特别注意的是，标识用户唯一性的应用必须是在同一个开发者帐号下管理，一个应用转移到另外一个帐号后，UnionId值也会变化，因此，使用UnionId的应用做应用转移需谨慎，如果必须做应用转移，需要提前做好数据迁移。

# 2\. 申请权限   

**步骤 1**    以开发者帐号登录“华为开发者联盟”。  
**步骤 2**    选择“管理中心 > 应用服务”    

**步骤3**     选择“开发服务 > 帐号”，点击产品名称，进入产品服务状态和服务信息页面。    

**步骤4**    选择“修改 ”，进入“设置帐号服务信息”，点击启动UnionId。

# 3\. 批量获取UnionId

## 3.1 前提条件

开发者在使用批量获取UnionId前，需要申请相关权限。请发送申请权限邮件至客服邮箱：developer@huawei.com，邮件格式如下：  
**标题：** 【联运应用权限申请】+_开发者公司名称_  
**正文样式：**  
       _CPID_  
        联系方式： _XXXX_  
        权限名称：批量获取UnionId  
        申请应用列表： _AppID（应用名称）、AppID（应用名称）、AppID（应用名称）_  
        申请原因：XXX

## 3.2 使用场景

● 开发者已经有应用接入了华为帐号，可以通过openId批量获取对应的unionId。  
● 开发者需要进行应用转移，应用转移完成后UnionId会发生变化，可以通过openId批量获取新的UnionId。

# 5\. 应用转移    

应用转移：将华为开发者联盟上的应用从一个帐号转移到另一个帐号进行维护，应用转移的操作指导请参见“[应用转移操作指南](https://developer.huawei.com/consumer/cn/devservice/doc/50112)”。  
同一个华为帐号用户在一个应用上OpenId是唯一且不会变化的（OpenId和应用的AppId关联）。同一个华为帐号用户在同一个开发者的所有应用中UnionId是唯一且不会变化的（UnionId和开发者的CpId关联）。  
因此，当发生应用转移后，同一个华为帐号用户，在登录应用后，UnionId会发生变化，但是openId不会发生变化，需要参见“3 批量获取UniondId”，使用新的UnionId替换旧的UnionId。
