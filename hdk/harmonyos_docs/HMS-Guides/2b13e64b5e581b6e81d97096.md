# 注册帐号及申请服务

  1. [登录注册](https://developer.huawei.com/consumer/cn/doc/20300)：注册成为开发者并完成实名认证（可申请个人帐号或企业帐号）。 
  2. [申请帐号服务](https://developer.huawei.com/consumer/cn/doc/HMS-Guides/apply_id-0000001050069756)：开通帐号服务并创建应用，填写应用信息（包名、证书指纹等），获取 APP ID。 
  3. [申请 Health Kit 服务](https://developer.huawei.com/consumer/cn/doc/HMS-Guides/apply_kitservice-0000001050071707)：获取 Health Kit 运动健康数据的使用权限。
