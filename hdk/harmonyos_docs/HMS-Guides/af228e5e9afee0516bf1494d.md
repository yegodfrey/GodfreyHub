# Panorama Kit 4.0.0版本 (2020-01-15)

最新子版本号：4.0.0.300

华为推出了全新的HMS Core 全景服务（Panorama Kit）4.0.0版本，此次的版本为全景服务的首个商用版本，为开发者提供了全景图像在三维立体空间的展示和交互能力，使观者犹如身在其中，欢迎广大开发者接入使用。

#### 新增特性

  1. 应用外全景展示（自动判断全景类型）：基于调用者指定的图片包含的信息，服务自动判断加载的是否是全景图片，如果是，则服务会在应用外新创建一个全屏窗口，实现全景内容的三维展示和交互。

  2. 应用外全景展示（指定全景类型）：基于调用者设定的全景类型，服务对图片进行强行加载和渲染，且服务会在应用外新创建一个全屏窗口，实现全景内容的三维展示和交互。

  3. 应用内全景展示：服务将全景图层返回给调用者，让全景服务能被更加灵活的使用，比如可以在应用中的某个区域展示全景信息，而不是应用外的全屏窗口展示。

  4. 支持不同类型的全景：支持球形全景、部分球形全景、柱状全景图平面图的全景展示。

  5. 支持不同的图片格式：支持JPG、JPEG和PNG格式的全景图片解析及其展示。

  6. 支持全景视角的调整：支持全景视角的调整，包括在视窗上直接滑动或通过手机传感器姿态进行360度的视角调整。




# SDK依赖说明

  1. 最新版本SDK需要用户手机上安装HMS Core（APK）4.0.0.300及以上版本； 如果用户手机没有安装，您的应用调用HMS Core（APK）时，会自动引导用户提示安装。

  2. 本服务的主要特性都可以在大多数华为终端上支持，部分高级特性依赖于EMUI版本。请参考[部分特性对于EMUI的依赖说明](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/emui_version_dependent_features "部分特性对于EMUI的依赖说明")。
