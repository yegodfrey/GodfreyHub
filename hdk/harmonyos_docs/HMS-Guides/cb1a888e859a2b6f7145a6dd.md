# 1 服务简介

HUAWEI Drive Kit（简称Drive Kit）允许您创建使用华为云空间的应用程序，华为云空间可以为您的应用提供云端存储功能，让用户在使用您开发的应用时产生的文件保存到云盘，也可以下载、同步和搜索在华为云盘中的所有文件，包括照片、视频以及文档等，也可以让用户对文件进行评论、回复。同时华为云空间为各类数据提供了全方位的安全保障，让用户更安全、便捷地管理数据。

当前华为云空间服务（HUAWEI Drive Kit）的核心能力包括文件的上传、下载和搜索，对文件的评论、回复，云端文件变化的查询、推送通知功能等。

# 2 场景介绍  


HUAWEI Drive Kit对开发者开放了丰富的Drive能力，方便开发者快速构建需要使用云存储能力的应用。HUAWEI Drive Kit的核心能力是文件的上传、下载和搜索，及云端文件变化查询、推送通知功能等。

## 2.1 开发场景

开发者可基于华为Drive SDK开发各种个性化的应用，让用户可以：

  * 方便快捷的管理、编辑和搜索云盘上的文件。

  * 在云盘上保存照片、绘图、录音、视频和各类设计作品。

  * 在其他智能手机、平板电脑或计算机上使用华为云盘中的文件。

  * 对文件进行评论、回复。
