原生广告是创建与应用内容融于一体的广告形式，支持开发者自由定制界面。

# 1\. 添加原生广告

原生广告需要通过[NativeAdLoader](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-nativeadloader)类获取。

## 步骤一：构建AdLoader

[NativeAdLoader](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-nativeadloader)类提供了[NativeAdLoader.Builder](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-nativeadloader-builder)类，可用于设置广告位ID、设置自定义选项和构建[NativeAdLoader](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-nativeadloader)对象。

示例代码如下所示：
      
      1. // "testy63txaom86"为专用的测试广告位ID。
        2. NativeAdLoader.Builder builder = new NativeAdLoader.Builder(this, "testy63txaom86");
        3. builder.setNativeAdLoadedListener(new NativeAd.NativeAdLoadedListener() {
        4.     @Override
        5.     public void onNativeAdLoaded(NativeAd nativeAd) {
        6.         // 广告获取完成后调用
        7.         ...
        8.     }
        9. }).setAdListener(new AdListener() {
        10.     @Override
        11.     public void onAdFailed(int errorCode) {
        12.         // 广告获取失败时调用
        13.         ...
        14.     }
        15. });
        16.   
         
        17. NativeAdLoader nativeAdLoader = builder.build();
    
    

当获取广告成功后，SDK会调用[NativeAd.NativeAdLoadedListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-nativead-nativeadloadedlistener)监听器的onNativeAdLoaded()方法返回[NativeAd](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-nativead-class)对象。

当获取广告失败后，SDK会调用[AdListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-adlistener)监听器的onAdFailed()方法。

## 步骤二：获取广告

[NativeAdLoader](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-nativeadloader)提供loadAd()和loadAds()两种方法获取广告。

  * ### **loadAd()****请求单个原生广告。**




[AdParam](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-adparam)是唯一的参数，代码如下所示：
      
      1. nativeAdLoader.loadAd(new AdParam.Builder().build());
    
    

调用loadAd()后，SDK将对添加的监听器方法进行一次成功或失败的回调。  


  * ### **loadAds()****请求多个原生广告** 。




loadAds()请求有两个参数，除[](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-adparam)[AdParam](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-adparam)外，还有请求加载的广告数量，最大为5。SDK返回的广告数量将会小于等于所请求的广告数量，并且广告皆不相同。

代码如下所示：
      
      1. nativeAdLoader.loadAds(new AdParam.Builder().build(), 5);
    
    

调用loadAds()后，监听器将会根据返回的广告个数进行多次回调。请求多个广告时，可以在回调代码中使用NativeAdLoader.isLoading()方法来判断广告是否已获取完成。代码如下所示：  

      
      1. // "testy63txaom86"为专用的测试广告位ID。
        2. NativeAdLoader.Builder builder = new NativeAdLoader.Builder(this, "testy63txaom86");
        3. NativeAdLoader nativeAdLoader = builder.setNativeAdLoadedListener(new NativeAd.NativeAdLoadedListener() {
        4.     @Override
        5.     public void onNativeAdLoaded(NativeAd nativeAd) {
        6.         if (nativeAdLoader.isLoading()) {
        7.             // nativeAdLoader仍在获取广告
        8.             ...
        9.         } else {
        10.             // nativeAdLoader完成广告获取
        11.             ...
        12.         }
        13.     }
        14. }).build();
        15. nativeAdLoader.loadAds(new AdParam.Builder().build(), 5);
    
    

注意：

再次使用[NativeAdLoader](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-nativeadloader)获取广告前，请确保先前的请求已经完成。

## 步骤三：展示原生广告

获取到广告后在监听器的回调方法中展示原生广告，需要在每个广告视图的一角展示“为什么看到此广告”的图标，并且必须展示广告标识。

以下是展示原生广告的步骤：

###     1. **定义原生广告布局**

需要自定义一个布局用于展示[NativeAd](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-nativead-class)中的素材。

注意：

必须将[NativeView](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-nativeview)作为原生广告的根布局，否则会影响广告收益。

对于使用RelativeLayout来展示素材视图的原生广告，其视图层次结构示例如下：
      
      1. <com.huawei.hms.ads.nativead.NativeView xmlns:android="http://schemas.android.com/apk/res/android"
        2.     android:orientation="vertical"
        3.     android:layout_width="match_parent"
        4.     android:layout_height="wrap_content"
        5.     ... >
        6.     <RelativeLayout
        7.         ... >
        8.         <com.huawei.hms.ads.nativead.MediaView
        9.             android:id="@+id/ad_media"
        10.             ... />
        11.         <RelativeLayout
        12.             ... >
        13.         <TextView
        14.             android:id="@+id/ad_title"
        15.             ...  />
        16.         // 其他素材
        17.         ...
        18.         </RelativeLayout>
        19.         // 其他素材
        20.         ...
        21.     </RelativeLayout>
        22. </com.huawei.hms.ads.nativead.NativeView>
    
    

###     2. **注册和填充素材视图**

获取到[NativeView](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-nativeview)对象后，需要注册和填充素材。

注册和填充标题、多媒体的示例代码如下：
      
      1. // ad_native为定义的原生广告布局XML文件名
        2. NativeView nativeView = (NativeView) getLayoutInflater().inflate(R.layout.ad_native, null);
        3. nativeView.setTitleView(nativeView.findViewById(R.id.ad_title));
        4. ((TextView) nativeView.getTitleView()).setText(nativeAd.getTitle());
        5. nativeView.setMediaView((MediaView) nativeView.findViewById(R.id.ad_media));
        6. nativeView.getMediaView().setMediaContent(nativeAd.getMediaContent());
    
    

依次设置其他要展示的广告素材。

[MediaView](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-mediaView)用于展示多媒体素材。如果获取的广告含有视频素材，则视频会在[MediaView](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-mediaView)内播放。否则[MediaView](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-mediaView)会显示一个图片素材。

###     3. **向NativeView****注册原生广告对象**

示例代码如下：
      
      1. nativeView.setNativeAd(nativeAd);
    
    

###     4. **展示NativeView**  


将[NativeView](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-nativeview)添加到界面即可展示原生广告。示例代码如下：
      
      1. private void loadAd() {
        2.     NativeAdLoader.Builder builder = new NativeAdLoader.Builder(this, "testy63txaom86");
        3.     builder.setNativeAdLoadedListener(new NativeAd.NativeAdLoadedListener() {
        4.         @Override
        5.         public void onNativeAdLoaded(NativeAd nativeAd) {
        6.             // TODO
        7.             ...
        8.             // 获取NativeView视图
        9.             NativeView nativeView = (NativeView) getLayoutInflater().inflate(R.layout.ad_native, null);
        10.             // 注册和填充原生广告素材视图
        11.             initNativeAdView(nativeAd, nativeView);
        12.             // 将NativeView添加到界面
        13.             FrameLayout adFrameLayout = findViewById(R.id.frame_layout_ad);
        14.             adFrameLayout.removeAllViews();
        15.             adFrameLayout.addView(nativeView);
        16.             // TODO
        17.             ...
        18.         }
        19.     });
        20.     ...
        21. }
        22. private void initNativeView(NativeAd nativeAd, NativeView nativeView) {
        23.     // 注册和填充标题素材视图
        24.     nativeView.setTitleView(nativeView.findViewById(R.id.ad_title));
        25.     ((TextView) nativeView.getTitleView()).setText(nativeAd.getTitle());
        26.     // 注册和填充多媒体素材视图
        27.     nativeView.setMediaView((MediaView) nativeView.findViewById(R.id.ad_media));
        28.     nativeView.getMediaView().setMediaContent(nativeAd.getMediaContent());
        29.     // 注册和填充其他素材视图
        30.     ...
        31.     // 注册原生广告对象
        32.     nativeView.setNativeAd(nativeAd);
        33. }

# 3\. 原生视频广告

原生广告除了包含图片、文字外，还可能会包含视频素材。HUAWEI Ads SDK还提供了以下两个类用于视频的配置和控制。

  * ## **VideoConfiguration**




通过[VideoConfiguration](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-videoconfiguration)类，可以对原生视频进行相关配置。示例代码如下：
      
      1. // "testy63txaom86"为专用的测试广告位ID。
        2. NativeAdLoader.Builder builder = new NativeAdLoader.Builder(this, "testy63txaom86");
        3. VideoConfiguration videoConfiguration = new VideoConfiguration.Builder()
        4.         // 设置是否在静音状态下开始播放视频素材。其默认值为true。
        5.         .setStartMuted(true)
        6.         .build();
        7. NativeAdConfiguration adConfiguration = new NativeAdConfiguration.Builder()
        8.         .setVideoConfiguration(videoConfiguration)
        9.         .build();
        10. builder.setNativeAdOptions(adConfiguration);
    
    

  * ## **VideoOperator**




[VideoOperator](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-videooperator)类用于视频信息获取和视频控制。控制器实例需要通过调用[NativeAd](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-nativead-class).getVideoOperator()方法获得。当广告中没有视频素材时，此方法也会返回[VideoOperator](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-videooperator)对象。
      
      1. VideoOperator videoOperator = nativeAd.getVideoOperator();
    
    

[VideoOperator](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-videooperator)提供hasVideo()方法判断广告中是否有视频素材。  


通过实现[VideoOperator.VideoLifecycleListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-videolifecyclelistener)类可以监听视频播放过程中的事件。
      
      1. videoOperator.setVideoLifecycleListener(new VideoOperator.VideoLifecycleListener() {
        2.     @Override
        3.     public void onVideoEnd() {
        4.         // TODO
        5.         ...
        6.         super.onVideoEnd();
        7.     }
        8. });

# 5\. 原生广告设置选项

通过[NativeAdConfiguration](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-nativeadconfiguration)对象可以实现对原生广告的自定义设置。示例代码如下：
      
      1. // "testy63txaom86"为专用的测试广告位ID。
        2. NativeAdLoader.Builder builder = new NativeAdLoader.Builder(this, "testy63txaom86");
        3. NativeAdConfiguration adConfiguration = new NativeAdConfiguration.Builder()
        4.         .setVideoConfiguration(videoConfiguration) // 设置视频选项

了解详细方法，请参见API文档中的[NativeAdConfiguration.Builder](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-nativeadconfiguration-builder)类。

  * ## 自定义版“不再显示该广告”




通过[NativeAdConfiguration.Builder](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-nativeadconfiguration-builder)类中的setRequestCustomDislikeThisAd()方法可以设置是否要自定义“不再显示该广告”。当设置为自定义版“不再显示该广告”时，原生广告将会显示“为什么看到此广告”图标。如果需要隐藏“为什么看到此广告”图标，可调用[NativeAdConfiguration.Builder](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-nativeadconfiguration-builder)类中的setChoicesPosition()方法将其设置为不可见。

示例代码如下：
      
      1. NativeAdConfiguration adConfiguration = new NativeAdConfiguration.Builder()
        2.         .setRequestCustomDislikeThisAd(true) // 需要自定义“不再显示该广告”
        3.         .setChoicesPosition(NativeAdConfiguration.ChoicesPosition.INVISIBLE) // 隐藏“为什么看到此广告”图标
        4.         .build();
        5. NativeAdLoader nativeAdLoader = builder.setNativeAdOptions(adConfiguration).build();
    
    

注意：

若要隐藏“为什么看到此广告”图标，则需要在自定义广告选项列表中添加“为什么看到此广告”选项。当点击“为什么看到此广告”选项时，调用[NativeView](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-nativeview)类中的gotoWhyThisAdPage()方法即可跳转到为什么看到此广告的页面。

当原生广告加载完成时，可调用[NativeAd](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-nativead-class).isCustomDislikeThisAdEnabled()判断是否已设置为要自定义“不再显示该广告”。另外，可通过[NativeAd](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-nativead-class).getDislikeAdReasons()方法获取“不再显示该广告”的信息列表，然后将其显示在开发者自定义界面中。

示例代码如下：
      
      1. if (nativeAd.isCustomDislikeThisAdEnabled()) {
        2.     List<DislikeAdReason> dislikeAdReasons = nativeAd.getDislikeAdReasons();
        3. }
    
    

通过[NativeAd](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-nativead-class).dislikeAd()方法可以将被选中的“不再显示该广告”选项信息反馈给SDK。

示例代码如下：
      
      1. nativeAd.dislikeAd(dislikeAdReason);
