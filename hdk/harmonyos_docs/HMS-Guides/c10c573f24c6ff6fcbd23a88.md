# 1\. 概述

HuaweiIdAuthButton是华为帐号提供的一个界面类，此类展示华为风格的登录按钮，可以方便开发者快速地实现符合《[华为帐号图标使用规范](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/account-specification)》的登录按钮。注意此类只处理按钮的视觉方面，如果要触发登录动作，请使用setOnClickListener(OnClickListener)注册一个监听器。

# 2\. 开发准备

按《[华为帐号服务开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/account-preparation)》中的步骤配置AppGallery Connect并集成HMS Core SDK之后即可使用HuaweiIdAuthButton。

注意：HuaweiIdAuthButton要求HMS Core SDK版本为4.0.0.300及以上。

# 3\. 使用指导

HuaweiIdAuthButton和一般的界面类一样，有两种使用方式，一种是在布局xml文件中进行声明，另外一种是在Java代码中创建HuaweiIdAuthButton类的实例，并动态添加到布局中，开发者可以根据自己的需要选择使用。

## 3.1. 通过布局xml文件使用

### 3.1.1. 控件声明

首先按以下方式声明HuaweiIdAuthButton控件：
      
      1. <com.huawei.hms.support.hwid.ui.HuaweiIdAuthButton
        2.      android:layout_width="wrap_content"
        3.      android:layout_height="wrap_content"
        4. />

HuaweiIdAuthButton提供了以下几种自定义样式参数：

---|---|---

hwid_button_theme_no_title| 按钮不展示文字。  
hwid_color_policy| hwid_color_policy_blue| 按钮颜色风格为蓝色，只有hwid_button_theme= hwid_button_theme_full_title时可用。  
hwid_color_policy_black| 按钮颜色风格为黑色。  
hwid_color_policy_gray| 按钮颜色风格为灰色，只有hwid_button_theme= hwid_button_theme_full_title时可用。  
hwid_color_policy_red| 按钮颜色风格为红色。  
hwid_color_policy_white| 按钮颜色风格为白色。  
hwid_color_policy_white_with_border| 按钮颜色风格为带描边白色，只有hwid_button_theme= hwid_button_theme_full_title时可用。  
hwid_corner_radius| hwid_corner_radius_large| 按钮圆角设置，大圆角。  
hwid_corner_radius_medium| 按钮圆角设置，中等圆角。  
hwid_corner_radius_small| 按钮圆角设置，小圆角。

      1. xmlns:app="http://schemas.android.com/apk/res-auto"

        2.     android:layout_width="wrap_content"
        3.     android:layout_height="wrap_content"
        4.     app:hwid_button_theme="hwid_button_theme_full_title"
        5.     app:hwid_color_policy="hwid_color_policy_blue"

## 3.2. 通过Java代码创建实例

### 3.2.1. 控件声明

通过HuaweiIdAuthButton的构造函数可以创建对应实例，并通过addView的方式把HuaweiIdAuthButton加入到布局中。

构造函数| 说明  
---|---  
HuaweiIdAuthButton(Context context)| 构造方法，创建HuaweiIdAuthButton实例。  
HuaweiIdAuthButton(Context context, AttributeSet attributeSet)| 构造方法，创建HuaweiIdAuthButton实例，根据属性集加载样式。  
HuaweiIdAuthButton(Context context, AttributeSet attributeSet, int defStyleAttr)| 构造方法，创建HuaweiIdAuthButton实例，可以指定默认样式。  
  
示例代码：
      
      1. HuaweiIdAuthButton huaweiIdAuthButton = new HuaweiIdAuthButton(this);
        2. LinearLayout layout = findViewById(R.id.layout_sign_in_api);
        3. layout.addView(huaweiIdAuthButton);
    
    

### 3.2.2. 自定义参数

HuaweiIdAuthButton提供了以下几种自定义样式参数：

自定义参数方法| 可选值| 说明  
---|---|---  
setTheme(int theme)| HuaweiIdAuthButton.THEME_FULL_TITLE| 按钮主题为展示图标+标题。  
HuaweiIdAuthButton.THEME_NO_TITLE| 按钮主题为不展示标题。  
setColorPolicy(int colorPolicy)| HuaweiIdAuthButton.COLOR_POLICY_BLUE| 按钮颜色风格为蓝色，只有主题为THEME_FULL_TITLE时可用。  
HuaweiIdAuthButton.COLOR_POLICY_BLACK| 按钮颜色风格为黑色。  
HuaweiIdAuthButton.COLOR_POLICY_GRAY| 按钮颜色风格为灰色，只有主题为THEME_FULL_TITLE时可用。  
HuaweiIdAuthButton.COLOR_POLICY_RED| 按钮颜色风格为红色。  
HuaweiIdAuthButton.COLOR_POLICY_WHITE| 按钮颜色风格为白色。  
HuaweiIdAuthButton.COLOR_POLICY_WHITE_WITH_BORDER| 按钮颜色风格为带描边白色，只有主题为THEME_FULL_TITLE时可用。  
setCornerRadius(int cornerRadiusPx)| HuaweiIdAuthButton.CORNER_RADIUS_LARGE| 按钮圆角设置，大圆角  
HuaweiIdAuthButton.CORNER_RADIUS_MEDIUM| 按钮圆角设置，中等圆角  
HuaweiIdAuthButton.CORNER_RADIUS_SMALL| 按钮圆角设置，小圆角  
setUIMode(int theme, int colorPolicy, int cornerRadius)| 参考以上theme，colorPolicy，cornerRadius的可选值| 设置HuaweiIdAuthButton的主题、颜色风格和圆角半径。  
setEnabled(boolean flag)| true/false| 设置是否可以点击。  
  
示例代码：  

      
      1. HuaweiIdAuthButton huaweiIdAuthButton = new HuaweiIdAuthButton(this);
        2. huaweiIdAuthButton.setOnClickListener(new View.OnClickListener() {
        3.     @Override
        4.         public void onClick(View v) {
        5.         // do sign in
        6.     }
        7. });
        8. huaweiIdAuthButton.setTheme(HuaweiIdAuthButton.THEME_FULL_TITLE);
        9. huaweiIdAuthButton.setColorPolicy(HuaweiIdAuthButton.COLOR_POLICY_BLUE);
        10. huaweiIdAuthButton.setCornerRadius(HuaweiIdAuthButton.CORNER_RADIUS_LARGE);
        11. LinearLayout layout = findViewById(R.id.layout_sign_in_api);
        12. layout.addView(huaweiIdAuthButton);
