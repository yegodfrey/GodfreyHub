在接口调用过程中，请求方在获取接收方的响应结果后，如果返回结果中包含了查询结果的签名字符串，请求方可以对签名字符串使用支付公钥进行验签，确认返回结果没有被篡改。公钥获取参考[查询支付服务信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/appgallery_querypaymentinfo)。建议您把公钥存放在服务端并在服务端来完成签名校验，保证接口调用的安全性。

1.获取需要验签的返回结果字符串，例如[obtainOwnedPurchases](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapClient-v4#obtainOwnedPurchases)接口返回的inAppPurchaseDataList中商品信息需要验签，先取第1条商品信息的JSON字符串参与验签。

2.获取对应的签名字符串，例如[obtainOwnedPurchases](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapClient-v4#obtainOwnedPurchases)接口返回的inAppSignature对应inAppPurchaseDataList的签名字符串，取第1条商品信息的签名字符串参与验签。

3.使用支付公钥对结果字符串和对应的签名字符串通过SHA256WithRSA算法进行验证。

JAVA示例代码如下：
    
    
    复制
      
        1. /** *校验签名信息    
         
        2. * @param content 结果字符串    
         
        3. * @param sign 签名字符串    
         
        4. * @param publicKey 支付公钥    
         
        5. * @param是否校验通过    
         
        6. */   
         
        7. public static boolean doCheck(String content, String sign, String publicKey) {   
         
        8.     if ( sign == null) {   
         
        9.         return false;   
         
        10.     }   
         
        11.     if (publicKey == null) {   
         
        12.         return false;   
         
        13.     }   
         
        14.     try {   
         
        15.         KeyFactory keyFactory = KeyFactory.getInstance("RSA");   
         
        16.         byte[] encodedKey = Base64.decode(publicKey);   
         
        17.         PublicKey pubKey = keyFactory.generatePublic(new X509EncodedKeySpec(encodedKey));   
         
        18.         java.security.Signature signature = null;   
         
        19.         signature = java.security.Signature.getInstance("SHA256WithRSA");   
         
        20.         signature.initVerify(pubKey);   
         
        21.         signature.update(content.getBytes(StandardCharsets.UTF_8));   
         
        22.         byte[] bsign = Base64.decode(sign);   
         
        23.         return signature.verify(bsign);   
         
        24.     } catch (RuntimeException e) {   
         
        25.         throw e;   
         
        26.     } catch (Exception e) {   
         
        27.         e.printStackTrace();   
         
        28.     }   
         
        29.     return false;   
         
        30. }
