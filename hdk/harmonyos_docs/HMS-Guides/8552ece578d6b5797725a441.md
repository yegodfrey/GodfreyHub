4\. 配置识别参数，调用“startRecognizing”启动语音识别。
      
      1. // 新建Intent，用于配置语音识别参数。
        2. Intent mSpeechRecognizerIntent = new Intent(MLAsrConstants.ACTION_HMS_ASR_SPEECH);
        3. // 通过Intent进行语音识别参数设置。
        4. mSpeechRecognizerIntent
        5.     // 设置识别语言为英文，若不设置，则默认识别英文。支持设置："zh": 中文；"en-US": 英文；"fr-FR": 法语。
        6.     .putExtra(MLAsrConstants.LANGUAGE, "zh")
        7.     // 设置识别文本返回模式为边识别边出字，若不设置，默认为边识别边出字。支持设置：   
        8.     // MLAsrConstants.FEATURE_WORDFLUX：通过onRecognizingResults接口，识别同时返回文字；
        9.     // MLAsrConstants.FEATURE_ALLINONE：识别完成后通过onResults接口返回文字。
        10.     .putExtra(MLAsrConstants.FEATURE, MLAsrConstants.FEATURE_WORDFLUX);
        11. // 启动语音识别。
        12. mSpeechRecognizer.startRecognizing(mSpeechRecognizerIntent);
    
    

5\. 识别完成后，释放资源
      
      1. if (mSpeechRecognizer!= null) {

        3. }

        4.     .putExtra(MLAsrCaptureConstants.LANGUAGE, "en-US")
        5.     // 设置拾音界面是否显示文字，MLAsrCaptureConstants.FEATURE_ALLINONE为不显示，MLAsrCaptureConstants.FEATURE_WORDFLUX为显示。
        6.     .putExtra(MLAsrCaptureConstants.FEATURE, MLAsrCaptureConstants.FEATURE_WORDFLUX);
    
    

2\. 创建activity，传入步骤1创建的Intent，用于拾音，并将结果返回原activity，可实时识别60s内（包括60s）的语音。
