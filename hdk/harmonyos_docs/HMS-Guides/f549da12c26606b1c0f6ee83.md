# 1\. SDK工作方式  


华为动态标签管理器服务（DTM）SDK在应用打包时会被集成进您的应用中，SDK会随着相关接口的调用而启动和关闭，不会在后台做任何额外动作。

  


# 2\. SDK权限说明  

    
    
    复制
      
        1.     <!--网络权限-->
        2.     <uses-permission android:name="android.permission.INTERNET" />
        3.     <!--检测网络状态-->
        4.     <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
    
    

# 3\. SDK数据收集  


DTM SDK不会保存和收集任何来自开发者的个人数据。DTM SDK只提供能力接口，业务方通过SDK的能力接口按需调用DTM端侧Service的服务能力。默认情况下，数据会上报到HA；遇到恶意数据、数据违法等情况下，可调用[setEnableReport](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/52967500#h1-1577154069978)接口关闭数据上报通道。

  


# 4\. SDK数据安全保护

HUAWEI DTM SDK与服务端采用HTTPS通信，客户端会对服务器的证书进行合法性校验。
