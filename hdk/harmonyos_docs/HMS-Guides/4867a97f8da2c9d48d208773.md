# Photo Deformer 简介

Photo Deformer 是一款制作特效相片的图像编辑APP，由俄罗斯STOIK SOFT出品，集合了AI自动检测人脸轮廓，自动或手动调整人脸形状，支持video和Gif 保存改造后的图片，DIY制作轻松有趣的人像图片。

# 业务挑战

图像人像调整编辑是Photo Deformer主要特色功能之一，能够提取图片中人脸的轮廓信息，并根据需要调整人脸形状，DIY制作人像图片。集成ML kit 人脸检测帮助Photo Deformer 实现了图像中高精度的多人脸检测，构建主要竞争力。

  * 第三方人脸轮廓检测精度不高：其他第三方人脸检测服务提供的检测精度不高，不能满足Photo Deformer的需求。

  * 多人脸检测无法实现：图片或照片中出现多人脸的情况非常普遍，但是之前开发者未能使用多人脸检测的能力，限制APP的应用场景。

  * 缺少同时支持华为和非华为机型的统一方案：Photo Deformer缺少能够覆盖华为手机和非华为手机扫描文本支付的统一方案，要么根据不同手机厂家需要集成多次，要么根据算法更新需要重新发布版本，无动态升级机制。




# 解决方案

凭借HMS ML kit 高性能的人脸检测服务，Photo Deformer 实现了多人脸检测，扩展了业务场景，为用户提供更加准确、全面的图像编辑服务，改善用户体验。  


  * HMS ML Kit人脸检测服务，精度高：HMS ML Kit人脸检测服务，支持855点人脸轮廓检测，检测精度高，用户体验好。

  * 支持多人脸同时检测：HMS ML Kit支持多人脸同时检测，有效支持Photo Deformer业务场景覆盖。

  * 一次开发，支持非华为手机，覆盖所有机型：HMS ML Kit支持华为及非华为手机，开发者只需要一次集成，即可覆盖市面上所有安卓系统机型。




# 合作受益

  * Photo Deformer客户：




Photo Deformer 通过HMS ML Kit 人脸检测服务补全图像中多人脸检测的功能，通过855点的人脸轮廓检测，增加检测精度，提升用户体验。

  * Photo Deformer用户：




享受更准确、多人脸的人像编辑服务，用户体验更好。
