# 1\. SDK工作方式

移动端SDK需要在应用打包时，被加载在您的应用当中。SDK会随着客户应用的启动而自动开始进行用户行为数据。当用户关闭应用时，SDK会随着客户应用的关闭而关闭，不会在后台做任何额外动作。

# 2\. SDK权限说明

SDK需要使用的权限：

  * android.permission.GET_TASKS：判断当前前台应用的权限。

  * android.permission.REAL_GET_TASKS：判断当前前台应用的权限。

  * android.permission.SYSTEM_ALERT_WINDOW：用于展示悬浮窗的权限。

  * android.permission.INTERNET：联网权限。

  * android.permission.ACCESS_NETWORK_STATE：检测网络权限。




# 3\. SDK收集数据

SDK 主要采集两类数据:

  * 事件公共属性：SDK在上报数据时会收集aaid，androidID(aaid没有值时获取)，设备名称，ROM版本号，EMUI版本，设备型号，应用包名，应用版本，SDK版本号，渠道号，SDK名称，操作系统，操作系统版本，系统语言，厂商，屏幕高度，屏幕宽度。

  * 自定义事件：用户自定义打点事件数据




# 4\. SDK数据安全保护

SDK端侧采集数据本地加密，与采集服务器采用HTTPS安全协议，并在上报数据时加密传输。
