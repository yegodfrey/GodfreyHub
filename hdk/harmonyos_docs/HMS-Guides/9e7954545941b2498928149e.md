# 1 概览

通过用户传入自己的位置，可以返回周边地点列表，继而通过获取到的SiteID，可以查询该地点的详细信息。

# 2 实现步骤

1\. 声明[SearchService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchservice)对象，并通过[SearchServiceFactory](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchservicefactory)创建[SearchService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchservice)实例。

说明：

创建SearchService实例需要传入context和API key参数。context参数建议传入Activity类型，否则需要升级HMS Core（APK）时不会弹出升级界面。API key是开发者在[华为开发者联盟](https://developer.huawei.com/consumer/cn)创建应用时生成的API key，注意需要对API key进行encodeURI编码。  


  


2\. 构建[NearbySearchRequest](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-nearbysearchrequest)对象，它是周边搜索的请求体。其中location是必选参数，其余可选：

  * location：用户当前的位置。

  * radius：可以指定搜索半径。单位是米，默认值是1公里，取值范围是1米-50公里。

  * query：输入搜索关键字。

  * poiType：返回指定POI类型的地点。

  * language：搜索结果的语种，取值范围参考[语种映射](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/hms-site-language)的语种代码。如果不传，使用query字段的语种或者地点的当地语言，query字段的语种优先。

  * politicalView：政治观点参数，采用ISO 3166-1-alpha-2规范的2位国家码。  


  * pageSize：每页返回的记录数。默认值是20，取值范围是1-20。

  * pageIndex：当前页数。默认值是1，取值范围是1-60。




3\. 创建[SearchResultListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchresultlistener)对象，该对象用来监听搜索结果。

4\. 通过第1步创建的[SearchService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchservice)对象调用nearbySearch()接口，传入第2步创建的[NearbySearchRequest](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-nearbysearchrequest)对象和第3步创建的[SearchResultListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchresultlistener)对象。

5\. 通过第3步创建的[SearchResultListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchresultlistener)对象获取搜索结果[NearbySearchResponse](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-nearbysearchresponse)对象，可从中获[Site](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-site)列表，解析具体的地址信息。

示例代码如下：
      
      1. // 声明SearchService对象
        2. private SearchService searchService;
        3. // 创建SearchService实例
        4. searchService = SearchServiceFactory.create(this, "API key");
        5. // 创建请求体
        6. NearbySearchRequest request = new NearbySearchRequest();
        7. Coordinate location = new Coordinate(48.893478, 2.334595);
        8. request.setLocation(location);
        9. request.setQuery("Paris");
        10. request.setRadius(1000);
        11. request.setPoiType(LocationType.ADDRESS);
        12. request.setLanguage("fr");
        13. request.setPageIndex(1);
        14. request.setPageSize(5);
        15. // 创建搜索结果监听器
        16. SearchResultListener<NearbySearchResponse> resultListener = new SearchResultListener<NearbySearchResponse>() {
        17.     // 正常结果返回
        18.     @Override
        19.     public void onSearchResult(NearbySearchResponse results) {
        20.         List<Site> sites = results.getSites();
        21.         if (results == null || results.getTotalCount() <= 0 || sites == null || sites.size() <= 0) {
        22.             return;
        23.         }
        24.         for (Site site : sites) {
        25.             Log.i("TAG", String.format("siteId: '%s', name: %s\r\n", site.getSiteId(), site.getName()));
        26.         }
        27.     }
        28.     //异常结果返回
        29.     @Override
        30.     public void onSearchError(SearchStatus status) {
        31.         Log.i("TAG", "Error : " + status.getErrorCode() + " " + status.getErrorMessage());
        32.     }
        33. };
        34. // 调用周边搜索接口
        35. searchService.nearbySearch(request,resultListener);
