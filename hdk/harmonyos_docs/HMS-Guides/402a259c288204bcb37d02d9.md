# Push Kit 4.0.4版本（2020-05-29）

最新子版本号：4.0.4.301

#### 新增特性

  1. 推送运营平台推送范围支持主题列表组合表达式模式与自定义表达式模式的订阅用户。

  2. 支持发送上行消息的能力。

  3. 支持基于第三方审核结果的消息推送。  





# Push Kit 4.0.3版本（2020-04-13）

最新子版本号：4.0.3.301

#### 新增特性

  1. 推送运营平台页面优化若干。  


  2. 主题订阅功能不再受限于低EMUI系统版本。

  3. 通知消息复杂样式部分高级能力回合到EMUI 9.1.x版本。




# Push Kit 4.0.2版本（2020-03-02）

最新子版本号：4.0.2.300

#### 新增特性

  1. 服务端发送Push消息API参数变更

**字段**| **变更**| **说明**  
---|---|---  
message.android.notification.inbox_content| 新增| 新增通知消息Inbox样式  
message.android.notification.buttons| 新增| 新增通知消息动作按钮  
  2. 支持Inbox样式通知栏消息

  3. 通知栏消息支持设置按钮

  4. 端侧新增onTokenError方法（申请token失败回调方法）

  5. 优化控制台发消息排版




# Push Kit 4.0.1版本（2020-01-23）

最新子版本号：4.0.1.300

#### 新增特性

支持Eclipse项目中集成Push SDK。

# Push Kit 4.0.0版本（2020-01-15）

最新子版本号：4.0.0.300

#### 增改特性

  1. 新增通知消息前台展示功能

  2. 新增自动初始化能力

应用启动时自动初始化Push，自动申请token。默认关闭，需要应用主动设置开启。

  3. 优化以下功能支持范围

主题订阅/退订支持在EMUI 8.1及以上版本使用（极少量早期EMUI 8.1设备不支持）

  4. 新增WebPush消息推送代理能力

  5. 新增iOS应用消息推送代理能力

  6. Push服务端变更通知消息与透传消息的划分依据

只要存在message.android.notification节点就代表是通知消息

# SDK依赖说明

  1. 最新版本SDK需要用户手机上安装HMS Core（APK） 4.0.0.300及以上版本； 如果用户手机没有安装，您的应用调用HMS Core时，会自动引导用户提示安装。  


  2. 本服务的主要特性都可以在大多数华为终端上支持，部分高级特性依赖于EMUI版本。请参考 [部分特性对于EMUI的依赖说明](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/emui_version_dependent_features)。




提示：您的应用在华为应用市场上架过程中，如有问题可发送邮件至 [HMSCore@huawei.com](mailto:HMSCore@huawei.com) 咨询。
