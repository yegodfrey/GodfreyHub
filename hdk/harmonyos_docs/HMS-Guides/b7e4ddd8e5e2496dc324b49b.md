# SDK 权限说明

#### SDK 权限

开发者应用集成 Health Kit，本身不需要申请手机系统的额外权限。

#### Health Core 权限

调用 Health Kit 的接口，最终会由 Health Core 来处理，对于不同的接口调用，需要 Health Core 具备相应的权限，这些权限的声明应在开发者的隐私声明中告知用户。

  * 联网权限：用于进行 Health Core 和 Health Kit 云之间同步数据。 
  * 位置权限：如果需要订阅轨迹数据或绑定蓝牙设备，则需要 Health Core 从手机获取位置权限。 
  * 计步传感器访问权限：如果需要订阅计步数据，则需要 Health Core 从手机获取计步数据的权限。 
  * 蓝牙权限：如果需要调用蓝牙设备接口，则需要 Health Core 获取蓝牙接口调用权限。
