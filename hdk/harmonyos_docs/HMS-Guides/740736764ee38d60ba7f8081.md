# 1\. 检查应用类型

由于应用创建后应用类型不可更改，在正式开发游戏之前，请确保应用的类型为“游戏”。

1、登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，选择“我的应用”。

2、点击应用。

3、在“分发 > 应用上架 > 应用信息”中查看“应用分类”，确保类型为“游戏”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191127183301.49184910994352653259176502451179:50510424043526:2800:C46790FEBCA4A0B9F4075E549BB4AF85317E62EDF7E70D4A4EA7AED4A2CFFF69.png?needInitFileName=true)

说明：

如果应用分类不是“游戏”，则需要参考[创建应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-create_app)重新创建应用，并申请相关服务。

# 2\. 检查签名证书配置  


1、请确认已提前创建应用的签名证书，并生成签名证书的指纹，相关操作请参见[配置签名证书指纹](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/game-preparation-v4#config_certificate)。

2、请确认已提前打开相应服务，请参见[打开相关服务](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/game-preparation-v4#service)。

3、确保开发环境在运行和编译应用程序时使用的签名证书与华为AppGallery Connect上配置签名证书指纹的签名文件一致，否则连接HMS Core（APK）将失败。

# 3\. 准备应用参数

在开发游戏前，请确保下表所示信息已经具备。

类别| 参数| 类型| 来源  
---|---|---|---  
公共| Keystore-file| 文件| 自行创建。  
应用ID| 字符串| 应用服务详情，获取方法参考[查询应用信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/appgallery_queryappinfo)。  
应用包名| 字符串  
支付服务| CP ID| 字符串| 支付服务详情，获取方法参见[查询支付服务信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/appgallery_querypaymentinfo)。  
支付公钥| 字符串  
游戏服务| 游戏私钥| 字符串| 游戏服务详情，获取方法参见[查询游戏服务信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/appgallery_querygameinfo)。  
游戏公钥| 字符串
