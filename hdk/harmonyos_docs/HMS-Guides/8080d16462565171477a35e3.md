# 自检工具

华为提供对应用自动检查的能力。您只需填写应用相关信息、上传APK包，平台将自动扫描APK并输出自检报告。您可以根据自检报告改进应用，自检通过即可提交应用上架，是您上架应用的好帮手。

1、登录 [AppGallery Connect 网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择“我的应用”。

2、在产品列表中展开应用所在的产品，点击应用名称。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191120094637.03369305606992753240051658018011:50510108075533:2800:BFE0323EAD28EB948F74FC0DBBF92EE1791230A2FB72F1168D2C117BB0B54C04.png)

3、选择“开发”页签，在左侧导航栏选择“开发资源 > 接入检测”，点击“创建自检”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191120094701.44038502279896816747174034506152:50510108075533:2800:48A86F372FF784E6888FFDD713F2234875390F4A9F84BDB062A3FE88F40DA2F2.png)

4、确认应用信息已填写正确后，点击“提交”。

● 如果“应用介绍”、“应用简介”、“应用分类”、“付费情况”、“分发国家”未自动同步已设置的应用信息，请根据实际情况补充填写。

● 可单击“浏览”按钮上传需要自检的APK软件包。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191120094726.09662244272562654669792097702388:50510108075533:2800:176B7EE9832BA12D26E10003AA276E6E8F89D1A6368E354D87B691270B2C0D32.png)

5、创建自检成功后会在检测记录列表中展示检查结果，点击“查看报告”可以查看检测结果。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191120095139.92574411723584170065088654190209:50510108075533:2800:C7E9FF875096852E0C250CB7268B479E3BF5045357B349433A2FF7E0DAED383E.png)
