# 1.Game Kit介绍

Game Kit通过游戏App给系统提供精细化场景信息、配置信息、网络信息等，系统给游戏App反馈系统状态信息等，使得双方能够利用这些信息进行更紧密和深入的协作，在系统资源有限的情况下进一步改善玩家的游戏体验。

# 2.应用场景

l 游戏App通过集成Game Kit，可以为系统提供丰富、实时、精准的数据，系统结合游戏下发的数据及系统状态更合理调度资源，提升游戏体验。

l 系统可以为集成Game Kit的游戏App反馈系统状态信息，游戏App根据这些信息进行游戏的负载调整，保障游戏的流畅体验。

# 3.服务特点

l 接入快速，消息封装协议化，交互简单。

l 游戏App和系统的双向协作优化，提升游戏体验。
