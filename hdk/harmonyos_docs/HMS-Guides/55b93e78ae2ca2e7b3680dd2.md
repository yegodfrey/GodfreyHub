# **ComfortDelGro****简介**

ComfortDelGro是新加坡知名打车软件，为个人和家庭提供便捷的出租车预定服务。它为用户提供从预订、接送、出租车位置跟踪等全流程打车服务。

# **业务挑战**

用户可通过自动定位当前所在位置发送打车申请，司机根据用户提供的位置接送用户。在这个过程中，存在如下挑战：

  * 当用户在楼间距密集的城市峡谷时，其设备的GPS信号受到遮挡，ComforDelGro无法准确定位用户所在道路侧位置。

  * 由于用户定位的位置信息不准确，司机到达后与用户实际位置偏差较大，这会导致司机与用户间的二次沟通，降低接送效率，更甚至用户会取消订单。




# **解决方案**

  * **超级卫星定位，精准定位并展示用户位置：** 借助华为定位服务的超级卫星定位能力，及时用户处在高楼密集遍布的环境，ComfortDelGro也能够帮助用户精准定位其当前位置，并使用华为地图服务构建地图展示界面，这样用户的位置就能在界面中精准展示，用户和司机双方都能直观了解各自所在位置。

  * **城市打车不错边，用户与司机的体验双双提升：** 基于用户位置的精准展示，如所处道路侧，司机人员能够根据地图导航准确、快速找到用户。这样，用户和司机便不会因位置误差而互相错过，用户打车体验提升，司机的接单效率提高。

  * **降低开发、维护成本：** 华为定位服务和地图服务的集成过程简单，且后期维护成本低。ConfortDelGro仅用10天便完成定位服务、地图服务、推送服务的集成与测试，并在华为应用市场上架。这大大减少ComforDelGro优化基于位置的产品体验的工作量，使ComfortDelGro能够更加聚焦优化产品服务逻辑和提升服务质量。

  * **To****用户**

****精准的定位能力让用户不再对定位偏差感到烦躁，丰富的地图呈现让用户实时追踪车辆状态，掌握行程动态。司机也能够提升其接送效率，获取更多收益。
