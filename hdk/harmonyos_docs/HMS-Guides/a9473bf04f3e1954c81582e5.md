# User-ID功能的计算逻辑

HUAWEI Analytics Kit支持按User-ID或按设备标识您应用内的用户。当您想分析同一个账号在不同设备、不同平台的数据，或分析登录状态的用户行为时，可以选择按User-ID标识用户。

举个例子介绍一下User-ID功能的计算逻辑：

假设有两台设备X和Y，上报的事件明细如下：

设备X上报的事件：用户打开APP，刚开始在未登录状态下进行了一系列的操作(步骤1-->3)；后来使用了账号B登录了设备，并进行了一系列操作(步骤4-->7)；再后来将设备X给了另外一个用户，该用户使用账号C登录该设备进行了一系列操作(步骤8-->11);最后C用户退出了该手机，在未登录状态下又使用了一段时间设备(步骤12-->13)。

设备Y上报的事件：用户换了一部新手机，先打开APP刚开始没有登录进行了一系列的操作(步骤14-->16)；后来使用账号B登录该手机进行操作(步骤17-19)。

设备X、Y上报的事件明细：

序号|  设备|  事件|  上报设备id(AAID)|  上报账号ID(User-ID)|  系统用户标识|  登录标识  
---|---|---|---|---|---|---  
1|  X|  APP安装|  A|  NULL|  A|  FALSE  
2|  X|  打开APP|  A|  NULL|  A|  FALSE  
3|  X|  操作APP|  A|  NULL|  A|  FALSE  
4|  X|  登录APP|  B|  NULL|  A|  FALSE  
5|  X|  操作APP|  B|  B|  B|  TRUE  
6|  X|  操作APP|  B|  B|  B|  TRUE  
7|  X|  退出APP|  B|  B|  B|  TRUE  
8|  X|  另一账号登录APP|  C|  C|  C|  TRUE  
9|  X|  操作APP|  C|  C|  C|  TRUE  
10|  X|  操作APP|  C|  C|  C|  TRUE  
11|  X|  退出APP|  C|  C|  C|  TRUE  
12|  X|  操作APP|  A|  NULL|  A|  FALSE  
13|  X|  操作APP|  A|  NULL|  A|  FALSE  
14|  Y|  APP安装|  D|  NULL|  D|  TRUE  
15|  Y|  打开APP|  D|  NULL|  D|  TRUE  
16|  Y|  操作APP|  D|  NULL|  D|  TRUE  
17|  Y|  登录APP|  B|  B|  B|  TRUE  
18|  Y|  操作APP|  B|  B|  B|  TRUE  
19|  Y|  操作APP|  B|  B|  B|  TRUE  
  
User-ID功能的计算逻辑**：**

对于同一个session中的操作，系统认为是同一个用户进行的。即上表中第1->7步的操作，如果是在同一个session中，系统会自动将登录前的AAID用已登录的User-ID进行补齐，后续所有的指标统计都以补齐后的User-ID为主键进行统计。

session补齐后的事件明细表如下：

序号|  设备|  事件|  上报设备id(AAID)|  上报账号ID(User-ID)|  系统用户标识|  登录标识  
---|---|---|---|---|---|---  
1|  X|  APP安装|  A|  NULL|  A-->B|  FALSE  
2|  X|  打开APP|  A|  NULL|  A-->B|  FALSE  
3|  X|  操作APP|  A|  NULL|  A-->B|  FALSE  
4|  X|  登录APP|  B|  NULL|  A-->B|  FALSE  
5|  X|  操作APP|  B|  B|  B|  TRUE  
6|  X|  操作APP|  B|  B|  B|  TRUE  
7|  X|  退出APP|  B|  B|  B|  TRUE  
8|  X|  另一账号登录APP|  C|  C|  C|  TRUE  
9|  X|  操作APP|  C|  C|  C|  TRUE  
10|  X|  操作APP|  C|  C|  C|  TRUE  
11|  X|  退出APP|  C|  C|  C|  TRUE  
12|  X|  操作APP|  A|  NULL|  A|  FALSE  
13|  X|  操作APP|  A|  NULL|  A|  FALSE  
14|  Y|  APP安装|  D|  NULL|  D-->B|  TRUE  
15|  Y|  打开APP|  D|  NULL|  D-->B|  TRUE  
16|  Y|  操作APP|  D|  NULL|  D-->B|  TRUE  
17|  Y|  登录APP|  B|  B|  B|  TRUE  
18|  Y|  操作APP|  B|  B|  B|  TRUE  
19|  Y|  操作APP|  B|  B|  B|  TRUE  
  
上表中最终统计结果为：有**3** 个用户(A、B、C)，其中通过已登录条件过滤后的用户数是**2****个**(B、C)。
