# 应用证书指纹

#### 创建应用的证书指纹文件

  1. 打开命令行工具，输入“keytool”，验证该命令是否可以运行。
         
         keytool

如果提示不是内部或外部命令，也不是可运行的程序。请确保您已安装 JDK，并配置好环境变量。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515184204.22733201391239285924402879601989:50510515105457:2800:A139454CFA8067490A4B4B01403233BB88CFE756C8400ED00FF6CC57FDB65064.png?needInitFileName=true?needInitFileName=true)

  2. 输入命令。
         
         keytool -genkey -alias key -keyalg RSA -keystore d:key.keystore -validity 365

genkey 表示生成密钥对。alias 指定生成密钥对的别名，此处命名为 key。keyalg 指定生成密钥的算法，此处为 RSA 加密算法。validity 指定证书的有效期，单位为天，此处为 365 天。keystore 指定密钥库的存储路径，此处表示存储在 d：盘下。您可以根据实际需要，修改对应的描述。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515184204.02844110599291641388021539481049:50510515105457:2800:262593EB58FBF66068C336D588D26037B8C12653DDCA43629EA92B96166C9707.png?needInitFileName=true?needInitFileName=true)

     1. 根据提示，输入密钥库口令，如：123456abc。再次输入新口令：123456abc。 
     2. 根据提示，完成姓名、单位、组织、城市、省、国家的输入。 
     3. 确认是否输入正确，若正确，输入“y”，若错误，输入“n”。则重新填写。 
     4. 输入密钥口令，可以和之前的一样，比如：123456abc。 


  3. 至此，我们便创建好了应用的证书指纹签名文件，可以在 d 盘中找到命名为 key 的 keystore 文件。。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515184204.10158328638241300437797721003555:50510515105457:2800:408338916B51687448558904B496037B791A0B29B761F3E2E5F4D4FC28270E26.png?needInitFileName=true?needInitFileName=true)




#### 获取证书指纹文件对应的 SHA256 指纹

  1. 打开命令行工具，执行命令。
         
         keytool -list -v -keystore d:key.keystore

  2. 根据提示，输入密钥库口令：123456abc。从运行结果中获取对应的 SHA256 指纹。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515184204.25393159906912662869881189946207:50510515105457:2800:1E9162B2152C836EC19EA4AFA9BCD65CE6D1041BD6621C455CBBBACC3BF64F54.png?needInitFileName=true?needInitFileName=true)
         
         keytool -list -v -keystore d:key.keystore




#### 将证书指纹文件导入到应用中

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515184204.68915357226122389663612597494216:50510515105457:2800:AD9710B9D0261320715D688605EFBD85045E66B65EC6CE46A2CD9CD1F01AA7CE.png?needInitFileName=true?needInitFileName=true)

在”Store File”下将d盘中的 key.keystore 文件导入。并输入此前创建签名时设置的密码和别名。导入后，打开模块级的“build.gradle”文件。可以看到导入的结果。
