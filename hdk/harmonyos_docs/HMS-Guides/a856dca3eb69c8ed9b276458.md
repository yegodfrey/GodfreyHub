# 操作步骤

1.在AndroidStudio开发环境中添加当前应用的AppGallery Connect配置文件。

  * 登录[AppGallery Connect 网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择“我的项目”。

  * 在项目列表中找到您的项目，在项目列表中单击需要集成SDK的应用。

  * 在“项目设置”页面中，单击“应用”栏下的“agconnect-services.json”下载配置文件。

  * 将“agconnect-services.json”文件拷贝到应用级根目录下。




![](http://10.116.132.176:8080/idp-edit-service/editor/image/1032914/1_zh-cn_image_0000001050161878.png)

说明：

（1）在获取agconnect-services.json文件前，请确保已经完成高级分析服务的开通（开通步骤参见：[开通高级分析服务](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/Configuring#Open)）。

（2）如果您在“项目设置”模块进行过任何修改动作，包括但不限于：设置数据存储位置、开启或管理某些API等。您需要下载最新的agconnect-services.json，并替换Android应用模块App的根目录下已有的文件。

****

2.在主工程gradle中添加maven仓地址和agconnect服务依赖。
      
      1.  maven {url 'https://developer.huawei.com/repo/'}
    
    
      
      1. classpath 'com.huawei.agconnect:agcp:1.2.1.301'

3.在App模块gradle添加插件配置和SDK的版本集成。
      
      1. apply plugin: 'com.huawei.agconnect'
    
    
      
      1. implementation 'com.huawei.hms:hianalytics:5.0.0.301'
    
    

说明：

（1）maven仓地址直接在浏览器中打开，无法进行访问，只能在IDE中配置。

（2）如果应用同时需要集成push、game等其他SDK，有可能导致旧版本（2.3.0.304之前，包括2.3.0.304）的hianalytics获取aaid失败，这是因为push、game、hianalytics等SDK都依赖了华为base，最终合并成的base可能会与旧版本hianalytics依赖的opendevice不配套，接口不兼容。规避冲突方法：

        a.保持base和opendevice版本一致。

        b.将base和opendevice版本都升级到3.0.3.x以上，版本可以不一致。

        c.将所有的SDK都升级到最新。

说明：

无论是远程maven仓集成SDK，还是本地集成，请注意插件不能加在gradle首行，否则会出现应用闪退。

4.单击“Sync now”或“Sync Project with Gradle Files”，开始构建工程。
