# 服务简介

华为情景感知服务（Huawei Awareness Kit）为您提供获取用户当前时空、活动状态、音频设备状态、环境光、天气、信标等情景感知组合能力。调用这些能力，您的app可以通过更高效的方式，洞悉用户当前所处的情景，为用户提供更加智慧和贴心的体验。

## 华为情景感知服务优势

  * 融合的感知能力：统一调用，可获取多维度、可持续演进的融合情景感知能力。

  * 精确的感知结果：系统软硬件能力结合，从底层获取数据，更精确更高效。

  * 更快的响应速度：本地独立芯片处理，云侧服务请求就近响应。

  * 更低的系统消耗：感知能力共享，避免各应用与设备各自交互，降低系统开销。




*与EMUI（或Magic UI）和Kirin芯片配合，可获取更佳性能、速度及低功耗。

## Capture API和Barrier API

  * Capture API




Capture API允许您的app请求用户当前状态，如用户当前时间状态、当前位置、活动状态、耳机是否插入。例如，您的app可以在打开时请求用户时间和位置，以便推荐附近适合周末的休闲娱乐活动。

  * Barrier API




您的app可以设定情景状态的“围栏”，当用户状态达到预设情景状态时，服务会给您的app发送通知。您可以组合使用情景感知能力的围栏，以达到不同的目的。例如，您可以设定当用户进入**预设的商圈范围** 且**停留超过预设时长** 时，为用户推荐附近的服务。

# 能力介绍

## 时间感知  


时间感知能力当前支持获取大多数国家和地区的节假日信息，及全球所有城市的日出日落时间。节假日信息会定期更新，保证数据及时性与准确性。

  * Capture




获取当地或指定位置的时间状态，例如：是工作日还是周末；是否是节日；当前是早晨、下午、夜晚还是深夜。

支持通过定位信息或IP地址获取设备所在地的时间状态，或输入[ISO 3166-1 Alpha-2标准编码](https://www.iso.org/obp/ui/#search)来获取指定地区的时间状态。

**注意** ：通过定位信息获取设备所在地的时间状态仅需要大概的位置信息（经纬度精确到小数点后2位），您在获取用户的位置信息需要预先获得用户的明示同意。若使用VPN、代理服务器等访问网络，可能导致通过IP获取的时间状态与实际时间状态不符合。

  * Barrier




基于目标时间设定定时器或围栏，例如：设定日出前后1小时为“日出围栏”。

## 位置感知  


  * Capture




获取当前位置的经纬度。

  * Barrier




基于位置目标、半径（不小于200m）及停留时长，设定位置围栏，例如：设定目标周围500m范围内为围栏，当用户进入该范围时且停留超过指定时长时，触发围栏通知。

**注意** ：开发者在调用位置感知能力时，需要预先获得用户的明示同意。当未开启GPS定位功能，或所处位置GPS信号弱，可能会导致无法获取当前位置，也无法触发地理围栏。

## 活动感知

  * Capture




获取用户活动状态，包括：步行、跑步、骑行、开车、静止状态。

  * Barrier




感知用户状态变化，例如：从静止状态进入跑步状态等。

**注意** ：开发者在调用活动感知能力时，需要预先获得用户的明示同意。

## 信标感知  


信标是一种小型的、可以周期性向附近周边发送信号的设备，在信标信号范围内的设备可以收到信标发送的信号，根据此信号从云端获取相应信息。

目前Awareness Kit支持广播格式是iBeacon或Eddystone-UID的Beacon设备。广播中的Beacon ID字段，是用户自定义的，相同的Beacon ID被Awareness Kit视为同一个Beacon。开发者需告知用户这一点。

Beacon硬件设备的使用和管理方法详细请参考近距离通信服务的[Beacon管理](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/Nearby-Service-Beacon-Management)。

  * Capture




是否连接、断开、靠近已经注册的信标。

  * Barrier




基于信标状态设定信标围栏，例如：设定发现信标的围栏，当情景感知服务发现信标时触发围栏通知。

## 音频设备状态感知

支持可连接音频设备状态感知，当前支持的音频设备类型包括：3.5mm和Type C有线耳机、蓝牙耳机（蓝牙耳机是指被设备识别为“耳机”的蓝牙装置，有可能包括蓝牙耳机、某些蓝牙音响等装置）、车载蓝牙音响等。

  * Capture




获取音频设备当前状态，是连接还是未连接。

  * Barrier




感知音频设备状态变化，例如：耳机从插入变成拔出状态等。

**说明：** 在第三方手机上，可能存在对系统广播进行管控的情况，从而导致华为移动服务无法正常侦听到该广播，如蓝牙协议连接状态的广播。这会导致用户注册的与蓝牙设备相关的围栏无法正常触发。

## 环境光感知  


  * Capture




获取设备所处环境的光照度，单位Lux。光照度是设备光传感器接收到的强度，当光传感器被遮挡或被强光照射，获取的光照度会随之发生变化。

  * Barrier




设定环境光围栏，例如：设定当光照度小于100lux时，提示用户打开“手电筒”功能。

**说明** ：对于某些型号的手机，可能由于省电设置而限制Awareness Kit环境光能力，导致环境光功能不可用。开发者若希望环境光能力不受省电设置的影响，可提醒用户将HMS Core设置为不受省电策略影响。

## 天气感知

  * Capture




支持查询设备所处位置和指定位置的天气情况，查询当天24h和未来7天内（含当天）的天气情况，包括：温度、体感温度、湿度、风力、风向、紫外线强度、AQI和生活指数等，其中，AQI和生活指数仅提供中国大陆数据。

支持通过定位信息或IP地址获取设备所在地的天气情况，若使用VPN、代理服务器等访问网络，可能导致通过IP获取的天气情况与实际天气情况不符合。

支持输入地区名称获取指定地区的天气情况，地区名称由国家\区域、省\州、城市、区、县\镇五个层级组成，您可以输入某些层级的地址信息获取相应天气情况。为了获取更加精确的天气情况，建议输入名称时输入全部五个层级的名称。

  * Barrier




天气感知能力不支持围栏功能。

# 隐私声明

在基于HMS SDK开发时，您应当确认同意《[华为开发者服务协议](https://developer.huawei.com/consumer/cn/doc/start/20201)》、《[华为APIs使用协议](https://developer.huawei.com/consumer/cn/doc/distribution/app/20209)》、《[AppGallery Connect数据处理附录](https://developer.huawei.com/consumer/cn/doc/distribution/app/20215)》。情景感知服务不会保存任何个人数据，且不会向其他第三方披露个人数据。开发者在需要获取用户的敏感个人数据时（如位置信息等），需要预先获得用户的明示同意。
