# 1\. 概述

本章节针对华为作为最终用户数据处理者，开发者作为最终用户数据控制者的数据处理进行说明，包括：

•  华为处理的个人数据清单。

•  提供开发者如何帮助最终用户实现对数据的控制。

  


表1 个人数据处理清单  


个人数据| 使用目的| 存留期  
---|---|---  
图片XMP信息| 华为全景服务分析图片的XMP信息中是否包含全景定义信息，并基于此信息对图片进行渲染。| 不保存。华为全景服务在分析XMP数据后立即删除。  
  
# 2\. 如何控制最终用户的数据

华为全景服务在处理个人数据后立即删除，不会保存用户的个人数据。因此，华为无法指导开发者如何帮助最终用户实现对数据的控制。
