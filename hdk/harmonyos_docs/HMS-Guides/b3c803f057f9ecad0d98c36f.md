# AutoRecorderController 开发

#### 启动记录

启动记录的时候，必须指定数据类型，明确表明需要启动哪一种类型的数据记录。指定数据类型的方式有两种： 

  * 通过华为支持的数据类型（DataType）来记录。 
  * 通过指定数据采集器（DataCollector）来记录。 



通过数据采集器来记录时，必须指定数据类型和采集器类型（例如：RAW 原生数据，Derived 衍生数据等），RAW 类型指的是从传感器上直接传递过来的数据，没有经过任何数据的处理，Derived 类型指的是基于 RAW 类型数据，做过一部分操作的数据，例如平均、划分、统计等。

数据采集器记录时，其他的信息目前不需要添加，例如设备信息、数据流信息等，三方应用可以只通过数据类型、采集器类型、调用者包名来组装采集器进行记录。

目前，只支持累计步数（DT_CONTINUOUS_STEPS_TOTAL）、增量步数（DT_CONTINUOUS_STEPS_DELTA）类型的自动记录功能。

  1. **使用数据类型启动记录累积步数信息**
         
         HiHealthOptions options = HiHealthOptions.builder().build();
         AuthHuaweiId signInHuaweiId = HuaweiIdAuthManager.getExtendedAuthResult(options);
         AutoRecorderController controller = HuaweiHiHealth.getAutoRecorderController(context, signInHuaweiId);
         
         // 以DT_CONTINUOUS_STEPS_TOTAL为例,启动记录此类型之后,摇动手机时,累计步数就会自动插入到数据库中
         DataType dataType = DataType.DT_CONTINUOUS_STEPS_TOTAL;
         controller.startRecord(dataType).addOnCompleteListener(new OnCompleteListener<Void>() {
             @Override
             public void onComplete(Task<Void> taskResult) {
                 // 接口不会一直返回成功,所以需要增加异常回调的处理,目前接口失败的原因包括:应用没有授权,类型不支持
                 if (taskResult.isSuccessful()) {
                     Log.i("TEST","onComplete startRecordByType Successful");
                 } else {
                     Log.i("TEST","onComplete startRecordByType Failed");
                 }
             }
         }).addOnSuccessListener(new OnSuccessListener<Void>() {
             @Override
             public void onSuccess(Void result) {
                 Log.i("TEST","onSuccess startRecordByType Successful");
             }
         }).addOnFailureListener(new OnFailureListener() {
             @Override
             public void onFailure(Exception e) {
                 Log.i("TEST","onFailure startRecordByType Failed: " + e.getMessage());
             }
         });

  2. **使用数据采集器启动记录累积步数信息**

数据采集器的记录与数据类型的记录唯一的区别，就是需要打包 DataCollector 信息，在调用记录接口 startRecord 时传入 DataCollector 信息：
         
         HiHealthOptions options = HiHealthOptions.builder().build();
         AuthHuaweiId signInHuaweiId = HuaweiIdAuthManager.getExtendedAuthResult(options);
         AutoRecorderController controller = HuaweiHiHealth.getAutoRecorderController(context, signInHuaweiId);
         
         DataCollector dataCollector = new DataCollector.Builder()
                 .setDataType(DataType.DT_CONTINUOUS_STEPS_TOTAL)
                 .setPackageName(context)
                 .setDataGenerateType(DataCollector.DATA_TYPE_RAW)
                 .build();
         
         controller.startRecord(dataCollector).addOnCompleteListener(new OnCompleteListener<Void>() {
             @Override
             public void onComplete(Task<Void> taskResult) {
                 // 接口不会一直返回成功,所以需要增加异常回调的处理,目前接口失败的原因包括:应用没有授权,类型不支持
                 if (taskResult.isSuccessful()) {
                     Log.i("TEST","onComplete startRecordByCollector Successful");
                 } else {
                     Log.i("TEST","onComplete startRecordByCollector Failed");
                 }
             }
         }).addOnSuccessListener(new OnSuccessListener<Void>() {
             @Override
             public void onSuccess(Void result) {
                 Log.i("TEST","onSuccess startRecordByCollector Successful");
             }
         }).addOnFailureListener(new OnFailureListener() {
             @Override
             public void onFailure(Exception e) {
                 Log.i("TEST","onFailure startRecordByCollector Failed: " + e.getMessage());
             }
         });




#### 停止记录

停止记录操作有三种方式，包括数据类型、数据采集器、记录信息。

记录信息推荐使用 getRecords 接口获取，或通过记录信息（record）构造接口创建。创建记录信息（Record）时，可以指定数据类型、数据采集器信息，同时指定两种信息时，须保证数据采集器的数据类型与记录信息的数据类型完全一致，否则会报错。

  1. **通过数据类型停止记录累积步数信息**
         
         HiHealthOptions options = HiHealthOptions.builder().build();
         AuthHuaweiId signInHuaweiId = HuaweiIdAuthManager.getExtendedAuthResult(options);
         AutoRecorderController controller = HuaweiHiHealth.getAutoRecorderController(context, signInHuaweiId);
         
         controller.stopRecord(DataType.DT_CONTINUOUS_STEPS_TOTAL)
             .addOnCompleteListener(new OnCompleteListener<Void>() {
                 @Override
                 public void onComplete(Task<Void> taskResult) {
                     // 接口不会一直返回成功,所以需要增加异常回调的处理,目前接口失败的原因包括:应用没有授权,类型不支持
                     if (taskResult.isSuccessful()) {
                         Log.i("TEST","onComplete stopRecordByType Successful");
                     } else {
                         Log.i("TEST","onComplete stopRecordByType Failed");
                     }
                 }
             })
             .addOnSuccessListener(new OnSuccessListener<Void>() {
                 @Override
                 public void onSuccess(Void result) {
                     Log.i("TEST","onSuccess stopRecordByType Successful");
                 }
             })
             .addOnFailureListener(new OnFailureListener() {
                 @Override
                 public void onFailure(Exception e) {
                     Log.i("TEST","onFailure stopRecordByType Failed: " + e.getMessage());
                 }
             });



  2. **通过数据采集器停止记录累积步数信息**
         
         HiHealthOptions options = HiHealthOptions.builder().build();
         AuthHuaweiId signInHuaweiId = HuaweiIdAuthManager.getExtendedAuthResult(options);
         AutoRecorderController controller = HuaweiHiHealth.getAutoRecorderController(context, signInHuaweiId);
         
         DataCollector dataCollector = new DataCollector.Builder()
                 .setDataType(DataType.DT_CONTINUOUS_STEPS_TOTAL)
                 .setPackageName(context)
                 .setDataGenerateType(DataCollector.DATA_TYPE_RAW)
                 .build();
         
         // 如果想通过采集器来停止记录，最好使用之前启动记录时所用的采集器，避免采集器不一致导致功能无法正常执行
         controller.stopRecord(dataCollector).addOnCompleteListener(new OnCompleteListener<Void>() {
             @Override
             public void onComplete(Task<Void> taskResult) {
                 // 接口不会一直返回成功,所以需要增加异常回调的处理,目前接口失败的原因包括:应用没有授权,类型不支持
                 if (taskResult.isSuccessful()) {
                     Log.i("TEST","onComplete stopRecordByCollector Successful");
                 } else {
                     Log.i("TEST","onComplete stopRecordByCollector Failed");
                 }
             }
         }).addOnSuccessListener(new OnSuccessListener<Void>() {
             @Override
             public void onSuccess(Void result) {
                 Log.i("TEST","onSuccess stopRecordByCollector Successful");
             }
         }).addOnFailureListener(new OnFailureListener() {
             @Override
             public void onFailure(Exception e) {
                 Log.i("TEST","onFailure stopRecordByCollector Failed: " + e.getMessage());
             }
         });

  3. **通过记录信息停止记录累积步数信息**

虽然 Record 对象可以直接创建，但还是建议三方开发者先使用 getRecords 接口获取 Record 对象，再通过下面的接口停止记录：
         
         HiHealthOptions options = HiHealthOptions.builder().build();
         AuthHuaweiId signInHuaweiId = HuaweiIdAuthManager.getExtendedAuthResult(options);
         AutoRecorderController controller = HuaweiHiHealth.getAutoRecorderController(context, signInHuaweiId);
         
         controller.getRecords().addOnCompleteListener(new OnCompleteListener<List<Record>>() {
             @Override
             public void onComplete(Task<List<Record>> task) {
                 Log.i("TEST","stopRecordByRecord getRecords firstly");
                 if (task.isSuccessful()) {
                     Log.i("TEST","stopRecordByRecord getRecords Successful");
                     List<Record> result = task.getResult();
                     if (result == null) {
                         return;
                     }
                     if (result.size() == 0) {
                         Log.i("TEST","stopRecordByRecord there is no any record exits");
                         return;
                     }
                     for (Record record : result) {
                         controller.stopRecord(record)
                             .addOnCompleteListener(new OnCompleteListener<Void>() {
                                 @Override
                                 public void onComplete(Task<Void> task) {
                                     if (task.isSuccessful()) {
                                         Log.i("TEST","stopRecordByRecord Successful");
                                     } else {
                                         Log.i("TEST","stopRecordByRecord Failed");
                                     }
                                 }
                             });
                     }
                 }
             }
         });




#### 查看记录信息列表

查看记录信息列表，可以查看当前应用的记录信息，已经取消记录的不会显示在这里。

  1. **查看当前应用的记录信息**
         
         HiHealthOptions options = HiHealthOptions.builder().build();
         AuthHuaweiId signInHuaweiId = HuaweiIdAuthManager.getExtendedAuthResult(options);
         AutoRecorderController controller = HuaweiHiHealth.getAutoRecorderController(context, signInHuaweiId);
         
         controller.getRecords().addOnCompleteListener(new OnCompleteListener<List<Record>>() {
             @Override
             public void onComplete(Task<List<Record>> task) {
                 // 接口不会一直返回成功,所以需要增加异常回调的处理,目前接口失败的原因包括:应用没有授权,类型不支持
                 Log.i("TEST","getAllRecords:onComplete");
                 // 只有task为成功时,才能获取到Record的列表信息，所以必须加此判断
                 if (task.isSuccessful()) {
                     Log.i("TEST","getAllRecords Successfully");
                     List<Record> result = task.getResult();
                     if (result == null) {
                         return;
                     }
                     if (result.size() == 0) {
                         Log.i("TEST","getAllRecords there is no any record exits");
                         return;
                     }
                     for (Record record : result) {
                         Log.i("TEST","getAllRecords Record : " + record.toString());
                     }
                 }
             }
         }).addOnFailureListener(new OnFailureListener() {
             @Override
             public void onFailure(Exception e) {
                 Log.i("TEST","getAllRecords Failed: " + e.getMessage());
             }
         });



  2. **查看当前应用指定类型的记录信息**

使用指定类型来获取记录信息，除了会获取到用类型去启动的那部分记录信息，还会获取到用采集器去启动的记录信息，前提是，采集器中的数据类型与入参一致。
         
         HiHealthOptions options = HiHealthOptions.builder().build();
         AuthHuaweiId signInHuaweiId = HuaweiIdAuthManager.getExtendedAuthResult(options);
         AutoRecorderController controller = HuaweiHiHealth.getAutoRecorderController(context, signInHuaweiId);
         
         DataType dataType = DataType.DT_CONTINUOUS_STEPS_TOTAL;
         controller.getRecords(dataType).addOnCompleteListener(new OnCompleteListener<List<Record>>() {
             @Override
             public void onComplete(Task<List<Record>> task) {
                 // 接口不会一直返回成功,所以需要增加异常回调的处理,目前接口失败的原因包括:应用没有授权,类型不支持
                 Log.i("TEST","getRecordsByType:onComplete");
                 // 只有task为成功时,才能获取到Record的列表信息，所以必须加此判断
                 if (task.isSuccessful()) {
                     List<Record> result = task.getResult();
                     if (result == null) {
                         return;
                     }
                     if (result.size() == 0) {
                         Log.i("TEST","getRecordsByType there is no record with this type exits");
                         return;
                     }
                     for (Record record : result) {
                         Log.i("TEST","getRecordsByType Record : " + record.toString());
                     }
                 }
             }
         }).addOnFailureListener(new OnFailureListener() {
             @Override
             public void onFailure(Exception e) {
                 Log.i("TEST","getRecordsByType Failed: " + e.getMessage());
             }
         });
