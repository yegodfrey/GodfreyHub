# 自定义数据类型  
  
HUAWEI Health Kit 支持新增自定义数据类型。

注意：创建的自定义数据类型不能使用 HUAWEI Health Kit 的命名空间，即“com.huawei”。

**创建自定义数据**

  * 客户端：

通过调用 [SettingController](https://developer.huawei.com/consumer/cn/doc/HMS-References/settingcontroller-0000001050089660).[addDataType](https://developer.huawei.com/consumer/cn/doc/HMS-References/settingcontroller-0000001050089660)(DataTypeAddOptions options) 方法创建自定义数据类型，通过调用 [SettingController](https://developer.huawei.com/consumer/cn/doc/HMS-References/settingcontroller-0000001050089660).[readDataType](https://developer.huawei.com/consumer/cn/doc/HMS-References/settingcontroller-0000001050089660)(String dataTypeName) 方法读取已创建的自定义数据类型（详细操作可参考 [SettingController](https://developer.huawei.com/consumer/cn/doc/HMS-References/settingcontroller-0000001050089660)）。



  * 服务端：

通过创建具有自定义数据类型名称及字段的数据采集器（可参考 [dataCollectors: create](https://developer.huawei.com/consumer/cn/doc/HMS-References/datacollectors_create-0000001050114852)），开发者可创建自定义数据类型。例如：
        
        POST
        https://health-api.cloud.huawei.com/hihealth/v1/dataCollectors
        Content-Type: application/json
        Authorization: Bearer ***
        
        {
          "collectorName": "DataCollectorExample",
          ...
          "collectorDataType": {
            "field": [
              {
                "name": "customizedField1",
                "format": "integer"
              },
             {
                "name": "customizedField2",
                "format": "float"
              }
            ],
            "name": "customized.datatypename"
          },
          ...
        }
