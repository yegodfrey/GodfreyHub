# 1\. 开发准备常见问题

## 1.1 如何获取华为全景服务的能力？

华为公司发布的手机一般都会预装HMS Core（APK），在手机系统与HMS Core版本满足要求的前提下，开发者只需调用全景SDK就能获取全景图浏览能力。

## 1.2 全景服务是否包含服务端？

全景服务是一个纯客户端服务，聚焦于全景图片展示时三维模型的构建、渲染及交互。

## 1.3 全景服务对手机和软件有哪些要求？

原则上安装了HMS Core（APK）4.0.0.300及以上的Android 6.0以上的华为终端设备即可支持华为全景服务。

## 1.4 调用全景服务收费吗？

全景SDK当前提供的接口均免费。

## 1.5 全景服务是否会涉及用户隐私？

全景服务在全景图片的加载、建模、渲染和显示等所有过程中，都不会去存储或上传图片的信息及片段，不涉及用户隐私。

# 2\. 开发过程常见问题  


## 2.1 当前全景服务支持哪些格式的全景图？  


图片格式上支持 jpg、jpeg和png。

图片内容上支持球体全景图（包括部分球体）和环形（柱状）全景图。

## 2.2 全景服务支持展示的全景图片大小是多少？

浏览的平面图片大小不超过20M，分辨率不超16384像素*8192像素，随着图片大小增加，响应时间、内存占用、CPU占用及能耗都会有相应的增加。

## 2.3 为何图片是对的，[loadImageInfo(Context context, Uri uri)](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/panorama-api-panointerface#loadImageInfo "loadImageInfo\(Context context, Uri uri\)")接口会返回失败？

**问题原因分析：**

[loadImageInfo(Context context, Uri uri)](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/panorama-api-panointerface#loadImageInfo "loadImageInfo\(Context context, Uri uri\)")接口会检测图片中的XMP元数据是否携带了GPano标准的信息，如果未检测到，会返回失败。

**解决方案：**

可使用[PendingResult<ImageInfoResult> loadImageInfo(Context context, Uri uri, int type)](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/panorama-api-panointerface#loadImageInfo2)指定图片类型进行强制跳转。

## 2.4 [setValue](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/panorama-api-localinterface#setValue "setValue")、[getValue](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/panorama-api-localinterface#getValue "getValue")具体用于设置/获取什么属性？

[setValue](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/panorama-api-localinterface#setValue "setValue")、[getValue](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/panorama-api-localinterface#getValue "getValue")可以设置/获取的属性见[PanoramaInterface](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/panorama-api-panointerface "PanoramaInterface")中[Public Field Summary](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/panorama-api-panointerface#Public%20Field%20Summary)小节或相关注释，各个版本可能会有所改变。当前版本（4.0.3.300版本）用于设置/获取全景图的渲染方式（[KEY_RENDER_MODE](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/panorama-api-panointerface#KEY_RENDER_MODE "KEY_RENDER_MODE")）、当前方位角（[KEY_CURRENT_AZIMUTH](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/panorama-api-panointerface#KEY_CURRENT_AZIMUTH "KEY_CURRENT_AZIMUTH")）以及当前水平方向视场角（[KEY_CURRENT_HORIZONTAL_FOV](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/panorama-api-panointerface#KEY_CURRENT_HORIZONTAL_FOV "KEY_CURRENT_HORIZONTAL_FOV")）。

## 2.5 极坐标形式展示是否支持应用外全景展示调用？

暂不支持。如需体验全景图的极坐标形式展示，开发者可使用应用内全景展示调用，详情可参考[应用内全景展示调用](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/panorama-guideinside "应用内全景展示调用")。

## 2.6 视频全景是否支持环形展示？

支持环形展示。使用环形展示需要开发者设置环形的宽高比，若未设置，则将按2:1的宽高比进行显示，可能与视频实际宽高比不符，造成画面拉伸，影响显示效果。

## 2.7 环形展示的视频全景需要在何时设置视频宽高比？

获取用于视频显示的surface之后都可以进行宽高比的设置，开发者需确保宽高比与视频实际宽高比一致。可在mediaplayer.Prepare后，获取mediaPlayer的实际宽高后进行设置。

2.8是否支持图片全景与视频全景之间的动态切换？

支持动态切换，但需要开发者进行图片与视频资源的管理。
