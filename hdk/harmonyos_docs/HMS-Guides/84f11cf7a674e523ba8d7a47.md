# **Cut Cut 简介**

Cut Cut 是一款以抠图为特色玩法的专业图片编辑App，由麒麟合盛（APUS）出品，集合了AI自动抠图、轻松换背景、专业图片编辑、艺术滤镜相机、海量素材库等功能，可轻松制作适合分享到 WhatsApp 或 Facebook 等社交媒体的图片。

# **业务挑战**

图像分割是Cut Cut主要特色功能之一，能选择并提取图片内的人物对象，并根据需要将其粘贴到任何背景上。集成ML Kit图像分割之前，Cut Cut面临多重业务挑战，急需一套高性能、高可靠、优质体验的算法方案。

  * 云侧算法调用服务成本高：云侧图像分割算法调用的是第三方的API，随着用户增加，云侧的算法服务调用成本和服务器成本将随之增加。

  * 云侧调用数据传输，部分用户存在隐私安全方面的顾虑：云侧调用由于需要上传图片数据到服务器，部分用户对于上传自己的照片存在隐私安全方面的顾虑。

  * 端侧本地算法优化需要更改App：如果不上传到云侧，仅靠手机端算法来实现图像分割的功能，虽然也可以实现，但现有方案的算法固化在App内，如果算法需要升级，那么需要重新发布App版本，用户更新成本高。




# **解决方案**

随着HMS 4.0的重磅发布，HMS ML kit上线了图像分割服务，向第三方开发者提供识别图片或视频帧中各分类元素对应的像素能力，支持第三方应用在图像分割结果的基础上实现如图像区域调优，人像着色，魔法天空等功能特性。HMS ML Kit的图像分割服务完美地支持了Cut Cut的业务发展需求。

  * 服务免费，无调用次数限制：HMS致力于构建全场景智慧新生态，HMS ML Kit图像分割端侧算法免费开放且无调用次数限制，且ML Kit作为核心战略业务，在未来也将会持续投入，帮助更多的开发者实现业务创新和成功。

  * 端侧图片处理，无隐私泄露风险：HMS ML Kit的图像分割服务支持端侧处理，不依赖用户网络环境，算法随时随地可在本地流畅、精准运行，且无数据上传泄露风险。

  * 一次开发集成，算法随HMS更新而更新：开发者集成ML Kit图像分割后，仅需一次开发，便可享受模型持续更新、升级的便利，ML Kit模型伴随HMS core版本动态更新，无需重复、频繁发布应用版本。

# **合作受益**

  * **To Cut Cut** ：




HMS ML Kit图像分割服务免费开放且支持动态更新，降低了Cut Cut对图像分割服务的维护成本和使用成本，且ML Kit分割图片速度快、分割准确度高，还可支持图像分割业务拓展天空、草地等11类图像类型分割和可支持视频分割，大提升了Cut Cut的竞争力及用户体验。

离线也可进行精准图像分割，享受速度更快、效果更好的抠图体验。
