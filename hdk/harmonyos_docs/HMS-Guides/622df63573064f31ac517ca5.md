# 现状

        第三方APP的每台服务器每次接入华为服务时，都调用/oauth2/v2/token（或/oauth2/v3/token）接口去申请一个应用级Access Token，降低了自身服务性能的同时，浪费了华为的服务器资源。

# 建议方案

        在当前实现方案的基础上，在应用级Access Token 1小时有效期内重复使用，降低应用级Access Token的申请频率，1个小时内申请一次Access Token即可。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200212172327.89692953397467912644198611296500:50510211094630:2800:292642F14456BF4B3E8AC62CE37CE949B543DE934E0964BAF9C43C915956EB61.png)

# 最优方案

        应用级Access Token具有1个小时的有效期，且同一个APP的服务器之间是可以共享的，所以建议新增一个Access Token共享服务器，每隔一小时从华为Oauth-Server申请Access Token，APP如果需要接入华为服务时，直接从Access Token共享服务器获取即可。
