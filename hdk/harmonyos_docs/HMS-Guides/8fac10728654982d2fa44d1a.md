# 简介

HUAWEI Health Kit 在 Android 客户端提供了以下几个关键 API 接口：

  1. 运动健康数据的增删改查：[DataController](https://developer.huawei.com/consumer/cn/doc/HMS-Guides/datacontroller_develop-0000001050071677)。 
  2. 外设传感器的数据实时上报：[SensorsController](https://developer.huawei.com/consumer/cn/doc/HMS-Guides/sensorscontroller_develop-0000001050069728)。 
  3. 持续记录运动数据：[AutoRecorderController](https://developer.huawei.com/consumer/cn/doc/HMS-Guides/autorecord_develop-0000001050071679) 。 
  4. 创建与管理单次运动或者活动：[ActivityRecordsController](https://developer.huawei.com/consumer/cn/doc/HMS-Guides/activityrecord_develop-0000001050069730)。

#### DataController

**简介**

对运动数据和健康数据（[DataType](https://developer.huawei.com/consumer/cn/doc/HMS-References/datatype-0000001050089916)、[HealthDataTypes](https://developer.huawei.com/consumer/cn/doc/HMS-References/healthdatatypes-0000001050092315)、[SportDataTypes](https://developer.huawei.com/consumer/cn/doc/HMS-References/sportdatatypes-0000001050090882)）进行管理，包括增删改查等操作。还支持对当天统计数值和当天本地设备的统计数值进行特性化查询，并支持对六种数据类型的修改添加监听。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515184201.80210547359709526426205313256685:50510515105457:2800:AA99A790E41CA58F9651B9A19FCD0FD7BE0CCC16B7B616CA291AFE11D33CB6AD.png?needInitFileName=true?needInitFileName=true)

六种支持监听的数据类型如下：

  * 基础代谢率(以每天千卡为单位)：DataType.DT_INSTANTANEOUS_CALORIES_BMR。 
  * 体脂率：DataType.DT_INSTANTANEOUS_BODY_FAT_RATE。 
  * 身高（以米为单位）：DataType.DT_INSTANTANEOUS_HEIGHT。 
  * 单次饮水量（以升为单位）：DataType.DT_INSTANTANEOUS_HYDRATE。 
  * 用餐时摄入的的营养成分列表：DataType.DT_INSTANTANEOUS_NUTRITION_FACTS。 
  * 体重（以千克为单位）：DataType.DT_INSTANTANEOUS_BODY_WEIGHT。 



**使用场景**

  * 调用 insert 接口，将运动数据（健康数据）存储到 Health 平台。 
  * 调用 delete 接口，从 Health 平台删除运动数据（健康数据）。 
  * 调用 update 接口，更新 Health 平台中的运动数据（健康数据）。 
  * 调用 read 接口，从 Health 平台读取运动数据（健康数据）。 
  * 调用 readTodaySummation 接口， 从 Health 平台读取当天（从设备系统时区的凌晨零点到当前时间内）运动健康数据的累计值。 
  * 调用 readTodaySummationFromDevice 接口，从 Health 平台读取当天（从设备系统时区的凌晨零点到当前时间内）由本地设备产生的运动健康数据的统计值。 
  * 调用 registerModifyDataMonitor 接口，可以添加对上述六种数据类型的监听，被监听的数据类型的数据在 Health 平台有变更时，会自动触发，通知到应用。 
  * 调用 unregisterModifyDataMonitor 接口，可以取消调用 registerModifyDataMonitor 接口时添加的监听。 
  * 调用 syncAll 接口，应用可以主动触发端云数据同步， 端是指本地 Health 平台， 云是指云端服务器。 
  * 调用 clearAll 接口，应用可以清空本应用写入端测和云测的所有数据。 



#### SensorsController

**使用蓝牙连接**

Huawei Health Kit 通过使用 GATT 协议支持蓝牙低功耗设备，蓝牙低功耗 API 提供扫描可用 BLE 设备和绑定 BLE 设备接口，允许应用通过 AutoRecorder 或 SensorsController 获取 BLE 设备产生的数据”，具体包括3个功能：

  * 扫描可用的低功耗蓝牙设备。 
  * 保存并关联设备。 
  * 删除并解除绑定设备。 



**获取数据采集器**

SensorsController 提供捕捉数据采集器的实时上报的原始数据，具体功能包括：

  * 列出所有可用的数据采集器。 
  * 注册监听，接收传感器上报的数据。 
  * 移除监听，停止接收数据。 



SensorsController 不会自动储存数据采集器上报的数据，并且系统重启时也会将注册的监听信息注销。如果想要储存并且持续记录信息，请使用 AutoRecorder，推荐用户两个 API 结合使用。

#### AutoRecorderController

**简介**

后台自动记录数据，通过该接口可以实现传感器数据的自动记录。例如：步数记录

**使用场景**

  * 调用 startRecord 启动数据的自动记录。 
  * 调用 stopRecord 结束数据的自动记录。 
  * 调用 getRecords 查看当前应用启动了哪些数据的自动记录。 



#### ActivityRecordsController

**简介**

标记日常运动行为。例如：早上8:00-9:00 用户打算启动一次跑步，可以通过 ActivityRecords 将这段时间的运动标记为跑步。

**使用场景**

  * 调用 beginActivityRecord 启动活动记录。 
  * 调用 endActivityRecord 结束活动记录。 
  * 调用 addActivityRecord 将历史的活动记录写入 Health 平台。 
  * 调用 getActivityRecord 从 Health 平台读取历史活动记录。 
  * 调用 addActrivityRecordsMonitor 添加活动记录状态的监听，当活动记录状态变化时通过回调通知调用方。 
  * 调用 removeActivityRecordsMonitor 去除活动记录状态的监听。
