# 是否可以在连接阶段不进行token验证?

可以。但是，未经身份验证建立的连接是不安全的，并且可能使设备面临严重的安全漏洞。为避免这种情况，请始终使用身份验证来保护您的连接。

# 能保证不同类型的数据按发送顺序收到吗?

不能。可以保证相同类型的数据按其发送顺序到达。例如，如果发送方发送FILE数据后接着发送BYTES数据，接收方有可能先收到BYTES数据再收到FILE数据。

# 为什么和对方设备在传输的过程中，还能收到该设备的扫描回调onFound/onLost事件？

扫描和传输在同一时间，可能使用的不同技术，例如：传输使用的Wi-Fi，扫描使用的可能是蓝牙。所以针对扫描的回调事件，开发者需要进行过滤，对已建立连接设备的扫描回调事件，开发者要按需进行特殊处理（比如，过滤掉onFound/onLost事件）。

# 连接华为Nearby Message服务出现8058错误，如何处理？

出现8058错误，是因为没有通过权限认证，权限认证需要使用互联网，请检查是否有接入互联网。

# Nearby Message数据是否加密？

Nearby Message数据是通过HTTPS传输的，我们不会做任何额外加密。

# **Beacon设备是什么？可以在哪获取到Beacon设备？**    

Beacon是使用BLE技术向周围发送自己“特有ID”的一种物理设备，接收到该ID后，运行在智能手机的应用可以对该信号进行响应。

可以通过登录Beacon生产厂商的官方网站购买，购买Beacon设备。

# 开发者是否必须选择数据存储地，开发者配置的**Beacon** 数据存储到哪里？

是的，开发者必须选择数据存储地。

开发者需要选择APP对应的数据存储地（德国，新加坡，中国，俄罗斯），Beacon存储地与APP的数据存储地一致。

# 为什么需要ACCESS_FINE_LOCATION权限?    

考虑到BLE信标通常与位置相关联，所以须声明ACCESS_FINE_LOCATION权限。没有此权限，扫描将无法返回任何结果。

# 独立SDK和普通SDK有哪些区别?

独立SDK：应用集成该SDK后，使用该应用的设备不需要安装HMS Core APK，就能使用近距离通信服务的全部功能。主要在无法安装HMS Core APK的场景下使用。

普通SDK：简称SDK，应用集成该SDK后，使用该应用的设备需要安装HMS Core APK，并且主要的功能在HMS Core APK中实现的。这种方式，能实现应用和近距离通信服务的解耦。

# 独立SDK使用的时候有哪些特殊要求？

由于新版本安卓权限的管控问题，使用独立SDK的时候，您需要在工程中将SDKVersion设置成28。
