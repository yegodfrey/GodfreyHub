# 1.概述

本章节针对华为作为最终用户数据处理者，开发者作为最终用户数据控制者的数据处理进行说明，包括：

•  华为处理的个人数据清单。

•  提供开发者如何帮助最终用户实现对数据的控制。

  


**表1  个人数据处理清单**  


个人数据| 使用目的| 存留期  
---|---|---  
经度，纬度| 华为定位服务处理经纬度信息提供逆地理编码服务，为用户计算对应的地理地址。| 不保存。华为定位服务在处理个人数据后立即删除。  
  
# 2.指导开发者如何帮助最终用户实现对数据的控制

华为定位服务通过GPS+WiFi+基站定位的混合定位模式为应用开发者提供一套简单易用的精确定位接口，连接数字世界与物理世界。

华为定位服务在处理个人数据后立即删除，不会保存用户的个人数据。因此，华为无法指导开发者如何帮助最终用户实现对数据的控制。
