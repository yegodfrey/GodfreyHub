# 在Android Studio项目中集成HMS SDK

针对Android Studio开发环境，华为提供了maven仓集成方式的HMS SDK包。在开始开发前，您需要将HMS SDK集成到您的Android Studio开发环境中。

## 在Android Studio开发环境中添加当前应用的AppGallery Connect配置文件

**步骤1** 登录[ AppGallery Connect 网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择“我的应用”。

**步骤2**  在项目列表中找到您的项目，在项目中点击需要集成HMS SDK的应用。

**步骤3**  在“项目设置”页面中，单击“应用”栏下的“agconnect-services.json”下载配置文件

**步骤4**  将agconnect-services.json文件拷贝到应用级根目录下。

## 配置HMS SDK的maven仓地址

**步骤1**  打开AndroidStudio项目级build.gradle文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191220175106.89965758868326330721117190032746:50510527121218:2800:64DC4028DE6588F63D3602F2D5CBCE1C41E34B5E5E574C0B83B51A2A9C469DE5.png?needInitFileName=true?needInitFileName=true)

**步骤2**  添加如下配置。

  * 在allprojects ->repositories里面配置HMS SDK的maven仓地址。

  * 在buildscript->repositories中配置HMS SDK的maven仓地址。

  * 在buildscript -> dependencies里面增加配置。



      
      1. buildscript {        
        2.     repositories {            
        3.         google()
        4.         jcenter()
        5.         maven {url 'https://developer.huawei.com/repo/'}        
        6.    }        
        7.     dependencies {           
        8.         classpath 'com.huawei.agconnect:agcp:1.2.1.301'        
        9.     }
        10. }
        11. allprojects {            
        12.     repositories {
        13.         google()
        14.         jcenter()
        15.         maven {url 'https://developer.huawei.com/repo/'}            
        16.     }        
        17. }
    
    

注意：

maven仓地址直接在浏览器中打开无法访问，只能在IDE中配置。

## 添加编译依赖  


**步骤1**  打开应用级的build.gradle文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191220175124.31336288396629942947735888686230:50510527121218:2800:7586D3540C4CE8682F6C4FFBDE1187AABE3F0002F6A4E2E0286ABEC521A6AA8D.png?needInitFileName=true?needInitFileName=true)

**步骤2**  在“dependencies”中添加如下编译依赖。
      
      1. dependencies{ 
        2.   implementation 'com.huawei.hms:identity:{version}' 
        3.  }
    
    

注意：

 _identity:{version}_  替换为实际的SDK版本号，如：implementation 'com.huawei.hms:identity:**4.0.4.300** '

**步骤3**  在文件结尾添加配置。
      
      1. apply plugin: 'com.huawei.agconnect'
    
    

## 同步工程 

重新打开修改完的build.gradle文件，右上方出现“Sync Now”链接。点击“Sync Now”等待同步完成。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191220175253.88822765366369245142567805125235:50510527121218:2800:ED03DC794842477B9EC6F89DBA1FD201E7B3148BA7B9316129F36123B1928EE8.png?needInitFileName=true?needInitFileName=true)

注意：

如果出现错误，请检查网络连接是否正常，以及检查gradle文件是否正确。

## 多语言设置

  * 如果您的应用不需要设置只支持某些特定语言，则请忽略本步骤。应用将默认支持所有HMS SDK支持的语言。

  * 如果您的应用需要设置只支持某些特定语言，则可通过本步骤配置：




    a.    打开项目工程下app目录的build.gradle文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191220175303.53641465548105991581323078056303:50510527121218:2800:9199D25ECAB9F869FF3098661A2D06A5409687FC54717BF9B7008AA018959137.png?needInitFileName=true?needInitFileName=true)

    b.    在“android”->“defaultConfig”中新增resConfigs配置，“en”（英语） 和 “zh-rCN”（简体中文） 为必须配置的语种，配置格式如下：
      
      1. android {
        2.     defaultConfig{
        3.         ...
        4.         resConfigs "en", "zh-rCN", "需要支持的其他语言"
        5.     }
        6.  }
    
    

        HMS SDK支持的语言列表请参考[HMS SDK支持的语言](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/hmssdk_supported_language)。

# 在Eclipse项目中集成HMS SDK  


针对Eclipse开发环境，华为提供了下载HMS SDK包本地集成的方式。在开始开发前，您需要将HMS SDK集成到您的Eclipse开发环境中。

## 下载SDK  


**步骤1** 下载HMS Base SDK和要集成的服务SDK，并解压zip包。

下载地址请参见：[Eclipse SDK下载](https://developer.huawei.com/consumer/cn/doc/development/HMS-Library/sdk-download)

**步骤2** 将所有SDK工程导入到您的工作空间。

    a. 选择菜单“File > Import”，再选择“Android > Existing Android Code Into Workspace”，单击“Next”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200119195413.45969901945305423414797587926356:50510527121218:2800:E397C4E01C3FE8B97DB2FF5BFE74B48DEE8A7C585999337566BC0C170C14FBFE.png?needInitFileName=true?needInitFileName=true)

    b. 单击“Browse”，选择工程所在的文件夹目录。在“Projects”下显示待导入的工程，默认全部勾选，单击“Finish”。

注意：

待导入的工程必须和工作空间在相同的磁盘空间里，例如都在“D:\”。如果不在，您可以选择“Copy projects into workspace”，将工程文件复制到工作空间。

![](http://10.116.132.132:8080/idp-edit-service/editor/image/1032914/1_zh-cn_image_0000001050197888.png)

## 添加工程依赖关系  


**步骤1** 右键单击您的工程，选择“Properties”。

**步骤2** 在左侧选择“Android”，单击“Add”，选择已导入空间的工程，单击“Apply and Close”。

![](http://10.116.132.132:8080/idp-edit-service/editor/image/1032914/1_zh-cn_image_0000001050319710.png)

**步骤3  **右键单击HMSSdkAvailableUpdate工程，选择“Properties”。

**步骤4** 在左侧选择“Android”，单击“Add”，选择HMSSdkUI工程，单击“Apply and Close”。

![](http://10.116.132.176:8080/idp-edit-service/editor/image/1032914/1_zh-cn_image_0000001050325950.png)

**步骤5**  由于Eclipse的xml文件不支持$符号，将HMSSdkAvaliableUpdate和Agconnect-core工程下AndroidManifest.xml文件中的“${applicationId}”替换成您的应用包名。
      
      1. <application>
        2.     <provider
        3.         android:name="com.huawei.agconnect.core.provider.AGConnectInitializeProvider"
        4.         android:authorities="_${applicationId}_.AGCInitializeProvider"
        5.         android:exported="false" />
        6.     <service
        7.         android:name="com.huawei.agconnect.core.ServiceDiscovery"
        8.         android:exported="false" />
        9. </application>
    
    

## 拷贝HMSSdkStats资源文件到您的工程目录

将HMSSdkStats工程中assets目录下的资源文件拷贝到您的工程中assets目录下。

注意：

如果依赖其他的kit资源，还需要复制对应kit的资源文件到您的工程目录下。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200527172932.30248615412623736527595947014947:50510527121218:2800:E25D7DAA2E9561C86CB73A9988D63957847A5B42749E4F78CDDB6A912AB0B9E5.png?needInitFileName=true?needInitFileName=true)

## 配置工程project.properties文件

打开您工程的project.properties文件，添加如下代码，用于合并子工程中的Manifest文件。
      
      1. manifestmerger.enabled=true                                              
    
    

说明：

ADT必须是17以上版本。

## 在AndroidManifest.xml文件中配置appid

**步骤1** 打开您的工程的AndroidManifest.xml文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200119200109.81066605954765398208613356936197:50510527121218:2800:73609AA81C367A7F773B006A63423A6142ED86882F98D84F80FC88B1951C231A.png?needInitFileName=true?needInitFileName=true)

**步骤2**  配置应用的appid。

将“value”的值 _123456789_ 替换为您在华为开发者联盟网站上申请的appid。
      
      1. <meta-data
        2.     android:name="com.huawei.hms.client.appid"
        3.     android:value="_123456789_ " />
