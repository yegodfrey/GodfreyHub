# **客户端关键接口说明**

WisePlay DRM客户端接口按照第三方框架API实现，接口定义请直接参考[MediaDrm](https://developer.android.com/reference/android/media/MediaDrm)、[MediaCodec](https://developer.android.com/reference/android/media/MediaCodec)。

MediaDrm的关键接口包括：

[openSession](https://developer.android.com/reference/android/media/MediaDrm#openSession\(\))

[getKeyRequest](https://developer.android.com/reference/android/media/MediaDrm#getKeyRequest\(byte%5B%5D,%20byte%5B%5D,%20java.lang.String,%20int,%20java.util.HashMap%3Cjava.lang.String,%20java.lang.String%3E\))

[provideKeyResponse](https://developer.android.com/reference/android/media/MediaDrm#provideKeyResponse\(byte%5B%5D,%20byte%5B%5D\))

[restoreKeys](https://developer.android.com/reference/android/media/MediaDrm#restoreKeys\(byte%5B%5D,%20byte%5B%5D\))

[queryKeyStatus](https://developer.android.com/reference/android/media/MediaDrm#queryKeyStatus\(byte%5B%5D\))

[isCryptoSchemeSupported](https://developer.android.com/reference/android/media/MediaDrm#isCryptoSchemeSupported\(java.util.UUID\))

MediaCodec的关键接口包括：

[configure](https://developer.android.com/reference/android/media/MediaCodec#configure\(android.media.MediaFormat,%20android.view.Surface,%20android.media.MediaCrypto,%20int\))

[dequeueInputBuffer](https://developer.android.com/reference/android/media/MediaCodec#dequeueInputBuffer\(long\))

[queueSecureInputBuffer](https://developer.android.com/reference/android/media/MediaCodec#queueSecureInputBuffer\(int,%20int,%20android.media.MediaCodec.CryptoInfo,%20long,%20int\))

[dequeueOutputBuffer](https://developer.android.com/reference/android/media/MediaCodec#dequeueOutputBuffer\(android.media.MediaCodec.BufferInfo,%20long\))

[releaseOutputBuffer](https://developer.android.com/reference/android/media/MediaCodec#releaseOutputBuffer\(int,%20boolean\))

# 获取license

  1.创建MediaDrm对象并传入WisePlay DRM的UUID；

  2.调用MediaDrm的[openSession](https://developer.android.com/reference/android/media/MediaDrm#openSession\(\))方法打开一个会话并获取到sessionId；

  3.调用MeidaDrm的[getKeyRequest ](https://developer.android.com/reference/android/media/MediaDrm#getKeyRequest\(byte%5B%5D,%20byte%5B%5D,%20java.lang.String,%20int,%20java.util.HashMap%3Cjava.lang.String,%20java.lang.String%3E\))方法，获取License请求消息体的KeyRequest对象，传入的参数的说明如下：

  *  **sessionId** ：openSession方法返回的sessionId；

  *  **initData** ：如果KeyType为MediaDrm.KEY_TYPE_STREAMING或MediaDrm.KEY_TYPE_OFFLINE，则传入影片PSSH Box的值，PSSH Box值可从媒体的索引文件中获取（Dash流从mpd文件中获取，HLS流从m3u8文件中获取）；如果keyType是MediaDrm.KEY_TYPE_RELEASE，这个值为空；

  *  **mimeType** ：媒体类型，如果Android API版本小于26且mimeType是视频或者音频的媒体类型，传入cenc,其它都默认返回传入的mimeType，keyType是KEY_TYPE_RELEASE时可为空；

  * **keyType** ：在线获取license的场景下，填写MediaDrm.KEY_TYPE_STREAMING；获取离线license场景下，填写MediaDrm.KEY_TYPE_OFFLINE；删除license场景，填写MediaDrm.KEY_TYPE_RELEASE；

  * **optionalParameters** ：传空。




  4.在线发送获取License请求，请求以POST方式发送给业务服务器，请求头的content-type头域设置为application/json，请求的消息体为第三步获取的KeyRequest 对象的getData方法获取到的数据；

  5.得到服务端响应后，将服务端透传的WisePlay DRM Server响应的内容，通过[provideKeyResponse](https://developer.android.com/reference/android/media/MediaDrm#provideKeyResponse\(byte%5B%5D,%20byte%5B%5D\))方法，传递给底层Plugin，传入的参数为：从服务端获取到的license数据的byte数组。

**     代码样例：**

        3. try {

        7.     byte[] initData = Base64.decode(PSSH_BOX, Base64.DEFAULT);

        21.     connection.connect();
        22.     String body = "{\"payload\":\""+new String(data , UTF_8)+"\",\"psshBox\":\""+initData+"\",\"keyType\":\""+MediaDrm.KEY_TYPE_STREAMING+"\"}";
        23.     BufferedWriter writer = new BufferedWriter(new OutputStreamWriter(connection.getOutputStream(), "UTF-8"));

# 内容解密

  1. 创建[MediaCrypto](https://developer.android.com/reference/android/media/MediaCrypto.html#MediaCrypto\(java.util.UUID,%20byte%5B%5D\))对象，传入WisePlay DRM的UUID以及前边获取到的sessionId；

  2. 创建[MediaCodec](https://developer.android.com/reference/android/media/MediaCodec)对象，调用[configure](https://developer.android.com/reference/android/media/MediaCodec#configure\(android.media.MediaFormat,%20android.view.Surface,%20android.media.MediaCrypto,%20int\))方法配置MediaCodec，传入之前创建的MediaCrypto对象；

  3. 解析媒体数据，根据解析到的数据创建CryptoInfo对象（此信息封装了ISO/IEC (FDIS 23001-7:2016)“ISO基本媒体文件格式文件中的普通加密”中概述的元数据。）；

  4. 调用MediaCodec的[dequeueInputBuffer](https://developer.android.com/reference/android/media/MediaCodec#dequeueInputBuffer\(long\))，从 input 缓冲区队列申请空buffer；

  5. 把需要解码的每一帧数据拷贝到前边申请的空buffer，然后调用MediaCodec的[queueSecureInputBuffer](https://developer.android.com/reference/android/media/MediaCodec#queueSecureInputBuffer\(int,%20int,%20android.media.MediaCodec.CryptoInfo,%20long,%20int\))，将要解码的数据放入 input 缓冲区队列解码；

  6. MediaCodec 模块从 input 缓冲区队列取一帧数据进行解码处理，解码处理结束后，MediaCodec 将原始数据 buffer 置为 empty 后放回 input 缓冲区队列，将解码后的数据放入到 output 缓冲区队列；

  7. 调用MediaCodec的[dequeueOutputBuffer](https://developer.android.com/reference/android/media/MediaCodec#dequeueOutputBuffer\(android.media.MediaCodec.BufferInfo,%20long\))，从 output 缓冲区队列获取解码后的数据buffer；

  8. 调用MediaCodec的[releaseOutputBuffer](https://developer.android.com/reference/android/media/MediaCodec#releaseOutputBuffer\(int,%20boolean\))，对编解码后的 buffer 进行渲染/播放，渲染/播放完成后，再将该 buffer 释放回 output 缓冲区队列。




# 离线license管理

## 1.**获取离线license****信息**

  1. 对于离线License，在获取到License之后，调用[provideKeyResponse](https://developer.android.com/reference/android/media/MediaDrm#provideKeyResponse\(byte%5B%5D,%20byte%5B%5D\))方法，底层会返回这个离线License对应的keySetId，即离线licence的唯一id，业务需要自己保存这个id；

  2. 调用MediaDrm的[restoreKeys](https://developer.android.com/reference/android/media/MediaDrm#restoreKeys\(byte%5B%5D,%20byte%5B%5D\))，传入keySetId，后续即可使用该离线License。如果license已过期或keySetid不存在，则restoreKeys会失败,客户端需要重新到服务端申请License；

  3. 使用MediaDrm的[queryKeyStatus](https://developer.android.com/reference/android/media/MediaDrm#queryKeyStatus\(byte%5B%5D\))方法可查询license的剩余可播放时长和剩余有效期时长。

## 3. **使用离线license****播放**

  1. 通过MediaDrm的[restoreKeys](https://developer.android.com/reference/android/media/MediaDrm#restoreKeys\(byte%5B%5D,%20byte%5B%5D\))方法传入sessionId和license的keySetId判断license是否可以恢复，可以的话进行下一步；否则删除本地缓存的license关联关系；

  2. 如果license已经过期不要初始化编解码器。




## 4.**播放过程中监听license**

  1. 通过MeidaDrm的[setOnEventListener](https://developer.android.com/reference/android/media/MediaDrm#setOnEventListener\(java.util.concurrent.Executor,%20android.media.MediaDrm.OnEventListener\))方法设置listener监听；

  2. 如果listener的event等于MediaDrm.EVENT_KEY_REQUIRED，表示license即将过期（license有效期还有30秒的时候触发）；

  3. 如果listener的event等于MediaDrm.EVENT_KEY_EXPIRED，表示license已经过期；

  4. 如果即将过期，业务可自行决定是否触发重新申请license流程。
