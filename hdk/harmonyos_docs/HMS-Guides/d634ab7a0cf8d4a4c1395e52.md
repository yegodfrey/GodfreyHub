ML Kit同时支持32位和64位架构，如您只需要64位架构的二进制文件，可以参考如下方法移除32位的二进制文件。
      
      1. android{
        2.     defaultConfig{
        3.         ndk.abiFilters 'arm64-v8a', 'x86_64'
        4.     }
        5. }
    
    

通过以上配置，可以有效减少您的应用集成ML Kit SDK之后的包大小。
