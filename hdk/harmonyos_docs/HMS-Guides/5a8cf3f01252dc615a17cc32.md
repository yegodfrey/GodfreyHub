# **背景介绍**

同程艺龙是中国在线旅行行业的创新者和领先者。2020年4月22日，同程艺龙推出了全新的服务品牌“同程旅行”，致力于让旅行更简单、更快乐，持续创新，为用户创造简单、快捷、智能的出行服务。

# **面临挑战**

如何提供更加贴心的旅行服务，在激烈的市场竞争中拥有差异化竞争优势，是各大旅行公司一直在思考的问题。怎样才能及时甚至提前洞悉用户需求，提供最适合的选择，是同程旅行面临的业务挑战：

  * 如何根据特定用户的特定情景，如所处的位置、节假日信息、天气情况等，提供刚刚好的服务。

  * 如何通过更快的响应速度，获得更精准的情景感知结果，且尽可能降低对系统资源的消耗。




# **解决方案**

华为HMS情景感知服务（Awareness Kit）提供获取用户情景状态的组合能力，如用户所处位置、活动状态、节假日、天气情况等感知能力。调用这些能力，可以更高效地洞悉用户当前所处的情景，为用户提供更加智慧的旅行体验。

同程旅行通过调用HMS情景感知服务，注册地理围栏、查询天气情况等，实现了“千人千面”的定制化服务。

例如，用户离开常驻城市，抵达目的地机场，通过分析以上情景，感知用户可能需要预定当地的酒店。此时，同程将为用户推荐当地酒店预定专属福利。

再如，用户即将前往旅行目的地，通知用户该地的天气情况、穿衣指数等信息，让用户享受同程更加贴心和人性化的服务。

# **合作收益**

  * **同程旅行**         




第一时间洞悉用户需求，提升用户下订单的概率。

一次集成即可获取多种感知能力，无需另外投入研发人力，节省建设成本，且感知结果精准、响应速度快、系统消耗低。

  * **同程用户**         




享受更加贴近需求的个人服务，简单、快捷、智能地出行。
