# 修改包名、导入证书指纹

#### 修改包名

包名修改方式请参考“[应用包名](https://developer.huawei.com/consumer/cn/doc/HMS-Guides/package_name-0000001050069758)”。注意包名需与“[申请帐号服务](https://developer.huawei.com/consumer/cn/doc/HMS-Guides/apply_id-0000001050069756)”中填写的包名一致。

#### 导入证书指纹

导入证书指纹请参考“[应用证书指纹](https://developer.huawei.com/consumer/cn/doc/HMS-Guides/signing_fingerprint-0000001050071709)”。注意证书指纹需与“[申请帐号服务](https://developer.huawei.com/consumer/cn/doc/HMS-Guides/apply_id-0000001050069756)”中填写的证书指纹一致。
