# 1\. 场景介绍

Push Kit支持通过APNs（Apple Push Notification service）向iOS设备发送消息的能力，即支持iOS消息推送代理功能。

# 2\. 开发准备

当前AppGallery Connect不支持创建iOS应用，所以iOS推送代理功能是挂在某一个安卓应用中。您需要先创建一个安卓应用，请参考安卓应用[开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/Preparations)。

要实现给iOS应用推送消息，需要参考苹果官网指导在苹果开发者网站上创建一系列凭证和证书，主要包括创建Identifiers、Keys、Certificates，然后下载证书到本地，添加到钥匙串后导出p12文件。其次需要一个iOS应用的token，用于向指定的iOS设备发送消息。其它准备请参考下面内容。
