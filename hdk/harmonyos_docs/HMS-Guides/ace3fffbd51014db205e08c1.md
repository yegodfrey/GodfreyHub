本章节主要指导开发者如何管理Beacon设备。近距离通信服务提供了两种管理Beacon设备的方法，一种是通过RESTful接口，使用方法可以查看API参考[RESTful APIS of Beacon](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-call-process)，或者示例代码[Becon管理示例代码参考](https://developer.huawei.com/consumer/cn/doc/development/HMS-Examples/nearby-service-examples#h1-1584084290661-0)。另一种通过网页操作，本章节主要讲解网页操作的使用方法。开始管理Beacon设备之前，需要完成如下操作

  1. 开通近距离通信服务。

  2. 创建服务子账号。

  3. 选择数据存储站点。

  4. 注册Beacon设备，使用方法请参考[注册Beacon](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-register-beacon)。




# 创建服务账号秘钥  


开发者给第三方用户创建服务账号秘钥，第三方用户可以使用该账号管理Beacon。详情请参考[API Console操作指南](https://developer.huawei.com/consumer/cn/doc/start/api-console-guide) -》“4.3 服务账号秘钥”。

说明：

在联盟创建服务账号秘钥（service account）时，对应的clientID将会存储在四个站点(中国、亚非拉、欧洲、俄罗斯)的Nearby服务器。当开发者将service account分配给具体的用户时，需要在隐私声明中指明clientID的存储位置。

# 管理Beacon设备

选择完成存储站点之后，就看到该站点上所有注册的Beacon设备，通过该页面对Beacon进行管理。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200227094529.01701771681306632319771195989136:50510610105628:2800:3D8D3159405B29211F2ADEDA05A3DE4D0EBD2B1EFC85E630ACD0155925927CBE.png?needInitFileName=true)  

图中标识①的地方，可以对每个Beacon进行“详情”，“消息附件”，“删除”三个操作。

详情：可以改变Beacon的状态（激活，去激活和停用）和更新Beacon设备属性。

消息附件：可以配置消息附件和删除消息附件。

删除：删除Beacon设备。

## 详情

在“详情”操作界面中，标记①的位置可以改变Beacon的状态（激活，去激活和停用）。

经纬度信息，支持三种方式获取：

1、通过在地图上选点。

2、在“位置信息”输入要搜索具体地点，通过搜索获取具体地点的经纬度信息。

3、手动输入经纬度信息，对于华为地图不支持的地区，需要您手动输入。华为地图支持的国家和地区请查询[支持的国家和地区](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/hms-map-supportedregions)。

修改完Beacon设备的属性，点击“提交”即可生效。

## 消息附件(Attachment)

在“消息附件”的配置页面中，点击标记①处“配置”可以配置消息附件具体内容；点击标记②处“删除”可以删除该消息附件。

在该页面填写相应的消息类型、消息内容，点击“提交”，完成配置消息附件的操作。
