# 移动端SDK  


移动端SDK需要在应用打包时，被加载到您的应用中，SDK会随着应用启动而运行在客户进程中。当用户关闭应用时，SDK会随着客户应用关闭而关闭，不会在后台做额外的操作。

# SDK权限说明

SDK 需要使用的权限如下，各个服务不同应用场景需要使用的权限不同，详细请参考[指定权限](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-assigning-permissions-4)。

  * 相机权限：android.permission.CAMERA 用于通过摄像头实时获取图片或视频。
  * 访问网络权限：android.permission.INTERNET 用于访问网络获取云侧服务。
  * 麦克风权限：android.permission.RECORD_AUDIO 用于录音。

  * 写存储权限：android.permission.WRITE_EXTERNAL_STORAGE 用于升级算法版本。
  * 读存储权限：android.permission.READ_EXTERNAL_STORAGE 用于读取设备存储的图片。
  * 查看网络状态权限：android.permission.ACCESS_NETWORK_STATE 用于查看网络连接状态信息。

  * 查看Wi-Fi网络状态权限：android.permission.ACCESS_WIFI_STATE 用于查看Wi-Fi网络状态相关信息。




# SDK收集数据

ML Kit部分服务支持两种集成SDK的方式：Full SDK和基础SDK，详情请参考[集成HMS SDK](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-agc)。

开发者在使用Full SDK服务过程中，ML Kit会对API的调用情况进行必要的数据收集，用于统计分析及服务改进。您需要在应用的隐私政策中告知用户。在使用基础SDK服务过程中，在用户许可后进行数据收集。收集的数据不包含任何个人数据，收集的数据信息如下：

  * 设备及使用信息：设备型号、客户端EMUI版本号、Android版本号、运营商标识信息、网络链接类型、提供服务的国家码。
  * 应用信息：开发者应用名称、HMS ML Kit版本号、应用包名、应用appId。
  * 接口信息：接口调用类型、APK的版本号、算法模型名称、算法模型版本、开放能力或者子能力标识、接口调用结果码、接口响应时延、翻译服务的源语言和目的语言、语音时长、语音数据使用的语言、语音合成使用语言、语音合成使用的语音类型、音频文件时长、音频文件的语言。



# SDK数据安全保护

ML Kit SDK与ML Kit端侧服务之间的数据交换基于Binder传输，Android系统本身的安全机制保障了基于Binder传输的数据安全。

ML Kit SDK 调用云侧服务采用https post请求发送，并对应用的可靠性进行鉴权识别。
