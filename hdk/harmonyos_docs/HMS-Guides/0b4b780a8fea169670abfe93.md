# Drive Kit 4.0.3版本 (2020-04-15)

最新子版本号：4.0.3.300

华为云空间服务推出了全新的Drive SDK 4.0.3 版本，本版本接口变更如下，欢迎广大开发者接入。

#### 新增特性

  1. 新增文件评论和回复特性。

支持对文件评论和回复的新增、获取、删除、修改。

  2. 新增文件在线预览特性。

支持生成在浏览器中在线打开文档的链接。

  3. 新增批量调用Drive接口能力。




#### 修改特性

  1. 增强文件基础管理能力。

支持获取用户是否承认有下载已知恶意软件或其他滥用文件风险的能力；




# Drive Kit 4.0.0版本 (2020-01-15)

最新子版本号：4.0.0.301

华为云空间服务推出了全新的Drive SDK 4.0.0 版本，本版本接口变更如下，欢迎广大开发者接入。

#### 新增特性

  1. 新增文件搜索特性：支持基于文件名称、MimeType等属性搜索和过滤。

  2. 新增基于应用的文件权限管理：支持每个应用仅访问自己的文件和数据。




#### 修改特性

  1. 增强文件基础管理能力：支持文件内容更新，图片视频扩展元数据查询和提取。支持生成用于浏览器的临时下载链接。

  2. 增强APP接入Scope权限控制：支持应用数据管理权限和应用内文件管理权限。




  


# **SDK****依赖说明**

  1. 最新版本SDK需要用户手机上安装HMS Core（APK）3.0.0.303及以上版本； 如果用户手机没有安装，您的应用调用HMS Core时，会自动引导用户提示安装。

  2. 本服务的主要特性都可以在大多数华为终端上支持，部分高级特性依赖于EMUI版本。请参考[部分特性对于EMUI的依赖说明](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/emui_version_dependent_features)。




提示：您的应用在华为应用市场上架过程中，如有问题可发送邮件至HMSCore@huawei.com咨询。
