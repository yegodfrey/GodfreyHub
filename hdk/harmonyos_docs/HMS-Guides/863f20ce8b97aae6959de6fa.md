# 场景介绍

根据《[国家新闻出版署关于防止未成年人沉迷网络游戏的通知](http://www.sapprft.gov.cn/sapprft/contents/6588/407807.shtml)》的要求提供了防沉迷接入方案，中国大陆发布的游戏需要开发者按照上述通知结合游戏自身完成游戏防沉迷功能的开发。

# 注意事项

[PlayersClient.submitPlayerEvent](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/playersclient-v4#submitPlayerEvent)和[PlayersClient.getPlayerExtraInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/playersclient-v4#getPlayerExtraInfo)如果返回7002或7006错误码，需进行如下处理：

  * 7002：需判断是否为网络问题，如果不是网络问题则表示该帐号未在中国大陆注册，请直接放通，无需进行强制处理。

  * 7006：表示该帐号未在中国大陆注册，请直接放通，无需进行强制处理。




# 实名认证

中国大陆地区发布的游戏必须要进行实名认证，用户在使用华为帐号登录游戏或使用华为支付时会引导用户强制进行实名认证，具体请参见[游戏登录](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/game-login-v4)。

# 防沉迷监控

玩家登录或切入游戏时，游戏需要上报玩家进入游戏的事件。玩家退出或切出游戏时，游戏需要上报玩家退出游戏的事件。华为游戏服务根据玩家事件统计玩家游戏时长，游戏可以实时查询玩家是否成年以及玩家当天的累计游戏时长，根据国家要求对未成年人的游戏时间进行防沉迷监控。

玩家的累计游戏时长是指当前玩家的华为帐号在所有游戏中的当天累计时长总和，计算方式为在线时长+离线时长。

  * 在线时长是指最近一次上报进入游戏事件且未上报退出事件时玩家在当前游戏中已经累计的在线时长，以及玩家在其他游戏会话中的在线时长（取最近一次心跳离进入游戏时的时长+15分钟）。

  * 离线时长是指已经通过进入+退出游戏事件上报后已经结算的时长。

4、如果玩家未成年，则需使用[PlayerExtraInfo.getPlayerDuration](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/playerextrainfo#getPlayerDuration)查看其当前的累计游戏时长，该游戏时长为玩家当天最新的累计游戏时长。游戏需要根据累计游戏时长进行未成年玩家的防沉迷监控，具体规则由开发者自行定义。

5、当玩家退出游戏、从前台切到后台或游戏异常退出（进程终止、手机重启等）时，应用再次调用[PlayersClient.submitPlayerEvent](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/playersclient-v4#submitPlayerEvent)上报玩家退出游戏事件。
