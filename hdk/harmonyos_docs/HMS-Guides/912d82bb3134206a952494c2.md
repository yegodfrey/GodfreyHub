# 1 证书申请

在创建Wallet kit服务之前，需要提前使用华为提供的证书生成工具，按照如下步骤生成私钥和证书请求文件：

  


**步骤1：** 下载[WalletKitGenerateRsa.zip](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyManage/011/111/111/0000000000011111111.20200227162556.10962902167273306792451175074471:50510430014336:2800:8F53725196F9A8751227811F311461357CC023667A42BB41AFB2D57E5B099695.zip?needInitFileName=true "WalletKitGenerateRsa.zip")压缩包，解压并打开，双击运行**Generator certificate****.bat** 文件：

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200227162746.81439950717745923310159671842595:50510430014336:2800:3C6708DD4B9976F50D3110B90A3382357015DE1EF9B7830C939DFAC4356ED2CC.png?needInitFileName=true)

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200227162905.94764752622674540432198761869016:50510430014336:2800:34840F3F77AC944FD113A3D00BA5CE7DCA7AE942ACA19B9FC1DB8F8AF5E1F11E.png?needInitFileName=true)

  


**步骤2：** 按照提示，输入服务号，建议格式为【hwpass.公司简称.项目名称.pass.服务项目】，可为大小写英文字母、数字，中间以.分割，长度不超过100个字符。

            例：服务项目为发票类的为hwpass.xxx.xxx.pass.invoice。

**步骤3：** 运行成功后，界面会提示生成的文件路径，默认当前路径的RSA密钥文件夹下：

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200413114732.08205642292173712825597860095101:50510430014336:2800:6237AA8EE2B1F31F71DEDA88BBC1AD94D8BB66D706B70EB8EE1EB8CDA7F9D094.png?needInitFileName=true)

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200413114732.65813415112272496449931999004885:50510430014336:2800:4B04B87898D327A2FFF11292B5B3D1A34590A47B7A7071DE31E1841B95846669.png?needInitFileName=true)![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200227163128.07351692663698343723188302249930:50510430014336:2800:623EE590258A0D4D553E6FE591397622CDAD316865EFF6021ECABF37E845AF3D.png?needInitFileName=true)

**步骤4：** 服务号.txt结尾的文件为证书请求CSR文件，华为开发者联盟网站AGC上注册Wallet Kit服务时使用。

服务号.pem结尾的文件为私钥，请妥善保存，不要泄露给其他人。

# 2 公私钥申请

在创建wallet kit服务之前，需要提前使用华为提供的公私钥生成工具，按照如下步骤生成公钥和私钥：

**步骤 1  **下载[RSAUtils.zip](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyManage/011/111/111/0000000000011111111.20200403101243.96886392927962073152370918877585:50510430014336:2800:6F1C87F89812736B81BBF889D200CB435A6DE3C3F89B3AAE7A826E687A2C465B.zip?needInitFileName=true "RSAUtils.zip")压缩包，解压并打开RSAUtils文件夹，双击运行**start.bat** 文件：

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200403101122.03609210524712610731498029884522:50510430014336:2800:E184DC5EB1D232D0D7624B0343973E80DDF80C87C9D033AEFFB788B06EEBAD8D.png?needInitFileName=true)

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200403101131.50157745393414064110131127453207:50510430014336:2800:1FE5269EA73E5AF181BB4B879382F36306600B9388D375E5F6322158899D2689.png?needInitFileName=true)

**步骤 2  **运行成功后，界面会提示公私钥生成的文件路径，默认当前路径的out文件夹下：

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200403101038.44114945570577733499831612577309:50510430014336:2800:FB879E6B23982504A58C4AFDDAC1C2D9DD83CDFD8BA4B491FE299FE45E7693C2.png?needInitFileName=true)

**步骤 3****** 公钥文件为publickey.txt，请将文件内容拷贝后在华为开发者联盟网站AGC上注册Wallet Kit服务时使用。

私钥文件为privateKey.txt，请妥善保存。
