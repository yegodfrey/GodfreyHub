在开始API开发工作之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-process-4)，同时请确保您的工程中已经[配置HMS Core SDK的maven仓地址](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-maven-4)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-product-sdk-4)。

1\. 创建拍照购物分析器。可以通过拍照购自定义参数类[MLRemoteProductVisionSearchAnalyzerSetting](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLSearchAnalyzerSetting-4)创建分析器。
      
      1. // 方式1：使用默认的参数配置。 
        2. MLRemoteProductVisionSearchAnalyzer analyzer  
        3.     = MLAnalyzerFactory.getInstance().getRemoteProductVisionSearchAnalyzer(); 
        4. // 方式2：使用自定义的参数配置。 
        5. MLRemoteProductVisionSearchAnalyzerSetting settings = new MLRemoteProductVisionSearchAnalyzerSetting.Factory() 
        6.     // 设置最多返回的商品信息数。 
        7.     .setLargestNumOfReturns(16) 
        8.     .create(); 
        9. MLRemoteProductVisionSearchAnalyzer analyzer  
        10.     = MLAnalyzerFactory.getInstance().getRemoteProductVisionSearchAnalyzer(settings);
    
    

2\. 通过android.graphics.Bitmap构造[MLFrame](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLFrame-4)，支持的图片格式包括：jpg/jpeg/png/bmp。
      
      1. // 通过bitmap创建MLFrame，bitmap为输入的Bitmap格式图片数据。 
        2. MLFrame mlFrame = new MLFrame.Creator().setBitmap(bitmap).create();
