# 操作步骤

1.如果没有华为开发者联盟帐号，需要先注册帐号并通过实名认证。详细操作请参见[帐号注册认证](https://developer.huawei.com/consumer/cn/devservice/doc/20300)。

2.参见[创建项目](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-get-started#createproject)和在[项目中添加应用](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-get-started#createapp)完成应用的创建。

3. 开通高级分析服务：

  * 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，单击“我的项目”图标。

  * 选择需要查看分析数据的应用。

  * 单击“分析”下的任意菜单可开通分析服务。




![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200511144418.55882812133697652853961921624416:50510511124018:2800:102AEF4C768722E3897A639083832950075D33ACFA580E31AEF025EF0D3B3467.png?needInitFileName=true)

4\. 进入“项目接入设置”页面，设置数据存储位置、时区、货币、设置用户数据留存时间、设置自然周定义后，单击“完成”，即完成Analytics Kit服务开通。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200511144443.72648274695297472791561825124188:50510511124018:2800:8EA4C3E3EADC06E737CC07D355C255D62D14476606A373F0D4EEABC21F26AF9C.png?needInitFileName=true)

说明：

请打开[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，“我的项目 > 项目设置 > API管理”开启HUAWEI Analytics。
