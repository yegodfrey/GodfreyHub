# **背景介绍**

去哪儿网是中国领先的无线和在线旅游平台，通过全平台覆盖，随时随地为消费者提供机票、酒店、度假、旅游团购、及旅行信息的深度搜索，帮助消费者找到性价比高的产品、优质的信息和便捷的预订方式，聪明地安排旅行。

# **面临挑战**

旅行行业经过多年的发展，同质化竞争严重。如何第一时间洞悉用户的需求，在旅行的不同环节间智能衔接，往往成为留住用户形成商业闭环的关键，也是去哪儿体现差异化竞争优势面临的挑战：

  * 如何在用户的旅行状态发生变化时，根据用户所处的特定情景，如所处的位置、节假日信息、天气情况等，提供刚刚好的服务。

  * 如何通过更快的响应速度，获得更精准的情景感知结果，且尽可能降低对系统资源的消耗。




# **解决方案**

华为HMS情景感知服务（Awareness Kit）提供获取用户情景状态的组合能力，如用户所处位置、活动状态、节假日、天气情况等感知能力。调用这些能力，可以更高效地洞悉用户当前所处的情景，为用户提供更加智慧的旅行体验。

去哪儿网通过调用HMS情景感知服务，注册地理围栏、时间围栏、查询天气情况等，帮助消费者更聪明地安排旅行。

例如，在即将闭园时，用户依然在景区内游玩，同时第二天也是个出游的好天气。通过分析以上情景，感知用户可能意犹未尽，需要预定周边其他景区门票和附近的酒店，去哪儿旅行APP此时将为用户推荐对应的热门套餐，给用户提供贴心的旅行安排。

再如，当发现用户超过酒店的退房时间仍停留在酒店范围内，通过分析以上情景，感知用户可能需要续订，去哪儿旅行APP此时将为用户推荐续订酒店的优惠套餐，提升订单转化率。
