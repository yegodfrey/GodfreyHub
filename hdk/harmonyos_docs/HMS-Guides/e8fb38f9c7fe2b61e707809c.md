本章节主要介绍接入华为支付的客户端开发步骤，以帮助开发者快速了解华为支付提供的客户端接口及其调用方法。请开发者参考“应用开发-场景介绍-支付场景举例”，基于接口使用场景，自行选择相应的开发章节。

对于使用自定义价格支付pay接口的开发者需要完成如下开发步骤：

    1. 初始化Agent

    2. 调用pay自定义价格支付接口完成支付

    另外对于有自己应用服务器的开发者需要完成支付回调服务器的开发工作，详细步骤参考《服务端开发》章节。

# 1 初始化Agent

    HMS Agent 套件提供了对HMS Core SDK原生接口的二次封装，处理了部分必要的接入逻辑而不再将它们暴露给开发者，使用封装后的Agent接口接入HMS Core SDK，可大大提升接入效率，降低出错几率。

##### 

## 1.1 开发步骤

    **调用init**

    请务必在application的onCreate方法中初始化HMS Agent套件。如果没有自己的application类，请创建MyApplication类，并在manifest文件中配置application节点的name属性。  
    **示例代码：**
      
      1.  /** 
        2.  *初始化HMS Agent
        3.  */
        4. public class MyApplication extends Application {
        5.         @Override
        6.         public void onCreate() {        
        7.                 super.onCreate();
        8.                 HMSAgent.init(this);
        9.         }
        10. }

# 2 调用pay自定义价格支付接口

## 2.1 接口说明

   **  接口名：**void HMSAgent.Pay.pay (PayReq request, PayHandler handler)，简称pay。

    接口详细定义请参见pay。

    自定义价格pay支付接口仅限于国内开放，适用开发者对单个国家或地区提供的商品或服务自行定价或随时修改价格的场景，开发者无需使用华为PMS系统进行商品全球定价。可以帮助开发者快速实现应用内支付功能。

但是对于没有服务器的单机应用，开发者可以调用Agent中封装的PaySignUtil.rsaSign(PaySignUtil.getStringForSign(payReq), pay_priv_key)方法获取支付签名信息，此时请开发者自行确保私钥的安全性。对于有服务器的非单机应用，我们强烈建议开发者在自己的应用服务器端保存签名私钥，并在服务器端完成签名操作，避免私钥的泄露，参考《服务端开发》章节。  


如果上述示例代码中的payReq.sign无法用PaySignUtil.rsaSign(PaySignUtil.getStringForSign(payReq), pay_priv_key)获取，请参考如下方式获取签名（详见客户端示例代码）：

    **签名方法：**

**1\. 构造源串**

    将支付参数中需要参与签名的参数（参与签名的参数是指[payreq](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-tv-pay)中标识需要签名的参数，值为空<包括null和"">的不参与签名），按参数名的ASCII码的增序排序，若遇到相同首字母，则看第二个字母，以此类推。  
    例如：

    BankId=JUNNETNET&amount=2.00¬ifyTime=1353317037173&orderId=918370122485714G&payType=2&productName=珍珠项链&requestId=1352286825177&result=0&userName=lilan

**2\. 生成签名值**

（a）将源串使用RSA算法（SHA256WithRSA）进行签名。  
（b）将签名后的字符数组经过Base64.encode编码，生成签名值。

    支付结果校验说明  


    当出现以下情况时需要查询订单实际状态：  
       ●  支付过程异常中断  
       ●  支付结果码为-1005、30005、30002  
       ●  结果码为0但是验签失败  
    对于非单机应用（应用有自己的服务器端）由于支持支付结果回调自己的应用服务器，客户端需要访问自己的服务器确认是否支付成功的情况，具体开发者客户端和开发者服务器的支付验证接口协议，由开发者客户端和开发者服务器自行协定。  
    **说明：对于单机应用（应用无自己的服务器端）需要调用PaySignUtil.checkSign(payInfo, pay_pub_key)接口进行签名操作，在服务器端完成签名的可在客户端跳过此步骤。**
