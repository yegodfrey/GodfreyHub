# 1 概述

酒店、家用门锁是华为钱包与酒店及门锁厂商合作推出的用手机替代房门实体钥匙的功能。用户在办理酒店入住时可授权开通酒店房卡，用手机NFC功能刷卡（家用门锁则需要与支持的品牌门锁进行配对后方可使用），就能解锁房门。

Wallet Kit提供商户将酒店以及家用门锁模拟至华为钱包的能力。商户仅需注册开发者联盟应用后在相应位置配置推广服务，开发者联盟会将产品内容上架至华为钱包App内的内容展示位。用户点击后华为钱包将模拟商户进行发卡操作，发卡完成后用户将在华为钱包中领取一张未配对/未授权的卡片，待用户点击配对/授权按钮并在特定写卡器上执行写卡操作后即可领取一张已激活的酒店或者家用门锁卡片。

注：此方式当前仅支持中国大陆区域。

# 3 功能实现

## 3.1 卡劵领取

### **商户配置推广服务**

商户通过申请开发者联盟应用后可配置相应的推广服务 ，可将产品内容上架至华为钱包App内的内容展示位，合作伙伴可触达华为钱包里的优质流量，以提高商品或品牌的曝光度和知名度。

例：通过申请推广服务，合作伙伴可将内容配置到开发者联盟中，图片素材及目的访问URL地址需由合作伙伴提供，华为运营人员审核后发布。

  1. 创建Wallet Kit推广服务。

![](http://10.116.132.132:8080/idp-edit-service/editor/image/1032914/1_zh-cn_image_0000001050176432.gif)

  2. 选择推广样式。

![](http://10.116.132.132:8080/idp-edit-service/editor/image/1032914/1_zh-cn_image_0000001050418411.gif)

  3. 上传资料。

![](http://10.116.132.176:8080/idp-edit-service/editor/image/1032914/1_zh-cn_image_0000001050267142.gif)

  4. 创建推广服务成功。

![](http://10.116.132.176:8080/idp-edit-service/editor/image/1032914/1_zh-cn_image_0000001050178485.gif)

推广服务可以让华为钱包用户在访问华为钱包会员卡等栏目时浏览到商户配置的推广服务展示位，用户可以点击配置的展示位跳转到商户相对应的推广H5，此H5推广界面可以是比如用户申领会员卡界面或其他推广内容。




### **华为钱包代替商户进行发卡操作**

用户点击华为钱包推广服务展示位后，华为钱包将读取商户配置在开发者联盟的模板信息，并通过华为服务器签名保存到华为钱包中。同时还将调用TSM服务申请指令在芯片中开通NFC卡片，开通成功后将生成一张未配对/未授权的卡片。

### **离线写卡**

用户点击去配对/去授权按钮，华为钱包将激活卡片并打开卡模拟，门锁或者写卡器等写卡设备通过NFC非接通道写入个人化信息并完成配对/授权，待操作执行完毕后商户即可通过特定读卡器验证配对/授权是否成功。
