# 简介

HUAWEI Health Kit 允许三方生态应用通过 REST API 接口访问数据库，对用户数据进行增、删、改、查等操作，为消费者提供运动健康类数据服务。

当前 HUAWEI Health Kit 提供四大类 REST API 接口：

#### dataCollectors

**简介：** 对数据采集器进行增删改查等操作，其中数据采集器用于采集传感器的运动健康类数据，采集的数据可以是传感器的原始数据，也可以是经过转换或合并后的派生数据。

**使用场景**

  * 调用 create 接口，创建一个数据采集器，并存储到数据库。 
  * 调用 delete 接口，从数据库删除数据采集器信息。 
  * 调用 update 接口，更新已存在的数据采集器信息到数据库。 
  * 调用 get 接口，从数据库读取一个数据采集器信息。 
  * 调用 list 接口， 从数据库读取该用户下所有的数据采集器列表。 



#### dataCollectors.sampleSets

**简介：** 对采样数据集以及采样点进行增删改查等操作，其中采样点是数据采集器得到的样本点数据，采样数据集是一系列有关联的采样点。

**使用场景**

  * 调用 patch 接口，上传数据采集器采集的采样数据到数据库。 
  * 调用 delete 接口，从数据库删除指定时间内所有采样点。 
  * 调用 get 接口，从数据库读取指定时间内所有采样点。 
  * 调用 history 接口，从数据库读取指定数据采集器下的采样数据的历史记录。 



#### activityRecords

**简介：** 对活动记录进行增删改查等操作，活动记录指用户在一段时间内某个活动状态的持续过程记录。

**使用场景**

  * 调用 update 接口，创建或者修改一个 activityRecord，并存储到数据库。 
  * 调用 delete 接口，从数据库删除指定的 activityRecord 数据。 
  * 调用 list 接口，从数据库查询用户已创建的活动记录列表。 



#### sampleSet: polymerize

**简介：** 对特定数据类型或数据采集器的数据进行合并分组并返回分组结果，例如查询每日的运动步数等。

**使用场景：**

  * 调用 sampleSet: polymerize 接口，将特定数据类型或数据采集器的数据按一定规则分组。
