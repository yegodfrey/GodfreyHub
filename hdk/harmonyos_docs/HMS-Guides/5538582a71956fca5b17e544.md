# 1 SDK工作方式

移动端SDK需要在应用编译打包时，被加载在您的应用当中。SDK会随着客户应用的调用而启动，不会自动启动，也不会在后台做任何额外动作。

# 2 SDK权限说明

SDK不需要任何权限。  


# 3 SDK收集数据

SDK会使用客户应用的appid、包名和接口调用情况，用于牵引Site服务能力的持续优化和改进。  
SDK不会收集用户数据。

# 4 SDK数据安全保护

SDK不会收集用户个人数据。
