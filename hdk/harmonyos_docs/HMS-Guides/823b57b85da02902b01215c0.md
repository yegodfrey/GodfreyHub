# 1 概览

本章节将向您介绍如何在地图上绘制标记、覆盖物以及形状等。详情请参见示例代码工程中的MarkersExample.js、PolygonsExample.js、PolylinesExample.js、CirclesExample.js以及OverlaysExample.js等文件。点击[这里](https://developer.huawei.com/consumer/cn/doc/development/HMS-Examples/hms-map-v4-example-rn)下载示例代码。

# 2 添加标记

您可以在地图上添加标记，来标识商店、建筑等的位置，还可以通过信息窗来提供附加信息。

下面的代码段使用默认图标在地图上添加一个简单的标记：
    
    
    复制
      
        1. import {Marker} from 'react-native-hms-map';
        2. ...
        3. <Marker
        4.     coordinate={{latitude: 41.0083, longitude: 28.9784}}
        5.     title={'Hello Huawei Map'}
        6.     ...
        7. />

您可以将默认图标替换为自定义的图片或者通过修改标记属性来更改标记图标。下表列举了支持自定义的标记属性。

## 2.1 标记组件属性

属性| 类型| 默认值| 描述  
---|---|---|---  
title| 字符串| <None>| 标记标题。该属性仅在组件没有<Callout />子组件时使用，此时使用默认的信息窗行为，既展示标题也展示提供的描述。  
description| 字符串| <None>| 标记描述。该属性仅在组件没有<Callout />子组件时使用，此时使用默认的信息窗行为，既展示标题也展示提供的描述。  
image| ImageSource| <None>| 用作标记图标的自定义图片。仅支持使用本地图片资源。  
icon| ImageSource| <None>| 待渲染的标记图标（等同于GMSMarker Class的icon属性）。  
pinColor| Color| <None>| 如果没有提供自定义标记视图或自定义图片，将使用平台默认的大头针图标。你可以通过该属性设置该图标的颜色。如果使用自定义标记，请忽略该属性。支持的颜色有限。当设置为不支持的颜色时，将采用默认的红色。  
coordinate| LatLng| <None>| 标记的坐标。  
anchor| Point| (0.5, 1)| 标记的锚点。锚点用于将标记锚定在地图上。坐标（0，0）、（1，0）、（0，1）和（1，1） 分表表示标记图片的左上角、右上角、左下角以及右下角。  
calloutAnchor| Point| (0.5, 0)| 指定在标记图片中展示信息窗的坐标点。该属性需与anchor属性采用同样的坐标系来设置。详情请参见anchor属性。默认值为图片的顶部中央。  
flat| Boolean| false| 设置是否在地图或者面向相机的公告牌上平铺展示该标记。  
identifier| 字符串| <None>| 用于后续引用该标记的标识符。  
rotation| 浮点| 0| 表示标记旋转角度的浮点数，单位为度。  
draggable| <null>| <None>| 非取值型属性。用来指定标记是否可以拖动（更改位置）。  
tracksViewChanges| Boolean| true| 指定标记是否跟踪视图修改。建议尽可能的关闭该功能来提升自定义标记的性能。  
opacity| 浮点| 1.0| 标记的不透明度，取值范围为0.0~1.0。  
  
## 2.2 标记事件

事件名| 返回值| 描述  
---|---|---  
onPress| { coordinate: LatLng, position: Point }| 用户长按标记时调用的回调。  
onCalloutPress| <None>| 用户点击信息窗视图时调用的回调。  
onDragStart| { coordinate: LatLng, position: Point }| 用户开始拖拽（可拖拽的）标记时调用的回调。  
onDrag| { coordinate: LatLng, position: Point }| 标记拖拽过程中持续调用的回调。  
onDragEnd| { coordinate: LatLng, position: Point }| 标记拖拽结束时调用的回调。该事件通常是您想重新设置标记在地图上的坐标时调用。  
  
## 2.3 标记方法

方法名| 参数| 描述  
---|---|---  
showCallout| <None>| 展示标记的气泡。  
hideCallout| <None>| 隐藏标记的气泡。  
animateMarkerToCoordinate| coordinate: LatLng, duration: number| 动画化标记移动。  
redraw| <None>| 重绘标记。该属性在标记有更新且tracksViewChanges成本过高的情况下比较有用。

## 2.5 标记onPress事件

您可以使用onPress事件来侦听标记点击事件。标记点击事件的默认动作是展示（可用的）标记信息窗并将标记在地图上居中展示。
    
    
    复制
      
        1. <Marker
        2.     ref={this.ref1}
        3.     coordinate={{latitude: 41.0083, longitude: 28.9784}}
        4.     onPress={e => console.log('onPress #1')}
        5. />
    
    

## 2.6 标记拖拽事件

您可以使用onDragStart、onDrag以及onDragEnd事件来侦听标记点击事件。如需拖拽标记，用户需要长按该标记、将标记托转至屏幕上指定的位置、然后释放标记。用户开始拖拽标记时，将调用onDragStart。用户拖拽标记的过程中，反复调用onDrag。用户停止标记拖拽时，调用onDragEnd。
    
    
    复制
      
        1. <Marker
        2.     ref={this.ref1}
        3.     coordinate={{latitude: 89.1522, longitude: 1.1577}}
        4.     onDragStart={() => console.log('Dragging started')}
        5.     onDrag={() => console.log('Dragging')}
        6.     onDragEnd={() => console.log('Dragging end')}
        7. />
    
    

## 2.7 标记信息窗（部分支持）

    复制
      
        1. <Marker
        2.     coordinate={{latitude: 26.0210, longitude: 25.3512}}

        4.     description={'Marker Snippet'}
        5. />

# 4 添加形状

您可以通过HMS Core Map SDK在地图上添加不同的形状，包括折线、多边形、圆形以及覆盖物等。

## 4.1 添加折线

折线由多个有序的LatLng类型组成。

示例代码如下：
    
    
    复制
      
        1. const polylines = [
        2.     {latitude: 41.01929, longitude: 28.967267},
        3.     {latitude: 41.016785, longitude: 28.986971},
        4.     {latitude: 41.001917, longitude: 28.978743},
        5.     {latitude: 41.002298, longitude: 28.954132},
        6. ];
        7. ...
        8. <Polyline coordinates={polylines} />
    
    

  


侦听折线点击事件。
    
    
    复制
      
        1. <Polyline
        2.     coordinates={polylines}
        3.     tappable
        4.     onPress={() => {
        5.         console.log('onPress on polyline');
        6.     }}
        7. />

        7. />

     复制
