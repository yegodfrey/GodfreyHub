# **步骤5：** “商户生成卡劵包推送至华为钱包APP”方式设置Wallet Kit服务基本信息

点击申请产品接入华为钱包服务，进入Wallet Kit服务基本信息设置页面：

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200317154609.22358574496679595412848094444182:50510603090758:2800:35A21FFCDD646A7E85FAF7B8B9F373EAC31D40009B413DCA4CF4DE78C12B099E.png?needInitFileName=true)

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200403101622.25347913920105297123174240175818:50510603090758:2800:23B59898527C620B5C2AD9D235F43B5333417FED4E41BDDD8C766964FC378210.png?needInitFileName=true)

说明：

  * 服务类型：分为钥匙、证、券、卡、票，开发者选择其中的一种。




 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200403101707.86051479887768355036149664950022:50510603090758:2800:BF8C2C64FF88B46BF063FF2974EDFCC51A9A5BE7842593CCA817E8E6CC9C2E25.png?needInitFileName=true)

  * 服务项目：服务项目依赖所选择的服务类型，不同的服务类型，有不同的服务项目。例如当服务类型选择“钥匙”时，对应的服务项目有：“政企门钥匙”、“民宿门钥匙”、“家用门钥匙”等。




![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200403101728.34756737482096152480860190117347:50510603090758:2800:E915701463F31193EBF5BFEDA4DE5AECA870977FD14CF65F0CF25FA9BF1A2FAC.png?needInitFileName=true)

  * 服务名称：wallet kit首页列表展示该开发者所有创建的服务时，服务名称用于区分不同的服务。

  * 服务号：用于wallet kit服务器区分不同的服务且保证唯一性。填写时需要遵守一定的格式要求。




![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200403101755.64144784705245628475381079766158:50510603090758:2800:AE81891D9F6CAC816EED4992773EFD59C243424B4A044DAA53417AE707A7126C.png?needInitFileName=true)

  * 接入方式：国内支持二种接入方式，APP接入对应“商户生成卡劵包推送至华为钱包APP”方式，云端接入对应“商户生成JWE数据推送至华为服务器”方式。商户可以根据自己的需求选择适合自己类型的接入方式。




   注：选择云端接入时用户需要填写“回调地址”、“用户公钥”二项资料，选择APP接入则只需要上传证书请求文件生成证书即可。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200403101845.66419746730411312914431661282568:50510603090758:2800:2B5BAC07D0A2A0D50124BCA3C59EB49985D2335D4293A9D06C991DE44053D8E0.png?needInitFileName=true)

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200403101845.59411787829313194843273526260788:50510603090758:2800:7B76AC35824E5A759E080CCBD6D948D1E00C77FB60A2866306B32C03AA5FB607.png?needInitFileName=true)

  * 回调地址：开发者提供给wallet kit的地址，用于wallet kit反向回调开发者。

  * 公钥：开发者将在“安全组件申请”步骤中生成的公钥复制粘贴到此处，后续该公钥将作为wallet kit服务器认证开发者身份的方式。

  * 证书请求：开发者将在“安全组件申请”步骤中生成的证书请求文件内容复制粘贴到此处，Wallet Kit服务器一般会在5分钟后生成公钥证书，可在Wallet Kit首页列表中点击对应的服务名称超链接后进入详情页面，点击“服务号.cer”文件即可下载到本地。

  





# **步骤6： 点击“下一步”，进入NFC参数设置页面。需要专业的人员设置NFC参数信息。**

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200317154456.60102399450052651191451580007252:50510603090758:2800:F94CCEBF8B6D84F90DD31543FCA904E376A0A58E6DE138FB53161928119750F3.png?needInitFileName=true)

  * 是否支持跨移动设备同步：是否允许同一个帐户跨设备备份和恢复。开发者选择是或者否（选择此项需要对应实现开发指南章节[**商户实现卡劵更新流程**](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/wallet-guide-pushpass#h1-1582719855401)的接口才可支持此能力）。

  * 是否开通NFC能力：服务类型为门钥匙、一卡通、门禁卡、交通卡、社会保障卡、港澳通行证、护照时，需要开通NFC能力，同时需要配置应用号和参数。其余的服务类型可以选择不开通NFC能力。新建服务时已默认对应的选项。

  * 应用ID（AID）：可以使用已有的应用ID；也可以通过右侧的“获取AID”按钮新创建新应用ID。

  * 外部认证密钥：用于离线读写卡时外部认证校验。该字段要求所填写的内容格式为16 进制数 （字符为 0-F），最大长度为 32。

  * 文件参数定义：需要设置秘钥信息、文件大小、备注。




# **步骤7：** 点击“下一步”，创建完成后，返回Wallet Kit服务创建首页，可对所创建的服务进行查看、修改和删除
