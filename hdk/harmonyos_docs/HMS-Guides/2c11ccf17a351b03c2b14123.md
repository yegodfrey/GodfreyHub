华为定位服务采用GPS、WiFi、基站等多途径的混合定位模式进行定位，赋予应用开发者快速、精准地获取用户位置信息的能力，构建全球定位服务能力，助力开发者发展全球业务。当前测试环节只提供了位置更新能力的测试样例，其他功能测试请参考API 接口说明。

**本章节讲述的测试接口如下：**

[requestLocationUpdates()](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/fusedlocationproviderclient)

[getLastLocation()](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/locationresult)

注意：

目前HMS Location Kit功能只支持集成HMS Core SDK 3.0.0.300以上版本的应用，并且测试设备必须安装

3.0.0.300以上HMS Core（APK）。

# **1\. requestLocationUpdates()**  


## **1.1 预置条件**

1、网络连接正常    


2、手机已安装HMS Core（APK）和Location Demo    


3、在设置-应用-HMS Core-权限中，打开位置权限  


4、在“设置>安全和隐私>定位服务>访问我的位置信息”中    


5、打开位置信息开关

## **1.2 测试步骤**

1、打开Location Demo

2、点击requestLocationUpdates with callback按钮。

3、再点击requestLocationUpdates with callback按钮。

4、如果您想停止定位请求，请点击removeLocationUpdates with callback按钮。

## **1.3 预期结果**

请求发送成功，获取到相应的位置信息。

# **2\. getLastLocation()**

## **2.1 预置条件**

1、网络连接正常    


2、手机已安装HMS Core（APK）和Location Demo    


3、在设置-应用-HMS Core-权限中，打开位置权限  


4、在“设置>安全和隐私>定位服务>访问我的位置信息”中    


5、打开位置信息开关

## **2.2 测试步骤**

1、打开Location Demo    


2、点击getLastLocation接口按钮    


3、连续多次点击getLastLocation

## **2.3 预期结果**

每次都能成功获取坐标或者空值，获取坐标的话，则为手机所在位置的经纬度坐标（如果没有缓存位置信息，则返回为空值）。

注意：

当访问我的位置信息开关关闭，发送request时，[getLastLocation](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/locationresult)接口返回值为null，

[requestLocationUpdates](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/fusedlocationproviderclient)接口不会返回任何信息。
