在开始API开发工作之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-process-4)，同时请确保您的工程中已经[配置HMS Core SDK的maven仓地址](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-maven-4)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-landmark-sdk-4)。

1\. 创建地标分析器。可以通过地标识别自定义参数类[MLRemoteLandmarkAnalyzerSetting](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLRemoteLandmarkAnalyzerSetting-4)创建分析器。  

      
      1. // 方式1：使用默认的参数配置。 
        2. MLRemoteLandmarkAnalyzer analyzer = MLAnalyzerFactory.getInstance().getRemoteLandmarkAnalyzer(); 
        3. // 方式2：使用自定义的参数配置。 
        4. /** 
        5.   * setLargestNumOfReturns 识别结果的最大数量。 
        6.   * setPatternType  分析器使用的模式。   
        7.   * MLRemoteLandmarkAnalyzerSetting.STEADY_PATTERN：值为1，即稳定模式。 
        8.   * MLRemoteLandmarkAnalyzerSetting.NEWEST_PATTERN：值为2，即最新模式。 
        9.   */  
        10. MLRemoteLandmarkAnalyzerSetting settings = new MLRemoteLandmarkAnalyzerSetting.Factory() 
        11.     .setLargestNumOfReturns(1) 
        12.     .setPatternType(MLRemoteLandmarkAnalyzerSetting.STEADY_PATTERN)         
        13.     .create(); 
        14. MLRemoteLandmarkAnalyzer analyzer = MLAnalyzerFactory.getInstance().getRemoteLandmarkAnalyzer(settings);
    
    

2\. 通过android.graphics.Bitmap构造[MLFrame](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLFrame-4)，支持的图片格式包括：jpg/jpeg/png/bmp，建议图片尺寸不小于640*640像素。
      
      1. MLFrame mlFrame = new MLFrame.Creator().setBitmap(bitmap).create();
    
    

3\. 进行地标识别。

        13.             int errorCode = mlException.getErrCode();
