# 2\. ID Token模式和Authorization Code模式的集成方法有什么区别？

如果合作伙伴有自己的业务服务器，请优先选择Authorization Code模式。

首次登录时，两种模式都要求用户同意授权。

然后，当身份验证信息到期时，ID Token模式与第一次相同用户每次登录时都应同意授权。

Authorization Code模式只需要从服务器端通过刷新令牌刷新访问令牌，更快，更可靠，更方便。

# 3\. 如果集成的Kit调用HMS Base的话，需要申请Base的什么权限和采集哪些数据？

#### SDK权限说明

SDK需要使用的权限：

  * 网络连接权限：android.permission.INTERNET（打点和引导升级）

  * 获取网络状态权限：android.permission.ACCESS_NETWORK_STATE

  * 安装apk权限：android.permission.REQUEST_INSTALL_PACKAGES（引导升级）

  * 写SD卡权限：android.permission.WRITE_EXTERNAL_STORAGE（引导升级）




#### SDK收集数据  


SDK主要采集以下数据：

HMSSDK版本、应用包名、调用API、调用时间、UUID、appid、ROM版本号、机型、应用版本号。
