# SDK工作方式  


移动端SDK需要在应用编译打包时，被加载在您的应用当中。

SDK会随着客户应用的调用而启动，不会自动启动，也不会在后台做任何额外动作。

# SDK权限说明

Nearby Connection业务需要以下权限：

l   android.permission.ACCESS_NETWORK_STATE

l   android.permission.ACCESS_WIFI_STATE

l   android.permission.BLUETOOTH

l   android.permission.BLUETOOTH_ADMIN

l   android.permission.ACCESS_COARSE_LOCATION

l   android.permission.ACCESS_FINE_LOCATION

l   android.permission.CHANGE_WIFI_STATE

l   android.permission.INTERNET

Nearby Message业务需要以下权限：

l   android.permission.INTERNET

l   android.permission.BLUETOOTH

l   android.permission.BLUETOOTH_ADMIN

l   android.permission.ACCESS_COARSE_LOCATION

l   android.permission.ACCESS_FINE_LOCATION

 

注意：

Android6.0之后蓝牙需要后面两个权限。

  


**SDK 收集数据**  


Nearby SDK 仅处理了用户需要传输的数据，没有搜集其他数据。

# SDK数据安全保护

Nearby Service与服务端采用HTTPS通信，会对服务器的证书进行合法性校验，并对Message在云侧进行加密存储。
