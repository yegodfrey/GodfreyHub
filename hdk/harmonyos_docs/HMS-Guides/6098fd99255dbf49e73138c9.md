HMS Core Toolkit是一个IDE工具插件，提供一套含应用创建、编码和转换、调测、测试和发布的开发工具，助您高效集成HMS Core，打造出色的应用。

# 功能介绍

  * Convertor

代码转换工具，帮您轻松将现有的应用代码转换为集成HMS Core的应用代码。

如果开发者已有集成第三方移动服务的应用程序，可以使用华为提供的Convertor工具将第三方移动服务相关的API接口自动转换为HMS Core相对应的API接口，实现快速转换和集成HMS Core的能力。

  * Repository

提供HMS Core服务和能力的仓库，支持库的查看、导入和升级。

  * Coding Assistant

提供HMS Core API描述、场景化的示例代码和模板，可通过拖拽生成代码，提高编码效率。

  * Cloud Debugging（即将开放）

一键接入华为全系列真机，7*24小时免费使用。
