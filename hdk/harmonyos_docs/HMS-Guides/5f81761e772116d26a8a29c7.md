错误码| 错误码说明| 解决方法  
---|---|---  
CE-001| 未获取到采集服务器地址| 请检查agconnect-services.json配置文件中“collector_url”否有地址，请不要修改此地址。  
NE-001| 初始化SSL连接失败| Eclipse项目中集成：请检查SDK发布包的assets目录下是否存在CA根证书文件（hianalyticscas.bks）。Android Studio项目中集成：请选择“支持>技术支持>[在线提单](https://developer.huawei.com/consumer/cn/support/feedback)”提交问题，华为支持人员会及时处理。  
NE-002| 验证证书失败| Eclipse项目中集成：请检查SDK发布包的assets目录下是否存在CA根证书文件（hianalyticscas.bks）。  
Android Studio项目中集成：请选择“支持>技术支持>[在线提单](https://developer.huawei.com/consumer/cn/support/feedback)”提交问题，华为支持人员会及时处理。  
NE-003| 无网络权限| 请检查是否有网络权限。  
NE-004| IO异常| 请选择“支持>技术支持>[在线提单](https://developer.huawei.com/consumer/cn/support/feedback)”提交问题，华为支持人员会及时处理。  
NE-005| 连接错误| 请检查网络后重试。  
NE-006| URL错误| 请检查agconnect-services.json配置文件中“collector_url”是否被修改，请勿使用无效的地址。  
PE-001| 参数值为空| 请检查传入的参数值是否为空，根据日志查看对应参数。  
PE-002| 参数值长度超过256个字符| 请检查传入的参数是否超过256个字符。  
PE-003| 必选参数缺失| 请检查传入的参数是否缺少必选参数。  
PE-004| 使用了保留字| 请检查传入的参数是否使用了系统保留的关键字（自动采集的事件ID、自动采集的属性ID）。  
PE-005| 事件参数过多| 请检查传入的Bundle参数是否过多，size最多2048，length最大200k；用户属性最多25对。  
PE-006| 参数名格式错误| 请检查事件ID，Bundle的key等，是否符合校验规则。  
IE-001| 未在主线程中init| 请在主线程中初始化SDK。  
IE-002| 应用未在应用市场上架| 应用未在应用市场上架，请上架应用市场。  
IE-003| 未初始化HA SDK| 未初始化SDK，请检查是否有IE-004或者IE-005错误码。  
  
IE-004| 未集成AGC Core SDK| 请检查项目的Exterbal  Libraries中是否下载agconnect-core SDK。  
IE-005| 未获取到正确的HMS Core SDK| 请检查项目的Exterbal  Libraries中是否下载hms opendevice sdk 和 hms base sdk；并检查版本号是否匹配。  
IE-006| 未开启开关| 请检查采集开关（setAnalyticsEnabled）是否关闭。  
SE-001| 初始化实例失败| SDK初始化失败，请检查是否有SE-002或SE-003错误码。  
  
SE-002| 获取AAID失败| 请检查项目的Exterbal  Libraries中是否下载hms opendevice sdk 和 hms base sdk；并检查版本号是否匹配。  
SE-003| 获取AGC Token失败| 请检查项目的Exterbal  Libraries中是否下载agconnect-core SDK。
