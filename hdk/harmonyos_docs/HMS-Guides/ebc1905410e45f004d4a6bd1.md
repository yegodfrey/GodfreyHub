# 

本指南向您介绍如何将HUAWEI Ads SDK集成到APP中，是展示广告和获得收入的第一步，一旦集成了SDK，就可以选择一种广告类型（如原生广告或激励视频广告），按照相应的步骤实现。

# 1\. 前提条件

  * 您需要安装4.0.0及以上版本的HMS Core（APK）。如果未安装，则无法使用HUAWEI Ads SDK的相关接口。

  * 在开发应用前需要在[华为开发者联盟](https://developer.huawei.com/consumer/cn)网站上注册成为开发者并完成实名认证，具体方法可参考“[帐号注册认证](https://developer.huawei.com/consumer/cn/devservice/doc/20300)”。

  * 参见[创建项目](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-get-started#createproject)和在[项目中添加应用](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-get-started#createapp)完成应用的创建。

  * ## 在Eclipse项目中集成HUAWEI Ads SDK




### **下载SDK**

**步骤1  **[下载](https://developer.huawei.com/consumer/cn/doc/development/HMS-Library/ads-kit-sdk-eclipse)并解压adssdk-eclipse-{version}.zip，解压后将生成8个Eclipse Library工程，如下表所示:

工程名| 提供的能力| 需求场景。  
---|---|---  
ads-base| HMS Ads SDK 基础功能包| 该工程必须集成。  
ads-banner| 提供Banner广告能力| 需要集成Banner广告能力时，集成该工程以及ads-base, ads-native工程。  
ads-consent| 提供征求用户意见能力| 需要征求用户意见时，集成该工程以及ads-base工程。  
ads-lang| 提供多语言能力| 需要使用多语言能力时，集成该工程以及ads-base工程。  
ads-native| 提供原生广告能力| 需要集成原生广告时，集成该工程以及ads-base工程。  
ads-reward| 提供激励广告能力| 需要集成激励广告时，集成该工程以及ads-base工程。  
ads-interstitial| 提供插屏广告能力| 需要集成插屏广告时，集成该工程以及ads-base工程。  
ads-splash| 提供开屏广告能力| 需要集成开屏广告时，集成该工程以及ads-base工程。

**修改AndroidManifest.xml文件**

如果您的工程中的AndroidManifest.xml配置的minSdkVersion小于19，建议修改为19，或者删除SDK各个工程下AndroidManifest.xml 中以下的配置，避免编译错误的问题。
      
      1. <uses-sdk
        2.     android:minSdkVersion="19"
        3.     android:targetSdkVersion="29" />
    
    

注意：

您的工程安装在低于Android API Level 19 的手机上时会请求不到广告。

由于Eclipse的xml文件不支持$符号，将ads-base工程下AndroidManifest.xml文件中的“${applicationId}”替换成您的应用包名。  

      
      1. <application>
        2.     ...
        3.     <activity android:name="com.huawei.openalliance.ad.activity.PPSLauncherActivity"
        4.         android:theme="@android:style/Theme.Translucent.NoTitleBar"
        5.         android:exported="true">
        6.         <intent-filter>
        7.             <action android:name="android.intent.action.VIEW"/>
        8.             <category android:name="android.intent.category.DEFAULT"/>
        9.             <category android:name="android.intent.category.BROWSABLE"/>
        10.             <data android:scheme="hwpps" android:host="**${applicationId}** "/>
        11.         </intent-filter>
        12.     </activity>
        13.     ...
        14. </application>
    
    

### **修改project.properties文件**

在开发工程的project.properties文件添加或修改如下：
      
      1. target=android-29
        2. manifestmerger.enabled=true
    
    

说明：

ADT必须是17以上版本。

# 3\. 配置网络权限

在targetSdkVersion 28及以上的手机上允许http网络请求，建议在AndroidManifest.xml做以下配置：
      
      1. <application
        2.     ...
        3.     android:usesCleartextTraffic="true"
        4.     >
        5.     ...
        6. </application>
    
    

# 4\. 配置混淆脚本

开发者编译APK前需要配置不要混淆HUAWEI Ads SDK，避免功能异常。

Android Studio开发环境里的配置文件是“proguard-rules.pro”，Eclipse开发环境里的配置文件是“proguard-project.txt”。

    1\. 打开Android工程的混淆配置文件。

    2\. 加入排除HMS SDK的混淆配置。
      
      1. -keep class com.huawei.openalliance.ad.** { *; }
        2. -keep class com.huawei.hms.ads.** { *; }
    
    

# 5\. 初始化SDK

建议在应用启动的时候调用[HwAds](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-hwads).init()接口初始化HUAWEI Ads SDK，开发者需要自行实现AdSampleApplication类。  


示例代码如下：

在AndroidManifest.xml添加Application名称。
      
      1. <application
        2.     android:name=".AdSampleApplication"
        3.     ...
        4.     >
        5.     ...
        6. </application>
    
    

实现AdSampleApplication类，并初始化SDK。
      
      1. ...
        2. import com.huawei.hms.ads.HwAds;
        3. ...
        4. public class AdSampleApplication extends Application {
        5.     @Override
        6.     public void onCreate() {
        7.         super.onCreate();
        8.         HwAds.init(this);
        9.     }
        10.     ...
        11. }
    
    

当然，也可以在Activity中初始化SDK。

示例代码如下：
      
      1. ...
        2. import com.huawei.hms.ads.HwAds;
        3. ...
        4. public class MainActivity extends Activity {
        5.     private BannerView bannerView;
        6.     @Override
        7.     protected void onCreate(Bundle savedInstanceState) {
        8.         super.onCreate(savedInstanceState);
        9.         setContentView(R.layout.activity_main);
        10.         // 初始化HUAWEI Ads SDK.
        11.         HwAds.init(this);
        12.         ...
        13.     }
        14. }
