一级分类| 二级分类| 三级分类| SDK3.0| SDK4.0  
---|---|---|---|---  
开发总体原则| HMS SDK 4.0兼容HMS SDK 3.0功能但新增了部分功能，原有业务逻辑无变更，但调用方法/参数/返回值/类所在包名均做了调整优化，建议开发者新建一个项目重新下载依赖包并按照新的开发文档操作。  
公共配置| SDK下载| NA| 推荐使用Android  Studio，通过maven仓方式下载。| 支持2种方式：1\. 支持Android Studio，通过maven仓方式下载。2\. 支持Eclipse，通过下载HMS SDK包本地集成。  
支付| 客户端| 接口优化| 业务逻辑不变，但类名称、类所属的包名、方法名、常量等做了优化刷新，请按照新的开发文档集成。  
能力增强| InAppPurchaseData 类| 不支持| 新增 InAppPurchaseData 类，开发者可以利用该类解析 json 格式的InAppPurchaseData的数据。  
获取商品信息的原始价格| 不支持| 通过obtainProductInfo接口获取在AppGallery Connect配置的商品详情时，返回的ProductInfo数据中增加商品原价originalLocalPrice和商品原价微单位价格originalMicroPrice。开发者可以通过获取该值，达到同时显示原价和实际价格的作用。  
IapClientHelper 工具类| 不支持| 新增IapClientHelper工具类，开发者可以通过该类的parseRespCodeFromIntent方法获取返回码，通过该类的parseRespMessageFromIntent方法获取响应消息。  
IapClient.PriceType 接口| 不支持| 新增IapClient.PriceType接口，开发者可通过该类获取IN_APP_CONSUMABLE、IN_APP_NONCONSUMABLE、IN_APP_SUBSCRIPTION的常量定义。  
InAppPurchaseData.PurchaseState 接口| 不支持| 新增InAppPurchaseData.PurchaseState接口，开发者可通过该类获取PURCHASED、CANCELED、REFUNDED 的常量定义。  
新增服务器接口| Subscription服务验证购买Token| 不支持| 新增方便开发者在提供订阅服务前进行校验是否成功收费/该订阅是否在有效期内。  
取消订阅| 不支持| 新增  
延迟结算| 不支持| 新增  
返还订阅费用| 不支持| 新增  
撤销订阅| 不支持| 新增  
已取消或者退费购买查询| 不支持| 新增  
华为帐号| 类名/包名/方法名优化更新| NA| 业务逻辑不变，但类名称、类所属的包名、方法名、常量等做了优化刷新，请按照新的开发文档集成。  
游戏| 能力增强| 防沉迷| 华为提供查询玩家实名情况和拉起实名弹框的功能，不支持游戏时长统计。| 不提供查询玩家实名情况和接口调用拉起实名弹框的能力。变更如下功能：1\. 登录华为帐号时强制实名，对未实名玩家自动弹实名认证框，未实名不允许进入游戏（需要玩家手机的HMS Core（APK）版本不低于4.0且开发者已向华为运营申请游戏强制实名）。2\. 玩家游戏行为上报，开发者在玩家登录和退出游戏时（包括游戏切换后台或再返回前台、关机等场景）向华为服务器上报玩家行为，华为服务器计算时长并提供接口供开发者查询玩家的累计游戏时长。  
排行榜| 不支持| 新增  
游戏存档| 不支持| 新增  
玩家信息统计| 不支持| 新增  
游戏基本信息| 不支持| 新增
