当商户有更新卡劵需求时，商户可调用华为服务器的接口更新卡片模板及用户特有信息的实例。

华为服务器提供以下几种方式更新卡劵。

下面以会员卡实例为例来描述实现更新卡劵的具体流程。

# 1 全量更新模板

当商户调用全量更新模板接口传入HwLoyaltyObject实例时华为服务器会通过modelId字段查询并覆盖数据库的HwLoyaltyObject实例。

具体实现可参考[服务器示例代码](https://developer.huawei.com/consumer/cn/doc/development/HMS-Examples/wallet-sample-code)。
      
      1. // ID of the loyalty model you want to update.
        2. String modelId = "xxxxxx";
        3. // Read an example HwWalletObject from a JSON file. The corresponding loyalty model will be replaced by this
        4. // HwWalletObject.
        5. String modelJson = CommonUtil.readWalletObject("FullUpdateLoyaltyModel.json");
        6. // Update the loyalty model.
        7. String urlParameter = "loyalty/model/";
        8. WalletBuildService loyaltyBuildService = new WalletBuildServiceImpl();
        9. HwWalletObject loyaltyModelUpdated 
        10. loyaltyBuildService.fullUpdateWalletModel(urlParameter, modelId, modelJson);
        11. assertThat(modelId, equalTo(loyaltyModelUpdated.getPassStyleIdentifier()));
    
    

# 2 局部更新模板

当商户调用局部更新模板接口传入HwLoyaltyObject时华为服务器会通过modelId查询并比对当前数据库的HwLoyaltyObject数据，当接口传入的数据。

具体实现可参考[服务器示例代码](https://developer.huawei.com/consumer/cn/doc/development/HMS-Examples/wallet-sample-code)。
      
      1. // ID of the loyalty model you want to update.
        2. String modelId = "xxxxx";
        3. // Read an example HwWalletObject from a JSON file. The corresponding loyalty model will merge with this
        4. // HwWalletObject.
        5. String modelJson = CommonUtil.readWalletObject("PartialUpdateLoyaltyModel.json");
        6. // Update the loyalty model.
        7. String urlParameter = "loyalty/model/";
        8. WalletBuildService loyaltyBuildService = new WalletBuildServiceImpl();
        9. HwWalletObject loyaltyModelUpdated =
        10. loyaltyBuildService.partialUpdateWalletModel(urlParameter, modelId, modelJson);
        11. assertThat(modelId, equalTo(loyaltyModelUpdated.getPassStyleIdentifier()));
    
    

# 3 全量更新用户特有信息的实例（Instance）

当商户调用全量更新模板接口传入HwLoyaltyObject时华为服务器会通过modelId查询覆盖当前数据库的HwLoyaltyObject。

具体实现可参考[服务器示例代码](https://developer.huawei.com/consumer/cn/doc/development/HMS-Examples/wallet-sample-code)。
      
      1. // ID of the loyalty instance to be updated.
        2. String instanceId = "xxxx";
        3. // Read an example HwWalletObject from a JSON file. The corresponding loyalty instance will be replaced by this
        4. // HwWalletObject.
        5. WalletBuildService walletBuildService = new WalletBuildServiceImpl();
        6. String instanceJson = CommonUtil.readWalletObject("FullUpdateLoyaltyInstance.json");
        7. String modelId = JSONObject.parseObject(instanceJson, HwWalletObject.class).getPassStyleIdentifier();
        8. HwWalletObject hwWalletInstanceNew = walletBuildService.createHwWalletObject(instanceJson, instanceId, modelId);
        9. // Update the loyalty instance.
        10. String urlParameter = "loyalty/instance/";
        11. HwWalletObject loyaltyInstanceUpdated =
        12. walletBuildService.fullUpdateWalletInstance(urlParameter, instanceId, hwWalletInstanceNew);
        13. assertThat(instanceId, equalTo(loyaltyInstanceUpdated.getSerialNumber()));
    
    

# 4 局部更新用户特有信息实例（Instance）

当商户调用局部更新用户特有信息实例接口传入HwLoyaltyObject时华为服务器会通过modelId查询并比对当前数据库的HwLoyaltyObject数据，当接口传入的Object数据字段在数据已有则会覆盖数据库数据，如果不存在则将新增字段插入数据库的HwLoyaltyObject数据中。

具体实现可参考[服务器示例代码](https://developer.huawei.com/consumer/cn/doc/development/HMS-Examples/wallet-sample-code)。
      
      1. // ID of the loyalty instance to be updated.
        2. String instanceId = "xxxxx";
        3. // Read an example HwWalletObject from a JSON file. The corresponding loyalty model will merge with this
        4. // HwWalletObject.
        5. String instanceJson = CommonUtil.readWalletObject("PartialUpdateLoyaltyInstance.json");
        6. WalletBuildService walletBuildService = new WalletBuildServiceImpl();
        7. HwWalletObject hwWalletInstanceNew = walletBuildService.createHwWalletObject(instanceJson, instanceId, null);
        8. // Update the loyalty instance.
        9. String urlParameter = "loyalty/instance/";
        10. HwWalletObject loyaltyInstanceUpdated =
        11. walletBuildService.partialUpdateWalletInstance(urlParameter, instanceId, hwWalletInstanceNew);
        12. assertThat(instanceId, equalTo(loyaltyInstanceUpdated.getSerialNumber()));
