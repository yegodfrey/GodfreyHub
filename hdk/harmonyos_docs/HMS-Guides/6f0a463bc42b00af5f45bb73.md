# 1 概览

您可以通过某一地点的SiteID来获取该地点的详细信息，SiteID是地点的唯一标识符。

# 2 实现步骤

1\. 声明[SearchService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchservice)对象，并通过[SearchServiceFactory](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchservicefactory)创建[SearchService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchservice)实例。

说明：

创建SearchService实例需要传入context和API key参数。context参数建议传入Activity类型，否则需要升级HMS Core（APK）时不会弹出升级界面。API key是开发者在[华为开发者联盟](https://developer.huawei.com/consumer/cn)创建应用时生成的API key，注意需要对API key进行encodeURI编码。  


  


2\. 创建[DetailSearchRequest](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-detailSearchRequest)对象，它是详情查询的请求体。并传入以下参数：

  * siteId：地址ID，必选项。

  * language：搜索结果的语种，取值范围参考[语种映射](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/hms-site-language)的语种代码。如果不传，使用地点的当地语言。

  * politicalView：政治观点参数，采用ISO 3166-1-alpha-2规范的2位国家码。  





3\. 创建[SearchResultListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchresultlistener)对象，该对象用来监听搜索结果。

4\. 通过第1步创建的[SearchService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchservice)对象调用detailSearch()接口，传入第2步创建的[DetailSearchRequest](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-detailSearchRequest)对象和第3步创建的[SearchResultListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchresultlistener)对象。

5\. 过第3步创建的[SearchResultListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchresultlistener)对象获取搜索结果[DetailSearchResponse](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-detailSearchResponse)对象，可从中获Site对象，即地址信息：

方法名| 功能  
---|---  
getSiteId()| 获取地点的ID。  
getName()| 获取地点名称。  
getFormatAddress()| 获取格式化的地点详细地址。  
getAddress()| 获取地点详细信息。  
getLocation()| 获取地点的经纬度。  
getViewport()| 获取地点的可视区域。  
getPoi()| 获取地点的POI信息。  
  
示例代码如下：  

      
      1. private SearchService searchService;
        2. //实例化 
        3. searchService = SearchServiceFactory.create(this, "API key");
        4. //创建详情查询请求体 
        5. DetailSearchRequest request = new DetailSearchRequest();
        6. //siteId是必选项 
        7. request.setSiteId(siteId);
        8. request.setLanguage("fr");
        9. //结果监听器 
        10. SearchResultListener<DetailSearchResponse> resultListener = new SearchResultListener<DetailSearchResponse>() {
        11.         @Override
        12.         public void onSearchResult(DetailSearchResponse results) {
        13.             Site site;
        14.             if (results == null || (site = results.getSite()) == null) {
        15.                 Log.i(TAG, "Result is Empty!");
        16.                 return;
        17.             }
        18.             AddressDetail addressDetail = site.getAddress();
        19.             Coordinate location = site.getLocation();
        20.             Poi poi = site.getPoi();
        21.             CoordinateBounds viewport = site.getViewport();
        22.             StringJoiner response = new StringJoiner("\n");
        23.             response.add("success\n");
        24.             response.add(String.format(
        25.                     "siteId: '%s', Name: %s, FormatAddress: %s, Country: %s, CountryCode: %s,             Location: %s, PoiTypes: %s, Viewport: %s \r\n",
        26.                     site.getSiteId(), site.getName(), site.getFormatAddress(),
        27.                     (addressDetail == null ? "" : addressDetail.getCountry()),
        28.                     (addressDetail == null ? "" : addressDetail.getCountryCode()),
        29.                     (location == null ? "" : (location.getLat() + "," + location.getLng())),
        30.                     (poi == null ? "" : Arrays.toString(poi.getPoiTypes())),
        31.                     (viewport == null ? "" : viewport.getNortheast() + "," + viewport.getSouthwest())));
        32.             Log.i(TAG, "onDetailSearchResult: " + response.toString());
        33.         }
        34.         //返回错误状态码 
        35.         @Override
        36.         public void onSearchError(SearchStatus status) {
        37.             Log.e(TAG, "Error : " + status.getErrorCode() + " " + status.getErrorMessage());
        38.         }
        39.     };
        40. //详情查询接口 
        41. searchService.detailSearch(request, resultListener);
