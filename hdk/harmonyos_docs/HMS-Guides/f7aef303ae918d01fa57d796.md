# 1 SDK工作方式  


Drive SDK在应用打包时会被加载到客户应用中，会随着应用启动而运行在客户应用中。客户应用调用Drive SDK接口，Drive SDK向Drive Server发送网络请求，Drive Server处理Drive SDK请求后返回结果给Drive SDK，Drive SDK解析请求结果，返回给客户应用进行处理。当用户关闭应用时，Drive SDK会随着客户应用关闭而关闭，不会在后台做任何额外的操作。

# 2 SDK权限说明  


Drive SDK需要使用的权限：

  1. 访问网络权限：android.permission.INTERNET，用于访问网络和Drive Server通信。

  2. 读写存储权限：android.permission.WRITE_EXTERNAL_STORAGE，用于上传下载文件。




# 3 SDK数据收集

Drive SDK收集以下信息用来分析应用运营数据：开发者应用appID、操作类型、上传文件的名称、上传或下载文件的大小、操作结果。收集以下信息用来分析问题：开发者应用名称、开发者应用appID、用户唯一标识unionId、操作类型、手机型号、上传或下载文件的大小和名称。

# 4 SDK数据安全保护

Drive SDK与Drive Server采用HTTPS通信，客户端会对服务器的证书进行合法性校验，文件的上传和下载都是由HTTPS进行安全传输。通过Drive SDK上传的文件在Drive Server进行加密保存。

对于客户应用传入的AccessToken等敏感数据，Drive SDK不会缓存到本地存储。
