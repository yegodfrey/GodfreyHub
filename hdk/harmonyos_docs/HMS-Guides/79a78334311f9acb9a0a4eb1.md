此章节针对华为作为最终用户数据处理者，开发者作为最终用户数据控制者的数据处理进行说明，包括：  


  * 华为处理的个人数据清单；

  * 提供指导使客户实现对最终用户数据主体权利的支持。




# **1  ****华为处理的个人数据清单**

**个人数据清单**| **使用目的**| **存留期**  
---|---|---  
sharing code， message| 发布者将sharing code 和 message 发布到Nearby服务器，订阅者发现附近的发布者，然后从Nearby服务器获取该发布者注册的message 。| 1) message TTL（最大存活时间）超时，数据在Nearby服务器中删除。开发者可以设置TTL，默认策略是TTL为240秒，最大TTL为86400秒。2)最终用户取消发布消息时，数据在Nearby服务器中删除。  
beacon information，attachment information| 开发者在“华为开发者联盟”注册beacon和 attachment信息，订阅者发现附近beacon广播的beacon ID，然后从Nearby服务器获取该开发者注册的 attachment 。| 1)开发者可以在“华为开发者联盟”主动删除数据。2)开发者注销帐号时，Nearby 服务器删除该帐号下相关的数据。  
service account、client ID| 开发者在“华为开发者联盟”创建service account,实现应用级身份认证。Service account对应唯一的client ID，开发者可基于service account实现beacon管理。| 开发者可以在“开发者联盟”主动删除数据。  
  
# ****2  **指导开发者如何帮助最终用户实现对数据的控制**

## **2.1  ****如何清除最终用户的数据**

1） 开发者可以在应用程序中集成Nearby SDK，提供设置TTL和取消消息发布的功能。当TTL过期或最终用户取消发布消息时，message将在Nearby服务器中被删除。

请参考《NearbyService API参考》[Policy.Builder](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-message-policy-builder)和[MessageEngine](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-message-messageengine)。

2） 开发者可以主动在华为开发者联盟或通过Nearby Service提供的接口来删除您的最终用户的beacon和 attachment信息。

请参考[Beacon管理](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/Nearby-Service-Beacon-Management)章节和[RESTful APIS of Beacon](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-call-process)。

3） 开发者可以删除华为开发者帐号，该帐号下相关的beacon和 attachment信息会被删除。

## **2.2  ****如何导出最终用户的数据**

1）开发者可以在应用程序中集成Nearby SDK，为最终用户提供获取message的功能。

请参考《NearbyService API参考》[MessageEngine](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-message-messageengine)。

2）开发者可以在华为开发者联盟或基于Nearby Service提供的接口来实现beacon和 attachment信息导出。

请参考[Beacon管理](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/Nearby-Service-Beacon-Management)章节和[RESTful APIS of Beacon](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-call-process)。
