# 开启了DEBUG模式，但应用调试界面未显示上报数据？

**【根因分析】**

可能有如下原因：

  * 未开通高级分析服务。

  * 获取的agconnect-services.json不是原始文件

  * 未开启调试模式。

  * 端侧logcat日志数据没有上报成功。




**【解决方法】**

按如下步骤检查配置：

1.请确保已开通高级分析服务并检查API管理的开关是否开启（系统默认开启）。

2.请确保agconnect-services.json文件是原始文件，未有任何改动。

3.检查[调试模式](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/Accessing_Analytics_Kit_Android#Access_Debugging)是否开启。

4.查看端侧logcat日志数据是否上报成功，如果日志中有打印“resultCode: 200”，说明数据上报成功。未成功可能有如下两个原因：

原因一：开发者使用了tools:node="replace"，该参数导致应用某些配置与AGC sdk配置冲突，导致调用AGC接口获取token失败。

原因二：编译APK时未进行排除Analytics Kit混淆配置，导致APK出现异常。

针对原因一：

  1. 将参数改为tools:node="merge"。

  2. 手动把AGC所有的AndroidManifest文件信息写到开发者App的AndroidManifest文件信息里。




针对原因二：

  1. 打开Android工程的混淆配置文件。

  2. 加入排除Analytics Kit的混淆配置。



      
      1. -keep class com.hianalytics.android.**{*;}
        2. -keep class com.huawei.updatesdk.**{*;}
        3. -keep class com.huawei.hms.**{*;}
        4. -keep class com.huawei.agconnect.**{*;}
        5. -keep interface com.huawei.hms.analytics.type.HAEventType{*;}
        6. -keep interface com.huawei.hms.analytics.type.HAParamType{*;}
    
    

# 数据上报失败，服务器返回错误码401？类似报错如下："java.lang.RuntimeException: Unable to get provider com.huawei.agconnect.core.provider.AGConnectInitializeProvider: java.security.InvalidParameterException: url is null"

【根因分析】

可能有两种原因：

  * 开发者没有下载agconnect-services.json文件。

  * 下载agconnect-services.json文件之前没有在页面单击开启分析服务的API权限。




【解决方法】

针对原因一：登录[AGC网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，下载agconnect-services.json文件。

针对原因二：检查[AGC网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)“项目设置 > API管理”，打开HUAWEI Analytics。
