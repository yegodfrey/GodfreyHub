# 1 服务介绍

华为地图服务提供JavaScript语言开发的应用编程接口，帮助您轻松完成适用于浏览器的地图应用开发。

支持基础地图展示，地图交互， 路径规划，位置搜索，地理编码等，满足大多数开发者的需求。

# 2 使用说明

1\. 使用服务前，需要在开发者联盟网站上获取API KEY。具体操作步骤请参考[创建凭证](https://developer.huawei.com/consumer/cn/doc/start/api-console-guide#h2-1582599047826-0)->API密钥。

说明：

为增强API KEY的安全性，推荐您对API KEY进行限制。可以在API KEY的编辑页面进行**应用限制** 和**API限制** 。
