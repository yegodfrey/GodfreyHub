# 在Manifest指定权限

在调用时间感知能力时，开发者需要先在Manifest中指定相应的权限。
      
      1. <!-- 位置权限，此权限为敏感权限，声明后还需在代码中动态申请-->
        2. <uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
        3. <!-- 位置权限，若只使用基于IP的时间快照功能，可申明此权限-->
        4. <uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
    
    

# 导入接口类

使用时间状态感知能力，除需要导入情景感知服务的公共能力类外，还需要导入时间状态相关的类。
      
      1. import com.huawei.hmf.tasks.OnFailureListener;
        2. import com.huawei.hmf.tasks.OnSuccessListener;
        3. import com.huawei.hms.kit.awareness.Awareness;
        4. //导入时间快照相关类
        5. import com.huawei.hms.kit.awareness.capture.TimeCategoriesResponse;
        6. import com.huawei.hms.kit.awareness.status.TimeCategories;
        7. //导入时间围栏相关类
        8. import com.huawei.hms.kit.awareness.barrier.AwarenessBarrier;
        9. import com.huawei.hms.kit.awareness.barrier.BarrierStatus;
        10. import com.huawei.hms.kit.awareness.barrier.TimeBarrier;
        11. import com.huawei.hms.kit.awareness.barrier.BarrierUpdateRequest;
    
    

# 能力开发

## Capture能力开发

1\. 获取Awareness Kit的“Capture Client”。

2\. 通过“Capture Client”调用时间状态查询能力接口查询情景状态。

3\. 监听情景感知服务结果返回，进行应用的业务处理。
      
      1. Awareness.getCaptureClient(this).getTimeCategories()
        2.         .addOnSuccessListener(new OnSuccessListener<TimeCategoriesResponse>() {
        3.             @Override
        4.             public void onSuccess(TimeCategoriesResponse timeCategoriesResponse) {
        5.                 TimeCategories categories = timeCategoriesResponse.getTimeCategories();
        6.                 int[] timeInfo = categories.getTimeCategories();
        7.             }
        8.         })
        9.         .addOnFailureListener(new OnFailureListener() {
        10.             @Override
        11.             public void onFailure(Exception e) {
        12.                 Log.e(TAG, "get Time Categories failed", e);
        13.             }        
        14.         });
    
    

## Barrier能力开发

以下以开发时间“duringPeriodOfDay”的Barrier为例（在指定时区的指定时间段内，Barrier状态为true）。

1\. 定义Barrier。  

      
      1. long oneHourMilliSecond = 60 * 60 * 1000L;
        2. AwarenessBarrier periodOfDayBarrier = TimeBarrier.duringPeriodOfDay(TimeZone.getDefault(),        
        3.         11 * oneHourMilliSecond, 12 * oneHourMilliSecond);
    
    

2\. 定义Barrier状态改变时触发的“PendingIntent”，本示例中为发送一个广播，同时新建一个广播接收器用来接收这个广播。
      
      1. final String BARRIER_RECEIVER_ACTION = getApplication().getPackageName() + "TIME_BARRIER_RECEIVER_ACTION";
        2. Intent intent = new Intent(BARRIER_RECEIVER_ACTION); 
        3. PendingIntent pendingIntent = PendingIntent.getBroadcast(this, 1, intent, PendingIntent.FLAG_UPDATE_CURRENT);
        4. TimeBarrierReceiver barrierReceiver = new TimeBarrierReceiver();registerReceiver(barrierReceiver, new IntentFilter(BARRIER_RECEIVER_ACTION));
    
    

3\. 定义Barrier对应的标签Label，然后添加Barrier。
      
      1. String timeBarrierLabel = "period of day barrier";
        2. BarrierUpdateRequest.Builder builder = new BarrierUpdateRequest.Builder();
        3. BarrierUpdateRequest request = builder.addBarrier(timeBarrierLabel, periodOfDayBarrier,pendingIntent).build(); 
        4. Awareness.getBarrierClient(context).updateBarriers(request)
        5.         .addOnSuccessListener(new OnSuccessListener<Void>() {
        6.             @Override
        7.             public void onSuccess(Void aVoid) {
        8.                 Toast.makeText(getApplicationContext(), "add barrier success", Toast.LENGTH_SHORT).show();
        9.             }
        10.         })
        11.         .addOnFailureListener(new OnFailureListener() {
        12.             @Override
        13.             public void onFailure(Exception e) {
        14.                 Toast.makeText(getApplicationContext(), "add barrier failed", Toast.LENGTH_SHORT).show();
        15.                 Log.e(TAG, "add barrier failed", e);
        16.             }        
        17.         });
    
    

4\. 定义广播接收器，用于监听Barrier事件，收到事件后进行应用的业务处理。
      
      1. class TimeBarrierReceiver extends BroadcastReceiver {
        2.     @Override
        3.     public void onReceive(Context context, Intent intent) {
        4.         BarrierStatus barrierStatus = BarrierStatus.extract(intent);
        5.         String label = barrierStatus.getBarrierLabel();
        6.         switch(barrierStatus.getPresentStatus()) {
        7.             case BarrierStatus.TRUE:
        8.                 Log.i(TAG, label + " status:true");
        9.                 break;
        10.             case BarrierStatus.FALSE:
        11.                 Log.i(TAG, label + " status:false");
        12.                 break;
        13.             case BarrierStatus.UNKNOWN:
        14.                 Log.i(TAG, label + " status:unknown");
        15.                 break;
        16.         }
        17.     }
        18. }
