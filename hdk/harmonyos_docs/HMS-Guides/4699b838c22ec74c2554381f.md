本章节主要介绍接入华为云空间服务的开发步骤，以帮助开发者快速了解华为云空间服务提供的客户端接口及其调用方法。请开发者基于应用自身的使用场景，自行选择相应的开发章节。

# 1 功能描述

Drive SDK提供的主要能力以及调用方法如下：

  1. 获取鉴权信息。        

  2. 调用About.get()接口获取用户信息及授权页面。        

  3. 调用Files接口进行文件管理和搜索。        

  4. 调用Changes接口注册资源变化通知channel，开启文件变化通知功能。

  5. 调用Comments接口评论文件。

  6. 调用Replies接口对评论进行回复。

## 2.3 开发步骤

### **2.3.1  ****集成HMS**

如上所述，使用Drive SDK时，应用需要先通过HMS SDK获取用户信息，详见[集成Drive SDK和HMS SDK。](https://developer.huawei.com/consumer/cn/doc/drivekit-devpreparations#integDriveHMS)

### **2.3.2  ****设置HMS Scope**

通过HMS SDK登录时，需要通过HMS的[HuaweiIdAuthParamsHelper.setScopeList](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-huaweiidauthparamsHelper#setScopeList)接口设置Drive Scope，用于获取访问Drive接口的权限：
      
      1. List<Scope> scopeList = new ArrayList<>();
        2. scopeList.add(new Scope(DriveScopes.SCOPE_DRIVE)); //所有权限，除了应用文件夹权限
        3. scopeList.add(new Scope(DriveScopes.SCOPE_DRIVE_READONLY)); // 只允许查看文件内容和元数据
        4. scopeList.add(new Scope(DriveScopes.SCOPE_DRIVE_FILE)); //允许查看和管理文件
        5. scopeList.add(new Scope(DriveScopes.SCOPE_DRIVE_METADATA)); //允许查看和管理文件元数据，但不包括文件实体
        6. scopeList.add(new Scope(DriveScopes.SCOPE_DRIVE_METADATA_READONLY)); //只允许查看文件元数据，但不包括文件实体
        7. scopeList.add(new Scope(DriveScopes.SCOPE_DRIVE_APPDATA)); //支持APP数据上传和存储
        8. scopeList.add(HuaweiIdAuthAPIManager.HUAWEIID_BASE_SCOPE); // 账号基本权限
        9. HuaweiIdAuthParams authParams = new HuaweiIdAuthParamsHelper(DEFAULT_AUTH_REQUEST_PARAM)
        10.            .setAccessToken()
        11.            .setIdToken()
        12.            .setScopeList(scopeList)
        13.            .createParams();
    
    

不同的DriveScope对应不同的权限， 第三方开发者可以根据自己的业务需要申请对应权限。具体登录流程请参考[《华为帐号服务开发指南》](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/account-guide-v4)。

# 3 获取用户信息

## 3.1 场景介绍

第三方应用可以通过[**About.get**](https://developer.huawei.com/consumer/cn/doc/drivekit-drive-about#get)接口获取到用户华为云空间信息，例如空间容量大小，允许上传的最大文件大小等。

## 3.2 开发步骤

**步骤1****调用**[**Drive.Builder.build**](https://developer.huawei.com/consumer/cn/doc/drivekit-drive-builder#build)**接口创建Drive****对象。**
      
      1.  private Drive buildDrive() {    
        2.     Drive service = new Drive.Builder(CredentialManager.getInstance().getCredential(), context).build();      
        3.     return service;  
        4. }
    
    

**步骤2****调用[About.get](https://developer.huawei.com/consumer/cn/doc/drivekit-drive-about#get)****接口获取用户信息，设置字段setFields("*")****表示返回所有字段** 。
      
      1. private About getAbout() {
        2.     About response = null;
        3.     try {
        4.         Drive drive = buildDrive();
        5.         Drive.About about = drive.about();
        6.         response = about.get().setFields("*").execute();
        7.         String res = response.toString();
        8.     } catch (Exception e) {
        9.         Log.e(TAG, "getInfo error: " + e.toString());
        10.     }
        11.     return response;
        12. }
    
    

注意：

获取用户信息接口是联网耗时接口，需要放在子线程中调用。

**步骤3****如果**[**About.get**](https://developer.huawei.com/consumer/cn/doc/drivekit-drive-about#get)**接口返回响应中needUpdate****字段值为true****，表示需要用户更新安全策略，开发者需要根据返回的地址，跳转到授权页面，用户同意后可继续使用业务。**  

      
      1.  /**
        2. * 判断是否要提示用户更新协议
        3. *
        4. * @param about 返回的About响应
        5. */
        6. private void checkUpdateProtocol(About about) {
        7.     if (about == null) {
        8.         return;
        9.     }
        10.     Log.d(TAG, "checkUpdate: " + about.toString());
        11.     Object updateValue = about.get("needUpdate");
        12.     boolean isNeedUpdate = false;
        13.     if (updateValue instanceof Boolean) {
        14.         isNeedUpdate = (Boolean) updateValue;
        15.     }
        16.     if (!isNeedUpdate) {
        17.         return;
        18.     }
        19.     Object urlValue = about.get("updateUrl");
        20.     String url = "";
        21.     if (urlValue instanceof String) {
        22.         url = (String) urlValue;
        23.     }
        24.     if (TextUtils.isEmpty(url)) {
        25.         return;
        26.     }
        27.     Uri uri = Uri.parse(url);
        28.     if (!"https".equals(uri.getScheme())) {
        29.         return;
        30.     }
        31.     Intent intent = new Intent(Intent.ACTION_VIEW, uri);
        32.     try {
        33.         startActivity(intent);
        34.     } catch (ActivityNotFoundException e) {
        35.         Logger.e(TAG, "Activity Not found");
        36.     }
        37. }
    
    

注意：

needUpdate字段为可选字段，[**About.get**](https://developer.huawei.com/consumer/cn/doc/drivekit-drive-about#get)接口可能并不返回该字段。

# 4 文件管理和搜索

## 4.1 场景介绍

华为云空间服务的核心能力是对云端文件的管理，用户可以通过华为云空间服务方便快捷的管理、编辑华为云盘上的文件，支持创建、获取文件列表、拷贝、修改文件、移入回收站、清空回收站文件及搜索云盘上的文件等能力。

调用[**Files.create**](https://developer.huawei.com/consumer/cn/doc/drivekit-drive-files#createContent)接口创建文件：

文件上传方式分为直接上传和断点续传两种，其中直接上传支持的最大文件大小为20M，推荐低于5M的文件通过直接上传的方式上传，而断点续传不限制文件大小，推荐超过5M的文件使用断点续传的方式上传。

方式一：直接上传文件。
      
      1. /**    
        2. * 上传文件，该方式支持上传进度保存功能  
        3. * （用户上传过程中断网等，下次再上传同一个文件时会接着上次的进度上传）
        4. *

        6. * @param parentId 文件所在目录ID    
        7. * @param thumbnailImageBuffer 缩略图数据    
        8. * @param thumbnailMimeType 缩略图文件类型    
        9. */

        11.     try {      
        12.         if (filePath == null) {   
        13.             Logger.e(TAG, "createFile error, filePath is null."); 
        14.             return;        
        15.         }

        17.         FileContent fileContent = new FileContent(null, file);      
        18.         // 设置缩略图数据        
        19.         File.ContentExtras contentExtras = new File.ContentExtras();    
        20.         File.ContentExtras.Thumbnail thumbnail = new File.ContentExtras.Thumbnail();
        21.         thumbnail.setContent(Base64.encodeBase64String(thumbnailImageBuffer));        
        22.         thumbnail.setMimeType(thumbnailMimeType);        
        23.         contentExtras.setThumbnail(thumbnail);        
        24.         File content = new File()                
        25.             .setFileName(file.getName())                
        26.             .setParentFolder(Collections.singletonList(parentId))

        38.     } catch (Exception e) {        
        39.         Logger.e(TAG, "createFile exception: " + filePath + e.toString());

# 5 开启文件变化通知

## 5.1 场景介绍

华为云空间服务提供当文件发生变化时推送通知的能力，从而保持云端与本地文件同步。使用Changes功能需要第三方实现可实时接收变化的Server服务器，该Server可以接收变化并将变化信息实时推送给相应的客户端，客户端接收消息后可以及时刷新变化。

## 5.2 开发步骤

**步骤1****第三方实现可以接收文件变化的Server****服务器，需要将该Server****的地址注册到Drive****，Drive****在发送变化消息时需要校验Server****地址的有效性。**

登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，将Server服务器域名注册到Drive方法如下图：

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200113193800.12839840687337586278905353369627:50510610091120:2800:BB78EA06F3AE2E46FCF9D2C52F687ED32103D1E64C92557B309554E3B8138BA4.png?needInitFileName=true?needInitFileName=true)

**步骤2****开发者Server****服务器需要能解析Drive****发送的文件变化消息，Drive****消息的消息头格式如下：**

**表1  **

参数| 类型| 可选| 说明  
---|---|---|---  
X-HW-Channel-ID| varchar(255)| 必选| 第三方开发者指定的，通过[**Changes.subscribe**](https://developer.huawei.com/consumer/cn/doc/drivekit-drive-changes#subscribe)接口上报给Drive服务器的用户唯一标识。  
X-HW-Channel-Token| varchar(255)| 可选| 通过[**Changes.subscribe**](https://developer.huawei.com/consumer/cn/doc/drivekit-drive-changes#subscribe)接口Drive服务器返回的Cursor，Server需要对Cursor进行校验。

X-HW-Message-Number| Int64| 必选| 消息号，后面的消息总是大于前面的，但是并不是连续的。Sync消息总是为1。

**步骤3****第三方Server****服务器下发变化通知应用。**

第三方Server服务器能够将Drive发送的变化消息下发通知到应用，让应用刷新变化内容；Drive不限制第三方Server下发变化通知的实现方式，但推荐开发者使用华为推送服务，华为推送服务已经实现了将服务器消息推送到指定应用的功能，使用华为推送服务需要对接HMS Core Push SDK，具体参考[《消息推送服务》](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/push-introduction)。若不使用华为推送服务，则不需要集成HMS Core Push SDK，但第三方Server需要自己实现消息推送的功能。

## 9.2 开发步骤

以批量创建文件夹为例来说明具体开发步骤：

**步骤1****调用**[**Drive.Builder.build**](https://developer.huawei.com/consumer/cn/doc/drivekit-drive-builder#build)**接口构造Drive对象。**
      
      1.  private Drive buildDrive() {

        3.     return service;
        4. }
    
    

**步骤2****创建JsonBatchCallback****回调对象，调用Drive****的batch****函数获取BatchRequest****对象，再调用Files.Create****的queue****函数将操作添加到队列中，再执行[BatchRequest.execute](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/drivekit-batchrequest#excute)****即可完成批量操作** 。
      
      1. /**

        5.     @Override

        7.         Logger.i(TAG, "callback error: " + e.toString());
        8.     }
        9.     @Override
        10.     public void onSuccess(File file, HttpHeaders responseHeaders) throws IOException {
        11.         Logger.i(TAG, "callback sucessful: " + file.toString()); 
        12.     }
        13. };
        14. /**
        15.  * 批量创建目录
        16.  */
        17. private void batchCreateDirectory() {
        18.     Drive drive = buildDrive();
        19.     BatchRequest batch = drive.batch();
        20.     try {
        21.         for (int i = 0; i < 2; i++) {
        22.             Map<String, String> appProperties = new HashMap<>();
        23.             appProperties.put("appProperties", "property");
        24.             SimpleDateFormat formatter = new SimpleDateFormat("yyyyMMdd_HHmmss_SSS");
        25.             String dirName = formatter.format(new Date()) + "_" + i;
        26.             Logger.i(TAG, "executeFilesCreate: " + dirName);
        27.             File file = new File();
        28.             file.setFileName(dirName)
        29.                     .setAppSettings(appProperties)
        30.                     .setMimeType("application/vnd.huawei-apps.folder");
        31.             Drive.Files.Create create = drive.files().create(file);
        32.             create.queue(batch, callback);
        33.         }
        34.         batch.execute();
        35.     } catch (Exception e) {
        36.         Logger.e(TAG, "batchCreateDirectory error: " + e.toString());
        37.     }
        38. }
