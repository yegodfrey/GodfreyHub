针对AndroidStudio开发环境，华为提供了maven仓集成方式的HMS SDK包。在开始开发前，您需要将HMS SDK集成到您的Android Studio开发环境中。

# 1 在Android Studio开发环境中添加当前应用的AppGallery Connect配置文件

1\. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择“我的应用”。

2\. 在名称列表中找到应用，点击对应的名称。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200416224743.91023831541255379646989284801617:50510427032749:2800:1346CA9652243874F5A827CC1ADFD439BB23497B98DF655FDE9A41CD43F0285C.png?needInitFileName=true)

3\. 选择“开发 > 概览”。

4\. 单击“应用”栏下的“agconnect-service.json”下载配置文件。

5\. 将agconnect-service.json文件拷贝到模块目录下。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200312222112.98573843155150138528782432052424:50510427032749:2800:4AA01DF1684779B555D966B3E397708C9716271B952BD9B3504870899191F4B8.png?needInitFileName=true)  


# 2 配置HMS SDK的Maven仓地址

1\. 打开AndroidStudio项目级build.gradle文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200312222027.84563221724152485004027988410877:50510427032749:2800:1698C4CB16EAE7323A72DE05C7AF197ED5716886433BC1709CD5BEBF8350B000.png?needInitFileName=true)  


2\. 添加华为AGC插件以及配置Maven仓地址。

在allprojects -> repositories里面配置HMS SDK的Maven仓地址。

在buildscript -> repositories里面配置HMS SDK的Maven仓地址。

在buildscript -> dependencies里面增加配置。
      
      1. buildscript {
        2.     repositories {
        3.         google()
        4.         jcenter()
        5.         maven {url 'https://developer.huawei.com/repo/'}
        6.     }
        7.     dependencies {
        8.         classpath 'com.huawei.agconnect:agcp:1.2.1.301'
        9.     }
        10. }
        11. allprojects {
        12.     repositories {
        13.         google()
        14.         jcenter()
        15.         maven {url 'https://developer.huawei.com/repo/'}
        16.     }
        17. }
    
    

说明：

Maven仓地址直接在浏览器中打开无法访问，只能在IDE中配置。

# 3 添加编译依赖

1\. 打开项目app目录下的build.gradle文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200409211905.49801757510027076248545093069872:50510427032749:2800:B27C37DE6BC491B8D602D0FA840AAD69F2B584BAF932A47E126B0FBE9140F2F6.png?needInitFileName=true)

2\. 配置编译依赖。
      
      1. dependencies {implementation 'com.huawei.hms:maps:{version}'}
    
    

说明：

{version} 替换为实际的SDK版本号。最新的版本号是**implementation 'com.huawei.hms:maps: 4.0.1.300'** 。

3\. 在文件头中添加AGC插件依赖配置。  

      
      1. apply plugin: 'com.huawei.agconnect'
    
    

说明：

配置apply plugin: 'com.huawei.agconnect'必须添加到配置apply plugin: 'com.android.application'后。

华为Map Kit支持的最低Android版本（minSdkVersion）是Android 4.4 （API等级是19）。

4\. 在android中配置签名。将“生成签名证书指纹”章节生成的签名文件复制到您工程的app目录下，并在build.gradle文件中配置签名。
      
      1. android {
        2.     signingConfigs {
        3.         release {
        4.             storeFile file("hmsmapdemo.keystore")
        5.             storePassword "123456"
        6.             keyAlias "androiddebugkey"
        7.             keyPassword "123456"
        8.             v2SigningEnabled true
        9.         }
        10.     }
        11.     buildTypes {
        12.         release {
        13.             minifyEnabled false
        14.             proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'), 'proguard-rules.pro'
        15.             signingConfig signingConfigs.release
        16.         }
        17.         debug {
        18.             signingConfig signingConfigs.release}
        19.         }
        20.     }
        21. }
    
    

# 4 同步数据

重新打开修改后的build.gradle文件。在页面的右上角会出现一个Sync Now链接。点击Sync Now，等待同步完成。

# 5 配置混淆脚本

编译APK前需要配置不要混淆HMS SDK ，避免功能异常。

1、打开您的应用的混淆脚本文件。

2、加入排除HMS SDK混淆的配置。
      
      1. -ignorewarnings
        2. -keepattributes *Annotation*
        3. -keepattributes Exceptions
        4. -keepattributes InnerClasses
        5. -keepattributes Signature
        6. -keepattributes SourceFile,LineNumberTable
        7. -keep class com.hianalytics.android.**{*;}
        8. -keep class com.huawei.updatesdk.**{*;}
        9. -keep class com.huawei.hms.**{*;}
    
    

3、如果您使用了AndResGuard，需要在混淆配置文件中加入AndResGuard白名单。
      
      1. "R.string.agc*",
        2. "R.string.hms*",
        3. "R.string.connect_server_fail_prompt_toast",
        4. "R.string.getting_message_fail_prompt_toast",
        5. "R.string.no_available_network_prompt_toast",
        6. "R.string.third_app_*",
        7. "R.string.upsdk_*",
        8. "R.layout.hms*",
        9. "R.layout.upsdk_*",
        10. "R.drawable.upsdk*",
        11. "R.color.upsdk*",
        12. "R.dimen.upsdk*",
        13. "R.style.upsdk*"
    
    

# 6 配置React Native部分

  * 请下载并解压React Native版的Map SDK。




SDK下载地址：[下载React Native版的Map SDK](https://developer.huawei.com/consumer/cn/doc/development/HMS-Library/hms-map-v4-sdkdownload-rn)。

  * 将Map SDK复制到您工程的node_modules目录下。




结构如下：

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200416225242.74976120521559369058456992913252:50510427032749:2800:FCB38B6ECE6FF4370D2884079851B13FE1577B8B5ABC6F28A8E7C0B85A4F4E1E.png?needInitFileName=true)

  * 将如下类导入到您工程的MainApplication.java文件中：



      
      1. import com.huawei.hms.rn.map.MapsPackage;
    
    

然后将如下行添加至您的getPackages方法：
      
      1. packages.add(new MapsPackage());
    
    

最终的文件结构如下：

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200416225445.31881043421175823425735085529589:50510427032749:2800:CC3278015B5C0D4B93A6D4A59171C1549D878084C119FCADA38BA7BD1166F29B.png?needInitFileName=true)

  * 将如下行添加至您工程的android/settings.gradle文件中：



      
      1. rootProject.name = 'RNHMSMap Demo'
        2. include ':react-native-hms-map'
        3. project(':react-native-hms-map').projectDir = new File(rootProject.projectDir, '../node_modules/react-native-hms-map/android')
        4. apply from: file("../node_modules/@react-native-community/cli-platform-android/native_modules.gradle"); applyNativeModulesSettingsGradle(settings)
        5. include ':app'
    
    

  * 将如下行添加到android/app/build.gradle文件中的dependencies下：



      
      1. implementation project(':react-native-hms-map')
