一级分类| 二级分类| HMS SDK 2.0| HMS SDK4.0  
---|---|---|---  
公共配置| SDK升级要求| 支持直接从HMS  SDK2.0升级至HMS  SDK4.0  
SDK下载| 提供Eclipse/Android  Studio/通用方式三种方式。| 支持2种方式：1\. 支持Android Studio，通过maven仓方式下载。2\. 支持Eclipse，通过下载HMS SDK包本地集成。  
HMS Agent| 支持| 取消了HMS Agent，无需再集成  
manifest配置| 需要手动配置。| 1\. 使用Android Studio可通过JSON文件自动配置。2\. 使用Eclipse，需要参考执行部分手动配置。  
支付| 支付回调| 客户端支付成功后，华为服务器会主动回调通知您的服务器。| 取消支付成功回调机制，提供新的主动校验机制。开发者如需对支付结果进行校验，可以参考[Order服务购买Token校验](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/iap-order-service-purchase-token-verification-v4)。  
消耗概念| 不涉及消耗操作。| 用户支付成功，需要在商品发放成功后，对消耗型商品进行消耗（调用consumeOwnedPurchase接口），否则用户无法继续购买。  
发货流程| 支付完成后，开发者的客户端或服务器进行支付验签，验签成功后开始发货。| 对于消耗性商品，开发者在发货成功后需要调用consumeOwnedPurchase接口将商品状态从已拥有但未消耗置换为已消耗，具体商品支付、发货和消耗逻辑请参考[购买商品流程](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/iap-purchase-subscription-process-v4)。  
商品类型| 消耗型/非消耗型| 除消耗型/非消耗型商品，新增订阅型商品。  
掉单补单| 客户端需要将可能存在掉单（支付结果返回300XX错误码等）的订单号缓存，调用getOrderDetail接口向华为服务器请求该订单实际支付结果。| HMS SDK 4.0订单完全托管，客户端通过调用obtainOwnedPurchases接口向华为服务器请求掉单信息。  
支付验签| 1\. 存在支付私钥和支付公钥2\. HMS SDK 2.0需要对支付返回的参数做排序、拼装等操作，并使用支付私钥对拼接后的字符串做签名处理| 1\. 只有支付公钥，支付公钥的值与获取方式均与HMS SDK 2.0不同。2\. 华为服务器会将待验签的字符串直接返回给应用客户端或开发者服务器，开发者可直接使用支付公钥对该字符串签名，无需开发者对待签名字符串做排序、拼装等。  
商户请求号（商户侧订单号）| 商户订单id由开发者自定义订单id（通过请求中的requestId字段）| 1\. HMS SDK 4.0订单id全托管，即支付完成后，由华为服务器生成华为订单id或商户请求号返回给客户端。2\. 若开发者希望使用自定义订单id，可通过客户端请求的developerPayload字段，将自定义订单id和华为订单id关联起来。  
获取商品信息| 通过getProductDetails接口| 通过obtainProductInfo接口  
沙盒功能（非真实支付）| 不支持，CP可通过定价0元商品支付| 支持  
游戏| 校验登录验签| 1\. 通过login接口返回的ts、playerId、playerLevel、gameAuthSign等参数做排序生成待签名字符串；2\. 开发者需要向华为游戏服务器请求验签| 机制不变，唯一变化点在于获取ts、playerId、playerLevel、gameAuthSign等参数非login接口返回的，而是getCurrentPlayer接口  
游戏成就| 不支持| 新增  
游戏事件上报| 不支持| 新增  
防沉迷| 华为提供查询玩家实名情况和拉起实名弹框的功能，不支持游戏时长统计。| 不提供查询玩家实名情况和接口调用拉起实名弹框的能力。变更如下功能：1\. 登录华为帐号时强制实名，对未实名玩家自动弹实名认证框，未实名不允许进入游戏（需要玩家手机的HMS Core（APK）版本不低于4.0且开发者已向华为运营申请游戏强制实名）。2\. 玩家游戏行为上报，开发者在玩家登录和退出游戏时（包括游戏切换后台或再返回前台、关机等场景）向华为服务器上报玩家行为，华为服务器计算时长并提供接口供开发者查询玩家的累计游戏时长。  
排行榜| 不支持| 新增  
游戏存档| 不支持| 新增  
玩家信息统计| 不支持| 新增  
游戏基本信息| 不支持| 新增  
华为分析服务| 华为分析服务| 不涉及| 新增
