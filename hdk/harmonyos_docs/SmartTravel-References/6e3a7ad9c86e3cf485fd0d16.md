# CarConnectInfo  
  
Name | Type | Description  
---|---|---  
modelId[8] | char | Model ID allocated by Huawei to the manufacturer to identify the vehicle brand and model. For example, in the value 0003EB00, **0003EB** indicates the vehicle brand and **00** indicates the vehicle model. Manufacturers need to apply for this ID to Huawei for official use.  
brMac[20] | char | Classic Bluetooth address of the head unit. The format is AA:BB:CC:DD:EE:FF. The valid length is 17.  
connectAllowType | uint32_t | Connection modes supported by the head unit. The value of bit 0 indicates the support for wireless mode: 0 (not supported) and 1 (supported). The value of bit 1 indicates the support for USB: 0 (not supported) and 1 (supported). The value of bit 2 indicates the support for scan to connect mode: 0 (not supported) and 1 (supported). For details about the value, see [CarConnectAllowType](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/car-connect-allow-type-0000001052795163).  
carDeviceId | char* | Head unit ID, which uniquely identifies a head unit.  
idLen | uint32_t | Length of the ID.
