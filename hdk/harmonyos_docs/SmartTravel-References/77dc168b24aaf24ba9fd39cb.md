# Scenario Metadata

#### Scenario Overview

After the head unit connects to and requests scenario metadata from HiCar, HiCar will send scenario metadata to the head unit based on the request when scenario metadata is generated. Scenario metadata includes:

     * Calendar metadata
     * Weather metadata
     * AI Tips metadata
     * IoT metadata

#### Data Type

530

#### API Version

1.0

#### API Definition

**Table 1** Scenario metadata APIParameter | Mandatory | Type | Description  
---|---|---|---  
ScenceData | Yes | object | Scenario metadata. For details, please refer to Table 2.  
ScenceDataResp | Yes | object | Response data. For details, please refer to Table 4.  
  
**Table 2** ScenceDataParameter | Mandatory | Type | Description  
---|---|---|---  
Type | Yes | int | Scenario metadata type:
     * **1** : calendar
     * **2** : weather
     * **3** : AI Tips
     * **4** : IoT  
Status | Yes | int | Metadata status:
     * **0** : created and updated
     * **1** : removed  
Id | Yes | int | Unique metadata ID.  
Title | Yes | string | App display name.  
AppIcon | No | byte[] | App icon.  
AppPackage | Yes | string | App package name.  
InfoImage | No | byte[] | Information image.  
MainText | Yes | string | Main information text.  
SubText | Yes | string | Auxiliary information text.  
OptText | No | string | Optional text.  
OptImage | No | byte[] | Optional image, which may be involved in weather metadata, such as the location icon.  
Button1 | No | object | Response button 1 supported by the current metadata, which is involved in IoT metadata and can be used to display the control button. For details, please refer to Table 3.  
Button2 | No | object | Response button 2 supported by the current metadata, which is not involved currently. For details, please refer to Table 3.  
Button3 | No | object | Response button 3 supported by the current metadata, which is not involved currently. For details, please refer to Table 3.  
  
**Table 3** ButtonX**Parameter** | Mandatory | **Type** | **Description**  
---|---|---|---  
BtnText | Yes | string | Button text.  
BtmImage | Yes | byte[] | Button icon.  
BtnType | Yes | string | Button type:
     * **emphasize** : confirmation type, for example, an OK button.
     * **normal** : non-default, for example, a Cancel button.
     * **check** : check box  
  
**Table 4** ScenceDataRespParameter | Mandatory | Type | Description  
---|---|---|---  
RespCode | Yes | int | Response result:
     * **100000** : received
     * **100001** : not received  
CardClick | Yes/No | boolean | Indicates whether a click event occurs:
     * **true** : A click event occurs. For example, a user touches a card.
     * **false** : No click event occurs.
This parameter is mandatory when a click event is sent.  
Id | Yes/No | int | Unique metadata ID. This parameter is mandatory when a click event is sent.  
Type | Yes/No | int | Scenario metadata type:
     * **1** : calendar
     * **2** : weather
     * **3** : AI Tips
     * **4** : IoT
This parameter is mandatory when a click event is sent.  
Button1 | Yes/No | boolean | The value is **true** if a user touches a button, and **false** otherwise. This parameter is mandatory when a button click event is sent.  
  
#### API Examples

#### [h2]Calendar Metadata

The following is the sample code when the HiCar app sends calendar metadata to the head unit:
    
    {
        "ScenceData" : {
            "Type" : 1,
            "Status" : 0,
            "Id" : 1234,
            "Title" : "Calendar",
            "AppIcon" : [],
            "AppPackage" : "com.huawei.calendar",
            "InfoImage" : [],
            "MainText" : "Test",
            "SubText" : "All day",
            "OptText" : "Wednesday, August 24"
        }
    }

The head unit sends a response message to the HiCar app. The sample code is as follows:
    
    {
        "ScenceDataResp": {
            "RespCode" : 100000,
            "Id" : 1234,
            "Type" : 1,
            "CardClick" : true
        }
    }
