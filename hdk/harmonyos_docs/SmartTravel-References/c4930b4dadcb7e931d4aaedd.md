# isSupportCarGpsAbility  
  
Function  
---  
boolean isSupportCarGpsAbility()  
Checks whether the GPS data (longitude, latitude, altitude, precision, satellite time, and moving direction) of the vehicle can be obtained.  
  
**Return**

Type | Description  
---|---  
boolean | Returned result:
     * **true** : yes
     * **false** : no
Returns **true** if any of the following data types can be obtained from the head unit and **false** otherwise: longitude, latitude, altitude, precision, satellite time, and moving direction.
