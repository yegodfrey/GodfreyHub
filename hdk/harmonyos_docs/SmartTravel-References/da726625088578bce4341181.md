# SetGPSDataReportFreq  
  
Function  
---  
int32_t (*SetGPSDataReportFreq)( int32_t locationFreq, int32_t drivingFreq, int32_t sensorFreq)  
Dynamically sets the GPS data reporting frequency. If the set frequency exceeds the limit, an error is returned.  
  
**Parameters**

**Name** | **Type** | **Description**  
---|---|---  
locationFreq | int32_t | Frequency for reporting GPS location data, in Hz.  
drivingFreq | int32_t | Vehicle body data reporting frequency, in Hz.  
sensorFreq | int32_t | Sensor data reporting frequency, in Hz.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : success
     * Negative value: failure
