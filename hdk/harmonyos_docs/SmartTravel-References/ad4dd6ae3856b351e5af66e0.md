# DeviceServiceChange  
  
Function  
---  
void (*DeviceServiceChange)(const char* serviceId, uint32_t idLen, int state)  
Reports the HiCar service status.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
*serviceId | char | Virtual service ID on the phone.  
idLen | uint32_t | Length of the service ID.  
state | int | Device event type. For details, see [HiCarEvent](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/hicar-event-0000001052556437).
