# HiCarRegisterListener  
  
Function  
---  
int32_t HiCarRegisterListener(CarListener *listener)  
Registers HiCar listeners for receiving HiCar device status changes, service changes, and HiCar data.  
  
**Parameters**

**Name** | **Type** | **Description**  
---|---|---  
listener | CarListener | HiCar listeners.  
  
**Return**

Type | Description  
---|---  
int32_t | Registration result.
     * **0** : Registration succeeded.
     * Other values: Registration failed.
