# Scenario Overview

The HiCar app requires the head unit to report the name and logo icon of the vehicle brand for the following purposes:

     * Displaying the vehicle brand information in the device discovery dialog box
     * Displaying the name and logo of the vehicle brand in the app icon area on the projection screen, so that users can touch the brand icon to switch to the native in-vehicle infotainment (IVI) system screen

After a HiCar connection is set up, the HiCar screen of the phone is projected to in-vehicle screen. Users can touch the vehicle brand icon in the app list area on the HiCar screen to return to the native IVI system screen. After the head unit connects to the HiCar phone, it must send the vehicle brand logo icon to the phone as requested. The HiCar phone then displays the obtained logo. If the head unit does not transfer the logo, the default HiCar icon will be used.
