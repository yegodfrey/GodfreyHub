# updateGop (Beta)  
  
Method  
---  
CarConfig updateGop(int gop)  
Updates the number of frames between two I-frames of the head unit.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
gop | int | Number of frames between two I-frames. The value range is 30–600.  
  
**Return**

Type | Description  
---|---  
CarConfig | Vehicle configuration.
