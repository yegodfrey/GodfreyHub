# updateCodecType (Beta)  
  
Method  
---  
CarConfig updateCodecType(int codecType)  
Updates the video codec type of the head unit.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
codecType | int | Video codec type:
     * **1** : H.264 (default value)
     * **2** : H265  
  
**Return**

Type | Description  
---|---  
CarConfig | Vehicle configuration.
