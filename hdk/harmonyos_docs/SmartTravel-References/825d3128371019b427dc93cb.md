# HiCarStopProjection  
  
Function  
---  
int32_t HiCarStopProjection(HICAR_HANDLE handle)  
Stops HiCar projection.  
  
**Name** | **Type** | **Description**  
---|---|---  
handle | HICAR_HANDLE | HiCar handle, which is obtained through **GetHiCarHandle**.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : success
     * Other values: failure
