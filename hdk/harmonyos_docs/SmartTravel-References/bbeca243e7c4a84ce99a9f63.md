# onAppInfoUpdate  
  
Method  
---  
void onAppInfoUpdate(String deviceId, List<AppInfoBean> appInfoBeans);  
Callback for updated **AppInfo** data (mobile phone app updates such as icons or package names) of the converged desktop.  
  
**Parameters**

Parameter Name | Parameter Type | Description  
---|---|---  
deviceId | String | **deviceId** of the peer device (mobile phone).  
appInfoBeans | List<AppInfoBean> | **AppInfo** data list of updated apps.
