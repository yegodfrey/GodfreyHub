# HiCarStartAdv  
  
Function  
---  
int32_t HiCarStartAdv()  
Triggers HiCar to send advertising packets so that the HiCar phone can detect the head unit. When the user touches the HMI app icon, the app needs to call this API. The advertising timeout interval is 2 minutes. When the advertising times out, the **DeviceChange** function receives the **HICAR_DEVICE_ADV_TIMEOUT (111)** status code. The HMI app then needs to prompt the user to exit HiCar or resend the advertising packets.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : success
     * Other values: failure
