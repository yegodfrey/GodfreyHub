# RegisterChannelCallback  
  
Function  
---  
int (*RegisterChannelCallback)(const ChannelCallback *channelCallback)  
Registers the pointer to the channel callback function.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
*channelCallback | const ChannelCallback | Channel callback function.  
  
**Return**

Type | Description  
---|---  
int | Operation result.
     * **0** : success
     * Other values: failure
