# DMSDPVirtualStreamDataHeader  
  
Name | Type | Description  
---|---|---  
streamType | uint32_t | Stream type of the virtual audio stream.  
length | uint32_t | Data length per frame in the virtual audio stream, excluding the header.  
reserveds | [DMSDPReserveds](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-reserveds-0000001052570505) | Reserved word of the data header of the virtual audio stream.
