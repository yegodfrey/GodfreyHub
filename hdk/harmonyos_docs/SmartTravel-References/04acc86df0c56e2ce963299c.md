# surfaceChanged  
  
Method  
---  
void surfaceChanged(SurfaceHolder surfaceHolder, int format, int width, int height)  
Updates a surface.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
surfaceHolder | SurfaceHolder | surfaceHolder object.  
format | int | Pixel format of the surface. The options are as follows: PixelFormat.RGBA_8888, PixelFormat.RGBX_8888, PixelFormat.RGBA_F16, PixelFormat.RGBA_1010102, PixelFormat.RGB_888, or PixelFormat.RGB_565.  
width | int | New surface width (in dp).  
height | int | New surface height (in dp).
