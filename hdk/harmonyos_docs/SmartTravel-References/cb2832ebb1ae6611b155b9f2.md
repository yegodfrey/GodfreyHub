# Vehicle Sensor (Speed/Acceleration)

#### Scenario Overview

After a HiCar connection is set up between the head unit and the phone, the HiCar app sends a request to the head unit to obtain the light intensity, vehicle speed, acceleration, and gyroscope data. After receiving the requested data, the head unit reports the corresponding data. After the corresponding data changes, report the changed data.

#### Data Type

510

#### API Version

1.0

#### API Definition

**Table 1** Vehicle sensor APIParameter | **Mandatory** | Type | **Description**  
---|---|---|---  
service | Yes | string | Service type. The value is **sensorData** for the current service.  
subService | Yes | string | Subservice type. The value is **transmission** for the current service.  
command | Yes | int | Instructions:
     * **0** : The HiCar app requests sensor data from the head unit.
     * **1** : The head unit reports sensor data to the HiCar app.  
data | Yes | object | Parameter. For details, see Table 2.  
timestamp | Yes | int | Timestamp, which is accurate to millisecond. Unix time, for example, 1617087892722.  
  
**Table 2** dataParameter | **Mandatory** | Type | **Description**  
---|---|---|---  
illumination | Yes | int[] | Light intensity inside and outside the vehicle, in the format of [intensity inside the vehicle, intensity outside the vehicle]. Unit: lx Example: [100, 1000] Requirements:
     * [1,1]: Request the data.
     * [-1,-1]: Stop reporting the data.  
speed | Yes | int | Vehicle speed (integer type). Unit: km/h Example: 80 Requirements:
     * **1** : Request the data.
     * **-1** : Stop reporting the data.  
acc | Yes | int[] | Definition of three acceleration axes (X, Y, and Z): The forward direction of the vehicle is the positive direction of the X axis, the forward direction of the vehicle on the left is the positive direction of the Y axis, and the vertical direction is the positive direction of the Z axis.      * [1,1,1]: Request the data.
     * [-1,-1,-1]: Stop reporting the data.  
gry | Yes | int[] | Definition of three axes (X, Y, and Z) of the gyroscope: The forward direction of the vehicle is the positive direction of the X axis, the forward direction of the vehicle on the left is the positive direction of the Y axis, and the vertical direction is the positive direction of the Z axis. Unit: rad/s Example: [1.15,0.01,0] Requirements:
     * [1,1,1]: Request the data.
     * [-1,-1,-1]: Stop reporting the data.  
  
After the head unit and phone are connected, the head unit needs to proactively report the subscribed sensor data to the HiCar app. The reporting period is as follows:

     * Vehicle speed: Updated when the vehicle speed changes. To avoid message congestion, the update interval is 1s or longer for normal driving (less than 80 km/h) and 500 ms or longer for high-speed driving (greater than 80 km/h).
     * Light intensity, acceleration, and gyroscope: Updated per second.

#### API Examples

Example: The HiCar app requests sensor data from the head unit.
    
    {
        "service": "sensorData", 
        "subService": "transmission", 
        "command": 0, 
        "data": {
            "illumination": [1,1], 
            "speed": 1, 
            "acc": [1,1,1], 
            "gry": [1,1,1]
        }
    }

Example: The head unit reports sensor data to the HiCar app.
    
    {
        "service": "sensorData", 
        "subService": "transmission", 
        "command": 1, 
        "data": {
            "illumination": [100,1000], 
            "speed": 80, 
            "acc": [1.15,0.01,0], 
            "gry": [1.10,3.15,0.45]
        }, 
        "timestamp": 1617087892722
    }
