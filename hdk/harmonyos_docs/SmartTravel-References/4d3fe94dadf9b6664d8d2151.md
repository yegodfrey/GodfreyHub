# GetCameraCapability  
  
Function  
---  
int32_t (*GetCameraCapability)(DMSDPCameraCapabilities** capabilities, uint32_t* num)  
Queries the attribute information of the available cameras. Use the Release API to release the collected capability set resources.  
  
**Parameters**

**Name** | **Type** | **Description**  
---|---|---  
capabilities | [DMSDPCameraCapabilities](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-camera-capabilities-0000001052250536) | Capability set.  
num | uint32_t | Number of capability sets. Each camera has one capability set.  
  
**Return**

Type | Description  
---|---  
int32_t | Attributes of each local camera.
