# removeSecureFile  
  
Function  
---  
boolean removeSecureFile(string fileName)  
The HiCar SDK uses this callback to delete an authentication file. Authentication files are managed by the HMI app.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
fileName | string | Name of the file to be deleted.  
  
**Return**

Type | Description  
---|---  
boolean | Indicates whether the deletion is successful:
     * **true** : success
     * **false** : failure
