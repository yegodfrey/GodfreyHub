# BleParams  
  
Name | Type | Description  
---|---|---  
*serviceUuid | const char | Service UUID required when GATT is used for Nearby data communication.  
*readUuid | const char | UUID for the read characteristic of the GATT service.  
*writeUuid | const char | UUID for the write characteristic of the GATT service.  
serviceEnable | int | Indicates whether GATT starts the service. The options are as follows:
     * **0** : no
     * **1** : yes  
attrPerm | int | Read and write permissions on attributes defined in the GATT protocol.  
charProp | int | Properties corresponding to the characteristics in the GATT protocol.  
minInterval | int | Minimum interval for the GATT client to send advertising data, in milliseconds.  
maxInterval | int | Maximum interval for the GATT client to send advertising data, in milliseconds.  
timeout | int | Advertising timeout interval of the GATT client, in seconds. The value **0** indicates that advertising does not stop. The default value is 120 seconds.  
*nearbyAdvData | char | Advertising data sent by the GATT client.  
iadvDataLen | int | Length of advertising data sent by the GATT client.
