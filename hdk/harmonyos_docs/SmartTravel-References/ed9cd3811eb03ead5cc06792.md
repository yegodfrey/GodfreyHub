# GetParamsType  
  
Enumerator | Description  
---|---  
GET_DEV_MAC | Obtains the device MAC address in the format of xx:xx:xx:xx:xx:xx (capital letters required).  
GET_MODEL_ID | Obtain the device model ID.  
GET_DEV_NAME | Obtains the device name. Disabled.  
GET_MAP_PORT | Obtains the port number mapped to the BR service UUID.  
GET_WIFI_ABILITY | Obtains the Wi-Fi capability.  
GET_BLE_ADV_POWER | Obtains signal strength of BLE advertising.  
GET_GC_IP | Obtain the IP address that is allocated to GC.
