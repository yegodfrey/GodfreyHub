# HiCarRelease  
  
Function  
---  
int32_t HiCarRelease()  
Deregisters the HiCar SDK when the HiCar service is not in use.  
  
**Return**

Type | Description  
---|---  
int32_t | Deregistration result.
     * **0** : Deregistration succeeded.
     * Other values: Deregistration failed.
