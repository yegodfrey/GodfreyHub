# Overview  
  
#### Interface Summary

Interface | Description  
---|---  
CarListener | Listener that contains callbacks for events of the HUAWEI HiCar (HiCar for short) SDK.  
HiCarInitCallback | Callback for **HiCarAdapter** instantiation.  
  
#### Class Summary

Class | Description  
---|---  
CarConfig | Defines HiCar-related parameters, including the model ID, Bluetooth MAC address of the head unit, and resolution and physical size of the in-vehicle screen.  
CarAudioListener | Provides audio-related callbacks of the HiCar SDK.  
HiCarAdapter | Provides the main functional APIs of the HiCar SDK, including the SDK initialization, advertising for device discovery, and projection APIs.  
HiSightSurfaceView | Used for video UI layout and provided in the form of views.  
TrustPhoneInfo | Returns information about authenticated devices.  
HiCarConst | Defines the constant values used in the HiCar SDK, including the event ID and error code.  
HardwareInfo | Defines head unit hardware information.
