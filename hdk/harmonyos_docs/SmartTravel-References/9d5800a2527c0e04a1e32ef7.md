# getModelId  
  
Method  
---  
String getModelId()  
Obtains the value of **ModelId** , which is allocated by Huawei to distinguish between vehicle manufacturers and models.  
  
**Return**

Type | Description  
---|---  
String | A character string that identifies the vehicle manufacturer. The value consists of eight characters. The first six characters are the vehicle manufacturer ID, and the last two characters are the vehicle model ID.
