# updateAdvPower (Beta)  
  
Method  
---  
CarConfig updateAdvPower(int advPower)  
Updates the advertisement signal strength of the head unit.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
advPower | int | Head unit broadcast signal strength. The value range is –128 to +127.  
  
**Return**

Type | Description  
---|---  
CarConfig | Vehicle configuration.
