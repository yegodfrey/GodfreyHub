# DataReceive  
  
Function  
---  
void (*DataReceive)(const char *deviceId, uint32_t idLen, int dataType, char *data, uint32_t dataLen)  
Receives data from HiCar.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
*deviceId | char | Device ID of the phone.  
idLen | uint32_t | ID length.  
dataType | int | Data type. For details, see [CarDataType](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/car-data-type-0000001052955157).  
*data | char | Data content.  
dataLen | uint32_t | Data length.
