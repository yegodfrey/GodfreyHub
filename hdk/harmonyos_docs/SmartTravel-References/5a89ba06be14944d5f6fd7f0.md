# Call Metadata

#### Scenario Overview

After the head unit connects to HiCar and is authorized to obtain the call metadata, HiCar will notify the head unit of the basic call information and status once HiCar detects that the call status changes. Then, the head unit will be able to send the data to the dashboard, HUD, or central display screen for display, or process the call logic based on the call metadata.

516

#### API Version

1.0

#### API Definition

**Table 1** Call metadataParameter | Mandatory | Type | Description  
---|---|---|---  
CallData | Yes | object | Call metadata. For details, please refer to Table 2.  
CallDataResp | Yes | object | Response data. For details, please refer to Table 3.  
  
**Table 2** CallDataParameter | Mandatory | Type | Description  
---|---|---|---  
ContactName | Yes | String | Contact name.  
RemoteNumber | Yes | String | Incoming phone number.  
Direction | Yes | int | Call direction:
     * **0** : UNKNOWN
     * **1** : OUTGOING
     * **2** : INCOMING  
Status | Yes | int | Call status:
     * **0** : IDLE
     * **1** : ACTIVE
     * **2** : HOLDING
     * **3** : DIALING
     * **4** : ALERTING
     * **5** : INCOMING
     * **6** : WAITING
     * **7** : DISCONNECTED
     * **8** : DISCONNECTING  
CallStartTimestamp | Yes | long | Start timestamp of a call.  
CallID | Yes | String | Call ID.  
CallApp | Yes | int | Call app:
     * **0** : UNKNOWN
     * **1** : TELEPHONY (carrier call)
     * **2** : HICALL (MeeTime call)  
NumberMarktype | Yes | String | Marked type of a phone number, which labels an incoming phone number so that the user can quickly identify the type of the call. The options are as follows:
     * Space: default value
     * **crank** : spam
     * **fraud** : scam
     * **promote sales** : advertising
     * **house agent** : estate agency
     * **express** : delivery service
     * **taxi** : taxi
     * **insurance** : insurance & loans  
ReleaseCause | Yes | int | Release reason.
     * **-1** : UNKNOWN
     * **0** : call ended
     * **1** : call rejected
     * **2** : call failed  
  
**Table 3** CallDataRespParameter | Mandatory | Type | Description  
---|---|---|---  
RespCode | Yes | int | Response result:
     * **100000** : received
     * **100001** : not received  
  
#### API Examples

When the call status changes, the HiCar app sends the call metadata to the authorized head unit based on the user authorization record. The sample code is as follows:
    
    {
        "CallData": {
    	"ContactName": "tom",
    	"RemoteNumber": "123456789",
    	"Direction": 1,
    	"Status": 1,
    	"CallStartTimestamp": 1999,
    	"CallID": "123456789",
    	"CallApp": 2,
    	"NumberMarktype": "insurance",
    	"ReleaseCause": 1
         }
    }

After receiving the message, the head unit sends a response message to the HiCar app. The sample code is as follows:
    
    {
        "CallDataResp" : {
            "RespCode" : 100000
        }
    }
