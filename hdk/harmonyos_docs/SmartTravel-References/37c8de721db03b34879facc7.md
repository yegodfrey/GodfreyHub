# DMSDPCameraParam  
  
Name | Type | Description  
---|---|---  
*id | const char | Pointer to the camera ID character string.  
idLen | uint32_t | Length of the camera ID character string.  
width | uint32_t | Resolution width.  
height | uint32_t | Resolution height.  
fps | uint32_t | FPS configuration.  
dataFormat | uint32_t | Image format.
