# StartAdv  
  
Function  
---  
int (*StartAdv)(const void *context)  
Starts BLE advertising.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
*context | const void | The void* is used to represent the structure differences of different device parameters. Currently, the context parameter points to **BleAdvData**.  
  
**Return**

Type | Description  
---|---  
int | Operation result.
     * **0** : success
     * Other values: failure
