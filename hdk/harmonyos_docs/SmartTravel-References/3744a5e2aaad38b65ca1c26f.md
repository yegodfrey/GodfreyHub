# Dark/Light Mode  
  
#### Scenario Overview

If the vehicle sensor has the capability of detecting Dark/Light mode, the HiCar app can switch between the modes based on this capability.

After the head unit is powered on and started, it needs to call the corresponding API provided by the HiCar SDK to report whether Dark/Light mode detection is supported, as well as the current mode. When the mode changes, the latest mode is reported to the HiCar app.

#### Setting Dark/Light Mode During SDK Initialization

**Table 1** Key-value pairs of Dark/Light mode during initializationValue | Type | **Description**  
---|---|---  
DAY_NIGHT_MODE | String | Whether the vehicle can detect Dark/Light mode and the current mode:
     * **day** : Light mode
     * **night** : Dark mode
     * **notsupport** : The Dark/Light mode is not supported. This is the default value.
     * **pending** : The current mode cannot be determined, but the information can be dynamically sent to HiCar later.  
  
The following is an example of setting the control modes when initializing the HiCar SDK:
    
    CarConfig.Builder builder = **new** CarConfig.Builder();
    Map<String, String> config = **new** HashMap<String, String>();
    config.put(**"DAY_NIGHT_MODE"** ,  **"day"**);  
    builder.withInitialConfig(config);

When the head unit detects that Dark/Light mode changes, it needs to report the current mode to the HiCar app.

#### Data Type

501

#### API Version

1.0

#### API Definition

**Table 2** Dark/Light mode APIParameter | **Mandatory** | Type | **Description**  
---|---|---|---  
dayNightMode | Yes | string | Dark/Light mode:
     * **day** : Light mode
     * **night** : Dark mode  
  
#### API Examples

Example: The head unit reports Dark/Light mode to the HiCar app.
    
    Light mode:
    {
        "dayNightMode":"day"
    }
    Dark mode:
    {
        "dayNightMode":"night"
    }
