# onLoadAllAppInfo  
  
Method  
---  
void onLoadAllAppInfo(String deviceId, List<AppInfoBean> appInfoBeans)  
Callback method for all **AppInfo** data of the converged desktop.  
  
**Parameters**

Parameter Name | Parameter Type | Description  
---|---|---  
deviceId | String | **deviceId** of the peer device (mobile phone).  
appInfoBeans | List<AppInfoBean> | **AppInfo** of the converged desktop.
