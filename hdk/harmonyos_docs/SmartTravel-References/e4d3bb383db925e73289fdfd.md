# getLocationFreq  
  
Function  
---  
int getLocationFreq()  
Obtains the frequency of reporting GPS location data.  
  
**Return**

Type | Description  
---|---  
int | Reporting frequency:
     * **–1** : Failed to obtain the frequency.
     * A value ≥ 0: Actual reporting frequency.
