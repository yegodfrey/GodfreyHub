# Disconnect  
  
Function  
---  
int (*Disconnect)(const void *channelInfo)  
Closes the connection channel.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
*channelInfo | const void | Channel information. The void * is used to represent the data structure differences between different devices.
     * BLE driver: not supported currently.
     * BR driver: used for imperceptible reconnections of the BR channel. **channelInfo** points to the **BrChannelData** structure.
     * Wi-Fi driver: not supported currently.  
  
**Return**

Type | Description  
---|---  
int | Operation result.
     * **0** : success
     * Other values: failure
