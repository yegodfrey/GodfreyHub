# onAppInfoRemove  
  
Method  
---  
void onAppInfoRemove(String deviceId, List<AppInfoBean> appInfoBeans)  
Callback for removed **AppInfo** data (apps uninstalled from the mobile phone) of the converged desktop.  
  
**Parameters**

Parameter Name | Parameter Type | Description  
---|---|---  
deviceId | String | **deviceId** of the peer device (mobile phone).  
appInfoBeans | List<AppInfoBean> | **AppInfo** data list of apps that have been uninstalled.
