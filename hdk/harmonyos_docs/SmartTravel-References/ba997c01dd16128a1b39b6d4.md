# DMSDPGetAudioHandler  
  
Function  
---  
int32_t DMSDPGetAudioHandler(DMSDPAudioHandler* audioHandler)  
Obtains the audio (speaker and microphone) functions, and stores them in the **DMSDPAudioHandler** structure.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
*audioHandler | DMSDPAudioHandler | A set of audio device interface pointers.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : success
     * Negative value: failure
