# init  
  
Method  
---  
void init(Context context, CarConfig carConfig, HiCarInitCallback callback)  
Initializes the HiCar SDK.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
context | Context | Device context.  
carConfig | CarConfig | Head unit configuration, including the Bluetooth MAC address, size of the projection area, screen resolution, and physical screen size.  
callback | HiCarInitCallback | HiCar SDK initialization callback function. The definition is as follows: HiCarInitCallback void onInitSuccess(HiCarAdapter adapter); void onBinderDied(); void onInitFail(int errCode); The **onInitSuccess** method is used to trigger callback after service object initialization and return the instantiated object in the callback parameter. **void onInitFail(int errCode)** is triggered after the initialization has timed out for 30s. **errCode** indicates the returned error code. The **onBinderDied** method is used to trigger callback when a service exception occurs. For example, the service exits abnormally or is killed by another process. The upper-layer app can restart the service or clear the resources (by clearing the **HiCarAdapter** instantiation object) based on the service scenario requirements.
