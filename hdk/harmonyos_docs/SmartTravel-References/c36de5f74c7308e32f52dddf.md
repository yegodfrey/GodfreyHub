# DMSDPGetGPSHandler  
  
Function  
---  
int32_t DMSDPGetGPSHandler(DMSDPGPSHandler* gpsHandler)  
Obtains GPS related data, stored in the **DMSDPGPSHandler** structure.  
  
**Parameters**

**Name** | **Type** | **Description**  
---|---|---  
* gpsHandler | DMSDPGPSHandler | Functional method structure.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : success
     * Negative value: failure
