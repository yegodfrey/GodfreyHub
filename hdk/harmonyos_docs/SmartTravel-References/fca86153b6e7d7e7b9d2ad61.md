# initBtSocket  
  
Function  
---  
int32_t (*initBtSocket)(RfcommServerInfo serverInfo)  
Creates Bluetooth sockets based on **RfcommServerInfo** provided by the HiCar SDK, and processes data received from the Bluetooth sockets.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | Description  
---|---|---  
serverInfo | RfcommServerInfo | Server parameter required for setting up an RFCOMM Bluetooth socket connection.  
  
**Return**

Type | Description  
---|---  
int | Returned result:
     * **0** : success
     * Other values: failure
