# onAppInfoAdd

Method  
---  
void onAppInfoAdd(String deviceId, List<AppInfoBean> appInfoBeans)  
Callback method for new **AppInfo** data (newly installed apps on the mobile phone) of the converged desktop.  
  
**Parameters**

Parameter Name | Parameter Type | Description  
---|---|---  
deviceId | String | **deviceId** of the peer device (mobile phone).  
appInfoBeans | List<AppInfoBean> | **AppInfo** data list of newly installed apps.
