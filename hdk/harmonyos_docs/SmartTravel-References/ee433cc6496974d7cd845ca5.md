# Navigation Focus

#### Scenario Overview

By default, HiCar provides the navigation service. If the head unit also provides the native navigation service, conflicts may occur when they run at the same time. Therefore, the HiCar app and head unit need to negotiate about the navigation focus.

     * When the HiCar app starts navigation, it notifies the head unit that the navigation focus is **HICAR** , and the head unit needs to stop the native navigation service.
     * When the HiCar app stops navigation, it notifies the head unit that the navigation focus is **HICAR_STOP** , and the head unit processes the logic by itself.
     * When the head unit starts navigation, it notifies the HiCar app that the navigation focus is **NATIVE** , and the HiCar app needs to stop the navigation service.
     * When the head unit stops navigation, it notifies the HiCar app that the navigation focus is **NATIVE_STOP** , and the HiCar app processes the logic by itself.

#### Data Type

503

#### API Version

1.0

#### API Definition

**Table 1** Navigation Focus APIParameter | **Mandatory** | Type | **Description**  
---|---|---|---  
navFocus | Yes | string | Navigation Focus
     * **HICAR** : The navigation focus is switched to the navigation service provided by the HiCar app.
     * **HICAR_STOP** : The HiCar navigation app stops navigation and releases the navigation focus.
     * **NATIVE** : The navigation focus is switched to the native navigation service.
     * **NATIVE_STOP** : The original vehicle stops navigation and releases the navigation focus.  
  
#### API Examples

Example: The HiCar app requests navigation focus from the head unit.
    
    {
        "navFocus":"HICAR"
    }

Example: The HiCar app notifies the head unit that the HiCar app releases the navigation focus.
    
    {
        "navFocus":"HICAR_STOP"
    }

Example: The head unit requests navigation focus from the HiCar app.
    
    {
        "navFocus":"NATIVE"
    }

Example: The head unit notifies the HiCar app that the head unit releases the navigation focus.
    
    {
        "navFocus":"NATIVE_STOP"
    }
