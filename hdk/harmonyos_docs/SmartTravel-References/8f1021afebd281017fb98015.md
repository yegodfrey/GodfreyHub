# Overview

Return Type | Function Name  
---|---  
int32_t | HiCarInit Initializes the HiCar SDK.  
int32_t | HiCarRelease Deregisters the HiCar SDK.  
int32_t | HiCarRegisterListener Registers HiCar listeners for receiving HiCar device status changes, service changes, and HiCar data.  
int32_t | HiCarStartAdv Triggers HiCar to send advertising packets so that the HiCar phone can detect the head unit.  
int32_t | HiCarStopAdv Stops HiCar from sending advertising packets.  
int32_t | HiCarReconnect Triggers an imperceptible connection. The head unit reconnects to a previously connected phone without being perceived, when a Bluetooth pairing request is detected and the phone was not disconnected by the user.  
int32_t | HiCarGetPinCode Obtains the PIN. After sending the broadcast, the HMI app obtains the PIN and displays it on the in-vehicle screen so that the user can enter the PIN on the phone for authentication.  
int32_t | HiCarStartProjection Starts HiCar projection when the Display service is started.  
int32_t | HiCarStopProjection Stops HiCar projection when the Display service is stopped.  
int32_t | HiCarPauseProjection Pauses HiCar projection when the Display service is paused.  
void* | HiCarNewObject Creates a service object based on the type of the HiCar service object.  
int32_t | HiCarDeleteObject Destroys a service object to release memory.  
int32_t | HiCarPostEvent Sends an event to HiCar, such as a touchscreen event, key event, or voice wakeup event.  
int32_t | HiCarSendData Sends a type of data stream to HiCar, such as the head unit logo image.  
char* | HiCarGetSdkVersion Obtains the HiCar version number for subsequent SDK updates.  
int32_t | HiCarGetTrustDeviceList Obtains the list of devices that have been authenticated by the head unit.  
int32_t | HiCarDeleteTrustDevice Deletes a specified trusted device. After the device is deleted, it must be authenticated again.  
int32_t | HiCarDisconnectDevice Disconnects the head unit from a specified phone.  
int32_t | HiCarGetConnectionType Obtains the current HiCar connection mode.  
int32_t | HiCarStartBluetoothRecommend Starts RFCOMM listening on the interaction between the phone and the head unit, and recommends the use of HiCar once the interaction is complete.
