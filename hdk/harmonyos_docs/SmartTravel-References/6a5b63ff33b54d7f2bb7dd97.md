# registerBtSocketCallback  
  
Function  
---  
int registerBtSocketCallback(BtSocketDataCallback *callback)  
Obtains the data processing function from the HiCar SDK to process the data obtained from Bluetooth sockets.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | Description  
---|---|---  
*callback | BtSocketDataCallback | Callback function.  
  
**Return**

Type | Description  
---|---  
int | Returned result:
     * **0** : success
     * Other values: failure
