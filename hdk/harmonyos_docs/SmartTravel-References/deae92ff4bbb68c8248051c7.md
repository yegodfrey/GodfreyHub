# startReconnect  
  
Method  
---  
int startReconnect(String macAddress)  
int startReconnect(String macAddress, boolean isManualReconnect)  
Starts automatic connection.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | Description  
---|---|---  
macAddress | String | Bluetooth address of the device to be connected.  
isManualReconnect | boolean | Whether the reconnection is triggered manually:
     * **true** : manual reconnection
     * **false** : non-manual reconnection  
  
**Return**

Type | Description  
---|---  
int | Only the value **0** indicates that the API is called successfully. For details, please refer to [HiCarConst](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/hicar-const-0000000000030396).
