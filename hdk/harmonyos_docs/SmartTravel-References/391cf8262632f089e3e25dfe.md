# Constructor  
  
Constructor  
---  
CustomizedAudioAttributes(AudioAttributes aa, int focusGain, Map<String, String> map)  
Constructor based on **AudioAttributes**.  
  
**Parameters**

Parameter Name | Parameter Type | Parameter Description  
---|---|---  
aa | AudioAttributes | Audio attributes. For details, see Google's description of **AudioAttributes**.  
focusGain | int | Audio focus type. For details, see the audio focus parameters of Google **AudioManager**. Example: **1** : Permanent focus, such as music. **2** : Transient focus, such as the call, notification, alarm, and instant message app. **3** : Duck focus, such as navigation. **4** : Exclusive and transient focus.  
map | Map<String, String> | Extended parameter, which is used to pass other audio parameters.  
  
Constructor  
---  
CustomizedAudioAttributes(int streamType, int focusGain, Map<String, String> map)  
Constructor based on **StreamType**.  
  
**Parameters**

Parameter Name | Parameter Type | Parameter Description  
---|---|---  
streamType | int | Audio stream type. For details, see the audio stream parameters of **AudioManager**. Example: **0** : Voice call (such as VoIP call) **1** : Sonification sounds (for example, sound played when using the UI) **2** : Call ringtone (such as for calls and VoIP calls) **3** : Text to speech **4** : Alert tone (such as the alarm tone) **5** : Prompt tone **8** : Prompt tone during a call (such as busy tone and DTMF tone) **10** : Voice played by an accessibility feature (such as the screen reader)  
focusGain | int | Audio focus type. For details, see the audio focus parameters of Google **AudioManager**. Example: **1** : Permanent focus, such as music. **2** : Transient focus, such as the call, notification, alarm, and instant message app. **3** : Duck focus, such as navigation. **4** : Exclusive and transient focus.  
map | Map<String, String> | Extended parameter, which is used to pass other audio parameters.
