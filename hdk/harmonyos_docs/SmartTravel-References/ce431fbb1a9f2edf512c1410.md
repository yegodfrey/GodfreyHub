# updateVideoHeight  
  
Method  
---  
CarConfig updateVideoHeight(int videoHeight)  
Updates the height of the projection area.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
videoHeight | int | Height of the projection area, in pixels.  
  
**Return**

Type | Description  
---|---  
CarConfig | Vehicle configuration.
