# readSecureFile  
  
Function  
---  
byte[] readSecureFile(string fileName)  
The HiCar SDK uses this callback to read an authentication file. Authentication files are managed by the HMI app.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
fileName | string | Name of the authentication file.  
  
**Return**

Type | Description  
---|---  
byte[] | Byte array of the authentication file.
