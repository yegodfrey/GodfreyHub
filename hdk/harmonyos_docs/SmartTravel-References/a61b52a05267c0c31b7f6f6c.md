# HiCarReconnect  
  
Function  
---  
int32_t HiCarReconnect(const char *bluetoothMac, uint32_t realLen)  
Triggers a imperceptible connection. The head unit reconnects to a previously connected phone without being perceived, when a Bluetooth pairing request is detected and the phone was not disconnected by the user.  
  
**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
bluetoothMac | const char* | Bluetooth MAC address of a phone. Segments in the value are separated by colons (:), for example, AA:BB:CC:DD:EE.  
realLen | uint32_t | Length of the Bluetooth MAC address of a phone.  
  
**Return**

Type | Description  
---|---  
int32_t | Imperceptible connection result:
     * **0** : success
     * Other values: failure
