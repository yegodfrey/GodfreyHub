# Metadata Capabilities

#### Scenario Overview

After connecting to HiCar, the head unit can request open app metadata from the HiCar app for auxiliary display on the dashboard/head-up display (HUD).

When responding to a head unit request, the HiCar app returns the metadata types that can be opened based on user authorization. The head unit further obtains specific metadata based on the returned result.

Navigation metadata is not supported currently.

#### DataType

514

#### API Version

1.0

#### API Definition

**Table 1** Metadata capability APIParameter | Mandatory | Type | Description  
---|---|---|---  
RequestAAData | Yes | int | Request message, which is used by the head unit to request open app metadata from the HiCar app. The request message contains the app metadata type, which is indicated by the bit. Value **1** indicates that the metadata type is requested, and value **0** indicates that the metadata type is not requested. Specifically:
     * Bit 1: audio metadata
     * Bit 2: call metadata
     * Bit 3: navigation metadata (not supported currently)
     * Bit 4: calendar metadata
     * Bit 5: weather metadata
     * Bit 6: AI Tips metadata
     * Bit 7: IoT metadata
The head unit needs to convert binary data into int data based on the data usage scenario before reporting the data, for example:
     * Binary number 0111 should be converted to 7, indicating that the audio, call, and navigation metadata is requested.
     * Binary number 0101 should be converted to 5, indicating that the audio and navigation metadata is requested.
     * Binary number 01111000 should be converted to 120, indicating that the calendar, weather, AI Tips, and IoT metadata is requested.  
RequestCaller | Yes | string | **modelId** of the current vehicle model.  
  
**Table 2** Metadata capability response dataParameter | Mandatory | Type | Description  
---|---|---|---  
ResponseAAData | Yes | object | Response data. For details, please refer to Table 3.  
  
**Table 3** ResponseAADataParameter | Mandatory | Type | Description  
---|---|---|---  
MEDIA | Subject to the request | boolean | Audio metadata:
     * **true** : Request for obtaining audio metadata is allowed.
     * **false** : Request for obtaining audio metadata is rejected.  
CALL | Subject to the request | boolean | Call metadata:
     * **true** : Request for obtaining call metadata is allowed.
     * **false** : Request for obtaining call metadata is rejected.  
NAVIGATION | Subject to the request | boolean | Navigation metadata (not supported currently).
     * **true** : Request for obtaining navigation metadata is allowed.
     * **false** : Request for obtaining navigation metadata is rejected.  
CALENDAR | Subject to the request | boolean | Calendar metadata:
     * **true** : Request for obtaining calendar metadata is allowed.
     * **false** : Request for obtaining calendar metadata is rejected.  
WEATHER | Subject to the request | boolean | Weather metadata:
     * **true** : Request for obtaining weather metadata is allowed.
     * **false** : Request for obtaining weather metadata is rejected.  
INTELLIGENT | Subject to the request | boolean | AI Tips metadata:
     * **true** : Request for obtaining AI Tips metadata is allowed.
     * **false** : Request for obtaining AI Tips metadata is rejected.  
IOT | Subject to the request | boolean | IoT metadata:
     * **true** : Request for obtaining IoT metadata is allowed.
     * **false** : Request for obtaining IoT metadata is rejected.  
  
#### API Examples

The head unit sends a request to the HiCar app to obtain metadata. The following is sample code where the head unit requests audio metadata, call metadata, and navigation metadata from the app:
    
    {
        "RequestAAData" : 7,
        "RequestCaller" : "00040900"
    }

The HiCar app responds to the head unit's metadata request depending on the user authorization. The following is sample code where the HiCar app only opens audio and call metadata to the head unit:
    
    {
        "ResponseAAData":{
            "MEDIA":true,
            "CALL":true,
            "NAVIGATION":false
        }
    }
