# GPSSensor  
  
Function  
---  
void (*GPSSensor)(char *sensor, int32_t len)  
Reports vehicle sensor data, including the acceleration and gyroscope data. The reporting starts when **RegisterGpsDataCallBack** is called and continues until **UnRegisterGpsDataCallBack** is called.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
*sensor | char | Sensor data. Example: $GPACC,<1>,<2>,<3>,<4>,<5>,<6>,<7>,<8>*<10>  
len | int32_t | Data length.
