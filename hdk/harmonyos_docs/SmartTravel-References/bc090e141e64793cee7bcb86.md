# WifiAbilityParam  
  
Name | Type | Description  
---|---|---  
isSupportGO | int | Indicates whether GO is supported.
     * **1** : supported
     * **0** : not supported  
isSupportGC | int | Indicates whether GC is supported.
     * **1** : supported
     * **0** : not supported  
isSupportGband | int | Indicates whether the 2.4 GHz frequency band is supported.
     * **1** : supported
     * **0** : not supported  
isSupportAband | int | Indicates whether the 5 GHz frequency band is supported.
     * **1** : supported
     * **0** : not supported  
isSupportRSDB | int | Indicates whether RSDB is supported.
     * **1** : supported
     * **0** : not supported  
currStaFreq | in | Current working frequency.  
selfGcMac[STR_MAC_ADDR_LEN + 1] | char | MAC address of the head unit when functioning as the GC.  
selfBssid[STR_MAC_ADDR_LEN + 1] | char | BSSID of the head unit when functioning as the GO.  
channelData | [Channel](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/channel-0000001052690857) | Information about the supported channels.  
countryCode[COUNTRY_CODE_LEN] | char | Country or region code.
