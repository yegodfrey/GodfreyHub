# Brand Name

After the head unit is powered on and started, call an API provided by the HiCar SDK to report the vehicle brand information.

**Table 1** Set the brand name during initializationValue | Type | **Description**  
---|---|---  
CAR_BRAND | String | Vehicle brand, which is displayed below the vehicle logo icon in the device discovery dialog box on the phone.
     * When the vehicle brand information can be obtained, set this parameter to the actual vehicle brand.
     * If the head unit cannot obtain the vehicle brand information, set this parameter to **notsupport** , which is the default value.  
  
The following is an example of setting the control modes when initializing the HiCar SDK:
    
    CarConfig.Builder builder = **new** CarConfig.Builder();
    Map<String, String> config = **new** HashMap<String, String>();
    config.put(**"CAR_BRAND"** ,  **"XXX"**);   
    builder.withInitialConfig(config);
