# CarDisplayCapability  
  
Name | Type | Description  
---|---|---  
codecs | int32_t | Video encoding format.
     * **1** : H264 (default value)
     * **2** : H265  
fps | int32_t | Frame rate, which can be 30 fps (default value) or 60 fps.  
gop | int32_t | I-frame interval (number of P-frames that occur between I-frames).  
bitrate | int32_t | Bit rate. The value ranges from 1 to 10 Mbit/s. The default value is 5 Mbit/s.  
minBitrate | int32_t | Minimum video stream bit rate.  
maxBitrate | int32_t | Maximum video stream bit rate.  
dpi | int32_t | DPI value of the virtual device.  
profile | int32_t | Video stream profile.  
level | int32_t | Video stream level.  
screenWidth | int32_t | Physical width of the in-vehicle screen, in millimeters.  
screenHeight | int32_t | Physical height of the in-vehicle screen, in millimeters.  
width | int32_t | Width of the projection area on the in-vehicle screen, in pixels.  
height | int32_t | Height of the projection area on the in-vehicle screen, in pixels.
