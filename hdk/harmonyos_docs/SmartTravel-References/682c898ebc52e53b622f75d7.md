# SetAudioParameter  
  
Function  
---  
int32_t (*SetAudioParameter)(const char* id, uint32_t idLen, int32_t sessionId, uint32_t streamType, const DMSDPProfiles* profiles)  
Sets speaker parameters.  
  
**Parameters**

**Name** | **Type** | **Description**  
---|---|---  
*id | const char* | Speaker ID.  
idLen | uint32_t | Length of the speaker ID.  
sessionId | int32_t | Session ID.  
streamType | uint32_t | Audio type. For details, please refer to [DMSDPAudioStreamType](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-audio-stream-type-0000001052570507).  
*profiles | const [DMSDPProfiles](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-profiles-0000001052490527) | Profiles.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : success
     * Negative value: failure
