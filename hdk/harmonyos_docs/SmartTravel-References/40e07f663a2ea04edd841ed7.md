# OpenAudioRecord  
  
Function  
---  
int32_t (*OpenAudioRecord)(const char* id, uint32_t idLen, int32_t sessionId, int32_t inputSource, const DMSDPProfiles* profiles)  
Initializes the microphone.  
  
**Name** | **Type** | **Description**  
---|---|---  
*id | const char | Microphone ID.  
idLen | uint32_t | Length of the microphone ID.  
sessionId | int32_t | Session ID.  
inputSource | int32_t | Data source. For details, please refer to DMSDPAudioSource.  
* profiles | const [DMSDPProfiles](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-profiles-0000001052490527) | Profiles.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : success
     * Negative value: failure
