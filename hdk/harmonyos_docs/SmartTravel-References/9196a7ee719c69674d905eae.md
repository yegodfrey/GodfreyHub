# getCarDataReportFreq  
  
Function  
---  
CarDataReportFreq getCarDataReportFreq()  
Obtains vehicle body data.
     1. Each time the HiCar SDK registers a listener with the HMI app, the app registers the data reporting frequency with the SDK.
     2. The unit is Hz. For example, if **locationFreq** is set to **1** , it indicates 1 Hz.
     3. The expected reporting frequency is 1 Hz for GPS location data, 10 Hz for vehicle body data, and 40 Hz for sensor data. Set the frequency based on the actual conditions.  
  
**Return**

Type | Description  
---|---  
CarDataReportFreq | Vehicle body data reporting frequency.
