# Change History  
  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230817210317.24640763240893439791896997315188:50001231000000:2800:F132FE2030BC83CED8329E2AACB6AB36EB4FC4AC2EF984D30B69B3D439BCFB4A.png?needInitFileName=true?needInitFileName=true)

You must pay attention to the following notes in the change history:

     * **Modified** : Modification or deletion of existing open capabilities, which requires your special attention. If the modification is not adapted, the existing features will be affected. 
     * **Added** : New open capabilities. You can adapt to the new capabilities as required. If the adaptation is not performed, the existing features are not affected. 

Date | Version | Description  
---|---|---  
2022-03-11 | 1.8 | New:
     1. Added the API for determining whether to support virtual calls. This API is required when the head unit needs to process carrier calls through the Bluetooth channel. For details, please refer to [Virtual Call](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/virtual-modem-0000001194963766).   
2021-09-10 | 1.7 | Added:
     1. Added the APIs for reporting the light intensity, vehicle speed, acceleration, and gyroscope data. For details, please refer to [Vehicle Sensor (Speed/Acceleration)](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/vehicle-sensors-0000001199289937). 
Modified:
     1. Deleted the **onKeyUp** and **onKeyDown** functions of **HiSightSurfaceView**.   
2021-05-24 | 1.6 | Modified:
     1. Added the device connection failure and advertising sending timeout events to the connection event callback. For details, please refer to [onDeviceChange](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/on-device-change-0000001058057723). 
Added:
     1. Added the API for querying whether the head unit microphone is available. For details, please refer to [getCarAudioRecordingStatus (Beta)](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/get-car-audio-recording-status-0000001140488731). 
     2. Added the notification for manual disconnection of HiCar. For details, please refer to [Notification for User-initiated Disconnection from the Head Unit](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/disconnection-notification-0000001199330041). 
     3. Added support for turning on or off the screen with voice commands. For details, please refer to [Turning the Screen On/Off](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/screen-on-off-0000001199289939). 
     4. Added support for using voice commands to take photos using the in-vehicle camera. For details, please refer to [Photographing with the Vehicle-mounted Camera](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/vehicle-mounted-camera-0000001153450250).
