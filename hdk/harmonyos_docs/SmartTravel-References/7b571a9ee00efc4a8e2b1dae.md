# getCodecType (Beta)  
  
Method  
---  
int getCodecType()  
Obtains the video codec type for projection.  
  
**Return**

Type | Description  
---|---  
int | Video codec type for projection:
     * **1** : H.264 (default value)
     * **2** : H265
