# updateFps (Beta)  
  
Method  
---  
CarConfig updateFps(int fps)  
Updates the number of transmitted frames per second of the head unit .  
  
**Parameters**

**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
fps | int | Frame per second. The value range is 20–60.  
  
**Return**

Type | Description  
---|---  
CarConfig | Vehicle configuration.
