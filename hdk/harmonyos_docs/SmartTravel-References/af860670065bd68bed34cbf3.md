# getDrivingFreq  
  
Function  
---  
int getDrivingFreq()  
Obtains the frequency of reporting vehicle body data.  
  
**Return**

Type | Description  
---|---  
int | Reporting frequency:
     * **–1** : Failed to obtain the frequency.
     * A value ≥ 0: Actual reporting frequency.
