# CarConnectAllowType  
  
Enumerator | Description  
---|---  
HICAR_CONNECT_INVALID=0 | The head unit does not support any connection mode.  
HICAR_CONNECT_ONLY_ADVERTISE=1 | The head unit supports only Wi-Fi connectivity through BLE advertising.  
HICAR_CONNECT_ONLY_USB=2 | The head unit supports only USB wired connections.  
HICAR_CONNECT_ADVERTISE_USB=3 | The head unit supports Wi-Fi connectivity through BLE advertising, as well as USB connections.  
HICAR_CONNECT_ONLY_QRCODE=4 | The head unit supports only Wi-Fi connectivity through QR code scanning.  
HICAR_CONNECT_QRCODE_USB=6 | The head unit supports Wi-Fi connectivity through QR code scanning, as well as USB connections.
