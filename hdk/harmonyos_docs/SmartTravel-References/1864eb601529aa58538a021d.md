# isSupportCarGpsSensorAbility  
  
Function  
---  
boolean isSupportCarGpsSensorAbility()  
Checks whether the vehicle sensor data (acceleration, gyroscope, and data time) can be obtained.  
  
**Return**

Type | Description  
---|---  
boolean | Returned result:
     * **true** : success
     * **false** : failure
