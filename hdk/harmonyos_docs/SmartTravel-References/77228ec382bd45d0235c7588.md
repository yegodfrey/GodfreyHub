# Builder  
  
Constructor  
---  
CarConfig(Builder builder)  
Defines the configuration information about the head unit. The constructor is a private class and is not used to construct this class.  
  
**Parameters**

Parameter Name | Parameter Type | Description  
---|---|---  
builder | Builder | Inner class of **CarConfig** , which is used to construct this class.
