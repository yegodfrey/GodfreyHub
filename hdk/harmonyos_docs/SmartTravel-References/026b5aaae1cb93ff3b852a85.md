# HiCarStopAdv  
  
Function  
---  
int32_t HiCarStopAdv()  
Stops HiCar from sending advertising packets. When the user touches the home button to return to the native HMI screen, this API must be called to stop the advertising.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : success
     * Other values: failure
