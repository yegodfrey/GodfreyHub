# Release  
  
Function  
---  
void (*Release)(int32_t type, void* ptr,uint32_t num)  
Releases resources.  
  
**Parameters**

**Name** | **Type** | Parameter desc  
---|---|---  
type | int32_t | Type of resource to be released. For details, please refer to [DMSDPCameraReleaseType](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-camera-release-type-0000001059006878#EN-US_TOPIC_0000001059006878). Corresponds to **QueryCameraCapability**.  
*ptr | void | Corresponds to **DMSDPCameraCapabilities* capabilities**.  
num | uint32_t | Quantity.  
  
**Return**

Type | Description  
---|---  
char* | Character string of the camera attribute set.
