# SendData

Function  
---  
int (*SendData)(const unsigned char *data, int dataLen, const void *channelInfo)  
Sends data.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
*data, | const unsigned char | Number of bytes to be sent.  
dataLen | int | Length of the bytes to be sent.  
*channelInfo | const void | Channel model.  
  
**Return**

Type | Description  
---|---  
int | Operation result.
     * **0** : success
     * Other values: failure
