# UpdateServiceStatus  
  
Function  
---  
int32_t (*UpdateServiceStatus)(const char *id, uint32_t idLen, const DMSDPServiceStatus status)  
Notifies the HiCar SDK of the status update of the virtual device service, such as device activation/deactivation and insertion/removal.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
*id | char | ID of the virtual device service, such as **speaker1**.  
idLen | uint32_t | Length of the virtual device service ID.  
status | [DMSDPServiceStatus](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-service-status-0000001059358436#EN-US_TOPIC_0000001059358436) | Type of the reported status, such as activated, deactivated, inserted, or removed.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
