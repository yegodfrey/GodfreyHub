# HiCarDisconnectDevice  
  
Function  
---  
int32_t HiCarDisconnectDevice(const uint8_t *phoneId, uint32_t idLen)  
Disconnects from the specified phone.  
  
**Name** | **Type** | **Description**  
---|---|---  
phoneId | uint8_t* | Unique phone identifier.  
idLen | uint32_t | Length of the phone ID, which contains a maximum of 128 characters.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : success
     * Other values: failure
