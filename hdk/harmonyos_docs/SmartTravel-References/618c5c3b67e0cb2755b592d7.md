# DMSDPExtendInfo  
  
Name | Type | Description  
---|---|---  
*key | char | Keyword of a customized extended field. The keyword is an enumerated string. The options are as follows: **CAMERA_LOCATION** : camera location. **CAMERA_DESC** : user-defined camera description.  
keyLen | uint32_t | Length of the keyword of a customized extended field.  
*value | char | Value of the keyword of a customized extended field. When **key** is set to **CAMERA_LOCATION** , the value of this parameter is an enumerated character string. The options are as follows: **CAR_FRONT** : front of the vehicle. **CAR_TAIL** : rear of the vehicle. **CAR_LEFT** : left side of the vehicle. **CAR_RIGHT** : right side of the vehicle. **CAR_INSIDE** : inside the vehicle. **CAR_DRIVER** : driver's seat. **CAR_CODRIVER** : front left seat. **CAR_REARSEAT_LEFT** : rear left seat. **CAR_REARSEAT_RIGHT** : rear right seat. When **key** is set to **CAMERA_DESC** , the value of this parameter is a custom description that contains no more than 256 characters.  
valueLen | uint32_t | Length of the value corresponding to the extended field keyword.
