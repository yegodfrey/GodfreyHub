# Brand Name

After the head unit is powered on and started, call an API provided by the HiCar SDK to report the vehicle brand information.

**Table 1** Set the brand name during initializationParameter | **Description**  
---|---  
CarConfig.CarDeviceInfo.carBrand[64] | Vehicle brand name.  
CarConfig.CarDeviceInfo.carBrandLen | Length of the vehicle brand name.  
  
The following is an example of setting the control modes when initializing the HiCar SDK:
    
    CarConfig config;
    ......
    /* Vehicle brand information */
    memset_s((void*)&(config.deviceInfo.carBrand[0]), CAR_BRAND_MAX_LEN, 0, CAR_BRAND_MAX_LEN);
    memcpy_s((void*)&(config.deviceInfo.carBrand[0]), CAR_BRAND_MAX_LEN, "HICAR", strlen("HICAR"));
    config.deviceInfo.carBrandLen = strlen("HICAR");
    ......
    int retCode = HiCarInit(&config);
