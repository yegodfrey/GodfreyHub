# CarConnectionType  
  
Enumerator | Description  
---|---  
HICAR_CONNECTION_UNKNOWN=0 | The connection mode between the head unit and the phone is unknown.  
HICAR_CONNECTION_WIFI=3 | The connection mode between the head unit and the phone is Wi-Fi.  
HICAR_CONNECTION_USB=6 | The connection mode between the head unit and the phone is USB.
