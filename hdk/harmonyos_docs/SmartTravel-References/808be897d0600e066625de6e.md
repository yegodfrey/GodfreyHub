# unRegisterCarDataListener  
  
Function  
---  
boolean unRegisterCarDataListener(GpsDataCallBack gpsDataCallBack)  
Unsubscribes from GPS data of the head unit.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
gpsDataCallBack | GpsDataCallBack | GPS data callback.  
  
**Return**

Type | Description  
---|---  
boolean | Unsubscription result:
     * **true** : success
     * **false** : failure
