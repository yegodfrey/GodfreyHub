# CarEventType  
  
Enumerator | Description  
---|---  
HICAR_EVENT_REMOTE_CTRL=1 | Touchscreen event. When sent using **HiCarPostEvent** , the content is in the **HwRemoteCtrlEvent** structure.  
HICAR_EVENT_VOICE_WAKEUP | Voice wakeup event. When sent via **HiCarPostEvent** , the content is the wakeup phrase in JSON format.  
HICAR_EVENT_REQUEST_IDRFRAME | Request I-frames from the phone. When sent via **HiCarPostEvent** , the content can be set to NULL and the size can be set to **0**.  
HICAR_EVENT_LOG_SECTION_CHANGE | Notifies the head unit of the change in the writable status of the log area. When sent via **HiCarPostEvent** , if the carried content is **1** , the log area is writable; if the content is **0** , the log area is unwritable.
