# GetGPSDataReportFreq  
  
Function  
---  
int32_t (*GetGPSDataReportFreq)( int32_t *locationFreq, int32_t *drivingFreq, int32_t *sensorFreq)  
Obtains the GPS data reporting frequency, in Hz. For example, if **locationFreq** is set to 1, the frequency is 1 Hz. The expected reporting frequency is 1 Hz for location, 10 Hz for driving, and 40 Hz for sensor.  
  
**Parameters**

**Name** | **Type** | **Description**  
---|---|---  
locationFreq | int32_t | GPS data reporting frequency, in Hz.  
drivingFreq | int32_t | Vehicle body data reporting frequency, in Hz.  
sensorFreq | int32_t | Sensor data reporting frequency, in Hz.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : success
     * Negative value: failure
