# readStreamBufferCustom  
  
Function  
---  
int readStreamBufferCustom(int sessionId, int length)  
Callback for the HiCar SDK to obtain PCM data from the HMI app on the head unit, if the recording is successful on the head unit.  
  
**Parameters**

Parameter Name | Parameter Type | Description  
---|---|---  
sessionId | int | Recording ID.  
length | int | Length of the PCM data to be transmitted.  
  
**Return**

Type | Description  
---|---  
byte[] | PCM data to be returned by the HMI app on the head unit.
