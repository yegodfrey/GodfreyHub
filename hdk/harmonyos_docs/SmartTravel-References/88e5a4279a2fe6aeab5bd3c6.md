# updateCarConfig  
  
Method  
---  
int updateCarConfig(CarConfig carConfig)  
Updates the head unit configuration.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
carConfig | CarConfig | Head unit configuration, including the Bluetooth MAC address, size of the projection area, screen resolution, and physical screen size.  
  
**Return**

Type | Description  
---|---  
int | Only the value **0** indicates that the API is called successfully. For details, please refer to [HiCarConst](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/hicar-const-0000000000030396).
