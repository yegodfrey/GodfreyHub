# updateVideoWidth  
  
Method  
---  
CarConfig updateVideoWidth(int videoWidth)  
Updates the width of the projection area.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
videoWidth | int | Width of the projection area, in pixels.  
  
**Return**

Type | Description  
---|---  
CarConfig | Vehicle configuration.
