# updateSupportReconnect  
  
Method  
---  
CarConfig updateSupportReconnect(boolean supportReconnect)  
Updates whether the automatic reconnection is supported.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
supportReconnect | boolean | Indicates whether the automatic connection is supported.  
  
**Return**

Type | Description  
---|---  
CarConfig | Vehicle configuration.
