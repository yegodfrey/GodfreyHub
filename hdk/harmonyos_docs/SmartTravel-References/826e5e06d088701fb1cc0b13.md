# WriteSecureFile  
  
Function  
---  
int32_t (*WriteSecureFile)(const char *filename, uint32_t offset, uint8_t *buf, uint32_t len)  
Writes data to the authentication file.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
*filename | char | File name.  
offset | uint32_t | Offset of the file to be written.  
*buf | uint8_t | Buffer to be read.  
len | uint32_t | Buffer size.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : success
     * **1** : failure
