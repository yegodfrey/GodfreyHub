# CloseAudioRecord  
  
Function  
---  
int32_t (*CloseAudioRecord)(const char* id, uint32_t idLen, int32_t sessionId)  
Releases an audio recording device.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
*id | const char | Microphone ID.  
idLen | uint32_t | Length of the microphone ID.  
sessionId | int32_t | Session ID.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : success
     * Negative value: failure
