# ServiceUuidRelatedSessionId  
  
Name | Type | Description  
---|---|---  
serviceUuid[BT_SERVICE_UUID_LEN + 1] | char | Classic Bluetooth service UUID.  
sessionId | int | Session ID. The BR channel can use a service UUID to establish a connection or use a port to establish an insecure RFCOMM connection. Nearby uses the session ID to identify the connection session.
