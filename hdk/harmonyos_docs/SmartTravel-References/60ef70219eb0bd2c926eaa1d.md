# getCodecConfigureFlag (Beta)  
  
Method  
---  
int getCodecConfigureFlag()  
Obtains the customized parameters of the projection decoder.  
  
**Return**

Type | Description  
---|---  
int | Customized parameter of the projection decoder. The default value is **0** , indicating that no customization is required.
