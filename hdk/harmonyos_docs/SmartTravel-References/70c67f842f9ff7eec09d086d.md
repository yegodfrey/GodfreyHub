# isRemoteSupport  
  
Method  
---  
boolean isRemoteSupport()  
Checks whether the peer device (mobile phone) supports the converged desktop capability.  
  
**Return**

Type | Description  
---|---  
boolean | Whether the peer device (mobile phone) supports the converged desktop capability:
     * **true** : yes
     * **false** : no
