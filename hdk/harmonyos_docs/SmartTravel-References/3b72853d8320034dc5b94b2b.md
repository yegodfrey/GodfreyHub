# connectGpsService  
  
Function  
---  
void connectGpsService(Context context, ServiceConnectCallback callback)  
Binds with the GPS data collection service. After the binding is successful, call the **onServiceConnected** method of **ServiceConnectCallback**. If the service is disconnected abnormally, call the **onServiceDisconnected** method.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
context | Context. | Context  
callback | ServiceConnectCallback | Callback function when the binding is successful or the connection is disconnected.
