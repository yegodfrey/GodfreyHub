# Driving State

#### Scenario Overview

The head unit needs to report the driving state to the HiCar app so that the HiCar app can implement functions and services related to driving safety.

Driving state:

     * Driving mode: The vehicle is put into the D (Drive), R (Reverse), or N (Neutral) gear.
     * Parking mode: An automatic transmission vehicle is put into the P (Park) gear, or a manual transmission vehicle is put into the N gear and the handbrake is pulled up.

After the head unit is connected to the phone, the head unit needs to proactively report the current driving status to the HiCar app and update any status changes in a timely manner. After receiving the driving status information reported by the head unit, the HiCar app responds to the message to prevent failure in obtaining driving status information caused by transmission issues.

If the head unit does not receive a response message from the HiCar app after sending the driving mode information, the head unit needs to resend the driving mode information for three times at an interval of 1s. If the head unit receives any response message from the HiCar app during the resending, the reporting is successful. If no response message is received after three resends, the transmission link may be faulty. In this case, the head unit needs to record the exception information.

#### Data Type

506

#### API Version

1.0

#### API Definition

**Table 1** Driving Status APIParameter | **Mandatory** | Type | **Description**  
---|---|---|---  
drivingMode | No | int | Vehicle driving status:
     * **-1** : The vehicle driving state cannot be reported.
     * **0** : Driving.
     * **1** : Parking.
This state does not need to be reported when the driving status hasn't changed.  
errorCode | Yes | int | Result code. For details, see [Result Codes](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/errorcode-0000001153460180#EN-US_TOPIC_0000001153460180).  
  
#### API Examples

Example: The head unit reports the driving state to the HiCar app.
    
    {
        "drivingMode":0
    }

Example: The HiCar app sends a response message to the head unit.
    
    Success:
    {
        "errorCode":100000
    }
    Failure (due to invalid parameter settings):
    {
        "errorCode":100001
    }
