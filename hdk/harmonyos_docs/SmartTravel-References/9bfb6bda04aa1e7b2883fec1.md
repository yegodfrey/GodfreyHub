# onInitSuccess  
  
Function  
---  
void onInitSuccess(HiCarAdapter adapter)  
Indicates that the initialization is successful. This callback is triggered after the object is instantiated.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
adapter | HiCarAdapter | **HiCarAdapter** object for instantiation.
