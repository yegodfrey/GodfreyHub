# Overview  
  
Name | Description  
---|---  
[HiCarEvent](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/hicar-event-0000001052556437) | Type of the event reported by HiCar to the head unit.  
[CarDrivingPosition](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/car-driving-position-0000001051476408) | Position of the driver's seat in the vehicle.  
[CarObjectType](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/car-object-type-0000001051795144) | HiCar object type, for example, reverse control object.  
[CarEventType](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/car-event-type-0000001052595144) | Head unit event type, which is used for the **HiCarPostEvent** API.  
[CarDataType](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/car-data-type-0000001052955157) | Head unit data type, which is used for the **HiCarSendData** API.  
[CarConnectAllowType](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/car-connect-allow-type-0000001052795163) | Connection mode supported by the head unit.  
[CarConnectionType](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/car-connection-type-0000001053622137) | Current connection mode of HiCar, which can be USB or Wi-Fi.  
[CarDeviceType](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/car-device-type-0000001053862159) | Type of the head unit.  
[CarConnectionStatus](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/car-connection-status-0000001053502171) | Status of the connection between the head unit and the phone, which can be connected or disconnected.
