# UpdateConfig  
  
Function  
---  
int32_t (*UpdateConfig)(const char* id, uint32_t idLen, int32_t key, char* value, uint32_t valLen)  
Updates the settings of a specified camera. The southbound API returns the address of the API implementation function.  
  
**Parameters**

**Parameter name** | **Parameter type** | Parameter desc  
---|---|---  
*id | const char | Camera ID.  
idLen | uint32_t | Length of the camera ID.  
key | int32_t | Parameter type. For details, please refer to [DSMDPCameraConfigKey](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-camera-config-key-0000001051491812).  
*value | char | Parameter string.  
valLen | uint32_t | Length.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : Camera settings are updated successfully.
     * Other value: Camera settings failed to be updated.
