# HwRemoteCtrlHeader  
  
Name | Type | Description  
---|---|---  
version | uint16_t | Version number.  
dFlag | uint16_t | Direction in which the event is sent. This field is set to **DIRECTION_FROM_SINK** for messages sent from the head unit to the phone.  
wFlag | uint16_t | Window type. Set this parameter to **0** for a single window.  
wr1Flag | uint16_t | Reserved field. Set it to **0**.  
wr2Flag | uint16_t | Reserved field. Set it to **0**.  
rFlag | uint16_t | Reserved field. Set it to **0**.  
inputCategory | uint16_t | Input type. The value can be **0**.  
len | uint16_t | Length of the entire TCP payload in the unit of eight bits.  
sessionId | uint8_t | Reserved field. Set it to **0**.  
reserveData | uint8_t | Reserved field. Set it to **0**.  
windowsId | uint8_t | Reserved field. Set it to **0**.  
windowsStat | uint8_t | Reserved field. Set it to **0**.  
windowsReserved1 | uint8_t | Reserved field. Set it to **0**.  
windowsReserved2 | uint8_t | Reserved field. Set it to **0**.
