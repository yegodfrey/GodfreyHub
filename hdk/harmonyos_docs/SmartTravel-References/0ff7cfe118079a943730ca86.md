# Shared Internet Access

#### Scenario Overview

After a HiCar connection is established between the head unit and the phone, the head unit can request to share the Internet access provided by the phone. The process can be briefly described as follows:

     1. The head unit sends an Internet access sharing request to the HiCar app through the HiCar SDK.
     2. The HiCar app performs authorization based on how shared Internet access has been configured by the user.
     3. The procedure will proceed only if the sharing is allowed. If otherwise, the request will be rejected, and the procedure ends.
     4. The HiCar app sends the shared Internet access configuration information to the head unit.
     5. After receiving the configuration information, the HiCar app starts Internet access sharing.
     6. The sharing can be ended in either of the following ways:
        1. By the head unit: The head unit sends a stop message, and the HiCar app responds to the message.
        2. By the user: The HiCar app sends a stop message (as initiated by the user), and the head unit responds to the message.

#### Data Type

511

#### API Version

1.0

#### API Definition

#### [h2]Internet Sharing Request

**Table 1** Internet sharing request**Parameter** | **Mandatory** | **Type** | **Description**  
---|---|---|---  
service | Yes | string | Service type. The value is **net** for the current service.  
subService | Yes | string | Subservice type. The value is **internetShare** for the current service.  
command | Yes | int | Instructions:
     * **0** : The head unit sends an Internet sharing request to the HiCar app.
     * **1** : The HiCar app sends a request to the head unit to cancel Internet sharing.  
data | Yes | object | Parameter. For details, see Table 2.  
  
**Table 2** data**Parameter** | **Mandatory** | **Type** | **Description**  
---|---|---|---  
enable | Yes | int | Indicates to enable the shared Internet access or not:
     * **0** : Disable.
     * **1** : Enable.  
  
#### [h2]Responses to the Internet Sharing Request

**Table 3** Responses to the Internet sharing request**Parameter** | **Mandatory** | **Type** | **Description**  
---|---|---|---  
service | Yes | string | Service type. The value is **net** for the current service.  
subService | Yes | string | Subservice type. The value is **internetShare** for the current service.  
command | Yes | int | Instructions:
     * **0** : The head unit sends an Internet sharing request to the HiCar app.
     * **1** : The HiCar app sends a request to the head unit to cancel Internet sharing.  
errorCode | Yes | int | Result code. For details, see [Result Codes](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/errorcode-0000001153460180#EN-US_TOPIC_0000001153460180).  
data | No | object | Parameter. For details, see Table 4.  
  
**Table 4** data**Parameter** | **Mandatory** | **Type** | **Description**  
---|---|---|---  
gateway | No | string | Gateway address for shared Internet access, for example, "192.168.1.100".  
dns | No | string | Shared Internet address, for example, "192.168.1.100".  
  
#### API Examples

Example: The head unit sends an Internet sharing request to the HiCar app.
    
    {
        "service":"net",
        "subService":"internetShare",
        "command":0,
        "data":{
            "enable":1
        }
    }

Example: The HiCar app returns the request result to the head unit (if the user authorizes the head unit to share the Internet access).
    
    {
        "service":"net",
        "subService":"internetShare",
        "command":0,
        "errorCode":100000,
        "data":{
            "gateway":"192.168.1.100",
            "dns":"192.168.1.100"
        }
    }

Example: The HiCar app returns the request result to the head unit (if the user does not authorize the head unit to share the Internet access).
    
    {
        "service":"net",
        "subService":"internetShare",
        "command":0,
        "errorCode":100002
    }

Example: The head unit sends a request to the HiCar app to cancel Internet sharing.
    
    {
        "service":"net",
        "subService":"internetShare",
        "command":0,
        "data":{
            "enable":0
        }
    }

Example: The HiCar app sends a response to the head unit to cancel Internet sharing.
    
    {
        "service":"net",
        "subService":"internetShare",
        "command":0,
        "errorCode":100000
    }

Example: The HiCar app notifies the user of disabling the Internet sharing function of the head unit on the phone.
    
    {
        "service":"net",
        "subService":"internetShare",
        "command":1,
        "data":{
            "enable":0
        }
    }

Example: The head unit sends a response to the HiCar app, indicating that the user has disabled the Internet sharing function on the head unit.
    
    {
        "service":"net",
        "subService":"internetShare",
        "command":1,
        "errorCode":100000
    }
