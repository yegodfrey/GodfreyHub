# HiCarEvent  
  
Enumerator | Description  
---|---  
HICAR_DEVICE_CONNECTED=101 | Connected.  
HICAR_DEVICE_CONNECTING=102 | Connecting.  
HICAR_DEVICE_DISCONNECTED=103 | Disconnected.  
HICAR_DEVICE_DISCONNECTING=104 | Disconnecting.  
HICAR_DEVICE_NO_DATA=105 | -  
HICAR_DEVICE_DETECT_DISCONNECT=106 | When the device detects a disconnection, the HMI app returns to the native IVI system screen.  
HICAR_DEVICE_NET_UNSTABLE_MILD=107 | -  
HICAR_DEVICE_TCP_CONNECTED=108 | -  
HICAR_DEVICE_CONNECT_TIMEOUT_FOR_REPORT=109 | -  
HICAR_DEVICE_MANUAL_DISCONNECT=110 | If the user proactively disconnects the connection on the phone, the HMI app needs to record the action. The action is reserved in the current power-on period and will not trigger any automatic connection in the period.  
HICAR_DEVICE_ADV_TIMEOUT=111 | Notification for the advertising packet sending time-out. The current timeout period is 2 minutes.  
HICAR_DEVICE_SERVICE_UPDATE=201 | Service update.  
HICAR_DEVICE_SERVICE_PAUSE=202 | The service is suspended, such as where the HiCar app is temporarily running in the background.  
HICAR_DEVICE_SERVICE_RESUME=203 | The service enters the recovery state, such as where the HiCar app is switched from the background to the foreground when there is an incoming call.  
HICAR_DEVICE_SERVICE_START=205 | The service starts.  
HICAR_DEVICE_SERVICE_STOP=206 | The service stopped.  
HICAR_DEVICE_DISPLAY_SERVICE_PLAYING=207 | Projection is successful.  
HICAR_DEVICE_OPEN_CAMERA | The camera is enabled.  
HICAR_DEVICE_CLOSE_CAMERA | The camera is disabled.  
HICAR_DEVICE_OPEN_SPEAKER | The speaker is enabled.  
HICAR_DEVICE_CLOSE_SPEAKER | The speaker is disabled.  
HICAR_DEVICE_OPEN_MIC | The microphone is enabled.  
HICAR_DEVICE_CLOSE_MIC | The microphone is disabled.  
HICAR_DEVICE_VIRMODEM_CALLING=307 | Event for a connected carrier call. Microphone parameters such as echo cancellation during a call can be set.  
HICAR_DEVICE_VIRMODEM_HANGUP=308 | Event for an ended carrier call. Microphone parameters can be restored after the call is end.  
HICAR_DEVICE_VOIP_CALLING=309 | Event for a connected VoIP call. Microphone parameters such as echo cancellation during a call can be set.  
HICAR_DEVICE_VOIP_HANG_UP=310 | Event for an ended VoIP call. Microphone parameters can be restored after the call is end.
