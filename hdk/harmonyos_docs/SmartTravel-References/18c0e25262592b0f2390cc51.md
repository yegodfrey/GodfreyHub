# Init  
  
Function  
---  
int (*Init)(const void *context, const char *ifName)  
Initializes the driver to ensure that other driver interfaces are available.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
*context | const void | Context structure. Currently, this parameter is disabled and can be set to null.  
*ifName | const char | Driver name. For details, see the macro definitions in the **driver_adapt.h** file.
     * #define BLE_DRIVER_NAME "ble"
     * #define BR_DRIVER_NAME "br"
     * #define WIFI_DRIVER_NAME "wifi"
     * #define USB_DRIVER_NAME "usb"  
  
**Return**

Type | Description  
---|---  
int | Operation result.
     * **0** : success
     * Other values: failure
