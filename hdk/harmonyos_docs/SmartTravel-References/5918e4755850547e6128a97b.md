# UnRegisterGPSDataCallback  
  
Function  
---  
int32_t (*UnRegisterGPSDataCallback)()  
Prompts the device to stop data collection when the phone stops using the location service. The head unti then deregisters the data backhaul API and stops GPS data collection.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : success
     * Negative value: failure
