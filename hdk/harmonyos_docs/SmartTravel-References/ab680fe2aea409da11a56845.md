# Data Interactions

#### Interaction Overview

HiCar defines a series of APIs for data interactions between the head unit and the HiCar app on the phone. These APIs are used for vehicle control and vehicle attribute transmission between the head unit and the HiCar app. Based on the different data transmitted by the interface, the data is classified into the following types:

     * Non-JSON-based: Used by the head unit to report fixed information, such as the driving position and head unit type, during SDK initialization.
     * JSON-based: Transmits variable information, such as the vehicle speed and driving status, between the head unit and HiCar app in request/response mode. Different data interaction APIs are distinguished by the data type field during receiving and sending.

Android head units can exchange data with the HiCar app through the APIs provided by the HiCar SDK.

     * The head unit receives data sent by the HiCar app (related API: **CarListener::onDataReceive(String deviceId, int dataType, byte[] data)**).
     * The head unit sends data to the HiCar app (related API: **HiCarAdapter::sendCarData(int dataType, byte[] data)**).
