# RegisterListener  
  
Function  
---  
int32_t (*RegisterListener)(const DMSDPListener* listener)  
Registers a camera listener to listen for camera status changes.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
*listener | const DMSDPListener | Listener implementation function.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : success
     * Other values: failure
