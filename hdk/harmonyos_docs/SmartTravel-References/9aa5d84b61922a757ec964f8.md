# HiCarSendData  
  
Function  
---  
int32_t HiCarSendData(HICAR_HANDLE handle, CarDataType dataType, uint8_t* data, uint32_t size)  
Sends a type of data stream to HiCar, such as the head unit logo image.  
  
**Name** | **Type** | **Description**  
---|---|---  
handle | HICAR_HANDLE | HiCar handle, which is obtained through **GetHiCarHandle**.  
dataType | [CarDataType](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/car-data-type-0000001052955157) | Data type.  
data | uint8_t | Data content.  
size | uint32_t | Data size, in bytes.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : Data is sent.
     * Other values: Data failed to be sent.
