# getSecureFileSize  
  
Function  
---  
long getSecureFileSize(string fileName)  
The HiCar SDK uses this callback to obtain the size of an authentication file. Authentication files are managed by the head unit.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | Description  
---|---|---  
fileName | string | Name of the file that stores authentication information.  
  
**Return**

Type | Description  
---|---  
long | Authentication file size, in bytes.
