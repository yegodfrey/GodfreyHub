# Converged Desktop App List

#### Scenario Overview

In the converged desktop form, the head unit can request the list of apps that support HiCar, and display them together with its local native apps.

#### Data Type

528

#### API Version

1.0

#### API Definition

**Table 1** App information APIParameter | Mandatory | Type | Description  
---|---|---|---  
RequestData | Yes | string | Request data. Currently, the value can only be **all** , indicating that all app data is requested.  
RequestCaller | Yes | string | **modelId** of the current vehicle model.  
  
#### API Examples

The sample code for the head unit to request app data from the HiCar app is as follows:
    
    {
        "RequestData" : "all",
        "RequestCaller" : "00040900"
    }

After receiving the request, HiCar returns the app data through the **AppInfoChangeListener** API. The head unit needs to listen to this API to obtain the app data.
