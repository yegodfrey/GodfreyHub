# BusinessControl  
  
Function  
---  
int32_t (*BusinessControl)(uint32_t cmd, void* inputPara, uint32_t inLen, void* outputPara, uint32_t outLen)  
Notifies the head unit of the audio device status changes, including connection setup and disconnections.  
  
**Parameters**

**Name** | **Type** | **Description**  
---|---|---  
cmd | uint32_t | Command word (reserved). For details, see **DMSDPBusinessControlCmd**.  
*inputPara | void | Input parameters.  
inLen | uint32_t | Length of input parameters.  
*outputPara | void | Output parameters.  
outLen | uint32_t | Length of output parameters.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : success
     * Negative value: failure
