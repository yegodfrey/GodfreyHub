# BusinessControl  
  
Function  
---  
int32_t (*BusinessControl)(uint32_t cmd, void* inputPara, uint32_t inLen, void* outputPara, uint32_t outLen)  
Controls the camera services, such as camera rotation and tilting. If there is no such service, this function can be implemented as empty. Extended functions are reserved.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
cmd | uint32_t | Command (reserved for extension). For details, see **DMSDPBusinessControlCmd**.  
*inputPara | void | Input parameters.  
inLen | uint32_t | Length of input parameters.  
*outputPara | void | Output parameters.  
outLen | uint32_t | Length of output parameters.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : success
     * Other values: failure
