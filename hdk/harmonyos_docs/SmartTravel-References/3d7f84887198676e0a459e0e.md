# Overview  
  
Name | Description  
---|---

HwRemoteCtrlContentEvent | ContentEvent structure, which is not supported currently.

HwRemoteCtrlInputEvent | InputEvent sub-structure, which is not supported currently.  
HwRemoteCtrlInputEventDetails | InputEvent structure, which is not supported currently.  
HwRemoteCtrlVirtualKeyEventDetails | VirtualKeyEvent structure, which is not supported currently.  
HwRemoteCtrlMessageDetails | Message structure, which is not supported currently.
