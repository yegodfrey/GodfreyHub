# BusinessControl  
  
Function  
---  
int32_t (*BusinessControl)(uint32_t cmd, void* inputPara, uint32_t inLen, void* outputPara, uint32_t outLen)  
Conducts GPS service control. Currently, only the **cmd** field is used.  
  
**Parameters**

**Name** | **Type** | **Description**  
---|---|---  
cmd | uint32_t | Command word. For details, please refer to [GpsControlType](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/gps-control-type-0000001051650072).  
*inputPara | void | Input parameter, which is an extended field and is not used currently.  
inLen | uint32_t | Length of input parameters.  
*outputPara | void | Output parameters.  
outLen | uint32_t | Length of output parameters.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : success
     * Negative value: failure
