# RegisterSendDataCallback  
  
Function  
---  
int32_t (*RegisterSendDataCallback)(const char* id, uint32_t idLen, const DMSDPSendBackDataCB cb)  
Registers a camera image callback, so that the southbound API can use this callback to return image data. The northbound DeviceVirtualization Engine calls this function before using any camera.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
*id | const char | Camera ID.  
idLen | uint32_t | Length of the camera ID.  
cb | const [DMSDPSendBackDataCB](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-send-back-data-cb-0000001051491950) | Callback function.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : success
     * Other values: failure
