# CarDeviceType  
  
Enumerator | Description  
---|---  
HICAR_DEVICE_UNKNOWN=0 | The HiCar device type is unknown. This is the default value.  
HICAR_DEVICE_DONGLEA=1 | The device type is reserved type A.  
HICAR_DEVICE_DONGLEB=2 | The device type is reserved type B.  
HICAR_DEVICE_VISION=3 | The device type is reserved type C.  
HICAR_DEVICE_FRONT=4 | The HiCar device type is telematics box.
