# Navigation Metadata (Not Supported Currently)

#### Scenario Overview

After the head unit connects to HiCar and is authorized to obtain the navigation metadata, it will receive the navigation metadata once HiCar detects that the navigation data changes. The head unit can display the data on the dashboard/HUD.

Before using the navigation metadata, you need to request it. For details, please refer to [Metadata Capabilities](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/app-metadata-capability-0000001383252450#EN-US_TOPIC_0000001383252450).

#### DataType

517

#### API Version

1.0

#### API Definition

**Table 1** Navigation metadata**Parameter** | Mandatory | **Type** | **Description**  
---|---|---|---  
type | Yes | String | Navigation status:
     * **create** : navigation started
     * **update** : navigation updated
     * **remove** : navigation ended  
navData | Yes | object | Navigation data. For details, please refer to Table 3.  
  
**Table 2** Navigation metadata response data**Parameter** | Mandatory | **Type** | **Description**  
---|---|---|---  
NavigationDataResp | Yes | object | Response data. For details, please refer to Table 4.  
  
**Table 3****navData** navigation data**Parameter** | Mandatory | **Type** | **Description**  
---|---|---|---  
PackageName | Yes | String | Map app package name.  
NavTurnImage | Yes | byte[] | Byte data of the directional arrow image.  
RoadName | Yes | String | Road name.  
Distance | Yes | String | Steering distance.  
  
**Table 4** NavigationDataRespParameter | Mandatory | Type | Description  
---|---|---|---  
RespCode | Yes | int | Response result:
     * **100000** : received
     * **100001** : not received  
  
#### API Examples

When navigation metadata is available, the HiCar app sends a navigation metadata packet to the head unit. The sample code is as follows:
    
    {
        "type": "update", //create, update, remove
        "navData": {
            "PackageName": "com.xxx.xxx",
    	"NavTurnImage": [],
    	"RoadName": "Drive to xxx road",
    	"Distance": "888 meters"
        }
    }

After receiving the message, the head unit sends a response message to the HiCar app. The sample code is as follows:
    
    {
        "NavigationDataResp" : {
            "RespCode" : 100000
        }
    }
