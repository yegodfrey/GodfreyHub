# updateDpi (Beta)  
  
Method  
---  
CarConfig updateDpi(int dpi)  
Updates the number of dots per inch (DPI) on the head unit.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
dpi | int | Dots per inch. The value range is 120–640.  
  
**Return**

Type | Description  
---|---  
CarConfig | Vehicle configuration.
