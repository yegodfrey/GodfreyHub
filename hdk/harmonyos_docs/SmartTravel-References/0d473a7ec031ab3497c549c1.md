# HiCarInit  
  
Function  
---  
int32_t HiCarInit(CarConfig *carConfig, CarLogFuncGroup *logGroup)  
Initializes the HiCar SDK, which must be completed to use the HiCar service.  
  
**Parameters**

**Name** | **Type** | **Description**  
---|---|---  
carConfig | [CarConfig](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/car-config-0000001052476463) | Vehicle configuration.  
logGroup | [CarLogFuncGroup](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/car-log-func-group-0000001050174637) | Prints logs.  
  
**Return**

Type | Description  
---|---  
int32_t | Initialization result.
     * **0** : Initialization succeeded.
     * Other values: Initialization failed.
