# HiCarPauseProjection  
  
Function  
---  
int32_t HiCarPauseProjection(HICAR_HANDLE handle)  
Pauses HiCar projection. It is called when the HMI app receives the **HICAR_DEVICE_SERVICE_PAUSE** state.  
  
**Name** | **Type** | **Description**  
---|---|---  
handle | HICAR_HANDLE | HiCar handle, which is obtained through **GetHiCarHandle**.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : success
     * Other values: failure
