# DMSDPVirtualStreamData  
  
Name | Type | Description  
---|---|---  
*data | uint8_t | Virtual audio stream data.  
timeStampUs | int64_t | Timestamp of each frame in the virtual audio stream.  
usage | uint32_t | Usage of the virtual audio stream, such as media or phone.  
*header | [DMSDPVirtualStreamDataHeader](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-virtual-stream-data-header-0000001051809204) | Data header of the virtual audio stream.
