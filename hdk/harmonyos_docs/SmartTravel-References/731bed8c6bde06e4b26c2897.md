# unRegisterCarListener  
  
Method  
---  
int unRegisterCarListener(CarListener listener)  
Unregisters a HiCar SDK event listener.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
listener | CarListener | HiCar SDK event listener.  
  
**Return**

Type | Description  
---|---  
int | Only the value **0** indicates that the API is called successfully. For details, please refer to [HiCarConst](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/hicar-const-0000000000030396).
