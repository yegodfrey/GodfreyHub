# ReceiveData  
  
Function  
---  
void (*ReceiveData)(ChannelType channelType, const void *channelParam, const unsigned char *data, int dataLen)  
Reports received data packets to Nearby.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
channelType | [ChannelType](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/channel-type-0000001051652094) | Channel type.  
*channelParam | const void | Channel parameter structure, mainly used by the BR driver. For details about **channelParam** , see the description of **BrChannelData**.  
*data | const unsigned char | Number of received bytes.  
dataLen | int | Length of the received bytes.
