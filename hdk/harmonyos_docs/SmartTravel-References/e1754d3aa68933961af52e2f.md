# writeSecureFile  
  
Function  
---  
boolean writeSecureFile(string fileName, byte[] data)  
The HiCar SDK uses this callback to save an authentication file to the local head unit or secure storage. Authentication files are managed by the HMI app.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
fileName | string | Name of the authentication file.  
data | byte[] | Information to be stored.  
  
**Return**

Type | Description  
---|---  
boolean | Whether the writing is successful.
     * **true** : success
     * **false** : failure
