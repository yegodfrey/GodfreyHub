# CreateWifiChannel  
  
Function  
---  
int (*CreateWifiChannel)(const void *context, const void *wifiData)  
Creates a Wi-Fi hotspot for the head unit.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
*context | const void | The void* is used to represent the structure differences of different device parameters. Currently, the **context** parameter is disabled and can be set to null.  
*wifiData | const void | The void* is used to represent the structure differences of different device parameters. The input parameter is the pointer (int *) to the channel frequency. The hotspot name (SSID) and password (key) are generated by the head unit and reported to Nearby.  
  
**Return**

Type | Desc  
---|---  
int | Operation result.
     * **0** : success
     * Other values: failure
