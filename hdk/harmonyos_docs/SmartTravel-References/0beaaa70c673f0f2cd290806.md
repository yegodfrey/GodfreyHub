# isSupportHiCar  
  
Method  
---  
boolean isSupportHiCar(String bluetoothmac)  
Checks whether HiCar is supported on the phone connected to the head unit via Bluetooth.  
  
**Parameters**

Parameter Name | Parameter Type | Description  
---|---|---  
macAddress | String | Bluetooth address of the phone.  
  
**Return**

Type | Description  
---|---  
boolean | Supported or not:
     * **true** : yes
     * **false** : no
