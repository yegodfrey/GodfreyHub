# HiCarDeleteObject  
  
Function  
---  
int32_t HiCarDeleteObject(HICAR_HANDLE handle, CarObjectType objType, void* obj)  
Destroys a service object to release memory. This API needs to be called when **HiCarPostEvent** is not called after **HiCarNewObject**.  
  
**Name** | **Type** | **Description**  
---|---|---  
handle | HICAR_HANDLE | HiCar handle, which is obtained through **GetHiCarHandle**.  
objType | [CarObjectType](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/car-object-type-0000001051795144) | Object type.  
size | uint32_t | Object size.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : The memory is released.
     * Other values: The memory failed to be released.
