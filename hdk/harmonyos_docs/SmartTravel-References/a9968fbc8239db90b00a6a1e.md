# GetParam  
  
Function  
---  
int (*GetParam)(GetParamsType paramType, void *paramValue)  
Obtains device attributes and capabilities.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
paramType | [GetParamsType](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/get-params-type-0000001052250830) | Parameter type.  
*paramValue | void | Data structure pointer. The void * is used to represent the data structure differences between different devices.  
  
**Return**

Type | Description  
---|---  
int | Operation result.
     * **0** : success
     * Other values: failure
