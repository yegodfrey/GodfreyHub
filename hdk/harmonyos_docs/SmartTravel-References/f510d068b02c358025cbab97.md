# Head Unit Types

The functionality of HiCar is affected by the hardware and software capabilities of the head unit. In order for HiCar to provide different functions for different head units, the head unit needs to report the head unit type during HiCar SDK initialization.

**Table 1** Key-value pair for reporting the head unit type during initializationValue | Type | **Description**  
---|---|---  
DEVICE_TYPE | int | Head unit type.
     * **0** : Unknown type (value used when the head unit is not configured)
     * **1** : Dongle A with HiCar installed after delivery, usually Android head units
     * **2** : Dongle B with HiCar installed after delivery
     * **3** : Smart display powered by HUAWEI HiCar
     * **4** : Head units pre-installed with HiCar  
  
The following is an example:
    
    CarConfig.Builder builder = **new** CarConfig.Builder();
    Map<String, String> config = **new** HashMap<String, String>();
    config.put(**"DEVICE_TYPE"** ,3);  
    builder.withInitialConfig(config);
