# Voice Prompt Broadcast  
  
#### Scenario Overview

In the voice interaction between the HiCar and the head unit, if a virtual audio channel needs to be recreated, the beep tone of the voice prompt may be lost or become a crack sound due to overlong delay. To avoid this situation, you can save the beep tone file on the head unit. After receiving the notification message from the HiCar app, the head unit broadcasts the beep tone locally.

A standard audio file must be preset for the head unit to broadcast the beep tone.

#### Data Type

519

#### API Version

1.0

#### API Definition

**Table 1** API for voice prompt broadcastParameter | **Mandatory** | Type | **Description**  
---|---|---|---  
isVoicePromptSupport | No | int | Whether the head unit supports local beep tone broadcast:
     * **1** : The HiCar app queries whether the head unit can broadcast the beep tone locally.
     * **2** : The head unit supports local beep tone broadcast.
     * **-1** : The head unit does not support local beep tone broadcast.  
voicePrompt | No | int | Instruction on beep tone broadcast delivered by the HiCar app to the head unit:
     * **0** : Stop broadcasting the beep tone.
     * **1** : Start broadcasting the beep tone.  
  
#### API Examples

     1. Example: The HiCar app queries whether the head unit supports the broadcast of the beep tone.
        1. Message content:
               
               {
                   "isVoicePromptSupport":1
               }

        2. Response message:
               
               {
                   "isVoicePromptSupport":2
               }

     2. Example: The HiCar app sends an instruction to the head unit to start or stop broadcasting the beep tone.
            
            {
                "voicePrompt":1
            }
