# Notification for User-initiated Disconnection from the Head Unit  
  
#### Scenario Overview

When automatic connection is supported, the head unit needs to correctly identify the scenario where the user proactively ends the HiCar connection so that the automatic connection is not initiated in this scenario.

When the user proactively ends the HiCar connection, the HiCar app notifies the head unit of the disconnection. After receiving the notification, the head unit needs to respond.

#### Data Type

518

#### API Version

1.0

#### API Definition

**Table 1** API for notifications for user-initiated disconnections from the head unitParameter | **Mandatory** | Type | **Description**  
---|---|---|---  
isUserDisconnect | No | int | User-initiated disconnection message and response:
     * **0** : The HiCar app delivers the message of user-initiated disconnection to the head unit.
     * **1** : The head unit responds to the disconnection message.  
  
#### API Examples

Example: The HiCar App sends a message to the head unit, indicating that the user proactively ends the connection.
    
    {
        "isUserDisconnect":0
    }

Example: The head unit sends a response message to the HiCar app.
    
    {
        "isUserDisconnect":1
    }
