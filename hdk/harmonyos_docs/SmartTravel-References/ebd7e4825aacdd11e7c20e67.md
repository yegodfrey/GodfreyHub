# ReadStreamBuffer  
  
Function  
---  
int32_t (*ReadStreamBuffer)(const char* id, uint32_t idLen, int32_t sessionId, DMSDPVirtualStreamData* data)  
Records audio data. During the implementation of this API, pay attention to thread safety, as different threads may call this API.  
  
**Parameter name** | **Type** | **Description**  
---|---|---  
*id | const char | Microphone ID.  
idLen | uint32_t | Length of the microphone ID.  
sessionId | int32_t | Session ID.  
*data | [DMSDPVirtualStreamData](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-virtual-stream-data-0000001052609206) | Microphone data.  
  
**Return**

Type | Desc  
---|---  
int32_t | Operation result.
     * **0** : success
     * Negative value: failure
