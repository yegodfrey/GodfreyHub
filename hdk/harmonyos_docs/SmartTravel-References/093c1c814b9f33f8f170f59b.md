# Vehicle Control (AC/Window)  
  
#### Scenario Overview

Vehicle control APIs are used to control in-vehicle devices including the air conditioner (AC), windows, and sunroofs. After the user wakes up the voice assistant, they can issue voice commands. The HiCar app identifies the user intent and sends vehicle control data to the head unit. The head unit then controls the AC, windows, sunroof, or other devices as instructed.

To improve the overall control efficiency, after the phone is connected to the head unit, the HiCar app proactively queries the head unit about the vehicle control capabilities. The head unit needs to respond with feedback about vehicle control capabilities and current state. When the status of the AC, windows, sunroof, or other devices changes, the head unit needs to proactively send the latest status information to the HiCar app.

#### Data Type

500

#### API Definition

**Table 1** Vehicle control APIsParameter | **Mandatory** | Type | **Description**  
---|---|---|---  
VehicleControlCapability | Yes | object | Queries information of vehicle control capabilities, which is sent by the HiCar app to the head unit to query which vehicle control capabilities are supported by the head unit.  
VehicleControlCapabilityResp | Yes | object | Returns vehicle control capability information, which contains the supported capabilities and reports the vehicle control status changes. For details, see Table 2.  
VehicleControl | Yes | object | Vehicle control information used to control the air conditioner, windows, or sunroof at a time. For details, see Table 3.  
VehicleControlResp | Yes | object | API used to return response about vehicle control settings. For details, see Table 4.

---|---|---|---

status | Yes | string | Mute status:

     * **unmute** : Not muted.

status | Yes | string | AC status:

     * **off** : Turned off.

**Table 3** VehicleControlParameter | **Mandatory** | **Type** | **Description**  
---|---|---|---  
volume | intent | Yes | string | Volume control operation:
     * **mute** : Mute.
     * **unmute** : Unmute.
     * **setvolume** : Set the volume.  
volume | Yes | string | Volume level after the volume is increased or decreased. This parameter is carried only when the volume is set.  
airConditioner | intent | Yes | string | AC control operation:
     * **turnon** : Power on the AC.
     * **turnoff** : Turn off the AC.
     * **settemp** : Set the AC temperature.  
temperature | No | string | Set the AC temperature in °C. This parameter is carried when the AC temperature is set, or if the user specifies the temperature when turning on the air conditioner.  
skyLight | intent | Yes | string | Sunroof control operation:
     * **open** : Enable.
     * **close** : Disable.  
vehicleWindow | windowType | Yes | string | Controllable window types:
     * **all** : All windows.
     * **leftfront** : Front left window.
     * **rightfront** : Front right window.
     * **leftback** : Rear left window.
     * **rightback** : Rear right window.
     * **front** : Front windows (left and right).
     * **back** : Rear windows (left and right).  
intent | Yes | string | Window status:
     * **open** : Enable.
     * **close** : Disable.  
percent | No | string | Percentage of opened windows. The value ranges from 1 to 100. For example, if the percentage is 20%, the passed value is **20**.

#### API Examples

#### [h2]Obtaining and Reporting Vehicle Control Capabilities

Example: The HiCar app requests to obtain the vehicle control capabilities from the head unit.
    
    {
    	"VehicleControlCapability": {}
    }

Example: The head unit responds to the HiCar app with feedback about its vehicle control capabilities.
    
    {
    	"VehicleControlCapabilityResp": {
    		"volume": {
    			"support": "true",
    			"status": "unmute",
    			"maxVolume": "7",
    			"minVolume": "0",
    			"currentVolume": "6"
    		},
    		"airConditioner": {
    			"support": "true",
    			"maxTemperature": "30",
    			"minTemperature": "15",
    			"status": "on",
    			"currentTemperature": "25"
    		},
    		"skyLight": {
    			"support": "true",
    			"status": "close"
    		},
    		"vehicleWindow": {
    			"leftFront": "true",
    			"leftFrontStatus": "close",
    			"rightFront": "true",
    			"rightFrontStatus": "close",
    			"leftBack": "true",
    			"leftBackStatus": "close",
    			"rightBack": "true",
    			"rightBackStatus": "close",
    			"isPercentSupport": "false"
    		}
    	}
    }

#### [h2]Vehicle Control Examples

Example: The HiCar app sends the air conditioner control commands to the head unit.
    
    {
        "VehicleControl": {
              "airConditioner": {
                    "intent":"turnon",
              }
        }
    }
    {
        "VehicleControl": {
              "airConditioner": {
                    "intent":"settemp",
                    "temperature":"25"
              }
        }
    }
    {
        "VehicleControl": {
              "airConditioner": {
                    "intent":"turnoff",
              }
        }
    }

Example: The head unit responds to the HiCar app with feedback about the air conditioner control.
    
    {
        "VehicleControlResp": {
             "respCode":"success",
             "airConditioner": {
                    "status":"on",
                    "currentTemperature":"25"
              }
         }
    }
    {
        "VehicleControlResp": {
             "respCode":"success",
             "airConditioner": {
                    "status":"off",
              }
         }
    }

Example: The HiCar app sends the sunroof control commands to the head unit.
    
    {
        "VehicleControl": {
              "skyLight": {
                    "intent":"close"
              }
        }
    }

Example: The head unit responds to the HiCar app with feedback about the sunroof control.
    
    {
        "VehicleControlResp": {
             "respCode":"success",
              "skyLight": {
                    "status":"close"
              }
        }
    }

Example: The HiCar app sends the window control commands to the head unit.
    
    {
        "VehicleControl": {
              "vehicleWindow": {
                    "windowType":"all",
                    "intent":"open",
                    "percent":"20"
              }
        }
    }

Example: The head unit responds to the HiCar app with feedback about the window control.
    
    {
        "VehicleControlResp": {
             "respCode":"success",
              "vehicleWindow": {
                    "leftFrontStatus":"open",
                    "rightFrontStatus":"open",
                    "leftBackStatus":"open",
                    "rightBackStatus":"open"
              }
        }
    }

Example: The HiCar app sends the volume control commands to the head unit.
    
    {
        "VehicleControl": {
              "volume": {
                    "intent":"setvolume",
                    "volume":"7", 
              }
        }
    }
    {
        "VehicleControl": {
              "volume": {
                    "intent":"mute",
              }
        }
    }

Example: The head unit responds to the HiCar app with feedback about the volume control.
    
    {
        "VehicleControlResp": {
             "respCode":"success",
             "volume": {
                    "status":"unmute",
                    "currentVolume":"7"
              }
         }
    }
