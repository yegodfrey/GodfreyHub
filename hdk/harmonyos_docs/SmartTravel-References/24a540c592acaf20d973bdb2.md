# EventType  
  
Enumerator | Description  
---|---  
EVENT_CONNECT = 1 | Channel connection is successful.  
EVENT_CONNECT_FAIL | Channel connection failed.  
EVENT_DISCONNECT | The channel is disconnected.  
EVENT_SCAN_RESULT | Disabled.  
EVENT_CREATE_WIFI_SUCCESS | A Wi-Fi hotspot is successfully created.  
EVENT_CONFIG_IP_SUCCESS | The Wi-Fi IP address is set successfully.  
EVENT_GROUP_STARTED | Disabled.  
EVENT_GROUP_REMOVED | Disabled.
