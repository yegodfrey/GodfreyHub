# Overview  
  
Return Type | Function Name  
---|---  
int32_t | DMSDPGetGPSHandler Obtains GPS related data, stored in the **DMSDPGPSHandler** structure.  
int32_t | RegisterGpsDataCallBack When the phone starts to use the location service, it requests GPS data from the device. The device registers the data backhaul API with a third-party system to obtain the basic GPS data, vehicle body data, and sensor data. Data collection is implemented by the vehicle manufacturers.  
int32_t | UnRegisterGPSDataCallback When the phone stops using the location service, it prompts the device to stop data collection. The device then deregisters the data backhaul API and stops GPS data collection.  
int32_t | GetGPSDataReportFreq Obtains the GPS data reporting frequency, in Hz. For example, if **locationFreq** is set to 1, the frequency is 1 Hz. The HiCar SDK expects the location information to be reported at a frequency of 1 Hz, the vehicle body data to be reported at a frequency of 10 Hz, and the vehicle sensor data to be reported at a frequency of 40 Hz. Manufacturers can adjust the frequency based on the actual device.  
int32_t | SetGPSDataReportFreq Dynamically sets the GPS data reporting frequency. If the set frequency exceeds the limit, an error is returned.  
int32_t | RegisterListener Registers the GPS listener.  
int32_t | BusinessControl Conducts GPS service control.
