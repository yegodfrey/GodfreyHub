# HiCarGetConnectQRCode  
  
Function  
---  
int32_t HiCarGetConnectQRCode (uint8_t *url, uint32_t maxLen)  
Obtains the QR code value. when the head unit is on the QR code scanning screen.  
  
**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
url | uint8_t | QR code value buffer.  
maxLen | uint32_t | Maximum buffer length.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * Values larger than 0: Success, in which case the length of the QR code value is returned as well.
     * 0 or negative values: Failure.
