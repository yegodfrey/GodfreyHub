# Overview  
  
Name | Description  
---|---  
DMSDPGPSCallback | Uploads the location information, vehicle body data, sensor data, and basic data (such as the vehicle brand and model) of the head unit. For details, please refer to [GPS Data Format Definition](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/gps-data-format-0000001053730837).  
DMSDPGpsHandler | GPS service management structure, which provides functions such as registration, deregistration, frequency obtaining, and frequency setting.
