# Audio Metadata

#### Scenario Overview

After the head unit connects to HiCar and is authorized to obtain the audio metadata, HiCar will notify the head unit of the basic audio information and status once HiCar detects that the audio playback status changes. Then, the head unit will be able to send the data to the dashboard/HUD for display.

Before using the audio metadata, you need to request it. For details, please refer to [Metadata Capabilities](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/app-metadata-capability-0000001383252450#EN-US_TOPIC_0000001383252450).

#### DataType

515

#### API Version

1.0

#### API Definition

**Table 1** Audio metadataParameter | Mandatory | Type | Description  
---|---|---|---  
MediaData | Yes | object | Audio metadata. For details, please refer to Table 2.  
MediaDataResp | Yes | object | Response data. For details, please refer to Table 3.  
  
**Table 2** MediaData**Parameter** | Mandatory | **Type** | **Description**  
---|---|---|---  
Name | Yes | String | Audio file.  
Artist | Yes | String | Artist.  
TotalTime | Yes | int | Total audio duration, in seconds.  
ElapsedTime | Yes | int | Played duration, in seconds.  
AlbumName | Yes | String | Album name.  
AlbumArtURL | No | String | URL of the album cover image.  
Status | Yes | int | Playback status:
     * **0** : no playback task
     * **1** : playback stopped
     * **2** : playback paused
     * **3** : playing
     * **6** : buffering
For details, please refer to **android.media.session.PlaybackState** in native Android APIs.  
AppName | No | String | Audio app name.  
AppIcon | No | byte[] | Byte data of the audio app icon.  
AppPackage | Yes | String | Audio app package name.  
  
**Table 3** MediaDataRespParameter | Mandatory | Type | Description  
---|---|---|---  
RespCode | Yes | int | Response result:
     * **100000** : received
     * **100001** : not received  
  
#### API Examples

When the audio playback status changes, the HiCar app sends the audio metadata to the authorized head unit based on the user authorization record. The sample code is as follows:
    
    {
        "MediaData" : {
            "Name" : "Dream It Possible",
            "Artist" : "",
            "TotalTime" : 204,
            "ElapsedTime" : 50,
            "AlbumName" : "Dream It Possible",
            "AlbumArtURL" : "https://xxxxx",
            "AlbumArtIcon" : [],
            "Status" : 3,
            "AppName" : "HUAWEI Music HUAWEI HiCar",
            "AppIcon" : [],
            "AppPackage" : "com.huawei.music"
        }
    }

After receiving the message, the head unit sends a response message to the HiCar app. The sample code is as follows:
    
    {
        "MediaDataResp" : {
            "RespCode" : 100000
        }
    }
