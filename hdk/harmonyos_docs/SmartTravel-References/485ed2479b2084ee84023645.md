# CarDeviceInfo  
  
Name | Type | Description  
---|---|---  
carBrand[64] | char | Vehicle brand name.  
carBrandLen | uint32_t | Length of the vehicle brand name.  
dayNightInfo[12] | char | Indicates whether the vehicle is in Dark mode or Light mode:
     * **night** : The vehicle is in Dark mode.
     * **day** : The vehicle is in Light mode.
     * **pending** : The current mode cannot be determined, but the information can be dynamically sent to HiCar later.
     * **notsupport** : The vehicle does not support reporting of the Dark/Light mode information.  
carDayNightLen | uint32_t | Length of the mode name. For example, if the mode is Light mode, the value of the parameter (**day**) is **3**.  
steeringWheelPos | uint32_t | Indicates whether the driver's seat is in the left or right side of the vehicle.
     * **0** : Left.
     * **1** : Right.  
deviceType | uint32_t | Head unit type.
     * **0** : unknown (default value)
     * **1** : reserved type A
     * **2** : reserved type B
     * **3** : Smart display powered by HUAWEI HiCar
     * **4** : telematics box  
filePath | [DataInfo](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/data-info-0000001050167995) | Save path of log files.
     * This file path is used to store run logs for fault analysis.
     * Ensure that the path is writable during initialization (**HiCarInit**).
     * The **ConfigDir** folder is included in each version release. Copy the folder to the log file path, such as **/tmp/hicarlogs/**.In this case, the configuration file is stored under **/tmp/hicarlogs/ConfigDir/**.  
entertainmentAllowType | uint32_t | Whether entertainment apps (such as video and game apps whose icons are marked with the character "P") are available during driving:
     * **1** (**HICAR_ONLY_PARK_ALLOW**): Entertainment apps are available only when the vehicle is parked.
     * **0** (**HICAR_ALWAYS_ALLOW**): Entertainment apps are always available (default value).
