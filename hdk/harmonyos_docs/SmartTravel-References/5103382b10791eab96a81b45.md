# update5gChannels (Beta)  
  
Method  
---  
CarConfig update5gChannels(int[] support5gChannels)  
Updates the list of 5 GHz Wi-Fi channels supported by the head unit.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
support5gChannels | int[] | List of 5 GHz Wi-Fi channels supported by the head unit, for example, **[36,40,44,48,149]**.  
  
**Return**

Type | Description  
---|---  
CarConfig | Vehicle configuration.
