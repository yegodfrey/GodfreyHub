# GetVideoData  
  
Function  
---  
int32_t (*GetVideoData)(const uint8_t *pPacket, uint32_t nPktSize, int64_t timeStamp,int64_t duration, VideoFrameInfo *info)  
Obtains the data of the projected video stream.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
*pPacket | uint8_t | Video stream data in bytes.  
nPktSize | uint32_t | Size of the current frame data in bytes.  
timeStamp | int64_t | Timestamp of the current frame.  
duration | int64_t | Not involved in HiCar services. Retain the default value **0**.  
*info | [VideoFrameInfo](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/video-frame-info-0000001050172654) | Additional frame information.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : The display is normal.
     * **-1** : The frame is discarded.
