# getStreamType  
  
Method  
---  
int getStreamType()  
Obtains the stream type of this audio component.  
  
**Return**

Type | Description  
---|---  
int | Audio stream type. For details, see the audio stream parameters of **AudioManager**. Example: **0** : Voice call (such as VoIP call) **1** : Sonification sounds (for example, sound played when using the UI) **2** : Call ringtone (such as for calls and VoIP calls) **3** : Text to speech **4** : Alert tone (such as the alarm tone) **5** : Prompt tone **8** : Prompt tone during a call (such as busy tone and DTMF tone) **10** : Voice played by an accessibility feature (such as the screen reader)
