# HiCarDeleteTrustDevice  
  
Function  
---  
int32_t HiCarDeleteTrustDevice(const uint8_t *phoneId, uint32_t idLen)  
Deletes a specified trusted device. After the device is deleted, it must be authenticated again.  
  
**Name** | **Type** | **Description**  
---|---|---  
phoneId | uint8_t* | Unique phone identifier.  
idLen | uint32_t | Phone ID, which contains a maximum of 128 characters.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * Negative value: The devices failed to be deleted.
     * Values other than 0: Indicate the number of deleted devices.
