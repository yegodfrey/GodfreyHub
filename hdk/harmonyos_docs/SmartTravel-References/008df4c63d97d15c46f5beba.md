# Overview

Structure | Function in the Structure | Description  
---|---|---  
BtRecommendAdpterOps | registerBtSocketCallback(BtSocketDataCallback *callback) | Obtains the data processing function from the HiCar SDK to process the data obtained from Bluetooth sockets.  
initBtSocket(RfcommServerInfo serverInfo) | Creates Bluetooth sockets based on **RfcommServerInfo** provided by the HiCar SDK, and processes data received from the Bluetooth sockets.  
sendData(char *data) | Called by the HiCar SDK to send data to the phone.  
unregisterBtSocketCallback() | A deregister function that releases the data processing function obtained from the HiCar SDK.  
deInitBtSocket() | A de-initialization function that destroys Bluetooth sockets.
