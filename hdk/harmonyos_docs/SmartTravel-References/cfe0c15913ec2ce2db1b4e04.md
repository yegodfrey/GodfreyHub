# CloseCamera  
  
Function  
---  
int32_t (*CloseCamera)(const char* id, uint32_t idLen)  
Closes a specified camera. The southbound API returns the address of the API implementation function.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
*id | const char | Camera ID.  
idLen | uint32_t | Length of the camera ID.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : The camera is closed.
     * Other value: An exception occurs when closing the camera.
