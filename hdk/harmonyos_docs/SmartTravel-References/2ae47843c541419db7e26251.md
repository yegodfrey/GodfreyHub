# registerCarDataListener  
  
Function  
---  
boolean registerCarDataListener(GpsDataCallBack gpsDataCallBack)  
Subscribes to GPS data from the head unit. After opening a navigation app, the phone sends a GPS data request to the head unit. The HiCar SDK on the head unit subscribes to GPS data listening from the head unit. Through the listening interface, the head unit sends GPS basic data, sensor data, and vehicle body data to the HiCar SDK.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
gpsDataCallBack | GpsDataCallBack | GPS data callback.  
  
**Return**

Type | Description  
---|---  
boolean | Subscription result:
     * **true** : success
     * **false** : failure
