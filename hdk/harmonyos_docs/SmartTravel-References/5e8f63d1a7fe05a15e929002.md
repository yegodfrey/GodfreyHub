# DMSDPAudioFocus  
  
Enumerator | Description  
---|---  
AUDIOFOCUS_NONE = 0 | -  
AUDIOFOCUS_GAIN = 1 | HiCar requests to occupy audio focus for an extended period of time. If focus is lost, the playback stops and the focus is released.  
AUDIOFOCUS_GAIN_TRANSIENT = 2 | HiCar requests to occupy audio focus for a short period of time. If focus is lost, the playback is paused.  
AUDIOFOCUS_GAIN_TRANSIENT_MAY_DUCK = 3 | HiCar requests to occupy audio focus for a short period of time. If focus is lost, the playback can go on but the volume should be turned down.  
AUDIOFOCUS_GAIN_TRANSIENT_EXCLUSIVE = 4 | HiCar requests to occupy audio focus for a short period of time. Other audio sources that don't have focus are expected to be muted.  
AUDIOFOCUS_RELEASE = 5 | HiCar requests for the release of audio focus.  
AUDIOFOCUS_LOSS = -1 | HiCar loses audio focus or cannot obtain audio focus.  
AUDIOFOCUS_LOSS_TRANSIENT = -2 | HiCar temporarily loses audio focus.  
AUDIOFOCUS_LOSS_TRANSIENT_CAN_DUCK = -3 | HiCar can continue the playback through the media channel, but the volume needs to be turned down.
