# Screen Operation Mode

HiCar displays the screen focus for different modes of operation, including touchscreen operations, knob operations, and others. The head unit needs to report the operation modes supported by the screen and the preferred operation mode during HiCar SDK initialization.

**Table 1** Key-value pair of control modes reported during initializationValue | Type | Description  
---|---|---  
INPUT_FEATURES | int | Operation mode supported by the screen of the head unit, which is determined based on the bit.
     * Touchscreen operation: Bit 0. **1** : supported; **0** : not supported.
     * Knob operation: Bit 1. **10** : supported; **00** : not supported.
     * Touch panel operation: Bit 2. **100** : supported; **000** : not supported.
You will need to convert the result into int-type data based on the actual situation and then report the data. For example, if the touchscreen operation (1) is supported, report **1**. If the knob operation (10) is supported, report **2**. If the touchscreen and knob operations (11) are supported, report **3**. If all operation modes (111) are supported, report **7**.  
PRIMARY_INPUT | int | Main operation mode of the head unit screen, which can be reported when multiple operation modes are supported.
     * **1** : Touchscreen operation (default value).
     * **2** : Knob operation.
     * **3** : Touch panel operation.  
  
The following is an example of setting the control modes when initializing the HiCar SDK:
    
    CarConfig.Builder builder = **new** CarConfig.Builder();
    Map<String, String> config = **new** HashMap<String, String>();
    config.put(**"PRIMARY_INPUT"** ,  **1**);  
    builder.withInitialConfig(config);
