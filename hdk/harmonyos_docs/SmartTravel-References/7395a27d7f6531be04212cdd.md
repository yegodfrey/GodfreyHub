# onDeviceServiceChange  
  
Function  
---  
void onDeviceServiceChange(string serviceId, int state)  
HiCar SDK device service event callback, mainly used to listen for the projection service. The remote device ID and event type are carried in the event callback.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
serviceId | string | Virtual service ID of a remote device.  
state | int | Device event type. The optional types defined in the HiCar SDK are as follows:
     * EVENT_DEVICE_SERVICE_PAUSE = 202; //The service is paused.
     * EVENT_DEVICE_SERVICE_RESUME = 203; //The service is resumed.
     * EVENT_DEVICE_SERVICE_START = 204; //The service is started.
     * EVENT_DEVICE_SERVICE_STOP = 205;//The service is stopped.
     * EVENT_DEVICE_DISPLAY_SERVICE_PLAYING = 207;//Projection is started.
     * EVENT_DEVICE_DISPLAY_SERVICE_PLAY_FAILED = 208;//Projection failed.
     * EVENT_DEVICE_SERVICE_VIRMODEM_CALLING = 209;//A modem call is in process.
     * EVENT_DEVICE_SERVICE_VIRMODEM_HANG_UP = 210;//A modem call is ended.
     * EVENT_DEVICE_SERVICE_VOIP_CALLING = 214;//A VoIP call is answered.
     * EVENT_DEVICE_SERVICE_VOIP_HANG_UP = 215;//A VoIP call is ended.
