# Overview  
  
Name | Description  
---|---  
[DMSDPCameraDataType](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-camera-data-type-0000001051651804) | Data types of the output camera images, including H.264, H.265, RGB565, and NV21.  
[DMSDPCameraReleaseType](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-camera-release-type-0000001052571843) | Type of the data structure to be released. Currently, it is used only in the case of querying camera capability information.  
[DSMDPCameraConfigKey](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-camera-config-key-0000001051491812) | Camera configuration data type. Currently, only FPS is supported.
