# HiCarPostEvent  
  
Function  
---  
int32_t HiCarPostEvent(HICAR_HANDLE handle, CarEventType eventType, const char* content, uint32_t size)  
Sends an event to HiCar, such as a touchscreen event, key event, or voice wakeup event.  
  
**Name** | **Type** | **Description**  
---|---|---  
handle | HICAR_HANDLE | HiCar handle, which is obtained through **GetHiCarHandle**.  
eventType | [CarEventType](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/car-event-type-0000001052595144) | Event type.  
content | char | Event content, which can be a character string or event structure.  
size | uint32_t | Size of the event content, in bytes.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : The event is sent.
     * Other values: The event failed to be sent.
