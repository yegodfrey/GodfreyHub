# CarBaseInfo  
  
Function  
---  
void (*CarBaseInfo)(char *info, int32_t len)  
Reports basic vehicle data, including the model ID, device ID, vehicle brand, and vehicle model. The reporting starts when **RegisterGpsDataCallBack** is called and continues at 1 Hz until **BusinessControl GPS_STOP_CALLBACK_BASE_INFO** or **unRegisterGpsDataCallBack** is received.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
*info | char | Basic data. Example: $RMTINFO,01,02,EXAMPLE,XC5*50  
len | int32_t | Data length.
