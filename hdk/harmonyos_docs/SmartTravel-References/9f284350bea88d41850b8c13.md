# Overview  
  
Name | Description  
---|---  
[DMSDPAudioProfile](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-audio-profile-0000001053089209) | Used by the audio device to report an audio profile, including the sampling rate, number of audio channels, and sampling resolution.  
[DMSDPAudioProfiles](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-audio-profiles-0000001052249190) | Used by the audio device to report audio profiles, including the quantity.  
[DMSDPProfile](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-profile-0000001052889208) | Used by the HiCar SDK to open the audio profile reported by the audio device, including the sampling rate, number of audio channels, sampling resolution, and codec type.  
[DMSDPProfiles](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-profiles-0000001052490527) | Used by the HiCar SDK to open the audio profiles reported by the audio device, including the quantity.  
[DMSDPAudioCodecs](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-audio-codecs-0000001052570753) | Audio codec capabilities supported by the head unit, including the number of supported types.  
[DMSDPReserved](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-reserved-0000001051650460) | DMSDP reserved word.  
[DMSDPReserveds](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-reserveds-0000001052570505) | A set of DMSDP reserved words, including the number of reserved words.  
[DMSDPAudioCapabilities](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-audio-capabilities-0000001051490470) | Audio capability set of the head unit.  
[DMSDPVirtualStreamDataHeader](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-virtual-stream-data-header-0000001051809204) | Data header in audio data written to the head unit.  
[DMSDPVirtualStreamData](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-virtual-stream-data-0000001052609206) | Audio data written to the head unit.  
[DMSDPAudioBussinessCtrlData](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-audio-business-ctrl-data-0000001052969213) | Service status change that the SDK notifies the head unit of, for example, enabling or disabling the speaker service.
