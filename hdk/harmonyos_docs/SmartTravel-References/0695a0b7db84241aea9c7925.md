# Driver's Seat  
  
The driving position indicates whether the driver's seat of the vehicle is on the left or right. The HiCar app can adjust the UI layout based on the driving position, for example, displaying the dock area on the left or right.

After the head unit is started, the driving position should be reported during HiCar SDK initialization.

**Table 1** Parameter of the driver's seat during initializationParameter | Description  
---|---  
CarConfig.CarDeviceInfo.steeringWheelPos | Driver's seat:
     * **0** : Left rudder, that is, the driver's seat is on the left.
     * **1** : Right rudder, that is, the driver's seat is on the right .  
  
The following is an example of setting the control modes when initializing the HiCar SDK:
    
    CarConfig config;
    ......
    /* Driver seat */
    config.deviceInfo.steeringWheelPos = 0;
    ......
    int retCode = HiCarInit(&config);
