# DMSDPServiceStatus  
  
Enumerator | Description  
---|---  
PLUGIN = 1 | A device, such as a USB camera, is inserted.  
UNPLUG | A device, such as a USB camera, is removed.  
AVAILABLE | The device is available.  
UNAVAILABLE | The device is not available.
