# ChannelStateChange  
  
Function  
---  
void (*ChannelStateChange)(ChannelType channelType, EventType eventType, const void *data, int dataLen)  
Defines the callback function for channel status changes. The device interacts with the Nearby module through this callback function.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
channelType | [ChannelType](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/channel-type-0000001051652094) | Channel type.  
eventType | [EventType](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/event-type-0000001052492157) | Event type.  
*data | const void | Channel parameters.  
dataLen | int | Parameter length of a channel.
