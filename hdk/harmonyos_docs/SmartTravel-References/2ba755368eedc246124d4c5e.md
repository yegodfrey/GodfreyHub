# File Description  
  
Files Name | Files Description  
---|---  
hicar.h | Defines the app APIs integrated during HMI app development.  
HwRemoteControlEvent.h | Defines reverse control events, such as key events, knob events, and touchscreen events.  
dmsdp_errno.h | Defines the result codes of the HiCar SDK.  
bt_socket_wrapper.h | Defines the recommendation function after a Bluetooth connection is established.  
dmsdp_camera_handler.h | Defines the API for the HiCar SDK to call the camera hardware.  
dmsdp_camera_data_type.h | Defines the data type for the HiCar SDK to call the camera hardware.  
dmsdp_audio_handler.h | Defines the API for the HiCar SDK to call the audio hardware (speaker or microphone).  
dmsdp_audio_data_type.h | Defines the data type for the HiCar SDK to call the audio hardware.  
dmsdp_gps_handler.h | Defines the API for the HiCar SDK to call the GPS.  
dmsdp_business.h | Defines the API for the head unit to notify the HiCar SDK of related information.  
driver_adapt.h | Defines the API for the HiCar SDK to call the Wi-Fi, Bluetooth, or USB hardware.
