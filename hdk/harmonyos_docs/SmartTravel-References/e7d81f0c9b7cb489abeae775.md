# UpdateServiceAction  
  
Function  
---  
int32_t (*UpdateServiceAction)(const char *id, uint32_t idLen, DMSDPServiceAction *action)  
The head unit notifies the HiCar SDK of events such as audio focus change and adding a camera or audio device.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
*id | char | ID of the virtual device service, such as **speaker1**.  
idLen | uint32_t | Length of the virtual device service ID.  
*action | [DMSDPServiceAction](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-service-action-0000001051488196) | Type of the reported event, such as audio focus changes, or adding a camera or audio device.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
