# DMSDPAudioChannelMasks

Enumerator | Description  
---|---  
AUDIO_CHANNEL_OUT_MONO = 0x1u | The head unit's speaker output is mono.  
AUDIO_CHANNEL_OUT_STEREO = 0x3u | The head unit's speaker output is stereo.  
AUDIO_CHANNEL_IN_MONO = 0x10u | The head unit's microphone input is mono.  
AUDIO_CHANNEL_IN_STEREO = 0xCu | The head unit's microphone input is stereo.
