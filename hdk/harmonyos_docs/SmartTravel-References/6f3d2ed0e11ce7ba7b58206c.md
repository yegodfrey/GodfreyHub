# DeviceModelId  
  
Name | Type | Description  
---|---|---  
modelId[DEV_MODEL_ID_LEN] | unsigned char | Device model ID, which is the unique device identifier requested by the manufacturer from Huawei. According to the Nearby protocol, the length is 3 bytes.  
subModelId | unsigned char | Device sub-model ID, which is used to differentiate devices of the same model with different ID designs.  
subModelFlag | unsigned char | Indicates whether a device has a sub-model ID.
     * **1** : yes
     * **0** : no
