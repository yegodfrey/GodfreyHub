# updateCodecConfigureFlag (Beta)  
  
Method  
---  
CarConfig updateCodecConfigureFlag(int codecConfigureFlag)  
Updates the customized parameters of the head unit decoder.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
codecConfigureFlag | int | Customized configuration parameter of the decoder. This parameter is determined by the chip and does not need to be configured separately. Generally, the default value **0** is used.  
  
**Return**

Type | Description  
---|---  
CarConfig | Vehicle configuration.
