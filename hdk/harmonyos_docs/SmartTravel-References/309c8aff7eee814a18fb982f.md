# StopAdv

Function  
---  
int (*StopAdv)(const void *priv)  
Stops BLE advertising.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
*priv | const void | The void* is used to represent the structure differences of different device parameters. Currently, the priv parameter is not enabled and can be set to null.  
  
**Return**

Type | Description  
---|---  
int | Operation result.
     * **0** : success
     * Other values: failure
