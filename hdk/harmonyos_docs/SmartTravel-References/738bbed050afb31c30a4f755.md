# Converged Desktop App Operations

#### Scenario Overview

The head unit can obtain apps from HiCar and display the apps on its native screen. When a user touches one of these app icons, the head unit needs to interact with HiCar in the way preset by the HiCar SDK.

#### Data Type

529

#### API Version

1.0

#### API Definition

**Table 1** App operation APIParameter | Mandatory | Type | Description  
---|---|---|---  
RequestApp | Yes | object | Request data. For details, please refer to Table 2.  
RequestAppResp | Yes | object | Response data. For details, please refer to Table 3.  
  
**Table 2** RequestAppParameter | Mandatory | Type | Description  
---|---|---|---  
Action | Yes | string | Operation type:
     * **start** : start
     * **pause** : pause  
AppPackage | Yes | string | App package name.  
  
**Table 3** RequestAppRespParameter | Mandatory | Type | Description  
---|---|---|---  
RespCode | Yes | int | Response result:
     * **100000** : successful
     * **100001** : failed
     * **100002** : app not found  
AppPackage | Yes | string | App package name.  
Description | No | string | Description.  
  
#### API Examples

The sample code for the head unit to request the HiCar app to open an app is as follows:
    
    {
        "RequestApp" : {
            "Action" : "start",
            "AppPackage" : "com.android.mediacenter"
        }
    }

After receiving the request, the HiCar app responds as follows:
    
    {
        "RequestAppResp" : {
            "RespCode" : 100000,
            "AppPackage" : "com.android.mediacenter",
            "Description" : "success"
        }
    }
