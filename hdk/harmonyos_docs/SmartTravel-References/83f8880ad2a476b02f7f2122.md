# SetParamsType  
  
Enumerator | Description  
---|---  
SET_BLE_PARAMS | Sets the BLE parameters.  
SET_BR_UUID | Sets the BR service UUID.  
SET_WIFI_LOCAL_IP | Sets the IP address bound to the local WLAN0 network adapter.
