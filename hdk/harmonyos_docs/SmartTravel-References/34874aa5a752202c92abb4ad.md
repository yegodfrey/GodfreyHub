# RegisterListener  
  
Function  
---  
int32_t (*RegisterListener)(const DMSDPListener* listener)  
Registers a callback for audio device status changes and device behavior changes with the head unit.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
*listener | const DMSDPListener | Listener callback list.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : success
     * Negative value: failure
