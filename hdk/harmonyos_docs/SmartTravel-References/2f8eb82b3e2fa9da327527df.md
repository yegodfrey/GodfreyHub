# OpenCamera  
  
Function  
---  
int32_t (*OpenCamera)(const DMSDPCameraParam* param)  
Opens a specified camera to obtain the image in the specified format. The southbound API returns the address of the API implementation function.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
*param | const [DMSDPCameraParam](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-camera-param-0000001059166476#EN-US_TOPIC_0000001059166476) | Parameter object that specifies the camera to open.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : The camera is opened.
     * Other value: An exception occurs when opening the camera.
