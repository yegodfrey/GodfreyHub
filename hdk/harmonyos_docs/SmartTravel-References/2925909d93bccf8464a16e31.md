# GetHiCarHandle  
  
Function  
---  
void (*GetHiCarHandle)(HICAR_HANDLE handle)  
Obtains the HiCar operation handle, which will be used to send events and report data.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
handle | HICAR_HANDLE | HiCar operation handle.
