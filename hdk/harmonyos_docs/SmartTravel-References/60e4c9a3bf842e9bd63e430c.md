# RequestAudioFocus  
  
Function  
---  
int32_t (*RequestAudioFocus)(int32_t streamType, int32_t focusType);  
Requests focus from the head unit.  
  
**Parameters**

**Name** | **Type** | **Description**  
---|---|---  
streamType | int32_t | Audio stream type. For details, please refer to **DMSDPAudioStreamType**.  
focusType | int32_t | Audio focus type. For details, please refer to **DMSDPAudioFocus**.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : success
     * Negative value: failure
