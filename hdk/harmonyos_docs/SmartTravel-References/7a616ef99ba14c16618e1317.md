# getAdvPower (Beta)  
  
Method  
---  
int getAdvPower()  
Obtains the advertisement signal strength of the head unit.  
  
**Return**

Type | Description  
---|---  
int | Head unit broadcast signal strength. The value range is –128 to +127.
