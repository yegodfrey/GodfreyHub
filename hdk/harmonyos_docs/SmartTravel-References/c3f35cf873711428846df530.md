# CloseAudioTrack  
  
Function  
---  
int32_t (*CloseAudioTrack)(const char* id, uint32_t idLen, int32_t sessionId)  
Releases the audio playback device.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
*id | const char | Speaker ID.  
idLen | uint32_t | Length of the speaker ID.  
sessionId | int32_t | Session ID.  
  
**Return**

Type | Desc  
---|---  
int32_t | Operation result.
     * **0** : success
     * Negative value: failure
