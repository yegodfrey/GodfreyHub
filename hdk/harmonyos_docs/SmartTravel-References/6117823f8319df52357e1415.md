# HiCarNewObject  
  
Function  
---  
void* HiCarNewObject(HICAR_HANDLE handle, CarObjectType objType, uint32_t size)  
Create a service object based on the type of the HiCar service object. HiCar provides service object pools management to manage the frequent interaction with certain services, avoiding frequent memory allocation and release for service data and facilitating life cycle management. Currently, it is mainly used for reverse control services.  
  
**Name** | **Type** | **Description**  
---|---|---  
handle | HICAR_HANDLE | HiCar handle, which is obtained through **GetHiCarHandle**.  
objType | [CarObjectType](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/car-object-type-0000001051795144) | Object type.  
size | uint32_t | Object size.  
  
**Return**

Type | Description  
---|---  
void* | Operation result.
     * Non-NULL: The memory is successfully applied for and needs to be converted into the target object pointer.
     * NULL: The application for memory for the new object failed.
