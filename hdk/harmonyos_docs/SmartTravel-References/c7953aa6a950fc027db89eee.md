# ServiceUuidMapPort  
  
Name | Type | Description  
---|---|---  
serviceUuid[BT_SERVICE_UUID_LEN + 1] | char | Classic Bluetooth service UUID.  
port | int | Port number (also called channel ID) mapped to the classic Bluetooth service UUID, which needs to be obtained from the bottom-layer protocol stack.
