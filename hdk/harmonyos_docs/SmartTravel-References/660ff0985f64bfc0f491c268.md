# isSupportCarGpsDrivingStatusAbility  
  
Function  
---  
boolean isSupportCarGpsDrivingStatusAbility()  
Checks whether the vehicle status data (vehicle speed, steering angle, data time, mode, and wheel speed) can be obtained.  
  
**Return**

Type | Description  
---|---  
boolean | Returned result:
     * **true** : yes
     * **false** : no
Return **true** if any of the following data types can be obtained from the head unit and **false** otherwise: vehicle speed, steering angle, data time, mode, and wheel speed.
