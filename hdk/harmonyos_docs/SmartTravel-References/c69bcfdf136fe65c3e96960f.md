# getCarAudioRecordingStatus (Beta)  
  
Function  
---  
int getCarAudioRecordingStatus()  
The HiCar SDK uses the callback function, and the head unit app determines whether the head unit microphone can be used and returns the corresponding value based on the actual situation. Then the HiCar SDK determines whether to initialize **Audiorecord** based on the returned value.  
  
**Return**

Type | Desc  
---|---  
int | Availability status of the head unit microphone.
     * **0** : invalid
     * **1** : unavailable
     * **2** : available
