# getSupport5gChannels (Beta)  
  
Method  
---  
String getSupport5gChannels()  
Obtains the list of 5 GHz Wi-Fi channels supported by the head unit.  
  
**Return**

Type | Description  
---|---  
String | List of 5 GHz Wi-Fi channels supported by the head unit, for example, **[36,40,44,48,149]**.
