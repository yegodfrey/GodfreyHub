# DeviceChange  
  
Function  
---  
void (*DeviceChange)(const char* deviceId, uint32_t idLen, int state, int errorCode)  
Reports the HiCar device status.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
deviceId | char* | ID of the connected phone.  
idLen | uint32_t | Length of the phone ID.  
state | int | Device event type. For details, see [HiCarEvent](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/hicar-event-0000001052556437).  
errorCode | int | Result code.
