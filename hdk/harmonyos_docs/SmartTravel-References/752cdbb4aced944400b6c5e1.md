# Release  
  
Function  
---  
void (*Release)(int32_t type, void* ptr,uint32_t num)  
Releases resources of a specified type. For example, the type of the resource released after capability query is **RELEASE_TYPE_QUERY_ABILITY**.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
type | int32_t | Type of the resource to be released. For details, please refer to [DMSDPAudioReleaseType](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-audio-release-type-0000001051809206). Corresponds to **GetAudioCapability**.  
*ptr | void | Corresponds to **DMSDPAudioCapabilities* capabilities**.  
num | uint32_t | Quantity.
