# WriteStreamBuffer  
  
Function  
---  
int32_t (*WriteStreamBuffer)(const char* id, uint32_t idLen, int32_t sessionId, DMSDPVirtualStreamData* data)  
Plays the audio data. During the implementation of this API, pay attention to thread safety, as different threads may call this API.  
  
**Parameters**

**Name** | **Type** | **Description**  
---|---|---  
*id | const char | Speaker ID.  
idLen | uint32_t | Length of the speaker ID.  
sessionId | int32_t | Session ID.  
*data | [DMSDPVirtualStreamData](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/dmsdp-virtual-stream-data-0000001052609206) | Speaker data.  
  
**Return**

Type | Description  
---|---  
int32_t | Number of played audio bytes.
