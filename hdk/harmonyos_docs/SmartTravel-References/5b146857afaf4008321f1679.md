# RegisterGpsDataCallBack  
  
Function  
---  
int32_t (*RegisterGPSDataCallback)( DMSDPGPSCallback *callback)  
Requests GPS data from the head unit when the phone starts to use the location service. The head unit then registers the data backhaul API with the HMI app to obtain the basic GPS data, vehicle body data, and sensor data. Data collection is implemented by the vehicle manufacturers.  
  
**Parameters**

**Name** | **Type** | **Description**  
---|---|---  
*callback | DMSDPGPSCallback | Uploads the location information, vehicle body data, sensor data, and basic data (such as the vehicle brand and model) of the head unit. For details, please refer to [GPS Data Format Definition](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/gps-data-format-0000001053730837).  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : success
     * Negative value: failure
