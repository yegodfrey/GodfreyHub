# Physical Shortcut Buttons  
  
#### Scenario Overview

If the vehicle features physical buttons for navigation, contacts, and music, after HiCar connection is established, the user can press these physical buttons to open the map, contacts list, and music app of HiCar. However, the opened app cannot be specified. The map, contacts, or music app that is most recently used will be opened.

After detecting that a physical button on the head unit is pressed, the head unit reports corresponding data to the HiCar app.

#### Data Type

509

#### API Version

1.0

#### API Definition

**Table 1** API for physical button shortcutsParameter | **Mandatory** | Type | **Description**  
---|---|---|---  
KEYCODE | Yes | string | Physical shortcut button:
     * **NAVIGATION** : Physical navigation button.
     * **TEL** : Physical contacts button.
     * **MEDIA** : Physical music button.  
  
#### API Examples

Example: Press the physical navigation key to open a map app.
    
    {
        " KEYCODE":"NAVIGATION"
    }

Example: Press the physical contacts key to open a contacts app.
    
    {
        "KEYCODE":"TEL"
    }

Example: Press the physical music key to open a music app.
    
    {
        "KEYCODE":"MEDIA"
    }
