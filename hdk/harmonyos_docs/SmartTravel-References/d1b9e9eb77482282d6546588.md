# updateDefaultBitrate (Beta)  
  
Method  
---  
CarConfig updateDefaultBitrate(int defaultBitrate)  
Updates the default projection bit rate of the head unit.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
defaultBitrate | int | Default projection bit rate. The value must be greater than or equal to 500 x 1000.  
  
**Return**

Type | Description  
---|---  
CarConfig | Vehicle configuration.
