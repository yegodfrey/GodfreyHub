# getFocusGain  
  
Method  
---  
int getFocusGain()  
Obtains the focus type.  
  
**Return**

Type | Description  
---|---  
int | Audio focus type. For details, see the audio focus parameters of Google AudioManager. Example: **1** : Permanent focus, such as music. **2** : Transient focus, such as the call, notification, alarm, and instant message app. **3** : Duck focus, such as navigation. **4** : Exclusive and transient focus.
