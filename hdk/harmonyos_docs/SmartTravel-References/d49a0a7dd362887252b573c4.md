# GetSecureFileSize  
  
Function  
---  
int32_t (*GetSecureFileSize)(const char* fileName, uint32_t nameLen)  
Obtains the size of the HiCar authentication file.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
*filename | char | File name.  
nameLen | uint32_t | File name length.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **-1** : The file does not exist or an error occurred when obtaining the file.
     * Other values: Indicates the actual file size.
