# onInitFail  
  
Function  
---  
void onInitFail(int errCode)  
Indicates that the initialization failed. This callback is triggered after the initialization has timed out for 30s.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
errCode | int | Result code. For details, please refer to [HiCarConst](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/hicar-const-0000000000030396).
