# getDefaultAudioFormat (Beta)  
  
Method  
---  
int getDefaultAudioFormat()  
Obtains the default audio data output format.  
  
**Return**

Type | Description  
---|---  
int | Default audio data output format:
     * **0** : AAC
     * **1** : PCM
