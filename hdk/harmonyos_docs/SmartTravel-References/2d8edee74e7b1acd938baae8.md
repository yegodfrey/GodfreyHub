# DMSDPAudioFormats  
  
Enumerator | Description  
---|---  
AUDIO_FORMAT_PCM_16_BIT = 0x1u | The sampling resolution is 16 bits.  
AUDIO_FORMAT_PCM_8_BIT = 0x2u | The sampling resolution is 8 bits.  
AUDIO_FORMAT_PCM_32_BIT = 0x3u | The sampling resolution is 32 bits.  
AUDIO_FORMAT_PCM_24_BIT = 0x6u | The sampling resolution is 24 bits.
