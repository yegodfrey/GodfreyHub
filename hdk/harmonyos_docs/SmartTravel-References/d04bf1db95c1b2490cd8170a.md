# Result Codes  
  
The result codes for interaction between the HiCar app and the head unit comply with the following rules:

     * The code is a 6-digit decimal number.
     * The most significant bit is 1, which is reserved for future extension.
     * The second most significant two bits correspond to the data exchange type.
     * The three least significant bits indicate the error category in the specific data exchange type.

**Table 1** Response codeerrorCode | Description  
---|---  
100000 | Success  
100001 | The input parameter is invalid.  
100002 | User authorization has not been granted.  
100003 | The function is not supported.  
100004 | Executing the user intent failed.  
100999 | Unknown error.
