# HiCarGetPinCode  
  
Function  
---  
int32_t HiCarGetPinCode(uint8_t *pinCode, uint32_t maxLen)  
Obtains the PIN. After sending the broadcast, the HMI app obtains the PIN and displays it on the in-vehicle screen so that the user can enter the PIN on the phone for authentication. This API requires the head unit to support the function to obtain secure random numbers.  
  
**Name** | **Type** | **Description**  
---|---|---  
pinCode | uint8_t* | Buffer for receiving the PIN by a third party.  
maxLen | uint32_t | Maximum buffer length.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * Values larger than 0: Success, in which case the length of the PIN is returned as well. The current value is 6.
     * 0 or negative values: Failure.
