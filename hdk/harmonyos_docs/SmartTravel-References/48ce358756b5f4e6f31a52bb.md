# HiCarGetTrustDeviceList  
  
Function  
---  
int32_t HiCarGetTrustDeviceList(TrustPhoneInfo** list, uint32_t listLen)  
Obtains the list of devices that have been authenticated by the head unit.  
  
**Name** | **Type** | **Description**  
---|---|---  
list | [TrustPhoneInfo](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/trust-phone-info-0000001051636392) | List of devices (phones) that have been authenticated. Note: The memory allocated by the list must be consecutive. The list points to the start address of consecutive addresses. Input **& list**.  
listLen | int32_t | Length of the list, that is, the number of the authenticated devices.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * Negative value: The list failed to be obtained.
     * Other values: Indicates the length of the list.
