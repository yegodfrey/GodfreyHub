# updateAudioSourceConfig  
  
Method  
---  
Config updateAudioSourceConfig(Map<String, String> audioSourceConfig)  
Sets the **AudioSource** configuration table.  
  
**Return**

Type | Description  
---|---  
CarConfig | Vehicle configuration.  
  
**Parameters**

Parameter Name | Parameter Type | Parameter Description  
---|---|---  
audioSourceConfig | Map<String, String> | Configures the **AudioSource** parameter in **AudioRecord**. The default **AudioSource** table is as follows: MIC: 1 VOICE_COMMUNICATION: 7 You can set **MIC** and **VOICE_COMMUNICATION** to the required values. For example, set **MIC** to **2** and set **VOICE_COMMUNICATION** to **6**.
