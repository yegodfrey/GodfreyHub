# Low-fuel, Low-battery, and Low-tire-pressure States  
  
#### Scenario Overview

HiCar provides low-fuel, low-battery, and low-tire-pressure data for vehicle service apps to support service recommendation.

The head unit needs to proactively report the vehicle state data after HiCar is successfully connected, and update changes of state data.

#### Data Type

507

#### API Version

1.0

#### API Definition

**Table 1** API for low-fuel, low-battery, and low-voltage statesParameter | **Mandatory** | Type | Description  
---|---|---|---  
isOilEmpty | Yes | boolean | Whether the vehicle is low on fuel:
     * **true** : The vehicle is low on fuel.
     * **false** : The vehicle is not low on fuel.  
isBatteryLow | Yes | boolean | Whether the vehicle is low on battery:
     * **true** : The vehicle is low on battery.
     * **false** : The vehicle is not low on battery.  
isTpLow | Yes | boolean | Whether the tire pressure is low:
     * **true** : The tire pressure is low.
     * **false** : The tire pressure is not low.  
  
#### API Examples

#### [h2]Message Reported Once Connected to HiCar

Example: A vehicle powered by a diesel or gas engine reports the status information.
    
    {
        "isOilEmpty":false,
        "isTpLow":false
    }

Example: An electric vehicle reports the status information.
    
    {
        "isBatteryLow":false,
        "isTpLow":false
    }

#### [h2]Message Reported When Status Changes

Example: The head unit reports the low fuel information to the HiCar app.
    
    {
        "isOilEmpty":true
    }

Example: The head unit reports the low battery information to the HiCar app.
    
    {
        "isBatteryLow":true
    }

Example: The head unit reports the low tire pressure information to the HiCar app.
    
    {
        "isTpLow":true
    }
