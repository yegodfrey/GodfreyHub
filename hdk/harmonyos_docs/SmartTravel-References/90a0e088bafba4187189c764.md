# openAudioRecordCustom  
  
Function  
---  
int openAudioRecordCustom(int sessionId, int audioSource, int audioSampleRate, int channelMask, int format)  
Callback for the HiCar SDK to inform the HMI app to start recording, with the required recording specifications carried.  
  
**Parameters**

Parameter Name | Parameter Type | Description  
---|---|---  
sessionId | int | Recording ID.  
audioSource | int | **audioSource** information for the recording.  
audioSampleRate | int | Sampling rate required for the recording.  
channelMask | int | Number of channels required for the recording.  
format | int | Audio format required for the recording.  
  
**Return**

Type | Description  
---|---  
int | Whether the recording is successful:
     * **0** : The recording is successful. HiCar will obtain PCM data through **readStreamBuffer**.
     * **-1** : The recording fails. HiCar will automatically call the head unit's microphone for recording.
