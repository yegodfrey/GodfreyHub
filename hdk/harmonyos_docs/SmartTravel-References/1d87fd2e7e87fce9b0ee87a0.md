# onPinCode  
  
Function  
---  
void onPinCode(string pinCode)  
The HiCar SDK uses this callback to return the created PIN to the HMI. This PIN is required for authentication in the initial connection between the phone and the head unit.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
pinCode | string | PIN generated by the head unit.
