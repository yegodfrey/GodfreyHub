# sendData  
  
Function  
---  
int sendData(char *data)  
Called by the HiCar SDK to send data to the phone.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | Description  
---|---|---  
*data | char | Data to be transmitted.  
  
**Return**

Type | Description  
---|---  
int | Returned result:
     * **0** : success
     * Other values: failure
