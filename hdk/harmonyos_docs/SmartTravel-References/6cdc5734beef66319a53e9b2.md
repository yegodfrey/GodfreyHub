# VideoFrameInfo

Name | Type | Description  
---|---|---  
length | uint16_t | Total length of the frame information, including the structure to which pack points.  
screenRotation | uint8_t | Left rotation degree of the window.
     * **0** : positive
     * **90** : 90 degrees
     * **180** : negative
     * **270** : 270 degrees  
hasNavigationKey | uint8_t | Indicates whether the current frame carries the navigation key.  
pack[1] | char | Reserved for extended information.
