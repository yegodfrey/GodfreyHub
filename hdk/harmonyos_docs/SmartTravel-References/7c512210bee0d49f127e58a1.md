# Driver's Seat  
  
The driving position indicates whether the driver's seat of the vehicle is on the left or right. The HiCar app can adjust the UI layout based on the driving position, for example, displaying the dock area on the left or right.

After the head unit is started, the driving position should be reported during HiCar SDK initialization.

**Table 1** Key-value pair of the driver's seat during initializationValue | Type | **Description**  
---|---|---  
DRIVING_POSITION | String | Driver's seat:
     * **left** : The driver's seat is on the left (default).
     * **right** : The driver's seat is on the right.  
  
The following is an example:
    
    CarConfig.Builder builder = **new** CarConfig.Builder();
    Map<String, String> config = **new** HashMap<String, String>();
    config.put(**"DRIVING_POSITION"** ,  **"left"**);  
    builder.withInitialConfig(config);
