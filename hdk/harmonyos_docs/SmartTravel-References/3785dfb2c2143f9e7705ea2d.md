# GetAudioCapabilityString  
  
Function  
---  
const char* (*GetAudioCapabilityString)(uint32_t *len)  
Obtains the attributes of available audio devices (including speakers and microphones) in the form of JSON character string.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
*len | uint32_t | Length of the JSON character string of the audio capability (including speakers and microphones).  
  
**Return**

Type | Description  
---|---  
int32_t | Attributes of available audio devices (including speakers and microphones).
