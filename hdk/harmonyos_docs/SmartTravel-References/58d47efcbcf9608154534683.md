# getConnectionType  
  
Method  
---  
int getConnectionType()  
Obtains the connection mode.  
  
**Return**

Type | Description  
---|---  
int | Connection mode:
     * **4** : wireless connection
     * **5** : wired connection
     * **-1** : unknown
For details, please refer to [HiCarConst](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/hicar-const-0000000000030396).
