# HiCarStartBluetoothRecommend  
  
Function  
---  
int32_t HiCarStartBluetoothRecommend(const CarConfig *config)  
Starts RFCOMM listening on the Bluetooth interaction between the phone and the head unit, and recommends the use of HiCar once the interaction is complete.  
  
**Parameter Name** | **Parameter Type** | **Description**  
---|---|---  
config | CarConfig | Head unit configuration.  
  
**Return**

Type | Description  
---|---  
int32_t | API calling result:
     * **0** : success
     * Other values: failure
