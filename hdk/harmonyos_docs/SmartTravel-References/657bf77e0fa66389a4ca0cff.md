# DMSDPGetCameraHandler  
  
Function  
---  
int32_t DMSDPGetCameraHandler(DMSDPCameraHandler* cameraHandler)  
Obtains the function set implemented by the camera APIs, stored in the DMSDPCameraHandler structure.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
* cameraHandler | DMSDPCameraHandler | Pointer to the external input DMSDPCamearHandler structure, which is used to store the function pointers for implementing camera APIs. For details about each API pointer, see the following description.  
  
**Return**

Type | Description  
---|---  
int32_t | Operation result.
     * **0** : success
     * Other values: failure
