# Deinit  
  
Function  
---  
int (*Deinit)(const void *context)  
Releases driver resources, including disabling BLE advertising, BR connection, and Wi-Fi hotspot.  
  
**Parameters**

**Name** | **Type** | Description  
---|---|---  
*context | const void | Context structure. Currently, this parameter is disabled and can be set to null.  
  
**Return**

Type | Description  
---|---  
int | Operation result.
     * **0** : success
     * Other values: failure
