# onDeviceChange  
  
Function  
---  
void onDeviceChange(string deviceId, int state, int errorCode)  
HiCar SDK device event callback, mainly used to listen for the connection events between the phone and the head unit. The remote device ID and event type are carried in the event callback.  
  
**Parameters**

**Parameter Name** | **Parameter Type** | **Parameter Description**  
---|---|---  
deviceId | string | ID of the remote device. The upper-layer app saves the IDs of the remote device and device service based on the callback result. These IDs are used to distinguish the device or service during subsequent API calling. The reported device or device service ID is valid only in the current connection. They will become invalid immediately once the connection is disconnected.  
state | int | Device event type. The optional types defined in the HiCar SDK are as follows:
     * EVENT_DEVICE_CONNECT = 101;//The devices are connected to each other.
     * EVENT_DEVICE_DISCONNECT = 102;//The devices are disconnected from each other.
     * EVENT_DEVICE_CONNECT_FAILD= 103;//The device connection fails.
     * EVENT_DEVICE_PROJECT_CONNECT = 104;//The projection channel is set up.
     * EVENT_DEVICE_PROJECT_DISCONNECT = 105;//The projection channel is disconnected.
     * EVENT_DEVICE_ADV_START = 106;//Advertising starts.
     * EVENT_DEVICE_ADV_STOP = 107;//Advertising stops.
     * EVENT_DEVICE_MIC_REQUEST = 109;//Request to use the in-vehicle microphone.
     * EVENT_DEVICE_MIC_RELEASE = 110;//The in-vehicle microphone has been released.
     * EVENT_DEVICE_START_ADV_TIMEOUT = 124;//The advertising sending times out.  
errorCode | int | Result code. For details, please refer to [HiCarConst](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/hicar-const-0000000000030396).
