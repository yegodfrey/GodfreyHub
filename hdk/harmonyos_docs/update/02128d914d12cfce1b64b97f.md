# 1月  
  
#### 华为 HarmonyOS 手机/平板安全更新 - 2023年1月

本更新详细介绍了华为HarmonyOS手机/平板设备涉及的安全漏洞。对于华为手机/平板设备，如果安全补丁标签是 2023-01-01 或更高级别，就意味着已解决本公告以及 2023年1月的 HarmonyOS 安全公告中所述的所有问题。要了解如何查看设备的安全补丁标签和更新HarmonyOS版本，请参阅[安全更新](https://device.harmonyos.com/cn/docs/security/update/security-updates-0000001054170598)。

华为正在发布主要旗舰机型的月度安全维护版本，建议收到更新的用户都在自己的设备上接收这些更新。

#### 漏洞详情

下面提供了本次安全更新所有安全漏洞的详细信息，漏洞列在所影响的组件下，包含CVE、漏洞描述、漏洞影响、严重程度、受影响版本。

CVE | 漏洞描述 | 漏洞影响 | 严重程度 | 受影响版本  
---|---|---|---|---
