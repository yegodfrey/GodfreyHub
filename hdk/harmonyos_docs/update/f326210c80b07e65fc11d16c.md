# 9月  
  
#### 华为 HarmonyOS 穿戴设备安全更新 - 2023年9月

本更新详细介绍了华为HarmonyOS穿戴设备涉及的安全漏洞。对于华为穿戴设备，如果安全补丁标签是 2023-09-01 或更高级别，就意味着已解决本公告以及 2023年9月的 HarmonyOS 安全公告中所述的所有问题。要了解如何查看设备的安全补丁标签和更新HarmonyOS版本，请参阅[安全更新](https://device.harmonyos.com/cn/docs/security/update/security-updates-0000001054170598)。

华为正在发布主要穿戴设备的月度安全维护版本，建议收到更新的用户都在自己的设备上接收这些更新。

#### 漏洞详情

下面提供了本次安全更新所有安全漏洞的详细信息，漏洞列在所影响的组件下，包含CVE、漏洞描述、漏洞影响、严重程度、受影响版本。
