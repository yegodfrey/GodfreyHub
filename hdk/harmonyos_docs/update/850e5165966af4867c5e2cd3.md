# 安全更新  
  
HarmonyOS安全团队负责管理在HarmonyOS系统中发现的安全漏洞。HarmonyOS安全团队会通过内部安全研究找出安全漏洞，并会对外部上报的漏洞采取应对措施。

如果您或您的团队发现HarmonyOS系统中存在安全或隐私的问题，请参考[HarmonyOS安全奖励计划](https://device.harmonyos.com/cn/docs/security/HarmonyOS_Security_Bounty_Program/oem_security_plans-0000001115856754)提交报告。

#### 常见问题

#### [h2]如何查看手机/平板/手表的HarmonyOS 版本和安全补丁标签。

1、打开设备的“设置”应用。

2、点击底部附近的“关于手机”/“关于平板电脑”/“关于”。

3、查看您的“HarmonyOS 版本”和“安全补丁标签”。

#### [h2]如何更新手机/平板/手表的HarmonyOS版本。

1、打开设备的“设置”应用。

2、依次点击底部附近的“系统和更新”，然后点击顶部附近的“软件更新”。

3、您会看到系统的更新状态，按照屏幕上提示的步骤操作。

#### [h2]如何反馈HarmonyOS系统中存在的安全或隐私以外的问题。

HarmonyOS 系统中存在的安全或隐私以外的问题请前往[华为官方客户服务-服务支持](https://consumer.huawei.com/cn/support/)反馈。
