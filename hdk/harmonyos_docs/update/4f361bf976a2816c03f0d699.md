# 4月  
  
#### HarmonyOS 安全补丁公告 - 2024年4月

本 HarmonyOS 安全公告详细介绍会影响 HarmonyOS 设备的安全漏洞。安全补丁标签为**2024-04-0 1**或更新的 HarmonyOS 系统已解决了本公告中所述的所有问题。

如果您发现了 HarmonyOS 系统中存在安全或隐私漏洞，请参考[HarmonyOS安全奖励计划](https://device.harmonyos.com/cn/docs/security/HarmonyOS_Security_Bounty_Program/oem_security_plans-0000001115856754)提交报告。

#### HarmonyOS 安全缓解措施

[安全指南](https://device.harmonyos.com/cn/docs/documentation/guide/security-guidelines-overall-0000001050032745)总结了 HarmonyOS 系统提供的缓解措施。这些功能有助于降低 HarmonyOS 系统上的安全漏洞被成功利用的可能性。

较高版本的 HarmonyOS 系统中提供的安全增强功能让攻击者更加难以利用 HarmonyOS 系统上存在的问题，建议用户都尽可能升级到最新版本 HarmonyOS 。
