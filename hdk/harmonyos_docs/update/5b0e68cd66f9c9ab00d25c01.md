# 安全公告  
  
定期为HarmonyOS设备发布安全更新是确保安全的重要举措，本页面列举了我们已发布的HarmonyOS安全公告，公告针对可能会影响HarmonyOS安全的问题提供了修复程序。如果您发现了HarmonyOS中存在安全或隐私漏洞，请参考[HarmonyOS安全奖励计划](https://device.harmonyos.com/cn/docs/security/HarmonyOS_Security_Bounty_Program/oem_security_plans-0000001115856754)提交报告。
