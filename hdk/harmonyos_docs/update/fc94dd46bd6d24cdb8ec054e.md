# 安全公告

#### 关于华为手机/平板安全更新

     * 华为将发布下列所选设备的月度和季度安全更新。
     * 每月度和每季度的安全更新包括 HarmonyOS 安全问题补丁，以及华为手机/平板特有安全问题的补丁。
     * 尽管华为尽最大努力将安全补丁合入到对应型号设备上，但安全补丁的交付时间可能会因地区和型号而异。

如果您或您的团队发现 HarmonyOS 系统中存在安全或隐私的问题，请参考[HarmonyOS安全奖励计划](https://device.harmonyos.com/cn/docs/security/HarmonyOS_Security_Bounty_Program/oem_security_plans-0000001115856754)提交报告。

如果您或您的团队发现 HarmonyOS 系统中存在安全或隐私以外的问题，请前往[华为官方客户服务-服务支持](https://consumer.huawei.com/cn/support/)反馈。
