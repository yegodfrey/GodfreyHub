在应用测试阶段，您可以在AppGallery Connect中配置测试帐号，并设置允许这些帐号执行沙盒测试。沙盒测试可以测试如下场景：

  * 帐号登录测试。

  * 商品支付测试：包括非消耗商品、消耗商品、自动续费订阅型商品支付，联调过程中无需真实支付即可完成端到端的测试。

  * 游戏成就测试。




注意：

目前沙盒测试功能只支持集成 HMS SDK 3.0版本的应用，并且测试设备必须安装3.0以上HMS Core（APK）。如果使用HMS SDK 2.0版本的支付接口测试仍将导致真实的扣费。

# 1\. 创建测试帐号

在进行测试前，如果当前还未创建测试帐号，需要先创建测试帐号，具体操作请参考[管理测试帐号](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-tester_account_mgt)。

# 2\. 测试非订阅型商品支付

您可以在设备上登录已配置的测试帐号，并安装该待测试应用。发起普通商品（非订阅型商品）购买时，华为IAP会检测到该用户为测试用户，跳过实际支付环节，直接支付成功。在测试过程中，请注意以下几点：

  * 沙盒测试场景下的购买流程与正式环境的购买流程一致。

  * 华为IAP购买成功后的收据信息中，会携带值为0的purchaseType字段，标识此次购买为沙盒测试的记录。

  * 沙盒环境下创建普通商品订单，本质是创建一个已经完成了的支付订单，所以即使中途取消还是会成功购买这个商品。

  * 沙盒环境下购买非消耗型商品，购买之后可以执行消耗，之后可以再次购买，以方便测试。

  * 沙盒测试拉起收银台时会弹出沙盒标志的弹框，收银台和成功页均有沙盒标志。




# 3\. 测试订阅型商品支付

订阅商品的购买流程和普通商品的购买流程类似，但订阅还有其他细节场景，比如续订成功或失败，续订周期时长。为了帮助您快速测试您应用的订阅场景，沙盒环境下的订阅续订时间会比正常情况更快，引入“**时光机** ”概念。“**时光机** ”仅针对订阅商品的续期时间，不影响订阅商品的生效时间（比如订阅周期为1周，商品在3分钟后发生续期，此时订阅商品有效期延长了1周）。

**实际时限**| **测试时限**  
---|---  
1周| 3分钟  
1个月| 5分钟  
2个月| 10分钟  
3个月| 15分钟  
6个月| 30分钟  
1年| 1小时  
  
在测试过程中，请注意以下几点：

  * 沙盒环境下发起订阅时仍需要完成**签约或绑卡** ，但该过程不会真实扣费。

  * 自动续期处理不需要完成真实扣款，华为IAP会直接返回成功。

  * 沙盒场景下的自动续期最多持续6次。

  * 沙盒测试拉起收银台时会弹出沙盒标志的弹框，收银台和成功页均有沙盒标志。建议沙盒场景下订阅续期处理和正式环境下订阅区分开，减少测试订单数据对正式订单数据的干扰。




# 4\. 测试游戏功能

游戏未正式上架前，可以使用测试帐号登录游戏并测试游戏中的成就、排行榜、存档，在测试时需注意：由于成就、排行榜数据会随着测试帐号的游戏操作发生变化，而成就、排行榜发布后将无法重置成就，因此测试阶段请勿发布。

另外，应用助手展示成就、排行榜、存档的功能必须在应用上架后才能正常展示，并且只能在EMUI 9.0及以上且安装了10.3及以上版本应用助手的终端设备上展示。
