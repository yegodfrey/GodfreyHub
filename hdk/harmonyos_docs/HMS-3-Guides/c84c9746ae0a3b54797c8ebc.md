# 1.场景介绍

华为Push Kit将消息推送到用户之后，会将消息送达状态以回执消息形式发送到开发者应用回执服务器。目前只支持安卓应用消息。

开发者可以基于接收到的消息回执进行消息数据统计和分析，目前以下消息状态会有回执消息。

**回执状态码**| **状态码描述**| **详细解释**  
---|---|---  
0| 成功| NA  
2| 应用已卸载| 需安装应用  
5| 消息推送的目标用户Push token在用户手机本地不存在| 需重新安装应用  
6| 通知栏消息不展示| 请排查以下三种原因：

  * 开发者在App中调用Push Kit的turnOffPush设置了不显示通知栏消息；
  * 用户关闭了设备上的系统通知栏总开关；
  * 用户关闭了本App的通知栏渠道开关；

  
10| 消息丢弃标识| 为非活跃设备，消息丢弃  
15| 离线消息替换| 离线缓存消息被覆盖，未下发  
27| 收到App的Push透传消息，拉起服务失败本地缓存| NA  
102| 消息频控丢弃| 单一设备推送消息超过限制，消息丢弃。频控策略，单个设备每天最多3000条。  
201| 无效消息发送管控| 重新安装应用并打开  
  
**建议：**  


对上述状态中的2、5、6、10、201做过滤处理，减少对这些用户的无效推送。

# 2.开发准备

## 2.1 开通回执权益

1、登录 [AppGallery Connect 网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) ，选择“我的应用”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191218121450.11263331773282441066356013857002:50510115015056:2800:2099B2C81CDDC13910C2107928B3B14D4BD19CCBA122EB8F79B768222A483B59.png)                           

2、选择需要开通服务的应用所属产品的名称，进入应用信息页面。

3、点击“开发”页签，左侧导航选择“增长服务 > 推送服务”。

4、点击“开通”，配置推送服务的状态。开通服务后，可以选择是否开通回执。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191218121506.28736410617182857634290740085628:50510115015056:2800:983A77C7FAD0143868CD126F5F54671996D6B850C7F53A7C8CE5A31D59E985C7.png)

## 2.2 回执参数配置

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191218121517.97790519092087006029069089359659:50510115015056:2800:0B5D615236875DB13E2FF23BDBDC485B715DE77B1FE6531B1110979CFE50BC2A.png)

1、配置消息回执的回调地址，您的回执消息接收url。

2、配置https证书。

**注意：** 目前华为PUSH服务器和接收回执消息的APP服务器之间走的是HTTPS协议，华为PUSH服务器会校验APP服务器提供证书的合法性，请APP服务器务必使用正式商用的HTTPS证书。

3、配置回调用户名和回调密钥（非必填）进行身份验证。

4、点击“测试回执”可以对回执地址进行功能测试，测试通过点击“提交”完成服务的开通。

**场景描述：**

调用服务端发送Push消息接口进行消息推送时，设置bi_tag，消息回执时会返回给开发者的应用服务器，这样可以通过识别bi_tag对消息的推送情况进行统计分析，[请参考服务端发送Push消息API](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/push-server-send)。
