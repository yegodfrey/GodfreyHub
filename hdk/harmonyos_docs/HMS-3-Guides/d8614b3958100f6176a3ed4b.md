# 自检工具

华为提供对应用自动检查的能力。您只需填写应用相关信息、上传APK包，平台将自动扫描APK并输出自检报告。您可以根据自检报告改进应用，自检通过即可提交应用上架，是您上架应用的好帮手。

1、登录 [AppGallery Connect 网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择“我的应用”。

2、 在产品列表中展开应用所在的产品，点击应用名称。

                                              ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191130182914.99770621242411419293587112075437:50501203090313:2800:3D0780225EE395AF62DF5308280961B1F70869C07BA7D109A12C1AD11F634BB2.png)

3、选择“开发”页签，在左侧导航栏选择“开发资源 > 接入检测”，点击“创建自检”.

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191130182914.66505040496741875334430735991667:50501203090313:2800:5865A1804474B254D07D0D1EDB131A94E8687F6D7C560099A86E40DBBFED2E8F.png)

4、确认应用信息已填写正确后，点击“提交”。

− 如果“应用介绍”、“应用简介”、“应用分类”、“付费情况”、“分发国家”未自动同步已设置的应用信息，请根据实际情况补充填写。

− 可单击“浏览”按钮上传需要自检的APK软件包。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191130182914.80615033620360024513797653633859:50501203090313:2800:FC56B06BCF36F5E24F2925D42C50F18B666EB94D6554884FB6FACCF3440B8CDF.png)

5、创建自检成功后会在检测记录列表中展示检查结果，点击“查看报告”可以查看检测结果。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191130182914.92248595811975185646066328266163:50501203090313:2800:C0FDD11C1531879F0A0B58B0204DF718A6E7C9FFEBE283AF708FC3896CAEE7D7.png)
