# 1\. 自检工具

华为提供对应用自动检查的能力。您只需填写应用相关信息、上传APK包，平台将自动扫描APK并输出自检报告。您可以根据自检报告改进应用，自检通过即可提交应用上架，是您上架应用的好帮手。

自检步骤请参考AppGallery Connect帮助中心：[自检应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-auto_check)

注意：

目前新版自检工具需要在AppGallery Connect实名认证过的企业或者个人的帐号才可以使用。
