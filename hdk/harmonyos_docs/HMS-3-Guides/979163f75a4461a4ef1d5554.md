# 指定权限

在调用Scan Kit时，开发者需要先在Manifest中指定相应的权限。Android提供了两种扫码权限：“ CAMERA”（相机权限） 和“READ_EXTERNAL_STORAGE”（读文件权限）。
    
    
    复制
      
        1. <!--相机权限 --> 
        2. <uses-permission android:name="android.permission.CAMERA" />  
        3. <uses-feature android:name="android.hardware.camera" />  
        4. <!--读文件权限 --> 
        5. <uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE"/>
    
    

在Manifest中指定权限后，还需要在代码中动态申请一下权限:
    
    
    复制
      
        1. //CAMERA_REQ_CODE为用户自定义，用于接收权限校验结果 
        2. ActivityCompat.requestPermissions(this,new String[]{Manifest.permission.CAMERA, Manifest.permission.READ_EXTERNAL_STORAGE},CAMERA_REQ_CODE);
    
    

# Default View调用方式

## 1 业务流程

使用Default View调用方式的主要业务流程如下：

1、用户打开应用发起扫码申请。

2、校验是否有相机权限和文件读取权限。

3、权限验证通过后，调用HMS SDK的“startScan”扫码接口，返回扫码状态。

4、 HMS SDK回调应用的“onActivityResult”接口传递扫码结果。

5、 应用封装扫码结果返回给用户。

## 2 开发步骤

1、在调用模块中的清单文件中进行声明。
    
    
    复制
      
        1. <activity  android:name="com.huawei.hms.hmsscankit.ScanKitActivity"   
        2.            android:screenOrientation="portrait"/>
    
    

2、根据实际需求创建扫码选项参数。如果您能确定读取条形码格式，可以将条形码检测器配置为仅检测这些格式，提高条形码检测器的速度。以下样例中设置FORMAT_QR_CODE表示只支持QR码的识别。
    
    
    复制
      
        1. HmsMLVisionScanDetectorOptions options = newHmsMLVisionScanDetectorOptions.Builder().setBarcodeFormats(HmsMLVisionScan. FORMAT_QR_CODE).build()；
    
    

3、 调用“ScanUtil”的静态方法“startScan”方法发起扫码请求。“REQUEST_CODE_SCAN”为开发者设置的请求码，用于接收回调结果。
    
    
    复制
      
        1. ScanUtil.startScan(this, REQUEST_CODE_SCAN, options);
    
    

4、实现回调接口接收扫码结果。
    
    
    复制
      
        1. @Override 
        2.     protected void onActivityResult(int requestCode, int resultCode, Intent data) { 
        3.         super.onActivityResult(requestCode, resultCode, data); 
        4.         if (resultCode == RESULT_OK && data != null && requestCode == REQUEST_CODE_SCAN) { 
        5.             Object obj = data.getParcelableExtra(ScanUtil.RESULT); 
        6.             if (!TextUtils.isEmpty(((HmsMLVisionScan) obj).rawValue)) { 
        7.                 Toast.makeText(this, ((HmsMLVisionScan) obj).rawValue, Toast.LENGTH_SHORT).show(); 
        8.             } 
        9.         } 
        10.     }
    
    

# Customized View调用方式

## 1 业务流程

使用Customized View调用方式的主要业务流程如下：

1、用户打开应用发起扫码请求。

2、校验是否有相机权限和文件读取权限。

3、初始化应用定制的view，触发扫码检测。

4、HMS SDK回调应用的“onResult”接口传递扫码结果。

# Bitmap API调用方式

## 1 业务流程

使用Bitmap API调用方式的主要业务流程如下：

1、用户打开应用发起扫码请求。

2、校验是否有相机权限和文件读取权限。

3、权限验证通过后，调用HMS SDK的“decodeWithBitmap”扫码接口，返回扫码结果。

4、应用封装扫码结果返回给用户。

1、获取相机数据。
