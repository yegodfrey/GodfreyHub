沙盒测试允许您在接入华为应用内支付联调过程中无需真实支付即可完成端到端的测试，您可以在AppGallery Connect中配置测试帐号，并设置允许这些帐号执行沙盒测试。

说明：

目前沙盒测试功能只支持集成 HMS SDK 3.0及以上版本 的应用，并且测试设备必须安装3.0以上华为移动服务（APK）。如果使用 HMS SDK 2.0版本的支付接口测试仍将导致真实的扣费。

# 配置沙盒测试环境

● 设置测试帐号

在进行测试前，您需要在AppGallery Connect中用户与访问添加测试帐号，这些测试帐号都是真实的华为帐号。具体参考[测试帐号管理](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-tester_account_mgt)。

说明：

添加沙盒测试帐号之后需要30min~1h才能生效。使用时请检查当前的帐号是否支持沙盒测试。

●  配置沙盒测试版本

如果您的测试包此前没有上架过版本，只需要确保其版本大于0；如果已有上架的版本，则测试包的版本需要大于上架版本。

# 测试非订阅型商品支付

您可以在设备上登录已配置的测试帐号，并安装该待测试应用。发起普通商品（非订阅型商品）购买时，华为IAP会检测到该用户为测试用户，跳过实际支付环节，直接支付成功。

● 沙盒测试场景下的购买流程与正式环境的购买流程一致。

● 华为IAP购买成功后的收据信息中，会携带值为0的purchaseType字段，标识此次购买为沙盒测试的记录。

注意：

● 沙盒环境下创建普通商品订单，本质是创建一个已经完成了的支付订单，所以即使中途取消还是会成功购买这个商品。

● 沙盒环境下购买非消耗型商品，购买之后可以执行消耗，之后可以再次购买，以方便测试。

●  沙盒测试拉起收银台时会弹出沙盒标志的弹框，收银台和成功页均有沙盒标志。

# 测试订阅商品续订

订阅商品的购买流程和普通商品的购买流程类似，但订阅还有其他细节场景，比如续订成功或失败，续订周期时长。为了帮助您快速测试您应用的订阅场景，沙盒环境下的订阅续订时间会比正常情况更快，引入“**时光机** ”概念。“**时光机** ”仅针对订阅商品的续期时间，不影响订阅商品的生效时间（比如订阅周期为1周，商品在3分钟后发生续期，此时订阅商品有效期延长了1周）。

实际时限                | 测试时限                  
---|---  
1周                | 3分钟                  
1个月                | 5分钟                  
2个月                | 10分钟                  
3个月                | 15分钟                  
6个月                | 30分钟                  
1年                | 1小时                  
  
 

沙盒环境下发起订阅时仍需要完成**签约或绑卡** ，但该过程不会真实扣费。

自动续期处理不需要完成真实扣款，华为IAP会直接返回成功。

沙盒场景下的自动续期最多持续6次。

沙盒测试拉起收银台时会弹出沙盒标志的弹框，收银台和成功页均有沙盒标志。
