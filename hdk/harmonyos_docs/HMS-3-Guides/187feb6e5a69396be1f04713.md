# 1\. AppGallery Connect配置  
  
在开始开发应用前，需要在AppGallery Connect中配置相关信息。

## 1.1 注册成为开发者

在开发应用前需要在华为开发者联盟网站上注册成为开发者并完成实名认证，具体方法可参考[帐号注册认证](https://developer.huawei.com/consumer/cn/doc/20300 "帐号注册认证")。

## 1.2 创建应用

参见AppGallery Connect帮助中心的[创建应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/50102 "创建应用")章节创建应用。

  * “软件包类型”：必须选择“APK(Android应用)”。

  * “支持设备”：必须选择“手机、平板”。

  * “应用包名”：必须与最终发布的APK包名一致。

  * “应用分类”：选择“应用”或“游戏”。




# 2\. 集成Ads Kit SDK

注意：

当您下载或使用下述Kits组件时，您应当确认同意[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/devservice/doc/20201)、[《华为APIs使用协议》](https://developer.huawei.com/consumer/cn/doc/distribution/app/20209)以及该表格中与您使用的Kits相对应的应当签署的协议，否则您不得下载或使用相应Kits组件。您理解并承诺，您的下载或使用相应Kits的行为，视为您同意前述所有协议，且您将基于这些协议承担相应的法律责任与义务。

开发者接入华为广告服务时，可根据需要集成如下其中1个或2个SDK:

  1. ads-identifier sdk：获取OAID和“限制个性化广告”开关

  2. ads-installreferrer sdk：获取转化跟踪参数




开发者可以配置maven仓地址自动下载Ads Kit SDK，不需要手工下载，配置步骤如下：

## 步骤1 配置HUAWEI Ads SDK的maven仓地址

打开AndroidStudio项目级build.gradle文件，在allprojects ->repositories里面配置SDK的maven仓地址。

## 步骤2 配置依赖

打开子工程app下的build.gradle文件，在dependencies新增SDK的依赖。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200115091703.11580755179676027185663155237121:50510721115105:2800:86AC630AACDB5A8B8C156A2EB9E2FA32B06C1AFA1D3D1BFBD973D19C00F216EA.png?needInitFileName=true)
      
      1. dependencies {
        2.   implementation 'com.huawei.hms:ads-identifier:3.4.28.305'
        3.   implementation 'com.huawei.hms:ads-installreferrer:3.4.28.305'
        4. }
    
    

**说明：**

可以根据需要选择依赖的SDK。

如果需要获取OAID和“限制个性化广告”开关， 仅仅依赖com.huawei.hms:ads-identifier即可。

如果需要获取转化跟踪参数，仅仅依赖com.huawei.hms:ads-installreferrer即可。
