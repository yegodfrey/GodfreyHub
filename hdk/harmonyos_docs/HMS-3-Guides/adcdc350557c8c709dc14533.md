# 1.业务简介

华为帐号为开发者提供了简单、安全的登录授权功能，方便用户快捷登录。用户不必输入帐号、密码和繁琐验证，就可以通过“华为帐号登录”快速登录，即刻使用开发者的 app。

# 2.服务特点

## **2.1 接入方便，规范统一**

服务手机、平板、大屏等全场景生态，接入规范统一，方便开发者接入华为生态；

## **2.2 海量用户，全球化服务**

服务全球[190+国家和地区](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/account-countrycode)，支持[70+种语言](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/hmssdk_language)，用户达5亿+规模，用户可快速登录开发者应用；

## **2.3 安全可靠，遵循国际标准**

遵循OAuth2.0和OpenID connect等国际标准协议, 具备高安全性密码验证和手机号验证双因素认证能力。

# 3.服务场景

## **快捷登录应用**

终端用户可以使用华为帐号登录应用，首次登录应用需要用户授权确认，后续即可一键登录。且帐号实现全场景生态，一个帐号即可登录所有应用。
