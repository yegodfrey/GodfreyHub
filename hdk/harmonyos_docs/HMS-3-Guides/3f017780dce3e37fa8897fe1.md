本章节主要介绍接入华为PUSH的准备步骤，以帮助开发者更快速的完成华为推送服务（HUAWEI Push Kit）的接入。

必备步骤主要包括：

1、AppGallery Connect配置

2、集成HMS SDK

3、配置manifest.xml文件

4、配置混淆脚本

# 1\. AppGallery Connect配置

在开始开发应用前，需要在AppGallery Connect中配置相关信息。

## 1.1 注册成为开发者

在开发应用前需要在[华为开发者联盟](https://developer.huawei.com/consumer/cn)网站上注册成为开发者并完成实名认证，具体方法可参考“[帐号注册认证](https://developer.huawei.com/consumer/cn/devservice/doc/20300)”。

## 1.2 创建应用

参见AppGallery Connect帮助中心的[创建应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-create_app)章节创建应用并上传一个临时APK包，配置如下：

  * “软件包类型”：选择“APK(Android应用)”或者“RPK(快应用)”

  * “支持设备”：选择“手机”

  * “应用分类”：选择“应用”或者“游戏”




注意：

临时APK包用于AppGallery Connect读取应用包名，因此临时APK包的包名必须是最终要发布的应用的APK包名。

  


## 1.3 生成签名证书指纹

签名证书指纹用于在通过华为HMS SDK调用HMS Core service时，校验应用的真实性。开发者在使用HMS Core service前必须将签名证书指纹配置到AppGallery Connect的，在配置前需要根据签名证书在本地生成签名证书指纹。

在申请前需要满足以下2个条件：

  * 已创建应用程序的签名文件，签名证书创建可参考[生成签名证书](https://developer.huawei.com/consumer/cn/codelab/HMSPreparation/index.html#3)。

  * 当前开发的PC已经安装JDK。




操作步骤如下：

1\. 打开命令行工具（使用CMD命令），执行cd命令进入keytool.exe所在的目录（图中样例为PC上java程序安装在C盘的Program Files (x86)目录）。

2\. 执行命令**keytool -list -v -keystore** _< keystore-file>_，按命令行提示进行操作。

## 1.4 配置签名证书指纹

1\. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，选择“我的应用”。

2\. 点击应用名称进入应用开发页面。

3\. 在“开发 > 概览”页面的“应用”区域，将“SHA256证书指纹”配置为生成签名证书指纹步骤中生成的SHA256指纹。

## 1.5 设置数据存储位置

开发者使用Push Kit需要[设置数据存储位置](https://developer.huawei.com/consumer/cn/doc/development/app/agc-data-storage-location)，如果不设置，基于主题的发送功能将不可用。

## 1.6 打开相关服务

a. 打开PUSH服务开关

具体操作步骤请参见[打开服务开关](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-enable_service#enable-service)

b. 配置推送服务参数

具体操作步骤请参见[配置推送服务参数](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-enable_service#set-push-param)

# 2\. 集成HMS SDK

具体操作步骤请参见[集成HMS SDK](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Library/push-sdk-integrate)

# 3\. 配置manifest.xml文件

集成最新的HMS Core Push SDK版本后要在AndroidManifest.xml文件的application节点下参照以下步骤注册Service，用于接收华为推送的消息与令牌。

● 注册YourHmsMessageService

YourHmsMessageService类需要开发者自己定义，继承于com.huawei.hms.push.HmsMessageService类并实现其中的方法。
      
      1. <service
        2.       android:name=".YourHmsMessageService"
        3.       android:exported="false">
        4.       <intent-filter>
        5.             <action android:name="com.huawei.push.action.MESSAGING_EVENT" />
        6.       </intent-filter>
        7. </service>
    
    

注意：

exported属性需要设置为false。

● 注册HmsMsgService
      
      1. <service
        2.     android:name="com.huawei.hms.support.api.push.service.HmsMsgService"
        3.     android:enabled="true"
        4.     android:exported="true"
        5.     android:process=":pushservice">
        6.     <intent-filter>
        7.         <action android:name="com.huawei.push.msg.NOTIFY_MSG" />
        8.         <action android:name="com.huawei.push.msg.PASSBY_MSG" />
        9.     </intent-filter>
        10. </service>
    
    

注意：

开发者集成Push SDK版本低于**3.0.3.301** 必须注册该Service。3.0.3.301版本及之后版本不需要注册。

  


# 4\. 配置混淆脚本

开发者编译APK前需要配置不要混淆HMS SDK，避免功能异常。

1\. 打开Android工程的混淆配置文件。

2\. 加入排除HMS SDK的混淆配置。
      
      1. -ignorewarnings
        2. -keepattributes *Annotation* 
        3. -keepattributes Exceptions 
        4. -keepattributes InnerClasses 
        5. -keepattributes Signature 
        6. -keepattributes SourceFile,LineNumberTable 
        7. -keep class com.hianalytics.android.**{*;} 
        8. -keep class com.huawei.updatesdk.**{*;} 
        9. -keep class com.huawei.hms.**{*;}
    
    

3\. 如果开发者使用了AndResGuard，需要在混淆配置文件中加入AndResGuard允许清单。
      
      1. "R.string.hms*",
        2. "R.string.connect_server_fail_prompt_toast",
        3. "R.string.getting_message_fail_prompt_toast",
        4. "R.string.no_available_network_prompt_toast",
        5. "R.string.third_app_*",
        6. "R.string.upsdk_*",
        7. "R.layout.hms*",
        8. "R.layout.upsdk_*",
        9. "R.drawable.upsdk*",
        10. "R.color.upsdk*",
        11. "R.dimen.upsdk*",
        12. "R.style.upsdk*",
        13. "R.string.agc*"
