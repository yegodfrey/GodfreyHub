# 1\. 登录华为帐号

## 1.1 场景介绍

华为帐号是用户访问华为云业务的凭证，拥有华为帐号的用户，可以使用华为云业务，如华为云服务、华为游戏中心、华为应用市场等。

华为帐号登录是指基于[OAuth2.0协议标准](https://oauth.net/2/)和[OpenID Connect协议](https://openid.net/connect/)，第三方应用可以获取华为帐号用户身份认证信息(ID Token)或用户的临时授权票据(Authorization Code)，用于用户使用华为帐号安全登录第三方应用。Authorization Code模式仅适用于有自己服务器的应用，ID Token模式同时适合单机应用和有自己服务器的应用。开发者可根据实际情况选择其中一种模式实现。

本章节主要介绍使用ID Token模式登录华为帐号的开发步骤。

## 1.2 业务流程

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200117155045.11971418883073843291097631290263:50510324064420:2800:875F97F3101772A410A95D01113F59AC3E196989FFF2BC4486F887024ECD7104.png)

整体流程：

1、用户选择华为帐号登录方式登录应用。

2、应用向HUAWEI Account SDK发起登录请求。

3、华为帐号拉起用户登录授权界面，界面上会根据登录请求中携带的授权域(scope)信息， 显式告知用户需要授权的内容。

4、用户确认允许授权后，华为帐号返回ID Token信息。

5、应用选择使用本地方式验证或华为帐号服务器方式验证ID Token，具体说明参见验证ID Token有效性。

## 1.3 开发步骤

    复制

        2. new HuaweiIdSignInOptions.Builder(HuaweiIdSignInOptions.DEFAULT_SIGN_IN).requestIdToken("").build();

### **1.3.2 验证ID Token有效性**

● 方式1：本地验证

1、从<https://oauth-login.cloud.huawei.com/.well-known/openid-configuration>中的jwks_uri字段获取公钥URI，访问公钥URI获取公钥。  
公钥每天更新一次，应用服务器可以缓存公钥的值。

2、验证签名。ID Token是JWT格式的，验证ID Token的签名可以采用通用的JWT库，例如[jwt.io](https://jwt.io/)。将ID Token复制到Encoded中，可以看到kid的值，通过kid去获取第一步中的公钥，将其放入VERIFY SIGNATURE的公钥中就可以验证签名。

3、验证ID Token中iss字段的值是否等于“https://accounts.huawei.com”。

4、验证ID Token中aud字段的值等于应用的client_id。

5、验证ID Token中的过期时间（exp字段）是否已过期。

6、如果以上验证均通过，则表示用户ID Token验证通过，应用可使用登录结果中的用户信息。

● 方式2：服务器验证

应用调用[ID Token合法性验证接口](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-verify-id-token-v3)向华为帐号服务器发送ID Token验证请求，华为帐号服务器向应用直接返回验证结果。  


**注意** ：

由于调用“[ID Token合法性验证接口](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-verify-id-token-v3)”会带来耗时，并且受网络状况的影响，所以服务器验证方式只能用于调试目的，在商用环境需要采用本地验证的方式。

# 2\. 华为帐号登录（Authorization Code）

## 2.1 场景介绍

华为帐号是用户访问华为云业务的凭证，拥有华为帐号的用户，可以使用华为云业务，如华为云服务、华为游戏中心、华为应用市场等。

华为帐号登录是指基于[OAuth2.0协议标准](https://oauth.net/2/)和[OpenID Connect协议](https://openid.net/connect/)，第三方应用可以获取华为帐号用户身份认证信息(ID Token)或用户的临时授权票据(Authorization Code)，用于用户使用华为帐号安全登录第三方应用。Authorization Code模式仅适用于有自己服务器的应用，ID Token模式同时适合单机应用和有自己服务器的应用。开发者可根据实际情况选择其中一种模式实现。

本章节主要介绍使用Authorization Code模式登录华为帐号的开发步骤。

## 2.2 业务流程

整体流程：

1、用户选择华为帐号登录方式登录应用。

2、应用向HUAWEI Account SDK发起登录请求。

3、华为帐号拉起用户登录授权界面，界面上会根据登录请求中携带的授权域(scope)信息， 显式告知用户需要授权的内容。

# 4\. 静默登录

## 4.1 场景介绍

静默登录是指用户在退出应用时如果用户已经进行过登录授权，当用户再次返回应用界面时，应用不希望拉起任何登录授权界面，在后台直接通过静默方式获取用户登录信息。

## 4.2 业务流程

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200117155239.41301940152972273064791646364064:50510324064420:2800:13A335E9D22B62074B56C23D826AAFF25D97D46A290304100137A7E541D323CC.png)

1、用户进行了触发静默登录的场景，根据应用实际场景由开发者自行设定。

2、应用调用[HuaweiIdSignInOptions.Builder](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-huaweiidsigninoptions-builder#HuaweiIdSignInOptions.Builder-Builder0)的默认构造方法配置鉴权参数。

3、HUAWEI Account SDK向应用返回包含授权参数的[HuaweiIdSignInOptions](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-huaweiidsigninoptions)对象。

4、应用调用[HuaweiIdSignIn](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-huaweiidsignin)的getClient方法初始化HuaweiIdSignInClient实例。

5、HUAWEI Account SDK向应用返回[HuaweiIdSignInClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-huaweiidsignInclient)对象。

6、应用调用[HuaweiIdSignInClient.silentSignIn](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-huaweiidsignInclient#HuaweiIdSignInClient-silentSignIn)方法向HMS SDK发起静默登录请求。

7、HUAWEI Account SDK检查用户是否符合静默登录的授权，并向应用返回授权结果。

8、应用根据授权结果自行确定后续处理。

静默登录功能涉及应用的关键开发步骤如下：

# 6\. 自动读取短信验证码

## 6.1 场景介绍

HMS SDK提供了SMS Retriever服务，通过调用SMS Retriever相关接口可以实现自动读取短信验证码，为用户省去手动输入短信验证码的操作。

在应用无法获取移动设备的短信读取权限时，可以使用此功能。通过SMS Retriever的相关接口，开发者可以在Android应用程序中自动执行基于SMS的用户验证，而不需要用户手动输入验证代码。

## 6.2 业务流程

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200117155313.83604677543181837772603936769878:50510324064420:2800:3107BBDBA2DFA84C01281B9A74219ABDD229A11B0C21215062BB3ADC52D39FB3.png)

1、用户在应用客户端需要验证手机号的界面中输入手机号，并请求获取验证码。

2、应用调用[SmsRetriever.getClient()](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-smsretriever#SmsRetriever-getClientActivity)方法向HUAWEI Account SDK请求初始化[SmsRetrieverClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-smsretrieverclient)实例。

3、HUAWEI Account SDK向应用客户端返回[SmsRetrieverClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-smsretrieverclient)对象。

4、应用调用[SmsRetrieverClient.startSmsRetriever()](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-smsretrieverclient#SmsRetrieverClient-startSmsRetriever)方法向HUAWEI Account SDK请求开启读取短信服务，HUAWEI Account SDK将请求发送到HUAWEI Account Server。

5、HUAWEI Account Server开启读取短信服务，并通过HUAWEI Account SDK向应用客户端返回开启结果。

6、应用客户端将用户手机号传递给应用服务端。

7、应用服务端根据手机号生成短信验证码，并且按照[一定格式](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-smsretrieverclient#messagerule)的短信模板发送短信到用户手机。

8、HUAWEI Account Server监听短信，校验短信与应用客户端的匹配，将符合规则的短信通过定向广播的方式发送给应用客户端。

9、应用客户端收到HUAWEI Account Server发送的定向内容，解析出短信验证码，并在应用界面中展示读取到的验证码。

10、用户确认验证码无误后确认发送验证码请求。

11、应用客户端将用户发送的验证码发送给应用服务端验证。

12、应用服务端确认验证码无误后向应用客户端返回验证结果。

## 6.3 注意事项

●  SMS Retriever提供了完全自动化的用户体验，但是它也要求开发者在短信消息体中设置一个自定义的hash值，如果开发者不是该消息的发送者，那么不建议使用SMS Retriever。

●  HMS Core（APK）需要用户授予移动设备的短信读取权限。

## 6.4 开发步骤

自动读取短信验证码功能涉及应用的关键开发步骤如下：

1、应用调用[SmsRetriever.getClient()](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-smsretriever#SmsRetriever-getClientActivity)方法请求初始化[SmsRetrieverClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-smsretrieverclient)实例。
    
    
    复制
      
        1. SmsRetrieverClient client = SmsRetriever.getClient(this);
    
    

2、应用调用[SmsRetrieverClient.startSmsRetriever()](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-smsretrieverclient#SmsRetrieverClient-startSmsRetriever)方法请求开启短信读取服务。
    
    
    复制
      
        1. Task<Void> task = client.startSmsRetriever();
        2. task.addOnCompleteListener(new OnCompleteListener<Void>() {
        3.     @Override
        4.     public void onComplete(Task<Void> task) {

        6.             // 开启服务成功，可以继续后续流程

        10. });
