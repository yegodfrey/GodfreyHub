# 1\. 服务简介

华为帐号适用于访问所有华为服务。华为帐号为开发者提供了简单、安全的登录授权功能，方便用户快捷登录。

# 2\. 服务特点

●  快捷的登录体验

简单、安全、快捷的一键登录及授权，降低用户注册和登录成本。

●  持续增长的海量用户

华为持续稳定增长的海量活跃用户，将给您的应用或服务带来巨大的用户数及访问量。

●  高度重视用户安全和隐私

我们提供多种方法来保护用户帐号安全和隐私，这些方法包括高安全性密码、帐号保护、登录。
