# 1\. 场景介绍

《[关于规范网络游戏运营加强事中事后监管工作的通知](http://www.gov.cn/xinwen/2016-12/07/content_5143968.htm)》再次强调网络游戏运营主体加强针对未成年人的监管和保护。华为根据《[关于保护未成年人身心健康实施网络游戏防沉迷系统的通知](http://www.gov.cn/zwgk/2007-04/13/content_581444.htm)》以及其附件《网络游戏防沉迷系统开发标准》、《网络游戏防沉迷系统实名认证方案》的要求提供了防沉迷接入方案，开发者需要按照《网络游戏防沉迷系统开发标准》结合自身应用的实现逻辑完成游戏防沉迷功能的开发。防沉迷处理的业务逻辑如下图所示。

# 2\. 业务流程

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191202160351.34947069780125209697465476586146:50510324122756:2800:70DCA478C2FA0583AB965102CB40347ADFD475EC50A9CCD477E1303C259B375B.png)

说明：

游戏防沉迷涉及的[getPlayerCertificationIntent](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/getcertificationIntent-v3)和[getPlayerCertificationInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/getcertificationInfo-v3)接口没有严格的先后调用顺序，如何调用接口以及调用的时机可以由开发者按照《网络游戏防沉迷系统开发标准》结合自身应用的逻辑自行设计，本业务流程仅作为示例供开发者参考。

1、应用统计用户的游戏累计时长，游戏时间超时应用判断需要进行防沉迷处理。

2、应用调用[getPlayerCertificationInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/getcertificationInfo-v3)接口检查用户的实名认证情况。

3、HMS SDK向应用返回用户的实名认证信息。

4、应用根据返回结果的hasAdult参数判断是否需要实名认证。  


  * 如果hasAdult为-1，表示未实名认证，转到下一步。

  * 如果hasAdult为0或1，表示已实名认证，应用可以记录用户的实名认证情况备用。




5、应用调用[getPlayerCertificationIntent](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/getcertificationIntent-v3)接口请求获取实名认证页面。

6、HMS SDK向应用返回包含实名认证页面的Intent对象。

7、应用根据Intent对象跳转至实名认证页面。

8、用户在实名认证页面中进行实名认证。

9、认证成功后HMS SDK向应用返回页面的响应消息。

10、在用户已实名认证成功后，应用可以调用[getPlayerCertificationInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/getcertificationInfo-v3)接口检查用户是否成年。

11、HMS SDK通过回调方式向应用返回用户是否成年。

12\. 应用返回结果的hasAdult参数进行防沉迷设置。  


  * 如果hasAdult为1，表示用户已成年，则不纳入防沉迷系统。

  * 如果hasAdult为0，表示用户未成年，则需要将用户纳入防沉迷系统。




# 3\. 注意事项

游戏防沉迷功能相关接口目前仅对中国大陆用户有效。  


# 4\. 开发步骤

游戏防沉迷涉及应用的关键开发步骤如下：

1、在游戏启动或连接断开时初始化HuaweiApiClient对象并连接HMS Core（APK），具体方法参见[初始化HuaweiApiClient对象](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/game-apiclient)。如果已经连接，请跳过本步骤。

2、调用[getPlayerCertificationInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/getcertificationInfo-v3)接口。  
应用根据回调结果中的hasAdult参数判断用户的实名认证信息。

-  如果为0，表示未实名认证。应用需要使用getPlayerCertificationIntent()方法获取回调结果中的intent对象，通过startActivityForResult方法跳转至实名认证页面。  
-  如果为1，表示已实名认证，应用需要继续查询用户是否成年。
