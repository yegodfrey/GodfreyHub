# 1. 应用概况

## 1.1 功能简介

应用概况通过集中展现当前APP的核心数据指标（如：新增用户数、用户活跃情况等），并提供事件分析、活跃度分析的入口，帮助开发者快速了解APP近期整体的数据表现情况。

## 1.2 功能详述

1、登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击“分析”图标。

2、选择需要查看分析数据的应用。

3、点击“高级分析”页签->” Dashboard” ->”应用概况”进入报告页面。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191217180407.52074416126944871861212948217288:50510115131116:2800:9DFB693AFFCD66A6BB69B56E9E7D5BEC476D1D2A8A5F25ABAE8A20772E8B3C99.png)

应用概况页面整体上划分为8个功能区域：

**1）   数据概览区域：**

展示近7天平均的新增用户数及新用户次日留存率、活跃用户数、累计用户数、访问时长。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191217180407.50450120885879585351933513451599:50510115131116:2800:175455C8DFADA727CCB374C0A58D1BE46A672A3D82CBF8A41727CE327AB10C05.png)

指标说明：

① 新增用户数(7日平均)：以登录日期为基准，计算前7天的平均新增用户数，并展示与前一天的平均新增用户数的同比变化趋势；  
② 新用户次日留存率(7日平均)：以登录日期为基准，计算前7天的平均新用户次日留存率，并展示与前一天的平均新用户次日留存率的同比变化趋势；  
③ 活跃用户数(7日平均)：以登录日期为基准，计算前7天的平均活跃用户数，并展示与前一天的平均活跃用户数的同比变化趋势；  
④累计用户数：以登录日期为基准，计算历史累计用户数；  
⑤访问时长：以登录日期为基准，计算前7天的平均访问时长，并展示与前一天的平均访问时长的同比变化趋势  


注意：

HUAWEI Analytics Kit 所展示的数据，除实时趋势是分钟级更新外，其他各项指标均为每天更新。

**2）   过滤器区域：**

您可以按不同时段、从用户属性和受众两个维度，筛选您关注的事件。

**3）实时分析区域：**

实时分析卡片提供近30分钟的用户数变化趋势和事件数变化趋势，可点击图中（1）处“用户数”或“事件数”按钮进行切换。

  * 启动次数：应用启动次数

该区域展示了新用户数、会话次数、访问时长、访问深度，可查看新用户的位置、机型分布，同时可按日、周、月查看新用户的回访情况。点击右下角跳转链接，可查看详情，帮助您快速掌握新用户的数据表现，为新用户的运营策略制定提供数据支撑。

# 3. 事件分析

## 3.1 功能简介

HAUWEI Analytics Kit提供了丰富的事件分析功能，支持[预置事件](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/Development-Guide#preset_events)（包含自动采集事件、预定义事件）和自定义事件。

按事件ID对您上报的事件数据进行聚合，支持您查看事件概览和事件分析详情，如事件发生的整体趋势、事件来源的机型分布、事件来源的系统版本分布等。

## 3.2 功能详述

1、登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击“分析”图标。

2、选择需要查看分析数据的应用。

3、点击“高级分析”页签->”事件分析”进入报告页面。

您可以在“事件分析”页签查看所有的事件列表，包括事件名称、事件ID、日均事件数、日均用户数、人均次数。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200111103357.56936510716888108760734616575222:50510115131116:2800:16AA05E52DAE68E1283DCBE9299661EDFC5C7645E8FBFE6145636C48B9178AEC.png)

 1)过滤器：您可以从用户属性或受众两个维度，选择不同的条件筛选您关注的事件。

 

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191217180407.17486103510873222112847232271672:50510115131116:2800:06FD4364110DF1F569EEEF95DAE09FFDE566B426DA402E029706CBA385CE64FB.png)

2)日期：您可以按不同的时段筛选您关注的事件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191217180407.50524967038721060430554902375124:50510115131116:2800:9F60EFD16432F9BE975802A46713681A53E3366B996E7AD9AD49E275737CB07F.png)

### 3.2.1 查看事件详情（每天更新）

点击事件名称，可查看某个事件的分析详情，包括：实时趋势、历史趋势、自定义参数分布、默认指标分析（应用版本分布、机型占比分布、系统版本分布、每次会话事件数）。

除了实时趋势是分钟级更新外，其他各项指标均为每天更新。

您可以使用过滤器控件和日期控件（如下图(1)处，具体使用参考[查看概览](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/3021002#app_overview)）以及事件选择下拉框（如下图(2)处），来快速选择需分析的事件。

**2.****历史趋势**

通过历史趋势指标，您可以：

  * 查看您选择的时间段内，日均事件数、日均用户数、人均次数的变化趋势。

除了默认指标分析，您还可以自行指定需要分析的事件参数（[如何指定分析哪些参数？](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/3021002#event_management)），以便对您的用户做更深入的洞察。

通过自定义参数分布报告，您可以：

  * 对于字符串型参数：可查看该参数在选定时间段内各个取值的数量分布情况和用户数分布情况（如图中(1)所示）、按天对比各个取值数量（如图中(2)所示）、以及查看各个取值的明细数据（如图中(3)所示）。

  * 对于数字型参数：可查看该参数在选定时间段内按天的平均值趋势、总和趋势。




## 3.3 规格说明

  * 每个APP最多支持500个事件（含系统预定义事件和自定义事件）。

  * 每个事件最多支持25个参数，每个APP最多支持100个参数（不包含系统自动采集事件的参数。）

  * 每个APP的每个字符型参数，最多统计500个参数值（历史累计），超出的统一归为其他。

  * 事件ID、参数ID：长度均不能超过256个字符。

  * 事件名称、参数名称：长度均不能超过255个字符。

  * 事件描述：长度不超过1000个字符。




# 4. 用户分析

## 4.1功能简介

通过对活跃用户的分析，您可以了解产品对于用户的吸引粘性，从而指定针对性促活策略。

## 4.2 功能详述

1、登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击“分析”图标。

2、选择需要查看分析数据的应用。

3、点击“高级分析”页签，选择“用户分析->活跃用户”，进入“活跃用户”页面。

### 4.2.1查看活跃用户报告（每天更新）

1.您可使用过滤器控件和日期控件，快速筛选您需要分析的数据范围。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191217180526.53757875913823479542902717750211:50510115131116:2800:D62583F058084FC515D94B1DD8A0051A0D06F24566723422FB0CF6CF8E002DD7.png)

2.点击下图（1）处可切换查看活跃用户数和活跃率的趋势分析，活跃用户详情如图中（3）处；

# 6. 归因分析

## 6.1功能简介

应用内事件的归因分析用来衡量待归因事件（如push消息点击事件）对目标转化事件（如下单购买）的转化贡献。您可以通过定义目标转化事件和待归因事件，并选择归因模型，即可生成归因分析报告。帮助识别判断营销渠道转化效果，及时调整策略。  
归因模型是指一种或一组规则，用于确定如何将销售功劳和转化功劳分配给转化路径中的接触点。例如，“末次事件归因”模型会将 100% 的功劳分配给销售或转化之前的最终接触点（即单击），而“首次事件归因”模型会将 100% 的功劳分配给引发转化路径的接触点。

（3）应用版本详情

本页面通过分析应用在统计日，各个版本的活跃用户数、活跃用户占比、平均活跃间隔、平均事件数、平均会话数、平均访问时长、版本状态，帮助您了解各个版本用户的活跃情况。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191217181013.11638759719989710967613408069820:50510115131116:2800:6CD74228665FCB556CB9343BC654FDE8748D4F3A9D2C2FD3B8D0A49601A29138.png)

[**指标说明详情**](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/23588874#Metrics)**：**

  * 活跃用户数：统计日当日访问APP的去重用户数。

  * 活跃用户占比：统计日当日该版本活跃用户数在总活跃用户中的占比。

  * 平均间隔：SUM(统计日日活用户上一次活跃时间距离统计日的间隔天数)/统计日日活用户数。

  * 平均事件数：SUM(统计日当日用户访问APP的事件总数)/统计日日活用户数。

  * 平均会话数：SUM(统计日当日用户访问APP的会话次数)/统计日日活用户数。

  * 访问时长：SUM(统计日日活用户会话时长)/统计日日活用户数。

  * 状态：通过版本发布时间、日活用户采用率及采用率增长情况，定义版本状态。




① 成功发布：每日活跃用户 (DAU) 的采用率大于 10%。  
② 上次发布：发布超过 15 天，且该版本的每日活跃用户采用率大于10%。  
③ 正在发布：自发布第一天起，每日活跃用户采用率增长大于2%。  
④ 采用率低：自发布第一天起，每日活跃用户采用率从未达到 10%，且增长率小于等于2%。

### 13.2.3用户属性

功能简介：

您可以维护自定义的用户属性，这些自定义的用户属性可用于定义受众群组，或作为查看各种报告的过滤条件。

功能详述：

1、登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击“分析”图标。

2、选择需要查看分析数据的应用。

3、点击“高级分析”页签，进入“用户属性”页面。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191217181014.48996524864931743561122353692139:50510115131116:2800:DAE9AE6C20C863FBD433EF7C0101D5496A0006A6A386A074B12132FBF9DBF807.png)

通过在“用户属性”页面，您可以：

  * 查看用户属性的基本信息，包括属性ID、属性说明、属性描述等。

  * 管理用户属性：创建和编辑用户属性。




**注意：**

用户属性ID不能超过256字符、用户属性名称不能超过255个字符，且非空。

管理用户属性：

点击“用户属性”页面右上角的“新建”按钮，可以创建新的用户属性。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191217181153.66304854541755025065013658412758:50510115131116:2800:31D1EF2BC30772E9D9AB14D162A14F83EBA7C9CBC281A8AE45B4A458B13EA6D8.png)

参数填写说明如下表所示：

**参数**| **填写说明**  
---|---  
属性ID| 用户属性标识，长度在256个字符以内。  
属性名称| 填写便于您记忆和理解的用户属性名称。  
属性说明| 填写您定义此用户属性的目的、场景等信息。  
  
点击“用户属性”页面“操作”栏中的“编辑”按钮，可以修改您自定义的用户属性。

## 13.3规格说明

  * 用户属性ID：长度不超过256个字符。

  * 用户属性名称：长度不超过255个字符。

  * 用户属性备注：长度不超过1000个字符。

  * 注册用户属性数：一个APP不超过25个，只包含自定义用户属性，不包含系统用户属性。

  * 对用户属性名称、描述的修改，立即生效；新增、删除用户属性，次日生效。
