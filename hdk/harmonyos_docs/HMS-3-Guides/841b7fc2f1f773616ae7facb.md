# ******1\. 升级HMS APK******

（必选）在工程的AndroidManifest.xml文件中，添加provider组件，用于HMS SDK引导升级HMS APK，提供给系统安装器读取升级文件。
    
    
    复制
      
        1. <application
        2.   ...
        3.   <provider
        4.    android:name="com.huawei.hms.update.provider.UpdateProvider"
        5.    <!--“xxx.xxx.xxx”用实际的应用包名替换-->
        6.    android:authorities="xxx.xxx.xxx.hms.update.provider"
        7.    android:exported="false"
        8.    android:grantUriPermissions="true" >
        9.   </provider>
        10.   ...
        11. </application>
