# 服务简介绍

华为统一扫码服务（Scan Kit）提供便捷的条形码和二维码扫描与解析能力，帮助您快速构建应用内的扫码功能。

得益于华为在计算机视觉领域能力的积累，Scan Kit可以实现远距离条码或二维码的检测与自动放大，从而解决远距离扫码场景中条形码或二维码难以识别的问题。同时，针对常见复杂扫码场景（如：强光照、污损、柱面等）做了针对性识别优化，提升扫码成功率与用户体验。

# 场景介绍

## 1 支持的码格式

l   一维码：EAN-8、EAN-13、UPC-A、UPC-E、Codabar、Code 39、Code 93、Code 128、ITF

l   二维码：QR Code、Data Matrix、PDF417、Aztec

说明：

将陆续支持更多的码格式。

## 2 支持的调用方式

l   Default View方式：应用直接调用Scan Kit的扫码Activity，扫描结果通过异步回调接口传递给应用。支持通过相机扫码或者导入图片扫码。

l   Customized View方式：应用直接创建RemoteView，扫描结果通过异步回调接口传递给应用。支持通过相机扫码或者导入图片扫码。

l   Bitmap API方式：应用通过接口直接传递Bitmap，接口直接返回扫码结果给应用。 您可以在您的应用中调用相机API获取Bitmap，或通过导入本地图片的方式获取Bitmap，然后调用Scan Kit的Bitmap API完成解码。

您可以根据需求选择更加适合的调用方式：

调用方式| 特点| 适合场景  
---|---|---  
Default View方式| 开发者不需要理解、处理应用与相机间的各种交互，调用后均由Scan Kit完成。但是，不支持开发者自定义扫码界面UI。| 开发者不需要自定义UI。  
Customized View方式| 开发者不需要理解、处理应用与相机间的各种交互，调用后均由Scan Kit完成。但是，需要开发者自定义扫码界面UI。| 开发者需要自定义UI，且希望Scan Kit处理与相机间的各种交互。  
Bitmap API方式| 开发者仅使用Scan   Kit的识别与解析能力，需要自行处理应用与相机间的各种交互，并向Scan Kit传递Bitmap。| 开发者只需要图片方式的解码能力。  
  
  


# 隐私声明

开发者在基于HMS SDK开发时，您需要遵守《[华为开发者服务协议](https://developer.huawei.com/consumer/cn/doc/start/20201)》、《[华为APIs使用协议](https://developer.huawei.com/consumer/cn/doc/distribution/app/20209)》、《[AppGallery Connect数据处理附录](https://developer.huawei.com/consumer/cn/doc/distribution/app/20215)》。Scan Kit扫码流程完全在设备端处理，不会上传和保存任何个人数据和图像数据。
