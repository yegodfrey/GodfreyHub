# 自检CheckList  


为尽早发现问题，尽量减少开发者集成业务提交审核后被打回的概率，HMS业务提供了提交审核前自检checklist。请下载

“[支付服务开发自检Checklist.xlsx](https://obs.cn-north-2.myhwclouds.com/hms-ds-wf/b/7a07fc75f75b4658b644223f9b933a40-3826757466287285192.xlsx)”进行自检，检查通过后，再提交上架应用。

# 自检工具

华为提供对应用自动检查的能力。开发者只需填写应用相关信息、上传APK包，平台将自动扫描APK并输出自检报告。开发者可以根据自检报告改进应用，自检通过即可提交应用上架。

自检步骤请参考AppGallery Connect帮助中心的[自检应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-auto_check)。

说明：

目前新版自检工具需要在开发者联盟实名认证过的企业或者个人的帐号才可以使用。
