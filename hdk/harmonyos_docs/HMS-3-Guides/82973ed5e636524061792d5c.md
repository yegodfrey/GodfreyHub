在调用showFloatWindow、hideFloatWindow、getCertificationInfo和getCertificationIntent接口前，需要初始化HuaweiApiClient对象并连接HMS Core（APK）。HuaweiApiClient对象初始化方法如下。
    
    
    复制
      
        1. HuaweiApiClient apiClient = new HuaweiApiClient.Builder(this)
        2.             .addApi(HuaweiGame.GAME_API)
        3.             .addConnectionCallbacks(connectCallbacks)
        4.             .addOnConnectionFailedListener(connectFailedListener)
        5.             .build();     
        6. apiClient.connect(this);    //连接HMS Core
    
    

  * apiClient为HuaweiApiClient对象名称，开发者可以自行定义。

  * connectCallbacks为连接HMS Core（APK）的结果回调，定义如下：



    
    
    复制
      
        1. public interface ConnectionCallbacks {
        2.     int CAUSE_SERVICE_DISCONNECTED = 1; // 连接断开
        3.     int CAUSE_NETWORK_LOST = 2; // 无网络
        4.     int CAUSE_API_CLIENT_EXPIRED = 3; // client过期废弃
        5.     void onConnected();
        6.     void onConnectionSuspended(int cause);
        7. }
    
    

  * onConnected回调方法表示连接HMS Core（APK）成功，开发者可以继续调用其他业务接口。onConnectionSuspended回调方法在HuaweiApiClient对象变成断开状态时会被调用，需要开发者在此回调方法中尝试恢复连接（connect）。

  * connectFailedListener为连接失败时监听，定义如下：



    
    
    复制
      
        1. public interface OnConnectionFailedListener {
        2.     void onConnectionFailed(ConnectionResult result);
        3. }
    
    

开发者可以在onConnectionFailed方法中通过ConnectionResult.getErrorCode获取错误码。ConnectionResult定义如下：
    
    
    复制
      
        1. public final class ConnectionResult {
        2.     public static final int SUCCESS = 0;           //成功
        3.     public static final int SERVICE_MISSING = 1;   //设备上未安装HMS
        4.     public static final int SERVICE_VERSION_UPDATE_REQUIRED = 2;  //设备上安装的HMS需要升级
        5.     public static final int SERVICE_DISABLED = 3;  //设备上的HMS已经不可用
        6.     public static final int SIGN_IN_REQUIRED = 4;  //用户未登录
        7.     public static final int INVALID_ACCOUNT = 5;   //无效的帐号
        8.     public static final int BINDFAIL_RESOLUTION_REQUIRED = 6; //HMS SDK内部错误
        9.     public static final int BINDFAIL_RESOLUTION_BACKGROUND = 7;
        10.     public static final int INTERNAL_ERROR = 8;   //发生内部错误
        11.     public static final int SERVICE_INVALID = 9;   //设备上安装的HMS不是真实的
        12.     public static final int DEVELOPER_ERROR = 10;  //HMS SDK内部错误，获取不到aidl句柄
        13.     public static final int LICENSE_CHECK_FAILED = 11;  //License检查失败
        14.     public static final int CANCELED = 13;   //用户在HMS升级提示框取消升级
        15.     public static final int TIMEOUT = 14;    //HMS升级时下载升级包超时
        16.     public static final int SERVICE_MISSING_PERMISSION = 19;
        17.     public static final int SERVICE_UNSUPPORTED = 21;  //设备版本太老不支持HMS
        18.     public static final int API_UNAVAILABLE = 1000;
        19.     private final int a;
        20.     public ConnectionResult(int var1) {
        21.         this.a = var1;
        22.     }
        23.     public int getErrorCode() {
        24.         return this.a;
        25.     }
        26. }
    
    

初始化HuaweiApiClient并连接HMS Core（APK）的JAVA示例代码如下：
    
    
    复制
      
        1. HuaweiApiClient apiClient =  new HuaweiApiClient.Builder(this)
        2.            .addApi(HuaweiGame.GAME_API)
        3.            .addConnectionCallbacks(new HuaweiApiClient.ConnectionCallbacks() {
        4.                @Override
        5.                public void onConnected() {
        6.                    //connect成功，应用可以业务接口。
        7.                }
        8.                @Override
        9.                public void onConnectionSuspended(int cause) {
        10.                }
        11.            })
        12.            .addOnConnectionFailedListener(new HuaweiApiClient.OnConnectionFailedListener() {
        13.                @Override
        14.                public void onConnectionFailed(ConnectionResult connectionResult) {
        15.                }
        16.            }) .build();
        17. apiClient.connect(this);
