# **定位服务开发指南**

要使用华为定位服务API，需要确保您的设备已经下载并安装了HMS Core服务组件，并将相关的SDK集成到您的项目中。有关详细信息，请参阅[开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/location-preparation-v3)。

# **1\. 定位服务开发步骤**

## **1.1 指定应用权限**

1、Android提供了两种位置权限： ACCESS_COARSE_LOCATION（粗略的位置权限） 和ACCESS_FINE_LOCATION（精确的位置权限）。需要在Manifest文件中申请权限：
      
      1. <uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION"/>
        2. <uses-permission android:name="android.permission.ACCESS_FINE_LOCATION"/>
    
    

2、在Android Q版本中，如果您需要应用程序在后台执行时也具备持续定位能力，需要在Manifest文件中申请ACCESS_BACKGROUND_LOCATION权限：
      
      1. <uses-permission android:name="android.permission.ACCESS_BACKGROUND_LOCATION" />
    
    

3、在Manifest中添加后，还要在代码中动态申请一下权限(Android 6.0危险权限要求)：      
      
      1. if (Build.VERSION.SDK_INT <= Build.VERSION_CODES.P) {
        2.     Log.i(TAG, "sdk < 28 Q");
        3.     if (ActivityCompat.checkSelfPermission(this,
        4.         Manifest.permission.ACCESS_FINE_LOCATION) != PackageManager.PERMISSION_GRANTED
        5.         || ActivityCompat.checkSelfPermission(this,
        6.             Manifest.permission.ACCESS_COARSE_LOCATION) != PackageManager.PERMISSION_GRANTED) {
        7.         String[] strings =
        8.             {Manifest.permission.ACCESS_FINE_LOCATION, Manifest.permission.ACCESS_COARSE_LOCATION};
        9.         ActivityCompat.requestPermissions(this, strings, 1);
        10.     }
        11. } else {
        12.     if (ActivityCompat.checkSelfPermission(this,
        13.         Manifest.permission.ACCESS_FINE_LOCATION) != PackageManager.PERMISSION_GRANTED
        14.         || ActivityCompat.checkSelfPermission(this,
        15.             Manifest.permission.ACCESS_COARSE_LOCATION) != PackageManager.PERMISSION_GRANTED
        16.         || ActivityCompat.checkSelfPermission(this,
        17.             "android.permission.ACCESS_BACKGROUND_LOCATION") != PackageManager.PERMISSION_GRANTED) {
        18.         String[] strings = {android.Manifest.permission.ACCESS_FINE_LOCATION,
        19.             android.Manifest.permission.ACCESS_COARSE_LOCATION,
        20.             "android.permission.ACCESS_BACKGROUND_LOCATION"};
        21.         ActivityCompat.requestPermissions(this, strings, 2);
        22.     }
        23. }

在Activity的OnCreate()方法中创建一个[FusedLocationProviderClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/fusedlocationproviderclient-v3)实例，通过该实例调用定位相关接口。

        5. }
    
    

## **1.3 检查设备定位设置**

设备的相关定位设置会影响华为定位服务的定位结果，例如位置开关选项处于关闭状态时，将无法获取到位置信息。因此，建议您在持续获取位置信息之前，先检查设备设置是否满足定位条件。华为定位服务提供了检查设备定位相关设置的能力，通过[LocationServices](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/locationservice-v3)的[getSettingsClient(Activity activity)](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/locationservice-v3)获取[SettingsClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/settingsclient-v3)实例，然后调用[checkLocationSettings( LocationSettingsRequest locationSettingsRequest)](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/settingsclient-v3)接口获取定位设置结果，当设置不满足定位条件时，将为您提供解决方案以提示用户打开对应的权限（HMS Core服务定位权限必须打开，Android Q版本必须选择“始终允许”）。

1、获取SettingsClient的服务接口
      
      1. SettingsClient settingsClient = LocationServices.getSettingsClient(this);
    
    

2、调用[checkLocationSettings()](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/settingsclient-v3)检查设备设置
      
      1. LocationSettingsRequest.Builder builder = new LocationSettingsRequest.Builder();
        2. mLocationRequest = new LocationRequest();
        3. builder.addLocationRequest(mLocationRequest);
        4. LocationSettingsRequest locationSettingsRequest = builder.build();
        5. //检查设备定位设置
        6. settingsClient.checkLocationSettings(locationSettingsRequest)
        7.         .addOnSuccessListener(new OnSuccessListener<LocationSettingsResponse>() {
        8.             @Override
        9.             public void onSuccess(LocationSettingsResponse locationSettingsResponse) {
        10.                 //设置满足定位条件，再发起位置请求
        11.                 fusedLocationProviderClient
        12.                         .requestLocationUpdates(mLocationRequest, mLocationCallback, 
        13.                                 Looper.getMainLooper())
        14.                         .addOnSuccessListener(new OnSuccessListener<Void>() {
        15.                             @Override
        16.                             public void onSuccess(Void aVoid) {
        17.                                 //接口调用成功的处理
        18.                             }
        19.                         });
        20.             }
        21.         })
        22.         .addOnFailureListener(new OnFailureListener() {
        23.             @Override
        24.             public void onFailure(Exception e) {
        25.                 //设置不满足定位条件
        26.                 int statusCode = ((ApiException) e).getStatusCode();
        27.                 switch (statusCode) {
        28.                     case LocationSettingsStatusCodes.RESOLUTION_REQUIRED:
        29.                         try {
        30.                             ResolvableApiException rae = (ResolvableApiException) e;
        31.                             //调用startResolutionForResult可以弹窗提示用户打开相应权限
        32.                             rae.startResolutionForResult(MainActivity.this, 0);
        33.                         } catch (IntentSender.SendIntentException sie) {
        34.                             //…
        35.                         }
        36.                         break;
        37.                 }
        38.             }
        39.         });
    
    

## **1.4 持续获取位置信息**

如果您希望应用可以持续获取设备位置，可以使用华为定位服务提供的[requestLocationUpdates()](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/fusedlocationproviderclient-v3)接口。该接口根据入参形式的不同，将以两种不同的形式将位置信息返回。一种是通过调用您已经定义的[LocationCallback.onLocationResult()](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/locationcallback-v3)回调方法返回一个包含位置信息的[LocationResult](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/locationresult-v3)对象，另一种是将位置信息置于Pendingintent扩展信息中返回。

当您的应用程序不再需要接收位置更新时，应当停止位置更新，以便于降低功耗。要停止位置更新，可以调用[removeLocationUpdates()](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/fusedlocationproviderclient-v3)，传入与[requestLocationupdates()](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/fusedlocationproviderclient-v3)接口相对应的[LocationCallback](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/locationcallback-v3)或Pendingintent对象。这里以回调方式作为样例，代码如下。详细的参数说明见[location接口说明](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/hms-location-v3)。

1、设置持续定位请求参数
      
      1. LocationRequest mLocationRequest = new LocationRequest();        
        2. // 设置位置更新的间隔(毫秒为单位)        
        3. mLocationRequest.setInterval(10000);        
        4. // 设置权重        
        5. mLocationRequest.setPriority(LocationRequest.PRIORITY_HIGH_ACCURACY);
    
    

2、定义位置更新回调   

      
      1. LocationCallback mLocationCallback;        
        2. mLocationCallback = new LocationCallback() {        
        3.                @Override        
        4.                public void onLocationResult(LocationResult locationResult) {        
        5.                    if (locationResult != null) {        
        6.                        //处理位置回调结果        
        7.                    }        
        8.                }        
        9.            };
    
    

3、调用[requestLocationUpdates()](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/fusedlocationproviderclient-v3)进行持续定位
      
      1. fusedLocationProviderClient        
        2.                    .requestLocationUpdates(mLocationRequest, mLocationCallback, Looper.getMainLooper())        
        3.                    .addOnSuccessListener(new OnSuccessListener<Void>() {        
        4.                        @Override        
        5.                        public void onSuccess(Void aVoid) {        
        6.                            //接口调用成功的处理        
        7.                        }        
        8.                    })
        9.                    .addOnFailureListener(new OnFailureListener() {        
        10.                        @Override        
        11.                        public void onFailure(Exception e) {        
        12.                            //接口调用失败的处理        
        13.                        }        
        14.                    });
    
    

4、调用[removeLocationUpdates()](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/fusedlocationproviderclient-v3)停止位置更新  

      
      1. //注意：停止位置更新时，mLocationCallback必须与requestLocationUpdates方法中的LocationCallback参数为同一对象。
        2. fusedLocationProviderClient.removeLocationUpdates(mLocationCallback)        
        3.                .addOnSuccessListener(new OnSuccessListener<Void>() {        
        4.                    @Override        
        5.                    public void onSuccess(Void aVoid) {      
        6.                        //停止位置更新成功        
        7.                    }        
        8.                })
        9.                .addOnFailureListener(new OnFailureListener() {        
        10.                    @Override        
        11.                    public void onFailure(Exception e) {      
        12.                        //停止位置更新失败        
        13.                    }        
        14.                });

# **2\. 活动识别服务开发步骤**

要使用华为活动识别服务API，需要确保您的设备已经下载并安装了HMS Core服务组件，并将相关的SDK集成到您的项目中。有关详细信息，请参阅[开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/location-preparation-v3)。以下仅为代码片段，详情请参考完整示例代码。

## **2.1 指定应用权限**

1、在Android Q以下版本使用活动识别需要在manifest文件中配置以下权限()：
      
      1. <uses-permission android:name="com.huawei.hms.permission.ACTIVITY_RECOGNITION"/>
    
    

2、在Android Q及以上版本中，需要在Manifest文件中申请以下权限：
      
      1. <uses-permission android:name="android.permission.ACTIVITY_RECOGNITION" />
    
    

注：在使用以上权限时，需做动态权限处理。

## **2.2 创建活动识别服务客户端**

在Activity的OnCreate()方法中创建一个ActivityRecognitionClient实例，通过该实例调用活动识别相关接口：
      
      1. private ActivityRecognitionClient activityRecognitionClient;
        2. protected void onCreate(Bundle savedInstanceState) {    
        3.               activityRecognitionClient = ActivityRecognition.getClient(this);     
        4. };
    
    

## **2.3 活动识别更新**

使用活动识别服务，首先需要您注册活动识别更新，可以检测用户当前是步行，骑自行车，静止等状态。

** _步骤1：新建PendingIntent_**
      
      1.  //获取PendingIntent及回调结果的方式可自定义，这里以广播为例进行说明

        5.      Intent intent = new Intent(this, LocationBroadcastReceiver.class);
        6.      intent.setAction(LocationBroadcastReceiver.ACTION_PROCESS_LOCATION);

        10.                @Override
        11.                public void onFailure(Exception e) {
        12.                    Log.e(TAG, "requestActivityUpdates onFailure:" + e.getMessage());
        13.                 }
        14.                });
        15.       } catch (Exception e) {
        16.          Log.e(TAG, "requestActivityUpdates exception:" + e.getMessage());
        17.       }
    
    

**_步骤3：_**** _移除活动识别更新_**

在使用完活动识别后需要进行移除操作，移除活动识别定时监听，参数PendingIntent必须与requestActivityUpdates (long detectionIntervalMillis, PendingIntent callbackIntent)参数里的PendingIntent是同一个。
      
      1. try {

        10.        .addOnFailureListener(new OnFailureListener() {
        11.                @Override
        12.                public void onFailure(Exception e) {
        13.                    Log.e(TAG, "removeActivityUpdates onFailure:" + e.getMessage());
        14.                 }

        16.      } catch (Exception e) {
        17.            Log.e(TAG, "removeActivityUpdates exception:" + e.getMessage());
        18.      }
    
    

**_步骤4：_** _**活动识别结果获取**_

活动识别结果。

        12.     }
        13. }
    
    

**2.4 活动过渡更新**  


接口提供检测活动过渡条件（进入，退出）的功能，例如需要检测用户从走路变为骑自行车的状态时，应用通过调用requestActivityTransitionUpdates(request, pendingIntent)方法获取活动过渡的状态变化。

** _步骤1：_** _**设置监听活动过渡请求参数**_
      
      1.  int STILL = 3;
        2. ActivityTransition activityTransition1 = new ActivityTransition(STILL, 0);    
        3. ActivityTransition activityTransition2 = new ActivityTransition(STILL, 1);
        4. List<ActivityTransition> transitions = new ArrayList<>();   
        5. transitions.add(activityTransition1);       
        6. transitions.add(activityTransition2);    
        7. ActivityTransitionRequest request = new ActivityTransitionRequest();
        8. request.setTransitions(transitions);
