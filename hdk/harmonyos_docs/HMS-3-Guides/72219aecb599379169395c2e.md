# 1\. 场景介绍

游戏登录是指开发者为应用申请游戏服务后，华为允许应用使用用户的华为帐号登录游戏。通过华为游戏服务，开发者可以安全快速地获取用户，共享华为庞大的用户资源。

游戏登录的各种场景交互细节如下所示：

● 场景1：游戏启动时登录华为帐号。

1、用户启动游戏，应用加载游戏首页。

2、如果用户在当前设备未登录华为帐号，将展示华为帐号登录页面。

3、如果用户的华为帐号为中国大陆用户且未进行实名认证，将展示实名认证页面引导用户实名认证。中国大陆以外地区用户不展示实名认证页面。

4、用户登录成功后，应用可以获取玩家信息。

● 场景2：游戏启动时跳过华为帐号登录。

1、用户启动游戏，应用加载游戏首页。

2、如果用户在当前设备未登录华为帐号，将展示华为帐号登录页面。

3、用户选择取消登录返回游戏首页。

4、应用允许用户匿名或通过非华为帐号进入游戏。

说明：

中国大陆地区发布的网络游戏不允许跳过华为帐号登录，仅允许部分单机游戏通过游客方式进入游戏。

● 场景3：游戏内登录。

1、用户点击游戏内华为帐号登录入口按钮，展示华为帐号登录页面。游戏内登录入口图标需使用华为帐号图标标识，具体要求请参见[华为图标规范](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/icon-specification)。

2、用户输入帐号信息后点击登录。

3、用户登录成功后，应用可以获取华为帐号下的玩家信息。  


说明：

此场景仅允许中国大陆以外地区发布的游戏实现，中国大陆地区发布的游戏不允许游戏内登录。

# 2\. 业务流程

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191202141628.91653104256633685447941926590705:50510506084531:2800:DC8F7B0511A5A56F9ABE57F009AA18861C80549B597A805DFC0DC5D1AB282470.png?needInitFileName=true)

1、用户启动游戏时登录，或在游戏内通过华为帐号登录图标入口登录（仅适用于中国大陆以外地区）。

2、应用调用[HuaweiIdSignIn](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-huaweiidsignin)的getClient方法请求初始化[HuaweiIdSignInClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-huaweiidsignInclient)实例。

3、HMS SDK向应用返回当前用户的[HuaweiIdSignInClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-huaweiidsignInclient)实例。

4、应用调用[HuaweiSignInClient.getSignInIntent](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-huaweiidsignInclient#getSignInIntent)方法向HMS SDK发起华为帐号登录请求。

5、HMS SDK检查用户的华为帐号登录情况。  
如果用户在当前终端未登录华为帐号，转到6。否则，转到8。

6、HMS SDK向用户拉起华为帐号登录页面。

7、用户在华为帐号登录页面进行登录操作。

  * 如果用户输入华为帐号名和密码后确认登录，转到下一步。

  * 如果用户此时选择取消登录，则直接回到游戏首页。对于中国大陆发布的游戏，仅允许少量单机游戏通过游客方式访问 。对于中国大陆以外地区发布的游戏，由应用自行控制是否匿名或通过其他帐号进入游戏，本流程结束，如果用户后续再通过游戏内的华为帐号登录图标入口登录，则从2重新开始登录流程。




8、HMS SDK检查用户华为帐号的实名认证情况。  
如果是中国大陆用户且未进行实名认证，转到9。否则，转到11。

9、HMS SDK向用户拉起实名认证页面。

10、用户提交实名认证信息。

11、HMS SDK向应用返回[SignInHuaweiId](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-signInhuaweiId)对象，应用可以从该对象中获取用户的华为帐号信息。

12、HMS SDK向用户展示欢迎信息。

13、如果游戏配置了游戏公告，HMS SDK同时向用户展示游戏公告信息。

14、应用调用[Games.getPlayersClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/games-v3#getPlayersClient)方法请求初始化[PlayersClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/playersclient-v3)实例。

15、HMS SDK向应用返回当前玩家的[PlayersClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/playersclient-v3)实例。

16、应用调用[PlayersClient.getCurrentPlayer](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/playersclient-v3#getCurrentPlayer)方法向HMS SDK请求获取当前玩家信息。   

17、HMS SDK向应用返回包含当前玩家信息的[Player](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/player-v3)对象。

18、应用从Player对象中获取用户昵称、用户头像、用户等级（[PlayerLevelInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/playerlevelInfo-v3)对象）、登录签名、时间戳等信息。

  * 如果应用有自己的开发者服务器，转到19。

  * 如果应用没有自己的服务器，则由应用客户端直接调用[校验登录签名](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/verify-login-signature-v3)接口请求登录签名验证，验证成功后即可允许玩家进入游戏。    




注意：

为了保证安全性，强烈建议由应用服务端进行登录签名验证。

19、应用根据获取的玩家信息向开发者服务器请求进行登录验签，以验证玩家信息的准确性。    

20、开发者服务器调用[校验登录签名](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/verify-login-signature-v3)接口向华为服务器请求进行登录签名验证。

21、华为服务器向开发者服务器返回验签结果。

22、开发者服务器验证华为游戏服务器返回的验签结果后向应用客户端返回验签结果。

23、如果游戏有自己的游戏帐号，需检查当前华为帐号与玩家当前游戏帐号的关联情况。  


对于有自己的游戏帐号并且支持存档的游戏，当用户以华为帐号登录游戏时，为保证用户可以在华为帐号下继续之前的游戏，开发者需要根据以下不同场景进行不同的操作。

  * 如果当前华为帐号未关联任何游戏帐号，且当前游戏帐号也未关联任何华为帐号，开发者可选择自动或提示用户确认后将当前登录华为帐号与当前游戏帐号关联。

  * 如果当前华为帐号已与玩家的其他游戏帐号关联，且当前游戏帐号已与其他华为帐号关联，提示并让用户选择执行以下操作：

    - 加载当前登录华为帐号关联的游戏帐号（存档）。  
    - 继续当前游戏。

  * 如果当前华为帐号已与玩家的其他游戏帐号关联，但当前游戏帐号未与其他华为帐号关联，提示并让用户选择执行以下操作：

    - 加载当前登录华为帐号关联的游戏帐号（存档）。  
    - 继续当前游戏。  
    - 更新当前登录华为帐号绑定的游戏帐号为当前游戏帐号。    




24、在确认登录成功后，应用允许玩家进入游戏。    

# 3\. 注意事项

  * 使用华为帐号登录游戏前，必须已经提前为应用打开帐号和游戏服务，参见[打开相关服务](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/game-preparation-v3#service)。

  * 如果用户在游戏最初启动登录流程时拒绝登录，当玩家再次启动游戏时，不要自动调用登录接口，避免用户在开始游戏时反复拒绝登录。

  * 用户在游戏过程中切出游戏并在其他应用中切换了华为帐号，再次回到游戏时，应用必须重新调用[PlayersClient.getCurrentPlayer](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/playersclient-v3#getCurrentPlayer)检查玩家ID是否与现有玩家ID一致，如果不一致则需要引导用户重新登录。




# 4\. 开发步骤

游戏登录功能涉及的关键开发步骤如下：

1、调用[HuaweiIdSignIn](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-huaweiidsignin)的getClient方法请求初始化[HuaweiIdSignInClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-huaweiidsignInclient)实例。
      
      1. HuaweiIdSignInClient signInClient = HuaweiIdSignIn.getClient(this, HuaweiIdSignInOptions.DEFAULT_GAMES_SIGN_IN);
    
    

2、调用[HuaweiIdSignInClient.getSignInIntent](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-huaweiidsignInclient#getSignInIntent)方法发起华为帐号登录。   
      
      1. startActivityForResult(signInClient.getSignInIntent(), 8888);
    
    

3、在页面的onActivityResult中处理登录结果，调用[HuaweiIdSign.getSignedInAccountFromIntent](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-huaweiidsignin#HuaweiIdSignIn-getSignedInAcconutFromIntent)方法获取登录授权结果。    
      
      1. private SignInHuaweiId huaweiIdInfo;    //记录登录结果对象
        2. //获取登录结果信息
        3. public SignInHuaweiId getHuaweiIdInfo() {
        4.     return huaweiIdInfo;
        5. }
        6. //记录登录结果信息
        7. public void setHuaweiIdInfo(SignInHuaweiId huaweiIdInfo) {
        8.     this.huaweiIdInfo = huaweiIdInfo;
        9. }
        10. protected void onActivityResult(int requestCode, int resultCode, Intent data) {
        11.     super.onActivityResult(requestCode, resultCode, data);
        12.     if (requestCode == 8888) {
        13.         Task<SignInHuaweiId> signInHuaweiIdTask = HuaweiIdSignIn.getSignedInAccountFromIntent(data);
        14.         if (signInHuaweiIdTask.isSuccessful()) {
        15.             setHuaweiIdInfo(signInHuaweiIdTask.getResult());
        16.             // TODO: 登录成功，获取用户信息 | sign in success, get user information
        17.             Log.i(TAG, "sign in success, user info: " + signInHuaweiIdTask.getResult().toString());
        18.         } else {
        19.             // 登录失败 | sign in fail
        20.             Log.e(TAG, "sign in failed, status: " + ((ApiException) signInHuaweiIdTask.getException()).getStatusCode());
        21.         }
        22.     }
        23. }
    
    

4、应用调用[Games.getPlayersClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/games-v3#getPlayersClient)方法请求初始化[PlayersClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/playersclient-v3)实例，并调用[PlayersClient.getCurrentPlayer](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/playersclient-v3#getCurrentPlayer)方法获取当前玩家信息。
      
      1. private void currentPlayerInfo() {
        2.     PlayersClient playersClient = Games.getPlayersClient(this, getHuaweiIdInfo());
        3.     Task<Player> playerTask = playersClient.getCurrentPlayer();
        4.     playerTask.addOnSuccessListener(new OnSuccessListener<Player>() {
        5.         @Override
        6.         public void onSuccess(Player player) {
        7.             // TODO 请求成功，获取玩家信息
        8.             Log.i(TAG, "getPlayerInfo Success, player info: " + player.toString());
        9.         }
        10.     }).addOnFailureListener(new OnFailureListener() {
        11.         @Override
        12.         public void onFailure(Exception e) {
        13.             // 获取玩家信息失败
        14.             if (e instanceof ApiException) {
        15.                 Log.e(TAG, "getPlayerInfo failed, status: " + ((ApiException) e).getStatusCode());
        16.             }
        17.         }
        18.     });
        19. }
    
    

5、应用根据获取的登录签名调用[校验登录签名](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/verify-login-signature-v3)接口对玩家信息进行验签。    

注意：

为了确保游戏私钥和游戏公钥的安全性，强烈建议将验签过程放在应用服务端进行。如果没有服务器保存密钥，建议在C或者C++语言编译的库中存储密钥，或者在java代码中分不同位置存储密钥，然后相加获得完整密钥。

6、如果游戏有自己的游戏帐号，需执行当前华为帐号与游戏帐号的关联，具体由开发者自行开发。
