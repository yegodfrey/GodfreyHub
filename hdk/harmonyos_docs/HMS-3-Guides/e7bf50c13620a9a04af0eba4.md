准备一部华为手机，且“HMS Core（APK）”版本在2.6.5及以上。完成上述获取转化跟踪参数业务代码的补全后，就可以进行编译。编译有错误时，根据错误提示，进行代码修改。完成编译后，生成apk安装并运行。

# 1\. 生成转化跟踪参数

由于转化跟踪参数需要在华为广告平台投放后才能正常获取，我们在此处提供了Demo，可以在端侧生成转化跟踪参数，供开发者APP在测试阶段调测使用。Demo下载地址参考“[示例代码](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Examples/3030510-v3 "示例代码")”。

注意：

只有包名为“com.huawei.pps.hms.test”的工程，才可以使用获取转化跟踪参数的测试功能。

# 2\. 修改您的App用于测试转化跟踪参数

## 2.1 SDK方式

在创建InstallReferrerClient时设置为测试模式，调用setTest(true)，如下图所示：
    
    
    复制
      
        1. mReferrerClient = InstallReferrerClient.newBuilder(mContext).setTest(true).build();
        2. mReferrerClient.startConnection(installReferrerStateListener);
    
    

注意：

setTest(true)仅用于测试，正式发布版本请setTest(false)。

## 2.2 AIDL方式

在测试时设置绑定的AIDL服务的包名为”com.huawei.pps.hms.test”，如下图所示：
    
    
    复制
      
        1. mServiceConnection = new InstallReferrerServiceConnection();
        2. Intent intent = new Intent(Constants.SERVICE_ACTION);
        3. intent.setPackage(Constants.TEST_SERVICE_PACKAGE_NAME);
        4. boolean result = mContext.bindService(intent, mServiceConnection, Context.BIND_AUTO_CREATE);
        5. Log.i(TAG, "bindService result: " + result);
    
    

注意：

包名“com.huawei.pps.hms.test”仅用于测试，正式发布版本请使用包名“com.huawei.hwid”。

# 3\. 正确集成转化跟踪参数功能

如果从日志中可以看到正确获取转化跟踪参数，表示您的App已正确集成转化跟踪参数功能。
