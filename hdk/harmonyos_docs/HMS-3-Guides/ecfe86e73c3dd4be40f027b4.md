# 1. 服务场景举例

开发一个APP产品“示例PUSH服务”，通过接入HUAWEI Push Kit，用来实现如下功能：

1. 推送最新消息至消费者终端上的APP。

2. 消费者点击消息可实现如下4个场景之一。

l   点击PUSH消息打开指定APP

l   点击PUSH消息打开指定网页

l   点击PUSH消息自定义行为

l   点击PUSH消息打开富媒体内容

# 2. 开发流程

开发者需按照接入流程指导来完成客户端部分的开发和服务端部分的开发。

将上文的开发场景分解如下：

1、消息发送与接收

l   客户端开发\--实现消息接收

开发者的APP客户端接收HUAWEI Push Kit发送的消息。

l   服务端开发\--实现消息发送

开发者在自己的APP服务器上调用PUSH接口，通过HUAWEI Push Kit实现消息批量发送，同时可以自定义发送消息的格式和内容以及选择推送的客户端。

2、点击消息触发动作

点击消息后触发动作由华为终端EMUI系统自动实现，应用开发者只需要做消息封装即可。
