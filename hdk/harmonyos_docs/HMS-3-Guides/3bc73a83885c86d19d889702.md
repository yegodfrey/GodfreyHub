# 1\. 场景介绍

发布地区中包含中国大陆的游戏，必须集成游戏助手。游戏助手是指游戏界面中以浮标方式展示华为游戏中心的入口，用户点击浮标后可查看用户在华为游戏中心的游戏增值功能，如浏览论坛、领取礼包、查看攻略、游戏录屏等。

# 2\. 业务流程

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191202152026.89255567551726602594879420086855:50510323023659:2800:AF9E982FD10C5D2A73F96495EA94CC1CB544D984F0EC4FE04DADD3D6212328F8.png)

1、用户启动游戏后，游戏完成启动流程，具体参见[游戏启动](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/game-start-v3)。

2、应用调用[showFloatWindow](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/showfloatwindow-v3)接口请求展示游戏助手浮标。

3、HMS SDK在游戏界面展示游戏助手浮标。

4、用户点击游戏浮标。

如果当前设备未安装华为游戏中心，系统将提示下载并安装华为游戏中心。

5、HMS SDK向用户展示游戏助手页面。

6、用户在游戏助手页面中操作，例如查看论坛热帖、查看礼包等。

7、HMS SDK向华为游戏中心请求相关信息。

8、华为游戏中心向HMS SDK返回相关信息。

9、HMS SDK在游戏助手页面展示用户查看的信息。

10、用户离开当前游戏界面。

11、应用调用[hideFloatWindow](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/hidefloatwindow-v3)接口请求隐藏浮标。

12、HMS SDK隐藏浮标。

# 3\. 注意事项

  * 中国大陆发布的游戏必须集成游戏浮标，中国大陆以外地区无需集成。

  * 浮标的展示和隐藏功能，在本应用的所有游戏操作界面中都要具备。




# 4\. 开发步骤

游戏助手功能涉及应用的关键开发步骤如下：

1、在游戏启动时初始化HuaweiApiClient对象并连接HMS Core（APK），具体方法参见[初始化HuaweiApiClient对象](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/game-apiclient)。

注意：

本步骤仅在游戏启动或当前连接断开时执行，请勿重复连接HMS Core（APK）。
    
    
    复制
      
        1. HuaweiApiClient apiClient =  new HuaweiApiClient.Builder(this)
        2.             .addApi(HuaweiGame.GAME_API)
        3.             .addConnectionCallbacks(new HuaweiApiClient.ConnectionCallbacks() {
        4.                 @Override
        5.                 public void onConnected() {
        6.                     //connect成功
        7.                 }
        8.                 @Override
        9.                 public void onConnectionSuspended(int cause) {
        10.                 }
        11.             })
        12.             .addOnConnectionFailedListener(new HuaweiApiClient.OnConnectionFailedListener() {
        13.                 @Override
        14.                 public void onConnectionFailed(ConnectionResult connectionResult) {
        15.                 }
        16.             }) .build();
        17.  apiClient.connect(this);
    
    

2、调用[showFloatWindow](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/showfloatwindow-v3)接口。

应用需要在所有游戏界面Activity的onResume中调用showFloatWindow接口展示浮标。  
示例代码如下：
    
    
    复制
      
        1. protected void onResumeShowFloat() {
        2.     super.onResume();
        3.     Log.i(TAG,"apiClient isConnected："+apiClient.isConnected());
        4.     if (apiClient != null && apiClient.isConnected()) {
        5.         PendingResult<ShowFloatWindowResult> pendingRst = HuaweiGame.HuaweiGameApi.showFloatWindow(apiClient,this);
        6.         pendingRst.setResultCallback(new ResultCallback<ShowFloatWindowResult>() {
        7.             @Override
        8.             public void onResult(ShowFloatWindowResult showFloatWindowResult) {
        9.                 int code = showFloatWindowResult.getStatus().getStatusCode();
        10.                 Log.i(TAG,"if showFloatWindowResult code:"+code);
        11.             }
        12.         });
        13.     }
        14.     else {
        15.         apiClient.connect(this);
        16.         apiClient.setConnectionCallbacks(new HuaweiApiClient.ConnectionCallbacks() {
        17.             @Override
        18.             public void onConnected() {
        19.                 Log.i(TAG,"else apiClient isConnected:"+apiClient.isConnected());
        20.                 PendingResult<ShowFloatWindowResult> pendingRst = HuaweiGame.HuaweiGameApi.showFloatWindow(apiClient,GameActivity.this);
        21.                 pendingRst.setResultCallback(new ResultCallback<ShowFloatWindowResult>() {
        22.                     @Override
        23.                     public void onResult(ShowFloatWindowResult showFloatWindowResult) {
        24.                         int code = showFloatWindowResult.getStatus().getStatusCode();
        25.                         Log.i(TAG,"else showFloatWindowResult code:"+code);
        26.                     }
        27.                 });
        28.             }
        29.             @Override
        30.             public void onConnectionSuspended(int i) {
        31.             }
        32.         });
        33.     }
        34. }
    
    

3、HMS SDK展示浮标，用户点击浮标打开游戏助手，并在游戏助手页面中互动，此部分由HMS SDK自行完成，开发者无需关注。

注意：

游戏调试阶段，需要测试浮标能正常拖动、隐藏，翻转手机浮标能显示。如果点击浮标界面提示“没有相关内容”或无法“无法连接服务器，请稍后重试”，是因为游戏没有上线，调试时可忽略。

4、调用[hideFloatWindow](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/hidefloatwindow-v3)接口。  


应用需要在Activity的onPause中调用hideFloatWindow接口隐藏浮标。  
示例代码如下：
    
    
    复制
      
        1. private void onPauseHideFloat() {
        2.     super.onPause();
        3.     Log.i(TAG,"into onPauseHideFloat");
        4.     if (apiClient != null && apiClient.isConnected()){
        5.         Log.i(TAG,"if into onPauseHideFloat apiClient isConnected:"+apiClient.isConnected());
        6.         HuaweiGame.HuaweiGameApi.hideFloatWindow(apiClient, this);
        7.     }else{
        8.         apiClient.connect(this);
        9.         Log.i(TAG,"else into onPauseHideFloat:"+apiClient.isConnected());
        10.     }
        11. }
