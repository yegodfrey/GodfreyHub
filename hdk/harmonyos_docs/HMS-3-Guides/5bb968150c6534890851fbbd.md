# 1\. 使用场景

广告主APP开发者可通过Ads Kit提供SDK，获得APP转化跟踪参数，广告主可基于转化跟踪参数进行APP推广渠道分析，方便开发者清楚掌握各渠道转化效果分析。

# 2\. 注意事项

获取转化跟踪参数前，确保APP必须已经集成ads-installreferrer SDK，参见[开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/3030302 "开发准备")。

# 4\. 开发步骤

1.创建转化跟踪参数状态监听器。

实现[InstallReferrerStateListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/3030505 "InstallReferrerStateListener")监听器接口的两个方法onInstallReferrerSetupFinished和onInstallReferrerServiceDisconnected，代码示例如下：
    
    
    复制
      
        1. /**
        2.  * Create a listener.
        3.  */
        4. private InstallReferrerStateListener installReferrerStateListener = new InstallReferrerStateListener() {
        5.     @Override
        6.     public void onInstallReferrerSetupFinished(int responseCode) {
        7.         switch (responseCode) {
        8.             case InstallReferrerClient.InstallReferrerResponse.OK:
        9.                 Log.i(TAG, "connect ads kit ok");
        10.                 getInstallReferrer();
        11.                 break;
        12.             case InstallReferrerClient.InstallReferrerResponse.FEATURE_NOT_SUPPORTED:
        13.                 Log.i(TAG, "FEATURE_NOT_SUPPORTED");
        14.                 mCallback.onFial("Please upgrade HMS version to 2.6.5 or later");
        15.                 break;
        16.             case InstallReferrerClient.InstallReferrerResponse.SERVICE_UNAVAILABLE:
        17.                 Log.i(TAG, "SERVICE_UNAVAILABLE");
        18.                 mCallback.onFial("Please install the lasted version of HMS app");
        19.                 break;
        20.             default:
        21.                 Log.i(TAG, "responseCode: " + responseCode);
        22.                 break;
        23.         }
        24.     }
        25.     @Override
        26.     public void onInstallReferrerServiceDisconnected() {
        27.         Log.i(TAG, "onInstallReferrerServiceDisconnected");
        28.     }
        29. };
    
    

2.创建[InstallReferrerClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/3030506-v3 "InstallReferrerClient")实例。

**步骤1** 调用[InstallReferrerClient.newBuilder](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/3030507-v3 "InstallReferrerClient.newBuilder")创建一个Builder实例。

**步骤2** 调用[build](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/3030507-v3 "build")创建[InstallReferrerClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/3030506-v3)实例。

mReferrerClient = InstallReferrerClient.newBuilder(InstallReferrerActivity.this).build();

3.连接转化跟踪参数服务。

**说明：**

建立与转化跟踪参数服务的连接，不要在主线程中调用该方法。

**步骤1** 创建一个子线程。

**步骤2** 设置[startConnection](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/3030506-v3 "startConnection")的监听器为2中已创建的[InstallReferrerStateListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/3030505 "InstallReferrerStateListener") 监听器。
    
    
    复制
      
        1. private Thread connectThread = new Thread() {
        2.    @Override
        3.    public void run() {
        4.        connect();
        5.    }
        6. };
        7. /**
        8. * 连接HMS服务
        9. */
        10. private void connect() {
        11.     mReferrerClient = InstallReferrerClient.newBuilder(InstallReferrerActivity.this).build();
        12.     mReferrerClient.startConnection(installReferrerStateListener);
        13. }
