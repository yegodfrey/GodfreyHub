AppGalleryKit联运服务是指华为和开发者为将应用通过华为应用市场发布而进行的联运分成合作。华为向开发者提供华为应用市场平台能力接入、数据报表、活动运营、用户运营等一系列服务，开发者可以借此获取多种优质华为应用市场推荐资源。联运服务的合作模式包括但不限于付费应用与应用内购买业务。

● “付费应用”：是指用户需要支付一定金额以后，才可以下载及安装的应用。

● “应用内购买”：是指用户在安装应用后，使用应用的过程中，通过支付一定金额购买应用内的数字内容、高级功能或其他增值服务。用户的支付行为在应用内产生。

开发者接入联运服务前必须与华为签订[联运服务协议](https://developer.huawei.com/consumer/cn/doc/20204)。更详细的联运服务介绍请参见[联运服务介绍](https://developer.huawei.com/consumer/cn/doc/60801)。

# HMS Core

联运服务需要使用[HMS Core](https://developer.huawei.com/consumer/cn/hms)的能力，其中涉及联运的相关服务如下：

● 华为帐号：全球华为用户有数亿规模，将华为帐号添加到您的应用中，您的应用可以方便、安全、快速的使用华为帐号登录，从而迅速推广应用，共享华为庞大的用户价值。华为帐号业务详细介绍可参见[华为帐号业务介绍](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/account-introduction-v3)。

● 华为支付：使用华为支付，您可以为用户提供方便、安全的支付，支持多种支付方式。HUAWEI IAP当前已经覆盖全球100多个国家和地区，不久将会覆盖全球绝大部分国家和地区。华为支付的详细业务介绍可参见[华为支付业务介绍](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/iap-introduction)。

● 游戏服务：华为游戏服务为开发者提供了华为帐号登录、公告等基本能力，并且支持快速实现游戏成就、游戏事件上报等功能，支持开发者快速、低成本的构建游戏。

● 华为分析：联运服务要求开发者在应用启动后初始化华为分析服务，用于采集系统级事件和基于Activity的页面事件，开发者可根据采集的数据进行报表分析和用户分析。

● 应用升级：开发者可以使用AppGallery静默安装能力，方便、快捷、及时的在应用内提示升级。

● 其他服务：HMS Core的其他服务为可选接入，开发者可根据实际需求接入。

# 联运应用

联运应用是指开发者接入联运服务后开发的非游戏类应用，联运应用要求开发者接入的服务：华为帐号、华为支付、华为分析、应用升级。

# 联运游戏

联运游戏是指开发者接入联运服务后开发的游戏类应用，联运游戏要求开发者接入的服务：华为帐号、华为支付、游戏服务、华为分析、应用升级。
