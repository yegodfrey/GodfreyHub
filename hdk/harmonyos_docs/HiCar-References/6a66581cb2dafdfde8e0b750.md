# 融合桌面应用操作

## 场景说明

车机将获取的来自HiCar的应用显示到车机原生界面后，当用户点击这部分应用图标后，车机需按照HiCar SDK设定的方式与HiCar进行交互。

## Data Type

529

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:-------------|:----|:-----|:-------------------------------------------------------------------------------------------|
|RequestApp|必选|object|请求数据，详见[表2](#ZH-CN_TOPIC_0000001975712798__zh-cn_topic_0000001557372653_table126461732397)。|
|RequestAppResp|必选|object|响应数据，详见[表3](#ZH-CN_TOPIC_0000001975712798__zh-cn_topic_0000001557372653_table1943683611395)。|
[**表1**应用操作接口]

|参数名称|必选/可选|类型|说明|
|:---------|:----|:-----|:---------------|
|Action|必选|string|操作类型： * start：打开|
|AppPackage|必选|string|应用包名。|
[**表2**RequestApp]

|参数名称|必选/可选|类型|说明|
|:----------|:----|:-----|:-----------------------------------------------|
|RespCode|必选|int|响应结果： * 100000：处理成功 * 100001：处理失败 * 100002：应用不存在|
|AppPackage|必选|string|应用包名。|
|Description|可选|string|描述信息。|
[**表3**RequestAppResp]

## 接口示例

车机向HiCar App请求打开某个应用的示例代码如下所示：

```screen
{
    "RequestApp" : {
        "Action" : "start",
        "AppPackage" : "com.android.mediacenter"
    }
}
```

HiCar App在收到请求后，回应消息示例如下所示：

```screen
{
    "RequestAppResp" : {
        "RespCode" : 100000,
        "AppPackage" : "com.android.mediacenter",
        "Description" : "success"
    }
}
```
