# DMSDPAudioChannelMasks

|Enumerator|Desc|
|:------------------------------|:------------------|
|AUDIO_CHANNEL_OUT_MONO = 0x1u|车机Speaker输出的能力为单声道。|
|AUDIO_CHANNEL_OUT_STEREO = 0x3u|车机Speaker输出的能力为双声道。|
|AUDIO_CHANNEL_IN_MONO = 0x10u|车机Mic采集的能力为单声道。|
|AUDIO_CHANNEL_IN_STEREO = 0xCu|车机Mic采集的能力为双声道。|
