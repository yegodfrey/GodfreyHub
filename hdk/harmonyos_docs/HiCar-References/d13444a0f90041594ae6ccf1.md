# GetVideoData

|Function|
|:---------------------------------------------------------------------------------------------------------------------------|
|int32_t (*GetVideoData)(const uint8_t *pPacket, uint32_t nPktSize, int64_t timeStamp,int64_t duration, VideoFrameInfo *info)|
|获取投屏视频流数据。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:----------------------------------------------------------------------------------------------------------------|:-----------------|
|*pPacket|uint8_t|视频字节流数据（byte）。|
|nPktSize|uint32_t|当前帧数据大小（byte）。|
|timeStamp|int64_t|当前帧时间戳。|
|duration|int64_t|HiCar业务不涉及，默认为0即可。|
|*info|[VideoFrameInfo](https://developer.huawei.com/consumer/cn/doc/HiCar-References/video-frame-info-0000001050172654)|额外的帧信息。|

**Return**

|Type|Desc|
|:------|:----------------------|
|int32_t|返回结果： * 0：正常显示 * -1：帧丢弃|
