# 虚拟通话

## 场景说明

HiCar App需要车机上报是否支持虚拟通话能力，用于HiCar连接后的通话音频使能。

## Data Type

523

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:---------|:----|:-----|:----------------------------------------------------------------------------------------|
|service|必选|string|业务类型，当前业务取值"virtualModem"。|
|subService|必选|string|子业务类型，当前业务取值"capability"。|
|command|必选|int|命令字： * 0：HiCar App询问车机是否支持虚拟Modem。 * 1：车机响应是否支持虚拟Modem。|
|errorCode|必选|int|车机响应信息见错误码列表。 * 100000：支持 * 100003：不支持|
|data|可选|object|参数。详见[表2](#ZH-CN_TOPIC_0000001194963766__zh-cn_topic_0000001225428385_table788971315254)。|
[**表1**虚拟通话能力]

|参数名称|必选/可选|类型|说明|
|:---------|:----|:--|:---------------|
|showCallUI|必选|int|* 0：不展示HiCar通话胶囊|
[**表2**data]

## 接口示例

HiCar App查询车机是否支持虚拟Modem。

```screen
{
    "service":"virtualModem",
    "subService":"capability",
    "command":0
}
```

车机应答HiCar App支持虚拟Modem。

```screen
{
    "service":"virtualModem",
    "subService":"capability",
    "command":1,
    "errorCode":100000
}
```

车机应答HiCar App不支持虚拟Modem。

```screen
{
    "service":"virtualModem",
    "subService":"capability",
    "command":1,
    "errorCode":100003
}
```

若是车机不支持虚拟通话的情况下，需要增加字段屏蔽HiCar通话胶囊。示例如下所示：

```screen
{
    "service":"virtualModem",
    "subService":"capability",
    "command":1,
    "errorCode":100003,
    "data":{
        "showCallUI":0
    }
}
```
