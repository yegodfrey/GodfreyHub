# 车机屏幕息亮屏

## 场景说明

如果车机支持控制车机屏幕息屏/亮屏操作，连接HiCar后，用户可以通过HiCar语音操控车机屏幕息屏或亮屏。例如：用户语音 "打开屏幕"，车机屏幕点亮；用户语音"关闭屏幕"，车机屏幕息屏。

## Data Type

521

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:----------------|:----|:-----|:-----------------------------------------------------------------------------------|
|queryScreenState|必选|string|HiCar App向车机查询当前车机屏幕的息屏/亮屏状态，字段值为"state"。|
|isSupportAbility|可选|int|车机上报是否支持操作车机屏幕息屏/亮屏操作： * 1：支持 * -1：不支持|
|screenState|可选|int|当前车机屏幕的息屏/亮屏状态： * 1：打开，即亮屏状态 * 2：关闭，即息屏状态|
|deviceScreenOper|可选|int|车机屏幕操作指令： * 1：打开，即亮屏指令 * 2：关闭，即息屏指令|
|response|可选|int|操作响应返回码： * 100000：成功 * 100004：失败|
|screenStateChange|可选|int|屏幕息屏/亮屏状态在非HiCar指令触发时发生变化，例如用户通过物理按键控制屏幕息屏/亮屏，需要主动上报HiCar App： * 1：打开，即亮屏 * 2：关闭，即息屏|
[**表1**操作车机屏幕息屏/亮屏接口]

## 接口示例

1. 查询车机是否具备语音操作车机屏幕的能力。
   1. HiCar App向车机发送查询消息。

      ```screen
      {
          "queryScreenState":"state"
      }
      ```

   2. 车机向HiCar App返回响应消息。

      （1）支持，并且当前处于开启状态。

      ```screen
      {
          "isSupportAbility":1,
          "screenState":1
      }
      ```

      （2）支持，并且当前处于关闭状态

      ```screen
      {
          "isSupportAbility":1,
          "screenState":2
      }
      ```

      （3）不支持

      ```screen
      {
          "isSupportAbility":-1
      }
      ```

2. 用户语音操作打开/关闭车机屏幕。
   1. HiCar App向车机发送操作指令消息。

      （1）打开屏幕

      ```screen
      {
          "deviceScreenOper":1
      }
      ```

      （2）关闭屏幕

      ```screen
      {
          "deviceScreenOper":2
      }
      ```

   2. 车机向HiCar App返回响应消息。 （1）成功应答

      ```screen
      {
          "response":100000
      }
      ```

      （2）失败应答

      ```screen
      {
          "response":100004
      }
      ```

3. 车机主动上报屏幕状态，例：用户操作车机硬件开关，开启/关闭屏幕。 车机主动向HiCar App发送消息。

   ```screen
   {
       "screenStateChange":1
   }
   ```
