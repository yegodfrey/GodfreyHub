# CloseCamera

|Function|
|:--------------------------------------------------------------------|
|int32_t (*CloseCamera)(const char* id, uint32_t idLen)|
|函数指针定义，表示根据指定参数关闭Camera设备，南向返回该接口实现函数地址，北向Dvkit根据业务需要调用该函数关闭Camera设备。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-----------------|:-------------|
|*id|const char|Camera ID。|
|idLen|uint32_t|Camera ID长度。|

**Return**

|Type|Desc|
|:------|:-----------------------------------|
|int32_t|返回结果： * 0：关闭Camera成功 * 非0：关闭Camera异常|
