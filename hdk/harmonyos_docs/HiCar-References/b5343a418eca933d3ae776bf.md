# DMSDPAudioDevice

|Enumerator|Desc|
|:-----------------------------------|:---------------------------------|
|AUDIO_DEVICE_TYPE_SPEAKER = 0u|虚拟出来的普通speaker，比如播放音乐，导航播报等。|
|AUDIO_DEVICE_TYPE_MIC = 1u|虚拟出来的普通Mic，比如语音交互时用来采集录音。|
|AUDIO_DEVICE_TYPE_MODEM_SPEAKER = 2u|虚拟出来的通话speaker，专门用来播放打电话过程中远端的说话声。|
|AUDIO_DEVICE_TYPE_MODEM_MIC = 3u|虚拟出来的通话mic，专门用来采集打电话过程中本端用户的说话声。|
