# obtainFileShareNotificationInstance

|Method|
|:--------------------------------------------------------------------------------------|
|void obtainFileShareNotificationInstance(FileShareStatusNotification notification)|
|车机侧需定义FileShareStatusNotification变量保存该参数，后续通过notifyStatustoPhone方法将车机的授权状态或用户操作状态通知到手机。|

**Parameters**

|Parameter name|Parameter type|Parameter desc|
|:-------------|:--------------------------|:--------------------------------|
|notification|FileShareStatusNotification|详见FileShareStatusNotification类说明。|

FileShareStatusNotification类以及参数相应状态码和返回值说明如下：

```screen
public interface FileShareStatusNotification {
    int notifyStatusToPhone(int status);
}
```

|Method|
|:----------------------------------|
|int notifyStatusToPhone(int status)|
|将车机的授权状态或用户操作状态通知到手机。|

**Parameters**

|Parameter name|Parameter type|Parameter desc|
|:-------------|:-------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|status|int|* 1：同意接收。接下来进入发送中状态，手机端开始发送文件。 * 2：车机侧存储空间不足，拒绝接收。车机应先判断是否有足够的存储空间，满足则弹框询问用户是否同意接收。若存储空间不足车机端应提示用户，并返回状态码2。 * 3：用户主动拒绝接收，根据拒绝原因的不同手机端会有相应的提示。 * 4：车机端取消发送文件 * 5：车机端主动取消接收文件|

**Return**

|Type|Desc|
|:---|:---------------------------------------------------------------------------------------------------|
|int|* 0：成功。 * 1：当前HiCar未连接，车机端应提示用户连接HiCar。 * 2：手机不支持文件互传 * 6：当前为忙碌状态，无法发送消息 * 8：车机没有注册FileShareListener|
