# ServiceUuidRelatedSessionId

|Name|Type|Desc|
|:-----------------------------------|:---|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
|serviceUuid[BT_SERVICE_UUID_LEN + 1]|char|经典蓝牙service uuid。|
|sessionId|int|BR通道可以用一个service uuid询问来建立连接或者通过端口来进行unsecure rfcomm连接。 HiCar BR通道有2个通道连接会话，一个是通过service uuid来建立连接，另一个是通过port来建立连接。 Nearby将BR通道每个连接会话都用一个sessionId来标识。|
