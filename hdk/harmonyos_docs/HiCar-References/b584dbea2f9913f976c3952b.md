# getSecureFileSize

|Function|
|:---------------------------------------------|
|long getSecureFileSize(string fileName)|
|HiCar SDK通过回调的方式，由车机应用实现认证文件的管理，该回调用于获取认证文件大小。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-----------------|:-------------|
|fileName|string|存储认证信息的文件名。|

**Return**

|Type|Desc|
|:---|:------------|
|long|认证文件大小，单位：字节。|
