# CarConnectInfo

|Name|Type|Desc|
|:---------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|modelId[8]|char|华为分配给厂家的ModelId。例如00010001（仅示例）。调试及正式商用时该参数值需要厂商向华为申请获得。|
|brMac[20]|char|车机经典蓝牙地址。格式为AA:BB:CC:DD:EE:FF。有效长度为17。|
|connectAllowType|uint32_t|车机支持的连接方式。第0bit位为0表示不支持无线连接，为1表示支持无线连接；第1bit位为0表示不支持USB连接，为1表示支持USB连接；第2bit位为0表示不支持扫码连接，为1表示支持扫码连接。取值详见[CarConnectAllowType](https://developer.huawei.com/consumer/cn/doc/HiCar-References/car-connect-allow-type-0000001052795163)。|
|carDeviceId|char*|车机唯一标识。|
|idLen|uint32_t|标识的长度。|
