# Release

|Function|
|:----------------------------------------------------|
|void (*Release)(int32_t type, void* ptr,uint32_t num)|
|释放指定类型的资源，比如查询能力后的资源释放，类型为RELEASE_TYPE_QUERY_ABILITY。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-----------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
|type|int32_t|释放资源类型，详见[DMSDPAudioReleaseType](https://developer.huawei.com/consumer/cn/doc/HiCar-References/dmsdp-audio-release-type-0000001051809206)。 对应GetAudioCapability。|
|*ptr|void|对应DMSDPAudioCapabilities* capabilities。|
|num|uint32_t|个数。|
