# 车载摄像头拍照

## 场景说明

如果车机支持控制车载摄像头进行拍照操作，连接HiCar后，用户可以通过HiCar语音操控摄像头拍照。

## Data Type

522

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:---------|:----|:-----|:-----------------------------------------------------------------------------------------|
|service|必选|string|业务类型，当前业务取值为"photo"。|
|subService|必选|string|子业务类型，当前业务取值为"capability"。|
|command|必选|int|命令字： * 0：HiCar App获取拍照相关能力 * 1：HiCar App向车机下发拍照指令 * 2：车机向HiCar App主动上报拍照结果|
|errorCode|必选|int|错误码： * 100000：成功 * 100004：失败|
|data|必选|object|参数。详见[表2](#ZH-CN_TOPIC_0000001199459873__zh-cn_topic_0000001149600291_table6692136122416)。|
[**表1**操作车载摄像头拍照接口]

|参数名称|必选/可选|类型|说明|
|:-----|:----|:-----|:-------------------------------------------------------------------------------------------|
|camera|必选|object|摄像头参数。详见[表3](#ZH-CN_TOPIC_0000001199459873__zh-cn_topic_0000001149600291_table851563482417)。|
[**表2**data]

|参数名称|必选/可选|类型|说明|
|:-----------------|:----|:--|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|isControlSupported|必选|int|车载摄像头是否支持控制，基于bit位上报： * bit0：是否支持操作摄像头，0不支持，1支持 * bit1： 前置摄像头，0不支持，1支持 * bit2： 后置摄像头，0不支持，1支持 * bit3： 左置摄像头，0不支持，1支持 * bit4： 右置摄像头，0不支持，1支持 * bit5： 内部摄像头，0不支持，1支持 * bit6： 360全景摄像头，0不支持，1支持 示例： * 0：不支持 * 7（0000111）：前后摄像头支持|
|position|必选|int|拍照所使用的车载摄像头，基于bit位下发： * bit0：1，使用摄像头进行拍照 * bit1： 前置摄像头，0不使用，1使用 * bit2： 后置摄像头，0不使用，1使用 * bit3： 左置摄像头，0不使用，1使用 * bit4： 右置摄像头，0不使用，1使用 * bit5： 内部摄像头，0不使用，1使用 * bit6： 360全景摄像头，0不使用，1使用 示例： * 3（0000011）：使用前置摄像头拍照 * 7（0000111）：使用前后摄像头拍照|
[**表3**camera]

## 接口示例

1. 查询车机是否具备语音操作车机拍照的能力。
   1. HiCar App向车机发送查询消息。

      ```screen
      {
          "service":"photo",
          "subService":"capability",
          "command":0
      }
      ```

   2. 车机向HiCar App返回响应消息。

      （1）支持并上报摄像头信息。

      ```screen
      {
          "service":"photo",
          "subService":"capability",
          "command":0,
          "errorCode":100000,
          "data":{
              "camera":{
                  "isControlSupported":3
              }
          }
      }
      ```

      （2）不支持。

      ```screen
      {
          "service":"photo",
          "subService":"capability",
          "command":0,
          "errorCode":100004
      }
      ```

2. 用户语音操作车机拍照。
   1. HiCar App向车机发送拍照指令消息。

      ```screen
      {
          "service":"photo",
          "subService":"capability",
          "command":1,
          "data":{
              "camera":{
                  "position":3
              }
          }
      }
      ```

   2. 车机向HiCar App返回响应消息。

      （1）成功应答

      ```screen
      {
          "service":"photo",
          "subService":"capability",
          "command":1,
          "errorCode":100000
      }
      ```

      （2）失败应答

      ```screen
      {
          "service":"photo",
          "subService":"capability",
          "command":1,
          "errorCode":100004
      }
      ```

3. 车机设备主动上报拍照。例：部分设备有自身的语音功能，为防止与HiCar语音冲突，非HiCar App请求需主动上报。 车机向HiCar App主动上报消息。

   ```screen
   {
       "service":"photo",
       "subService":"capability",
       "command":2,
       "data":{
           "camera":{
               "position":3
           }
       }
   }
   ```
