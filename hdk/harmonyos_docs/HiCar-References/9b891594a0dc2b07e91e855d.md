# RequestAudioFocus

|Function|
|:-------------------------------------------------------------------|
|int32_t (*RequestAudioFocus)(int32_t streamType, int32_t focusType);|
|HiCar SDK向车机申请焦点。|

**Parameters**

|**Parameter name**|**Parameter type**|**Parameter desc**|
|:-----------------|:-----------------|:----------------------------|
|streamType|int32_t|音频流类型，详见DMSDPAudioStreamType。|
|focusType|int32_t|音频焦点类型，详见DMSDPAudioFocus。|

**Return**

|Type|Desc|
|:------|:-------------------|
|int32_t|返回结果： * 0：成功 * <0：失败|
