# sendKeyEvent

|Method|
|:----------------------------------------|
|int sendKeyEvent(int keyCode, int action)|
|发送按键事件。|

**Parameters**

|Parameter name|Parameter type|Parameter desc|
|:-------------|:-------------|:------------------------------------------------------------------------|
|keyCode|int|keyCode的值。|
|action|int|按键操作： * 0：ACTION_DOWN * 1：ACTION_UP * 2：类似旋转按钮转动，不区分ACTION_DOWN和ACTION_UP|

**Return**

|Type|Desc|
|:---|:---------------------------------------------------------------------------------------------------------------------------|
|int|0表示调用成功，非0表示调用失败，详见[HiCarConst](https://developer.huawei.com/consumer/cn/doc/HiCar-References/hicar-const-0000000000030396)。|
