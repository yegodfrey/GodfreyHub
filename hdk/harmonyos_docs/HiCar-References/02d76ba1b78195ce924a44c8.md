# RegisterSendDataCallback

|Function|
|:------------------------------------------------------------------------------------------------|
|int32_t (*RegisterSendDataCallback)(const char* id, uint32_t idLen, const DMSDPSendBackDataCB cb)|
|函数指针定义，表示注册Camera图像的回调函数的函数，南向实现使用北向注册的图像回调函数回传图像数据，北向DvKit在使用Camera之前，调用该函数指针注册图像回调函数。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:----------------------------------------------------------------------------------------------------------------------------------|:-------------|
|*id|const char|Camera ID。|
|idLen|uint32_t|Camera ID长度。|
|cb|const [DMSDPSendBackDataCB](https://developer.huawei.com/consumer/cn/doc/HiCar-References/dmsdp-send-back-data-cb-0000001051491950)|回调函数。|

**Return**

|Type|Desc|
|:------|:-------------------|
|int32_t|返回结果： * 0：成功 * 非0：失败|
