# removeSecureFile

|Function|
|:---------------------------------------------|
|boolean removeSecureFile(string fileName)|
|HiCar SDK通过回调的方式，由车机应用实现认证文件的管理，该回调用于删除安全认证文件。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-----------------|:-------------|
|fileName|string|需要删除的文件名。|

**Return**

|Type|Desc|
|:------|:-------------------------------|
|boolean|是否删除成功： * true：删除成功 * false：删除失败|
