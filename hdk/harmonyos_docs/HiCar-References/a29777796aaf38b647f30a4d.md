# GetGPSDataReportFreq

|Function|
|:-------------------------------------------------------------------------------------------------|
|int32_t (*GetGPSDataReportFreq)( int32_t *locationFreq, int32_t *drivingFreq, int32_t *sensorFreq)|
|获取GPS数据上报频率，单位是Hz，例如：设置locationFreq为1，则表示1Hz。 SDK期望的location的上报频率是1Hz，driving是10Hz，sensor是40Hz。|

**Parameters**

|**Parameter name**|**Parameter type**|**Parameter desc**|
|:-----------------|:-----------------|:-----------------|
|locationFreq|int32_t|GPS数据上报频率，单位Hz。|
|drivingFreq|int32_t|车身数据上报频率，单位Hz。|
|sensorFreq|int32_t|车的传感器数据上报频率，单位Hz。|

**Return**

|Type|Desc|
|:------|:-------------------|
|int32_t|返回结果： * 0：成功 * <0：失败|
