# Overview

|Return type|Function name|
|:----------|:-------------------------------------------------------------------------------------------------------------------------------------|
|int32_t|DMSDPGetGPSHandler 获取GPS有关数据的功能方法，存放在DMSDPGPSHandler结构体中。|
|int32_t|RegisterGpsDataCallBack 手机开始使用位置服务时，手机向设备请求GPS相关数据，设备侧向三方注册数据回传接口，获取基础GPS数据、车身数据和Sensor传感器数据。数据采集工作由厂商实现。|
|int32_t|UnRegisterGPSDataCallback 手机停止使用位置服务时，手机通知设备停止数据采集操作，注销注册的数据回传接口，并停止GPS数据采集。|
|int32_t|GetGPSDataReportFreq 获取GPS数据上报频率，单位是Hz，例如：设置locationFreq为1，则表示1Hz。 SDK期望的location的上报频率是1Hz，driving是10Hz，sensor是40Hz，设备厂商可以按照设备的实际频率上报。|
|int32_t|SetGPSDataReportFreq 动态设置GPS数据上报频率，如设置频率参数大于支持的最大值，返回错误。|
|int32_t|RegisterListener 注册GPS侦听。|
|int32_t|BusinessControl GPS业务控制。|
