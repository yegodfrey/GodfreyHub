# 语音状态

## 场景说明

车机的语音唤醒物理按键一般是复用按键，包括唤醒语音/退出语音、电话接听/挂断功能。为了使车机能够根据语音状态来进行语音唤醒物理按键功能的定义和复用，HiCar App会在语音状态发生变化时向车机发送当前的语音状态。

## Data Type

505

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:---------|:----|:--|:----------------------------------------------------------|
|voiceState|必选|int|HiCar语音状态： * 0：IDLE，空闲态，即处于未唤醒状态或者已退出唤醒状态。 * 1：WAKEUP，唤醒状态。|
[**表1**语音状态接口]

## 接口示例

HiCar App向车机发送语音状态示例：

```screen
语音唤醒态：
{
    "voiceState":1
}
空闲态（未唤醒或已退出语音唤醒态）：
{
    "voiceState":0
}
```
