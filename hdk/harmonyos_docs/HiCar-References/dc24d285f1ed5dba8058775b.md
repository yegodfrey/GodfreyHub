# 车机侧语音唤醒

## 场景说明

HiCar支持通过语音交互进行导航、电话和音乐操作。车机支持语音唤醒功能时，可以将语音唤醒事件传递到HiCar App，来唤醒HiCar语音，并完成业务交互。

## Data Type

2

## 接口版本

1.0

## 接口定义

|**参数名称**|||必选/可选|**类型**|说明|
|:-----------|--------------|-----------------|:----|:-----|:--------------------------------------------------------------------------------|
|frontEndInfo|-|-|必选|map|车机信息。|
|frontEndInfo|wakeType|-|必选|string|唤醒方式： * voice：语音唤醒，必须填写wakeWord参数。 * buttonPress：物理按键唤醒。|
|frontEndInfo|intent|-|必选|string|用户意图： * startVoiceRecognize：语音唤醒或物理按键唤醒开始语音识别。 * stopVoiceRecognize：物理按键触发停止语音识别。|
|frontEndInfo|voice|-|必选|map|语音信息。|
|frontEndInfo|voice|wakeWord|可选|string|华为语音唤醒词，"小艺小艺"。|
|frontEndInfo|voice|vendorName|必选|string|语音前端处理的供应商名称，"xunfei"、"baidu"。|
|frontEndInfo|voice|version|必选|string|语音前端处理的供应商版本号，如"10.0.0.1"。|
|frontEndInfo|voice|infoToVendorCloud|可选|string|发送给云端的信息：前端处理必须与云端语音供应商一一对应。|
|frontEndInfo|centralControl|-|必选|map|车载中控信息。|
|frontEndInfo|centralControl|vendorName|必选|string|车载中控供应商名称，如"博泰"。|
|frontEndInfo|centralControl|version|必选|string|车载中控版本号，如"10.0.0.1"。|
|frontEndInfo|car|-|必选|map|车辆信息。|
|frontEndInfo|car|micNumber|必选|int|拾音的麦克风个数。|
|frontEndInfo|car|speakerNumber|必选|int|扬声器个数。|
[**表1**车机侧语音交互接口]

## 接口示例

车机组装唤醒数据，调用HiCar SDK提供的接口发送唤醒数据。

```screen
物理按键唤醒示例：
{
	"frontEndInfo": {
		"car": {
			"micNumber": 2,
			"speakerNumber": 4
		},
		"centralControl": {
			"vendorName": "XX",
			"version": "10.0.0.12"
		},
		"intent": "startVoiceRecognize",
		"voice": {
			"infoToVendorCloud": "HicarManager",
			"vendorName": "10.0.0.12",
			"version": "12"
		},
		"wakeType": "buttonPress"
	}
}
物理按键结束语音示例： 
{
	"frontEndInfo": {
		"car": {
			"micNumber": 2,
			"speakerNumber": 4
		},
		"centralControl": {
			"vendorName": "XX",
			"version": "10.0.0.12"
		},
		"intent": "stopVoiceRecognize",
		"voice": {
			"infoToVendorCloud": "HicarManager",
			"vendorName": "10.0.0.12",
			"version": "12"
		},
		"wakeType": "buttonPress"
	}
}
```
