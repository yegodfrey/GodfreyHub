# HiCarInit

|Function|
|:-----------------------------------------------------------------|
|int32_t HiCarInit(CarConfig *carConfig, CarLogFuncGroup *logGroup)|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-------------------------------------------------------------------------------------------------------------------|:-------------|
|carConfig|[CarConfig](https://developer.huawei.com/consumer/cn/doc/HiCar-References/car-config-0000001052476463)|汽车配置信息。|

**Return**

|Type|Desc|
|:------|:--------------------------|
|int32_t|初始化结果： * 0：初始化成功 * 非0：初始化失败|
