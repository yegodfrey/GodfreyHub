# 品牌图标

## Data Type

502

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:------------|:----|:-----|:-----------------------------|
|brandIconData|必选|string|获取汽车品牌logo图标的PNG数据，字段取值为"PNG"。|
[**表1**品牌图标接口]

## 接口示例

HiCar App向车机发送数据示例：

```screen
{
    "brandIconData":"PNG"
}
```

车机收到上述数据，获取汽车品牌icon图片时，返回对应的图片PNG数据。
