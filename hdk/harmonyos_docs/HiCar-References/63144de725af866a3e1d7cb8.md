# 车辆控制（空调/车窗）

## 场景说明

车控接口包括对空调、车窗、天窗等车内设备的控制接口。用户唤醒语音后，通过语音发出控制指令，HiCar App识别出意图后发送车控数据到车机，由车机完成对空调、车窗、天窗等设备的控制。

为了提升整体控制效率，当手机和车机连接成功后，HiCar App会主动向车机询问车控能力，车机需要回复并反馈车控能力及当前的状态。后续当空调、车窗、天窗等设备状态发生变化时，车机需要主动向HiCar App发送最新的状态。

## Data Type

500

## 接口定义

|参数名称|必选/可选|类型|说明|
|:---------------------------|:----|:-----|:------------------------------------------------------------------------------------------------------------------------|
|VehicleControlCapability|必选|object|车控能力询问信息。由HiCar App向车机发起，询问当前车机的车控能力支持情况。|
|VehicleControlCapabilityResp|必选|object|车控能力返回信息，供车机返回支持的车控能力，以及车控状态变化时主动上报。详见[表2](#ZH-CN_TOPIC_0000001153290426__zh-cn_topic_0000001102124142_table30995191)。|
|VehicleControl|必选|object|车控设置信息，空调、天窗、车窗同一时刻会设置一种，不会全部设置。详见[表3](#ZH-CN_TOPIC_0000001153290426__zh-cn_topic_0000001102124142_table14127948203611)。|
|VehicleControlResp|必选|object|车控设置返回接口，错误码必须包含，空调、车窗、天窗和设置接口保持一致。详见[表4](#ZH-CN_TOPIC_0000001153290426__zh-cn_topic_0000001102124142_table313205210387)。|
[**表1**车控接口]

|参数名称||必选/可选|**类型**|说明|
|:-------------|------------------|:----|:-----|:------------------------------------|
|volume|support|必选|string|是否支持音量控制： * true：支持 * false：不支持|
|volume|status|必选|string|静音状态： * mute：静音 * unmute：非静音|
|volume|maxVolume|必选|string|音量最大值。|
|volume|minVolume|必选|string|音量最小值。|
|volume|currentVolume|必选|string|当前音量。|
|airConditioner|support|必选|string|是否支持控制空调： * true：支持 * false：不支持|
|airConditioner|maxTemperature|必选|string|空调支持的最高温度。单位：摄氏度。|
|airConditioner|minTemperature|必选|string|空调支持的最低温度。单位：摄氏度。|
|airConditioner|status|必选|string|空调开关状态： * on：开启状态 * off：关闭状态|
|airConditioner|currentTemperature|必选|string|空调当前温度。单位：摄氏度。空调处于关闭状态时，此参数值无意义。|
|skyLight|support|必选|string|是否支持控制天窗： * true：支持 * false：不支持|
|skyLight|status|必选|string|天窗开启状态： * open：开启状态 * close：关闭状态|
|vehicleWindow|leftFront|必选|string|是否支持控制主驾车窗（左前）： * true：支持 * false：不支持|
|vehicleWindow|leftFrontStatus|必选|string|主驾车窗状态： * open：开启状态 * close：关闭状态|
|vehicleWindow|rightFront|必选|string|是否支持控制副驾车窗（右前）： * true：支持 * false：不支持|
|vehicleWindow|rightFrontStatus|必选|string|副驾车窗状态： * open：开启状态 * close：关闭状态|
|vehicleWindow|leftBack|必选|string|是否支持控制左后车窗： * true：支持 * false：不支持|
|vehicleWindow|leftBackStatus|必选|string|左后车窗状态： * open：开启状态 * close：关闭状态|
|vehicleWindow|rightBack|必选|string|是否支持控制右后车窗： * true：支持 * false：不支持|
|vehicleWindow|rightBackStatus|必选|string|右后车窗状态： * open：开启状态 * close：关闭状态|
|vehicleWindow|isPercentSupport|可选|string|是否支持车窗百分比控制： * true：支持 * false：不支持|
[**表2**VehicleControlCapabilityResp]

|参数名称||必选/可选|**类型**|说明|
|:-------------|-----------|:----|:-----|:-----------------------------------------------------------------------------------------------------------------------------|
|volume|intent|必选|string|音量控制动作： * mute：静音 * unmute：取消静音 * setvolume：设置音量|
|volume|volume|必选|string|音量调高或者调低后的音量值。只有设置音量时携带此参数。|
|airConditioner|intent|必选|string|空调控制动作： * turnon：开启空调 * turnoff：关闭空调 * settemp：设置空调温度|
|airConditioner|temperature|可选|string|设置的空调温度。单位：摄氏度。设置空调温度时携带此参数。开启空调时如果用户带了温度则携带此参数。|
|skyLight|intent|必选|string|天窗控制动作： * open：开启 * close：关闭|
|vehicleWindow|windowType|必选|string|控制的车窗类型： * all：全部车窗 * leftfront：主驾车窗 * rightfront：副驾车窗 * leftback：左后车窗 * rightback：右后车窗 * front：前排车窗（主驾和副驾） * back：后排车窗（左后和右后）|
|vehicleWindow|intent|必选|string|车窗状态： * open：开启 * close：关闭|
|vehicleWindow|percent|可选|string|车窗开启的百分比，取值为1~100，比如打开20%，传递的值是20。|

|vehicleWindow|rightFrontStatus|必选|string|副驾车窗状态： * open：开启状态 * close：关闭状态|

|vehicleWindow|rightBackStatus|必选|string|右后车窗状态： * open：开启状态 * close：关闭状态|

### 车控示例

HiCar App向车机发送空调控制指令示例：

```screen
{
    "VehicleControl": {
          "airConditioner": {
                "intent":"turnon",
          }
    }
}
{
    "VehicleControl": {
          "airConditioner": {
                "intent":"settemp",
                "temperature":"25"
          }
    }
}
{
    "VehicleControl": {
          "airConditioner": {
                "intent":"turnoff",
          }
    }
}
```

车机向HiCar App返回空调控制消息示例：

```screen
{
    "VehicleControlResp": {
         "respCode":"success",
         "airConditioner": {
                "status":"on",
                "currentTemperature":"25"
          }
     }
}
{
    "VehicleControlResp": {
         "respCode":"success",
         "airConditioner": {
                "status":"off",
          }
     }
}
```

HiCar App向车机发送天窗控制指令示例：

```screen
{
    "VehicleControl": {
          "skyLight": {
                "intent":"close"
          }
    }
}
```

车机向HiCar App返回天窗控制消息示例：

```screen
{
    "VehicleControlResp": {
         "respCode":"success",
          "skyLight": {
                "status":"close"
          }
    }
}
```

HiCar App向车机发送车窗控制指令示例：

```screen
{
    "VehicleControl": {
          "vehicleWindow": {
                "windowType":"all",
                "intent":"open",
                "percent":"20"
          }
    }
}
```

车机向HiCar App返回车窗控制消息示例：

```screen
{
    "VehicleControlResp": {
         "respCode":"success",
          "vehicleWindow": {
                "leftFrontStatus":"open",
                "rightFrontStatus":"open",
                "leftBackStatus":"open",
                "rightBackStatus":"open"
          }
    }
}
```

HiCar App向车机发送音量控制指令示例：

```screen
{

          "volume": {
                "intent":"setvolume",
                "volume":"7", 
          }
    }
}

                "intent":"mute",
          }
    }
```

```screen
{
    "VehicleControlResp": {
         "respCode":"success",

                "status":"unmute",
                "currentVolume":"7"
          }
     }
```
