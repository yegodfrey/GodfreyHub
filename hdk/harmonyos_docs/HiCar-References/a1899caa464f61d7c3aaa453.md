# 文档更新记录

> 注意
>
> 请汽车硬件开发者使用前务必关注修订记录中的说明，其中：
>
> * **变更**：对已有开放能力的修改、删除等，开发者需重点关注，未适配时会对已有功能产生影响。
> * **新增**：新增开放能力，开发者应根据需要进行适配。未适配时不会影响已有功能。
