# onTransmissionStatusUpdate

|Method|
|:-------------------------------------------|
|void onTransmissionStatusUpdate(int status);|
|文件传输过程中，各种状态的回调。|

**Parameters**

|Parameter name|Parameter type|Parameter desc|
|:-------------|:-------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|status|int|**a.** **手机向车机发送文件：** * 102：车机端接收手机端文件发送请求，HMI应调用FileShareStatusNotification接口通知手机。 * 103：车机端存储空间不足，无法接收手机端发送的文件。HMI应调用FileShareStatusNotification接口通知手机。 * 104：车机端用户操作拒绝接收文件。HMI应调用FileShareStatusNotification接口通知手机。 * 105：手机端请求发送文件请求超时（即用户30秒无任何操作，不接收也不拒绝）。 * 106：准备发送。该状态码会在车机端点击接收之后，开始传输文件之前发送。此时车机端可以显示缩略图，进度0%。 * 107：发送过程中手机端取消发送。车机端应在该状态码回调时，销毁接收弹框并提示用户对端取消发送。 * 108：发送过程中车机端取消接收。HMI应调用FileShareStatusNotification接口通知手机。 * 111：所有文件发送成功。车机端在接收成功后可选择直接打开文件，或执行刷新图库、提示用户发送成功等操作。 **b.** **车机向手机发送文件：** * 202：手机端接收车机端文件发送请求。 * 203：手机存储空间不足，无法接收文件。车机端应提示用户手机端存储空间不足。 * 204：手机端用户操作拒绝接收文件。车机端应提示用户拒绝接收。 * 205：车机端请求发送文件超时。 * 206：车机端准备发送（HMI无需发送此状态）。 * 207：发送过程中车机端取消发送文件，HMI应调用FileShareStatusNotification接口通知手机。 * 208：发送过程中手机端取消接收文件。 * 211：所有文件发送成功（HMI无需发送此状态）。|
