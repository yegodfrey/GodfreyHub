# 屏幕操作方式

车机屏幕常见的操作方式包括触摸操作、旋钮操作等，HiCar将根据不同的操作方式进行屏幕焦点显示。车机需要在HiCar SDK初始化时上报车机屏幕支持的操作方式以及首选的操作方式。

|键值|类型|说明|
|:-------------|:--|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|INPUT_FEATURES|int|车机屏幕支持的操控方式，基于bit位区分是否支持： * 触摸操作，bit位0，支持1，不支持0 * 旋钮操作，bit位1，支持10，不支持00 * 触摸板操作，bit位2，支持100，不支持000 厂商需要根据实际支持的情况，将结果转换成int型数据进行上报，例如支持触摸操作（1）则上报1、支持旋钮操作（10）则上报2、同时支持触摸操作和旋钮操作（11）则上报3，全部支持（111）则上报7，以此类推。|
|PRIMARY_INPUT|int|车机屏幕主要操作方式，支持一个或者多个时上报主要的操作方式： * 1：触摸操作（缺省默认值） * 2：旋钮操作 * 3：触摸板操作|
[**表1**初始化时上报车机屏幕操作方式键值对]

HiCar SDK初始化设置示例：

```screen
CarConfig.Builder builder = newCarConfig.Builder();
Map<String, String> config = newHashMap<String, String>();
config.put("PRIMARY_INPUT",  1);  
builder.withInitialConfig(config);
```
