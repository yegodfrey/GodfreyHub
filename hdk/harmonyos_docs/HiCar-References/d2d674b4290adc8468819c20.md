# 文件说明

|Files name|Files description|
|:-----------------------|:---------------------------------------|
|hicar.h|用于定义厂商开发HMI应用时集成的应用接口。|
|HwRemoteControlEvent.h|用于定义反向控制事件定义，比如按键、旋钮、触屏等事件。|
|dmsdp_errno.h|用于定义HiCar SDK的错误码。|
|bt_socket_wrapper.h|用于定义蓝牙推荐功能的接口。|
|dmsdp_camera_handler.h|用于定义HiCar SDK对Camera硬件的调用接口。|
|dmsdp_camera_data_type.h|用于定义HiCar SDK对Camera硬件调用的数据类型。|
|dmsdp_audio_handler.h|用于定义HiCar SDK对Audio（Speaker/MIC）硬件的调用接口。|
|dmsdp_audio_data_type.h|用于定义HiCar SDK对Audio硬件调用的数据类型。|
|dmsdp_gps_handler.h|用于定义HiCar SDK对GPS的调用接口。|
|dmsdp_business.h|用于定义车机向HiCar SDK通知有关信息的接口。|
|driver_adapt.h|用于定义HiCar SDK对Wi-Fi/蓝牙/USB硬件的调用接口。|
