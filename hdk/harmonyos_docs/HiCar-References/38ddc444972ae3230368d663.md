# getCarAudioRecordingStatus（Beta）

|Function|
|:----------------------------------------------------------------------------------------|
|int getCarAudioRecordingStatus()|
|HiCar SDK通过回调的方式，由车机应用判断车机MIC是否可以使用，并根据情况返回对应的值，然后HiCar SDK根据返回的值判断是否进行Audiorecord的初始化构建。|

**Return**

|Type|Desc|
|:---|:--------------------------------|
|int|车机MIC的可用状态： * 0：无效 * 1：不可用 * 2：可用|
