# Release

|Function|
|:--------------------------------------------------------|
|void (*Release)(int32_t type, void* ptr,uint32_t num)|
|函数指针定义，释放资源，该类资源是指南向实现中申请内存返回给DvKit，DvKit使用完毕后，调用该接口释放内存。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|type|int32_t|释放资源类型。 详见[DMSDPCameraReleaseType](https://developer.huawei.com/consumer/cn/doc/HiCar-References/dmsdp-camera-release-type-0000001059006878#ZH-CN_TOPIC_0000001059006878) 对应QueryCameraCapability。|
|*ptr|void|对应DMSDPCameraCapabilities* capabilities。|
|num|uint32_t|个数。|

**Return**

|Type|Desc|
|:----|:-----------------|
|char*|Camera的属性信息的集合字符串。|
