# UpdateConfig

|Function|
|:-------------------------------------------------------------------------------------------------|
|int32_t (*UpdateConfig)(const char* id, uint32_t idLen, int32_t key, char* value, uint32_t valLen)|
|函数指针定义，表示使用参数中指定的配置更新Camera id指定的Camera配置，南向返回该接口实现函数地址，北向DvKit根据业务需要调用该接口更新运行中的Camera配置。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|*id|const char|Camera ID。|
|idLen|uint32_t|Camera ID长度。|
|key|int32_t|参数类型。 详见[DSMDPCameraConfigKey](https://developer.huawei.com/consumer/cn/doc/HiCar-References/dmsdp-camera-config-key-0000001058580763#ZH-CN_TOPIC_0000001058580763)。|
|*value|char|参数字符串。|
|valLen|uint32_t|参数长度。|

**Return**

|Type|Desc|
|:------|:-------------------------|
|int32_t|返回结果： * 0：更新成功 * 非0：更新配置失败|
