# 融合桌面HiCar前后台显示

## 场景说明

在融合桌面形态下，HiCar会通知车机跟随场景变化，将HiCar切换到前台或后台，典型场景如下：

* 车机与手机通过HiCar进行连接时，HiCar可能会先显示投屏前界面，供用户确认授权后，再进行业务的初始化。投屏前界面包括：安全驾驶声明、隐私协议变更确认、超级隐私模式、OOBE引导界面等。投屏前界面会在首次连接或部分投屏前界面有更新时显示，因此该情景下，需要在连接成功时先将HiCar拉至前台，待用户确认后，方可将HiCar切换至后台执行融合桌面相关业务逻辑。
* 应用启动失败时（如网络较差时，音乐模板界面加载失败，用户点击失败提示界面的确认按钮等），需要直接返回车机界面，此时车机需要将HiCar切换到后台。
* 从车机融合桌面点击图标进入部分应用时，该部分应用中存在返回按钮，点击后需要直接返回车机界面，此时车机需要将HiCar切换到后台。
* 手机上打开支持HiCar的应用，摇一摇或者点击HiCar实况通知的流转按钮（仅HarmonyOS 5及以上系统支持），将应用流转到车机侧，此时车机需要将HiCar切换到前台。
* 手机摇一摇发起导航时，车机需要将HiCar切换到前台。

## 接口示例

车机与手机连接时，HiCar App会主动将是否需要将HiCar切换到后台的信息发送到车机，不需要车机事先请求，示例如下所示：

```screen
{
    "ProjectAction" : {
        "Background" : false
    }
}
```

车机在收到消息后，如果为false，则需要将HiCar界面拉至前台，待用户确认后，再次收到消息为true后，将HiCar界面切换至后台。此时向HiCar App发送响应消息，示例如下所示：

```screen
{
    "ProjectActionResp" : {
        "RespCode" : 100000
    }
}
```
