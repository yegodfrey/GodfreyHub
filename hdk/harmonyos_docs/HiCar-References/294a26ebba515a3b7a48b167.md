# 物理按键快捷键

## 场景说明

如果车辆中存在物理导航/联系人/音乐按键，连接HiCar后，用户可以通过车机物理按键，一键打开HiCar中对应的地图/联系人/音乐应用。打开应用时无法指定具体的应用，只能打开用户上一次使用的地图/联系人/音乐应用。

车机在检测到车机物理按键被按下后，需要向HiCar App上报相应的数据。

## Data Type

509

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:------|:----|:-----|:-------------------------------------------------------------------|
|KEYCODE|必选|string|物理快捷按钮： * NAVIGATION：物理导航按键 * TEL：物理联系人按键 * MEDIA：物理音乐按键 * BACK：返回事件|
[**表1**物理按键快捷键接口]

## 接口示例

按下物理导航按键，进入地图应用示例：

```screen
{
    "KEYCODE":"NAVIGATION"
}
```

按下物理联系人按键，进入联系人应用示例：

```screen
{
    "KEYCODE":"TEL"
}
```

按下物理音乐按键，进入音乐应用示例：

```screen
{
    "KEYCODE":"MEDIA"
}
```

触发返回事件示例：

```screen
{
    "KEYCODE":"BACK"
}
```
