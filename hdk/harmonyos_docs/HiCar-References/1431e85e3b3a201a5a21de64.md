# 音频元数据

## 场景说明

车机连接HiCar，在请求音频元数据获得用户授权后，当HiCar在音频播放状态发生改变时，将会通知车机音频的基础信息和状态，车机可将这些数据送到仪表盘或HUD进行显示。
> 说明
>
> 1. 使用音频元数据之前，需要先请求相关元数据，详见[元数据能力](https://developer.huawei.com/consumer/cn/doc/HiCar-References/app-metadata-capability-0000001383093924#ZH-CN_TOPIC_0000001383093924)。
> 2. HarmonyOS 6.0支持音频元数据歌词传输，当前HarmonyOS 6.0版本中仅支持华为音乐和QQ音乐。

## DataType

515

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:------------|:----|:-----|:---------------------------------------------------------------------------------------------|
|MediaData|必选|object|音频元数据，详见[表2](#ZH-CN_TOPIC_0000001383253864__zh-cn_topic_0000001340916006_table18336155611473)。|
|MediaDataResp|必选|object|响应数据，详见[表3](#ZH-CN_TOPIC_0000001383253864__zh-cn_topic_0000001340916006_table1943683611395)。|
[**表1**音频元数据]

|**参数名**|必选/可选|**类型**|**说明**|
|:-----------|:----|:-----|:---------------------------------------------------------------------------------------------------------------------|
|Name|必选|String|音频名称。|
|Artist|必选|String|音频演唱者。|
|TotalTime|必选|int|音频总时长。单位：秒。|
|ElapsedTime|必选|int|已播放时长。单位：秒。|
|AlbumName|必选|String|专辑名称。|
|AlbumArtURL|可选|String|专辑封面图片URL。|
|AlbumArtIcon|可选|byte[]|专辑封面byte数据。 > 说明 > 专辑封面byte数据（AlbumArtIcon）和专辑封面图片URL（AlbumArtURL）同时只会传输其中一种数据参数。若无专辑封面数据传输，则需要使用另外默认音乐图片代替以防止程序崩溃。|
|Status|必选|int|播放状态： * 0：None，无播放任务。 * 1：停止播放。 * 2：暂停播放。 * 3：正在播放。 * 6：正在缓冲。 具体可参考Android原生API的android.media.session.PlaybackState内容。|
|AppName|可选|String|音频应用名。|
|AppIcon|可选|byte[]|音频应用图标byte数据。|
|AppPackage|必选|String|音频应用包名。|
|Lyric|可选|String|歌词 标准的LRC歌词格式：[mm:ss.xx]歌词内容。其中mm是分钟，ss是秒，xx是毫秒|
[**表2**MediaData]

|参数名称|必选/可选|类型|说明|
|:-------|:----|:--|:--------------------------------|
|RespCode|必选|int|响应结果： * 100000：接收成功 * 100001：接收失败|
[**表3**MediaDataResp]

|参数名称|必选/可选|类型|说明|
|:----------|:----|:--|:-----------------------------------|
|ElapsedTime|必选|int|播放时间，单位：秒。 HiCar App每隔一秒向车机侧发送一次该数据。|
[**表4**ElapsedTime]

## 接口实例

HiCar App在音频播放状态变化时，根据用户授权记录，向授权车机发送音频元数据的示例报文如下所示：

```screen
{
    "MediaData" : {
        "Name" : "Dream It Possible",
        "Artist" : "",
        "TotalTime" : 204,
        "ElapsedTime" : 50,
        "AlbumName" : "Dream It Possible",
        "AlbumArtURL" : "https://xxxxx",
        "AlbumArtIcon" : [],
        "Status" : 3,
        "AppName" : "华为音乐 HUAWEI HiCar",
        "AppIcon" : [],
        "AppPackage" : "com.huawei.music"
    }
}
```

车机在收到消息后，向HiCar App发送响应消息，示例如下所示：

```screen
{
    "MediaDataResp" : {
        "RespCode" : 100000
    }
}
```

音频播放过程中，每隔1s，手机侧HiCar App会向车机发送播放进度（单位：秒）数据。

```screen
{
    "ElapsedTime" : 50
}
```
