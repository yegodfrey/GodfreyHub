# 深浅模式

## 场景说明

当汽车传感器具备深浅模式探测能力时，HiCar App可以基于此能力进行深浅模式的切换。

车机上电启动后，需要调用HiCar SDK提供的接口上报是否支持深浅模式检测及当前所处的模式，后续在模式发生变化时主动向HiCar App上报最新的模式。

## SDK初始化时设置深浅模式

|参数|说明|
|:---------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
|CarConfig.CarDeviceInfo.dayNightInfo[12]|车辆是否支持深浅模式检测及当前所处模式。 * "night" ：当前所处深色模式。 * "day" ： 当前所处浅色模式。 * "pending" ：无法确定当前所处模式，但是可能后续动态上报深浅模式信息给HiCar，使用该字符串。 * "notsupport" ：确定汽车不支持上报深浅模式时，使用该字符串。|
[**表1**初始化时设置深浅模式参数]

HiCar SDK初始化设置示例：

```screen
CarConfig config;
......
memcpy_s((void*)&(config.deviceInfo.dayNightInfo[0]), CAR_DAY_NIGHT_MAX_LEN, 0, CAR_DAY_NIGHT_MAX_LEN);
memcpy_s((void*)&(config.deviceInfo.dayNightInfo[0]), CAR_DAY_NIGHT_MAX_LEN, "night", strlen("night"));
config.deviceInfo.carDayNightLen = strlen("night");
......
int retCode = HiCarInit(&config);
```

车机在深浅模式发生变化时需要主动向HiCar App上报当前所处的模式。

## Data Type

501

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:-----------|:----|:-----|:----------------------------|
|dayNightMode|必选|string|深浅模式： * day：浅色模式 * night：深色模式|
[**表2**深浅模式接口]

## 接口示例

车机向HiCar App上报深浅模式示例：

```screen
浅色模式：
{
    "dayNightMode":"day"
}
深色模式：
{
    "dayNightMode":"night"
}
```
