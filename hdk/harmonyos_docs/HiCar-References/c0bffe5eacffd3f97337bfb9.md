# isNextDevice

|Method|
|:---------------------------------------|
|bool isNextDevice()|
|判断已经连接上HiCar的可信设备是否运行HarmonyOS 5及以上版本系统。|

**Return**

|Type|Desc|
|:------|:--------------------------------------------------|
|boolean|true：是HarmonyOS 5及以上版本系统 false：不是HarmonyOS 5及以上版本系统|
