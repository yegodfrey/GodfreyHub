# GetParam

|Function|
|:---------------------------------------------------------|
|int (*GetParam)(GetParamsType paramType, void *paramValue)|
|获取设备属性和能力信息。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:--------------------------------------------------------------------------------------------------------------|:----------------------------------|
|paramType|[GetParamsType](https://developer.huawei.com/consumer/cn/doc/HiCar-References/get-params-type-0000001052250830)|获取参数的类型。|
|*paramValue|void|数据的结构体指针， 采用void *通配不同设备设置的数据结构体差异。|

**Return**

|Type|Desc|
|:---|:-------------------|
|int|返回结果： * 0：成功 * 非0：失败|
