# WriteStreamBuffer

|Function|
|:------------------------------------------------------------------------------------------------------------|
|int32_t (*WriteStreamBuffer)(const char* id, uint32_t idLen, int32_t sessionId, DMSDPVirtualStreamData* data)|
|播放音频数据。该接口在实现时需要注意线程安全，存在不同线程调用该接口的情况。|

**Parameters**

|**Parameter name**|**Parameter type**|**Parameter desc**|
|:-----------------|:---------------------------------------------------------------------------------------------------------------------------------|:-----------------|
|*id|const char|Speaker ID。|
|idLen|uint32_t|Speaker ID长度。|
|sessionId|int32_t|Session ID。|
|*data|[DMSDPVirtualStreamData](https://developer.huawei.com/consumer/cn/doc/HiCar-References/dmsdp-virtual-stream-data-0000001052609206)|Speaker数据。|

**Return**

|Type|Desc|
|:------|:-------|
|int32_t|播放音频字节数。|
