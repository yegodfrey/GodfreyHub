# HiCarStartProjection

|Function|
|:-------------------------------------------------------|
|int32_t HiCarStartProjection(HICAR_HANDLE handle)|
|启动HiCar投屏，当厂商HMI应用收到HICAR_DEVICE_SERVICE_RESUME状态时调用该接口。|

|**Parameter name**|**Parameter type**|**Parameter desc**|
|:-----------------|:-----------------|:------------------------------|
|handle|HICAR_HANDLE|HiCar句柄，通过GetHiCarHandle获取到的句柄。|

**Return**

|Type|Desc|
|:------|:---------------------------------------|
|int32_t|启动投屏结果： * 1：启动HiCar投屏成功 * 非1：启动HiCar投屏失败|
