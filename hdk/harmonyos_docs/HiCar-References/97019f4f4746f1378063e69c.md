# SetParam

|Function|
|:---------------------------------------------------------------|
|int (*SetParam)(SetParamsType paramType, const void *paramValue)|
|在Init执行完成之后，为driver设置参数信息。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:--------------------------------------------------------------------------------------------------------------|:----------------------------------|
|paramType|[SetParamsType](https://developer.huawei.com/consumer/cn/doc/HiCar-References/set-params-type-0000001052890840)|设置参数的类型。|
|*paramValue|const void|数据的结构体指针， 采用void *通配不同设备设置的数据结构体差异。|

**Return**

|Type|Desc|
|:---|:-------------------|
|int|返回结果： * 0：成功 * 非0：失败|
