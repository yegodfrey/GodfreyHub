# WriteSecureFile

|Function|
|:--------------------------------------------------------------------------------------------|
|int32_t (*WriteSecureFile)(const char *filename, uint32_t offset, uint8_t *buf, uint32_t len)|
|向鉴权认证文件写数据。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-----------------|:-------------|
|*filename|char|存储的文件名。|
|offset|uint32_t|写文件的偏移位置。|
|*buf|uint8_t|读取的buffer。|
|len|uint32_t|buffer的大小。|

**Return**

|Type|Desc|
|:------|:------------------|
|int32_t|返回结果： * 0：成功 * 1：失败|
