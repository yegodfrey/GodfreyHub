# HiCarGetConnectQRCode

|Function|
|:------------------------------------------------------------|
|int32_t HiCarGetConnectQRCode (uint8_t *url, uint32_t maxLen)|
|获取二维码码值。车机进入扫码连接界面后，获取生成二维码的码值。|

|**Parameter name**|**Parameter type**|**Parameter desc**|
|:-----------------|:-----------------|:-----------------|
|url|uint8_t|二维码码值Buffer。|
|maxLen|uint32_t|Buffer的最大长度。|

**Return**

|Type|Desc|
|:------|:-------------------------------------------------|
|int32_t|返回结果： * >0：获取二维码码值成功，返回二维码码值的长度。 * 0或负数：获取二维码码值失败。|
