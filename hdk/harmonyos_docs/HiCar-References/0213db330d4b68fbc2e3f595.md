# 错误码表

HiCar APP和车机间交互的错误码，错误码格式如下：

* 6位十进制数
* 最高1位为1，保留后续扩展
* 次高两位对应数据交互类型
* 最低3位表示具体数据交互类型中的错误类型

|errorCode|描述|
|:--------|:------|
|100000|成功|
|100001|输入参数不合法|
|100002|用户未授权|
|100003|不支持此功能|
|100004|意图执行失败|
|100999|未知异常|
[**表1**错误码]
