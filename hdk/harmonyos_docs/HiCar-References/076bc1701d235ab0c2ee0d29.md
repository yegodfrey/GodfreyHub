# DMSDPSendBackDataCB

|Function|
|:-----------------------------------------------------------------------------------------------------------------|
|int32_t (*DMSDPSendBackDataCB)(const char *id, uint32_t idLen, const uint8_t *buffer, uint32_t len, int32_t type);|
|用于接收设备返回的图像数据的接收函数指针定义，DVkit会注册接收函数指针到厂商设备实现。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-----------------|:------------------------------------------------------------------------------------------------------------------------------------|
|*id|const char|Camera ID。|
|idLen|uint32_t|Camera ID长度。|
|*buffer|const uint8_t|视频流数据地址。|
|len|uint32_t|视频流长度。|
|type|int32_t|视频流类型，详见[DMSDPCameraDataType](https://developer.huawei.com/consumer/cn/doc/HiCar-References/dmsdp-camera-data-type-0000001051651804)。|

**Return**

|Type|Desc|
|:------|:-------------------|
|int32_t|返回结果： * 0：成功 * 非0：失败|
