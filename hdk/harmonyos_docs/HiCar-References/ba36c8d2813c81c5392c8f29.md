# CreateWifiChannel

|Function|
|:------------------------------------------------------------------|
|int (*CreateWifiChannel)(const void *context, const void *wifiData)|
|创建车机Wi-Fi热点。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-----------------|:--------------------------------------------------------------------------------------------|
|*context|const void|context采用void *通配不同设备数据结构体差异，目前参数context未启用，可传NULL。|
|*wifiData|const void|wifiData采用void *通配不同设备数据结构体差异。这里传入是信道频率frequency的指针(int *)。热点的名称(ssid)和密码(key)由车机生成上报给Nearby。|

**Return**

|Type|Desc|
|:---|:-------------------|
|int|返回结果： * 0：成功 * 非0：失败|
