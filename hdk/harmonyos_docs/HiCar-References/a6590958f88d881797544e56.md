# writeSecureFile

|Function|
|:--------------------------------------------------------|
|boolean writeSecureFile(string fileName, byte[] data)|
|HiCar SDK通过回调的方式，由车机应用实现认证文件的管理，该回调用于保存认证信息到车机本地文件或安全存储区。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-----------------|:-------------|
|fileName|string|认证信息的文件名。|
|data|byte[]|需要存储的信息。|

**Return**

|Type|Desc|
|:------|:-------------------------------|
|boolean|是否写入成功： * true：写入成功 * false：写入失败|
