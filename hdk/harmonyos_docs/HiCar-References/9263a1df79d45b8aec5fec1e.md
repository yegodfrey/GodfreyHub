# getCarDataReportFreq

|Function|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|CarDataReportFreq getCarDataReportFreq()|
|获取车辆的车身数据。 1. HiCar SDK向车厂注册完监听后，由车厂将上报的频率注册给HiCar SDK，每次注册后设置一次即可。 2. 该数据的单位是Hz，例如：设置locationFreq为1，则表示1Hz。 3. HiCar SDK期望的GPS位置信息的上报频率是1Hz，车身数据是10Hz，传感器数据是40Hz；车机厂商请按照实际的频率数据进行上报（上报实际的平均频率）。|

**Return**

|Type|Desc|
|:----------------|:-------|
|CarDataReportFreq|车辆的车身数据。|
