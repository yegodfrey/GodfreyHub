# HiCarGetTrustDeviceList

|Function|
|:----------------------------------------------------------------------|
|int32_t HiCarGetTrustDeviceList(TrustPhoneInfo** list，uint32_t listLen)|
|获取当前和车机完成鉴权认证后的设备列表。|

|**Parameter name**|**Parameter type**|**Parameter desc**|
|:-----------------|:----------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------|
|list|[TrustPhoneInfo](https://developer.huawei.com/consumer/cn/doc/HiCar-References/trust-phone-info-0000001051636392)|完成鉴权认证的设备（手机）列表。 注：此处的list所分配的内存需要是连续的，list指向连续地址的首地址，将&list传入。|
|listLen|int32_t|传入列表list的长度，想要获取手机的个数。|

**Return**

|Type|Desc|
|:------|:---------------------------------|
|int32_t|返回结果： * <0 ：获取失败， * 其他：获取可信设备列表的长度|
