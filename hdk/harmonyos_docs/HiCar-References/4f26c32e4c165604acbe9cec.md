# 融合桌面应用列表

## 场景说明

在融合桌面形态下，车机可以请求获取支持HiCar的应用列表，用于显示到车机原生的应用列表中，将HiCar应用与本地应用进行融合显示。

## Data Type

528

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:------------|:----|:-----|:-----------------------------|
|RequestData|必选|string|请求数据的内容，当前仅支持"all"，表示请求所有应用数据。|
|RequestCaller|必选|string|当前车型的modelId。|
[**表1**应用信息接口]

## 接口示例

车机向HiCar App请求获取应用数据的示例代码如下所示：

```screen
{
    "RequestData" : "all",
    "RequestCaller" : "00010001"
}
```

请求后HiCar将会通过AppInfoChangeListener相关接口返回应用数据信息，车机需要监听该接口并获取应用数据。
