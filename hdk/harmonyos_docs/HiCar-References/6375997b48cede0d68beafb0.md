# Overview

|Name|Desc|
|:---------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------|
|[DMSDPCameraDataType](https://developer.huawei.com/consumer/cn/doc/HiCar-References/dmsdp-camera-data-type-0000001051651804)|支持输出的Camera图像数据类型，包括H264，H265，RGB565, NV21。|
|[DMSDPCameraReleaseType](https://developer.huawei.com/consumer/cn/doc/HiCar-References/dmsdp-camera-release-type-0000001052571843)|释放的数据结构类型，当前仅有查询的Camera能力信息需要南向实现中申请内存返回给DvKit，DvKit使用完毕后，调用该接口触发南向实现释放为存储能力信息申请的内存。|
|[DSMDPCameraConfigKey](https://developer.huawei.com/consumer/cn/doc/HiCar-References/dmsdp-camera-config-key-0000001051491812)|Camera配置数据类型，当前仅支持FPS。|
