# onAppInfoUpdate

|Method|
|:---------------------------------------------------------------------|
|void onAppInfoUpdate(String deviceId, List<AppInfoBean> appInfoBeans);|
|回调有更新的融合桌面AppInfo数据（手机上应用有更新，比如图标、包名等）。|

**Parameters**

|Parameter name|Parameter type|Parameter desc|
|:-------------|:----------------|:-----------------|
|deviceId|String|对端设备（手机）deviceId。|
|appInfoBeans|List<AppInfoBean>|有更新的应用AppInfo数据列表。|
