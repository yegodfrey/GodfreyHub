# Overview

|Name|Desc|
|:---------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|DMSDPGPSCallback|数据回调结构体，厂商可通过此接口上传车机侧的位置信息、车身数据、传感器数据、基础数据（如汽车品牌、型号等）。详细可参考[GPS相关数据格式定义](https://developer.huawei.com/consumer/cn/doc/HiCar-References/gps-data-format-0000001053730837)。|
|DMSDPGpsHandler|GPS业务管理结构体，提供了注册、去注册、获取频率、设置频率等功能。|
