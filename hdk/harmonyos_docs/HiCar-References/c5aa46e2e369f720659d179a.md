# HiCarPauseProjection

|Function|
|:------------------------------------------------|
|int32_t HiCarPauseProjection(HICAR_HANDLE handle)|
|暂停HiCar投屏，当收到HICAR_DEVICE_SERVICE_PAUSE状态时调用。|

|**Parameter name**|**Parameter type**|**Parameter desc**|
|:-----------------|:-----------------|:------------------------------|
|handle|HICAR_HANDLE|HiCar句柄，通过GetHiCarHandle获取到的句柄。|

**Return**

|Type|Desc|
|:------|:---------------------------------------|
|int32_t|暂停投屏结果： * 1：暂停HiCar投屏成功 * 非1：暂停HiCar投屏失败|
