# update5gChannels（Beta）

|Method|
|:--------------------------------------------------|
|CarConfig update5gChannels(int[] support5gChannels)|
|更新车机支持的WiFi 5G信道列表。|

**Parameters**

|Parameter name|Parameter type|Parameter desc|
|:----------------|:-------------|:----------------------------------------|
|support5gChannels|int[]|车机支持的WiFi 5G信道列表，示例取值36, 40, 44, 48, 149。|

**Return**

|Type|Desc|
|:--------|:--------|
|CarConfig|车机配置信息对象。|
