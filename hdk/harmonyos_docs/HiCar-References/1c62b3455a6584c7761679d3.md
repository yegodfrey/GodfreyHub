# 车机类型

集成HiCar的车机因硬件配置、软件能力不同会直接影响HiCar的功能。为了便于HiCar后续针对不同的车机提供不同的功能，车机需要在HiCar SDK初始化时上报车机类型。

|键值|类型|说明|
|:----------|:--|:----------------------------------------------------------------------------------------------------------------------|
|DEVICE_TYPE|int|车机类型： * 0：未知类型（车机未设置时的取值） * 1：Dongle A，后装HiCar，多为安卓车机 * 2：Dongle B，后装HiCar * 3：HUAWEI HiCar车载智慧屏 * 4：前装车机，即出厂预置HiCar的车机|
[**表1**初始化时上报车机类型的键值对]

HiCar SDK初始化设置示例：

```screen
CarConfig.Builder builder = newCarConfig.Builder();
Map<String, String> config = newHashMap<String, String>();
config.put("DEVICE_TYPE",3);  
builder.withInitialConfig(config);
```
