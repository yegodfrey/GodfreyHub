# 车服务通道

## 场景说明

HiCar提供车服务通道，用于车机和接入HiCar的车服务应用间进行数据传输。

车机启动并成功连接手机后，需要主动上报允许使用车服务通道的权限名。手机端仅有拥有此权限的车服务应用才能与车机端车服务进行通讯。

## Data Type

508

## 接口版本

1.0

## 接口定义

|**参数名称**||必选/可选|**类型**|说明|
|:--------------|------------|:----|:-----|:--------------------------------------------------------------|
|serviceInfo|permission|必选|string|汽车品牌对应的车服务包名，多个包名以英文逗号分隔。HiCar以此作为车机服务App白名单，只允许白名单中App使用车服务接口。|
|serviceInfo|carBrand|必选|string|品牌信息，由车厂自定义。车服务App可以根据此品牌信息，适配不同的车服务功能。|
|serviceInfo|carModel|必选|string|型号信息，由车厂自定义。车服务App可以根据此型号信息，适配不同的车服务功能。|
|serviceInfo|version|必选|string|车服务版本号，由车厂自定义。车服务App可以根据此版本号，适配不同的车服务功能。|
|requestService|requestInfo|必选|string|请求内容，具体内容由车服务自定义。例如车厂可以使用此字段，要求车服务App填入口令之类的鉴权信息，供车机做App的身份识别。|
|requestService|clientIp|必选|string|手机客户端IP，由HiCar App填充。|
|requestService|serviceIp|必选|string|车机服务端IP，由HiCar App填充。|
|requestService|sessionId|必选|string|交互ID。|
|responseService|responseInfo|必选|string|服务端响应内容，由车服务自定义。例如车厂可以使用此字段，填入自定义数据通道的口令等信息，供自定义通道的认证校验等。|
|responseService|channelInfo|必选|string|服务端通道信息，由车服务自定义。例如rtsp服务的数据通道，车厂可以将rtsp服务的url填入此字段。|
|responseService|result|必选|string|请求结果： * accept：接受请求 * reject：拒绝请求|
|responseService|sessionId|必选|string|交互ID，车机响应时保持和请求时一致。|
|dataToCar|-|必选|string|车服务应用发往车机的数据，具体内容由车服务自定义，车服务App可以发送一些简单的数据到车机。|
|dataToApp|-|必选|string|车机发往车服务应用的数据，具体内容由车服务自定义，车机可以发送一些简单的数据到车服务App。|
[**表1**车服务通道接口]

## 接口示例

车机连上手机后，车机主动上报支持接入的应用列表示例：

```screen
{
    "serviceInfo": {
        "permission":"com.android.demo1, com.android.demo2",
        "carBrand":"brand",
        "carModel":"mode",
        "version":"1.0"
     }
}
```

车服务通道建立后，车服务应用和车机间交互示例：

车服务应用向车机发送数据示例：

```screen
{
    "dataToCar":"2"
}
```

车机向车服务应用发送数据示例：

```screen
{
    "dataToApp":"123"
}
```

车服务应用请求自定义数据通道示例：

```screen
{
    "requestService": {
        "requestInfo":"request car service",
        "serviceIp":"192.168.1.200",
        "clientIp":"192.168.1.100",
        "sessionId":"123"
    }
}
```

车机响应车服务应用自定义数据通道请求示例：

```screen
{
    "responseService": {
        "responseInfo":"response car service",
        "channelInfo":"192.168.1.100:100",
        "result":"accept",
        "sessionId":"123"
    }
}
```
