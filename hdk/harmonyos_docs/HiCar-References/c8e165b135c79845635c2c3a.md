# HiCarNewObject

|Function|
|:-------------------------------------------------------------------------------------------|
|void* HiCarNewObject(HICAR_HANDLE handle, CarObjectType objType, uint32_t size)|
|根据对象类型，创建业务对象。HiCar内部为了管理个别业务数据与HiCar频繁交互场景，提供了业务对象池管理，避免业务数据频繁分配释放内存，以及生命周期管理。目前主要用于反向控制业务。|

|**Parameter name**|**Parameter type**|**Parameter desc**|
|:-----------------|:--------------------------------------------------------------------------------------------------------------|:------------------------------|
|handle|HICAR_HANDLE|HiCar句柄，通过GetHiCarHandle获取到的句柄。|
|objType|[CarObjectType](https://developer.huawei.com/consumer/cn/doc/HiCar-References/car-object-type-0000001051795144)|对象类型。|
|size|uint32_t|对象大小。|

**Return**

|Type|Desc|
|:----|:----------------------------------------------|
|void*|返回结果： * 非NULL：表示申请空间成功，需转换成目标对象指针 * NULL：表示申请失败|
