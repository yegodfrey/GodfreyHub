# isSupportCarGpsDrivingStatusAbility

|Function|
|:--------------------------------------------|
|boolean isSupportCarGpsDrivingStatusAbility()|
|判断是否允许获取汽车的车身驾驶状态数据(车速、方向盘转向角、数据时间、模式、轮速)。|

**Return**

|Type|Desc|
|:------|:------------------------------------------------------------------------------|
|boolean|返回结果： * true：支持 * false：不支持 如果有一个能力(车速、方向盘转向角、数据时间、模式、轮速)支持，则返回true，否则，返回false。|
