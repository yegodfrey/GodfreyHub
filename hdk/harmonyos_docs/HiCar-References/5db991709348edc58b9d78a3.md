# 导航元数据

## 场景说明

车机连接HiCar，在请求导航元数据并获得用户授权后，当HiCar在导航数据发生变化时，将会接收到相应的导航元数据。车机可将这些数据用于仪表盘或HUD显示。
> 说明
>
> 使用导航元数据之前，需要先请求相关元数据，详见[元数据能力](https://developer.huawei.com/consumer/cn/doc/HiCar-References/app-metadata-capability-0000001383252450#ZH-CN_TOPIC_0000001383252450)。

## DataType

517

## 接口版本

1.0

## 接口示例

HiCar App在有导航元数据时，向车机发送导航元数据报文，示例如下所示：

```screen
{
    "type": "update", //create，update，remove
    "navData": {
        "AppName": "com.amap.hmapp",
        "NavTurnImage": [],
        "CurrentRoadName": "进入xxx路",
        "ToDistance": "888",
        "NaviTurnMode": "002E", // 导航转向模式
        "Distance": "888",// 下一次动作剩余距离
        "RoadName":"xxx路", // 下一次进入的道路名
        "IntersectionView": [],// 路口放大图
        "ViewWidth": "10",// 路口放大图宽
        "ViewHeight": "10",// 路口放大图高
        "TrafficLane": "000F", // 行车道
        "NaviBearing": "0",// 导航方向
        "RemainingTime": "0",// 剩余时间
        "DestLocation": "xxx" //终点名称
    }
}
```

车机在收到消息后，向HiCar App发送响应消息，示例如下所示：

```screen
{
    "NavigationDataResp" : {
        "RespCode" : 100000
    }
}
```
