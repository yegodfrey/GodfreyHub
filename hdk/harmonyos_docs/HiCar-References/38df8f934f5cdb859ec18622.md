# CloseAudioRecord

|Function|
|:-----------------------------------------------------------------------------|
|int32_t (*CloseAudioRecord)(const char* id, uint32_t idLen, int32_t sessionId)|
|释放音频录音设备。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-----------------|:-------------|
|*id|const char|MIC ID。|
|idLen|uint32_t|MIC ID长度。|
|sessionId|int32_t|Session ID。|

**Return**

|Type|Desc|
|:------|:------------------------------------|
|int32_t|返回结果： * 0：关闭MIC设备成功 * <0：关闭MIC设备失败/异常|
