# 行驶状态

## 场景说明

车机需要向HiCar App上报行驶状态，便于HiCar App实现保障驾驶安全相关的功能和业务。

行驶状态：

* 行车模式：汽车处于行车（D档）/倒车（R档）/空挡（N档）
* 停车模式：自动挡车处于驻车档（P档）；手动挡车处于空挡+手刹模式

车机和手机连接后需要主动向HiCar App上报当前所处的行驶状态，并在行驶状态发生变化后及时更新。HiCar App在接收到车机上报的行驶状态信息后会进行消息响应，以避免因为传输问题导致未获取到行驶状态信息。

如果车机发送行驶状态信息后没有收到HiCar App的响应消息，那么需要车机间隔重发，间隔重发次数为3次，每次间隔时间为1秒，重发期间只要收到一次HiCar App的响应消息，则表示此次上报成功。如果间隔重发3次依然没有收到响应消息，则表明传输链路可能出现故障，需要车机侧记录相应异常信息。

## Data Type

506

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:----------|:----|:--|:-----------------------------------------------------------------------------------------------------------------------------------|
|drivingMode|可选|int|车辆行驶状态： * -1：不支持上报车辆行驶状态 * 0：行车状态 * 1：停车状态 行驶状态不变化时不需要上报。|
|errorCode|必选|int|错误码，详见[错误码表](https://developer.huawei.com/consumer/cn/doc/HiCar-References/errorcode-0000001199330043#ZH-CN_TOPIC_0000001199330043)。|
[**表1**行驶状态接口]

## 接口示例

车机向HiCar App上报行驶状态示例：

```screen
{
    "drivingMode":0
}
```

HiCar App向车机发送的响应消息示例：

```screen
成功示例：
{
    "errorCode":100000
}
失败示例(参数不合法)：
{
    "errorCode":100001
}
```
