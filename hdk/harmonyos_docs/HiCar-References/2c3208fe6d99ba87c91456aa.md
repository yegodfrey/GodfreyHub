# startBluetoothRecommend

|Function|
|:-----------------------------------------------------------------------------------------------|
|startBluetoothRecommend|
|在连接HiCar前，车机HMI应用监听到有蓝牙连接后，调用此接口可启动推荐使用HiCar功能 。收到手机侧反馈后会通过CarListener的onShowStartPage回调通知HMI应用。|
