# GetCameraCapability

|Function|
|:------------------------------------------------------------------------------------|
|int32_t (*GetCameraCapability)(DMSDPCameraCapabilities** capabilities, uint32_t* num)|
|函数指针定义，查询可用的Camera属性信息集合，返回Camera属性集结构体。使用Release接口释放采集到的能力集资源。|

**Parameters**

|**Parameter name**|**Parameter type**|**Parameter desc**|
|:-----------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------|
|capabilities|[DMSDPCameraCapabilities](https://developer.huawei.com/consumer/cn/doc/HiCar-References/dmsdp-camera-capabilities-0000001058966849#ZH-CN_TOPIC_0000001058966849)|能力集。|
|num|uint32_t|能力集个数，每Camera 1个。|

**Return**

|Type|Desc|
|:------|:---------------------------------------|
|int32_t|查询本地Camera属性信息，返回查询到的各个可用Camera的属性信息的集合。|
