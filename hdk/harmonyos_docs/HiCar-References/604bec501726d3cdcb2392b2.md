# getStreamType

|Method|
|:------------------|
|int getStreamType()|
|获取音频流类型。|

**Return**

|Type|Desc|
|:---|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|int|音频流类型，详情见AudioManager音频流参数。 例值： 0：语音通话（比如打电话、VoIP通话）。 1：发声辅助语音（比如使用UI界面时听到的声音）（语音播报音）。 2：通话铃声（比如打电话、VoIP通话）。 3：文本语音。 4：警示音（比如起床闹钟）。 5：提示音。 8：正在通话中提示音（比如线路忙音、DTMF音）。 10：易用性辅助语音（比如屏幕文字朗读器）。|
