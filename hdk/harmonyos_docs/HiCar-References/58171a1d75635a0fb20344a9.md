# TrustPhoneInfo

|Name|Type|Desc|
|:----------------------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------|
|phoneIdRealLen|uint32_t|手机唯一标识长度。|
|phoneId[PHONE_ID_MAX_LEN]|uint8_t|手机唯一标识。|
|phoneNameRealLen|uint32_t|手机名称长度。|
|phoneName[PHONE_NAME_MAX_LEN]|uint8_t|手机名称。|
|phoneBrMacRealLen|uint32_t|手机蓝牙地址长度。|
|phoneBrMac[BR_MAC_MAX_LEN]|uint8_t|手机蓝牙地址。|
|lastConnectTime|int64_t|最近一次连接的系统时间。|
|connectStatus|uint32_t|连接状态，详见[CarConnectionStatus](https://developer.huawei.com/consumer/cn/doc/HiCar-References/car-connection-status-0000001053502171)。|
