# 导航焦点

## 场景说明

HiCar App默认提供导航服务，如果车机本机也提供车载导航服务，同时运行时会出现冲突，因此需要HiCar App和车机间协商导航焦点：

* HiCar App启动导航时通知车机导航焦点为HICAR，车机侧需要停止导航服务。
* HiCar App停止导航时通知车机导航焦点为HICAR_STOP，车机侧可自行处理逻辑。
* 车机侧启动导航时通知HiCar App导航焦点为NATIVE，HiCar App需要停止导航服务。
* 车机侧停止导航时通知HiCar App导航焦点为NATIVE_STOP，HiCar App可自行处理逻辑。
* 车机侧与手机侧协商导航焦点时可以发送navFocusPolicy，可以选择导航互斥策略。

## Data Type

503

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:-------|:----|:-----|:-------------------------------------------------------------------------------------------------------------------------------|
|navFocus|必选|string|导航焦点： * HICAR：导航焦点切换到HiCar提供的导航服务。 * HICAR_STOP: HiCar导航应用停止导航，释放导航焦点。 * NATIVE：导航焦点切换到车机本地提供的导航服务。 * NATIVE_STOP：原车停止导航，释放导航焦点。|
[**表1**导航焦点接口]

|参数名称|必选/可选|类型|说明|
|:-------------|:----|:--|:------------------------------------------------------------------------------------------------|
|navFocusPolicy|可选|int|导航互斥策略（默认为2）： * 1：车机本地导航与HiCar投屏界面发起的导航、手机上发起的导航均互斥。 * 2：车机本地导航与HiCar投屏界面上发起的导航互斥，但允许与手机上发起的导航共存。|
[**表2**导航互斥策略接口]

## 接口示例

车机向手机发送导航互斥策略示例：

```screen
{
    "navFocusPolicy":1
}
```

HiCar App向车机请求导航焦点示例：

```screen
{
    "navFocus":"HICAR"
}
```

HiCar App通知车机HiCar App释放导航焦点示例：

```screen
{
    "navFocus":"HICAR_STOP"
}
```

车机向HiCar App请求导航焦点示例：

```screen
{
    "navFocus":"NATIVE"
}
```

车机通知HiCar App车机释放导航焦点示例：

```screen
{
    "navFocus":"NATIVE_STOP"
}
```
