# UnRegisterGPSDataCallback

|Function|
|:-------------------------------------------------|
|int32_t (*UnRegisterGPSDataCallback)()|
|手机停止使用位置服务时，手机通知设备停止数据采集操作，注销注册的数据回传接口，并停止GPS数据采集。|

**Return**

|Type|Desc|
|:------|:-------------------|
|int32_t|返回结果： * 0：成功 * <0：失败|
