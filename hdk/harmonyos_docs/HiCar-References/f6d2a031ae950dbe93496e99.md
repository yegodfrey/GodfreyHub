# GPSLocation

|Function|
|:----------------------------------------------------------------------------------------------|
|void (*GPSLocation)(char *location, int32_t len)|
|位置信息回传接口，包括经纬度、高度、精度、卫星时间、行进方向等。 RegisterGpsDataCallBack时开始持续上报，UnRegisterGpsDataCallBack时停止上报。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
|*location|char|具体的位置数据。例如： $GPGGA,092204.999,4250.5589,S,14718.5084,E,1,04,24.4,12.2,M,19.7,M,,0000*1F$GPRMC,024813.640,A,3158.4608,N,11848.3737,E,10.05,324.27,150706,,,A*50|
|len|int32_t|数据长度。|
