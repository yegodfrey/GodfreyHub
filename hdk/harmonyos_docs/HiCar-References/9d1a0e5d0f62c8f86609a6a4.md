# 低油低电低压状态

## 场景说明

HiCar会为车服务应用提供低油/低电/胎压低压状态数据，用于支撑车服务应用向用户提供推荐服务。

车机需要在HiCar连接成功后主动上报这些车身状态数据，并在后续状态数据发生变化时更新数据状态。

## Data Type

507

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:-----------|:----|:------|:--------------------------------------------------|
|isOilEmpty|必选|boolean|是否处于低油状态： * true：汽（柴）油车处于低油状态 * false：汽（柴）油车未处于低油状态|
|isBatteryLow|必选|boolean|是否处于低电状态： * true：电动汽车处于低电状态 * false：电动汽车未处于低电状态|
|isTpLow|必选|boolean|是否处于胎压低压状态： * true：处于胎压低压状态 * false：未处于胎压低压状态|
[**表1**低油低电低压状态接口]

## 接口示例

### 车机连上HiCar主动上报当前车身状态

汽（柴）油车上报状态示例：

```screen
{
    "isOilEmpty":false,
    "isTpLow":false
}
```

电动汽车上报状态示例：

```screen
{
    "isBatteryLow":false,
    "isTpLow":false
}
```

### 车机主动上报变化后的车身状态

车机向HiCar App上报低油状态示例：

```screen
{
    "isOilEmpty":true
}
```

车机向HiCar App上报低电状态示例：

```screen
{
    "isBatteryLow":true
}
```

车机向HiCar App上报胎压低压状态示例：

```screen
{
    "isTpLow":true
}
```
