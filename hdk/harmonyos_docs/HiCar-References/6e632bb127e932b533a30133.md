# 品牌名称

车机上电初始化时通过HiCar SDK接口设置汽车品牌信息。

|键值|类型|说明|
|:--------|:-----|:-------------------------------------------------------------------------------------------------|
|CAR_BRAND|String|汽车品牌名称，用于显示在手机侧发现连接框汽车Logo图标下方。 * 支持获取汽车品牌信息时，请根据实际的汽车品牌。 * 车机无法获取汽车品牌信息时，请设置为"notsupport"。（缺省默认值）|
[**表1**初始化时设置品牌名称]

HiCar SDK初始化设置示例：

```screen
CarConfig.Builder builder = newCarConfig.Builder();
Map<String, String> config = newHashMap<String, String>();
config.put("CAR_BRAND",  "XXX");   
builder.withInitialConfig(config);
```
