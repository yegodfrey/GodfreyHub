# startReconnect

|Method|
|:---------------------------------------------------------------|
|int startReconnect(String macAddress)|
|int startReconnect(String macAddress, boolean isManualReconnect)|
|开始自动连接。|

**Parameters**

|Parameter name|Parameter type|Parameter desc|
|:----------------|:-------------|:---------------------------------|
|macAddress|String|待连接的设备蓝牙地址。|
|isManualReconnect|boolean|是否为手动回连： * true：手动回连 * false：非手动回连|

**Return**

|Type|Desc|
|:---|:---------------------------------------------------------------------------------------------------------------------------|
|int|0表示调用成功，非0表示调用失败，详见[HiCarConst](https://developer.huawei.com/consumer/cn/doc/HiCar-References/hicar-const-0000000000030396)。|
