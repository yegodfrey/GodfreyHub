# Overview

|结构体|结构体内函数|说明|
|:-------------------|:-------------------------------------------------------|:---------------------------------------------------------|
|BtRecommendAdpterOps|registerBtSocketCallback(BtSocketDataCallback *callback)|从HiCar SDK中获得数据接收处理函数，用于处理从蓝牙socket中获取的数据。|
|BtRecommendAdpterOps|initBtSocket(RfcommServerInfo serverInfo)|根据HiCar SDK给出的RfcommServerInfo创建蓝牙socket，并处理从socket中接收的数据。|
|BtRecommendAdpterOps|sendData(char *data)|HiCar SDK会调用此函数，将数据回复给手机。|
|BtRecommendAdpterOps|unregisterBtSocketCallback()|反注册函数，释放从HiCar SDK中拿到的数据处理函数。|
|BtRecommendAdpterOps|deInitBtSocket()|反初始化函数，销毁蓝牙socket。|
