# onTransmissionProgressUpdate

|Method|
|:-----------------------------------------------|
|void onTransmissionProgressUpdate(int progress);|
|文件传输过程中，文件传输进度的回调，1s一次。|

**Parameters**

|Parameter name|Parameter type|Parameter desc|
|:-------------|:-------------|:------------------------------|
|progress|int|表示传输百分比的0~100的正整数，如50表示传输进度50%。|
