# 元数据能力

## 场景说明

车机连接HiCar后，可以请求HiCar App开放应用元数据，用于仪表盘/HUD辅助显示。

HiCar App响应车机请求时，会根据用户授权情况，返回可开放的元数据类型。车机根据返回结果，再进一步获取具体的元数据内容。

## DataType

514

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:------------|:----|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|RequestAAData|必选|int|请求消息，用于车机向HiCar App请求开放应用元数据。 请求消息包含应用元数据类型，基于bit位区分对应的元数据类型，取值1表示请求对应元数据，取值0表示不请求。详细说明如下： * Bit位1，音频元数据 * Bit位2，通话元数据 * Bit位3，导航元数据 * Bit位4，日历元数据 * Bit位5，天气元数据 * Bit位6，情景智能元数据 * Bit位7，IoT元数据（暂不支持） 车机需要根据数据使用场景将二进制转成int型进行上报，例如： * 二进制0111，数值7，表示请求音频、通话、导航元数据。 * 二进制0101，数值5，表示请求音频、导航元数据。 * 二进制01111000，数值120，表示请求日历、天气、情景智能元数据。|
|RequestCaller|必选|string|当前车型的modelId。|
[**表1**元数据能力接口]

|参数名称|必选/可选|类型|说明|
|:-------------|:----|:-----|:--------------------------------------------------------------------------------------------|
|ResponseAAData|必选|object|响应数据，详见[表3](#ZH-CN_TOPIC_0000001383093924__zh-cn_topic_0000001340436470_table20251124410111)。|
[**表2**元数据能力响应数据]

|参数名称|必选/可选|类型|说明|
|:----------|:-----|:------|:-------------------------------------------------|
|MEDIA|根据请求回复|boolean|音频元数据： * true：允许获取音频元数据 * false：禁止获取音频元数据|
|CALL|根据请求回复|boolean|通话元数据： * true：允许获取通话元数据 * false：禁止获取通话元数据|
|NAVIGATION|根据请求回复|boolean|导航元数据： * true：允许获取导航元数据 * false：禁止获取导航元数据|
|CALENDAR|根据请求回复|boolean|日历元数据： * true：允许获取日历元数据 * false：禁止获取日历元数据|
|WEATHER|根据请求回复|boolean|天气元数据： * true：允许获取天气元数据 * false：禁止获取天气元数据|
|INTELLIGENT|根据请求回复|boolean|情景智能元数据： * true：允许获取情景智能元数据 * false：禁止获取情景智能元数据|
|IOT|根据请求回复|boolean|IoT元数据（暂不支持）： * true：允许获取IoT元数据 * false：禁止获取IoT元数据|
[**表3**ResponseAAData]

## 接口实例

车机向HiCar App请求获取元数据，请求音频元数据、通话元数据、导航元数据的报文示例如下所示：

```screen
{
    "RequestAAData" : 7,
    "RequestCaller" : "00010001"
}
```

HiCar App响应车机请求时，根据用户授权，返回可开放的元数据类型，如只开放音频元数据和通话元数据的报文示例如下所示：

```screen
{
    "ResponseAAData":{
        "MEDIA":true,
        "CALL":true,
        "NAVIGATION":false
    }
}
```
