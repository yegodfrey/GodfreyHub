# 媒体控制指令

## 场景说明

支持原车发送指令控制媒体应用音频播控操作，包括播放/暂停，上一首，下一首，进度调节，收藏和设置循环模式。

## Data Type

555

## 接口版本

1.0

## 接口定义

|参数名|类型|必选/可选|说明|
|:--------|:-----|:----|:------------------------------------------------------------------------------------------------------------------------|
|command|string|必选|播控操作命令： * play：播放 * pause：暂停 * playNext：下一首 * playPrevious：上一首 * setLoopMode：设置循环模式 * seekTo：跳转某一节点 * toggleFavorite：是否收藏|
|parameter|object|可选|seek命令参数： * progressPercentage：拖动进度百分比，取值范围（0.0 - 100.0） * mediaSeekToPosition：拖动进度位置点，单位为毫秒（ms） 上述参数传递一个即可。|
[**表1**参数说明]

## 接口示例

1. 有参数命令，seek操作。使用进度百分比作为参数，示例如下所示：

   ```screen
   {
     "command": "seekTo",
     "parameter": {
       "mediaSeekToPosition": 30000, //进度占总时长播放比
     }
   }
   ```

   或使用指定播放位置作为参数，示例如下所示：

   ```screen
   {
     "command": "seekTo",
     "parameter": {
       "progressPercentage": 30.5 //指定播放位置，单位：毫秒
     }
   }
   ```

2. 无参数命令，如设置循环模式，示例如下所示：

   ```screen
   {
     "command": "play",
     "parameter": {}
   }
   ```
