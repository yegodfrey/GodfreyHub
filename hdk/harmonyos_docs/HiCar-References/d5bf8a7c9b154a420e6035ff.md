# VideoFrameInfo

|Name|Type|Desc|
|:---------------|:-------|:---------------------------------------------|
|length|uint16_t|帧信息总长度，包含pack指向的整个结构体。|
|screenRotation|uint8_t|窗口左旋度数： * 0：正向 * 90：左旋90度 * 180：负向 * 270：左旋270|
|hasNavigationKey|uint8_t|当前帧是否携带导航键。|
|pack[1]|char|扩展信息，目前保留。|
