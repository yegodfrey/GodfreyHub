# getCodecType（Beta）

|Method|
|:-----------------|
|int getCodecType()|
|获取投屏视频编码方式。|

**Return**

|Type|Desc|
|:---|:-----------------------------------------|
|int|投屏的视频编码方式，视频流编码类型： * 1：H264，缺省默认值 * 2：H265|
