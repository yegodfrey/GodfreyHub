# registerCarDataListener

|Function|
|:----------------------------------------------------------------------------------------------|
|boolean registerCarDataListener(GpsDataCallBack gpsDataCallBack)|
|向车机订阅GPS的数据。 手机侧打开导航后，由手机向车机发起GPS数据请求，车机侧华为SDK向车机订阅GPS数据的监听，通过监听接口，车机向华为回传GPS的基础数据、Sensor和车身数据。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-----------------|:-------------|
|gpsDataCallBack|GpsDataCallBack|GPS数据回调。|

**Return**

|Type|Desc|
|:------|:--------------------------|
|boolean|订阅的结果： * true：成功 * false：失败|
