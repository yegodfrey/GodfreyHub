# updateCodecConfigureFlag（Beta）

|Method|
|:---------------------------------------------------------|
|CarConfig updateCodecConfigureFlag(int codecConfigureFlag)|
|更新车机解码器的定制配置参数。|

**Parameters**

|Parameter name|Parameter type|Parameter desc|
|:-----------------|:-------------|:-----------------------------------|
|codecConfigureFlag|int|解码器的定制配置参数，芯片相关配置，不需要厂商单独配置，一般为默认值0。|

**Return**

|Type|Desc|
|:--------|:--------|
|CarConfig|车机配置信息对象。|
