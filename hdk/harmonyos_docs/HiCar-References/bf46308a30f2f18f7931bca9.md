# unRegisterCarAudioListener（Beta）

|Method|
|:--------------------------------------------------------|
|int unRegisterCarAudioListener(CarAudioListener listener)|
|取消HiCar SDK音频事件侦听。|

**Parameters**

|Parameter name|Parameter type|Parameter desc|
|:-------------|:---------------|:-------------------|
|listener|CarAudioListener|HiCar SDK音频事件侦听回调函数。|

|Type|Desc|
|:---|:---------------------------------------------------------------------------------------------------------------------------|
|int|0表示调用成功，非0表示调用失败，详见[HiCarConst](https://developer.huawei.com/consumer/cn/doc/HiCar-References/hicar-const-0000000000030396)。|
