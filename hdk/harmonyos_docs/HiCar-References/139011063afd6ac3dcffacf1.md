# getCustomizedAudioAttributes（Beta）

|Function|
|:------------------------------------------------------------------------------------------------------------------------------------------|
|CustomizedAudioAttributes getCustomizedAudioAttributes(int[] usage, int[] contentType, int focusGain, Map<String, String> info)|
|HiCar SDK通过回调的方式，由车机应用根据原始信息映射构造AudioAttributes/StreamType并返回给HiCar SDK，SDK根据映射后的AudioAttributes或者StreamType申请焦点进行焦点管理或创建AudioTrack进行音频流播放。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|usage|int[]|手机侧发送的音频数据的Usage，多音源混音场景存在多个有效Usage，将音频数据的所有有效Usage都上报给车机应用，由车机应用决定优先级和转换策略。|
|contentType|int[]|类似Usage的策略，将音频数据的所有contentType上报给车机应用。|
|focusGain|int|音频焦点类型，详情参考谷歌AudioManager音频焦点参数。 例值： 0：非谷歌AudioManager音频焦点参数，为该接口新增参数。用于区分该接口的调用时是音频播放还是音频焦点申请的操作 1：长焦点类型，音乐等场景。 2：短焦点类型，电话、通知、闹铃、QQ、微信等场景。 3：DUCK焦点，导航等场景。 4：独占焦点。 当该值为0时，说明当前是在获取音频播放需要使用的streamtype或者AudioAttributes。厂商HMI应用需要根据传递参数中的usage，转换为指定的streamtype或者AudioAttributes，并根据此参数实例化CustomizedAudioAttributes并返回。 当该值不为0时，说明当前是在获取申请焦点使用的streamtype或者AudioAttributes，传递下来的焦点类型使用情况参考谷歌AudioManager音频焦点参数。厂商HMI应用可根据usage，转换为指定的streamtype或者AudioAttributes；或者结合usage以及 focusGain的值转换成适当的streamtype或者AudioAttributes，并根据此参数实例化CustomizedAudioAttributes并返回。|
|info|Map<String, String>|预留的扩展属性，用于将手机侧音频类信息上报给车机应用。|

**Return**

|Type|Desc|
|:------------------------|:---------|
|CustomizedAudioAttributes|自定义音频策略属性。|
