# 驾驶位置

驾驶位置标识车辆的驾驶位置是在左侧还是在右侧。HiCar App可以根据驾驶位置信息调整UI布局展示，例如将DOCK区域显示在左侧或右侧。

车机上电启动后，需在HiCar SDK初始化时上报驾驶位置。

|参数|说明|
|:---------------------------------------|:----------------------------------------|
|CarConfig.CarDeviceInfo.steeringWheelPos|车辆驾驶位置： * 0：左舵车，即驾驶位置在左侧 * 1：右舵车，即驾驶位置在右侧|
[**表1**初始化时设置驾驶位置参数]

HiCar SDK初始化设置示例：

```screen
CarConfig config;
......
/* 驾驶位置 */
config.deviceInfo.steeringWheelPos = 0;
......
int retCode = HiCarInit(&config);
```
