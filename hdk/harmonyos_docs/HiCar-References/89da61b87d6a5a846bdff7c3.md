# Connect

|Function|
|:--------------------------------------|
|int (*Connect)(const void *channelInfo)|
|连接通道。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-----------------|:------------------------------------------------------------------------------------------------------------------------------------------|
|*channelInfo|const void|channelInfo通道相关参数, 通配各设备参数差异。 * BLE driver：暂不适配。 * BR driver：无感连接场景需要调用Connect函数实现BR通道回连，channelInfo为结构体BrChannelData。 * Wi-Fi driver：暂不适配。|

**Return**

|Type|Desc|
|:---|:-------------------|
|int|返回结果： * 0：成功 * 非0：失败|
