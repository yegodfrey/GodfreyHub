# 导航流转

## 场景说明

HiCar通过开放导航流转的方式，将导航地址的数据传递到车机，车机在正确获取到相关数据后，可以用于车机导航。

## Data Type

542

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:-------------|:----|:-----|:----------------------------------------|
|address|必选|string|导航地址|
|latitude|必选|double|坐标纬度|
|longitude|必选|double|坐标经度|
|hopType|可选|int|地址流转类型： * 1：地图导航 * 2：摇一摇导航 * 3：剪贴板复制导航|
|mapName|可选|int|地图应用名称： * 0：未知 * 1：高德地图 * 2：百度地图 * 3：花瓣地图|
|coordinateType|可选|int|地图坐标系类型： * 0：GCJ02国内坐标编码 * 1：WGS84国际坐标编码|

|参数名称|必选/可选|类型|说明|
|:--------|:----|:--|:-------------------------------------|
|errorCode|必选|int|车机是否需要拉起原车导航： * 100000：支持 * 100003：不支持|

## 接口示例

HiCar App在识别到目的地数据时，向车机发送导航流转数据报文内容示例如下：

```screen
{
    "address":"华为研究所"
    "latitude":30.505311
    "longitude":114.402329
    "hopType":1 // 1: 地图导航 2: 摇一摇导航 3: 剪贴板复制导航
    "mapName":1 // 0: 未知 1: 高德 2: 百度 3: 花瓣
    "coordinateType":0 // 0: GCJ02国内坐标编码 1: WGS84国际坐标编码
}
```

如果车机需要拉起原车导航则回复支持：

```screen
{
    "errorCode":100000
}
```

不支持：

```screen
{
    "errorCode":100003
}
```
