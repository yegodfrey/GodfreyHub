# readSecureFile

|Function|
|:---------------------------------------------|
|byte[] readSecureFile(string fileName)|
|HiCar SDK通过回调的方式，由车机应用实现认证文件的管理，该回调用于读取认证文件信息。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-----------------|:-------------|
|fileName|string|获取认证信息的文件名。|

**Return**

|Type|Desc|
|:-----|:---------|
|byte[]|认证文件的字节数组。|
