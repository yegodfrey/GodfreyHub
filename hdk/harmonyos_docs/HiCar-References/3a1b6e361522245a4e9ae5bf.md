# onAppInfoRemove

|Method|
|:--------------------------------------------------------------------|
|void onAppInfoRemove(String deviceId, List<AppInfoBean> appInfoBeans)|
|回调需要移除的融合桌面AppInfo数据（手机上卸载的应用）。|

**Parameters**

|Parameter name|Parameter type|Parameter desc|
|:-------------|:----------------|:-------------------|
|deviceId|String|对端设备（手机）deviceId。|
|appInfoBeans|List<AppInfoBean>|已经被卸载的应用AppInfo数据列表。|
