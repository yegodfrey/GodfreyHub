# DMSDPAudioFocus

|Enumerator|Desc|
|:--------------------------------------|:----------------------------------|
|AUDIOFOCUS_NONE = 0|-|
|AUDIOFOCUS_GAIN = 1|HiCar请求长期占有音频焦点，失去焦点者停止播放和释放焦点。|
|AUDIOFOCUS_GAIN_TRANSIENT = 2|HiCar请求短时占有音频焦点，失去焦点者暂停播放。|
|AUDIOFOCUS_GAIN_TRANSIENT_MAY_DUCK = 3|HiCar请求短时占有音频焦点，失去焦点者可以继续播放但音量需要降低。|
|AUDIOFOCUS_GAIN_TRANSIENT_EXCLUSIVE = 4|HiCar请求短时占有音频焦点，但希望失去焦点者不要有声音播放。|
|AUDIOFOCUS_RELEASE = 5|HiCar请求释放音频焦点。|
|AUDIOFOCUS_LOSS = -1|车机通知HiCar失去了音频焦点或无法获得音频焦点。|
|AUDIOFOCUS_LOSS_TRANSIENT = -2|车机通知HiCar暂时失去了音频焦点。|
|AUDIOFOCUS_LOSS_TRANSIENT_CAN_DUCK = -3|车机通知HiCar可以继续通过媒体通道播放，但是需要音量降低。|
