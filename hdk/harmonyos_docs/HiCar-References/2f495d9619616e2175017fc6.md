# isSupportCarGpsAbility

|Function|
|:---------------------------------------|
|boolean isSupportCarGpsAbility()|
|判断是否允许获取汽车的GPS数据(经度、纬度、高度、精度、卫星时间、行进方向)。|

**Return**

|Type|Desc|
|:------|:---------------------------------------------------------------------------------|
|boolean|返回结果： * true：支持 * false：不支持 如果有一个能力(经度、纬度、高度、精度、卫星时间、行进方向)支持，需要返回为true，不支持返回false。|
