# HiCarGetPinCode

|Function|
|:-------------------------------------------------------------------|
|int32_t HiCarGetPinCode(uint8_t *pinCode, uint32_t maxLen)|
|获取PIN码。厂商HMI应用在发送广播后，获取PIN码显示在车机屏幕，用户在手机侧输入该码进行认证。需要车机硬件环境支持获取安全随机数。|

|**Parameter name**|**Parameter type**|**Parameter desc**|
|:-----------------|:-----------------|:-----------------|
|pinCode|uint8_t*|三方接收PIN码的Buffer。|
|maxLen|uint32_t|Buffer的最大长度。|

**Return**

|Type|Desc|
|:------|:------------------------------------------------------|
|int32_t|返回结果： * >0：获取PIN码成功，返回PIN码的长度，当前返回值为6。 * 0或负数：获取PIN码失败。|
