# 通话元数据

## 场景说明

车机连接HiCar，在请求通话元数据获得用户授权后，当HiCar在通话状态发生改变时，将会通知车机通话的基础信息和状态，车机可将这些数据送到仪表盘、HUD或者车机中控界面进行显示，也可以根据通话元数据进行通话逻辑处理。
> 说明
>
> 使用通话元数据之前，需要先请求相关元数据，详见[元数据能力](https://developer.huawei.com/consumer/cn/doc/HiCar-References/app-metadata-capability-0000001383093924#ZH-CN_TOPIC_0000001383093924)。

## DataType

516

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:-----------|:----|:-----|:-----------------------------------------------------------------------------------------------|
|CallData|必选|object|具体通话元数据，详见[表2](#ZH-CN_TOPIC_0000001433534081__zh-cn_topic_0000001391116369_table13313536121019)。|
|CallDataResp|必选|object|响应数据，详见[表3](#ZH-CN_TOPIC_0000001433534081__zh-cn_topic_0000001391116369_table1943683611395)。|
[**表1**通话元数据]

|参数名称|必选/可选|类型|说明|
|:-----------------|:----|:-----|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|ContactName|必选|String|联系人名称。|
|RemoteNumber|必选|String|来电号码。|
|Direction|必选|int|通话方向： * 0：UNKNOWN，未知 * 1：OUTGOING，呼出 * 2：INCOMING，呼入|
|Status|必选|int|呼叫状态： * 0：IDLE，空闲 * 1：ACTIVE，通话 * 2：HOLDING，保持 * 3：DIALING，拨号 * 4：ALERTING，响铃 * 5：INCOMING，来电振铃 * 6：WAITING，呼叫等待 * 7：DISCONNECTED，断开 * 8：DISCONNECTING，正在断开|
|CallStartTimestamp|必选|long|呼叫开始时间戳。|
|CallID|必选|String|通话标识。|
|CallApp|必选|int|通话应用： * 0：UNKNOWN，未知 * 1：TELEPHONY，运营商通话 * 2：HICALL，畅连通话|
|NumberMarktype|必选|String|号码标记类型。在来电场景标记远端号码类型，识别广告或诈骗电话，供用户参考是否接听。标记类型包括： * 空格：默认取值 * crank：骚扰电话 * fraud：诈骗电话 * promote sales：广告推销 * house agent：房产中介 * express：快递送餐 * taxi：出租车 * insurance：保险理财|
|ReleaseCause|必选|int|释放原因： * -1：UNKNOWN，未知原因 * 0：通话结束 * 1：呼叫被拒绝 * 2：呼叫失败|
[**表2**CallData]

|参数名称|必选/可选|类型|说明|
|:-------|:----|:--|:--------------------------------|
|RespCode|必选|int|响应结果： * 100000：接收成功 * 100001：接收失败|
[**表3**CallDataResp]

## 接口示例

HiCar App在呼叫状态发生变化时，根据用户授权记录，向授权车机发送呼叫元数据的示例报文如下所示：

```screen
{
    "CallData": {
	"ContactName": "tom",
	"RemoteNumber": "123456789",
	"Direction": 1,
	"Status": 1,
	"CallStartTimestamp": 1999,
	"CallID": "123456789",
	"CallApp": 2,
	"NumberMarktype": "insurance",
	"ReleaseCause": 1
     }
}
```

车机在收到消息后，向HiCar App发送响应消息，示例如下所示：

```screen
{
    "CallDataResp" : {
        "RespCode" : 100000
    }
}
```
