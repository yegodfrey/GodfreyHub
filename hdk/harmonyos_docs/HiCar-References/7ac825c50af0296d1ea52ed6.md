# HiCarStopProjection

|Function|
|:-----------------------------------------------|
|int32_t HiCarStopProjection(HICAR_HANDLE handle)|
|停止HiCar投屏。|

|**Parameter name**|**Parameter type**|**Parameter desc**|
|:-----------------|:-----------------|:------------------------------|
|handle|HICAR_HANDLE|HiCar句柄，通过GetHiCarHandle获取到的句柄。|

|Type|Desc|
|:------|:---------------------------------------|
|int32_t|停止投屏结果： * 1：停止HiCar投屏成功 * 非1：停止HiCar投屏失败|
