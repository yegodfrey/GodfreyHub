# 动态切换投屏区域尺寸

## 场景说明

车机侧改变投屏区域的宽高，手机侧接收车机侧发来的数据自适应调整显示的分辨率，达到较好的观感体验。
> 说明
>
> 1. 该特性需手机侧HarmonyOS系统版本在6.1.0.120及以上。
> 2. 该特性当前仅在融合桌面中支持。

## Data Type

547

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:---|:----|:-----|:--------------------------------------------------|
|code|必选|int|状态码填1。 用于适配屏幕宽高改变后投屏显示，分屏改变后车机向手机发送此消息，手机收到此消息重新显示。|
|data|必选|Object|Json格式的数据对象，{"width":1920,"height":1080}。单位为px。|
[**表1**Request]

|参数名称|必选/可选|类型|说明|
|:---|:----|:--|:-----------------------------------------------------|
|code|/|int|状态码为2。 手机侧处理完毕，请求车机侧取消蒙层。开发者可以根据547消息监听状态码2，隐藏车机侧蒙层显示。|
[**表2**Response]

## 接口示例

车机向手机发送改变后的投屏区域宽高数据：

```screen
{
  "code":1,
  "data":{
    "width":1920,
    "height":1080
  }
}
```

车机接收来自手机侧的响应数据：

```screen
{
  "code":2,
}
```
