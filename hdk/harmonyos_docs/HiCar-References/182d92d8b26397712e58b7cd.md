# getModelId

|Method|
|:----------------------------------------|
|String getModelId()|
|获取ModelId，该值为华为分配给车机厂商的标识值，用于区分汽车厂商和汽车型号。|

**Return**

|Type|Desc|
|:-----|:------------------------------------|
|String|标识汽车厂商的字符串，共8位字符，前6位为汽车厂商标识，后2位为车型标识。|
