# Overview

|Return type|Function name|
|:----------|:---------------------------------------------------------------------------------------|
|int32_t|HiCarInit 初始化HiCar SDK。|
|int32_t|HiCarRelease 注销HiCar SDK。|
|int32_t|HiCarRegisterListener 注册HiCar侦听事件，用于接收HiCar设备状态变化，服务变化，接收HiCar数据等。|
|int32_t|HiCarStartAdv 触发HiCar发送广播，HiCar手机可以发现车机。|
|int32_t|HiCarStopAdv 停止HiCar发送广播。|
|int32_t|HiCarReconnect 触发无感连接。厂商在检测到蓝牙配对，并且上次非用户主动断开的情况下，调用该接口触发车机无感连接之前已经配对过的手机，并最终完成HiCar连接投屏。|
|int32_t|HiCarGetPinCode 获取PIN码。厂商在发送广播后，获取PIN码显示在车机屏幕，以便用户在手机侧输入该码进行认证。|
|int32_t|HiCarStartProjection 启动HiCar投屏，当收到Display服务启动状态时进行投屏。|
|int32_t|HiCarStopProjection 停止HiCar投屏，当收到Display服务停止状态时停止投屏。|
|int32_t|HiCarPauseProjection 暂停HiCar投屏，当收到Display服务暂停状态时暂停投屏。|
|void*|HiCarNewObject 创建业务对象。根据HiCar业务对象管理对象类型，创建业务对象。|
|int32_t|HiCarDeleteObject 销毁业务对象。用于业务对象回收和内存释放。|
|int32_t|HiCarPostEvent 车机向HiCar发送事件，比如触屏事件、按键事件、语音唤醒事件等。|
|int32_t|HiCarSendData 车机向HiCar发送某类数据流，比如车机Logo图片等。|
|char*|HiCarGetSdkVersion 获取HiCar的版本号。用于后续SDK的版本升级。|
|int32_t|HiCarGetTrustDeviceList 获取当前和车机完成鉴权认证后的设备列表。|
|int32_t|HiCarDeleteTrustDevice 删除指定可信设备，删除后需要重新建立鉴权认证。|
|int32_t|HiCarDisconnectDevice 从车机侧断开与指定手机之间的连接。|
|int32_t|HiCarGetConnectionType 获取当前HiCar的连接方式。|
|int32_t|HiCarStartBluetoothRecommend 开始启动车机侧Rfcomm监听，等待和手机交互完成推荐使用。|
