# DMSDPServiceStatus

|Enumerator|Desc|
|:----------|:---------------|
|PLUGIN = 1|设备插入，比如USB摄像头插入。|
|UNPLUG|设备拔出，比如USB摄像头拔出。|
|AVAILABLE|设备当前可用。|
|UNAVAILABLE|设备当前不可用。|
