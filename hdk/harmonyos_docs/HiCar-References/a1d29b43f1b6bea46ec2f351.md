# DMSDPAudioCapabilities

|Name|Type|Desc|
|:--------|:------------------------------------------------------------------------------------------------------------------------|:------------------------------|
|*id|char|音频设备的id，比如"mic1"或者"speaker1"。|
|idLen|uint32_t|音频设备的id长度。|
|type|[DMSDPAudioDevice](https://developer.huawei.com/consumer/cn/doc/HiCar-References/dmsdp-audio-device-0000001053089211)|音频设备的类型。|
|profiles|[DMSDPAudioProfiles](https://developer.huawei.com/consumer/cn/doc/HiCar-References/dmsdp-audio-profiles-0000001052249190)|音频设备支持的能力集，比如采样率、通道数等。|
|codecs|[DMSDPAudioCodecs](https://developer.huawei.com/consumer/cn/doc/HiCar-References/dmsdp-audio-codecs-0000001052570753)|音频设备支持的编解码能力，比如PCM，AAC等。|
|reserveds|[DMSDPReserveds](https://developer.huawei.com/consumer/cn/doc/HiCar-References/dmsdp-reserveds-0000001052570505)|保留字参数，后续扩展。比如speaker是否支持音频分流能力。|
