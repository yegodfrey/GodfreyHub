# 前台应用检测

## 场景说明

车机侧HMI应用对HiCar当前的打开应用缺乏实时感知，故通过在HiCar SDK中增加前台应用通知接口，使HMI应用能够实时获取HiCar当前打开应用的包名、类型。目前支持智慧桌面、融合桌面。典型场景如下：

* 融合桌面可以在车机的原生Dock栏里面显示当前HiCar前台应用图标

## Data Type

537

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:-----|:----|:-----|:------------------------------------------------------------------------|
|action|必选|String|"registerForegroundAppChange"：注册监听； "unregisterForegroundAppChange"：解注册监听|
[**表1**注册和解注册前台应用监听]

|参数名称|必选/可选|类型|说明|
|:------|:----|:-----|:--------------|
|appType|必选|int|应用类型，具体应用类型参考下表|
|package|必选|String|应用包名|
[**表2**前台应用信息]

|应用类型|appType|
|:---|:------|
|未知类型|0|
|工具类型|1|
|地图类型|2|
|音频类型|3、4|
|通话类型|5|
|娱乐类型|6|
[**表3**应用类型]

## 接口示例

车机需要监听HiCar前台应用变化时，注册前台应用监听，示例代码如下所示：

```screen
{
    "action":"registerForegroundAppChange"
}
```

HiCar前台应用发生变化时，HiCar会将前台应用传给车机，示例代码如下所示：

```screen
{
    "appPackageList": [
        {
            "appType": 1,
            " packageName ": "....",
        }
    ]
}
```
