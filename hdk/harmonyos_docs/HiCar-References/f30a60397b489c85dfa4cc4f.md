# onDeviceServiceChange

|Function|
|:--------------------------------------------------------------------|
|void onDeviceServiceChange(string serviceId, int state)|
|HiCar SDK设备服务事件回调，当前HiCar SDK的设备服务主要指投屏服务。在该回调方法中携带远端设备虚拟服务标识和事件类型信息。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-----------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|serviceId|string|远端设备虚拟服务标识。|
|state|int|HiCar SDK中定义的设备服务类型如下： * EVENT_DEVICE_SERVICE_PAUSE = 202; //服务暂停 * EVENT_DEVICE_SERVICE_RESUME = 203; //服务恢复 * EVENT_DEVICE_SERVICE_START = 204; //服务启动 * EVENT_DEVICE_SERVICE_STOP = 205; //服务停止 * EVENT_DEVICE_DISPLAY_SERVICE_PLAYING = 207；//开始投屏 * EVENT_DEVICE_DISPLAY_SERVICE_PLAY_FAILED = 208；//投屏失败 * EVENT_DEVICE_SERVICE_VIRMODEM_CALLING = 209；//Modem通话接听中 * EVENT_DEVICE_SERVICE_VIRMODEM_HANG_UP = 210；//Modem通话挂断 * EVENT_DEVICE_SERVICE_VOIP_CALLING = 214；//VoIP通话接听后发送该事件 * EVENT_DEVICE_SERVICE_VOIP_HANG_UP = 215; //VoIP通话挂断后发送该事件|
