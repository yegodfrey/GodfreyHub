# onTransmissionCompletedUpdate

|Method|
|:---------------------------------------------------------------------|
|void onTransmissionCompletedUpdate(int succeedCount, int failedCount);|
|文件传输过程中，当前文件传输数量的统计结果的回调（成功、失败数量），1s一次。|

**Parameters**

|Parameter name|Parameter type|Parameter desc|
|:-------------|:-------------|:-------------|
|succeedCount|int|传输中当前已成功文件的数量。|
|failedCount|int|传输中当前已失败文件的数量。|
