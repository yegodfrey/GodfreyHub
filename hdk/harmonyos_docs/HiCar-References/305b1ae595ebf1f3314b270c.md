# init

|Method|
|:--------------------------------------------------------------------------|
|void init(Context context, CarConfig carConfig, HiCarInitCallback callback)|
|提供HiCar SDK初始化接口。|

**Parameters**

|Parameter name|**Parameter type**|Parameter desc|
|:-------------|:-----------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|context|Context|应用的设备上下文。|
|carConfig|CarConfig|车机配置信息对象，车机配置信息包含车机蓝牙Mac地址，投屏区域大小，屏幕分辨率，屏幕物理尺寸等信息。|
|callback|HiCarInitCallback|HiCar SDK初始化回调函数，定义如下： HiCarInitCallback void onInitSuccess(HiCarAdapter adapter); void onBinderDied(); void onInitFail(int errCode); onInitSuccess接口用于初始化成功，对象实例化完成后触发回调，在回调的参数中返回HiCarAdapter实例化对象。 void onInitFail(int errCode)接口在初始化失败时（超时时间为30s），触发调用此回调函数，errCode为返回的错误码。 onBinderDied接口用于服务发生异常时触发回调，例如服务异常退出，或被其他进程杀死触发该回调。上层应用根据业务场景需要，可以选择重新拉起服务或者清理释放资源(将HiCarAdapter实例化对象清空)。|
