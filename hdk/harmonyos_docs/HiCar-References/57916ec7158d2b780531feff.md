# GetAudioCapability

|Function|
|:----------------------------------------------------------------------------------|
|int32_t (*GetAudioCapability)(DMSDPAudioCapabilities** capabilities, uint32_t *num)|
|查询可用的Audio(Speaker/MIC)属性信息集合，返回规定格式的结构体。|

**Parameters**

|**Parameter name**|**Parameter type**|**Parameter desc**|
|:-----------------|:--------------------------------------------------------------------------------------------------------------------------------|:--------------------|
|** capabilities|[DMSDPAudioCapabilities](https://developer.huawei.com/consumer/cn/doc/HiCar-References/dmsdp-audio-capabilities-0000001051490470)|Audio能力集。|
|*num|uint32_t|能力集的个数，包括Speaker，MIC。|

**Return**

|Type|Desc|
|:------|:---------------------------------------------------------------|
|int32_t|查询本地Audio(Speaker/MIC)属性信息，返回查询到的各个可用Audio(Speaker/MIC)的属性信息的集合。|
