# BusinessControl

|Function|
|:-----------------------------------------------------------------------------------------------------------|
|int32_t (*BusinessControl)(uint32_t cmd, void* inputPara, uint32_t inLen, void* outputPara, uint32_t outLen)|
|函数指针定义，Camera业务控制，预留扩展函数，根据业务需要DvKit可能通过该函数指针下发控制命令到南向Camera，用于业务控制，例如Camera旋转，俯仰等操作，如果没有该类业务，该函数空实现即可。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-----------------|:-----------------------------------|
|cmd|uint32_t|命令字（预留扩展）。 详见DMSDPBusinessControlCmd|
|*inputPara|void|输入参数。|
|inLen|uint32_t|输入参数长度。|
|*outputPara|void|输出参数。|
|outLen|uint32_t|输出参数长度。|

**Return**

|Type|Desc|
|:------|:-------------------|
|int32_t|返回结果： * 0：成功 * 非0：失败|
