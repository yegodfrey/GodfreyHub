# 方控模拟滑动按键

## 场景说明

为优化用户体验，连接HiCar后，用户可以通过方控模拟滑动按键来控制滑动浏览在白名单上的视频应用。

车机在检测到车机物理按键被按下后，需要向HiCar App上报相应的数据。

## Data Type

543

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:-----|:----|:-----|:--------------------------------------------------------------------|
|action|必选|string|* querySupportApps：查询支持的app列表 * moveNext：查看下个视频 * movePrevious：查看上个视频|
[**表1**方控模拟滑动按键]

## 接口示例

车机向HiCar发送白名单应用查询请求示例：

```screen
{
    "action"："querySupportApps"
}
```

按下下滑按钮，执行下滑操作示例：

```screen
{
    "action":"moveNext"
}
```

按下上滑按钮，执行上滑操作示例：

```screen
{
    "action":"movePrevious"
}
```
