# onPinCode

|Function|
|:----------------------------------------------------------|
|void onPinCode(string pinCode)|
|HiCar SDK使用该回调返回给车机应用当前产生的PIN码值。车机与手机首次连接时，需要手机侧输入PIN码进行验证。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-----------------|:-------------|
|pinCode|string|车机生成的PIN码。|
