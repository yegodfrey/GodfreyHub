# updateGop（Beta）

|Method|
|:---------------------------|
|CarConfig updateGop(int gop)|
|更新车机两个I帧之间的间隔帧数。|

**Parameters**

|Parameter name|Parameter type|Parameter desc|
|:-------------|:-------------|:------------------------|
|gop|int|两个I帧之间的间隔帧数，取值范围30 ~ 600。|

**Return**

|Type|Desc|
|:--------|:--------|
|CarConfig|车机配置信息对象。|
