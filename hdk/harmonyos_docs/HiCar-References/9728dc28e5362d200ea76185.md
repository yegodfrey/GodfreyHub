# onDeviceChange

|Function|
|:-------------------------------------------------------------|
|void onDeviceChange(string deviceId, int state, int errorCode)|
|HiCar SDK设备事件回调，主要是手机与车机的连接事件。在事件回调方法中携带远端设备标识和事件类型信息。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|deviceId|string|远端设备标识，上层应用根据该回调结果保存远端设备和设备服务标识，后续接口调用中需要使用这些标识来区分设备或设备服务。上报的设备或设备服务标识仅在当次连接中有效，连接断开后该标识会立即失效。|
|state|int|HiCar SDK中定义的设备事件类型如下： * EVENT_DEVICE_CONNECT = 101;//设备已连接 * EVENT_DEVICE_DISCONNECT = 102;//设备已断连 * EVENT_DEVICE_CONNECT_FAILED= 103;//设备连接失败 * EVENT_DEVICE_PROJECT_CONNECT = 104;//投屏通道已连接 * EVENT_DEVICE_PROJECT_DISCONNECT = 105;//投屏通道断开连接 * EVENT_DEVICE_ADV_START = 106;//开始发现广播通知 * EVENT_DEVICE_ADV_STOP = 107;//停止发现广播通知 * EVENT_DEVICE_MIC_REQUEST = 109;//请求使用车机Mic * EVENT_DEVICE_MIC_RELEASE = 110;//车机Mic释放通知 * EVENT_DEVICE_AUTH_SUCCEED = 113;//鉴权成功通知 * EVENT_DEVICE_START_ADV_TIMEOUT = 124;//广播发送超时|
|errorCode|int|错误码信息，详见[HiCarConst](https://developer.huawei.com/consumer/cn/doc/HiCar-References/hicar-const-0000000000030396)。|
