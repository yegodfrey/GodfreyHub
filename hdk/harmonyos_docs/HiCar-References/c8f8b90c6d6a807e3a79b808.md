# readStreamBufferCustom

|Function|
|:----------------------------------------------------|
|int readStreamBufferCustom(int sessionId, int length)|
|若车机打开录音成功，HiCar SDK通过回调的方式，从车机HMI获取PCM数据。|

**Parameters**

|Parameter name|Parameter type|Parameter desc|
|:-------------|:-------------|:-----------------|
|sessionId|int|当前录音场景的编号ID。|
|length|int|本次读取需要传输的PCM数据的长度。|

**Return**

|Type|Desc|
|:-----|:--------------|
|byte[]|车机HMI要返回的PCM数据。|
