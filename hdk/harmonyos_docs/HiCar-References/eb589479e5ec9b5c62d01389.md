# CarBaseInfo

|Function|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
|void (*CarBaseInfo)(char *info, int32_t len)|
|车机基础数据回传函数，包括ModelId、DeviceId、汽车品牌、汽车型号等。 RegisterGpsDataCallBack时开始以1Hz频率持续上报，当收到BusinessControl GPS_STOP_CALLBACK_BASE_INFO或unRegisterGpsDataCallBack事件时停止上报。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-----------------|:------------------------------------|
|*info|char|基础数据。例如 $RMTINFO,01,02,EXAMPLE,XC5*50|
|len|int32_t|数据长度。|
