# HiCarStartAdv

|Function|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|int32_t HiCarStartAdv()|
|触发HiCar发送广播，HiCar手机可以发现车机。 当点击厂商HMI应用图标，进入应用界面的时候，厂商HMI应用需要调用发送广播接口，广播超时时间为2min，超时时侦听函数的DeviceChange会收到HICAR_DEVICE_ADV_TIMEOUT（111）状态码，HMI应用需要提示用户是退出HiCar，或重新发送广播。|

**Return**

|Type|Desc|
|:------|:--------------------------------------|
|int32_t|触发发送广播执行结果： * 0：触发HiCar发送广播成功 * 非0：触发失败|
