# DMSDPGetAudioHandler

|Function|
|:------------------------------------------------------------|
|int32_t DMSDPGetAudioHandler(DMSDPAudioHandler* audioHandler)|
|获取Audio(Speaker/MIC)功能方法，存放在DMSDPAudioHandler结构体中。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-----------------|:------------------|
|*audioHandler|DMSDPAudioHandler|各种操作Audio设备接口指针的集合。|

**Return**

|Type|Desc|
|:------|:-----------------------|
|int32_t|返回结果： * 0：操作成功 * <0：操作失败|
