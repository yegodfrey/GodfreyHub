# onCustomSavePath

|Method|
|:---------------------------------------------------------|
|String onCustomSavePath(List<String> defaultSavePathList);|
|车机可通过本接口设置自定义存储路径，文件存储动作由SDK内部完成。|

**Parameters**

|Parameter name|Parameter type|Parameter desc|
|:------------------|:-------------|:----------------------------------|
|defaultSavePathList|List<String>|默认的文件存储路径列表，默认存储在HMI应用私有目录，结尾包含文件名。|

**Return**

|Type|Desc|
|:-----|:-----------------------------------------------------------|
|String|HMI应用通过返回值返回给SDK来设置自定义的存储路径。 注：当前所有文件存储路径一致，暂不支持为单个文件配置存储路径。|
