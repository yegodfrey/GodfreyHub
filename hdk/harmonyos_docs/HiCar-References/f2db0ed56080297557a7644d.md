# updateFps（Beta）

|Method|
|:---------------------------|
|CarConfig updateFps(int fps)|
|更新车机每秒传输帧数。|

**Parameters**

|Parameter name|Parameter type|Parameter desc|
|:-------------|:-------------|:------------------|
|fps|int|每秒传输帧数，取值范围20 ~ 60。|

**Return**

|Type|Desc|
|:--------|:--------|
|CarConfig|车机配置信息对象。|
