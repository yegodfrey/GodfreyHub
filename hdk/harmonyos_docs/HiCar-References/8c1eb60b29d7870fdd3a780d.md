# WifiAbilityParam

|Name|Type|Desc|
|:------------------------------|:------------------------------------------------------------------------------------------------|:-----------------------|
|isSupportGO|int|是否支持做GO： * 1：支持 * 0：不支持|
|isSupportGC|int|是否支持做GC： * 1：支持 * 0：不支持|
|isSupportGband|int|是否支持2.4G： * 1：支持 * 0：不支持|
|isSupportAband|int|是否支持5G： * 1：支持 * 0：不支持|
|isSupportRSDB|int|是否支持RSDB： * 1：支持 * 0：不支持|
|currStaFreq|int|当前工作的频率。|
|selfGcMac[STR_MAC_ADDR_LEN + 1]|char|车机作为GC的MAC地址。|
|selfBssid[STR_MAC_ADDR_LEN + 1]|char|车机作为GO时的bssid。|
|channelData|[Channel](https://developer.huawei.com/consumer/cn/doc/HiCar-References/channel-0000001052690857)|支持的信道列表信息。|
|countryCode[COUNTRY_CODE_LEN]|char|国家码。|
