# updateAdvPower（Beta）

|Method|
|:-------------------------------------|
|CarConfig updateAdvPower(int advPower)|
|更新车机广播信号强度。|

**Parameters**

|Parameter name|Parameter type|Parameter desc|
|:-------------|:-------------|:------------------------|
|advPower|int|车机广播信号强度，取值范围 -128 ~ 127。|

**Return**

|Type|Desc|
|:--------|:--------|
|CarConfig|车机配置信息对象。|
