# CloseAudioTrack

|Function|
|:----------------------------------------------------------------------------|
|int32_t (*CloseAudioTrack)(const char* id, uint32_t idLen, int32_t sessionId)|
|释放音频播放设备。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-----------------|:-------------|
|*id|const char|Speaker ID。|
|idLen|uint32_t|Speaker ID长度。|
|sessionId|int32_t|Session ID。|

**Return**

|Type|Desc|
|:------|:-------------------------|
|int32_t|返回结果： * 0：更新成功 * <0：更新配置失败|
