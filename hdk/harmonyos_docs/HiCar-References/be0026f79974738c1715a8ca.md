# getFocusGain

|Method|
|:-----------------|
|int getFocusGain()|
|获取焦点类型。|

**Return**

|Type|Desc|
|:---|:----------------------------------------------------------------------------------------------------|
|int|音频焦点类型，详情见谷歌AudioManager音频焦点参数。 例值： 1：长焦点类型，音乐等场景。 2：短焦点类型，电话、通知、闹铃、QQ、微信等场景。 3：DUCK焦点，导航等场景。 4：独占焦点。|
