# UpdateServiceStatus

|Function|
|:----------------------------------------------------------------------------------------------|
|int32_t (*UpdateServiceStatus)(const char *id, uint32_t idLen, const DMSDPServiceStatus status)|
|车机向HiCar SDK通知虚拟设备服务的状态更新，比如设备使能/去使能，插入/拔出等。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:------------------------------------------------------------------------------------------------------------------------|:-------------------------|
|*id|char|虚拟设备服务的id字符串，比如"speaker1"。|
|idLen|uint32_t|虚拟设备服务的id字符串长度。|
|status|[DMSDPServiceStatus](https://developer.huawei.com/consumer/cn/doc/HiCar-References/dmsdp-service-status-0000001052886930)|上报的状态类型，使能/去使能，插入/拔出等。|

**Return**

|Type|Desc|
|:------|:--------|
|int32_t|上报状态是否成功。|
