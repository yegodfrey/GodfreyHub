# SetAudioParameter

|Function|
|:----------------------------------------------------------------------------------------------------------------------------------|
|int32_t (*SetAudioParameter)(const char* id, uint32_t idLen, int32_t sessionId, uint32_t streamType, const DMSDPProfiles* profiles)|
|设置Speaker音频参数。|

**Parameters**

|**Parameter name**|**Parameter type**|**Parameter desc**|
|:-----------------|:-------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------|
|*id|const char*|Speaker ID。|
|idLen|uint32_t|Speaker ID长度。|
|sessionId|int32_t|Session ID。|
|streamType|uint32_t|音频类型，详见[DMSDPAudioStreamType](https://developer.huawei.com/consumer/cn/doc/HiCar-References/dmsdp-audio-stream-type-0000001052570507)。|
|*profiles|const [DMSDPProfiles](https://developer.huawei.com/consumer/cn/doc/HiCar-References/dmsdp-profiles-0000001052490527)|profiles。|

**Return**

|Type|Desc|
|:------|:---------------------------------------------|
|int32_t|返回结果： * 0：设置Speaker音频参数成功 * <0：设置Speaker音频参数失败|
