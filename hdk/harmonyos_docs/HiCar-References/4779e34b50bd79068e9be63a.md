# 前台娱乐应用检测

## 场景说明

HiCar SDK会将在HiCar场景中正处于前台的娱乐应用，通知到车机侧。车机可以根据该结果，合理处理相关业务逻辑，例如当视频类应用处于前台时，车机侧可以通过调整音频缓存解决音画不同步问题。

## Data Type

533

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:-------|:----|:-----|:--------------------------------------------------------------------------------|
|status|必选|int|应用状态： * 1：appType类型的应用在前台 * 0：appType类型的应用不在前台|
|appType|必选|string|需要检测的应用类型，当前固定为"video"。|
|appName|必选|string|当前处于前台的应用名称，一般为应用包名。 如果当前没有appType类型应用处于前台（status值为0时），该参数为空字符串。|
|RespCode|必选|int|车机接收到HiCar SDK发送的appType类型应用消息后，做出相应处理后返回结果给手机HiCar： * 100000：处理成功 * -100000：处理失败|
[**表1**前台应用检测]

## 接口示例

HiCar SDK通知车机当前appType类型应用处于前台，示例代码如下所示：

```screen
{
    "status":1,
    "appType":"video",
    "appName":"com.huawei.himovie"
}
```

HiCar SDK通知车机当前没有appType类型应用处于前台，示例代码如下所示：

```screen
{
    "status":0,
    "appType":"video",
    "appName":""
}
```

车机处理逻辑成功后向HiCar SDK发送消息，示例代码如下所示：

```screen
{
   " RespCode":100000
}
```
