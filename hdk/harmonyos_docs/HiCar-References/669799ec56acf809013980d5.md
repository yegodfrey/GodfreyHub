# GetAudioCapabilityString

|Function|
|:-----------------------------------------------------|
|const char* (*GetAudioCapabilityString)(uint32_t *len)|
|查询可用的Audio(Speaker/MIC)属性信息集合，返回规定格式的Json字符串。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-----------------|:-----------------------------|
|*len|uint32_t|Audio(Speaker/MIC)能力Json字符串长度。|

**Return**

|Type|Desc|
|:------|:---------------------------------------------------------------|
|int32_t|查询本地Audio(Speaker/MIC)属性信息，返回查询到的各个可用Audio(Speaker/MIC)的属性信息的集合。|
