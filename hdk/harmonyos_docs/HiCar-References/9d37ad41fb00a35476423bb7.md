# updateAudioSourceConfig

|Method|
|:--------------------------------------------------------------------|
|Config updateAudioSourceConfig(Map<String, String> audioSourceConfig)|
|配置AudioSource的配置表。|

**Return**

|Type|Desc|
|:--------|:--------|
|CarConfig|车机配置信息对象。|

**Parameters**

|Parameter name|Parameter type|Parameter desc|
|:----------------|:------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
|audioSourceConfig|Map<String, String>|配置AudioRecord中参数AudioSource。一般默认AudioSource表为： MIC：1 VOICE_COMMUNICATION：7 现在可以配置MIC和VOICE_COMMUNICATION的值，可以设置为用户需要的大小。例如MIC：2 VOICE_COMMUNICATION：6|
