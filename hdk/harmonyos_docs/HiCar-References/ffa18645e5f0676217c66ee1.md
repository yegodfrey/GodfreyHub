# DMSDPAudioType

|Enumerator|Desc|
|:-------------------------------------------------|:--------------------------------|
|AUDIO_USAGE_UNKNOWN = 0|未知属性的音频类型。|
|AUDIO_USAGE_MEDIA = 1|媒体属性的音频类型，比如音乐，电影中的声轨。|
|AUDIO_USAGE_VOICE_COMMUNICATION = 2|通话属性的音频类型，比如运营商电话或者VoIP。|
|AUDIO_USAGE_VOICE_COMMUNICATION_SIGNALLING = 3|通话内的信号音，比如"哔哔"忙音，或者DTMF按键音。|
|AUDIO_USAGE_ALARM = 4|警报属性的音频类型，比如闹钟铃声。|
|AUDIO_USAGE_NOTIFICATION = 5|通知属性的音频类型。|
|AUDIO_USAGE_NOTIFICATION_TELEPHONY_RINGTONE = 6|电话铃声属性的音频类型。|
|AUDIO_USAGE_NOTIFICATION_COMMUNICATION_REQUEST = 7|请求进入或结束某个通话的提示音，比如加入某个VoIP或者视频会议。|
|AUDIO_USAGE_NOTIFICATION_COMMUNICATION_INSTANT = 8|用于即时通话中的通知音，比如短信提示音。|
|AUDIO_USAGE_NOTIFICATION_COMMUNICATION_DELAYED = 9|非立即通知音类型，比如E-Mail来件提示。|
|AUDIO_USAGE_NOTIFICATION_EVENT = 10|提醒注意的通知音类型，比如手机低电提醒。|
|AUDIO_USAGE_ASSISTANCE_ACCESSIBILITY = 11|辅助功能的音频类型，比如屏幕阅读声音。|
|AUDIO_USAGE_ASSISTANCE_NAVIGATION_GUIDANCE = 12|用于导航过程中的播报音。|
|AUDIO_USAGE_ASSISTANCE_SONIFICATION = 13|用户交互的声音。|
|AUDIO_USAGE_GAME = 14|游戏中的声音。|
|AUDIO_USAGE_VIRTUAL_SOURCE = 15|虚拟音源的声音。|
|AUDIO_USAGE_ASSISTANT = 16|响应用户查询的声音，说明性质的声音。|
|AUDIO_USAGE_TTS = 17|语音播报的声音。|
