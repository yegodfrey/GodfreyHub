# 车辆传感器（车速/加速度等）

## 场景说明

当车机和手机建立HiCar连接后，HiCar App会向车机请求获取光线强度、车辆速度、加速度、陀螺仪数据，车机在收到请求数据后，应上报相应数据，并在对应数据后续发生变化后，主动上报变化后的数据。

## Data Type

510

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:---------|:----|:-----|:-----------------------------------------------------------------------------------------|
|service|必选|string|业务类型，当前业务取值为"sensorData"。|
|subService|必选|string|子业务类型，当前业务取值为"transmission"。|
|command|必选|int|命令字： * 0：HiCar App向车机请求传感器数据 * 1：车机向HiCar App上报传感器数据|
|data|必选|object|参数，详见[表2](#ZH-CN_TOPIC_0000001153300362__zh-cn_topic_0000001102640416_table6692136122416)。|
|timestamp|必选|int|时间戳，精确到毫秒。 unix time，例如：1617087892722。|
[**表1**车辆传感器接口]

|参数名称|必选/可选|类型|说明|
|:-----------|:----|:----|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|illumination|必选|int[]|车内外光线强度，格式：[车内,车外]。 单位：lx。 示例：[100,1000]。 约定： * [1,1]：表示请求该数据 * [-1,-1]：表示停止上报该数据|
|speed|必选|int|整型车速值。 单位：km/h 示例：80。 约定： * 1：表示请求该数据 * -1：表示停止上报该数据|
|acc|必选|int[]|加速度三轴x/y/z定义：车辆前进方向为x轴正向，前进左侧为y轴正向，垂直向上为z轴正向。 单位：![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250630214129.67013554502618160500953490720572:50001231000000:2800:2877134A9338A6F1380B0E0803093B3D5677D086938AF37C8B344F6B367128FC.png) 示例：[2.55,0.88,6.23]。 约定： * [1,1,1]：表示请求该数据 * [-1,-1,-1]：表示停止上报该数据|
|gry|必选|int[]|陀螺仪三轴x/y/z定义：车辆前进方向为x轴正向，前进左侧为y轴正向，垂直向上为z轴正向。 单位：rad/s 示例：[1.15,0.01,0]。 约定： * [1,1,1]：表示请求该数据 * [-1,-1,-1]：表示停止上报该数据|
[**表2**data]

车机和手机连接后，车机需主动向HiCar App上报订阅的传感器数据，上报周期约定如下：

* 车速：车速发生变化后更新。为避免消息拥塞，正常行车（车速80km/h以下）更新周期间隔1s以上，高速行车（车速80km/h以上）更新周期间隔500ms以上。
* 光线强度、加速度、陀螺仪：每秒更新。

## 接口示例

HiCar App向车机请求传感器数据，示例如下所示：

```screen
{
    "service": "sensorData", 
    "subService": "transmission", 
    "command": 0, 
    "data": {
        "illumination": [1,1], 
        "speed": 1, 
        "acc": [1,1,1], 
        "gry": [1,1,1]
    }
}
```

车机向HiCar App上报传感器数据，示例如下所示：

```screen
{
    "service": "sensorData", 
    "subService": "transmission", 
    "command": 1, 
    "data": {
        "illumination": [100,1000], 
        "speed": 80, 
        "acc": [1.15,0.01,0], 
        "gry": [1.10,3.15,0.45]
    }, 
    "timestamp": 1617087892722
}
```
