# HiCarSendData

|Function|
|:---------------------------------------------------------------------------------------------|
|int32_t HiCarSendData(HICAR_HANDLE handle, CarDataType dataType, uint8_t* data, uint32_t size)|
|车机向HiCar发送某类数据流，比如车机Logo图片等。|

|**Parameter name**|**Parameter type**|**Parameter desc**|
|:-----------------|:----------------------------------------------------------------------------------------------------------|:------------------------------|
|handle|HICAR_HANDLE|HiCar句柄，通过GetHiCarHandle获取到的句柄。|
|dataType|[CarDataType](https://developer.huawei.com/consumer/cn/doc/HiCar-References/car-data-type-0000001052955157)|数据类型。|
|data|uint8_t|数据的内容。|
|size|uint32_t|数据内容的大小。|

**Return**

|Type|Desc|
|:------|:---------------------------|
|int32_t|返回结果： * 0：发送数据成功 * 非0：发送数据失败|
