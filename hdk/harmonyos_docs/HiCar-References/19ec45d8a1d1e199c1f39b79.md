# HwRemoteCtrlHeader

|Name|Type|Desc|
|:---------------|:-------|:---------------------------------|
|version|uint16_t|版本号。|
|dFlag|uint16_t|事件发送方向，车机发给手机填DIRECTION_FROM_SINK。|
|wFlag|uint16_t|窗口类型，单窗口填0。|
|wr1Flag|uint16_t|预留字段，填0。|
|wr2Flag|uint16_t|预留字段，填0。|
|rFlag|uint16_t|预留字段，填0。|
|inputCategory|uint16_t|输入类型，可填0。|
|len|uint16_t|以8位为单位的整个TCP有效载荷的长度。|
|sessionId|uint8_t|预留字段，填0。|
|reserveData|uint8_t|预留字段，填0。|
|windowsId|uint8_t|预留字段，填0。|
|windowsStat|uint8_t|预留字段，填0。|
|windowsReserved1|uint8_t|预留字段，填0。|
|windowsReserved2|uint8_t|预留字段，填0。|
