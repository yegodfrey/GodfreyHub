# 主动断开车机连接通知

## 场景说明

车机在支持自动连接的情况下，需要正确识别用户主动断开HiCar连接的场景，便于在该场景下不发起自动连接。

用户主动断开HiCar连接时，HiCar App会通知到车机，车机收到通知后需应答。

## Data Type

518

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:---------------|:----|:--|:-------------------------------------------------------|
|isUserDisconnect|可选|int|用户主动断开消息及响应： * 0：用户主动断开连接消息，由HiCar App向车机下发 * 1：车机响应断开消息|
[**表1**主动断开车机连接通知接口]

## 接口示例

HiCar App向车机发送用户主动断开连接的消息：

```screen
{
    "isUserDisconnect":0
}
```

车机向HiCar App回复响应消息：

```screen
{
    "isUserDisconnect":1
}
```
