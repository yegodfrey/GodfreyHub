# CarDisplayCapability

|Name|Type|Desc|
|:-----------|:------|:-------------------------------|
|codecs|int32_t|视频编码格式， * 1：H264（默认缺省值） * 2：H265|
|fps|int32_t|帧率，默认30fps，支持60fps。|
|gop|int32_t|I帧的间距( 两个相邻的I帧，间隔多少帧 )。|
|bitrate|int32_t|Bit率，默认5M，最小1M，最大10M。|
|minBitrate|int32_t|最小视频流码率。|
|maxBitrate|int32_t|最大视频流码率。|
|dpi|int32_t|虚拟设备DPI值。|
|profile|int32_t|视频流层级。|
|level|int32_t|视频流等级。|
|screenWidth|int32_t|车机屏幕物理尺寸宽度。单位毫米。|
|screenHeight|int32_t|车机屏幕物理尺寸高度，单位毫米。|
|width|int32_t|车机投屏区域宽度，单位像素。|
|height|int32_t|车机投屏区域高度，单位像素。|
