# 共享上网

## 场景说明

当车机和手机建立HiCar连接后，车机可以请求使用手机的网络进行共享上网。过程可简要描述为：

1. 车机通过HiCar SDK向HiCar App发送共享上网请求。
2. HiCar App根据用户的共享上网配置进行授权。
3. 如果用户配置不同意，则拒绝车机的共享上网请求，整个流程结束；如果用户配置同意则继续下一步。
4. HiCar App向车机发送共享上网配置信息。
5. 车机接收配置信息后，HiCar App启动共享上网。
6. 结束共享上网分为两种场景：
   1. 车机侧主动结束：车机主动发送停止消息，HiCar App响应。
   2. 用户在手机侧主动结束：HiCar App主动发送停止消息，车机响应。

## Data Type

511

## 接口版本

1.0

## 接口定义

### 共享上网请求消息

|**参数名**|必选/可选|**类型**|**说明**|
|:---------|:----|:-----|:----------------------------------------------------------------------------------------|
|service|必选|string|业务类型，当前业务取值为"net"。|
|subService|必选|string|子业务类型，当前业务取值为"internetShare"。|
|command|必选|int|命令字： * 0：车机向HiCar App发起共享上网请求 * 1：HiCar App向车机发起取消共享上网请求|
|data|必选|object|参数，详见[表2](#ZH-CN_TOPIC_0000001153450248__zh-cn_topic_0000001149080387_table113672431101)。|
[**表1**共享上网请求消息]

|**参数名**|必选/可选|**类型**|**说明**|
|:------|:----|:-----|:-------------------------------------|
|enable|必选|int|使能或者去使能共享上网，取值： * 0：去使能共享上网 * 1：使能共享上网|
[**表2**data]

### 共享上网响应消息

|**参数名**|必选/可选|**类型**|**说明**|
|:---------|:----|:-----|:-----------------------------------------------------------------------------------------------------------------------------------|
|service|必选|string|业务类型，当前业务取值为"net"。|
|subService|必选|string|子业务类型，当前业务取值为"internetShare"。|
|command|必选|int|命令字： * 0：车机向HiCar App发起共享上网请求 * 1：HiCar App向车机发起取消共享上网请求|
|errorCode|必选|int|错误码，详见[错误码表](https://developer.huawei.com/consumer/cn/doc/HiCar-References/errorcode-0000001199330043#ZH-CN_TOPIC_0000001199330043)。|
|data|可选|object|参数，详见[表4](#ZH-CN_TOPIC_0000001153450248__zh-cn_topic_0000001149080387_table1830010355112)。|
[**表3**共享上网响应消息]

|**参数名**|必选/可选|**类型**|**说明**|
|:------|:----|:-----|:--------------------------|
|gateway|可选|string|共享上网的网关地址，如"192.168.1.100"。|
|dns|可选|string|共享上网的地址，如"192.168.1.100"。|
[**表4**data]

## 接口示例

车机向HiCar App，请求共享上网：

```screen
{
    "service":"net",
    "subService":"internetShare",
    "command":0,
    "data":{
        "enable":1
    }
}
```

HiCar App向车机返回请求结果（用户授权同意车机侧共享上网请求）：

```screen
{
    "service":"net",
    "subService":"internetShare",
    "command":0,
    "errorCode":100000,
    "data":{
        "gateway":"192.168.1.100",
        "dns":"192.168.1.100"
    }
}
```

HiCar App向车机返回请求结果（用户未授权车机侧共享上网请求）：

```screen
{
    "service":"net",
    "subService":"internetShare",
    "command":0,
    "errorCode":100002
}
```

车机向HiCar App请求取消共享上网：

```screen
{
    "service":"net",
    "subService":"internetShare",
    "command":0,
    "data":{
        "enable":0
    }
}
```

HiCar App向车机响应取消共享上网：

```screen
{
    "service":"net",
    "subService":"internetShare",
    "command":0,
    "errorCode":100000
}
```

HiCar App向车机通知用户在手机侧主动取消车机的共享上网功能：

```screen
{
    "service":"net",
    "subService":"internetShare",
    "command":1,
    "data":{
        "enable":0
    }
}
```

车机向HiCar App响应手机侧用户主动取消车机共享上网功能：

```screen
{
    "service":"net",
    "subService":"internetShare",
    "command":1,
    "errorCode":100000
}
```
