# Overview

|Return type|Function name|
|:----------|:----------------------------------------------------------------------|
|int32_t|DMSDPGetAudioHandler 获取Audio(Speaker/MIC)功能方法，存放在DMSDPAudioHandler结构体中。|
|int32_t|GetAudioCapability 查询可用的Audio(Speaker/MIC)属性信息集合，返回规定格式的结构体。|
|char*|GetAudioCapabilityString 查询可用的Audio(Speaker/MIC)属性信息集合，返回规定格式的Json字符串。|
|int32_t|SetAudioParameter 设置Speaker音频参数。|
|int32_t|WriteStreamBuffer 播放音频数据。|
|int32_t|CloseAudioTrack 释放某次音频播放。|
|int32_t|OpenAudioRecord 打开MIC设备。|
|int32_t|ReadStreamBuffer 录制音频数据。|
|int32_t|CloseAudioRecord 释放音频录音设备。|
|void|Release 释放指定类型的资源，比如查询能力后的资源释放，类型为RELEASE_TYPE_QUERY_ABILITY。|
|int32_t|RegisterListener 向车机注册音频设备状态变化和设备行为变化的回调。|
|int32_t|BusinessControl 向车机通知音频设备的状态变化。|
|int32_t|RequestAudioFocus 向车机申请焦点。|
|int32_t|AbandonAudioFocus 通知车机释放焦点。|
