# closeAudioRecordCustom

|Function|
|:----------------------------------------|
|int closeAudioRecordCustom(int sessionId)|
|若车机打开录音成功，HiCar SDK通过回调的方式，从车机HMI获取PCM数据。|

**Parameters**

|Parameter name|Parameter type|Parameter desc|
|:-------------|:-------------|:-------------|
|sessionId|int|当前录音场景的编号ID。|

**Return**

|Type|Desc|
|:---|:---------------------------|
|int|关闭录音，释放资源是否成功： 0：关闭成功 1：关闭失败|
