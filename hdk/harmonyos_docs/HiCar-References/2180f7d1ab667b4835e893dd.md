# sendFileShareRequestUris

|Method|
|:-------------------------------------------------------------------------|
|FileShareManager.getInstance().sendFileShareRequestUris(context, uriList);|
|车机端向手机发起文件传输请求。|

**Parameters**

|Parameter name|Parameter type|Parameter desc|
|:-------------|:-------------|:-------------------------|
|context|Context|有权限访问这个 URI 对应的文件的context。|
|uriList|List<String>|准备传输的文件的uri列表。|

**Return**

|Type|Desc|
|:---|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|int|在执行文件传输的业务逻辑之前，SDK会先判断当前文件是否满足发送标准： * 0：满足发送标准，接下来会执行文件传输的业务逻辑。 * 1：不满足。原因是HiCar未连接，车机端应提示用户连接HiCar。 * 2：不满足。原因是手机端不支持文件互传功能，车机端应弹窗提示用户升级手机HiCar应用。 * 3：不满足。原因是勾选或传入了不支持的文件类型，当前只支持图片和视频传输，车机端应提示用户。 * 4：不满足。原因是发送文件个数超过限制（20个）。 * 5：不满足。原因是发送文件总大小超过限制（10G）。 * 6：不满足。原因是文件正在发送过程中。 * 7：不满足。原因是方法入参错误。 * 8：不满足。原因是车机没有注册FileShareListener。|
