# HiCarReconnect

|Function|
|:---------------------------------------------------------------------------|
|int32_t HiCarReconnect(const char *bluetoothMac, uint32_t realLen)|
|触发无感连接。厂商在检测到蓝牙配对，并且上次非用户主动断开的情况下，调用该接口触发车机无感连接，回连之前已经配对过的手机，并最终完成HiCar连接投屏。|

|**Parameter name**|**Parameter type**|**Parameter desc**|
|:-----------------|:-----------------|:----------------------------------|
|bluetoothMac|const char*|手机蓝牙Mac地址字符串。冒号分割，比如AA:BB:CC:DD:EE。|
|realLen|uint32_t|手机蓝牙Mac地址字符串长度。|

**Return**

|Type|Desc|
|:------|:-----------------------------|
|int32_t|无感连接结果： * 0：无感连接成功 * 非0：无感连接失败|
