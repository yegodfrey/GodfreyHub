# DMSDPProfile

|Name|Type|Desc|
|:-----|:-------|:------------------------------|
|*key|char|描述音频具体能力，比如"channel"，"format"等。|
|keyLen|uint32_t|上述音频能力字符串的长度。|
|value|uint32_t|上述音频能力的取值。|
