# 驾驶位置

驾驶位置标识车辆的驾驶位置是在左侧还是在右侧。HiCar App可以根据驾驶位置信息调整UI布局展示，例如将DOCK区域显示在左侧或右侧。

车机上电启动后，需在HiCar SDK初始化时上报驾驶位置。

|键值|类型|说明|
|:---------------|:-----|:------------------------------------------------------|
|DRIVING_POSITION|String|车辆驾驶位置： * left：左舵车，即驾驶位置在左侧（缺省默认值） * right：右舵车，即驾驶位置在右侧|
[**表1**初始化时上报驾驶位置键值对]

HiCar SDK初始化设置示例：

```screen
CarConfig.Builder builder = newCarConfig.Builder();
Map<String, String> config = newHashMap<String, String>();
config.put("DRIVING_POSITION",  "left");  
builder.withInitialConfig(config);
```
