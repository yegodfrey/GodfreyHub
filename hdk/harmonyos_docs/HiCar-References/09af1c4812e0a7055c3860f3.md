# initBtSocket

|Function|
|:---------------------------------------------------------|
|int32_t (*initBtSocket)(RfcommServerInfo serverInfo)|
|根据HiCar SDK给出的RfcommServerInfo创建蓝牙socket，并处理从socket中接收的数据。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-----------------|:--------------------------------|
|serverInfo|RfcommServerInfo|建立蓝牙Rfcomm socket连接时，需要的server参数。|

**Return**

|Type|Desc|
|:---|:-------------------|
|int|返回结果： * 0：成功 * 非0：失败|
