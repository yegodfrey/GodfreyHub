# sendCarData

|Method|
|:-----------------------------------------|
|int sendCarData(int dataType, byte[] data)|

**Parameters**

|Parameter name|Parameter type|Parameter desc|
|:-------------|:-------------|:-------------|
|dataType|int|发送的数据类型。|
|data|byte[]|发送的数据内容。|

|Type|Desc|
|:---|:---------------------------------------------------------------------------------------------------------------------------|
