# HiCarEvent

|Enumerator|Desc|
|:------------------------------------------|:--------------------------------------------|
|HICAR_DEVICE_CONNECTED=101|设备已连接。|
|HICAR_DEVICE_CONNECTING=102|设备正在连接中。|
|HICAR_DEVICE_DISCONNECTED=103|设备已断开连接。|
|HICAR_DEVICE_DISCONNECTING=104|设备正在断开中。|
|HICAR_DEVICE_NO_DATA=105|-|
|HICAR_DEVICE_DETECT_DISCONNECT=106|设备检测到断开，车机应用根据该消息，退回到车机原生界面。|
|HICAR_DEVICE_NET_UNSTABLE_MILD=107|-|
|HICAR_DEVICE_TCP_CONNECTED=108|-|
|HICAR_DEVICE_CONNECT_TIMEOUT_FOR_REPORT=109|-|
|HICAR_DEVICE_MANUAL_DISCONNECT=110|用户在手机侧主动断开连接，车机应用需要记录该动作，在此次上电周期保留，不会再触发无感连接。|
|HICAR_DEVICE_ADV_TIMEOUT=111|广播发送超时通知。当前是2min超时。|
|HICAR_DEVICE_SERVICE_UPDATE=201|服务更新。|
|HICAR_DEVICE_SERVICE_PAUSE=202|服务进入暂停状态，比如HiCar应用暂时退到车机后台。|
|HICAR_DEVICE_SERVICE_RESUME=203|服务进入恢复状态，比如HiCar应用在后台时有来电，需要把HiCar应用从后台拉到前台。|
|HICAR_DEVICE_SERVICE_START=205|服务启动。|
|HICAR_DEVICE_SERVICE_STOP=206|服务停止。|
|HICAR_DEVICE_DISPLAY_SERVICE_PLAYING=207|投屏成功通知。|
|HICAR_DEVICE_OPEN_CAMERA|通知打开Camera事件|
|HICAR_DEVICE_CLOSE_CAMERA|通知关闭Camera事件|
|HICAR_DEVICE_OPEN_SPEAKER|通知打开Speaker事件|
|HICAR_DEVICE_CLOSE_SPEAKER|通知关闭Speaker事件|
|HICAR_DEVICE_OPEN_MIC|通知打开Mic事件|
|HICAR_DEVICE_CLOSE_MIC|通知关闭Mic事件|
|HICAR_DEVICE_VIRMODEM_CALLING=307|运营商电话接通事件。用于设置Mic通话过程回声消除等参数。|
|HICAR_DEVICE_VIRMODEM_HANGUP=308|运营商电话挂断事件。用于通话结束恢复其Mic参数。|
|HICAR_DEVICE_VOIP_CALLING=309|VoIP电话接通事件。用于设置Mic通话过程回声消除等参数。|
|HICAR_DEVICE_VOIP_HANG_UP=310|VoIP电话挂断事件。用于通话结束恢复其Mic参数。|
