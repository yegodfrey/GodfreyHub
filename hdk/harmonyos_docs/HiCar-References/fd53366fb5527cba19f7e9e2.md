# 导航路线元数据

## 场景说明

HiCar会将地图应用导航的路线数据同步给原车，用于原车还原导航路线。

## Data Type

557

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:---------|:----|:-----|:---------------------|
|bundleName|必选|String|当前路线所属的应用包名|
|mapStatus|必选|int|当前地图应用状态，当前固定是导航中状态"1"|
|route|必选|String|导航路线数据|
[**表1**导航路线元数据]

|**参数名**|必选/可选|**类型**|**说明**|
|:-------|:----|:-----|:------------------|
|RespCode|必选|int|响应结果： * 100000：接收成功|
[**表2**NaviRouteDataResp]

## 接口示例

当 HiCar App 收到地图应用传的导航路线数据后，手机侧向车机侧发送导航路线元数据，Data Type 值为 557。示例如下所示：

```screen
{
"bundleName": "xxxxx",
"mapStatus": 1,
"route": "xxxxx"
}
```

车机在收到消息后，向HiCar App发送响应消息，示例如下所示：

```screen
{
    "NaviRouteDataResp" : {
        "RespCode" : 100000
    }
}
```
