# 车机视频流解码能力

## 场景说明

部分车机由于硬件性能原因，在播放视频时可能由于视频流解码阻塞出现视频卡顿现象。为缓解这一问题，HiCar支持车机上报当前视频流解码是否阻塞的信息，动态调整发送到车机侧的视频流帧数量。

## Data Type

535

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:---------|:----|:------|:----------------------------------------------------------------------------------|
|isSupport|必选|boolean|手机侧是否支持动态调整视频流帧数： * true：支持 * false：不支持 手机侧因系统版本因素可能不支持动态调整视频流帧数，该信息HiCar会主动发送到车机侧。|
|isBlocking|必选|boolean|车机解码视频流是否阻塞： * true：阻塞，请求手机侧降低视频流帧数 * false：不阻塞，请求手机侧恢复视频流帧数|
[**表1**车机视频流解码能力接口]

## 接口示例

HiCar App向车机发送是否支持动态调整视频流帧数，示例如下所示：

```screen
{
    "isSupport"：true
}
```

车机根据视频流解码是否阻塞向HiCar App上报数据，示例如下所示：

```screen
{
    "isBlocking":true
}
```
