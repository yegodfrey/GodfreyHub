# DMSDPExtendInfo

|Name|Type|Desc|
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|*key|char|自定义扩展字段关键字。 关键字取值为枚举字符串，当前取值如下： CAMERA_LOCATION: 表示Camera位置信息 CAMERA_DESC：表示Camera自定义描述信息|
|keyLen|uint32_t|扩展字段关键字的长度。|
|*value|char|扩展字段关键字对应的值。 当key值为CAMERA_LOCATION时，位置信息取值为枚举字符串，取值如下： "CAR_FRONT"：车头 "CAR_TAIL"：车尾 "CAR_LEFT"：车左侧 "CAR_RIGHT"：车右侧 "CAR_INSIDE"：车内 "CAR_DRIVER"：驾驶舱 "CAR_CODRIVER"：副驾驶位 "CAR_REARSEAT_LEFT"：后排左侧 "CAR_REARSEAT_RIGHT"：后排右侧 当key值为CAMERA_DESC时，value字段填写自定义描述信息，描述信息建议不超过256字符。|
|valueLen|uint32_t|扩展字段关键字对应值的长度。|
