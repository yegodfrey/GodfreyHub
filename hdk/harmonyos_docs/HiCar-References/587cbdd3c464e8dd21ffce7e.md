# CarConnectAllowType

|Enumerator|Desc|
|:-----------------------------|:------------------------------|
|HICAR_CONNECT_INVALID=0|车机不支持任何连接方式。|
|HICAR_CONNECT_ONLY_ADVERTISE=1|车机只支持BLE广播发现Wi-Fi连接。|
|HICAR_CONNECT_ONLY_USB=2|车机只支持USB有线连接方式。|
|HICAR_CONNECT_ADVERTISE_USB=3|车机既支持BLE广播发现Wi-Fi连接，又支持USB有线连接。|
|HICAR_CONNECT_ONLY_QRCODE=4|车机只支持二维码发现Wi-Fi连接。|
|HICAR_CONNECT_QRCODE_USB=6|车机既支持二维码发现Wi-Fi连接，又支持USB有线连接。|
