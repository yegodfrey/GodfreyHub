# DMSDPAudioStreamType

|Enumerator|Desc|
|:-------------------------------|:----------|
|AUDIO_STREAM_VOICE_CALL = 0|电话呼叫的音频流。|
|AUDIO_STREAM_SYSTEM = 1|系统声音的音频流。|
|AUDIO_STREAM_RING = 2|电话铃声的音频流。|
|AUDIO_STREAM_MUSIC = 3|音乐播放的音频流。|
|AUDIO_STREAM_ALARM = 4|警报的音频流。|
|AUDIO_STREAM_NOTIFICATION = 5|通知的音频流。|
|AUDIO_STREAM_BLUETOOTH_SCO = 6|蓝牙通话语音的音频流。|
|AUDIO_STREAM_SYSTEM_ENFORCED = 7|强制系统声音的音频流。|
|AUDIO_STREAM_DTMF = 8|电话过程中按键音频流。|
|AUDIO_STREAM_TTS = 9|语音播报音频流。|
|AUDIO_STREAM_ACCESSIBILITY = 10|辅助音频流|
