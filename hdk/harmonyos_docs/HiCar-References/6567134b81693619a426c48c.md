# HiCarPostEvent

|Function|
|:------------------------------------------------------------------------------------------------------|
|int32_t HiCarPostEvent(HICAR_HANDLE handle, CarEventType eventType, const char* content, uint32_t size)|
|车机向HiCar发送某类事件，比如触屏事件、按键事件、语音唤醒事件等。|

|**Parameter name**|**Parameter type**|**Parameter desc**|
|:-----------------|:------------------------------------------------------------------------------------------------------------|:------------------------------|
|handle|HICAR_HANDLE|HiCar句柄，通过GetHiCarHandle获取到的句柄。|
|eventType|[CarEventType](https://developer.huawei.com/consumer/cn/doc/HiCar-References/car-event-type-0000001052595144)|事件的类型。|
|content|char|事件的内容，可以是字符串，也可以是事件结构体。|
|size|uint32_t|事件内容的大小，字节数。|

**Return**

|Type|Desc|
|:------|:---------------------------|
|int32_t|返回结果： * 0：发送事件成功 * 非0：发送事件失败|
