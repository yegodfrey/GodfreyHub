# HiCarDeleteObject

|Function|
|:---------------------------------------------------------------------------------------------------------------------------------------------------|
|int32_t HiCarDeleteObject(HICAR_HANDLE handle, CarObjectType objType, void* obj)|
|销毁业务对象，用于业务对象回收和内存释放。如果调用HiCarNewObject后，再调用HiCarPostEvent后，不需要再单独调用HiCarDeleteObject。如果只调用HiCarNewObject，不调用HiCarPostEvent，需要单独调用HiCarDeleteObject。|

|**Parameter name**|**Parameter type**|**Parameter desc**|
|:-----------------|:--------------------------------------------------------------------------------------------------------------|:------------------------------|
|handle|HICAR_HANDLE|HiCar句柄，通过GetHiCarHandle获取到的句柄。|
|objType|[CarObjectType](https://developer.huawei.com/consumer/cn/doc/HiCar-References/car-object-type-0000001051795144)|对象类型。|
|size|uint32_t|对象大小。|

**Return**

|Type|Desc|
|:------|:---------------------------|
|int32_t|返回结果： * 0：释放空间成功 * 非0：释放空间失败|
