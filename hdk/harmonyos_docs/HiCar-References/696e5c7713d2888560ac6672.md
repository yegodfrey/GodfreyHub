# Overview

## Interface Summary

|Interface|Desc|
|:----------------|:-----------------------------------|
|CarListener|HUAWEI HiCar（以下简称HiCar） SDK事件侦听回调接口。|
|HiCarInitCallback|HiCarAdapter实例化回调接口。|

## Class Summary

|Class|Desc|
|:-----------------|:------------------------------------------------------|
|CarConfig|该类定义HiCar相关的配置参数，包含的配置项有modelID，车机蓝牙Mac，车机屏幕的分辨率和物理尺寸等。|
|CarAudioListener|HiCar SDK音频类相关回调侦听接口。|
|HiCarAdapter|该类提供HiCar SDK主要功能性接口，包含SDK初始化，设备发现广播，投屏类接口等。|
|HiSightSurfaceView|该类用于视频界面布局，以控件的形式提供给厂商。|
|TrustPhoneInfo|该类用于返回已认证的设备信息。|
|HiCarConst|该类用于定义HiCar SDK中使用的常量值，包含事件ID和错误码。|
|HardwareInfo|该类用于定义车机硬件信息。|
