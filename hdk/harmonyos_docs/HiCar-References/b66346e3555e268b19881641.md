# DataReceive

|Function|
|:----------------------------------------------------------------------------------------------------|
|void (*DataReceive)(const char *deviceId, uint32_t idLen, int dataType, char *data, uint32_t dataLen)|
|厂商HMI应用通过该接口接收来自HiCar的数据。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-----------------|:------------------------------------------------------------------------------------------------------------------|
|*deviceId|char|手机的设备ID。|
|idLen|uint32_t|ID长度。|
|dataType|int|数据类型，详见[CarDataType](https://developer.huawei.com/consumer/cn/doc/HiCar-References/car-data-type-0000001052955157)。|
|*data|char|数据内容。|
|dataLen|uint32_t|数据长度。|
