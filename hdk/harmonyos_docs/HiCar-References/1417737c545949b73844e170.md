# CarEventType

|Enumerator|Desc|
|:-----------------------------|:------------------------------------------------------------------|
|HICAR_EVENT_REMOTE_CTRL=1|触屏事件。使用HiCarPostEvent发送时，content为HwRemoteCtrlEvent结构体。|
|HICAR_EVENT_VOICE_WAKEUP|语音唤醒事件，使用HiCarPostEvent发送时，content为json格式唤醒字符串。|
|HICAR_EVENT_REQUEST_IDRFRAME|车机主动向手机请求I帧。使用HiCarPostEvent发送时，内容content可置为NULL，size为0。|
|HICAR_EVENT_LOG_SECTION_CHANGE|通知车机日志区可写状态变化。使用HiCarPostEvent发送时，携带的内容是1，表示日志区可写；携带的内容是0，表示日志区不可写。|
