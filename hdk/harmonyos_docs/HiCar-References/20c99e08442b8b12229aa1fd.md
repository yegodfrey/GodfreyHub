# 语音提示音播报

## 场景说明

HiCar与车机间的语音交互方案，如果涉及到重新创建虚拟音频通道，可能会由于时延较大导致语音提示音播报"滴"声丢失或破音播放。为避免该种情况，车机可以选择在车机侧保存"滴"声语音文件，收到HiCar App发送的通知消息后，在本地播放"滴"声语音提示音。
> 说明
>
> 车机播报"滴"的提示音，需预置标准音频文件。

## Data Type

519

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:-------------------|:----|:--|:-------------------------------------------------------------------------------|
|isVoicePromptSupport|可选|int|车机是否支持本地播放语音提示音： * 1：HiCar App向车机询问是否支持本地播放提示音 * 2：车机支持本地播放提示音 * -1：车机不支持本地播放提示音|
|voicePrompt|可选|int|HiCar App向车机下发的语音提示音操作指令： * 0：停止播放提示音 * 1：开始播放提示音|
[**表1**语音提示音播报接口]

## 接口示例

1. HiCar App查询车机是否具备播报"滴"提示音能力。
   1. HiCar App向车机查询是否支持播报提示音，发送的消息：

      ```screen
      {
          "isVoicePromptSupport":1
      }
      ```

   2. 车机向HiCar App返回响应消息：

      ```screen
      {
          "isVoicePromptSupport":2
      }
      ```

2. HiCar App下发指令到车机开始/停止播放"滴"提示音。

   ```screen
   {
       "voicePrompt":1
   }
   ```
