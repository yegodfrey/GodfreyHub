# getSupport5gChannels（Beta）

|Method|
|:----------------------------|
|String getSupport5gChannels()|
|获取车机支持的WiFi 5G信道列表。|

**Return**

|Type|Desc|
|:-----|:------------------------------------------|
|String|车机支持的WiFi 5G信道列表，示例取值[36, 40, 44, 48, 149]。|
