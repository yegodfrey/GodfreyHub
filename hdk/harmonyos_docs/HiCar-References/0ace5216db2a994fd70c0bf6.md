# DMSDPVirtualStreamData

|Name|Type|Desc|
|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------|:-----------------|
|*data|uint8_t|虚拟音频流数据。|
|timeStampUs|int64_t|虚拟音频流每帧的时间戳。|
|usage|uint32_t|虚拟音频流的用途，比如媒体，电话等。|
|*header|[DMSDPVirtualStreamDataHeader](https://developer.huawei.com/consumer/cn/doc/HiCar-References/dmsdp-virtual-stream-data-header-0000001051809204)|虚拟音频流的数据头。|
