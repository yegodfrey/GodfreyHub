# updateDefaultBitrate（Beta）

|Method|
|:-------------------------------------------------|
|CarConfig updateDefaultBitrate(int defaultBitrate)|
|更新车机默认投屏码率。|

**Parameters**

|Parameter name|**Parameter type**|Parameter desc|
|:-------------|:-----------------|:------------------------|
|defaultBitrate|int|默认投屏码率，取值不能小于500*1000bit。|

**Return**

|Type|Desc|
|:--------|:--------|
|CarConfig|车机配置信息对象。|
