# openAudioRecordCustom

|Function|
|:----------------------------------------------------------------------------------------------------------|
|int openAudioRecordCustom(int sessionId, int audioSource, int audioSampleRate, int channelMask, int format)|
|HiCar SDK通过回调的方式，通知车机HMI开始录音，并携带所需的录音规格。|

**Parameters**

|Parameter name|Parameter type|Parameter desc|
|:--------------|:-------------|:--------------------|
|sessionId|int|当前录音场景的编号ID。|
|audioSource|int|本次录音涉及的audioSource信息。|
|audioSampleRate|int|本次录音需使用的采样率。|
|channelMask|int|本次录音需使用的通道数。|
|format|int|本次录音需使用的音频格式。|

**Return**

|Type|Desc|
|:---|:------------------------------------------------------------------------------|
|int|是否成功打开录音： * 0：录音成功，HiCar会回调readStreamBuffer拿PCM数据。 * -1：录音失败，HiCar会自行调用车机mic录音。|
