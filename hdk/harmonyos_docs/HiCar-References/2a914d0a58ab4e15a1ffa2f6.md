# DMSDPGetCameraHandler

|Function|
|:---------------------------------------------------------------|
|int32_t DMSDPGetCameraHandler(DMSDPCameraHandler* cameraHandler)|
|获取Camera设备接口实现的函数集合的方法，存放在DMSDPCameraHandler结构体中。|

**Parameters**

|**Parameter name**|**Parameter type**|Parameter desc|
|:-----------------|:-----------------|:-------------------------------------------------------------------|
|* cameraHandler|DMSDPCameraHandler|外部输入的DMSDPCameraHandler结构体指针，用于保存各个操作Camera设备接口实现函数指针，每个接口指针详见下文的描述。|

**Return**

|Type|Desc|
|:------|:-------------------|
|int32_t|返回结果： * 0：成功 * 非0：失败|
