# DeviceModelId

|Name|Type|Desc|
|:------------------------|:------------|:----------------------------------------------------------|
|modelId[DEV_MODEL_ID_LEN]|unsigned char|设备型号ID，厂商向华为申请的设备信息唯一标识。Nearby协议规定长度3个字节。|
|subModelId|unsigned char|设备子型号ID，用于区分不同外形特征的同款设备。|
|subModelFlag|unsigned char|标识设备是否有Sub-Model ID： * 1：表示有submodel ID * 0：表示没有submodel ID|
