# ReadStreamBuffer

|Function|
|:-----------------------------------------------------------------------------------------------------------|
|int32_t (*ReadStreamBuffer)(const char* id, uint32_t idLen, int32_t sessionId, DMSDPVirtualStreamData* data)|
|录制音频数据。该接口在实现时需要注意线程安全，存在不同线程调用该接口的情况。|

|**Parameter name**|**Parameter type**|**Parameter desc**|
|:-----------------|:---------------------------------------------------------------------------------------------------------------------------------|:-----------------|
|*id|const char|MIC ID。|
|idLen|uint32_t|MIC ID长度。|
|sessionId|int32_t|sessionID。|
|*data|[DMSDPVirtualStreamData](https://developer.huawei.com/consumer/cn/doc/HiCar-References/dmsdp-virtual-stream-data-0000001052609206)|MIC数据。|

**Return**

|Type|Desc|
|:------|:-------------------|
|int32_t|返回结果： * 0：成功 * <0：失败|
