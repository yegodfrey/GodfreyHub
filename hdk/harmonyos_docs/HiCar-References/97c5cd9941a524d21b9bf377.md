# 深浅模式

## 场景说明

当汽车传感器具备深浅模式探测能力时，HiCar App可以基于此能力进行深浅模式的切换。

车机上电启动后，需要调用HiCar SDK提供的接口上报是否支持深浅模式检测及当前所处的模式，后续在模式发生变化时主动向HiCar App上报最新的模式。

## SDK初始化时设置深浅模式

|键值|类型|说明|
|:-------------|:-----|:--------------------------------------------------------------------------------------------------------------------------|
|DAY_NIGHT_MODE|String|车辆是否支持深浅模式检测及当前所处模式： * day：浅色模式 * night：深色模式 * notsupport：不支持深浅模式（缺省默认值） * pending：无法确定当前所处模式，但是可能后续动态上报深浅模式信息给HiCar，使用该字符串|
[**表1**初始化时上报深浅模式键值对]

HiCar SDK初始化设置示例：

```screen
CarConfig.Builder builder = newCarConfig.Builder();
Map<String, String> config = newHashMap<String, String>();
config.put("DAY_NIGHT_MODE",  "day");  
builder.withInitialConfig(config);
```

车机在深浅模式发生变化时需要主动向HiCar App上报当前所处的模式。

## Data Type

501

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:-----------|:----|:-----|:----------------------------|
|dayNightMode|必选|string|深浅模式： * day：浅色模式 * night：深色模式|
[**表2**深浅模式接口]

## 接口示例

车机向HiCar App上报深浅模式示例：

```screen
浅色模式：
{
    "dayNightMode":"day"
}
深色模式：
{
    "dayNightMode":"night"
}
```
