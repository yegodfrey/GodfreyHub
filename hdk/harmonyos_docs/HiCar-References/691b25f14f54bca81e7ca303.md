# 品牌名称

车机上电初始化时通过HiCar SDK接口设置汽车品牌信息。

|参数|说明|
|:-----------------------------------|:----------|
|CarConfig.CarDeviceInfo.carBrand[64]|汽车品牌名称。|
|CarConfig.CarDeviceInfo.carBrandLen|汽车品牌名称实际长度。|
[**表1**初始化时设置品牌名称]

HiCar SDK初始化设置示例：

```screen
CarConfig config;
......
/* 汽车品牌信息 */
memset_s((void*)&(config.deviceInfo.carBrand[0]), CAR_BRAND_MAX_LEN, 0, CAR_BRAND_MAX_LEN);
memcpy_s((void*)&(config.deviceInfo.carBrand[0]), CAR_BRAND_MAX_LEN, "HICAR", strlen("HICAR"));
config.deviceInfo.carBrandLen = strlen("HICAR");
......
int retCode = HiCarInit(&config);
```
