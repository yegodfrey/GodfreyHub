# 场景说明

HiCar App需要车机上报汽车品牌文字信息和汽车品牌Logo图标，用于：

* 在连接过程中的发现弹窗中展示汽车品牌。
* 在投屏成功后，在应用图标区域显示汽车品牌Logo图标及品牌文字，可供用户点击后从HiCar投屏界面切换到车机原始系统界面。

HiCar连接认证成功，手机HiCar界面投屏到车机屏幕上进行显示，通过HiCar界面Home页的应用列表区域的汽车品牌icon图标点击后可以返回到车机屏幕，此汽车品牌icon图标需要车机传递给HiCar。车机在和手机HiCar完成连接认证后收到手机HiCar侧请求时传递给手机HiCar，手机HiCar获取到icon图标后进行显示，如车机未传递此icon图标则采用HiCar默认的图标。
