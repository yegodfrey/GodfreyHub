# HiCarStopAdv

|Function|
|:------------------------------------------------------|
|int32_t HiCarStopAdv()|
|停止HiCar发送广播。当在发广播的时候，用户点击HOME物理键返回车机原生界面，此时需要调用该接口停止广播。|

**Return**

|Type|Desc|
|:------|:--------------------------------------|
|int32_t|停止发送广播执行结果： * 0：停止HiCar发送广播成功 * 非0：停止失败|
