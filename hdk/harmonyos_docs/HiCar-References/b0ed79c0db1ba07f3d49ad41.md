# 获取说明

目前HUAWEI HiCar向开发者提供应用接入和设备接入的API参考，其中：

* 应用接入的API参考，仅向合作中的开发者开放，处于合作中的开发者可参考[获取文档](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/get-docs-app-0000001150423322)申请相关权限。待访问权限配置生效后重新登录本页面，切换到左侧相应菜单即可查看相关API参考。
* 设备接入的API参考，开发者可在左侧目录中直接查看。
