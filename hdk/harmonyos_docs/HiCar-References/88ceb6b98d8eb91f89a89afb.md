# 场景元数据

## 场景说明

车机连接HiCar，车机向HiCar请求场景元数据，HiCar会根据车机的请求情况，在有场景元数据产生时，向车机发送具体场景元数据信息。场景元数据包括：

* 日历元数据
* 天气元数据
* 情景智能元数据

> 说明
>
> 使用场景元数据之前，需要先请求相关元数据，详见[元数据能力](https://developer.huawei.com/consumer/cn/doc/HiCar-References/app-metadata-capability-0000001383093924#ZH-CN_TOPIC_0000001383093924)。

## Data Type

530

## 接口版本

1.0

## 接口定义

|参数名称|必选/可选|类型|说明|
|:-------------|:----|:-----|:---------------------------------------------------------------------------------------------|
|ScenceData|必选|object|场景元数据数据，详见[表2](#ZH-CN_TOPIC_0000002012196541__zh-cn_topic_0000001557539137_table126461732397)。|
|ScenceDataResp|必选|object|响应数据，详见[表4](#ZH-CN_TOPIC_0000002012196541__zh-cn_topic_0000001557539137_table1943683611395)。|

|参数名称|必选/可选|类型|说明|

|Id|必选|int|元数据的唯一标识。|
|Title|必选|string|应用显示的名称。|
|AppIcon|可选|byte[]|应用的图标。|
|AppPackage|必选|string|应用的包名。|
|InfoImage|可选|byte[]|信息图片。|
|MainText|必选|string|主信息文本。|
|SubText|必选|string|辅助信息文本。|
|OptText|可选|string|可选文本。|
|OptImage|可选|byte[]|可选图片，天气元数据可能涉及，比如定位图标。|
|Button1|可选|object|当前元数据支持的响应按钮1，IoT元数据涉及，可用于显示控制开关。详见[表3](#ZH-CN_TOPIC_0000002012196541__zh-cn_topic_0000001557539137_table102366973216)。|
|Button2|可选|object|当前元数据支持的响应按钮2，当前不涉及。详见[表3](#ZH-CN_TOPIC_0000002012196541__zh-cn_topic_0000001557539137_table102366973216)。|
|Button3|可选|object|当前元数据支持的响应按钮3，当前不涉及。详见[表3](#ZH-CN_TOPIC_0000002012196541__zh-cn_topic_0000001557539137_table102366973216)。|
[**表2**ScenceData]

|**参数名**|必选/可选|**类型**|**说明**|

[**表3**ButtonX]

|参数名称|必选/可选|类型|说明|
|:--------|:----|:------|:--------------------------------------------------------------|

|Type|可选/必选|int|场景类元数据的类型： * 1：日历 * 2：天气 * 3：情景智能 发送用户点击事件时，该字段为必选。|
|Button1|可选/必选|boolean|用户点击开关按钮置为true，未点击置为false。 发送按钮点击事件时，该字段为必选。|

## 接口示例

### 日历元数据

HiCar 有日历元数据后，手机侧向车机侧发送日历元数据，Data Type 值为 530。其中 ScenceData 中的 Type 为 1，表示日历元数据。示例如下所示：

```screen
{
    "ScenceData" : {
        "Type" : 1,
        "Status" : 0,
        "Id" : 1234,
        "Title" : "日历",
        "AppIcon" : [],
        "AppPackage" : "com.huawei.calendar",
        "InfoImage" : [],
        "MainText" : "测试",
        "SubText" : "全天",
        "OptText" : "8月24日周三"
    }
}
```

车机向HiCar App发送响应消息，示例如下所示：

```screen
{
    "ScenceDataResp": {
        "RespCode" : 100000,
        "Id" : 1234,
        "Type" : 1,
        "CardClick" : true
    }
}
```

### 天气元数据

HiCar 有天气元数据后，手机侧向车机侧发送天气元数据，Data Type 值为 530。其中 ScenceData 中的 Type 为 2，表示天气元数据。示例如下所示：

```screen
{
    "ScenceData" : {
        "Type" : 2,
        "Status" : 0,
        "Id" : 7867,
        "AppName" : "天气 HUAWEI HiCar",
        "AppIcon" : [],
        "AppPackage" : "com.huawei.hicar",
        "InfoImage" : [],
        "MainText" : "30℃",
        "SubText" : "空气优质\n33℃/26℃",
        "OptText" : "江夏区"，
        "OptImage" : [],
    }
}
```

车机向HiCar App发送响应消息，示例如下所示：

```screen
{
    "ScenceDataResp": {
        "RespCode" : 100000,
        "Id" : 7867,
        "Type" : 2,
        "CardClick" : true
    }
}
```
