# HiCarDeleteTrustDevice

|Function|
|:---------------------------------------------------------------------|
|int32_t HiCarDeleteTrustDevice(const uint8_t *phoneId, uint32_t idLen)|
|删除指定可信设备，删除后需要重新建立鉴权认证。|

|**Parameter name**|**Parameter type**|**Parameter desc**|
|:-----------------|:-----------------|:-----------------|
|phoneId|uint8_t*|手机唯一标识。|
|idLen|uint32_t|ID长度，不能大于128。|

**Return**

|Type|Desc|
|:------|:-----------------------|
|int32_t|返回结果： * <0：删除失败 * 0：删除成功|
