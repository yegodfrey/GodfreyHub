|public SpaceRenderRotationParams(float x, float y, float z, int surroundTime, int surroundDirection) 3D动态渲染模式参数默认构造函数。 左手坐标系，伸出左手，让拇指和食指成"L"形，大拇指向右，食指向上。其余的手指指向前方，这样就建立了一个左手坐标系。其中，拇指、食指和其余手指分别代表x，y，z轴的正方向。|

|z|空间Z坐标，取值范围：\[-5.0, 5.0\]，单位：米。|
|surroundTime|单周环绕时间，取值范围：\[2, 40\]，单位：秒。|
|surroundDirection|单周环绕方向，取值范围：\[0, 1\]。|
