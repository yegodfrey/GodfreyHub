#### [h2]PRO_PHOTO_MODE

Field  
---  
public static final int PRO_PHOTO_MODE 专业拍照模式。 特别提醒：
                1. android.control.aeTargetFpsRange 除了支持设置设备上报的能力值外还支持12-60固定帧率的设置，例如[12,12]、[13,13]专业相机模式下，支持最大可设置的帧率为30固定帧率场景下，可使用[RequestKey.HW_PRO_SENSOR_EXPOSURE_TIME_VALUE](https://developer.huawei.com/consumer/cn/doc/Media-References/requestkey-0000001053433784#ZH-CN_TOPIC_0000001053433784__HW_PRO_SENSOR_EXPOSURE_TIME_VALUE)调节快门速度快门速度设置低于(1/FPS)的情况下不会影响帧率，高于1/FPS的情况下会改变帧率为(1/exposureTime)。
                2. 广角暂不支持设置30以上fps。  
  
#### [h2]PRO_VIDEO_MODE

Field  
---  
public static final int PRO_VIDEO_MODE 专业录像模式。 特别提醒：
                1. android.control.aeTargetFpsRange 除了支持设置设备上报的能力值外还支持12-60固定帧率的设置，例如[12,12]、[13,13]专业录像模式下，支持最大可设置的帧率为60(视设备能力而定，部分设备专业录像最大仅支持到30帧)。
                2. 广角暂不支持设置30以上fps。
