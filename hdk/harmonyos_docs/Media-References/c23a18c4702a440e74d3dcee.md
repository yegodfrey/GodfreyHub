# HwAudioEffectManager

|Class Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public final class HwAudioEffectManager 音效管理类，例如：创建音效、设置音效生效，获取音效等。 > 说明 > 音效开启时： > * rtttl和imy格式的在线歌曲不支持播放。 > * amr格式的本地歌曲不支持播放。 > * flac格式的本地歌曲，若大小超过60MB不支持播放。|

### setEqSuperChannelBalance

|Method|
|:-----------------------------------------------------|
|public int setEqSuperChannelBalance(int param) 设置声道平衡。|

**Parameters**

|Name|Description|
|:----|:--------------------------------------------------------------------|
|param|偏移常数，取值范围：[-5, 5]内的的整数。 * 负数时声音偏左，右声道减小，左声道不变。 * 正数时声音偏右，左声道减小，右声道不变。|

**Return** **s**

|Type|Description|
|:---|:-----------------------------|
|int|声道平衡设置是否成功。 * 0：设置成功 * -1：设置失败|
