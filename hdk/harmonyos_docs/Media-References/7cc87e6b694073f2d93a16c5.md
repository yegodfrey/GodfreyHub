# Overview

该包提供了华为图像服务中图片处理接口，开发者集成该SDK后，可以调用华为图像服务提供的对应能力，包括：图像颜色滤镜、贴纸花字、图文智能排版、图像主题标签、图片裁剪。

## Interface summary

|Interface|Description|
|:---------------------------------------------------------------------------------------------------------------------------------------------|:-------------|
|[ImageVisionInterface](https://developer.huawei.com/consumer/cn/doc/development/Media-References/vision-imagevisioninterface-0000001050439417)|提供了图像处理功能的接口。|
|[ImageVision.VisionCallBack](https://developer.huawei.com/consumer/cn/doc/development/Media-References/vision-vision--0000001050995901)|初始化图像处理服务回调接口。|

## Class summary

|Class|Description|
|:----------------------------------------------------------------------------------------------------------------------------|:--------------|
|[ImageVision](https://developer.huawei.com/consumer/cn/doc/development/Media-References/vision-imagevision-0000001050199211)|获取图像处理功能基本接口对象。|
|[ImageVisionImpl](https://developer.huawei.com/consumer/cn/doc/development/Media-References/imagevisionimpl-0000001050197188)|图像处理功能接口实现类。|
