## Public Methods

### getSupportedHdrType

|Method|
|:--------------------------------------------------------|
|public static String getSupportedHdrType() 获取设备支持HDR类型列表。|

**Return** **s**

|Type|Description|
|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------|
|String|系统硬件支持的Hdr类型列表，如：HdrVivid、Hdr10、Hlg、Hdr10+、DolbyVision，可多选。以','作为不同Hdr类型之间的分割符号，如系统硬件支持HdrVivid、Hdr10两种Hdr类型，返回"Hdrvivid,Hdr10"。 返回null或空字符串，表示系统硬件不支持Hdr。|

### setHdrAbility

|Method|
|:-----------------------------------------------------------------|
|public static boolean setHdrAbility(boolean status) 打开或关闭设备的HDR能力。|

**Parameters**

|Name|Description|
|:-----|:------------------------------------|
|status|打开或关闭设备的HDR能力。 * true：打开。 * false：关闭。|

**Returns**

|Type|Description|
|:------|:---------------------------|
|boolean|设置结果。 * true：成功。 * false：失败。|

> 说明
>
> * 打开设备HDR能力，将提高屏幕的最大亮度值。

### setCaptionsLayer

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------|
|public static boolean setCaptionsLayer(SurfaceView surfaceView, double ratio) 设置字幕/弹幕图层高亮显示能力。需要调用了[setHdrLayer](#section352420410114)接口设置视频图层高亮，该接口才能生效。|

**Parameters**

|Name|Description|
|:----------|:----------------------------------------|
|surfaceView|SurfaceView实例，该SurfaceView实例应该显示字幕或弹幕。|
|ratio|设置该字幕或弹幕图层的亮度相对于UI图层亮度的倍数。必须大于1.0，建议值：1.5|

**Returns**

|Type|Description|
|:------|:---------------------------|
|boolean|设置结果。 * true：成功。 * false：失败。|

### setBrightness

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public static int setBrightness(int brightnessAlt) 设置显示设备的峰值亮度。在HDR Vivid SDK渲染转码接口处理HDR Vivid视频，进行色调映射和颜色空间转换过程中使用。 * 如果输出是Surface模式，且屏幕不支持HDR时，使用该值。 * 如果输出是Buffer模式，且输出Buffer的颜色空间为BT.709，使用该值。|

**Parameters**

|Name|Description|
|:------------|:-----------------------|
|brightnessAlt|显示设备的峰值亮度，范围[203~10000]。|

**Returns**

|Type|Description|
|:---|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|int|设置成功，返回[HDR_ABILITY_SUCCESS](#ZH-CN_TOPIC_0000001274843210__p13033117192)，否则返回相应的错误码。 错误码取值范围： * [HDR_ABILITY_ERROR_ILLEGAL_ARGUMENT](#ZH-CN_TOPIC_0000001274843210__p87091658111919)：函数参数是无效的。|
