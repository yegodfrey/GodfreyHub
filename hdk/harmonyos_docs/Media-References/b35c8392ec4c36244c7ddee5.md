# CameraKit  
  
Class Info  
---  
CameraKit功能入口类。 一般而言，完整的工作流分为下面几步： [必选步骤] 通过[getInstance(Context)](https://developer.huawei.com/consumer/cn/doc/Media-References/camerakit-0000001053113781#ZH-CN_TOPIC_0000001053113781__getInstance-android.content.Context-)获取CameraKit实例对象，此过程包含兼容性检查，正确返回表示CameraKit可用。 [可选步骤] 通过[registerCameraDeviceCallback(CameraDeviceCallback, Handler)](https://developer.huawei.com/consumer/cn/doc/Media-References/camerakit-0000001053113781#ZH-CN_TOPIC_0000001053113781__registerCameraDeviceCallback-com.huawei.camera.camerakit.CameraDeviceCallback-android.os.Handler-)及 [unregisterCameraDeviceCallback(CameraDeviceCallback)](https://developer.huawei.com/consumer/cn/doc/Media-References/camerakit-0000001053113781#ZH-CN_TOPIC_0000001053113781__unregisterCameraDeviceCallback-com.huawei.camera.camerakit.CameraDeviceCallback-)进行相机设备状态回调的设置，此步骤可选。 [可选步骤] 通过[getCameraIdList()](https://developer.huawei.com/consumer/cn/doc/Media-References/camerakit-0000001053113781#ZH-CN_TOPIC_0000001053113781__getCameraIdList--)获取支持的逻辑相机列表， 这里还可以通过[getCameraInfo(String)](https://developer.huawei.com/consumer/cn/doc/Media-References/camerakit-0000001053113781#ZH-CN_TOPIC_0000001053113781__getCameraInfo-java.lang.String-)获取更多相机设备相关的信息，比如朝向等，此步骤可选。 [可选步骤] 通过[getSupportedModes(String)](https://developer.huawei.com/consumer/cn/doc/Media-References/camerakit-0000001053113781#ZH-CN_TOPIC_0000001053113781__getSupportedModes-java.lang.String-)获取当前相机支持的模式，模式类型定义在[Mode.Type](https://developer.huawei.com/consumer/cn/doc/Media-References/mode_type-0000001052713807)，此步骤可选。 [可选步骤] 通过[getModeCharacteristics(String, int)](https://developer.huawei.com/consumer/cn/doc/Media-References/camerakit-0000001053113781#ZH-CN_TOPIC_0000001053113781__getModeCharacteristics-java.lang.String-int-)获取模式相关的静态能力， 并通过具体能力查询接口查询支持与否和支持范围，如[ModeCharacteristics.getSupportedZoom()](https://developer.huawei.com/consumer/cn/doc/Media-References/modecharacteristics-0000001052515103#ZH-CN_TOPIC_0000001052515103__getSupportedZoom--)获取支持变焦等。 [可选步骤]通过[createMode(String, int, ModeStateCallback, Handler)](https://developer.huawei.com/consumer/cn/doc/Media-References/camerakit-0000001053113781#ZH-CN_TOPIC_0000001053113781__createMode-java.lang.String-int-com.huawei.camera.camerakit.ModeStateCallback-android.os.Handler-)创建指定类型的模式或 通过[changeMode(Mode, int, ModeStateCallback)](https://developer.huawei.com/consumer/cn/doc/Media-References/camerakit-0000001053113781#ZH-CN_TOPIC_0000001053113781__changeMode-com.huawei.camera.camerakit.Mode-int-com.huawei.camera.camerakit.ModeStateCallback-)从当前模式切换至指定类型的模式。 **Since:** 2019-02-26

#### [h2]changeMode

Method  
---  
public void changeMode(@NonNull [Mode](https://developer.huawei.com/consumer/cn/doc/Media-References/mode-0000001053273774) curMode, int modeType, @NonNull [ModeStateCallback](https://developer.huawei.com/consumer/cn/doc/Media-References/modestatecallback-0000001052955040) callback) 切换模式。 切换模式，保持摄像头不变，对于切换模式，此方法相比createMode可获得更高的性能。 建议在当前模式的激活态下直接切换模式，如果当前模式未激活或是当前模式资源已经被释放，相比用createMode可获得的性能收益将会减少。 模式成功创建后，会回调[ModeStateCallback.onCreated(Mode)](https://developer.huawei.com/consumer/cn/doc/Media-References/modestatecallback-0000001052955040#ZH-CN_TOPIC_0000001052955040__onCreated-com.huawei.camera.camerakit.Mode-)。 入参为空会引发空指针异常，不支持的模式或入参无效会引发非法参数异常。  
  
**Parameters:**

Parameter Name | Parameter Description  
---|---  
curMode | 有效的模式对象，此参数不能为空。 有效的模式指的是模式对象的生命周期内没有发生设备异常，也就是说没有收到[ModeStateCallback.onFatalError(Mode, int)](https://developer.huawei.com/consumer/cn/doc/Media-References/modestatecallback-0000001052955040#ZH-CN_TOPIC_0000001052955040__onFatalError-com.huawei.camera.camerakit.Mode-int-)通知。 如果模式成功创建，但是运行过程中摄像头被其他高优先级的应用占用，这种状态下的模式也被认为是无效的模式。 调用release释放后的模式对象，也认为是有效的模式对象。  
modeType | 模式类型，可以通过[getSupportedModes(String)](https://developer.huawei.com/consumer/cn/doc/Media-References/camerakit-0000001053113781#ZH-CN_TOPIC_0000001053113781__getSupportedModes-java.lang.String-)获取。  
callback | 负责模式创建和模式运行时的通知，空入参将会引发空指针异常。  
  
#### [h2]registerCameraDeviceCallback

Method  
---  
public void registerCameraDeviceCallback(@NonNull [CameraDeviceCallback](https://developer.huawei.com/consumer/cn/doc/Media-References/cameradevicecallback-0000001052833785) callback, android.os.Handler handler) 注册相机设备状态回调。 此方法允许多次调用，重复传入相同的callback会被忽略，只有第一次传入有效。 此方法可监控摄像头和闪光灯状态。  
  
**Parameters:**

Parameter Name | Parameter Description  
---|---  
callback | 处理设备状态的回调。  
handler | 用于设备使用状态变化回调的操作
                * 如果参数为空，则回调在调用线程中发生；如果参数不为空，则回调在handler中发生。
                * 如果传入的handler不为空，则应该保证在整个CameraKit的生命周期内有效，如果外部提前释放handler，可能会引起异常。  
  
**Throws:**

Throw Name | Throw Description  
---|---  
java.lang.NullPointerException | 当入参为空时抛出该异常。
