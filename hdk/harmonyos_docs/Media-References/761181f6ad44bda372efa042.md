# WisePlayer.LoadingListener

|Interface Info|
|:---------------------------------------------------|
|public interface LoadingListener 定义播放器缓冲相关事件的监听器的接口。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|void|[onLoadingUpdate](#section139823011526)([WisePlayer](https://developer.huawei.com/consumer/cn/doc/development/Media-References/wiseplayer-0000001050316766) wp, int percent) 当前播放正在缓冲中的回调方法。|
|void|[onStartPlaying](#section8929191815)([WisePlayer](https://developer.huawei.com/consumer/cn/doc/development/Media-References/wiseplayer-0000001050316766) wp) 媒体资源开始播放的回调方法，播放器通过该监听器回调通知业务App的场景包括： * 媒体内容首次开始播放。 * 在播放中由于网络质量变差、seek、切换码率时产生缓冲Buffering，在缓冲结束后重新播放。|

### onLoadingUpdate

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void onLoadingUpdate([WisePlayer](https://developer.huawei.com/consumer/cn/doc/development/Media-References/wiseplayer-0000001050316766) wp, int percent) 当前播放正在缓冲中的回调方法。|

**Parameters**

|Name|Description|
|:------|:--------------------------------|
