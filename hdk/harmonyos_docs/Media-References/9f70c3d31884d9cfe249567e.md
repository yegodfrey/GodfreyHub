# MediaBuffer

|Class Info|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class MediaBuffer 用来描述媒体流的数据buffer，在[ByteBuffer](https://developer.android.google.cn/reference/java/nio/ByteBuffer?hl=en)和[MediaMeta](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediameta-0000001157012727)的基础之上，封装了更多的媒体信息。|
