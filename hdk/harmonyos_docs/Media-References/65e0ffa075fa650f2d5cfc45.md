# ActionStateCallback  
  
Class Info  
---  
模式动作执行过程中，执行状态结果的回调处理；如启动预览后状态变化、拍照结束状态、手动对焦结束、人脸检测结果返回等。 作为[ModeConfig.Builder.setStateCallback(com.huawei.camera.camerakit.ActionStateCallback, android.os.Handler)](https://developer.huawei.com/consumer/cn/doc/Media-References/modeconfig_builder-0000001052595081#ZH-CN_TOPIC_0000001052595081__setStateCallback-com.huawei.camera.camerakit.ActionStateCallback-android.os.Handler-)的入参，用于响应后续模式产生的状态结果。 一般的工作流程参见[Mode.startPreview()](https://developer.huawei.com/consumer/cn/doc/Media-References/mode-0000001053273774#ZH-CN_TOPIC_0000001053273774__startPreview--) [Mode.takePicture()](https://developer.huawei.com/consumer/cn/doc/Media-References/mode-0000001053273774#ZH-CN_TOPIC_0000001053273774__takePicture--) 等。 **Since:** 2019-06-25
