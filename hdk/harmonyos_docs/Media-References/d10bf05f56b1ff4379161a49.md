# HAEAudioProperty

|Class Info|
|:--------------------------------------------------|
|public class HAEAudioProperty 导出音频的属性（编码格式、采样率、声道）。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-----------------------------------------------------------------|
|void|[setChannels](#section36231417192810)(int channels) 设置音频声道数。|
|void|[setEncodeFormat](#section13680738155)(int encodeFormat) 设置音频编码格式。|
|void|[setSampleRate](#section131961350142812)(int sampleRate) 设置音频采样率。|

## Public Methods

### setChannels

|Method|
|:---------------------------------------------|
|public void setChannels(int channels) 设置音频声道数。|

**Parameters**

|Name|Description|
|:-------|:--------------------|
|channels|声道数。当前仅支持双声道，设置值只能为2。|

### setEncodeFormat

|Method|
|:------------------------------------------------------|
|public void setEncodeFormat(int encodeFormat) 设置音频编码格式。|

**Parameters**

|Name|Description|
|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------|
|encodeFormat|编码格式。具体常量请参见[Constants](https://developer.huawei.com/consumer/cn/doc/development/Media-References/audioeditor_constants-0000001237718101)。|

### setSampleRate

|Method|
|:-------------------------------------------------|
|public void setSampleRate(int sampleRate) 设置音频采样率。|

**Parameters**

|Name|Description|
|:---------|:-------------------------|
|sampleRate|采样率。当前仅支持：44100HZ、48000HZ。|
