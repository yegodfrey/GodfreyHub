# HdrVividColorFormat

|Enum Info|
|:--------------------------------------------|
|HdrVividColorFormat 渲染实例工作在转码模式下支持的颜色格式的枚举类型。|

## Enum Value Summary

|Enum Value and Description|
|:-----------------------------------------------|
|COLORFORMAT_R8G8B8A8 RGBA格式，每个向量用8比特存储，取值为1。|
|COLORFORMAT_NV12 NV12格式，每个向量用8比特存储，取值为2。|
|COLORFORMAT_YUV420_888 YUV420格式，每个向量用8比特存储，取值为3。|
|COLORFORMAT_YUV420P10 YUV420格式，每个向量10比特存储，取值为4。|
