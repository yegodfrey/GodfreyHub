#### [h2]getSupportedZoom

Method  
---  
public float[] getSupportedZoom() 获取当前模式支持的变焦范围。 开发者应该在执行变焦操作[Mode.setZoom(float)](https://developer.huawei.com/consumer/cn/doc/Media-References/mode-0000001053273774#ZH-CN_TOPIC_0000001053273774__setZoom-float-)之前应该检查当前模式是否支持变焦操作。 如果支持变焦，则返回值为支持的变焦的区间，数组长度固定为2，对应闭区间的[minZoom, maxZoom]； 如果当前相机或模式不能变焦时，将会得到[1.0f，1.0f]的结果。 设置的变焦值允许为区间中的任意浮点数，变焦值越大，图像放大倍率越高，反之则越低。 当存在广角时，变焦值可以小于1，此时会自动切换到广角镜头；当存在长焦时，变焦值查过某个临界值（不同镜头的临界值不同，常见的有3.0f，5.0f等）， 此时会自动切换到长焦镜头。  
  
**Returns:**

Type | Description  
---|---  
float[] | 支持的变焦范围。  
  
**See Also:**

[Mode.setZoom(float)](https://developer.huawei.com/consumer/cn/doc/Media-References/mode-0000001053273774#ZH-CN_TOPIC_0000001053273774__setZoom-float-)
