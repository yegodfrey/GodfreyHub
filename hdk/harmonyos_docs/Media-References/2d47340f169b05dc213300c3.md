# RequestKey  
  
Class Info  
---  
定义模式中允许设置的参数。 一般而言，完整的工作流分为下面几步： 通过[ModeCharacteristics.getSupportedParameters()](https://developer.huawei.com/consumer/cn/doc/Media-References/modecharacteristics-0000001052515103#ZH-CN_TOPIC_0000001052515103__getSupportedParameters--) 获取当前模式支持的所有的可设置的参数，这个方法返回的参数列表中的值都会定义在[RequestKey](https://developer.huawei.com/consumer/cn/doc/Media-References/requestkey-0000001053433784)。 开发者也可以通过[ModeCharacteristics.getParameterRange(CaptureRequest.Key)](https://developer.huawei.com/consumer/cn/doc/Media-References/modecharacteristics-0000001052515103#ZH-CN_TOPIC_0000001052515103__getParameterRange-android.hardware.camera2.CaptureRequest.Key-)传入指定的参数来查询当前参数支持的取值范围，如果返回值是长度为0的列表，说明这个参数在当前模式下不支持。比如想要查询滤镜是否支持ModeCharacteristics.getParameterRange(RequestKey.HW_FILTER_EFFECT)。 如果参数定义的类型是布尔型，比如[HW_MIRROR](https://developer.huawei.com/consumer/cn/doc/Media-References/requestkey-0000001053433784#ZH-CN_TOPIC_0000001053433784__HW_MIRROR), 通过上述Range查询的结果只会是元素为True，长度为1的列表。推荐采用[ModeCharacteristics.getSupportedParameters()](https://developer.huawei.com/consumer/cn/doc/Media-References/modecharacteristics-0000001052515103#ZH-CN_TOPIC_0000001052515103__getSupportedParameters--)查询参数的设置只能通过通过[Mode.setParameter(CaptureRequest.Key, Object)](https://developer.huawei.com/consumer/cn/doc/Media-References/mode-0000001053273774#ZH-CN_TOPIC_0000001053273774__setParameter-android.hardware.camera2.CaptureRequest.Key-T-)或是 [Mode.setParameters(Map)](https://developer.huawei.com/consumer/cn/doc/Media-References/mode-0000001053273774#ZH-CN_TOPIC_0000001053273774__setParameters-java.util.Map-)，需要注意参数可设置的值范围。详细方法可参考[Mode](https://developer.huawei.com/consumer/cn/doc/Media-References/mode-0000001053273774)。 **Since:** 2019-06-28
