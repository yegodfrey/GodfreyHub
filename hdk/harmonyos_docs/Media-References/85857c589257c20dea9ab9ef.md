# 错误码

|错误码|值|描述|解决方法|
|:--------------------|:-|:------|:-----------------|
|RUNTIME_SYSTEM_ERROR|-1|其他错误|请检查错误日志并进行相应处理|
|INVALID_INPUT_ERROR|-2|参数输入错误|请检查输入参数是否正确|
|KIT_STATUS_ERROR|-3|Kit状态错误|请检查Kit是否安装以及是否最新版本|
|NOT_FULL_SCREEN_ERROR|-4|非全屏异常|请检查当前界面是否处于全屏状态|

若您的问题仍无法解决，请通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题，华为支持人员会及时处理。
