# 错误码

|错误码|值|描述|解决办法|
|:-----------------------|:----------|:--------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------|
|OK|0|成功。|-|
|ASYNC_OK|-1000|异步操作成功。|-|
|ERROR_NO_MEM|-12|内存不足，对象创建或者资源申请失败。|请查看系统内存是否已满。|
|ERROR_PERMISSION_DENIED|-13|权限被拒绝。|请检查是否授予相关权限。|
|ERROR_NO_INIT|-19|未初始化的错误，表示某个模块未进行初始化就直接操作，或者未遵守正确的调用流程。|请分析Android Logcat是否有未初始化的模块。|
|ERROR_BAD_VALUE|-22|错误的值。|请确认入参的取值。|
|ERROR_INVALID_OPERATION|-38|无效的操作，表示当前状态不允许此操作。|请检查接口调用顺序。|
|ERROR_TIMED_OUT|-110|超时。|请检查是否有阻塞调用。|
|ERROR_UNKNOWN|-2147483648|未知的错误。|请分析Android Logcat的报错模块和具体报错信息。|
|ERROR_INVALID_PARAM|-2147483646|无效的参数。|请检查入参的取值是否有效。|
|ERROR_NOT_INITED|-2147483645|未初始化。|请检查是否有未初始化的类。|
|ERROR_UNSUPPORTED|-2147483644|不支持某种能力或者操作。|请分析Android Logcat的报错模块和具体报错信息。|
|ERROR_NO_SUCH_FILE|-2147483643|文件不存在，表示本地媒体流文件或者XML配置文件不存在。|请检查您配置的文件路径。|
|ERROR_RESOURCE_LIMIT|-2147483641|资源受限。|请检查剩余内存是否充足。|
|ERROR_INVALID_STATE|-2147483640|无效的状态，表示App没有进行相邻状态的切换，或者向不存在的状态切换。|请检查插件的接口调用顺序。|
|ERROR_OP_FAILED|-2147483637|操作失败。|请分析Android Logcat报错模块和具体报错信息。|
|ERROR_IO|-2147483636|读写文件失败。|请检查读写文件操作是否合法。|
|ERROR_NO_MEDIA_TYPE|-2147483631|无效的媒体类型，表示非音视频类型，导致错误。|请检查指定媒体类型的参数取值。支持的媒体类型请参见[MediaType](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediatype-0000001110521292)。|
|ERROR_NO_MEDIA_TRACK|-2147483630|不存在媒体track，表示媒体文件或者媒体流异常导致错误。|请检查媒体文件中是否包含选择的媒体类型。|
|ERROR_NO_AUDIODECODER|-2147483623|音频解码器不存在，调用音频硬件解码器或者软件解码器失败。|可[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)，华为支持人员会及时处理。|
|ERROR_NO_VIDEODECODER|-2147483622|视频解码器不存在，调用视频硬件解码器或者软件解码器失败|可[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)，华为支持人员会及时处理。|
|ERROR_NOT_SUPPORTED_FILE|-2147483616|表示该文件的格式不支持。|请检查媒体文件的格式。|

若您的问题仍无法解决，请通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题，华为支持人员会及时处理。
