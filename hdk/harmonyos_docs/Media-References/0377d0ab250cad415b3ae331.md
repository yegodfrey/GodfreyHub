# Overview  
  
包含华为影像能力开放接口，通过提供一套全新的高级编程API，支持三方实现大光圈、人像、HDR、视频HDR、视频人物虚化、超级夜景等特性。

#### Class Summary

Class | Description  
---|---  
[ActionDataCallback](https://developer.huawei.com/consumer/cn/doc/Media-References/actiondatacallback-0000001053113779) | 模式动作执行过程中，产生数据结果（如拍照图像数据、深度数据等）的回调处理。  
[ActionStateCallback](https://developer.huawei.com/consumer/cn/doc/Media-References/actionstatecallback-0000001053753754) | 模式动作执行过程中，执行状态结果的回调处理；如启动预览后状态变化、拍照结束状态、手动对焦结束、人脸检测结果返回等。
