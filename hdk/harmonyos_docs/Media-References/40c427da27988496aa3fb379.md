# HVEKeyFrameAbility

|Interface Info|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public interface HVEKeyFrameAbility 关键帧能力接口，具备关键帧能力的资源和特效都会实现此接口，包括资源[HVEAudioAsset](https://developer.huawei.com/consumer/cn/doc/Media-References/hveaudioasset-0000001156050672)、[HVEImageAsset](https://developer.huawei.com/consumer/cn/doc/Media-References/hveimageasset-0000001156929212)、[HVEStickerAsset](https://developer.huawei.com/consumer/cn/doc/Media-References/hvestickerasset-0000001202689207)、[HVEVideoAsset](https://developer.huawei.com/consumer/cn/doc/Media-References/hvevdeoasset-0000001155730670)、[HVEWordAsset](https://developer.huawei.com/consumer/cn/doc/Media-References/hvewordasset-0000001201930665)以及[HVEEffect](https://developer.huawei.com/consumer/cn/doc/Media-References/hveeffect-0000001156929220)（色彩调节，滤镜调节以及蒙版三种特效支持关键帧能力，其中内嵌特效（如蒙版等）的关键帧跟随所属资源的关键帧能力，外联特效实现了[HVEKeyFrameAbility](https://developer.huawei.com/consumer/cn/doc/Media-References/hveeeyframeability-0000001245615369)接口）。|
