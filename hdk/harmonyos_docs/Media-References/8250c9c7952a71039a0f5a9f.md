# Metadata.SceneDetectionType  
  
Annotation Info  
---  
场景识别返回结果。 请注意，在不同设备，版本上有差异可识别的场景有差异，部分场景可能不进行识别。 **Since:** API版本 VersionInfo.API_LEVEL_1以上 **See Also:** [Mode.setSceneDetection(boolean)](https://developer.huawei.com/consumer/cn/doc/Media-References/mode-0000001053273774#ZH-CN_TOPIC_0000001053273774__setSceneDetection-boolean-), [ActionStateCallback.onSceneDetection(Mode, int, ActionStateCallback.SceneDetectionResult)](https://developer.huawei.com/consumer/cn/doc/Media-References/actionstatecallback-0000001053753754#ZH-CN_TOPIC_0000001053753754__onSceneDetection-com.huawei.camera.camerakit.Mode-int-com.huawei.camera.camerakit.ActionStateCallback.SceneDetectionResult-)
