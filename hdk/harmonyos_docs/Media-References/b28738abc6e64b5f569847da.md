# WisePlayer.EventListener

|Interface Info|
|:------------------------------------------------|
|public interface EventListener 定义播放器播放事件上报监听器的接口。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|boolean|[onEvent](#section139823011526)([WisePlayer](https://developer.huawei.com/consumer/cn/doc/development/Media-References/wiseplayer-0000001050316766) wp, int what, int extra, Object obj) 播放器播放信息上报的回调方法。|

## Public Methods

### onEvent

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public boolean onEvent([WisePlayer](https://developer.huawei.com/consumer/cn/doc/development/Media-References/wiseplayer-0000001050316766) wp, int what, int extra, Object obj) 播放器媒体以及播放事件上报的回调方法。|

**Parameters**

|Name|Description|
|:----|:--------------------------------------------------------------------------------------------------------------------------------|
|wp|播放器实例。|
|what|事件类型，播放器事件主码，定义请参见[事件码](https://developer.huawei.com/consumer/cn/doc/development/Media-References/info-code-0000001050199191)。|
|extra|事件附带的扩展参数，播放器事件子码，用于细化该事件的具体类型，默认值是0。 当前对应功能暂未开放。|
|obj|事件附带的对象，默认为null，定义请参见[事件码](https://developer.huawei.com/consumer/cn/doc/development/Media-References/info-code-0000001050199191)。|

**Return** **s**

|Type|Description|
|:------|:------------------------------------------------------------------------------|
|boolean|[onEvent](#section139823011526)处理返回结果。 * true：App已经处理了事件。 * false：消息没有被处理，将被丢弃。|
