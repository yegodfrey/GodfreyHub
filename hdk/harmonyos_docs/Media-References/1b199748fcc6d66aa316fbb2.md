# WisePlayerFactory

|Class Info|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public abstract class WisePlayerFactory [WisePlayer](https://developer.huawei.com/consumer/cn/doc/development/Media-References/wiseplayer-0000001050316766)播放器工厂类。|

[WisePlayer](https://developer.huawei.com/consumer/cn/doc/development/Media-References/wiseplayer-0000001050316766)播放器工厂类，您可以在完成工厂类初始化后，通过工厂类实例创建一个[WisePlayer](https://developer.huawei.com/consumer/cn/doc/development/Media-References/wiseplayer-0000001050316766)播放器实例。

**Java Sample code:**

```screen
// WisePlayer播放器工厂
private WisePlayerFactory factory = null;

// 初始化WisePlayer播放器工厂
private void initFactory(){
    WisePlayerFactoryOptionsExt.Builder factoryOptions = new WisePlayerFactoryOptionsExt.Builder().setDeviceId("xxx");
    // 设置日志配置信息
    LogConfigInfo logCfgInfo = new LogConfigInfo(1, "", 20, 1024);
    factoryOptions.setLogConfigInfo(logCfgInfo);
    WisePlayerFactory.initFactory(context, factoryOptions.build(), new InitFactoryCallback() {
        @Override
        public void onSuccess(WisePlayerFactory wisePlayerFactory) {
            // 初始化成功
            factory = wisePlayerFactory;
        }
        
        @Override
        public void onFailure(int errorCode, String message) {
            // 初始化失败，记录失败日志
            log.e("init player factory fail reason :" + message + ", errorCode is " + errorCode);
       }
    });
}

// 使用WisePlayer工厂创建播放器实例
private WisePlayer getPlayer() {
    if (null != factory) {
        try {
            return factory.createWisePlayer();
        } catch (CreateComponentException e) {
            Log.w("create wisePlayer error:" + e.getMessage());
        }
    }
    return null;
}
```
