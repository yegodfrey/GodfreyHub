## Public Constructors

### NodeBase

|Constructor|
|:-----------------------------------------------------------------------------------------------|
|NodeBase(const char *mime = nullptr, bool isProcThreadCreated = true, bool isAsync = true) 构造函数。|

**Parameters**

|Name|Description|
|:------------------|:-----------------------------------------------------------------------------------|
|mime|指定节点的mime类型，默认为空。|
|isProcThreadCreated|是否需要创建处理buffer的线程，默认true。 当Node有比较耗时的操作时，在不影响外部响应的前提下，设置该入参为true，创建一个额外的线程用于处理耗时的操作。|
|isAsync|指定节点工作在同步还是异步状态。 * true：异步状态，默认。 * false：同步状态。|
