# BufferFlag

|Enum Info|
|:-----------------|
|MediaBuffer的标志位枚举。|

## Enum Value Summary

|Enum Value and Description|Value|
|:---------------------------------------|:----|
|BF_EOS 表示该buffer是媒体流中最后一个buffer。|1|
|BF_KeyFrame 表示该buffer是关键帧。|2|
|BF_CodecData 表示该buffer是codec specific数据。|4|
|BF_AVPacket 表示该buffer是AVPacket。|8|
|BF_AVFrame 表示该buffer是AVFrame。|16|
