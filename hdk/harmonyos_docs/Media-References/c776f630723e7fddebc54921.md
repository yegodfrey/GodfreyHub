# 错误码

|错误码|描述|解决方法|
|:-----|:----------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1001|系统内部错误（System inner error）。|系统内部异常，建议尝试重试调用接口。|
|1011|超过日最大允许访问次数 （The request has reached the day max limit）。|请参见[服务限额](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/service-quota-0000001269258736)。|
|1012|超过月最大允许访问次数（The request has reached the month max limit）。|请参见[服务限额](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/service-quota-0000001269258736)。|
|1013|超过月最大允许字符数（The request has reached the month max char limit）。|请参见[服务限额](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/service-quota-0000001269258736)。|
|1015|超过并行任务数（The request has reached the max concurrent limit）。|请参见[服务限额](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/service-quota-0000001269258736)。|
|2002|参数错误（Parameter error）。|请检查并填入符合要求的Request参数。|
|2003|调用第三方接口失败（Invoke third service method fail）。|可[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)，华为支持人员会及时处理。|
|2004|数据库异常（DB error）。|可[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)，华为支持人员会及时处理。|
|2037|歌曲总时长过长（input time is too long)。|歌曲总时长过长，请删除部分内容。|
|2038|歌曲内容不能有且仅有一个"<rest>"作为内容（input can't be only contain one 'rest'）。|内容只有"<rest>"，请补充歌词。|
|2039|文本内容风控校验没有通过（wiseguard rejected）。|请检查文本内容是否含有敏感词汇。|
|2040|解析MusicXML失败（parse XML failed）。|请检查MusicXML内容，例如格式或是否已删除"<!DOCTYPE score-partwise PUBLIC "-//Recordare//DTD MusicXML 3.1 Partwise//EN" "http://www.musicxml.org/dtds/partwise.dtd">"字段等。|
|2041|歌词长度过长（lyric is too long）。|歌词总数超出限制，请删除部分内容。|
|2043|无效的伴奏ID（accompaniment id is invalid）|请参见[歌声合成预置曲目说明](https://developer.huawei.com/consumer/cn/doc/development/Media-References/rest_api_public_description-0000001317085953#section457618201567)。|
|2044|歌词无效（lyrics are invalid）|歌词为空或超出最大长度。|
|2045|歌词与模板不匹配（lyrics do not match the template）|歌词与模板歌词样式不匹配，请参见[歌声合成预置曲目说明](https://developer.huawei.com/consumer/cn/doc/development/Media-References/rest_api_public_description-0000001317085953#section457618201567)。|
|2050|输入音高不符合音色指定音高（input pitch is invalid）|MusicXML输入音高不符合音色指定音高。请参见[3.1-歌声合成发音人说明](https://developer.huawei.com/consumer/cn/doc/development/Media-References/rest_api_public_description-0000001317085953#section653112589229)。|
|2052|无效的模板类型（The accompaniment does not have the corresponding templateType）|请参见[歌声合成预置曲目说明](https://developer.huawei.com/consumer/cn/doc/development/Media-References/rest_api_public_description-0000001317085953#section457618201567)，选择对应的发音人。|
|80005|文本错误，请输入英文（text error, please enter english）。|请检查需要转换的文本。当language参数为英文时，text中不可包含中文字符。|
|001001|鉴权失败（The request have no permission）。|请确认凭据具有正确的API调用权限，具体请参见[客户端模式（Client Credentials）](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-oauth-0000001053629189#section12493191334711)。|

若上述方式无法解决，可[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)，华为支持人员会及时处理。
