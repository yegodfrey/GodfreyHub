# 错误码

## ResultCode

|错误码|值|描述|解决方法|
|:----------------------|:-----|:----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|SUCCESS|0|调用成功。|-|
|ERROR_PARAMS|230001|参数错误。|请检查输入参数是否正确。|
|ERROR_STATUS|230002|状态错误。|1. 请检查SDK是否正确初始化。 2. 请检查各接口的调用顺序是否正确。|
|ERROR_IMAGE|230003|图片解析失败。|1. 请检查图片是否超出[限制条件](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/introduction-0000001050042264#section1625014101085)。 2. 若图片不带XMP信息，请检查是否设置了图片类型。|
|ERROR_IO|230004|加载图片文件失败。|1. 请检查图片文件是否存在。 2. 请检查应用是否有访问图片的权限。|
|ERROR_UNINIT|230005|未初始化。|请调用初始化接口。|
|ERROR_REMOTE|230006|远程调用错误。|内部错误，请反馈到[Stack Overflow](https://stackoverflow.com/questions/tagged/huawei-mobile-services?tab=Newest)论坛。|
|ERROR_TIMEOUT|230007|调用超时。|内部错误，请尝试重启HMS Core。|
|ERROR_HMS_NOT_AVAILABLE|230008|HMS Core（APK）不可用。|请接入网络下载新版本HMS Core。|
|ERROR_HMS_IS_UPDATING|230009|HMS Core（APK）升级中|请等待HMS Core升级完成|
|ERROR_HMS_UPDATE_FAILED|230010|HMS Core（APK）升级失败|请接入网络下载新版本HMS Core。|
|ERROR_METHOD_NOT_FOUND|230011|未找到需要调用的方法|请检查调用的方法名是否正确|
|ERROR_METHOD_INVOKE|230012|反射调用方法异常|请检查HMS Core（APK）安装是否正常。|

## HMS Core Error Code

|错误码|值|描述|解决方法|
|:--|:---|:----------------------|:---------------------------------------------------------------------------------------------------------------|
|-|1200|HMS Core正在升级中，内部服务未准备好。|请在HMS Core升级完成后再尝试。|
|-|1201|内部服务未准备好。|HMS Core错误，请反馈到[Stack Overflow](https://stackoverflow.com/questions/tagged/huawei-mobile-services?tab=Newest)论坛。|
|-|1212|全景服务需要升级。|请升级全景服务。|

若您的问题仍无法解决，请选择[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题，华为支持人员会及时处理。
