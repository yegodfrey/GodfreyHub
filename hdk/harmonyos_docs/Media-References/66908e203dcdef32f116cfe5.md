#### 歌声合成填词规则说明

* 输入歌词不超过120字。
* 输入歌词建议为中文和阿拉伯数字，若输入其他形式字符，只会计入字符数统计，在合成过程中会被忽略。
* isAutoFill设置为false，未开启智能填词：输入歌词的每句字数大于等于推荐歌词样式的对应句字数时，多余字数会被自动截去。
* isAutoFill设置为true，开启智能填词：
  1. 输入歌词字数不强制匹配预置曲目推荐歌词样式，但不得为空。
  2. 若输入歌词句数与推荐歌词样式句数不匹配，则多余句子会被舍去，不足的句子使用输入歌词循环填充。
  3. 当每句的字数与推荐歌词样式中对应句不匹配时，支持推荐歌词字数对应句的一半及以上字数；若不足推荐歌词字数对应句的一半，则推荐歌词字数对应句的一半中缺少的字数使用"啦"来填充，超出最大歌词样式对应句字数部分会被舍去。
  4. 输入歌词中阿拉伯数字会按0\~9转化为汉字。例："51劳动节"转化为"五一劳动节"，而不会转化为"五十一劳动节"。
