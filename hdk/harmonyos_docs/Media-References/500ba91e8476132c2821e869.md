# Overview

包含音频播放管理的基础API。

## Interface Summary

|Interface|Description|
|:----------------------------------------------------------------------------------------------------------------------------------------|:-----------------------|
|[HwAudioManager](https://developer.huawei.com/consumer/cn/doc/development/Media-References/hwaudiomanager-0000001050299058)|获取音频播放管理、配置管理、队列管理接口。|
|[HwAudioStatusListener](https://developer.huawei.com/consumer/cn/doc/development/Media-References/hwaudiostatuslistener-0000001050191645)|播放状态监听接口，用于音频状态发生变更后的回调。|
|[INotificationFactory](https://developer.huawei.com/consumer/cn/doc/development/Media-References/inotificationfactory-0000001175782607)|通知工厂，用于创建通知栏的音频播放控件。|

## Class Summary

|Class|Description|
|:----------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------|
|[HwAudioConfigManager](https://developer.huawei.com/consumer/cn/doc/development/Media-References/hwaudioconfigmanager-0000001050191649)|音频配置管理，例如：设置缓存大小、清除缓存、保存播放列表等。|
|[HwAudioEffectManager](https://developer.huawei.com/consumer/cn/doc/development/Media-References/hwaudioeffectmanager-0000001142597807)|音效管理类，例如：创建音效、设置音效生效，获取音效等。|
|[HwAudioManagerFactory](https://developer.huawei.com/consumer/cn/doc/development/Media-References/hwaudiomanagerfactory-0000001050431727)|对[HwAudioManager](https://developer.huawei.com/consumer/cn/doc/development/Media-References/hwaudiomanager-0000001050299058)实施初始化的工具。|
|[HwAudioPlayerConfig](https://developer.huawei.com/consumer/cn/doc/development/Media-References/hwaudioplayerconfig-0000001050299072)|创建[HwAudioManager](https://developer.huawei.com/consumer/cn/doc/development/Media-References/hwaudiomanager-0000001050299058)所需的配置。|
|[HwAudioPlayerManager](https://developer.huawei.com/consumer/cn/doc/development/Media-References/hwaudioplayermanager-0000001050189514)|音频播放管理，例如：播放、暂停、上一首、下一首、停止播放、进度条等。|
|[HwAudioQueueManager](https://developer.huawei.com/consumer/cn/doc/development/Media-References/hwaudioqueuemanager-0000001050431731)|音频队列管理，例如：删除列表中指定位置的音频等。|
