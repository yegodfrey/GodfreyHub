# Mode  
  
Class Info  
---  
模式操作类。 特定的拍摄场景对应特定的模式，模式对象仅能通过如下方法获取： 使用[CameraKit.createMode(String, int, ModeStateCallback, Handler)](https://developer.huawei.com/consumer/cn/doc/Media-References/camerakit-0000001053113781#ZH-CN_TOPIC_0000001053113781__createMode-java.lang.String-int-com.huawei.camera.camerakit.ModeStateCallback-android.os.Handler-)创建模式对象,并通过 [ModeStateCallback](https://developer.huawei.com/consumer/cn/doc/Media-References/modestatecallback-0000001052955040) 进行模式状态的回调。 使用[CameraKit.changeMode(Mode, int, ModeStateCallback)](https://developer.huawei.com/consumer/cn/doc/Media-References/camerakit-0000001053113781#ZH-CN_TOPIC_0000001053113781__changeMode-com.huawei.camera.camerakit.Mode-int-com.huawei.camera.camerakit.ModeStateCallback-)切换模式对象，并通过 [ModeStateCallback](https://developer.huawei.com/consumer/cn/doc/Media-References/modestatecallback-0000001052955040) 进行模式状态的回调模式的操作流程建议为：
                * 创建模式：调用[CameraKit.createMode(String, int, ModeStateCallback, Handler)](https://developer.huawei.com/consumer/cn/doc/Media-References/camerakit-0000001053113781#ZH-CN_TOPIC_0000001053113781__createMode-java.lang.String-int-com.huawei.camera.camerakit.ModeStateCallback-android.os.Handler-)。并通过 [ModeStateCallback.onCreated(com.huawei.camera.camerakit.Mode)](https://developer.huawei.com/consumer/cn/doc/Media-References/modestatecallback-0000001052955040#ZH-CN_TOPIC_0000001052955040__onCreated-com.huawei.camera.camerakit.Mode-)获取创建的模式。创建失败会有[ModeStateCallback.onCreateFailed(java.lang.String, int, int)](https://developer.huawei.com/consumer/cn/doc/Media-References/modestatecallback-0000001052955040#ZH-CN_TOPIC_0000001052955040__onCreateFailed-java.lang.String-int-int-)回调。
                * 配置模式：模式创建后，调用[configure()](https://developer.huawei.com/consumer/cn/doc/Media-References/mode-0000001053273774#ZH-CN_TOPIC_0000001053273774__configure--)来配置，ModeConfig的创建详见 [ModeConfig.Builder](https://developer.huawei.com/consumer/cn/doc/Media-References/modeconfig_builder-0000001052595081)。模式配置成功后会有[ModeStateCallback.onConfigured(Mode)](https://developer.huawei.com/consumer/cn/doc/Media-References/modestatecallback-0000001052955040#ZH-CN_TOPIC_0000001052955040__onConfigured-com.huawei.camera.camerakit.Mode-)回调, 如果配置失败，会有[ModeStateCallback.onConfigureFailed(Mode, int)](https://developer.huawei.com/consumer/cn/doc/Media-References/modestatecallback-0000001052955040#ZH-CN_TOPIC_0000001052955040__onConfigureFailed-com.huawei.camera.camerakit.Mode-int-)回调。
                * 启动预览：配置完成后模式就进入可操作状态，可以调用[startPreview()](https://developer.huawei.com/consumer/cn/doc/Media-References/mode-0000001053273774#ZH-CN_TOPIC_0000001053273774__startPreview--)启动预览，也可以 调用[setFocus(int, Rect)](https://developer.huawei.com/consumer/cn/doc/Media-References/mode-0000001053273774#ZH-CN_TOPIC_0000001053273774__setFocus-int-android.graphics.Rect-)设置对焦模式和对焦区域，或其他参数配置，比如设置美颜 或调用[setParameter(CaptureRequest.Key, Object)](https://developer.huawei.com/consumer/cn/doc/Media-References/mode-0000001053273774#ZH-CN_TOPIC_0000001053273774__setParameter-android.hardware.camera2.CaptureRequest.Key-T-)设置其他参数。
                * 释放模式：调用[release()](https://developer.huawei.com/consumer/cn/doc/Media-References/mode-0000001053273774#ZH-CN_TOPIC_0000001053273774__release--)来关闭模式和释放资源。
模式使用的简单代码示例如下：
    
    // 创建全局的动作状态回调
         final ActionStateCallback stateCallback = new ActionStateCallback() {
             public void onPreview(Mode mode, @PreviewResult.State int state, @Nullable PreviewResult result) {
             }
             public void onTakePicture(Mode mode,@PreviewResult.State int state, @Nullable TakePictureResult result) {
             }
         };
         // 创建全局的动作数据回调
         final ActionDataCallback dataCallback = new ActionDataCallback() {
             public void onImageAvailable(Mode mode, int id, Image image) {
             }
         };
         // 创建全局的模式状态回调
         ModeStateCallback callback = new ModeStateCallback() {
             public void onCreated(Mode mode) {
                 // 模式创建成功并配置模式
                 ModeConfig.Builder builder = mode.getModeConfigBuilder();
                 builder.setStateCallback(stateCallback, handler)
                 builder.setDataCallback(dataCallback, handler)
                 builder.addPreviewSurface(surface);
                 mode.configure();
             }
             public void onConfigured(Mode mode) {
                 // 模式配置成功，可以操作模式
                 mode.startPreview();
             }
         };
         // 开始创建模式
         CameraKit.getInstance(context).createMode(id, Mode.Type.BOKEH_MODE, callback, handler);

#### [h2]configure

Method  
---  
public void configure() 配置模式参数。 当一个新的模式成功创建后，首先需要对模式进行配置，在configure前需要调用[getModeConfigBuilder()](https://developer.huawei.com/consumer/cn/doc/Media-References/mode-0000001053273774#ZH-CN_TOPIC_0000001053273774__getModeConfigBuilder--)获取 ModeConfig.Builder实例进行配置，模式配置中主要是设置预览、拍照、录像用到的Surface。其中预览的surface必须配置， 其他可以选择性配置。没有配置过Surface，相应的功能也不能使用。建议操作流程为：
                1. 首先,设置预览、拍照、录像用到的Surface，例如配置拍照surface，则调用 [ModeConfig.Builder.addCaptureImage(Size, int)](https://developer.huawei.com/consumer/cn/doc/Media-References/modeconfig_builder-0000001052595081#ZH-CN_TOPIC_0000001052595081__addCaptureImage-android.util.Size-int-)，配置成功，则[takePicture()](https://developer.huawei.com/consumer/cn/doc/Media-References/mode-0000001053273774#ZH-CN_TOPIC_0000001053273774__takePicture--)方法才可用。
                2. 最后，模式配置成功后，[ModeStateCallback.onConfigured(com.huawei.camera.camerakit.Mode)](https://developer.huawei.com/consumer/cn/doc/Media-References/modestatecallback-0000001052955040#ZH-CN_TOPIC_0000001052955040__onConfigured-com.huawei.camera.camerakit.Mode-)方法会回调，模式会进入可用状态，此时模式对外提供的动作才能操作。
此外，可以重新加入相应的Surface，再次配置模式以获得功能的支持。 在模式配置时，会对模式配置参数做有效性的检测，非法的参数或是无效的参数可能引发异常,如previewSurface为空， 则会抛出IllegalArgumentException异常。  
  
**Throws:**

Throw Name | Throw Description  
---|---  
java.lang.IllegalArgumentException | 如果配置参数无效。

#### [h2]startPreview

Method  
---  
public void startPreview() 启动预览。 此函数的合法调用必须确保以下三个条件：
                1. 已经调用[ModeStateCallback.onConfigured(com.huawei.camera.camerakit.Mode)](https://developer.huawei.com/consumer/cn/doc/Media-References/modestatecallback-0000001052955040#ZH-CN_TOPIC_0000001052955040__onConfigured-com.huawei.camera.camerakit.Mode-)成功配置过模式。

                3. 调用[ModeConfig.Builder.addPreviewSurface(android.view.Surface)](https://developer.huawei.com/consumer/cn/doc/Media-References/modeconfig_builder-0000001052595081#ZH-CN_TOPIC_0000001052595081__addPreviewSurface-android.view.Surface-)已经成功设置了预览的Surface。
非法的调用会引起状态异常或是非法调用异常，重复调用将被忽略成无效操作。

#### [h2]takePicture

Method  
---  
public void takePicture(@NonNull java.io.File file) 拍摄一张照片，并保存成指定的文件。 此函数的合法调用必须确保以下三个条件：
                1. 确保当前模式支持拍照：调用[ModeCharacteristics.isCaptureSupported()](https://developer.huawei.com/consumer/cn/doc/Media-References/modecharacteristics-0000001052515103#ZH-CN_TOPIC_0000001052515103__isCaptureSupported--)返回true。
                2. 启动预览：调用[startPreview()](https://developer.huawei.com/consumer/cn/doc/Media-References/mode-0000001053273774#ZH-CN_TOPIC_0000001053273774__startPreview--)，并且成功回调 [ActionStateCallback.PreviewResult.State.PREVIEW_STARTED](https://developer.huawei.com/consumer/cn/doc/Media-References/actionstatecallback_previewresult_state-0000001052515105#ZH-CN_TOPIC_0000001052515105__PREVIEW_STARTED)。
                3. 设置拍照尺寸和格式：调用[ModeConfig.Builder.addCaptureImage(android.util.Size, int)](https://developer.huawei.com/consumer/cn/doc/Media-References/modeconfig_builder-0000001052595081#ZH-CN_TOPIC_0000001052595081__addCaptureImage-android.util.Size-int-)。
非法的调用会引起状态异常或是非法调用异常。 正常的拍照以回调方式通知，分别是[ActionStateCallback.TakePictureResult.State.CAPTURE_COMPLETED](https://developer.huawei.com/consumer/cn/doc/Media-References/actionstatecallback_takepictureresult_state-0000001052955042#ZH-CN_TOPIC_0000001052955042__CAPTURE_COMPLETED)和 [ActionStateCallback.TakePictureResult.State.CAPTURE_FILE_SAVED](https://developer.huawei.com/consumer/cn/doc/Media-References/actionstatecallback_takepictureresult_state-0000001052955042#ZH-CN_TOPIC_0000001052955042__CAPTURE_FILE_SAVED)回调。 限制1：连续拍照的间隔必须是要等上一张照片拍完后才能下发下一张照片的动作，开发者应该监听 [ActionStateCallback.TakePictureResult.State.CAPTURE_COMPLETED](https://developer.huawei.com/consumer/cn/doc/Media-References/actionstatecallback_takepictureresult_state-0000001052955042#ZH-CN_TOPIC_0000001052955042__CAPTURE_COMPLETED)状态，违反此限制的行为将导致第二次的拍照动作不能成功。 限制2：在拍照的过程中会忽略掉其他动作的响应，这个行为视具体模式而定。

#### [h2]configure

---  
public void configure() 配置模式参数。 当一个新的模式成功创建后，首先需要对模式进行配置，在configure前需要调用[getModeConfigBuilder()](https://developer.huawei.com/consumer/cn/doc/Media-References/mode-0000001053273774#ZH-CN_TOPIC_0000001053273774__getModeConfigBuilder--)获取 ModeConfig.Builder实例进行配置，模式配置中主要是设置预览、拍照、录像用到的Surface。其中预览的surface必须配置， 其他可以选择性配置。没有配置过Surface，相应的功能也不能使用。建议操作流程为：
                1. 首先,设置预览、拍照、录像用到的Surface，例如配置拍照surface，则调用 [ModeConfig.Builder.addCaptureImage(Size, int)](https://developer.huawei.com/consumer/cn/doc/Media-References/modeconfig_builder-0000001052595081#ZH-CN_TOPIC_0000001052595081__addCaptureImage-android.util.Size-int-)，配置成功，则[takePicture()](https://developer.huawei.com/consumer/cn/doc/Media-References/mode-0000001053273774#ZH-CN_TOPIC_0000001053273774__takePicture--)方法才可用。
                2. 最后，模式配置成功后，[ModeStateCallback.onConfigured(com.huawei.camera.camerakit.Mode)](https://developer.huawei.com/consumer/cn/doc/Media-References/modestatecallback-0000001052955040#ZH-CN_TOPIC_0000001052955040__onConfigured-com.huawei.camera.camerakit.Mode-)方法会回调，模式会进入可用状态，此时模式对外提供的动作才能操作。
此外，可以重新加入相应的Surface，再次配置模式以获得功能的支持。 在模式配置时，会对模式配置参数做有效性的检测，非法的参数或是无效的参数可能引发异常,如previewSurface为空， 则会抛出IllegalArgumentException异常。
