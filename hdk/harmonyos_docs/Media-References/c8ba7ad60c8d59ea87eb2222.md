# WisePlayer.ErrorListener

|Interface Info|
|:------------------------------------------------|
|public interface ErrorListener 定义播放器错误信息上报监听器的接口。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|boolean|[onError](#section139823011526)([WisePlayer](https://developer.huawei.com/consumer/cn/doc/development/Media-References/wiseplayer-0000001050316766) wp, int what, int extra) 播放器错误信息上报的回调方法。|

## Public Methods

### onError

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public boolean onError([WisePlayer](https://developer.huawei.com/consumer/cn/doc/development/Media-References/wiseplayer-0000001050316766) wp, int what, int extra) 播放器错误信息上报的回调方法。|

**Parameters**

|Name|Description|
|:----|:-------------------------------------------------------------------------------------------------------------------------|
|wp|播放器实例。|
|what|播放器主错误码，定义参见 [错误码](https://developer.huawei.com/consumer/cn/doc/development/Media-References/error-code-0000001050181663)。|
|extra|播放器子错误码，播放器内部的错误码定义，用于细化故障原因的分析和问题定位，建议业务App在日志和业务打点上报中包含子错误码信息。|

**Return** **s**

|Type|Description|
|:------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|boolean|[onError](#section139823011526)处理返回结果。 * true：播放器认为错误已经被App处理。 * false：播放器认为错误没有被处理，会调用App注册的[WisePlayer.PlayEndListener](https://developer.huawei.com/consumer/cn/doc/development/Media-References/on-completion-listener-0000001050181701)对象的[onPlayEnd](https://developer.huawei.com/consumer/cn/doc/development/Media-References/on-completion-listener-0000001050181701#section139823011526)方法上报播放结束。|
