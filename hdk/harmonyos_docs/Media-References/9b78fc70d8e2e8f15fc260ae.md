# MediaFilter

|Struct Info|
|:------------------------------------------------------------------------------------------------------------------------|
|MediaFilter 预置的过滤Pipeline类，内部调用AI插件，接口均为同步接口。不仅可以调用预置的插件，还可以调用自定义的插件，前提是需要实现自定义插件并设置Pipeline配置文件。可支持多实例，实例个数与插件自身实例数限制有关。|
