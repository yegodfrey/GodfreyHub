# Overview

基于Android MediaCodec的[configure](https://developer.android.com/reference/android/media/MediaCodec#public-methods_1)和[setParameters](https://developer.android.com/reference/android/media/MediaCodec#setParameters(android.os.Bundle))，通过扩展configure的[MediaFormat](https://developer.android.com/reference/android/media/MediaFormat#MediaFormat())和setParameters的[Bundle](https://developer.android.com/reference/android/os/Bundle)所用keys，来实现Video Engine的scale、crop、qp-regulation、nonRefPFrames、LTR、ROI等高级视频编码功能。

扩展configure的MediaFormat参数keys如下：

|**Name**|**Value Type**|**Description**|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------|:------------------------------|
|[vendor.hisi.hisi-ext-codec-vendor-configure](https://developer.huawei.com/consumer/cn/doc/development/Media-References/codec-api-constants-0000001064739284#ZH-CN_TOPIC_0000001064739284__section18442111813408)|Integer|可选，查询codec高级特性的能力集时,需要设置此key为1。|
|[vendor.hisi.hisi-ext-codec-ltr-nums](https://developer.huawei.com/consumer/cn/doc/development/Media-References/codec-api-constants-0000001064739284#ZH-CN_TOPIC_0000001064739284__section5610144124518)|Integer|可选，长期参考帧的数量。|
