#### Public Constructors

#### LogConfigInfo

|Constructor|
|:-------------------------------------------------------------------------------------------------|
|public LogConfigInfo(int logLevel, String logFilePath, int logFileNum, int logFileSize) 设置的日志配置信息。|

Parameters  

|Name|Description|
|:----------|:----------------------------------------------------------------------------------------------------------------------|
|logLevel|日志级别。日志级别支持： * 0：支持DEBUG级别及以上的日志输出。 * 1：支持INFO级别及以上的日志输出。 * 2：支持WARN级别及以上的日志输出。 * 3：支持ERROR级别及以上的日志输出。 * 10：不输出日志。|
|logFilePath|日志文件存储路径。文件路径如果为空，则获取默认路径。默认路径为："/data/data/App包名/files/videoplayerkit/"。如果设置的路径没有可写权限，则取默认路径。 说明： 设置的日志文件存储路径必须具备可写权限。|
|logFileNum|日志文件总数量。取值范围\[10, 100\]，默认数量为20。|
|logFileSize|日志单个文件大小。单位：Kbytes，取值范围\[500, 10000\]，默认大小为1024。|
