# HdrVividStatus

|Enum Info|
|:-----------------------------|
|HdrVividStatus 渲染相关函数返回值的枚举类型。|

## Enum Value Summary

|Enum Value and Description|
|:------------------------------------------------------|
|HDRVIVID_NULL_POINTER 指针类型的函数参数的值为空，取值为-2。|
|HDRVIVID_UNKNOWN_ERROR 内部出现未明确定义类型的错误，取值为-1。|
|HDRVIVID_SUCCESS 函数调用成功，取值为0。|
|HDRVIVID_UNSUPPORTED 参数或能力不支持，取值为1。|
|HDRVIVID_ILLEGAL_STATE 当前函数不在规定的状态下调用，取值为2。|
|HDRVIVID_ILLEGAL_ARGUMENT 函数参数是无效的，取值为3。|
|HDRVIVID_BUFFER_IN_USE 渲染实例工作在缓冲输入或输出时，缓冲区正被App占用，取值为4。|
