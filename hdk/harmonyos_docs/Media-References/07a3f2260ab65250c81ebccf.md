## Public Methods

### onAudioAvailable

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|void onAudioAvailable(String taskId, [HAEAiDubbingAudioInfo](https://developer.huawei.com/consumer/cn/doc/development/Media-References/haeaidubbingaudioinfo-0000001155964882) audioFragment, int offset, Pair<Integer, Integer> range, Bundle bundle) 合成音频流回调接口，通过此接口将音频合成数据返回给App。|

**Parameters**

|Name|Description|
|:------------|:------------------------------------------------------------------------------------------------------------------------|
|taskId|AI配音任务ID。|
|audioFragment|音频数据。|
|offset|一个AI配音任务会对应一个音频合成数据队列，该字段表示本次传输的音频分片在该队列中的偏移量。|
|range|本次传输的音频分片所在的文本区域，包含起始位置，不包含结束位置。例如： AI配音任务传入一段文本"机器学习，Hello！"，文本会被分割成"机器学习，"和"Hello！"两段文本，这两段文本对应的range分别为[0, 5）、[5, 11）。|
|bundle|扩展字段。|
