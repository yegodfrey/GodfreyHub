# ActionDataCallback  
  
Class Info  
---  
模式动作执行过程中，产生数据结果（如拍照图像数据、深度数据等）的回调处理。 作为[ModeConfig.Builder.setDataCallback(com.huawei.camera.camerakit.ActionDataCallback, android.os.Handler)](https://developer.huawei.com/consumer/cn/doc/Media-References/modeconfig_builder-0000001052595081#ZH-CN_TOPIC_0000001052595081__setDataCallback-com.huawei.camera.camerakit.ActionDataCallback-android.os.Handler-)的入参，用于响应后续模式产生的数据结果。 一般的工作流程参见[Mode.takePicture()](https://developer.huawei.com/consumer/cn/doc/Media-References/mode-0000001053273774#ZH-CN_TOPIC_0000001053273774__takePicture--)。 **Since:** 2019-06-25
