# 数据模型

## Config

|参数|是否必选|参数类型|描述|
|:------------------|:---|:------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|type|是|Integer|发音人类型ID，取值请参见[AI配音发音人说明](https://developer.huawei.com/consumer/cn/doc/development/Media-References/rest_api_public_description-0000001317085953#section1317103515473)。|
|speed|是|Integer|语速，取值范围：[50, 200]。|
|pitch|是|Integer|基频（音调），取值范围：[50, 200]。|
|volume|是|Integer|音量，取值范围：[90, 240]。|
|outputEncoderFormat|是|Integer|音频编码格式： * 0：PCM * 1：MP3|

## Data

|参数|是否必选|参数类型|描述|
|:-------|:---|:-----|:-----------------------|
|text|是|String|待合成的文本，应为UTF-8编码。|
|language|是|String|文本语言，支持：chinese、english。|

## TtsingConfig

|参数|是否必选|参数类型|描述|
|:---------------------|:---|:------|:------------------------------------------|
|type|是|Integer|发音人类型ID： * 1：抒情流行女声 * 2：民谣男声 * 3：国风女声|
|outputEncoderFormat|是|Integer|音频编码格式： 0：PCM|
|wordDurationForceAlign|否|String|字级别强制对齐开关，取值： * true：开启 * false：关闭 默认false。|

## TtsingData

|参数|是否必选|参数类型|描述|
|:--------------|:---|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|lyric|否|String|MusicXML文档，引号及换行符均需要进行转义。|
|lyrics|否|String[]|预置曲目歌词，与"lyric"不可同时输入。|
|language|是|String|语言，目前支持：chinese。|
|accompanimentId|否|String|预置曲目ID，请参见[歌声合成预置曲目说明](https://developer.huawei.com/consumer/cn/doc/development/Media-References/rest_api_public_description-0000001317085953#section457618201567)。|
|isAutoFill|否|String|是否开启智能填词，取值为： * true：开启 * false：关闭 默认false。更多内容请参见[歌声合成填词规则说明](https://developer.huawei.com/consumer/cn/doc/development/Media-References/rest_api_public_description-0000001317085953#section57848524154)。|

## TtsStatusRsp

|参数|是否必选|参数类型|描述|
|:------------|:---|:-----|:---------|
|taskId|是|String|任务标识。|
|taskStatus|是|String|任务状态码。|
|taskStatusMsg|是|String|任务状态信息。|
|resultUrl|否|String|结果文件下载URL。|

## TtsingStatusRsp

|参数|是否必选|参数类型|描述|
|:------------|:---|:-----|:---------|

|taskStatus|是|String|任务状态码。|
