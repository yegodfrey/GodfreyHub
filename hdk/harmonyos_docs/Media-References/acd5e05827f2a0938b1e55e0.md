# Overview

包含Video Kit播放器SDK的功能集合，入口类为[WisePlayerFactory](https://developer.huawei.com/consumer/cn/doc/development/Media-References/wpf-0000001050197166)。

## Interface Summary

|Interface|Description|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------|
|[InitFactoryCallback](https://developer.huawei.com/consumer/cn/doc/development/Media-References/init-factory-callback-0000001050199187)|定义[WisePlayer](https://developer.huawei.com/consumer/cn/doc/development/Media-References/wiseplayer-0000001050316766)播放器初始化工厂回调的接口。|
|[Preloader](https://developer.huawei.com/consumer/cn/doc/development/Media-References/preloader-0000001052554589)|定义内容预加载器接口。|
|[WisePlayer](https://developer.huawei.com/consumer/cn/doc/development/Media-References/wiseplayer-0000001050316766)|定义视频播放功能的[WisePlayer](https://developer.huawei.com/consumer/cn/doc/development/Media-References/wiseplayer-0000001050316766)播放器的接口。|
|[WisePlayer.ErrorListener](https://developer.huawei.com/consumer/cn/doc/development/Media-References/on-error-listener-0000001050181705)|定义播放器错误信息上报监听器的接口。|
|[WisePlayer.EventListener](https://developer.huawei.com/consumer/cn/doc/development/Media-References/on-info-listener-0000001050274538)|定义播放器媒体以及播放信息上报监听器的接口。|
|[WisePlayer.IRecommendVideoCallback](https://developer.huawei.com/consumer/cn/doc/development/Media-References/recommend-video-info-0000001060038420)|定义推荐内容请求接口。|
|[WisePlayer.LoadingListener](https://developer.huawei.com/consumer/cn/doc/development/Media-References/on-buffering-listener-0000001050421601)|定义播放器缓冲相关事件的监听器的接口。|
|[WisePlayer.PlayEndListener](https://developer.huawei.com/consumer/cn/doc/development/Media-References/on-completion-listener-0000001050181701)|定义播放完成监听器的接口。|
|[WisePlayer.PreviewPicListener](https://developer.huawei.com/consumer/cn/doc/development/Media-References/previewpiclistener-0000001317764325)|定义播放器缩略图信息上报监听器的接口。|
|[WisePlayer.ReadyListener](https://developer.huawei.com/consumer/cn/doc/development/Media-References/on-prepared-listener-0000001050179532)|定义媒体内容已经完成准备监听器的接口。|
|[WisePlayer.ResolutionUpdatedListener](https://developer.huawei.com/consumer/cn/doc/development/Media-References/on-videosize-changed-listener-0000001050421605)|定义播放视频分辨率发生变化监听器的接口。|
|[WisePlayer.SeekEndListener](https://developer.huawei.com/consumer/cn/doc/development/Media-References/on-seek-complete-listener-0000001050179536)|定义[seek](https://developer.huawei.com/consumer/cn/doc/development/Media-References/wiseplayer-0000001050316766#section128567191026)操作完成的监听器的接口。|
|[WisePlayer.SubtitleUpdateListener](https://developer.huawei.com/consumer/cn/doc/development/Media-References/subtitle-update-listener-0000001160411175)|定义播放器字幕信息上报监听器的接口。|
