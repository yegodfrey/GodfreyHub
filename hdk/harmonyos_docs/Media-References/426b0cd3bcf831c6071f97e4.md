# Overview

该包提供了华为图像服务中场景动效服务接口，开发者集成该SDK后，可以调用场景动效中位移、旋转、等5种基础动效和跟手粒子、水波纹等9种高级动效能力。

## Interface summary

|Interface|Description|
|:--------------------------------------------------------------------------------------------------------------------------------------|:--------------|
|[ImageRender.RenderCallBack](https://developer.huawei.com/consumer/cn/doc/development/Media-References/rendercallback-0000001050754791)|场景动效服务回调接口。|
|[ImageRenderInterface](https://developer.huawei.com/consumer/cn/doc/development/Media-References/imagerenderinterface-0000001050439501)|提供了场景动效服务的基本接口。|
|[IStreamCallBack](https://developer.huawei.com/consumer/cn/doc/development/Media-References/istreamcallback-0000001054922339)|动效录制回调接口。|
|[IBindCallBack](https://developer.huawei.com/consumer/cn/doc/development/Media-References/ibindcallback-0000001054888276)|绑定渲染视图回调接口。|
|[IParseCallBack](https://developer.huawei.com/consumer/cn/doc/development/Media-References/iparsecallback-0000001054858021)|脚本解析结束回调接口。|
