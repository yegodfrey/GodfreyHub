#### QUEUE_APPEND

|Field|
|:---------------------------------------------------------------------------------------------------|
|public static final int QUEUE_APPEND 串行排队模式。当您选择排队模式时，如果有多个语音合成任务，这些任务按照调用次序，顺序执行。 Constant Value: 0|

#### QUEUE_FLUSH

|Field|
|:----------------------------------------------------------------------------------------------------------------|
|public static final int QUEUE_FLUSH 清空队列模式。当您选择清空队列模式时，会清空待执行的语音合成任务，并停止当前语音合成任务，立即执行当前的语言合成任务。 Constant Value: 1|

Parameters  

|Name|Description|
|:---|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

|mode|AI配音任务播放模式。 mode参数组合值： * 串行排队模式且配音引擎合成的语音不使用内部播放器自动播放，使用外部播放器： HAEAiDubbingEngine.[QUEUE_APPEND](#section433810314211) \| HAEAiDubbingEngine.[EXTERNAL_PLAYBACK](#section386083617410) * 串行排队模式且合成音频后使用内部播放器自动播放，同时将音频流返回给App： HAEAiDubbingEngine.[QUEUE_APPEND](#section433810314211) \| HAEAiDubbingEngine.[OPEN_STREAM](#section33765421049) * 清空队列模式且配音引擎合成的语音不使用内部播放器自动播放，使用外部播放器：HAEAiDubbingEngine.[QUEUE_FLUSH](#section153380311124) \| HAEAiDubbingEngine.[EXTERNAL_PLAYBACK](#section386083617410) * 清空队列模式且合成音频后使用内部播放器自动播放，同时将音频流返回给App： HAEAiDubbingEngine.[QUEUE_FLUSH](#section153380311124) \| HAEAiDubbingEngine.[OPEN_STREAM](#section33765421049)|

|Type|Description|
|:-----|:----------|
|String|返回AI配音任务ID。|
