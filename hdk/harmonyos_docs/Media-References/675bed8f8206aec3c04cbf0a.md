# Metadata.FocusMode  
  
Annotation Info  
---  
对焦模式种类。 **Since:** 2019-08-20 **See Also:** [ModeCharacteristics.getSupportedAutoFocus()](https://developer.huawei.com/consumer/cn/doc/Media-References/modecharacteristics-0000001052515103#ZH-CN_TOPIC_0000001052515103__getSupportedAutoFocus--), [Mode.setFocus(int, Rect)](https://developer.huawei.com/consumer/cn/doc/Media-References/mode-0000001053273774#ZH-CN_TOPIC_0000001053273774__setFocus-int-android.graphics.Rect-)  
  
#### Public Fields

#### [h2]HW_AF_OFF

Field  
---  
public static final byte HW_AF_OFF 对焦模式：手动对焦。 **Since:** API版本 VersionInfo.API_LEVEL_1以上  
  
#### [h2]HW_AF_CONTINUOUS

Field  
---  
public static final byte HW_AF_CONTINUOUS 对焦模式：连续自动对焦。  
  
#### [h2]HW_AF_TOUCH_AUTO

Field  
---  
public static final byte HW_AF_TOUCH_AUTO 对焦模式：触发一次触摸对焦然后转成连续自动对焦模式。  
  
#### [h2]HW_AF_TOUCH_LOCK

Field  
---  
public static final byte HW_AF_TOUCH_LOCK 对焦模式：触发一次触摸对焦然后对焦锁定。
