# Overview

该包提供了华为图像服务中图片处理功能返回结果类和图文智能排版功能的返回结果类，开发者集成该SDK后，开发者可以查看返回结果。

## Class summary

|Class|Description|
|:----------------------------------------------------------------------------------------------------------------------------|:-------------|
|[ImageVisionResult](https://developer.huawei.com/consumer/cn/doc/development/Media-References/vison--0000001307643985)|图像处理功能返回结果类。|
|[ImageLayoutInfo](https://developer.huawei.com/consumer/cn/doc/development/Media-References/imagelayoutinfo-0000001307724001)|图文智能排版功能返回结果类。|
|[ResultCode](https://developer.huawei.com/consumer/cn/doc/development/Media-References/resultcode-0000001260203894)|通用返回码。|
