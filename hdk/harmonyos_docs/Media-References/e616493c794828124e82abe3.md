# Metadata.FairLightType  
  
Annotation Info  
---  
光效种类。 一人像光像对场景有比较严格的限制，当前只有摄像头中只有一个位置距离合适的人脸时，拍摄的照片才会有效果。 如下场景可能会导致拍摄照片没有光效效果：
                * 预览人脸过近或者过远。
                * 预览人脸不完整。
                * 预览中多个人脸。
