|Name|Description|
|:-------|:------------------------------------------------------------------|
|urlArray|播放媒体内容的多个CDN URL地址，支持的流协议和媒体内容包括： * DASH+MP4 * HLS+TS * HTTP(S)+MP4|

#### ready

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void ready() 异步准备播放器和媒体资源。 需要在调用前设置播放数据源和视频显示的View，调用该方法播放器将立即返回，播放器在完成媒体资源准备后通过监听器[WisePlayer.ReadyListener](https://developer.huawei.com/consumer/cn/doc/development/Media-References/on-prepared-listener-0000001050179532)的[onReady](https://developer.huawei.com/consumer/cn/doc/development/Media-References/on-prepared-listener-0000001050179532#section139823011526)()回调方法通知。|

#### start

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void start() 开始或继续播放。如果以前已暂停播放，则将从暂停的位置继续播放。如果播放已完成或之前从未开始过，则从头开始播放。 说明： 1、当前FLV直播调用[pause](#section23225616217)暂停后不能通过[start](#section1724320122)恢复播放，App可以通过启动新的播放实例达到继续播放的目的。 2、在调用[start](#section1724320122)接口时，需要确保显示媒体内容的view没有被销毁。|

#### pause

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void pause() 暂停播放，调用[start](#section1724320122)()可恢复播放。 说明： 播放器切换至后台状态需要挂起媒体内容播放时，需要调用[suspend](#section1788394373916)()。 当前FLV直播调用[pause](#section23225616217)()暂停后不能通过[start](#section1724320122)()恢复播放，App可以通过启动新的播放实例达到继续播放的目的。|

#### suspend

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void suspend() 挂起播放器。 播放器切换至后台状态挂起媒体内容播放，播放器回到前台时调用[resume](#section322644813392)()恢复播放。如果在播放器切换至后台状态时需要采用纯音频播放模式，请调用[setPlayMode](#section432711221297)()。|

#### resume

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void resume(int play) 恢复播放器。 播放器回到前台时恢复播放，调用此方法前可以调用[setView](#section11355124518594)()接口重新设置视频内容显示对象。 说明： 1、当前FLV直播调用[suspend](#section1788394373916)()暂停切后台，后续通过[resume](#section322644813392)()切回前台的时候，会重新拉流，存在黑帧现象，App可以考虑在切换回前台的时候增加过渡画面。 2、在调用[start](#section1724320122)接口时，需要确保显示媒体内容的view没有被销毁。|

Parameters  

|Name|Description|
|:---|:-------------------------------------------------|
|play|控制恢复前台后的播放状态： * 0：播放状态 * 1：暂停状态 * -1：保持切换至后台时的播放状态|

#### seek

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void seek(int time) 定位到指定时间播放。实际开始播放位置为早于或者等于指定时间的关键帧位置。 在[seek](#section128567191026)完成时，播放器通过[WisePlayer.SeekEndListener](https://developer.huawei.com/consumer/cn/doc/development/Media-References/on-seek-complete-listener-0000001050179536)通知App。 说明： 当前FLV直播不支持seek调用。|

Parameters  

|Name|Description|
|:---|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|time|媒体内容的时间，单位：毫秒。 当定位到指定的时间位置时，将定位到早于指定时间的最近一个关键帧。如果时间为负数，则保持当前的播放位置不变，如果时间大于媒体内容总时长，播放器将上报[MEDIA_SEEK_NO_AVAILABLE_SEGMENT](https://developer.huawei.com/consumer/cn/doc/development/Media-References/error-code-0000001050181663#ZH-CN_TOPIC_0000001050181663__p1156415864519)错误。|
