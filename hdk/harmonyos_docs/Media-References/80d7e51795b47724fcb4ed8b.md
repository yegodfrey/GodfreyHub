# 公共说明

* 接口协议：**HTTPS**
* 请求方法：**POST**
* 接口数据格式：**JSON**
* 接口数据字符编码：**UTF-8**
* 消息头中的Content-Type需要设置为**application/json; charset=UTF-8**
* string类的参数说明中未明确特殊字符校验规则的，规则校验为不允许填写如下特殊字符：< > & % | \ /（base64编码后的字符串除外）

## 密钥分配

您在AppGallery Connect上注册并开通WisePlay DRM服务，即可获取接入WisePlay DRM服务的PortalID、AESKey（敏感数据加密密钥）和SignKey（接口认证签名密钥）信息。

* PortalID用于设置请求消息头中的**x-portalId**参数。
* AESKey用于加密KeyInfo对象中的**key**参数。
* SignKey用于生成请求消息头中的**x-sign**参数。

## 敏感数据传递

接口传递敏感数据时对敏感字段值采用AES/GCM/NoPadding模式加密后再拼接到postBody中传输。敏感数据加密密钥为[密钥分配](#section864212117557)中的AESKey。
> 说明
>
> 当前接口中的敏感数据包括：内容加密密钥（KeyInfo对象中的key参数）。

## 接口认证签名

接口认证签名统一使用HmacSHA256签名算法计算签名，将签名结果进行base64编码后设置到请求消息头中的x-sign参数。

HmacSHA256签名算法如下：**HmacSHA256(basePath+resourcePath+queryString+x-appId+x-portalId+x-timeStamp+postBody, signKey)。**

|参数|描述|
|:-----------|:----------------------------------------------|
|basePath|服务的基础路径|
|resourcePath|资源路径标识|
|queryString|URL中第一个"？"之后的字符串|
|x-appId|开发者在AppGallery Connect平台上申请的应用appId|
|x-portalId|系统ID标识，为[密钥分配](#section864212117557)中的PortalID|
|x-timeStamp|请求发送时间戳|
|postBody|消息体的整个字符串（JSON串），为HTTPS的整个报文体部分（UTF-8编码后的字符串）|
|signKey|接口认证签名密钥，为[密钥分配](#section864212117557)中的SignKey|

> 说明
>
> * 上述加号（+）表示字符串的拼接，不需填入加号（+）。
> * basePath+resourcePath+queryString：请求的URL去掉协议头和IP/域名后的值，如访问地址为：https://1.1.1.1:8080/a/b/c?p1=1&p2=2，则basePath+resourcePath+queryString为"/a/b/c?p1=1&p2=2" （注意：含a前面的斜杠）。

签名算法示例代码：

```screen
// 获取字符串的字节数组值（字符串转UTF-8字节）
byte[] secretBytes = Base64.getDecoder().decode(signKey); 
byte[] originalWordBytes =originalWord.getBytes("UTF-8"); 
try
{
    //初始化Mac对象
    Mac mac = Mac.getInstance("HmacSHA256");
    //定义密钥
    SecretKey secretKey = new SecretKeySpec(secretBytes, "HmacSHA256");
    //初始化密钥
    mac.init(secretKey);
    //进行加密处理
    byte[] encryptedWordBytes = mac.doFinal(originalWordBytes);
    //进行Base64编码
    String encryptedWord = Base64.getEncoder().encodeToString(encryptedWordBytes);
}
```
