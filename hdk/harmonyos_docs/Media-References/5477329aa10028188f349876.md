# 同步接口（流式）

#### 功能介绍

将文本同步转为语音。

输出PCM流参数：

* 采样率：16000Hz
* 声道：1
* 位深：16bit
* 格式：pcm_s16le  

#### 场景描述

将待合成的文本上传到服务端，服务端流式返回文本对应的语音。  

#### 使用约束

适用于短文本语音合成，要求中文不超过500字符，英文不超过3000字符且不超过500个单词。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|应用服务端 --\> 音频编辑服务|
|URI|{rootUrl}/v1/audioeditor/gateway/ai/dubbing/sync 说明： {rootUrl}在不同站点有不同的URL，具体请参见[站点信息](https://developer.huawei.com/consumer/cn/doc/development/Media-References/rest_api_public_description-0000001317085953#section10142203818241)。|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/octet-stream或application/json|
|----|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### 请求参数

Request Header  

|参数|是否必选|参数类型|描述|
|:-----------------|:---|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|X-Request-ID|是|String|请求事务标识，保证唯一即可。|
|X-Package-Name|是|String|App包名。|
|X-Country-Code|是|String|App所在归属国家。|
|HMS-APPLICATION-ID|是|String|App标识，即Client ID。|
|certFingerprint|否|String|证书指纹。|
|Authorization|是|String|您动态获取的[Access Token](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-oauth-0000001053629189)。 说明： Bearer后面拼接空格，再拼接获取的access_token。|

Request Body  

|参数|是否必选|参数类型|描述|
|:-----|:---|:----------------------------------------------------------------------------------------------------------------------------------|:----|
|data|是|[Data](https://developer.huawei.com/consumer/cn/doc/development/Media-References/data_model-0000001268605794#section14837155812311)|文本信息。|
|config|是|[Config](https://developer.huawei.com/consumer/cn/doc/development/Media-References/data_model-0000001268605794#section35091312322)|音频信息。|

#### 请求示例

```
POST /v1/audioeditor/gateway/ai/dubbing/sync HTTP/1.1
X-Request-ID: a6596b8a-87b0-4cb3-97fe-45e91432515f
X-Package-Name: com.huawei.demo
X-Country-Code: cn
HMS-APPLICATION-ID: 123456
certFingerprint: xxx
Content-Type: application/json
Authorization: Bearer ***

{
    "data": {
        "text": "你好",
        "language": "chinese"
    },
    "config": {
        "type": 2,
        "speed": 100,
        "pitch": 100,
        "volume": 90,
        "outputEncoderFormat": 1
    }
}
```

#### 响应参数

状态码为200时：

响应结果包含在HTTPS的响应体中，响应结果的成功或失败需通过HTTPS Headers的Content-Type字段来区分。

Response Header  

|参数|是否必选|参数类型|描述|
|:-----------|:---|:-----|:------------------------------------------|
|Content-Type|是|String|取值为：application/octet-stream，表示响应成功。|
|Content-Type|是|String|取值为：application/json; charset=UTF-8，表示响应失败。|

Response Body

成功响应内容为合成音频的音频字节流。

失败响应内容如下：  

|参数|是否必选|参数类型|描述|
|:------|:---|:-----|:--------------------------------------------------------------------------------------------------------------------|
|retCode|是|String|详细错误码，请参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/Media-References/errorcode-0000001323704145)。|
|retMsg|是|String|错误码描述，请参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/Media-References/errorcode-0000001323704145)。|

#### 响应示例

```
HTTP/1.1 200 OK
Content-Type: application/octet-stream

"响应体为音频字节流"
```
