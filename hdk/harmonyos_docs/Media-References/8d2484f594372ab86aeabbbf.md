# PanoramaInterface.PanoramaLocalInterface

|Interface Info|
|:-----------------------------------------------------|
|public interface PanoramaLocalInterface 提供了应用内全景展示的接口。|

|Qualifier and Type|Method Name and Description|
|:-----------------|:----------------------------------------------------------------------------|
|int|[init](#section1489534554916)() 初始化应用内全景展示接口。|

### getValue

|Method|

|:-----|:---------------------------------|

### setControlMode

|Method|
|:------------------------------------------------------|
|void setControlMode(int mode) 设置全景图浏览的控制方式，支持使用过程中动态切换。|

**Parameter** **s**

|Name|Description|
|:---|:--------------------------------------------------------------------------------------|
|mode|设置全景图浏览的控制方式。 当前支持的类型有：手机姿态控制和触摸控制，其中触摸控制需要您调用[updateTouchEvent](#section342841614596)。|

### updateTouchEvent

|Method|
|:-------------------------------------------------------------------------------------|
|void updateTouchEvent(MotionEvent event) 更新视图触摸事件，在开启触屏控制模式的情况下，全景服务将根据触屏事件动态调整视图显示内容。|

**Parameter** **s**

|Name|Description|
|:----|:--------------------------------------------------------------------------------------------|
|event|Android标准触摸事件，触摸位置以全景图View控件左上角为原点，可通过View的OnTouchListener传入。 您可处理掉上层App需要的触摸事件，将其余事件转给SDK处理。|

|Method|
|:--------------------------------|
