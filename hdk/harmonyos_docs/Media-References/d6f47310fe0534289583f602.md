# Overview

## Struct Summary

|Struct|Description|
|:------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[INode](https://developer.huawei.com/consumer/cn/doc/development/Media-References/inode-0000001113343414)|节点接口类，Pipeline中所有插件都继承于此接口类。该类中的虚函数都只有空实现或默认实现。|
|[NodeListener](https://developer.huawei.com/consumer/cn/doc/development/Media-References/nodelistener-0000001113533742)|节点回调类，用于向节点注册回调函数。|
|[NodeBase](https://developer.huawei.com/consumer/cn/doc/development/Media-References/nodebase-0000001159703233)|节点基础类，继承[INode](https://developer.huawei.com/consumer/cn/doc/development/Media-References/inode-0000001113343414)，实现所有节点的公共逻辑。|
|[SourceNode](https://developer.huawei.com/consumer/cn/doc/development/Media-References/sourcenode-0000001159823217)|源节点类，继承[NodeBase](https://developer.huawei.com/consumer/cn/doc/development/Media-References/nodebase-0000001159703233)，处于Pipeline头部且从资源中获取原始数据的生产者节点，不存在上游节点，但有下游节点。|
|[FilterNode](https://developer.huawei.com/consumer/cn/doc/development/Media-References/filternode-0000001113503308)|过滤节点类，继承[NodeBase](https://developer.huawei.com/consumer/cn/doc/development/Media-References/nodebase-0000001159703233)，处于Pipeline中部且对数据进行处理或变换的处理者节点，有上游节点和下游节点。|
|[SinkNode](https://developer.huawei.com/consumer/cn/doc/development/Media-References/sinknode-0000001113343416)|Sink节点类，继承[NodeBase](https://developer.huawei.com/consumer/cn/doc/development/Media-References/nodebase-0000001159703233)，处于Pipeline尾部且对数据进行Sink的节点，有上游节点，但不存在下游节点。|
|[IPipeline](https://developer.huawei.com/consumer/cn/doc/development/Media-References/ipipeline-0000001159703235)|Pipeline接口类，定义操作Pipeline的所有接口。该类中的虚函数只有空实现或默认实现。|
|[PipelineBase](https://developer.huawei.com/consumer/cn/doc/development/Media-References/pipelinebase-0000001159823219)|Pipeline基础类，继承[IPipeline](https://developer.huawei.com/consumer/cn/doc/development/Media-References/ipipeline-0000001159703235)，实现Pipeline的公共逻辑。|
|[PipelineListener](https://developer.huawei.com/consumer/cn/doc/development/Media-References/pipelinelistener-0000001113372466)|Pipeline回调类，注册到Pipeline里面，用于从Pipeline获取消息。|
|[MediaFilter](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediafilter-0000001113503310)|预置插件类，内部可调用视频超分插件或声音事件检测插件，接口均为同步接口。不仅可以调用预置的插件，还可以调用自定义的插件，前提是需要实现自定义插件并设置Pipeline配置文件。|
|[MMListener](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mmlistener-0000001113385740)|[MediaFilter](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediafilter-0000001113503310)回调类，上报[MediaFilter](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediafilter-0000001113503310)内部消息和buffer。|
|[MediaBuffer](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediabuffer-0000001113395492)|多种类型数据的载体，包括压缩域数据、raw域数据等。|
|[MediaMeta](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediameta-0000001159875293)|数据封装类，可根据键值获取和更改对应的数据。|
|[MediaParcel](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediaparcel-0000001113394572)|序列化数据的载体。|
|[Clock](https://developer.huawei.com/consumer/cn/doc/development/Media-References/clock-0000001113399682)|用于[SinkNode](https://developer.huawei.com/consumer/cn/doc/development/Media-References/sinknode-0000001113343416)间的同步。|
|[ClockCore](https://developer.huawei.com/consumer/cn/doc/development/Media-References/clockcore-0000001113343418)|核心时钟类，用于多个[SinkNode](https://developer.huawei.com/consumer/cn/doc/development/Media-References/sinknode-0000001113343416)的时钟同步。|
|[Writer](https://developer.huawei.com/consumer/cn/doc/development/Media-References/writer-0000001184523071)|写入器，用于将数据写入[INode](https://developer.huawei.com/consumer/cn/doc/development/Media-References/inode-0000001113343414)节点。|
