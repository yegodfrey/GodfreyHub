# MediaPlayer

|Class Info|
|:------------------------------------------------------------------------------------------------------------|
|public class MediaPlayer 将底层框架具体的Pipeline接口封装成与多媒体具体业务相近的接口，支持音视频的播放，可以通过设置文件路径来播放本地文件。支持异步操作，可通过设置回调来获取运行状况。|
