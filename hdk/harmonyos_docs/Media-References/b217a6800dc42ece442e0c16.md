# HwAudioPlayItem

|Class Info|
|:-------------------------------------------------------------------------------------------------------------------------------------------|
|public class HwAudioPlayItem implements Cloneable, Parcelable 音频的数据类，例如：专辑名称、是否为在线音频、艺术家等。 必须设置的参数：音频ID、音频是否在线，在线歌曲还需设置音频在线URL，本地歌曲设置音频本地路径。|

|public void setFilePath(String filePath) * 设置音频本地路径，用于播放指定本地文件目录的音频文件。例如：/sdcard/Music/audioFile.mp3 * 设置Android工程目录下指定文件夹的音频路径，用于播放打包在APK里的音频文件，支持以下两种路径： * Android工程目录"\app\src\main\res\raw"，路径设置必须以hms_res://开头，且音频文件不带扩展名，例如：hms_res://audioFile * Android工程目录"\app\src\main\assets"，路径设置必须以hms_assets://开头，且音频文件需带扩展名，例如：hms_assets://audioFile.mp3|

### setContentLength

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void setContentLength(long contentLength) 通过设置chunk模式音频资源的本地缓存文件大小信息，播放chunk模式的音频资源，例如在线播放文件管理器下我的云盘内的音频文件。 > 说明 > contentLength设置请和音频资源文件实际大小保持一致。 > * 若设置偏大：歌曲结束后会继续静音播放至文件结束。 > * 若设置偏小：导致歌曲播放不完整。|

**Parameters**

|Name|Description|
|:------------|:-------------------------|
|contentLength|本地缓存的音频文件大小，单位：byte，默认值：0。|
