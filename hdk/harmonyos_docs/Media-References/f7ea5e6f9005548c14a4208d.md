Parameters  

|Name|Description|
|:------------------|:------------------------------------|
|inAudioPath|待进行环境选择的音频文件本地全路径，不可为空。|
|outAudioDir|进行环境选择后的音频保存的本地文件路径，不可为空。|
|outAudioName|进行环境选择后的音频保存的文件名。|
|changeSoundCallback|环境选择结果回调，包括进度、成功、失败、取消。 说明： 回调发生在子线程。|
