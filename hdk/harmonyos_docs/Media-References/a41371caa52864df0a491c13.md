# SetSoundEffectListener

|Interface Info|
|:-----------------------------------------------------|
|public interface SetSoundEffectListener 设置某音效生效的监听器接口。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-----------------------------------------------------------------------------|
|void|[onSuccess](#section15481736111411)(int data) 设置成功后的回调。|
|void|[onError](#section9501336141417)(int errorCode, String errorMessage) 设置失败后的回调。|

## Public Methods

### onSuccess

|Method|
|:--------------------------------------|
|void onSuccess(int data) 设置某音效数据成功后的回调。|

**Parameters**

|Name|Description|
|:---|:------------------|
|data|设置某音效数据成功的返回值，固定为0。|

### onError

|Method|
|:-------------------------------------------------------------|
|void onError(int errorCode, String errorMessage) 设置音效数据失败后的回调。|

**Parameters**

|Name|Description|
|:-----------|:-------------------------------------------------------------------------------------------------------------|
|errorCode|详情请查看[错误码](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/error-code-0000001050752777)。|
|errorMessage|错误消息。|
