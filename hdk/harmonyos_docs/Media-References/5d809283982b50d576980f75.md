Parameters

|audioExtractCallback|音频提取结果回调，包括进度、成功、失败、取消。 说明： 回调发生在子线程。|

#### transformAudio(String inAudioPath, String outAudioPath, HAEAudioTransformConfig inAudioConfig, OnTransformCallBack transformCallBack)

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void transformAudio(String inAudioPath, String outAudioPath, [HAEAudioTransformConfig](https://developer.huawei.com/consumer/cn/doc/development/Media-References/haeaudiotransformconfig-0000001507526645) inAudioConfig, [OnTransformCallBack](https://developer.huawei.com/consumer/cn/doc/development/Media-References/ontransformcallback-0000001156926717) transformCallBack) 音频格式转换。该接口将输入的音频文件转换为目标格式的音频文件，并且支持指定采样率、通道数和比特率。|

Parameters  

|Name|Description|
|:----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|inAudioPath|输入文件的路径，如"/sdcard/Music/AudioEdit/format/audio/music.mp3"。|
|outAudioPath|输出的文件的路径（后缀为目标格式），音频格式如".wav"作为后缀名，输出的文件路径为"/sdcard/Music/AudioEdit/format/music.wav"。支持格式包括：MP3、WAV、FLAC。|
|inAudioConfig|* 输出的文件详细格式，支持指定采样率范围：\[6000, 19200\]。不同封装格式支持的采样率不同，具体支持转换的格式以及对应采样率，可以通过[SUPPORT_SAMPLE_RATE](https://developer.huawei.com/consumer/cn/doc/development/Media-References/haeaudiotype-0000001457766696#section72492308528)常量获取。 * 支持指定通道数范围：单声道、双声道。 * 支持指定的比特率范围：大于0即可。|
|transformCallBack|转码进度和结果的回调。转码进度取值范围：\[0, 100\]。|
