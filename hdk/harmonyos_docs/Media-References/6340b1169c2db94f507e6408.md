# CameraDeviceCallback

Class Info  
---  
相机设备状态变化的全局监听回调，如监听摄像头设备有效性状态或闪光灯设备有效性状态。 当被占用的相机释放或发现有新的外部相机连接时，上报相机状态为可用。 当其他应用或服务使用相机时或者外部相机断开连接时，上报相机状态为不可用。 **Since:** 2019-06-25
