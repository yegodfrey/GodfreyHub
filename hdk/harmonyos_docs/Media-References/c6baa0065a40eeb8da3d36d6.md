# Mode.ResultCode

Annotation Info  
---  
设置动作下发状态的返回码。 如执行模式变焦时[Mode.setZoom(float)](https://developer.huawei.com/consumer/cn/doc/Media-References/mode-0000001053273774#ZH-CN_TOPIC_0000001053273774__setZoom-float-),返回变焦动作下发结果，可以返回下发成功、 未知错误导致操作失败、不支持的操作、参数不合法、操作时机错误等状态。请注意此返回值不是动作执行的数据结果。 **Since:** 2019-04-20  
  
#### Public Fields

#### [h2]RESULT_SUCCESS

Field  
---  
public static final int RESULT_SUCCESS 操作成功。  
  
#### [h2]RESULT_FAILED_UNKNOWN

Field  
---  
public static final int RESULT_FAILED_UNKNOWN 未知错误导致操作失败。  
  
#### [h2]RESULT_UNSUPPORTED_OPERATION

Field  
---  
public static final int RESULT_UNSUPPORTED_OPERATION 操作不支持。  
  
#### [h2]RESULT_ILLEGAL_ARGUMENT

Field  
---  
public static final int RESULT_ILLEGAL_ARGUMENT 非法入参。  
  
#### [h2]RESULT_ILLEGAL_STATE

Field  
---  
public static final int RESULT_ILLEGAL_STATE 操作时机错误。  
  
#### [h2]RESULT_CONFLICTED

Field  
---  
public static final int RESULT_CONFLICTED 操作冲突。
