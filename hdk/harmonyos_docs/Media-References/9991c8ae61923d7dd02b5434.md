# ModeCharacteristics.ConflictAction  
  
Annotation Info  
---  
定义模式中提供的功能，可以用于描述某个模式的功能之间的互斥（如录像模式下，美肤和滤镜互斥，若美肤生效后，滤镜则无法同时生效）。 查询互斥则通过[ModeCharacteristics.getConflictActions()](https://developer.huawei.com/consumer/cn/doc/Media-References/modecharacteristics-0000001052515103#ZH-CN_TOPIC_0000001052515103__getConflictActions--)。 **Since:** 2019-06-28  
  
#### Public Fields

#### [h2]HW_AI_MOVIE_ACTION

Field  
---  
public static final int HW_AI_MOVIE_ACTION 定义录像模式下，AI电影模式。 描述多个功能之间的冲突。如果此功能存在冲突，则模式的参数[RequestKey.HW_AI_MOVIE](https://developer.huawei.com/consumer/cn/doc/Media-References/requestkey-0000001053433784#ZH-CN_TOPIC_0000001053433784__HW_AI_MOVIE)不能使用。 **See Also:** [RequestKey.HW_AI_MOVIE](https://developer.huawei.com/consumer/cn/doc/Media-References/requestkey-0000001053433784#ZH-CN_TOPIC_0000001053433784__HW_AI_MOVIE), [ModeCharacteristics.getConflictActions()](https://developer.huawei.com/consumer/cn/doc/Media-References/modecharacteristics-0000001052515103#ZH-CN_TOPIC_0000001052515103__getConflictActions--)
