# 元服务首次被用户运行之后，我们可以定向push消息吗？同时运行元服务和App的时候，如果我们后台统一发送push，会收到两条一样的吗？

元服务消息采用订阅机制，开发者需要申请某场景下的消息模板+用户主动订阅该场景消息，才可以发送消息；

基于上述元服务和App不同的发送消息机制，用户不应该收到两条一样的消息。如果同时开发App和元服务，开发者应主动规避向相同用户发送同样内容和类似内容的消息。
