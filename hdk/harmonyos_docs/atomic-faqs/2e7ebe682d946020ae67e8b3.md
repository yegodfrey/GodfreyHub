# 当前的业务场景模板没有被满足，后续是否还会开放更多的模板？

欢迎开发者通过[申请权益](https://developer.huawei.com/consumer/cn/doc/atomic-guides/push-as-timeline#section592010820304)提交模板设计述求，经平台评估通过的模板，会纳入服务动态场景模板。
