# 元服务和服务卡片共享内存吗？

元服务和服务卡片运行在不同的进程中，不共享内存。此外，服务卡片页面和其对应的EntryFormAbility也是运行在不同的进程中。服务卡片运行机制请参考：

[ArkTS卡片概述](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/arkts-form-overview)
