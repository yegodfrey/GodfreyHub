# 一个工程可以同时开发应用和元服务吗？

可以通过DevEco Studio可以创建应用与元服务的混合工程。

建议先创建一个应用工程，然后在工程内创建元服务模块。
> 说明
>
> 元服务只能使用元服务API集，应用不受此限制。打包为元服务的模块不能使用元服务API集之外的API，否则编译报错无法生成目标二进制安装包。
