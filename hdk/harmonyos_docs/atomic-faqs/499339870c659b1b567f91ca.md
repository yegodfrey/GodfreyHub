# 元服务WebView组件是否需要校验业务域名？

自HarmonyOS 5.0.0.135及以上版本，元服务WebView组件只做主域名及内嵌iframe主域名校验，网页内加载资源引用到的域名（https请求、websocket请求）不再做域名校验。HarmonyOS 5.0.0.135以下版本，网页内加载的资源引用到的业务域名仍需业务域名配置。请您务必做好兼容方案。

**解决措施**

方案一：操作系统版本低于HarmonyOS 5.0.0.135（不包含此版本），已上架的元服务如需成功加载H5页面，需要继续做业务域名配置，以避免加载白屏。

方案二：操作系统版本低于HarmonyOS 5.0.0.135（不包含此版本），如果开发者无法配置业务域名，建议在元服务中提示用户：操作系统版本过低，建议升级操作系统后重试。
