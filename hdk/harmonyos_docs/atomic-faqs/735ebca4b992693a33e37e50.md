# 元服务如何调试App Linking链接

## 问题现象

在AGC配置元服务App Linking链接后，如何验证App Linking链接能否正确打开元服务？

## 解决方案

1. 配置元服务链接：作为目标方提供App Linking跳转能力时，您的账号需要是[企业开发者](https://developer.huawei.com/consumer/cn/doc/start/edrna-0000001062678489)账号，且已开通了[App Linking服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-enable-0000001058870473)。具体配置步骤参考[创建元服务链接](https://developer.huawei.com/consumer/cn/doc/atomic-guides/atomic-applinking#section48651523147)。
2. 将配置的元服务链接点击发布，使其处于"已生效"状态。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/47/v3/sdd5KYIoQ4mzgykAJxFy_w/zh-cn_image_0000002628398484.png?HW-CC-KV=V1&HW-CC-Date=20260910T055430Z&HW-CC-Expire=31536000000&HW-CC-Sign=28B553EBE5110135AD721F701AD2C48EA4A277A201DB566558FCC94F5B5E78ED "点击放大")

   > 说明
   >
   > App Linking链接状态处于"已生效"时，暂不支持删除。
3. 将对应元服务部署安装到测试真机上。
4. 将配置的元服务链接生成二维码，通过扫码查看是否可以正确跳转该元服务；或者将配置的链接复制到备忘录中，在备忘录中点击链接查看是否可打开元服务。
