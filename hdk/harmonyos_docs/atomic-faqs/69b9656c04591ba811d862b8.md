# 开发者是否需要在元服务内提供注销账号功能？

请参考全国网络安全标准化技术委员会对《个人信息安全规范》中关于开发者向用户提供"账户注销"功能的解读[《"账户注销"如何落地实施？》](https://www.tc260.org.cn/front/postDetail.html?id=20200617153952)。

对于元服务开发者，关于注销账号：

1、若元服务内不涉及账号体系，则无需提供注销账号服务；

2、若元服务内涉及账号体系，应根据账号使用场景，为用户提供便捷的删除非账号信息/删除用户数据服务、注销开发者自有账号服务，并明确注销对象，可参考APP常见个人信息保护问题FAQ\> [账号注销常见问题](https://developer.huawei.com/consumer/cn/doc/app/faq-11)中关于元服务场景的介绍。
