# H5页面怎么使用华为账号手机号授权能力？

H5页面内无法使用华为账号开放能力，推荐使用HarmonyOS应用开发，规范调用[快速验证手机号Button](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/scenario-fusion-button-getphonenumber)组件。推荐使用HarmonyOS应用开发用户高频使用的界面，通过页面获取用户授权的手机号之后，参数传递给H5页面。
