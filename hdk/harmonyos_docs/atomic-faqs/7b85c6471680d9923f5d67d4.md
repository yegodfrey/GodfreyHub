# 元服务界面有多个功能入口均依赖用户先关联开发者账号才能浏览、使用，开发者可以在用户一进入元服务就向用户申请手机号授权完成账号关联吗？应该怎么优化体验？

用户进入元服务后华为账号静默登录，元服务须即点即用，用户可以查看、浏览、使用元服务常规功能。开发者须在用户意图真实发生等合理场景时，再恰当向用户收集手机号、进行账号关联，不能在用户一进入元服务还未开始浏览内容时即弹出手机号授权面板获取用户手机号。同时须避免不合理场景向用户申请非必要的权限，如不需要使用手机号场景，向用户申请手机号授权。

开发者须通过场景化授权button调用手机号授权面板和完成授权，场景化授权面板支持按钮、文本链接、icon、icon+文案的场景。

当开发者界面多个功能入口均依赖用户先关联开发者账号才能浏览、使用时，建议开发者优先进行业务流程优化，在必要环节再向用户申请手机号授权。

**不符合规范的不合理场景案例：**

用户在浏览元服务任意内容时，需要完成手机号授权才能继续浏览，但打开的页面内容无需依赖用户手机号授权
