# 元服务加载H5页面白屏可能的原因及解决方案

**可能原因**

场景一：未配置业务域名

场景二：业务域名未生效

**解决措施**

场景一：元服务通过AtomicServiceWeb加载H5页面需要[配置业务域名](https://developer.huawei.com/consumer/cn/doc/atomic-guides/agc-help-harmonyos-business-domain)，网页内iframe的域名也需要配置。

场景二：域名配置默认24小时生效。可在设置>应用和元服务>元服务>移除元服务，后重新安装立即生效。

如果仍然出现白屏，可能是页面代码问题，开发者可以使用浏览器打开对应页面验证页面是否存在问题，或者参考[使用Devtools工具调试前端页面](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/web-debugging-with-devtools)进行调试。
