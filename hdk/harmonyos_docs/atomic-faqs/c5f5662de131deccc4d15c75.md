# 如何获取code？

目前服务动态支持 2 种方式获取code：

1. 使用华为支付订单号[sysTransOrderNo](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/payment-sys-query-order)作为code（用户需在前端拉起过华为支付收银台，通过华为支付下单后获取）。对于合单支付场景，需使用子订单号作为code，多个子订单可用于激活多个卡片进行消息发送；
2. 通过前端场景化button获取code，参考[服务动态授权码Button](https://developer.huawei.com/consumer/cn/doc/atomic-guides/scenario-fusion-button-atomic-getservicecode)。
