# 针对已开发App的开发者，元服务与App的一体两面是什么关系，有什么区别？

一方面，元服务是业务的轻量级载体，更注重核心功能的体验，目的让用户能够快速完成需求闭环，无需安装，即点即用，用完即走。

另一方面，同一个业务下，App和元服务能够起到互为补充的作用，App专注私域流量的获取和转化，元服务通过HarmonyOS服务分发能力触达更多、更精准的用户。
