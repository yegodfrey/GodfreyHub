# 服务商第三方平台授权信息列表中出现名称为空的数据项

## 问题现象

将元服务授权给服务商第三方平台后，商家如果删除元服务，服务商在第三方平台查看已授权元服务的信息列表时，出现名称为空的数据项，如何解决？

## 解决方案

该问题需要商家解除授予第三方平台的已删除元服务的权限，参考[解除授权](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/manage-authorization-0000002554235495#section16971142435420)，点击"**应用授权**"页签，在需要解除授权应用的"操作"列点击"解除授权"，然后在二次确认弹窗中点击"确认"即可。
