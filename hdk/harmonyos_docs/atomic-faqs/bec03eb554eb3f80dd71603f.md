# 用户首次进入元服务时，已同意统一用户隐私声明，在用户授权手机号关联开发者账号时，还需要用户再次同意用户隐私声明吗？

元服务定位是给用户提供快捷、简单的服务，沉浸式、轻量感的体验。用户首次进入元服务触发的隐私声明弹框，在该隐私声明如果包含了本元服务完整的个人信息处理规则，用户授权手机号后不会产生超出个人信息处理规则描述的个人信息处理活动，且是用户主动点击同意操作的前提下，通常属于有效的同意。是否需要在后续业务流程中增加用户隐私声明相关的确认流程，具体以开发者的法务、隐私与监管部门沟通结果为准。
