# 元服务备案初审FAQ

#### 个人开发者异地备案时，哪些地域需要提供居住证？

证件地址非内蒙古、上海（不支持学生证备案）、浙江、广东（以及权威网站有效期限查询结果页面）、江苏、陕西（优先居住证，可学生证）、四川（需提供在四川学习、生活、工作的相关证明）、贵州、湖北、江西、福建等本地的，都需要居住证或暂住证。  

#### 企业开发者的主体负责人是否必须为法定代表人？

企业主体负责人是否必须是法定代表人，不同地域有所不同：

1）主体单位负责人必须是法定代表人：天津、内蒙古、陕西、宁夏、新疆、湖北、湖南、河南、上海、浙江、江西、贵州、重庆、云南、西藏、广西、广东、福建、黑龙江、河北、山东、青海。

2）主体单位负责人可以不是法定代表人，但必须提供授权书：吉林、山西、甘肃、江苏、安徽、四川（个体工商户不允许授权）。

3）主体单位负责人可以不是法定代表人，无需提供授权书：北京、海南、辽宁。  

#### 企业开发者的互联网信息负责人是否必须为法定代表人？

互联网信息负责人是否必须是法定代表人，不同地域有所不同：

1）互联网信息负责人可以不是法定代表人，但必须提供授权书：天津、黑龙江、上海、江苏、安徽、福建、湖北、湖南、重庆、四川、贵州、陕西、青海、宁夏。

2）互联网信息负责人可以不是法定代表人，无需提供授权书：北京、河北、山西、内蒙古、辽宁、吉林、浙江、江西、山东、河南、广东、广西、海南、云南、西藏、甘肃、新疆。  

#### 哪些情况涉及前置审批？

元服务服务范围/元服务名称/元服务类目等涉及前置审批，需提前获取前置审批，各地域前置审批要求或有所不同，请基于备案地要求进行操作。  

#### 同一主体下待备案的元服务名称可否与已备案的快应用同名？

不行，元服务备案目前采用的备案模式在监管后台是快应用模式，同一名字的元服务不能通过备案校验及审核，建议改名后提交；如一定要使用相同的名字，可使用APP模式进行备案

（如已完成相应HarmonyOS APP备案，可参考[APP备案FAQ（备案通过后，备案号多久能在元服务上展示出来？）](#section15221034117)直接在此备案基础上进行）。  

#### 元服务命名方面有哪些注意事项？

元服务命名需满足[《元服务命名规范》](https://developer.huawei.com/consumer/cn/doc/atomic-guides/atomic-service-naming-conversion)。  

#### 可否使用元服务APP ID进行备案？

不行，必须使用元服务包名（格式：com.atomicservice.APP ID），备案通过后才能在AG上架时通过备案校验。  

#### 为何备案通过，但AG上架时备案校验却不通过？

管局备案状态更新时差会导致AG上架备案校验不通过，管局备案变更状态更新至少有半天时差，最好在备案通过后第二天提交AG上架审核。  

#### 营业执照及身份证等证件照有什么要求？

需要最新的有效证件，彩色件（扫描件亦可），拍入边框，且关键信息清晰。  

#### 备案通过后，备案号多久能在元服务上展示出来？

备案通过后，需在上架流程"备案信息"处对本元服务的备案情况进行校验，校验通过且上架后备案号即可在元服务档案页上展示出来。
