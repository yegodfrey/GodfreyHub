# 发起订阅消息时，如何处理标题相同的模板？

相同模板标题的订阅消息发送机制：若返回的公共模板id相同或者模板名称相同，则按照开发者传入的实例模板id顺序进行过滤掉，只保留第一个。同时将被过滤掉的实例模板id返回给开发者。如开发者传入['10001','10002','10003']，其中10001和10003公共模板id是相同的，则本次只展示10001和10002，10003被过滤掉。订阅最终结果可以为[{'10001':'ACCEPTED','10002':'ACCEPTED','10003':'FILTERED'}]。
