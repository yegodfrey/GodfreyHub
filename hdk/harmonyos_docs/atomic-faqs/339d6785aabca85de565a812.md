# 开发者怎么在元服务中使用开发者账号体系？

当开发者需要在元服务中使用开发者账号体系时，可以用手机号作为账号关联的媒介，将开发者账号与华为账号建立直接的关联关系，进而同步和展示用户在开发者账号下的数据资产，向用户提供更好的服务和用户体验。

最佳设计实践：

1. 通过手机号进行账号关联 ![](https://media:801782453029505447 "点击放大")

   <br />

2. 开发者账号存在手机号、邮箱、工号等多种体系时，优先以手机号进行账号关联 ![](https://media:801782453029899448 "点击放大")

注：元服务的华为账号体系下，开发者须规范账号相关界面用语，须避免使用"注册"、"登录"、"退出"等字样，避免用户对多账号体系的理解产生歧义，须对应使用"创建"（如，在账号相关文档中可描述"用于同步安朴酒店会员账号数据资产，或创建安朴酒店会员账号"）、"关联"（如"关联安朴会员"、"关联猫眼账号"）和"退出关联"字样。

相关术语使用可查看下表：

表：账号相关设计语言的统一口径参考  

|---------|-------------------------------------------------------------------------------------------------|---------------------------------|----------------------------------------------------------------------------------------------------------------------------|
|设计语言统一口径|定义说明|使用场景|使用方法和建议|
|登录|使用任意元服务时，用户设备必须先登录华为账号。元服务开发者需要构建用户体系时，须使用华为官方提供的登录能力，获取华为账号提供的用户身份标识，创建元服务用户。|用户打开元服务后，完成静默登录|开发者在用户首次进入元服务同意用户隐私声明后，调用登录API进行静默登录，并获取用户的身份标识 UnionID/OpenID 以开展服务。 开发者界面应避免使用"登录"字样，相关场景描述须改成"关联"。|
|退出登录|元服务开发者禁止操作退出华为账号登录，HarmonyOS系统仅提供通过系统设置等方式退出华为账号登录的能力。用户退出华为账号登录后，所有元服务将无法访问使用。|用户从系统设置将华为账号退出登录|元服务须静默登录华为账号，开发者应避免使用"退出登录"字样；需退出与华为账号关联的开发者账号时，建议使用"退出关联|
|授权手机号|用户部分业务活动仅用户UnionID/OpenID无法满足服务履约，需要用户授权手机号，开发者可向用户申请手机号授权，经过用户同意后，开发者才可获得由平台验证后的手机号，进而为用户提供相应服务。|涉及手机号授权的场景，如外卖、网约车、支付、关联开发者账号等场景。|用户对于索要手机号等敏感信息，天然带有抵触、反感情绪，对于元服务的设计，我们建议在用户意图真实发生以及必备权限以实现服务提供时，恰当向用户申请手机号授权。|
|关联XX账号/会员|通过手机号，将用户在开发者账号体系下的账号与华为账号UnionID建立关联，以同步用户在其他平台、客户端的用户信息和数据资产到当前元服务。|需要将开发者账号与华为账号建立"关联"关系的场景，如关联奈雪会员|开发者可以在必要的业务环节或"我的"页面，通过调用Scenario Fusion Kit提供的手机号授权场景化Button组件，拉起规范的手机号授权面板，向用户申请获取手机号授权，根据业务需要，通过手机号作为媒介，将开发者账号与华为账号建立关联关系|
|退出关联|用户关联开发者账号后，退出华为账号下关联的开发者账号|需要退出关联账号的场景|退出华为账号下关联的开发者账号，用户界面不再呈现开发者账号下的数据资产和会员权益，需重新关联以恢复。|
|切换XX账号|用户华为账号关联开发者账号1后，切换到另一个开发者账号2|切换关联的开发者账号的场景|须先解除当前关联的开发者账号，再关联新的开发者账号。 开发者可通过调用Scenario Fusion Kit提供的手机号授权场景化Button组件，拉起规范的手机号授权面板，选择需要关联的手机号向用户申请获取手机号授权。|
