# 服务动态卡片支持展示动态更新的图片吗？

不支持。卡片上展示的图片，需使用华为统一分配的商品图片资源ID（SKUId），详见[申请图片资源托管](https://developer.huawei.com/consumer/cn/doc/atomic-guides/push-as-timeline#section19921168203013)。
