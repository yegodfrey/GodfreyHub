# 手机号授权是永久授权吗，什么时候需要重新向用户申请授权？

华为账号手机号授权仅提供单次授权能力，即元服务开发者每次获取手机号授权都要向用户申请。对于单次授权，在用户授权后，元服务开发者即可获取到用户的手机号，可建立"华为用户(openID/unionID)-手机号-开发者用户账号"的关联关系，在用户再次打开元服务时，开发者通过静默登录拿到openID/unionID，可以通过上述关联关系，识别到对应的开发者用户账号，继续为用户提供服务，不需要重新向用户获取手机号。

元服务开发者获取过手机号后，可根据业务诉求判断是否需要再次向用户申请授权。在用户手机号没失效、没有触发风控等场景，则不需要重新向用户申请手机号授权。异常情况（如距上次获取手机号已经经过X个月、用户更换了华为账号或开发者账号手机号等），开发者认为需要重新校验用户的手机号，则可让用户重新点击button组件授权获取手机号。
