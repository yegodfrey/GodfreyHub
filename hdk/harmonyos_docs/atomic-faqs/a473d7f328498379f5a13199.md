# 开发元服务对开发成本/周期有什么影响？代码复用要怎么设计？

HarmonyOS代码复用及代码量评估模型：

业界TOP平台小程序页面：小程序页面以功能/特性按需HarmonyOS代码适配，页面需重写。工作量按照1:0.7评估。

HarmonyOS应用代码：元服务仅能使用元服务API集，应用代码需将调用了非元服务API集代码适配，工作量按移植代码计算30%代码量。元服务代码可直接给应用复用。
