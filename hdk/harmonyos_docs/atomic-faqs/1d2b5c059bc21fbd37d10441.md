# 元服务API 9和API 11有什么区别，如何升级到API 11？

> 说明
>
> 请避免基于API 9进行元服务开发。

1. 元服务API 9和 API 11的区别：
   * 兼容性：API 9仅支持 HarmonyOS 4.0及以下版本，而无法在 HarmonyOS NEXT及以上版本上运行。API 11包含了HarmonyOS NEXT元服务所需的全部 API集。
   * 功能性：API 11引入了更多功能和改进，确保元服务在最新的HarmonyOS环境中高效运行和兼容新特性。
2. 如何升级到API 11：请参考官方开发者网站，下载最新的[开发工具套件](https://developer.huawei.com/consumer/cn/download/)。
