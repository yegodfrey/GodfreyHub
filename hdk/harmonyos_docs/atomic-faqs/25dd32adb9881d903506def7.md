# 元服务的服务商城已经有了吗？

元服务上架请参考元服务开发接入指南及应用市场相关的指导（联系HarmonyOS开发者技术支持申请权限）。系统通过应用市场、负一屏、小艺等的发现/推荐/搜索等华为众多与用户的触点实现元服务的多入口分发。加上服务直达的特征，消费者可以更为方便快捷的使用到元服务。
