# 元服务的包大小是2MB么？

整体包体积不超过10MB（可申请突破）。分包情况下，首包及子包不超过2MB。详细请参见[分包](https://developer.huawei.com/consumer/cn/doc/atomic-guides/atomic-subcontract)。
