# 元服务AtomicServiceEnhancedWeb如何调试前端页面

## 问题现象

元服务使用AtomicServiceEnhancedWeb组件时，如何调试前端页面？

## 背景知识

[AtomicServiceEnhancedWeb](https://developer.huawei.com/consumer/cn/doc/atomic-guides/atomicserviceweb-guidelines#atomicserviceenhancedweb)是[AtomicServiceWeb](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ohos-atomicservice-atomicserviceweb)的增强版，为开发者提供Web页面加载、页面交互、更多H5高阶开放能力等，保障开发者在H5混合ArkTS开发的场景有更加连续的体验。在元服务内，可使用AtomicServiceEnhancedWeb组件显示Web页面，且需要[配置业务域名](https://developer.huawei.com/consumer/cn/doc/atomic-guides/agc-help-harmonyos-business-domain)。AtomicServiceEnhancedWeb不需要注入ASCF框架即可运行，具体参考[开发指南](https://developer.huawei.com/consumer/cn/doc/atomic-guides/develop-atomicserviceenhancedweb)。

## 解决方案

AtomicServiceEnhancedWeb组件支持和ArkWeb一样的devtools调试能力，具体操作步骤如下：

1. 在DevEco Studio中找到当前元服务的进程id。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/97/v3/3KksB4SCRvyhaxo95WRRrQ/zh-cn_image_0000002628558362.png?HW-CC-KV=V1&HW-CC-Date=20260910T055430Z&HW-CC-Expire=31536000000&HW-CC-Sign=3A34D5289EDFCFFD93A5DE802B4BF5440163D498AE53016BAF86C2FA7A2CD409 "点击放大")

2. 在命令行里执行如下命令转发端口： hdc fport tcp:9222 localabstract:webview_devtools_remote_18526。

   > 说明
   >
   > "webview_devtools_remote_"后面的数字（18526）为第一步查到的元服务进程号。
3. 在Chrome浏览器上输入chrome://inspect/#devices，[打开调试工具页面](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/web-debugging-with-devtools#在chrome浏览器上打开调试工具页面)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/40/v3/P9O4APnuSYuzasWancneHQ/zh-cn_image_0000002628398450.png?HW-CC-KV=V1&HW-CC-Date=20260910T055430Z&HW-CC-Expire=31536000000&HW-CC-Sign=C4DE8DDF9EED85AC1D709475951CD976709333072FF54F755A6780DD3E6BFC25 "点击放大")
4. 点击inspect开始调试页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8d/v3/p7HgewYSSR-jaqC3xo0Onw/zh-cn_image_0000002658917673.png?HW-CC-KV=V1&HW-CC-Date=20260910T055430Z&HW-CC-Expire=31536000000&HW-CC-Sign=34D009ED729CAD1DEF4C20DDA3E5BD5AFA0731500A2B96377A74B0C1AF5DB444 "点击放大")

## 常见FAQ

Q：如何判断hdc fport是否执行成功，有哪些常见的返回信息？

A：hdc fport命令执行成功会输出Forwardport result:OK，其他返回信息详见[创建正向端口转发任务](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/hdc#创建正向端口转发任务)介绍。
