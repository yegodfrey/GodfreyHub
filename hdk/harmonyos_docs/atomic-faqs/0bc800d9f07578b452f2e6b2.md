# 怎么接入平台统一的用户协议和隐私声明？

为了规范元服务处理用户个人信息的行为，满足监管合规要求并保障用户的合法权益，以及规范化、标准化隐私声明内容，提升元服务审核通过率，在提交元服务上架时，需在"版本信息"页面填写隐私声明。支持您基于AGC提供的标准隐私声明模板生成自己的隐私声明，后续在提交上架申请时，您只需勾选该隐私声明即可。如开发者的HarmonyOS应用/元服务使用了隐私声明托管服务，则还需另外填写用户协议以供应用/元服务首次弹框使用，否则将无法提交审核。相关接入指南请参阅[标准化隐私声明托管服务](https://developer.huawei.com/consumer/cn/doc/app/agc-help-privacy-policy-app-0000002282162168)。
