# 开发者如何获取用户的模板订阅状态？

开发者在元服务内基于用户主动操作发起订阅请求，可通过[RequestResult](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/push-servicenotification#requestresult)接口查询用户的模板订阅结果，当返回的ResultCode为0时，表示用户同意订阅，元服务可基于账号向用户推送服务通知消息；若返回其他值，则表示订阅未成功。详情请参考[ResultCode](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/push-servicenotification#resultcode)
