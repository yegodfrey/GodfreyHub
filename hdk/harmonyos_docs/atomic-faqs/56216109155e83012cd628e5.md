# 想使用华为账号服务的API，需要先注册元服务吗？注册元服务到哪个阶段可以使用账号服务？

需要先注册元服务再开发，注册成功后即可调用华为账号登录API，获取用户的OpenId/UnionID。

如需获取头像、昵称、手机号可参见原有[申请流程](https://developer.huawei.com/consumer/cn/doc/atomic-guides/account-atomic-client-id)。
