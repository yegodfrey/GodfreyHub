# 为什么要做切换？

为给用户提供更安全更规范的交互体验，手机号授权获取方式需切换为Button组件方式；同时，元服务平台将于2025年5月30日下线手机号授权获取的API，下线后，以API方式获取手机号授权将不可用，为避免影响元服务获取手机号授权的业务能力，需要使用了API方式获取手机号授权的元服务开发者在此日期之前完成相应元服务从API方式向Button组件方式的切换。
