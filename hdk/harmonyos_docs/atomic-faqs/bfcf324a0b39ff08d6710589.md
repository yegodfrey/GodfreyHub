# 元服务H5如何调用页面方法

AtomicServiceWeb后续将不再支持[registerJavaScriptProxy](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-webview-webviewcontroller#registerjavascriptproxy)、[runJavaScript](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-webview-webviewcontroller#runjavascript)等接口，开发者可以通过JS SDK提供的接口获取相关数据。

|----|-------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------|
|图片|[has.cameraPicker.pick()](https://developer.huawei.com/consumer/cn/doc/atomic-guides/components-atomicserviceenhancedweb#hascamerapickerpick)|拍照或录像。|
|图片|[has.photoViewPicker.select()](https://developer.huawei.com/consumer/cn/doc/atomic-guides/components-atomicserviceenhancedweb#hasphotoviewpickerselect)|拍照或选择图片。|
|文件|[has.filePreview.openPreview()](https://developer.huawei.com/consumer/cn/doc/atomic-guides/components-atomicserviceenhancedweb#hasfilepreviewopenpreview)|预览文件，只支持预览本地文件。|
|上传下载|[has.request.uploadFile()](https://developer.huawei.com/consumer/cn/doc/atomic-guides/components-atomicserviceenhancedweb#hasrequestuploadfile)|上传文件。|
|上传下载|[has.request.downloadFile()](https://developer.huawei.com/consumer/cn/doc/atomic-guides/components-atomicserviceenhancedweb#hasrequestdownloadfile)|下载文件|
|网络|[has.connection.getNetworkType()](https://developer.huawei.com/consumer/cn/doc/atomic-guides/components-atomicserviceenhancedweb#hasconnectiongetnetworktype)|获取网络状态。|
|地理位置|[has.location.getLocation()](https://developer.huawei.com/consumer/cn/doc/atomic-guides/components-atomicserviceenhancedweb#haslocationgetlocation)|获取当前地理位置。|
