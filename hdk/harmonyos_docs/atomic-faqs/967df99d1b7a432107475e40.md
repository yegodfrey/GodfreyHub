# HarmonyOS 4.4及以前版本升级到HarmonyOS NEXT版本后的历史数据适配留存策略

HarmonyOS 4.4及以前版本升级到HarmonyOS NEXT版本不兼容，以前的元服务要在NEXT上使用API 11+重新开发。
