# 业务域名配置失败可能的原因及解决方案

问题现象一

界面提示：处理请求时发生未知错误，请稍后重试。

解决措施

业务域名配置请将下载的配置文件（配置文件以"APPID.txt"格式命名，例如您的元服务APPID为XXX，则下载的配置文件名称为"XXX.txt"）放置到域名根目录下，例如"test.com.cn/XXX.txt"，并须确保可以成功访问该配置文件。

问题现象二

界面提示"输入内容包含非法域名"，可点击提示信息旁边的"查看详情"查看详细的错误提示信息。

可能原因

该域名未把配置文件放在域名根目录下

解决措施

1. 若在域名根目录下新建APPID.txt命名的配置文件，确保复制的内容要新增空格、换行等，否则配置文件无法生效。
2. APPID.txt的校验暂不支持CFCA证书的域名，请更换证书。
