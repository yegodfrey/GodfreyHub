# 业务域名配置数量超过10个如何处理？

当前业务域名配置支持配置父域名，放开所有子域名，例如：配置https://huawei.com，匹配所有huawei.com下的子域名，如https://123.huawei.com，不区分协议和端口。

若业务域名配置数量还不能满足您的需求，您可发送邮件向华为运营人员申请放宽限制。在收到您的申请后，华为运营人员将在1-3个工作日内为您安排对接人员。申请方法如下：

1. 申请邮箱地址：atomicservice@huawei.com。
2. 邮件标题：[业务域名配置]-[元服务名称]-[APP ID]-[Developer ID]，APP ID等查询方法可参见[查看应用基本信息](https://developer.huawei.com/consumer/cn/doc/app/agc-help-appinfo-0000001100014694)。
3. 邮件正文：请说明申请使用哪些域名及必要性。
