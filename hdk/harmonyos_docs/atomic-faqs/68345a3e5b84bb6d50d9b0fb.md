# 静默登录对开发者有什么价值？通过登录API，可以获取用户的手机号吗？

元服务静默登录是华为官方提供的账号能力，能帮助开发者方便地获取用户身份标识，快速建立元服务内的用户体系，也是华为账号开放能力及元服务平台能力使用的基础。元服务开发者可通过登录API获取用户的身份标识UnionID、OpenID等用户数据，完成华为账号静默登录，有利于提高元服务的获客、转化和留存。根据UnionID、OpenID可进一步使用平台提供的获取手机号能力、支付能力、元服务留存和复访能力（如服务通知）。此外，在换机、多设备等场景下，平台基于华为账号实现元服务数据资产跨端同步，实现用户在多端上即点即用和数据继承。

当元服务需要获取或完善用户个人资料（头像、手机号、收货地址、发票抬头）时，可通过华为账号提供的相关能力，引导用户填写、管理相关信息并完成授权，以[获取华为账号用户信息](https://developer.huawei.com/consumer/cn/doc/atomic-guides/account-guide-atomic-get-user-info-overview)。
