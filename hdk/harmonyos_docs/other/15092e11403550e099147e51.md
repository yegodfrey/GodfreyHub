# 响应式布局方案

我们关注到大多数应用在折叠屏展开态上存在内容拉伸放大的现象，针对这一问题我们提供了一套具备响应式能力的控件，帮助开发者对android页面的局部区域进行快速的适配, 从而避免应用内容被过量放大的现象。

#### 重复布局

布局特点：利用屏幕的宽度优势，将相同属性的布局组件横向并列同时排布。

适用场景：内容运营类列表信息，例如歌单列表、应用列表等。

适配规则：可以定义单个元素的宽度规则，随着屏幕宽度的变化，⾃动计算可以重复的元素的个数，满足宽度条件时横向重复排列。

**代码接入方式**

动态创建：本方法可以在逻辑代码中直接生成相关的控件。

     1. 导入控件包
            
            import com.huawei.rspuikit.androidn.hwrsplinearlayout.widget.HwRspLinearLayout

     2. 代码由继承LinearLayout改为继承HwRspLinearLayout或者通过new HwRspLinearLayout直接使用，代码使用方式示例如下
            
            @Override
            protected void onCreate(Bundle savedInstanceState) {
                    super.onCreate(savedInstanceState);
                    setContentView(R.layout.activity_hwrsplinearlayout);
                    HwRspLinearLayout mMainLayout = findViewById(R.id.hw_rsp_linearlayout);
                    mMainLayout.setOrientation(LinearLayout.VERTICAL);
                    mMainLayout.setRspEnable(true);
                    mMainLayout.setRspItemSpace(10);
                    // 设置展开态列数
                    mMainLayout.setRspColNum(4);
                }

**接口能力**

响应式控件扩展并兼容原生LinearLayout控件接口，扩展控件接口及说明如下表。

接口函数 | 输入 | 输出 | 返回值 | 接口具体描述 | 接口范围  
---|---|---|---|---|---  
setRspColNum | int rspColNum | 无 | void | 响应式控件列数设置 | HwRsplinearlayout控件使用，不配置默认2  
setRspEnable | boolean isRspEnable | 无 | void | 使能响应式能力配置 | HwRsplinearlayout控件使用，不配置默认false  
setRspItemSpace | int | 无 | void | 响应式控件每列元素之间间距设置 | HwRsplinearlayout控件使用，不配置默认0（如果不设置，元素间距使用用户设置的margin，设置后则元素间距使用设置值）

**瀑布布局**

布局特点：利用屏幕的宽度优势，将原来单列纵向布局，拓展为两列或多列的纵向布局。

适用场景：适合用卡片呈现内容的场景，通过卡片的横纵扩展在⼤屏上展示更多内容。

适配规则：可以定义单个组件的宽度规则，随着页面宽度的变化，⾃动计算可以重复的卡片个数，满足条件时横向排列更多卡片。

针对瀑布布局特点，华为提供了多种类型的响应式控件来满足不同的场景诉求。主要包括以下响应式GridView、ListView和RecyclerView。

HwRspViewPager提供了androidx包下的和support V7包下的ViewPager的支持。

     * androidx引入AAR包：
           
           implementation "com.huawei.ui.rspuikit:hwrspviewpager-androidsupx:{version}"

     * support V7引入AAR包：
           
           implementation "com.huawei.ui.rspuikit:hwrspviewpager-androidsup:{version}"

**接入HwRspViewPager**

     * 如果应用直接使用ViewPager，则直接在代码和layout布局文件中将ViewPager替换成HwRspViewPager：
           
           <com.huawei.rspwidget.androidsupx.viewpager.HwRspViewPager
                   android:background="@id/view_pager"
                   android:layout_width="match_parent"
                   android:layout_height="wrap_content"
                   app:rsp_need_adjust="true"
                   />

     * 如果自定义View继承了ViewPager，在代码里把继承关系中的ViewPager替换成HwRspViewPager：
           
           import com.huawei.rspwidget.androidsupx.viewpager.HwRspViewPager;
           
           public class LooperViewPager extends HwRspViewPager

     * 如果应用还重写了onMeasure或者调用了onMeasure方法，需要将方法名改为onMeasure2，否则编译不通过：
           
           @Override
               protected void onMeasure2(int widthMeasureSpec, int heightMeasureSpec) {
                   super.onMeasure(widthMeasureSpec, heightMeasureSpec);
               }

    setAdapter(new HwRspPagerAdapter() {
                @Override
                public Object instantiateItem(@NonNull ViewGroup container, int position) {
                    super.instantiateItem(container, position);
                }
            });

可配置参数的说明和使用方式见下表：

参数名 | 参数类型 | 参数取值 | 参数说明  
---|---|---|---  
rsp_need_adjust | boolean | 取值：true/false 默认：true | 大屏下是否需要执行响应式逻辑  
rsp_adjust_type | enum | 取值：center 默认：center | 使用哪种范式来调整ViewPager，默认使用居中的方式  
rsp_indicator_view_id | integer | 默认：null | 导航点View ID  
rsp_page_margin | integer | 默认：null | Item间距，见图5中的PM。如果用户未指定，则使用小屏下设置的值，如果还未设置，则使用默认值12dp  
rsp_width_adjust_mode | enum | 取值： un_change/scale/aspect 默认：null | 单个Item的宽调整策略： un_change：宽不变，IW_NEW=IW scale：按照配置rsp_scale_width缩放，IW_NEW=IW* rsp_scale_width aspect：按照配置rsp_aspect依据高等比缩放，IW_NEW=IH_NEW* rsp_aspect  
rsp_scale_width | float | 默认：null | 宽缩放大小，如果未配置则默认为0.5  
rsp_height_adjust_mode | enum | 取值：un_change/scale/aspect 默认：null | 参见rsp_width_adjust_mode  
rsp_scale_height | float | 默认：null | 高缩放大小，如果未配置则默认为0.5  
rsp_aspect | float | 默认：null | 单个Item的高宽比，如果未设置则使用ViewPager的高宽比：VPH/VPW  
rsp_off_page_limit | integer | 默认：null | Item的缓存数量，不设置则使用系统默认值  
rsp_one_page_item_cnt | Integer | 默认：null | 一页完整显示多少个Item，参见图二的两张卡片。不设置则使用默认值2  
  
说明：以上参数都可以通过两种方式使用

方式一：在layout布局文件中配置

方式二：在代码中通过HwRspViewPager.getConfig().setXXX来配置

**FAQ:**

**使用华为响应式控件是不是会对其他厂商的设备产生影响？**

华为响应式控件是继承android原生控件的基础上新增了在折叠屏上响应式的能力，在其他厂商设备上不会开启该新增的能力，会走原生的android控件绘制流程，并不会对其他厂商的设备产生影响。
