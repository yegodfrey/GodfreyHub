# 生活服务类场景  
  
生活服务类场景主要包括购物、出行、生活服务等类型的应用。

此类场景旨在让用户享受大屏幕的高效交互。需要避免出现大图片、大字体、大卡片等，导致大屏幕上交互效率更低。建议开发者重点关注首页、推荐列表页、详情页和广告弹窗等，有针对性地适配以提高用户体验。

#### 首页&推荐列表页

在折叠态到展开态，建议采用自适应布局、重复布局等进行页面的显示适配，以保证在一屏内向用户展示更丰富的内容，充分利用大屏的空间，提高浏览效率。不建议直接放大内容元素，导致出现大图片大字体等问题，既影响了应用的质感和美观，也不利于高效浏览。

推荐列表类页面，在展开态建议通过更多的列数，提升推荐效率，避免折叠展开列数不变，导致列表中的图片过大。

#### 详情页

在详情页中，页面的核心图片往往放置于顶部位置，图片支持左右滑动翻看。在展开态下，为了避免图片撑满屏幕宽度后过大，建议开发者调整图片显示数量，在图片两侧增加上一张、下一张图片的部分画面。不建议直接将图片放大，导致一屏幕显示信息过少。

#### 广告弹窗

弹出框在该场景中较为常见。建议展开态和折叠态弹出框保持相同的大小，或最大不超过原来的1.2倍。不建议弹出框直接放大太多，导致显示不全或无法交互。
