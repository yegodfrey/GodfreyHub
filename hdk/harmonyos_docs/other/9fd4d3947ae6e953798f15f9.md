# H5类场景  
  
H5类页面常见于各种小程序或网页版应用，针对此类场景，开发者应该尽量保证页面内容适应屏幕宽度显示。

#### 内容元素自适应布局

在此类页面中，开发者应保证页面元素适应屏幕宽度显示，建议采用自适应布局。文字、图标等元素在保持折叠态大小的前提下，对元素间距进行适当拉伸。此外，还可以采用延伸布局、挪移布局、重复布局等对页面进行适配。不建议页面保持折叠态样式左右留白，导致屏幕空间的浪费。

#### 背景自适应布局

部分H5页面中有明显的带色彩或图片的背景，需要将背景和内容信息分层，背景和内容均适配宽屏的显示。
