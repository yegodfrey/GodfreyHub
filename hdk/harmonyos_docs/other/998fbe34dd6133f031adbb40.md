# 游戏类场景

游戏垂类应用界面需按照游戏类型和场景分类，实施最优化布局，获得最佳用户体验效果。

#### 益智类游戏

建议游戏元素居中，背景采用自然和谐的颜色填充方案。

杜绝以下几种严重影响用户体验的方案：

     * 侧边加广告展示 
     * 两侧留黑边

#### 视界拓展类游戏

     * 非对战类和无游戏公平性约束的游戏，采用“横向内容保持，纵向视野拓展”视界拓展方案，让用户获得更大视野的沉浸式效果。 
     * 对战类游戏且存在游戏公平性约束条件的游戏，采用“横向内容裁剪，纵向视野补偿”，且补偿视界面积不小于裁剪面积，既满足了游戏公平性诉求，也适配了展开态大屏特殊比例。
