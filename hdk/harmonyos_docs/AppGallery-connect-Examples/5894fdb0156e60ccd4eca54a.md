# iOS

本Xcode工程包含了Objective-C语言的示例代码，提供了使用云数据库实现数据的新增、修改和删除等功能。

|名称|Gitee|GitHub|
|:--------------|:-------------------------------------------------------|:-------------------------------------------------------|
|Objective-C示例代码|[链接](https://gitee.com/appgallery_connect/agc-ios-demos)|[链接](https://github.com/AppGalleryConnect/agc-ios-demos)|

> 注意
>
> * 在运行示例代码前，请先完成README文件中的准备工作。
> * 如果您需要直接运行示例代码，请注意以下两点： 1. 必须下载自己应用的agconnect-services.plist文件，拷贝到示例工程的根目录下。
>
>   2. 需要执行 'pod install' 命令为工程添加依赖库。
