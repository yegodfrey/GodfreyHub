# HarmonyOS

该DevEco Studio工程包含了Java语言的示例代码，提供了测试崩溃实现的功能。

|名称|Gitee|GitHub|
|:-------|:-------------------------------------------------------------|:-------------------------------------------------------------|
|Java示例代码|[链接](https://gitee.com/appgallery_connect/agc-HarmonyOS-demos)|[链接](https://github.com/AppGalleryConnect/agc-HarmonyOS-demos)|

> 注意
>
> 如果您需要直接运行示例代码，请注意以下两点：
>
> 1. 必须下载自己应用的agconnect-services.json文件，拷贝到示例工程的应用级根目录下。
>
> 2. 需要修改示例工程中应用级config.json中的bundleName为开发者自己的应用包名。
>
> 详细说明请参考示例工程中的README文件。
