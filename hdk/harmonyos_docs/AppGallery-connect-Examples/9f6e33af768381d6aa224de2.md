# Android

该Android Studio工程包含了Java和Kotlin语言的示例代码，提供了创建和查看分析应用内消息的功能。

|名称|Gitee|GitHub|
|:--------------|:----------------------------------------------------------------------------------|:----------------------------------------------------------------------------------|
|Java/Kotlin示例代码|[链接](https://gitee.com/appgallery_connect/agc-demos/tree/main/Android/appmessaging)|[链接](https://github.com/AppGalleryConnect/agc-demos/tree/main/Android/appmessaging)|

> 说明
>
> 如果您需要直接运行示例代码，请注意以下两点：
>
> 1. 必须下载自己应用的agconnect-services.json文件，拷贝到示例工程的应用级根目录下。
> 2. 需要修改示例工程中应用级build.gradle中的applicationid为开发者自己的应用包名。
>
> 详细说明请参考示例工程中的README文件。
