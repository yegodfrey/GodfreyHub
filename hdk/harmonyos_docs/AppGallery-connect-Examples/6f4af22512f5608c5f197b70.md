# HarmonyOS

该DevEco Studio工程包含了TypeScript语言（API9及以上）的示例代码，提供了在HarmonyOS端使用云存储服务进行上传、删除文件等功能。

|名称|Gitee|GitHub|
|:----------------------|:--------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------|
|TypeScript示例代码（API9及以上）|[链接](https://gitee.com/appgallery_connect/agc-HarmonyOS-demos/tree/master/OpenHarmony/cloudstorage)|[链接](https://github.com/AppGalleryConnect/agc-HarmonyOS-demos/tree/master/OpenHarmony/cloudstorage)|

> 说明
>
> 如果您需要直接运行示例代码，请注意以下两点：
>
> 1. 必须下载自己应用的agconnect-services.json文件，拷贝到示例工程的应用级根目录下。
> 2. 需要修改示例工程中应用级config.json中的bundleName为开发者自己的应用包名。
>
> 详细说明请参考示例工程中的README文件。
