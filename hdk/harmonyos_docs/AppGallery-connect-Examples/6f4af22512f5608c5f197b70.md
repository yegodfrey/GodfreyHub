# HarmonyOS

该DevEco Studio工程包含了TypeScript语言（API9及以上）的示例代码，提供了在HarmonyOS端使用云存储服务进行上传、删除文件等功能。

2. 需要修改示例工程中应用级config.json中的bundleName为开发者自己的应用包名。
