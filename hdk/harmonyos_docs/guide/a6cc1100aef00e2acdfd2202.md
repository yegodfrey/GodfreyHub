# 源码下载时，提示“Download code-xxx.tar.gz timeout”

#### 问题现象

新建工程，下载源码时失败，并提示“Download code-xxxx.tar.gz timeout!

Error: failed to download the image resource: Download code-xxxx.tar.gz timeout!”

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102434.15209229688147694771841116947051:50001231000000:2800:D8C707AACA65F36983BA5306B74727E26177565CC9ACDB1342682B2ECD094B57.png?needInitFileName=true?needInitFileName=true)

#### 解决措施

出现以上问题，通常为网络存在问题。请参考以下步骤确认网络状态并配置代理。

     1. 在输出控制区的右上角点击+，在终端窗口输入命令：ping repo.huaweicloud.com，如果回显多条“64 bytes from xxx”则网络正常，否则，如下图所示，网络不可达，请检查网络设置。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102434.21451083582606994557557430086625:50001231000000:2800:1C5E34E665940DA0FCD5062781F27010BD1AF458B44521EE723905D9B97EAA94.png?needInitFileName=true?needInitFileName=true)

     2. 如果网络不能直接访问Internet，需要通过代理服务器才可以访问，请在Ubuntu环境的用户目录下，执行以下命令，打开**.bashrc** 文件并在**.bashrc** 文件添加export HTTPS_PROXY=your_proxy，其中your_proxy请根据实际情况填写。
            
            vim ~/.bashrc

     3. 重启Ubuntu环境。
     4. 在本地Window平台的VS Code重新[连接远程Ubuntu环境](https://device.harmonyos.com/cn/docs/documentation/guide/ide-install-windows-ubuntu-0000001194073744#section128105597379)。
