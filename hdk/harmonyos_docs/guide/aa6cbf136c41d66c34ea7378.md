# 导入OpenHarmony源码

Import Project适用于打开DevEco Device Tool创建的工程项目和导入[获取的OpenHarmony源码](https://gitee.com/openharmony/docs/blob/master/zh-cn/device-dev/get-code/sourcecode-acquire.md)。如果是导入OpenHarmony源码，在打开工程时，点击**Import** **Project** ，然后配置产品和Ohos版本号即可。

#### 导入源码

     1. 打开DevEco Device Tool，进入Home页，点击**Import Project** 打开工程。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102406.68141329010660055700901276168390:50001231000000:2800:C699B0E02ECB1149EEBFEA4B6B4673466EE6B47B55F1D075B2153515840B52A4.png?needInitFileName=true?needInitFileName=true)

     2. 选择OpenHarmony源码根目录路径，然后再选择**Import OpenHarmony Source** 选项，点击**Import** 进行导入。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102406.88484781249831137360029251962414:50001231000000:2800:B080F4C7C26E29381E38F3EFB1E7F241359BC2BC21631F30D8F24E3D0BCEC2F4.png?needInitFileName=true?needInitFileName=true)

工程存储路径不能包含中文字符、空格。如果工程存储路径包含中文字符或空格，可能导致编译失败。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102407.34468552857372925593237140232132:50001231000000:2800:7C417EB90A53CEF8C5FCD9DB3C0D13C00259B453724BEFD23A4423C13155A87E.png?needInitFileName=true?needInitFileName=true)

     3. 在Import Project界面，选择**Product** 后，会自动填充对应的SOC、Board、Company和Kernel信息，然后Ohos Ver选择对应的OpenHarmony源码版本。OpenHarmony源码支持的**Product** 详细信息，请参考[OpenHarmony支持的产品列表](https://gitee.com/openharmony/docs/blob/master/zh-cn/device-dev/quick-start/quickstart-appendix-compiledform.md)。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102407.31179444335360074425598072254497:50001231000000:2800:320EC8599E90DEF7AE8A3798E26575FD6432FB76C1E4018B1AB2184AC75277D5.png?needInitFileName=true?needInitFileName=true)

        * 该列表展示的OpenHarmony Master主干支持的产品，如果您使用的是其它分支版本，可能出现部分产品不支持的情况，请以各分支支持的实际情况为准。
        * 从3.1.0.600版本起，DevEco Device Tool允许用户在导入源码时暂不选择适配产品（即**Product** 设置为**No****n****e** ），此时其他配置项不可配置。其设备绑定操作可在源码导入完成后进行。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102407.64875901750685019010528897443722:50001231000000:2800:5255D6C54EF6D5FECB9398A48972E76039337D8304498E867FA451593349B929.png?needInitFileName=true?needInitFileName=true)

     4. 点击**Open** 打开工程或源码。

#### 绑定设备

从3.1.0.600版本起，DevEco Device Tool允许用户在导入源码时暂不选择适配产品，源码导入成功后，可在任务列表中进行绑定操作。

     1. 在任务列表中单击工程对应的![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102407.66188740597754769096707473968769:50001231000000:2800:6121D2D8C0DA707E43E45B20776C7838D2AE2DF73CA73C7E24D04687479D4CA3.png?needInitFileName=true?needInitFileName=true)按钮。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102407.20740205315796180906385428344436:50001231000000:2800:2FE10D379AC4697A4352751E7CF7D8A0DBD6B7A5FCC221D17CA87C57801114EA.png?needInitFileName=true?needInitFileName=true)

     2. 在弹出的产品列表中选择要适配绑定的设备类型。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102407.43364074939783525656390843059367:50001231000000:2800:AA08AC504FEB2F4E4DA0F78FAEFA7DE8789ED95DE32E6F52A135417603AEA41C.png?needInitFileName=true?needInitFileName=true)

     3. 查看绑定设备后的任务列表。

        * 如果绑定的是OpenHarmony已适配的设备，任务列表中会展示该产品的能力子集。
        * 如果绑定的是OpenHarmony未适配的设备，DevEco Device Tool根据绑定设备的信息进行分析，在任务列表中展示某些能力子集。
