# C/C++代码编辑

DevEco Device Tool支持C/C++的代码编辑，基于C/C++插件，支持代码查找、关键字高亮、代码自动补齐、代码输入提示和代码检查等功能。详细的说明请参考[C/C++代码编辑](https://code.visualstudio.com/docs/cpp/cpp-ide)。
