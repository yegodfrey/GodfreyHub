# USB转串口驱动安装

#### 问题现象

Windows系统，在设备管理中查看串口信息，如果如下图所示，串口驱动异常，则需要安装USB转串口的驱动。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102435.58616998197788126716355869599339:50001231000000:2800:CD61E8EA4E07FBD067C19CA33EFDC61FA382E28E0F523690CC284ABF67102608.png?needInitFileName=true?needInitFileName=true)

#### 解决措施

     1. 点击[链接](http://www.hihope.org/download/download.aspx?mtt=8)下载CH341SER USB转串口驱动程序。
     2. 点击安装包，安装驱动程序。
     3. 驱动安装完成后，重新插拔USB接口，串口信息显示如下图所示。
