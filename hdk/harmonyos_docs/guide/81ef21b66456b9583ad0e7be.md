# 编译Neptune开发板源码

DevEco Device Tool支持Neptune开发板（基于W800芯片）的源码一键编译功能，提供编译工具链和编译环境依赖的检测及一键安装，简化复杂编译环境的同时，提升了编译的效率。

Neptune开发板编译环境为Ubuntu环境。

#### 前提条件

获取OpenHarmony的源码存在多种方式，具体请参考[创建OpenHarmony工程](https://device.harmonyos.com/cn/docs/documentation/guide/create_project-0000001072200151)或[导入OpenHarmony源码](https://device.harmonyos.com/cn/docs/documentation/guide/open_project-0000001071680043)。如果导入的源码是通过“repo方式”获取，在执行编译前，请执行如下脚本安装编译器及二进制工具。通过其它方式获取的OpenHarmony源码，请跳过该操作。
    
    bash build/prebuilts_download.sh

#### 操作步骤

     1. 在菜单栏中点击**Project Settings** ，进入Neptune工程配置界面。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102412.30531929748901945567143971058462:50001231000000:2800:02EECFDBDC81C1699E6A1A3930BDDE0577D874B656C92D2DA99A9A96EA8EDC3D.png?needInitFileName=true?needInitFileName=true)

     2. 在**Tool Chain** 页签中，DevEco Device Tool会自动检测环境依赖是否完备。

        * 如工具为“uninstalled”状态（![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102412.50344958404061742905962066237326:50001231000000:2800:5A272A8732EC2FEFB1E0D795CD2869EB0D3ACC8FD2E4DA2FC4ABB3B38785706D.png?needInitFileName=true?needInitFileName=true)），可单击**Download Uninstalled Tools** ，自动安装所需工具，或单击工具后方的**Dow****n****load** 安装指定工具。
        * 如当前识别到的工具类型有缺失，需要补充，可单击**Add Utility** 添加。
        * 如工具无法通过**Download** 方式直接安装，可能是由于网络原因导致。此种情况下，DevEco Device Tool无法连接到工具链下载网站，需要用户自行修复网络，或通过其他方式将正式发布的[OpenHarmony工具链安装包](https://gitee.com/openharmony/docs/blob/master/zh-cn/device-dev/get-code/sourcecode-acquire.md#获取方式3从镜像站点获取)存储到本地，单击**Import** 导入。
        * 如“OpenHarmony Environment Dependency”的状态异常（![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102412.93329220402808907798291838754232:50001231000000:2800:7033D34B079B4E07501BF99B6AAB1B5997A49F1E64CD23BA7D4AEE46E9DA9FDF.png?needInitFileName=true?needInitFileName=true)），请单击**Install** 安装。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102412.73573441261739789452624915314482:50001231000000:2800:A91D4DC06DEC5F102EA218DBA620D3E77091ED9A41E6A2992E7D3CDA346863C0.png?needInitFileName=true?needInitFileName=true)

部分依赖安装需要使用root权限，请在**TERMINAL** 窗口输入用户密码进行安装。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102412.37020776738146020617161852100326:50001231000000:2800:E8CFC8FE844364785E55B4FAE287985FD9E4A035BDAE8F1DB80E0E674F175F5F.png?needInitFileName=true?needInitFileName=true)

若出现安装pip组件失败，可参考[修改Python源的方法](https://device.harmonyos.com/cn/docs/documentation/guide/ide-set-python-source-0000001227639986)进行修改，完成尝试重新安装；

若出现安装apt组件失败，可参考[修改apt源的方法](https://device.harmonyos.com/cn/docs/documentation/guide/faq-toolchain-install-0000001301623822)进行修改，完成后尝试重新安装。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102412.78384361070071946466700168442555:50001231000000:2800:536ED841583FD7B0C41BB162969BC0DBEEC05607D9C9737863A95AA1B4D85A6E.png?needInitFileName=true?needInitFileName=true)

安装完成后，工具和环境依赖的状态显示为![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102412.55801791345854442598178465077620:50001231000000:2800:75C749715820F1C88880D7C9E1FDDC7068185929D8FCE0A202CC3AC28049C4D9.png?needInitFileName=true?needInitFileName=true)。

     3. 在**PROJECT TASKS** 中，点击对应开发板下的**Build** ，执行编译。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102412.55734601274980917073408148866503:50001231000000:2800:6C6BF443309290BCDF2A04654841A0A2F3FBF1FC83B52C492457984FCFE3841C.png?needInitFileName=true?needInitFileName=true)

     4. 等待编译完成，在**TERMINAL** 窗口输出“SUCCESS”，编译完成。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102412.76662468704555490323760269086078:50001231000000:2800:C7EBA0DDDB230298E7A10FB98B54C4F1CB13AA9FEF6417BD5245A56E1996757D.png?needInitFileName=true?needInitFileName=true)

编译完成后，可以在工程的**out** 目录下，查看编译生成的文件，用于后续的[烧录Neptune开发板镜像](https://device.harmonyos.com/cn/docs/documentation/guide/ide-neptune-upload-0000001115763974)。
