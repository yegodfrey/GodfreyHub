# Trace分析

DevEco Device Tool提供Trace分析功能，可以实时跟踪应用在开发板上运行时的CPU的用率、内存占用、运行的任务或事件。开发者可以在任意时刻开始或停止记录Trace，并以图形化形式展示事件、内存、CPU、运行轨迹等信息。开发者可以根据采集的跟踪数据查看导致内存或CPU异常的事件或进程，从而进行源代码的优化。

Trace分析功能，当前只支持LiteOS内核的轻量和小型系统。

下面以Hi3516DV300为例，介绍Trace分析功能的使用。

#### 启动Trace分析

**前提条件**

     * 已获取开发板源码，当前支持Trace分析的源码为Openharmony3.0及以上版本。
     * 已连接开发板。

**操作步骤**

     1. 打开工程/源码，具体可参考[导入OpenHarmony源码](https://device.harmonyos.com/cn/docs/documentation/guide/open_project-0000001071680043)。
     2. 在“PROJECT TASKS”中，点击ipcamera_hispark_taurus下的**Menu Config** ，在右侧**TERMINAL** 窗口中，使用键盘的方向键，选中**Kernel** ，点击向右方向键，进入**Kerne****l** 配置页面。

     3. 在**Kernel** 配置页面，使用键盘的方向键，选中**Enable Hook Feature** ，点击向右方向键，开启Hook功能；然后选中**Enable Trace Feature** ，点击向右方向键，开启Trace功能，开启后，如下图所示。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102428.72238533201907896739386312310459:50001231000000:2800:E0C58B997A2511619C5BCA77A51622285365BA4BA7F1180273F047814B680363.png?needInitFileName=true?needInitFileName=true)

     4. 使用键盘方向键，选中**Trace work mode** ，点击向右方向键，进入Trace模式选择，选择Online mode。选择后会自动开启**Enable Trace Client Visualization and Control** 功能，如下图所示。

     5. 点击**ESC** 键，在弹出的对话框中，输入字母**Y** 保存配置。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102428.46850157840740894566411869421303:50001231000000:2800:7F6043A2AA06D3F22C32285948D9C984C82F49DDF4FDF08F04880A02938D292D.png?needInitFileName=true?needInitFileName=true)

     6. 编译开发板源码，具体请参考[编译Hi3516DV300开发板源码](https://device.harmonyos.com/cn/docs/documentation/guide/ide-hi3516dv300-compile-0000001146686054)。
     7. 烧录开发板源码，具体请参考[烧录Hi3516DV300开发板镜像](https://device.harmonyos.com/cn/docs/documentation/guide/upload_hi3516_small_system-0000001326267405)。
     8. 在**PROJECT TASKS** 中，点击hi3516DV300下的**Configure bootloader(Boot OS)** ，在右侧TERMINAL窗口出现重启开发板提示“Please reset the board”时，重启开发板，等待**TERMINAL** 窗口提示“SUCCESS”。

     9. 在**PROJECT TASKS** 中，点击hi3516DV300下的**Trace Analysis** ，进入Trace分析页面。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102428.34110661176927995069462373754662:50001231000000:2800:BCDCE95797B2BF029ABA97A28CAFC1E3733FA58FD5840FA490A21ED6470922CD.png?needInitFileName=true?needInitFileName=true)

     10. 在Trace分析页面，点击**Live Capture** ，在弹出的窗口中，选择串口号和要跟踪的事件类型。点击**OK** 后，开始采集数据。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102428.74982672593889998763875099909519:50001231000000:2800:42F192FBC23EBA569E10BB084BB49E707B9A98F73557CFD8F76FC46A81912EE0.png?needInitFileName=true?needInitFileName=true)

     11. 数据采集过程中，可点击各页签查看实时数据，可点击**Stop Capturing** 结束采集。
