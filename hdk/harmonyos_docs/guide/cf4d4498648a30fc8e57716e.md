# 写入NFC标签信息

使用应用调测助手App，申请Product ID，并将Product ID写入到NFC中。

首先需要在Device Partner平台申请测试权限，用于功能调测。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230511111803.71155286626304211102461715446299:50001231000000:2800:F39DE10E94E3CA3301E3696D450CB9BA16D68D6E112F290B44F119C4D0C7E1DB.png?needInitFileName=true?needInitFileName=true)

（1）申请和取消权限生效需要5分钟。

（2）取消权限，需要开发者手动删除缓存，（因为系统自动删除缓存数据需要1小时，hilinksvc会先读取缓存数据，会导致取消权限还能正常调测的问题）。

a. 登录[Device Partner](https://devicepartner.huawei.com)平台，进入管理中心。

b. 选择“帐号管理 > 基本资料”，单击右上角的“申请测试权限”。

c. 单击“立刻申请测试权限”申请测试权限。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230511111803.72989950249318294344419137197466:50001231000000:2800:72160783F01BFDBBCC4F4282E5C6D68643E135D376C265782833AB28140D1106.png?needInitFileName=true?needInitFileName=true)

     1. 打开手机的NFC功能。
     2. 打开应用调测助手App，选择底部的“NFC”标签页。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230511111804.44629693098160785584177836644085:50001231000000:2800:BA1FD32D796DC3A9FDF0C2AD03306B19B55E8EB3F4DA4E6F62BF5873837FA90C.png?needInitFileName=true?needInitFileName=true)

     3. 点击“选择”按钮，若华为帐号未登录，请先登录华为帐号。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230511111804.97063246414409104835849435899322:50001231000000:2800:BBB02565A946984163BED47963A0D82C2135C0A70F5184F71200F678C8056CC0.png?needInitFileName=true?needInitFileName=true)

     4. 点击“申请”按钮，系统会自动分配Product ID。每个帐号最多可申请3个有效的Product ID，每个Product ID的有效期为1个月。Product ID失效后可重新申请。
     5. 选择已申请的Product ID。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230511111804.87533283752792966633760499221222:50001231000000:2800:445C92EAECDAA6A4117130E4FF0F4ED35C32AC92C6362D7910C6108F8449C369.png?needInitFileName=true?needInitFileName=true)

     6. 输入Hi3861开发板的SN号码。SN号为可选填写，如果开发者需要通过NFC标签获取相关设备信息，可以在这里填写SN号。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230511111804.52024330529395770889670528276808:50001231000000:2800:6EDBC75BBD90154403977AA5532E956789A133AC38CAB0F44456C1CE2D570DDC.png?needInitFileName=true?needInitFileName=true)

     7. 点击“置入缓存区”按钮，此时数据处于待写入状态。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230511111804.30224907158092040517435523634933:50001231000000:2800:73E2DC0362CE78258B55E522B2837E9C65715C1464F584FFDC63085B190FBDEE.png?needInitFileName=true?needInitFileName=true)

     8. 将手机靠近NFC标签，此时开始将缓存区的数据写入到NFC标签中，写入完成后，状态会变为“已成功写入标签”。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230511111804.85947438598698199858656880727058:50001231000000:2800:057FBA608377842D512F82F8BE9E3C43898025376B3FF0374657E795D02036CF.png?needInitFileName=true?needInitFileName=true)
