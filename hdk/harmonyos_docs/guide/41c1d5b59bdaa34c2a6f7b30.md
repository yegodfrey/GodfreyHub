# 编译Bearpi-HM Micro开发板源码

DevEco Device Tool支持Bearpi-HM Micro开发板（基于STM32MP157芯片）的源码一键编译功能，提供编译工具链和编译环境依赖的检测及一键安装，简化复杂编译环境的同时，提升了编译的效率。

Bearpi-HM Micro开发板编译环境为Ubuntu环境，支持的OpenHarmony源码版本为3.2 Beta1及以上。

#### 前提条件

获取OpenHarmony的源码存在多种方式，具体请参考[创建OpenHarmony工程](https://device.harmonyos.com/cn/docs/documentation/guide/create_project-0000001072200151)或[导入OpenHarmony源码](https://device.harmonyos.com/cn/docs/documentation/guide/open_project-0000001071680043)。如果导入的源码是通过“repo方式”获取，在执行编译前，请执行如下脚本安装编译器及二进制工具。通过其它方式获取的OpenHarmony源码，请跳过该操作。
    
    bash build/prebuilts_download.sh

#### 操作步骤

     1. 在菜单栏中点击**Project Settings** ，进入BearPi-HM Micro工程配置界面。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102413.40432670576889083806792109314016:50001231000000:2800:EC2A68243296AF0EF61CEA8EF46D489A1AAF9C8E2DA19637989D80A9205B4C57.png?needInitFileName=true?needInitFileName=true)

     2. 在**Tool Chain** 页签中，DevEco Device Tool会自动检测环境依赖是否完备。

        * 如工具为“uninstalled”状态（![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102413.69281671663025494117448367092805:50001231000000:2800:F3E22EBD49EFFCBB4EC8884E9727D24E3A334F21F4BBCB830A46334E44278A35.png?needInitFileName=true?needInitFileName=true)），可单击**Download Uninstalled Tools** ，自动安装所需工具，或单击工具后方的**Dow****n****load** 安装指定工具。
        * 如当前识别到的工具类型有缺失，需要补充，可单击**Add Utility** 添加。
        * 如工具无法通过**Download** 方式直接安装，可能是由于网络原因导致。此种情况下，DevEco Device Tool无法连接到工具链下载网站，需要用户自行修复网络，或通过其他方式将正式发布的[OpenHarmony工具链安装包](https://gitee.com/openharmony/docs/blob/master/zh-cn/device-dev/get-code/sourcecode-acquire.md#获取方式3从镜像站点获取)存储到本地，单击**Import** 导入。
        * 如“OpenHarmony Environment Dependency”的状态异常（![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102413.76584010913546524967923512247601:50001231000000:2800:615986C9CA86B885FB36D34EE5E674B4385CDE51B0E266C2CE4F08236DEDB8D4.png?needInitFileName=true?needInitFileName=true)），请单击**Install** 安装。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102413.86050786426354353232690706807302:50001231000000:2800:974DFD792C1CA7AEBA94FB4B1A9A19B0E11BE21EAC1746BE36FC30230280E815.png?needInitFileName=true?needInitFileName=true)

部分依赖安装需要使用root权限，请在**TERMINAL** 窗口输入用户密码进行安装。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102413.34677068495954462925510977286891:50001231000000:2800:BCC31D9C2972BF69E6CB0E11AD11F6FD820AD858E29B308858DFCBD1937E55EF.png?needInitFileName=true?needInitFileName=true)

若出现安装pip组件失败，可参考[修改Python源的方法](https://device.harmonyos.com/cn/docs/documentation/guide/ide-set-python-source-0000001227639986)进行修改，完成尝试重新安装；

若出现安装apt组件失败，可参考[修改apt源的方法](https://device.harmonyos.com/cn/docs/documentation/guide/faq-toolchain-install-0000001301623822)进行修改，完成后尝试重新安装。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102413.75028419769651500710820345585829:50001231000000:2800:3AEE636782ECC285928A00E36FD5F0AC6DC53CF6259F77380603707CD373C883.png?needInitFileName=true?needInitFileName=true)

安装完成后，工具和环境依赖的状态显示为![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102413.25964038945236912367358440469757:50001231000000:2800:40E66409EEA8DE7DCDE38C2FF3D39694B9CA507675D5FD363DA10BC90FFA158F.png?needInitFileName=true?needInitFileName=true)。

     3. 在**PROJECT TASKS** 中，点击对应开发板下的**Build** ，执行编译。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102413.85173532357781505506026917819873:50001231000000:2800:52BAC4AD78A93E968E2ACD055CB4128987140ABF39F47141F6FFD523B2B38C88.png?needInitFileName=true?needInitFileName=true)

     4. 等待编译完成，在**TERMINAL** 窗口输出“SUCCESS”，编译完成。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102413.06783753074254517561280158489639:50001231000000:2800:BA723CAFC2D3525D4DE37A33A4641122DCAC2AF5C88FB3C076F4F839489CB993.png?needInitFileName=true?needInitFileName=true)

编译完成后，可以在工程的**out** 目录下，查看编译生成的文件，用于后续的[烧录Bearpi-HM Micro开发板镜像](https://device.harmonyos.com/cn/docs/documentation/guide/upload_bearpi_hm_micro-0000001334566993)。
