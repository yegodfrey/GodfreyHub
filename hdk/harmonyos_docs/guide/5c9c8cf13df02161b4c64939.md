# Windows平台安装DevEco Device Tool后，打开Visual Studio Code，不显示对应图标

#### 问题现象

在Windows平台安装DevEco Device Tool设备开发工具后，打开Visual Studio Code在左侧边栏没有DevEco Device Tool图标。 但是，打开Extension后发现DevEco Device Tool相关的插件已经安装成功。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102431.27969134517957841443180546065664:50001231000000:2800:46D7D4E19851CDF0E645B28C1639541DF78CB63A15E7F7281F371570D970B8CD.png?needInitFileName=true?needInitFileName=true)

#### 解决措施

     1. 关闭Windows打开的所有VSCode窗口 。
     2. 通过**Win+R** 打开运行框，输入"%AppData%\Code"打开VSCode在C盘下的文件目录。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102431.81961569241157401707208180443774:50001231000000:2800:124769DFB0F905031FE4FAB55A1584384EDA96AC9D4169F7B39F5CFA1AEC8C72.png?needInitFileName=true?needInitFileName=true)

     3. 删掉如下图所示的Cache和CachedData两个文件夹，重新打开VSCode即可。
