# 创建OpenHarmony工程

通过DevEco Device Tool创建OpenHarmony工程，并自动下载相应版本的OpenHarmony源码，源码类型包括OpenHarmony Stable Version、OpenHarmony Sample和HarmonyOS Connect Solution。根据开发需求，可以选择任意一种类型进行下载。其中：

     * **OpenHarmony Stable Version** ：OpenHarmony稳定版本源码，通过镜像站点获取，支持OpenHarmony-v3.0.3-LTS、OpenHarmony-v3.1-Release、OpenHarmony-v3.2-Beta3、OpenHarmony-v3.2-Beta4、OpenHarmony-v3.2-Beta5、OpenHarmony-v3.2-Release、OpenHarmony-v4.0-Beta1、OpenHarmony-v4.0-Beta2版本。镜像站点的源码，一般取自该稳定版本的发布时间点，因此，通过镜像站点获取的源码可能不是该版本最新源码。如果您需要获取对应版本的最新源码，请参考[从码云仓库获取源码](https://gitee.com/openharmony/docs/blob/master/zh-cn/device-dev/get-code/sourcecode-acquire.md#获取方式1从码云仓库获取)，获取源码后，请参考[导入OpenHarmony源码](https://device.harmonyos.com/cn/docs/documentation/guide/open_project-0000001071680043)章节，在DevEco Device Tool中导入源码。
     * **OpenHarmony Sample** ：针对不同SOC和开发板进行适配后的OpenHarmony发行版示例源码，可根据您已有的开发板，选择对应的示例开源发行版，快速体验OpenHarmony设备开发。关于支持的发行版示例源码及介绍，请访问[DevEco Marketplace](https://repo.harmonyos.com/#/cn/solution)。
     * **HarmonyOS****Connect Solution** ：根据[华为智能硬件合作伙伴网站](https://devicepartner.huawei.com/cn/)中定义的鸿蒙智联解决方案的配置信息，创建鸿蒙智联解决方案工程。该工程使用已评估的OpenHarmony稳定版本源码，通过Gitee开源站点下载，配合DevEco Device Tool的支持，快速完成鸿蒙智联解决方案项目开发。

#### 前提条件

只有在Windows环境通过Remote SSH远程连接上Ubuntu环境的情况下，才可以创建OpenHarmony新工程，具体请参考[配置Windows远程访问Ubuntu环境](https://device.harmonyos.com/cn/docs/documentation/guide/ide-install-windows-ubuntu-0000001194073744#section1566312395170)。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102405.55564979789495543909162139278141:50001231000000:2800:74F511AE622E3919519D08306BE59EEBDBFEF5481AC024EDDC64844095133BB2.png?needInitFileName=true?needInitFileName=true)

若Windows环境未远程连接Ubuntu环境，**New Project** 功能仅针对海思企业用户，不支持创建OpenHarmony工程。

#### 创建新工程并获取镜像站点源码

OpenHarmony稳定版本源码，支持OpenHarmony-v3.0.3-LTS、OpenHarmony-v3.1-Release、OpenHarmony-v3.2-Beta3、OpenHarmony-v3.2-Beta4、OpenHarmony-v3.2-Beta5、OpenHarmony-v3.2-Release、OpenHarmony-v4.0-Beta1、OpenHarmony-v4.0-Beta2版本。

     1. 打开DevEco Device Tool，进入Home页，点击**New Project** 创建新工程。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102405.62957696652884051124825133388599:50001231000000:2800:CA0E449A0388E5129BAA73E7EC171E83F070C98B1CF3AF79CE7E9BFB46567A39.png?needInitFileName=true?needInitFileName=true)

     2. 在新工程的配置向导页，配置工程相关信息，包括：

        * **OpenHarmony Source Code** ：选择需要下载的OpenHarmony源码，请选择**OpenHarmony Stable Version** 下的源码版本，支持OpenHarmony-v3.0.3-LTS、OpenHarmony-v3.1-Release、OpenHarmony-v3.2-Beta3、OpenHarmony-v3.2-Beta4、OpenHarmony-v3.2-Beta5、OpenHarmony-v3.2-Release、OpenHarmony-v4.0-Beta1、OpenHarmony-v4.0-Beta2版本。
        * **Project Name** ：设置工程名称。
        * **Project Path** ：选择工程文件存储路径。
        * **SOC** ：选择支持的芯片。
        * **Board** ：选择支持的开发板。
        * **Product：** 选择产品。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102405.09839421860775938814977069225180:50001231000000:2800:9FC65C2B20D050A81DA33AB4290D313915D21134C81F9EBDE6ECC5D4CFCBC1EE.png?needInitFileName=true?needInitFileName=true)

     3. 工程配置完成后，点击**Confirm** ，DevEco Device Tool会自动启动OpenHarmony源码的下载。由于OpenHarmony稳定版本源码包体积较大，请耐心等待源码下载完成。

     1. 打开DevEco Device Tool，进入Home页，点击**New Project** 创建新工程。

     2. 在新工程的配置向导页，配置工程相关信息，包括：

        * **Project Name** ：设置工程名称。
        * **Project Path** ：选择工程文件存储路径。
        * **SOC** ：选择支持的芯片。
        * **Board** ：选择支持的开发板。
        * **Product：** 选择产品。

     3. 工程配置完成后，点击**Confirm** ，DevEco Device Tool会自动启动OpenHarmony发行版源码的下载，请耐心等待源码下载完成。

#### 创建新工程并获取HarmonyOS Connect源码

#### [h2]创建HarmonyOS Connect工程

     1. 打开DevEco Device Tool，进入Home页，点击**New Project** 创建新工程。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102406.50688558877109473067353424944433:50001231000000:2800:302008BEBBF58F79B00F81859ACC52EE647F621F4A3F9FFEDF7EFD288D0D93CD.png?needInitFileName=true?needInitFileName=true)

     2. 在新工程的配置向导页的**OpenHarmony Code** 界面，选择**HarmonyOS Connect Solution** ，然后设置相关参数：

        * **Select Solution Profile** ：选择从HarmonyOS Connect解决方案中下载的Profile文件。
        * **Select README.md file** : 选择开发板对应的Readme.md文件。Readme.md为开发板功能介绍等相关说明。当前文档名称及格式不支持修改，请与“README.md”保持一致。
        * **Select Chip Datasheet (Optional)** ：（可选）选择芯片配置手册，模组厂商可参考该手册进行适配开发，一般为pdf格式文件。
        * **Source Download Method** ：选择源码下载的方式，支持ssh和https两种协议，关于两种协议的区别请参考[https协议和ssh协议在使用上的差别](https://gitee.com/help/articles/4238#article-header0)。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102406.37199164299143116359962896746617:50001231000000:2800:EB206A2F0617DB1B0A1F4E042228A93C0FDF2A2CEA45B05B269E570A6BF40930.png?needInitFileName=true?needInitFileName=true)

下载HarmonyOS Connect解决方案源码，通过repo方式从码云仓库获取，DevEco Device Tool会自动检测依赖工具是否满足。如果不满足，请根据安装指导，在Ubuntu系统中安装相关工具。

安装完成后可点击刷新按钮重新进行检查，如果刷新后依旧不能检测到相关工具，可尝试重启Ubuntu系统后重试。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102406.06523816471289610396010067085032:50001231000000:2800:A51468525CBF8A637077F115D7E0A077B657E47C625859B7F5287B5FC1745ACC.png?needInitFileName=true?needInitFileName=true)

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102406.17818620326157687315876997695868:50001231000000:2800:CF399E6428112CF6CD05A74B61D68FEC38E847666E01EE4A78D2294B2BE5F92C.png?needInitFileName=true?needInitFileName=true)

     3. 点击**OK** ，返回工程配置界面，设置**Project Name** 、**Project Path** 参数（**SOC** 和**Board** 不可修改），然后点击**Confirm** 。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102406.08750337136949045268159443519495:50001231000000:2800:BF5CB576007E9EAE637FEA97A1962902A9162515BA45DA9443B08EFEC12F12A8.png?needInitFileName=true?needInitFileName=true)

     4. 工程配置完成后，点击**Confirm** ，DevEco Device Tool会自动启动OpenHarmony发行版源码的下载，请耐心等待源码下载完成。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102406.50273845155627021056279123536571:50001231000000:2800:622BD3665D0C5F1FF92A82C79FED1242090C87B71E0810119869F7D244511747.png?needInitFileName=true?needInitFileName=true)

     5. OpenHarmony源码下载完成后，在DevEco Device Tool左侧工具栏中**PROJECT TASKS > Config**界面，可通过如下两种方式，开发芯片相关业务代码。

        * **Using scaffolding templates** ：在OpenHarmony源码的根目录下，创建Vendor、Device和自定义源码目录，并生成相关源码目录及代码模板，开发者可在此基础上开发业务代码。
          * **Device Code Repository** ：配置用于存放Device目录源码的远程git仓。源码开发完成后，需将Device目录下的源码上传至该Git仓库，便于下游厂商下载。
          * **Vendor Code Repository** ：配置用于存放Vendor目录源码的远程git仓。源码开发完成后，需将Vendor目录下的源码上传至该Git仓库，便于下游厂商下载。
          * **Branch Name** ：填写仓库中存储代码的分支名。
          * **Add additional code repository** ：配置用于存放其他目录源码的远程git仓。源码开发完成后，需将该目录下的源码上传至该Git仓库，便于下游厂商下载。

在**Create Target Directory** 中选择**Using scaffolding templates** 创建源码目录及生成代码模板。然后点击**Save** ，保存设置的git仓信息。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102406.98639912249788514127383760647894:50001231000000:2800:9F80846F53744B0E770D079338C674619F6ACFA11867A4F9734A7A7903E9323F.png?needInitFileName=true?needInitFileName=true)

        * **Clone Remote Repository** ：从远程git仓中克隆芯片相关业务代码，进行增量开发。
          * **Device Code Repository** ：远程Deivce源码目录下的git仓。
          * **Vendor Code Repository** ：远程Vendor源码目录下的git仓。.
          * **Branch Name** ：填写仓库中存储代码的分支名。
          * **Add additional code repository** ：远程其它源码git仓。

填写对应仓库地址后，在**Create Target Directory** 中点击**Clone Remote Repository** ，克隆远程git仓库代码。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102406.94651927024676032569932128403474:50001231000000:2800:3C058F163C60A3043ED00C7AFD2243D9E120F476357A5DA3ACDC3D573E46239D.png?needInitFileName=true?needInitFileName=true)

     6. 配置完成后，请根据适配开发指导进行开发。

#### [h2]打包HarmonyOS Connect Profile文件

使用DevEco Device Tool开发完HarmonyOS Connect源码后，需要使用DevEco Device Tool打包生成芯片解决方案Profile文件，然后在Device Partner平台上传Profile文件。

在DevEco Device Tool左侧工具栏中，点击**PROJECT TASKS > Pack**进行打包。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102406.67883465346399326845833191911834:50001231000000:2800:A20B76D00A0B55BA7324B522C0BF2E090433BBAB4F95AD29F8B9ABF18C16EE51.png?needInitFileName=true?needInitFileName=true)

打包成功后，文件将保存在工程根目录中。
