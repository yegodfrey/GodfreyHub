# 使用远程hdc能力

DevEco Device Tool采用Windows+Ubuntu混合设备开发环境，降低了嵌入式开发的环境配置复杂度。在子系统开发过程中，开发者需要将Ubuntu环境中编译好的内容先同步到Windows环境，再通过Windows环境同步到开发设备上。

由于子系统的多样性，以及开发调测工作的特殊性，开发者可能需要在编译环境和设备之间进行频繁的交互，此时需要两次同步的处理方式不但会浪费开发时间，还容易出现拷贝错误等问题。

针对此种情况，从3.1 Release版本开始，DevEco Device Tool在远程开发模式中，提供远程hdc能力，将Ubuntu环境、Windows环境、开发设备三者连通，使用户可以不用感知Windows的存在，直接在Ubuntu侧与设备进行交互。

当前仅适配标准系统的RK3568、Hi3516DV300支持远程hdc能力。

#### 前提条件

     * 开发板已完成烧录。
     * Windows环境与Ubuntu环境、开发设备保持连接状态。
     * Windows环境中已下载SDK包并解压。
       * 发布版本的SDK下载路径可参考OpenHarmony官网的版本说明，例如[OpenHarmony 3.2 Release](https://docs.openharmony.cn/pages/v3.2/zh-cn/release-notes/OpenHarmony-v3.2-release.md/)。
       * 若您需要使用OpenHarmony Master分支的最新特性，可使用OpenHarmony CI提供的[每日构建](http://ci.openharmony.cn/workbench/cicd/dailybuild/dailylist)版本。

#### 操作步骤

     1. 在菜单栏中点击**Project Settings** ，进入工程配置界面。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241216195802.36399703828163375431531239960213:50001231000000:2800:A044D062C5753B81E506A190911FE460261C941D982E45AD17F3EEAB5764C6BA.png?needInitFileName=true?needInitFileName=true)

     2. 在“Tool Chain”页签的“Utilities”区域查看“Hdc_Client”、“Hdc_Server”的安装情况。

        * 若“Hdc_Client”、“Hdc_Server”的状态为“installed”，请继续执行后续操作。
        * 若“Hdc_Client”、“Hdc_Server”的状态为“Not installed”，请单击右侧的“Import”按钮导入toolchains压缩包（将SDK软件包解压后得到），或跳转至[资源管理](https://device.harmonyos.com/cn/docs/documentation/guide/resource_manager-0000001492281786)界面，将toolchains压缩包导入至Utilities分类下。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241216195802.77596446800647971206124054053339:50001231000000:2800:E4C1B10693CC349B4ED4AB9F51FD4CB8B6462AD9D1DD0F6080F24775B0CF6F01.png?needInitFileName=true?needInitFileName=true)

其中，Hdc_Server需要导入toolchains-windows-x64-_version_.zip，Hdc_Client需要导入toolchains-linux-x64-_version_.zip。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241216195802.15126396413977735537927827330365:50001231000000:2800:A65BB90105ACCABC2F31C3C54BDC7B442ECA4F2AD360EAA18A9483DBDE19FA87.png?needInitFileName=true?needInitFileName=true)

     3. 在工程配置界面设置HDC连接参数。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241216195802.78396210792843780450308965931929:50001231000000:2800:F7A26597158E2C5DFA4DDCB1CB32C20E56D4475306ABD3572EF7384F64A6B89E.png?needInitFileName=true?needInitFileName=true)

确认远程计算机（Ubuntu开发环境）与本地计算机（Windows开发环境）为连接状态（**REMOTE DEVELOPMENT > Local PC**右边连接按钮为![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241216195802.29261350669593323672109004449968:50001231000000:2800:7B6B86D7A6FD81F9FA7DDC446BB8B0CD0035688AC8B5B84A199AAC4A90B66905.png?needInitFileName=true?needInitFileName=true)）。

        * hdc_server_ip：Windows本地IP地址。
        * hdc_server_port：应用于hdc服务的端口，默认为8710，可自行设置。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241216195802.20114798547114747739819495320954:50001231000000:2800:43AF99BD24CD99940BEF95ECA2346440187111B49F00B654B4478C273ABD9325.png?needInitFileName=true?needInitFileName=true)

     4. 启动HDC功能。

单击“PROJECT TASKS”中的“HDC”会自动启动HDC服务。从4.0 Release版本起，HDC服务启动后弹出设备文件系统窗口，开发者可在此窗口中方便地进行文件传输。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241216195802.59343811866743452079958067529175:50001231000000:2800:B09FE4816C806D89BAFB8ABB43372A36F954D4896B00C0981CE26CF78F43228F.png?needInitFileName=true?needInitFileName=true)

     5. 按照实际需要进行hdc操作。

hdc的具体使用方法请参考[《hdc使用指导》](https://docs.openharmony.cn/pages/v5.0/zh-cn/device-dev/subsystems/subsys-toolchain-hdc-guide.md/)。
