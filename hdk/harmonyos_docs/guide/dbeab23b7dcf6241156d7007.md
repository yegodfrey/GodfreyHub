# 烧录Hispark Phoenix开发板镜像

Hispark Phoenix的镜像烧录通过Winodow环境进行烧录，开发者启动烧录操作后，DevEco Device Tool通过Remote远程模式，将Ubuntu环境下编译生成的待烧录程序文件和烧录工具拷贝至Windows目录下，然后通过Windows的烧录工具将程序文件烧录至开发板中。

#### 前提条件

请安装开发板串口驱动程序，请参考[Hi3516DV300/Hi3751V350开发板串口驱动安装指导](https://device.harmonyos.com/cn/docs/documentation/guide/hi3516_hi3518-drivers-0000001050743695)。

#### 操作步骤

     1. 请连接电脑USB口和待烧录开发板miniUSB debug接口。
     2. 在DevEco Device Tool中，选择**REMOTE DEVELOPMENT > Local PC**，查看远程计算机（Ubuntu开发环境）与本地计算机（Windows开发环境）的连接状态。

        * 如果Local PC右边连接按钮为![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102419.04738066267820781323682678086168:50001231000000:2800:3A73C94FD7A723791EDD926C51F9F45BBF93BD770D268524CB224A77C0750262.png?needInitFileName=true?needInitFileName=true)，则远程计算机与本地计算机为已连接状态，不需要执行其他操作。
        * 如果Local PC右边连接按钮为![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102419.61047376900661663828399346200741:50001231000000:2800:C926CADC2FD2F3E3BCDB253654830A0B0412F7F74268FAE775EB703841D5A053.png?needInitFileName=true?needInitFileName=true)，则点击绿色按钮进行连接。连接时DevEco Device Tool会重启服务，因此请不要在下载源码或源码编译过程中进行连接，否则会中断任务。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102419.94089542185891739508853155953637:50001231000000:2800:2B35EBA9D774C569C01D7F9BD18E7A37C230CE004C8363F9592DB8CD5E95EFAC.png?needInitFileName=true?needInitFileName=true)

     3. 在Windows系统中查看串口信息（在电脑的左下角![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102419.67513555775252975307028300934179:50001231000000:2800:DB404A3CAC470E006CC3411C9BF4FC5372F9138897297CC0856FBCDFE8B75284.png?needInitFileName=true?needInitFileName=true)图标，点击鼠标右键选择“设备管理器”中查看），并记录下串口号。
     4. 在菜单栏中点击**Project Settings** 按钮，进入Hispark Phoenix工程配置界面。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102419.25743449747679366912289674546539:50001231000000:2800:BBC148699C7DEE5B1F0F8A50E36F4F2EEB4D9AA98EEF1E8C5D9EDE562D81B81F.png?needInitFileName=true?needInitFileName=true)

     5. 在**Tool Chain** 页签，检查Uploader烧录器工具是否已安装。

        * 如工具为“uninstalled”状态（![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102419.78724889623946560552890393583348:50001231000000:2800:9755110A793BF3C5E48309E42F568828AC022FF638C4D65EC0396A057F439B45.png?needInitFileName=true?needInitFileName=true)），可单击**Download Uninstalled Tools** ，自动安装所需工具，或单击工具后方的**Dow****n****load** 安装指定工具。
        * 如工具无法通过**Download** 方式直接安装，可能是由于网络原因导致。此种情况下，DevEco Device Tool无法连接到工具链下载网站，需要用户自行修复网络，或通过其他方式将正式发布的[OpenHarmony工具链安装包](https://gitee.com/openharmony/docs/blob/master/zh-cn/device-dev/get-code/sourcecode-acquire.md#获取方式3从镜像站点获取)存储到本地，单击**Import** 导入。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102419.21409398149646642328835640064405:50001231000000:2800:E6FBB8333272E885D31F7906327DD65828BBB8AC3479ED756795B1B4DC1812CC.png?needInitFileName=true?needInitFileName=true)

     6. 在**hispark_phoenix** 页签，设置烧录选项，包括upload_port、upload_partitions和upload_protocol。

        * upload_protocol：选择烧录协议，固定选择“hiburn-net”。
        * upload_port：选择已查询到的串口号。
        * upload_partitions_profile：选择待烧录程序的配置文件，该配置文件会指定烧录文件名称、起始烧录地址、地址长度等信息；同时请勾选**Enable to use upload_partitions_profile for upload** 选项。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102419.69079928372464718993540644084747:50001231000000:2800:71A4761731480772EB0C8C3690EBA46DE2AA550380CC418B331E01E8A15394C9.png?needInitFileName=true?needInitFileName=true)

如需修改烧录profile文件，在设置烧录分区起始地址和分区长度时，应根据实际待烧录文件的大小进行设置，要求设置的烧录分区大小，要大于待烧录文件的大小；同时，各烧录文件的分区地址设置不能出现重叠。

首次烧录，请勾选**Enable to use upload_partitions_profile for upload** 选项，会自动生成upload_partitions文件。再次烧录时，可根据实际情况选择生成upload_partitions文件进行自定义烧录，也可以再勾选**Enable to use upload_partitions_profile for upload** 选项，使用upload_partitions_profile重新生成upload_partitions文件用于烧录。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102419.97708684693427637995426916312056:50001231000000:2800:8C44C16E28277A44398F24C5A4432326BBF5D032DC6531C6057D9549236F1922.png?needInitFileName=true?needInitFileName=true)

     7. 检查和设置连接开发板后的网络适配器的IP地址信息，设置方法请参考[设置网口烧录的IP地址信息](https://device.harmonyos.com/cn/docs/documentation/guide/set_ipaddress-0000001141825075)。
     8. 设置网口烧录的IP地址信息，设置如下选项：

        * upload_net_server_ip：选择7中设置的IP地址信息。例如192.168.50.2
        * upload_net_client_mask：设置开发板的子网掩码，工具会自动根据选择的upload_net_server_ip进行设置。例如255.255.255.0
        * upload_net_client_gw：设置开发板的网关，工具会自动根据选择的upload_net_server_ip进行设置。例如192.168.50.1
        * upload_net_client_ip：设置开发板的IP地址，工具会自动根据选择的upload_net_server_ip进行设置。例如192.168.50.3

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102419.61374534653904629616362412913459:50001231000000:2800:250F743EC1347005F427B8AF0AEB2BB2045396726EB9102095A7AE5CCF7808BA.png?needInitFileName=true?needInitFileName=true)

配置完成后工程将自动保存。

     9. 在工具安装目录下，打开resources\uploaders\hiburn\5.5.2\config\burn.config文件，修改serialCommandTimeout的值为120或以上，并保存。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102419.92704790625257457019798198386961:50001231000000:2800:FB61AF24EC5BF7AA2ADFA7BC2F76B04270FFEDF081CC729562CE883618BC7169.png?needInitFileName=true?needInitFileName=true)

     10. 在“PROJECT TASKS”中，点击**Upload** 按钮，启动烧录。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102419.53666378759588583722965738159231:50001231000000:2800:5F2BB793B757DF3225A9191EEC8A8E6BEF68A82936261D2121251BDA1BBB46FA.png?needInitFileName=true?needInitFileName=true)

如果开始烧录时，其他串口工具如MobaXterm连接了开发板的串口，则需要断开与开发板串口的连接，否则烧录会失败。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102419.68948754465829324090506814024705:50001231000000:2800:5CFE93BEC6EBF58FE28EA93B0E36DEA0173D98DF1CA9F83B5F8A269E69BADB7A.png?needInitFileName=true?needInitFileName=true)

     11. 启动烧录后，显示如下提示信息时，请在15秒内，按下开关电源键对单板(下电并)上电，启动烧录。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102419.87896754196976524973455186660796:50001231000000:2800:6FF20C05060AB20E133E3495312B2B834CE35138B2B90B62E8ABBCF91B3FAE59.png?needInitFileName=true?needInitFileName=true)

重新上电后，界面提示如下信息时，表示烧录成功。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102419.09733857867263341775315265684096:50001231000000:2800:B190B3593579A739441A5C736CEB0013AF2BF00EFD09A49CDF5DA72062FD4F69.png?needInitFileName=true?needInitFileName=true)
