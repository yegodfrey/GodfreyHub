# 烧录Neptune开发板镜像

Neptune的镜像烧录通过Winodow环境进行烧录，开发者启动烧录操作后，DevEco Device Tool通过Remote远程模式，将Ubuntu环境下编译生成的待烧录程序文件拷贝至Windows目录下，然后通过Windows的烧录工具将程序文件烧录至开发板中。

     1. 请连接好电脑和待烧录开发板，需要连接串口。
     2. 在DevEco Device Tool中，选择**REMOTE DEVELOPMENT > Local PC**，查看远程计算机（Ubuntu开发环境）与本地计算机（Windows开发环境）的连接状态。

        * 如果Local PC右边连接按钮为![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102420.53450141304094508934638765526454:50001231000000:2800:4D9066E314F4161AA5D0734C1D1C06D808711A3C19FED404A9309F8048AB5CCE.png?needInitFileName=true?needInitFileName=true)，则远程计算机与本地计算机为已连接状态，不需要执行其他操作。
        * 如果Local PC右边连接按钮为![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102420.14336870865165768466852593682634:50001231000000:2800:750C44779CB89782C02E8FAAB051EA62CF09594C8E4EE4648AD2F80CC76758FC.png?needInitFileName=true?needInitFileName=true)，则点击绿色按钮进行连接。连接时DevEco Device Tool会重启服务，因此请不要在下载源码或源码编译过程中进行连接，否则会中断任务。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102420.93612923341113906196165571522134:50001231000000:2800:D6B54214BA813F672DFCD40421E006C918E6CCCAFFFB4ADD9736ED4DA130DE5C.png?needInitFileName=true?needInitFileName=true)

     3. 在菜单栏中点击**Project Settings** 按钮，进入Neptune工程配置界面。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102421.43070225238622121177667485940579:50001231000000:2800:AC0F2149EDD7447B0367D37871D5478E1E379A39ED64229ED36517D10FC14111.png?needInitFileName=true?needInitFileName=true)

     4. 在**neptune_iot** 页签，设置烧录选项，包括**upload_port** 、**upload_partitions** 和**upload_protocol** 。配置完成工程将自动保存。

        * **upload_partitions** ：选择待烧录的文件名称。DevEco Device Tool已预置默认的烧录文件信息，如果需要修改待烧录文件地址，可点击每个待烧录文件后的![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102421.27678317379572629969098524926010:50001231000000:2800:C6FC2262938EAF9FE04A36D69092552C9EFA038DD6A4EDB6E97348D3B788E222.png?needInitFileName=true?needInitFileName=true)按钮进行修改。
        * **upload_protocol** ：选择烧录协议，固定选择“xmodem”。
        * **upload_port** ：选择烧录的串口。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102421.16739454102594727751727419916556:50001231000000:2800:7B65240A29B73BF778AF840BCF33378E088BB1CEDD9C4E388A17B1E783721F5F.png?needInitFileName=true?needInitFileName=true)

     5. 在**PROJECT TASKS** 中，点击**Upload** 按钮，启动烧录。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102421.66281831212547729562899835072417:50001231000000:2800:D6420F9B6E9231120699B3D2251DA561D050EA6C70B02BEEC0E5BB63A5326A4B.png?needInitFileName=true?needInitFileName=true)

     6. 启动烧录后，界面提示如下信息时，请按开发板上的**RST** 按钮重启开发板。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102421.34859891097880710072600481731234:50001231000000:2800:20EDB3EAB5C70B3A0E0E2E501576C61CA3A084B8990572041B8011B56977AA58.png?needInitFileName=true?needInitFileName=true)

重新上电后，界面提示**SUCCESS** 信息时，表示烧录成功。
