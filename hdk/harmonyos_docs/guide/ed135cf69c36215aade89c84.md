# 栈分析和镜像分析

DevEco Device Tool通过集成Stack Analysis栈分析工具和Image Analysis镜像分析工具，用于开发过程中的内存不足、内存溢出等问题进行分析，帮助开发者更加精准的分析、定位问题。

     * Stack Analysis栈分析工具是基于静态二进制分析手段，提供任务栈开销估算值和函数调用关系图示，为栈内存使用、分析、优化、问题定位等开发场景提供较为准确的静态内存分析数据参考。
     * Image Analysis镜像分析工具对工程构建出的elf文件进行内存占用分析，支持开发者快速评估内存段、符号表使用情况。

栈分析和镜像分析功能，当前只支持LiteOS内核的轻量和小型系统。

该特性在DevEco Device Tool 2.2 Beta2及更高版本中支持。

#### 前提条件

在使用栈分析和镜像分析工具前，请使用DevEco Device Tool对源码进行编译。

#### 启动分析任务

下面以Hi3861V100开发板为例，介绍Stack Analysis栈分析工具的使用方法。

     1. 在工程任务窗口启动分析任务：点击**Stack Analysis** ，启动栈分析工具；点击**Image Analysis** ，启动镜像分析工具。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102427.98891479581164416565023835309561:50001231000000:2800:63D29F1F273D432A8431FE491AF9B1C8DAABC7A2D93D1FF12AB18994C3022F9C.png?needInitFileName=true?needInitFileName=true)

     2. 等待分析任务完成后，在弹出的页面，即可查阅Stack Analysis栈分析和Image Analysis镜像分析结果。

#### 结果展示说明

#### [h2]栈分析结果说明

栈分析结果按照函数列表和调用关系进行展示。

     * **Function List** ：函数列表界面显示每个函数的函数名称和函数内部栈开销

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102427.41096638021011596457568565254068:50001231000000:2800:F96F4A5FF0FDF9B359350C3A567167A835D53A4353B105E5CCDDC9FC441071B8.png?needInitFileName=true?needInitFileName=true)

     * **Call Graph** ：调用关系界面显示每个函数的调用关系，包括函数名称、调用深度、函数最大栈开销。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102427.25827162327924356604619084162534:50001231000000:2800:4E7E28DC65985037EACDE2F230B8FF14A2EF8367CDC5D5AF9B57DA7B28C2F4B8.png?needInitFileName=true?needInitFileName=true)

#### [h2]镜像分析结果展示

镜像分析结果按照内存区域、详细信息、文件大小、模块大小、目录大小5个界面进行展示。

     * **Memory Regions** ：内存区域界面以表格的形式展示了每个区域的内存使用情况，包含了起始地址、结束地址、大小、可用内存以及内存占用。表格下方的饼图可以动态显示选中的内存数据。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102427.47513378833080660054021297200502:50001231000000:2800:7C307DCB532EAE03E02D62E0E18D0E166C115CFA9C94C780D641141885738C75.png?needInitFileName=true?needInitFileName=true)

     * **Memory Details：** 内存详细信息里显示了Section和Symbol的信息。通过树状表格展示层级关系、名称、VMA、LMA以及Size。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102427.72094241427464233384988610688336:50001231000000:2800:8E33470839A4F75EE22773167600BB617D206758FF87842799354EFB543531EA.png?needInitFileName=true?needInitFileName=true)

     * **File Size：** 文件大小里展示了.a文件和.o文件的层级关系以及不同section的内存占用。
     * **Module Size** ：模块大小里展示了模块和组件的层级关系以及不同section的内存占用。
     * **Folder Size** ：目录大小里展示了目录和文件以及.a和.o文件的层级关系，以及不同section的内存占用。
