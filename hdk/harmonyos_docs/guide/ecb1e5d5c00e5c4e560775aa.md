# Hi3861V100在Windows平台烧录按了RST后超时失败

#### 问题现象

Hi3861V100在Windows平台烧录，根据提示按了RST按键之后依旧没有反应，最终因超时导致烧录失败。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102435.52310264742309765805290112967999:50001231000000:2800:5F799D46BDE03D5ABAFDF15E714281B7BE2B495D998A147D6282B83C5A76530C.png?needInitFileName=true?needInitFileName=true)

#### 解决措施

     * 用户没有接跳线帽，开发者需要将跳线帽装到开发板上。正确接法请参考[链接](https://docs.openharmony.cn/pages/v5.0/zh-cn/device-dev/quick-start/quickstart-appendix-hi3861.md/)。
     * 用户虽然烧录时有接跳线帽，但是跳线帽的接错了，即使按了RST键也没有生效，请参考[Hi3861开发板介绍](https://docs.openharmony.cn/pages/v5.0/zh-cn/device-dev/quick-start/quickstart-appendix-hi3861.md/)重新连接。
     * 用户当前PC上连接多个设备，选择的端口号不是当前设备对应的。
     * 用户需要将主板从通用底板上拔下来，再进行烧录（硬件问题，出现概率较低）。
