# Windows平台安装DevEco Device Tool失败，VSCode侧边栏显示“DEVECO:REMOTE DEVELOPMENT”

#### 问题现象

在Windows平台安装DevEco Device Tool安装成功，打开VSCode点击DevEco图标后，正常应该显示如下图1。如果安装失败，则显示如下图2。

#### 解决措施

#### [h2]可能原因一：Python版本不匹配

出现以上问题，可能的原因之一为Python版本不匹配，例如开发者使用的是Anaconda3软件管理Python版本，当前DevEco Device Tool可能与该版本不适配，建议开发者下载匹配的Python版本（Python 3.8~3.9），并重新安装Python和DevEco Device Tool。Python下载可参考以下地址：

     * 华为云： https://repo.huaweicloud.com/python/3.8.10/python-3.8.10-amd64.exe
     * Python官网 ： https://www.python.org/ftp/python/3.8.10/python-3.8.10-amd64.exe

#### [h2]可能的原因二：安装路径存在中文字符

安装路径中存在中文，例如中文用户名或者中文文件夹，建议卸载后重新安装。
