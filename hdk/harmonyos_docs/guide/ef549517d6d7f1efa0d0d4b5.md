# 烧录Hi3861V100开发板镜像

Hi3861V100的镜像烧录通过Window环境进行烧录，开发者启动烧录操作后，DevEco Device Tool通过Remote远程模式，将Ubuntu环境下编译生成的待烧录程序文件拷贝至Windows目录下，然后通过Windows的烧录工具将程序文件烧录至开发板中。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102418.91994235152883005968110974347545:50001231000000:2800:844FC9D3A02C56C86AC5141C5977BAD90FFE259363DC7C9F16703F56362B74E8.png?needInitFileName=true?needInitFileName=true)

目前3.1 Beta2版本已支持**Windows环境** 的编译烧录，若编译是在Windows环境下进行的，则对应的烧录指导请参见[Hi3861V100开发板Windows环境编译与烧录](https://device.harmonyos.com/cn/docs/documentation/guide/hi3861-windows-0000001445255984)。

#### 前提条件

请安装Hi3861V100开发板USB转串口驱动程序，请参考[USB转串口驱动安装](https://device.harmonyos.com/cn/docs/documentation/guide/hi3861-drivers-0000001058153433)。

#### 操作步骤

     1. 请连接好电脑和待烧录开发板，需要连接USB口，具体可参考[Hi3861V100开发板介绍](https://device.harmonyos.com/cn/docs/documentation/guide/quickstart-lite-introduction-hi3861-0000001105041324)。
     2. 在DevEco Device Tool中，选择**REMOTE DEVELOPMENT > Local PC**，查看远程计算机（Ubuntu开发环境）与本地计算机（Windows开发环境）的连接状态。

        * 如果Local PC右边连接按钮为![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102418.43442548363579301775182944034271:50001231000000:2800:FF87FAE27E0C8FAFA03FC9133E6C7AB79BE6A576E086F12C98808AEBCA2CE6BF.png?needInitFileName=true?needInitFileName=true)，则远程计算机与本地计算机为已连接状态，不需要执行其他操作。
        * 如果Local PC右边连接按钮为![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102418.78125764940099569368630549991521:50001231000000:2800:9340085D77786CA15CBE01F7DE23B8306E668E8963F00EEECD53C9F836387B85.png?needInitFileName=true?needInitFileName=true)，则点击绿色按钮进行连接。连接时DevEco Device Tool会重启服务，因此请不要在下载源码或源码编译过程中进行连接，否则会中断任务。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102418.93102871235127037584627619178338:50001231000000:2800:96227BB0AFDC44A976DD49BE58B4D2B6554B54AE5F0CB0D531865F42FC12F2AC.png?needInitFileName=true?needInitFileName=true)

     3. 在菜单栏中点击**Project Settings** 按钮，进入Hi3861V100工程配置界面。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102418.51648957439525971637236986078603:50001231000000:2800:93A4FC8A507DE2485FEA3674EAA13494BB9DEEB49CEE27F9A294CECFF7A370E3.png?needInitFileName=true?needInitFileName=true)

     4. 在**Tool Chain** 页签，检查Uploader烧录器工具是否已安装。

        * 如工具为“uninstalled”状态（![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102418.82367878756012180987987713556660:50001231000000:2800:B900CCD3D6FD6CAE1C8ACCAA56E379E682934FD2E8F3120A551BA6CCD8791AAA.png?needInitFileName=true?needInitFileName=true)），可单击**Download Uninstalled Tools** ，自动安装所需工具，或单击工具后方的**Dow****n****load** 安装指定工具。
        * 如工具无法通过**Download** 方式直接安装，可能是由于网络原因导致。此种情况下，DevEco Device Tool无法连接到工具链下载网站，需要用户自行修复网络，或通过其他方式将正式发布的[OpenHarmony工具链安装包](https://gitee.com/openharmony/docs/blob/master/zh-cn/device-dev/get-code/sourcecode-acquire.md#获取方式3从镜像站点获取)存储到本地，单击**Import** 导入。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102418.25719669703079233603566588155192:50001231000000:2800:BCC8F5B235761C8AA5DEC5B704F367531EC287BB9BE57F5F0733103F0BF3DC9D.png?needInitFileName=true?needInitFileName=true)

     5. 在**wifiiot_hispark_pegasus** 页签，设置烧录选项，包括upload_port、upload_protocol和upload_partitions。配置完成后工程将自动保存。

        * upload_port：选择已查询的串口号。
        * upload_protocol：选择烧录协议，选择“hiburn-serial”。
        * upload_partitions：选择待烧录的文件名称。DevEco Device Tool已预置默认的烧录文件信息，如果需要修改待烧录文件地址，可点击每个待烧录文件后的![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102418.50473752707985627756390244258196:50001231000000:2800:6BE54D909730E85241141E2E069FA0384B4B3D5EB3847D68A691ADFC204761D2.png?needInitFileName=true?needInitFileName=true)按钮进行修改。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102418.52082453287690563644868880775709:50001231000000:2800:0AF268524E9BFB5FAE687CFF565AAE51388D439A58AE2D6203CF2BF47634D648.png?needInitFileName=true?needInitFileName=true)

配置完成后工程将自动保存。

     6. 在“PROJECT TASKS”中，点击hi3861下的**Upload** 按钮，启动烧录。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102418.94074276426028980738631707733114:50001231000000:2800:5DD6F0A92740DCF2880D2F177EDF1ACE83205AD7098B4A0DD2B051CA4A071725.png?needInitFileName=true?needInitFileName=true)

     7. 启动烧录后，显示如下提示信息时，请在15秒内，按下开发板上的RST按钮重启开发板。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102418.90507758832432277858840266156434:50001231000000:2800:DD5F294B5B7A5E5262F90283A4BF35E32AED32347A50F663F656EFDA817214B9.png?needInitFileName=true?needInitFileName=true)

重新上电后，界面提示如下信息时，表示烧录成功。
