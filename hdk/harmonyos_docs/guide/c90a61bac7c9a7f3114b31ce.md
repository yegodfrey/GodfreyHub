# 点击REMOTE DEVELOPMENT中的Local PC的连接按钮后异常的处理方法

#### 问题现象

烧录时，在Windows平台点击REMOTE DEVELOPMENT > Local PC点击连接按钮（绿色三角按钮），按钮变成红色正方形随即又变成绿色三角形按钮；或者没有任何反应。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102435.81222660068211095589574667564550:50001231000000:2800:A74760A2D1A4C4CEF9C45DEF7BEEABD575DF01683B150C3A91E2B656E44B473B.png?needInitFileName=true?needInitFileName=true)

#### 解决措施

可能的原因是Windows平台下Python版本不匹配，例如开发者使用的是Anaconda3软件管理Python版本，当前DevEco Device Tool可能与该版本不适配，建议开发者下载匹配的Python版本（Python 3.8~3.9），并重新在Windows平台安装Python和DevEco Device Tool。Python下载可参考以下地址：

     * 华为云： https://repo.huaweicloud.com/python/3.8.10/python-3.8.10-amd64.exe
     * Python官网 ： https://www.python.org/ftp/python/3.8.10/python-3.8.10-amd64.exe
