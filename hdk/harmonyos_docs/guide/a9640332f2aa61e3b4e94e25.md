# 编译BearPi-HM Nano开发板源码

DevEco Device Tool支持BearPi-HM Nano开发板（基于Hi3861V100芯片）的源码一键编译功能，提供编译工具链和编译环境依赖的检测及一键安装，简化复杂编译环境的同时，提升了编译的效率。

BearPi-HM Nano开发板编译环境为Ubuntu环境。

#### 前提条件

获取OpenHarmony的源码存在多种方式，具体请参考[创建OpenHarmony工程](https://device.harmonyos.com/cn/docs/documentation/guide/create_project-0000001072200151)或[导入OpenHarmony源码](https://device.harmonyos.com/cn/docs/documentation/guide/open_project-0000001071680043)。如果导入的源码是通过“repo方式”获取，在执行编译前，请执行如下脚本安装编译器及二进制工具。通过其它方式获取的OpenHarmony源码，请跳过该操作。
    
    bash build/prebuilts_download.sh

#### 操作步骤

     1. 在菜单栏中点击**Project Settings** ，进入BearPi-HM Nano工程配置界面。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102411.77350615116912553127637109797132:50001231000000:2800:11C09B9F65D974374C38874C7398403E2F2D6DA6015F3E9C6C28E04263CB1337.png?needInitFileName=true?needInitFileName=true)

     2. 在**Tool Chain** 页签中，DevEco Device Tool会自动检测依赖的编译工具链是否完备。

        * 如工具为“uninstalled”状态（![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102411.93205350269048270840648992542619:50001231000000:2800:99651826C2A249CC653B54A7748B6F9A19690228756BBD470B2414E69A4DD635.png?needInitFileName=true?needInitFileName=true)），可单击**Download Uninstalled Tools** ，自动安装所需工具，或单击工具后方的**Dow****n****load** 安装指定工具。
        * 如当前识别到的工具类型有缺失，需要补充，可单击**Add Utility** 添加。
        * 如工具无法通过**Download** 方式直接安装，可能是由于网络原因导致。此种情况下，DevEco Device Tool无法连接到工具链下载网站，需要用户自行修复网络，或通过其他方式将正式发布的[OpenHarmony工具链安装包](https://gitee.com/openharmony/docs/blob/master/zh-cn/device-dev/get-code/sourcecode-acquire.md#获取方式3从镜像站点获取)存储到本地，单击**Import** 导入。
        * 如“OpenHarmony Environment Dependency”的状态异常（![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102411.33822471621265888869538411575868:50001231000000:2800:30F74B3606B42103983E25EFCB311CBEF805589BA9FCA20ECBD535A6B7DACA74.png?needInitFileName=true?needInitFileName=true)），请单击**Install** 安装。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102411.31646002727822182008803087731026:50001231000000:2800:095090254BF8419E4A63F0F30EEC001CE678688C776F43630FDF0F25AA9D3574.png?needInitFileName=true?needInitFileName=true)

部分工具安装需要使用root权限，请在**TERMINAL** 窗口输入用户密码进行安装。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102411.25979675927513540754989157746657:50001231000000:2800:A633FCD7011BF8E951319FD1956C46B8F334C196EE79B09D7C263F5813F69AFA.png?needInitFileName=true?needInitFileName=true)

若出现安装pip组件失败，可参考[修改Python源的方法](https://device.harmonyos.com/cn/docs/documentation/guide/ide-set-python-source-0000001227639986)进行修改，完成尝试重新安装；

若出现安装apt组件失败，可参考[修改apt源的方法](https://device.harmonyos.com/cn/docs/documentation/guide/faq-toolchain-install-0000001301623822)进行修改，完成后尝试重新安装。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102411.68768406760331866563301318557341:50001231000000:2800:E9372D8F996AAB79A5EA54BD0EA0F2000C586BCA58C746044F622EDD73941135.png?needInitFileName=true?needInitFileName=true)

安装完成后，工具和环境依赖的状态显示为![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102411.31777376315910143212457280032147:50001231000000:2800:04F9AF48C1E725B629DE7CEC7AED5B5453634CA965EAB58B8DB85479054B4441.png?needInitFileName=true?needInitFileName=true)。

     3. 在**bearpi_hm_nano** 配置页签中，设置源码的编译类型**build_type** ，默认为"debug类型，请根据需要进行修改。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102411.67446947878616328691064460001780:50001231000000:2800:394E3C13EDD42AC7283E158FB3599558C9B85E7FA042C316CA3F3EEE9B7C1329.png?needInitFileName=true?needInitFileName=true)

     4. 在DevEco Device Tool界面的PROJECT TASKS中，点击对应开发板下的**Build** ，执行编译。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102412.45352061175733553711723872180872:50001231000000:2800:16540F36E3B828001C4347339D43575A1EA9FC3A0D402A6FB4558A80DBAB398A.png?needInitFileName=true?needInitFileName=true)

     5. 等待编译完成，在**TERMINAL** 窗口输出“SUCCESS”，编译完成。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102412.56952848846790680361427276786412:50001231000000:2800:D9DB5EE655556A50C2E38C0E0BC9DD3665390AF452CEBB7EA0BA0D986675D501.png?needInitFileName=true?needInitFileName=true)

编译完成后，可以在工程的**out** 目录下，查看编译生成的文件，用于后续的[烧录BearPi-HM Nano开发板镜像](https://device.harmonyos.com/cn/docs/documentation/guide/ide-bearpi-hm-nano-upload-0000001115604076)。
