# 通过Remote-SSH远程连接时，提示“An SSH installation couldn't be found”

#### 问题现象

通过Remote-SSH远程连接时，弹窗提示“An SSH installation couldn't be found”。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102432.35928010281246452853959071740921:50001231000000:2800:5563D63B30D0695D434F62C51CFB9870807F1F748C026EC75EB4267F5F3C1703.png?needInitFileName=true?needInitFileName=true)

#### 解决措施

出现以上问题，主要是因为VSCode使用的Windows系统下的SSH服务的缺失，可以通过以下任意一种方式安装SSH服务解决此问题。

#### [h2]方式一：通过Windows可选功能安装OpenSSH客户端

     1. 在Windows桌面左下角，用右键点击开始，在弹出的菜单中选择**应用和功能** ，打开应用和功能页面。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102432.37367622586923353406276614470198:50001231000000:2800:3C48F9B7A36499FDBABAEBAA253F7509584B865D668E0495EA717CDE53B872CB.png?needInitFileName=true?needInitFileName=true)

     2. 在应用和功能页面，点击**可选功能** 。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102432.81094095316136905984927124513269:50001231000000:2800:B550E66FE29D6F7166ED05DC6E45E420BCA271EA0499147BD53D3FABCAF049D0.png?needInitFileName=true?needInitFileName=true)

     3. 在可选功能页面，点击**添加功能** 。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102433.55458844641275991698499281944447:50001231000000:2800:EF6CEA3BB2632F66A04EDEDFD0462F6B5DD1D4138804FC060877A767989096F1.png?needInitFileName=true?needInitFileName=true)

     4. 在添加可选功能页，输入SSH，找到OpenSSH客户端并勾选，点击安装后，等待安装完成。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102433.42900616896431705894751437826396:50001231000000:2800:71525C19F1D1B3CA9EE62BC3B396A3859EBAA14F0866A8B231D0FDF11E49D2FD.png?needInitFileName=true?needInitFileName=true)

     5. 安装完成后，关闭VSCode，重新打开，再进行远程连接。

#### [h2]方式二：通过Windows提供的PowerShell来安装OpenSSH客户端

     1. 在Windows桌面左下角，用右键点击开始，在弹出的菜单中选择Windows PowerShell（管理员）(A)。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102433.13606743003785161039715693807928:50001231000000:2800:E3708E950AF638C5F0F14424476C00730C5C0513E4B3C74260470D05AC1B30B3.png?needInitFileName=true?needInitFileName=true)

     2. 使用如下命令检测是否安装OpenSSH软件。
            
            Get-WindowsCapability -Online | ? Name -like 'OpenSSH*'

如果已安装OpenSSH，会显示如下图的信息。如果没有安装OpenSSH，请执行步骤3。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102433.79191437605798051541202581106850:50001231000000:2800:4C0E4799FCCD39CE3B1B679C4A9A8107A8F5578C369E7BF051399C2FCE503704.png?needInitFileName=true?needInitFileName=true)

     3. 使用如下命令安装OpenSSH软件。
            
            Add-WindowsCapability -Online -Name OpenSSH.Client~~~~0.0.1.0

     4. 安装完成后，关闭VS Code，重新打开，再进行远程连接。
