# 编译时，提示“'Python': No such file or directory”

#### 问题现象

编译时，提示在/usr/bin/env目录下没有python文件，即“'Python': No such file or directory”

#### 解决措施

出现以上问题，可能的原因为远程的linux服务器上没有符合要求的Python版本（Python 3.8~3.9版本）。

按照以下步骤确认远程的linux服务器上是否有符合要求的Python版本 。

     1. 在linux服务器上打开终端，输入whereis python，查询Python路径。
            
            whereis python

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102434.73410551698911148292587027363660:50001231000000:2800:E420426333CF4840F06DDBE24085E3A3F87C00288EF8ED4A170BB03BF51ED2BC.png?needInitFileName=true?needInitFileName=true)

     2. 检查输出结果是否包含/usr/bin/python3.8 或者 /usr/bin/python3.9，如果包含，则执行如下命令（命令中python版本按实际情况修改）。如果输出结果不包含usr/bin/python3.8 或者 /usr/bin/python3.9，请执行步骤3。
            
            sudo ln -s /usr/bin/python3.8 /usr/bin/python

     3. 执行如下命令，重新安装DevEco Device Tool，其中devicetool-linux-tool-3.1.0.200根据实际情况修改。
            
            sudo ./devicetool-linux-tool-3.1.0.200.sh
