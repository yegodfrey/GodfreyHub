# 远程开发模式下，检查本地计算机与远程计算机的连接状态

如果使用远程开发模式，将远程计算机对源码编译后的文件烧录到与本地计算机相连的开发板中，需要先检查本地计算机与远程计算机的连接状态。

     1. 在DevEco Device Tool中，点击**REMOTE DEVELOPMENT > Local PC** ，查看本地计算机与远程计算机的连接状态。

        * 如果Local PC右边连接按钮为![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102430.36251886041150917920355933931559:50001231000000:2800:C6509C07D60BBED9C0CD21353FB9E4F1AAF4376E759515089EC669576F38D49F.png?needInitFileName=true?needInitFileName=true)，则本地计算机与远程计算机为已连接状态，不需要执行其他操作。
        * 如果Local PC右边连接按钮为![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102430.38875266270391955388365436750265:50001231000000:2800:647CCCD30698EE09B48D41524CEA2C1EB2DBB4FD9FA7A0466B4B0F976D6F74C5.png?needInitFileName=true?needInitFileName=true)，则点击绿色连接按钮。然后执行步骤2。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102430.81170036213871468424808765923181:50001231000000:2800:D3C667E174867837421FE3D1C8A4F9535655EC4F9E82A271238CED6BE407F34C.png?needInitFileName=true?needInitFileName=true)

     2. 在弹出的输入框中，输入登录远程计算机的密码，然后回车，连接本地计算机与远程计算机。
