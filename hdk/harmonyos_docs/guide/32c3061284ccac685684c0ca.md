# 使用RTT方式传递调测信息

在嵌入式开发过程中，常需要将调试信息重定向到串口来展示，而常规的重定向方式会占用调试通信带宽或串行通信资源，当设备的串口资源较少时，会由于资源的分配问题导致重定向效果不是非常理想。

针对此种情况，从3.1.0.600版本开始，DevEco Device Tool提供RTT（Real Time Transmit）调试方式，打通Windows环境和调试设备之间的RTT通道，解放设备串口资源，实现调测信息的实时传递。

#### 前提条件

     * 开发者自行集成SEGGER提供的RTT包，并编译烧录到开发板上。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102425.21632286285007212192839049227847:50001231000000:2800:58C9B3160FE9BE2F769E983860CA9F6FC9F9FA5A5A809156487C081BCEF4BDD1.png?needInitFileName=true?needInitFileName=true)

RTT的使用方法软件包请开发者自行从因特网获取。

     * 待调测的应用已烧录到开发板上。
     * Windows环境与开发设备使用JLink调试器保持连接状态。

#### 操作步骤

     1. 在菜单栏中点击**Project Settings** ，进入工程配置界面。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102425.28667532894224866238461243647448:50001231000000:2800:D3D7E315CAE3A6E53453FD837F83D844132197C7A2D476604557C68F221E6EB3.png?needInitFileName=true?needInitFileName=true)

     2. 在开发板配置界面中，单击**manager** 按钮，打开“Configuration Manager”窗口。
     3. 开启“Show Advanced”，并在搜索框中输入“rtt”，勾选搜索到的“debug_rtt_config”并单击**Confirm** 。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102425.26224298822362741058301402381528:50001231000000:2800:30E676F9A711843048B851F683D9CFE7A83D53CA186C18B1E71BE55128C489E0.png?needInitFileName=true?needInitFileName=true)

     4. 在“Project Config”的导航树中选择“debug_rtt_config”，设置RTT配置项。

        1. 勾选“enabled”。
        2. “address”和“port”为默认配置，不可修改。
        3. 设置“type”：
           * console：调测信息以文本形式展示在终端中。
           * binary：将二进制转换为其他字节流类型，此时需要同时配置“encoding”配置项。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102425.04030444455061478785729935541941:50001231000000:2800:56D575BEB52F2E6BFAA6DA80AFA7BDCB5B9448074978880ED04E848C07382704.png?needInitFileName=true?needInitFileName=true)

     5. 启动调测应用，在“TERMINAL”中可查看到实时调测信息。
