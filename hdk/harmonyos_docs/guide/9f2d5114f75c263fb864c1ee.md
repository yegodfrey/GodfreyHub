# 烧录Bearpi-HM Micro开发板镜像

Bearpi-HM Micro的镜像烧录通过Winodow环境进行烧录，开发者启动烧录操作后，DevEco Device Tool通过Remote远程模式，将Ubuntu环境下编译生成的待烧录程序文件拷贝至Windows目录下，然后通过Windows的烧录工具将程序文件烧录至开发板中。

#### 前提条件

     * 在Windows环境中，下载并安装[STM32CubeProgrammer](https://www.st.com/zh/development-tools/stm32cubeprog.html#get-software)，安装时根据向导默认安装即可 。
     * 请安装USB转串口驱动程序，请参考[USB转串口驱动安装](https://device.harmonyos.com/cn/docs/documentation/guide/hi3861-drivers-0000001058153433)

#### 操作步骤

     1. 通过TypeC数据线，把电脑与BearPi-HM Micro开发板进行连接。
     2. 将开发板的拨码开关上拨到“000”烧录模式，并按一下开发板的**RESET** 按键。
     3. 在DevEco Device Tool中，选择**REMOTE DEVELOPMENT > Local PC**，查看远程计算机（Ubuntu开发环境）与本地计算机（Windows开发环境）的连接状态。

        * 如果Local PC右边连接按钮为![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102422.32289028712920800569002896002071:50001231000000:2800:79C1890580074B226092730D9CFB6AD249530B1B49436A4A287D9CE6E8BF8D38.png?needInitFileName=true?needInitFileName=true)，则远程计算机与本地计算机为已连接状态，不需要执行其他操作。
        * 如果Local PC右边连接按钮为![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102422.01808928218138243113032071831784:50001231000000:2800:EFC06CA0A6CDD5BA4A32F4FDBE66700E181E7601723387A4C04A0CF2553D88F4.png?needInitFileName=true?needInitFileName=true)，则点击绿色按钮进行连接。连接时DevEco Device Tool会重启服务，因此请不要在下载源码或源码编译过程中进行连接，否则会中断任务。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102422.24869793429099000175753062644214:50001231000000:2800:64B022CEE85F63D2D91A7E55B1A12DF58F1F5AF50B7E886DCA833D84FF1DA927.png?needInitFileName=true?needInitFileName=true)

     4. 在菜单栏中点击**Project Settings** 按钮，进入Bearpi-HM Micro工程配置界面。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102422.09213510749123704870841173200149:50001231000000:2800:EA02165BEE6EA81BAE7FA7996F8095AB65CC8E108C36427986FDCF5D52A2D75E.png?needInitFileName=true?needInitFileName=true)

     5. 在**Tool Chain** 页签，检查Uploader烧录器工具是否已安装。

如工具为“uninstalled”状态（![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102422.74833630761757057415966514931272:50001231000000:2800:60DAE655A0A0FDB8FAA40266224B7A3EE12BEDC2C20EEFE53A367036B0A71F9C.png?needInitFileName=true?needInitFileName=true)），表明烧录工具未安装。Bearpi-HM Micro开发板所需烧录工具暂未被DevEco Device Tool收录，需要开发者自行下载exe文件到本地后，单击![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102422.49697807886116640102010815940694:50001231000000:2800:405429AE82836E9F735A041FD20523F1F1AA16EFEDBB8AA1F091BC50A64D6092.png?needInitFileName=true?needInitFileName=true)导入。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102422.54914316764025679158583121893907:50001231000000:2800:D2ED9DD8ECC34B617075B1A2528EC43FA670942B570712E7E533FEC0952460F7.png?needInitFileName=true?needInitFileName=true)

     6. 在**bearpi_hm_micro** 页签，设置烧录选项，包括upload_port、upload_partitions和upload_protocol。配置完成后工程将自动保存。

        * **upload_port** ：选择烧录的串口。
        * **upload_protocol** ：选择烧录协议，固定选择“STM32_Programmer_CLI”。
        * **upload_partitions** ：选择待烧录的文件名称。DevEco Device Tool已预置默认的烧录文件信息，如果需要修改待烧录文件地址，可点击每个待烧录文件后的![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102422.92482241450994708870805379799119:50001231000000:2800:588940CC3BE9CECF4701C395380DF183D431BD3754F0F897AB7AD2468E2BF7AF.png?needInitFileName=true?needInitFileName=true)按钮进行修改。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102422.42591220260336892603194746101276:50001231000000:2800:DC7761249725070A809BCC62957EBD9D49552B69E29BE4DC360A1203DB2D7ACA.png?needInitFileName=true?needInitFileName=true)

在设置烧录分区起始地址和分区长度时，应根据实际待烧录文件的大小进行设置，要求设置的烧录分区大小，要大于待烧录文件的大小；同时，各烧录文件的分区地址设置不能出现重叠。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102422.32905295909594545765197473307262:50001231000000:2800:0049CC2AEA8443A68AE7B8B91B5E2EA835AAC2A63170AC3E1D4C0D3F3FDC0B68.png?needInitFileName=true?needInitFileName=true)

     7. 在**PROJECT TASKS** 中，点击**Upload** 按钮，启动烧录。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102422.39768275512155505020201082171802:50001231000000:2800:DCB02A78FBE8801546FBC00F4C8251E17D2DB7A8B30D0A8FE4D3F70E7422D96F.png?needInitFileName=true?needInitFileName=true)

界面提示**SUCCESS** 信息时，表示烧录成功。
