# 在Tool Chain点击Install安装工具链，执行pip install时，网络不可达

在开发板编译环节中，DevEco Device Tool可以一键安装开发板编译所需要的依赖，其中部分依赖需要安装Python组件。由于默认的Python源是在海外，因此，可能出现因网络问题导致安装超时和失败的情况。出现这种情况，可将Python的源修改为国内的源，然后再重新尝试安装，修改方法如下：

     1. 在Linux平台执行如下命令创建配置文件pip.conf。
            
            mkdir -p ~/.config/pip
            touch ~/.config/pip/pip.conf

     2. 通过vim打开pip.conf。（如果vim未安装，可以通过sudo apt-get install vim进行安装）。
            
            vim ~/.config/pip/pip.conf

     3. 按如下示例修改配置文件pip.conf，如下示例是以华为云的源为例进行说明，您也可以根据需要，修改为其它源。
            
            [global]
            index-url = https://repo.huaweicloud.com/repository/pypi/simple 
            trusted-host = repo.huaweicloud.com 
            timeout = 120
