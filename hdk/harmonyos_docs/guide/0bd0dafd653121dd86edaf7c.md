# 设置网口烧录的IP地址信息

     1. 使用网口连接开发板。
     2. 打开**控制面板 > 网络和Internet > 网络连接**，找到连接开发板后出现的网卡。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102435.64515175609041790604276463915933:50001231000000:2800:87E2D2155ABA2B81281EF85A5442E570AF265D8D43382AD9EB19BA9E1D447416.png?needInitFileName=true?needInitFileName=true)

     3. 点击**右键 > 属性 > 网络 > Internet协议版本4（TCP/IPv4）**，打开IP地址设置页面。
     4. 勾选“使用下面的IP地址”，然后手动输入**IP地址、子网验码和默认网关** ，如下所示。
