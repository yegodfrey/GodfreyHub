# HCS可视化管理

HCS（HDF Configuration Source）是HDF驱动框架的配置描述代码，是为了实现配置代码与驱动代码解耦，以及便于配置的管理而设计的一种Key-Value为主体的文本格式。

为了提升开发效率，DevEco Device Tool提供HCS可视化管理功能，可以通过可视化的方式对HCS文件内容进行配置。

     1. 在DevEco Device Tool的编辑器中打开.hcs文件，右键选择**HCS Configuration Source View** ，进入HCS可视化视图。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102408.67981950548744083506291246763638:50001231000000:2800:DF10D82CC6B9ADEE3B9D35CA9D7F2B2A4BD24CB5F8E5459F61070074183AE3C4.png?needInitFileName=true?needInitFileName=true)

     2. 在HCS可视化视图中，变更节点或属性信息。

HCS可视化视图支持的操作包括：

        * 点击选中某个节点，在右侧Parameters边栏中修改节点名称或类型。
        * 右击某个节点/属性：
          * 如果右击节点，可以增加子节点、子属性及删除该节点。
          * 如果右击属性，可以删除该属性。
