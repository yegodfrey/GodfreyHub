# Hi3516DV300/Hi3751V350系列开发板串口驱动安装

#### 问题现象

Windows系统，在设备管理器中查看串口信息，如果如下图所示，串口驱动异常，则需要安装USB转串口的驱动。由于使用不同的串口线，可能出现以下两种现象：

     * 现象一：提示“PL2303HXA自2012已停产，请联系供应商”

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102434.65190365415777193097146386806165:50001231000000:2800:75CF305B4ABEBB7C0EB37CEECEF6711754B063F446D8FE6C2B01C9C20CE2E98E.png?needInitFileName=true?needInitFileName=true)

     * 现象二：提示“USB Serial”

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102434.83337418128001656718644856510880:50001231000000:2800:AFA6775ECBA9AFE09EA6E89D434806DD4358397098D3EA28404C98F10B20F0FE.png?needInitFileName=true?needInitFileName=true)

#### 解决措施

     1. 点击链接[下载USB-to-Serial Comm Port](http://www.hihope.org/download/download.aspx?mtt=12)驱动程序。
     2. 点击安装包，安装驱动程序。
     3. 驱动安装完成后，重新插拔USB接口，串口信息显示如下图所示。
