# 烧录BearPi-HM Nano开发板镜像

BearPi-HM Nano的镜像烧录通过Winodow环境进行烧录，开发者启动烧录操作后，DevEco Device Tool通过Remote远程模式，将Ubuntu环境下编译生成的待烧录程序文件拷贝至Windows目录下，然后通过Windows的烧录工具将程序文件烧录至开发板中。

     1. 请连接好电脑和待烧录开发板，需要连接串口。
     2. 在DevEco Device Tool中，选择**REMOTE DEVELOPMENT > Local PC**，查看远程计算机（Ubuntu开发环境）与本地计算机（Windows开发环境）的连接状态。

        * 如果Local PC右边连接按钮为![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102420.81422707604356990630754381453671:50001231000000:2800:0E3839A7BE72135225C8D7831CC6EF2D2F39F41AF8192F9CDCD426C60798B041.png?needInitFileName=true?needInitFileName=true)，则远程计算机与本地计算机为已连接状态，不需要执行其他操作。
        * 如果Local PC右边连接按钮为![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102420.13738442530677091167687924964535:50001231000000:2800:8B3FD37674EB73F0D445F6CCAF1E7D26A99E78B2503827A4600AE4193659944B.png?needInitFileName=true?needInitFileName=true)，则点击绿色按钮进行连接。连接时DevEco Device Tool会重启服务，因此请不要在下载源码或源码编译过程中进行连接，否则会中断任务。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102420.16754135645701951313444306456325:50001231000000:2800:4BB100438900256A2B5D7A22DBFC6851E37C8536AFB3B0EDF502847F31F7EAFA.png?needInitFileName=true?needInitFileName=true)

     3. 在菜单栏中点击**Project Settings** 按钮，进入BearPi-HM Nano工程配置界面。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102420.90724926708280200777912287173026:50001231000000:2800:855E6D3251BD43646015C7F4BF2A4B1636F3EE442F221D3E86F636045771FEF2.png?needInitFileName=true?needInitFileName=true)

     4. 在**Tool Chain** 页签，检查Uploader烧录器工具是否已安装。

        * 如工具为“uninstalled”状态（![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102420.43449379153848945570623722892648:50001231000000:2800:BA99B4B28D6CD2CCE2EEFFE1BFB127E25650CD3BC8AE292059CE817A7B4BB346.png?needInitFileName=true?needInitFileName=true)），可单击**Download Uninstalled Tools** ，自动安装所需工具，或单击工具后方的**Dow****n****load** 安装指定工具。
        * 如工具无法通过**Download** 方式直接安装，可能是由于网络原因导致。此种情况下，DevEco Device Tool无法连接到工具链下载网站，需要用户自行修复网络，或通过其他方式将正式发布的[OpenHarmony工具链安装包](https://gitee.com/openharmony/docs/blob/master/zh-cn/device-dev/get-code/sourcecode-acquire.md#获取方式3从镜像站点获取)存储到本地，单击**Import** 导入。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102420.95754844848615860398797292843232:50001231000000:2800:C0D4F6AFDD0653CEA3231EB868E1DCCAADA7C80817BE17B1F9203711041952E5.png?needInitFileName=true?needInitFileName=true)

     5. 在**bearpi_hm_nano** 页签，设置烧录选项，包括upload_port、upload_partitions和upload_protocol。配置完成后工程将自动保存。

        * upload_partitions：选择待烧录的文件名称。DevEco Device Tool已预置默认的烧录文件信息，如果需要修改待烧录文件地址，可点击每个待烧录文件后的![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102420.41995495643098601343534820629152:50001231000000:2800:640B8C80DD7A0B071EF7AF41559712DB8F18B3AA729701B65E191B5BACAB1F30.png?needInitFileName=true?needInitFileName=true)按钮进行修改。
        * upload_protocol：选择烧录协议，这里选择“hiburn-serial”。
        * upload_port：选择烧录的串口。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102420.13460180439260110803722553142977:50001231000000:2800:7A93691CB0F31B46F7203B2023D5ED7F872107EE2B44F6209057F622AE2B69A3.png?needInitFileName=true?needInitFileName=true)

     6. 在“PROJECT TASKS”中，点击**Upload** 按钮，启动烧录。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102420.15654863199661362322482522969210:50001231000000:2800:45A3C841F600C437BE2945A516431DFBA5E9F54C8BBDA144E8DAE018C43F5E9D.png?needInitFileName=true?needInitFileName=true)

     7. 启动烧录后，显示如下提示信息时，请在15秒内，按下开发板上的RST按钮重启开发板。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102420.13598451545018455915846081577888:50001231000000:2800:ECC374F74C0FDE0E75A1AB834159A31804EDF4B7A9ED5E332EDF8863CC9EDAEF.png?needInitFileName=true?needInitFileName=true)

重新上电后，界面提示如下信息时，表示烧录成功。
