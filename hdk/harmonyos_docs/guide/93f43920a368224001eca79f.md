# 编译Hispark Phoenix开发板源码

DevEco Device Tool支持Hispark Phoenix开发板（基于Hi3751V350芯片）的源码一键编译功能，提供编译工具链和编译环境依赖的检测及一键安装，简化复杂编译环境的同时，提升了编译的效率。

Hispark Phoenix开发板编译环境为Ubuntu环境，支持的OpenHarmony源码版本为3.2 Beta1及以上。

#### 前提条件

获取OpenHarmony的源码存在多种方式，具体请参考[创建OpenHarmony工程](https://device.harmonyos.com/cn/docs/documentation/guide/create_project-0000001072200151)或[导入OpenHarmony源码](https://device.harmonyos.com/cn/docs/documentation/guide/open_project-0000001071680043)。如果导入的源码是通过“repo方式”获取，在执行编译前，请执行如下脚本安装编译器及二进制工具。通过其它方式获取的OpenHarmony源码，请跳过该操作。
    
    bash build/prebuilts_download.sh

#### 操作步骤

     1. 在菜单栏中点击**Project Settings** ，进入Hispark Phoenix工程配置界面。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102410.55030886725952827875093802318448:50001231000000:2800:B4EF03D6161722F9F568ADB7545BE4E8DCFE4CE570322B76C528EF59C31917AB.png?needInitFileName=true?needInitFileName=true)

     2. 在**Tool Chain** 页签中，DevEco Device Tool会自动检测环境依赖是否完备。

        * 如工具为“uninstalled”状态（![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102411.09417333950284407937114927290327:50001231000000:2800:26BA731E08EAE9626795ADF7179BD084FC1B2F5E41C1451FA6ED5C4267B51185.png?needInitFileName=true?needInitFileName=true)），可单击**Download Uninstalled Tools** ，自动安装所需工具，或单击工具后方的**Dow****n****load** 安装指定工具。
        * 如当前识别到的工具类型有缺失，需要补充，可单击**Add Utility** 添加。
        * 如工具无法通过**Download** 方式直接安装，可能是由于网络原因导致。此种情况下，DevEco Device Tool无法连接到工具链下载网站，需要用户自行修复网络，或通过其他方式将正式发布的[OpenHarmony工具链安装包](https://gitee.com/openharmony/docs/blob/master/zh-cn/device-dev/get-code/sourcecode-acquire.md#获取方式3从镜像站点获取)存储到本地，单击**Import** 导入。
        * 如“OpenHarmony Environment Dependency”的状态异常（![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102411.50272180947572875758361182110731:50001231000000:2800:FF3F0773D4D42DD5068A41AA8358221FD02D06421DEDF9D5557272342DDE0552.png?needInitFileName=true?needInitFileName=true)），请单击**Install** 安装。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102411.12243918528156886267164434451778:50001231000000:2800:84A93D9C9C4A26A4A9A715987776B5038CEF2078079C2A9D4B031F1AD10CE2CE.png?needInitFileName=true?needInitFileName=true)

部分依赖安装需要使用root权限，请在**TERMINAL** 窗口输入用户密码进行安装。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102411.03606355178721163532498669743860:50001231000000:2800:31C5CE35D42F04954768D27BB6EB06E74A4B26C12CDD92D5694D3C1C9E7940E1.png?needInitFileName=true?needInitFileName=true)

若出现安装pip组件失败，可参考[修改Python源的方法](https://device.harmonyos.com/cn/docs/documentation/guide/ide-set-python-source-0000001227639986)进行修改，完成尝试重新安装；

若出现安装apt组件失败，可参考[修改apt源的方法](https://device.harmonyos.com/cn/docs/documentation/guide/faq-toolchain-install-0000001301623822)进行修改，完成后尝试重新安装。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102411.38281489355297717098640237896761:50001231000000:2800:D6EA249CCDBFF567D44D97B300073F97C0A661DC87D5739FA82BEC19FFACBB3E.png?needInitFileName=true?needInitFileName=true)

安装完成后，工具和环境依赖的状态显示为![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102411.83028320590207575686640103480540:50001231000000:2800:6B969B2CD558B68EC69D6013CC23CA5C01546B46CE49B7D654968B5DA82C84E5.png?needInitFileName=true?needInitFileName=true)。

     3. 在**PROJECT TASKS** 中，点击对应开发板下的**Build** ，执行编译。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102411.14925765904178969278416924323191:50001231000000:2800:8B315DFB83EDA7A8202CA4EE45ACF3F308E7652A01844BCA2B0DA3B8C8169C68.png?needInitFileName=true?needInitFileName=true)

     4. 等待编译完成，在**TERMINAL** 窗口输出“SUCCESS”，编译完成。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102411.39196166526734450288051089087900:50001231000000:2800:C97ADE87C37352C4F3B04FCBAD06B487545060154E002BEF47BCEE8D70E6B5DE.png?needInitFileName=true?needInitFileName=true)

编译完成后，可以在工程的**out** 目录下，查看编译生成的文件，用于后续的[烧录Hispark Phoenix开发板镜像](https://device.harmonyos.com/cn/docs/documentation/guide/upload_hispark_phoenix-0000001334326461)。
