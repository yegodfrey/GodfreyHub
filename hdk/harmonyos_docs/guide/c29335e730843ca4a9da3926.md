# 串口工具使用

DevEco Device Tool集成了串口工具，可以方便的使用串口工具连接上开发板。主要用于以下场景：

     * Hi3516DV300/Hi3518EV300开发板：使用串口工具运行镜像
     * Hi3861V100开发板：使用串口工具执行AT指令

以Hi3516DV300开发板为例，串口工具的使用方法如下：

     1. 点击工具栏的**Monitor** ，打开串口工具。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102434.37760881857449321327150900364091:50001231000000:2800:AAABF3B6A52D1406BBC2CC8F9FD46A067C2F9DABA978629037E3031B3C7A5E4B.png?needInitFileName=true?needInitFileName=true)

     2. 在TERMINAL中，输入对应的编号选择串口。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102434.94600864464480448414558586018335:50001231000000:2800:32973B62A1D2FDF50FD6EFA74BD974458628D5B6A6F87677265D38A44D85B7FD.png?needInitFileName=true?needInitFileName=true)

     3. 进入串口工具后，执行相关指令，具体请参考[Hi3516DV300镜像运行](https://device.harmonyos.com/cn/docs/documentation/guide/quickstart-lite-steps-hi3516-running-0000001144234446)、[Hi3518EV300镜像运行](https://device.harmonyos.com/cn/docs/documentation/guide/quickstart-lite-steps-hi3518-running-0000001144074654)和[Hi3861V100执行AT指令](https://docs.openharmony.cn/pages/v5.0/zh-cn/device-dev/quick-start/quickstart-ide-3861-running.md/)。
