# DevEco Device Tool 3.1Beta2安装后再安装之前的版本无弹窗提示已存在安装版本

如果您已安装DevEco Device Tool 3.1 Beta2版本，在未卸载的情况下，再次安装DevEco Device Tool 3.1 Beta2之前的版本，未正常弹出弹框提示已存在安装版本，进而未引导您进入卸载流程。

出现该问题的原因是：自从3.1Beta2版本开始，DevEco Device Tool切换了程序安装框架，之前版本的旧程序安装框架无法检测新程序安装框架，所以无法检测出已安装版本。

您可以通过手动卸载的方式，先卸载已安装的新版本软件，再重新安装之前的版本。手动卸载的方式如下：

     * 方式一：进入**控制面板 > 程序 > 程序和功能 > 卸载程序**，双击列表中的DevEco Device Tool，根据提示完成卸载。
     * 方式二：进入DevEco Device Tool安装目录（如果遗忘了安装目录，可以在C:\Users\用户名\\.deveco-device-tool\ settings.json文件中的'path'字段中找到），双击“uninstall.exe”卸载程序，根据提示完成卸载。
