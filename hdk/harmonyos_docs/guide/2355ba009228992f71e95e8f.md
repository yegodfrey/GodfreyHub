# 提示Python3不存在的处理方法

#### 问题现象

在Windows平台下安装DevEco Device Tool过程中，弹出报错信息如下图：

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102431.01763607495188490615438065209668:50001231000000:2800:F080F33685BE032FABDACCAC37F0D7B492ABD8161063C346FAEF1287C9DE45E7.png?needInitFileName=true?needInitFileName=true)

#### 解决措施

#### [h2]安装的DevEco Device Tool为3.0 Beta1版本

当安装的DevEco Device Tool为3.0 Beta1版本，出现以上报错信息可能的原因为系统环境变量缺少配置。

按如下步骤在系统变量中添加“C:\Windows\system32”。

     1. 打开环境变量窗口，双击变量Path或选中Path后点击编辑，打开编辑环境变量窗口。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102431.85222929982561852559900219532161:50001231000000:2800:5C8E4FA8A7035A58667E4F733003941B7B2BBB74331616DDD411923DD34066CF.png?needInitFileName=true?needInitFileName=true)

     2. 在编辑环境变量窗口，点击新建，在输入框中填写“C:\Windows\system32”，然后点击确定，完成环境变量的配置。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102431.40147017169955390899073739431592:50001231000000:2800:B009AD8CD9B35F00639D6278EED9FA763EAA696703EBED64D64BA9CF1CE05CB5.png?needInitFileName=true?needInitFileName=true)

#### [h2]安装的DevEco Device Tool为2.1 Release版本

当安装的DevEco Device Tool为2.1Release版本，出现以上报错信息可能的原因为：

     1. 未安装python或python版本不正确，与DevEco Device Tool 2.1 Release匹配的Python版本为64位的3.7.4 ~ 3.8

打开CMD命令行工具，输入python：

如果提示命令找不到，开发者需要安装python，且python版本为：3.7.4 ~ 3.8。

如果返回的python版本不是3.7.4 ~ 3.8，开发者需要重新安装匹配的版本。

如果Python是32位的，请重新安装64位的Python。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102431.21886416080288648273972118011811:50001231000000:2800:A7308E2883F33147530AD6D38CE7E891A7E123C1A69A612EABC2AE077492D210.png?needInitFileName=true?needInitFileName=true)

     2. 通过Anaconda管理安装的python

DevEco Device Tool 2.1 Release暂时不支持这种方式，建议单独安装DevEco Device Tool匹配的python版本。

     3. 系统环境变量缺少配置

参考如上步骤，在系统变量中添加“C:\Windows\system32”。
