# DevEco Device Tool工具安装过程中的日志文件获取

DevEco Device Tool为3.0 Beta1版本以及之后的版本，支持用户自定义安装目录，安装过程中的日志文件保存在DevEco Device Tool的安装目录。

例如：在安装过程中选择了F盘，则日志文件保存在F:\Huawei\DevEco-Device-Tool，文件名为InstallationLog.txt。

获取到日志后，如需帮助，可访问[华为开发者论坛-华为开发者联盟 (huawei.com)](https://developer.huawei.com/consumer/cn/forum/block/device)。
