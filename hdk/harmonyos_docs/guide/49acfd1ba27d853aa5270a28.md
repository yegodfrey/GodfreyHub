# 编译或烧录时，提示“Please install 'node' first”的处理方法

#### 问题现象

在Remote模式下编译或烧录时，未检测到Node.js，则会出现以下“Please install ‘node’first”的报错信息。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102433.99738995753033282464007266422063:50001231000000:2800:F5904D5F9BAA08E24CFC563E159DC2F026CAE0E8E817DEE0646B385DE8FF9F13.png?needInitFileName=true?needInitFileName=true)

#### 解决措施

     1. 在Ubuntu环境的用户目录下，执行以下命令，打开**.bashrc** 文件。
            
            vim ~/.bashrc

     2. 在**.bashrc** 文件找到设置node环境变量的语句，如下图所示，将该语句先复制，然后再注释该语句。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102433.06519117070332975000799381640181:50001231000000:2800:568FBC40349CE9B4F5B9C02B5ADEDD67D8849C5B0AA88A6906F812B0A1E3A68E.png?needInitFileName=true?needInitFileName=true)

     3. 执行vim ~/.profile文件，打开**.profile** 文件，将步骤2复制的语句添加到**.profile** 文件末尾并保存退出。
            
            vim ~/.profile

     4. 分别执行source ~/.bashrc 和source ~/.profile命令，重新加载这两个文件。
            
            source ~/.bashrc
            
            source ~/.profile

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102433.38578012442001970458830239660755:50001231000000:2800:2ABB801CCD89FDF039D98659A90E9D511002CCD9945B4D94913AD664BEACE203.png?needInitFileName=true?needInitFileName=true)

~/.profile：每个用户可使用该文件自定义个人用户的shell信息。每当用户登录时执行一次修改，默认保存的是环境变量的配置信息。然后执行用户的.bashrc文件。

~/..bashrc：该文件包含专用于某个用户的bash shell的bash信息，当该用户登录时以及每次打开新的shell时，该文件被读取。
