# Perf分析

DevEco Device Tool提供Perf分析功能，可以通过对开发板源码进行事件采样，获取CPU硬件事件、高精度周期事件、OS软件事件，生成Perf文件。Perf分析器对输出的perf文件进行热点函数和热点路径分析。基于Perf分析，可以进行算法优化、代码优化，以提高执行速度、减少内存占用。

Perf分析功能，当前只支持LiteOS内核的轻量和小型系统。

下面以Hi3516DV300为例，介绍Perf分析功能的使用。

#### 启动Perf分析

**前提条件**

     * 已获取开发板源码，当前支持Perf分析的源码为Openharmony Master主干源码。
     * 已连接开发板。

**操作步骤**

     1. 打开工程/源码，具体可参考[导入OpenHarmony源码](https://device.harmonyos.com/cn/docs/documentation/guide/open_project-0000001071680043)。
     2. 在**PROJECT TASKS** 中，点击hi3516DV300下的**Menu Config** ，在右侧TERMINAL窗口中，使用键盘的方向键，选中Kernel，点击向右方向键，进入Kernel配置页面。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102428.60432077139786791349883745359866:50001231000000:2800:608F644163CB68D80FE2AF94EAA9CC9BF6ACA3A127FD0B59DDF8D394BB079834.png?needInitFileName=true?needInitFileName=true)

     3. 在**Kernel** 配置页面，使用键盘的方向键，选中**Enable Hook Feature** ，点击向右方向键，开启Hook功能；选中**Enable Perf Feature** ，点击向右方向键，开启Perf功能，开启后，如下图所示。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102429.27435707509263176117222689561870:50001231000000:2800:50E83DD634FF7523EFE419DA80070F95EE9295D8549A8E38E4FECE0738A93303.png?needInitFileName=true?needInitFileName=true)

     4. 点击**ESC** 键，在弹出的对话框中选中保存配置。
     5. 编译开发板源码，具体请参考[编译Hi3516DV300开发板源码](https://device.harmonyos.com/cn/docs/documentation/guide/ide-hi3516dv300-compile-0000001146686054)。
     6. 烧录开发板源码，具体请参考[烧录Hi3516DV300开发板镜像](https://device.harmonyos.com/cn/docs/documentation/guide/upload_hi3516_small_system-0000001326267405)。
     7. 在**PROJECT TASKS** 中，点击hi3516DV300下的**Configure bootloader(Boot OS)** ，在右侧**TERMINAL** 窗口出现重启开发板提示“Please reset the board”时，重启开发板，等待TERMINAL窗口提示“SUCCESS”。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102429.90978971838243983232949823995775:50001231000000:2800:299608F0609B885FE7EA4D08B184DDF39593CEDED46CFF47056B443D1B7623F3.png?needInitFileName=true?needInitFileName=true)

     8. 在**PROJECT TASKS** 中，点击hi3516DV300下的**Monitor** ，在右侧TERMINAL窗口输入如下命令
            
            cd /bin //切换当前目录到bin目录
            ./perf list  // 查询当前支持的事件

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102429.24141813384615461961256638447596:50001231000000:2800:C226DFC12CB69E6469E47CE5275EF29B508C7D1F4C879940508441DA5AA7D87D.png?needInitFileName=true?needInitFileName=true)

     9. 根据上一步查询结果，将{event-name}替换成对应的事件名，执行下列指令，生成perf.data。
            
            ./perf record -e {event-name} cycles //设置采样事件名称
            ./perf start// 开始采样
            ./perf stop //结束采样

采样结束后，通过如下命令，可以看到生成的perf.data，并通过nfs方法将perf.data文件从开发板中共享到本地电脑。
            
            cd /storage/data//切换当前目录到data目录
            ls //列出当前目录下的文件

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102429.34056661889749671828188651778941:50001231000000:2800:F691BC4B5DFF38B99EEE54BFA49E2987EA54A1616ADD032907009C3D5389B32A.png?needInitFileName=true?needInitFileName=true)

     10. 点击**Product** **Settings** ，在**hi3516dv300** 配置页签中，配置Analysis Options。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102429.41090164549040400605014396954996:50001231000000:2800:BBDD9E83B0A50F18292A58067D18BD5A96D01E01E8CCC0F693B6FB8B663C1A60.png?needInitFileName=true?needInitFileName=true)

如果Project Config选项中没有以下配置项，可点击manager按钮，然后在配置框中分别勾选上相应选项即可。

        * **analysis_rootfs_path** ：配置到rootfs文件夹，编译时自动生成，默认在out\hispark_taurus\ipcamera_hispark_taurus路径下。
        * **analysis_perf_path** ：配置为步骤5中共享到本地电脑的perf.data文件。
        * **analysis_elf_path** ：配置为OHOS_image文件所在路径，OHOS_image为编译时自动生成，默认在out\hispark_taurus\ipcamera_hispark_taurus路径下。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102429.20339428018351534194065807657747:50001231000000:2800:08A69FA9B450F317CF741FE6A691AAA4716D600B0B861C16AB28B8DED1AA2083.png?needInitFileName=true?needInitFileName=true)

     11. 在**PROJECT TASKS** 中，点击hi3516DV300下的**Perf Analysis** ，进入Perf分析页面。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102429.41686389544886426019906444139814:50001231000000:2800:C53A43BB42F57D214D1825E6458C5A76CB51AD0AD48BD2B280196FC03E8447C5.png?needInitFileName=true?needInitFileName=true)
