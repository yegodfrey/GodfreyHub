# 编译Hi3516DV300开发板源码

DevEco Device Tool支持Hi3516DV300开发板的源码一键编译功能，提供编译工具链和编译环境依赖的检测及一键安装，简化复杂编译环境的同时，提升了编译的效率。Hi3516DV300分别支持“小型系统”和“标准系统”的OpenHarmony源码编译：

     * Small System，小型系统：面向应用处理器，例如Arm Cortex-A的设备，参考内存≥1MiB，提供更高的安全能力，提供标准的图形框架，提供视频编解码的多媒体能力。典型产品有智能家居领域的IPCamera、电子猫眼、路由器以及智慧出行域的行车记录仪等。
     * Standard System，标准系统：面向应用处理器，例如Arm Cortex-A的设备，参考内存≥128MiB，提供增强的交互能力，提供3D GPU以及硬件合成能力，提供更多控件以及动效更丰富的图形能力，提供完整的应用框架。典型产品有高端的冰箱显示屏等。

Hi3516DV300“小型系统”和“标准系统”的源码编译过程完全相同，编译环境为Ubuntu环境，下面以“小型系统”为例进行介绍。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102409.51759824791560401710500599888944:50001231000000:2800:3B67ED539FBABE6F352940AEFEEBF6E8715CC7D8D14303230F84A258D9622D59.png?needInitFileName=true?needInitFileName=true)

OpenHarmony 3.2之前版本标准系统可成功编译运行于Hi3516DV300开发板，3.2及之后版本标准系统不再针对Hi3516DV300开发板提供完整验证，可能无法编译或运行。

#### 前提条件

获取OpenHarmony的源码存在多种方式，具体请参考[创建OpenHarmony工程](https://device.harmonyos.com/cn/docs/documentation/guide/create_project-0000001072200151)或[导入OpenHarmony源码](https://device.harmonyos.com/cn/docs/documentation/guide/open_project-0000001071680043)。如果导入的源码是通过“repo方式”获取，在执行编译前，请执行如下脚本安装编译器及二进制工具。通过其它方式获取的OpenHarmony源码，请跳过该操作。
    
    bash build/prebuilts_download.sh

#### 操作步骤

此处以**ipcamera_hispark_taurus** 为例，**ipcamera_hispark_taurus****_linux** 、**hispark_taurus_standard** 等Hi3516DV300相关产品的编译过程与此相同。

     1. 在菜单栏中点击**Project Settings** ，进入Hi3516DV300工程配置界面。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102409.22027895706143721055463217503035:50001231000000:2800:4385FD54164A49856F3DD42B4350C96025ABF24855341A926E6598E564944C4F.png?needInitFileName=true?needInitFileName=true)

     2. 在**Tool Chain** 页签中，DevEco Device Tool会自动检测依赖的编译工具链是否完备。

        * 如工具为“uninstalled”状态（![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102409.26760582148970399232384582825984:50001231000000:2800:3F48E8D31D5B57A8224880AED91D43E765D99A1477BB40BB73B442D25F580281.png?needInitFileName=true?needInitFileName=true)），可单击**Download Uninstalled Tools** ，自动安装所需工具，或单击工具后方的**Dow****n****load** 安装指定工具。
        * 如当前识别到的工具类型有缺失，需要补充，可单击**Add Utility** 添加。
        * 如工具无法通过**Download** 方式直接安装，可能是由于网络原因导致。此种情况下，DevEco Device Tool无法连接到工具链下载网站，需要用户自行修复网络，或通过其他方式将正式发布的[OpenHarmony工具链安装包](https://gitee.com/openharmony/docs/blob/master/zh-cn/device-dev/get-code/sourcecode-acquire.md#获取方式3从镜像站点获取)存储到本地，单击**Import** 导入。
        * 如“OpenHarmony Environment Dependency”的状态异常（![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102409.28480939749972527719911171725546:50001231000000:2800:281DFB6E833CA60F80A5D5F0738892FD1E22D15CBFAA3C131A02D3FA62C0B87C.png?needInitFileName=true?needInitFileName=true)），请单击**Install** 安装。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102409.91441661121923871408453855615266:50001231000000:2800:E69498330174405598D693BE723F91EA771240764FD162A44D2E81A507F5BC49.png?needInitFileName=true?needInitFileName=true)

部分工具安装需要使用root权限，请在**TERMINAL** 窗口输入用户密码进行安装。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102409.43808365944664932460911025890411:50001231000000:2800:7827B996097CA47ECEB77B803C31BA71B8CAADA29252495272BAC745E362BBBF.png?needInitFileName=true?needInitFileName=true)

若出现安装pip组件失败，可参考[修改Python源的方法](https://device.harmonyos.com/cn/docs/documentation/guide/ide-set-python-source-0000001227639986)进行修改，完成尝试重新安装；

若出现安装apt组件失败，可参考[修改apt源的方法](https://device.harmonyos.com/cn/docs/documentation/guide/faq-toolchain-install-0000001301623822)进行修改，完成后尝试重新安装。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102410.83079854071932456271910209413189:50001231000000:2800:D4EE7F0FC57CC56AECC342FA3FBB5FE1A1F219A177D535E7698C4D7C07539D24.png?needInitFileName=true?needInitFileName=true)

安装完成后，工具和环境依赖的状态显示为![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102410.67357173316322518715606748106512:50001231000000:2800:BFD0E0A8C71ECDB3EA5C01A8C43AA637D6A875D47C3BF6EF8414B83A9AA89E9D.png?needInitFileName=true?needInitFileName=true)。

     3. 在**ipcamera_hispark_taurus** 配置页签中，设置源码的编译类型**build_type** ，默认为“debug”类型，请根据需要进行修改。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102410.34438273900456971708305968338133:50001231000000:2800:FC7F0B9B51125D0B106149C75D57DAE9A71C761C67D80941A28AD7C209229470.png?needInitFileName=true?needInitFileName=true)

     4. 在**PROJECT TASKS** 中，点击对应开发板下的**Build** ，执行编译。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102410.66466971710157636310802009202257:50001231000000:2800:9D07364CE5728EE603E4BAA8388FE3238B43DAF9E8E43BC20CABFAF892733158.png?needInitFileName=true?needInitFileName=true)

     5. 等待编译完成，在**TERMINAL** 窗口输出“SUCCESS”，编译完成。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102410.32598557488760590077596778666273:50001231000000:2800:18052B7A7F5BEF72C5B3C01DA4F91D8D73CDA33D7CD50CB3F493ED452709D62A.png?needInitFileName=true?needInitFileName=true)

编译完成后，可以在工程的**out** 目录下，查看编译生成的文件，用于后续的[Hi3516DV300开发板烧录](https://device.harmonyos.com/cn/docs/documentation/guide/upload_hi3516_small_system-0000001326267405)。
