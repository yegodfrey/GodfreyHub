# 注册远程访问Ubuntu环境的公钥

通过Windows远程连接Ubuntu环境进行开发，在连接过程中，需要您频繁的输入远程连接密码来进行连接。为解决该问题，您可以使用SSH公钥来进行设置。

注册远程访问Ubuntu环境的公钥，需要使用Git工具执行相关命令，请提前安装Git工具。

     1. 双击**Git bash****.exe** 命令行窗口，执行如下命令。其中username和ip请填写ubuntu系统用户名与ip地址。ip地址可在ubuntu终端中使用ifconfig获取。
            
            ssh-keygen -t rsa
            ssh-copy-id -i ~/.ssh/id_rsa.pub username@ip

生成的SSH公钥文件id_rsa.pub默认存储在C:\Users\username\\.ssh目录下，其中username为用户实际用户名，如果username字符串中存在空格，使用命令ssh-copy-id -i ~/.ssh/id_rsa.pub username@ip将SSH公钥复制到远程环境时，会报错“ERROR：failed to open ID file 'XXX': No such file or directory”，此时，使用双引号将含有空格的文件路径括起来，即ssh-copy-id -i "C:\Users\username\\.ssh\id_rsa.pub"username@ip。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102430.67415701001170467180731899808923:50001231000000:2800:54B6BF46E5F8CA164E5093ED71583979BC25620B77E258F4E39A546F387EECEA.png?needInitFileName=true?needInitFileName=true)

     2. 命令执行过程中，公钥储存位置若为默认，直接回车进行下一步；根据界面提示，设置passphrase公钥密码或直接回车留空，并再次输入确认。程序若扫描本地并查找到公钥文件后，按照提示输入ubuntu帐户密码。命令执行完毕，此时SSH公钥已生成，并成功复制到ubuntu远程环境。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102430.29088328733942588262855987212314:50001231000000:2800:39EAA3F838971739F1594841E2DE91090626ED4445390F6AD876E78BB357C85B.png?needInitFileName=true?needInitFileName=true)

若设置了passphrase公钥密码，则在远程连接ubuntu环境时，将提示您输入该密码。

若出现蓝框标注的连接提示，说明此时本地客户端无法识别远程主机，输入yes后回车继续执行。

     3. 在Visual Studio Code中，点击远程连接的设置按钮，并选择打开config文件。
