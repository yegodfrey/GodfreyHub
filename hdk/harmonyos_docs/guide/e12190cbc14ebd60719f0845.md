# DevEco Device Tool插件安装失败处理办法

如果您已安装DevEco Device Tool 3.0 Release及以前的版本，在安装DevEco Device Tool 3.1 Beta1版本后，使用Remote远程模式连接后，可能出现一直停留在DevEco Device Tool的插件安装界面，如下图所示。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102429.63510439070781073818034298374414:50001231000000:2800:6EC515557E8C897DD59183AE93619A9DE413229ABE161D5B79C4DBE5B1661FA9.png?needInitFileName=true?needInitFileName=true)

如果出现以上问题现象，可通过如下方式进行解决：

     1. 使用Remote远程连接模式连接Ubuntu环境。
     2. 在Visual Studio Code的插件管理窗口，手动卸载**DevEco Device Tool Debug** 和**Huawei DevEco Device Tool** 插件。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102429.73924218194058110532935741820324:50001231000000:2800:B478BC428A05D57DEB9A6FD76ABEC00D24A4CD8A93262AF0DD626CE01CEE90AF.png?needInitFileName=true?needInitFileName=true)

     3. 重新加载或重启Visual Studio Code，等待插件自动安装完成。
