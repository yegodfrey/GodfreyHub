# 安装DevEco Device Tool后，打开VSCode，提示“No Python at 'xxx\python.exe'”的处理方法

#### 问题现象

在Windows平台安装了DevEco Device Tool后，如果重新安装了Python，且安装过程中修改了安装的路径。当再次打开VSCode的时候，无法打开DevEco Device Tool，日志信息提示“No Python at'D:\Program Files\Python38\python.exe'”。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102432.38183936348302108721132671127551:50001231000000:2800:2369BD34B054B8702577DE732C080F87F1FAD6347E3828E679DACBC36EFE4CD4.png?needInitFileName=true?needInitFileName=true)

#### 解决措施

出现以上情况，是因为DevEco Device Tool运行需要使用python的虚拟环境，DevEco Device Tool安装目录\core\deveco-venv\pyvenv.cfg配置文件中保存了Python的安装路径。

如果开发者重新安装Python且更换了安装路径后，DevEco Device Tool工具无法正常发现Python，可以通过任意一种方式解决：

方式一：手动修改配置文件pyvenv.cfg中的Python安装路径.

     * ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102432.75193894893641703481115375604942:50001231000000:2800:66FE455752221705D2AA11FD0CD7C718F15ABE4C0186859EEAB35C0E035ABCDD.png?needInitFileName=true?needInitFileName=true)

     * 方式二：重新安装DevEco Device Tool，会自动读取Python的安装路径并写入到pyvenv.cfg配置文件中。
