# OpenHarmony设备开发文档

[OpenHarmony](https://docs.openharmony.cn/pages/zh-cn/了解OpenHarmony/了解OpenHarmony开源项目/)是由开放原子开源基金会（OpenAtom Foundation）孵化及运营的开源项目，目标是面向全场景、全连接、全智能时代，基于开源的方式，搭建一个智能终端设备操作系统的框架和平台，促进万物互联产业的繁荣发展。

如果您开发的设备使用到OpenHarmony能力，请参考“[OpenHarmony设备开发文档](https://docs.openharmony.cn/pages/v5.0/zh-cn/device-dev/device-dev-guide.md/)”进行开发。
