# 使用测试套件完成Rust测试

OpenHarmony为开发者提供了自测试框架，开发者可根据测试需求开发相关测试用例，在开发阶段提前发现缺陷，提高代码质量。但手动测试用例操作相对繁琐，为提升测试效率，从4.0 Release版本起，DevEco Device Tool支持Rust测试套件的整体编译，为开发者提供便捷的自测工具，提升开发效率。

#### 前提条件

已导入所需工程。

#### 操作步骤

     1. 在TERMINAL中执行如下命令编译指定测试套件。

命令格式为：
            
            ./build.sh --product-name 设备类型 --target-cpu arm --build-target 待编译测试套件路径 --fast-rebuild --no-prebuilt-sdk

OpenHarmony默认提供的Rust测试套件源码路径为“base/hiviewdfx/hitrace/test/unittest/rust/”，开发者可自行设计符合[测试框架](https://gitee.com/openharmony/docs/blob/master/zh-cn/readme/测试子系统.md#测试框架目录简介)要求的测试用例及存放路径。

示例如下：
            
            ./build.sh --product-name rk3568 --target-cpu arm --build-target base/hiviewdfx/hitrace/test/unittest/rust/hitracechain:rust_hitracechain_test --fast-rebuild --no-prebuilt-sdk

     2. 启动hdc。

        1. 参考[使用远程hdc能力](https://device.harmonyos.com/cn/docs/documentation/guide/remote_hdc-0000001491837812)配置hdc环境。
        2. 在“PROJECT TASKS”中单击HDC，启动hdc服务。

     3. 修改配置。

打开源码根目录下的“test/testfwk/developer_test/config/user_config.xml”进行如下设置：

        * testcase：设置为true则自动编译测试套件，设置为false不会自动化编译。此处建议设置为**false** 。
        * device：hdc服务信息，即步骤2中配置的hdc_server_ip和hdc_server_port。设备sn为自动获取字段，不需要修改。
        * test_cases：测试套件编译后的存放路径。
