# 编译RK3568开发板源码

DevEco Device Tool支持Rockchip RK3568开发板的源码一键编译功能，提供编译工具链和编译环境依赖的检测及一键安装，简化复杂编译环境的同时，提升了编译的效率。

RK3568开发板编译环境为Ubuntu环境。

#### 前提条件

获取OpenHarmony的源码存在多种方式，具体请参考[创建OpenHarmony工程](https://device.harmonyos.com/cn/docs/documentation/guide/create_project-0000001072200151)或[导入OpenHarmony源码](https://device.harmonyos.com/cn/docs/documentation/guide/open_project-0000001071680043)。如果导入的源码是通过“repo方式”获取，在执行编译前，请执行如下脚本安装编译器及二进制工具。通过其它方式获取的OpenHarmony源码，请跳过该操作。
    
    bash build/prebuilts_download.sh

#### 操作步骤

     1. 在菜单栏中点击**Project Settings** ，进入RK3568工程配置界面。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102412.77070506552011275118141449458760:50001231000000:2800:184650739851C3221AD0C536F8C4F8D7E2FB3AC5C776711F200D21E2F46BE80C.png?needInitFileName=true?needInitFileName=true)

     2. 在**Tool Chain** 页签中，DevEco Device Tool会自动检测依赖的编译工具链是否完备。

        * 如工具为“uninstalled”状态（![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102412.71764513427550131877898090136237:50001231000000:2800:1D99D8EB7AAAB53EA59484C3491472D5B7D10D1134A3E27C30F89F403CC0895A.png?needInitFileName=true?needInitFileName=true)），可单击**Download Uninstalled Tools** ，自动安装所需工具，或单击工具后方的**Dow****n****load** 安装指定工具。
        * 如当前识别到的工具类型有缺失，需要补充，可单击**Add Utility** 添加。
        * 如工具无法通过**Download** 方式直接安装，可能是由于网络原因导致。此种情况下，DevEco Device Tool无法连接到工具链下载网站，需要用户自行修复网络，或通过其他方式将正式发布的[OpenHarmony工具链安装包](https://gitee.com/openharmony/docs/blob/master/zh-cn/device-dev/get-code/sourcecode-acquire.md#获取方式3从镜像站点获取)存储到本地，单击**Import** 导入。
        * 如“OpenHarmony Environment Dependency”的状态异常（![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102412.99662835833737486276307139131662:50001231000000:2800:0481762EF66C4F3FE8B5EA65ABC747C6CCE88CBBD2A80D16E809CE73F57240C3.png?needInitFileName=true?needInitFileName=true)），请单击**Install** 安装。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102412.19552325873305510313268439224748:50001231000000:2800:0D3451C6D1389F3DA42337611D2D493CA806E34E2F47EAFA6CC5B716CDB16567.png?needInitFileName=true?needInitFileName=true)

部分工具的安装需要使用root权限，请在**TERMINAL** 窗口输入用户密码进行安装。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102413.21531232719651713576925245039283:50001231000000:2800:0904E7754460F2F013A95CDB090B5D391611494FD4F92AF8B4351DD715C2D998.png?needInitFileName=true?needInitFileName=true)

若出现安装pip组件失败，可参考[修改Python源的方法](https://device.harmonyos.com/cn/docs/documentation/guide/ide-set-python-source-0000001227639986)进行修改，完成尝试重新安装；

若出现安装apt组件失败，可参考[修改apt源的方法](https://device.harmonyos.com/cn/docs/documentation/guide/faq-toolchain-install-0000001301623822)进行修改，完成后尝试重新安装。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102413.67145672545026947140415489396611:50001231000000:2800:1C7ADFF4613A2BC2E41ABC244868F32AE45C903EDEB727033F0E5CDDF1C9A017.png?needInitFileName=true?needInitFileName=true)

安装完成后，工具和环境依赖的状态显示为![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102413.10934996302504275359296331364177:50001231000000:2800:D897F9EA9FBF3E742EF47A975277B33CFB356CD6ED3897AB50F5F6D08F0B9EEF.png?needInitFileName=true?needInitFileName=true)。

     3. 在**rk3568** 配置页签中，设置源码的编译类型**build_type** ，默认为"debug"类型，请根据需要进行修改。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102413.36493544259746424869542097978302:50001231000000:2800:CDDE195801A1552A9AD1E7E01965B26561C1FFA6FF30547B63888DAC4CA34DB4.png?needInitFileName=true?needInitFileName=true)

     4. 在DevEco Device Tool界面的**PROJECT TASKS** 中，点击对应开发板下的**Build** ，执行编译。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102413.51432766137576722547634299533688:50001231000000:2800:68CE3A4F961A2958EE467DF030A8F899503D510234B16B8533A0C17D0B87DDB9.png?needInitFileName=true?needInitFileName=true)

     5. 等待编译完成，在**TERMINAL** 窗口输出“SUCCESS”，编译完成。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102413.16872496956912657602941055446596:50001231000000:2800:E7CC69B5FAAE6FA2AA18F13D8B6D414FE8D44A602F2157D9E57FE2905AFC6117.png?needInitFileName=true?needInitFileName=true)

编译完成后，可以在工程的**out** 目录下，查看编译生成的文件，用于后续的[RK3568开发板烧录](https://device.harmonyos.com/cn/docs/documentation/guide/ide-rk3568-upload-0000001239220669)。
