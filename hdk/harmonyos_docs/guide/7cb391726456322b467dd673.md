# 调试能力介绍

DevEco Device Tool工具支持常用的调试能力，开发者如果使用调试能力，首先保证编译出来的二进制文件含有调试信息。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102422.34281759431456068567134604035682:50001231000000:2800:A508DA7C08BBF53D5F9AF5C636C87D396411BC568A28FB60D77D46AAC216212B.png?needInitFileName=true?needInitFileName=true)

当前集成的OpenHarmony工程编译过程进行了优化，编译出来的二进制文件，不含调试信息，暂不支持调试能力。后续版本会对工程编译进行适配，支持编译配置，生成带有调试信息的二进制文件，支持调试能力。

以下内容主要针对DevEco Device Tool的调试能力进行描述。

调试工作界面如下图所示，主要分为调试功能区、调试侧边栏和调试控制台。

#### 常用调试功能

#### [h2]调试功能区

#### [h2]管理断点

     * **函数断点**

在Visual Studio Code中插入函数断点的方式有多种方法:

       1. 用鼠标点击代码行最左侧的位置
       2. 在侧边栏的“BREAKPOINTS”中手动添加断点函数
       3. 使用快捷键“F9”

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102423.06053141504481123292734812018360:50001231000000:2800:8C3CD5ABD1A93210D706E79214FE52B511FA502F27FBD4BB03029E44F978A023.png?needInitFileName=true?needInitFileName=true)

     * **条件断点**

在代码函数所在行的最左侧，点击鼠标右键选择Add Conditional Breakpoint，然后输入断点的条件和进入次数即可。

     * **内联断点**

将鼠标放到要打断点的函数，然后点击鼠标右键选择“Add Inline Breakpoint”，或者使用快捷键“Shift+F9”。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102423.13879601115258247099052045364265:50001231000000:2800:FFF2785E26729276FCA9C97034AA0357C1680C8FB4419C885CE56D153713AAE3.png?needInitFileName=true?needInitFileName=true)

     * **内存断点**

点击**DEVECO MEMORY > open memory view**查看内存，右击某一条具体的内存数据，根据需要作出选择，其中断点类型分为：

       * Break on Value Read：读
       * Break on Value Change：写
       * Break on Value Access：读或写

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102423.59567488631016134802780831335997:50001231000000:2800:9EC15FF93867E96488F1B4B798A0A9A342D1C3AE064488A79DBD4A1EF91ED738.png?needInitFileName=true?needInitFileName=true)

插入断点之后，在左侧MEMORY BREAKPOINTS窗口将显示已经增加的内存断点数据，右击某一条断点数据，可进行的操作包括：

       * Remove Memory Breakpoint：删除当前选中的断点。
       * Remove All Memory Breakpoint：删除所有断点。
       * Enable Memory Breakpoint：使断点生效。
       * Disable Memory Breakpoint：使断点失效。

#### 查看及修改变量

在调试过程中，可以通过“VARIABLES”查看变量（包括局部变量、全局变量以及静态变量）的取值来判断程序的计算结果是否有误，从而快速进行代码检查。如果需要对变量值进行修改，请双击对应的变量值，键入修改值。

同时，也可以通过“WATCH”功能来监控指定的变量信息，点击![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102423.67865153221420243860948245376490:50001231000000:2800:4580F3179FBA48FE238DEEC99C696B84ECEA151848FDF9F9426B4CC42844EC21.png?needInitFileName=true?needInitFileName=true)图标来添加变量。

另外，还可以通过打开**DEVECO LIVEWATCH > live watch view**，实时监控变量。

#### 查看调用栈

在调试过程中，可以通过查看调用栈来分析主程序调用的各子程序的调用关系，从而快速进行代码检查。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102423.66834878103274183011559833515321:50001231000000:2800:5A4B38993D76B9D586DCDC004D6C2448F0CAF884F811FF2DCDF4F19711737C32.png?needInitFileName=true?needInitFileName=true)

#### 查看及修改寄存器

在调试过程中，可以通过查看相关寄存器的值来确定各参数值是否有误以及代码执行的位置，从而快速进行代码检查。如果需要对寄存器值进行修改，请双击寄存器值，然后键入修改值。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102423.79608984802255597919552492365186:50001231000000:2800:6EC0675E37D5D8DF60307C1E05DC75F235EE8F08579A800EBA2079E54713E3EF.png?needInitFileName=true?needInitFileName=true)

#### 查看反汇编

在调试过程中，通过查看反汇编，可以确认代码的汇编实现，从而快速进行代码检查。在代码页面，点击右键，然后点击**Open Disassembly View** ，查看反汇编。

#### 查看内存

在调试过程中，通过查看对应的内存地址，获取内存地址中的取值，可以准确分析代码中各变量的取值及存储状态，从而快速进行代码检查。

点击**DEVECO MEMORY > open memory view**查看内存。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102424.86100341763721612235144336955933:50001231000000:2800:A0B0DD25A1007361026E659D0D07F24EB779A47A57E5D4B0C82B020452643491.png?needInitFileName=true?needInitFileName=true)

然后输入对应的开始地址（如：0x00401469）和地址长度（0x128），即可查看对应的内存信息。可以对某一地址的值进行修改、也可以在当前显示的地址页面进行上下翻滚来显示更多的内存地址，还可以通过点击右上角的**Save** 按钮将当前内存页面的数据保存到本地文件中。
