# 碰一碰拉起原子化服务

通过手机碰一碰Hi3861开发板的NFC标签，拉起设备配网原子化服务，点击“配网”后，手机会自动为Hi3861开发板连接WLAN，并配置手机与Hi3861开发板之间的通信通道，从而拉起控制原子化服务。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230511111804.27336957934849529209356341080011:50001231000000:2800:309C31F6DBD849A9E31728D5B80A5DD04EE919E2DCB2F88836CF8BE846EEF65A.png?needInitFileName=true?needInitFileName=true)

在碰一碰拉起原子化服务前，手机需要登录华为帐号，该帐号需要与在“应用调测助手”中申请Product ID时登录的华为帐号保持一致。

     1. 打开手机NFC功能，确认手机已经接入WLAN无线网络。
     2. 在每次触碰NFC标签前，请点击Hi3861开发板的**RST** 复位按键，对Hi3861开发板进行复位。
     3. 使用手机背部接触NFC标签，手机弹出以下页面。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230511111804.61845990663482999381596089031234:50001231000000:2800:CD3B772E89E0A1516C51B82626348A22C18E4D4D9D6723DA922060D6CF6FDBF7.png?needInitFileName=true?needInitFileName=true)

在触碰NFC标签时，请将手机与开发板保持在5cm以内的距离，如果未能发现设备，请重新触碰NFC标签。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230511111804.24924399968339301176112374764386:50001231000000:2800:57118498E4D53E00A880C60A782F3DAC57BE4B73A04E0B61AAFDCEC619A5E119.png?needInitFileName=true?needInitFileName=true)

     4. 点击配网，并等待配网完成。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230511111804.98391893009887621979550467629368:50001231000000:2800:233B7270EDAC13B18EBE27F2AF7049CBF6C3F8C5F780538411421F59136B811D.png?needInitFileName=true?needInitFileName=true)

如果出现“扫描设备失败”，可以根据如下操作进行重试。

        1. 断开手机的WLAN连接，然后再重新连接WLAN。
        2. 点击Hi3861开发板的**RST** 复位按键，对Hi3861开发板进行复位。
        3. 重新触碰NFC标签进行配网。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230511111805.28717305828603381554446375003866:50001231000000:2800:2497BC4B4064FC6F312732DEA5D6BE331CAF585BF908DD010BE8AB7B44A9CF12.png?needInitFileName=true?needInitFileName=true)

     5. 配网完成后自动跳转到设备控制页面半屏态， 向上滑动后，点击**查看更多** 跳转到全屏态。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230511111805.51368420480768703681053790438850:50001231000000:2800:6B3C0C86A81863F8F93314E7FCA32E1B4DC33AA6E7E8473298AFAD58170D29D4.png?needInitFileName=true?needInitFileName=true)

     6. 在设备控制页面进行操作，可以在Hi3861开发板的液晶显示屏上，查看是否能够收到相应指令。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230511111805.72635048300807909924964966730643:50001231000000:2800:F3BEA32ADC80AEC3013EA1BB35A5FEC20EA3A5CE72354BCE3D0BAEB140A972B0.png?needInitFileName=true?needInitFileName=true)

至此，恭喜您已完成碰一碰特性的开发与体验。
