# 编译Hi3861V100开发板源码

DevEco Device Tool支持Hi3861V100开发板的源码一键编译功能，提供编译工具链和编译环境依赖的检测及一键安装，简化复杂编译环境的同时，提升了编译的效率。

以下内容为**Ubuntu环境** 的编译指导。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102410.49398844591020320701896859477747:50001231000000:2800:D01D4C30B1648033244DC9FB2200FCE25AAD5655D68D43A287E01B56DD3E7264.png?needInitFileName=true?needInitFileName=true)

目前3.1 Beta2版本已支持**Windows环境** 的编译烧录，请参见[Hi3861V100开发板Windows环境编译与烧录](https://device.harmonyos.com/cn/docs/documentation/guide/hi3861-windows-0000001445255984)。

#### 前提条件

获取OpenHarmony的源码存在多种方式，具体请参考[创建OpenHarmony工程](https://device.harmonyos.com/cn/docs/documentation/guide/create_project-0000001072200151)或[导入OpenHarmony源码](https://device.harmonyos.com/cn/docs/documentation/guide/open_project-0000001071680043)。如果导入的源码是通过“repo方式”获取，在执行编译前，请执行如下脚本安装编译器及二进制工具。通过其它方式获取的OpenHarmony源码，请跳过该操作。
    
    bash build/prebuilts_download.sh

#### 操作步骤

     1. 在菜单栏中点击**Project Settings** ，进入Hi3861工程配置界面。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102410.58756008538798461887757032378504:50001231000000:2800:9940814EC1437C1DA1C823A8A1DF334336175384FEB8FC9D279B1A45E9426B6C.png?needInitFileName=true?needInitFileName=true)

     2. 在**Tool Chain** 页签中，DevEco Device Tool会自动检测依赖的编译工具链是否完备。

        * 如工具为“uninstalled”状态（![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102410.41413160372350941258310200280658:50001231000000:2800:6343ED882F25FC6080A7122734902731F63E18722367DD2F04370051D3AA2965.png?needInitFileName=true?needInitFileName=true)），可单击**Download Uninstalled Tools** ，自动安装所需工具，或单击工具后方的**Dow****n****load** 安装指定工具。
        * 如当前识别到的工具类型有缺失，需要补充，可单击**Add Utility** 添加。
        * 如工具无法通过**Download** 方式直接安装，可能是由于网络原因导致。此种情况下，DevEco Device Tool无法连接到工具链下载网站，需要用户自行修复网络，或通过其他方式将正式发布的[OpenHarmony工具链安装包](https://gitee.com/openharmony/docs/blob/master/zh-cn/device-dev/get-code/sourcecode-acquire.md#获取方式3从镜像站点获取)存储到本地，单击**Import** 导入。
        * 如“OpenHarmony Environment Dependency”的状态异常（![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102410.24304182288268792806670086857439:50001231000000:2800:7E7D5300AC0FE2B0FAB004509E884530921D621B9C2F465CFE5A0E0CDE036B89.png?needInitFileName=true?needInitFileName=true)），请单击**Install** 安装。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102410.75166868419944523181001595747805:50001231000000:2800:99CDDA280A88415992DFE2D3FD0996C1B7E205E3DC7E4EBD45AF5BEA0503042F.png?needInitFileName=true?needInitFileName=true)

部分工具安装需要使用root权限，请在**TERMINAL** 窗口输入用户密码进行安装。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102410.29025065327217117395847462330405:50001231000000:2800:3729B910CEC5E5AC0BE5B8BE0BF064CA76421EE174AF2D128473FF354239700E.png?needInitFileName=true?needInitFileName=true)

若出现安装pip组件失败，可参考[修改Python源的方法](https://device.harmonyos.com/cn/docs/documentation/guide/ide-set-python-source-0000001227639986)进行修改，完成尝试重新安装；

若出现安装apt组件失败，可参考[修改apt源的方法](https://device.harmonyos.com/cn/docs/documentation/guide/faq-toolchain-install-0000001301623822)进行修改，完成后尝试重新安装。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102410.19151466572300671776920687471588:50001231000000:2800:EA3DEBDF91CE4F9A25C53D47C134002982609B230FE126319ABB05A6CC1ADF94.png?needInitFileName=true?needInitFileName=true)

安装完成后，工具和环境依赖的状态显示为![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102410.31816744232333479779515192751756:50001231000000:2800:40C8B554197DA0C3F6F79AA7DBFC051E72E772FFD69E5CEA0C97480BA7FC6A6F.png?needInitFileName=true?needInitFileName=true)。

     3. 在**wifiiot_hispark_pegasus** 配置页签中，设置源码的编译类型**build_type** ，默认为"debug"类型，请根据需要进行修改。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102410.59593993198381897283707539968797:50001231000000:2800:C4C2CAC588FD19EA424BB59DF83CB9A93B696F3C1F664E155018C24ED7C1B262.png?needInitFileName=true?needInitFileName=true)

     4. 在DevEco Device Tool界面的**PROJECT TASKS** 中，点击对应开发板下的**Build** ，执行编译。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102410.27387217302692405831875254183291:50001231000000:2800:86DF3AD8CE17CF9814A117303EE635CA33012DD757C3F2E50EAD85C7F5C65C88.png?needInitFileName=true?needInitFileName=true)

     5. 等待编译完成，在**TERMINAL** 窗口输出“SUCCESS”，编译完成。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102410.32158741740620665557149490296104:50001231000000:2800:17A839A56044AC9437D56467993451BDD2588647667F4896BB809D641F73EFFF.png?needInitFileName=true?needInitFileName=true)

编译完成后，可以在工程的**out** 目录下，查看编译生成的文件，用于后续的[Hi3861V100开发板烧录](https://device.harmonyos.com/cn/docs/documentation/guide/upload_hispark_phoenix-0000001334326461)。
