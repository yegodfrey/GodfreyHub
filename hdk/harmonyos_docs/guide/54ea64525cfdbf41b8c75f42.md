# Hi3861V100开发板Windows环境编译与烧录

为简化Hi3861V100开发板开发流程，提供了Windows环境下配套的源码及开发工具链，便于开发者基于Windows环境进行开发。以提供的Demo为例，介绍在Windows环境下如何进行编译与烧录，开发者可在Demo的基础上自行设计开发新功能，通过DevEco Device Tool完成编译，并烧录到开发板中。

#### 开发准备

开发环境：[DevEco Device Tool 3.1 Release](https://device.harmonyos.com/cn/develop/ide#download)及以上

#### 创建工程

     1. 打开DevEco Device Tool，进入Home页，点击**New Project** 新建工程。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102436.01858177616973552608893912098733:50001231000000:2800:C74AA45E17460B7B39D6CC40646A626E19ACAEF3217DB1AE9CDC9728C78C23CA.png?needInitFileName=true?needInitFileName=true)

     2. 配置工程各项参数后，单击**Confirm** 。

        * 在“Project Name”中输入自定义的工程名称。
        * 在“SOC”下拉列表中选择“HI3861”。
        * “Board”类型会在选择SOC后自动联想为“hi3861”。
        * 在“Project Path”中配置工程存放路径。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102436.31408529040288270240908697883502:50001231000000:2800:07CE74CE31DAA9A9DFC8B6B2EF4AFB95925DA37925F1768EE3EF9265A66420D9.png?needInitFileName=true?needInitFileName=true)

路径不能超过260个字符，建议将下载解压后的源码工程修改为简短的名字，如hi3861，防止路径过长导致的编译错误问题。

        * “SDK”中自动联想Hi3861工程所需SDK及状态，如显示为“Uninstalled”，可单击**Download** 直接下载安装，或单击**Import** 导入本地SDK。

#### 配置工具链

     1. 在菜单栏中点击**Project Settings** ，进入Hi3861工程配置界面。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102436.98067507277125859404296202505506:50001231000000:2800:1AA01ABD54BCCC543542F7DC688E006EFC9B094CE416A3DC96475E2048386A48.png?needInitFileName=true?needInitFileName=true)

     2. 在**Tool Chain** 页签中检查所需工具是否已安装。

如工具为“uninstalled”状态（![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102436.63145195194839806685507156748587:50001231000000:2800:87C5ADF762D22AD90AAA26114248EAC6CA7C53C3F3F4A51E2DB50DB88FEBB183.png?needInitFileName=true?needInitFileName=true)）：

        * 可单击**Download Uninstalled Tools** ，自动安装所需工具，或单击工具后方的**Dow****n****load** 安装指定工具。
        * 也可以单击Import导入提前下载到本地的工具。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102436.09581114452757855131460782713202:50001231000000:2800:7E72876782D4C3BCA18E3A47977ACF7A5F00042264AF032B5C040B83FE1846CD.png?needInitFileName=true?needInitFileName=true)

#### 编译

     1. 在DevEco Device Tool界面的**PROJECT TASKS** 中，点击**Build** ，执行编译。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102436.68513064641013027880651062459477:50001231000000:2800:1C3296E3F5ACF7793DBD225B44B1A49A736424F392E9EBF07BFC5E25FB6CEFD8.png?needInitFileName=true?needInitFileName=true)

     2. 等待编译完成，在**TERMINAL** 窗口输出“SUCCESS”，编译完成。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102436.19652882953358806821844753730573:50001231000000:2800:330509F3D996F4B4B5B8BF413474FEFE189528BC5D8BA02E53351887702FA581.png?needInitFileName=true?needInitFileName=true)

#### 烧录

#### [h2]前提

     1. 使用配套的Type-C数据线，连接开发板与电脑的USB口；
     2. 安装串口驱动：打开开发准备时下载的工具链，在DevTools_Hi3861V100_v1.0/usb_serial_driver文件夹下，双击CH341SER.EXE驱动，进入安装界面，点击安装按钮即可。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102436.76774385261293855101345550863757:50001231000000:2800:667F56EE6C334C67E606EAB58C9E4A5FDF097DDD7F241EE22D9408710CD1C2CD.png?needInitFileName=true?needInitFileName=true)

安装完成后，在DevEco Device Tool中点击**Project Settings** ，若右侧upload_port中有开发板对应的烧录串口，说明连接成功，即可开始烧录。

#### [h2]操作步骤

     1. 在菜单栏中点击**Project Settings** ，在右侧upload下方的**upload_port** 中选择端口（如COM5[USB-SERIAL CH340(COM5)]，以实际端口号为准）。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102436.41613645152127236370193738120057:50001231000000:2800:B7F3908CA5C61B1FDA410986C24182C375BC08DFF0B010FEBC0C7E66B95CD39F.png?needInitFileName=true?needInitFileName=true)

     2. 在DevEco Device Tool界面的**PROJECT TASKS** 中，点击**Upload** ，执行烧录。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102436.37779205970488536292682468394954:50001231000000:2800:DDEB14321EC4858D1969BE14CEC14B03260545E1FEA45F2A9F4E33FFCF307FD2.png?needInitFileName=true?needInitFileName=true)

     3. 当出现提示“Connecting, please reset device...”，在开发板上按下RST键进行开发板复位。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102436.47873722968158642619963111326844:50001231000000:2800:1DF126A88C510902B57CAE02A83B25FF343CEB645E00202B61FDBD2FA47C997C.png?needInitFileName=true?needInitFileName=true)

     4. 等待烧录完成，在**TERMINAL** 窗口输出“SUCCESS”，表示烧录成功。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102436.32874481090852247132451206388996:50001231000000:2800:3581A498E4E7985DA4747B2DF2CACF53C994F250AEA786EA0C855DF83A7326EA.png?needInitFileName=true?needInitFileName=true)

烧录之后可以通过monitor界面查看串口打印日志以及通过[栈分析和镜像分析](https://device.harmonyos.com/cn/docs/documentation/guide/ide-stack-image-analysis-0000001134643900)查看开发过程中的内存不足、内存溢出等问题进行，帮助开发者更加精准的分析、定位问题。
