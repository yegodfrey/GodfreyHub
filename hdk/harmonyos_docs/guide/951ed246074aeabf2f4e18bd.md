# 烧录RK3568开发板镜像

RK3568的镜像烧录通过Winodow环境进行烧录，开发者启动烧录操作后，DevEco Device Tool通过Remote远程模式，将Ubuntu环境下编译生成的待烧录程序文件拷贝至Windows目录下，然后通过Windows的烧录工具将程序文件烧录至开发板中。

#### 前提条件

[下载](https://gitee.com/hihope_iot/docs/blob/master/HiHope_DAYU200/烧写工具及指南/windows/DriverAssitant_v5.1.1.zip)并安装驱动DriverInstall.exe。当安装窗口显示“安装驱动成功”时，即表示驱动已安装完成，可进入后续烧录步骤。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102421.76457371654482135448056514813910:50001231000000:2800:94434F3334F5AC1CD178D4797D0A4A71819B876B045FADDE67896089B6B8B88A.png?needInitFileName=true?needInitFileName=true)

如果已经安装旧版本的RK3568开发板驱动程序，请先点击"驱动卸载"按钮卸载驱动，然后再点击"驱动安装"按钮安装驱动。

#### 操作步骤

     1. 请连接好电脑和待烧录开发板，连接USB接口，具体可参考[RK3568开发板介绍](https://docs.openharmony.cn/pages/v5.0/zh-cn/device-dev/quick-start/quickstart-appendix-rk3568.md/)。
     2. 在DevEco Device Tool中，选择**REMOTE DEVELOPMENT > Local PC**，查看远程计算机（Ubuntu开发环境）与本地计算机（Windows开发环境）的连接状态。

        * 如果Local PC右边连接按钮为![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102421.85615557816597643365351353174658:50001231000000:2800:4EB27CDF41711173555F1B720AFD102F875F9FF42A10B2DFBE38BC1EFA003F93.png?needInitFileName=true?needInitFileName=true)，则远程计算机与本地计算机为已连接状态，不需要执行其他操作。
        * 如果Local PC右边连接按钮为![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102421.50666117524782968440778774026371:50001231000000:2800:D94112C82F6C7F7CFED10EBBABCCF7DBB3AB8DAE59488E0085872E96902A1CD0.png?needInitFileName=true?needInitFileName=true)，则点击绿色按钮进行连接。连接时DevEco Device Tool会重启服务，因此请不要在下载源码或源码编译过程中进行连接，否则会中断任务。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102421.66602179134910021877071875052274:50001231000000:2800:4EA70DB0D56DF0AC7F8EB94631DF150C8FB1A5BE721180C582B58891D4E16D2C.png?needInitFileName=true?needInitFileName=true)

     3. 在菜单栏中点击**Project Settings** 按钮，进入RK3568工程配置界面。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102421.71896891877805575468811220092115:50001231000000:2800:387E8C47666FE0EAB66352E643606BEAA3E3CB9873F08F06D91B6B00A5BF825A.png?needInitFileName=true?needInitFileName=true)

     4. 在**Tool Chain** 页签，检查Uploader烧录器工具是否已安装。

        * 如工具为“uninstalled”状态（![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102421.55489222121783478808295420449778:50001231000000:2800:9FD8B97692515B18621D7923DF3A0F3C5F1B5E55DC27416434A39046E44FE668.png?needInitFileName=true?needInitFileName=true)），可单击**Download Uninstalled Tools** ，自动安装所需工具，或单击工具后方的**Dow****n****load** 安装指定工具。
        * 如工具无法通过**Download** 方式直接安装，可能是由于网络原因导致。此种情况下，DevEco Device Tool无法连接到工具链下载网站，需要用户自行修复网络，或通过其他方式将正式发布的[OpenHarmony工具链安装包](https://gitee.com/openharmony/docs/blob/master/zh-cn/device-dev/get-code/sourcecode-acquire.md#获取方式3从镜像站点获取)存储到本地，单击**Import** 导入。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102421.49694612776379735741834209995751:50001231000000:2800:435DE815AC20AC853070584F9DE5C35C5E16865208B7876D6378CF06A740808A.png?needInitFileName=true?needInitFileName=true)

     5. 在**rk3568** 页签，设置烧录选项，包括upload_partitions和upload_protocol。配置完成后工程将自动保存。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102421.78534819310239351075442431978109:50001231000000:2800:FF22F724CD097D9589C5D7E24D3430DEBE1E50F22CCCF4E0A57DBF0AAD981840.png?needInitFileName=true?needInitFileName=true)

RK3568烧录时不需要单独设置upload_port。

        * **upload_partitions_profile** ：选择待烧录程序的配置文件，该配置文件会指定烧录文件名称、起始烧录地址、地址长度等信息；同时请勾选**Enable to use upload_partitions_profile for upload** 选项。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102421.50400116817279678652023921934523:50001231000000:2800:75FA4E5166D8120470043A9D570A8E7A9F21623E27E19C2AB9AD87CF3158FF92.png?needInitFileName=true?needInitFileName=true)

如需修改烧录profile文件，在设置烧录分区起始地址和分区长度时，应根据实际待烧录文件的大小进行设置，要求设置的烧录分区大小，要大于待烧录文件的大小；同时，各烧录文件的分区地址设置不能出现重叠。

首次烧录，请勾选**Enable to use upload_partitions_profile for upload** 选项，会自动生成upload_partitions文件。再次烧录时，可根据实际情况选择生成upload_partitions文件进行自定义烧录，也可以再勾选**Enable to use upload_partitions_profile for upload** 选项，使用upload_partitions_profile重新生成upload_partitions文件用于烧录。

        * **upload_protocol** ：选择烧录协议，固定选择“upgrade”。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102421.83325503800168709144810231889816:50001231000000:2800:37CCBD0B853954039F8CFDFB887B3262DD64D72569A270830DDA511D8C143864.png?needInitFileName=true?needInitFileName=true)

     6. 在**PROJECT TASKS** 中，点击**rk3568** 下的**Upload** 按钮启动烧录。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102421.78034439963083309775442118414723:50001231000000:2800:CFE3E342A80AF24EEFCB5FE573EC1F9C163627A885E90318B2CF05562F58FC10.png?needInitFileName=true?needInitFileName=true)

     7. 当屏幕提示“Operation paused，Please press Enter key to continue”，请按**回车键** 继续。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102422.76598996058577531102472988377832:50001231000000:2800:21FCF937D5592342D47C20B200E486659DFAE614A4BAE4E0EEC53510AD50C035.png?needInitFileName=true?needInitFileName=true)

如果开发板未处于烧录模式，屏幕会提示“The board is not in Loader mode.Please Hold on the VOL+key...”，此时，请长按音量+键，3秒后保持长按状态并点击**RESET** 键，然后再过3秒放开音量+键，使开发板进入烧录模式。

等待开发板烧录完成，当屏幕提示如下信息时，表示烧录成功。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240930102422.10936204971974165846927547550804:50001231000000:2800:2F67366C4172C8C667F2F6F4E0140F440C904519E17F5AB6A00401EC8D63333C.png?needInitFileName=true?needInitFileName=true)
