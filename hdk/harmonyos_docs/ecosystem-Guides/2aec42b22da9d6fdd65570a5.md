# SDK包说明

HUAWEI Research Android SDK 以华为帐号统一登录鉴权，为研究APP提供知情同意、加入研究项目、穿戴设备数据收集、测量数据上云、量表问卷等能力，降低研究APP开发门槛，助力合作伙伴加速创新研究。

* huawei-research-android-bridge、huaweiresearch-android-common：提供获取知情同意及加入研究等与HUAWEI Research平台对接的功能接口。
* huawei-research-android-research（可选）：支持获取文章及调查问卷，提供研究相关的接口。
* huaweiresearch-android-sensor（可选）：支持获取运动健康开放平台数据。具体数据请下载"华为运动健康App"查阅。接口说明请见"3.3.2 穿戴设备数据采集基础能力"。
* huaweiresearch-android-sensorpro-wear、huaweiresearch-android-sensorpro-common、huaweiresearch-android-sensorpro-alg（可选）：支持华为手表、手环等穿戴设备传感器数据及运动健康数据导出。目前支持对接的设备有华为手环4Pro、华为手环6、华为手环7、华为Watch D、华为Watch GT 2、华为Watch GT 2 Pro（ECG手表）和华为Watch GT 3。接口说明请见"3.3.3 穿戴设备数据采集扩展能力"。
* huaweiresearch-android-sensorpro-scale（可选）：支持华为智能体脂秤 2 Pro、体脂秤 3和体脂秤 3Pro，用于体脂测量和获取体成分数据。
