# 基础类型元数据

1. 在Huawei Research平台创建普通元数据 HUAWEI Research平台提供元数据管理能力，研究项目管理员在HUAWEI Research平台"项目管理">"元数据"中新增元数据，如下图所示：

   **图1**创建元数据   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172623.86467341574973282746655468420734:50001231000000:2800:2A0112CA41DF9D18FFEA8DD891269DF315B450626AD3DFFC14941D196901F436.png?needInitFileName=true?needInitFileName=true "点击放大")
2. 在Android工程中创建相应的元数据类 开发者可以根据HUAWEI Research项目上定义的元数据，在应用开发工程中，手动创建元数据类。创建元数据类需继承于HiResearchBaseMetadata（与HUAWEI Research平台中元数据相对应），并指定元数据名称及版本号。元数据示例请参见下方"TestPlainData"类。

   实体类示例，如下所示：

   ```codeblock
   importcom.huawei.hiresearch.common.annotation.metadata.HiResearchField;
   importcom.huawei.hiresearch.common.model.metadata.HiResearchBaseMetadata;
   importcom.huawei.hiresearch.common.annotation.metadata.HiResearchMetadata;
   import staticcom.huawei.hiresearch.common.annotation.metadata.HiResearchMetaType.*DEFAULT*;
   @HiResearchMetadata(name = "TestPlainData", version = "1.0", metaType = *DEFAULT*)
   public classTestPlainData extendsHiResearchBaseMetadata {
        /**
   * 第一个字段
   */
   @HiResearchField(name = "field1")
        privateString field1;
        /**
   * 第二个字段
   */
   @HiResearchField(name = "field2")
        private long field2;
        /**
   * 第三个字段
   */
   @HiResearchField(name = "field3")
        private boolean field3;
        /**
   * 第四个字段
   */
   @HiResearchField(name = "field4")
        private double field4;
        /**
   * 第五个字段
   */
   @HiResearchField(name = "field5")
        privateString field5;
        /**
   * default constructor
   */
   publicTestPlainData() {
        }
        publicString getField1() {
            return this.field1;
        }
        public voidsetField1(String field1) {
            this.field1= field1;
        }
        public longgetField2() {
            return this.field2;
        }
        public voidsetField2(longfield2) {
            this.field2= field2;
        }
        public booleanisField3() {
            return this.field3;
        }
        public voidsetField3(booleanfield3) {
            this.field3= field3;
        }
        public doublegetField4() {
            return this.field4;
        }
        public voidsetField4(doublefield4) {
            this.field4= field4;
        }
        publicString getField5() {
            return this.field5;
        }
        public voidsetField5(String field5) {
            this.field5= field5;
        }
    }
   ```

3. 登录Huawei Research平台查看上传数据 待上传成功后，登录Huawei Research平台，关联自定义元数据，创建数据表，查看数据记录。
