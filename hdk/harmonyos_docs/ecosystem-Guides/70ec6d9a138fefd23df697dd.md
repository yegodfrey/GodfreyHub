# 安装SDK

完成项目接入后可联系华为Research侧项目负责人或电邮：HiResearch@huawei.com，获取SDK。

通过pip命令安装Python SDK，执行命令如下：

```codeblock
pip install hiresearchsdk-x.x.x-py3-none-any.whl
```

> 说明
>
> * 如果您的环境尚未安装pip，请参见[pip官网](https://pip.pypa.io/en/stable/installing/)安装。
> * 如果已安装旧版本的Python SDK，建议先卸载已有版本，然后再安装新版本的SDK。
