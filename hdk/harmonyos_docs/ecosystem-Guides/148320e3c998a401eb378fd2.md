# 国际和平妇幼保健院-女性生理健康研究

**1.简介**

中国福利会国际和平妇幼保健院基于HUAWEI Research开展女性健康研究，构建女性健康研究APP，结合华为智能穿戴设备和专业设备，在用户知情同意下检测用户心率、脉搏、睡眠、运动、体温等健康数据，帮助女性进行生理周期管理和预测，实现女性长期健康跟踪与关怀。

**2.核心痛点**

* 研究招募难 女性生理周期平均为28天，招募用户即使只采集一个周期的生理数据，也需要长达28天左右的连续采集，耗时耗力，导致用户招募困难。


* 参与者依从性不高 女性生理周期数据采集，参与者需频繁用到试纸、体温计等工具，操作繁琐，参与者依从性较差。


* 数据整理困难 传统研究数据处理需经过参与者记录、反馈，研究人员收集、整理再分析的过程，容易混淆、遗漏等。

**3.解决方案**

* 穿戴便携24h采集： 在隐私授权下，通过华为智能穿戴设备，可随时随地自动采集，即使招募周期长，也无需花费大量精力，且用户可用手机注册参与，方便快捷。


* 穿戴设备测量轻松无感： 通过穿戴设备采集数据，管理和预测女性生理期与排卵期，可减小参与者使用试纸、体温计测量的烦扰，为女性长期生理健康管理奠定基础。


* 大数据分析和可视化管理： HUAWEI Research提供大数据分析框架、数据深度处理和分析服务，帮助国际和平妇幼保健院创新实践，挖掘数据价值，提升研究管理水平。

**4.合作受益**

* 中国福利会国际和平妇幼保健院 数据采集方便快捷，更易招募参与者，获取的研究数据质量更高，更易于产生创新研究成果。


* 用户 提供女性生理周期管理，一站式预测女性生理期和排卵期；

  提供女性生理周期健康指导，帮助女性主动进行生理周期健康管理。
