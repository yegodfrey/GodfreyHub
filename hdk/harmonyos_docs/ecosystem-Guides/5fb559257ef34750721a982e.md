# 用户绑定

* 接口说明 进行体成分测量前，需要将用户的性别、年龄、身高基本信息通过此接口绑定到体脂秤端。体脂秤可以根据下发的用户信息，在测量体重时计算体脂率并在LED显示器上显示。在不修改称端用户信息的情况下，测量时体脂秤以最后一次下发的基本信息进行体脂率计算。

  > 注意
  >
  > 调用此接口进行绑定时，需要用户站到体脂秤上保证LED亮起。
* 接口方法

  ```codeblock
  public voidchangeUser(UserProfileInfo userInfo, SensorProCallback<Integer> callback)
  ```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:-------|:-------------------------|:------------------------|:------|
  |userInfo|UserProfileInfo|用户基本信息|M|
  |callback|SensorProCallback<Integer>|交换用户信息操作接过： * 0：成功 * 1：失败|M|
  [**表1**输入参数]

  |字段名|数据类型|说明|必选M/可选O|
  |:-----|:-----|:---------------------|:------|
  |huid|String|主用户id，不能为null和空字符串|M|
  |uid|String|子用户id，当只使用主用户时，此字段可为空。|O|
  |height|int|身高信息，单位cm，50cm-250cm|M|
  |gender|int|性别信息，1：男，0：女|M|
  |age|int|年龄信息，18-80岁|M|
  [**表2**UserProfileInfo（用户基本信息参数）]

* 响应参数

  |响应方法名|参数名|数据类型|说明|
  |:---------|:-----------|:------|:-------------------|
  |onResponse|errorCode|int|返回错误码|
  |onResponse|returnObject|Integer|绑定结果值。 * 0：成功 * 1：失败|
  [**表3**响应参数]
