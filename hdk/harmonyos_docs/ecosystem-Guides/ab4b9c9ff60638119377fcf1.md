# 四川大学华西医院-高原健康研究

**1.** **简介**

高原健康研究由四川大学华西医院发起，通过佩戴华为智能穿戴设备，基于血氧饱和度、心率、心率变异性等生理参数变化，结合用户主观感受，实现高原反应的风险评估与主动监测，并给出健康指导和建议，帮助高原旅居用户进行健康管理。

**2.** **核心痛点**

* 常规招募参与样本少 医院及研究机构的常招募方式通常只能招募到少数参与者，研究样本有限，导致研究优化改进受限。

* 高原反应初步诊断主观性较大 对于高原反应的初步诊断，一般通过自我评估症状来实现，当前国际公认的标准是患者填写"路易斯湖表问卷"，根据其头痛症状、肠胃道症状、疲惫虚弱程度和头晕程度来判断患者高原反应的严重程度。但是这样的评估方式主要依赖于患者对身体状况的主观判断，不同患者可能会出现不同的判断结果，无法体现出客观的高原反应风险结果。

* 无法实现实时动态监测 高原反应风险评估需要结合血氧、心率等数据监测，但传统研究数据收集需要经记录，反馈，再整理等步骤，且数据收集容易受高原上多种复杂情况影响，难以实现数据实时动态监测和收集。

**3.** **解决方案**

* 开发技术助力研究招募：

  HUAWEI Research开放研究类APP开发框架，借助华为智能穿戴设备的检测能力，与华西医院合作发起高原健康研究，通过华为创新研究APP广泛招募研究用户，在用户知情同意的情况下轻松获取高价值的研究数据，助力机构孵化创新的研究成果。
* 开放传感器能力快速获取数据：

  HUAWEI Research开放传感器能力，在用户知情同意下，可快速获取参与者血氧饱和度、心率等高价值研究数据，建立一套基于完整的高原反应评估模型，为高原反应风险评估提供客观依据。
* 大数据分析能力和可视化管理，实现24小时动态数据监测

  HUAWEI Research开放传感器能力，在用户知情同意下提供连续24小时数据监测。数据经华为可穿戴设备采集后每日同步上传即可获取，并且HUAWEI Research可以提供大数据分析框架和存储管理，通过AI算法助力医院更加高效地分析数据，提升研究水平。

**4.** **合作受益**

* 华西医院 通过华为创新研究APP作为研究入口，广泛招募研究参与者，基于华为智能穿戴设备高性能传感器，获取更多高价值的研究数据。基于HUAWEI Research大数据分析能力，深度分析和处理数据，挖掘数据价值，助力机构孵化创新性研究成果。

* 用户 用户通过华为应用市场搜索并下载"华为创新研究APP"，加入【高原健康研究】，配备华为智能穿戴设备，轻松实现高原反应风险评估；专业的高原科普知识与结果建议，助力高原旅居用户主动健康管理；对于高原反应中高风险用户，还会收到医院电话回访，给出健康指导建议。
