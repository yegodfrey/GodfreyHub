# 下载文件

本文介绍如何将HUAWEI Research文件管理中的文件下载至本地。

如将/Example_Dir目录下的Example.xls文件下载至本地，脚本如下：

```codeblock
import com.huawei.hiresearch.client.model.files.GetFileRequest;
import com.huawei.hiresearch.client.model.files.GetFileResponse;
import java.io.IOException;
public class DownloadFile {
    public static void main (String[] args) throws IOException {
        // 获取鉴权
        HiResearchAuth hiResearchDemo = new HiResearchAuth();
        // 获取最新accesstoken
        String accessToken = hiResearchDemo.getAccessToken();
        GetFileRequest getFileRequest = new GetFileRequest(accessToken);
        getFileRequest.setFilePath("/Example_Dir/Example.xls");
        getFileRequest.setOutputPath("D:/");
        GetFileResponse response = hiResearchDemo.getClient().getResearchDataProvider().downloadFile(getFileRequest);
        System.out.println(response.getObjectKey());
    }
}
```
