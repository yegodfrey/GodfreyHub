# 血压

* 接口说明 从血压设备上获取血压数据。请联系HUAWEI Research团队，确认您的设备是否支持此能力。若需要配置连续数据开关请参考"实时健康数据"整个章节说明。

* 接口方法

```codeblock
public void getBloodPressureData(intstartTime, intendTime, @NonNull finalSensorProTransFileCallback<List<BloodPressureInfo>> callback);
```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:--------|:-----------------------------------------|:--------|:------|
  |startTime|int|获取数据的开始时间|M|
  |endTime|int|获取数据的结束时间|M|
  |callback|SensorProCallback<List<BloodPressureInfo>>|获取血压数据|M|
  [**表1**输入参数]


* 响应参数

  |响应方法名|参数名|数据类型|说明|
  |:---------|:-----------|:------------------------|:-------|
  |onProgress|progress|Progress|文件传输通用回调|
  |onResponse|errorCode|int|返回错误码|
  |onResponse|returnObject|List< BloodPressureInfo >|返回结果说明|
  [**表2**响应参数]

|字段名|数据类型|说明|
|:----------|:---|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|dataStamp|int|数据时间戳|
|systolicBP|int|收缩压，高压|
|diastolicBP|int|舒张压|
|bpm|int|脉搏|
|label|int|血压测量前活动 1：正常 2：未按照标准姿势测量 3：未保持静止 4：运动后测量（测量前5分钟内有中高强度运动） 5：佩戴过松，算法可出值 6：佩戴过紧，算法可出值|
|remindType|int|血压测量提醒： 1：非提醒拉起的测量 2：出睡自动拉起的测量 3：晨起定时测量 4：普通定时测量 5：睡前定时测量|
|flag|int|测量异常标记： 0：正常 1：正常 2：正在测量 3：放气结束 4：异常出值：佩戴未与心脏齐平 5：异常出值：未保持静止，微动 6：异常出值：运动后测量（测量前5分钟内有中高强度运动） 7：异常出值：有较大的肢体动作或ACC变化大（坐车等） 8：异常出值：佩戴过松 9：异常出值：佩戴过紧 16：测量时间超过3min 17：压力加压过大，达到气囊可承受门限300mmHg 18：测量失败：未佩戴 19：测量失败：未保持静止，大的肢体动作 20：测量失败：信号质量差 21：测量失败：佩戴过松 22：测量失败：佩戴过紧 23：测量失败：pid控制出错 24：测量失败：其他未分类错误 25：测量失败：血压结果值超出测量范围 26：测量失败：心率不规则 32：气囊：加压出错，非线性升压，漏气或连接松动 33：气囊：当前安装的M码表带及气囊与腕围设置不匹配 34：气囊：当前安装的L码表带及气囊与腕围设置不匹配 35：气囊：未安装气囊 48：未设置腕围|
|reserved|int|0：白天；1：夜间|
[**表3**BloodPressureData(血压数据)]
