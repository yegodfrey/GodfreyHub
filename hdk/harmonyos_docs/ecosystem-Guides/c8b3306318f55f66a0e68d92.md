# 研究数据类型

HUAWEI Research支持采集的研究数据类型如下：

|分类|数据类型|数据说明|
|:--|:-------|:-------------------------------------------------------------------------------------------------------------------------|
|传感器|PPG|绿光、红光、环境光、红外数据，采样频率：100Hz|
|传感器|ECG|心电数据，采样频率：500Hz|
|传感器|ACC|传感器（X轴、Y轴、Z轴）数值，采样频率：100Hz|
|传感器|GYRO|传感器（X轴、Y轴、Z轴）数值，采样频率：100Hz|
|健康|基本信息|性别、年龄、省份、城市、身高、体重|
|健康|血压|收缩压、舒张压、心率|
|健康|体温|体温，皮肤温度、环境温度|
|健康|心率|**主动测量心率**：每5秒采集一个样本值，采集时长默认5分钟|
|健康|心率|**连续心率**：24小时连续检测，每一分钟采集一个样本值|
|健康|心率|**每日心率统计**：最大心率、最小心率|
|健康|血氧|**主动测量血氧**：每1秒采集一个样本值，采集时长默认5分钟|
|健康|血氧|**连续血氧**：睡眠期间连续检测，每分钟采集一个平均样本值|
|健康|血氧|**每日血氧统计**：最大血氧、最低血氧、平均血氧|
|健康|体成分|水分量、水分率、非脂肪物质含量、肌肉量、骨盐量、蛋白质、体重、BMI、脂肪率、基础代谢率、腰臀比、身体得分、身体年龄、身体类型、身体形态、肌肉均衡、脂肪均衡、骨骼肌量、部位肌肉量、四肢相对骨骼肌量指数、脂肪量、内脏脂肪量、内脏脂肪等级、生物阻抗|
|健康|心律失常筛查结果|**筛查结果**：未见异常、不规则心律、高心率、低心率、房颤、早搏|
|健康|心律失常筛查结果|**风险等级**：无风险、低风险、中风险、高风险|
|健康|科学睡眠|出睡时间、入睡时间、浅睡时长、深睡时长、做梦时长、清醒时长、白天睡眠时长、睡眠总时长、睡眠得分、每分钟睡眠状态详情|
|健康|RRI|**主动测量RRI**：采集时长默认5分钟|
|健康|RRI|**连续RRI**：24小时连续检测，每分钟采集一组|
|运动|每日运动量|**每日跑步、步行、爬山的运动量统计数据** 跑步：步数、卡路里、距离 步行：步数、卡路里、距离 爬山：步数、卡路里、距离|
|运动|每分钟运动量|**每分钟跑步、步行、爬山的运动量统计数据** 跑步：步数、卡路里、距离、心率、运动强度 步行：步数、卡路里、距离、心率、运动强度 爬山：步数、卡路里、距离、心率、运动强度、爬升高度|
|运动|单次运动量|**单次运动的统计数据** 跑步：步数、卡路里、距离、时长、速度、最大/最小心率 步行：步数、卡路里、距离、时长、速度、最大/最小心率 骑行：卡路里、时长、最大/最小心率|
|运动|单次运动详情数据|**单次运动每5秒钟的详情数据** 跑步：心率、速度、步频 步行：心率、速度、步频 骑行：心率|
