# 中国医疗保健国际交流促进会-血管健康研究

**1. 简介**

中国医疗保健国际交流促进会（简称中国医促会）基于HUAWEI Research快速开展血管健康研究，配合华为智能穿戴设备，为用户提供血管健康风险筛查和专业健康指导建议，以帮助人们实现居家、便捷的血管健康评估管理方案，了解自身血管健康状态，开启健康美好生活。

**2.** **核心痛点**

* 常规招募参与的样本少

  医院及研究机构的常规招募方式（如地推宣传等）通常只能招募到少数参与者，研究数据样本有限，导致研究优化改进受限。


* 无法动态长时监测

  动脉硬化是动脉变厚、变硬等一些列变化的总称，可使动脉失去弹性、管腔狭窄，其发生和发展是一个隐匿、渐进的过程，是多种心血管疾病的早期表现，但传统检测方法多数操作复杂、设备昂贵。


* 血管健康管理意识待提升

  目前，动脉硬化早期检测在我国仍未得到重视和普及，只停留在三级及个别的二级专科医院，绝大部分动脉硬化亚临床患者无自觉症状，并不会主动到大医院检查。

**3.** **解决方案**

* 开发技术助力用户招募： HUAWEI Research开放研究类APP开发框架，帮助中国医促会高效开展血管健康研究，用户可用手机注册参与，并在用户知情同意的情况下轻松获取高价值的研究数据。

* 实现居家便捷检测： HAUWEI Research开放华为智能穿戴设备传感器能力，融合检测脉搏波传导速度，筛查动脉硬化风险，帮助用户居家管理血管健康。

* 持续输出专业科普教育： HUAWEI Research联合TOP专家和权威机构，设计个性化指导建议，定期科普专业文章，帮助用户呵护自身血管健康。

**4.** **合作受益**

* 中国医促会

  快速发布APP到华为应用市场（现已上线至华为创新研究APP），广泛招募参与者，配合华为智能穿戴设备，数据采集方便快捷。

  基于HUAWEI Research大数据分析能力，深度分析和处理数据，挖掘数据价值，更易于产生创新研究成果。


* 用户

  提供动脉硬化风险筛查和健康指导建议，实现居家血管健康管理。

  专业科普知识，自主管理健康，主动预防，开启健康生活。

  在华为应用市场搜索"华为创新研究"，下载并安装，配合华为智能穿戴设备即可体验，自主筛查动脉硬化风险。
