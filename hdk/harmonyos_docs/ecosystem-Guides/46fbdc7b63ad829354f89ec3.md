# FAQ

**FAQ**

[问题一]什么样的伙伴能和擎云生态合作？

1. 认可擎云生态合作模式和价值观。

2. 伙伴拥有自主研发能力和自主品牌的售后服务能力。

[问题二]怎么样申请测试样机？

按照合作伙伴申请流程，审核通过后华为终端即向合作方发放测试样机。

[问题三]产品如何推荐给擎云生态？

1. 请您将贵公司简介及产品详细资料发送邮件到qingyun@huawei.com

2. 请确保企业信息真实有效，产品无侵权、违法、违规等情形。

[问题四]目前和擎云生态适配的产品有那些？

目前和擎云生态适配的产品详情，可在适配清单查阅。
