# 简单查询

本章节介绍如何使用过滤条件查询研究数据表。

SearchTableDataRequest请求参数释义如下：

|参数名|数据类型|说明|必选M/可选O|
|:------------|:--------------------|:----------------------------------------------|:------|
|sessionToken|String|鉴权获取到的sessionToken。|M|
|tableId|String|查询表的Table ID。可在数据表列表页面中查看到相应数据表的Table ID。|M|
|filters|List<FilterCondition>|过滤器列表|O|
|sorts|List<SortCondition>|排序字段列表|O|
|desireSize|int|查询数据表时，每页数据条数。最大默认5000条。|O|
|includeFields|List<String>|需查询的列字段，不指定返回全部字段。|O|
|excludeFields|List<String>|查询结果不需要返回的字段。 > 注意 > 该参数不能与include_filelds同时使用。|O|
[**表1**SearchTableDataRequest请求参数]

支持的过滤类型如下：

|FilterOperatorType|说明|
|:---------------------------|:----|
|OPERATOR_TYPE_EQUALS|等于|
|OPERATOR_TYPE_NOT_EQUALS|不等于|
|OPERATOR_TYPE_CONTAINS|包含|
|OPERATOR_TYPE_GREATER_THAN|大于|
|OPERATOR_TYPE_LESS_THAN|小于|
|OPERATOR_TYPE_GREATER_EQUALS|大于等于|
|OPERATOR_TYPE_LESS_EQUALS|小于等于|
|OPERATOR_TYPE_EXISTS|字段存在|
|OPERATOR_TYPE_NOT_EXISTS|字段不存在|
|OPERATOR_TYPE_IN|在列表中|
|OPERATOR_TYPE_NOT_IN|不在列表中|
[**表2**过滤类型]

支持的排序类型如下表：

|SortOperatorType|说明|
|:---------------|:-|
|SORT_TYPE_ASC|升序|
|SORT_TYPE_DESC|降序|
[**表3**排序类型]

支持的过滤条件逻辑类型如下表

|FilterLogicType|说明|
|:--------------|:-|
|LOGIC_TYPE_AND|与|
|LOGIC_TYPE_OR|或|
