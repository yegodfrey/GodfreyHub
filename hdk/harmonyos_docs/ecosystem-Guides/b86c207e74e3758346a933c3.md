# 人工审核认证

1. 进入人工审核认证界面

   **图1**选择企业资料人工审核认证   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172607.09132298901129849710533191850600:50001231000000:2800:E91371D8DEAC3AD4C93A1749502157B368BE75227CA9093AEF32E77B5CF6365A.png?needInitFileName=true?needInitFileName=true "点击放大")

2. 根据营业执照填写企业信息

   **图2**填写企业信息   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172607.64459657889030275554977951011168:50001231000000:2800:2CBDAA9A2679F0DC192CCF39AAAFEB7B0B3863743F47D1184136AFC8FC7BFCCA.png?needInitFileName=true?needInitFileName=true "点击放大")

3. 上传企业证件：

   ① 若机构有营业执照，在"**营业执照**"栏上传营业执照

   ② 若机构无法提供营业执照，则上传事业单位法人证书

   **图3**上传营业执照/法人证书   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172607.59208017865429071646925736737484:50001231000000:2800:1EFCC5D2ACDCB41D1F02AF34BE68E32CC800CF8E40E4D8D8B03F2B09AA3E6FC2.png?needInitFileName=true?needInitFileName=true "点击放大")

4. 法定代表人身份验证

   法定代表人身份验证方式有两种：上传手持身份证和人脸验证。

   **图4**法人代表验证方式   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172607.64543953077362044242895431164180:50001231000000:2800:43697CE0ED97B6AB9EFFEB4B51E4CE93B0F7AD50CBB57DB6902BFFC41C80FBEF.png?needInitFileName=true?needInitFileName=true "点击放大")

   所有信息填写完毕后，签署《华为开发者联盟与隐私的声明》和《华为开发者服务协议》，点击"下一步"，等待审核，审核结果会在1-2个工作日发送至联系人邮箱。
