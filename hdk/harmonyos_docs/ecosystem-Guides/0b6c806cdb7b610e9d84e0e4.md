# 连接设备

* 接口说明 选择蓝牙扫描的穿戴设备后，进行设备连接。

* 接口方法

  ```codeblock
  public voidconnectBTDevice(@NonNull BluetoothDevice bluetoothDevice, @NonNull SensorProCallback<String> callback)
  ```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:--------------|:----------------|:---|:------|
  |bluetoothDevice|BluetoothDevice|穿戴设备|M|
  |callback|SensorProCallback|返回结果|M|
  [**表1**输入参数]

* 响应参数

  |响应方法名|参数名|数据类型|说明|
  |:---------|:-----------|:-----|:-----|
  |onResponse|errorCode|int|返回错误码|
  |onResponse|returnObject|String|返回结果说明|
  [**表2**响应参数]

* 示例代码

  ```codeblock
  import android.bluetooth.BluetoothDevice;
  import com.huawei.hiresearch.sensorfat.SensorScaleManager;
  import com.huawei.hiresearch.sensorprosdk.provider.callback.SensorProCallback; 

  /**
   * 设备连接
   * @param bluetoothDevice 穿戴设备
   */
  public void connectBTDevice(BluetoothDevice bluetoothDevice) {
          SensorScaleManager.getInstance().getScaleBaseProvider().connectBTDevice(bluetoothDevice, new SensorProCallback<String>() {
  @Override
  public void onResponse(int errorCode, String returnObject) {
          // TODO:连接成功 (errorCode：错误码；returnObject：返回数据)
          }
          });
          }
  ```
