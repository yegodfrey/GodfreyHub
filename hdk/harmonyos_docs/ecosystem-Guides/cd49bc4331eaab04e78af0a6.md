# 数据上云

HUAWEI Research支持测量数据标准化上云、自定义数据上云。

HUAWEI Research平台提供元数据管理能力，用于校验上传数据格式。元数据包括系统元数据和用户自定义元数据。平台预置系统元数据，支持采集的运动健康数据标准化上传。
