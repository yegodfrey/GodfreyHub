# 301医院&北京大学第一医院&华中科技大学同济医学院附属同济医院-呼吸健康研究

**1.简介**

呼吸健康研究项目由301医院、北京大学第一医院、华中科技大学同济医学院附属同济医院联合发起，基于华为智能穿戴设备，将体温、呼吸率等生理参数结合异常咳嗽音的智能识别判断，进行肺部感染风险的主动筛查，实现居家主动呼吸健康管理。

**2.核心痛点**

* 常规参与招募的样本量少： 医院及研究机构的常规招募方式（如张贴海报宣传等）通常只能招募到少数参与者，研究样本有限，导致研究优化改进受限

* 难以实现居家呼吸健康管理： 呼吸系统疾病由于发病率高、疾病负担重、传染性强，对人口健康威胁大等缘故，已成为全球性医疗保健与公共卫生的重要问题。通过传统方式（如医院检测）耗时费力，患者不能实时监测自身的呼吸健康状况，导致无法对自身呼吸状况进行有效健康管理。


* 自主健康管理意识待提升：

  在国家卫健委提倡全民健康、普及健康知识的大环境下，国民整体的自主健康管理意识还需进一步提升。

**3.解决方案**

* 开发技术助力用户招募：

  HUAWEI Research开放研究类APP开发框架，帮助301医院、北京大学第一医院、华中科技大学同济医学院附属同济医院高效开展呼吸健康研究，用户可用手机注册参与，并在用户知情同意的情况下轻松获取高价值的研究数据


* 实现居家便捷检测：

  HUAWEI Research开放华为智能穿戴设备传感器能力，将体温、呼吸率等生理参数结合异常咳嗽音的智能识别判断，进行肺部感染风险的主动筛查，实现居家主动呼吸健康管理，助力机构创新研究与技术的孵化。


* 持续输出专业科普教育：

  HUAWEI Research联合301医院、北京大学第一医院、华中科技大学同济医学院附属同济医院专科医生，打造呼吸健康科普内容，提升用户自主健康管理意识。

**4.合作受益**

* 301医院、北京大学第一医院、华中科技大学同济医学院附属同济医院 通过华为创新研究统一入口，更易招募参与者，更智能便捷地开展创新研究。


* 用户 享受每日风险筛查、呼吸系统健康小知识和权威专家提供的健康建议，实现居家主动呼吸健康管理。
