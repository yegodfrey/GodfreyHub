# 华中科技大学附属同济医院-情绪健康研究

**1.简介**

华中科技大学同济医学院附属同济医院基于HUAWEI Research开展情绪研究，构建情绪健康研究APP，配合华为智能穿戴设备高性能心率传感器、运动传感器，帮助情绪障碍人群进行运动进程规划、疗效检测。

**2.核心痛点**

* 无法长期实时检测 人的情绪易受现实情境、生物周期、认知判断和生活方式等影响，传统情绪检测和识别技术无法长期连续检测参与者情绪状态，了解情绪的发展过程。


* 实际操作繁琐，用户依从度不高 运动疗法改善情绪障碍研究，常规方式需要通过系列问卷调查和检测手段对参与者的情绪状态、运动情况进行综合评估，操作繁琐，用户长期依从度较差。


* 运动后效果难以通过传统方式获取 情绪障碍由紧张、焦虑、忧郁、担心和恐惧等交织而成，复杂多样，采取运动疗法改善情绪障碍，传统方式难以对运动后效果，特别是短期效果进行评估。

**3.解决方案**

* 穿戴设备便携24小时检测： 华为智能穿戴设备具有便携，24小时长程、居家检测的特点，可随时随地自动测量。


* 开放传感器能力快速获取数据： HUAWEI Research开放传感器能力，在用户知情同意下，可快速获取参与者的心率、睡眠、运动等高价值研究数据，实时了解参与者的运动情况和情绪变化。


* 开发技术助力效果评估： HUAWEI Research开放研究类APP开发框架和大数据分析框架，在隐私授权下不仅能获取大样本量用户运动轨迹与脉搏数据，还可精确分析其心率变异性、运动模式及运动消耗等数据，并进行综合评估。

**4.合作受益**

* 华中科技大学附属同济医院 更易招募参与者，在隐私授权下，快捷方便获取临床数据用于研究工作。

  用户依从度更高，研究数据质量大幅度提升。


* 用户 帮助情绪障碍用户进行有效的运动疗法治疗，避免药物治疗带来的副作用，并帮助进行自我情绪健康管理。
