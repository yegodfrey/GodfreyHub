# 血氧饱和度

* 接口说明 从穿戴设备上获取每分钟平均血氧饱和度数据。请联系HUAWEI Research团队，确认您的设备是否支持此能力。若需要配置连续数据开关请参考 "实时健康数据"整个章节说明。

* 接口方法

  ```codeblock
  public voidgetSpo2DataHistory(intstartTime, intendTime, @NonNull finalSensorProTransFileCallback<List<Spo2FilterAvgData>> callback);
  ```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:--------|:-----------------------------------------|:--------|:------|
  |startTime|int|获取数据的开始时间|M|
  |endTime|int|获取数据的结束时间|M|
  |callback|SensorProCallback<List<Spo2FilterAvgData>>|获取平均血氧|M|
  [**表1**输入参数]

* 响应参数

  |响应方法名|参数名|数据类型|说明|
  |:---------|:-----------|:----------------------|:-------|
  |onProgress|progress|Progress|文件传输通用回调|
  |onResponse|errorCode|int|返回错误码|
  |onResponse|returnObject|List<Spo2FilterAvgData>|返回结果说明|
  [**表2**响应参数]

  |字段名|数据类型|说明|
  |:--------------|:---|:---------|
  |spo2DataLen|int|有效的血氧个数|
  |startTimeStamp|long|血氧数据的开始时间戳|
  |spo2AVGViewData|int|用于显示的血氧值|
  [**表3**Spo2FilterAvgData(每分钟平均血氧)]
