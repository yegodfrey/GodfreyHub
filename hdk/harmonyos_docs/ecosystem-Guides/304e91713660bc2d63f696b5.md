# 健康相关数据

* RRI数组: RriDataArray 一个RRI数据包含一分钟内R-R的时间间隔，时间间隔为ms

  |字段名|数据类型|说明|
  |:----------|:-----------------|:--------------------------------------------------------------------------------|
  |timeStamp|long|数据时间戳|
  |rriData|List<RriDataPoint>|一分钟的RRI数据数组|
  |motionState|List<Integer>|motion state高4位是acc运动状态，低4位是ppg幅值状态，acc是0-7共8个级别，越高运动状态越强，ppg是0-2，2信号质量很好，0信号质量不好|
  [**表1**RriDataArray]

* 单个RRI数据：RriDataPoint 包含此个心率R波间隔，时间为毫秒。

  |字段名|数据类型|说明|
  |:-------|:---|:---------|
  |rriValue|int|R波间隔，单位为ms|
  |sqiValue|int|信号质量|
  [**表2**RriDataPoint]

* 主动测量RRI：RealTimeRriData

  |字段名|数据类型|说明|
  |:-----------|:----------|:-------|
  |rriTime|int|数据时间戳|
  |rriIntensity|int|RRI信号强度|
  |rriAccState|int|ACC运动状态|
  |rriList|List<int[]>|一组RRI值数组|
  [**表3**RealTimeRriData]

* 心率数据：HrData

  |字段名|数据类型|说明|
  |:--------|:---|:----|
  |dataStamp|long|数据时间戳|
  |hrValue|int|心率值|
  [**表4**HrData]

* 每分钟平均血氧：Spo2FilterAvgData 一分钟内平均血氧，如下9800表示每分钟平均血氧饱和度为98%。

  |字段名|数据类型|说明|
  |:--------------|:---|:------------|
  |startTimeStamp|long|血氧数据的开始时间戳|
  |spo2AVGViewData|int|平均值血氧饱和度* 100|
  [**表5**Spo2FilterAvgData]

* 每分钟样本睡眠数据：SleepStatusPoint

  |字段名|数据类型|说明|
  |:--------|:---|:-------------------------------------------|
  |timeStamp|long|开始时间|
  |status|int|睡眠类型： * 1：浅睡 * 2：快速眼动 * 3：深睡 * 4：清醒 * 5：零星小睡|
  [**表6**SleepStatusPoint]

* ECG数据：EcgInfo

  |字段名|数据类型|说明|
  |:-----------|:----|:----|
  |ecgTimeStamp|long|时间戳|
  |ecgData|int[]|ECG数据|
  |lead|int|导联状态|
  [**表7**EcgInfo]

* 运动强度数据：Intensity

  |字段名|数据类型|说明|
  |:-------------|:----|:--------------------|
  |startTimeStamp|int|开始时间戳|
  |intensity|int[]|运动强度集合 * 1：低 * 3：中高强度|
  [**表8**Intensity]

* 穿戴设备数据：WearStatus

  |字段名|数据类型|说明|
  |:--------|:----|:---------------------------|
  |timeStamp|int|时间戳|
  |state|int[]|佩戴状态 * 0：佩戴； * 1：未佩戴； * 2：未知|
  [**表9**WearStatus]
