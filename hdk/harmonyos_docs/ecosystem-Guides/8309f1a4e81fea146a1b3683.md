# 查询设备电池状态

* 接口说明 获取穿戴设备电量（单位：%）。

* 接口方法

  ```codeblock
  public voidgetBattery(@NonNull finalSensorProCallback<Integer> callback);
  ```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:-------|:---------------------------|:---|:------|
  |callback|SensorProDeviceStateCallback|返回结果|M|
  [**表1**输入参数]

* 响应参数

  |响应方法名|参数名|数据类型|说明|
  |:---------|:---|:------|:----------|
  |onResponse|code|int|返回错误码(成功：0)|
  |onResponse|data|Integer|电量，单位：%|
  [**表2**响应参数]

* 示例代码

  ```codeblock
  importcom.huawei.hiresearch.sensorprosdk.SensorProManager;
  importcom.huawei.hiresearch.sensorprosdk.provider.callback.SensorProCallback; 
  /**
  * 查询设备电池状态
  * **@param** **serviceId**
  */
  public voidgetBattery(String serviceId) {
       SensorProManager.getInstance().getDeviceProvider().getBattery(newSensorProCallback<Integer>() {
           /**
  *
  * **@param** **code** 状态码(0：成功)
  * **@param** **data** 电量
  */
  @Override
           public voidonResponse(intcode, finalInteger data) {
               // **TODO:查询成功**
  }
       });
   }
  ```
