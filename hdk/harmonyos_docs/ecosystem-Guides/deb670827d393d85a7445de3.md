# 301医院-心脏健康研究

**1. 简介**

301医院基于HUAWEI Research快速构建心脏健康研究APP，配合华为智能穿戴设备高性能心率传感器，依托全国70多家协作医院，精细化识别心律失常，为用户提供房颤及早搏、筛查、确诊、跟踪、随访等一站式整合管理和房颤风险预测服务。自推出以来，已招募超过220万参与者，帮助进行心律失常早期干预和主动健康管理。

**2. 核心痛点**

* 常规招募参与的样本少： 医院及研究机构的常规招募方式（如地推宣传等）通常只能招募到少数参与者，研究数据样本有限，导致研究优化改进受限。


* 无法24h实时监测数据： 心律失常早期多无明显症状，发作无规律，且发作时间短暂，稍纵即逝，患者往往不易察觉，知晓率和就诊率低，但一旦恶化可导致脑卒中等并发症，需长期持续监测，进行早期干预。


* 自主健康管理意识待提升： 在国家卫健委提倡全民健康、普及健康知识的大环境下，国民整体的自主健康管理意识还需进一步提升。

**3. 解决方案**

* 开发技术助力用户招募： HUAWEI Research开放研究类APP开发框架，帮助301医院高效开发心脏健康研究APP，用户可用手机注册参与，并在用户知情同意的情况下轻松获取高价值的研究数据。


* 实现居家便携24h筛查： HUAWEI Research开放华为智能穿戴设备心率传感器能力，随时随地捕捉稍纵即逝的心律失常，实现一键检测、24h智能监护，帮助用户居家管理心脏健康。


* 持续输出专业科普教育： HUAWEI Research联合301医院专科医生，打造心脏健康科普内容，提升用户自主健康管理意识。

**4. 合作受益**

* 301医院 发布APP到华为应用市场，广泛招募参与者，基于HUAWEI Research大数据分析能力，深化研究方向，不断进行研究创新。

  相关研究成果在ESC 2019上发表、JACC全文刊载，作为中国优秀原创研究代表写入世界版图，2020年，研究成果再次刊载在全球心脏和心血管系统领域的著名期刊《美国心脏病学会杂志》（JACC）和国际著名医学期刊《欧洲心脏病杂志》（EHJ）上，且被写入欧洲心脏病学会ESC 2020年最新发布的房颤管理指南。


* 用户 精细化识别心律失常，筛查房颤及早搏，居家管理心脏健康。

  专业科普知识，自主管理健康，主动预防，开启健康生活。

  在华为应用市场搜索"心脏健康研究"，下载并安装，配合华为智能穿戴设备即可体验，自主管理心脏健康。
