# 关闭实时测量采集

* 接口说明 关闭穿戴设备采集混合数据开关。

* 接口方法

  ```codeblock
  public voidstopCollectCustomData(@NonNull SensorProCallback<byte[]> callback)
  ```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:-------|:-------------------------|:--------|:------|
  |callback|SensorProCallback<byte[] >|关闭采集的操作结果|M|
  [**表1**输入参数]

* 响应参数

  |响应方法名|参数名|数据类型|说明|
  |:---------|:-----------|:-----|:-----|
  |onResponse|errorCode|int|返回错误码|
  |onResponse|returnObject|byte[]|返回结果说明|
  [**表2**响应参数]
