# 扫描设备

* 接口说明 通过蓝牙根据设备类型扫描指定穿戴设备。

  > 说明
  >
  > 手机需要开启蓝牙并授予APP位置权限后，才能调用穿戴设备蓝牙扫描接口。
* 接口方法

  ```codeblock
  public voidscanDevice(intdeviceItemType, SensorProDeviceDiscoverCallback callback)
  ```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:-------------|:------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:------|
  |callback|SensorProDeviceDiscoverCallback|返回扫描到穿戴设备|M|
  |deviceItemType|int|设备类型： * 1：表示HUAWEI WATCH GT 2系列：支持HUAWEI LTN、HUAWEI VID、HUAWEI WATCH GT 2 Pro研究设备 * 3：表示荣耀手环5：支持HONOR BAND 5研究设备 * 5：表示华为手环4系列：支持HUAWEI Band 4、HUAWEI Band 4 Pro研究设备 * 6：表示华为手环6、手环7：支持HUAWEI BAND 6、HUAWEI BAND 7研究设备 * 7：表示华为WATCH D ：支持WATCH D研究设备 * 8：表示S-TAG：支持HUAWEI S-TAG研究设备 * 9：表示华为WATCH GT 3系列：支持WATCH GT 3研究设备|M|
  [**表1**输入参数]


* 响应参数

  |响应方法名|参数名|数据类型|说明|
  |:------------------------|:-----|:--------------|:---------------------------------------------------------------------|
  |onDeviceDiscovered|device|BluetoothDevice|* 回调描述：扫描到设备时 * 参数描述：返回扫描到的设备信息，该类引自android.bluetooth. BluetoothDevice|
  |onDeviceDiscoveryFinished|NA|NA|扫描结束|
  |onDeviceDiscoveryCanceled|NA|NA|取消扫描|
  |onFailure|cause|int|* 回调描述：扫描失败 * 参数描述：错误码|
  [**表2**响应参数]

          public void onDeviceDiscoveryCanceled() {

          }

           * cause : 错误码
           */
