# 申请研究项目

* **准入条件：研究项目通过国家指定的伦理审查委员会的审批；**

1. 进入HUAWEI Research项目申请界面

   进入[HUAWEI Research创新研究平台官网](https://developer.huawei.com/consumer/cn/HiResearch/)，点击"**立即加入**"，进入HUAWEI Research生态服务。

   **图1**Research官网页面   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172607.25904938353962857149766158058404:50001231000000:2800:3055A139B6F5EAF323B342A62FC59EC7073BF4A52BC1E237AABA7EEA9CE53D31.png?needInitFileName=true?needInitFileName=true "点击放大")

2. 申请创建研究项目

   1. 首次进入HUAWEI Research生态服务，需要签署服务协议，请您仔细阅读服务协议并签署。如下图所示：

      **图2**签署HUAWEI Research使用协议   
      ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172608.61121152274054581012686605380532:50001231000000:2800:FAED8268CC456A9F4E034530B00EF059BF3BB7D100CF380D86C4E992C98E2E88.png?needInitFileName=true?needInitFileName=true "点击放大")
   2. 点击"**申请研究项目** "

      **图3**申请研究项目入口   
      ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172608.47385685424200618048967405974041:50001231000000:2800:69C969E1F1128C6AE7405F1EED3FF3944AD5A357F0F9BE91B7C28503B6A8889B.png?needInitFileName=true?needInitFileName=true "点击放大")
   3. 填写项目信息 填写项目名称、计划招募用户规模，并上传伦理报告，按需勾选研究数据类型，点击"**提交**"按钮提交申请。

      **图4**   
      ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172608.62052153459757926673062493199595:50001231000000:2800:AA352223B3AF9F0C3B5F9C2A0AAD0EB63F65548AED26FCB94264B64EB325C7B4.png?needInitFileName=true?needInitFileName=true "点击放大")
   4. Health Kit权限申请**（非必选）**

      如果使用商用版本，则需要进行Health Kit权限申请；如果设备要进行科研版本更新，则不需要进行这一步，等待平台审核即可（1周左右）。如有疑问，请联系HiResearch@huawei.com

      ①在开发者联盟平台里的"**应用服务** "中查找"**开发服务** "，点击"**Health Kit**"模块

      勾选完成后，提交审核。
   5. 项目审核通过 项目审核通过后，将收到项目审核通过的邮件，可通过邮件中的平台地址和邀请码，注册并登录该研究项目。

      **图11**审核通过   
      ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172608.51360883130663155244769641276096:50001231000000:2800:89B9CDA8648341031AB60CD953294908ABB4CBBE6915132210F33251A7800F27.png?needInitFileName=true?needInitFileName=true "点击放大")

      邮件邀请码的有效期是3天，若邀请码过期，可以进入开发者联盟项目页面，点击"**进入** **HUAWEI Research**"，注册并登录该研究。

      **图12**进入HUAWEI Research
