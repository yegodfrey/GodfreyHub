# 监控设备状态

* 接口说明 穿戴设备连接状态变更时，会通过回调方法进行通知。

* 接口方法

  ```codeblock
  public voidregisterStateMonitor(@NonNull SensorProDeviceStateCallback callback)
  ```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:---------|:------------------|:---|:------|
  |deviceInfo|SensorProDeviceInfo|穿戴设备|M|
  |callback|SensorProCallback|返回结果|M|
  [**表1**输入参数]

* 响应参数

  |响应方法名|参数名|数据类型|说明|
  |:---------|:-----------|:-----|:-----|
  |onResponse|errorCode|int|返回错误码|
  |onResponse|returnObject|String|返回结果说明|
  [**表2**响应参数]

  |字段名|数据类型|说明|
  |:-----------------|:-----|:----|
  |deviceName|String|设备名称|
  |deviceIdentify|String|MAC地址|
  |version|String|设备版本|
  |deviceConnectState|int|连接状态|
  |productType|int|产品类型|
  |deviceModel|String|设备型号|
  |deviceItemType|int|设备类型|
  |wearType|int|佩戴类型|
  [**表3**SensorProDeviceInfo（设备信息）]
