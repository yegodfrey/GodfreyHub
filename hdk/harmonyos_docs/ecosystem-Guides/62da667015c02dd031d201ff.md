# 单次运动记录

* 接口说明 从穿戴设备上获取运动记录，返回运动记录的workoutid。

* 接口方法

  ```codeblock
  public voidgetSingleMotionRecords(intbeginTime, intendTime, SensorProCallback<List<WorkOutRecord>> callback)
  ```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:--------|:-------------------------------------|:---------|:------|
  |startTime|int|数据开始时间|M|
  |endTime|int|数据结束时间|M|
  |callback|SensorProCallback<List<WorkOutRecord>>|返回单次运动记录ID|M|
  [**表1**输入参数]

* 响应参数

  |参数名|数据类型|说明|
  |:-----------|:------------------|:--------|
  |errorCode|int|返回错误码|
  |returnObject|List<WorkOutRecord>|运动量详情结果说明|
  [**表2**响应参数]

  |字段名|数据类型|说明|
  |:-------------------------|:---|:-------|
  |workout_record_id|int|单次运动记录ID|
  |workout_index_count|int|单次运动索引条数|
  |pace_index_count|int|配速信息索引条数|
  |workout_section_index|int|分段信息索引条数|
  |workout_section_index|int|分片数据|
  |workout_blood_oxygen_index|int|血氧信息索引条数|
  [**表3**WorkOutRecord（运动统计数据）]
