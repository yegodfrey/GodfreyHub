# 接入运动健康开放服务

1. 登录开发者联盟。

   登录[华为开发者联盟](https://developer.huawei.com/consumer/cn)，如果没有帐号，请先注册，注册方法请参考[注册企业帐号](https://developer.huawei.com/consumer/cn/doc/development/ecosystem-Guides/02_01_register_account-0000001076757454)。

2. 进入生态服务页面。
3. 在"智慧生活"里选择"运动健康（服务）"，如下图所示：

   **图1**智慧生活   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172614.28557782737839286224853379295704:50001231000000:2800:03618E6F61DCCC9F6AEF416EBC40530DF56EC4D6F87E69693448E807079B77DA.png?needInitFileName=true?needInitFileName=true "点击放大")

4. 点击"申请运动健康服务"，如下图所示：

   **图2**申请运动健康服务   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172614.83812453096768120093287598691210:50001231000000:2800:AAEBC16D4782E7CA2DD815C9762CA7BA3311E059B3E497F1DD40AF83DF3004BE.png?needInitFileName=true?needInitFileName=true "点击放大")

5. 从下拉列表选择刚才创建并且已开通帐号服务的产品，如下图所示：

   **图3**帐号服务   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172614.34766450493026458498285656366841:50001231000000:2800:4C81A77EB6FC1C80D7C05833DFDB9C8BCEE9B9523BF3E68FE4EC73F3126467B0.png?needInitFileName=true?needInitFileName=true "点击放大")

6. 勾选产品必需申请的数据权限,如下图所示：

   **图4**数据权限   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172614.44169311838451682632362135861480:50001231000000:2800:FF99B623D76C1A8092702A86C1A469585B762DAF8D82570E90B4F2EDA2CDE5EA.png?needInitFileName=true?needInitFileName=true "点击放大")

   > 注意
   >
   > 添加服务时，遵循权限最小化原则：根据业务需求选择必要的数据访问权限，并同意服务条款。数据权限应与业务相符，不可申请超出业务范围或者暂时不适用的权限，否则将无法通过审批。更详细操作步骤请参阅：[开发者联盟帮助文档](https://developer.huawei.com/consumer/cn/doc/development/huaweihealth-Guides/registering-applying-account-0000001053710730)。
