# 每日运动量

* 接口说明 从穿戴设备获取每日统计数据，包括跑步、步行、爬山等步数以及卡路里等每日运动量数据。

* 接口方法

  ```codeblock
  public voidgetTodayTotalMotion(@NonNull SensorProCallback<TodayMotionDataArray> callback)
  ```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:-------|:--------------------------------------|:---------|:------|
  |callback|SensorProCallback<TodayMotionDataArray>|返回每日运动统计数据|M|
  [**表1**输入参数]

* 响应参数

  |参数名|数据类型|说明|
  |:-----------|:-------------------|:-------|
  |errorCode|int|返回错误码|
  |returnObject|TodayMotionDataArray|每日统计数据数组|
  [**表2**响应参数]

  |字段名|数据类型|说明|
  |:---------------|:--------------------|:------|
  |dataTotalMotions|List<TodayMotionData>|每日统计数据集|
  [**表3**TodayMotionDataArray（每日运动统计数据集）]

  |字段名|数据类型|说明|
  |:----------|:---|:-----------------------------------------------------------------------------------|
  |motion_type|int|运动类型： * 1：walk * 2：running * 3：climbing the mountain * 4：bike * 5：standing * 6：sleep|
  |step|int|步数|
  |calorie|int|卡路里|
  |distance|int|距离|
  [**表4**TodayMotionData（每日运动统计数据）]
