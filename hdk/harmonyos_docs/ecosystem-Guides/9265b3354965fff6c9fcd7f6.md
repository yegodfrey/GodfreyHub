# 手动引入依赖

如您选择不带有依赖的SDK文件hiresearch-client-x.x.x.jar，您可手动解压hiresearch-client-x.x.x-with-dependencies.jar包，在\META-INF\maven\com.huawei.hiresearch\schemasdk目录下，找到pom.xml文件，打开文件查看相关依赖，将所需的依赖拷贝复制到自己的工程中。
