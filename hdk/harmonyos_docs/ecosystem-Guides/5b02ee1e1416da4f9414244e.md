# 向算法输入原始数据

* 接口说明 接收到设备返回的实时数据，传给STAG算法解析。

* 接口方法

```codeblock
public static List<PostureResult> getBoltParseResult(FeatureData returnObject, boolean cbMagChecked) 
 
```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:-----------|:----------|:--------|:------|
  |returnObject|FeatureData|设备实时返回的数据|M|
  |cbMagChecked|boolean|是否采集MAG数据|M|
  [**表1**输入参数]


* 响应参数

  |参数名|数据类型|说明|
  |:----------------|:------------------|:----|
  |postureResultList|List<PostureResult>|算法返回值|
  [**表2**响应参数]

  |字段名|数据类型|说明|
  |:---------------|:---------------|:---|
  |nativeFeature|PostureFeature|原生特征|
  |postureExFeature|PostureExFeature|扩展特征|
  [**表3**PostureResult]

  > 说明
  > 1. STAG设备需要放在脚部夹子或者腰部夹子上，才能获取到实时数据，放在充电器上也没有数据。
  > 2. STAG采集磁力计原始数据，需要根据当地磁场环境，自行校正软磁、硬磁参数。
  >
  >    * 软磁、硬磁参数参考值：

  >    * 校正方法：Y=AX-B
  >    * X为磁力计原始数据；Y为磁力计校正后数据

  |字段名|数据类型|说明|
  |:---|:-----|:---------------------------------|
  |acc|CPIMU|三轴加速度（±16g，重力加速度转换系数0.00048828）|
  |gyro|CPIMU|三轴陀螺仪（±32rad/s，弧度/秒转换系数0.00122173）|
  |mag|CPIMU|三轴磁力计（±3000uT，请校正软磁、硬磁后使用）|
  |quat|CPQUAT|单位四元数（qw，qx，qy，qz）|
  [**表4**PostureFeature]

  |字段名|数据类型|说明|
  |:--|:----|:------|
  |x|float|X轴方向加速度|
  |y|float|Y轴方向加速度|
  |z|float|Z轴方向加速度|
  [**表5**CPIMU]

  |字段名|数据类型|说明|
  |:--|:----|:-------|
  |qw|float|单位四元数qw值|
  |qx|float|单位四元数qx值|
  |qy|float|单位四元数qy值|
  |qz|float|单位四元数qz值|
  [**表6**CPQUAT]

  |字段名|数据类型|说明|
  |:-----|:--------|:-------|
  |mat|float[][]|3×3旋转矩阵|
  |invmat|float[][]|3×3逆旋转矩阵|
  [**表7**PostureExFeature]


* 示例代码

```codeblock
List<PostureResult> postureResultList = 
PostureDataConvertUtils.getBoltParseResult(returnObject, true)
 
```
