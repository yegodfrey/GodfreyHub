# 监控设备状态

* 接口说明 穿戴设备连接状态变更时，会通过回调方法进行通知。

* 接口方法

  ```codeblock
  public voidregisterStateMonitor(@NonNull SensorProDeviceStateCallback callback);
  ```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:-------|:---------------------------|:---|:------|
  |callback|SensorProDeviceStateCallback|返回结果|M|
  [**表1**输入参数]

* 响应参数

  |响应方法名|参数名|数据类型|说明|
  |:---------|:---------|:------------------|:----------|
  |onResponse|code|int|返回错误码(成功：0)|
  |onResponse|deviceInfo|SensorProDeviceInfo|设备信息|
  [**表2**响应参数]

  |字段名|数据类型|说明|必选M/可选O|
  |:-----------------|:-----|:---------------------------------------------|:------|
  |deviceName|String|设备名称|M|
  |deviceIdentify|String|MAC地址|M|
  |version|String|设备版本|O|
  |deviceConnectState|int|设备连接状态： * 1：正在连接； * 2：已连接； * 3：连接断开； * 4：连接失败。|O|
  |productType|int|产品类型|O|
  |deviceModel|String|设备型号|O|
  |deviceItemType|int|设备类型|O|
  |wearType|int|佩戴类型|O|
  [**表3**SensorProDeviceInfo（设备信息）]

* 示例代码

  ```codeblock
  importcom.huawei.hiresearch.sensorprosdk.SensorProManager;
  importcom.huawei.hiresearch.sensorprosdk.datatype.device.SensorProDeviceInfo;
  importcom.huawei.hiresearch.sensorprosdk.provider.callback.SensorProDeviceStateCallback;

  /**
  * 设备状态监控
  * **@param** **serviceId**
  */
  public voidregisterStateMonitor(String serviceId) {
       SensorProManager.getInstance().getDeviceProvider().registerStateMonitor(serviceId, newSensorProDeviceStateCallback() {
           /**
  * **@param** **code** 错误码
  * **@param** **deviceInfo** 设备信息
  */
  @Override
           public voidonResponse(intcode, SensorProDeviceInfo deviceInfo) {
               // **TODO:调用成功**
  }
       });
   }
  ```
