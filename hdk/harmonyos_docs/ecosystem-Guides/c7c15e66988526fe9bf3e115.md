# 树兰医疗感染科医生集团------肝脏脂肪研究

**1.简介**

肝脏脂肪研究是树兰医疗感染科医生集团基于华为智能体脂秤开展的肝脏脂肪风险筛查研究，结合大数据验证，检测肝脏脂肪等级，提供专业健康指导建议，对脂肪肝进行早期预防和主动干预，帮助用户实现居家肝脏健康管理。

**2.核心痛点**

* 常规招募参与的样本少 医院及研究机构的常规招募方式（如地推宣传等）通常只能招募到少数参与者，研究数据样本有限，导致研究优化改进受限

* 肝脏健康管理意识待提升 现在我国的脂肪肝发病率不断升高，发病年龄也日趋年轻化。人群基数大，恶化比例高，并显著提升死亡风险率。所以需要提升大家对脂肪肝的知晓率，主动、及时地对脂肪肝进行管理和干预，以防疾病进一步恶化。

* 无法实现动态及时检测 由于脂肪肝的知晓率低，大部分人以为只有肥胖人群才会得脂肪肝，一些风险用户可能出现发现不及时的现象；确诊有脂肪肝的患者，也不能及时居家监测脂肪肝的好转/恶化情况。

**3.解决方案**

* 开发技术助力研究招募： HUAWEI Research开放研究类APP开发框架，帮助树兰医疗感染科医生集团开展肝脏脂肪研究，并在华为创新研究APP中提供研究入口，用户通过手机和华为智能体脂秤 3 Pro就能参与研究，在用户知情同意的情况下轻松获取高价值的研究样本。

* 华为智能体脂秤提供检测能力： 基于华为智能体脂秤3 Pro，结合大数据验证，检测肝脏脂肪等级，筛查肝脏脂肪风险，对脂肪肝进行早期预防和主动干预，帮助用户实现居家肝脏健康管理。对于研究机构，也能助力实现创新研究的孵化与突破。

* 分层分级进行管理： 基于肝脏脂肪风险等级，对风险用户提供分层分级管理，提供个性化的指导建议和服务，并跟踪风险等级变化趋势，自主管理您的肝脏健康。

**4.合作受益**

* 树兰医疗感染科医生集团 快速发布APP到华为应用市场（现已上线至华为创新研究APP），广泛招募参与者，配合华为智能体脂秤，数据采集方便快捷。

  基于HUAWEI Research大数据分析能力，深度分析和处理数据，挖掘数据价值，更易于产生创新研究成果。
* 用户 用户通过华为应用市场搜索并下载"华为创新研究APP"，结合华为智能体脂秤3 Pro，即可筛查肝脏脂肪风险。

  低成本、居家即可测量，自主管理肝脏健康。

  肝脏脂肪风险便捷筛查，享受个性化指导建议和服务。

  权威机构建议，用户可主动预防、及时干预自身肝脏健康。
