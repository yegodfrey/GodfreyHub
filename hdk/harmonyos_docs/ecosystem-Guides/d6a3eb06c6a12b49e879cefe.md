# 心脏健康研究

301医院心脏健康研究项目借助HUAWEI Research创新研究平台和华为智能穿戴设备高精度传感器技术，继2019年ESC大会上首度证实移动技术用于房颤管理的可行性，并被写入2020年ESC房颤诊断和管理指南之后，第三次在2021年ESC大会上发表了基于光电容积脉搏波（PPG）技术人工智能房颤风险预警和单导联ECG筛查、预测房颤发作准确性及可行性报告。自推出以来，已招募超过300万参与者，筛查出10000+疑似房颤的人群，帮助6000+高风险用户通过房颤整合管理平台MAFA对接协作医院进行诊断，并获得一站式心律失常整合管理服务。

**2019** **年ESC：** **基于智能穿戴设备PPG进行连续房颤检测的可行性** ^１^

PPG阳性信号的91.6％确认为AF；大多数AF发作在14天之内被发现。

**2019** **年JACC:** **基于智能设备的光电容积描记技术，验证筛查心房颤动的有效性** ^2^

通过使用基于智能设备的光电容积描记（PPG）技术，结合使用移动健康方法的临床护理AF管理路径，在一个以人群为基础的大型队列中调查AF筛查的有效性。

**2020** **年ESC：** **写入2020 ESC房颤管理指南** ^3^

指南引用"基于心脏健康研究闭环管理服务，可有效地降低心血管事件发生率"。

**2021** **年ESC：**

**（1）机器学习模型能预测房颤发作风险，** **帮助用户提前做出预警反应** ^4^

借助HUAWEI Research创新研究平台，基于可穿戴设备持续监测大数据，AI预测心房颤动（房颤）发作风险预测房颤发作灵敏度为94.04%, 特异性为96.35%，召回率为94.04%。

**（2）** **智能技术支持的整合管理降低房颤多共病高危患者不良事件** ^5^

移动技术与智能穿戴设备支持的整合管理ABC，有效降低老年多共病患者的不良事件。

**（3）** **基于MAFA II管理平台，ChiOTEAF注册研究显示NOAC** **依从性不足及使用抗血小板药物是老年高危房颤患者的突出问题** ^6^

心脏健康研究APP集成MAFA II管理平台，对接前沿的房颤筛查技术，帮助医生及患者更好地管理疾病。

**2022** **年ESC：**

**（1）使用可穿戴设备监测房颤发作和血压动态变化，验证血压变化与房颤发生相关性** ^7^

通过可穿戴设备持续监测，证实24小时平均血压升高、反杓型血压和脉压差超过60 mmHg均会增加房颤易感性，为个性化"房颤风险控制"的临床应用提供了依据。

**（2）结合智能设备和人工智能工具进行以患者为中心的自我管理，可有效降低房颤负担并检测房颤发作** ^8^

将智能设备和AI工具纳入房颤临床护理路径，通过适当的节律控制管理和上游危险因素控制，可有效降低房颤负担并检测房颤发作。

**（3）通过移动健康技术和智能设备，可提高心律失常患者的运动依从性，改善患者体力活动习惯** ^9^

基于心脏健康研究APP，结合智能设备，给患者提供个性化的生活方式和运动指导，可促进心律失常患者体力活动习惯的改善以降低风险。

**2023** **年ESC：基于MAFA II管理平台，结合智能技术监测心血管危险因素预测房颤发生** ^10^

结合移动技术与智能穿戴设备，监测心血管危险因素：OSA、高血压、频发异位有助于预测房颤发生，呼吁对心血管风险进行有效的主动管理，以降低房颤负担。
