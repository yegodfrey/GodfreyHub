# 获取STAG离线存储文件

* 接口说明 同步STAG设备中离线存储的文件。

* 接口方法

```codeblock
public void getSTAGHistoryData(int startTime, int endTime, SensorProTransFileCallback<List<GaitPostureHistoryData>> callback) 
 
```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:-------|:-----------------------------------------------|:----------|:------|
  |callback|SensorProCallback< List<GaitPostureHistoryData>>|获取离线文件的操作结果|M|
  [**表1**输入参数]


* 响应参数

  |响应方法名|参数名|数据类型|说明|
  |:---------|:-----------|:-----------------------------|:-----|
  |onProgress|progress|Progress|文件传输进度|
  |onResponse|errorCode|int|返回错误码|
  |onResponse|returnObject|List< GaitPostureHistoryData >|返回结果说明|
  [**表2**响应参数]

* 示例代码

```codeblock
int stagEndTime =(int) (System.currentTimeMillis()/1000);
int stagStartTime = stagEndTime - 2*24*60*60;
SensorProManager.getInstance().getHealthProvider().getSTAGHistoryData(stagStartTime, stagEndTime, new SensorProTransFileCallback<List<GaitPostureHistoryData>>() {
     @Override
     public void onProgress(Progress progress) {
         LogUtils.info(TAG, " progress   " + progress.getDoneTotalSize() + "/" + progress.getFileTotalSize());
     }

     @Override
     public void onResponse(int errorCode, List<GaitPostureHistoryData> returnObject) {
         if (returnObject != null) {
                 LogUtils.info(TAG, " returnObject：" + JSON.toJSONString(returnObject));
             }
     }
 });
```
