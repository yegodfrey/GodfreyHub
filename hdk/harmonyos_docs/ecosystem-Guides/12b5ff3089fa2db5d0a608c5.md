# 附件类型元数据

1. 在Huawei Research平台创建元数据 HUAWEI Research平台提供元数据管理能力，研究项目管理员在HUAWEI Research平台"项目管理">"元数据"中新增元数据，如下图所示：

   **图1**附件类型元数据

2. 在Android工程中创建元数据类 开发者可以根据HUAWEI Research项目上定义的元数据，在应用开发工程中，手动创建元数据类。创建元数据类需继承于HiResearchBaseMetadata（与HUAWEI Research平台中元数据相对应），并指定元数据名称及版本号。元数据示例请参见下方"TestAttachment"类。

   ```codeblock
   importcom.huawei.hiresearch.common.annotation.metadata.HiResearchField;
   importcom.huawei.hiresearch.common.model.metadata.HiResearchBaseMetadata;
   importcom.huawei.hiresearch.common.annotation.metadata.HiResearchMetadata;
   importcom.huawei.hiresearch.common.annotation.metadata.HiResearchAttachmentField;
   importjava.util.List;
   import staticcom.huawei.hiresearch.common.annotation.metadata.HiResearchMetaType.*DEFAULT*;
   @HiResearchMetadata(name = "AttachmentMetadataExamole", version = "1.0", metaType = *DEFAULT*)
   public classTestAttachment extendsHiResearchBaseMetadata {
        /**
   * 第一个字段
   */
   @HiResearchField(name = "field1")
        private long field1;
        /**
   * 单个附件
   */
   @HiResearchAttachmentField(name = "field2")
        privateString field2;
        /**
   * 附件数组
   */
   @HiResearchAttachmentField(name = "field3")
        privateList<String> field3;
        /**
   * default constructor
   */
   publicTestAttachment() {
        }
        public longgetField1() {
            return this.field1;
        }
        public voidsetField1(longfield1) {
            this.field1= field1;
        }
        publicString getField2() {
            return this.field2;
        }
        public voidsetField2(String field2) {
            this.field2= field2;
        }
        publicList<String> getField3() {
            return this.field3;
        }
        public voidsetField3(List<String> field3) {
            this.field3= field3;
        }
    }
   ```

3. 上传数据到Huawei Research平台 以TestAttachment为例，上传普通元数据，示例代码如下：

   ```codeblock
   import com.huawei.hiresearch.bridge.BridgeManager2; 
   import com.huawei.hiresearch.bridge.provider.BridgeDataProvider; 
   import io.reactivex.disposables.CompositeDisposable; 
   private final CompositeDisposable mDisposable = new CompositeDisposable(); 
   @Override protected void onDestroy() {
            super.onDestroy();
            mDisposable.dispose();
            }

   //上传元数据
   private voiduploadData(String projectCode, TestAttachment data) {
        BridgeDataProvider bridgeDataProvider = BridgeManager2.getInstance(projectCode).getBridgeDataProvider();
        mDisposable.add(bridgeDataProvider.uploadWithAttachment(data, null, true)
        .subscribe(resp ->{
            if(resp.getSuccess()) {
                //**TODO:上传成功**
   } else{
                //**TODO：上传失败**

                }

            //**TODO:上传元数据异常**
        }));
    }
   ```

4. 登录Huawei Research平台查看上传数据 待上传成功后，登录Huawei Research平台，关联自定义元数据，创建数据表，查看数据记录。
