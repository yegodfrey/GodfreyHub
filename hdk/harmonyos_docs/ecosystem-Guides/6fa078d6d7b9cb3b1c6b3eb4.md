# 心脏瓣膜术后居家管理研究

**2021年JACC** **：以智能穿戴设备监测，将部分院内监测转院外居家监测是可行的** ^1^

传导障碍，尤其是左束支传导阻滞（LBBB），是经导管主动脉瓣置换术（TAVR）的常见并发症。华为Watch GT2 Pro ECG手表能够通过单导联心电图（ECG）对传导干扰进行长期评估，本次研究旨在研究华为智能手表对TAVR后的传导干扰评估的可行性。研究中，招募了接受TAVR的患者入组，要求患者在出院后一周内每天激活手表记录两次，并在随后的一个月内每周至少两天激活记录。所有心律失常事件通过心电图中心实验室进行评定，由院方医生进行指导。结果表明近一半的患者中在TAVR后的第一周观察到LBBB，而他们中的大多数人在随后的三周内心电图都恢复正常。验证了华为可穿戴设备能够为TAVR患者提供便捷的远程健康管理，特别是在传导障碍方面。

**2022** **年JAHA：** **智能穿戴设备助力经导管主动脉瓣置换术（TAVR）患者远程健康管理** ^2^

通过华为Watch GT2 Pro ECG手表实现便捷、长程的心电等体征监测，结合医院专业心脏团队随访，为TAVR术后出院回家的患者提供远程医疗服务，实现一种新颖的远程管理策略。

**2023** **年EHJ：以智能穿戴手表监测TAVR术后高危患者的心律失常，降低不良事件发生** ^3^

以一位72岁有高血压病史的女性患者为例，在接受经导管主动脉瓣置换术（TAVR）后，使用智能手表持续监测心电及定期随访，术后1个月心电图仍显示左束支传导阻滞（LBBB），医生团队及时关注患者心电数据，进行随访并及时干预，患者TAVR术后11个月LBBB自发恢复。智能穿戴设备可实现对高危人群的远程监测，同时为需要立即就医或住院的事件提供关键警报。
