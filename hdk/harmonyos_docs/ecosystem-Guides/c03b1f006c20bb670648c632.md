# 读取运动健康数据

* 查询运动量统计数据 查询运动量数据，请确保已在开通运动健康服务时开通"运动数据类"-"查看步数、距离、热量"权限，并在请求运动健康鉴权时请求赋予"运动量只读"权限。

  查询指定时间段内运动量统计数据，支持分页查询。查询条件结构如下：

  |参数名|数据类型|说明|必选M/可选O|
  |:--------|:----------|:-----------|:------|
  |startTime|long|查询启始时间戳（13位）|M|
  |endTime|long|查询终止时间戳（13位）|M|
  |option|QueryOption|查询选项，用于分页查询|O|
  [**表1**DataQuery（查询条件）]

  |参数名|数据类型|说明|必选M/可选O|
  |:-----|:---|:---------------|:------|
  |limit|int|分页即限制返回记录条数|O|
  |offset|int|启始记录偏移量|O|
  |order|int|排序，0默认排序（升序）,1降序|O|
  [**表2**QueryOption（查询条件分页选项）]

  查询结果SportSumData返回值类型如下表所示：

  |参数名|数据类型|说明|
  |:--------|:---|:--------------|
  |steps|int|步数，单位：步|
  |distance|int|距离，单位：米（m）|
  |calories|int|消耗卡路里，单位：卡（cal）|
  |intensity|int|中高强度时间，单位：分钟|
  [**表3**SportSumData返回值类型]

  示例代码如下：

  ```codeblock
  import com.huawei.hiresearch.common.model.sport.SportSumData; 
  import com.huawei.hiresearch.sensor.SensorManager; 
  import com.huawei.hiresearch.sensor.model.bean.query.DataQuery; 
  import com.huawei.hiresearch.sensor.provider.SportProvider; 
  import com.huawei.hiresearch.sensor.service.query.QueryOption; 
  import java.util.List; 
  import io.reactivex.disposables.CompositeDisposable; 
  private final CompositeDisposable mDisposable = new CompositeDisposable(); 
  @Override 
  protected void onDestroy() { 
      super.onDestroy(); 
      mDisposable.dispose(); 
  } 
  /** 
  * 查询运动量 
  */ 
  private void querySportSum() { 
      SportProvider sportProvider = SensorManager.getInstance().getSportProvider(); 
      //构建查询条件 
      DataQuery dataQuery = new DataQuery(); 
      //设置查询起始时间戳 
      dataQuery.setStartTime(1580721846000L); 
      //设置查询终止时间戳 
      dataQuery.setEndTime(1580894646000L); 
      //设置查询选项 
      QueryOption queryOption = new QueryOption(); 
      //设置启始查询偏移量（用于分页查询） 
      queryOption.setOffset(0); 
      //设置每次查询最多记录数 
      queryOption.setLimit(100); 
      //设置排序 0:默认升序 1：降序 
      queryOption.setOrder(0); 
      dataQuery.setOption(queryOption); 
      mDisposable.add(sportProvider.querySportSum(dataQuery) 
              .subscribe(resp -> { 
                  if (resp.getSuccess()) { 
                      //TODO:成功 
                      List<SportSumData> data = resp.getData(); 
                      if (null != data) { 
                          for (SportSumData item : data) { 
                              //当日总步数 
                              int steps = item.getSteps(); 
                              //当日运动距离 
                              int distance = item.getDistance(); 
                              //当日消耗卡路里 
                              int calories = item.getCalories(); 
                              //当日运动强度 
                              int intensity = item.getIntensity(); 
                          } 
                      } 
                  } else { 
                      //TODO:失败 
                      String code = resp.getCode(); //内部错误码 
                      String msg = resp.getMessage(); //错误信息描述 
                  } 
              }, err -> { 
                  //TODO：异常 
              }) 
      ); 
  }
  ```

* 查询单次运动数据 查询单次运动数据，请确保已在开通运动健康服务时开通"运动数据类"-"查看单次运动汇总数据"权限，并在请求运动健康鉴权时请求赋予"单次运动只读"权限。

  查询指定时间段内单次运动数据，支持分页查询。按运动模式分为：步行、骑行和跑步三种。查询接口分别为：querySingleSportWalk、querySingleSportRun和querySingleSportRide。三种模式接口调用返回值类型均相同。

  查询条件结构如下：

  |参数名|数据类型|说明|必选M/可选O|
  |:--------|:----------|:-----------|:------|
  |startTime|long|查询启始时间戳（13位）|M|
  |endTime|long|查询终止时间戳（13位）|M|
  |option|QueryOption|查询选项，用于分页查询|O|
  [**表4**DataQuery（查询条件）]

  |参数名|数据类型|说明|必选M/可选O|
  |:-----|:---|:---------------|:------|
  |limit|int|分页即限制返回记录条数|O|
  |offset|int|启始记录偏移量|O|
  |order|int|排序，0默认排序（升序）,1降序|O|
  [**表5**QueryOption（查询条件分页选项）]

  查询结果SingleSportData返回值类型如下表所示：

  |参数名|数据类型|说明|
  |:------------|:-----|:------------------------------------|
  |type|int|运动类型 * 30005：走步 * 30006：跑步 * 30007：骑行|
  |distance|int|运动距离，单位：米（m）|
  |calories|int|消耗卡路里，单位：卡（cal）|
  |totalTime|int|运动时长，单位：毫秒（ms）|
  |avgSpeed|double|平均速度，单位：千米/秒|
  |avgPace|float|平均配速，单位：秒/千米|
  |avgStepRage|int|平均步频，单位：步/分钟|
  |stepDistance|double|步幅，单位：米（m）|
  |step|int|步数，单位：步|
  |avgHeartRate|int|平均心率，单位：次/分钟|
  |totalAltitude|float|总高度，单位：分米（dm）|
  |totalDescent|float|总偏移，单位：分米（dm）|
  [**表6**SingleSportData返回值类型]

* 查询实时运动数据 查询实时运动数据，请确保已在开通运动健康服务时开通"运动数据类"-"查看实时运动数据"权限，并在请求运动健康鉴权时请求赋予"实时运动只读"权限。

  实时采集运动数据，实时运动开关成对调用，数据采集结束后需调用停止方法终止设备端实时数据采集及上报。

  查询结果SportRealtimeData返回值类型如下表所示：

  |参数名|数据类型|说明|
  |:-----------|:----|:-------------------------------------------------|
  |sportState|int|实时运动状态 * 0：开始运动 * 1：运动暂停 * 2：运动中 * 3：运动继续 * 4：运动停止|
  |distance|int|运动距离，单位：米|
  |heartRate|int|心率，单位：次/分钟|
  |speed|float|平均速度，单位：米/秒|
  |timeStamp|long|时间戳，单位：毫秒|
  |calorie|int|消耗卡路里，单位：cal|
  |totalSteps|int|总步数，单位：steps|
  |stepRate|int|步频，单位：steps/min|
  |totalCreep|int|总爬升高度，单位：m|
  |totalDescent|int|总下降高度，单位：m|
  [**表7**SportRealtimeData返回值类型]

  示例代码如下：

  ```codeblock
  import com.huawei.hiresearch.common.model.sport.realtime.SportRealtimeData; 
  import com.huawei.hiresearch.sensor.SensorManager; 
  import com.huawei.hiresearch.sensor.listener.RealTimeDataStopListener; 
  import com.huawei.hiresearch.sensor.listener.RealTimeSportDataReadListener; 
  import com.huawei.hiresearch.sensor.provider.SportProvider; 
  //开始采集实时运动数据 
  private void startRealtimeSport() { 
     SportProvider sportProvider = SensorManager.getInstance().getSportProvider(); 
     sportProvider.startRealtimeSport(new RealTimeSportDataReadListener<SportRealtimeData>() { 
         /** 
         * 实时上报 
         * @param data 
         */ 
         @Override 
         public void onRunning(SportRealtimeData data) { 
             //运动状态：0空闲，1运动中，2运动暂停，3运动停止 
             int sportState = data.getSportState(); 
             // 距离 
             int distance = data.getDistance(); 
             //跑步时长 
             int duration = data.getDuration(); 
             //心率 
             int heartRate = data.getHeartRate(); 
             //速度 
             float speed = data.getSpeed(); 
         } 
         /** 
         * 实时数据采集暂停 
         */ 
         @Override 
         public void onPause() { 
         } 
         /** 
         * 继续采集 
         */ 
         @Override 
         public void onContinue() { 
         } 
         /** 
         * 停止 
         */ 
         @Override 
         public void onStop() { 
         } 
         /** 
         * 实时数据采集异常 
         * @param code 错误码 
         * @param msg  错误信息 
         */ 
         @Override 
         public void onError(int code, String msg) { 
         } 
     }); 
  } 
  //停止实时运动数据采集 
  private void stopRealtimeSport(){ 
     SportProvider sportProvider = SensorManager.getInstance().getSportProvider(); 
     sportProvider.stopRealtimeSport(new RealTimeDataStopListener() { 
         /** 
         * 停止成功 
         */ 
         @Override 
         public void onSuccess() { 
         } 
         /** 
         * 停止异常 
         * @param errorCode 
         * @param msg 
         */ 
         @Override 
         public void onError(int errorCode, String msg) { 
         } 
     }); 
  }
  ```
