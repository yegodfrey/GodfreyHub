# 获取实时数据

* 接口说明 注册接口，接收实时返回的运动传感器数据。

> 说明
>
> 1. STAG设备需要放在脚部夹子或者腰部夹子上，才能获取到实时数据，放在充电器上也没有数据。
> 2. STAG采集磁力计原始数据，需要根据当地磁场环境，自行校正软磁、硬磁参数。

* 接口方法

```codeblock
public void registerFeatureDataCallback (finalSensorProCallback<FeatureData> callback) 
```

* 输入参数

* 示例代码

```codeblock
 
import com.huawei.hiresearch.sensorprosdk.SensorProManager; 
importcom.huawei.hiresearch.sensorprosdk.provider.callback.SensorProCallback; 
import com.huawei.hiresearch.sensorprosdk.datatype.custom.FeatureData; 
import com.huawei.hiresearch.sensorprosdk.utils.LogUtils; 
import com.alibaba.fastjson.JSON; 
 
 
SensorProManager.getInstance().getCustomProvider().registerFeatureDataCallback(new SensorProCallback<FeatureData>() {
     @Override
     public void onResponse(int errorCode, FeatureData returnObject) {
         if (returnObject != null) {
             //acc
             if (returnObject.getSensorData() != null && returnObject.getSensorData().getAccDataArray() != null) {
                 LogUtils.info(TAG, "AccData = " + JSON.toJSONString(returnObject.getSensorData().getAccDataArray()));
             }
             //gyro
             if (returnObject.getSensorData() != null && returnObject.getSensorData().getGyroDataArray() != null) {
                 LogUtils.info(TAG, "GyroData = " + JSON.toJSONString(returnObject.getSensorData().getGyroDataArray()));
             }
             //mag
             if (returnObject.getSensorData() != null && returnObject.getPostureData().getMagDataArray() != null) {
                 LogUtils.info(TAG, "MagData = " + JSON.toJSONString(returnObject.getPostureData().getMagDataArray()));
             }
             //步态
             if (returnObject.getPostureData() != null && returnObject.getPostureData().getGaitPostureDataArray() != null) {
                 LogUtils.info(TAG, "GaitPostureData = " + JSON.toJSONString(returnObject.getPostureData().getGaitPostureDataArray()));
             }
             
         }
     }
 });
 
```
