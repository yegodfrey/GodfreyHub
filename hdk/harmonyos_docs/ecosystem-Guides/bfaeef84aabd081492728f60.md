# 301医院-睡眠呼吸暂停研究

**1.简介**

301医院基于心脏健康研究APP，配合华为智能穿戴设备，发起睡眠呼吸暂停研究，实现了睡眠呼吸暂停风险便捷筛查、个性化分层分级跟踪指导、就医推荐和定制专属干预方案等睡眠健康管理服务。

**2.核心痛点**

* 检出率和知晓率低: 睡眠呼吸暂停是仅次于失眠的睡眠障碍，全国约有5000万睡眠呼吸暂停患者，但90%未被检测出来，且知晓率和主动就诊率低。


* PSG在一般人群中使用受限 多导睡眠监测（PSG）是衡量客观睡眠及诊断阻塞性睡眠呼吸暂停（OSA）的金标准，但存在操作复杂、花费昂贵、对专业人员要求高等问题，且设备本身会影响睡眠质量。


* 慢性疾病不易管理 睡眠呼吸暂停与房颤、高血压、冠心病等多种慢性心血管疾病紧密相关，具有病程长、病因复杂、健康损害等特点，但传统慢病管理存在诸多困难。

**3.解决方案**

* 持续进行科普教育： HUAWEI Research联合301医院专科医生，打造睡眠健康科普，进行宣传与教育，提高用户对睡眠呼吸暂停的认识和主动检测意识。


* 使用穿戴设备在大规模人群中进行初筛： 基于华为智能穿戴设备高性能心率传感器，在用户知情同意的前提下，智能识别睡眠、心率变异性（HRV）、心率、血氧等信息，多参数融合判断，进行睡眠呼吸暂停风险筛查。


* 分层分级进行管理： 基于HUAWEI Research，提供睡眠呼吸暂停风险分层分级的专业建议，帮助用户改善睡眠健康。

**4.合作受益**

* 301医院 深化研究方向，加速心脏与睡眠健康的创新性研究，多模态交叉融合，打造主动健康管理解决方案。


* 用户 提供睡眠呼吸暂停居家风险筛查，在家即可进行睡眠呼吸暂停风险评估；

  提供分级分层个性化睡眠健康指导建议，帮助自主管理睡眠健康。
