# 上传文件

本章节介绍如何将本地文件上传至HUAWEI Research文件管理。

如需要将本地D盘目录下的Example.xls文件上传至/Example_Dir目录下，脚本如下：

```codeblock
import com.huawei.hiresearch.client.model.files.UploadFileRequest;
import com.huawei.hiresearch.client.model.files.UploadFileResponse;
import java.io.IOException;
public class UploadFile {
    public static void main (String[] args) throws IOException {
        // 获取鉴权
        HiResearchAuth hiResearchDemo = new HiResearchAuth();
        // 获取最新accesstoken
        String accessToken = hiResearchDemo.getAccessToken();
        UploadFileRequest uploadFileRequest = new UploadFileRequest(accessToken);
        // 文件本地路径
        uploadFileRequest.setObjectPath("D:\\Example.xls");
        // 上传目标路径
        uploadFileRequest.setDestPath("\\Example_Dir\\Example.xls");
        UploadFileResponse response = hiResearchDemo.getClient().getResearchDataProvider().uploadFile(uploadFileRequest);
        System.out.println(response.getObjectKey());
    }
}
```

上传成功后，可登录HUAWEI Research的Portal平台，打开"文件"页面查看已上传文件。
