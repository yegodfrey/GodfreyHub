# 获取SDK

完成项目接入后可联系华为Research侧项目负责人或电邮：HiResearch@huawei.com，获取SDK。

下载Java SDK工具包。下载成功解压后有两个jar包可供选用：

* hiresearch-client-x.x.x.jar 不包含自身依赖
* hiresearch-client-x.x.x-with-dependencies.jar 包含所有自身依赖
