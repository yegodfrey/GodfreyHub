# 单次运动统计信息

* 接口说明 从穿戴设备上获取运动记录，根据单次运动的WorkoutId查询单次运动的统计信息。

* 接口方法

  ```codeblock
  public voidgetSingleMotionStaticMsg(intworkoutRecordId,SensorProCallback<WorkOutRecordStatistics> callback)
  ```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:--------------|:-----------------------------------------|:----------------|:------|
  |workoutRecordId|int|单次运动上手环的workoutid|M|
  |callback|SensorProCallback<WorkOutRecordStatistics>|返回单次运动统计信息|M|
  [**表1**输入参数]

* 响应参数

  |参数名|数据类型|说明|
  |:-----------|:----------------------|:-----|
  |errorCode|int|返回错误码|
  |returnObject|WorkOutRecordStatistics|运动记录数据|
  [**表2**响应参数]

  |字段名|数据类型|说明|
  |:------------------------|:---|:------------------------------|
  |workout_record_id|int|单次运动记录ID|
  |workout_status|int|单次运动状态 * 1：完成 * 2：未完成|
  |workout_start_time|int|起始时间：格林尼治时间格式|
  |workout_end_time|int|结束时间：格林尼治时间格式|
  |workout_calorie|int|卡路里，单位：千卡|
  |workout_distance|int|距离，单位：米|
  |workout_step|int|步数|
  |workout_total_time|int|总时长，单位：秒|
  |workout_speed|int|平均速度，单位：dm/s|
  |workout_climb|int|累计爬升高度：单位（分米）|
  |workout_HrABS_peak|int|心率最小、最大值|
  |workout_load_peak|int|运动负荷|
  |workout_etraining_effect|int|运动效果|
  |workout_Epoc|int|最大耗氧量|
  |workout_maxMET|int|MET|
  |workout_recovery_time|int|完全恢复时长|
  |workout_exercise_duration|int|活动时间：秒|
  |workout_date_Info|int|年月日，形式如："YYYYMMDD"|
  |workout_type|int|单次运动类型|
  |swim_type|int|主泳姿: 1：蛙泳 2：自由泳 3：蝶泳 4：仰泳 5：混合泳|
  |swim_pull_times|int|划水次数，没有则不上报，关键特性，用来判断是否支持相关特性。|
  [**表3**WorkOutRecordStatistics（单次运动的统计数据）]
