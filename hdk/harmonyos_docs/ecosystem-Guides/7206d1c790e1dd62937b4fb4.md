# APP设计

1. 登录[华为创新研究平台](https://research.cloud.huawei.com.cn/researchportal/#/login)。
2. 在左侧导航菜单中选择"**项目管理 > APP设计**"菜单，如下图所示。

   **图1**APP设计   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172611.57223771592467366405427178308236:50001231000000:2800:50D82854A7CB24B1722ED7A15C38154B44EF7AAA8855FFDC5EC6417710E232DA.png?needInitFileName=true?needInitFileName=true "点击放大")

3. 单击"**获取APP信息** "按钮，弹出授权页面，填入华为开发者联盟的用户名，密码及验证码，单击"**授权并登录**"。如下图所示。

   **图2**华为帐号登录   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172611.88814495575294819040640500291396:50001231000000:2800:8123E0A579B0176C86DA3A729BACB609C8759638021A84462B864DB782443217.png?needInitFileName=true?needInitFileName=true "点击放大")

4. 授权成功后，页面"APP名称"会显示"AppGallery Connect"所关联的应用的名称，上传APP Logo，选择"**用户基本信息** "和"**主题风格** "，单击"**下一步**"，如下图所示。

   **图3**APP基本信息   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172611.07241220045999572808538691021951:50001231000000:2800:25D79B3B790BF1263658C7810CD72358DD7FC636A5EFAED1CA1354A01CE5560E.png?needInitFileName=true?needInitFileName=true "点击放大")

5. 页面跳转至功能设计页面，配置用户协议和隐私声明的按钮，选择量表问卷和科普文章，单击"下一步"，如下图所示。

   **图4**APP功能设计   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172611.18372813189612511167706257016057:50001231000000:2800:BEBAA93D0544634264103A7B42142A1A63537F3B985E0C269D936D66498CA1B6.png?needInitFileName=true?needInitFileName=true "点击放大")

6. 单击"**生成APP**"，APP生成成功后，在页面显示二维码供用户使用华为手机浏览器扫描下载APK文件，如下图所示。
