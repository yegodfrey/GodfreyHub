# 体脂秤数据采集

体成分测量需对接体脂秤专用设备，且集成huawei-research-android-sensorpro-scale-x.x.aar。

* 体脂秤设备连接使用scale包ScaleBaseProvider进行对设备扫描和设备连接；
* 体脂秤测量使用ScaleMeasureProvider类进行体成分的数据测量。

> 注意
>
> 1. 当前可支持设备华为智能体脂秤2 Pro、体脂秤3和体脂秤3 Pro测量。
> 2. 在体脂秤扫描连接之前，需要保证APP存在蓝牙和位置权限。
