# 获取凭证

1. 打开HUAWEI Research平台Portal页面，输入用户名和密码登录成功后。
2. 鼠标移动到右上角用户名上，弹出按钮菜单，单击"帐号设置"，弹出如下弹框：

   **图1**帐号设置   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172629.00823973512457219946886931198399:50001231000000:2800:84BF45FAFEC854383620B84509FA83A36373068741B3ACBEBB7736750CD5D7A9.png?needInitFileName=true?needInitFileName=true "点击放大")

3. 单击"我的凭证"，弹出如下弹框：

   **图2**我的凭证   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172629.50486721238018482701824494410377:50001231000000:2800:A9C8F154B2D7ADC6920D62A92FDB83513FD621D5820AE1A42C4005FD10C0FE20.png?needInitFileName=true?needInitFileName=true "点击放大")

4. 点击"新增访问密钥"，如下图所示：

   **图3**新增访问密钥   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172629.12398509204504156927899254591027:50001231000000:2800:53AADCAF0D2F4AA6CFA0130C6B9372146B88A375FB00BA6388D2BA14995216E6.png?needInitFileName=true?needInitFileName=true "点击放大")

5. 请妥善保存密钥ID（accessKey）和密钥（secretKey），关闭该页面后就不能再次查看到密钥，每个用户最多可以创建2个密钥。
