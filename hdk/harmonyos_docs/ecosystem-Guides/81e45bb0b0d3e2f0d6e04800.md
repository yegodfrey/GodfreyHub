# 体温

* 接口说明 从穿戴设备上获取体温数据。请联系HUAWEI Research团队，确认您的设备是否支持此能力。若需要配置连续数据开关请参考"实时健康数据"整个章节说明。

* 接口方法

```codeblock
public void getTemperatureData(intstartTime, intendTime, @NonNull finalSensorProTransFileCallback<List<TemperatureData>> callback);
```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:--------|:---------------------------------------|:--------|:------|
  |startTime|int|获取数据的开始时间|M|
  |endTime|int|获取数据的结束时间|M|
  |callback|SensorProCallback<List<TemperatureData>>|获取体温数据|M|
  [**表1**输入参数]

  * 响应参数

    |响应方法名|参数名|数据类型|说明|
    |:---------|:-----------|:--------------------|:-------|
    |onProgress|progress|Progress|文件传输通用回调|
    |onResponse|errorCode|int|返回错误码|
    |onResponse|returnObject|List<TemperatureData>|返回结果说明|
    [**表2**响应参数]

  |字段名|数据类型|说明|
  |:-------------------|:----|:----|
  |dataStamp|int|数据时间戳|
  |skinTemperature|float|皮肤温|
  |mainBoardTemperature|float|体温|
  |ambientTemperature|float|环境温度|
  |measureStatus|float|测量状态|
  [**表3**TemperatureData (体温数据)]
