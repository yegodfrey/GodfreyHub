# 传感器数据格式数据

SensorData数据如下表所示：

|字段名|数据类型|说明|
|:------------|:------------|:----|
|ppgDataArray|PPGDataArray|PPG数据|
|gyroDataArray|GyroDataArray|陀螺仪数据|
|accDataArray|AccDataArray|ACC数据|
[**表1**SensorData]

* PPG数据：PPGDataArray

  |字段名|数据类型|说明|
  |:------------|:-----|:-----------|
  |timeStamp|long|数据采集时间戳|
  |channelConfig|byte[]|ppg通道配置信息|
  |channelLength|int|通道个数|
  |ppgAMB1Values|int[]|通道1的环境光PPG信号|
  |ppgAMB2Values|int[]|通道2的环境光PPG信号|
  |ppgAMB3Values|int[]|通道3的环境光PPG信号|
  |ppgAMB4Values|int[]|通道4的环境光PPG信号|
  |ppgG1Values|int[]|通道1绿光的PPG信号|
  |ppgG2Values|int[]|通道2绿光的PPG信号|
  |ppgIRValues|int[]|红外光PPG信号|
  |ppgRedValues|int[]|红光PPG信号|
  [**表2**PPGDataArray]

* 陀螺仪数据详情：GyroData

  |字段名|数据类型|说明|
  |:----|:---|:---|
  |gyroX|int|X轴数据|
  |gyroY|int|Y轴数据|
  |gyroZ|int|Z轴数据|
  [**表3**GyroData]

* ACC数据：AccDataArray

  |字段名|数据类型|说明|
  |:------------|:--------|:--------|
  |accConfig|int|acc配置信息|
  |channelSize|int|通道个数|
  |timeStamp|long|采集时间（时间戳）|
  |accValueArray|AccData[]|数据详情|
  [**表4**AccDataArray]

  ACC数据详情：AccData

  |字段名|数据类型|说明|
  |:---|:---|:---|
  |accX|int|X轴数据|
  |accY|int|Y轴数据|
  |accZ|int|Z轴数据|
  [**表5**AccData]
