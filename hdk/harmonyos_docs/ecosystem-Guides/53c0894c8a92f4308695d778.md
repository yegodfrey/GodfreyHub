# 获取实时健康数据

* 接口说明 开启组合数据采集后，此接口会实时从穿戴设备获取数据。


* 接口方法

  ```codeblock
  public void registerFeatureDataCallback (finalSensorProCallback<FeatureData> callback)
  ```


* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:-------|:-----------------------------|:-----------|:------|
  |callback|SensorProCallback<FeatureData>|获取组合数据后的操作结果|M|
  [**表1**输入参数]


* 响应参数

  |响应方法名|参数名|数据类型|说明|
  |:---------|:-----------|:----------|:----|
  |onResponse|errorCode|int|返回错误码|
  |onResponse|returnObject|FeatureData|混合数据|
  [**表2**响应参数]

  |字段名|数据类型|说明|
  |:--------------|:---------------|:--------------|
  |hrData|HrData|心率数据，每5s上报一个心率。|
  |realTimeRriData|RRIData|RRI数据|
  |spo2RawData|RealTimeSpo2Data|血氧数据，每秒上报一个血氧。|
  |ecgInfo|EcgInfo|心电数据|
  |sensorData|SensorData|传感器数据|
  [**表3**FeatureData（组合数据）]

  |字段名|数据类型|说明|
  |:--------|:---|:---------|
  |dataStamp|int|数据时间戳|
  |hrValue|int|心率(单位:bpm)|
  [**表4**HrData（心率信息）]

  |字段名|数据类型|说明|
  |:-------------|:-----|:------------------------------------|
  |rriTime|int|数据时间戳|
  |rriMotionState|int []|本数据测量时，穿戴设备的运动状态|
  |rriValue|int []|RR间隔,单位为ms|
  |sqiValue|int []|本数据的信号质量，0表示测量信号较差，不建议取用。100表示测量信号良好。|
  [**表5**RRIData（RRI信息）]

  |字段名|数据类型|说明|
  |:--------|:---|:----|
  |timestamp|int|数据时间戳|
  |spo2Value|int|血氧饱和度|
  [**表6**RealTimeSpo2Data（血氧信息）]

  |字段名|数据类型|说明|
  |:------------|:------------|:----|
  |ppgDataArray|PpgDataArray|ppg数据|
  |gyroDataArray|GyroDataArray|陀螺仪数据|
  |accDataArray|AccDataArray|acc数据|
  [**表7**SensorData（传感器数据）]

* 获取实时心率示例代码

  ```codeblock
  import com.huawei.hiresearch.sensorprosdk.datatype.hr.HrData;  
  import com.huawei.hiresearch.sensorprosdk.datatype.custom.SensorProUniteCollectTypeConfigure; 
  import com.huawei.hiresearch.sensorprosdk.datatype.custom.SensorProUnitePPGConfigure; 
  import com.huawei.hiresearch.sensorprosdk.provider.callback.SensorProCallback;  
    
  /**  
  *设备主动上报实时心率信息回调  
  */  
  public void registerFeatureDataCallback(final SensorProCallback<FeatureData> callback) { 
          SensorProManager.getInstance().getHealthProvider().registerFeatureDataCallback(new SensorProCallback<FeatureData>() { 
              /**
               * @param errorCode 错误码
               * @param data 返回信息
               */ 
              @Override 
              public void onResponse(int errorCode, FeatureData data) { 
                  if (errorCode == 100000 || errorCode == 0) { 
                      // TODO:上报成功回调
                      if (data != null && data.getHrData() != null) { 
                          HrData hrData = data.getHrData();
                          int dataStamp = hrData.getDataStamp();
                          int hrValue = hrData.getHrValue();
                      } 
                  } else { 
                      // TODO:上报异常回调，请查阅"错误码章节"
                  } 
  } 
  }); 
  } 
  /** 
   * 采集配置 
   * 实时采集：心率 
   * 后台采集：请与实际采集保持一致，此处以"采集RRI"做演示 
   */  
  public void startCollectCustomData() {
  SensorProUniteCollectTypeConfigure realTimeDataCollectConfigure = new SensorProUniteCollectTypeConfigure();
  realTimeDataCollectConfigure.setCollectHr (true);
  realTimeDataCollectConfigure.setParseData(true);
  SensorProUniteCollectTypeConfigure offlineDataCollectConfigure = new SensorProUniteCollectTypeConfigure();
  offlineDataCollectConfigure.setCollectRRI(true);
  offlineDataCollectConfigure.setParseData(true);
  offlineDataCollectConfigure.setStorageFile(true);
  SensorProUnitePPGConfigure ppgConfigure = new SensorProUnitePPGConfigure();

  SensorProManager.getInstance().getCustomProvider().startActiveAndOfflineCustomData (realTimeDataCollectConfigure, offlineDataCollectConfigure, ppgConfigure, new SensorProCallback<byte[]>() { 
  /**  
    * @param errorCode 错误码 
    * @param returnObject 返回信息 
    */  
  @Override 
   public void onResponse(int errorCode, byte[] returnObject) {
  ```
