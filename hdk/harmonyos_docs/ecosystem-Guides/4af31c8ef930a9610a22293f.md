# 科学睡眠

1. 打开科学睡眠监测开关
   * 接口说明 打开科学睡眠监测开关。打开开关后进入睡眠时，会进行科学睡眠监测。默认情况下，穿戴设备的科学睡眠监测开关为开启状态。

   * 接口方法

     ```codeblock
     public voidopenScientificSleepSwitch(@NonNull finalSensorProCallback<byte[]> callback)
     ```

   * 输入参数

     |字段名|数据类型|说明|必选M/可选O|
     |:-------|:------------------------------|:---|:------|
     |callback|IBaseResponseCallback< byte[] >|回调信息|M|
     [**表1**输入参数]

   * 响应参数

     |响应方法名|参数名|数据类型|说明|
     |:---------|:-----------|:-----|:-----|
     |onResponse|errorCode|int|返回错误码|
     |onResponse|returnObject|byte[]|返回结果说明|
     [**表2**响应参数]

   * 示例代码


3. 获取睡眠数据
   * 接口说明 从穿戴设备上获取睡眠原始数据后，对原始数据进行计算获取睡眠详细数据。

     建议睡眠过程中不要调用此接口，在一个完整睡眠出睡后再调用此接口。例如，次日出睡后同步昨日整夜睡眠。午休睡醒后，同步午休睡眠数据。
   * 接口方法

     ```codeblock
     public voidgetSleepDetails(UserProfile userProfile, intstartTime, intendTime, SensorProSleepDetailCallback<SleepAlgDetailData> callback)
     ```

   * 输入参数

     |字段名|数据类型|说明|必选M/可选O|
     |:----------|:-------------------------------------------------|:------------|:------|
     |startTime|Int|查询数据开始时间|M|
     |endTime|Int|查询数据结束时间|M|
     |userProfile|UserProfile|用户信息|M|
     |callback|SensorProSleepDetailCallback< SleepAlgDetailData >|获取睡眠详情和睡眠统计数据|M|
     [**表5**输入参数]

     > 注意
     >
     > startTime和endTime，建议间隔30分钟以上
   * 响应参数

     |响应方法名|参数名|数据类型|说明|
     |:---------|:-----------------|:-----------------|:---------------|
     |onProgress|progressType|int|进度类型（200：睡眠同步类型）|
     |onProgress|value|int|进度值（0-100）|
     |onResponse|errorCode|int|返回错误码|
     |onResponse|sleepAlgDetailData|SleepAlgDetailData|睡眠详情和睡眠统计数据|
     [**表6**响应参数]

     |字段名|数据类型|说明|
     |:-------------------------|:--------------------------|:------|
     |errorCode|int|错误码|
     |errCodeArr|List<AlgErrorCode>|算法计算错误码|
     |sleepAlgStatisticDataArray|List<SleepAlgStatisticData>|睡眠统计数据|
     |sleepAlgSampleDataArray|List<SleepAlgSampleData>|睡眠详情数据|
     [**表7**SleepAlgDetailData（睡眠详情和睡眠统计数据）]

     |字段名|数据类型|说明|
     |:---------------|:-----|:-----------------------|
     |goBedTime|long|上床时间|
     |startTime|long|开始时间|
     |fallAsleepTime|long|最早入睡时间|
     |wakeUpTime|long|最迟出睡时间|
     |deepSleepPartCnt|int|深睡得分|
     |sleepEfficiency|int|百分比（睡眠效率：评估的一个结果； 0~100）|
     |sleepLatency|int|睡眠潜伏期（单位：毫秒）|
     |sleepScore|int|睡眠得分1（0~100）|
     |sleepScoreOrign|int|睡眠得分2|
     |snoreFreq|int|打鼾频率（每小时多少次； 0~1000）|
     |validData|double|数据有效性|
     [**表8**SleepAlgStatisticData（睡眠统计数据）]

     |字段名|数据类型|说明|
     |:--------|:-----|:-------------------------------------|
     |startTime|long|开始时间戳|
     |endTime|long|结束时间戳|
     |Status|String|* 1：浅睡 * 2：快速眼动 * 3：深睡 * 4：清醒 * 5：零星小睡|
     [**表9**SleepAlgSampleData（睡眠详情数据）]

     |字段名|数据类型|说明|
     |:-----|:---|:-|
     |age|int|年龄|
     |gender|int|性别|
     [**表10**UserProfile（用户特征）]
