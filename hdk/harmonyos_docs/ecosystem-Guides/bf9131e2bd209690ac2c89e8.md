# 知情同意

研究APP需在用户登录前，通过《隐私声明》及《用户协议》知会相关约定，并让用户签署相关协议。HUAWEI Research平台提供用户知情同意管理能力，研究项目管理员可以在HUAWEI Research平台"研究管理"->"用户知情同意"页面中发布《隐私声明》及《用户协议》。
