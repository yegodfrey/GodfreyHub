# 下载传感器原始数据文件

1. 打开原始数据采集开关。

* 接口说明 获取原始数据，提供打开和关闭原始数据采集开关。使用时先打开采集连续数据原始数据开关，再调用接口查询并下载原始数据。

* 接口方法

  ```codeblock
  public voidstartCollectCustomData(@NonNull SensorProUniteCollectTypeConfigure collectTypeConfigure, SensorProUnitePPGConfigure ppgConfigure, @NonNull SensorProCallback<byte[]> callback) 
  ```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:-------------------|:---------------------------------|:-------|:------|
  |collectTypeConfigure|SensorProUniteCollectTypeConfigure|采集数据类型选项|M|
  |ppgConfigure|SensorProUnitePPGConfigure|ppg配置文件|M|
  |callback|SensorProCallback<**byte**[]>|返回结果|M|
  [**表1**输入参数]

* 响应参数

  |响应方法名|参数名|数据类型|说明|
  |:---------|:-----------|:-----|:----------|
  |onResponse|errorCode|int|返回错误码(成功：0)|
  |onResponse|returnObject|byte[]|返回结果说明|
  [**表2**响应参数]

* 示例代码

  ```codeblock
  import com.huawei.hiresearch.sensorprosdk.SensorProManager;
  import com.huawei.hiresearch.sensorprosdk.datatype.custom.SensorProUniteCollectTypeConfigure;
  import com.huawei.hiresearch.sensorprosdk.datatype.custom.SensorProUnitePPGConfigure;
   import com.huawei.hiresearch.sensorprosdk.provider.callback.SensorProCallback; 
   
  SensorProUniteCollectTypeConfigure offlineCollectConfigureOpenRespiration = new SensorProUniteCollectTypeConfigure();
  offlineCollectConfigureOpenRespiration.setParseData(true);
  offlineCollectConfigureOpenRespiration.setStorageFile(true);
  offlineCollectConfigureOpenRespiration.setCheckWearCollect(true);
  //offlineCollectConfigureOpenRespiration.setCollectEcg(true);  //采集ecg
  //offlineCollectConfigureOpenRespiration.setCollectGyro(true);  //采集陀螺仪
  offlineCollectConfigureOpenRespiration.setCollectAcc(true);  //采集acc
  offlineCollectConfigureOpenRespiration.setCollectPpg(true);  //采集ppg
  SensorProUnitePPGConfigure sensorProUnitePPGConfigure = new SensorProUnitePPGConfigure();
  sensorProUnitePPGConfigure.setFrequency(SensorProUnitePPGConfigure.FrequencyHZ.Frequency_100HZ);
  //sensorProUnitePPGConfigure.setFrequency(SensorProUnitePPGConfigure.FrequencyHZ.Frequency_25HZ); //根据需要选择对应频率
  sensorProUnitePPGConfigure.setLightType(SensorProUnitePPGConfigure.LightType.THREE_LIGHT_MODE);
  sensorProUnitePPGConfigure.setPpgChanel(SensorProUnitePPGConfigure.PPGChannel.FULL);
  SensorProManager.getInstance().getCustomProvider().startCollectCustomData(offlineCollectConfigureOpenRespiration, sensorProUnitePPGConfigure, new SensorProCallback<byte[]>() {
      @Override
      public void onResponse(int errorCode, byte[] returnObject) {
          //TODO:
      }
  });
  ```

3. 查询已采集文件

* 接口说明 先连接设备，然后查询当前设备侧已采集的文件。

* 接口方法

  ```codeblock
  public void readCollectFileInfo(SensorProTransFileCallback<List<CollectDataInfo>> callback)
  ```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:-------|:------------------------------------------------|:---|:------|
  |callback|SensorProTransFileCallback<List<CollectDataInfo>>|返回结果|M|
  [**表5**输入参数]

  CollectDataInfo

  |字段名|数据类型|说明|
  |:------------|:-----|:----------|
  |sinkFilePath|String|文件App侧落盘路径|
  |fileNumber|int|文件序号|
  |deviceAddress|String|设备地址|
  |fileName|String|文件名|
  |header|String|文件头header|
  |startTime|int|开始时间|
  |endTime|int|结束时间|
  |fileLen|int|文件长度|
  |readPosition|int|读取位置|
  |isFull|int|文件是否为空（0：否）|
  |fileStatus|int|文件状态|
  [**表6**CollectDataInfo]

* 响应参数

  |响应方法名|参数名|数据类型|说明|
  |:---------|:-----------|:-------|:----------|

  |onResponse|errorCode|int|返回错误码(成功：0)|
  |onResponse|returnObject|byte[]|返回结果说明|

4. 下载文件

* 接口说明 先查询设备侧已采集的文件，获得查询后的文件编号，阻塞调用下载接口，下载所有查询到的文件保存到本地。

* 接口方法

  ```codeblock
  public void downloadDataFileByNumber(int fileNumber, String filePath, String fileName, SensorProTransFileCallback<FinishCode> callback)
  ```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:---------|:-------------------------------------|:--------|:------|
  |fileNumber|int|文件编号|M|
  |filePath|String|保存到本地的路径|M|
  |fileName|String|保存到本地的文件名|M|
  |callback|SensorProTransFileCallback<FinishCode>|返回结果|M|
  [**表8**输入参数]

* 响应参数

  |响应方法名|参数名|数据类型|说明|
  |:---------|:-----------|:-------------|:------------|
  |onProgress|progress|Progress|下载进度|
  |onResponse|errorCode|int|返回错误码(下载完成：0)|
  |onResponse|returnObject|FinishCode|传输完成标记|
  |onBreak|breakinfo|BreakPointInfo|中断点信息|
  [**表9**响应参数]

* 示例代码

  ```codeblock

          //TODO:

  ```
