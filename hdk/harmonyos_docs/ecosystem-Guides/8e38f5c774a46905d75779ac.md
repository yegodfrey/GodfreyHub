# 在Intellij IDEA中安装

本章节介绍如何在IntelliJ IDEA中安装Java SDK。

1. 将解压后文件夹中的文件hiresearch-client-x.x.x-with-dependencies.jar拷贝到您的项目的libs目录中。您也可以选择不包含自身依赖的hiresearch-client-x.x.x.jar，但需要参考2.3.3手动引入依赖。

   **图1**jar包

2. 在 Intellij IDEA中选择您的工程，选择"File"->"Project Structure"打开项目配置菜单。

   **图2**Project Structure   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172626.45237561330611274726036532605361:50001231000000:2800:ABCA780069BA1594698CFD8EC7431FC1B789ACACAA1720E94244E7053921FAA8.png?needInitFileName=true?needInitFileName=true)

3. 在Modules菜单选中您的Module，单击"Dependency"选项卡并打开"JARS or directories"菜单引入jar包。
