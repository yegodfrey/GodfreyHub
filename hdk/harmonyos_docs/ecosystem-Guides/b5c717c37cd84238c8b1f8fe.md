# 南京鼓楼医院&北京协和医院&中国医疗保健国际交流促进会-血糖健康研究

**1.** **简介**

血糖健康研究项目由南京鼓楼医院、北京协和医院、中国医疗保健国际交流促进会等专业机构联合发起，通过华为穿戴高性能传感器监测到的血管弹性、睡眠心率、脉搏波等体征，实现腕间的高血糖风险评估，降低了高血糖筛查的门槛，及时识别高血糖风险并提示用户关注身体健康。

**2.** **核心痛点**

* 常规招募参与的样本少：

医院及研究机构的常规招募方式（如地推宣传等）通常只能招募到少数参与者，研究数据样本有限，导致血糖健康研究优化改进受限。

* 糖尿病疾病的知晓率和治疗率较低：

  在全球，糖尿病的患病人数高达5.37亿，这一慢性疾病在中国尤为常见，中国的糖尿病患病人数位居全球第一，糖尿病相关医疗支出位居全球第二；糖尿病前期症状不十分明显，在成人中的知晓率仅为35%，很多人在有症状就医后已确诊糖尿病I或II型且病情不可逆，错失了最佳治疗时机。如果在糖尿病早期及时知晓潜在风险并采取积极的干预措施，使治疗窗口前移，则发展为糖尿病或者损伤器官组织的风险是可控，甚至是可逆的。因此，日常生活中需要有一个高血糖风险监测、评估手段，初筛出潜在风险人群，并在确诊后及时采取干预措施，对于预防糖尿病风险和糖尿病前期人群具有极大的价值和意义。


* 自主健康管理意识待提升：

不少年轻人认为糖尿病是中老年病，和自己没多大关系，殊不知高血糖年轻化的趋势在这30年明显上涨，这与现代人高糖、高脂饮食偏多、运动偏少或者休息不充分等有关。

**3.** **解决方案**

* 开发技术助力用户招募：

  HUAWEI Research开放研究类APP开发框架，帮助南京鼓楼医院、北京协和医院、中国医疗保健国际交流促进会高效开展血糖健康研究，用户可用手机注册参与，并在用户知情同意的情况下轻松获取高价值的研究数据。
* 使用穿戴设备在大规模人群中进行初筛：

  基于华为智能穿戴设备高性能传感器，在用户知情同意的前提下，智能识别血管弹性、睡眠心率、脉搏波等信息，多参数融合判断，进行高血糖风险筛查。
* 持续输出专业科普教育：

  HUAWEI Research联合TOP专家和权威机构，定期科普血糖健康专业文章，提升用户自主健康管理意识。

**4.** **合作受益**

* 南京鼓楼医院、北京协和医院、中国医疗保健国际交流促进会

通过华为创新研究统一入口，更易招募参与者，更智能便捷地开展创新研究。

* 用户

帮助用户评估低、中、高三档高血糖风险等级，并在手表端和手机端给出相关建议，低风险建议用户继续保持健康的生活习惯，中、高风险评估结果建议用户去医院进行进一步检查。
