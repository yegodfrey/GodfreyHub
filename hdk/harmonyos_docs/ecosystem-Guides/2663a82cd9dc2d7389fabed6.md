# 单次运动实时测量

* 接口说明 关闭穿戴设备采集实时数据开关。

* 接口方法

```codeblock
public void stopCollectCustomData(@NonNull SensorProCallback<byte[]> callback)
```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:-------|:-------------------------|:--------|:------|
  |callback|SensorProCallback<byte[] >|关闭采集的操作结果|M|
  [**表1**输入参数]


* 响应参数

  |响应方法名|参数名|数据类型|说明|
  |:---------|:-----------|:-----|:-----|
  |onResponse|errorCode|int|返回错误码|
  |onResponse|returnObject|byte[]|返回结果说明|
  [**表2**响应参数]

* 示例代码

```codeblock
SensorProManager.getInstance().getCustomProvider().stopCollectCustomData(new SensorProCallback<byte[]>() {
@Override
public void onResponse(int errorCode, byte[] returnObject) {
LogUtils.info(TAG, "stop errorCode = " + errorCode);
}
});
```

单次运动实时测量包含如下接口：

1. 设置app控制或联动；
   * 接口说明 设置APP控制（APP只开启关闭单次运动）或联动（APP下发运动数据在设备侧显示）

   * 接口方法

     ```codeblock

     ```

   * 输入参数

     |字段名|数据类型|说明|必选M/可选O|

     |operateType|int|* 0：APP联动 * 1：APP控制|M|
     |callback|SensorProCallback<byte[]>|运动联动配置结果|M|
     [**表3**输入参数]

   * 响应参数

     |响应方法名|参数名|数据类型|说明|
     |:---------|:-----------|:-----|:-----|
     |onResponse|errorCode|int|返回错误码|
     |onResponse|returnObject|byte[]|返回结果说明|

2. 设置运动数据实时上报开关；
   * 接口说明 开启后，穿戴设备数据可以实时同步APP上。

   * 接口方法

     ```codeblock
     public voidnoticeRealTimeWorkOut(intswitchNoticeType);
     ```

   * 输入参数

     |字段名|数据类型|说明|必选M/可选O|
     |:---------------|:---|:-------------|:------|
     |switchNoticeType|int|开关状态 1：开启 0：关闭|M|
     [**表5**输入参数]

   * 示例代码

     ```codeblock
     importcom.huawei.hiresearch.sensorprosdk.SensorProManager;

     /**
     * 通知APP开始接受实时数据/ 开启、关闭单次运动通知APP
     *
     * **@param** **switchNoticeType** 0 关闭，1 开启
     */
     public voidnoticeRealTimeWorkOut(intswitchNoticeType) {
              SensorProManager.getInstance().getMotionProvider().noticeRealTimeWorkOut(switchNoticeType);
      }
     ```

3. 注册单次运动实时数据回调；
   * 接口说明 打开单次运动开关后，可通过此接口获取穿戴设备单次运动实时上报数据。

   * 接口方法

     ```codeblock

     ```

   * 输入参数

     |字段名|数据类型|说明|必选M/可选O|
     |:-------|:-------------------------------------|:---------|:------|
     |callback|SensorProCallback<RealTimeWorkoutData>|返回单次运动实时数据|M|
     [**表6**输入参数]

   * 响应参数

     |响应方法名|参数名|数据类型|说明|
     |:---------|:-----------|:------------------|:-------|
     |onResponse|errorCode|int|返回错误码|
     |onResponse|returnObject|RealTimeWorkoutData|单次运动实时数据|
     [**表7**响应参数]

     |字段名|数据类型|说明|
     |:--------------------|:---|:-----------------------------|
     |duration|int|数据时间戳|
     |hr|int|心率：单位：bpm|
     |hr_zone|int|最大心率区间|
     |step|int|步数, 单位：步|
     |cadence|int|步频，单位：步/分钟|
     |pace|int|配速，单位：秒/公里|
     |distance|int|距离，单位：分米|
     |calorie|int|卡路里，单位：卡|
     |total_rise|int|累计爬升 单位:dm|
     |total_descend|int|累计下降 单位:dm|
     |total_altitude|int|高度 单位:dm|
     |aerobic_te|int|有氧训练效果|
     |anaerobic_te|int|无氧训练效果|
     |performance_condition|int|效益指标|
     |time_info|int|数据产生的时间：格林尼治时间，按照从1970年1月1日秒累计|
     |operator_type|int|执行状态|
     |recovery_time|int|恢复时间，单位：分钟|

5. 运动告警（可选）。
   * 接口说明 根据设置的告警值，设备告警。

   * 接口方法

     ```codeblock
     public voidconfigHeartRateRange(HeartRateZone heartRateZone, SensorProCallback<byte[]> callback);
     ```

   * 输入参数

     |字段名|数据类型|说明|必选M/可选O|
     |:------------|:------------------|:-------|:------|
     |heartRateZone|HeartRateZone|心率各区间的定义|M|
     |callback|SensorProCallback<>|返回开启结果|M|
     [**表11**输入参数]

     |字段名|数据类型|说明|
     |:-----------------|:---|:-----------------------|
     |fitnessThreshold|int|心率区间下限 心率区间最低定义，默认98|
     |warmUpThreshold|int|热身门限 热身的上限心率门限，默认118|
     |fatBurnThreshold|int|燃脂门限 燃脂的上限心率门限，默认138|
     |aerobicThreshold|int|有氧耐力门限 有氧耐力的上限心率门限，默认158|
     |anaerobicThreshold|int|无氧耐力门限 无氧耐力的上限心率门限，默认177|
     |maximumThreshold|int|最大门限 最大心率门限，默认196|
     |HRWarnSwitch|int|告警开关|
     |HRWarnMax|int|心率告警门限，默认196|
     |HRClassifyMethod|int|划分方式： * 0：最大心率 * 1：储备心率|
     |HRMaxValue|int|最大心率值，默认196|
     |HRRestValue|int|静息心率，默认69|
     [**表12**HeartRateZone（心率区间）]

   * 响应参数

     |响应方法名|参数名|数据类型|说明|
     |:---------|:-----------|:-----|:-----|
     |onResponse|errorCode|int|返回错误码|
     |onResponse|returnObject|byte[]|返回结果说明|
     [**表13**响应参数]
