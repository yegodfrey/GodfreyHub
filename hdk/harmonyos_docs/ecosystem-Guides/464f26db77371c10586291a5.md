# 运动强度信息

* 接口说明 获取运动强度信息。

* 接口方法

  ```codeblock
  public voidgetSportIntensity(intstartTime, intendTime, finalSensorProTransFileCallback<List<Intensity>> callback)
  ```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:--------|:------------------------------------------|:------------------------------|:------|
  |startTime|int|获取数据的开始时间|M|
  |endTime|int|获取数据的结束时间|M|
  |callback|SensorProTransFileCallback<List<Intensity>>|获取状态改变的startTimeStamp、intensity|M|
  [**表1**输入参数]

* 响应参数

  |响应方法名|参数名|数据类型|说明|
  |:---------|:-----------|:--------------|:-------|
  |onProgress|progress|Progress|文件传输通用回调|
  |onResponse|errorCode|int|返回错误码|
  |onResponse|returnObject|List<Intensity>|返回结果说明|
  [**表2**响应参数]

  |字段名|数据类型|说明|
  |:-------------|:---|:---------------------|
  |startTimeStamp|int|开始时间戳|
  |intensity|int|运动强度集合： * 1：低 * 3：中高强度|
  [**表3**WearStatus(佩戴状态信息)]
