# 体成分测量

* 接口说明 由APP主动调用接口发起测量，体脂秤设备收到命令后直接启动测量流程。若有未结束的测量动作，则取消现有测量并重新开始新的测量。

  > 注意
  > * 四电极测量用时需要20秒左右，八电极测量用时需要45秒左右。
  > * 使用此接口前请先进行用户基本信息绑定，若输入的用户信息与体脂秤端绑定的信息不一致，会出现测量的体脂率结果与体成分详情数据产生偏差。
* 接口方法

  ```codeblock
  public voidmeasureSingleRealtime(UserProfileInfo userInfo,
           SensorProCallback<BodyCompositionDetailData> callback)
  ```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:-------|:-------------------------------------------|:---------------|:------|
  |userInfo|UserProfileInfo|用户基本信息|M|
  |callback|SensorProCallback<BodyCompositionDetailData>|测量数据以及计算的体成分数据回调|M|
  [**表1**输入参数]

  |字段名|数据类型|说明|必选M/可选O|
  |:-----|:-----|:---------------------|:------|
  |huid|String|主用户id，不能为null和空字符串|M|
  |uid|String|子用户id，当只使用主用户时，此字段可为空。|O|
  |height|int|身高信息，单位cm，50cm-250cm|M|
  |gender|int|性别信息，1：男，0：女|M|
  |age|int|年龄信息，18-80岁|M|
  [**表2**UserProfileInfo（用户基本信息参数）]

* 响应参数

  |响应方法名|参数名|数据类型|说明|
  |:---------|:-----------|:------------------------|:-----------|
  |onResponse|errorCode|int|返回错误码|
  |onResponse|returnObject|BodyCompositionDetailData|测量得到的体成分详情数据|
  [**表3**响应参数]

  |字段名|数据类型|说明|
  |:----------------------|:----------------------|:---------------------------------------------------------------------------------------------|
  |electrodeNumber|int|测量时使用的电极数，当使用华为智能体脂秤2 Pro进行测量时，此结果值为8，表示8电极测量，使用其他方式测量时，此值为4，表示4电极测量结果，若未赤脚测量此结果为0，无法获取到体成分数据。|
  |checkFlag8|int|此字段表示算法中使用八电极计算详细数据时是否成功，若成功则为0，否则为1。|
  |checkFlag4|int|当使用八电极算法计算不成功时校验四电极体成分结果，若成功则为0。|
  |measureData|FatMeasureData|体脂秤测量数据，主要是体重、体脂、阻抗等测量过程数据|
  |BodyComposition|BodyComposition|SDK包内集成的算法计算出的身体成分数据|
  |MuscleDetailComposition|MuscleDetailComposition|SDK包内集成的算法计算出的各躯段的肌肉详情数据|
  |FatDetailComposition|FatDetailComposition|SDK包内集成的算法计算出的各躯段的脂肪详情数据|
  |BodyLevel|BodyLevel|SDK包内集成的算法评估的身体得分等数据|
  [**表4**BodyCompositionDetailData（体成分详情数据）]
