# 心率

* 接口说明 从穿戴设备上获取心率数据。请联系HUAWEI Research团队，确认您的设备是否支持此能力。若需要配置连续数据开关请参考 "实时健康数据"整个章节说明。

* 接口方法

  ```codeblock
  public voidgetHrDataHistory(intstartTime, intendTime, @NonNull finalSensorProTransFileCallback<List<HrData>> callback);
  ```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:--------|:------------------------------|:--------|:------|
  |startTime|int|获取数据的开始时间|M|
  |endTime|int|获取数据的结束时间|M|
  |callback|SensorProCallback<List<HrData>>|获取心率数据|M|
  [**表1**输入参数]

* 响应参数

  |响应方法名|参数名|数据类型|说明|
  |:---------|:-----------|:-----------|:-------|
  |onProgress|progress|Progress|文件传输通用回调|
  |onResponse|errorCode|int|返回错误码|
  |onResponse|returnObject|List<HrData>|返回结果说明|
  [**表2**响应参数]

  |字段名|数据类型|说明|
  |:--------|:---|:----|
  |dataStamp|int|数据时间戳|
  |hrValue|int|心率值|
  [**表3**HrData(心率数据)]
