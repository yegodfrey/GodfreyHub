# 运动相关数据

* 每日运动统计数据：TodayMotionData

  |字段名|数据类型|说明|
  |:----------|:---|:-------------------------------------|
  |motion_type|int|运动类型 * 1：walk * 2：running * 3：climbing|
  |step|int|步数|
  |calorie|int|卡路里|
  |distance|int|距离|
  [**表1**TodayMotionData]

* 每日运动量详情：FitnessDetailData

  |字段名|数据类型|说明|
  |:---------|:----------------|:----------|
  |sampleList|List<SamplePoint>|每日运动量详情样本数据|
  |statusList|List<StatusPoint>|每日运动量状态数据|
  [**表2**FitnessDetailData]

* 每日运动量详情：SamplePoint

  |字段名|数据类型|说明|
  |:--------|:---|:--------------------------------------------------------------------------------------|
  |timeStamp|long|运动量样本时间，单位分钟|
  |type|int|运动量数据类型 * 1：步数数据类型 * 2：卡路里数据类型 * 3：距离数据类型 * 4：运动时长 * 5：高度数据类型 * 6：静息心率数据类型 * 7：动态心率数据类型|
  |value|int|数值|
  [**表3**SamplePoint]

* 每日运动量详情：StatusPoint

  |字段名|数据类型|说明|
  |:--------|:---|:------------------------------------------------------------------------------------------------|
  |timeStamp|long|运动量状态时间，单位分钟|
  |type|int|运动量数据类型 * 0：未指定。说明：运动类型无需指定时，使用此字段 * 1：走路 * 2：跑步 * 3：爬山 * 4：骑车 * 5：站立 * 6：浅睡 * 7：深睡 * 8：清醒 * 9：游泳|
  [**表4**StatusPoint]

* 单次运动的统计数据：WorkOutRecordStatistics

  |字段名|数据类型|说明|
  |:-----------------|:---|:--------------------|
  |workout_record_id|int|单次运动记录ID|
  |workout_status|int|单次运动状态 * 1：完成 * 2：未完成|
  |workout_start_time|int|起始时间：格林尼治时间格式|
  |workout_end_time|int|结束时间：格林尼治时间格式|
  |workout_calorie|int|卡路里，单位：千卡|
  |workout_distance|int|距离，单位：米|
  |workout_step|int|步数|
  |workout_total_time|int|总时长，单位：秒|
  |workout_speed|int|平均速度，单位：dm/s|
  |workout_climb|int|累计爬升高度：单位（分米）|
  |workout_HrABS_peak|int|心率最小、最大值|
  [**表5**WorkOutRecordStatistics]

* 单次运动的详细数据：WorkoutData

  |字段名|数据类型|说明|
  |:-------------|:----------------------|:----------------|
  |workoutId|int|单次运动记录ID|
  |timeStamp|int|采集数据开始的时间戳|
  |interval|int|采集心率、跑速、步频数据的时间间隔|
  |detailDataList|List<WorkoutDetailData>|一组数据包含多个心率，跑速、步频|
  [**表6**WorkoutData]
