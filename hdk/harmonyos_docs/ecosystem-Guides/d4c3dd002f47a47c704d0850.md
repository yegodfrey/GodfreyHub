# 初始化

本章节介绍如何初始化JAVA SDK，该步骤是使用SDK的所有API的前提。

初始化HiResearchClient类，样例代码如下：

```codeblock
import com.huawei.hiresearch.client.HiResearchClient;
import com.huawei.hiresearch.client.config.ClientConfig;
import com.huawei.hiresearch.client.config.HttpConfig;
import java.util.concurrent.TimeUnit;
public class InitClient {
    public static void main(String[] args) {
        // 初始化HttpConfig类
        HttpConfig httpConfig = new HttpConfig();
        // 设置连接超时,单位:s, 默认30s
        httpConfig.setConnectTimeout(100);
        httpConfig.setConnectTimeoutUnit(TimeUnit.SECONDS);
        // 设置读取超时,单位:s, 默认30s
        httpConfig.setReadTimeout(100);
        httpConfig.setReadTimeoutUnit(TimeUnit.SECONDS);
        // 设置写超时,单位:s, 默认30s
        httpConfig.setWriteTimeout(100);
        httpConfig.setWriteTimeoutUnit(TimeUnit.SECONDS);
        // 设置断连后自动重连,默认不重连
        httpConfig.setRetryOnConnectionFailure(true);
        // 初始化ClientConfig类
        ClientConfig clientConfig = new ClientConfig();
        //  HiResearch平台API地址
        String apiUrl = "https://hiresearch-kit.cbg-app.huawei.com";
        // HiResearch平台对应项目编码
        String projectCode = "<yourPojectCode>";
        clientConfig.setBaseUrl(apiUrl);
        clientConfig.setStudyId(projectCode);
        // 初始化HiResearchClient,其中proxyConfig为代理设置,用户可根据需要设置
        HiResearchClient hiResearchClient = new HiResearchClient(clientConfig, httpConfig, null);
    }
}
```
