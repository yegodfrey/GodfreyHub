# 开启算法

* 接口说明 打开算法开关。

* 接口方法

```codeblock
PostureDataConvertUtils.startPostureDetection(int freq, int cpFusionMode);
 
```

* 输入参数

|字段名|数据类型|说明|必选M/可选O|
|:-----------|:---|:-----------------------------------------------------------|:------|
|freq|int|频率；范围[100，200] 100：100hz；200：200hz|M|
|cpFusionMode|int|融合模式；范围[0，1，2] 0：只采集陀螺仪数据； 1：采集ACC+陀螺仪数据； 2：采集ACC+陀螺仪+MAG数据。|M|
[**表1**输入参数]

* 示例代码

```codeblock
PostureDataConvertUtils.startPostureDetection(freq, cpFusionMode); 
 
```
