# 创建数据表

本章节介绍如何使用Python SDK创建数据表。

用户可使用Python SDK创建数据表用来存储分析数据或分析结果。

举例：创建数据表存储用户基本信息表，表名为user_baseinfo。表字段信息如下：

|字段名|数据类型|说明|
|:------------|:------|:---------|
|user_number|String|用户编号|
|age|Integer|年龄|
|sex|Integer|性别，0：女；1：男|
|province|String|省份|
|city|String|城市|
|register_time|String|注册时间|
[**表1**user_baseinfo]

样例代码如下：

```codeblock
from hiresearchsdk import BridgeClient
from hiresearchsdk.config import BridgeConfig, HttpClientConfig
from hiresearchsdk.model import ProjectMemberSignInRequest
from hiresearchsdk.model.table import CreateTableRequest, TableField
# 初始化BridgeConfig类
bridgeconfig = BridgeConfig("<yourPojectCode>", "product")
# 连接超时时间，单位s，不设置则默认30s
connect_timeout = 20
# 等待接口返回超时时间，单位s，不设置则默认30s
read_timeout = 20
# 是否失败重试，默认不重试
retry_on_fail = True
# 初始化HttpClientConfig类
httpconfig = HttpClientConfig(connect_timeout, read_timeout, retry_on_fail)
bridgeclient = BridgeClient(bridgeconfig, httpconfig)
# 获取SDK鉴权
request = AuthRequest("<yourAccessKey>", "<yourSecretKey>")
authResponse = bridgeclient.get_authenticate_provider().auth(request)
accessToken = authResponse.get_accessToken()
accessTokenDurationInMillis = authResponse.get_accessTokenDurationInMillis()
refreshToken =  authResponse.get_refreshToken()
refreshTokenDurationInMillis = authResponse.get_refreshTokenDurationInMillis()
# 拼接数据表字段，TableField.TYPE_STRING字段数据类型
fields = list()
fields.append(TableField("user_number", TableField.TYPE_STRING, "用户编码"))
fields.append(TableField("age", TableField.TYPE_BIGINT, "年龄"))
fields.append(TableField("sex", TableField.TYPE_BIGINT, "性别，0：女；1：男"))
fields.append(TableField("province", TableField.TYPE_STRING, "省份"))
fields.append(TableField("city", TableField.TYPE_STRING, "城市"))
fields.append(TableField("register_time", TableField.TYPE_STRING, "注册时间"))
# 构造创建表请求
req = CreateTableRequest(accessToken, "user_baseinfo", "用户基本信息", fields)
# 创建表
result = bridgeclient.get_bridgedata_provider().create_study_table(req)
# 获取表的Table ID
print(result.get_table_id())
```

> 说明
>
> 系统会给SDK创建的表自动添加一个字段"uniqueid"作为主键。当使用脚本写入数据时可不传入该字段值，系统会自动生成UUID作为"uniqueid"字段值，写入数据表。
