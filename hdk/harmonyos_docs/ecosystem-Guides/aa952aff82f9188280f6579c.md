# 实时健康数据

实时数据是指测量过程中实时采集并上报的数据。当前支持心率、血氧、RRI、ACC、PPG、GYRO 、ECG传感器、单次运动的实时测量。

* 实时心率、血氧、RRI、ACC、PPG、GYRO、ECG传感器的测量数据的获取方法如下：
  1. 先正确佩戴设备，连接设备后；
  2. 注册对应数据的上报回调，调用"开启运动健康数据实时测量"接口开启测量；
  3. 在对应回调中获取、上传实时数据。
  4. 测量完毕后，调用"关闭运动健康数据实时测量"接口。
* 单次运动实时测量：
  1. 设置app控制或联动；
  2. 设置运动数据实时上报开关；
  3. 注册单次运动实时数据回调；
  4. 开启、关闭单次运动；
  5. 运动告警（可选）。

> 注意
>
> * 除实时运动测量，实时数据不会保留在设备侧，如果不进行实时接收和存储，将无法再次获取此时段数据。
> * 开始实时上报测量结束之后需要调用关闭接口进行关闭，否则穿戴设备会一直进行数据测量。
> * 开启测量前，请保持足够电量（20%以上），并正确佩戴设备，具体佩戴方式请参见设备说明。
> * 同步数据时，不要开启主动测量。
> * 开启主动测量前，需先关闭其他主动测量。
