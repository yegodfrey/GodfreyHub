# RRI

* 接口说明 从运动设备上获取RRI历史数据。请联系HUAWEI Research团队，确认您的设备是否支持此能力。若需要配置连续数据开关请参考 "实时健康数据"整个章节说明。

* 接口方法

  ```codeblock
  public voidgetRriDataHistory(intstartTime, intendTime, finalSensorProTransFileCallback<List<RriDataArray>> callback);
  ```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:--------|:------------------------------------|:--------|:------|
  |startTime|int|获取数据的开始时间|M|
  |endTime|int|获取数据的结束时间|M|
  |callback|SensorProCallback<List<RriDataArray>>|返回RRI数据数组|M|
  [**表1**输入参数]

* 响应参数

  |响应方法名|参数名|数据类型|说明|
  |:---------|:-----------|:-----------------|:-------|
  |onProgress|progress|Progress|文件传输通用回调|
  |onResponse|errorCode|int|返回错误码|
  |onResponse|returnObject|List<RriDataArray>|返回结果说明|
  [**表2**响应参数]

  |字段名|数据类型|说明|
  |:----------------|:-----------------|:----------------------------|
  |timeStamp|long|数据时间戳|
  |length|int|数据长度|
  |motionStateNumber|int|运动状态编号|
  |ppgStateNumber|int|Ppg状态编号|
  |rriData|List<RriDataPoint>|Rri数据集合|
  |motionState|List<Integer>|一分钟内每一秒钟的运动状态，越高运动状态越强|
  |ppgState|List<Integer>|一分钟内每一秒钟的信号质量，范围是0-2，越高信号质量越强|
  [**表3**RriDataArray(RRI数组)]
