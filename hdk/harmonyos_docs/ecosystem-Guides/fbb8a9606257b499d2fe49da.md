# 调查问卷结果上云

调查问卷作答后，将问卷中所有答案上传至HUAWEI Research云端。

问题答案结构如下：

|参数名|数据类型|说明|必选M/可选O|
|:--------------|:---------|:-------------------------------------------|:------|
|questionnaireId|String|调查问卷ID|M|
|questionId|String|单道问题ID|M|
|questiontype|String|问题类型 * 00：单选 * 01：多选 * 02：问答 * 03：排序 * 04：打分|M|
|createTime|String|创建时间|O|
|answer|AnswerInfo|问题答案|M|
[**表1**QuestionResult]

|参数名|数据类型|说明|必选M/可选O|
|:------|:---------------|:----|:------|
|content|String|问答题答案|O|
|choices|List<ChoiceInfo>|选择题答案|O|
[**表2**AnswerInfo]

|参数名|数据类型|说明|必选M/可选O|
|:----|:-----|:-----|:------|
|key|String|选择答案键值|M|
|value|String|选择答案内容|O|
[**表3**content]

示例代码如下：

```codeblock
import com.huawei.hiresearch.bridge.model.bridge.QuestionResult; 
import com.huawei.hiresearch.research.ResearchManager2; 
import com.huawei.hiresearch.research.provider.QuestionnaireProvider; 
import java.util.List; 
import io.reactivex.disposables.CompositeDisposable; 
private final CompositeDisposable mDisposable = new CompositeDisposable(); 
@Override 
protected void onDestroy() { 
   super.onDestroy(); 
   mDisposable.dispose(); 
} 
/** 
* 上传问卷答案 
* @param projectCode  申请研究项目时所获取的项目编码 
* @param questionResults 问卷答案 
*/ 
private void putQuestionnaireResults(String projectCode, List<QuestionResult> questionResults) { 
   QuestionnaireProvider questionnaireProvider = ResearchManager2.getInstance(projectCode).getQuestionnaireProvider(); 
   mDisposable.add(questionnaireProvider.putQuestionnaireResults(questionResults) 
           .subscribe(resp -> { 
               if (resp.getSuccess()) { 
                   //TODO:上传问卷答案成功 
               } else { 
                   //TODO：上传问卷答案失败 
                   int statusCode = resp.getStatusCode(); //HTTP状态码 
                   String code = resp.getCode(); //内部错误码 
                   String msg = resp.getMessage(); //错误信息描述 
               } 
           }, err -> { 
               //TODO:上传问卷答案异常 
           })); 
}
```
