# 接入指南

**擎云生态合作接入指南**

【擎云生态合作】

报名时间：2020.05.01-2021.12.31

【擎云生态合作的目标和愿景】

与生态合作伙伴，共同打造擎云生态体系, 在未来信息技术领域的发展路径上形成话语权和优势。

【我们寻找的合作伙伴】

1. 伙伴能够提供自主知识产权的软件包/驱动或原型机等。

2. 伙伴拥有自主研发能力及售后服务能力。

3. 伙伴具有一定的资产规模，财务状况良好。

【合作伙伴申请流程】

1. 步骤一：提交申请

提交相关产品和合作伙伴资料。

2. 步骤二：初步审核

对合作伙伴的资质和产品竞争力初步评估和审核。

3. 步骤三：NDA签署

4. 步骤四：样机发放

测试样机和测试环境的申请与发放。

5. 步骤五：测试验收

7. 步骤七：网站公示

【擎云生态邮箱】

qingyun@huawei.com

【常见问题】

[问题一]什么样的伙伴能和擎云生态合作？

1. 认可擎云生态合作模式和价值观。

2. 伙伴拥有自主研发能力和自主品牌的售后服务能力。

[问题二]怎么样申请测试样机？

按照合作伙伴申请流程，审核通过后华为终端即向合作方发放测试样机。

[问题三]产品如何推荐给擎云生态？

1. 请将贵公司简介及产品详细资料发送邮件到 qingyun@huawei.com

2. 请确保企业信息真实有效，产品无侵权、违法、违规等情形。
