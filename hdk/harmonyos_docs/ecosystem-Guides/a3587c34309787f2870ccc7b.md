# 聚合查询

本章节介绍如何使用聚合查询对研究数据表进行简单分析统计，如求最小值、最大值、均值等。

SearchTableDataRequest请求参数释义如下表所示：

|参数名|数据类型|说明|必选M/可选O|
|:--------------|:--------------------|:----------------------------------------|:------|
|sessionToken|String|鉴权获取到的sessionToken。|M|
|tableId|String|查询表的Table ID。可在数据表列表页面中查看到相应数据表的Table ID。|M|
|filters|List<FilterCondition>|过滤器列表|O|
|aggregationInfo|Aggregation|聚合查询信息|M|
[**表1**SearchTableDataRequest请求参数]

支持的聚合类型如下表所示：

|AggType|说明|
|:------|:--|
|MAX|最大值|
|MIN|最小值|
|AVERAGE|平均值|
|SUM|和|
[**表2**聚合类型]
