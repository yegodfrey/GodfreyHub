# 业务介绍

**擎云生态合作业务介绍**

擎云生态合作是基于华为擎云系列桌面终端推出的生态适配计划，旨在丰富与完善桌面终端的应用生态，涵盖办公、设计、学习等场景，诚邀三方软件和外设厂商参与。

1. 目标与愿景/Positioning

与生态合作伙伴，共同打造擎云生态体系，在未来信息技术领域的发展路径上形成话语权和优势。

2. 生态优势/Benefits

(1) 拥有核心技术： 完全自主的核心技术能够为更多的用户提供坚实的技术支撑。

(2) 庞大的客户群体：拥有全球各地庞大的客户群体，为合作伙伴产品的研发/设计/销售赋能，多方面快速提升伙伴的产品知名度与客户体验。

(3) 品牌加持与曝光：针对生态产品，有华为品牌加持，助力合作伙伴品牌声量提升。

3. 我们寻找的合作伙伴/partners

(1) 伙伴能够提供自主知识产权的软件包/驱动或原型机等。

(2) 伙伴拥有自主研发能力及售后服务能力。

(3) 伙伴具有一定的资产规模，财务状况良好。
