# 创建应用

1. 先使用华为账号登录[开发者联盟账号中心](https://id1.cloud.huawei.com/AMW/portal/userCenter/index.html?service=https://developer.huawei.com/consumer/cn/#/security)，确定华为账号是否已绑定邮箱。

   **图1**登录华为账号   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172609.14690105775748144369682258327958:50001231000000:2800:8813AD602404AC27FFCE17376EF8469662FF7D6AB584BA94C4866416239588CD.png?needInitFileName=true?needInitFileName=true "点击放大")

   登录后，如下图中标红位置，如果提示未绑定邮箱，请先绑定邮箱，如果已绑定邮箱，请继续下一步。

   **注意：** 建议绑定**华为邮箱**。如果绑定时，提示华为邮箱被其他账号绑定，建议您退出当前账号，使用华为邮箱登录，如果忘记密码，可以使用页面上"忘记密码"链接找回密码。

   **图2**绑定华为邮箱   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172609.49647952754546228028907826553366:50001231000000:2800:5F3B20C27CD36605A08F20981F8397A1328574918E525717CC50D4F26D97EB6C.png?needInitFileName=true?needInitFileName=true "点击放大")

2. 登录[开发者联盟](https://developer.huawei.com/consumer/cn/)，点击"**管理中心**"

   **图3**进入管理中心   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172609.30523335678656060638920663799442:50001231000000:2800:057A5891FF60E805EEC6F406B42AA6E21F2ED9D7420115D7A0C7D9B51525BE3B.png?needInitFileName=true?needInitFileName=true "点击放大")

3. 点击"**生态服务** "->"**应用服务** "->"**AppGallery Connect**"

   **图4**进入AppGallery Connect   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172609.08492336737893331059126805532723:50001231000000:2800:EAD581FFEF92FCFB942CDEF7D835C0B487643B7E02DAD4B55ECD1CED7FC80287.png?needInitFileName=true?needInitFileName=true "点击放大")

4. 点击"**我的应用**"

   **图5**进入我的应用   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172609.36307912269135639743853112795121:50001231000000:2800:F9E203CA4C5296B5FDA511258DCDB4152770AECB637D475636024354D7A03AF0.png?needInitFileName=true?needInitFileName=true "点击放大")

5. 点击"**新建** "按钮，填写应用名称、应用包名、应用分类、选择默认语言，勾选"**添加到项目** "，完成后点击"**确定**"，进入应用信息页面。

   **图6**点击新建   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172609.83678241864769145694319699509453:50001231000000:2800:7DE95A25AF3FA98C31017BD137A50209BF43AB59A85BE8353D4858A6C68780BE.png?needInitFileName=true?needInitFileName=true "点击放大")

   **图7**创建应用   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172609.46909205191086664594804554488405:50001231000000:2800:ACD5229222D8DD80B71CA77D4AB6CBC11775ABA92C12C3B6F74C5B352678D96E.png?needInitFileName=true?needInitFileName=true "点击放大")

   在"**我的应用** "切换到"**我的项目**"

   **图8**切换我的项目   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172609.70193323776394647705287656921331:50001231000000:2800:E0DD889ABF933271ECE53795F05C8950E0CA622BF962E978FA554B29606A4E4C.png?needInitFileName=true?needInitFileName=true "点击放大")

   弹出一个提示框，点击"**确定**"

   **图9**点击确定   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172609.78367925514241753791278852001129:50001231000000:2800:68D1567280C8E84891AD861AFDF722BA16E888A3173116F8241C06E2E841D620.png?needInitFileName=true?needInitFileName=true)

   手动输入包名，格式如：com.xxxxcompany(机构名称).heartstudy(项目名称)

   **图10**手工输入包名   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172610.09708833329688400137491007909040:50001231000000:2800:8DF142CE6760F71FF55E04EFEEBAE2FB1A5E3CBF0197274B45015D08DE68115E.png?needInitFileName=true?needInitFileName=true "点击放大")

6. 完成创建应用之后，保存**APP ID** 、**APP Secret** 、**应用包名** 、**Agconnect文件**几项信息。

   **图11**开发者联盟应用信息   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172610.10582123159566882218482934717768:50001231000000:2800:F5039C307582FA0557527915FB9C2C710207B15C20991D22198A1643E06425CA.png?needInitFileName=true?needInitFileName=true "点击放大")

7. 登录[华为创新研究平台](https://research.cloud.huawei.com.cn/researchportal/#/login)，点击华为账号登录。

   **图12**登录创新研究平台   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172610.12910173149055599703074198753063:50001231000000:2800:0149F235782122E8B26892C816324B8BE0196567D57F71E4A86F477803DFEBF6.png?needInitFileName=true?needInitFileName=true "点击放大")

   **注意：** 登录时一定要勾选，**获取您的邮件地址** 复选框。

   **图13**获取邮件地址   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172610.96051733043658334685017646708536:50001231000000:2800:BDA1D12B43B7CADC787DF4BE3762A7ADBB6DFC6BA28608EDA8553ADAC23A9B61.png?needInitFileName=true?needInitFileName=true "点击放大")

8. 登录成功后，项目列表为空白，将您华为账号绑定的邮箱地址及需要加入的项目名称，发送给项目管理员【即开发者联盟上申请该项目的人员】。项目管理员会将您的账号，添加到相应的项目中，添加成功后，再刷新研究分析平台页面就可以看到对应项目。

   **图14**加入研究项目   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172610.49005238701187837601039968642792:50001231000000:2800:67C21A1EF79D6DB3403F9EF3017BFABC97848C04EE34A8AE07DF93454C74E0F6.png?needInitFileName=true?needInitFileName=true "点击放大")

9. 进入项目后，在使用自动生成app模块之前，项目管理员需要自行在项目配置模块里设置**APP ID** 、**APP Secret** 、**应用包名** 、**Agconnect文件**；这几项信息在开发者联盟应用创建之后生成，将应用的信息复制粘贴到Huaweiresearch平台添加保存即可。

   **注：** **app secret** **保存后会为空显示，所以如果后续需要再次修改其他字段，都需要重新填写** **app secret**

   **图15**项目配置信息
