# 中科院心理研究所-情绪识别研究

**1.简介**

中国科学院心理研究所基于HUAWEI Research构建情绪研究APP，借助华为穿戴设备，获取连续的心率间隔（RRI）及运动、睡眠数据，实现N种情绪的精细化识别。

**2.核心痛点**

* 常规招募的样本量少 研究机构传统招募形式（如院内宣传等）招募到的参与者往往人数有限，研究样本量少，从而降低研究结果的意义。


* 难以获取到传感器数据 常规情绪研究通常只能得到结果数据，难以获取传感器数据，导致研究深度和综合度受限。


* 无法24小时连续监测情绪状态 人的情绪具有丰富性、蔓延性、不稳定性等特点，易受现实情境、生物周期、认知判断等影响，传统情绪检测和识别技术无法24小时连续监测参与者情绪状态，了解情绪的发展过程。

**3.解决方案**

* APP开发框架助力用户招募： HUAWEI Research开放研究类APP开发框架，帮助中科院心理研究所构建情绪研究APP，用户可用手机注册参与，并在其知情同意的情况下轻松获取高价值的研究数据


* 开放传感器能力： 在用户隐私授权前提下，HUAWEI Research开放华为终端设备上心率间隔（RRI）及运动、睡眠数据等信息，为基于数据的情绪识别提供有力支撑。


* 智能终端居家便携24小时测量： 通过华为智能穿戴设备，可随时随地自动测量情绪状态，实时了解参与者的情绪变化。

**4.合作受益**

* 中国科学院心理研究所 佩戴手环无感采集研究数据，更易招募参与者。

  获取24小时传感器数据，捕捉动态变化情况，加速创新性研究。


* 用户 提供N种情绪的精细化识别，帮助了解自我情绪状态，自主调节情绪和进行心理健康管理。
