# 南方医科大学南方医院-儿童步态异常研究

**1.简介**

南方医科大学南方医院基于HUAWEI Research开展儿童步态异常研究，借助华为穿戴设备，检测儿童异常步态，实现包括儿童足病筛查、异常报警、问卷评估、康复建议和跟踪管理的儿童步态异常闭环解决方案。

**2.核心痛点**

* 常规招募参与人数少： 医院常规招募方式（如院内宣传等）通常只能招募到少数参与者，研究数据样本有限，降低了研究结果的意义。


* 数据采集限制多，儿童适应能力有限: 步态研究进行数据采集时通常在特定空间进行，并需参与者在跑步机等设备上行走，而儿童对新的环境多有陌生感，接触跑台不多，且不同年龄的儿童适应能力不同，易导致数据出现偏差。


* 步态数据分析和识别操作复杂: 传统步态检测需在图象序列中将人体步态轮廓提取出来，再进行特征提取、建立数据库或进行步态识别等，操作较为复杂。

**3.解决方案**

* 开发技术助力用户招募： HUAWEI Research开放研究类APP开发框架，帮助南方科技大学南方医院高效开展研究，用手机注册即可参与。


* 穿戴设备实时监测异常步态： HUAWEI Research开放传感器能力，在用户知情同意下提供步态参数监测，可实时采集儿童步态数据，助力南方医院开展儿童步态异常研究，临床诊断儿童足病，形成儿童足病数据库。


* 儿童足病筛查与评估： 南方医院基于HUAWEI Research和儿童足病数据库开展研究，结合华为穿戴监测的日常步态参数和问卷量表，设计儿童足病筛查与评估机制，依据设备筛查和医生诊断结果，推荐针对性康复干预方案。

**4.合作受益**

* 南方医院 便于招募儿童受试者，解决儿童日常步态异常检测难题，形成儿童足病数据库。

  结合华为穿戴监测能力和问卷量表，研究儿童足病筛查与评估机制，为更早介入干预提供便利条件，服务更多患者。


* 用户 借助华为穿戴设备，及时实现儿童异常步态检测并进行足病筛查，尽早就医诊治，实现对病情的控制或逆转。
