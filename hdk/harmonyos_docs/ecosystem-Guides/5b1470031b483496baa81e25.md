# 运动健康数据上云

HUAWEI Research支持将获取到的运动健康数据直接上云。

Android SDK获取运动健康数据项与HUAWEI Research研究分析平台的元数据映射关系如下表所示：

|数据项|||AndroidSDK数据项|元数据|
|:--|-------|------------|:--------------------|:-------------------------|
|运动类|运动量统计数据|以"天"为周期的统计数据|SportSumData|DailyWorkout|
|运动类|单次运动数据|以"次"为维度的统计数据|SingleSportData|SingleWorkout|
|运动类|实时运动数据|实时数据|SportRealtimeData|SingleWorkoutProcessDetail|
|健康类|睡眠数据|以"天"为周期的统计数据|SleepData|SleepEpisode|
|健康类|体成分数据|以"次"为维度的统计数据|BodyCompositionData|BodyComposition|
|健康类|实时RRI数据|实时数据|RRIRealTimeData|RRI|
|健康类|实时心率数据|实时数据|HeartRateRealTimeData|HeartRate|
|健康类|心率统计数据|以"天"为周期的统计数据|HeartRateData|DailyHeartRate|
|健康类|血压数据|需接入专业设备|BloodPressureData|BloodPressure|
|健康类|血糖数据|需接入专业设备|BloodSugarData|BloodGlucose|
|健康类|血氧数据|以"天"为周期的统计数据|Spo2Data|DailyBloodOxygenSaturation|
[**表1**运动健康数据]

以获取到的睡眠数据（SleepData）为例，上云的示例代码如下：

```codeblock
import com.huawei.hiresearch.bridge.BridgeManager2; 
import com.huawei.hiresearch.bridge.listeners.OnMetadataUploadProgressChanged; 
import com.huawei.hiresearch.bridge.model.dataupload.BinaryProgressStatus; 
import com.huawei.hiresearch.bridge.model.dataupload.MetadataCompressResultInfo; 
import com.huawei.hiresearch.bridge.provider.BridgeDataProvider; 
import com.huawei.hiresearch.common.model.base.SensorData; 
import java.util.List; 
import io.reactivex.disposables.CompositeDisposable; 
import com.huawei.hiresearch.common.model.health.SleepData; 
private final CompositeDisposable mDisposable = new CompositeDisposable(); 
@Override 
protected void onDestroy() { 
   super.onDestroy(); 
   mDisposable.dispose(); 
} 
// sleepDataList:参考3.5小节"获取运动健康数据"，获取到的睡眠数据列表，List<SleepData>
uploadData("your projectCode", sleepDataList); 
//上传标准化运动健康数据 
private <T extends SensorData> void uploadData(String projectCode, List<T > data) { 
   BridgeDataProvider bridgeDataProvider = BridgeManager2.getInstance(projectCode).getBridgeDataProvider(); 
   mDisposable.add(bridgeDataProvider.uploadSportHealth(data, new OnMetadataUploadProgressChanged() { 
       @Override 
       public void onCompressProgress(BinaryProgressStatus status) { 
           //TODO：压缩进度 
           //总进度值 
           int maxValue = status.getMaxValue(); 
           //当前进度值 
           int currentValue =status.getCurrentValue(); 
       } 
       @Override 
       public void onCompressComplete(MetadataCompressResultInfo compressResp) { 
           //TODO：压缩完成 
       } 
       @Override 
       public void onUploadProgress(BinaryProgressStatus status) { 
           //TODO：标准化运动健康数据上传进度 
           //总进度值 
           int maxValue = status.getMaxValue(); 
           //当前进度值 
           int currentValue =status.getCurrentValue(); 
       } 
   }).subscribe(resp -> { 
       if (resp.getSuccess()) { 
           //TODO:上传成功 
       } else { 
           //TODO：上传失败 
           int statusCode = resp.getStatusCode(); //HTTP状态码 
           String code = resp.getCode(); //内部错误码 
           String msg = resp.getMessage(); //错误信息描述 
       } 
   }, err -> { 
       //TODO:上传标准化运动健康数据异常 
   })); 
}
```
