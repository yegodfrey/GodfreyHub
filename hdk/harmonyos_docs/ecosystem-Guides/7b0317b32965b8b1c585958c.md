# 开启实时测量

* 接口说明 打开开关，开始测量。

* 接口方法

```codeblock
 public void startNewActiveAndOfflineCustomData(@NonNull SensorProUniteCollectTypeConfigure activeCollectTypeConfigure,
                                             @NonNull SensorProUniteCollectTypeConfigure offlineCollectTypeConfigure,
                                             SensorProUniteConfigure configure,
                                             @NonNull SensorProCallback<byte[]> callback) 
```

* 输入参数

|字段名|数据类型|说明|必选M/可选O|
|:---------------------------|:---------------------------------|:---------|:------|
|realtimeCollectTypeConfigure|SensorProUniteCollectTypeConfigure|实时测量开关控制配置|M|
|offlineCollectTypeConfigure|SensorProUniteCollectTypeConfigure|连续采集开关控制配置|M|
|configure|SensorProUniteConfigure|特殊采集配置|O|
|callback|SensorProCallback< byte[]>|开关结果|M|
[**表1**输入参数]

|字段名|数据类型|说明|
|:---------------------------------|:---------------------------------------------------------------------|:------------------------------------------------------------------------------------------------|
|SensorProUniteCollectTypeConfigure|public SensorProUniteCollectTypeConfigure setStorageFile(boolean var1)|设置此接口配置的采集数据项的数据采集模式。 * true：数据后台采集模式，即数据保存在设备侧，不进行实时上报； * false（默认值）：数据实时采集模式，即数据不保存在设备侧，进行实时上报。|
|SensorProUniteCollectTypeConfigure|public void setRealtimeMesureTimeOut(long var1)|仅在实时测量模式下生效。设置实时测量的持续时长。建议单次实时测量时长控制在5分钟内。|
|SensorProUniteCollectTypeConfigure|public SensorProUniteCollectTypeConfigure setCollectGyro(boolean var1)|设置是否采集陀螺仪数据。 * true：采集该项数据； * false（默认值）：不采集该项数据。|
|SensorProUniteCollectTypeConfigure|public SensorProUniteCollectTypeConfigure setCollectEcg(boolean var1)|设置是否采集ECG数据。 * true：采集该项数据； * false（默认值）：不采集该项数据。 > 说明 > 请确保您的设备支持ECG采集，设备型号及测量方法请参见华为穿戴设备官网说明。|
|SensorProUniteCollectTypeConfigure|public SensorProUniteCollectTypeConfigure setCollectPpg(boolean var1)|设置是否采集PPG数据。 * true：采集该项数据； * false（默认值）：不采集该项数据。|
|SensorProUniteCollectTypeConfigure|public SensorProUniteCollectTypeConfigure setCollectHr(boolean var1)|设置是否采集心率数据。 * true：采集该项数据； * false（默认值）：不采集该项数据。|
|SensorProUniteCollectTypeConfigure|public SensorProUniteCollectTypeConfigure setCollectSpo2(boolean var1)|设置是否采集血氧数据。 * true：采集该项数据； * false（默认值）：不采集该项数据。 > 说明 > 建议避免在运动状态开启血氧测量。|
|SensorProUniteCollectTypeConfigure|public SensorProUniteCollectTypeConfigure setCollectAcc(boolean var1)|设置是否采集ACC数据。 * true：采集该项数据； * false（默认值）：不采集该项数据。|
|SensorProUniteCollectTypeConfigure|public SensorProUniteCollectTypeConfigure setCollectRRI(boolean var1)|设置是否采集RRI数据。 * true：采集该项数据； * false（默认值）：不采集该项数据。|
|SensorProUniteCollectTypeConfigure|public SensorProUniteCollectTypeConfigure setParseData (boolean var1)|设置成true。|
|SensorProUniteCollectTypeConfigure|public void setCollectMag(boolean collectMag)|设置是否采集磁力计数据。 * true：采集该项数据； * false（默认值）：不采集该项数据。|
|SensorProUniteCollectTypeConfigure|public void setCollectGaitPosture(boolean collectGaitPosture)|设置是否采集姿态角数据。 * true：采集该项数据； * false（默认值）：不采集该项数据。|
|SensorProUniteCollectTypeConfigure|public void setCheckWearCollect(boolean checkWearCollect)|设置是否检查穿戴采集(采集姿态角时必须配置)。 * true：配置采集； * false（默认值）：不配置采集。|

* 示例代码

```codeblock
 
SensorProUniteCollectTypeConfigure activeCollectTypeConfigure = new SensorProUniteCollectTypeConfigure(); 
                activeCollectTypeConfigure.setParseData(true); 
                activeCollectTypeConfigure.setRriInterval(10); 
                activeCollectTypeConfigure.setRealtimeMesureTimeOut(10 * 60 * 1000); 
                activeCollectTypeConfigure.setCollectAcc(true); 
                activeCollectTypeConfigure.setCollectGyro(true); 
                activeCollectTypeConfigure.setCollectMag(true); 
                activeCollectTypeConfigure.setCollectGaitPosture(true); 
                activeCollectTypeConfigure.setCheckWearCollect(true); 
                SensorProUniteCollectTypeConfigure offlineCollectTypeConfigure = new SensorProUniteCollectTypeConfigure(); 
                SensorProUniteConfigure togetherConfig = new SensorProUniteConfigure(); 
                SensorProUnitePPGConfigure sensorProUnitePPGConfigure1 = new SensorProUnitePPGConfigure(); 
                sensorProUnitePPGConfigure1.setFrequency(SensorProUnitePPGConfigure.FrequencyHZ.Frequency_100HZ); 
                sensorProUnitePPGConfigure1.setLightType(SensorProUnitePPGConfigure.LightType.THREE_LIGHT_MODE); 
                sensorProUnitePPGConfigure1.setPpgChanel(SensorProUnitePPGConfigure.PPGChannel.FULL); 
                togetherConfig.setPpgConfigure(sensorProUnitePPGConfigure1); 
                SensorProUniteIMUConfigure accConfigure = new SensorProUniteIMUConfigure(); 
                accConfigure.setFrequency(SensorProUniteIMUConfigure.FrequencyHZ.Frequency_100HZ); 
                togetherConfig.setAccConfigure(accConfigure); 
                SensorProUniteMAGConfigure magConfigure = new SensorProUniteMAGConfigure();
magConfigure.setFrequency(SensorProUniteMAGConfigure.FrequencyHZ.Frequency_100HZ);
togetherConfig.setMagConfigure(magConfigure);
SensorProManager.getInstance().getCustomProvider().startNewActiveAndOfflineCustomData( 
                        activeCollectTypeConfigure, offlineCollectTypeConfigure, togetherConfig, 
                        new SensorProCallback<byte[]>() { 
                            @Override 
                            public void onResponse(int errorCode, byte[] returnObject) { 
                                LogUtils.info(TAG, "开启 errorCode ：" + errorCode); 
                            } 
                        } 
                );  
  
 
```
