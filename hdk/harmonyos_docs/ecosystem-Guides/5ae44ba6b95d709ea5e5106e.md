# 单次运动详细信息

* 接口说明 从穿戴设备上获取单次运动的详细信息。

* 接口方法

  ```codeblock
  public voidgetMotionMsgDetail(WorkOutRecord workOutRecord, finalSensorProCallback<List<WorkoutData>> callback)
  ```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:------------|:-----------------------------------|:----------------|:------|
  |workOutRecord|WorkOutRecord|单次运动上手环的workoutid|M|
  |callback|SensorProCallback<List<WorkoutData>>|返回单次运动统计信息|M|
  [**表1**输入参数]

  |字段名|数据类型|说明|
  |:-------------------------|:---|:-------|
  |workout_record_id|int|单次运动记录ID|
  |workout_index_count|int|单次运动索引条数|
  |pace_index_count|int|配速信息索引条数|
  |workout_section_index|int|分段信息索引条数|
  |workout_section_index|int|分片数据|
  |workout_blood_oxygen_index|int|血氧信息索引条数|
  [**表2**WorkOutRecord（运动统计数据）]

  |字段名|数据类型|说明|
  |:-------------|:----------------------|:----------------|
  |workoutId|int|运动id|
  |frameNo|int|Frame编号|
  |timeStamp|int|时间戳|
  |interval|int|时间间隔|
  |dataArraySize|int|组数：表示有多少组Data|
  |dataSize|int|组长：表示一个Data结构体的大小|
  |bitmap|int|位图|
  |detailDataList|List<WorkoutDetailData>|运动详细数据集|
  [**表3**WorkoutData（单次运动详细数据）]

* 响应参数

  |响应方法名|参数名|数据类型|说明|
  |:---------|:-----------|:----------------|:-------|
  |onProgress|progress|Progress|文件传输通用回调|
  |onResponse|errorCode|int|返回错误码|
  |onResponse|returnObject|List<WorkoutData>|返回结果说明|
  [**表4**响应参数]
