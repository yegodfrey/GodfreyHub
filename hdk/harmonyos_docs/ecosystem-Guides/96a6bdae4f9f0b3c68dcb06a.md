# 数据采集

1. 安装APP后，打开APP如下图所示，单击同意用户协议与隐私权政策，然后单击"华为帐号一键登录"。

   **图1**华为帐号登录   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172611.92428911987248184879341651392391:50001231000000:2800:F43667A99EF69800E2344028C5FD12873627801AC5A7E50C6A15D0492DFDD0FB.png?needInitFileName=true?needInitFileName=true)

2. 完善个人信息，填写编号，选择年龄，性别，身高，体重，城市，单击"保存信息"。

   **图2**个人信息   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172611.23065045621765221606684723646261:50001231000000:2800:38F6D2A9C5729F9DF357E78470E99D2FC21F11D758EF31979D63B679781C2D5E.png?needInitFileName=true?needInitFileName=true)

3. 进入主页，单击右上角"未连接"，进行设备连接操作。

   **图3**APP主页   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172611.76902906175332924561845874885389:50001231000000:2800:358581E5DE47959A775DA67268DBCE91E07494DE3F22164A087F34828F3C2AAF.png?needInitFileName=true?needInitFileName=true "点击放大")

4. 手机通知栏开启"位置信息"，单击"手表"（或"手环"），搜索附近手表设备蓝牙，单击相应蓝牙名称，进行连接。

   **图4**连接设备   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172611.61134022371559480220894306258306:50001231000000:2800:1F4E5A1E49C7081BEC970013E21F3FCE6D77FF64DBBCC926A063A3942FA7A8C1.png?needInitFileName=true?needInitFileName=true "点击放大")

5. 连续数据采集及上传：穿戴设备佩戴后会自动采集睡眠、连续血氧、连续心率、连续RRI等数据，打开 APP 并连接设备，会自动同步设备中的数据，并上传到HUAWEI Research平台。 "统计页"下拉刷新也可以触发数据同步上传（如当天存在未同步数据，或数据上传失败，统计页会有相关提示）。

   **图5**统计页数据同步及上传   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172611.50341454847400986733438666952546:50001231000000:2800:DB773C0F6C5148ABA5D5F5E1DFC926B89AD2BF6180BC53B8B9C1B4E8A1EC7E54.png?needInitFileName=true?needInitFileName=true "点击放大")

6. 主动测量数据采集及上传：APP主页选择"心率"，单击"开始测量"，测量结束后，心率测量数据会自动上传到HUAWEI Research平台。

   **图6**主动测量心率   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172611.34567746099025467665707435845620:50001231000000:2800:95229771E75EE498F868391296B36042D7CF501B1434BA461CB7704265DF33C3.png?needInitFileName=true?needInitFileName=true "点击放大")
