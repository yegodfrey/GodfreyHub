# 开启实时测量采集

* 接口说明 开启穿戴设备实时数据开关。支持实时心率、实时RRI、实时血氧、实时传感器（PPG、ACC、GYRO 、ECG）及多种实时数据组合上报。

* 接口方法

  ```codeblock
  public voidstartActiveAndOfflineCustomData (@NonNull SensorProUniteCollectTypeConfigure realtimeCollectTypeConfigure,@NonNull SensorProUniteCollectTypeConfigure offlineCollectTypeConfigure, SensorProUnitePPGConfigure ppgConfigure, @NonNull SensorProCallback<byte[]> callback)
  ```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:---------------------------|:---------------------------------|:---------|:------|
  |realtimeCollectTypeConfigure|SensorProUniteCollectTypeConfigure|实时测量开关控制配置|M|
  |offlineCollectTypeConfigure|SensorProUniteCollectTypeConfigure|连续采集开关控制配置|M|
  |ppgConfigure|SensorProUnitePPGConfigure|PPG采集配置|O|
  |callback|SensorProCallback< byte[]>|开关结果|M|
  [**表1**输入参数]

  |字段名|数据类型|说明|
  |:---------------------------------|:----------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------|
  |SensorProUniteCollectTypeConfigure|public SensorProUniteCollectTypeConfigure setStorageFile(boolean var1)|设置此接口配置的采集数据项的数据采集模式。 * true：数据后台采集模式，即数据保存在设备侧，不进行实时上报； * false（默认值）：数据实时采集模式，即数据不保存在设备侧，进行实时上报。|
  |SensorProUniteCollectTypeConfigure|public void setRealtimeMesureTimeOut(long var1)|仅在实时测量模式下生效。设置实时测量的持续时长。建议单次实时测量时长控制在5分钟内。|
  |SensorProUniteCollectTypeConfigure|public SensorProUniteCollectTypeConfigure setCollectGyro(boolean var1)|设置是否采集陀螺仪数据。 * true：采集该项数据； * flase（默认值）：不采集该项数据。|
  |SensorProUniteCollectTypeConfigure|public SensorProUniteCollectTypeConfigure setCollectEcg(boolean var1)|设置是否采集ECG数据。 * true：采集该项数据； * flase（默认值）：不采集该项数据。 > 注意 > 请确保您的设备支持ECG采集，设备型号及测量方法请参见华为穿戴设备官网说明。|
  |SensorProUniteCollectTypeConfigure|public SensorProUniteCollectTypeConfigure setCollectPpg(boolean var1)|设置是否采集PPG数据。 * true：采集该项数据； * flase（默认值）：不采集该项数据。|
  |SensorProUniteCollectTypeConfigure|public SensorProUniteCollectTypeConfigure setCollectHr(boolean var1)|设置是否采集心率数据。 * true：采集该项数据； * flase（默认值）：不采集该项数据。|
  |SensorProUniteCollectTypeConfigure|public SensorProUniteCollectTypeConfigure setCollectSpo2(boolean var1)|设置是否采集血氧数据。 * true：采集该项数据； * flase（默认值）：不采集该项数据。 > 注意 > 建议避免在运动状态开启血氧测量。|
  |SensorProUniteCollectTypeConfigure|public SensorProUniteCollectTypeConfigure setCollectAcc(boolean var1)|设置是否采集ACC数据。 * true：采集该项数据； * flase（默认值）：不采集该项数据。|
  |SensorProUniteCollectTypeConfigure|public SensorProUniteCollectTypeConfigure setCollectRRI(boolean var1)|设置是否采集RRI数据。 * true：采集该项数据； * flase（默认值）：不采集该项数据。|
  |SensorProUniteCollectTypeConfigure|public SensorProUniteCollectTypeConfigure setCollectTemperature(boolean var1)|设置是否采集体温数据。 * true：采集该项数据； * flase（默认值）：不采集该项数据。|
  |SensorProUniteCollectTypeConfigure|public SensorProUniteCollectTypeConfigure setParseData (boolean var1)|设置成true。|
  [**表2**SensorProUniteCollectTypeConfigure（测量配置）]

  > 注意
  >
  > 在实时测量结束15s后才会进入后台采集状态，此段时间内不采集数据，可下发同步命令同步数据，亦可再次开启实时测量。
  >
  > 后台采集开关控制配置offlineCollectTypeConfigure，请与"连续数据"、"统计数据"数据采集配置一致。

  |配置类名|配置接口|说明|

  |SensorProUnitePPGConfigure|public SensorProUnitePPGConfigure setPpgChanel(SensorProUnitePPGConfigure.PPGChannel var1)|配置PPG上报通道。 * PPGChannel. GREEN：绿光及其环境光通道。 * PPGChannel. INFRARED：红外及其环境光通道。 * PPGChannel. FULL：红外、绿光全通道及其环境光通道。|
  |SensorProUnitePPGConfigure|public SensorProUnitePPGConfigure setFrequency(SensorProUnitePPGConfigure.FrequencyHZ var1)|配置PPG采集频率。 * FrequencyHZ. Frequency_100HZ：100Hz； * FrequencyHZ. Frequency_25HZ：25Hz。|
  [**表3**SensorProUnitePPGConfigure（PPG测量配置）]

  > 注意
  >
  > 请确认设备穿戴设备固件版本是否支持上述配置。
