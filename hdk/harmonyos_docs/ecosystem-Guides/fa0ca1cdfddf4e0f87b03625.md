# 接入FAQ

**［问题一］HUAWEI Research的联系方式？**

HiResearch@huawei.com

**［问题二］如何加入HUAWEI Research开展研究项目？**

在开发者联盟页面注册企业帐号，申请加入研究项目，具体请参考"[研究项目申请指导](https://developer.huawei.com/consumer/cn/doc/32304)"。

**［问题三］HUAWEI Research创新研究平台支持采集哪些类型的数据？**

HUAWEI Research可采集PPG、ACC、ECG等智能终端传感器数据、华为运动健康数据、量表问卷、研究任务以及灵活自定义的研究数据。
