# 运动量详情

* 接口说明 从穿戴设备上获取每分钟运动量数据，包含每分钟运动卡路里、运动间隔、步数、爬高、静息心率、运动心率，以及每分钟的运动相关的状态。

* 接口方法

  ```codeblock
  public voidgetDetailMotionData(intstartTime, intendTime, SensorProCallback<FitnessDetailData> callback)
  ```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:--------|:-----------------------------------|:---------|:------|
  |startTime|int|数据开始时间|M|
  |endTime|int|数据结束时间|M|
  |callback|SensorProCallback<FitnessDetailData>|返回每日运动统计数据|M|
  [**表1**输入参数]

  > 注意
  >
  > startTime和endTime需相差1分钟以上。
* 响应参数

  |参数名|数据类型|说明|
  |:-----------|:----------------|:--------|
  |errorCode|int|返回错误码|
  |returnObject|FitnessDetailData|运动量详情结果说明|
  [**表2**响应参数]

  |字段名|数据类型|说明|
  |:---------|:----------------|:---------|
  |sampleList|List<SamplePoint>|sample帧数据集|
  |statusList|List<StatusPoint>|采样数据集|
  [**表3**FitnessDetailData（每日运动量详情）]
