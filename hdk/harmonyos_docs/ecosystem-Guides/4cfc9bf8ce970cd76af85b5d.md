# 接入指南

HUAWEI Research Android SDK以华为帐号统一登录鉴权，为研究APP提供知情同意、加入研究项目、穿戴设备数据收集、测量数据上云、量表问卷等能力，降低研究APP开发门槛，助力合作伙伴加速创新研究。

本文档基于Android 8.1（API Level 28）编写。Android SDK具有向下兼容的特性，新版本完全兼容老版本。
