# 移除设备

* 接口说明 移除已连接的穿戴设备。

* 接口方法

  ```codeblock
  public voidremoveBTDevice(@NonNull SensorProDeviceInfo deviceInfo, @NonNull SensorProCallback<String> callback)
  ```

* 输入参数

  |字段名|数据类型|说明|必选M/可选O|
  |:---------|:------------------|:---|:------|
  |deviceInfo|SensorProDeviceInfo|穿戴设备|M|
  |callback|SensorProCallback|返回结果|M|
  [**表1**输入参数]

  |字段名|数据类型|说明|必选M/可选O|
  |:-----------------|:-----|:----|:------|
  |deviceName|String|设备名称|M|
  |deviceIdentify|String|MAC地址|M|
  |version|String|设备版本|O|
  |deviceConnectState|int|连接状态|O|
  |productType|int|产品类型|O|
  |deviceModel|String|设备型号|O|
  |deviceItemType|int|设备类型|O|
  |wearType|int|佩戴类型|O|
  [**表2**SensorProDeviceInfo（设备信息）]

* 响应参数

  |响应方法名|参数名|数据类型|说明|
  |:---------|:-----------|:-----|:-----|
  |onResponse|errorCode|int|返回错误码|
  |onResponse|returnObject|String|返回结果说明|
  [**表3**响应参数]

* 示例代码

  ```codeblock
  import com.huawei.hiresearch.sensorfat.SensorScaleManager; 
  import com.huawei.hiresearch.sensorprosdk.provider.callback.SensorProCallback; 
  import com.huawei.hiresearch.sensorprosdk.datatype.device.SensorProDeviceInfo;   
  /**
  * 移除设备
  */
  public voidremoveBTDevice() {
           SensorProDeviceInfo sensorProDeviceInfo = newSensorProDeviceInfo();
           sensorProDeviceInfo.setDeviceName("HUAWEI WATCH GT 2-405");
           sensorProDeviceInfo.setDeviceIdentify("88:40:3B:EB:04:05");
           SensorScaleManager.getInstance().getScaleBaseProvider().removeBTDevice(sensorProDeviceInfo, newSensorProCallback<String>() {
  @Override
  /**
  *
  * **@param** **errorcode** 状态码
  * **@param** **returnObject** 结果数据
  */
  public voidonResponse(interrorCode, String returnObject) {
           // **TODO:移除成功 (errorCode：错误码；returnObject：返回数据)**
  }
           });
           }
  ```
