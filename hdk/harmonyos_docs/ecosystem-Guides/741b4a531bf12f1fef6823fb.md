# Android SDK FAQ

**［问题一］元数据上传失败，页面提示String类型字段长度超长**。

平台要求String类型字段最大长度为8K，如果字段长度超过8K，可以设置字段类型为"Text"。Text类型字段最大长度为2M。

**［问题二］上传数据是附件形式，需要设置什么类型上传？**

可以将字段的类型设置为"Attachment"类型。

**［问题三］加入研究项目失败，提示"Missing or invaild Authorization header"。**

请先确定是否已经登录，登录后才可加入研究项目。

**［问题四］每个元数据自带五个保留字段，需要上传数据时是否需要对这个字段插入数据。**

保留字段有"uniqueid"、"healthid"、"uploadtime"、"recordtime","recordschema","externalid"，以及"groupid"。其中"uniqueid，healthid，uploadtime，recordschema"四个保留字段，用户上传数据时可不用写入数据，系统会自动写入数据，"recordtime"如不填则与"uploadtime"保持一致。

**［问题五］元数据上传后，如何在平台查看已上传的数据？**

登录创新研究平台，单击"数据管理 > 数据表"，新增数据表关联您需要查看的元数据，保存成功后，单击数据表名称，即可跳转到数据查看页面。
