# 在Eclipse中安装

本章节介绍如何在Eclipse中安装Java SDK。

1. 将解压后文件夹中的文件hiresearch-client-x.x.x-with-dependencies.jar拷贝到您的项目的libs目录下。您也可以选择不包含自身依赖的hiresearch-client-x.x.x.jar，但需要参考2.3.3手动引入依赖。

   **图1**hiresearch-client-x.x.x-with-dependencies.jar   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172625.82248789702010816807163740408268:50001231000000:2800:CD2893DBC82AAA1EC924E3780C7C8F5A73C74FB854D6FC542EF1BB2EA2ECB03B.png?needInitFileName=true?needInitFileName=true)

2. 在 Eclipse 中选择您的工程，在jar包邮件菜单中选择"build path"->"add to build path"，选择 步骤 1中拷贝至项目libs目录下的jar包。

   **图2**add to build path   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240813172625.64107104047943630703612096850237:50001231000000:2800:07EBE25E2B92BBAF2D3DE9F2DA4AFBF15FCFFAC8EFEC9886A9CC345DB0FED340.png?needInitFileName=true?needInitFileName=true "点击放大")

3. 选择完成，即可完成引入。
