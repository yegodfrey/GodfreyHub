# 简介

JAVA SDK适用于第三方研究系统，与HUAWEI Research创新研究平台的鉴权后，通过相关API读取与分析研究数据表中的数据。

在使用JAVA SDK前，您需要：

* 了解HUAWEI Research创新研究平台，熟悉"数据管理"->"数据表"页面用法。
* 登录HUAWEI Research平台，联系华为Research侧项目负责人创建项目密钥。

本文档详细介绍了JAVA SDK的安装、鉴权API、数据表查询API及其示例。
