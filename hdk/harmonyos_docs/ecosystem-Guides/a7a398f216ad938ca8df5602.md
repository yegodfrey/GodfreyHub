# 连续数据

设备佩戴状态下，就会进行RRI，血氧、心率等数据的自动测量，并且保存到穿戴设备上。连接设备后调用如下接口，可以获取到穿戴设备上的连续数据。
> 注意
>
> 同步连续数据需在同步完成一项数据后，再同步另一项数据。

* **[RRI](https://developer.huawei.com/consumer/cn/doc/ecosystem-Guides/03_03_04_01_rridatahistory-0000001113764746)**   
* **[血氧饱和度](https://developer.huawei.com/consumer/cn/doc/ecosystem-Guides/03_03_04_02_spo2datahistory-0000001160284655)**   
* **[心率](https://developer.huawei.com/consumer/cn/doc/ecosystem-Guides/03_03_04_03_rridatahistory-0000001113604850)**   
* **[体温](https://developer.huawei.com/consumer/cn/doc/ecosystem-Guides/03_03_03_04_04-0000001362572616)**   
* **[血压](https://developer.huawei.com/consumer/cn/doc/ecosystem-Guides/03_03_03_04_05-0000001362253096)**   
* **[佩戴状态](https://developer.huawei.com/consumer/cn/doc/ecosystem-Guides/03_03_04_04_wearablestate-0000001159964673)**
