# 示例代码

该Android Studio工程调用了激活、去激活和状态回调的接口，实现设备部署服务。您可以轻松地在自己的Android应用中加入HEM相关的功能，点击[了解更多](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/HMSHEMKit)。

在这个Demo中，您将使用已经创建好的Demo工程实现对HEM设备部署服务开放能力的API调用，通过Demo您可以体验到：

* 如何使用Android Studio高效地集成HEM SDK。
* 如何正确使用HEM的各个接口。
