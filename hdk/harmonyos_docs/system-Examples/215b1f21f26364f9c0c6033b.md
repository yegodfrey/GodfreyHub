# 示例代码

该Android Studio工程包含了Network Kit中URL请求和文件上传/下载的示例代码，通过Demo您可以体验到：

* 如何集成Network Kit，并通过两种不同的方式（HttpClient和RestClient方式 ）完成同步和异步网络请求。
* 如何通过集成Network Kit实现文件的上传/下载功能。
