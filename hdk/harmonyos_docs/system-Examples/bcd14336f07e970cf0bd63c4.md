# 示例代码

在这个Demo中，您将使用已经创建好的Demo工程实现对华为无线传输服务开放能力的API调用，通过Demo您可以体验到：

* 获取网络QoE信息
* 将传输质量反馈给WirelessKit
* 进行网络弱信号预测
* 设置Wi-Fi高优先级发包
* 使用双Wi-Fi能力

|名称|**Gitee**|GitHub|
|:-------|:---------------------------------------------------------|:----------------------------------------------------------|
|Java示例代码|[链接](https://gitee.com/hms-core/hms-wireless-demo-android)|[链接](https://github.com/HMS-Core/hms-wireless-demo-android)|

> 说明
>
> 在使用示例代码前请详细阅读示例工程中的"README"文件。您需要完成以下操作后才可以运行示例代码。
>
> 1. 在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站下载自己应用的"agconnect-services.json"文件，拷贝到示例工程的应用级根目录下。
>
> 2. 修改示例工程中应用级"build.gradle"文件中的"applicationId"为您自己的应用包名。
