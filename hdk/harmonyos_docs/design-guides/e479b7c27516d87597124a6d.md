# 下拉按钮

下拉按钮可让用户在多个选项之间选择。开发相关描述请参考 [Select](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-select) 文档。

## 如何使用

需过滤当前界面内容、快速切换类型 (如存储位置) ，或选项内容 (如设置密保问题) 时，使用下拉按钮。

## 视觉样式

### 沉浸光感

当下拉按钮组件需要悬浮在页面之上常驻时，建议适配[沉浸光感](https://developer.huawei.com/consumer/cn/doc/design-guides/immersivelight-0000002612101053)提高按钮的精致度和空间感，为界面带来更丰富的视觉体验。在任何情况下，弹出的菜单栏均可以采用沉浸光感。
