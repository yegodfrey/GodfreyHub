# 状态机卡片

状态机卡片主要展示于负一屏状态机，其核心价值在于将任务可视化，稳定预期反馈，降低用户焦虑。相较于实况窗，状态机通知持续更长，流程更为完整。

## 卡片类型

状态机卡片可分为左文右图、左右文本、单文本、进度可视、效率多实例 5 种类型，可根据实际业务选择合适多卡片类型。

支持运营在卡片结构中配置图片、特征色、文字、交互跳转、节点动效，但不支持更改卡片本身的结构。

## 内容聚焦

卡片文本、图片、用色需保证清晰易于识别。整体配色和谐统一，插图主体简洁清晰，配图传递主题明确。

### 图片质量

保证图片画面清晰，图片交付尺寸为 220*220px，确保图形占比易于识别查看。图片需考虑深色、浅色两种模式的显示效果，确保两种模式下用户均能清晰识别关键信息。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ec/v3/T79D4Rc7ScidMviCdrRBaA/zh-cn_image_0000002729076645.png?HW-CC-KV=V1&HW-CC-Date=20261008T151018Z&HW-CC-Expire=31536000000&HW-CC-Sign=DF60B08FDC7AECB593FC21C00753A62D66B44CA2CA6B01F8A89D7C001D9E0C5C "点击放大")

### 图片信息量

能够辅助用户理解，减少繁杂细节，主体物清晰可识别；

插图应与状态机内容相关，解释当前状态；

避免将状态机用于营销、广告场景，配图应避免过强的营销感。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/06/v3/V7U57b2oQfeoD6qrdH5Wbg/zh-cn_image_0000002699317386.png?HW-CC-KV=V1&HW-CC-Date=20261008T151018Z&HW-CC-Expire=31536000000&HW-CC-Sign=42931CA5A4672403724B96E514D10B4FD1BC9AF9F98B203D852D5686BBDFD0A8 "点击放大")

### 强调色

统一强调色值：卡片内容区高亮色跟随行业图标颜色。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a5/v3/JOlqmxxgTySGst77DY6Y2A/zh-cn_image_0000002728956691.png?HW-CC-KV=V1&HW-CC-Date=20261008T151018Z&HW-CC-Expire=31536000000&HW-CC-Sign=47CD461AA96FDFDF3D1769FFE0D72434D315E926256EAD8520691FD5E06FC569 "点击放大")

### 图片内容

配图应对用户有意义，从用户使用场景出发，增强跨场景、跨应用对信息表达能力。

### 新材质适配

默认场景下使用系统适配的玻璃背板，运营场景可叠加 75% 不透明度的彩色背板。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6c/v3/4LVj7utIRBuWq-3QSFEAOA/zh-cn_image_0000002729076649.png?HW-CC-KV=V1&HW-CC-Date=20261008T151018Z&HW-CC-Expire=31536000000&HW-CC-Sign=7E7A0720B404BD8A3878CB7CD7540D62E31AD5DA0AEA908A382C0EA5AABDEBC3 "点击放大")

### 文字

主要文本字号统一使用 24vp（Bold）；

向用户提供当前时间的重要信息，在卡片上显示用户关注的关键内容或数据；

避免将状态机用于营销、广告场景或其他未经评审的场景。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b9/v3/90lAWdZjThWh0HJrNUGDjQ/zh-cn_image_0000002699317388.png?HW-CC-KV=V1&HW-CC-Date=20261008T151018Z&HW-CC-Expire=31536000000&HW-CC-Sign=FC06CFD80093086730F915C6B23DB6E18A7D28D973CE408DE0486B2538408C42 "点击放大")

### 大字体

在大字体场景下，最大支持放大至 1.3 倍，更大倍数不支持，并且需要保持卡片默认高度不变。

尽量选择单一实例类模版，保证内容聚焦，直观易读。

## 连续性

确保交互操作简单便捷，符合人机交互体验要求，用户的体验流程顺畅不中断。

### 体验连贯

点击状态机主卡进入对应服务界面，若使用全局返回手势，则回到状态机本身；

一个辅助操作：必要时，明确接续状态/异常下一步，保证用户的全流程体验不中断。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/96/v3/PDN5Gl7QRgy9jAwEnd4Pgw/zh-cn_image_0000002729076651.png?HW-CC-KV=V1&HW-CC-Date=20261008T151018Z&HW-CC-Expire=31536000000&HW-CC-Sign=105E96137C522DC5FF24F41FFCC9C305E6C6988BF1427FA5CC31A946D01DD615 "点击放大")

### 热区清晰

鸿蒙NEXT无障碍手势规范：控件和交互式元素都要有点击热区，该目标至少为 48*48dp；

效率场景应控制多例数量，尽量保证热区的可点击；

卡片内无复杂交互，不要在卡片内设计整张卡片响应的左右滑动或上下滑动。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5b/v3/ajQYsYK9SCeed_3eIfuBXg/zh-cn_image_0000002699317390.png?HW-CC-KV=V1&HW-CC-Date=20261008T151018Z&HW-CC-Expire=31536000000&HW-CC-Sign=D13BA90616E31F96F1BA686D961B50AC3FD83710E6C23C2ADE5729E5539B2F2F "点击放大")

### 微动效

鸿蒙NEXT动效规范：动效应避免过度的视觉冲击或复杂的动画，不占用过多资源或注意力。通过细腻、克制的方式表现，传递高级感和精致感；负一屏状态机支持自动轮播，支持定义微动效，但要避免闪烁，并符合鸿蒙动效规范要求。

| | |
|**推荐** 优雅微动效|**不推荐** 避免突兀的闪烁|
