# 出行导航类

|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|出行导航类场景通常包含查询地点信息，路线建议，导航，打车等核心功能，用户可以通过悬浮面板体验到面板与底层地图间的交互，围绕此核心场景，此类应用有如下特点： * 手机使用底部半模态面板，其他设备上使用侧边半模态面板 * 面板支持多档位高度滑动调节 * 面板默认高度，需要依据屏幕尺寸的不同而有所区分，充分发挥屏幕尺寸优势 * 折叠屏&平板上侧边的半模态面板支持用户自行拖拽至左侧或右侧位置 * 建议折叠屏和平板等宽屏设备上，Tab 放置在半模态面板内|
|  |

## 首页

1. 直板机上使用底板的半模态面板。在折叠屏、平板等宽屏设备上，使用侧边的半模态面板而非全屏拉伸的底板面板，减少面板对地图的遮挡。
2. 面板默认高度，依据屏幕尺寸的不同而有所区分：手机和折叠屏设备使用「中」高度的面板高度，减少对地图的遮挡。宽屏端设备因为屏幕空间足够，面板默认以最高高度展示。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/86/v3/za-nOdYPSrCQNSdllEWU6w/zh-cn_image_0000002364803197.png?HW-CC-KV=V1&HW-CC-Date=20260909T132133Z&HW-CC-Expire=31536000000&HW-CC-Sign=5CF12AE6B26709C1CB4B46572BA782374397278AF32CF2BCFE8C607AA3C9B792 "点击放大")

## 搜索

搜索场景是地图类应用核心功能之一，点击搜索可以拉起面板，以面板最大高度显示，搜索结果以列表结构显示。建议在手机和折叠屏上，搜索框限制在面板内。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/63/v3/5WqZFEfwRt28AyNkhEDZ_w/zh-cn_image_0000002330764886.png?HW-CC-KV=V1&HW-CC-Date=20260909T132133Z&HW-CC-Expire=31536000000&HW-CC-Sign=AF55E86BFFF489D4C60DD52FF423F17C6B7B778F3DF0FCAD8CFEBAA3DD985CB2 "点击放大")

## 路线

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3a/v3/LfATs40wSBa4c6AJ4rKqTw/zh-cn_image_0000002330764974.png?HW-CC-KV=V1&HW-CC-Date=20260909T132133Z&HW-CC-Expire=31536000000&HW-CC-Sign=25900DFFCC610B7C124B1DE2D258BAF6E4269EAE91AAC7ED5B1A57D44339581D "点击放大")

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/49/v3/qdcE58lRQZmIjW7JTM2ltg/zh-cn_image_0000002330924770.png?HW-CC-KV=V1&HW-CC-Date=20260909T132133Z&HW-CC-Expire=31536000000&HW-CC-Sign=4C6066A9087AD4BC44E342569138CF53A8C21B19EF87C1DD8F421473C075965A "点击放大")

### 导航

导航功能作为出行导航的核心场景之一，建议多端设备上统一设计方案。在手机设备上，顶部背景面板与底部半模态面板使用沉浸式的设计，与设备边框不留间距；在折叠屏和平板设备上，沿用悬浮面板的设计，部分内容在大屏上通过自适应布局带来更好使用体验；在电脑设备上，无导航功能，可以通过点击路线结果，展示具体的出行方案。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bc/v3/skTFPZXQQaeNuuOEXv_ooA/zh-cn_image_0000002330764938.png?HW-CC-KV=V1&HW-CC-Date=20260909T132133Z&HW-CC-Expire=31536000000&HW-CC-Sign=3847D578E6C7D7D095A37A47A739C99FA63E2323C90F49CBBC636699FF4CF86D "点击放大")

### 打车

打车功能在出行导航场景中经常用到，因此在面板首页有固定的打车入口。进入打车页面时，多端设备上面板高度默认中档位高度显示，展示打车目的地搜索框和常用功能区域，地图上显示打车起点定位。在手机上，同时展示半模态面板和地图选点；在大屏设备上，露出更多地图，提升使用体验。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ee/v3/QqHTlUUPTTuLmcqZgFydsQ/zh-cn_image_0000002364803233.png?HW-CC-KV=V1&HW-CC-Date=20260909T132133Z&HW-CC-Expire=31536000000&HW-CC-Sign=021685FD26370A6DB0D968D0F1D1A4EDDE8E2D1CE95DFCEA5B3DDE62D7C3988C "点击放大")

**选择车型**

选择起点和终点后，进入车型选择列表，在多端设备上，车型列表在半模态面板上展示，打车路线在地图上展示。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/89/v3/rOw03ZB0SyqCq4J4Ru2hGg/zh-cn_image_0000002364843097.png?HW-CC-KV=V1&HW-CC-Date=20260909T132133Z&HW-CC-Expire=31536000000&HW-CC-Sign=F91F4F538EDDF6C36C52E1EC5E1AA8572E32B8283963E4D4E19BF78FDD247AED "点击放大")

## 实况窗

实况通知是一种帮助用户聚焦进行中任务、方便快速查看和即时处理的消息提醒，包含胶囊态、卡片态。在地图导航场景中，导航和打车时都可在实况通知中展示重要信息。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b8/v3/qAXVaphfRjmGVuKDXWeLDQ/zh-cn_image_0000002330924802.png?HW-CC-KV=V1&HW-CC-Date=20260909T132133Z&HW-CC-Expire=31536000000&HW-CC-Sign=04D08219FDE210DE4A58BF79CBDFF7C5A311D204D620BA16F8FE08AD06051B55 "点击放大")

### 多种状态

1. 同一个事件活动在不同场景下仅出现一个形态，如当前事件所承载的落地页在前台，则当前无胶囊；如当前为通知中心/锁屏，则不显示胶囊。
2. 通知中心的实况通知卡片会默认显示在顶部，避免滥用对用户造成打扰。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ab/v3/MhiyVPVWSuiXJh6RFklc9w/zh-cn_image_0000002330764894.png?HW-CC-KV=V1&HW-CC-Date=20260909T132133Z&HW-CC-Expire=31536000000&HW-CC-Sign=0B03B5A89B455D7186BD15E666DEFA04F2A0576ED3392B8BA3499338C0F0DD7E "点击放大")
