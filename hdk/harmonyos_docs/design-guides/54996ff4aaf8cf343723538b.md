# 菜单

一种临时性弹出窗口，用于展示用户可执行的操作。开发相关描述请参考 [Menu](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-menu) 文档。

![](https://media:301781259458312619 "点击放大")  

#### 如何使用

菜单项中不显示与当前内容无关的项。菜单顺序：最常用菜单项放在菜单顶部依次排列。菜单的通用基础构成元素通过 [MenuItemOptions](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-menuitem#menuitemoptions对象说明) 进行配置，选中状态及选中图标可通过 [Selected](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-menuitem#selected) 进行配置。多级菜单的展开样式可通过 [subMenuExpandingMode](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-menu#submenuexpandingmode12) 进行配置。长按悬浮菜单通过 [bindContextMenu](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-universal-attributes-menu#bindcontextmenu8) 进行调用。

#### 视觉规则

#### 沉浸光感

组件已提供[沉浸光感](https://developer.huawei.com/consumer/cn/doc/design-guides/immersivelight-0000002612101053)样式，建议使用菜单组件时，采用沉浸光感样式为应用页面带来更丰富的空间感交互视觉体验。

![](https://media:301781259458861628 "点击放大")  

#### 响应式布局

手机

![](https://media:301781259458918629 "点击放大")

泛手机统一宽度为固定 224vp

<br />

电脑设备

![](https://media:301781259458991630 "点击放大")

电脑菜单宽度根据内容自适应，默认最小宽度 224vp，可配置菜单最小宽度，但不得低于 64vp
