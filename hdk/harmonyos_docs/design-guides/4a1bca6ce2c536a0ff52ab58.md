# 影音娱乐类

长视频、短视频、直播、音乐等类型的应用或业务场景很常见。这类场景的核心都是沉浸式的视频播放和互动，围绕此核心场景，此类应用有如下特点：

* 海量视频内容资源 (一应俱全)
* 沉浸式视频播放状态 (持续粘性)
* 简单的信息架构，层级扁平 (适合做特殊设计优化)
* 快捷的手势交互，易学，沉浸感强 (操作流)
* 注重作者与观赏者的互动 (社交因素)
* 探索延展相关业务：多方同台直播、视频内商品推广 (商业机会)

## 长视频

在视频应用中，首页顶部往往会有广告内容。针对影音场景，使用沉浸式广告图可以达到更好的沉浸式体验效果。

### 画中画体验

建议支持画中画能力，用户可在浏览其他内容的同时通过悬浮小窗继续观看视频。

* 开启方式一：点击视频播放页的画中画按钮，调起悬浮小窗；
* 开启方式二：点击返回键或使用全局返回手势，在返回上一级界面的同时调起悬浮小窗。
* 首次使用时，建议直接调起授权弹窗，引导用户开启画中画权限。

### 短视频自适应沉浸式

短视频沉浸是一种通过全屏展示、弱化界面干扰，让用户专注于视频内容的呈现模式。针对主流的9:16比例视频进行处理，结合屏幕比例尺寸、系统控件布局、视频裁剪等技术，以增强视觉沉浸感。开发者可参考 adaptive_video 使用说明进行适配与快速上手，短视频浏览区域将综合考虑页面窗口尺寸、视频比例、Tab导航栏高度等信息，根据沉浸规则计算沉浸式布局方案。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/42/v3/fIwi-suiQheZGn5_bp7IQg/zh-cn_image_0000002624498717.png?HW-CC-KV=V1&HW-CC-Date=20260909T172456Z&HW-CC-Expire=31536000000&HW-CC-Sign=4896BCA8F43E9CB76FA69BE638CB23AC1217EC986A5B572685BAC0687A8BA968 "点击放大")

以下是adaptive_video 使用的自适应沉浸布局计算规则

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3e/v3/ABT5m-CMQu2WVTpSDUqI2Q/zh-cn_image_0000002624618679.png?HW-CC-KV=V1&HW-CC-Date=20260909T172456Z&HW-CC-Expire=31536000000&HW-CC-Sign=06CE1C3901227A76FFDBD2C00E884FB302BD3743941A90DE6A450C0A88503807 "点击放大")

|序号|窗口宽高比X|沉浸规则描述|
|:-|:----------------|:-------------------------------------------------------------------------------------------------------------------|
