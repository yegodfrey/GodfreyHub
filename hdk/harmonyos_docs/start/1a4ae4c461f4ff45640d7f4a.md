# 接入华为支付商户平台

若您需要交易已上架的商品或希望在需求广场抢单，则需接入华为支付商户平台；如无交易需求，则无需接入。

1. 在卖家中心-店铺信息创建完毕后，点击支付接入下的"申请接入"按钮；

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/62/v3/9UAWVaPhSIWDh5Ip6I94IQ/zh-cn_image_0000002567186619.png?HW-CC-KV=V1&HW-CC-Date=20261008T152608Z&HW-CC-Expire=31536000000&HW-CC-Sign=1E505ED086345A7DCDF48E798872FA8E53C986B634D2E06EF0936A79C33CDF25)

2. 点击授权华为账号登录，确认接受邀请；

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/91/v3/zUXZz1h5S9mChahWufSPSQ/zh-cn_image_0000002567066597.png?HW-CC-KV=V1&HW-CC-Date=20261008T152608Z&HW-CC-Expire=31536000000&HW-CC-Sign=CFEDEECE0E6402428F83DC1993A4B2427C6F1AD40F38D58B4D0D23FFD3F1B3E3)![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0/v3/I1O-LXBWSfC10wKM3oI8-Q/zh-cn_image_0000002536146842.png?HW-CC-KV=V1&HW-CC-Date=20261008T152608Z&HW-CC-Expire=31536000000&HW-CC-Sign=71FB368075A15448FB284F21986C7D60065E1812F3B82BAAB1D084378737CB0D "点击放大")

3. 根据系统提示完成申请管理员账户、商户主体信息填写，商户经营信息填写，点击提交，等待审核；（填写明细可参考["平台子商户如何提交申请"](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-zishanghuruwang-0000001720049550#section6562121910312)文档说明）

4. 审核通过后，则接入状态显示"已接入"，您可以正常在生态市场进行交易，或在需求广场进行抢单。
