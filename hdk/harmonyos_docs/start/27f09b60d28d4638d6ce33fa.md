# 各类目入驻条件

华为开发者联盟生态市场的商户类型有六大类，包括应用软件、服务市场、企业应用、硬件市场、HarmonyOS专区、解决方案。入驻华为开发者联盟生态市场的任一类目需要满足相应的入驻条件。  

#### 入驻前须知

在您入驻之前请认真阅读[《华为开发者联盟生态市场商户管理规范》](https://developer.huawei.com/consumer/cn/doc/start/overview-0000001066590774)。生态市场咨询邮箱：partner@huawei.com  

#### 应用软件

为用户提供各类应用软件及网站开发服务，包括：终端移动应用、华为快应用、服务器应用软件及服务端相关应用软件、建站服务等。

成为华为开发者联盟生态市场应用开发的商户需要符合以下条件：

1、符合国家/区域相关法律、法规规定、拥有正规的公司资质；

2、营业执照需要满1年，注册资金不低于10万；

3、能提供基于开发者需求的成熟、稳定的应用软件；

4、接受《[华为开发者联盟生态市场商户合作协议](https://terms-drcn.platform.dbankcloud.cn/agreementservice/developer/getAgreementTemplate?agrType=1172&country=cn&language=zh_cn&version=2026040701)》并按照协议相互约束的条款开展业务合作；

5、接受生态市场的相关协议及管理规范。  

#### 服务市场

提供企业经营相关的全方位服务，包含：各类定制服务、培训与认证服务、数据迁移、环境配置、故障排查、安全加固，技术支持，架构咨询、华为主题开发服务等。

成为华为开发者联盟生态市场服务市场的商户需要符合以下条件：

1、符合国家/区域相关法律、法规规定、拥有正规的公司资质；

2、营业执照需要满2年，注册资金不低于10万；

3、接受《[华为开发者联盟生态市场商户合作协议](https://terms-drcn.platform.dbankcloud.cn/agreementservice/developer/getAgreementTemplate?agrType=1172&country=cn&language=zh_cn&version=2026040701)》并按照协议相互约束的条款开展业务合作；

4、接受生态市场的相关协议及管理规范。  

#### 企业应用

提供企业管理的一站式信息化解决方案，满足企业办公、财务、人力资源、销售、广告营销等各个领域的管理需求。

成为华为开发者联盟生态市场企业应用的商户需要符合以下条件：

1、符合国家/区域相关法律、法规规定、拥有正规的公司资质；

2、营业执照需要满2年，注册资金不低于50万；

3、能提供企业软件及SaaS服务，有不少于2年的行业经验；

4、接受《[华为开发者联盟生态市场商户合作协议](https://terms-drcn.platform.dbankcloud.cn/agreementservice/developer/getAgreementTemplate?agrType=1172&country=cn&language=zh_cn&version=2026040701)》并按照协议相互约束的条款开展业务合作；

5、接受生态市场的相关协议及管理规范。  

#### 硬件市场

为中小企业用户，提供基础硬件购买服务，包括模组、智能硬件、传感器、芯片、物联网硬件。

成为华为开发者联盟生态市场硬件市场的商户需要符合以下条件：

1、符合国家/区域相关法律、法规规定、拥有正规的公司资质；

2、营业执照需要满2年，注册资金不低于50万；

3、营业执照经营范围需包含相关硬件的自营/代理条款；

4、接受《[华为开发者联盟生态市场商户合作协议](https://terms-drcn.platform.dbankcloud.cn/agreementservice/developer/getAgreementTemplate?agrType=1172&country=cn&language=zh_cn&version=2026040701)》并按照协议相互约束的条款开展业务合作；

5、接受生态市场的相关协议及管理规范。  

#### HarmonyOS专区

基于HarmonyOS提供应用服务，包含HarmonyOS应用开发、OpenHarmony设备开发、OpenHarmony开发工具模板等。  

成为华为开发者联盟生态市场HarmonyOS专区商户需要符合以下条件：

1、符合国家/区域相关法律、法规规定、拥有正规的公司资质；

2、营业执照需要满1年，注册资金不低于50万；

3、能够提供成熟、专业的HarmonyOS应用或OpenHarmony硬件服务；

4、接受《[华为开发者联盟生态市场商户合作协议](https://terms-drcn.platform.dbankcloud.cn/agreementservice/developer/getAgreementTemplate?agrType=1172&country=cn&language=zh_cn&version=2026040701)》并按照协议相互约束的条款开展业务合作；

5、接受生态市场的相关协议及管理规范。  

#### 解决方案

围绕各个垂直行业的业务特征，打造标准化解决方案，为游戏、电商、金融、教育、物流、政务、多媒体、物联网、大数据等各类行业用户提供一站式的产品解决方案与服务。

成为华为开发者联盟生态市场解决方案商户需要符合以下条件：

1、符合国家/区域相关法律、法规规定、拥有正规的公司资质；

2、营业执照需要满2年，注册资金不低于50万；

3、具备整体解决方案的构建能力和涉及第三方系统的端到端管理能力，有成功可追溯的解决方案客户案例；

4、接受《[华为开发者联盟生态市场商户合作协议](https://terms-drcn.platform.dbankcloud.cn/agreementservice/developer/getAgreementTemplate?agrType=1172&country=cn&language=zh_cn&version=2026040701)》并按照协议相互约束的条款开展业务合作；

5、接受生态市场的相关协议及管理规范。
