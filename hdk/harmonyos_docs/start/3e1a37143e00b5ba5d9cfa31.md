# 管理已购服务

购买API服务后，您可以参考服务详情页右上角的API文档调用API。在API调用次数配额即将用尽时，您还可以选择再次购买。

## 筛选并查看

购买API服务成功后，您可以在已购服务列表筛选出API服务进行管理。

1. 在生态市场首页，点击首页右上角"买家中心"，点击左侧列表列"已购服务"，进入已购服务列表。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/32/v3/ocqCfm_-TH-QwD2lt3cS8A/zh-cn_image_0000001254461883.png?HW-CC-KV=V1&HW-CC-Date=20261008T151749Z&HW-CC-Expire=31536000000&HW-CC-Sign=C4F095F205A3BCBF87C3905626086CCD2577B4F19CF50AF920C1623134417BCD "点击放大")

2. 已购服务列表中的订单状态有开通中、开通失败、已开通、已过期4种。每种状态的含义如下：

   |**状态**|**含义**|
   |:-----|:----------------------------------------------------------------------------------------------------|
   |开通中|已购买但还未开通成功的订单。|
   |开通失败|已购买但是开通失败的订单，对于此状态订单您可以[重试开通](#section21971854205817)。如果持续开通失败，可联系商户反馈问题。|
   |已开通|已购买并开通成功的服务订单，您可以通过查看API文档使用服务。|
   |已过期|已购买开通但服务时间已到期的服务订单，您可以根据套餐类型选择[再次购买](#section1948182911283)服务。 > 说明 > 当您再次购买失败后，订单状态会分别变为"已过期（通知失败）"。|

3. 在已购服务管理页，可根据服务名称关键字搜索查找要处理的订单，点击服务订单左侧的 "服务名称"，查看服务基本信息、使用方式、当前规格、资源配额及相关订单。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5b/v3/8Y96v3jaRyibNGEJ2WbMFA/zh-cn_image_0000001296816690.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T151749Z&HW-CC-Expire=31536000000&HW-CC-Sign=835FB9BBA70461DF940E606CCD0A92669ABE57BF5409C13198992AE6D027948B "点击放大")

4. 已支付的API接入服务订单，不支持退款及订单验收，待支付订单不支持改价，可取消订单并删除订单。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bb/v3/D7Idm1g0QbWbuNocaFeEEw/zh-cn_image_0000002177302949.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T151749Z&HW-CC-Expire=31536000000&HW-CC-Sign=4D20EF9751C7D9E3E4E18F8B360568A27169CC358B7B6FEEA1CB2EE3730B8268 "点击放大")

## 使用API服务

您可以通过调用API或集成SDK的方式使用API服务，从而获取API商户提供的数据或资源。

1. 进入已购服务列表，点击"已开通"服务订单左侧"服务名称"进入服务详情页。
2. 点击右上角"查看API文档"，进入API文档。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/76/v3/eS5SdFENSmS7heSIfdOFXQ/zh-cn_image_0000001209831008.png?HW-CC-KV=V1&HW-CC-Date=20261008T151749Z&HW-CC-Expire=31536000000&HW-CC-Sign=383B41E744FED60073A1C1559F649D07FD74699E39339F27F39E1FDD8DD989CE "点击放大")

3. 查看API文档，并使用获取的访问Token调用。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f9/v3/ufZsmmblQbqWUKDpJV-O9w/zh-cn_image_0000001300630780.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T151749Z&HW-CC-Expire=31536000000&HW-CC-Sign=7D517D3BC37DE16F6F920D86EFC136570F34315BFF3B026CDAE78FCC36C04C45 "点击放大")
> 说明
>
> 通过集成SDK方式使用API服务前需要下载SDK后配合指导文档使用。
>
> 如果商户提供了API管理台，服务详情页右上角会展示"去管理"，点击跳转后可管理API服务。

## 再次购买

当您购买了包周期API服务且服务订单处于"已开通"或"已过期"两种状态时，您可以选择再次购买服务。购买方式如下：

1. 进入已购服务列表，选择并筛选出状态为"已开通"或"已过期"的服务订单，点击订单右侧"详情"进入服务详情页，点击右上角"再次购买"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2a/v3/skq_OTPvThamsQZjU0E_Qg/zh-cn_image_0000001300311376.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T151749Z&HW-CC-Expire=31536000000&HW-CC-Sign=45B24C56378D30CD03FB322B5936863FB23AB8DF29363CD091D81119111C7F01 "点击放大")
> 说明
>
> 如再次购买失败，您可以点击右侧"详情"，在详情页点击"重试通知"；若重试仍不成功，您可以点击"反馈问题"反馈。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cc/v3/uS2jKOhCTL2in8udpC2mvw/zh-cn_image_0000001255216197.png?HW-CC-KV=V1&HW-CC-Date=20261008T151749Z&HW-CC-Expire=31536000000&HW-CC-Sign=C6F686212D9A6D91EC61B5774DFF8295A4E196F772171D5BE74D64D2716408C8)

2. 在商品详情页，选择合适的套餐及规格等后进行再次购买，购买流程请参见购买服务[购买服务](https://developer.huawei.com/consumer/cn/doc/start/devmall-marketplace-cp-apiservice-purchase-0000001209810000)。

> 注意
>
> * 当您的API服务配额即将到期或已经到期时，生态市场会以邮件和短信的方式通知您，您可以在收到通知消息后再次购买。
> * API类接入服务同规则服务的0元套餐，只能购买一次，不可再次购买。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9c/v3/6_jbFt8EQOak4F9vOtjNAA/zh-cn_image_0000001349816829.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T151749Z&HW-CC-Expire=31536000000&HW-CC-Sign=ACD495F186BD75B26C0E5F5C5C574EC8828A4DE2CD57E282DCA68E5B4FB1679F "点击放大")

## 重试开通

当您购买服务成功但服务却开通失败时，您可以进入已购服务列表，点击状态为"开通失败"服务订单右侧的"详情"，点击"重试开通"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a9/v3/gDRCgaTMQfu867ua13nA9g/zh-cn_image_0000001209678786.png?HW-CC-KV=V1&HW-CC-Date=20261008T151749Z&HW-CC-Expire=31536000000&HW-CC-Sign=DC5ABF10714E416232121D57E67C27307D7209DFBA804881048EBBFCA2882A22 "点击放大")

点击后订单状态将会变为"开通中"，直到生态市场并刷新重试开通结果。如若您多次重试开通后仍失败，可以点击顶部的"反馈问题"，填写问题详情并提交后等待运维人员处理，也可以点击网站右侧的服务咨询填写问题表单。
