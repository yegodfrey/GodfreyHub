# 管理已购服务

购买API服务后，您可以参考服务详情页右上角的API文档调用API。在API调用次数配额即将用尽时，您还可以选择再次购买。

## 筛选并查看

购买API服务成功后，您可以在已购服务列表筛选出API服务进行管理。

1. 在生态市场首页，点击首页右上角"买家中心"，点击左侧列表列"已购服务"，进入已购服务列表。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/32/v3/ocqCfm_-TH-QwD2lt3cS8A/zh-cn_image_0000001254461883.png?HW-CC-KV=V1&HW-CC-Date=20260909T141903Z&HW-CC-Expire=31536000000&HW-CC-Sign=31CB02AE4E0F0D02BB64063B416F153708A0735E8C66A1FCD06AB87F8C6CF3BE "点击放大")

2. 已购服务列表中的订单状态有开通中、开通失败、已开通、已过期4种。每种状态的含义如下：

   |**状态**|**含义**|
   |:-----|:----------------------------------------------------------------------------------------------------|
   |开通中|已购买但还未开通成功的订单。|
   |开通失败|已购买但是开通失败的订单，对于此状态订单您可以[重试开通](#section21971854205817)。如果持续开通失败，可联系商户反馈问题。|
   |已开通|已购买并开通成功的服务订单，您可以通过查看API文档使用服务。|
   |已过期|已购买开通但服务时间已到期的服务订单，您可以根据套餐类型选择[再次购买](#section1948182911283)服务。 > 说明 > 当您再次购买失败后，订单状态会分别变为"已过期（通知失败）"。|

3. 在已购服务管理页，可根据服务名称关键字搜索查找要处理的订单，点击服务订单左侧的 "服务名称"，查看服务基本信息、使用方式、当前规格、资源配额及相关订单。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5b/v3/8Y96v3jaRyibNGEJ2WbMFA/zh-cn_image_0000001296816690.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T141903Z&HW-CC-Expire=31536000000&HW-CC-Sign=FB904916F0CFDF5103F373A944AEE94E3A1F038BF2C2A60629BB935A7D487EE0 "点击放大")

4. 已支付的API接入服务订单，不支持退款及订单验收，待支付订单不支持改价，可取消订单并删除订单。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bb/v3/D7Idm1g0QbWbuNocaFeEEw/zh-cn_image_0000002177302949.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T141903Z&HW-CC-Expire=31536000000&HW-CC-Sign=391A090873AAC8F135E3D1BD3396D4FE7BBAE9B1B16F23705BA62FEB2EC0AB25 "点击放大")

## 使用API服务

您可以通过调用API或集成SDK的方式使用API服务，从而获取API商户提供的数据或资源。

1. 进入已购服务列表，点击"已开通"服务订单左侧"服务名称"进入服务详情页。
2. 点击右上角"查看API文档"，进入API文档。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/76/v3/eS5SdFENSmS7heSIfdOFXQ/zh-cn_image_0000001209831008.png?HW-CC-KV=V1&HW-CC-Date=20260909T141903Z&HW-CC-Expire=31536000000&HW-CC-Sign=8B26B88DEB50A7A53CE3BE94BDB824039491C8DB4D77D75BEC9D6A5FF0E7DB6B "点击放大")

3. 查看API文档，并使用获取的访问Token调用。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f9/v3/ufZsmmblQbqWUKDpJV-O9w/zh-cn_image_0000001300630780.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T141903Z&HW-CC-Expire=31536000000&HW-CC-Sign=6205000964A55E0647AF1B483B5560C84BC9672CDFF9E0D01D7C071D9BFBE9F1 "点击放大")
> 说明
>
> 通过集成SDK方式使用API服务前需要下载SDK后配合指导文档使用。
>
> 如果商户提供了API管理台，服务详情页右上角会展示"去管理"，点击跳转后可管理API服务。

## 再次购买

当您购买了包周期API服务且服务订单处于"已开通"或"已过期"两种状态时，您可以选择再次购买服务。购买方式如下：

1. 进入已购服务列表，选择并筛选出状态为"已开通"或"已过期"的服务订单，点击订单右侧"详情"进入服务详情页，点击右上角"再次购买"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2a/v3/skq_OTPvThamsQZjU0E_Qg/zh-cn_image_0000001300311376.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T141903Z&HW-CC-Expire=31536000000&HW-CC-Sign=47C986375E74D05F6456C43357679A404BAB8992FAF4C0A4D2EBF9A0914982A6 "点击放大")
> 说明
>
> 如再次购买失败，您可以点击右侧"详情"，在详情页点击"重试通知"；若重试仍不成功，您可以点击"反馈问题"反馈。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cc/v3/uS2jKOhCTL2in8udpC2mvw/zh-cn_image_0000001255216197.png?HW-CC-KV=V1&HW-CC-Date=20260909T141903Z&HW-CC-Expire=31536000000&HW-CC-Sign=64F45CDC5CE708B594D057914DC1D65C7AE5E8E67030C92E3320592A67967FF5)

2. 在商品详情页，选择合适的套餐及规格等后进行再次购买，购买流程请参见购买服务[购买服务](https://developer.huawei.com/consumer/cn/doc/start/devmall-marketplace-cp-apiservice-purchase-0000001209810000)。

> 注意
>
> * 当您的API服务配额即将到期或已经到期时，生态市场会以邮件和短信的方式通知您，您可以在收到通知消息后再次购买。
> * API类接入服务同规则服务的0元套餐，只能购买一次，不可再次购买。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9c/v3/6_jbFt8EQOak4F9vOtjNAA/zh-cn_image_0000001349816829.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T141903Z&HW-CC-Expire=31536000000&HW-CC-Sign=9C52E6009F5554BFC4E1F3CF8400C2B7DAEAF503DE71D6F86C1715CC5F707282 "点击放大")

## 重试开通

当您购买服务成功但服务却开通失败时，您可以进入已购服务列表，点击状态为"开通失败"服务订单右侧的"详情"，点击"重试开通"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a9/v3/gDRCgaTMQfu867ua13nA9g/zh-cn_image_0000001209678786.png?HW-CC-KV=V1&HW-CC-Date=20260909T141903Z&HW-CC-Expire=31536000000&HW-CC-Sign=CFE060FAC1751C21D510C3C618700763F23E54E011DC1C245F2DAA1CAE81D543 "点击放大")

点击后订单状态将会变为"开通中"，直到生态市场并刷新重试开通结果。如若您多次重试开通后仍失败，可以点击顶部的"反馈问题"，填写问题详情并提交后等待运维人员处理，也可以点击网站右侧的服务咨询填写问题表单。
