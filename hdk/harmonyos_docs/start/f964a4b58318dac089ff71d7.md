# 界面说明

买家联系店铺客服的会话窗口如下图所示：

![](https://media:401788750494348057 "点击放大")

1. 您可以发送具体商品的链接给卖家，也可以在右侧浏览卖家店铺其他推荐商品。
2. 右侧导航栏可以查看"我的订单"和"店铺信息"。
3. 支持发送图片给卖家，主动点击对话输入框上方的"服务评价"也可以对本次咨询服务进行打分，点击"优惠券"可查看并领取该店铺当前的优惠券。

![](https://media:401788750494382058)  
会话窗口存在时效性，若您长时间未回复，系统会自动发消息提醒您，仍未回复系统会自动结束会话。
