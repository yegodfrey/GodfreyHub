# 华为合作伙伴后付费业务结算协议

下载查看：[《华为合作伙伴后付费业务结算协议》](https://terms-dra.platform.hicloud.com/agreementservice/developer/getAgreementTemplate?agrType=1240&country=cn&language=zh_cn&version=2021111201)

最后更新日期：2021年11月30日

本协议是您（以下又称"合作伙伴"）与华为订立的具备法律效力的协议。本协议为您与华为已订立的[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/start/agreement-0000001052728169)的补充协议，与其共同确立您使用华为服务的后付费业务结算（定义见下）所享有的权利和负有的义务。您点击本协议下方的"我同意"按键（或类似按键）或使用本协议下任何服务即视为自您接受或使用之日（"生效日期"）起对本协议的充分理解和完全接受。如果您不同意本协议，您应当停止使用本协议下的服务。

本协议未尽事宜，按照[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/start/agreement-0000001052728169)执行。如本协议条款与[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/start/agreement-0000001052728169)发生冲突的，仅在华为合作伙伴后付费业务结算的范围内，以本协议条款为准。  

#### 1. 定义

除非本协议另有规定，否则本协议中的术语与[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/start/agreement-0000001052728169)中的含义相同。如无特别说明，下列术语在本协议中的含义为：

1.1"合作伙伴"或"您"：指任何使用华为服务后与华为进行后付费结算的开发者。

1.2"后付费业务结算"：指您通过使用华为服务，向最终用户提供（包括但不限于展示、分发、推广和开发）您的产品和/或服务，并通过后付费的方式（信用卡支付除外）向华为支付华为服务使用费的行为。

1.3"项目子协议"：指您和华为签订的关于使用具体华为服务的协议。本协议未尽事宜（如：结算金额、保证金、账户信息、开票名称等），按您和华为签订的项目子协议执行；本协议条款与项目子协议条款不一致的，以项目子协议条款为准。  

#### 2. 后付费业务范围

后付费业务的范围包括但不限于如下交易模式：  

|交易模式|具体描述|
|:---|:------------------|
|CPA|按激活数量进行计费|
|CPC|按点击次数进行计费|
|CPM|按某一媒介或广告曝光千次的数量进行计费|
|CPD|按非更新成功下载次数进行计费|
|CPS|以某种类型收入为计算基数进行计费|
|CPL|按实际有效线索提交量进行计费|
|CPT|按时间段进行计费|
|CPI|按非更新成功安装次数进行计费|
|CPP|按装机数量进行计费|

#### 3. 结算要求

3.1 双方的结算方式采用月度结算。结算货币为人民币。

3.2 如您为付款方，您应当在华为开具发票后30个自然日内，将确认后的结算金额以银行汇款方式汇入华为指定账户。如果您未在约定期限内付款，华为有权按逾期天数及0.04%/天收取滞纳金或单方面终止合作。

3.3 信用管控：华为将在项目子协议中明确该子协议下的信用管控模式（1）保证金 或（2）保函。

（1）保证金：您应在相应项目子协议生效后三十（30）个自然日内，将该项目子协议中约定的保证金金额汇至华为指定银行账户。同时华为有权根据业务范围变化或您付款延迟等情况来调整保证金金额。您须在收到华为增补保证金书面通知后的七（7）个工作日内缴纳完成。如果您未在约定期限内缴纳保证金，华为有权单方面暂时中止相应项目子协议的履行或终止相应项目子协议；

如您逾期支付结算费用，华为有权在相应项目子协议下按您未付款金额（包含滞纳金）扣除保证金，并向您发出保证金补缴通知；

相应项目子协议终止时，华为在相应项目子协议约定的结算期结束后30个自然日内将保证金余额无息退还至您方指定银行账户，如遇国家法定节假日则顺延。

（2）保函：您应在相应项目子协议生效后三十（30）个自然日内向华为提供华为可接受的银行开具的、不可撤销的、见索即付的银行履约保函；同时华为有权根据业务范围变化或您付款延迟等情况来调整保函金额。您须在收到乙方增补银行保函书面通知后的七（7）个工作日内提供原保函的修改函或者新的保函，确保保函金额为调整后的金额。如果您未在约定期限内提供上述保函或保函的修改函，华为有权单方面暂时中止相应项目子协议的履行或终止相应项目子协议；

如您逾期支付结算费用，华为有权在相应项目子协议下按您未付款金额（包含滞纳金）扣除保函，并向您发出保函补缴通知；

如保函在有效期内被部分或全部索赔，您有义务在索赔日起七（7）个工作日内向华为提供由原担保银行开立的、将担保金额恢复至原担保金额的履约保函修改函，或提供新的履约保函。新的履约保函或履约保函的修改函必须保持有效至原到期日或变更后的到期日。华为在进行索赔后会向您发出银行保函补缴通知，但您无权以未收到华为通知为由拒绝上述义务。银行履约保函有效期不得早于协议结算终止时间；如双方拟在本协议到期后续约的，双方应在本协议到期前就履约保函延期或提交新的履约保函另行协商一致，由此产生的延期费用（如有）由您承担。  

#### 4. 税务与发票

4.1 所有向华为或您征收的税款由各方根据所在区域的适用税法/税务条例相应承担。

4.2 本协议下的所有结算金额均包括增值税、代扣税等相关税费。

4.3 您需要承诺提供的发票接受方主体和华为签约主体一致。此外，您应向华为提供正确的开票税务信息，如纳税人资质，税务登记号等，以便确定华为向您开具的增值税会发票类型（增值税专用发票/增值税普通发票）。华为作为善意第三人无法对您提供的开票信息进行复核。华为将依据收到的金额，对于属于华为应税范围的部分全额开具发票。如因您提供的税务信息错误，需重新开具发票，涉及发票退回的相关费用需由您承担。华为开具给您的发票内容和税率，根据华为向您提供的实际业务类型开具。  

#### 5. 协议终止

任何一方终止[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/start/agreement-0000001052728169)后，本协议将自动终止。任何一方终止本协议后，[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/start/agreement-0000001052728169)并不自动终止。  

#### 6. 分发区域与签约主体

本协议仅适用于[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/start/agreement-0000001052728169)附件A第I部分的业务区域为中国大陆地区的合作伙伴。您将与于中华人民共和国成立的华为软件技术有限公司签约。  

#### 7. 法律适用和争议解决

按照[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/start/agreement-0000001052728169)的"法律适用和争议解决"执行。
