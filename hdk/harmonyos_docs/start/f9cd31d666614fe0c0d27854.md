# 开具发票

需求方在购买定制化需求服务后，您需给用户开具发票。

生态市场目前不支持三方线上电子发票，所以需要商户线下给需求方邮寄发票。

1.登录卖家中心。

2.在左侧导航栏，点击开票管理。

![](https://media:401788750498334134 "点击放大")

3.在需求订单管理页，找到目标订单，点击处理发票。

![](https://media:401788750498389135 "点击放大")

4.填写发票代码和邮寄信息，点击确定。

![](https://media:401788750498455136 "点击放大")

5.发票状态为已开具，则开票完成。

![](https://media:401788750498688137 "点击放大")
