# 开具发票

需求方在购买定制化需求服务后，您需给用户开具发票。

生态市场目前不支持三方线上电子发票，所以需要商户线下给需求方邮寄发票。

1.登录**卖家中心**。

2.在左侧导航栏，点击**开票管理。**

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0b/v3/h0ELk3q7QKO8h8-JQjEheg/zh-cn_image_0000001349694497.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T131905Z&HW-CC-Expire=31536000000&HW-CC-Sign=A83AAC36D6F3FA4525102F1068CE8881E5F38EBBC6AC5762BB183B2E43B971A6 "点击放大")

3.在需求订单管理页，找到目标订单，点击**处理发票。**

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/aa/v3/VZwGzjsfQ4OyPr3oqqOFFw/zh-cn_image_0000001296815202.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T131905Z&HW-CC-Expire=31536000000&HW-CC-Sign=DC1A8519831D0CADB07B4F1FCD77049630A42A3719A191A243F0E3EEC9569225 "点击放大")

4.填写发票代码和邮寄信息，点击**确定**。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bc/v3/UfWwgwjJTWiA7-8r_VlXzg/zh-cn_image_0000001349815217.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T131905Z&HW-CC-Expire=31536000000&HW-CC-Sign=289060DBB2AA4761D3DD57C9B3A9DF20C6FDF02AD0FCE30F7105B979A234D049 "点击放大")

5.发票状态为**已开具**，则开票完成。
