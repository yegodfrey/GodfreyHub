# 开具发票

需求方在购买定制化需求服务后，您需给用户开具发票。

生态市场目前不支持三方线上电子发票，所以需要商户线下给需求方邮寄发票。

1.登录**卖家中心**。

2.在左侧导航栏，点击**开票管理。**

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0b/v3/h0ELk3q7QKO8h8-JQjEheg/zh-cn_image_0000001349694497.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T141927Z&HW-CC-Expire=31536000000&HW-CC-Sign=5524C58F6861446E0D57235D249D871575C538973283DE7F5F6D0BCFAC79F866 "点击放大")

3.在需求订单管理页，找到目标订单，点击**处理发票。**

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/aa/v3/VZwGzjsfQ4OyPr3oqqOFFw/zh-cn_image_0000001296815202.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T141927Z&HW-CC-Expire=31536000000&HW-CC-Sign=6A6935CD3162790BBE8201E1338DB435722C33F6691BFC3FD845BA6449860E87 "点击放大")

4.填写发票代码和邮寄信息，点击**确定**。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bc/v3/UfWwgwjJTWiA7-8r_VlXzg/zh-cn_image_0000001349815217.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T141927Z&HW-CC-Expire=31536000000&HW-CC-Sign=5E51FC5E725A3809928B8329587586848528C1D12103FEA9FA26476056520543 "点击放大")

5.发票状态为**已开具**，则开票完成。
