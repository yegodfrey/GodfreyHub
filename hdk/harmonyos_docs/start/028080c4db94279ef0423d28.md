# 人脸识别认证

人脸识别认证需要您在移动端（如手机）录制人脸信息、填写身份证号码信息进行个人信息验证，验证通过后返回PC端补充信息即可完成认证。

1. 点击头像下拉框中的"[去认证](https://developer.huawei.com/consumer/cn/verified/enrollment)"，进入"实名认证"页面。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202407.79206746183228831680590945674140:50001231000000:2800:52DE93198B33F109ED9D8FB79C0267714CBBF617B5806679468CC2D228AACE2E.png)

<!-- -->

2. 点击"个人开发者"图标或"下一步"，进入开发者类型选择页面。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202407.18737469908674194873535063416561:50001231000000:2800:549B3D5504CBCCDB0A92229C2DDD5B7005163B6E445608398E7983DCE7C40CB9.png "点击放大")

<!-- -->

3. 选择人脸识别认证，进入到人脸识别认证页面。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202407.40437977225862170498738311584760:50001231000000:2800:6F221A94C2BB372467CAE156597147CDC7E6D590452F6A187A34D6DD3D937C1D.png "点击放大")

<!-- -->

4. 点击图标获取人脸验证二维码。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202408.17140921263904513873476428718191:50001231000000:2800:43EA73834F6D5C022763EAEBD6F335C115EC129D228F40DEB0B662E5F8296015.png "点击放大")

<!-- -->

5. 使用华为浏览器或微信扫描二维码，并根据提示完成身份验证（二维码有效时间15分钟，请在15分钟内完成人脸验证）。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202408.59466969412156759032645473522454:50001231000000:2800:EF0E75312EF4CFE7B9ED9A82D9DBB82F1ACDBBB781859752297FEA79CC20A0AE.png "点击放大")

<!-- -->

6. 人脸验证通过后，返回PC端，补充信息，签署[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/start/agreement-0000001052728169)，点击"下一步"，认证完成（如页面提示系统异常，请您耐心等待，我们将在1个工作日内完成处理）。
