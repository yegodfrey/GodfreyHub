# 申请开票

您在生态市场订单支付完成后，可以在线上申请开具发票。开票信息中填写的企业（或个人）视为与生态市场进行实际交易的法律主体。

## 前提条件

客户必须先完善账户信息且进行实名认证后，才能开具发票。

## 注意事项

1. **在生态市场购买的商品，发票由对应的商户开具** （华为自营商品除外），具体支持开票类型，以和该商户沟通确认为准。
2. 订单交易的款项，若您使用企业网银支付，款项暂入到深圳市讯联智付网络有限公司（华为旗下子公司）的银行账户。订单确认验收后，您才可以向商户申请开票。
3. 发票抬头类型为企业时，才可开具增值税专用发票。
4. 生态市场只支持根据订单开票，发票金额不能自定义，需按照订单金额进行开票。

## 开票操作

1.登录**买家中心**。

2.在左侧导航栏，点击**订单。**

## 退换发票

1.退换生态市场发票仅包括在生态市场购买产品所开具的发票。

2.订单在开票后想要退票时，需将之前开具的纸质发票线下邮寄给商户。商户收到您寄回的发票后完成后续退票操作。

## FAQ答疑

### **1、发票类型有哪些？**

生态市场开具的发票类型有"增值税普通发票"和"增值税专用发票"，支持电子发票和纸质发票。具体购买商品订单支持的开票类型，以商户配置为准。

### **2、开具增值税专用发票时需要提供哪些信息？**

开具增值税专用发票时，需要在**添加发票抬头** 信息页面输入"抬头名称、税号、税务注册地址、注册电话（手机号/固话）、开户银行、开户银行账号"，信息请务必和贵司财务部门核实，确保信息准确。

### **3、使用网银支付的可以开专票吗？**

开票与支付方式无关，使用企业网银支付，在订单已完成后都支持开票。

### **4、开具发票有时间限制吗？**

无，您的订单在已完成状态时可以申请发票，不限制开票时间。

### **5、如何设置发票类型？**

生态市场开具的发票类型有"增值税普通发票"和"增值税专用发票"，支持电子发票和纸质发票。

* 增值税普通发票：若不具备一般纳税人资质的小规模纳税人，请选择增值税普通发票，所开具的发票不能用于进项税抵扣。抬头类型为个人或者组织时，只能创建发票类型为增值税普通发票的模板。


* 增值税专用发票：若具备一般纳税人资质，需要进行进项税抵扣，请选择增值税专用发票。
