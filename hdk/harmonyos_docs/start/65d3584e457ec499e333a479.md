# 生态市场处理的个人数据清单

本文档向使用了生态市场的客户（简称"客户"）说明客户作为数据控制者，华为作为数据处理者时，华为如何存储和处理客户的用户数据。

生态市场在提供服务时会处理您用户的个人数据， 下表列出了客户作为数据控制者，华为作为数据处理者时，华为如何处理最终用户的个人数据。

|**个人数据**|**使用目的**|**留存期**|
|:--------------|:--------------------------------------------------------|:-------------|
|UserId|UserId是最终用户在登录时的唯一标识符，用来区分不同的用户。|用户销户后立即删除|
|NickName（昵称）|NickName是用户设置后，在商户的订单列表，更容易区分买家。|用户销户后立即删除|
|店铺信息|商户通过店铺来发布商品，买家可以通过店铺来查看商户的所有的商品。|用户销户后立即删除|
|需求信息|买家发布众包需求，指定商户完成众包需求，或者商户在需求广场抢单完成众包需求。|用户销户后立即删除|
|需求手机号码|买家发布众包需求信息后，商户可以通过隐私号码，关联买家的手机号码，与买家沟通需求。|用户销户后立即删除|
|发票信息|买家申请开票信息，包括商业联系人联系信息（邮寄信息），账户标识 （纳税编码），税务账户注册信息（税务注册地址）等。|用户销户后立即删除|
|物流收货地址 联系号码 联系人|用于两个场景： 1、买家接收商户快递的发票信息； 2、买家接收商户快递的硬件类商品信息。|用户销户后立即删除|
|订单记录|买家在生态市场支付订单等信息。|用户销户后将保存七年后删除|
|财经类资料|保证金缴纳、充值/消耗等信息。|用户销户后将保存三十年后删除|
