# 团队账号FAQ

#### 开通团队账号功能需要哪些条件？

通过开发者联盟实名认证的企业或个人账号即可开通团队账号。  

#### 在哪里开通团队账号功能？

登录开发者联盟管理中心，在"开发者中心-团队账号"处点击添加团队成员即可。  

#### 开通团队账号功能后可以添加多少个团队成员？

目前添加团队成员上限为200个。  

#### 添加某位成员时，已达到最大限制，无法接收邀请？

每位华为用户最多可加入50个团队，达到上限无法接收邀请。  

#### 邮箱一直收不到邀请链接怎么办？

可通过联盟客服渠道-[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/ticketCard)，描述问题后，联盟工作人员会帮助您查询原因并提供激活链接。  

#### 如何修改团队账号中的账号角色、权限？

成员账号无法修改自己权限，只能联系账号持有者修改。  

#### 如何联系团队账号持有者？

登录团队账号管理中心-开发者中心-开发者信息处，可查询账号持有者的邮箱、手机等联系方式。  

#### 为什么成员账号登录后看到的服务比账号持有者的服务少很多？

当前联盟仅支持成员参与应用市场（付费推广、应用内付费除外）、流量变现服务和主题中心业务的操作。暂不支持成员独立结算及其他开放能力（如Push、账号、HUAWEI HiAI等）服务。  

#### 在团队账号所支持的不同业务中如何给角色分配不同的App权限？

在所有业务中，只有账号持有者可以设置、修改所有成员拥有哪些应用的访问权限，如果不需要对某个成员限制，使用默认值"所有App"即可。

* 系统管理（联盟管理中心）中除运营角色外，其他角色自动获取所有App访问权限，不支持修改。

* 应用市场中所有角色均可被设置不同的App访问权限。应用市场下的管理员、App管理员、法务角色邀请新成员账号加入本团队时，只能为被邀请者分配其所拥有的App权限。

* 流量变现服务中管理员角色自动获取所有App访问权限，不支持修改，其他角色的App访问权限可以被账号持有者限制。

* 主题中心业务不涉及App权限，所以角色均没有App访问权限。

#### 当弹窗显示需要账号持有者/法务签署相关协议时，账号持有者/法务应如何签署？

请账号持有者/法务登入管理中心或AppGallery Connect后根据相关弹窗提示进行签署。相关协议签署指导请点击[签署指南](https://developer.huawei.com/consumer/cn/doc/start/asg-0000001058696173)。  

#### 团队账号与账号组的区别是什么？

团队账号用于支持单一主体账号下面多个成员账号的登录与权限管理服务。成员账号可参与应用市场（付费推广、应用内付费除外）开发、运营、数据分析操作、鲸鸿动能流量变现服务中媒体展示位管理及相关报表等操作，帮助企业、团队成员共同协作完成开发、分发、商户服务、运营分析等工作。

账号组一般用于在不同的开发者账号/企业主体之间建立关联关系，但各开发者账号/企业主体之间的业务为独立运营。如您的业务为联运业务相关需求，则申请加入账号组的开发者账号，可以参与账号组专享的福利政策、活动；如您的业务为关联主体相关需求，则要求不同的企业主体之间为具有关联关系的法人或组织（当前，关联主体账号组仅支持中国大陆企业开发者使用）。
