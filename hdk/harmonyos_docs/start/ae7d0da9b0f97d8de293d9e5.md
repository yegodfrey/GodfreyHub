# 安全圈

**安全圈**（四川大学学生作品）

虚拟现实赋能安全教育，在游戏中掌握灾害逃生技能。

## 作品类型

公益类

## 入选情况

创新应用-成型APP类 **★★**

## 开发者

赵一燃、付铄雯、姜雨孜、李明辉、朱千奥

## 功能介绍

安全圈APP以山区环境为背景，模拟泥石流、山洪和滑坡三大山地灾害典型场景，并设定三种角色模式，分别为管理者、教师与学生，用户可以自主选择。

游戏中，用户将根据画面、语音等提示了解周围环境，随后借助手柄完成一系列主线和辅线任务，如选择逃生路线，或根据触发的关键人物、物品作出判断等等。游戏结束后，系统还会自动生成一份测评反馈报告，对游戏成绩进行科学评估，帮助用户巩固逃生知识、提升避险意识。

## 应用价值

2019年开发者们在四川省凉山彝族自治州喜德县进行调研，当地水土流失比较严重，泥石流灾害长期威胁当地居民的生命安全。触景生情的开发者们决定开发一款应用软件，来帮助以喜德县为典型代表的西南山地灾害多发地区的学校师生躲避灾害。

西南地区山地灾害多发，因灾致贫返贫已成为脱贫攻坚的痛难点，居民需要接受安全教育以便更好地防范灾害，但传统的安全教育存在形式化、效率低等问题；采用手机应用形式可以较低的人力、物力、时间成本完成安全教育，并且由于VR具有浸入性和真实性，使用者能身临其境般地感受到自然灾害所带来的紧张感和压迫感，从而提高心理承受能力。

## 实现路径

开发者利用前期在喜德县实地调研时无人机航拍得到的红莫镇中兴小学图片，使用3DMax进行建筑的3D建模，并使用Unity3d和华为VR的SDK进行编程与VR游戏开发，接入了华为VR Engine。使用者在使用本应用时，需要使用华为手机并连接华为VR GLASS方可使用本应用。

在APP的开发过程中，开发者们与华为技术专家一起成功解决了泥石流的特效难题；华为特别提供的HUAWEI VR Glass和手机还帮助他们快速完成了3D游戏版本到VR版本的转制。
