# 了解插件

HarmonyOS开发助手是一款专为HarmonyOS应用/元服务开发者设计的AI插件，支持在多个主流IDE（DevEco Studio、VS Code、HBuilderX）上安装使用。它以自然语言对话为核心交互方式，提供一站式生成元服务、小程序转元服务、三方库鸿蒙化以及一多适配能力，大大降低了HarmonyOS应用/元服务开发门槛。  

#### 主要功能

|功能模块|功能说明|
|:-------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[一站式生成元服务](https://developer.huawei.com/consumer/cn/doc/start/hosdevassistant-create-atomic-0000002588351378)|插件内置鸿蒙行业优秀实践，开发者无需具备丰富的编程经验，仅需通过文字输出需求指令，即可一站式生成开箱即用的元服务工程和代码，真正实现零基础友好开发。|
|[小程序转换元服务](https://developer.huawei.com/consumer/cn/doc/start/hosdevassistant-convert-atomic-0000002588511306)|* 微信/支付宝小程序转换ASCF元服务：插件通过封装DevEco Studio核心能力与ASCF转换引擎，轻松实现微信/支付宝小程序到ASCF元服务的代码自动转换，减少重复性适配工作。 * uni-app小程序转换鸿蒙元服务：支持通过对话方式，快速无缝地将uni-app小程序转换为鸿蒙元服务，降低入驻鸿蒙生态的成本。|
|[三方库鸿蒙化](https://developer.huawei.com/consumer/cn/doc/start/hosdevassistant-lib-hos-0000002618910941)|支持通过对话方式，快速将非鸿蒙版本的三方库鸿蒙化，供HarmonyOS应用使用。|
|[一多适配](https://developer.huawei.com/consumer/cn/doc/start/hosdevassistant-multidevice-0000002658443256)|一多适配是鸿蒙生态面向多终端提供的"[一次开发，多端部署](https://developer.huawei.com/consumer/cn/doc/best-practices/bpta-multi-device-overview)"（简称"一多"）的能力，旨在基于一套代码，让应用在不同类型的设备上都能正常运行并提供优质体验。传统适配工作需投入高昂人力，而使用本插件，开发者无需亲自进行复杂的手动编码，只需输入文字指令，插件便可快速为工程设计适配方案、完成适配代码的生成与验证，并输出清晰规范的适配报告，轻松解决多设备开发成本高、效率低的问题。|

#### 主流IDE平台支持说明

当前HarmonyOS开发助手的各个功能模块在DevEco Studio、VS Code和HbuilderX上的支持情况如下表所示。  

|功能||VS Code|DevEco Studio|HbuilderX|
|:-------|------------------|:------|:------------|:--------|
|一站式生成元服务||支持|支持|不支持|
|小程序转换元服务|微信/支付宝小程序转换ASCF元服务|支持|不支持|不支持|
|小程序转换元服务|uni-app小程序转换鸿蒙元服务|不支持|不支持|支持|
|三方库鸿蒙化||支持|不支持|不支持|
|一多适配||支持|支持|不支持|
