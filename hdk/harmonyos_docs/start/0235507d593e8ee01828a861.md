# 账号组冻结管理

## 冻结账号组

在进行定期审查账号组信息过程中，如果您的账号组存在以下违规行为，我们将对您的账号组进行冻结，同时账号组所有成员将接收到账号组冻结邮件通知：

1. 未如实申报名下持有的所有开发者账号。
2. 未如实申报子公司名下所有的开发者账号。
3. 未如实申报关联公司名下所有的开发者账号。
4. 其他违规行为，包括但不限于：违反[《关联主体服务协议》](https://terms-drcn.platform.dbankcloud.cn/agreementservice/developer/getAgreementTemplate?agrType=1329&country=cn&language=zh_cn&version=2026030501)或[《华为应用市场联运服务协议》](https://developer.huawei.com/consumer/cn/doc/app/20204)相关规定等。

## 冻结影响

当账号组被冻结后，账号组信息将处于失效状态，您之前所享有的基于有效账号组信息的相关福利政策、活动等也将失效。

## 解除冻结申请

如需对账号组进行解冻申请，账号组管理员可以通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)，附上申请理由以及相关材料证明（如补报关联开发者账号的截图证明等）提交解冻申请。

账号组管理员在线提交解冻申请后，工作人员将在5-7个工作日内完成审批，审批结果将通过邮件告知账号组所有成员。
