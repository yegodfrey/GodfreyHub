# 沟通需求

商户看到您的需求后，可以在需求广场进行抢单。抢单成功后，商户或平台运营会联系您沟通需求。定向需求商户可选择接受或拒绝。

需求发布后您可以查看商户响应情况。如已有商户响应，您可以查看联系方式主动联系商户并澄清自己的需求。

1. 登录**买家中心**。
2. 在左侧导航栏，点击**需求管理**。
3. 在需求列表中找到目标需求，当需求状态列显示为沟通中，即表示已有商户抢单（或定向需求已被指定商户接受）。您可以点击**联系商户** 查看商户联系方式澄清需求。
