# 商户退出

商户想要终止和生态市场的合作可以申请退出生态市场。在合作期间没有违反生态市场商户管理规范，退出后将会退回保证金。
> 注意
>
> 提交退出申请前，请商户完成自检工作，如因商户自身原因造成的业务订单未完成、发票未开具等情况，将影响到退出的办理进度，由此造成的退出进度延后，责任由商户承担。

## 商户自检操作流程

1. 登录生态市场[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)。
2. 自行检查是否有服务中的订单，是否有未开具发票的情况。如上述两种情况存在，则需要进行如下操作： （1）有未完成业务、订单：将业务、订单服务完成。

   （2）有未开具发票（二选一）：
   * 主动联系用户将发票开具完成。

   * 让用户邮件发送生态市场说明不需要发票。

> 说明
>
> * 请商户严格进行业务订单、发票开具的自检操作，如果有遗漏或没有自检直接发起退出流程，后经生态市场核实，将会严重拖后退出流程。

3. 邮件发送退出申请至**partner@huawei.com**，内容包含：服务商ID、店铺ID、营业执照扫描件、保证金银行汇款截图、 《华为开发者联盟生态市场商户退出资料》盖章（在签字处盖章以及骑缝章）扫描件。
> 说明
>
> * 《华为开发者联盟生态市场商户退出资料》需联系生态市场运营获取：partner@huawei.com。

4. 生态市场收到退出邮件后，核实订单和发票情况。审核通过后，商户店铺将被冻结，无法再执行店铺相关操作。

5. 店铺被冻结后，商户需将保证金收据原件寄回。

6、生态市场在收到退出申请邮件后，将回复邮寄地址。快递中需附上说明（包括但不限于）：退 xxx 保证金、服务商账号、公司名称。

请勿邮寄到付件。
