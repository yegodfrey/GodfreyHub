## 创建项目级凭证

使用 API前请先创建凭证。凭证有如下四种：服务账号密钥、OAuth 2.0 客户端ID、API密钥、应用级客户端ID，介绍如下：

1. **服务账号密钥：**通过机机账号实现服务器到服务器应用级身份认证。
2. **OAuth 2.0 客户端ID：**通过用户第三方授权，让您的应用有权访问用户数据（项目级）。
3. **API密钥：**通过简单的API密钥来标识您的项目，访问公开级别的数据，以便检查权限和访问情况。
4. **应用级客户端ID：**通过用户第三方授权，让您的应用有权访问用户数据（应用级）。该创建入口已经关闭，历史数据仍然可以使用。
