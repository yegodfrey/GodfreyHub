# 一站式生成元服务

插件内置鸿蒙行业优秀实践，开发者无需具备丰富的编程经验，仅需通过自然语言描述需求，即可在指定目录一站式生成开箱即用的元服务工程代码，真正实现零基础友好开发。同时，插件支持通过对话将生成的元服务直接推送至真机或者模拟器上运行，并完成编译打包。此外，插件面板还提供上架自检入口，方便您快速自查软件包问题，提高上架审核通过率。

## 前提条件

* 已[登录插件](https://developer.huawei.com/consumer/cn/doc/start/hosdevassistant-login-0000002588351354)。
* 已[完成插件的配置](https://developer.huawei.com/consumer/cn/doc/start/hosdevassistant-config-0000002588511280)。
* 如果需要运行到模拟器上，确保DevEco Studio已安装所需版本的模拟器。

## 生成元服务

本章节以VS Code为例描述如何生成元服务，在其他IDE上操作类似。

### 生成元服务工程

1. 在VS Code中打开一个空目录。
2. 进入插件界面，在左下角切换模式为"元服务生成"，并在对话框中输入类似下述提示语：生成一个元服务，并添加对元服务功能、布局详细要求的提示词。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/14/v3/XH4GZ-qSR6uVSBBALJg5Jg/zh-cn_image_0000002759757527.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=E2586AE686C50EE5FECAB64F158840FD5796081FFD01B545C5082AFF0F03060D)

3. 等待"待办清单"中各任务的执行完成。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d6/v3/gnW4BWm8SACtUaVH5tapPw/zh-cn_image_0000002759677423.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=701C1ED8DE197F2646F0F15E4314E39A84438609579E04E741AF7C3FE4D2412E)

### 会话中关联元服务并配置签名

元服务构建编译过程中，插件会自动引导您进行签名配置。

1. 如当前元服务工程尚未与AGC上的元服务关联，则对话框会先弹出关联元服务卡片。
   * 如AGC已存在待关联的元服务，选择元服务所属的团队以及元服务名称，点击"提交"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7f/v3/cVzHTl17SuGjxDVmvZDClA/zh-cn_image_0000002774773645.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=FF30DD8645BFB566ADF63D5586027BFDEE1FDBF347A808611DC1E273D96F1872)

   * 如需新建一个元服务进行关联，点击"新建应用"页签，选择团队、应用类型、应用名称和分类、项目，点击"提交"，新建应用成功且自动与当前元服务工程关联。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9c/v3/QG_Yx2GcQC2j0OT61W7_4Q/zh-cn_image_0000002774795093.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=5D16ECBC8D00FA71E6BB7C85A19D5C0A8092429C533C3A29426BD90EBAAECE2A)

   > 说明
   >
   > 插件当前也支持您[在工具面板关联应用](#section10191132374819)。
2. 元服务关联成功后，插件会与您确认配置的签名类型（调试签名/发布签名）。
   * 如后续需将元服务推送至真机运行调试，建议选择"调试签名"，插件将为元服务配置调试签名。 注意
     >
     > PC必须连接真机后才可配置调试签名。
   * 如后续计划直接打包元服务进行发布上架，建议选择"发布签名"，插件将为元服务配置发布签名。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/32/v3/KSuVfb6jQVuYpS0OUP5jYw/zh-cn_image_0000002743683080.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=765C13E20C893BC7ABC8B62AAFD2B3E2F21E1D3FA1B1A67774DBF7DEB6B10389)

## 在真机上运行元服务

1. 确保真机已与PC连接。
2. 确保元服务已配置调试签名。

   如未完成，可在对话框中输入"帮我创建调试签名"的提示语，插件将快速帮您完成签名配置，具体流程可参见[会话中关联元服务并配置签名](#section72401243163710)。 说明
   >
   > 插件当前也支持您[在工具面板配置签名](#section623214451435)。
3. 在对话框中输入类似下述提示语：将当前项目推包到手机运行。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/37/v3/YWXyrG9UQXKfDo7jm9OovQ/zh-cn_image_0000002772911179.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=91F4930CFFB1BCDE500BED839851355D716F7C1E6FCBD16C3AC8C85BFBFE0FCC)
4. 插件将元服务推送到连接的真机上运行。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/97/v3/c2WFAHj1QeiKIjuyQaNn1Q/zh-cn_image_0000002772756203.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=8BD2745B71400E89593B19CCE42CD9AE5601B4BE9740C3661CE66C68D9919D6C "点击放大")

   >
   > 插件当前也支持您[在工具面板配置签名](#section623214451435)。
2. 在插件对话框中输入类似下述提示语：帮我打包用于最终上架。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/83/v3/Ey3yWU-uTwKRRZfRjiy0RA/zh-cn_image_0000002658599996.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=25CAE377E3F9C98E87C75C77D82EB4142A94E2F0EFE2CC4010E2D0AC5A6BC08F)
