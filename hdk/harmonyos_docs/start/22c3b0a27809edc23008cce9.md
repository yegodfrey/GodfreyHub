# 一站式生成元服务

插件内置鸿蒙行业优秀实践，开发者无需具备丰富的编程经验，仅需通过自然语言描述需求，即可在指定目录一站式生成开箱即用的元服务工程代码，真正实现零基础友好开发。同时，插件支持通过对话将生成的元服务直接推送至真机或者模拟器上运行，并完成编译打包。此外，插件面板还提供上架自检入口，方便您快速自查软件包问题，提高上架审核通过率。

## 前提条件

* 已[登录插件](https://developer.huawei.com/consumer/cn/doc/start/hosdevassistant-login-0000002588351354)。
* 已[完成插件的配置](https://developer.huawei.com/consumer/cn/doc/start/hosdevassistant-config-0000002588511280)。
* 如果需要运行到模拟器上，确保DevEco Studio已安装所需版本的模拟器。

## 生成元服务

本章节以VS Code为例描述如何生成元服务，在其他IDE上操作类似。

### 生成元服务工程

1. 在VS Code中打开一个空目录。
2. 进入插件界面，在左下角切换模式为"元服务生成"，并在对话框中输入类似下述提示语：生成一个元服务，并添加对元服务功能、布局详细要求的提示词。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a1/v3/5WqqJlTUTBWMFdhy1MzIyw/zh-cn_image_0000002759757527.png?HW-CC-KV=V1&HW-CC-Date=20260915T115630Z&HW-CC-Expire=31536000000&HW-CC-Sign=F6CA4DA6D8AFF37693BEC1E59F842FC36A9A52E1E34EFECAAF86EE35D37D1F5D)

3. 等待"待办清单"中各任务的执行完成。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e6/v3/wp-puHSTQy2K2c-RbGsvJA/zh-cn_image_0000002759677423.png?HW-CC-KV=V1&HW-CC-Date=20260915T115630Z&HW-CC-Expire=31536000000&HW-CC-Sign=AAEF26D6254BC9EA19354E2538DA27617EC4A007DAFE1CFE508BDD8ED683FA72)

### 会话中关联元服务并配置签名

元服务构建编译过程中，插件会自动引导您进行签名配置。

1. 如当前元服务工程尚未与AGC上的元服务关联，则对话框会先弹出关联元服务卡片。
   * 如AGC已存在待关联的元服务，选择元服务所属的团队以及元服务名称，点击"提交"。
   * 如需新建一个元服务进行关联，点击"创建元服务"，插件将拉起AGC控制台页面，参考[关联新建的元服务](#section1758819298178)的步骤4-7创建元服务后，返回插件对话框选择创建的元服务即可。

   > 说明
   >
   > 插件当前也支持您[在工具面板关联元服务](#section10191132374819)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/43/v3/l2ev7MetSO-N8EfvxhmHoQ/zh-cn_image_0000002730237784.png?HW-CC-KV=V1&HW-CC-Date=20260915T115630Z&HW-CC-Expire=31536000000&HW-CC-Sign=395A2A3244B82B5F3904DE7ECC2FEAB03EFE24C3B829A0036667CBCF72871B27)
2. 元服务关联成功后，插件会与您确认配置的签名类型（调试签名/发布签名）。
   * 如后续需将元服务推送至真机运行调试，建议选择"调试签名"，插件将为元服务配置调试签名。 注意
     >
     > PC必须连接真机后才可配置调试签名。
   * 如后续计划直接打包元服务进行发布上架，建议选择"发布签名"，插件将为元服务配置发布签名。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d0/v3/DJKVm-71Qt-Az_Hi9wl7hg/zh-cn_image_0000002730077936.png?HW-CC-KV=V1&HW-CC-Date=20260915T115630Z&HW-CC-Expire=31536000000&HW-CC-Sign=914EFA5C89FBA2563C8686874D86BA11EEF58298D00DD38E8E3800D2A1033889)

2. 确保元服务已配置调试签名。

   > 插件当前也支持您[在工具面板手动配置签名](#section623214451435)，但强烈建议您使用插件自动帮您配置签名。

## （可选）在工具面板手动配置签名

您可以在插件配置页面，为元服务手动配置调试或发布签名。

   |参数|说明|
   |:----------|:-----------------------------------------------------------------------------------------------|
   |密钥名称|输入密钥名称。|
