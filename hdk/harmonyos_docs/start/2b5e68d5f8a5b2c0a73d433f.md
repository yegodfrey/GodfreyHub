# 在HBuilderX中安装

## 下载插件

在[DCloud插件市场](https://ext.dcloud.net.cn/)搜索HarmonyOS Dev Assistant下载。

## 搭建安装环境

请确保电脑配置满足如下要求：

* 操作系统：Windows/macOS
* HBuilderX：HBuilderX 5.07版本及以上
* DevEco Studio：DevEco Studio 6.1版本及以上
* Node.js：最低版本Node.js 18.x，推荐版本Node.js 20.x LTS

## 安装插件

1. 参考[HBuilderX插件安装方式](https://hx.dcloud.net.cn/Tutorial/PluginsInstall)安装插件。
