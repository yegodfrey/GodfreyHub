# 企业开发者场景指南

1. 注册华为开发者联盟账号，详细操作可参考[注册账号](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。
2. 实名认证为企业开发者：可参考[企业开发者实名认证](https://developer.huawei.com/consumer/cn/doc/start/edrna-0000001062678489)。
3. 生态市场为您提供了丰富的商品品类，您作为买家可以通过首页推荐和商品搜索功能寻找商品。详见[买家操作指南](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-userguide-0000001070424123)
4. 发布需求：生态市场下设子板块众包平台，为买家提供定制化需求的众包模式服务 ，如果在生态市场中找不到合适的商品，买家可以在众包平台发布[定制需求](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-crowdsourcing-0000001070585565)，商户可以承接该需求，为买家设定报价，完成定制化方案的交易。
5. 创建SDK：企业开发者账号登录后，点击"卖家中心"可直接进入卖家中心"SDK管理"页面。（创建好的SDK可直接发布，并在生态市场首页进行展示：在商品列表页无店铺跳转，也无"认证商户"标识）。

1) SDK内容信息填写规范请参考：[SDK审核指南](https://developer.huawei.com/consumer/cn/doc/start/sdk-review-guide-0000001913103001)
