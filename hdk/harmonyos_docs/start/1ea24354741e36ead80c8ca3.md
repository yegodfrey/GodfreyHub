# 付费服务

当您希望在自己的应用内集成并使用华为开发者联盟某项需要付费的开放能力（如超出免费额度的地图资源服务调用等）或使用平台推广服务（如应用市场应用推广、流量变现等）时，您需要开通付费服务并维护对应的发票信息。开通付费服务后，您可根据需要使用的业务类型进行费用的充值、使用及结算开票等。

## 开通付费服务流程（企业开发者）

## 开通付费服务流程（个人开发者）

登录[华为开发者联盟官网](https://developer.huawei.com/consumer/cn/)，点击"管理中心"，选择"开发者中心"，选择"付费服务"，完善您的联系人姓名、联系人电话和发票发送邮箱，阅读并同意《华为合作伙伴付费服务协议》后勾选复选框，进行提交。

## FAQ

### 付费服务开通流程是怎样的？

登录[华为开发者联盟官网](https://developer.huawei.com/consumer/cn/home)，在"管理中心 > 开发者中心 > 付费服务"中填写发票和邮寄信息后，点击"保存"，完成服务开通。

### 付费服务开通后，余额充值到账时间？

当天的充值一般下个工作日处理并到账。

### 付费服务开通后，余额充值最小金额和最大金额？

充值金额无多少限制，但金额数额应为整数。

### 付费服务开通后，余额是否支持信用卡充值？

暂不支持信用卡支付进行充值。

### 付费服务开通后，账户本月充值发票开具时间？

开发票时间：本月开上个月的发票，发票寄出时间在20号左右（节假日顺延），本月的发票下个月会为您开具寄出。

### 小规模纳税人如何申请充值发票？

其他资料不变，在上传小规模纳税人资格证书和税务登记证的地方也上传三证合一的营业执照即可。

### 充值发票开具后多久会过期？

发票在开出180天后才会过期。
