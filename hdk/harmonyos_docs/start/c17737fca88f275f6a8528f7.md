# 优惠管理

商户可开展优惠促销活动，目前生态市场支持设置的优惠促销类型有：优惠活动、优惠券、秒杀活动。本文将详细介绍操作步骤。

## 设置商品优惠活动

1. 登录生态市场[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)。
2. 进入**优惠管理**页面，点击"创建优惠"，进入优惠信息填写页面。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/86/v3/BBLNlIecQTKqcJm8Byks2A/zh-cn_image_0000001070456993.png?HW-CC-KV=V1&HW-CC-Date=20261008T150456Z&HW-CC-Expire=31536000000&HW-CC-Sign=2CB244323F4E8043651A3ABA3F9549E1C42E6E921414E1616639D6A8599E7266 "点击放大")

3. 根据页面提示填写：设置优惠商品及规格、优惠名称、优惠类型、优惠金额、优惠时间范围、优惠条件，确认信息无误后点击"保存优惠"即可。具体字段填写可参考下表： ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ee/v3/C76XG33xSGKzd2-ODS-aPA/zh-cn_image_0000001071085062.png?HW-CC-KV=V1&HW-CC-Date=20261008T150456Z&HW-CC-Expire=31536000000&HW-CC-Sign=60B1FD525D17E5359A190DBEDD5FAC6449C18819A53854774FF23A7AA083FF60 "点击放大")

   |**字段**|**描述**|
   |:-----|:-------------------------------------------|
   |设置优惠商品|选择需要设置优惠的目标商品及规格|
   |优惠名称|自定义设置优惠名称。该名称将展示在商品详情页的优惠信息里。|
   |优惠类型|满减：表示在商品原价基础上直接减价。 折扣：表示在商品原价基础上打折。|
   |优惠金额|满减：设置门槛金额和减免金额 折扣：设置折扣百分比|
   |优惠时间范围|设置优惠活动的开始时间和结束时间。 到开始时间时优惠自动生效，到结束时间时优惠自动失效。|
   |优惠条件|目前只有无条件享受：表示使用此优惠无额外的限制条件。|

   > 说明
   > * 单个商品及规格仅允许同时参与一个满减/折扣活动
   > * 设置满减优惠时，门槛金额不得超过商品原价，减免金额不得超过门槛金额
   > * 设置折扣优惠时，折扣百分比仅允许输入100以内的正整数

## 管理商品优惠

您可以对现有的优惠进行编辑、停用、删除等操作，实现对商品优惠的管理。

1. 登录生态市场[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)。

2. 在左侧导航栏，选择**优惠管理**。

3. 在优惠列表中，对目标商品进行相应操作。

|**操作**|**描述**|
|:-----|:-------------------------------|
|优惠管理|点击**操作** 列的**优惠管理**，然后修改相关信息。|
|停用优惠|点击**操作** 列的**关闭**，该优惠信息对所有用户不可见。|
|删除优惠|点击**操作** 列的**删除**，即可删除该优惠。|

2. 进入**优惠管理**页面，点击"创建优惠券"，进入优惠券信息填写页面。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9e/v3/4OuIk5wEQA2qUDJL_dq_MQ/zh-cn_image_0000001166216041.png?HW-CC-KV=V1&HW-CC-Date=20261008T150456Z&HW-CC-Expire=31536000000&HW-CC-Sign=3F00D8F9939126E0CA99B27985D21C22B560B6A7E8FBCEEA594EB7C49B5542C4 "点击放大")

2. 进入**优惠管理**页面，点击"创建秒杀"，进入页面填写秒杀活动的信息。
