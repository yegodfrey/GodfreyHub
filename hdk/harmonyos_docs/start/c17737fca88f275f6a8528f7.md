# 优惠管理

商户可开展优惠促销活动，目前生态市场支持设置的优惠促销类型有：优惠活动、优惠券、秒杀活动。本文将详细介绍操作步骤。  

#### 设置商品优惠活动

1. 登录生态市场[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)。
2. 进入优惠管理页面，点击"创建优惠"，进入优惠信息填写页面。

![](https://media:401788750486001933 "点击放大")

3. 根据页面提示填写：设置优惠商品及规格、优惠名称、优惠类型、优惠金额、优惠时间范围、优惠条件，确认信息无误后点击"保存优惠"即可。具体字段填写可参考下表： ![](https://media:401788750486056934 "点击放大")

   |字段|描述|
   |:-----|:-------------------------------------------|
   |设置优惠商品|选择需要设置优惠的目标商品及规格|
   |优惠名称|自定义设置优惠名称。该名称将展示在商品详情页的优惠信息里。|
   |优惠类型|满减：表示在商品原价基础上直接减价。 折扣：表示在商品原价基础上打折。|
   |优惠金额|满减：设置门槛金额和减免金额 折扣：设置折扣百分比|
   |优惠时间范围|设置优惠活动的开始时间和结束时间。 到开始时间时优惠自动生效，到结束时间时优惠自动失效。|
   |优惠条件|目前只有无条件享受：表示使用此优惠无额外的限制条件。|

   ![](https://media:401788750486080935)  
   * 单个商品及规格仅允许同时参与一个满减/折扣活动
   * 设置满减优惠时，门槛金额不得超过商品原价，减免金额不得超过门槛金额
   * 设置折扣优惠时，折扣百分比仅允许输入100以内的正整数

#### 使用商品优惠

1. 优惠创建成功后会出现在"优惠管理"页面的列表里，点击操作列的"启动"后，该优惠信息对所有用户可见。

![](https://media:401788750486139936 "点击放大")

2. 使用优惠效果如下图所示：

![](https://media:401788750486171937 "点击放大")  

#### 管理商品优惠

您可以对现有的优惠进行编辑、停用、删除等操作，实现对商品优惠的管理。

1. 登录生态市场[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)。

2. 在左侧导航栏，选择优惠管理。

3. 在优惠列表中，对目标商品进行相应操作。  

|操作|描述|
|:---|:----------------------|
|优惠管理|点击操作列的优惠管理，然后修改相关信息。|
|停用优惠|点击操作列的关闭，该优惠信息对所有用户不可见。|
|删除优惠|点击操作列的删除，即可删除该优惠。|

#### 设置优惠券

1. 登录生态市场[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)。

2. 进入优惠管理页面，点击"创建优惠券"，进入优惠券信息填写页面。

![](https://media:401788750486206938 "点击放大")

3.填写优惠券具体信息，注意优惠券与优惠活动是默认同时使用的。目前优惠券类型包括满减券、折扣券、代金券三种。

![](https://media:401788750486262939 "点击放大")

4.优惠券创建完毕后，可查看优惠券，或者选择停用优惠券。

![](https://media:401788750486308940 "点击放大")

5.此时优惠券已在店铺首页展示，买家可点击领取。

![](https://media:401788750486347941 "点击放大")

<br />

#### 设置秒杀活动

1. 登录生态市场[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)。

2. 进入优惠管理页面，点击"创建秒杀"，进入页面填写秒杀活动的信息。

![](https://media:401788750486378942 "点击放大")

3.选择参与秒杀活动的商品，并填写秒杀活动的具体信息。

![](https://media:401788750486422943 "点击放大")

4.创建完毕后，可查看商品的秒杀活动，或者停止该活动。

![](https://media:401788750486454944 "点击放大")
