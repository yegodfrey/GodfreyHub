# 企业开发者如何实名认证

企业开发者实名认证分为企业对公账户打款认证、企业资料人工审核认证、华为云授权认证三种方式。推荐您使用企业对公账户打款认证，对公账户打款认证简单易操作，认证时间相对较短。

企业对公账户打款认证和企业资料人工审核认证总体流程如下：

* 选择企业对公账户打款认证方式认证，详见：[对公银行打款认证](https://developer.huawei.com/consumer/cn/doc/start/atpopb-0000001062836624)（推荐）。
* 选择企业资料人工审核认证方式认证，详见：[企业资料人工审核认证](https://developer.huawei.com/consumer/cn/doc/start/mracoei-0000001062678404)。
* 选择华为云授权认证方式认证，详见：[华为云授权认证](https://developer.huawei.com/consumer/cn/doc/start/cloudqrz-0000001154842822)。
