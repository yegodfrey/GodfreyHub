# FAQ

**1、账号提示已实名认证，无法认证新的账号类型怎么办？**

答：如您之前已经实名认证为企业开发者，现在想重新认证为服务商，您可以：使用新的手机号码或者邮箱，注册全新华为账号后，[实名认证为服务商](https://developer.huawei.com/consumer/cn/reseller/account/profile)。

**2、如何添加子账号上架SDK？**

答：您可参考如下方式：

（1）团队账号能力仅针对2023年之前，以企业账号申请卖家身份的生态市场合作伙伴；

（2）认证为服务商的卖家，暂不能使用，有任何疑问可咨询：partner@huawei.com获得帮助。

**3、无法通过法人手持身份证认证方式完成认证怎么办？**

答：推荐对公打款方式认证，提供对公银行账号，确认打款信息完成认证。详见：[对公银行打款认证](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/sp_partner-hmos_develop_partner_guide-0000002101543573)

**4、上传excel/压缩文件提示存在风险怎么办？**

答：如您使用的是苹果MAC电脑压缩，会产生隐藏文件，请删除后重新上传。如需帮助，可联系生态市场官方邮箱：partner@huawei.com。

**5、保证金是什么？是否可以免缴？**

答：为了更好地保障华为开发者联盟生态市场用户的权益，提升生态市场商户的服务水平和商品质量。发布商品前，商户需缴纳保证金。未缴纳保证金的商户不得上架商品。如您针对保证金有疑问，可联系生态市场官方邮箱：partner@huawei.com获得帮助。

**6、获取方式为什么推荐ohpm坐标地址？**

答：为了给应用开发者提供更便捷获取您SDK的体验，快速将SDK添加到IDE工程文件中，同时也方便SDK包体的统一管理及维护，发布SDK时建议提交OpenHarmony三方库中心仓SDK获取地址。

SDK服务商构建及提供SDK时，建议：[采用字节码HAR方式](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V5/ide-hvigor-build-har-V5)，开启代码混淆及Release模式。

参考文档：[OpenHarmony三方库中心仓指南](https://ohpm.openharmony.cn/#/cn/help/publishrequirefile)

**7、SDK上传前需要进行签名配置吗？**

答：SDK签名配置为可选操作，若需签名请申请发布类型的证书进行SDK的签名配置，签名验证时请检查签名产物profile文件中type字段是否为release模式。详见：[签名指导文档](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-hvigor-build-har)

**8、【约束与限制】项如何填写？**

答：约束与限制即您SDK的版本号、最低API版本、目标API版本、编译API版本，可在对应工具及设备的"关于"介绍里查询。

参考文档：[应用开发过程使用的SDK版本](https://developer.huawei.com/consumer/cn/doc/harmonyos-releases/app-compatibility-influence-factor#section99881928838)
