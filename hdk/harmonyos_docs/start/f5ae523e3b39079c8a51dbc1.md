# 查询配额

## 功能介绍

用户使用API服务后，生态市场将调用本接口，查询剩余配额信息。

## 接口原型

|承载协议|HTTPS POST|
|----|-------------------------------------------------------------------|
|接口方向|华为服务器 -> 商户服务器|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 请求参数

**Body**

下表列出了请求Body中使用JSON格式携带商品信息，请求验签需要携带的URL参数请参见[安全校验规则](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-marketplace-spapi-autodeliveryprg-0000001380928181#section26527379136)。

|参数名||必选(M)/可选(O)|类型|描述|
|:-|-|:----------|:-----|:-----------------------------------------------------------------------------------------------------------|
|action||M|String|取值固定为getServiceQuota。|
|requestId||M|String|请求ID，每次请求均不相同。|
|apiClientId||M|String|API客户端ID，即clientid。|
|serviceCode||M|String|服务Code，详情请参见[术语表](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-terminology-0000001446432989)。|

## 响应参数

|参数名|必选(M)/可选(O)|类型|描述|
|:---------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------|
|retCode|M|String|调用结果码，结果码定义参见"[结果码](#section2124191573512)"。|
|retMsg|M|String|调用结果描述。|
|quotaInfos|M|[quotaInfos[]](https://developer.huawei.com/consumer/cn/doc/devmall-marketplace-spapi-queryquota-0000001245106317#ZH-CN_TOPIC_0000001245106317__table2238104145718)|总配额信息。|

**quotaInfos**

|参数名|必选(M)/可选(O)|类型|描述|
|:-------------|:----------|:-----|:------------------------------------------------------------------------------------------------------------|
|id|M|String|配额ID。|
|chargeItemCode|M|String|计费项Code，详情请参见[术语表](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-terminology-0000001446432989)。|
|usedAmount|M|String|当前已使用的配额数量。|
|totalAmount|M|String|总的配额数量。|
|effectTime|M|String|生效时间，Unix时间戳。|
|expireTime|M|String|过期时间，Unix时间戳。|

## 结果码

|结果码|含义|
|:-----|:---------------------|
|000000|成功|
|000001|鉴权失败|
|000002|请求参数不合法|
|000003|时间戳校验失败（请求时间与本地时间差异较大）|
|000099|其它服务内部错误|

## 示例代码

```screen
//处理请求
public Object dealQuota(String signature, String timestamp, String eventId, @RequestBody String requestString) {
        //处理请求超时
        if (new Date().getTime() - Long.parseLong(timestamp) > 30 * 60 * 60 * 60) {
            log.error("dealQuota fail. timestamp {} is invalid.", timestamp);
            return new CommonRet(ConstantRet.TIME_INVALID_CODE, ConstantRet.TIME_INVALID_MSG);
        }
        List<String> paraList = new ArrayList<>();
        paraList.add(timestamp)
        paraList.add(eventId);
        //验证签名
        String realSig = CommonUtil.hmacSha256Hex(paraList, CommonUtil.getDeliveryKey());
        if (!StringUtils.equals(realSig, signature)) {
            log.error(
                    "dealQuota verifySignature fail. para timestamp = {}, eventId = {}, signature = {}, RealSig = {}",
                    timestamp, eventId, signature, realSig);
            return new CommonRet(ConstantRet.VERIFY_CODE, ConstantRet.VERIFY_MSG);
        }
        //获取参数，GetQuotaReq是包含请求参数的数据类
        return apiService.getQuota(timestamp, eventId, signature, JSON.parseObject(requestString, GetQuotaReq.class));
    }

//发送响应
public GetQuotaRsp getQuota(String timestamp, String eventId, String signature, GetQuotaReq request) {
        GetQuotaRsp getQuotaRsp = new GetQuotaRsp();
        List<ApiAmountData> queryRsp =
            apiAmountMapper.queryApiAmount(request.getApiClientId(), request.getServiceCode());
        if (CollectionUtils.isEmpty(queryRsp)) {
            log.error("getQuota para fail. request = {}", request);
            getQuotaRsp.setRetMsg(ConstantRet.PARA_INVALID_MSG);
            getQuotaRsp.setRetCode(ConstantRet.PARA_INVALID_CODE);
            return getQuotaRsp;
        }
        List<UsedQuotaInfo> quotaInfos = new ArrayList<>();
        queryRsp.forEach(x -> {
            UsedQuotaInfo rsp = new UsedQuotaInfo();
            rsp.setEffectTime(String.valueOf(x.getEffectTime().getTime()));
            rsp.setExpireTime(String.valueOf(x.getExpireTime().getTime()));
            rsp.setId(x.getId());
            rsp.setChargeItemCode(x.getChargeItemCode());
            rsp.setTotalAmount(x.getTotalAmount());
            rsp.setUsedAmount(x.getUsedAmount());
            quotaInfos.add(rsp);
        });

        getQuotaRsp.setRetMsg(ConstantRet.SUCCESS_MSG);
        getQuotaRsp.setRetCode(ConstantRet.SUCCESS_CODE);
        getQuotaRsp.setQuotaInfos(quotaInfos);
        log.info("getQuota success para timestamp = {}, eventId = {}", timestamp, eventId);
return getQuotaRsp;
    }
```
