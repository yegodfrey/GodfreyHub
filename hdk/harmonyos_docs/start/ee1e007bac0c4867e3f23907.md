# 注册账号

华为开发者联盟为成员开发者提供丰富的技术能力与服务支持，包括但不限于开发工具、API接口、云资源等，全面赋能优质应用的创新与开发。开发者需先[注册](https://id1.cloud.huawei.com/CAS/portal/userRegister/regbyemail.html)华为开发者联盟账号，并完成[实名认证](https://developer.huawei.com/consumer/cn/doc/start/itrna-0000001076878172)流程，方可使用更多联盟提供的功能与服务资源。

## 注册账号

如果您已经有华为开发者联盟账号，可以[登录账号](#section3118151619304)进入华为开发者联盟。如果您没有华为开发者联盟账号，请按以下步骤注册：

1. 点击["注册"](https://id1.cloud.huawei.com/CAS/portal/userRegister/regbyemail.html)进入账号注册页面。
2. 您可以通过电子邮箱或手机号码注册华为开发者联盟账号。 注意
   >
   > 如您需要认证企业开发者账号，请使用企业的公共邮箱或公共手机号注册华为账号，避免个人账号信息与企业开发者信息绑定，影响账号后续使用。

   如果您使用电子邮箱注册，可以点击"邮件地址注册"按钮，输入正确的邮件地址和验证码，设置密码后，点击"注册"。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202406.25482072207362955422360429609579:50001231000000:2800:A99234D9C1AA331805386B377A48214831C4FCA3B9BAC1DC1D2FB06EDEB9B923.png)

   如果您使用手机号码注册，可以点击"手机号注册"按钮，输入正确的手机号码和验证码，设置密码后，点击"注册"。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202406.32220955116114475997174169843533:50001231000000:2800:E38953FE4A1865ED9A7078BABD2432AF4E7628F8128E77B1443B2FA4C70165E6.png)


3. 点击"同意"[《华为账号用户协议》](https://id1.cloud.huawei.com/AMW/portal/agreements/userAgreement/zh-CN_userAgreement.html?version=china)和[《关于华为账号与隐私的声明》](https://id1.cloud.huawei.com/AMW/portal/agreements/accPrivacyStatement/zh-CN_accPrivacyStatement.html)，完成账号注册。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202406.20680469257801531667533696369028:50001231000000:2800:7DF6816DF7F821951E8FCD6B26016B7FDBF6610E240806B2223470AAF29DD2B6.png)如果您使用电子邮箱注册，为了方便您后续找回密码，还需要您设置安全手机号。
