# 个人银行卡认证

银行卡认证需要您在实名认证页面提供银行卡卡号（支持信用卡及借记卡）、银行预留手机号及身份证号码信息进行信息验证。

1. 点击头像下拉框中的"[去认证](https://developer.huawei.com/consumer/cn/verified/enrollment)"，进入"实名认证"页面。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202409.17160180069879513289826605535243:50001231000000:2800:E43C31B72B5213DA3A806EC0394291E8D15A2735968C11863F9F6F3A9EAE651C.png)


2. 点击"个人开发者"图标或"下一步"，进入开发者类型选择页面。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202409.82950718756024026630525063627413:50001231000000:2800:FD6173E1D5276ABFED294EDEA097B4FA0FF201B6469F4B0FAE2997FBEFA267FF.png "点击放大")


3. 选择个人银行卡认证，进入到银行卡认证页面。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202409.18968676386506901399654923617693:50001231000000:2800:CC0CA0038EF0E329EA65BBCE5488E1F94524D4F67749679A585E7DB5A77EAC1C.png "点击放大")


4. 完善银行卡信息，如您填写的信息正确，点击"下一步"跳转到完善信息页面。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202409.74638634133162234115039217190635:50001231000000:2800:F6616776C430B72677CD0A91564E7A110DF521B43DBB08A02AC2D6326670DFA8.png "点击放大")


5. 完善个人信息，签署[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/start/agreement-0000001052728169)，点击"下一步"，完成认证（如页面提示系统异常，请您耐心等待，我们将在1个工作日内完成处理）。
