# 开发者知识MCP

#### 概览

鸿蒙开发者知识MCP服务（Model Context Protocol，简称MCP）基于标准模型上下文协议，为AI客户端提供鸿蒙官方开发者文档的实时检索与全文获取能力。接入后，您的AI客户端可随时调用官方最新的开发指南、API参考、上架规范等内容，无需本地维护语料，确保信息与官网同步。

当前服务提供两类核心工具，覆盖开发者知识查询的核心场景。  

|工具|说明|
|:---------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|searchDocuments|使用此工具，可查找有关鸿蒙开发者相关的最新官方文档，包括官方版本说明、API参考、开发指南、最佳实践、行业实践、FAQ、IDE指南、UX设计、应用上架及分发等内容。 此工具会返回匹配的文本块、名称和文档标识。如果返回的内容片段不够详细，无法回答用户的问题，请使用此工具返回的文档唯一标识parent，调用getDocumentsById工具来检索完整的文档内容。|
|getDocumentsById|使用此工具，可在一次调用中检索单个或多个文档（最多10个）的完整内容，文档唯一标识列表names为searchDocuments工具调用结果中所有parent字段列表。|

#### 获取MCP工具及其规范

如需获取鸿蒙开发者知识MCP服务当前可用的工具及其规范，可通过curl命令调用tools/list方法实现，参考如下示例。

```
curl --location 'https://connect-api.cloud.huawei.com/api/developerknowledge/mcp' \
     --header 'content-type: application/json' \
     --header 'accept: application/json, text/event-stream' \
     --data '{
          "method": "tools/list",
          "jsonrpc": "2.0",
          "id": 1
     }'
```

#### 使用指南

鸿蒙开发者知识MCP服务是一个远程MCP服务器。以DevEco Studio为例，在支持MCP协议的AI客户端中添加如下远程服务配置。

```
{
  "mcpServers": {
    "harmonyos_developer_knowledge": {
      "url": "https://connect-api.cloud.huawei.com/api/developerknowledge/mcp",
      "type": "http"
    }
  }
}
```

不同AI客户端的配置路径略有差异，具体请参考对应客户端的MCP配置文档。  

#### 语料库范围

包括鸿蒙官方版本说明、API参考、开发指南、最佳实践、行业实践、FAQ、IDE指南、UX设计、应用上架及分发等最新文档。  

#### 数据新鲜度

鸿蒙开发者知识MCP服务与鸿蒙开发者官网文档保持准实时同步。官网文档发布后，内容同步延迟不超过30分钟，确保调用获取的信息与官方最新发布内容一致。
