# 上架SDK说明

> 注意
>
> * 登录企业开发者账号/服务商账号后，点击"卖家中心"可在左侧导航栏"SDK管理"直接进入录入SDK页面。
> * SDK内容信息填写规范请参考：[SDK审核指南](https://developer.huawei.com/consumer/cn/doc/start/sdk-review-guide-0000001913103001)。

1. 在[伙伴SDK首页](https://developer.huawei.com/consumer/cn/market/landing/SDK)，登录企业开发者账号/服务商账号后，进入卖家中心。
2. 进入卖家中心后，选择"SDK管理"。
3. 点击"创建SDK"。
4. 填写SDK信息。

   |**发布项**|**发布标准**|
   |:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |SDK名称|1. SDK名称仅用于对SDK命名，介绍、版本、电话号码等与命名无关内容，请勿出现在商品名称中。 2. SDK名称应不少于10个字符不多于40个字符。 3. SDK名称中无需包含鸿蒙版、HarmonyOS SDK， HarmonyOS NEXT、鸿蒙端等字样，直接使用实际SDK名即可。|
   |SDK介绍|SDK一句话简介，字数应不少于60字符且不超过180字符|
   |SDK提供者|系统自动获取企业名称，如修改需提供关联证明。|
   |SDK图标|图片支持JPG/JPEG/PNG，尺寸为100x100px，大小不超过5M。|
   |SDK类别及子类|选择SDK所属的类别及对应子类，SDK类别查询请参考[《SDK分类示例（试行版）》](https://developer.huawei.com/consumer/cn/doc/start/sdk-classification-0000001867143762)。|
   |用户协议（非必填项）|1. 请上传SDK关联的协议或合同（SDK上架时关联的合同信息，），SDK必须与所关联的协议或合同一致。 2. 支持pdf、docx、zip格式（zip中只能包含pdf或docx），不超过10M。|
   |联系邮箱|填写真实可联系的邮箱。|
   |SDK详情|1. 填写的详情，应当包括但不限于：SDK功能介绍（必填）、提供商介绍（必填）、核心优势（必填）、约束与限制（必填）、成功案例（选填）（缺少必填项可能会被驳回，可参考：[SDK审核政策](https://developer.huawei.com/consumer/cn/doc/start/sdk-gallery-policy-0000001913021977)）。 2. 应当保持字体、字号、字色一致，排版要规范，不能出现明显的空格、换行等不合理排版问题，保持页面信息整齐美观。 3. 支持插入图片和视频，图片支持JPG/JPEG/PNG格式，最大宽度不超过900px、每张图片大小不超过5M，如详情内容仅有图片或截图，没有文字说明，则驳回。 4. 避免使用广告法敏感词，如：国家级、最佳、极致、世界第一等。 5. SDK会提供富文本内容，需按照提示内容进行填写，如不按照提示填写，可能会被驳回。|
   |SDK及其接口文档|> 说明 > 1、支持单独/批量添加SDK版本（如v1.0、v2.0等），每个版本需提交对应说明文档等必要信息； > 2、支持已上架SDK版本更新：通过编辑入口进入，添加新增版本号（如原v1.0基础上新增v1.1），新版本需补充对应的说明文档等必要信息，历史版本信息保留展示。 1、填写SDK包名：如果SDK上架到OHPM仓库，则为仓库坐标名，一般等同于HarmonyOS模块中oh-package.json5文件中定义的name字段。 2、填写SDK版本号：如果SDK上架到OHPM仓库，则为仓库坐标版本号，一般等同于HarmonyOS模块中oh-package.json5文件中定义的version字段。 3、版本更新说明：根据SDK版本的实际变更情况，填写内容。 4、填写SDK的发布时间，以SDK服务商官网正式公告日期为准。 5、填写SDK获取地址： a.如果SDK上架到OHPM中心仓，OHPM地址为自动校验填充，无需填写； b.如果SDK上架到OHPM企业自建仓库，则填写OHPM企业自建仓库地址； c.如果SDK托管到企业自有网站，建议提供官网SDK HarmonyOS版本的介绍页链接。 6、SDK包是否签名：确认SDK签名状态，根据实际打包情况勾选"已签名"或"未签名"。 7、填写是否在全国SDK管理平台登记：根据实际情况，选择"已登记"或"未登记"。 8、上传接口文档：支持.docx/.pdf格式，不超过10M，如无文件可提供有效外链。 > 说明 > 接口文档须包含以下内容：接口名称、调用方式、请求参数、返回参数、调用示例、错误码。 9、上传SDK Demo：支持zip格式，不超过100M。 10、上传使用指南：使用指南需区别于接口文档，请提供有效的SDK集成使用指导，格式统一、美观规范，支持pdf/docx/zip（≤10M，zip内须仅含pdf/docx），如无文件可提供有效外链。 11、权限与隐私：针对权限名称、权限说明、权限使用目的及操作进行详细填写。 > 说明 > **【敏感权限范围】HarmonyOS NEXT定义的user_grant权限**：包括位置、相机、麦克风、图片和视频、音乐和音频、通讯录、日历、运动数据、蓝牙、星闪、身体传感器等。 > **提示：** user_grant权限可能随操作系统版本更新发生变化，当前系统支持权限组请参考[应用权限组列表](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V5/app-permission-group-list-V5)。 12、是否涉及处理个人数据：请根据SDK实际功能情况填写是否涉及处理个人数据，若未涉及则隐私政策及合规使用指南为非必填项。 13、隐私政策：请填写对应SDK的隐私政策链接，[SDK隐私政策规范性参考](https://developer.huawei.com/consumer/cn/doc/start/sdk-privacy-policy-specifications-0000001867303626)。 14、合规使用指南：请填写对应SDK的合规使用指南，支持上传pdf/docx/zip格式（≤10M，zip内须仅含pdf/docx），如无文件可提供有效外链，[合规使用指南规范性参考](https://developer.huawei.com/consumer/cn/doc/start/sdk-compliance-specifications-0000001913103017)。|

5.SDK预检

SDK预检旨在提升SDK审核通过率，结合模型对SDK高频出现的问题进行系统性的预先检测并提供修改意见，可大幅降低上架时间成本，建议企业开发者对SDK自主预检后再进行SDK发布。

a. 填写完所有SDK信息后，选择【保存】，系统将弹窗提示"已保存，请在未上架SDK列表内，点击【操作】里的【预检】按钮对已添加SDK版本进行预检"；点击【确认】后，将进入到未上架列表；在未上架列表点击【操作】里的【预检】按钮进入预检页面。

b. 填写完所有SDK信息后，选择【编辑发布】，系统将弹窗提示"建议先完成预检以提升上架审核通过率（直接发布将中断进行中的预检），是否确认发布？"；点击【确认】后，将提交审核并进入到审核列表；点击【取消】将回到商品信息填写页面，可选择【保存】，在未上架列表点击【操作】里的【预检】按钮进入预检页面。
