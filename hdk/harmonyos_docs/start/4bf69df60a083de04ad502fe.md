# 账号组介绍

账号组是开发者联盟为已实名的开发者提供的一项服务，账号组一般用于在不同的开发者账号/企业主体之间建立关联关系，但各开发者账号/企业主体之间的业务为独立运营，您可以邀请您企业主体所有关联的开发者账号加入账号组。

当前，账号组类型分为关联主体账号组及联运服务账号组。

如您的业务为关联主体相关需求，则要求不同的企业主体之间为具有关联关系的法人或组织。

为确保定义的准确性与业务场景的匹配度，"关联关系"一词的含义将根据其适用的具体业务场景而有所不同，具体如下：

一般场景下，"关联关系"指：

（1）直接或间接具有绝对控股关系（例如拥有50%的投票权）的实体之间，例如母公司与子公司；

（2）满足直接或间接受同一实体控股条件的实体之间，例如子公司与子公司；

（3）申请绑定的实体之间应当有一定的业务相关性。

当您的业务适用的华为服务协议或相关规则中对关联关系另有约定的（例如华为数字商品及联运服务），以对应服务协议或相关规则中的约定为准。

定义适用原则：开发者在特定业务场景下，应依据上述对应场景的定义进行判断和承诺，请您注意查看对应服务协议或相关规则。华为有权根据业务实质判断具体服务所属的场景，并适用相应的定义。

如您的业务为联运业务相关需求，则申请加入账号组的开发者账号，可以参与账号组专享的福利政策、活动。

创建账号组主要流程如下：

1. 主账号创建账号组。
2. 主账号添加成员账号。
