# 购买服务

SaaS（即Software as a Service）服务，为一种通过网络提供的软件服务。您可以在精选应用服务购买SaaS服务后，使用商户提供的免登地址使用SaaS服务。

## 前提条件

* 如果您没有华为开发者联盟账号，需要先注册账号并通过实名认证。详细操作请参见[账号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。
* 请确保您已[开通付费服务](https://developer.huawei.com/consumer/cn/doc/start/payment-service-0000001052865979)。

## 购买SaaS服务

1、在生态市场找到想购买的SaaS商品，点击进入商品详情页。

2、购买服务前，您可以参考服务详情中服务描述、服务价格、使用指南等信息后购买。当前SaaS服务提供了按年、按月、按次等多种售卖方式，选择所需的规格和套餐后，勾选相关协议后点击购买。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7f/v3/FPQ9znnAQtS_7j50w6MN8A/zh-cn_image_0000002477439386.png?HW-CC-KV=V1&HW-CC-Date=20260909T141410Z&HW-CC-Expire=31536000000&HW-CC-Sign=08E63F354900C226BF5486ABE7DDBFD3C64463277B28C5A3C04613E749BC5609 "点击放大")

3、进入订单支付页，确认订单后支付即可。

4、服务购买成功后，您可进入买家中心查看。
