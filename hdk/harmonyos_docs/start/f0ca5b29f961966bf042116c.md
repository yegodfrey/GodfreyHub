# 术语表

下表详细解释了生态市场涉及的专业术语信息：

|术语|解释|
|:-----|:------------------------------------------|
|openId|当商户的商品接入生态市场且用户购买后，生态市场给用户分配的用户标识。|
|计费项|即服务的计费项，比如短信服务的定价如果为1元/条，则短信发送条数即为计费项。|
|客户端ID|即clientid，生态市场为购买API服务用户生成的API访问凭据。|
|服务Code|当商户的服务在生态市场上架后，生态市场为服务分配的Code。|
|商品Code|当商户的服务下的商品在生态市场上架后，生态市场为服务下的商品分配的Code。|
|线索|开发者在尝试购买、咨询服务等过程中表现出的可能对某一个服务有购买或使用意愿的行为痕迹。|
