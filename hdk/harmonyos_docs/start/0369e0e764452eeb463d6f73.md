# 在DevEco Studio中安装

## 下载插件

[点击](https://plugins.jetbrains.com/plugin/32572-harmonyos-dev-assistant)下载插件。

## 搭建安装环境

请确保电脑配置满足如下要求：

* 操作系统：Windows/macOS
* DevEco Studio：DevEco Studio 6.1版本及以上
* Node.js：最低版本Node.js 18.x，推荐版本Node.js 20.x LTS（如需使用多设备适配功能，最低版本须为Node.js 22.x）

## 安装插件

1. 启动DevEco Studio，在顶部菜单栏选择"File > Settings"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6b/v3/7HqVKS1LRnWIjphPC4YTMw/zh-cn_image_0000002688599577.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=0C2441886CB5C6689CAB1E4EFFFF20552C2E41FA0061B519F83C41FB1207B825)

2. 选择"Plugins"选项卡，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/88/v3/FJJGhS6yRL2KOxuxqvPEWw/zh-cn_image_0000002658440040.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=A903A28ED10D4E9A08D594B7DD2D23740B748E00B590A3C679AECA0D3F2F8D35)，选择"Install Plugin from Disk..."。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7d/v3/MTvmXvS7Trqcmk8TQAVAIA/zh-cn_image_0000002658440038.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=ACF1F38598535CFD2DA8D975B2E33C965804B3A15BAA14B954BDA57EE806B2CD)
