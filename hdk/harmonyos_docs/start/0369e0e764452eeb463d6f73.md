# 在DevEco Studio中安装

#### 下载插件

[点击](https://plugins.jetbrains.com/plugin/32572-harmonyos-dev-assistant)下载插件。  

#### 搭建安装环境

请确保电脑配置满足如下要求：

* 操作系统：Windows/macOS
* DevEco Studio：DevEco Studio 6.1版本及以上
* Node.js：最低版本Node.js 18.x，推荐版本Node.js 20.x LTS（如需使用一多适配功能，最低版本须为Node.js 22.x）  

#### 安装插件

1. 启动DevEco Studio，在顶部菜单栏选择"File \> Settings"。 ![](https://media:901788320231385130)

2. 选择"Plugins"选项卡，点击![](https://media:901788320231418131)，选择"Install Plugin from Disk..."。

   ![](https://media:901788320231455132)
3. 在弹出的文件选择窗口中，选择未解压的插件包，点击"OK"。 ![](https://media:901788320231499133)

4. 点击"OK"。 ![](https://media:901788320231551134)

5. 在DevEco Studio右侧边栏，点击"HarmonyOS Dev Assistant"，打开HarmonyOS开发助手登录界面。 ![](https://media:901788320231592135)
