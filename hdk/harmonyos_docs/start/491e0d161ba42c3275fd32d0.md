# 发布需求

生态市场下设子板块众包平台，为买家提供定制化需求的众包模式服务 ，如果在生态市场中找不到合适的商品，买家可以在众包平台发布定制需求，商户可以承接该需求，为买家设定报价，完成定制化方案的交易。

生态市场众包平台支持发布以下种类的需求。

## 发布普通需求

在需求广场---发布需求，该需求对所有的商户和需求方可见。具有对应服务资质的商户均可对该需求进行响应，并提交相应的方案。您可以将多家方案进行对比，然后选择最优方案。

1. 进入[需求广场页面](https://developer.huawei.com/consumer/cn/market/demandsquare)，点击发布需求。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bb/v3/rQfyFcNvQYiZpaAKVbWCIA/zh-cn_image_0000002684244625.png?HW-CC-KV=V1&HW-CC-Date=20260909T162857Z&HW-CC-Expire=31536000000&HW-CC-Sign=D9FEC5BF5E1A9FE3056DF6D83C1B928DFA810AAC17FA0967EE615C269C3E5D56 "点击放大")

2. 填写需求相关信息，阅读并选中**同意** 《华为开发者联盟生态市场用户协议》**，** 然后点击**发布**。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/48/v3/Nn4P8qrgSTyLaqfrlPoVnQ/zh-cn_image_0000001129924257.png?HW-CC-KV=V1&HW-CC-Date=20260909T162857Z&HW-CC-Expire=31536000000&HW-CC-Sign=EF7C9F8C9E1C516805EC7511D963CB9FA5906BB0080B8E7C18F43483E255D644 "点击放大")

|**参数**|**描述**|
|:--------|:---------------------------------------------------------------------------|
|选择您的需求类型|按实际情况选择一级需求类型。|
|选择您的需求子类型|按实际情况选择二级需求类型。|
|一句话需求|简要描述您的需求。|
|（可选）描述需求|按照界面提示详细描述您的需求。|
|预算范围|在列表中选择您的预算区间。|
|（可选）服务地域|在列表中选择您的服务地域。|
|（可选）需求文件|按实际情况上传zip格式/不超过10M的需求文件，详细澄清您的需求。|
|联系手机号|输入您的联系手机号获取验证码，然后点击确认，商户响应该需求后将通过该手机号码联系您。如您未填写联系方式，将在商户接单后，由平台运营与您联系建立需求沟通。|

> 说明
>
> * 如您未注册登录，点击**发布** 将先跳转至华为开发者联盟网站进行注册登录，具体操作要求请参见[注册登录](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。
> * 如您未进行实名认证，将先跳转至华为开发者联盟进行开发者实名认证，具体操作要求请参见[实名认证](https://developer.huawei.com/consumer/cn/doc/start/rna-0000001062530373)。

## 发布定向需求

在特定商户店铺首页发布需求，仅对该商户可见，其他商户不会看到您发送的需求信息。

1. 进入[商户列表页](https://developer.huawei.com/consumer/cn/market/shop-list)，点击商户。

2.根据行业选择筛选，或者搜索目标商户。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/39/v3/yfvkwJ5iSmSqTtg-PTBCTA/zh-cn_image_0000002654405006.png?HW-CC-KV=V1&HW-CC-Date=20260909T162857Z&HW-CC-Expire=31536000000&HW-CC-Sign=EECBD127B28144020FD7169731C10167A122FA13AA24736D43F209536112CC7D "点击放大")

3. 进入店铺后，点击"定制需求"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/87/v3/jfvwHvflTaKGLinen5rB_A/zh-cn_image_0000002592761290.png?HW-CC-KV=V1&HW-CC-Date=20260909T162857Z&HW-CC-Expire=31536000000&HW-CC-Sign=AC64011C8E1A15DF25ED104783A13BBA2EBC52E59D4B531624E0C23C677754CF "点击放大")

4. 填写需求相关信息，阅读并选中**同意** 《华为开发者联盟生态市场用户协议》，然后点击**发布**。

|选择您的需求子类型|按实际情况选择二级需求类型。|
|一句话需求|简要描述您的需求。|
|（可选）详细描述您的需求|按照界面提示详细描述您的需求。|

5. 提交需求后，您可以登录**买家中心**，在需求管理页面查看已发布的需求。
