# 登录插件

使用HarmonyOS开发助手，需要使用[已实名认证](https://developer.huawei.com/consumer/cn/doc/start/rna-0000001062530373)的华为开发者账号登录。本章节以VS Code为例描述如何登录插件，在其他IDE上登录操作类似。

1. 点击插件主界面"华为账号登录"按钮。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/49/v3/HfFTQHfWS6ijXGoFRIWc9A/zh-cn_image_0000002719975553.png?HW-CC-KV=V1&HW-CC-Date=20260924T082630Z&HW-CC-Expire=31536000000&HW-CC-Sign=C6156CBD120D43F9FEEACEC4D13698AC5FF9F25175484E5E4F68DF6D1E0F780B)

2. 在弹出的账号登录页面，输入已实名认证的华为开发者账号信息完成登录。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/dc/v3/n7JP0hWiTdWgEqEavicf2w/zh-cn_image_0000002658599980.png?HW-CC-KV=V1&HW-CC-Date=20260924T082630Z&HW-CC-Expire=31536000000&HW-CC-Sign=1A65C539BB0D504DA9E5FAFE9232ED68D68E2AB005B7CED118257EF000188E1B)

3. 返回编辑器，此时若当前账号团队尚未签署插件相关隐私声明与使用条款，点击蓝色链接阅读协议内容后点击"同意"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/96/v3/F-0Fai3lSASbshwKheflrA/zh-cn_image_0000002690136440.png?HW-CC-KV=V1&HW-CC-Date=20260924T082630Z&HW-CC-Expire=31536000000&HW-CC-Sign=AD19D01476AA2F8562AF2628946889619E30F760D84E15570B6AA0389DD4CBFF)

4. 进入主界面，接下来您需要先[对插件进行必要配置](https://developer.huawei.com/consumer/cn/doc/start/hosdevassistant-config-0000002588511280)，方可正式使用插件。
