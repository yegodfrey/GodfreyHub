# 登录插件

使用HarmonyOS开发助手，需要使用[已实名认证](https://developer.huawei.com/consumer/cn/doc/start/rna-0000001062530373)的华为开发者账号登录。本章节以VS Code为例描述如何登录插件，在其他IDE上登录操作类似。

1. 点击插件主界面"华为账号登录"按钮。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5a/v3/UvzowqsyTV2YmzCwH77xwA/zh-cn_image_0000002719975553.png?HW-CC-KV=V1&HW-CC-Date=20260915T115630Z&HW-CC-Expire=31536000000&HW-CC-Sign=B554F4E86DF38B3DD2BCBB5E453B3246323C16545504E0801108D3FF2476D2AB)

2. 在弹出的账号登录页面，输入已实名认证的华为开发者账号信息完成登录。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7c/v3/x8YOp4DvTei_c79Uq11IPQ/zh-cn_image_0000002658599980.png?HW-CC-KV=V1&HW-CC-Date=20260915T115630Z&HW-CC-Expire=31536000000&HW-CC-Sign=C06AE08F827922BF1BA1907624F7AA25F907AD9FF0483FE6B3DC4F96752F0C0E)

3. 返回编辑器，此时若当前账号团队尚未签署插件相关隐私声明与使用条款，点击蓝色链接阅读协议内容后点击"同意"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/50/v3/AhVEnsQuR0mWMV5IBXTdqw/zh-cn_image_0000002690136440.png?HW-CC-KV=V1&HW-CC-Date=20260915T115630Z&HW-CC-Expire=31536000000&HW-CC-Sign=AC9C05D28D852A9EA43F6E8D9A2AE39A4DA3F3921A6FE48D280DECDC648F9B7A)

4. 进入主界面，接下来您需要先[对插件进行必要配置](https://developer.huawei.com/consumer/cn/doc/start/hosdevassistant-config-0000002588511280)，方可正式使用插件。
