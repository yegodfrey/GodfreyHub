# 登录插件

使用HarmonyOS开发助手，需要使用[已实名认证](https://developer.huawei.com/consumer/cn/doc/start/rna-0000001062530373)的华为开发者账号登录。本章节以VS Code为例描述如何登录插件，在其他IDE上登录操作类似。

1. 点击插件主界面"华为账号登录"按钮。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/49/v3/HfFTQHfWS6ijXGoFRIWc9A/zh-cn_image_0000002719975553.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=7B13E53871CDAA01328D33C60DF616A2A4D38B95703050A8FA8B63868C0E7F11)

2. 在弹出的账号登录页面，输入已实名认证的华为开发者账号信息完成登录。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/dc/v3/n7JP0hWiTdWgEqEavicf2w/zh-cn_image_0000002658599980.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=21B88AAC77EDA794ACDE705365BB2B7F12BFD9DC913FD258CAF0D7304EF8EB8F)

3. 返回编辑器，此时若当前账号团队尚未签署插件相关隐私声明与使用条款，点击蓝色链接阅读协议内容后点击"同意"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/96/v3/F-0Fai3lSASbshwKheflrA/zh-cn_image_0000002690136440.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=1A03E63797A4E6D979E5E97F4D5EF09CD74FC08719F4B6E6C9A311B7643A337D)

4. 进入主界面，接下来您需要先[对插件进行必要配置](https://developer.huawei.com/consumer/cn/doc/start/hosdevassistant-config-0000002588511280)，方可正式使用插件。
