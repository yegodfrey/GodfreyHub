# 个人开发者如何实名认证

个人开发者实名认证分为人脸识别认证、个人银行卡认证、身份证人工审核认证、华为云授权认证四种方式。推荐您使用人脸识别认证，简单易操作，即时通过认证。

人脸识别认证、个人银行卡认证、身份证人工审核认证总体流程如下：

* 选择人脸识别认证方式认证，详见：[人脸识别认证](https://developer.huawei.com/consumer/cn/doc/start/facial-0000001271652446)（推荐）。
* 选择个人银行卡认证方式认证，详见：[个人银行卡认证](https://developer.huawei.com/consumer/cn/doc/start/ibca-0000001062388135)。
* 选择人工审核认证方式认证，详见：[身份证人工审核认证](https://developer.huawei.com/consumer/cn/doc/start/micraa-0000001062276335)。
* 选择华为云授权认证方式认证，详见：[华为云授权认证](https://developer.huawei.com/consumer/cn/doc/start/cloudrz-0000001200842383)。
