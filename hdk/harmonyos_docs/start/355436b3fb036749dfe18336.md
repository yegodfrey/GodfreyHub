# 生态市场订单

用户在生态市场下单购买商品后，商户可以在卖家中心查看订单详情。

## 查看订单详情

1. 登录生态市场[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)。

2. 在左侧导航栏，点击生态市场订单。

3. 在订单列表页，可通过订单状态筛选订单，点击订单号可查看该订单详情。右侧操作列针对不同状态的订单有不同的操作，包括：修改价格、审核退款等。
