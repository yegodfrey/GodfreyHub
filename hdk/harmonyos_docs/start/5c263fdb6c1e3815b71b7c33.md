#### 一、我们如何收集和使用您的个人信息

您使用华为支付服务各项功能的过程中，我们需要收集您的一些信息，用于向您提供服务、提升我们的服务质量、保障您的账户和资金安全以及符合国家法律法规及监管规定。如我们对您个人信息收集或使用的目的、范围、方式发生重大变化的，我们将以信息、邮件、弹窗方式通知您并再次征得您的同意

我们将通过华为支付为您提供下述服务，在您使用相关服务的过程中，我们会处理下列服务所必需的信息，以便履行我们的合同义务，确保您能正常使用本应用的相关功能。我们在不同设备上提供的服务存在差异，且可能会随着提供特性的持续演进而略有不同，最终以实际设备上提供的服务为准。

在您使用华为支付开户、绑卡、支付功能获取短信验证码时，我们会调用信息权限，用于向您提供短信验证码自动填入服务。

在您使用华为支付开户、交易、账户升级、绑卡、签约功能时，我们可能会调用相机权限获取您的活体人脸信息用于验证您的真实身份，以满足风控、反洗钱和反恐怖融资要求。

在您使用华为支付账户升级功能时，我们可能会调用存储（媒体和文件）权限以便于您上传有效身份证件影像，用于满足风控、反洗钱和反恐怖融资要求。

在您使用华为支付服务时，我们会调用电话权限识别您的运营商信息，用于优化网络请求状态，以提供更流畅的服务。
