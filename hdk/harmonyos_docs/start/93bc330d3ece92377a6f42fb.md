# SDK合规使用指南规范性参考

根据国家法律法规对SDK、个人信息保护、服务体验等方面提出的具体要求，提供SDK的商户需通过明确易懂的方式主动向SDK使用者提供合规使用指南，帮助SDK使用者合规接入和使用SDK，保护用户隐私和数据安全。

## 1. 合规使用指南提交规范

1.1 提供SDK的商户必须在鸿蒙生态伙伴SDK专区提供自身的可便捷查看的SDK合规使用指南链接。提供SDK的商户必须确保该链接始终能正常打开。

1.2 建议您的SDK合规使用指南应包含以下内容：

（1）SDK使用者接入/升级至满足监管新规的最新SDK版本。

（2）SDK使用者在《隐私政策》中添加关于本SDK收集使用个人信息的目的、方式和范围等，并提供告知文案示例供使用者参考。

（3）SDK使用者在获得用户同意后初始化SDK，并提供清晰明了的操作指引步骤。

（4）可选信息配置开关的配置，提供向最终用户行使数据主体权利的入口和方式。

（5）其他SDK所涉及合规使用的功能和操作补充说明。

## 2. 合规使用指南内容规范

SDK应简洁、清晰、易懂地向SDK使用者提供合规使用说明，具体要求可参考SDK用户权益保障基本要求的[合规使用说明](https://developer.huawei.com/consumer/cn/doc/start/sdk-user-rights-protection-0000001913103009#section103786835213)。建议您按照如下结构排版撰写合规使用指南结构大纲：

### 一、最新SDK版本说明

**写作指导**：告知SDK使用者接入/升级至满足监管新规的最新SDK版本。

### 二、权限调用合规要求

**写作指导：**

（1）说明SDK所需的系统权限与各业务功能间的关系，并说明权限**申请时机**。

（2）仅声明实现SDK服务目的合理关联的系统权限，不应声明与SDK功能无关的系统权限。

（3）SDK不应使用其未声明但SDK开发者应用软件已申请的相关系统权限。

***样例：***

|*权限名称*|*权限说明*|*使用目的*|*权限申请时机*|
|:---------------------------|:-----------------|:-------------------------|:----------|
|*如：ohos.permission.INTERNET*|*如：允许使用Internet网络*|***在使用XX功能时*** *，用于访问网络数据*|*如：调用xx功能时*|

### 三、延迟初始化要求

**写作指导：**

（1）本节向开发者介绍SDK初始化的方法，要求开发者在获取用户同意后再初始化SDK。

（2）提供清晰的SDK初始化操作指引。

（3）说明SDK初始化及各项业务功能接口合规调用时机，如最终用户选择使用第三方登录方式后，初始化某第三方登录 SDK。

***样例：***

*为了避免您的应用在未获取用户的同意前SDK提前处理用户的个人信息。我们提供了SDK初始化的接口getInstance* *，请保证您的应用获取用户同意后才能调用此接口初始化SDK。*

### 四、最小化使用功能要求

**写作指导：**

（1）本节介绍开发者如何便捷的配置开启或关闭SDK功能及处理可选个人信息。

（2）SDK涉及提供扩展业务功能的，应说明SDK各项扩展业务功能及对应关闭的配置方式、示例。

（3）SDK收集个人信息频次、精度可配置的，应说明不同频次、精度使用目的、场景及对应选择的配置方式、示例。

***样例*** ***：***

*我们的SDK针对扩展功能和可选的个人信息的处理提供了配置能力，您可以基于业务诉求选择开启或关闭相关功能。*

* *如何开启或关闭扩展功能*

  *您可以通过xxxx配置开启或关闭SDK相关XXX扩展功能，以为您提供XXX服务。*
* *如何开启或关闭处理可选个人信息*

  *您可以通过xxxx配置开启或关闭可选个人信息开关。当您开启后，我们还会收集和使用XXXX（填写可选个人信息），帮您更好的实现XX业务功能。*
* *如何配置收集个人信息的频度和精度（如涉及）*

  *为了满足不同业务实现需求，我们对XXX个人信息提供了不同频度和精度的配置，您可以根据实际的业务需求，通过XXX接口进行配置。*

### 五、隐私政策披露要求与示例说明

**写作指导：**提供向最终用户披露条款的示例，包括自身SDK名称、公司名称、处理个人信息类型及目的、自身个人信息处理规则文本下载或展示链接等。

***样例：***

*在您接入、使用【XXX SDK】服务前，我们要求您在隐私政策中向用户告知我们SDK的名称、SDK提供方名称、收集个人信息类型、使用目的、隐私政策链接，并获取用户的同意或取得其他合法性基础，* *在提供xxx服务时，涉及处理敏感个人信息/向中华人民共和国境外提供个人信息，建议您单独弹框获取用户的单独同意* *。您可以参考如下方式提供条款内容：*

* *以文字方式向用户告知*

  ***第三方SDK名称*** *：以产品对外的品牌名为准*

  ***第三方公司名称*** *：* *XXX*公司

  ***收集个人信息类型*** *：按照SDK隐私声明中全部的个人信息类型写作，不用按照功能分别描述，不用写到具体数据项。例外场景需要描述具体的数据项，例如涉及监管关注的数据项，则需写数据项明细。* ***样例*** *：应用基本信息、应用内设备标识符、网络信息、系统基本信息、系统设置信息。*

  ***使用目的*** *：汇总个人信息处理说明中所有信息的使用目的。如果您只使用部分SDK功能，则可以根据实际功能进行裁剪。*

  ***隐私政策链接：*** *提供SDK隐私声明的链接*


* *以表格方式向用户告知*

  |*第三方SDK名称*|*第三方公司名称*|*收集个人信息类型*|*使用目的*|*隐私政策链接*|
  |:------------|:--------|:------------------------------------------------------------------------------------------------------------------------------|:----------------------|:-------------|
  |*以产品对外的品牌名为准*|*XXX*公司|*按照SDK隐私声明中全部的个人信息类型写作，不用按照功能分别描述，不用写到具体数据项。例外场景需要描述具体的数据项，例如涉及监管关注的数据项，则需写数据项明细。* ***样例：**应用基本信息、应用内设备标识符、网络信息、系统基本信息、系统设置信息。*|*汇总个人信息处理说明中所有信息的使用目的。*|*提供SDK隐私声明的链接*|

### 六、最终用户授权同意的建议方式

**写作指导：**提供获取最终用户授权同意的建议方式，其中需要取得最终用户单独同意的，应显著提示并给出示例。

### 七、保障个人信息主体权利

**写作指导：**本节介绍SDK如何便捷的支持开发者管理用户个人数据。如涉及以嵌入接口形式向最终用户提供行使权利的，应提供接口调用方式、示例，不涉及可裁剪。

***样例：***

*为了保障用户便捷的实现访问、复制、更正和删除个人信息，我们在SDK中提供了相关的接口，支持您通过接口调用方式来执行用户关于个人信息的访问、复制、更正和删除的权利请求。*

* *如何获取用户的数据*

  *您可以通过调用xxxx查询接口获取用户数据副本。*
* *如何修改用户的数据*

  *您可通过调用xxxx接口修改最终用户的数据。*
* *如何删除用户的数据*

  *您可通过调用xxxx接口删除最终用户的数据。*
