# 组件类商品上架说明

1. 在[生态市场首页](https://developer.huawei.com/consumer/cn/market/)，登录账号后，点击右上角"我的"，进入卖家中心。
2. 进入卖家中心后，在左侧导航栏选择"商品管理"。
3. 选择"发布商品"。
4. 填写商品接入信息和业务信息。

   |**发布项**|**发布标准**|
   |:--------|:-------------------------------------------------|
   |商品一级分类|应用开发。|
   |商品二级分类|组件。|
   |组件类型|按需选择，分类为UI、媒体、算法、工具、数据、网络及协议、安全、开发框架、文件操作、示例教程、场景。|
   |组件子类|选择组件所属的组件子类。|
   |跨平台开发框架|选择组件支持的跨平台开发框架。|
   |（可选）自定义标签|设置标签，以便于客户搜索，或根据标签快速查找商品。|

5. 填写商品基础信息。

   |**发布项**|**发布标准**|
   |:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |商品名称|1. 商品名称应描述准确，与内容相符，软件与软件著作权证书中软件名称相符。建议名称为"XXX组件"（XXX为组件内容描述）。 2. 商品名称应与业界命名规范一致，不可以出现拼写错误，如：将wordpress拼成wordpess。 3. 商品名称不能扩大宣传，不可以直接借助华为名义，如：命名为"华为XXX"。 4. 商品名称仅用于对商品命名，介绍、价格、版本、电话号码等与命名无关内容，请勿出现在商品名称中。 5. 商品名称应不多于40个字符。 6. 组件名称中无需包含鸿蒙版、HarmonyOS， HarmonyOS NEXT、鸿蒙端等字样，直接使用实际组件名即可。 7. 命名不得出现任何法律、行政法规规定禁止的，有违公序良俗的或有违生态市场协议/规则的内容。|
   |（可选）Logo|图片支持JPG/JPEG/PNG，尺寸为100x100px，大小不超过5M。|
   |（可选）宣传图/效果图|1. 我们强烈建议您提供清晰（尺寸1920*1080）或（1080*1920）、吸引人的宣传图或效果图，这样可以帮助用户快速直观地了解您产品的特点及其预期效果，有助于提升商品的曝光及吸引力。 2. 可接受的尺寸范围在800*800~2000*2000之间；支持png，jpg，jpeg，gif格式；单张图片不超过10M；最多可上传8张，其中第一张将同时用于商品列表页的展示。|
   |商品简介|1. 在商品列表和详情页面展示，字数应不超过256个字符。 2. 商品简介不能只介绍公司信息，需要简要介绍商品信息。 3. 介绍不得出现任何法律、行政法规规定禁止的，有违公序良俗的或有违生态市场协议/规则的内容。|
   |（可选）视频文件|如商品需附加视频，可填写此项。|
   |（可选）视频封面|如视频文件需添加封面，可填写此项。|
   |自述文件（README）|1. 选择MarkDown（推荐）或富文本格式。 2. 填写的内容应当包括但不限于：功能介绍、环境要求、快速入门、使用样例、示例效果、API说明、配置说明、权限要求、技术支持、开源许可协议、获取方式等。需按照提示内容进行填写，否则可能会被驳回。 3. README文档应当保持字体、字号、字色一致，排版要规范，不能出现明显的空格、换行等不合理排版问题，保持页面信息整齐美观。 4. 支持插入图片和动图，图片支持JPG/JPEG/PNG/GIF格式，最大宽度不超过900px、每张图片大小不超过5M，如详情内容仅有图片或截图，没有文字说明，则驳回。 5. 遵守广告法等相关法律法规要求及生态市场协议规则，不得出现违反前述要求的内容，包括但不限于国家级、最佳、极致、世界第一等广告法敏感词。 6. 若上传的组件为闭源，请提供获取源码的联系方式（手机号、邮箱、联系人等）。您提供的联系方式将在组件详情页面中公开展示，用于商户或用户与您联系。|

6. 兼容性。

   |**发布项**|**发布标准**|
   |:--------------|:------------------------|
   |支持的HarmonyOS版本|选择组件所支持的HarmonyOS版本号。|
   |支持的应用类型|选择组件所支持的应用类型。|
   |支持的设备类型|选择组件所支持的设备类型。|
   |DevEco Studio版本|选择组件所支持的DevEco Studio版本号。|

7. 组件信息。

   |**发布项**|**发布标准**|
   |:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |Code|即身份标识，规范如下： > 说明 > 非ArkTS工程不需要代码合入，仅需在上架填写材料时，按照规范填写命名。 * Code命名：组件以"agcit_"开头，后面可增加"数字、字母、_"，最大长度128，为了避免冲突，建议命名规则为：agcit_${自定义组织标识}_${组件名称}。建议代码工程根目录和Code保持一致。 * 组件命名建议：agcit_${行业/kit/分类}_${功能名} 行业举例：办公、政务、医疗、餐饮等，组件与行业属性强相关时适用。 kit举例：account 、iap、push等，组件主要为kit使用样例时适用。 分类举例：UI、媒体、算法、工具、数据、网络及协议。 * Code要求：组件Code要求在生态市场唯一，上架生态市场时会要求填写此Code，并校验和代码中的配置是否一致，后续不可修改。 * Code写入：组件提供者需要将该外部Code写入到src/main/resource/base/element/string.json文件中，其中key为外部code，value为版本号（版本号建议采用**[** **主版本号].[** **次版本号].[** **修订号]** 三段式版本号格式）。示例如下： ```screen { "string": [ ...... { "name": "${外部code}", "value": "${版本号}" } ...... } ```|
   |（可选）应用品类|选择组件可支撑的应用品类，发布后不支持修改。|
   |以下"ohpm托管位置""代码仓库地址""主页地址"三个字段，至少填写一个。||
   |（可选）ohpm托管位置|1. ohpm包名：请输入组件在OHPM仓库的包名，如有组名则形如：@组名/包名。 2. ohpm版本号：请输入您的组件在ohpm仓的版本号。 > 说明 > 1. 包名和版本号强相关，填了包名，必须填写版本号。|
   |（可选）代码仓库地址|1. 代码仓库地址：请输入组件在代码仓库(gitee、gitcode、github)的根目录地址，以.git结尾。 2. 组件相对路径：若代码仓库内存在多个组件，请输入组件在仓库内的有效目录（例如：src/component）。 3. 分支名：请输入您的组件在代码仓库内的分支名，不填默认master。 > 说明 > 代码仓库地址、组件相对路径和分支名非强相关，允许只填写代码仓库地址。|
   |（可选）主页地址|请输入您的组件在其他平台的主页地址。|
   |版本号|请输入组件本次发布的版本号，将用于生成组件的更新记录。|
   |版本说明|请输入组件本次发布的版本说明，将用于生成组件的更新记录。|
   |发布者|如果您是服务商用户，不展示内容；如果您是企业开发者，展示内容为企业全称；如果您是个人开发者，展示内容为华为账号昵称。相关内容由系统自动填入，不支持修改。|
   |开源情况|选择开闭源。 * 选择"开源"时，需要选择适用的开源许可协议。 * 选择"闭源"时，需要填写使用许可协议，可上传附件或者填写URL。 附件支持上传.pdf/.docx/.zip格式的文件（zip中只能包含pdf或docx），文件大小不超过10M。|

8. 权限与隐私。

   |**发布项**|**发布标准**|
   |:------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |权限声明|1. 针对权限名称、权限说明、权限使用目的及操作进行详细填写。 2. **敏感权限范围：** **HarmonyOS NEXT定义的user_grant权限：**包括位置、相机、麦克风、图片和视频、音乐和音频、通讯录、日历、运动数据、设备发现与连接、身体传感器等。 3. **提示：** user_grant权限可能随着操作系统版本更新发生变化，当前系统支持权限组请参考[应用权限组列表](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V5/app-permission-group-list-V5)。|
   |是否涉及处理个人数据|选择"是"或"否"。 > 注意 > 是否涉及处理个人数据选择"否"时，"隐私政策"及"SDK合规使用指南"为非必填项。|
   |（可选）SDK合规使用指南|1. 支持pdf、docx、zip格式（zip中只能包含pdf或docx），不超过10M。 2. SDK合规使用指南应包含以下内容： 1. 组件使用者接入/升级至满足监管新规的最新组件版本。 2. 组件使用者在《隐私政策》中添加关于本组件收集使用个人信息的目的、方式和范围等，并提供告知文案示例供使用者参考。 3. 组件使用者在获得用户同意后初始化组件，并提供清晰明了的操作指引步骤。 4. 可选信息配置开关的配置，提供向最终用户行使数据主体权利的入口和方式。 5. 其他组件所涉及合规使用的功能和操作补充说明。|
