# 实名认证介绍

华为开发者联盟为开发者提供丰富的技术能力与服务支持，包括但不限于开发工具、API接口、云资源等，全面赋能优质应用的创新与开发。开发者需先[注册](https://id1.cloud.huawei.com/CAS/portal/userRegister/regbyemail.html)华为开发者联盟账号，并完成实名认证流程，方可使用更多联盟提供的功能与服务资源。开发者账号类型分为个人开发者和企业开发者类型。

## 实名认证入口

1. 进入[华为开发者联盟官网](https://developer.huawei.com/consumer/cn/)，点击"[管理中心](https://developer.huawei.com/consumer/cn/console/overview)"或者头像下拉框中的"立即登录"进入登录页面，输入账号密码后点击登录。
2. 点击头像下拉框中的"去认证"。进入"实名认证"页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d6/v3/lte-ZB5rSRKdghbNxC0wmw/zh-cn_image_0000002486779945.png?HW-CC-KV=V1&HW-CC-Date=20260909T173120Z&HW-CC-Expire=31536000000&HW-CC-Sign=98EA8601842379F3DC15975E2AEB0E088C37E0D76824DA9932808781CA697619)

3. 选择认证类型（个人开发者/企业开发者），根据页面提示进行实名认证。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c7/v3/4nZjpszQTHuv2k1uyJRNmQ/zh-cn_image_0000002434853346.png?HW-CC-KV=V1&HW-CC-Date=20260909T173120Z&HW-CC-Expire=31536000000&HW-CC-Sign=17697BBA8635CFEB45C2DD8EE48255409790F28B2173E8D8FF23B0A478CCDDF8 "点击放大")

|企业开发者|打款认证（**推荐**使用，最快30分钟）|企业对公账号、法定代表人姓名、法定代表人身份证号码信息|1. 企业开发者实名认证暂不支持电子营业执照，请提供最新的"三证合一"的营业执照照片或扫描件，确保营业执照上的企业信息和国家企业信用公示系统公示的一致。 2. **政府部门或事业单位实名认证**，需提供统一社会信用代码证书/事业单位法人证书（或其他有效证件）扫描件，法定代表人手持身份证正反面照片。分别上传至企业证件"营业执照"上传处和"法定代表人身份证"上传处。 3. 法定代表人为香港（中国）、澳门（中国）、台湾（中国）人士，可提交手持通行证或护照的照片；海外人士请提供手持护照的照片，保证法定代表人证件信息和营业执照一致。如果您提交实名认证时系统提示校验失败，可以[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/ticketCard)联系我们。 4. 目前不支持香港（中国）、澳门（中国）、台湾（中国）、海外企业及海外个人注册认证中国大陆开发者联盟账号，您可以在[华为开发者联盟海外官网](https://developer.huawei.com/consumer/en/)进行注册认证。|
