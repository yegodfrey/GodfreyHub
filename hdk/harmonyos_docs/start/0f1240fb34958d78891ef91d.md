# 商品推荐管理

商品推荐管理包含**：商品可见** 、**首页推荐** 和**置顶推荐**三大功能，本文将分别介绍下这三大功能。

## 商品可见

商品可见用来设置商品是否在生态市场前台页面与搜索结果中对外展现，将商品设置为不可见时，用户无法通过生态市场前台页面和搜索访问商品页面，只能通过商品URL[c1] 或已购买的订单进行访问或购买。

## 首页推荐

首页推荐用来设置商品是否在店铺首页"精选"栏目中展现。"精选"栏目默认隐藏，首次将商品设置为推荐时才会展示。

## 置顶推荐

商户可自己指定置顶在售商品，置顶功能目前仅针对"精选"栏目中的商品。
