# 隐私号码实名认证

为确保生态市场隐私号业务的合规运营，商户需完成隐私号码实名认证，才可以与买家通过隐私号码进行沟通，具体操作步骤如下：

1. 在卖家中心---店铺信息维护---隐私号码实名认证中，上传相关信息（手机号与固话均支持）；

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/aa/v3/YKdlXGpXTEKP5swfF9Fecg/zh-cn_image_0000002531810960.png?HW-CC-KV=V1&HW-CC-Date=20260909T134116Z&HW-CC-Expire=31536000000&HW-CC-Sign=6E9980591CAADA2F6A130756202BE29845E8909A9DEC4F610CA0608394F3007A)

2. 点击提交，等待审核；

3. 提交审核后，您可以通过隐私号码，与买家进行联系；

4. 若审核不通过，您将无法联系买家。可点击"查看原因"了解详情，修改后重新提交，直至审核通过。
