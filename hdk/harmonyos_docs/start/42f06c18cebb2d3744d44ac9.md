# 续费实例

## 功能介绍

用户续费后生态市场将调用该接口，您需要将自己维护的到期日进行更新。

## 接口原型

|承载协议|HTTPS POST|
|----|-------------------------------------------------------------------|
|接口方向|华为服务器 -> 商户服务器|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 请求参数

### Body

下表中列出了请求Body中使用JSON格式需要携带的续费信息，请求验签需要携带的URL参数请参见[安全校验规则](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-marketplace-spsaasservice-autodeliveryprg-0000001249275447#section34923151503)。

|参数名|必选(M)/可选(O)|类型|说明|
|:---------------------|:----------|:---------|:---------------------------------------------------------------------------------------------------------------|
|action|M|String|取值固定为renewInstance。|
|orderId|M|String|订单ID。|
|orderCode|M|String|订单编号。|
|instanceId|M|String|实例ID，全局唯一，由生态市场统一分配。|
|openId|M|String|即购买服务的用户ID，对于同一商户是相同的，对于不同商户是不同的。|
|periodType|M|Integer|周期类型:1包年、2包月、3包天。|
|periodNumber|M|Integer|周期数量。|
|orderAmount|M|BigDecimal|订单金额。（单位：元）。|
|payAmount|M|BigDecimal|支付金额（单位：元）。|
|amount|O|Integer|商品下单数量。|
|skuCode|M|String|商品购买规格属性。|
|productCode|M|String|生态市场商品Code，详情请参见[术语表](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-terminology-0000001446432989)。|
|expiredTime|O|DateTime|过期时间，Unix时间戳，yyyy-MM-dd HH:mm:ss|
|requestId|M|String|请求ID，每次请求均不相同。|
|quotaInfos|O|quotaInfos|服务的总配额信息。|
|hasOverpaidRank|O|Boolean|服务是否开通了超额定价，true代表开通，false代表未开通。|
|overpaidRankExpireTime|O|String|超额定价的有效期，Unix时间戳。|

**quotaInfos**

|参数名|必选(M)/可选(O)|类型|描述|
|:-------------|:----------|:-----|:------------------------------------------------------------------------------------------------------------|
|id|M|String|配额ID。|
|chargeItemCode|M|String|计费项Code，详情请参见[术语表](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-terminology-0000001446432989)。|
|amount|M|String|配额数量。|
|effectTime|M|String|生效时间，Unix时间戳。|
|expireTime|M|String|过期时间，Unix时间戳。|

## 响应参数

|参数|必选(M)/可选(O)|类型|说明|
|:------|:----------|:-----|:------------------------------------------|
|retCode|O|String|调用结果码，结果码定义参见"[结果码](#section2841191514352)"|
|retMsg|O|String|调用结果描述|

## 结果码

|结果码|含义|
|:-----|:---------------------------------------|
|000000|成功|
|000001|鉴权失败|
|000002|请求参数不合法|
|000003|时间戳校验失败（请求时间与本地时间差异较大）|
|000004|实例ID不存在（续费、过期、变更套餐、释放资源可能返回）|
|000099|其它服务内部错误|
|000100|请求处理中（对于异步发货的服务，需返回此结果码，服务市场会持续询问直到发货成功）|

## 响应示例

```screen

	"retMsg" : "renew instance success"
```

## 示例代码

```screen
// 处理请求
public Object dealInstance(String signature, String timestamp, String eventId, @RequestBody String requestString) {
    // 处理请求超时逻辑
    if (new Date().getTime() - Long.parseLong(timestamp) > 30 * 60) {
        log.error("dealInstance fail. timestamp {} is invalid.", timestamp);
        return new CommonRsp(SaasRetCodeEnum.TIME_INVALID.getRetCode(), SaasRetCodeEnum.TIME_INVALID.getRetMsg());
    }
    List<String> paraList = new ArrayList<>();
    paraList.add(timestamp);
    paraList.add(eventId);
    // 验证签名
    String realSig = CommonUtil.hmacSha256Hex(paraList, CommonUtil.getDeliveryKey());
    if (!StringUtils.equals(realSig, signature)) {
        log.error(
            "dealInstance verifySignature fail. para timestamp = {}, eventId = {}, signature = {}, RealSig = {}",
            timestamp, eventId, signature, realSig);
        return new CommonRsp(SaasRetCodeEnum.VERIFY_FAIL.getRetCode(), SaasRetCodeEnum.VERIFY_FAIL.getRetMsg());
    }

    // 获取参数，RenewInstanceReq是包含请求参数的数据类
    RenewInstanceReq request = JSON.parseObject(requestString, RenewInstanceReq.class);
    return dealInstanceService.renewInstance(request);
}

// 发送响应
public CommonRsp renewInstance(RenewInstanceReq request) {
        SaasPurchase entity = new SaasPurchase();
        SaasData queryInfo = saasPurchaseMapper.querySaasByOpenIdAndInstanceId(null, request.getInstanceId());
        if (queryInfo == null || !StringUtils.equals(queryInfo.getStatus(), "normal")) {
            log.error("renewInstance fail, instanceId {} not exist.", request.getInstanceId());
            return new CommonRsp(SaasRetCodeEnum.INSTANCE_NOT_EXIST.getRetCode(),
                SaasRetCodeEnum.INSTANCE_NOT_EXIST.getRetMsg());
        }
        entity.setExpireTime(request.getExpireTime());
        entity.setUpdateTime(new Date());
        entity.setInstanceId(request.getInstanceId());
        entity.setRequestId(request.getRequestId());
        entity.setOrderId(request.getOrderId());
        entity.setOverPaidRankExpireTime(request.getOverpaidRankExpireTime());
        entity.setHasOverPaidRank(request.isHasOverpaidRank() ? 1 : 0);
        int ret = saasPurchaseMapper.updateSaasByOpenIdAndInstanceId(entity);
        if (ret == 0) {
            // 需要返回错误
            log.error("renewInstance fail, instanceId {}.", request.getInstanceId());
            return new CommonRsp(SaasRetCodeEnum.PARA_ERROR.getRetCode(), SaasRetCodeEnum.PARA_ERROR.getRetMsg());
        }
        updateQuotaInfo(request.getInstanceId(), request.getQuotaInfos());
        return new CommonRsp(SaasRetCodeEnum.SUCCESS.getRetCode(), SaasRetCodeEnum.SUCCESS.getRetMsg());
    }

private void updateQuotaInfo(String instanceId, List<QuotaInfo> request) {
        request.forEach(quotaInfo -> {
            QuotaInfoPO rec = new QuotaInfoPO();
            rec.setChargeItemCode(quotaInfo.getChargeItemCode());
            rec.setCreateTime(new Date());
            rec.setTotalAmount(quotaInfo.getAmount());
            rec.setEffectTime(quotaInfo.getEffectTime());
            rec.setExpireTime(quotaInfo.getExpireTime());
            rec.setId(quotaInfo.getId());
            rec.setInstanceId(instanceId);
            saasQuotaInfoMapper.updateQuotaInfo(rec);
        });
    }
```
