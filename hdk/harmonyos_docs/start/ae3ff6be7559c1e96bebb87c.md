# 系统权限（联盟管理中心）角色与权限

当前开发者联盟管理中心提供6种团队账号角色：

* 管理员：拥有管理中心、AppGallery Connect和流量变现服务等业务的所有权限，可查看所有团队成员，可添加、变更、邀请、删除管理员以外的团队成员。  

  |权限|权限明细|
  |:-----|:---------------------------------------------------------------------------------------|
  |团队账号|详见：[团队账号](https://developer.huawei.com/consumer/cn/console/setting/teamAccountInfoList)。|
  |云测试|安卓原生、华为全系列机型、App全控件、全路径、全自动化测试。|
  |云调试|华为旗舰手机、EMUI、安卓原生系统抢先体验，快速测试验证。|
  |我的API|详见：[我的API](https://developer.huawei.com/consumer/cn/console#/myProject)。|
  |API库|详见：[API库](https://developer.huawei.com/consumer/cn/console#/apiList/0)。|
  |凭证|详见：[凭证](https://developer.huawei.com/consumer/cn/console#/myProject)。|
  |商户服务|开通、查看、管理商户信息。|
  |付费服务|开通、查看、管理付费信息。|
  |余额|充值或查看余额、充值记录。|
  |收益|查看、管理、下载产品收益。|
  |账单|查看和管理付费账单。|
  |隐私联系信息|查看和添加隐私联系信息。|
  |授权管理|选择凭证添加或删除授权。|
  |支付报表|查看支付明细。|
  |消费明细|查看所有消费明细。|

* 财务：管理账号财务信息，拥有管理中心商户服务、付费信息、收益等权限，同时可被分配应用市场角色。  

  |权限|权限明细|
  |:---|:------------------------------------------------------------------------------------------|
  |商户服务|开通、查看、管理商户信息。|
  |付费服务|开通、查看、管理付费信息。|
  |余额|充值或查看余额、充值记录。|
  |收益|查看、管理、下载产品收益。|
  |账单|查看和管理付费账单。|
  |团队账号|详见：[团队账号](https://developer.huawei.com/consumer/cn/console#/mysetting/teamAccountInfoList)。|
  |支付报表|查看支付明细。|

* 开发：通过平台提供的HMS API 服务创建项目应用。  

  |权限|权限明细|
  |:-----|:-----------------------------------------------------------------------|
  |我的API|详见：[我的API](https://developer.huawei.com/consumer/cn/console#/myProject)。|
  |API库|详见：[API库](https://developer.huawei.com/consumer/cn/console#/apiList/0)。|
  |凭证|详见：[凭证](https://developer.huawei.com/consumer/cn/console#/myProject)。|
  |隐私联系信息|查看和添加隐私联系信息。|
  |授权管理|选择凭证添加或删除授权。|

* 测试：查看团队账号信息，拥有云测试及云调试权限。  

  |权限|权限明细|
  |:--|:------------------------------|
  |云测试|安卓原生、华为全系列机型、App全控件、全路径、全自动化测试。|
  |云调试|华为旗舰手机、EMUI、安卓原生系统抢先体验，快速测试验证。|
