# 需求管理

需求在您未确认商户、提交订单的情况下，您可以在**买家中心** **>** **需求管理**查看需求详情及意向方案和合同，也可进行需求撤销。

## 查看需求详情

1. 登录**买家中心**。
2. 在左侧导航栏，点击**需求管理**。
3. 在需求管理页，点击**需求标题** 可查看该需求详情，包括需求ID，需求标题、需求描述、需求类型、预算范围、创建时间、需求状态、商户信息、需求文件、关联的订单编号（点击链接可查看订单详情）、方案列表、交付件等。

## 撤销需求

在确认商户之前，您可以随时**撤销**发布的需求。

## 修改需求

1. 在商户响应前，您可以对发布的需求进行修改。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6c/v3/RgVMq_EARDqPRghNsCsO9w/zh-cn_image_0000002176718501.png?HW-CC-KV=V1&HW-CC-Date=20260909T144306Z&HW-CC-Expire=31536000000&HW-CC-Sign=22E816E4D9923872D69AD34C935B6C2835D39C726C0CB0CB2D517EA3E36BBFB0 "点击放大")

2. 在需求被驳回后，您可以查看驳回原因并对其进行修改，再次提交。
