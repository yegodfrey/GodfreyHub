# 对公银行打款方式认证注意事项

## 法定代表人信息校验

### 法定代表人身份证号填写

如果法定代表人为非中国大陆居民，法定代表人身份证号码处填写的身份证号与在工商局办理企业证件使用的号码保持一致即可（如护照号等）。

### 法定代表人信息验证次数

每个账号有4次机会验证法定代表人信息，如果您信息验证未通过，请检查您的企业名称、统一社会信用代码、法定代表人姓名、法定代表人身份证号是否输入正确。若4次都未能验证通过，只能选择企业资料人工审核认证方式进行认证，请确保填写的信息正确。

## 对公银行打款认证

### 对公银行打款认证次数

一个账号有2次机会提交企业对公银行打款认证，每次认证有2次机会输入收到的打款金额及打款附言（随机码）。如果您提交2次企业对公银行打款认证都未能通过，只能选择企业资料人工审核认证方式进行认证。

### 输入到账金额及打款附言（随机码）时间要求

请您在收到华为开发者联盟发起打款的短信或邮件通知后，及时关注并联系对公账户管理员，通过网上银行、手机银行、银行柜台等方式查询到账金额及打款附言（随机码）。1个工作日内回到[实名认证页面](https://developer.huawei.com/consumer/cn/console#/serviceCards/)，输入到账金额及打款附言（随机码），单击"提交认证"。如逾期未输入到账金额及打款附言（随机码）提交认证，系统将自动驳回申请。 注意
