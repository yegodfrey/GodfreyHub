# 主题中心角色与权限

当前主题中心业务提供5种团队账号角色，成员账号需完成华为开发者实名认证（个人或企业）后，方可使用相关角色与权限，各角色的权限明细请参考：[主题中心角色与权限](https://developer.huawei.com/consumer/cn/doc/distribution/content/funcation19-0000001104887590#ZH-CN_TOPIC_0000001104887590__section41701641193120)。
