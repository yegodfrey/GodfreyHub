# 商品修改

商户可以在 "[商品管理](https://developer.huawei.com/consumer/cn/market/provider/prod-list)"中修改已上架的商品。修改后，需要通过审核才能生效。  
![](https://media:401788750495754085)  
* 提交发布商品申请失败或已上架商品修改后被驳回，均可修改后再次提交申请。
* 对于已上架的商品，可以在"我的商品"中对规格进行下架，规格下架操作请参考[商品下架](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-commodity-discontinue-0000001071402644)。
* 新发布的商品，可基于最新一次被驳回的记录修改。
* 所有规格都已下架的商品，不支持再新增或修改规格。  

#### 操作步骤

1. 进入[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)页面。

2. 点击左侧导航的"商品管理"，进入"商品列表"页面。点击待修改的目标商品操作列的"编辑"。

![](https://media:401788750495811086 "点击放大")

3. 修改商品信息。

* 可以根据需求修改商品接入信息、基础信息、业务信息、售卖方式等信息。
* 可以在商品规格及售价模块中，修改已上架规格的价格、为已有规格新增计费模式、已上架商品新增规格。

4. 修改商品信息后，点击"提交"，由运营进行审核通过后商品自动上架。  
![](https://media:401788750495977087)  
* 商户在修改商品的过程中，点击页面左下方"存草稿"，可以将内容保存为草稿。后续可在"商品管理"中查看。
* 提交申请后，需要通过审核才能生效。您可以在"商品管理"页面查看审核中的商品信息，只有当商品修改申请审核通过后，修改的信息才会生效。
