# 验收交付件

商户将根据您的定制需求提供并上传交付件，在最终交付前您可以联系商户修改交付件，确认验收后交易完成。

1. 登录买家中心。
2. 在左侧导航栏，点击需求管理。
3. 在需求列表中找到目标需求，在需求详情的中的方案列表中，点击交付件名称查看/下载交付件。 ![](https://media:401788750497343112 "点击放大")

* 点击确认交付件"√" ![](https://media:401788750497372113 "点击放大")

4. 确认验收交付件后，订单状态为"已完成"则交易完成。

![](https://media:401788750497400114 "点击放大")
