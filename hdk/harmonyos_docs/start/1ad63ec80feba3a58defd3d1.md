# 验收交付件

商户将根据您的定制需求提供并上传交付件，在最终交付前您可以联系商户修改交付件，确认验收后交易完成。

1. 登录**买家中心。**
2. 在左侧导航栏，点击**需求管理**。
3. 在需求列表中找到目标需求，在需求详情的中的**方案列表** 中**，** 点击**交付件名称** 查看/下载交付件。
