# TargetedMemoryReactivation(TMR)

TargetedMemoryReactivation(TMR)（首都师范大学学生作品）

基于"定向记忆再激活"的技术原理，提出使用华为智能穿戴设备代替多导睡眠仪监测睡眠阶段，制作可提高记忆力的应用。

学习类  

#### 入选情况

创新应用-创意构思类 ★  

#### 开发者

张亚坤、吕焕博  

#### 功能介绍

基于"定向记忆再激活"（Targeted Memory Reactivation，简称TRM）的技术原理，提出使用华为智能穿戴设备代替多导睡眠仪监测睡眠阶段，制作可提高记忆力的TMR应用。  

#### 应用价值

主要用于辅助实验室研究，通过改变记忆材料达到不同目的，如改善注意力偏差、治疗抑郁症等。TMR技术尚未成熟，将来有望应用于教育和临床行业。  

#### 实现路径

Targeted Memory Reactivation（TRM）是一种在睡眠期间操纵记忆处理的方法。在science和nature上均有文献表明在慢波睡眠（NREM）睡眠期间给予感觉线索提示可以激活相关记忆并促进记忆巩固。在一系列的学习领域都发现了该效应，包括但不限于陈述性记忆和程序性记忆。同时，研究者在未监测睡眠阶段，仅依靠计时估算慢波睡眠（NREM）的情况下进行了测试。连续3个晚上，在66名健康的年轻测试者睡眠中使用MP3播放器来播放荷兰语单词，期间不采取任何睡眠控制或音调唤醒。结果显示，3个晚上后，在报告睡眠质量未被干扰的测试者中，在睡眠期间有提示的单词相比于没有提示的单词记忆效果高出20%，即在不通过多导睡眠仪实时监测睡眠阶段的实验条件下，TRM依旧可提高记忆效果。但TRM想要在实际生活中广泛使用，依旧需要有对睡眠和睡眠阶段的监测，如何摆脱多导睡眠仪从而实现设备的便携性以及价格的亲民性是首要解决的问题。

华为在睡眠数据分析方面具有领先的专业性，如华为手环B6所拥有的HUAWEI TruSleep2.0睡眠监测技术，能准确记录用户深睡、浅睡、REM/睡梦的睡眠结构，剖析用户睡眠质量并提供改善和个性化服务。开发者预计采用HUAWEI Watch或华为手环的wear engine穿戴设备开放能力代替多导睡眠仪来监测被测试者的睡眠阶段，从而达到实验室条件下提高记忆能力的效果。
