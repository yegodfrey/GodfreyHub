# 生态市场介绍

华为开发者联盟生态市场面向开发者提供伙伴 SDK 、三方库、开发服务、人力服务、培训服务等资源，助力开发者轻松跨越开发门槛，高效构建鸿蒙应用。

生态市场咨询邮箱：partner@huawei.com  

#### 商户权益

生态市场依托华为开发者联盟的用户基础，可为商户提供一系列营销工具、经营管理工具和激励扶持计划，包括联盟全域营销曝光机会、多种激励形式和专业赋能培训等资源及产品支持，助力合作伙伴实现商业成功。

1. 提供一系列经营管理工具

生态市场为商户提供店铺管理、商品管理、服务管理、优惠管理、需求管理、订单管理、分成结算、发票管理等经营管理以及一系列营销工具。

2. 提供激励扶持计划

1) 带来全域营销曝光

为商户提供联盟全域联运推广流量，线下联合打造品牌的机会。

2) 匹配多种激励形式

低额交易服务费、丰富的活动助力渠道销售。

3) 提供专业赋能培训

华为开放能力在线培训助力商户技术创新。  

#### 买家权益

生态市场为买家提供服务全程监管的交易保障体系、平台担保交易、多种产品及服务。

1. 四大商品分类

为买家提供SDK、开发服务、培训服务、人力服务等相关商品。

2. 1对1定制服务

定制需求匹配对接，满足买家快速寻找商户完成定制化服务的诉求。

3. 甄选商品优惠

平台优选认证商户，为买家提供安全、优惠的产品和应用解决方案。
