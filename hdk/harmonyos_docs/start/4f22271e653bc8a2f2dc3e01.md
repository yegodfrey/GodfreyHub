# 同步配额

#### 功能介绍

用户购买商品并付款成功，生态市场将调用本接口，将用户订购的商品配额信息同步给您。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|华为服务器 -\> 商户服务器|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|
|----|-------------------------------------------------------------------|

#### 请求参数

Body

下表列出了请求Body中使用JSON格式携带的商品配额信息，请求验签需要携带的URL参数请参见[安全校验规则](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-marketplace-spapi-autodeliveryprg-0000001380928181#section26527379136)。  

|参数名|必选(M)/可选(O)|类型|描述|
|:---------------------|:----------|:-------------|:-----------------------------------------------------------------------------------------------------------|
|action|M|String|取值固定为modifyServiceQuota。|
|requestId|M|String|请求ID，每次请求均不相同。|
|openId|M|String|购买服务的用户ID，全局唯一，由精选应用服务统一分配。|
|apiClientId|M|String|API客户端ID，即ClientId。|
|serviceCode|M|String|服务Code，详情请参见[术语表](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-terminology-0000001446432989)。|
|quotaInfos|M|quotaInfos\[\]|配额信息。|
|hasOverpaidRank|O|Boolean|服务是否开通了超额定价，true代表开通，false代表未开通。|
|overpaidRankExpireTime|O|String|超额定价的有效期，Unix时间戳。|

quotaInfos  

|参数名|必选(M)/可选(O)|类型|描述|
|:-------------|:----------|:-----|:------------------------------------------------------------------------------------------------------------|
|id|M|String|配额ID。|
|chargeItemCode|M|String|计费项Code，详情请参见[术语表](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-terminology-0000001446432989)。|
|amount|M|String|配额数量。|
|effectTime|M|String|生效时间，Unix时间戳，,yyyyMMddHHmmss|
|expireTime|M|String|过期时间，Unix时间戳，yyyyMMddHHmmss|

#### 响应参数

|参数名|必选(M)/可选(O)|类型|描述|
|:------|:----------|:-----|:------------------------------------------------|
|retCode|M|String|调用结果码，结果码定义参见"[结果码](#section984302432611)"。|
|retMsg|M|String|调用结果描述。|
|authUrl|O|String|如您的服务提供了API管理台，需要返回控制台访问url。最大长度不超过512，须为HTTPS地址。|

#### 结果码

|结果码|含义|
|:-----|:---------------------|
|000000|成功|
|000001|鉴权失败|
|000002|请求参数不合法|
|000003|时间戳校验失败（请求时间与本地时间差异较大）|
|000099|其它服务内部错误|

#### 响应示例

```
HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8

#### 示例代码

```
//处理请求
public Object dealQuota(String signature, String timestamp, String eventId, @RequestBody String requestString) {
        //处理请求超时
        if (new Date().getTime() - Long.parseLong(timestamp) > 30 * 60 * 60 * 60) {
            log.error("dealQuota fail. timestamp {} is invalid.", timestamp);
            return new CommonRet(ConstantRet.TIME_INVALID_CODE, ConstantRet.TIME_INVALID_MSG);
        }
        List<String> paraList = new ArrayList<>();
        paraList.add(timestamp);
        paraList.add(eventId);
        //验证签名
        String realSig = CommonUtil.hmacSha256Hex(paraList, CommonUtil.getDeliveryKey());
        if (!StringUtils.equals(realSig, signature)) {
            log.error(
                    "dealQuota verifySignature fail. para timestamp = {}, eventId = {}, signature = {}, RealSig = {}",
                    timestamp, eventId, signature, realSig);
            return new CommonRet(ConstantRet.VERIFY_CODE, ConstantRet.VERIFY_MSG);
        }
        //获取参数，SynQuotaReq是包含请求参数的数据类
        return apiService.synQuota(timestamp, eventId, signature, JSON.parseObject(requestString, SynQuotaReq.class));
    }

//发送响应
public SynQuotaRsp synQuota(String timestamp, String eventId, String signature, SynQuotaReq request) {
        SynQuotaRsp synQuotaRsp = new SynQuotaRsp();

        if (CollectionUtils.isEmpty(request.getQuotaInfos())) {
            log.error("synQuota para fail. request = {}", request);
            synQuotaRsp.setRetMsg(ConstantRet.PARA_INVALID_MSG);
            synQuotaRsp.setRetCode(ConstantRet.PARA_INVALID_CODE);
            return synQuotaRsp;
        }
        List<ApiAmountData> queryRsp =
            apiAmountMapper.queryApiAmount(request.getApiClientId(), request.getServiceCode());
        Set<String> dealSet = new HashSet<>();
        queryRsp.forEach(x -> 
            dealSet.add(x.getChargeItemCode() + "," + x.getId());
        });
        // 对已经存在的配额信息直接过滤
        for (QuotaInfo x : request.getQuotaInfos()) {
        if (dealSet.contains(x.getChargeItemCode() + "," + x.getId())) {
                continue;
            }
            ApiAmountData apiAmountData = new ApiAmountData();
            apiAmountData.setApiClientId(request.getApiClientId());
            apiAmountData.setServiceCode(request.getServiceCode());
            apiAmountData.setOpenId(request.getOpenId());
            apiAmountData.setOverpaidRankExpireTime(null == request.getOverpaidRankExpireTime() ? null
                : new Date(Long.parseLong(request.getOverpaidRankExpireTime())));
            apiAmountData.setHasOverpaidRank(null == request.isHasOverpaidRank() ? false : request.isHasOverpaidRank());
            apiAmountData.setId(x.getId());
            apiAmountData.setChargeItemCode(x.getChargeItemCode());
            apiAmountData.setTotalAmount(x.getAmount());
            apiAmountData.setEffectTime(new Date(Long.parseLong(x.getEffectTime())));
            apiAmountData.setExpireTime(new Date(Long.parseLong(x.getExpireTime())));
            apiAmountData.setUsedAmount("0");
            apiAmountMapper.insertApiAmount(apiAmountData);
        }

       synQuotaRsp.setRetMsg(ConstantRet.SUCCESS_MSG);
        synQuotaRsp.setRetCode(ConstantRet.SUCCESS_CODE);
        synQuotaRsp.setRetAuthUrl(ConstantRet.PARA_INVALID_URL);
        log.info("synQuota success para timestamp = {}, eventId = {}", timestamp, eventId);
return synQuotaRsp;
    }
