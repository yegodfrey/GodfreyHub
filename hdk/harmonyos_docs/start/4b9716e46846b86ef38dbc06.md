# 成员退出账号组

1. 用成员账号登录[华为开发者联盟官网](https://developer.huawei.com/consumer/cn/)，进入"管理中心 > 开发者中心 > 账号组"，点击"退出账号组"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/12/v3/aGDI2ZwTQnmwFkEFrnmvaQ/zh-cn_image_0000002616121651.png?HW-CC-KV=V1&HW-CC-Date=20261008T144957Z&HW-CC-Expire=31536000000&HW-CC-Sign=6BD4D10AEC6B6411155A02456FBEA2CE4D439CE43AE90E43C8CCE31747B0E315 "点击放大")


2. 仔细阅读弹框内容后点击"确定"，成员账号即可成功退出账号组。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/74/v3/B0aBZ5dnT3WBm-2_eCaa6A/zh-cn_image_0000002470198013.png?HW-CC-KV=V1&HW-CC-Date=20261008T144957Z&HW-CC-Expire=31536000000&HW-CC-Sign=5C6BE954DDCAA760A7BF884CEDE02CB6C4AA8D3C1E64BB5ED06036C30ACAC315)
