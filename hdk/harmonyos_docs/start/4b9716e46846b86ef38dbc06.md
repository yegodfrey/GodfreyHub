# 成员退出账号组

1. 用成员账号登录[华为开发者联盟官网](https://developer.huawei.com/consumer/cn/)，进入"管理中心 \> 开发者中心 \> 账号组"，点击"退出账号组"。

   ![](https://media:801782184086299430 "点击放大")

<!-- -->

2. 仔细阅读弹框内容后点击"确定"，成员账号即可成功退出账号组。 ![](https://media:801782184086334431)
