# 多设备适配

为了实现"[一次开发，多端部署](https://developer.huawei.com/consumer/cn/doc/best-practices/bpta-multi-device-overview)"，应用需要同时适配手机、平板、折叠屏等多类设备，开发者需要逐一处理因设备屏幕形态差异与硬件能力差异造成的适配问题，工作量大且兼容风险高。本插件聚焦屏幕适配与相机适配两大高频场景，提供自动化生成能力：开发者只需描述适配需求，插件即可快速生成高质量的方案设计与工程代码，并自动完成编译验证，大幅降低多端适配的技术门槛与人力投入。

插件提供的多设备适配能力支持情况如下。

|支持的工程类型|* HarmonyOS应用 * 元服务|
|-------|-----------------------------------------------------------------------------------------------------------|
|适配项目|当前支持屏幕适配与相机适配两大核心场景，具体适配项如下： * 屏幕适配：自适应布局、响应式布局、安全区避让、软键盘避让、多设备窗口、折叠开合/悬停 * 相机适配：前后/内外切换、旋转镜头、预览取景、拍照录像、连续性|
|适配设备|直板机、双折叠、阔折叠、三折叠、小折叠、平板|
|适配范围|支持以下任一适配范围： * 全工程一次性处理 * 指定问题和适配范围，仅对工程中的相关页面、目录、代码片段或业务模块进行适配 一个任务可包含多个适配范围，并可为不同范围指定不同的适配项目。|

## 前提条件

* 已[登录插件](https://developer.huawei.com/consumer/cn/doc/start/hosdevassistant-login-0000002588351354)。
* 已[完成插件的配置](https://developer.huawei.com/consumer/cn/doc/start/hosdevassistant-config-0000002588511280)。

## 多设备适配

本章节以VS Code为例描述如何对HarmonyOS应用/元服务工程进行多设备适配，在其他IDE上操作类似。

1. 在VS Code中打开待适配的工程。
2. 进入插件界面，左下角切换模式为"一多适配"，在对话框中输入提示语，输出具体的适配要求（建议包含适配范围、适配项目与目标设备）。
   * 如需进行全工程一次性处理，提示语可参考如下范例：帮我对当前工程进行折叠屏和平板的响应式缩进布局适配。
   * 如需进行指定范围/问题的适配，提示语可参考如下范例：帮我解决登录界面在Pura X Max展开态内屏上软键盘留白问题。

   插件会根据界面适配任务复杂度自动判断是否生成高保真；您也可以在提示语中明确要求生成，如"实施修改前生成高保真让我确认"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3a/v3/rGarw35yT6G91jGThnnpew/zh-cn_image_0000002724248691.png?HW-CC-KV=V1&HW-CC-Date=20260922T021030Z&HW-CC-Expire=31536000000&HW-CC-Sign=2509845D36E68BB250BC7995C448F0724B167AFD6F0AA2CD4D1D4002034933AB)
3. 插件开始启动适配流程。整个流程中，插件会在每个关键节点请求您的审视与确认，以确保方案始终贴合您的意图。
   1. 插件解析工程并分析适配场景，与开发者确认适配场景。
   2. 确认无误后，插件生成任务执行计划，推送给开发者确认。
   3. 基于确认结果，插件生成标准化SPEC，推送至开发者审核。若提示语中指定了高保真需求，还会同步输出高保真预览；若未指定，插件会根据界面适配任务复杂度自动判断是否生成高保真。
   4. 审核通过后进行执行阶段，插件基于SPEC生成适配代码。
   5. 插件请求开发者确定自动化测试任务后，拉起模拟器自动执行编译安装，发起测试并完成问题闭环；多模交互测试任务还会将适配后的新页面截图上传至多模态模型来验证页面UI效果。
   6. 插件输出最终适配报告与代码Diff。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d8/v3/FSxD4_jiQQW5EU__9MrPRg/zh-cn_image_0000002694295800.png?HW-CC-KV=V1&HW-CC-Date=20260922T021030Z&HW-CC-Expire=31536000000&HW-CC-Sign=A10013FC02E6ADB2C6FF66EDC1319E708F3C373032D5B8D97B6599BD019562D5)
4. 您可在"待审批文件"栏审核代码Diff，选择接纳或者撤销修改。如不操作，则默认为全部接纳。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e1/v3/Sp8DZ4ygSNSMoUIo8iL8OA/zh-cn_image_0000002724020509.png?HW-CC-KV=V1&HW-CC-Date=20260922T021030Z&HW-CC-Expire=31536000000&HW-CC-Sign=A088D7B2B5472EF31C1A391753693FB3284FA3AF5A9B8562B7CB03EBE458537B "点击放大")

5. 进入资源管理器界面，可获取适配后的工程代码。后续您也可以手动将工程推送到DevEco Studio模拟器上验证适配效果。
