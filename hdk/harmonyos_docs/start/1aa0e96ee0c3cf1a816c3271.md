# 商品下架

商户可以下架已上架的商品，若下架商品下的某规格（如下步骤3说明），则该规格不再显示，其他规格正常销售；如下架整个商品（如下步骤4说明）或下架该商品下的所有规格，则该商品及商品下所有规格皆不在前台显示，且后续不可对该商品做任何操作。

商品下架后不可恢复，如需重新上架需重新发布新商品，请谨慎操作。

## 操作步骤

1. 进入[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)页面。

2. 点击左侧导航的"商品管理"进入商品列表。

3. **下架某一商品规格** 。（若需下架整个商品，请忽略此步骤）。

a. 点击商品操作列的"编辑"，进入商品信息编辑页面。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4b/v3/fj00ar0xSZyEqcQ--3JXng/zh-cn_image_0000002592816744.png?HW-CC-KV=V1&HW-CC-Date=20260909T155944Z&HW-CC-Expire=31536000000&HW-CC-Sign=408BB115DA75A3867C49453E224D7868A16AE1E4821D6E50C6961E4A5CEA4304 "点击放大")

b. 选择需要下架的商品规格，点击操作列的"删除"，即可下架该规格。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d0/v3/YdeDwodaTd-zh_NHTiNdyQ/zh-cn_image_0000001325968925.png?HW-CC-KV=V1&HW-CC-Date=20260909T155944Z&HW-CC-Expire=31536000000&HW-CC-Sign=3E64B4CD5B28708D68AC8858094F37A6BD0244335A795834D23F4E34D197762F "点击放大")

4. **下架整个商品** （若仅下架商品的某一规格，请忽略此步骤）。

a. 选择需要下架的商品，点击操作列的"下架"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7e/v3/nktR73qmRyaedTsuBpjh5w/zh-cn_image_0000002592976886.png?HW-CC-KV=V1&HW-CC-Date=20260909T155944Z&HW-CC-Expire=31536000000&HW-CC-Sign=1177A36FEA3574D1736213ADF71D3BE41317A83250972248558C5700F26C842C "点击放大")

a. 在商品下架页面填写商品下架原因、详细下架原因及商户自检文件（仅付费商品需上传，免费商品无需上传**）** ，点击提交，由运营进行审核，审核通过后商品自动下架。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/82/v3/srIDGq9CTiOoIT2FGP9wng/zh-cn_image_0000001082379638.png?HW-CC-KV=V1&HW-CC-Date=20260909T155944Z&HW-CC-Expire=31536000000&HW-CC-Sign=E0F6E277F628B9F2A5918D1EBFD9F4FF33BACB1783C6732B0D0A10809BE75133 "点击放大")
> 说明
>
> * 商户自检文件 即《华为开发者联盟生态市场商品下架申请函》，商户填写后，需加盖公章并上传。
