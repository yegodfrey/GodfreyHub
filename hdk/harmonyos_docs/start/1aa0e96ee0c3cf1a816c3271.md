# 商品下架

商户可以下架已上架的商品，若下架商品下的某规格（如下步骤3说明），则该规格不再显示，其他规格正常销售；如下架整个商品（如下步骤4说明）或下架该商品下的所有规格，则该商品及商品下所有规格皆不在前台显示，且后续不可对该商品做任何操作。

商品下架后不可恢复，如需重新上架需重新发布新商品，请谨慎操作。  

#### 操作步骤

1. 进入[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)页面。

2. 点击左侧导航的"商品管理"进入商品列表。

3. 下架某一商品规格。（若需下架整个商品，请忽略此步骤）。

a. 点击商品操作列的"编辑"，进入商品信息编辑页面。

![](https://media:401788750496481093 "点击放大")

b. 选择需要下架的商品规格，点击操作列的"删除"，即可下架该规格。

![](https://media:401788750496521094 "点击放大")

4. 下架整个商品（若仅下架商品的某一规格，请忽略此步骤）。

a. 选择需要下架的商品，点击操作列的"下架"。

![](https://media:401788750496575095 "点击放大")

a. 在商品下架页面填写商品下架原因、详细下架原因及商户自检文件（仅付费商品需上传，免费商品无需上传），点击提交，由运营进行审核，审核通过后商品自动下架。

![](https://media:401788750496612096 "点击放大")  
![](https://media:401788750496638097)  
* 商户自检文件 即《华为开发者联盟生态市场商品下架申请函》，商户填写后，需加盖公章并上传。
* 可邮件咨询：partner@huawei.com，并获取。
