# SDK隐私政策规范性参考

提供SDK的商户需提供隐私政策链接，确保遵守适用的法律法规，履行个人信息保护义务，并遵循合法、正当、必要和诚信的处理原则。  

#### 1. 隐私政策提交规范

#### 1.1 总体规范及展示路径

（1）提供SDK的商户必须在鸿蒙生态伙伴SDK专区提供自身的可便捷查看的隐私政策链接。隐私政策内容需公开透明，且需和SDK在运行中对用户个人信息的处理保持一致。提供SDK的商户必须确保该链接始终能正常打开。

（2）隐私政策必须单独成文，不可作为用户协议的一部分存在。

（3）隐私政策中必须有明确的开发者主体，且仅需要在隐私政策中声明1次即可。如使用的隐私政策为集团或第三方隐私政策，您需要在隐私政策中明确说明集团或第三方与开发者的关联关系。

（4）展示路径：隐私政策将在SDK详情页隐私政策位置进行展示，见下图：

#### 1.2 隐私政策链接格式参考

隐私政策自动化审核需要读取您提供的隐私政策，并进行自动化分析，如果提供的隐私协议链接不支持内容获取（比如PDF、图片格式等），可能会造成审核不通过，需要人工进行处理。如果希望快速通过审核，请开发者尽量提供符合规范的隐私政策链接。

隐私政策链接规范如下：

（1）标准url格式：如 http(s): //www.example.com/privacy/；

（2）为静态html页面，用中文文字显示，统一一种字体，统一一种编码格式，无乱用符号，不需登录、点击、不需再跳转，允许对内容进行自动化分析、验证；

（3）链接不能为博客、微博、Github和云笔记等；

（4）不为pdf、word、图片等文件格式。  

#### 2. 隐私政策内容规范

隐私政策结构需清晰明了，有主题划分，易于用户阅读与理解。建议您按照如下结构排版撰写隐私政策结构大纲：  

#### 一、我们如何收集和使用用户的个人信息

写作指导：以文字描述方式介绍SDK提供的功能范围及每个功能处理个人信息的相关内容。SDK收集使用个人信息因功能而异，可分为必选与可选两类，需明确告知用户信息收集的目的、范围、方式、使用频率、是否为扩展功能等。如果涉及处理敏感个人信息，相关说明需要加粗显示。

* 功能必选情况下的个人信息收集与使用： 目的：为实现SDK的核心功能，如登录、支付等。

  方式：通过用户授权，收集必要的个人信息，如用户名、密码、支付信息等。

  范围：如设备型号、操作系统版本、网络状态等，仅限于完成特定功能所需的信息，确保数据的最小化和精确性。

  频率：如在SDK初始化时收集一次，之后仅在必要时进行更新。
* 功能可选情况下的个人信息收集与使用： 目的：提供额外的增值功能，如个性化推荐、社交分享等。

  方式：在用户选择开启相应功能后，收集相关信息以优化服务体验。

  范围：如浏览记录、兴趣爱好、位置信息等，根据用户选择的功能进行信息收集，不涉及非必要数据的收集。

  频率：根据用户实际使用情况和功能需求进行动态收集和处理。
* 如果涉及个性化推荐或大数据分析业务功能，需要描述其业务功能所使用的个人信息种类、目的意图、主要运行机制。
* 必要个人信息和可选个人信息：在每个功能的描述中，要区分描述对应所需必要个人信息、可选个人信息，如："SDK会收集必要个人信息XXX和根据您/开发者的配置收集可选个人信息XXX，以提供XXX能力"或"如果您或开发者使用xxx功能，则会额外收集可选个人信息XXX,XXX"。  

#### 二、设备权限调用

写作指导：介绍SDK依赖的权限，说明权限的使用目的，不涉及可裁剪。嵌套第三方SDK的权限暂不用说明。权限范围包括：

* 敏感权限范围：

HarmonyOS NEXT定义的user_grant权限：包括位置、相机、麦克风、图片和视频、音乐和音频、通讯录、日历、运动数据、蓝牙、星闪、身体传感器等。

提示：user_grant权限可能随着操作系统版本更新发生变化，当前系统支持权限组请参考[应用权限组列表](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/app-permissions)。

* 应仅声明实现SDK服务目的合理关联的系统权限，不应声明与SDK功能无关的系统权限。
* SDK不应使用其未声明但SDK使用者应用软件已申请的相关系统权限。
* 应声明和申请对最终用户权益影响最小的系统权限，如粗略和精准位置的不同场景申请等。
* 权限名称必须使用HarmonyOS定义的权限名称。

样例：  

|权限名称|权限说明|使用目的|
|:-------------------------|:---------------|:----------------|
|如：ohos.permission.INTERNET|如：允许使用Internet网络|在使用XX功能时，用于访问网络数据|

#### 三、对未成年人的保护

如果SDK会向未成年人收集任何个人信息和敏感信息，则需在隐私政策中制定专门的未成年人个人信息处理规则，清晰的说明收集未成年人个人数据的范围和用途，并且要求开发者以显著、清晰的方式获得监护人的合法授权。

样例：

我们非常重视对未成年人个人信息的保护，我们将严格按照国家法律法规要求对未成年人提供服务并对未成年人提供保护。如果您是未成年人，需要您的父母或其他监护人同意您使用开发者应用并同意相关应用的服务条款。父母或其他监护人也应采取适当的预防措施来保护未成年人，包括监督其对开发者应用的使用。

特别地，如果您是儿童（不满十四周岁的未成年人），在您使用开发者应用和我们的服务前，请务必通知您的父母或其他监护人一起仔细阅读开发者应用隐私声明、本声明以及我们专门制定的《XXX未成年人隐私保护声明》，并在您的父母或其他监护人同意或指导后，使用开发者应用和我们的服务或向我们提供信息。如果您是儿童的父母或其他监护人，请确保您监护的儿童在您的同意或指导下使用开发者应用和我们的服务以及向我们提供信息。  

#### 四、与第三方共享

如涉及向第三方共享的场景，需要提供此内容，不涉及可裁剪。

样例：

为了向您提供部分功能/服务，例如【功能1】、【功能2】等，我们需要将您的个人信息提供给第三方。为了保障您的数据安全和隐私，我们与合作伙伴签订了数据安全保护协议，明确了合作伙伴对您的数据的保护责任、义务和要求。

目前本应用（或服务）涉及共享信息合作伙伴列表如下：  

|第三方名称|处理目的和方式|涉及个人信息种类|第三方官网链接或 隐私声明链接|
|:-----|:------|:--------|:--------------|
|XX有限公司|安全保障|IMEI、OAID|https://xxxxx|

#### 五、SDK集成第三方服务声明

写作指导：如SDK涉及集成使用第三方SDK需要提供此内容，不涉及可裁剪。应明示使用的第三方SDK名称、主体名称、处理个人信息类型及目的、个人信息处理规则等。

样例：

为了向您提供部分功能/服务，例如社交分享，我们集成了合作伙伴的软件工具开发包（简称"SDK"）或其他类似的应用程序。  

|第三方SDK/服务名称|第三方公司名称|收集个人信息类型|使用目的|隐私政策链接|
|:----------|:-------|:-----------------|:------|:------------|
|微信分享SDK|腾讯科技有限公司|设备标识符，您分享的内容、图片、视频|分享内容至微信|https://xxxxx|

#### 六、SDK关联启动其他应用声明

写作指导：如SDK涉及关联启动App需要提供此内容，不涉及可裁剪。需要向开发者告知SDK关联启动App的场景和目的，要求在其隐私政策中告知用户。  

#### 七、管理用户的个人信息

写作指导：详细说明个人信息控制者对个人信息进行安全保护的措施。包括但不限于：

（1）个人信息完整性保护措施，个人信息传输、存储和备份 过程的加密措施，个人信息访问、 使用的授权和审计机制，个人信息的保留和删除机制等。

（2）最终用户行使其决定、查阅、复制、转移、更正、补充、删除等权利的方式和程序。

（3）基于个人同意处理个人信息的，应提供有效的最终用户撤回同意的方式。

（4）法律、行政法规规定应当告知的其他事项。  

#### 八、信息存储地点及期限

（一）存储地

写作指导：如涉及数据跨境传输，请在此予以详细说明

我们会在以下情况跨境处理您的信息：

出于【例如，出于业务运作的考虑，包括开展营销、调查、促销和业务开发以及客户支持】，我们需要向【数据跨境的接收方的名称或姓名】分享您的【XX数据类型】，信息分享前我们会【XX方法：如完成国家安全评估，签署DTA等（业务根据实际情况写）】，采用【XX技术：如数据传输加密等（业务根据实际情况写）】保障您的数据安全。若您需要进一步了解【接收方】详情，您可以【访问其官网链接XXX/拨打其电话XXX/通过发送待咨询的问题到XX邮箱】 。

若您需要行使您的相关权利，可以访问/咨询【接收方联系方式】。

出于业务完整运作的考虑，我们需要向XX公司分享您的文本信息，信息分享前我们已经完成了XX评估，以及数据分享过程我们会采用加密的技术保障您的数据安全，若您需要进一步了解XX公司详情，您可以访问其官网链接：XXX。

若您需要行使您的相关权利，可以访问XX公司的官网链接XXX，与他们取得联系。

写作指导：按功能维度介绍每个功能收集的个人信息存储期限及到期后的处理方式。

【具体的数据留存时间说明】

在您注销账号后，XX、XX将立刻删除，XX、XX因【填写原因】将保存XXX后删除。

XX、XX保留期限不超过\\仅保存XX。

样例：

#### 九、如何联系我们

提供明确的反馈和投诉的渠道，并明确提供收到回应的时间。  

#### 十、隐私政策变更

当隐私政策发生重大变化，需及时更新隐私政策，并明确说明使用何种方式及时通知用户。
