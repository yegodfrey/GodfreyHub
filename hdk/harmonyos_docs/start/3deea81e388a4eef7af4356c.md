# 三方库鸿蒙化

插件支持通过对话方式，快速将非鸿蒙版本的三方库鸿蒙化，供HarmonyOS应用使用，有效降低手动适配成本。

当前支持对Flutter、React Native和Android原生三方库鸿蒙化。  

#### 前提条件

* 已获取三方库文件。
* 根据三方库类型完成本地环境搭建：Flutter三方库需[完成Flutter环境搭建](https://gitcode.com/openharmony-tpc/flutter_samples/blob/master/ohos/docs/03_environment/OpenHarmony-flutter环境搭建指导.md)，React Native三方库需[完成React Native环境搭建](https://gitcode.com/CPF-RN/ohos_react_native/blob/main/README.md)。
* 已[登录插件](https://developer.huawei.com/consumer/cn/doc/start/hosdevassistant-login-0000002588351354)。
* 已[完成插件的配置](https://developer.huawei.com/consumer/cn/doc/start/hosdevassistant-config-0000002588511280)。  

#### 转换三方库

本章节以VS Code为例描述如何进行三方库鸿蒙化，在其他IDE上操作类似。

1. 在VS Code中打开待转换的三方库工程。 ![](https://media:401788748921922512 "点击放大")

2. 进入插件界面，在左下角切换模式为"三方库鸿蒙化"，在对话框中输入类似下述提示语：将当前工程进行鸿蒙化适配。 ![](https://media:401788748921979513)

3. 等待各阶段任务执行完成。 ![](https://media:401788748922085514 "点击放大")

4. 进入资源管理器界面，查看鸿蒙化后的三方库工程。 "ohos"目录下即为鸿蒙化三方库，供项目后续调用。

   ![](https://media:401788748922437515 "点击放大")

   "example \> ohos"目录下还提供了鸿蒙化三方库的Demo样例，供您查看转换效果。

![](https://media:401788748922576516 "点击放大")  

#### 在模拟器上运行鸿蒙化三方库Demo

1. 使用DevEco Studio打开"example \> ohos"目录下的Demo工程。
2. 在模拟器中运行Demo，具体请参考[使用模拟器运行应用](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-run-emulator)。

![](https://media:401788748922756517 "点击放大")  

#### 在真机上运行鸿蒙化三方库Demo

1. 使用DevEco Studio打开"example \> ohos"目录下的Demo工程。
2. 将Demo推送到连接的真机上运行，具体请参考[使用本地真机运行应用](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-run-device)。

![](https://media:401788748922864518 "点击放大")
