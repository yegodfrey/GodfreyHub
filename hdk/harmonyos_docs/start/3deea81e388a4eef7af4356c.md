# 三方库鸿蒙化

插件支持通过对话方式，快速将非鸿蒙版本的三方库鸿蒙化，供HarmonyOS应用使用，有效降低手动适配成本。

当前支持对Flutter、React Native和Android原生三方库鸿蒙化。

## 前提条件

* 已获取三方库文件。
* 根据三方库类型完成本地环境搭建：Flutter三方库需[完成Flutter环境搭建](https://gitcode.com/openharmony-tpc/flutter_samples/blob/master/ohos/docs/03_environment/OpenHarmony-flutter环境搭建指导.md)，React Native三方库需[完成React Native环境搭建](https://gitcode.com/CPF-RN/ohos_react_native/blob/main/README.md)。
* 已[登录插件](https://developer.huawei.com/consumer/cn/doc/start/hosdevassistant-login-0000002588351354)。
* 已[完成插件的配置](https://developer.huawei.com/consumer/cn/doc/start/hosdevassistant-config-0000002588511280)。
