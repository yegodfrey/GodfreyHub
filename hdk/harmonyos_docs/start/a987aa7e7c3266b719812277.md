# 自动发货接口整体方案

本章描述了第三方服务接入生态市场需要实现自动发货接口定义，您通过实现以下接口，即可获得为用户成功开通、续费或者变更的信息，并将成功信息返回给生态市场展示给用户。每次接口的调用都需要做安全校验和签名校验。

## 自动发货接口开发要求

在进行接口开发之前，需要先了解接口开发的整体要求：

|项目|说明|
|:-----|:--------------------------------|
|传输协议|仅支持HTTPS传输协议（443端口）|
|请求方法|除验证Token和免登接口外，其他接口均采用POST方法提交|
|数据格式|提交和响应均为JSON格式|
|字符编码|统一使用UTF-8字符编码|
|签名算法|HMAC_SHA256|
|签名规则|参见"[签名规则](#section26527379136)"描述|
|请求超时时间|10s|

## 安全方案

**安全校验规则**

生态市场发送给您的所有请求中会以 URL参数（GET 参数）的方式添加如下安全校验参数到URL上。包含的安全校验参数如下：

|参数|类型|说明|
|:--------|:------|:-------------------------------------------------------------|
|timestamp|Integer|UNIX时间戳。|
|eventId|String|32位随机字符串，包含大小写字母、数字。|
|signature|String|加密签名，signature中包含提前约定的deliveryKey和请求URL中的eventId和timestamp等参数。|

> 说明
>
> 安全参数通过URL参数承载，无业务含义。实际的业务参数均通过消息体承载。

**签名规则**

您需要对请求中的加密签名进行校验，校验规则如下：

1. 通过 timestamp判断是否已经超时（当前建议验签超时时间为30s）。
2. 将 timestamp、eventId 两个参数及deliveryKey进行字典排序。

> 注意
>
> 免登接口为GET请求方式，除上述参数外，action、instanceId、requestId等请求参数也要进行字典排序。

3. 将排序后的字符串，拼接成一个完整字符串并进行HMAC-SHA256加密，加密秘钥取deliveryKey，详见[HMAC-SHA256加密](https://commons.apache.org/proper/commons-codec/apidocs/org/apache/commons/codec/digest/HmacUtils.html)。
4. 您将加密后的字符串与 signature 对比即可。

**示例**

假设请求为：https://www.website.com?timestamp=1&eventId =2&signature=xxxx，则根据signature生成规则，signature=base64_encode(HMAC_SHA256(deliveryKey,"deliveryKey=3&eventId=2&timestamp=1"))，

其中base64_encode为base64编码方法。

**签名校验**

签名校验示例代码（Java）：

```screen
public static boolean verifySignature(String parameterTimestamp, String parameterEventId,
    String parameterSignature) {
    String deliveryKey = "00xxxxFC"; // deliveryKey线下提供
    List<String> params = new ArrayList<>();
params.add(parameterTimestamp);
params.add(parameterEventId);
params.add(deliveryKey);

    List<String> valueToDigestList = params.stream().sorted().collect(Collectors.toList());
    String valueToDigest = StringUtils.join(valueToDigestList, "");
    String signature = Base64
        .encodeBase64String(HmacUtils.hmacSha256Hex(deliveryKey, valueToDigest).getBytes(StandardCharsets.UTF_8));
return StringUtils.equals(signature, signature);
}
```

> 注意
>
> deliveryKey为服务接入时针对单个服务生成的安全秘钥，由生态市场和商户提前约定。deliveryKey仅参与计算，不携带进入请求参数中。
