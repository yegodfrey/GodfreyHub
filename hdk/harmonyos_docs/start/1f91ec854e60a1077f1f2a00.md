# API接口主动通知方式

主动通知方式适用于用户购买完成之后，立即开通的产品。

如果采用主动通知的生产方式，您需要按照先配置API的URL信息，包含：密钥、开通服务URL、续费服务URL、服务过期通知URL、服务释放通知URL、获取实例URL，API配置完成后还需进行API测试 。
