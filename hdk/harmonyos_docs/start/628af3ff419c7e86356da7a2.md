# 生态路径介绍

生态市场针对个人开发者、企业开发者及服务商均有针对性的生态路径，可满足不同身份的合作伙伴的各类生态需求，助力业务发展与商业成功。

当前：

①、企业开发者可直接创建SDK，服务商可入驻成为商户后上架商品，成为卖家；

②、个人开发者及企业开发者可选购心仪商品进行购买，成为买家。  

|序号|账号类型|身份|权限|备注|
|:------:|:----------:|:-:|:------------------------------------:|:----------:|
|1 <br />|个人开发者 <br />|买家|选购/下载任意上架产品；可发布定制化需求。|/|
|2|企业开发者|买家|选购/下载任意上架产品；可发布定制化需求。|/|
|3|企业开发者|卖家|创建SDK：企业开发者账号创建的SDK仅支持在生态市场展示，不支持购买；|不支持其他品类创建与发布|
|4|服务商|卖家|可上架SDK、开发服务、培训服务、人力服务等相关商品；可在需求广场进行抢单。|需满足上架规范及条件|
