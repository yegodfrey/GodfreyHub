# 华为云授权认证

选择华为云授权认证需要您的账号已在华为云平台完成实名认证。如您的账号已在华为云实名认证为企业客户，通过华为云授权认证只能实名认证为华为开发者联盟的企业开发者。

操作指导：

1. 使用已经实名认证的华为云账号登录[华为开发者联盟官网](https://developer.huawei.com/consumer/cn/)进入认证方式选择页面，点击华为云授权认证的"下一步"前往华为云授权页面。
