# 企业资料人工审核认证注意事项

1. 企业名称与企业证件上登记公司名称一致。
2. 确保营业执照为最新的营业执照，政府/事业单位提供最新的事业单位法人证书/统一社会信用代码证书；社会团体提供最新的社会团体法人登记证书。
3. 上传的图片可以添加"华为开发者认证、华为备案"等水印；但不能包含受限水印或遮挡关键信息，例如公司名称、公司证件号。
4. 如果您用于认证的证件是刚颁发的新证件，建议在颁发日期的7个工作日后再提交实名认证申请，否则可能会导致认证失败。
5. 您需要确保提交的证件在有效期内，且不能临近过期，否则会导致认证失败（企业证件自认证之日起6个月内不过期，法定代表人身份证自认证之日起3个月内不过期）。
