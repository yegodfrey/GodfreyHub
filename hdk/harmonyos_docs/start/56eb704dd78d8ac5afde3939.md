# 账号归属区别

* 选择个人开发者，完成实名认证后的账号归属个人。适用群体为个人、个体工商户。
* 选择企业开发者，完成实名认证后的账号归属企业。适用群体为企业、党政及国家机关、事业单位、民办非企业单位、社会团体、社会组织。

账号认证的开发者类型对您的账号归属有很大影响。例如，使用个人手机或个人邮箱注册认证为企业开发者，账号责任人变动（离职、调岗），产生账号纠纷时，可能会对企业账号的使用产生不便。

建议您使用公共邮箱或公共手机号注册华为账号并申请企业实名认证，避免个人账号信息与企业开发者信息绑定，影响账号后续使用。
