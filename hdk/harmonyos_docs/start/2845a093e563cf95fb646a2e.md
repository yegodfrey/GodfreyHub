# 确定商户并支付

选择并**确认商户，** 核对方案和合同，并点击**提交订单**，然后按照双方合同约定线上支付款项。

1. 登录**买家中心**。
2. 在左侧导航栏，点击**需求管理**。
3. 在需求列表中找到目标需求，在需求详情的方案列表中选择目标商户，点击确认商户"√"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9b/v3/QXpKCM9wQSS35GODuJm1rA/zh-cn_image_0000002141421872.png?HW-CC-KV=V1&HW-CC-Date=20261008T185209Z&HW-CC-Expire=31536000000&HW-CC-Sign=CFB013F550185DD9F5DFFD6A2C7023651D61DC381DBFEB25CF0F641C451C9AB3 "点击放大")

4. 提交订单
   * 核对订单信息，并仔细阅读合同内容无误，勾选"同意"，点击提交订单。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a6/v3/myQDYGZJRmiF02IUxFCsbg/zh-cn_image_0000001126115369.png?HW-CC-KV=V1&HW-CC-Date=20261008T185209Z&HW-CC-Expire=31536000000&HW-CC-Sign=CA359387E459576A6BFD114FF07EB075562A299BB17727CC5F7AF73A865101CC "点击放大")

     > 注意
     > * 勾选"同意"即表示您同意并自愿按照该合同内容履行合同义务。
5. 线上支付
   * 确认订单价格，使用企业网银支付。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7d/v3/erlN6QONSQOurNvnv2DD1Q/zh-cn_image_0000002509359907.png?HW-CC-KV=V1&HW-CC-Date=20261008T185209Z&HW-CC-Expire=31536000000&HW-CC-Sign=0CDE81C9DACD9DF22CC917F8382D82CBC9CED28B57AB8807E4AA439B1F6E1D3A "点击放大")

   * 支付完成后，订单状态即进入"交付中"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cf/v3/y6rRBKj6SLO0z-TMBzoC6A/zh-cn_image_0000002477464412.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T185209Z&HW-CC-Expire=31536000000&HW-CC-Sign=21BF40B9770F6105AA5F64AAD0950AE4171F683834007687E44162A3ACC068B5 "点击放大")
