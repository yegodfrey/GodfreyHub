# 确定商户并支付

选择并**确认商户，** 核对方案和合同，并点击**提交订单**，然后按照双方合同约定线上支付款项。

1. 登录**买家中心**。
2. 在左侧导航栏，点击**需求管理**。
3. 在需求列表中找到目标需求，在需求详情的方案列表中选择目标商户，点击确认商户"√"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9b/v3/QXpKCM9wQSS35GODuJm1rA/zh-cn_image_0000002141421872.png?HW-CC-KV=V1&HW-CC-Date=20260909T175107Z&HW-CC-Expire=31536000000&HW-CC-Sign=FCE038DE21842908C07D1BD115E303C2B4469C02DA0F5F5791C5A0E8087626EE "点击放大")

4. 提交订单
   * 核对订单信息，并仔细阅读合同内容无误，勾选"同意"，点击提交订单。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a6/v3/myQDYGZJRmiF02IUxFCsbg/zh-cn_image_0000001126115369.png?HW-CC-KV=V1&HW-CC-Date=20260909T175107Z&HW-CC-Expire=31536000000&HW-CC-Sign=43B54C1CCF5D5EB8E5306C97F4BED9D9A096846EAE8E7E3EC6009E6C9DB248C4 "点击放大")

     > 注意
     > * 勾选"同意"即表示您同意并自愿按照该合同内容履行合同义务。
5. 线上支付
   * 确认订单价格，使用企业网银支付。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7d/v3/erlN6QONSQOurNvnv2DD1Q/zh-cn_image_0000002509359907.png?HW-CC-KV=V1&HW-CC-Date=20260909T175107Z&HW-CC-Expire=31536000000&HW-CC-Sign=E299910ACC478C152852697CBF79CF55BB088D1EB5328DBB8926B4F4207F0CBD "点击放大")

   * 支付完成后，订单状态即进入"交付中"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cf/v3/y6rRBKj6SLO0z-TMBzoC6A/zh-cn_image_0000002477464412.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T175107Z&HW-CC-Expire=31536000000&HW-CC-Sign=7E64B72BE6DA508362887D753D0CB9244E678657B67D745E33BFB2E7A857314C "点击放大")
