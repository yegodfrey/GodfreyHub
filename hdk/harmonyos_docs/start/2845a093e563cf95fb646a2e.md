# 确定商户并支付

选择并确认商户，核对方案和合同，并点击提交订单，然后按照双方合同约定线上支付款项。

1. 登录买家中心。
2. 在左侧导航栏，点击需求管理。
3. 在需求列表中找到目标需求，在需求详情的方案列表中选择目标商户，点击确认商户"√"。 ![](https://media:401788750496868102 "点击放大")

4. 提交订单
   * 核对订单信息，并仔细阅读合同内容无误，勾选"同意"，点击提交订单。 ![](https://media:401788750496921103 "点击放大")

     ![](https://media:401788750496948104)  
     * 勾选"同意"即表示您同意并自愿按照该合同内容履行合同义务。
5. 线上支付
   * 确认订单价格，使用企业网银支付。 ![](https://media:401788750496993105 "点击放大")

   * 支付完成后，订单状态即进入"交付中"。 ![](https://media:401788750497027106 "点击放大")
