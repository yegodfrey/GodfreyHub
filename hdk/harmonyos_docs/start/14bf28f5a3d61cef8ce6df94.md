# 交易管理相关功能

本文介绍需求管理和需求订单两个交易管理功能。

## 需求管理

当需求方向您定向发布需求、或您在需求广场抢单后，即会产生需求。需求管理是对定向需求和已接单需求的管理功能。

### 需求列表

进入**卖家中心-** **需求管理，**待接单需求/需求管理列表提供了一些过滤筛选条件供您快速找到相应需求。

1. 需求ID：如果客户通过定制需求下单，此处ID为每条需求的唯一ID，可以使用ID进行需求查询。

2. 需求标题：需求方所发布的一句话需求描述，可以使用需求标题进行需求查询。

3. 需求来源：如果需求方向您定向发布的需求，来源为：定向发布；如果您在需求广场进行抢单，需求来源为：需求广场。

4. 需求类型：需求方发布需求的类型，可以根据需求一二级类型进行需求筛选 。

5. 预算范围：需求方发布的需求预算。

6. 需求方：展示需求方的用户名，可以根据需求方用户名进行需求查询。

7. 创建时间：需求方创建需求的时间，可以根据时间进行需求筛选。

8. 需求状态：需求的生命周期状态。

* 沟通中：已接单需求，此时可上传方案和合同。


* 交付中：已下单需求，此时状态的订单可进行上传交付件等操作。


* 已成交：已下单且完成交付件验收的需求。


* 已关闭：已撤销的需求、已取消、退款已完成的需求。

9. 操作：

* 待接单需求页：接受需求（选择接受后需求即归入需求管理页）、拒绝。


* 需求管理：常用操作包括联系需求方、上传方案和交付件等。

### 需求详情

除了列表页的常用信息外，详情页还会显示以下需求相关信息：

1. 需求方信息：展示需求方账号名称。

2. 需求内容：包含列表页信息、服务地域和需求文件（如有），并提供了关联的订单号的链接（状态为交付中的需求）。关于订单业务，请参考[需求订单](#section022812170110)。

3. 沟通记录：与客户沟通中可添加沟通记录，会显示在这里。

4. 方案列表：已上传的方案及交付件会显示在这里。

5. 合同管理：展示已上传合同文件、报价、服务有效期和需求确认状态。

## 需求订单

当需求方对定制需求下单后，即会产生订单。需求订单是对定制需求产生的所有订单的管理功能。

## 订单列表

进入**卖家中心-需求订单，**订单列表提供了一些过滤筛选条件供您快速找到相应的订单。

1. 订单编号：每条订单的唯一编号，可以使用编号进行订单查询。

2. 需求标题：订单所关联的需求链接。关于需求，请参考[需求管理](#section16995195517511)。

3. 订单价格：此价格和您在合同管理中维护的报价一致。

4. 买家名称：展示需求方的用户名和联系方式。

5. 创建时间：用户下单时间。

6. 订单状态：订单的生命周期状态。

* 待支付：买家提交订单后，未进行支付。


* 交付中：买家支付后，进入交付中状态。


* 已完成：已下单且完成交付件确认的订单。


* 已关闭：已取消、退款已完成的订单。
* 退款：买家发起退款申请的订单。

7. 操作：常用操作包括审核退款等。

## 订单详情

除了订单列表页的常用信息外，详情页还会显示以下订单相关信息：

* 需求方信息：展示需求方账号名称。
* 订单信息: 订单备注：需求方提交订单时添加的备注，会显示在这里。

  退款情况（如有）：退款状态（点击链接可查看退款审核历史）。

  取消原因（如有）：需求方取消订单时填写的取消原因，会显示在这里。
* 合同信息：展示已签署的合同名称（点击可查看合同文件）、合同状态和服务有效期。
