# 配置插件

在正式使用插件前，您需要先配置AI模型与DevEco Studio安装路径。如需使用三方库鸿蒙化功能，您还需要先配置对应的运行环境。本章节以VS Code为例描述配置操作，在其他IDE上的操作类似。

## 配置模型

1. 首次登录插件，界面会提示您当前未配置模型，点击"去配置"链接。 说明
   >
   > 后续如需修改模型配置，可点击插件右上角设置按钮进入模型配置界面操作。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e1/v3/bFnosutMTsG2sXchg6WieQ/zh-cn_image_0000002690137332.png?HW-CC-KV=V1&HW-CC-Date=20260915T115630Z&HW-CC-Expire=31536000000&HW-CC-Sign=BBACA10262BDABC975771DF7BCFA998106D8A2B84896260D38A0521327E7C0D3)
2. 进入模型配置界面。通常您可以通过供应商添加常见的模型，如您需使用的模型不在供应商列表内，可通过URL添加。
   * 方式一：通过供应商添加
     1. 在"通过供应商添加"页签，点击"添加模型"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/85/v3/-kHotMU7RYibyV6_VBJoSA/zh-cn_image_0000002684834670.png?HW-CC-KV=V1&HW-CC-Date=20260915T115630Z&HW-CC-Expire=31536000000&HW-CC-Sign=E95B27C82AF6FF6C5D2E5FA500C093C559B10AEA1D4AC46E87158CBEF56A8758)

     2. 选择供应商，并输入对应的API Key，点击"保存"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cd/v3/HO0iBHYGQWC1qTmYtn8k8A/zh-cn_image_0000002684857414.png?HW-CC-KV=V1&HW-CC-Date=20260915T115630Z&HW-CC-Expire=31536000000&HW-CC-Sign=9052DB1B9EF4870DEA70D5C6E05AC3DAEADD6272BB0B390F29FFF259E93DEE97)

   * 方式二：通过URL添加
     1. 在"通过URL添加"页签，点击"添加模型"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9c/v3/jCxEgRHKRkC7UVgJ4khENQ/zh-cn_image_0000002714581113.png?HW-CC-KV=V1&HW-CC-Date=20260915T115630Z&HW-CC-Expire=31536000000&HW-CC-Sign=0396810D6F03007549DDB161CB5A2399943BBCDE9924FFD3BF38AF1C4C0756E7)

     2. 配置模型的名称、协议、URL、API Key和模型，点击"保存"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/95/v3/GpBvBS_KRei_LhVNB4rkTg/zh-cn_image_0000002714587577.png?HW-CC-KV=V1&HW-CC-Date=20260915T115630Z&HW-CC-Expire=31536000000&HW-CC-Sign=BAA27537CB21EFBB7484F8C76927ED18A5D2805E632101D6155723E1EF7F0538)

   > 说明
   >
   > 多设备适配的多模交互验证功能可执行UI效果比对验证，显著提升适配效果，强烈建议您使用此功能。此功能要求配置多模态大模型（如kimi3、minimax3）。

## 配置DevEco Studio安装路径

1. 点击插件右上角设置按钮。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e8/v3/scYyehqkS_GkqNDibSTpKg/zh-cn_image_0000002658599974.png?HW-CC-KV=V1&HW-CC-Date=20260915T115630Z&HW-CC-Expire=31536000000&HW-CC-Sign=62A3B2043918F255CFCE2652B3934040E5D0565283535987951E9ECE735ADCA6)

2. 在"基础配置 > DevEco-Studio配置"栏，设置本地DevEco Studio的安装路径。 说明
   >
   > Mac上可以手动复制DevEco-Studio安装路径保存：打开Finder进入Applications应用列表，找到DevEco-Studio图标，右键选择Show Package Contents，进入应用内部目录。选中Contents文件夹，按住option键并右键选择Copy Contents as Pathname，即可获取到DevEco-Studio安装路径。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f6/v3/AAk6MedTS3K4egpxPOtVxg/zh-cn_image_0000002688719407.png?HW-CC-KV=V1&HW-CC-Date=20260915T115630Z&HW-CC-Expire=31536000000&HW-CC-Sign=8C0B7E2F4527603A9E373B52B2D901C4963D9685A3A94F64FA1097948E817513)

## （可选）配置Flutter运行环境

如需使用Flutter三方库鸿蒙化功能，您需要先[完成Flutter环境搭建](https://gitcode.com/openharmony-tpc/flutter_samples/blob/master/ohos/docs/03_environment/OpenHarmony-flutter环境搭建指导.md)，然后在插件内配置Flutter运行环境参数。

1. 点击插件右上角设置按钮。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b5/v3/olNfu1rFQQaUgrR2UHDn3g/zh-cn_image_0000002691499990.png?HW-CC-KV=V1&HW-CC-Date=20260915T115630Z&HW-CC-Expire=31536000000&HW-CC-Sign=D1A0DB65E70FBDB211AB0E81E4DBE470520CA9E1466DE6061C7FCF7FBD50C5D0)

2. 在"基础配置 > Flutter环境配置"栏，设置Flutter运行环境参数，包括Flutter SDK根目录、Pub缓存路径、Pub仓库地址、Flutter存储镜像。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ff/v3/n329mEK3R3OgcrvZXVpVDg/zh-cn_image_0000002726512731.png?HW-CC-KV=V1&HW-CC-Date=20260915T115630Z&HW-CC-Expire=31536000000&HW-CC-Sign=56936FB9E2A7082E046937FC0E7E87A60E657286C72D2DE5BE8CFCE6721B5F75 "点击放大")

## （可选）配置React Native运行环境

如需使用React Native三方库鸿蒙化功能，您需要先[完成React Native环境搭建](https://gitcode.com/CPF-RN/ohos_react_native/blob/main/README.md)，然后在插件内配置React Native运行环境参数。

1. 点击插件右上角设置按钮。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7c/v3/EZxH6xrJRP-ZMNzPIYEN_A/zh-cn_image_0000002691501748.png?HW-CC-KV=V1&HW-CC-Date=20260915T115630Z&HW-CC-Expire=31536000000&HW-CC-Sign=FFE40355B93314C7453247105333CB678CC64B57A2DD3BCE63659E42C9A4E86A)

2. 在"基础配置 > RN配置"栏，设置CAPI环境变量。默认值RNOH_C_API_ARCH=1。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/37/v3/i2Z5PtoVTuKInme_V8_4Ng/zh-cn_image_0000002696953436.png?HW-CC-KV=V1&HW-CC-Date=20260915T115630Z&HW-CC-Expire=31536000000&HW-CC-Sign=4AE5A6923F0ABF4B0C97CB853B3E4E31F1A587B9179E5E45F554A73D459E76A8 "点击放大")
