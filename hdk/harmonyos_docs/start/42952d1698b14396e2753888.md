# 配置插件

在正式使用插件前，您需要先配置AI模型与DevEco Studio安装路径。如需使用三方库鸿蒙化功能，您还需要先配置对应的运行环境。本章节以VS Code为例描述配置操作，在其他IDE上的操作类似。

## 配置模型

1. 首次登录插件，界面会提示您当前未配置模型，点击"去配置"链接。 说明
   >
   > 后续如需修改模型配置，可点击插件右上角设置按钮进入模型配置界面操作。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8b/v3/q6bi_W-USTWr5G9nRM-l_A/zh-cn_image_0000002690137332.png?HW-CC-KV=V1&HW-CC-Date=20260924T082630Z&HW-CC-Expire=31536000000&HW-CC-Sign=C9C2F266DBA494BB6965EBAED8CF3686E22E8B8CDB4AD9463EBE2823FAA3C405)
2. 进入模型配置界面。通常您可以通过供应商添加常见的模型，如您需使用的模型不在供应商列表内，可通过URL添加。
   * 方式一：通过供应商添加
     1. 在"通过供应商添加"页签，点击"添加模型"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3b/v3/8ksdW0jJQDyjCm4c5PIuMg/zh-cn_image_0000002684834670.png?HW-CC-KV=V1&HW-CC-Date=20260924T082630Z&HW-CC-Expire=31536000000&HW-CC-Sign=DC5950D651CB88296CB51AD2CE7AF1AF8CD43482FFB8029D23D48FD97630E25C)

     2. 选择供应商，并输入对应的API Key，点击"保存"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/85/v3/Ytjm80NWTyWujBXeBl6SJA/zh-cn_image_0000002684857414.png?HW-CC-KV=V1&HW-CC-Date=20260924T082630Z&HW-CC-Expire=31536000000&HW-CC-Sign=3256CBD6D2D61ED23B2768522291F2E84F6F840F07B98E78BA4452CD9109A8D9)

   * 方式二：通过URL添加
     1. 在"通过URL添加"页签，点击"添加模型"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0/v3/8K9leHmuTRaSZRKIpgVIXw/zh-cn_image_0000002714581113.png?HW-CC-KV=V1&HW-CC-Date=20260924T082630Z&HW-CC-Expire=31536000000&HW-CC-Sign=DDD7ED24A006AE0F0ED026A6E497DB409BEBC1AAB57D732BDD184A35368FE1C1)

     2. 配置模型的名称、协议、URL、API Key和模型，点击"保存"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c5/v3/yuuQsAXbQhOOrJRpk9hXMw/zh-cn_image_0000002714587577.png?HW-CC-KV=V1&HW-CC-Date=20260924T082630Z&HW-CC-Expire=31536000000&HW-CC-Sign=201A3EB995D5C1B23A07E733AD20C002A15382DB151BB02C8C5EA6A78B8285B4)

   > 说明
   >
   > 多设备适配的多模交互验证功能可执行UI效果比对验证，显著提升适配效果，强烈建议您使用此功能。此功能要求配置多模态大模型（如kimi3、minimax3）。

## 配置DevEco Studio安装路径

1. 点击插件右上角设置按钮。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/52/v3/ZzkNVKm1TTmHFU6ncAnV3A/zh-cn_image_0000002658599974.png?HW-CC-KV=V1&HW-CC-Date=20260924T082630Z&HW-CC-Expire=31536000000&HW-CC-Sign=AB0E2F4014EA4490F15EA58252DAC8380208C2B251DCE204E0813132729981A0)

2. 在"基础配置 > DevEco-Studio配置"栏，设置本地DevEco Studio的安装路径。 说明
   >
   > Mac上可以手动复制DevEco-Studio安装路径保存：打开Finder进入Applications应用列表，找到DevEco-Studio图标，右键选择Show Package Contents，进入应用内部目录。选中Contents文件夹，按住option键并右键选择Copy Contents as Pathname，即可获取到DevEco-Studio安装路径。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/14/v3/Yvfxy3fPRnSFY5su56SsnA/zh-cn_image_0000002688719407.png?HW-CC-KV=V1&HW-CC-Date=20260924T082630Z&HW-CC-Expire=31536000000&HW-CC-Sign=6DBB2EA783722CD592EE6A09DA1762AE4871FB6560C4BD0519352F483C5F3B1A)

## （可选）配置Flutter运行环境

如需使用Flutter三方库鸿蒙化功能，您需要先[完成Flutter环境搭建](https://gitcode.com/openharmony-tpc/flutter_samples/blob/master/ohos/docs/03_environment/OpenHarmony-flutter环境搭建指导.md)，然后在插件内配置Flutter运行环境参数。

1. 点击插件右上角设置按钮。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a1/v3/U49aenu-Rp-c32GjUOaPmg/zh-cn_image_0000002691499990.png?HW-CC-KV=V1&HW-CC-Date=20260924T082630Z&HW-CC-Expire=31536000000&HW-CC-Sign=4E911F3B1179ADAF6EE34F79AEF12E863630D0D2413170308FDD8077228C2FDB)

2. 在"基础配置 > Flutter环境配置"栏，设置Flutter运行环境参数，包括Flutter SDK根目录、Pub缓存路径、Pub仓库地址、Flutter存储镜像。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e4/v3/7N4SWic6QBWtOP4uB8YDiA/zh-cn_image_0000002726512731.png?HW-CC-KV=V1&HW-CC-Date=20260924T082630Z&HW-CC-Expire=31536000000&HW-CC-Sign=2D4CD846929C74A3280DB02841CD3E3EF806D62C45CEDA277CF43D9BAA6A64A9 "点击放大")

## （可选）配置React Native运行环境

如需使用React Native三方库鸿蒙化功能，您需要先[完成React Native环境搭建](https://gitcode.com/CPF-RN/ohos_react_native/blob/main/README.md)，然后在插件内配置React Native运行环境参数。

1. 点击插件右上角设置按钮。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cb/v3/dFQBxn3iRR-GzeGoPm44Eg/zh-cn_image_0000002691501748.png?HW-CC-KV=V1&HW-CC-Date=20260924T082630Z&HW-CC-Expire=31536000000&HW-CC-Sign=92B16335F2660411525D33AB1D378834C670F4A6C130F11D064DE3539565A6DF)

2. 在"基础配置 > RN配置"栏，设置CAPI环境变量。默认值RNOH_C_API_ARCH=1。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/37/v3/zpjvTTvrQNiJKkNoABCFaw/zh-cn_image_0000002696953436.png?HW-CC-KV=V1&HW-CC-Date=20260924T082630Z&HW-CC-Expire=31536000000&HW-CC-Sign=93D143E0F9B29AE021F7624B3F3115DB0A05DE07BEEDC31BBF6C2DAECED8FD1D "点击放大")
