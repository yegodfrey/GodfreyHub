# 配置插件

在正式使用插件前，您需要先配置AI模型与DevEco Studio安装路径。如需使用三方库鸿蒙化功能，您还需要先配置对应的运行环境。本章节以VS Code为例描述配置操作，在其他IDE上的操作类似。

## 配置模型

1. 首次登录插件，界面会提示您当前未配置模型，点击"去配置"链接。 说明
   >
   > 后续如需修改模型配置，可点击插件右上角设置按钮进入模型配置界面操作。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/59/v3/rS_RHfogSt6qYKm0o5OB2w/zh-cn_image_0000002690137332.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=BA628B08B92A6595787C57DF29C4475E3261D4976DC7C3E760B93DBBE95FDD1C)
2. 进入模型配置界面。通常您可以通过供应商添加常见的模型，如您需使用的模型不在供应商列表内，可通过URL添加。
   * 方式一：通过供应商添加
     1. 在"通过供应商添加"页签，点击"添加模型"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/41/v3/G6FYIuJGS6-mTN0KKhKfKQ/zh-cn_image_0000002778619539.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=731C70400EFB412E1081C8D4DFDFD7B9E7D485DEC309A29395C35C6DC0E7C565)

     2. 选择供应商，并输入对应的API Key，点击"保存"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/50/v3/uf2GFgbrRfSrR_quIswsBQ/zh-cn_image_0000002684857414.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=F7357737C4AFD1FB492FA9782BD761B19F63418F7962678B3EE7EFB2DAB8BC48)

   * 方式二：通过URL添加
     1. 在"通过URL添加"页签，点击"添加模型"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/46/v3/rmFoVWDMSX-l4EXV3uuQPw/zh-cn_image_0000002748981378.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=2FBECE617AFFB2AA3E1D1D4EA29A817BB3BB8BAFE85FF35730FC7336669A35E8)

     2. 配置模型的名称、协议、URL、API Key和模型，点击"保存"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cc/v3/lCujaRoeTlqTIyuoO0bRdg/zh-cn_image_0000002778614099.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=7153CF7F51313BC22217B1FD912E0BB853CB0099DD8D01000B626FF973C0681F "点击放大")

   > 说明
   >
   > 多设备适配的多模交互验证功能可执行UI效果比对验证，显著提升适配效果，强烈建议您使用此功能。此功能要求配置多模态大模型（如Kimi-K3、MiniMax-M3）。

## 配置DevEco Studio安装路径

1. 点击插件右上角设置按钮。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fa/v3/Iv4mRByTShyo4wsxi0ou8A/zh-cn_image_0000002658599974.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=8D52FE4E7D7519F5A91160442B4362318CBDA6F57BD3DBEF6C865E3F48F60A1D)

2. 在"基础配置 > DevEco-Studio配置"栏，设置本地DevEco Studio的安装路径。 说明
   >
   > Mac上可以手动复制DevEco-Studio安装路径保存：打开Finder进入Applications应用列表，找到DevEco-Studio图标，右键选择Show Package Contents，进入应用内部目录。选中Contents文件夹，按住option键并右键选择Copy Contents as Pathname，即可获取到DevEco-Studio安装路径。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9c/v3/-6kEZPDtSG2tDcZ2KHfSKg/zh-cn_image_0000002778742009.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=B290F1C4C2F341D738D3E3C1D0DA18885A8EC58D89134B4FD219D5432C10709B "点击放大")

## （可选）配置Flutter运行环境

如需使用Flutter三方库鸿蒙化功能，您需要先[完成Flutter环境搭建](https://gitcode.com/openharmony-tpc/flutter_samples/blob/master/ohos/docs/03_environment/OpenHarmony-flutter环境搭建指导.md)，然后在插件内配置Flutter运行环境参数。

1. 点击插件右上角设置按钮。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f5/v3/EN92ZClVQs-KQjL95EKgIw/zh-cn_image_0000002691499990.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=302F02907F1D749A473FE3E7B2D14C76A5CE97834B9CE1490FF10A19F2B74B1D)

2. 在"基础配置 > Flutter环境配置"栏，设置Flutter运行环境参数，包括Flutter SDK根目录、Pub缓存路径、Pub仓库地址、Flutter存储镜像。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6a/v3/CTuBMkaRQ0atig4i6budDA/zh-cn_image_0000002778621503.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=F9ACB2C236088C43484514F602829FDF69863906211721D90923BF469BB258BF)

## （可选）配置React Native运行环境

如需使用React Native三方库鸿蒙化功能，您需要先[完成React Native环境搭建](https://gitcode.com/CPF-RN/ohos_react_native/blob/main/README.md)，然后在插件内配置React Native运行环境参数。

1. 点击插件右上角设置按钮。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d1/v3/eVdGymriQmuWigK_-CGNRw/zh-cn_image_0000002691501748.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=7D52C1178FE3B50E5F9CE7B64E154692D600217138D26A1FCAC890BFA15A8949)

2. 在"基础配置 > RN配置"栏，设置CAPI环境变量。默认值RNOH_C_API_ARCH=1。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8e/v3/yMnt17GdRAKz4Waf0vcgvw/zh-cn_image_0000002748982236.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=8E812942D1F9DF9CA1CB3616F88DADD24A79181BB976CC00FBDD33789BE7D3AC)
