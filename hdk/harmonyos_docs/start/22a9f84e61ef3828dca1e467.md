# 成员账号使用指导

无论开发者是否有华为账号都可以收到由团队账号持有者或成员发出的加入团队邀请。若该账号只使用团队账号下系统管理、应用市场（AppGallery Connect）和流量变现服务相关业务，则无需进行实名认证，即可在角色权限内进行操作；若该账号需要使用主题中心业务，则需要完成开发者实名认证（企业或个人），才可以在相关角色权限内进行操作。  

#### 如何成为团队成员账号

接受团队成员邀请：

* 账号持有者添加成功后，成员会收到一封含有激活链接的邀请邮件。打开邀请邮件，被邀请成员需在邮件内显示的期限内点击"点击激活您的华为账号xxxxx"，即可跳转到开发者联盟激活页面。

* 未注册的华为账号也可接受邀请，成员需要在邀请邮件所显示的期限内，先注册华为账号再接受邀请，验证成功后即可加入该团队。

#### 切换团队

若您已加入多个团队，在操作时，您可以在管理中心及应用市场的页面中随时查看您当前所在团队或切换至所在的其他团队。具体操作如下：

1. 管理中心：鼠标箭头放置在右上角头像处，可查看当前所在团队名称。如需切换团队，可点击下拉箭头展开所有团队进行选择。同时，若您已完成华为开发者实名认证，您也可以点击您认证的名称，进入至您本人的账号管理中心。蓝色带星号小旗帜标记了本人账号认证的主体名称。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250916151620.25708027102078250909452027659665:50001231000000:2800:3DB62259F322E58175880D89BA836C3071E5113F3A1F79F31B9BA4D839FE6F30.png)

2. 在应用市场AppGallery Connect的页面中也可以查看或切换团队，[点击此处](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-manageaccount-0000001099996700#section118755447354)查看详情。  

#### 查看账号信息

1. 查看/修改自己在团队内的信息。 选择自己需查看信息的团队，点击左侧"开发者中心 -- 开发者信息"在此可以查看您在该团队内的信息角色、权限等信息。

   您也可以在此修改在本团队内的相关信息，包括：
   * 在团队内显示的昵称；

   * 团队成员接受该团队内相关信息的联系邮箱；

   * 团队成员是否接受团队内由系统发送的有关账号持有者在商户服务及付费服务的相关信息，此处默认打开；

   * 选择收取系统发送的信息的语种，此处语种默认为账号持有者当前使用的语种；

   * 选择是否接受营销邮件，此处默认关闭。

   此处团队成员信息为邀请人在邀请该团队成员时填写的相关信息，同时账号持有者或其他有修改权限的成员有权在邀请成功后对团队成员的"昵称"与"联系邮箱"进行修改。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250916151621.92952421595354895529139593038248:50001231000000:2800:877A15E4C706EF45129A70C8657804B988F69C1DE8D139CA5F049A120590A3A3.png)
2. 查看团队账号持有者信息：选择自己需查看信息的团队，点击左侧"开发者中心 -- 开发者信息"，在此可以查看该团队的账号持有者信息。
3. 查看其他团队成员信息：团队成员若需查看所加入的团队内其他成员信息，可点击头像-团队成员列表，选择所需查看的团队名称，点击左侧"开发者中心 -- 团队账号"即可查看其成员账号信息、角色及应用查看维度。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250916151621.14091205390870088567615675421346:50001231000000:2800:38ECA5A0A82BCC273762BDAD189373720C13678B2CD7738E7F332645956DD409.png)

#### 退出团队账号

1. 主动退出团队。 点击右上角头像，选择自己需退出的团队，点击左侧"开发者中心 -- 开发者信息"，将页面移动至底部，此处设有"离开团队"按钮，点击此按钮并点击弹窗中的"确认"即可退出该团队。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250916151621.55537506059164167071244337181095:50001231000000:2800:BFBD2BA748DDFD11259AB68101C6C1372B6BDEC97E54E4AF19C4D6FE40746709.png)
2. 账号到期退出团队。
   * 账号持有者可设定团队成员在其团队内的有效时间，若团队成员账号在到期前账号持有者未续期，则该成员账号会在到期后该账号无法登入该团队，相关角色及权限即失效。
   * 系统会在团队成员账号到期前一个月及一周发送提醒信息至团队成员提供的联系邮箱中，若需继续使用该团队账号的相关功能，请及时与账号持有者/管理员联系，及时对您的团队成员账号期限进行修改。
   * 当账号持有者的账号处于停用、销户等异常状态时，成员账号在团队切换界面仍可以看到该团队信息，但团队名称置灰，且点击后无法进入团队管理中心，系统会弹窗提示账号持有者状态异常，此时成员账号可以点击弹窗中按钮，离开当前团队。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250916151621.98311804799843475351288191246528:50001231000000:2800:28378EDD1DD32A47C0D365AAA5F32A6BB32C02EED5A3952F87D4E1DA7E924472.png)  
团队成员账号无论在任何情况下退出团队，都需要进行重新邀请操作，团队成员通过邀请邮件确认后才能再次加入该团队。  

#### 成员账号邀请成员账号及管理

同一个团队中，系统管理员账号及应用市场中的管理员账号及APP管理员，已支持邀请新的团队成员账号。具体权限如下：  

|业务|角色|权限|备注|
|:---------------------|:-----|:-----------------------------|:-----------------------|
|系统权限（联盟管理中心）|管理员|此角色可以添加、删除、邀请和修改除管理员本身以外的成员。|/|
|应用市场AppGallery Connect|管理员|该角色可添加应用市场业务内其他角色成员（法务除外）。|被邀请者可拥有邀请者的部分或者全部应用访问权限。|
|应用市场AppGallery Connect|APP管理员|该角色可添加应用市场业务内其他角色成员（管理员与法务除外）。|被邀请者可拥有邀请者的部分或者全部应用访问权限。|
