作品以"智慧交通与交通安全"为总体目标，提供了一种基于边缘计算的道路交叉口的交通事故智能识别与分析系统，用于辅助交警和事故双方分析交通事故、判定责任。

## 应用价值

交通路口是交通事故主要发生地之一，来自不同方向的交通流在此汇集，形成交通流冲突点，导致其交通状况比道路其他部分要复杂得多，故交通路口成为交通事故发生的高风险区域。当交通事故发生时，当事人往往会因事故责任的归属产生分歧，此时需采取报警并保留事故现场的处理措施，但这样易造成局部交通的拥堵或瘫痪，影响城市交通的正常通行。同时，交警到达现场后还需调取该路口的视频录像进行事故责任分析，如果没有雷达测速，整个事故处理流程繁琐耗时。

作品通过轨迹还原及车速估算，可清晰地看到事故发生原因，辅助交警和事故双方分析交通事故、判定责任。通过HiKey970开发板，可便捷地在各个交通路口部署此作品，在本地完成交通事故的分析和处理，通过边缘计算为智慧城市的建设做贡献。

## 实现路径

为了准确有效地识别出监控视频中的交通事故，开发者复现了ICPR 2014年会议上的论文"Motion Interaction Field for Accident Detection in Trafﬁc Surveillance Video"。根据论文提出的算法，可以准确地判断是否发生交通事故以及事故发生的位置。为了识别事故车辆，开发者使用了深度学习模型------YOLOv3来进行车辆识别。

算法上，作品通过MIF模型生成运动交互场的光流算法进行事故检测和发生地定位，使用CNN深度神经网络和层次聚类算法进行车辆检测与跟踪。为了分析事故，作品设计了UFIR滤波器对事故车辆的轨迹进行还原，自动计算车辆速度、位置和碰撞轨迹。为了得到车辆速度和碰撞角度，开发者使用透视变换将轨迹图转化为俯视图，通过分析俯视图获取车速和碰撞角度。事故检测和分析所需的技术目前均已通过Python实现，并在计算机中进行了仿真验证。在Intel Core i7-9750H CPU @2.60GHz, 32GB RAM设备中，此算法可流畅进行，并得到准确的事故分析结果和事故报告。

作品已经在计算机和华为研制的基于麒麟970芯片的人工智能开发板------HiKey970上成功复现项目的全部功能，通过边缘计算为智慧城市建设助力。当代码部署在HiKey970开发板以及云端，交警和事故双方就可以通过手机连接开发板或云服务器，对交通事故进行快速处理和分析，以有效避免因交通事故纠纷引发的交通拥堵和事故逃逸。
