# 4. SDK处理个人信息

您的产品及服务需要尊重用户隐私，确保遵守适用的法律法规，履行个人信息保护义务，并遵循合法、正当、必要和诚信的处理原则。同时，您应协助SDK使用者合规地使用SDK，保护用户隐私。您的SDK在处理用户个人信息时，需要遵守的要求包括不限于如下：  

#### 最小必要

4.1 SDK收集和使用个人信息应当具有明确、合理的目的，并与处理目的直接相关。

4.2 SDK收集和使用个人信息应当限于实现处理目的的最小范围。

4.3 SDK收集和使用个人信息的类型、频次、精度应满足实现业务功能所必须的最小范围。

4.4 应仅在SDK使用者使用具体业务功能时，开始收集和使用个人信息。

4.5 SDK使用者或最终用户拒绝提供可选个人信息，SDK不应拒绝提供与该信息无关的业务功能。

4.6 不再提供某项个人信息收集能力时，应同步移除相关个人信息收集代码。

4.7 不应声明与SDK功能无关的系统权限。

4.8 根据业务功能所需集成必要的第三方SDK，不应集成冗余的第三方SDK。

4.9 SDK在非服务所必须或无合理应用场景下，不得自启动或关联启动。  

#### 隐私告知

4.10 应简洁、清晰、易懂地公开展示SDK个人信息处理规则。

4.11 SDK应单独制定个人信息处理规则，内容不限于包括：个人信息处理者的名称或者姓名和联系方式；个人信息的处理目的、处理方式，处理的个人信息类型、保存期限；个人行使本法规定权利的方式和程序；法律、行政法规规定应当的其他事项。

4.12 应明确SDK基本业务功能和扩展业务功能，区分描述对应所需必要个人信息、可选个人信息，以及需向最终用户申请的系统权限。

4.13 涉及敏感个人信息的描述应采用文字加粗、字号增大等方式突出显示。

4.14 处理不满十四周岁未成年人个人信息的，应当制定专门的个人信息处理规则。

4.15 向中华人民共和国境外提供个人信息的，应明示境外接收方的名称或者姓名、联系方式、处理目的、处理方式、个人信息类型以及最终用户向境外接收方行使权利的方式和程序等事项。

4.16 处理个人信息进行个性化推荐或大数据分析业务功能的，应告知其业务功能所使用的个人信息类型、目的意图、主要运行机制等。

4.17 涉及分享个人信息至其他第三方的，应明示第三方产品名称、主体名称、处理个人信息类型及目的、个人信息处理规则等。

4.18 涉及集成使用第三方SDK的，应明示使用的第三方SDK名称、主体名称、处理个人信息类型及目的、个人信息处理规则等。

<br />

#### 获取同意

4.19 处理个人信息前应告知处理个人信息规则，并协助SDK使用者取得最终用户的同意。

4.20 基于个人同意处理个人信息的，应协助SDK使用者向最终用户提供有效的撤回同意的方式。

4.21 处理敏感个人信息前，应协助SDK使用者取得最终用户的单独同意。

4.22 处理不满十四周岁未成年人个人信息前，应协助SDK使用者取得未成年人的父母或其他监护人的同意。

4.23 处理个人信息涉及跨境传输的，应协助SDK使用者取得最终用户的单独同意。

4.24 收集个人信息用于个性化推荐功能或大数据分析业务的，应向SDK使用者告知并在取得最终用户的授权同意情况下方可开展相关业务功能。  

#### 权限使用

4.25 声明SDK所需权限及其使用场景，由SDK使用者应用软件向系统申请相关权限。

4.26 仅声明实现SDK功能所必要的系统权限。

4.27 应仅在SDK使用者使用具体业务功能时，申请对应系统权限。

4.28 不应使用未声明但SDK使用者应用软件已申请的相关系统权限。

4.29 最终用户拒绝相关权限申请，SDK不应拒绝提供与该权限无关的业务功能，或频繁弹窗向最终用户申请该权限。
