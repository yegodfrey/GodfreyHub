# 购买服务

API服务一般指的是算法或者数据的集成，开发者在购买API服务后，可以通过服务的调用地址来获取相关的服务（算法或数据）。

如果您没有华为开发者联盟账号，需要先注册账号并通过实名认证。详细操作请参见账号[注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。

## 获取访问Token

获取身份访问凭据后，您便可以使用身份凭据获取Token。

**功能介绍**

在使用API服务前，需要通过华为开放平台进行鉴权，并获取认证通过后的Token。

**接口原型**

|---------|-------------------------------------------------------------------|
|**承载协议**|HTTPS POST|
|**接口方向**|开发者服务器 -> 华为服务器|
|**接口URL**|https://connect-api.cloud.huawei.com/api/oauth2/v1/token|
|**数据格式**|请求：Content-Type: application/json 响应：Content-Type: application/json|

**请求参数**

请求参数以JSON格式传入，包含参数如下:

|**参数名称**|**必选(M)/可选(O)**|**数据类型**|**参数说明**|
|:------------|:--------------|:-----------|:------------------------|
|grant_type|M|String(256)|固定传入"client_credentials"。|
|client_id|M|String(256)|客户端ID，即获取身份凭证中的"客户端ID"。|
|client_secret|M|String(2048)|客户端密钥，即获取身份凭证中的"客户端密钥"。|
|service_code|M|String|服务Code，即获取身份凭证中的"服务Code"。|

**请求示例**

```screen
1.  POST /api/oauth2/v1/token
2.  Host: connect-api.cloud.huawei.com
3.  Content-Type: application/json
4.  {
5.     "grant_type":"client_credentials",
6.     "client_id":"26********20",
7.     "client_secret":"************************"
8.     "service_code":"C-example"
9.  }
```

**响应参数**

返回值为JSON格式的字符串，包含参数如下。

|**参数名称**|**必选(M)/可选(O)**|**数据类型**|**参数说明**|
|:-----------|:--------------|:----------|:-----------------------------------------------------------------------------------------------------------------|
|access_token|O|String|访问Token，用于API服务接口调用。 此参数只在获取成功时返回。|
|expires_in|O|Long|access_token的有效期，单位秒。您需要在过期时间到达时重新调用本接口获取新的access_token。 此参数只在获取成功时返回。|
|ret|O|String(100)|获取Token失败时的错误信息，包含错误码及描述信息的JSON字符串，格式为{"code":*retcode* , "msg": "*description*"}，retcode为错误码，description为错误码描述信息。|

**调用示例**

```screen
1.  public static String getToken(String domain, String clientId, String clientSecret, String serviceCode) {
2.      String token = null;
3.      try {
4.          HttpPost post = new HttpPost(domain + "/oauth2/v1/token");
5.   
6.   
7.          JSONObject keyString = new JSONObject();
8.          //client_id亦可通过方法参数clientId传入
9.          keyString.put("client_id", "18893***83957248");
10.        //client_secret亦可通过方法参数clientSecret传入
11.        keyString.put("client_secret", "B15B497B44E080EBE2C4DE4E74930***52409516B2A1A5C8F0FCD2C579A8EB14");
12.        keyString.put("grant_type", "client_credentials");
13.        //service_code亦可通过方法参数serviceCode传入
14.        keyString.put("service_code","C-example")
15. 
16. 
17.        StringEntity entity = new StringEntity(keyString.toString(), Charset.forName("UTF-8"));
18.        entity.setContentEncoding("UTF-8");
19.        entity.setContentType("application/json");
20.        post.setEntity(entity);
21. 
22. 
23.        CloseableHttpClient httpClient = HttpClients.createDefault();
24.        HttpResponse response = httpClient.execute(post);
25.        int statusCode = response.getStatusLine().getStatusCode();
26.        if (statusCode == HttpStatus.SC_OK) {
27.            BufferedReader br =
28.                new BufferedReader(new InputStreamReader(response.getEntity().getContent(), Consts.UTF_8));
29.            String result = br.readLine();
30.            JSONObject object = JSON.parseObject(result);
31.            token = object.getString("access_token");
32.        }
33.        post.releaseConnection();
34.        httpClient.close();
35.    } catch (Exception e) {
36. 
37. 
38.    }
39.    return token;
40.}
```

获取到用于访问API的Access Token后，您便可以根据服务详情页中的API文档使用API。
