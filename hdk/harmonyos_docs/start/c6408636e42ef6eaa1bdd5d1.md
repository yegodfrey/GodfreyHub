# 在VS Code中安装

## 搭建安装环境

请确保电脑配置满足如下要求：

* 操作系统：
  * *-win32-x64.vsix支持运行于Windows
  * *-darwin-x64.vsix支持运行于macOS 12+ (Intel)
  * *-darwin-arm64.vsix支持运行于macOS 12+ (Apple Silicon)
* VS Code：最低版本VS Code 1.85.0，推荐版本VS Code 1.90+（建议使用近半年内的稳定版） 说明
  >
  > 支持码道、TRAE CN、CodeBuddy等基于VS Code底座开发的IDE在"IDE模式"安装使用HarmonyOS开发助手。
* DevEco Studio：DevEco Studio 6.1版本及以上
* Node.js：最低版本Node.js 18.x，推荐版本Node.js 20.x LTS（如需使用多设备适配功能，最低版本须为Node.js 22.x）
