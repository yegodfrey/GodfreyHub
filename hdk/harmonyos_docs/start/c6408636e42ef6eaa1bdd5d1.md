# 在VS Code中安装

#### 搭建安装环境

请确保电脑配置满足如下要求：

* 操作系统：
  * \*-win32-x64.vsix支持运行于Windows
  * \*-darwin-x64.vsix支持运行于macOS 12+ (Intel)
  * \*-darwin-arm64.vsix支持运行于macOS 12+ (Apple Silicon)
* VS Code：最低版本VS Code 1.85.0，推荐版本VS Code 1.90+（建议使用近半年内的稳定版）
* DevEco Studio：DevEco Studio 6.1版本及以上
* Node.js：最低版本Node.js 18.x，推荐版本Node.js 20.x LTS（如需使用一多适配功能，最低版本须为Node.js 22.x）  

#### 安装插件

1. 打开VS Code，点击左侧活动栏的扩展面板按钮。 ![](https://media:901788320231696137)

2. 在顶部搜索框中输入关键词"HarmonyOS Dev Assistant"，找到插件"HarmonyOS Dev Assistant for VS Code"，点击"Install"。 ![](https://media:901788320231735138)

3. 点击"Trust Publisher \& Install"。 ![](https://media:901788320231772139)

4. 等待插件安装，完成后左侧活动栏将展示插件图标![](https://media:901788320231802140)，点击图标，打开HarmonyOS开发助手登录界面。
