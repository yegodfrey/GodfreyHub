# 删除账号组成员

1. 用账号组管理员账号登录[华为开发者联盟官网](https://developer.huawei.com/consumer/cn/)，进入"管理中心 > 开发者中心 > 账号组"，在成员列表中找到需要删除的成员账号，点击"删除"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bc/v3/ncjYkLNHRN6jgv5-mRqrqQ/zh-cn_image_0000002585521910.png?HW-CC-KV=V1&HW-CC-Date=20260909T141305Z&HW-CC-Expire=31536000000&HW-CC-Sign=58058978984346D7A293872A468CF793BB338A4344E6F6060A44DD45BBAB0E6E "点击放大")


2. 仔细阅读弹框内容后点击"确定"，该成员账号从账号组中删除。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b0/v3/vwg9o4ItSFa4H2puUJR7CA/zh-cn_image_0000002436592914.png?HW-CC-KV=V1&HW-CC-Date=20260909T141305Z&HW-CC-Expire=31536000000&HW-CC-Sign=B455BE68CBEAA8B7F6AA805AA10E089B58C95E3AD838C81611EBCE150168E694 "点击放大")
