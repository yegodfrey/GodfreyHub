# 删除账号组成员

1. 用账号组管理员账号登录[华为开发者联盟官网](https://developer.huawei.com/consumer/cn/)，进入"管理中心 \> 开发者中心 \> 账号组"，在成员列表中找到需要删除的成员账号，点击"删除"。

   ![](https://media:801782184086112427 "点击放大")

<!-- -->

2. 仔细阅读弹框内容后点击"确定"，该成员账号从账号组中删除。 ![](https://media:801782184086199428 "点击放大")
