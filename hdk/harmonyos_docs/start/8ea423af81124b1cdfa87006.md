# 申请退款

用户在商品确认验收前，可申请退款。已确认验收的商品无法申请退款。

1. 登录[买家中心](https://developer.huawei.com/consumer/cn/market/buyer/cloud-orders)。

2. 找到需要退款的订单，点击申请退款。

![](https://media:401788750485798930 "点击放大")

3. 填写退款金额，选择退款原因，并写明详细的退款说明，点击提交。

![](https://media:401788750485835931 "点击放大")

4.卖家审核退款通过后，退款金额将原路退回到您的支付账户。
