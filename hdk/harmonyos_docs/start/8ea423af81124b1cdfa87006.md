# 申请退款

用户在商品确认验收前，可申请退款。已确认验收的商品无法申请退款。

1. 登录[买家中心](https://developer.huawei.com/consumer/cn/market/buyer/cloud-orders)。

2. 找到需要退款的订单，点击申请退款。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ec/v3/EMRLLgDNQpGTqPgYcCBoFA/zh-cn_image_0000001079238008.png?HW-CC-KV=V1&HW-CC-Date=20260909T170811Z&HW-CC-Expire=31536000000&HW-CC-Sign=B926A337905A8E0770AC3D13835C2DC321CBF8EB480009B2C0D5FD56ED0AAAEA "点击放大")

3. 填写退款金额，选择退款原因，并写明详细的退款说明，点击提交。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d1/v3/zSyGGq8MQXqf85vSdLstUA/zh-cn_image_0000002141313074.png?HW-CC-KV=V1&HW-CC-Date=20260909T170811Z&HW-CC-Expire=31536000000&HW-CC-Sign=C497DA0F9B6F5D1A0443001A666B92537808763B9FB1712CBE4DA67756CB0B36 "点击放大")

4.卖家审核退款通过后，退款金额将原路退回到您的支付账户。
