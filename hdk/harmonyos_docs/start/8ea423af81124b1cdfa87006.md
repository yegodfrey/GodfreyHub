# 申请退款

用户在商品确认验收前，可申请退款。已确认验收的商品无法申请退款。

1. 登录[买家中心](https://developer.huawei.com/consumer/cn/market/buyer/cloud-orders)。

2. 找到需要退款的订单，点击申请退款。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ec/v3/EMRLLgDNQpGTqPgYcCBoFA/zh-cn_image_0000001079238008.png?HW-CC-KV=V1&HW-CC-Date=20261008T180701Z&HW-CC-Expire=31536000000&HW-CC-Sign=F1D65C6B6E7A533783808C50AE379523A6A17D03B6E06330F1A64659E699A045 "点击放大")

3. 填写退款金额，选择退款原因，并写明详细的退款说明，点击提交。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d1/v3/zSyGGq8MQXqf85vSdLstUA/zh-cn_image_0000002141313074.png?HW-CC-KV=V1&HW-CC-Date=20261008T180701Z&HW-CC-Expire=31536000000&HW-CC-Sign=D0369D0758E848AEC4199C33742121849B3FAC6625E71479A4A5182EA178A132 "点击放大")

4.卖家审核退款通过后，退款金额将原路退回到您的支付账户。
