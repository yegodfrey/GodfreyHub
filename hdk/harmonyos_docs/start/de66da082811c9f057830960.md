# 使用入门

为了保证用户能够正常使用您上架的SaaS服务，您必须首先完成SaaS服务相关自动发货接口的开发：

1. 了解SaaS服务接口开发的整体要求、安全校验规格、签名及验签的规则，详情请参见[自动发货接口整体方案](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-marketplace-spsaasservice-autodeliveryprg-0000001249275447)。
2. 您需要针对不同使用阶段用户的需求，完成用户使用全流程过程中的涉及的所有接口开发。
   * 用户购买成功后您需要[创建实例](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-marketplace-spsaasservice-createinstance-0000001249235405)为用户提供服务。
   * 用户选择续费服务后您需要[续费实例](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-marketplace-spsaasservice-renewinstance-0000001248915453)刷新实例过期时间。
   * 用户购买的服务套餐过期后您需要[过期实例](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-marketplace-spsaasservice-expinstance-0000001204355450)停止用户使用。
   * 用户购买的服务套餐过期7天后您需要[销毁实例](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-marketplace-spsaasservice-releaseinstance-0000001204515410)。
   * 用户购买成功后，您需要实现[免登接口](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-marketplace-spsaasservice-logininstance-0000001204675404)保证用户可以免登使用。
