# 查看已取消的订单

需求方可在未支付款项前取消订单，您也会收到邮件提醒。

1.登录卖家中心。

2.在左侧导航栏，点击需求订单。在订单列表找到需求方取消的订单，此时状态为已关闭。

![](https://media:401788750497643119 "点击放大")

3.点击订单号，在订单详情中查看订单取消原因。
