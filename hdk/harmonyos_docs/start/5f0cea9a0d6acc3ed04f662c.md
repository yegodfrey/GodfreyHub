# 前提条件

## 众包平台介绍

生态市场众包平台是商户管理客户需求的统一平台。商户可以在需求广场抢单或在需求管理系统中进行定向需求接单，与需求方建立联系，记录、跟踪项目售前进度，提交方案及报价单，完成交易。

## 前提条件

1. 由于众包平台的需求大多数可通过商户类型进行系统匹配，所以您至少需要入驻一个生态市场类目，方可使用众包平台，详情请参见**[商户入驻](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-isvregistration-conditions-0000001071403548)**。
2. 在商户入驻生态市场后定制需求接单功能自动开启。
