# 需求订单

您提交需求订单，且完成支付后，可以在**买家中心** **>** **需求订单**查看订单详情。您也可进行订单取消。

## 查看订单详情

1.登录**买家中心**。

2.在左侧导航栏，点击**需求订单。**

3.在需求订单页，点击**订单号**可查看该订单详情，包括关联的需求（点击需求标题可查看需求详情）、商品总价、订单状态、创建时间、支付时间、订单备注、商户信息、合同信息等。

## 取消订单

在您与商户协商一致的情况下，可以在支付前取消订单。

1.登录**买家中心**。

2.在左侧导航栏，点击**需求订单。**

3.在需求订单列表，找到目标订单，点击操作列**取消订单**。
