# 创建实例

## 功能介绍

用户购买商品并付款成功，生态市场将调用本接口，通知您开始创建实例。

## 接口原型

|承载协议|HTTPS POST|
|----|-------------------------------------------------------------------|
|接口方向|华为服务器 -> 商户服务器|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

> 说明
>
> * instanceId统一由生态市场指定，不接受商户自定义ID。
> * 商户接口需支持幂等，如果实例已创建成功，但是又收到了同一个实例的创建请求，需要返回成功（不需要额外创建新实例）。

## 请求参数

### Body

下表列出了请求Body中使用JSON格式需要携带创建的实例信息，请求验签需要携带的URL参数请参见[安全校验规则](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-marketplace-spsaasservice-autodeliveryprg-0000001249275447#section34923151503)。

|参数名|必选(M)/可选(O)|类型|描述|
|:---------------------|:----------|:---------|:---------------------------------------------------------------------------------------------------------------|
|action|M|String|取值固定为createInstance。|
|orderId|M|String|订单ID。|
|orderCode|M|String|订单编号。|
|instanceId|M|String|实例ID，全局唯一，由生态市场统一分配。|
|openId|M|String|即购买服务的用户ID，对于同一商户是相同的，对于不同商户是不同的。|
|periodType|M|Integer|周期类型:1包年、2包月、3包天。|
|periodNumber|M|Integer|周期数量。|
|orderAmount|M|BigDecimal|订单金额。（单位：元）。|
|payAmount|M|BigDecimal|支付金额（单位：元）。|
|amount|O|Integer|商品下单数量。|
|skuCode|M|String|商品购买规格属性。|
|productCode|M|String|生态市场商品Code，详情请参见[术语表](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-terminology-0000001446432989)。|
|expireTime|M|String|过期时间，Unix时间戳，yyyy-MM-dd HH:mm:ss|
|requestId|M|String|请求ID，每次请求均不相同。|
|isTrial|M|Boolean|是否为试用版。|
|quotaInfos|O|quotaInfos|服务的总配额信息。|
|hasOverpaidRank|O|Boolean|服务是否开通了超额定价，true代表开通，false代表未开通。|
|overpaidRankExpireTime|O|String|超额定价的有效期，Unix时间戳。|

**quotaInfos**

|参数名|必选(M)/可选(O)|类型|描述|
|:-------------|:----------|:-----|:------------------------------------------------------------------------------------------------------------|
|id|M|String|配额ID。|
|chargeItemCode|M|String|计费项Code，详情请参见[术语表](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-terminology-0000001446432989)。|

|effectTime|M|String|生效时间，Unix时间戳。|
|expireTime|M|String|过期时间，Unix时间戳。|

## 响应参数

|参数名|必选(M)/可选(O)|类型|描述|
|:----------|:----------|:-----|:-----------------------------------------------------------------------------------------------------|
|retCode|M|String|调用结果码，结果码定义参见"[结果码](#section2841191514352)"。|
|frontEndUrl|M|String|前台地址：客户购买商品后，可以访问的网站地址。|
|adminUrl|O|String|管理地址：客户购买商品后，可以访问的管理后台地址。|
|userName|O|String|管理员账号：客户购买商品后，访问商户管理后台的账号。|
|password|O|String|管理员初始密码：客户购买商品后，访问商户管理后台的密码。|
|retMsg|O|String|调用结果描述。|
|authUrl|O|String|免登url，最大长度512，要求为https地址，为商户提供的免登url。比如："https://www.example.com"。 > 说明 > 返回的authUrl中只能包含一个符合要求的url地址。|
|extendInfo|O|String|自定义扩展数据，最大长度 2048。|

## 结果码

|错误码|含义|
|:-----|:---------------------------------------|
|000000|成功|
|000001|鉴权失败|
|000002|请求参数不合法|
|000003|时间戳校验失败（请求时间与本地时间差异较大）|
|000004|实例ID不存在（续费、过期、释放资源可能返回）|
|000099|其它服务内部错误|
|000100|请求处理中（对于异步发货的服务，需返回此结果码，生态市场会持续询问直到发货成功）|

// 处理请求
public Object dealInstance(String signature, String timestamp, String eventId, @RequestBody String requestString) {
    // 处理请求超时逻辑
    if (new Date().getTime() - Long.parseLong(timestamp) > 30 * 60) {
        log.error("dealInstance fail. timestamp {} is invalid.", timestamp);
        return new CommonRsp(SaasRetCodeEnum.TIME_INVALID.getRetCode(), SaasRetCodeEnum.TIME_INVALID.getRetMsg());
    }
    List<String> paraList = new ArrayList<>();
    paraList.add(timestamp);
    paraList.add(eventId);
    // 验证签名
    String realSig = CommonUtil.hmacSha256Hex(paraList, CommonUtil.getDeliveryKey());
    if (!StringUtils.equals(realSig, signature)) {
        log.error(
            "dealInstance verifySignature fail. para timestamp = {}, eventId = {}, signature = {}, RealSig = {}",
            timestamp, eventId, signature, realSig);
        return new CommonRsp(SaasRetCodeEnum.VERIFY_FAIL.getRetCode(), SaasRetCodeEnum.VERIFY_FAIL.getRetMsg());
    }

    // 获取参数，CreateInstanceReq是包含请求参数的数据类
    CreateInstanceReq request = JSON.parseObject(requestString, CreateInstanceReq.class);
    return dealInstanceService.createInstance(request);
}

// 发送响应
public PurchaseInstanceRsp createInstance(PurchaseInstanceReq request) {
        PurchaseInstanceRsp rsp = new PurchaseInstanceRsp();
        String productCode = request.getProductCode();
        SaasService saasService = saasServiceMapper.querySaasServiceByCode(productCode);
        if (saasService == null) {
            log.error("createInstance productCode {} is invalid.", productCode);
            return new PurchaseInstanceRsp(SaasRetCodeEnum.PARA_ERROR.getRetCode(),
                SaasRetCodeEnum.PARA_ERROR.getRetMsg(), request.getInstanceId());
        }
        insertToDB(request);
        rsp.setExtendInfo(saasService.getExtendInfo());
        rsp.setAuthUrl(saasService.getAuthUrl());
        rsp.setInstanceId(request.getInstanceId());
        rsp.setRetCode(SaasRetCodeEnum.SUCCESS.getRetCode());
        rsp.setRetMsg(SaasRetCodeEnum.SUCCESS.getRetMsg());
        return rsp;
    }

public void insertToDB(PurchaseInstanceReq request) {
        insertPurchaseInfo(request);
        insertQuotaInfo(request);
    }

private void insertPurchaseInfo(PurchaseInstanceReq request) {
        SaasPurchase entity = new SaasPurchase();
        entity.setPsId(CommonUtil.getUUID());
        entity.setOrderId(request.getOrderId());
        entity.setUpdateTime(new Date());
        entity.setCreateTime(new Date());
        entity.setExpireTime(request.getExpireTime());
        entity.setOpenId(request.getOpenId());
        entity.setInstanceId(request.getInstanceId());
        entity.setStatus("normal");
        entity.setProductCode(request.getProductCode());
        entity.setRequestId(request.getRequestId());
        entity.setOverPaidRankExpireTime(request.getOverpaidRankExpireTime());
        entity.setHasOverPaidRank(request.isHasOverpaidRank() ? 1 : 0);
        Integer trialFlag = request.isIsTrial() ? 1 : 0;
        entity.setTrialFlag(trialFlag);
        saasPurchaseMapper.insertSaasPurchase(entity);
    }

private void insertQuotaInfo(PurchaseInstanceReq request) {
        if (CollectionUtils.isEmpty(request.getQuotaInfos())) {
            return;
        }
        request.getQuotaInfos().forEach(quotaInfo -> {
            QuotaInfoPO rec = new QuotaInfoPO();
            rec.setChargeItemCode(quotaInfo.getChargeItemCode());
            rec.setCreateTime(new Date());
            rec.setUpdateTime(new Date());
            rec.setTotalAmount(quotaInfo.getAmount());
            rec.setUsedAmount("0");
            rec.setEffectTime(quotaInfo.getEffectTime());
            rec.setExpireTime(quotaInfo.getExpireTime());
            rec.setId(quotaInfo.getId());
            rec.setInstanceId(request.getInstanceId());
            saasQuotaInfoMapper.insertQuotaInfo(rec);
        });
    }
