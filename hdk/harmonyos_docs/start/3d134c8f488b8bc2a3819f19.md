# 团队账号预览

团队账号是开发者联盟为实名开发者提供的多个成员账号登录与权限管理服务。当前团队账号支持成员参与应用市场（付费推广、应用内付费除外）开发、运营、数据分析操作、鲸鸿动能流量变现服务中媒体展示位管理及相关报表操作，以及主题中心业务中作品、活动、评论等管理的操作。暂不支持成员独立结算及部分开放能力（如HUAWEI HiAI等）服务。

团队账号支持企业、团队多个账号安全登录，并对所有成员账号进行角色权限管理，帮助企业、团队成员共同协作完成开发、分发、商户服务、运营分析等工作，轻松解决部门内部和跨部门之间的数据共享和流转问题，实现高效开发、分发、推广、变现。每个团队中团队成员的上限为200个。
