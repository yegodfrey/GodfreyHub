# 如何在DevEco Studio上用插件集成组件\&模板

鸿蒙生态市场插件支持在DevEco Studio中直接浏览、搜索并使用丰富组件、模板资源，可帮助开发者快速创建工程、实现代码编写与组件选择的无缝集成，提升开发效率。

插件特性：

* 资源丰富：提供组件、模板全方位覆盖，满足不同项目需求。
* 提升开发效率：通过组件、模板复用，开发者可以快速搭建项目，减少重复代码的编写，节省大量时间和精力。
* 实时更新：与华为生态市场同步更新，确保开发者始终使用最新资源。

#### 二、安装插件

#### 1. 在线安装

1. 安装DevEco Studio 6.0.1 Beta及其以上版本的DevEco Studio。
2. 打开DevEco Studio插件市场并搜索安装插件。 启动IDE，点击顶部菜单栏中的"File"（文件） \> "Settings"（设置）。在设置窗口中，选择"Plugins"（插件）选项卡，进入插件市场。在搜索框输入HarmonyOS Component Center，点击"Install"（安装）按钮进行下载安装。

#### 三、获取组件

#### 1. 访问组件市场界面

打开IDE后，点击顶部菜单栏中的"Tools"（工具栏） \> "Component Market"（组件市场），进入组件市场界面。

![](https://media:401788750490340998)  

#### 2. 搜索和浏览组件

在组件市场界面，您可以通过左上角搜索框输入关键词，快速查找所需的组件。

您也可以点击右侧组件分类，查看不同类型的组件资源。

您可以自主选择合适的排序方式，对组件进行挑选。

![](https://media:401788750490386999)  

#### 3. 集成组件到项目

找到目标组件后，点击组件详情页卡片中的按钮，即可将组件添加到您的项目中。

![](https://media:401788750490427001)  

#### 四、获取模板

#### 1.访问模板市场界面

打开IDE后，点击顶部菜单栏中的"File"（文件） \> "New"（新建） \> "Create Project from Template Market"（从模板市场创建项目），进入模板市场界面。

![](https://media:401788750490465002)  

#### 2.搜索和浏览模板

在模板市场界面，您可以通过左上角搜索框输入关键词，快速查找所需的模板。

您可以点击模板品类，筛选不同品类下的模板资源。

在左侧模板列表页点击感兴趣的模板，可在右侧详情页查看模板具体信息。

若您想查看更多资源，可点击左下角链接跳转官网查看更多。

![](https://media:401788750490538003)  

#### 3.创建工程

找到目标模板后，点击右下角"Next"（下一步）按钮创建新工程。

![](https://media:401788750490602004)

填写相关信息后，点击右下角"Import"（导入）按钮，即可使用对应模板。

![](https://media:401788750490644005)  

#### 五、通过插件更新组件模板

1. 安装1.5.0及以上版本的插件。
2. 选择需要更新的组件或模板。 打开IDE后，右键点击需要更新的组件或模板的根文件名，选择菜单中的"Update from HarmonyOS Component Market"（从鸿蒙生态市场更新）。

   ![](https://media:401788750490678006)

   在弹窗中选择"Upgrade to target version"（升级到目标版本）、"Target version download path"（目标版本下载路径）等信息。

   ![](https://media:401788750490712007)
3. 更新组件或模板。 进行不同版本的对比，选择需要的内容进行同步。

   对比功能的详细操作说明可以参考[官方文档](https://www.jetbrains.com/help/idea/comparing-files-and-folders.html#comparing_folders)。

![](https://media:401788750490761008)  

#### 六、常见问题

#### 在组件市场通过源码安装组件失败，提示"Git operation failed. Please check your network connection or Git proxy settings."，应如何解决？

该问题是因为网络环境已配置代理，导致访问Gitee仓库时出现网络链路异常，造成组件下载失败。您可以通过命令配置Git代理后，解决相关问题。

具体的配置方式如下：

1. 打开 IDE 后，点击顶部菜单栏中的"View"（视图） \> "Tool Windows"（工具窗口） \> "Terminal"（终端），进入标签页。
2. 输入git config --global http.proxy（代理服务器地址：[http://proxyUsername:proxyPassword@proxy.server.com:port](http://proxyUsername:proxyPassword@proxy.server.com:port/)）。
