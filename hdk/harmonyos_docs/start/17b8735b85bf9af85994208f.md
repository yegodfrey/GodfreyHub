# 获取需求

#### 在需求广场中抢单

1. 进入[需求广场页面](https://developer.huawei.com/consumer/cn/market/demandsquare)。

2. 在需求列表中查找合适的需求，点击抢单。

![](https://media:401788750493519042 "点击放大")

3. 在"确定抢单"对话框点击确认，提示抢单成功后，您可在卖家中心-需求管理查看需求状态。

![](https://media:401788750493549043 "点击放大")

4. 如提示框显示操作失败，则您暂未入驻生态市场该类目，请参考商户入驻进行该类目入驻。

![](https://media:401788750493573044 "点击放大")

<br />

#### 用户向您发布定向需求

1. 登录[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)。

2. 在左侧导航栏，点击需求管理。

3. 点击待接单需求，按需求类别为定向需求过滤，可以查看需求方向您发布的定向需求。

![](https://media:401788750493626045 "点击放大")  
4. 对需求做出响应

* 接受需求：点击目标需求操作列的接受需求，然后在确认接单对话框中点击确定。 ![](https://media:401788750493661046 "点击放大")

* 拒绝需求：点击目标需求操作列的拒绝，然后在拒绝需求对话框中输入拒绝理由，点击提交。 ![](https://media:401788750493722047 "点击放大")
