# 获取需求

## 在需求广场中抢单

1. 进入[需求广场页面](https://developer.huawei.com/consumer/cn/market/demandsquare)。

2. 在需求列表中查找合适的需求，点击**抢单**。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ca/v3/bs2kX3H2SNaHiE5r6osiPA/zh-cn_image_0000001988451385.png?HW-CC-KV=V1&HW-CC-Date=20260909T164545Z&HW-CC-Expire=31536000000&HW-CC-Sign=DBC8B7474DC1BFE1C6C9D5334F3AC8A717B8E08A4707DA475AC0B7C2EA6A1AD0 "点击放大")

3. 在"确定抢单"对话框点击确认，提示抢单成功后，您可在**卖家中心-需求管理**查看需求状态。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ce/v3/stGSHoGFTd2uPONQfmonqQ/zh-cn_image_0000002173443305.png?HW-CC-KV=V1&HW-CC-Date=20260909T164545Z&HW-CC-Expire=31536000000&HW-CC-Sign=416681AA9EDA95AE49871F6BD6C27401F8756AD42D870786E675BF1650B61624 "点击放大")

4. 如提示框显示操作失败，则您暂未入驻生态市场该类目，请参考**商户入驻**进行该类目入驻。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b7/v3/1EokwPaDRRWspEfewA-1Zg/zh-cn_image_0000002173055797.png?HW-CC-KV=V1&HW-CC-Date=20260909T164545Z&HW-CC-Expire=31536000000&HW-CC-Sign=1C4F7F9E672F3CDFEE8A682A538159E46189FA706908C05D7C33D5DDDF4BCA8A "点击放大")

## 用户向您发布定向需求

1. 登录[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)。

2. 在左侧导航栏，点击**需求管理。**

3. 点击**待接单需求**，按需求类别为定向需求过滤，可以查看需求方向您发布的定向需求。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d9/v3/KTP6lHdcSsiwvU6hqKIEmg/zh-cn_image_0000001296492668.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T164545Z&HW-CC-Expire=31536000000&HW-CC-Sign=34235D5AF826A28AE943D596FC8EDBD9D9548DF8352C32ECB7019C48F5F4B6E0 "点击放大")

4. 对需求做出响应

* **接受需求** ：点击目标需求操作列的**接受需求** ，然后在确认接单对话框中点击确定。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c4/v3/4szTCx2KSo6vpu9_tWFUSw/zh-cn_image_0000001082847000.png?HW-CC-KV=V1&HW-CC-Date=20260909T164545Z&HW-CC-Expire=31536000000&HW-CC-Sign=DF432669564D1E4DE0AA6B866939123FD3D9A72DF3F9E8D1684D9B1142A13645 "点击放大")
* **拒绝需求** ：点击目标需求操作列的**拒绝** ，然后在拒绝需求对话框中输入拒绝理由，点击**提交** 。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3e/v3/ReIzbTNJTric4cezOSFCHw/zh-cn_image_0000001349572233.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T164545Z&HW-CC-Expire=31536000000&HW-CC-Sign=3B8F480EB24B97AF7F262188C25B25E9D6EC0E550613836B888378096E0D3378 "点击放大")
