# 获取需求

## 在需求广场中抢单

1. 进入[需求广场页面](https://developer.huawei.com/consumer/cn/market/demandsquare)。

2. 在需求列表中查找合适的需求，点击**抢单**。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ca/v3/bs2kX3H2SNaHiE5r6osiPA/zh-cn_image_0000001988451385.png?HW-CC-KV=V1&HW-CC-Date=20261008T174422Z&HW-CC-Expire=31536000000&HW-CC-Sign=078835B5946D6B8743DE42099978FBC3789E9C14D6AAE03A82755AEE71BFDA11 "点击放大")

3. 在"确定抢单"对话框点击确认，提示抢单成功后，您可在**卖家中心-需求管理**查看需求状态。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ce/v3/stGSHoGFTd2uPONQfmonqQ/zh-cn_image_0000002173443305.png?HW-CC-KV=V1&HW-CC-Date=20261008T174422Z&HW-CC-Expire=31536000000&HW-CC-Sign=B1B5D573C063D3C350BAD0D2FD976C0A614718EAD54985CA3E2AE334A4ED65F1 "点击放大")

4. 如提示框显示操作失败，则您暂未入驻生态市场该类目，请参考**商户入驻**进行该类目入驻。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b7/v3/1EokwPaDRRWspEfewA-1Zg/zh-cn_image_0000002173055797.png?HW-CC-KV=V1&HW-CC-Date=20261008T174422Z&HW-CC-Expire=31536000000&HW-CC-Sign=D3F7665529DE5E1A47E91F0E0273D47F2684078F7D342230D968B939A9A4D398 "点击放大")

## 用户向您发布定向需求

1. 登录[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)。

2. 在左侧导航栏，点击**需求管理。**

3. 点击**待接单需求**，按需求类别为定向需求过滤，可以查看需求方向您发布的定向需求。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d9/v3/KTP6lHdcSsiwvU6hqKIEmg/zh-cn_image_0000001296492668.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T174422Z&HW-CC-Expire=31536000000&HW-CC-Sign=59FA910901559A837CDFE7E5F1DBA15710477BF9C0005493B2E6C1B969A5618A "点击放大")

4. 对需求做出响应

* **接受需求** ：点击目标需求操作列的**接受需求** ，然后在确认接单对话框中点击确定。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c4/v3/4szTCx2KSo6vpu9_tWFUSw/zh-cn_image_0000001082847000.png?HW-CC-KV=V1&HW-CC-Date=20261008T174422Z&HW-CC-Expire=31536000000&HW-CC-Sign=C033F5A2D4730547836B7B07E19FD8FF6E69825EAEC7D34F26B7EA442D1AF0EC "点击放大")
* **拒绝需求** ：点击目标需求操作列的**拒绝** ，然后在拒绝需求对话框中输入拒绝理由，点击**提交** 。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3e/v3/ReIzbTNJTric4cezOSFCHw/zh-cn_image_0000001349572233.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T174422Z&HW-CC-Expire=31536000000&HW-CC-Sign=AE91CAD9EB3B2F67A3C8CE3596B81018E4ED9F1C7EB087A5A01A9BBD580D2B5D "点击放大")
