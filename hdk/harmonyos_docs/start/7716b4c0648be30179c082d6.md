# 流量变现服务角色与权限

当前流量变现服务提供3种团队账号角色如下：

* 管理员：查看、管理流量变现服务所有操作，如管理媒体展示位、查看媒体收益等。

* App管理员：查看、管理流量变现服务媒体展示相关操作，查看相应报表信息。

* 数据运营：查看流量变现服务数据和报表信息。
