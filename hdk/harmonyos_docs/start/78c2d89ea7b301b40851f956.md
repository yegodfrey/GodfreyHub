# SDK监管政策与审核策略动态

您有责任确保您提供的SDK版本遵从当地法律法规、并符合所有适用的政策，您应对您SDK的合法性、准确性、完整性和可靠性负责，这里附上近期中国对SDK的合规要求，以下为不完全列举，仅供参考，您应当按照您SDK的情况自行对从事的所有行为及结果承担责任。

* [2021年11月](https://developer.huawei.com/consumer/cn/doc/start/sdk-regulatory-policy-202111-0000001913103013)  
* [2023年02月](https://developer.huawei.com/consumer/cn/doc/start/sdk-regulatory-policy-202302-0000001867143766)  
* [2023年09月](https://developer.huawei.com/consumer/cn/doc/start/sdk-regulatory-policy-202309-0000001913183377)
