# 结算规则

#### 结算启动前提条件

商户需接入华为支付商户平台，同意使用"第三方支付服务商花瓣支付（深圳）有限公司（简称"花瓣支付"）"为商户提供支付服务，并根据签订的华为开发者联盟生态市场商户合作协议（可能涉及第三方支付服务费率）进行结算及分账等。用户在生态市场购买商户的商品后，花瓣支付代理商户向用户接收用户付款，将交易资金记录至商户在花瓣支付开通的商户号，并根据华为开发者联盟生态市场商户合作协议的约定和法律法规要求，在一定周期内将交易资金分账后划转至商户指定账户。  

#### 结算周期

1、对账与发票：华为每月10号出具上个自然月用户确认验收订单的结算账单，用户未确认收货的订单不计入结算账单。商户需在收到账单的10个日历日内完成账单确认或发起异议。逾期未提出异议的，视为接受账单，华为开具服务费发票给商户。商户需要自行承担对用户开票的责任。

2、分账：华为每月15日前将上个自然月用户已确认验收的订单对应商户和华为结算金额通过花瓣支付分账到商户和华为在花瓣支付开通的商户号，并于第二个工作日划款至商户和华为在花瓣支付开通的商户号对应银行账户。  

#### 结算公式

华为基于商户的产品与服务在生态市场上每次成交订单总价的百分比收取服务费，

结算公式： 结算金额=商品交易额\*(1-[支付渠道的手续费费率](https://developer.huawei.com/consumer/cn/doc/00002)）\*（1-服务费比率)

商品交易额指的是扣除商品折扣、优惠券、满减券金额后，买家实际支付的金额。

#### 退款订单的结算

在买家支付订单到确认收货前，买家可在线提交退款申请，退款成功的订单，在结算账单中不统计扣款和支付订单。
