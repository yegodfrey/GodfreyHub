## 4. 定义

4.1"**华为支付服务** "、"**华为支付** "或"**本服务** "：指由我们提供与运营的华为支付服务技术与功能，包括**账户管理服务** 和**支付交易处理。**

4.2"**账户管理服务** "**：**指我们提供的身份实名认证、交易信息查询、资金交易处理、账户及管理员配置等管理服务。

4.3"华为支付账户"：是指您通过我们的认证后，由我们根据您的真实意愿为您开立的支付账户（以下简称"支付账户"），用于记录预付交易资金余额、反映账户流水信息。

4.4"**支付交易处理** "**：**指我们提供的非银行支付服务，是我们作为支付中介机构，受您委托依托计算机信息系统为您提供的货币资金转移或其他授权服务，包括但不限于代收代付款项、余额支付、快捷支付、聚合收银台等。

4.5"**华为支付商户号** "或"**商户号** "**：**指我们为您提供的唯一编号，用于记录身份信息、资金余额和反映交易明细信息。华为支付商户号将与您提供的合法银行账户绑定，我们根据您或开发者联盟运营方的指令及本协议约定对您的银行账户做相应资金扣划和归集。

4.6"**华为支付商户平台** "**或** "**商户平台** "**：** 指由我们提供和维护的商户管理软件系统**（** **[https://petalpay-merchant.cloud.huawei.com](https://petalpay-merchant.cloud.huawei.com/)** **）** ，您或您委托开发者联盟运营方通过该平台提交相关信息和材料，开通商户号；开通成功后可通过该平台查询、管理您的商户号以及使用平台提供的营销、推广等功能，具体功能以该平台实际提供的为准。您使用商户平台，还应阅读并遵守《华为支付商户平台使用协议》**。**

4.7"**华为账号** "**：** 指您凭以访问华为支付、华为应用、服务、网站或其他非华为服务的个人识别标识，您开通华为支付，即视为您本人同意授权我们将您的华为账号（开发者账号）与商户号相关联，您应阅读并遵守[《华为账号用户协议》](https://id1.cloud.huawei.com/AMW/portal/agreements/userAgreement/zh-cn_userAgreement.html?version=china&countryCode=cn&reqClientType=2088)。

4.8"**用户** "**：**指使用华为支付服务向您购买商品或服务的消费者。

4.9"**商户** "或"**您** "**：** 指使用华为支付服务并向用户销售商品或服务的经营者**。**

4.10"**结算** "：指用户购买您的商品或服务后，我们将交易资金记录至您的商户号**。由于您与开发者联盟运营方已签署相关协议，您授权我们按照开发者联盟运营方提供的结算规则对您进行结算。**

4.11"**延迟结算** "**：**指存在或可能存在异常交易时，我们将您的商户号中的相应资金延迟结算至绑定银行账户；已经结算的，延迟转账至您指定银行账户或支付账户。

4.12"**充值"：**指根据您的指令或本协议约定，您委托我们将银行或第三方资金渠道内的资金划转到您的华为支付账户内。

4.13"**提现** "**：**指根据您的指令或本协议约定，我们将您商户号中的资金划转至您绑定银行账户的行为。

4.14"**退款**"：指商户因商品或服务取消交易，将已支付款项退还至用户原付款账户的过程。

4.15"**异常交易** "**：** 指用户、商户在使用华为支付过程中发生的异常交易行为，包括但不限于拒付、伪卡、盗卡、伪冒交易、非账户主体授权交易、持卡人/支付账户主体否认交易等账户主体否认、撤销的交易，或无真实交易背景、与真实交易背景不相符的虚假交易，以及涉嫌洗钱、套现、恶意欺诈、涉黄、涉赌等违法违规行为的违规交易等**。**

4.16"**华为开发者联盟** "或"**开发者联盟**"：是指由华为软件技术有限公司及其关联公司运营的向华为开发者提供产品和服务（包括但不限于开放平台、华为软件、分发服务、推广服务等），以供华为开发者用于向用户提供（包括但不限于展示、分发、推广和开发）开发者产品的网站、开放平台及其对接平台的总称。开发者联盟接受您委托，代理您申请开通华为支付服务、按约定设定相关结算规则，向我们传递、同步您的身份信息、交易信息以完成交易流程，即华为软件技术有限公司及其关联公司。

4.17"**华为开发者**"：是指已在华为开发者联盟官网成功开通开发者账号并获得授权使用开发者联盟服务开发和/或向用户提供开发者产品的个人、法人或其它组织，即本协议中的商户。

4.18"**开发者账号** "：是指您已在华为开发者联盟官网上完成在线实名认证流程的华为账号，您应阅读并遵守**[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/start/agreement-0000001052728169)** 。**您在开通华为支付时，同意授权开发者账号与您的华为支付商户号相关联。** 您可以在开发者联盟上为您的开发者账号（管理员账号）添加关联的成员账号（合称"**开发者账号**"），并为成员账号配置相应权限，用于查询、操作您的商户号，成员账号对商户号进行的一切操作视为您自身作出（具体功能以实际提供的为准）。
