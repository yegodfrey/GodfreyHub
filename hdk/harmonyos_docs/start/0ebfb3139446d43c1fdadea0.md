# 店铺信息维护

商户需要在卖家中心完善店铺信息，操作流程如下：

1. 登录生态市场[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)。

2. 在左侧导航栏，选择店铺信息维护。

3. 在店铺维护页面填写基本信息和联系方式，点击提交。

|字段|描述|
|:------|:------------------------------------------------------------------------------|
|店铺Logo|上传店铺 Logo 图片。|
|店铺名称|填写店铺名称。|
|行业分类|此处可参考营业执照经营范围，需选择明确的行业属性标签： 1. 错选或多选则驳回； 2. 如果选择"综合"分类，则默认涵盖全部行业类别，请勿再勾选其他行业分类。|
|店铺简介|围绕着店铺上架商品，商户业务和技术实力、服务优势等特点进行介绍。|
|店铺上班时间段|填写客服在线服务时间。|
|客服电话|填写客服联系电话。|
|客服邮箱|填写客服邮箱地址。|
|客服QQ|填写客服QQ。|
|微信公众号|填写企业微信公众号。|

注：

1）店铺logo尺寸建议为300x300px，只支持JPG/PNG/GIF，不支持动图，大小不超过3M（最好是横版，需要能够显示全）。

2）店铺名称不可包含华为字样。例如：XX公司华为官方店。

3）服务商及企业开发者店铺logo，务必为企业logo；个人开发者店铺logo，应简洁明了，易于识别。

4）店铺logo务必遵循相关法律法规，确保不侵犯他人知识产权；避免使用受版权保护的图形，字体等元素；若引起法律纠纷，由商户自行负责。

5）客服电话暂不支持固话和400电话。

> 说明
>
> * 店铺信息提交后，需生态市场运营审核。审核通过后，店铺才对所有用户可见。
> * 首次提交店铺信息时，店铺处于尚未对外发布状态。可先前往商品管理页面上架商品，店铺信息和商品信息会同步提交给运营审核。
> * 每次修改店铺信息都需要运营审核。
