# 生态市场

1、点击进入[伙伴SDK页面](https://developer.huawei.com/consumer/cn/market/landing/SDK)；

2、查找SDK

a.按关键词查找：您可以在搜索框内输入关键词，系统会根据您的关键词为您匹配对应SDK；

b.按精选榜单查找：您可以通过SDK精选榜单，找到您想要的SDK；

c.按热门分类查找：根据您想要的分类，找到合适的SDK。
