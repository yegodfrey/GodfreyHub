# FAQ

## 插件设置-关联应用-当前应用界面提示"关联应用信息已过期，请重新关联应用"

**问题现象**

进入插件设置界面，"关联应用 > 当前应用"栏提示"关联应用信息已过期，请重新关联应用"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5f/v3/9xxJFYmLQ2-hJUA11WB6Lw/zh-cn_image_0000002775052909.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=ADECCBCB82A2BE57103B80AB5D99A8ED767C0ED4DC6CB0BD620A3D44E9F9D589)

**解决措施**

出现此提示，可能有如下原因：

* 当前应用工程的项目路径与插件保存的已关联应用项目路径不一致。
* 当前应用工程的app.json5中的包名（bundleName）与插件保存的关联应用包名不一致。

请分别排查项目路径和包名，确保一致。如确实需更换应用包名，请重新为当前应用工程关联正确的应用。
