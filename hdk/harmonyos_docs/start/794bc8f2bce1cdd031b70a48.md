# 注册登录FAQ

## 账号注册和登录流程

账号注册和登录的流程请见：[注册账号](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。

## 账号（手机/邮箱）要求

手机号和邮箱必须能收到验证码，同一个手机号或邮箱只能注册一个账号，不支持同一个手机或邮箱注册多个账号。

## 取消登录验证码

验证码是保证账号安全的手段，无法直接取消，如果想要不提示登录验证码，可以尝试以下方式：

1. 加强账号密码，长度不低于8个字符，且至少一个大写字母、一个小写字母、一个数字和一个标点符号，避免与原密码以及在其他业务设置的密码相同或相似。
2. 将账号的安全手机/安全邮箱设置为与登录的手机号/邮箱不同。
3. 不要在多台电脑，多个IP地址登录。
4. 清除浏览器缓存，重新登录PC端页面时，选择记住此浏览器。
