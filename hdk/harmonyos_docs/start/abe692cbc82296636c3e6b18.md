# 跟踪需求

抢单或接受需求后，您可在**卖家中心-需求管理**系统中进行需求跟踪。

1. 登录[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)。
2. 在左侧导航栏，点击**需求管理**。
3. 在需求列表中找到目标需求，点击**操作列** 联系需求方的电话图标与其取得联系，并记录与客户的沟通内容。
   * 找到目标需求，点击**需求标题**查看详情。
   * 在**需求详情页面** 的沟通记录中，点击**添加记录** 。
