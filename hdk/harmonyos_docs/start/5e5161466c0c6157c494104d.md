# 申请发票

您在订单支付完成后，可在线上申请开票。

1.登录**买家中心**。

2.在左侧导航栏，点击**需求订单。**

3.在需求订单列表，找到目标订单，点击操作列**申请开票**。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/33/v3/K8ZFP_XPQkCSXP5FXWWUNQ/zh-cn_image_0000002509384153.png?HW-CC-KV=V1&HW-CC-Date=20260909T142554Z&HW-CC-Expire=31536000000&HW-CC-Sign=38CF9F2864F7D8E37D3F7BCDC80117B3ABADC1CF1117CB0297A3962FA4AF34FE "点击放大")

4.填写发票信息。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c5/v3/SmJ0CkK4RVaRTqK6ZwsmAA/zh-cn_image_0000001088741862.png?HW-CC-KV=V1&HW-CC-Date=20260909T142554Z&HW-CC-Expire=31536000000&HW-CC-Sign=82D5F33CC527ABBA7FBEF7879CF5A94414BF5E32343DC089EEACC8300AE583A1 "点击放大")

5.如需纸质发票，要填写收票人信息。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ff/v3/Qlg2f8YyT8iLHEfPvAygQQ/zh-cn_image_0000001088422892.png?HW-CC-KV=V1&HW-CC-Date=20260909T142554Z&HW-CC-Expire=31536000000&HW-CC-Sign=4184EF9BFB65F74ECA2592707B46253A0F66EA07B0815350945BE9953E6A55E5 "点击放大")

6.查看开票详情。

* 在需求订单列表，找到目标订单，点击操作列**查看开票** 可查看开票详情**。**

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3d/v3/VuhCb5C0Qk-6kicAFpbfaw/zh-cn_image_0000002509503593.png?HW-CC-KV=V1&HW-CC-Date=20260909T142554Z&HW-CC-Expire=31536000000&HW-CC-Sign=D180AFBCB74BD33C92B37E8B1D83280D0FA15BEE50B41C988A8BD0B2F11ED996 "点击放大")

* 开票进度为**开票完成** ，则商户已完成开票处理。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/69/v3/YOWLaDDoRz6ui_OseIZQMA/zh-cn_image_0000001239685736.png?HW-CC-KV=V1&HW-CC-Date=20260909T142554Z&HW-CC-Expire=31536000000&HW-CC-Sign=8053948855D0DD09D8ACBB0F394CAA2F36B80CB67ABA1720CAE70A0E6961CD17)

  说明：
  * 若您使用企业网银支付，款项暂入到深圳市讯联智付网络有限公司（华为旗下子公司）的银行账户。
  * 订单确认验收后，平台将会与商户进行结算，您的商品如需开票，将由商户开具。
