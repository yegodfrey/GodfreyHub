# 申请发票

您在订单支付完成后，可在线上申请开票。

1.登录买家中心。

2.在左侧导航栏，点击需求订单。

3.在需求订单列表，找到目标订单，点击操作列申请开票。

![](https://media:401788750498745138 "点击放大")

4.填写发票信息。

![](https://media:401788750498782139 "点击放大")

<br />

5.如需纸质发票，要填写收票人信息。

![](https://media:401788750498816140 "点击放大")

<br />

6.查看开票详情。

* 在需求订单列表，找到目标订单，点击操作列查看开票可查看开票详情。

![](https://media:401788750498987141 "点击放大")

* 开票进度为开票完成，则商户已完成开票处理。 ![](https://media:401788750499016142)

  说明：
  * 若您使用企业网银支付，款项暂入到深圳市讯联智付网络有限公司（华为旗下子公司）的银行账户。
* 订单确认验收后，平台将会与商户进行结算，您的商品如需开票，将由商户开具。
