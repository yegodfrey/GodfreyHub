# 申请发票

您在订单支付完成后，可在线上申请开票。

1.登录**买家中心**。

2.在左侧导航栏，点击**需求订单。**

3.在需求订单列表，找到目标订单，点击操作列**申请开票**。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/33/v3/K8ZFP_XPQkCSXP5FXWWUNQ/zh-cn_image_0000002509384153.png?HW-CC-KV=V1&HW-CC-Date=20261008T152444Z&HW-CC-Expire=31536000000&HW-CC-Sign=4CDE433D631F4CF767B02259010D734753A823A9669C68B803888E557ACA6792 "点击放大")

4.填写发票信息。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c5/v3/SmJ0CkK4RVaRTqK6ZwsmAA/zh-cn_image_0000001088741862.png?HW-CC-KV=V1&HW-CC-Date=20261008T152444Z&HW-CC-Expire=31536000000&HW-CC-Sign=A70DC2D568E556C3154A9601C92FAC2BB8C8382C1BE51512DFD7E542BF5E5660 "点击放大")

5.如需纸质发票，要填写收票人信息。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ff/v3/Qlg2f8YyT8iLHEfPvAygQQ/zh-cn_image_0000001088422892.png?HW-CC-KV=V1&HW-CC-Date=20261008T152444Z&HW-CC-Expire=31536000000&HW-CC-Sign=BFF3D182796D36C3DC5F8C95D583AF4946AB6F56C271C6D15A7A559704FFAFBA "点击放大")

6.查看开票详情。

* 在需求订单列表，找到目标订单，点击操作列**查看开票** 可查看开票详情**。**

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3d/v3/VuhCb5C0Qk-6kicAFpbfaw/zh-cn_image_0000002509503593.png?HW-CC-KV=V1&HW-CC-Date=20261008T152444Z&HW-CC-Expire=31536000000&HW-CC-Sign=E5D8D91F4853F52DAF433F8A7DC2C1A2BE1DED477831242E30CF2B891A865F7D "点击放大")

* 开票进度为**开票完成** ，则商户已完成开票处理。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/69/v3/YOWLaDDoRz6ui_OseIZQMA/zh-cn_image_0000001239685736.png?HW-CC-KV=V1&HW-CC-Date=20261008T152444Z&HW-CC-Expire=31536000000&HW-CC-Sign=3E2A685342C2B6DFA2C8D77B3D6C4DE570812F86C79AA5D6873B868EF6C812C0)

  说明：
  * 若您使用企业网银支付，款项暂入到深圳市讯联智付网络有限公司（华为旗下子公司）的银行账户。
  * 订单确认验收后，平台将会与商户进行结算，您的商品如需开票，将由商户开具。
