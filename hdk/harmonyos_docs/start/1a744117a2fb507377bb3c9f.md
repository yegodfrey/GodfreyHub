# 商品发布

商品发布请严格按照商品发布说明执行，说明中发布标准为生态市场商品审核的标准。过程中遇到任何问题，请联系我们，邮箱：partner@huawei.com

生态市场商品发布、修改等各项申请审核会在1-5个工作日内完成。

商品上架如有相关问题，生态市场将通过商户信息中的客服邮箱、服务与支持中的售后邮箱等进行邮件通知，请确保贵司在各处登记的邮箱在24小时内有响应，如超时未响应，生态市场将对问题商品进行隐藏处理。

华为开发者联盟生态市场商品发布说明如下表所示：

1.上架商品发布标准：  

|发布项|发布标准|
|:------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|商品所属一级分类|选择正确的商品一级分类： * 如果您要发布组件、模板，一级分类选择"应用开发"； * 如果您要发布开发服务、人力服务、培训服务，一级分类选择"生态服务"；|
|商品所属二级分类|需选择正确的商品二级分类|
|商品行业分类|此处仅支持选择店铺已审核通过的行业标签（参考营业执照经营范围），如果商品含有明确的行业属性，则需要选择对应的行业标签： 1. 如商品为：医疗行业元服务开发服务，则所属行业需选择"医疗健康"，错选或多选则驳回； 2.如果选择"综合"分类，则默认涵盖全部行业类别，请勿再勾选其他行业分类。|
|商品是否定义为行业解决方案|需通过行业化、场景化服务解决方案，提供全生命周期的行业应用集成服务；满足选择"是"，如不满足，需选择"否"。|
|（可选）自定义标签|商品的核心关键词，有助于提升商品站内搜索成功率，数量不超过8个，每个标签字数不超过12个字符。|
|商品名称|1. 商品名称应描述准确，与内容相符。 2. 商品名称应与业界命名规范一致，不可以出现拼写错误，如：将wordpress拼成wordpess。 3. 商品名称不能过度宣传，不可以直接借助华为名义，如：命名为"华为XXX"。 4. 商品名称仅用于对商品命名，介绍、价格、电话号码等与命名无关内容，请勿出现在商品名称中。|
|商品图片|图片支持JPG/JPEG/PNG格式： 1. 商品主图：尺寸为100\*100px，大小不超过5M； 2. 商户图片：尺寸为300\*300px，大小不超过5M； 3. 商品详情截图：宽度为900px，大小不超过10M，须与商品内容相关，数量不超过6张。|
|宣传图/效果图|当您发布的商品接所属一级分类为应用开发时，我们强烈建议您提供宣传图/效果图，以便客户能够快速直观地了解您提供的商品及其能够达成的效果： 1.建议尺寸为1920\*1080或1080\*1920，可接受的尺寸范围在800\*800\~2000\*2000之间； 2.支持png、jpg、jpeg、gif格式；单张图片不超过10M； 3.最多可上传8张，其中第1张将同时用于商品列表页的展示。|
|商品简介|1. 商品简介不能只做公司信息介绍，需与商品信息相关。 2. 在商品列表和详情页面展示，字数应不少于60字符且不超过180字符。|
|商品亮点|1. 亮点内容应当基于商品本身，如果有多个亮点，可以通过换行进行展示，使页面更加清晰和易于阅读。|
|商品详情|1. 填写的商品详情，应当包含商品的详细信息：包括但不限于商品的核心功能和服务、产品优势、应用场景等，如大段介绍公司信息，缺少商品信息，则驳回；商品详情内容应当和接入类型、商品名称相对应，如选择鸿蒙应用-定制开发商品，但详情内容为营销推广、代运营等，和鸿蒙应用定制开发无关，则驳回。 2. 商品说明应当保持字体、字号、字色一致，排版要规范，不能出现明显的空格、换行等不合理排版问题，保持页面信息整齐美观。 3. 不允许放入非华为的外部链接等类似跳转信息，如出现则驳回（组件类、模板类、解决方案类除外，需审视）。 4. 支持插入图片和视频，图片支持JPG/JPEG/PNG格式，最大宽度不超过900px、每张图片大小不超过5M，如详情内容仅有图片或截图，没有文字说明，则驳回。 5. 避免使用广告法敏感词，如：国家级、最佳、极致、世界第一等。|
|（可选）成功案例|1.案例名称：不超过64个字，名称应描述准确，与内容相符； 2.案例图标尺寸：100\*100px；png、jpg、jpeg格式；不超过5M； 3.案例预览方式可选扫码下载（填写已上架应用市场的app对应的Applinking链接）或者视频动图（视频支持MP4/MOV格式；建议720p分辨率；视频文件大小不超过200MB；动图支持GIF格式；大小不超过30MB）； 4.最多支持上传5个成功案例。|
|（可选）商品资质|1. 上传商品取得的相关资质信息文件，软件商品必须上传与商品名称相符的软件著作权证书，且著作权人须与发布商品公司主体一致。 2. 商品如涉及开源部分，请如实提供商品开源声明。 3. 支持.zip/.docx/.pdf 格式文件。 4. 文件大小不超过10M。|
|使用指南|1. 与商品相符的有效的操作手册和商品手册，而非商品介绍。 2. 使用指南须说明用户从生态市场购买产品后，如何登录、使用等。 3. 使用指南中不可出现第三方平台的使用地址、登录地址等链接。 注：使用指南需提供详细指导内容，不可仅提供跳转第三方网页内容的链接，否则直接驳回。 4. 字体要一致，排版要规范，保持整齐美观。 5. 支持上传.zip/.docx/.pdf 格式的文件，文件大小不超过10M。|
|售后支持范围|参照样例按照实际服务内容表述，售后内容可以包含服务内容、服务时间、服务电话、服务邮箱等，可勾选7\*8小时、7\*24小时、365天技术维护，也可以根据企业实际情况自行编辑输入。 说明： * 如售后服务时间超过5\*8小时，请确保服务时间内及时响应各联系方式收到的各类售后问题。 <!-- --> * 售后服务邮箱，请确保邮件24小时内能得到答复。 参考样例： 售后服务时间：7 \* 8小时 售后服务内容：XXX系统使用问题 服务热线：010-864\*\*\*96 服务邮箱：xxx@qq.com|
|售卖方式|1. 规格信息必须完整。 2. 规格命名应有一定规则，不能简单地以"规格1"、"规格2"类似命名，不能简单地以计费方式"年"、"月"类似命名，不能简单地以计数单位"套"、"次"、"一套"类似命名。 3. 请选择准确的计费模式。 4. 同一商品不同版本，请以规格做区分，无需以不同的版本发布多个商品。|
|最终用户协议|上传的合同与协议需与该商品相关；支持pdf、docx、zip格式（zip中只能包含pdf或docx），不超过10M。|
|(可选)特殊商品协议|如商品需特殊协议，可填写此项。|

具体操作如下：

登录[生态市场](https://developer.huawei.com/consumer/cn/market/)，右上角进入我的---卖家中心，进入"商品管理"，按要求进行"发布商品"。

1）业务信息：

![](https://media:401788750487026952 "点击放大")

a.商品所属类目和行业必须与发布商品的属性相一致。

2）商品基础信息：

![](https://media:401788750487069953 "点击放大")

a.商品主图：建议尺寸为100x100px，只支持JPG/PNG/JPEG。

b.商品简介不少于100字，包含但不限于产品优势、功能描述、应用场景等。若出现具体合作企业或单位，将合作凭证上传至"商品资质"处

3）商品详情页：

![](https://media:401788750487100954 "点击放大")

a.商品详情图片建议宽度为900px，长度不限。只支持JPG/PNG/JPEG，大小不超过10M。

b.商品详情不可放外部链接（如二维码、小程序等），可放400电话。

c.商品详情若出现案例，需要提供凭证证明。（如官网案例截图，截图要涵盖官网名称、案例，或者是合作合同）。凭证在"商品资质"处上传。

d.商品详情不可以使用广告法敏感词，如：国家级、最佳、极致、世界第一等。

e.商品详情不得含有与商品无关的内容。

4）商品协议：

![](https://media:401788750487127955 "点击放大")

a.最终用户协议即为：商户与买家签订的合同模板。
