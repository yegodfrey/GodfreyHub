# 启明行

启明行（华中科技大学学生作品）

让中国上千万视力残疾者和视力障碍者能够独立的无障碍出行。  

#### 作品类型

公益类  

#### 入选情况

创新应用-成型APP类 ★★  

#### 开发者

曾强、周江南  

#### 功能介绍

启明行为千万视力残疾者和视力障碍者无障碍出行保驾护航，借助地图的定位、导航、AI、AR引擎让视障者在熟悉的地方能独立地走出家门，在不熟悉的复杂的场景可以求助专业视频客服人员，开启盲人无障碍出行新方向。

#### 应用价值

视力残疾者和视力障碍者因缺乏定向能力，没有信心接受复杂的场景，导致可选择的活动范围小，闲暇时也更倾向于呆在家中，少有聚餐、外出购物等娱乐方式。启明行的技术方案能切实解决视力残疾者和视力障碍者出行的难题，对他们的生活娱乐学习提供全面的帮助。启明行进入导航界面即可实时接收路线提醒，还可查询附近的无障碍设施。视力残疾者和视力障碍者熟悉的场景可仅靠启明行的定位导航AR偏角检测来完成基本出行服务，不熟悉的场景还可靠AI识别和视频客服来提供更加全面的出行服务。作品界面采用转盘的交互方式，在不看屏幕的情况下通过单手滑动即可操作。如，手指点击屏幕任何地方向左上滑动，松开手指时即可听到左前方路况介绍。  

#### 实现路径

应用的技术框架：Android、GPS

使用的技术能力：使用华为GPS能力令定位导航更加高效准确；使用华为HMS推送等能够稳定接收消息通知；使用华为HiAI的AI识别模块，帮助视障者识别道路上的障碍物；使用华为云服务器存储用户数据以及华为云视频搭建实时视频客服系统。
