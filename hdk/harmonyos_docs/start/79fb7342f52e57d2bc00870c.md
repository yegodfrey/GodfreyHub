# 点击"提交需求"购买商品

1. 点击[其他资源商品列表页](https://developer.huawei.com/consumer/cn/market/prod-list?fromNav=otherSource)。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1b/v3/_S5HyRrSTm-FdgM_UigXCQ/zh-cn_image_0000002593003136.png?HW-CC-KV=V1&HW-CC-Date=20260909T140529Z&HW-CC-Expire=31536000000&HW-CC-Sign=4B3DF4BE9A9D47FC61B16FA04C2FCF50AC9E61FC98A1CC69DE1D6116416A9B2F "点击放大")

2. 进入待购买商品的详情页，在商品的选配选项中选择想要购买的规格；

3.点击"提交需求"按钮，进入需求提交页，填写需求相关信息，然后点击"提交"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9a/v3/JlV7oaoeSMGTz0k-4wTMMA/zh-cn_image_0000002623304117.png?HW-CC-KV=V1&HW-CC-Date=20260909T140529Z&HW-CC-Expire=31536000000&HW-CC-Sign=5734365AB4B423A87AE048903093A7EE1AC19264381C1D795015C61F2F751BF6 "点击放大")

|**参数**|**描述**|
|:-------|:---------------------------------|
|需求标题|简要描述您的需求。|
|（可选）描述需求|按照界面提示详细描述您的需求。|
|（可选）需求文件|按实际情况上传zip格式/不超过10M的需求文件，详细澄清您的需求。|

4.提交需求后，您可以登录买家中心，在需求管理页面选择"按需报价需求"，查看卖家的报价情况。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e9/v3/PowEeHLCTPqgN_CUho5E1g/zh-cn_image_0000002592864562.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T140529Z&HW-CC-Expire=31536000000&HW-CC-Sign=377664C03A704C789D621C6C80BEC20C4502BE7C8DF00DF62F443B77B3337A9F "点击放大")

## 企业网银支付FAQ

**1、插入U盾后提示插入成功，但是无法显示客户账号信息是什么原因？**

答：使用的浏览器兼容性可能存在问题，更换浏览器再试一下。

**2、建行的客户识别号怎么查？**

答：①登录企业网银，在网页左上角有显示；②如果是第一次登录企业网银，要用网银盾来登录，登录的时间银行系统会显示识别号。

**3、招商银行---跳转至银行网银页面后，报错"无该用户可操作模式，请联系网银管理员在业务管理菜单中进行设置"。**

答：使用管理员用户登录招商银行网银，点击"系统管理---业务管理"查看操作员是否有"商务支付"权限，如无，按照提示设置后，重新进行支付。

**4、使用企业网银为什么报超出限额，每家银行限额是多少？**

答：企业网银正常情况下不会存在限额问题，除非用户自己在开户时设置了限额，如果页面提示超出限额，建议用户自己电话对应银行进行查询。

**5、为什么企业网银支付时报错没权限或者未设置限额？**

答：出现此种报错，是因为未开通B2B电子商务支付业务，需用户前往银行开通。

**6、登录提示"本页不但包含安全的内容，也包含不安全的内容，是否显示不安全的内容？"。**

回答：打开IE浏览器，点击"工具---INTERNET选项---安全---自定义级别"将其中"显示混合内容"改为"启动"。
