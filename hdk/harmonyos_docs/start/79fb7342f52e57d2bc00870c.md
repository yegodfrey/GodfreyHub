# 点击"提交需求"购买商品

1. 点击[其他资源商品列表页](https://developer.huawei.com/consumer/cn/market/prod-list?fromNav=otherSource)。

![](https://media:401788750493806048 "点击放大")

2. 进入待购买商品的详情页，在商品的选配选项中选择想要购买的规格；

3.点击"提交需求"按钮，进入需求提交页，填写需求相关信息，然后点击"提交"。  
![](https://media:401788750493846049 "点击放大")  

|参数|描述|
|:-------|:---------------------------------|
|需求标题|简要描述您的需求。|
|（可选）描述需求|按照界面提示详细描述您的需求。|
|（可选）需求文件|按实际情况上传zip格式/不超过10M的需求文件，详细澄清您的需求。|

4.提交需求后，您可以登录买家中心，在需求管理页面选择"按需报价需求"，查看卖家的报价情况。

![](https://media:401788750493903050 "点击放大")

5.待卖家填写报价后，若您对价格无异议，可以点击"同意报价"。

![](https://media:401788750493970051 "点击放大")

6.议价成功后，即可确认并提交订单。

![](https://media:401788750494013052 "点击放大")

7.提交订单后进入支付页，当前支持企业网银支付。

![](https://media:401788750494060053 "点击放大")

8.支付完成后，订单状态即进入"交付中"。待卖家上传交付件后，您可以点击"查看交付件"去下载交付件。

![](https://media:401788750494163054 "点击放大")

![](https://media:401788750494217055 "点击放大")

9.确认交付件无误后，可以点击"确认验收"完成订单。

![](https://media:401788750494260056 "点击放大")  

#### 企业网银支付FAQ

1、插入U盾后提示插入成功，但是无法显示客户账号信息是什么原因？

答：使用的浏览器兼容性可能存在问题，更换浏览器再试一下。

2、建行的客户识别号怎么查？

答：①登录企业网银，在网页左上角有显示；②如果是第一次登录企业网银，要用网银盾来登录，登录的时间银行系统会显示识别号。

3、招商银行---跳转至银行网银页面后，报错"无该用户可操作模式，请联系网银管理员在业务管理菜单中进行设置"。

答：使用管理员用户登录招商银行网银，点击"系统管理---业务管理"查看操作员是否有"商务支付"权限，如无，按照提示设置后，重新进行支付。

4、使用企业网银为什么报超出限额，每家银行限额是多少？

答：企业网银正常情况下不会存在限额问题，除非用户自己在开户时设置了限额，如果页面提示超出限额，建议用户自己电话对应银行进行查询。

5、为什么企业网银支付时报错没权限或者未设置限额？

答：出现此种报错，是因为未开通B2B电子商务支付业务，需用户前往银行开通。

6、登录提示"本页不但包含安全的内容，也包含不安全的内容，是否显示不安全的内容？"。

回答：打开IE浏览器，点击"工具---INTERNET选项---安全---自定义级别"将其中"显示混合内容"改为"启动"。
