# 生态服务商品

1. 点击进[生态服务页面](https://developer.huawei.com/consumer/cn/market/svc-list/8596a458630a4761acaae0ec846c09c2)；
2. 查找生态服务商品；
   1. 按关键词查找：您可以在搜索框内输入关键词，系统会根据您的关键词为您匹配对应生态服务商品；
2. 按类别与行业查找：您可以通过您想要的类别和行业过滤条件进行筛选，查找商品。
