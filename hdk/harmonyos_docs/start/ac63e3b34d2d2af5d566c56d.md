# 点击"立即购买"购买商品

1. 点击[其他资源商品列表页](https://developer.huawei.com/consumer/cn/market/prod-list?fromNav=otherSource)。

2.进入待购买商品的详情页，在商品的选配选项中选择想要购买的规格。

3. 点击立即购买，进入订单确认界面，确认您所要购买的商品信息无误后，勾选同意[《华为开发者联盟生态市场用户协议》](https://terms-drcn.platform.dbankcloud.cn/agreementservice/developer/getAgreementTemplate?agrType=1171&country=cn&language=zh_cn&version=2025010902)、《[关于开发者联盟生态市场与隐私的声明](https://terms-drcn.platform.dbankcloud.cn/agreementservice/developer/getAgreementTemplate?agrType=1238&country=cn&language=zh_cn&version=2021121301)》和《商品服务协议》，点击"提交订单"。

![](https://media:401788750489398980 "点击放大")

![](https://media:401788750489463981 "点击放大")

4. 提交订单进入支付流程，支持企业网银支付。

![](https://media:401788750489516982 "点击放大")

5. 完成购买后，你可以进入[买家中心](https://developer.huawei.com/consumer/cn/market/buyer/cloud-orders)查看订单详情，并[申请开具发票](https://developer.huawei.com/consumer/cn/doc/start/123456-0000001088289802)。

![](https://media:401788750489553983 "点击放大")
