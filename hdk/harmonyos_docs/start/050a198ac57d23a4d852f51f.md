# 入驻流程说明

## 入驻流程

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/60/v3/qeJ3XK5RTGqO1aLILhaMjw/zh-cn_image_0000002535575320.png?HW-CC-KV=V1&HW-CC-Date=20260909T132542Z&HW-CC-Expire=31536000000&HW-CC-Sign=940DBE074E334A7826B55F1C3C743D58ED3F5C7995861A7C6AE87BC659440FE8)

## 操作步骤

1. 注册华为开发者联盟账号，详细操作可参考[注册账号](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。

2. 实名认证为服务商：

（1）点击[此处链接](https://developer.huawei.com/consumer/cn/reseller/account/profile)跳转合作伙伴实名认证页面，选择服务商卡片进行**实名认证**，完成资料填写并提交实名认证审核。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7d/v3/wavoqtMCRYWPsOmqLLpdZg/zh-cn_image_0000001448780714.png?HW-CC-KV=V1&HW-CC-Date=20260909T132542Z&HW-CC-Expire=31536000000&HW-CC-Sign=38FD52C49A5785D0B8629B764DB99DCA46EA932572DD270EAA6F7ABB42300268 "点击放大")
> 注意
>
> * **若您已有华为账号且未进行实名认证，可直接登录后，通过服务商角色进行认证。**
>
>
> * **若您已有华为账号且已通过个人/企业开发者实名认证，请重新注册新账号进行认证。**为了您后续业务开展体验，建议您优先使用企业邮箱进行华为账号注册。

3. 申请入驻生态市场。

（1）进入【[服务商管理中心](https://developer.huawei.com/consumer/cn/reseller/overview)】，点击左侧"生态市场"，选择"申请入驻"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e1/v3/a7JT-PB_TVabRgu8RiysLA/zh-cn_image_0000002100720345.png?HW-CC-KV=V1&HW-CC-Date=20260909T132542Z&HW-CC-Expire=31536000000&HW-CC-Sign=8EB1F77EF29928C9FC5F600A527C61EB1CF3D8EA35F7CB3D2CCD9800D4ECBDC0 "点击放大")

（2）按页面提示填写相关信息，提交审核，等待工作人员审核。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/af/v3/Y8yX7PGqTfaOT_TLM4E3Qg/zh-cn_image_0000002064722920.png?HW-CC-KV=V1&HW-CC-Date=20260909T132542Z&HW-CC-Expire=31536000000&HW-CC-Sign=3FD2028CC1EC60AD0B77B253592B5EC0723C3BD6620ACE5F906222A94D5AFA74 "点击放大")
> 说明
>
> 业务资质模板：合同截图必须清晰可见，并且必须有合作双方的盖章。
>
> zip格式：可包含xlsx、docx、pdf、png、jpg、jpeg格式，不能含有文件夹。若上传出现问题，可更换浏览器，继续上传。

4. 缴纳保证金。

（1）入驻申请通过后， 在【服务商计划-保证金中心】选择"缴纳保证金"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/51/v3/PBt6p2bGT4CsDwr-_RN0nQ/zh-cn_image_0000002064733292.png?HW-CC-KV=V1&HW-CC-Date=20260909T132542Z&HW-CC-Expire=31536000000&HW-CC-Sign=125D789C79FA7099B6AA1DFE9652628115E6273CBD8A28EB930B798989685D91 "点击放大")

（2）缴纳保证金时会校验付费服务是否开通，没有开通按要求开通即可。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c1/v3/BvVhGoEHSHGd0OlCORNeSA/zh-cn_image_0000001498145529.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T132542Z&HW-CC-Expire=31536000000&HW-CC-Sign=A46306E78FC4C89F6A56EB4AB5DE83925D709826303080A854BD94133F0D1D5B "点击放大")
> 说明
>
> 目前仅支持线下对公账户打款，支付完成后在页面填写银行转账流水号并上传支付凭证。凭证上传后，需等待审核人员审核：审核通过即代表保证金缴纳完成。

5. 保证金缴纳审核通过后，可点击左侧【生态市场】菜单，进入卖家中心，按步骤配置店铺后上架商品。

6. 接入华为支付商户平台

若您需要交易已上架的商品或希望在需求广场抢单，则需接入华为支付商户平台；如无交易需求，则无需接入。

（1）在卖家中心-店铺信息创建完毕后，点击支付接入下的"申请接入"按钮；

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7e/v3/B44wAjofQ0OBzjGVYkk1AA/zh-cn_image_0000002561730821.png?HW-CC-KV=V1&HW-CC-Date=20260909T132542Z&HW-CC-Expire=31536000000&HW-CC-Sign=B31AC5249B67CA13386A38983BD47D78D020B81285353E0CB5D52A1DF57F85BE)

（2）点击授权华为账号登录，确认接受邀请；

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/23/v3/iEFWgSNdTmqWWfbmCpxlGA/zh-cn_image_0000002561733375.png?HW-CC-KV=V1&HW-CC-Date=20260909T132542Z&HW-CC-Expire=31536000000&HW-CC-Sign=E2527757BA4783B6A369E297548CE06157E0FE27AFB01B1F20F36212CD1B988D)![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/18/v3/wgW7KjsIRH-sCXNRfgeZyA/zh-cn_image_0000002561733523.png?HW-CC-KV=V1&HW-CC-Date=20260909T132542Z&HW-CC-Expire=31536000000&HW-CC-Sign=DB16AE9EA8763DD6323D8F0669A9ADE721BED378E294568F49A09FF88A2A4B28 "点击放大")

（3）根据系统提示完成申请管理员账户、商户主体信息填写，商户经营信息填写，点击提交，等待审核；（填写明细可参考["平台子商户如何提交申请"](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-zishanghuruwang-0000001720049550#section6562121910312)文档说明）

（4）审核通过后，则接入状态显示"已接入"，您可以正常在生态市场进行交易，或在需求广场进行抢单。
