# 入驻流程说明

## 入驻流程

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/60/v3/qeJ3XK5RTGqO1aLILhaMjw/zh-cn_image_0000002535575320.png?HW-CC-KV=V1&HW-CC-Date=20261008T142549Z&HW-CC-Expire=31536000000&HW-CC-Sign=6F5C2BDC9C5B32A0BC1153392192ED845E66D043BAE11458D6DCA6C1BF5EE404)

## 操作步骤

1. 注册华为开发者联盟账号，详细操作可参考[注册账号](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。

2. 实名认证为服务商：

（1）点击[此处链接](https://developer.huawei.com/consumer/cn/reseller/account/profile)跳转合作伙伴实名认证页面，选择服务商卡片进行**实名认证**，完成资料填写并提交实名认证审核。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7d/v3/wavoqtMCRYWPsOmqLLpdZg/zh-cn_image_0000001448780714.png?HW-CC-KV=V1&HW-CC-Date=20261008T142549Z&HW-CC-Expire=31536000000&HW-CC-Sign=BBBD36F3A0A169B17E2CA5B9033A97FBDCD6EBD413A37D718B149F47B1CF2D79 "点击放大")
> 注意
>
> * **若您已有华为账号且未进行实名认证，可直接登录后，通过服务商角色进行认证。**
>
>
> * **若您已有华为账号且已通过个人/企业开发者实名认证，请重新注册新账号进行认证。**为了您后续业务开展体验，建议您优先使用企业邮箱进行华为账号注册。

3. 申请入驻生态市场。

（1）进入【[服务商管理中心](https://developer.huawei.com/consumer/cn/reseller/overview)】，点击左侧"生态市场"，选择"申请入驻"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e1/v3/a7JT-PB_TVabRgu8RiysLA/zh-cn_image_0000002100720345.png?HW-CC-KV=V1&HW-CC-Date=20261008T142549Z&HW-CC-Expire=31536000000&HW-CC-Sign=8B6E6F325995DDD841B5780A0C1C1CD14ED3E72AA34CCAFFFD8678D481772DF6 "点击放大")

（2）按页面提示填写相关信息，提交审核，等待工作人员审核。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/af/v3/Y8yX7PGqTfaOT_TLM4E3Qg/zh-cn_image_0000002064722920.png?HW-CC-KV=V1&HW-CC-Date=20261008T142549Z&HW-CC-Expire=31536000000&HW-CC-Sign=D80D8A94779047304B2E8FC6EB81D1753D3F99CBE109E91A57BA26FF5F597FE6 "点击放大")
> 说明
>
> 业务资质模板：合同截图必须清晰可见，并且必须有合作双方的盖章。
>
> zip格式：可包含xlsx、docx、pdf、png、jpg、jpeg格式，不能含有文件夹。若上传出现问题，可更换浏览器，继续上传。

4. 缴纳保证金。

（1）入驻申请通过后， 在【服务商计划-保证金中心】选择"缴纳保证金"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/51/v3/PBt6p2bGT4CsDwr-_RN0nQ/zh-cn_image_0000002064733292.png?HW-CC-KV=V1&HW-CC-Date=20261008T142549Z&HW-CC-Expire=31536000000&HW-CC-Sign=32B316A014297600168FCED696BE871AFE98F7DD145082B7737ED945C3F63E2D "点击放大")

（2）缴纳保证金时会校验付费服务是否开通，没有开通按要求开通即可。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c1/v3/BvVhGoEHSHGd0OlCORNeSA/zh-cn_image_0000001498145529.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T142549Z&HW-CC-Expire=31536000000&HW-CC-Sign=9801E58367776E34FEDB068909FB9CC8A97022CBEC53A4B43903E090D34610DA "点击放大")
> 说明
>
> 目前仅支持线下对公账户打款，支付完成后在页面填写银行转账流水号并上传支付凭证。凭证上传后，需等待审核人员审核：审核通过即代表保证金缴纳完成。

5. 保证金缴纳审核通过后，可点击左侧【生态市场】菜单，进入卖家中心，按步骤配置店铺后上架商品。

6. 接入华为支付商户平台

若您需要交易已上架的商品或希望在需求广场抢单，则需接入华为支付商户平台；如无交易需求，则无需接入。

（1）在卖家中心-店铺信息创建完毕后，点击支付接入下的"申请接入"按钮；

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7e/v3/B44wAjofQ0OBzjGVYkk1AA/zh-cn_image_0000002561730821.png?HW-CC-KV=V1&HW-CC-Date=20261008T142549Z&HW-CC-Expire=31536000000&HW-CC-Sign=5FDE6C12839DC5172E22CB01E9479105990EA9D44B1B835009862F90F4E30C86)

（2）点击授权华为账号登录，确认接受邀请；

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/23/v3/iEFWgSNdTmqWWfbmCpxlGA/zh-cn_image_0000002561733375.png?HW-CC-KV=V1&HW-CC-Date=20261008T142549Z&HW-CC-Expire=31536000000&HW-CC-Sign=F7F3C89EB609B04CDF591B2C337000D1E29C3BA2525BB804E2C17795A2D2A54A)![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/18/v3/wgW7KjsIRH-sCXNRfgeZyA/zh-cn_image_0000002561733523.png?HW-CC-KV=V1&HW-CC-Date=20261008T142549Z&HW-CC-Expire=31536000000&HW-CC-Sign=9EE1A9A177FFA29263F01D894776A503BD04C902900F2A033923FCA960BAB6E5 "点击放大")

（3）根据系统提示完成申请管理员账户、商户主体信息填写，商户经营信息填写，点击提交，等待审核；（填写明细可参考["平台子商户如何提交申请"](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-zishanghuruwang-0000001720049550#section6562121910312)文档说明）

（4）审核通过后，则接入状态显示"已接入"，您可以正常在生态市场进行交易，或在需求广场进行抢单。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b9/v3/EOqSFE0nQjK_Vhn75JkbuQ/zh-cn_image_0000002561764843.png?HW-CC-KV=V1&HW-CC-Date=20261008T142549Z&HW-CC-Expire=31536000000&HW-CC-Sign=21574CBB14782E4E6C7EB9628FBDFC01BAEACD392418CC0D96AEFB781BCA4E2B)
