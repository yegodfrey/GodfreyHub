# 对公银行打款认证

对公银行打款认证需要您提供一个公司的对公银行账号，华为开发者联盟将通过银联商务支付股份有限公司向此账号里转入随机金额并提供打款附言（随机码），您在华为开发者联盟实名认证页面准确输入到账金额及打款附言（随机码）后，即可完成认证。

1. 点击头像下拉框中的"[去认证](https://developer.huawei.com/consumer/cn/verified/enrollment)"，进入"实名认证"页面。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202408.74924880657012334054736898557340:50001231000000:2800:9B649BC6273B110402C22581E887140262430D77F859698AC2E6BBD93E8CB628.png)

<!-- -->

2. 点击"企业开发者"图标或"下一步"，进入开发者类型选择页面。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202408.09877137835642297314389542790872:50001231000000:2800:08AF7DCE9A30F719742C900FBE947D893CA2FFD556FAA4A3BA565926D1889AF0.png "点击放大")

3. 选择对公银行打款认证，进入打款认证页面。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202408.00029847600589637424865906650086:50001231000000:2800:F32887995002B103E30536170022534D20F97B6CF091AD1F20A10C94D82DBD01.png "点击放大")

<!-- -->

4. 完善企业的基本信息和企业银行账户信息。
   1. 企业的基本信息：企业的基本信息需要和企业营业执照上信息保持一致。
   2. 企业银行信息填写有2种方法。 方法一：在"开户银行"输入框里输入关键字，系统会匹配出含有关键字的银行信息，在下拉菜单中选中您的企业银行后，系统自动把银行名称填充到输入框内（如建设银行，请输入"建设"），银行信息填写完成。填写支行信息操作同开户银行一致。

      ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202408.23209506170801534109770923515992:50001231000000:2800:8BE9E8636FC670AE4247954A1266CEC0A6F140F13D4E6CBB7421673AC45D6188.png "点击放大")

      <br />

      方法二：点击"开户银行"后面的搜索按钮（如上图），进入银行搜索页面。输入支行号点击查询，选中查询出的支行，点击"确认"系统自动把银行名称填充到输入框内，银行信息填写完成。  
      ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202408.89034624153223534771735583416078:50001231000000:2800:72D060ABE70DFE21F937D668D3A02276F832B9084A7B123BF3494494B2AAC9B1.png "点击放大")  
      ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202408.41693753926991022788012824600361:50001231000000:2800:B11CB21247B18314991F40CE6C495E2CB102458ABE7BFFB33D296B5003B29171.png)  
      如果没有找到贵公司对公银行账户的银行或支行信息，可以[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)反馈或者选择人工审核的方式。

      系统自动填充银行信息：

      ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202408.89101730412532021121422876579777:50001231000000:2800:B8FD97E65BA057F5D7EEB7A92F756E42BD73B5CF5C7D2F0FB32C12C3C999307D.png)

   企业的基本信息和企业银行账户信息：

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202408.94582458969275876455289336692729:50001231000000:2800:022DB620759E6B1ECFA5E9C6858BA239C529DA0CAFC480E1A9423225AEEA1220.png "点击放大")

   企业的基本信息和企业银行账户信息填写完成后，签署[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/start/agreement-0000001052728169)，点击"下一步"，系统会同步验证企业的法定代表人信息，若验证通过后，系统会发送邮件和短信通知您已发起打款申请。通知发出后30分钟\~3工作日内，银联账户将向您提供的银行账户打一笔小于1元的款项，且将在打款附言中提供随机的6位数随机码。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202409.67722432370577820232076918288550:50001231000000:2800:0C30A9A9FB0BBA3568F7623E5DEB5852354946FF64C5934DAFA3B5F3BF6584DA.png "点击放大")

5. 输入打款金额及打款附言（随机码）。 在收到打款通知后的1个工作日内，请关注对公账户。收到打款后，登录开发者联盟进入"[管理中心](https://developer.huawei.com/consumer/cn/console/overview)"，点击页面"待处理事项 \> 实名认证审核中"通知消息查看或左边菜单栏"开发者信息"进入打款金额及打款附言（随机码）输入页面。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202409.20482960028262443234256974855492:50001231000000:2800:65FF28E75971BF0C0E066AC03348055AFB1C2107F24315A71F0A4141B820F89C.png "点击放大")

   输入打款金额和打款附言（随机码）后，点击"提交认证"，系统自动审核。如您填写的金额和打款附言（随机码）正确，实名认证通过；如填写的金额或打款附言（随机码）错误，实名认证被立即驳回。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202409.32779554518924403661053647912898:50001231000000:2800:88EE888000EC341B5F31367EB01FA3ABA9FCC80AD8B76E7ECB58223682022CC6.png "点击放大")
