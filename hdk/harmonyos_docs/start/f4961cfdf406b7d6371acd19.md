# 技术支持

联盟提供了如下四种客服渠道，便于更高效的解答开发者在应用上架、投放、开放能力接入等工作过程中遇到的问题。

## 智能客服

[智能客服](https://developer.huawei.com/consumer/cn/customerService/#/bot-dev-top/faq-top/faq-talk-top)24小时在线服务、自助式智慧应答，海量知识库，即问即答，更高效的解答开发者在注册认证、应用上下架、开放能力接入等工作过程中遇到的问题。

## 联盟工单系统

### 在线提单

通过联盟网站"支持 > [在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)"进入工单系统，1-2个工作日内可获得客服回复。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251119171603.95524048820324209518239622737296:50001231000000:2800:C74043AA46EA9355A971C28CB6539C24181A365177DCAC613BD9DC560E4A5F65.png "点击放大")

### 查看我的工单

在联盟网站右上角的账号头像下拉列表中选择"[我的工单](https://developer.huawei.com/consumer/cn/personalcenter/myCustom/ticketlist)"。

## 联盟邮箱

开发者联盟邮箱地址为：[devConnect@huawei.com](mailto:devConnect@huawei.com)，1-2个工作日内可获得客服回复。

## 社区问答

[社区问答](https://developer.huawei.com/consumer/cn/forum/)，1-2个工作日内可获得客服回复。
