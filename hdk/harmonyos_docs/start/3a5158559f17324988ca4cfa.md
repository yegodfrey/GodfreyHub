# API类商品接入说明

1. 登录生态市场卖家中心。
2. 在左侧导航栏，选择商品管理。
3. 点击发布商品。
4. 填写商品接入信息，点击下一步。

|**发布项**|**发布标准**|
|:---------|:-----------------------------------------------|
|选择接入类型|选择API类接入。|
|选择APP交付形态|Rest API。|
|选择API托管模式|托管或非托管。 选择"托管"，请选择托管API的项目、托管API的数据处理位置、托管的API分组|
|选择是否提供控制台|是或否。|
|填写自动交付接口地址|填写 API自动交付接口地址。|

5. 填写商品基础信息，点击下一步

|**发布项**|**发布标准**|
|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|商品名称|1. 请输入商品名称。|
|商品图片|2. 商品图片，用于上架后在商品详情页展示，不超过6个。 3. 图片支持JPG/JPEG/PNG格式，商品主图：尺寸为100X100px，大小不超过5M；商户图片：尺寸为300X300px，大小不超过5M；商品截图：宽度为900px，大小不超过10M 商品主图须与商品内容相关，如商品使用页面、介绍等，不可只上传logo、名称等无介绍作用的图片。|
|商品简介|请填写您的商品简介，此信息将在生态市场的商品列表页面进行展示，字数不少于100字。|
|商品亮点|请填写您商品的详细介绍信息，此信息将在商品详情页面的头部进行展示，建议尽量详细地描述您的商品。|
|商品详情|1. 填写的商品详情，至少包含商品详细信息，商品的核心功能和服务。 2. 商品说明不低于500字，字体要一致，排版要规范，保持整齐美观，请勿出现大量无故换行。 3. 不允许放入非华为的外部链接等类似跳转信息，如出现则驳回（组件类、模板类、解决方案类除外，需审视）。 4. 支持插入图片和视频，图片支持JPG/JPEG/PNG格式，最大宽度不超过900px、每张图片大小不超过3M，最多可上传17个。 5. 不应出现通过其他方式获取商务等描述，如：商务申请或详细价格请咨询xxx。 避免使用广告法敏感词，如：国家级、最佳、极致、世界第一等。|
|（可选）商品资质|1. 上传商品取得的相关资质信息文件，软件商品必须上传与商品名称相符的软件著作权证书，且著作权人须与发布商品公司主体一致。 2. 商品如涉及开源部分，请如实提供商品开源声明。 3. 支持.zip/.docx/.pdf/格式文件。 4. 文件大小不超过10M。|
|使用指南|1. 请提供与商品相符的有效的操作手册和商品手册，而非商品介绍。 2. 使用指南须说明用户从生态市场购买产品后，如何登录、使用等。 3. 使用指南中不可出现第三方平台的使用地址、登录地址等链接。 4. 字体要一致，排版要规范，保持整齐美观。 5. 支持上传.zip/.docx/.pdf格式的文件，文件大小不超过10M。|
|售后支持范围|参照样例按照实际服务内容表述，至少包含服务内容、服务时间、服务电话、服务邮箱4项内容。 > 说明 > * 如售后服务时间超过5*8小时，请确保服务时间内及时响应各联系方式收到的各类售后问题 > * 售后服务邮箱，请确保邮件24小时内能得到答复 **参考样例：** 售后服务时间：7 * 8小时 售后服务内容：XXX系统使用问题 服务热线：010-864***96 服务邮箱：xxx@qq.com|

6. 填写商品业务信息，点击下一步。

|**发布项**|**发布标准**|
|:--------|:----------------------------------------------|
|商品所属一级分类|请选择正确的商品一级分类（商品一级分类是指业务所属一级导航），商品分类必须与商品所属导航一致。|
|商品所属二级分类|请选择正确的商品二级分类（商品二级分类是指业务所属二级导航），商品分类必须与商品所属导航一致。|
|（可选）自定义标签|设置标签方便客户根据标签快速查找到您的商品。|

7. 填写商品售卖信息， API类商品只支持一次性资源包，且有效期为一年。0元商品默认为试用商品限购1次。

|**发布项**|**发布标准**|
|:------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
|商品规格及售价|* 规格信息必须完整。 * 规格命名应有一定规则，不能简单地以"规格1"、"规格2"类似命名，不能简单地以计费方式"年"、"月"类似命名，不能简单地以计数单位"套"、"次"、"一套"类似命名。 * 请选择准确的计费模式。 同一商品不同版本，请以规格做区分，无需以不同的版本发布多个商品。 API接入服务支持上架0元商品。|

8. 填写发票信息。

|**发布项**|**发布标准**|
|:-------|:-------------|
|选择发票类型|普通发票、增值税专用发票。|
|选择普通发票类型|电子普通发票、纸质普通发票。|

9. 填写商品协议，点击下一步。

|**发布项**|**发布标准**|
|:---------|:--------------------------------------------------|
|最终用户协议|请上传商品关联的合同名称（商品上架时关联的合同信息，即《商品服务协议》），商品必须与所关联的合同一致。|
|（可选)特殊商品协议|如商品需特殊协议，可填写此项。|
