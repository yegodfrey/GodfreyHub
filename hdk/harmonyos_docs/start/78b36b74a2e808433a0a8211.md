# 身份证人工审核认证

人工审核认证需要您上传身份证原件正反面扫描件和手持身份证人像面照片进行认证。

1. 点击头像下拉框中的"[去认证](https://developer.huawei.com/consumer/cn/verified/enrollment)"，进入"实名认证"页面。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202409.48367825676456546480807524186632:50001231000000:2800:96A952BF217FCEF3B1AE2DB9CD42E6C0D7013EBBAD83C6A92719A9EB376A5E70.png)


2. 点击"个人开发者"图标或"下一步"，进入开发者类型选择页面。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202409.20861780293320521329853887846955:50001231000000:2800:A584BC0D7D89D11E3050E58CD54BC35201486A63F8D7BB39EAC8A1446AE325BE.png "点击放大")


3. 选择身份证人工审核认证，进入到人工审核认证页面。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202410.57083490783496549762317976040205:50001231000000:2800:E21D9EA8015D48581FCABEBB6A0425E33496CBAA7A6663C2F441E80F315DB37E.png "点击放大")


4. 上传证件照片、填写个人信息后，签署[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/start/agreement-0000001052728169)，点击"下一步"，审核结果会在1-2个工作日发送至联系人邮箱。
