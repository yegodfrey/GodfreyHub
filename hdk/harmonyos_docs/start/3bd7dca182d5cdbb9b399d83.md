# 生态市场FAQ

**1、我已经是企业开发者，提示我没有权限进入生态市场卖家中心是什么原因？**

答：您已有华为账号且已通过个人/企业开发者实名认证，请重新注册新账号进行认证，认证为商户后进行生态市场的业务开展。为了您后续业务开展体验，建议您优先使用企业邮箱进行华为账号注册。

**2、我需要发票，可以如何申请开具？**

答：在生态市场购买的商品，发票由对应的商户开具（华为自营商品除外），具体支持开票类型，以和该商户沟通确认为准。

**3、我是商户身份，为什么不能发布定制需求啊？**

答：目前商户在开通店铺后，可进行需求抢单，但不可发布需求；实名后的个人开发者或企业开发者可发布需求，并在买家中心进行需求管理。

**4、卖家商品被平台侧隐藏了，按照要求修改后怎么取消隐藏？**

答：您可通过邮箱 **partner@huawei.com** 进行反馈并申请取消隐藏，平台侧核实无误后会取消隐藏，恢复商品正常展示。
