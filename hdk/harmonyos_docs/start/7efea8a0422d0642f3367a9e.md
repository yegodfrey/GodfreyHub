4. SDK预检 SDK预检旨在提升SDK审核通过率，结合模型对SDK高频出现的问题进行系统性的预先检测并提供修改意见，可大幅降低上架时间成本，建议企业开发者对SDK自主预检后再进行SDK发布。

   a.填写完所有SDK信息后，选择【保存】，系统将弹窗提示"已保存，请在未上架SDK列表内，点击【操作】里的【预检】按钮对已添加SDK版本进行预检"；点击【确认】后，将进入到未上架列表；在未上架列表点击【操作】里的【预检】按钮进入预检页面。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/89/v3/i_zXMZ5YQwGU-Q9vCPOYOg/zh-cn_image_0000002684401821.png?HW-CC-KV=V1&HW-CC-Date=20261008T152054Z&HW-CC-Expire=31536000000&HW-CC-Sign=32CAE907B245AAB49FDFD27D8E8743340D01212A7BACD1FBEFBD400068FF6253)

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/79/v3/TC3FMTXqSIKn3QuXanV9dQ/zh-cn_image_0000002654403258.png?HW-CC-KV=V1&HW-CC-Date=20261008T152054Z&HW-CC-Expire=31536000000&HW-CC-Sign=9ED8C2EC398AE171C9164E7F8F724E48E2120AA683B584F2CEFD31B84F5DE967 "点击放大")

   b.填写完所有SDK信息后，选择【编辑发布】，系统将弹窗提示"建议先完成预检以提升上架审核通过率（直接发布将中断进行中的预检），是否确认发布"；点击【确认】后，将提交审核并进入到审核列表；点击【取消】将回到商品信息填写页面，可选择【保存】，在未上架列表点击【操作】里的【预检】按钮进入预检页面。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fa/v3/YVCSDH5gQhWNHNw5It8MLQ/zh-cn_image_0000002684243407.png?HW-CC-KV=V1&HW-CC-Date=20261008T152054Z&HW-CC-Expire=31536000000&HW-CC-Sign=F4D08CF4C9B0866BC958F49DE14A30CD0428196B50E84781DAF12ABC53651FEF)

   c.点击【预检】后进入预检详情页面，点击【点击开始】进入内容识别页面；支持对【SDK包体】、【权限清单】、【合规使用指南】及【隐私政策】进行检测；【合规使用指南】及【隐私政策】支持PDF或Docx文档格式的检测，暂不支持链接形式和zip文件的检测；预检结果在预检开始后在预检详情页面获取。
