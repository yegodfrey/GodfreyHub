# 政策中心

华为全场景智慧生态的蓬勃发展离不开您的优质创新及产品，但追求成就必然伴随着责任。如下的开发者政策可更好地确保服务品质，让我们携手通过AGC、游戏中心、主题产品、鲸鸿动能广告等向华为终端的亿级用户分发及推广更多优质的创新及产品。欢迎您通过下方的内容快速了解我们的政策。
