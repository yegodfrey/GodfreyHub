## 接口原型

|承载协议|HTTPS GET|
|-----|-------------------------------------------------------------------|
|接口方向|商户服务器 -> 华为服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/oauth2/v1/token|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 请求参数

请求参数由Header中传入，包含参数如下：

|参数名称|必选(M)/可选(O)|数据类型|参数说明|
|:-----------|:----------|:-----------|:--------------------------------------|
|client_id|M|String(256)|客户端ID，用户申请Token时使用的clientId，由精选应用服务生成。|
|access_token|M|String(2048)|客户端Token，用户申请Token中获取到的Token，由精选应用服务生成。|

> 说明
>
> 除Header参数外，请求还需要携带验签必需的URL参数，详情请参见[安全校验规则](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-marketplace-spapi-autodeliveryprg-0000001380928181#section26527379136)。

## 请求示例

```screen
POST api/oauth2/v1/token
Host: connect-api.cloud.huawei.com
"client_id": "26********20"
Content-Type: application/json
"access_token":"****"
```

## 返回参数

返回值为JSON格式的字符串，包含参数如下：

|参数名称|必选(M)/可选(O)|数据类型|参数说明|
|:-----------|:----------|:-----|:-----------------------------------------------------------------------------------------------------------|
|client_id|M|String|客户端ID。|
|expires_in|M|Long|access_token的有效期，单位：秒。|
|service_code|O|String|服务Code，详情请参见[术语表](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-terminology-0000001446432989)。|

## 响应示例

```screen
HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8
{
"client_id": "26********20",
"expires_in": 7199,
"service_code": "serviceCode"
}
```

## 示例代码

验证Token示例代码（Java）

```screen
public static boolean verifyToken(String domain, String clientId, StringclientToken) {
boolean isValid = false;
try {
        HttpGet get = new HttpGet(domain + "/api/oauth2/v1/token");
        get.setHeader("client_id", clientId);
        get.setHeader("access_token", clientToken);
        CloseableHttpClient httpClient = HttpClients.createDefault();
        HttpResponse response = httpClient.execute(get);
        int statusCode = response.getStatusLine().getStatusCode();
if (statusCode == HttpStatus.SC_OK) {
            BufferedReader br =
new BufferedReader(new InputStreamReader(response.getEntity().getContent(), Consts.UTF_8));
String result = br.readLine();
            JSONObject object = JSON.parseObject(result);
            int expiresIn = object.getInteger("expires_in");
            isValid = expiresIn > 0;
        }
        get.releaseConnection();
        httpClient.close();
    } catch (Exception e) {
    }
return isValid;
}
```
