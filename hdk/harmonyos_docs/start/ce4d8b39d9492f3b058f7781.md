# 共栖

共栖（苏州大学学生作品）

以寓教于乐的形式普及鸟类知识，在游戏中探索人与鸟类的共处之道。  

#### 作品类型

公益类  

#### 入选情况

创新应用-成型APP类 ★★  

#### 开发者

刘佳豪、朱晨清、金晗昕、谢仪伟、陈思彤  

#### 功能介绍

《共栖》是一款以环境保护与鸟类保护为主题的应用。《共栖》让用户作为一个自然保护区的护鸟员，在白天巡山观鸟、夜间记录感悟的交替过程中，使用户的鸟类知识得到普及，并通过展现人类活动对鸟类生活环境的破坏，潜移默化的提升用户的自然环境保护意识。

#### 应用价值

《共栖》使用人群是可以使用智能手机的所有用户，在放松用户身心的同时，潜移默化的向用户传递环境保护与鸟类保护的理念。在接入华为HMS Core的Location Kit之后能够根据用户所处位置触发不同的游戏事件。《共栖》给予用户充分的选择自由，让用户定制属于自己的"修复环境策略"，使用户在画这个平台上能够自己切身感受到人类的活动对于鸟类生存环境的影响。更可贵的是，用户通过此游戏可以以小见大，将获得的环境保护意识投射到日常生活当中，为自然与人类的和谐相处贡献自己的一份力量。

通过华为的"校园开发者计划", 《共栖》开发团队能够和HMS生态中其他校园开发者交流技术、分享经验，并且把从线上线下的技术沙龙和精品课程中接触到的最新技术和解决方案应用到开发中。华为平台技术专家们也为这个大学生团队提供专业指导，帮助其高效接入华为终端开放能力及服务。《共栖》最终成功融入了多项HMS能力，实现了诸如基于用户地理位置触发不同场景等功能。
