# 使用入门

为了保证用户能够正常使用您上架的API服务，您必须首先完成API服务相关自动发货接口的开发：

1. 了解API服务接口开发的整体要求、安全校验规格、签名及验签的规则，以确保接口开发正确，详情请参见[自动发货接口整体方案](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-marketplace-spapi-autodeliveryprg-0000001380928181)。
2. 为了验证请求发起方的身份，确保请求安全，您需要验证请求Token是否合法，详情请参见[验证Token](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-marketplace-spapi-token-0000001329808250)。
3. 您需要完成[同步配额](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-marketplace-spapi-queryquota-0000001381008801)、[查询配额](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-marketplace-spapi-apiqueryquota-0000001381128001)的开发，以确保您已获得了套餐配额信息并可以正确地返回给用户套餐剩余配额信息。
