# 撤销账号组

1. 用账号组管理员账号登录[华为开发者联盟官网](https://developer.huawei.com/consumer/cn/)，进入"管理中心 > 开发者中心 > 账号组"，点击"撤销账号组"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/34/v3/KOVl5Ai6RymuU-pNceAtJQ/zh-cn_image_0000002616121437.png?HW-CC-KV=V1&HW-CC-Date=20260909T171546Z&HW-CC-Expire=31536000000&HW-CC-Sign=740887FC6AF2769943AEE8A8653C7C915BBCAB64C676A61798696B1116216CE9)
