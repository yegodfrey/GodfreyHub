# 撤销账号组

1. 用账号组管理员账号登录[华为开发者联盟官网](https://developer.huawei.com/consumer/cn/)，进入"管理中心 > 开发者中心 > 账号组"，点击"撤销账号组"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/34/v3/KOVl5Ai6RymuU-pNceAtJQ/zh-cn_image_0000002616121437.png?HW-CC-KV=V1&HW-CC-Date=20261008T181453Z&HW-CC-Expire=31536000000&HW-CC-Sign=B65E4A55618434051F5FA54BD425108528893D00D1B77AE4C9FC6AAD9094870F)
