# 撤销账号组

1. 用账号组管理员账号登录[华为开发者联盟官网](https://developer.huawei.com/consumer/cn/)，进入"管理中心 \> 开发者中心 \> 账号组"，点击"撤销账号组"。

   ![](https://media:801782184086002424)

<!-- -->

2. 仔细阅读弹框内容后，点击"确定"即可撤销账号组。 ![](https://media:801782184086031425 "点击放大")
