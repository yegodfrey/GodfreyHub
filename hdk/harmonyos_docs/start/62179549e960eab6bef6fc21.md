# DevEco Studio

生态市场SDK支持在DevEco Studio中直接浏览、搜索并使用，可帮助开发者快速创建工程、实现代码编写与SDK选择的无缝集成，提升开发效率。

DevEco Studio下载链接：[最新版本 - 下载中心 - 华为开发者联盟](https://developer.huawei.com/consumer/cn/download/)

1、生态市场SDK在DevEco Studio上 入口：

a.DevEco Studio左侧导航栏"鸿蒙生态伙伴SDK市场"或"Partner SDK"

![](https://media:401788750500700168 "点击放大")

b.DevEco Studio左侧导航栏"More tool windows"---"鸿蒙生态伙伴SDK市场"或"Partner SDK"

![](https://media:401788750500827169 "点击放大")

c.DevEco Studio上方导航栏"工具"---"鸿蒙生态伙伴SDK市场"或"Partner SDK"

![](https://media:401788750500957170 "点击放大")

2、搜索工程所需SDK

a.搜索框---关键词搜索，搜索框输入关键词搜索，如"即时通讯""直播点播""审核认证"等；

![](https://media:401788750501089171 "点击放大")

b.优选/GIIC检测筛选

鸿蒙生态伙伴SDK 优选库是基于生态市场已上架SDK的精选方案，该优选库严格遵循国家标准、行业规范等多元评估体系，从合规性、个人信息保护、网络安全、生态贡献度及开发者体验等多个维度进行综合评定。

鸿蒙生态伙伴SDK GIIC检测库是生态市场已上架并通过工信部及全国智慧物联网（GIIC）审核检测的SDK；

![](https://media:401788750501214172 "点击放大")

c.分类列表页筛选，根据一级分类、二级分类可准确筛选出工程所需的SDK；

![](https://media:401788750501329173 "点击放大")

3、添加SDK至工程

a.找到所需SDK后，查看SDK相关信息，如SDK详情、权限与隐私、兼容性等。

![](https://media:401788750501445174 "点击放大")

b.在SDK详情页右上方可直接添加选中的SDK至工程；

![](https://media:401788750501699175 "点击放大")

c.部分SDK无法直接添加至工程，需跳转至OHPM或伙伴官网进行获取；

![](https://media:401788750501834176 "点击放大")
