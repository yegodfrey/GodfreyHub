# DevEco Studio

生态市场SDK支持在DevEco Studio中直接浏览、搜索并使用，可帮助开发者快速创建工程、实现代码编写与SDK选择的无缝集成，提升开发效率。

DevEco Studio下载链接：[最新版本 - 下载中心 - 华为开发者联盟](https://developer.huawei.com/consumer/cn/download/)

1、生态市场SDK在DevEco Studio上 入口：

a.DevEco Studio左侧导航栏"鸿蒙生态伙伴SDK市场"或"Partner SDK"

2、搜索工程所需SDK

a.搜索框---关键词搜索，搜索框输入关键词搜索，如"即时通讯""直播点播""审核认证"等；

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/59/v3/gm_nWQ5eTR6DBzhHaUAG5Q/zh-cn_image_0000002712345038.png?HW-CC-KV=V1&HW-CC-Date=20261008T164209Z&HW-CC-Expire=31536000000&HW-CC-Sign=CCDFA922D9E5A5E3AD256B026B721D17E50A0C5D26C4B3262FE707B9550E75C8 "点击放大")

b.优选/GIIC检测筛选

鸿蒙生态伙伴SDK 优选库是基于生态市场已上架SDK的精选方案，该优选库严格遵循国家标准、行业规范等多元评估体系，从合规性、个人信息保护、网络安全、生态贡献度及开发者体验等多个维度进行综合评定。

鸿蒙生态伙伴SDK GIIC检测库是生态市场已上架并通过工信部及全国智慧物联网（GIIC）审核检测的SDK；

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a3/v3/ip4goMzhSJqnN6Gilp2s7Q/zh-cn_image_0000002742063997.png?HW-CC-KV=V1&HW-CC-Date=20261008T164209Z&HW-CC-Expire=31536000000&HW-CC-Sign=E630CF0C3734A5C290E6BEC569486C3CF99C520215B1DC64EF8323D0FE9610CB "点击放大")

c.分类列表页筛选，根据一级分类、二级分类可准确筛选出工程所需的SDK；

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ac/v3/bwaUZxPeSFe4jZIiCw_GUw/zh-cn_image_0000002712185092.png?HW-CC-KV=V1&HW-CC-Date=20261008T164209Z&HW-CC-Expire=31536000000&HW-CC-Sign=25761992CB8A690DBF4756018443EDA53A03A65A819F97EC566D05A743141621 "点击放大")
