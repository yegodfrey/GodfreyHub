# 耀星计划操作指导

"耀星计划"：是华为于2017年底宣布启动的一项全球激励计划，该计划基于10亿美元激励资源，通过耀星创新激励、耀星·领航计划、耀星·火花计划，分别为应用分发、服务分发、内容分发创新、生态共建、开放能力接入等领域，提供覆盖应用开发全生命周期、面向开发创新、用户增长、商业推广、数字营销等多维度的激励和扶持。目前, 全球范围内已有过万开发者和创新应用获得了耀星激励。2023年耀星计划全面升级，持续以全领域多元化资源激励鸿蒙开发创新，携手伙伴共建鸿蒙新生态。

## 1. 如何申请

### 1.1 前提条件

开发者需在华为开发者联盟[注册账号](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)并[实名认证](https://developer.huawei.com/consumer/cn/doc/start/itrna-0000001076878172)，方可申请"耀星计划"。

### 1.2 相关规则

1. "耀星计划"生态合作伙伴类型有：开放能力接入、数字服务创新、生态共建；"耀星计划"领域有：AR、华为支付、多屏、智慧车载、智能穿戴、创新应用、创新游戏、元服务、云云共建生态伙伴、教育中心（耀星·火花计划）、媒体生态伙伴（信息流、主题图片、音乐音频）。开发者需选择正确的生态合作伙伴类型及领域，否则会影响评估结果。

2. 开发者可为同一应用/服务报名不同生态合作伙伴类型下的不同领域，但天内不可在同一领域重复报名。自收到评估结果日起30天后，如有更新创新点，可再次报名该领域。

## 2. 关于评估

在每一评估周期内，华为终端云服务部负责对当期收到的申请资料进行评估，按照不同类型不同领域的评估规则评定星级。入选开发者完成"耀星计划"协议签署后，由华为执行对应星级的激励资源发放。![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260225111403.65681847596245614866850873066317:50001231000000:2800:892CE4A49D1EF12EA539573863E15059F311914940F2F00E2E01D3968837CC98.jpg "点击放大")

报名：耀星计划月度评审，每月20日24点为当期报名截止时间。

公告：下月20日左右在开发者联盟官网公布当期评审结果。

签约：开发者需在收到评估结果通知的3个工作日内完成签约，否则顺延至下月，超15个自然日未签约视为放弃本次入选。

反馈账号：开发者需在收到评奖结果通知后3个工作日内完成账号反馈，否则延期到下期发放；超1年未反馈账号视为放弃本次入选。

激励发放：耀星计划工作组将在评估结果通知发出后的12个工作日内发放激励资源。

## 3. 评估结果通知及签约

### 3.1 评估结果通知

开发者可在"我的报名"查看评估结果，或留意报名所填联系邮箱，查看news@notice02.developer.huawei.com发出的通知。

如评估结果为不通过，则本次流程结束，您可尝试申请其他类型领域，或更新产品在一个月后重新申请此类型领域；如评估结果为通过，请完成"耀星计划"协议签署。协议签署有线下和线上两种方式。

### 3.2 协议签署

> 注意
>
> 超15天未签约视为放弃本次入选，"线上签约"按钮置灰不可点击。

1. 线上签署协议

开发者在"我的报名"→"查看"，点击"线上签约"，在协议页面勾选同意，点击确认即为完成签约。当回到"我的报名"→"查看"，"线上签约"按钮置灰不可点击，代表签约已完成。

## 5.激励资源发放

### 5.1 专区资料

此资源为耀星计划工作组自运营资源，开发者无需额外申请操作。

### 5.2 耀星流量券

> 注意
>
> 耀星流量券在各账户的配额充值后无法更改，仅可反馈一次，请谨慎选择；
>
> · 耀星流量券自发放之日起有效期1年，到期系统自动作废；
>
> · 耀星流量券仅限入选"耀星计划"的产品使用，违规操作将被禁止投放或除名；
>
> · 推广账号以初次反馈为准，如因反馈错误导致无法充值/建立投放任务，责任由开发者承担；
>
> · 评奖后耀星计划工作人员会在3个工作日内邮件与满足条件的入选开发者确认耀星流量券充值到各个账户的配额；

确定华为应用市场投放配额后，开发者需线上反馈入选产品在华为应用市场的推广账号信息。

## 7. 其他

### 7.1 联合宣传
