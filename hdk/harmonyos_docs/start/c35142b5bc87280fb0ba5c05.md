# SDK上架地图

生态市场针对SDK的上架，为企业开发者及服务商提供了同一上传路径，助力业务发展与商业成功。

SDK提交后，会在1-3个工作日进行审核，审核通过后即可上架并在生态市场展示。

SDK审核详见[SDK政策审核](https://developer.huawei.com/consumer/cn/doc/start/sdk-gallery-policy-0000001913021977)。
