# 使用IM客服

## 查看会话

卖家开通IM客服后，通过卖家中心-IM客服菜单下的在线客服"进入"，打开IM客服页面后选择当前会话，即可查看会话列表。或者可以直接登录云客服管理台查看会话。

* 云客服管理台URL地址：[https://css.cloud.huawei.com/agent-workbench/admin/RealTimeMonitoring](https://css.cloud.huawei.com/agent-workbench/admin/RealTimeMonitoring)
* 若您还未开通IM客服，可按[IM客服开通指导](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-im-isvguide-dredge-0000001343658457)操作。
* 买家发送消息，实时网页右下角会弹出"新消息"提醒，也可直接点击提醒进入查看。

## 会话管理

**云客服管理员**通过会话管理可以了解待服务会话、服务中会话、所有座席的历史会话。

* 待服务会话：正在排队等待服务的会话，等待时长，并协助转接。
* 服务中的会话：可以查看沟通内容、评价内容，并协助转接。
* 历史会话：查看沟通内容、评价内容，沟通时长。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b0/v3/DGY65J6WTIGgW07FT6wa0A/zh-cn_image_0000001344818385.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T163625Z&HW-CC-Expire=31536000000&HW-CC-Sign=597E94B3A588ACD5861C2CACEB9BBC0D977041249E636833A46BCE392E349837 "点击放大")

**座席客服**通过会话管理可以获得服务中会话列表、待服务会话，完成转接、邀评等操作。

* 可通过"当前会话"查看正在服务中的会话界面，可设置工作状态、邀评、结束会话等。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/18/v3/P6pCfkqlThGIRwTde9Wuuw/zh-cn_image_0000001348267489.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T163625Z&HW-CC-Expire=31536000000&HW-CC-Sign=35786D5B789867BA532C10F50740FD8B1BFF148E9C9016CA9A896E74F68CE5F3 "点击放大")

* 转接会话只能转接给当前在线的其他座席。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e4/v3/cYvlMepzRZGRe__-9VVwTQ/zh-cn_image_0000001295070546.png?HW-CC-KV=V1&HW-CC-Date=20261008T163625Z&HW-CC-Expire=31536000000&HW-CC-Sign=E4A130F1754760FB50DE2D8209744B769120FC3ED2771FE8673F780AD848CD2E "点击放大")

* 座席账号的会话管理共有3个菜单选项，分别对应以下操作：

|---------|--------------------|
|**菜单选项**|**支持操作**|
|待服务中的会话列表|排队等待时长、转接|
|服务中的会话列表|查看会话内容、转接|
|已结束的会话列表|查看会话内容、消息数、会话时长、评价内容|

## 其他设置

**云客服管理员** 可选择云客服管理台左侧菜单栏中的**设置**，配置工作时间、邀请设置等。

1. **时间计划：**云客服平台设置有工作时间初始值，卖家可根据情况选择修改，配置工作日、节假日、自定义工作日（若默认值与实际工作时间不同，可自行设置）。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/25/v3/7gmpYEX2Q5ygBFRhrk-QnQ/zh-cn_image_0000001348916049.png?HW-CC-KV=V1&HW-CC-Date=20261008T163625Z&HW-CC-Expire=31536000000&HW-CC-Sign=8135752869A86954C1F0A781F8A67FF64669A7089D61A61CEBD447B6D06B0CA9 "点击放大")
> 注意
>
> 建议您在配置客服工作时间的时候，和店铺信息中的店铺上班时间段保持一致，避免给买家造成混淆。可在[店铺信息维护](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-store-maintenance-0000001071244324)中设置店铺上班时间段。

2. **超时设置：**访客超时未回复的时限和提醒、座席超时未回复的时限和提醒（建议采用默认值）。

* 卖家可自行设置访客服务时长，系统默认为1小时35秒，若访客未回复超过设置时间，可弹出超时提示语，系统预设的提示语卖家可以选择编辑修改。自动提醒有三次提醒，最后一次提醒后买家未回复则会话自动结束。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fb/v3/zQn8LxN2RW-Cr24HowvSQg/zh-cn_image_0000001344822229.png?HW-CC-KV=V1&HW-CC-Date=20261008T163625Z&HW-CC-Expire=31536000000&HW-CC-Sign=5507E81CE21477A0DA56A0C53BFC08FE610DB870DD9FA0E95E697D1DB94B67B9 "点击放大")
> 注意
>
> 访客服务系统默认为1小时35秒，最长可设置23小时59分59秒。

3. **邀评设置：**邀请评价时的提示语、评价时的选项设置（建议采用默认值）。

* 配置"满意度邀请提示语"，"问题是否解决提示语"，点击输入框右侧的编辑符号进行提示语修改。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5b/v3/i3Xitac_TS6tk_FW8GCNFA/zh-cn_image_0000001291982704.png?HW-CC-KV=V1&HW-CC-Date=20261008T163625Z&HW-CC-Expire=31536000000&HW-CC-Sign=6EE908ACA5037E898C7DDACF4D37E6DAB99711631E29B425356374E7EF3DD921 "点击放大")

* 评分选项设置，星级对应的满意程度以及匹配的**评价** **标签内容** 和**数量**支持修改，点击输入框右侧的编辑符号进行修改，若标签文字内容清空则这个标签在买家侧不展示。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fa/v3/ATutwBCnQryRO6ctn36_Ew/zh-cn_image_0000001291823132.png?HW-CC-KV=V1&HW-CC-Date=20261008T163625Z&HW-CC-Expire=31536000000&HW-CC-Sign=4FB75A408F2CE56CE63BF3E0085CA3BCD64039520F6D549DE2BE11D9A699BE25 "点击放大")

4. **参数配置：**将"离线消息发送"的值0修改为1，非工作时间发消息时可以自动回复买家信息（建议修改）。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7d/v3/0cJ6VNF9QQGa65fDGWsXzA/zh-cn_image_0000001344744041.png?HW-CC-KV=V1&HW-CC-Date=20261008T163625Z&HW-CC-Expire=31536000000&HW-CC-Sign=ABD6F19C1D739711348ABA256F0A57968611992D054B76F190047A615AE61D63 "点击放大")

5. **语言管理/国家地区管理：**默认无需设置。

## 数据看板

**云客服管理员**通过数据看板可以了解会话统计数据、服务满意度质量等数据。

* **Dashboard** 只统计展示当天已结束的会话数据。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/eb/v3/N_S4oixxSbOPwP1rBysqGg/zh-cn_image_0000001344944509.png?HW-CC-KV=V1&HW-CC-Date=20261008T163625Z&HW-CC-Expire=31536000000&HW-CC-Sign=F50F9C2A7929C8213E137800DA189D1BC0294F6DEC85A4D517755204213EFBD2 "点击放大")

* **满意度报表**支持查看截止前一天的数据，可以选择日期范围、业务、技能组、座席维度来查询满意度情况。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ac/v3/_jLzB6-bRZuCfSadrqoNAg/zh-cn_image_0000001345064161.png?HW-CC-KV=V1&HW-CC-Date=20261008T163625Z&HW-CC-Expire=31536000000&HW-CC-Sign=AC697659ABF047D8D7EB2BE0C5790C5FB2E68627767D82ABFC4505ABBE282527 "点击放大")
