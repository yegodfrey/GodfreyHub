# 使用IM客服

#### 查看会话

卖家开通IM客服后，通过卖家中心-IM客服菜单下的在线客服"进入"，打开IM客服页面后选择当前会话，即可查看会话列表。或者可以直接登录云客服管理台查看会话。

* 云客服管理台URL地址：<https://css.cloud.huawei.com/agent-workbench/admin/RealTimeMonitoring>
* 若您还未开通IM客服，可按[IM客服开通指导](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-im-isvguide-dredge-0000001343658457)操作。
* 买家发送消息，实时网页右下角会弹出"新消息"提醒，也可直接点击提醒进入查看。

![](https://media:401788750491324017 "点击放大")

![](https://media:401788750491397018 "点击放大")  

#### 会话管理

云客服管理员通过会话管理可以了解待服务会话、服务中会话、所有座席的历史会话。

* 待服务会话：正在排队等待服务的会话，等待时长，并协助转接。
* 服务中的会话：可以查看沟通内容、评价内容，并协助转接。
* 历史会话：查看沟通内容、评价内容，沟通时长。

![](https://media:401788750491463019 "点击放大")

座席客服通过会话管理可以获得服务中会话列表、待服务会话，完成转接、邀评等操作。

* 可通过"当前会话"查看正在服务中的会话界面，可设置工作状态、邀评、结束会话等。

![](https://media:401788750491537020 "点击放大")

* 转接会话只能转接给当前在线的其他座席。

![](https://media:401788750491574021 "点击放大")

* 座席账号的会话管理共有3个菜单选项，分别对应以下操作：

|---------|--------------------|
|菜单选项|支持操作|
|待服务中的会话列表|排队等待时长、转接|
|服务中的会话列表|查看会话内容、转接|
|已结束的会话列表|查看会话内容、消息数、会话时长、评价内容|

#### 业务管理

云客服管理员管理问候语业务信息、问题分类、关联技能组，选择左侧菜单栏中的业务管理-应用管理进行操作。

1. 业务信息（可选配置）

设置会话开始与结束时自动回复的问候语。

![](https://media:401788750491815022 "点击放大")

2. 问题分类（可选配置）

设置问题分类，买家选择问题分类后，再自动分配对应座席。

![](https://media:401788750491899023 "点击放大")

买家发起会话后，自动弹出问题分类的界面如下：

![](https://media:401788750491956024 "点击放大")

3. 关联技能组（必选操作）

![](https://media:401788750492058025 "点击放大")  
![](https://media:401788750492091026)  
首次开通IM客服的会话界面显示名称对应店铺名称，若卖家更改店铺名称，需要在云客服管理台-业务管理-应用管理，修改应用名，和店铺名保持一致。

![](https://media:401788750492198027 "点击放大")  

#### 成员管理

云客服管理员可选择左侧菜单栏中的成员管理-技能组管理，点击"+"新增；根据提示完成技能组创建。

![](https://media:401788750492271028 "点击放大")

![](https://media:401788750492330029 "点击放大")

创建好技能组后，需要在技能组下分配成员坐席，点击坐席分配，选择成员，点击添加，确定保存完成坐席分配。

![](https://media:401788750492387030 "点击放大")

![](https://media:401788750492468031 "点击放大")  

#### 其他设置

云客服管理员可选择云客服管理台左侧菜单栏中的设置，配置工作时间、邀请设置等。

1. 时间计划：云客服平台设置有工作时间初始值，卖家可根据情况选择修改，配置工作日、节假日、自定义工作日（若默认值与实际工作时间不同，可自行设置）。

![](https://media:401788750492535032 "点击放大")  
![](https://media:401788750492560033)  
建议您在配置客服工作时间的时候，和店铺信息中的店铺上班时间段保持一致，避免给买家造成混淆。可在[店铺信息维护](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-store-maintenance-0000001071244324)中设置店铺上班时间段。

2. 超时设置：访客超时未回复的时限和提醒、座席超时未回复的时限和提醒（建议采用默认值）。

* 卖家可自行设置访客服务时长，系统默认为1小时35秒，若访客未回复超过设置时间，可弹出超时提示语，系统预设的提示语卖家可以选择编辑修改。自动提醒有三次提醒，最后一次提醒后买家未回复则会话自动结束。

![](https://media:401788750492632034 "点击放大")  
![](https://media:401788750492657035)  
访客服务系统默认为1小时35秒，最长可设置23小时59分59秒。

3. 邀评设置：邀请评价时的提示语、评价时的选项设置（建议采用默认值）。

* 配置"满意度邀请提示语"，"问题是否解决提示语"，点击输入框右侧的编辑符号进行提示语修改。

![](https://media:401788750492921036 "点击放大")

* 评分选项设置，星级对应的满意程度以及匹配的评价标签内容和数量支持修改，点击输入框右侧的编辑符号进行修改，若标签文字内容清空则这个标签在买家侧不展示。

![](https://media:401788750493004037 "点击放大")

4. 参数配置：将"离线消息发送"的值0修改为1，非工作时间发消息时可以自动回复买家信息（建议修改）。

![](https://media:401788750493078038 "点击放大")

5. 语言管理/国家地区管理：默认无需设置。  

#### 数据看板

云客服管理员通过数据看板可以了解会话统计数据、服务满意度质量等数据。

* Dashboard只统计展示当天已结束的会话数据。

![](https://media:401788750493201039 "点击放大")

* 满意度报表支持查看截止前一天的数据，可以选择日期范围、业务、技能组、座席维度来查询满意度情况。

![](https://media:401788750493328040 "点击放大")

关于满意度各个参数的解释，您可以将鼠标移至"满意度报表"右上方的"？"，弹窗会列出相关参数解释。

![](https://media:401788750493388041 "点击放大")
