# 耀星计划·校园创新激励FAQ

1. 谁可以申请？

具有正式学籍的在读学生均可申请耀星计划·校园创新激励（如发现申请者非在读学生，将取消其参与/获奖资格）。

<br />

2. 我是未成年人也可以申请吗？

可以，但未满十八周岁的未成年人，应由法定监护人以自身名义实名认证，报名参加。

※ 未成年人作品无法上架华为应用市场。

<br />

3. 对申请人数有限制吗？

创意应用类个人或团队（不超过5人）均可申请，创新体验类仅可以个人为单位申请。

<br />

4. 个人/团队可以上传多个作品吗？

可以，耀星计划·校园创新激励按作品评选。

<br />

5. 个人/团队可以连续每月上传同一作品吗（在作品有更新情况下）？

可以，如果您的作品做了优化更新，可再次提交评选。

<br />

6. 如何申请？

开发者在华为开发者联盟官网注册并实名认证 → 在[耀星计划·校园创新激励](https://developer.huawei.com/consumer/cn/activity/schoolActivity/detail/101617781684062008)页面点击"我要报名" → 填写资料提交附件→进入评选（如资料有缺漏工作人员将联系您补齐）。

※ 每期评选结果会在华为开发者联盟官网公示，后期工作人员将联系入选者发放各项激励

<br />

7. 需要提交的资料有哪些？

在[耀星计划·校园创新激励](https://developer.huawei.com/consumer/cn/activity/schoolActivity/detail/101617781684062008)页面点击"申请加入"，按照要求填写资料以及提交附件即可。

<br />

8. 为什么上传附件失败？

情况一：附加过大，超过200M上传限制；

解决方式：将文件上传网盘，在要上传的压缩包内附上网盘地址密码，由工作人员自行获取。

情况二：压缩包内有另外的压缩文件；

解决方式：将内部的压缩文件解压成文件夹后再整体压缩。

情况三：压缩包内文件类型过多（目前只支持xlsx,docx,pptx,pdf,jpg,png,jpeg，bmp,gif,ico,txt,apk,mp4,wmv,rm,rmvb,avi,Ogg,WebM）；

解决方式：删除相关文件或者转化格式，或将此类文件上传网盘，在要上传的压缩包内附上网盘地址密码，由工作人员自行获取。

<br />

9. 提交后还能修改作品吗？

可以，在当期评选开始前您可多次上传更新您的作品，我们以最后一次提交的资料为评选版本。

<br />

10. 每月有固定报名时间吗？提交多久后能评审出来？

随时均可报名。"耀星计划·校园创新激励"按照报名情况月度或季度组织评审。

<br />

11. 评审结果在哪里公示？

每期评选结果会在华为开发者联盟官网公示，后期工作人员将联系入选者发放各项激励。

<br />

12. 激励发放一般多久能收到？

各项激励将陆续在3个月内发放完成。

<br />

13. 作品入选后有优化更新，还能获得更多的激励吗？

可以，如果您的作品入选后做了优化更新，可再次提交评选，如有升星（如原为★，再次提交评选被评为★ ★ ） 我们将补发激励差额；如果您的作品没有入选，欢迎优化更新后再次提交。

<br />

14. 过程中遇到问题如何求助？

有任何问题可邮件向 shiningstar1@huawei.com 反馈，说明您的问题并留下联系方式，工作人员将及时与您联系。
