# 2021年11月

## 工信部发布"关于开展信息通信服务感知提升行动的通知"

2021年11月至2022年3月底，工信部开展"524"行动，对SDK的要求包括：

1. 内嵌SDK在非服务所必须或无合理应用场景下，不得自启动或关联启动。
2. 内嵌SDK应提供相应功能，由用户自主选择是否开启关联启动。

详情请参见：[工业和信息化部关于开展信息通信服务感知提升行动的通知](https://www.miit.gov.cn/jgsj/xgj/APPqhyhqyzxzzxd/gzdt/art/2021/art_3ddc2eb32416483799b04c432954d066.html)。
