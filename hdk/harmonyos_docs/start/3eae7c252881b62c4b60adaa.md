# 申请退款

您可根据双方交易合同的退款规则，与商户协商一致后进入退款流程。

1.登录买家中心。

2.在左侧导航栏，点击需求订单。

3.点击操作列进行申请退款。

![](https://media:401788750498140129 "点击放大")  
![](https://media:401788750498164130)  
* 确认交付件后不支持发起退款申请。

* 核对订单信息，并填写退款金额及退款原因，提交后待商户后台确认。 ![](https://media:401788750498195131 "点击放大")

* 订单状态显示为已关闭则退款流程完成。

![](https://media:401788750498228132 "点击放大")

后续操作

1. 在订单状态列可查看退款状态。

2. 处于退款中-待商户确认或退款驳回的订单，点击操作列的取消退款可以取消退款申请。  
![](https://media:401788750498251133)  
* 如果退款申请已经通过审核，将无法取消退款。
