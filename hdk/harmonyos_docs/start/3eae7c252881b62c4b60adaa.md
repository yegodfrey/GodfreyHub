# 申请退款

您可根据双方交易合同的退款规则，与商户协商一致后进入退款流程。

1.登录**买家中心**。

2.在左侧导航栏，点击**需求订单。**

3.点击操作列进行**申请退款。**

> 注意
>
> * 确认交付件后不支持发起退款申请。

* 核对订单信息，并填写退款金额及退款原因，提交后待商户后台确认。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e9/v3/SK4_f7qwTk6Z95YvYgGnKQ/zh-cn_image_0000001129748889.png?HW-CC-KV=V1&HW-CC-Date=20260909T153843Z&HW-CC-Expire=31536000000&HW-CC-Sign=F47CF42ECE07081310F7393C57A525E41A55E3DEB80381DA92148852948ACB9E "点击放大")

* 订单状态显示为**已关闭**则退款流程完成。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d0/v3/iq3T0B75Qte3_YzNmsZ3Ng/zh-cn_image_0000001126386369.png?HW-CC-KV=V1&HW-CC-Date=20260909T153843Z&HW-CC-Expire=31536000000&HW-CC-Sign=C5E8E6455C15198E709082C5D593F1ECEB268D6225624EED8E9095380049D8E7 "点击放大")

**后续操作**

1. 在**订单状态**列可查看退款状态。

2. 处于**退款中** **-** **待商户确认** 或**退款驳回** 的订单，点击**操作** 列的**取消退款**可以取消退款申请。
> 注意
>
> * 如果退款申请已经通过审核，将无法取消退款。
