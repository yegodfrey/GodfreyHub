# 账户

进入管理中心页面，在"我的账户"中可查看您的余额、收益和账单等。

## 余额

开发者可以在余额里给付费推广服务充值，查看付费推广费用的余额和充值明细，充值前申请付费服务（详见[付费服务](https://developer.huawei.com/consumer/cn/doc/start/payment-service-0000001052865979)）。开发者在付费服务中可以配置充值发票信息。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260115092018.14789639396574591994793584598229:50001231000000:2800:3EA4FB66E0DF8FE8B9F21D34BF55CB045188D9548DC8F9E8396A891640C1111E.png)

充值付款支持如下两种方式，有关详细信息，请参阅：[华为应用市场付费推广操作指南](https://developer.huawei.com/consumer/cn/doc/promotion/bp-introduction-0000001309070266)。

1. 线上充值：使用网银直接支付，充值款项即时到账。

2. 线下充值：每笔订单充值金额应与银行实际每笔付款金额相同，2个工作日内到账。

如需申请充值退款，请[点击此处](https://developer.huawei.com/consumer/cn/doc/0010011)参考线上退款申请流程。

## 消费明细

开发者可以通过"消费明细"页面查看您多项服务的消费概览。
