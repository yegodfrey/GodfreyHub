# 过期实例

## 功能介绍

用户购买的产品过期时，生态市场会调用该接口，您接到请求后需要将指定的实例冻结。

## 接口原型

|承载协议|HTTPS POST|
|----|-------------------------------------------------------------------|
|接口方向|华为服务器 -> 商户服务器|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 请求参数

### Body

下表列出了请求Body中使用JSON格式需要携带的实例过期信息，请求验签需要携带的URL参数请参见[安全校验规则](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-marketplace-spsaasservice-autodeliveryprg-0000001249275447#section34923151503)。

|参数名|必选(M)/可选(O)|类型|描述|
|:---------|:----------|:-----|:---------------------|
|action|M|String|取值固定为expireInstance。|
|instanceId|M|String|实例ID，全局唯一，由生态市场商城统一分配。|
|requestId|M|String|请求ID，每次请求均不相同。|

## 响应参数

|参数名|必选(M)/可选(O)|类型|描述|
|:------|:----------|:-----|:-------------------------------------------|
|retCode|M|String|调用结果码，结果码定义参见"[结果码](#section2841191514352)"。|
|retMsg|O|String|调用结果描述。|

## 结果码

|结果码|含义|
|:-----|:---------------------------------------|
|000000|成功|
|000001|鉴权失败|
|000002|请求参数不合法|
|000003|时间戳校验失败（请求时间与本地时间差异较大）|
|000004|实例ID不存在（续费、过期、变更套餐、释放资源可能返回）|
|000099|其它服务内部错误|
|000100|请求处理中（对于异步发货的服务，需返回此结果码，生态市场会持续询问直到发货成功）|

## 响应示例

```screen
HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8
{
	"retCode" : "000000",
	"retMsg" : "expire instance success"
}
```

## 示例代码

```screen
// 处理请求
public Object dealInstance(String signature, String timestamp, String eventId, @RequestBody String requestString) {
    // 处理请求超时逻辑
    if (new Date().getTime() - Long.parseLong(timestamp) > 30 * 60) {
        log.error("dealInstance fail. timestamp {} is invalid.", timestamp);
        return new CommonRsp(SaasRetCodeEnum.TIME_INVALID.getRetCode(), SaasRetCodeEnum.TIME_INVALID.getRetMsg());
    }
    List<String> paraList = new ArrayList<>();
    paraList.add(timestamp);
    paraList.add(eventId);
    // 验证签名
    String realSig = CommonUtil.hmacSha256Hex(paraList, CommonUtil.getDeliveryKey());
    if (!StringUtils.equals(realSig, signature)) {
        log.error(
            "dealInstance verifySignature fail. para timestamp = {}, eventId = {}, signature = {}, RealSig = {}",
            timestamp, eventId, signature, realSig);
        return new CommonRsp(SaasRetCodeEnum.VERIFY_FAIL.getRetCode(), SaasRetCodeEnum.VERIFY_FAIL.getRetMsg());
    }

    // 获取参数，ExpireInstanceReq是包含请求参数的数据类
    ExpireInstanceReq request = JSON.parseObject(requestString, ExpireInstanceReq.class);
    return dealInstanceService.expireInstance(request);
}

// 发送响应
public CreateInstanceRsp createInstance(CreateInstanceReq request) {
    CreateInstanceRsp rsp = new CreateInstanceRsp();
    String productCode = request.getProductCode();
    SaasService saasService = saasServiceMapper.querySaasServiceByCode(productCode);
    if (saasService == null) {
        log.error("createInstance productCode {} is invalid.", productCode);
        return new CreateInstanceRsp(SaasRetCodeEnum.PARA_ERROR.getRetCode(),
            SaasRetCodeEnum.PARA_ERROR.getRetMsg(), request.getInstanceId());
    }
    SaasPurchase entity = new SaasPurchase();
    entity.setPsId(CommonUtil.getUUID());
    entity.setOrderId(request.getOrderId());
    entity.setUpdateTime(new Date());
    entity.setCreateTime(new Date());
    entity.setExpireTime(request.getExpiredTime());
    entity.setOpenId(request.getOpenId());
    entity.setInstanceId(request.getInstanceId());
    entity.setStatus("normal");
    entity.setProductCode(request.getProductCode());
    entity.setRequestId(request.getRequestId());
    Integer trialFlag = request.getIsTrial() ? 1 : 0;
    entity.setTrialFlag(trialFlag);
    saasPurchaseMapper.insertSaasPurchase(entity);
    rsp.setInstanceId(request.getInstanceId());
    rsp.setRetCode(SaasRetCodeEnum.SUCCESS.getRetCode());
    rsp.setRetMsg(SaasRetCodeEnum.SUCCESS.getRetMsg());
    return rsp;
}
```
