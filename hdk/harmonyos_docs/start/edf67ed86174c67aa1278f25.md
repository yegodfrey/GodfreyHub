# 保证金规则及缴纳方式

为了更好地保障华为开发者联盟生态市场用户的权益，提升生态市场商户的服务水平和商品质量。发布商品前，商户需缴纳保证金。未缴纳保证金的商户不得上架商品。本文为您介绍商户保证金规则。  

#### 商户保证金收取规则

2021年2月24日--2022年2月28日平台试运营期间实行保证金减免的优惠政策。

自2022年3月1日起，商户申请入驻生态市场，审核通过后，需要缴纳保证金叁万元（￥30,000.00）人民币。

缴纳保证金后，生态市场开具收据给商户。  
![](https://media:401788750484024907)  
1. 2022年3月1日前入驻成功的商户，保证金无需补交，后续如要入驻其他商品类目，则正常缴纳。

<!-- -->

2. 若商户退出生态市场，入驻时所缴纳的保证金予以退还，商户退出生态市场操作详见[商户退出](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-isvexit-0000001070456319)。
