# 提交方案和合同

您与需求方确认了需求、服务内容、项目价格后，可以在需求详情页提交方案和合同。需求方确认方案和合同后，一键提交订单，您也会收到邮件提醒。  

#### 提交方案

1. 登录[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)。
2. 在左侧导航栏，点击需求管理。
3. 找到目标需求，点击需求标题查看详情。
4. 在需求详情页面的方案列表区域，点击添加方案。
5. 在添加方案对话框填写方案信息并上传附件，点击提交方案。  
   ![](https://media:401788750496711098 "点击放大")  
   ![](https://media:401788750496735099)  
   * 方案配置后，会直接发送给需求方。一个需求内可以配置多个方案供需求方选择，并可以对方案进行删除和修改。

|参数|描述|
|:-----|:-------------|
|方案名称|自定义填写方案名称，便于识别|
|方案文件|上传方案附件，用户可以下载|
|备注（可选）|填写方案备注，用户可以看到|

#### 提交合同

1. 在需求详情页面的合同管理区域，点击上传合同。
2. 在上传对话框填写合同信息并上传附件，点击确定。 ![](https://media:401788750496780100 "点击放大")

   ![](https://media:401788750496807101)  
   * 合同配置后，会直接发送给需求方。一个需求内只可以配置一份合同，在需求方确认订单前可以对合同进行修改上传，需求方确认后，不可修改已上传合同。

|参数|描述|
|:----|:-----------------|
|合同名称|自定义填写合同名称，便于用户进行确认|
|合同文件|上传方案附件，用户可以下载|
|发票类型|选择可提供的发票类型，便于用户识别|
|合同价格|填写项目合同金额，便于用户识别|
|服务有效期|填写服务有效期，便于用户识别|
