# 提交方案和合同

您与需求方确认了需求、服务内容、项目价格后，可以在需求详情页提交方案和合同。需求方确认方案和合同后，一键提交订单，您也会收到邮件提醒。

## 提交方案

1. 登录[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)。
2. 在左侧导航栏，点击**需求管理。**
3. 找到目标需求，点击**需求标题**查看详情。
4. 在需求详情页面的方案列表区域，点击**添加方案**。
5. 在添加方案对话框填写方案信息并上传附件，点击**提交方案** 。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/61/v3/ae2Pl60tTKu7fdMoGldzdA/zh-cn_image_0000001070958980.png?HW-CC-KV=V1&HW-CC-Date=20260909T161503Z&HW-CC-Expire=31536000000&HW-CC-Sign=A082265B8E3625604CDF3DA6DA0B0825D3E9C8F9A7B4AAE048F6FFD9EA719306 "点击放大") 说明
   > * 方案配置后，会直接发送给需求方。一个需求内可以配置多个方案供需求方选择，并可以对方案进行删除和修改。

|**参数**|**描述**|
|:-----|:-------------|
|方案名称|自定义填写方案名称，便于识别|
|方案文件|上传方案附件，用户可以下载|
|备注（可选）|填写方案备注，用户可以看到|

## 提交合同

1. 在需求详情页面的合同管理区域，点击**上传合同**。
2. 在上传对话框填写合同信息并上传附件，点击**确定** 。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4b/v3/0E2BH8qeQ1SCfzBFaRnH2A/zh-cn_image_0000001079496190.png?HW-CC-KV=V1&HW-CC-Date=20260909T161503Z&HW-CC-Expire=31536000000&HW-CC-Sign=C962D9FA80E65D88AFDC60B4224B5318DA14F37CAAF0E03B1577232C46CD1EB9 "点击放大")
   > 说明
   > * 合同配置后，会直接发送给需求方。一个需求内只可以配置一份合同，在需求方确认订单前可以对合同进行修改上传，需求方确认后，不可修改已上传合同。

|**参数**|**描述**|
|:-----|:-----------------|
|合同名称|自定义填写合同名称，便于用户进行确认|
|合同文件|上传方案附件，用户可以下载|
|发票类型|选择可提供的发票类型，便于用户识别|
|合同价格|填写项目合同金额，便于用户识别|
|服务有效期|填写服务有效期，便于用户识别|
