# 查看方案和合同

商户了解您的需求后，会给您提供需求方案。如果您接受商户的方案和报价，即可进行合同签署，确定合作商户。您也可以联系商户对方案和报价进行进一步讨论。

1. 登录买家中心。
2. 在左侧导航栏，点击需求管理。
3. 查看方案。
   * 在需求列表中找到目标需求，点开需求详情，在方案列表中点击方案附件下载查看方案。

   ![](https://media:401788750496257090 "点击放大")
4. 查看合同。
   * 在需求列表中找到目标需求，点开需求详情，在方案列表中点击合同名称进行下载或查看。 ![](https://media:401788750496301091 "点击放大")
