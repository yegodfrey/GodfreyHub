# 查看方案和合同

商户了解您的需求后，会给您提供需求方案。如果您接受商户的方案和报价，即可进行合同签署，确定合作商户。您也可以联系商户对方案和报价进行进一步讨论。

1. 登录**买家中心**。
2. 在左侧导航栏，点击**需求管理**。
3. **查看方案** 。
   * 在需求列表中找到目标需求，点开需求详情，在方案列表中点击**方案附件**下载查看方案。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/39/v3/3ONqzeaQQzemd6TuNccljg/zh-cn_image_0000002176656141.png?HW-CC-KV=V1&HW-CC-Date=20260909T153143Z&HW-CC-Expire=31536000000&HW-CC-Sign=3708ED47C1D8F7E4FF5D77B6BD5AE2EA844D5EC5F6A33ECF66CD1A0506021587 "点击放大")
4. **查看合同** 。
   * 在需求列表中找到目标需求，点开需求详情，在方案列表中点击**合同名称** 进行下载或查看。
