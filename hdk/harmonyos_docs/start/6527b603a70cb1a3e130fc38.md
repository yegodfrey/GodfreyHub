# 联盟生态

为了更好地连接开发者，基于华为终端的开放能力及服务，打造丰富的移动数字业务体验，华为开发者联盟将组织包括HUAWEI Developer Day、鸿蒙开发者大赛平台等线上和线下的活动，并开放社区运营能力及提供耀星计划资源扶持，为开发者提供全面的互动交流和品牌曝光机会。在激励创新的同时，与开发者合作共赢，共同构建万物互联的智慧终端生态。

## 1.线下沙龙---HUAWEI Developer Day

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260225111402.80114666170006697641715865786425:50001231000000:2800:9B2B2734D195B1F39B4FD969866C28E147530257DF263FC6819415CD79A940F2.png "点击放大")

HUAWEI Developer Day（简称HDD）华为开发者日是华为终端与开发者深度交流的平台，通过主题演讲、闭门研讨、动手实验室和展区交流等活动将HarmonyOS的新技术及华为终端的全新开放能力赋能给开发者。

HDD系列活动包含鸿蒙生态伙伴论坛、技术峰会、鸿蒙赋能交流会等，通过举办线上、线下活动助力开发者和生态伙伴加入鸿蒙生态，共建共享鸿蒙新世界。

截至2024年6月，已发表480多个主题演讲，涵盖开发、分发、变现以及生态激励与扶持等领域，覆盖135城市、活动覆盖人次2000万+。

欢迎广大开发者积极参与HDD系列活动！若您有感兴趣技术课题，可以反馈给华为开发者联盟，我们会在接下来的活动中带来更多创新技术内容。

如何参与？

您可以关注华为开发者联盟官网的活动信息，及时报名参与，任何问题均可反馈至活动官网邮箱[program@huawei.com](mailto:program@huawei.com)。

## 2.线上竞赛---鸿蒙开发者竞赛平台

华为开发者联盟推出的鸿蒙开发者大赛平台，旨在鼓励开发者基于华为前沿开放能力及服务开发创新应用/产品的滚动式系列热点竞赛平台。大赛平台除了为开发者提供丰厚的奖金之外，还会提供能力接入的技术支持、创新应用/产品的营销推广，以及全球化的平台资源扶持，助力开发者加速实现业务发展。

截至2024年10月，平台已上线了16场赛事，共覆盖了170+国家和地区，报名人次超过5万，产出10000+创新成果，为开发者提供了3500万+奖励资源。

欢迎广大开发者关注并参与鸿蒙开发者大赛平台上的各项赛事。

## 3.生态扶持---10亿耀星计划

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260225111402.95715182132315669075364899657919:50001231000000:2800:72843100553B8A1F9C55C1D1C4E096CC48A1783D4827F1D062B9B22FA18E3EB1.png "点击放大")

"耀星计划"是华为于2017年底宣布启动的一项全球激励计划，基于10亿美元激励资源，持续面向全球激励开发者创新，携手共建鸿蒙生态。2024年1月耀星计划再升级，持续激励鸿蒙应用、元服务、SDK等领域创新：伴随着HarmonyOS NEXT鸿蒙星河版陆续开放，鸿蒙生态进一步加速，展现出蓬勃的发展态势。耀星计划面向接入开放能力、适配全场景终端体系、共建鸿蒙生态的创新开发者，提供覆盖应用开发商业化全生命周期的，面向开发创新、用户增长、商业推广、数字营销等多维度的激励和扶持。鸿蒙千帆起，未来持续与全球开发者携手，共建鸿蒙繁荣生态。

**耀星计划激励对象**

* 激励基于华为终端各项能力的开放创新：接入鸿蒙商业开放能力，包括广告商业能力、Push 商业能力、出境业务、AI 意图框架、华为支付、元服务等一项或者多项能力的应用； 接入鸿蒙全场景及创新能力，包括智慧车载、折叠屏、Pad、鸿蒙智能穿戴等多终端设备，为华为终端用户提供全场景智慧化生活体验。
* 激励助力华为终端构建鸿蒙商业生态 ：接入华为应用及服务分发体系的创新应用、创新游戏、信息流、音乐音频、教育等，基于鸿蒙商业生态合作，激励开发者创新升级，引领用户体验。
* 激励携手华为终端共建鸿蒙生态：激励与华为终端云服务共建生态，在生态建设、产品创新、关键技术引入、商业创新等方面有突出表现的云云共建、三方 SDK 等领域的合作伙伴。

在激励范围内的应用/产品均可至华为开发者联盟官网申请耀星计划扶持资源，华为终端云服务将每月进行一次作品评估，评估通过的作品即可获得资源扶持。

反馈建议请发送至耀星计划邮箱：[program@huawei.com](mailto:program@huawei.com)、[shiningstar1@huawei.com](mailto:shiningstar1@huawei.com)。

更多详情请见[耀星计划活动页](https://developer.huawei.com/consumer/cn/activity/yaoxingActivity/detail/617)。

## 4.社区运营---开发者互动

华为开发者社区是一个为开发者提供信息传播、开发交流、技术分享的交流空间。聚焦鸿蒙应用开发，助力开发者解决各类技术问题，开发者可以在社区分享开发经验，还可以在此获得最新行业资讯、技术干货、解决方案等信息。

活动信息可关注[官网活动版块](https://developer.huawei.com/consumer/cn/activity)。

论坛互动可关注[开发者联盟论坛版块](https://developer.huawei.com/consumer/cn/forum/)。
