# 个人开发者和企业开发者的区别

华为开发者联盟为开发者提供一站式应用开发、分发、运营及变现服务。注册并完成实名认证，是您开启这一切能力与服务的关键步骤。开发者需先[注册](https://id1.cloud.huawei.com/CAS/portal/userRegister/regbyemail.html)华为开发者联盟账号，并完成[实名认证](https://developer.huawei.com/consumer/cn/doc/start/itrna-0000001076878172)流程，方可使用更多联盟提供的功能与服务资源。开发者账号类型分为个人开发者和企业开发者类型。  
* [账号归属区别](https://developer.huawei.com/consumer/cn/doc/start/account-ownership-0000002497011337)  
* [账号服务与权益区别](https://developer.huawei.com/consumer/cn/doc/start/account-differences-0000002464051890)
