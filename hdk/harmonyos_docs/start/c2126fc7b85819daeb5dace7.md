# 创建账号组

1. 登录[华为开发者联盟官网](https://developer.huawei.com/consumer/cn/)，点击"管理中心 > 开发者中心 > 账号组"，进入账号组页面。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/73/v3/EOe6-D_jQIKxhEPrlq8bnQ/zh-cn_image_0000002470080129.png?HW-CC-KV=V1&HW-CC-Date=20261008T150911Z&HW-CC-Expire=31536000000&HW-CC-Sign=F279353F72A9CD6DF65E3A7DA2D2319FAEDCCAF66C4F9BE960736387F04503EF)


2. 点击"创建账号组"进入账号组创建页面。

   企业开发者：可创建关联主体账号组及联运服务账号组，关联主体账号组内的成员可享受该账号组内专享的跳转互通政策，联运服务账号组内的成员可享受联运服务的相关福利政策和活动。

   **关联主体账号组：**

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2f/v3/5UkHaewOQNavWkm_YZ0Z4g/zh-cn_image_0000002436570400.png?HW-CC-KV=V1&HW-CC-Date=20261008T150911Z&HW-CC-Expire=31536000000&HW-CC-Sign=9E41D00AD63E957E611134C9CBBE4B845C3013BE007045116CC38257DF086349)

   **联运服务账号组：**

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2/v3/9UXKlNy1Rt2t4gJFyqOhrg/zh-cn_image_0000002513308196.png?HW-CC-KV=V1&HW-CC-Date=20261008T150911Z&HW-CC-Expire=31536000000&HW-CC-Sign=54D7A7929774CEE5C92D7D681FC022F28F47B35762D2F0DC7514378A3423E1E7)

   个人开发者：可创建联运服务账号组，账号组内的成员可享受联运服务的相关福利政策和活动。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/19/v3/S79AfoZiRg-GDzl6MALJ-A/zh-cn_image_0000002470162301.png?HW-CC-KV=V1&HW-CC-Date=20261008T150911Z&HW-CC-Expire=31536000000&HW-CC-Sign=5FF65A29CD70501927AEECF4B55827ED2AC8A2F789A7EE6C4F856B633C2E6C2D)


3. 输入账号组名称，点击"提交"，账号组创建成功，当前账号成为该账号组的管理员账号。 注意
   >
   > 账号组一旦创建成功，组名不可修改。如修改组名，需要撤销账号组，并重新创建和邀请成员。
