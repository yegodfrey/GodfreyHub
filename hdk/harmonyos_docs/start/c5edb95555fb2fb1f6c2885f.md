# 报表

华为开发者联盟提供了应用服务和主题服务两类报表供开发者使用。您可以点击"管理中心 > 我的报表"进入报表页面，通过报表更好的管理您的APP。应用服务和主题服务对应的报表及报表可查看的内容如下：

|服务类型|报表名称|报表可查看的内容|
|:--------|:----------|:-----------------|
|应用服务 联运报表|应用市场报表|下载安装、新增留存等|
|应用服务 联运报表|支付报表|支付明细、优惠券明细等|
|应用服务 联运报表|账号报表|用户总数、新增用户数等|
|应用服务 联运报表|PUSH报表|PUSH用户详情、PUSH消息详情等|
|应用服务 联运报表|云文件夹报表|云文件夹下载报表、云文件夹推广报表|
|应用服务 联运报表|活动发放优化、新游预约|/|
|主题服务|主题报表|应用ID、应用单价、应用销售额等|
