# 企业资料人工审核认证

企业资料人工审核认证需要提供企业相关证件、法定代表人身份证证件或完成法定代表人人脸识别验证。如法定代表人验证方式选择"人脸识别"，不需要提供法定代表人身份证证件。

提交企业资料人工审核认证，选择不同的法定代表人验证方式，需要的资料如下：

* 上传法定代表人手持身份证：企业证件、法定代表人手持身份证正反面照片。
* 法定代表人人脸识别：企业证件、法定代表人人脸识别验证。

1. 点击头像下拉框中的"[去认证](https://developer.huawei.com/consumer/cn/verified/enrollment)"，进入"实名认证"页面。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202410.92347651086503922206191544766800:50001231000000:2800:A49F4C3A29BC1486F8EEAAC045B86BAF17458BCC5DAED0D46DF9BB638A58F1DA.png)


2. 点击"企业开发者"图标或"下一步"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202410.05340949062141537630819309556321:50001231000000:2800:2DCF4FF0E123E0855207AECF28339C8797EF8A0883F99C4A82A60675DCB752ED.png "点击放大")


3. 如需上架的应用是非敏感应用，可选择对公银行打款认证或企业资料人工审核认证的其中一种认证方式进行认证。如您后续需上架的应用是敏感应用，建议您在此步骤即优先选择对公银行打款认证方式进行实名认证，以免后续上架敏感应用再次触发打款验证。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202410.07952944574484898765717524042938:50001231000000:2800:688BC4BFA0E9F21C2B939CBECD2AC64BDFEE1AED716811FEE61192C7ACD3145A.png "点击放大")


4. 选择企业资料人工审核认证，进入到人工审核认证页面。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202410.42109251310733550648723885968378:50001231000000:2800:E7CDA483245B35DBB3589F7790E83828E92AA1F1B4564085D4EE5A00393B3B71.png "点击放大")


5. 根据页面提示，上传企业证件、核对/填写企业信息及法定代表人信息（上传法定代表人手持身份证正反面照片或通过法定代表人人脸验证）。签署[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/start/agreement-0000001052728169)，点击"下一步"完成提交，审核结果会在1-2个工作日发送至联系人邮箱。
