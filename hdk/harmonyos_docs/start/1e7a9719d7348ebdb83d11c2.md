# 账号停用及申诉流程

## 目的和范围

为共建良好平台生态，提升用户体验及保证开发者利益，我们可能会对违反华为平台协议及规则或存在其他问题的开发者账号采取相应的处理措施，以便您更规范地使用开发者账号和了解当您对处理有异议时的申诉方式。

以下规则适用于所有在华为开发者联盟提交认证的开发者账号。

## 账号处理原因和措施

|违规类别|违规行为|账号处理措施|
|:--------|:----------------------------------------------------------|:--------------------|
|虚假信息|开发者存在提供虚假信息、盗用他人资质等干扰平台审核、存在安全风险的行为。|停用|
|认证主体状态异常|开发者账号的认证主体被列入严重违法失信企业名单，营业执照的经营状态为注销、吊销。|停用|
|联系信息无效|开发者账号联系电话空号、停机，且未提供联系邮箱； 开发者账号联系邮箱无效。|停用|
|联系信息异常|开发者账号联系电话累计呼叫3次联系不上（如关机、无人接听等）。|发送整改通知，如5个工作日内未整改则停用|
|认证资质不符合要求|不符合资质要求或资质过期未更新。如企业证件过期、企业名称变更、企业主体不一致、未提供法定代表人证件等。|发送整改通知，如10个工作日内未整改则停用|
|其他|开发者利用账号恶意攻击华为开放平台。|停用|
|其他|不同开发者账号的法定代表人存在密切关联，或公司性质非母公司、子公司或兄弟公司等关联公司，进行批量注册数量达2个及以上。|停用|
|其他|其它违反法律法规和监管要求或经认定可能会对用户或其它开发者的利益造成损害的行为。|视情况严重程度处理|

> 说明
>
> 若适用的法律法规或监管政策对于以上违规场景有更为严厉的监管要求或处理措施，以适用的法律法规为准。

## 处理措施说明

对于违反华为平台协议及规则或存在其他问题的开发者账号，华为开发者联盟有权单方视情节轻重调整处理措施。处理措施包括但不限于如下内容：

1. 限期整改：华为向开发者发送整改通知电子邮件。开发者应在通知提及的限定期限内，对账号的认证信息进行整改与更新，逾期未整改账号将被停用。
2. 开发者账号停用：华为停用开发者在华为开发者联盟注册的账号，该账号无法使用华为服务。

## 处理措施执行

1. 华为开发者联盟在发现开发者存在违法违规或违反协议条款的行为后，会第一时间发送整改通知或停用开发者账号等处理，并通过电子邮件通知开发者。
2. 对于停用的开发者账号，不再支持用同一主体认证新账号（如有异议，请发邮件至[devConnect@huawei.com](mailto:devConnect@huawei.com) 进行申诉）。
3. 开发者在收到处理措施通知后，如有疑问，可通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)进行反馈。
4. 华为开发者联盟有权根据账号问题严重程度，进行处理措施调整，包括但不限于缩短整改期限、停用账号或其他加严处理措施等。
5. 对于本规则未能涵盖的其他任何违法违规行为，由华为开发者联盟根据严重及影响程度，采取包括但不限于通知整改、停用开发者账号、下架产品以及其他华为开发者联盟认为适合的处理措施。

## 申诉流程

1. 定义：开发者对于账号的处理措施有异议并可自证不存在违规行为。
2. 申诉方式： 企业开发者：

   可通过[账号停用申诉](https://developer.huawei.com/consumer/cn/verified/accountActivation)进行企业资质（包括企业营业执照照片或扫描件及法定代表人身份证正反面照片）和申诉及承诺函进行在线提交；如您的账号无法登录发起在线申诉，可提供企业营业执照照片或扫描件、法定代表人身份证正反面照片和[申诉承诺函](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260910153402.76970944311899538429206691138790:50001231000000:2800:79730F25254A905C1C03407EC3C191F6181446812E8D4FC697471C69D15F4EC5.zip?needInitFileName=true)发邮件至[devConnect@huawei.com](mailto:devConnect@huawei.com) 进行申诉（申诉材料请以.pdf、.xlsx、.png、.jpg、.jpeg等格式以普通附件形式通过邮件发送，请勿压缩或使用超大附件、云附件等其他附件形式提供）。

   个人开发者：

   可提供您的身份证正反面照片、手持身份证头像面照片及[申诉承诺函](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260910153402.14417291150261893736226551564718:50001231000000:2800:36D1689C914A1B10D67A64314BAA68C18C566585276FB4B342586398EF0E41B2.zip?needInitFileName=true)发邮件至[devConnect@huawei.com](mailto:devConnect@huawei.com) 进行申诉（申诉材料请以.pdf、.xlsx、.png、.jpg、.jpeg等格式以普通附件形式通过邮件发送，请勿压缩或使用超大附件、云附件等其他附件形式提供）。
3. 处理结果通知：处理结果将通过电子邮件方式进行告知。

## 生效及解释

1. 本规则自发布之日起生效。
2. 账号的处理的相关信息可能会通过管理中心消息系统、开发者在华为开发者联盟平台注册认证时填写的电子邮箱或其他合理的方式进行通知，此类通知在发送时即视为已送达收件人。开发者需确保所提供的电子邮箱等信息是真实、有效的，并且未设置过滤规则，否则可能导致您无法及时收到相应的通知，因此造成的一切责任由开发者自行承担。
3. 华为开发者联盟有权在必要时修改本规则修改后的规则内容将公布于开放平台，本规则一经公布即生效，请开发者定期关注华为开发者联盟网站。

如您对本规则有任何疑问，可以通过以下方式联系华为开发者联盟：通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)或发邮件至 [devConnect@huawei.com](mailto:devConnect@huawei.com) 咨询。
