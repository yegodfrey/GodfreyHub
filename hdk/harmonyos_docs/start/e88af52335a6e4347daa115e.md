# 华为开发者商户服务协议

点击查看：[协议变更点](https://developer.huawei.com/consumer/cn/doc/agreement-changes)

下载查看：[《华为开发者商户服务协议》](https://terms-drcn.platform.dbankcloud.cn/agreementservice/developer/getAgreementTemplate?agrType=1003&country=cn&language=zh_cn&version=2026031101)

更新日期：2026年03月11日

本协议是您（以下又称"开发者"）与华为订立的具备法律效力的协议，以便您使用本协议下的商户服务通过华为平台向最终用户（下称"用户"）提供付费产品或获取变现收益。本协议为您与华为订立的[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/start/agreement-0000001052728169)的补充协议，与其共同确立您在使用本协议下的服务时的享有的权利和负有的义务。点击本协议页面下方的"我同意"按键或使用本协议下任何服务即视为自您接受、使用之日（"生效日期"）起对本协议的充分理解和完全接受。如果您不同意本协议，您应当停止使用本协议下的服务。

本协议未尽事宜，按照[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/start/agreement-0000001052728169)执行。如本协议条款与[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/start/agreement-0000001052728169)条款存在任何不一致之处，仅与商户服务相关的不一致之处以本协议条款为准。

## 1. 定义

除非本协议另有规定，否则本协议中的术语与[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/start/agreement-0000001052728169)中的术语意义相同。下列术语在本协议中的含义为：

1.1"**商户服务**"：华为向开发者提供的、让开发者通过华为平台提供联运付费产品或其他合作付费产品，或让开发者获取变现收益的华为服务。商户服务包括但不限于联运服务、鲸鸿动能服务和AGD Pro服务。

1.2"**付费产品**"：用户需付费才能使用的产品，包括但不限于付费下载产品、应用内购买产品或其它付费数字内容产品。

1.3"**联运付费产品**"：指开发者通过联运服务提供的付费产品。

1.4"**联运服务**"：是指华为和开发者为将产品通过华为平台分发而进行的合作及各自的相关行为。华为的行为包括提供应用市场平台能力接入、数据报表、活动运营、用户运营等一系列服务。

1.5"**鲸鸿动能服务**"：指华为通过鲸鸿动能服务平台向开发者提供的、在开发者的产品中进行广告展示或信息推广进而使开发者获取变现收益的服务。

1.6"**付费下载产品**"：是指用户需要支付一定金额以后，才可以下载及使用的产品。

1.7"**应用内购买产品**"：是指用户安装应用软件后，在使用应用的过程中，通过支付一定金额购买的应用内的数字内容、高级功能、订阅服务或其他增值服务。用户的支付行为在应用内产生。

1.8"**华为AppGallery应用变现服务** "或"**AGD Pro服务**"：指华为通过华为AppGallery应用变现服务平台向开发者提供的、在开发者的产品中投放应用下载或应用促活任务，从而使开发者获取变现收益的服务。

1.9"**定价**"：指您从华为提供的价格段列表中自行选择的价格。

1.10"**价格段**"：指华为在华为平台为产品销售制定的价格段。

1.11"**收款账户**"：是指开发者在其指定的金融机构开立的的存款账户，此账户开立于开发者注册国家/地区内，能通过电汇或其他电子转账形式（统称为"电子转账"）收取付款交易处理过程中的款项。

1.12"**付款交易**"：指通过商户服务处理用户购买联运付费产品或进行广告展示或信息推广的付款，并将结算款（定义见第4条）汇入开发者的收款账户。

1.13"**付款处理方**"：华为授权的向开发者提供商户结算服务的实体，通过其服务，有华为商户号的开发者可收取联运付费产品和其他合作付费产品的费用、通过鲸鸿动能服务获取的变现收益、通过AGD Pro服务获取的变现收益（合称"收入"）。

1.14"**华为商户号** "或"**商户号**"：由付款处理方分配给开发者的财务账号，与您的开发者账号（华为账号）及您开通商户服务时提交的银行账号相关联；开发者授权付款处理方通过此账号代为收取和转汇通过商户服务获得的收入。

## 2. 付费服务与付费服务账户

2.1定价

2.1.1如您使用联运服务向用户提供联运付费产品，则您选择提供的联运付费产品将以您设置的定价提供给用户。默认您设置的定价包含扣缴增值税（"VAT"）、商品与服务税（"GST"）、服务税（"Service Tax"）、销售税（"Sales Tax"）及其它适用的间接税及附加税（以下统称为"间接税"）、数字服务税（"Digital Service Tax"）和用户预提税等按照相关税法要求涉及的各项税费。您设置的定价将适用于您选择销售该等联运付费产品的所有国家和地区。按照《华为开发者服务协议》，如果您是与于中华人民共和国成立的深圳市华为思义技术有限公司签约，且业务分发区域为俄罗斯，则默认您设置的定价不含中国增值税（如涉及），您与华为将按照第4.1条进行结算分成。

开发者只能使用联运服务处理用户通过合法真实的商品销售购买联运付费产品的付款交易。

2.1.2如您使用鲸鸿动能服务获取变现收益，则您与华为将按照第4.2条进行结算分成。

2.1.3如您使用AGD Pro服务获取变现收益，则您与华为将按照第4.3条进行结算分成。

2.2支付渠道

您使用联运服务向用户提供联运付费产品时，所有支付渠道（含话费渠道）将默认开通。（所有支付渠道及对应费用信息详见附件B）。

2.3为了您可以通过使用商户服务获得收入，您必须根据另行与付款处理方达成的《华为支付商户服务协议（开发者联盟）》获得有效的商户号，由付款处理方批准您使用商户号，并维持该账号的良好信誉。

## 3. 税务与发票

华为和您各自承担税法要求各自应承担的相关税费。如您选择通过联运服务向用户提供联运付费产品、使用鲸鸿动能服务或AGD Pro服务获取变现收益，则遵循如下税务条款约定：

3.1间接税

3.1.1针对联运付费产品，华为将对用户就购买联运付费产品向华为支付的款项按照附件C扣缴间接税，除非华为认定用户在使用话费支付时运营商已经缴纳间接税，或根据部分国家和地区法律法规的规定，华为不被认定为纳税义务人。

3.1.2华为向您支付的分成收入为含税价。若适用法律要求华为向您支付的任何款项需代扣缴增值税及附加税，该税款将从您的分成收入中进行扣减。若华为认为前述税款到期应缴，则华为将向相关主管部门代扣代缴全额税款。按照《华为开发者服务协议》，如果您是与于中华人民共和国成立的深圳市华为思义技术有限公司签约，且业务分发区域为俄罗斯，向您支付的所有费用不包含中国增值税（如涉及）。如涉及代扣中国增值税，则由华为承担。

3.2直接税

3.2.1用户预提税：若用户向华为支付的款项需缴纳预提税或类似的税款，华为将承担此类税款，尽管存在前述规定，华为保留在计算结算款（定义见下）时从结算款中扣除前述预提税的权利。

3.2.2若当地法律要求华为向您支付的任何款项需缴纳预提税及附加税，您将承担全额税款。若华为认为前述税款到期应缴，则华为将向相关主管部门代扣代缴全额税款。若您在华为向相关主管部门缴纳预提税之前（保证有充足的时间来执行优惠税率）向华为提供相关信息及材料证明您有权享受适用的所得税条约或当地法律中规定的优惠税率，则华为将根据该优惠税率支付折算后的预提税（若有适用的所得税条约或因其它原因使其可行）。在您要求时，华为将向您出具代缴预提税的证明（可能包括预提税凭证）。

3.2.3若您所在的国家法律要求华为提供的平台服务需要缴纳预提税及附加税，您有义务代扣代缴预提税。您应该向相关税务机关申报和支付预提税及附加税，并向华为出具代缴预提税及附加税的证明，向华为申请补偿。**若您应代扣未代扣而使得您或者华为被税务机关要求补税，**则您应负责承担并支付此类代扣税，以及由相关税务机关征收的任何附加费、滞纳金、利息及罚款等。

3.3除前两项所述的间接税和预提税外，若适用法律要求华为向您支付的任何款项需代扣缴其他税费，该税款将从您的分成收入中进行扣减。如根据中国税法规定（适用于中国大陆地区，不包含港澳台区域），个人开发者的产品或服务分发到中国大陆的情形，个人开发者的收入需由华为代扣个人所得税。

请参见附件C，获悉您需要缴纳的税金及履行您的纳税义务的详细信息。请参见附件F，获悉华为代扣代缴税款的信息。

3.4除前三项所述的间接税、预提税和华为代扣缴其他税费外，任何其它所得税、营业税、房产税或其它任何基于您的业务收入而产生的类似纳税义务，您将自行承担，负责申报和缴纳。

在本协议有效期内，若任何税种的税率发生增减调整、税种被废除、新税种生效，或对该等税种的解释或适用方式发生任何变更，则应对本协议条款作出公平调整以应对上述变更，确保双方均免受不利的财务影响，且该调整（如有）须经双方协商一致确认。

（6）若依照法律华为支付给您的RSRA余额需要缴纳增值税、预提税或其它税款，华为将在付款前直接扣除相应金额。
