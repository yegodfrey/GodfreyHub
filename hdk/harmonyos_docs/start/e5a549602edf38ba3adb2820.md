# 团队账号

> 说明
>
> **1、团队账号能力仅针对2023年之前，以企业账号申请卖家身份的生态市场合作伙伴。**
>
> **2、认证为商户的卖家，暂不能使用，有任何疑问可咨询：partner@huawei.com**

卖家可以添加多个团队成员账号，并对所有成员账号进行角色权限管理，帮助企业共同协作完成运营、财务、客服等工作。

1. 进入[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)，在左侧菜单栏找到"团队账号管理"。
2. 点击"配置团队账号"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c6/v3/wXc08fUzTnGfLLJ6Fgrz0g/zh-cn_image_0000001328314612.png?HW-CC-KV=V1&HW-CC-Date=20260909T170712Z&HW-CC-Expire=31536000000&HW-CC-Sign=6B58F270A50AF6DBDE239F545702A4F1B1374E0F67DC25159A9ACAA0A6BA5AB5 "点击放大")


3. 点击右上角"添加成员账号"。可对名下成员账号进行编辑或删除。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f2/v3/Cw2kqpwPRjKwk44bfa1I2Q/zh-cn_image_0000001328475352.png?HW-CC-KV=V1&HW-CC-Date=20260909T170712Z&HW-CC-Expire=31536000000&HW-CC-Sign=3D441829B94C4EB9DF3835AEE347AF67017FF7B1B43849ADFA4A6F48810FCD86 "点击放大")


4. 按照提示添加成员账号信息，点击"下一步"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/17/v3/b_Lky4DTQKeQRsfTg9YiXQ/zh-cn_image_0000001379635873.png?HW-CC-KV=V1&HW-CC-Date=20260909T170712Z&HW-CC-Expire=31536000000&HW-CC-Sign=81EBC3AE293237B9E70B4E22680C0991093F61D529604D8B55267BA66D52F7F5 "点击放大")


5. 设置角色与应用，下滑找到"生态市场"，支持创建"卖家管理员"、"客服"两种角色，支持角色多选。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cc/v3/R58_r05_QMO-cgOes4mxgA/zh-cn_image_0000001328476216.png?HW-CC-KV=V1&HW-CC-Date=20260909T170712Z&HW-CC-Expire=31536000000&HW-CC-Sign=138756CDBD78E52257C3FAB1885F10879D2D69EF24B781E572F35A140EF7B8D5 "点击放大")

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/37/v3/m0horHjgTi-0n_N2OtNG8g/zh-cn_image_0000001328636360.png?HW-CC-KV=V1&HW-CC-Date=20260909T170712Z&HW-CC-Expire=31536000000&HW-CC-Sign=DF76D0E86D599BECBB584DBF064C32077BAA5C36346D8067B405185F354B35CE "点击放大")
   > 说明
   >
   > "卖家管理员"的权限包括"客服"的所有权限。


6. 确认账号信息与权限。"提交"即创建成功。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/37/v3/rYSTfQV4SP2NAA1Cep4MPg/zh-cn_image_0000001328637204.png?HW-CC-KV=V1&HW-CC-Date=20260909T170712Z&HW-CC-Expire=31536000000&HW-CC-Sign=22EAFB86F8E07D67B9C91652E8D42AF98AEF64167C2A97421E3BA74B842C459B "点击放大")


7. 在创建团队账号时填写的"联系邮箱"将收到激活提醒邮件。 具体使用及团队账号相关FAQ可查看[开发者联盟团队账号使用指导](https://developer.huawei.com/consumer/cn/doc/start/maug-0000001058696103)。激活后的账号可直接用于生态市场登录。
