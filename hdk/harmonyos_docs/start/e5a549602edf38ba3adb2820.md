# 团队账号

> 说明
>
> **1、团队账号能力仅针对2023年之前，以企业账号申请卖家身份的生态市场合作伙伴。**
>
> **2、认证为商户的卖家，暂不能使用，有任何疑问可咨询：partner@huawei.com**

卖家可以添加多个团队成员账号，并对所有成员账号进行角色权限管理，帮助企业共同协作完成运营、财务、客服等工作。

1. 进入[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)，在左侧菜单栏找到"团队账号管理"。
2. 点击"配置团队账号"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c6/v3/wXc08fUzTnGfLLJ6Fgrz0g/zh-cn_image_0000001328314612.png?HW-CC-KV=V1&HW-CC-Date=20261008T180600Z&HW-CC-Expire=31536000000&HW-CC-Sign=78A89D95858230F2CF93DB8DE23956ECE3307F111342A77489AA20A3EFA7DC75 "点击放大")


3. 点击右上角"添加成员账号"。可对名下成员账号进行编辑或删除。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f2/v3/Cw2kqpwPRjKwk44bfa1I2Q/zh-cn_image_0000001328475352.png?HW-CC-KV=V1&HW-CC-Date=20261008T180600Z&HW-CC-Expire=31536000000&HW-CC-Sign=575BDAE6BC6AB98F428E2009014B35DF6BE95E0006F5B53A6DAF9AAF3727DB6B "点击放大")


4. 按照提示添加成员账号信息，点击"下一步"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/17/v3/b_Lky4DTQKeQRsfTg9YiXQ/zh-cn_image_0000001379635873.png?HW-CC-KV=V1&HW-CC-Date=20261008T180600Z&HW-CC-Expire=31536000000&HW-CC-Sign=C5F05218EA186C8FCB26BEDFC554BC716C3B4AA40C489FABF3FC791947AC5D59 "点击放大")


5. 设置角色与应用，下滑找到"生态市场"，支持创建"卖家管理员"、"客服"两种角色，支持角色多选。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cc/v3/R58_r05_QMO-cgOes4mxgA/zh-cn_image_0000001328476216.png?HW-CC-KV=V1&HW-CC-Date=20261008T180600Z&HW-CC-Expire=31536000000&HW-CC-Sign=F12B0F9C7704B59A178834BA367FD5D1D3D52C5229A2E2A97F875DADDE6B1885 "点击放大")

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/37/v3/m0horHjgTi-0n_N2OtNG8g/zh-cn_image_0000001328636360.png?HW-CC-KV=V1&HW-CC-Date=20261008T180600Z&HW-CC-Expire=31536000000&HW-CC-Sign=CEF9FDE825DCBA652787DFBC5BE6DFF7D1DC05AAE5DCAA018CC37C0FFAD8BB32 "点击放大")
   > 说明
   >
   > "卖家管理员"的权限包括"客服"的所有权限。


6. 确认账号信息与权限。"提交"即创建成功。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/37/v3/rYSTfQV4SP2NAA1Cep4MPg/zh-cn_image_0000001328637204.png?HW-CC-KV=V1&HW-CC-Date=20261008T180600Z&HW-CC-Expire=31536000000&HW-CC-Sign=7EC73EB1DDB04EA5F96DBEE50BB0E0B8DDE6CF3A7A6F3AF1A846E0D63A8DC0CA "点击放大")


7. 在创建团队账号时填写的"联系邮箱"将收到激活提醒邮件。 具体使用及团队账号相关FAQ可查看[开发者联盟团队账号使用指导](https://developer.huawei.com/consumer/cn/doc/start/maug-0000001058696103)。激活后的账号可直接用于生态市场登录。
