# 团队账号

![](https://media:401788750484279912)  
1、团队账号能力仅针对2023年之前，以企业账号申请卖家身份的生态市场合作伙伴。

2、认证为商户的卖家，暂不能使用，有任何疑问可咨询：partner@huawei.com

<br />

卖家可以添加多个团队成员账号，并对所有成员账号进行角色权限管理，帮助企业共同协作完成运营、财务、客服等工作。

1. 进入[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)，在左侧菜单栏找到"团队账号管理"。
2. 点击"配置团队账号"。 ![](https://media:401788750484470913 "点击放大")

<!-- -->

3. 点击右上角"添加成员账号"。可对名下成员账号进行编辑或删除。 ![](https://media:401788750484522914 "点击放大")

<!-- -->

4. 按照提示添加成员账号信息，点击"下一步"。 ![](https://media:401788750484589915 "点击放大")

<!-- -->

5. 设置角色与应用，下滑找到"生态市场"，支持创建"卖家管理员"、"客服"两种角色，支持角色多选。 ![](https://media:401788750484625916 "点击放大")

   ![](https://media:401788750484681917 "点击放大")  
   ![](https://media:401788750484711918)  
   "卖家管理员"的权限包括"客服"的所有权限。

<!-- -->

6. 确认账号信息与权限。"提交"即创建成功。 ![](https://media:401788750484800919 "点击放大")

<!-- -->

7. 在创建团队账号时填写的"联系邮箱"将收到激活提醒邮件。 具体使用及团队账号相关FAQ可查看[开发者联盟团队账号使用指导](https://developer.huawei.com/consumer/cn/doc/start/maug-0000001058696103)。激活后的账号可直接用于生态市场登录。
