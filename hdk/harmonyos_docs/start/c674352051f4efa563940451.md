# 小程序转换元服务

插件支持将微信/支付宝/Taro/uni-app小程序转换为ASCF元服务，大大减少重复性适配工作，降低入驻鸿蒙生态的成本。转换后，您还可以通过对话将元服务直接推送至真机或者模拟器上运行，并完成编译打包。此外，插件面板还提供上架自检入口，方便您快速自查软件包问题，提高上架审核通过率。

## 前提条件

* 已[登录插件](https://developer.huawei.com/consumer/cn/doc/start/hosdevassistant-login-0000002588351354)。
* 已[完成插件的配置](https://developer.huawei.com/consumer/cn/doc/start/hosdevassistant-config-0000002588511280)。
* 如果需要运行到模拟器上，确保DevEco Studio已安装所需版本的模拟器。

## 转换元服务

本章节以VS Code为例描述如何将小程序转换为元服务，在其他IDE上操作类似。

### 转换元服务工程

1. 在VS Code中打开**待转换工程的上一级目录** 。

   例如，待转换工程为"xiaochengxu"，则打开其上级目录"project"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9e/v3/kdFYjFVTS3Wu7n1TdSfpJQ/zh-cn_image_0000002759758595.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=E8309CC2D199DCB0CA2E5A4DB5876AE4554C33D221D1D1BA525774CD8A9E03C7)
2. 进入插件界面，在左下角切换模式为"元服务转换"，在对话框中输入类似下述提示语：当前是一个XXX小程序，帮我转换为ASCF元服务工程。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/97/v3/fkWThrKeSnaFZ_f8VRSY_w/zh-cn_image_0000002772885631.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=F6FF08C0CED2E379A1651CE36E8CCC10A3670022807EB838B0D5B4CD4E77FBA9)

3. 等待"待办清单"中各任务的执行完成。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/70/v3/1NrdAz4DQWK2JjW6v2OxJQ/zh-cn_image_0000002772756331.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=C2E29FFE815502EB54BE2228F470D5DC4626E308985190C394CD41EA5532CBBA)

### 会话中关联元服务并配置签名

元服务构建编译过程中，插件会自动引导您进行签名配置。

1. 如当前元服务工程尚未与AGC上的元服务关联，则对话框会先弹出关联元服务卡片。
   * 如AGC已存在待关联的元服务，选择元服务所属的团队以及元服务名称，点击"提交"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/93/v3/JElbdGO-TfiDODQROHXmaQ/zh-cn_image_0000002745184566.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=F805C3F564A924FE39EC60603EBDAD6A3D94B5339440F730B69CF17ABE5DCF77)

   * 如需新建一个元服务进行关联，点击"新建应用"页签，选择团队、应用类型、应用名称和分类、项目，点击"提交"，新建应用成功且自动与当前元服务工程关联。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/74/v3/a9qWHZLCQaaPeA7rw83mEA/zh-cn_image_0000002774783613.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=27F0C730D515BECA9116A400A2B2AF862F6450D5C55338CE864C0C752C19EF01)

   > 说明
   >
   > 插件当前也支持您[在工具面板关联应用](#section817914331914)。
2. 元服务关联成功后，插件会与您确认配置的签名类型（调试签名/发布签名）。
   * 如后续需将元服务推送至真机运行调试，建议选择"调试签名"，插件将为元服务配置调试签名。 注意
     >
     > PC必须连接真机后才可配置调试签名。
   * 如后续计划直接打包元服务进行发布上架，建议选择"发布签名"，插件将为元服务配置发布签名。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/55/v3/6P3NGUctQwKvphM2ItrY0Q/zh-cn_image_0000002745184856.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=205CE892D8CFF1BAC944BCAB503C81ECB93D49DB7C6F34EFAE314F5D4148ABA9)

## 在真机上运行元服务

1. 确保真机已与PC连接，且真机上已安装ASCF引擎（在负一屏或华为应用市场搜索"元服务ASCF示例"，点击运行，系统会自动安装）。
2. 确保元服务已配置调试签名。

   如未完成，可在对话框中输入"帮我创建调试签名"的提示语，插件将快速帮您完成签名配置，具体流程可参见[会话中关联元服务并配置签名](#section8973741143918)。 说明
   >
   > 插件当前也支持您[在工具面板配置签名](#section139016181214)。
3. 在对话框中输入类似下述提示词：已完成签名，帮我运行到真机上。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bc/v3/lvlkdUZoTdydcufO2soVRA/zh-cn_image_0000002743368514.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=FF97CC05E446CAA646E2DBBEC44A426C152F82B32A91A59D0708387BD49F3D97)
4. 插件将元服务推送到连接的真机上运行。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/93/v3/vtbo1VF5SUGxCNzn5DQvyg/zh-cn_image_0000002772916611.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=9689C342B89CD3AB57A42FBC03463F3693FBFF1EB907B95AF5482596C20FE321)

   >
   > 插件当前也支持您[在工具面板配置签名](#section139016181214)。
2. 在插件对话框中输入类似下述提示语：帮我打包用于最终上架。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/49/v3/qERFRMVOT468YrpcAK8kEg/zh-cn_image_0000002714979001.png?HW-CC-KV=V1&HW-CC-Date=20261009T034830Z&HW-CC-Expire=31536000000&HW-CC-Sign=BB69ED56806E7E24D4ADFCA9DA373685EEA007FA114C8D35C01EE25F4ED4E7E8)

>
> 使用关联应用功能前，请确保当前打开的项目工程为HarmonyOS工程。（注：HBuilderX中可为uni-app工程）
