# 小程序转换元服务

插件支持将微信/支付宝小程序转换为ASCF元服务，或者将uni-app小程序转换为鸿蒙元服务，大大减少重复性适配工作，降低入驻鸿蒙生态的成本。转换后，您还可以通过对话将元服务直接推送至真机或者模拟器上运行，并完成编译打包。此外，插件面板还提供上架自检入口，方便您快速自查软件包问题，提高上架审核通过率。  

#### 前提条件

* 已[登录插件](https://developer.huawei.com/consumer/cn/doc/start/hosdevassistant-login-0000002588351354)。
* 已[完成插件的配置](https://developer.huawei.com/consumer/cn/doc/start/hosdevassistant-config-0000002588511280)。
* 如果需要运行到模拟器上，确保DevEco Studio已安装所需要版本的模拟器。  

#### 转换元服务

本章节以VS Code为例描述如何将小程序转换为元服务，在其他IDE上操作类似。

1. 在VS Code中打开待转换工程的上一级目录。 例如，待转换工程为"xiaochengxu"，则打开其上级目录"project"。

   ![](https://media:901788320227679061)
2. 进入插件界面，在左下角切换模式为"元服务转换"，在对话框中输入类似下述提示语：当前是一个XXX小程序，帮我转换为ASCF元服务工程。 ![](https://media:901788320227753062)

3. 等待"待办清单"中各任务的执行完成。 ![](https://media:901788320227810063 "点击放大")

4. 元服务构建编译过程中，插件会自动引导您进行签名配置。
   1. 如当前元服务工程尚未与AGC上的元服务关联，则对话框会先弹出关联元服务卡片。
      * 如AGC已存在待关联的元服务，选择元服务所属的团队以及元服务名称，点击"提交"。
      * 如需新建一个元服务进行关联，点击"创建元服务"，插件将拉起AGC控制台页面，参考[关联新建的元服务](#section3351552018)的步骤4-7创建元服务后，返回插件对话框选择创建的元服务即可。

      ![](https://media:901788320227836064)  
      插件当前也支持您[在工具面板关联元服务](#section817914331914)。

      ![](https://media:901788320227876065)

      <br />

   2. 元服务关联成功后，插件会与您确认配置的签名类型（调试签名/发布签名）。
      * 如后续需将元服务推送至真机运行调试，建议选择"调试签名"，插件将为元服务配置调试签名。  
        ![](https://media:901788320227904066)  
        PC必须连接真机后才可配置调试签名。
      * 如后续计划直接打包元服务进行发布上架，建议选择"发布签名"，插件将为元服务配置发布签名。

![](https://media:901788320227951067)  

#### 在模拟器上运行元服务

1. 在插件对话框中输入类似下述提示词：将包推送到模拟器上运行调试。 ![](https://media:901788320228008068 "点击放大")

2. 插件将拉起DevEco Studio中的模拟器运行元服务。 ![](https://media:901788320228094069 "点击放大")

#### 在真机上运行元服务

1. 确保真机已与PC连接，且真机上已安装ASCF引擎（在负一屏或华为应用市场搜索"元服务ASCF示例"，点击运行，系统会自动安装）。
2. 确保元服务已配置调试签名。  
   如未完成，可在对话框中输入"帮我创建调试签名"的提示语，插件将快速帮您完成签名配置，具体流程可参见[转换元服务-步骤4](#ZH-CN_TOPIC_0000002688719389__li5964015703)。  
   ![](https://media:901788320228121070)  
   插件当前也支持您[在工具面板手动配置签名](#section139016181214)，但强烈建议您使用插件自动帮您配置签名。
3. 在对话框中输入类似下述提示词：已完成签名，帮我运行到真机上。 ![](https://media:901788320228171071)

4. 插件将元服务推送到连接的真机上运行。 ![](https://media:901788320228236072)

#### 上架自检

1. 确保元服务已配置发布签名。  
   如未完成，可在对话框中输入"帮我创建发布签名"的提示语，插件将快速帮您完成签名配置，具体流程可参见[转换元服务-步骤4](#ZH-CN_TOPIC_0000002688719389__li5964015703)。  
   ![](https://media:901788320228263073)  
   插件当前也支持您[在工具面板手动配置签名](#section139016181214)，但强烈建议您使用插件自动帮您配置签名。
2. 在插件对话框中输入类似下述提示语：帮我打包用于最终上架。 ![](https://media:901788320228317074)

3. 等待"待办清单"中各任务的执行完成。 ![](https://media:901788320228360075)

4. 进入资源管理器界面，在"build \> outputs"目录下获取带签名的元服务软件包。 ![](https://media:901788320228410076)

5. 打开插件配置界面，在"关联元服务"页签的"上架自检"区域，点击文件选择按钮。 ![](https://media:901788320228441077)

6. 选择刚刚编译生成的带签名的元服务软件包，点击"提交自检"。 ![](https://media:901788320228475078)

7. 等待自检结果。 ![](https://media:901788320228508079)

8. 报告生成后，点击"报告"可查看详细信息。 ![](https://media:901788320228541080)

#### （可选）在工具面板关联元服务

您可以在插件配置页面，将生成的元服务工程与AGC上的元服务关联，支持关联已有的元服务，或者新建一个元服务进行关联。  
![](https://media:901788320228667081)  
使用关联元服务功能前，请确保当前打开的项目工程为HarmonyOS工程。（注：HbuilderX中可为uni-app工程）  

#### 关联已有的元服务

1. 点击插件右上角设置按钮。 ![](https://media:901788320228771082)

2. 在"关联元服务"页签，点击"关联元服务"。 ![](https://media:901788320228809083)

3. 选择AGC上元服务所属的团队以及元服务名称，点击"关联"。 ![](https://media:901788320228841084)

4. 元服务成功关联后，"当前元服务"区域将展示元服务的详细信息。 ![](https://media:901788320228878085)

#### 关联新建的元服务

1. 点击插件右上角设置按钮。 ![](https://media:901788320228915086)

2. 在"关联元服务"页签，点击"关联元服务"。 ![](https://media:901788320228951087)

3. 点击"创建元服务"，浏览器将打开AGC控制台页面。 ![](https://media:901788320228980088)

   <br />

4. 在"应用开发基础信息"页面，填写待创建的元服务名称，分类仅支持选择"应用"，完成后点击"下一步"。 ![](https://media:901788320229024089)

5. 进入"所属项目信息"页面，为元服务选择所属的项目后，点击"下一步"。
   * 如需将元服务添加到已有项目，点击下拉框进行选择。
   * 如需将元服务添加到新项目，直接在框中填写新项目名称。

   ![](https://media:901788320229071090)
6. 进入"云开发数据处理位置"页面，设置或管理项目的数据处理位置。
   * 如项目尚未设置数据处理位置：
     1. 点击"启用"。 ![](https://media:901788320229101091)

        <br />

     2. 在"启用"栏为您的项目勾选一个或多个数据处理位置，并在"设为默认"栏将其中一个设置为默认数据处理位置。 ![](https://media:901788320229147092)

        <br />

   * 如项目已设置过数据处理位置，可点击"管理"启用新的数据处理位置、取消已启用的数据处理位置，或修改默认数据处理位置。 ![](https://media:901788320229187093)

     <br />

7. 点击"确认"，元服务创建完成。 ![](https://media:901788320229222094)

8. 返回HarmonyOS开发助手界面，点击"关联元服务"，选择正确的团队和刚刚创建的元服务，点击"关联"。 ![](https://media:901788320229268095)

9. 界面展示元服务的详细信息，表示元服务已成功关联。 ![](https://media:901788320229303096)

#### （可选）在工具面板手动配置签名

您可以在插件配置页面，为元服务手动配置调试或发布签名。

1. 打开插件配置界面，在"关联元服务"页签点击"添加签名"。 ![](https://media:901788320229341097)

2. 输入签名信息。 ![](https://media:901788320229380098)

   |参数|说明|
   |:----------|:-------------------------------------------------------------------------------------------------------|
   |密钥名称|输入密钥名称。|
   |密钥密码|输入密钥密码，必须由大写字母（A-Z）、小写字母（a-z）、数字（0-9）和特殊符号（\`\~!@#$%\^\&\*()_+\\\|\[\];:'",\<.\>/?）中的两种以上字符的组合，长度为8-32位。|
   |签名类型|选择"调试签名"或者"发布签名"。|
   |调试设备|仅当"签名类型"选择"调试签名"时需要配置。 选择已在AGC注册的设备。如需使用本地设备调试，可点击"使用本地设备"，当前连接的真机设备将被添加到调试设备列表。之后，您可以在列表中勾选该设备。|
   |证书名称|输入证书名称。 说明： 每个账号仅支持创建3个调试证书和3个发布证书。|
   |Provision名称|输入Provision名称。|
   |签名存储地址|选择签名存储地址，默认存储在当前工程的.cert文件夹下。|
