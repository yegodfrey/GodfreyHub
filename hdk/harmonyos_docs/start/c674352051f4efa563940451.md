# 小程序转换元服务

插件支持将微信/支付宝小程序转换为ASCF元服务，或者将uni-app小程序转换为鸿蒙元服务，大大减少重复性适配工作，降低入驻鸿蒙生态的成本。转换后，您还可以通过对话将元服务直接推送至真机或者模拟器上运行，并完成编译打包。此外，插件面板还提供上架自检入口，方便您快速自查软件包问题，提高上架审核通过率。

## 前提条件

* 已[登录插件](https://developer.huawei.com/consumer/cn/doc/start/hosdevassistant-login-0000002588351354)。
* 已[完成插件的配置](https://developer.huawei.com/consumer/cn/doc/start/hosdevassistant-config-0000002588511280)。
* 如果需要运行到模拟器上，确保DevEco Studio已安装所需要版本的模拟器。

## 转换元服务

本章节以VS Code为例描述如何将小程序转换为元服务，在其他IDE上操作类似。

### 转换元服务工程

1. 在VS Code中打开**待转换工程的上一级目录** 。

   例如，待转换工程为"xiaochengxu"，则打开其上级目录"project"。

2. 进入插件界面，在左下角切换模式为"元服务转换"，在对话框中输入类似下述提示语：当前是一个XXX小程序，帮我转换为ASCF元服务工程。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/20/v3/hhnjaNSJT8StwmsjNxuNlw/zh-cn_image_0000002759678489.png?HW-CC-KV=V1&HW-CC-Date=20260915T115630Z&HW-CC-Expire=31536000000&HW-CC-Sign=1D3B3B0EBF88C387644E6E7C5B72FD5C88D5D51BBD9746866C9BB7584455A582)

元服务构建编译过程中，插件会自动引导您进行签名配置。

   * 如需新建一个元服务进行关联，点击"创建元服务"，插件将拉起AGC控制台页面，参考[关联新建的元服务](#section3351552018)的步骤4-7创建元服务后，返回插件对话框选择创建的元服务即可。

   > 说明
   >

     >

   * 如后续计划直接打包元服务进行发布上架，建议选择"发布签名"，插件将为元服务配置发布签名。

## 在真机上运行元服务

1. 确保真机已与PC连接，且真机上已安装ASCF引擎（在负一屏或华为应用市场搜索"元服务ASCF示例"，点击运行，系统会自动安装）。
2. 确保元服务已配置调试签名。

   如未完成，可在对话框中输入"帮我创建调试签名"的提示语，插件将快速帮您完成签名配置，具体流程可参见[会话中关联元服务并配置签名](#section8973741143918)。 说明
   >
   > 插件当前也支持您[在工具面板手动配置签名](#section139016181214)，但强烈建议您使用插件自动帮您配置签名。
3. 在对话框中输入类似下述提示词：已完成签名，帮我运行到真机上。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7e/v3/mDE7umP0RQmaj-k_5xxa0w/zh-cn_image_0000002658440032.png?HW-CC-KV=V1&HW-CC-Date=20260915T115630Z&HW-CC-Expire=31536000000&HW-CC-Sign=1E1446F8DDD1020AD6DD472E081CDF1F4BBF4DCA267B22C05463C633AB1BF281)

   |参数|说明|
   |:----------|:-----------------------------------------------------------------------------------------------|
   |密钥名称|输入密钥名称。|
   |密钥密码|输入密钥密码，必须由大写字母（A-Z）、小写字母（a-z）、数字（0-9）和特殊符号（`~!@#$%^&*()_+\|[];:'",<.>/?）中的两种以上字符的组合，长度为8-32位。|
   |签名类型|选择"调试签名"或者"发布签名"。|
   |调试设备|仅当"签名类型"选择"调试签名"时需要配置。 选择已在AGC注册的设备。如需使用本地设备调试，可点击"使用本地设备"，当前连接的真机设备将被添加到调试设备列表。之后，您可以在列表中勾选该设备。|
   |证书名称|输入证书名称。 > 说明 > 每个账号仅支持创建3个调试证书和3个发布证书。|
   |Provision名称|输入Provision名称。|
   |签名存储地址|选择签名存储地址，默认存储在当前工程的.cert文件夹下。|
