# 开通IM客服

IM客服是生态市场买家和卖家在线实时交流的工具，卖家开通并启用客服后，买家就可以在您的店铺主页以及商品详情页面，点击**联系店铺客服**直接与您进行在线交流。

开通IM客服之前请确认您已经完成[华为开发者联盟实名认证](https://developer.huawei.com/consumer/cn/doc/start/itrna-0000001076878172)。

开通步骤图例指导见下图，必选步骤完成后即可启用IM客服，可选步骤根据需要在启用前或启用后配置即可。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c6/v3/9efQK3UXSlGUXbGB8gvPXg/zh-cn_image_0000001344856641.png?HW-CC-KV=V1&HW-CC-Date=20261008T184356Z&HW-CC-Expire=31536000000&HW-CC-Sign=09DC820A745F93F5E633713CC5CC419557A345C26FE5D78D5066AC1F348761E4 "点击放大")

## 开通IM客服

1. 进入[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)，在左侧菜单栏找到"IM客服"。


2. 点击进入详情，点击开通IM客服下方的"开通IM客服"。

* 开通时间大约需要十分钟左右，请您耐心等待，可刷新网页查看开通状态。
* 若提示开通失败，请稍后重试或点击在线提单由技术人员帮助您解决。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/24/v3/fFcSpudoSAOpR1RC2QGF0w/zh-cn_image_0000001295641074.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T184356Z&HW-CC-Expire=31536000000&HW-CC-Sign=ADBB8117FDAC417BCE06D8F698E7EC4AB9B461AB4B1D7E1D7D73FD905887B880 "点击放大")

## 配置成员与部门

IM客服开通成功后， 第二步需要**配置成员与部门。**

* 您可以为公司业务配置相应的售前、售后、技术支持等不同部门，并邀请公司成员负责相应的岗位（前期可以先配置一名客服坐席即可）。

点击"去配置"，跳转到IM客服管理台，此时页面会提示未关联组织 ，请先完成组织创建。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ea/v3/UpakpXC5S6eKDhyRJ5cBlg/zh-cn_image_0000001344181277.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T184356Z&HW-CC-Expire=31536000000&HW-CC-Sign=4E1F4900D4A215A3D61D66997F72FA6121F462504D7A287488EBAE2C86FEB861 "点击放大")

1. **创建组织：**

点击页面"+"图标，根据提示完成组织创建。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ea/v3/Wy0jvbcgTzK2DlTGIllAsQ/zh-cn_image_0000001291473734.png?HW-CC-KV=V1&HW-CC-Date=20261008T184356Z&HW-CC-Expire=31536000000&HW-CC-Sign=7885FF669DDF19B12C546EE5F0BDE8557F9DA6BA7A56B2620DF8375B0A3047E0 "点击放大")

组织创建成功后，点击创建成功页面的"进入管理后台"，返回绑定组织页面，点击已创建组织图标**右上角** **关联** **标识**完成组织绑定。如下图示：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/70/v3/UQk8IQiIRni5F-44MjPo-A/zh-cn_image_0000001343552525.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T184356Z&HW-CC-Expire=31536000000&HW-CC-Sign=369199240A6F21E6F435A9FF868642309A22DECB511A007218FD37FA9853D7BD "点击放大")

2. **成员与部门：**

* 统一管理您组织下的成员与部门，为成员赋予相应的角色，成员会根据其角色拥有相应服务的使用权限。

组织关联后，点击已关联的组织图标，页面跳转到成员与部门、云客服配置页面；点击成员与部门下"进入"，页面进入成员与部门关联页面，如下所示：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/21/v3/63WZ3QrGQOajKHysZ6B1lQ/zh-cn_image_0000001344193613.png?HW-CC-KV=V1&HW-CC-Date=20261008T184356Z&HW-CC-Expire=31536000000&HW-CC-Sign=FE2D2C62F6F4392EA23E901C4F2559F945FDF0F44C40E439B88F790E1C5D34FB "点击放大")

打开成员与部门页面后，系统已存在两个成员，一个是自动创建的超级管理员、一个是创建组织时创建的组织管理员，这两个成员都可以维护组织和成员信息。

3. **新建成员：**

* 新建成员之前还可以新建部门结构（可选）。
* 可以新建自定义账号成员。点击"创建成员"，根据提示完成自定义账号成员创建。
* **创建成员**时可以授予角色权限，支持自动生成密码或手工设置密码。账号创建成功会给填写的手机号发送激活提示短信。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/50/v3/B6Yv_Qb_QzqO50g0g26nOQ/zh-cn_image_0000001343554165.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T184356Z&HW-CC-Expire=31536000000&HW-CC-Sign=9B7892A842A6272C1BD853E34C9CC02837DD39A70A8CDEAAB9AB8E62BD5B8408)

* **邀请成员加入** 可以邀请已有华为账号加入成员。点击"邀请成员加入"，根据提示完成华为账号成员邀请。

  账号创建成功会给填写的联系方式手机号发送激活提示短信，点击短信内链接登录即可激活账号。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d7/v3/lKaRVAk3RCGEkFNq5hob6w/zh-cn_image_0000001349164329.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T184356Z&HW-CC-Expire=31536000000&HW-CC-Sign=9D31D89C246299BE48E0AA0B90A91B4F3BCD878579A7362A9D22F6CED47FB654 "点击放大")

* 若提示"暂不支持邀请老账号加入组织"，可以尝试在[账号设置](https://developer.huawei.com/consumer/cn/doc/account-management-0000001052865467)中修改"账号名"后重新邀请。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e8/v3/d0NfrVSiSMi6zNh-ZsLQkw/zh-cn_image_0000001296250704.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T184356Z&HW-CC-Expire=31536000000&HW-CC-Sign=225C3CB51DFBE0E64A09AE23FB9FA18043A0F6D66D0A856153D26BACE3B7A05E "点击放大")
> 注意
>
> * 账号名可以在华为-账号中心查看，可以从账号下拉菜单-账号设置进入。
> * 添加成员后，系统会给填写的联系方式手机号发送激活提示短信，点击短信内链接登录激活账号，未激活的账号不可以设置为座席客服。
> * 云客服管理台URL地址：[https://css.cloud.huawei.com/agent-workbench/admin/RealTimeMonitoring](https://css.cloud.huawei.com/agent-workbench/admin/RealTimeMonitoring)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/16/v3/8GXtgPssSZGopxUs8Tyk2Q/zh-cn_image_0000001353389821.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T184356Z&HW-CC-Expire=31536000000&HW-CC-Sign=EFDB60E1EED6DAC0294D07F0D32B84FE3F3E1C740148F055593681413E735043 "点击放大")

4. **角色授权：**

新建成员完成后，对新建的成员进行角色授权操作，权限添加后保存即可。点击操作栏的编辑或者更多进行角色授权。云客服平台角色对应的权限见下表：

|-----------|---------------------|
|**云客服平台角色**|**角色权限** **说明**|
|超级管理员|开通客服时，系统自动创建，与卖家账号相同。|
|组织管理员|创建组织时配置，可以管理部门与成员。|
|云客服管理员|配置与管理客服，查看客服数据统计。|
|在线座席|客服会话、会话管理。|

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f8/v3/Roo1gc5sRxOJWyEoAdeJGQ/zh-cn_image_0000001296737394.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T184356Z&HW-CC-Expire=31536000000&HW-CC-Sign=2D58E478856DEEF0B6377B9B9F6000C7F1E85BE3580B4D41A6F47D495E9128A2 "点击放大")
> 说明
>
> 卖家可以给超级管理员、组织管理员授予云客服管理员权限，方便后续的客服管理操作。

## 配置云客服

配置云客服必须是角色为"**云客服管理员**"的账号才可以操作。

返回卖家中心-IM客服菜单，点击Step 3 **配置云客服**下方的"去配置"进入跳转到云客服管理台。

也可直接点击云客服管理台URL进入：[https://css.cloud.huawei.com/agent-workbench/admin/RealTimeMonitoring](https://css.cloud.huawei.com/agent-workbench/admin/RealTimeMonitoring)

1. **同步座席：**

在座席管理点击"手工同步"，从部门中同步角色为"在线座席"的成员，不会同步未激活的账号。

座席账号在创建后登录云客服管理台即为激活。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/60/v3/uA8MA2-jTDSoyI0dygKEXQ/zh-cn_image_0000001291967722.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T184356Z&HW-CC-Expire=31536000000&HW-CC-Sign=0512FCCD6AED3A0E6868718BC9820EB50570814CEA50616DF25106B7082CA3C9 "点击放大")

2. **创建技能组：**

新开通IM客服能力，是没有技能组关联的，需至少创建一个；选择左侧菜单栏中的**成员管理-技能组管理**，点击"+"新增；根据提示完成技能组创建。

* 创建技能组提示的非工作时间提示语为可选内容，样例：目前是非客服工作时间，请等待客服上班后联系。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6d/v3/-4v1Pw3-SM6VgKWdR4Kgvw/zh-cn_image_0000001343549493.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T184356Z&HW-CC-Expire=31536000000&HW-CC-Sign=F7FD500CE7FEC5D981FA48C3FCF16EB9AC362D386E9966E0AC564DCB6B459FCD "点击放大")

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7c/v3/8ndpOZU8QaGGn3wUwnFz3A/zh-cn_image_0000001296119198.png?HW-CC-KV=V1&HW-CC-Date=20261008T184356Z&HW-CC-Expire=31536000000&HW-CC-Sign=45454499BD30DCEFA6D725D672DBE7597969A08D8B20B07EC1E91D9B8928179E "点击放大")

3. **坐席分配：**

创建好技能组后，需要在技能组下分配成员坐席，点击**坐席分配**，选择成员，点击添加，确定保存完成坐席分配。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c2/v3/yqpiZAWOSoCfetUOZFMFBg/zh-cn_image_0000001291309942.png?HW-CC-KV=V1&HW-CC-Date=20261008T184356Z&HW-CC-Expire=31536000000&HW-CC-Sign=F199F9227E75E84369B4789355632794FBFF7431068E126444FBE4EBAEB6AEC6 "点击放大")

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/14/v3/KsUO1PMdS1KEnOJ3vc77DQ/zh-cn_image_0000001343549985.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T184356Z&HW-CC-Expire=31536000000&HW-CC-Sign=D2F0561FFEC87BB56FD40F7FFD008E7BC2032564FA0D05EF2F6D84E38868FBA8 "点击放大")

4. **关联技能组：**

打开云客服管理台**业务管理-应用管理** ，选择**关联技能组-点击关联**，按要求填写完成保存。

此时IM客服配置已完成，可以启用IM客服。

## 启用IM客服

返回卖家中心-IM客服菜单-点击"启用IM客服"，启用后该店铺下属的所有商品详情页和店铺主页将展示"联系客服"，买家可以通过IM客服联系卖家。
