# 开通IM客服

IM客服是生态市场买家和卖家在线实时交流的工具，卖家开通并启用客服后，买家就可以在您的店铺主页以及商品详情页面，点击**联系店铺客服**直接与您进行在线交流。

开通IM客服之前请确认您已经完成[华为开发者联盟实名认证](https://developer.huawei.com/consumer/cn/doc/start/itrna-0000001076878172)。

开通步骤图例指导见下图，必选步骤完成后即可启用IM客服，可选步骤根据需要在启用前或启用后配置即可。

## 开通IM客服

1. 进入[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)，在左侧菜单栏找到"IM客服"。


2. 点击进入详情，点击开通IM客服下方的"开通IM客服"。

* 开通时间大约需要十分钟左右，请您耐心等待，可刷新网页查看开通状态。
* 若提示开通失败，请稍后重试或点击在线提单由技术人员帮助您解决。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/24/v3/fFcSpudoSAOpR1RC2QGF0w/zh-cn_image_0000001295641074.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T174259Z&HW-CC-Expire=31536000000&HW-CC-Sign=FC142F18CD23B167A635ACD5A990238B11F29D0FEE68E4FB00E611CB1F5D6387 "点击放大")

## 配置成员与部门

IM客服开通成功后， 第二步需要**配置成员与部门。**

* 您可以为公司业务配置相应的售前、售后、技术支持等不同部门，并邀请公司成员负责相应的岗位（前期可以先配置一名客服坐席即可）。

点击"去配置"，跳转到IM客服管理台，此时页面会提示未关联组织 ，请先完成组织创建。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ea/v3/UpakpXC5S6eKDhyRJ5cBlg/zh-cn_image_0000001344181277.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T174259Z&HW-CC-Expire=31536000000&HW-CC-Sign=7668CD6C86E715FE998EA117DF631F39BACBAA1F4590B8190DE2E664F94168B4 "点击放大")

1. **创建组织：**

点击页面"+"图标，根据提示完成组织创建。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ea/v3/Wy0jvbcgTzK2DlTGIllAsQ/zh-cn_image_0000001291473734.png?HW-CC-KV=V1&HW-CC-Date=20260909T174259Z&HW-CC-Expire=31536000000&HW-CC-Sign=DF561E0AFC2047F1A9B0F348CB9E3AC4A0E7CDD16EDDF5E97B47D066E647F1FC "点击放大")

组织创建成功后，点击创建成功页面的"进入管理后台"，返回绑定组织页面，点击已创建组织图标**右上角** **关联** **标识**完成组织绑定。如下图示：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/70/v3/UQk8IQiIRni5F-44MjPo-A/zh-cn_image_0000001343552525.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T174259Z&HW-CC-Expire=31536000000&HW-CC-Sign=E7FBD25CA69928C7C25A31E75CBC711DE7B7B2742506E32E87E96421DCC83489 "点击放大")

2. **成员与部门：**

* 统一管理您组织下的成员与部门，为成员赋予相应的角色，成员会根据其角色拥有相应服务的使用权限。

组织关联后，点击已关联的组织图标，页面跳转到成员与部门、云客服配置页面；点击成员与部门下"进入"，页面进入成员与部门关联页面，如下所示：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/21/v3/63WZ3QrGQOajKHysZ6B1lQ/zh-cn_image_0000001344193613.png?HW-CC-KV=V1&HW-CC-Date=20260909T174259Z&HW-CC-Expire=31536000000&HW-CC-Sign=CA310973CD289BCFCC4E860B00AD26CE3964DF02D998F8D7340AA4E5D3ABFDA2 "点击放大")

打开成员与部门页面后，系统已存在两个成员，一个是自动创建的超级管理员、一个是创建组织时创建的组织管理员，这两个成员都可以维护组织和成员信息。

3. **新建成员：**

* 新建成员之前还可以新建部门结构（可选）。
* 可以新建自定义账号成员。点击"创建成员"，根据提示完成自定义账号成员创建。
* **创建成员**时可以授予角色权限，支持自动生成密码或手工设置密码。账号创建成功会给填写的手机号发送激活提示短信。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/50/v3/B6Yv_Qb_QzqO50g0g26nOQ/zh-cn_image_0000001343554165.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T174259Z&HW-CC-Expire=31536000000&HW-CC-Sign=D8DFCA0C3197CCDFC261733A36B9649038C780FA29244982BD98B87BDC676F4C)

* **邀请成员加入** 可以邀请已有华为账号加入成员。点击"邀请成员加入"，根据提示完成华为账号成员邀请。

  账号创建成功会给填写的联系方式手机号发送激活提示短信，点击短信内链接登录即可激活账号。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d7/v3/lKaRVAk3RCGEkFNq5hob6w/zh-cn_image_0000001349164329.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T174259Z&HW-CC-Expire=31536000000&HW-CC-Sign=D7610C50DFD6E307BF02EB218D6D6A71F4C5F3F008502FDB1672A2B0E746394E "点击放大")

* 若提示"暂不支持邀请老账号加入组织"，可以尝试在[账号设置](https://developer.huawei.com/consumer/cn/doc/account-management-0000001052865467)中修改"账号名"后重新邀请。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e8/v3/d0NfrVSiSMi6zNh-ZsLQkw/zh-cn_image_0000001296250704.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T174259Z&HW-CC-Expire=31536000000&HW-CC-Sign=73FABFA9611A7595095041FA6DB3FB0B2873589FA91F48C4A3EB56D5380DD83E "点击放大")
> 注意
>
> * 账号名可以在华为-账号中心查看，可以从账号下拉菜单-账号设置进入。
> * 添加成员后，系统会给填写的联系方式手机号发送激活提示短信，点击短信内链接登录激活账号，未激活的账号不可以设置为座席客服。
> * 云客服管理台URL地址：[https://css.cloud.huawei.com/agent-workbench/admin/RealTimeMonitoring](https://css.cloud.huawei.com/agent-workbench/admin/RealTimeMonitoring)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/16/v3/8GXtgPssSZGopxUs8Tyk2Q/zh-cn_image_0000001353389821.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T174259Z&HW-CC-Expire=31536000000&HW-CC-Sign=18C47444024D34F2E635FD5A4571CB7C62710ACEEAA6C2243E89255D0973B7B8 "点击放大")

4. **角色授权：**

新建成员完成后，对新建的成员进行角色授权操作，权限添加后保存即可。点击操作栏的编辑或者更多进行角色授权。云客服平台角色对应的权限见下表：

|-----------|---------------------|
|**云客服平台角色**|**角色权限** **说明**|
|超级管理员|开通客服时，系统自动创建，与卖家账号相同。|
|组织管理员|创建组织时配置，可以管理部门与成员。|
|云客服管理员|配置与管理客服，查看客服数据统计。|
|在线座席|客服会话、会话管理。|

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f8/v3/Roo1gc5sRxOJWyEoAdeJGQ/zh-cn_image_0000001296737394.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T174259Z&HW-CC-Expire=31536000000&HW-CC-Sign=36D2CB5738E90F807C5694CC2CC84598877704A13261A699205605D95260BBA3 "点击放大")
> 说明
>
> 卖家可以给超级管理员、组织管理员授予云客服管理员权限，方便后续的客服管理操作。

## 配置云客服

配置云客服必须是角色为"**云客服管理员**"的账号才可以操作。

返回卖家中心-IM客服菜单，点击Step 3 **配置云客服**下方的"去配置"进入跳转到云客服管理台。

也可直接点击云客服管理台URL进入：[https://css.cloud.huawei.com/agent-workbench/admin/RealTimeMonitoring](https://css.cloud.huawei.com/agent-workbench/admin/RealTimeMonitoring)

1. **同步座席：**

在座席管理点击"手工同步"，从部门中同步角色为"在线座席"的成员，不会同步未激活的账号。

座席账号在创建后登录云客服管理台即为激活。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/60/v3/uA8MA2-jTDSoyI0dygKEXQ/zh-cn_image_0000001291967722.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T174259Z&HW-CC-Expire=31536000000&HW-CC-Sign=54047129DA7AE199CF192BFCB1C8E1D6FCF4CCC99E8A8FC3F7520C89E7BF75F6 "点击放大")

2. **创建技能组：**

新开通IM客服能力，是没有技能组关联的，需至少创建一个；选择左侧菜单栏中的**成员管理-技能组管理**，点击"+"新增；根据提示完成技能组创建。

* 创建技能组提示的非工作时间提示语为可选内容，样例：目前是非客服工作时间，请等待客服上班后联系。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6d/v3/-4v1Pw3-SM6VgKWdR4Kgvw/zh-cn_image_0000001343549493.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T174259Z&HW-CC-Expire=31536000000&HW-CC-Sign=C3CFCE363AF380BCC3F67F0173962095DE83C06F38E45F483613CD5401F4E655 "点击放大")

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7c/v3/8ndpOZU8QaGGn3wUwnFz3A/zh-cn_image_0000001296119198.png?HW-CC-KV=V1&HW-CC-Date=20260909T174259Z&HW-CC-Expire=31536000000&HW-CC-Sign=6ED6AB8886896054BDE3D156B4E46AA7EB9045ACB7B2C2A361232065AF5C703A "点击放大")

3. **坐席分配：**

创建好技能组后，需要在技能组下分配成员坐席，点击**坐席分配**，选择成员，点击添加，确定保存完成坐席分配。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c2/v3/yqpiZAWOSoCfetUOZFMFBg/zh-cn_image_0000001291309942.png?HW-CC-KV=V1&HW-CC-Date=20260909T174259Z&HW-CC-Expire=31536000000&HW-CC-Sign=7D039C1F0736F71C45903DE0CD53BEB4A77E5B7DAFFF5A882FD8BC0835455736 "点击放大")

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/14/v3/KsUO1PMdS1KEnOJ3vc77DQ/zh-cn_image_0000001343549985.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T174259Z&HW-CC-Expire=31536000000&HW-CC-Sign=729B377DA99D614ADCDE967BBD1798799E974B26D039C82E5D2C6A03AACF053E "点击放大")

4. **关联技能组：**

打开云客服管理台**业务管理-应用管理** ，选择**关联技能组-点击关联**，按要求填写完成保存。

此时IM客服配置已完成，可以启用IM客服。

## 启用IM客服

返回卖家中心-IM客服菜单-点击"启用IM客服"，启用后该店铺下属的所有商品详情页和店铺主页将展示"联系客服"，买家可以通过IM客服联系卖家。
