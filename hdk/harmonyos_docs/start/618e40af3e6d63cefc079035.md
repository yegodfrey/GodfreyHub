# 开通IM客服

IM客服是生态市场买家和卖家在线实时交流的工具，卖家开通并启用客服后，买家就可以在您的店铺主页以及商品详情页面，点击联系店铺客服直接与您进行在线交流。

开通IM客服之前请确认您已经完成[华为开发者联盟实名认证](https://developer.huawei.com/consumer/cn/doc/start/itrna-0000001076878172)。

<br />

开通步骤图例指导见下图，必选步骤完成后即可启用IM客服，可选步骤根据需要在启用前或启用后配置即可。

![](https://media:401788750487203956 "点击放大")  

#### 开通IM客服

1. 进入[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)，在左侧菜单栏找到"IM客服"。

<!-- -->

2. 点击进入详情，点击开通IM客服下方的"开通IM客服"。

* 开通时间大约需要十分钟左右，请您耐心等待，可刷新网页查看开通状态。
* 若提示开通失败，请稍后重试或点击在线提单由技术人员帮助您解决。

![](https://media:401788750487378957 "点击放大")  

#### 配置成员与部门

IM客服开通成功后， 第二步需要配置成员与部门。

* 您可以为公司业务配置相应的售前、售后、技术支持等不同部门，并邀请公司成员负责相应的岗位（前期可以先配置一名客服坐席即可）。

点击"去配置"，跳转到IM客服管理台，此时页面会提示未关联组织 ，请先完成组织创建。

![](https://media:401788750487461958 "点击放大")

1. 创建组织：

点击页面"+"图标，根据提示完成组织创建。

![](https://media:401788750487494959 "点击放大")

组织创建成功后，点击创建成功页面的"进入管理后台"，返回绑定组织页面，点击已创建组织图标右上角关联标识完成组织绑定。如下图示：

![](https://media:401788750487540960 "点击放大")

2. 成员与部门：

* 统一管理您组织下的成员与部门，为成员赋予相应的角色，成员会根据其角色拥有相应服务的使用权限。

组织关联后，点击已关联的组织图标，页面跳转到成员与部门、云客服配置页面；点击成员与部门下"进入"，页面进入成员与部门关联页面，如下所示：

![](https://media:401788750487612961 "点击放大")

打开成员与部门页面后，系统已存在两个成员，一个是自动创建的超级管理员、一个是创建组织时创建的组织管理员，这两个成员都可以维护组织和成员信息。

3. 新建成员：

* 新建成员之前还可以新建部门结构（可选）。
* 可以新建自定义账号成员。点击"创建成员"，根据提示完成自定义账号成员创建。
* 创建成员时可以授予角色权限，支持自动生成密码或手工设置密码。账号创建成功会给填写的手机号发送激活提示短信。

![](https://media:401788750487693962)

* 邀请成员加入可以邀请已有华为账号加入成员。点击"邀请成员加入"，根据提示完成华为账号成员邀请。 账号创建成功会给填写的联系方式手机号发送激活提示短信，点击短信内链接登录即可激活账号。

![](https://media:401788750487799963 "点击放大")

* 若提示"暂不支持邀请老账号加入组织"，可以尝试在[账号设置](https://developer.huawei.com/consumer/cn/doc/account-management-0000001052865467)中修改"账号名"后重新邀请。

![](https://media:401788750487880964 "点击放大")  
![](https://media:401788750487912965)  
* 账号名可以在华为-账号中心查看，可以从账号下拉菜单-账号设置进入。
* 添加成员后，系统会给填写的联系方式手机号发送激活提示短信，点击短信内链接登录激活账号，未激活的账号不可以设置为座席客服。
* 云客服管理台URL地址：<https://css.cloud.huawei.com/agent-workbench/admin/RealTimeMonitoring>

![](https://media:401788750487984966 "点击放大")

4. 角色授权：

新建成员完成后，对新建的成员进行角色授权操作，权限添加后保存即可。点击操作栏的编辑或者更多进行角色授权。云客服平台角色对应的权限见下表：  

|-------|---------------------|
|云客服平台角色|角色权限说明|
|超级管理员|开通客服时，系统自动创建，与卖家账号相同。|
|组织管理员|创建组织时配置，可以管理部门与成员。|
|云客服管理员|配置与管理客服，查看客服数据统计。|
|在线座席|客服会话、会话管理。|

![](https://media:401788750488086967 "点击放大")  
![](https://media:401788750488115968)  
卖家可以给超级管理员、组织管理员授予云客服管理员权限，方便后续的客服管理操作。  

#### 配置云客服

配置云客服必须是角色为"云客服管理员"的账号才可以操作。

返回卖家中心-IM客服菜单，点击Step 3 配置云客服下方的"去配置"进入跳转到云客服管理台。

也可直接点击云客服管理台URL进入：<https://css.cloud.huawei.com/agent-workbench/admin/RealTimeMonitoring>

![](https://media:401788750488202969 "点击放大")

![](https://media:401788750488241970 "点击放大")

![](https://media:401788750488379971 "点击放大")

1. 同步座席：

在座席管理点击"手工同步"，从部门中同步角色为"在线座席"的成员，不会同步未激活的账号。

座席账号在创建后登录云客服管理台即为激活。

![](https://media:401788750488475972 "点击放大")

2. 创建技能组：

新开通IM客服能力，是没有技能组关联的，需至少创建一个；选择左侧菜单栏中的成员管理-技能组管理，点击"+"新增；根据提示完成技能组创建。

* 创建技能组提示的非工作时间提示语为可选内容，样例：目前是非客服工作时间，请等待客服上班后联系。

![](https://media:401788750488541973 "点击放大")

![](https://media:401788750488770974 "点击放大")

3. 坐席分配：

创建好技能组后，需要在技能组下分配成员坐席，点击坐席分配，选择成员，点击添加，确定保存完成坐席分配。

![](https://media:401788750488819975 "点击放大")

![](https://media:401788750488900976 "点击放大")

4. 关联技能组：

打开云客服管理台业务管理-应用管理，选择关联技能组-点击关联，按要求填写完成保存。

此时IM客服配置已完成，可以启用IM客服。

![](https://media:401788750489018977 "点击放大")  

#### 启用IM客服

返回卖家中心-IM客服菜单-点击"启用IM客服"，启用后该店铺下属的所有商品详情页和店铺主页将展示"联系客服"，买家可以通过IM客服联系卖家。

![](https://media:401788750489096978 "点击放大")
