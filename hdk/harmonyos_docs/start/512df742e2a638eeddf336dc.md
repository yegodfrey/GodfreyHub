# 管理中心介绍

## 管理中心介绍

开发者在联盟官网注册并实名认证后，登录并点击"[管理中心](https://developer.huawei.com/consumer/cn/console/overview)"即可进入管理中心页面。

## 添加卡片

如果管理中心展示的卡片较少，您可以通过"添加"功能添加您需要的卡片，具体步骤如下：

1. 使用已实名认证的账号登录，进入"[管理中心](https://developer.huawei.com/consumer/cn/console/overview)"页面。如果您的华为开发者联盟账号尚未实名认证，请参见[实名认证](https://developer.huawei.com/consumer/cn/doc/start/rna-0000001062530373)。
2. 点击服务分类的"![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260115092016.78375817960802284472495892406707:50001231000000:2800:DAB804471BA3E9FC8782CC5163F6797998DDF803F6177A492E0D2507BF35EFD2.gif)"图标。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260115092016.09339869991082618448327685107127:50001231000000:2800:7B6440F994F2345D47EDF82026394A3C513974E070F244DC58FC0BCB1F09C04A.png)
3. 在服务类型中，勾选希望在管理中心中显示的服务，然后点击"关闭"（卡上的蓝色勾号图标表示卡片已被选中）。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260115092016.92696862341998256086134640166660:50001231000000:2800:5E1626BAB25F9BA0BD91F1126A7B826435C08033C1021DF5EA7C3FDC541EE63A.png)

## 删除卡片

如果管理中心展示的服务卡片过多，可以通过删除功能删除您不需要的卡片，具体操作如下：

1. 点击服务类型后的"![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260115092016.37857091998026122612916011667318:50001231000000:2800:8EAE2594780B824B7F6C0944E3EC7D5426CA2302C21079BF68726AB9D4ACF7E7.gif)"图标。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260115092016.81741849433081552692875712855054:50001231000000:2800:90D73E7E838C7DF26EBC6C1CAC6A10CFFD197858370ED64394E2A070A082A72F.png)


2. 在显示的页面上，点击带有蓝色勾号图标的服务卡取消勾选。蓝色勾号图标消失后，点击"关闭"，服务卡片将从控制台中消失。
