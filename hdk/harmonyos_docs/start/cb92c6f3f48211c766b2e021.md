# 发起会话

1. 买家在卖家店铺首页和商品详情页均可联系客服，但如果卖家未开通客服功能，商品或店铺页就没有联系客服的入口。

![](https://media:401788750489613984 "点击放大")

2. 在具体的商品详情页右侧店铺信息下方，点击"联系店铺客服"进入会话界面。

![](https://media:401788750489648985 "点击放大")
