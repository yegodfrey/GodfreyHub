# 发起会话

1. 买家在卖家店铺首页和商品详情页均可联系客服，但如果卖家未开通客服功能，商品或店铺页就没有联系客服的入口。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b1/v3/AdF2OinwSh-pU9lLjsFwnw/zh-cn_image_0000002477438772.png?HW-CC-KV=V1&HW-CC-Date=20260909T145338Z&HW-CC-Expire=31536000000&HW-CC-Sign=8AD1D4746FE5334F49872FE510337257A2D18A4451D899BE88921FCB763C5203 "点击放大")

2. 在具体的商品详情页右侧店铺信息下方，点击"**联系店铺客服**"进入会话界面。
