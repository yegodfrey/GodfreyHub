# 服务商场景指南

1. 注册华为开发者联盟账号，详细操作可参考[注册账号](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。  
![](https://media:401788750495683084)  
* 若您已有华为账号且未进行实名认证，可直接登录后，通过服务商角色进行认证。

<!-- -->

* 若您已有华为账号且已通过个人/企业开发者实名认证，请重新注册新账号进行认证。为了您后续业务开展体验，建议您优先使用企业邮箱进行华为账号注册。

2. 入驻流程详见：[入驻流程说明](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-isvregistration-process-0000001071085290)

3. 为了更好地保障华为开发者联盟生态市场用户的权益，提升生态市场商户的服务水平和商品质量。发布商品前，商户需缴纳保证金。未缴纳保证金的商户不得上架商品。详见：[保证金规则及缴纳方式](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-isvregistration-deposit-0000001071245220)

4.上架商品

商品发布请严格按照商品发布说明执行，说明中发布标准为生态市场商品审核的标准，您可以参考[商品管理](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-commodity-publish-0000001070882279)。过程中遇到任何问题，请联系我们，邮箱：partner@huawei.com

5.商户可以在需求广场抢单或在需求管理系统中进行定向需求接单，与需求方建立联系，记录、跟踪项目售前进度，提交方案及报价单，完成交易。详见：[定制需求管理](https://developer.huawei.com/consumer/cn/doc/start/dev-mall-crowdsouring-0000001070863451)
