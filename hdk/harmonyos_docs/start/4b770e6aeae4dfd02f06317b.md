# 华为云授权认证

华为云授权认证需要您的账号已在华为云平台完成个人客户实名认证。

操作指导：

1. 使用已经实名认证的华为云账号登录[华为开发者联盟官网](https://developer.huawei.com/consumer/cn/)进入认证方式选择页面，点击华为云授权认证的"下一步"进入前往华为云授权页面。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251023202410.60214270831094617076580588123144:50001231000000:2800:ED6EF94C02D7E64B646CE756E0A1AC2BF39EA5C578427957D7699EEF8E571808.png "点击放大")


2. 点击"前往华为云"，进入数据授权页面，勾选同意授权后，返回华为云授权页面，点击"已完成授权"后，跳转到完善个人实名认证资料页面。
