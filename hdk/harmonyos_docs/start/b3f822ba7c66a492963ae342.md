# 9. SDK优选审核（试行版）

#### 概述

鸿蒙生态伙伴SDK优选库是基于生态市场已上架SDK产品的精选方案，旨在推动鸿蒙生态高质量发展，促进开发者共享生态价值。该优选库严格遵循国家标准、行业规范等多元评估体系，从合规性、个人信息保护、网络安全、生态贡献度及开发者体验等多个维度进行综合评定。通过评定的SDK将获得"优选"认证标识，为开发者提供权威选型参考。优选工作将持续动态开展，确保开发者能够获取更优质、更高效的SDK解决方案。

不参加优选评估的可单独知会SDK优选库运营方。  
![](https://media:401788750502651186)  
1.SDK市场及优选库涉及的包括但不限于商标、标识等相关权利均为华为所有，未经华为公司书面事先明示许可，任何第三方不得以任何形式使用。

2.华为会不定期对本文档的内容进行更新。

3.本文档仅作为使用指导，文档中的所有陈述、信息和建议不构成任何明示或暗示的担保。  

#### 一、 基础准入评估

#### 1．合法合规

1.1 内容合法合规：SDK须严格遵循《中华人民共和国网络安全法》、《网络信息内容生态治理规定》、《网络暴力信息治理规定》、《人工智能生成合成内容标识办法》、《互联网政务应用安全管理规定》等相关法律法规，保障网络安全，确保SDK为用户提供合法、安全、健康的服务。

1.2 知识产权：SDK及其内容需具备完整权利或得到充分授权，不得侵犯他人知识产权（包括商标、版权、商业秘密和其他专有权利）等合法权益，遵守适用的法律法规。

1.3 未成年人保护：无论服务对象是否包括未成年人，SDK均不得包含任何可能危害未成年人身心健康的有害内容。若SDK所服务的应用可供未成年人访问，必须严格遵守《中华人民共和国未成年人保护法》、《未成年人网络保护条例》及其他适用法律法规和行业标准。

当SDK向未成年人收集任何个人信息和敏感数据时，必须遵守适用的未成年人隐私保护法规。如《个人信息保护法》、《App违法违规收集使用个人信息行为认定方法》 、《儿童个人信息网络保护规定》以及其他适用的法律法规。

1.4 其他：SDK服务商应遵守所有适用的法律法规要求，须履行相应的合规义务。若SDK服务的应用涉及海外业务，须遵从当地法律法规要求。  

#### 2．个人信息处理

SDK服务商应确保其个人信息处理活动严格遵循工信部及全国智慧物联网（GIIC）的相关规范要求，包括但不限于：《工业和信息化部关于进一步提升移动互联网应用服务能力的通知》和《鸿蒙软件开发工具包 用户权益保护与个人信息收集技术要求》。

入选优选库的SDK须通过GIIC的权威测评，符合优选库制定的审核标准或规范要求。同时业界最佳实践和行业惯例也应当成为重要参照，为更符合实际要求，优选库将挑选可靠的描述或标准供SDK上线时遵从。

SDK个人信息处理具体要求包括但不限于：

<br />

2.1 获得同意

（1）收集个人信息前须告知目的、方式及范围等规则，获得最终用户授权后方可收集，并提供便捷有效的撤回同意方式；

（2）收集敏感个人信息前，应取得最终用户的单独同意；

（3）收集不满十四周岁未成年人个人信息前，应取得未成年人的父母或其他监护人的同意；

（4）向中华人民共和国境外提供个人信息的，应取得最终用户的单独同意；

（5）收集个人信息用于个性化推荐功能或大数据分析业务的，应向SDK使用者告知并在取得最终用户的授权同意情况下方可开展相关业务功能；

（6）授权及撤回方式需与SDK使用者协商确定，确保最终用户知情且主动明确同意，SDK依授权结果进行个人信息收集。

<br />

2.3 最小必要

（1）收集个人信息应当具有明确、合理的目的，并与处理目的直接相关；

（2）收集个人信息应当限于实现处理目的的最小范围，参考GIIC《鸿蒙软件开发工具包 用户权益保护与个人信息收集技术要求》附录B界定必要/可选个人信息及对应用途场景。

（3）必要个人信息收集范围不应超出GIIC《鸿蒙软件开发工具包 用户权益保护与个人信息收集技术要求》附录B同类目一般范围；可选个人信息不宜超出其扩展收集范围。

（4）SDK使用者或最终用户拒绝提供可选个人信息，SDK不应拒绝提供其他与该信息无关的业务功能使用；

（5）个人信息宜本地处理，非业务必需不得传输至SDK服务器端；

（6）收集个人信息的数量、频次、精度应满足实现业务功能所必须的最小范围；

（7）不宜收集不可变设备标识符，同一终端、同一业务场景下不宜收集多个设备标识符；

（8）不再提供某项个人信息收集能力时，应同步移除相关个人信息收集代码，因集成使用其他第三方SDK无法实现个人信息收集代码移除的，应确保不再运行相关代码逻辑；

（9）应仅在SDK使用者使用具体业务功能后，开始收集个人信息。  
![](https://media:401788750502676187)  
使用业务功能指SDK使用者应用软件调用具体业务功能API，非业务功能API不应作为收集个人信息的触发条件，如SDK初始化或参数配置等行为。

2.4 系统权限申请和使用

（1）应仅声明实现SDK服务目的合理关联的系统权限，不应声明与SDK功能无关的系统权限；

（2）应仅在SDK使用者使用具体业务功能时，申请对应系统权限；

（3）应声明和申请对最终用户权益影响最小的系统权限，按场景分级，如位置精度区分；

（4）SDK宜仅声明所需权限及其使用场景，由SDK使用者应用软件向系统申请相关权限；

（5）SDK不应使用其未声明但SDK使用者应用软件已申请的相关系统权限；

（6）最终用户拒绝相关权限申请，SDK不应拒绝提供其他与该权限无关业务功能使用，或频繁弹窗向最终用户申请该权限。

<br />

2.5 管理第三方SDK

（1）应精简集成第三方SDK至业务必需最小数量，并前置评估其个人信息保护能力；

（2）须通过隐私政策强制披露SDK关键信息，含名称、主体、目的、收集个人信息种类及处理规则等；

（3）需动态监控所集成第三方SDK版本迭代，及时修复漏洞或替换；对确认违规SDK须立即停用或规避风险。  
![](https://media:401788750502700188)  
SDK集成使用其他第三方SDK的情形包括SDK直接在自身代码中内嵌接入，以及因SDK运行所需，要求SDK使用者必须在其应用软件代码中内嵌接入。

2.6 对外数据传输

（1）应采用HTTPS等加密传输协议进行数据交互，确保个人信息传输安全；

（2）应在传输前对敏感个人信息单独进行加密；

（3）使用HTTPS传输协议时，宜开启SDK与SDK服务器端的双向验证机制，确保SDK服务器端的身份真实性。

<br />

2.7 配置能力提供要求

SDK向使用者提供功能服务应同时提供相关业务功能及个人信息配置能力，具体要求请参见[SDK审核指南](https://developer.huawei.com/consumer/cn/doc/start/sdk-review-guide-0000001913103001)中的[SDK配置能力提供要求](https://developer.huawei.com/consumer/cn/doc/start/sdk-function-0000001867303614#section9341204516442)。  

#### 3．用户权益保障

SDK服务商须在SDK提供服务的全生命周期各阶段协同SDK使用者共同保障最终用户权益，不得出现违规侵害用户权益的行为。

3.1 提供服务前要求

（1）个人信息处理规则

SDK应简洁、清晰、易懂地公开展示其个人信息处理规则，并满足以下要求：

（a）个人信息处理规则中应包括：个人信息处理者名称和联系方式；处理个人信息的种类、目的、方式、范围及保存期限；收集、存储、使用、加工、传输、提供、公开、删除等个人信息处理环节的具体规则；最终用户行使其决定、查阅、复制、转移、更正、补充、删除等权利的方式和程序；法律、行政法规规定应当告知的其他事项。

（b）SDK应单独制定个人信息处理规则，并明示其对应的SDK名称，不应与公司内其他APP、网站、小程序等产品共用同一规则；

（c）同一主体多个SDK宜分别制定个人信息处理规则，共用同一规则的，应显著区分不同SDK对应的各环节处理规则（如：单独章节、SDK名称加粗标识等）；

（d）个人信息种类不应采用概况性描述，应具体明确信息名称，如明确OAID、ODID等具体信息名称，而非仅概括性描述为"设备标识符"；

（e）应明确SDK基本业务功能和扩展业务功能，区分描述对应所需必要个人信息、可选个人信息，以及需向最终用户申请的系统权限；

（f）涉及敏感个人信息的名称应采用文字加粗、字号增大等方式突出显示；

（g）处理不满十四周岁未成年人个人信息的，应当制定专门的个人信息处理规则；

（h）向中华人民共和国境外提供个人信息的，应明示境外接收方的名称或者姓名、联系方式、处理目的、处理方式、个人信息的种类以及最终用户向境外接收方行使权利的方式和程序等事项；

（i）处理个人信息进行个性化推荐或大数据分析业务功能的，应告知其业务功能所使用的个人信息种类、目的意图、主要运行机制等；

（j）集成使用第三方SDK或因业务需要将个人信息传输至其他第三方的，应告知第三方产品名称、主体名称、第三方处理个人信息种类及目的、第三方个人信息处理规则等。

（2）SDK合规使用说明

应简洁、清晰、易懂地向SDK使用者提供合规使用说明，具体要求请参见[SDK用户权益保障基本要求](https://developer.huawei.com/consumer/cn/doc/start/sdk-user-rights-protection-0000001913103009)中的[合规使用说明](https://developer.huawei.com/consumer/cn/doc/start/sdk-user-rights-protection-0000001913103009#section103786835213)要求。

<br />

3.2 服务提供过程中要求

（1）个人信息处理规则变更应及时告知SDK使用者，不应使用热更新等远程控制方式擅自更改个人信息处理规则；

（2）不应擅自变更SDK使用者各项业务功能及个人信息配置状态；

（3）因主管部门、监管机构要求整改或个人信息处理规则发生重大变更的SDK版本更新，应主动通知SDK使用者，SDK使用者3个月未更新的，宜采用强制方式要求其更新；

（4）发生或可能发生个人信息泄露、篡改、丢失的，应通过邮件、电话等方式逐一告知SDK使用者，并采取补救措施，需要更新SDK版本的，宜采用强制方式要求SDK使用者更新；

（5）停止集成某SDK须移除其代码并要求提供方删除或匿名化处理相关个人信息（法律法规要求留存的除外）；

（6）版本更新后，宜采用便捷方式兼容SDK使用者已有的配置选项；

（7）提供互联网弹窗信息服务的，不应出现欺骗、误导、强迫最终用户跳转、下载、浏览等行为；

（8）应建立最终用户诉求和投诉响应管理机制，并在接到诉求和投诉后15个工作日内进行响应；

（9）宜定期评估SDK个人信息保护能力（自评估或第三方检测）。

<br />

3.3 停止提供服务后的保障要求

（1）停止对外提供服务前，应告知SDK使用者对已处理个人信息的处理方式；

（2）停止对外提供服务后，应通知SDK开发者及时删除SDK相关代码，对已收集的个人信息进行删除或匿名化。  

#### 4．漏洞管理

SDK服务商须确保在架版本无重大安全隐私问题或高危漏洞，遵循国家主管部门管理要求及网络安全管理措施。SDK优选库将持续关注国家及外部监管单位的漏洞报告，一旦发现有确认的风险，甚至导致公开舆情等场景，将立即启动"去优选"程序。优选库还将不定期巡检SDK，以确保其不存在已知漏洞。  

#### 5．生命周期管理

SDK服务商须严格遵循本指南[3．用户权益保障](#section15743164416503) 中的要求，对在架版本实施全生命周期合规管理，确保持续维护更新，不得存在侵害用户权益的违规行为；若当前版本SDK持续在架超12个月，且经通知后仍无法确认维护状态或明确放弃维护，优选库可执行"去优选"并下架风险版本。  

#### 二、 生态贡献评估

#### 6．生态价值

SDK优选库依据鸿蒙应用集成量及留存率等指标动态评估SDK生态价值，在相同功能分类中，指标数据排名靠前的SDK将获得更高优选分值，以作评估。  

#### 7．开发者体验

7.1 极简开发：SDK服务商应确保上架版本的文档完备性、能力有效性及文档易用性，其中文档需全面覆盖API功能说明且与SDK包内容一致，建议提供demo工程示例；核心API调用结果及错误码需准确有效，符合开发者预期；优选库将依据上述因素综合评估SDK质量，不符合要求者将限制优选资格直至整改通过。

7.2 功能完备度：SDK服务商须确保其SDK覆盖所属类别定义的核心功能范畴，优选库将基于权威材料或标准以及类别特征清单进行功能完备性验证，未达最低功能阈值要求者将不能纳入优选库，并视其情形限期补充完善。

7.3 快速集成： SDK服务商在上架提供SDK获取地址时须提供OpenHarmony Package Manager（OHPM）获取地址，以保障开发者能够以标准化流程高效接入和集成。  

#### 三、 SDK优选评估规则

#### 综合评估规则

* 准入筛选机制

SDK须通过基础准入评估（强制性基准项），未达标者自动排除，不具备后续评估资格。

* 分级评估流程

通过基础准入评估的SDK，将进入生态贡献专项评估，从生态价值、开发者体验等维度进行深度审核。

自愿选择不参加优选评估的SDK服务商可知会SDK优选库运营方，未知会运营方的，默认参加优选评估。  

#### 持续评估机制

* 动态监测机制

基于中国信通院及其授权机构的检测数据，结合公开漏洞情报与舆情信息，对优选库中的SDK进行持续风险管理。若发现安全或合规问题，触发系统下架机制的，移出优选库。

* 复审机制

按周期复审：每季度对优选库中的SDK进行多维评估，并启动系统性再评估流程。根据复审结果动态调整SDK的优选状态标识，确保库中SDK符合最新评估标准。

按申请复审：对评估结果有异议的，可向运营方申请，运营方根据申请的合理性自主判断是否启动复审。  

#### 四、 SDK优选库违规处置规范

为规范SDK优选库管理，对于违反《SDK优选审核》及《[SDK审核指南](https://developer.huawei.com/consumer/cn/doc/start/sdk-review-guide-0000001913103001)》的SDK，优选库将依据违规情节的严重程度采取相应的处置措施，具体如下：

（1）风险警示

将违规SDK纳入风险清单，并采取以下管控措施：

* 移除优选标识，并通过生态市场SDK详情页、DevEco Testing、AppAnalyzer等渠道公示风险版本；
* 定向推送风险提示，向集成该SDK的开发者发送通知，降低潜在技术风险。

（2）限期整改

* 暂停优选资格，并向SDK服务商发送整改通知，要求其在规定期限内完成修复并提交新版SDK；
* 逾期未达标的SDK，将被强制隐藏并下架。

（3）直接下架

对存在严重违规行为或整改无效的SDK，将直接执行下架处理。

<br />

* 处置依据

优选库基于合规性审查结果独立判定违规等级，并有权根据实际风险情况动态调整处置措施。
