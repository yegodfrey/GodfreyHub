# 订单管理

## 查看订单

登录生态市场[买家中心](https://developer.huawei.com/consumer/cn/market/buyer/cloud-orders)，在左侧导航栏中找到生态市场订单，在订单列表页，可查看该订单详情，包括订单编号、支付时间，商品信息等。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d1/v3/PcLgb0AATweZAoszCG2arg/zh-cn_image_0000001126228187.png?HW-CC-KV=V1&HW-CC-Date=20261008T152521Z&HW-CC-Expire=31536000000&HW-CC-Sign=B8B04D479F6B877F03CDC565BC0597D912D08D711A2CACE599C1D3E51BF00A77 "点击放大")

## 取消订单

登录生态市场[买家中心](https://developer.huawei.com/consumer/cn/market/buyer/cloud-orders)，在左侧导航栏中找到生态市场订单，找到需要取消的订单，点击取消订单，选择取消原因，填写具体说明，点击提交，即可取消订单。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f3/v3/JrdHXDE5RZivx9EiDIRATQ/zh-cn_image_0000002141469214.png?HW-CC-KV=V1&HW-CC-Date=20261008T152521Z&HW-CC-Expire=31536000000&HW-CC-Sign=E1EFC0357F270F45B54BB363DC79718BE3CB7446E747366E9D5743B607B55946 "点击放大")

## 未支付订单

需要购买的商品在未支付的情况下，您可以登录生态市场[买家中心](https://developer.huawei.com/consumer/cn/market/buyer/cloud-orders)，找到未支付订单，点击支付，完成订单支付。
