# 团队账号角色与权限

华为开发者联盟已实名的企业/个人开发者，即可使用团队账号服务。账号持有者拥有开发者联盟管理中心、应用市场、各开放能力所有权限，可以为自己的账号添加多名团队成员，成为团队账号（最多200个）。账号持有者当前可以在系统管理、应用市场、流量变现服务和主题中心等业务中赋予团队成员不同的角色，如开发、运营、财务、法务、测试等，并将账号持有者在业务中的相关权限分配给成员，使团队可以更快速便捷的运营自己的产品。
