# 交付并完成交易

需求方提交订单后，将按照双方合同约定线上支付款项，订单状态为"交付中"后您可开始准备并上传交付件。

在最终交付前，您可以根据需求方要求修改交付件，需求方确认最终交付件后完成交易。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/08/v3/kcxbGu6qSEy_GNNNgeRtIg/zh-cn_image_0000001349918469.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T140013Z&HW-CC-Expire=31536000000&HW-CC-Sign=D54C327AE8A9931C39233FEFF5F0B0ECAE2EBAC42ECE24B2E1ACECB9EE484ECB "点击放大")

## 上传交付件

1. 登录[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)。
2. 在左侧导航栏，点击**需求管理**。
3. 找到目标需求，在**需求详情** 页面的方案列表区域，点击**添加交付件** 。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d3/v3/A8-dvy3NT7S-xlrJMxFyaA/zh-cn_image_0000001070724711.png?HW-CC-KV=V1&HW-CC-Date=20261008T140013Z&HW-CC-Expire=31536000000&HW-CC-Sign=4C14C90F65F9D15D08CA11CFAFA4A75726A70F4828713BE84B3AD13007970545 "点击放大")
4. 在添加方案对话框填写方案信息并上传交付件，点击**确定** 。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/27/v3/zJMkIz48R7iFTOLbK90zXQ/zh-cn_image_0000001071403040.png?HW-CC-KV=V1&HW-CC-Date=20261008T140013Z&HW-CC-Expire=31536000000&HW-CC-Sign=3140CEDD6818E5D272FFF7AA353F6BC9AFB31B454149A73C8564731687B6BB5C "点击放大")
   > 说明
   > * 交付件配置后，会直接发送给需求方。一个需求内可以配置多个交付件，并可以对交付件进行删除和修改。

|**参数**|**描述**|
|:-----|:--------------|
|方案名称|自定义填写方案名称，便于识别|
|方案文件|上传交付件附件，用户可以下载|
|备注（可选）|填写交付件备注，用户可以看到。|

5.需求方确认交付件后，订单状态为"已完成"则交易完成。
