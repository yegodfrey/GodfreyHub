# 交付并完成交易

需求方提交订单后，将按照双方合同约定线上支付款项，订单状态为"交付中"后您可开始准备并上传交付件。

在最终交付前，您可以根据需求方要求修改交付件，需求方确认最终交付件后完成交易。

## 上传交付件

1. 登录[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)。
2. 在左侧导航栏，点击**需求管理**。
3. 找到目标需求，在**需求详情** 页面的方案列表区域，点击**添加交付件** 。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d3/v3/A8-dvy3NT7S-xlrJMxFyaA/zh-cn_image_0000001070724711.png?HW-CC-KV=V1&HW-CC-Date=20260909T130013Z&HW-CC-Expire=31536000000&HW-CC-Sign=F973563F75F4AF27E4785BDED817ABC3A22260C26E9B1B69FF656F28CF45EAE1 "点击放大")
4. 在添加方案对话框填写方案信息并上传交付件，点击**确定** 。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/27/v3/zJMkIz48R7iFTOLbK90zXQ/zh-cn_image_0000001071403040.png?HW-CC-KV=V1&HW-CC-Date=20260909T130013Z&HW-CC-Expire=31536000000&HW-CC-Sign=0F649B70B19B4AF2222AE46D9D43ECAAD33893FB6479AFD2B3C1DBC8D38808CE "点击放大")
   > 说明
   > * 交付件配置后，会直接发送给需求方。一个需求内可以配置多个交付件，并可以对交付件进行删除和修改。

|**参数**|**描述**|
|:-----|:--------------|
|方案名称|自定义填写方案名称，便于识别|
|方案文件|上传交付件附件，用户可以下载|
|备注（可选）|填写交付件备注，用户可以看到。|

5.需求方确认交付件后，订单状态为"已完成"则交易完成。
