# 交付并完成交易

需求方提交订单后，将按照双方合同约定线上支付款项，订单状态为"交付中"后您可开始准备并上传交付件。

在最终交付前，您可以根据需求方要求修改交付件，需求方确认最终交付件后完成交易。

![](https://media:401788750497132107 "点击放大")  

#### 上传交付件

1. 登录[卖家中心](https://developer.huawei.com/consumer/cn/market/provider/prod-list)。
2. 在左侧导航栏，点击需求管理。
3. 找到目标需求，在需求详情页面的方案列表区域，点击添加交付件。 ![](https://media:401788750497160108 "点击放大")

4. 在添加方案对话框填写方案信息并上传交付件，点击确定。 ![](https://media:401788750497197109 "点击放大")

   ![](https://media:401788750497226110)  
   * 交付件配置后，会直接发送给需求方。一个需求内可以配置多个交付件，并可以对交付件进行删除和修改。

|参数|描述|
|:-----|:--------------|
|方案名称|自定义填写方案名称，便于识别|
|方案文件|上传交付件附件，用户可以下载|
|备注（可选）|填写交付件备注，用户可以看到。|

5.需求方确认交付件后，订单状态为"已完成"则交易完成。

![](https://media:401788750497285111 "点击放大")
