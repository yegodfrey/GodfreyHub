# 协议更新

协议更新分为"协议强制签署的情况"和"协议非强制签署的情况"两种情形。

1. 协议强制签署的情况
   * 后续如某协议有重要条款变更，则您必须重新签署此协议才能继续使用管理中心，如您不同意协议的更新内容，您应该停止使用管理中心。在这种情况下，更新的协议会以弹窗的形式展现在管理中心首页，并显示协议变更点，提醒您重新签署。例如，华为推送服务使用协议有更新，则您在进入"管理中心"页面的时候，会弹出提示要您重新签署，并在协议上方显示更新描述，您可以快速看到协议变更点。

   * 如强制签署协议已更新，账号持有者或法务未及时对已更新的协议进行签署，则团队成员在进入团队账号时会提示需提醒账号持有者或拥有法务角色的团队成员进行签署，签署后，所有团队成员即可正常使用团队账号。

2. 协议非强制签署的情况 后续如某协议有一般条款变更，如因被要求遵守使用的法律、法规等导致的变更，一般条款变更不会影响您的权益和服务使用时，更新的协议会进行公示，请您前往管理中心上方公告栏，阅读并同意签署协议变更。
