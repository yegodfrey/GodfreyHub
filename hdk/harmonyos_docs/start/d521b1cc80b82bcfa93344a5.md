# 添加账号组成员

添加账号组成员，既需要主账号添加成员账号，又需要成员账号接收邀请。以上操作都完成后才可添加成功。

## 关联主体添加账号组成员

1. 点击"添加成员"进入添加账号组成员页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/23/v3/M0txNzxrQXiENqze6HfbJA/zh-cn_image_0000002492534805.png?HW-CC-KV=V1&HW-CC-Date=20261008T174253Z&HW-CC-Expire=31536000000&HW-CC-Sign=2D17116CE85C6F36920A3BEAFB0FA228D552288766D5215C3424CE4FB7A49307)

2. 需提供本账号开发者证件、关联开发者账号信息、关联开发者证件、关联邀请函、股权关系比例证明，签署[《关联主体服务协议》](https://terms-drcn.platform.dbankcloud.cn/agreementservice/developer/getAgreementTemplate?agrType=1329&country=cn&language=zh_cn&version=2026030501)并点击"添加"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/66/v3/2WuuAg5gQQiTMBp3rGYY0A/zh-cn_image_0000002492454853.png?HW-CC-KV=V1&HW-CC-Date=20261008T174253Z&HW-CC-Expire=31536000000&HW-CC-Sign=A335B86EF0A0C84DEC4A7E2206EC4B43D6BC51A8350967CA2727FD90C2C4B576)

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/68/v3/DRm6iP_QQjimQxa_5p-Edg/zh-cn_image_0000002459495300.png?HW-CC-KV=V1&HW-CC-Date=20261008T174253Z&HW-CC-Expire=31536000000&HW-CC-Sign=2E80FED4066C9DF45655E60A25DAD47784B4B929ABB0992B43ADE7F2EB5E23E9)
3. 经开发者联盟审批通过后，系统会向成员账号的联系邮箱发送邀请邮件。 注意
   >
   > 关联主体账号组仅支持中国大陆企业开发者使用。

## 联运服务添加账号组成员

点击"添加成员"进入添加账号组成员页面。选择账号类型（手机/邮箱），输入成员的开发者账号和联系人邮箱，点击"添加"，系统会向成员账号的联系邮箱发送邀请邮件。

> 联运服务账号组当前不支持跨站邀请。中国大陆开发者：只能邀请中国大陆开发者；俄罗斯开发者：只能邀请俄罗斯开发者；其他国家/地区的开发者：不能邀请中国大陆和俄罗斯的开发者，可以邀请其他国家/地区开发者。

## 成员接受邀请

1. 成员账号在联系邮箱找到邀请邮件，点击激活链接"这里"，进入加入账号组页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f8/v3/5sQKNNW6S1ykUJsIXM89gw/zh-cn_image_0000002470106389.png?HW-CC-KV=V1&HW-CC-Date=20261008T174253Z&HW-CC-Expire=31536000000&HW-CC-Sign=CE45F489B043D6B9D842A8FADC81928796E6FAD11AB8DB51F4E19E0124F8F301 "点击放大")


2. 用成员账号登录[华为开发者联盟官网](https://developer.huawei.com/consumer/cn/)，仔细阅读弹框中的邀请信息后，如果同意加入，点击"加入"即可成为账号组成员。
