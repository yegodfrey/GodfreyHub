# 管理团队账号

账号持有者或其他有权限的成员账号登录开发者联盟官网后，进入管理中心，在"开发者中心"中点击进入"团队账号"进行添加成员、设置角色、管理权限等操作。

所需角色：账号持有者或其他有权限的成员账号，详情请参见[角色权限](https://developer.huawei.com/consumer/cn/doc/start/tarap-0000001059365850)。

## 添加团队成员

1. 账号持有者或其他有权限的成员账号登录联盟管理中心，通过左侧菜单栏"开发者中心-团队账号"进入团队账号页面，点击"添加成员账号"。一个团队中，团队成员的上限为200个。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250916151619.53144019419894396108849287383633:50001231000000:2800:C7020D5B74E77C1013329074810AB232BA39F86434DA6E53E851E2C07152B30F.png)

2. 按照页面提示选择账号类型，填写成员的账号及邮箱地址，设置成员账号有效期。确保邮件地址真实有效，成员才能收到邀请邮件并激活。被邀请的团队成员需在由邀请人发出的最新一封的邀请邮件中所提示的时效内激活账号，若超过最新一封邀请邮件内的激活期限则需要再次邀请。 填写需要邀请的团队成员信息包含：

   * 在团队内显示的成员名称。
   * 团队成员接收该团队内相关信息的邮箱。
   * 该团队成员在本团队内的有效期限。
     * 选择"永久有效"，表明该成员在账号持有者删除该成员、解散该团队或其主动退出前将永久有效。

     * 选择"到期日期"，则可以设置该账号角色在团队内的到期日期。

   > 说明
   >
   > 此处账号持有者为成员账号配置的"昵称"与"联系邮箱"在团队成员成功加入本团队后，团队成员可自行修改。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250916151620.89345752930613901348016107178959:50001231000000:2800:7DEBBBA9DCAA7438163448DADC3C959D6559AED25EEC75A9EDED8CF0E3064199.png)
3. 选择被邀请成员在本团队内的角色，角色下方则包含其角色在该业务内的相应权限。若设置为"系统管理"中的"管理员"角色则其将自动拥有除法务相关角色以外的所有角色。具体角色与权限请[点击查看](https://developer.huawei.com/consumer/cn/doc/start/tarap-0000001059365850)。同时，此处可以为团队成员设置相应的应用访问权限，下图所框出的角色默认拥有账号持有者"所有APP"的访问权限，无法修改。其余角色均可在下拉框中选择该账号查看应用的维度。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250916151620.79658245979784096962490783445038:50001231000000:2800:5DE76B392FB1F40F7B6E903E4E09ABB2C38A0E1B210228380974A6C9A7B0D5D2.png)
4. 设置应用访问权限：点击"否"选择相应的APP，也可输入应用名称或APP ID进行搜索。当勾选"系统管理"下的角色时，默认拥有"所有应用"的访问权限，无法修改。设置完毕后点击"提交"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250916151620.48188941434054724174247968961524:50001231000000:2800:CC1548AFFC6F7253F3EF44E9157A247C28021ADECF02571ABDDEE550D9C9EAB3.png)

5. 账号信息确认：确认成员账号设置无误后，点击"确认提交"，显示"添加成功"，邀请邮件会发送至被邀请成员的联系邮箱。若账号持有者或管理员因邀请过期或其他原因需要重新邀请团队成员，可点击"重新邀请"。邀请有效期以最新一封邀请邮件中所显示的有效期为准。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250916151620.46221359831236762536109686107906:50001231000000:2800:6E65A6C04E5A47844EAAEEF0CBB75EBF6CB8977A89FF8513870B7A5BB7A82B3C.png)

## 编辑团队成员信息

当团队中成员的工作内容有调整后，账号持有者及其他有权限的成员账号可以对团队成员的权限进行修改，修改成员账号的操作如下：

1. 在团队账号成员列表中选择需要变更权限的成员，点击"编辑"即可重新设置成员权限。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250916151620.37864106138198327425197104397452:50001231000000:2800:6A5907C481EA5496FFE5CC12089ED77AFE7094487CC4F5A4DDA8E7276496D9B4.png)

2. 修改团队成员账号信息，此处可修改信息与邀请步骤中填写团队成员的信息一致，[点击此处](#section179147174817)查看详情。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250916151620.03226616709321676802006641987750:50001231000000:2800:77232FE114B51E73E64A1EF7D2395FBC35E5B56F149C8586B8D1DEBED3C5C59A.png)
3. 配置权限：账号持有者可在此选择所邀请的团队成员在本团队内的相关权限，具体可查看[角色与权限](https://developer.huawei.com/consumer/cn/doc/start/maug-0000001058696103#section15955175795718)。
4. 确认修改无误后，点击"提交"，页面会弹窗提示"修改成功"。修改完成后，被修改角色的成员账号邮箱，会收到提示邮件，告知其在团队内的角色与权限已修改。

## 删除团队成员

团队成员主动退出团队，此成员会自动从团队账号列表中删除。或者，团队账号持有者或系统管理员可以手动删除成员，步骤如下：

在团队账号成员列表中选择目标账号，点击"删除"。在弹出的提示框中，点击"确认"即可成功删除该成员。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250916151620.17641388635649905508357960384886:50001231000000:2800:856CEF617C911C91B901B619DA95FEDB19E49D1D957409E66A2C94C1A0E3FF1D.png)成员删除后，不会影响该成员原先在团队中为团队已完成生效的相应操作，例如应用上架、邀请其他团队成员等。
