# 沙盒测试

在应用测试阶段，您可以在AppGallery Connect中配置沙盒测试账号，通过配置测试账号可以同时接入华为应用内支付、付费下载、游戏等不同服务，从而可以模拟真实环境进行免费测试。  

#### 前提条件

如需使用支付订单、订阅服务和游戏功能的沙盒测试，请确保您的应用已集成HMS Core SDK 3.0及以上版本。更多沙盒测试说明如下：

* 华为应用内支付：沙盒测试说明请参见[应用内支付沙盒测试](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/sandbox-testing-0000001050035039)。
* 付费下载：沙盒测试说明请参见[测试付费下载应用](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/appgallerykit-paidapps-testfunction-0000001073423057)。
* 游戏服务：游戏功能测试说明请参见[游戏功能测试](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/game-test-0000001050123493)。

#### 清除购买历史记录

如果您需要使用测试账号重复测试订阅和非消耗型商品的购买，可以清除购买历史记录。

1. 登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"用户与访问"。
2. 左侧导航栏选择"沙盒测试 \> 测试账号"，勾选账号，点击"清除购买历史记录"，成功后再购买订阅和非消耗型商品。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250609203216.53953117342141655324764500634584:50001231000000:2800:220A4293C1F81E3E487EA094224081C29909C0FC86F34961C35AF6E41D3EB406.png)

#### 中断测试账号的购买流程

如果您需要模拟购买失败或中断的情况，以验证网络问题等导致购买中断时的处理逻辑是否准确，可以中断此测试账号的购买流程。

1. 登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"用户与访问"。
2. 左侧导航栏选择"沙盒测试 \> 测试账号"，点击账号，并在编辑页面勾选"中断此测试账号的购买流程"。 点击"确认"后，即可在沙盒环境中实现该测试账号的购买持续失败。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250609203216.73558045800829057153377103008929:50001231000000:2800:9B1F43E69D0E57C6ED5EFBB3D944693AEAE5841788E4DAF68F0DBCC292CAAE6B.png)
3. 若要使该沙盒账号的购买或订阅续期恢复正常，可以取消勾选"中断此测试账号的购买流程"并确认。
