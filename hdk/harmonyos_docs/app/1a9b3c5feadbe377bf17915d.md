# 使用限制

|限制项|限制|
|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
|截屏操作|仅支持HarmonyOS 5.0.0及以上版本的所有真机设备。|
|文件管理|当前暂不支持文件管理功能。|
|应用安装完成后是否支持自动打开|HAP和APP格式的HarmonyOS应用安装完成后均会自动打开，无需手动操作。|
|支持同时调试的设备数|单机调试场景下，每次调试仅支持申请1台设备，同一账号最多可同时占用2台设备。|
|调试设备权限修改|申请设置权限后，将开放部分"设置"功能，例如开启深色模式、切换输入法等，以下高风险操作仍被禁止：设置锁屏密码、登录/修改华为账号、开启设备锁/查找设备、尝试Root、自行升级或降级设备操作系统版本、恢复出厂设置或刷机、管理云空间，以及其他任何因非正常使用行为导致设备无法恢复或严重影响后续用户使用的不可逆操作等。|
|应用包类型|支持上传和安装已配置签名信息的debug和release版本应用包，暂不支持In-house应用。|
