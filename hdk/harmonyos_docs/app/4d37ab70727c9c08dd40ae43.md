# 检查测试手机设置

测试近场服务之前需要您开启手机相关权限，并且添加“小艺建议”到桌面，以便接收近场测试推送内容。

                1. 根据应用类型以及应用或元服务上架情况进行相应处理。
                   * 应用类型是HarmonyOS应用

如果您的应用已上架，则进入华为应用市场下载至测试手机并安装应用。

如果您的应用尚未正式上架，则通过[邀请测试](https://developer.huawei.com/consumer/cn/doc/app/agc-help-invite-test-overview-0000002287701773)的方式下载至测试手机并安装应用。

                   * 应用类型是元服务

如果您的元服务已上架华为应用市场，则跳过本步骤。

如果您的元服务尚未上架华为应用市场，则通过[邀请测试](https://developer.huawei.com/consumer/cn/doc/app/agc-help-invite-test-overview-0000002287701773)的方式将未上架的元服务加载至测试手机。

                2. 测试手机登录华为账号，且须确保华为账号绑定的手机号已添加到测试用户列表中。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7b/v3/wKInm_5iRCa2FPfdKEGRTA/zh-cn_image_0000002477593769.png?HW-CC-KV=V1&HW-CC-Date=20261005T043442Z&HW-CC-Expire=86400&HW-CC-Sign=38DDD64775EBBB3A9C64E7A900D9C5DEFD6F079BA0E5014E853F4A9E39A6D3F9)

                3. 测试手机开启意图框架调试开关。操作路径：设置 - 系统 - 开发者选项 - 意图框架调试，开启“意图框架调试”开关。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/eb/v3/2hvVapT8SX-39PLayTfnyA/zh-cn_image_0000002477599001.png?HW-CC-KV=V1&HW-CC-Date=20261005T043442Z&HW-CC-Expire=86400&HW-CC-Sign=16BF44176663D529B81299969138900EEE3BB22EF0FC43684D6948E20E4B3B2F)

                4. 打开系统位置权限。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/82/v3/x_sTMOZjRyGqNakNPRO8Aw/zh-cn_image_0000002477552365.png?HW-CC-KV=V1&HW-CC-Date=20261005T043442Z&HW-CC-Expire=86400&HW-CC-Sign=A7FB530256810545631103230AB586A10B7F15614EDB82938DA48F6FFB7DC816)

                5. 打开小艺App，开启如下两个开关。
                   * “个性化推荐”开关。

操作路径：小艺App - 点击右上角头像 - 设置 - 个性化推荐 - “个性化推荐”开关。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cc/v3/wZz7DhUtSqiO09dI3wnUkw/zh-cn_image_0000002378770034.png?HW-CC-KV=V1&HW-CC-Date=20261005T043442Z&HW-CC-Expire=86400&HW-CC-Sign=1A45514284859A7C29B403A9A7BA7555935A707CE0F90A738370EBC3DFF77C1D)

                   * “基于位置信息提供服务”开关。

操作路径：小艺App - 点击右上角头像 - 设置 - 其他 - “基于位置信息提供服务”开关。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a5/v3/1Y_KJecDR9efO8dzRf5gIQ/zh-cn_image_0000002378770902.png?HW-CC-KV=V1&HW-CC-Date=20261005T043442Z&HW-CC-Expire=86400&HW-CC-Sign=6B7521B0B5851707D53EC09F83D7E052F87195FD712FC2133795E8E831FAD1C0)

                6. 添加“小艺建议”到桌面。

操作路径：设置 - 小艺 - 小艺建议 - 添加“小艺建议”到桌面。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/70/v3/AxoaqJp1S5qIuGgY6p5Rog/zh-cn_image_0000002477623509.png?HW-CC-KV=V1&HW-CC-Date=20261005T043442Z&HW-CC-Expire=86400&HW-CC-Sign=0EB9628DFE36626F134C5C2AA1CB0267D9E189685605F46A16669EFCF27BBA7C)

请先点击“添加“小艺建议”到桌面”，通过左右滑动选择2*2和4*4卡片（目前不支持在2*4卡片中出卡，所以请确保不要选择2*4卡片）。然后点击“添加至桌面”，将两种尺寸的卡片均添加至桌面。
