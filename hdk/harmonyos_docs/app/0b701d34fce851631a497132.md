# 告警总览

开发者配置告警规则后，当系统监测到监控指标满足告警触发条件时，将自动触发告警，并在告警总览页面生成相应的告警记录。告警总览页面支持通过告警名称、指标类型、系统版本、应用版本、触达状态等条件以及自定义时间范围筛选告警记录。告警记录可留存30天，从告警发生到上报存在分钟级时延。开发者可以在该页面点击按钮跳转到故障指标页面，查看每条告警记录对应的异常指标详情，并可对告警进行屏蔽或签收操作。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中点击您的应用/元服务。
3. 左侧导航栏选择"质量 \> APMS \> 故障告警"，进入故障告警主界面。
4. 选择"告警总览"页签，进入告警总览页面。 ![](https://media:101782873164006059 "点击放大")

   |参数|说明|
   |:---|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |告警时间|监测指标达到阈值时触发告警的时间。|
   |告警名称|创建告警规则时自定义的名称。|
   |指标类型|与告警规则中配置的"指标类型"相对应。目前支持监测以下类型的异常指标： * CPP CRASH：进程崩溃 * JS ERROR：JS错误 * PROCESS KILL：进程终止 * MEMORY_LEAK：内存泄漏 * FD_LEAK：句柄泄漏 * THREAD_LEAK：线程泄漏 * OOM：内存溢出 * APP_FREEZE：应用无响应|
   |触发条件|与告警规则中配置的"告警触发条件"相对应。用来指定告警条件，达到或超过指定条件阈值时，则触发告警。|
   |触达状态|告警通知的发送结果或告警的处理结果。包括： * 发送失败：告警通知未能成功发送。在此状态下，可执行的操作有查看异常指标明细、屏蔽告警。 * 已送达：告警通知已成功发送。在此状态下，可执行的操作有查看异常指标明细、屏蔽告警、签收告警。 * 已签收：告警故障已被确认。在此状态下，可执行的操作有查看异常指标明细、屏蔽告警。 * 已屏蔽：告警规则已被屏蔽。在此状态下，可执行的操作有查看异常指标明细。|
   |系统版本|应用适配的系统版本。|
   |应用版本|应用的版本标识。|

5. 通过设置告警名称、指标类型、系统版本、应用版本、触达状态、时间范围等过滤条件，可以筛选告警记录。点击"重置"可清除所有已设置的过滤条件。
   * 在"告警名称"输入框中输入告警名称，可以筛选同一条告警规则对应的告警记录。支持模糊匹配。
   * 通过"时间范围"选择器，可以自定义时间范围筛选告警记录。日期时间采用北京时间（UTC+8）。
   * 通过"指标类型"、"系统版本"、"应用版本"或"触达状态"下拉框，可以筛选特定类型的告警记录。下拉框中的备选值均支持多选。

   ![](https://media:101782873164144060 "点击放大")
6. 筛选出具体的告警记录后，通过点击"操作"列中的不同按钮，可以查看异常指标明细或处理告警。 ![](https://media:101782873164185061 "点击放大")

   * 查看：点击后将跳转到故障指标页面，您可以查看对应指标的问题列表。
   * 屏蔽：当系统中发生特定事件或条件时，可能会触发大量告警。这些告警可能是由于临时性问题、已知故障或正在进行的维护操作引起的。在这些情况下，过多的告警通知可能会导致信息过载，干扰实际的故障排查和处理工作。此时，您可以屏蔽该告警。在屏蔽时段内，系统将不再通过邮件、短信或回调链接方式发送该告警规则的告警通知，从而减少干扰。不过，告警总览界面仍能看到对应的告警记录，状态显示为"已屏蔽"。同时，"告警规则配置"页面中该条告警对应的告警规则也将被屏蔽，到期后自动恢复。如果需要提前取消屏蔽，可以重新进行设置。 操作方法：将鼠标悬停在"屏蔽"按钮上，在弹出的气泡框中选择屏蔽时间（1小时、1天、1周），然后点击"确定"。

     ![](https://media:101782873164217062)
   * 签收：当您已知晓故障原因或已经开始处理时，可以签收某个告警或批量签收同一类故障引起的确认该告警。这样做可以停止告警的语音提示，同时便于追踪告警处理进度，并避免多人重复处理同一告警。
     * 签收单个告警 操作方法：将鼠标悬停在对应告警记录"操作"列的"签收"按钮上，在弹出的气泡框中点击"确定"即完成确认。

       ![](https://media:101782873164246063)
     * 批量签收告警 操作方法：

       1. 通过过滤条件筛选告警记录后，勾选告警记录表头的选框，或逐一勾选告警记录行首的选框（勾选时可通过点击"重置"按钮调整选择范围），然后点击"批量签收"。  
          ![](https://media:101782873164272064)  
          "批量签收"功能仅适用于"触达状态"为"已送达"的告警记录。如果您同时勾选了其他状态的告警记录，系统将自动跳过不进行签收处理。

          ![](https://media:101782873164335065 "点击放大")
       2. 在弹出的对话框中点击"确定签收"，即完成告警确认。 ![](https://media:101782873164379066)
