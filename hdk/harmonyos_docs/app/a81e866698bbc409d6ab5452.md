# 申请调试证书

证书是为HarmonyOS应用/元服务配置签名信息的数字证书，可保障软件代码完整性和发布者身份真实性。证书格式为.cer，包含公钥、证书指纹（即证书的摘要信息）等信息。

根据使用场景的不同，证书分为调试证书、发布证书两种：

* 调试证书：调试证书用于应用/元服务调试场景。如果您只需要使用一台调试设备，并且业务支持自动签名，建议使用DevEco Studio提供的[自动签名](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-signing-auto)，此时无需获取调试证书。如果您使用多台调试设备或者会在断网情况下调试，则需要手动签名，此时您需要申请、下载调试证书。
* [发布证书](https://developer.huawei.com/consumer/cn/doc/app/agc-help-add-releasecert-0000001946273961)：发布证书用于应用/元服务发布的场景。当需要发布应用/元服务至华为应用市场时，您需要申请、下载发布证书，用于后续打包正式发布包。

> 说明
>
> 每个账号最多可申请3个调试证书。

## 前提条件

* 您已准备好[证书请求文件](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-signing-manual#section1245916381106)。
* 您的账号角色已[获取"访问调试类证书"权限](https://developer.huawei.com/consumer/cn/doc/app/agc-help-manageaccount-0000001099996700#ZH-CN_TOPIC_0000001099996700__li626645853313)。

## 操作步骤

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"证书、APP ID和Profile"。
2. 在左侧导航栏选择"证书、APP ID和Profile > 证书"，进入"证书"页面，点击"新增证书"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/75/v3/ec9VUk7qRC2SRViCaODmdg/zh-cn_image_0000002558952727.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=F208CD1874BD4849B9C2FDDCC7BCED4277BBC02A4268B78BF3C54B434F984F6A)

3. 在弹出的"新增证书"窗口填写要申请的证书信息，点击"提交"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/eb/v3/zTvZP9-vTgu4MjT9zLy3vQ/zh-cn_image_0000001948277617.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=F4B149EE6B3B0C598898D1A288BA1AA86A10FBB9678F1FEAA4C579B46738494F)

   |参数|说明|
   |:------------|:------------|
   |证书名称|不超过100个字符。|
   |证书类型|选择"调试证书"。|
   |选取证书请求文件（CSR）|上传准备好的证书请求文件。|

4. 证书申请成功后，"证书"页面展示证书名称等信息。点击"下载"，将生成的证书保存至本地，供后续调试签名使用。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b8/v3/MlTWpXafToKj64CJQ7dxaQ/zh-cn_image_0000001969075458.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=68AA348F86D4835AB1E3A0142EA8BA930391FDB9556B0AD42443CBA6BA7E4DB7)

   > 注意
   > * 证书申请成功即为"生效"状态。目前实名认证开发者的调试证书有效期为1年，未实名开发者的调试证书有效期为14天。
   > * 若证书状态变为"失效"或"已吊销"，表示当前证书已不可用，且通过此证书申请的Profile也会全部失效或吊销。您需要重新申请证书与Profile。
   > * 证书一旦废除将不可恢复，且通过此证书申请的Profile也会全部失效，请谨慎操作。
