# 申请二进制证书

二进制程序需使用华为颁发的二进制证书签名，才能在鸿蒙PC上正常运行。
> 说明
>
> 二进制证书仅支持企业开发者使用，且每个账号最多可申请3个二进制证书。

## 申请开通权限

二进制证书目前为受限开放，如需体验可通过[在线工单系统](https://developer.huawei.com/consumer/cn/support/feedback/#/)与我们联系。

工单"问题分类"请选择"AppGallery Connect > 证书、APP ID和Profile > 证书"，并在"问题描述"中提供如下信息：

* 企业名称及开发者ID
* 应用名称及APP ID
* 应用的业务场景与用途
* 申请的证书类型：二进制证书

## 准备工作

* 请准备好[证书请求文件](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-signing-manual#section1245916381106)。
* 请确保您的账号角色已[获取"访问发布类证书"权限](https://developer.huawei.com/consumer/cn/doc/app/agc-help-manageaccount-0000002306610129#ZH-CN_TOPIC_0000002306610129__li626645853313)。

## 操作步骤

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"证书、APP ID和Profile"。
2. 在左侧导航栏选择"证书、APP ID和Profile > 证书"，进入"证书"页面，点击"新增证书"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a3/v3/6azSWtMXTBiUmwkTTlZ2mg/zh-cn_image_0000002558948907.png?HW-CC-KV=V1&HW-CC-Date=20260909T165653Z&HW-CC-Expire=31536000000&HW-CC-Sign=FA7D483ACCDF8B1FF2C25E9ED133ED3441AABB9AD8D09564C0A64DC6BB091EE3)

3. 在弹出的"新增证书"窗口填写要申请的证书信息，点击"提交"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/66/v3/cIyJXeftTqqvKi7uKR3hMg/zh-cn_image_0000002391520716.png?HW-CC-KV=V1&HW-CC-Date=20260909T165653Z&HW-CC-Expire=31536000000&HW-CC-Sign=9F585F3F63C22F9817B430928384A214366C13EDE1E864B346A76DCF5BFD1038)

   |参数|说明|
   |:------------|:-----------------|
   |证书名称|自定义证书名称，不超过100个字符。|
   |证书类型|选择"二进制证书"。|
   |选取证书请求文件（CSR）|上传准备好的证书请求文件。|

4. 证书申请成功后，"证书"页面展示证书名称等信息。点击"下载"，将生成的证书保存至本地，供后续发布签名使用。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e5/v3/X4T0XoPmSTCqJNAjlUYauA/zh-cn_image_0000002425122473.png?HW-CC-KV=V1&HW-CC-Date=20260909T165653Z&HW-CC-Expire=31536000000&HW-CC-Sign=4C84C57F011C94A817D887C4582EA669EAD92725FA6C20B55979F15D4E41902B)

   > 注意
   > * 证书申请成功即为"生效"状态。若证书状态变为"失效"或"已吊销"，表示当前证书已不可用，您需要重新申请证书。
   > * 证书一旦废除将不可恢复，请谨慎操作。
