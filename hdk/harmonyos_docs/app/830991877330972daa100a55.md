# 申请企业应用重签名证书

对于通过企业MDM应用或者离线安装器分发的企业应用，当前仅使用开发者自身的证书进行签名，存在一定安全风险。为提升企业应用分发的安全性，AGC提供了企业应用重签名证书，用于对企业应用进行安全检测与签名。

在发布企业应用时，您需要使用企业应用重签名证书对应用包签名。请参考本文档申请并下载企业应用重签名证书。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bd/v3/Ai7TrYRiTgKt9g22ArIp9Q/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043444Z&HW-CC-Expire=86400&HW-CC-Sign=AD2BA1D66EE3056A2246F120BDD0917BEDE570C816B2B152684485AAEFA3EB60)

企业应用重签名证书仅支持企业开发者使用，且每个账号仅可申请2个企业应用重签名证书。

#### 申请开通权限

您需满足如下条件，才可申请企业应用重签名证书：

                1. [注册华为开发者账号](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)并[完成企业开发者实名认证](https://developer.huawei.com/consumer/cn/doc/start/ht-edrna-0000001154848578)
                2. 申请开通权限，方法如下：
                   * 申请邮箱地址：agconnect@huawei.com。
                   * 邮件标题：[申请企业应用重签名证书]-[应用名称]-[应用包名]-[APP ID]-[Developer ID]，Developer ID等查询方法可参见[查看应用信息](https://developer.huawei.com/consumer/cn/doc/app/agc-help-view-app-info-0000002282674569)。
                   * 邮件正文：请说明申请原因。

#### 准备工作

                * 请准备好[证书请求文件](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-signing-manual#section1245916381106)。
                * 请确保您的账号角色已[获取“访问发布类证书”权限](https://developer.huawei.com/consumer/cn/doc/app/agc-help-manageaccount-0000002306610129#ZH-CN_TOPIC_0000002306610129__li626645853313)。

#### 操作步骤

                1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择“证书、APP ID和Profile”。
                2. 在左侧导航栏选择“证书、APP ID和Profile > 证书”，进入“证书”页面，点击“新增证书”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/35/v3/KGe-B1EoSbupIzNf1WJ5sg/zh-cn_image_0000002479272772.png?HW-CC-KV=V1&HW-CC-Date=20261005T043444Z&HW-CC-Expire=86400&HW-CC-Sign=29951D6B13475749B91A58DE70D5B4F7FB541237893EEC5B0DDF2218144DAC11)

                3. 在弹出的“新增证书”窗口填写要申请的证书信息，点击“提交”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/27/v3/iXp6-EZGRjCA7HiKUpLwSQ/zh-cn_image_0000002511394193.png?HW-CC-KV=V1&HW-CC-Date=20261005T043444Z&HW-CC-Expire=86400&HW-CC-Sign=C979313BAE25675906D6C06E2A83DB7616D72EFC29676D33AF1D7FE8618BBB2D)

参数 | 说明  
---|---  
证书名称 | 自定义证书名称，不超过100个字符。  
证书类型 | 选择“企业应用重签名证书”。  
选取证书请求文件（CSR） | 上传准备好的证书请求文件。  
  
                4. 证书申请成功后，“证书”页面展示证书名称等信息。点击“下载”，将生成的证书保存至本地，供后续发布签名使用。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e7/v3/j5ygYerjQQObLgKU1zx0PA/zh-cn_image_0000002479276556.png?HW-CC-KV=V1&HW-CC-Date=20261005T043444Z&HW-CC-Expire=86400&HW-CC-Sign=481F91D0D11F20160C7B2BA64061C3A38513DDFC52E8D723B116588A9176B7C0)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4/v3/AqD19tJ1T5-OobcAmmKoJw/caution_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043444Z&HW-CC-Expire=86400&HW-CC-Sign=902DFC137F7798A4B1C4307B1E8FBFFC0896EF8D19FA36F56C8EB1C595ED0C8F)

                   * 证书申请成功即为“生效”状态。若证书状态变为“失效”，表示当前证书已不可用，您需要重新申请证书。
                   * 证书一旦废除将不可恢复，请谨慎操作。
