# 上传软件包

您需要先上传待发布的正式版本，以便在发布时能选择到对应的版本。上传时，AppGallery Connect会对上传的包进行合法性检测，同时还提供了上架自检功能来助您提高应用审核通过率。

## 提交软件包

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"APP与元服务"。
2. 选择要发布的应用。
3. 左侧导航选择"应用上架 > 软件包管理"，点击页面右上角的"上传"。
4. 在"上传包"窗口，先选择"使用场景"，然后点击"+"上传软件包。 若上传的软件包只用于测试发布，可以选择"仅测试"。若软件包需要在全网正式发布，请选择"测试和正式上架"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/86/v3/m7Y_TSYrSWWhZYvCfxwfuQ/zh-cn_image_0000002444702464.png?HW-CC-KV=V1&HW-CC-Date=20261008T155750Z&HW-CC-Expire=31536000000&HW-CC-Sign=9394CCE5AB5D72536E66C0EECC2630B241A140E6CDD11AA09CE86C75F3C9A896)

上传完成后，软件包管理页面会生成一条记录，展示软件包基本信息。

* 文件名：软件包文件名。
* 包名：应用包名，对应包内的bundleName字段。
* 版本（版本号）：版本名称与版本号，分别对应包内的versionNumber和versionCode字段。
* 构建版本：构建版本号，用于区分同一主版本下的不同测试子版本，对应包内的buildVersion字段。如包内无buildVersion字段，则显示"--"。
* 设备类型：支持的设备类型，对应包内的deviceTypes字段。
* 使用场景：传包时选择的使用场景。
* 上传时间：上传包的时间。
* 合法性：合法性检测结果，具体请参见[合法性检测](#section161521438134716)。
* 上架自检：上架自检结果，具体请参见[上架自检](#section15203163921310)。

## 合法性检测

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"APP与元服务"。
2. 选择要发布的应用。
3. 左侧导航选择"应用上架 > 软件包管理"，查看软件包对应的"合法性"栏。

## （推荐）上架自检

为提高应用审核通过率，建议您使用上架自检功能。该功能使用热门移动终端设备，按照华为应用市场上架标准对应用进行兼容性、稳定性、性能、功耗、UX、隐私等测试，可帮助您提前发现和解决问题。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"APP与元服务"。
2. 选择要发布的应用。
3. 左侧导航选择"应用上架 > 软件包管理"，点击软件包"操作"列"启动自检"。 说明
   >
   > 每个应用同时只能进行2个上架自检任务（包含状态为"终止中"和"检测中"的任务）。自检启动后，可随时点击"终止自检"结束任务。若您在启动自检后删除了软件包，自检任务将继续执行，需等待自检任务结束才可以执行新的自检任务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/10/v3/saa5-vt_TVm4F40l9XeZnA/zh-cn_image_0000002547830373.png?HW-CC-KV=V1&HW-CC-Date=20261008T155750Z&HW-CC-Expire=31536000000&HW-CC-Sign=A2F88B7A1AFFE7C28755D47A8B06360C85337C007986139A5AD82D1A13506635)
4. 在"上架自检"栏查看检测进度与结果。检测完成后，AGC将发送邮件通知您，您可以点击邮件中的"软件包管理"链接前往"软件包管理"页面查看检测结果。
   * 检测中：表示正在检测软件包。检测时长可能受终端设备数量和排队情况影响，请耐心等待。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8c/v3/j5rkWmXwQM2HDM9XYZA8vw/zh-cn_image_0000002686275386.png?HW-CC-KV=V1&HW-CC-Date=20261008T155750Z&HW-CC-Expire=31536000000&HW-CC-Sign=1926498C29B73CD8B01113F7E8999FB8B3DD81F1383F8830E117F6A69D356981)

   * 通过：表示检测通过，可以提交上架。点击"报告"可查看详细的检测报告。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c6/v3/Zi3UzBtSSUC84EBfexSoNA/zh-cn_image_0000002547826445.png?HW-CC-KV=V1&HW-CC-Date=20261008T155750Z&HW-CC-Expire=31536000000&HW-CC-Sign=9B8F5AC04040D1379BCF0BDD8389FB6CDF06EA1C0A1480DEDCF664183C43D8A3)
