# 功耗报告

功耗报告是对鸿蒙应用功耗情况的整体呈现，一方面从时间维度提供整体前后台耗电随着时间的变化趋势，另一方面提供器件耗电的分布图，明确各器件耗电比例。

![](https://media:101782378088553290)

* 折线图：周期内页面前后台耗电速率变化趋势，默认展示P90和平均值曲线。
* 柱状图：各器件耗电分布比例。
