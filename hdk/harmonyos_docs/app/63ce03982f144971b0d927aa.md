# 选择待发布软件包

从上传的版本中选择需要发布的软件包。

## 前提条件

已[上传软件包](https://developer.huawei.com/consumer/cn/doc/app/agc-help-release-atomic-upload-pkg-0000002293811142)，且软件包同时满足如下条件：

* "使用场景"为"测试和正式上架"。
* [合法性检测](https://developer.huawei.com/consumer/cn/doc/app/agc-help-release-atomic-upload-pkg-0000002293811142#section161521438134716)结果为"已达标"。

## 操作步骤

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"快速开始"中的"元服务一站式平台"卡片。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e6/v3/G8Wq-XYUQyyjS81a_HggZw/zh-cn_image_0000002529682783.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=D80ED7A38FD063D224C3976575F36AE8DA65469A2E6E67F8C754C504A55DD155)

2. 在左上角下拉列表选择要发布的元服务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6f/v3/AqPVCzRhRnmnME11N-HStA/zh-cn_image_0000002566867053.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=A01CF0EFA43C8FE149837213B5126FFAA673521EFC790E8C3B81DC1A62767414)

3. 左侧导航选择"元服务上架 > 版本信息"下待发布的版本。
4. 进入"软件版本"区域，点击"版本选取"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e3/v3/E2on92ikSK2Nc0RnqH3uag/zh-cn_image_0000002532938214.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=7FAEFA836576CDC15A9034AE5AF6703A92438E380C12AEBA8C9A6E114BBEBBD9)

5. 弹出窗口将展示已上传的、通过合法性检测的软件包，选择待发布的软件包，点击"选取"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5a/v3/j3CtrtyfQ-G_4aAVpeARLA/zh-cn_image_0000002563938101.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=12B6D65C323B9FE901D2A91D2C1C694D25EDA048782BBE4CAB650DD162E5C8C7)

6. 当您发布软件包的API Level ≥ 11时，可以设置是否对软件包进行加密。加密的影响、效果详细参见[应用加密](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/code-protect)。
   * 加密：用户在客户端安装的软件包为加密的，安全性较高。
   * 不加密：用户在客户端安装的软件包为不加密的，应用的启动速率较快。

   > 注意
   >
   > 如果元服务的设备仅包含运动手表，则不支持加密。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6a/v3/a0BLy68jTBeeYazB_0-qBQ/zh-cn_image_0000002532938216.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=143E84E55856A5E2079A3CDF2EF2C7DAF9B8E71638554124E3890BAC9AA93F46)
7. 当您的元服务正式版本下架之后，再次上架时，选取软件包的版本号要高于历史发布过的全网版本号。不满足要求的软件包无法选择，如下图： ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/26/v3/gFQPr9roT32ZcJGYQsxfsg/zh-cn_image_0000002533098166.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=EB6F71CC451168882CE1900A2E041972BA5459EAB086B3E3E464A22744CD36C2)
