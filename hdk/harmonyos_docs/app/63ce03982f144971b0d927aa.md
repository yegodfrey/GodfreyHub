# 选择待发布软件包

从上传的版本中选择需要发布的软件包。

## 前提条件

已[上传软件包](https://developer.huawei.com/consumer/cn/doc/app/agc-help-release-atomic-upload-pkg-0000002293811142)，且软件包同时满足如下条件：

* "使用场景"为"测试和正式上架"。
* [合法性检测](https://developer.huawei.com/consumer/cn/doc/app/agc-help-release-atomic-upload-pkg-0000002293811142#section161521438134716)结果为"已达标"。

## 操作步骤

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"快速开始"中的"元服务一站式平台"卡片。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e6/v3/G8Wq-XYUQyyjS81a_HggZw/zh-cn_image_0000002529682783.png?HW-CC-KV=V1&HW-CC-Date=20261008T191340Z&HW-CC-Expire=31536000000&HW-CC-Sign=5E182831CA102AF8E0526EE9CE481A7B2A18D2E7735EA42F70DB2094EC5EFE18)

2. 在左上角下拉列表选择要发布的元服务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6f/v3/AqPVCzRhRnmnME11N-HStA/zh-cn_image_0000002566867053.png?HW-CC-KV=V1&HW-CC-Date=20261008T191340Z&HW-CC-Expire=31536000000&HW-CC-Sign=091CBFDBF09090CDB7390D04E8636BFE9D4B0487FEB72141771F3A6A75981ADD)

3. 左侧导航选择"元服务上架 > 版本信息"下待发布的版本。
4. 进入"软件版本"区域，点击"版本选取"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e3/v3/E2on92ikSK2Nc0RnqH3uag/zh-cn_image_0000002532938214.png?HW-CC-KV=V1&HW-CC-Date=20261008T191340Z&HW-CC-Expire=31536000000&HW-CC-Sign=501B4504903E75A04D11B168E2606E95629E1F8CE0A08E94D81138B78475D69B)

5. 弹出窗口将展示已上传的、通过合法性检测的软件包，选择待发布的软件包，点击"选取"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5a/v3/j3CtrtyfQ-G_4aAVpeARLA/zh-cn_image_0000002563938101.png?HW-CC-KV=V1&HW-CC-Date=20261008T191340Z&HW-CC-Expire=31536000000&HW-CC-Sign=349F145D224E3F16294B77806F2A68B13A94B7B7D20BE8B36864D2197C12D6C7)

6. 当您发布软件包的API Level ≥ 11时，可以设置是否对软件包进行加密。加密的影响、效果详细参见[应用加密](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/code-protect)。
   * 加密：用户在客户端安装的软件包为加密的，安全性较高。
   * 不加密：用户在客户端安装的软件包为不加密的，应用的启动速率较快。

   > 注意
   >
   > 如果元服务的设备仅包含运动手表，则不支持加密。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6a/v3/a0BLy68jTBeeYazB_0-qBQ/zh-cn_image_0000002532938216.png?HW-CC-KV=V1&HW-CC-Date=20261008T191340Z&HW-CC-Expire=31536000000&HW-CC-Sign=962733D0640FEDAC4096B90278C32DB70758250A4A8E5E9991B7FB6816D6B2BB)
7. 当您的元服务正式版本下架之后，再次上架时，选取软件包的版本号要高于历史发布过的全网版本号。不满足要求的软件包无法选择，如下图： ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/26/v3/gFQPr9roT32ZcJGYQsxfsg/zh-cn_image_0000002533098166.png?HW-CC-KV=V1&HW-CC-Date=20261008T191340Z&HW-CC-Expire=31536000000&HW-CC-Sign=DB78277B82B4373EE2C1C6935F742470EFB1E87797A27172D26A67C0855448DB)
