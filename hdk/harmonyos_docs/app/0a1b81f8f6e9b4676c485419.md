# 停止测试

若您发现测试版本存在严重问题、或者已完成测试，可以在"版本列表"页面手动停止测试。测试版本停止测试后，状态会立即变为"已失效"。测试版本失效后，新用户将不再能下载安装测试版本，已安装的用户仍然可以继续使用，直到安装时间超过90天。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/89/v3/bLLmHGdcSr6wkbOY-kYERg/zh-cn_image_0000002314072456.png?HW-CC-KV=V1&HW-CC-Date=20261008T193044Z&HW-CC-Expire=31536000000&HW-CC-Sign=EB68C8F03486C3D8DBCF45AF7E6160C7B9B8C284BC7A56C6A3A6BEAAF2D6E9F7)

用户安装到本地的公开测试版本，在安装后最多可使用90天（不管期间测试任务是否停止），90天后应用将无法启动。
