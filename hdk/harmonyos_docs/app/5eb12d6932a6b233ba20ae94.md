# 素材管理

您可在素材管理页面上传宽*高为600*600px、600*800px、442*248px、1200*600px四种尺寸的主题图，并可设置素材模板的主标题、副标题、按钮名称、关联的POI位置、跳转页面等信息。
> 说明
>
> * 主题图最多支持上传500张，主标题、副标题、按钮名称、跳转页面、嵌入式参数素材最多支持添加100个。
> * 被模板使用的素材不支持编辑和删除。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"APP与元服务"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8/v3/9y1s4_hsRv64lwRH6nqpqg/zh-cn_image_0000002485038992.png?HW-CC-KV=V1&HW-CC-Date=20261008T141135Z&HW-CC-Expire=31536000000&HW-CC-Sign=E018A84410560A2EAF3E8B722F8E6A29428E63E5CF09D73629EFBACAD0EACDD7 "点击放大")
2. 进入"HarmonyOS"页签，您可通过包名、应用名称、应用类型等信息进行筛选，然后在应用列表中点击您的应用/元服务名称。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/52/v3/2dTqTGRWRCm_gnFtPTiFUg/zh-cn_image_0000002471134136.png?HW-CC-KV=V1&HW-CC-Date=20261008T141135Z&HW-CC-Expire=31536000000&HW-CC-Sign=B156F458987284A9AAE8821DFDBB12EBBA6FB2EFE129ED0AECBF1F995247528B)

3. 左侧菜单栏选择"应用上架/元服务上架 > 服务素材"，进入服务素材主界面。
4. 选择"素材管理"页签，上传主题图，并填写其他素材信息。每项素材至少添加1个。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a8/v3/iG4wC1e7QFSug4xEmrXiAA/zh-cn_image_0000002505454138.png?HW-CC-KV=V1&HW-CC-Date=20261008T141135Z&HW-CC-Expire=31536000000&HW-CC-Sign=2E1C686B893D617B7A354A6498F0C02E92DCA3E91F0B4528E7A2C1D74DC7DC91 "点击放大")
