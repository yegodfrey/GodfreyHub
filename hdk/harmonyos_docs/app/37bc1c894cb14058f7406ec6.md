# 管理接入的华为开放能力

华为为HarmonyOS应用/元服务提供了众多开放能力，您可以选择接入，从而增加应用/元服务的能力。

在使用这些开放能力前，您需要开启相关能力。当前有两种方式：

* [直接开启](#ZH-CN_TOPIC_0000002465058093__li8528129202410)：若开放能力支持勾选，表示该能力可直接开启，无需申请。
* [申请开启](#ZH-CN_TOPIC_0000002465058093__li111920517243)：若开放能力不可勾选，表示该能力暂未完全开放，需要申请通过才可开启。

> 说明
>
> 配置的开放能力信息会写入Profile，建议您在申请Profile前完成所需开放能力的配置。如果您在申请Profile后修改了开放能力配置，原有profile将失效，并且不可用于上架，请重新下载Profile。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中找到您的项目，并点击选择需开启开放能力的应用/元服务。
3. 在"项目设置"页面，选择"开放能力管理"页签。 说明
   >
   > 若您没有找到"开放能力管理"页签，请重新创建新的HarmonyOS应用/元服务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c2/v3/lZVCiUfXSCSpQ3RJu6UkFQ/zh-cn_image_0000002607827019.png?HW-CC-KV=V1&HW-CC-Date=20261008T184017Z&HW-CC-Expire=31536000000&HW-CC-Sign=590AE5D38180B8AB91F0517CEE7107B03B7561E4321996F52930CABAADB0D59D)

4. 开启所需的开放能力。详细能力的配置请参考对应开放能力的开发指导，以下仅举例描述大体配置过程。
   * **若开放能力支持勾选，表示该能力可直接开启。**

     在"能力开关"栏勾选需要开启的开放能力开关（以地图服务为例），点击右上角"保存"即可。支持多选，一次操作（勾选或者取消勾选）的能力开关不得超过10个。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/33/v3/w7F70RmiRROn2xfoHskDew/zh-cn_image_0000002577435852.png?HW-CC-KV=V1&HW-CC-Date=20261008T184017Z&HW-CC-Expire=31536000000&HW-CC-Sign=94BD29400F3C24D66DD3092D0D7FB42B964E1005E3B82D485BAE5D1D9738B389)

   * **若开放能力不可勾选，表示该能力暂未完全开放，需申请通过才可开启。**
     1. 以数字盾服务为例，点击对应能力的"申请"按钮。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7c/v3/eDlwBCuSRyuuw6OoOJmaCA/zh-cn_image_0000002613911137.png?HW-CC-KV=V1&HW-CC-Date=20261008T184017Z&HW-CC-Expire=31536000000&HW-CC-Sign=601A1DE6C9107958F9E7518ABEA148E4A04D776FAD23BD1E513A2249BA333A75)

     2. 如弹出"申请规则"提示框，表示当前开放能力存在一定约束限制条件。若确认已满足所有条件，点击"下一步"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/81/v3/L80CjmiTQFOqUIFQAPNxRw/zh-cn_image_0000002716270143.png?HW-CC-KV=V1&HW-CC-Date=20261008T184017Z&HW-CC-Expire=31536000000&HW-CC-Sign=DE99197D290C1781017F5877F78C64619D6C857BBC518FA2F6776FF267217485)

     3. 在"新建业务申请"窗口填写申请原因，必要时可上传附件，然后点击"提交"。 各能力的申请界面与要求可能存在差异，请以实际界面为准。

        ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9e/v3/Cl991a5GRDG-GXJyqX0Mpg/zh-cn_image_0000002583542414.png?HW-CC-KV=V1&HW-CC-Date=20261008T184017Z&HW-CC-Expire=31536000000&HW-CC-Sign=E6C634C9D799273C8E92C0B8CB9432B4F992CE3204D5357BD133F8927699D7C9)

     4. 进入互动中心页面，可看到申请已提交的消息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/49/v3/Lrsn7KwWRqe2PWsaVDEXOA/zh-cn_image_0000002505886755.png?HW-CC-KV=V1&HW-CC-Date=20261008T184017Z&HW-CC-Expire=31536000000&HW-CC-Sign=EB31553AF17E9B8F759BB9EC612373C4EC2A60A8FB4F3006EB716B702A6B4C62)

        返回"开放能力管理"页面，申请状态变为"审核中"。各能力的审批时长已展示在申请页面，请您耐心等待。

        ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0d/v3/6cMfRGVHT2uvoNBqNzpY3Q/zh-cn_image_0000002613915065.png?HW-CC-KV=V1&HW-CC-Date=20261008T184017Z&HW-CC-Expire=31536000000&HW-CC-Sign=8F763E2C900887B8DA07E2728B6F734E5F15EBCF1778A1185D90A46EFC1F9049)

        申请审批通过后，互动中心会发送通知消息给您，同时您也会收到邮件通知。申请状态变为"已通过"，同时对应的能力开关会为您自动开启。

        ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cc/v3/AjV-QEe8TVaoSpKIXF7Y7A/zh-cn_image_0000002614079185.png?HW-CC-KV=V1&HW-CC-Date=20261008T184017Z&HW-CC-Expire=31536000000&HW-CC-Sign=A41855138B7AB34D0E7C9FDE30FE76D2683CFC617CFCF9997A98096B8E290EFE)

        > 说明
        > * 后续如需关闭开放能力，可取消勾选对应的能力开关，点击"保存"。一次操作的能力开关不得超过10个。修改能力开关状态后，请务必重新下载Profile。
        > * 若开放能力包含主能力和子能力，需参考以上步骤分别申请主能力和子能力。以华为账号服务为例，"华为账号"为主能力，其下包含"获取收货地址"等多个子能力。当前AGC已默认为应用/元服务开启"华为账号"主能力，子能力则需分别自行申请开启。
