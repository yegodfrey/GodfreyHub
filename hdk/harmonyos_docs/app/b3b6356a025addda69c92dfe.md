# 分发分析

您可以在"分发分析"页签下查看Android应用的使用情况和销售情况数据，以及快应用的相关数据报表：

* Android应用： 通过"[下载安装](#section14231122115416)"、"[分发实时数据](#section20722103818397)"、"[预约](#section20681916192113)"、"[游戏新增与留存](#section6674513132314)"和"[内容报表](#section9624112162717)"衡量用户安装及持续使用应用的情况。

  通过"[付费下载](#section1195022172614)"、"[付费下载明细](#section10177517266)"了解应用的销售情况。

* 快应用： 通过"[快应用用户报表](#section1287517408189)"和"[快应用运行报表](#section556275516317)"了解快应用的用户和运行数据。

#### 指标说明

|指标|说明|
|:-----------|:----------------------------------------------------------------|
|有效曝光次数|应用在华为应用市场推荐、排行榜、搜索等资源位被展示次数，图片露出50%以上且曝光时间大于1s才算有效曝光。|
|ICON点击次数|应用在华为应用市场内曝光的ICON被点击的次数。|
|有效曝光点击率|ICON曝光次数/有效曝光。|
|详情页访问次数（客户端）|在华为应用市场客户端统计的应用详情页被浏览的次数。|
|总下载成功次数|计算方式：更新下载成功次数+新下载成功次数。|
|更新下载成功次数|用户通过华为应用市场更新应用版本产生的下载成功次数。 计算方式：只要是在应用市场检测到要更新的包，更新下载成功后都会记入一次更新。|
|新下载成功次数|用户通过华为应用市场新下载成功次数。 计算方式：第一次下载成功算一次，卸载后重新下载也算一次。|
|详情页转化率|计算方式：详情页新下载次数（仅包括详情页带来的新下载次数）/详情页访问次数。|
|安装成功次数|应用在华为应用市场安装成功次数。|
|新安装成功次数|用户通过华为应用市场新下载并安装成功的次数。|
|安装成功率|新下载应用安装成功的比例。 计算方式：新安装成功次数/新下载成功次数。|
|卸载次数|* 卸载次数：从华为应用市场新安装的应用被卸载的次数。 * 总卸载次数：从所有渠道安装/更新的应用被卸载的次数。|
|分享次数|中国大陆区域，应用被分享的次数。|

#### 分发实时数据

"分发实时数据"为您展示了查询当日和前日的各项指标的动态对比数据，当您的数据波动达到一定数值时，AGC会根据实际情况为您推荐对应服务，帮助您提升数据表现。  

#### 服务开通条件

只有当您满足以下任意一项开通条件，并且通过华为运营人员的月度审核时，才能使用分发实时数据服务：

* 至少上架过一款HarmonyOS应用/元服务
* 商推等级达到银级以上
* 游戏联运等级达到白金级及以上
* 应用联运流水排名TOP 50
* 使用AGC付费服务（含生态市场、开发者学堂等服务）且消费金额不低于10万元
* 使用以下AGC服务至少3个：认证服务、云函数、云数据库、云存储、Dynamic Ability、远程配置、App Linking、应用内消息、预测服务、性能服务、崩溃服务  
  ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250905102217.83924155636570554016689137519387:50001231000000:2800:B6F3CB61E522C9031E5B8A1673BF235952E38C16C2811663E7AE768EE299E5C6.png)  
华为运营人员会于每月月末核查，并为符合上述任意条件的开发者于次月开通分发实时数据服务。通过审核后，您将会收到互动中心的信息通知。已开通服务但不符合条件者会被及时从已开通名单中剔除。
