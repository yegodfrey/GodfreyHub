# ConfigValues

|Class Info|
|:--------------------------------------------------------------------------------------------------------------|
|ConfigValues 存储数据的类，在fetch方法中返回的ConfigValues对象用于调用apply方法。针对fetch方法返回的ConfigValues对象，只是从云端同步下来的数据，不包含default数据。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------------------------------|:------------------------------------------------------------------|
|boolean|[containKey](#section17211816175910)(key: string) 配置数据中是否包含指定的Key值。|
|string | number | boolean | [] | undefined|[getValue](#section578016104015)(key: string) 返回Key对应的Value值。|

## Public Methods

### containKey

|Method|
|:-------------------------------------------------|
|containKey(key: string): boolean 配置数据中是否包含指定的Key值。|

**Parameters**

|Parameter|Description|
|:--------|:-----------------|
|key|要查询的Key值，string类型。|

**Return**

|Type|Description|
|:------|:---------------------------------|
|boolean|如果配置数据中包含指定的Key值，返回true，否则返回false。|

### getValue

|Method|
|:--------------------------------------------------------------------------------------|
|getValue(key: string): string | number | boolean | [] | undefined 从配置集合中获取指定Key的Value值。|

**Parameters**

|Parameter|Description|
|:--------|:----------|
|key|指定的Key值。|

**Return**

|Type|Description|
|:-----------------------------------------|:--------------------------------------------------------------------------------------------------|
|string | number | boolean | [] | undefined|Value值。 支持多种数据类型： * string：字符串类型值 * number：数字类型值 * boolean：布尔类型值 * []：数组类型值 如果Key值不存在，则返回undefined。|
