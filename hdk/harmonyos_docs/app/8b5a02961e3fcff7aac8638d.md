# 管理应用

在云调试服务主界面，选择“我的信息”页签，点击“一帧多屏”后，您可以在下方的“应用”页签上传、删除应用，或查看已上传应用的相关信息。

                * 上传应用：点击“本地上传”区域，从本地上传HAP或APP格式的应用包。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6e/v3/mrK62AwISBmbfpbq50mm2w/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043442Z&HW-CC-Expire=86400&HW-CC-Sign=07604D414E1B8846ADCAA6E58ED2C47B2C9FE0B23BBE74DF16068EA20EB10FE7)

上传应用包时，系统会对包名、版本和SHA256进行重复性校验。允许上传具有相同包名和版本但SHA256不同的应用包。如果待上传应用包的包名、版本和SHA256与已成功上传的应用包完全一致，则无法上传并弹框提示您。

                * 删除应用：鼠标悬停在应用图框上方，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6a/v3/HsI1SP_VRP67Cnx4rnSQnQ/zh-cn_image_0000002553155702.png?HW-CC-KV=V1&HW-CC-Date=20261005T043442Z&HW-CC-Expire=86400&HW-CC-Sign=DD343141AACA18740CEE40EA86500DB9DF5386A61475FCB5C453E997A3E64355)即可删除已上传的应用。
                * 查看应用信息：点击“更多”，在弹出框中将显示已上传应用包的大小、上传时间等信息。
