# 降级到免费档套餐

升级到按量付费档套餐后，您也可以选择降级，将付费档关闭，仅使用免费配额。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中点击您的项目，进入"项目设置"页面。
3. 点击"项目套餐"页签，进入项目套餐列表页面。
4. 找到您需要降级的套餐，点击"降级到免费档"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1a/v3/Zi64c_wfTZC8iq-K19hFLg/zh-cn_image_0000002374036834.png?HW-CC-KV=V1&HW-CC-Date=20260909T153857Z&HW-CC-Expire=31536000000&HW-CC-Sign=8CC11FE3CB71123E992D2F58E05DDBB49FE417E6BE6BCEA9614B0AB1614743CB)

5. 仔细阅读"确认降级"提示后，点击"确认"，即可完成套餐降级。套餐降级立刻生效。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d4/v3/k2-BCz4JSGOebcWP0I2Tkw/zh-cn_image_0000002247764460.png?HW-CC-KV=V1&HW-CC-Date=20260909T153857Z&HW-CC-Expire=31536000000&HW-CC-Sign=B6A67A0E20FD26184A69BEFFF9B481FDFEF6381EAF0B0B38DE7BA6DAD1248F47)

6. 返回项目套餐列表，可看到套餐名后缀已变更为"免费档"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6a/v3/MEzxytadS0CL0DiFnD73TA/zh-cn_image_0000002374038150.png?HW-CC-KV=V1&HW-CC-Date=20260909T153857Z&HW-CC-Expire=31536000000&HW-CC-Sign=01CD1CF99AD85F852DCBF046C1CB5729D2921CC5798D0FFF4B05D6B440DAD899)
