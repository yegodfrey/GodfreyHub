# 获取HarmonyOS应用安装失败的报表文件

## 功能介绍

获取HarmonyOS应用安装失败报表数据的CSV或者Excel文件地址。

接口调用者的角色：账号持有者、国内管理员、App管理员、国内运营。

## 接口原型

|承载协议|HTTPS GET|
|-----|---------------------------------------------------------------------------------------------------------------|
|接口方向|开发者服务器 -> 华为服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/report/harmony-report/v1/harmony/installFailedAnalysisExport/*{appId}*|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

### Query

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:-------------------|:----------|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|startTime|M|String|查询开始时间。 UTC时间。 格式：*YYYYMMDD* **startTime** 和**endTime**之间不超过180天。|
|endTime|M|String|查询结束时间。 UTC时间。 格式：*YYYYMMDD* **startTime** 和**endTime**之间不超过180天。|
|timeType|O|String|基于时间类型查询，取值范围： * day：按天查询 * week：按周查询 * month：按月查询|
|language|O|String|查询语言。 报表title会根据不同语言来展现。 只支持简体中文（zh-CN）, 美式英文（en-US），俄文（ru-RU）。|
|filterCondition|O|List<String>|过滤器，取值范围： * countryId：按国家/地区过滤。 * deviceName：按机型过滤。 * downloadType：按下载类型过滤。 * appVersion：按应用版本过滤。 如果不传，默认无过滤器。 URL示例： &filterCondition=countryId&filterCondition=deviceName&filterCondition=downloadType|
|filterConditionValue|O|List<String>|过滤器对应的值。 * 如果过滤器为countryId，此参数的取值为国家码的字符串数组，例如"CN, AL, AD, AT"。具体国家码列表参考[国家码](https://developer.huawei.com/consumer/cn/doc/app/agc-help-connect-api-appendix-countrycode-0000002236201362)。传入"all"表示查询全球，"all"不区分大小写。 * 如果过滤器为deviceName，此参数的取值为设备型号的名称，如： "Mate30Pro-5G版"、"P40-lite"、"P30-Pro"、"P40-lite-5G"、"nova7-SE"、"nova7_SE_5G乐活版"、"nova6-5G版"、"mate20"。 * 如果过滤器为downloadType，此参数的取值为：1（新下载）、2（更新下载）。 * 如果过滤器为appVersion，此参数的取值为应用版本，多个版本以英文逗号分隔，如："1.0.0,2.0.0"。"all"表示查询所有应用版本，"all"不区分大小写。 如果传入多个过滤器，使用多个filterConditionValue表示，顺序必须与filterCondition中过滤器的顺序一致。URL示例： &filterConditionValue=CN&filterConditionValue=mate20&filterConditionValue=1&filterConditionValue=1.0.0|
|groupBy|O|String|数据统计的分组信息，支持按如下依据分组。取值范围： * dateAndCodeAndReason：按日期、安装失败错误码和错误原因分组 * deviceNameAndCodeAndReason：按机型、安装失败错误码和错误原因分组 * downloadTypeAndCodeAndReason：按下载类型、安装失败错误码和错误原因分组 * countryIdAndCodeAndReason：按国家/地区、安装失败错误码和错误原因分组 * appVersionAndCodeAndReason：按应用版本、安装失败错误码和错误原因分组|
|exportType|O|String|导出文件类型。 取值范围： * CSV：导出CSV文件格式 * EXCEL：导出Excel文件格式 默认值：CSV。|

## 响应参数

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------|:----------|:------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|fileURL|M|String|导出CSV或Excel文件的路径。 报表文件中字段语言由**language** 参数指定，首个字段为**groupBy**参数中指定的数据统计分组类型。 文件中包含的字段说明请参见[HarmonyOS应用安装失败的报表数据说明](#ZH-CN_TOPIC_0000002236041554__zh-cn_topic_0000002050317844_zh-cn_topic_0000001058592408_p87115333411)。|
|ret|M|[ConnectRet](https://developer.huawei.com/consumer/cn/doc/app/agc-help-report-api-data-connectret-0000002273219845)|包含返回码及描述信息的结果。|

**HarmonyOS应用安装失败的** **报表数据说明**

|字段名|字段含义|
|:--------|:--------------------------------------------------|
|日期|数据统计日期。|
|机型|数据统计按机型进行分组。|
|下载类型|数据统计按下载类型进行分组。|
|应用版本|数据统计按应用版本进行分组。|
|国家/地区|数据统计按国家或地区进行分组。|
|错误代码|安装失败返回的错误码。|
|错误原因|安装失败的错误原因。|
|安装失败设备数|时间间隔范围内的安装失败设备数。|
|安装失败设备数占比|时间间隔范围内的安装失败设备数占比（统计日当日该错误码对应的安装失败设备数/统计周期内总安装设备数）。|
|安装失败次数|时间间隔范围内的安装失败次数。|
|安装失败次数占比|时间间隔范围内的安装失败次数占比（统计日当日该错误码对应的安装失败次数/统计周期内总安装次数）。|
