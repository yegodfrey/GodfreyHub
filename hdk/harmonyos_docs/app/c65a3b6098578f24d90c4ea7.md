# 更新应用软件包信息

#### 功能介绍

APP软件包上传完成后，通过该接口刷新HarmonyOS应用/元服务的软件包信息。  
![](https://media:101782378030823885)  
该接口支持解析软件包中的构建版本号（buildVersion），用于区分同一主版本下的不同测试子版本。解析完成后，可以从查询应用软件包信息接口返回的[packageInfo](https://developer.huawei.com/consumer/cn/doc/app/agc-help-publish-api-query-package-info-0000002328848469#ZH-CN_TOPIC_0000002328848469__p2219104885313)参数中获取buildVersion字段。

接口调用者的角色：账号持有者、管理员、APP管理员、运营。  

#### 接口原型

|承载协议|HTTPS PUT|
|接口方向|开发者服务器 -\> 华为服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/publish/v3/app-package-info|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|
|-----|--------------------------------------------------------------------|

#### 请求参数

<br />

#### Header

![](https://media:101782378030849886)  
本接口支持使用Service Account方式和API客户端方式，二者区别请参见[获取服务端授权](https://developer.huawei.com/consumer/cn/doc/app/agc-help-connect-api-obtain-server-auth-0000002271134661)。

Service Account方式：  

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Authorization|M|String|认证信息，格式为"Authorization: Bearer ${JWT}"。JWT为[通过Service Account方式获取授权](https://developer.huawei.com/consumer/cn/doc/app/agc-help-connect-api-obtain-server-auth-0000002271134661#section104621343151212)中获取的鉴权令牌。|

API客户端方式：  

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|M|String|客户端ID，获取方法参考[创建API客户端](https://developer.huawei.com/consumer/cn/doc/app/agc-help-connect-api-obtain-server-auth-0000002271134661#section103mcpsimp)。|
|Authorization|M|String|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/app/agc-help-connect-api-obtain-server-auth-0000002271134661#section09831133141712)中获取的access_token。|

#### Query

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:-----------|:----------|:----------|:----------------------------------|
|appId|M|String|需要更新的应用ID。|
|releaseType|O|Integer(32)|应用发布方式。 取值范围： * 1：全网 默认值：1|
|releasePhase|O|Integer(32)|分阶段发布标识。 取值范围： * 0：全网 * 3：分阶段 默认值：0|

#### Body

请求Body中使用JSON格式携带更新的应用软件包信息，参数如下表所示。  

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:-------|:----------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|fileName|M|String(255)|文件名称，包括文件的后缀名。|
|objectId|M|String(512)|文件在文件服务器中的对象ID。 说明： objectId的获取流程：先调用[获取上传文件地址](https://developer.huawei.com/consumer/cn/doc/app/agc-help-upload-api-upload-url-0000002236201294)接口，然后调用[上传文件](https://developer.huawei.com/consumer/cn/doc/app/agc-help-upload-api-upload-file-0000002271160621)接口上传文件，最后得到[获取上传文件地址](https://developer.huawei.com/consumer/cn/doc/app/agc-help-upload-api-upload-url-0000002236201294)接口返回的objectId。|

#### 请求示例

```
PUT /api/publish/v3/app-package-info?appId=10******57 HTTP/1.1
Host: connect-api.cloud.huawei.com
client_id: 4141******68
Content-Type: application/json
Authorization: Bearer *******
{
      "fileName": "c******d.app",
      "objectId": "CN/2024112702/*****.app"
}
```

#### 响应参数

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:--------|:----------|:-------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------|
|ret|M|[ConnectRet](https://developer.huawei.com/consumer/cn/doc/app/agc-help-publish-api-data-connectret-0000002271160589)|包含返回码及描述信息的结果。|
|packageId|O|String(32)|软件包上传后内部id，用于[查询软件包编译状态](https://developer.huawei.com/consumer/cn/doc/app/agc-help-publish-api-query-compile-status-0000002236041434)接口调用。|

```

    "ret": {
        "code": 0,
        "msg": "success"
    },
    "packageId": "1573*******5952"
}
```
