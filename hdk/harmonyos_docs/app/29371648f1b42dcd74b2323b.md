# 调试应用

通过云调试服务，您可以在不同HarmonyOS 5及以上设备上调试HAP/APP格式的应用，从而提前发现并解决问题。
> 说明
>
> 在本场景下，如无特殊说明，"应用"所指代的对象包括HarmonyOS 5及以上应用和元服务。

## 前提条件

* 调试应用前必须先[申请调试设备](https://developer.huawei.com/consumer/cn/doc/app/agc-help-clouddebug-applyequip-0000002254916518)。
* 请准备好已[配置签名信息](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-publish-app#section945904791115)的debug或release版本应用包，且应用包大小不可超过4GB。

## 上传应用

1. 设备初始化成功后，系统将自动进入"单机调试"页面。若您申请的设备为折叠电脑，请勿切换至"显示器模式"，因为该模式会导致网络中断且无法进行其他操作，请点击"确定"继续调试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9a/v3/dneEtxrLTDyHmRcCFySngg/zh-cn_image_0000002747383745.png?HW-CC-KV=V1&HW-CC-Date=20261008T145818Z&HW-CC-Expire=31536000000&HW-CC-Sign=9989A9CE6A64A70E803B7A33F0C00AAD7600252249AFEA971D46D33F8AEE3491)

2. 点击右侧区域"应用"页签下的"本地上传"，上传本地待调试的应用包。上传完成后，应用自动安装。应用安装成功后，您可在左侧设备区域查看安装完成的应用。 您还可以在"我的信息"页签下上传应用，具体操作方法请参见[管理应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-clouddebug-manageapp-0000002578460771)。

   > 说明
   > * 当前支持上传和安装已配置签名信息的debug和release版本应用包，暂不支持In-house应用。若应用包未配置签名信息，将被系统拦截，无法上传。
   > * 上传应用包时，系统会对包名、版本和SHA256进行重复性校验。允许上传具有相同包名和版本但SHA256不同的应用包。如果待上传应用包的包名、版本和SHA256与已成功上传的应用包完全一致，则无法上传并弹框提示您。
   > * HAP和APP格式的HarmonyOS应用在真机设备上安装完成后均会自动打开，无需您手动操作。

## 调试说明

目前支持以下两种方式调试应用，请根据实际需求选择：

* 方式一：[PC上调试应用](#section081042915213)

  应用安装完成后，您可以直接在"单机调试"页面通过鼠标滑动、点击等操作来调试应用。
* 方式二：[扫码在本地手机上调试应用](#section164431443104)

  应用安装完成后，将鼠标悬停在"单机调试"页面的二维码上，然后在您的手机上左滑进入负一屏界面，触摸右上角按钮扫描二维码，将调试界面投屏到您的手机上进行调试。

### PC上调试应用

完成应用安装后，返回"单机调试"页面，您可在左侧设备区域通过鼠标滑动、点击等远程操作调试设备，了解应用的运行和使用情况。

您还可以在右侧区域的不同页签（基于所选调试设备动态刷新）中，根据实际需要进行其他调试操作：

* 应用：您可以手动安装或删除已上传的其他应用。
* [控制参数](https://developer.huawei.com/consumer/cn/doc/app/agc-help-clouddebug-location-0000002289516745)：您可以通过控制参数面板与调试设备进行交互，支持剪贴板同步、打开网页、推送图片至调试设备、Shell脚本调试和模拟定位。
* [截屏](https://developer.huawei.com/consumer/cn/doc/app/agc-help-clouddebug-capturescreen-0000002254916522)：当您在调试应用过程中遇到需要保存的特殊场景信息时，可以通过截屏功能保存场景界面，方便后续定位问题。
* [Hilog](https://developer.huawei.com/consumer/cn/doc/app/agc-help-clouddebug-viewlog-0000002289629825)：您可以在线查看和导出设备运行期间的系统日志和应用日志。

## 设置权限

为满足开发者的日常调试需求，云调试服务对远程真机设备开放了部分"设置"功能，例如开启深色模式、切换输入法等。在修改远程真机设备的系统设置之前，请先按照以下步骤开通设置权限。

1. 在调试界面，点击右上角的"设置权限"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/78/v3/bOH5ffbAQeyokzSZFoOL8Q/zh-cn_image_0000002693208892.png?HW-CC-KV=V1&HW-CC-Date=20261008T145818Z&HW-CC-Expire=31536000000&HW-CC-Sign=9168571140DC2C17554DD4B6A3A38FC24CC375E1D646028FE4FAAEAAFA59C7F4 "点击放大")

2. 请仔细阅读"设置项权限申请说明"弹窗中的远程真机使用规范说明。如确认需要申请设置权限，请勾选选框，然后点击"申请权限"。 说明
   > * 基于安全风险考虑，开通"设置权限"后，云调试服务仅开放部分"设置"功能，以下高风险操作仍被禁止：设置锁屏密码、登录/修改华为账号、管理云空间、开启设备锁/查找设备、尝试Root、自行升级或降级设备操作系统版本、恢复出厂设置或刷机，以及其他任何因非正常使用行为导致设备无法恢复或严重影响后续用户使用的不可逆操作等。
   > * 每日申请设置权限的次数上限为10次，以账号为维度计数。规则如下：
   >   * 统计周期：自然日（00:00~23:59），以北京时间为准。
   >   * 计数规则：以点击"申请权限"按钮的时间为准，每成功申请1次计数加1。
   >   * 重置规则**：**每日00:00自动重置所有开发者账号的申请次数。
   >   * 权限有效期**：**单次调试结束后，权限将自动收回。如需再次进行设置操作，需重新申请权限。
