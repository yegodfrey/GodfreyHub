# 管理服务端密钥

华为服务器要求对每个服务端API请求进行JSON Web Token（JWT）授权。您可以使用从[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)下载的API密钥生成JWT。您用私钥对Token签名生成JWT，授权您发起的服务端API请求。
