# 符号表

符号表是程序编译过程中生成的一种映射数据文件，其可用于将崩溃等问题的堆栈与日志还原为可读的源码。符号表页面提供符号表的查看、上传、下载与删除的管理能力。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到对应项目，在项目下的应用列表中点击对应应用/元服务。
3. 左侧导航栏选择"质量 \> APMS \> 配置管理"，进入配置管理主界面。
4. 选择"符号表"页签，进入符号表管理页面。 ![](https://media:101782378081797134)

   以下为符号表页面对应的筛选条件说明：  

   |--------|------------------------------------------------------------------------------|
   |参数|说明|
   |应用版本|应用的版本标识|
   |符号表文件|符号表文件名称|
   |类型|符号表文件名称类型，包括： * so：Native(C/C++)符号表文件 * map：ArkTS/JS符号表文件 * json：ArkTS/JS符号表文件|
   |Build ID|Native(C/C++)符号表文件的构建产生唯一标识，可用于还原其对应构建产物二进制执行过程中产生的崩溃堆栈行。|
   |大小|符号表文件的体积大小|
   |上传时间|符号表文件的上传时间|

5. 点击操作栏的"下载"按钮可以下载指定符号表文件，点击"删除"按钮可以删除指定的符号表文件。 ![](https://media:101782378081832135)

#### 符号表上传

![](https://media:101782378081863136)

* 点击右上角的"点击上传"按钮，可以将符号表文件上传至后台，用于后续崩溃等故障问题分析的堆栈和日志的还原。
* 上传时需选择符号表所对应的应用版本。故障分析页面在还原堆栈时，将根据产生崩溃堆栈的应用版本，以及崩溃堆栈中的符号表文件名选择对应的符号表文件还原异常日志。
* 同时支持将相同版本的符号表文件打包成zip文件批量上传，但需确保所有so文件位于zip压缩包的根目录，且压缩后的zip文件小于3G。

![](https://media:101782378081888137)  
如果上传过相同文件名+应用版本的符号表文件，继续上传将会覆盖之前上传的文件。  

#### 符号表获取

方式：DevEco Studio构建生成

DevEco Studio是HarmonyOS应用的官方开发工具，在构建应用（尤其是Release包）时，从DevEco Studio NEXT Developer Beta2（5.0.3.502）版本开始不会自动生成符号表文件，需要手动开启。具体配置和路径如下：

* 构建配置：需确保项目的build-profile.json5或模块的build.json5中"开启符号表生成"开关处于开启状态（默认已关闭，需要手动开启配置，详情请参见"[配置CPP](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-hvigor-cpp)" ）。
* 生成路径：经DevEco编译构建，生成在工程的/build/default/intermediates/libs目录下，默认是不带符号的版本。可通过Linux file命令查询二进制文件的BuildID以核对是否匹配。其中，BuildID是用于标识二进制文件的唯一标识符，通常由编译器在编译时生成，not stripped表示该动态库是包含符号表的。
