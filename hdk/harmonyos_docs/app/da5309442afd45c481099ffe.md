# 配置隐私声明

发布元服务时，您需要提供隐私政策，便于用户了解元服务的数据收集和使用情况。

元服务必须先使用AGC的隐私声明托管服务生成自己的隐私声明，才能在版本信息页面选择到。详细内容参见[配置隐私政策（元服务）](https://developer.huawei.com/consumer/cn/doc/app/agc-help-privacy-policy-atomic-0000002317135133)和[配置用户协议](https://developer.huawei.com/consumer/cn/doc/app/agc-help-privacy-user-agreement-0000002282265450)。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"快速开始"中的"元服务一站式平台"卡片。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9b/v3/SQ6Dc4zARFqCGRUBkvp1zg/zh-cn_image_0000002529682783.png?HW-CC-KV=V1&HW-CC-Date=20261008T170337Z&HW-CC-Expire=31536000000&HW-CC-Sign=B1ECECB80646F4D2BD6125CF129AC2A1DC986A5224D8EAA778398BC1E464B493)

2. 在左上角下拉列表选择要发布的元服务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/51/v3/qYuSkBH2Ru-rT4QykxUr7g/zh-cn_image_0000002566867053.png?HW-CC-KV=V1&HW-CC-Date=20261008T170337Z&HW-CC-Expire=31536000000&HW-CC-Sign=C14D00CB007AD7F29F401FE6F299622C8B82BA1CD6823846786511086DDC97FF)

3. 左侧导航选择"元服务上架 > 版本信息"下待发布的版本。
4. 进入"隐私声明"区域，选择您生成的隐私政策和用户协议。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a8/v3/aJoqprFATP2ib426R6sDuw/zh-cn_image_0000002328505333.png?HW-CC-KV=V1&HW-CC-Date=20261008T170337Z&HW-CC-Expire=31536000000&HW-CC-Sign=74BD6681F1998C298EE19340D78D5BD56E458D5639F5C2B978283487019841B6)
