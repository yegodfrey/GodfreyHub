# 配置隐私声明

发布元服务时，您需要提供隐私政策，便于用户了解元服务的数据收集和使用情况。

元服务必须先使用AGC的隐私声明托管服务生成自己的隐私声明，才能在版本信息页面选择到。详细内容参见[配置隐私政策（元服务）](https://developer.huawei.com/consumer/cn/doc/app/agc-help-privacy-policy-atomic-0000002317135133)和[配置用户协议](https://developer.huawei.com/consumer/cn/doc/app/agc-help-privacy-user-agreement-0000002282265450)。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"快速开始"中的"元服务一站式平台"卡片。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9b/v3/SQ6Dc4zARFqCGRUBkvp1zg/zh-cn_image_0000002529682783.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=A8B3DF2BBE716B64B9329D58BE6BC1F62C11BB8E82E90D57174CCF798701BE77)

2. 在左上角下拉列表选择要发布的元服务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/51/v3/qYuSkBH2Ru-rT4QykxUr7g/zh-cn_image_0000002566867053.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=23E53A0227D95A2192C15FB89D02A31AEABC8F85B93FB55C15578453367D82FF)

3. 左侧导航选择"元服务上架 > 版本信息"下待发布的版本。
4. 进入"隐私声明"区域，选择您生成的隐私政策和用户协议。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a8/v3/aJoqprFATP2ib426R6sDuw/zh-cn_image_0000002328505333.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=018D9219AA84F5DABAF43E40A48A8FDF457CD4AF37C32EAD0E4172DB76AC3033)
