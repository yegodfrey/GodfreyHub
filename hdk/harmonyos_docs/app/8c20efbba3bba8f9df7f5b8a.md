# 创建iOS应用

如果您需要在华为应用市场发布您的应用，或者使用AGC提供的各类服务，您需要先在AGC中创建应用。

## 前提条件

您已[注册华为开发者账号](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)并[实名认证](https://developer.huawei.com/consumer/cn/doc/start/itrna-0000001076878172)。

## 操作步骤

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)，点击"开发与服务"。
2. 在项目列表中点击您的项目。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251223163107.30065098297654461656680933211506:50001231000000:2800:A890B1D34C016A73019598F9D6D630E64918A1AA9B02600AE8ABF622892F2F03.png)

3. 若项目中没有应用，在"项目设置"页面中点击"添加应用"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251223163107.80810067612022365888483952764186:50001231000000:2800:EB14E55320B26D6C076012C9AE9564355508A745419C7B1FAACBA92782ACC3A5.png)

   若项目中已有应用，展开顶部"选择应用"列表框，点击"添加应用"。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251223163107.73306868427952389292001151791628:50001231000000:2800:3806B6559BD7CD4D4DC6CF18C80E15A2563C972FB265FF0FA90D025784E150E5.png)


4. 在"添加应用"页面中设置参数后，点击"确认"。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251223163107.96219013827617216562936470298622:50001231000000:2800:FB429CA50A5018EC314C6CC55B6DFF4E541C09E18B24CC5791CDD50B72D85AC4.png)

   |参数|说明|
   |:-----------|:------------------------------|
   |选择平台|选择"iOS"。 > 说明 > macOS平台也请选择iOS。|
   |软件包ID|iOS应用的唯一标识，即应用包名。|
   |应用名称|应用名称，不能含有"黄赌毒"等低俗敏感字样。|
   |App Store ID|Apple 账号。|
