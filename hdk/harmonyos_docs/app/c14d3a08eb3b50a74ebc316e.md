# 内容预约

## 概述

您的应用在鸿蒙应用市场上发布之后，您可以通过内容预约服务，在活动上线前向用户推广您应用内的相关活动，高效触达目标用户，提高用户活跃度。

如果您的鸿蒙应用使用内容预约服务，首先需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)上架应用，再在[应用推广引擎](https://developer.huawei.com/consumer/cn/service/apcs/aggrowth/chassis/resources/scheduledService/mgt)使用内容预约服务，以便在应用市场推广您应用内的活动。

内容预约审核通过后，应用市场将出现对应的内容预约卡片，用户可以通过点击卡片查看对应活动并体验您的应用，如果用户没有下载，将引导用户下载应用；如果用户已经安装应用，则可以在活动上线时进行提示并跳转至应用内对应页面。

## **前提条件**

1. 您的鸿蒙应用已在鸿蒙应用市场发布上架。
2. 若未在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)创建鸿蒙应用，请参考[创建HarmonyOS应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-create-app-0000002247955506)开始创建应用并提交应用上架。
3. 登录应用推广引擎时，使用有对应权限的账号。

## **账号授权**

若您登录的是账号持有者账号，则无需授权。若您登录的是协作者账号，请根据以下步骤让持有者给您授权。

* 账号持有者账号登录[应用推广引擎](https://developer.huawei.com/consumer/cn/service/apcs/aggrowth/chassis/workbench)。
* 点击右上角-账号管理-新增按钮。若您的账号已被账号持有者授予过其他权限，请找到对应的华为账号，编辑权限即可。![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/84/v3/QxCBAfyKQCCO50k-BScLEw/zh-cn_image_0000002658513729.png?HW-CC-KV=V1&HW-CC-Date=20260929T062030Z&HW-CC-Expire=31536000000&HW-CC-Sign=9E296B256CF523BABB58CA46EA13C32686CA87EDD924D879AFF3615DA059535E "点击放大")
* 填写需增加协作者对应权限的账号id（手机号/邮箱），勾选内容推广，预约宣发权限，选择授权应用，并保存。

## **FAQ**

**1.为什么创建内容预约任务时选不到我的应用** **？**

开发者您好，一般有两种情况：1.您的应用在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)状态异常，请确认应用是已经正常上架的状态。2.您登录应用推广引擎的开发者账号没有权限，请用主账号或有授权的账号创建内容预约任务。
