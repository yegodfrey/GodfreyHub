# 联系我们

## **1. 审核问题咨询及申诉**

### **AI助手（常见问题自助解答场景）**

如需快速咨询应用审核常见问题，可使用[AI助手](https://developer.huawei.com/consumer/cn/customerService/)获取自助解答。

温馨提示：[AI助手](https://developer.huawei.com/consumer/cn/customerService/)回复内容仅供参考，具体以人工审核结果为准。如需进一步协助，可咨询人工客服。

### **互动中心（通用咨询&申诉场景）**

若您对应用审核结果有任何疑问或需要申诉（包括附件材料传递等），欢迎通过[互动中心平台](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/interactive)联系我们。

1、 从"应用审核"模块推送的审核相关消息通知窗口，直接回复即可召唤人工。

2、 "申诉与反馈"模块，提交"[申诉](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/interactive/appeal)"或者新建"[问题反馈](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/interactive/feedback)"。

人工服务时间：周一至周五 08: 30-12: 00，13: 30-18: 00 （法定节假日除外）。

请参考[互动中心指导文档](https://developer.huawei.com/consumer/cn/doc/app/agc-help-interaction-center-0000002276985946)。

### **电话沟通（快速咨询场景）**

若您需要对某款应用的审核意见进行快速修改指导，可通过[电话](https://developer.huawei.com/consumer/cn/service/apcs/aggrowth/chassis/contactUs/appReview)与我们沟通。请点击"立即联系"并填写您需要咨询的问题，我们收到后会尽快与您联系，请保持电话畅通。

人工服务时间：周一至周五 08: 30-12: 00，13：30-18: 00 （法定节假日除外）。
> 说明
>
> 该功能目前处于分阶段开放中，如您看到"内测中"提示，建议先通过互动中心渠道反馈咨询。

### **电子邮件（暂无AppGallery Connect账号场景）**

如果您没有AppGallery Connect账号，但对应用审核意见有疑问或需要申诉，可将问题一次性详细描述后发送邮件至 developer@huawei.com 联系我们。

人工服务时间：周一至周五 08: 30-12: 00，13: 30-18: 00 （法定假期除外）。

## **2. 审核政策沟通交流**

### **预约1V1专家沟通**

若您需要探讨应用审核政策、审核管控理念，希望提前研讨规划以提升应用审核通过率，可申请[1v1审核预约沟通](https://developer.huawei.com/consumer/cn/service/apcs/aggrowth/chassis/contactUs/appReview)服务，申请通过后，我们的审核专家将通过华为云会议与您展开深度交流。
> 说明
>
> 1、预约申请名额有限，具体开放时间请您在申请页面留意预约日期详情。
>
> 2、每个自然年内，每位开发者可以申请3次1V1专家沟通服务，建议您仅在确有需要时提交申请。

## **3. 审核加急**

多数应用的上架申请一般需要1-3个工作日，如若您遇到紧急情况（如需修复应用严重问题、发布紧急活动等）可[申请审核加急](https://developer.huawei.com/consumer/cn/service/apcs/aggrowth/chassis/contactUs/appReview)，以加快上架进度。
> 说明
>
> 1、当前仅HarmonyOS应用或元服务（Harmony 5.0及以上）支持申请审核加急，在申请审核加急之前，请确保您已提交应用上架审核申请。
>
> 2、在一个自然年内，每个应用可以申请3次审核加急，请您仅在必要的情况下申请。
>
> 3、若发生加急队列拥堵、版本变化较大或其他特殊情况，可能会导致审核时间延长。
