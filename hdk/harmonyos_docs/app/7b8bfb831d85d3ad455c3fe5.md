# 应用素材规范

AppGallery Connect对您上传的应用素材数量、大小、分辨率等有相关限制。上传前，建议您先仔细了解素材规范。

|**应用素材**||**数量**|**比例**|**分辨率**|**格式**及大小|**备注**|
|:-|-|:-----|:-----|:-------|:-----------------|:-------|
|（必传）应用图标||1张|/|216*216|PNG：500KB以内|图标需为正方形。|
|（必传）应用介绍截图||3-5张|16:9|1280*720|PNG/JPG/JPEG：5MB以内|/|

## HarmonyOS应用（手机/平板）

### 规范

|**应用素材**||**数量**|**比例**|**分辨率**|**格式**及大小|**备注**|

|（必传）应用图标||1张|/|216*216|* PNG：500KB以内 * WEBP：100KB以内（不允许为动图）|图标需为正方形。|

|（必传）应用介绍截图|竖向截图|3-5张|9:16|720*1280|* PNG/JPG/JPEG：5MB以内 * WEBP：200KB以内（不允许为动图）|/|

## 快应用（手机）

### 规范

> 说明
>
> 手机快应用（包括普通应用和游戏应用）中仅游戏应用支持上传应用介绍视频。

|**应用素材**||**数量**|**比例**|**分辨率**|**格式**及大小|**备注**|
|:---------|----|:-----|:-----|:-------|:------------------------------------------|:-----------------------------------------|
|（必传）应用图标||1张|/|216*216|* PNG：2MB以内 * WEBP：100KB以内（不允许为动图）|图标需为正方形。|
|（必传）应用介绍截图|横向截图|3-5张|/|800*450|* PNG/JPG/JPEG：2MB以内 * WEBP：100KB以内（不允许为动图）|/|
|（必传）应用介绍截图|竖向截图|3-5张|/|450*800|* PNG/JPG/JPEG：2MB以内 * WEBP：100KB以内（不允许为动图）|/|
|（可选）应用介绍视频|横向视频|1-3个|16:9|1280*720|MOV/MP4：500MB以内，长度15秒-2分钟|应用介绍视频将展示在应用详情页的"介绍"页签下，且介绍视频与介绍截图方向需保持一致。|
|（可选）应用介绍视频|竖向视频|1-3个|9:16|720*1280|MOV/MP4：500MB以内，长度15秒-2分钟|应用介绍视频将展示在应用详情页的"介绍"页签下，且介绍视频与介绍截图方向需保持一致。|
