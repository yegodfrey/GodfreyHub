# 创建HarmonyOS应用/元服务

当前在AGC新创建的HarmonyOS应用/元服务为HarmonyOS NEXT版本，不支持创建HarmonyOS 3.1/4.0及以下版本的HarmonyOS应用/元服务。具体操作请参见[创建HarmonyOS应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-create-app-0000002247955506) \| [创建元服务](https://developer.huawei.com/consumer/cn/doc/app/agc-help-create-atomic-service-0000002247795706)。
