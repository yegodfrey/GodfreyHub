# 开始使用

## 浏览器要求

推荐您使用如下浏览器访问华为AppGallery Connect（以下简称AGC）。

* Google Chrome
* Firefox
* Microsoft Edge

## 注册华为开发者账号

要在AGC中发布应用或使用AGC的服务，您需要先注册一个华为开发者账号。华为开发者账号基于华为账号进行实名认证即可。

### 注册华为账号

您可以前往[华为开发者联盟官网](https://developer.huawei.com/consumer/cn/)进行华为账号注册，具体请参见[注册账号](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。如果您已经拥有华为账号，可跳过本步骤。

### 实名认证

账号注册完后，需要完成实名认证才能享受华为开放的各类能力和服务，您可以选择认证成为企业开发者或个人开发者，企业开发者比个人开发者享受的服务更多，具体介绍请参见[实名认证介绍](https://developer.huawei.com/consumer/cn/doc/start/itrna-0000001076878172)。

### 开通商户服务

如果您的应用与华为应用市场进行收益分成（付费应用或接入华为应用内支付），您需要提前开通商户服务并签署华为商户服务协议，具体请参见[开通商户服务](https://developer.huawei.com/consumer/cn/doc/start/merchant-service-0000001053025967)。

### 信息版块

* 开发者账号信息，您可以查看账号信息或切换团队。
* 展示在架应用和审核中应用的数量。
* 展示互动中心待办内容，内容分类包括应用审核、服务申请、活动与动态、系统通知、申诉与反馈等。优先展示与用户强相关的应用审核内容，最多显示2条，点击消息可直接打开消息详情页面。点击"更多"按钮，可进入互动中心首页查看或处理更多的待办事项。

### 引导版块

点击服务卡片区域，可跳转到对应服务主界面。

* 元服务一站式平台：点击后进入基于AGC平台底座构建的元服务子控制台界面，聚合了所有元服务相关的业务特性，如元服务上架、基础服务、服务分发增长、数据分析等，助力您快速上架和经营元服务。
* 云开发：点击后进入"云开发（Serverless）"分组下的认证服务主界面，其它云开发服务还有云函数、云数据库、云缓存、云存储等。
* 云测试：点击后进入云测试服务主界面，正式上架前您可通过云测试能力，高效完成应用包体在真机上的测试，同时借助其测试报告等工具高效闭环问题，提升上架审核通过效率。
* 应用上架：点击后进入"APP与元服务 > 分发 > 应用上架/元服务上架 > 应用信息"界面，您可在此处完善应用信息。进行充分的测试验证后，即可将应用提交上架。
* 数据概览：点击后进入"分析 > 概览"界面，为您提供应用的分析总览数据、应用全生命周期分析服务，深度分析应用的分发、质量、运营数据，通过数据驱动产品优化和精细化运营。
* 组件&模板：点击后进入鸿蒙生态伙伴模板&组件专区，提供模块化、可复用的开发模板&组件。
* 云调试：点击后进入云调试服务主界面，云调试为您提供高效的云端设备调试解决方案，帮助您解决设备机型不足、设备管理困难及bug无法复现等问题。
* 推送：点击后进入推送服务主界面，此服务可建立云端到终端的消息推送通道，提供实时、高效、精准的消息推送服务。
* 应用推广：点击后进入华为应用市场应用推广平台，您可以使用此平台在华为应用市场客户端推广您的应用。
* APMS：点击后进入应用性能监测服务主界面，应用无需集成SDK，即可通过异常管理、性能管理页面快速发现、定位、解决应用崩溃、应用启动、Ability页面切换和Web页面加载时的问题，实时检测应用在每个设备上的运行状态，确保应用稳定运行。
* App Linking：点击后进入App Linking服务主界面，为您提供创建应用链接、元服务链接以及跨平台链接能力。
* HarmonyOS行业解决方案：点击后进入HarmonyOS行业解决方案专区，为您提供行业应用高频使用的API、组件、模板、SDK等接入方案，以及全流程在线支持，帮助您快速开发HarmonyOS应用和元服务。

### 服务动态版块

展示与服务强相关的内容，最多显示3条。当服务动态内容等于或超过2条时，显示"更多"按钮，点击该按钮，可进入服务动态内容列表页。
