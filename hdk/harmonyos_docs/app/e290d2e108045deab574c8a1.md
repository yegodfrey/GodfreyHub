# 获取HarmonyOS应用或元服务报表的指标数据

#### 功能介绍

获取HarmonyOS应用下载安装、用户分析、留存分析报表或者元服务分发分析报表的指标数据。

如果接口调用者是普通开发者，则接口调用者的角色：账号持有者、国内管理员、App管理员、国内运营。

#### 接口原型

承载协议 | HTTPS POST  
---|---  
接口方向 | 开发者服务器 -> 华为服务器  
接口URL | https://connect-api.cloud.huawei.com/api/report/harmony-report/v1/harmony/analyticsReport/_{appId}_  
数据格式 | 请求：Content-Type: application/json 响应：Content-Type: application/json

#### [h2]Body

参数名称 | 必选(M)/可选(O) | 类型 | 参数说明  
---|---|---|---  
measures | M | List<String> | 指标集合，多个使用,号分隔。 取值范围及具体含义请参见measures指标说明。  
startTime | M | String | 查询开始时间。 UTC时间格式：yyyy-MM-ddTHH:mm:ss，例如“2015-01-01T00:00:00”。 **startTime** 和**endTime** 之间不超过180天。  
endTime | M | String | 查询结束时间。 UTC时间格式：yyyy-MM-ddTHH:mm:ss，例如“2015-01-01T23:59:59”。 **startTime** 和**endTime** 之间不超过180天。  
frequency | O | String | 基于日期维度查询，取值范围：
                * day：按天查询
                * week：按周查询
                * month：按月查询  
chainStartTime | M | String | 对比上周期数据的周期开始时间。 UTC时间格式：yyyy-MM-ddTHH:mm:ss，例如“2015-01-01T00:00:00”。  
chainEndTime | M | String | 对比上周期数据的周期结束时间。 UTC时间格式：yyyy-MM-ddTHH:mm:ss，例如“2015-01-01T23:59:59”。  
order | O | String | 排序字段（目前仅支持day）及排序方式（升序，降序）。当需要按某个指标排序时，直接将指标名传入即可。 取值范围：
                * day：按日期升序
                * day desc：按日期降序  
group | O | String | 分组字段，多个使用,号分隔。 取值范围：
                * country_code：按国家码分组
                * province：按省份分组
                * city：按城市分组
                * app_version：按应用版本分组
                * device_prod_sprdname：按设备型号的名称分组  
filterCondition | O | List<String> | 过滤器，取值范围：
                * countryId：按国家过滤
                * appVersion：按应用版本过滤
                * deviceName：按机型过滤
如果不传，默认无过滤器。  
filterConditionValue | O | List<String> | 过滤器对应的值。
                * 如果过滤器为countryId，此参数的取值为国家码的字符串数组，例如“CN, AL, AD, AT”。具体国家码列表参考[国家码](https://developer.huawei.com/consumer/cn/doc/app/agc-help-connect-api-appendix-countrycode-0000002236201362)。传入“all”表示查询全球，“all”不区分大小写。
                * 如果过滤器为appVersion，此参数的取值为应用版本，多个版本以英文逗号分隔，如：“1.0.0,2.0.0”。“all”表示查询所有应用版本，“all”不区分大小写。
                * 如果过滤器为deviceName，此参数的取值为设备型号的名称，如：“Mate30Pro-5G版”、“P40-lite”、“P30-Pro”、“P40-lite-5G”、“nova7-SE”、“nova7_SE_5G乐活版”、“nova6-5G版”、“mate20”。  
limit | O | Integer(32) | 限制返回的条数。 默认为空，不限制返回条数。然而受平台限制，数据可能返回不全。
