# 检查测试手机设置

测试近场服务之前需要您开启手机相关权限，并且添加“小艺建议”到桌面，以便接收近场测试推送内容。

                1. 根据应用类型以及应用或元服务上架情况进行相应处理。
                   * 应用类型是HarmonyOS应用

如果您的应用已上架，则进入华为应用市场下载至测试手机并安装应用。

如果您的应用尚未正式上架，则通过[邀请测试](https://developer.huawei.com/consumer/cn/doc/app/agc-help-invite-test-overview-0000002287701773)的方式下载至测试手机并安装应用。

                   * 应用类型是元服务

如果您的元服务已上架华为应用市场，则跳过本步骤。

如果您的元服务尚未上架华为应用市场，则通过[邀请测试](https://developer.huawei.com/consumer/cn/doc/app/agc-help-invite-test-overview-0000002287701773)的方式将未上架的元服务加载至测试手机。

                2. 测试手机登录华为账号，且须确保华为账号绑定的手机号已添加到测试用户列表中。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/19/v3/8WMfDyZGSPOSxI-a9uEN-A/zh-cn_image_0000002477593769.png?HW-CC-KV=V1&HW-CC-Date=20261005T043437Z&HW-CC-Expire=86400&HW-CC-Sign=70EC53ABDA8C326096FFD1B1B631809AC79A46703D7403244028C2AF8BD7F765)

                3. 测试手机开启意图框架调试开关。操作路径：设置 - 系统 - 开发者选项 - 意图框架调试，开启“意图框架调试”开关。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9c/v3/CPmMyLvtSVG89DOHW1errQ/zh-cn_image_0000002477599001.png?HW-CC-KV=V1&HW-CC-Date=20261005T043437Z&HW-CC-Expire=86400&HW-CC-Sign=A15A306CEDD016159555F09AE4768834B544EBF528884F5DC848B027E6F5037B)

                4. 打开系统位置权限。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4a/v3/CqNdkhaUQtO9gqDSIp5uOw/zh-cn_image_0000002477552365.png?HW-CC-KV=V1&HW-CC-Date=20261005T043437Z&HW-CC-Expire=86400&HW-CC-Sign=92362DAE9E8B82AF5A718FF1DB42447652BB4F4053D73C02EDC86AE422797957)

                5. 打开小艺App，开启如下两个开关。
                   * “个性化推荐”开关。

操作路径：小艺App - 点击右上角头像 - 设置 - 个性化推荐 - “个性化推荐”开关。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9d/v3/ddQq5OGVQI-DRv1aQRrRWg/zh-cn_image_0000002378770034.png?HW-CC-KV=V1&HW-CC-Date=20261005T043437Z&HW-CC-Expire=86400&HW-CC-Sign=5E0AD73D2154F3125751AA1FA96BCD015ED734B9EF43C5A3CC544BE3BB0C8734)

                   * “基于位置信息提供服务”开关。

操作路径：小艺App - 点击右上角头像 - 设置 - 其他 - “基于位置信息提供服务”开关。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5b/v3/bJ_r7arvTFeX9DbrPdnG2w/zh-cn_image_0000002378770902.png?HW-CC-KV=V1&HW-CC-Date=20261005T043437Z&HW-CC-Expire=86400&HW-CC-Sign=87E591551DF431C0DA3515A96A215E6D23081D75DAD3D0727D7A2DA7D4F4BC89)

                6. 添加“小艺建议”到桌面。

操作路径：设置 - 小艺 - 小艺建议 - 添加“小艺建议”到桌面。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bd/v3/J7InkUdMQJWBqlUfK8l82A/zh-cn_image_0000002477623509.png?HW-CC-KV=V1&HW-CC-Date=20261005T043437Z&HW-CC-Expire=86400&HW-CC-Sign=BCFD33820EB1722A52EA9E9930EC049401DC5AC1C811F441E4B1A13F462889B4)

请先点击“添加“小艺建议”到桌面”，通过左右滑动选择2*2和4*4卡片（目前不支持在2*4卡片中出卡，所以请确保不要选择2*4卡片）。然后点击“添加至桌面”，将两种尺寸的卡片均添加至桌面。
