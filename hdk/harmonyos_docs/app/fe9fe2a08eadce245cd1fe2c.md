# 性能报告

性能报告是对鸿蒙应用性能概况做整体的呈现，目前涵盖了三种性能指标：启动耗时、卡顿丢帧率、页面切换耗时。默认从时间维度和版本维度提供变化趋势，默认提供P90和平均值的比对。
