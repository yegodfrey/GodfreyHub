# 设置应用内默认值

您可以在远程配置对象中设置应用程序内的默认值，以便您的应用程序在连接到远程配置服务之前按照预期运行。如果云端未设置参数值，则可以使用本地默认值。

当前支持两种类型的默认值：

* XML资源文件类型的默认值 在工程的resources/profile中增加一个远程配置默认值的xml文件，其中键值对为<value key="testkey">testvalue</value>，例如文件configdefault.xml。

  ```screen
  <remoteconfig>
       <value key="test1">test1</value>
       <value key="test2">true</value>
       <value key="test3">123</value>
       <value key="test4">123.456</value>
       <value key="test5">test-test</value>
  </remoteconfig>
  ```

  调用[RemoteConfig.applyDefault](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-api-remoteconfig-0000002664883514#section9109980584)传入默认值，传入后立即生效。

  ```screen
  RemoteConfig.applyDefault(ResourceTable.Profile_configdefault);
  ```

* Record<string, object>：键值对对象，以Map形式传入默认参数。

  调用[RemoteConfig.applyDefault](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-api-remoteconfig-0000002664883514#section9109980584)传入默认值，传入后立即生效。

  ```screen
  let map:Record<string,Object> = {};
  map["a"] = 1;
  map["b"] = "str";
  RemoteConfig.applyDefault(map);
  ```
