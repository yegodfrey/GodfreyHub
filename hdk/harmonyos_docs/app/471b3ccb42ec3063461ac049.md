# 指标详情

终端用户使用鸿蒙应用的过程中，可能出现应用功耗的问题，这些问题会上报并呈现到功耗的指标详情页面。开发者可以在该页面查看应用器件耗电趋势、耗电速率与维度分布。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到对应项目，在项目下的应用列表中点击对应应用/元服务。
3. 左侧导航栏选择"质量 > APMS > 故障指标"，进入故障指标主界面。
4. 选择"功耗"页签，进入功耗指标详情页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e8/v3/L-YoytpEQrebmy763hyXcg/zh-cn_image_0000002590419718.png?HW-CC-KV=V1&HW-CC-Date=20261008T140812Z&HW-CC-Expire=31536000000&HW-CC-Sign=18EF6EEB02DF2CD01067511AEE7AD87CAC3E2776649F8A60A97E7220ECF7B502)

   以下为功耗指标图表对应的筛选条件说明：

   |筛选条件|说明|
   |:---|:---------------------------|
   |应用版本|应用的版本标识|
   |系统版本|应用适配的系统版本|
   |设备型号|唯一标识设备硬件规格和版本的代码，例如：ALN-AL00|
   |时间范围|筛选数据的时间段|

## 趋势分析

功耗趋势分析呈现应用功耗数据的变化情况。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9a/v3/esiYvevaQdqA9Gu_uf7BfQ/zh-cn_image_0000002620779373.png?HW-CC-KV=V1&HW-CC-Date=20261008T140812Z&HW-CC-Expire=31536000000&HW-CC-Sign=53CF64D9260F0CBBC3172ADDA929D75D3D8AE2A2E2B94B1939BABD6181511D02)

* 耗电趋势图表默认呈现前台耗电量关于版本的柱形趋势图，每个柱形内通过不同颜色呈现不同器件的耗电量。
* 左上角下拉筛选可以切换耗电趋势的指标计算方式，支持"前台"、"后台"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/24/v3/e2fjCfHRQf2hgE_GZca0zw/zh-cn_image_0000002620859501.png?HW-CC-KV=V1&HW-CC-Date=20261008T140812Z&HW-CC-Expire=31536000000&HW-CC-Sign=04CAC18F701936D74C8E662370F6B3ED7BC0C9FA80D96BCFBE612784A19F1779)

* 左图展示前台耗电速率与后台耗电速率随时间的变化趋势；右图展示前台使用时长、后台使用时长、总使用时长随时间的变化趋势。
* 左上角（右图-使用时长）下拉筛选可以切换使用时长趋势图标指标的计算方式，支持"分钟"、"小时"。

## 维度分布

应用功耗维度分布呈现应用功耗数据与应用版本等维度的集中分布关系。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/81/v3/Qv6jwyZGQ_SWRBgxADHNtQ/zh-cn_image_0000002590419838.png?HW-CC-KV=V1&HW-CC-Date=20261008T140812Z&HW-CC-Expire=31536000000&HW-CC-Sign=42ECD7203CFCAA809942BB3B35F392980374FD36D831236E962BDA32AB14E3C9)

* 维度分布图表默认展示"前台耗电量"在"应用版本"、"系统版本"、"设备型号"三个维度上的Top 5分布情况，展示对应维度值的占比。
* 切换右上角下拉筛选可以更新维度分布的计算依据，支持"前台耗电量"、 "后台耗电量"、 "前台耗电速率"与 "后台耗电速率"。
