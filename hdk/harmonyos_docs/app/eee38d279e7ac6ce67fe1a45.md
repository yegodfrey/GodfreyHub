# 选择待发布软件包

从上传的版本中选择需要发布的软件包。

## 前提条件

已[上传软件包](https://developer.huawei.com/consumer/cn/doc/app/agc-help-release-app-upload-pkg-0000002277983368)，且软件包同时满足如下条件：

* "使用场景"为"测试和正式上架"。
* [合法性检测](https://developer.huawei.com/consumer/cn/doc/app/agc-help-release-app-upload-pkg-0000002277983368#section161521438134716)结果为"已达标"。

## 操作步骤

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"APP与元服务"。
2. 选择要发布的应用。
3. 左侧导航选择"应用上架 > 版本信息"下待发布的版本。
4. 进入"软件版本"区域，点击"版本选取"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/16/v3/EgQpVgaZSJ-uoir6faqhuQ/zh-cn_image_0000002532933964.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=1C3EE1ACE56F9A7F15ACF1F1A174CA462B1E8C07CC75F2D7A4E18AEF3CB79374)

5. 弹出窗口将展示已上传的、通过合法性检测的软件包，选择待发布的软件包，点击"选取"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0f/v3/aNP72vN3QMidouLe4UrKoQ/zh-cn_image_0000002533095494.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=8218CC363A2F88C3D5AB5A09581E7200F61056B6630AD2ABE2D3605EA4804D88)

6. 当您发布软件包的API Level ≥ 11时，可以设置是否对软件包进行加密。加密的影响、效果详细参见[应用加密](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/code-protect)。
   * 加密：用户在客户端安装的软件包为加密的，安全性较高。
   * 不加密：用户在客户端安装的软件包为不加密的，应用的启动速率较快。

   > 注意
   >
   > 如果应用的设备仅包含运动手表，则不支持加密。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e4/v3/KtkKlTUmQZeoKwbem4kd8Q/zh-cn_image_0000002532933968.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=6CD00A98BB93298839D2622A7DE0839035761D145D9BD9C2B9642CC820FD6135)
