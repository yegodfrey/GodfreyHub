# 删除设备

当后续不再使用某个已注册的设备时，您可以将该设备从列表中删除。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"证书、APP ID和Profile"。
2. 在左侧导航栏选择"证书、APP ID和Profile > 设备"，进入"设备"页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/69/v3/qvaKx49qQEyOy7n3DPdgmw/zh-cn_image_0000002490114708.png?HW-CC-KV=V1&HW-CC-Date=20261008T161354Z&HW-CC-Expire=31536000000&HW-CC-Sign=29343CA1E46874CCAB0CEB895E7FEAE2BF2056FFB79F29C43EA6637989F9C0E3)

3. 勾选一个或多个需要删除的设备，点击"批量删除设备"，在弹出窗口中点击"确认"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6d/v3/bPNZC_sgT8-GmhYX39UdQg/zh-cn_image_0000002313307054.png?HW-CC-KV=V1&HW-CC-Date=20261008T161354Z&HW-CC-Expire=31536000000&HW-CC-Sign=6F3F95BFD59C27E5ACFA64FB7BD80FBE02215B7BC980D4B025641D3B9C326DC0)

   若提示"部分设备已被HarmonyAppProvision使用，无法删除"，表示设备已被Profile绑定。参考如下操作解绑：

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a6/v3/Guqq9uKgRwe8rLh9rhiMTw/zh-cn_image_0000002287668160.png?HW-CC-KV=V1&HW-CC-Date=20261008T161354Z&HW-CC-Expire=31536000000&HW-CC-Sign=FE135988B982B458CCF35E503F2597C80BBB9238989ECDB6CC6C08C5A3E819DF)

   1. 左侧菜单选择"Profile"。
   2. 点击待解绑的Profile的"编辑设备"。
   3. 去勾选待删掉的设备，将设备与Profile解绑。
4. 返回设备列表，可查看设备删除情况。
   * 如设备在添加后一年内被删除，该设备将置灰显示且不再可用，效果如下图所示，但仍占用此一年的设备名额。设备添加时间满一年后，该已被删除的设备将被自动从列表中清除，清除后该设备不再占用设备名额。如设备在添加一年后被删除，该设备将直接从列表中清除，也不再占用设备名额。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/82/v3/6W6DFxAkRAmEAUNzHuSbSg/zh-cn_image_0000002286557136.png?HW-CC-KV=V1&HW-CC-Date=20261008T161354Z&HW-CC-Expire=31536000000&HW-CC-Sign=F0B77B45E20593B1596574A41EF146E2F2A70FD6507082ABB67066338520FEC2)

   * 如您想重新添加在一年内被删除的、置灰显示的设备，可以通过[添加单个设备](https://developer.huawei.com/consumer/cn/doc/app/agc-help-add-device-0000002283189937#ZH-CN_TOPIC_0000002283189937__li116281013114813)或者[批量导入设备](https://developer.huawei.com/consumer/cn/doc/app/agc-help-add-device-0000002283189937#ZH-CN_TOPIC_0000002283189937__li142073458288)的方式，重新编辑新的设备名称，输入原UDID，即可添加成功。**需要注意的是，设备的注册时间依然以首次添加时间为准。**
