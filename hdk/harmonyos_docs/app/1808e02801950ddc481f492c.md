# 预置卡片及快照开发说明  
  
#### 卡片属性

选择意图名称后，需要配置如下三部分卡片信息：

                * moduleName：应用模块名。
                * abilityName：应用能力名。
                * formName：卡片名。

配置完成后，可在右侧“预览效果”处查看配置是否有误。

若您提前在EntryCard目录下配置了卡片快照，预览效果如下图所示。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8c/v3/4OeVigM3QVmEhPx16WQHAg/zh-cn_image_0000002349183640.png?HW-CC-KV=V1&HW-CC-Date=20261005T043442Z&HW-CC-Expire=86400&HW-CC-Sign=89B27C7EFD578148E37E04B0EB7DA2EB9D090C40DE3D3D6F5E2CFF00ACF6694C)

若您未创建卡片快照，则在配置应用卡片属性后，右侧预览效果将为空，并且提示您“未获取到快照内容”，如下图所示。

#### 开发说明

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0b/v3/5dOtv5P-TyWdkfMb03iFHA/zh-cn_image_0000002349023852.png?HW-CC-KV=V1&HW-CC-Date=20261005T043442Z&HW-CC-Expire=86400&HW-CC-Sign=533AC960FC5D2C870B6F56F55C210118C32F1422FF3661F5CC57429B6B593DB8)

为保证配置应用卡片属性后，预览效果与现网真实展示效果一致，如上图所示，请您在应用开发过程中，提前设计好每一张服务卡片的快照图，并保证对每一张服务卡片均按照下图中的EntryCard目录创建了对应的文件夹。快照图片命名遵循格式“卡片名称-2x2.png”，例如当存在widget 2x2卡片时，快照图片命名为：widget-2x2.png。将每一张服务卡片的快照图拷贝到对应服务卡片的snapshot目录下，若存在默认图片则将其删除。

若工程中无EntryCard目录，请参考[创建服务卡片](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-service-widget#section111689357301)在工程中补充服务卡片的快照图，并升级应用。
