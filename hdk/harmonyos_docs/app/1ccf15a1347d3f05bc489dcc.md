# 配置本地化基础信息（介绍、特性、素材）

您可以为应用支持的语言配置相应的应用介绍、特性、介绍截图和视频，以及推荐视频，这些信息将展示在应用详情页面，用户通过这些信息可以快速了解您的应用。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"APP与元服务"。
2. 选择要发布的应用。
3. 左侧导航选择"应用上架 > 版本信息"下待发布的版本。
4. 进入"可本地化基础信息"区域，选择配置的语言。 "语言"栏将展示您在"应用信息"中配置的语言类别。此处仅支持切换语言，不支持新增或删除语言。如果没有为所有语言配置相应的信息，则将使用默认语言配置的内容。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e5/v3/-zqz-aa5QbS5_C0pQs3YYA/zh-cn_image_0000002313954405.png?HW-CC-KV=V1&HW-CC-Date=20261008T181453Z&HW-CC-Expire=31536000000&HW-CC-Sign=AAC2C92541C35740F66A16CE0358D60AB9D2B7D8E8C18E50C96BE42CBE54518F)

5. 填写应用介绍、应用一句话简介、新版本特性。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6f/v3/slqU0TgLR6etNnK5NTaTTg/zh-cn_image_0000002313955533.png?HW-CC-KV=V1&HW-CC-Date=20261008T181453Z&HW-CC-Expire=31536000000&HW-CC-Sign=1F822E374AB649B7F749ABFEABA54FB65CB7F03640340CEE0E39ED0E7C15CDAA)

   |参数|必填/选填|说明|
   |:------------|:----|:------------------------------------------------------------------------|
   |应用介绍|必填|简单描述该应用的功能、产品定位等，字数不能超过8000字符。|
   |应用一句话简介（小编推荐）|必填|突出描述应用的特色，吸引用户使用，中文不能超过17字符，其他语言不能超过80字符。|
   |新版本特性|选填|描述新版本的重点特性，中国大陆站点不能超过500字符，非中国大陆站点不能超过1000字符。 升级版本时，该信息将展示在华为应用市场的应用更新页面。|

6. 上传应用介绍截图、介绍视频和推荐视频。如果应用支持多种设备，需要选择不同设备的页签进行配置，以下截图仅为示例。各设备上传图片、视频规范请参见[素材规范](https://developer.huawei.com/consumer/cn/doc/app/agc-help-app-visual-asset-spec-0000002277607976)。 说明
   > * 运动手表和智能手表共用一套素材，统一在"手表"页签上传。
   > * 智慧屏设备素材请在"大屏"页签上传。
