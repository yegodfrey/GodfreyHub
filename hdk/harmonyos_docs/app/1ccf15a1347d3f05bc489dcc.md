# 配置本地化基础信息（介绍、特性、素材）

您可以为应用支持的语言配置相应的应用介绍、特性、介绍截图和视频，以及推荐视频，这些信息将展示在应用详情页面，用户通过这些信息可以快速了解您的应用。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"APP与元服务"。
2. 选择要发布的应用。
3. 左侧导航选择"应用上架 \> 版本信息"下待发布的版本。
4. 进入"可本地化基础信息"区域，选择配置的语言。 "语言"栏将展示您在"应用信息"中配置的语言类别。此处仅支持切换语言，不支持新增或删除语言。如果没有为所有语言配置相应的信息，则将使用默认语言配置的内容。

   ![](https://media:401788761067398301)

   <br />

5. 填写应用介绍、应用一句话简介、新版本特性。 ![](https://media:401788761067429302)

   <br />

   <br />

   |参数|必填/选填|说明|
   |:------------|:----|:------------------------------------------------------------------------|
   |应用介绍|必填|简单描述该应用的功能、产品定位等，字数不能超过8000字符。|
   |应用一句话简介（小编推荐）|必填|突出描述应用的特色，吸引用户使用，中文不能超过17字符，其他语言不能超过80字符。|
   |新版本特性|选填|描述新版本的重点特性，中国大陆站点不能超过500字符，非中国大陆站点不能超过1000字符。 升级版本时，该信息将展示在华为应用市场的应用更新页面。|

6. 上传应用介绍截图、介绍视频和推荐视频。如果应用支持多种设备，需要选择不同设备的页签进行配置，以下截图仅为示例。各设备上传图片、视频规范请参见[素材规范](https://developer.huawei.com/consumer/cn/doc/app/agc-help-app-visual-asset-spec-0000002277607976)。  
   ![](https://media:401788761067451303)  
   * 运动手表和智能手表共用一套素材，统一在"手表"页签上传。
   * 智慧屏设备素材请在"大屏"页签上传。

   ![](https://media:401788761067492304 "点击放大")
