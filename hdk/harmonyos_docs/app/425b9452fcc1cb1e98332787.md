### applyDefault

|Method|
|:----------------------------------------------------------------------------------------------|
|applyDefault(values: Resource | Record<string, object>): void 应用默认配置值。当远程配置未拉取成功或某些键不存在时，使用默认值。|

**Parameters**

|Parameter|Description|
|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|values|配置值，支持两种类型： * Resource：资源文件引用。xml文件的资源ID，资源格式为： ```screen <remoteconfig> <value key="test1">test</value> <value key="test2">true</value> <value key="test3">123</value> ... </remoteconfig> ``` * Record<string, object>：键值对对象，以Map形式传入默认参数。 ```screen let map:Record<string,Object> = {}; map["a"] = 1; map["b"] = "str"; RemoteConfig.applyDefault(map); ```|

|[ConfigValues](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-api-configvalues-0000002665043408) | null|最近一次拉取成功的缓存数据，如果没有缓存数据则返回null。|

### fetch

|Method|
|:------------------------------------------------------------------------------------------------------------------------|
|fetch(intervalSeconds?: number): Promise<ConfigValues> 从云侧获取最新的配置数据，由参数传入间隔时间，间隔内返回缓存数据。 此方法需要ohos.permission.INTERNET权限。|

**Parameters**

|Parameter|Description|
|:--------------|:---------------------------------|
|intervalSeconds|可选。 获取数据的间隔时间，单位是秒。如果不传，则默认间隔12小时。|

**Return**

|Type|Description|
|:-----------------------------------------------------------------------------------------------------------------------------------|:-----------|
|Promise<[ConfigValues](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-api-configvalues-0000002665043408)>|获取配置返回的异步结果。|

### fetchDiscrete

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------|
|fetchDiscrete(intervalSeconds: number, discreteTime: number): Promise<ConfigValues> 从云侧离散拉取配置数据，在指定的时间窗口拉取。 此方法需要ohos.permission.INTERNET权限。|

**Parameters**

|Parameter|Description|
|:--------------|:----------------------------------------------------------------------------------------|
|intervalSeconds|获取数据的间隔时间，单位是秒。|
|discreteTime|离散时间窗口，单位是秒。 远程配置将在[intervalSeconds, intervalSeconds + discreteTime] 范围内随机选择拉取时间，以分散请求峰值。|

**Return**

|Type|Description|
|:-----------------------------------------------------------------------------------------------------------------------------------|:-----------|
|Promise<[ConfigValues](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-api-configvalues-0000002665043408)>|获取配置返回的异步结果。|

### getMergedAll

|Method|
|:--------------------------------------------------------------------|
|getMergedAll(): Record<string, object> | undefined 返回默认值和云端值合并后的所有值 。|

**Return**

|Type|Description|
|:---------------------------------|:----------------------------------------------------|
|Record<string, object> | undefined|返回所有配置的键值对对象，如果没有配置数据则会返回空数组, undefined为防御性设计，实际不会返回。|

### clearAll

|Method|
|:--------------------------------------------|
|clearAll(): void 清除所有的缓存数据，包括从云侧获取的数据和传入的默认值。|

### getValue

|Method|
|:-----------------------------------------------------------------------------------------------------------------|
|getValue(key: string): string | number | boolean | [] | undefined 返回Key值对应的Value值。本方法获取的是当前项目使用的合并后的配置数据（云端 + 默认）。|

**Parameters**

|Parameter|Description|
|:--------|:----------|
|key|Key值，字符串格式。|

**Return**

|Type|Description|
|:-----------------------------------------|:--------------------------------------------------------------------------------------------------------|
|string | number | boolean | [] | undefined|Key对应的Value值。 支持多种数据类型： * string：字符串类型值 * number：数字类型值 * boolean：布尔类型值 * []：数组类型值 如果Key值不存在，则返回undefined。|

### setDeveloperMode

|Method|
|:--------------------------------------------------------------------------------|
|setDeveloperMode(isDeveloperMode: boolean): void 设置开发者模式，将不限制客户端获取数据的次数，云侧仍将进行流控。|

**Parameters**

|Parameter|Description|
|:--------------|:----------------------------------------------------|
|isDeveloperMode|是否设置为开发者模式。 * true: 启用开发者模式 * false: 使用普通模式 默认为false。|
