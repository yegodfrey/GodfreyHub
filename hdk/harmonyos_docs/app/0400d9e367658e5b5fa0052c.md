# 查看测试报告  
  
在一帧多屏调试过程中，系统会自动生成测试报告。您既可以在调试过程中实时查看报告，也可以在调试结束后查看完整报告。您可在“测试报告”页签查看您调试过的设备的相关测试信息，以及优惠时长、套餐余额和按量付费的额度消耗。

#### 前提条件

您正在进行或者已完成应用调试。

#### 操作步骤

                1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击“开发与服务”。
                2. 在项目列表中点击需要测试的项目。
                3. 在左侧导航栏选择“质量 > 云调试”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a6/v3/oz7ezRM_Rwu5ld87Ait1eg/zh-cn_image_0000002578270233.png?HW-CC-KV=V1&HW-CC-Date=20261005T043443Z&HW-CC-Expire=86400&HW-CC-Sign=318711C489FBD8A8877983279DF333C3B7F8060AA6E2CEEE7A35BC7332C1A4D2)

                4. 在“测试报告”页签下，点击右侧的“一帧多屏”，您可以查看所有调试任务下多个设备的优惠时长、套餐余额和按量付费的总计额度消耗。点击任一调试任务“测试时间”列左侧的![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ff/v3/TA7CVcG_QB28T4RvUCdZUw/zh-cn_image_0000002547670444.png?HW-CC-KV=V1&HW-CC-Date=20261005T043443Z&HW-CC-Expire=86400&HW-CC-Sign=4BDE16C162629A6B984E1631CF3169E33D654F78CA1425054AF41E71A0901735)，将展开显示该调试任务下每个调试设备的优惠时长、套餐余额和按量付费的额度消耗。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0f/v3/zllewafmTfWmBy3p5K3mjQ/zh-cn_image_0000002553315114.png?HW-CC-KV=V1&HW-CC-Date=20261005T043443Z&HW-CC-Expire=86400&HW-CC-Sign=33D33D5CC963EDD4E0A559997E8B78A7D7059098C32C4D2A83CA1371E314DE9F)

                5. 点击某一调试任务“操作”列的“查看”，将进入测试报告详情页面，您可以在此页面查看历史调试设备的详细信息、应用安装记录以及历史截图数据。
