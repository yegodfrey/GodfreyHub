# 小艺建议出卡问题的反馈方法

如果您携带手机进入测试POI或全网POI的200米感应范围内，按照排查建议检查后小艺建议仍未出卡或出卡内容不符合预期，请依次执行以下步骤进行反馈：

                1. 通过小艺App反馈问题并提交日志。
                2. 通过反馈助手App反馈问题并提交日志。
                3. 邮件反馈问题。

#### 小艺App反馈

                1. 在手机桌面搜索并打开小艺App。如未查找到，可通过桌面下拉搜索小艺。 

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9b/v3/VDjIDa3JRNqqwD-T6MgmJw/zh-cn_image_0000002446517053.png?HW-CC-KV=V1&HW-CC-Date=20261005T043444Z&HW-CC-Expire=86400&HW-CC-Sign=C1A170E3AF95534540739D5DB542C16A5BFC39A289AFAAEFB1ADB5EA3C9C1B99)

                2. 点击左上角箭头，返回上一级页面。 

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/74/v3/98E-PPhURbOwdmQU30PGpw/zh-cn_image_0000002413081898.png?HW-CC-KV=V1&HW-CC-Date=20261005T043444Z&HW-CC-Expire=86400&HW-CC-Sign=4FE6C4220EDE3DA02646F532C70ADCAE180F5969C78599D51C814889AE560838)

                3. 点击右上角的头像，进入“我的”页面。 

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4e/v3/cdXAB3baQL-z1S24KCJurw/zh-cn_image_0000002413083354.png?HW-CC-KV=V1&HW-CC-Date=20261005T043444Z&HW-CC-Expire=86400&HW-CC-Sign=E9A0AC35F2E9E63A478C42E12D67EE8831EFB1A630372C39CF7AF1E7F8F68749)

                4. 点击“帮助与客服”。 

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/82/v3/3qiz86EbRtifwhJZDAU29w/zh-cn_image_0000002413085558.png?HW-CC-KV=V1&HW-CC-Date=20261005T043444Z&HW-CC-Expire=86400&HW-CC-Sign=7DE4271D68A63745BD467EB6D950F9BA00BA9EAFD17A40EDD7C95F6741B64EFC)

                5. 在“帮助与客服”页面，点击左下角的“问题与建议”。 

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5f/v3/pYPQ7goSRPiHdEhG1MbNKg/zh-cn_image_0000002446526957.png?HW-CC-KV=V1&HW-CC-Date=20261005T043444Z&HW-CC-Expire=86400&HW-CC-Sign=83CE752BBC3C6001B98CF3C841B3616D5949A26D5D69C5FE6A5F63A7E10EA946)

                6. “问题类型”选择“小艺建议”，填写“问题描述或建议”，并勾选“共享应用日志，以便更准确诊断问题”，然后点击“提交”。 

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d9/v3/vD2Dc_WzRuuCQU80C4ThiQ/zh-cn_image_0000002533602001.png?HW-CC-KV=V1&HW-CC-Date=20261005T043444Z&HW-CC-Expire=86400&HW-CC-Sign=FBC718C04A64CA7F9182C850F9C4C55CE842739DAE9B58449E524076551E92A4)

                7. 提交之后，界面会显示问题编号。请记录该问题编号，并在邮件反馈时附上。 

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e7/v3/MMwfvetERYyn5MVXmJ8ZNQ/zh-cn_image_0000002412932322.png?HW-CC-KV=V1&HW-CC-Date=20261005T043444Z&HW-CC-Expire=86400&HW-CC-Sign=59C2C764EB518BB516B961889EE1BF4CD689F1653871DDA95A3487343655D560)

#### 反馈助手App反馈

                1. 在手机桌面搜索并打开反馈助手App。如果未找到，可通过桌面下拉搜索反馈助手。 

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/21/v3/W46DdCkrTLKx4gk1fNdlUw/zh-cn_image_0000002413093464.png?HW-CC-KV=V1&HW-CC-Date=20261005T043444Z&HW-CC-Expire=86400&HW-CC-Sign=B9BEFC8CC0EC8B5D1B441A17C29F30F278B2603F8F22F65B9A5DF0CBAF0D7788)

                2. 打开反馈助手后，点击页面底部的“反馈”。 

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/66/v3/cn6GrzVoQkS3e98cImtPQA/zh-cn_image_0000002446700869.png?HW-CC-KV=V1&HW-CC-Date=20261005T043444Z&HW-CC-Expire=86400&HW-CC-Sign=80F28E72FDD3DC5C951F397A5EF1696FC2FBFF52A7E2C66AA066CE904AA28B46)

                3. 按照实际情况选择问题概率和问题类型，并填写问题描述，然后点击“提交”。 

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9a/v3/RxlZRtI2QbG3gn1YFp167w/zh-cn_image_0000002413142354.png?HW-CC-KV=V1&HW-CC-Date=20261005T043444Z&HW-CC-Expire=86400&HW-CC-Sign=14A9D5119DAC0A4B497BB5E50BF67282CB3277981C1C9DF7C0ED0CB8C81F0944)

                4. 提交之后，界面会显示问题单号。请记录该问题单号，并在邮件反馈时附上。 

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fc/v3/L1Cu5HboTuaHN1ibW17RuA/zh-cn_image_0000002446538773.png?HW-CC-KV=V1&HW-CC-Date=20261005T043444Z&HW-CC-Expire=86400&HW-CC-Sign=87714ED88E9FDAACCC7874CDB2AC9D47F200555CE9E04341F1B6BF215C7F8DDA)

#### 邮件反馈

通过小艺App和反馈助手App反馈问题后，请发送邮件给华为运营人员。邮件格式要求如下：

                * **邮箱地址**

[agconnect@huawei.com](mailto:agconnect@huawei.com)

                * **邮件标题**

【近场服务出卡问题】

                * **邮件内容**

需包含以下信息：

                  * 开发者ID：即Developer ID，获取方法请参见[查看应用信息](https://developer.huawei.com/consumer/cn/doc/app/agc-help-view-app-info-0000002282674569)。
                  * 应用ID：即APP ID，获取方法请参见[查看应用信息](https://developer.huawei.com/consumer/cn/doc/app/agc-help-view-app-info-0000002282674569)。
                  * 应用/元服务名称
                  * 使用的位置ID：获取方法请参见查询位置ID。
                  * 问题简述：简要描述下是不出卡，还是出卡内容不符合预期。
                  * 小艺App的问题编号：如果提交问题后未记录问题编号，请参见查询问题编号进行获取。
                  * 反馈助手App的问题单号：如果提交问题后未记录问题单号，请参见查询问题编号进行获取。
                  * 问题发生的时间段：例如8月5日14:00 -14:30。
                  * 自检截图：需提供的截图请参见补充自检截图截取。
