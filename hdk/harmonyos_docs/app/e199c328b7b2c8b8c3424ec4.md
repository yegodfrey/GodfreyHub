# 发布时关联

> 注意
>
> * 一个HarmonyOS应用仅能关联一个在架Android应用。
> * 关联关系建立后不可再变更，后续升级不支持重新编辑关联关系。

在AppGallery Connect发布版本点击"提交审核"时，系统会自动按匹配规则检测您名下是否存在可关联的Android应用。如有，则弹出下图所示窗口。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e2/v3/r3bmt4cOTuSyI1vMNRlojg/zh-cn_image_0000002385908933.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=9652E8F9E5D1925BDB35D6268AC5A45F27A4A84EBD558364A7A692AB268314ED)

* 如果需要关联的Android应用已经上架：
  * 此应用的安卓版：选择"已上架"
  * 关联安卓应用：选择需要关联的Android应用 说明
    >
    > 需要资产转移的HarmonyOS游戏必须选择"已上架"的Android应用。
  * 共同加入应用系列：进行关联的Android应用和HarmonyOS应用将维护在一个应用系列中，如果您之前已经维护了应用系列，可以选择对应的应用系列，否则则创建新的应用系列。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ee/v3/OpBQi6eOS2GMgEdbObDsMQ/zh-cn_image_0000002352150612.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=3301BCC8320FA1C1D7F7C2F4829E4785D4CA05FC5ABC091AD77DEC25938AC5F8)
* 如果需要关联的Android应用还未上架： "此应用的安卓版"选择"未上架"，点击"保存"，然后提交版本发布审核。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/dc/v3/UtxFg6XKTy2NNCKC_nbtyw/zh-cn_image_0000002385926557.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=068E64E927712796D9BBF10D3B73267A258CC5E35A6F97F32E4FAC82013C7567)

  当HarmonyOS应用版本发布成功后，您可以在"应用信息"界面查看关联的Android应用。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/89/v3/cKsMMspiT6CidpsZAcH3AA/zh-cn_image_0000002385929361.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=6701DFBBCBD566BEC3B984F9F038211B6D47B9A997219D6908F5619FF4C9BD8F)

如果您在提交发布版本时没有配置关联Android应用，还可以在"应用信息"界面的"关联安卓应用"处进行关联。
