# 上传软件包

上传用于小游戏测试或正式上架的软件包后，AppGallery Connect会对软件包自动检测合法性，您可以根据报告或者错误码修复软件包问题。

#### 前提条件

确保小游戏软件包已符合上架要求。软件包要求请参见[准备游戏软件包](https://developer.huawei.com/consumer/cn/doc/app/agc-help-release-minigame-prepare-0000002424763490#section24731651195720)。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8d/v3/0MTP93TNTQ-oHzYD_obpAg/caution_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043501Z&HW-CC-Expire=86400&HW-CC-Sign=42D1706887C7CC22BA683EED4A74D60501A5F6812EFE0B4B6BE34E4694039401)

请确保小游戏已申请[JSVM权限](https://developer.huawei.com/consumer/cn/doc/app/agc-help-release-minigame-acl-and-ability-0000002425276004#section13637635175211)和[存储空间管理服务](https://developer.huawei.com/consumer/cn/doc/app/agc-help-release-minigame-acl-and-ability-0000002425276004#section17374114165216)，并且待上架软件包内已配置相关权限信息.。

#### 操作步骤

                1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击“APP与元服务”，选择待上架的小游戏。左侧导航栏选择“元服务上架 > 软件包管理”，在右侧页面点击“上传”。
                2. 在弹出的“上传包”窗口中先选择使用场景，再上传小游戏软件包。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/25/v3/7lNXd8pGS2Cm4pkH3-Isrg/zh-cn_image_0000002459067037.png?HW-CC-KV=V1&HW-CC-Date=20261005T043501Z&HW-CC-Expire=86400&HW-CC-Sign=52DB6D377FBA6D7C708A61CECE417D4DEA10777763C7471F94370010C54801A0)

                3. 软件包上传成功后，AppGallery Connect自动检测软件包的合法性，检测结果展示在“合法性”列。
                   * 已达标：表示小游戏软件包满足规范要求，可以用于正式上架。

点击“报告”查看详细的检测报告。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/45/v3/IYJnk7hjT3qSz0ACZ6xHyw/zh-cn_image_0000002425468386.png?HW-CC-KV=V1&HW-CC-Date=20261005T043501Z&HW-CC-Expire=86400&HW-CC-Sign=B68C5A899C118CE0119E4104BF2DAF90FE8F5080AEC31CC1B16BDCF225FD6E18)

                   * 待优化：表示小游戏软件包可以用于正式上架，但仍存在一些问题可能导致后续审核被驳回，或者影响游戏体验。

建议点击“报告”查看详细的检测报告，进一步优化软件包，并在优化后重新上传软件包。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ed/v3/b5n0iQjkTYyH8AiehYqmhQ/zh-cn_image_0000002425628270.png?HW-CC-KV=V1&HW-CC-Date=20261005T043501Z&HW-CC-Expire=86400&HW-CC-Sign=9A6E3E0E095812B020BDCE727B82547585665442B305FD13BAC50FB0B3DFE3A7)

                   * 不通过：表示小游戏软件包不满足上架要求，不允许用于正式上架。

点击“报告”或错误码链接，查看详细的原因与修改建议，并在修改后重新上传软件包。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bb/v3/k6N8DhXmRwylSW1MZJLTtQ/zh-cn_image_0000002459147045.png?HW-CC-KV=V1&HW-CC-Date=20261005T043501Z&HW-CC-Expire=86400&HW-CC-Sign=0214E5BD77C7E46E1A56F2A990B2B503D8CA10A10064C829F0D8A0DAF8B0D4E9)![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e8/v3/psLBCPAkQnyoQYV8blg8ww/zh-cn_image_0000002459067197.png?HW-CC-KV=V1&HW-CC-Date=20261005T043501Z&HW-CC-Expire=86400&HW-CC-Sign=00F1A77106F51CA16FB87BB6AE56B9FF753EEB4D612F0992D2E318C182F526AF)

                4. （推荐）为了提高小游戏审核的通过率，建议使用“上架自检”检测功能。该功能按照华为应用市场的上架标准，在热门移动终端设备上测试小游戏软件包的兼容性、稳定性、性能、功耗、UX等，可帮助小游戏软件包提前发现问题。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0f/v3/zvXZofOASYe_P11C6eL5DA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043501Z&HW-CC-Expire=86400&HW-CC-Sign=9FE0B3EC47F255C50D3D93C71EBCAFF9A1315BB433823DA37491CEDCD387EE4E)

每个小游戏同时只能进行1个自检任务。若您在启动自检后删除了软件包，自检任务将继续执行，需等待自检任务结束才可以执行新的自检任务。

点击“操作”列的“启动自检”，执行“上架自检”检测功能。启动检测后，可在“上架自检”列查看检测进度与结果。

                   * 检测中：表示正在检测小游戏软件包。检测时长可能受终端设备数量和排队情况影响，请耐心等待。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ea/v3/9S48_vKARZCG93xJYZhdwA/zh-cn_image_0000002425468510.png?HW-CC-KV=V1&HW-CC-Date=20261005T043501Z&HW-CC-Expire=86400&HW-CC-Sign=3EE4E01FD562639482151C9BB151680D285E8A4367D486623B1D279F62BE5B49)

                   * 通过：表示小游戏软件包检测通过，可以用于正式上架。

点击“报告”查看详细的检测报告。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/11/v3/DxC2C_RnS6a4D6HgPQreVQ/zh-cn_image_0000002425628350.png?HW-CC-KV=V1&HW-CC-Date=20261005T043501Z&HW-CC-Expire=86400&HW-CC-Sign=D52A2F8FB56AC8BFF1EAF52F50A0454DB5024D46D2EF4B05FB7956BF8335A555)

                   * 待优化：表示检测未通过。若“合法性”检测通过，但“上架自检”检测未通过，该小游戏软件包可以用于正式上架，但存在审核被驳回的风险。

建议点击“报告”查看详细的检测报告，进一步优化小游戏软件包，并在优化后重新上传软件包。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ca/v3/-xqyuEl7T_20ylgeLFhy0g/zh-cn_image_0000002459147093.png?HW-CC-KV=V1&HW-CC-Date=20261005T043501Z&HW-CC-Expire=86400&HW-CC-Sign=BF9E62EBED96F7093ADA703B5C798E315265200BFBE49C6C4AF4612878530886)

                   * 系统异常：表示系统发生错误。

点击“报告”查看详细原因。若不展示“报告”，请点击“启动自检”重试。若还有疑问请[联系客服](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/interactive/feedback/1/)。
