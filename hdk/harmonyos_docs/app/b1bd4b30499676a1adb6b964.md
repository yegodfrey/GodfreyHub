# 填写审核信息与联系方式

## 填写审核信息

如果您的元服务需要对用户进行身份验证，请提交有效的账号信息，若元服务内的功能需要连接设备或需要特殊的运行环境等场景才能使用，请提供演示视频或文件，以便华为审核人员完成相关功能的审核。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"快速开始"中的"元服务一站式平台"卡片。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/29/v3/c8sG1pfVRqCu0td2xRh8Sw/zh-cn_image_0000002529682783.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=B8AA5FC2A9EDBA917B398F33A1D91AAB2974C07AC598FA1202E5C0129BC96023)

2. 在左上角下拉列表选择要发布的元服务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cc/v3/UgiNgb1XRzKDkrZi5zONOg/zh-cn_image_0000002566867053.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=443C483DF47D7C2E83C1EE987E222FE29C8E1D35EA0DFC1031FEA6D132EC38B9)

3. 左侧导航选择"元服务上架 > 版本信息"下待发布的版本。
4. 进入"应用审核信息"区域，填写审核相关信息。
   * 需要登录进行审核：如果存在需要登录后才可使用的功能，需要勾选，并提供测试账号和密码。
   * 备注：提供有助于审核人员更准确、高效测试您元服务的额外信息，比如在审核时需要的特别设置等。
   * 自测文件：若元服务内的功能需要在连接设备或特殊运行环境等场景下才能使用，请您提供自测文件，以提升审核通过率。自测文件必须为.docx（不超过15MB）或.mp4文件，最多可上传5个，总大小不超过500MB。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7d/v3/A5qg78btRF69lnWiX8040A/zh-cn_image_0000002484243084.jpg?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=B425A3A83A430AF24EC5FE335C9E7E5E4331EB05EEDE326813D198F26CFD8313)

## 填写联系方式

账号归属地为中国大陆地区的开发者，还需预留元服务负责人的联系方式，以便于华为审核人员与您联系沟通。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"快速开始"中的"元服务一站式平台"卡片。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/76/v3/te0-TdhEQZG9YjuP-m2rsg/zh-cn_image_0000002529682783.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=399BC64553212ED18526551DDA570870243C1BEDE47561BD57ABCC3502C59EF8)

2. 在左上角下拉列表选择要发布的元服务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3e/v3/rf8nCEuzQtKaCZ8fn1XS6g/zh-cn_image_0000002566867053.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=90FB298C43F3B8C844F26A493E23DEE2B734C0D93EE2CA0C39EA6BF3F565BC3D)

3. 左侧导航选择"元服务上架 > 版本信息"下待发布的版本。
4. 进入"联系方式"区域，填写元服务负责人的手机号码和邮箱。
   * 手机号码：如果您有审核问题需要沟通，审核人员将致电该号码。
   * 邮箱：用于接收上架审核结果，元服务整改或下架通知。
   * 验证码：输入手机验证码，要求验证通过。
   * 姓名：用于沟通核实负责人身份。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d8/v3/aZrzp_sITxWMyrPS4kdHVw/zh-cn_image_0000002526718229.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=B0D45091CC295683428111ED32FD85AEE202D56A1F13D9EA353E701371814B75 "点击放大")
