# 配置内容分级

内容分级用于标识您的元服务适宜用户的年龄段。年龄分级作为元服务的重要属性，在华为应用市场的应用详情页展示给用户，帮助用户找到适合其年龄段的元服务，从而为未成年人用户打造纯净的使用环境。

AGC提供了调查问卷，根据您回答的内容，自动生成年龄分级结果。请根据实际情况如实填写。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"快速开始"中的"元服务一站式平台"卡片。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/90/v3/_rV_iKC2QDegoJb4HhRPDg/zh-cn_image_0000002529682783.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=650EC986F212CFEBA316F00515FC8F1F513A4B6EEE8B270FAC42985F01CDCB79)

2. 在左上角下拉列表选择要发布的元服务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/77/v3/rLA9nAr9SXWznNS8mcyRBQ/zh-cn_image_0000002566867053.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=B73600AC40891961B8330668D24C75349B19CB3E50D3CE5E403D98D6721B3B5A)

3. 左侧导航选择"元服务上架 > 版本信息"下待发布的版本。
4. 进入"内容分级"区域，点击"设置"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/85/v3/zniaGbxGRlyPHHI7PB-HDg/zh-cn_image_0000002327610921.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=F4E45B9F00BBB08043DC3E12DEBD8CF00A4FC680BD784DE4E1E618212BEA31DD)

5. 在弹出窗口点击"填写调查问卷"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/de/v3/6Q2c9sLpRkeuxnLuoBMuPA/zh-cn_image_0000002293811238.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=21ADF0302534BD610D45DF672557D2C850FC021A9D861AB774E48B9801466650)

6. 填写问卷中的问题，中途可点击"保存"保存已完成的内容。全部填写完成，点击"验证"，获取年龄分级结果。 注意
   > * 请务必据实填写问卷中的问题，对元服务内容虚假陈述可能会导致元服务的下架或冻结。
   > * 如果点击"验证"，结果显示"拒绝评级"，请查看拒绝评级的详细原因，修改不当内容后重新上传符合规范的元服务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/09/v3/AZ0gPDhgQyKFJz3ZDv36ZQ/zh-cn_image_0000002327731149.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=20E4B39A894F5855CFB3AFCE1BB47A44D0877BBC1CEF48A5600162A18C65DB57)

7. 基于计算的最低年龄分级结果，结合元服务情况，选择合适的年龄分级，然后点击"提交"。 例如计算结果是"12+"或者更低龄，但您认为内容更适合18+的用户，可选择您预期的年龄。发布后，在华为应用市场将展示您设置的"18+"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/41/v3/Ve60FdYwQDuODpzXv12QLw/zh-cn_image_0000002380883152.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=3C4ED8A29FB9A4939B78F91A096540728F9CB1272CF5D06BD7A6362DC58F3C21)

8. 如果您最终选择的年龄分级为3、8或者12，点击"提交"后，您还需再次确认您的元服务是否仅面向儿童。
   * 选择"是"：如果元服务分类是儿童类，点击"确认"成功提交分级；如果元服务分类不是儿童类，则需要前往"应用信息"页面[配置应用分类](https://developer.huawei.com/consumer/cn/doc/app/agc-help-release-atomic-class-tag-0000002293651518)为儿童类。
   * 选择"否"：点击"确认"成功提交分级。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/16/v3/QIALS_FXQZyUKAyUElj7WA/zh-cn_image_0000002327610953.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=64F348C361A70C3FAE929B616A9BA4C7550D695BB4EBB52D1D56FA8445B75499)

9. 提交分级后，即可查看详细的年龄分级结果。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9c/v3/P9x2yJH8S2S7pqHMazpOpg/zh-cn_image_0000002327731181.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=175FCA83955AE2584BF23546DA363964065338808B9E565C3F8FC0FA9D2D5ECE)

   > 说明
   > * 年龄分级问卷可能会不定期更新。如果年龄分级问卷内容发生变更，系统会提醒您"问卷已更新，请重新填写调查问卷"，您需重新填写年龄分级问卷，才可以提交元服务上架申请。
   > * 更新元服务版本时，如果新版本会影响调查问卷中的答案，您需要重新作答提交问卷；如果没有影响，则无需重新作答，系统将继承之前的年龄分级结果。
