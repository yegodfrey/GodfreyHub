# 配置内容分级

内容分级用于标识您的元服务适宜用户的年龄段。年龄分级作为元服务的重要属性，在华为应用市场的应用详情页展示给用户，帮助用户找到适合其年龄段的元服务，从而为未成年人用户打造纯净的使用环境。

AGC提供了调查问卷，根据您回答的内容，自动生成年龄分级结果。请根据实际情况如实填写。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"快速开始"中的"元服务一站式平台"卡片。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/90/v3/_rV_iKC2QDegoJb4HhRPDg/zh-cn_image_0000002529682783.png?HW-CC-KV=V1&HW-CC-Date=20261008T163518Z&HW-CC-Expire=31536000000&HW-CC-Sign=247CCD869A4B33AFD23D5BE6F77C9DCAD3B5B7F4BD55FB9B25629A44759CE8BC)

2. 在左上角下拉列表选择要发布的元服务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/77/v3/rLA9nAr9SXWznNS8mcyRBQ/zh-cn_image_0000002566867053.png?HW-CC-KV=V1&HW-CC-Date=20261008T163518Z&HW-CC-Expire=31536000000&HW-CC-Sign=E04EA479655FA769A99336D7E6AB113AD252C8BB983FB14698E0A417063835C2)

3. 左侧导航选择"元服务上架 > 版本信息"下待发布的版本。
4. 进入"内容分级"区域，点击"设置"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/85/v3/zniaGbxGRlyPHHI7PB-HDg/zh-cn_image_0000002327610921.png?HW-CC-KV=V1&HW-CC-Date=20261008T163518Z&HW-CC-Expire=31536000000&HW-CC-Sign=DA27C6800DEEB805FE48DF954FBDB2AA7111C6487E0565369B9B14EE0690CB97)

5. 在弹出窗口点击"填写调查问卷"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/de/v3/6Q2c9sLpRkeuxnLuoBMuPA/zh-cn_image_0000002293811238.png?HW-CC-KV=V1&HW-CC-Date=20261008T163518Z&HW-CC-Expire=31536000000&HW-CC-Sign=63B1E12ECD548E35BFE45A1D14211C03BCF53CB106DE2134C020FCF8D43317C6)

6. 填写问卷中的问题，中途可点击"保存"保存已完成的内容。全部填写完成，点击"验证"，获取年龄分级结果。 注意
   > * 请务必据实填写问卷中的问题，对元服务内容虚假陈述可能会导致元服务的下架或冻结。
   > * 如果点击"验证"，结果显示"拒绝评级"，请查看拒绝评级的详细原因，修改不当内容后重新上传符合规范的元服务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/09/v3/AZ0gPDhgQyKFJz3ZDv36ZQ/zh-cn_image_0000002327731149.png?HW-CC-KV=V1&HW-CC-Date=20261008T163518Z&HW-CC-Expire=31536000000&HW-CC-Sign=3152725DBAAD63C8DDFDDBDB0380C98DAB7CD73CEBD8399EEBCD91D071C3170C)

7. 基于计算的最低年龄分级结果，结合元服务情况，选择合适的年龄分级，然后点击"提交"。 例如计算结果是"12+"或者更低龄，但您认为内容更适合18+的用户，可选择您预期的年龄。发布后，在华为应用市场将展示您设置的"18+"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/41/v3/Ve60FdYwQDuODpzXv12QLw/zh-cn_image_0000002380883152.png?HW-CC-KV=V1&HW-CC-Date=20261008T163518Z&HW-CC-Expire=31536000000&HW-CC-Sign=72D3518A2CFDCBBE3AD4762AE501A4C2ABE0887BCBE6845BABE7F60986D415D5)

8. 如果您最终选择的年龄分级为3、8或者12，点击"提交"后，您还需再次确认您的元服务是否仅面向儿童。
   * 选择"是"：如果元服务分类是儿童类，点击"确认"成功提交分级；如果元服务分类不是儿童类，则需要前往"应用信息"页面[配置应用分类](https://developer.huawei.com/consumer/cn/doc/app/agc-help-release-atomic-class-tag-0000002293651518)为儿童类。
   * 选择"否"：点击"确认"成功提交分级。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/16/v3/QIALS_FXQZyUKAyUElj7WA/zh-cn_image_0000002327610953.png?HW-CC-KV=V1&HW-CC-Date=20261008T163518Z&HW-CC-Expire=31536000000&HW-CC-Sign=774DA6535EF012108D97EE38DBDDDD23481E5C17D36AB1759E0F9E07FE70C406)

9. 提交分级后，即可查看详细的年龄分级结果。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9c/v3/P9x2yJH8S2S7pqHMazpOpg/zh-cn_image_0000002327731181.png?HW-CC-KV=V1&HW-CC-Date=20261008T163518Z&HW-CC-Expire=31536000000&HW-CC-Sign=C513280028848689999DEF95C2BCEF25D51F89CF4B43A652AD88282B1C9F82DE)

   > 说明
   > * 年龄分级问卷可能会不定期更新。如果年龄分级问卷内容发生变更，系统会提醒您"问卷已更新，请重新填写调查问卷"，您需重新填写年龄分级问卷，才可以提交元服务上架申请。
   > * 更新元服务版本时，如果新版本会影响调查问卷中的答案，您需要重新作答提交问卷；如果没有影响，则无需重新作答，系统将继承之前的年龄分级结果。
