# 报告解读

质量报告是APMS系统对应用运行状态进行多维度量化评估的输出载体，为开发者提供客观、可视化的质量度量依据，是连接应用运行质量数据与改进决策的关键桥梁。以数据驱动的方式全景呈现应用质量趋势，助力团队快速识别质量瓶颈，量化改进成效。
