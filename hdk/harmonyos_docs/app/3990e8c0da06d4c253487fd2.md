# 编辑推荐业务介绍

全新HarmonyOS系统下，AppGallery将启动全新体验，秉承"不只是STORE，更是GALLERY"理念，首页以沉浸式、杂志化的Feed流为主。  

#### "编辑推荐"是什么？

编辑推荐面向优质应用与游戏开放。由专业的编辑团队，每天带领用户探索生活方式与文化；以杂志化的视觉体验，播报潮流与新知，分享应用和游戏的玩法与攻略；用深度的内容，传递应用和游戏世界中，最新的资讯与活动。  

#### "编辑推荐"要求

如果您的App有多UI/UE/功能亮点、有影响力的运营模式、生活场景解决方案的创新、热点话题或科技趋势；如果您的游戏具备高质量的制作水准、技术玩法创新、能够引领美术潮流。期待您的加入，报名申请详细步骤如下。  

#### 《编辑推荐》栏目申请方式

* 请您下载报名表按要求填写内容，并提供评审。下载[华为应用市场《编辑推荐》栏目申请表.xlsx](https://media:301779075890718679)

<!-- -->

* 将申请表与内容包打包发送至邮箱developer@huawei.com，邮件命名《编辑推荐》栏目申请+应用名称。
* 编辑将依照评审机制，对报名应用及材料进行审视。
