# AI辅助分析

AI分析与传统日志分析的核心区别在于传统分析是基于规则和模式匹配的方式给出问题分析结果及定界，而AI辅助分析利用大模型的推理能力，引用历史故障知识库和业界通用知识库，对故障日志进行推理和分析，将开发者从繁重、重复的日志筛选中解放出来，精力聚焦于问题的解决方案上。

1. 应用冻屏问题一直是定位过程中的一大难题，往往需要掌握较多的分析技巧和知识才能准确定位。现在，借助AI分析能力，不仅可以大幅降低问题定位的门槛，还能基于故障库中的大数据给出常见的解决方案。只需点击故障详情中的"AI分析"按钮，即可在右侧弹出会话窗口，获取AI分析结果。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c3/v3/1hNIXGfaTbuvMGd1pum-UA/zh-cn_image_0000002613668917.png?HW-CC-KV=V1&HW-CC-Date=20260916T033630Z&HW-CC-Expire=31536000000&HW-CC-Sign=6C1FEA1B2197FBA263BC51C1A491B18764C5301BD7B4A237E7AA6BD0B9AEC1B6)

2. 以流式方式持续输出AI分析的结果，由浅到深逐步分析故障的根因给出相关的分析结果，包含【故障基本信息】、【根因分析】、【三级根因定位】、【证据链】、【根本原因】、【根因模块】、【修复建议】分析模块，使用者可以逐步掌握该类型的分析过程及关键点。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/14/v3/Mzfxid2DSYOIro-hILs-4g/zh-cn_image_0000002611981397.png?HW-CC-KV=V1&HW-CC-Date=20260916T033630Z&HW-CC-Expire=31536000000&HW-CC-Sign=10DB572C08E807EADBE127B2B082FC03ED9919FE0021AA74D3CA44ECFD3374D8)

3. AI分析会结合鸿蒙系统的故障知识库给出对应的故障根因、根因模块和修复建议，使用者可以根据修复建议结合自身工程源码进行问题修复。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f0/v3/KA_23xOWTV-0GN69KHKUSw/zh-cn_image_0000002581542172.png?HW-CC-KV=V1&HW-CC-Date=20260916T033630Z&HW-CC-Expire=31536000000&HW-CC-Sign=5D0E76E9529D36F7284AA3965DA4DE2A7C7D069B3170E2DF7CEDE7CDA4E3E733)

4. 使用结束后可以通过点击空白处或右侧的"x"按钮能够关闭该对话框。
