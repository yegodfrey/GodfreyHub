# Permission

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|id|O|String(32)|权限ID。|
|provisionName|O|String(256)|权限名称。|
|apl|O|String(20)|权限等级。 取值范围： * normal：默认等级，允许应用访问超出默认规则外的普通系统资源，如配置Wi-Fi信息、调用相机拍摄等。这些系统资源的开放（包括数据和功能）对用户隐私以及其他应用带来的风险较低。 * system_basic：系统基础等级，允许应用访问操作系统基础服务（系统提供或者预置的基础功能）相关的资源，如系统设置、身份认证等。这些系统资源的开放对用户隐私以及其他应用带来的风险较高。 * system_core：系统核心等级，涉及开放操作系统核心资源的访问操作。这部分系统资源是系统最核心的底层服务，一旦遭受破坏，操作系统将无法正常运行。|
|grantType|O|String(32)|授权方式。 取值范围： * system_grant：表示系统授权类型，在该类型的权限许可下，应用被允许访问的数据不会涉及到用户的个人信息。 * user_grant：表示用户授权类型，在该类型的权限许可下，应用被允许访问的数据将会涉及到用户的个人信息。 * manual_settings：表示手动设置授权类型，在该类型的权限许可下，应用被允许访问的数据将会涉及到用户的个人信息，应用被允许执行的操作可能对系统或者用户产生严重的影响。|
|supportDevice|O|List\<String\>|权限支持的设备列表。 值为空表示支持所有的设备。|
|startApiVersion|O|String(32)|权限的起始API版本号。|
|permissionLanguages|O|List\<[PermissionLanguage](https://developer.huawei.com/consumer/cn/doc/app/agc-help-provision-api-data-permissionlanguage-0000002585575019)\>|权限的多语言信息。 数组长度不超过1000。|
