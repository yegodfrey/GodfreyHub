# 推广管理

* 在推广任务列表，支持针对单个任务启用或停用；支持勾选全部/部分任务进行批量启用或批量停用。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7/v3/PAiF3rwZTcO3mAEqhLy3KQ/zh-cn_image_0000002656440338.png?HW-CC-KV=V1&HW-CC-Date=20261008T153934Z&HW-CC-Expire=31536000000&HW-CC-Sign=07885A6B92F2F67B936F569A8466E266B0C2B0EF6648A8D2873F6DBEF1F7EC88 "点击放大")

* 任务状态包括草稿、启用中、停用、完成、审核中、审核不通过、审核通过，可筛选对应状态的任务。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/47/v3/ZXbcdlZlRX6V7_SYnuWiVw/zh-cn_image_0000002686639737.png?HW-CC-KV=V1&HW-CC-Date=20261008T153934Z&HW-CC-Expire=31536000000&HW-CC-Sign=E7CD93621B9BEF225BAE4D99400029B7BDEEB0ED00D5A1CB517ED37B158A23A6 "点击放大")
> 注意
>
> 推广任务新建并保存后，状态为草稿；后续编辑草稿态的任务时，不支持再次保存，编辑后仅支持提交审核。
