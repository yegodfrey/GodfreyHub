# 推广管理

* 在推广任务列表，支持针对单个任务启用或停用；支持勾选全部/部分任务进行批量启用或批量停用。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7/v3/PAiF3rwZTcO3mAEqhLy3KQ/zh-cn_image_0000002656440338.png?HW-CC-KV=V1&HW-CC-Date=20260911T034430Z&HW-CC-Expire=31536000000&HW-CC-Sign=F1D5116A7C7B6564F1B50DFB84358753768F9B4EDA84F4EFF196EF13E02C30C7 "点击放大")

* 任务状态包括草稿、启用中、停用、完成、审核中、审核不通过、审核通过，可筛选对应状态的任务。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/47/v3/ZXbcdlZlRX6V7_SYnuWiVw/zh-cn_image_0000002686639737.png?HW-CC-KV=V1&HW-CC-Date=20260911T034430Z&HW-CC-Expire=31536000000&HW-CC-Sign=A308F8C777609AAF8EC62A24996A1681F413329EBAD4037678D7F7838325A94E "点击放大")
> 注意
>
> 推广任务新建并保存后，状态为草稿；后续编辑草稿态的任务时，不支持再次保存，编辑后仅支持提交审核。
