# RemoteConfigOptions

|Class Info|
|:-------------------------------------------------|
|RemoteConfigOptions 远程配置初始化选项接口，用于配置SDK的连接参数和认证信息。|

## Public Property Summary

|属性名|类型|必填|说明|
|:----------------------|:------|:-|:-----------------|
|context|Context|是|应用上下文对象，用于获取应用资源|
|regin|string|是|主区域标识（如"CN"）|
|reginBack|string|否|备用区域标识（如"CN_back")|
|agcgwAllRegin|string|是|AGC网关主区域地址|
|agcgwAllReginBack|string|否|AGC网关备用区域地址|
|websocketgwAllRegin|string|是|WebSocket网关主区域地址|
|websocketgwAllReginBack|string|否|WebSocket网关备用区域地址|
|storageUrlRegin|string|是|存储服务主区URL|
|storageUrlReginBack|string|否|存储服务备用区域URL|
|agcgwUrl|string|是|AGC网关URL|
|productId|string|是|项目ID，从AGC控制台获取|
|appId|string|是|应用ID，从AGC控制台获取|
|clientId|string|是|客户端ID，用于身份认证|
|apiKey|string|是|API密钥，用于服务调用认证|
