# 灰度采集

灰度采集支持圈选故障设备，精准采集故障日志，帮助开发者定位线上问题，适用于需要获取详细故障信息的场景。页面提供创建任务、查看进度和分析故障日志的能力。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到对应项目，在项目下的应用列表中点击对应应用/元服务。
3. 左侧导航栏选择"质量 > APMS > 配置管理"，进入配置管理主界面。
4. 选择"灰度采集"页签，进入灰度采集管理页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2/v3/ih4BfbXtSLW9haGMGWPvdQ/zh-cn_image_0000002624722857.png?HW-CC-KV=V1&HW-CC-Date=20261008T152113Z&HW-CC-Expire=31536000000&HW-CC-Sign=69646DB33A17B2F34A417DBD8070E55775201B78F9790DD5B9CF6A9939BB87C3)

   以下为灰度采集页面对应的筛选条件说明：

   |------|-----------------------------------------------------------------------------------------------------------------------------------------------------|
   |**参数**|**说明**|
   |故障类型|支持采集的故障类型，包括： * RSS_LEAK：RSS内存泄漏故障 * JS_LEAK：ArkTs OOM故障 * FD_LEAK：FD内存泄漏故障 * GPU_LEAK：GPU内存泄漏故障|
   |应用版本|应用的版本标识|
   |设备型号|设备型号标识|
   |ROM版本|系统软件版本标识|
   |开始时间|灰度采集任务的创建时间|
   |结束时间|灰度采集任务的结束时间|
   |计划采集数据|计划采集的故障日志数量|
   |已采集数量|当前已经采集到的故障日志数量|
   |状态|灰度采集任务执行状态，包括： * 已创建：灰度采集任务已经创建成功，等待下发到故障设备 * 已停止：开发者手动停止灰度任务 * 采集中：灰度采集任务已经下发到故障设备 * 采集成功：灰度采集任务已采集到预期故障日志份数，自动停止任务 * 采集失败：灰度采集任务未采集到预期故障日志份数，自动停止任务|
   |操作|可以对灰度采集任务执行的动作，包括： * 终止：主动停止灰度采集任务 * 智能分析：查看故障日志分析结论|

> 说明
>
> 使用灰度采集功能，需要开发者提前在应用中适配并启用灰度功能，具体配置方法请参见"[性能分析服务](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/performance-analysis-kit)"。

## 创建灰度采集任务

1. 点击右上角的"创建任务"按钮，创建新的灰度采集任务。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/54/v3/8WoPtdjUTOi5RLnBks6CRA/zh-cn_image_0000002619524017.png?HW-CC-KV=V1&HW-CC-Date=20261008T152113Z&HW-CC-Expire=31536000000&HW-CC-Sign=08A5715E859B99A2DBC5441CF7617AEC7ECBF99AC0FA07DA823AC35865F63044)

2. 选择需要分析的"故障类型"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4a/v3/-1RfT4uVRH-lQGX-TjG1Vg/zh-cn_image_0000002588964496.png?HW-CC-KV=V1&HW-CC-Date=20261008T152113Z&HW-CC-Expire=31536000000&HW-CC-Sign=3E37BC74CD5E7D86C0B0D56D8E7865535B38F5BB308B1CDFBD83F28997FBAA26)

3. 如需精准的圈选故障设备，可以补充"应用版本"、"ROM版本"、"设备型号"信息。
4. 故障日志默认采集10份，支持调整采集日志份数，最大允许采集20份故障日志。
5. 通过"采集时间"设置灰度采集任务的生效时间，最长时间7天。

> 说明
>
> * 每个应用只允许有一个灰度采集任务在运行中，如果新建灰度采集任务，需要确保历史灰度采集任务已经结束。
> * 每个应用每周最多允许下发3次灰度采集任务，超过3次会创建失败。

## 查看灰度采集任务状态

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8e/v3/z6VFjKwkR9Sx9uM3-ngvrA/zh-cn_image_0000002619412669.png?HW-CC-KV=V1&HW-CC-Date=20261008T152113Z&HW-CC-Expire=31536000000&HW-CC-Sign=1C312551511D108C234257DC650EC260ED427372FADA4D19453CEED58634915D)

* 在列表中可以查看灰度采集任务执行进度。
* 点击"刷新"按钮，可以刷新任务进度，查看采集故障日志的份数。
* 点击操作栏的"终止"按钮可以提前终止当前灰度采集任务。
* 如已采集到故障日志，点击操作栏的"智能分析"按钮可以查看故障日志分析结果。
