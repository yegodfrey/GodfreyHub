# 配置隐私标签信息

游戏发布设备类型包括手机、平板、PC/2in1、智慧屏时，要求配置隐私标签信息。

隐私标签帮助玩家提前了解游戏使用玩家个人数据的情况。隐私标签展示效果请参见[客户端展示效果](https://developer.huawei.com/consumer/cn/doc/privacy-label#section1815423719106)。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"APP与元服务"，选择待上架的游戏。
2. 左侧导航栏选择"应用上架 > 版本信息"下待发布的版本。
3. 进入右侧页面的"隐私标签信息录入"区域，根据实际情况勾选是否涉及个人信息收集：
   * 如果不涉及收集用户的信息数据，"是否涉及个人信息收集"选择"否"，配置结束。
   * 如果涉及收集用户的信息数据，"是否涉及个人信息收集"选择"是"，继续配置。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a5/v3/hmU-4-EPRC-RhKTeP3k32A/zh-cn_image_0000002509382631.png?HW-CC-KV=V1&HW-CC-Date=20261008T140145Z&HW-CC-Expire=31536000000&HW-CC-Sign=6038A219E1C721C155F081D88857D539C17A112B1E279192C811A10B23849982)

4. 请选择与游戏相关联的业务场景，最多支持同时勾选6种业务场景。 说明
   >
   > 若您的游戏中不涉及广告与营销的相关内容，请勿在业务场景中勾选"广告与营销"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3b/v3/txUCvd0gT7y7aFC4dHXjJA/zh-cn_image_0000002477302692.png?HW-CC-KV=V1&HW-CC-Date=20261008T140145Z&HW-CC-Expire=31536000000&HW-CC-Sign=65BC5F0FAA6E8760703F112E026018AE3311FDFD31E358E2FFDF8A4391F0D3E6)

5. 依次在已勾选的业务场景下添加对应的数据项。 业务场景和数据项具体内容参见[AppGallery隐私标签服务说明](https://developer.huawei.com/consumer/cn/doc/app/privacy-label)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9/v3/wpLEJHYGSYGYsnljmUqpnA/zh-cn_image_0000002515359251.png?HW-CC-KV=V1&HW-CC-Date=20261008T140145Z&HW-CC-Expire=31536000000&HW-CC-Sign=60E2BEFC88FF539CFBFDA4DAE88EFAB3951CD4289078D5C82CB582842F99B29B)

6. 配置完业务场景的数据项后，可在"关联到用户数据汇总"页签查看全部数据。 说明
   >
   > 业务场景页签下的数据项不能为空。若存在未配置数据项的业务场景，对应业务场景页签的左上角将有红点提示。
