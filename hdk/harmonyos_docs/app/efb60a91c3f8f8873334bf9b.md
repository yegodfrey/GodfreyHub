# 获取云端配置项

## 前提条件

* 您已在AGC控制台[设置云端配置项](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-setcloudconfig-0000002694843251)。
* 您需要在您的应用中[集成SDK](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-integratesdk-0000002665043402)。

## 获取和更新云端配置数据到本地

调用[RemoteConfig.fetch](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-api-remoteconfig-0000002664883514#section1176012013115)接口从远程配置服务获取参数值，返回异步任务。获取成功后会返回从云端同步的[ConfigValues](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-api-configvalues-0000002665043408)数据（可通过此类只获取云端数据），再调用[RemoteConfig.apply](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-api-remoteconfig-0000002664883514#section486198212)接口传入云端同步获取的值使其生效。

```screen
RemoteConfig.fetch().then(configValues => {
  hilog.info(0x0000, 'testTag', `Succeeded in fetching data, configValues: ${JSON.stringify(configValues)}`);
  RemoteConfig.apply();
// 开发者自行处理业务逻辑
}).catch((error: Error) => {
  hilog.error(0x0000, 'testTag', 'Fetch Apply error %{public}s', error.name+error.message);
})
```

[RemoteConfig.fetch](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-api-remoteconfig-0000002664883514#section1176012013115)接口可能会有网络延迟，导致[RemoteConfig.apply](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-api-remoteconfig-0000002664883514#section486198212)接口未能将云端最新的数值传入。为了避免此情况，您可以先调用[RemoteConfig.fetch](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-api-remoteconfig-0000002664883514#section1176012013115)接口，然后在需要传入云端数据的地方先调用[RemoteConfig.loadLastFetched](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-api-remoteconfig-0000002664883514#section747015487214)接口加载之前通过[RemoteConfig.fetch](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-api-remoteconfig-0000002664883514#section1176012013115)接口获取的信息，然后再调用[RemoteConfig.apply](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-api-remoteconfig-0000002664883514#section486198212)接口。

以下为[RemoteConfig.loadLastFetched](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-api-remoteconfig-0000002664883514#section747015487214)接口的示例代码：

```screen
ConfigValues last = RemoteConfig.loadLastFetched();
config.apply(last);
```

> 说明
>
> [RemoteConfig.fetch](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-api-remoteconfig-0000002664883514#section1176012013115)接口默认更新周期为12小时，也可以自行设置更新周期，在更新周期内再次调用[RemoteConfig.fetch](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-api-remoteconfig-0000002664883514#section1176012013115)接口不会去云侧同步数据，而是使用本地缓存数据直接返回。

## 获取参数值

在设置默认值和更新云端参数值后，您可以调用[RemoteConfig.getValue](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-api-remoteconfig-0000002664883514#section11870122513219)接口通过键值来获取参数进行使用。

## 获取全部参数值

您可以调用[RemoteConfig.getMergedAll](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-api-remoteconfig-0000002664883514#section743811341720)一次性获取全部本地默认值和云端参数值，而不是通过键值来读取，相同键值的参数会使用云端数据。

```screen
let values: Record<string,Object> | undefined;
values = RemoteConfig.getMergedAll();
```

## 重置参数值

您可以调用[RemoteConfig.clearAll](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-api-remoteconfig-0000002664883514#section011016145315)清空之前所有的参数值，将设置的默认值、云端参数值全部都清除。

```screen
RemoteConfig.clearAll();
```
