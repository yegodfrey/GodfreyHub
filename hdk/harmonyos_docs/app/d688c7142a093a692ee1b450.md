# 概述

发布应用/元服务时，您需要提供隐私政策，以便用户了解应用的数据收集和使用情况。

* **HarmonyOS应用** ：支持选择自定义隐私政策，或者使用隐私声明托管服务生成隐私声明。
  * 如果已经有专门描述隐私政策和用户隐私权利的网站：在发布时，可以直接填写网址，无需参考本章节进行隐私声明托管。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/27/v3/T0wpm15ASPGhe8KHOVremg/zh-cn_image_0000002560876161.png?HW-CC-KV=V1&HW-CC-Date=20261008T162506Z&HW-CC-Expire=31536000000&HW-CC-Sign=D6FC76861045B1DCC2960AD7C4E0A09D4C2049CF2101863BB39262DAD1FF5253)


  * 如果没有：当应用发布地区包含中国大陆区域，且分发设备为手机、平板或PC/2in1时，可以使用AppGallery Connect的隐私声明托管服务，基于标准化模板生成自己的隐私声明。在发布时，选择创建的内容即可。具体请参见[配置隐私政策（HarmonyOS应用）](https://developer.huawei.com/consumer/cn/doc/app/agc-help-privacy-policy-app-0000002282162168)和[配置用户协议](https://developer.huawei.com/consumer/cn/doc/app/agc-help-privacy-user-agreement-0000002282265450)。"用户协议"非必须配置项，您可以根据实际情况进行选择是否配置。

    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/11/v3/HPrdzxSITAebl8bZ4Y-HRg/zh-cn_image_0000002530036380.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T162506Z&HW-CC-Expire=31536000000&HW-CC-Sign=DE71B669AFD0004F360D87F6DCDEFD72C9A7DFA6142A7490AF141E360D9FE450)

* **元服务** ：必须使用AppGallery Connect的隐私声明托管服务，基于标准化模板生成自己的隐私声明。在发布时，选择创建的内容即可。具体请参见[配置隐私政策（元服务）](https://developer.huawei.com/consumer/cn/doc/app/agc-help-privacy-policy-atomic-0000002317135133)和[配置用户协议](https://developer.huawei.com/consumer/cn/doc/app/agc-help-privacy-user-agreement-0000002282265450)。"用户协议"非必须配置项，您可以根据实际情况进行选择是否配置。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e7/v3/OFpDT4SrTUyKvGjdq7LlxQ/zh-cn_image_0000002332556801.png?HW-CC-KV=V1&HW-CC-Date=20261008T162506Z&HW-CC-Expire=31536000000&HW-CC-Sign=18BD32DD3F0ADAA7A0DABFAD9C99DF4B8D835E78D102926AC65C1B2CCB8EFFD9)

  若账号下的部分元服务无需使用隐私托管服务，请联系华为申请。在收到申请后，华为将在1-3个工作日内安排对接人员。申请方法如下：
  * 申请邮箱地址：agconnect@huawei.com。
  * 邮件标题：[托管隐私声明禁用清单]-[应用类型]-[应用名称]-[应用包名]-[应用ID]-[Developer ID]，应用包名等查询方法可参见[查看应用信息](https://developer.huawei.com/consumer/cn/doc/app/agc-help-view-app-info-0000002282674569)。
  * 邮件正文：请说明申请原因。

如果在应用/元服务中使用了隐私托管服务，则首次打开应用/元服务，会默认显示标准化隐私弹窗，您可以在应用/元服务中集成AppGallery Kit的[隐私管理服务](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/store-privacy)实现查询隐私链接、查询隐私签署状态、停止隐私协议和拉起标准化隐私弹窗等功能。
> 注意
>
> * 请在应用/元服务上架前，使用debug模式模拟接入[隐私管理服务](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/store-privacy#未上架应用接入隐私管理服务)，验证隐私弹窗效果。
> * 请在应用/元服务启动时，主动监听[隐私弹框签署结果公共事件](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/store-privacy#隐私弹框签署结果公共事件)或[查询隐私签署状态](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/store-privacy#查询隐私签署状态-1)，确保用户同意隐私声明之后，再执行业务代码，如申请设备权限。
> * 请勿在应用/元服务中自行实现弹窗展示隐私声明，否则会因为重复弹窗问题导致上架审核被驳回。
