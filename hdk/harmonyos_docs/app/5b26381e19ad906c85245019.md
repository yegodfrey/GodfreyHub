# 设置上架时间

## 设置上架时间

您可以选择让元服务审核通过后立即上架，也可以指定一个特定时间上架。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"快速开始"中的"元服务一站式平台"卡片。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/01/v3/N-Grv9B0ROqyhuvKzRF93g/zh-cn_image_0000002529682783.png?HW-CC-KV=V1&HW-CC-Date=20261008T153519Z&HW-CC-Expire=31536000000&HW-CC-Sign=9B1BAF767080011F968A7C2A3A4E61FE1304FECF4B446DD5885F836665BEDD9D)

2. 在左上角下拉列表选择要发布的元服务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7f/v3/H528gVx_RaOQpIbu1TBhGw/zh-cn_image_0000002566867053.png?HW-CC-KV=V1&HW-CC-Date=20261008T153519Z&HW-CC-Expire=31536000000&HW-CC-Sign=1A2BFA2699A528766F38E366175D9323E21E6A64A631514082D0785F3B2F3242)

3. 左侧导航选择"元服务上架 > 版本信息"下待发布的版本。
4. 进入"上架"区域，设置上架时间。 指定时间：选择时为您的本地时间，设置完成后，系统将自动转换成UTC标准时间，并显示在时间框后。

   > 说明
   >
   > 如果后续需要在指定时间前上架，可以[手动发布待上架元服务](#section0726113812279)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fc/v3/9ziQPhS9QcqKz0R5Rww2Wg/zh-cn_image_0000002327611073.png?HW-CC-KV=V1&HW-CC-Date=20261008T153519Z&HW-CC-Expire=31536000000&HW-CC-Sign=9E1F1061F9AAF9E624798AF474B4235BCB7925E29531EBA43A28448FA4053082)

## 手动发布待上架元服务

如果您之前设置了指定时间上架，审核通过后您又想在设定时间之前上架，则可以手动发布上架。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"快速开始"中的"元服务一站式平台"卡片。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/36/v3/BHFJ4iGoRN6SJ2Gq-1JL3Q/zh-cn_image_0000002529682783.png?HW-CC-KV=V1&HW-CC-Date=20261008T153519Z&HW-CC-Expire=31536000000&HW-CC-Sign=9D12B5107D4EFB41E43830ADD9502D0A670915E46306032DF2458D1E04F26109)

2. 在左上角下拉列表选择要发布的元服务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6f/v3/zN1bJYz5RXWSKH_mPSADdQ/zh-cn_image_0000002566867053.png?HW-CC-KV=V1&HW-CC-Date=20261008T153519Z&HW-CC-Expire=31536000000&HW-CC-Sign=9995FBD5C60BB6563576D5BDD3C575655A35FABE3380D6DD002DFD36C10871F5)

3. 左侧导航选择"元服务上架 > 版本信息"下待发布的版本。
4. 点击右上角的"手动发布"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a1/v3/OIQLMVtlTzmraPBjx4fh6A/zh-cn_image_0000002344394057.png?HW-CC-KV=V1&HW-CC-Date=20261008T153519Z&HW-CC-Expire=31536000000&HW-CC-Sign=21BBB08FF31EB664279A9D568FF50CCC3672C781577C08A04557C58162305523)

5. 点击"确认"。 手动发布一般在几分钟内生效。
