# 设置上架时间

## 设置上架时间

您可以选择让元服务审核通过后立即上架，也可以指定一个特定时间上架。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"快速开始"中的"元服务一站式平台"卡片。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/01/v3/N-Grv9B0ROqyhuvKzRF93g/zh-cn_image_0000002529682783.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=2E5059969E03EA1A97AFE5BA13F2664F394DB4DD0F7E99A2C1EE95C29BF08C95)

2. 在左上角下拉列表选择要发布的元服务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7f/v3/H528gVx_RaOQpIbu1TBhGw/zh-cn_image_0000002566867053.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=DC80D239F2CDA520C247E913170253EEE6E336EED71539B96D497D7A4106C49E)

3. 左侧导航选择"元服务上架 > 版本信息"下待发布的版本。
4. 进入"上架"区域，设置上架时间。 指定时间：选择时为您的本地时间，设置完成后，系统将自动转换成UTC标准时间，并显示在时间框后。

   > 说明
   >
   > 如果后续需要在指定时间前上架，可以[手动发布待上架元服务](#section0726113812279)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fc/v3/9ziQPhS9QcqKz0R5Rww2Wg/zh-cn_image_0000002327611073.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=3CC22F4553AD8D3AC7D25FB617F7FF4D9CEB8529A05F7C208A188982492334AE)

## 手动发布待上架元服务

如果您之前设置了指定时间上架，审核通过后您又想在设定时间之前上架，则可以手动发布上架。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"快速开始"中的"元服务一站式平台"卡片。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/36/v3/BHFJ4iGoRN6SJ2Gq-1JL3Q/zh-cn_image_0000002529682783.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=36F353BFD4922D88710418F185BDDD745CC4A50BE9E7489E03FA4363DF08A6B9)

2. 在左上角下拉列表选择要发布的元服务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6f/v3/zN1bJYz5RXWSKH_mPSADdQ/zh-cn_image_0000002566867053.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=A6891AE043DC058B915AE9490DDD991A42CA9F8616D5BBEAEAACBC957DD94958)

3. 左侧导航选择"元服务上架 > 版本信息"下待发布的版本。
4. 点击右上角的"手动发布"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a1/v3/OIQLMVtlTzmraPBjx4fh6A/zh-cn_image_0000002344394057.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=753730E2A544FB619013B7DC91980D5B2D848227F9A411D98C21A4EF5442F5AC)

5. 点击"确认"。 手动发布一般在几分钟内生效。
