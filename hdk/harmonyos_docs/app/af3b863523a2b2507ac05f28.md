# 批量修改商品

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"APP与元服务"。
2. 在应用列表中点击需要批量修改商品的应用。
3. 在"运营"页签下的左侧导航栏中，选择"产品运营>商品管理"。
4. 下载表格，批量修改商品信息并上传。 注意
   >
   > 请按照规范批量修改商品信息，否则会在上传时报错，具体错误信息可参见[常见错误说明](https://developer.huawei.com/consumer/cn/doc/app/mistakes-0000001958955121)。
   * 方法一：

   a）点击页面右上角![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107153645.89891093333799225853123065159358:50001231000000:2800:553BB08E2F0563E996FA5F7E7A8D92DDE474782E5E56D6C688AE97E17257EE92.png "点击放大")，下载商品模板并保存到本地。

   b）按规范修改商品信息。

   c）点击"批量操作"下拉选项中的 "修改商品"，并在弹出的添加框中点击![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107153645.68506733854814122679704663686773:50001231000000:2800:CAB691B61EE30BA3608A05735BD98870565D8FDD8FB98550A1CA5BE5B547B20D.png "点击放大")选择上传已填写的商品模板。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107153645.82569112887664931661269378063971:50001231000000:2800:1FAA330A3C2E6F72C65103BC52024F73FC412ECC61C3FF50D910755609C3ACEE.png)
   * 方法二：

   a）点击"导出商品"，下载商品信息表格并保存到本地。

   b）按规范修改商品信息。

   c）点击"批量操作"下拉选项中的 "修改商品"，并在弹出的添加框中点击![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107153645.78139713599346812957158340889146:50001231000000:2800:575410F31C705F6D5E11829536B001256F80E0992EA7D9E42AE23B7D22536FA9.png "点击放大")选择上传已修改的商品信息表格。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107153645.19861085841242949429926093536944:50001231000000:2800:22511121B0FD38AB0AB9408FF7972DC43DAB76EC1C02BA516EEEBB1776E710A6.png)

5. 在确认页面可查看商品信息修改前后对比图，点击"确定"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107153645.44417022745452108860714571857725:50001231000000:2800:0B8E00508E3EA50AABCA58F497E99C6B4C412FC3F27649B1BEC39C9CA77FFD9C.png "点击放大")

   > 说明
   >
   > 已通过审核的数字商品，如果仅修改其价格和商品销售范围，则无需重新提交审核，新价格和新的商品销售范围立即生效；如果还修改了其他基本信息或审核信息，则需要再次提交审核，数字商品方可生效。
