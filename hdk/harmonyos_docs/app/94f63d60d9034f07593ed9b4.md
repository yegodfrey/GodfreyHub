# 上传已注册意图的软件包

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6f/v3/K_L-2ihbQli7O7kswxReUQ/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043439Z&HW-CC-Expire=86400&HW-CC-Sign=8E6793647B93B6A3590DE7C0AE25E943E3485F4D151C2FDEB0383F09B40FDF52)

如果软件包尚未注册意图，请先完成[意图开发](https://developer.huawei.com/consumer/cn/doc/app/agc-help-insight-config-poi-0000002349175932)。

请根据您的应用/元服务上架状态，判断是否需要上传软件包：

                * 如果您注册意图的应用/元服务已上架到华为应用市场，可跳过本步骤。
                * 如果您注册意图的应用/元服务尚未上架，则需要[上传软件包](https://developer.huawei.com/consumer/cn/doc/app/agc-help-release-app-upload-pkg-0000002277983368)。
