# Android应用转移

Android应用转移是指将AppGallery Connect中的Android应用（含游戏）从一个账号转移到另一个账号进行维护。
> 注意
>
> 当前应用转移仅对账号信息做转移，之前接入的服务、申请的权限等都无法确保转移成功，转入方需要重新调试所有接入的服务和能力，确认没有问题再上架。
> 说明
>
> 若转出方账号存在异常，无法登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)或找不到"应用转移"按钮，请参考开发者联盟管理中心的[非HarmonyOS应用转移](https://developer.huawei.com/consumer/cn/doc/app/agc-help-transferapp-0000001099998802)文档。

## 前提条件

* 当前支持转移的应用类型：
  * apk应用支持手机、手表、智慧屏和车机设备。
  * rpk应用支持手机、智慧屏和车机设备。


* 待转移应用状态不能在审核中，需属于"准备提交"、"待上架"、"已上架"、"待修改"、"已撤销上架"或"被开发者下架"中的一种。
* 待转移应用不能有手机预装服务、权签服务、音乐服务、零售预装样机服务。
* 若应用开通了HealthServiceKit服务，请先完成转入方开发者资质审核，具体请参见运动健康服务《[应用开发者申请资质说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/application-qualification-description-0000001425636570)》。
* 转入方、转出方开发者账号都已实名认证，未被冻结，且无违规处罚记录（已取消处罚或已缴清违约金等）。
* 转入方开发者需使用团队账号接收应用。
* 若转出方为商户用户，转入方需开通商户服务才可以接收应用。
* 推广应用请排查以下情况：
  * 若应用存在有效投放任务，如：付费推广、游戏有奖下载活动、云文件夹推广、礼包合作、预装合作、技术合作，需要前往[华为应用市场付费推广平台](https://developer.huawei.com/consumer/cn/service/apcs/app/home.html)完成或者取消任务。
  * 若应用已授权给客户投放伙伴，需要前往[华为应用市场付费推广平台](https://developer.huawei.com/consumer/cn/service/apcs/app/home.html)取消授权。

  * 若推广账户仍有余额，请在退款后申请应用转移。
* 存在运营活动请排查以下情况：
  * 若应用下的礼包任务状态为"草稿、新建驳回、撤销、下线通过"时可转移，如不处于以上状态，需要下线或删除礼包后申请转移。
  * 若活动的奖品是华为优惠券，且活动的任务状态为"草稿、新建驳回、撤销"时可转移，如不处于以上状态，需要活动结束15天后申请转移。
  * 若活动的奖品是礼包或第三方卡券，且活动的任务状态为"草稿、新建驳回、撤销、终止、下线通过"时可转移，如不处于以上状态，需要活动结束后申请转移。

## 提交应用转移申请

### 转出方发起应用转移申请

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"APP与元服务"。
2. 在应用列表中选择待提交应用转移申请的应用，进入应用详情页。
3. 点击页面底部的"应用转移"，系统会自动检测应用是否符合转移条件。 说明
   >
   > 如果您的应用在转移流程中，则不能再申请应用转移。点击"应用转移"仅用于申请操作，若您想要查看审核情况，请参见"[查看应用转移进度](#section897674113113)"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c0/v3/nKAl53TAR0CRZVh8X09wsQ/zh-cn_image_0000002510922196.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=06E879C8D4619D43A734FF4F42E362AD5C6D9A17A87C0421613F7614F0A24C57)
4. 若应用不符合转移条件，需根据提示进行处理，可参考[前提条件](#section1511853114505)排查原因。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/36/v3/en5HRQ7DSBqScR-ZHCYXZA/zh-cn_image_0000001472790161.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=BEAB0F7B75CB28541D6A3B4FE4B4E018843C4F5D796F3363A8921DDA74DF7FFD)
5. 若应用符合转移条件，则进入"应用（含游戏）转移申请"页面，填写完成后点击"提交"。
   * 转入者ID：接收应用的开发者账号。
   * 转入者名称：接收应用的开发者名称。 说明
     >
     > 您可以在"[管理中心 > 开发者信息](https://developer.huawei.com/consumer/cn/console/setting/profile)"页面查看转入者的名称。个人开发者应填写"个人基本信息"模块的"真实姓名"，企业开发者应填写"账号持有者信息"模块的"名称"。
   * 转移原因：申请应用转移的原因（最多200字）。
   * 附件：补充应用转移原因的附件（大小在100MB以内的zip格式文件）。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/29/v3/ftjACBCzRIyT8e32mIOMQg/zh-cn_image_0000002509186297.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=2FE1E13135223F8CC0E4990F31CEDDEADCAAEE9E27E608578E1023D5D545C1B6)
6. 如果您是使用子账号发起的应用转移申请，提交成功后，需要转出方团队管理员再确认。如果是团队账号发起的应用转移申请，可跳过以下步骤。
   1. 转出方团队管理员登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击首页左下角"互动中心待办"的"更多"，进入互动中心页面。

   2. 选择"应用审核"，点击"应用转移申请已提交"，在对话界面点击"查看转移申请"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b6/v3/qeeMxmhERJS0-B_PwhfQpA/zh-cn_image_0000002551742449.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=3F1CC7C43002D35129D2C35788707D932A3D0FA4B42BB80C0D190293D8BC28CC)

   3. 在弹出的"转出方团队代表确认"框中，您可以同意或拒绝转出应用。

      ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4/v3/1asVH46CSXqDYtg1hnfYoQ/zh-cn_image_0000002480741016.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=24EADA498C9D879B76F5E29AA5BF2ADFA632DCF2577FB66B1295AB8274279ED0)
      * 点击"拒绝"表示您拒绝转出应用，转移流程结束。
      * 点击"同意转出"后，子账号会接收到同意转出通知；团队账号后续可以[查看应用转移进度](#section897674113113)；转入方会收到应用转移申请。

### 转入方确认接收应用

当转出方已确认转出应用，转入方即可收到应用转移申请。

1. 转入方登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击首页左下角"互动中心待办"的"更多"，进入互动中心页面。
2. 选择"应用审核"，点击"应用转移接受确认"，在对话界面点击"查看转移申请"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/98/v3/W4QZz_X6TpeDlX365_43Kg/zh-cn_image_0000002520702454.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=1D44CBF97FEB179A5A0BBAE15DC1E45E4A917A94BA36A4C5859C81FDE0A6A4DB)

3. 在弹出的"转入方确认"框中，您可以同意或拒绝接收应用。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a4/v3/2XH8Co48QiuxXTc2rIxyww/zh-cn_image_0000002522962300.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=D33958CE5D5E56BE07277874C8DA91FE6E9E1A79C454302054EC9D850FE647EE)
   * 如果您同意接收应用：
     1. 在"是否接收"处选择"同意"。
     2. 在"版权资质文件"处上传版权和版号资质（大小在100MB以内的zip格式文件）。具体请参见《[资质审核要求](https://developer.huawei.com/consumer/cn/doc/app/80301)》。 说明
        > * 若应用所属原公司已注销无法提供公章，或者个人开发者离职需转移至本公司却无法提供签名，还需要提供相关证明文件进行申请。
        > * 若应用状态是"准备提交"（草稿态）或者提交的软件包分发地不包含中国大陆，则不需要提交版权资质文件。
     3. 勾选"我已阅读并同意《应用（含游戏）转移声明》"。
     4. 点击"提交"，应用转移提交华为方审核。


   * 如果您拒绝接收应用：
     1. 在"是否接收"处选择"拒绝"。
     2. 在"拒绝转移原因"处输入拒绝接收应用的原因（最多200字）。
     3. 点击"提交"，应用转移流程结束。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/42/v3/hccIJCFtQKK5BSAf0XG1Yg/zh-cn_image_0000002515746391.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=BFEE376C62C237967913F47C9210E34C085284D0EF17842FAE4F7936A807C739)

### 查看应用转移进度

登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击首页左下角"互动中心待办"的"更多"，进入互动中心页面，在应用转移的对话界面点击"查看转移申请"，可以查看转移进度。

* 当应用转移申请状态处于"审核中"时，如果转入方还未确认接收，转出方团队管理员可以通过点击"取消转移"来撤回应用转移申请。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/51/v3/IuLa3wApQfWAdUUxcxeliw/zh-cn_image_0000002483426558.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=663608A2B505C4D8440DFB11A42FF7DD01B6152D0FCBBBB0DA47CB58610983CF)

* 当应用转移申请状态处于"检测通过"时，表示转入方已经确认接收。
* 当应用转移申请状态处于"资质审核中"时，表示转入方已经提交资质审核。 说明
  >
  > 审核人员会在3个工作日内处理应用转移申请，并通过邮件或者互动中心发送审核结果，请耐心等待。
* 当应用转移申请状态处于"资质审核通过"时，表示转入方提交的资质审核已经通过。
* 当应用转移申请状态处于"转移驳回"时，表示华为方不同意应用转移申请， 转出方需要根据审核意见修改后再次提交申请。
* 当应用转移申请状态处于"转移成功"时，表示华为方已经同意应用转移申请， 应用转移完成。

## 提交审核

应用转移成功后，华为方会通过邮件或者互动中心发送转移成功通知。

转入方需在3个工作日内登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)重新提交应用审核并更新版权、版号等资质文件，审核通过后华为应用市场方能显示新的开发者名称。若未及时更新或更新的文件不符合华为应用市场资质审核标准，则华为应用市场有权下架该应用。

## FAQ

### Mac电脑的Safari浏览器阻止打开应用转移页面，如何处理？

**现象描述：**使用Mac电脑进行应用转移，点击"应用转移"按钮时，Safari浏览器会阻止打开应用转移页面。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/af/v3/X7HIXy5kQJqSfybo7MYwhQ/zh-cn_image_0000002542679427.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=C24FEA32DCC2572D6E527A6A51DDAE5C6E4E54C45656F55825F1CDF5F2031955)

### 是否支持跨站点转移？

支持。
