# (可选）配置应用签名证书指纹

签名证书指纹是应用签名证书（.cer文件）的摘要信息，用于校验应用的真实性。如您的应用当前集成的华为相关服务（如华为账号服务）依赖签名证书指纹，您需要在应用调试或上架前将签名证书指纹配置到AGC。
> 说明
>
> 调试和发布使用的签名证书不同，因此调试和发布前请分别基于使用的证书配置相应的证书指纹。

不同应用类型配置方式有所不同，请根据应用类型进行配置：

* [Android应用](#section95912032173715)
* [HarmonyOS应用/元服务（API 9以下）](#section1766216380372)
* [HarmonyOS应用/元服务（API 9及以上）](#section5181019153511)

## Android应用

如待发布应用为Android应用，您需通过命令行方式生成应用的签名证书指纹，然后将指纹证书配置到AGC。每个Android应用最多支持添加10个签名证书指纹。

### 生成签名证书指纹

在生成签名证书指纹前，请确保：

* 您已创建应用程序的签名证书，签名证书创建请参见[生成签名证书](https://developer.huawei.com/consumer/cn/codelab/HMSPreparation/index.html#2)。
* 当前PC已经安装[JDK](https://www.oracle.com/java/technologies/javase-downloads.html)。

操作步骤如下：

* Windows
  1. 执行CMD命令打开命令行工具，执行**cd** 命令进入keytool.exe所在的目录（以下样例为JDK安装在C盘的Program Files目录）。

     ```screen
     cd C:\Program Files\Java\jdk\bin
     ```

  2. 执行命令**keytool -list -v -keystore** *<keystore-file>* ，按命令行提示进行操作。*<keystore-file>* 为应用签名证书的完整路径。

     例如：

     ```screen
     keytool -list -v -keystore C:\TestApp.jks
     ```

  3. 根据结果获取对应的SHA256指纹。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/16/v3/C7_K49dLQqSp5mF8Kjem6Q/zh-cn_image_0000001629114240.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=E56D8BAAD463BE3F2E2C9375142EEE3AC00B8844C9B5FE114BEC667678823B5E)

* macOS
  1. 打开Terminal终端。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/64/v3/K79FFkGkTn6bCZZVTOCPVw/zh-cn_image_0000001629246446.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=812074DAC6237BAC6254A735ECD2AF9D11FEE74EB2A5B3B8155E7707E2EFD672)

  2. 执行命令**keytool -list -v -keystore** *<keystore-file>* ，按命令行提示进行操作。*<keystore-file>* 为应用签名证书的完整路径。

     例如：

     ```screen
     keytool -list -v -keystore /Users/admin/Downloads/HmsDemo.jks
     ```

  3. 根据结果获取对应的SHA256指纹。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cf/v3/kfJ1f-1RQm6FM_5fWbz-IA/zh-cn_image_0000001629274228.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=1AFDB0B7DC6B932F26B088DD554C43CC67100095A504941FCEBC2A9B450DF0D2)

### 配置签名证书指纹

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，进入[项目列表](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/myProject)。
2. 在项目列表中找到您的项目，在项目中点击您的应用。
3. 在"项目设置 > 常规"页面的"应用"区域，点击"SHA256证书指纹"后的"添加证书指纹"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d1/v3/IlDNDImHRLyEj3yWch92hA/zh-cn_image_0000001677650877.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=3CE6A8014366B30E76A5B44394DF6BBF293C44968BF3BF2E9306ED363F8CD2E5)
4. 在输入框中填入[步骤3](#ZH-CN_TOPIC_0000001628566748__li951717401398)获取的签名证书指纹，点击"保存"。 说明
   >
   > 指纹配置成功后大约10分钟左右生效，请您耐心等待。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/24/v3/Q3xgKoCmS0KOaecm9xARKQ/zh-cn_image_0000001629611352.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=4D6713FE3B47765DBBFFAF0211DDF956765DA8DA7D14780049680F59E3D33ABC)

## HarmonyOS应用/元服务（API 9以下）

如HarmonyOS应用/元服务支持的API版本低于API 9，您可选择通过命令行方式手动生成签名证书指纹、或者使用DevEco Studio自动生成签名证书指纹，然后将获取的指纹证书配置到AGC。每个应用/元服务最多支持添加10个签名证书指纹。

### 手动生成签名证书指纹

在生成签名证书指纹前，请确保您已通过DevEco Studio或命令行工具[生成密钥文件（.p12文件）和证书请求文件（.csr文件）](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V2/publish_app-0000001053223745-V2#section9752152162813)。

操作步骤如下：

* Windows
  1. 执行CMD命令打开命令行工具，执行**cd** 命令进入keytool.exe所在的目录（以下样例为JDK安装在C盘的Program Files目录）。

     ```screen
     cd C:\Program Files\Java\jdk\bin
     ```

  2. 执行命令**keytool -list -v -keystore** *<keystore-file>* ，按命令行提示进行操作。*<keystore-file>* 为应用/元服务签名证书的完整路径。

     例如：

     ```screen
     keytool -list -v -keystore D:\harmony\key\myApplication.p12
     ```

  3. 根据结果获取对应的SHA256指纹。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a/v3/G3Fml9HpQyWBbXLN3lspFg/zh-cn_image_0000001629594556.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=63B309249DEE1A92596BF1C2F116D07EDFB26DFE403BDAB5CE2DE058F97475FC)

* macOS
  1. 打开Terminal终端。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a9/v3/SgH1iX7_QOG4Yl8KxcOApw/zh-cn_image_0000001629598188.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=B4D48B295083EE486EAF61C5665FEE3A6ABA77F4CE85F6C1026CAE19BFE3417E)

  2. 执行命令**keytool -list -v -keystore** *<keystore-file>* ，按命令行提示进行操作。<keystore-file>为应用/元服务签名证书的完整路径。

     例如：

     ```screen
     keytool -list -v -keystore /Users/xxxxxx/Downloads/myApplication.p12
     ```

  3. 根据结果获取对应的SHA256指纹。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/85/v3/u6HNM4S-RWKw3o2RVgNthA/zh-cn_image_0000001629435004.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=94D3D2A2EBA23A31EEEC889884685BFABC9160371655B3B75FC94CED5328D3CC "点击放大")
