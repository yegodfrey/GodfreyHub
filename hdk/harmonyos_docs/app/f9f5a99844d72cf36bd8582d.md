# (可选）配置应用签名证书指纹

签名证书指纹是应用签名证书（.cer文件）的摘要信息，用于校验应用的真实性。如您的应用当前集成的华为相关服务（如华为账号服务）依赖签名证书指纹，您需要在应用调试或上架前将签名证书指纹配置到AGC。  
![](https://media:301781667761084555)  
调试和发布使用的签名证书不同，因此调试和发布前请分别基于使用的证书配置相应的证书指纹。

不同应用类型配置方式有所不同，请根据应用类型进行配置：

* [Android应用](#section95912032173715)
* [HarmonyOS应用/元服务（API 9以下）](#section1766216380372)
* [HarmonyOS应用/元服务（API 9及以上）](#section5181019153511)

#### Android应用

如待发布应用为Android应用，您需通过命令行方式生成应用的签名证书指纹，然后将指纹证书配置到AGC。每个Android应用最多支持添加10个签名证书指纹。  

#### 生成签名证书指纹

在生成签名证书指纹前，请确保：

* 您已创建应用程序的签名证书，签名证书创建请参见[生成签名证书](https://developer.huawei.com/consumer/cn/codelab/HMSPreparation/index.html#2)。
* 当前PC已经安装[JDK](https://www.oracle.com/java/technologies/javase-downloads.html)。

操作步骤如下：

* Windows
  1. 执行CMD命令打开命令行工具，执行cd命令进入keytool.exe所在的目录（以下样例为JDK安装在C盘的Program Files目录）。

     ```
     cd C:\Program Files\Java\jdk\bin
     ```

  2. 执行命令keytool -list -v -keystore \<keystore-file\>，按命令行提示进行操作。\<keystore-file\>为应用签名证书的完整路径。

     例如：

     ```
     keytool -list -v -keystore C:\TestApp.jks
     ```

  3. 根据结果获取对应的SHA256指纹。 ![](https://media:301781667761428556)

* macOS
  1. 打开Terminal终端。 ![](https://media:301781667761736557)

  2. 执行命令keytool -list -v -keystore \<keystore-file\>，按命令行提示进行操作。\<keystore-file\>为应用签名证书的完整路径。

     例如：

     ```
     keytool -list -v -keystore /Users/admin/Downloads/HmsDemo.jks
     ```

  3. 根据结果获取对应的SHA256指纹。

![](https://media:301781667761790558)  

#### 配置签名证书指纹

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，进入[项目列表](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/myProject)。
2. 在项目列表中找到您的项目，在项目中点击您的应用。
3. 在"项目设置 \> 常规"页面的"应用"区域，点击"SHA256证书指纹"后的"添加证书指纹"。

   ![](https://media:301781667761851559)
4. 在输入框中填入[步骤3](#ZH-CN_TOPIC_0000001628566748__li951717401398)获取的签名证书指纹，点击"保存"。  
   ![](https://media:301781667762059560)  
   指纹配置成功后大约10分钟左右生效，请您耐心等待。

![](https://media:301781667762391561)  

#### （可选）删除签名证书指纹

您可将不需要的指纹删除。  
![](https://media:301781667762447562)  
删除指纹会导致需要对应用合法进行校验的所有API调用失败，请谨慎操作。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，进入[项目列表](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/myProject)。
2. 在项目列表中找到您的项目，在项目中点击您的应用。
3. 在"项目设置 \> 常规"页面的"应用"区域，找到"SHA256证书指纹"栏中需删除的指纹，点击![](https://media:301781667762513563)。

   ![](https://media:301781667762559564)

   <br />

4. 弹出确认提示框，核对指纹信息无误后，点击"确认"。 ![](https://media:301781667762596565)

   <br />

   <br />

#### HarmonyOS应用/元服务（API 9以下）

如HarmonyOS应用/元服务支持的API版本低于API 9，您可选择通过命令行方式手动生成签名证书指纹、或者使用DevEco Studio自动生成签名证书指纹，然后将获取的指纹证书配置到AGC。每个应用/元服务最多支持添加10个签名证书指纹。  

#### 手动生成签名证书指纹

在生成签名证书指纹前，请确保您已通过DevEco Studio或命令行工具[生成密钥文件（.p12文件）和证书请求文件（.csr文件）](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V2/publish_app-0000001053223745-V2#section9752152162813)。

操作步骤如下：

* Windows
  1. 执行CMD命令打开命令行工具，执行cd命令进入keytool.exe所在的目录（以下样例为JDK安装在C盘的Program Files目录）。

     ```
     cd C:\Program Files\Java\jdk\bin
     ```

  2. 执行命令keytool -list -v -keystore \<keystore-file\>，按命令行提示进行操作。\<keystore-file\>为应用/元服务签名证书的完整路径。

     例如：

     ```
     keytool -list -v -keystore D:\harmony\key\myApplication.p12
     ```

  3. 根据结果获取对应的SHA256指纹。 ![](https://media:301781667762629566)

* macOS
  1. 打开Terminal终端。 ![](https://media:301781667762664567)

  2. 执行命令keytool -list -v -keystore \<keystore-file\>，按命令行提示进行操作。\<keystore-file\>为应用/元服务签名证书的完整路径。

     例如：

     ```
     keytool -list -v -keystore /Users/xxxxxx/Downloads/myApplication.p12
     ```

  3. 根据结果获取对应的SHA256指纹。 ![](https://media:301781667762747568 "点击放大")

#### 自动生成签名证书指纹

![](https://media:301781667762885569)  
DevEco Studio 3.0 Beta2 3.0.0.803及以上版本才支持自动生成签名证书指纹。

1. 打开DevEco Studio，进入[配置工程的签名信息](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-publish-app#section945904791115)的界面，点击"Store file(\*.p12)"后的指纹图标。

   ![](https://media:301781667763091570)
2. 弹出的"Certificate Fingerprint"窗口将展示自动生成的签名证书指纹，复制保存此信息。 ![](https://media:301781667763287571)

#### 配置签名证书指纹

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，进入[项目列表](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/myProject)。
2. 在项目列表中找到您的项目，在项目中点击您的应用/元服务。
3. 在"项目设置 \> 常规"页面的"应用"区域，点击"SHA256证书/公钥指纹"后的"添加公钥指纹"。 ![](https://media:301781667763392572)

   <br />

4. 在"添加SHA256公钥指纹"窗口，"添加方式"选择"输入指纹"，然后在输入框中填入之前获取的签名证书指纹，点击"确认"。 ![](https://media:301781667763435573)

   <br />

5. 指纹添加成功后，将展示在"SHA256证书/公钥指纹"栏。  
   ![](https://media:301781667763466574)  
   指纹最迟在25小时后生效。如您急需指纹生效，请执行下一步操作。

   ![](https://media:301781667763604575)

   <br />

6. （可选）如果希望配置的公钥指纹快速生效，请在指纹成功配置10分钟后，通过改变应用/元服务工程"app.json5"文件中的"versionCode"字段的值触发指纹生效。例如，原先值为"1000000"，修改为"1000001"。 ![](https://media:301781667763638576)
