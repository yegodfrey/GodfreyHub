# 修改测试态服务  
  
当您创建的测试态服务已过生效时段或需要调整POI点位、测试用户、卡片内容等时，您可以尝试修改测试态服务。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e5/v3/UhXRqi4-SHycVqLPPHvDDg/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043456Z&HW-CC-Expire=86400&HW-CC-Sign=CB98AA12A7743BCCBE0060E828F69515FF123C18DA2F8D47A4A191F8BBBFCDD7)

如果测试态服务有正在进行的测试任务，请先删除相关测试任务。在修改测试态服务之前，需先将其下线，然后进行编辑和提交。提交修改的测试态服务后，需重新创建测试任务并开始测试。

                1. 如果测试态服务未开始测试，请忽略此步骤。

如果测试态服务已开始测试，在左侧菜单栏选择“近场服务>近场测试”，进入近场测试主界面。在“测试管理”列表中点击要修改测试任务“操作”列的“删除”，将正在进行中的测试任务从列表中删除。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/97/v3/cZaqIG67TsCf87f5xkSaww/zh-cn_image_0000002485642129.png?HW-CC-KV=V1&HW-CC-Date=20261005T043456Z&HW-CC-Expire=86400&HW-CC-Sign=B821D47F8E91AA1FDD86CAA48F4F0A41D75A28C81EB97BAC3F845F8AEDDD7503)

                2. 在左侧菜单栏选择“近场服务>近场管理”，进入近场管理主界面。选择“服务管理”页签，在服务列表中点击要修改测试态服务“操作”列的“下线”。测试态服务下线后，才可对其进行修改。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8e/v3/8NO7WSxqRzSkOmrtZgw4Vg/zh-cn_image_0000002515039060.png?HW-CC-KV=V1&HW-CC-Date=20261005T043456Z&HW-CC-Expire=86400&HW-CC-Sign=3C9FD1BD0022AB2FA32E389F35E7892F5D2DBBCA08B3AD7D50C4704F27C2A776)

                3. 点击该测试态服务“操作”列的“编辑”，进入“编辑服务”页面。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9b/v3/MgtUnSqQSmGDivcosQDtTQ/zh-cn_image_0000002546599073.png?HW-CC-KV=V1&HW-CC-Date=20261005T043456Z&HW-CC-Expire=86400&HW-CC-Sign=B19305D9725183C484651783121E0B5B0176EAB52E8B63CE3793C3AD623DA5CE)

                4. 在“编辑服务”页面各配置区域进行修改，然后点击“提交”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bd/v3/7liZSm38SkOvM2bzlJu0Dg/zh-cn_image_0000002485653209.png?HW-CC-KV=V1&HW-CC-Date=20261005T043456Z&HW-CC-Expire=86400&HW-CC-Sign=05B439F12965EA667B429C1A955A81F1B7715C15FFA54493F52D18566A7BF51B)

                5. 在弹出框中点击“前往测试”，系统将跳转至“创建测试”页面 。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a7/v3/0d2jPdEIR0au4-_A9R0hrw/zh-cn_image_0000002485776313.png?HW-CC-KV=V1&HW-CC-Date=20261005T043456Z&HW-CC-Expire=86400&HW-CC-Sign=54ED9E02F3AEB96A1BB038C24F6BAE2CB3C7C91CAC6F96E39C7E57D75545244A)

                6. 根据实际需求编辑测试任务名称，并选择测试内容。然后点击页面右上角的“开始测试”，重新下发测试任务。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/04/v3/3IwNL4FSRdmzyBbrXi0ltQ/zh-cn_image_0000002452745846.png?HW-CC-KV=V1&HW-CC-Date=20261005T043456Z&HW-CC-Expire=86400&HW-CC-Sign=9AEDC898FC63619D1E29B17C277A95E1896142F737BF7CBBD8D5490AB3AE4B98)

                7. 以下操作台界面可辅助您查看POI地理围栏的范围，以及测试手机是否进入测试POI的200米感应范围内。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c5/v3/t6VgkVZrR0W_f-pSuvDBaA/zh-cn_image_0000002485797085.png?HW-CC-KV=V1&HW-CC-Date=20261005T043456Z&HW-CC-Expire=86400&HW-CC-Sign=2FBA015F3DE41F667E679B2E28A0AFA114948465B649DD86FF27A5209CA09270)
