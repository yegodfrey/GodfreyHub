# 设置自动刷新价格  
  
除人工修改商品价格方式外，我们还提供了每日汇率联动刷新价格的方式，帮助您解决可能因个别国家汇率波动较大而人工刷新不及时导致商品价格更新滞后的问题。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251209111317.20812957417855219699473361514330:50001231000000:2800:6B7534D497FE6CAFB1935C10A5721E238B9B8E414E354BB76C26532790B36426.png)

                * 当前，商品管理自动刷新价格为定向邀请功能，仅针对部分开发者开放。
                * 针对已设置自动刷新价格的国家/地区，您也无法通过[接口方式](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-pms-manage_product-0000001162468125#section1975810512053)人为修改这些国家/地区的商品价格，否则将会报错20008，请进入AGC控制台商品管理“设置”页面取消对应国家自动刷新价格设置。

#### 前提条件

您已成功创建应用内商品。

#### 操作步骤

                1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择“APP与元服务”。
                2. 在应用列表中点击需要设置自动刷新价格的应用。
                3. 在“运营”页签下的左侧导航栏中，选择“产品运营 > 商品管理”。
                4. 选择“商品列表”页签，并点击“设置”。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251209111317.46780386814441279836437555107865:50001231000000:2800:44981CF6B2F052498AD1A5961C0BFDCFBBEFD9C468E9A2206E41614604F71D5B.png)

                5. 在“设置”页面，选择自动刷新价格的国家/地区。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251209111317.73992839462176425767529761461205:50001231000000:2800:B52BD0323DBA6A36B16F9F600F5EF73EB4C87ECB4A8E7D7D3A0CBA419AE30C31.png)

已设置的自动刷新价格的国家/地区，将按照“汇率换算基准价格*汇率”的计算方式，每日固定时间点根据汇率自动刷新商品价格。该项设置针对本应用下所有商品生效，您可进入具体商品价格页面查看当天最新价格。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251209111318.77448772198794798695673664275533:50001231000000:2800:C2152138095CA7A506F07BF18A10D30754D029DBF169695EB1ACB3B6F5B0D4B5.png)

                6. 点击“保存”，并在弹窗中点击“确定”。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251209111318.38069274534373852411091437373099:50001231000000:2800:07FAF0024BD41E4B03DA797FF38EFBA8F38AEA5CEB20BE213C27C268BC07CAA1.png)

                   * 已选择的国家/地区不支持通过手动方式刷新商品价格。
                   * 已选择的国家/地区不支持设置促销价格，且系统将自动删除已设置的促销活动。
                   * 如需手动刷新某个已选择的国家/地区的商品价格，或者设置促销活动，请先取消对应国家/地区的自动刷新价格设置。
