# 还原数字商品

商品被删除后，您将无法通过商品列表查看该商品的相关信息。如果您需要找回已删除的商品，您可通过还原操作，将该商品恢复至商品列表中。
> 说明
>
> 目前，仅支持90天（含）内已删除商品的还原操作。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"APP与元服务"。
2. 在应用列表中点击需要被还原的商品的应用。
3. 在"运营"页签下的左侧导航栏中，选择"产品运营 > 商品管理"。
4. 点击页面右上角![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107153646.60362594795292356562562203237106:50001231000000:2800:F97F8833026D280C99C09AF6D709AA10561988BD4A175BF73CC2FA0578E3F022.png "点击放大")还原商品。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107153646.33328178612668315561555009664831:50001231000000:2800:72AA77B9BA0557D259C32C4E4BB9AE40BC6B59971130E74FF7B847795CEBE5CF.png "点击放大")
5. 在查询框中输入商品ID或商品标题，点击"确定"进行查询。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107153646.99414749243715024012467287117024:50001231000000:2800:BD8B31BE704303CB447F8D3F0FF47D792336CCE97D74497EAD097DF78AAD841E.png "点击放大")

6. 点击待还原商品"操作"列的"还原"，即可成功还原该商品。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107153646.71470333244386685533039616358261:50001231000000:2800:6C7D88BC33CF24ADF4AF04AB0B581CE59D403B2BD1CC2AD0D2EC48D692A81D64.png "点击放大")
