# 概述

HarmonyOS应用/元服务开发完成后，建议您在本地进行调试，以查看和验证应用/元服务的运行效果。

应用/元服务支持使用真机设备、模拟器、预览器调试，调试流程大致如下。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b3/v3/NvR5U2_NS66G2comP_a9ew/zh-cn_image_0000001991575393.jpg?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=C9D0D7A98FC2E6F9DE6F7F773D3C9D74DC8F750F3EF4C74659B048D26F6BF848 "点击放大")

1. 配置签名信息：使用模拟器和预览器调试无需签名，使用真机设备调试则需要对HAP进行签名。华为提供了两种签名方式，请根据实际情况选择：
   * [自动签名](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-signing-auto)：如果您只需要使用一台调试设备，建议使用DevEco Studio提供的自动签名。若业务不支持自动签名，则需使用手动签名。
   * 手动签名：如果您使用多台调试设备或者会在断网情况下调试，您需要在AGC中[申请调试证书](https://developer.huawei.com/consumer/cn/doc/app/agc-help-add-debugcert-0000001914263178)、[注册调试设备](https://developer.huawei.com/consumer/cn/doc/app/agc-help-add-device-0000001946142249)、[申请调试Profile](https://developer.huawei.com/consumer/cn/doc/app/agc-help-add-debugprofile-0000001914423102)后，再[手动配置签名信息](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-signing-manual#section15586174616)。
2. [设置调试类型](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-run-debug-configurations#section1170735241213)：调试类型默认为Detect Automatically。
3. [设置HAP安装方式](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-run-debug-configurations#section531811771410)：选择先卸载应用/元服务后再重新安装或覆盖安装。
4. [启动调试](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-debug-arkts-debug)：启动debug调试或attach调试。
