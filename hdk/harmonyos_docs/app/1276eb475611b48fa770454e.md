# Overview

## Interface Summary

|Interface|Description|
|:--------------------------------------------------------------------------------------------------------------------------|:-------------------------------|
|[RemoteConfig](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-api-remoteconfig-0000002664883514)|远程配置核心操作接口，提供配置的初始化、拉取、应用和读取等功能。|

## Class Summary

|Class|Description|
|:----------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------|
|[ConfigValues](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-api-configvalues-0000002665043408)|存储数据的类，在fetch方法中返回的ConfigValues对象用于调用apply方法。针对fetch方法返回的ConfigValues对象，只是从云端同步下来的数据，不包含default数据。|
