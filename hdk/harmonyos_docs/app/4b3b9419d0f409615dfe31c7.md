# 获取HarmonyOS应用下载安装的报表文件

#### 功能介绍

获取HarmonyOS应用下载安装报表数据的CSV或者Excel文件地址。

接口调用者的角色：账号持有者、国内管理员、App管理员、国内运营。  

#### 接口原型

|承载协议|HTTPS GET|
|接口方向|开发者服务器 -\> 华为服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/report/harmony-report/v1/harmony/appDownloadAnalysisExport/{appId}|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|
|-----|-----------------------------------------------------------------------------------------------------------|

#### Query

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:-------------------|:----------|:-------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|startTime|M|String|查询开始时间。 UTC时间。 格式：YYYYMMDD startTime和endTime之间不超过180天。|
|endTime|M|String|查询结束时间。 UTC时间。 格式：YYYYMMDD startTime和endTime之间不超过180天。|
|timeType|O|String|基于时间类型查询，取值范围： * day：按天查询 * week：按周查询 * month：按月查询|
|language|M|String(10)|查询语言。 报表title会根据不同语言来展现。 只支持简体中文（zh-CN）, 美式英文（en-US），俄文（ru-RU）。|
|filterCondition|O|List\<String\>|过滤器，取值范围： * countryId：按国家过滤 * appVersion：按应用版本过滤 * province：按省份过滤 * city：按城市过滤 * deviceName：按机型过滤 如果不传，默认无过滤器。 支持countryId、appVersion、province、city和deviceName同时使用，URL示例：\&filterCondition=countryId\&filterCondition=appVersion\&filterCondition=province\&filterCondition=city\&filterCondition=deviceName|
|filterConditionValue|O|List\<String\>|过滤器对应的值。 * 如果过滤器为countryId，此参数的取值为国家码的字符串数组，例如"CN, AL, AD, AT"。具体国家码列表参考[国家码](https://developer.huawei.com/consumer/cn/doc/app/agc-help-connect-api-appendix-countrycode-0000002236201362)。传入"all"表示查询全球，"all"不区分大小写。 * 如果过滤器为appVersion，此参数的取值为应用版本，多个版本以英文逗号分隔，如："1.0.0,2.0.0"。"all"表示查询所有应用版本，"all"不区分大小写。 * 如果过滤器为province，此参数的取值为省份，例如"上海市, 江苏省, 浙江省"。 * 如果过滤器为city，此参数的取值为城市，例如"上海市, 南京市, 杭州市"。 * 如果过滤器为deviceName，此参数的取值为设备型号的名称，如： "Mate30Pro-5G版"、"P40-lite"、"P30-Pro"、"P40-lite-5G"、"nova7-SE"、"nova7_SE_5G乐活版"、"nova6-5G版"、"mate20"。 如果传入多个过滤器，使用多个filterConditionValue表示，顺序必须与filterCondition中过滤器的顺序一致。URL示例： \&filterConditionValue=CN\&filterConditionValue=1.0.0\&filterConditionValue=江苏省\&filterConditionValue=南京市\&filterConditionValue=mate20|
|groupBy|O|String|数据统计的分组信息，支持按如下依据分组。取值范围： * date：按日期分组 * countryId：按国家分组 * appVersion：按应用版本分组 * province：按省份分组 * city：按城市分组 * deviceName：按机型分组 默认值：date。|
|exportType|O|String|导出文件类型。 取值范围： * CSV：导出CSV文件格式 * EXCEL：导出Excel文件格式 默认值：CSV。|

#### 响应参数

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------|:----------|:------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|fileURL|M|String|导出CSV或Excel文件的路径。 报表文件中字段语言由language参数指定，首个字段为groupBy参数中指定的数据统计分组类型。 文件中包含的字段说明请参见[HarmonyOS应用下载安装的报表数据说明](#ZH-CN_TOPIC_0000002271000737__zh-cn_topic_0000002046015285_p11623192525520)。|
|ret|M|[ConnectRet](https://developer.huawei.com/consumer/cn/doc/app/agc-help-report-api-data-connectret-0000002273219845)|包含返回码及描述信息的结果。|

HarmonyOS应用下载安装的报表数据说明  

|字段名|字段含义|
|:-------|:----------------------------------------------------|
|日期|数据统计日期。|
|应用版本|数据统计按应用版本进行分组。|
|国家/地区|数据统计按国家或地区进行分组。|
|机型|数据统计按机型进行分组。|
|有效曝光次数|应用在华为应用市场推荐、排行榜、搜索等资源位被展示次数，图片露出50%以上且曝光时间大于1s才算有效曝光。|
|ICON点击次数|应用在华为应用市场内曝光的ICON被点击的次数。|
|有效曝光点击率|ICON点击次数/有效曝光次数。|
|详情页访问次数|在华为应用市场内统计的应用详情页被浏览的次数。|
|总下载成功次数|更新下载成功次数 + 新下载成功次数。|
|更新下载成功次数|用户通过华为应用市场更新应用版本产生的下载成功次数。|
|新下载成功次数|用户通过华为应用市场新下载成功次数。 计算方式：第一次下载成功算一次，卸载后重新下载也算一次。|
|详情页转化率|详情页新下载次数（仅包括详情页带来的新下载次数）/详情页访问次数。|
|安装成功次数|应用在应用市场安装成功的次数（包含更新安装成功次数+新安装成功次数）。|
|新安装成功次数|用户通过华为应用市场新下载并安装成功的次数。|
|安装成功率|新下载应用安装成功的比例，即新安装成功次数/新下载成功次数。|
|卸载次数|从所有渠道安装或更新的应用被卸载的次数。|
