# AgreementBaseInfo（隐私政策协议）

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:-----------|:---------------------------------------------------|
|name|M|String(100)|隐私政策协议名称。|
|appName|O|String(255)|应用名称。|
|companyName|O|String(1024)|公司名称。|
|briefDesc|O|String(500)|产品简介。|
|effectiveTime|O|Integer(64)|隐私政策协议生效时间与1970年1月1日午夜之间的差值，以毫秒为单位。例如：1733555215000。|
