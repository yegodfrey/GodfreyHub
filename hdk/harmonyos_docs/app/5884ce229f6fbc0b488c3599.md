# 批量修改商品

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"APP与元服务"。
2. 在应用列表中点击需要批量修改商品的应用。
3. 在"运营"页签下的左侧导航栏中，选择"产品运营>商品管理"。
4. 下载表格，批量修改商品信息并上传。 注意
   >
   > 请按照规范批量修改商品信息，否则会在上传时报错，具体错误信息可参见[常见错误说明](https://developer.huawei.com/consumer/cn/doc/app/agc-help-mistakes-0000002425264353#ZH-CN_TOPIC_0000002425264353)。
   * 方法一：

   a）点击页面右上角![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d2/v3/7Oo6SGqJR2Cqo0UJyDyxiA/zh-cn_image_0000001931836388.png?HW-CC-KV=V1&HW-CC-Date=20260916T033630Z&HW-CC-Expire=31536000000&HW-CC-Sign=1104089C6205597D188CB3E83C97CCC82E5A8D7D0634AB7012D5760EDDEDDD1A "点击放大")，下载商品模板并保存到本地。

   b）按规范修改商品信息。

   c）点击"批量操作"下拉选项中的 "修改商品"，并在弹出的添加框中点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9d/v3/MWU2o7qUTP254wTU-YE9ZA/zh-cn_image_0000001959074937.png?HW-CC-KV=V1&HW-CC-Date=20260916T033630Z&HW-CC-Expire=31536000000&HW-CC-Sign=9609BE621AC4BB19FA2DF0B243FF0355894B64B7466637CBED4C58B495E6EB93 "点击放大")选择上传已填写的商品模板。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/14/v3/qbNcU6S9QQGIVAkcfTQd6w/zh-cn_image_0000002449458877.png?HW-CC-KV=V1&HW-CC-Date=20260916T033630Z&HW-CC-Expire=31536000000&HW-CC-Sign=88466E76DA6D4254354F2BA623A4DBBA2DCE09CE65307C57C4345689B0347664)
   * 方法二：

   a）点击"导出商品"，下载商品信息表格并保存到本地。

   b）按规范修改商品信息。

   c）点击"批量操作"下拉选项中的 "修改商品"，并在弹出的添加框中点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b0/v3/ZMwXc-K3STCIBIBppRYLxQ/zh-cn_image_0000001933997360.png?HW-CC-KV=V1&HW-CC-Date=20260916T033630Z&HW-CC-Expire=31536000000&HW-CC-Sign=78B57C5D632ED073B9A52E1CC4F1848CE35184C3C873A4F13B5E867F28D1EA67 "点击放大")选择上传已修改的商品信息表格。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/13/v3/LCIm0JvkRHG4JYEzPg8fZw/zh-cn_image_0000002415820428.png?HW-CC-KV=V1&HW-CC-Date=20260916T033630Z&HW-CC-Expire=31536000000&HW-CC-Sign=4BCB3F734E1F481FAA6600379258F7D29BE2370814C8E7CB709895B1A6139486)

5. 在确认页面可查看商品信息修改前后对比图，点击"确定"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/28/v3/Xfsuhls1R8isswaee-HeXQ/zh-cn_image_0000001931995772.png?HW-CC-KV=V1&HW-CC-Date=20260916T033630Z&HW-CC-Expire=31536000000&HW-CC-Sign=E52C6A544EA71F30BE40FFE83DBAC188884DAE886DC2031A3A58DF23626CEC68 "点击放大")

   > 说明
   >
   > 已通过审核的数字商品，如果仅修改其价格和商品销售范围，则无需重新提交审核，新价格和新的商品销售范围立即生效；如果还修改了其他基本信息或审核信息，则需要再次提交审核，数字商品方可生效。
