# 批量修改商品

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"APP与元服务"。
2. 在应用列表中点击需要批量修改商品的应用。
3. 在"运营"页签下的左侧导航栏中，选择"产品运营>商品管理"。
4. 下载表格，批量修改商品信息并上传。 注意
   >
   > 请按照规范批量修改商品信息，否则会在上传时报错，具体错误信息可参见[常见错误说明](https://developer.huawei.com/consumer/cn/doc/app/agc-help-mistakes-0000002425264353#ZH-CN_TOPIC_0000002425264353)。
   * 方法一：

   a）点击页面右上角![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d2/v3/7Oo6SGqJR2Cqo0UJyDyxiA/zh-cn_image_0000001931836388.png?HW-CC-KV=V1&HW-CC-Date=20261008T182704Z&HW-CC-Expire=31536000000&HW-CC-Sign=55F2AA6D42F4E533BEF014B5979A6E6042007337D2FD276F42098E2F76516CDA "点击放大")，下载商品模板并保存到本地。

   b）按规范修改商品信息。

   c）点击"批量操作"下拉选项中的 "修改商品"，并在弹出的添加框中点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9d/v3/MWU2o7qUTP254wTU-YE9ZA/zh-cn_image_0000001959074937.png?HW-CC-KV=V1&HW-CC-Date=20261008T182704Z&HW-CC-Expire=31536000000&HW-CC-Sign=F6717B5AF47D188111214A6F6E69DD5ED93A145B047AB4F858F79BB4F7B4A686 "点击放大")选择上传已填写的商品模板。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/14/v3/qbNcU6S9QQGIVAkcfTQd6w/zh-cn_image_0000002449458877.png?HW-CC-KV=V1&HW-CC-Date=20261008T182704Z&HW-CC-Expire=31536000000&HW-CC-Sign=6FD3D7C471E0BB5C111BD574007B4605B368913317F9FC5CCE953856B7236A5F)
   * 方法二：

   a）点击"导出商品"，下载商品信息表格并保存到本地。

   b）按规范修改商品信息。

   c）点击"批量操作"下拉选项中的 "修改商品"，并在弹出的添加框中点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b0/v3/ZMwXc-K3STCIBIBppRYLxQ/zh-cn_image_0000001933997360.png?HW-CC-KV=V1&HW-CC-Date=20261008T182704Z&HW-CC-Expire=31536000000&HW-CC-Sign=11D3D1B9125BD7BC2F8BC673A2B3CDFD30ADC97C1FC3F5ADD6AD04B5681C7B0F "点击放大")选择上传已修改的商品信息表格。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/13/v3/LCIm0JvkRHG4JYEzPg8fZw/zh-cn_image_0000002415820428.png?HW-CC-KV=V1&HW-CC-Date=20261008T182704Z&HW-CC-Expire=31536000000&HW-CC-Sign=347CD03EB04B5FFA3CE14ACA39D7770FC155BAE193E5E3B8D191510E5C9F62DA)

5. 在确认页面可查看商品信息修改前后对比图，点击"确定"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/28/v3/Xfsuhls1R8isswaee-HeXQ/zh-cn_image_0000001931995772.png?HW-CC-KV=V1&HW-CC-Date=20261008T182704Z&HW-CC-Expire=31536000000&HW-CC-Sign=B8D40B89FC3B87EC01C96078A8D21B0D0D115E1772FFA6CF133B9EBC75562D91 "点击放大")

   > 说明
   >
   > 已通过审核的数字商品，如果仅修改其价格和商品销售范围，则无需重新提交审核，新价格和新的商品销售范围立即生效；如果还修改了其他基本信息或审核信息，则需要再次提交审核，数字商品方可生效。
