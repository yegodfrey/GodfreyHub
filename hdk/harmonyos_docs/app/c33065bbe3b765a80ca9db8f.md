# 开发流程

|序号|任务|说明|
|:-|:-------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------|
|1|[创建项目和应用](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-create-app-0000002664883504)|项目是您在AGC资源的组织实体，您可以将一个应用的不同平台版本添加到同一个项目中。|
|2|[开通服务](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-enable-service-0000002665043400)|首次使用远程配置服务前，需要先开通此服务。|
|3|[集成SDK](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-integratesdk-0000002665043402)|在使用远程配置相关功能前，您需要将AGC SDK及远程配置SDK集成到您的开发环境。|
|4|[设置应用内默认值](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-setvalue-0000002694923357)|您可以在远程配置对象中设置应用程序内的默认值，以便您的应用程序在连接到远程配置服务之前按照预期运行。|
|5|[设置云端配置项](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-setcloudconfig-0000002694843251)|您可以在AGC创建新的云端配置项，根据所需的条件逻辑，将新的配置项替换到应用中。|
|6|[获取云端配置项](https://developer.huawei.com/consumer/cn/doc/app/remoteconfig-hos-arkts12-obtainconfig-0000002664883510)|您可以通过相关接口获取所需配置项的值。|
