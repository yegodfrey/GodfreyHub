# MemberRoleList

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------------|:----------|:-------------------------------------------------------------------------------------------------------------|:---------------------------------------------|
|uid|O|String|团队成员的账号ID。|
|huaweiAccountName|O|String|团队成员的华为账号名称。|
|memberNickName|O|String|团队成员的昵称。|
|memberState|O|Integer|团队成员的状态。 取值范围： * 1：邀请中 * 2：邀请过期 * 3：生效中 * 4：过期|
|roles|O|List<[Role](https://developer.huawei.com/consumer/cn/doc/app/agc-help-publish-api-data-role-0000002679289169)>|团队成员的角色。|
