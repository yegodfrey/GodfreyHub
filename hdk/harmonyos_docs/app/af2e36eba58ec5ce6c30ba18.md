# 查看服务套餐详情

您可以在AppGallery Connect查看当前项目下订阅的所有免费档和按量付费档套餐。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中点击您的项目，进入"项目设置"页面。
3. 点击"项目套餐"页签，可查看当前项目下的套餐列表。
   * 如果套餐名后缀为"免费档"，表示已订阅该免费档套餐。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/06/v3/naR-5K7mS6WGCbB3OVMNpQ/zh-cn_image_0000002373879262.png?HW-CC-KV=V1&HW-CC-Date=20260909T153044Z&HW-CC-Expire=31536000000&HW-CC-Sign=71663BCA909F2DA7F0974055EAB74708E58C2CFB3870BA430B8D40AA4234029E)

   * 如果套餐名后缀为"按量付费档"，表示已订阅该按量付费档套餐。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9d/v3/-KEqGdreTPC-SX8bE7nNEA/zh-cn_image_0000002373879970.png?HW-CC-KV=V1&HW-CC-Date=20260909T153044Z&HW-CC-Expire=31536000000&HW-CC-Sign=F1D44F3E55705C12D3CEFE57C850F7F5BF432904C500693BC7821904B26E0C3E)
