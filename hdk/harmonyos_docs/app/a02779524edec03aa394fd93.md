# 应用认领

上传软件包时，如果您发现包名已被占用，且确认该软件包为您所有，且您尚未在华为开发者联盟上传过该软件包，则可通过申请应用认领来获取该应用的归属权。应用认领成功后， 该应用会自动转入您的账号下，您可在AppGallery Connect实现对应用的管理及维护。
> 注意
>
> * 如果认领的应用原本是在架状态，认领成功后应用会被下架。
> * 应用认领后，原有的所有服务将无法使用，且不保留历史下载量和评论数据，即仅认领应用软件包，请谨慎操作。
> * 如果您只需要更换主体，建议选择[应用转移](https://developer.huawei.com/consumer/cn/doc/app/agc-help-apptransfer-0000001439309461)，以防应用下架以及数据的丢失。

## 前提条件

当前仅中国大陆地区开发者的APK和RPK应用支持应用认领申请。

## 提交应用认领申请

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"APP与元服务"。
2. 在应用列表中选择待提交应用认领申请的应用，进入应用详情页。
3. 在上传软件包处上传您想要认领的软件包。
4. 在弹出的"包名重复"提示框中点击"应用认领"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/61/v3/jtp3veuYSdKF2-ocy7i5eA/zh-cn_image_0000001432704640.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=8D036786813C4BF659C3AF82EC6D2E39CD85640911FE5B60BA1AEEE14BD19EAB)

5. 阅读弹出框中的建议说明后，填写应用认领申请，完成后点击"提交"。
   * 应用包名：待认领应用的包名。
   * 空白包下载链接：点击"空白包"下载待签名空白包，解压HWNS.zip获取空白包HWNS.apk。 说明
     >
     > RPK包无法通过以下方式获取，请参考[RPK包获取方法](#section2762820384)。
   * 上传签名包：参考以下步骤将待认领应用的签名写入该空白包中，并上传。
     1. 找到待认领应用的签名文件（.jks文件），选择一个目录存放该文件。
     2. 将下载的空白包HWNS.apk和签名文件存放在同一目录下。
     3. 打开cmd，进入上面目录地址，输入命令（对应替换黑色加粗文件）：jarsigner -verbose -keystore ***test.jks*** -signedjar ***test.apk*** ***HWNS.apk** **test*** 说明
        >
        > 命令字段解析：
        > * test.jks：待认领应用的签名文件。
        > * test.apk：写入签名后的空白包。
        > * HWNS.apk：下载的空白包。
        > * test：签名文件test.jks的别名。
   * 上传附件：上传相关应用认领理由的附件（大小在5MB以内的zip格式文件）。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ed/v3/eU7R5wEpRgSQfOhjipl5jQ/zh-cn_image_0000002476962054.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=16E830D6DFB38B9797A56E2E3E7A4AD73FE183A71D468F95091B901D7415B00F)
6. 提交成功后，您可以点击首页左下角"互动中心待办"的"更多"，进入互动中心页面查看成功提交通知。审核完成后互动中心将会发送审核结果，请您耐心等待。

## RPK包获取方法

1. 请参考[快应用IDE操作指南](https://developer.huawei.com/consumer/cn/doc/Tools-Guides/ide-overview-0000001147936547)下载并安装[华为快应用IDE](https://developer.huawei.com/consumer/cn/doc/Tools-Library/quickapp-ide-download-0000001101172926)。
2. 点击菜单栏"新建项目 > 快应用"后，点击"下一步"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e7/v3/hBpFVO60RYmfuwoyELO1RA/zh-cn_image_0000001483266141.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=255AB8E13E66D27B85FE4CB485E183C16D75468555F5FB23C6F0A063AB476AB9)

3. 选择"Hello World"模板，并点击"下一步"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/62/v3/4lfjmFdMT6eVy7iRSSspTA/zh-cn_image_0000001483353581.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=2221FE5B8C236B4F299BF01BE65FB8FA452F198C41353CE35F5D22DE58C3C4DA)

4. 填写"应用名称"、"应用包名"后，点击"确定"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/93/v3/gYPIYMIeTGC5jwg9XslWYg/zh-cn_image_0000001432877464.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=D681AAE49FF13CE667248F9FA9808C971E0154C3347F16E516699A3CFC059FD8)

5. 为了避免RPK包过大（带签名空包大小需在4KB-15KB之间），删去/src/common/logo.png文件。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/24/v3/vYNTHEXfSQG4ddCcZh6Mgg/zh-cn_image_0000001433022260.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=27FA1BC9828DB64917526AFCE71A906C6333760D0C0D1B250017959DEF3F0238)

6. 菜单栏点击"Tools > Certificate"，在界面右下角提示中选择"导入签名"，选择应用发布签名文件"certificate.pem"、"private.pem"后，所选文件会自动存放到工程/sign/release目录下。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/97/v3/hSGiC4zPQH-96vkNR6i-2g/zh-cn_image_0000001433181500.png?HW-CC-KV=V1&HW-CC-Date=20260916T030830Z&HW-CC-Expire=31536000000&HW-CC-Sign=3C1441F0157AC813158695D44F986FF9536ECACF0696A210D093ACC50042D20F)

7. 点击菜单栏"Build > Run Build"，完成后自动弹出RPK包存放的位置，您也可以在dist目录下找到文件。
