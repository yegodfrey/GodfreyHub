# 快速入门

APMS作为面向开发者的应用质量管理系统，遵循[AGC账号管理体系](https://developer.huawei.com/consumer/cn/doc/app/agc-help-developid-0000002235870038)，账号持有者可以通过邀请其他华为账号加入到团队，并指定"管理员"、"APP管理员"或"开发"角色，即可使用APMS全量功能。
