# 配置本地化基础信息（介绍、特性）

您可以为元服务支持的语言配置相应的应用介绍和特性，这些信息将展示在应用详情页面，用户通过这些信息可以快速了解您的元服务。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"快速开始"中的"元服务一站式平台"卡片。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/55/v3/IDK7DJ94TZyaLPvg7S0KDw/zh-cn_image_0000002529682783.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=CC168D4A161BE62BA69B8D99D3BA7E87E5B68EC7A04199509224981DD980A783)

2. 在左上角下拉列表选择要发布的元服务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8c/v3/MG_8MnNyQLyW15gUE4zeOw/zh-cn_image_0000002566867053.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=FF110C610C85F6142FBBDFAA43710753637AF09DD0A0646156D075DE6EF9F5AA)

3. 左侧导航选择"元服务上架 > 版本信息"下待发布的版本。
4. 进入"可本地化基础信息"区域，选择配置的语言。 "语言"栏将展示您在"应用信息"中配置的语言类别。此处仅支持切换语言，不支持新增或删除语言。如果没有为所有语言配置相应的信息，则将使用默认语言配置的内容。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3d/v3/tWxAe0dhSJOeLvd0mZYKaA/zh-cn_image_0000002293811230.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=3ADEB99803E9B7CD1EE058E7901A7F7749325674496FFA6C0029FCB5D9CC4B57)

5. 填写应用介绍、应用一句话简介。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e7/v3/5ShWH6hPSmCPZyeGLp8F-w/zh-cn_image_0000002515539144.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=5DF0AA758141248A308FC4BDDF62980738E88D775F7F9296BFBB86915EAC3FB4)

   |参数|必填/选填|说明|
   |:------------|:----|:------------------------------|
   |应用介绍|必填|简单描述该元服务的功能、产品定位等，字数不能超过8000字符。|
   |应用一句话简介（小编推荐）|必填|突出描述元服务的特色，吸引用户使用。 字数要求17字符以内。|
