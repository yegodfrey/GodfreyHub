# Lang

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----|:----------|:-----|:---------------------------------------------|
|lang|O|String|当前语言种类。 取值范围： * zh_cn：中文 * en_us：英文 * ru_ru：俄语|
|value|O|String|当前语言对应的角色名称。|
