# 《全国汽车流通信息管理系统备案》

#### 法规依据

《汽车销售管理办法》

第二条：在中华人民共和国境内从事汽车销售及其相关服务活动，适用本办法。

从事汽车销售及其相关服务活动应当遵循合法、自愿、公平、诚信的原则。

第三条：本办法所称汽车，是指《汽车和挂车类型的术语和定义》(GB/T 3730.1)定义的汽车，且在境内未办理注册登记的新车。第二十七条：供应商、经销商应当自取得营业执照之日起90日内通过国务院商务主管部门全国汽车流通信息管理系统备案基本信息。供应商、经销商备案的基本信息发生变更的，应当自信息变更之日起30日内完成信息更新。
