# 查看和导出日志

云调试服务支持在线查看和导出日志，通过获取设备运行期间的系统日志、应用日志，帮助用户定位问题。

## 前提条件

查看日志前必须先[申请调试设备](https://developer.huawei.com/consumer/cn/doc/app/agc-help-clouddebug-applyequip-0000002254916518)。

## 操作步骤

1. 调试设备申请成功后，进入调试页面，点击"HiLog"页签。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/35/v3/J-soXm8NQU-fmecP-DljSg/zh-cn_image_0000002693317830.png?HW-CC-KV=V1&HW-CC-Date=20261008T192718Z&HW-CC-Expire=31536000000&HW-CC-Sign=7FC2D608E682F164A6BCC4F0A489C8E85781FAFD00A479187CC1A5D5D68FBFA5 "点击放大")


2. 日志信息可以按照日志类型分为verbose、debug、info、warn、error和assert，您可通过点击日志类型下拉框选择相应的日志类型后，点击"获取日志"。 说明
   >
   > 日志可实时展示500条，下载25000条。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e7/v3/fTF2J-LFQLyIGcpGRZar8Q/zh-cn_image_0000002709548397.png?HW-CC-KV=V1&HW-CC-Date=20261008T192718Z&HW-CC-Expire=31536000000&HW-CC-Sign=AB8FD678D97AE9A4B3CDCB84684867BB9A249384A95938ABAC6DF90A7B1D6583)

   您也可在关键字输入框中输入关键字后，点击"获取日志"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/29/v3/yG4xs-rVSEG6wiZtXYIreg/zh-cn_image_0000002709665993.png?HW-CC-KV=V1&HW-CC-Date=20261008T192718Z&HW-CC-Expire=31536000000&HW-CC-Sign=595E707EB7AFE46400798E239844D2365EA8BC4F9C9A6A61CCCBC0234F40E08C)
3. （可选）获取到相关日志信息后，您可点击"导出日志"，将获取的日志保存至本地。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6e/v3/zL8XnaJ2SuqvLyErXqxu-w/zh-cn_image_0000002679988406.png?HW-CC-KV=V1&HW-CC-Date=20261008T192718Z&HW-CC-Expire=31536000000&HW-CC-Sign=F34120C94F8BEA4B0800D894BD5DA76E2DC4E21DB17A8034F104272EA29758E8)

4. （可选）点击"清空"，即可一键清除已获取的日志。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/61/v3/snF3_cVJSe2oYOAx60Y7Jw/zh-cn_image_0000002679828566.png?HW-CC-KV=V1&HW-CC-Date=20261008T192718Z&HW-CC-Expire=31536000000&HW-CC-Sign=C7B3C8B5C58E017F8FBB214DF1A5B0DD92C0D9E1A8B632A88EC32300669A5C55)
