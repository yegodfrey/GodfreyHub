# 修改测试态服务

当您创建的测试态服务已过生效时段或需要调整POI点位、测试用户、卡片内容等时，您可以尝试修改测试态服务。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/97/v3/Xr_fR9RYQAmbWEHwx7HSKg/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043438Z&HW-CC-Expire=86400&HW-CC-Sign=DFEB1E37D1711570279BCEC4B5AF9E8A00885C04CE37AAC3E7CC89D21049DE6C)

如果测试态服务有正在进行的测试任务，请先删除相关测试任务。在修改测试态服务之前，需先将其下线，然后进行编辑和提交。提交修改的测试态服务后，需重新创建测试任务并开始测试。

                1. 如果测试态服务未开始测试，请忽略此步骤。

如果测试态服务已开始测试，在左侧菜单栏选择“近场服务>近场测试”，进入近场测试主界面。在“测试管理”列表中点击要修改测试任务“操作”列的“删除”，将正在进行中的测试任务从列表中删除。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4d/v3/8rdKjGmWRNuqdL3q8gWmoQ/zh-cn_image_0000002452778836.png?HW-CC-KV=V1&HW-CC-Date=20261005T043438Z&HW-CC-Expire=86400&HW-CC-Sign=0B0401AFF95649948B4B069C1ADF6317415322440150C357DE7ADF5F9389D2E0)

                2. 在左侧菜单栏选择“近场服务>近场管理”，进入近场管理主界面。选择“服务管理”页签，在服务列表中点击要修改测试态服务“操作”列的“下线”。测试态服务下线后，才可对其进行修改。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/60/v3/XUrDRXjvQI--dKDm9KlWGA/zh-cn_image_0000002516391516.png?HW-CC-KV=V1&HW-CC-Date=20261005T043438Z&HW-CC-Expire=86400&HW-CC-Sign=A256976D20C47CD971C47EE9ADF8447BCDE59505C3FCA9AB108ABAA3957C57AA)

                3. 点击该测试态服务“操作”列的“编辑”，进入“编辑服务”页面。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d7/v3/aQ1tjI_lTHCZDecgkZmB3w/zh-cn_image_0000002516551436.png?HW-CC-KV=V1&HW-CC-Date=20261005T043438Z&HW-CC-Expire=86400&HW-CC-Sign=BB6BE1479137538FAE26353ACEE540674D2518705B2731227C4D8F1D9F874B9D)

                4. 在“编辑服务”页面各配置区域进行修改，然后点击“提交”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a7/v3/Cfua2jVDRl27IaAbGgUDvA/zh-cn_image_0000002485698645.png?HW-CC-KV=V1&HW-CC-Date=20261005T043438Z&HW-CC-Expire=86400&HW-CC-Sign=2E1303EBA7F10734284FAA5246813BCFBB10CD6166AEE4624587224F36BE49E7)

                5. 在弹出框中点击“前往测试”，系统将跳转至“创建测试”页面 。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7e/v3/C1WD2nlbTc6LID8C3aipFw/zh-cn_image_0000002452778848.png?HW-CC-KV=V1&HW-CC-Date=20261005T043438Z&HW-CC-Expire=86400&HW-CC-Sign=F0AA071012EBF0FC2FC4E16B0411B98C7B9EC2250B9356577F7C5EFDED092662)

                6. 根据实际需求编辑测试任务名称，并选择测试内容。然后点击页面右上角的“开始测试”，重新下发测试任务。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/37/v3/tDHI3kvgQbu7ByAAe60T9w/zh-cn_image_0000002452619228.png?HW-CC-KV=V1&HW-CC-Date=20261005T043438Z&HW-CC-Expire=86400&HW-CC-Sign=927AAA8E9B903F55A5EFEAF1FEB19FB02FFBEECCE5CD5CDF2722B1FDA2C183A3)

                7. 以下操作台界面可辅助您查看POI地理围栏的范围，以及测试手机是否进入测试POI的200米感应范围内。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ee/v3/c3v5TomQR3axx8615XGI_g/zh-cn_image_0000002485818577.png?HW-CC-KV=V1&HW-CC-Date=20261005T043438Z&HW-CC-Expire=86400&HW-CC-Sign=7C2F924A25B8112F31DE472BE70BCB984C82FDB3B8B6CFAE6FF04C55403A2481)
