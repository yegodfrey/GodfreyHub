# 测试反馈

您可在AGC控制台查看和管理用户使用邀请测试应用过程中反馈的体验问题，支持通过系统上报的时间、安装版本、设备型号等信息筛选查看问题数据，帮助您即时发现应用问题，持续改进服务质量并提升用户体验。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"APP与元服务"。
2. 在应用列表页的"HarmonyOS"页签，点击应用名称，进入"分发"页面。
3. 在左侧导航栏选择"应用测试/元服务测试 > 测试反馈"，进入"测试反馈"页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/79/v3/MXIekLXoRven0s_6BtiOlg/zh-cn_image_0000002586205019.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=EA0A5D7DD3373FD63DBD44DF7DBD0B9C0E43F01F3E7F30A5CB005559EC7EA386 "点击放大")

4. 页面列表展示所有用户反馈的问题链接。如用户上传了问题截图，链接处还会展示截图，点击可预览查看图片内容。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fe/v3/svCDyNiMSTi-coR-dcTkrQ/zh-cn_image_0000002586324995.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=CD9F0A9F218F6AB6981BD453AE75DC61641580D52858B31B816C0D9E9F0EB738)

5. 在"操作"列可下载或者删除对应的测试反馈，支持单个或批量操作。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c/v3/5hHHI4stSzyEJUXgO6L8tA/zh-cn_image_0000002555805208.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=AA25CE42F5B1DCF91FC001D13274FBC27A473E4278FAD746AFEA492A7E46C2ED)

6. 点击问题描述超链接，可以打开测试反馈详情页，查看更详细的问题描述和设备信息。 您还可在此页面删除当前问题反馈，或者同时删除反馈与对应的测试用户。删除后，该测试用户将从测试群组中移除，若该用户仍有测试需求，也可以重新邀请用户参与测试。
