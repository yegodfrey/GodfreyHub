# OtherRatingResult

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:----------|:---------------------------------------------------------------------------------------|
|gradeTypeId|O|Integer(32)|年龄分级标准ID。 取值范围： * 7：巴西分级|
|gradeTypeName|O|String(32)|年龄分级标准。 取值范围： * ClassInd：巴西分级|
|ratingResult|O|Integer(32)|年龄分级结果。 取值范围： * 1：所有年龄段 * 2：年满6周岁 * 3：年满10周岁 * 4：年满12周岁 * 5：年满14周岁 * 6：年满16周岁 * 7：年满18周岁|
