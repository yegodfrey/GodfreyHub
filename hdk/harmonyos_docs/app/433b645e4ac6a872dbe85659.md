# 使用限制

## API 限额

|操作|限额|
|:-------------------------|:---------------------------------------------------------------------------------|
|接口调用频率|20次/设备/小时。|
|网关返回429，500，502，503，504错误码|根据连续失败次数确定限流时间，失败次数为x（>2），则限流时间为2^x-1^分钟，最高为256分钟。限流时返回FETCH_THROTTLED错误，接口暂时无法访问。|

## 参数和条件限制

* 对单个项目最多可以有2000个参数和500个条件，所有参数值字符串的总长度不能超过800K个字符。
* 参数名称和条件名称最多可包含256个字符，且必须以下划线或英文字母（A-Z、a-z）开头，还可以包含数字。

## 历史版本管理限制

支持最多90天300个历史版本管理和回退能力。
