# 创建项目和应用

项目是您在AGC资源的组织实体，您可以将一个应用的不同平台版本添加到同一个项目中。当您的应用需要使用AGC服务时，您可以[创建应用并绑定项目](https://developer.huawei.com/consumer/cn/doc/app/agc-help-create-app-0000002247955506)。
