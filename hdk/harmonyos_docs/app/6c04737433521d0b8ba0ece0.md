# 申请调试证书

在调试阶段，如果您需要使用手动签名，必须配置调试证书。请参考本文档申请并下载调试证书，手动签名的完整操作请参考[手动签名](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-signing-manual)。
> 说明
>
> 每个账号最多可申请3个调试证书。

## 前提条件

* 您已准备好[证书请求文件](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-signing-manual#section1245916381106)。
* 您的账号角色已[获取"访问调试类证书"权限](https://developer.huawei.com/consumer/cn/doc/app/agc-help-manageaccount-0000002306610129#ZH-CN_TOPIC_0000002306610129__li626645853313)。

## 操作步骤

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"证书、APP ID和Profile"。
2. 在左侧导航栏选择"证书、APP ID和Profile > 证书"，进入"证书"页面，点击"新增证书"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c8/v3/syPK2THnRyShm7FP6DUDew/zh-cn_image_0000002558930553.png?HW-CC-KV=V1&HW-CC-Date=20260909T161421Z&HW-CC-Expire=31536000000&HW-CC-Sign=C04CADBC5B890579B5CB0612C8E3A64EE28587CACFCD2FA625CE29FB4B249E62)

3. 在弹出的"新增证书"窗口填写要申请的证书信息，点击"提交"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e2/v3/OUii-5sJSY6xmrBMelyHBQ/zh-cn_image_0000002430005465.png?HW-CC-KV=V1&HW-CC-Date=20260909T161421Z&HW-CC-Expire=31536000000&HW-CC-Sign=D55AE15E4509A731864CF4F3332B2DE8284D91977D3A7888574BC6F9790AB61E)

   |参数|说明|
   |:------------|:-----------------|
   |证书名称|自定义证书名称，不超过100个字符。|
   |证书类型|选择"调试证书"。|
   |选取证书请求文件（CSR）|上传准备好的证书请求文件。|

4. 证书申请成功后，"证书"页面展示证书名称等信息。点击"下载"，将生成的证书保存至本地，供后续调试签名使用。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fd/v3/_cTpUO52SiOsRX-eQE43fA/zh-cn_image_0000002430045513.png?HW-CC-KV=V1&HW-CC-Date=20260909T161421Z&HW-CC-Expire=31536000000&HW-CC-Sign=10896B07FD66006039360EB0349356F42D1F0C98C4CB5A32C1D6D606178123AA)

   > 注意
   > * 目前实名认证开发者的调试证书有效期为1年，未实名开发者的调试证书有效期为14天。若调试过程中出现应用启动被拦截、提示应用过期等问题，可优先排查是否为调试证书过期导致，证书过期后将无法正常完成调试签名。
   > * 在调试阶段，如果您更新调试证书，则需要[同步更新调试Profile](https://developer.huawei.com/consumer/cn/doc/app/agc-help-debug-profile-0000002248181278)，如果您[配置了公钥指纹](https://developer.huawei.com/consumer/cn/doc/app/agc-help-cert-fingerprint-0000002278002933)，也需要同步做更新。
   > * 若证书状态变为"失效"或"已吊销"，表示当前证书已不可用，且通过此证书申请的Profile也会全部失效或吊销。您需要重新申请证书与Profile。
   > * 证书一旦废除将不可恢复，且通过此证书申请的Profile也会全部失效，请谨慎操作。
