# SimpleGroupInfo

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:--------------|:----------|:------|:--------------------------------|
|groupId|M|String|测试群组ID。|
|groupName|M|String|测试群组名称。|
|addedTestersNum|O|String|测试群组中已添加的测试成员。|
|groupType|O|Integer|群组类别。 取值范围： * 0：外部群组（默认） * 1：内部群组|
