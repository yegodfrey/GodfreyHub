# 配置隐私标签信息

隐私标签将展示在应用详情页面，帮助用户提前了解应用使用个人数据的情况。

只有支持手机、平板、PC/2in1或智慧屏的HarmonyOS应用才需要配置此信息。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"APP与元服务"。
2. 选择要发布的应用。
3. 左侧导航选择"应用上架 > 版本信息"下待发布的版本。
4. 进入"隐私标签信息录入"区域，根据实际情况配置内容。
   * 如果不涉及收集用户的信息数据，"是否涉及个人信息收集"选择"否"，配置结束。
   * 如果涉及收集用户的信息数据，"是否涉及个人信息收集"选择"是"，继续配置。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5a/v3/ZThKQDKdRTykgMlqh0UykQ/zh-cn_image_0000002356440494.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=50D848CCBD7D442CD7F172DC42D4868DFA5FE6CBA3C0D43113651E004EB82AAC)

5. 选择业务场景，最多支持同时勾选六种业务场景。 注意
   >
   > 如果您的应用中不涉及广告与营销的相关内容，请勿在业务场景中勾选"广告与营销"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2c/v3/-CKkKbsqQ06gKWgmJ60kiA/zh-cn_image_0000002319546469.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=94B9ADA8563ED1FF799E428FB1AC79EE3A9695109E28ED094C302F0E04B7C039)

6. 依次选择业务场景对应的页签，点击左下角的"+添加"，配置相关数据项。业务场景和数据项具体内容参见[AppGallery隐私标签介绍](https://developer.huawei.com/consumer/cn/doc/app/privacy-label)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d0/v3/e-BpCiimQFKfjL0mf6v5ug/zh-cn_image_0000002284957392.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=61EDB300AC25356FADA21679A5B071E14032295C9AFB33212B0E3A5ED78CCE1E)

7. 配置完所有业务场景的数据项后，可到"关联到用户数据汇总"页签查看全部数据。 说明
   >
   > 每个业务场景下的数据项不能为空，如果存在未配置数据项的业务场景，相应业务场景页签左上角将有红点提示。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d6/v3/88PEioK2RFWjlePy-PmM_g/zh-cn_image_0000002284962964.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=4B1596A3905C18D0CE486C2BE9E1220BC85A680086E536619795D27754453A81)
