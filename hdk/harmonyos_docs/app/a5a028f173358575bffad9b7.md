# 元服务嵌入式运行测试

完成元服务嵌入式运行开发后，您需发送嵌入式运行测试申请邮件，由华为侧协助完成测试验证。申请邮件格式如下：

                * 邮箱地址：[agconnect@huawei.com](mailto:agconnect@huawei.com)
                * 邮件标题：元服务嵌入式运行测试申请
                * 邮件正文：需包含元服务名称和APP ID，获取方法请参见[查看应用信息](https://developer.huawei.com/consumer/cn/doc/app/agc-help-view-app-info-0000002282674569)。

华为侧完成验证后，将邮件回复您测试结果。
