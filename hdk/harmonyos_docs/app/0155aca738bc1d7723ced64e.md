# 集成SDK

## 安装远程配置SDK

1. 运行ohpm -v命令，检查当前环境是否已安装ohpm命令行工具。
   * 如果返回版本号，则表示已安装。
   * 如果报错提示ohpm不存在，则参考[三方依赖管理工具（ohpm）](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-ohpm-cli)完成安装。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/85/v3/-EMpoWLETlCL0nztEcLoxg/zh-cn_image_0000002686725462.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=BE511693F71E0A599F6B562B1E57E20615D8096ECA326095C92ABD8AEEDCF4B9)
2. 下载安装远程配置SDK。

   ```screen
   ohpm install @hw-agconnect/remote-config
   ```

## 初始化远程配置SDK

1. 在项目的"entry/src/main/ets/entryability/EntryAbility.ets"文件中导入远程配置SDK。

   ```screen
   import RemoteConfig, { RemoteConfigOptions } from '@hw-agconnect/remote-config';
   ```

2. 在EntryAbility.ets文件的onCreate方法中初始化远程配置SDK。

   ```screen
   //初始化SDK
   onCreate(want: Want, launchParam: AbilityConstant.LaunchParam): void {
     let remoteConfigOptions: RemoteConfigOptions = {
       context: this.context,
       regin: 'CN',
       reginBack: 'CN_back',
       agcgwAllRegin: 'connect-drcn.dbankcloud.cn',
       agcgwAllReginBack: 'connect-drcn.hispace.hicloud.com',
       websocketgwAllRegin: 'connect-ws-drcn.hispace.dbankcloud.cn',
       websocketgwAllReginBack: 'connect-ws-drcn.hispace.dbankcloud.com',
       storageUrlRegin: 'https://agc-storage-drcn.platform.dbankcloud.cn',
       storageUrlReginBack: 'https://agc-storage-drcn.cloud.huawei.com.cn',
       agcgwUrl: 'connect-drcn.dbankcloud.cn',
       productId: 'xxx',
       appId: 'xx',
       clientId: 'xxx',
       apiKey: 'xxx'
     };
     RemoteConfig.initialize(remoteConfigOptions);
   }
   ```

   其中，各参数的值可在"项目设置 > 常规"页面中查询。点击参数后面的复制按钮，可复制参数值。

   需配置的参数值和"常规"页面参数的对应关系如下：
   * productId替换为"项目"栏中"项目ID"的值
   * appId替换为"应用"栏中"APP ID"的值
   * clientId替换为"项目"栏中"Client ID"的值
   * apiKey替换为"项目"栏中"API密钥（凭据）"的值
