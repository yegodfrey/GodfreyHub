# 告警通知

告警通知模板是预定义的消息格式，用于生成和发送告警通知，旨在提升告警通知的一致性、完整性和可读性，从而帮助开发者更高效地响应和处理告警。

目前不支持开发者自定义通知模板，APMS提供了默认的告警通知模板。当告警发生时，系统将根据开发者在创建告警规则时选择的邮箱、短信或回调链接触达方式，将告警通知发送给指定的接收人。

## 告警模板

```screen
尊敬的开发者，您好！
您的应用/元服务 {appName} 于 {alarmTime} 发生 {alarmLevel} 告警。
告警名称：{alarmName}
指标类型：{errorType}
触发原因：{metricText}
详情链接：{link}
请您尽快处理，以免影响业务。谢谢！
```

各字段含义如下：

* appName：应用/元服务名称
* alarmTime：告警发生的时间
* alarmLevel：告警级别
* alarmName：告警名称
* errorType：指标类型，以文本形式描述。
* metricText：告警触发条件，以文本形式描述。
* link：告警总览页面链接。账号持有者或被赋予应用权限的成员账号点击该链接后，将直接跳转至对应应用的"告警总览"页面，并按照告警名称、指标类型和时间范围条件自动过滤展示筛选后的结果数据，如下图所示。**仅邮箱和回调链接两种触达方式的告警通知中包含该字段。**
