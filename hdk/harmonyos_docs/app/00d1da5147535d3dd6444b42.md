# 上传软件包

您需要先上传待发布的正式版本，以便在发布时能选择到对应的版本。上传时，AppGallery Connect会对上传的包进行合法性检测，同时还提供了上架自检功能来助您提高应用审核通过率。

## 提交软件包

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"快速开始"中的"元服务一站式平台"卡片。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/67/v3/0oDP8zZqRViMfYeNYrrbqg/zh-cn_image_0000002529682783.png?HW-CC-KV=V1&HW-CC-Date=20261008T172402Z&HW-CC-Expire=31536000000&HW-CC-Sign=C6578639403EE574A375252889F39CC6B2F931911A5639B9C6B2479EA52FAAF9)

2. 在左上角下拉列表选择要发布的元服务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f2/v3/JmukHjzpRViuzxlEBWs7pQ/zh-cn_image_0000002566867053.png?HW-CC-KV=V1&HW-CC-Date=20261008T172402Z&HW-CC-Expire=31536000000&HW-CC-Sign=3781A63C9D602E818498F667824DF74A1726924819BFF1C552DC8023E2B54FCF)

3. 左侧导航选择"元服务上架 > 软件包管理"，点击页面右上角的"上传"。
4. 在"上传包"窗口，先选择"使用场景"，然后点击"+"上传软件包。 若上传的软件包只用于测试发布，可以选择"仅测试"。若软件包需要在全网正式发布，请选择"测试和正式上架"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fc/v3/7Z4LZPOcSrmOCRpYwOJlmQ/zh-cn_image_0000002451149718.png?HW-CC-KV=V1&HW-CC-Date=20261008T172402Z&HW-CC-Expire=31536000000&HW-CC-Sign=047290B2C0F9D5F371409657A608E97621E126F0AB394CB722C307ADAE9307CE)

上传完成后，软件包管理页面会生成一条记录，展示软件包基本信息。

* 文件名：软件包文件名。
* 包名：元服务包名，对应包内的bundleName字段。
* 版本（版本号）：版本名称与版本号，分别对应包内的versionNumber和versionCode字段。
* 构建版本：构建版本号，用于区分同一主版本下的不同测试子版本，对应包内的buildVersion字段。如包内无buildVersion字段，则显示"--"。
* 设备类型：支持的设备类型，对应包内的deviceTypes字段。
* 使用场景：传包时选择的使用场景。
* 上传时间：上传包的时间。
* 合法性：合法性检测结果，具体请参见[合法性检测](#section161521438134716)。
* 上架自检：上架自检结果，具体请参见[上架自检](#section15203163921310)。

## （推荐）上架自检

为提高元服务审核通过率，建议您使用上架自检功能。该功能使用热门移动终端设备，按照华为应用市场上架标准对元服务进行兼容性、稳定性、性能、功耗、UX、隐私等测试，可帮助您提前发现和解决问题。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"快速开始"中的"元服务一站式平台"卡片。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0b/v3/tzgCsD5YTpGA7r6e1jpm3Q/zh-cn_image_0000002529682783.png?HW-CC-KV=V1&HW-CC-Date=20261008T172402Z&HW-CC-Expire=31536000000&HW-CC-Sign=D587BE6B4BE030D83414FC05614B4755FEA1A976971CE1AC2275546983BB3747)

2. 在左上角下拉列表选择要发布的元服务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bc/v3/GIas0ob5TsuUc9edtbvD1w/zh-cn_image_0000002566867053.png?HW-CC-KV=V1&HW-CC-Date=20261008T172402Z&HW-CC-Expire=31536000000&HW-CC-Sign=EAC48D1B8C60333759D6E5D3B63317C497D75CA0B2383DADAC017C18C76BE3BB)

3. 左侧导航选择"元服务上架 > 软件包管理"，点击软件包"操作"列"启动自检"。 说明
   >
   > 每个元服务同时只能进行2个上架自检任务（包含状态为"终止中"和"检测中"的任务）。自检启动后，可随时点击"终止自检"结束任务。若您在启动自检后删除了软件包，自检任务将继续执行，需等待自检任务结束才可以执行新的自检任务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/11/v3/z8zshs9HQlGcy32oSIKG7w/zh-cn_image_0000002516240496.png?HW-CC-KV=V1&HW-CC-Date=20261008T172402Z&HW-CC-Expire=31536000000&HW-CC-Sign=0D871FDA9FFFBC56D6A3869A88E80288BA0F995408BE362A2DCA8E5B04BA3025)
4. 在"上架自检"栏查看检测进度与结果。检测完成后，AGC将发送邮件通知您，您可以点击邮件中的"软件包管理"链接前往"软件包管理"页面查看检测结果。
   * 检测中：表示正在检测软件包。检测时长可能受终端设备数量和排队情况影响，请耐心等待。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ea/v3/XcaWbLkkTs2wWVA0OmakLQ/zh-cn_image_0000002716295129.png?HW-CC-KV=V1&HW-CC-Date=20261008T172402Z&HW-CC-Expire=31536000000&HW-CC-Sign=71711EF0EC4F858A4D799B9C2F8F81CBB6B6E1DDB30A3F6A874E1DA1BB5CDFF3)

   * 通过：表示检测通过，可以提交上架。点击"报告"可查看详细的检测报告。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2a/v3/lpQf-PE3T5GXCkhG1uY0UA/zh-cn_image_0000002547840401.png?HW-CC-KV=V1&HW-CC-Date=20261008T172402Z&HW-CC-Expire=31536000000&HW-CC-Sign=D4D8CEFCBE1C1EBE0543F0570AC8472B35DBE645EB91740E42B9003790656830)
