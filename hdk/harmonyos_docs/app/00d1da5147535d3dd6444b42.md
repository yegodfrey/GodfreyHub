# 上传软件包

您需要先上传待发布的正式版本，以便在发布时能选择到对应的版本。上传时，AppGallery Connect会对上传的包进行合法性检测，同时还提供了上架自检功能来助您提高应用审核通过率。

## 提交软件包

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"快速开始"中的"元服务一站式平台"卡片。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/67/v3/0oDP8zZqRViMfYeNYrrbqg/zh-cn_image_0000002529682783.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=4706331DBAD58D9589AD00D3D5ECF9440FBA53BEBFE7ABCFEBC345939A15C22D)

2. 在左上角下拉列表选择要发布的元服务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f2/v3/JmukHjzpRViuzxlEBWs7pQ/zh-cn_image_0000002566867053.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=88028C95F25F564FF3C2A6FC456D1BB3CC04FFEAFD883E81498EEDE9AFD3AD19)

3. 左侧导航选择"元服务上架 > 软件包管理"，点击页面右上角的"上传"。
4. 在"上传包"窗口，先选择"使用场景"，然后点击"+"上传软件包。 若上传的软件包只用于测试发布，可以选择"仅测试"。若软件包需要在全网正式发布，请选择"测试和正式上架"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fc/v3/7Z4LZPOcSrmOCRpYwOJlmQ/zh-cn_image_0000002451149718.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=A8D6A602D4AAE8A25905B3B984D983A5FB34C1D53D1CC22F853EF384BBF7C1AC)

上传完成后，软件包管理页面会生成一条记录，展示软件包基本信息。

* 文件名：软件包文件名。
* 包名：元服务包名，对应包内的bundleName字段。
* 版本（版本号）：版本名称与版本号，分别对应包内的versionNumber和versionCode字段。
* 构建版本：构建版本号，用于区分同一主版本下的不同测试子版本，对应包内的buildVersion字段。如包内无buildVersion字段，则显示"--"。
* 设备类型：支持的设备类型，对应包内的deviceTypes字段。
* 使用场景：传包时选择的使用场景。
* 上传时间：上传包的时间。
* 合法性：合法性检测结果，具体请参见[合法性检测](#section161521438134716)。
* 上架自检：上架自检结果，具体请参见[上架自检](#section15203163921310)。

## （推荐）上架自检

为提高元服务审核通过率，建议您使用上架自检功能。该功能使用热门移动终端设备，按照华为应用市场上架标准对元服务进行兼容性、稳定性、性能、功耗、UX、隐私等测试，可帮助您提前发现和解决问题。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"快速开始"中的"元服务一站式平台"卡片。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0b/v3/tzgCsD5YTpGA7r6e1jpm3Q/zh-cn_image_0000002529682783.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=120CFC2479C7AA89F180B8B68B8CFBA5941DE521C496C0A2CBAA4F8079683A9B)

2. 在左上角下拉列表选择要发布的元服务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bc/v3/GIas0ob5TsuUc9edtbvD1w/zh-cn_image_0000002566867053.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=A49F69C7F5E1AEA5B396A0A663CBDFDD0EC1E95BCEA755BBC669DCCD116DABFB)

3. 左侧导航选择"元服务上架 > 软件包管理"，点击软件包"操作"列"启动自检"。 说明
   >
   > 每个元服务同时只能进行2个上架自检任务（包含状态为"终止中"和"检测中"的任务）。自检启动后，可随时点击"终止自检"结束任务。若您在启动自检后删除了软件包，自检任务将继续执行，需等待自检任务结束才可以执行新的自检任务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/11/v3/z8zshs9HQlGcy32oSIKG7w/zh-cn_image_0000002516240496.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=E5F2AA02796BDC79A0F89686439C1C791D6E573E7BEE4D670136537D48862910)
4. 在"上架自检"栏查看检测进度与结果。检测完成后，AGC将发送邮件通知您，您可以点击邮件中的"软件包管理"链接前往"软件包管理"页面查看检测结果。
   * 检测中：表示正在检测软件包。检测时长可能受终端设备数量和排队情况影响，请耐心等待。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ea/v3/XcaWbLkkTs2wWVA0OmakLQ/zh-cn_image_0000002716295129.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=FFCA036B9003CD11F86A00251153514CDEBDE1FBF388B2631B909639B97D6077)

   * 通过：表示检测通过，可以提交上架。点击"报告"可查看详细的检测报告。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2a/v3/lpQf-PE3T5GXCkhG1uY0UA/zh-cn_image_0000002547840401.png?HW-CC-KV=V1&HW-CC-Date=20260916T032631Z&HW-CC-Expire=31536000000&HW-CC-Sign=CD223F59FE3970DBC54FB2328C4B389AE06A1CA2ACAA4FA19B3976279F39F169)
