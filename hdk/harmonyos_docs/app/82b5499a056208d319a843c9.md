# 概述

|-------------------------------------------------------------------------------------------------------------------|-|
|应用开发和测试完成后，您可以将各种类型（APK、RPK、AppBundle、APP、EXE）的软件包提交发布申请，AppGallery Connect可以将您的应用分发至全球多个国家和地区，同时支持手机、PC、大屏等多种终端设备。| |

|操作|说明|
|:----------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------|
|[发布应用（APP）](https://developer.huawei.com/consumer/cn/doc/app/agc-help-releaseharmony-0000001933963166)|通过AppGallery Connect发布HarmonyOS应用/元服务后，用户即可在华为应用市场搜索获取您的HarmonyOS应用/元服务。|
|[发布应用（APK）](https://developer.huawei.com/consumer/cn/doc/app/agc-help-releaseapkrpk-0000001106463276)|通过AppGallery Connect发布Android应用后，用户即可在华为应用市场搜索获取您的应用。|
|[发布应用（RPK）](https://developer.huawei.com/consumer/cn/doc/app/agc-help--release-fastapp-0000001099836868)|通过AppGallery Connect发布快应用后，用户即可在华为应用市场、快应用中心搜索应用后直接运行应用。|
|[发布应用（AppBundle）](https://developer.huawei.com/consumer/cn/doc/app/agc-help-releasebundle-0000001100316672)|您可以将Android应用包打包成aab格式进行发布，应用市场将根据用户设备类型、使用功能等提供对应的软件包，从而有效减小用户下载安装的软件包体积。|
|[发布应用（Windows）](https://developer.huawei.com/consumer/cn/doc/app/agc-help-pcapp-0000001146516651)|通过AppGallery Connect发布Windows应用后，用户即可在Windows版应用市场搜索获取您的应用。|
