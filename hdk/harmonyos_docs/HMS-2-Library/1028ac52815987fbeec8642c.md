针对不同的开发环境，华为提供3种HMS SDK基础包，当前HMS SDK基础包版本号为2.6.3.306，请开发者根据自身实际情况选择一种方式集成HMS SDK。

警告:  


● 集成HMS SDK基础包后，还必须集成HMS SDK Agent包，具体请参见[集成HMS SDK Agent](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_app_hmsagent)。  


● HMS SDK基础包和HMS SDK Agent包的主版本号必须一致，例如HMS SDK基础包版本为2.6.3.306，必须也配套使用2.6.3.xxx版本的HMS SDK Agent，2.6.3即为主版本号。

# 1. AndroidStudio  


1、打开AndroidStudio项目根路径下的build.gradle文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200224203954.51376804995744999661613966581780:50510916032942:2800:0092F06F80FFF842D54A414A82FF5A465D52727650BA71D9B820F7C7473C0DD1.png?needInitFileName=true?needInitFileName=true)

在“allprojects”->“repositories”里面配置HMSSDK的maven仓地址。
      
      1. allprojects { 
        2.             repositories { 
        3.                 google() 
        4.                 jcenter() 
        5.                 maven {url 'https://developer.huawei.com/repo/'} 
        6.             } 
        7. }
    
    

说明：

maven仓地址直接在浏览器中打开无法访问，只能在IDE中配置。

  


2、打开app目录下的build.gradle文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200224204002.36721663539038351824016514013278:50510916032942:2800:73083FF73B972A129E5F9F993D9A71501EB4CBB28FFF9AFCAD1A961E6FFB4323.png?needInitFileName=true?needInitFileName=true)

在“dependencies”中添加如下编译依赖。
      
      1. dependencies {      
        2.  compile 'com.huawei.android.hms:hwid:{version}'      
        3.  compile 'com.huawei.android.hms:iap:{version}'
        4. }
    
    

说明：

hwid为华为帐号服务，iap为华为支付服务。{version} 替换为实际的SDK版本号，如：compile 'com.huawei.android.hms:hwid:2.6.3.306'。

  


3、重新打开修改完的build.gradle文件，右上方出现“Sync Now”链接。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200224204010.33475771358571827357627513545686:50510916032942:2800:5D28E351C91329633D1B0F19A7C2096AF3FE3E08E3EA99E2A80B7FE72F94EC43.png?needInitFileName=true?needInitFileName=true)

点击“Sync Now”等待同步完成。

说明：

如果出现错误，请检查网络连接是否正常，以及检查gradle文件是否正确。

  


4、多语言设置。

● 如果您的应用不需要设置只支持某些特定语言，则请忽略本步骤。应用将默认支持所有HMS SDK支持的语言。  
● 如果您的应用需要设置只支持某些特定语言，则可通过本步骤配置。  
打开项目工程下app目录的build.gradle文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200224204021.01277076470475546667142809742623:50510916032942:2800:32D31D88AE4238A3F948ED4659E891CA9D916E6ED2413EA2CCBA8A5B314D451D.png?needInitFileName=true?needInitFileName=true)

在“android”->“defaultConfig”中新增resConfigs配置，“en”（英语） 和 “zh-rCN”（简体中文）为必须配置的语种，配置格式如下：
      
      1. android { 
        2.         defaultConfig { 
        3.                 ... 
        4.                 resConfigs "en", "zh-rCN"，"需要支持的其他语言" 
        5.         } 
        6. }

# 3. 通用方式  


如果“AndroidStudio”或“Eclipse+ADT”两种开发方式都无法正常集成HMS SDK，可选择本章节的方式集成。

1、下载[hmssdk-gradle-2.6.3.306.zip](https://appfile1.hicloud.com:443/FileServer/getFile/app/000/001/111/0000000000000001111.20191219225710.43246600540642972934306762078452:20471231000000:0001:53987CCD13B9A3DF50F2E618917BBEC93831E8E155BCB4FEDB1DE41C9EC8FFF2.zip?needInitFileName=true)并解压，得到下表所示目录。  
SHA256校验：4d05a48673791420ff606cdd78c74596283b70f2fc8d0639d673fbdd5cf1338a  
大小：1,259,410（Bytes）

目录| 说明  
---|---  
libs| 包含HMS SDK所有功能的jar包。通用方式只有一个hmssdk-{version}.jar包，包含帐号、支付、消息、推送、游戏服务。  
res| HMS SDK需要使用的资源目录，包含多国语言包。应用如果不需要集成多种语言，可以适当裁剪。但是必须保留应用的默认语言和简体中文。  
assets| HMS SDK请求华为服务器需要使用的证书文件。警告：证书文件非常重要，拷贝时请勿遗漏。  
  
2、集成工程。  
请直接将libs、res和assets目录下的所有文件及子目录拷贝到开发者APP工程的同名目录下。如果目录不存在，请先创建。
