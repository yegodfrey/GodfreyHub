针对不同的开发环境，华为提供3种HMS SDK基础包，当前HMS SDK基础包版本号为2.6.3.306，请开发者根据自身实际情况选择一种方式集成HMS SDK。

警告:  


● 集成HMS SDK基础包后，还必须集成HMS SDK Agent包，具体请参见[集成HMS SDK Agent](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Library/hmssdk_jointOper_game_hmsagent)。  


● HMS SDK基础包和HMS SDK Agent包的主版本号必须一致，例如HMS SDK基础包版本为2.6.3.306，必须也配套使用2.6.3.xxx版本的HMS SDK Agent，2.6.3即为主版本号。

# 1. AndroidStudio  


1、打开AndroidStudio项目根路径下的build.gradle文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200224203739.57126994460617259774065664723561:50510916032941:2800:2E1F22F4E60DA54B467F53F30F116D5489A9EC15DA69EDF87A73C0D5E882AE6D.png?needInitFileName=true?needInitFileName=true)

在“allprojects”->“repositories”里面配置HMSSDK的maven仓地址。
      
      1. allprojects { 
        2.             repositories { 
        3.                 google() 
        4.                 jcenter() 
        5.                 maven {url 'https://developer.huawei.com/repo/'} 
        6.             } 
        7. }
    
    

说明：

maven仓地址直接在浏览器中打开无法访问，只能在IDE中配置。

  


2、打开app目录下的build.gradle文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200224203748.08126377230949580128648005514634:50510916032941:2800:D1F8B1D9340ECCB82800B091ED0EE2BA94D5103118B2533471449B24DB61EF04.png?needInitFileName=true?needInitFileName=true)

在“dependencies”中添加如下编译依赖。
      
      1. dependencies {      
        2.  compile 'com.huawei.android.hms:iap:{version}'      
        3.  compile 'com.huawei.android.hms:game:{version}'
        4. }
    
    

说明：

iap为华为支付服务，game为华为游戏服务。{version} 替换为实际的SDK版本号，如：compile 'com.huawei.android.hms:iap:2.6.3.306'。

  


3、重新打开修改完的build.gradle文件，右上方出现“Sync Now”链接。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200224203757.83459776858632384772842860284621:50510916032941:2800:91C7C27DDA227F33DFEC832022A20AAF52088ED474691A26EE41047017D97071.png?needInitFileName=true?needInitFileName=true)

点击“Sync Now”等待同步完成。

说明：

如果出现错误，请检查网络连接是否正常，以及检查gradle文件是否正确。

  


4、多语言设置。

● 如果您的应用不需要设置只支持某些特定语言，则请忽略本步骤。应用将默认支持所有HMS SDK支持的语言。  
● 如果您的应用需要设置只支持某些特定语言，则可通过本步骤配置。  
打开项目工程下app目录的build.gradle文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200224203805.34740839167481005218029116776240:50510916032941:2800:1DD33EBCB6A9B4719E19486198DF0C59426713CE7576F81F3B3A24B681475A6A.png?needInitFileName=true?needInitFileName=true)

在“android”->“defaultConfig”中新增resConfigs配置，“en”（英语） 和 “zh-rCN”（简体中文）为必须配置的语种，配置格式如下：
      
      1. android { 
        2.         defaultConfig { 
        3.                 ... 
        4.                 resConfigs "en", "zh-rCN"，"需要支持的其他语言" 
        5.         } 
        6. }

# 3. 通用方式  


如果“AndroidStudio”或“Eclipse+ADT”两种开发方式都无法正常集成HMS SDK，可选择本章节的方式集成。

1、下载[hmssdk-gradle-2.6.3.306.zip](https://appfile1.hicloud.com:443/FileServer/getFile/app/000/001/111/0000000000000001111.20191219225710.43246600540642972934306762078452:20471231000000:0001:53987CCD13B9A3DF50F2E618917BBEC93831E8E155BCB4FEDB1DE41C9EC8FFF2.zip?needInitFileName=true)并解压，得到下表所示目录。  
SHA256校验：4d05a48673791420ff606cdd78c74596283b70f2fc8d0639d673fbdd5cf1338a  
大小：1,259,410（Bytes）

目录| 说明  
---|---  
libs| 包含HMS SDK所有功能的jar包。通用方式只有一个hmssdk-{version}.jar包，包含帐号、支付、消息、推送、游戏服务。  
res| HMS SDK需要使用的资源目录，包含多国语言包。应用如果不需要集成多种语言，可以适当裁剪。但是必须保留应用的默认语言和简体中文。  
assets| HMS SDK请求华为服务器需要使用的证书文件。警告：证书文件非常重要，拷贝时请勿遗漏。  
  
2、集成工程。  
请直接将libs、res和assets目录下的所有文件及子目录拷贝到开发者APP工程的同名目录下。如果目录不存在，请先创建。
