本章节主要介绍接入华为PUSH的准备步骤，以帮助开发者更快速的完成华为PUSH的接入。

必备步骤主要包括：

1\. 注册认证成为开发者

2\. 配置应用签名

3\. 创建产品和应用

4\. 开通推送服务

5\. 获取推送服务参数

6\. 下载SDK

7\. 集成工程

  


# 1\. 注册认证成为开发者     

如果开发者还没有华为开发者帐号，请访问[华为开发者联盟](https://developer.huawei.com/consumer/cn/)进行帐号注册认证，如果开发者后续计划接入华为支付服务，请注册认证成为“企业开发者”。

详细开发者网站帐号注册流程请参考：

<https://developer.huawei.com/consumer/cn/devservice/doc/20300>

  


# 2\. 配置应用签名

在申请华为Push服务前，请开发者先确定自己的应用包名，并创建开发工程，同时请确保开发环境已安装jdk。

**步骤：**

1\. 请在开发环境生成keystore签名证书，该配置属于通用技术，此处不详细描述，假设开发者生成的证书名为mykeystore.keystore

2\. 打开命令行工具（使用CMD命令），执行cd命令进入keytool.exe所在的目录。

cd %JAVA_HOME%/bin

3\. 执行命令keytool -list -v -keystore <keystore-file>，按命令行提示进行操作。

其中 <keystore-file>是应用签名文件的完整路径。

例如：C:\Program Files (x86)\Java\jdk1.7.0_25\bin>keytool -list -v -keystore E:\HMS_SDK_2.5.1.300\Sample\HMSSdkSample_2.5.1.300_AS\HmsSample\mykeystore.keystore

4\. 获取对应的SHA256指纹，如图2-8所示。

# 6\. 集成工程       


## **6.1 集成SDK**

**注意：**

Push业务现在已全面切换到新的HMS SDK，原老版本的CloudPush_SDK_XXX.jar包已不提供下载和维护，请开发者尽快切换到新版本的SDK。新接入Push服务的开发者不用关注，直接使用本文档的SDK。

切换说明：

· HMS SDK现有的Push接口兼容对应的老版本的Push接口，原老版本的setTag/getTag/deleteTag功能暂时不可用，HMS SDK会在后续版本实现该功能。

· APP不能同时集成HMS SDK和老版本的HMS Core Push SDK，如果使用HMS SDK，必须删除老版本的HMS Core Push SDK代码和jar包。

· 应用已经在华为开发者联盟上开通过老的Push服务，切换到HMS Push Kit不需要另外开通Push服务，只需要添加应用的SHA256证书指纹即可。
