# 代码结构

|序号|文件名|文件用途|
|:-|:--------------------|:-----------------------------------------------------|
|1|AlertActivity|大屏端设备收到手机端连接请求时，弹出请求提示框，供用户选择是否允许手机端连接到本机。|
|2|MainActivity|提供投屏服务开关设置、加密开关设置、密码设置入口，以及展示本机设备名称、网络信息等。|
|3|SinkTesterService|投屏服务核心逻辑类，初始化Cast Engine服务，配置投屏参数，处理手机端连接请求、连接状态变化等逻辑。|
|4|PasswordActivity|供用户设置密码，该密码用于密码模式下设置密码使用。|
|5|PinActivity|PIN码模式下，手机端请求连接本机大屏端时，展示PIN码，以便手机端输入。|
|6|PlayActivity|用于投屏状态中，展示投屏画面。|
|7|SeparatedEditText|密码输入框自定义控件。|
|8|SharedPreferenceUtil|辅助工具类，提供以SharedPreference方式存取数据的工具函数，主要用于用户密码的持久化。|
|9|Utils|辅助工具类，提供静态工具方法。|
|10|attrs.xml|自定义属性文件，提供密码输入框自定义属性。|
|11|activity_alert.xml|提供AlertActivity的具体布局。|
|12|activity_main.xml|提供MainActivity的具体布局。|
|13|activity_password.xml|提供PasswordActivity的具体布局。|
|14|activity_pin.xml|提供PinActivity的具体布局。|
|15|activity_play.xml|提供PlayActivity的具体布局。|
