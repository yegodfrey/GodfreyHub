# 服务中心便捷服务露出规则

为保证用户体验，元服务提供的便捷服务应符合一定规则从而在服务中心露出。详情请参见“[元服务总体开发要求](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/atomic-service-development-requirements-0000001105286996)”。
