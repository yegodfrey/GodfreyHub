# 多窗口交互

折叠屏展开态、平板、电脑等大屏幕设备，具有多任务并行和效率型任务处理的先天优势。为了能够充分发挥这一优势，系统提供了悬浮窗、分屏、平行视界三种多窗口交互的形式，让用户在大屏幕设备上的多任务并行、临时任务处理等使用体验更佳。

以下文档从开发的角度具体阐述了这三种多窗口交互形式：[多窗口分类说明](https://developer.harmonyos.com/cn/docs/design/des-guides/overview-0000001117674074)，[多窗口基础体验要求](https://developer.harmonyos.com/cn/docs/design/des-guides/basic-0000001110501590)，[悬浮窗交互介绍](https://developer.harmonyos.com/cn/docs/design/des-guides/floatingwindow-0000001156821475)。

分屏能力是系统层级的能力，需要我们在config.json文件中配置相关项，配置如下：
    
    "resizeable": true,
      "metaData": {
        "customizeData" : [{
          "name" : "com.huawei.*****.multiwindow.multiinstance.enable",
          "value" : "true"
        }]
      },
     

更多内容可以参考：[分屏设计指导](https://developer.harmonyos.com/cn/docs/design/des-guides/splitscreen-0000001110661494)
