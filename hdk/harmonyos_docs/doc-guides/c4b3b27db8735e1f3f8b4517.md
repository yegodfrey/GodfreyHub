# 简介

由于折叠屏在展开态下屏幕尺寸会变大，这一特性会有利于更高效的信息展示或更沉浸的内容浏览。而要充分利用好折叠屏的大屏幕优势，需要我们在开发过程中对宽屏的页面布局进行正确地适配。正确适配的前提是，对折叠屏动态布局相关内容有所了解。

折叠屏动态布局是针对折叠屏设备宽度变化而进行界面版面重排的一种布局方式，我们可以根据界面信息架构是否随着屏幕设备规格的变化而变化将动态布局分为“自适应动态布局”和“响应式动态布局”两类，其中界面信息架构不随屏幕设备规格的变化而变化的为“自适应动态布局”；界面信息架构随着屏幕设备规格的变化而变化的为“响应式动态布局”。
