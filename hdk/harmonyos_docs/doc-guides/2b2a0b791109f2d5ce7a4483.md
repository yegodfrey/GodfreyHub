# 应用/服务运行

#### 配置签名信息

应用/服务在真机设备上运行，需要提前为应用/服务进行签名，DevEco Studio为开发者提供了自动化签名方案，可以一键完成应用/服务签名。具体操作如下：

单击**File**** > ****Project Structure > ****Project > Signing** **Configs** 界面勾选**Automatically generate signature** ，等待自动签名完成即可，单击**OK** 。如下图所示：

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113503.28159044128910091069961240997690:50001231000000:2800:3244FA7B6EFB6FC1CE36D451C5DC9C10F3413237E37096D1896D5DB9613A6EB4.png?needInitFileName=true?needInitFileName=true)

如果您的应用/服务使用了“system_basic”和“system_core”权限，请参考[修改应用权限等级](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/ohos-auto-configuring-signature-information-0000001271659465#section42735161005)修改签名模板。您使用到的应用权限，可以在自动化签名完成后，单击**Show Restricted Permissions** 进行查看。

#### 运行应用/服务

安装OpenHarmony应用可以通过DevEco Studio安装，也可以通过使用hdc_std工具进行手动安装。

     * 通过DevEco Studio安装：将设备连接上DevEco Studio后，单击![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113503.05658605822157801821998382040019:50001231000000:2800:5ACF08BC55A0855A0C29EC3861EA7A8314178E35EF0A5824A16CA928B4DE56F3.png?needInitFileName=true?needInitFileName=true)按钮即可安装。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113503.85375297555116478625183204210495:50001231000000:2800:0EA502DCC8BBD897F8F7C41ABEBC8EEC530C3BBB8F1C11A2E85ABA7912531E71.png?needInitFileName=true?needInitFileName=true)

     * 通过hdc_std工具安装：手动执行命令行完成应用的安装。

hdc_std工具本身需要手动从开源仓中获取。然后使用工具命令将编译后的hap包安装到设备上。

相关命令如下：

       * 安装命令

**install [-r/-d/-g]_package_**

命令示例：
             
             hdc_std install _E:\ohos-admin.hap_

       * 日志抓取命令

**hilog**

命令示例：
             
             hdc_std hilog

完整的hdc_std工具使用指导及命令格式请参见[hdc_std使用指导](https://gitee.com/openharmony/docs/blob/OpenHarmony-3.1-Release/zh-cn/device-dev/subsystems/subsys-toolchain-hdc-guide.md)。
