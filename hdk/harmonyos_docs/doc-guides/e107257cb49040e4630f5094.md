# 元服务分享

通过分享的方式，将元服务分享到其它设备上，用户确认后可直接免安装启动服务。

华为分享：用户可在元服务内选择分享，打开“华为分享”开关后，将元服务分享给附近同样打开了“华为分享”开关的好友，好友点击确认后直接启动服务。
