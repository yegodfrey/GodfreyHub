# 服务卡片不同布局适配

考虑到Pocket设备的内、外屏特点，一个应用同一外观规格可以有多个卡片布局，例如日历在2 * 2规格下可能存在桌面2*2卡片和小外屏2 * 2卡片。

布局适配可以参考如下方法：

     1. 建议UX设计师将这两种卡片尽量设计为同一布局，仅针对不同屏幕大小，调整边距，方便布局复用；

        1. UX发布相关规范可参考：[外屏卡片规范](https://developer.harmonyos.com/cn/docs/design/des-guides/service-widget-devices-folder-0000001196710774)

     2. JS卡片页面通过hml+css+json开发指导，可以参考[JS API参考](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-apis-overview-0000001056361791)。

如果同一外观规格卡片布局不能复用，需要分别开发两套布局，并需要将两套布局写在同一HML文件中，根据卡片请求方传递的字段刷新对应布局。区分加载不同布局的关键是区分使用方，外屏桌面和设置界面在申请时候将在自定义字段（PARAM_FORM_CUSTOMIZE_KEY）增加一个键名为EXTENED_FA_CARD，值为TYPE_BALI，方便卡片提供方进行判断。卡片使用方代码如下：
            
            Bundle bundleParams = new Bundle();
            bundleParams.putString("EXTENED_FA_CARD", "TYPE_BALI");
            intent.putExtra(AbilityFormUtils.PARAM_FORM_CUSTOMIZE_KEY, bundleParams);

下面，将以时钟卡片为例，详细介绍适配过程：

#### 步骤一：监听键值对，判断卡片布局类型

生命周期onCreateForm中，通过读取EXTENED_FA_CARD的值识别使用方，如果其值为TYPE_BALI，则对卡片标志位baliType进行数据绑定刷新。代码示例如下：
    
    @Override
    protected ProviderFormInfo onCreateForm(Intent intent) {
    HwLog.info(TAG, " onCreateForm ");
    IntentParams intentParams = intent.getParam(AbilitySlice.PARAM_FORM_CUSTOMIZE_KEY);
    if (intentParams.getParam("EXTENED_FA_CARD").equals("TYPE_BALI")) {
    isBali = true;
    }
    }

如果能获得该值，说明此次请求方为Pocket外屏应用或外屏桌面应用设置；通过将该标志赋给成员变量isBali ，并将其放入zsonObject中，可以与JS卡片的变量baliType进行绑定。
    
    zsonObject.put(JSData.BALITYPE,isBali);
    FormBindingData formBindingData = new FormBindingData(zsonObject);

#### 步骤二：在JS中绑定标志位

在卡片JS文件中自定义baliType变量，用于标识使用方是否为Pocket外屏桌面或外屏设置桌面。baliType值默认为false，表示默认不是Pocket外屏服务卡片布局，只有查询到标志位才会置为true。
    
    export default {
        data: {
            clockimages:{
                face:this.$r('app.media.fa_clock_widget'),
                hourHand:this.$r('app.media.fa_clock_widget_hour'),
                minuteHand:this.$r('app.media.fa_clock_widget_minute'),
                secondHand:this.$r('app.media.fa_clock_widget_second'),
                faceNight:this.$r('app.media.fa_black_clock_widget'),
                hourHandNight:this.$r('app.media.fa_black_clock_widget_hour'),
                minuteHandNight:this.$r('app.media.fa_black_clock_widget_minute'),
                secondHandNight:this.$r('app.media.fa_black_clock_widget_second'),
                digitColor:this.$r('app.color.fa_clock_digit_color'),
                digitColorNight:this.$r('app.color.fa_clock_digit_color_night'),
                digitRadiusRatio:"0.55",
            },
     
            city:this.$t{'strings.fa_city_pre1'},
            date:new Date().toLocaleDateString(),
            hourswests:"-8",
            baliType:false,
        }
    }

#### 步骤三：HML布局适配

根据baliType属性，调整布局。示例代码如下：
    
    <div class="container" onclick="routerEvent">
    <stack>
    <div style="height: 100%; width: 100%; background-color: {{$r('app.color.fa_background_color')}};"></div>
        <image src="{{$r('app.media.fa_background_image')}}" style="width: 100%; height: 100%; background-size: cover; background-position: center;"></image>
        <div class="ratio_div">
        <div class="clock_group">
        <clock class="clock" clockconfig="{{clockimages}}" hourswest="{{hourswests}}" onhour="refresh"></clock>
            <div class="txt_group">
            <text class="txt_city">{{city}}</text>
            <text class="txtFix_date" if="{{baliType}}">********</text>
            <text class=""text_date>{{date}}</text>
            </div>
        </div>
        </div>
    </stack>
    </div>

其中：
    
    <text class="txtFix_date" if="{{baliType}}">********</text>

通过if条件，表示该控件只在Pocket外屏布局显示；如果为false，则默认不显示。

#### 步骤四：卡片适配刷新

部分应用需要适配外屏卡片刷新，但刷新接口onTriggerFormEvent中无Intent参数，刷新示例代码如下：
    
    @Override
        protected void onTriggerFormEvent(int formId,String message){
            if (DEBUG){
                LogUtil.info(TAG,:"onTriggerFormEvent.formId:"+ formId +",message:"+message;);
            }
            if(message == null || message.length() == 0) {
                LogUtil.warning(TAG,"onTriggerFormEvent.get empty message.");
                return;
            }
     
            CallbackParameter parameter = new CallbackParameter(CallbackParameter.EVENT_TRIGGER_EVENT,formId,message);
            parameter.setAbility(this);
            FormControllerManager manager=getControllerProvider();
            String formName = manager.getTriggerFormName(message);
            if (!EMPTY_STRING.equals(formName)){
                traverseMonthViewControllers(parameter,formName);
            }
        }

该如何判断该卡片是Huawei Pocket外屏卡片来进行刷新呢？

下面以日历适配代码为例，简单介绍适配思路。可在onCreateForm中，将FromId 和标志位共同存储在卡片应用的SP中，方便刷新时候查询、判断。
    
    /**
     *saveFormBaliInfo
     *
     * @param formId formId
     * @param isBaliOuterScreen isBaliOuterScreen
     */
     
        public void saveFormBaliInfo(int formId,boolean isBaliOuterScreen){
            if(formId<0){
                return;
            }
            PreferencesUtil preferencesUtil = new PreferencesUtil(mContext.getApplicationContext(),IS_BALI_SP_NAME);
            LogUtil.info(TAG,"saveFormBaliInfo() formId: " + formId + ", preferences :" + preferencesUtil);
            if(preferencesUtil.getPreferences() !=null){
                preferencesUtil.setPreferencesStringFlushSync(Long.toString(formId),String.valueOf(isBaliOuterScreen));
            }
        } 

在每次回调onTriggerFormEvent时查询卡片SP，对比FormId ，获取标志位信息，从而避免刷新出Pocket卡片外的卡片内容。
