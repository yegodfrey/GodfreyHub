# 服务卡片原理介绍

服务卡片是元服务的一种界面展示形式，将元服务的重要信息或操作前置到服务卡片，以实现服务直达、减少体验层级的目的。

服务卡片常用于嵌入到其他应用（当前只支持系统应用）中作为其界面的一部分显示，并支持拉起页面，发送消息等基础的交互功能。服务卡片使用方负责显示卡片。对于卡片这一形式，我们需要能够理解以下几个概念：

**服务卡片提供方**

卡片提供方的功能在于提供卡片显示内容的HarmonyOS应用或元服务，控制卡片的显示内容、控件布局以及控件点击事件。

**服务卡片使用方**

卡片使用方可以显示卡片内容的宿主应用，控制卡片在宿主中展示的位置。

**服务卡片管理服务**

卡片管理服务主要用于管理系统中所添加卡片的常驻代理服务，包括卡片对象的管理与使用，以及卡片周期性刷新等。

有关卡片运作机制的相关内容，可以参考：[服务卡片概述](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/ability-service-widget-overview-0000001062607955)

本文推荐使用JS卡片。如下指导也是根据JS卡片的开发方式进行。
