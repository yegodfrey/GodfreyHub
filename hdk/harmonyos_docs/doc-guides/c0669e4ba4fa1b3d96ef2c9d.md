# 分布式UI测试框架  
  
#### 1 框架概述

分布式UI测试框架是HarmonyOS应用界面测试框架，提供UI控件查找，点击，检视，按键注入等API并且支持跨设备测试。HarmonyOS应用开发者基于该测试框架可以编写和运行简洁可靠的UI自动化测试用例。

使用说明:如果您测试的UI中包含web范式或声明式范式开发的页面，需使用harmonyos 2.0或以上的真机/模拟器以及com.huawei.ohos.testkit:runner:2.0.0.200测试框架版本。

**表1** 测试能力概览序号 | 功能点 | 描述  
---|---|---  
1 | 控件查找 | 使用简洁易用的控件定位API，描述目标控件特征  
2 | 控件操作 | 点击、滑动、多点触控等UI操作；控件属性和状态查询  
3 | 按键注入 | 注入按键事件(后退键，键盘按键等)  
4 | 跨设备操作 | 操作/查询分布式网络上的其他设备上的FA界面  
  
#### 2 引用方式

应用开发者通过在工程build.gradle中添加如下编译依赖引入分布式UI测试框架。
    
    dependencies {
      implementation fileTree(dir: 'libs', include: ['*.jar', '*.har'])
      testImplementation 'junit:junit:4.13.1'
      ohosTestImplementation 'com.huawei.ohos.testkit:runner:2.0.0.200'
      ohosTestAnnotationProcessor "com.huawei.ohos.testkit:processor:2.0.0.100"
      // other dependencies
    }

#### 3 API使用说明

分布式UI测试框架提供三个基础API类：UiDriver，By，UiComponent，大部分UI测试用例均可以通过使用这三个API类来编写实现。

     * UiDriver类为UI测试的入口，提供控件查找，控件存在性检查以及按键注入能力
     * By类用于描述目标控件特性(常用的控件特征包括控件文本、控件id等)，UiDriver根据By描述的控件特征信息来完成控件定位查找
     * UiComponent为UiDriver查找返回的控件对象，他提供控件属性查询，控件点击，滑动查找等触控/检视能力

如下示例代码通过UiDriver, By, UiComponent三个API类完成控件的查找和点击操作：
    
    UiDriver.create().findComponent(By.text("button")).click();

#### [h2]3.1 控件查找

分布式UI测试框架通过By类提供了丰富的控件特征描述API，用以匹配查找要操作/检视的目标控件。By提供的API能力具有下述几个特点:

     * 支持单属性匹配和多属性组合匹配，例如同时指定目标控件text和id
     * 控件属性支持多种匹配模式(EQUALS，CONTAINS，STARTS_WITH，ENDS_WITH, MATCHES)
     * 支持控件相对定位，可通过isBefore和isAfter等API限定邻近控件特征进行辅助定位

**表2** 支持的控件属性序号 | 属性名称 | 属性类型  
---|---|---  
1 | id | int  
2 | text | String  
3 | type | String  
4 | enabled | boolean  
5 | contentDesc | String  
6 | clickable | boolean  
7 | focused | boolean  
8 | scrollable | boolean  
9 | selected | boolean  
  
**3.1.1 控件绝对定位**

适用于可根据控件自身属性特征进行定位的情形。

**示例代码1** 查找id为ResourceTable.Id_button的控件：
    
    UiComponent button = driver.findComponent(By.id(ResourceTable.Id_button));

**示例代码2** 查找id为ResourceTable.Id_button并且状态为enabled的控件, 适用于无法通过单一属性定位的场景：
    
    UiComponent button = driver.findComponent(By.id(ResourceTable.Id_button).enabled(true));

通过By.id(xxx).enabled(yyy)来对目标控件的多个属性进行指定。

**示例代码3** 查找文本中包含hello的控件, 适用于控件属性取值不能完全确定的场景：
    
    UiComponent txt = driver.findComponent(By.text("hello", ValuePattern.CONTAINS));

通过向By.text()方法传入第二个参数ValuePattern.CONTAINS来指定文本匹配规则；默认规则为ValuePattern.EQUALS，即目标控件text属性必须严格等于给定值。

**3.1.2 控件相对定位**

适用于无法根据控件自身属性特征进行定位，需借助临近特征控件进行辅助定位的情形。一般地，特征控件为某个具有全局唯一特征的控件(例如具有唯一的text)。

By.isAfter()和By.isBefore()两个API用于描述目标控件建与特征空间的相对关系约束。

    UiComponent switch = driver.findComponent(By.id(ResourceTable.Id_switch).isAfter(By.text("Item3_2")));

#### [h2]3.2 控件操作

UiComponent类代表UI界面上的一个控件，一般通过UiDriver.findComponent(By)方法查找。使用该类的实例，可以进行控件属性获取，控件点击，滑动查找，文本注入等操作。

**表3** 控件操作API序号 | API | 功能描述  
---|---|---  
1 | UiComponent.click() | 点击控件  
2 | UiComponent.longLick() | 长按控件  
3 | UiComponent.doubleClick() | 双击控件  
4 | UiComponent.inputText(String) | 向控件输入文本(适用于文本框控件)  
5 | UiComponent.scrollSearch(By) | 滑动查找子控件(适用于ListContainer等可滑动的容器控件)  
  
**表4** 控件属性查询API序号 | API | 功能描述  
---|---|---  
1 | UiComponent.getId() | 获取控件id  
2 | UiComponent.getText() | 获取控件text  
3 | UiComponent.getType() | 获取控件类型  
4 | UiComponent.getContentDesc() | 获取控件ContentDescription属性  
5 | UiComponent.isEnabled() | 获取控件是能状态  
6 | UiComponent.isClickable() | 检查控件是否可点击  
7 | UiComponent.isScrollable() | 检查控件是否可滑动  
8 | UiComponent.isFocused() | 检查控件是否获得焦点  
9 | UiComponent.isSelected() | 检查控件是否被选中  
  
**示例代码1** 控件点击：
    
    driver.findComponent(By.id(ResourceTable.Id_button)).click();

**示例代码2** 通过get接口获取控件属性后，可以使用断言接口对其进行断言检查：
    
    UiComponent component = driver.findComponent(By.id(ResourceTable.Id_title));
    assertEquals("Hello", component.getText());

**示例代码3** 在ListContainer控件中滑动查找text为Item3_3的子控件：
    
    UiComponent listContainer = driver.findComponent(By.id(ResourceTable.Id_list));
    boolean found = listContainer.scrollSearch(By.text("Item3_3"));
    assertTrue(found, "Target component not found!");

**示例代码4** 向输入框控件中输入文本：
    
    UiComponent editText = driver.findComponent(By.id(ResourceTable.Id_input));
    editText.inputText("user_name");

#### [h2]3.3 按键注入

按键注入API由UiDriver类提供，当前只提供了pressBack()方法，用于在当前FA页面触发"后退"事件。

**表5** 事件注入API序号 | API | 功能描述  
---|---|---  
1 | UiDriver.pressBack() | 在当前FA页面触发"后退"事件  
  
#### [h2]3.4 分布式操作

分布式UI测试框架为本端设备和远端设备提供一致的测试能力API，唯一的区别在于UiDriver实例的创建方式。

     * 使用UiDriver.create()方法创建的实例用于操控本端设备上的FA界面
     * 使用UiDriver.createForRemoteDevice(DeviceType)方法创建的实例用于操作远端设备上的FA界面

其中DeviceType参数为远端设备类型, 支持的取值范围为{PHONE, PAD, TV, WATCH, LAPTOP, CAR, ALL}, 其中ALL用于匹配任意类型的设备。

**示例代码1** 在远端PAD界面上输入文本：
    
    UiDriver driver = UiDriver.createForRemoteDevice(DeviceType.PAD);
    UiComponent editor = driver.findComponent(By.id(ResourceTable.Id_input));
    editor.inputText("user_name");

#### 4 测试用例编写说明

分布式UI测试框架当前支持编写JUnit语法范式的测试用例，具体编写说明请参考[Java测试用例编写说明](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/unittest-framework-0000001152596374#section151372407594)。

在应用UI测试中，通常需要先拉起FA页面，再使用API对UI元素进行操控和检视；测试完成后需要在teardown阶段销毁FA页面。使用HarmonyOS Ability框架提供的AbilityDelegator测试Kit，可以完成FA的拉起、销毁等操作。 
    
    @Test
    public void clickButton() {
        // 获取AbilityDelegator单例
        IAbilityDelegator DELEGATOR =AbilityDelegatorRegistry.getAbilityDelegator();
        UiDriver DRIVER = UiDriver.create();
        Intent intent = new Intent();
        // 使用AbilityDelegator拉起待测试的FA页面
        intent.setElementName(DELEGATOR.getAppContext().getBundleName(),"SettingsPage)");
        DELEGATOR.startAbilitySync(intent);
        Time.sleep(2000L);
        // 使用UiTest相关API进行界面元素操作/检视
        UiComponent widget = DRIVER.findComponent(BY.id(ResourceTable.Id_button));
        widget.click();
        assertEquals("clicked", widget.getText());
    }
