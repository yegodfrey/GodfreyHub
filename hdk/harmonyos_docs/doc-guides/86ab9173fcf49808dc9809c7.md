# 导入Sample工程

DevEco Studio支持Sample工程的导入功能，通过对接Gitee开源社区中的Sample资源，可一键导入Sample工程到DevEco Studio中。

下面介绍导入OpenHarmony Sample的方法。

     1. 在DevEco Studio的欢迎页，进入**Configure （****或**![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113453.38995758439025793451076369489655:50001231000000:2800:481D3D8383E51E67D1975D87A5E31DF0C561F1450B076101D0FA17F275C037D7.png?needInitFileName=true?needInitFileName=true)**图标****） > Settings > Version Control > Git**界面，单击**Test** 按钮检测是否安装Git工具。
        * 已安装，请根据2开始导入Sample。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113453.62260639897174232471432736392661:50001231000000:2800:F789D3B01D201693EF14E2F08E7DA9410574965EECA71A723C3B1A1ADF0205D8.png?needInitFileName=true?needInitFileName=true)

        * 未安装，请单击**Download and Install** ，DevEco Studio会自动下载并安装。安装完成后，请根据2开始导入Sample。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113453.86409177285709231766618828388981:50001231000000:2800:67024D15A8ECD9148A064A962A86DD8088A5B5EECCBCBE6E53718AEEB487383B.png?needInitFileName=true?needInitFileName=true)

     2. 在DevEco Studio的欢迎页，单击**Import Sample** 按钮，导入Sample工程。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113453.48868414630670166397468039272391:50001231000000:2800:47C43A82314EB29697E9F15617022E8C873B38326054B423C374DFFFB4A13A20.png?needInitFileName=true?needInitFileName=true)

在打开工程的情况下，可以点击**File > New > Import… > Import Sample**来进行导入 。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113453.41887401895054524669856412776829:50001231000000:2800:88D84080AAE16AE000CEC4D816BAF4354865026FA4B37A2800EDDF1ACD34B34E.png?needInitFileName=true?needInitFileName=true)

     3. 在**OpenHarmony Samples** 下选择需要导入的Sample工程，然后单击**Next** 。
     4. 设置**Project name** 和**Project location** ，然后单击**Finish** ，等待Sample工程导入完成。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113453.49572812318794132258845722683730:50001231000000:2800:B5F393DFFCE40158A45AFD33A616AA28E5098BF36A90C71504425BE7F8A2F6D5.png?needInitFileName=true?needInitFileName=true)

     5. 导入Sample后，等待工程同步完成即可。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113453.50210869795273326957375331993459:50001231000000:2800:8D9CF9F0FA105AACDB2393E8B2E61B070C770C81DF23B64A87A71635ED023B1B.png?needInitFileName=true?needInitFileName=true)

如果网络受限，导入时会提示“Failed to connect to gitee.com port 443: Time out”连接超时错误，请[配置Git代理信息](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/faq-development-environment-0000001168829643#section2846101894313)。
