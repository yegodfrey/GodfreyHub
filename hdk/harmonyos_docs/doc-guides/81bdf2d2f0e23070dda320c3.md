# 交互不中断示例代码

hml 文件示意如下：
    
    <!-- index.hml -->
     
    <div class="container">
    <!-- 头部位置布局 -->
      <div class="top">
        <div class="top_left">
          <image src="pages/common/images/ic_public_back.png" class="top_image"></image>
          <text class="top_text">
            华为事件
          </text>
        </div>
        <div>
          <image src="pages/common/images/ic_public_more.png" class="top_image2"></image>
        </div>
      </div>
    <!-- 栅格布局，图片自适应设备 -->
      <grid-container columns="6" id="mygrid">
        <grid-row style="justify-content: space-around; width: 100%;">
          <grid-col class="left" sm="6" md="5">
            <image src="pages/common/images/xBody_Picture.png" class="footPicture_image"></image>
          </grid-col>
        </grid-row>
      </grid-container>
    <!-- 内容区 -->
      <text class="content">
        根据上文提到的体验诉求，对比于普通屏幕手机，为了保证体验连续性，需要满足以下基础体验要求：\n1)图片、视频等视觉元素不应发生变形、裁剪等信息缺失。\n2)展开态字体大小不应发生明显变化，在保证可读性的基础上，建议保持跟折叠态一样的大小。\n3)一般情况下，展开态不应出现页面内的内容元素数量减少，或图片元素模糊、分辨率下降或视觉体。
      </text>
    <!-- 底部评论区 -->
      <div class="footer">
        <input id="textarea" class="footer_search" placeholder="我想说…">
        </input>
        <image src="pages/common/images/ic_public_comments.png" class="footer_images"></image>

    </div>
