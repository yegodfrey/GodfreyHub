# 开发智能穿戴表盘

HarmonyOS面向UI设计师提供了简单的表盘开发方式，通过使用HarmonyOS表盘开发工具，无需编写代码，就可以进行表盘功能、布局的配置以及资源导入，完成表盘开发。

表盘开发分为四个步骤：表盘设计、使用表盘工具开发表盘、表盘上表调试（可选）、表盘发布到表盘市场。

#### 表盘设计

智能穿戴的核心功能是时间展示，所以表盘设计首先要考虑的是如何清晰地展示时间。开发者可以选择使用指针样式、数字样式或是两种样式的综合表现。在表盘的设计上，需要注意背景样式和时间样式的和谐。除了核心功能外，开发者还可以添加其他自定义功能模块。详情请参考 _[表盘控件及数据说明](https://developer.huawei.com/consumer/cn/doc/distribution/content/watch-widget-0000001129929459)_ ，了解手表开放的控件能力与数据能力，进行表盘设计。

#### 使用表盘工具开发表盘

表盘设计完成后，使用HarmonyOS提供的表盘工具进行表盘开发。

     1. 对表盘设计中的单个元素进行分解，分解为 _[表盘控件及数据说明](https://developer.huawei.com/consumer/cn/doc/distribution/content/watch-widget-0000001129929459)_ 中描述的基础基础控件，如一个图标、一个文本。
     2. 按照分解的基础控件完成资源切图。
     3. 使用表盘工具，完成表盘布局配置和资源图片导入，导出表盘资源包。

#### （可选）表盘调试

通过华为运动健康App，可以将表盘安装到手表上进行调测。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113857.34549921517388377606066558326421:50001231000000:2800:4C039A3ABB7C02912D2E58BBC832FF655EAF3EB37173820235B26DD5EBAED86F.png?needInitFileName=true?needInitFileName=true)

     1. 使用华为运动健康App的 _[Beta版本](https://developer.huawei.com/consumer/cn/doc/distribution/content/themes-design-tools-0000001054531194)_ 进行调测。
     2. 调测功能只对华为注册设计师开放，需要使用 _[认证为华为主题设计师](https://developer.huawei.com/consumer/cn/doc/distribution/content/settlement-guidance-0000001056348857)_ 的账号登录运动健康App。

表盘的调试方法如下：

     1. 将打包好的表盘资源包保存到手机中。资源包后缀名为.hwt，资源包的命名不能包含中文，只能包含英文字符、数字。
     2. 安装并登录华为运动健康App。
     3. App扫码绑定手表，进入“我的 > 我的设备 > 表盘市场”，加载已保存到手机的表盘资源包，并选择安装到手表上。
     4. 在手表上查看表盘效果。

#### 表盘发布到主题市场

在进行表盘发布前，需要使用已实名认证的开发者账号，登陆 _[华为开发者联盟网站](https://developer.huawei.com/consumer/cn/)_ 。

如果是第一次上传表盘，需要先将“主题中心”添加到“管理中心”，流程如下：

     1. 在开发者联盟网站首页右上角，点击进入“管理中心”。
     2. 点击页面右上角的“自定义桌面”，选择“内容服务”，勾选“主题中心”。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113857.41925425592493965591639591960099:50001231000000:2800:A0F836B15182033E60082E550E7D144A568A046AABE9D5D4DBF35A01DB6F3654.png?needInitFileName=true?needInitFileName=true)

如果已经添加了“主题中心”到“自定义桌面”，表盘发布流程如下：

     1. 在[开发者联盟网站](https://developer.huawei.com/consumer/cn/)首页右上角，点击进入“管理中心”，在左侧导航栏选择“内容服务”，点击“主题中心”。
     2. 点击“上传作品”，发布新表盘。

勾选“主题”，点击弹窗中心的“+”添加表盘资源包（.hwt）并上传。

     3. 表盘上传成功后，状态显示为审核中，华为工作人员将在5个工作日内审核完成。
