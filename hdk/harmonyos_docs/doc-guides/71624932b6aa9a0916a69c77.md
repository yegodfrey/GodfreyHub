# 响应式布局

响应式布局页面内的信息架构会随着设备屏幕规格的变化而发生变化。常见的响应式动态布局的变形形式为：挪移布局、重复布局、瀑布布局等。

#### 挪移布局

**图1** 挪移布局效果示意  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113811.04576330892352035631639444588464:50001231000000:2800:1C0ED0068CB84A3D78F500BFAF6D5230BF5E21EEEEAD8764C11A60B449E64605.gif?needInitFileName=true?needInitFileName=true)

布局特点：布局内的元素根据布局的宽度来选择是上下排布还是左右排布。

适用场景：信息架构层级少的页面，例如门户网站首页面、内容详情页面等。

适配规则：首先判断布局区域是否有明显的“宽高特征”，即横纵比是否大于4:3；其次判断横向宽度，是否能容得下若干个元素，如果容得下就左右排布，容不下就上下排布。

其示例代码请参考：[挪移布局](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/foldable-screen-samples-move-layout-0000001442736429)

#### 重复布局

**图2** 重复布局效果示意  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113811.24390773750068295349453564350188:50001231000000:2800:04B11929A1E81D835FBB105EBE716B7493712B39440B0C1BC7B4D103675921B8.gif?needInitFileName=true?needInitFileName=true)

布局特点：利用屏幕的宽度优势，将相同属性的布局组件横向并列同时排布。

适用场景：内容运营类列表信息，例如歌单列表、应用列表等。

适配规则：可以定义单个元素的宽度规则，随着屏幕宽度的变化，⾃动计算可以重复的元素的个数，满足宽度条件时横向重复排列。

其示例代码请参见：[重复布局](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/foldable-screen-samples-repeat-layout-0000001442616461)
