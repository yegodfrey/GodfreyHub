# 在Router中运行应用/服务

在Router（路由器）中安装和运行HarmonyOS应用/服务，可以使用网线连接PC和路由器，或者将PC和路由器连接到同一个WLAN。

#### 前提条件

     * 已将Router升级为开发者版本，获取开发者版本参考[获取路由器开发版本](https://developer.huawei.com/consumer/cn/doc/development/smarthome-Guides/111-0000001110603976)。
     * 已将PC连接到Router。
     * 在Router中运行应用/服务，需要根据[为应用/服务进行签名](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/ide_debug_device-0000001053822404#section677893315228)章节，提前对应用/服务进行签名。

#### 操作步骤

     1. 使用网线或WLAN方式，将PC和路由器进行连接。
     2. 在DevEco Studio的Terminal窗口，执行**ipconfig** 命令，查看路由器IP地址。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113437.05457070025828948941668986844796:50001231000000:2800:4B4EC378C51DE1233D63288B60E771ECA4A69BC52D9966DFEA5008D3A678EEF3.png?needInitFileName=true?needInitFileName=true)

     3. 在Terminal窗口，使用**telnet** 命令登录到Router串口，示例如下，IP地址请根据上一步查询的结果进行修改。
            
            telnet 192.168.3.1

     4. 在Terminal窗口，依次执行**sh、****su** 和**setconsole** ，打开路由器串口打印功能。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113437.38392054871855187005525245057222:50001231000000:2800:96ADB0FC178FF60B5AB5DB7DA673166A034A1A07E66EF5B5AA2C14EBD21A2993.png?needInitFileName=true?needInitFileName=true)

     5. 在DevEco Studio菜单栏中，单击**Run >Run'模块名称'**或![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113437.55424733797008659916721519829746:50001231000000:2800:D7641056DFDB93F98C2DF8493DC528E180C16ECB5F04FF983E07436D48F722AB.png?needInitFileName=true?needInitFileName=true)，或使用默认快捷键**Shift+F10** （macOS为**Control+R** ）运行应用/服务。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113437.31307054281484040981661869565810:50001231000000:2800:5F5A51899D1405AAE7037A83B94B3697F9FF1A32A2B6A992FC3056F266574E59.png?needInitFileName=true?needInitFileName=true)

     6. 界面会弹出设备选择框，选择要推送的Router进行安装运行，单击**OK** 。
     7. 界面会弹出输入密码的提示框，该密码是Router的Web维护页面登录密码，输入后单击**OK** ，即可把HAP包推送到Router安装。
     8. DevEco Studio启动HAP的编译构建和安装。安装成功后，会在Terminal中打印日志信息。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113437.25631650285474852645523929158597:50001231000000:2800:4CE6B2E0FCB602191A114E327C9486C106CC85ECEB9556CAB46A644C83C91411.png?needInitFileName=true?needInitFileName=true)

具体打印日志信息，由开发者在应用/服务中自行定义。
