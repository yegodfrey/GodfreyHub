# 在Car中运行应用/服务

在Car中安装和运行HarmonyOS应用/服务，采用**USB** 连接方式。

#### 前提条件

在Car中运行应用/服务，需要根据[为应用/服务进行签名](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/ide_debug_device-0000001053822404#section677893315228)章节，提前对应用/服务进行签名。

#### 操作步骤

     1. 使用USB方式，连接Car和PC端。
     2. 在菜单栏中，单击**Run >Run'模块名称'**或![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113436.64051844773855175796436315036928:50001231000000:2800:41FCD0BE83CC6A609F67CFF40A589B6AA39404400BA01966BFCC513F030D3B79.png?needInitFileName=true?needInitFileName=true)，或使用默认快捷键**Shift+F10** （macOS为**Control+R** ）运行应用/服务。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113436.60984856423464762365848082062094:50001231000000:2800:426831198B830BDDE5D3119B2111DBF7F9715446F6856E8A362D2224DFD10A29.png?needInitFileName=true?needInitFileName=true)

     3. DevEco Studio启动HAP的编译构建和安装。安装成功后，Car会自动运行安装的HarmonyOS应用/服务。
