# 媒体会话管理开发概述

AVSession是一套媒体播放控制框架，对媒体服务和界面进行解耦，并提供规范的通信接口，使应用可以自由、高效地在不同的媒体之间完成切换。

#### 约束与限制

     * 在使用完AVSession类后，需要及时进行资源释放。
     * 播放器类需要使用ohos.media.player.Player，否则无法正常接收按键事件。
