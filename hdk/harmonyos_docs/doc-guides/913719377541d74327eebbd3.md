# 功耗测试  
  
功耗测试主要验证HarmonyOS应用在华为真机设备上运行的功耗，包括屏幕占用时长、WLAN占用时长、音频占用时长等。具体功耗测试项的详细说明请参考[功耗测试标准](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/app-power-testing-0000001182513117)。

功耗测试支持Phone，包格式包括Hap/App。

#### 前提条件

     * 已注册华为开发者帐号，并完成实名认证，具体请参考[帐号注册和实名认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。
     * 已通过DevEco Studio开发完应用，并编译构建生成Hap或App，具体请参考[DevEco Studio使用指南](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/tools_overview-0000001053582387)。

#### 创建测试任务

     1. 访问[HUAWEI DevEco Service](https://cn.devecostudio.huawei.com/)页面，使用华为开发者帐号进行登录。
     2. 点击界面上的“从这里开始”按钮，进入到控制台。
     3. 选择或者创建一个项目，如果新创建一个项目，注意选择HarmonyOS。

     4. 进入项目空间，在左侧导航栏中选择**测试服务 > HarmonyOS云测试**，进入HarmonyOS云测试页面**，** 点击HarmonyOS云测试页面右侧的**创建测试** 按钮，进入创建测试任务页面**。**

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113510.11886963335305953478130826550961:50001231000000:2800:426BD91DD3A9FCBA3F56E44BAC2C97810FF28D035F95A62D369049864C48481D.png?needInitFileName=true?needInitFileName=true)

     5. 在创建测试任务页面选择**功耗测试** ，设置如下信息后，点击**下一步** 。
        * 应用程序：选择待测试的HarmonyOS应用包，包括HAP和APP两种格式，如果未上传应用，请先从本地上传一个HarmonyOS应用包。
        * 应用分类：设置应用的一级分类、二级分类和三级分类。

每天只能进行100次功耗测试任务，请合理安排测试任务。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113510.84208649800969163250200388529359:50001231000000:2800:4DE209B39D365FBCDEC2A0E034C7A079490D07E1707F2D71328C67E42341ECF2.png?needInitFileName=true?needInitFileName=true)

     6. 选择测试设备，功耗测试支持手机（Phone）和轻量级智能穿戴（LiteWearable）。
     7. 任务创建完成后，请等待测试任务完成，可以在HarmonyOS云测试任务列表中查看任务状态。

#### 查看测试报告

测试任务执行完成后，在任务列表中，可以点击**查看测试报告** 按钮，查看测试结果详细信息。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113510.38095428621383581043241560098987:50001231000000:2800:74D1E81A2F6490E918811F72DD09E9F5477A38735E51500F0118A9F08576FC99.png?needInitFileName=true?needInitFileName=true)

在测试报告的概览页，可以查看测试任务的整体情况，如测试通过率、问题分布、在各个测试终端上的问题分布情况。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113510.68892856945867038816454006093875:50001231000000:2800:8AB4478F97D8E73F0870E2A89D2A1F4E14DC289A17B3FBFCE09D768766B65E8E.png?needInitFileName=true?needInitFileName=true)

点击测试设备后的**查看详情** 按钮，可以查看测试任务详情信息，如测试截屏、异常信息和日志信息。
