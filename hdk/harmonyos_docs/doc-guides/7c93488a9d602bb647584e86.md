# 外屏服务卡片开发参数配置

Pocket小外屏的卡片模板推荐在已经完成手机桌面服务卡片开发的基础上进行扩展，需要在配置文件config.json中对forms字段进行修改：
    
    "forms": [
      {
        "name": "Form_Js",
        "description": "form_description",
        "type": "JS",
        "jsComponentName": "card",
        ……
      ],
        "metaData": {
          "customizeData": [
            {
              "name": "exteCoverFACard",
              "value": "com.huawei.testApp"
            }
          ]
        }
      }
    ]

即在FormAbility的config.json文件中增加一个卡片属性的元数据，数据解释如下：

**表1** Config属性 | 参数说明 | 是否可以缺省  
---|---|---  
metaData | 元数据 | 否  
customizeData | 键值对数组 | 否  
Name | 名称建议“exteCoverFACard” | 是  
Value | 数值为包名 | 否

“exteCoverFACard” 取值是为了让小外屏桌面能筛选。如果不配置该字段，则不会显示在外屏上。
