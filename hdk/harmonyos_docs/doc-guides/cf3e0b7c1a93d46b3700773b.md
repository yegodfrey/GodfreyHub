# 导入Sample工程

DevEco Studio支持Sample工程的导入功能，通过对接Gitee开源社区中的Sample资源，可一键导入Sample工程到DevEco Studio中。

下面介绍导入HarmonyOS Sample的方法。

     1. 在DevEco Studio的欢迎页，进入**Configure**** > Settings > Version Control > Git**界面，单击**Test** 按钮检测是否安装Git工具。
        * 已安装，请根据2开始导入Sample。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113422.03818335416893618903746516250686:50001231000000:2800:5D1406963D0AACFF4934BF6DC4B625D5ED7458FC4A925C71C8953B836404AEE4.png?needInitFileName=true?needInitFileName=true)

        * 未安装，请单击**Download and Install** ，DevEco Studio会自动下载并安装。安装完成后，请根据2开始导入Sample。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113422.14104729578559333297891583365119:50001231000000:2800:73BB847A8FD1BD4FAC4FECFC578902AD42F332913CE05B62C55B827854510BD3.png?needInitFileName=true?needInitFileName=true)

     2. 在DevEco Studio的欢迎页，单击**Import Sample** 按钮，导入Sample工程。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113422.62474014515952598195688822552920:50001231000000:2800:A1A6516F77BE51088A71C58EA638F5014708BFFA6954BD69F602084BB91E7798.png?needInitFileName=true?needInitFileName=true)

在打开工程的情况下，可以单击**File > New >Import >Import Sample**来进行导入。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113422.98086561021206576561291195911401:50001231000000:2800:DED164FA39D1E7F291200FEAA29B8DA15C4151F38FE59DDF44A458048749123A.png?needInitFileName=true?needInitFileName=true)

     3. 在**HarmonyOS Samples** 下选择需要导入的Sample工程，然后单击**Next** 。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113422.10123830689526757865300741450525:50001231000000:2800:E85869AF2CC7B80192A4539CB7E133BFD3A2DA1E62D0B3DCBEAD4FB874887195.png?needInitFileName=true?needInitFileName=true)

     4. 设置**Project name** 和**Project location** ，然后单击**Finish** ，等待Sample工程导入完成。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113422.27461311673541842477027944394677:50001231000000:2800:F58F94F4984C8AF32924ABE92C024EF799D5D021894361F3F56966561F71ADA6.png?needInitFileName=true?needInitFileName=true)

     5. 导入Sample后，等待工程同步完成即可。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113423.01332504292362309852484355503339:50001231000000:2800:2AA107BA9F1101981EAD658F4657FA06180D7F6B57B7A81BF29AB6D12BBA40C5.png?needInitFileName=true?needInitFileName=true)

如果网络受限，导入时会提示“Failed to connect to gitee.com port 443: Time out”连接超时错误，请[配置Git代理信息](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/faq-development-environment-0000001168829643#section2846101894313)。
