# 折叠屏系列应用开发指导概述

基于HarmonyOS，开发者可以开发折叠屏应用，提供丰富便捷的外屏体验。

此文档针对华为折叠屏产品，提供应用适配的规格要求描述以及适配指导。

#### 折叠屏形态

     * 展开态：折叠屏设备完全展开后的形态。有更大的屏幕尺寸，可充分显示应用内容。
     * 折叠态：折叠屏设备折叠后的形态。折叠后屏幕尺寸变小。
     * 支架态：折叠屏设备处于完全展开和折叠的中间状态，可平稳放置。

#### 折叠外屏

部分折叠屏在折叠态时，有一块可显示、可交互的屏幕，称为外屏。

当外屏较大时，其交互基本和手机保持一致，当外屏较小时，一般用来显示关键信息或执行快捷操作。

目前华为折叠屏有大外屏和小外屏两种规格。

大外屏尺寸接近一个普通的手机，可直接按照手机或折叠屏折叠态的布局及交互设计。

小外屏尺寸较小，仅能显示少量关键信息或快捷操作，需要进行相应的适配设计。
