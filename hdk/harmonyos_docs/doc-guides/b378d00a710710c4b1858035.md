# 百分比使用

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113814.53641947795771070480082343054714:50001231000000:2800:0FA1D5771E258352987B9478AE1AD24A3E08EC32061127D28B06B6A3984354B5.png?needInitFileName=true?needInitFileName=true)

从API Version 5 开始支持。

支持部分字段（width，height，margin，top，left）的百分比设置，通过指定百分比，让框架在运行时自动换算成真实像素值，可以在一定程度上帮助应用进行多设备的显示自适应，在不同尺寸的屏幕上显示尽可能做到一致或合理的布局。本章节通过一个小示例来说明具体的使用。

定义一个div容器class样式，其width及 height 均设置为100%，将该容器放置在hml文件的最外层，则其显示效果将为填满整个屏幕。

布局文件：
    
    // index.hml
    <div class="container"></div>

样式文件如下：
    
    /* index.css */
    .container {
         width: 100%;   /* 容器宽度设置为 100% */
         height: 100%;  /* 容器高度设置为 100% */
         justify-content: center;
         align-items: center;
         flex-direction: column;
         background-color: aquamarine;  /* 设置背景色为碧绿色 */
     }

在轻量级智能穿戴（454x454) 上运行效果为铺满屏幕：

**图1** 454x454 手表屏幕显示效果  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113814.32643201093225141818373343484712:50001231000000:2800:CDE3456E5B314FB0790FF3ED8F03F845A1C8BD0FA6F9B9126663BDD93C3A4AD0.png?needInitFileName=true?needInitFileName=true)

接下来，在上面的容器组件中增加一个按钮，并通过百分比来控制按钮组件的尺寸：
    
    // index.hml
    <div class="container">
         <input class="button" type="button" value="Button"></input>
     </div>
    
    /* index.css */
    .button {
         width: 50%;  /* 设置按钮组件的宽度为父组件的50% */
         height: 30%;  /* 设置按钮组件的高度为父组件的30% */
         font-size: 30px;
         background-color: #262626;
     }

在屏幕尺寸不同的设备上运行，按钮的大小会进行自动适配。

**图2** 454x454屏幕尺寸设备上，按钮实际尺寸为227x136，百分比计算会通过浮点数计算后保留整数部分  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113814.91607672785860663921022086526108:50001231000000:2800:80BA99E86E27837CBBEFEA0AF4E3EB4B88C88351DAEC51E0F5E7434FC92E5E7F.png?needInitFileName=true?needInitFileName=true)

为了展示通过在top和left上应用百分比来调整按钮在父组件上的位置（top、left仅stack下有效），在按钮的外层再增加一级 stack 容器，并将该容器的尺寸设置为最外层容器的70%。
    
    // index.hml
    <div class="container">
         <stack class="stackContainer">
             <input class="button" type="button" value="Button"></input>
         </stack>
     </div>
    
    /* index.css */
    .stackContainer {
         width: 70%;
         height: 70%;
         background-color: azure;
     }

查看运行效果，可以看到按钮的尺寸发生了变化，这是因为百分比的计算都是相对于自己所在的父组件的，增加一层 stack 容器后，按钮组件的父组件变为了长宽为70%的 stack 组件：

**图3** 454x454屏幕尺寸设备，按钮宽：454x70%x50% = 158 （158.9 取整数部分） 高：454x70%x30% = 95 (95.34取整数部分）  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113815.57042031290937488207830377820792:50001231000000:2800:9840F747382BE8D6928AD3EB2E30264BCB4F8BC4F6FFB8953F053E79D42A5DAA.png?needInitFileName=true?needInitFileName=true)

修改按钮的top和left来调整按钮的位置：
    
    /* index.css */
    .button {
         top: 10%;   /* 设置y轴上距离父组件为父组件高度的10%位置 */
         left: 10%;  /* 设置x轴上距离父组件为父组件宽度的10%位置 */
         width: 50%;
         height: 30%;
         font-size: 30px;
         background-color: #262626;
     }

**图4** 454x454屏幕尺寸设备  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113815.02310868964139347282329644704166:50001231000000:2800:344C894AFDE7BD9D58EB2EDC66008B8D6B48DF9F51F442B970C4577266044644.png?needInitFileName=true?needInitFileName=true)

为了熟悉margin百分比的使用，再增加一个与stack容器同级的黑色退出按钮，margin（包括margin-top, margin-left, margin-right, margin-bottom）百分比的计算是相对于父组件的高度的。
    
    // index.hml
    <div class="container">    
        <stack class="stackContainer">        
            <input class="button" type="button" value="Button"></input>    
        </stack>    
        <input class="button2" type="button" value="Exit"></input>
    </div>
    
    /* index.css */
    .button2 {
         width: 50%;
         height: 20%;
         font-size: 30px;
         background-color: black;
     }

运行之后可以看到，在没有配置margin的情况下，其是紧贴stack下方显示的：

**图5** 454x454屏幕尺寸设备  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113815.28262564144697059479667207224630:50001231000000:2800:5FCB69E3FA3EC979443D71A94306762DEC5DF8EC024EDA60419D58BFDCBC2D6F.png?needInitFileName=true?needInitFileName=true)

为了达到退出按钮与stack组件拉开一定距离，通过设置 margin-top 来实现：
    
    /* index.css */
    .button2 {
         margin-top: 2%;  /* 父组件高度的2% */
         width: 50%;
         height: 20%;
         font-size: 30px;
         background-color: black;
     }

总体上百分比的使用可以在一定程度上支持对相同布局在不同屏幕上的显示的自动缩放，能够达到一定的多设备适配效果，如果两个设备的屏幕尺寸的长宽比是相同的，仅仅是尺寸不一样，那布局的显示排布在这两个设备上将会显示的比较协调一致；但如果屏幕尺寸比相差较大，则单纯通过百分比则不太容易达成，建议调用device接口的getInfo方法判断屏幕尺寸来确定加载不同的页面。
