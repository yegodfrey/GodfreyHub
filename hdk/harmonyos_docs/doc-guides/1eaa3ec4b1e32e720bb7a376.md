# 下载与安装软件

DevEco Studio支持Windows和macOS系统，下面将针对两种操作系统的软件安装方式分别进行介绍。

#### Windows环境

#### [h2]运行环境要求

为保证DevEco Studio正常运行，建议电脑配置满足如下要求：

     * 操作系统：Windows10 64位
     * 内存：8GB及以上
     * 硬盘：100GB及以上
     * 分辨率：1280*800像素及以上

#### [h2]下载和安装DevEco Studio

     1. 进入[HUAWEI DevEco Studio产品页](https://developer.harmonyos.com/cn/develop/deveco-studio#download)，单击下载列表右侧的![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113419.61941993099469437059067128128786:50001231000000:2800:3476E5AB2CA9C79F41CD0E41834B0822FDB55C846FD0AC5261879193BC03F25B.png?needInitFileName=true?needInitFileName=true)按钮，下载DevEco Studio。
     2. 下载完成后，双击下载的“deveco-studio-xxxx.exe”，进入DevEco Studio安装向导。在如下界面选择安装路径，默认安装于C:\Program Files路径下，也可以单击**Browse...** 指定其他安装路径，然后单击**Next** 。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113419.33860602985172133901595685131669:50001231000000:2800:9CBEBF8F1C3F4272180C331715C9E969C207D29CDB2F9AC42945D153E4B5FE51.png?needInitFileName=true?needInitFileName=true)

     3. 在如下安装选项界面勾选**DevEco Studio** 后，单击**Next** ，直至安装完成。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113419.64768426942055016941106215728438:50001231000000:2800:34BC0569B3C107280684DA2D685C34A07C0E64A049205A08915BC41DF2E0551B.png?needInitFileName=true?needInitFileName=true)

     4. 安装完成后，单击**Finish** 完成安装。

#### macOS环境

#### [h2]运行环境要求

为保证DevEco Studio正常运行，建议电脑配置满足如下要求：

     * 操作系统：macOS 10.15/11.x/12.x
     * 芯片类型：Intel系列
     * 内存：8GB及以上
     * 硬盘：100GB及以上
     * 分辨率：1280*800像素及以上

#### [h2]下载和安装DevEco Studio

     1. 进入[HUAWEI DevEco Studio产品页](https://developer.harmonyos.com/cn/develop/deveco-studio#download)，单击下载列表后的![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113419.62334428865563818079564748502025:50001231000000:2800:C3B4D7F4CBE0DEE2C28B13528B1BCE58B42054AC1C924040A1397E4D4259A9C1.png?needInitFileName=true?needInitFileName=true)按钮，下载DevEco Studio。
     2. 下载完成后，双击下载的“deveco-studio-xxxx.dmg”软件包。
     3. 在安装界面中，将“**DevEco-Studio.app** ”拖拽到“**Applications** ”中，等待安装完成。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113419.97992907860634263718541595301275:50001231000000:2800:EF710E13D7BF27D243CF48DE69A10BEB60F183F7CB8309A7B91CEB295EC709D9.png?needInitFileName=true?needInitFileName=true)

     4. 安装完成后，接下来请根据[配置开发环境](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/environment_config-0000001052902427)，检查和配置开发环境。
