# 在Wearable中运行应用/服务

在Wearable中安装和运行HarmonyOS应用/服务，可以采用**USB** 连接方式或者**IP Connect****ion** 的连接方式。采用**IP Connect****ion** 连接方式要求Wearable和PC端在同一个网段，建议将Wearable和PC连接到同一个WLAN下。

#### 使用USB连接方式

#### [h2]前提条件

     * 在Wearable中，打开“开发者模式”，可在**设置 >关于**中，连续单击“版本号”，直到提示“您已处于开发者模式！”即可。然后在**设置 >开发人员选项**中，打开“**HDC调试** ”开关。
     * 在Wearable中运行应用/服务，需要根据[为应用/服务进行签名](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/ide_debug_device-0000001053822404#section677893315228)章节，提前对应用/服务进行签名。

#### [h2]操作步骤

     1. 使用USB方式，连接Wearable和PC端。
     2. 在菜单栏中，单击**Run >Run'模块名称'**或![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113436.51526976404587933807513878881034:50001231000000:2800:35BD876CAA0CCC678D94C04B6A71B6FDEE418E528D93CE74F78DA1F4E6E54431.png?needInitFileName=true?needInitFileName=true)，或使用默认快捷键**Shift+F10** （macOS为**Control+R** ）运行应用/服务。

     3. DevEco Studio启动HAP的编译构建和安装。安装成功后，Wearable会自动运行安装的HarmonyOS应用/服务。

#### 使用**IP Connect****ion** 连接方式

#### [h2]前提条件

     * 已将Wearable和PC连接到同一WLAN网络。
     * 在Wearable中，打开“开发者模式”，可在**设置 >关于**中，连续单击“版本号”，直到提示“您已处于开发者模式！”即可。然后在**设置 >开发人员选项**中，打开“**HDC调试** ”和“**通过WlAN调试** ”开关。
     * Wearable上的5555端口为打开状态。如果未打开，可以通过使用USB连接方式连接上设备后，执行如下命令打开。
           
           hdc tmode port 5555

     * 在Wearable中运行应用/服务，需要根据[为应用/服务进行签名](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/ide_debug_device-0000001053822404#section677893315228)章节，提前对应用/服务进行签名。
