# 使用远程真机运行应用/服务

#### 概述

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113435.17331910445406599566719396015074:50001231000000:2800:2D04B57FAD06A947983A76B3C74071122D2F5DE3F36EEDD1987443BE2C6BEF13.png?needInitFileName=true?needInitFileName=true)

该特性在DevEco Studio V2.2 Beta1及更高版本中支持。

如果开发者没有真机设备资源，则不能很方便的调试和验证HarmonyOS应用，为方便开发者，DevEco Studio提供了**Remote Device** 远程真机设备资源供开发者使用，减少开发成本。目前，远程真机支持Phone和Wearable设备，开发者使用远程真机调试和运行应用时，同本地物理真机设备一样，需要对应用/服务进行签名才能运行。

相比远程模拟器，远程真机是部署在云端的真机设备资源，远程真机的界面渲染和操作体验更加流畅，同时也可以更好的验证应用/服务在真机设备上的运行效果，比如性能、手机网络环境等。

#### 前提条件

     * 已注册成为华为开发者，并完成华为开发者[实名认证](https://developer.huawei.com/consumer/cn/doc/start/ibca-0000001062388135)。
     * 已对应用/服务进行签名，具体签名指导请参考[配置签名信息](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/ide_debug_device-0000001053822404#section793484619307)。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113435.42293715348070989371148914263456:50001231000000:2800:425A5BE73BBF1662014B1EB1E42AA1E65297A9D739F86DC0B55D242650A8E018.png?needInitFileName=true?needInitFileName=true)

需要注意的是，远程真机每次释放后重新申请，服务端分配的设备都不一样。因此，每次重新申请远程真机后，都需要对应用/服务重新进行签名。

#### 操作步骤

     1. 在DevEco Studio菜单栏，单击**Tools > Device Manager**。
     2. 在**Remote Device** 页签中，单击**Sign In** ，在浏览器中弹出华为开发者联盟帐号登录界面，请输入[已实名认证](https://developer.huawei.com/consumer/cn/doc/start/ibca-0000001062388135)的华为开发者联盟帐号的用户名和密码进行登录（[查看登录授权常见问题](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/faq-remote-emulator-login-0000001087243722)）。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113435.22462306937254637360601172436206:50001231000000:2800:BB838C04F90D49551145A946DE0BC4E8CC358E5F6450618E849B68DFA047073A.png?needInitFileName=true?needInitFileName=true)

     3. 登录后，请单击界面的**允许** 按钮进行授权。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113435.82709428493105859814896037586780:50001231000000:2800:BDA3EEAC725E6BBA0F2787825485D516027ED5CCF7CBEC81F5F2D31141D2B5F3.png?needInitFileName=true?needInitFileName=true)

     4. 在**Single device** 中，单击设备运行按钮![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113435.43919626079397278683592793914035:50001231000000:2800:287634F1F64C53A74F201FC3E178741094FE336B9DB814DDDA3A4998722F0ECD.png?needInitFileName=true?needInitFileName=true)，启动远程真机设备（同一时间只能启动一个设备）。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113435.19352226249036465909687282599824:50001231000000:2800:BBEC16D8867A37AA5B57124630E4EAD912BAE312C454BAFB33298EBBCB5A42C3.png?needInitFileName=true?needInitFileName=true)

     5. 单击DevEco Studio的**Run > Run'模块名称'**或![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113435.20325604135253889504425606400264:50001231000000:2800:644C1DBDFEA574812702A89720027E431E2A0DF5E2DE9CB3B6AA4027F42CB775.png?needInitFileName=true?needInitFileName=true)，或使用默认快捷键**Shift+F10** （macOS为**Control+R** ）。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113435.43195350325655636287899418955848:50001231000000:2800:206A31B3A464F6FC56A467E7218875312F69D55720DD8CD50BB97BE96D2278F2.png?needInitFileName=true?needInitFileName=true)

     6. DevEco Studio会启动应用/服务的编译构建，完成后应用/服务即可运行在远程真机上。
