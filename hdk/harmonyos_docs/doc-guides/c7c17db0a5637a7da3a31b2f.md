# 开发前准备

#### 约束与限制

内屏业务，在折叠后，业务不建议流转到外屏，即折叠动作后，系统将进入锁屏态，业务退到后台或中止。

外屏业务，尽量简单，主要呈现形式为服务卡片。

#### 适用范围

华为Pocket折叠屏产品。

#### 使用对象

需要适配折叠屏手机的应用开发者。

#### 环境准备

请根据下列步骤，进行环境准备：

     1. 请到官方网站下载最新的 [HUAWEI DevEco Studio](https://developer.harmonyos.com/cn/develop/deveco-studio#download_beta)。
     2. 请参考配置配置HarmonyOS SDK，完成DevEco Studio的安装和开发环境配置。
