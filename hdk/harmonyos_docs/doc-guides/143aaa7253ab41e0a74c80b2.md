# 在TV中运行应用/服务

当前暂不支持使用商用智慧屏（TV）真机进行运行和调试，如需运行和调试智慧屏应用或原子化服务，请使用[远程模拟器](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/run_simulator-0000001053303709#section1379810553263)或[远程真机](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/ide-remote-real-device-0000001167977777)。
