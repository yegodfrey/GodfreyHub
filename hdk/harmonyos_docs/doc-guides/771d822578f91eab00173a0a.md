# 创建和运行Hello World

开发环境配置好后，可以通过运行Hello World工程来验证环境设置是否正确。

#### 创建一个新工程

     1. 在DevEco Studio的欢迎页，选择**Create Project** 开始创建一个新工程。
     2. 根据工程创建向导，在**OpenHarmony** 页签，选择“Empty Ability”模板，单击**Next** 。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113451.47306870472638821396668378358012:50001231000000:2800:E59693B16BB3FBA0261F160CE6D996BA4CE34006C44F5187138463AB0E531438.png?needInitFileName=true?needInitFileName=true)

     3. 单击**Next** ，各个参数保持默认值即可，单击**Finish** ，关于各个参数的详细介绍，请参考[创建和配置新工程](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/ohos-create-new-project-0000001263280423#section7599145817329)。

#### 运行Hello World

     1. 将搭载OpenHarmony标准系统的开发板与电脑连接。
     2. 单击**File**** > ****Project Structure > ****Project > Signing****Configs** 界面勾选“**Automatically generate signature** ”，等待自动签名完成即可，单击**OK** 。如下图所示：
