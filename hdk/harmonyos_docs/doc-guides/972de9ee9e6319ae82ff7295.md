# 概述

Complication是一种可视化交互组件，用于在表盘上展示复杂数据，如步数、心率、天气等各类丰富多样的数据。用户不仅可以在表盘上查看各类数据，了解数据的动态变化，还可以点击Complication组件快速访问应用。Complication组件的样式如图所示。

**图1** Complication组件  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113857.43991945563657683719739680554762:50001231000000:2800:E9FD4052D223B904626DFDF9F76C5E632A3491518F52CDB55FB441D73EAFBF25.png?needInitFileName=true?needInitFileName=true)

应用提供固定格式的数据给表盘，表盘框架根据表盘主题所定义样式和布局将收到的数据渲染显示在表盘上。其具体交互如图所示。

**图2** Complication数据交互框架图

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113857.16054046390259765799631307433142:50001231000000:2800:1C23D00553F5025D1902CB5E7288EB2F4EB42ECAAD65CD1D7EB225BAA77A26E0.png?needInitFileName=true?needInitFileName=true)

     * 表盘：定义样式和布局。
     * 表盘框架：
       * 将三方应用的复杂数据按照表盘定义的样式和布局渲染出来。
       * 实时更新三方应用提供的数据。
       * 表盘上复杂数据自定义配置管理。
     * 三方应用：向表盘注册并更新数据。
