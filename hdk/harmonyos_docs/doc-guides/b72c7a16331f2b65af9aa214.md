# 在Phone和Tablet中运行应用/服务

在Phone和Tablet中运行HarmonyOS应用/服务的操作方法一致，可以采用USB连接方式或者IP Connection的连接方式。采用IP Connection连接方式要求Phone/Tablet和PC端在同一个网段，建议将Phone/Tablet和PC连接到同一个WLAN下。

#### 使用USB连接方式

#### [h2]前提条件

     * 在Phone或者Tablet中，打开“开发者模式”，可在**设置 > 关于手机/关于平板**中，连续多次单击“版本号”，直到提示“您正处于开发者模式”即可。然后在设置的**系统与更新 > 开发人员选项**中，打开**“USB调试”** 开关。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113435.60947281596200570708000002333999:50001231000000:2800:AF5B726711EC3668435726284F8D29FB69F30ECC15FC15ABBEC7A39F74404F07.png?needInitFileName=true?needInitFileName=true)

     * 在Phone或者Tablet中运行应用/服务，需要根据[为应用/服务进行签名](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/ide_debug_device-0000001053822404#section677893315228)章节，提前对应用/服务进行签名。

#### [h2]操作步骤

     1. 使用USB方式，将Phone或者Tablet与PC端进行连接。
     2. 在Phone或者Tablet中，**USB连接方式** 选择“传输文件”。
     3. 在Phone或者Tablet中，会弹出“是否允许USB调试”的弹框，单击**确定** 。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113435.27982320575170088002318413582500:50001231000000:2800:DA3B31B5699BC0884B02C0B71B048E5D1223C6500BDD9F2CDDDDC03288CA9E71.png?needInitFileName=true?needInitFileName=true)

     4. 在菜单栏中，单击**Run >Run'模块名称'**或![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113436.92069398952404848152315981477382:50001231000000:2800:F9FA83FB408323A2C6604178DD6DA87948286E39CBA34C5ED01127A9E3121A73.png?needInitFileName=true?needInitFileName=true)，或使用默认快捷键**Shift+F10** （macOS为**Control+R** ）运行应用/服务。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113436.77831128969239749106043002055465:50001231000000:2800:4123F4FC3AB58A45FF280B4466BB8FC8DF60946C240C387746CE8ADFF90DDB8A.png?needInitFileName=true?needInitFileName=true)

     5. DevEco Studio启动HAP的编译构建和安装。安装成功后，Phone或者Tablet会自动运行安装的HarmonyOS应用/服务。

#### 使用IP Connection连接方式

#### [h2]前提条件

     * 已将Phone/Tablet和PC连接到同一WLAN网络。
     * 已获取Phone/Tablet端的IP地址，可通过**设置 > 关于手机/关于平板 > 状态信息 > IP地址**进行查看。
     * Phone/Tablet上的5555端口为打开状态，默认是关闭状态，可以通过[使用USB连接方式](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/run_phone_tablat-0000001064774652#section198029384419)连接上设备后，执行如下命令打开。
           
           hdc tmode port 5555

     * 在Phone/Tablet中运行应用/服务，需要根据[为应用/服务进行签名](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/ide_debug_device-0000001053822404#section677893315228)章节，提前对应用/服务进行签名。

#### [h2]操作步骤

     1. 在DevEco Studio菜单栏中，单击**Tools >IP Connection**，输入连接设备的IP地址，单击![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113436.07851308263131351080970514130561:50001231000000:2800:6464CFD816304C92F65D5AABB2D24AC3692878024FD8ACB8FF521C3D1C885CD5.png?needInitFileName=true?needInitFileName=true)，连接正常后，设备状态为**online** 。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113436.50073667375256474636283513795645:50001231000000:2800:172867C52259D6649414072F38C06D16B6581545F54F4F47BFAD2DA3FA0FCD63.png?needInitFileName=true?needInitFileName=true)

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612113436.03679244281949229787083714067967:50001231000000:2800:867E7BC62085299ACFC61E97D2AB381E5772F1C979D6406173999D55AFD43650.png?needInitFileName=true?needInitFileName=true)

     3. DevEco Studio启动HAP的编译构建和安装。安装成功后，Phone/Tablet会自动运行安装的HarmonyOS应用/服务。
