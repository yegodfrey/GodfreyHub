# 交互架构

经过前面动态布局的相关学习，相信我们的开发者对折叠屏适配的基本要求已经有了一定的了解，并且能够熟练开发一个简单折叠屏展开态页面。但折叠屏的功能远不止通过正常的动态布局为用户提供连续的体验这么简单。由于折叠屏有着大屏幕的特点，所以还可以为用户提供这样的功能：在大屏幕设备上，同时显示两个页面，增添用户的操作空间，提升用户的操作体验。

那么如何在开发过程中实现上述功能呢？可以通过交互架构的方法来完成。

何为交互架构？当应用之中的两个页面间存在关联关系的时候，可以考虑采用组合页面的方式，在不同场景诉求下，选择合适的页面组合关系展现页面。

交互架构的重点在于选择合适的页面组合关系，而我们能够使用到的页面组合关系有以下三种：层级关系、主从关系、并列关系。

有关这三种关系的具体内容，我们提供了相关链接[交互架构](https://developer.harmonyos.com/cn/docs/design/des-guides/page-composition-architecture-0000001193424988)供参考学习。
