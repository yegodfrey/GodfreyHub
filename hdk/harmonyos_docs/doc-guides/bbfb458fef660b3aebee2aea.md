# 语音播报开发概述

语音播报（Text to Speech，下文简称TTS），基于华为智慧引擎（HUAWEI HiAI Engine）中的语音播报引擎，向开发者提供人工智能应用层API。该技术提供将文本转换为语音并进行播报的能力。

#### 约束与限制

     * 支持超长文本播报，最大文本长度为100000个字符。
     * 语音播报不支持多线程调用。
