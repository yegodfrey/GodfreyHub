# 内外屏接续场景适配

随着服务卡片逐渐增多，卡片对从外屏跳转到内屏的业务诉求逐渐增多。本节将结合卡片分类，介绍相关适配方法。 根据Java卡片（继承Ability）不支持自定义点击事件，JS卡片（继承AceAbility）支持自定义点击事件，接续适配分为两类，每类接续均需要两步：

     1. 外屏启动应用ability。
     2. 外屏刷新提示界面。

#### JS卡片适配方法

外屏启动应用ability ，这里需要给JS卡片其中一个控件设置Message自定义点击事件，示例代码如下：
    
    <!-- 跳转至二级界面 -->
    <div style="width: 100%;" grab:click="bail_travel_info" accessibilityimportance="no">
     
    </div>
    
    "bali_travel_info":{
            "action": "message",
            "params":{
                "message":"openPage",
                "page":"pages/home/home",
                "dimension":"2",
                "showFlight":"{{showFlight}}",
                "hasJourney":"{{hasJourney}}"
            }
        },

再在onTriggerFormEvent中回调处理Message信息，处理方法，如下图：
    
    @Override
        protected void onTriggerFormEvent(Ability ability,long formId,String message){
            LogUtil.info(TAG,"onTriggerFormEvent: " + formId + "message: " + message);
            //启动FA
            IntentParams intentParams = new IntentParams();
            intentParams.setParam("params",message);
            BundleUtil.startHmAbility(CommonConstant.PACKAGE_NAME,TARGET_ABILITY,intentParams,ability);
     
            //bali外屏点击跳转，需要跳转外屏提示页面
            displayOpenTip(ability,formId);
        }
     
     
        private void displayOpenTip(Ability ability,long formId){
          isBaliExtendScreenOpenTip = true;
          updateFormData(formId,ability);
            Timer timer=new Timer();
            timer.schedule(()->{
                isBaliExtendScreenOpenTip = false;
                updateFormData(formId,ability);
                timer.cancel();
            },3000);
        }

最后提醒界面延迟处理，可在 displayOpenTip 方法中通过定时器Timer 回调updataFormData方法刷新。

#### Bundle名称绑定功能

Huawei Pocket外屏服务卡片命名统一采用卡片的description作为卡片名称，但是内屏服务卡片的description已经取名为“XX快捷模式”，且不可更改，直接显示在外屏并不合适

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230804142212.94736242901846706076386521910747:50001231000000:2800:C81502031B11AA1426082F2C0CDE2896C6EA74F6E178EEEF0C0D2A486B17978B.png?needInitFileName=true?needInitFileName=true)

因此Pocket外屏新增一种bundle名称绑定能力，可将Form的 descipiton 描述替换为bundle名称描述，例如，相机的bundle名称为“相机”，decription为“模式快捷入口”）。

适配方法：在Form卡片自定义 CustomizeDatas 中新增“changeDescription”字段，表示启用该能力（如果配置该公用能力，Pocket外屏的FA的命名替换成“相机”，如果不适配将沿用“模式快捷入口”）
    
    "metaData":{
           "customizeData": [
               {
                   "name":"exteCoverFACard",
                   "value":"com.huawei.codelab.show.myapplication3"
               },
               {
                   "name":"changeDescription",
                   "value":"true"
               },
           ]
       }
