# nonRDA域SDK隐私声明

nonRDA域SDK是由深圳引望智能技术有限公司（以下简称"我们"或"引望"）面向应用开发者（以下简称"开发者"）提供北向nonRDA域开放能力及服务。

开发者根据nonRDA域SDK的开发文档和指南在其应用中集成了nonRDA域SDK后，我们将通过被集成的nonRDA域SDK向开发者的最终用户（以下简称"您"或"用户"）提供相关服务，处理开发者应用相关的数据，相关数据中可能包含您的个人信息。引望非常重视您的个人信息和隐私保护，我们将会按照法律要求和业界成熟的安全标准，为您的个人信息提供相应的安全保护措施。我们将通过本声明向您说明我们如何收集、使用、披露、保护、存储及传输您的个人信息。

请注意：**我们要求集成** **nonRDA域 SDK** **的所有开发者严格遵循法律法规、与引望之间的相关协议和** **nonRDA域 SDK** **合规使用指南** **的要求处理您的个人信息；** **在接入、使用各开放能力前，我们要求开发者在其产品应用的隐私政策中向您告知其集成SDK处理个人信息的基本情况，并获取您的同意或取得其他合法性基础。但我们无法控制开发者及其开发者应用如何处理开发者所控制的个人信息，也不对其行为负责。我们建议您认真阅读开发者应用相关用户协议及隐私政策，在确认充分了解并同意开发者如何处理您的个人信息后再使用开发者应用。**

## 我们如何收集和使用您的个人信息

引望仅会根据本声明以下所述目的和方式收集和使用您的个人信息，如果我们要将收集的您的个人信息用于本声明未载明的其他目的，我们会以合理的方式自行或通过开发者明确向您告知，并再次获取您的同意或取得其他合法性基础。如果SDK存在扩展功能或收集和使用了可选个人信息，我们会在下文特别说明。

**设备管理服务**

设备管理服务提供了获取VIN码、SN的接口，调用方通过相关接口可获取到VIN码、SN个人信息。

**车辆控制服务**

车辆控制服务提供获取车辆VIN号的接口，SDK调用方可以通过接口获取到VIN号。

**全景环视舱外相机管理**

全景环视服务提供车外相机获取视频流的通路，SDK调用方通过全景环视SDK可收集车外图像信息。

**视觉感知服务**

提供了疲劳分神检测、表情识别、手势识别、活体识别功能。

**疲劳分神**

疲劳分神，为了提供驾驶员在行驶过程中对驾驶员进行疲劳或分神提醒，SDK会收集开发者应用调用SDK接口的信息。处理的个人信息包括**驾驶员的人脸信息**，其中人脸信息用于模型推理进行疲劳分神检测，以上个人信息均在端侧使用。

**表情识别**

表情识别，为了提供微笑拍照能力，SDK会收集开发者应用调用SDK接口的信息。处理的个人信息包括舱内**所有用户的人脸信息**，其中人脸信息用于模型推理进行微笑抓拍，以上个人信息均在端侧使用。

**手势识别**

手势识别，为了提供手势识别功能，SDK会收集开发者应用调用SDK接口的信息。处理的个人信息包括**舱内图像，捕捉用户置信度最高的手势**，其中舱内图像用于模型推理对手势进行识别，以上个人信息均在端侧使用。

**活体识别**

活体识别，为了提供活体识别功能，SDK会收集开发者应用调用SDK接口的信息。处理的个人信息包括**锁车下电之后、舱内图像**，其中舱内图像信息用于模型推理对遗留物体进行检测，以上个人信息均在端侧使用。

**智慧寻车**

智慧寻车，为了提供智慧寻车功能，SDK会收集开发者应用调用SDK接口的信息。处理的个人信息包括**舱外图像、位置信息**，其中舱外图像信息用于模型推理对停车位号进行检测，位置信息用于模型推理对楼层进行识别，以上个人信息均在端侧使用。

**日志代理服务**

日志代理提供U盘或者Wi-Fi导出日志的能力及服务。处理的个人信息包括硬件序列号（SN）、设备型号，用于生成日志压缩文件名称。以上信息不会上传至服务器，仅在本地处理。

**驾驶出行引擎服务**

为了保证语音控制、仪表/HUD显示的体验，媒体类应用会调用驾驶出行引擎SDK上报用户播放的媒体信息。处理的媒体信息包括**用户播放的** **歌曲名、歌手、播放状态数据**，其中歌曲名、歌手、播放状态用于传输给仪表/HUD等设备显示，播放状态用于记录用户使用习惯以便语音控制时决策使用的媒体应用，以上个人信息均在端侧使用。

**用户中心服务**

用户中心服务提供获取车机账号的用户个人信息的接口，SDK调用方可以通过接口获取到用户账号User ID、用户账号角色、用户账号昵称和用户认证 Token。

## **设备权限调用**

当您使用相应功能及服务时，我们会通过开发者应用向系统申请您设备的相应权限。您可以在设备的设置功能或"隐私设置"中查看权限状态，并可自行选择开启或关闭部分或全部权限。

开发者在集成、使用相应开放能力时，将自行决定权限的调用范围，因此开发者应对权限的调用及用途向您进行说明。您根据开发者应用的请求开启任一权限即代表授权我们可以处理相关个人信息来为您提供对应服务；一旦您关闭任一权限即代表您取消了授权，我们将不再基于对应权限继续处理相关个人信息，可能无法继续为您提供该权限所对应的服务。请注意，您关闭权限的决定不会影响此前基于您授权所进行的个人信息处理活动的效力。
