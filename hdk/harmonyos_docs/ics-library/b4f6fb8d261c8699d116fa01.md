# 座舱互联SDK隐私声明

座舱互联SDK是由深圳引望智能技术有限公司（以下简称"我们"或"引望"）面向应用开发者（以下简称"开发者"）提供的手机与车机间业务流转开放能力及服务。开发者根据座舱互联SDK的开发文档和指南在其应用中集成了座舱互联SDK后，我们将通过被集成的座舱互联SDK向开发者的最终用户（以下简称"您"或"用户"）提供相关服务，处理开发者应用相关的数据，相关数据中可能包含您的个人信息。引望非常重视您的个人信息和隐私保护，我们将会按照法律要求和业界成熟的安全标准，为您的个人信息提供相应的安全保护措施。我们将通过本声明向您说明我们如何收集、使用、披露、保护、存储及传输您的个人信息。

请注意：**我们要求集成** **座舱互联SD** **K** **的所有开发者严格遵循法律法规、与引望之间的相关协议和** **座舱互联SDK合规使用指南** **的要求处理您的个人信息；** **在接入、使用各开放能力前，我们要求开发者在其产品应用的隐私政策中向您告知其集成SDK处理个人信息的基本情况，并获取您的同意或取得其他合法性基础。但我们无法控制开发者及其开发者应用如何处理开发者所控制的个人信息，也不对其行为负责。我们建议您认真阅读开发者应用相关用户协议及隐私政策，在确认充分了解并同意开发者如何处理您的个人信息后再使用开发者应用。**

## 我们如何收集和使用您的个人信息

引望仅会根据本声明以下所述目的和方式收集和使用您的个人信息，如果我们要将收集的您的个人信息用于本声明未载明的其他目的，我们会以合理的方式自行或通过开发者明确向您告知，并再次获取您的同意或取得其他合法性基础。如果SDK存在扩展功能或收集和使用了可选个人信息，我们会在下文特别说明。

**镜像操控**

镜像操控功能提供了在手机侧操作、控制车机后排屏幕的能力。处理的个人信息包括网络信息，用于进行服务搜索发现以及在网络处于关闭时及时给予用户提示。此外座舱互联SDK使用设备信息，包括车机的设备名称、设备ID、BSSID、手机的ODID，车机的BSSID用于搜索近端设备并与其进行连接，设备名称及设备ID用于标识连接的设备，手机的ODID用于车机标识手机。以上信息不会上传至服务器，仅在本地处理。

**遥控器**

遥控器功能提供了在手机触摸板操作、控制车机后排屏幕的能力。处理的个人信息包括网络信息，用于进行服务搜索发现以及在网络处于关闭时及时给予用户提示。此外座舱互联SDK使用设备信息，包括车机的SSID、热点密码、设备ID，车机的SSID、热点密码用于手机连接车机，设备ID用于标识连接的设备。以上信息不会上传至服务器，仅在本地处理。

**手机投屏**

手机投屏功能提供了将手机画面和手机声音投屏至车机屏幕播放的能力。处理的个人信息包括网络信息，用于进行服务搜索发现以及在网络处于关闭时及时给予用户提示。此外座舱互联SDK使用设备信息，包括车机SSID、热点密码、设备ID、屏幕录制内容，车机的SSID、热点密码用于手机连接车机，设备ID用于标识连接的设备，屏幕录制内容用于投屏至车机进行播放。以上信息不会上传至服务器，仅在本地处理。

## **设备权限调用**

当您使用相应功能及服务时，我们会通过开发者应用向系统申请您设备的相应权限。您可以在设备的设置功能或"隐私设置"中查看权限状态，并可自行选择开启或关闭部分或全部权限。

开发者在集成、使用相应开放能力时，将自行决定权限的调用范围，因此开发者应对权限的调用及用途向您进行说明。您根据开发者应用的请求开启任一权限即代表授权我们可以处理相关个人信息来为您提供对应服务；一旦您关闭任一权限即代表您取消了授权，我们将不再基于对应权限继续处理相关个人信息，可能无法继续为您提供该权限所对应的服务。请注意，您关闭权限的决定不会影响此前基于您授权所进行的个人信息处理活动的效力。

|权限|权限描述|使用目的|
|:----------|:--------|:----------------------------------|
|获取蓝牙信息|获取蓝牙名称|获取蓝牙名称作为手机设备名称传递到车机进行显示。|
|获取网络状态权限|获取网络状态|用于检测当前的网络连接是否有效。|
|获取Wi-Fi状态权限|获取Wi-Fi状态|用于获取当前Wi-Fi接入的状态以及WLAN热点的信息。|
|获取附近的设备|获取附近的设备|用于使用蓝牙发现附近的设备并与其进行连接。|
|获取位置权限|获取附近的设备|用于WiFi直连发现附近的设备并与其进行连接，不会获取具体的位置信息。|
|获取相机权限|获取摄像头使用|用于扫码获取车机连接信息并与其进行连接。|
|获取本地网络|获取本地网络信息|用于发现车机服务。|

## 对未成年人的保护

您知悉，本SDK仅面向已合法取得机动车驾驶证的成年人，不向未成年人提供服务。

## 管理您的个人信息

引望非常尊重您对个人信息的关注，我们将遵照相关法律法规的要求，协调、支持并保障您行使访问、复制、更正、删除等个人信息主体权利。

由于您是通过开发者应用使用座舱互联SDK和服务，如果您希望访问、复制或更正与座舱互联SDK和服务相关的个人信息，您应通过开发者应用提供的路径实现您的个人信息主体权利。

为保障您访问、复制、更正和删除个人信息的权利实现，我们在与开发者的协议中，明确要求开发者承诺根据法律法规要求向您提供便捷的权利实现方式。您也可以通过本声明"[如何联系我们](#section865154774115)"章节中所述联系方式与我们取得联系，我们将尽力协调、支持并保障您的上述权利实现。

当您直接向我们提出个人信息主体权利时，为了保障您的数据安全和其他合法权益，我们可能会对您的身份进行验证并要求您提供验证身份所必要的个人信息，同时我们也可能会向开发者提供收集的身份验证信息以核实您的身份。在验证确认您的身份后，我们会根据法律法规要求及时响应您的相关请求。

如您对您的数据主体权利有进一步要求或存在任何疑问、意见或建议，可通过本声明中"[如何联系我们](#section865154774115)"章节中所述方式与我们取得联系，并行使您的相关权利。
