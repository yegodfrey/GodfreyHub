# **1\. Go示例代码介绍**

Golang 示例代码对华为Push的服务端接口进行封装，包含丰富的示例程序，方便开发者参考或直接使用。

Golang 示例代码主要包括以下组成：

包名| 说明  
---|---  
examples| 示例代码，其中每个包可独立运行  
httpclient| 发送网络请求的公共包  
push| Push服务端的接口封装  
  
Golang 示例代码接入前需确认是否安装Golang环境，推荐Golang版本1.11及以上。

解压Golang 示例代码；

将解压后的文件夹中的 org.huawei.com包放入GOPATH路径下或者项目工程的vendor目录；

刷新工程，确保文件出现在GOPATH路径或者vendor目录下；

# **2\. 方法定义说明**

Golang 示例代码以push包中的Client结构体为入口，Client结构体的每一个方法完成了对一个华为Push服务端接口的调用；

Client结构体包括以下方法：

方法名称| 说明  
---|---  
SendMessage| 向设备推送消息  
  
可通过方法” func NewClient(c *Config) (*Client, error)”获取初始化后的Client，其传入参数Config为相关配置。

# 3\. 配置参数说明

使用examples包中提供的功能时，需要先在examples>>common包中的pushclient.go和target.go中配置相关信息。

pushclient.go主要配置以下内容：

配置字段| 说明  
---|---  
appId| 应用的APP ID，从应用信息获取  
appSecret| 应用的SecretKey，从应用信息获取  
authUrl| 华为OAuth2.0服务获取token接口地址，[请参考开放平台鉴权章节3.2客户端密码模式](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/30101#h2-3-2-)  
pushUrl| 华为Push服务访问地址，[请参考服务端发送Push消息API](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/push-sendapi)  
  
target.go主要配置以下内容：

配置字段| 说明  
---|---  
TargetTopic| 需要订阅/退订/查询的主题名称  
TargetCondition| 需要发送的主题组合表达式。  
TargetToken| 需要执行操作的设备的token，从设备获取  
TargetTokenArray| 需要执行操作的所有设备的token集合，从设备获取
