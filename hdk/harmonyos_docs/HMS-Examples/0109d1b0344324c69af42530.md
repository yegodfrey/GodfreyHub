# 1\. Java 示例代码简介

Java示例代码对华为push的服务端接口进行封装，包含丰富的示例程序，方便开发者参考或直接使用。

Java 示例代码主要包括以下组成：

包名| 说明  
---|---  
examples| 示例代码，其中每个包可独立运行  
messaging| Push服务端的接口封装  
  
Push 示例代码接入推荐jdk版本8.0及以上, 推荐IDE为IntelliJ IDEA。

# 2\. Java方法定义说明

Java 示例代码以cmo.huawei.push.javasdk.messaging下HuaweiMessaging类为入口，HuaweiMessaging类的每一个方法完成了对一个华为push服务端接口的调用；

HuaweiMessaging包括以下方法：

方法名称| 说明  
---|---  
sendMessage| 向设备推送消息  
subscribeTopic| 订阅主题  
unsubscribeTopic| 退订主题  
listTopics| 查询某设备订阅的主题列表  
  
# 3\. 配置参数说明

配置名称| 说明  
---|---  
appid| 应用的APP ID，从应用信息获取  
appsecret| 应用的SecretKey，从应用信息获取  
token_server| 华为OAuth2.0服务获取token接口地址，[请参考开放平台鉴权章节3.2客户端密码模式](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/30101#h2-3-2-)  
push_open_url| 华为Push服务访问地址，[请参考服务端发送Push消息API](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/push-sendapi)
