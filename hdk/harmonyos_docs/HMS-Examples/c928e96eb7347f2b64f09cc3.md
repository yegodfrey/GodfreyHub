# **1\. Python示例代码介绍**

Python 示例代码对华为push的服务端接口进行封装，为开发者提供快速接入华为push的示例，包含丰富的示例程序，方便开发者参考或直接使用。

Python 示例代码主要包括以下组成：

包名| 说明  
---|---  
examples| 示例代码，其中每个包可独立运行  
push_admin| Push服务端的接口封装  
  
Push 示例代码接入推荐Python版本2.7及以上, 推荐IDE为JetBrains PyCharm。

# **2\. 方法定义说明**

Python 示例代码以push_admin包中的messaging结构体为入口，messaging结构体的每一个方法完成了对一个华为push服务端接口的调用；

messaging包括以下方法：

方法名称| 说明  
---|---  
send_message| 向设备推送消息  
subscribe_topic| 订阅主题  
unsubscribe_topic| 退订主题  
list_topics| 查询某设备订阅的主题列表  
initialize_app| 初始化配置项  
  
# 3\. 配置参数说明

initialize_app的参数说明如下：

配置名称| 说明  
---|---  
appid| 应用的APP ID，从应用信息获取  
appsecret| 应用的SecretKey，从应用信息获取  
token_server| 华为OAuth2.0服务获取token接口地址，[请参考开放平台鉴权章节3.2客户端密码模式](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/30101#h2-3-2-)  
push_open_url| 华为Push服务访问地址，[请参考服务端发送Push消息API](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/push-sendapi)
