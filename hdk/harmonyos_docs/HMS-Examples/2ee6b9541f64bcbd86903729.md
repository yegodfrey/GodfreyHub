# 1\. 示例代码介绍

Node.js示例代码对华为Push的服务端接口进行封装，包含丰富的示例程序，方便开发者参考或直接使用。

Node.js示例代码主要包括以下组成：

包名| 说明  
---|---  
examples| demo示例代码，可独立运行调用每个接口  
utils| 工具包：公共网络请求及公共校验方法  
push| Push服务端的接口封装  
  
Node.js示例代码接入前应安装node环境。

解压Node.js示例代码；

将获取的源码，进行tsc编译后，放置到工程中使用即可；

# 2\. 方法定义说明

Node.js示例代码以index.ts文件为入口，新new一个对象HcmNamespace，调用对象中的初始化方法进行初始化操作，然后进入不同的方法模块，如消息方法模块和主题方法模块，再调用每一个模块中的方法完成了对一个华为push服务端接口的调用；

HcmNamespace结构体包括以下方法：

方法名称| 说明  
---|---  
init| 初始化操作  
messaging| 在消息方法模块new一个消息对象  
checkInit| 校验初始化参数是否有值  
  
Messaging结构体包括以下方法：

方法名称| 说明  
---|---  
send| 向设备推送消息  
  
# 3\. 配置参数说明

使用examples包中提供的功能时，需要先在examples>>common包中的config.js进行初始化参数配置。

初始化参数配置| 说明  
---|---  
AppId| 应用的APP ID，从应用信息获取  
AppSecret| 应用的SecretKey，从应用信息获取  
AuthUrl| 华为OAuth2.0服务获取token接口地址，[请参考开放平台鉴权章节3.2客户端密码模式](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/30101#h2-3-2-)  
PushUrl| 华为Push服务访问地址，[请参考服务端发送Push消息API](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/push-sendapi)  
请求参数字段配置| 说明  
---|---  
TargetTopic| 需要订阅/退订/查询的主题名称  
TargetCondition| 需要发送的主题组合表达式。  
TargetToken| 发送到的设备Token  
TargetTokenArray| 发送到的多个设备的Token
