# 客户端示例代码

本章节提供[GitHub上示例代码](https://github.com/HMS-Core/hms-sitekit-demo)的链接。

目前提供了SDK for Android的示例代码，它包含了大多数接口的使用方法，您可以在里面找到很多开发指南章节里用到的代码片段。

注意：

如果您将示例代码成功装到了手机上，但查询不到结果，那么您需要配置一个agconnct-services.json文件和签名证书，具体步骤见[开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/hms-site-configuringagc)。
