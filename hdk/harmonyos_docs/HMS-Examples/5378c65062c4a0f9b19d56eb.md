# **1\. 示例代码介绍**

C#示例代码对华为HMS的Push服务接口进行封装，包含丰富的示例程序，方便开发者参考或直接使用。

示例代码主要包括以下文件夹：

文件夹| 说明  
---|---  
src\AGConnectAdmin| 对HMS Push服务封装的类库  
src\AGConnectAdminDemo.Examples| 集成HMS Push服务的一些例子  
  
示例代码工程需要使用Visual Studio 2019以上版本的开发工具打开，类库提供以下种框架版本：

  * .NET Framework 4.5

  * .NET Standard 2.0




1、解压示例代码；

2、将解压后的**dist** 目录复制到你的应用工程中适当的位置，例如<ProjectPath>\Libs，然后在你的应用工程中引用对应的程序集即可。

请按下表选择合适的程序集：

目标框架| 引用程序集  
---|---  
.NET Framework 4.7.1 或更低版本（参考[Cross-platform targeting](https://docs.microsoft.com/en-us/dotnet/standard/library-guidance/cross-platform-targeting)）| dist\net45\AGConnectAdmin.dll  
.NET Framework 4.7.2 或更高版本| dist\netstandard2.0\AGConnectAdmin.dll  
.NET Standard 2.0 或更高版本| dist\netstandard2.0\AGConnectAdmin.dll  
  
# 2\. 类定义说明  


示例代码中的主要的类定义如下：

类名称| 说明  
---|---  
AppOptions| 与开发者应用相关的配置信息  
AGConnectApp| 表示一个开发者应用。  
AGConnectMessaging| 提供Push服务相关接口的调用方法。  
Message| 表示一个推送消息的内容结构体  
  
# 3\. 配置项说明

配置项名称| 说明  
---|---  
ClientId| 应用的APP ID，从应用信息获取  
ClientSecret| 应用的SecretKey，从应用信息获取  
LoginUri| 华为OAuth2.0服务获取Token接口地址，[请参考开放平台鉴权章节3.2客户端密码模式](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/30101#h2-3-2-)  
ApiBaseUri| 华为Push服务接口地址，[请参考服务端发送Push消息API](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/push-sendapi)
