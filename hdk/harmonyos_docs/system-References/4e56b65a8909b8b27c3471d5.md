# OnlyConnect

|Annotation Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public @interface OnlyConnect 请求方法注解类型，设置预建链注解，设置了@OnlyConnect的所有请求只建链，不进行[ResponseBody](https://developer.huawei.com/consumer/cn/doc/system-References/network-httpclient-responsebody-0000001074446287)网络数据交互。|

Java Sample code：

```
@GET
@OnlyConnect
Submit<String> getTestOnlyConnect(@Url String url);
```
