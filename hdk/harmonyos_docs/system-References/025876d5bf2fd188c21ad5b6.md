#### EDDYSTONE_UID_LENGTH

|Fields|
|:--------------------------------------------------------------------------------------------------------------------------------------|
|public static final int EDDYSTONE_UID_LENGTH Eddystone UID的长度，单位：字节。一个Eddystone UID包含10个字节NameSpace，紧接着是6个字节Instance。 Constant Value：16|

#### IBEACON_ID_LENGTH

|Fields|
|:-----------------------------------------------------------------------------------------------------------------------------------|
|public static final int IBEACON_ID_LENGTH iBeacon ID的长度，单位：字节。一个iBeacon ID包含16字节的UUID，紧接着是2个字节Major值，然后是2字节Minor值。 Constant Value：20|
