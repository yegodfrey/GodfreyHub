# IConnectProcess

|Interface Info|
|:----------------------------------------------------|
|public interface IConnectProcess 定义AIDL和HIDL连接信息回调接口。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|void|[sendConnectedInfo](#section8421250144513)([CommonResponse](https://developer.huawei.com/consumer/cn/doc/development/system-References/commonresponse-0000001115529724) response) AIDL和HIDL连接信息回调接口，包括连接信息及AIDL、HIDL接口函数异常调用信息。|

## Public Methods

### sendConnectedInfo

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|void sendConnectedInfo([CommonResponse](https://developer.huawei.com/consumer/cn/doc/development/system-References/commonresponse-0000001115529724) response) AIDL和HIDL连接信息回调接口，包括连接信息及AIDL、HIDL接口函数异常调用信息。|

**Parameters**

|Name|Description|
|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|response|消息响应的数据结构，类型为[CommonResponse](https://developer.huawei.com/consumer/cn/doc/development/system-References/commonresponse-0000001115529724)。 * 当response.[getCode](https://developer.huawei.com/consumer/cn/doc/development/system-References/commonresponse-0000001115529724#section10857203517598)()非0/非200，表示连接异常或者AIDL或者HIDL接口调用异常，异常信息参见response.[getMsg](https://developer.huawei.com/consumer/cn/doc/development/system-References/commonresponse-0000001115529724#section8674184412417)()，错误码具体请参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/system-References/error-code-0000001126788617)。 * 当response.[getCode](https://developer.huawei.com/consumer/cn/doc/development/system-References/commonresponse-0000001115529724#section10857203517598)()为0表示数据有效，表示连接正常以及接口调用正常。 * 当response.[getCode](https://developer.huawei.com/consumer/cn/doc/development/system-References/commonresponse-0000001115529724#section10857203517598)()为200表示数据有效，表示响应数据为FAILURE_EVENT上报。|
