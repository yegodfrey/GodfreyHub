# RawBeaconCondition

|Class Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------|
|public class RawBeaconCondition implements Parcelable 定义信标的过滤条件，只有符合此条件定义的信标会触发通知。 如果有多个过滤条件，不同条件间为逻辑或关系，符合任意一条条件即会触发通知。 注意： 使用此条件，不需要信标在云端注册和配置消息附件。|
