# ModemServiceState

|Class Info|
|:---------------------------------------------------------------------------------|
|public class ModemServiceState implements Parcelable Modem服务状态类型，注册服务后可收到该类型的回调消息。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:--------------------------------------------------|
|int|[getServiceType](#section10857203517598)() 获取服务类型。|
|int|[getState](#section42361481035)() 获取Modem服务状态。|
|int|[getResult](#section8674184412417)() 获取Modem服务注册结果。|

#### Public Methods

#### getServiceType

|Method|
|:------------------------------------------------|
|public int getServiceType() 获取本次回调消息所属的Modem服务类型。|

Returns  

|Type|Description|
|:---|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|int|Modem服务类型，与注册接口使用的服务类型保持一致，具体可见Modem可提供的服务类型[ServiceType](https://developer.huawei.com/consumer/cn/doc/system-References/constant-values-0000001079806248#section178653815568)定义|

#### getState

|Method|
|:----------------------------------|
|public int getState() 获取Modem服务的状态。|

Returns  

|Type|Description|
|:---|:-------------------------------------------|
|int|Modem服务是否可用的状态，0：可用(当getResult() 也为0时)，1：不可用|

#### getResult

|Method|
|:--------------------------------------|
|public int getResult() 获取向Modem注册服务的结果。|

Returns  

|Type|Description|
|:---|:---------------------------------------|
|int|Modem注册服务的结果，0 :成功，3：Modem不支持当前服务，其他：失败。|
