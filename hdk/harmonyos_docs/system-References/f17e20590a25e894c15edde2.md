#### addMdmNumberList

Supported Devices  

|Device Type|OS Version|
|:----------|:---------------------------|
|手机、平板|EMUI 5.1及以上或HarmonyOS 2.0及以上|

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public boolean addMdmNumberList(ComponentName admin, ArrayList\<String\> numbers, int blockMode, boolean isOutgoing, boolean isBlockList) 设置通话黑名单和白名单。如果将号码添加至通话黑名单，设备将拦截此号码的来去电；如果设置了通话白名单，设备将拦截所有非白名单号码的来去电。来电和去电可分开设置，互不影响。 注意： 1. 需要申请com.huawei.permission.sec.MDM_PHONE_MANAGER权限。 2. APK设置numbers累计数量总和不能超过200，否则接口返回false。|

Parameters  

|Name|Description|
|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|admin|调用该接口的组件名称，不能为null。|
|numbers|需要设置的电话号码，传入全数字号码。(上限200)|
|blockMode|号码匹配的可选模式： * 全匹配，黑白名单均适用：DevicePhoneManager.MATCH_ALL_MODE = 0; * 匹配开头，黑白名单均适用：DevicePhoneManager.MATCH_PREFIX_MODE = 1; * 拦截所有号码，黑名单适用：DevicePhoneManager.BLOCK_ALL_MODE = 2； * 允许所有号码，白名单适用：DevicePhoneManager.ALLOW_ALL_MODE = 3； * 其他 int 值非法。|
|isOutgoing|表示设置去电名单或来电名单。取值为"true"表示设置去电黑白名单；取值为"false"表示设置来电黑白名单。|
|isBlackList|表示设置通话黑名单或白名单。取值为"true"表示设置通话黑名单；取值为"false"表示设置通话白名单。 如果设备已设置通话黑名单，则无法再设置通话白名单。必须先调用removeMdmNumberList()接口移除已设置的通话黑名单。 反之，如果设备已设置通话白名单，则无法再设置通话黑名单。必须先调用removeMdmNumberList()接口移除已设置的通话白名单。|

Return  

|Type|Description|
|:------|:-------------------------|
|boolean|* true：配置成功。 * false：配置失败。|

Throws  

|Name|Description|
|:----------------|:----------------------------------------------------------------|
|SecurityException|* 此APK未经设备管理激活。 * 无com.huawei.permission.sec.MDM_PHONE_MANAGER权限。|

如果需要获取通话状态通知结果，开发者需要在你的工程中定义一个广播接收器BroadcastReceiver。在AndroidManifest.xml中指定action为" action.huawei.CALL_STATUS_NOTIFICATION_FOR_MDM "，同时配置exported为false。

如：

```
<receiver
```

在广播接收器中，开发者通过intent获取到Bundle对象，然后从Bundle对象中获取状态值。

Bundle中有以下字段:

boolean is_outgoing: true: 去电 false：来电

boolean is_connected: true:通话接通 false：通话未接通

int who_hang_up: 1: 我方挂断 2：对方挂断 3:其他场景挂断

int disconnected_cause_reason: 通话结束具体原因(有下面几种取值)

1： 本地挂断，如点击挂断按钮挂断电话。

2： 对方挂断。

3 ：来电拒接。

4 ：来电无人接听。

5： 主叫时拒接或无人接听，等待运营商提示后自动挂断。

6： 其他场景异常挂断。

通话状态通知结果字段获取只能通过下面方式:

Bundle. getBoolean("is_outgoing") 参数只能是is_outgoing

Bundle. getBoolean ("is_connected") 参数只能是is_connected

Bundle. getInt("who_hang_up") 参数只能是who_hang_up

Bundle.getInt("disconnected_cause_reason") 参数只能是disconnected_cause_reason

示例代码：

```
public class MdmBroadcastReceiver extends BroadcastReceiver {
    @Override
    public void onReceive(Context context, Intent intent) {
        if (intent == null) {
            return ;
        }
        Bundle bundle = intent.getExtras();
        if (bundle != null) {
            boolean isOutGoing = bundle. getBoolean("is_outgoing");
            boolean isConnected = bundle. getBoolean("is_connected");
            int hungUp = bundle.getInt("who_hang_up");
            int causeReason = bundle.getInt("disconnected_cause_reason ");
            if (causeReason ==1) {
                //业务逻辑处理
            } else {
                //业务逻辑处理
            }
        }
    }
}
```
