## Public Methods

### addQuicHint

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public abstract void addQuicHint(boolean isForce, String... domains) 全局添加支持QUIC协议的域名，只有当显式地配置域名支持QUIC后，才会在协商时使用QUIC，同时需要将[HttpClient.Builder](https://developer.huawei.com/consumer/cn/doc/system-References/network-httpclient-builder-0000001072701879)的QUIC协议开关赋为true。|

**Parameters**

|Name|Description|
|:------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|isForce|是否强制使用QUIC协议。默认值为false。 * true：强制使用QUIC协议，第一次请求就使用QUIC协议，若服务器不支持QUIC协议，则降级至HTTP（HTTP/1.1或HTTP/2）协议。 * false：协商使用QUIC协议，第一次请求用HTTP（HTTP/1.1或HTTP/2）协议，协商成功后使用QUIC协议。|
|domains|需要支持QUIC协议的域名列表。|

### initConnectionPool

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public abstract void initConnectionPool(int maxIdleConnections, long keepAliveDuration, TimeUnit timeUnit) 配置全局连接池最大空闲连接数及空闲连接的保活时间。多次设置时，后设置的参数值需要最大空闲连接数和保活时间同时大于当前值才会生效。|

**Parameters**

|Name|Description|
|:-----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|maxIdleConnections|最大空闲连接数，默认值：8。 当设置参数小于0时，使用默认值。|
|keepAliveDuration|保活时间，默认值：5。 当设置参数小于0时，使用默认值。|
|timeUnit|保活时间的单位，默认值：[TimeUnit](https://developer.android.com/reference/java/util/concurrent/TimeUnit).MINUTES。 * [TimeUnit](https://developer.android.com/reference/java/util/concurrent/TimeUnit).DAYS：时间单位，天，表示24小时。 * [TimeUnit](https://developer.android.com/reference/java/util/concurrent/TimeUnit).HOURS：时间单位，小时，表示60分钟。 * [TimeUnit](https://developer.android.com/reference/java/util/concurrent/TimeUnit).MICROSECONDS：时间单位，微秒，表示千分之一毫秒。 * [TimeUnit](https://developer.android.com/reference/java/util/concurrent/TimeUnit).MILLISECONDS：时间单位，毫秒，表示千分之一秒。 * [TimeUnit](https://developer.android.com/reference/java/util/concurrent/TimeUnit).MINUTES：时间单位，分，表示60秒。 * [TimeUnit](https://developer.android.com/reference/java/util/concurrent/TimeUnit).NANOSECONDS：时间单位，纳秒，表示千分之一微秒。 * [TimeUnit](https://developer.android.com/reference/java/util/concurrent/TimeUnit).SECONDS：时间单位，秒，表示1秒。|
