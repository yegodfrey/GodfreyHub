# DataResponse

|Class Info|
|:------------------------------------------------------------------------------------------|
|public class DataResponse implements Parcelable Modem服务提供的业务相关数据，包含应用查询上报数据以及Modem 主动上报的数据。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-------------------------------------------------|
|int|[getServiceType](#section10857203517598)() 获取服务类型。|
|int|[getSn](#section42361481035)() 获取本次响应对应的请求编号。|
|ArrayList\<Byte\>|[getData](#section8674184412417)() 获取Modem服务响应的数据。|

#### Public Methods

#### getServiceType

|Method|
|:------------------------------------------------|
|public int getServiceType() 获取本次回调消息所属的Modem服务类型。|

Returns  

|Type|Description|
|:---|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|int|Modem服务类型，与注册接口使用的服务类型保持一致，具体可见Modem可提供的服务类型[ServiceType](https://developer.huawei.com/consumer/cn/doc/system-References/constant-values-0000001079806248#section178653815568)定义|

#### getSn

|Method|
|:--------------------------------|
|public int getSn() 获取本次响应对应的请求编号。|

Returns  

|Type|Description|
|:---|:-------------------------|
|int|当应用进行了查询等操作时，获取本次响应对应的请求编号|

#### getData

|Method|
|:-------------------------------------------------|
|public ArrayList\<Byte\> getData() 获取Modem服务响应的数据。|

Returns  

|Type|Description|
|:----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|ArrayList\<Byte\>|Modem服务响应的数据以字节码流形式上报给应用，应用可转换成json 字符串， 弱网信息上报内容转换成字符串后如下所示 { "enterWeakSignalAfterTimeLen":9, // 预计还有多久进入到弱网环境,单位：s "result": 0, // 弱网预测结果，0:成功，否则失败 "weakSignalTimeLen":31 // 预计弱网环境持续多久，单位：s }|
