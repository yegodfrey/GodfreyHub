### setDefaultLauncher

**Supported Devices**

|Device Type|OS Version|
|:----------|:---------------------------|
|手机、平板|EMUI 5.0及以上或HarmonyOS 2.0及以上|
|智慧屏|HarmonyOS 2.0及以上|

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void setDefaultLauncher (ComponentName admin, String packageName, String className) 设置第三方桌面为默认桌面。 注意： 1. 需要申请com.huawei.permission.sec.SDK_LAUNCHER权限。 2. setDefaultLauncher API只能设置使用自签名的桌面应用，即桌面应用程序的签名必须和管控程序的签名一致。 3. 被设置为桌面应用的Activity，需要在AndroidManifest.xml里面声明ACTION_MAIN、CATEGORY_HOME和CATEGORY_DEFAULT属性。 4. 当设备已开机但用户尚未解锁设备时，EMUI 5.0及以上或HarmonyOS 2.0及以上设备将在安全的"直接启动"模式下运行。该模式下只支持设置了directBootAware的应用且无法访问应用私密数据，需要三方桌面应用在组件里设置<activity|provider|receiver|service ... android:directBootAware="true">，并针对应用数据访问进行适配（注意：不能在用户解锁前使用凭据加密(CE)存储数据）： 1. 对于用户解锁前就需要使用的必要数据，务必迁移至设备加密存储，可在用户解锁前通过DeviceProtectedStorageContext进行读取和使用。 2. 对于无法迁移到设备加密存储或用户解锁前非必要的数据，可以通过接收用户解锁通知，在用户解锁后主动获取并使用（监听ACTION_USER_UNLOCKED）。|

**Parameters**

|Name|Description|
|:----------|:----------------------|
|admin|调用该接口的APK的组件名称，不能为null。|
|packageName|要设置的第三方桌面包名，不能为null。|
|className|要设置的第三方桌面类名，不能为null。|

**Return**

|Type|Description|
|:---|:----------|
|void|-|

**Throws**

|Name|Description|
|:-----------------------|:--------------------------------------------------------------------------|
|SecurityException|* 此APK未经设备管理激活。 * 无com.huawei.permission.sec.SDK_LAUNCHER权限。 * 此APK不属于当前用户。|
|IllegalArgumentException|admin、packageName、className至少一个为null。|

### installCertificateWithType

**Supported Devices**

|Device Type|OS Version|
|:----------|:---------------------------|
|手机、平板|EMUI 5.1及以上或HarmonyOS 2.0及以上|

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public boolean installCertificateWithType(ComponentName admin, int type, byte[] certBuffer, String name, String password, int flag, boolean isRequestAccess) 安装用户证书。通过该接口可实现证书的静默安装，无需用户确认。支持PKCS12 和PEM_BASE64 两种证书类型。安装的证书支持VPN_APP和WLAN两种证书用途设置。 注意： 1. 需要申请com.huawei.permission.sec.MDM_DEVICE_MANAGER权限。 2. 安装证书参数flag=0时，安装证书前必须设置锁屏密码。|

**Parameters**

|Name|Description|
|:--------------|:---------------------------------------------------------------------------------|
|admin|调用该接口的组件名称，不能为null。|
|type|安装证书类型，支持 PKCS12，PEM_BASE64。 * CERTIFICATE_PKCS12 = 0 * CERTIFICATE_PEM_BASE64 = 1|
|certBuffer|将证书流文件读入到byte数据，读取pkcs12文件一般设计密码。|
|name|指定安装证书名字。|
|password|证书的密码，提起证书流时的密码，一般pkcs12证书涉及。|
|flag|证书安装用途。 * 1： WLAN用途。 * 0： vpn和应用，安装证书前必须设置锁屏密码。|
|isRequestAccess|是否自动授权 mdm 应用可访问证书。 * true：自动授权。 * false：不自动授权。|

**Return**

|Type|Description|
|:------|:------------------------------------------------------------------------|
|boolean|* true：安装成功（若指定isRequestAccess为true，则证书安装并授权MDM都成功才返回true）。 * false：安装失败。|

**Throws**

|Name|Description|
|:-----------------------|:-----------------------------------------------------------------|
|SecurityException|* 此APK 经设备管理激活。 * 无com.huawei.permission.sec.MDM_DEVICE_MANAGER权限。|
|IllegalArgumentException|参数admin为null。|
