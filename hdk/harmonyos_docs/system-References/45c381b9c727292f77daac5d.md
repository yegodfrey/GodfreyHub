# Permission

|Annotation Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public @interface Permission 定义使用Nearby Message API需要的权限类型。 初始化Nearby Message API时应申请相应的权限，且消息发布[put](https://developer.huawei.com/consumer/cn/doc/development/system-References/messageengine-0000001050130686#ZH-CN_TOPIC_0000001245914897__p5691mcpsimp)、消息获取[get](https://developer.huawei.com/consumer/cn/doc/development/system-References/messageengine-0000001050130686#ZH-CN_TOPIC_0000001245914897__p5732mcpsimp)时的[Policy](https://developer.huawei.com/consumer/cn/doc/development/system-References/message-policy-0000001050132625)应该与申请的权限匹配，否则会导致任务失败。例如，在获取消息任务时设置的[Policy](https://developer.huawei.com/consumer/cn/doc/development/system-References/message-policy-0000001050132625)为[BLE_ONLY](https://developer.huawei.com/consumer/cn/doc/development/system-References/message-policy-0000001050132625#section1373442225715)，但是初始化Nearby Message API时只申请了麦克风权限（[PERMISSION_MICROPHONE](https://developer.huawei.com/consumer/cn/doc/development/system-References/permission-0000001050132623#section2736112514458)），会导致任务失败（收到错误码[STATUS_MESSAGE_MISSING_PERMISSIONS](https://developer.huawei.com/consumer/cn/doc/development/system-References/stauscode-0000001050132575#section18642656103113)）。|
