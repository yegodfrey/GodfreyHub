# 数据模型

## 信标设备结构体

|参数|是否必选|类型|描述|
|:----------|:---|:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------------|
|beaconId|是|String|信标设备的ID，取值范围：0~9和a~f，最长为64个字符。组合规则如下： * iBeacon的beaconId = UUID（16字节）+ Major（2字节）+ Minor（2字节） * Eddystone的beaconId = NameSpace ID（10字节）+ Instance ID（6字节）|
|beaconType|是|int|信标设备的类型，取值范围： * 1：iBeacon * 2：Eddystone-UID|
|beaconDesc|否|String|信标名称，最长为256个字符。|
|placeId|否|String|信标设备的位置信息，最长为256个字符。|
|longitude|否|double|经度，取值范围：[-180.0, +180.0]。|
|latitude|否|double|纬度，取值范围：[-90.0, +90.0]。|
|indoorLevel|否|String|信标设备所在的楼层，最长为64个字符。|
|stability|否|String|信标设备的位置稳定性，取值范围： * Stable * Portable * Mobile * Roving|
|properties|否|String|信标设备的属性，最长为256个字符，且为json格式，每个信标设备最多可配两个属性值，格式如：{key1:value,key2:value}。|
|status|否|int|信标设备的状态，取值范围： * 1：激活状态 * 2：非激活状态 * 3：停用状态 说明 > 注册信标设备和更新信标设备属性的接口不支持传入该字段。|
