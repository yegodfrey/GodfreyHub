# ConnectResult

|Class Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------|
|public final class ConnectResult implements Parcelable 反馈的连接结果，可用于获取连接成功或者失败对应的状态码。如果连接成功，可以通过[getChannelPolicy](#section117015162312)()获取此连接实际的通道策略。|
