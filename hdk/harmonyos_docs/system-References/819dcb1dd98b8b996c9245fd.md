#### getNetworkQoeClient(Activity activity)

|Method|
|:-------------------------------------------------------------------------------------------------|
|public static NetworkQoeClient getNetworkQoeClient(Activity activity) 获取NetworkQoeClient实例，并初始化实例。|

#### getNetworkQoeClient(Context context)

|Method|
|:-----------------------------------------------------------------------------------------------|
|public static NetworkQoeClient getNetworkQoeClient(Context context) 获取NetworkQoeClient实例，并初始化实例。|

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220715180204.24146300056318212268508830325737:50530714111204:2800:143D17EB337E10F2678A84ABFD3F0121AF49381FF35294B73FADD2F7C9EC3D4F.png?needInitFileName=true?needInitFileName=true)  
当传入参数为非Activity类型时，如果使用NetworkQoeClient实例调用Wireless服务接口发生异常，就不会弹出UI交互界面提示用户处理，只会返回错误码。例如：当HMS Core不符合Wireless服务的版本要求时，便会返回错误码907135003，此时需要手动升级HMS Core。如果需要拉起升级引导界面，建议传入Activity类型参数替代Context类型，创建Client实例。
