# Message

|Interface Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class Message implements Parcelable 近场设备间共享的消息类。一条消息由类型、命名空间和消息内容组成。在Nearby Message的场景中，主要存在三种消息：App调用[put](https://developer.huawei.com/consumer/cn/doc/development/system-References/messageengine-0000001050130686#section8851250699)接口发布的消息、Beacon设备BLE广播的原始消息和在开发者联盟项目下配置的Beacon附件消息。 说明： * 类型（type）：用户自定义的一系列消息的标识。 * 命名空间（namespace）：用户自定义的一系列类型消息的标识，一个命名空间下有多种类型的消息。当获取到的消息为App发布的消息或者原始Beacon消息，命名空间为默认值[MESSAGE_NAMESPACE_RESERVED](#section17776152214545)；当获取到的消息为Beacon附件消息，命名空间为开发者联盟项目中配置的命名空间值。 * 消息内容（content）：字节数组，您可以根据需求进行拓展内容，如：通过该content传输自定义json字符串内容，但需注意大小限制为6000B。|
