## Public Methods

### registerCallback

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------|
|boolean registerCallback(Context context, IInteractionResProcess resProcess, IInteractionConnectProcess connectProcess, int appType) 注册回调函数。|

**Parameters**

|Name|Description|
|:-------------|:----------------------------|
|context|App的应用上下文，不可为null。|
|resProcess|Modem交互信息回调接口，不可为null。|
|connectProcess|AIDL和HIDL连接信息回调接口，不可为null。|
|appType|应用类型，不可为null，取值范围可见AppType定义。|

**Return** **s**

|Type|Description|
|:------|:-----------------------------------|
|boolean|注册结果。 * true：表示注册成功。 * false：表示注册失败。|

|Method|
