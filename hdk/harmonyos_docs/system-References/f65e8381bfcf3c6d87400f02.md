# 获取部署策略详情

#### 功能介绍

应用服务器向华为HEM服务器调用该接口获取部署策略详情，用于查看具体的部署策略配置。  

#### 场景描述

开发者查询设备部署策略详情。  

#### 使用约束

无。  

#### 接口原型

|承载协议|HTTPS+POST+JSON|
|接口方向|EMM厂商服务端-\>行业解决方案服务端|
|接口URL|POST https://hemapi-drcn.cloud.huawei.com//hds/v1/customer/emm/profile/get|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|--------------------------------------------------------------------------|

#### 请求参数

|参数名称|类型|必须|长度|描述信息|
|:---|:-----|:-|:-|:---|
|id|String|M|32|策略ID|

#### 响应参数

Response Header  

|参数名称|类型|必须|长度|描述信息|
|:------|:------|:-|:--|:-----|
|rtnCode|Integer|M|11|响应码|
|rtnMsg|String|M|32|响应描述|
|rtnDesc|String|O|255|失败描述|
|result|Profile|O| |部署策略详情|

#### 返回码

|返回值|备注|
|:-------|:-------|
|0|成功|
|85300001|参数不合法|
|85300004|未授权|
|85320001|组织用户不存在|
|85320002|组织用户未认证|
|85320003|组织用户状态异常|
|85320011|部署策略不存在|
