# BeaconPicker

|Class Info|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class BeaconPicker implements Parcelable 定义信标及信标消息附件的过滤条件，当扫描到符合此过滤条件的信标和信标消息附件时，会根据[TriggerOption](https://developer.huawei.com/consumer/cn/doc/development/system-References/beacon-api-triggeroption-0000001507735505)中的通知配置参数触发通知。 如果有多个过滤条件，不同条件间为逻辑或关系，符合任意一条条件即可。|
