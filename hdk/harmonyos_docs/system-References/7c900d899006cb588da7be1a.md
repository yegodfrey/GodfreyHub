# IInteractionResProcess

|Interface Info|
|:-------------------------------------------------------|
|public interface IInteractionResProcess 定义Modem交互信息回调接口。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-------------------------------------------------------------------------------------------------------|
|void|[sendResponse](#section521334419530)(InteractionResponse response) Modem交互信息回调接口，包括正常交互的结果数据以及主动上报的数据信息。|

## Public Methods

### sendResponse

|Method|
|:------------------------------------------------------------------------------------|
|void sendResponse(InteractionResponse response) Modem交互信息回调接口，包括正常交互的结果数据以及主动上报的数据信息。|

**Parameters**

|Name|Description|
|:-------|:--------------------------------------------------------------------------------------------------|
|response|消息响应的数据结构。 * 当response.getResultCode()为非0，表示与Modem交互异常。 * 当response.getResultCode()为0，表示与Modem交互正常。|

## 不同请求与response实例对照表

> 说明
>
> 当请求失败时，response.getResultCode()取值为非0；当请求成功时，请参见如下实例对照表。

|interface|type|description|
|:--------|:--------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|notify|NotifyType.START_SERVICE|通知modem启动通信体验优化服务。 resultCode = 0: 本次notify操作请求成功，modem增强服务已启动，接下来可收到Modem主动上报的业务数据。 responseType = 0: 本次response为请求的结果回复 dataType = -1: 本次response无相关的业务数据返回|
|**--**|**--**|Modem通信体验优化服务启动后，主动上报的业务数据。 responseType = 1: 本次response为Modem主动上报的业务数据。 dataType = 0: 本次response主动上报的为特定json结构的业务数据，例如： ```screen "{"ulRate": 35519, "dlRate": -1, "ulBuffertime": 0}" ``` key值（String类型）和对应含义如下： * *ulRate*：上行空口实时速率，单位字节每秒(byte/s)，int 类型，有效值为非负整数 * *dlRate*：下行空口实时速率，单位字节每秒(byte/s)，int 类型，有效值为非负整数 * *ulBuffertime*：上行数据缓存最大时长，单位毫秒(ms)，int类型，有效值为非负整数|
|**--**|**--**|Modem通信体验优化服务启动后，主动上报的异常数据。 responseType = 1: 本次response为Modem主动上报的业务数据。 dataType = 1: 本次response主动上报的为Modem通信体验优化服务已停止的通知，例如： ```screen "service has already stopped, plz start first to continue" ``` 如果收到该消息，则表示Modem的通信体验优化服务已经停止，您的应用需要重新下发启动服务请求(notify, NotifyType.START_SERVICE)，使Modem通信体验优化服务继续工作，否则您将不能再接收到Modem上报的任何数据。|
|notify|NotifyType.STOP_SERVICE|通知Modem停止通信体验优化服务。 resultCode = 0: 本次notify操作请求成功，Modem通信体验优化服务已停止，Modem不再主动上报业务数据。 responseType = 0: 本次response为请求的结果回复 dataType = -1: 本次response无相关的业务数据返回|
|notify|NotifyType.EXPIRED_DATA_DROP|通知Modem丢弃无效\失效的缓存数据。 resultCode = 0: 本次notify操作请求成功，Modem已清理老旧的缓存数据。 responseType = 0: 本次response为请求的结果回复 dataType = -1: 本次response无相关的业务数据返回 > 说明 > * 当前只有配置了白名单的应用才可以成功下发该操作，非白名单应用调用该接口直接返回失败。|
|notify|NotifyType.MODEM_BUFFER_INFO|通知Modem立刻上报一次业务数据。 resultCode = 0: 本次notify操作请求成功，Modem会立刻上报一条上下行空口速率及Buffer缓存时长数据， 通过IInteractionResProcess回调接口通知给应用。 responseType = 0: 本次response为请求的结果回复 dataType = -1: 本次response无相关的业务数据返回|
|setState|StateType.SET_HIGH_PRIORITY_FILTER_RULE|向Modem设置高优先级发送的数据包过滤规则。 resultCode = 0: 本次setState操作请求成功，Modem会根据设置的过滤规则进行数据包的优先发送。 responseType = 0: 本次response为请求的结果回复 dataType = -1: 本次response无相关的业务数据返回|
|setState|StateType.SET_MODEM_CACHE_THRESHOLD|向Modem设置缓存上报的高低门限。 resultCode = 0: 本次setState操作请求成功，Modem会根据设置的门限进行缓存数据的主动上报。 responseType = 0: 本次response为请求的结果回复 dataType = -1: 本次response无相关的业务数据返回|
