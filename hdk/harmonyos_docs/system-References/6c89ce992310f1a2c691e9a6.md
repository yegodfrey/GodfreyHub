# ICoordResProcess

|Interface Info|
|:-------------------------------------------------------|
|public interface ICoordResProcess 定义Modem 服务消息交互上报的回调接口。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-------------------------------------------------------------------------------------|
|void|[onExceptionReport](#section8421250144513)(ExpResponse response) Modem异常状态上报的回调接口。|
|void|[onCnfReport](#section12564294811)(CnfResponse response) Modem对App下发的请求的响应回调。|
|void|[onDataReport](#section42621300816)(DataResponse response) Modem服务向APP上报的具体业务数据。|
|void|[onStartServiceReport](#section611331887)(ModemServiceState response) Modem的服务状态的回调接口。|

## Public Methods

### onExceptionReport

|Method|
|:-------------------------------------------------------------|
|void onExceptionReport(ExpResponse response) Modem异常状态上报的回调接口。|

**Parameters**

|Name|Description|
|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------|
|response|Modem状态异常的消息响应的数据结构，类型为ExpResponse 。当前仅识别Modem复位异常。 * 当response.getEventType()=1时，表示Modem开始发生复位 * 当response.getEventType()=2时，表示Modem复位完成，此时应用需要**重新注册**服务|

### onCnfReport

|Method|
|:----------------------------------------------------------|
|void onCnfReport(CnfResponse response) Modem对App下发的请求的响应回调。|

**Parameters**

|Name|Description|
|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|response|Modem是否正常接收到本次请求，类型为[CnfResponse](https://developer.huawei.com/consumer/cn/doc/system-References/agentservice_coordiantion_cnfresponse-0000002055867218) 。 * 当response.getResult()=0时，表示Modem成功收到了本次请求的消息，否则表示本次请求异常 * 当response.getResult()=5时，表示请求超时，Modem未收到本次请求，无法响应|

### onDataReport

|Method|
|:-------------------------------------------------------------|
|void onDataReport(DataResponse response) Modem服务向APP上报的具体业务数据。|

**Parameters**

|Name|Description|
|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|response|Modem服务向APP上报的具体业务数据，类型为 [DataResponse](https://developer.huawei.com/consumer/cn/doc/system-References/agentservice_coordiantion_dataresponse-0000002092184481)。 * 收到该回调消息后，可先通过response.getServiceType()确认当前消息所属的服务类型 * 当response.getServiceType()=1时，表示当前消息属于弱网预测服务，此消息为弱网预测结果，需要通过response.getData()得到具体的内容，并转换成字符串，结果示例如下： { "enterWeakSignalAfterTimeLen":9, // 预计还有多久进入到弱网环境,单位：s "result": 0, // 弱网预测结果，0:成功，否则失败 "weakSignalTimeLen":31 // 预计弱网环境持续多久，单位：s }|

### onStartServiceReport

|Method|
|:---------------------------------------------------------------------|
|void onStartServiceReport(ModemServiceState response) Modem的服务状态的回调接口。|

**Parameters**

|Name|Description|
|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|response|Modem的服务状态的回调接口，类型为[ModemServiceState](https://developer.huawei.com/consumer/cn/doc/system-References/agentservice_coordiantion_modemservicestate-0000002056025558)。应用注册服务后，会首先收到该回调消息，通知应用此时Modem的服务是否可用。只有当Modem服务可用时，后续的数据下发和上报才能正常工作。 * 当response.getResult()=0且response.getState()=0时，表示Modem服务正常可用 * 当response.getResult()=3，表示当前手机的Modem不支持应用注册的服务|
