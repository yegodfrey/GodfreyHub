# BleSignal

|Interface Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public interface BleSignal BLE（Bluetooth Low Energy，简称BLE）信号属性。它由RSSI（全称"Received Signal Strength Indicator"，表示接收的信号强度）和TxPower（全称"Transmission Power"，表示距离1m处的发送功率）组成。|

## Public Field Summary

|Qualifier and Type|Field and Description|
|:-----------------|:------------------------------------------------------|
|static final int|[BLE_UNKNOWN_TX_POWER](#section1628820301409) 未知发送功率等级。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:---------------------------------------------------|
|int|[getRssi](#section5299124616254)() 获取接收的信号强度。|
|int|[getTxPower](#section182421737102615)() 获取距离1米的发送功率。|

## Public Fields

### BLE_UNKNOWN_TX_POWER

|Fields|
|:-------------------------------------------------------------------------------|
|public static final int BLE_UNKNOWN_TX_POWER 未知发送功率等级。 Constant Value：0x80000000|

## Public Methods

### getRssi

|Method|
|:-----------------------|
|int getRssi() 获取接收的信号强度。|

**Returns**

|Type|Description|
|:---|:-----------------------------------------------------------------|
|int|返回接收的信号强度，单位：dBm，有效范围：[-127, 127]。该值为加权值，距离越近统计到的强度有更高的权重，信号强度会越大。|

### getTxPower

|Method|
|:----------------------------|
|int getTxPower() 获取距离1米的发送功率。|

**Returns**

|Type|Description|
|:---|:-------------------------------------------------------------------------------------|
|int|返回距离1米的发送功率，单位：dBm。如果无法获取到蓝牙广播器的发送功率时，返回[BLE_UNKNOWN_TX_POWER](#section1628820301409)。|
