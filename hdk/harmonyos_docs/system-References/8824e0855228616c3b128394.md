# 配置消息附件

#### 功能介绍

为信标设备配置消息附件。  

#### 场景描述

创建信标设备后，调用此接口为信标设备配置需要广播的消息附件。  

#### 使用约束

需要获取服务帐号凭证，请参见[基于Service Account开放鉴权](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-service-account-0000001053509221)。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|应用服务器或App应用 -\> 近距离通信服务器|
|接口URL|https://{[域名](https://developer.huawei.com/consumer/cn/doc/development/system-References/common-interface-0000001050151532#section2028854715910)}/WiseCloudNearbyBeaconService/v1/updateAttachment/{beaconId}?projectId=\[projectId\]|
|数据格式|Content-type: application/json|
|-----|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### 路径参数

|参数|是否必选|参数类型|描述|
|:-------|:---|:-----|:-------|
|beaconId|是|String|信标设备的ID。|

#### 查询参数

|参数|是否必选|参数类型|描述|
|:--------|:---|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
|projectId|否|String|获取方式请参见[获取projectId](https://developer.huawei.com/consumer/cn/doc/development/system-References/common-interface-0000001050151532#section4913155719102)。|

#### 请求参数

Request Header  

|参数|是否必选|类型|描述|
|:------------|:---|:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|timeStamp|是|Long|请求头参数，时间戳。|
|srcTranID|是|String|请求头参数，事务ID，最长为24个字符。|
|Authorization|是|String|请求头参数，用于网关认证，请参见[基于Service Account开放鉴权](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-service-account-0000001053509221)获取JWT。|

Request Body  

|参数|是否必选|类型|描述|
|:---------|:---|:-----|:----------------------------------------------------------------------|
|attachment|是|object|消息附件信息，具体参见[消息附件结构体定义](#ZH-CN_TOPIC_0000001201075076__p10709558195711)。|

消息附件结构体定义  

|参数值|类型|是否必选|功能|
|:-----------|:-----|:---|:------------------------------------------|
|attachmentId|String|否|消息附件的ID，配置消息附件时必须为空。|
|namespace|String|是|创建项目时对应的命名空间，最长为32个字符。|
|type|String|是|消息类型，用户自定义，最长为16个字符。|
|value|String|是|消息附件内容，必须为Base64编码，最长为4096个字符，解码后最大为2048字节。|

#### 响应参数

Response Header  

|参数|是否必选|参数类型|描述|
|:-------------|:---|:------|:------------------|
|Content-Type|否|String|上传文件Content-Type。|
|Content-Length|是|Integer|上传文件Content-Length。|

Response Body

状态码为200时：

请求成功，响应体如下。  

|参数|类型|描述|
|:---------|:-----|:--------------------------------------------------------------|
|attachment|object|具体参见[消息附件结构体定义](#ZH-CN_TOPIC_0000001201075076__p9581145412195)。|

消息附件结构体定义  

|参数|类型|功能|
|:-----------|:-----|:-----------------|
|attachmentId|String|消息附件的ID，服务器生成，36位。|
|namespace|String|参数传入时的原始值。|
|type|String|参数传入时的原始值。|
|value|String|参数传入时的原始值。|

状态码为非200时：  
请求失败，响应体如下。

* 非业务（网关校验失败、token过期等情况）请求失败时：  

  |参数|类型|描述|
  |:----|:-----|:----------|
  |error|String|非业务返回的错误信息。|

* 业务请求失败时：  

  |参数|类型|描述|
  |:-----------|:-----|:------------------------------------------------------------------------------------|
  |serviceError|object|业务返回的错误信息。请见下文[serviceError](#ZH-CN_TOPIC_0000001201075076__table20403133123715)详细信息。|

  serviceError  

  |参数|类型|参数含义|
  |:------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------|
  |code|int|错误码，错误码描述见[错误码](https://developer.huawei.com/consumer/cn/doc/development/system-References/login-beacon-0000001050154445#section181310319453)。|
  |status|String|错误状态。|
  |message|String|错误描述信息。|

#### 响应示例

* 使用过期的Authorization进行调用，返回错误的响应体。

  ```
  HTTP/1.1 401
  Content-Type: application/json
  Content-Length: 27

  {
      "error": "session timeout"
  }
  ```

* 业务请求失败时，返回错误的响应体，例如传入一个无效的beaconId。

  ```
  HTTP/1.1 400
  Content-Type: application/json
  Content-Length: 84

  {
      "serviceError": {
          "code": 400000007,
          "message": "Beacon ID aibc3331 is invalid.",
          "status": "Bad Request"
      }
  }
  ```

* 请求成功，返回成功的响应体。

  ```
  HTTP/1.1 200
  Content-Type: application/json
  Content-Length: 143

  {
      "attachment": {
          "namespace": "dev9105385871708487577",
          "attachmentId": "202001141654556730274476060148700160",
          "type": " myType",
          "value": "SGVsbG8gSE1TIQ=="
      }
  }
  ```

#### 错误码

|状态码|错误码|描述|建议业务处理方式|
|:--|:--------|:------------------------|:---------------------------------------------------------------------------------------|
|400|400000001|请求头参数不对。|检查请求头参数。|
|400|400000002|请求体参数不对。|检查请求体参数。|
|400|400000007|beaconId不合法。|请检查beaconId。|
|400|400000009|当前信标设备未激活。|激活当前信标设备。|
|400|400009001|attachmentId不为空。|检查请求体attachmentId字段是否为空。|
|400|400009002|消息附件的value不是合法的Base64字符串。|检查请求体value字段是否为合法Base64字符串。|
|400|400009003|消息附件内容过大。|检查请求体value字段是否超过最大限制2048 byte。|
|400|400009004|已配置的消息附件数量已达到最大限制。|删除不需要的消息附件。|
|403|403000003|服务帐号不可用。|在华为开发者联盟的管理中心可查看服务帐号状态。|
|403|403000004|当前帐号没有权限操作此信标设备。|检查服务帐号是否拥有此信标设备。|
|403|403000005|当前帐号无权限操作此命名空间。|切换为可操作该命名空间的帐号。|
|404|404000006|信标设备不存在。|检查信标设备是否存在，或注册信标设备。|
|500|500000001|内部服务错误。|请选择[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题，华为支持人员会及时处理。|
