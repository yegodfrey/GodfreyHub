# 公共说明

* 采用OAuth 2.0认证。
* 请求参数和返回数据统一采用UTF-8编码。
* 您的服务器端在调用接口时，统一的消息头格式如下：

  |参数|参数类型|是否必选|描述|
  |:------------|:-----|:---|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
  |Content-Type|String|是|取值为：application/json; charset=UTF-8|
  |Authorization|String|是|请参见[基于OAuth 2.0开放鉴权](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides-V5/open-platform-oauth-0000001053629189-V5)。 > 说明 > Bearer后面拼接空格，再拼接获取的access_token。|
  |openId|String|是|最大255。 应用接入华为帐号登录（sign-in）可以获取到OpenId（同一个用户，不同应用，OpenId值不同）。|
  |ts|String|否|请求时间戳timestamp。 参数为1到14位的数字。|
  |i18n|String|否|界面语言： * en_US * zh_CN 默认值：zh_CN 中文。|
