# 取消分配部署策略

#### 功能介绍

应用服务器向华为HEM服务器调用该接口取消分配部署策略到指定设备。  

#### 场景描述

开发者取消分配部署策略到指定设备。  

#### 使用约束

无。  

#### 接口原型

|承载协议|HTTPS+POST+JSON|
|接口方向|EMM厂商服务端-\>行业解决方案服务端|
|接口URL|POST https://hemapi-drcn.cloud.huawei.com/hds/v1/customer/emm/device/profile/unbind|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|-----------------------------------------------------------------------------------|

#### 请求参数

Request Body  

|参数名称|类型|必须|长度|描述信息|
|:------------|:---------|:-|:-|:------|
|profileId|String|M|32|策略ID|
|serialNumbers|String\[\]|M| |设备序列号列表|

#### 响应参数

Response Body  

|参数名称|类型|必须|长度|描述信息|
|:------|:------|:-|:--|:---|
|rtnCode|Integer|M|11|响应码|
|rtnMsg|String|M|32|响应描述|
|rtnDesc|String|O|255|失败描述|

#### 返回码

|返回值|备注|
|:-------|:----|
|0|成功|
|85300001|参数不合法|
|85300004|未授权|
|85320021|设备不存在|

#### 报文样例

|项目|示例|
|:---|:-----------------------------------------------------------------------------|
|请求地址|https://hemapi-drcn.cloud.huawei.com/hds/v1/customer/emm/device/profile/unbind|
|请求报文|{ "serialNumbers": \[ "T6SIF1", "T6SIF2", "T6SIF3" \] }|

|成功响应报文|{ "rtnCode": 0, "rtnMsg": "Success" }|
|失败响应报文|{ "rtnCode": 85320021, "rtnMsg": "Error", "rtnDesc": "device not found!", "result": \[ "T6SIF" \], "totalCount": 1 }|
|------|--------------------------------------------------------------------------------------------------------------------|
