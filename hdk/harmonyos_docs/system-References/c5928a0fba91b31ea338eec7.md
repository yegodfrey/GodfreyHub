#### setScreenCastGrabDisabled

Supported Devices  

|Device Type|OS Version|
|:----------|:---------------|
|智慧屏|HarmonyOS 2.0及以上|

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------|
|public boolean setScreenCastGrabDisabled(ComponentName admin, boolean isDisabled) 禁用/启用投屏抢占。 注意：需要申请com.huawei.permission.sec.MDM_DEVICE_MANAGER权限。|

Parameters  

|Name|Description|
|:---------|:-----------------------------|
|admin|调用该接口的组件名称，不能为null。|
|isDisabled|* true：禁用投屏抢占。 * false：启用投屏抢占。|

Return  

|Type|Description|
|:------|:-------------------------|
|boolean|* true：配置成功。 * false：配置失败。|

Throws  

|Name|Description|
|:-----------------------|:-----------------------------------------------------------------|
|SecurityException|* 此APK未经设备管理激活。 * 无com.huawei.permission.sec.MDM_DEVICE_MANAGER权限。|
|IllegalArgumentException|参数admin为null。|
