# IInteractionConnectProcess

|Interface Info|
|:---------------------------------------------------------------|
|public interface IInteractionConnectProcess 定义AIDL和HIDL连接信息回调接口。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:--------------------------------------------------------------------------------------------|
|void|sendConnectedInfo(InteractionResponse response) AIDL和HIDL连接信息回调接口，包括连接信息及AIDL、HIDL接口函数异常调用信息。|

#### Public Methods

#### sendConnectedInfo

|Method|
|:-------------------------------------------------------------------------------------------------|
|void sendConnectedInfo(InteractionResponse response) AIDL和HIDL连接信息回调接口，包括连接信息及AIDL、HIDL接口函数异常调用信息。|

Parameters  

|Name|Description|
|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
|response|消息响应的数据结构，类型为InteractionResponse。 * 当response.getResultCode()非0，表示连接异常或者AIDL或者HIDL接口调用异常，错误码含义具体请参见错误码。 * 当response.getResultCode()为0表示数据有效，表示连接正常以及接口调用正常。|
