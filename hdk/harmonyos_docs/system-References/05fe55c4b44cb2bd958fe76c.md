# MessageHandler

|Class Info|
|:---------------------------------------------------------------------------------|
|public class MessageHandler 目标消息的回调处理类。在目标消息发现、目标消息丢失及目标消息关联设备的蓝牙信号发生变化或距离发生变化时触发。|

#### onBleSignalChanged

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void onBleSignalChanged([Message](https://developer.huawei.com/consumer/cn/doc/development/system-References/message-message-0000001050132615) message, [BleSignal](https://developer.huawei.com/consumer/cn/doc/development/system-References/blesignal-0000001073839258) bleSignal) 当第一次扫描到Beacon设备时或者检测到扫描到Beacon设备的信号强度等级发生变化（RSSI变化超过10dbm）时此回调函数会被调用。 此回调目前只支持BLE Beacon Message，此回调不支持订阅时用到PendingIntent。|
