# ICoordConnProcess

|Interface Info|
|:--------------------------------------------------------|
|public interface ICoordConnProcess 定义与底层服务的AIDL连接状态的回调接口。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:--------------------------------------------------|
|void|sendConnectedInfo(int response) 底层服务的AIDL连接状态的回调接口。|

## Public Methods

### sendConnectedInfo

|Method|
|:-------------------------------------------------------|
|void sendConnectedInfo(int response) 底层服务的AIDL连接状态的回调接口。|

**Parameters**

|Name|Description|
|:-------|:--------------------------------------------------------------------------------------------------------|
|response|与底层服务的AIDL连接状态。 * 当response为0时，表示AIDL连接正常。 * 当response非0表示与底层服务的AIDL连接异常，接口无法正常调用，数据无法正常下发或上报，可尝试注销后重新注册。|
