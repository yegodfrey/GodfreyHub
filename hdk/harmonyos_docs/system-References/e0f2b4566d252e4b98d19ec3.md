# 获取批次列表

#### 功能介绍

应用服务器向华为HEM服务器调用该接口获取企业设备批次信息。  

#### 场景描述

开发者根据上传类型，获取设备批次列表。  

#### 接口原型

|承载协议|HTTPS+POST+JSON|
|接口方向|EMM厂商服务端-\>行业解决方案服务端|
|接口URL|POST https://hemapi-drcn.cloud.huawei.com/hds/v1/customer/emm/device-batches/get|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|--------------------------------------------------------------------------------|

#### 请求参数

Request Body  

|参数|参数类型|是否必选|长度|描述|
|:--------|:------|:---|:-|:-------------------------------------------------------------------------------------------------------|
|pageNum|Integer|否|11|页码，取值范围：pageNum\>0，默认值1。|
|pageSize|Integer|否|11|单页数量，取值范围 (0，100\]，默认值10。|
|sortBy|String|否|64|取值范围： * projectName：项目名称。 * resellerName：渠道商名称。 * deviceCount：设备数量。 * updatedTime：更新时间。 默认值：updatedTime。|
|sortOrder|String|否|32|取值范围： * desc：降序。 * asc：升序。 默认：desc。|

#### 响应参数

Response Header  

|参数|参数类型|是否必选|描述|
|:-----------|:-----|:---|:----------------------------------|
|Content-Type|String|是|取值为：application/json; charset=UTF-8|

Response Body  

|参数|参数类型|是否必选|长度|描述|
|:---------|:------------------------------------------------------------------------------------------------------------------------------|:---|:--|:----|
|rtnCode|Integer|是|11|响应码。|
|rtnMsg|String|是|32|响应描述。|
|rtnDesc|String|否|255|失败描述。|
|result|[DeviceBatch](https://developer.huawei.com/consumer/cn/doc/development/system-References/metadata-devicebatch-0000001135431419)|是| |批次列表。|
|pageNum|Integer|是|11|页码。|
|pageSize|Integer|是|11|单页数量。|
|totalPages|Integer|是|11|总页数。|
|totalCount|Integer|是|11|总记录数。|

#### 返回码

|返回值|备注|
|:-------|:-------|
|0|成功|
|85300001|参数不合法|
|85300004|未授权|
|85320001|组织用户不存在|
|85320002|组织用户未认证|
|85320003|组织用户状态异常|
