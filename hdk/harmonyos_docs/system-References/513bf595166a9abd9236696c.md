# Policy

|Class Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class Policy implements Parcelable 定义了一系列消息发布（[put](https://developer.huawei.com/consumer/cn/doc/development/system-References/messageengine-0000001050130686#ZH-CN_TOPIC_0000001245914897__p5691mcpsimp)）或消息获取（[get](https://developer.huawei.com/consumer/cn/doc/development/system-References/messageengine-0000001050130686#ZH-CN_TOPIC_0000001245914897__p5732mcpsimp)）的策略。策略由发现模式（FindingMode）和生存时间值（TTL，全称Time To Live）等组成。|
