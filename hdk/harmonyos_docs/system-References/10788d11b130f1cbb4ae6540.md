|:---------------------------------------------------|

|Qualifier and Type|Method Name and Description|

#### Public Methods

#### registerCallback

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------|
|boolean registerCallback(Context context, int serviceType, ICoordResProcess callback, ICoordConnProcess connProcess) 注册Modem的服务（如弱网预测服务）及回调函数。|

Parameters  

|Name|Description|
|:----------|:---------------------------------------|
|context|App的应用上下文，不可为null。|
|serviceType|注册使用的服务类型，当前Modem提供的弱网预测服务 serviceType=1|
|callback|Modem交互信息回调接口，不可为null。|
|connProcess|AIDL和HIDL连接信息回调接口，不可为null。|

Returns  

|Type|Description|
|:------|:------------------------------------------------------------------------------------------------------------|
|boolean|注册结果。 * true：表示注册成功。注意：注册成功不代表服务可用，需要收到onStartServiceReport回调且服务状态正常后，才能正常进行数据交互，如查询、数据下发上报等。 * false：表示注册失败。|

#### unRegisterCallback

|Method|
|:--------------------------------------------------------|
|void unRegisterCallback(int serviceType) 注销Modem的服务及对应回调。|

|Method|
|:------------------------------------------|
|boolean queryWeakSignal(int sn) 查询当前弱网预测信息。|

Parameters  

|Name|Description|

Returns  

|Type|Description|
|:------|:---------------------------------|
|boolean|查询是否成功。 * true：查询成功。 * false：查询失败。|

#### getAidlConnectStatus

|Method|
|:-------------------------------------------|
|boolean getAidlConnectStatus() 获取当前AIDL连接状态。|
