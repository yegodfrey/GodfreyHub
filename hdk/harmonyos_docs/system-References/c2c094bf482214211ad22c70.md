#### Public Methods

#### setVpnDisabled

Supported Devices  

|Device Type|OS Version|
|:----------|:---------------------------|
|手机、平板|EMUI 5.1及以上或HarmonyOS 2.0及以上|

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public boolean setVpnDisabled(ComponentName admin, boolean isDisabled) 设置手机的VPN禁用策略。当禁用手机VPN时，会断掉已经连接的VPN，手机的VPN界面会置灰，不可编辑，同时也不可以通过三方应用连接VPN。当允许使用时，手机的 VPN功能恢复正常。 注意：需要申请com.huawei.permission.sec.MDM_VPN权限。|

Parameters  

|Name|Description|
|:---------|:-----------------------------|
|admin|调用该接口的组件名称，不能为null。|
|isDisabled|* true：禁用VPN。 * false：允许使用VPN。|

Return  

|Type|Description|
|:------|:-------------------------|
|boolean|* true：配置成功。 * false：配置失败。|

Throws  

|Name|Description|
|:-----------------------|:------------------------------------------------------|
|SecurityException|* 此APK未经设备管理激活。 * 无com.huawei.permission.sec.MDM_VPN权限。|
|IllegalArgumentException|参数错误或admin为null。|

#### setVpnProfile

Supported Devices  

|Device Type|OS Version|
|:----------|:---------------------------|
|手机、平板|EMUI 5.1及以上或HarmonyOS 2.0及以上|

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public boolean setVpnProfile(ComponentName admin, DeviceVpnProfile profile) 配置手机中的VPN，配置文件profile中有关键字key来区分各个VPN，若key已存在则修改已配置的VPN，若key不存在则增加一个新的VPN。 注意：需要申请com.huawei.permission.sec.MDM_VPN权限。|

Parameters  

|Name|Description|
|:------|:------------------|
|admin|调用该接口的组件名称，不能为null。|
|profile|存放VPN的配置。|

|DeviceVpnProfile构造方法|说明|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------|
|public DeviceVpnProfile(String key)|传入key构造，其余使用默认值，String类型为""，type为0，mppe 为true。|
|public DeviceVpnProfile(String key, String name, int type, String server,String username, String password, boolean mppe, String l2tpSecret,String ipsecIdentifier, String ipsecSecret, String ipsecUserCert,String ipsecCaCert, String ipsecServerCert)|传入所有的属性的参数。|

|属性类型|属性名称|说明|
|:------|:--------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|String|key|VPN的唯一标识，不可为null，不可为空字符串。|
|String|name|VPN的名称。|
|int|type|VPN 的类型，有效范围 0-6。 * 0：TYPE_PPTP * 1：TYPE_L2TP * 2：TYPE_L2TP_IPSEC_PSK * 3：TYPE_L2TP_IPSEC_RSA * 4：TYPE_IPSEC_XAUTH_PSK * 5：TYPE_IPSEC_XAUTH_RSA * 6：TYPE_IPSEC_HYBRID_RSA|
|String|server|服务器名称。|
|String|username|用户名。|
|String|password|密码。|
|boolean|mppe|PPP加密。|
|String|l2tpSecret|L2TP密钥。|
|String|ipsecIdentifier|IPSec标识符。|
|String|ipsecSecret|IPSec预共享密钥。|
|String|ipsecUserCert|IPSec用户证书。|
|String|ipsecCaCert|IPSec CA证书.|
|String|ipsecServerCert|IPSec 服务器证书。|

Return  

|Type|Description|
|:------|:-------------------------|
|boolean|* true：配置成功。 * false：配置失败。|

Throws  

|Name|Description|
|:-----------------------|:------------------------------------------------------|
|SecurityException|* 此APK未经设备管理激活。 * 无com.huawei.permission.sec.MDM_VPN权限。|
|IllegalArgumentException|参数错误或admin 为null。|

#### getVpnList

Supported Devices  

|Device Type|OS Version|
|:----------|:---------------------------|

|Method|
|:-------------------------------------------------------------------------------|
|public List\<String\> getVpnList(ComponentName admin) 获取手机中的所有的 VPN 的 key 组成的列表。|

Parameters  

|Name|Description|
|:----|:-------------------------------------------------------------------------------------|
|admin|调用该接口的应用的组件名称。参数admin若不为空，则获取的是本应用配置的VPN的key组成的列表；若admin为空则获取的是手机中所有应用配置的VPN的key组成的列表。|
