# MediaType

|Class Info|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public final class MediaType 需要传递的网络数据的Multipurpose Internet Mail Extensions（以下简称MIME）类型。MediaType对象一般包含了三种信息：type、subtype以及charset。通常将这些信息传入[parse](#section1534631411119)方法中，就可以解析出MediaType对象。 例如："text/x-markdown;charset=utf-8"： * "text"为type类型，表示是文本类类型。 * "/"后的"x-markdown"为subtype类型，表示是文本类型下的markdown小类。 * "charset=utf-8"为charset类型，表示采用UTF-8字符集编码。|
