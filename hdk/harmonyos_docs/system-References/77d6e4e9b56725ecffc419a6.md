# HEM SDK接口设计

SDK主要提供激活与去激活以及通知回调接口。

1. 激活： HemLicenseManager.getInstance().activeLicense(String licenseKey)

<!-- -->

1. 去激活： HemLicenseManager.getInstance().deActiveLicense(String licenseKey)

2. 状态回调：

设置状态回调方法

HemLicenseManager.getInstance().setStatusListener(HemLicenseStatusListener listener)

状态回调接口

public interface HemLicenseStatusListener {

void onStatus(int errorCode, int msg);

}

errorCode取值：  

|参数名称|类型|长度|
|:-----------------|:---|:---------|
|INTERNAL_ERROR|1000|内部错误|
|NETWORK_DISCONNECT|1001|网络未连接|
|LICENSE_INVALID|1002|无效的License|
|LICENSE_EXPIRE|1003|License过期|
|ACTIVITE_SUCCESS|2000|激活成功|
|ACTIVITE_FAIL|2001|激活失败|
|DEACTIVITE_SUCESS|3000|去激活成功|
|DEACTIVITE_FAIL|3001|去激活失败|
