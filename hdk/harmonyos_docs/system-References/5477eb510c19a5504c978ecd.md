# MessageEngine

|Class Info|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public abstract class MessageEngine Nearby Message功能的API接口类。可以给您的应用提供近场设备间消息发布、消息获取和信标设备的发现及其附件消息获取功能。 > 说明 > * 使用此API不需要绑定华为帐号，但要求您在华为开发者联盟注册项目、开通近距离通信服务，并申请API KEY，操作请参见[开发准备](https://developer.huawei.com/consumer/cn/doc/development/system-Guides/config-agc-0000001050040578)。 > * 除明确可以在后台使用的接口（如：[get](#section2112412181)()）外，其余所有API接口都必须在应用处于前台时才能调用。put和unput、get和unget应该成对使用。|

### get(MessageHandler handler, GetOption option)

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public abstract [Task](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/task_tresult-0000001050121148)<Void> get([MessageHandler](https://developer.huawei.com/consumer/cn/doc/development/system-References/messagehandler-0000001050132619) handler, [GetOption](https://developer.huawei.com/consumer/cn/doc/development/system-References/getoption-0000001050130682) option) 获取近场设备发布的消息。可获取的消息类型有：近场相同App发布到云端的消息、已经配置到华为云服务的Beacon附件消息以及原始Beacon广播消息。可以通过[GetOption](https://developer.huawei.com/consumer/cn/doc/development/system-References/getoption-0000001050130682)中的[MessagePicker](https://developer.huawei.com/consumer/cn/doc/development/system-References/messagepicker-0000001050130666)参数过滤目标消息。只有在开发者联盟注册的同一项目（[获取projectId](https://developer.huawei.com/consumer/cn/doc/development/system-References/common-interface-0000001050151532#section4913155719102)）下的App发布的消息才能被获取。|

**Parameters**

|Name|Description|
|:------|:-----------------------------------------------------------------------------------------------------------------------------|
|handler|获取到目标消息时的回调处理类。|
|option|本次获取消息过程的[GetOption](https://developer.huawei.com/consumer/cn/doc/development/system-References/getoption-0000001050130682)参数。|

**Returns**

|Type|Description|
|:-----------------------------------------------------------------------------------------------------------------------------|:----------------------------|
|[Task](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/task_tresult-0000001050121148)<Void>|Task封装的API调用结果，应用可注册回调获取结果详情。|

**Sample code：**

```screen
private void subscribe(String namespace, String type, int ttlSeconds, OnCompleteListener<Void> listener,
        GetCallback callback) {
        Policy policy = new Policy.Builder().setTtlSeconds(ttlSeconds).build();
        MessagePicker picker = new MessagePicker.Builder().includeNamespaceType(namespace, type).build();
        GetOption.Builder builder = new GetOption.Builder().setPolicy(policy).setPicker(picker);
        if (callback != null) {
            builder.setCallback(callback);
        }
        Nearby.getMessageEngine(getActivity()).get(mMessageHandler, builder.build()).addOnCompleteListener(listener);
    }
```
