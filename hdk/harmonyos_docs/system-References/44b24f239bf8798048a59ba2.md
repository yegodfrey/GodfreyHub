# DeviceBluetoothManager

|Class Info|
|:--------------------------------------------|
|public class DeviceBluetoothManager 蓝牙相关的管理类。|

|术语解释|||||
|:----------------------------------------|----------------------------------------------------|------------------------------------------------------------------|-----------|------------|
|涉及接口禁止/允许蓝牙设备可被发现模式[setDiscoverableDisabled](#section8672152335317)。 禁止/允许蓝牙设备有限可被发现模式[setLimitedDiscoverableDisabled](#section103962148594)。|||||
|Allow Bluetooth Discoverable Mode|enable||disable||
|Allow Bluetooth Limited Discoverable Mode|enable|disable|enable（不可用）|disable（不可用）|
|最终结果|蓝牙打开时，蓝牙是可被发现（有时间限制，缺省120s）。|蓝牙打开时，蓝牙是可被发现（没有时间限制）。|蓝牙不可被发现。||
|安全性|一般|最差|最高||
|设置菜单的行为表现 注意： 8.X以后版本无此项，不适用。|对应设置菜单的：2分钟超时。与现在默认一样，有开放检测和倒计时。 更多里的检测超时设置：与默认是一样的。|对应设置菜单的：从不超时 有开放检测对附近所有蓝牙设备可见（与用户在设置菜单主动设置为永不超时一致）。 更多里的检测超时设置：置灰。|对应设置菜单的：开放检测都是置灰的。 更多里的检测超时设置：置灰。||

#### Public Methods

#### addBluetoothDevicesToBlockList

Supported Devices  

|Device Type|OS Version|
|:----------|:-------------------------|
|手机、平板|EMUI 11.0或HarmonyOS 2.0及以上|

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public boolean addBluetoothDevicesToBlockList(ComponentName admin, ArrayList\<String\> devices) 配置蓝牙禁止清单，禁止清单上的蓝牙设备将不能被连接。 注意： 1. 需要申请com.huawei.permission.sec.MDM_BLUETOOTH权限。 2. 如果有多个应用设置了蓝牙黑名单，取所有黑名单的合集。 3. 如果某个设备已被添加到蓝牙黑名单，就不能再被任何应用添加至蓝牙白名单。|

Parameters  

|Name|Description|
|:------|:----------------------------------------------------------------------------|
|admin|调用该接口的组件名称。|
|devices|* 蓝牙MAC地址列表。如果列表为空或者列表中的地址不符合MAC地址的格式，则返回false。 * 单个APK的蓝牙黑名单中包含的设备数目不能超过200。|

Return  

|Type|Description|
|:------|:-------------------------|
|boolean|* true：配置成功。 * false：配置失败。|

Throws  

|Name|Description|
|:----------------|:------------------------------------------------------------|
|SecurityException|* 此APK未经设备管理激活。 * 无com.huawei.permission.sec.MDM_BLUETOOTH权限。|
