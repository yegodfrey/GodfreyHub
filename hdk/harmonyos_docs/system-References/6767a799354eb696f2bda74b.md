# NetworkParameters

|Annotation Info|
|:----------------------------------------------------------------|
|public @interface NetworkParameters 请求参数注解类型，设置请求参数配置，格式为JSON字符串。|

**Java Sample code：**

```screen
@GET("https://developer.huawei.com/")
Submit<String> getBaidu(@NetworkParameters String options);
```

|**options**|Description|
|:------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|call_timeout|配置请求超时参数，int类型，单位：ms。默认值为0，请求超时不生效。取值范围为：20≤call_timeout。当您使用全双工模式时不应设置此参数。|
|concurrent_connect_delay|配置复合建链超时参数，int类型，单位：ms。默认值为：500。 * 当[connect_timeout](#ZH-CN_TOPIC_0000002023143954__zh-cn_topic_0000001245131303_p387219395387)小于等于2000时，取值范围为：100≤concurrent_connect_delay≤[connect_timeout](#ZH-CN_TOPIC_0000002023143954__zh-cn_topic_0000001245131303_p387219395387)。 * 当[connect_timeout](#ZH-CN_TOPIC_0000002023143954__zh-cn_topic_0000001245131303_p387219395387)大于2000时，取值范围为：100≤concurrent_connect_delay≤2000。|
|connect_empty_body|配置是否建链和传输数据，boolean类型。默认值为：false。 * true：仅建链，不传输数据 * false：建链并传输数据|
|connect_timeout|配置连接超时参数，int类型，单位：ms。默认值为：10000。 * 当concurrent_connect_delay小于等于1000时，取值范围为：1000≤connect_timeout。 * 当concurrent_connect_delay取值大于1000时。取值范围为：concurrent_connect_delay<connect_timeout。|
|enable_concurrent_connect|配置是否开启复合建链，boolean类型。默认值为：true。 * true：开启复合建链 * false：不开启复合建链|
|ping_interval|配置ping帧探测时间间隔参数，int类型，单位：ms。默认值为：0，ping帧探测特性不生效。取值范围为：0<ping_interval。|
|read_timeout|配置读超时时间参数，int类型，单位：ms。默认值为：10000。取值范围为：0<read_timeout。|
|retry_time|配置请求重试次数参数，重试条件为I/O异常，int类型，单位：次。默认值为：1，一次失败重试。取值范围为：0≤retry_time。|
|write_timeout|配置写超时时间参数，int类型，单位：ms。默认值为：10000。取值范围为：0<write_timeout。|
