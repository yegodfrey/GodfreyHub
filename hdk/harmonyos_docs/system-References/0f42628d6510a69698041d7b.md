## Public Methods

### setSecurityLevel

**Supported Devices**

|Device Type|OS Version|
|:----------|:---------------------------|
|手机、平板|EMUI 5.1及以上或HarmonyOS 2.0及以上|

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public boolean setSecurityLevel(ComponentName admin, int level) 配置WLAN允许连接的热点的最低安全级别。 配置WLAN允许连接的热点安全级别之后，只有达到或高于此级别的热点可以连接，其它的热点都无法连接。安全级别根据WLAN的认证方式定义，认证方式和安全级别的映射关系如下： * SECURITY_LEVEL_1 =1: OPEN * SECURITY_LEVEL_2 =2: WEP * SECURITY_LEVEL_3 =3: WPA * SECURITY_LEVEL_4 =4: LEAP/PWD * SECURITY_LEVEL_5 =5: FAST/PEAP * SECURITY_LEVEL_6 =6: TLS/TTLS/SIM/AKA 注意： 1. 需要申请com.huawei.permission.sec.MDM_WIFI权限。 2. 如果有多个应用设置了该策略，以最后一次策略设置的级别为准。|

**Parameters**

|Name|Description|
|:----|:-----------------------------------------------------|
|admin|调用该接口的组件名称，不能为null。|
|level|允许连接WLAN安全级别，取值范围在SECURITY_LEVEL_1到SECURITY_LEVEL_6之间。|

**Return**

|Type|Description|
|:------|:-------------------------|
|boolean|* true：配置成功。 * false：配置失败。|

**Throws**

|Name|Description|
|:----------------|:-------------------------------------------------------|
|SecurityException|* 此APK未经设备管理激活。 * 无com.huawei.permission.sec.MDM_WIFI权限。|

### getSecurityLevel

**Supported Devices**

|Device Type|OS Version|
|:----------|:---------------------------|
|手机、平板|EMUI 5.1及以上或HarmonyOS 2.0及以上|

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public int getSecurityLevel(ComponentName admin) 获取当前WLAN允许连接的热点的最低安全级别。 配置WLAN允许连接的热点安全级别之后，只有达到或高于此级别的热点可以连接，其他的热点都无法连接。安全级别根据WLAN的认证方式定义，认证方式和安全级别的映射关系如下： * SECURITY_LEVEL_1 : OPEN * SECURITY_LEVEL_2 : WEP * SECURITY_LEVEL_3 : WPA * SECURITY_LEVEL_4 : LEAP/PWD * SECURITY_LEVEL_5 : FAST/PEAP * SECURITY_LEVEL_6 : TLS/TTLS/SIM/AKA|

**Parameters**

|:----|:----------------------------------------------|

**Return**

|Type|Description|
|:---|:--------------------------------------------------|
|int|WLAN允许连接的热点的最低安全级别。如果未配置，则返回默认级别（SECURITY_LEVEL_1）。|
