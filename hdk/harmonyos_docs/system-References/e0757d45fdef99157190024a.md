# Device

|参数名称|类型|必须|长度|描述信息|
|:---------------------|:------|:-|:--|:----------------------------------------------------------------------|
|serialNumber|String|M|32|SN号|
|deviceBatchId|String|M|32|批次ID|
|model|String|O|128|型号|
|hwDpcStatus|String|O|64|HEMDPC部署状态|
|deployStatus|String|O|64|设备部署状态，枚举值： NOT_YET：部署策略已分配 SUCCESS：策略部署成功 CANCEL：用户取消部署 FAILURE：策略部署失败|
|mdmStrategy|String|O|128|Mdm策略|
|profileName|String|O|128|Profile名称|
|projectId|String|M|64|项目id|
|projectName|String|O|128|项目名称|
|createdTime|long|O|32|创建时间|
|isOperatorCancelDeploy|Boolean|O|32|是否是运营取消部署|
|projectDeviceType|Integer|O|11|1.移动设备 2.大屏设备|
|deviceSource|Integer|O|11|设备来源，枚举值： 1：扫码员上传 2：CSV上传 3：第三方同步 4：企业录入|
|activeStatus|Integer|O|11|设备生效状态，枚举值： 1：生效 2：失效|
