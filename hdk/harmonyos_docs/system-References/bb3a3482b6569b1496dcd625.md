# 查询消息附件列表

## 功能介绍

查询信标设备下面所有已配置的消息附件。

## 场景描述

调用此接口查询信标设备下面所有配置的消息附件的信息。

## 使用约束

* 需要获取服务帐号凭证，请参见[基于Service Account开放鉴权](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-service-account-0000001053509221)。
* 信标设备需要处于激活状态。

## 接口原型

|承载协议|HTTPS GET|
|-----|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|接口方向|应用服务器或App应用 -> 近距离通信服务器|
|接口URL|https://{[域名](https://developer.huawei.com/consumer/cn/doc/development/system-References/common-interface-0000001050151532#section2028854715910)}/WiseCloudNearbyBeaconService/v1/queryBeaconAttachment/{beaconId}?projectId=[projectId]|
|数据格式|Content-type: application/json|

## 路径参数

|参数|是否必选|参数类型|描述|
|:-------|:---|:-----|:-------|
|beaconId|是|String|信标设备的ID。|

## 查询参数

|参数|是否必选|参数类型|描述|
|:--------|:---|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
|projectId|否|String|获取方式请参见[获取projectId](https://developer.huawei.com/consumer/cn/doc/development/system-References/common-interface-0000001050151532#section4913155719102)。|

**Request Header**

|参数|是否必选|类型|描述|

|srcTranID|是|String|请求头参数，事务ID，最长为24个字符。|

无

## 响应参数

**Response Header**

|参数|是否必选|参数类型|描述|
|:-------------|:---|:------|:------------------|
|Content-Type|否|String|上传文件Content-Type。|
|Content-Length|是|Integer|上传文件Content-Length。|

**Response Body**

**状态码为200时：**

请求成功，响应体如下。

|参数|类型|描述|
|:----------|:---------|:----------------------------------------------------------------------|
|attachments|Json Array|消息附件结构体的列表，具体参见[消息附件结构体定义](#ZH-CN_TOPIC_0000001201235086__p6444293217)。|

**消息附件** **结构体定义**

```screen
{
    "namespace": "namespace002",
    "attachmentId": "202001191739115580278122214157680128",
    "type": "4",
    "value": "5oiR5piv5Lit5Zu95Lq6qw"
}
```

|参数值|类型|功能|
|:-----------|:-----|:---------------------|
|attachmentId|String|消息附件的ID，配置消息附件时系统自动生成。|
|namespace|String|消息附件对应的命名空间。|
|type|String|消息类型，用户自定义，最长为16个字符。|
|value|String|消息附件内容，base64编码字符串。|

**状态码为非200时：**

请求失败，响应体如下。

* 非业务（网关校验失败、token过期等情况）请求失败时：

  |参数|类型|描述|
  |:----|:-----|:----------|
  |error|String|非业务返回的错误信息。|

* 业务请求失败时：

  |参数|类型|描述|
  |:-----------|:-----|:------------------------------------------------------------------------------------|
  |serviceError|object|业务返回的错误信息。请见下文[serviceError](#ZH-CN_TOPIC_0000001201235086__table20403133123715)详细信息。|

  **serviceError**

  |参数|类型|参数含义|
  |:------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------|
  |code|int|错误码，错误码描述见[错误码](https://developer.huawei.com/consumer/cn/doc/development/system-References/login-beacon-0000001050154445#section181310319453)。|
  |status|String|错误状态。|
  |message|String|错误描述信息。|

## 响应示例

* 使用过期的Authorization进行调用，返回错误的响应体。

  ```screen
  HTTP/1.1 401

  content-length: 27

  {
      error: "session timeout"
  }
  ```

* 业务请求失败时，返回错误的响应体，例如查询一个不存在的信标设备的消息附件列表。

  ```screen
  HTTP/1.1 404
  Content-type: application/json
  content-length: 113

  {
      "serviceError": {
            "code": 404000006,
            "message": "The beacon with ID bea001 does not exist.",
            "status": "Not Found"
      }
  }
  ```


* 请求成功，返回成功的响应体。

  ```screen
  HTTP/1.1 200
  content-length: 78
  Content-Type: application/json;charset=UTF-8

  {
      "attachments": [
          {
              "namespace": "namespace002",
              "attachmentId": "202001191739115580278122214157680128",
              "type": "4",
              "value": "5oiR5piv5Lit5Zu95Lq6qw"
          }
      ]
  }
  ```

|403|403000003|服务帐号不可用。|在华为开发者联盟的管理中心可查看服务帐号状态。|
|403|403000004|没有权限操作此信标设备。|检查服务帐号是否拥有此信标设备。|
|404|404000006|当前信标设备不存在。|检查信标设备是否存在。|
|500|500000001|内部服务错误。|请选择[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题，华为支持人员会及时处理。|
