# BeaconEngine

|Class Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public abstract class BeaconEngine 信标功能的API接口类。可以给您的应用提供近场设备间信标设备的发现及其附件消息获取功能。 说明： * 使用此接口不需要绑定华为帐号，但要求您在华为开发者联盟注册项目、开通近距离通信服务，并申请API KEY，操作请参见[开发准备](https://developer.huawei.com/consumer/cn/doc/development/system-Guides/config-agc-0000001050040578)。 <!-- --> * 接口[registerScanTask](#section37961827165318)和[unRegisterScanTask](#section17117249115318)应该成对使用。|
