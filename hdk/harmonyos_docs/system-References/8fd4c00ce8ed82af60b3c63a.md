## Public Constructors

### HapticSlice

|Constructor|
|:---------------------------------------------------------------------------------------------------------------|
|HapticSlice(int time, int type, int duration, float intensity, float sharpness) 使用时间、波形类型(瞬态或者连续)、时长、强度、锐度来构造对象。|

**Parameters**

|Name|Description|
|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|time|表示波形的时间戳，属性值为int类型，取值范围[0,1800000]，单位为ms，该属性不可缺省。|
|type|表示波形的振动类型，属性值为int类型，该属性不可缺省。在{@link [com.huawei.devices.hapticsengine.HapticChannel](https://developer.huawei.com/consumer/cn/doc/development/system-References/hapticchannel-0000001088782783)}中用整型常量定义了波形的振动类型，例如：用户可通过{@code [HapticChannel.SLICE_TYPE_CONTINUOUS](https://developer.huawei.com/consumer/cn/doc/development/system-References/hapticchannel-0000001088782783#ZH-CN_TOPIC_0000001088782783__section3844134133511)}作为入参，表示振动波形为连续波形。|
|duration|表示波形的振动时长，属性值为int类型，取值范围[0,1800000]，单位为ms。|
|intensity|表示波形的振动强度，属性值为浮点类型，取值范围[0,1]。|
|sharpness|表示波形的振动锐度，属性值为浮点类型，取值范围[0,1]。|
