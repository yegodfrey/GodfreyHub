# IQueryModem

|Interface Info|
|:-----------------------------------------------|
|public interface IQueryModem 定义注册回调、查询以及注销回调的接口。|

|Qualifier and Type|Method Name and Description|
|:-----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|boolean|[registerCallback](#section361141916184)(Context context, [IResProcess](https://developer.huawei.com/consumer/cn/doc/system-References/iresprocess-0000001132456931) resProcess, [IConnectProcess](https://developer.huawei.com/consumer/cn/doc/system-References/iconnectprocess-0000001085514666)connectProcess) 注册回调函数。|

|boolean|[enable](#section13190104404515)(String category) 打开接收某一失败事件信息开关。|
|boolean|[disable](#section18627145254711)(String category) 关闭接收某一失败事件信息开关。|

#### Public Methods

#### registerCallback

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|boolean registerCallback(Context context, [IResProcess](https://developer.huawei.com/consumer/cn/doc/system-References/iresprocess-0000001132456931) resProcess, [IConnectProcess](https://developer.huawei.com/consumer/cn/doc/system-References/iconnectprocess-0000001085514666) connectProcess) 注册回调函数。|

Parameters  

|Name|Description|
|:-------------|:-------------------------|
|context|App的应用上下文，不可为null。|
|resProcess|Modem查询信息回调接口，不可为null。|
|connectProcess|AIDL和HIDL连接信息回调接口，不可为null。|

Returns  

|Type|Description|
|:------|:-----------------------------------|
|boolean|注册结果。 * true：表示注册成功。 * false：表示注册失败。|

|:------------------------------|

#### queryModem

|Method|
|:---------------------------------------------------------------------------------------------------------|
|boolean queryModem(String category) 查询某一指标信息。 指标查询需要App位置android.permission.ACCESS_FINE_LOCATION权限，否则查询失败。|

Parameters  

|Name|Description|
|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|category|查询指标参数。 查询参数详情可参见常量值[Lte](https://developer.huawei.com/consumer/cn/doc/system-References/constant-values-0000001079806248#section32831837192112)、[Nr](https://developer.huawei.com/consumer/cn/doc/system-References/constant-values-0000001079806248#section1335964412278)、[Bearer](https://developer.huawei.com/consumer/cn/doc/system-References/constant-values-0000001079806248#section4586124114311)。 查询结果及格式可参见[queryParameters与value映射表](https://developer.huawei.com/consumer/cn/doc/system-References/iresprocess-0000001132456931#section172381142121416)。|

Returns  

|Type|Description|
|:------|:---------------------------------|
|boolean|查询是否成功。 * true：查询成功。 * false：查询失败。|

#### getAidlConnectStatus

|Method|
|:--------------------------------------------|
|boolean getAidlConnectStatus() 获取您的App当前连接状态。|

Returns  

|Type|Description|
|:------|:------------------------------------------------------------------------------------------------------|
|boolean|获取您的App当前连接状态。 * true：注册[registerCallback](#section361141916184)后AIDL连接成功。 * false：未注册、注册失败或者注册成功后连接断开。|
