# DeviceCameraManager

|Class Info|
|:---------------------------------------|
|public class DeviceCameraManager 相机相关的类。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-------------------------------------------------------------------------------------------|
|boolean|[setVideoDisabled](#section560114556142)(ComponentName admin, boolean isDisabled) 禁用/启用录像功能。|
|boolean|[isVideoDisabled](#section18237152971710)(ComponentName admin) 查询录像功能禁用状态。|

#### Public Methods

#### setVideoDisabled

Supported Devices  

|Device Type|OS Version|
|:----------|:---------------------------|
|手机、平板|EMUI 5.1及以上或HarmonyOS 2.0及以上|

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public boolean setVideoDisabled(ComponentName admin, boolean isDisabled) 禁用/启用录像功能。 注意： 1. 需要申请com.huawei.permission.sec.MDM_CAMERA权限。 2. 该接口仅禁用华为相机的录像功能，三方相机不适用。如果需要禁用相机，请使用原生的禁用相机接口(DevicePolicyManager类的setCameraDisabled接口)。|

Parameters  

|Name|Description|
|:---------|:-------------------------|
|admin|调用该接口的组件名称，不能为null。|
|isDisabled|* true：禁用录像。 * false：启用录像。|

Return  

|Type|Description|
|:------|:-------------------------|
|boolean|* true：配置成功。 * false：配置失败。|

Throws  

|Name|Description|
|:----------------|:---------------------------------------------------------|
|SecurityException|* 此APK未经设备管理激活。 * 无com.huawei.permission.sec.MDM_CAMERA权限。|

#### isVideoDisabled

Supported Devices  

|Device Type|OS Version|
|:----------|:---------------------------|
|手机、平板|EMUI 5.1及以上或HarmonyOS 2.0及以上|

|Method|
|:------------------------------------------------------------------|
|public boolean isVideoDisabled(ComponentName admin) 查询录像功能是否已禁用/启用。|

Parameters  

|Name|Description|
|:----|:----------------------------------------------|
|admin|调用该接口的组件名称，查询该应用配置的策略；参数为null时，获取所有应用设置的综合策略结果。|

Return  

|Type|Description|
|:------|:--------------------------------|
|boolean|* true：录像功能被禁止。 * false：录像功能未被禁止。|
