# 删除设备

#### 功能介绍

应用服务器向华为HEM服务器调用该接口删除指定设备。  

#### 场景描述

开发者调用该接口删除指定设备。  

#### 使用约束

无。  

#### 接口原型

|承载协议|HTTPS+POST+JSON|
|接口方向|EMM厂商服务端-\>行业解决方案服务端|
|接口URL|POST https://hemapi-drcn.cloud.huawei.com/hds/v1/customer/emm/device/delete|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|---------------------------------------------------------------------------|

#### 请求参数

Request Body  

|参数名称|类型|必须|长度|描述信息|
|:------------|:---------|:-|:-|:-----------------------------------------|
|serialNumbers|String\[\]|M| |设备列表。注：横向越权检查，通过openId解析UID，查询UID与SN的绑定关系。|

#### 响应参数

Response Header  

|参数|参数类型|是否必选|描述|
|:-----------|:-----|:---|:----------------------------------|
|Content-Type|String|是|取值为：application/json; charset=UTF-8|

Response Body  

|参数名称|类型|必须|长度|描述信息|
|:------|:----------------------------------------------------------------------------------------------------------------------------------------|:-|:--|:------|
|rtnCode|Integer|M|11|响应码|
|rtnMsg|String|M|32|响应描述|
|rtnDesc|String|O|255|失败描述|
|result|[DeleteDeviceBatch](https://developer.huawei.com/consumer/cn/doc/development/system-References/metadata-devicebatch-0000001135431419)\[\]|M| |删除的批次列表|

#### 返回码

|返回值|备注|
|:-------|:-------|
|0|成功|
|85300001|参数不合法|
|85300004|未授权|
|85320001|组织用户不存在|
|85320002|组织用户未认证|
|85320003|组织用户状态异常|
|85320021|设备不存在|

#### 响应示例

|项目|示例|
|:---|:---------------------------------------------------------------------|
|请求地址|https://hemapi-drcn.cloud.huawei.com/hds/v1/customer/emm/device/delete|
|请求报文|{ "serialNumbers": \["G5YT420A187654567"\] }|

|响应报文|{ "rtnCode": 0, "rtnMsg": "Success", "result": \[\], "totalCount": 0 }|
|异常响应报文|{ "rtnCode":85320021, "rtnMsg": "Error", "rtnDesc": "serialNumber not exists!", }|
|------|---------------------------------------------------------------------------------|
