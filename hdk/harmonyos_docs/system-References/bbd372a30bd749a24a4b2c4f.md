## Public Methods

### add(String line)

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public Headers.Builder add(String line) 添加消息头信息，格式："name:value"，会自动去除"name"和"value"的首尾空格，"name"取值范围为ASCII表中除空格外的所有可显示字符，"value"取值范围为ASCII表中换行符及所有可显示字符。当使用非指定范围内的字符时需与服务端约定使用UTF-8方式进行编码和解码。当传入不符合要求的字符串时，会抛出对应异常。|

**Parameters**

|Name|Description|
|:---|:----------|
|line|待添加的消息头信息。|

**Returns**

|Type|Description|
|:--------------|:--------------------------------------------------------------------------------------------------------------------|
|Headers.Builder|[Headers](https://developer.huawei.com/consumer/cn/doc/system-References/network-common-headers-0000001075725150)构造器。|

### add(String name, String value)

|Method|
|:-------------------------------------------------------------------------------------------------------------------------|
|public Headers.Builder add(String name, String value) 添加消息头信息，当使用非指定范围内的字符时，需与服务端约定使用UTF-8方式进行编码和解码。当传入不符合要求的字符串时，会抛出对应异常。|

**Parameters**

|Name|Description|
|:----|:----------------------------------------------|
|name|消息头信息的"name"，取值范围：ASCII表中除空格外的所有可显示字符。|
|value|消息头信息的"value"，自动去除首尾空格，取值范围：ASCII表中换行符及所有可显示字符。|

**Returns**

|Type|Description|
|:--------------|:--------------------------------------------------------------------------------------------------------------------|
|Headers.Builder|[Headers](https://developer.huawei.com/consumer/cn/doc/system-References/network-common-headers-0000001075725150)构造器。|

### addLenient(String line)

|Method|
|:----------------------------------------------------------------------|
|public Headers.Builder addLenient(String line) 添加消息头信息，格式："name:value"。|

**Parameters**

|Name|Description|
|:---|:---------------------------------------------------------------------------------------------------------------------------------|
|line|待添加的消息头信息。格式："name:value"，转换时会自动去除"value"首尾空格。当传入字符串中不含":"时，"name"值为""，"value"值为字符串的值；当字符串第一个字符为":"时，"name"值为""，"value"值为":"后的字符串。|

**Returns**

|Type|Description|
|:--------------|:--------------------------------------------------------------------------------------------------------------------|
|Headers.Builder|[Headers](https://developer.huawei.com/consumer/cn/doc/system-References/network-common-headers-0000001075725150)构造器。|
