# 说明

|Name|Description|
|:------|:----------------------------------------------------------------------------------------------------------------------------|
|Android|基于Java语言开发的独立Android应用程序接口，提供客户端URL请求及文件上传/下载能力。其中URL请求支持标准HTTP协议缓存、QUIC协议、全双工模式，均需要服务端侧支持对应能力。文件下载使用gzip压缩，同样需要服务端侧支持gzip下载。|
