# 查询信标设备列表

## 功能介绍

查询服务帐号（Service Account）下面所有的信标设备信息。

## 场景描述

调用此接口分页列举出当前开发者帐号下的所有的信标设备信息。

## 使用约束

需要获取服务帐号凭证，请参见[基于Service Account开放鉴权](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-service-account-0000001053509221)。

## 接口原型

|承载协议|HTTPS POST|
|-----|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|接口方向|应用服务器或App应用 -> 近距离通信服务器|
|接口URL|https://{[域名](https://developer.huawei.com/consumer/cn/doc/development/system-References/common-interface-0000001050151532#section2028854715910)}/WiseCloudNearbyBeaconService/v1/queryBeaconList?projectId=[projectId]|
|数据格式|Content-type: application/json|

## 查询参数

|参数|是否必选|参数类型|描述|
|:--------|:---|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
|projectId|否|String|获取方式请参见[获取projectId](https://developer.huawei.com/consumer/cn/doc/development/system-References/common-interface-0000001050151532#section4913155719102)。|

## 请求参数

**Request Header**

|参数|是否必选|类型|描述|
|:------------|:---|:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|timeStamp|是|Long|请求头参数，时间戳。|
|srcTranID|是|String|请求头参数，事务ID，最长为24个字符。|
|Authorization|是|String|请求头参数，用于网关认证，请参见[基于Service Account开放鉴权](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-service-account-0000001053509221)获取JWT。|

**Request Body**

|参数|是否必选|类型|描述|
|:-------|:---|:-----|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|upOrDown|是|int|用于分页查询，1表示向后查询， 2表示向前查询。|
|pageSize|是|int|用于分页查询， 表示一页查询出的信标设备数量（最大值100）。|
|sequence|是|Long|表示信标设备的序号，由注册信标设备时，系统自动生成。 * 如果upOrDown是1，则表示上一页的最后一个信标设备的序号。 * 如果upOrDown是2，则表示上一页的第一个信标设备的序号。|
|status|否|String|0、1组成的字符串，用于匹配特定状态的信标设备进行返回。 从最低位依次往高位推算，第一位表示是否匹配激活状态的信标设备，第二位表示是否匹配去激活状态的信标设备，第三位表示是否匹配停用状态的信标设备。0表示不匹配，1表示匹配。例如：00000001表示匹配激活的信标设备，00000100表示匹配停用的信标设备，00000101表示匹配激活或者停用的信标设备。 此参数不传则默认取00000011，匹配激活或者去激活状态的信标设备，最长为8个字符。|
|property|否|String|key:value键值对，表示信标设备的属性，用于匹配特定属性的信标设备，最长为64个字符。|

## 响应参数

**Response Header**

|参数|是否必选|参数类型|描述|
|:-------------|:---|:------|:------------------|
|Content-Type|否|String|上传文件Content-Type。|
|Content-Length|是|Integer|上传文件Content-Length。|

**Response Body**

**状态码为200时：**

请求成功，响应体如下。

|参数|类型|描述|
|:---------|:---------|:------------------------------------------------------------------------|
|moreBeacon|int|表示是否还要更多的信标设备。 * 1表示还有信标设备，可以再次查询 * 0表示没有更多的信标设备|
|beacons|Json Array|信标设备结构体的列表，具体参见下面[信标设备结构体定义](#ZH-CN_TOPIC_0000001246154911__p6444293217)。|

**信标设备结构体定义：**

```screen
{
    "sequence": 1578643043892,
    "beaconDesc": "beacon1 test",
    "beaconType": 1,
    "beaconId": "beac0025",
    "status": 2
}
```

|参数|类型|描述|
|:---------|:-----|:-----------------------------|
|beaconId|String|信标设备的ID。|
|beaconType|int|信标设备的类型。|
|beaconDesc|String|信标设备的描述。|
|status|int|信标设备的状态： * 1：激活 * 2：去激活 * 3：停用|
|sequence|Long|信标设备的序号。|

**状态码为非200时：**

请求失败，响应体如下。

* 非业务（网关校验失败、token过期等情况）请求失败时：

  |参数|类型|描述|
  |:----|:-----|:----------|
  |error|String|非业务返回的错误信息。|

* 业务请求失败时：

  |参数|类型|描述|
  |:-----------|:-----|:------------------------------------------------------------------------------------|
  |serviceError|object|业务返回的错误信息。请见下文[serviceError](#ZH-CN_TOPIC_0000001246154911__table20403133123715)详细信息。|

  **serviceError**

  |参数|类型|参数含义|
  |:------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------|
  |code|int|错误码，错误码描述见[错误码](https://developer.huawei.com/consumer/cn/doc/development/system-References/login-beacon-0000001050154445#section181310319453)。|
  |status|String|错误状态。|
  |message|String|错误描述信息。|
