# 注册信标设备

#### 功能介绍

注册一个新的信标设备。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230925101416.14373976534742559047645910010990:50001231000000:2800:D829164BF9D5A77C301149BB70FFCB0CCD80EC0AA7C7B51046A34B2E4DF3497D.png?needInitFileName=true?needInitFileName=true)  
仅限企业开发者帐号注册信标设备。  

#### 场景描述

调用此接口注册一个新的信标设备信息。  

#### 使用约束

需要获取服务帐号凭证，请参见[基于Service Account开放鉴权](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-service-account-0000001053509221)。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|应用服务器或App应用 -\> 近距离通信服务器|
|接口URL|https://{[域名](https://developer.huawei.com/consumer/cn/doc/development/system-References/common-interface-0000001050151532#section2028854715910)}/WiseCloudNearbyBeaconService/v1/registerBeacon?projectId=\[projectId\]|
|数据格式|Content-type: application/json|
|-----|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### 查询参数

|参数|是否必选|参数类型|描述|
|:--------|:---|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
|projectId|否|String|获取方式请参见[获取projectId](https://developer.huawei.com/consumer/cn/doc/development/system-References/common-interface-0000001050151532#section4913155719102)。|

#### 请求参数

Request Header  

|参数|是否必选|参数类型|描述|
|:------------|:---|:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|srcTranID|是|String|请求头参数，事务ID，最长为24个字符。|
|timeStamp|是|Long|请求头参数，时间戳。|
|Authorization|是|String|请求头参数，用于网关认证，请参见[基于Service Account开放鉴权](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-service-account-0000001053509221)获取JWT。|

Request Body  

|参数|是否必选|参数类型|描述|
|:-----|:---|:-----|:------------------------------------------------------------------------------------------------------------------------------------|
|beacon|是|object|信标设备的信息，具体参见信标设备[数据模型](https://developer.huawei.com/consumer/cn/doc/development/system-References/common-datamodel-0000001050158333)。|

#### 响应参数

Response Header  

|参数|是否必选|参数类型|描述|
|:-------------|:---|:------|:------------------|
|Content-Type|否|String|上传文件Content-Type。|
|Content-Length|是|Integer|上传文件Content-Length。|

Response Body

状态码为200时：

请求成功，无响应体。

状态码为非200时：  
请求失败，响应体如下。

* 非业务（网关校验失败、token过期等情况）请求失败时：  

  |参数|类型|描述|
  |:----|:-----|:----------|
  |error|String|非业务返回的错误信息。|

* 业务请求失败时：  

  |参数|类型|描述|
  |:-----------|:-----|:------------------------------------------------------------------------------------|
  |serviceError|object|业务返回的错误信息。请见下文[serviceError](#ZH-CN_TOPIC_0000001201395062__table20403133123715)详细信息。|

  serviceError  

  |参数|类型|参数含义|
  |:------|:-----|:-------------------------------------|
  |code|int|错误码，错误码描述见[错误码](#section181310319453)。|
  |status|String|错误状态。|
  |message|String|错误描述信息。|

#### 响应示例

* 使用过期的Authorization进行调用，返回错误的响应体。

  ```
  HTTP/1.1 401 Unauthorized
  Content-type: application/json
  content-length: 27

  {
      "error": "session timeout"
  }
  ```

* 业务请求失败时，返回错误的响应体，例如注册一个已经注册过的信标设备。

  ```
  HTTP/1.1 409 Conflict
  Content-type: application/json
  content-length: 102

  {
      "serviceError": {
          "code": 409001002,
          "message": "The beacon ID has been registered.",
          "status": "Conflict"
      }
  }
  ```

* 请求成功，返回成功的响应体。

  ```
  HTTP/1.1 200 OK
  Content-type: application/json
  content-length: 0
  ```

#### 错误码

|状态码|错误码|描述|建议业务处理方式|
|:--|:--------|:----------------------|:---------------------------------------------------------------------------------------|
|400|400000001|请求头参数不对。|检查请求头参数。|
|400|400000002|请求体参数不对。|检查请求体参数。|
|400|400000006|非法的信标ID前缀。|检查注册的信标ID是否以正确的前缀开始。|
|403|403000003|服务帐号不可用或服务帐号非企业帐号。|在华为开发者联盟的管理中心可查看服务帐号状态。|
|409|409001001|单个子帐号下面最多可创建10000个信标设备。|检查此帐号创建的信标设备数量，建议删除废弃的信标设备信息。|
|409|409001002|信标设备记录已经存在。|检查该信标设备是否已经注册过。|
|409|409001003|信标设备与此帐号的关系信息已经存在。|检查该信标设备是否已经注册过。|
|500|500000001|内部服务错误。|请选择[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题，华为支持人员会及时处理。|
