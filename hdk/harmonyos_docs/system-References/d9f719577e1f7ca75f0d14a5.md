# Data

|Class Info|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class Data implements Parcelable 设备之间进行数据传输的数据类，数据以一个特定的类型（本地文件、传输流、字节消息）发送，接收方也需要以该类型接收。比如，接收stream数据必须通过[asStream](#section146406371551)()返回的InputStream读取。|

### fromFile(File javaFile)

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public static Data fromFile(File javaFile) throws FileNotFoundException 从javaFile创建一个[FILE](https://developer.huawei.com/consumer/cn/doc/development/system-References/data-type-0000001050132603#section181981039201911)类型数据实例。远端收到文件后会以**dataId** 命名且没有文件扩展名，存储在"/Downloads/Nearby"目录下。 应用负责对这个文件重命名，并且添加合适的扩展名。如果有必要，在进行文件传输之前，可以先把文件的全名发送给远端（比如，可以使用[BYTES](https://developer.huawei.com/consumer/cn/doc/development/system-References/data-type-0000001050132603#section8206112311193)进行文件名传输）。 > 注意 > 应用需要授予读取此目录文件的必要权限。|
