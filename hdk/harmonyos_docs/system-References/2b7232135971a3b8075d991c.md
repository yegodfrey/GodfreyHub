#### reportAppQuality

|Method|
|:--------------------------------------------------------------|
|int reportAppQuality(in Bundle data) 应用反馈业务通信质量信息给Wireless Kit。|

Parameters  

|Name|Description|
|:---|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|data|调用者业务通信质量信息。Key值（String类型）和对应解释如下： * eventId：应用异常事件，int类型。 * 1代表"播放卡顿"。 * 2代表"网络异常"。 * 3代表"统计信息"。 * 4代表"视频上传慢"。 * direction：数据传输方向，int类型。 * 1代表"上传"。 * 2代表"下载"。 * netReason：网络相关错误码，String类型。 * "1"代表"IP地址异常"。 * "2"代表"连接关闭"。 * "3"代表"连接拒绝"。 * "4"代表"连接重置"。 * "5"代表"连接超时"。 * "6"代表"主机名未解析"。 * "7"代表"网络断开"。 * "8"代表"网络切换"。 * "9"代表"QUIC协议失败"。 * 如果问题场景不在上述范围内，用户可自己填写其它值。如果String字串由整数构成，整数值需要大于100。 * pkgName：应用包名，String类型。 * version：应用当前版本号，String类型。 * errorTime：异常发生时间，String类型。|

Returns  

|Type|Description|
|:---|:----------------------------|
|int|反馈数据结果。 * 0：反馈成功。 * 其它值：反馈失败。|

Throws  

|Name|Description|
|:--------------|:----------|
|RemoteException|AIDL远程调用异常。|
