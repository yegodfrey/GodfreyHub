#### onState

|Method|
|:------------------------------------------------|
|void onState(int state, int errorCode) 接收播放状态的回调。|

Parameters  

|Name|Description|
|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|state|播放状态的回调。在{@link [com.huawei.devices.hapticsengine.HapticPlayer](https://developer.huawei.com/consumer/cn/doc/development/system-References/hapticplayer-0000001076882430)}中用整型常量定义了播放状态。 * 当回调状态为{@code [HapticPlayer.HAPTIC_STATE_STOPPED](https://developer.huawei.com/consumer/cn/doc/development/system-References/hapticplayer-0000001076882430#ZH-CN_TOPIC_0000001076882430__section540801723412)}时，表示播放停止； <!-- --> * 当回调状态为{@code [HapticPlayer.HAPTIC_STATE_COMPLETED](https://developer.huawei.com/consumer/cn/doc/development/system-References/hapticplayer-0000001076882430#ZH-CN_TOPIC_0000001076882430__section14173195511341)}时，表示播放完成； * 当回调状态为{@code [HapticPlayer.HAPTIC_STATE_ERROR](https://developer.huawei.com/consumer/cn/doc/development/system-References/hapticplayer-0000001076882430#ZH-CN_TOPIC_0000001076882430__section786619517356)}时，表示播放错误。|
|errorCode|播放错误码的回调。 * 当回调状态为{@code [HapticPlayer.HAPTIC_STATE_STOPPED](https://developer.huawei.com/consumer/cn/doc/development/system-References/hapticplayer-0000001076882430#ZH-CN_TOPIC_0000001076882430__section540801723412)}时，表示播放停止，对应的错误码为300； <!-- --> * 当回调状态为{@code [HapticPlayer.HAPTIC_STATE_COMPLETED](https://developer.huawei.com/consumer/cn/doc/development/system-References/hapticplayer-0000001076882430#ZH-CN_TOPIC_0000001076882430__section14173195511341)}时，表示播放完成，对应的错误码为100； * 当回调状态为{@code [HapticPlayer.HAPTIC_STATE_ERROR](https://developer.huawei.com/consumer/cn/doc/development/system-References/hapticplayer-0000001076882430#ZH-CN_TOPIC_0000001076882430__section786619517356)}时，表示播放错误，对应的错误码为500。|
