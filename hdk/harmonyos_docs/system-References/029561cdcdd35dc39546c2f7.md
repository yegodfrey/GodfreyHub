# Overview

提供振动波形播放管理类，例如播放、停止，设置属性，设置动态调节，通道配置，设置动态曲线，设置动态波形等。

## Interface Summary

|Interface|Description|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|:----------|
|[HapticPlayer.OnPlayStateListener](https://developer.huawei.com/consumer/cn/doc/development/system-References/hapticplayer-onplaystatelistener-0000001076881786)|播放状态回调接口。|
