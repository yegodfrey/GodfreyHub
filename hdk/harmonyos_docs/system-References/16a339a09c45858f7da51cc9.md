## Public Methods

### getDualWifiServiceIntent

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public Task<WirelessResult> getDualWifiServiceIntent() 获取双Wi-Fi服务的Intent。用于绑定IDualWifiService。绑定成功后，可以[使用双Wi-Fi提供的服务](https://developer.huawei.com/consumer/cn/doc/development/system-Guides/client-dualwifi-dev-procedure-0000001092981422#section18429957141718)。|

**Returns**

|Type|Description|
|:-------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Task<WirelessResult>|通过[addOnSuccessListener](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/task_tresult-0000001050121148#section947111462618)和[addOnFailureListener](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/task_tresult-0000001050121148#section321517595278)添加监听，然后通过[onSuccess](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/onsuccesslistener-0000001050121140#section32821622269)和[onFailure](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/onfailurelistener-0000001050123093#section32821622269)方法获取任务执行结果。|
