# Overview

|Name|Description|
|:---|:--------------------------------------------------------------------|
|公共说明|介绍服务域名并解释如何获取服务帐号、鉴权凭证及projectId。|
|信标设备|基于低功耗蓝牙（Bluetooth Low Energy，简称BLE）的物理设备，遵循的广播协议有EddyStone和iBeacon两种。|
|消息附件|用户为信标设备在云服务侧自定义的消息内容，可以根据信标设备ID获取。|
|命名空间|一系列信标设备的域名标识，多个信标设备可以属于同一个命名空间。|
|数据模型|Nearby云服务可提供配置管理的信标设备信息。|
