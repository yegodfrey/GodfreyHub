# ChannelPolicy

|Class Info|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public final class ChannelPolicy implements Parcelable 通道策略。用于选择建立连接时所使用的通道。比如选择[CHANNEL_HIGH_THROUGHPUT](#section1960675614920)通道策略，Nearby Connection会使用Wi-Fi直连作为传输通道，提供高吞吐传输服务，此策略适合进行批量图片或视频等大文件的传输业务。|

#### Public Field Summary

|Qualifier and Type|Field and Description|
|:-----------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------|
|static final ChannelPolicy|[CHANNEL_AUTO](#section2850132724920) 自动通道策略。以最快的速度建立连接，提供基础传输能力（通常为基于蓝牙的低速传输通道）。并自动尝试建立Wi-Fi直连的高吞吐传输通道。建立成功后，会把传输任务自动切换到高吞吐传输通道。|
|static final ChannelPolicy|[CHANNEL_HIGH_THROUGHPUT](#section1960675614920) 高吞吐通道策略。建立基于Wi-Fi直连的高吞吐传输通道，提供高吞吐传输能力，此策略适合批量图片或视频等大文件的传输业务。|
|static final ChannelPolicy|[CHANNEL_INSTANCE](#section1682220175504) 即时通道策略。以最快的速度建立连接，提供基础传输能力（通常为基于蓝牙的低速传输通道），后续不会尝试建立Wi-Fi直连的高速通道。此策略适合建立连接耗时短且进行小数据量传输的业务。|
|static final Parcelable.Creator\<ChannelPolicy\>|[CREATOR](#section296210172711) ChannelPolicy对象的构造器。|

#### Public Fields

#### CHANNEL_AUTO

|Fields|
|:-----------------------------------------------------------------------------------------------------------------------------------------|
|public static final ChannelPolicy CHANNEL_AUTO 自动通道策略。以最快的速度建立连接，提供基础传输能力（通常为基于蓝牙的低速传输通道）。并自动尝试建立Wi-Fi直连的高吞吐传输通道。建立成功后，会把传输任务自动切换到高吞吐传输通道。|

#### CHANNEL_HIGH_THROUGHPUT

|Fields|
|:-------------------------------------------------------------------------------------------------------------------------|
|public static final ChannelPolicy CHANNEL_HIGH_THROUGHPUT 高吞吐通道策略。建立基于Wi-Fi直连的高吞吐传输通道，提供高吞吐传输能力，此策略比较适合进行批量图片或视频等大文件的传输业务。|

#### CHANNEL_INSTANCE

|Fields|
|:-------------------------------------------------------------------------------------------------------------------------------------------|
|public static final ChannelPolicy CHANNEL_INSTANCE 即时通道策略。以最快的速度建立连接，提供基础传输能力（通常为基于蓝牙的低速传输通道），后续不会尝试建立Wi-Fi直连的高速通道。此策略适合建立连接耗时短且进行小数据量传输的业务。|
