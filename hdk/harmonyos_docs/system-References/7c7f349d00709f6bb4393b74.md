#### setSuperTrustListForHwSystemManger

Supported Devices  

|Device Type|OS Version|
|:----------|:-------------------------|
|手机、平板|EMUI 11.0或HarmonyOS 2.0及以上|
|智慧屏|HarmonyOS 2.0及以上|

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public boolean setSuperTrustListForHwSystemManger(ComponentName admin, ArrayList\<String\> list) 设置可信任应用列表。 * 1、默认允许显示该应用的通知，用户不可修改。 * 2、禁止用户修改APK的联网权限（包括数据业务和WLAN）； * 3、设置应用为信任应用，允许开启悬浮窗，悬浮窗不需要用户确认，禁止用户取消/修改APK的相关权限。 * 4、接口不具备保活功能。 * 5、默认允许开机自启；允许关联启动；用户不可修改。 * 6、添加白名单后将不允许电池优化。 注意： 1. 需要申请com.huawei.systemmanager.permission.ACCESS_INTERFACE 和com.huawei.permission.sec.MDM_APP_MANAGEMENT权限。 2. 功能2,3从EMUI 9.0.1开始支持。其中禁止用户取消/修改APK的相关权限功能在EMUI 11.0及之后请使用[addRuntimePermissionFixAppList](https://developer.huawei.com/consumer/cn/doc/system-References/deviceapplicationmanager-api-0000001053201926#section1216122323517)接口。 3. 功能5从EMUI 9.0开始支持。 4. 功能6从EMUI 9.0到HarmonyOS2.0支持。 5. 需与接口[addPersistentApp](https://developer.huawei.com/consumer/cn/doc/system-References/deviceapplicationmanager-api-0000001053201926#section25901291716)配合使用。|
