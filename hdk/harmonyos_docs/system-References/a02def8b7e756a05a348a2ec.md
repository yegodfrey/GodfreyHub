#### Public Methods

#### setInfrardDisabled

Supported Devices  

|Device Type|OS Version|
|:----------|:---------------------------|
|手机、平板|EMUI 8.0及以上或HarmonyOS 2.0及以上|

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------|
|public boolean setInfrardDisabled(ComponentName admin, boolean isDisabled) 允许/禁止红外功能。 注意：需要申请com.huawei.permission.sec.MDM_INFRARED权限。|

Parameters  

|Name|Description|
|:---------|:-----------------------------|
|admin|调用该接口的APK的组件名称，不能为null。|
|isDisabled|* true：禁止红外功能。 * false：允许红外功能。|

Return  

|Type|Description|
|:------|:-------------------------|
|boolean|* true：配置成功。 * false：配置失败。|

Throws  

|Name|Description|
|:----------------|:--------------------------------------------------------------------------|
|SecurityException|* 此APK未经设备管理激活。 * 无com.huawei.permission.sec.MDM_INFRARED权限。 * 此APK不属于当前用户。|
