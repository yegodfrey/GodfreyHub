# DeviceLocationManager

|Class Info|
|:-------------------------------------------|
|public class DeviceLocationManager 地理位置相关的类。|

|术语解释|||
|:--------------|----------------------------------------------------|---------------------|
|涉及接口禁止/允许被动定位[allowPassiveLocation](#section837045114119)|||
|PassiveLocation|Enable|Disable|
|最终结果|其他APP获取的位置信息主动上报，定时接受；依赖于三方应用，三方不更新位置信息，自己只有等待；比较省电。|不会接受其他APP定时发送过来的位置信息。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:----------------------------------------------------------------------------------------------|
|boolean|[allowPassiveLocation](#section837045114119)(ComponentName admin, boolean isAllowed) 允许/禁止被动定位。|
|boolean|[getPassiveLocationPolicy](#section72281034183720)(ComponentName admin) 获取被动定位禁止状态。|

## Public Methods

### allowPassiveLocation

**Supported Devices**

|Device Type|OS Version|
|:----------|:---------------------------|
|手机、平板|EMUI 8.0及以上或HarmonyOS 2.0及以上|

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------|
|public boolean allowPassiveLocation(ComponentName admin, boolean isAllowed) 允许/禁止被动定位。 注意：需要申请com.huawei.permission.sec.MDM_LOCATION权限。|

**Parameters**

|Name|Description|
|:--------|:-----------------------------|
|admin|调用该接口的APK的组件名称，不能为null。|
|isAllowed|* true：允许被动定位。 * false：禁止被动定位。|

**Return**

|Type|Description|
|:------|:-------------------------|
|boolean|* true：配置成功。 * false：配置失败。|

**Throws**

|Name|Description|
|:-----------------------|:--------------------------------------------------------------------------|
|SecurityException|* 此APK未经设备管理激活。 * 无com.huawei.permission.sec.MDM_LOCATION权限。 * 此APK不属于当前用户。|
|IllegalArgumentException|admin为null时。|

### getPassiveLocationPolicy

**Supported Devices**

|Device Type|OS Version|
|:----------|:---------------------------|
|手机、平板|EMUI 8.0及以上或HarmonyOS 2.0及以上|

|Method|
|:-----------------------------------------------------------------------|
|public boolean getPassiveLocationPolicy(ComponentName admin) 获取被动定位禁止状态。|

**Parameters**

|Name|Description|
|:----|:----------|
|admin|调用该接口的组件名称。|

**Return**

|Type|Description|
|:------|:-------------------------------|
|boolean|* true：被动定位被禁止。 * false：未禁止被动定位。|

**Throws**

|Name|Description|
|:-----------------------|:-----------------------------|
|SecurityException|* 此APK未经设备管理激活。 * 此APK不属于当前用户。|
|IllegalArgumentException|admin为null时。|
