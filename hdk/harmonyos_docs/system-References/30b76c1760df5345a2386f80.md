#### getParameter

|Method|
|:-----------------------------------------------------|
|public String getParameter(String command) 获得线性马达振动能力。|

Parameters  

|Name|Description|
|:------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
|command|查询等级目前适配了两个参数： * HapticsKitConstant.HW_HAPTIC_DIRECTION_VALUE 查询当前设备支持的线性马达轴向。 <!-- --> * HapticsKitConstant.HW_HAPTIC_GRADE_VALUE 查询当前设备支持的线性马达振动等级。|

Returns  

|Type|Description|
|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|String|* 参数HapticsKitConstant.HW_HAPTIC_DIRECTION_VALUE的返回结果。 * X：设备支持X轴线性马达振动 * Z：设备支持Z轴线性马达振动 * unsupport：当前设备不支持线性马达振动的能力，需要保持原先振动的方式 * 参数HapticsKitConstant.HW_HAPTIC_GRADE_VALUE的返回结果为线性马达振动的能力等级。|
