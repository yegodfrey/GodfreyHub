#### installPackage

Supported Devices  

|Device Type|OS Version|
|:----------|:---------------------------|
|手机、平板|EMUI 4.1及以上或HarmonyOS 2.0及以上|
|智慧屏|HarmonyOS 2.0及以上|

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void installPackage(ComponentName admin, String packagePath) 静默安装某应用。 packagePath为当前APK的路径（包含APK名称），为APK的真实路径。 比如通过如下代码： String packagePath = Environment.getExternalStorageDirectory().getAbsolutePath(); 此时的packagePath为"/storage/emulated/0/\*\*\*.apk" 注意： 1. 需要申请com.huawei.permission.sec.MDM_APP_MANAGEMENT权限。 2. 建议新起线程进行静默安装，以免发生ANR。 3. EMUI 10.0及以上或HarmonyOS 2.0及以上的版本参数packagePath需要使用File Content Provider的格式，并仅限应用数据目录下文件。如 FileProvider.getUriForFile(this,provideName,new File("data/data/packageName/cache/aaaa.apk")).toString(); 而且需要会话授权，允许系统进程访问该文件。如： grantUriPermission("android", contentUri, Intent.FLAG_GRANT_READ_URI_PERMISSION);|

Parameters  

|Name|Description|
|:----------|:------------------------------------|
|admin|调用该接口的APK的组件名称，不能为null。|
|packagePath|当前要安装package的路径，当package为无效路径时，调用无作用。|

Return  

|Type|Description|
|:---|:----------|
|void|-|

Throws  

|Name|Description|
|:-----------------------|:--------------------------------------------------------------------------------|
|SecurityException|* 此APK未经设备管理激活。 * 无com.huawei.permission.sec.MDM_APP_MANAGEMENT权限。 * 此APK不属于当前用户。|
|IllegalArgumentException|admin为null时。|

EMUI 10.1.0及以上或HarmonyOS 2.0及以上的版本如果需要获取静默安装通知结果，开发者需要在工程中定义一个广播接收器BroadcastReceiver。在AndroidManifest.xml中指定action为"com.huawei.intent.action.InstallMdmPackage"，同时配置exported为false。

如：

```
<receiver
    android:name=".MdmBroadcastReceiver_Install"
    android:enabled="true"
    android:exported="false">
    <intent-filter>
        <action android:name="com.huawei.intent.action.InstallMdmPackage" />
    </intent-filter>
</receiver>
```

在广播接收器中，开发者通过intent获取到Bundle对象，然后从Bundle对象中获取静默安装包名和静默安装状态值。

Bundle中有两个字段：

String packageName: 静默安装应用的包名。

int installStatus: 静默安装状态值。有下面几种状态：

* 0 静默安装成功。
* 1 静默安装失败，APK不在MDM安装白名单内。
* 4 静默安装失败，APK覆盖安装过程中签名不匹配。
* 5 静默安装失败，APK物理文件损坏。

静默安装字段获取只能通过下面方式：

Bundle.getString("packageName") 参数只能是packageName

Bundle.getInt("returnCode") 参数只能是returnCode

示例代码：

```
public class MdmBroadcastReceiver_Install extends BroadcastReceiver {
    @Override
    public void onReceive(Context context, Intent intent) {
        if (intent == null) {
            return ;
        }
        Bundle bundle = intent.getExtras();
        if (bundle != null) {
            String packageName = bundle.getString("packageName");
            int returnCode = bundle.getInt("returnCode");
            if (returnCode == 0) { //returnCode=0的时候是静默安装成功
                //业务逻辑处理
            } else { //returncode != 0
                //业务逻辑处理
            }
        } else {
            //具体逻辑实现
        }
    }
}
```

#### disableInstallSource

Supported Devices  

|Device Type|OS Version|
|:----------|:---------------------------|
|手机、平板|EMUI 4.1及以上或HarmonyOS 2.0及以上|

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void disableInstallSource(ComponentName admin, List\<String\> trustList) 添加安装应用源白名单。 本接口会屏蔽安装方式，仅包名添加到trustList列表的应用，有安装其他应用的功能，如某些应用市场。包名不在此list中的应用市场，不能安装应用。同时，调用此方法后，SD卡、adb等安装方式都会不生效。 注意： 1. 需要申请com.huawei.permission.sec.MDM_APP_MANAGEMENT权限。 2. 当前APK设置trustList累计数量总和不能超过200，否则抛出IllegalArgumentException异常。 3. trustList不能包含系统应用。|

Parameters  

|Name|Description|
|:--------|:-------------------------------------------------------------------|
|admin|调用该接口的APK的组件名称，不能为null。|
|trustList|包名List，即仅在此List中的应用能安装应用，如在List加入某应用市场包名，非此List中应用市场、SD卡、adb都不能安装应用。|

Return  

|Type|Description|
|:---|:----------|
|void|-|

Throws  

|Name|Description|
|:-----------------------|:--------------------------------------------------------------------------------|

|IllegalArgumentException|* admin为null。 * trustList为null或empty。 * trustList包含无效包名。 * trustList中包名数量超过200。|
