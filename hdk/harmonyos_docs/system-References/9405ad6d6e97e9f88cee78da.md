# 获取DPC列表

## 功能介绍

应用服务器向华为HEM服务器调用该接口获取EMM厂商上传的DPC APK。

## 场景描述

DPC APK由EMM厂商在华为开发者联盟官网上传，上传时会绑定项目，该接口返回关联企业项目的所有DPC APK。

## 使用约束

无。

## 接口原型

|承载协议|HTTPS+POST+JSON|
|-----|-----------------------------------------------------------------------|
|接口方向|EMM厂商服务端->行业解决方案服务端|
|接口URL|POST https://hemapi-drcn.cloud.huawei.com/hds/v1/customer/emm/dpc/all|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|

## 请求参数

无。

## 响应参数

**Response Header**

|参数|参数类型|是否必选|描述|
|:-----------|:-----|:---|:----------------------------------|
|Content-Type|String|是|取值为：application/json; charset=UTF-8|

**Response Body**

|参数名称|类型|必须|长度|描述信息|
|:------|:----------------------------------------------------------------------------------------------------------------|:-|:--|:------|
|rtnCode|Integer|M|11|响应码|
|rtnMsg|String|M|32|响应描述|
|rtnDesc|String|O|255|失败描述|
|result|[Dpc](https://developer.huawei.com/consumer/cn/doc/development/system-References/metadata-dpc-0000001267204874)[]|M|  |Dpc列表数据|

## 返回码

|返回值|备注|
|:-------|:----|
|0|成功|
|85300001|参数不合法|
|85300004|未授权|
