# DataCallback

|Class Info|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public abstract class DataCallback 数据收发回调事件类。调用[sendData](https://developer.huawei.com/consumer/cn/doc/development/system-References/transferengine-0000001050130658#section10201153764712)(String, [Data](https://developer.huawei.com/consumer/cn/doc/development/system-References/data-0000001050132599))方法后，通过此类监控数据传输的过程。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|abstract void|[onReceived](#section4844134385219)(String endpointId, [Data](https://developer.huawei.com/consumer/cn/doc/development/system-References/data-0000001050132599) data) 给应用回调返回接收的[Data](https://developer.huawei.com/consumer/cn/doc/development/system-References/data-0000001050132599)实例。|
|abstract void|[onTransferUpdate](#section18715435195410)(String endpointId, [TransferStateUpdate](https://developer.huawei.com/consumer/cn/doc/development/system-References/transferstateupdate-0000001050132605) update) 数据收发状态回调。|

## Public Methods

### onReceived

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public abstract void onReceived(String endpointId, [Data](https://developer.huawei.com/consumer/cn/doc/development/system-References/data-0000001050132599) data) 给应用回调返回接收的[Data](https://developer.huawei.com/consumer/cn/doc/development/system-References/data-0000001050132599)实例。 > 注意 > 该方法会在收到对端数据data时进行回调，回调时，数据可能没有接收完成。因此，您需要使用[onTransferUpdate](#section18715435195410)(String, [TransferStateUpdate](https://developer.huawei.com/consumer/cn/doc/development/system-References/transferstateupdate-0000001050132605))回调方法判断数据的接收状态。|

**Parameters**

|Name|Description|
|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|endpointId|远端设备标识。|
|data|[Data](https://developer.huawei.com/consumer/cn/doc/development/system-References/data-0000001050132599)实例，[BYTES](https://developer.huawei.com/consumer/cn/doc/development/system-References/data-type-0000001050132603#section8206112311193)、[FILE](https://developer.huawei.com/consumer/cn/doc/development/system-References/data-type-0000001050132603#section181981039201911)或[STREAM](https://developer.huawei.com/consumer/cn/doc/development/system-References/data-type-0000001050132603#section1613311470194)类型。|

### onTransferUpdate

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public abstract void onTransferUpdate(String endpointId, [TransferStateUpdate](https://developer.huawei.com/consumer/cn/doc/development/system-References/transferstateupdate-0000001050132605) update) 数据收发状态回调。|

**Parameters**

|Name|Description|
|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|endpointId|远端设备标识。|
|update|数据传输进度刷新。例如，可以通过update获取[FILE](https://developer.huawei.com/consumer/cn/doc/development/system-References/data-type-0000001050132603#section181981039201911)类型的已传输字节，用于更新文件传输进度。|
