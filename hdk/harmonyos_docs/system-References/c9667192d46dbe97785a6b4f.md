# BeaconMsgCondition

|Class Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class BeaconMsgCondition implements Parcelable 定义信标消息附件过滤条件，只有符合此条件定义的信标会触发通知。 如果有多个过滤条件，不同条件间为逻辑或关系，符合任意一条条件即会触发通知。 注意： 使用此条件，需要待过滤的信标在云端注册并配置消息附件。|
