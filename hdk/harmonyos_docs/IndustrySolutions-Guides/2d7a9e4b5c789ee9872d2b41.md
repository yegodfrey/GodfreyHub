# 成为合作伙伴

本章节介绍如何成为OpenHarmony生态使能合作伙伴。成为合作伙伴之后，可以依托平台提供的解决方案，实现多设备场景化智能联动，助力智能化和数字化转型。

整个流程包含注册华为帐号、完成企业实名认证、加入合作计划、签署协议等环节，具体操作如下：

     1. 打开[OpenHarmony生态使能](https://devicepartner.huawei.com/openharmony/cn/)页面。
        * **未注册华为帐号** => 2
        * **已注册华为帐号** => 3
     2. **注册华为帐号。**
        1. 单击右上角的“注册”，进入注册页面。
        2. 通过电子邮箱或手机号码注册华为帐号。
           * 如果选择“手机号码注册”，输入正确的手机号码和验证码，设置密码后，单击“注册”。
           * 如果选择“电子邮箱注册”，输入正确的电子邮箱地址和验证码，设置密码后，单击“注册”。
        3. 阅读 _[《华为帐号用户协议》](https://id1.cloud.huawei.com/AMW/portal/agreements/userAgreement/zh-CN_userAgreement.html?version=china)_ 和 _[《关于华为帐号与隐私的声明》](https://id1.cloud.huawei.com/AMW/portal/agreements/accPrivacyStatement/zh-CN_accPrivacyStatement.html)_ ，单击“同意”，注册成功后进入实名认证页面，执行 4。
     3. **登录华为帐号。**
        1. 单击右上角的“登录”，进入登录页面。
        2. 输入帐号、密码和短信验证码后，单击“授权并登录”。
           * 如果**未完成实名认证** 或**实名认证失败** ，单击“前往认证”，进入实名认证页面，执行 4。
           * 如果**已完成实名认证** ，但未签署协议，执行 5。
           * 如果**实名认证审核中** ，请等待实名认证通过后，执行 5。
     4. **完成企业帐号的实名认证** ，可从以下两种方式中任选一种：
        * **方式一：对公银行打款认证**
          1. 选择“对公银行打款认证”。
          2. 完善企业基本信息和企业银行账户信息。

企业基本信息必须和企业营业执照上信息保持一致。

          3. 勾选“我已阅读并同意《华为开发者联盟与隐私的声明》”和“我已阅读并同意《开发者联盟企业认证信息共享协议》”，单击“下一步”。

系统会发送邮件和短信通知您已发起打款申请。通知发出后30分钟~3工作日内，尾号为0505的联盟账户将向您提供的银行账户打一笔小于1元的款项。

          4. 输入打款金额。

在收到打款申请通知后的3个工作日内，请关注对公账户。

收到打款后，登录[华为开发者联盟](https://developer.huawei.com/consumer/cn/develop/)，单击右上角的“管理中心”。在左侧菜单栏选择“开发者中心 > 设置 > 开发者信息”进入打款金额页面，输入打款金额。

          5. 单击“提交认证”，系统自动审核。
             * 如果填写的金额正确，实名认证通过。
             * 如填写的金额错误，实名认证失败。根据报错提示信息，重新输入金额或者重新打款认证。

输入金额错误达到两次后，可以选择“重新打款认证”，之前填写的认证信息会保留，需要重新获取验证码。

        * **方式二：企业资料人工审核认证**
          1. 选择“企业资料人工审核认证”。
          2. 完善企业信息。（标有红色星号*的项目是必填项）

企业基本信息必须和企业营业执照上信息保持一致。

          3. 勾选“我已阅读并同意《华为开发者联盟与隐私的声明》”和“我已阅读并同意《开发者联盟企业认证信息共享协议》”，单击“下一步”。
          4. 等待审核通过。在平台可以查看审核进展。
     5. **签署协议。**

阅读《关于华为OpenHarmony使能合作伙伴平台与隐私的声明》，勾选“我已阅读并同意以上内容”，单击“同意” 。

签署完成后，可以在“帐号管理 > 协议管理”页面，下载或解除已签署的协议。

     6. **申请加入OpenHarmony生态使能合作伙伴计划。**
        1. 首次进入OpenHarmony生态使能的“管理中心”时，需要填写基本行业信息。

        2. 单击“提交申请”，申请加入“OpenHarmony生态使能合作伙伴计划”。
        3. 等待审批通过。
