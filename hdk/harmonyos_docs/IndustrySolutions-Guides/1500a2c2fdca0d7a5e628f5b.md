# 查看安全公告与补丁

Device Partner平台按月发布HarmonyOS行业使能套件安全补丁公告，便于合作伙伴及时获取补丁，修复OpenHarmony以及使能套件的安全漏洞。

平台支持订阅安全公告，合作伙伴在收到安全公告之后，应当尽快获取并安装补丁。

#### 订阅安全公告

为了方便伙伴及时获取安全补丁的相关信息，平台提供了公告订阅功能。

     1. 登录[OpenHarmony生态使能](https://devicepartner.huawer.com/openharmony/cn/)，进入“管理中心”。
     2. 在平台左侧导航中，选择“公告补丁”。
     3. 单击页面右上方的“订阅”。
     4. 在弹出的窗口中，输入电子邮箱，并单击“订阅”。
        * 订阅成功后，如果平台发布安全公告后，将会推送通知到上述邮箱，以便于伙伴及时获取并安装补丁。
        * 订阅成功后，如果需要取消订阅公告，单击页面右上方的“订阅”，在弹出的窗口中单击“取消订阅”即可。

#### 获取并安装补丁

     1. 登录[OpenHarmony生态使能](https://devicepartner.huawer.com/openharmony/cn/)，进入“管理中心”。
     2. 在平台左侧导航中，选择“公告补丁”。
     3. 在安全公告列表中，按月份查找所需的安全补丁公告，单击“查看”，进入安全公告页面。
     4. 查看公共内容，单击“安全补丁”下载补丁，并进行解压。压缩包内部的文件说明，参见表1。

**表1** 安全补丁结构说明文件夹/文件 | 说明  
---|---  
patch | 内部文件夹中包含一个或多个补丁文件，补丁文件名后缀为“.diff”。  
partner-security-notice-2021-03-cn.html | 补丁安全公告（中文版）。  
partner-security-notice-2021-03-en.html | 补丁安全公告（英文版）。  
security-notice.json | 补丁详情说明，包括问题严重性、影响组件、系统版本、技术分析、修复办法、补丁包路径等。  
security-notice.csv | 补丁详情说明，包括问题严重性、影响组件、系统版本、技术分析、修复办法、补丁包路径等。  
  
     5. 执行如下打补丁命令。

通过文件“security-notice.csv”，可以查看该补丁包中的补丁文件数量，以及每个补丁文件所在的路径（参见文件中的“patch_files”字段）。

如果包含多个补丁文件，则需要对各个补丁文件分别打补丁。
            
            **cd** {将要打补丁的系统文件目录}
            **git apply******{补丁解压后所在的文件路径}

**示例：** 以“2021-08 harmonyos-partner-patch-2021.08.1.0.zip ”中的“001_CVE-2021-22441.diff”补丁文件为例，假设补丁包zip文件解压至$PATCH目录，系统当前所在目录为HarmonyOS代码根目录，则执行如下命令：
            
            **cd** drivers/adapter/khdf/linux
            **git apply** $PATCH/patch/HarmonyOS\ 2.0/drivers/adapter/khdf/linux/001_CVE-2021-22441.diff
