# 管理帐号

本章节介绍如何维护企业基本信息、管理已签署的协议。

#### 维护基本资料

     1. 登录[OpenHarmony生态使能](https://devicepartner.huawei.com/openharmony/cn/)，进入“管理中心”。
     2. 在左侧导航栏选择“帐号 > 基本资料”，可以查看和编辑企业信息。
        * 单击页面右上角的“开发者信息”，进入开发者信息设置页面。支持修改或完善开发者名称、企业地址、联系方式等信息。
        * 单击页面右上角的“帐号设置”，进入华为帐号设置页面。支持修改或完善个人信息、进行安全设置、开展实名认证。
        * 单击页面下方的“编辑基本信息”，可编辑企业的中英文简称、地址、主营业务、联系人等信息。

#### 管理协议

     1. 登录[OpenHarmony生态使能](https://devicepartner.huawei.com/openharmony/cn/)，进入“管理中心”。
     2. 在左侧导航栏选择“帐号 > 协议管理”，可以下载或解除已签署的签署协议文件。
        * **下载协议：** 单击“下载”，可以下载并查看协议内容。
        * **解除协议：** 仅支持解除《关于华为智能硬件合作伙伴平台与隐私的声明》协议。单击“解除签署”，在确认提示框中单击“确定”，即可解除签署。
