# 获取资源文件

本章节介绍如何获取**管理平台软件** 与**操作系统软件** 两类资源。

     * **管理平台软件：** 用于统一管理大量矿鸿设备的系统软件的生命周期。支持设备管理、许可证管理、安全凭据管理、OTA管理等功能以及数据可视化管理，有助于实现高效运维。同时，支持用户和权限管理、矿点分组管理功能，适用于不同的组织管理体系。
     * **操作系统软件：** 用于设备的矿鸿操作系统，包含矿鸿微型处理器软件、矿鸿小型控制器软件、矿鸿标准交互设备软件等多种类型。

#### 操作步骤

     1. 登录[OpenHarmony生态使能](https://devicepartner.huawei.com/openharmony/cn/)，进入“管理中心”。
     2. 在左侧导航中，选择“资源中心 > 行业资源中心”。
     3. 选择所需的软件。

支持通过软件类型、软件名称等进行筛选。
