# 获取设备License

本章节指导ISV（Independent Software Vendors）合作伙伴通过管理中心获取设备License。

#### 基本概念

     * **License** ：按照软件的特性、版本、使用期限等对软件使用权进行授权的许可证。ISV合作伙伴通过管理中心获取License并发放给设备商，再由设备商将License安装到对应的矿鸿设备以完成设备激活。
     * **激活码** ：用于申请设备License。ISV合作伙伴签署商业合同后，华为产品经理会在管理中心后台录入订单。订单审核通过后，ISV合作伙伴会收到通知邮件，并可以通过管理中心获取对应的设备激活码。

根据使用场景的不同，激活码分为调测激活码和商用激活码两种类型，分别可以生成调测License与商用License。

#### 获取激活码

在申请License之前，合作伙伴需要获取设备激活码。

     1. 登录[OpenHarmony生态使能](https://devicepartner.huawei.com/openharmony/cn/)，进入“管理中心”。
     2. 在左侧导航中，选择“量产管理 > 激活码申请”。
     3. 申请激活码。
        1. 在列表中找到状态为“待申请”的订单，单击“申请”。

#### 申请License

合作伙伴申请License时，需要通过管理中心上传企业英文简称、产品类型、产品名称、设备序列号、激活码、系统名称、系统版本号等信息。

     1. 登录[OpenHarmony生态使能](https://devicepartner.huawei.com/openharmony/cn/)，进入“管理中心”。
     2. 在左侧导航中，选择“量产管理 > License申请”。
     3. 下载设备序列号模板，按照模板填写申请参数，并上传文件。

提交License申请后，大概需要等待10分钟（所需时间与申请数量有关），可以查看到申请结果。

        * 如果申请成功，列表中的状态会变为“申请完成”，同时合作伙伴会收到邮件通知。在申请记录页面单击“下载”，可以获取对应的License文件。
        * 如果申请失败，请联系技术支持人员确认详情。
