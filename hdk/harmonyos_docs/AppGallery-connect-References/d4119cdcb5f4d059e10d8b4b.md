# ConfigValues

|Interface Info|
|:-------------------------------------------------------------------------------------------------------------------------------|
|public interface ConfigValues 存储数据的类，在fetch方法中返回的ConfigValues对象用于调用apply方法。针对fetch方法返回的ConfigValues对象，只是从云端同步下来的数据，不包含default数据。|
