# CloudDBZone

一个CloudDBzone对象表示一个Cloud DB的存储区域，通过该类提供的方法实现对CloudDBzone中数据的增、删、改、查和事务等操作，实现端云数据的管理。

|:----------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Promise\<number\>|[executeUpsert](#section17755153212411)\<T\>(objectList: T\[\] \| T) 将一个或者多个对象写入到当前CloudDBZone。|
|Promise\<number\>|[executeDelete](#section137618361416)\<T\>(objectList: T\[\] \| T) 删除CloudDBZone中与传入对象主键值相同的一个或者多个对象。|

#### Methods

#### executeUpsert

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|executeUpsert\<T\>(objectList: T\[\] \| T): Promise\<number\> 调用此方法将一个或者多个对象写入到当前CloudDBZone。如果在CloudDBZone已经存在主键值相同的对象，则更新CloudDBZone中已有的对象；如果不存在，则写入一个或者多个新的对象。 调用本方法需要遵循以下约束： * 仅当CloudDBZone为打开状态时，才允许调用该方法写入对象，否则会导致写入失败。 * 写入多个对象时，数据总大小不能超过2MB，否则会导致写入失败。 * 写入多个对象时，数据总条数不能超过1000条，否则会导致写入失败。 * 操作加密对象的数据条数过大时，建议分批多次写入。|

Parameters  

|Parameter name|Parameter desc|
|:---------------------|:-------------|
|objectList: T\[\] \| T|一个或者多个待写入的对象。|

Return  

|type|desc|
|:----------------|:----------------------------------------------------------|
|Promise\<number\>|Promise对象。通过此Promise对象可以异步获取操作结果，写入成功返回写入成功的条数，写入失败则返回异常信息。|

#### executeDelete

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|executeDelete\<T\>(objectList: T\[\] \| T): Promise\<number\> 调用此方法删除CloudDBZone中与传入对象主键值相同的一个或者多个对象。删除操作只关注对象的主键值是否相同，不考虑对象其它属性和存储的数据是否匹配。如果CloudDBZone中不存在相同主键值的对象，调用此方法将不做任何操作，对CloudDBZone无影响，执行结果为成功。 调用本方法需要遵循以下约束： * 仅当CloudDBZone为打开状态时，才允许调用此方法删除对象，否则会导致删除失败。 * 删除多个对象时，数据总大小不能超过2MB，否则会导致删除失败。 * 删除多个对象时，数据总条数不能超过1000条，否则会导致删除失败。|

Parameters  

|Parameter name|Parameter desc|
|:---------------------|:-------------|
|objectList: T\[\] \| T|一个或者多个待删除的对象。|

Return  

|type|desc|
|:----------------|:--------------------------------------------------------|
|Promise\<number\>|Promise对象。通过此Promise对象可以异步获取操作结果，删除成功返回删除成功的条数，失败则返回异常信息。|

#### executeQuery

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|executeQuery\<T\>(cloudDBZoneQuery: CloudDBZoneQuery\<T\>): Promise\<CloudDBZoneSnapshot\<T\>\> 调用此方法从CloudDBZone中查询满足特定条件的对象，并将查询到的结果集封装到一个CloudDBZoneSnapshot中。 调用本方法需要遵循以下约束： * 仅当CloudDBZone为打开状态时，才允许调用此方法查询对象，否则会导致查询失败。 * 每次查询结果的数据大小不能超过5MB，否则会导致查询失败。 * 查询结果中包含的数据条数不能超过1000条，否则会导致查询失败。|

Parameters  

|Parameter name|Parameter desc|
|:--------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|cloudDBZoneQuery: CloudDBZoneQuery\<T\>|一个CloudDBZoneQuery对象，表征查询条件。CloudDBZoneQuery类中提供了诸如where()、equalTo()、notEqualTo()、greaterThan()等方法，用以封装和实现查询的条件，具体可参见[CloudDBZoneQuery](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-web-0000001127836521)。|

Return  

|type|desc|
|:----------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Promise\<CloudDBZoneSnapshot\<T\>\>|Promise对象。通过此Promise对象可以异步获取操作结果，如果查询成功，通过该对象可以获取一个[CloudDBZoneSnapshot](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonesnapshot-web-0000001127719373)对象，其中封装了查询的结果集；如果查询失败，通过该对象可以获取异常信息。|

#### executeAverageQuery

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|executeAverageQuery\<T\>(cloudDBZoneQuery: CloudDBZoneQuery\<T\>, fieldName: string): Promise\<number\> 调用此方法从CloudDBZone中查找满足特定条件的对象，返回指定字段的算术平均值。 仅当CloudDBZone为打开状态时，才允许调用此方法查询指定字段的平均值，否则会导致查询失败。|

Parameters  

|Parameter name|Parameter desc|
|:--------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|cloudDBZoneQuery: CloudDBZoneQuery\<T\>|一个CloudDBZoneQuery对象，表征查询条件。CloudDBZoneQuery类中提供了诸如where()、equalTo()、notEqualTo()、greaterThan()等方法，用以封装和实现查询的条件，具体可参见[CloudDBZoneQuery](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-web-0000001127836521)。|
|fieldName|用于指定查询对象中需要计算平均值的字段名称。 指定字段的数据类型只支持如下类型：Byte、Short、Integer、Long、Float、Double、IntAutoIncrement和LongAutoIncrement。|

Return  

|type|desc|
|:----------------|:-----------------------------------------------------------|
|Promise\<number\>|Promise对象。通过此Promise对象可以异步获取操作结果，查询成功返回指定字段的算术平均值，失败则返回异常信息。|

#### runTransaction

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|runTransaction(transactionFunction: TransactionFunction): Promise\<boolean\> 调用此方法可以执行一个指定的事务操作。您通过实现[TransactionFunction](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-transactionfunction-web-0000001080700214)接口，可以将增、删、改、查等操作放在一个事务中去执行。本方法会直接操作云侧的数据，实现对云侧存储区数据的管理操作，包含数据的增、删、改、查操作。 调用本方法需要遵循以下约束： * 仅在正常连接网络时可调用该方法实现查询功能，否则会导致事务执行失败。 * 仅当CloudDBZone为打开状态时，才允许调用此方法执行事务操作，否则会导致事务执行失败。 * 一个事务内可以进行多次数据操作，查询操作必须在写入操作和删除操作之前进行。 * 一个事务中多次查询结果的总数据大小不能超过5MB，否则会导致事务失败。 * 一个事务中多次查询结果的总数据条数不能超过1000条，否则会导致事务失败。 * 一个事务中包含的写入和删除对象的总条数不能超过1000条，否则会导致事务失败。 * 一个事务内的多次写入和删除操作的数据大小不能超过2MB，否则会导致写入失败。|

Parameters  

|Parameter name|Parameter desc|
|:---------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|transactionFunction: TransactionFunction|一个实现的TransactionFunction接口，可以将一组操作封装在TransactionFunction中，然后通过此接口在一个事务中实现多个增、删、改、查操作，具体请参见[TransactionFunction](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-transactionfunction-web-0000001080700214)。|

Return  

|type|desc|
|:-----------------|:--------------------------------------------------------------|
|Promise\<boolean\>|Promise对象，通过此Promise对象可以异步获取事务的执行结果。 * true：表示成功。 * false：表示失败。|

#### subscribeSnapshot

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|subscribeSnapshot\<T\>(cloudDBZoneQuery: CloudDBZoneQuery\<T\>, listener: OnSnapshotListener\<T\>): Promise\<ListenerHandler\> 调用此方法注册一个对特定对象的侦听，当侦听的对象发生变化，触发注册的[OnSnapshotListener](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-onsnapshotlistener-web-0000001081019780)回调。注册快照侦听后，快照侦听需要一定的时间（受限于网络状态）才会生效，因此，在侦听生效前的快照不会推送到端侧，待侦听生效后，端侧可正常收到快照；当快照的大小超过5MB或者快照包含的数据条数超过1000条时，快照将无法推送至端侧。 调用本方法需要遵循以下约束： 仅当CloudDBZone为打开状态时，才允许调用此方法注册侦听，否则会导致注册侦听失败。|

Parameters  

|Parameter name|Parameter desc|
|:--------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|cloudDBZoneQuery: CloudDBZoneQuery\<T\>|一个CloudDBZoneQuery对象，表征查询条件。构造查询条件时，当前仅支持等值订阅，即仅支持使用[equalTo()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-web-0000001127836521#section197761791979)方法，且查询条件中最少包含一个字段，最多包含5个字段，多个查询条件之间采用"与"运算。 说明： 在注册侦听器时，equalTo()支持的字段数据类型如下：Boolean、Byte、Short、Integer、Long、Double、Float、String和Date。|
|listener: OnSnapshotListener\<T\>|侦听器对象，一旦此CloudDBZone中的数据发生变化，就会调用侦听器中onSnapshot方法，具体请参见[OnSnapshotListener](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-onsnapshotlistener-web-0000001081019780)。|

Return  

|type|desc|
|:----------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Promise\<[ListenerHandler](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-listenerhandler-web-0000001127497625)\>|一个Promise对象，如果订阅成功，可以通过该Promise对象获取到一个ListenerHandler对象，在您显式地调用ListenerHandler类中的[remove()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-listenerhandler-web-0000001127497625#section520052033014)方法之前，侦听器会一直生效。|

#### executeServerStatusQuery

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|executeServerStatusQuery(): Promise\<ServerStatus\> 调用此方法从CloudDBZone中查询当前服务器的状态，并将查询到的服务器状态封装到一个[ServerStatus](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-serverstatus-web-0000001499744509)中。当前ServerStatus中包含服务器的时间戳状态。 调用本方法需要遵循以下约束： * 仅当CloudDBZone为打开状态时，才允许调用此方法查询服务器的状态，否则会导致查询失败。|

Return  

|type|desc|
|:----------------------|:-------------------------------------------------------|
|Promise\<ServerStatus\>|Promise对象。通过此Promise对象可以异步获取操作结果，查询成功返回服务器的状态，失败则返回异常信息。|
