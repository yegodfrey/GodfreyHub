# ohAegHuksDecText

ohAegHuksDecText(keyAlias: string, text: string | Uint8Array): Promise<string>

基于HUKS的AES-GCM解密，配套[ohAegHuksEncText](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ohaeghuksenctext-0000001911924845)接口使用，分组模式、填充模式如下：

|分组模式|密钥长度（bit）|填充模式|API版本|
|:---|:--------|:--------|:----|
|GCM|256|NoPadding|11+|

**导入模块：**

```screen
import { AegHuks } from '@hw-agconnect/petal-aegis';
```

**参数** **：**

|参数名|类型|必填|说明|
|:-------|:----------------|:-|:-----------------------------------------------------------|
|keyAlias|string|是|密钥别名。|
|text|string或Uint8Array|是|待解密内容（ohAegHuksEncText加密后的结果），格式为**iv:密文**或者同类的Uint8Array格式。|

**返回值：**

|参数|类型|说明|
|:----------|:-----|:---------|
|decryptText|String|解密后的明文字符串。|

**示例：**

```screen
import { AegHuks } from '@hw-agconnect/petal-aegis';
import { buffer } from '@kit.ArkTS';

async function aesgcmhuks() {
  let alias = 'aegis';//密钥别名
  let plainText = 'hello world'; //待加密内容
  let iv = '987654321321'; //长度12字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let ivUint8 = new Uint8Array(buffer.from(iv, 'utf-8').buffer);

  try {
    let encryptText = await AegHuks.ohAegHuksEncText(alias, plainText, ivUint8);
    //aesgcmhuks  encryptText: 57,56,55,54,53,52,51,50,49,51,50,49,58,62,116,223,197,220,185,91,93,201,66,157,214,65,43,1,223,93,210,43,137,65,231,164,80,76,23,232
    console.log("aesgcmhuks ", 'encryptText: ' + encryptText);

    let decryptText = await AegHuks.ohAegHuksDecText(alias, encryptText);
    if (plainText === decryptText) {
      console.info('aesgcmhuks decrypt ok');
    }
    console.log("aesgcmhuks ", 'decryptText: ' + decryptText);
  } catch (err) {
    console.log("aesgcmhuks ", 'err: ' + err);
  }
}
```
