# AsyKeyPair

非对称算法生成的公私钥返回值类型，分别有公钥和私钥：

**参数** **：**

|参数名|类型|说明|
|:---------|:----------------|:---------------------------------------------------------------------|
|publicKey|Uint8Array或string|公钥内容，genAsyKeyPairy方法生成为Uint8Array格式，genAsyKeyPairBase64方法生成为base64格式。|
|privateKey|Uint8Array或string|私钥内容，genAsyKeyPairy方法生成为Uint8Array格式，genAsyKeyPairBase64方法生成为base64格式。|

**导入模块** **：**

```typescript
import { aegis } from '@hw-agconnect/petal-aegis';
```
