# 获取应用简略信息

## 功能介绍

批量查询应用简略信息。接口调用者的角色：账号持有者、管理员、App管理员、开发。

## 接口原型

|承载协议|HTTPS GET|
|-----|----------------------------------------------------------------------------------------|
|接口方向|开发者服务器 -> 华为服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/cds/app-distirbution/v1/all/app-brief-info/list|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 请求参数

### Header

> 说明
>
> 本接口只支持OAuth客户端方式。

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
|oauth2Token|M|String|认证信息，传入[获取用户授权码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section949717114392)中获取的Access Token。|
|userID|M|Integer|主账号用户id，即团队ID。通过[获取团队列表](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-getteamlist-0000001158245075)接口获取。|

### Query

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:------|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
|appId|O|String|需要查询的应用ID列表，多个值间以半角逗号分隔。 appId和packageNames必须传一个，如果同时存在则以appId为准。|
|packageNames|O|String|需要查询的应用包名，多个包名用逗号分隔，最大100个。 appId和packageNames必须传一个，如果同时存在则以appId为准。|
|appType|O|String|应用类型。 * 1：移动应用(包括普通应用和游戏) * 2：电视应用 * 4：路由器应用 * 8：华为VR应用 * 9：手表应用 * 19：RPK应用 * 23：大屏快应用 * 27：车机应用 * 28：车机快应用 * 29：运动手表 * 30：云游戏 * 9998：ios应用 * 9999：web应用|
|appDistStatus|O|String|应用分发状态列表，多个值间以半角逗号分隔。 * -999：审核中 * -995：升级中 * 0：不通过 * 1：已下架（含强制下架） * 62：待上架 * 101：已上架（含升级不通过，申请下架失败） * 99999：申请下架 * 9998：草稿 * 9997：已删除|
|fromRecCount|O|Integer|起始页数。从1开始，表示第1个。如果不传，默认值：1。|
|maxReqCount|O|Integer|每页返回条数；缺省20（最大1000）。|
|sortType|O|String|排序方式。|

## 响应参数

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:-------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------|
|appInfos|M|List<[AppBriefInfo](#ZH-CN_TOPIC_0000001111845106__p15218928192818)>|应用简略信息列表。|
|notExistIDs|M|String|不存在的应用ID列表，多个间以逗号分隔。|
|ret|M|String|包含返回码及描述信息的JSON字符串，格式为{"code":*retcode* , "msg": "*description*"}，retcode为返回码，description为返回码描述信息。|

**AppBriefInfo**

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:-----------|:----------|:--------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
|prodSerialNo|M|Integer|应用序列号。|
|appID|M|String|应用ID。|
|appName|M|String|应用名称。|
|projectId|M|String|项目ID。|
|appType|M|String|应用类型。 * 1：移动应用(包括普通应用和游戏) * 2：电视应用 * 4：路由器应用 * 8：华为VR应用 * 9：手表应用 * 19：RPK应用 * 23：大屏快应用 * 27：车机应用 * 28：车机快应用 * 29：运动手表 * 30：云游戏 * 9998：ios应用 * 9999：web应用|
|packageName|M|String|应用包名。|
|teamId|M|String|应用归属的团队账号id。|
|packageType|M|Integer|软件包类型。 * 1：APK * 2：RPK * 3：WPK * 4：EXE（云应用）|
|deviceTypes|M|List<[DeviceTypeInfo](#ZH-CN_TOPIC_0000001111845106__p1663313164299)>|应用的设备类型。|

**DeviceTypeInfo**

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:------|:------------------------------------------------------------------------------------------------------------------------|
|deviceType|M|Integer|设备类型。 * 4：手机 * 6：VR * 7：手表 * 8：大屏 * 9：路由器 * 10：车机|
|appAdapters|M|String|适配设备类型，多个间逗号分隔。 * 1：荣耀立方（路由器） * 4：手机 * 5：平板 * 6：VR * 7：手表（智能表Android wear系统） * 8：TV * 9：路由器 * 11：儿童手表 * 12：智能手表 * 13：带屏音箱|

## 调用示例

```screen
public static void getAppBriefInfoList(String domain, String oauth2Token, Integer userID, String packageNames) {
	HttpGet get = new HttpGet(domain + "/cds/app-distirbution/v1/all/app-brief-info/list?packageNames=" + packageNames);
	get.setHeader("oauth2Token", oauth2Token);
	get.setHeader("userID", String.valueOf(userID));
	try {
		CloseableHttpClient httpClient = HttpClients.createDefault();
		CloseableHttpResponse httpResponse = httpClient.execute(get);
		int statusCode = httpResponse.getStatusLine().getStatusCode();
		if (statusCode == HttpStatus.SC_OK) {
			BufferedReader br =
					new BufferedReader(new InputStreamReader(httpResponse.getEntity().getContent(), Consts.UTF_8));
			String result = br.readLine();
			JSONObject object = JSON.parseObject(result);
			System.out.println(object.get("ret"));
			AppInfos[] appInfos = (AppInfos[]) object.get("appInfos");
			String notExistIDs = (String) object.get("notExistIDs");
		}	}
	catch (Exception e) {

	}}
```
