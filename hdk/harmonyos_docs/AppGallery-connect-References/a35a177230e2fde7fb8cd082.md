# ohAegHmacSha256TextHex

ohAegHmacSha256TextHex(text: string | Uint8Array, key: string | Uint8Array): Promise<string>

HmacSHA256消息认证码算法，返回十六进制编码类型的SHA256值，算法说明如下：

|摘要算法|支持种类|API版本|
|:---|:-----|:----|
|HASH|SHA256|11+|

**导入模块：**

```typescript
import { AegHmac } from '@hw-agconnect/petal-aegis';
```

**参数** **：**

|参数名|类型|必填|说明|
|:---|:----------------|:-|:----------------------------|
|text|string或Uint8Array|是|明文内容。|
|key|string或Uint8Array|是|明文密钥（string类型的key需要16进制编码格式）。|

**返回值：**

|参数|类型|说明|
|:--|:--------|:-----------------|
|字符串|hexString|生成的加密hexString字符串。|

**示例：**

```typescript
import { AegHmac } from '@hw-agconnect/petal-aegis';
import { buffer } from '@kit.ArkTS';

function HmacSHA2562() {
  let text = 'hello world';
  let key = '12345678912345678912345678912345';//长度32字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let keyUint8 = new Uint8Array(buffer.from(key, 'utf-8').buffer);

  AegHmac.ohAegHmacSha256TextHex(text, keyUint8).then((data) => {
    //HmacSHA2562  result: f79b3dc14e1a237bd3bd1a8087eb433e6d7fec3ac749da447f4859d349321e73
    console.log("HmacSHA2562 ", 'result: ' + data);
  }).catch((err) => {
    console.log("HmacSHA2562 ", 'err: ' + err);
  })
}
```
