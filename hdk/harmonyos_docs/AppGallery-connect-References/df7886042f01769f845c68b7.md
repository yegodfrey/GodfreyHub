# FFPerFrameExtendedCameraInfo

每帧数据的摄像机扩展信息。
> 说明
>
> 在相机的大世界空间平移的情况下，添加摄像机扩展信息可使预测帧更精确。在其他情况下，通常是不必要添加的。

**Structure Declaration**

```screen
typedef struct FFPerFrameExtendedCameraInfo {
    FFStructureType sType;
    const void* pNext;
    FFMat4x4 proj;
    FFMat4x4 translatedInvViewProj;
    FFMat4x4 translatedView;
    FFMat4x4 translatedViewProj;
    FFVec3D worldPosition;
} FFPerFrameExtendedCameraInfo;
```

**Members**

|Name|Mandatory/Optional|Description|
|:--------------------|:-----------------|:---------------------------------------------------------------------------------------|
|sType|Mandatory|此结构体类型必须为**FF_STRUCTURE_TYPE_PER_FRAME_EXTENDED_CAMERA_INFO**。|
|pNext|Optional|指向扩展链中的下一个结构体的指针。扩展参数，可缺省，默认值为NULL。|
|proj|Mandatory|投影矩阵，对应于从视图空间坐标（View Space Coordinates）到剪辑空间坐标（Clip Space Coordinates）的转换。|
|translatedInvViewProj|Mandatory|视图投影矩阵的逆矩阵，对应于从剪辑空间坐标（Clip Space Coordinates）到以相机为中心的世界空间坐标（World Space Coordinates）的转换。|
|translatedView|Mandatory|视图矩阵。对应于从以相机为中心的世界空间坐标（World Space Coordinates）到视图空间坐标（View Space Coordinates）的转换。|
|translatedViewProj|Mandatory|视图投影矩阵，对应于从以相机为中心的世界空间坐标（World Space Coordinates）到剪辑空间坐标（Clip Space Coordinates）的转换。|
|worldPosition|Mandatory|相机相对于世界坐标（World Coordinates）原点的平移。|
