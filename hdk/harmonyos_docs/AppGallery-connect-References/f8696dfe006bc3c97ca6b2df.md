# AGCStorageReference

|Class Info|
|:--------------------------------------------------------------------------------|
|@interface AGCStorageReference : NSObject 云端文件的引用，提供对象的列举、上传、下载、删除、元数据更新等各项操作的封装。|

## Property Summary

|Qualifier and Type|Property Name and Description|
|:-----------------|:----------------------------|
|AGCStorage|storage 引用所在AGCStorage实例。|
|NSString|bucketName 引用所在的存储实例名称。|
|NSString|path 云端文件或目录的路径。|
|NSString|name 文件或目录名。|
