# AGCCloudDBQuery

```screen
@interface AGCCloudDBQuery : NSObject
```

提供了诸如where、equalTo、notEqualTo、inArray等丰富的谓词查询来构造查询条件。您可以基于上述谓词查询方法构造自己的AGCCloudDBQuery对象，并作为executeQuery、executeAverageQuery和executeQueryUnsynced等方法的参数传入，Cloud DB会基于指定的查询条件从CloudDBZone中获取到对应的对象并返回查询结果。

## +where:

调用此方法来获取一个AGCCloudDBQuery对象，并指定CloudDBZone中查询的对象类型。AGCCloudDBQuery对象不提供任何构造方法，只能通过where方法获取一个对象类型实例。

**OBJECTIVE-C**

```screen
+ (nonnull instancetype)where:(nonnull Class)clazz;
```

**Parameters**

|Parameter name|Parameter desc|
|:-------------|:---------------------|
|clazz|一个Class对象，自定义的对象类型实体类。|

**Return**

|type|desc|
|:-----------|:---------------------------|
|instancetype|一个指定目标实体类的AGCCloudDBQuery对象。|

调用此方法来设置查询结果按指定字段升序排列。

使用此方法对字段进行排序时，建议针对排序的字段创建索引，否则，当该对象类型的数据量达到一定条数时，可能因为查询效率低引起查询超时或失败，影响用户体验。

## -limit:

调用此方法添加查询条件，用于限定返回查询结果集中的数据数量。

* 如无需设置"offset"，则默认从首个对象开始获取前count个对象。如果查询结果集中的对象数目小于count个，则全量返回对象。
* 如设置"offset"，则返回从offset位置开始的count个对象。如果从offset位置开始后的对象数目小于count个，则全量返回从offset位置开始后的对象。

调用此方法之前必须先调用where方法获取AGCCloudDBQuery实例。

**OBJECTIVE-C**

* 无需设置"offset"

  ```screen
  - (nonnull instancetype)limit:(int)count;
  ```

* 设置"offset"

  ```screen
  - (nonnull instancetype)limit:(int)count offset:(int)offset;
  ```

**Parameters**

|Parameter name|Parameter desc|
|:-------------|:----------------------------------|
|count|限定允许获取的数据记录条数。|
|offset|指定数据记录的起始位置。 您可以根据需要自选是否设置offset位置。|

**Return**

|type|desc|
|:-----------|:-----------------------------------------|
|instancetype|一个AGCCloudDBQuery对象，包含限定返回查询结果集中数据数量的查询条件。|

## -startAt:

调用此方法设置查询数据的起始位置，返回该起始位置以后的数据记录，返回结果包含指定起始位置对应的数据记录。

为了保证startAt的查询性能，Cloud DB要求您在调用本方法构造查询条件前，先创建本次查询所需的索引。如果未创建索引，您可能会收到一个异常信息，您需要根据异常信息创建缺少的索引。

在一个查询中，仅允许使用startAt、startAfter、endAt或者endBefore方法中的一个，且只能调用一次。

构造查询条件时，startAt方法可以单独使用，也可以和equalTo、orderByAsc、orderByDesc或者limit方法组合使用，组合使用时，必须在equalTo、orderByAsc、orderByDesc之后，limit之前调用。

* 没有和orderByAsc或者orderByDesc接口组合使用时，会默认按照主键的升序进行排序，并返回指定起始位置以后的数据记录。
* 当和equalTo组合使用时，equalTo指定的查询字段不允许为主键字段；且equalTo仅支持数据类型NSNumber <AGCBool>、NSNumber<AGCByte>、NSNumber<AGCShort>、NSNumber<AGCInt>、NSNumber<AGCLong>、NSNumber<AGCFloat>、NSNumber<AGCDouble>、NSString和NSDate。
* 当和orderByAsc或者orderByDesc组合使用时，必须创建排序对应的字段索引，且只能使用两者中的一种；orderByAsc或者orderByDesc指定的字段的值不允许为空。orderByAsc和orderByDesc仅支持数据类型NSNumber<AGCByte>、NSNumber<AGCShort>、NSNumber<AGCInt>、NSNumber<AGCLong>、NSNumber<AGCFloat>、NSNumber<AGCDouble>、NSString和NSDate。
* 当和equalTo、且和orderByAsc或者orderByDesc之一组合使用时，equalTo指定的字段不能和orderByAsc或orderByDesc指定的字段重复。

**OBJECTIVE-C**

```screen
- (nonnull instancetype)startAt:(nonnull AGCCloudDBObject *)object;
```

**Parameters**

|Parameter name|Parameter desc|
|:-------------|:----------------|
|object|起始位置对应的对象，对象不能为空。|

**Return**

|type|desc|
|:-----------|:----------------------------------------------------------|
|instancetype|一个AGCCloudDBQuery对象，设置在查询结果中获取从起始位置开始的数据记录，结果包含起始位置对应的数据记录。|

* 当和equalTo组合使用时，equalTo指定的查询字段不允许为主键字段；且equalTo仅支持数据类型NSNumber <AGCBool>、NSNumber<AGCByte>、NSNumber<AGCShort>、NSNumber<AGCInt>、NSNumber<AGCLong>、NSNumber<AGCFloat>、NSNumber<AGCDouble>、NSString和NSDate。
* 当和orderByAsc或者orderByDesc组合使用时，必须创建排序对应的字段索引，且只能使用两者中的一种；orderByAsc或者orderByDesc指定的字段的值不允许为空。orderByAsc和orderByDesc仅支持数据类型NSNumber<AGCByte>、NSNumber<AGCShort>、NSNumber<AGCInt>、NSNumber<AGCLong>、NSNumber<AGCFloat>、NSNumber<AGCDouble>、NSString和NSDate。
* 当和equalTo、且和orderByAsc或者orderByDesc之一组合使用时，equalTo指定的字段不能和orderByAsc或orderByDesc指定的字段重复。

**OBJECTIVE-C**

```screen
- (nonnull instancetype)endBefore:(nonnull AGCCloudDBObject *)object;
```

**Parameters**

|Parameter name|Parameter desc|
|:-------------|:--------------------------------|
|object|终止位置对应的AGCCloudDBObject对象，对象不能为空。|

**Return**

|type|desc|
|:-----------|:---------------------------------------------------------|
|instancetype|一个AGCCloudDBQuery对象，设置在查询结果中获取终止位置之前的数据记录，结果不包含终止位置对应的数据记录|
