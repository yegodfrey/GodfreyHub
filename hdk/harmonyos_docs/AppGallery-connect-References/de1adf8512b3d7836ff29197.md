# CloudDBZoneSnapshot

|class info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.agconnect.cloud.database.CloudDBZoneSnapshot CloudDBZoneSnapshot类用于描述本次查询到的快照数据，包含全量的对象集合、新增和修改的对象集合和新删除的对象集合等，您可以调用不同的方法获取需要的数据结果。每次使用CloudDBZoneSnapshot对象后，必须显式地调用release()方法来释放相关的资源，否则会导致资源泄漏或者增、删、改、查等功能不可用。|

|Return type|Method name|
|:-----------------------|:----------------------------------------------------------------|
|boolean|[hasPendingWrites](#section168002230584)() 判断当前快照中是否存在尚未同步到云端的对象。|
|boolean|[isFromCloud](#section1567122635811)() 判断当前快照中的对象是否从云端查询得到。|

|void|[release](#section2038011075811)() 释放快照占用的资源。|

### isFromCloud

|Method|
