# UploadTask

|Class Info|
|:-------------------------------------------------------------------------|
|public class UploadTask extends StorageTask<UploadTask.UploadResult> 上传任务。|

## Protected Method Summary

|Return|Method|
|:-----|:---------------------------------------------|
|void|[onCanceled](#section4928192922414)() 取消任务。|
|void|[resetState](#section11802204717438)() 重置任务状态。|
|void|[schedule](#section185518616445)() 执行任务。|
|void|[onPaused](#section6691109103110)() 暂停当前上传任务。|

## Protected Methods

### onCanceled

|Method|
|:--------------------------------|
|protected void onCanceled() 取消任务。|

### resetState

|Method|
|:---------------------------------------------------------------|
|protected void resetState() 重置任务的状态。例如任务执行过程中出现异常，重置状态后，继续执行该任务。|

### schedule

|Method|
|:------------------------------------------------------------|
|protected void schedule() 执行任务。上传任务在调用putFile接口时会内部调用该方法执行任务。|

### onPaused

|Method|
|:----------------------------------|
|protected void onPaused() 暂停当前上传任务。|
