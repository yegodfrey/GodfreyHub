## Interface Summary

|Interface|Description|
|:---------|:----------|
|IComponent|定义组件的接口。|
|IShared|定义共享组件的接口|

**Sample Code**

```screen
// 定义组件
public struct TestComponent1 : IComponent
{
    public int value;
    public override string ToString() => value.ToString();
}

// 定义共享组件
public struct SharedComponent1 : IShared
{
    public int value;
}
```

## Attribute Summary

|Attribute|Description|
|:-------------------------------|:-------------------------------------------------------------------------------------------------|
|ComponentLookupAttribute|为ILookup组件指定专用的RangeLookup。 示例如下： ```screen [ComponentLookup(typeof(T))] ```|
|ComponentKeyAttribute|为组件类型自定义序列化key。 示例如下： ```screen [ComponentKey("name")] ```|
|GenericTypeRegistrationAttribute|用于注册泛型组件/标签的具体类型实例及其序列化key。 示例如下： ```screen [GenericTypeRegistration("comp-int", typeof(int))] ```|

**Sample Code**

```screen
// 声明Lookup组件类型为RangeLookup
[ComponentLookup(typeof(RangeLookup<,>))]
internal struct LookupStringRange : ILookup<string> 
{
    internal        string      value;
    public          string      GetLookup()   => value;
    public override string      ToString()    => value;
}

// 给定义的Tag指定序列化名称
[TagName("test-tag")]
public struct TestTag : ITag { }

// 给定义的Component指定序列化名称
[ComponentKey("test-component1")]
public struct TestComponent1 : IComponent
{
    public int value;
    public override string ToString() => value.ToString();
}

// 指定泛型组件/标签的具体类型以及序列化名称
[GenericTypeRegistration("generic-comp-int", typeof(int))]
[GenericTypeRegistration("generic-comp-string", typeof(string))]
public struct TestGenericComponent<T> : IComponent
{
    public T t1;
}
```
