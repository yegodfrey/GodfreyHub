# FrameFlow_SetPredictionAlgorithm

|Function Info|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|FFResult FrameFlow_SetPredictionAlgorithm(FFInstance instance, const FFPredictionAlgorithmInfo\* pPredictionAlgorithmInfo, FFAlgorithmCapabilitiesInfo\* pCapabilitiesInfo); 设置预测算法。|

Parameters  

|Name|Description|
|:-----------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|instance|库实例。|
|pPredictionAlgorithmInfo|指向[FFPredictionAlgorithmInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffpredictionalgorithminfo-0000001791494320)结构体的指针，表示预测算法类型及插帧方案。|
|pCapabilitiesInfo|指向[FFAlgorithmCapabilitiesInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffalgorithmcapabilitiesinfo-0000001791334612)结构体的指针，表示预测算法配置信息。|

Return  

|Type|Description|
|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------|
|FFResult|返回结果。 成功时返回0，失败则返回错误码，具体请参见[FFResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffresult-0000001838093829)。|
