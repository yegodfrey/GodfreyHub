# ObjectTypeInfo

|class info|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.agconnect.cloud.database.ObjectTypeInfo 对象类型的信息，包含对象类型的版本和对象类型定义等，用于[createObjectType()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agconnectclouddb-0000001542275989#section114216263118)方法调用，实现本地开发环境中对象类型的创建。您不需要直接访问该类，只需要从AppGallery Connect控制台导出用于HarmonyOS应用开发的java类型文件，通过createObjectType()方法调用即可。|
