# FFStencilValueSemantic

模板值。
> 注意
>
> 对remapTable需要使用0初始化，即将所有物体先标记为静态物体，否则将会导致预测输出不稳定。

**Enum Info**

```screen
typedef enum FFStencilValueSemantic {
    FF_STENCIL_VALUE_SEMANTIC_GENERIC_DYNAMIC_OBJECT = 0,
    FF_STENCIL_VALUE_SEMANTIC_STATIC_OBJECT = 1,
    FF_STENCIL_VALUE_SEMANTIC_MAIN_CHARACTER = 2,
    FF_STENCIL_VALUE_SEMANTIC_REPROJECTIBLE_DYNAMIC_OBJECT = 3,
    FF_STENCIL_VALUE_SEMANTIC_SKYBOX = 4,
    FF_STENCIL_VALUE_SEMANTIC_PASS_THROUGH = 5,
} FFStencilValueSemantic;
```

**Enum Value Summary**

|**Enum Value**|Description|
|:-----------------------------------------------------|:-----------------------------------------------------------------------------|
|FF_STENCIL_VALUE_SEMANTIC_GENERIC_DYNAMIC_OBJECT|可自行运动的普通动态物体，这些物体由更复杂的计算来处理。|
|FF_STENCIL_VALUE_SEMANTIC_STATIC_OBJECT|普通静态物体，其屏幕运动完全由相机运动决定，对这些物体的计算处理是轻量级的。 > 注意 > 如果错误地将动态物体视为静态物体，有可能会导致明显的闪烁问题。|
|FF_STENCIL_VALUE_SEMANTIC_MAIN_CHARACTER|主要人物，被视为动态物体。|
|FF_STENCIL_VALUE_SEMANTIC_REPROJECTIBLE_DYNAMIC_OBJECT|可重新投影的动态物体，由其在模板重新映射表中的位置来标识。每个独立物体都应在表中有自己的条目。每个帧都可以提供每个物体的运动矩阵，以提高这些物体的预测质量。|
|FF_STENCIL_VALUE_SEMANTIC_SKYBOX|天空盒，被视为静态物体。|
|FF_STENCIL_VALUE_SEMANTIC_PASS_THROUGH|特殊枚举值，将使用游戏原始的模板值。|
