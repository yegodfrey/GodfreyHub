# 常见错误码

Aegis中的加解密算法均是通过[@ohos.security.cryptoFramework (加解密算法库框架)](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-cryptoframework)或[@ohos.security.huks (通用密钥库系统)](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-huks)封装实现的，错误码可以参考[crypto framework错误码](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/errorcode-crypto-framework)或[HUKS错误码](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/errorcode-huks)以及[通用错误码](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/errorcode-universal)。

**Aegis错误码如下：**

|错误码|说明|解决方案|
|:----|:--------|:-------------------|
|10001|参数无效|请检查入参的类型及长度|
|20001|Key的类型错误|请检查枚举类型中是否存在该值|
|20002|Key的长度不正确|请检查参数Key的长度是否符合要求|
|30001|算法加解密失败|请检查加解密算法的入参长度和格式是否正确|
