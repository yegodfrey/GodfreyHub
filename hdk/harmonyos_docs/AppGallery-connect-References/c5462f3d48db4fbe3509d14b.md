# AGCStorageTask

|Class Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|@interface AGFCStorageTask<TResult> : NSObject 任务的管理，提供存储任务的各种状态操作的封装，是[AGCStorageUploadTask](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstorageuploadtask-0000001126781970)和[AGCStorageDownloadTask](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragedownloadtask-0000001172821639)的父类。|

## Property Summary

|Qualifier and Type|Property Name and Description|
|:-----------------|:----------------------------|
|BOOL|isComplete 任务是否完成。|
|BOOL|isSuccessful 任务是否成功。|
|BOOL|isCanceled 任务是否已取消。|
|TResult|result 任务成功的结果。|
|NSError|error 任务失败的错误。|
|TResult|timePointState 任务过程中的状态。|
|BOOL|isPaused 任务是否暂停。|
|BOOL|isInProgress 任务是否进行中。|
