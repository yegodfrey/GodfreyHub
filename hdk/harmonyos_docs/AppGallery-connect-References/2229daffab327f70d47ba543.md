# FFGrabInfo

指定的预测算法所需的每帧数据。

**Structure Declaration**

```screen
typedef struct FFGrabInfo {
    FFStructureType sType;
    void* pNext;
    FFPerFrameDataFlags dataFlags;
} FFGrabInfo;
```

**Members**

|Name|Mandatory/Optional|Description|
|:--------|:-----------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|sType|Mandatory|此结构体类型必须为**FF_STRUCTURE_TYPE_GRAB_INFO**。|
|pNext|Optional|指向扩展链中的下一个结构体的指针。扩展参数，可缺省，默认值为NULL。|
|dataFlags|Mandatory|当前数据类型的位掩码，具体请参见[FFPerFrameDataFlagBits](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffperframedataflagbits-0000001791494368)。如果传入多个，则必须使用丨分开，例如，**FF_PER_FRAME_DATA_SCENE_COLOR_BIT 丨 FF_PER_FRAME_DATA_DEPTH_BIT**|
