# ProductGroupInfo

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:--------|:----------|:---------|:--------------------------------------|
|groupId|O|String(32)|分组ID。 创建时不需传入，系统自动生成。更新时必须传入。|
|groupName|M|String(30)|分组名称 。|
|status|O|String|分组状态，更新接口不支持修改分组状态，取值如下： * active：上线状态。|
