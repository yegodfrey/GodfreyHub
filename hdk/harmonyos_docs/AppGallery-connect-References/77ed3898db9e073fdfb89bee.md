# AGCConfigValues

```screen
@interface AGCConfigValues : NSObject
```

存储数据的类，在fetch方法中返回的ConfigValues对象用于调用apply()方法。 针对fetch方法返回的ConfigValues对象，只是从云端同步下来的数据，不包含default数据。

## -contain:

数据中是否包含对应Key值。

**OBJECTIVE-C**

```screen
- (BOOL)contain:(nonnull NSString *)key;
```

**SWIFT**

```screen
func contain(_ key: String) -> Bool
```

**Parameters**

|Parameter|Description|
|:--------|:----------|
|key|远程配置参数Key值。|

**Return**

是否包含Key。

## -valueAsBool:

返回Key对应的BOOL类型的Value值。

**OBJECTIVE-C**


**SWIFT**


**Parameters**

|Parameter|Description|
|:--------|:----------|
|key|远程配置参数Key值。|

**Return**
