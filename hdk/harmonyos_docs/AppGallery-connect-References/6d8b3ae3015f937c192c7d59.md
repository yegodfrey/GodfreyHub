# FunctionCallable

设置需要调用的云函数后，可以通过此类的方法调用云函数或设置超时时间。

## Method Summary

|Qualifier and Type|Method Name and Description|
|:---------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------|
|Promise<[FunctionResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/functionresult-ts-0000001471061338)>|[call](#section318632915452)(reqBody?:any) 调用云函数，参数可选。|
|void|[setTimeout](#section13869161855113)(timeout:number) 设置函数执行的超时时长（单位：毫秒）。|
|number|[getTimeout](#section111415635320)() 获取当前设定的超时时长（单位：毫秒）。|

## Property Summary

|Name|Type|Description|
|:------|:-----|:---------------------------|
|timeout|number|调用云函数的超时时长（单位：毫秒），默认70000毫秒。|

## Methods

### call

|Method|
|:------------------------------------------------------|
|call(reqBody?:any): Promise<FunctionResult> 调用云函数，参数可选。|

**Parameters**

|Name|Description|
|:------|:------------------------------------------|
|reqBody|可选参数，包含云函数入参值的对象。对象中包含的入参值需要与创建云函数时设置的入参对应。|

**Return**

|Type|Description|
|:---------------------------------------------------------------------------------------------------------------------------------------|:-------------------|
|Promise<[FunctionResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/functionresult-ts-0000001471061338)>|以异步方式返回的包含函数执行结果的对象。|

### setTimeout

|Method|
|:---------------------------------------------|
|setTimeout(timeout:number) 设置函数执行的超时时长（单位：毫秒）。|

**Parameters**

|Name|Description|
|:------|:-----------------|
|timeout|调用云函数的超时时长（单位：毫秒）。|

### getTimeout

|Method|
|:-------------------------------|
|getTimeout() 获取当前设定的超时时长（单位：毫秒）。|

**Return**

|Type|Description|
|:-----|:-------------------|
|number|返回调用云函数的超时时长（单位：毫秒）。|
