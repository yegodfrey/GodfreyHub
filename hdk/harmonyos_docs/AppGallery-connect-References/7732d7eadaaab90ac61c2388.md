# CloudDBZoneObjectOperatorConstraint

提供了诸如build()、equalTo()、notEqualTo()、in()等一系列用于构造查询条件的谓词查询。您可以基于上述的谓词方法构造自己的CloudDBZoneObjectOperatorConstraint对象，仅作为[update()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section1881840185010)、[batchUpdate()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section20931138154917)、[batchUpdateByCondition()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section037353591218)、[batchDelete()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section441211816372)或者[batchDeleteByCondition()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section12734357113812)方法的参数传入，云数据库会基于指定的约束条件来进行更新。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250116140802.86247249733815175588817651029578:50001231000000:2800:1B43B9C7A49B5B8A96C6FDFD5175002F92B96BEBC0FE9BDD428EE412C2408784.png?needInitFileName=true?needInitFileName=true)  
* CloudDBZoneObjectOperatorConstraint作为更新操作的约束条件，与CloudDBZoneQuery查询条件不同。
* 构造约束条件时，仅支持使用以下13种谓词，equalTo()、notEqualTo()、greaterThan()、greaterThanOrEqualTo()、lessThan()、lessThanOrEqualTo()、in()、beginsWith()、endsWith()、contains()、isNull()、isNotNull()和byUid()。
* 构造约束条件时，同一约束条件下约束谓词需小于或等于30个。
