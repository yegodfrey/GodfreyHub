# HMFTaskCompletionSource

|Class Info|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|用于开发者自定义任务。 TResult 任务执行成功返回的数据类型。 Objective-C ``` @interface HMFTaskCompletionSource<__covariant TResult> : NSObject ``` Swift ``` open class TaskCompletionSource<TResult> : NSObject ```|

#### -setResult:

设置任务执行成功。

Objective-C

```
- (void)setResult:(TResult _Nullable)result;
```

Swift

```
func setResult(_ result: TResult?)
```

Parameters  

|Name|Description|
|:-----|:----------|
|result|任务执行的结果。|

#### -setError:

设置任务执行失败。

Objective-C

```
- (void)setError:(nonnull NSError *)error;
```

Swift

```
func setError(_ error: Error)
```

Parameters  

|Name|Description|
|:----|:----------|
|error|任务失败的错误。|

#### -getTask

返回异步任务。

Objective-C

```
- (nonnull HMFTask<TResult> *)getTask;
```

Swift

```
func getTask() -> Task<TResult>
```
