# ListOptions

|Interface Info|
|:--------------------------------------------|
|export interface ListOptions 云端目录列举时的分页参数信息类。|

## Property Summary

|Name|Type|Mandatory/Optional|Description|
|:---------|:-----|:-----------------|:------------------------------|
|maxResults|number|Optional|返回的目录和文件的总个数，设置范围1~1000，默认值为50。|
|pageMarker|string|Optional|分页查询时的分页标识符。|
