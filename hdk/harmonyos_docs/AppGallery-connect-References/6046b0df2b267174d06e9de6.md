# QueryArchetypeChunk<T1, ...>

|Class/Struct Info|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public readonly struct QueryArchetypeChunk<T1> : IEnumerable<ArchetypeChunk<T1>>where T1 : struct 查询结果的原型块集合，继承了IEnumerable<ArchetypeChunk<T1, ...>>，支持迭代访问。 T为struct，最多支持10个泛型。|

## Property Summary

|Name|Type|Description|
|:---------|:---|:----------|
|Count|int|查询实体数量。|
|ChunkCount|int|查询块数量。|

**Sample Code**

```screen
var world = new IECSWorld();
var query = world.Query<PgdPosition>();
world.CreateEntity(new PgdPosition());
// 查询匹配的实体数
query.ArchetypeChunk.Count; // 1
// 查询匹配的Archetype数
query.ArchetypeChunk.ChunkCount; // 1
```
