# ohAegSMEnc

ohAegSMEnc(text: Uint8Array, key: Uint8Array, iv?: Uint8Array): Promise\<Uint8Array\>

SM4-CBC加密算法，加密结果是Uint8Array类型，建议与[ohAegSMDec](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ohaegsmdec-0000001910265101)配套使用，分组模式、填充模式如下：  

|分组模式|密钥长度（bit）|填充模式|API版本|
|:---|:--------|:----|:----|
|CBC|128|PKCS7|11+|

导入模块：

```
import { AegSM } from '@hw-agconnect/petal-aegis';
```

参数：  

|参数名|类型|必填|说明|
|:---|:---------|:-|:---------------------------|
|text|Uint8Array|是|明文内容。|
|key|Uint8Array|是|明文工作密钥。|
|iv|Uint8Array|否|如果没有传入，接口会自动生成iv，随密文一同作为返回值。|

返回值：  

|参数|类型|说明|
|:----------|:---------|:------|
|encryptText|Uint8Array|加密后的密文。|
