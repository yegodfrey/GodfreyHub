# 删除用户账号

#### 功能介绍

Serverless用户数据删除模板通过云函数监听认证服务的删除用户账号消息，实现删除对应用户数据。此Serverless模板从userCancelAccount请求消息中UID字段值获取用户数据。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|华为服务器 -\> 开发者服务器|
|接口URL|开发者提供用户认证接口URL，必须为HTTPS协议。|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|
|-----|-------------------------------------------------------------------|

#### 请求参数

请求参数以JSON格式传入，包含参数如下。  

|参数名称|必选(M)/可选(O)|数据类型|参数说明|
|:------------|:----------|:------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|email|M|String|邮箱地址。|
|emailVerified|O|Integer|邮箱地址是否需要被认证鉴权。 取值范围： * 1：是 * 0：否|
|Op|O|String|触发器的事件类型。 取值范围： * 0: registration * 1: deregistration * 2: sign-in * 3: sign-out|
|Phone|O|String|手机号码。|
|productId|O|String|项目ID。|
|providers|O|String|认证鉴权模式。 取值范围： * 0: anonymous account * 1: HUAWEI ID * 2: Facebook * 3: Twitter * 4: WeChat * 5: HUAWEI GameCenter * 6: QQ * 7: Weibo * 8: Google * 9: Google Play Games * 10: self-owned account * 11: mobile number * 12: email address * 13: Apple ID 注意： 当您选择的默认数据处理位置位于德国、新加坡或俄罗斯时，您可以使用Facebook、Twitter、Google或Google Play Games账号的认证鉴权模式。|
|uid|M|String|用户ID。|

#### 请求示例

```
POST https://example.com/auth
         Content-Type: application/json; charset=utf-8
{
    "email":"xxxx@huawei.com",
    "emailVerified":0,
    "op":"2",
    "phone":"+86-13112345678",
    "productId":"258913027873071736",
    "providers":[{"provider":11,"uid":"448552213585866496"}],
    "uid":"671456524878745645"
}
```

#### 响应参数

返回值为JSON格式的字符串，包含参数如下。  

|参数名称|必选(M)/可选(O)|数据类型|参数说明|
|:---|:----------|:----------|:--------------|
|UID|O|String(100)|通过监听云函数获取的用户ID。|

#### 响应示例

```
HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8
{
         "UID": "671456524878745645"
}
```
