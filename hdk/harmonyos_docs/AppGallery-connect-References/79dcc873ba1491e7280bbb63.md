# CalendarPicker

CalendarPicker是一个基于系统基础组件开发的日历选择器组件，包含单日期选择、多日期选择和时间段选择，支持自定义一周起始日，支持自定义主题样式。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250403114001.71405018095727093090407403808439:50001231000000:2800:D64040284475566F886EF33E83064447822E569110420737DC984C86A7BC7D84.png)  
* 该组件从API Version 11开始支持。
* 支持的设备类型：手机、平板、2in1。  

#### 子组件

可以包含单个子组件。  

#### 接口

#### UICalendarPicker(option: UICalendarPickerOptions)

UICalendarPickerOptions对象说明  

|名称|参数类型|必填|描述|
|:---------------|:--------------------------------------------------------------------------------------------------------|:-|:-------------------------------------------------------------------|
|type|[TypePicker](#ZH-CN_TOPIC_0000001894208829__table0638312154815)|否|日期选择器类型。 默认值为SINGLE，表示单日期。|
|customColor|[ResourceColor](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-types#resourcecolor)|否|定制颜色，取值范围： * 所选日期背景色 * 当日字体 * 箭头 * 年月滚轮|
|customFontColor|[ResourceColor](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-types#resourcecolor)|否|定制未选中的文字颜色。|
|startDayOfWeek|number|否|一周起始天。取值范围：0\~6之间的整数。 默认值为0，表示星期天。|
|startYear|number|否|切换年月的起始年份，默认值为1900。|
|endYear|number|否|切换年月的结束年份，默认值为2100。|
|selected|Date|否|选中的单日期，默认值为当前系统日期。|
|selectDates|Date\[\]|否|选中的多日期、时间段。 * 多日期的默认值为当前系统日期。 * 时间段只取前两个日期作为开始和结束日期，默认值为当前系统日期开始的一周。|
|yOffset|number|否|弹窗垂直方向偏移量，默认垂直居中对齐。|
|customBuildPanel|() =\> void|否|自定义触发弹窗的控件。|

TypePicker枚举说明  

|名称|描述|
|:-------|:---|
|SINGLE|单日期。|
|MULTIPLE|多日期。|
|RANGE|时间段。|

#### 事件

|名称|描述|
|:------------------------------------------------------|:------------|
|onSelected(callback: (date: Date \| Date\[\]) =\> void)|日期选择完成后触发该事件。|

import { UICalendarPicker, TypePicker } from '@hw-agconnect/ui-calendar-picker';
​
// xxx.ets
@Entry
@Component
struct Index {
  @State selectedDate: Date = new Date(2024, 2, 1);
​
  build() {
    Column() {
      Text('自定义日期控件').fontSize(30)
      Column() {
        UICalendarPicker({
          type: TypePicker.SINGLE,
          customColor: Color.Pink,
          selected: this.selectedDate,
          onSelected: (date) => {
            this.selectedDate = date as Date;
          }
        }) {
          Text(this.selectedDate.toLocaleDateString())
            .fontSize(20)
            .fontColor(Color.Pink)
            .borderColor(Color.Pink)
            .borderWidth(1)
            .padding(10)
        }
​

    }
    .width('100%')
    .height('100%')
  }
}
