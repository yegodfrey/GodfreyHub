# ohAegEccVerifySignText

ohAegEccVerifySignText(text: string \| Uint8Array, pubKey: string \| Uint8Array, sign: string \| Uint8Array): Promise\<boolean\>

ECDSA公钥验签，配套[ohAegEccSignText](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ohaegeccsigntext-0000001910515581)和[ohAegEccSignTextBase64](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ohaegeccsigntextbase64-0000001864356230)接口使用，密钥类型、摘要算法等如下：  

|非对称密钥类型|摘要|API版本|
|:------|:-----|:----|
|ECC256|SHA256|11+|

导入模块：

```
import { AegEcc } from '@hw-agconnect/petal-aegis';
```

参数：  

|参数名|类型|必填|说明|
|:-----|:----------------|:-|:--------------------------------------------------------|
|text|string或Uint8Array|是|待验签的原文。|
|pubKey|string或Uint8Array|是|验签使用的公钥，base64编码过的字符串或Uint8Array。|
|sign|string或Uint8Array|是|签名值（使用ohAegEccSignText 或者 ohAegEccSignTextBase64 签名后的结果）。|

返回值：  

|参数|类型|说明|
|:---|:------|:------------------------|
|验签结果|boolean|返回验签结果，true:通过，false:不通过。|

示例一：

```
import { AegEcc } from '@hw-agconnect/petal-aegis';

async function ecdsasign() {
  let plainText = 'hello world'; //待签名内容
  //用于签名的私钥，长度256位，实际使用时建议使用ECC密钥生成方法生成，不能硬编码在代码中
  let priKey = 'MDECAQEEIHhx/XDnVZ+iUyHGReZWmoiuEDAi/1a6XpfsqgJwBwqIoAoGCCqGSM49AwEH';
  //用于验签的公钥，长度256位，实际使用时建议使用ECC密钥生成方法生成，不能硬编码在代码中
  let pubKey = 'MFkwEwYHKoZIzj0CAQYIKoZIzj0DAQcDQgAE4qxPKKFb9cpehr8MP2HGgl+38f7WZMQFaVSN7fddWGPriv8a7tIBDohMFMn9Ankdm9ZZFTOpzOH3O/iYebM61A==';

  try {
    let signText = await AegEcc.ohAegEccSignText(plainText, priKey);
    //ecdsasign  signText: 48,70,2,33,0,152,240,91,73,177,185,254,253,14,80,209,202,36,0,165,65,129,116,196,163,18,24,124,75,137,246,151,61,21,22,171,143,2,33,0,201,9,6,142,61,113,124,22,0,211,83,27,247,49,153,78,163,16,226,28,169,129,63,99,203,40,17,110,248,244,95,34
    console.log("ecdsasign ", 'signText: ' + signText);

    let decryptText = await AegEcc.ohAegEccVerifySignText(plainText, pubKey, signText);

    if (decryptText == true) {
      console.info('ecdsasign verify ok');
    }
  } catch (err) {
    console.log("ecdsasign ", 'err: ' + err);
  }
}
```
