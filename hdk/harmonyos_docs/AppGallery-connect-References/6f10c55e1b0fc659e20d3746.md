# MatchPlayerInfoParam

|Interface Info|
|:-------------------------------------------------|
|export interface MatchPlayerInfoParam 包含匹配规则的玩家信息。|

## Property Summary

|Name|Type|Description|
|:----------|:---------------------|:-------------------------------------------------------------------------------------------------------------------------|
|playerId|string|玩家联机对战账号ID。 > 说明 > 联机对战服务在初始化后，根据玩家ID为用户玩家生成的联机对战账号ID。|
|matchParams|Record<string, number>|自定义匹配参数，JSON结构，最多支持5条匹配规则。key为属性名，value为属性值，如 {'level' : 10 , 'score' : 100}。 > 说明 > 该参数中的属性名需要与matchCode所属规则中配置的玩家属性一一对应。|
