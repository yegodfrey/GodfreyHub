# 错误码

|错误码|值|描述|解决方法|
|:------------------------------------------------|:----|:---------------|:------------------------|
|FunctionErrorCode.GET_CREDENTIAL_NULL|12001|使用的凭证文件内容为空。|使用有效的认证凭据。|
|FunctionErrorCode.CLIENT_TYPE_ERROR|12002|agcClient数据类型错误。|使用有效的认证凭据。|
|FunctionErrorCode.GET_GW_URL_FAIL|12003|获取网关地址失败。|检查依赖包或认证凭据是否正确。|
|FunctionErrorCode.GET_ACCESS_TOKEN_FAIL|12004|获取accessToken失败。|请检查网络情况或认证凭据信息是否正确。|
|FunctionErrorCode.HTTP_TRIGGER_IS_NULL|12005|输入的被调用函数名为空。|请使用合规的参数内容。|
|FunctionErrorCode.CREATE_REST_CLIENT_FAIL|12006|创建restClient失败。|请检查commons依赖包是否导入正常。|
|FunctionErrorCode.TIMEOUT_OUT_OF_RANGE|12007|输入数值超出限定范围。|超时时间值范围(0, 55000\]，单位为ms。|
|FunctionErrorCode.REQUEST_BODY_INVALID_INPUT_TYPE|12008|输入参数类型无效。|请使用合规的参数内容。|
|FunctionErrorCode.RESPONSE_IS_NULL|12009|返回的响应体为空。|请检查被调用函数返回的内容情况。|
|FunctionErrorCode.RESPONSE_STATUS_IS_NULL|12010|返回的响应状态为空。|请检查请求或返回情况。|
|FunctionErrorCode.CONVERT_DATA_TYPE_FAILED|12011|转换数据类型失败。|请使用fastJson可进行转换的类型。|
|FunctionErrorCode.HTTP_STATUS_IS_NOT_SUCCESS|12012|返回的响应状态不是200。|请检查请求或返回情况。|
|FunctionErrorCode.SEND_REQUEST_FAILED|12013|发送调用请求失败。|请检查请求或返回情况。|
|FunctionErrorCode.GET_API_GW_URL_FAIL|12014|获取Api网关地址失败。|请检查网络情况或认证凭据信息是否正确。|
