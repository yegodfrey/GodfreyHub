# ListParam

|Interface Info|
|:--------------------------------------|
|export interface ListParam 列举文件操作的相关参数。|

## Parameters

|Name|Type|Mandatory/Optional (M/O)|Description|
|:---------|:-----|:-----------------------|:----------------------------------------------------------------------------------|
|cloudPath|string|O|云端文件的绝对路径，不传则为云端的根目录。|
|maxResults|number|O|列举文件的最大数量，不传则列举所有文件。|
|pageMarker|string|O|分页标识。 可使用上一次的列举结果对象（ListResult）中的pageMarker字段作为下一页的分页标识，再调用本方法获取下一页数据。若不传，则不进行分页获取。|
