# UploadOptions

|Interface Info|
|:----------------------------------------|
|export interface UploadOptions 上传请求的相关参数。|

#### Property Summary

|Name|Type|Description|
|:---------------|:--------------------|:-----------------------------------------------------------------------------------------|
|destination|string \| File|上传文件的目标位置。支持字符串和File对象两种参数类型，目标地址的命名取决于字符串内容和File对象的名称。如果未设置此参数，则使用本地文件名作为目标文件名，并忽略目录地址信息。|
|onUploadProgress|(event: any) =\> void|上传的回调进度函数。|
