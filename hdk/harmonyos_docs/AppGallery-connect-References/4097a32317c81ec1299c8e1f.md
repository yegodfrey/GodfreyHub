# ObjectTypeMapping

|interface info|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public @interface ObjectTypeMapping 定义对象类型的映射名。 您可以调用该方法映射java格式文件中不符合Java语言规范的对象类型名称。 您在AppGallery Connect控制台创建对象类型后，导出用于Android SDK应用开发的java类型文件，如果java格式的对象类型文件中有不符合Java语言规范的对象类型名称，您可以修改类名（即对象类型名称），并通过添加注解的方式建立云侧与本地开发环境中对象类型名称的映射关系，并在后续的开发中使用映射后的对象类型名称，使其适配语言规范格式。|
