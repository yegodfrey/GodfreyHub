# 查询软件包编译状态

## 功能介绍

此接口用于查询软件包的编译状态。接口调用者的角色：账号持有者、管理员、APP管理员。

## 接口原型

|承载协议|HTTPS GET|
|-----|--------------------------------------------------------------------------|
|接口方向|开发者服务器 -> 华为服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/publish/v2/package/compile/status|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 请求参数

## 响应参数

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:-----------|:----------|:-------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|ret|M|String(100)|包含返回码及描述信息的JSON字符串，格式为{"code":*retcode* , "msg": "*description* "}，retcode为返回码，description为返回码描述信息。返回码请参见[错误码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-publishingapi-errorcode-0000001163523297)。|
|pkgStateList|M|[PackageStates](#ZH-CN_TOPIC_0000001111685206__p0229956142012)|软件包列表。|

**PackageStates说明**

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:---------------|:----------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|pkgId|M|String|软件包id。|
|aabCompileStatus|O|Integer|此配置项即将废弃，新接入应用请使用successStatus获取结果。 编译状态。 取值范围： * 0：未发送 * 1：编译中 * 2：编译完成 * 3：编译失败|
|failReason|O|Integer|此配置项即将废弃，新接入应用请使用successStatus获取结果。 Android AAB软件包编译失败时返回的错误码。 取值范围： * 6：使用了动态下载功能，未正确集成华为[Dynamic Ability SDK](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-dynamicability-introduction-0000001057944549)。 * 7：Module配置不正确，universal apk无法正常运行。 * 8：使用了Asset Pack。 * 9：AAB包下载失败。 * 10：AAB包下载失败，AAB包为空。 * 11：AAB包格式有问题，无法解压。 * 12：AAB包使用bundletool解析失败。 * 13-18：AAB包编译失败。 * 19：AAB包超过上限150MB。|
|successStatus|M|Integer(32)|软件包状态汇总结果。 取值范围： * 0：正常 * 1：解析中 * 2：失败，表示软件包不可用|

## 调用示例

```screen
public static JSONObject getAabStatus(String domain, String clientId, String token, String appId, String pkgIds) {
	HttpGet get = new HttpGet(domain + "/publish/v2/package/compile/status?appId=" + appId + "&pkgIds=" + pkgIds);

	get.setHeader("Authorization", "Bearer " + token);
	get.setHeader("client_id", clientId);
	try {
		CloseableHttpClient httpClient = HttpClients.createDefault();
		CloseableHttpResponse httpResponse = httpClient.execute(get);
		int statusCode = httpResponse.getStatusLine().getStatusCode();
		if (statusCode == HttpStatus.SC_OK) {
			BufferedReader br =
				new BufferedReader(new InputStreamReader(httpResponse.getEntity().getContent(), Consts.UTF_8));
			String result = br.readLine();

			// Object returned by the app information query API, which can be received using the AppInfo object. For details, please refer to the API reference.
			JSONObject object = JSON.parseObject(result);

			return object;
		}
	} catch (Exception e) {

	}
	return null;
}
```
