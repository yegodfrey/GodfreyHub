# DatabaseCollection

云数据库待操作表的DatabaseCollection对象，通过该类提供对该表数据的增、删、改、查等操作。

## Summary

|Qualifier and Type|Method name|
|:-------------------|:---------------------------------------------------------------------------------|
|Promise<number>|[upsert](#section108601543193811)<T>(objectList: T[] | T) 将一个或者多个对象写入到当前存储区。|
|Promise<number>|[delete](#section11094764018)<T>(objectList: T[] | T) 删除存储区中与传入对象主键值相同的一个或者多个对象。|
|DatabaseZoneQuery<T>|[query](#section1894820514118)() 获取DatabaseZoneQuery对象，开始构造查询条件。如果不构造查询条件，则默认全量查询。|

## Methods

### upsert

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|upsert<T>(objectList: T[] | T): Promise<number> 将一个或者多个对象写入到当前存储区。 如果在存储区中已经存在主键值相同的对象，则更新已有的对象；如果不存在，则写入一个或者多个新的对象。 调用本方法需要遵循以下约束： * 写入多个对象时，数据总大小不能超过2MB，否则会导致写入失败。 * 写入多个对象时，数据总条数不能超过1000条，否则会导致写入失败。|

**Parameters**

|Parameter name|Parameter desc|
|:------------------|:-------------|
|objectList: T[] | T|一个或者多个待写入的对象。|

**Return**

|type|desc|
|:--------------|:----------------------------------------------------------|
|Promise<number>|Promise对象。通过此Promise对象可以异步获取操作结果，写入成功返回写入成功的条数，写入失败则返回异常信息。|

**Sample Code**

```screen
let record = collection.upsert({
"id":2000,
"bookName" : "book_name_002",
"author" : "huawei2",
"price" : 1020
});
```

或者

```screen
let bookInfo = new BookInfo();
bookInfo.setId(2000);
bookInfo.setBookName("book_name_002");
bookInfo.setAuthor("huawei2");
bookInfo.setPrice(1020);
let record = collection.upsert(bookInfo);
```

### delete

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|delete<T>(objectList: T[] | T): Promise<number> 调用此方法删除存储区中与传入对象主键值相同的一个或者多个对象。删除操作只关注对象的主键值是否相同，不考虑对象其它属性和存储的数据是否匹配。如果存储区中不存在相同主键值的对象，调用此方法将不做任何操作，对存储区无影响，执行结果为成功。 调用本方法需要遵循以下约束： * 删除多个对象时，数据总大小不能超过2MB，否则会导致删除失败。 * 删除多个对象时，数据总条数不能超过1000条，否则会导致删除失败。|

**Parameters**

|Parameter name|Parameter desc|
|:------------------|:-------------|
|objectList: T[] | T|一个或者多个待删除的对象。|

**Return**

|type|desc|
|:--------------|:-----------------------------------------------------------|
|Promise<number>|Promise对象。 通过此Promise对象可以异步获取操作结果，删除成功返回删除成功的条数，删除失败则返回异常信息。|

**Sample Code**

```screen
let record = collection.delete({
"id":2000
});
```

或者

```screen
let bookInfo = new BookInfo();
bookInfo.setId(2000);
let record = collection.delete(bookInfo);
```

### query

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------|
|query(): DatabaseZoneQuery<T> 调用此方法获取DatabaseZoneQuery对象，DatabaseZoneQuery对象中提供了诸如equalTo()、notEqualTo()、in()等一系列谓词查询来构造查询条件，最后调用get()方法来执行查询操作。|

**Return**

|type|desc|
|:-------------------|:-----------------------------------------------------------------|
|DatabaseZoneQuery<T>|表的DatabaseZoneQuery对象，通过该对象可以构造诸如equalTo()、notEqualTo()、in()等查询条件。|

**Sample Code**

```screen
let query: DatabaseZoneQuery<BookInfo> = collection.query()
```
