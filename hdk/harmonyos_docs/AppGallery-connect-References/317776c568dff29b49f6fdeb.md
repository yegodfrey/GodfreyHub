# ohAegAesCbcDecText

ohAegAesCbcDecText(text: string | Uint8Array, key: string | Uint8Array): Promise<string>

AES-CBC解密算法，配套[ohAegAesCbcEncText](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ohaegaescbcenctext-0000001866096105)接口使用，分组模式、填充模式如下：

|分组模式|密钥长度（bit）|填充模式|API版本|
|:---|:----------|:----|:----|
|CBC|128|192|256|PKCS7|11+|

**导入模块** **：**

```typescript
import { AegAesCbc } from '@hw-agconnect/petal-aegis';
```

**参数** **：**

|参数名|类型|必填|说明|
|:---|:---------|:-|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|text|Uint8Array|是|待解密内容（使用[ohAegAesCbcEnc](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ohaegaescbcenc-0000001910092457)加密的结果），格式为**iv:密文**或者同类的Uint8Array格式。|
|key|Uint8Array|是|明文工作密钥。|

**返回值：**

|参数|类型|说明|
|:----------|:-----|:---------|
|decryptText|String|解密后的明文字符串。|

**示例：**

```typescript
import { AegAesCbc } from '@hw-agconnect/petal-aegis';
import { buffer } from '@kit.ArkTS';

async function aescbc() {
  let plainText = 'hello world'; //待加密内容
  let key = '1234567891234567'; //长度16字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let iv = '9876543217654321'; //长度16字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let keyUint8 = new Uint8Array(buffer.from(key, 'utf-8').buffer);
  let ivUint8 = new Uint8Array(buffer.from(iv, 'utf-8').buffer);

  try {
    let encryptText = await AegAesCbc.ohAegAesCbcEncText(plainText, keyUint8, ivUint8);
    //aescbc  encryptText: 57,56,55,54,53,52,51,50,49,55,54,53,52,51,50,49,58,133,226,121,40,63,164,152,8,118,113,218,94,73,63,83,218
    console.log("aescbc ", 'encryptText: ' + encryptText);

    let decryptText = await AegAesCbc.ohAegAesCbcDecText(encryptText, keyUint8);

    if (plainText === decryptText) {
      console.info('decrypt ok');
    }
    console.log("aescbc ", 'decryptText: ' + decryptText);
  } catch (err) {
    console.log("aescbc ", 'err: ' + err);
  }
}
```
