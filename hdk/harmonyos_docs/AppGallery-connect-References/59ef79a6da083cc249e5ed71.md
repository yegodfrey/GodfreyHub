# rsaEncTextSync

rsaEncTextSync(alg: RSAAlg, plaintext: string, pubKey: string \| Uint8Array): Uint8Array

rsa加密算法同步方法，返回Uint8Array格式密文，建议与[rsaDecTextSync](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/rsadectextsync-0000002302040466)配套使用。

导入模块：

```
import { aegis } from '@hw-agconnect/petal-aegis';
```

参数：  

|参数名|类型|必填|说明|
|:--------|:-----------------------------------------------------------------------------------------------------------|:-|:----------------------------|
|alg|[RSAAlg](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/rsaalg-0000002335959885)|是|RSA模式枚举。|
|plaintext|string|是|待加密的明文内容， string为普通字符串。|
|publicKey|string或Uint8Array|是|加密使用的公钥，Base64字符串或Uint8Array。|

返回值：  

|参数|类型|说明|
|:----------|:---------|:------|
|encryptText|Uint8Array|加密后的密文。|
