# Overview

## 服务调用

Database

获取Database服务。

举例：

```screen
let database: Database = cloud.database(config: DatabaseConfig)
```

## Summary

### Interface

|Interface||
|:-------|------------------------------|
|Database|Database的入口，通过该接口获取Database服务。|

### Classes

|Classes||
|:-----------------|------------------------------------------------------------------|
|DatabaseCollection|云数据库的DatabaseCollection对象，通过该类实现数据的创建、删除、更新和查询等操作。|
|DatabaseZoneQuery|提供诸如equalTo()、notEqualTo()、in()等一系列谓词查询来构造查询条件，最后调用get()方法来执行查询操作。|
|DatabaseException|Database的异常类，用于获取异常的错误码和错误信息。|

### Type

|type||
|:-------------|----------------------------------------|
|ObjectTypeInfo|schema属性，无需自己构造，直接导入控制台下载的schema文件即可。|
|DatabaseConfig|Database服务的属性，包括schema属性、存储区名字、traceId等。|
