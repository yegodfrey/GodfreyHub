# 撤销用户凭据

#### 功能介绍

此接口用于撤销已经颁发的用户访问凭据。  

#### 使用约束

* 接口调用者的角色：管理员、APP管理员、开发。
* 接口调用次数限制：500个请求/client_id/秒  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者服务器-\>华为认证服务|
|接口URL|https://{domain}/api/oauth2/third/v1/revoke-token?productId={productId} 中国站点的domain：connect-api.cloud.huawei.com 德国站点的domain：connect-api-dre.cloud.huawei.com 新加坡站点的domain：connect-api-dra.cloud.huawei.com 俄罗斯站点的domain：connect-api-drru.cloud.huawei.com 注意： 调用[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)接口时使用的域名必须与本接口域名保持一致，例如本接口使用"connect-api-dre.cloud.huawei.com"，则调用[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)接口必须使用"https://connect-api-dre.cloud.huawei.com/api/oauth2/v1/token"。|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|
|-----|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### 请求参数

#### Query

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:--------|:----------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------|
|productId|M|String|项目ID，查询方法可参见[查询项目ID](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-developerid-projectid-0000001166543063)。|

#### Header

![](https://media:801773135264206142)  
本接口支持使用Service Account方式和API客户端方式，二者区别请参见[获取服务端API授权](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-obtain-apiauthorization-0000001374178549)。

Service Account方式  

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|uid|M|String|待撤销凭据的用户。|
|Authorization|M|String|认证信息，格式为"Authorization: Bearer ${JWT}"。JWT为[通过Service Account方式获取授权](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-obtain-apiauthorization-0000001374178549#section276512551310)中获取的鉴权令牌。|

API客户端方式  

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|M|String|客户端ID，获取方法参考[创建API客户端](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-obtain-apiauthorization-0000001374178549#section186371930132016)。|
|uid|M|String|待撤销凭据的用户。|
|Authorization|M|String|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain-token-project-0000001477336048)中获取的access_token。|

```

Content-Type: application/json
client_id: 680************560

```

#### 响应参数

|参数|必选（M）/可选（O）|参数类型|描述|
|:--|:----------|:----------|:--------------------------------------------------------------------------------------------|
|ret|M|String(100)|包含返回码及描述信息的JSON字符串，格式为{"code":retcode, "msg": "description"}，retcode为返回码，description为返回码描述信息。|

#### 响应示例

```
{
	"ret": {
		"code": 0,
		"msg": "OK"
	}
}
```

#### 调用示例

```
"Java"
    /**
     * 撤销用户凭据
     *
     * @param productId 项目ID
     * @param uid 待撤销的token的用户ID
     * @param client_id clientID
     * @param clientToken clientToken
     */
    public static void revokeTokenServer(String productId, String uid, String client_id, String clientToken) {
        HttpPost post = null;
        CloseableHttpClient httpClient = null;
        try {
            /** 新建POST请求 */
            post = new HttpPost(
                "https://connect-api.cloud.huawei.com/api/oauth2/third/v1/revoke-token?productId=" + productId);

            /** 设置Header认证信息 */
            post.setHeader("uid", uid);
            post.setHeader("client_id", client_id);
            post.setHeader("Authorization", "Bearer " + clientToken);
            /** 发送请求 */
            httpClient = HttpClients.createDefault();
            HttpResponse response = httpClient.execute(post);
            /** 处理返回参数 */
            int statusCode = response.getStatusLine().getStatusCode();
            if (statusCode == HttpStatus.SC_OK) {
                BufferedReader br =
                    new BufferedReader(new InputStreamReader(response.getEntity().getContent(), Consts.UTF_8));
                String result = br.readLine();
                JSONObject object = JSON.parseObject(result);
                String retCode = object.getJSONObject("ret").getString("code");
                System.out.println(retCode);
            }
        } catch (Exception e) {
            e.printStackTrace();
        } finally {
            try {
                if (Objects.nonNull(post)) {
                    post.releaseConnection();
                }
                if (Objects.nonNull(httpClient)) {
                    httpClient.close();
                }
            } catch (Exception e) {
                e.printStackTrace();
            }
        }
    }
```
