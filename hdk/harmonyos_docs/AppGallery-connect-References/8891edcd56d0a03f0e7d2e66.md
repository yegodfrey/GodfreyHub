# hashHex

hashHex(alg:HashAlg, plaintext:string): Promise<string>

消息摘要算法，返回16进制的hex string格式密文。

**导入模块：**

```typescript
import { aegis } from '@hw-agconnect/petal-aegis';
```

**参数** **：**

|参数名|类型|必填|说明|
|:--------|:-------------------------------------------------------------------------------------------------------------|:-|:--------|
|alg|[HashAlg](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/hashalg-0000001964740733)|是|HASH模式枚举。|
|plaintext|string|是|明文普通字符串。|

**返回值：**

|参数|类型|说明|
|:--|:--------|:-----------------|
|字符串|hexString|生成的加密hexString字符串。|

**示例：**

```typescript
import { aegis } from '@hw-agconnect/petal-aegis';
import { buffer } from '@kit.ArkTS';

async function demo() {
  let plainText = 'hello world';   
  try {
    let hashStr: string = await aegis.hashHex(aegis.HashAlg.SHA256, plainText);
    //hash: b94d27b9934d3e08a52e52d7da7dabfac484efe37a5380ee9088f7ace2efcde9
    console.log('hash: ' + hashStr);
  } catch (err) {
    console.log('err: ' + err);
  }
}
```
