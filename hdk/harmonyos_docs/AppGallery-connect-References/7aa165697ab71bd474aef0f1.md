# PgdHybrid

|Class/Struct Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public abstract class PgdHybrid<tauthoring> where TAuthoring : Component</tauthoring> PgdHybrid<TAuthoring>是混合模式Authoring脚本的抽象基类，TAuthoring约束为UnityEngine.Component，用于在MonoBehaviour/组件中方便地访问Pgd Entity、ECS组件以及对象池。 开发者使用该基类进行混合模式开发时可忽略对象池底层逻辑，仅需配置ECS Entity组件并挂载至团结引擎Editor场景中，便可实现混合模式的初始化，类型定义位于Pgd插件包的Runtime/Hybrid/PgdHybrid.cs。|

## Property Summary

|Name|Type|Description|
|:---------|:--------|:-------------------------------------------------------------|
|TAuthoring|Component|继承自UnityEngine.Component的Authoring组件类型。 一般为具体业务的MonoBehaviour。|

## Methods

### Handle

|Method|
|:-----------------------------------------------------------------------------------------------|
|abstract void Handle(TAuthoring authoring) 派生类必须实现的核心逻辑入口。 用于基于传入的Authoring组件配置或更新对应的ECS Entity。|

**Parameters**

|Name|Type|Description|
|:--------|:---------|:--------------------|
|authoring|TAuthoring|当前正在处理的Authoring组件实例。|

**Sample Code**

```screen
using Pgd;
using UnityEngine;

public class EnemyAuthoring : MonoBehaviour
{
    public float moveSpeed = 5f;

    public class EnemyHybrid : PgdHybrid<EnemyAuthoring>
    {
        public override void Handle(EnemyAuthoring authoring)
        {
            // 获取或创建与该Authoring关联的模板Entity
            var entity = GetHybridEntity(authoring);

            // 将Authoring中的配置同步到ECS组件
            AddComponent(entity, new EnemyComponent
            {
                MoveSpeed = authoring.moveSpeed
            });
        }
    }
}

public struct EnemyComponent : IComponent
{
    public float MoveSpeed;
}
```

### GetHybridEntity

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------|
|protected IEntity GetHybridEntity() 通过当前Hybrid所在MonoBehavior，直接获取或初始化其挂载的GameObject对应的模板Entity。 若未设置上下文将抛出InvalidOperationException。|

**Return**

|Type|Description|
|:------|:--------------------------|
|IEntity|与当前上下文Authoring对应的模板Entity。|

**Sample Code**

```screen
using Pgd;
using UnityEngine;

public class EnemyAuthoring : MonoBehaviour
{
    public float moveSpeed = 5f;

    public class EnemyHybrid : PgdHybrid<EnemyAuthoring>
    {
        public override void Handle(EnemyAuthoring authoring)
        {
            // 自动获取当前Mono脚本挂载GameObject的模板Entity
            var entity = GetHybridEntity();
        }
    }
}
```

### GetHybridEntity

|Method|
|:---------------------------------------------------------------------------------------------|
|protected IEntity GetHybridEntity(GameObject prefab) 通过给定的Prefab或场景GameObject获取或按需初始化模板Entity。|

**Parameters**

|Name|Type|Description|
|:-----|:---------|:----------------|
|prefab|GameObject|用作模板的Prefab或场景实例。|

**Return**

|Type|Description|
|:------|:-------------------------------------------------------------|
|IEntity|与指定GameObject关联的模板Entity。 若prefab为空，则会抛出ArgumentNullException。|

**Sample Code**

```screen
public class GenericHybrid : PgdHybrid<EnemyAuthoring>
{
    public override void Handle(EnemyAuthoring authoring)
    {
        var entity = GetHybridEntity(authoring.gameObject);
        // 为该GameObject的模板Entity添加其他组件
    }
}
```

### GetComponent

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------|
|protected TComponent GetComponent() where TComponent : Component 从当前Hybrid上下文Authoring组件上获取指定类型的组件，在上下文未设置时抛出InvalidOperationException。|

**Return**

|Type|Description|
|:---------|:------------------------------------|
|TComponent|从上下文Authoring上获取到的组件实例。 若未找到，则返回null。|

**Sample Code**

```screen
public class HybridWithAnimator : PgdHybrid<EnemyAuthoring>
{
    public override void Handle(EnemyAuthoring authoring)
    {
        // 从当前Authoring对象上获取Animator组件
        var animator = GetComponent<Animator>();
    }
}
```

### AddComponent

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|protected bool AddComponent(IEntity entity, T component) where T : struct, IComponent 向指定ECS Entity上添加一个给定值的组件，相当于调用entity.AddComponent(in component)。 用于在Hybrid中为实体配置数据。|

**Parameters**

|Name|Type|Description|
|:--------|:------|:------------|
|entity|IEntity|需要被添加组件的目标实体。|
|component|T|要添加到实体上的组件值。|

**Return**

|Type|Description|
|:---|:-----------------------------|
|bool|* true：添加成功。 * false：实体已包含该组件。|

**Sample Code**

```screen
public class HybridAddComponent : PgdHybrid<EnemyAuthoring>
{
    public override void Handle(EnemyAuthoring authoring)
    {
        var entity = GetHybridEntity(authoring);
        var data = new EnemyComponent { MoveSpeed = authoring.moveSpeed };
        AddComponent(entity, data);
    }
}
```

### AddComponent

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------|
|protected bool AddComponent(IEntity entity) where T : struct, IComponent 向指定ECS Entity上添加一个默认值的组件，相当于调用entity.AddComponent<T>()。|

**Parameters**

|Name|Type|Description|
|:-----|:------|:------------|
|entity|IEntity|需要被添加组件的目标实体。|

**Return**

|Type|Description|
|:---|:-----------------------------|
|bool|* true：添加成功。 * false：实体已包含该组件。|

**Sample Code**

```screen
public struct Tag_Enemy : IComponent {}

public class HybridAddDefaultComponent : PgdHybrid<EnemyAuthoring>
{
    public override void Handle(EnemyAuthoring authoring)
    {
        var entity = GetHybridEntity(authoring);
        // 为实体添加一个标记组件
        AddComponent<Tag_Enemy>(entity);
    }
}
```

### SetComponent

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|protected void SetComponent(IEntity entity, T component) where T : struct, IComponent 设置或覆盖指定ECS Entity上的组件值，相当于调用entity.Set(in component)。 适用于在Hybrid逻辑中更新已有组件的数据。|

**Parameters**

|Name|Type|Description|
|:--------|:------|:------------------|
|entity|IEntity|需要被更新组件值的目标实体。|
|component|T|新的组件值，将覆盖实体上的同类型组件。|

**Sample Code**

```screen
public class HybridSetComponent : PgdHybrid<EnemyAuthoring>
{
    public override void Handle(EnemyAuthoring authoring)
    {
        var entity = GetHybridEntity(authoring);
        // 覆盖已有EnemyComponent的MoveSpeed
        SetComponent(entity, new EnemyComponent
        {
            MoveSpeed = authoring.moveSpeed * 1.2f
        });
    }
}
```
