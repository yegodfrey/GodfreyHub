# 申请下载链接

## 功能介绍

此接口用于生成一个固定链接，支持全屏/MINI详情页直接下载的能力。

## 接口原型

|承载协议|HTTPS POST|
|-----|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|接口方向|合作平台服务器->应用市场服务器|
|接口URL|**https://** *{domain}* **/api/agd/cbs/v2/agd-link-generate** * 中国站点的domain：connect-api.cloud.huawei.com * 德国站点的domain：connect-api-dre.cloud.huawei.com * 新加坡站点的domain：connect-api-dra.cloud.huawei.com * 俄罗斯站点的domain：connect-api-drru.cloud.huawei.com|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|

## 请求参数

### Header

|参数|必选(M)/可选(O)|类型|描述|
|:------------|:----------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|M|String|客户端ID，获取方法请参见[创建API客户端](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section103mcpsimp)。|
|Authorization|M|String|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)中获取的access_token。|

### Body

|参数名称|必选(M)/可选(O)|类型|说明|
|:------------|:----------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
|appName|O|String(256)|被分发的应用名。|
|callerAppName|O|String(255)|媒体app名。|
|callerPkgName|M|String(128)|媒体包名。|
|channelPkgId|O|String(255)|渠道包ID，对应AGC页面"渠道包管理"中的"包内渠道编码"。|
|detailType|M|String(4)|用户点击链接下载应用后的安装方式。 * 6：全屏详情页，手动安装。|
|pkgName|M|String(128)|被分发的应用包名。|
|referrer|O|String(255)|归因参数，当您需要进行后续的归因分析时，可参考[高阶归因分析](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agdlink-analysis-refer-0000001117762116)。|
|ts|M|String(255)|发送请求的UTC时间戳。|
|country|O|String(2)|申请链接的国家码（ISO编码，例如：CN，RU），需要和后续链接实际使用的国家保持一致。|

## 响应参数

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:--------|:----------|:------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|link|M|String|生成的应用下载链接，字段参数参考[link参数详情](#ZH-CN_TOPIC_0000001198049129__p63661549123110)。例如 : hiapplink://com.huawei.appmarket?appId=C9136&callType=AGDAPI&channelId=xxx&detailType=6&referrer=0&id=07a356ad623b43deaf323bc5bcc5be01&s=DFB47D13E799F12F0EF62E1B485AC7B01466D76CA562D2D0312C191DF48C83A8&pkgId=test&v=1.0&callParam=%7B%22partnerInfo%22%3A%7B%22partnerId%22%3A%22testAGCid2%22%2C%22pkgId%22%3A%22test%22%7D%2C%22taskInfo%22%3A%22test2%22%7D|
|expire|O|String|链接有效期，单位：秒。 > 说明 > 该值为申请开通权限时由运营进行配置，请按具体需要填写。|
|dependGms|O|Integer|是否依赖GMS。 * 0：不依赖 * 1：依赖|
|rtnCode|M|String|返回码，请参见[错误码](#section1537715511869)。|
|rtnDesc|M|String|返回码描述。|

**link参数详情**：

|参数|说明|
|:---------|:------------------------------------------------------------------------------------------------------|
|appId|应用ID。|
|callType|固定为"AGDAPI"。|
|channelId|请求的媒体包名。|
|detailType|下载安装方式。|
|referrer|请求的referrer，如果没有传归因参数则为0。|
|id|链接一次性唯一ID。|
|s|链接签名信息。|
|v|华为应用市场依赖的版本兼容参数。|
|pkgId|渠道包ID。|
|callParam|推广任务，为经过URLEncode的JSON格式，包括： "taskInfo": "推广任务Id" "partnerInfo"：{"partnerId": "112", "pkgId": "渠道包ID" }|

## 调用示例

```screen
"Java"
    public static void generate(String domain, String token, String clientId){
        HttpPost put = new HttpPost(domain + "/cbs/v2/agd-link-generate");

        put.setHeader("Authorization", "Bearer " + token);
        put.setHeader("client_id", clientId);

        JSONObject keyString = new JSONObject();
        // Configure the app to be free of charge.
        keyString.put("callerPkgName", "test.api.agd.supportteam");//Please replace with your media application package name
        keyString.put("detailType", 7);//Please replace with your installation method
        keyString.put("pkgName", "com.huawei.appmarket");//Please replace with the package name of the application to be distributed
        keyString.put("ts", 202102261419L);
        StringEntity entity = new StringEntity(keyString.toString(), Charset.forName("UTF-8"));
        entity.setContentEncoding("UTF-8");
        entity.setContentType("application/json");
        put.setEntity(entity);

        try {
            CloseableHttpClient httpClient = HttpClients.createDefault();
            CloseableHttpResponse httpResponse = httpClient.execute(put);
            int statusCode = httpResponse.getStatusLine().getStatusCode();
            if (statusCode == HttpStatus.SC_OK) {
                BufferedReader br =
                    new BufferedReader(new InputStreamReader(httpResponse.getEntity().getContent(), Consts.UTF_8));
                String result = br.readLine();
                System.out.println(result);
            }
        } catch (Exception e) {
            System.out.println(e);
        }
    }
```
