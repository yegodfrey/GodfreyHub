# FFDrawFrameFlagsInfo

用于预测帧计算的标志信息。  
Structure Declaration

```
typedef struct FFDrawFrameFlagsInfo {
    FFStructureType     sType;
    const void*         pNext;
    FFDrawFrameFlags    flags;
} FFDrawFrameFlagsInfo;
```

Members  

|Name|Mandatory/Optional|Description|
|:----|:-----------------|:------------------------------------------------|
|sType|必填|此结构体类型必须为FF_STRUCTURE_TYPE_DRAW_FRAME_FLAGS_INFO。|
|pNext|选填|指向扩展链中的下一个结构体的指针。扩展参数，可缺省，默认值为NULL。|
|flags|必填|用于预测帧计算的标志。|
