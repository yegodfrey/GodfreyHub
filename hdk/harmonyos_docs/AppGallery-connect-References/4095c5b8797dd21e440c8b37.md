# ohAegSMDecText

ohAegSMDecText(text: string \| Uint8Array, key: string \| Uint8Array): Promise\<string\>

SM4-CBC解密算法，配套[ohAegSMEncText](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ohaegsmenctext-0000001864225580)接口使用，分组模式、填充模式如下：  

|分组模式|密钥长度（bit）|填充模式|API版本|
|:---|:--------|:----|:----|
|CBC|128|PKCS7|11+|

导入模块：

```
import { AegSM } from '@hw-agconnect/petal-aegis';
```

参数：  

|参数名|类型|必填|说明|
|:---|:----------------|:-|:----------------------------------------------------|
|text|string或Uint8Array|是|待解密内容（ohAegSMEncText加密后的结果），格式为iv:密文或者同类的Uint8Array格式|
|key|string或Uint8Array|是|解密使用的密钥（string类型的key需要使用16进制编码格式）。|

返回值：  

|参数|类型|说明|
|:----------|:-----|:---------|
|decryptText|String|解密后的明文字符串。|

示例：

```
import { AegSM } from '@hw-agconnect/petal-aegis';
import { buffer } from '@kit.ArkTS';

async function sm4cbc1() {
  let plainText = 'hello world'; //待加密内容
  let key = '1234567891234567'; //长度16字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let iv = '9876543217654321'; //长度16字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let keyUint8 = new Uint8Array(buffer.from(key, 'utf-8').buffer);
  let ivUint8 = new Uint8Array(buffer.from(iv, 'utf-8').buffer);

  try {
    let encryptText = await AegSM.ohAegSMEncText(plainText, keyUint8, ivUint8);
    //sm4cbc1  encryptText: 57,56,55,54,53,52,51,50,49,55,54,53,52,51,50,49,58,155,33,239,15,249,8,1,141,7,122,48,126,61,60,108,22
    console.log("sm4cbc1 ", 'encryptText: ' + encryptText);
    let decryptText = await AegSM.ohAegSMDecText(encryptText, keyUint8);
    if (plainText === decryptText) {
      console.info('sm4cbc1 decrypt ok');
    }
    console.log("sm4cbc1 ", 'decryptText: ' + decryptText);
  } catch (err) {
    console.log("sm4cbc1 ", 'err: ' + err);
  }
}
```
