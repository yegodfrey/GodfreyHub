# sm4EncSync

sm4Enc(alg: SM4Alg, plaintext: Uint8Array, key: string | Uint8Array, iv?: string | Uint8Array): Promise<Uint8Array>

sm4加密算法同步方法，返回Uint8Array格式密文，建议与[sm4DecSync](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/sm4decsync-0000002283835440)配套使用。

**导入模块：**

```typescript
import { aegis } from '@hw-agconnect/petal-aegis';
```

**参数** **：**

|参数名|类型|必填|说明|
|:--------|:-----------------------------------------------------------------------------------------------------------|:-|:--------------------------------------------------------------------------------------|
|alg|[SM4Alg](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/sm4alg-0000001937701454)|是|SM4模式枚举。|
|plaintext|Uint8Array|是|明文内容。|
|key|string或Uint8Array|是|密钥内容，hexstring或Uint8Array格式， 长度请参考模式SM4Alg的密钥长度（bit）。|
|iv|string或Uint8Array|否|iv偏移量内容，hexstring或Uint8Array格式，如果传入IV，返回结果的密文中不会携带iv，如果不传入iv，返回的密文结果会携带自动生成的IV，长度为16字节。|

**返回值：**

|参数|类型|说明|
|:----------|:---------|:------|
|encryptText|Uint8Array|加密后的密文。|
