# Overview

Dynamic Ability服务包。  

#### Interface Summary

|Interface|Description|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------|:------------------------|
|[FeatureInstallManager](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/featureinstallmanager-0000001057944555)|负责统一管理从华为应用市场动态加载整个过程的接口。|
|[InstallStateListener](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/installstatelistener-0000001059050276)|监听App中动态加载状态的监听器接口。|
|[FeatureTask](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/featuretask-0000001057492597)|表示执行一次动态加载的任务抽象类。|

#### Class Summary

|Class|Description|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[FeatureInstallRequest](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/featureinstallrequest-0000001057642233)|包含了向华为应用市场请求动态加载的信息。|
|[FeatureCompat](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/featurecompat-0000001057762241)|动态加载Split APK的入口类。|
|[FeatureInstallManagerFactory](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/featureinstallmanagerfactory-0000001057642235)|创建[FeatureInstallManager](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/featureinstallmanager-0000001057944555)的工厂类。|
|[OnFeatureSuccessListener](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/onfeaturesuccesslistener-0000001058092551)|动态加载任务中表示加载成功的监听器类。|
|[OnFeatureFailureListener](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/onfeaturefailurelistener-0000001058572526)|动态加载任务中表示加载失败的监听器类。|
|[OnFeatureCompleteListener](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/onfeaturecompletelistener-0000001058442234)|动态加载任务中表示加载完成的监听器类。无论加载成功还是失败，均属于加载完成。|
|[FeatureInstallSessionStatus](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/featureinstallsessionstatus-0000001058092553)|在执行动态加载任务过程中，表示各个状态的状态码类。|
|[FeatureInstallErrorCode](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/featureinstallerrorcode-0000001057642245)|在执行动态加载任务过程中，表示失败的错误码类。|

#### Exception Summary

|Exception|Description|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------|
|[CommonInstallException](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/commoninstallexception-0000001058572528)|动态加载过程失败的异常类。|
|[FeatureInstallException](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/featurelnstallexception-0000001057762253)|动态加载过程中安装阶段失败的异常类。|
