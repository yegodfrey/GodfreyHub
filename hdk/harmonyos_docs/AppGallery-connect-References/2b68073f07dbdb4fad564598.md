# TokenResult

登录用户的Token信息。

## Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:------------------------------------------------------------|
|String|[getToken](#section392617261028)() 返回当前登录的用户token信息。|
|number|[getExpirePeriod](#section166317548416)() 返回当前登录的用户token的有效期。|

## Methods

### getToken

|Method|
|:----------------------------------|
|getToken():string 返回当前登录的用户token信息。|

**Return**

|Type|Description|
|:-----|:----------|
|string|当前登录的用户信息。|

**Sample Code**

```screen
agconnect.auth().getCurrentUser().then(user => {
    if (user == null) {                       
        return;          
    }          
    user.getToken(false).then(tokenResult =>{            
        let tokenString = tokenResult.getToken();                    
    }).catch(err => {
        alert(err);        
    });
}
```

### getExpirePeriod

|Method|
|:-------------------------------------------|
|getExpirePeriod():number 返回当前登录的用户token的有效期。|

**Return**

|Type|Description|
|:-----|:----------------|
|number|获取Token的有效期，单位为秒。|

**Sample Code**

```screen
agconnect.auth().getCurrentUser().then(user => {
    if (user == null) {                       
        return;          
    }          
    user.getToken(false).then(tokenResult =>{            
        let tokenPeriod = tokenResult.getExpirePeriod();                    
    }).catch(err => {
        alert(err);        
    });
}
```
