# FFVKDrawFrameInfo

绘制预测帧信息。

**Structure Declaration**

```screen
typedef struct FFVKDrawFrameInfo {
    FFStructureType    sType;
    const void*        pNext;
    VkCommandBuffer    vkCommandBuffer;
    uint8_t            frameIdx;
    FFVKImage          targetImage;
    FFVKImageSync      targetInitialSync;
    FFVKImageSync      targetFinalSync;
    FFBool             doDraw;
} FFVKDrawFrameInfo;
```

**Members**

|Name|Mandatory/Optional|Description|
|:----------------|:-----------------|:-----------------------------------------------------------------------------------------|
|sType|Mandatory|此结构体类型必须为**FF_STRUCTURE_TYPE_DRAW_FRAME_INFO**。|
|pNext|Optional|指向功能扩展链中的下一个结构体的指针。扩展参数，可缺省，默认值为NULL。|
|vkCommandBuffer|Mandatory|Vulkan的命令缓冲区。|
|frameIdx|Mandatory|飞行中的帧编号，需小于framesInFlight。|
|targetImage|Mandatory|注册后用于预测帧的图像资源。当[doDraw](#ZH-CN_TOPIC_0000001791334740__p13450152411593)为FF_TRUE时，此值必须为非零值。|
|targetInitialSync|Mandatory|预测帧的同步初始信息，用于Vulkan的渲染同步控制。|
|targetFinalSync|Mandatory|预测帧的同步最终信息，用于Vulkan的渲染同步控制。|
|doDraw|Mandatory|是否执行绘制。 * FF_TRUE：执行绘制。 * FF_FALSE：不执行绘制。|
