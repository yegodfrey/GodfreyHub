# Transaction

Transaction类用来描述一个事务，事务内提供[executeQuery()](#section99171302912)、[executeUpsert()](#section57761025132914)和[executeDelete()](#section1078512333289)方法，实现对云侧存储区数据的管理操作，包含数据的增、删、改、查等。

* 事务仅在联网的情况下进行，一旦离线该事务操作将失败。
* 一个事务内可以进行多次数据操作，查询操作必须在写入操作和删除操作之前进行。
* 一个事务中包含的写入和删除对象的总条数不能超过1000条，且一个事务内的多次写入操作和 删除操作的数据总大小不能超过2MB。
* 一个事务中多次查询结果的总数据大小不能超过5MB，多次查询结果的总数据条数不能超过1000条。

## Summary

|Qualifier and Type|Method name|
|:-----------------|:-------------------------------------------------------------------------------------------------------|
|Promise<T[]>|[executeQuery](#section99171302912)<T>(cloudDBZoneQuery: CloudDBZoneQuery<T>) 在事务中从云侧存储区查询获取满足特定条件的对象集合。|
|Transaction|[executeUpsert](#section57761025132914)(objectList: T[]) 在事务中将一组对象批量写入到云侧存储区。|
|Transaction|[executeDelete](#section1078512333289)(objectList: T[]) 在事务中批量删除云侧存储区中的一组对象。|

## Methods

### executeQuery

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|executeQuery<T>(cloudDBZoneQuery: CloudDBZoneQuery<T>): Promise<T[]> 调用此方法在事务中从云侧存储区查询获取满足特定条件的对象集合。事务是原子的，事务内的操作要么全部成功，要么全部失败。 调用本方法需要遵循以下约束： * 仅在正常连接网络时可调用该方法实现查询功能，一旦离线该操作将失败。 * 事务中的查询操作必须在写入操作之前，否则将导致事务执行异常。 * 一个事务中多次查询结果的总数据大小不能超过5MB，否则会导致事务失败。 * 一个事务中多次查询结果的总数据条数不能超过1000条，否则会导致事务失败。|

**Parameters**

|Parameter name|Parameter desc|
|:------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|cloudDBZoneQuery: CloudDBZoneQuery<T>|一个CloudDBZoneQuery对象，表征查询条件。CloudDBZoneQuery类中提供了诸如where、equalTo、notEqualTo、greaterThan等方法，用以封装和实现查询的条件，具体可参见[CloudDBZoneQuery](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-web-0000001127836521)。|

**Return**

|type|desc|
|:-----------|:----------------------------------------------------------|
|Promise<T[]>|Promise对象。通过此Promise对象可以异步获取查询的数据列表，您可以根据该数据列表进行后续的写入和删除操作。|

### executeUpsert

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|executeUpsert(objectList: T[]): Transaction 调用此方法在事务中将一组对象批量写入到云侧存储区。事务是原子的，事务内的操作要么全部成功，要么全部失败。 调用本方法需要遵循以下约束： * 事务中的写入操作必须在查询之后，否则将导致事务执行异常。 * 仅在正常连接网络时可调用该方法实现写入功能，一旦离线该操作将失败。 * 一个事务内的多次写入操作和删除操作的数据总大小不能超过2MB，否则会导致事务失败。 * 一个事务中多次写入和删除操作的总数据条数不能超过1000条，否则会导致事务失败。 * 操作加密对象的数据条数过大时，建议分批多次写入。|

**Parameters**

|Parameter name|Parameter desc|
|:--------------|:---------------|
|objectList: T[]|一个数据列表，表示待写入的数据。|

**Return**

|type|desc|
|:----------|:------------------------|
|Transaction|一个事务对象，您可以在该返回值上定义其它事务操作。|

### executeDelete

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|executeDelete(objectList: T[]): Transaction 调用此方法在事务中批量删除云侧存储区中的一组对象。事务是原子的，事务内的操作要么全部成功，要么全部失败。删除操作只关注对象的主键是否一致，不考虑对象其它属性和存储的数据是否匹配。 调用本方法需要遵循以下约束： * 仅在正常连接网络时可调用该方法实现删除功能，一旦离线该操作将失败。 * 一个事务内的多次写入和删除操作的数据总大小不能超过2MB，否则会导致写入失败。 * 一个事务中多次写入和删除操作的总数据条数不能超过1000条，否则会导致事务失败。|

**Parameters**

|Parameter name|Parameter desc|
|:--------------|:---------------|
|objectList: T[]|一个数据列表，表示待删除的数据。|

**Return**

|type|desc|
|:----------|:-------------------------|
|Transaction|一个事务的对象，您可以在该返回值上定义其它事务操作。|
