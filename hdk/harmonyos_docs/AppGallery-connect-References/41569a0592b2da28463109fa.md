# sm4DecText

sm4DecText(alg: SM4Alg, ciphertext: Uint8Array, key: string \| Uint8Array, iv?: string \| Uint8Array): Promise\<string\>

sm4解密算法，返回解密后的明文内容字符串，建议与[sm4EncText](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/sm4enctext-0000001937542118)配套使用。

导入模块：

```
import { aegis } from '@hw-agconnect/petal-aegis';
```

参数：  

|参数名|类型|必填|说明|
|:---------|:-----------------------------------------------------------------------------------------------------------|:-|:---------------------------------------------------------------------------------------------------------------------------|
|alg|[SM4Alg](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/sm4alg-0000001937701454)|是|SM4模式枚举。|
|ciphertext|Uint8Array|是|[sm4EncText](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/sm4enctext-0000001937542118)生成的密文内容。|
|key|string或Uint8Array|是|密钥内容，hexstring或Uint8Array格式， 长度请参考模式SM4Alg的密钥长度（bit）。|
|iv|string或Uint8Array|否|iv偏移量内容，hexstring或Uint8Array格式，如果传入IV，返回结果的密文中不会携带iv，如果不传入iv，返回的密文结果会携带自动生成的IV，长度为16字节。|

返回值：  

|参数|类型|说明|
|:----------|:-----|:---------|
|decryptText|String|解密后的明文字符串。|

示例：

```
import { aegis } from '@hw-agconnect/petal-aegis';
import { buffer } from '@kit.ArkTS';

async function demo() {
  let plainText = 'hello world'; //待加密内容
  let key = '1234567891234567'; //长度16字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let iv = '9876543217654321'; //长度16字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let keyUint8 = new Uint8Array(buffer.from(key, 'utf-8').buffer);
  let ivUint8 = new Uint8Array(buffer.from(iv, 'utf-8').buffer);

  try {
    let encryptText = await aegis.sm4EncText(aegis.SM4Alg.SM4_CBC_PKCS7Padding, plainText, keyUint8, ivUint8);
    //encryptText: 155,33,239,15,249,8,1,141,7,122,48,126,61,60,108,22
    console.log('encryptText: ' + encryptText);

    let decryptText = await aegis.sm4DecText(aegis.SM4Alg.SM4_CBC_PKCS7Padding, encryptText, keyUint8, ivUint8);
    if (plainText === decryptText) {
      console.info('decrypt ok');
    }
    console.log('decryptText: ' + decryptText);
  } catch (err) {
    console.log('err: ' + err);
  }
}
```
