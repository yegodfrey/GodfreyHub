# 创建版本

#### 功能介绍

此接口用于创建云托管站点版本，已归档版本可作为新版本的基线版本。  

#### 使用约束

仅支持版本状态为"FINALIZED"的版本作为基线版本。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者服务器 -\> 华为服务器|
|接口URL|https://{domain}/api/cloudhosting/web/v1/version/create 其中{domain}依站点区分： * 中国：connect-api.cloud.huawei.com * 德国：connect-api-dre.cloud.huawei.com * 新加坡：connect-api-dra.cloud.huawei.com * 俄罗斯：connect-api-drru.cloud.huawei.com <br /> 注意： 调用[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)接口时使用的域名必须与本接口域名保持一致，例如欧洲站点使用"connect-api-dre.cloud.huawei.com"，则调用[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)接口必须使用"https://connect-api-dre.cloud.huawei.com/api/oauth2/v1/token"。|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|
|-----|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### 请求参数

#### Header

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:-----|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Authorization|M|String|认证鉴权信息。 认证方式：Bearer token。 格式:"Authorization: Bearer ${access_token}"。 access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)中获取的access_token。|
|productId|M|String|项目ID，获取方法参考[查询开发者账号ID及项目ID](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-developerid-projectid-0000001166543063)。|
|requestid|M|String|自定义的请求字符串，必须唯一标识此请求。|
|client_id|M|String|客户端ID，获取方法参考[创建API客户端](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudhost-getstarted-0000001166760172#section59981526588)。|
|service|M|String|API业务标识。固定值：hosting。|

#### Body

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|siteId|M|String(64)|云托管版本所在的站点ID。 可根据站点名称查询站点ID，获取方法参考[查询站点信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-cloudhost-querysite-0000001166826430)。|
|baseVersion|O|String(64)|基线版本号，基于该版本创建新的版本。 仅支持版本状态为"FINALIZED"的版本作为基线版本。|

#### 请求示例

```
curl --location --request POST 'https://connect-api.cloud.huawei.com/api/cloudhosting/web/v1/version/create' \
--header 'productId: 258779603740930923' \
--header 'Authorization: Bearer eyJraWQiOiJJQXNyUjFm***************FEBJWctGVEI7hU' \
--header 'requestid: 876456' \
--header 'client_id: 7261907****1591808' \
--header 'service: hosting' \
--header 'Content-Type: application/json' \
--data-raw '{
    "siteId": "HdPU2XH5QJCs6uyuLI3oEg",
    "baseVersion": "j7JxSO4xSMmGUD5aan-XWg"
}'
```

#### 响应参数

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:--------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------|
|ret|O|String|包含返回码及描述信息的JSON字符串，格式为{"code":retcode, "msg": "description"}，retcode为返回码，description为返回码描述信息。|
|code|O|String|结果状态码，参考[状态码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-cloudhost-errorcode-0000001260940301)。|
|message|O|String|结果描述信息。|
|siteVersion|O|[siteVersion](#ZH-CN_TOPIC_0000001166653462__table139745893119)|版本信息。|

siteVersion  

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|version|M|String|站点版本号。|
|siteId|M|String|站点ID。|
|tenantId|M|String|租户ID，与项目ID一致。|
|versionStatus|M|String|版本状态，参考[版本状态码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-cloudhost-versioncode-0000001211707815)。 创建版本包含状态："CREATING"和"CREATED"。|
|fileCount|M|Integer|包含的文件数量。|
|zipFileSize|M|Integer|zip压缩包大小。|
|sourceSize|M|Integer|解压缩后的资源总大小。|
|createDate|M|Long|版本创建时间。|
|modifyDate|M|Long|版本修改时间。|
|expireDate|M|Long|版本过期时间。|
