# RelationManager

|Class/Struct Info|
|:-----------------------------------------------------------------------------------|
|public static class RelationManager 关系操作的主要管理类，其中的操作接口都已拓展到了IEntity上，可通过IEntity直接使用。|

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110251.45213138958866866616562830925344:50001231000000:2800:7ECA7EA3B7D7B16AF8F89E732C523300CDD1602BAF5592E6DAA2FFD60AFE03B7.png)  
在RelationManager中使用到如下两个泛型：

* TR：表示关系泛型。通过实现IGenericRelation\<TGenericKey\>和IEntityRelation接口自定义的关系均可使用。
* TK：表示关系对象泛型。无特殊指定。

使用关系对表示为：entity -TR-\> TK。

#### Methods

#### AddRelation\<TR\>

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|bool AddRelation\<TR\>(this IEntity entity, in TR relation, out RelationOptionsEnum option) 添加或修改关系，如关系不存在则添加，如关系已存在则修改原来关系。 TR为IRelation。 例如：A -R-\> B（V1）添加关系，A -R-\> B（V2）覆盖关系，关系中值V1被V2覆盖。|

Parameters  

|Name|Type|Description|
|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------|
|entity|IEntity|entity，表示该函数作为entity的拓展。|
|relation|TR|关系实体。 实现自IGenericRelation\<TGenericKey\>和IEntityRelation接口。|
|option|[RelationOptionsEnum](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/relation-overview-0000002477827333#section9707941992)|返回参数。 表示操作类型。|

Return  

|Type|Description|
|:---|:---------------------------------|
|bool|* true：表示添加关系成功。 * false：表示添加关系失败。|

Sample Code

```
var world = new IECSWorld();
var entity1 = world.CreateEntity(1);
var entity2 = world.CreateEntity(2);
var target1 = world.CreateEntity(10);
entity.AddRelation(new AttackRelation { target = target1, attackDamage = 10 }, out RelationOptionsEnum option); // option=Add
entity.AddRelation(new AttackRelation { target = target1, attackDamage = 15 }, out option); // option=Modify
```

#### GetBeRelatedLinks\<TR\>

|Method|
|:----------------------------------------------------------------------------------------------------------|
|List\<EntityRelationPair\> GetBeRelatedLinks\<TR\>(this IEntity target) 获取以target为目标的TR关系对列表。 TR为IRelation。|

Parameters  

|Name|Type|Description|
|:-----|:------|:-----------------------|
|entity|IEntity|entity，表示该函数作为entity的拓展。|

Return  

|Type|Description|
|:-------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|List\<EntityRelationPair\>|[EntityRelationPair](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/relation-entityrelationpair-0000002477827365)为关系对结构体，返回的是关系对的list集合。|

Sample Code

```
var world = new IECSWorld();
var target = world.CreateEntity();
var entity1 = world.CreateEntity();
var entity2 = world.CreateEntity();
entity1.AddRelation(new AttackRelation { target = target, attackDamage = 10 }, out _);
entity2.AddRelation(new AttackRelation { target = target, attackDamage = 20 }, out _);

List<EntityRelationPair> entityRelationPairs = target.GetBeRelatedLinks<AttackRelation>();
foreach (EntityRelationPair pair in entityRelationPairs)
{
    if (pair.EntityId == entity1.Id)
    {
        AreEqual("( 2 -> 1 )", pair.ToString());    
    }
    if (pair.EntityId == entity2.Id)
    {
        AreEqual("( 3 -> 1 )", pair.ToString());
    }
}
```

#### HasRelationType\<TR\>

|Method|
|:------------------------------------------------------------------------|
|bool HasRelationType\<TR\>(this IEntity entity) 判断是否存在TR关系。 TR为IRelation。|

Parameters  

|Name|Type|Description|
|:-----|:------|:-----------------------|
|entity|IEntity|entity，表示该函数作为entity的拓展。|

Return  

|Type|Description|
|:---|:------------------------------|
|bool|* true：表示存在关系。 * false：表示不存在关系。|

Sample Code

```
var world = new IECSWorld();
var target1 = world.CreateEntity();
var entity = world.CreateEntity();
var entity1 = world.CreateEntity();
entity.AddRelation(new AttackRelation { target = target1, attackDamage = 10 }, out _);
entity1.AddRelation(new AttackRelation { target = target1, attackDamage = 10 }, out _);

IsTrue(entity.HasRelationType<AttackRelation>());
IsTrue(entity1.HasRelationType<AttackRelation>());
IsFalse(target1.HasRelationType<AttackRelation>()); // 关系只是单向的，entity->target1
target1.AddRelation(new AttackRelation() { target = entity, attackDamage = 5 }, out _); // 建立target1->entity
IsTrue(target1.HasRelationType<AttackRelation>());
```
