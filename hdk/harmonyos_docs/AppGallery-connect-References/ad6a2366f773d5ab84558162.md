# GetFilesOptions

|Interface Info|
|:----------------------------------------------|
|export interface GetFilesOptions 获取文件列表请求的相关参数。|

#### Property Summary

|Name|Type|Mandatory/Optional|Description|
|:--------|:-----|:-----------------|:----------------------------------------|
|maxKeys|number|Optional|返回的目录和文件的总个数，设置的最大值必须小于等于1000，默认值为1000。|
|marker|string|Optional|文件对象列表。|
|prefix|string|Optional|列举以指定的字符串prefix开头的对象。|
|delimiter|string|Optional|如果传'/'，则会返回目录列表和文件列表；如果不传，仅返回包含所有对象的文件列表。|
