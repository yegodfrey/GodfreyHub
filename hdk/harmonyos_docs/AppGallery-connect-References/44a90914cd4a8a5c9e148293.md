# AGConnectServicesConfig

AGConnectServicesConfig类型需要包含以下参数：  

|Name|Type|Mandatory/Optional|Description|
|:--------------------|:-----|:-----------------|:-----------------|
|agcgw|any|Mandatory|AGC网关信息。|
|agcgw_all|any|Optional|各站点对应的域名。|
|client|any|Mandatory|当前项目下的项目信息和当前应用信息。|
|service|any|Mandatory|各服务需要使用的配置参数。|
|oauth_client|any|Optional|凭据信息。|
|app_info|any|Optional|当前项目下所有应用的应用信息。|
|region|string|Optional|默认数据处理位置。|
|configuration_version|string|Optional|配置文件的版本号。|
