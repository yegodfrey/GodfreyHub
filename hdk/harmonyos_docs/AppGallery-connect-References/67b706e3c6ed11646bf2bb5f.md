# SetRtmChannelPropertiesReq

|Class Info|
|:------------------------------------------------------------------------|
|RTM频道属性设置请求。 OBJECTIVE-C @interface SetRtmChannelPropertiesReq : NSObject|

## Property Summary

|Name|Type|Mandatory/Optional|Description|
|:----------------|:-----------|:-----------------|:-------------------------------------------|
|channelId|NSString|Mandatory|频道ID，仅支持数字(0-9)和字母 (A-Z,a-z)。|
|channelProperties|NSDictionary|Mandatory|频道属性。属性key最长100个字节，属性value最长1948个字节。最多可设置5组。|
