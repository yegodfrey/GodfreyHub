# QQAuthProvider

QQ账号凭证的提供者。仅支持Web，不支持快应用。

## Method Summary

|Qualifier and Type|Method Name and Description|
|:-------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------|
|[AGConnectAuthCredential](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauthcredential-web-0000001054104571)|static [credentialWithToken](#section121411406373)(token:string, openId:string, autoCreateUser:boolean): 登录凭证的构造器。|

## Methods

### credentialWithToken

|Method|
|:----------------------------------------------------------------------------------------------------------------|
|static credentialWithToken(token:string, openId:string, autoCreateUser:boolean):AGConnectAuthCredential 登录凭证的构造器。|

**Parameters**

|Name|Description|
|:-------------|:--------------------|
|token|由QQ SDK授权后获得的 token。|
|openId|由QQ SDK授权后获得的 openId。|
|autoCreateUser|是否自动创建账号（可选），默认为true。|

**Return**

|Type|Description|
|:----------------------|:-----------|
|AGConnectAuthCredential|AGConnect凭证。|

**Sample Code**

```screen
agconnect.auth.QQAuthProvider.credentialWithToken('token', 'openId', false)
```
