# GPMError

|Interface Info|
|:---------------------------------------------------------------------|
|游戏性能管理SDK返回码。 OBJECTIVE-C ```screen @interface GPMError : NSObject ```|

## 返回码

|返回码|值|描述|
|:-------------------------------|:---|:---------------------------------------------------|
|SUCCESS|0|成功。|
|COMMON_ERROR|1001|内部系统错误。|
|GPM_SAMPLE_TOKEN_FLOW_CONTROLLED|1002|获取令牌Token失败。|
|GPM_PARAMS_INVALID|2001|接口参数错误，请检查参数是否正确。|
|GPM_INIT_USER_IDENTITY_INVALID|2002|初始化参数错误，未设置userIdentity，或者userIdentity超出长度限制（0，756）。|
|GPM_AGC_AUTH_FAIL|2003|获取AGC Token失败，请检查初始化参数中clientId或clientSecret正确性。|
|GPM_NOT_INIT|2004|在调用启用采集器前未进行初始化。|
|GPM_COLLECTOR_NOT_ENABLE|2005|在设置场景前未启用采集器。|
|GPM_SCENE_NOT_START|2006|在设置场景加载完成或场景标签时未设置场景开始。|
|NETWORK_ERROR|3001|网络异常，请检查网络是否正常。|
