# ReceiveRtmPeerMessageNotify

|Interface Info|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|export type ReceiveRtmPeerMessageNotify = [RtmMessageNotify](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/rtmmessagenotify-harmonyos-0000001833189381) 接收RTM点对点消息回调通知对象。|

#### Property Summary

|Name|Type|Description|
|:------------|:----------------|:-----------------------------------------------------------|
|senderId|string|* 消息来自客户端接口时，则senderId为消息发送者的玩家ID。 * 消息来自服务端接口时，则senderId为空。|
|messageType|number|消息类型。 * 1：文本 * 2：二进制|
|message|string/Uint8Array|消息内容。|
|isFromOpenApi|boolean|是否来自服务端接口。 * true：来自服务端接口 * false：来自客户端接口|
|timestamp|number|消息发送时间戳，即距离1970年1月1日0点的毫秒数。|
|clientMsgId|string|客户端发送消息唯一标识。|
|serverMsgId|string|全局发送消息唯一标识。|
