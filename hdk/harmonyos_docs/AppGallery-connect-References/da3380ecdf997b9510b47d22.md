# ohAegSha256TextHex

ohAegSha256TextHex(text: string | Uint8Array): Promise<string>

SHA256消息摘要算法，返回十六进制编码的SHA256值，算法说明如下：

|摘要算法|支持种类|API版本|
|:---|:-----|:----|
|HASH|SHA256|11+|

**导入模块：**

```typescript
import { AegSha256 } from '@hw-agconnect/petal-aegis';
```

**参数** **：**

|参数名|类型|必填|说明|
|:---|:----------------|:-|:----|
|text|string或Uint8Array|是|明文内容。|

**返回值：**

|参数|类型|说明|
|:--|:-----|:-----------------|
|字符串|String|生成的加密hexString字符串。|
