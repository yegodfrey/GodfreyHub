## Methods

### ToString

|Method|
|:-----------------------------------------------|
|string ToString() 返回查询的组件和标签信息，打印的组件和标签名字均会带命名域。|

**Return**

|Type|Description|
|:-----|:------------|
|string|返回查询的组件和标签信息。|

**Sample Code**

```screen
var world = new IECSWorld();
// 创建一个Query
var query = world.Query().WithAllTags(ITags.Get<Inactive>());
// 打印Query信息，对于无泛型Query，Components为空。预设组件/标签命名域为"Pgd."，自定义组件/标签/共享组件根据实际情况而定
query.ToString(); // "Query: { Components:[], Tags:[Pgd.Inactive], SharedComponents:[]}"
```

### IsMatch

|Method|
|:--------------------------------------------------------------------------------------------------------------------------|
|bool IsMatch(in IComponents components, in ITags iTags, in IComponents sharedComponents = default) 判断查询实例与输入的组件类型和标签类型是否匹配。|

**Parameters**

|Name|Type|Description|
|:---------------|:----------|:--------------------|
|components|IComponents|组件类型集合。|
|iTags|ITags|标签类型集合。|
|sharedComponents|IComponents|共享组件类型集合。 默认为default。|

**Return**

|Type|Description|
|:---|:-------------------------------------------------------------|
|bool|* true：表示查询实例与输入的组件类型和标签类型相匹配。 * false：表示查询实例与输入的组件类型和标签类型不匹配。|

**Sample Code**

```screen
var world = new IECSWorld();
// 创建一个Query，并设置过滤条件
var query = world.Query().WithAllTags(ITags.Get<TestTag1>()).WithoutAllTags(ITags.Get<TestTag2>());
// 判断输入条件是否满足Query的所有过滤条件
query.IsMatch(default, ITags.Get<TestTag1>()); // true
query.IsMatch(default, ITags.Get<TestTag2>()); // false
```
