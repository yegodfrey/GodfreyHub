# HybridTransformSync

|Class/Struct Info|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class HybridTransformSync : PgdSystem<GoLink, PgdLocalTransform> HybridTransformSync是一个继承自PgdSystem<GoLink, PgdLocalTransform>的系统。 用于在每帧更新时将ECS中的PgdLocalTransform位置和旋转同步回绑定的GameObject Transform。 若使用混合模式开发并需要实现组件位置旋转同步，需手动注册该PgdSystem。 类型定义位于Pgd插件包的Runtime/Hybrid/HybridSync.cs。|

## Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:---------------------------------------------------------------------------------|
|void|[OnUpdate](#section113690269179)() 在系统更新阶段被调用，通过查询包含GoLink与PgdLocalTransform的实体集合。|

## Methods

### OnUpdate

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|protected override void OnUpdate() 在系统更新阶段被调用，通过查询包含GoLink与PgdLocalTransform的实体集合，逐个将PgdLocalTransform.Position和PgdLocalTransform.Rotation写回到对应的goLink.transform。 若gameObject或transform为空，则会输出错误日志并跳过该实体。|

**Sample Code**

```screen
var world = new IECSWorld();
world.RegisterSystem(new HybridTransformSync());
world.Update();
```
