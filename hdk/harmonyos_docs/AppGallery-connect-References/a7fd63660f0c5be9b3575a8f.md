# IEntityRelation

|Class/Struct Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------|
|public interface IEntityRelation : IGenericRelation<IEntity>{} 通用的关系接口，通过实现该接口来表示实体与实体之间的关系。 该接口继承自IGenericRelation，通过实现该接口定义的关系，对应的关系目标只能是实体。|

**Sample Code**

```screen
public struct AttackRelation : IEntityRelation
{
    public int attackDamage;
    public IEntity target;
    public IEntity GetGenericKey() => target;
    public override string ToString() => target.Id.ToString();
}
```
