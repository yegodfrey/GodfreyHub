# AGCEmailAuthProvider

|Class Info|
|:----------------------------------------------------------------------|
|邮箱凭证提供者。 Objective-C ``` @interface AGCEmailAuthProvider : NSObject ```|

#### +credentialWithEmail:password:

通过邮箱和密码获取凭证。如果创建用户时设置了密码，可以采用邮箱和密码登录。

<br />

Objective-C

```
+ (nonnull AGCAuthCredential *)credentialWithEmail:(nonnull NSString *)email
                                          password:(nonnull NSString *)password;
```

Swift

```
class func credential(withEmail email: String, password: String) -> AGCAuthCredential
```

<br />

Parameters  

|Name|Description|
|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|email|邮箱。|
|password|密码。 默认密码规则如下，若您参考[安全配置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-security-configuration-0000001324925609)自定义了密码复杂度请满足自定义的复杂度： 1. 密码长度至少8个字符； 2. 密码必须包含如下至少两种字符的组合： * 至少一个小写字母； * 至少一个大写字母； * 至少一个数字； * 至少一个特殊字符：\`!@#$%\^\&\*()-_=+\\\|\[{}\];:'",\<.\>/? 和空格。 3. 密码不能和手机号码或者邮箱一样。|

Return

Email凭证。  

#### +credentialWithEmail:password:verifyCode:

通过邮箱和验证码获取凭证。如果创建账户的时候没有设置过密码，则只能通过此接口进行登录，此时的password字段不赋值。

Objective-C

```
+ (nonnull AGCAuthCredential *)credentialWithEmail:(nonnull NSString *)email
                                          password:(nullable NSString *)password
                                        verifyCode:
                                            (nonnull NSString *)verifyCode;
```

Swift

```
class func credential(withEmail email: String, password: String?, verifyCode: String) -> AGCAuthCredential
```

<br />

Parameters  

|Name|Description|
|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|email|邮箱。|
|password|密码（可选）。如果携带了密码，则密码和验证码都会校验。 默认密码规则如下，若您参考[安全配置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-security-configuration-0000001324925609)自定义了密码复杂度请满足自定义的复杂度： 1. 密码长度至少8个字符； 2. 密码必须包含如下至少两种字符的组合： * 至少一个小写字母； * 至少一个大写字母； * 至少一个数字； * 至少一个特殊字符：\`!@#$%\^\&\*()-_=+\\\|\[{}\];:'",\<.\>/? 和空格。 3. 密码不能和手机号码或者邮箱一样。|
|verifyCode|验证码 Link用户的时候必填。|

Return

Email凭证。  

#### +requestVerifyCodeWithEmail:settings:

邮箱申请验证码。

<br />

Objective-C

```
+ (HMFTask<AGCVerifyCodeResult *> *)requestVerifyCodeWithEmail:(nonnull NSString *)email
                        settings:(nonnull AGCVerifyCodeSettings *)settings;
```

Swift

```
class func requestVerifyCode(withEmail email: String, settings: AGCVerifyCodeSettings) -> Task<AGCVerifyCodeResult>!
```

<br />

Parameters  

|Name|Description|
|:-------|:--------------------------------------------------|
|email|邮箱地址。|
|settings|验证码属性的配置，包括验证码应用场景（注册登录或者重置密码），发送验证码的语言，发送验证码的时间间隔。|

Return

申请验证码异步任务。
