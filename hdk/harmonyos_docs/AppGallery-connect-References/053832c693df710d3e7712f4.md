# 数据捐赠

#### 功能描述

此接口用于向用户发送服务事件通知。  

#### 使用约束

单次最多发送100条服务事件。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者服务器 -\> 华为服务器|
|接口URL|https://apigw-edu.cloud.huawei.com.cn/app/app-service-api/v1/cp/service-events/notify|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|
|-----|-------------------------------------------------------------------------------------|

#### 请求参数

#### Header

|参数|是否必选|参数类型|描述|
|:------------|:---|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|x-event-type|是|String|固定填"USER"。|
|x-appid|是|String|上架服务所关联的应用ID，获取方法请参见[获取参数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/appgallerykit-app-intent-donation-0000001653541318#ZH-CN_TOPIC_0000001653541318__li13581913164)。|
|Authorization|是|String|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token为应用ID所对应的应用级Token，即[获取Token](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/appgallerykit_gettoken-0000001050123505)中获取的access_token。|
|x-trace-id|是|String|联运跟踪ID，请求方使用随机数生成，最长32位。|

#### Body

|参数|是否必选|参数类型|描述|
|:---------------|:---|:----------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|abilityId|是|String|服务标识符，获取方法请参见[获取参数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/appgallerykit-app-intent-donation-0000001653541318#ZH-CN_TOPIC_0000001653541318__li6252131513428)。|
|openId|是|String|和请求头中的x-appid关联的用户ID。|
|intentName|是|String|捐赠数据的意图名称，按类型填写请参见[意图分类](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/appgallerykit-app-intent-donation-0000001653541318#section18960185620231)。|
|identifier|是|String|捐赠数据的唯一标识。|
|intentEntityInfo|是|Object|事件实体信息，具体请参见[事件实体相关字段](#ZH-CN_TOPIC_0000001656769014__p2638161994316)。|
|intentTargetInfo|是|[intentTargetInfo](#ZH-CN_TOPIC_0000001656769014__p1691862314117)|事件跳转信息。|

intentTargetInfo  

|参数|是否必选|参数类型|描述|
|:-------|:---|:-------------------------------------------------------|:------------------------------|
|deepLink|否|[deepLink](#ZH-CN_TOPIC_0000001656769014__p541445416417)|需要跳转的deeplink地址，和faInfo可任选一个传入。|
|faInfo|否|[faInfo](#ZH-CN_TOPIC_0000001656769014__p1387420511429)|需要拉起的快卡信息，和deepLink可任选一个传入。|
|faParams|否|Object|需要拉起的快卡参数，接入方自定义。|

deepLink  

|参数|是否必选|参数类型|描述|
|:---------|:---|:-----|:---------------|
|url|是|String|需要跳转的deeplink地址。|
|appName|是|String|应用名称。|
|appPackage|是|String|应用包名。|

faInfo  

|参数|是否必选|参数类型|描述|
|:----------|:---|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|bundleName|是|String|Bundle名称。获取方式请参见[获取接入参数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/appgallerykit-app-intent-donation-0000001653541318#ZH-CN_TOPIC_0000001653541318__li6252131513428)。|
|moduleName|否|String|模块名。获取方式请参见[获取接入参数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/appgallerykit-app-intent-donation-0000001653541318#ZH-CN_TOPIC_0000001653541318__li6252131513428)。|
|abilityName|是|String|服务名。获取方式请参见[获取接入参数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/appgallerykit-app-intent-donation-0000001653541318#ZH-CN_TOPIC_0000001653541318__li6252131513428)。|

事件实体相关字段：

* LearningSituation  

  |参数|是否必选|参数类型|描述|
  |:-----------------|:---|:-----|:--------------------------------------------------------------|
  |entityId|是|String|业务用于区分不同实体的字段，每条不一样。|
  |entityName|是|String|固定填"LearningSituation"。|
  |lsSubject|是|String|学情主题，建议为课程名称。|
  |lsDescription|是|String|学情描述，可填写"学情更新"。|
  |lsType|是|ENUM|学情类型。 * 1-日报 * 2-周报 * 3-月报|
  |lsImage|是|String|学情封面url，用于模板展示。|
  |availableBeginTime|是|String|事件的生效时间，如预约上新时间，精确到秒，格式为"yyyy-MM-DDTHH:mm:ss+TIMEZONE"。|
  |availableEndTime|是|String|事件的失效时间，超过该时间后，事件不再通知用户，精确到秒，格式为"yyyy-MM -DDTHH:mm:ss+TIMEZONE"|

* MediaAppointmentInfo  

  |参数|是否必选|参数类型|描述|
  |:-----------------|:---|:-----|:---------------------------------------------------------------|
  |entityId|是|String|业务用于区分不同实体的字段，每条不一样。|
  |entityName|是|String|固定填"MediaAppointmentInfo"。|
  |mediaName|是|String|媒体主题，用于模板展示。|
  |mediaType|是|ENUM|媒体类型，固定填4-有声上新。|
  |onlineTime|是|String|上线时间格式为"yyyy-MM-DDTHH:mm:ss+TIMEZONE"。|
  |mediaImage|是|String|媒体封面url，用于模板展示。|
  |availableBeginTime|是|String|事件的生效时间，如预约上新时间，精确到秒，格式为"yyyy-MM-DDTHH:mm:ss+TIMEZONE"。|
  |availableEndTime|是|String|事件的失效时间，超过该时间后，事件不再通知用户，精确到秒，格式为"yyyy-MM -DDTHH:mm:ss+TIMEZONE"。|

#### 请求示例

```
POST {url}
Content-Type: application/json
x-appid:******
x-trace-id: *******
x-event-type：******
Authorization: Bearer ******
"body":
{
    "events": [
        {
            "abilityId": "string",
            "openId": "string",
            "intentName": "ViewLearningProgress",
            "identifier": "string",
             "intentEntityInfo": {
                "entityId": "string",
                "entityName": "string",
                "lsSubject": "string",
                "lsDescription": "string",
                "lsType": 1,
                "availableBeginTime": "string",
                "availableEndTime": "string",
                "lsImage": "string"
            },
            "intentTargetInfo": {
                "deepLink": {
                    "appPackage": "string",
                    "url": "string"
                },
                "faInfo": {
                    "bundleName": "string",
                    "abilityName": "string"
                }
            }
        }
    ]
}
```

#### 响应参数

|参数|是否必选|参数类型|描述|
|:----------|:---|:-----|:---------------------------------------------------------------------------------------------|
|errorEvents|否|String|批量通知时，如果有事件处理失败，会在该参数中记录具体错误的请求ID。|
|result|否|String|如果resultCode为0且errorEvents的长度为0，代表成功。 resultDesc：错误描述 resultCode：[错误码](#section17457111971515)|

#### 响应示例

```
HTTP/1.1 200 OK
Content Type : application/json ; charset=UTF-8
{
    "errorEvents": [
        {
            "requestId": "2023082310",
            "resultInfo": {
                "desc": "ability not found with eventName"
            }
        }
    ],
    "result": {
        "resultCode": 0,
        "resultDesc": "Operation success"
    }
}
```

#### 错误码

|错误码|说明|
|:---------|:-------------------------------|
|401|app应用级token鉴权失败，检查请求的token是否已过期。|
|1143149448|没有操作权限。|
