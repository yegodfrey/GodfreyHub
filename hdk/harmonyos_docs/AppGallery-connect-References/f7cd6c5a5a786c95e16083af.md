# 错误码

|错误码|值|描述|解决方法|
|:-----------------------------|:----|:----------------|:------------------------------|
|FAIL_TO_GET_CREDENTIAL_SERVICE|11000|获取Client Token失败。|请检查网络环境或应用agcConnectConfig配置信息。|
|FAIL_TO_GET_NETWORK_SERVICE|11001|网络请求失败。|请检查网络环境。|
|FAIL_TO_CALL_CLOUD_FUNCTION|11002|调用云函数失败。|请检查请求或返回情况。|
|FAIL_TO_GET_ACCESS_TOKEN|11003|无法获取用户Token信息。|请检查用户是否成功登录。|
