# 导出用户

#### 功能介绍

此接口用于导出认证服务中的用户信息。  

#### 使用约束

* 接口调用者的角色：管理员、APP管理员、开发。
* 接口调用次数限制：20个请求/client_id/秒  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者服务器-\>华为认证服务|
|接口URL|https://{domain}/api/auth-service/v1/server/user:export 中国站点的domain：connect-api.cloud.huawei.com 德国站点的domain：connect-api-dre.cloud.huawei.com 新加坡站点的domain：connect-api-dra.cloud.huawei.com 俄罗斯站点的domain：connect-api-drru.cloud.huawei.com 注意： 调用[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)接口时使用的域名必须与本接口域名保持一致，例如本接口使用"connect-api-dre.cloud.huawei.com"，则调用[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)接口必须使用"https://connect-api-dre.cloud.huawei.com/api/oauth2/v1/token"。|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|
|-----|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### Body

|参数名称|必选（M）/可选（O）|参数类型|参数说明|
|:----|:----------|:-----|:------------------------------------------------------------------------|
|block|O|String|当前存储块号。不填默认是0。第1次调用时，block设置为0。服务端会返回totalBlock。后面采用循环调用，遍历导出block块里面的用户。|

#### 调用示例

```
"Java"
  /**
     * 导出用户
     * 第1次调用block设置为0。会返回totalBlock。后面采用循环调用，遍历导出block块里面的用户
     * int totalBlock = exportUserByServer("xxxxx", "xxxxx", "xxxxx", 0);
     * for (int block = 1; block < totalBlock; block++) {
     * exportUserByServer("xxxxx", "xxxxx", "xxxxx", block);
     * }
     *
     * @param token access_token， 获取方式见请求参数说明。
     * @param productId 项目ID， 获取方式见请求参数说明。
     * @param clientId 客户端ID，获取方式见请求参数说明。
     * @param block 块号
     * @return 总共的块数
     */
    public static int exportUserByServer(String token, String productId, String clientId, Integer block) {
        HttpPost post = null;
        CloseableHttpClient httpClient = null;
        int totalBlock = 0;
        try {
            /** 新建POST请求 */
            post = new HttpPost("https://connect-api.cloud.huawei.com/api/auth-service/v1/server/user:export");

            /** 设置Header认证信息 */
            post.setHeader("productId", productId);
            post.setHeader("Authorization", "Bearer " + token);
            post.setHeader("client_id", clientId);

            /** 组装请求Body，使用JSON格式携带查询信息 */
            StringEntity entity = new StringEntity(String.format("{\"block\":%d}", block), Charset.forName("UTF-8"));
            entity.setContentEncoding("UTF-8");
            entity.setContentType("application/json");
            /** 设置请求Body */
            post.setEntity(entity);
            /** 发送请求 */
            httpClient = HttpClients.createDefault();
            HttpResponse response = httpClient.execute(post);
            /** 处理返回参数 */
            int statusCode = response.getStatusLine().getStatusCode();
            if (statusCode == HttpStatus.SC_OK) {
                BufferedReader br =
                    new BufferedReader(new InputStreamReader(response.getEntity().getContent(), Consts.UTF_8));
                String result = br.readLine();
                JSONObject object = JSON.parseObject(result);
                JSONArray jsonArr = object.getJSONArray("users");
                for (int i = 0; i < jsonArr.size(); i++) {
                    JSONObject jsonObject = jsonArr.getJSONObject(i);
                    System.out.println(jsonObject);
                }
                totalBlock = object.getInteger("totalBlock");
            }
        } catch (Exception e) {
        } finally {
            try {
                if (Objects.nonNull(post)) {
                    post.releaseConnection();
                }
                if (Objects.nonNull(httpClient)) {
                    httpClient.close();
                }
            } catch (Exception e) {
                e.printStackTrace();
            }
        }
        return totalBlock;
    }
```
