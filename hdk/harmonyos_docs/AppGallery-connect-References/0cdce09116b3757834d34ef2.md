# GetRtmChannelHistoryMessagesReq

|Interface Info|
|:----------------------------------------------------------------|
|export interface GetRtmChannelHistoryMessagesReq 查询RTM频道历史消息请求对象。|

## Property Summary

|Name|Type|Mandatory/Optional|Description|
|:--------|:-----|:-----------------|:-------------------------------------|
|channelId|string|Mandatory|频道ID，仅支持数字(0-9)和字母 (A-Z,a-z)。|
|startTime|number|Optional|查询消息的开始时间戳，大于等于0，单位：毫秒。不传或传0即查询所有时间范围。|
|count|number|Optional|查询消息数量，大于等于0，单位：条，不传或传0即查询频道内所有消息。|
