# IEntity

|Class/Struct Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------|
|public readonly struct IEntity : IEquatable<IEntity> 实体的核心结构体，实体的底层实现，继承了IEquatable<IEntity>。 实体创建必须通过IECSWorld或Archetype的创建实体方法创建，不能用关键字new创建。|

|Enum info|
|:--------------------------------------------------------------------------------|

|public enum [EntityNodeStatus](#section11803752298) 实体类枚举值，用于描述实体在树结构中的归属状态。|

### IsDeleted

|Method|
|:---------------------------|
|bool IsDeleted() 判断实体是否已经删除。|

**Return**

|Type|Description|
|:---|:-------------------------------|
|bool|* true：表示实体已删除。 * false：表示实体未删除。|

**Sample Code**


### GetBatched

|Method|
|:----------------------------------------------------------|
|BatchProcessor GetBatched() 获取一个批量处理器，并将该批量处理器的目标实体设置为当前实体。|

**Return**

|Type|Description|
|:-------------|:----------|
|BatchProcessor|批量处理器。|

**Sample Code**

```screen
var world   = new IECSWorld();
var entity  = world.CreateEntity();
// 用批处理器对实体进行操作，可以通过后置调用Process()方法，实现延后处理
entity.GetBatchProcessor()
    .AddComponent(new PgdPosition(1, 2, 3))
    .AddComponent(new Name("test"))
    .RemoveComponent<PgdScale>()
```
