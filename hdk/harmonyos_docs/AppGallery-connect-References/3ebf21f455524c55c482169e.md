# ChildEntitiesNode

|Class/Struct Info|
|:--------------------------------------------------------------------------------------------------|
|public struct ChildEntitiesNode : IComponent 预设的组件，继承了IComponent，用于管理一个实体的所有子实体。在首次添加子实体时，会自动添加该组件。|

## Property Summary

|Name|Type|Description|
|:------------|:---|:----------|
|ChildrenCount|int|子实体数量。|

**Sample Code**

```screen
var world = new IECSWorld();
var entity = world.CreateEntity(1);
// 首次添加子实体时，会自动给父实体添加ChildEntitiesNode组件
entity.AddChild(world.CreateEntity(2));
// 检查子实体数量
entity.GetComponent<ChildEntitiesNode>().ChildrenNum; // 1
```

|Qualifier and Type|Method Name and Description|
