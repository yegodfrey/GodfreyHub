# FunctionOptions

包含调用函数时传入的参数信息。  

#### Parameters

|Name|Type|Mandatory/Optional (M/O)|Description|
|:----------|:-----|:-----------------------|:----------------------|
|name|string|M|函数名称。|
|version|string|O|函数版本，默认为最新版本。|
|timeout|number|O|函数执行超时时长，默认为70000ms。|
|params|any|O|函数参数。|
|emulatorUrl|string|O|本地云函数测试桩地址，用于调试端云一体化特性。|
