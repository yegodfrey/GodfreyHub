# LocalAudioInfo

|Class Info|
|:-----------------------------------------------------------------|
|本地音效播放信息。 OBJECTIVE-C ``` @interface LocalAudioInfo : NSObject ```|

#### Property Summary

|Name|Type|Description|
|:-------|:-------|:----------------------------|
|soundId|int|音效ID，大于等于0。|
|filePath|NSString|音频文件路径，本地路径和网络URL均可。|
|loop|int|循环播放次数，大于等于0，默认值0表示无限循环。|
|volume|int|音效音量系数，取值范围\[0, 100\]，默认值100。|
