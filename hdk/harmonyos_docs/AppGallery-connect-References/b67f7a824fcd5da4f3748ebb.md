# Axis

|Class Info|
|:----------------------------------------------------|
|玩家朝向信息。 OBJECTIVE-C ``` @interface Axis: NSObject ```|

#### Property Summary

|Name|Type|Description|
|:------|:----------|:---------------------------------------------|
|forward|simd_float3|世界坐标系前轴（Z轴）的单位向量。该参数是长度为3的数组，三个值依次表示前、右、上的坐标值。|
|right|simd_float3|世界坐标系右轴（X轴）的单位向量。该参数是长度为3的数组，三个值依次表示前、右、上的坐标值。|
|up|simd_float3|世界坐标系上轴（Y轴）的单位向量。该参数是长度为3的数组，三个值依次表示前、右、上的坐标值。|
