# hmacHexSync

hmacHexSync(alg:HmacAlg, text:string\|Uint8Array, key:string\|Uint8Array): string

消息认证算法，返回Uint8Array格式密文。

导入模块：

```
import { aegis } from '@hw-agconnect/petal-aegis';
```

参数：  

|参数名|类型|必填|说明|
|:---|:-------------------------------------------------------------------------------------------------------------|:-|:----------------------------------------------|
|alg|[HmacAlg](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/hmacalg-0000001964620509)|是|HmacAlg模式枚举。|
|text|string\|Uint8Array|是|明文内容。|
|key|string或Uint8Array|是|密钥内容，hexstring或Uint8Array格式， 长度请参考HmacAlg的密钥长度。|

返回值：  

|参数|类型|说明|
|:---|:---------|:------------------|
|字节数组|Uint8Array|加密后的Uint8Array格式密文。|

示例：

```
import { aegis } from '@hw-agconnect/petal-aegis';
import { buffer } from '@kit.ArkTS';

async function demo() {
  let plainText = 'hello world';  
  let key = '12345678912345678912345678912345';//长度32字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let keyUint8 = new Uint8Array(buffer.from(key, 'utf-8').buffer);
  try {
    let hashStr: string = aegis.hmacHexSync(aegis.HmacAlg.SHA256, plainText, keyUint8);
    //mac hash: f79b3dc14e1a237bd3bd1a8087eb433e6d7fec3ac749da447f4859d349321e73
    console.log('mac hash: ' + hashStr);
  } catch (err) {
    console.log('err: ' + err);
  }
}
```
