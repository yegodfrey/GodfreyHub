# 批量更新商品

> 注意
>
> 如果您前期已使用该接口为您的**HarmonyOS 5.0及以上应用** 接入商品管理，请尽快切换至[HarmonyOS 5.0及以上 V2版本接口](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-batchupdateproduct-harmonyosnext-0000002131508852)。

## 功能介绍

此接口用于批量更新商品定义信息，展示语言，商品价格，促销活动信息。

## 使用约束

接口调用者的角色：账号持有者、管理员、APP管理员、运营。

## 接口原型

|承载协议|HTTPS PUT|
|-----|--------------------------------------------------------------------------------------------------------|
|接口方向|开发者服务器->数字商品服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/pms/product-price-service/v1/manage/product/batchImportProducts|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|

## 请求参数

### Header

> 说明
>
> API Client和OAuth Client区别参见[使用入门](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114)。

**API Client方式**

|参数|必选(M)/可选(O)|类型|描述|
|:------------|:----------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|M|String|客户端ID，获取方法参考[创建API客户端](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section103mcpsimp)。|
|Authorization|M|String|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)中获取的access_token。|
|appId|M|String|应用ID，获取方法参考[查询应用信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/appgallery_queryappinfo)。|

**OAuth Client方式**

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
|oauth2Token|M|String|认证信息，传入[获取用户授权码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section949717114392)中获取的Access Token。|
|appId|M|String|应用ID，获取方法参考[查询应用信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/appgallery_queryappinfo)。|

### Body

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:--------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------|:------------------|
|requestId|M|String|请求序列ID，开发者自定义唯一标识符。|
|products|M|List<[ProductImportInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-pms-pimportinfo-android-0000002135929344)>|商品列表信息。|

|failedNumber|O|Integer|批量更新商品中的失败个数。|
|successNumber|O|Integer|批量更新商品中的成功个数。|
|resultInfo|O|List<[ProductImportErrorInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-pms-pierrorinfo-android-0000002136087432)>|失败原因说明。|

## 调用示例

```screen
"Java"
public static ProductBatchUpdateResp batchUpdateProductInfo(String domain, String clientId, String authorization,
    String appId, ProductBatchUpdateReq req) {
    String url = domain + "/api/pms/product-price-service/v1/manage/product/batchImportProducts";
    HttpPut put = new HttpPut(url);
    setHttpHead(clientId, authorization, appId, put);
    StringEntity entity = new StringEntity(JSON.toJSONString(req), ContentType.create("application/json", "UTF-8"));
    put.setEntity(entity);
    String result = getApiResp(put);
    if (StringUtils.isNotEmpty(result)) {
        return JSON.parseObject(result, ProductBatchUpdateResp.class);
    }
    return null;
}
```
