# AGCFunctionCallable

|Class Info|
|:------------------------------------------------------------------------------|
|Cloud Function函数。 Objective-C ``` @interface AGCFunctionCallable : NSObject ```|

#### timeoutInterval

获取或设置函数的超时时间，默认70秒。

Objective-C

```
@property (assign, readwrite, nonatomic) NSTimeInterval timeoutInterval;
```

Swift

```
var timeoutInterval: TimeInterval { get set }
```

#### -call

调用没有入参的函数。

Objective-C

```
- (id)call;
```

Swift

```
func call() -> Any!
```

<br />

Return

执行结果。  

#### -callWithObject:

调用有入参的函数。

Objective-C

```
- (id)callWithObject:(nullable id)object;
```

Swift

```
func call(with object: Any?) -> Any!
```

<br />

Parameters  

|Name|Description|
|:-----|:------------------------------------------------------------------------------------|
|object|包含函数入参值的对象，可以是NSNumber、NSString、NSArray、NSDictionary和自定义类型。对象中包含的入参值需要与创建云函数时设置的入参对应。|

Return

执行结果。您可以在接口返回的HMFTask中设置一个addOnCompleteListener回调监听，在回调方法中获取包含函数执行结果的[AGCFunctionResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcfunctionresult-0000001058947256)对象。
