# ohAegEccSignTextBase64

ohAegEccSignTextBase64(text: string \| Uint8Array, priKey: string \| Uint8Array): Promise\<string\>

ECDSA私钥签名，返回Base64编码的签名结果，密钥类型、摘要算法等如下：  

|非对称密钥类型|摘要|API版本|
|:------|:-----|:----|
|ECC256|SHA256|11+|

导入模块：

```
import { AegEcc } from '@hw-agconnect/petal-aegis';
```

参数：  

|参数名|类型|必填|说明|
|:-----|:----------------|:-|:------------------------------|
|text|string或Uint8Array|是|待签名的内容。|
|priKey|string或Uint8Array|是|ECC私钥，base64编码过的字符串或Uint8Array。|

返回值：  

|参数|类型|说明|
|:-----|:-----|:---------------|
|签名后的内容|String|签名后的内容，base64编码。|
