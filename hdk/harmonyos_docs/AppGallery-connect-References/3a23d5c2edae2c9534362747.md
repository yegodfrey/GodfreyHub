# ohAegFileSha256

ohAegFileSha256(filePath: string): Promise<Uint8Array>

文件SHA256消息摘要算法，返回Uint8Array类型的SHA256值，算法说明如下：

|摘要算法|支持种类|API版本|
|:---|:-----|:----|
|HASH|SHA256|11+|

**导入模块：**

```typescript
import { AegSha256 } from '@hw-agconnect/petal-aegis';
```

**参数** **：**

|参数名|类型|必填|说明|
|:-------|:-----|:-|:--------------------|
|filePath|string|是|文件的路径，请确保调用方拥有文件处理权限。|

**返回值：**

|参数|类型|说明|
|:---|:---------|:------------------|
|字节数组|Uint8Array|生成的加密Uint8Array字符串。|
