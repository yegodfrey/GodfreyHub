# 创建聚合链接短链接

## 功能介绍

此接口用于创建聚合链接短链接，您可以直接创建一个短链接，也可以使用一个长链接生成短链接。

## 使用约束

* 接口调用者的角色：账号持有者、管理员、APP管理员、开发、运营。
* Rest创建的聚合链接，在AGC控制台不显示。
* 调用次数限制：
  * 5次/每IP地址/每秒
  * 1000次/每IP地址/每小时
* 数量限制：10万个短链接/每天/每项目。

## 接口原型

|承载协议|HTTPS POST|
|-----|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|接口方向|开发者服务器->华为服务器|
|接口URL|https://{domain}/api/applinking/v1/links * 中国站点的domain：connect-api.cloud.huawei.com * 欧洲站点的domain：connect-api-dre.cloud.huawei.com * 亚太站点的domain：connect-api-dra.cloud.huawei.com * 俄罗斯站点的domain：connect-api-drru.cloud.huawei.com > 注意 > 调用[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)接口时使用的域名必须与本接口域名保持一致，例如本接口使用"connect-api-dre.cloud.huawei.com"，则调用[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)接口必须使用"https://connect-api-dre.cloud.huawei.com/api/oauth2/v1/token"。|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

### Body

请求Body中使用JSON格式携带更新的语言描述信息，参数如下表所示。

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:-----------|:----------|:-------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|longUrl|O|String|聚合链接的长链接地址，支持使用长链接地址生成短链接。长链接格式请参见[手动构造聚合链接](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-createlinks-defined-0000001055514692)。 longUrl和linkInfo必选1个，如果同时传入，优先使用linkInfo。 > 注意 > 手动构造的聚合链接长链接地址需要符合HTTP标准，query等参数需要进行URL编码。|
|linkInfo|O|[LinkInfo](#ZH-CN_TOPIC_0000001141716380__p345041816436)|包含聚合链接详细信息的对象。 longUrl和linkInfo必选1个，如果同时传入，优先使用linkInfo。|
|suffixLength|O|String|短链接字符串后缀长度。 * SHORT：短链接使用短字符串后缀，从4位字符开始，4位字符使用完后继续增加位数。 * LONG：短链接使用长字符串后缀，固定17位字符长度。 默认为**SHORT**。|
|expireTime|O|Long|短链接失效时间，单位为秒，必须为大于300的整数。不传此参数则默认2年失效。|

                        String shortUrl = object.getString("shortUrl");
		}

	}
}
