# ProductPromotionDetailInfo

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:--------------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|promotionId|M|String|促销唯一ID。|
|productId|M|String|关联商品主键ID。|
|startDate|M|Integer(64)|开始促销时间，时间戳。|
|endDate|M|Integer(64)|结束促销时间，时间戳。|
|status|M|Integer|促销进行状态： * 0：进行中 * 1：未开始 * 2：已结束（包含强制结束）|
|promotionStatus|M|String|促销状态： * active：上线 * delete：删除 * inactive：下线|
|strategy|M|String|促销策略类型： * trial：免费试用 * introductory：按周期扣费|
|promotionTitle|M|String|促销价格名称。|
|defaultLocale|M|String|默认语言环境，请参见[国家/地区、语言、币种列表](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-supported-countries-overview-0000001146718725)。例如：zh_CN、en_US。|
|promotionDesc|O|String|默认促销描述信息。|
|createId|O|String|创建者ID。|
|createTime|O|String|创建时间。|
|updateId|O|String|修改者ID。|
|updateTime|O|String|修改时间。|
|periodUnit|O|String|优惠周期单位： * D：天 * W：周 * M：月 * Y：年|
|numberOfUnits|O|Integer|优惠周期数。如优惠两个月，numberOfUnits=2， periodUnit=M。|
|defaultPrice|M|String|基准换算价格。 说明： 当促销策略为免费试用时传入该字段可能会报错。|
|country|M|String|默认国家码，用于区分国家信息，请参见[国家/地区、语言、币种列表](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-supported-countries-overview-0000001146718725)。 例如CN。|
|currency|M|String|用于支付的默认币种，请参见[国家/地区、语言、币种列表](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-supported-countries-overview-0000001146718725)。 例如：USD、CNY、MYR。|
|introductory|O|List\<[PromotionIntroductoryInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-pms-pintroduceinfo-android-0000002171407049)\>|免费试用国家信息。|
|prices|O|List\<[CountryPriceInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-pms-cpriceinfo-android-0000002136087424#ZH-CN_TOPIC_0000002136087424__zh-cn_topic_0000001103538604_table146591959113716)\>|每个国家促销价格。 说明： 当促销策略为免费试用时传入该字段可能会报错。|
|languages|M|List\<[PromotionLanguageInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-pms-ptlanguageinfo-android-0000002171288649)\>|商品多语言信息。|
|promotionType|M|Integer|促销类型，默认值：0。 * 0：新用户促销 * 1：自定义人群促销 说明： 该参数仅HarmonyOS 5.0及以上应用支持。|
|offerId|O|String|优惠促销标识符，用于区分不同优惠促销，该ID当前商品下唯一。 说明： 该参数仅HarmonyOS 5.0及以上应用支持。|
