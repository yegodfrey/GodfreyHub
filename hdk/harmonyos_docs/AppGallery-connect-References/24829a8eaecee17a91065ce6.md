# 查询资产概要

## 功能介绍

华为游戏服务器调用此接口查询玩家在玩游戏的资产概要数据，并将信息展示在游戏中心的"在玩"页面上。

## 接口原型

|承载协议|HTTPS POST|
|------|-------------------------------------------------------------------|
|接口方向|华为游戏服务器 -> 开发者服务器|
|性能指标|TPS>500|
|最大响应时间|<500ms|
|接口URL|URL由华为运营联系您获取。|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 请求参数

Header参数

|参数|是否必选|类型|说明|
|:--------|:---|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|appId|是|String(32)|游戏在AppGallery Connect中生成的APP ID，获取方法请参见[查看应用基本信息](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-appinfo-0000001100014694)。|
|timestamp|是|String(32)|当前时间的时间戳，即距离GMT时间1970年1月1号0时0分0秒所差的毫秒数。|
|nonce|是|String(64)|随机字符串。|
|sign|是|String(1024)|华为服务器在发送请求时的签名字符串，生成步骤如下： 1. 将Header参数中的appId、timestamp、nonce字段依次拼接成一个待签名的字符串。 2. 对待签名字符串使用SHA256WithRSA/PSS算法进行签名。 3. 将签名后的字符串经过Base64编码，得到的字符串即为签名字符串。 您需要[获取验签公钥](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/get-public-key-0000001050164350)，并根据加密算法使用公钥对签名字符串进行验签，验签方法参见[验签机制](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-summary-0000002022225249#section205561419163916)。|

### Body参数

|参数|是否必选|类型|说明|
|:---------|:---|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|appId|是|String(32)|游戏在AppGallery Connect中生成的APP ID，获取方法请参见[查看应用基本信息](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-appinfo-0000001100014694)。|
|userId|是|String(256)|华为账号登录游戏后生成的玩家标识。|
|userIdType|是|Integer|玩家标识类型： * 1：playerId * 2：openId * 3：unionId * 4：gamePlayerId * 5：teamPlayerId * 6：thirdOpenId|
|serverId|否|String(32)|区服ID。|
|roleId|否|String(32)|角色ID。|
|lang|是|String(20)|语言，用于获取不同语言的[资产概要统计数据](#ZH-CN_TOPIC_0000002022105729__zh-cn_topic_0000001896629956_p425951173513)和[资产明细数据](#ZH-CN_TOPIC_0000002022105729__zh-cn_topic_0000001896629956_p1659182115443)，至少需要支持zh_CN（中文）和en_US（英文）。|

## 验签机制

1. 将Header参数中的appId、timestamp、nonce字段依次拼接成一个待验签的字符串。
2. 对待验签字符串使用SHA256WithRSA/PSS算法进行签名。
3. 将签名后的字符串经过Base64编码，得到的字符串与sign字段中的签名字符串进行一致性验证。 说明
   >
   > 游戏公钥在开通游戏服务后生成，查询方法参见[查询游戏服务信息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/query-game-info-0000001050164346)。

Java示例代码如下：

```screen
// 从Header中取出appId，timestamp，nonce，拼接成待签名的字符串
String rawStr = appId + timestamp + nonce;

// 获取验签公钥，具体实现方法由开发者自行决定，此处仅为接口示例
String publicKey = "xxxxxxxxx";

// 验签，BouncyCastleProvider的创建较耗费性能，建议写成单例
byte[] keyBytes = Base64.decodeBase64(publicKey.getBytes(StandardCharsets.UTF_8));
PKCS8EncodedKeySpec pkcs8KeySpec = new PKCS8EncodedKeySpec(keyBytes);
KeyFactory keyFactory = KeyFactory.getInstance("RSA");
PublicKey publicK =  keyFactory.generatePublic(pkcs8KeySpec);
Signature signature = Signature.getInstance("SHA256withRSA/PSS", new BouncyCastleProvider());
signature.initVerify(key);
signature.update(rawStr.getBytes(StandardCharsets.UTF_8));
signature.verify(Base64.decodeBase64(sign)); // sign是Header中的字段，即请求时传递的签名
```
