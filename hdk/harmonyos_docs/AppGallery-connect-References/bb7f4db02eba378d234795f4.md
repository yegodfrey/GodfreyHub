# Overview

包含AppGallery Connect APM服务的相关类。  

#### Class Summary

|Class|Description|
|:---------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------|
|[APMS](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/apms-0000001052488219)|APM SDK服务入口类。|
|[CustomTrace](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/customtrace-0000001051488170)|自定义跟踪记录，用于监控应用在特定场景，如用户登录场景下的性能。|
|[NetworkMeasure](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/networkmeasure-0000001052966915)|网络请求指标， 用于监控网络请求性能。|
|[ApmsLog](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/apmslog-0000001282058148)|自定义日志打印类，用于日志回捞。|
|[TaskInfo](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/taskinfo-0000001335131185)|描述回捞任务信息，实现了Parcelable接口，支持intent间传输。|

#### Interface Summary

|Interface|Description|
|:-----------------------------------------------------------------------------------------------------------------------------------------------|:--------------------|
|[FetchTask.FetchCallback](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/fetchcallback-0000001282762594)|回捞任务回调接口，用于通知接收到回捞任务。|

#### Annotation Summary

|Annotation|Description|
|:---------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------|
|[AddCustomTrace](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/addcustomtrace-0000001053086911)|AddCustomTrace是个注解类，主要用于修饰方法，会为方法创建自定义跟踪记录，以统计该方法的耗时。|
