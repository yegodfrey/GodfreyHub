# RoomInfo

|Interface Info|
|:------------------------------|
|export interface RoomInfo 房间信息。|

#### Property Summary

|Name|Type|Description|
|:-------------------|:----------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------|
|appId|string|应用ID。|
|roomId|string|房间ID。|
|roomStatus|number|房间状态。 * 0：空闲 * 1：帧同步中|
|roomType|string|自定义的房间类型。|
|roomCode|string|房间短码。|
|roomName|string|房间名称。|
|customRoomProperties|string|自定义房间属性。|
|ownerId|string|房主ID。|
|maxPlayers|number|房间最大支持人数，取值范围为\[1, 100\]。|
|players|[PlayerInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gameobe-playerinfo-js-0000001237750609)\[\]|房间内玩家列表。|
|router|[RouterInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gameobe-routerinfo-js-0000001237790587)|路由信息。|
|isPrivate|number|房间是否私有。 * 0：公开 * 1：私有|
|isLock|number|房间是否锁定，锁定状态的房间允许查询获取，但不允许加入。 * 0：非锁定 * 1：锁定|
|createTime|number|创建时间。|
