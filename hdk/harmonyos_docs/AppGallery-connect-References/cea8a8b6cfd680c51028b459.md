# AGCStorageError

|Class Info|
|:---------------------------------------------------------------|
|@interface AGCStorageError :NSError 操作云存储的文件或目录的任务产生的错误消息和错误码定义。|

#### ErrorCode

|Error Code|Error Message|
|:---------|:---------------------------------------------------------|
|11001|发生未知错误。|
|11002|项目不存在，或者端侧未使用华为认证服务进行认证。|
|11003|存储实例不存在。|
|11004|存储实例中的文件或目录不存在。|
|11005|配额已耗尽，请查看付费方案。|
|11006|用户身份认证失败，请重新登录并重试。|
|11007|用户不具备访问该文件或目录的权限。|
|11008|用户操作过于频繁，被限制访问。|
|11009|请求校验失败，请重试该请求。|
|11010|任务已取消。|
|11011|请求超时，请重试。|
|11012|本地文件访问失败，请确认文件是否存在，访问是否合法。|
|11013|网络异常，请重试。|
|11014|APP使用断点上传接口时，服务器使用SHA256散列值与接收到的文件内容对应的散列值校验出现不一致，请重新上传文件。|
|11015|网络不可用，请稍候重试。|
|11016|文件重复下载，请将本地文件删除或重命名。|
