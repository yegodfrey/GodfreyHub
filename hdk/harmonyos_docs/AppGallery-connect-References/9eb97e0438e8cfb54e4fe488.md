# ohAegRandom

ohAegRandom(len: number): Uint8Array

生成Uint8Array类型的安全随机数，可用于对称加解密的密钥、iv等。

**导入模块** **：**

```typescript
import { SafeRandom } from '@hw-agconnect/petal-aegis';
```

**参数：**

|参数名|类型|必填|说明|
|:--|:-----|:-|:----------|
|len|number|是|待生成安全随机数长度。|

**返回值：**

|参数|类型|说明|
|:---|:---------|:---------------|
|字节数组|Uint8Array|生成的安全随机数，长度为len。|
