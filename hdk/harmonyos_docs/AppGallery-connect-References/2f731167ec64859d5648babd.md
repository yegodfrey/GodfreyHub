# UploadResult

|Interface Info|
|:---------------------------------------|
|export interface UploadResult 上传文件的结果信息。|

#### Property Summary

|Name|Type|Description|
|:---------------|:---------------|:----------|
|bytesTransferred|number|已传输文件的字节数。|
|metadata|FileMetadata|文件的元数据。|
|reference|StorageReference|文件的引用信息。|
|state|TaskState|文件的上传状态信息。|
|task|UploadTask|上传文件任务。|
|totalByteCount|number|文件的总大小。|
