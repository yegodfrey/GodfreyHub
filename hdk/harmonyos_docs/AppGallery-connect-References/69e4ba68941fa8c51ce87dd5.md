# ohAegStringToUint8Array

ohAegStringToUint8Array(input: string): Uint8Array

字符串转换为Uint8Array格式。

导入模块：

```
import { AegStrUtil } from '@hw-agconnect/petal-aegis';
```

参数：  

|参数名|类型|必填|说明|
|:----|:-----|:-|:-------|
|input|string|是|待转换的字符串。|

返回值：  

|参数|类型|说明|
|:---|:---------|:---------------------|
|字节数组|Uint8Array|字符串转换后的Uint8Array格式内容。|

示例：

```
import { AegStrUtil } from '@hw-agconnect/petal-aegis';

function stringToUint8Array() {
  let strUtil: AegStrUtil = new AegStrUtil()
  let input = 'hello world'
  let result = strUtil.ohAegStringToUint8Array(input)
  //stringToUint8Array  result: 104,101,108,108,111,32,119,111,114,108,100
  console.log("stringToUint8Array ", 'result: ' + result);
}
```
