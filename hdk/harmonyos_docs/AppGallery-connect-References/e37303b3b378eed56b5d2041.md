# 通过下载方式提交发布

## 功能介绍

如果您将软件包保存在自己的服务器上，可以直接调用本接口提交应用审核，并传入软件包的下载地址。华为服务器会自动从下载地址中下载软件包后启动发布流程。接口调用者的角色：账号持有者、管理员、APP管理员。
> 说明
>
> 该接口需要在华为侧下载软件包并处理后上传，耗时较长，为异步接口。接口会立即响应成功，但这并不意味着最终发布成功。
>
> 您可以遵循[回调结果通知](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-notify-release-0000001158245063)接口的约束， 开发并提供回调能力，通过本接口的callbackAddr参数传入回调地址，用于接收软件包处理结果。
>
> 您也可以自行调用[查询应用信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-info-query-0000001158365045)接口判断应用是否已经提交审核成功（**releaseState** 为**4** ），或者登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)官网查看提审状态。

## 使用约束

非中国大陆开发者如需使用该API，应用发布地区必须包含中国大陆。中国大陆开发者无限制。

## 接口原型

|承载协议|HTTPS POST|
|-----|------------------------------------------------------------------------|
|接口方向|开发者服务器 -> 华为服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/publish/v2/app-submit-with-file|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

|:------------|:----------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

|Authorization|M|String|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)中获取的access_token。|

### Body

请求Body中使用JSON格式携带详细的发布信息，参数如下表所示。

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------------------------|:----------|:---------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|releaseTime|O|String(64)|指定发布时间，如果为空表示审核通过立即上架。UTC时间：yyyy-MM-ddTHH:mm:ssZZ，例如"2015-01-01T01:01:01+0800"。|
|remark|O|String(300)|提交发布的备注信息，可以为空，如果填写，长度范围在10-300。|
|releaseType|O|Integer|发布方式。 取值范围： * 1：全网。 * 3：分阶段。 默认值：1|
|downloadUrl|M|String|由您提供的软件包下载地址，支持APK/RPK/AAB/EXE等。 * APK：不超过4GB。 * RPK：快应用不超过20MB，快游戏不超过30MB。 * AAB：不超过150MB。 * EXE（Windows应用）: 不超过4GB。|
|downloadFileName|M|String(64)|downloadUrl下载地址中下载的文件名，包括后缀。|
|callbackAddr|O|String|应用发布回调地址，由您自行配置。应用发布结果由华为服务器调用[回调结果通知](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-notify-release-0000001158245063)接口通过该URL回调给您的开发者服务器。|
|requestId|M|String|您自定义的请求字符串，必须唯一标识此请求。结果回调时会携带该字段。|
|clearArk|O|String|是否清除方舟包（用于Android + 方舟升级到Android）。 取值范围： * 1：需要清除方舟包。 * 0：不需要清除方舟包。 默认值：0。|
|sensitivePermissionDesc|O|String|敏感信息。|
|phasedReleaseInfo|O|[PhasedReleaseInfo](#ZH-CN_TOPIC_0000001111845092__zh-cn_topic_0000001058910556_p113887247191)|分阶段发布信息。**releaseType**为3时，此参数必选。|
|versionName|O|String|Windows应用的软件包版本号。 文件类型为exe软件包时必选。|
|displayName|O|String|注册表显示名称，用于唯一标识Windows用。 文件类型为exe软件包时必选。|
|isPureDetection|O|Integer|是否申请绿色应用认证。 取值范围： * 0：否 * 1：是|
|sensitivePermissionIconUrl|O|String|绿色认证审核材料的objectId，isPureDetection=1时为必填项。该值为将绿色认证审核材料打成zip包，然后先调用[获取上传文件地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-upload-url-new-0000001111685200)接口，然后调用[上传文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-upload-file-new-0000001111845090)接口上传审核材料，最后得到[获取上传文件地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-upload-url-new-0000001111685200)接口返回的objectId。|
|isCommitSensitivePermissionTips|O|boolean|是否确认符合相关要求，true表示符合。isPureDetection=1时为必填项，且只可以填true。要求包括： * 非必要的使用场景禁止桌面、锁屏和其他应用弹出窗口骚扰用户行为。 * 非必要的使用场景禁止发送无法删除的常驻通知。 * 禁止影响用户体验的广告，如抬头、强制插屏、侧边等。 * 禁止引导用户开启开发者选项。 * 禁止引导用户开启USB调试模式。 * 禁止通过热补丁，引入恶意行为和不符合以上条款的行为。|

**PhasedReleaseInfo**

## 调用示例

```screen
public static void  releaseAppByDownload(String domain,String clientId, String token, String appId){
	HttpPost put = new HttpPost(domain + "/publish/v2/app-submit-with-file?appid=" + appId);

	put.setHeader("Authorization", "Bearer " + token);
	put.setHeader("client_id", clientId);

	JSONObject keyString = new JSONObject();
	keyString.put("downloadUrl", "www.testurl.com"); //replace by your actual url
	keyString.put("downloadFileName", "testfile"); //replace by your actual file name
	keyString.put("requestId", "1");

	StringEntity entity = new StringEntity(keyString.toString(), Charset.forName("UTF-8"));
	entity.setContentEncoding("UTF-8");
	entity.setContentType("application/json");
	put.setEntity(entity);

	try {
		CloseableHttpClient httpClient = HttpClients.createDefault();
		CloseableHttpResponse httpResponse = httpClient.execute(put);
		int statusCode = httpResponse.getStatusLine().getStatusCode();
		if (statusCode == HttpStatus.SC_OK) {
			BufferedReader br =
					new BufferedReader(new InputStreamReader(httpResponse.getEntity().getContent(), Consts.UTF_8));
			String result = br.readLine();

			JSONObject object = JSON.parseObject(result);
			System.out.println(object.get("ret"));
		}
	} catch (Exception e) {

	}
}
```
