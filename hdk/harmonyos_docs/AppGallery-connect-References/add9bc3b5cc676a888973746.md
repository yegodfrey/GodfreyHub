# PgdSystem / PgdSystem\<T1, ...\>

|Class/Struct Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public abstract class PgdSystem : QueryPgdSystemBase public abstract class PgdSystem\<T1\> : QueryPgdSystemBase(GenericComponent\<T1\>.Components)where T1 : struct, IComponent PgdSystem抽象类，开发者实现的系统需要继承该类，会自动创建查询体。 T为IComponent，最多支持10个泛型组件。 如果指定了组件类型，则会自动创建指定查询组件的查询体，否则自动创建的查询体默认匹配所有实体。|

#### PauseTimer

|Method|
|:--------------------------------------------------------------------------------------|
|void PauseTimer(bool pause = true) 暂停系统定时器，暂停后定时器不更新。 若暂停时定时器激活状态为false，则该定时器所属系统也不会更新。|

Parameters  

|Name|Type|Description|
|:----|:---|:----------------------------------------------|
|pause|bool|是否暂停定时器： * true：暂停定时器。 * false：开启定时器。 默认值为true。|

Sample Code

```
var system = new TestSystem("TestSystem").SetTickInterval(0.033);
// 暂停定时器
system.PauseTimer();
// 再次启动定时器
system.PauseTimer(false);
```
