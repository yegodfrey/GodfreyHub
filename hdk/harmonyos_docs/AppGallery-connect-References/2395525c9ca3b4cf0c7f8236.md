# Cloud

云侧入口类，为多个数据处理位置提供云服务实例。在Cloud初始化之后，您需要获取一个实例。然后您可以执行操作，例如，基于实例打开CloudDB对象。

#### database

|Method|
|:-----------------------------------------------------------------------------------------|
|database(config: DatabaseConfig): CloudDB 获取与数据处理位置对应的CloudDB实例。只有在获取实例后，才能打开存储区并进行数据管理操作。|

Parameters  

|Parameter|Description|
|:---------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|config: DatabaseConfig|DatabaseConfig对象，包含存储区的名称和traceId。 traceId用于跟踪请求操作，您可以在本地开发环境的日志中查看traceId。云数据库基于traceId提供[日志检索](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/clouddb-0000001483043177#section15174719364)能力，便于根据traceId在AGC云监控中定位异常请求。 traceId可以通过以下两种方式生成： * 用户自定义：该traceId可用于跟踪后续的所有请求操作。通过传入参数自定义traceId，若传入非法的traceId，系统将自动生成一个traceId。 自定义traceId的长度必须大于或等于1个字符，小于或等于32个字符，只能包含以下2种类型： * 字母（a-f） * 数字（0-9） * 系统自动生成：如果未自定义traceId，系统将自动为每个请求生成对应的traceId，以便跟踪定位每个请求操作。|

Return  

|Type|Description|
|:------|:-----------------------------------------------------------------|
|CloudDB|如果成功调用API，将获得CloudDB对象。您可以通过collection方法对CloudDB对象的数据进行增、删、改、查等操作。|
