# ServerStatus

ServerStatus类表示云侧服务器状态，当调用CloudDBZone类中的[executeServerStatusQuery](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-web-0000001080859822#section1324185773018)()方法成功查询云侧服务器状态时才会获取ServerStatus对象。ServerStatus对象中封装了云侧服务器当前时间戳。  

#### Field Summary

|Field|Desc|
|:----------------------|:----------|
|serverTimestamp: number|云侧服务器当前时间戳。|
