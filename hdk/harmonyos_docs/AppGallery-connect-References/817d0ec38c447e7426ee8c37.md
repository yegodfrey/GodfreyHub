# HMFExecutor

## -run:

在自定义的线程或者队列执行代码块。

**Objective-C**

```screen
- (void)run:(nonnull Runnable)runnable;
```

**Swift**

```screen
func run(_ runnable: @escaping Runnable)
```

**Parameters**

|Name|Description|
|:---------|:----------|
|*runnable*|触发要执行的代码块。|
