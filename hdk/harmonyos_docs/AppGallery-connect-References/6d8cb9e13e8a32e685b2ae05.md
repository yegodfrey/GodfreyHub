# CloudDBZoneGenericObject

CloudDBZoneGenericObject是CloudDBZoneObject的子类，提供了addFieldValue()、getFieldValue()、removeField()、isFieldExisted()、getFieldMap()和getObjectTypeName()等多个不同方法供开发者设置对象类型的字段名和对应值。您在AppGallery Connect控制台创建对象类型后，可以支持直接使用泛化对象的方式进行数据操作。支持对云侧数据库的数据进行增、删、改、查和事务操作。  

#### Summary

|Qualifier and Type|Method name|
|:-----------------------|:--------------------------------------------------------------------------------------------------------------|
|CloudDBZoneGenericObject|[build](#section296564433319)(objectTypeName: string) 获取一个指定对象类型名称的CloudDBZoneGenericObject泛化对象。|
|void|[addFieldValue](#section1120616413163)(fieldName: string, fieldValue: any, isPrimaryKey?: boolean) 添加泛化对象的字段和值。|
|void|[removeField](#section4301121411526)(fieldName: string) 移除泛化对象中的字段。|
|Map\<string, any\>|[getFieldMap](#section765691615210)() 获取泛化对象的所有字段和值。|
|any|[getFieldValue](#section1437121718528)(fieldName: string) 获取泛化对象中的字段。|
|boolean|[isFieldExisted](#section2847152781516)(fieldName: string) 查询泛化对象中是否存在某个字段。|
|string|[getObjectTypeName](#section13709013191010)() 获取当前泛化对象的对象类型名称。|

#### Methods

#### build

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|build(objectTypeName: string): CloudDBZoneGenericObject 调用此方法获取指定对象类型名称的CloudDBZoneGenericObject泛化对象实例。 CloudDBZoneGenericObject不提供任何构造方法，只能通过此方法来获取一个对象类型实例。传入的对象类型名称需要遵守对象类型创建规则，详细请参见[管理对象类型](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-agcconsole-objecttypes-0000001127675459)。|

Parameters  

|Parameter name|Parameter desc|
|:---------------------|:---------------|
|objectTypeName: string|指定泛化对象对应的对象类型名称。|

Return  

|type|desc|
|:-----------------------|:------|
|CloudDBZoneGenericObject|泛化对象实例。|

#### addFieldValue

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|addFieldValue(fieldName: string, fieldValue: any, isPrimaryKey?: boolean): void 调用此方法添加泛化对象的字段，可设置为主键。传入的字段名称需要遵守字段名创建规则，详细请参见[管理对象类型](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-agcconsole-objecttypes-0000001127675459)。|

Parameters  

|Parameter name|Parameter desc|
|:---------------------|:-------------------------------------------------|
|fieldName: string|添加泛化对象的字段名称。|
|fieldValue: any|泛化对象字段的值。|
|isPrimaryKey?: boolean|可选，是否标记为主键。 * true ：标记当前字段为主键。 * false：标记当前字段为非主键。|

#### removeField

|Method|

Parameters  

|Parameter name|Parameter desc|
|:----------------|:-------------|

|:----------------------------------------------------------------------|
