#### -createUserWithEmail:password:verifyCode:

邮箱创建账户。

<br />

Objective-C

```
- (HMFTask<AGCSignInResult *> *)
createUserWithEmail:(nonnull NSString *)email password:(NSString *_Nullable)password verifyCode:(nonnull NSString *)verifyCode;
```

Swift

```
func 
createUser(withEmail email: String, password: String?, verifyCode: String)
 -> Task<AGCSignInResult>!
```

<br />

Parameters  

|Name|Description|
|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|email|邮箱。|
|password|密码。 默认密码规则如下，若您参考[安全配置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-security-configuration-0000001324925609)自定义了密码复杂度请满足自定义的复杂度： 1. 密码长度至少8个字符； 2. 密码必须包含如下至少两种字符的组合： * 至少一个小写字母； * 至少一个大写字母； * 至少一个数字； * 至少一个特殊字符：\`!@#$%\^\&\*()-_=+\\\|\[{}\];:'",\<.\>/? 和空格。 3. 密码不能和手机号码或者邮箱一样。|
|verifyCode|验证码。|

Return

登录结果异步任务, 在任务成功后通过[\[AGCSignInResult user\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcsigninresult-ios-0000001054222395#section2425151124016)获取登录的用户信息。

<br />

Objective-C

```
- (HMFTask<AGCSignInResult *> *)

;
```

Swift

```
func 
createUser(withCountryCode countryCode: String, phoneNumber: String, password password: String?, verifyCode: String)
 -> Task<AGCSignInResult>!
```

<br />

Parameters  

|Name|Description|
|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|countryCode|国际电话区号，例如中国为86，德国49，俄罗斯7，新加坡65。 本字段支持多种格式（以中国为例）：86，+86。|
|phoneNumber|手机号码需要去掉"+"号 和国家（地区）码，例如：+86132xxxxxxxx，则取值132xxxxxxxx。|
|password|密码。 默认密码规则如下，若您参考[安全配置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-security-configuration-0000001324925609)自定义了密码复杂度请满足自定义的复杂度： 1. 密码长度至少8个字符； 2. 密码必须包含如下至少两种字符的组合： * 至少一个小写字母； * 至少一个大写字母； * 至少一个数字； * 至少一个特殊字符：\`!@#$%\^\&\*()-_=+\\\|\[{}\];:'",\<.\>/? 和空格。 3. 密码不能和手机号码或者邮箱一样。|
|verifyCode|验证码。|

Return

登录结果异步任务, 在任务成功后通过[\[AGCSignInResult user\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcsigninresult-ios-0000001054222395#section2425151124016)获取登录的用户信息。
