# FFDrawFrameInfo

绘制预测帧信息。

**Structure Declaration**

```screen
typedef struct FFDrawFrameInfo {
    FFStructureType sType;
    const void* pNext;
    uint32_t target;
    FFBool targetIsTexture;
    FFBool doDraw;
} FFDrawFrameInfo;
```

**Members**

|Name|Mandatory/Optional|Description|
|:--------------|:-----------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|sType|Mandatory|此结构体类型必须为**FF_STRUCTURE_TYPE_DRAW_FRAME_INFO**。|
|pNext|Optional|指向功能扩展链中的下一个结构体的指针。扩展参数，可缺省，默认值为NULL。|
|target|Mandatory|预测帧的纹理ID。当[doDraw](#ZH-CN_TOPIC_0000001838253753__p13450152411593)为FF_TRUE时，此值必须为非零值。|
|targetIsTexture|Mandatory|绘制对象是否为Texture。 * FF_TRUE：绘制对象是Texture，需要在[target](#ZH-CN_TOPIC_0000001838253753__p64491024115911)中传入TextureID。 * FF_FALSE：绘制对象不是Texture，需要在[target](#ZH-CN_TOPIC_0000001838253753__p64491024115911)中传入framebufferID。|
|doDraw|Mandatory|是否执行绘制。 * FF_TRUE：执行绘制。 * FF_FALSE：不执行绘制。|
