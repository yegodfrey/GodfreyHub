# 开始文件识别

待检测文件上传成功后，调用此接口开始进行广告识别。

## 使用约束

需要保证待识别文件已经上传成功。

## 接口原型

|承载协议|HTTPS POST|
|-----|----------------------------------------------------------------------------------------------|
|接口方向|开发者服务器 -> 华为服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/gmme/openapi/ad/{appId}/identification/{fileId}/start|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 请求参数

### path

|参数名称|必选（M）/可选（O）|类型|参数说明|
|:-----|:----------|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
|appId|M|String|应用ID，具体获取请参见[准备游戏信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-gameinformation-0000001327081581)。|
|fileId|M|String|文件ID， [获取文件上传地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-obtaining-upload-address-restapi-0000001623600041)接口返回的fileId。|

### Request Header

|参数名称|必选（M）/可选（O）|类型|参数说明|
|:------------|:----------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Content-Type|M|String|取值为：application/json; charset=UTF-8。|
|Authorization|M|String|签名信息，用于校验消息是否可信，格式为"Authorization: Bearer ${access_token}"，其中access_token为调用[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-obtaintoken-restapi-0000001624528617)接口返回的access_token。|
|client_id|M|String|客户端ID，具体获取请参见[准备游戏信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-gameinformation-0000001327081581)。|
|requestId|M|String|请求ID，请勿使用重复的请求ID进行请求。|

## 请求示例

```screen
POST https://connect-api.cloud.huawei.com/api/gmme/openapi/ad/{appId}/identification/{fileId}/start
Content-Type: application/json
Authorization: Bearer 1B6F4A44F5AB******AB78FACCAD51A54DB73ECBFD3C90AE35082E8
client_id: 12***67
requestId: 12***789
```

## 响应参数

|参数名称|必选（M）/可选（O）|类型|参数说明|
|:---|:----------|:------|:---------------------------------------------------------------------------------------|
|code|M|Integer|返回码。 * 0：成功。 * 600001：无效参数。 * 600045：应用不属于当前团队。 * 600104：应用未开启IM功能。 * 600184：创建广告识别任务失败。|
|msg|M|String|描述信息。|

## 响应示例

```screen
{
    "ret": {
        "code": 0,
        "msg": "Success"
    }
}
```

## 调用示例

```screen
private void start() throws IOException {
        OkHttpClient client = new OkHttpClient().newBuilder().build();
        MediaType mediaType = MediaType.parse("text/plain");
        RequestBody body = RequestBody.create(mediaType, "");
        Request request = new Request.Builder()
            .url(url + "/api/gmme/openapi/ad/" + this.appId + "/identification/" + fileId + "/start")
            .method("POST", body)
            .addHeader("requestId", "" + new Random().nextLong())
            .addHeader("client_id", this.clientId)
            .addHeader("Authorization", "Bearer " + this.token)
            .build();
        Response response = client.newCall(request).execute();
        ResponseBody responseBody = response.body();
        String bodyStrRespon = "";
        BufferedSource source = responseBody.source();
        source.request(Long.MAX_VALUE);
        Buffer buffer = source.getBuffer();
        Charset charset = Charset.forName("UTF-8");
        MediaType contentType = responseBody.contentType();
        if (contentType != null) {
            try {
                charset = contentType.charset(charset);
            } catch (UnsupportedCharsetException e) {
                e.printStackTrace();
            }
        }
        bodyStrRespon = buffer.clone().readString(charset);
        System.out.println(bodyStrRespon);
    }
```
