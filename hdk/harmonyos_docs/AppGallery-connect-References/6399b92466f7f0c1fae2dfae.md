# 修改版本文件列表

## 功能介绍

此接口用于对基线版本需要删除的文件做版本修改，标记需要删除文件的绝对路径，在归档版本时处理文件。

## 使用约束

* 如果您的新版本是全新版本（未基于基线版本创建），或者基线版本内没有需要删除的版本文件，不需要调用该接口。
* 当新版本的版本状态为"CREATED"时，可调用该接口。
* 可多次标记基线版本文件，基线版本文件一旦标记为"待删除"，无法撤销和回退，需要[删除版本](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudhost-restversion-0000001166577876#section62275462013)后重新[创建版本](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudhost-restversion-0000001166577876#section1547061019390)。

## 接口原型

|承载协议|HTTPS POST|
|-----|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|接口方向|开发者服务器 -> 华为服务器|
|接口URL|https://{domain}/api/cloudhosting/web/v1/version/modifyFilelist 其中{domain}依站点区分： * 中国：connect-api.cloud.huawei.com * 德国：connect-api-dre.cloud.huawei.com * 新加坡：connect-api-dra.cloud.huawei.com * 俄罗斯：connect-api-drru.cloud.huawei.com > 注意 > 调用[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)接口时使用的域名必须与本接口域名保持一致，例如欧洲站点使用"connect-api-dre.cloud.huawei.com"，则调用[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)接口必须使用"https://connect-api-dre.cloud.huawei.com/api/oauth2/v1/token"。|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 请求参数

### Header

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:-----|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Authorization|M|String|认证鉴权信息。 认证方式：Bearer token。 格式:"Authorization: Bearer ${access_token}"。 access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)中获取的access_token。|
|productId|M|String|项目ID，获取方法参考[查询开发者账号ID及项目ID](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-developerid-projectid-0000001166543063)。|
|requestid|M|String|自定义的请求字符串，必须唯一标识此请求。|
|client_id|M|String|客户端ID，获取方法参考[创建API客户端](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudhost-getstarted-0000001166760172#section59981526588)。|
|service|M|String|API业务标识。固定值：hosting。|

### Body

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|siteId|M|String(64)|云托管站点版本所在的站点ID。 可根据站点名称查询站点ID，获取方法参考[查询站点信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-cloudhost-querysite-0000001166826430)。|
|version|M|String(64)|当前版本的版本号（仅支持版本状态为"CREATED"的版本）。|
|deleteFiles|M|List<String>|需要删除的文件列表（文件的绝对路径），一次最多删除1000个。|

## 请求示例

```screen
curl --location --request POST 'https://connect-api.cloud.huawei.com/api/cloudhosting/web/v1/version/modifyFilelist' \
--header 'productId: 258779603740930923' \
--header 'Authorization: Bearer eyJraWQiOiJJQXNyU************FEBJWctGVEI7hU' \
--header 'requestid: 876456' \
--header 'client_id: 7261907****1591808' \
--header 'service: hosting' \
--header 'Content-Type: application/json' \
--data-raw '{
    "siteId": "KCM647QqTvyk7AqvH49jqQ",
    "version":"VIT6OmERQLiJREDr589mwA",
    "deleteFiles": [
        "/js/abc.js"
    ]
}'
```

## 响应参数

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------|:----------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------|
|code|O|String|修改结果状态码，参考[状态码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-cloudhost-errorcode-0000001260940301)。|
|message|O|String|修改结果描述。|
|ret|O|String|包含返回码及描述信息的JSON字符串，格式为{"code":*retcode* , "msg": "*description*"}，retcode为返回码，description为返回码描述信息。|

## 响应示例

### 成功示例

```screen
{
    "code": "0",
    "message": "OK"
}
```

### 业务失败示例

```screen
{
	"code":"VERSION.0005",
	"message":"Invalid version status."
}
```

### 鉴权失败示例

```screen
{
    "ret": {
        "code": 205524993,
        "msg": "client token auth failed"
    }
}
```
