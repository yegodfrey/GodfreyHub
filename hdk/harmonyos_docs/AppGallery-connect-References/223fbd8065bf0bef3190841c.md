# 获取元服务新增留存的报表文件

#### 功能介绍

获取元服务新增留存的报表数据的CSV或者Excel文件地址。

如果接口调用者是普通开发者，则接口调用者的角色：账号持有者、国内管理员、App管理员、国内运营。  

#### 接口原型

|承载协议|HTTPS GET|
|接口方向|开发者服务器 -\> 华为服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/report/distribution-operation-quality/v1/fa/userAnalysisExport/{appId}|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|
|-----|---------------------------------------------------------------------------------------------------------------|

#### Query

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:---------|:----------|:---------|:----------------------------------------------------------------------|
|language|O|String(10)|查询语言。 报表title会根据不同语言来展现。 只支持简体中文（zh-CN）, 美式英文（en-US），俄文（ru-RU）。 默认简体中文。|
|startTime|M|String|查询开始时间。 UTC时间。 格式：YYYYMMDD startTime和endTime之间不超过180天。|
|endTime|M|String|查询结束时间。 UTC时间。 格式：YYYYMMDD startTime和endTime之间不超过180天。|
|userTag|M|Integer|统计维度类型。 取值范围： * 0：按照账号维度 * 1：按照设备维度 默认值：0|
|exportType|O|String|导出文件类型。 取值范围： * CSV：导出CSV文件格式 * EXCEL：导出Excel文件格式 默认值：CSV|

#### 响应参数

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------|:----------|:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|fileURL|M|String|导出CSV或Excel文件的路径。 报表文件中字段语言由language参数指定。报表字段当前仅支持中文，您可以点击[文件样例.zip](https://media:801773137285778472)下载样例文件。 文件中包含的字段说明请参见[下载元服务新增留存的报表数据说明](#ZH-CN_TOPIC_0000001738465949__zh-cn_topic_0000001707833313_p25111717122119)。|
|ret|M|String|包含返回码及描述信息的JSON字符串。 格式为{"code":retcode, "msg": "description"}，其中retcode为返回码，description为返回码描述信息。|

下载元服务新增留存的报表数据说明  

|字段名|字段含义|
|:--------|:----------------|
|时间|数据统计日期。|
|新增用户数|首次访问服务的去重用户数。|
|活跃用户数|访问服务的去重用户数。|
|新增用户次日留存率|统计日新增用户次日保持活跃的比率。|
|新增用户三日留存率|统计日新增用户三日保持活跃的比率。|
|新增用户七日留存率|统计日新增用户七日保持活跃的比率。|
|新增设备数|首次访问服务的去重设备数。|
|活跃设备数|访问服务的去重设备数。|
|新增设备次日留存率|统计日新增设备次日保持活跃的比率。|
|新增设备三日留存率|统计日新增设备三日保持活跃的比率。|
|新增设备七日留存率|统计日新增设备七日保持活跃的比率。|
