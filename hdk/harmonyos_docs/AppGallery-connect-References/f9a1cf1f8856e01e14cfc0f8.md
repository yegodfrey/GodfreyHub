# InstantPublishBean

|Class Info|
|:--------------------------------------------|
|public class InstantPublishBean 游戏内嵌社区一键发布参数。|

#### Properties

|Name|Type|Description|
|:------------|:---------|:---------------------------------------------------------------------------------------------------------------|
|imagePaths|String\[\]|动态内容的配图路径。发布动态的配图要求如下： * 配图数量：单次发布动态最多9张图片。 * 配图格式：仅支持"jpeg"、"jpg"、"png"、"webp"、"gif"、"bmp"。 * 配图大小：最大支持10MB的文件。|
|momentContent|String|动态文本内容。仅支持纯文本字符，不支持表情符号；最大长度1000字节，超出长度的部分会被自动截断。|
