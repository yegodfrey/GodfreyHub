# StorageReference

|Interface Info|
|:----------------------------------------------------------------------------|
|export interface StorageReference 云端文件的引用，提供对象的列举、上传、下载、获取文件的下载地址、删除等各项操作的封装。|

## Method Summary

|Qualifier and Type|Method Name and Description|
|:------------------|:------------------------------------------------------------------------------------------------|
|Promise<string>|[getName](#section14179124773813)() 获取文件或目录名。|
|Promise<string>|[getBucket](#section12269491489)() 获取引用所在的存储实例名称。|
|Promise<void>|[getFile](#section47883211503)(filePath: string) 下载一个云端文件到本地路径并指定文件名称。|
|Promise<void>|[putFile](#section169241706523)(filePath: string) 将本地文件上传到云端。|
|Promise<void>|[delete](#section152912175213)() 删除StorageReference引用下的文件。|
|Promise<string>|[getDownloadURL](#section106353585619)() 获取StorageReference引用的下载地址，不支持目录的下载地址获取。|
|Promise<ListResult>|[listAll](#section51714428108)() 获取StorageReference引用下的所有文件和目录列表信息。|
|Promise<ListResult>|[list](#section13898839105413)(max: number) 获取StorageReference引用下的指定数量的文件列表。|
|Promise<ListResult>|[listByMarker](#section10491155545613)(max: number, marker: string) 分页获取StorageReference引用下的文件列表。|
