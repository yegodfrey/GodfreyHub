# 获取用户ID

#### 功能介绍

通过accessToken获取抽奖用户ID，即userId。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|华为服务器 -\> 开发者服务器|
|接口URL|开发者提供用户认证接口URL，必须为HTTPS协议。|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|
|-----|-------------------------------------------------------------------|

#### 请求参数

请求参数以JSON格式传入，包含参数如下。  

|参数名称|必选(M)/可选(O)|数据类型|参数说明|
|:----------|:----------|:----------|:----|
|accessToken|M|String(256)|认证凭据。|

#### 请求示例

```
POST https://your_auth_url
Content-Type: application/json; charset=utf-8
{
   "accessToken":"eyJhbGciOiJIUzU****************"
}
```

#### 响应参数

返回值为JSON格式的字符串，包含参数如下。  
![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220711103005.64247406783625314738569922445005:50530710025050:2800:FA7F45D325B2415E192DAF3EC8C25910C6A384A9F43D5349A7897370ABA21396.png?needInitFileName=true?needInitFileName=true)  
返回码使用标准HTTP状态码，详情请参考对应模板的返回码。  

|参数名称|必选(M)/可选(O)|数据类型|参数说明|
|:-----|:----------|:----------|:--------------------|
|userId|O|String(100)|根据accessToken获取的用户ID。|

#### 响应示例

```
HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8
{
    "userId": "10****01"
}
```
