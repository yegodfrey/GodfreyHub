# FFCvvZSemantic

规则观察体的Z轴可视坐标范围（以及深度测试方式）。  
Enum Info

```
typedef enum FFCvvZSemantic {
    FF_CVV_Z_SEMANTIC_MINUS_ONE_TO_ONE_FORWARD_Z = 0,
    FF_CVV_Z_SEMANTIC_ZERO_TO_ONE_REVERSE_Z = 1,
    FF_CVV_Z_SEMANTIC_MINUS_ONE_TO_ONE_REVERSE_Z = 2,
    FF_CVV_Z_SEMANTIC_ZERO_TO_ONE_FORWARD_Z = 3,
} FFCvvZSemantic;
```

Enum Value Summary  

|Enum Value|Description|
|:-------------------------------------------|:------------------------------------------------------------------------------------------------------------|
|FF_CVV_Z_SEMANTIC_MINUS_ONE_TO_ONE_FORWARD_Z|默认值。投影矩阵输出Z/W在\[-1, 1\]范围内，无需任何调整。如果投影矩阵是类似OpenGL的剪辑空间，则将使用此值。深度测试是用"\<="，即使用"小于或等于"比较函数进行的。|
|FF_CVV_Z_SEMANTIC_ZERO_TO_ONE_FORWARD_Z|投影矩阵输出Z/W在\[0, 1\]范围内，然后需手动调整到GL要求的\[-1, 1\]NDC范围。如果投影矩阵是类似DirectX的剪辑空间，则将使用此值。深度测试是用"\<="，即使用"小于或等于"比较函数进行的。|
|FF_CVV_Z_SEMANTIC_MINUS_ONE_TO_ONE_REVERSE_Z|与FF_CVV_Z_SEMANTIC_MINUS_ONE_TO_ONE_FORWARD_Z相同，但深度测试是使用"\>="完成的，即"大于或等于"比较函数。|
|FF_CVV_Z_SEMANTIC_ZERO_TO_ONE_REVERSE_Z|与FF_CVV_Z_SEMANTIC_ZERO_TO_ONE_FORWARD_Z相同，但深度使用"\>="完成，即"大于或等于"比较函数。|
