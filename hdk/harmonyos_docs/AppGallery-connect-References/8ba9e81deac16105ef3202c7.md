# CountryPriceInfo

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|price|M|Integer(64)|价格。|
|taxRate|O|String|税率。|
|taxValue|O|String|税额。|
|currencyCode|M|String|币种，用于支付的币种，请参见[国家/地区、语言、币种列表](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-supported-countries-overview-0000001146718725)。 如USD、CNY、MYR。默认CNY。|
|country|M|String|国家码，用于区分国家信息，请参见[国家/地区、语言、币种列表](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-supported-countries-overview-0000001146718725)。 如CN。默认CN。|
|countryChName|M|String|国家中文显示名称。|
|countryEnName|M|String|国家英文显示名称。|
