# FFPerFrameFinalColorData

每帧数据的最终颜色信息。  
Structure Declaration

```
typedef struct FFPerFrameFinalColorData {
    FFStructureType sType;
    const void* pNext;
    uint32_t finalColorTexture;
} FFPerFrameFinalColorData;
```

Members  

|Name|Mandatory/Optional|Description|
|:----------------|:-----------------|:-----------------------------------------------------|
|sType|Mandatory|此结构体类型必须为FF_STRUCTURE_TYPE_PER_FRAME_FINAL_COLOR_DATA。|
|pNext|Optional|指向扩展链中的下一个结构体的指针。扩展参数，可缺省，默认值为NULL。|
|finalColorTexture|Mandatory|带有UI的纹理信息。|
