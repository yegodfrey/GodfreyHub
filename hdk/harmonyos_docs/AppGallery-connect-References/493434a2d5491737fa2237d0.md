#### requestPhoneVerifyCode

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|requestPhoneVerifyCode(countryCode:string, phoneNumber:string,settings: VerifyCodeSettings):Promise\<[VerifyCodeResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-verifycoderesult-0000001522438129)\> 申请手机的验证码。|

Parameters  

|Name|Description|
|:----------|:-------------------------------------------------------------|
|countryCode|国际电话区号，例如中国为86，德国49，俄罗斯7，新加坡65。 本字段支持多种格式（以中国为例），如："86"，"+86"。|
|phoneNumber|手机号，需要去掉"+"号 和国家（地区）码，例如："+86132xxxxxxxx"，则取值"132xxxxxxxx"。|
|settings|验证码参数设置，可以设置验证码类型、发送语言和发送间隔。|

Return  

|Type|Description|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------|
|Promise\<[VerifyCodeResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-verifycoderesult-0000001522438129)\>|VerifyCodeResult的异步返回对象。|

Sample Code

```
let verifyCodeSettings = new VerifyCodeSettingBuilder()
  .setAction(VerifyCodeAction.REGISTER_LOGIN)
  .setLang('zh_CN')
  .setSendInterval(60)
  .build();
agconnect.auth().requestPhoneVerifyCode('countryCode','phoneNumber',verifyCodeSettings) 
```

#### resetPasswordByPhone

|Method|
|:--------------------------------------------------------------------------------------------------------------------|
|resetPasswordByPhone(countryCode: string, phoneNumber: string, newPassword: string, verifyCode: string) 通过手机账号重置用户密码。|

Parameters  

|Name|Description|
|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|countryCode|国家码。是指国际电话区号，例如中国为86，德国49，俄罗斯7，新加坡65。 本字段支持多种格式（以中国为例），例如："86"、"+86"。|
|phoneNumber|手机号。需要去掉"+"号和国家（地区）码，例如："+86132xxxxxxxx"，则取值"132xxxxxxxx"。|
|newPassword|新密码。 默认密码规则如下，若您参考[安全配置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-security-configuration-0000001324925609)自定义了密码复杂度，请满足自定义的复杂度： 1. 密码长度至少8个字符。 2. 密码必须包含如下至少两种字符的组合： * 至少一个小写字母 * 至少一个大写字母 * 至少一个数字 * 至少一个特殊字符：\`!@#$%\^\&\*()-_=+\\\|\[{}\];:'",\<.\>/? 和空格 3. 密码不能和手机号码或者邮箱一样。|
|verifyCode|验证码。|

Sample Code

```
agconnect.auth().resetPasswordByPhone(countryCode, phoneNumber, newPassword, verifyCode);
```
