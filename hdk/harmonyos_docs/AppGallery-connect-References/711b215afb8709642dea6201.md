# ohAegUint8ArrayToString

ohAegUint8ArrayToString(input: Uint8Array): string

Uint8Array格式转换为字符串。

导入模块：

```
import { AegStrUtil } from '@hw-agconnect/petal-aegis';
```

参数：  

|参数名|类型|必填|说明|
|:----|:---------|:-|:-------------------|
|input|Uint8Array|是|待转换的Uint8Array格式的内容。|

返回值：  

|参数|类型|说明|
|:--|:-----|:-------|
|字符串|String|转换后的字符串。|

示例：

```
import { AegStrUtil } from '@hw-agconnect/petal-aegis';

function uint8ArrayToString() {
  let strUtil: AegStrUtil = new AegStrUtil()
  let input = new Uint8Array([104, 101, 108, 108, 111, 32, 119, 111, 114, 108, 100])
  let result = strUtil.ohAegUint8ArrayToString(input)
  //uint8ArrayToString  result: hello world
  console.log("uint8ArrayToString ", 'result: ' + result);
}
```
