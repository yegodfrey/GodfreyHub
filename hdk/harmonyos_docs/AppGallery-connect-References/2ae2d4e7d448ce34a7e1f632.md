# VerifyCodeResult

验证码申请结果。  

#### Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-------------------------------------------------------------|
|string|[getShortestInterval](#section33984206325)() 获取两次发送验证码的最小时间间隔。|
|string|[getValidityPeriod](#section3114184812329)() 获取验证码有效期。|

#### Methods

#### getShortestInterval

|Method|
|:---------------------------------------------|
|getShortestInterval():string 获取两次发送验证码的最小时间间隔。|

Return  

|Type|Description|
|:-----|:--------------------|
|string|两次发送验证码的最小时间间隔。 单位：秒。|

Sample Code

```
agconnect.auth().requestPhoneVerifyCode('countryCode','phoneNumber',{action: VerifyCodeAction.REGISTER_LOGIN, lang: 'zh_CN', sendInterval: 60}).then(result => {
  var shortestInterval = result.getShortestInterval();
})
```

|Method|
|:-----------------------------------|

Return

|:-----|:------------|

Sample Code

```
agconnect.auth().requestVerifyCode('countryCode','phoneNumber',{action: VerifyCodeAction.REGISTER_LOGIN, lang: 'zh_CN', sendInterval: 60}).then(result => {

```
