# 查询项目详情及项目下的应用

## 功能介绍

此接口用于查询指定项目的详细项目信息和项目下的应用列表信息。

## 接口原型

|承载协议|HTTPS GET|
|-----|--------------------------------------------------------------------------------|
|接口方向|开发者服务器 -> 华为服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/project-service/v1/projects/{projectId}|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 请求参数

### Header

> 说明
>
> 本接口支持使用Service Account方式和OAuth客户端方式，二者区别请参见[使用入门](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114)。

**Service Account方式：**

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Authorization|M|String|认证信息，格式为"Authorization: Bearer *${JWT}* "。JWT为[通过Service Account方式获取授权](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section1785535363715)中获取的鉴权令牌。|

**OAuth客户端方式：**

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
|oauth2Token|M|String|认证信息，传入[获取用户授权码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section949717114392)中获取的Access Token。|

### Path

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:--------|:----------|:-----|:---------|
|projectId|M|String|需要查询的项目ID。|

### Query

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:--------|:----------|:-----|:-----------------------------------------------------------|
|queryFlag|O|String|是否需要查询项目下的应用信息。 * 0：不需要 * 1：需要 如果不传，默认值：0，响应参数中将不会返回appList。|

## 响应参数

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------|:----------|:-------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------|
|project|M|[Project](#ZH-CN_TOPIC_0000001158365067__zh-cn_topic_0000001059897765_p16958125112238)|项目信息。如果未查到项目信息，则返回空。|
|ret|M|String|包含返回码及描述信息的JSON字符串，格式为{"code":*retcode* , "msg": "*description*"}，retcode为返回码，description为返回码描述信息。|

**Project**

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:---------------------------------------------------------------------------------------------|:----------------------------------------------------------------------|
|projectId|O|String|项目ID|
|name|O|String|项目名称。|
|description|O|String|项目描述信息。|
|siteId|O|String|项目的数据存储位置。 * SG：新加坡站点 * DE：德国站点 * RU：俄罗斯站点 * CN：中国站点 如果项目未设置数据存储位置，则为空。|
|teamId|O|String|项目归属的团队账号ID。|
|appList|O|List<[AppBriefInfo](#ZH-CN_TOPIC_0000001158365067__zh-cn_topic_0000001059897765_p14226276613)>|该项目下的应用列表信息。如果请求参数queryFlag传入0，则不返回此参数。|
|downloadKey|O|Integer|项目中是否下载密钥。 * 1：下载 * 0：不下载|
|createTime|O|Integer|项目创建时间的UTC时间戳。|
|updateTime|O|Integer|最近一次项目修改时间的UTC时间戳。|
|accessTime|O|Integer|开发者账号在AppGallery Connect控制台中最近一次访问项目的时间，格式为UTC时间戳。|

**AppBriefInfo**

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:-------------|:----------|:-------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------|
|appId|O|String|应用ID。|
|appName|O|String|应用名称。|

|deviceType|O|Integer|设备类型。 * 4：手机 * 5：平板 * 6：VR * 7：手表 * 8：大屏 * 9：路由器 * 10：车机|
|detailType|O|Integer|应用的详细类型。 * 1：移动应用 * 2：电视应用 * 4：路由器应用 * 8：VR应用 * 9：手表应用 * 19：手机快应用 * 23：电视快应用 * 27：车机应用 * 28：车机快应用 * 9998：iOS应用 * 9999：WEB应用|
|appIcon|O|String|应用图标的URL地址。|
|packageName|O|String|应用包名。|
|hasPermission|O|Integer|当前开发者账号是否对应用有权限。 * 0：否 * 1：是|
|deviceTypes|O|List<[DeviceTypeInfo](#ZH-CN_TOPIC_0000001158365067__p999854164318)>|应用的设备类型，可支持多个设备。|
|iosAppStoreId|O|String|应用在苹果APP Store上的ID，对iOS应用有效。|
|iosTeamId|O|String|iOS团队ID，对iOS应用有效。|
|parentType|O|Integer|应用的一级分类。 * 2：游戏 * 13：应用|
|childType|O|String|应用的二级分类，详细请参见[应用分类](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-reference-apptype-0000001158365069)。|
|grandChildType|O|String|应用的三级分类，详细请参见[应用分类](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-reference-apptype-0000001158365069)。|

**DeviceTypeInfo**

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:------|:------------------------------------------------------------------------------------------------------------------------|
|deviceType|M|Integer|设备类型。 * 4：手机 * 6：VR * 7：手表 * 8：大屏 * 9：路由器 * 10：车机|
|appAdapters|M|String|适配设备类型，多个间逗号分隔。 * 1：荣耀立方（路由器） * 4：手机 * 5：平板 * 6：VR * 7：手表（智能表Android wear系统） * 8：TV * 9：路由器 * 11：儿童手表 * 12：智能手表 * 13：带屏音箱|

## 调用示例

```screen
public static void getUserTeamList(String domain, String oauth2Token, String projectId, String queryFlag) {
 HttpGet get = new HttpGet(domain + "/project-service/v1/projects/{" + projectId "}? queryFlag="+queryFlag);
get.setHeader("oauth2Token", oauth2Token);
try {
	CloseableHttpClient httpClient = HttpClients.createDefault();
	CloseableHttpResponse httpResponse = httpClient.execute(get);
	int statusCode = httpResponse.getStatusLine().getStatusCode();
	if (statusCode == HttpStatus.SC_OK) {
		BufferedReader br =
				new BufferedReader(new InputStreamReader(httpResponse.getEntity().getContent(), Consts.UTF_8));
		String result = br.readLine();
		JSONObject object = JSON.parseObject(result);
		System.out.println(object.get("ret"));
		Project project = (Project) object.get("project");
	}	
}
     catch (Exception e) {
   }
}
```
