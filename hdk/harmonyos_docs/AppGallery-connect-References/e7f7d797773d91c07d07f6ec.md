# GPMManager

|Class Info|
|:--------------------------------------------------------------|
|游戏性能管理SDK类。 OBJECTIVE-C ``` @interface GPMManager: NSObject ```|

#### - init:

初始化游戏性能管理SDK，该方法为异步初始化。

OBJECTIVE-C

```
- (void)init:(GPMInitParams *_Nonnull)initParams callbackDelegate:(id<GPMCallbackDelegate> _Nonnull)callbackDelegate;
```

Parameters  

|Name|Description|
|:------------------------------------------------------------------------------------------------------------------------------|:----------|
|[initParams](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-ios-gpminitparams-0000001969176033)|GPM初始化配置参数。|

Sample Code  
OBJECTIVE-C

```
GPMInitParams initParams = [[GPMInitParams alloc] init];
initParams.appId = appId;
initParams.clientId = clientId;
initParams.accessToken = accessToken; 
initParams.logLevel = 3;
initParams.userIdentity = userIdentity;
SelfGpmCallbackDelegate *delegate = [[SelfGpmCallbackDelegate alloc] init];
[GPMManager.getInstance init:initParams callbackDelegate:delegate];
```
