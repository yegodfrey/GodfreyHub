# ConfigVersion

|参数|必选(M)/可选(O)|类型|描述|
|:---------|:----------|:---|:---------------------------------|
|version|M|Long|当前最新版本号，如果是首次新增则为0，如果非首次则传入最新的版本号。|
|updateTime|M|Long|版本配置时间，为1970以来的毫秒数。|
