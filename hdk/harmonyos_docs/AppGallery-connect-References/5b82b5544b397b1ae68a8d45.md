# RecordResult

|class Info|
|:------------------------------|
|public class RecordResult 录制结果。|

#### Property Summary

|Name|Type|Description|
|:-------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
|code|int|返回码。 说明： 返回值为0则表示成功，其他[返回值](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/replayerrorcode-common-exceptions-0000001690642713)则表示失败。|
|msg|String|返回码描述信息。|
|filePath|String|包含文件名的视频导出路径。|
|tag|String|自定义标签，用于标记回调对应关系，便于失败处理，选填。|
