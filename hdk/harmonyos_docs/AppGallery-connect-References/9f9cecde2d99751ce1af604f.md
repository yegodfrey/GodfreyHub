# VerifyCodeResult

验证码申请结果。  

#### Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-------------------------------------------------------------|
|String|[getShortestInterval](#section23341483390)() 获取两次发送验证码的最小时间间隔。|
|String|[getValidityPeriod](#section511335013411)() 获取验证码有效期。|

#### Methods

#### getShortestInterval

|Method|
|:---------------------------------------------|
|getShortestInterval():string 获取两次发送验证码的最小时间间隔。|

Return  

|Type|Description|
|:-----|:--------------------------|
|string|两次发送验证码的最小时间间隔。 最小时间间隔，单位：秒|

Sample Code

```
agconnect.auth.PhoneAuthProvider.requestVerifyCode('countryCode','phoneNumber',agconnect.auth.Action.ACTION_REGISTER_LOGIN,'lang',sendInterval).then(result => {
var shortestInterval = result.getShortestInterval();
})
```

<br />

#### getValidityPeriod

|Method|
|:-----------------------------------|
|getValidityPeriod():string 获取验证码有效期。|

Return  

|Type|Description|
|:-----|:--------------|
|string|验证码有效期 有效期，单位：秒|

Sample Code

```
agconnect.auth.PhoneAuthProvider.requestVerifyCode('countryCode','phoneNumber',agconnect.auth.Action.ACTION_REGISTER_LOGIN,'lang',sendInterval).then(result => {
var validityPeriod = result.getValidityPeriod();
})
```
