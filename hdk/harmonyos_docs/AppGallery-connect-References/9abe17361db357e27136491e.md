# 按条件查询商品促销信息

#### 功能介绍

此接口用于商品促销查询，支持多条件过滤。  

#### 使用约束

接口调用者的角色：账号持有者、管理员、APP管理员、运营。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者服务器-\>数字商品服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/pms/product-price-service/v2/manage/product/promotion/list|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|---------------------------------------------------------------------------------------------------|

#### Body

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|requestId|M|String(64)|请求序列，开发者自定义唯一标识符。|
|productNo|O|String|查询指定的商品的促销信息。|
|promotionId|O|String|预留字段，暂不启用。|
|strategy|O|String|策略类型： * trial：免费（仅自动续期型商品支持） * introductory：按周期扣费（仅自动续期型商品支持） * pay-up-front：提前支付（仅自动续期型商品支持） * single-promotion：单商品优惠（仅消耗型，非消耗型，非续期型商品支持）|
|pageNum|O|Integer|请求查询的起始页码，默认值：1。|
|pageSize|O|Integer|每页请求数目，默认每页20条，最大不能超过300。|
|orderBy|O|String|按名称升序或者降序排序。配置JSON对象，key为属性名，value为排序规则。 * key取值范围为： * createTime：创建时间 * updateTime：更新时间 * status：促销进行状态 * startDate：开始促销时间 * endDate：结束促销时间 <!-- --> * value取值desc降序或者asc升序 例如：按createTime升序，updateTime降序, 则配置为{"createTime": "asc","updateTime": "desc"}|
|filterBy|O|String|支持按促销状态和时间过滤。配置JSON对象，key为属性名，value为过滤的值。 key值范围如下： * status：促销状态取值范围为 * 0：正在进行中的促销 * 1：未开始的促销 * 2：已结束的促销 例如：单选{"status":"0"}和多选{"status":\["0", "1"\]} * startDate：促销开始时间范围 例如：{"startDate":{"1621843475000":"1631435475000"}} * endDate：促销结束时间范围 例如：{"endDate":{"1621843475000":"1631435475000"}} * date：该时间范围内开始的促销、结束的促销和进行中的促销活动 例如：{"date":{"1621843475000":"1631435475000"}} key值可以包含上面的所有取值进行组合过滤，比如同时使用status和startDate过滤可以用下面的JSON： {"status":\[ "0","1"\],"startDate":{"1021843475000":"1631435475000"}}|
|promotionType|O|Integer|促销类型，默认值：0。 * 0：新用户促销 * 1：自定义人群促销 * 4：退订挽留促销|
|offerId|O|String|优惠促销标识符，用于区分不同优惠促销，该ID当前商品下唯一，最大长度64个字符，需满足\[0-9a-zA-Z\]，仅在促销类型为自定义人群促销时支持。|

#### 调用示例

```
"Java"
public static ProductPromotionQueryResp getProductPromotions(String domain, String clientId, String authorization, 
    String appId, ProductPromotionQueryReq request) { 
    ProductPromotionQueryResp resp = null;  
    try {  
        String url = domain + "/api/pms/product-price-service/v2/manage/product/promotion/list";  
        HttpPost post = new HttpPost(url);  
        post.setHeader(new BasicHeader("Authorization", "Bearer " + authorization));  
        post.setHeader(new BasicHeader("client_id", clientId));  
        post.setHeader(new BasicHeader("appId", appId)); // 使用appId

        StringEntity entity = new StringEntity(JSON.toJSONString(request),  
            ContentType.create("application/json", "UTF-8"));  
        post.setEntity(entity);  

        CloseableHttpClient httpClient = HttpClients.createDefault();  
        HttpResponse response = httpClient.execute(post);  
        int statusCode = response.getStatusLine().getStatusCode();  
        if (statusCode == HttpStatus.SC_OK) {  
            String result = EntityUtils.toString(response.getEntity(), Consts.UTF_8);  
            if (StringUtils.isNotEmpty(result)) { 
                resp = JSON.parseObject(result, ProductPromotionQueryResp.class);  
            }  
        }  
        post.releaseConnection();  
        httpClient.close();  
    } catch (Exception e) {  
        e.printStackTrace(); // 打印异常信息，以便调试
    }  
    return resp;  
}
```
