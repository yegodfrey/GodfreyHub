# TokenResult

登录用户的Token信息。

## Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:------------------------------------------------------------------------------|
|String|[getToken](#section1696914441077)() ```screen getString() ``` 返回当前登录用户的Token信息。|
|number|[getExpirePeriod](#section18283511686)() 返回当前登录用户Token的有效期。|

## Methods

### getToken

|Method|
|:-----------------------------------|
|getString():string 返回当前登录用户的Token信息。|

**Return**

|Type|Description|
|:-----|:--------------|
|string|当前登录用户的Token信息。|

**Sample Code**

```screen
agconnect.auth().getCurrentUser().then(user => {
    if (user == null) {                       
        return;          
    }          
    user.getToken(false).then(tokenResult =>{            
        let tokenString = tokenResult.getString;                    
    }).catch(err => {
        alert(err);        
    });
}
```

### getExpirePeriod

|Method|
|:------------------------------------------|
|getExpirePeriod():number 返回当前登录用户Token的有效期。|

**Return**

|Type|Description|
|:-----|:----------------|
|number|获取Token的有效期，单位为秒。|

**Sample Code**

```screen
agconnect.auth().getCurrentUser().then(user => {
    if (user == null) {                       
        return;          
    }          
    user.getToken(false).then(tokenResult =>{            
        let tokenPeriod = tokenResult.getExpirePeriod();                    
    }).catch(err => {
        alert(err);        
    });
}
```
