# FrameFlow_SetResolution2

|Function Info|
|:-------------------------------------------------------------------------------------------------------|
|FFResult FrameFlow_SetResolution2(FFInstance instance, const FFResolutionInfo2* pResolutionInfo); 设置分辨率。|

|Name|Description|
|:--------------|:-------------------------------------------------------------------------------------------------------------------------------------------------|

|Type|Description|
