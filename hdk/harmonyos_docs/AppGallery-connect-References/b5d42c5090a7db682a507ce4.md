# AGCFunctionException

#### Parameters

|Name|Description|
|:------|:------------------|
|message|异常的描述信息。|
|code|异常错误码，一般为此类中定义的错误码。|

#### 错误码

|错误码|值|描述|
|:-----------------------------|:---------|:----------------|
|FAIL_TO_GET_CREDENTIAL_SERVICE|11000|获取Client Token失败。|
|FAIL_TO_GET_NETWORK_SERVICE|11001|网络请求失败。|
|FAIL_TO_CALL_CLOUD_FUNCTION|11002|调用云函数失败。|
|AGC_HTTP_ERROR|10002|调用HTTP请求失败。|
|CLIENT_TOKEN_EXPIRED|0x0c401001|Client Token失效。|
|ACCESS_TOKEN_EXPIRED|0x0c401002|access token失效。|
