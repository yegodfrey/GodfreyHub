# 修改手机号或邮箱地址

## 功能介绍

此接口用于用户修改手机号码或者邮箱地址。

## 接口原型

|承载协议|HTTPS PUT|
|-----|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|接口方向|应用客户端 -> 华为认证服务器|
|接口URL|https://connect-drcn.dbankcloud.cn/agc/apigw/oauth2/third/v1/user-phone-email > 注意 > 调用[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/client-rest-auth-obtaintoken-0000001414202481)接口时使用的域名必须与本接口域名保持一致，例如本接口使用"connect-drcn.dbankcloud.cn"，则调用[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/client-rest-auth-obtaintoken-0000001414202481)接口必须使用"https://connect-drcn.dbankcloud.cn/agc/apigw/oauth2/v1/token"。|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 请求参数

### Query

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:--------|:----------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------|
|productId|M|String|项目ID，查询方法可参见[查询项目ID](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-developerid-projectid-0000001166543063)。|

### Header

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:-----|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|M|String|客户端ID，获取方法参考[获取客户端API授权](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-obtain-client-apiauthorization-0000001453744605)。|
|Authorization|M|String|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/client-rest-auth-obtaintoken-0000001414202481)中获取的access_token。|
|access_token|M|String|认证凭据。用户登录成功后，在登录接口的[响应参数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/client-rest-auth-signin-0000001294069348#section141867136564)"accessToken"中获取。|

### Body

|参数名称|必选（M）/可选（O）|参数类型|参数说明|
|:------------|:----------|:-----|:----------------------------------------------|
|lang|O|String|语言，格式为"zh_CN"。|
|newPhone|O|String|新手机号。|
|newEmail|O|String|新邮箱地址。 新邮箱地址和新手机号必填一个且只能填一个，即一次只修改手机号或者只修改邮箱地址。|
|newVerifyCode|M|String|新验证码。|

## 响应参数

|参数|必选（M）/可选（O）|参数类型|描述|
|:--|:----------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|ret|O|String(100)|包含返回码及描述信息的JSON字符串，格式为{"code":*retcode* , "msg": "*description* "}，retcode为返回码，description为返回码描述信息。返回码请参见[错误码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/client-rest-auth-errorcode-0000001353626777)。|

```screen
{
	"ret": {
		"code": 0,
		"msg": "string"
	}
}
```

## 调用示例

```screen
"Java"
    /**
     * 修改手机号
     *
     * @param token access_token 认证凭据
     * @param clientId 客户端ID
     * @param productId 项目ID
     * @param accessToken
     * @param newPhone 新手机号
     * @return 接口结果
     * @throws IOException 异常
     */
    public static AuthOperateRsp modifyPhoneOrEmail(String token, String clientId, String productId, String accessToken,
        String newPhone) throws IOException {
        UpdateUserPhoneEmailReq req =
            new UpdateUserPhoneEmailReq()
            .newPhoneSet(newPhone)
            .newVerifyCodeSet("123456")
//            .newEmailSet("when modify email")
            .langSet("zh_CN");

        HttpClient client = HttpClients.createDefault();

        HttpPut httpPut = new HttpPut("https://connect-drcn.dbankcloud.cn/agc/apigw/oauth2/third/v1/user-phone-email?productId=" + productId);

        httpPut.setEntity(new StringEntity(JSON.toJSONString(req), Charset.forName("UTF-8")));

        httpPut.setHeader("Accept", "application/json");
        httpPut.setHeader("Content-Type", "application/json;charset=utf-8");
        httpPut.setHeader("client_id", clientId);
        httpPut.setHeader("Authorization", "Bearer " + token);
        httpPut.setHeader("access_token", accessToken);

        HttpResponse response = client.execute(httpPut);

        return JSON.parseObject(IOUtils.toString(response.getEntity().getContent(), StandardCharsets.UTF_8),
            AuthOperateRsp.class);
    }
```
