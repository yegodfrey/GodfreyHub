# ProductPromotions

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:--------------------|:----------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
|promotionId|M|String|优惠唯一ID。|
|productId|M|String|关联商品主键ID。|
|startDate|M|Integer(64)|开始促销时间。|
|endDate|O|Integer(64)|结束促销时间。|
|status|M|Integer|促销进行状态： * 0：进行中 * 1：未开始 * 2：已结束（包含强制结束）|
|promotionStatus|M|String|促销状态： * active：上线 * delete：删除 * inactive：下线|
|strategy|M|String|促销策略类型： * trial：免费试用 说明 > 仅当关联商品为auto_subscription类型时支持配置trial。 * introductory：按周期扣费|
|promotionTitle|M|String|促销名称。|
|defaultLocale|O|String|默认语言环境，请参见[国家/地区、语言、币种列表](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-supported-countries-overview-0000001146718725)。 例如：zh_CN、en_US。|
|promotionDesc|O|String|默认促销描述信息。|
|createId|O|String|创建者ID。|
|createTime|O|String|创建时间。|
|updateId|O|String|修改者ID。|
|updateTime|O|String|修改时间。|
|periodUnit|O|String|优惠周期单位： * D：天 * W：周 * M：月 * Y：年|
|numberOfUnits|O|Integer|优惠周期数。如优惠两个月，numberOfUnits=2， periodUnit=M。|
|defaultTier|O|String|返回Null，已经没有实际意义。|
|defaultPrice|O|String|基准换算价格。|
|promotionCountryCount|M|Integer|商品促销的国家数。|
|promotionType|M|Integer|促销类型，默认值：0。 * 0：新用户促销 * 1：自定义人群促销|
