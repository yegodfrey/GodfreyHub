# 监听云数据库事件

## 功能介绍

云函数的CLOUDDB触发器监听云数据库中的onUpsert或onWrite请求消息。当发生这些请求消息时，云函数将对云数据库的数据执行相关操作。

## 接口原型

|承载协议|HTTPS POST|
|-----|-------------------------------------------------------------------|
|接口方向|华为服务器 -> 开发者服务器|
|接口URL|开发者提供用户认证接口URL，必须为HTTPS协议。|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 请求参数

请求参数以JSON格式传入，包含参数如下。

|参数名称|必选(M)/可选(O)|数据类型|参数说明|
|:---------------|:----------|:-----|:------------------------------------------------------------------------------------------------------------------|
|records|M|String|所有字段的数据信息。 其中字段分类如下： * before：历史数据。当首次添加新数据时，历史数据为空。 * after：添加或更新的数据。|
|objectTypeName|M|String|云数据库的对象类型名称。 > 说明 > 在云数据库中对象类型用于定义一组存储的对象。不同的对象类型对应不同的数据结构。 最大长度为30个字符，包括大写字母、小写字母、数字和下划线。必须以大写字母或小写字母开头，但不能包含特殊字符。|
|naturalStoreName|M|String|云数据库的实例名。 长度范围为1~20个字符，可以包含大写字母、小写字母和数字，但不能包含特殊字符。|
|eventType|M|String|操作类型。 取值范围： * onUpsert：数据表插入或更新数据。 * onWrite：数据插入或更新事件、数据删除事件、数据表清空事件。|

## 请求示例

```screen
{
"records": [
         {
                  "before": {
                            "gender": "Male",
                            "name": "Jack"       
                  },
                  "after": {
                            "gender": "Male",
                            "name": "Sam"
                  }
         }
],
    "objectTypeName":"EntityOne",
    "naturalStoreName":"AdminSdkZoneName",
    "eventType":"onUpsert",
}
```
