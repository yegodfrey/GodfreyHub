# AGConnectCloudDB

```
@interface AGConnectCloudDB : NSObject
```

Cloud DB入口类，采用单AGConnectCloudDB实例模式。初始化AGConnectCloudDB后，您需要先获取实例，然后基于该实例，可实现新建、打开、关闭或者删除CloudDBZone等功能。  

#### +initEnvironment:

调用此方法初始化AGConnectCloudDB。在获取AGConnectCloudDB实例前，必须先调用此方法初始化AGConnectCloudDB。

OBJECTIVE-C

```
+(void)initEnvironment:(NSError *_Nullable*_Nullable)error;
```

<br />

Parameters  

|Parameter name|Parameter desc|
|:-------------|:------------------------|
|error|NSError类型，用于返回初始化失败的错误信息。|

#### +shareInstance

调用此方法获取一个AGConnectCloudDB实例。获取实例后，才能使用云数据库服务进行应用开发和数据管理，如新建、打开、关闭和删除CloudDBZone等。一个应用只有一个AGConnectCloudDB实例。

OBJECTIVE-C

```
+(instancetype)shareInstance;
```

<br />

Return  

|type|desc|
|:---------------|:------------------|
|AGConnectCloudDB|AGConnectCloudDB实例。|

#### -createObjectType:error:

调用此方法在端侧创建或修改对象类型，定义存储CloudDBZoneObject的集合，存储应用产生的数据信息。

您从AppGallery Connect控制台导出的对象类型定义文件中包含全部对象类型定义文件和AGCCloudDBObjectTypeInfoHelper文件。您可以添加导出文件至应用对应目录下，通过设置createObjectType方法即可获取到对象类型信息，实现对象类型的定义和创建。

对象类型版本升级时，从AppGallery Connect控制台下载的对象类型版本需要高于当前已存在的对象类型版本。如果该方法的入参与已有并持久化的对象类型不一致时，系统将会自动升级该对象类型。

OBJECTIVE-C

```
-(void)createObjectType:(nonnull AGCCloudDBObjectTypeInfo *)objTypeInfo error:(NSError *_Nullable*_Nullable)error;
```

<br />

Parameters  

|Parameter name|Parameter desc|
|:-------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
|objectTypeInfo|不需要手动构建该参数，只需要从AppGallery Connect控制台下载Objective-C格式的对象类型定义文件，并添加至应用对应目录下，然后将参数值设置为" AGCCloudDBObjectTypeInfoHelper obtainObjectTypeInfo\] "，即可获取到对象类型信息。|
|error|NSError类型，用于返回创建或修改失败的错误信息。|

#### -openCloudDBZone:allowCreate:error:（已废弃）

调用此方法在端侧创建或者打开一个CloudDBZone对象，一个CloudDBZone对象表示一个唯一的数据存储区域。一个应用在端侧最多支持创建4个CloudDBZone。

您可以多次打开某个CloudDBZone，但每次使用完CloudDBZone后，都需要关闭该CloudDBZone，即每个打开操作需要一个对应的关闭操作，否则，会在删除CloudDBZone时，返回错误信息。

当使用AGCCloudDBZoneConfig对象打开一个已有的CloudDBZone时，需要保证AGCCloudDBZoneConfig中指定的属性与已有CloudDBZone的属性一致，如果不一致，会返回错误信息。

OBJECTIVE-C

```
- (nullable AGCCloudDBZone *)openCloudDBZone:(nonnull AGCCloudDBZoneConfig *)config allowCreate:(BOOL)allowCreate error:(NSError *_Nullable *_Nullable)error;
```

<br />

Parameters  

|Parameter name|Parameter desc|
|:-------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|config|[AGCCloudDBZoneConfig](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbzoneconfig-ios-0000001080699048)对象，用于创建或者打开CloudDBZone。|
|allowToCreate|是否允许创建CloudDBZone对象。 BOOL类型，取值包含： * YES：当AGCCloudDBZoneConfig对象中CloudDBZone存在时，打开已存在的CloudDBZone。当AGCCloudDBZoneConfig对象中CloudDBZone不存在时，创建新的CloudDBZone对象。 * NO：打开已存在的CloudDBZone。如果CloudDBZone不存在，将会返回错误信息。|
|error|NSError类型，创建或打开一个CloudDBZone对象失败时，会返回错误信息。|

Return  

|type|desc|
|:-------------|:----------------------------------------|
|AGCCloudDBZone|CloudDBZone对象，您可通过该对象实现数据增、删、改、查和数据侦听等功能。|

#### -openCloudDBZone2:allowCreate:callback:

调用此方法在端侧异步创建或者打开一个CloudDBZone对象，一个CloudDBZone对象表示一个唯一的数据存储区域。一个应用在端侧最多支持创建4个CloudDBZone。

您可以多次打开某个CloudDBZone，但每次使用完CloudDBZone后，都需要关闭该CloudDBZone，即每个打开操作需要一个对应的关闭操作，否则，会在删除CloudDBZone时，返回错误信息。

当使用AGCCloudDBZoneConfig对象打开一个已有的CloudDBZone时，需要保证AGCCloudDBZoneConfig中指定的属性与已有CloudDBZone的属性一致，如果不一致，会返回错误信息。

OBJECTIVE-C

```
- (void)openCloudDBZone2:(nonnull AGCCloudDBZoneConfig *)config allowCreate:(BOOL)allowCreate callback:(nullable void (^)(AGCCloudDBZone *_Nullable zone, NSError *_Nullable error))callback;
```

<br />

Parameters  

|Parameter name|Parameter desc|
|:-------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|config|[AGCCloudDBZoneConfig](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbzoneconfig-ios-0000001080699048)对象，用于创建或者打开CloudDBZone。|
|allowToCreate|是否允许创建CloudDBZone对象。 BOOL类型，取值包含： * YES：当AGCCloudDBZoneConfig对象中CloudDBZone存在时，打开已存在的CloudDBZone。当AGCCloudDBZoneConfig对象中CloudDBZone不存在时，创建新的CloudDBZone对象。 * NO：打开已存在的CloudDBZone。如果CloudDBZone不存在，将会返回错误信息。|
|callback|回调对象，对象中包含了openCloudDBZone2执行的结果和错误信息。执行成功，返回CloudDBZone；执行失败，返回错误信息。|

#### -closeCloudDBZone:error:

调用此方法关闭端侧打开的CloudDBZone对象。

使用本方法关闭某个CloudDBZone前，需要确保当前基于该CloudDBZone的数据的写入、删除、查询和快照侦听操作已完成，否则会无法关闭。

您在使用一个CloudDBZone进行数据增、删、改、查操作之后，可以根据需要选择是否暂时关闭该CloudDBZone，从而释放该CloudDBZone占有的资源。关闭CloudDBZone不删除底层的数据文件。关闭某个不存在的CloudDBZone，或者重复关闭时，系统均返回成功，不会返回错误信息。

OBJECTIVE-C

```
- (void)closeCloudDBZone:(nonnull AGCCloudDBZone *)zone error:(NSError *_Nullable *_Nullable)error;
```

<br />

Parameters  

|Parameter name|Parameter desc|
|:-------------|:-----------------------------|
|zone|需要关闭的CloudDBZone对象。|
|error|NSError类型，关闭失败或存在异常的时候，返回错误信息。|

#### -deleteCloudDBZone:error:

调用此方法删除端侧不再使用的CloudDBZone对象。仅在关闭CloudDBZone之后，才能执行删除CloudDBZone的操作。

当您无需继续使用某个CloudDBZone和其内的数据时，可以调用本方法彻底删除该CloudDBZone。您删除该CloudDBZone后，在释放内存资源的同时，还会同时删除其在磁盘上存储的数据文件。重复删除或者删除不存在的CloudDBZone，均返回成功，不会返回错误信息。

OBJECTIVE-C

```
- (void)deleteCloudDBZone:(nonnull NSString *)zoneName error:(NSError *_Nullable *_Nullable)error;
```

<br />

Parameters  

|Parameter name|Parameter desc|
|:-------------|:-----------------------------------------|
|zoneName|CloudDBZone的名称。|
|error|NSError类型，删除不再使用的CloudDBZone对象失败时，会返回错误信息。|

#### -enableNetwork:

调用此方法打开端云之间的数据同步开关，开关打开后，端侧和云侧之间才能进行数据同步。

AGConnectCloudDB初始化后，所有CloudDBZone的端云数据同步开关默认为打开状态，不需要应用显式调用。通常，在检测到网络状态良好且为WIFI网络时调用本方法。也可在用户授权使用移动数据网络时调用，具体需要以用户的网络授权为准。当端侧打开数据同步开关后，端侧会检查当前是否有未同步的数据，如果有未同步的数据则会触发端云数据同步操作。

OBJECTIVE-C

```
- (BOOL)enableNetwork:(nonnull NSString *)zoneName;
```

<br />

Parameters  

|Parameter name|Parameter desc|
|:-------------|:--------------|
|zoneName|CloudDBZone的名称。|

#### -disableNetwork:

调用此方法在端侧关闭端云之间的数据同步开关，关闭开关后，端侧和云侧之间不再进行数据同步。

数据同步开关仅控制单个CloudDBZone是否进行数据同步，仅在所有的CloudDBZone同步开关都关闭后，AGConnectCloudDB才会断开与云侧的连接，不再进行数据同步。同步开关的关闭状态不会持久化，当应用关闭，再次打开后，同步开关会默认为打开状态。通常，应用检测到用户使用移动数据网络（如4G网络）时调用，避免同步数据时使用用户的移动数据流量。是否关闭开关，具体需要以用户的网络授权为准。

OBJECTIVE-C

```
- (BOOL)disableNetwork:(nonnull NSString *)zoneName;
```

<br />

Parameters  

|Parameter name|Parameter desc|
|:-------------|:--------------|
|zoneName|CloudDBZone的名称。|

#### -setUserKey:userRekey:callback:（已废弃）

调用此方法设置或者修改Cloud DB数据全程加密的用户密码，默认进行用户密码弱校验。对于缓存模式，我们建议您在端侧开启本地数据库加密，保障本地数据安全。如果您在AppGallery Connect控制台上创建的对象类型包含加密字段，但是您未使用setUserKey方法设置用户密码，则该对象类型的数据将无法同步至云侧，且无法对云侧该对象类型的数据进行操作。

根据请求参数值的不同，分为如下三种情况：

* 当参数"userKey"的值不为nil或者空字符串，且参数"userReKey"的值为nil或者空字符串时，设置Cloud DB全程加密的用户密码。
* 当参数"userKey"的值不为nil或者空字符串，且参数"userReKey"的值不为nil或者空字符串时，将该Cloud DB的原全程加密密码修改为新设置全程加密密码。
* 当参数"userKey"的值为nil或者空字符串，为非法入参，系统会发生异常错误。

OBJECTIVE-C

```
- (void)setUserKey:(nonnull NSString *)userKey userRekey:(nullable NSString *)userRekey callback:(nullable void (^)(NSError *_Nullable error))callback;
```

|callback|回调对象。如果执行setUserKey失败，则通过该对象返回错误信息。|

#### -setUserKey:UserRekey:needStrongCheck:callback:

调用此方法设置或者修改Cloud DB数据全程加密的用户密码，并指定用户密码是否进行强校验。对于缓存模式，我们建议您在端侧开启本地数据库加密，保障本地数据安全。如果您在AppGallery Connect控制台上创建的对象类型包含加密字段，但是您未使用setUserKey方法设置用户密码，则该对象类型的数据将无法同步至云侧，且无法对云侧该对象类型的数据进行操作。

* 当参数"userKey"的值不为nil或者空字符串，且参数"userReKey"的值不为nil或者空字符串时，将该Cloud DB的原全程加密密码修改为新设置全程加密密码。

#### -updateDataEncryptionKey:

数据密钥用于加密用户数据，该密钥由系统自动生成。为避免长期使用同一密钥发生密钥被破解的风险，您可以调用该方法更新数据密钥。

OBJECTIVE-C

```
- (void)updateDataEncryptionKey:(nullable void (^)(NSError *_Nullable error))updateCallback;
```

<br />

Parameters  

|Parameter name|Parameter desc|
|:-------------|:----------------------------------|
|updateCallback|回调对象。如果执行setUserKey失败，则通过该对象返回错误信息。|

#### -addDataEncryptionKeyCallback:

调用此方法注册数据密钥变更的侦听。

注册侦听后，如果同一个用户拥有多台不同设备，其中一个在线设备更新数据密钥后，云侧会通知到该用户其它的在线设备，数据密钥已变更。

OBJECTIVE-C

```
- (void)addDataEncryptionKeyCallback:(nonnull AGCCloudDBOnDataEncryptionKeyChangeCallback)callback;
```

<br />

Parameters  

|Parameter name|Parameter desc|
|:-------------|:-------------------------------------------------------------------------------------------------|
|callback|回调对象，对象中包含了addDataEncryptionKeyCallback执行的结果。您需要根据callback返回值决定是否更新数据密钥，返回YES，更新数据密钥，返回NO，不更新数据密钥。|

#### -addEventCallback:

调用此方法注册用户密码变更事件的侦听。

注册侦听后，如果同一个用户拥有多台不同设备时，用户在其中一个在线设备更新用户密码后，云侧会通知到该用户其它的在线设备，其密码已变更。

OBJECTIVE-C

```
- (void)addEventCallback:(nonnull AGCCloudDBEventCallback)eventCallback;
```

<br />

Parameters  

|Parameter name|Parameter desc|
|:-------------|:------------------------------------------|
|eventCallback|回调对象，对象中包含了addEventCallback执行的结果，如用户密码变更事件。|
