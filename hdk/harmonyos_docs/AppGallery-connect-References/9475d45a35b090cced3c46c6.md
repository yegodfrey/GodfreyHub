# CloudDBZoneObjectOperator

基于指定主键值的对象实例、指定对象类型的Class或对象类型的名称，提供了[build](#section296564433319)()、[increment()](#section7617134411476)和[update()](#section289310261498)方法，实现构造操作对象的实例、更新指定字段的值的能力。仅作为[update()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section1881840185010)、[batchUpdate()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section20931138154917)或者[batchUpdateByCondition()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section037353591218)方法的参数传入，云数据库会基于指定的条件约束执行更新。  

#### Summary

|Qualifier and Type|Method name|
|:------------------------|:-------------------------------------------------------------------------------------------------------|
|CloudDBZoneObjectOperator|[build](#section296564433319)(object: any) 获取一个CloudDBZoneObjectOperator实例，并指定对象实例、对象类型的Class对象或对象类型的名称。|
|CloudDBZoneObjectOperator|[increment](#section7617134411476)(fieldName: string, delta: any) 对指定字段的值进行增量操作。|
|CloudDBZoneObjectOperator|[update](#section289310261498)(fieldName: string, value: any) 对某个字段的值进行更新操作。|

#### Methods

#### build

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|build(object: any): CloudDBZoneObjectOperator 获取一个CloudDBZoneObjectOperator实例，并指定对象实例、对象类型的Class对象或对象类型的名称。 CloudDBZoneObjectOperator不提供任何构造方法，只能通过此方法来获取一个CloudDBZoneObjectOperator实例。 入参为对象实例时，必须指定主键值，否则会返回异常。|

Parameters  

|Parameter name|Parameter desc|
|:-------------|:------------------------------------------------------------------------------------------------------------------------|
|object: any|指定对象类型。 取值包含： * 一个对象实例，用于根据对象更新。 * 一个Class用于根据条件更新的对象类型实体类。 * 一个字符串类型的对象类型名，用于构建基于泛化对象更新数据所需的CloudDBZoneObjectOperator对象。|

Return  

|type|desc|
|:------------------------|:-----------------------------|
|CloudDBZoneObjectOperator|CloudDBZoneObjectOperator对象实例。|

#### increment

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|increment(fieldName: string, delta: any): CloudDBZoneObjectOperator 调用此方法对指定字段的值进行增量操作。 调用本方法需要遵循以下约束： * 同一个[update()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section1881840185010)、[batchUpdate()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section20931138154917)或者[batchUpdateByCondition()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section037353591218)操作中，increment()和[update()](#section289310261498)方法不能操作同一个字段，否则会抛出错误。 * 不支持对主键字段、加密字段和敏感字段的值进行更新操作。 * 使用[update()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section1881840185010)进行增量操作时，fieldName对应数据类型支持Byte、Short、Integer、Long、Float和Double；fieldName为Long类型时，支持number和String类型的delta，其他数据类型只支持number类型delta。 * 使用[batchUpdate()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section20931138154917)或者[batchUpdateByCondition()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section037353591218)进行增量操作时，fieldName对应数据类型支持Short、Integer、Long、Float和Double；fieldName为Long类型时，支持number和String类型的delta，其他数据类型只支持number类型delta。|

Parameters  

|Parameter name|Parameter desc|
|:----------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|fieldName: string|增量更新的字段名称。 须知： 若未设置该字段的值，默认原始值为0，更新结果为增量值。|
|delta: any|增量更新的数值。 * 在原有值上加："正数"或者"+正数"。 * 在原有值上减："-正数"。 说明： * 若delta值传入1，则表示字段自增1；delta值传入-1，则表示字段自减1。 * 增量更新的值必须在字段类型对应的数值范围内。如：Byte类型，增量值的范围只能在-128 \~ +127之间。详细请参考[数据类型](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-aboutclouddb-0000001080975612#section13455181316114)。 * 由于number类型的精度限制，在对Long类型进行更新操作时，建议使用string类型作为参数传入。|

Return  

|type|desc|
|:------------------------|:----------------------------|
|CloudDBZoneObjectOperator|CloudDBZoneObjectOperator对象实例|

#### update

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|update(fieldName: string, value: any): CloudDBZoneObjectOperator 调用此方法对某个字段的值进行更新操作。 调用本方法需要遵循以下约束： * 同一个[update()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section1881840185010)、[batchUpdate()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section20931138154917)或者[batchUpdateByCondition()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section037353591218)操作中，[increment()](#section7617134411476)和update()方法中需至少指定一个字段，且不能操作同一个字段，否则会抛出错误。 * 不支持对主键字段、加密字段和敏感字段的值进行更新操作。|

Parameters  

|Parameter name|Parameter desc|
|:----------------|:-------------|
|fieldName: string|更新的字段名称。|
|value: any|更新字段的值。|

Return  

|type|desc|
|:------------------------|:----------------------------|
|CloudDBZoneObjectOperator|CloudDBZoneObjectOperator对象实例|
