# Trace

自定义跟踪记录，用于监控Web应用在自定义场景下的性能。  

#### Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:---------------------------------------------------------------------------------------------------------------------------|
|void|[start](#section14501903313)() 启动自定义跟踪记录。[start](#section14501903313)和[stop](#section5779184717361)方法必须成对出现。|
|void|[stop](#section5779184717361)() 停止自定义跟踪记录。[start](#section14501903313)和[stop](#section5779184717361)方法必须成对出现。|
|void|[setAttribute](#section987912113712)(attr: string, value: string) 设置自定义跟踪记录属性名称和属性值。如果属性已经存在，则更新属性的值。每个Trace实例最多只能设置5个自定义属性。|
|string|[getAttribute](#section1162713561403)(attr: string) 获取自定义跟踪记录指定的自定义属性值。|
|Array|[getAttributes](#section1275180104218)() 获取自定义跟踪记录的所有自定义属性。|
|void|[setMetric](#section2089194410466)(metric: string, value: number) 添加自定义跟踪记录指标。如果指标已经存在，则更新指标的值。|
|number|[getMetric](#section1991104414620)(metric: string) 获取自定义跟踪记录指定的自定义指标值。|
|Array|[getMetrics](#section792344164612)() 获取自定义跟踪记录的所有自定义指标。|

#### Methods

#### start

|Method|
|:------------------------------------------------------------------------------------------|
|start(): void 启动自定义跟踪记录。[start](#section14501903313)和[stop](#section5779184717361)方法必须成对出现。|

Sample Code

```
trace.start()
```

#### stop

|Method|
|:-----------------------------------------------------------------------------------------|
|stop(): void 停止自定义跟踪记录。[start](#section14501903313)和[stop](#section5779184717361)方法必须成对出现。|

Sample Code

```
trace.stop()
```

#### setAttribute

|Method|
|:---------------------------------------------------------------------------------------------------------|
|setAttribute(attr: string, value: string): void 设置自定义跟踪记录属性名称和属性值。如果属性已经存在，则更新属性的值。每个Trace实例最多只能设置5个自定义属性。|

Parameters  

|Name|Description|
|:----|:--------------------------------------------|
|attr|自定义属性名称，只能由中文、字母（不区分大小写）、数字和下划线组成，且长度不超过40字符。|
|value|自定义属性值，只能由中文、字母（不区分大小写）、数字和下划线组成，且长度不超过100字符。|

Sample Code

```
trace.setAttribute('file_name', 'upload.js')
```

#### getAttribute

|Method|
|:-----------------------------------------------------|
|getAttribute(attr: string): string 获取自定义跟踪记录指定的自定义属性值。|

Parameters  

|Name|Description|
|:---|:----------|
|attr|自定义属性名称。|

Return  

|Type|Description|
|:-----|:----------|
|string|自定义属性值。|

Sample Code

```
trace.getAttribute('file_name') // 'upload.js'
```

#### getAttributes

|Method|
|:----------------------------------------|
|getAttributes(): Array 获取自定义跟踪记录的所有自定义属性。|

Return  

|Type|Description|
|:----|:------------|
|Array|存放所有自定义属性的数组。|

Sample Code

```
trace.getAttributes() // [{ 'file_name': 'upload.js' }, { 'file_ext': 'js' }]
```

#### setMetric

|Method|
|:---------------------------------------------------------------------------|
|setMetric(metric: string, value: number): void 添加自定义跟踪记录指标。如果指标已经存在，则更新指标的值。|

Parameters  

|Name|Description|
|:-----|:------------------------------------------------|
|metric|自定义跟踪记录指标名称，只能由中文、字母（不区分大小写）、数字和下划线组成，且长度不超过40字符。|
|value|自定义跟踪记录指标值，只能为数字，且长度不超过100。|

Sample Code

```
trace.setMetric('file_size', 5000) 
```

#### getMetric

|Method|
|:----------------------------------------------------|
|getMetric(metric: string): number 获取自定义跟踪记录指定的自定义指标值。|

Parameters  

|Name|Description|
|:-----|:-----------|
|metric|自定义跟踪记录指标名称。|

Return  

|Type|Description|
|:-----|:----------|
|number|自定义跟踪记录指标值。|

Sample Code

```
trace.getMetric('file_size') // 5000
```

#### getMetrics

|Method|
|:-------------------------------------|
|getMetrics(): Array 获取自定义跟踪记录的所有自定义指标。|

Return  

|Type|Description|
|:----|:------------|
|Array|存放所有自定义指标的数组。|

Sample Code

```
trace.getMetrics() // [{ 'file_size': 5000 }, { 'type': 1 }]
```
