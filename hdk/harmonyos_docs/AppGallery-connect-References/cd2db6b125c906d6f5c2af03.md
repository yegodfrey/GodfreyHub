# 提交发布

#### 功能介绍

此接口用于提交应用审核，调用本接口前必须保证应用信息已补充完整，应用软件包已经上传。接口调用者的角色：账号持有者、管理员、APP管理员。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250825134803.89509726675740152752031979120268:50001231000000:2800:1623DA023AE4F775386A3A27952DB081BF4EB73DA5C957F37BE2C19E420ACAA8.png)  
软件包采用异步解析方式，请您在传包后等候2分钟再调用提交发布接口。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者服务器 -\> 华为服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/publish/v2/app-submit|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|
|-----|-------------------------------------------------------------------|

API客户端方式和OAuth客户端方式的区别请参见[使用入门](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114)。

API客户端方式：  

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|M|String|客户端ID，获取方法参考[创建API客户端](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section103mcpsimp)。|
|Authorization|M|String|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)中获取的access_token。|

OAuth客户端方式：  

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
|teamId|M|String|开发者所在团队的团队ID，可通过[获取团队列表](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-getteamlist-0000001158245075)接口获取。|
|oauth2Token|M|String|认证信息，传入[获取用户授权码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section949717114392)中获取的Access Token。|

#### Query

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:------|:--------------------------------------------------------------------------------------------------|
|appId|M|String|应用ID。|
|releaseTime|O|String|指定发布的UTC时间格式：yyyy-MM-ddTHH:mm:ssZZ，例如"2015-01-01T01:01:01+0800"。 说明： 如果releaseTime未填写，应用审核通过后会立即上架。|
|remark|O|String|提审发布的备注信息，可以为空。如果填写，长度范围在10-300。|
|releaseType|O|Integer|应用发布方式。 取值范围： * 1：全网 * 3：分阶段 说明： 应用发布方式为分阶段发布时，要求该应用存在一个已上架的版本。 默认值：1|

#### Body

当releaseType为3时，请求Body中phasedReleaseStartTime，phasedReleaseEndTime，phasedReleaseDescription必填，其他情况不用填写。

Body中使用JSON格式携带发布信息，参数如下表所示。  

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------------------------|:----------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|state|O|String|此参数无需设置。|
|phasedReleaseStartTime|M|String(64)|分阶段发布生效开始时间，UTC时间格式：yyyy-MM-ddTHH:mm:ssZZ，例如"2015-01-01T01:01:01+0800"。|
|phasedReleaseEndTime|M|String(64)|分阶段发布生效结束时间，UTC时间格式：yyyy-MM-ddTHH:mm:ssZZ，例如"2015-01-01T01:01:01+0800"。|
|phasedReleasePercent|M|String(10)|分阶段发布百分比。 * Android应用取值范围为0.00到100.00，必须精确到两位小数，不含百分号。 * HarmonyOS应用取值为0.00到100.00，可以不带小数或只带一位小数，不含百分号。|
|phasedReleaseDescription|M|String(500)|分阶段发布说明。|
|isPureDetection|O|Integer|是否申请绿色应用认证。 取值范围： * 0：否 * 1：是|
|sensitivePermissionIconUrl|O|String|绿色认证审核材料的objectId，isPureDetection=1时为必填项。该值为将绿色认证审核材料打成zip包，然后先调用[获取上传文件地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-upload-url-new-0000001111685200)接口，然后调用[上传文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-upload-file-new-0000001111845090)接口上传审核材料，最后得到[获取上传文件地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-upload-url-new-0000001111685200)接口返回的objectId。|
|isCommitSensitivePermissionTips|O|boolean|确认是否符合相关要求，true表示符合。isPureDetection=1时为必填项，且只可以填true。要求包括： * 非必要的使用场景禁止桌面、锁屏和其他应用弹出窗口骚扰用户行为。 * 非必要的使用场景禁止发送无法删除的常驻通知。 * 禁止影响用户体验的广告，如抬头、强制插屏、侧边等。 * 禁止引导用户开启开发者选项。 * 禁止引导用户开启USB调试模式。 * 禁止通过热补丁，引入恶意行为和不符合以上条款的行为。|

#### 调用示例

```
public static void  submit(String domain,String clientId, String token, String appId){
	HttpPost put = new HttpPost(domain + "/publish/v2/app-submit?appid=" + appId);

	put.setHeader("Authorization", "Bearer " + token);
	put.setHeader("client_id", clientId);

	try {
		CloseableHttpClient httpClient = HttpClients.createDefault();
		CloseableHttpResponse httpResponse = httpClient.execute(put);
		int statusCode = httpResponse.getStatusLine().getStatusCode();
		if (statusCode == HttpStatus.SC_OK) {
			BufferedReader br =
				new BufferedReader(new InputStreamReader(httpResponse.getEntity().getContent(), Consts.UTF_8));
			String result = br.readLine();

			JSONObject object = JSON.parseObject(result);
			System.out.println(object.get("ret"));
		}
	} catch (Exception e) {

	}
}
```
