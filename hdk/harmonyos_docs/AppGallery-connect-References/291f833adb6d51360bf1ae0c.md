# ohAegGenEccKeyPair

ohAegGenEccKeyPair(): Promise\<EccKeyPair\>

生成Uint8Array格式的ECC256公私钥对，可用于ECDSA签名和ECDH密钥协商。

参数：

无

返回值：  

|参数|类型|说明|
|:-----------|:---------|:-----------------------------------------------------------------------|
|EccKeyPair对象|EccKeyPair|EccKeyPair.publicKey 公钥，Uint8Array, EccKeyPair.privateKey 私钥, Uint8Array|

导入模块：

```
import { AegEcc } from '@hw-agconnect/petal-aegis';
```

示例：

```
import { AegEcc } from '@hw-agconnect/petal-aegis';

function genearateEccKey2() {
  AegEcc.ohAegGenEccKeyPair().then((data) => {
    console.log("genearateEccKey2", 'publicKey: ' + data.publicKey);
    console.log("genearateEccKey2", 'privateKey: ' + data.privateKey);
  }).catch((err) => {
    console.log("genearateEccKey2 error : ", err);
  })
}
```
