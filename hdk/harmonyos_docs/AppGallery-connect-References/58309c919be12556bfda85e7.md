# AGCAPM

|Class Info|
|:-----------------------------------------------------------------------------------------|
|AGCAPM APM SDK服务入口类，用于动态启用/停用APM性能监控数据采集。 Declaration ``` @interface AGCAPM : NSObject ```|

#### + getInstance

初始化APMS实例。在调用AGCAPM类的接口前，您需要先使用此方法初始化实例。

Declaration

```
+ (instancetype)getInstance
```

Return  

|Type|Description|
|:-----------|:----------|
|instancetype|AGCAPM实例对象。|

#### - enableCollection:

设置APM服务开关。开关的默认值为打开(true)，表示启用APM 应用性能数据采集。如果需要停用APM应用性能数据采集，可将开关值设为关闭(false)。

Declaration

```
- (void)enableCollection:(BOOL)enable
```

Parameters  

|Name|Description|
|:-----|:---------------------------------------------------------|
|enable|APM服务开关。 * true：打开，APM会采集性能监控数据。 * false：关闭，APM不会采集性能监控数据。|
