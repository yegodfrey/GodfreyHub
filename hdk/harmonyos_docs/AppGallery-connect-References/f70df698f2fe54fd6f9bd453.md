# Action

|Class Info|
|:--------------------------|
|public class Action 跳转动作信息。|

## Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:----------------------------------------------|
|String|getMessageTitle() 获取当前消息的消息标题，Picture消息无标题时返回空。|
|String|getActionUrl() 获取点击消息时操作按钮对应的内容。|
|ActionType|getActionType() 获取跳转类型。|

## Methods

### getMessageTitle

|Method|
|:-------------------------------------------|
|public String getMessageTitle() 获取当前消息的消息标题。|

**Return**

|Type|Description|
|:-----|:----------------------------|
|String|获取当前消息的消息标题，Picture消息无标题时返回空。|

### getActionUrl

|Method|
|:---------------------------------------------|
|public String getActionUrl() 获取点击消息时操作按钮对应的内容。|

**Return**

|Type|Description|
|:-----|:--------------------------------------------|
|String|获取点击消息时操作按钮对应的内容。 跳转链接：对应的跳转链接地址。 分享：对应的分享信息。|

|:---------|:------------------|
