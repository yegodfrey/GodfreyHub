# ProductImportErrorInfo

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:------|:-------------------------------------|
|productNo|O|String|批量操作失败的商品标识，开发者自定义商品标识，和appId唯一确定一个商品。|
|errorCode|O|Integer|错误码信息。|
|errorReason|O|String|此条商品操作失败原因。|
