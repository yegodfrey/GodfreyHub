# AGCRemoteConfigSource

远程配置获取的value值的来源。

## AGCRemoteConfigSourceInitial

获取的value值是类型初始值。

**OBJECTIVE-C**

```screen
AGCRemoteConfigSourceInitial
```

**SWIFT**

```screen
case initial = 0
```

## AGCRemoteConfigSourceLocal

获取的value值是本地默认值。

**OBJECTIVE-C**

```screen
AGCRemoteConfigSourceLocal
```

**SWIFT**

```screen
case local = 1
```

## AGCRemoteConfigSourceRemote

获取的value值是云端默认值。

**OBJECTIVE-C**

```screen
AGCRemoteConfigSourceRemote
```

**SWIFT**

```screen
case remote = 2
```
