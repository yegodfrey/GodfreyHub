# ohAegUint8ArraytoHexString

ohAegUint8ArraytoHexString(input: Uint8Array):string

Uint8Array格式转换为16进制的hex string字符串

**导入模块** **：**

```typescript
import { AegStrUtil } from '@hw-agconnect/petal-aegis';
```

**参数：**

|参数名|类型|必填|说明|
|:----|:---------|:-|:-------------------|
|input|Uint8Array|是|待转换的Uint8Array格式的内容。|

**返回值：**

|参数|类型|说明|
|:--|:--------|:--------------------|
|字符串|hexString|转换后的16进制hexString字符串。|

**示例：**

```typescript
import { AegStrUtil } from '@hw-agconnect/petal-aegis';

function Uint8ArraytoHexString() {
  let strUtil: AegStrUtil = new AegStrUtil()
  let input = new Uint8Array([104, 101, 108, 108, 111, 32, 119, 111, 114, 108, 100])
  let result = strUtil.ohAegUint8ArraytoHexString(input)
  //Uint8ArraytoHexString  result: 68656c6c6f20776f726c64
  console.log("Uint8ArraytoHexString ", 'result: ' + result);
}
```
