# ohAegAesGcmDecText

ohAegAesGcmDecText(text: string \| Uint8Array, key: string \| Uint8Array): Promise\<string\>

AES-GCM解密算法，配套[ohAegAesGcmEncText](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ohaegaesgcmenctext-0000001909994589)接口使用，分组模式、填充模式如下：  

|分组模式|密钥长度（bit）|填充模式|API版本|
|:---|:------------|:--------|:----|
|GCM|128\|192\|256|NoPadding|11+|

导入模块：

```
import { AegAesGcm } from '@hw-agconnect/petal-aegis';
```

参数：  

|参数名|类型|必填|说明|
|:---|:----------------|:-|:---------------------------------------------------------|
|text|string或Uint8Array|是|待解密内容（ohAegAesGcmEncText加密后的结果），格式为iv:密文或者同类的Uint8Array格式。|
|key|string或Uint8Array|是|明文工作密钥（string类型的key需要使用16进制编码格式）。|

返回值：  

|参数|类型|说明|
|:----------|:-----|:---------|
|decryptText|String|解密后的明文字符串。|

示例：

```
import { AegAesGcm } from '@hw-agconnect/petal-aegis';
import { buffer } from '@kit.ArkTS';

async function aesgcm() {
  let plainText = 'hello world'; //待加密内容
  let key = '1234567891234567'; //长度16字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let iv = '987654321321'; //长度12字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let keyUint8 = new Uint8Array(buffer.from(key, 'utf-8').buffer);
  let ivUint8 = new Uint8Array(buffer.from(iv, 'utf-8').buffer);

  try {
    let encryptText = await AegAesGcm.ohAegAesGcmEncText(plainText, keyUint8, ivUint8);
    //aesgcm  encryptText: 57,56,55,54,53,52,51,50,49,51,50,49,58,21,104,60,153,97,230,40,122,247,216,95,118,199,32,201,144,189,45,186,42,16,112,92,208,160,189,206
    console.log("aesgcm ", 'encryptText: ' + encryptText);

    let decryptText = await AegAesGcm.ohAegAesGcmDecText(encryptText, keyUint8);

    if (plainText === decryptText) {
      console.info('decrypt ok');
    }
    console.log("aesgcm ", 'decryptText: ' + decryptText);
  } catch (err) {
    console.log("aesgcm ", 'err: ' + err);
  }
}
```
