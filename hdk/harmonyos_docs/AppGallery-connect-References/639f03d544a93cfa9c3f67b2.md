# ConfigContainer

AGC Remote Config集合入口类，主要使用在AGConnectConfig的[loadLastFetched](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/web-remoteconfig-agconnectconfig-0000001057269353#section747015487214)中，可作为参数传入[apply](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/web-remoteconfig-agconnectconfig-0000001057269353#section486198212)，[loadLastFetched](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/web-remoteconfig-agconnectconfig-0000001057269353#section747015487214)输出的ConfigContainer类型对象，保存了最近一次从云端拉取成功的配置信息，ConfigContainer类型对象提供了如下方法，以方便使用者查看云端配置信息。

|Qualifier and Type|Method Name and Description|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------|
|boolean|[getValueAsBoolean](#section15774104885410)(key:string) 返回key对应的boolean类型值。|
|number|[getValueAsNumber](#section4625137553)(key:string) 返回key对应的number类型值。|
|string|[getValueAsString](#section810216222556)(key:string) 返回key对应的string类型的值。|
|[ConfigValueSource](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/web-remoteconfig-overview-0000001057829368#ZH-CN_TOPIC_0000001057829368__p7529626183019)|[getSource](#section1941429195515)() 返回来源。|
|ConfigValue|[getValue](#section2255173645515)(key: string) 返回key对应的值。|

|Map<string, string | number | boolean>|[getInputConfigMap](#section101741855125512)() 获取传入的配置信息。|
