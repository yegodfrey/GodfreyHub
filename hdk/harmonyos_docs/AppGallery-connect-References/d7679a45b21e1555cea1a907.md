# ohAegAesCbcDecTextHex

ohAegAesCbcDecTextHex(text: string \| Uint8Array, key: string \| Uint8Array): Promise\<string\>

AES-CBC解密算法，配套[ohAegAesCbcEncTextHex](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ohaegaescbcenctexthex-0000001909972801)接口使用，分组模式、填充模式如下：  

|分组模式|密钥长度（bit）|填充模式|API版本|
|:---|:------------|:----|:----|
|CBC|128\|192\|256|PKCS7|11+|

导入模块：

```
import { AegAesCbc } from '@hw-agconnect/petal-aegis';
```

参数：  

|参数名|类型|必填|说明|
|:---|:----------------|:-|:-----------------------------------|
|text|string或Uint8Array|是|待解密内容（使用ohAegAesCbcEncTextHex加密的结果）。|
|key|string或Uint8Array|是|明文工作密钥（string类型的key需要使用16进制编码格式）。|

返回值：  

|参数|类型|说明|
|:----------|:-----|:---------|
|decryptText|String|解密后的明文字符串。|

示例：

```
import { AegAesCbc } from '@hw-agconnect/petal-aegis';
import { buffer } from '@kit.ArkTS';

async function aescbc2() {
  let plainText = 'hello world'; //待加密内容
  let key = '1234567891234567'; //长度16字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let iv = '9876543217654321'; //长度16字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let keyUint8 = new Uint8Array(buffer.from(key, 'utf-8').buffer);
  let ivUint8 = new Uint8Array(buffer.from(iv, 'utf-8').buffer);

  try {
    let encryptText = await AegAesCbc.ohAegAesCbcEncTextHex(plainText, keyUint8, ivUint8);
    //aescbc2  encryptText: 39383736353433323137363534333231:85e279283fa498087671da5e493f53da
    console.log("aescbc2 ", 'encryptText: ' + encryptText);

    let decryptText = await AegAesCbc.ohAegAesCbcDecTextHex(encryptText, keyUint8);
    if (plainText === decryptText) {
      console.info('aescbc2 decrypt ok');
    }
    console.log("aescbc2 ", 'decryptText: ' + decryptText);
  } catch (err) {
    console.log("aescbc2 ", 'err: ' + err);
  }
}
```
