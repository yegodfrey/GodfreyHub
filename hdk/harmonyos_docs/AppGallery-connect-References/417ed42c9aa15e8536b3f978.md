# 通知获取资源包状态

## 功能介绍

游戏客户端在从用户设备读取游戏资源包时，需要调用此接口通知华为应用市场客户端当前读取的状态。在读取游戏资源包前需要通知应用市场客户端已开始读取，在完成读取资源包后也需要通知应用市场客户端已读取完成。调用时华为应用市场客户端会校验调用方App的签名值，如果签名校验不通过则直接返回失败。
> 注意
>
> 请您务必在读取游戏资源包前、后通知华为应用市场客户端，否则会影响您的游戏数据统计。

## 接口原型

|承载协议|ContentProvider，即Android应用程序之间进行数据交换的标准API。|
|----|---------------------------------------------------------------------------------------------|
|接口方向|游戏客户端->华为应用市场客户端|
|请求方式|context.getContentResolver.acquireUnstableContentProviderClient(uri).call(method,arg,extras);|

## 请求参数

|参数名|必选(M)/可选(O)|类型|说明|
|:-----|:----------|:-----|:----------------------------------------------------------------------------------------|
|uri|M|Uri|ContentProvider的请求URL，要求取值为Uri.parse("content://com.huawei.appgallery.game.CONTENT_URI")。|
|method|M|String|华为应用市场定义的请求方法名，方法名为"submitResAction"。|
|arg|M|String|华为应用市场暂未使用，取值为""。|
|extras|M|Bundle|存储"action"数据，即游戏资源包读取状态，有如下两种状态： * BEGIN：开始读取。 * END：读取完成。|

## 响应参数

|参数|必选(M)/可选(O)|类型|说明|
|:---------|:----------|:------|:--------------------|
|returnCode|M|Integer|提交结果。 * 0：成功。 * 1：失败。|

## 示例代码

```screen
    /**
     * provider URI
     */
    private static final String PROVIDER_URI = "content://com.huawei.appgallery.game.CONTENT_URI";

    /**
     * provider接口返回码
     */
    private static final String PROVIDER_RETURN_CODE = "returnCode";

    /**
     * 提交读取资源预下载包状态
     * 调用时机：启动游戏后和读取资源包完成后，分别传入参数BEGIN、END
     *
     * @param action BEGIN：开始读取  END：结束读取
     */
    private void submitResAction(String action) {
        try {
            ContentProviderClient contentProviderClient =
                    this.getApplicationContext().getContentResolver().acquireUnstableContentProviderClient(Uri.parse(PROVIDER_URI));
            Bundle param = new Bundle();
            param.putString("action", action);
            Bundle result =
                    contentProviderClient.call("submitResAction", "", param);
            if (result != null && result.getInt(PROVIDER_RETURN_CODE) == 0) {
                Log.d(TAG, "submitResAction success!");
            } else {
                 Log.e(TAG, "submitResAction failed");
            }
        } catch (IllegalArgumentException e) {
            Log.e(TAG, "submitResAction IllegalArgumentException!");
        } catch (Exception e) {
            Log.e(TAG, "submitResAction exception!");
        }
    }
```
