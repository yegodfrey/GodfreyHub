# AGConnectCloudDBException

|class info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------|
|public class AGConnectCloudDBException extends AGCException Cloud DB的异常基类，继承自AGCException。AGConnectCloudDBException提供了相应的方法供您获取异常相关的信息，包含错误码和详细错误信息。|
