# GmmeException

包含游戏多媒体的异常对象和错误定义。

## Property Summary

|Name|Description|
|:------|:---------------------------------|
|message|异常信息。|
|code|异常错误码，详见[错误码](#section7001115218)。|

## 错误码

|错误码|值|描述|
|:------------------------------------|:---|:------------------|
|PARAMS_ERROR|1001|参数错误。|
|HTTP_RESPONSE_CODE_ERROR|1002|请求接口错误。|
|HTTP_RESPONSE_DATA_ERROR|1003|请求返回数据错误。|
|HTTP_REQUEST_ERROR|1004|请求失败。|
|ENGINE_INIT_FAIL|3001|游戏多媒体对象初始化失败。|
|ENGINE_PARAM_ERROR|3002|游戏多媒体对象初始化参数错误。|
|ENGINE_UNINITIALIZED|3003|游戏多媒体对象未初始化。|
|ENGINE_DESTROY_ERROR|3004|游戏多媒体对象销毁失败。|
|ENGINE_AUTH_ERROR|3005|身份验证失败。|
|ENGINE_INTERNAL_ERROR|3006|游戏多媒体对象内部错误。|
|MUTE_PLAYER_FAILED|4001|房主申请禁言指定玩家指令失败。|
|MUTE_ALL_PLAYERS_FAILED|4002|房主申请禁言其他所有玩家指令失败。|
|CHANGE_PLAYER_ROLE_FAILED|4003|修改角色失败。|
|PLAYER_NOT_IN_ROOM|4100|玩家不在房间。|
|ROOM_NOT_EXIST|5001|房间不存在。|
|ROOM_INFO_EMPTY|5002|房间信息为空。|
|JOIN_ROOM_FAILED|5003|加入房间失败。|
|INVALID_ROLE_TYPE|5004|无效的角色类型。|
|LEAVE_ROOM_FAILED|5005|离开房间失败。|
|MUTE_LOCAL_AUDIO_FAILED|5006|静默玩家自身失败。|
|MUTE_REMOTE_AUDIO_FAILED|5007|屏蔽其他玩家失败。|
|MUTE_ALL_REMOTE_AUDIO_FAILED|5008|屏蔽其他全部玩家失败。|
|MUTE_PLAYER_BY_OWNER_FAILED|5009|执行房主禁言指令失败。|
|ROOM_MODIFY_FAILED|5010|修改房间失败。|
|ROOM_SWITCH_FAILED|5011|房间切换失败。|
|TEAM_ROOM_NOT_SUPPORT_MUTE_ONE_PLAYER|5012|屏蔽失败，小队房间不支持屏蔽指定玩家。|
|CREATE_LOCAL_AUDIO_STREAM_FAILED|6001|本地音频流创建失败。|
