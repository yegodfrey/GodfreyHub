# FFVKPerFrameData

指定的预测算法所需的每帧数据。

Structure Declaration

```
typedef struct FFVKPerFrameData {
    FFStructureType        sType;
    const void*            pNext;
    FFPerFrameDataFlags    flags;
    FFVKImage              sceneColorImage;
    FFVKImageSync          sceneColorInitialSync;
    FFVKImageSync          sceneColorFinalSync;
    FFVKImage              depthStencilImage;
    FFVKImageSync          depthStencilInitialSync;
    FFVKImageSync          depthStencilFinalSync;
    FFVKImage              finalColorImage;
    FFVKImageSync          finalColorInitialSync;
    FFVKImageSync          finalColorFinalSync;
    FFMat4x4               viewProj;
    FFMat4x4               invViewProj;
} FFVKPerFrameData;
```

Members  

|Name|Mandatory/Optional|Description|
|:----------------------|:-----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|sType|Mandatory|此结构体类型必须为FF_STRUCTURE_TYPE_PER_FRAME_DATA_3。|
|pNext|Optional|指向扩展链中的下一个结构体的指针。扩展参数，可缺省，默认值为NULL。|
|flags|Mandatory|当前数据类型的位掩码，具体请参见[FFPerFrameDataFlagBits](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffperframedataflagbits-vulkan-0000001838093929)。如果传入多个，则必须使用丨分开，例如，FF_PER_FRAME_DATA_SCENE_COLOR_BIT 丨 FF_PER_FRAME_DATA_DEPTH_BIT|
|sceneColorImage|Mandatory|注册后带有场景颜色信息的图像资源，格式必须为RGBA8。|
|sceneColorInitialSync|Mandatory|场景颜色的同步初始信息，用于Vulkan的渲染同步控制。|
|sceneColorFinalSync|Mandatory|场景颜色的同步最终信息，用于Vulkan的渲染同步控制。|
|depthStencilImage|Mandatory|注册后带有场景深度或模板信息的图像资源。|
|depthStencilInitialSync|Mandatory|场景深度或模板的同步初始信息，用于Vulkan的渲染同步控制。|
|depthStencilFinalSync|Mandatory|场景深度或模板的同步最终信息，用于Vulkan的渲染同步控制。|
|finalColorImage|Optional|注册后带有最终场景颜色信息的图像资源。当前暂不支持。|
|finalColorInitialSync|Optional|最终场景颜色的同步初始信息，用于Vulkan的渲染同步控制。|
|finalColorFinalSync|Optional|最终场景颜色的同步最终信息，用于Vulkan的渲染同步控制。|
|viewProj|Mandatory|相机投影矩阵，对应于从世界空间坐标（World Space Coordinates）到剪辑空间坐标（Clip Space Coordinates）的转换。|
|invViewProj|Mandatory|相机投影矩阵的逆矩阵，对应于从剪辑空间坐标（Clip Space Coordinates）到世界空间坐标（World Space Coordinates）的转换。|
