# FFVKDepthStencilFormatInfo

深度模板格式信息。

**Structure Declaration**

```screen
typedef struct FFVKDepthStencilFormatInfo {
    FFStructureType    sType;
    const void*        pNext;
    VkFormat           format;
} FFVKDepthStencilFormatInfo;
```

**Members**

|Name|Mandatory/Optional|Description|
|:-----|:-----------------|:--------------------------------------------------------|
|sType|必填|此结构体类型必须为**FF_STRUCTURE_TYPE_DEPTH_STENCIL_FORMAT_INFO**。|
|pNext|选填|指向扩展链中的下一个结构体的指针。扩展参数，可缺省，默认值为NULL。|
|format|必填|深度模板格式。|
