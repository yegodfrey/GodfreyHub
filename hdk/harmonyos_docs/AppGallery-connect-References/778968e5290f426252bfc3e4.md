# AGCCloudDBListenerHandler

```screen
@interface AGCCloudDBListenerHandler : NSObject
```

AGCCloudDBListenerHandler类表示一个快照侦听，当调用AGCCloudDBZone类中的[subscribeSnapshotWithQuery](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbzone-ios-0000001127718205#section79221294241)方法成功注册快照侦听时才会获取一个AGCCloudDBListenerHandler对象。直到您显式地调用remove方法注销快照侦听，否则快照侦听将会一直生效，即快照发生任何变化都会持续的通过[AGCCloudDBSnapshotCallback](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-type-definitions-ios-0000001127718207#section717024113136)触发回调。

## -remove

调用此方法注销快照侦听。如果未注销快照侦听，快照侦听将会一直生效，即快照发生任何变化都会持续的通过[AGCCloudDBSnapshotCallback](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-type-definitions-ios-0000001127718207#section717024113136)进行回调，且您将会无法关闭CloudDBZone。

**OBJECTIVE-C**

```screen
-(void)remove;
```
