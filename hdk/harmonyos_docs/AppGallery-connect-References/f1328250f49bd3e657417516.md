# ohAegHuksEnc

ohAegHuksEnc(keyAlias: string, text: Uint8Array, iv?: Uint8Array): Promise<Uint8Array>

基于HUKS的AES-GCM加密，无需传入密钥，加密结果是Uint8Array类型，建议与[ohAegHuksDec](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ohaeghuksdec-0000001865925604)配套使用，分组模式、填充模式如下：

|分组模式|密钥长度（bit）|填充模式|API版本|
|:---|:--------|:--------|:----|
|GCM|256|NoPadding|11+|

**导入模块：**

```screen
import { AegHuks } from '@hw-agconnect/petal-aegis';
```

**参数** **：**

|参数名|类型|必填|说明|
|:-------|:---------|:-|:----------------------------------|
|keyAlias|string|是|密钥别名|
|text|Uint8Array|是|待加密的明文内容|
|iv|Uint8Array|否|长度12字节，如果没有传入，接口会自动生成iv，随密文一同作为返回值。|

**返回值：**

|参数|类型|说明|
|:----------|:---------|:------|
|encryptText|Uint8Array|加密后的密文。|
