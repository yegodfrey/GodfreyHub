# 批量去激活商品

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250806180214.39977998808127190039263341644735:50001231000000:2800:1BDCB18DF82ED9153D20D2C7D99BB542357575E71540EE2E92B17C391B1524A8.png)  
如果您前期已使用该接口为您的HarmonyOS 5.0及以上应用接入商品管理，请尽快切换至[HarmonyOS 5.0及以上 V2版本接口](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-batchdeactproduct-harmonyosnext-0000002166748613)。  

#### 功能介绍

此接口用于批量去激活商品。  

#### 使用约束

接口调用者的角色：账号持有者、管理员、APP管理员、运营。  

#### 接口原型

|承载协议|HTTPS PUT|
|接口方向|开发者服务器-\>数字商品服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/pms/product-price-service/v1/manage/product/batchDeactive|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|--------------------------------------------------------------------------------------------------|

#### 请求参数

#### Header

|client_id|M|String|客户端ID，获取方法参考[创建API客户端](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section103mcpsimp)。|
|Authorization|M|String|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)中获取的access_token。|

OAuth Client方式  

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### Body

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:--------|:----------|:-------------|:--------------------|
|requestId|M|String|请求序列，开发者自定义唯一标识符。|
|products|M|List\<String\>|商品标识，只有上线状态的商品才能被去激活。|

#### 调用示例

```
"Java"
public static ProductDeactiveResp batchActive(String domain, String clientId, String authorization, String appId,
    ProductDeactiveReq req) {
    String url = domain + "/api/pms/product-price-service/v1/manage/product/batchDeactive";
    HttpPut put = new HttpPut(url);
    setHttpHead(clientId, authorization, appId, put);
    StringEntity entity = new StringEntity(JSON.toJSONString(req), ContentType.create("application/json", "UTF-8"));
    put.setEntity(entity);
    String result = getApiResp(put);
    if (StringUtils.isNotEmpty(result)) {
        return JSON.parseObject(result, ProductDeactiveResp.class);
    }
    return null;
}
```
