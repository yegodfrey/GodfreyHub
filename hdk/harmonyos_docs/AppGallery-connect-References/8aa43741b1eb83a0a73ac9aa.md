# ProductPromotionInfo

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------------------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|promotionId|O|String|促销唯一ID，创建时不需传入，系统自动生成。更新时必须传入，不支持修改。|
|productId|O|String|关联商品主键ID，对应[查询商品详情接口](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-getproductinfo-harmonyosnext-0000002131350708)中的id字段，不支持修改。（productNo为空时，必填）。|
|productNo|O|String|商品标识，对应[查询商品详情接口](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-getproductinfo-harmonyosnext-0000002131350708)中的productNo字段，不支持修改。（productId为空时，必填）。|
|startDate|M|Integer(64)|开始促销时间，时间戳。|
|endDate|O|Integer(64)|结束促销时间，时间戳。 说明： 进行中的促销只支持修改endDate字段和status字段。|
|status|O|String|促销状态，默认值：active，创建时不支持配置为inactive。 * active：上线 * inactive：下线 说明： 进行中的促销只支持修改endDate字段和status字段。|
|strategy|M|String|促销策略类型： * trial：免费试用（仅自动续期型商品支持） * introductory：按周期扣费（仅自动续期型商品支持） * pay-up-front：提前支付（仅自动续期型商品支持） * single-promotion：单商品优惠（仅消耗型，非消耗型，非续期型商品支持） 商品类型与策略类型映射关系请参见[商品类型与促销类型、策略类型关系映射表](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-faq-0000001304804872#section1333114369335)。|
|promotionTitle|M|String|促销名称。|
|defaultLocale|M|String|默认语言环境，请参见[国家/地区、语言、币种列表](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-supported-countries-overview-0000001146718725)。 例如：zh_CN、en_US。|
|promotionDesc|O|String|默认促销描述信息。|
|periodUnit|O|String|优惠周期单位，仅当关联商品为auto_subscription类型时支持配置： * D：天 * W：周 * M：月 * Y：年 说明： 免费试用促销可选择的周期为三天、一周、两周、一个月、两个月、三个月、六个月、一年。 按周期扣费促销可选择的周期与商品配置的周期相关： * 商品配置为一周的，促销可选一周、两周、三周、四周 * 商品配置为一个月的，促销可选一至十二个月 * 商品配置为两个月的，促销可选二、四、六、八、十、十二个月 * 商品配置为三个月的，促销可选三、六、九、十二个月 * 商品配置为六个月的，促销可选六、十二个月 * 商品配置为一年的，促销只能是一年|
|numberOfUnits|O|Integer|优惠周期数，仅当关联商品为auto_subscription类型时支持配置。如优惠两个月，numberOfUnits=2， periodUnit=M。|
|currency|O|String|用于支付的默认币种，strategy为introductory、single-promotion、pay-up-front时必须传入，请参见[国家/地区、语言、币种列表](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-supported-countries-overview-0000001146718725)。 例如：USD、CNY、MYR。|
|country|O|String|默认国家码，用于区分国家信息，strategy为introductory、single-promotion、pay-up-front时必须传入，请参见[国家/地区、语言、币种列表](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-supported-countries-overview-0000001146718725)。 例如：CN。|
|defaultPrice|O|String|默认价格，单位为分，strategy为introductory、single-promotion、pay-up-front时必须传入。|
|prices|M|List\<[PromotionPriceInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-pms-ptpriceinfo-harmonyosnext-0000002166748641)\>|各个国家的促销定价信息。如果不传，则促销无效。|
|languages|O|List\<[PromotionLanguageInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-pms-ptlanguageinfo-harmonyosnext-0000002131350740)\>|各个国家的语言信息。|
|promotionType|O|Integer|促销类型，默认值：0。 * 0：新用户促销 * 1：自定义人群促销 * 4：退订挽留促销 说明： * 该参数仅在创建商品促销时支持。 * 商品类型与促销类型映射关系请参见[商品类型与促销类型、策略类型关系映射表](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-faq-0000001304804872#section1333114369335)|
|offerId|O|String|优惠促销标识符，用于区分不同优惠促销，该ID当前商品下唯一，最大长度64个字符，需满足\[0-9a-zA-Z\]。 说明： * 仅在创建促销类型为自定义人群促销时支持，其他情况均不支持。 * 该参数不支持修改。|
|betweenOffersNumOfUnits|O|Number|优惠间隔周期数。 说明： * 仅在促销类型为退订挽留优惠时必填，其他促销类型返回null。 * 该参数不支持修改。 * 只支持传入0-12的数值。|
|betweenOffersPeriodUnit|O|String|优惠间隔时间单位。 说明： * 仅在促销类型为退订挽留优惠时必填，其他促销类型返回null。 * 该参数不支持修改。 * 支持配置： M：月|
