|key|自定义键值对的key值。 每组键值对的key最长为1KB，超过会被截断。最多可支持64组键值对，超过后不再保存更多的值。|

#### -log:

不设置自定义日志，默认级别为info。

OBJECTIVE-C

```
- (void)log:(NSString *)message;
```

SWIFT

```
open func log(message: String)
```

<br />

Parameters  

|Name|Description|
|:------|:-------------------------------------------------------------|
|message|自定义日志的内容。 单条日志长度最长不能超过4KB，超过会被截断。日志总大小限制为不超过64KB，超过会删除最早的日志条目。|

#### -logWithLevel:message:

设置自定义日志，并设置日志级别。

OBJECTIVE-C

```
- (void)logWithLevel:(AGCCrashLogLevel)level message:(NSString *)msg;
```

SWIFT

```
open func log(level: AGCCrashLogLevel, message: String)
```

<br />

Parameters  

|Name|Description|
|:------|:----------------------------------------------------------------------------------------------------|
|level|自定义日志的级别。 * DEBUG：表示添加DEBUG级别的日志。 * INFO：表示添加INFO级别的日志。 * WARN：表示添加WARN级别的日志。 * ERROR：表示添加ERROR级别的日志。|
|message|自定义日志的内容。 单条日志长度最长不能超过4KB，超过会被截断。日志总大小限制为不超过64KB，超过会删除最早的日志条目。|
