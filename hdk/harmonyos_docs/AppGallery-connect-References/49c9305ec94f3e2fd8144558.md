#### setCustomLogInfo

|Method|
|:-----------------------------------------------|
|public void log(int level, String text) 设置自定义日志。|

Parameters  

|Name|Description|
|:----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|level|自定义日志的级别。目前支持5个级别。 * HiLog.DEBUG：表示添加DEBUG级别的日志。 * HiLog.INFO：表示添加INFO级别的日志。 * HiLog.WARN：表示添加WARN级别的日志。 * HiLog.ERROR：表示添加ERROR级别的日志。 * HiLog.FATAL：表示添加FATAL级别的日志。|
|text|自定义日志的内容。 单条日志长度最长不能超过4KB，超过会被截断。日志总大小限制为不超过64KB，超过会删除最早的日志条目。|
