# 查询资源包文件

#### 功能介绍

查询资源包文件。  

#### 接口原型

|承载协议|HTTP GET|
|接口方向|开发者服务器 -\>华为服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/games-background-assets-service/v1/open-gw/dev/{devId}/package-files|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|-------------------------------------------------------------------------------------------------------------|

#### 请求参数

#### Header

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|M|String|客户端ID，获取方法参考[创建API客户端](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section103mcpsimp)，其中"角色"支持勾选"APP管理员"、"管理员"、"运营"。|
|Authorization|M|String|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)中获取的access_token。|

#### Path

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----|:----------|:---|:-----|
|devId|M|Long|开发者ID。|

#### Query

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:--------|:----------|:-----|:--------------------------------------------------------------------------------------------------------------------|
|appId|M|String|游戏APP ID，获取方法参考[查询应用信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/appgallery_queryappinfo)。|
|versionId|O|Long|资源包版本ID。 说明： versionId参数和fileIds参数，选择一个传入。|
|fileIds|O|String|资源包文件ID列表，使用英文逗号分隔。取值范围：\[1,500\]。 说明： versionId参数和fileIds参数，选择一个传入。|
|page|O|Int|请求页码，默认值：1。|
|limit|O|Int|列表查询单页数量。取值范围：\[1,100\]。 默认值：20|

```
GET /api/games-background-assets-service/v1/open-gw/dev/12***3344/package-files/?appId=69***47 HTTP/1.1
Host: connect-api.cloud.huawei.com
client_id: 41*****7168
Authorization: Bearer ******
```

#### 响应参数

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:---|:----------|:---------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------|
|ret|M|[GbasRet](#ZH-CN_TOPIC_0000002362274749__li1750915382310)|包含返回码及描述信息的JSON字符串，格式为{"code":retcode, "msg": "description"}，retcode为返回码，description为返回码描述信息。|
|data|M|[GWOpGetPackageFilesRspData](#ZH-CN_TOPIC_0000002362274749__li4691840161518)|查询资源包文件返回体。|

* GbasRet  

  |参数名称|必选(M)/可选(O)|类型|参数说明|
  |:---|:----------|:-----|:--------------------------------------------------------------------------------------------------------------------------------------|
  |code|O|Int|返回码，请参见[错误码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-respackapi-returncode-0000002328236396)。|
  |msg|O|String|返回码描述信息。|

* GWOpGetPackageFilesRspData  

  |参数名称|必选(M)/可选(O)|类型|参数说明|
  |:------------|:----------|:-------------------------------------------------------------------------|:----|
  |resourceFiles|O|List\< [GWOpPackageFile](#ZH-CN_TOPIC_0000002362274749__li1491672513168)\>|文件列表。|
  |totalCount|O|Int|文件总数。|

  * GWOpPackageFile  

    |参数名称|必选(M)/可选(O)|类型|参数说明|
    |:----------|:----------|:-----|:--------------------------------------------------------------------------|
    |fileId|O|String|文件ID。|
    |fileName|O|String|文件名称。|
    |versionId|O|String|资源包版本ID。|
    |fileLength|O|Long|升级包文件大小（字节数）。|
    |status|O|Int|文件状态： * 0：上传中（已申请） * 1：已生效（已发布） <!-- --> * 2：上传失败 * 3：扫描中 <!-- --> * 4：扫描失败|
    |downLoadUrl|O|String|文件下载地址。|
    |createTime|O|Long|创建时间。|
    |updateTime|O|Long|修改时间。|

#### 调用示例

```
public static JSONObject getResourceFiles(String domain, String client_id, String token, String appId) {
    HttpGet httpReq = new HttpGet(domain + "/api/games-background-assets-service/v1/open-gw/dev/12***3344/package-files/?appId=" + appId);
    httpReq.setHeader("client_id", client_id);
    httpReq.setHeader("Authorization", "Bearer " + token);
    try {
        CloseableHttpClient httpClient = HttpClients.createDefault();
        CloseableHttpResponse httpResponse = httpClient.execute(httpReq);
        int statusCode = httpResponse.getStatusLine().getStatusCode();
        if (statusCode == HttpStatus.SC_OK) {
            BufferedReader br = new BufferedReader(new InputStreamReader(httpResponse.getEntity().getContent(), Consts.UTF_8));
            String result = br.readLine();

            JSONObject object = JSON.parseObject(result);
            return object;
        }
    } catch (Exception e) {
        e.printStackTrace();
    }
    return null;
}
```
