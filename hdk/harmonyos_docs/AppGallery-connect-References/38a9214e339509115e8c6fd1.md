# APM

APM JS SDK服务入口类。  

#### Method Summary

|Qualifier and Type|Method Name and Description|
|:---------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------|
|void|[enable](#section7204103935710)(enable: boolean) 设置是否启用性能监控数据采集。|
|[Trace](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/trace-0000001052495065)|[createTrace](#section123301954101816)(traceName: string) 创建一条自定义跟踪记录。|

#### Methods

#### enable

|Method|
|:--------------------------------------------|
|enable(enable: boolean): void 设置是否启用性能监控数据采集。|

Parameters  

|Name|Description|
|:-----|:-----------------------------------------------------------------------|
|enable|是否启用性能监控数据采集。默认值为true。 * true：启动，APM会采集性能监控数据。 * false：关闭，APM不会采集性能监控数据。|

Sample Code

```
APM.enable(true)
```

#### createTrace

|Method|
|:-------------------------------------------------|
|createTrace(traceName: string): Trace 创建一条自定义跟踪记录。|

Parameters  

|Name|Description|
|:--------|:----------------------------------------------|
|traceName|自定义跟踪记录名称，只能包含中文、字母（不区分大小写）、数字和下划线，且长度不能超过40字符。|

Return  

|Type|Description|
|:---------------------------------------------------------------------------------------------------------------------|:----------|
|[Trace](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/trace-0000001052495065)|自定义追踪的实例。|

Sample Code

```
const trace = APM.createTrace('trace')
```
