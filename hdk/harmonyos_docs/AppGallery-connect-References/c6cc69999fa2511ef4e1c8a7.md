# 下单

#### 接口功能

本接口购买游戏内商品进行下单。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|华为服务器 -\> 三方应用服务器|
|性能指标|TPS\>200|
|最大响应时间|\<200ms|
|接口URL|URL从AGC中[接入配置](https://developer.huawei.com/consumer/cn/doc/app/game-center-prop-mall-0000002302937820#section21502017134016)获取。|
|------|--------------------------------------------------------------------------------------------------------------------------------|

#### 请求参数

Body参数：  

|参数|必选（M）/可选（O）|类型|说明|
|:---------|:----------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|requestId|M|String(64)|请求标识。|
|userId|M|String(256)|华为账号登录游戏后生成的玩家标识。|
|userIdType|M|Int|玩家标识类型： 1：playerId 2：openId 3：unionid 4：gamePlayerId 5：teamPlayerId 6：thirdUserId 说明： userId和userIdType配套使用，userId是值，userIdType是类型。|
|zoneId|M|String(64)|游戏内区服ID。|
|roleId|M|String(64)|游戏内角色ID。|
|productId|M|String(64)|商品ID。|
|price|M|Long|商品价格，单位：分。|
|quantity|M|Long|订购数量。|
|currency|M|String(4)|商品价格币种。|
|ts|M|Long|当前时间（单位为：milliseconds），由System.currentTimeMillis()获取。|
|sign|M|String(8192)|RSA签名（使用游戏服务公钥进行验签，待验签内容生成方法见[签名机制](#section7914950122315)）。 签名算法为SHA256WithRSA/PSS。 注意： * 考虑到自选参数格式多样化，本参数在"utf-8" urlencode后发送。 * Java中request的getParameter()方法会隐含进行urldecode。|

#### 请求示例

```
POST {第三方应用服务器url} HTTP/1.1
Content Type : application/x-www-form-urlencoded; charset=UTF-8
requestId=***&userIdType=1&userId=***&zoneId=***&roleId=***&productId=***&price=***currency=***&sign=***&ts= ***
```

#### 响应参数

返回码：200

Body参数：  

|参数|必选（M）/可选（O）|类型|说明|
|:------|:----------|:-----------|:---------------------------------------------------------------------------------------------------------|
|result|M|Int|操作结果： 0：成功 1：验签失败 2：业务信息错误，比如userId不存在,区服角色错误 3：IP白名单限制，开发者侧拒绝服务（禁止开发者设置白名单，错误码仅仅用于异常监控） 4：游戏内购买限制 99：其他错误|
|payload|M|String(256)|订单关键信息。 说明： 响应的payload，会用于后续的发货流程中。建议和游戏内下单时提供给华为收银台的保持相同，避免对后续发货流程的影响。|
|sign|M|String(8192)|签名信息。 待签名字符串： ``` payload=xxxx ``` RSA签名（使用游戏服务私钥进行签名，待验签内容生成方法见[签名机制](#section7914950122315)）|

#### 响应示例

```
HTTP/1.1 200 OK
Content Type : application/json ; charset=UTF-8
{
    "result":0,
    "payload":"*****"
}
```

#### 校验签名

#### 生成签名字符串

以如下参数数组为例：

```
requestId=550***00&userIdType=1&userId=144***50&zoneId=957***76&roleId=101&productId=11&price=600&currency=CNY&sign=XXX&ts= 174***64&quantity=1
```

1. 将请求参数中需要参与签名的参数，按参数名首字母的ASCII码将参数升序排序，若遇到相同首字母，则比较第二个字母，以此类推。需要参与签名的参数是指接口说明中"是否参与签名"列为"是"的参数。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250806180204.24608983002169997362680179107127:50001231000000:2800:17CC14338729F0A9589DC2920C26C0A35CA56A3A43E58F393D67974A3012B0F3.png)  
   * 没有值（包括null和""情况）的参数如果出现在请求中也需要包含到待签名数据中，参与签名的格式如下：

     ```
     parametername = 
     ```

   * 只有出现在接口中的参数需要参与验签，没有出现的不参与。
2. 排序完成之后，将所有数组值（value非空）进行urlencode。
3. 将urlencode之后的所有参数名和参数值的键值对以"\&"字符连接起来，此字符串便是待签名字符串，如下列字符串所示：

   ```
   currency=CNY&price=600&productId=11&quantity=1&requestId=550***00&roleId=101&sign=XXX&ts=174***64&userId=144***50&userIdType=1&zoneId=957***76
   ```

   生成待签名字符串的Java示例代码如下：

   ```
   public static String buildSortedSignData(Map<String, String> params) throws UnsupportedEncodingException {
       StringBuilder targetParamStr = new StringBuilder();
       Map<String, String> sortedParamMap = new TreeMap<>(params);
       for (Map.Entry<String, String> param : sortedParamMap.entrySet()) {
           String key = param.getKey();
           String value = param.getValue();
           targetParamStr.append(key)
               .append("=")
               .append(null == value ? "" : URLEncoder.encode(value, "UTF-8"))
               .append("&");
       }
       return targetParamStr.substring(0, targetParamStr.toString().length() - 1);
   }
   ```

4. 将待签名字符串使用游戏私钥按照RSA算法（SHA256WithRSA/PSS）进行签名，将签名后的字符串经过Base64编码，得到的字符串即为签名字符串。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250806180204.39792869896511277382922149585764:50001231000000:2800:FA896775FBBD145CE7668651A9FE9A86627EE532327C86261B87559278CE1918.png)  
   * 游戏私钥在开通游戏服务后生成，查询方法参见[查询游戏服务信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-prop-overview-0000002321821228#section714665315115)。
   * 正式上线时，示例代码中的privateKey请务必替换为AppGallery Connect上的[游戏私钥](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-prop-overview-0000002321821228#section204081625185415)；在自行验证时，亦可将代码中的privateKey在本地代码中替换为AppGallery Connect上的[游戏私钥](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-prop-overview-0000002321821228#section204081625185415)，用于自验证验签逻辑。
   * sign在RSA签名后需要进行Base64编码。  
   生成签名字符串的Java示例代码如下：

   ```
   public static String signWithRSA(byte[] data, String privateKey) throws Exception {
       byte[] keyBytes = Base64.decodeBase64(privateKey);
       PKCS8EncodedKeySpec pkcs8KeySpec = new PKCS8EncodedKeySpec(keyBytes);
       KeyFactory keyFactory = KeyFactory.getInstance("RSA");
       PrivateKey privateK = keyFactory.generatePrivate(pkcs8KeySpec);
       Signature signature = Signature.getInstance("SHA256WithRSA/PSS");
       signature.initSign(privateK);
       signature.update(data);
       return Base64.encodeBase64String(signature.sign());
   }
   ```

#### 校验签名

1. 获取请求参数，[生成签名字符串](#section93661014020)。
2. 使用游戏公钥对签名字符串进行验证。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250806180204.57801157155841590547354498281774:50001231000000:2800:B36D62540E9E41A424BE44C35D529EE70840B8AEC688AA69693978ABB7B75B9A.png)  
   * 游戏公钥在开通游戏服务后生成，查询方法参见[查询游戏服务信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-prop-overview-0000002321821228#section714665315115)。
   * 正式上线时，示例代码中的publicKey请务必替换为AppGallery Connect上的[游戏公钥](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-prop-overview-0000002321821228#section204081625185415)；在自行验证时，亦可将代码中的publicKey在本地代码中替换为AppGallery Connect上的[游戏公钥](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-prop-overview-0000002321821228#section204081625185415)，用于自验证验签逻辑。

   校验签名的Java示例代码如下：

   ```
   public static boolean verify(byte[] data, String publicKey, String sign) throws Exception {
       byte[] keyBytes = Base64.decodeBase64(publicKey);
       X509EncodedKeySpec keySpec = new X509EncodedKeySpec(keyBytes);
       KeyFactory keyFactory = KeyFactory.getInstance("RSA");
       PublicKey publicK = keyFactory.generatePublic(keySpec);
       Signature signature = Signature.getInstance("SHA256WithRSA/PSS");
       signature.initVerify(publicK);
       signature.update(data);
       return signature.verify(Base64.decodeBase64(sign));
   }
   ```

#### 服务端示例代码

* 验签示例代码

  ```
  "JAVA"
  package com.huawei.game.domain.develop.test;
  import org.apache.commons.codec.binary.Base64;
  import java.io.UnsupportedEncodingException;
  import java.net.URLEncoder;
  import java.nio.charset.StandardCharsets;
  import java.security.KeyFactory;
  import java.security.PublicKey;
  import java.security.Signature;
  import java.security.spec.X509EncodedKeySpec;
  import java.util.HashMap;
  import java.util.Map;
  import java.util.TreeMap;
  public class SecretVerifyTest {
      public static void main(String[] args) throws Exception {
          // 以下公钥和私钥为临时生成，以供展示代码示例，正式环境请替换
          String publicKey = "MIIBIjANBgkqh*****AB";
          String privateKey = "MIIEvAIBADANB*****==";
          System.out.println("公钥：" + publicKey);
          System.out.println("私钥：" + privateKey);
          // 模拟入参
          HashMap<String, String> reqMap = new HashMap<>();
          // 验签步骤
          // 1. 从请求中取出sign属性，注意：待验签的字符串不包含sign属性，此时需要从Map中取出。
          String reqSign = reqMap.remove("sign");
          System.out.println("加签结果：" + reqSign);
          // 2. 生成待验签的字符串。
          String targetStr = buildSortedSignData(reqMap);
          System.out.println("加签的字符串：" + targetStr);
          // 3. 进行验签，注意：此处验签的公钥需要修改为AGC管理台上的公钥。
          boolean result = verify(targetStr.getBytes(StandardCharsets.UTF_8), publicKey, reqSign);
          System.out.println("验签结果为：" + result);
      }
      /**
       * 生成待签名的字符串
       *
       * @param params 入参
       * @return 待签名的字符串
       */
      public static String buildSortedSignData(Map<String, String> params) throws UnsupportedEncodingException {
          StringBuilder targetParamStr = new StringBuilder();
          Map<String, String> sortedParamMap = new TreeMap<>(params);
          for (Map.Entry<String, String> param : sortedParamMap.entrySet()) {
              String key = param.getKey();
              String value = param.getValue();
              targetParamStr.append(key)
                  .append("=")
                  .append(null == value ? "" : URLEncoder.encode(value, "UTF-8"))
                  .append("&");
          }
          return targetParamStr.substring(0, targetParamStr.toString().length() - 1);
      }
      /**
       * 验签结果
       *
       * @param data 待验签的字符串
       * @param publicKey 公钥
       * @param sign 签名字符串
       * @return 验签结果
       */
      public static boolean verify(byte[] data, String publicKey, String sign) throws Exception {
          byte[] keyBytes = Base64.decodeBase64(publicKey);
          X509EncodedKeySpec keySpec = new X509EncodedKeySpec(keyBytes);
          KeyFactory keyFactory = KeyFactory.getInstance("RSA");
          PublicKey publicK = keyFactory.generatePublic(keySpec);
          Signature signature = Signature.getInstance("SHA256WithRSA/PSS");
          signature.initVerify(publicK);
          signature.update(data);
          return signature.verify(Base64.decodeBase64(sign));
      }
  }
  ```
