# FFVKImageSync

图像资源同步信息。

**Structure Declaration**

```screen
typedef struct FFVKImageSync {
    VkAccessFlagBits           accessMask;
    VkImageLayout              layout;
    VkPipelineStageFlagBits    stages;
} FFVKImageSync;
```

**Members**

|Name|Mandatory/Optional|Description|
|:---------|:-----------------|:-------------|
|accessMask|必填|Vulkan访问掩码。|
|layout|必填|Vulkan图像布局。|
|stages|必填|Vulkan管线阶段标志位。|
