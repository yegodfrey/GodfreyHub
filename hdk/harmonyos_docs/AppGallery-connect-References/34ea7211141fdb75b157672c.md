# AppRating

|参数|必选(M)/可选(O)|类型|描述|
|:----------|:----------|:------|:---------------------------------|
|reviewId|O|String|评论ID。|
|appVersion|O|String|应用版本号。|
|phoneType|O|String|机型。|
|rating|O|Integer|评分。|
|dateline|O|Long|评论时间，从1970/01/01 08:00:00开始计算的毫秒数。|
|countryCode|O|String|ISO标准国家码。|
