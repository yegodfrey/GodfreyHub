# 查询是否有在线商品

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250806180214.73363859246336843133198312072283:50001231000000:2800:9AF4DC20C5C06D3B5698784F67ECC795C5FD16EBB45967BBDFBD56C6FD722C39.png)  
如果您前期已使用该接口为您的HarmonyOS 5.0及以上应用接入商品管理，请尽快切换至[HarmonyOS 5.0及以上 V2版本接口](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-isproductactive-harmonyosnext-0000002166670145)。  

#### 功能介绍

此接口用于根据AppId查询是否有激活的商品。  

#### 使用约束

接口调用者的角色：账号持有者、管理员、APP管理员、运营。  

#### 接口原型

|承载协议|HTTPS GET|
|接口方向|开发者服务器-\>数字商品服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/pms/product-price-service/v1/manage/product/check|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|------------------------------------------------------------------------------------------|

#### Header

|:------------|:----------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|M|String|客户端ID，获取方法参考[创建API客户端](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section103mcpsimp)。|
|Authorization|M|String|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)中获取的access_token。|
|appId|M|String|应用ID，获取方法参考[查询应用信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/appgallery_queryappinfo)。|

|参数名称|必选(M)/可选(O)|类型|参数说明|

#### 请求示例

```

Content-Type: application/json
client_id: ***
Authorization: Bearer ***

```

#### 调用示例

```
"Java"
public static ProductCheckResp checkProductInfo(String domain, String clientId, String authorization,
    String appId) {
    String url = domain + "/api/pms/product-price-service/v1/manage/product/check";
    HttpGet get = new HttpGet(url);
    setHttpHead(clientId, authorization, appId, get);
    String result = getApiResp(get);
    if (StringUtils.isNotEmpty(result)) {
        return JSON.parseObject(result, ProductCheckResp.class);
    }
    return null;
}
```
