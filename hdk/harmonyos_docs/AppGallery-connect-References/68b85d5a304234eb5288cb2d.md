# AGCCloudDBObject

```screen
@interface AGCCloudDBObject : NSObject
```

AGCCloudDBObject类是一个NSObject类，属于对象类型的基类，您可以通过添加AppGallery Connect控制台导出的对象类型来实现创建继承此类的对象类型。 当前支持的数据类型：NSNumber <AGCBool>、NSNumber<AGCByte>、NSNumber<AGCShort>、NSNumber<AGCInt>、NSNumber<AGCLong>、NSNumber<AGCFloat>、NSNumber<AGCDouble>、NSData、NSDate、NSString和AGCCloudDBText。
