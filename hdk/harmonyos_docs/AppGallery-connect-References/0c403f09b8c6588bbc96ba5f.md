# ohAegSMDec

ohAegSMDec(text: Uint8Array, key: Uint8Array): Promise<Uint8Array>

SM4-CBC解密算法，配套[ohAegSMEnc](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ohaegsmenc-0000001864225584)接口使用，分组模式、填充模式如下：

|分组模式|密钥长度（bit）|填充模式|API版本|
|:---|:--------|:----|:----|
|CBC|128|PKCS7|11+|

**导入模块：**

```typescript
import { AegSM } from '@hw-agconnect/petal-aegis';
```

**参数** **：**

|参数名|类型|必填|说明|
|:---|:---------|:-|:------------------------------------|
|text|Uint8Array|是|待解密内容（ohAegSMEnc加密后的结果），格式为**iv:密文**。|
|key|Uint8Array|是|解密使用的密钥。|

**返回值：**

|参数|类型|说明|
|:----------|:---------|:--------------------|
|decryptText|Uint8Array|明文普通字符串的Uint8Array格式。|

**示例：**

```typescript
import { AegSM } from '@hw-agconnect/petal-aegis';
import { buffer } from '@kit.ArkTS';

async function sm4cbc3() {
  let plainText = 'hello world'; //待加密内容
  let key = '1234567891234567'; //长度16字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let iv = '9876543217654321'; //长度16字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let inputUint8 = new Uint8Array(buffer.from(plainText, 'utf-8').buffer);
  let keyUint8 = new Uint8Array(buffer.from(key, 'utf-8').buffer);
  let ivUint8 = new Uint8Array(buffer.from(iv, 'utf-8').buffer);

  try {
    let encryptText = await AegSM.ohAegSMEnc(inputUint8, keyUint8, ivUint8);
    //sm4cbc3  encryptText: 57,56,55,54,53,52,51,50,49,55,54,53,52,51,50,49,58,155,33,239,15,249,8,1,141,7,122,48,126,61,60,108,22
    console.log("sm4cbc3 ", 'encryptText: ' + encryptText);

    let decryptText = await AegSM.ohAegSMDec(encryptText, keyUint8);

    if (plainText === uint8ArrayToString(decryptText)) {
      console.info('sm4cbc3 decrypt ok');
    }
    console.log("sm4cbc3 ", 'decryptText: ' + uint8ArrayToString(decryptText));
  } catch (err) {
    console.log("sm4cbc3 ", 'err: ' + err);
  }
}

function uint8ArrayToString(data: Uint8Array) {
  let dataString = '';
  for (let i = 0; i < data.length; i++) {
    dataString += String.fromCharCode(data[i]);
  }
  return dataString;
}
```
