# hmacSync

hmacSync(alg:HmacAlg, text:string\|Uint8Array, key:string\|Uint8Array): Uint8Array

消息认证算法，返回Uint8Array格式密文。

导入模块：

```
import { aegis } from '@hw-agconnect/petal-aegis';
```

参数：  

|参数名|类型|必填|说明|
|:---|:-------------------------------------------------------------------------------------------------------------|:-|:----------------------------------------------|
|alg|[HmacAlg](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/hmacalg-0000001964620509)|是|HASH模式枚举。|
|text|string\|Uint8Array|是|明文内容。|
|key|string或Uint8Array|是|密钥内容，hexstring或Uint8Array格式， 长度请参考HmacAlg的密钥长度。|

返回值：  

|参数|类型|说明|
|:---|:---------|:------------------|
|字节数组|Uint8Array|生成的加密Uint8Array字符串。|
