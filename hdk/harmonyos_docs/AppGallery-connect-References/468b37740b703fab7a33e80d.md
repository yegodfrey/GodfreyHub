# 获取玩家ID

## 功能介绍

通过accessToken获取游戏排行榜的用户ID。

## 使用约束

必须使用https协议。

## 接口原型

|承载协议|HTTPS POST|
|-----|-------------------------------------------------------------------|
|接口方向|华为服务器 -> 开发者服务器|
|接口URL|您提供的用户认证接口URL，必须为https协议，格式为https://your_auth_url。|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 请求参数

请求参数以JSON格式传入，包含参数如下。

|参数名称|必选(M)/可选(O)|数据类型|参数说明|
|:----------|:----------|:-----------|:----------------------------------------------------------------------------------------------------------------------|
|appId|M|String(64)|应用ID，获取方法参考[查看应用基本信息](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-appinfo-0000001100014694)。|
|accessToken|M|String(2048)|玩家ID的认证凭据，来自于您调用函数接口时带的参数值。|

## 请求示例

```screen
POST https://your_auth_url
Content-Type: application/json; charset=utf-8
{
       "accessToken":"eyJhbGciOiJIUzU****************",
       "appId":"102***218"
}
```

## 响应参数

返回值为JSON格式的字符串，包含参数如下。
> 说明
>
> 返回码使用标准HTTP状态码，详情请参考[返回码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-serverless-leaderboards-returncode-0000001323309633)。

|参数名称|必选(M)/可选(O)|数据类型|参数说明|
|:---|:----------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------|
|ret|M|String|获取Token失败时返回的错误信息，包含错误码及描述信息的JSON字符串，格式为{"code":*retcode* , "msg": "*description* "}，详情请参见[ret参数](#ZH-CN_TOPIC_0000001296645276__li1171741871918)。|
|data|M|String|JSONObject字符串的信息，格式为{"playerId": "string"}，详情请参见[data参数](#ZH-CN_TOPIC_0000001296645276__li8176052152215)。|

* ret参数

  |参数名称|必选(M)/可选(O)|数据类型|参数说明|
  |:---|:----------|:------|:-------------------------------------|
  |code|M|Integer|返回码： * 0：成功。 * 403：accessToken无效，鉴权失败。|
  |msg|O|String|返回码的描述信息。|

* data参数

  |参数名称|必选(M)/可选(O)|数据类型|参数说明|
  |:-------|:----------|:----------|:----|
  |playerId|M|String(200)|用户ID。|

## 响应示例

```screen
HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8
{
	"ret": {
		"code": 0,
		"msg": "common success"
	},
	"data": {
		"playerId": "10****01"
	}
}
```
