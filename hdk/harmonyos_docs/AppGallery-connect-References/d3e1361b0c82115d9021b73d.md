# FFInstanceCreateInfo

创建库实例信息。

**Structure Declaration**

```screen
typedef struct FFInstanceCreateInfo {
    FFStructureType sType;
    const void* pNext;
    uint16_t majorVersion;
    uint16_t minorVersion;
    PFN_FrameFlow_ApiLoaderFunction pfnApiLoaderFunction;
    PFN_FrameFlow_ErrorReportCallback pfnErrorReportCallback;
    void* pUserData;
} FFInstanceCreateInfo;
```

**Members**

|Name|Mandatory/Optional|Description|
|:---------------------|:-----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|sType|Mandatory|此结构体类型必须为**FF_STRUCTURE_TYPE_INSTANCE_CREATE_INFO**。|
|pNext|Optional|指向功能扩展链中的下一个结构体的指针。扩展参数，可缺省，默认值为NULL。|
|majorVersion|Mandatory|游戏使用的API主要版本。 > 说明 > 插帧服务版本号由主要版本和次要版本组成，例如，当前版本为5.0，其中"5"为主要版本。版本号信息具体请参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/predict-frame-releasenotes-0000001630692613)。|
|minorVersion|Mandatory|游戏使用的API次要版本。 > 说明 > 插帧服务版本号由主要版本和次要版本组成，例如，当前版本为5.0，其中"0"为次要版本。版本号信息具体请参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/predict-frame-releasenotes-0000001630692613)。|
|pfnApiLoaderFunction|Optional|负责加载图形API入口点的函数。预留参数，默认值为NULL。|
|pfnErrorReportCallback|Optional|自定义的错误日志打印回调函数。默认值为NULL。|
|pUserData|Optional|自定义指针，将由实例传递给回调函数（例如[pfnApiLoaderFunction](#ZH-CN_TOPIC_0000001838093781__p15599189159)和[pfnErrorReportCallback](#ZH-CN_TOPIC_0000001838093781__p65597187151)）。默认值为NULL。|
