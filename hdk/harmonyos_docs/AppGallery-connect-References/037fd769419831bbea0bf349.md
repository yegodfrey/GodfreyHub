# FFResult

返回码。  
Enum Info

```
typedef enum FFResult {
    FF_SUCCESS = 0,
    FF_COLLECTING_PREVIOUS_FRAMES = 1,
    FF_NOT_ACTIVE = 2,
    FF_ERROR_METHOD_NOT_SUPPORTED = -1,
    FF_ERROR_INSUFFICIENT_INPUT_DATA = -2,
    FF_ERROR_INCOMPATIBLE_INPUT_DATA = -3,
    FF_ERROR_CONTRADICTIVE_INPUT_DATA = -4,
    FF_ERROR_NOT_INITIALIZED = -5,
    FF_ERROR_INTERNAL_ERROR = -6,
} FFResult;
```

Enum Value Summary  

|Return Code|Value|Description|
|:--------------------------------|:----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|FF_SUCCESS|0|成功。|
|FF_COLLECTING_PREVIOUS_FRAMES|1|调用绘制预测帧函数后，原始帧数据采集工作正在进行。此返回码为操作时的一种特殊状态，请耐心等待。|
|FF_NOT_ACTIVE|2|库实例未激活。请先[激活库实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/predict-frame-activate-instance-0000001580492828)。|
|FF_ERROR_METHOD_NOT_SUPPORTED|-1|插帧方案不支持。例如，使用FF_PREDICTION_ALGORITHM_HYDRA或FF_PREDICTION_ALGORITHM_IMAGE_ONLY_INTERPOLATION预测算法时，使用了不支持的外插方案则会报错，请根据[算法支持情况](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffpredictionalgorithm-0000001838093821)调整插帧方案。|
|FF_ERROR_INSUFFICIENT_INPUT_DATA|-2|数据缺失。例如，提供每帧数据时，缺少某些必填数据则会报错。请补充相关数据。|
|FF_ERROR_INCOMPATIBLE_INPUT_DATA|-3|输入数据类型不兼容。请修改为正确数据类型。|
|FF_ERROR_CONTRADICTIVE_INPUT_DATA|-4|输入数据矛盾。例如，[FFDrawFrameInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffdrawframeinfo-0000001838253753)中的targetIsTexture和target输入数据存在矛盾时则会报错。请修改为正确数据。|
|FF_ERROR_NOT_INITIALIZED|-5|未进行初始化。请先[创建一个库实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/predict-frame-create-instance-0000001580652660#section986414272417)。|
|FF_ERROR_INTERNAL_ERROR|-6|内部错误。|
