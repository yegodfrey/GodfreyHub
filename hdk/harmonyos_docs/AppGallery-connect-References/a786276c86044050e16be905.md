# ohAegHexStringToString

ohAegHexStringToString(input: string): string

16进制的hex string字符串转换为普通字符串。

**导入模块** **：**

```typescript
import { AegStrUtil } from '@hw-agconnect/petal-aegis';
```

**参数：**

|参数名|类型|必填|说明|
|:----|:-----|:-|:----------------------|
|input|string|是|待转换的16进制的hex string字符串。|

**返回值：**

|参数|类型|说明|
|:--|:-----|:---------|
|字符串|String|转换后的普通字符串。|

**示例：**

```typescript
import { AegStrUtil } from '@hw-agconnect/petal-aegis';

function hexStringToString() {
  let strUtil: AegStrUtil = new AegStrUtil()
  let input = '68656c6c6f20776f726c64'
  let result = strUtil.ohAegHexStringToString(input)
  //hexStringToString  result: hello world
  console.log("hexStringToString ", 'result: ' + result);
}
```
