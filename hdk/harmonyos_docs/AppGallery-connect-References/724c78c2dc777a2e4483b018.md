# CloudDBZoneQuery

|class info|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.agconnect.cloud.database.CloudDBZoneQuery 提供了诸如where()、equalTo()、notEqualTo()、in()等丰富的谓词查询来构造查询条件。您可以基于上述谓词查询方法构造自己的CloudDBZoneQuery对象，并作为executeQuery()、executeAverageQuery()和executeQueryUnsynced()等方法的参数传入，Cloud DB会基于指定的查询条件从CloudDBZone中获取到对应的对象并返回查询结果。|
