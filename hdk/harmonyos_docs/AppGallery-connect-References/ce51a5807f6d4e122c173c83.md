# AGConnectOptions

AGConnectOptions类型需要包含以下参数：  

|Name|Type|Mandatory/Optional|Description|
|:----------|:-------------|:-----------------|:----------|
|routePolicy|AGCRoutePolicy|Mandatory|路由地址。|
