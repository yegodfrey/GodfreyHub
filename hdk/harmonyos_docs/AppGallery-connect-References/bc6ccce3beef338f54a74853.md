# FFStencilRemapInfo

模板映射信息。

**Structure Declaration**

```screen
typedef struct FFStencilRemapInfo {
    FFStructureType sType;
    const void* pNext;
    FFStencilValueSemantic remapTable[FF_STENCIL_CAPACITY];
} FFStencilRemapInfo;
```

**Members**

|Name|Mandatory/Optional|Description|
|:---------|:-----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|sType|Mandatory|此结构体类型必须为**FF_STRUCTURE_TYPE_STENCIL_REMAP_INFO**。|
|pNext|Optional|指向扩展链中的下一个结构体的指针。扩展参数，可缺省，默认值为NULL。|
|remapTable|Mandatory|模板值语义表，具体请参见[FFStencilValueSemantic](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffstencilvaluesemantic-0000001838253773)。 > 注意 > * 必须是256个元素（0~255）的数组，其中每个数组索引都是模板掩码值。 > * 对remapTable需要使用0初始化，即将所有物体先标记为静态物体，否则将会导致预测输出不稳定。|
