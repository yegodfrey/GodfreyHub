# 上传单个文件

调用该接口上传待检测文件。

## 使用约束

文件上传地址有效时间为1小时，请及时上传。

## 接口原型

|承载协议|HTTPS PUT|
|-----|--------------------------------------------------------------------------------------------------------------------------------------------------------|
|接口方向|开发者服务器 -> 华为服务器|
|接口URL|[获取文件上传地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-obtaining-upload-address-restapi-0000001623600041)接口返回的url|
|数据格式|请求：Content-Type: text/csv 响应：Content-Type: application/json|

## 请求参数

### Request Header

|参数名称|必选（M）/可选（O）|类型|参数说明|
|:-------------------|:----------|:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Authorization|M|String|校验信息，即调用[获取文件上传地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-obtaining-upload-address-restapi-0000001623600041)接口返回的uploadHeaders参数中的Authorization。|
|x-amz-content-sha256|M|String|文件对象内容的sha256哈希值，即调用[获取文件上传地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-obtaining-upload-address-restapi-0000001623600041)接口返回的uploadHeaders参数中的x-amz-content-sha256。|
|x-amz-date|M|String|文件上传地址生成的时间，即调用[获取文件上传地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-obtaining-upload-address-restapi-0000001623600041)接口返回的uploadHeaders参数中的x-amz-date。|

### Request Body

本地待上传文件。

## 请求示例

```screen
PUT  获取文件上传地址接口返回的URL
x-amz-content-sha256:ac896e4fe5e3fa1df0******c5fe68fec7d10ff972cf5219274a20e
Authorization:AWS4-HMAC-SHA256 Credential=RTDMF0RK******81TBR5/20230613/cn-north-4/s3/aws4_request, SignedHeaders=content-length;content-type;host;x-amz-content-sha256;x-amz-date, Signature=a092a11662ca6e78d4ca91b4******ff790c29662a970435c182d6148
x-amz-date:20230613T063500Z
Content-Type:text/csv

"<file contents here>"
```

## 响应参数

接口返回的HTTP状态码为200时，表示文件上传成功。

## 调用示例

```screen
private void uploadFile(ApplyFileUploadRspData rspData) throws IOException {
        OkHttpClient client = new OkHttpClient().newBuilder().build();
        MediaType mediaType = MediaType.parse("text/csv");
        File file = new File("test5.csv");
        RequestBody body = RequestBody.create(mediaType, file);
        String urlUpload = rspData.getFileUploadInfo().getUploadUrl();
        Request request = new Request.Builder().url(urlUpload)
            .method("PUT", body)
            .addHeader("x-amz-content-sha256", rspData.getFileUploadInfo().getUploadHeaders().get(0).getValue())
            .addHeader("Authorization", rspData.getFileUploadInfo().getUploadHeaders().get(1).getValue())
            .addHeader("x-amz-date", rspData.getFileUploadInfo().getUploadHeaders().get(2).getValue())
            .addHeader("Content-Type", "text/csv")
            .build();
        Response response = client.newCall(request).execute();
        ResponseBody responseBody = response.body();
        String bodyStrRespon = "";
        BufferedSource source = responseBody.source();
        source.request(Long.MAX_VALUE);
        Buffer buffer = source.getBuffer();
        Charset charset = Charset.forName("UTF-8");
        MediaType contentType = responseBody.contentType();
        if (contentType != null) {
            try {
                charset = contentType.charset(charset);
            } catch (UnsupportedCharsetException e) {
                e.printStackTrace();
            }
        }
        bodyStrRespon = buffer.clone().readString(charset);
        System.out.println(bodyStrRespon);
    }
```
