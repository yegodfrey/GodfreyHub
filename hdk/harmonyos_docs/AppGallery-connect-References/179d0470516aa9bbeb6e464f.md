# AGCPhoneAuthProvider

|Class Info|
|:---------------------------------------------------------------------|
|手机凭证提供者。 Objective-C ``` @interface AGCPhoneAuthProvider: NSObject ```|

#### +credentialWithCountryCode:phoneNumber:password:

通过手机号和密码获取凭证。如果创建用户时设置了密码，可以采用手机号和密码登录。

<br />

Objective-C

```
+ (nonnull AGCAuthCredential *)credentialWithCountryCode:(nonnull NSString *)countryCode
                                             phoneNumber:(nonnull NSString *)phoneNumber
                                                password:(nonnull NSString *)password;
```

Swift

```
class func credential(withCountryCode countryCode: String, phoneNumber: String, password: String) -> AGCAuthCredential
```

<br />

Parameters  

|Name|Description|
|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|countryCode|国际电话区号，例如中国为86，德国49，俄罗斯7，新加坡65。 本字段支持多种格式（以中国为例）：86，+86。|
|phoneNumber|手机号码需要去掉"+"号 和国家（地区）码，例如：+86132xxxxxxxx，则取值132xxxxxxxx。|
|password|密码。 默认密码规则如下，若您参考[安全配置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-security-configuration-0000001324925609)自定义了密码复杂度请满足自定义的复杂度： 1. 密码长度至少8个字符； 2. 密码必须包含如下至少两种字符的组合： * 至少一个小写字母； * 至少一个大写字母； * 至少一个数字； * 至少一个特殊字符：\`!@#$%\^\&\*()-_=+\\\|\[{}\];:'",\<.\>/? 和空格。 3. 密码不能和手机号码或者邮箱一样。|

Return

手机凭证。  

#### +credentialWithCountryCode:phoneNumber:password:verifyCode:

通过手机号和验证码获取凭证。如果创建账户的时候没有设置过密码，则只能通过此接口进行登录，此时的password字段不赋值。

<br />

Objective-C

```
+ (nonnull AGCAuthCredential *)credentialWithCountryCode:(nonnull NSString *)countryCode
                                             phoneNumber:(nonnull NSString *)phoneNumber
                                                password:(nullable NSString *)password
                                              verifyCode:(nonnull NSString *)verifyCode;
```

Swift

```
class func credential(withCountryCode countryCode: String, phoneNumber: String, password: String?, verifyCode: String) -> AGCAuthCredential
```

<br />

Parameters  

|Name|Description|
|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|countryCode|国际电话区号，例如中国为86，德国49，俄罗斯7，新加坡65。 本字段支持多种格式（以中国为例）：86，+86。|
|phoneNumber|手机号码需要去掉"+"号 和国家（地区）码，例如：+86132xxxxxxxx，则取值132xxxxxxxx。|
|password|密码（可选）。如果携带了密码，则密码和验证码都会校验。 <br /> 默认密码规则如下，若您参考[安全配置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-security-configuration-0000001324925609)自定义了密码复杂度请满足自定义的复杂度： 1. 密码长度至少8个字符； 2. 密码必须包含如下至少两种字符的组合： * 至少一个小写字母； * 至少一个大写字母； * 至少一个数字； * 至少一个特殊字符：\`!@#$%\^\&\*()-_=+\\\|\[{}\];:'",\<.\>/? 和空格。 3. 密码不能和手机号码或者邮箱一样。|
|verifyCode|验证码，Link用户的时候必填。|

Return

手机凭证。  

#### +requestVerifyCodeWithCountryCode:phoneNumber:settings:

手机申请验证码。

Objective-C

```
+ (HMFTask<AGCVerifyCodeResult *> *)requestVerifyCodeWithCountryCode:(nonnull NSString *)countryCode
                                                         phoneNumber:(nonnull NSString *)phoneNumber
                                                            settings:(nonnull AGCVerifyCodeSettings *)settings;
```

Swift

```
class func requestVerifyCode(withCountryCode countryCode: String, phoneNumber: String, settings: AGCVerifyCodeSettings) -> Task<AGCVerifyCodeResult>!
```

<br />

Parameters  

|Name|Description|
|:----------|:-------------------------------------------------------|
|countryCode|国际电话区号，例如中国为86，德国49，俄罗斯7，新加坡65。 本字段支持多种格式（以中国为例）：86，+86。|
|phoneNumber|手机号码需要去掉"+"号 和国家（地区）码，例如：+86132xxxxxxxx，则取值132xxxxxxxx。|
|settings|验证码属性的配置，包括验证码应用场景（注册登录或者重置密码），发送验证码的语言，发送验证码的时间间隔。|

Return

申请验证码异步任务。
