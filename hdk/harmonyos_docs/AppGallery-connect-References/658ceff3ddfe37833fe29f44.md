# Cors

|Interface Info|
|:-------------------------------|
|export interface Cors 跨域配置的相关参数。|

#### Property Summary

|Name|Type|Mandatory/Optional|Description|
|:------------|:--------------|:-----------------|:-----------------------|
|origins|Array\<string\>|-|可跨域的源站地址信息。|
|methods|Array\<string\>|-|要求支持的可跨域的方法集合。|
|headers|Array\<string\>|Optional|要求支持的可跨域的头部集合。|
|maxAgeSeconds|number|Optional|跨域请求的响应可被缓存到客户端的时间，单位：秒。|
|exposeHeaders|Array\<string\>|Optional|跨域请求的响应的附加头部，不可出现空格。|
