# 创建统一链接

#### 功能介绍

此接口用于生成一个统一链接，仅支持通过三方联盟（玩咖）的白名单开发者申请，可实现在不同品牌手机获取到对应官方应用市场详情页的直接下载能力。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|合作平台服务器-\>应用市场服务器|
|接口URL|https://{domain}/api/spreadlink/v1/link-stamp/unified-link/create * 中国站点的domain：connect-api.cloud.huawei.com * 德国站点的domain：connect-api-dre.cloud.huawei.com * 新加坡站点的domain：connect-api-dra.cloud.huawei.com * 俄罗斯站点的domain：connect-api-drru.cloud.huawei.com|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### 请求参数

#### Header

|参数|必选(M)/可选(O)|类型|描述|
|:------------|:----------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|M|String|客户端ID，获取方法请参见[创建API客户端](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section103mcpsimp)。|
|Authorization|M|String|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)中获取的access_token。|

#### Body

|参数名称|必选(M)/可选(O)|类型|说明|
|:----------|:----------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
|packageName|M|String（256）|应用包名。|
|referrer|O|String(500)|归因参数，当您需要进行后续的归因分析时，可参考[高阶归因分析](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agdlink-analysis-refer-0000001117762116)。|
|devId|M|String(64)|开发者ID，仅在三方联盟白名单中的devId才能申请统一链接，否则返回失败。|
|ts|M|Int(64)|发送请求的UTC时间戳。|
|locale|O|String(2)|语言，若不传，默认zh_CN|
|iosLink|O|String(512)|ios链接|

#### 请求示例

```
POST https://connect-api.cloud.huawei.com/api/spreadlink/v1/link-stamp/unified-link/create
Content-Type: application/json
client_id: ***
Authorization: Bearer ***

{
  "packageName": "string",
  "referrer": "string",
  "devId": "string",
  "locale": "string",
  "iosLink": "string",
  "timestamp": 0
}
```

#### 响应参数

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:-------|:----------|:-----|:--------------|
|code|M|Int|返回码，例如：0|
|msg|O|String|返回描述，例如：success|
|deepLink|O|String|应用详情页deeplink地址|
|httpLink|O|String|应用详情页H5地址|

#### 返回码

|返回码|返回码信息|说明|
|:-----|:--------------------------|:----------|
|999102|create permission deny|权限问题返回失败|
|999207|Stamp link is being created|图章创建中返回失败|
|999200|Stamp link already exist|图章重复创建返回成功|
|999004|app not existed error|媒体信息不存在返回失败|
|999003|Query app zone error|媒体区域权限返回失败|
