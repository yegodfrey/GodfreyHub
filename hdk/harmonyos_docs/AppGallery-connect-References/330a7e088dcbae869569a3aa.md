# 错误码

#### FunctionErrorCode

|错误码|值|描述|解决方法|
|:-----------------------------------------|:----|:-----------------|:------------------------------------|
|FunctionErrorCode.GET_CREDENTIAL_NULL|12000|获取credential信息失败。|请使用有效的认证凭据。|
|FunctionErrorCode.GET_GW_URL_FAIL|12001|获取请求网关url头部域名失败|请使用有效的认证凭据，并检查网络情况。|
|FunctionErrorCode.GET_ACCESS_TOKEN_FAIL|12002|获取accessToken信息失败。|请使用有效的认证凭据，并检查网络情况。|
|FunctionErrorCode.CALL_CLOUD_FUNCTION_FAIL|12003|call方法调用失败。|请检查请求或返回情况。|
|FunctionErrorCode.TIMEOUT_OUT_OF_RANGE|12004|输入数值超出限定范围。|超时时长取值范围(0, 55000\]，单位为ms。请使用合规的参数内容。|
