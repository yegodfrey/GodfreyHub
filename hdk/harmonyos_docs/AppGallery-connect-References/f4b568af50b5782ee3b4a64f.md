#### Methods

#### createBucket

|Method|
|:---------------------------------------------------------------------------------------------------|
|public static Bucket createBucket(String bucketName) throws StorageException 在开通项目时选定的默认存储区域下创建存储实例。|

Parameters  

|Name|Description|
|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
|bucketName|存储实例名称。 说明： 存储实例名称限制如下： * 存储实例名称只能包含英文小写字母、数字、"-" * 存储实例名称只能以数字或字母开头。 * 存储实例名称长度要求不少于3个字符，且不能超过57个字符。 * 存储实例名称不能是IP地址。 * 存储实例名称不能以"-"结尾。 * 存储实例名称全局唯一，创建后，不能修改。|

Return  

|Type|Description|
|:-----|:----------|
|Bucket|返回存储实例。|
