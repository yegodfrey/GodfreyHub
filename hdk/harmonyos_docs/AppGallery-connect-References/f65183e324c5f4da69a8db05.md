# NetworkMeasure

|Class Info|
|:---------------------------------------------------------------------------|
|public class NetworkMeasure 网络请求指标， 用于监控网络请求性能。对于每次请求/响应，都需要创建新实例。该类是线程非安全的。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:--------------------|:-----------------------------------------------------------------------------------------------|
|void|[start](#section820mcpsimp)() 设置请求开始时间。|
|void|[stop](#section823mcpsimp)() 设置请求结束时间，并上报网络请求指标及自定义属性数据。|
|void|[setStatusCode](#section826mcpsimp)(int statusCode) 设置请求的响应码。|
|void|[setBytesSent](#section846mcpsimp)(long bytesSent) 设置请求体大小。|
|void|[setBytesReceived](#section866mcpsimp)(long bytesReceived) 设置响应体大小。|
|void|[setContentType](#section886mcpsimp)(String contentType) 设置响应体contentType类型。|
|void|[putProperty](#section906mcpsimp)(String propertyName, String propertyValue) 设置网络请求的自定义属性名称和属性值。|
|void|[removeProperty](#section931mcpsimp)(String propertyName) 从NetworkMeasure实例中移除已存在属性。|
|Map\<String, String\>|[getProperties](#section951mcpsimp)() 从NetworkMeasure实例中获取所有属性。|
|String|[getProperty](#section971mcpsimp)(String propertyName) 获取自定义属性值。|

|:---------------------------------------------------------------------------------------------------------------------|

|propertyValue|自定义属性值，只能由中文、字母（不区分大小写）、数字和下划线组成，且长度不能超过100字符。|
