# UpdateGroupConfig

|Interface Info|
|:-------------------------------------------|
|export interface UpdateGroupConfig 更新队伍信息参数。|

#### Property Summary

|Name|Type|Mandatory/Optional|Description|
|:--------------------|:-----|:-----------------|:-----------------------|
|groupName|string|Optional|新的队伍名称。|
|ownerId|string|Optional|新的队长ID。|
|customGroupProperties|string|Optional|自定义队伍属性，最大支持2048个字符。|
|isLock|number|Optional|队伍是否禁止加入。 * 0：不禁止 * 1：禁止|
