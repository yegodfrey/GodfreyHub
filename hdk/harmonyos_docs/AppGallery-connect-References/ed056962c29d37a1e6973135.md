# FileInfo

|**属性**|**类型**|必选(M)/可选(O)|**说明**|
|:-----------------|:-----------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|name|String|M|文件名称。|
|bucket|String|M|存储实例名称。|
|storageArea|String|M|存储区域名称。|
|storageRegion|String|M|后端OBS存储站点。|
|storageType|String|M|存储类型。|
|contentType|String|M|文件类型。Content-Type标头告诉客户端实际返回的内容类型。|
|contentDisposition|String|O|文件打开方式，响应头指示回复的内容该以何种形式展示，是以内联的形式（即网页的一部分），还是以附件的形式下载并保存到本地。|
|cacheControl|String|O|标准HTTP请求头字段Cache-Control。 * public：文件可缓存到任何位置。 * private：文件可以缓存到请求者的本地缓存中。 * no-cache：文件可以缓存，但有请求发出时，缓存会将此请求发到服务器，服务器验证请求中所描述的缓存是否过期，若未过期，返回304，缓存可使用，否则不可使用。 * no-store：缓存中不得存储任何关于客户端请求和服务端响应的内容。 * max-age=TIME_IN_SECONDS：文件可缓存的时长。|
|contentEncoding|String|O|标准HTTP请求头Content-Encoding，是一个实体消息首部，用于对特定媒体类型的数据进行压缩。当这个首部出现的时候，它的值表示消息主体进行了何种方式的内容编码转换。|
|contentLanguage|String|O|标准HTTP请求头 Content-Language，用来说明访问者希望采用的语言或语言组合，这样的话用户就可以根据自己偏好的语言来定制不同的内容。|
|sha256|String|O|文件SHA256值。|
|size|long|M|文件大小。|
|createTime|String|M|上传时间，时间日期格式:yyyy-MM-ddTHH:mm:ssZ。|
|updateTime|String|M|更新时间，时间日期格式:yyyy-MM-ddTHH:mm:ssZ。|
|metadata|Map<String,String>|O|元数据，用户自定义元数据。|
