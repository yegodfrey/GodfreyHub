# SetRtmChannelPlayerPropertiesReq

|Interface Info|
|:---------------------------------------------------------------------|
|export interface SetRtmChannelPlayerPropertiesReq 设置RTM频道内玩家自定义属性请求对象。|

#### Property Summary

|Name|Type|Mandatory/Optional|Description|
|:---------------|:----------------------|:-----------------|:----------------------------------------------|
|channelId|string|Mandatory|频道ID，仅支持数字(0-9)和字母 (A-Z,a-z)。|
|playerProperties|{\[k: string\]: string}|Mandatory|玩家自定义属性。属性Key最长100个字节，属性value最长1948个字节。最多可设置5组。|
