# 获取下载安装的报表

## 功能介绍

获取下载安装的报表数据的CSV或者Excel文件地址。接口调用者的角色：账号持有者、管理员、App管理员、运营。

## 接口原型

|承载协议|HTTPS GET|
|-----|-----------------------------------------------------------------------------------------------------------|
|接口方向|开发者服务器 -> 华为服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/report/distribution-operation-quality/v1/appDownloadExport/{appId}|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 请求参数

### Header

> 说明
>
> 本接口支持使用Service Account方式、API客户端方式和OAuth客户端方式，区别请参见[使用入门](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114)。

**Service Account** **方式：**

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Authorization|M|String|认证信息，格式为"Authorization: Bearer *${JWT}* "。JWT为[通过Service Account方式获取授权](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section1785535363715)中获取的鉴权令牌。|

**API客户端方式：**

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|M|String|客户端ID，获取方法参考[创建API客户端](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section103mcpsimp)。|
|Authorization|M|String|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)中获取的access_token。|

**OAuth客户端方式：**

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
|teamId|M|String|开发者所在团队的团队ID，可通过[获取团队列表](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-getteamlist-0000001158245075)接口获取。|
|oauth2Token|M|String|认证信息，传入[获取用户授权码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section949717114392)中获取的Access Token。|

### Path

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----|:----------|:-----|:--------------------------------------------------------------------------------------------------------------------|
|appId|M|String|应用ID，获取方法参考[查询应用信息](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-appinfo-0000001100014694)。|

### Query

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:-------------------|:----------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|language|M|String|查询语言，报表title会根据不同语言来展现，只支持简体中文（zh-CN），美式英文（en-US），俄文（ru-RU）。|
|startTime|M|String|查询开始时间，UTC时间，格式为YYYYMMDD。startTime和endTime之间不超过180天。|
|endTime|M|String|查询结束时间，UTC时间，格式为YYYYMMDD。startTime和endTime之间不超过180天。|
|filterCondition|O|List<String>|过滤器。 取值范围： * countryId：按国家过滤。 * businessType：按业务类型过滤。 * appVersion：按应用版本过滤。 如果不传，默认无过滤器。 支持countryId、businessType和appVersion同时使用，URL示例：&filterCondition=countryId&filterCondition=businessType&filterCondition=appVersion|
|filterConditionValue|O|List<String>|过滤器对应的值。 * 如果过滤器为countryId，此参数的取值为国家码的字符串数组，例如"CN, AL, AD, AT"。具体国家码列表参考[国家码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-reference-countrycode-0000001111845110)。传入"all"表示查询全球。传入"others"表示仅查询"US,CU,IR,SD,SY"（美国,古巴,伊朗,苏丹,叙利亚），获取的数据作为一个整体展示，例如"CN,AL,others"。"all"和"others"不区分大小写。 * 如果过滤器为businessType，此参数的取值为业务类型，取值范围为： * ALL：所有业务 * AppGallery：华为应用市场 * AppTouch：AppTouch业务 取值区分大小写。 * 如果过滤器为appVersion，此参数的取值为应用版本，多个版本以英文逗号分隔，如："1.0.0,2.0.0"。"all"表示查询所有应用版本，"all"不区分大小写。 如果传入多个过滤器，使用多个filterConditionValue表示，顺序必须与filterCondition中过滤器的顺序一致。URL示例：&filterConditionValue=CN&filterConditionValue=AppGallery。|
|groupBy|O|String|数据统计的分组信息，支持按如下依据分组。 取值范围： * date：按日期分组 * countryId：按国家分组 * businessType：按业务类型分组 * appVersion：按应用版本分组 默认值：date|
|exportType|O|String|导出文件类型。 取值范围： * CSV：导出CSV文件格式 * EXCEL：导出Excel文件格式 默认值：CSV|

## 响应参数

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:-------|:----------|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|fileURL|M|String|导出CSV或Excel文件的路径。 报表文件中字段语言由language参数指定，首个字段为groupBy参数中指定的数据统计分组类型。以报表字段为英文为例，您可以点击[文件样例.zip](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260310180804.30863952182041235722116855096702:50001231000000:2800:FEBAF7984E4CC842CC7E79142C3251EA94E4CFD275C1AF4D951F7E3CD2121253.zip?needInitFileName=true)下载样例文件。 文件中包含的字段说明请参见[下载安装报表数据说明](#ZH-CN_TOPIC_0000001158365059__p11623192525520)。|
|packName|M|String|应用包名。|
|ret|M|String|包含返回码及描述信息的JSON字符串，格式为{"code":*retcode* , "msg": "*description*"}，retcode为返回码，description为返回码描述信息。|

**下载安装报表数据说明**

|字段名（中文）|字段名（英文）|字段名（俄语）|字段含义|
|:------|:--------------------------|:-----------------------------------------|:----------------------------------------------------------|
|日期|Time|Время|数据统计按时间进行分组。 > 注意 > 只有当请求参数groupBy传入date时才会返回此字段。|
|国家/地区|Country/Region|Страна/регион|数据统计按国家或地区进行分组。 > 注意 > 只有当请求参数groupBy传入countryId时才会返回此字段。|
|业务类型|Channel|Канал|数据统计按业务类型进行分组。 > 注意 > 只有当请求参数groupBy传入businessType时才会返回此字段。|
|应用版本|App version|Версия приложения|数据统计按应用版本进行分组。 > 注意 > 只有当请求参数groupBy传入appVersion时才会返回此字段。|
|曝光|Impressions|Впечатления|应用在AppGallery推荐、排行榜、搜索等资源位被展示次数。|
|详情页查看|App details page views|Просмотры страницы сведений приложения|详情页被浏览的次数。|
|总下载成功|Total downloads|Общее количество загрузок|更新下载成功+新下载成功。|
|更新下载成功|Update downloads|Загрузки обновлений|用户通过华为应用市场更新应用版本产生的下载成功量。|
|新下载成功|New downloads|Новые загрузки|用户通过华为应用市场新增应用版本产生的下载成功量。|
|卸载数|Uninstalls|Удаления|应用安装后的卸载量。|
|曝光点击率|CTR|CTR|(详情页查看次数+快捷下载成功次数) / 曝光次数。|
|详情页转化率|CVR of app details page|CVR страницы сведений приложения|详情页带来的新下载成功量/详情页查看量。|
|安装成功率|Installs to downloads ratio|Отношение количества установок к загрузкам|应用下载成功后安装成功的比率。|
