# OnTokenListener

Token变化监听接口。  

#### Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-------------------------------------------------------------------------------|
|void|[onChanged](#section060516371695)(tokenSnapshot: TokenSnapshot) 监听Token变化时回调此方法。|

#### Methods

#### onChanged

|Method|
|:------------------------------------------------------------|
|onChanged(tokenSnapshot: TokenSnapshot):void 监听Token变化时回调此方法。|

Parameters  

|Name|Description|
|:------------|:----------|
|tokenSnapshot|当前Token快照。|

Sample Code

```
let listener = {
  onChanged:(tokenSnapshot)=>{
    // tokenSnapshot为包含getState和getToken方法的对象
    let state = tokenSnapshot.getState();
    let token = tokenSnapshot.getToken();
  }
};
// 登录场景
agconnect.auth().addTokenListener(listener);
```
