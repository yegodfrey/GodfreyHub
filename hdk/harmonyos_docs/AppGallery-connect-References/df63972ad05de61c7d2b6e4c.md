#### serverStatusQuery

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|serverStatusQuery(): Promise\<ServerStatus\> 调用此方法从云数据库中查询当前服务器的状态，并将查询到的服务器状态封装到一个[ServerStatus](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-serverstatus-server-nodejs-0000001766592781)中。当前ServerStatus中包含服务器的时间戳状态。|

Return  

|Type|Description|
|:----------------------|:-------------------------------------------------------|
|Promise\<ServerStatus\>|Promise对象。通过此Promise对象可以异步获取操作结果，查询成功返回服务器的状态，失败则返回异常信息。|
