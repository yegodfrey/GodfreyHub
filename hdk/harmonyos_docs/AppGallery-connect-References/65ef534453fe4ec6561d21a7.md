# RtmMessageNotify

|Class Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class RtmMessageNotify : [RtmMessageContent](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/rtmmessagecontent-csharp-0000001769587301) RTM消息通知。|

## Property Summary

|Name|Type|Description|
|:------------|:-----|:---------------------------------------------------------------|
|ServerMsgId|string|全局发送消息唯一标识。|
|ClientMsgId|string|客户端发送消息唯一标识。|
|Timestamp|long|消息发送时间戳，即距离1970年1月1日0点的毫秒数。|
|SenderId|string|* 消息来自客户端接口发送时，则senderId为消息发送者的玩家ID。 * 消息来自服务端接口发送时，则senderId为空。|
|FromOpenApi|bool|是否来自服务端接口发送。 * true：来自服务端接口发送 * false：来自客户端接口发送|
|MessageType|int|消息类型。 * 1：文本 * 2：二进制|
|MessageString|string|文本消息内容。|
|MessageBytes|byte[]|二进制消息内容。|
