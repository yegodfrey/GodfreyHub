# CustomTrace

|Class Info|
|:--------------------------------------------------------|
|public class CustomTrace 自定义跟踪记录，用于监控应用在特定场景，如用户登录场景下的性能。|

#### putProperty

|Method|
|:------------------------------------------------------------------------------------------------------------------|
|public void putProperty(String propertyName, String propertyValue) 设置自定义跟踪记录属性名称和属性值。每个CustomTrace实例最多只能设置5个自定义属性 。|

Parameters  

|Name|Description|
|:------------|:--------------------------------------------|
|propertyName|自定义属性名称，只能由中文、字母（不区分大小写）、数字和下划线组成，且长度不超过40字符。|
|propertyValue|自定义属性值，只能由中文、字母（不区分大小写）、数字和下划线组成，且长度不超过100字符。|
