# Overview

> 说明
>
> 所有类和接口仅适用于API 9及以下版本。

开发者与HMS Core进行交互，Tasks异步函数为开发者提供了同步和异步的接口调用方法。

## Interface Summary

|Interface|Description|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:------------------------|
|[Continuation](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-continuation-harmonyos-0000001207958453)|在一个任务执行完成后，继续执行该接口中包含的函数。|
|[ExecuteResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-executeresult-harmonyos-0000001162278482)|任务执行结果。|
|[OnCanceledListener](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-oncanceledlistener-harmonyos-0000001207718435)|任务被取消时调用此监听器。|
|[OnHarmonyCompleteListener](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-onharmonycompletelistener-0000001162438436)|任务完成时调用此监听器。|
|[OnFailureListener](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-onfailurelistener-harmonyos-0000001162119958)|任务执行失败时调用此监听器。|
|[OnSuccessListener](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-onsuccesslistener-harmonyos-0000001207839913)|当任务成功完成时调用此监听器。|
|[SuccessContinuation<TResult, TContinuationResult>](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-successcontinuation-harmonyos-0000001161959956)|在任务执行完成后继续执行该函数。|
