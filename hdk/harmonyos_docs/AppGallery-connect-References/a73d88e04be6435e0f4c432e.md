# FFPerFrameData

指定的预测算法所需的每帧数据。

**Structure Declaration**

```screen
typedef struct FFPerFrameData {
    FFStructureType sType;
    const void* pNext;
    FFPerFrameDataFlags flags;
    uint32_t sceneColor;
    uint32_t depthStencil;
    FFMat4x4 viewProj;
    FFMat4x4 invViewProj;
} FFPerFrameData;
```

**Members**

|Name|Mandatory/Optional|Description|
|:-----------|:-----------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|sType|Mandatory|此结构体类型必须为**FF_STRUCTURE_TYPE_PER_FRAME_DATA_3**。|
|pNext|Optional|指向扩展链中的下一个结构体的指针。扩展参数，可缺省，默认值为NULL。|
|flags|Mandatory|当前数据类型的位掩码，具体请参见[FFPerFrameDataFlagBits](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffperframedataflagbits-0000001791494368)。如果传入多个，则必须使用丨分开，例如，**FF_PER_FRAME_DATA_SCENE_COLOR_BIT 丨 FF_PER_FRAME_DATA_DEPTH_BIT**|
|sceneColor|Mandatory|带有场景颜色信息的纹理ID。纹理格式必须为RGBA8。|
|depthStencil|Mandatory|带有场景深度或模板信息的纹理ID。|
|viewProj|Mandatory|相机投影矩阵，对应于从世界空间坐标（World Space Coordinates）到剪辑空间坐标（Clip Space Coordinates）的转换。|
|invViewProj|Mandatory|相机投影矩阵的逆矩阵，对应于从剪辑空间坐标（Clip Space Coordinates）到世界空间坐标（World Space Coordinates）的转换。|
