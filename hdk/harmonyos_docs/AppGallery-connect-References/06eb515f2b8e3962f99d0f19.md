# 更新商品信息

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250806180212.98063572740271476848064426381833:50001231000000:2800:FD96A86F979A895A3419F690730E2CE2F44989EB45C410C353258CCFED547662.png)  
如果您前期已使用该接口为您的HarmonyOS 5.0及以上应用接入商品管理，请尽快切换至[HarmonyOS 5.0及以上 V2版本接口](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-updateproduct-harmonyosnext-0000002166670141)。  

#### 功能介绍

此接口用于更新商品定义信息，包含商品价格，展示语言和商品状态。  

#### 使用约束

接口调用者的角色：账号持有者、管理员、APP管理员、运营。  

#### 接口原型

|承载协议|HTTPS PUT|
|接口方向|开发者服务器-\>数字商品服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/pms/product-price-service/v1/manage/product|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|------------------------------------------------------------------------------------|

#### Header

#### 调用示例

```
"Java"
public static ProductUpdateResp updateProductInfo(String domain, String clientId, String authorization,
    String appId, ProductUpdateReq request) {
    String url = domain + "/api/pms/product-price-service/v1/manage/product";
    HttpPut put = new HttpPut(url);
    setHttpHead(clientId, authorization, appId, put);
    StringEntity entity =
        new StringEntity(JSON.toJSONString(request), ContentType.create("application/json", "UTF-8"));
    put.setEntity(entity);
    String result = getApiResp(put);
    if (StringUtils.isNotEmpty(result)) {
        return JSON.parseObject(result, ProductUpdateResp.class);
    }
    return null;
}
```
