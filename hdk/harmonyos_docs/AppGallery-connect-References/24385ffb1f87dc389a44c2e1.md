# ohAegAesCbcDec

ohAegAesCbcDec(text: Uint8Array, key: Uint8Array): Promise<Uint8Array>

AES-CBC解密算法，配套[ohAegAesCbcEnc](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ohaegaescbcenc-0000001910092457)接口使用，分组模式、填充模式如下：

|分组模式|密钥长度（bit）|填充模式|API版本|
|:---|:----------|:----|:----|
|CBC|128|192|256|PKCS7|11+|

**导入模块：**

```typescript
import { AegAesCbc } from '@hw-agconnect/petal-aegis';
```

**参数** **：**

|参数名|类型|必填|说明|
|:---|:---------|:-|:----------------------------------------------------------|
|text|Uint8Array|是|待解密内容（使用ohAegAesCbcEnc加密的结果），格式为**iv:密文**或者同类的Uint8Array格式。|
|key|Uint8Array|是|明文工作密钥。|

**返回值：**

|参数|类型|说明|
|:----------|:---------|:--------------------|
|decryptText|Uint8Array|明文普通字符串的Uint8Array格式。|

**示例：**

```typescript
import { AegAesCbc } from '@hw-agconnect/petal-aegis';
import { buffer } from '@kit.ArkTS';

async function aescbc3() {
  let plainText = 'hello world'; //待加密内容
  let key = '1234567891234567'; //长度16字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let iv = '9876543217654321'; //长度16字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let inputUint8 = new Uint8Array(buffer.from(plainText, 'utf-8').buffer);
  let keyUint8 = new Uint8Array(buffer.from(key, 'utf-8').buffer);
  let ivUint8 = new Uint8Array(buffer.from(iv, 'utf-8').buffer);

  try {
    let encryptText = await AegAesCbc.ohAegAesCbcEnc(inputUint8, keyUint8, ivUint8);
    //aescbc3  encryptText: 57,56,55,54,53,52,51,50,49,55,54,53,52,51,50,49,58,133,226,121,40,63,164,152,8,118,113,218,94,73,63,83,218
    console.log("aescbc3 ", 'encryptText: ' + encryptText);

    let decryptText = await AegAesCbc.ohAegAesCbcDec(encryptText, keyUint8);
    if (plainText === uint8ArrayToString(decryptText)) {
      console.info('aescbc3 decrypt ok');
    }
    console.log("aescbc3 ", 'decryptText: ' + uint8ArrayToString(decryptText));
  } catch (err) {
    console.log("aescbc3 ", 'err: ' + err);
  }
}
function uint8ArrayToString(data: Uint8Array) {
  let dataString = '';
  for (let i = 0; i < data.length; i++) {
    dataString += String.fromCharCode(data[i]);
  }
  return dataString;
}
```
