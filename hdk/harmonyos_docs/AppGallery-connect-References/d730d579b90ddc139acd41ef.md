# 通知资源包更新状态

## 功能介绍

游戏客户端在游戏资源包更新成功后，需要调用此接口向华为应用市场客户端提交游戏资源包的更新状态，同时会删除华为应用市场客户端为游戏客户端成功下载的游戏资源包。调用时华为应用市场客户端会校验调用方App的签名值，如果签名校验不通过则直接返回失败。

## 接口原型

|承载协议|ContentProvider，即Android应用程序之间进行数据交换的标准API。|
|----|---------------------------------------------------------------------------------------------|
|接口方向|游戏客户端->华为应用市场客户端|
|请求方式|context.getContentResolver.acquireUnstableContentProviderClient(uri).call(method,arg,extras);|

## 请求参数

|参数名|必选(M)/可选(O)|类型|说明|
|:-----|:----------|:-----|:----------------------------------------------------------------------------------------|
|uri|M|Uri|ContentProvider的请求URL，要求取值为Uri.parse("content://com.huawei.appgallery.game.CONTENT_URI")。|
|method|M|String|华为应用市场定义的请求方法名，方法名为"submitUpdateResult"。|
|arg|M|String|华为应用市场暂未使用，取值为""。|
|extras|M|Bundle|存储"result"数据，即更新游戏资源包的状态，有如下两种状态： * 0：成功。 * 1：失败。|

## 响应参数

|参数|必选(M)/可选(O)|类型|说明|
|:---------|:----------|:------|:--------------------|
|returnCode|M|Integer|提交结果。 * 0：成功。 * 1：失败。|

## 示例代码

```screen
    /**
     * provider URI
     */
    private static final String PROVIDER_URI = "content://com.huawei.appgallery.game.CONTENT_URI";

    /**
     * provider接口返回码
     */
    private static final String PROVIDER_RETURN_CODE = "returnCode";

    /**
     * 更新资源包下载状态
     * 调用时机：资源包全部下载并校验完，游戏客户端进行游戏资源包的更新完毕后调用
     *
     * @param submitResult 游戏资源包的更新状态
     */
    private void submitUpdateResult(String submitResult) {
        try {
            ContentProviderClient contentProviderClient =
                    this.getApplicationContext().getContentResolver().acquireUnstableContentProviderClient(Uri.parse(PROVIDER_URI));
            Bundle param = new Bundle();
            param.putInt("result", Integer.parseInt(submitResult));
            Bundle result =
                    contentProviderClient.call("submitUpdateResult", "", param);
            if (result != null && result.getInt(PROVIDER_RETURN_CODE) == 0) {
                Log.d(TAG, "submitUpdateResult success!");
            } else {
                Log.e(TAG, "submitUpdateResult failed!");
            }
        } catch (IllegalArgumentException e) {
            Log.e(TAG, "submitUpdateResult IllegalArgumentException");
        } catch (Exception e) {
            Log.e(TAG, "submitUpdateResult Exception");
        }
    }

```
