# EntityCreatedEvent

|Class/Struct Info|
|:-----------------------------------------------------------------------|
|public readonly struct EntityCreatedEvent : IEvent 实体创建事件结构体，当新实体被创建时触发。|

## Property Summary

|Name|Type|Description|
|:-------------|:--------|:-----------------|
|ParentEntityId|int|父实体ID。 其中-1表示无父实体。|
|Entity|IEntity|实体引用。|
|EcsWorld|IECSWorld|ECSWorld引用。|

**Sample Code**

```screen
// 定义实体创建事件处理器，可访问事件字段和属性
Action<EntityCreatedEvent> entityCreated = (evt) =>
{
    var parentId = evt.ParentEntityId;
    var entity = evt.Entity;
    var world = evt.EcsWorld;
};
```
