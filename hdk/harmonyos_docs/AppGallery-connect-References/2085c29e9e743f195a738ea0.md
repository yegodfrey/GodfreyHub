# AGConnectAppMessagingCallback

|Interface Info|
|:------------------------------------------------------------------------------------------|
|public interface AGConnectAppMessagingCallback 消息处理回调类，开发者如果需要实现自定义的显示界面，必须在消息相关事件触发时回调该接口。|

## Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:------------------------------------------------------------------------------------------------------------------------------------------------|
|void|[onMessageClick](#section191549530237)(@NonNull AppMessage appMessage, @NonNull Action action) 消息被点击时回调。|
|void|[onMessageDismiss](#section681112342412)(@NonNull AppMessage appMessage, @NonNull AGConnectAppMessagingCallback.DismissType dismissType) 消息消失时回调。|
|void|[onMessageDisplay](#section10243343172413)(@NonNull AppMessage appMessage) 消息展示时回调。自定义消息显示界面时该方法必须回调，否则无法确定消息是否真实显示，导致消息会重复显示。|
|void|[onMessageError](#section1451518210257)(@NonNull AppMessage appMessage) 消息图片加载异常时回调。|
