# VerifyCodeParam

获取验证码的相关参数类。  

#### Parameters

|Name|Type|Description|
|:-------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------|
|verifyCodeType|[PhoneVerifyCode](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-arkts-phoneverifycode-0000001680659957) \| [EmailVerifyCode](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-arkts-emailverifycode-0000001631740596)|编译器会根据其中kind自动推断类型，例如其内部kind填为：'phone'，则类型被推断为"PhoneVerifyCode"。|
|action|[VerifyCodeAction](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-arkts-verifycodeaction-0000001632354970)|验证码动作类型。|
|lang|string|验证码文字语言，例如中文："zh_CN"。|
|sendInterval|number|可选，验证码超时时间，默认为60s。|
