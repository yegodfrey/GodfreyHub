# AGCTwitterAuthParam

|Class Info|
|:-------------------------------------------------------------------------------------|
|Twitter OAuth 2.0 认证参数对象。 Objective-C ``` @interface AGCTwitterAuthParam: NSObject ```|

#### -initWithClientId:authCode:codeVerifier:redirectUrl

登录凭证构造器。

Objective-C

```
- (instancetype)initWithClientId:(NSString *)clientId authCode:(NSString *)authCode codeVerifier:(NSString *)codeVerifier redirectUrl:(NSString *)redirectUrl;
```

Swift

```
init(clientId: String?, authCode: String?, codeVerifier: String?, redirectUrl: String?) {}
```

<br />

Parameters  

|Name|Description|
|:-----------|:--------------------------------------|
|clientId|由 Twitter 授权后获得的 clientId。|
|authCode|从 Twitter 平台后获得的 authCode。|
|codeVerifier|请求Twitter OAuth 2.0授权接口传入的codeVerifier。|
|redirectUrl|重定向地址。|

Return

用于登录的参数对象。
