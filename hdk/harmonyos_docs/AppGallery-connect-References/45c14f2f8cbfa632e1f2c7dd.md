# ohAegHexStringToUint8Array

ohAegHexStringToUint8Array(input: string): Uint8Array

16进制的hex string字符串转换为Uint8Array格式。

**导入模块** **：**

```typescript
import { AegStrUtil } from '@hw-agconnect/petal-aegis';
```

**参数：**

|参数名|类型|必填|说明|
|:----|:-----|:-|:----------------------|
|input|string|是|待转换的16进制的hex string字符串。|

**返回值：**

|参数|类型|说明|
|:---|:---------|:-----------------|
|字节数组|Uint8Array|转换后的Uint8Array字符串。|

**示例：**

```screen
import { AegStrUtil } from '@hw-agconnect/petal-aegis';

function hexStringToUint8Array() {
  let strUtil: AegStrUtil = new AegStrUtil()
  let input = '68656c6c6f20776f726c64'
  let result = strUtil.ohAegHexStringToUint8Array(input)
  //hexStringToUint8Array  result: 104,101,108,108,111,32,119,111,114,108,100
  console.log("hexStringToUint8Array ", 'result: ' + result);
}
```
