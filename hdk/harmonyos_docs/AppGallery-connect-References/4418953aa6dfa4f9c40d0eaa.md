# FeatureInstallSessionStatus

|Class Info|
|:--------------------------------------------------------------------------------|
|public class FeatureInstallSessionStatus extends Object 在执行动态加载任务过程中，表示各个状态的状态码类。|

#### Field Summary

|Type|Name|Value|Description|
|:---|:-------------------------|:----|:---------------|
|int|UNKNOWN|0|未知状态。|
|int|PENDING|1|该下载正在等待中，并将很快处理。|
|int|DOWNLOADING|2|正在下载。|
|int|DOWNLOADED|3|已下载但尚未安装。|
|int|INSTALLING|4|正在安装。|
|int|INSTALLED|5|已安装。|
|int|FAILED|6|安装失败。|
|int|CANCELED|7|取消安装。|
|int|REQUIRES_USER_CONFIRMATION|8|下载需要用户确认。|
|int|CANCELING|9|正在取消。|
|int|REQUIRES_PERSON_AGREEMENT|10|下载需要签署用户协议。|
