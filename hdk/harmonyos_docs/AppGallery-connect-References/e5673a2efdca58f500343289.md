# AGCCloudDBQueryPolicy

```screen
NS_ENUM (NSInteger, AGCCloudDBQueryPolicy) {}
```

查询策略。

## AGCCloudDBQueryPolicyLocal

从本地缓存查询数据。

**OBJECTIVE-C**

```screen
AGCCloudDBQueryPolicyLocal = 1
```

## AGCCloudDBQueryPolicyCloud

从云侧存储区查询数据。

**OBJECTIVE-C**

```screen
AGCCloudDBQueryPolicyCloud = 2
```

## AGCCloudDBQueryPolicyDefault

从云侧存储区和本地缓存查询数据。

* 当设备离线时，从本地缓存查询数据。
* 当设备在线时，从云侧存储区和本地缓存查询数据。

**OBJECTIVE-C**

```screen
AGCCloudDBQueryPolicyDefault = 3
```
