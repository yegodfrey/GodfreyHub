# BrowsersCond

|参数|必选(M)/可选(O)|类型|描述|
|:---------|:----------|:-----|:------------------------------------------------------------------------------------------------------|
|systemName|O|String|浏览器名称。|
|operator|M|String|操作符。取值为： * LESS_THAN：\< * EQUAL：= * LESS_EQUAL：\<= * NOT_EQUAL：!= * GREATER_THAN：\>= * GREATER_EQUAL：\>|
|value|O|String|浏览器的版本号，最大长度32。|
