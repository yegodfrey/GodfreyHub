# ohAegGenEccKeyPairBase64

ohAegGenEccKeyPairBase64(): Promise<EccKeyPair>

生成Base64编码格式的ECC256公私钥对，可用于ECDSA签名和ECDH密钥协商。

**参数：**

无

**返回值：**

|参数|类型|说明|
|:-----------|:---------|:-------------------------------------------------------------------|
|EccKeyPair对象|EccKeyPair|EccKeyPair.publicKey 公钥，base64编码, EccKeyPair.privateKey 私钥, base64编码|

**导入模块** **：**

```typescript
import { AegEcc } from '@hw-agconnect/petal-aegis';
```

**示例：**

```typescript
import { AegEcc } from '@hw-agconnect/petal-aegis';

function genearateEccKey() {
  AegEcc.ohAegGenEccKeyPairBase64().then((data) => {
    console.log("genearateEccKey", 'publicKey: ' + data.publicKey);
    console.log("genearateEccKey", 'privateKey: ' + data.privateKey);
  }).catch((err) => {
    console.log("genearateEccKey error : ", err);
  })
}
```
