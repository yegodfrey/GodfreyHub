# FunctionParams

|Interface Info|
|:---------------------------------------|
|export interface FunctionParams 函数相关参数类。|

#### Public Field Summary

|Name|Type|Description|
|:------|:-----|:----------------------------------------|
|name|string|必填，函数名称。|
|version|string|可选，函数版本，默认值为"$latest"。|
|timeout|number|可选，函数运行超时时长，单位为ms，范围(0,55000\]，默认值为55000。|
|data|any|可选，函数请求体。|
