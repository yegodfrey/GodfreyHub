# Overview

#### Class/Struct Summary

|Class/Struct|Description|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------|
|[ComponentLookup\<TLookupComponent, TValue\>](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/lookup-componentlookup-0000002476912557)|索引ILookup\<T\>组件的结构体。|
|[LinkComponentLookup\<TLinkComponent\>](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/lookup-linkcomponentlookup-0000002476832801)|索引ILinkComponent组件的结构体。|
|[LookupExtensions](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/lookup-lookupextensions-0000002443392810)|提供查询所有或特定组件值的扩展方法的静态类。|

#### Interface Summary

|Interface|Description|
|:-----------------------------------------------------------------------------------------------------------------------------|:-------------------------------|
|[ILookup\<out T\>](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/lookup-ilookup-0000002476938313)|定义Lookup组件的接口。|
|ILinkComponent|定义链接组件的接口，继承了ILookup\<IEntity\>。|

Sample Code

```
// 定义链接组件
public struct AttackComponent : ILinkComponent {
    public IEntity target;
    public int data;
    public IEntity GetLookup() => target;
    public override string ToString() => target.ToString();
}
// 定义Lookup组件
public struct LookupName : ILookup<string> {
    public string name;
    public string GetLookup() => name;
    public override string ToString() => name;
}
```
