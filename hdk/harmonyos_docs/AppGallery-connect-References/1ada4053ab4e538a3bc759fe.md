# SM4Alg

SM4对称加解密算法枚举类型，枚举值、分组模式、填充模式如下：

|枚举值|分组模式|密钥长度（bit）|填充模式|API版本|
|:-------------------|:---|:--------|:-----------|:----|
|SM4_CBC_PKCS5Padding|CBC|128|PKCS5Padding|11+|
|SM4_CBC_PKCS7Padding|CBC|128|PKCS7Padding|11+|
|SM4_CTR_NoPadding|CTR|128|NoPadding|11+|
|SM4_OFB_NoPadding|OFB|128|NoPadding|11+|
|SM4_CFB_NoPadding|CFB|128|NoPadding|11+|
|SM4_CFB128_NoPadding|CFB|128|NoPadding|11+|

```typescript
import { aegis } from '@hw-agconnect/petal-aegis';
```
