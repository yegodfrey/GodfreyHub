# 获取识别结果下载地址

文件识别完成后，调用该接口获取识别结果文件的下载地址。  

#### 使用约束

文件有效期是一个小时，请及时下载查看。  

#### 接口原型

|承载协议|HTTPS GET|
|接口方向|开发者服务器 -\> 华为服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/gmme/openapi/ad/{appId}/identification/{fileId}/result|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|
|-----|-----------------------------------------------------------------------------------------------|

#### 请求参数

#### path

|参数名称|必选（M）/可选（O）|类型|参数说明|
|:-----|:----------|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
|appId|M|String|应用ID，具体获取请参见[准备游戏信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-gameinformation-0000001327081581)。|
|fileId|M|String|文件ID， [获取文件上传地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-obtaining-upload-address-restapi-0000001623600041)接口返回的fileId。|

#### Request Header

|参数名称|必选（M）/可选（O）|类型|参数说明|
|:------------|:----------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Content-Type|M|String|取值为：application/json; charset=UTF-8。|
|Authorization|M|String|签名信息，用于校验消息是否可信，格式为"Authorization: Bearer ${access_token}"，其中access_token为调用[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-obtaintoken-restapi-0000001624528617)接口返回的access_token。|
|client_id|M|String|客户端ID，具体获取请参见[准备游戏信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-gameinformation-0000001327081581)。|
|requestId|M|String|请求ID，请勿使用重复的请求ID进行请求。|

#### 请求示例

```
GET https://connect-api.cloud.huawei.com/api/gmme/openapi/ad/{appId}/identification/{fileId}/result
Content-Type: application/json
Authorization: Bearer 1B6F4A44F5AB******AB78FACCAD51A54DB73ECBFD3C90AE35082E8
client_id: 12***67
requestId: 12***789
```

#### 响应参数

|参数|类型|必选(M)/可选(O)|说明|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-----|:----------|:------------------------------------------------------------|
|[ret](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-obtaining-upload-address-restapi-0000001623600041#ZH-CN_TOPIC_0000001623600041__p1170913233715)|String|M|包含返回码及描述信息的JSON字符串，格式为{"code":retcode, "msg": "description"}。|
|[data](#ZH-CN_TOPIC_0000001623846533__p19327411817)|String|O|若调用成功，将返回文件下载信息。|

ret参数说明  

|参数名称|类型|必选（M）/可选（O）|参数说明|
|:---|:------|:----------|:------------------------------------------------------------------------------------------------------------------------|
|code|Integer|M|返回码。 * 0：成功。 * 600001：无效参数。 * 600045：应用不属于当前团队。 * 600104：应用未开启IM功能。 * 600181：广告识别正在进行中。 * 600182：调用接口失败。 * 600183：等待广告识别。|
|msg|String|M|描述信息。|

data参数说明  

|参数|类型|必选(M)/可选(O)|说明|
|:------|:-|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|headers|M|String|请求头，返回值为空。|
|url|M|String|识别结果文件的下载地址。例如 https://contentcenter-test-bj4-001.obs.cn-north-4.myhuaweicloud.com/GameCenter_GameDevImageScas_100_1/63/v3/2tt6qHmQR12V1Yt0-YtKMg/xxx.csv 说明： 识别结果文件的下载地址有效时间为1小时，超时后地址将失效，您需重新上传文件并识别。|

#### 调用示例

```
private String getResultUrl() throws IOException {
        OkHttpClient client = new OkHttpClient().newBuilder().build();
        MediaType mediaType = MediaType.parse("text/plain");
        RequestBody body = RequestBody.create(mediaType, "");
        Request request =
            new Request.Builder().url(url + "/api/gmme/openapi/ad/" + appId + "/identification/" + fileId + "/result")
                .method("GET", null)
                .addHeader("client_id", clientId)
                .addHeader("requestId", "" + new Random().nextLong())
                .addHeader("Authorization", "Bearer " + token)
                .build();
        Response response = client.newCall(request).execute();
        ResponseBody responseBody = response.body();
        String bodyStrRespon = "";
        BufferedSource source = responseBody.source();
        source.request(Long.MAX_VALUE);
        Buffer buffer = source.getBuffer();
        Charset charset = Charset.forName("UTF-8");
        MediaType contentType = responseBody.contentType();
        if (contentType != null) {
            try {
                charset = contentType.charset(charset);
            } catch (UnsupportedCharsetException e) {
                e.printStackTrace();
            }
        }
        bodyStrRespon = buffer.clone().readString(charset);
        System.out.println(bodyStrRespon);
        AdIdResultRsp rsp = JSON.parseObject(bodyStrRespon, AdIdResultRsp.class);
        return rsp.getData().getUrl();
    }

@Data
public class AdIdResultRsp {
    private ResourceInfo data;
    private MmrmsRet ret;
}

@Data
public class ResourceInfo {
  private Map<String, String> headers;
  private String method;
  private String url;
}

@Data
public class MmrmsRet {
    private Integer code;
    private String msg;
}
```
