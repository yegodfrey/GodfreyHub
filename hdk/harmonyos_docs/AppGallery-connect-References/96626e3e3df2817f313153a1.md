# AGConnectAppMessagingDisplay

|Interface Info|
|:-----------------------------------------------------------------------------|
|public interface AGConnectAppMessagingDisplay 消息显示的接口类。开发者如果需要自定义展示消息，必须继承该接口。|

## Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------|
|void|[displayMessage](#section166841212133516)(AppMessage appMessage, AGConnectAppMessagingCallback callback) 消息展示时调用。自定义显示界面时必须定义该方法，否则无法确定消息是否真实显示，导致消息会重复显示。|

## Method

### displayMessage

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------|
|public void displayMessage(AppMessage appMessage, AGConnectAppMessagingCallback callback) 消息展示时回调。自定义显示界面时该方法必须定义，否则无法确定消息是否真实显示，导致消息会重复显示。|

**Parameters**

|Name|Description|
|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|appMessage|包含消息信息的[AppMessage](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/appmessage-java-0000001199053045)实例。|
|callback|展示消息的回调结果，参见[AGConnectAppMessagingCallback](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectappmessagingcallback-java-0000001199053041)。|
