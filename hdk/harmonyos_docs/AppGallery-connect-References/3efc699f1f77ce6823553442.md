# AGCCloudDBZoneConfig

```screen
@interface AGCCloudDBZoneConfig : NSObject
```

该类用于创建AGCCloudDBZoneConfig对象，配置CloudDBZone的同步属性、访问属性、加密存储属性和数据持久化属性等信息。

## -initWithZoneName:syncMode:accessMode:

调用此方法在端侧创建AGCCloudDBZoneConfig对象，AGCCloudDBZoneConfig对象中包含CloudDBZone的名称、同步属性和访问属性等配置信息。

创建CloudDBZone成功后，不允许修改AGCCloudDBZoneConfig中的CloudDBZone名称、同步属性和访问属性。在创建CloudDBZone成功后，您再次调用[openCloudDBZone2](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agconnectclouddb-ios-0000001127600971#section179771131262)时，系统会校验本次AGCCloudDBZoneConfig中指定的属性与创建AGCCloudDBZoneConfig时指定的属性是否一致，如果不一致，会返回错误信息。

**OBJECTIVE-C**

```screen
- (nonnull instacetype)initWithZoneName:(NSString *_Nonnull)zoneName syncMode:(https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbzonesyncmode-ios-0000001080858652)syncMode accessMode:(https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbzoneaccessmode-ios-0000001127835355)accessMode;
```

**Parameters**

|Parameter name|Parameter desc|
|:-------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|zoneName|CloudDBZone名称，表示一个唯一的数据存储区域。命名方式如下： CloudDBZone名称长度必须大于或等于1个字符，小于或等于20个字符，只能包含以下2种类型，并且至少包含"字母"类型： * 字母（A-Z或a-z） * 数字（0-9） > 说明 > CloudDBZone名称必须以字母开头。|
|syncMode|CloudDBZone的数据同步属性，用于定义CloudDBZone端侧与云侧的数据是否进行同步。 取值包含： * AGCCloudDBZoneSyncModeLocalOnly：本地模式，数据只存储在端侧，不同步至云侧。 * AGCCloudDBZoneSyncModeCloudCache： 缓存模式，数据存储在云侧，端侧数据是云侧数据的子集，如果允许持久化，Cloud DB支持将查询的结果自动缓存至端侧。在端侧对云侧数据注册侦听后，云侧数据变化时，才会通知端侧。|
|accessMode|CloudDBZone的访问属性，用于定义用户应用访问CloudDBZone的安全属性。 枚举类型，取值包含： AGCCloudDBZoneAccessModePublic：公共存储区，根据您定义的权限对访问进行鉴权。|

## encrypted

端侧CloudDBZone是否加密。

* YES：表示该CloudDBZone是加密存储的。
* NO：表示该CloudDBZone不是加密存储的。

**OBJECTIVE-C**

```screen
@property (nonatomic, readonly, assign) BOOL encrypted;
```

## -setEncryptKey:rekey:

调用此方法设置或者修改端侧CloudDBZone数据加密存储的密钥，仅在CloudDBZone的数据允许持久化时设置加密密钥才会生效。数据加密以CloudDBZone为粒度进行设置。根据请求参数值，分为如下四种情况：

* 当参数"key"的值为null或者空字符串，且参数"rekey"的值为null或者空字符串时，该CloudDBZone不需要加密。
* 当参数"key"的值不为null或者空字符串，且参数"rekey"的值为null或者空字符串时，该CloudDBZone需要加密。
* 当参数"key"的值不为null或者空字符串，且参数"rekey"的值不为null或者空字符串时，将该CloudDBZone的原密钥修改为新密钥。
* 当参数"key"的值为null或者空字符串，且参数"rekey"的值不为null或者空字符串时，为非法入参，在调用[openCloudDBZone2](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agconnectclouddb-ios-0000001127600971#section179771131262)时，会返回错误信息。

**OBJECTIVE-C**

```screen
-(void)setEncryptKey:(NSString * _Nullable)key rekey:(NSString *_Nullable)rekey;
```

**Parameters**

|Parameter name|Parameter desc|
|:-------------|:------------------------------------------------------------------|
|key|端侧CloudDBZone的加密密钥，长度为1~128个字符。 新增密钥时，该参数值必填。|
|rekey|修改后的端侧CloudDBZone加密密钥，长度为1~128个字符。 修改密钥时，该参数值必填；否则，该参数值为null或者空字符串。|

## persistence

端侧CloudDBZone的数据持久化信息。CloudDBZone的数据同步属性为本地模式时，只支持数据持久化存储。

* YES：允许持久化存储。
* NO：不允许持久化存储。

**OBJECTIVE-C**

```screen
@property (nonatomic, readwrite, assign) BOOL persistence;
```

## capacity

端侧CloudDBZone的存储空间大小。值为"-1"时，表示无大小限制；值为其它整数时，代表实际大小。

CloudDBZone存储空间大小可设置为无限制，也可设置具体的存储空间大小。设置具体值时，必须大于或等于1MB，如未设置或者设置值无效时，系统会设置为默认值100 MB。当CloudDBZone存储的数据超过设定的阈值时，会删除最久未使用且超过阈值范围已同步的数据，未同步的数据不会被删除。CloudDBZone并不能保证存储的数据大小将保持在设置值以下，仅当存储的数据大小超过设置值时才尝试删除数据。

设置CloudDBZone的存储空间大小后，如果存储空间不满足当前所需，可通过该方法修改CloudDBZone的存储空间大小，修改存空间大小后需要重新[openCloudDBZone2](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agconnectclouddb-ios-0000001127600971#section179771131262)，修改的值才会生效。

仅当CloudDBZone的数据同步属性为缓存模式且数据持久化属性为持久化存储时，才允许调用此方法设置存储空间大小。

**OBJECTIVE-C**

```screen
@property (nonatomic, readwrite, assign) long capacity;
```

**Return**

|type|desc|
|:---|:-----------------------------------------------------------|
|long|CloudDBZone的大小，单位为字节。 * 返回值为-1时，表示无大小限制。 * 返回值为其它整数时，代表实际大小。|
