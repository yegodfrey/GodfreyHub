# ReviewInfo

|参数|必选(M)/可选(O)|类型|描述|
|:--------------|:----------|:------|:------------------------------------------------------------------|
|content|O|String|评论内容。|
|reviewId|O|String|评论ID。|
|appVersion|O|String|应用版本号。|
|phoneType|O|String|机型。|
|rating|O|Integer|评分。|
|likes|O|Integer|点赞数。|
|replies|O|Integer|回复数。|
|dateline|O|Long|评论时间，从1970/01/01 08:00:00开始计算的毫秒数。|
|auditState|O|Integer|审核状态： * 0：待风控审核 * 1：待分配 * 2：待人工审核 * 3：通过 * 4：不通过 * 5：自动通过 * 6：自动不通过|
|devReplyContent|O|String|开发者回复内容。|
|countryCode|O|String|ISO标准国家码。|
