# 验证用户凭据

## 功能介绍

此接口用于验证已经颁发的用户凭据并且检查用户凭据是否已经撤销。

## 使用约束

* 接口调用者的角色：管理员、APP管理员、开发。
* 接口调用次数限制：500个请求/client_id/秒

## 接口原型

|承载协议|HTTPS GET|
|-----|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|接口方向|开发者服务器->华为认证服务|
|接口URL|https://{domain}/api/oauth2/third/v1/verify-token?productId={productId} 中国站点的domain：connect-api.cloud.huawei.com 德国站点的domain：connect-api-dre.cloud.huawei.com 新加坡站点的domain：connect-api-dra.cloud.huawei.com 俄罗斯站点的domain：connect-api-drru.cloud.huawei.com > 注意 > 调用[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)接口时使用的域名必须与本接口域名保持一致，例如本接口使用"connect-api-dre.cloud.huawei.com"，则调用[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)接口必须使用"https://connect-api-dre.cloud.huawei.com/api/oauth2/v1/token"。|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 请求参数

### Query

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:--------|:----------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------|

### Header

> 说明
>
> 本接口支持使用Service Account方式和API客户端方式，二者区别请参见[获取服务端API授权](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-obtain-apiauthorization-0000001374178549)。

**Service Account方式**

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|accessToken|M|String|用户凭据。|
|Authorization|M|String|认证信息，格式为"Authorization: Bearer *${JWT}* "。JWT为[通过Service Account方式获取授权](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-obtain-apiauthorization-0000001374178549#section276512551310)中获取的鉴权令牌。|

**API客户端方式**

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|M|String|客户端ID，获取方法参考[创建API客户端](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-obtain-apiauthorization-0000001374178549#section186371930132016)。|
|accessToken|M|String|用户凭据。|
|Authorization|M|String|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain-token-project-0000001477336048)中获取的access_token。|

## 响应参数

|参数|必选（M）/可选（O）|参数类型|描述|
|:----------|:----------|:----------|:-------------------------------------------------------------------------------------------------|
|ret|M|String(100)|包含返回码及描述信息的JSON字符串，格式为{"code":*retcode* , "msg": "*description*"}，retcode为返回码，description为返回码描述信息。|
|productId|M|Integer|项目ID。|
|accessToken|M|String|JSON字符串，格式为{"token": "string", "validPeriod": xxx }，token为用户凭据，validPeriod为token有效时长。单位为秒。|
|uid|M|String|用户ID，唯一标识。|

## 调用示例

```screen
"Java  "
    /**
     * 通过华为认证服务进行验证用户凭据是否有效
     *
     * @param client_id clientId
     * @param clientToken clientToken
     * @param accessToken 用户凭据
     * @param productId 项目ID
     * @return uid
     */
    public static String verifyTokenServer(String clientId, String clientToken, String accessToken, String productId) {
        HttpGet get =
            new HttpGet("https://connect-api.cloud.huawei.com/api/oauth2/third/v1/verify-token?productId=" + productId);
        CloseableHttpClient httpClient = HttpClients.createDefault();
        get.setHeader("client_id", clientId);
        get.setHeader("accessToken", accessToken);
        get.setHeader("Authorization", "Bearer " + clientToken);
        try {

            CloseableHttpResponse httpResponse = httpClient.execute(get);
            int statusCode = httpResponse.getStatusLine().getStatusCode();
            if (statusCode == HttpStatus.SC_OK) {
                BufferedReader br =
                    new BufferedReader(new InputStreamReader(httpResponse.getEntity().getContent(), Consts.UTF_8));
                String result = br.readLine();

                JSONObject object = JSON.parseObject(result);
                return object.getString("uid");
            }
        } catch (Exception e) {
            e.printStackTrace();
        } finally {
            try {
                if (Objects.nonNull(get)) {
                    get.releaseConnection();
                }
                if (Objects.nonNull(httpClient)) {
                    httpClient.close();
                }
            } catch (Exception e) {
                e.printStackTrace();
            }
        }

        return null;
    }
```
