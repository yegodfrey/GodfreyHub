# 修改文件元数据

## 功能介绍

此接口用于修改文件元数据。

## 接口原型

|承载协议|HTTPS GET|
|-----|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|接口方向|开发者服务器->华为服务器|
|接口URL|https://{domain}/{bucket_name}/{object_name}?metadata=update > 注意 > * {bucket_name}为当前存储实例名称，{object_name}为待修改的文件名称。 > * {domain}为接口域名。 >   * 中国站点的域名：ops-server-drcn.agcstorage.link/v0 >   * 德国站点的域名：ops-server-dre.agcstorage.link/v0 >   * 新加坡站点的域名：ops-server-dra.agcstorage.link/v0 >   * 俄罗斯站点的域名：ops-server-drru.agcstorage.link/v0 > * 调用[获取Token](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agcapi-obtain-token-project-0000001477336048)接口时使用的站点必须与本接口使用的站点保持一致。例如本接口使用的站点是德国，即接口域名为"ops-server-dre.agcstorage.link/v0"，则调用[获取Token](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agcapi-obtain-token-project-0000001477336048)接口也必须使用德国站点，其接口域名需为"connect-api-dre.cloud.huawei.com"。|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 请求参数

### Header

> 说明
>
> 单次请求所有的header数量不得超过40个。

|参数|类型|必选(M)/可选(O)|说明|
|:------------------------|:-----|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Authorization|String|M|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agcapi-obtain-token-project-0000001477336048)中获取的access_token。|
|client_id|String|M|客户端ID，获取方法参考[创建API客户端](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-getapicredentials-0000001498508514#section8727185210538)。|
|productId|String|M|项目ID，查询方法可参见[查询项目ID](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-get-developerid-projectid-0000001166543063)。|
|X-Agc-Trace-Id|String|O|单个文件请求的Traceid。可不填或者随机生成，用于日志打印跟踪。|
|X-Agc-Content-Type|String|O|文件类型。 默认值：application/octet-stream|
|X-Agc-Content-Disposition|String|O|文件打开方式。|
|X-Agc-Content-Encoding|String|O|HTTP标准头部Content-Encoding。|
|X-Agc-Cache-Control|String|O|HTTP标准头部Cache-Control。|
|X-Agc-Content-Language|String|O|HTTP标准头部Content-Language。|
|X-Agc-meta-*|String|O|可以在请求中加入以"X-Agc-meta-"开头的消息头，用于加入自定义的元数据，以便对文件进行自定义管理。当用户获取此文件或查询此文件元数据时，加入的自定义元数据将会在返回消息的头中出现。 示例：X-Agc-meta-test: test metadata 保存实例为：test: test metadata > 说明 > * 元数据名称相同则覆盖。自定义的部署不区分大小写，最后记录均为小写的方式。X-Agc-meta-仅标记此header是传递元数据，并非元数据key的一部分。 > * 目录对象不支持自定义元数据，所以此接口不支持目录对象。|

## 响应参数

### Header

|参数|类型|必选(M)/可选(O)|说明|
|:-------------|:------|:----------|:--------------------------------------|
|status|Integer|M|HTTP响应码，200表示成功。|
|X-Agc-Trace-Id|String|O|单个文件请求的Traceid，与请求参数X-Agc-Trace-Id保持一致。|

### Body

|**属性**|**类型**|必选(M)/可选(O)|**说明**|
|:-----------------|:-----------------|:----------|:-----------------------------------------------------------|
|productId|String|M|项目ID。|
|name|String|M|文件名称。|
|bucket|String|M|存储实例名称。|
|storageArea|String|M|存储区域名称。|
|storageRegion|String|M|后端OBS存储站点。|
|storageType|String|M|存储类型。|
|contentType|String|M|文件类型。Content-Type标头告诉客户端实际返回的内容类型。|
|contentDisposition|String|O|文件打开方式，响应头指示回复的内容该以何种形式展示，是以内联的形式（即网页的一部分），还是以附件的形式下载并保存到本地。|
|sha256|String|O|文件SHA256值。|
|size|long|M|文件大小。|
|createTime|String|M|上传时间，时间日期格式:yyyy-MM-ddTHH:mm:ssZ。|
|updateTime|String|M|更新时间，时间日期格式:yyyy-MM-ddTHH:mm:ssZ。|
|metadata|Map<String,String>|O|元数据，用户自定义元数据。|

## 调用示例

```screen
import com.alibaba.fastjson.JSON;
import com.alibaba.fastjson.JSONObject;

import lombok.Builder;
import lombok.Getter;
import lombok.Setter;
import lombok.ToString;
import lombok.extern.slf4j.Slf4j;

import org.apache.commons.collections4.MapUtils;
import org.apache.http.Consts;
import org.apache.http.HttpStatus;
import org.apache.http.client.methods.CloseableHttpResponse;
import org.apache.http.client.methods.HttpGet;
import org.apache.http.client.utils.URIBuilder;
import org.apache.http.impl.client.CloseableHttpClient;
import org.apache.http.impl.client.HttpClients;
import org.junit.Ignore;

import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.util.HashMap;
import java.util.Map;

/**
 * 元数据管理REST API示例代码
 */
@Slf4j
public class MetadataManagingTest {

    /**
     * 更新元数据信息
     *
     * @param storageUrl 云存储url
     * @param param 更新元数据接口入参
     * @throws Exception 异常
     */
    public static void updateObjectMetadata(String storageUrl, ObjectMetadataParam param) throws Exception {
        URIBuilder uriBuilder =
            new URIBuilder(storageUrl + param.getBucketName() + "/" + param.getObjectName() + "?metadata=update");
        HttpGet get = new HttpGet(uriBuilder.build());
        get.setHeader("productId", param.getProjectId());
        get.setHeader("client_id", param.getClientId());
        get.setHeader("Authorization", "Bearer " + param.getToken());
        if (MapUtils.isNotEmpty(param.getMetadata())) {
            param.getMetadata().forEach((k, v) -> get.setHeader(k, v));
        }

        CloseableHttpClient httpClient = HttpClients.createDefault();
        CloseableHttpResponse httpResponse = httpClient.execute(get);
        int statusCode = httpResponse.getStatusLine().getStatusCode();
        if (statusCode == HttpStatus.SC_OK) {
            BufferedReader br =
                new BufferedReader(new InputStreamReader(httpResponse.getEntity().getContent(), Consts.UTF_8));
            String result = br.readLine();
            JSONObject object = JSON.parseObject(result);
            ObjectMetadata objectMetadata = JSONObject.toJavaObject(object, ObjectMetadata.class);
            log.info("updateObjectMetadata result:", objectMetadata);
        }
    }

    public void client() throws Exception {

        String clientToken = TokenServiceTest.getToken("https://connect-api.cloud.huawei.com/api/", "84903XXXXXX32064",
            "00E5CCADB655891XXXXXXXXXXXX8CDCC83ACF22");

        Map<String, String> metadata = new HashMap<>();
        metadata.put("X-Agc-meta-sha256", "get file sha256");
        metadata.put("X-Agc-Content-Encoding", "gzip");
        ObjectMetadataParam updateMetadataParam = ObjectMetadataParam.builder()
            .projectId("73643XXXXXX61998")
            .clientId("84903XXXXXX32064")
            .token(clientToken)
            .bucketName("test-q36q0")
            .objectName("sha256/test3.jpg")
            .metadata(metadata)
            .build();
        updateObjectMetadata("https://ops-server-drcn.agcstorage.link/v0/", updateMetadataParam);
    }

    public static void main(String[] args) throws Exception {
        new MetadataManagingTest().client();
    }

    @Builder
    @Getter
    static class ObjectMetadataParam {
        // 项目ID
        String projectId;

        // 客户端ID
        String clientId;

        // clientToken
        String token;

        // 云存储实例名
        String bucketName;

        // 待修改的文件名，需要携带路径。
        String objectName;

        Map<String, String> metadata;
    }

    /**
     * 文件的元数据
     */
    @Getter
    @Setter
    @ToString
    static class ObjectMetadata {
        // 项目Id
        private String productId;

        // 存储的实例名
        private String bucket;

        // 存储的区域
        private String storageArea;

        // 后端OBS存储站点
        private String storageRegion;

        // 存储的类型
        private String storageType;

        // 文件名
        private String name;

        // 文件类型
        private String contentType;

        // 上传时间，时间日期格式:yyyy-MM-ddTHH:mm:ssZ
        private String createTime;

        // 更新时间，时间日期格式:yyyy-MM-ddTHH:mm:ssZ
        private String updateTime;

        // 文件大小
        private long size;

        // 可选，元数据，用户自定义元数据
        private Map<String, String> metadata;

        // 可选，标准HTTP请求头 Content-Language
        private String contentLanguage;

        // 可选，标准HTTP请求头 Content-Encoding
        private String contentEncoding;

        // 可选，标准HTTP请求头 Cache-Control
        private String cacheControl;

        // 可选，文件打开方式
        private String contentDisposition;
    }
}
```
