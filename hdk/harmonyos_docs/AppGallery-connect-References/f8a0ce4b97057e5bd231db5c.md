## -updatePassword:verifyCode:provider:

更新当前用户的密码。

**Objective-C**

```screen
- (HMFTask *)updatePassword:(NSString *)newPassword
                 verifyCode:(NSString *)verifyCode
                   provider:(NSInteger)provider;
```

**Swift**

```screen
func updatePassword(_ newPassword: String!, verifyCode: String!, provider: Int) -> Any!
```

**Parameters**

|Name|Description|
|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|newPassword|新密码。 默认密码规则如下，若您参考[安全配置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-security-configuration-0000001324925609)自定义了密码复杂度请满足自定义的复杂度： 1. 密码长度至少8个字符； 2. 密码必须包含如下至少两种字符的组合： * 至少一个小写字母； * 至少一个大写字母； * 至少一个数字； * 至少一个特殊字符：`!@#$%^&*()-_=+\|[{}];:'",<.>/? 和空格。 3. 密码不能和手机号码或者邮箱一样。|
|VerifyCode|验证码。|
|provider|provider类型。|

**Return**

更新结果异步任务。
