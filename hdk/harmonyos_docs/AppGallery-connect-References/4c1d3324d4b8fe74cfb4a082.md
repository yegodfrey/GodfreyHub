# ohAegHuksEncTextHex

ohAegHuksEncTextHex(keyAlias: string, text: string | Uint8Array, iv?: string | Uint8Array): Promise<string>

基于HUKS的AES-GCM加密，无需传入密钥，加密结果是16进制编码的字符串类型，建议与[ohAegHuksDecTextHex](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ohaeghuksdectexthex-0000001911965185)配套使用，分组模式、填充模式如下：

|分组模式|密钥长度（bit）|填充模式|API版本|
|:---|:--------|:--------|:----|
|GCM|256|NoPadding|11+|

**导入模块：**

```screen
import { AegHuks } from '@hw-agconnect/petal-aegis';
```

**参数** **：**

|参数名|类型|必填|说明|
|:-------|:----------------|:-|:------------------------------------------------------------|
|keyAlias|string|是|密钥别名。|
|text|string或Uint8Array|是|明文内容。|
|iv|string或Uint8Array|否|如果没有传入，接口会自动生成iv，随密文一同作为返回值（string类型的iv需要使用16进制编码格式），长度为12字节。|

**返回值：**

|参数|类型|说明|
|:----------|:--------|:------|
|encryptText|hexString|加密后的密文。|
