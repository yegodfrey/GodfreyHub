# ohAegSignRSAWithPSSText

ohAegSignRSAWithPSSText(text: string | Uint8Array, priKey: string | Uint8Array): Promise<Uint8Array>

RSA3072私钥签名，返回Uint8Array类型的签名结果，密钥类型、填充模式、摘要算法等如下：

|非对称密钥类型|填充模式|摘要算法|掩码摘要|API版本|
|:------|:---|:-----|:----------|:----|
|RSA3072|PSS|SHA256|MGF1_SHA256|11+|

**导入模块：**

```typescript
import { AegRsaSign } from '@hw-agconnect/petal-aegis';
```

**参数** **：**

|参数名|类型|必填|说明|
|:-----|:----------------|:-|:------------------------------|
|text|string或Uint8Array|是|待签名的内容。|
|priKey|string或Uint8Array|是|RSA私钥，base64编码过的字符串或Uint8Array。|

**返回值：**

|参数|类型|说明|
|:-----|:---------|:------|
|签名后的内容|Uint8Array|签名后的内容。|
