|:------------------------------------------------------------------|

## - (HWPGMEngine *)create:

创建游戏多媒体实例。

OBJECTIVE-C

```screen
- (HWPGMEngine *)create:(EngineCreateParams* _Nullable)engineParam
        engineDelegate:(id<HWPGMEngineDelegate> _Nullable)engineDelegate;
```

**Parameters**

|Name|Description|
|:-------------|:---------------|
|engineParam|游戏多媒体实例初始化参数。|
|engineDelegate|开发者传入的游戏多媒体实例回调。|

**Return**

|Type|Description|
|:---|:--------------------------|
|int|创建游戏多媒体实例的结果。 * 0：成功 * 1：失败|

**Sample Code**

OBJECTIVE-C

```screen
EngineCreateParams *engineParam = [[EngineCreateParams alloc]init];   
engineParam.openId = openId // 玩家ID，必选
engineParam.logEnable = logEnable; // 开启SDK日志记录
engineParam.logPath = logPath; // 日志路径
engineParam.logSize = logSize; // 日志存储大小
engineParam.agcAppId = agcAppId; // 游戏应用在AGC上注册的APP ID
engineParam.clientId = clientId; // 客户端ID
engineParam.clientSecret = clientSecret; // 客户端ID对应的秘钥
engineParam.cpAccessToken = cpAccessToken; // AGC接入凭证（推荐）
HWPGMEngine *pgmeEngine = [HWPGMEngine getInstance];
SelfHWPGMEngineDelegate *engineDelegate = [[SelfHWPGMEngineDelegate alloc]init]; // HWPGMEngineDelegate回调实现
[HWPGMEngine create:engineParam engineDelegate:engineDelegate];
```
