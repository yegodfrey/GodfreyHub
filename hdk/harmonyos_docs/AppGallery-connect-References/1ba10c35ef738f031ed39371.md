# ohAegRsaEncText

ohAegRsaEncText(text: string | Uint8Array, pubKey: string | Uint8Array): Promise<Uint8Array>

RSA3072公钥加密算法，加密结果是Uint8Array类型，建议与[ohAegRsaDecText](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ohaegrsadectext-0000001910347093)配套使用，密钥类型、填充模式、摘要算法等如下：

|非对称密钥类型|填充模式|摘要算法|掩码摘要|API版本|
|:------|:---------|:-----|:----------|:----|
|RSA3072|PKCS1_OAEP|SHA256|MGF1_SHA256|11+|

**导入模块：**

```typescript
import { AegRsa } from '@hw-agconnect/petal-aegis';
```

**参数** **：**

|参数名|类型|必填|说明|
|:-----|:----------------|:-|:------------------------------|
|text|string或Uint8Array|是|明文内容。|
|pubKey|string或Uint8Array|是|RSA公钥，base64编码过的字符串或Uint8Array。|

**返回值：**

|参数|类型|说明|
|:----------|:---------|:------|
|encryptText|Uint8Array|加密后的密文。|
