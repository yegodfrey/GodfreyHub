# MetadataComplete

|Interface Info|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|export interface MetadataComplete 完整的元数据信息，包含可更新的元数据信息（[MetadataUpdatable](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-storage-metadataupdatable-0000001630983010)）及如下不可更新的元数据字段信息。|

## Parameters

|Name|Type|Mandatory/Optional (M/O)|Description|
|:---------|:-----|:-----------------------|:-------------|
|bucket|string|M|云存储的存储实例名称。|
|name|string|M|云端文件名称。|
|size|number|M|云端文件大小。|
|ctime|string|M|云端文件创建时间。|
|mtime|string|M|云端文件修改时间。|
|sha256Hash|string|M|云端文件的SHA256信息。|
