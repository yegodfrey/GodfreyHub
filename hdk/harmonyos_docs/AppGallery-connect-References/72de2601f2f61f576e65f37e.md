# 查询软件包列表

## 功能介绍

此接口用于查询应用当前关联的软件包列表信息。接口调用者的角色：账号持有者、管理员、APP管理员、运营。

## 接口原型

|承载协议|HTTPS GET|
|-----|-------------------------------------------------------------------|
|接口方向|开发者服务器 -> 华为服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/publish/v2/package-list|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 请求参数

### Header

> 说明
>
> API客户端方式和OAuth客户端方式的区别请参见[使用入门](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114)。

**API客户端方式：**

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|M|String|客户端ID，获取方法参考[创建API客户端](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section103mcpsimp)。|
|Authorization|M|String|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)中获取的access_token。|

**OAuth客户端方式：**

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
|teamId|M|String|开发者所在团队的团队ID，可通过[获取团队列表](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-getteamlist-0000001158245075)接口获取。|
|oauth2Token|M|String|认证信息，传入[获取用户授权码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section949717114392)中获取的Access Token。|

### Query

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:-----------|:----------|:------|:----------------------------|
|appId|M|String|应用ID。|
|fromRecCount|O|Integer|查询起始记录号。 默认值：1|
|maxReqCount|O|Integer|请求查询的软件包数。 取值范围：最大为100 默认值：10|

## 响应参数

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:---------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|ret|M|String(100)|包含返回码及描述信息的JSON字符串，格式为{"code":*retcode* , "msg": "*description* "}，retcode为返回码，description为返回码描述信息。返回码请参见[错误码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-publishingapi-errorcode-0000001163523297)。|
|retCount|M|Integer|返回的软件包数量。|
|totalCount|M|Integer|软件包总数量。|
|pkgList|M|List<[PackageInfo](#ZH-CN_TOPIC_0000001111685210__zh-cn_topic_0000001059070160_p592719917156)>|软件包列表信息。|
|packagePath|O|String|APK上传后的下载URL（有效期为5分钟），是一个完整的地址。|
|abisType|O|Integer|CPU架构类型。 取值范围： * 1：32位（armeabi-v7a|armeabi|x86|mips） * 2：64位（armeabi-v8a|x86_64|mips64） * 3：同时支持32位和64位 默认值：3|

**PackageInfo**

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:-------------------------------------------------------------------------------------|:-----------------------|
|pkgVersion|M|String|软件包唯一标识。|
|fileName|M|String|应用软件包文件名称。|
|versionCode|M|Integer|版本号，对应软件包中的versionCode。|
|versionName|O|String|版本描述，对应软件包中的versionName。|
|packageSize|M|Integer|软件包实体大小，从软件包中解析获得。|
|uploadTime|M|Integer|软件包上传时间。|
|shaCode|O|String|软件包SHA256摘要。|
|packageType|M|Integer|软件包类型。当前仅支持1，表示APK软件包。|
|mainObb|O|[ObbInfo](#ZH-CN_TOPIC_0000001111685210__zh-cn_topic_0000001059070160_p20608193610292)|APK软件包关联的主OBB文件。|
|patchObb|O|[ObbInfo](#ZH-CN_TOPIC_0000001111685210__zh-cn_topic_0000001059070160_p20608193610292)|APK软件包关联的补丁OBB文件。|

**ObbInfo**

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:---------|:----------|:------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|obbId|M|String|OBB文件ID。|
|obbType|M|Integer|OBB文件类型。 取值范围： * 1：主扩展文件 * 2：补丁扩展文件|
|fileName|M|String|文件名称，OBB文件上传后服务器会对OBB文件按以下规则重新命名： main|patch.*apkVersion* .*packageName*.obb main表示主扩展文件，patch表示补丁扩展文件。*apkVersion* 为APK包的版本号，*packageName*为APK包名。例如"main.314159.com.example.app.obb"。|
|sha256|O|String|OBB文件的SHA256摘要。|
|fileSize|M|Integer|OBB文件大小。|
|uploadTime|M|String|OBB文件上传时间。|

## 调用示例

```screen
public static JSONObject getAppPkgList(String domain, String clientId, String token, String appId,
        Integer fromRecCount, Integer maxReqCount) {
        HttpGet put = new HttpGet(domain + "/publish/v2/package-list?appId=" + appId + "&fromRecCount=" + fromRecCount
            + "&maxReqCount=" + maxReqCount);
        put.setHeader("Authorization", "Bearer " + token);
        put.setHeader("client_id", clientId);
        try {
            CloseableHttpClient httpClient = HttpClients.createDefault();
            CloseableHttpResponse httpResponse = httpClient.execute(put);
            int statusCode = httpResponse.getStatusLine().getStatusCode();
            if (statusCode == HttpStatus.SC_OK) {
                BufferedReader br =
                    new BufferedReader(new InputStreamReader(httpResponse.getEntity().getContent(), Consts.UTF_8));
                String result = br.readLine();
                JSONObject object = JSON.parseObject(result);
                return object;
            }
        } catch (Exception e) {
            System.out.println(e);
        } finally {
            put.releaseConnection();
        }
        return null;
    }
```
