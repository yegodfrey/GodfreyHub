# EmailInfo

Email账号信息类，用于更新用户当前Email账号信息的操作。  

#### Parameters

|Name|Type|Description|
|:---------|:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|email|string|Email账号。|
|verifyCode|string|Email验证码。|
|lang|string|验证码文字语言，例如中文："zh_CN"。所有支持的语言类型请参考[认证服务验证码语言类型](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-verifycode-langtype-0000002563105507)。|
