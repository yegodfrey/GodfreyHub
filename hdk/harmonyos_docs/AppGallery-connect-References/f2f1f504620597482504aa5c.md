# 删除单个游戏资源包

## 功能介绍

为及时释放您的设备空间，游戏客户端每成功获取一个游戏资源包的包体文件，便在预下载存储目录中删除当前包体文件。调用时华为应用市场客户端会校验调用方App的签名值，如果签名校验不通过则直接返回失败。

## 接口原型

|承载协议|ContentProvider，即Android应用程序之间进行数据交换的标准API。|
|----|---------------------------------------------------------------------------------------------|
|接口方向|游戏客户端->华为应用市场客户端|
|请求方式|context.getContentResolver.acquireUnstableContentProviderClient(uri).call(method,arg,extras);|

## 请求参数

|参数名|必选(M)/可选(O)|类型|说明|
|:-----|:----------|:-----|:----------------------------------------------------------------------------------------|
|uri|M|Uri|ContentProvider的请求URL，要求取值为Uri.parse("content://com.huawei.appgallery.game.CONTENT_URI")。|
|method|M|String|华为应用市场定义的请求方法名，方法名为"deleteSingleResFile"。|
|arg|M|String|游戏资源包名称。|
|extras|M|Bundle|华为应用市场暂未使用，取值为""。|

## 响应参数

|参数|必选(M)/可选(O)|类型|说明|
|:---------|:----------|:------|:----------------------------------|
|returnCode|M|Integer|提交结果。 * 0：成功，表示成功删除指定游戏资源包。 * 1：失败。|

## 示例代码

```screen
    /**
     * provider URI
     */
    private static final String PROVIDER_URI = "content://com.huawei.appgallery.game.CONTENT_URI";

    /**
     * provider接口返回码
     */
    private static final String PROVIDER_RETURN_CODE = "returnCode";

    /**
     * 根据文件名删除单个游戏资源包
     *
     * @param fileName 游戏资源包文件名称
     */
    private void deleteSingleResourceFile(String fileName) {
        try {
            Uri uri = Uri.parse(PROVIDER_URI);
            ContentProviderClient contentProviderClient =
                    this.getApplicationContext().getContentResolver().acquireUnstableContentProviderClient(uri);
            Bundle bundle = contentProviderClient.call("deleteSingleResFile", fileName, null);
            int rtnCode = bundle == null ? 1 : bundle.getInt(PROVIDER_RETURN_CODE);
            if (rtnCode == 0) {
                // 成功
            } else {
                // 失败
            }
        } catch (Exception e) {
            Log.e(TAG, e.getMessage());
        }
    }
```
