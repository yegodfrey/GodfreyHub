#### userReauthenticate

|Method|
|:-------------------------------------------------------------|
|userReauthenticate(credential: AGConnectAuthCredential) 账号重认证。|

Parameters  

|Name|Description|
|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|credential|重认证的凭证credential，与[signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-agconnectauth-0000001522558177#section136957141012)接口入参一致。|

Return  

|Type|Description|
|:-----------------------------------------------------------------------------------------------------------------------------------------------|:-----------|
|Promise\<[SignInResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-signinresult-0000001522278605)\>|账号重认证异步调用结果。|

Sample Code

```
agconnect.auth().getCurrentUser().then(user=>{
  // 手机重认证
  let credential = '';
  if(verifyCode){
    credential = PhoneAuthProvider.credentialWithVerifyCode(account, password, verifyCode);
  }else{
    credential = PhoneAuthProvider.credentialWithPassword(account, password);
  }
  agconnect.auth().getCurrentUser().then(async user => {
    if(user){
      await userReauthenticate(credential);
    }
  });

  // 邮箱重认证
  let credential = '';
  if(verifyCode){
    credential = EmailAuthProvider.credentialWithVerifyCode(account, password, verifyCode);
  }else{
    credential = EmailAuthProvider.credentialWithPassword(account, password);
  }
  agconnect.auth().getCurrentUser().then(async user => {
    if(user){
      await user.userReauthenticate(credential);
    }
  });
})
```

#### updatePassword

|Method|
|:-----------------------------------------------------------------------------------------------------------------------|
|updatePassword(newPassword: string, verifyCode: string, provider: number) 用户登录后，更新手机账号或邮箱账号的密码。以provider区分（11：手机，12：邮箱）。|

Parameters  

|Name|Description|
|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|newPassword|手机账号或邮箱账号的新密码。 默认密码规则如下，若您参考[安全配置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-security-configuration-0000001324925609)自定义了密码复杂度请满足自定义的复杂度： 1. 密码长度至少8个字符。 2. 密码必须包含如下至少两种字符的组合： * 至少一个小写字母 * 至少一个大写字母 * 至少一个数字 * 至少一个特殊字符：\`!@#$%\^\&\*()-_=+\\\|\[{}\];:'",\<.\>/? 和空格 3. 密码不能和手机号码或者邮箱一样。|
|verifyCode|手机账号或邮箱账号的验证码。|
|provider|更新密码的认证方式类型： * 11：手机 * 12：邮箱|

Sample Code

```
// 更新手机密码
agconnect.auth().getCurrentUser().then(async user => {
  if(user){
      // 手机provider为11
      await user.updatePassword(newPassword, verifyCode, provider);
  }
});

// 更新邮箱密码
agconnect.auth().getCurrentUser().then(async user => {
  if(user){
      // 邮箱provider为12
      await user.updatePassword(newPassword, verifyCode, provider);
  }
});
```

#### link

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|link(credential: [AGConnectAuthCredential](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-agconnectauthcredential-0000001471238990)): Promise\<[SignInResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-signinresult-0000001522278605)\> 当前用户关联新的登录方式。|

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250818213018.40372962130857002853498147139220:50001231000000:2800:B82ADA77301306A49293CD1A9B226602665CBB89F746EBBF33BBE1C966923AAE.png)  
此接口会验证用户Access Token和Refresh Token，请确保用户Refresh Token在有效期内，否则会抛出错误码203817986，表示用户Refresh Token无效。

收到此错误码后，请重新登录应用，获取新的Access Token和Refresh Token。

<br />

Parameters  

|Name|Description|
|:---------|:-------------------------------------------------------|
|credential|新的第三方登录凭证。 说明： 当关联的登录方式为手机账号或邮箱账号时仅支持"账号+验证码"的方式，不能传递密码。|

Return  

|Type|Description|
|:-----------------------------------------------------------------------------------------------------------------------------------------------|:-------------|
|Promise\<[SignInResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-signinresult-0000001522278605)\>|异步返回当前登录的用户信息。|

Sample Code

```
agconnect.auth().getCurrentUser().then(async user=>{
  let credential = PhoneAuthProvider.credentialWithVerifyCode(countryCode, account, password, verifyCode);
if(credential){
  await user.link(credential);
}
});
```
