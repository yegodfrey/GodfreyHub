# ServerStatus

ServerStatus类表示云侧服务器状态，当调用CloudDB中的[serverStatusQuery()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddb-server-nodejs-0000001734039358#section12358449111114)方法成功查询云侧服务器状态时才会获取ServerStatus对象。ServerStatus对象中封装了云侧服务器当前时间戳。  

#### Field Summary

|Field|Desc|
|:----------------------|:----------|
|serverTimestamp: number|云侧服务器当前时间戳。|
