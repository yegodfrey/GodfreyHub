# ComponentChangedEvent

|Class/Struct Info|
|:----------------------------------------------------------------------------------|
|public readonly struct ComponentChangedEvent : IEvent 组件变化事件结构体，当实体的组件被添加、移除或更新时触发。|

#### Property Summary

|Name|Type|Description|
|:------------|:------------------|:----------|
|ChangeType|ComponentChangeType|变化类型。|
|EntityId|int|实体ID。|
|ComponentId|int|组件ID|
|ComponentType|ComponentType|组件类型。|
|Entity|IEntity|实体引用。|
|EcsWorld|IECSWorld|ECSWorld引用。|

Sample Code

```
// 定义组件变更事件处理器，可访问事件字段和属性
Action<ComponentChangedEvent> componentChanged = (evt) =>
{
    var changeType = evt.ChangeType;
    var id = evt.EntityId;
    var compType = evt.ComponentType;
    var compId = evt.ComponentId;
    var entity = evt.Entity;
    var world = evt.EcsWorld;
};
```
