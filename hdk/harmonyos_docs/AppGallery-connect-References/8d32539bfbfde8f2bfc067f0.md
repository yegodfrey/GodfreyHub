# Function

|interface info|
|:----------------------------------------------------------------------------------------------------|
|public interface Function 通过实现该接口，并重写apply方法，来定义事务需要执行的操作。您可以在apply()方法中使用transaction进行数据的查询、写入和删除操作。|

## Public Method Summary

|Return type|Method name|
|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|boolean|[apply](#section35031448184717)(Transaction transaction) 通过实现此接口来定义事务需要执行的操作，即定义[Transaction](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-transaction-serverjava-0000001127491747)类中的查询、写入和删除操作。Cloud DB会自动调用apply()方法来执行您自定义的操作。|

## Public Methods

### apply

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|boolean apply(Transaction transaction) 通过实现此接口来定义事务需要执行的操作，即定义[Transaction](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-transaction-serverjava-0000001127491747)类中的查询、写入和删除操作。Cloud DB会自动调用apply()方法来执行您自定义的操作。|

**Parameters**

|Parameter name|Parameter desc|
|:-------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|transaction|事务对象，通过调用该对象的接口，完成事务中的对数据的增、删、改、查操作。详细信息请参见[Transaction](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-transaction-serverjava-0000001127491747)。|

**Return**

|type|desc|
|:------|:---------------------------------------------------|
|boolean|定义的事务内操作是否有效。 * true：定义的事务内操作有效。 * false：定义的事务内操作无效。|
