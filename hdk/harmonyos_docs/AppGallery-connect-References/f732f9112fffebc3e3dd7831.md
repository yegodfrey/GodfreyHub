# 错误码

|:-------------|:----------------|
|0|成功。|
|50010003|请求参数错误。|
|50010035|开始时间大于结束时间。|
|50010034|开始时间和结束时间之间超过6个月。|
|50010028|当前应用不属于该开发者。|
|50010059|未知异常。|
|100001|参数异常。|
