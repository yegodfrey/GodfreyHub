# ApmsLog

|Class Info|
|:-----------------------------------------------|
|public class ApmsLog 自定义日志打印类，用于日志回捞。打印日志会缓存到本地。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:------------------------------------------------------------------------|
|void|[v](#section1052mcpsimp)(String tag, String msg) 打印verbose日志。|
|void|[d](#section0267161841220)(String tag, String msg) 打印debug日志。|
|void|[i](#section040714526122)(String tag, String msg) 打印info日志。|
|void|[w](#section3202121141514)(String tag, String msg) 打印warn日志。|
|void|[e](#section122981649151513)(String tag, String msg) 打印error日志。|
|void|[flush](#section6463192491616)() 将日志缓存到本地文件。|
|void|[release](#section18381162261916)() 释放实例，释放后日志打印功能不可用。|
|void|[fetch](#section17826164517200)(FetchTask.FetchCallback callback) 拉取回捞任务。|
|void|[grant](#section41355535235)() 同意执行日志回捞任务。|
|void|[deny](#section1013713792411)() 拒绝执行日志回捞任务。|

### flush

|Method|
|:-------------------------------------------------------------------------|
|public void flush() 将日志缓存到本地文件。建议在应用退到后台或者退出时调用，异步操作。不调用时，部分日志将在应用下次重启时刷新。|
