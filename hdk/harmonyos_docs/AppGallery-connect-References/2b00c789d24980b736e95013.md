# 列举文件

## 功能介绍

此接口用于列举文件。

## 接口原型

|承载协议|HTTPS GET|
|-----|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|接口方向|开发者服务器->华为服务器|
|接口URL|https://{domain}/{bucket_name} > 注意 > * {bucket_name}为当前存储实例名称。 > * {domain}为接口域名。 >   * 中国站点的域名：ops-server-drcn.agcstorage.link/v0 >   * 德国站点的域名：ops-server-dre.agcstorage.link/v0 >   * 新加坡站点的域名：ops-server-dra.agcstorage.link/v0 >   * 俄罗斯站点的域名：ops-server-drru.agcstorage.link/v0 > * 调用[获取Token](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agcapi-obtain-token-project-0000001477336048)接口时使用的站点必须与本接口使用的站点保持一致。例如本接口使用的站点是德国，即接口域名为"ops-server-dre.agcstorage.link/v0"，则调用[获取Token](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agcapi-obtain-token-project-0000001477336048)接口也必须使用德国站点，其接口域名需为"connect-api-dre.cloud.huawei.com"。|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 请求参数

### Header

|参数|类型|必选(M)/可选(O)|说明|
|:-------------|:-----|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|String|M|客户端ID，获取方法参考[创建API客户端](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-getapicredentials-0000001498508514#section8727185210538)。|
|productId|String|M|项目ID，查询方法可参见[查询项目ID](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-get-developerid-projectid-0000001166543063)。|
|Authorization|String|M|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agcapi-obtain-token-project-0000001477336048)中获取的access_token。|
|X-Agc-Trace-Id|String|O|单个文件请求的Traceid。可不填或者随机生成，用于日志打印跟踪。|

### Query

|参数|类型|必选(M)/可选(O)|说明|
|:--------|:-----|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|max-keys|String|O|指定返回文件个数的最大值，默认值为50，取值范围为[1,1000]。 超出范围时，按照默认值进行处理。 如果因为max-keys的设置无法一次完成列举，返回结果会附加NextMarker元素作为下一次列举的marker。|
|marker|String|O|指定返回哪个标识符之后的文件，按照文件Key的UTF-8字典顺序排序。|
|prefix|String|O|列举以指定的字符串prefix开头的文件。|
|delimiter|String|O|将文件名按照特定字符分割的分割符。 > 注意 > 当前仅支持传空值或正斜杠（/），正斜杠（/）编码后为%2F。 * 如果指定了prefix参数，按delimiter对所有文件名进行分割，多个文件分割后从prefix到第一个delimiter之间相同的部分会形成一条CommonPrefixes。 * 如果未携带prefix参数，按delimiter对所有文件名进行分割，多个文件分割后从文件名开始到第一个delimiter之间相同的部分形成一条CommonPrefixes。|

## 响应参数

|参数|类型|必选(M)/可选(O)|说明|
|:-------------|:-------------------------------------------------------------|:----------|:----------------------------------------------------------------------------|
|status|Integer|M|HTTP响应码，200表示成功。|
|X-Agc-Trace-Id|String|O|单个文件请求的Traceid，与请求参数X-Agc-Trace-Id保持一致。|
|productId|String|M|项目ID。|
|bucket|String|M|存储实例名称。|
|nextMarker|String|O|如果本次没有返回全部结果，响应请求中将包含此字段，用于标明本次请求列举到的最后一个文件。后续请求可以指定Marker等于该值来列举剩余的文件。|
|isTruncated|Boolean|M|表明是否本次返回的ListBucketResult结果列表被截断。 * true：表示本次没有返回全部结果。 * false：表示本次已经返回了全部结果。|
|contents|[Content](#ZH-CN_TOPIC_0000001498518878__p086973141111)[]|M|存储实例中的文件列表。|
|contentType|String|M|文件类型，告诉客户端实际返回内容的类型。|
|commonPrefixes|[CommonPrefix](#ZH-CN_TOPIC_0000001498518878__p183512474399)[]|O|请求中带delimiter参数时返回的CommonPrefixes分组信息。|

**Content**

|参数|类型|必选(M)/可选(O)|说明|
|:-----------|:-----|:----------|:-------|
|key|String|M|文件名|
|size|String|M|文件大小|
|lastModified|String|M|文件最后修改时间|

**CommonPrefix**

|参数|类型|必选(M)/可选(O)|说明|
|:-----|:-----|:----------|:------------------------|
|prefix|String|O|请求中带delimiter参数时返回的分组信息前缀|

## 调用示例

```screen
import com.alibaba.fastjson.JSON;
import com.alibaba.fastjson.JSONObject;

import lombok.Builder;
import lombok.Getter;
import lombok.extern.slf4j.Slf4j;

import org.apache.commons.lang3.StringUtils;
import org.apache.http.Consts;
import org.apache.http.HttpStatus;
import org.apache.http.client.methods.CloseableHttpResponse;
import org.apache.http.client.methods.HttpGet;
import org.apache.http.client.utils.URIBuilder;
import org.apache.http.impl.client.CloseableHttpClient;
import org.apache.http.impl.client.HttpClients;

import java.io.BufferedReader;
import java.io.InputStreamReader;

/**
 * 列举文件REST API示例代码
 */
@Slf4j
public class ListObjectTest {
    /**
     * @param param 列举文件接口入参
     */
    public static void listObjects(String storageUrl, ListObjectsParam param) {
        try {
            URIBuilder uriBuilder = new URIBuilder(storageUrl + param.getBucketName());
            if (StringUtils.isNotEmpty(param.getPrefix())) {
                uriBuilder.addParameter("prefix", param.getPrefix());
            }
            if (StringUtils.isNotEmpty(param.getMaxKeys())) {
                uriBuilder.addParameter("max-keys", param.getMaxKeys());
            }
            if (StringUtils.isNotEmpty(param.getMarker())) {
                uriBuilder.addParameter("marker", param.getMarker());
            }

            HttpGet get = new HttpGet(uriBuilder.build());
            get.setHeader("productId", param.getProjectId());
            get.setHeader("client_id", param.getClientId());
            get.setHeader("Authorization", "Bearer " + param.getToken());

            CloseableHttpClient httpClient = HttpClients.createDefault();
            CloseableHttpResponse httpResponse = httpClient.execute(get);
            int statusCode = httpResponse.getStatusLine().getStatusCode();
            if (statusCode == HttpStatus.SC_OK) {
                BufferedReader br =
                    new BufferedReader(new InputStreamReader(httpResponse.getEntity().getContent(), Consts.UTF_8));
                String result = br.readLine();

                JSONObject object = JSON.parseObject(result);
                log.info("listObjects result:{}", object.toJSONString());
            }
        } catch (Exception e) {
            log.error("listObjects exception:", e);
        }
    }

    public static void main(String[] args) {
        ConstantsTest.preCheck();

        String clientToken = TokenServiceTest.getToken("https://connect-api.cloud.huawei.com/api/", "84903XXXXXX32064",
            "00E5CCADB655891XXXXXXXXXXXX8CDCC83ACF22");
        ListObjectsParam mirrorParam = ListObjectsParam.builder()
            .projectId("73643XXXXXX61998")
            .clientId("84903XXXXXX32064")
            .token(clientToken)
            .bucketName("test-q36q0")
            .prefix("temp")
            .marker("")
            .maxKeys("")
            .build();

        listObjects("https://ops-server-drcn.agcstorage.link/v0/", mirrorParam);
    }

    @Builder
    @Getter
    static class ListObjectsParam {
        // 项目ID
        String projectId;

        // 客户端ID
        String clientId;

        // clientToken
        String token;

        // 云存储实例名
        String bucketName;

        // 列举以指定的字符串prefix开头的文件
        String prefix;

        // 指定返回文件个数的最大值，默认50，取值范围为[1,1000]
        String maxKeys;

        // 指定返回哪个标识符之后的文件，按照文件Key的UTF-8字典顺序排序
        String marker;
    }
}
```
