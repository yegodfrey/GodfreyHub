# AGConnectCloudDBException

用于提供相应的方法供您获取异常相关的信息，包含错误码和详细错误信息。

|Constructor name|
|:-------------------------------------------------------------------------------------------------------------------------------|
|[constructor](#section15829165119278)(errorCode: string, errorMessage? string) 构造一个AGConnectCloudDBException对象，用于定义应用中可能发生的异常信息。|
