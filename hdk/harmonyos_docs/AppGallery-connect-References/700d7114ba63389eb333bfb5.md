# ITags

|Class/Struct Info|
|:--------------------------------------------------------------------------------------------------------------------------------------------------|
|public struct ITags : IEnumerable\<TagType\>, IEquatable\<ITags\> 标签类型集合结构体，主要用于为各模块的标签类型设置或批处理输入标签集合。 继承了IEmunerable\<TagType\>和IEquable\<ITags\>。|

#### Property Summary

|Name|Type|Description|
|:----|:---|:------------|
|Count|int|返回这一组标签类型的数量。|

Sample Code

```
// 创建包含Inactive组件的标签类型集合
var TagSet = ITags.Get<Inactive>();
// Count表示集合中有几种标签类型，该示例中为1
TagSet.Count;
```

#### HasAll

|Method|
|:------------------------------------------------------------------|
|readonly bool HasAll(in ITags iTags) 只读方法。 判断当前标签类型集合是否包含输入的标签类型集合。|

Parameters  

|Name|Type|Description|
|:----|:----|:----------|
|iTags|ITags|标签类型集合。|

Return  

|Type|Description|
|:---|:------------------------------------------|
|bool|* true：表示当前组完全包含输入组。 * false：表示当前组不完全包含输入组。|

Sample Code

```
// 创建标签类型集合
var tagSet1 = ITags.Get<Inactive>();
var tagSet2 = ITags.Get<Inactive, TestTag>();

// 判断当前集合是否完全包含另一集合
tagSet.HasAll(tagSet1); // true
```

#### HasAny

|Method|
|:-------------------------------------------------------------------------|
|readonly bool HasAny(in ITags iTags) 只读方法。 判断当前标签类型集合是否拥有输入的标签类型集合中任意标签类型。|

Parameters  

|Name|Type|Description|
|:----|:----|:----------|
|iTags|ITags|标签类型集合。|

Return  

|Type|Description|
|:---|:-----------------------------------------------|
|bool|* true：表示当前组包含输入组中至少一种类型。 * false：表示当前组完全不包含输入组。|

Sample Code

```
// 创建标签类型集合
var tagSet1 = ITags.Get<Inactive>();
var tagSet2 = ITags.Get<Inactive, TestTag>();

// 判断当前集合与另一集合是否有任意相同组件类型
tagSet1.HasAny(tagSet2); // true
```

#### Add

|Method|
|:---------------------------------------------------------|
|void Add(in ITags iTags) 将输入的标签类型集合包含的所有标签类型，添加到当前标签类型集合中。|

Parameters  

|Name|Type|Description|
|:----|:----|:----------|
|iTags|ITags|标签类型集合。|

Sample Code

```
// 创建标签类型集合
var tagSet1 = ITags.Get<Inactive>();
var tagSet2 = ITags.Get<Inactive, TestTag>();

// 将另一个集合添加到当前集合中，结果等于两个集合的并集，重复标签没有影响
tagSet1.Add(tagSet2); // 此时tagSet1包含Inactive和TestTag
```

#### Remove

|Method|
|:---------------------------------------------------------|
|void Remove(in ITags iTags) 移除当前标签类型集合中，与输入标签类型集合中相同的标签类型。|

Parameters  

|Name|Type|Description|
|:----|:----|:----------|
|iTags|ITags|标签类型集合。|

Sample Code

```
// 创建标签类型集合
var tagSet1 = ITags.Get<Inactive, TestTag1>();
var tagSet2 = ITags.Get<Inactive, TestTag2>();

// 将另一个集合从当前集合中移除，仅移除共同标签，非共同标签没有影响
tagSet1.Remove(tagSet2); // 此时tagSet1包含TestTag1
```

#### ToString

|Method|
|:---------------------------------------------------------|
|string ToString() 将当前标签类型集合的详细信息以字符串形式返回，打印的组件和标签名字均会带命名域。|

Return  

|Type|Description|
|:-----|:-------------|
|string|当前标签类型集合的详细信息。|

Sample Code

```

// 打印集合信息。预设组件/标签命名域为"Pgd."，自定义组件/标签/共享组件根据实际情况而定

```

#### Has\<T1, ...\>

|Method|
|:-------------------------------------------------------------------------|
|readonly bool Has\<T1, ...\>() 只读方法。 判断当前标签类型集合是否包含指定泛型，最多支持10个泛型。 T为ITag。|

Return  

|Type|Description|
|:---|:------------------------------------------------------------|
|bool|* true：表示当前ITags包含所有指定泛型标签类型。 * false：表示当前ITags不完全包含指定泛型标签类型。|

Sample Code

```
// 创建标签类型集合
var tagSet1 = ITags.Get<Inactive, TestTag1>();
// 判断集合是否包含指定标签类型，最多支持一次输入10个标签
tagSet1.Has<Inactive>(); // true
// 输入多个标签时，需要全包含才会返回true，否则为false
tagSet1.Has<Inactive, TestTag2>(); // false
```
