# ListResult

|Interface Info|
|:-----------------------------------------------------|
|export interface ListResult 列举云端目录时，该云端目录包含的文件和目录列表信息。|

## Property Summary

|Name|Type|Mandatory/Optional|Description|
|:---------|:-----------------|:-----------------|:---------------------|
|dirList|StorageReference[]|-|分页查询时返回的目录列表。|
|fileList|StorageReference[]|-|分页查询时返回的文件列表。|
|pageMarker|string | null|Optional|支持null值，分页查询时返回的分页标识符。|
