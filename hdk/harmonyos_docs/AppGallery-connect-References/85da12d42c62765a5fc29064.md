# aesDecTextSync

aesDecTextSync(alg: AESAlg, ciphertext: Uint8Array, key: string \| Uint8Array, iv?: string \| Uint8Array): string

aes解密算法同步方法，返回解密后的明文内容字符串，建议与[aesEncTextSync](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/aesenctextsync-0000002283717198)配套使用。

导入模块：

```
import { aegis } from '@hw-agconnect/petal-aegis';
```

参数：  

|参数名|类型|必填|说明|
|:---------|:-----------------------------------------------------------------------------------------------------------|:-|:---------------------------------------------------------------------------------------------------------------------------|
|alg|[AESAlg](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/aesalg-0000001937542110)|是|AES模式枚举。|
|ciphertext|Uint8Array|是|[aesEncText](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/aesenctext-0000001964620489)生成的密文内容。|
|key|string或Uint8Array|是|密钥内容，hexstring或Uint8Array格式， 长度请参考模式AESAlg的密钥长度（bit）。|
|iv|string或Uint8Array|否|iv偏移量内容，hexstring或Uint8Array格式，如果传入IV，返回结果的密文中不会携带iv，如果不传入iv，返回的密文结果会携带自动生成的IV，GCM IV长度为12字节，其它模式都是16字节。|

返回值：  

|参数|类型|说明|
|:----------|:-----|:---------|
|decryptText|String|解密后的明文字符串。|

示例：

```
import { aegis } from '@hw-agconnect/petal-aegis';
import { buffer } from '@kit.ArkTS';

async function demo() {
  let plainText = 'hello world'; //待加密内容
  let key = '1234567891234567'; //长度16字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let iv = '9876543217654321'; //长度16字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let keyUint8 = new Uint8Array(buffer.from(key, 'utf-8').buffer);
  let ivUint8 = new Uint8Array(buffer.from(iv, 'utf-8').buffer);

  try {
    let encryptText = aegis.aesEncTextSync(aegis.AESAlg.AES_CBC_PKCS7Padding, plainText, keyUint8);
    //aescbc  encryptText: 35,204,237,168,114,75,125,247,48,60,27,226,40,172,160,171,58,169,209,168,124,178,73,56,45,191,121,223,135,44,74,126,204
    console.log("aescbc ", 'encryptText: ' + encryptText);

    let decryptText = aegis.aesDecTextSync(aegis.AESAlg.AES_CBC_PKCS7Padding, encryptText, keyUint8);

    if (plainText === decryptText) {
      console.info('decrypt ok');
    }
    console.log("aescbc ", 'decryptText: ' + decryptText);
  } catch (err) {
    console.log("aescbc ", 'err: ' + err);
  }
}
```
