# Indexes

|interface info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public @interface Indexes 定义对象类型的索引。 您不需要调用该方法设置索引，您在AppGallery Connect控制台创建对象类型时，已经设置索引，详细请参见[管理对象类型](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-agcconsole-objecttypes-0000001127675459)。创建对象类型后，只需要从AppGallery Connect控制台导出用于开发Server端服务的java类型文件，添加至本地开发环境，即可实现本地开发环境中对象类型的定义和创建。|
