# sm4EncTextHex

sm4EncTextHex(alg: SM4Alg, plaintext: string, key: string \| Uint8Array, iv?: string \| Uint8Array): Promise\<string\>

sm4加密算法，返回16进制的hex string格式密文，建议与[sm4DecTextHex](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/sm4dectexthex-0000001937701458)配套使用。

导入模块：

```
import { aegis } from '@hw-agconnect/petal-aegis';
```

参数：  

|参数名|类型|必填|说明|
|:--------|:-----------------------------------------------------------------------------------------------------------|:-|:--------------------------------------------------------------------------------------|
|alg|[SM4Alg](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/sm4alg-0000001937701454)|是|SM4模式枚举。|
|plaintext|string|是|明文普通字符串。|
|key|string或Uint8Array|是|密钥内容，hexstring或Uint8Array格式， 长度请参考模式SM4Alg的密钥长度（bit）。|
|iv|string或Uint8Array|否|iv偏移量内容，hexstring或Uint8Array格式，如果传入IV，返回结果的密文中不会携带iv，如果不传入iv，返回的密文结果会携带自动生成的IV，长度为16字节。|

返回值：  

|参数|类型|说明|
|:----------|:--------|:------|
|encryptText|hexString|加密后的密文。|
