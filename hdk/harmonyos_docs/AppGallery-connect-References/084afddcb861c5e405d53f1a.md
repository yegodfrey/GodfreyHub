#### Methods

#### credentialWithPassword

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|static [credentialWithPassword](#section571196104114)(countryCode:string,phoneNumber:string,password:string):[AGConnectAuthCredential](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-agconnectauthcredential-0000001471238990) 通过手机账号和密码获取凭证。|

Parameters  

|Name|Description|
|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|countryCode|国际电话区号，例如中国为86，德国49，俄罗斯7，新加坡65。 本字段支持多种格式（以中国为例），例如"86"，"+86"。|
|phoneNumber|手机号码，需要去掉"+"号 和国家（地区）码，例如："+86132xxxxxxxx"，则取值"132xxxxxxxx"。|
|password|密码。 默认密码规则如下，若您参考[安全配置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-security-configuration-0000001324925609)自定义了密码复杂度请满足自定义的复杂度： 1. 密码长度至少8个字符。 2. 密码必须包含如下至少两种字符的组合： * 至少一个小写字母 * 至少一个大写字母 * 至少一个数字 * 至少一个特殊字符：\`!@#$%\^\&\*()-_=+\\\|\[{}\];:'",\<.\>/? 和空格 3. 密码不能和手机号码或者邮箱地址一样。|

Return  

|Type|Description|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------|:----------|
|[AGConnectAuthCredential](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-agconnectauthcredential-0000001471238990)|AGC凭证。|

Sample Code

```
PhoneAuthProvider.credentialWithPassword('countryCode', 'phoneNumber', 'password')
```
