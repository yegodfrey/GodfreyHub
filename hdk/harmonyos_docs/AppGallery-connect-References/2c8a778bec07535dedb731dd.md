# FrameFlow_GrabPerFrameData

|Function Info|
|:----------------------------------------------------------------------------------------------|
|FFResult FrameFlow_GrabPerFrameData(FFInstance instance, FFGrabInfo const \*pGrabInfo); 隐式抓取数据。|

|Name|Description|
|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------|
