# GetAvailableRoomsConfig

|Class Info|
|:-------------------------------------------------------------------------------|
|namespace Com.Huawei.Game.Gobes public class GetAvailableRoomsConfig 查询可用房间参数配置。|

#### Property Summary

|Name|Type|Mandatory/Optional|Description|
|:-----------|:-------------|:-----------------|:-------------------------------------------------------------------------------|
|RoomType|string|Optional|房间类型。|
|Offset|string|Optional|偏移量，使用房间的createTime作为每次请求的标记，第一次请求时为0。|
|Limit|int?|Optional|单次请求获取的房间数量，不选时服务端默认为20。|
|Sync|boolean|Optional|是否返回帧同步中的房间。 * true：返回的房间列表中将包含帧同步中的房间和空闲的房间。 * false：返回的房间列表中仅包含空闲的房间。 默认为true。|
|RoomTypeList|list\<string\>|Optional|房间类型列表。|
