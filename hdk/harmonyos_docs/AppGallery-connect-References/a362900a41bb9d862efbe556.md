# FFDrawFrameTargetCameraInfo

目标帧的相机信息。

**Structure Declaration**

```screen
typedef struct FFDrawFrameTargetCameraInfo {
    // Type of this structure, must be `FF_STRUCTURE_TYPE_PER_FRAME_TARGET_CAMERA_INFO`.
    FFStructureType    sType;
    // Pointer to the next structure in extension chain or NULL.
    const void*        pNext;
    // Provide camera view projection matrix for next/predicted frame
    FFMat4x4           targetViewProj;
} FFDrawFrameTargetCameraInfo;
```

**Members**

|Name|Mandatory/Optional|Description|
|:-------------|:-----------------|:----------------------------------------------------------------------------|
|sType|必填|此结构体类型必须为**FF_STRUCTURE_TYPE_PER_FRAME_TARGET_CAMERA_INFO**。|
|pNext|选填|指向扩展链中的下一个结构体的指针。扩展参数，可缺省，默认值为NULL。|
|targetViewProj|必填|相机投影矩阵，对应于从世界空间坐标（World Space Coordinates）到剪辑空间坐标（Clip Space Coordinates）的转换。|
