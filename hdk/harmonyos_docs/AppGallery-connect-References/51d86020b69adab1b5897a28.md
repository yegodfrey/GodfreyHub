# 按条件查询商品信息

## 功能介绍

此接口用于商品查询，支持多条件过滤，根据productNo和AppId唯一查询一个商品信息。

## 使用约束

接口调用者的角色：账号持有者、管理员、APP管理员、运营。

## 接口原型

|承载协议|HTTPS POST|
|-----|-----------------------------------------------------------------------------------------|
|接口方向|开发者服务器->数字商品服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/pms/product-price-service/v2/manage/product/list|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|

## 请求参数

### Header

> 说明
>
> API Client和OAuth Client区别参见[使用入门](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114)。

**API Client方式**

|参数|必选(M)/可选(O)|类型|描述|
|:------------|:----------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|M|String|客户端ID，获取方法参考[创建API客户端](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section103mcpsimp)。|
|Authorization|M|String|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)中获取的access_token。|
|appId|M|String|应用ID，获取方法参考[查询应用信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/appgallery_queryappinfo)。|

**OAuth Client方式**

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
|oauth2Token|M|String|认证信息，传入[获取用户授权码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section949717114392)中获取的Access Token。|
|appId|M|String|应用ID，获取方法参考[查询应用信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/appgallery_queryappinfo)。|

### Body

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:-----------|:----------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|requestId|M|String(64)|请求序列，开发者自定义唯一标识符。|
|productNo|O|String|查询应用内指定商品标识的商品，如果不传值默认查询所有应用内商品。支持多个商品标识过滤查询，使用英文逗号分隔。|
|productName|O|String(55)|待查询的商品名称，支持按关键字模糊查询。不支持特殊字符|。|
|purchaseType|O|String|如果查多种商品类型，使用英文逗号分隔，取值如下： * consumable：消耗型 * auto_subscription：自动续期型 * non_consumable：非消耗型 * non_renewing_subscription：非续期订阅型|
|status|O|String|如果查多种商品状态，使用英文逗号分隔，取值如下： * active：在线 * inactive：下线 * delete：删除 * drafts: 草稿 * toBeSubmitted: 待提交 * underReview：审核中 * rejected: 审核不通过|
|orderBy|O|String|按名称升序或者降序排序。配置JSON对象，key为属性名，value为排序规则。不传值时默认按照数据库中创建时间降序。 * key取值范围为： * price：价格 * updateTime：更新时间 * value取值desc降序或者asc升序 例如：按价格price升序，更新时间updateTime降序, 则配置为{"price": "asc","updateTime": "desc"}|
|beginTime|O|String|商品更新开始时间，格式为：yyyy-MM-dd HH:mm:ss。|
|endTime|O|String|商品更新结束时间，格式为：yyyy-MM-dd HH:mm:ss。 beginTime和endTime设置后可以查询出updateTime在此时间段内的商品。|
|pageNum|O|Integer|请求查询的起始页码，默认值：1。|
|pageSize|O|Integer|每页请求数目，默认每页20条，最大不能超过300。|
|country|M|String|将商品价格转为该国家的价格进行展示。 请参见[国家/地区、语言、币种列表](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-supported-countries-overview-0000001146718725)，例如US、CN。|
|groupId|O|String|订阅组ID，如果不为空，则仅查询该组下商品。|

## 调用示例

```screen
"Java"
public static ProductQueryResp getProductInfos(String domain, String clientId, String authorization, String appId, 
    ProductQueryReq request) { 
    ProductQueryResp resp = null;  
    try {  
        String url = domain + "/api/pms/product-price-service/v2/manage/product/list";  
        HttpPost post = new HttpPost(url);  
        post.setHeader(new BasicHeader("Authorization", "Bearer " + authorization));  
        post.setHeader(new BasicHeader("client_id", clientId));  
        post.setHeader(new BasicHeader("appId", appId)); // 使用appId

        StringEntity entity = new StringEntity(JSON.toJSONString(request),  
            ContentType.create("application/json", "UTF-8"));  
        post.setEntity(entity);  

        CloseableHttpClient httpClient = HttpClients.createDefault();  
        HttpResponse response = httpClient.execute(post);  
        int statusCode = response.getStatusLine().getStatusCode();  
        if (statusCode == HttpStatus.SC_OK) {  
            String result = EntityUtils.toString(response.getEntity(), Consts.UTF_8);  
            resp = JSON.parseObject(result, ProductQueryResp.class);  
        }  
        post.releaseConnection();  
        httpClient.close();  
    } catch (Exception e) {  
        e.printStackTrace(); // 打印异常信息，以便调试
    }  
    return resp;  
}
```
