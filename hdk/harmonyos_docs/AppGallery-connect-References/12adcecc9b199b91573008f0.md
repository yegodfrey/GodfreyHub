## Public Methods

### sign

|Method|
|:-----------------------------------------------------------------------------------------------------------|
|public AGCAuthJwtToken sign(String uid, String displayName, String photoUrl, String privateKey) 生成JWT token。|

**Parameters**

|Name|Description|
|:----------|:--------------------|
|uid|用户唯一标识，不能为空，最大长度1024。|
|displayName|用户昵称，可以为空，最大长度1024。|
|photoUrl|头像地址，可以为空，最大长度2048。|
|privateKey|私钥，不能为空。|

**Return**

|Type|Description|
|:--------------|:------------------------|
|AGCAuthJwtToken|JWT token对象，包含token和过期时间。|

### verifyAccessToken

|Method|
|:------------------------------------------------------------------------------------------|
|public AuthAccessToken verifyAccessToken(String accessToken, boolean checkRevoked) 验证Token。|

**Parameters**

|Name|Description|
|:-----------|:------------------------------------|
|accessToken|用户访问令牌，不能为空，端侧用户登录时产生。|
|checkRevoked|校验用户访问令牌是否被撤销，true去认证服务云侧校验，false不校验。|

**Return**

|Type|Description|
|:--------------|:----------|
|AuthAccessToken|验证TOKEN结果。|
