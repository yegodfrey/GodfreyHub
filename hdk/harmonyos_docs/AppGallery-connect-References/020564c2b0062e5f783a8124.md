# FeatureTask

|Class Info|
|:-----------------------------------------------------------|
|public abstract class FeatureTask<TResult> 表示执行一次动态加载的任务抽象类。|

|Qualifier and Type|Method Name and Description|
|:------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------|
|boolean|[isComplete](#section572462412275)() 判断该动态加载任务是否已经执行结束。|
|boolean|[isSuccessful](#section1874214206287)() 判断该动态加载任务是否已经执行成功。|
|Object|[getResult](#section8596597287)() 获取该动态加载任务的执行结果。|
|Exception|[getException](#section2302113562918)() 如果该任务执行失败，获取关于失败信息的Exception实例。|

## Public Methods

### isComplete

|Method|
|:---------------------------------------------|
|public boolean isComplete() 判断该动态加载任务是否已经执行结束。|

**Return**

|Type|Description|
|:------|:----------------------------|
|boolean|true表示该任务已经执行结束，false表示任务未结束。|

### isSuccessful

|Method|
|:-----------------------------------------------|
|public boolean isSuccessful() 判断该动态加载任务是否已经执行成功。|

**Return**

|Type|Description|
|:------|:---------------------------|
|boolean|true表示该任务已经执行成功，false表示执行失败。|

### getResult

|Method|
|:----------------------------------------|
|public Object getResult() 获取该动态加载任务的执行结果。|

**Return**

|Type|Description|
|:-----|:------------|

### getException

|Method|
|:----------------------------------------------------------------|
|public Exception getException() 如果该任务执行失败，可以获取关于失败信息的exception实例。|

**Return**

|Type|Description|
|:--------|:-----------------|

### addOnListener

|Method|
|:-------------------------------------------------------------------------------------------------------------------------|
|public FeatureTask<TResult> addOnListener(OnFinishListener<TResult> onFinishListener) 为该任务添加监听器，监听任务的执行情况。默认在主线程对该监听器进行回调。|

**Parameters**

|Name|Description|
|:---------------|:--------------|
|onFinishListener|监听任务执行状态的监听器实例。|

**Return**

|Type|Description|
|:-------------------|:--------------------|
|FeatureTask<TResult>|返回本次操作的FeatureTask对象。|

### addOnListener

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------|
|public FeatureTask<TResult> addOnListener(Executor executor, OnFinishListener<TResult> onFinishListener) 为该任务添加监听器，监听任务的执行情况。并在指定线程中对该监听器进行回调。|

**Parameters**

|Name|Description|
|:---------------|:--------------|
|executor|监听器回调时所在的线程执行器。|
|onFinishListener|监听任务执行状态的监听器实例。|

**Return**

|Type|Description|
|:-------------------|:--------------------|
|FeatureTask<TResult>|返回本次操作的FeatureTask对象。|
