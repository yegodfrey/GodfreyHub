# HMFTasks

|Class Info|
|:---------------------------------------------------------------------------------------------------------------------------------|
|任务调用封装。 Objective-C ``` @interface HMFTasks<__covariant TResult> : NSObject ``` Swift ``` open class Tasks<TResult> : NSObject ```|

#### +await:error:

同步等待任务结果，不可以在主线程调用。

Objective-C

```
+ (id _Nullable)await:(nonnull HMFTask<TResult> *)task
                error:(NSError *_Nullable *_Nullable)error;
```

Swift

```
class func await(_ task: Task<TResult>) throws -> Any
```

Parameters  

|Name|Description|
|:----|:-----------------------------|
|task|要等待的任务。|
|error|任务超时或者在主线程调用错误 @result 任务执行结果。|
