# ProductsQueryInfo

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:-----------------|:----------|:------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|id|M|String|商品ID，PMS内部生成。|
|productNo|M|String|开发者自定义商品标识，跟appId唯一确定一个商品。|
|productName|M|String|商品名称。|
|price|M|String|价格，单位为分。|
|purchaseType|M|String|商品类型，取值范围： * consumable：消耗型 * auto_subscription：自动续期型 * non_consumable：非消耗型 * non_renewing_subscription：非续期订阅型 * subscription：非自动续期类型（预留字段，暂未使用）|
|resourceType|M|Integer|资源类型，固定取值： 7：IAP（应用内虚拟商品）|
|localPrice|M|String|商品展示价格，包含商品实际价格和货币单位，预留字段。|
|updateTime|M|String|商品更新时间，格式为：yyyy-MM-dd HH:mm:ss。|
|status|M|String|商品状态，取值范围： * active：在线 * inactive：下线 * delete：删除 <!-- --> * drafts: 草稿 * toBeSubmitted: 待提交 * underReview：审核中 * rejected: 审核不通过|
|currency|M|String|用于支付的默认币种，请参见[国家/地区、语言、币种列表](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-supported-countries-overview-0000001146718725)。 例如：USD、CNY、MYR。|
|country|M|String|默认国家码，用于区分国家信息，请参见[国家/地区、语言、币种列表](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-supported-countries-overview-0000001146718725)。 例如CN。|
|defaultLocale|M|String|默认语言环境，请参见[国家/地区、语言、币种列表](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-supported-countries-overview-0000001146718725)。 例如：zh_CN、en_US。|
|productDesc|M|String|默认商品描述信息。|
|isPromotion|M|Integer|是否有正在生效的促销。|
|groupId|M|String|订阅组ID。|
|periodUnit|M|String|订购周期单位，采用[ISO8601](https://www.iso.org/iso-8601-date-and-time-format.html)格式指定，取值范围： * D：天 * W：周 * M：月 * Y：年|
|numberOfUnits|M|Integer|订购周期。 例如：订阅周期为2个月，则numberOfUnits=2， periodUnit=M。|
|developerId|M|String|开发者账号。|
|intRejectedType|O|Integer|审核拒绝类型，取值如下： * 0：商品审核失败 * 1：关联应用审核失败|
|productOnShelfType|O|String|该商品是否审核通过，取值如下： * 1：首次上架 * 2：变更场景|
|rejectedReasons|O|String|审核拒绝原因。|
