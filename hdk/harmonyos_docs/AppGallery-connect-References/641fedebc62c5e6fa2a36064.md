#### Methods

#### credentialWithPassword

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|static credentialWithPassword(countryCode:string,phoneNumber:string,password:string):[AGConnectAuthCredential](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauthcredential-web-0000001054104571) 通过手机号和密码获取凭证。|

Parameters  

|Name|Description|
|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|countryCode|国际电话区号，例如中国为86，德国49，俄罗斯7，新加坡65。 本字段支持多种格式（以中国为例）：86，+86。|
|phoneNumber|手机号，需要去掉"+"号 和国家（地区）码，例如：+86132xxxxxxxx，则取值132xxxxxxxx。|
|password|密码。 默认密码规则如下，若您参考[安全配置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-security-configuration-0000001324925609)自定义了密码复杂度请满足自定义的复杂度： 1. 密码长度至少8个字符； 2. 密码必须包含如下至少两种字符的组合： * 至少一个小写字母； * 至少一个大写字母； * 至少一个数字； * 至少一个特殊字符：\`!@#$%\^\&\*()-_=+\\\|\[{}\];:'",\<.\>/? 和空格。 3. 密码不能和手机号码或者邮箱一样。|

Return  

|Type|Description|
|:-------------------------------------------------------------------------------------------------------------------------------------------------|:------------|
|[AGConnectAuthCredential](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauthcredential-web-0000001054104571)|AGConnect 凭证。|

Sample Code

```
agconnect.auth.PhoneAuthProvider.credentialWithPassword('countryCode', 'phoneNumber', 'password')
```

#### credentialWithVerifyCode

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|static credentialWithVerifyCode(countryCode:string,phoneNumber:string, password:string, verifyCode:string):[AGConnectAuthCredential](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauthcredential-web-0000001054104571) 通过手机号和验证码获取凭证。|

Parameters  

|Name|Description|
|:----------|:-------------------------------------------------------|
|countryCode|国际电话区号，例如中国为86，德国49，俄罗斯7，新加坡65。 本字段支持多种格式（以中国为例）：86，+86。|
|phoneNumber|手机号，需要去掉"+"号 和国家（地区）码，例如：+86132xxxxxxxx，则取值132xxxxxxxx。|
|password|密码（可选）。 * 如果没有携带密码，则仅通过验证码校验。 * 如果携带了密码，则密码和验证码都会校验。|
|verifyCode|验证码。|

Return  

|Type|Description|
|:-------------------------------------------------------------------------------------------------------------------------------------------------|:-----------|
|[AGConnectAuthCredential](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauthcredential-web-0000001054104571)|AGConnect凭证。|

Sample Code

```
agconnect.auth.PhoneAuthProvider.credentialWithVerifyCode('countryCode', 'phoneNumber', 'password', 'verifyCode')
```

#### requestVerifyCode

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|static requestVerifyCode(countryCode:string, phoneNumber:string, action: number, lang: string, sendInterval: number):Promise\<[VerifyCodeResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/verifycoderesult-web-0000001054104573)\> 申请手机的验证码。 此方法已废弃，请调用[AGCAuth.requestPhoneVerifyCode](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section61992041193415)(countryCode:string, phoneNumber:string, action: number, lang: string, sendInterval: number)|

Parameters  

|Name|Description|
|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------|
|countryCode|国际电话区号，例如中国为86，德国49，俄罗斯7，新加坡65。 本字段支持多种格式（以中国为例）：86，+86。|
|phoneNumber|手机号，需要去掉"+"号 和国家（地区）码，例如：+86132xxxxxxxx，则取值132xxxxxxxx。|
|action|验证码属性的配置，包括验证码应用场景（注册登录或者重置密码） 验证码类型。 * agconnect.auth.Action.ACTION_REGISTER_LOGIN：登录/注册 * agconnect.auth.Action.ACTION_RESET_PASSWORD：重置密码|
|lang|发送验证码的语言，例如：zh_CN。|
|sendInterval|发送验证码的时间间隔，单位秒，支持30\~120秒。|

Return  

|Type|Description|
|:----------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------|
|Promise\<[VerifyCodeResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/verifycoderesult-web-0000001054104573)\>|VerifyCodeResult的异步返回对象。|

Sample Code

```
agconnect.auth.PhoneAuthProvider.requestVerifyCode('countryCode','phoneNumber',agconnect.auth.Action.ACTION_REGISTER_LOGIN,'lang',sendInterval）
```
