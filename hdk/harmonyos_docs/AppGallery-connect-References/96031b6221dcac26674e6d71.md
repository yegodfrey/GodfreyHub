# AGCInstance

|Qualifier and Type|Method Name and Description|
|:----------------------|:---------------------------------------------------------------------------------------------------------------|
|AGCInstance|[configInstance](#section37852571484)(config: AGConnectServicesConfig) AGC SDK初始化应用配置信息。|
|AGConnectServicesConfig|[config](#section131584351693)() 获取AGC SDK应用配置信息。|
|void|[setApiKey](#section151366539915)(apiKey: string) AGC SDK设置api_key。|
|void|[setClientSecret](#section54111220107)(clientSecret: string) AGC SDK设置client_secret。|
