# GetFileMetadataResponse

|Interface Info|
|:----------------------------------------------------|
|export type GetFileMetadataResponse 获取云端文件元数据请求的响应结果。|

## Property Summary

|Name|Type|Mandatory/Optional|Description|
|:-----------------|:------------------------|:-----------------|:----------------------------------------------------------|
|cacheControl|string|Optional|下载文件时服务器响应的网页缓存的行为。详情请参见HTTP协议中关于Cache-Control的定义。|
|contentDisposition|string|Optional|下载文件时服务器响应的保存到本地的文件名称。详情请参见HTTP协议中关于Content-Disposition的定义。|
|contentEncoding|string|Optional|下载文件时服务器响应的内容编码格式。详情请参见HTTP协议中关于Content-Encoding的定义。|
|contentLanguage|string|Optional|下载文件时服务器响应的内容语言格式。详情请参见HTTP协议中关于Content-Language的定义。|
|contentType|string|Optional|下载文件时服务器响应的文件类型。详情请参见HTTP协议中关于Content-Type的定义。|
|metadata|{ [key: string]: string;}|Optional|用户自定义的元数据结构，采用key-value结构保存。需要符合标准HTTP头部的规范。|
