# 删除频道属性

## 功能介绍

调用此接口可删除指定频道属性。

## 接口原型

|承载协议|HTTPS POST|
|-----|----------------------------------------------------------------------------------|
|接口方向|开发者服务器->华为RTM服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/grtm/openapi/rtm/{appId}/channel/property|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 请求参数

### Path

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----|:----------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------|
|appId|M|String(32)|应用ID，获取方法请参见[准备游戏信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-gameinformation-0000001327081581)。|

### Header

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|requestId|M|String|当前请求的唯一标识。|
|Authorization|M|String|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token为[获取Token（团队级）](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-obtaintoken-restapi-0000001624528617)中获取的access_token。|
|client_id|M|String|客户端ID，获取方法请参见[创建API客户端](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/creating-api-client-0000001738812141)。|

### Body

|参数名称|必选（M）/可选（O）|参数类型|参数说明|
|:-----------|:----------|:----------------|:-----------------------------------------|
|channelId|M|String(32)|需要删除属性的频道ID，仅支持数字(0-9)、字母(A-Z,a-z)和下划线(_)。|
|propertyKeys|M|List<String(100)>|需要删除的频道属性Key，支持任意字符串类型，最多支持删除5个频道属性|


## 响应参数

|参数|类型|必选(M)/可选(O)|说明|
|:---------------------------------------------------|:-----|:----------|:-----------------------------------------------------------------|
|[ret](#ZH-CN_TOPIC_0000001744721649__p1176072213012)|String|M|包含返回码及描述信息的JSON字符串，格式为{"code":*retcode* , "msg": "*description*"}。|

**ret参数说明**

|参数|必选（M）/可选（O）|参数类型|描述|
|:---|:----------|:-----|:------------------------------------------|
|code|M|int|返回码。 * 0：消息成功发送到RTM服务器。 * 1002：requestId重复。|
|msg|M|string|描述信息。|

## 响应示例

```screen
{
    "ret": {
        "code": 0,
        "msg": "success"
    }
}
```

## 调用示例

```screen
String url = "https://connect-api.cloud.huawei.com/api/grtm/openapi/rtm/400617443/channel/property"; 
String clientId = "1167324******62048";
String token = "eyJraWQiO******INo1BWONahbY";
Unirest.setTimeouts(0, 0);
HttpResponse<String> response = Unirest.delete(url)
.header("authorization", "Bearer " + token)
.header("client_id", clientId)
.header("content-type", "application/json")
.header("requestid", String.valueOf(new Random().nextLong()))
.body("{\n  \"channelId\": \"channelId\",\n  \"propertyKeys\": [ \n \"key1\" \n,\"key2\" \n ] \n }")
.asString();

String result = response.getBody();
System.out.println(result);
```
