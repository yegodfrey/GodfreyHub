# FFObjectMatrixPair

物体矩阵对信息。  
Structure Declaration

```
typedef struct FFObjectMatrixPair {
    uint8_t objectId;
    FFMat4x4 localToWorld;
    FFMat4x4 worldToLocal;
} FFObjectMatrixPair;
```

Members  

|Name|Mandatory/Optional|Description|
|:-----------|:-----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|objectId|Mandatory|此矩阵对所属物体的模板值。该值（例如x）必须在上一次调用[FrameFlowVK_SetStencilRemapInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflowvk-setstencilremapinfo-0000001791334684)函数时，被设置为具有FF_STENCIL_VALUE_SEMANTIC_REPROJECTIBLE_DYNAMIC_OBJECT的属性，并且在FFStencilRemapInfo::remapTable\[x\]中进行了重新映射。|
|localToWorld|Mandatory|物体从局部坐标（Local Coordinates）到世界坐标（World Coordinates）的变换矩阵。|
|worldToLocal|Mandatory|物体从世界坐标（World Coordinates）到局部坐标（Local Coordinates）的变换转换。|
