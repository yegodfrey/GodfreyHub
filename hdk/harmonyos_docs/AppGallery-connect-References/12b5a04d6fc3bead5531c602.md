# FFCvvZSemanticInfo

Z轴可视坐标范围信息。

Structure Declaration

```
typedef struct FFCvvZSemanticInfo {
    FFStructureType sType;
    const void* pNext;
    FFCvvZSemantic semantic;
} FFCvvZSemanticInfo;
```

Members  

|Name|Mandatory/Optional|Description|
|:-------|:-----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
|sType|Mandatory|此结构体类型必须为FF_STRUCTURE_TYPE_CVV_Z_SEMANTIC_INFO。|
|pNext|Optional|指向扩展链中的下一个结构体的指针。扩展参数，可缺省，默认值为NULL。|
|semantic|Mandatory|规则观察体的Z轴可视坐标范围（以及深度测试方式），具体请参见[FFCvvZSemantic](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffcvvzsemantic-vulkan-0000001838253893)。|
