### getRoom

|Method|
|:------------------------------------|
|getRoom(roomId: string): Room 获取房间信息。|

**Parameters**

|Name|Description|
|:-----|:----------|
|roomId|房间ID。|

**Return**

|Type|Description|
|:---|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Room|房间信息，包含房间的roomId、status、roomType、players、ownerId。 * roomId：房间ID。 * status：房间状态，0表示房间正常，1表示房间被禁言。 * roomType: 房间类型，1表示小队房间，2表示国战房间。 * players：房间成员数组，PlayerInfo类型，包含playerId。 * openId：玩家ID。 * isForbidden：是否被禁言。 * playerRole：国战房间中的角色，小队房间无此字段。 * ownerId：房主游戏多媒体账号ID。|

**Sample Code**

```screen
const gameMediaEngine = await GameMediaEngine.create(options);
const room: Room = gameMediaEngine.getRoom(roomId);
const {ownerId, roomType, players} = room;
```

### enableSpeakersDetection

|Method|
|:--------------------------------------------------------------------------------|
|enableSpeakersDetection(roomId: string, interval: number): void 开启检测发言玩家，默认为关闭状态。|

**Parameters**

|Name|Description|
|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|roomId|房间ID。|
|interval|统计周期，单位：毫秒，取值范围[100, 10000]，如果为0时则表示关闭音量统计。 > 说明 > * 在小队房间中，使用此参数设置音量统计周期时，取值为0表示关闭音量统计，其它数值均表示开启音量统计。 > * 此参数仅表示统计周期，并不表示触发周期。只有统计结果发生变化时，才会触发speakersDetection事件回调。|

**Sample Code**

```screen
const gameMediaEngine = await GameMediaEngine.create(options);
// 以200毫秒为周期检测音量信息
gameMediaEngine.enableSpeakersDetection(roomId, 200);
// 监听音量检测结果
gameMediaEngine.on('speakersDetection', (roomId: string, volumeInfos: volumeInfo[]) => {
  // 收到音量检测结果
});
```
