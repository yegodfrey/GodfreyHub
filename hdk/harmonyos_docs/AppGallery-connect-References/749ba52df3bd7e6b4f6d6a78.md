#### Methods

#### credentialWithPassword

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|static credentialWithPassword(email:string, password:string):[AGConnectAuthCredential](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts6-agconnectauthcredential-0000001604105085) 通过邮箱账号和密码获取凭证。|

Parameters  

|Name|Description|
|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|email|邮箱账号。|
|password|密码。 默认密码规则如下，若您参考[安全配置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-security-configuration-0000001324925609)自定义了密码复杂度请满足自定义的复杂度： 1. 密码长度至少8个字符。 2. 密码必须包含如下至少两种字符的组合： * 至少一个小写字母 * 至少一个大写字母 * 至少一个数字 * 至少一个特殊字符：\`!@#$%\^\&\*()-_=+\\\|\[{}\];:'",\<.\>/? 和空格 3. 密码不能和手机号码或者邮箱地址一样。|

Return  

|Type|Description|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|:----------|
|[AGConnectAuthCredential](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts6-agconnectauthcredential-0000001604105085)|AGC凭证。|

Sample Code

```
EmailAuthProvider.credentialWithPassword('email', 'password')
```

|verifyCode|验证码。|
