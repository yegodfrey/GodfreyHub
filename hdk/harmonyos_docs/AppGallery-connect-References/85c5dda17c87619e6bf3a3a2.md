# 用户登录

## 功能介绍

该接口用于用户使用账号密码登录。

## 接口原型

|承载协议|HTTPS POST|
|:----|:-----------------------------------------------------------------------|
|接口方向|应用客户端 -> 华为认证服务器|
|接口URL|https://connect-drcn.dbankcloud.cn/agc/apigw/oauth2/third/v1/user-signin|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 请求参数

### Query

|参数名称|必选(M)/可选(O)|参数类型|参数说明|
|:--------|:----------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------|
|productId|M|String|项目ID，查询方法可参见[查询项目ID](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-developerid-projectid-0000001166543063)。|

### Header

|参数名称|必选(M)/可选(O)|参数类型|参数说明|
|:------------|:----------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|M|String|客户端ID，获取方法参考[获取客户端API授权](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-restapi-0000001518509166#section18502104612500)。|
|Authorization|M|String|认证信息。格式为"Authorization: Bearer ${access_token}"。 * access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-obtaintoken-rest-0000001446607602)中获取的access_token。|

### Body

|参数名称|必选（M）/可选（O）|参数类型|参数说明|
|:-------------|:----------|:------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|provider|M|integer|账号授权提供方，取值及对应认证方式如下： * 0：匿名账号 * 1：华为账号 * 2：Facebook* * 3：Twitter* * 4：微信 * 5：华为游戏 * 6：QQ * 7：微博 * 8：Google* * 9：Google Play Game* * 10：自建账号 * 11：手机 * 12：邮箱 * 13：苹果账号 > 说明 > *星号标记的账号类型仅在海外站点支持，当您选择数据处理位置为德国、新加坡或俄罗斯时可以使用这些认证方式。|
|token|M|String|手机号码或者邮箱账号。|
|extraData|O|String|扩展字段，此处用于密码登录时填写密码，填写样例如 {\"password\":\"xxxxxxxxx\"}。|
|autoCreateUser|O|integer|是否自动创建用户，仅用于非托管账号。 * 0：不自动创建用户。 * 1：默认值，自动创建用户。|
|useJwt|M|integer|使用账号凭据JWT(Json Web Token)，固定传入"1"。|
|channelId|O|String|渠道标识，当前渠道划分为华为渠道、AppStore渠道以及GooglePlay渠道。当从这些渠道SDK登录时，该参数有值。|
|aaId|O|String|应用实例唯一编号。|

**请求示例**

```screen
POST agc/apigw/oauth2/third/v1/user-signin
content-type: application/json
productId: 99************83
client_id: 680************560
Authorization: Bearer ***
host: connect-drcn.dbankcloud.cn
{
	"provider": 0,
	"token": "string",
	"extraData": "string",
	"autoCreateUser": 0,
	"useJwt": 1,
	"channelId": "string",
	"aaId": "string"
}
```

## 响应参数

|参数|必选（M）/可选（O）|参数类型|描述|
|:-----------|:----------|:---------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|ret|O|String(100)|包含返回码及描述信息的JSON字符串。格式为{"code":*retcode* , "msg": "*description*"}。 * retcode为返回码。 * description为返回码描述信息。返回码请参见[错误码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-error-code-rest-0000001454149360)。|
|accessToken|O|String(100)|JSON字符串。格式为{"token": "string", "validPeriod": "string" }。 * token为用户凭据。 * validPeriod为token有效时长，单位为秒。|
|refreshToken|O|String(100)|JSON字符串。格式为{"token": "string", "validPeriod": "string"}。 * token为用户凭据。 * validPeriod为token有效时长，单位为秒。|
|userInfo|O|list<[UserInfo](#section1967861214174)>|用户信息。|
|providers|O|list<[ProviderUserInfo](#section164071284365)>|第三方的认证信息。|

### UserInfo

|参数|必选（M）/可选（O）|参数类型|描述|
|:-------------|:----------|:------|:------------------------------|
|uid|O|String|用户ID。|
|importUid|O|String|导入的用户ID，仅当存在导入用户时有值。|
|displayName|O|String|用户昵称。|
|photoUrl|O|String|头像地址。|
|provider|O|integer|首次认证的第三方标识。|
|emailVerified|O|integer|邮箱验证标识： * 0：邮箱未被验证。 * 1：邮箱已被验证。|
|passwordSetted|O|integer|密码设置标识： * 0：未设置密码。 * 1：已设置密码。|
|email|O|String|邮箱地址。|
|phone|O|String|手机号码。|

### ProviderUserInfo

|参数|必选（M）/可选（O）|参数类型|描述|
|:----------|:----------|:------|:------------------------------------------|
|uid|O|String|用户ID。|
|displayName|O|String|用户昵称。|
|photoUrl|O|String|头像地址。|
|provider|O|integer|首次认证的第三方标识。|
|openId|O|String|第三方用户标识，第三方SDK授权后即可获得。只有微信、QQ与华为游戏账号认证方式涉及。|
|email|O|String|邮箱地址。|
|phone|O|String|手机号码。|
|extId|O|String|扩展ID。|
