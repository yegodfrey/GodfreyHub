# 查询商品订阅分组信息

#### 功能介绍

此接口用于查询商品订阅分组信息。  

#### 使用约束

接口调用者的角色：账号持有者、管理员、APP管理员、运营。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者服务器-\>数字商品服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/pms/product-price-service/v2/manage/product/group/list|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|-----------------------------------------------------------------------------------------------|

#### Body

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:--------|:----------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|requestId|M|String(64)|请求序列，开发者自定义唯一标识符。|
|pageNum|O|Integer|起始页数，默认值：1。|
|pageSize|O|Integer|返回数据每页的条数， 默认是20。 取值范围：1\~300|
|orderBy|O|String|按名称升序或者降序排序。配置JSON对象，key为属性名，value为排序规则。不传值时默认按照数据库中创建时间降序。 * key取值范围为： * name：订阅分组名称 * createTime：创建时间 * updateTime：更新时间 * value取值desc降序或者asc升序 例如：按name降序，按createTime升序，则配置为{"name": "desc","createTime": "asc"}|

#### 调用示例

<br />

```
"Java"
public static ProductGroupQueryResp getProducGroups(String domain, String clientId, String authorization,
    String appId, ProductGroupQueryReq req) {
    String url = domain + "/api/pms/product-price-service/v2/manage/product/group/list";
    HttpPost post = new HttpPost(url);
    setHttpHead(clientId, authorization, appId, post);
    StringEntity entity = new StringEntity(JSON.toJSONString(req), ContentType.create("application/json", "UTF-8"));
    post.setEntity(entity);
    String result = getApiResp(post);
    if (StringUtils.isNotEmpty(result)) {
        return JSON.parseObject(result, ProductGroupQueryResp.class);
    }
    return null;
}
```
