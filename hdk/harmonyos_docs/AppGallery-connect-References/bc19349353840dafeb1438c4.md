# ReadOnlyEntitySet

|Class/Struct Info|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public readonly struct ReadOnlyEntitySet : IReadOnlyList<IEntity> 高性能实体访问的只读结构体，提供高效的实体访问和遍历，继承了IReadOnlyList<IEntity>。 主要用于Archetype批量创建实体和Lookup模块中，无法主动创建。|

## Property Summary

|Name|Type|Description|
|:-------|:----------------|:----------|
|Count|int|实体数量。|
|EcsWorld|IECSWorld|世界。|
|Ids|ReadOnlySpan<int>|实体标识的只读内存。|

**Sample Code**

```screen
var world = new IECSWorld();
var archetype = world.GetCreateArchetype(IComponents.Get<PgdPosition>());
// 批量创建3个实体，以ReadOnlyEntitySet结构返回
var entitySetRO = archetype.CreateEntities(3);
entitySetRO.Count; // 3
entitySetRO.EcsWorld; // 等于world
entitySetRO.Ids[0]; // 1
```
