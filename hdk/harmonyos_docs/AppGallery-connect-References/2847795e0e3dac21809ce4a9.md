# GPMError

|Class Info|
|:-----------------------------------------------------------------------|
|public sealed class GPMError 游戏性能管理SDK初始化返回码。 > 说明 > GPMError类的命名空间为GPM。|

## 返回码

|返回码|值|描述|
|:----------------------------------------|:---|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|GPM_SUCCESS|0|成功。|
|GPM_FAIL|1001|内部系统错误。|
|GPM_SAMPLE_TOKEN_NOT_OBTAINED|1002|获取令牌Token失败。|
|GPM_PARAMS_ERROR|2001|接口参数错误，请检查参数是否正确。|
|GPM_INIT_INVALID_USER_IDENTITY|2002|初始化参数错误，未设置[UserIdentity](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpminitparams-apis-0000001754248880#ZH-CN_TOPIC_0000001754248880__p828102971918)，或者UserIdentity超出长度限制（0，756）。|
|GPM_AGC_AUTH_FAIL|2003|获取AGC Token失败，请检查初始化参数中AccessToken或ClientSecret正确性。|
|GPM_NOT_INIT|2004|在调用启用采集器前未进行初始化。|
|GPM_COLLECTOR_NOT_ENABLE|2005|在设置场景前未启用采集器。|
|GPM_SCENE_NOT_START|2006|在设置场景加载完成或场景标签时未设置场景开始。|
|GPM_HTTP_NETWORK_ERROR|3001|网络异常，请检查网络是否正常。|
|GPM_NOT_SUPPORT_OPERATE_WHEN_AUTO_COLLECT|4001|GPM自动采集场景下不支持手动设置场景开始和场景结束。|
