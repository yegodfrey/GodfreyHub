# 上传资源

## 功能介绍

此接口用于提交上传资源。

## 使用约束

接口调用者的角色：账号持有者、管理员、APP管理员、运营。

## 接口原型

|承载协议|HTTPS POST|
|-----|-------------------------------------------------------------------------------------|
|接口方向|开发者服务器->数字商品服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/pms/product-price-service/v2/manage/resource|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|

## 请求参数

### Header

> 说明
>
> API Client和OAuth Client区别参见[使用入门](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114)。

**API Client方式**

|参数|必选(M)/可选(O)|类型|描述|
|:------------|:----------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|M|String|客户端ID，获取方法参考[创建API客户端](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section103mcpsimp)。|
|Authorization|M|String|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)中获取的access_token。|
|appId|M|String|应用ID，获取方法参考[查询应用信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/appgallery_queryappinfo)。|

**OAuth Client方式**

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
|oauth2Token|M|String|认证信息，传入[获取用户授权码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section949717114392)中获取的Access Token。|
|appId|M|String|应用ID，获取方法参考[查询应用信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/appgallery_queryappinfo)。|

### Body

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:--------|:----------|:------------|:------------------|
|requestId|M|String(64)|请求序列。|
|file|M|MultipartFile|上传的文件。|
|fileType|M|String|上传文件的类型，固定取值： 1：图片|
|zoneId|M|String|上传区域的ID，固定取值： 1：中国区|
|fileName|M|String|上传文件的名称。|

|参数名称|必选(M)/可选(O)|类型|参数说明|

## 调用示例

```screen
"Java"
public static ProductResourceUploadRespV2 uploadResource(String domain, String clientId, String authorization, String appId, 
    String fileName, String zoneId, String fileType, MultipartFile file) { 
    ProductResourceUploadRespV2 resp = null;  
    try {  
        String url = domain + "/api/pms/product-price-service/v2/manage/resource";  
        HttpPost post = new HttpPost(url);  
        post.setHeader(new BasicHeader("Authorization", "Bearer " + authorization));  
        post.setHeader(new BasicHeader("client_id", clientId));  
        post.setHeader(new BasicHeader("appId", appId)); // Use appId

        MultipartEntityBuilder builder = MultipartEntityBuilder.create();
        builder.addTextBody("fileName", fileName, ContentType.create("text/plain", "UTF-8"));
        builder.addTextBody("zoneId", zoneId, ContentType.create("text/plain", "UTF-8"));
        builder.addTextBody("fileType", fileType, ContentType.create("text/plain", "UTF-8"));

        if (file != null && !file.isEmpty()) {
            FileBody fileBody = new FileBody(file.getInputStream(), ContentType.DEFAULT_BINARY, file.getOriginalFilename());
            builder.addPart("file", fileBody);
        }

        // Build and set the request entity
        HttpEntity entity = builder.build();
        post.setEntity(entity);

        // Create and execute the request
        CloseableHttpClient httpClient = HttpClients.createDefault();  
        HttpResponse response = httpClient.execute(post);  
        int statusCode = response.getStatusLine().getStatusCode();  
        if (statusCode == HttpStatus.SC_OK) {  
            String result = EntityUtils.toString(response.getEntity(), "UTF-8");  
            if (StringUtils.isNotEmpty(result)) { 
                resp = JSON.parseObject(result, ProductResourceUploadRespV2.class);  
            }  
        }  
        post.releaseConnection();  
        httpClient.close();  
    } catch (Exception e) {  
        e.printStackTrace(); 
    }  
    return resp;  
}
```
