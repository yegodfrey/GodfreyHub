# CloudDBZoneObjectOperatorConstraint

提供了诸如where()、equalTo()、notEqualTo()、in()等丰富的谓词来构造约束条件。您可以基于上述的谓词方法构造自己的CloudDBZoneObjectOperatorConstraint对象，作为[executeBatchUpdate()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section1771340123818)、[executeBatchUpdateByCondition()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section22061653514)、[executeBatchDelete()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section18190184724218)或者[executeBatchDeleteByCondition()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section1670713412813)方法的参数传入，Cloud DB会基于指定的约束条件来进行更新或删除。
> 注意
>
> * CloudDBZoneObjectOperatorConstraint作为条件更新或删除操作的约束条件，与CloudDBZoneQuery查询条件不同。
> * 构造约束条件时，仅支持使用13种谓词，equalTo()、notEqualTo()、in()、greaterThan()、greaterThanOrEqualTo()、lessThan()、lessThanOrEqualTo()、beginsWith()、endsWith()、contains()、isNull()、isNotNull()和byUid()。
> * 构造约束条件时，同一约束条件下约束谓词需小于或等于30个。
