# ohAegHuksDec

ohAegHuksDec(keyAlias: string, text: Uint8Array): Promise<Uint8Array>

基于HUKS的AES-GCM解密，配套[ohAegHuksEnc](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ohaeghuksenc-0000001911924857)接口使用，分组模式、填充模式如下：

|分组模式|密钥长度（bit）|填充模式|API版本|
|:---|:--------|:--------|:----|
|GCM|256|NoPadding|11+|

**导入模块：**

```screen
import { AegHuks } from '@hw-agconnect/petal-aegis';
```

**参数** **：**

|参数名|类型|必填|说明|
|:-------|:---------|:-|:-------------------------------------------------------|
|keyAlias|string|是|密钥别名|
|text|Uint8Array|是|待解密内容（ohAegHuksEnc加密后的结果），格式为**iv:密文**或者同类的Uint8Array格式。|

**返回值：**

|参数|类型|说明|
|:----------|:---------|:--------|
|decryptText|Uint8Array|解密后的明文内容。|

**示例：**

```screen
import { AegHuks } from '@hw-agconnect/petal-aegis';
import { buffer } from '@kit.ArkTS';

async function aesgcmhuks3() {
  let alias = 'aegis';
  let plainText = 'hello world'; //待加密内容
  let iv = '987654321321'; //长度12字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let inputUint8 = new Uint8Array(buffer.from(plainText, 'utf-8').buffer);
  let ivUint8 = new Uint8Array(buffer.from(iv, 'utf-8').buffer);

  try {
    let encryptText = await AegHuks.ohAegHuksEnc(alias, inputUint8, ivUint8);
    //aesgcmhuks3  encryptText: 57,56,55,54,53,52,51,50,49,51,50,49,58,62,116,223,197,220,185,91,93,201,66,157,214,65,43,1,223,93,210,43,137,65,231,164,80,76,23,232
    console.log("aesgcmhuks3 ", 'encryptText: ' + encryptText);

    let decryptText = await AegHuks.ohAegHuksDec(alias, encryptText);
if (plainText === uint8ArrayToString(decryptText)) {
      console.info('aesgcmhuks3 decrypt ok');
    }
    console.log("aesgcmhuks3 ", 'decryptText: ' + uint8ArrayToString(decryptText));
  } catch (err) {
    console.log("aesgcmhuks3 ", 'err: ' + err);
  }
}
function uint8ArrayToString(data: Uint8Array) {
  let dataString = '';
  for (let i = 0; i < data.length; i++) {
    dataString += String.fromCharCode(data[i]);
  }
  return dataString;
}
```
