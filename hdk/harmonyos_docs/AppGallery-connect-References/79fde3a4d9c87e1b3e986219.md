# APMS

|Class Info|
|:----------------------------------------------------------------------|
|public class APMS APM SDK服务入口类，用于动态启用/停用APM性能监控数据采集、创建自定义跟踪记录和创建网络请求指标。|

|Qualifier and Type|Method Name and Description|
|:---------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------|
|static [APMS](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/apms-0000001052488219)|[getInstance](#section304mcpsimp)() 初始化APMS实例。|
|void|[enableCollection](#section325mcpsimp)(boolean enable) APM服务开关。设置为false时，APM会停止采集应用性能数据。默认值为true。|
|void|[enableAnrMonitor](#section17455144122519)(boolean enable) 设置ANR监控开关。设置为false时，表示停用ANR监控能力。默认值为true。|
|[CustomTrace](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/customtrace-0000001051488170)|[createCustomTrace](#section351mcpsimp)(String traceName) 创建自定义跟踪记录，traceName为记录的名称。|
|[NetworkMeasure](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/networkmeasure-0000001052966915)|[createNetworkMeasure](#section389mcpsimp)(String url, String httpMethod) 创建网络请求指标实例，用于采集网络性能数据。|
|void|[setUserIdentifier](#section99791215181716)(String userIdentifier) 为上报数据绑定用户标识，性能数据上报时会一并上报该用户标识，方便单用户问题定位。|
|ApmsLog|[createApmsLog](#section9294151513812)() 返回自定义日志打印实例，支持打印的日志被日志回捞任务拉取。|
|void|[setUserPrivacyAgreed](#section139413824718)(boolean isAgreed) 设置是否已同意用户隐私协议。设置为false时，表示尚未同意或者已拒绝用户隐私协议。默认值为true。|

## Public Methods

### getInstance

|Method|
|:----------------------------------------------------------------------|
|public static APMS getInstance() 初始化APMS实例。在调用APMS类的接口前，您需要先使用此方法初始化实例。|

**Return**

|Type|Description|
|:-------------------------------------------------------------------------------------------------------------------|:------------------------------------|
|[APMS](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/apms-0000001052488219)|APMS类的实例对象。初始化APMS实例后才可以调用APMS类的其他接口。|

### enableCollection

|Method|
|:-------------------------------------------------------------------------------------------------------------------------|
|public void enableCollection(boolean enable) 设置APM服务开关。开关的默认值为true（打开），表示启用APM应用性能数据采集。如果需要停用APM应用性能数据采集，可将开关值设为false（关闭）。|

**Parameters**

|Name|Description|
|:-----|:---------------------------------------------------------|
|enable|APM服务开关。 * true：打开，APM会采集性能监控数据。 * false：关闭，APM不会采集性能监控数据。|

**Sample Code**

```screen
APMS.getInstance().enableCollection(true);
```

### enableAnrMonitor

|Method|
|:--------------------------------------------------------------------------------------------------------------------|
|public void enableAnrMonitor(boolean enable) 设置ANR监控开关。开关的默认值为true（打开），表示启用ANR监控并上报数据。如果需要停用ANR监控能力，可将开关值设为false（关闭）。|

**Parameters**

|Name|Description|
|:-----|:----------------------------------------------------------------------------------|
|enable|ANR监控开关。 * true：打开，APM会监控应用ANR。 * false：关闭，APM不会监控应用ANR。 在APM服务开关打开的情况下，ANR监控开关才生效。|

**Sample Code**

```screen
APMS.getInstance().enableAnrMonitor(true);
```

### createCustomTrace

|Method|
|:--------------------------------------------------------------------------------------|
|public CustomTrace createCustomTrace(String traceName) 根据入参traceName，为应用中特定场景创建自定义跟踪记录。|

**Parameters**

|Name|Description|
|:--------|:-----------------------------------------------|
|traceName|自定义跟踪记录名称，只能包含中文、字母（不区分大小写）、数字和下划线，且长度不能超过100字符。|

**Return**

|Type|Description|
|:---------------------------------------------------------------------------------------------------------------------------------|:-------------------------|
|[CustomTrace](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/customtrace-0000001051488170)|自定义跟踪记录，用于跟踪记录应用在特定场景下的性能。|

### createNetworkMeasure

|Method|
|:--------------------------------------------------------------------------------------------------------|
|public NetworkMeasure createNetworkMeasure(String url, String httpMethod) 针对每个网络请求，创建网络请求指标实例，用于采集网络性能数据。|

**Parameters**

|Name|Description|
|:---------|:--------------------------------------------------------------|
|url|网络请求URL地址。|
|httpMethod|请求方法，仅支持GET、PUT、POST、DELETE、HEAD、PATCH、OPTIONS、TRACE或CONNECT方法。|

**Return**

|Type|Description|
|:---------------------------------------------------------------------------------------------------------------------------------------|:---------------------|
|[NetworkMeasure](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/networkmeasure-0000001052966915)|网络请求指标，用于采集网络请求指标性能数据。|

### setUserIdentifier

|Method|
|:----------------------------------------------------------------------------------------------------------------------------|
|public void setUserIdentifier(String userIdentifier) 为上报数据绑定用户标识，性能数据上报时会一并上报该用户标识，方便单用户问题定位。回捞日志需要配置此参数，用于在创建任务时指定回捞任务的执行对象。|

**Parameters**

|Name|Description|
|:-------------|:-----------------|
|userIdentifier|用户标识。您需要保证该标识隐私合规。|

**Sample Code**

```screen
APMS.getInstance().setUserIdentifier("475f5afaxxxxx");
```

### createApmsLog

|Method|
|:-----------------------------------------------------------|
|public ApmsLog createApmsLog() 返回自定义日志打印实例，支持打印的日志被日志回捞任务拉取。|

**Return**

|Type|Description|
|:------|:--------------------------|
|ApmsLog|自定义日志打印类，打印日志会缓存到本地，用于日志回捞。|

### setUserPrivacyAgreed

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------|
|public void setUserPrivacyAgreed(boolean isAgreed) 设置是否已同意用户隐私协议。在Application的onCreate方法中调用，如果尚未同意或者已拒绝用户隐私协议，须在同意用户隐私协议之后再调用一次该接口。|

**Parameters**

|Name|Description|
|:-------|:----------------------------------------------|
|isAgreed|是否已同意用户隐私协议。 * true：表示已同意。 * false：表示尚未同意或者已拒绝。|
