# FFCapabilitiesInfo

版本信息。

**Structure Declaration**

```screen
typedef struct FFCapabilitiesInfo {
    FFStructureType sType;
    void* pNext;
    uint16_t majorVersion;
    uint16_t minorVersion;
} FFCapabilitiesInfo;
```

**Members**

|Name|Mandatory/Optional|Description|
|:-----------------------|:-----------------|:------------------------------------------------|
|sType|必填|此结构体类型必须为**FF_STRUCTURE_TYPE_CAPABILITIES_INFO**。|
|pNext|选填|指向扩展链中的下一个结构体的指针。扩展参数，可缺省，默认值为NULL。|
|(Out value) majorVersion|必填|API主要版本。|
|(Out value) minorVersion|必填|API次要版本。|
