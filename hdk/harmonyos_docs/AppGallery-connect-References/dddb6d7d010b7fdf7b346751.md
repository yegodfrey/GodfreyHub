# ohAegSMEncTextHex

ohAegSMEncTextHex(text: string \| Uint8Array, key: string \| Uint8Array, iv?: string \| Uint8Array): Promise\<string\>

SM4-CBC加密算法，加密结果是十六进制编码格式，建议与[ohAegSMDecTextHex](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ohaegsmdectexthex-0000001910145413)配套使用，分组模式、填充模式如下：  

|分组模式|密钥长度（bit）|填充模式|API版本|
|:---|:--------|:----|:----|
|CBC|128|PKCS7|11+|

导入模块：

```
import { AegSM } from '@hw-agconnect/petal-aegis';
```

参数：  

|参数名|类型|必填|说明|
|:---|:----------------|:-|:----------------------------------------------------|
|text|string或Uint8Array|是|明文内容。|
|key|string或Uint8Array|是|明文工作密钥（string类型的key需要使用16进制编码格式）。|
|iv|string或Uint8Array|否|如果没有传入，接口会自动生成iv，随密文一同作为返回值（string类型的iv需要使用16进制编码格式）。|

返回值：  

|参数|类型|说明|
|:----------|:--------|:------|
|encryptText|hexString|加密后的密文。|
