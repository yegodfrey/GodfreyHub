# 应用文件要求

在上传应用文件到AppGallery Connect时，对于文件的类型、大小等有相关限制，如下表所示。

本章节仅提供HarmonyOS 3.1/4.0及以下应用/元服务和Android应用的文件要求，HarmonyOS NEXT应用/元服务的文件要求请参见[应用文件要求](https://developer.huawei.com/consumer/cn/doc/app/agc-help-connect-api-appendix-requirement-0000002271160693)。

## HarmonyOS 3.1/4.0及以下

### HarmonyOS应用

|**文件类型**|**说明**|**支持设备**|**文件大小**|**分辨率**|**支持格式**|
|:--------------------|:-----------------------------------------------------------------|:-----------------------|:---------------------------------|:--------------------------------------------|:----------------|
|应用图标|只能1个图标|手机/平板、路由器、手表|PNG最大500KB，WEBP最大100KB|216*216|PNG/WEBP|
|应用图标|只能1个图标|PC/2in1|最大500KB|216*216|PNG|
|应用图标|只能1个图标|智慧屏|PNG/JPG/JPEG最大2MB，WEBP最大100KB|307*172|JPG/JPEG/PNG/WEBP|
|应用介绍视频|最多3个视频|手机/平板、路由器|最大500MB，视频长度15秒-2分钟|竖屏：720*1280 横屏：1280*720|MOV/MP4|
|应用介绍视频|最多3个视频|PC/2in1、智慧屏、手表|不支持|||
|应用介绍视频对应海报|视频海报与应用介绍视频的数量需要一致，且必须按照xx1.mp4，xx1.png，xx2.mp4，xx2.png这样的顺序才能成功上传|手机/平板、路由器|PNG/JPG/JPEG最大2MB，WEBP最大100KB|竖屏：450*800 横屏：800*450|JPG/JPEG/PNG/WEBP|
|应用介绍视频对应海报|视频海报与应用介绍视频的数量需要一致，且必须按照xx1.mp4，xx1.png，xx2.mp4，xx2.png这样的顺序才能成功上传|PC/2in1、智慧屏、手表|不支持|||
|应用介绍截图|应用介绍截图|手机/平板|PNG/JPG/JPEG最大5MB，WEBP最大200KB，3-5张|竖屏：720*1280 横屏：1280*720|JPG/JPEG/PNG/WEBP|
|应用介绍截图|应用介绍截图|PC/2in1|最大5MB，3-5张|1280*720|JPG/JPEG/PNG|
|应用介绍截图|应用介绍截图|智慧屏|PNG/JPG/JPEG最大2MB，WEBP最大100KB，5-8张|1920*1080或1280*720|JPG/JPEG/PNG/WEBP|
|应用介绍截图|应用介绍截图|路由器|PNG/JPG/JPEG最大2MB，WEBP最大100KB，3-5张|竖屏：450*800 横屏：800*450|JPG/JPEG/PNG/WEBP|
|应用介绍截图|应用介绍截图|手表|PNG/JPG/JPEG最大2MB，WEBP最大100KB，4-8张|840*840|JPG/JPEG/PNG/WEBP|
|推荐视频|推荐视频将展示在应用详情页的顶部，仅开放给飞跃计划、联运等项目开发者使用|手机/平板、路由器|最大500MB，视频长度15秒-2分钟|1600*1200或1200*900|MOV/MP4|
|推荐视频|推荐视频将展示在应用详情页的顶部，仅开放给飞跃计划、联运等项目开发者使用|PC/2in1、智慧屏、手表|不支持|||

|推荐视频对应的海报|推荐视频对应的海报，海报个数与视频个数一致|PC/2in1、智慧屏、手表|不支持|||
|推荐图片|应用的推荐图片|智慧屏|PNG/JPG/JPEG最大2MB，WEBP最大100KB，4张|分辨率必须按照396*223、414*573、1920*1080、880*494的顺序更新|JPG/JPEG/PNG/WEBP|
|推荐图片|应用的推荐图片|手机/平板、PC/2in1、路由器、手表|不支持|||

|电子证书PDF文件|包含电子版权证书|所有|最大5MB|不涉及|PDF|
|文化部版号截图|游戏版号信息、版号证明，最多3张|手机/平板、PC/2in1、智慧屏、路由器、手表|最大4MB|无要求|JPG/JPEG/PNG/PDF|
|HarmonyOS应用受限权限使用说明视频|1个|手机/平板、PC/2in1、智慧屏、路由器、手表|最大500MB|不涉及|MOV/MP4|
