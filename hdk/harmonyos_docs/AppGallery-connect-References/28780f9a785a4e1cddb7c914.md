# 上传单个文件

## 功能介绍

调用此接口可以上传so文件、profile文件、symbol文件。

## 接口原型

|承载协议|HTTPS|
|------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|接口方向|开发者服务器 -> 华为服务器|
|接口方法|[获取文件上传地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/binary-optimization-obtain-url-0000001863302878#ZH-CN_TOPIC_0000001863302878__zh-cn_topic_0000001536629733_p8960111611019)接口中返回的请求方法。|
|接口URL|[获取文件上传地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/binary-optimization-obtain-url-0000001863302878#ZH-CN_TOPIC_0000001863302878__zh-cn_topic_0000001536629733_p1196012161609)接口中返回的URL地址，且URL地址未超过15分钟。|
|请求数据格式|[获取文件上传地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/binary-optimization-obtain-url-0000001863302878#ZH-CN_TOPIC_0000001863302878__zh-cn_topic_0000001536629733_p149605164010)接口中返回的headers参数中的Content-Type。|

## 请求参数

### Header

|参数名称|类型|必选(M)/可选(O)|参数说明|
|:-------------------|:-----|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|x-amz-content-sha256|string|M|文件对象内容的sha256哈希值，即调用[获取文件上传地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/binary-optimization-obtain-url-0000001863302878#ZH-CN_TOPIC_0000001863302878__zh-cn_topic_0000001536629733_p149605164010)接口返回的headers参数中的x-amz-content-sha256。|
|Authorization|string|M|校验信息，即调用[获取文件上传地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/binary-optimization-obtain-url-0000001863302878#ZH-CN_TOPIC_0000001863302878__zh-cn_topic_0000001536629733_p149605164010)接口返回的headers参数中的Authorization。 > 注意 > **Authorization**不是获取Token接口的access_token。|
|x-amz-date|string|M|文件上传地址生成的时间，即调用[获取文件上传地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/binary-optimization-obtain-url-0000001863302878#ZH-CN_TOPIC_0000001863302878__zh-cn_topic_0000001536629733_p149605164010)接口返回的headers参数中的x-amz-date。|
|Host|string|M|上传服务器地址，即调用[获取文件上传地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/binary-optimization-obtain-url-0000001863302878#ZH-CN_TOPIC_0000001863302878__zh-cn_topic_0000001536629733_p149605164010)接口返回的headers参数中的Host。|
|Content-Type|string|M|对象内容的类型，即调用[获取文件上传地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/binary-optimization-obtain-url-0000001863302878#ZH-CN_TOPIC_0000001863302878__zh-cn_topic_0000001536629733_p149605164010)接口返回的headers参数中的Content-Type。|

### Body

待上传的文件要求如下：

* 文件名须与调用[获取文件上传地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/binary-optimization-obtain-url-0000001863302878#ZH-CN_TOPIC_0000001863302878__zh-cn_topic_0000001536629733_p19582155345412)接口时填写的**fileName**保持一致。
* 文件大小须与调用[获取文件上传地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/binary-optimization-obtain-url-0000001863302878#ZH-CN_TOPIC_0000001863302878__zh-cn_topic_0000001536629733_p16582115385416)接口时填写的**fileSize**保持一致。

## 请求示例

```screen
PUT https://contentcenter.myhuaweicloud.com/GameCenter_xxx/67/v3/xxx/xxx.so
x-amz-content-sha256:a06***8d3
Authorization:***
x-amz-date:20220615T033053Z
Host:nsp-contentcenter-content-p01-drcn.obs.cn-north-2.myhuaweicloud.cn
Content-Type:application/octet-stream

{
    待上传的文件
}
```

## 返回码

|code|msg|Description|
|:---|:------------------|:----------|
|200|Success|文件上传成功。|
|3001|invalid parameters.|参数错误。|
