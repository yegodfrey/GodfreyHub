# ohAegHmacSha256Text

ohAegHmacSha256Text(text: string \| Uint8Array, key: string \| Uint8Array): Promise\<Uint8Array\>

HmacSHA256消息认证码算法，返回Uint8Array类型的SHA256值，算法说明如下：  

|摘要算法|支持种类|API版本|
|:---|:-----|:----|
|HASH|SHA256|11+|

导入模块：

```
import { AegHmac } from '@hw-agconnect/petal-aegis';
```

参数：  

|参数名|类型|必填|说明|
|:---|:----------------|:-|:----------------------------|
|text|string或Uint8Array|是|明文内容。|
|key|string或Uint8Array|是|明文密钥（string类型的key需要16进制编码格式）。|

返回值：  

|参数|类型|说明|
|:---|:---------|:------------------|
|字节数组|Uint8Array|生成的加密Uint8Array字符串。|

示例：

```
import { AegHmac } from '@hw-agconnect/petal-aegis';
import { buffer } from '@kit.ArkTS';

function HmacSHA256() {
  let text = 'hello world';
  let key = '12345678912345678912345678912345';//长度32字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let keyUint8 = new Uint8Array(buffer.from(key, 'utf-8').buffer);

  AegHmac.ohAegHmacSha256Text(text, keyUint8).then((data) => {
    //HmacSHA256  result: 247,155,61,193,78,26,35,123,211,189,26,128,135,235,67,62,109,127,236,58,199,73,218,68,127,72,89,211,73,50,30,115
    console.log("HmacSHA256 ", 'result: ' + data);
  }).catch((err) => {
    console.log("HmacSHA256 ", 'err: ' + err);
  })
}
```
