# FFVKInstanceCreateInfo

创建库实例信息。

**Structure Declaration**

```screen
typedef struct FFVKInstanceCreateInfo {
    FFStructureType                        sType;
    const void*                            pNext;
    uint16_t                               majorVersion;
    uint16_t                               minorVersion;
    VkInstance                             vkInstance;
    VkPhysicalDevice                       vkPhysicalDevice;
    VkDevice                               vkDevice;
    uint32_t                               queueFamilyIndex;
    uint8_t                                framesInFlight;
    PFN_vkGetInstanceProcAddr              pfnVulkanLoaderFunction;
    PFN_FrameFlowVK_ErrorReportCallback    pfnErrorReportCallback;
    void*                                  pUserData;
} FFVKInstanceCreateInfo;
```

**Members**

|Name|Mandatory/Optional|Description|
|:----------------------|:-----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|sType|Mandatory|此结构体类型必须为**FF_STRUCTURE_TYPE_INSTANCE_CREATE_INFO**。|
|pNext|Optional|指向功能扩展链中的下一个结构体的指针。扩展参数，可缺省，默认值为NULL。|
|majorVersion|Mandatory|游戏使用的API主要版本。 > 说明 > 插帧服务版本号由主要版本和次要版本组成，例如，当前版本为5.0，其中"5"为主要版本。版本号信息具体请参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/predict-frame-releasenotes-0000001630692613)。|
|minorVersion|Mandatory|游戏使用的API次要版本。 > 说明 > 插帧服务版本号由主要版本和次要版本组成，例如，当前版本为5.0，其中"0"为次要版本。版本号信息具体请参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/predict-frame-releasenotes-0000001630692613)。|
|vkInstance|Mandatory|Vulkan的实例句柄。|
|vkPhysicalDevice|Mandatory|Vulkan的物理设备句柄。|
|vkDevice|Mandatory|Vulkan的逻辑设备句柄。|
|queueFamilyIndex|Mandatory|Vulkan队列家族的索引，用于Vulkan命令队列的提交。|
|framesInFlight|Mandatory|飞行中的帧数，例如，如果下一帧需在前一帧呈现后才渲染，则要将framesInFlight设置为1。当前仅可设置为1。|
|pfnVulkanLoaderFunction|Mandatory|负责加载Vulkan图形API入口点的函数，通常直接赋值为Vulkan的vkGetInstanceProcAddr函数。|
|pfnErrorReportCallback|Optional|自定义的错误日志打印回调函数。默认值为NULL。|
|pUserData|Optional|自定义指针，将由实例传递给回调函数（例如[pfnVulkanLoaderFunction](#ZH-CN_TOPIC_0000001791494432__p367375213296)和[pfnErrorReportCallback](#ZH-CN_TOPIC_0000001791494432__p65597187151)）。默认值为NULL。|
