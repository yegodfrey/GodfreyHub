# AGCCloudDBTransaction

```screen
@interface AGCCloudDBTransaction : NSObject
```

AGCCloudDBTransaction类用来描述一个事务，事务内提供executeQuery、executeUpsert和executeDelete等方法，实现对云侧存储区数据的管理操作，包含数据的增、删、改、查等。一个事务内可以进行多次数据操作，查询操作必须在写入和删除操作之前进行。事务仅在联网的情况下进行，一旦离线该事务操作将失败。一个事务中包含的写入和删除对象的总条数不能超过1000条，且一个事务内的多次写入操作的数据总大小不能超过2MB。

## -executeQuery:error:

调用此方法在事务中从云侧存储区查询获取满足特定条件的对象集合。事务是原子的，事务内的操作要么全部成功，要么全部失败。

调用本方法需要遵循以下约束：

* 仅在正常连接网络时可调用该方法实现查询功能，一旦离线该操作将失败。
* 事务中的查询操作必须在写入操作和删除操作之前，否则将导致事务执行失败。
* 仅在CloudDBZone的同步属性为缓存模式时，支持相关事务操作。
* 一个事务中多次查询结果的总数据大小不能超过5MB，否则会导致事务失败。
* 一个事务中多次查询结果的总数据条数不能超过1000条，否则会导致事务失败。

## -executeUpsert:

调用此方法在事务中将一组对象批量写入到云侧存储区。事务是原子的，事务内的操作要么全部成功，要么全部失败。

调用本方法需要遵循以下约束：

* 事务中的写入操作必须在查询之后，否则将导致事务执行失败。
* 仅在正常连接网络时可调用该方法实现写入功能，一旦离线该操作将失败。
* 仅在CloudDBZone的同步属性为缓存模式时，支持相关事务操作。
* 一个事务内的多次写入操作的数据总大小不能超过2MB，否则会导致写入失败。
* 写入操作的数据为nil，或者其数据列表中的对象不属于同一个对象类型，会抛出异常。

**OBJECTIVE-C**

```screen
- (nullable AGCCloudDBTransaction *)executeUpsert:(nonnull NSArray *)objects;
```

**Parameters**

|Parameter name|Parameter desc|
|:-------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
|objects|一个[AGCCloudDBObject](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbobject-ios-0000001127600969)的列表，表示待写入的数据。|

**Return**

|type|desc|
|:--------------------|:---------------------------|
|AGCCloudDBTransaction|一个事务的对象，调用者可以在该返回值上定义其它事务操作。|

## -executeDelete:

调用此方法在事务中批量删除云侧存储区中的一组对象。事务是原子的，事务内的操作要么全部成功，要么全部失败。删除操作只关注对象的主键是否一致，不考虑对象其它属性和存储的数据是否匹配。

调用本方法需要遵循以下约束：

* 事务中的删除操作必须在查询之后，否则将导致事务执行失败。
* 仅在正常连接网络时可调用该方法实现删除功能，一旦离线该操作将失败。
* 仅在CloudDBZone的数据同步属性为缓存模式时，支持相关事务操作。
* 删除操作的数据为nil，或者其数据列表中的对象不属于同一个对象类型，会抛出异常。

**OBJECTIVE-C**

```screen
- (nullable AGCCloudDBTransaction *)executeDelete:(nonnull NSArray *)objects;
```

**Parameters**

|Parameter name|Parameter desc|
|:-------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
|objects|一个[AGCCloudDBObject](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbobject-ios-0000001127600969)的列表，表示待删除的数据。|

**Return**

|type|desc|
|:--------------------|:---------------------------|
|AGCCloudDBTransaction|一个事务的对象，调用者可以在该返回值上定义其它事务操作。|
