#### Methods

#### copy

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|copy(des: string \| Bucket \| File): Promise\<CopyResponse\> 文件的拷贝操作。 注意： 拷贝的源文件大小超过1GB不建议使用此接口。如果源文件大小超过1GB，该操作容易发生拷贝超时并导致拷贝失败。如确实需要拷贝超过1GB的文件，请采用下载该文件并重新上传的方式替代拷贝操作。|

Parameters  

|Name|Description|
|:---|:----------|
|des|拷贝操作的目标。|
