# FFInstanceGrabSupport

隐式抓取数据支持情况。  
Structure Declaration

```
typedef struct FFInstanceGrabSupport {
    FFStructureType    sType;
    const void*        pNext;
    FFBool             needColor;
    FFBool             needDepthStencil;
    FFBool             useRenderDoc;
} FFInstanceGrabSupport;
```

Members  

|Name|Mandatory/Optional|Description|
|:---------------|:-----------------|:------------------------------------------------------------------------------------------------|
|sType|Mandatory|此结构体类型必须为FF_STRUCTURE_TYPE_INSTANCE_GRAB_SUPPORT。|
|pNext|Optional|指向扩展链中的下一个结构体的指针。扩展参数，可缺省，默认值为NULL。|
|needColor|Mandatory|是否允许隐式抓取数据函数获取颜色数据。 * FF_TRUE：允许 * FF_FALSE：不允许|
|needDepthStencil|Mandatory|是否允许隐式抓取数据函数获取深度/模板数据。 * FF_TRUE：允许 * FF_FALSE：不允许|
|useRenderDoc|Mandatory|是否允许图形调试器RenderDoc在needColor为"FF_TRUE"时抓取帧数据。 * FF_TRUE：允许，仅在调试阶段使用。 * FF_FALSE：不允许，正式版本时请设置为此选项。|
