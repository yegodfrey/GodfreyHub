# AGConnectConfig

AGC Remote Config入口类。

## Property Summary

|Type|Name|Description|
|:-------------------------------------|:------------------------------|:-----------------------------------|
|number|fetchReqTimeoutMillis|fetch请求超时时间（毫秒，默认1分钟）。|
|number|minFetchIntervalMillis|fetch获取云端配置信息更新间隔周期（毫秒，默认12小时）。|
|number|latestSuccessfulFetchTimeMillis|上一次fetch接口调用成功时间戳（可查询，不可人为修改）。|
|FetchState|latestFetchState|上一次fetch接口获取云端配置信息成功情况（可查询，不可人为修改）。|
|Map<string, string | number | boolean>|defaultConfigValues|applyDefault接口传入的默认配置信息（可查询，不可人为修改）。|

## Methods

### initialized

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|initialized(): Promise<void> 初始化远程配置，应用初始化时调用，使上次关闭应用前最后一次生效的云端配置和默认配置重新生效，并能保证上次关闭应用时的latestSuccessfulFetchTimeMillis，latestFetchState，defaultConfigValues可被正确获取。（调用此接口前请确保已设置了与上次应用打开时相同的加解密对象）|

**Return**

|Type|Parameter desc|
|:------------|:-------------|
|Promise<void>|初始化远程配置异步结果。|

### setCryptImp

|Method|
|:-------------------------------------------------------------------------------------------|
|setCryptImp(cryptImpl: any): boolean 设置加解密对象，传入的对象需包含decrypt和encrypt两个方法，只对当前设置的浏览器数据存储方式生效。|

**Parameters**

|Parameter|Description|
|:--------|:----------------------------------|
|cryptImpl|用户自定义的加解密对象，需包含decrypt和encrypt两个方法。|

**Return**

|Type|Description|
|:------|:----------|
|boolean|加解密对象设置是否成功|

**Sample Code**

```screen
function Crypt(){
};
Crypt.prototype.encrypt = function(value){
  // 加密逻辑
  return encryptedValue;
};
Crypt.prototype.decrypt = function(value){
  // 解密逻辑
  return decryptedValue;
};
agconnect.remoteConfig().setCryptImp(new Crypt());
```

### setUserInfoPersistence

仅Web应用支持设置存储位置，快应用无需设置。

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|setUserInfoPersistence(persistence: [Persistence](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/web-remoteconfig-persistence-0000001057129221)): void 设置浏览器中数据的存储方式。|

**Parameters**

|Parameter|Description|
|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|persistence|数据存储方式，参考[Persistence](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/web-remoteconfig-persistence-0000001057129221)，默认persistence为0，远程配置相关信息数据持久化存储在浏览器IndexedDB中，数据长期存在。|

**Sample Code**

```screen
agconnect.remoteConfig().setUserInfoPersistence(Persistence.persistenceStorage)
```
