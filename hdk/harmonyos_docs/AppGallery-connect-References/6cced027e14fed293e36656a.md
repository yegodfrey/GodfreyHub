# OnSnapshotListener

|interface info|
|:----------------------------------------------------------------------------------------------------------------|
|public interface OnSnapshotListener 定义了一个快照侦听器接口。您如需侦听快照，则必须实现此接口，定义自己的侦听器。实现该接口时，需要同时调用subscribeSnapshot()来注册侦听。|

## Public Method Summary

|Return type|Method name|
|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
|void|[onSnapshot](#section17555512164514)(CloudDBZoneSnapshot<T> snapshot, AGConnectCloudDBException e) 注册快照侦听后，当侦听快照中的数据发生变化时，Cloud DB会自动调用onSnapshot()方法来执行自定义的操作。|

## Public Methods

### onSnapshot

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|void onSnapshot(CloudDBZoneSnapshot<T> snapshot, AGConnectCloudDBException e) 注册快照侦听后，当侦听快照中的数据发生变化时，Cloud DB会自动调用onSnapshot()方法来执行自定义的操作。 实现该接口时，需要显式地在该函数内通过参数snapshot调用release()方法来释放相关的资源，否则会导致无法获取最新的快照对象，且无法注销快照侦听。|

**Parameters**

|Parameter name|Parameter desc|
|:-------------|:-----------------------------------------------------------------|
|snapshot|变化后的快照对象，包含了全量的快照数据、新增和修改的对象集合以及新删除的对象集合。|
|e|Cloud DB的异常基类，当快照通知您快照发生变化的时候，如果发生异常，此参数不为null，您可基于异常对象e获取相关的错误信息。|
