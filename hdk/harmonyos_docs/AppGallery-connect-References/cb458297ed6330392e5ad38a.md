# AGCError

AGCError为AGC SDK异常类型基类，[AGCAuthException](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauthexception-web-0000001054503256)、[AGCRemoteConfigException](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/web-remoteconfig-agcremoteconfigexception-0000001057151634)、[AGCFunctionException](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcfunctionexception-web-0000001060490072)都继承了此类。  

#### Parameters

|Parameter|Description|
|:--------|:----------|
|message|异常消息。|
|code|异常错误码。|

#### 错误码

AGCError所包含的错误码为AGC SDK内部错误，业务相关错误码请具体查看[AGCAuthException](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauthexception-web-0000001054503256)、[AGCRemoteConfigException](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/web-remoteconfig-agcremoteconfigexception-0000001057151634)、[AGCFunctionException](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcfunctionexception-web-0000001060490072)。  

|错误码|错误码值|说明|
|:-------------------------------|:----|:------------------|
|AGC_INNER_ERROR|10000|AGC SDK内部错误。|
|NETWORK_REQUEST_ERROR|10001|AGC SDK网络请求失败。|
|GET_AAID_ERROR|10002|AAID生成失败。|
|ABTEST_LOAD_EXPERIMENTS_ERROR|10003|AB实验加载失败。|
|ABTEST_SAVE_EXPERIMENTS_ERROR|10004|AB实验保存失败。|
|ABTEST_REPLACE_EXPERIMENTS_ERROR|10005|AB实验更新失败。|
|FAIL_TO_GET_STORAGE_SERVICE|10006|AGC SDK内部存储能力不可用。|
|FAIL_TO_GET_NETWORK_SERVICE|10007|AGC SDK内部网络能力不可用。|
|REMOVE_TOKEN_FAILED|10008|Client Token清除失败。|
|GET_TOKEN_FAILED|10009|Client Token无法获取。|
|AGC_INIT_ERROR|10010|AGC SDK初始化失败。|
|FAIL_TO_GET_CREDENTIAL_SERVICE|10011|AGC SDK内部获取凭证能力不可用。|
|WEBSOCKET_NOT_SUPPORT|10012|当前不支持websocket。|
|WEBSOCKET_ERROR|10013|websocket错误。|
