# ObjectTypeInfo

|:--------------------|:------------------------------------------|
|schemaVersion: number|schema文件中的schemaVersion字段，可以自动从schema文件中获取。|

|objectTypes: any|schema文件中的objectTypes字段，可以自动从schema文件中获取。|
