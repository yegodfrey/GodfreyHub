# ProductCheckInfo

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:-----|:---------------------------|
|checkItem|M|String|商品检查编码，固定取值为201。|
|checkResult|M|String|检查结果： * 1：有激活的商品 * 0：没有激活的商品|
