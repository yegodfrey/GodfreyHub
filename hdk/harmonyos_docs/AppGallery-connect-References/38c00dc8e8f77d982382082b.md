# 应用游戏分类

本章节仅提供**HarmonyOS 3.1/4.0及以下应用/元服务和Android应用** 的分类，HarmonyOS NEXT应用/元服务的分类请参见[应用游戏分类](https://developer.huawei.com/consumer/cn/doc/app/agc-help-connect-api-appendix-apptype-0000002271160689)。

## 非手表

> 说明
>
> 为了提升游戏推荐的精准度，同时保障用户快速查找游戏的便捷体验，我们计划于2026年3月1日优化游戏的分类体系。
>
> 从2026年3月1日至2026年5月31日，**HarmonyOS 3.1/4.0及以下应用/元服务** 请调用[更新应用基本信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-info-update-0000001111685198)接口，并根据[新分类](#section1052311010245)修改childType和grandChildType参数。如果未能在2026年6月1日前完成参数更新，可能会导致接口调用异常。
>
> **Android应用** 不涉及本次修改，请继续使用[旧分类](#section1840622415220)。
