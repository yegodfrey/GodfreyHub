# FFPerFrameObjectMatrices

每帧数据的物体相机投影矩阵。  
Structure Declaration

```
typedef struct FFPerFrameObjectMatrices {
    FFStructureType sType;
    const void* pNext;
    uint32_t numMatrixPairs;
    const FFObjectMatrixPair* pMatrixPairs;
} FFPerFrameObjectMatrices;
```

Members  

|Name|Mandatory/Optional|Description|
|:-------------|:-----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------|
|sType|Mandatory|此结构体类型必须为FF_STRUCTURE_TYPE_PER_FRAME_OBJECT_MATRICES。|
|pNext|Optional|指向扩展链中的下一个结构体的指针。扩展参数，可缺省，默认值为NULL。|
|numMatrixPairs|Mandatory|物体矩阵对数组中的元素数。|
|pMatrixPairs|Mandatory|物体矩阵对数组，具体请参见[FFObjectMatrixPair](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffobjectmatrixpair-0000001791494348)。|
