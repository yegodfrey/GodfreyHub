# FileMetadata

|Interface Info|
|:----------------------------------------------------------------------------|
|export interface FileMetadata extends UploadMetadata 文件的所有元数据集合，不支持在目录上设置元数据。|

#### Property Summary

|Name|Type|Description|
|:-----|:-----|:--------------|
|bucket|string|存储实例的名称。|
|path|string|本地文件上传到云端的完整路径。|
|name|string|本地文件上传到云端后的名称。|
|size|number|文件的大小。|
|ctime|string|云端文件的创建时间。|
|mtime|string|云端文件的修改时间。|
