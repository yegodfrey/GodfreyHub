# AGConnectCloudDB

Cloud DB入口类，为多个数据处理位置提供AGConnectCloudDB实例。初始化AGConnectCloudDB后，您需要先获取实例，然后基于该实例，可实现打开或者关闭CloudDBZone等功能。  

#### Summary

|Qualifier and Type|Method name|
|:---------------------|:----------------------------------------------------------------------------------------------------------|
|void|[initialize](#section35300125219)(agconnectServiceConfig: AGConnectServicesConfig) 初始化AGConnectCloudDB。|
|AGConnectCloudDB|[getInstance](#section16294717127)(agcRoutePolicy?: AGCRoutePolicy) 获取对应数据处理位置的AGConnectCloudDB实例。|
|void|[createObjectType](#section10644219429)(objectTypeInfo: ObjectTypeInfo) 创建或修改对象类型，定义存储CloudDBZoneObject的集合。|
|Promise\<CloudDBZone\>|[openCloudDBZone](#section1366119221121)(config: CloudDBZoneConfig) 在端侧打开一个CloudDBZone对象。|
|void|[closeCloudDBZone](#section109681435112)(cloudDBZone: CloudDBZone) 关闭端侧打开的CloudDBZone对象。|

#### Methods

#### initialize

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------|
|initialize(agconnectServiceConfig: AGConnectServicesConfig): void 调用此方法初始化AGConnectCloudDB。在获取AGConnectCloudDB实例前，必须先调用此方法初始化AGConnectCloudDB。|

Parameters  

|Parameter name|Parameter desc|
|:----------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|agconnectServiceConfig: AGConnectServicesConfig|AppGallery Connect网站导出的参数配置，用于与服务端建立交互，详细请参见[集成SDK并使用数据库](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-sdk-integration-quickagame-0000001518866288)。|

Throws  

|Exception name|Exception desc|
|:------------------------|:-------------------------------------------------------------|
|AGConnectCloudDBException|云数据库异常基类，传入的agconnectServiceConfig不合法时，会返回异常信息。您必须显式地捕获并处理此异常。|

#### getInstance

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|getInstance(agcRoutePolicy?: AGCRoutePolicy): AGConnectCloudDB 调用此方法获取对应数据处理位置的AGConnectCloudDB实例。获取实例后，才能使用云数据库服务进行应用开发和数据管理，如打开和关闭CloudDBZone等。在不传入参数时，返回默认数据处理位置的实例。|

Parameters  

|Parameter name|Parameter desc|
|:------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|agcRoutePolicy?: AGCRoutePolicy|[AGCRoutePolicy](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-web-agcroutepolicy-0000001159665971)枚举对象。通过传入该对象，获取指定地区的AGConnectCloudDB实例。如果不传该参数，则返回默认数据处理位置的AGConnectCloudDB实例。|

Return  

|type|desc|
|:---------------|:------------------|
|AGConnectCloudDB|AGConnectCloudDB对象。|

#### createObjectType

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|createObjectType(objectTypeInfo: ObjectTypeInfo): void 调用此方法在端侧创建或修改对象类型，定义存储CloudDBZoneObject的集合，存储应用产生的数据信息。 您从AppGallery Connect控制台导出的对象类型定义json文件中主要包含版本信息和对象类型信息。您添加导出文件至应用对应目录下，通过设置createObjectType()即可获取到对象类型信息，实现对象类型的定义和创建。 对象类型版本升级时，从AppGallery Connect控制台下载的对象类型版本需要高于当前已存在的对象类型版本。如果该方法的入参与已有并持久化的对象类型不一致时，系统将会自动升级该对象类型。|

Parameters  

|Parameter name|Parameter desc|
|:-----------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|objectTypeInfo: ObjectTypeInfo|不需要手动构建该参数，只需要从AppGallery Connect控制台下载json格式的对象类型定义文件，并添加至应用对应目录下，然后将参数值设置为"require('../config/xxx.json');"，即可获取到对象类型信息，其中xxx.json为从控制台下载的json文件。 ``` objectTypeInfo = require('../config/xxxxx.json'); ```|

Throws  

|Exception name|Exception desc|
|:------------------------|:--------------------------------------------|
|AGConnectCloudDBException|云数据库异常基类，创建或修改对象类型失败时，会返回异常信息。您必须显式地捕获并处理此异常。|

#### openCloudDBZone

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|openCloudDBZone(config: CloudDBZoneConfig): Promise\<CloudDBZone\> 调用此方法在端侧打开一个CloudDBZone对象，一个CloudDBZone对象表示一个唯一的数据存储区域。 您可以多次打开某个CloudDBZone，但每次使用完CloudDBZone后，都需要关闭该CloudDBZone。当同一个CloudDBZone打开次数多于关闭次数时，该CloudDBZone仍然可用。|

Parameters  

|Parameter name|Parameter desc|
|:------------------------|:-----------------------------------------|
|config: CloudDBZoneConfig|CloudDBZoneConfig对象，内部包含了CloudDBZone对象的名称。|

Return  

|type|desc|
|:---------------------|:----------------------------------------------------------------------------------------|
|Promise\<CloudDBZone\>|Promise对象，接口调用成功则通过Promise获取到CloudDBZone对象，您可通过该对象实现数据增、删、改、查等功能；调用失败则通过Promise对象获取到异常信息。|

#### closeCloudDBZone

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|closeCloudDBZone(cloudDBZone: CloudDBZone): void 调用此方法关闭端侧打开的CloudDBZone对象。 使用本方法关闭某个CloudDBZone前，需要确保当前基于该CloudDBZone的数据的写入、删除、查询操作已完成，否则会无法关闭。 您在使用一个CloudDBZone进行数据增、删、改、查操作之后，可以根据需要选择是否暂时关闭该CloudDBZone，从而释放该CloudDBZone占用的资源。关闭某个不存在的CloudDBZone，或者重复关闭时，系统均返回成功，不会抛出异常。|

Parameters  

|Parameter name|Parameter desc|
|:-----------------------|:------------------|
|cloudDBZone: CloudDBZone|需要关闭的CloudDBZone对象。|

Throws  

|Exception name|Exception desc|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------|
|[AGConnectCloudDBException](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agconnectclouddbexception-quickgame-0000001128628120)|云数据库异常基类，关闭端侧打开的CloudDBZone对象失败时，会返回异常信息。您必须显式地捕获并处理此异常。|
