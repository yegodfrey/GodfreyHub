# AGCAppMessagingDelegate

|Class Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
|消息事件。 OBJECTIVE-C ```screen @protocol AGCAppMessagingDelegate <NSObject> ``` SWIFT ```screen public protocol AGCAppMessagingDelegate : NSObjectProtocol ```|

## -appMessagingOnDisplay:

消息展示回调。

**OBJECTIVE-C**

```screen
- (void)appMessagingOnDisplay:(nonnull AGCAppMessagingDisplayMessage *)message;
```

**SWIFT**

```screen
optional func appMessaging(onDisplay message: AGCAppMessagingDisplayMessage)
```

**Parameters**

|Name|Description|
|:------|:----------|
|message|当前消息|

## -appMessagingOnClick:button:

消息点击回调。

**OBJECTIVE-C**

```screen
- (void)appMessagingOnClick:(nonnull AGCAppMessagingDisplayMessage *)message
                     button:(AGCAppMessagingActionButton *_Nullable)button;
```

**SWIFT**

```screen
optional func appMessaging(onClick message: AGCAppMessagingDisplayMessage, button: AGCAppMessagingActionButton)
```

**Parameters**

|Name|Description|
|:------|:----------|
|message|当前消息。|
|button|点击的按钮。|
