# ListenerHandler

ListenerHandler类表示一个快照侦听，当调用CloudDBZone类中的[subscribeSnapshot()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-web-0000001080859822#section630612914412)方法成功注册快照侦听时才会获取一个ListenerHandler对象。直到您显式地调用remove()方法注销快照侦听，否则快照侦听将会一直生效，即快照发生任何变化都会持续的通知您并调用[onSnapshot()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-onsnapshotlistener-web-0000001081019780#section731919567292)方法。  

#### Summary

|Qualifier and Type|Method name|
|:-----------------|:---------------------------------------|
|void|[remove()](#section520052033014) 注销快照侦听。|

#### Methods

#### remove

|Method|
|:------------------------------------------------------------------------------------------------------|
|remove(): void 调用此方法注销快照侦听。如果未注销快照侦听，快照侦听将会一直生效，即快照发生任何变化都会持续的通知您并调用onSnapshot()方法，且您将会无法关闭CloudDBZone。|
