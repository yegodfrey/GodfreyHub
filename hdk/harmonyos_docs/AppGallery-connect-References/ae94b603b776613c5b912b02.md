# AESAlg

AES对称加解密算法枚举类型，枚举值、分组模式、填充模式如下：  

|枚举值|分组模式|密钥长度（bit）|填充模式|API版本|
|:-------------------|:---|:------------|:-----------|:----|
|AES_CBC_PKCS5Padding|CBC|128\|192\|256|PKCS5Padding|11+|
|AES_CBC_PKCS7Padding|CBC|128\|192\|256|PKCS7Padding|11+|
|AES_GCM_NoPadding|GCM|128\|192\|256|NoPadding|11+|
|AES_CFB_NoPadding|CFB|128\|192\|256|NoPadding|11+|
|AES_OFB_NoPadding|OFB|128\|192\|256|NoPadding|11+|
|AES_CTR_NoPadding|CTR|128\|192\|256|NoPadding|11+|

导入模块：

```
import { aegis } from '@hw-agconnect/petal-aegis';
```
