# UserRatioCond

|参数|必选(M)/可选(O)|类型|描述|
|:----------|:----------|:------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
|operator|M|String|操作符，取值范围： * LESS_EQUAL：\<= * GREATER_THAN：\>|
|value|M|Integer|取值范围为1-100000000，取值为用户百分比乘以100000000之后的整型值。 例如：若用户百分比为2%，此处需要配置为2000000。|
|randomValue|O|String|AGC会根据randomValue（默认值为default，您可以自定义）将每个应用实例映射到一个固定的整数或小数上面（0.000001\~100的范围），这样每个应用实例到服务器来获取数据时就能识别出是否满足当前的条件。 如果您想要一个应用实例被映射成多个数字，则需要添加多个此类型的条件，每个条件使用不同的随机数。|
