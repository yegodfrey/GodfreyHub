# HwGameAuthProvider

华为游戏账号凭证的提供者。仅支持快游戏。  

#### Method Summary

|Qualifier and Type|Method Name and Description|
|:-------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------|
|[AGConnectAuthCredential](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauthcredential-web-0000001054104571)|static [credentialWithPlayerSign](#section1994762615505)(HwGameAuthReq:HwGameAuthReq, autoCreateUser:boolean) 登录凭证的构造器。|

#### Methods

#### credentialWithPlayerSign

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|static credentialWithPlayerSign(HwGameAuthReq, autoCreateUser:boolean):[AGConnectAuthCredential](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauthcredential-web-0000001054104571) 登录凭证的构造器。|

Parameters

入参HwGameAuthReq对象中需要包含以下参数：  

|Name|Description|
|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
|playerSign|玩家的登录签名，用于应用服务端调用[校验登录签名](https://developer.huawei.com/consumer/cn/doc/HMSCore-References-V5/verify-login-signature-0000001050123503-V5)接口时，向华为发起登录签名验证。|
|playerId|账号ID，如果游戏不需要华为账号的登录结果进行鉴权，那么当返回playerId的时候就可以使用该值进入游戏。|
|displayName|用户的昵称。|
|imageUrl|玩家头像链接。|
|playerLevel|玩家等级。|
|signTs|时间戳，用于鉴权签名校验。|

Return  

|Type|Description|
|:-------------------------------------------------------------------------------------------------------------------------------------------------|:-----------|
|[AGConnectAuthCredential](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauthcredential-web-0000001054104571)|AGConnect凭证。|

Sample Code

```
qg.gameLoginWithReal({// 调用快游戏登录接口
  forceLogin:1,// 玩家未登录华为账号或鉴权失败时，是否拉起登录页面。0--不拉取,1--拉取
  appid:"",// 在华为开发者联盟上创建快游戏后分配的唯一标识。
  success:function(data){
    let HwGameAuthReq = {
      playerSign: data.gameAuthSign,
      playerId: data.playerId,
      displayName:data.displayName,
      imageUrl: data.imageUri,
      playerLevel: data.playerLevel,
      signTs: data.ts
    };  
agc.auth().signIn(agc.auth.HwGameAuthProvider.credentialWithPlayerSign(HwGameAuthReq )).then(res=>{
console.log("signIn ok");
}).
catch(e=>{
console.log("signIn fail");
});
  },
fail:function(data,code){console.log("gameLogin fail:" + JSON.stringify(data) + ", code:" + code);}
});
```
