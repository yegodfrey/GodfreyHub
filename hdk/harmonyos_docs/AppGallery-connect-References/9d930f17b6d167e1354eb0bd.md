# TransactionFunction

通过实现该接口，并重写apply方法，来定义事务需要执行的操作。您可以在apply()方法中使用transaction进行executeQuery、executeUpsert和executeDelete操作。

## Summary

|Qualifier and Type|Method name|
|:-----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Promise<boolean>|[apply](#section11779432202011)(transaction: Transaction) 通过实现此接口来定义事务需要执行的操作，即定义[Transaction](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-transaction-server-nodejs-0000001718772390)类中的executeQuery()、executeUpsert()和executeDelete()操作。Cloud DB会自动调用apply()方法来执行您自定义的操作。|

## Methods

### apply

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|apply(transaction: Transaction): Promise<boolean> 通过实现此接口来定义事务需要执行的操作，即定义[Transaction](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-transaction-server-nodejs-0000001718772390)类中的executeQuery()、executeUpsert()和executeDelete()操作。Cloud DB会自动调用apply()方法来执行您自定义的操作。|

**Parameters**

|Parameter name|Parameter desc|
|:-----------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|transaction: Transaction|事务对象，通过调用该对象的接口，完成事务中的对数据的增、删、改、查操作。详细信息请参见[Transaction](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-transaction-server-nodejs-0000001718772390)。|

**Return**

|type|desc|
|:---------------|:---------------------------------------------------------------------|
|Promise<boolean>|Promise对象，可通过该对象获取定义的事务内操作是否有效。 * true：定义的事务内操作有效。 * false：定义的事务内操作无效。|
