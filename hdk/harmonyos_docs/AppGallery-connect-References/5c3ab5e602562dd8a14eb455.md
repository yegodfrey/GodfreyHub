# FrameFlow_GetCapabilitiesInfo

|Function Info|
|:------------------------------------------------------------------------------|
|FFResult FrameFlow_GetCapabilitiesInfo(FFCapabilitiesInfo\* pCapsInfo); 查询版本信息。|

|Name|Description|
|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
