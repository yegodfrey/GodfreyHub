# CloudDBZone

一个CloudDBZone对象表示一个Cloud DB的存储区域，通过该类提供的方法实现对CloudDBZone中数据的增、删、改、查等操作，实现端云数据的管理。  

#### Summary

|Qualifier and Type|Method name|
|:----------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------|
|Promise\<number\>|[executeUpsert](#section17755153212411)\<T\>(objectList: T\[\] \| T) 将一个或者多个对象写入到当前CloudDBZone。|
|Promise\<number\>|[executeDelete](#section137618361416)\<T\>(objectList: T\[\] \| T) 删除CloudDBZone中与传入对象主键值相同的一个或者多个对象。|
|Promise\<CloudDBZoneSnapshot\<T\>\>|[executeQuery](#section1894919381041)\<T\>(cloudDBZoneQuery: CloudDBZoneQuery\<T\>) 从CloudDBZone中查询满足特定条件的对象，并将查询到的结果集封装到一个CloudDBZoneSnapshot中。|
|Promise\<number\>|[executeAverageQuery](#section748416563413)\<T\>(cloudDBZoneQuery: CloudDBZoneQuery\<T\>, fieldName: string) 从CloudDBZone中查找满足特定条件的对象，返回指定字段的数据记录值的算术平均值。|

#### Methods

#### executeUpsert

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|executeUpsert\<T\>(objectList: T\[\] \| T): Promise\<number\> 调用此方法将一个或者多个对象写入到当前CloudDBZone。如果在CloudDBZone已经存在主键值相同的对象，则更新CloudDBZone中已有的对象；如果不存在，则写入一个或者多个新的对象。 调用本方法需要遵循以下约束： * 仅当CloudDBZone为打开状态时，才允许调用该方法写入对象，否则会导致写入失败。 * 写入多个对象时，数据总大小不能超过2MB，否则会导致写入失败。 * 写入多个对象时，数据总条数不能超过1000条，否则会导致写入失败。|

Parameters  

|Parameter name|Parameter desc|
|:---------------------|:-------------|
|objectList: T\[\] \| T|一个或者多个待写入的对象。|

Return  

|type|desc|
|:----------------|:----------------------------------------------------------|
|Promise\<number\>|Promise对象。通过此Promise对象可以异步获取操作结果，写入成功返回写入成功的条数，写入失败则返回异常信息。|

#### executeDelete

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|executeDelete\<T\>(objectList: T\[\] \| T): Promise\<number\> 调用此方法删除CloudDBZone中与传入对象主键值相同的一个或者多个对象。删除操作只关注对象的主键值是否相同，不考虑对象其它属性和存储的数据是否匹配。如果CloudDBZone中不存在相同主键值的对象，调用此方法将不做任何操作，对CloudDBZone无影响，执行结果为成功。 调用本方法需要遵循以下约束： * 仅当CloudDBZone为打开状态时，才允许调用此方法删除对象，否则会导致删除失败。 * 删除多个对象时，数据总大小不能超过2MB，否则会导致删除失败。 * 删除多个对象时，数据总条数不能超过1000条，否则会导致删除失败。|

Parameters  

|Parameter name|Parameter desc|
|:---------------------|:-------------|
|objectList: T\[\] \| T|一个或者多个待删除的对象。|

Return  

|type|desc|
|:----------------|:--------------------------------------------------------|
|Promise\<number\>|Promise对象。通过此Promise对象可以异步获取操作结果，删除成功返回删除成功的条数，失败则返回异常信息。|

#### executeQuery

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|executeQuery\<T\>(cloudDBZoneQuery: CloudDBZoneQuery\<T\>): Promise\<CloudDBZoneSnapshot\<T\>\> 调用此方法从CloudDBZone中查询满足特定条件的对象，并将查询到的结果集封装到一个CloudDBZoneSnapshot中。 调用本方法需要遵循以下约束： * 仅当CloudDBZone为打开状态时，才允许调用此方法查询对象，否则会导致查询失败。 * 每次查询结果的数据大小不能超过5MB，否则会导致查询失败。 * 查询结果中包含的数据条数不能超过1000条，否则会导致查询失败。|

Parameters  

|Parameter name|Parameter desc|
|:--------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|cloudDBZoneQuery: CloudDBZoneQuery\<T\>|一个CloudDBZoneQuery对象，表征查询条件。CloudDBZoneQuery类中提供了诸如where()、equalTo()、notEqualTo()、greaterThan()等方法，用以封装和实现查询的条件，具体可参见[CloudDBZoneQuery](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-quickgame-0000001174747733)。|

Return  

|type|desc|
|:----------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Promise\<CloudDBZoneSnapshot\<T\>\>|Promise对象。通过此Promise对象可以异步获取操作结果，如果查询成功，通过该对象可以获取一个[CloudDBZoneSnapshot](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonesnapshot-quickgame-0000001128787912)对象，其中封装了查询的结果集；如果查询失败，通过该对象可以获取异常信息。|

#### executeAverageQuery

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|executeAverageQuery\<T\>(cloudDBZoneQuery: CloudDBZoneQuery\<T\>, fieldName: string): Promise\<number\> 调用此方法从CloudDBZone中查找满足特定条件的对象，返回指定字段的算术平均值。 仅当CloudDBZone为打开状态时，才允许调用此方法查询指定字段的平均值，否则会导致查询失败。|

Parameters  

|Parameter name|Parameter desc|
|:--------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|cloudDBZoneQuery: CloudDBZoneQuery\<T\>|一个CloudDBZoneQuery对象，表征查询条件。CloudDBZoneQuery类中提供了诸如where()、equalTo()、notEqualTo()、greaterThan()等方法，用以封装和实现查询的条件，具体可参见[CloudDBZoneQuery](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-quickgame-0000001174747733)。|
|fieldName|用于指定查询对象中需要计算平均值的字段名称。 指定字段的数据类型只支持如下类型：Byte、Short、Integer、Long、Float、Double。|

Return  

|type|desc|
|:----------------|:-----------------------------------------------------------|
|Promise\<number\>|Promise对象。通过此Promise对象可以异步获取操作结果，查询成功返回指定字段的算术平均值，失败则返回异常信息。|

#### executeServerStatusQuery

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|executeServerStatusQuery(): Promise\<ServerStatus\> 调用此方法从CloudDBZone中查询当前服务器的状态。并将查询到的服务器状态封装到一个[ServerStatus](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-serverstatu-quickgame-0000001450143888)中。当前ServerStatus中包含服务器的时间戳状态。 仅当CloudDBZone为打开状态时，才允许调用此方法查询服务器的状态，否则会导致查询失败。|

Return  

|type|desc|
|:----------------------|:-------------------------------------------------------|
|Promise\<ServerStatus\>|Promise对象。通过此Promise对象可以异步获取操作结果，查询成功返回服务器的状态，失败则返回异常信息。|
