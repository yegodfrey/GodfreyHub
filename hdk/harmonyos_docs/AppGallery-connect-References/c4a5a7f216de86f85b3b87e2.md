# Logger

|Interface Info|
|:-------------------------------|
|export interface Logger SDK日志对象。|

#### Property Summary

|Name|Type|Description|
|:----|:-------|:-----------------------------------------------------------------|
|level|LogLevel|日志打印级别，支持LogLevel.DEBUG、LogLevel.INFO、LogLevel.ERROR、LogLevel.OFF。|

Sample Code

```
// 设置日志打印级别
window.GOBE.Logger.level = window.GOBE.LogLevel.INFO;
```
