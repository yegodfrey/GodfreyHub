# AGCCloudDBZoneSyncMode

```screen
NS_ENUM (NSInteger, AGCCloudDBZoneSyncMode) {}
```

CloudDBzone的数据同步属性。

## AGCCloudDBZoneSyncModeLocalOnly

本地模式，数据只存储在端侧，不同步至云侧。

**OBJECTIVE-C**

```screen
AGCCloudDBZoneSyncModeLocalOnly = 0
```

## AGCCloudDBZoneSyncModeCloudCache

缓存模式，数据存储在云侧，端侧数据是云侧数据的子集，如果允许持久化，Cloud DB支持将查询的结果自动缓存至端侧。在端侧对云侧数据注册侦听后，云侧数据变化时，才会通知端侧。

**OBJECTIVE-C**

```screen
AGCCloudDBZoneSyncModeCloudCache = 1
```
