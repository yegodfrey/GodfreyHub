# ohAegHuksDecTextHex

ohAegHuksDecTextHex(keyAlias: string, text: string \| Uint8Array): Promise\<string\>

基于HUKS的AES-GCM解密，配套[ohAegHuksEncTextHex](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ohaeghuksenctexthex-0000001866085404)接口使用，分组模式、填充模式如下：  

|分组模式|密钥长度（bit）|填充模式|API版本|
|:---|:--------|:--------|:----|
|GCM|256|NoPadding|11+|

导入模块：

```
import { AegHuks } from '@hw-agconnect/petal-aegis';
```

参数：  

|参数名|类型|必填|说明|
|:-------|:----------------|:-|:----------------------------------------------------------|
|keyAlias|string|是|密钥别名。|
|text|string或Uint8Array|是|待解密内容（ohAegHuksEncTextHex加密后的结果），格式为iv:密文或者同类的Uint8Array格式。|

返回值：  

|参数|类型|说明|
|:----------|:-----|:---------|
|decryptText|String|解密后的明文字符串。|

示例：

```
import { AegHuks } from '@hw-agconnect/petal-aegis';
import { buffer } from '@kit.ArkTS';

async function aesgcmhuks2() {
  let alias = 'aegis';
  let plainText = 'hello world'; //待加密内容
  let iv = '987654321321'; //长度12字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let ivUint8 = new Uint8Array(buffer.from(iv, 'utf-8').buffer);

  try {
    let encryptText = await AegHuks.ohAegHuksEncTextHex(alias, plainText, ivUint8);
    //aesgcmhuks2  encryptText: 393837363534333231333231:3e74dfc5dcb95b5dc9429dd6412b01df5dd22b8941e7a4504c17e8
    console.log("aesgcmhuks2 ", 'encryptText: ' + encryptText);

    let decryptText = await AegHuks.ohAegHuksDecTextHex(alias, encryptText);

    if (plainText === decryptText) {
      console.info('aesgcmhuks2 decrypt ok');
    }
    console.log("aesgcmhuks2 ", 'decryptText: ' + decryptText);
  } catch (err) {
    console.log("aesgcmhuks2 ", 'err: ' + err);
  }
}
```
