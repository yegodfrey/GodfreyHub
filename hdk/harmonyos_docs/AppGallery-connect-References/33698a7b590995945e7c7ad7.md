# FFAlgorithmCapabilitiesInfo

预测算法配置信息。

**Structure Declaration**

```screen
typedef struct FFAlgorithmCapabilitiesInfo {
    FFStructureType sType;
    void* pNext;
    FFPerFrameDataFlags requiredPerFrameData;
    FFPerFrameDataFlags optimalPerFrameData;
    uint32_t warmUpPeriod;
    // ...
    uint32_t maxDynamicReprojectedObjects;
} FFAlgorithmCapabilitiesInfo;
```

**Members**

|Name|Mandatory/Optional|Description|
|:---------------------------------------|:-----------------|:-------------------------------------------------------------------------------------------------------|
|sType|Mandatory|此结构体类型必须为**FF_STRUCTURE_TYPE_ALGORITHM_CAPABILITIES_INFO**。|
|pNext|Optional|指向扩展链中的下一个结构体的指针。扩展参数，可缺省，默认值为NULL。|
|(Out value) requiredPerFrameData|Mandatory|此算法所需的每帧数据类型的位掩码。如果未提供此掩码中设置的某些位，在使用此算法预测帧时，将返回错误码FF_ERROR_INSUFFICIENT_INPUT_DATA。|
|(Out value) optimalPerFrameData|Mandatory|达到最佳预测质量或性能所需的每帧数据类型的位掩码。|
|(Out value) warmUpPeriod|Mandatory|预测帧将在第几帧后开始绘制，此帧之前的阶段为预测帧的准备（warmUp）阶段。例如，值为3时，则预测帧将在游戏自己生成的第3帧之后开始绘制，第3帧（含）之前的阶段为预测帧准备阶段。不同预测算法返回不同的数值。|
|(Out value) maxDynamicReprojectedObjects|Mandatory|可跟踪动态物体的最大数值。|
