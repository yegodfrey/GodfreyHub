# Persistence

仅Web应用支持设置存储位置，快应用/快游戏无需设置。

|Name|Value|Description|
|:-----------------|:----|:--------------------------------------------------------------------------------------------------------------|
|persistenceStorage|0|数据持久化存储在浏览器IndexedDB中，数据长期存在。 > 注意 > 由于在浏览器中持久化数据有数据泄露风险，且信息默认明文存储，请谨慎选择。同时您可以自行实现加解密方法，设置到SDK中，SDK会对数据进行加密后存储。|
|temporaryStorage|1|数据持久化存储在浏览器sessionStorage中，浏览器重启后数据清除。|
|memoryStorage|2|数据存储在内存中，不做持久化，浏览器页签刷新或重启浏览器，数据清除。|
