# 创建商品

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250806180208.88940292184721380100085175151126:50001231000000:2800:BD43182068F6868E88EBD82E3EDEF6A7EAFF1022A3273A0C15CCA47939BFF7F6.png)  
如果您前期已使用该接口为您的HarmonyOS 5.0及以上应用接入商品管理，请尽快切换至[HarmonyOS 5.0及以上 V2版本接口](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-addproduct-harmonyosnext-0000002131508844)。  

#### 功能介绍

此接口用于创建商品定义信息，包含商品价格，展示语言等。  

#### 使用约束

接口调用者的角色：账号持有者、管理员、APP管理员、运营。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者服务器-\>数字商品服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/pms/product-price-service/v1/manage/product|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|------------------------------------------------------------------------------------|

#### 请求参数

#### Header

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250806180208.82467534098039653987371665641985:50001231000000:2800:91E2A45D1B74175C1B513F3EBEBB82A71E4B2DEBE66C4BA9511BC689C1B8ABD9.png)

API Client方式  

|参数|必选(M)/可选(O)|类型|描述|
|:------------|:----------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|M|String|客户端ID，获取方法参考[创建API客户端](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section103mcpsimp)。|
|Authorization|M|String|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)中获取的access_token。|
|appId|M|String|应用ID，获取方法参考[查询应用信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/appgallery_queryappinfo)。|

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|

|参数|必选（M）/可选（O）|类型|描述|

|product|M|[ProductInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-pms-productinfo-android-0000002171288637)|商品信息。|

#### 调用示例

```
"Java"
public static ProductCreateResp createProductInfo(String domain, String clientId, String authorization,
    String appId, ProductCreateReq request) {
    String url = domain + "/api/pms/product-price-service/v1/manage/product";
    HttpPost post = new HttpPost(url);
    setHttpHead(clientId, authorization, appId, post);
    StringEntity entity =
        new StringEntity(JSON.toJSONString(request), ContentType.create("application/json", "UTF-8"));
    post.setEntity(entity);
    String result = getApiResp(post);
    if (StringUtils.isNotEmpty(result)) {
        return JSON.parseObject(result, ProductCreateResp.class);
    }
    return null;
}
```
