# 查询应用评分

#### 功能介绍

开发者查询对应应用下的评分列表及综合评分。  

#### 使用约束

接口调用者的角色：账号持有者、管理员、APP管理员、运营。  

#### 接口原型

|承载协议|HTTPS GET|
|接口方向|开发者服务器-\>应用市场服务端|
|接口URL|https://{domain}/api/reviews/v1/manage/dev/ratings?appId={appId}\&beginTime={beginTime}\&endTime={endTime}\&countries={countries}\&apkVersions={apkVersions}\&rating={rating}\&sort={sort}\&page={page}\&limit={limit} 中国站点的domain：connect-api.cloud.huawei.com 德国站点的domain：connect-api-dre.cloud.huawei.com 新加坡站点的domain：connect-api-dra.cloud.huawei.com 俄罗斯站点的domain：connect-api-drru.cloud.huawei.com 注意： 调用[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)接口时使用的域名必须与本接口域名保持一致，例如本接口使用"connect-api-dre.cloud.huawei.com"，则调用[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)接口必须使用"https://connect-api-dre.cloud.huawei.com/api/oauth2/v1/token"。|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### 请求参数

#### Query

|参数|必选(M)/可选(O)|参数类型|描述|
|:----------|:----------|:------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|appId|M|String|应用ID，获取方法参考[查询应用信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/appgallery_queryappinfo)。|
|beginTime|M|Long|开始时间的时间戳，从1970/01/01 08:00:00开始计算的毫秒数。|
|endTime|M|Long|结束时间的时间戳，从1970/01/01 08:00:00开始计算的毫秒数。 beginTime和endTime不能超过6个月的跨度。|
|countries|M|String|ISO国家码（例如：CN），多个国家码使用英文逗号分隔，但一次只能查询同一站点内的国家。取值请参考[国家码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-reference-countrycode-0000001111845110)。|
|apkVersions|O|String|应用版本（例：a.b.c），为应用市场中应用显示的版本号。该参数不设置时默认查询所有版本的评论内容，否则请设置具体版本，查询多个版本的评论内容时使用英文逗号分隔。|
|ratings|O|String|评分（1\~5），该参数不设置时默认查询所有评分的评论内容，否则请设置具体评分，查询多个评分的评论内容时使用英文逗号分隔。 例如： * 如果传递参数"5"为查询所有评分为5的评论。 * 如果传递参数"4,5"为查询所有评分为4和5的评论。|
|sort|O|Integer|排序方式，默认值：0。 * 0：BYTIME，按时间排序。 * 1：BYSCOREDESC，按分数降序。 * 2：BYSCOREASC，按分数排序。|
|page|O|Integer|请求查询的页码，默认1。 例如，查询时page配置为2，limit配置为20，表示返回时每页显示20条评论数据，当前查询第2页。|
|limit|O|Integer|每页请求数目，最大100条每页，默认50条。|

#### Header

|参数|必选(M)/可选(O)|类型|描述|
|:------------|:----------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|M|String|客户端ID，获取方法参考[创建API客户端](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section103mcpsimp)。|
|Authorization|M|String|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)中获取的access_token。|

#### 调用示例

```
"Java"
public static GetDevReviewRsp getDevAppRatings(Long devId, String appId, Long beginTime, Long endTime, String countries, String apkVersions, String rating, Integer sort, Integer page, Integer limit, String clientId, String authorization) {
    String url = domain + "/api/reviews/v1/manage/dev/ratings/";
    // 这里只填了必要的参数，其他参数请自行补充
    HttpGet get = new HttpGet(url + reviewId + "?appId=" + appId + "&beginTime=" + beginTime + "&endTime=" + endTime +
    "&limit=" + limit + "&page=" + page);
    get.setHeader("Authorization", "Bearer " + authorization);
    get.setHeader("client_id", clientId);
    try {
        CloseableHttpClient httpClient = HttpClients.createDefault();
        CloseableHttpResponse httpResponse = httpClient.execute(get);
        int statusCode = httpResponse.getStatusLine().getStatusCode();
        if (statusCode == HttpStatus.SC_OK) {
            BufferedReader br =
                new BufferedReader(new InputStreamReader(httpResponse.getEntity().getContent(), Consts.UTF_8));
            String result = br.readLine();
            GetDevAppRatingRsp resp = JSON.parseObject(result, GetDevAppRatingRsp.class);
            return resp;
        }
    } catch (Exception e) {
        log.info("getDevAppRatings fail", e);
    }
    return new GetDevAppRatingRsp();
}
```
