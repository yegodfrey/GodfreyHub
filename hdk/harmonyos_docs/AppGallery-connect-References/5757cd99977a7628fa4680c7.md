# ohAegAesGcmDecTextHex

ohAegAesGcmDecTextHex(text: string | Uint8Array, key: string | Uint8Array): Promise<string>

AES-GCM解密算法，配套[ohAegAesGcmEncTextHex](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ohaegaesgcmenctexthex-0000001910114273)接口使用，分组模式、填充模式如下：

|分组模式|密钥长度（bit）|填充模式|API版本|
|:---|:----------|:--------|:----|
|GCM|128|192|256|NoPadding|11+|

**导入模块：**

```typescript
import { AegAesGcm } from '@hw-agconnect/petal-aegis';
```

**参数** **：**

|参数名|类型|必填|说明|
|:---|:----------------|:-|:----------------------------------------------------------------|
|text|string或Uint8Array|是|待解密内容（ohAegAesGcmEncTextHex加密后的结果），格式为**iv:密文**或者同类的Uint8Array格式。|
|key|string或Uint8Array|是|明文工作密钥（string类型的key需要使用16进制编码格式）。|

**返回值：**

|参数|类型|说明|
|:----------|:-----|:---------|
|decryptText|String|解密后的明文字符串。|

**示例：**

```screen
import { AegAesGcm } from '@hw-agconnect/petal-aegis';
import { buffer } from '@kit.ArkTS';

async function aesgcm2() {
  let plainText = 'hello world'; //待加密内容
  let key = '1234567891234567'; //长度16字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let iv = '987654321321'; //长度12字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let keyUint8 = new Uint8Array(buffer.from(key, 'utf-8').buffer);
  let ivUint8 = new Uint8Array(buffer.from(iv, 'utf-8').buffer);

  try {
    let encryptText = await AegAesGcm.ohAegAesGcmEncTextHex(plainText, keyUint8, ivUint8);
    //aesgcm2  encryptText: 393837363534333231333231:15683c9961e6287af7d85f76c720c990bd2dba2a10705cd0a0bdce
    console.log("aesgcm2 ", 'encryptText: ' + encryptText);

    let decryptText = await AegAesGcm.ohAegAesGcmDecTextHex(encryptText, keyUint8);
    if (plainText === decryptText) {
      console.info('decrypt ok');
    }
    console.log("aesgcm2 ", 'decryptText: ' + decryptText);
  } catch (err) {
    console.log("aesgcm2 ", 'err: ' + err);
  }
}
```
