# AGCRemoteConfigException

## Parameters

|Parameter|Description|
|:--------|:----------|
|message|异常消息。|
|code|异常错误码。|

## 错误码

|Error Code|Value|Description|
|:-----------------------------------|:---------|:---------------------------------|
|FAIL_TO_GET_STORAGE_SERVICE|12000|获取内部储存模块失败。|
|FAIL_TO_DO_SET|12001|数据存储失败。|
|FAIL_TO_DO_GET|12002|获取存储数据失败。|
|FAIL_TO_DO_REMOVE|12003|删除数据失败。|
|FAIL_TO_GET_ABTEST_SERVICE|12004|AB测试无法使用。|
|FETCH_FAILED|12005|调用从云端获取最新的配置数据接口失败。|
|CLIENT_TOKEN_EXPIRED|0x0c401001|client token失效。|
|GET_REMOTE_CONFIG_ERROR_ENABLE_RETRY|0x0c260516|http status为429、500、502、503、504错误。|
|FETCH_THROTTLE_LIMIT|0x0c260517|在流控下发生超时。|
|FETCH_REQ_TIMEOUT|0x0c260518|请求云端配置信息超时。|
|APP_WITH_NO_VALID_CONFIG_INSTANCE|0x0c260519|未配置应用的config信息。|
