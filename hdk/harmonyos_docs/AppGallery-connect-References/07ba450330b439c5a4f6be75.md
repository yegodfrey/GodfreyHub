# TokenParams

|Interface Info|
|:----------------------------------------------------|
|export interface TokenParams verifyAccessToken方法的封装器。|

#### Public Field Summary

|Name|Type|Description|
|:-----------|:------|:----------------------------------------------------------------|
|accessToken|string|用户访问令牌，在用户登录设备时生成，不能为空。|
|checkRevoked|boolean|是否在AGC认证服务的云服务器上对用户的访问令牌进行身份验证，以检查访问令牌是否已被撤销。 true：校验。 false：不校验。|
