# Overview

## Classes

|Classes||
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[Cloud](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-cloud-server-nodejs-0000001781158433)|云侧入口类，为云数据库、云函数、认证服务等服务提供实例。|
|[CloudDB](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddb-server-nodejs-0000001734039358)|云数据库入口类，为多个数据处理位置提供实例。也就是说，每个数据处理位置只有一个CloudDB实例。您需要先获取实例，然后基于该实例，可实现打开CloudDBCollection等操作。|
|[AGConnectCloudDBException](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agconnectclouddbexception-server-nodejs-0000001766691621)|云数据库的异常基类，提供了相应的异常相关的信息，包含错误码和详细错误信息。|
|[CloudDBCollection](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405)|云数据库的存储区域，通过该类提供的方法实现对CloudDBCollection中数据的增、删、改、查和事务等操作，实现云侧数据的管理。|
|[CloudDBZoneGenericObject](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonegenericobject-server-nodejs-0000001766691625)|泛化对象，CloudDBZoneObject的子类 。支持直接使用泛化对象的方式进行数据操作。|
|[CloudDBZoneObjectOperator](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzoneobjectoperator-server-nodejs-0000001718772382)|用于实现构造操作对象的实例、更新指定字段的值的能力。|
|[CloudDBZoneObjectOperatorConstraint](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-objectoperatorconstraint-server-nodejs-0000001718931842)|提供了诸如build()、equalTo()、notEqualTo()、in()等一系列用于构造查询条件的谓词查询。可以基于上述的谓词方法构造自己的CloudDBZoneObjectOperatorConstraint对象。|
|[CloudDBZoneQuery](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-server-nodejs-0000001766572401)|提供诸如equalTo()、notEqualTo()、in()等一系列谓词查询来构造查询条件。您可以基于上述谓词查询来构造自己的CloudDBZoneQuery对象。|
|[CloudDBZoneSnapshot](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonesnapshot-server-nodejs-0000001766691629)|用于描述本次查询到的快照数据，包含全量的对象集合。|
|[Transaction](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-transaction-server-nodejs-0000001718772390)|用来描述一个事务，事务内提供executeQuery()、executeUpsert()和executeDelete()方法，实现对云侧存储区数据的管理操作，包含数据的增、删、改、查等。|
|[ServerStatus](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-serverstatus-server-nodejs-0000001766592781)|服务器状态信息。当调用CloudDB中的[serverStatusQuery()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddb-server-nodejs-0000001734039358#section12358449111114)方法成功查询云侧服务器状态时才会获取ServerStatus对象。|
