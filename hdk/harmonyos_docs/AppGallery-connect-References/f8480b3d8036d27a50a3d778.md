# aesDec

aesDec(alg: AESAlg, ciphertext: Uint8Array, key: string \| Uint8Array, iv?: string \| Uint8Array): Promise\<Uint8Array\>

aes解密算法，返回解密后的明文内容字符串，建议与[aesEnc](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/aesenc-0000001964620493)配套使用。

导入模块：

```
import { aegis } from '@hw-agconnect/petal-aegis';
```

参数：  

|参数名|类型|必填|说明|
|:---------|:-----------------------------------------------------------------------------------------------------------|:-|:-------------------------------------------------------------------------------------------------------------------|
|alg|[AESAlg](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/aesalg-0000001937542110)|是|AES模式枚举。|
|ciphertext|Uint8Array|是|[aesEnc](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/aesenc-0000001964620493)生成的密文内容。|
|key|string或Uint8Array|是|密钥内容，hexstring或Uint8Array格式， 长度请参考模式AESAlg的密钥长度（bit）。|
|iv|string或Uint8Array|否|iv偏移量内容，hexstring或Uint8Array格式，如果传入IV，返回结果的密文中不会携带iv，如果不传入iv，返回的密文结果会携带自动生成的IV，GCM IV长度为12字节，其它模式都是16字节。|

返回值：  

|参数|类型|说明|
|:----------|:---------|:--------------------|
|decryptText|Uint8Array|明文普通字符串的Uint8Array格式。|

示例：

```
import { aegis } from '@hw-agconnect/petal-aegis';
import { buffer } from '@kit.ArkTS';

async function demo() {
  let plainText = 'hello world'; //待加密内容
  let key = '1234567891234567'; //长度16字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let iv = '9876543217654321'; //长度16字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let keyUint8 = new Uint8Array(buffer.from(key, 'utf-8').buffer);
  let ivUint8 = new Uint8Array(buffer.from(iv, 'utf-8').buffer);
  let plainTextUint8 = new Uint8Array(buffer.from(plainText, 'utf-8').buffer);

  try {
    let encryptText = await aegis.aesEnc(aegis.AESAlg.AES_CBC_PKCS7Padding, plainTextUint8 , keyUint8);
    //aescbc  encryptText: 196,62,160,193,158,170,29,8,98,49,82,55,145,77,56,105,58,21,230,222,181,227,87,75,105,24,89,198,25,7,10,227,98
    console.log("aescbc ", 'encryptText: ' + encryptText);

    let decryptText = await aegis.aesDec(aegis.AESAlg.AES_CBC_PKCS7Padding, encryptText, keyUint8);
    if (plainTextUint8 === decryptText) {
      console.info('decrypt ok');
    }
    console.log("aescbc ", 'decryptText: ' + decryptText);
  } catch (err) {
    console.log("aescbc ", 'err: ' + err);
  }
}
```
