# OnSnapshotListener

定义了一个快照侦听器接口，如果您需要侦听快照，则必须实现此接口，定义自己的侦听器。实现该接口时，需要同时调用[subscribeSnapshot()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-web-0000001080859822#section630612914412)来注册侦听。  

#### Summary

|Qualifier and Type|Method name|
|:-----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|void|[onSnapshot](#section731919567292)(snapshot: CloudDBZoneSnapshot\<T\>, exception: AGConnectCloudDBException) 注册快照侦听后，当侦听快照中的数据发生变化时，Cloud DB会自动调用onSnapshot()方法来执行您自定义的操作。|

#### Methods

#### onSnapshot

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
|onSnapshot(snapshot: CloudDBZoneSnapshot\<T\>, exception: AGConnectCloudDBException): void 注册快照侦听后，当侦听快照中的数据发生变化时，Cloud DB会自动调用onSnapshot()方法来执行您自定义的操作。|

Parameters  

|Parameter name|Parameter desc|
|:-----------------------------------|:-------------------------------------------------------------|
|snapshot: CloudDBZoneSnapshot\<T\>|变化后的快照对象，包含了全量的快照数据、新增和修改的对象集合以及新删除的对象集合。|
|exception: AGConnectCloudDBException|Cloud DB的异常基类，当快照发生变化并触发回调时，如果发生异常，会返回异常信息，您可基于异常对象e获取相关的错误信息。|
