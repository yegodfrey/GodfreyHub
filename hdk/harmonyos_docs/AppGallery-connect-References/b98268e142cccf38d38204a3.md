#### userReauthenticate

|Method|
|:-------------------------------------------------------------|
|userReauthenticate(credential: AGConnectAuthCredential) 账号重认证。|

Parameters  

|Name|Description|
|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
|credential|重认证的凭证credential，与[signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section18413636501)接口入参一致。|

Return  

|Type|Description|
|:--------------------------------------------------------------------------------------------------------------------------------------|:----------|
|Promise\<[SignInResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/signinresult-web-0000001054424525)\>|创建账户异步调用结果。|

Sample Code

```
agconnect.auth().getCurrentUser().then(user=>{
  // 手机重认证
  let credential = '';
  if(verifyCode){
    credential = agconnect.auth.PhoneAuthProvider.credentialWithVerifyCode(account, password, verifyCode);
  }else{
    credential = agconnect.auth.PhoneAuthProvider.credentialWithPassword(account, password);
  }
  agconnect.auth().getCurrentUser().then(async user => {
    if(user){
      await agconnect.auth().userReauthenticate(credential);
    }
  });

  // 邮箱重认证
  let credential = '';
  if(verifyCode){
    credential = agconnect.auth.EmailAuthProvider.credentialWithVerifyCode(account, password, verifyCode);
  }else{
    credential = agconnect.auth.EmailAuthProvider.credentialWithPassword(account, password);
  }
  agconnect.auth().getCurrentUser().then(async user => {
    if(user){
      await agconnect.auth().userReauthenticate(credential);
    }
  });
})
```

#### updatePassword

|Method|
|:------------------------------------------------------------------------------------------------------------------|
|updatePassword(newPassword: string, verifyCode: string, provider: number) 用户登录后，更新手机或邮箱密码。以provider区分(11:手机,12:邮箱)。|

Parameters  

|Name|Description|
|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|newPassword|手机或邮箱的新密码。 默认密码规则如下，若您参考[安全配置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-security-configuration-0000001324925609)自定义了密码复杂度请满足自定义的复杂度： 1. 密码长度至少8个字符； 2. 密码必须包含如下至少两种字符的组合： * 至少一个小写字母； * 至少一个大写字母； * 至少一个数字； * 至少一个特殊字符：\`!@#$%\^\&\*()-_=+\\\|\[{}\];:'",\<.\>/? 和空格。 3. 密码不能和手机号码或者邮箱一样。|
|verifyCode|手机或邮箱验证码|
|provider|更新密码类型。 * 11：手机 * 12：邮箱|

Sample Code

```
// 更新手机密码
agconnect.auth().getCurrentUser().then(async user => {
  if(user){
      // 手机provider为11
      await user.updatePassword(newPassword, verifyCode, provider);
  }
});

// 更新邮箱密码
agconnect.auth().getCurrentUser().then(async user => {
  if(user){
      // 邮箱provider为12
      await user.updatePassword(newPassword, verifyCode, provider);
  }
});
```
