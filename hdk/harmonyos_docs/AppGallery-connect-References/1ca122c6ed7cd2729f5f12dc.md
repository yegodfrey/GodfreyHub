# EmailAuthProvider

邮箱凭证提供者。

## Method Summary

|Qualifier and Type|Method Name and Description|
|:-------------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[AGConnectAuthCredential](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauthcredential-web-0000001054104571)|static [credentialWithPassword](#section1924461982211)(email:string, password:string) 通过邮箱和密码获取凭证。|
|[AGConnectAuthCredential](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauthcredential-web-0000001054104571)|static [credentialWithVerifyCode](#section18780241192816)(email:string, password:string, verifyCode:string) 通过邮箱和验证码获取凭证。|
|Promise<[VerifyCodeResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/verifycoderesult-web-0000001054104573)>|static [requestVerifyCode](#section21571814315)(email:string, action: number, lang: string, sendInterval: number) 申请邮箱的验证码。 此方法已废弃，请调用[AGCAuth.requestEmailVerifyCode](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section101775733412)(email:string, action: number, lang: string, sendInterval: number)|

## Methods

### credentialWithPassword

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|static credentialWithPassword(email:string, password:string):[AGConnectAuthCredential](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauthcredential-web-0000001054104571) 通过邮箱和密码获取凭证。|

**Parameters**

|Name|Description|
|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|email|邮箱。|
|password|密码。 默认密码规则如下，若您参考[安全配置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-security-configuration-0000001324925609)自定义了密码复杂度请满足自定义的复杂度： 1. 密码长度至少8个字符； 2. 密码必须包含如下至少两种字符的组合： * 至少一个小写字母； * 至少一个大写字母； * 至少一个数字； * 至少一个特殊字符：`!@#$%^&*()-_=+\|[{}];:'",<.>/? 和空格。 3. 密码不能和手机号码或者邮箱一样。|

**Return**

|Type|Description|
|:-------------------------------------------------------------------------------------------------------------------------------------------------|:------------|
|[AGConnectAuthCredential](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauthcredential-web-0000001054104571)|AGConnect 凭证。|

**Sample Code**

```screen
agconnect.auth.EmailAuthProvider.credentialWithPassword('email', 'password')
```

### credentialWithVerifyCode

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|static credentialWithVerifyCode(email:string, password:string, verifyCode:string):[AGConnectAuthCredential](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauthcredential-web-0000001054104571) 通过邮箱和验证码获取凭证。|

**Parameters**

|Name|Description|
|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|email|邮箱。|
|password|密码（可选）。如果携带了密码，则密码和验证码都会校验。 默认密码规则如下，若您参考[安全配置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-security-configuration-0000001324925609)自定义了密码复杂度请满足自定义的复杂度： 1. 密码长度至少8个字符； 2. 密码必须包含如下至少两种字符的组合： * 至少一个小写字母； * 至少一个大写字母； * 至少一个数字； * 至少一个特殊字符：`!@#$%^&*()-_=+\|[{}];:'",<.>/? 和空格。 3. 密码不能和手机号码或者邮箱一样。|
|verifyCode|验证码。|

**Return**

|Type|Description|
|:-------------------------------------------------------------------------------------------------------------------------------------------------|:------------|
|[AGConnectAuthCredential](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauthcredential-web-0000001054104571)|AGConnect 凭证。|

**Sample Code**

```screen
agconnect.auth.EmailAuthProvider.credentialWithVerifyCode('email', 'password', 'verifyCode')
```

### requestVerifyCode

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|static requestVerifyCode(email:string, action: number, lang: string, sendInterval: number):Promise<[VerifyCodeResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/verifycoderesult-web-0000001054104573)> 申请邮箱的验证码。 此方法已废弃，请调用[AGCAuth.requestEmailVerifyCode](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section101775733412)(email:string, action: number, lang: string, sendInterval: number)|

**Parameters**

|Name|Description|
|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
|email|邮箱。|
|action|验证码属性的配置，包括验证码应用场景（注册/登录或者修改/重置密码）。 验证码类型。 * agconnect.auth.Action.ACTION_REGISTER_LOGIN：登录/注册 * agconnect.auth.Action.ACTION_RESET_PASSWORD：修改/重置密码|
|lang|发送验证码的语言，例如：zh_CN。|
|sendInterval|发送验证码的时间间隔，单位秒，支持30~120秒。|

**Return**

|Type|Description|
|:--------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------|
|Promise<[VerifyCodeResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/verifycoderesult-web-0000001054104573)>|VerifyCodeResult的异步返回对象。|

**Sample Code**

```screen
agconnect.auth.EmailAuthProvider.requestVerifyCode('email',agconnect.auth.Action.ACTION_REGISTER_LOGIN, 'lang', sendInterval)
```
