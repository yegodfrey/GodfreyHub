#### credentialWithPassword

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public static [AGConnectAuthCredential](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-agconnectauthcredential-0000001151371570) credentialWithPassword(String email, String password) 通过邮箱和密码获取凭证。 如果需要关联Email账号，为了确保Email账号为您所有，请调用[credentialWithVerifyCode](#section648110229154)(String email, String password, String verifyCode)接口。|

Parameters  

|Name|Description|
|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|email|邮箱。|
|password|密码。 默认密码规则如下，若您参考[安全配置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-security-configuration-0000001324925609)自定义了密码复杂度请满足自定义的复杂度： 1. 密码长度至少8个字符； 2. 密码必须包含如下至少两种字符的组合： * 至少一个小写字母； * 至少一个大写字母； * 至少一个数字； * 至少一个特殊字符：\`!@#$%\^\&\*()-_=+\\\|\[{}\];:'",\<.\>/? 和空格。 3. 密码不能和手机号码或者邮箱一样。|

Return  

|Type|Description|
|:----------------------|:-----------|
|AGConnectAuthCredential|AGConnect凭证。|
