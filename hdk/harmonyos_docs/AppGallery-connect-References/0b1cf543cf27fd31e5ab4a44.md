# EntitySet

|Class/Struct Info|
|:---------------------------------------------------------------------------------------------------------|
|public sealed class EntitySet : IList<IEntity> IList<IEntity>的实现，一组实体的列表形式表达，支持IList的基本列表操作，可以对一组实体进行批量操作。|

## Property Summary

|Name|Type|Description|
|:---------|:----------------|:----------|
|Count|int|实体数量。|
|Capacity|int|列表容量。|
|World|IECSWorld|世界。|
|Ids|ReadOnlySpan<int>|实体标识的只读内存。|
|IsReadOnly|bool|只读标志。|

**Sample Code**

```screen
var world = new IECSWorld();
var entity = world.CreateEntity(1);
// 创建一个EntitySet并添加一个实体
var entitySet = new EntitySet(world);
entitySet.Add(entity);
// 获取集合中实体数量
entitySet.Count;// 1
// 获取、设置集合容量
entitySet.Capacity; // 1
entity.Capacity = 5;
entitySet.Capacity; // 5
// 获取集合所属world
entitySet.World; // 等于world
// 获取集合所有实体Id
entitySet.Ids[0]; // 1
// 集合的只读属性，默认为false
entitySet.IsReadOnly; // false
```

### Sort<TComponent, TField>

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|SorterItem<TField>[] Sort<TComponent, TField>(string memberName, Order order, SorterItem<TField>[] fields = null) 将实体列表中的实体，按照指定组件的指定字段，以指定顺序，进行排序。 TComponent为IComponent，是排序指定组件，TField为排序指定组件字段数据类型，memberName为排序指定组件字段名，order为排序指定模式，fields为排序结果信息输出，未指定fields则会自动创建一个对应数组返回结果。|

**Parameters**

|Name|Type|Description|
|:---------|:-------------------|:----------|
|memberName|string|组件字段/属性的名字。|
|order|Order|排序模式枚举值。|
|fields|SorterItem<TField>[]|排序后的字段值数组。|

**Return**

|Type|Description|
|:-------------------|:-----------|
|SorterItem<TField>[]|返回排序后的字段值数组。|

**Sample Code**

```screen
var world = new IECSWorld();
var entitySet = new EntitySet(world);
entitySet.Add(world.CreateEntity());
for (int n = 0; n < 2; n++) 
{
    entitySet.Add(world.CreateEntity(new TestComponent1 { value = n }));
}
// 此时集合中实体顺序为：entity1, entity2, entity3
// SorterItem结构用于记录排序后实体Id、对应字段值、是否拥有指定组件字段信息
var fields = new SorterItem<int>[2];
// 若用于记录信息的SorterItem数组长度小于实体集合长度，会将其扩展至相同长度，此处排序前fields长度为2，排序后为3
// 没有指定组件字段的实体固定放在最后
fields = entitySet.Sort<TestComponent1, int>(nameof(TestComponent1.value), Order.Descending, fields);
/* 排序后集合情况 */
// 集合中实体顺序为：entity3, entity2, entity1
/* 排序后fields情况 */
// EntityId: 3, value: 1  EntityId: 2, value: 0  EntityId: 1, value: null
```
