|:------------------------------------------------------------------------------------|
|public interface FeatureInstallManager FeatureInstallManager负责统一管理从华为应用市场途径动态加载的整个过程。|

## Public Methods

### registerInstallListener

|Method|
|:----------------------------------------------------------------------------------------------------|
|public void registerInstallListener(InstallStateListener listener) 注册监听器，监听当前动态加载的状态，如下载进度，安装成功或者失败等。|

**Parameters**

|Name|Description|
|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|listener|开发者指定的[InstallStateListener](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/installstatelistener-0000001059050276)的实例，当动态加载任务执行状态发生更新时，会通过该监听器通知应用。|

### unregisterInstallListener

|Method|
|:-----------------------------------------------------------------------------------------------|
|public void unregisterInstallListener(InstallStateListener listener) 解注册监听器。当动态加载进度发生改变时，不再通知应用。|

**Parameters**

|Name|Description|
|:-------|:-------------------------------------------------------------------------------|
|listener|开发者在调用[registerInstallListener](#section62741512101)()方法时指定的监听器。在此处作为入参，将其进行解注册。|

### installFeature

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public FeatureTask<Integer> installFeature(FeatureInstallRequest request) 根据[FeatureInstallRequest](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/featureinstallrequest-0000001057642233)，动态加载特性或者语言包。|

**Parameters**

|Name|Description|
|:------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|request|开发者根据需求构造的[FeatureInstallRequest](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/featureinstallrequest-0000001057642233)实例，包含需要进行动态加载的特性和语言包信息。|

**Return**

|Type|Description|
|:------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------|
|[FeatureTask](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/featuretask-0000001057492597)<Integer>|返回本次操作的Task对象。通过监听该Task的状态，可以获取本次操作结果。|

### abortInstallFeature

|Method|
|:---------------------------------------------------------------------------------------|
|public FeatureTask<Void> abortInstallFeature(int installId) 根据表示动态加载任务的标识，可以终止当前动态加载的任务。|

**Parameters**

|Name|Description|
|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|installId|用于唯一标识每次动态加载任务的id。在调用installFeature方法安装特性或语言包时，从返回的[FeatureTask](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/featuretask-0000001057492597)中获取。|

**Return**

|Type|Description|
|:---------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------|
|[FeatureTask](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/featuretask-0000001057492597)<Void>|返回本次操作的Task对象。通过监听该Task的状态，可以获取本次操作的结果。|

### triggerUserConfirm

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public boolean triggerUserConfirm(InstallState sessionState, Activity activity, int requestCode) throws IntentSender.SendIntentException 弹出"同意协议"或"同意下载"的提示框。|

**Parameters**

|Name|Description|
|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|sessionState|当前请求的状态，传入在注册[InstallStateListener](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/installstatelistener-0000001059050276)监听器时通过onStateUpdate方法回调的[InstallState](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/installstate-0000001057642241)实例。|
|activity|当前页面的Activity。|
|requestCode|开发者自定义的请求码。|

**Return**

|Type|Description|
|:------|:---------------------------------|
|boolean|弹出提示框的请求是否成功。true表示请求成功，false表示失败。|
