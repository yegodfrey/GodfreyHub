# FrameFlowVK_ProvidePerFrameData

|Function Info|
|:--------------------------------------------------------------------------------------------------------------|
|FFResult FrameFlowVK_ProvidePerFrameData(FFVKInstance instance, const FFVKPerFrameData* pPerFrameData); 提供每帧数据。|

**Parameters**

|Name|Description|
|:------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------|
|instance|库实例。|
|pPerFrameData|指向[FFVKPerFrameData](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffvkperframedata-0000001838253857)结构体的指针，表示指定的预测算法所需的每帧数据。|

**Return**

|Type|Description|
|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
|FFResult|返回结果。 成功时返回0，失败则返回错误码，具体请参见[FFResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffresult-vulkan-0000001791494504)。|
