# RecordInfo

|Interface Info|
|:------------------------------------|
|export interface RecordInfo 对战记录条目信息。|

#### Property Summary

|Name|Type|Description|
|:---------|:---------|:--------------------|
|recordId|string|对战记录ID。|
|appVersion|string|应用版本号。|
|roomId|string|对战记录所属房间ID。|
|playerIds|string\[\]|对战记录中参与玩家的联机对战账号ID列表。|
|url|string|对战记录文件的下载链接。|
|fileSha256|string|对战记录文件的SHA256值。|
|createTime|string|记录创建时间戳。|
