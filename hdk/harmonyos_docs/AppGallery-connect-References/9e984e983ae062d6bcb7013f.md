# FFPredictionAlgorithm

预测算法。  
Enum Info

```
typedef enum FFPredictionAlgorithm {
    FF_PREDICTION_ALGORITHM_HYDRA = 0,
    FF_PREDICTION_ALGORITHM_GRIDWARP = 1,
    FF_PREDICTION_ALGORITHM_IMAGE_ONLY_INTERPOLATION = 2,
    FF_PREDICTION_ALGORITHM_MESH_REPROJ_EXTRAPOLATION = 3,
} FFPredictionAlgorithm;
```

Enum Value Summary  

|Enum Value|Inputs|Benefits|Expected issues|
|:------------------------------------------------|:---------------------|:------------------------------------|:-------------------------------------|
|FF_PREDICTION_ALGORITHM_HYDRA|彩色图像、深度和相机信息|对半透明场景和粒子效果，预测效果比较好。平均而言，功耗比其他选项低。|仅支持内插。|
|FF_PREDICTION_ALGORITHM_GRIDWARP|彩色图像、深度、模板、相机信息和动态对象矩阵|支持内插和外插。当大部分场景是不透明和静态时，效果最好。可以使用模板语义。|对于可变形、小体积、半透明对象、粒子和特效，预测效果相对而言不如另两种算法。|
|FF_PREDICTION_ALGORITHM_IMAGE_ONLY_INTERPOLATION|仅基于彩色图像，无额外数据|易于实现。|仅支持内插。相对于另三种算法，此预测算法开销较高。|
|FF_PREDICTION_ALGORITHM_MESH_REPROJ_EXTRAPOLATION|彩色图像、深度和相机信息|动态、透明和半透明物体单独绘制时，效果最好。|仅支持外插，仅支持OpenGL。|
