# 数据撤回

#### 功能描述

此接口用于主动撤回用户服务事件。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者服务器 -\> 华为服务器|
|接口URL|https://apigw-edu.cloud.huawei.com.cn/app/app-service-api/v1/cp/service-events/revoke|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|
|-----|-------------------------------------------------------------------------------------|

#### 请求参数

#### Header

|参数|是否必选|参数类型|描述|
|:------------|:---|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|x-event-type|是|String|固定填"USER"。|
|x-appid|是|String|上架服务所关联的应用ID。|
|Authorization|是|String|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token为应用ID所对应的应用级Token，即[获取Token](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/appgallerykit_gettoken-0000001050123505)中获取的access_token。|
|x-trace-id|是|String|联运跟踪ID，请求方使用随机数生成，最长32位|

#### Body

CPRevokeServiceEvent  

|参数|是否必选|参数类型|描述|
|:---------|:---|:-----|:--------------------|
|identifier|是|String|需要撤回的请求ID。|
|openId|是|String|和请求头中的x-appid关联的用户ID。|
|abilityId|是|String|服务标识符。|

#### 请求示例

```
POST {url}
Content-Type: application/json
x-appid:******
x-trace-id: *******
x-event-type：******
Authorization: Bearer ******
"body":
{
    "events": [
        {
            "identifier": "string",
            "openId": "string",
            "abilityId": "string"
        }
    ]
}
```

#### 响应参数

|参数|是否必选|参数类型|描述|
|:----------|:---|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------|
|errorEvents|否|String|批量通知时，如果有事件处理失败，在该参数中记录具体错误的请求ID。|
|result|否|String|如果resultCode为0且[errorEvents](#ZH-CN_TOPIC_0000001705040589__p037985018815)的长度为0，代表成功。 resultDesc：错误描述 resultCode：[错误码](#section17457111971515)|

#### 响应示例

```
HTTP/1.1 200 OK
Content Type : application/json ; charset=UTF-8
{
    "errorEvents": [
        {
            "requestId": "2023082310",
            "resultInfo": {
                "desc": "ability not found with eventName"
            }
        }
    ],
    "result": {
        "resultCode": 0,
        "resultDesc": "Operation success"
    }
}
```

#### 错误码

|错误码|说明|
|:---------|:-------------------------------|
|401|app应用级token鉴权失败，检查请求的token是否已过期。|
|1143149448|没有操作权限。|
