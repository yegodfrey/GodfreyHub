# GPMInitParams

|Class Info|
|:------------------------------------------------------------------------------|
|public sealed class GPMInitParams 游戏性能管理SDK初始化参数类。 说明： GPMInitParams类的命名空间为GPM。|

#### Property Summary

|Name|Type|Mandatory/Optional|Description|
|:---------------|:-----------------|:-----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|AppId|string|Mandatory|游戏APP ID信息，获取方法请参见[获取游戏信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-get-authentication-infomation-0000001801791669#section20509644364)。|
|ClientId|string|Mandatory|客户端Client ID信息，获取方法请参见[获取游戏信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-get-authentication-infomation-0000001801791669#section20509644364)。|
|ClientSecret|string|Optional|客户端Client Secret信息，获取方法请参见[获取游戏信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-get-authentication-infomation-0000001801791669#section20509644364)。|
|AccessToken|string|Optional|AGC接入凭证AccessToken信息，获取方法请参见[获取Token（项目级）](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-obtain-project-token-0000001801864849)。 说明： ClientSecret和AccessToken二者传其一即可。基于安全考虑，推荐使用AccessToken。若同时传入，将使用传入的AccessToken作为最终AGC接入凭证。|
|UserIdentity|string|Mandatory|三方账号OpenID。|
|AutoCollectScene|bool|Optional|是否在调用[GPMSDK.EnableCollector()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpmsdk-apis-0000001720136800#section6902152315716)后开始采集、上报游戏的性能数据： * true：表示调用GPMSDK.EnableCollector()后开始采集数据。 * false：表示调用GPMSDK.EnableCollector()后再需要设置场景和标签，才开始采集数据。 默认为false。|
|LogLevel|int|Optional|日志级别： * 0：关闭。 * 1：DEBUG。 * 2：INFO。 * 3：WARN。 * 4：ERROR。 默认为0|
|DataPath|string|Optional|SDK运行时数据和日志的存储目录，建议设置参数Application.persistentDataPath的路径值。 说明： 若未设置存储目录，将默认写到/data/data/游戏包名/files/gpm目录下。|
|CallbackHandler|GPMCallbackHandler|Mandatory|结果回调处理类。各接口通过对应的委托方法来通知回调结果。|
