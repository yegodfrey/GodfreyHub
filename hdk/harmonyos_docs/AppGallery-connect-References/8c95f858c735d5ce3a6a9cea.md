# SorterItem\<TField\>

|Class/Struct Info|
|:-------------------------------------------------------------------------------|
|public struct SorterItem\<TField\> 存储组件字段值及其所属实体，主要用于实体列表的自定义排序。 TField为指定字段的类型。|

#### Property Summary

|Name|Type|Description|
|:-------|:-----|:----------|
|EntityId|int|实体标识。|
|HasField|byte|字段存在标志。|
|Field|TField|字段值。|

Sample Code

```
var world = new IECSWorld();
var entitySet = new EntitySet(world);
entitySet.Add(world.CreateEntity());
for (int n = 0; n < 2; n++) 
{
    entitySet.Add(world.CreateEntity(new TestComponent1 { value = n }));
}
// SorterItem结构用于记录排序后实体Id、对应字段值、是否拥有指定组件字段信息
var fields = new SorterItem<int>[2];
// 若用于记录信息的SorterItem数组长度小于实体集合长度，会将其扩展至相同长度，此处排序前fields长度为2，排序后为3
// 没有指定组件字段的实体固定放在最后
fields = entitySet.Sort<TestComponent1, int>(nameof(TestComponent1.value), Order.Descending, fields);
fields[0].EntityId; // 3
fields[0].Field; // 1
fields[0].HasField; // true
```
