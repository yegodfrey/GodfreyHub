# FFPredictionAlgorithmInfo

预测算法类型及插帧方案。  
Structure Declaration

```
typedef struct FFPredictionAlgorithmInfo {
    FFStructureType sType;
    const void* pNext;
    FFPredictionAlgorithm algorithm;
    FFBool extrapolation;
} FFPredictionAlgorithmInfo;
```

Members  

|Name|Mandatory/Optional|Description|
|:------------|:-----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
|sType|Mandatory|此结构体类型必须为FF_STRUCTURE_TYPE_PREDICTION_ALGORITHM_INFO。|
|pNext|Optional|指向扩展链中的下一个结构体的指针。扩展参数，可缺省，默认值为NULL。|
|algorithm|Mandatory|算法类型，具体请参见[FFPredictionAlgorithm](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffpredictionalgorithm-vulkan-0000001791494476)。|
|extrapolation|Mandatory|插帧方案。 * true：外插 * false：内插 说明： 预测算法FF_PREDICTION_ALGORITHM_HYDRA和FF_PREDICTION_ALGORITHM_IMAGE_ONLY_INTERPOLATION仅支持内插方案。|
