# OnFeatureCompleteListener

|Class Info|
|:------------------------------------------------------------------------------------------------------------------------------------|
|public abstract class OnFeatureCompleteListener <TResult> implements OnFinishListener<TResult> 动态加载任务中表示加载完成的监听器类。无论加载成功还是失败，均属于加载完成。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-------------------------------------------------------------------------------------|
|void|[onComplete](#section12742437199)(FeatureTask<TResult> featureTask) 动态加载任务执行完成时，回调此函数。|

## Public Methods

### onComplete

|Method|
|:-------------------------------------------------------------------------------------------------------------------|
|public void onComplete(final FeatureTask<TResult> featureTask) 动态加载任务执行完成时，回调此函数。即，无论加载成功还是失败，注册该监听器后，均可以监听到任务执行的状态。|

**Parameters**

|Name|Description|
|:----------|:-----------------|
