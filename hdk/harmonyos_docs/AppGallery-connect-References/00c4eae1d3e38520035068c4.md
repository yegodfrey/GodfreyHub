# IQuery<T1, ...>

|Class/Struct Info|
|:---------------------------------------------------------------------------------------------------------|
|public sealed class IQuery<T1, ...> : IQuery IQuery的泛型模板，继承了IQuery，预设查询组件的查询体，提供流式API。 T为struct，最多支持10个泛型。|

## Property Summary

> 说明
>
> 泛型模板IQuery<T1, ...>继承自IQuery，因此泛型模板IQuery<T1, ...>拥有IQuery所有属性/字段，此处不再重复列出。

|Name|Type|Description|
|:-------------|:----------------------|:----------|
|ArchetypeChunk|QueryArchetypeChunk<T1>|查询原型块。|

**Sample Code**

```screen
var world = new IECSWorld();
// 创建一个Query，指定查询组件，在查询迭代时会返回组件值，过滤器中设置的组件、标签、共享组件不会在查询迭代时返回值
var query = world.Query<PgdPosition, PgdRotation>().WithAllTag(ITags.Get<TestTag1>());
// 使用QueryArchetypeChunk进行查询迭代
foreach(var (PgdPositionSegment, PgdRotationSegment, entities) in query.ArchetypeChunk)
{
    // PgdPositionSegment, PgdRotationSegment, entities等长，用任意一个的长度进行for循环都可以
    for (var i = 0; i < entities.Length; i++)
    {
        // 可以索引、取值直接访问并修改
        PgdPositionSegment[i].x++;
        PgdRotationSegment[i].x++;
        // entities是实体id数组，不是IEntity数组
        var id = entities[i];
    }
}
```

### ParallelForEach

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|void ParallelForEach(ForEachEntity<T1, ...> lambda) 迭代查询结果的实体并处理lambda表达式，将迭代的实体及其对应的组件数据引用传入lambda表达式。 该接口会根据查询的结果中的ArchetypeChunk数量进行多线程处理。线程分配方式为每一个ArchetypeChunk分配一个线程进行处理，在只有一个ArchetypeChunk的情况下直接在主线中处理。 该接口中线程数量限制最大为运行机器的逻辑核心数/2*1.5，在ArchetypeChunk数量超过最大线程限制时，会按照最大线程数分批次处理。 使用该接口一般查询结果在多ArchetypeChunk且每个ArchetypeChunk数据量相差不大的情况效果最好，若是数据量较少情况下使用该接口可能存在负优化。|

**Parameters**

|Name|Type|Description|
|:-----|:---------------------|:-------------------------|
|lambda|ForEachEntity<T1, ...>|lambda表达式，最多包含10个组件的实体的委托。|

**Sample Code**

```screen
var world = new IECSWorld();
// 创建一个Query，指定查询组件，在查询迭代时会返回组件值，过滤器中设置的组件、标签、共享组件不会在查询迭代时返回值
var query = world.Query<PgdPosition, PgdRotation>().WithAllTag(ITags.Get<TestTag1>());
// 使用ParallelForEach进行并行查询迭代，并行任务按照Archetype划分
query.ParallelForEach((ref PgdPosition position, ref PgdRotation rotation, IEntity entity) => 
{
    // 直接访问和修改组件值
    position.x++;
    rotation.x++;
    // entity是IEntity，可以使用IEntity的各个接口，但结构性变更操作需要使用CommandQueue.TSCommandQueue
});
```

### ParallelForEach

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|void ParallelForEach(ForEachEntity<T1, ...> lambda，int taskCount) 迭代查询结果的实体并处理lambda表达式，将迭代的实体及其对应的组件数据引用传入lambda表达式。 该接口会通过taskCount入参确定线程数量，将查询结果中每个ArchetypeChunk中的数据按照taskCount平均分配为对应数量的task，每一个task都由一个线程单独处理。当ArchetypeChunk中数据小于10000时，不会按照taskCount分配task，会直接在主线程上处理。 该接口中线程数量限制最大为运行机器的逻辑核心数/2*1.5，在taskCount数量超过最大线程限制时，仅分配最大线程数量进行处理。 使用该接口一般查询结果在少数ArchetypeChunk且ArchetypeChunk中数据量巨大的情况，若是多个ArchetypeChunk中且数据量较少情况下使用该接口可能存在负优化。|

**Parameters**

|Name|Type|Description|
|:--------|:---------------------|:-------------------------|
|taskCount|int|手动规划任务数量。|
|lambda|ForEachEntity<T1, ...>|lambda表达式，最多包含10个组件的实体的委托。|

**Sample Code**

```screen
var world = new IECSWorld();
// 创建一个Query，指定查询组件，在查询迭代时会返回组件值，过滤器中设置的组件、标签、共享组件不会在查询迭代时返回值
var query = world.Query<PgdPosition, PgdRotation>().WithAllTag(ITags.Get<TestTag1>());
// 使用ParallelForEach进行并行查询迭代，可以指定并行任务数
query.ParallelForEach((ref PgdPosition position, ref PgdRotation rotation, IEntity entity) => 
{
    // 直接访问和修改组件值
    position.x++;
    rotation.x++;
    // entity是IEntity，可以使用IEntity的各个接口，但结构性变更操作需要使用CommandQueue.TSCommandQueue
}, 3);
```
