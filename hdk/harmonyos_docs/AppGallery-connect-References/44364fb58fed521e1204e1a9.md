# 回调结果通知

#### 功能介绍

[通过下载方式提交发布](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-submit-with-file-0000001111845092)、[通过下载方式提交软件包](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-add-packageurl-0000001158245065)等接口均为异步处理接口，华为服务不会立刻返回执行结果。您需要提前传入自己的回调地址，执行成功后华为服务器根据该回调地址调用本接口向您的开发者服务器发送执行结果的通知。

在通过下载方式提交发布时，如果华为内部未知异常或开发者服务器网络不通等原因导致您未收到通知消息（一般在提交发布后5分钟内会发送通知消息），建议您定期通过[查询应用信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-info-query-0000001158365045)接口判断应用是否已经提交审核成功（releaseState为4）。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|华为服务器 -\> 开发者服务器|
|接口URL|[通过下载方式提交发布](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-submit-with-file-0000001111845092)、[通过下载方式提交软件包](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-add-packageurl-0000001158245065)等接口中传入的callbackAddr中指定的地址，您需自行保证地址能访问。|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|
|-----|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### 请求参数

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------------|:----------|:-----|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|callBackData|M|String|应用发布结果的JSON字符串，格式为：{"requestId": "xxx", "retCode": xxxxx, "desc": "xxx"，"pkgVersion":"xxx","downloadFileName":"xxx"}。 * requestId：您自定义的请求ID，与通过下载方式提交请求时传入的requestId一致。 * retCode：返回码。0表示成功，其他表示失败，具体参见[错误码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-publishingapi-errorcode-0000001163523297)。 * desc：返回码描述。 * pkgVersion：软件包版本信息。 * downloadFileName：软件包名称。|
|signatureRSAWithPSS|M|String|华为服务器在发送通知时对callBackData中的参数使用SHA256WithRSA/PSS算法进行了签名，并在signatureRSAWithPSS中返回签名后的字符串。 您需要使用[获取验签公钥](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-gettestkey-0000001158245081)中获取的验签公钥对签名字符串进行验签，验签方法参见[验签示例](#section134mcpsimp)。|

#### 响应参数

无需返回消息。  

#### 验签示例

```
/*
@content 待验签字符串，传入callBackData中携带的JSON字符串
@sign  签名字符串
*/
privatestaticvoidverifySignature(String content, String sign) {
	try{
		String pubKey = "验签公钥";     //替换为您在AGC中实际的验签公钥，参见获取验签公钥。
		X509EncodedKeySpec x509EncodedKeySpec = newX509EncodedKeySpec(Base64.decodeBase64(pubKey));
		KeyFactory keyFactory = KeyFactory.getInstance("RSA");
		PublicKey publicKey = keyFactory.generatePublic(x509EncodedKeySpec);
		Signature signature = Signature.getInstance("SHA256WithRSA/PSS");
		signature.initVerify(publicKey);
		signature.update(content.getBytes(Charset.forName("UTF-8")));
		if(!signature.verify(Base64.decodeBase64(sign))) {
			thrownewConnectException(EnumReturnCode.INVALID_PARAMETER, "Failed to verifySignature");
		}
	} catch(NoSuchAlgorithmException | SignatureException | InvalidKeyException | InvalidKeySpecException e) {
		LOG.error("verify signature failed", e);
		thrownewConnectException(EnumReturnCode.INVALID_PARAMETER, "Failed to verifySignature");
	} catch(Exception e) {
		LOG.error("verify signature failed", e);
		thrownewConnectException(EnumReturnCode.INVALID_PARAMETER, "Failed to verifySignature");
	}
}
```
