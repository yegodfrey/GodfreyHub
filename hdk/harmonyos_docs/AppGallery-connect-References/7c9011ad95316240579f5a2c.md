# HmacAlg

mac 消息认证算法枚举类型如下：  

|摘要算法|支持种类|密钥长度（bit）|API版本|
|:---|:-----|:--------|:----|
|HASH|SHA224|\>=28|11+|
|HASH|SHA256|\>=32|11+|
|HASH|SHA384|\>=48|11+|
|HASH|SHA512|\>=64|11+|
|HASH|SM3|\>=32|11+|

导入模块：

```
import { aegis } from '@hw-agconnect/petal-aegis';
```
