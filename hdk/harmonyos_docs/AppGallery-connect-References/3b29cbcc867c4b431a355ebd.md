# PlayerPosition

|Interface Info|
|:---------------------------------------------|
|export interface PlayerPosition 玩家在世界坐标系的坐标信息。|

#### Property Summary

|Name|Type|Description|
|:------|:-----|:------------------|
|forward|number|玩家在世界坐标系前轴（Z轴）的坐标值。|
|right|number|玩家在世界坐标系右轴（X轴）的坐标值。|
|up|number|玩家在世界坐标系上轴（Y轴）的坐标值。|
