# 获取安装失败数据的报表

#### 功能介绍

获取安装失败数据的报表CSV或EXCEL文件。接口调用者的角色：账号持有者、管理员、App管理员、运营。  

#### 接口原型

|承载协议|HTTPS GET|
|接口方向|开发者服务器 -\> 华为服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/report/distribution-operation-quality/v1/appDownloadFailExport/{appId}|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|
|-----|---------------------------------------------------------------------------------------------------------------|

#### Query

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:-------------------|:----------|:-------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|language|M|String|查询语言，报表title会根据不同语言来展现，只支持简体中文（zh-CN），美式英文（en-US），俄文（ru-RU）。|
|startTime|M|String|查询开始时间，UTC时间，格式为YYYYMMDD。 startTime和endTime之间不超过180天。|
|endTime|M|String|查询结束时间，UTC时间，格式为YYYYMMDD。 startTime和endTime之间不超过180天。|
|filterCondition|O|List\<String\>|过滤器，目前只支持机型"deviceName"、下载类型"downloadType"、应用版本"appVersion"和国家/地区"countryId"过滤。四个参数可以组合。如果不传此参数默认无过滤器。URL示例：\&filterCondition=deviceName\&filterCondition=downloadType\&filterCondition=countryId|
|filterConditionValue|O|List\<String\>|过滤器对应的值。 downloadType对应的取值：1（新下载）、2（更新下载）。 deviceName为设备型号的名称，取值例如： "Mate30Pro-5G版"、"P40-lite"、"P30-Pro"、"P40-lite-5G"、"nova7-SE"、"nova7_SE_5G乐活版"、"nova6-5G版"、"nova6-SE"。 countryId对应的值："CN,AL,AD,AT" appVersion对应的值："1.0.0,2.0.0" URL示例：\&filterConditionValue=mate20\&filterConditionValue=1\&filterConditionValue=CN|
|groupBy|O|List\<String\>|数据统计的分组信息。支持按照日期(date) 、机型(deviceName)、下载类型(downloadType)、应用版本（appVersion）或国家/地区(countryId)进行分组。如果不传默认按照日期分组。|
|exportType|O|String|导出文件类型，取值范围： * CSV：导出CSV文件格式 * EXCEL：导出Excel文件格式 默认值：CSV。|

#### 响应参数

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:-------|:----------|:-----|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|fileURL|M|String|导出CSV或EXCEL文件的路径。 报表文件中字段语言由language参数指定，首个字段为groupBy参数中指定的数据统计分组类型。以报表字段英文为例，您可以点击[文件样例.zip](https://media:801773137285553468)下载样例文件。 文件中包含的字段说明请参见[安装失败的报表数据说明](#ZH-CN_TOPIC_0000001158365063__p1685145815179)。|
|packName|M|String|应用包名。|
|ret|M|String|包含返回码及描述信息的JSON字符串，格式为{"code":retcode, "msg": "description"}，retcode为返回码，description为返回码描述信息。|

安装失败的报表数据说明  

|字段名（中文）|字段名（英文）|字段名（俄语）|字段含义|
|:--------|:-----------------------------------------------|:----------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|日期|date|Время|数据统计按时间进行分组。 注意： 只有当请求参数groupBy传入date时才会返回此字段。|
|机型|deviceName|Модель|数据统计按机型进行分组。 注意： 只有当请求参数groupBy传入deviceName时才会返回此字段。|
|下载类型|downloadType|Тип загрузки|数据统计按下载类型进行分组。 注意： 只有当请求参数groupBy传入downloadType时才会返回此字段。|
|应用版本|appVersion|Версия приложения|数据统计按应用版本进行分组。 注意： 只有当请求参数groupBy传入appVersion时才会返回此字段。|
|国家/地区|countryId|Страна/регион|数据统计按国家/地区进行分组。 注意： 只有当请求参数groupBy传入countryId时才会返回此字段。|
|错误代码|Result code|Код результата|安装失败返回的错误码，详细参考Android官方源代码 (INSTALL_FAILED_\*部分)[源代码查看链接](https://github.com/aosp-mirror/platform_frameworks_base/blob/master/core/java/android/content/pm/PackageManager.java)。|
|错误原因|Cause|Причина|安装失败的错误原因。|
|安装失败设备数|Devices with app installation failures|Устройства со сбоями установок|时间间隔范围内的安装失败设备数。|
|安装失败设备数占比|Proportion of devices with installation failures|Соотношение устройств со сбоями установки|时间间隔范围内的安装失败设备数占比。|
|安装失败次数|Installation failures|Сбои установки|时间间隔范围内的安装失败次数。|
|安装失败次数占比|Proportion of installation failures|Соотношение сбоев установок|时间间隔范围内的安装失败次数占比。|
