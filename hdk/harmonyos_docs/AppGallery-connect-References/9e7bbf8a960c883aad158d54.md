# FFVKOutputFormatInfo

输出预测帧的格式信息。

**Structure Declaration**

```screen
typedef struct FFVKOutputFormatInfo {
    FFStructureType    sType;
    const void*        pNext;
    VkFormat           format;
} FFVKOutputFormatInfo;
```

**Members**

|Name|Mandatory/Optional|Description|
|:-----|:-----------------|:-------------------------------------------------|
|sType|必填|此结构体类型必须为**FF_STRUCTURE_TYPE_OUTPUT_FORMAT_INFO**。|
|pNext|选填|指向扩展链中的下一个结构体的指针。扩展参数，可缺省，默认值为NULL。|
|format|必填|输出预测帧的格式。|
