# PasswordInfo

更新密码操作相关的密码信息类。  

#### Parameters

|Name|Type|Description|
|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------|
|password|string|新的密码。|
|verifyCode|string|验证码。申请验证码时VerifyCodeAction需使用VerifyCodeAction.RESET_PASSWORD方式。|
|providerType|[ProviderType](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-arkts-providertype-0000001632834650)|渠道类型，'email' 或 'phone'。|
