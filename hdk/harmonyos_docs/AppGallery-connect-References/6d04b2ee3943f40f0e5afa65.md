# ExportParam

|class Info|
|:-------------------------------|
|public class ExportParam 视频导出参数。|

## Property Summary

|Name|Type|Mandatory/Optional|Description|
|:------------------|:-----------|:-----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|templateId|String|Mandatory|模板ID。 > 说明 > "模板ID"请参见游戏高光时刻服务页面中[模板ID](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/game-highlight-associate-template-landing-page-0000001678064596#ZH-CN_TOPIC_0000001678064596__li64131045574)列信息。|
|fileName|String|Mandatory|导出的文件名，以.mp4结尾。|
|importFilePaths|List<String>|Mandatory|包含视频文件名的绝对路径列表。 > 说明 > 视频文件必须为.mp4格式，按顺序替换模板中的视频片段。|
|replaceWords|List<String>|Optional|用于替换视频模板文案的文字片段，最长30个字符。 > 说明 > 按顺序替换模板中的文字片段，如果为空则删除模板中的原文案内容，如果为null则不替换。|
|replaceStickerPaths|List<String>|Optional|包含图片文件名的绝对路径列表，图片文件仅支持.jpg/.png/.gif格式。 > 说明 > 按顺序替换模板中的图片，如果为空或为null则不替换。|
|replaceAudioPaths|List<String>|Optional|包含音频文件名的绝对路径列表，音频文件仅支持.mp3格式。 > 说明 > 按顺序替换模板中的音频片段，如果为空或为null则不替换。|
