# ohAegPbkdf2Sha256

ohAegPbkdf2Sha256(text: string | Uint8Array, salt: string | Uint8Array, iteration?: number): Promise<string>

PBKDF2密钥派生算法，返回十六进制编码类型的SHA256值，算法说明如下：

|密钥派生算法|HMAC函数摘要算法|字符串参数|API版本|
|:-----|:---------|:-----|:----|
|PBKDF2|SHA256|PBKDF2|11+|

**导入模块：**

```typescript
import { PbkdfUtil } from '@hw-agconnect/petal-aegis';
```

**参数** **：**

|参数名|类型|必填|说明|
|:--------|:----------------|:-|:-------------------------------------------------|
|text|string或Uint8Array|是|原始明文。|
|salt|string或Uint8Array|是|盐值（string类型的salt需要是十六进制编码格式）（Uint8Array类型长度至少为16）。|
|iteration|number|否|迭代次数 ，可选参数，默认值为10000，如果指定长度至少1000。|

**返回值：**

|参数|类型|说明|
|:--|:--------|:----------------------|
|字符串|hexString|加密后的hexString类型SHA256值。|

**示例：**

```screen
import { PbkdfUtil } from '@hw-agconnect/petal-aegis';
import { buffer } from '@kit.ArkTS';

function pbkdf2() {
  let input = 'hello world';
  let salt = '1234567891234567';//长度16字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let saltUint8 = new Uint8Array(buffer.from(salt, 'utf-8').buffer);
  let iteration = 1000;//迭代次数最少1000次

  PbkdfUtil.ohAegPbkdf2Sha256(input, saltUint8, iteration).then((result) => {
    //pbkdf2 result :  c05a685404b252e74b4b084816aad2e4cf4058ac7972fb589e19d37dcf658136
    console.log('pbkdf2 result : ', result)

  }).catch((err) => {
    console.log("pbkdf2", 'err: ' + err);
  })
}
```
