# Type Definitions

#### AGCCloudDBOnDataEncryptionKeyChangeCallback

用于侦听数据密钥修改的回调。

OBJECTIVE-C

```
typedef BOOL (^AGCCloudDBOnDataEncryptionKeyChangeCallback) (void);
```

#### AGCCloudDBEventCallback

用于侦听用户密码变更事件的回调。

OBJECTIVE-C

```
typedef void (^AGCCloudDBEventCallback) (AGCCloudDBEventType eventType);
```

#### AGCCloudDBZoneCompleteCallback

用于执行增、删、改操作以及数据记录条数的回调。

OBJECTIVE-C

```
typedef void (^AGCCloudDBZoneCompleteCallback) (NSInteger count, NSError *_Nullable error);
```

#### AGCCloudDBZoneAverageCallback

用于查询平均值的回调。

OBJECTIVE-C

```
typedef void (^AGCCloudDBZoneAverageCallback) (double average, NSError *_Nullable error);
```

#### AGCCloudDBZoneNumberCallback

用于查询最大值、最小值、求和结果的回调。

OBJECTIVE-C

```
typedef void (^AGCCloudDBZoneNumberCallback) (NSnumber number, NSError *_Nullable error);
```

#### AGCCloudDBSnapshotCallback

用于查询和订阅操作的回调。

OBJECTIVE-C

```
typedef void (^AGCCloudDBSnapshotCallback) (AGCCloudDBSnapshot *_Nullable snapshot, NSError *_Nullable error);
```

#### AGCCloudDBTransactionCallback

执行事务操作的回调。

OBJECTIVE-C

```
typedef BOOL (^AGCCloudDBTransactionCallback) (AGCCloudDBTransaction *_Nullable transaction);
```

#### AGCCloudDBQueryBlock

用于获取对象类型实例方法where的回调。

OBJECTIVE-C

```
typedef AGCCloudDBQuery *_Nonnull (^AGCCloudDBQueryBlock) (Class *_Nonnull clazz);
```

#### AGCCloudDBFilterBlock

用于添加orderByAsc、orderByDesc、isNotNull和isNull等过滤条件的回调。

OBJECTIVE-C

```
typedef AGCCloudDBQuery *_Nonnull (^AGCCloudDBFilterBlock) (NSString *_Nonnull fieldName);
```

#### AGCCloudDBValueFilterBlock

用于添加equalTo、notEqualTo、greaterThan、greaterThanOrEqualTo、lessThan、lessThanOrEqualTo、beginsWith、endsWith和contains等过滤条件的回调。

OBJECTIVE-C

```
typedef AGCCloudDBQuery *_Nonnull (^AGCCloudDBValueFilterBlock) (id _Nonnull value, NSString *_Nonnull fieldName);
```

#### AGCCloudDBArrayFilterBlock

用于添加inArray过滤条件的回调。

OBJECTIVE-C

```
typedef AGCCloudDBQuery *_Nonnull (^AGCCloudDBArrayFilterBlock) (NSArray *_Nonnull values, NSString *_Nonnull fieldName);
```

#### AGCCloudDBCountBlock

用于添加limit过滤条件的回调。

OBJECTIVE-C

```
typedef AGCCloudDBQuery *_Nonnull (^AGCCloudDBCountBlock) (int count);
```

#### AGCCloudDBCountOffsetBlock

用于添加limitOffset过滤条件的回调。

OBJECTIVE-C

```
typedef AGCCloudDBQuery *_Nonnull (^AGCCloudDBCountOffsetBlock) (int count, int offset);
```

#### AGCServerStatusCallback

用于回调服务器状态数据。

OBJECTIVE-C

```
typedef AGCCloudDBQuery *_Nonnull (^AGCServerStatusCallback) (AGCServerStatus *_Nullable serverStatus, NSError *_Nullable error);
```

#### AGCCloudDBObjectBlock

用于添加startAt、startAfter、endAt和endBefore过滤条件的回调。

OBJECTIVE-C

```
typedef AGCCloudDBQuery *_Nonnull (^AGCCloudDBObjectBlock) (AGCCloudDBObject *_Nonnull object);
```
