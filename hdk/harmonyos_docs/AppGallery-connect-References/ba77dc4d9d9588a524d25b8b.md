# AGCCloudDBZone

```
@interface AGCCloudDBZone : NSObject
```

一个CloudDBZone对象表示一个Cloud DB的存储区域，通过该类提供的方法实现对CloudDBZone中数据的增、删、改、查和事务等操作，实现端云数据的管理。  

#### -executeUpsertOne:onCompleted:

调用此方法将一个对象写入到当前CloudDBZone。如果在CloudDBZone已经存在主键值相同的对象，则更新CloudDBZone中已有的对象；如果不存在，则写入一个新的对象。

调用本方法需要遵循以下约束：

* 仅当CloudDBZone为打开状态时，才允许调用该方法写入对象，否则会导致写入失败。
* 每个对象的数据大小不能超过2MB，否则会导致写入失败。

OBJECTIVE-C

```
- (void)executeUpsertOne:(nonnull AGCCloudDBObject *)object onCompleted:(nullable AGCCloudDBZoneCompleteCallback)callback;
```

#### -executeUpsert:onCompleted:

调用此方法将一组对象批量写入到当前CloudDBZone。写入操作是原子的，即传入对象列表要么全部成功写入，要么全部失败。写入数据时，如果在CloudDBZone已经存在主键值相同的对象，则更新已有的对象；如果不存在，则写入新的对象。

调用本方法需要遵循以下约束：

* 仅当CloudDBZone为打开状态时，才允许调用此方法写入对象，否则会导致写入失败。
* 列表中每个对象的数据大小不能超过2MB，否则会导致写入失败。
* 列表的数据总条数不能超过1000条，否则会导致写入失败。
* 仅在"数据同步模式"为"缓存模式"且"数据持久化属性"为"非持久化"时，列表中所有对象的数据总大小不能超过2MB。

#### -executeDeleteOne:onCompleted:

调用此方法删除CloudDBZone中与传入对象主键值相同的一个对象。删除操作只关注对象的主键值是否相同，不考虑对象其它属性和存储的数据是否匹配。如果CloudDBZone中不存在相同主键值的对象，调用executeDeleteOne方法将不做任何操作，对CloudDBZone无影响，执行结果为成功。

仅当CloudDBZone为打开状态时，才允许调用此方法删除对象，否则会导致删除失败。

#### -executeDelete:onCompleted:

调用此方法批量删除CloudDBZone中与传入对象列表主键值相同的一组对象。删除操作只关注对象的主键是否一致，不考虑对象其它属性和存储的数据是否匹配。删除操作是原子的，即传入对象列表要么全部成功删除，要么全部失败。

* 仅当CloudDBZone为打开状态时，才允许调用此方法删除对象，否则会导致删除失败。
* 删除一组对象时，列表的数据总条数不能超过1000条，否则会导致删除失败。
* 列表中每个对象的数据大小不能超过2MB，否则会导致删除失败。
* 仅在"数据同步属性"为"缓存模式"且"数据持久化属性"为"非持久化"时，列表中所有对象的数据总大小不能超过2MB。

#### -executeQuery:policy:onCompleted:

调用此方法从CloudDBZone中查询满足特定条件的对象，并将查询到的结果集通过AGCCloudDBSnapshotCallback封装到一个AGCCloudDBSnapshot中。

调用本方法需要遵循以下约束：

* 仅当CloudDBZone为打开状态时，才允许调用此方法查询对象，否则会导致查询失败。
* 从云侧查询数据时，每次查询结果的数据大小不能超过5MB，否则会导致查询失败。
* 从云侧查询数据时，查询结果中包含的数据条数不能超过1000条，否则会导致查询失败。

#### -runTransaction:onCompleted:

调用此方法可以执行一个指定的事务操作。您通过AGCCloudDBTransactionCallback，将增、删、改、查等操作放在一个事务中去执行。本方法会直接操作云侧的数据，实现对云侧存储区数据的管理操作，包含数据的增、删、改、查操作。

调用本方法需要遵循以下约束：

* 仅当CloudDBZone为打开状态时，才允许调用此方法执行事务操作，否则会导致事务执行失败。
* 仅当CloudDBZone的同步属性为缓存模式时，才允许调用此方法执行事务操作。
* 一个事务内可以进行多次数据操作，查询操作必须在写入操作和删除操作之前进行。
* 一个事务中多次查询结果的总数据大小不能超过5MB，否则会导致事务失败。
* 一个事务中多次查询结果的总数据条数不能超过1000条，否则会导致事务失败。
* 一个事务中包含的写入和删除对象的总条数不能超过1000条，否则会导致事务执行失败。

OBJECTIVE-C

```
- (void)runTransaction:(nullable AGCCloudDBTransactionCallback)transaction onCompleted:(nullable void(^)(NSError *_Nullable error))callback;
```

#### -subscribeSnapshotWithQuery:policy:listener:

调用此方法注册一个对端侧或者云侧特定对象的侦听，当侦听的对象发生变化，触发注册的AGCCloudDBSnapshotCallback回调。注册快照侦听后，快照侦听需要一定的时间（受限于网络状态）才会生效，因此，在侦听生效前的快照不会推送到端侧，待侦听生效后，端侧可正常收到快照；当快照的大小超过5MB或者快照包含的数据条数超过1000条时，快照将无法推送至端侧。

调用本方法需要遵循以下约束：

* 仅当CloudDBZone为打开状态时，才允许调用此方法注册侦听，否则会导致注册侦听失败。
* 仅当CloudDBZone的同步属性为缓存模式时，才允许调用此方法注册侦听。

OBJECTIVE-C


|query|一个[AGCCloudDBQuery](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbquery-ios-0000001080858650)对象，表征查询条件。构造查询条件时，仅支持使用[equalTo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbquery-ios-0000001080858650#section15167143118209)方法，且查询条件中最少包含一个字段，最多包含5个字段，多个查询条件之间采用"与"运算。 说明： 在注册侦听器时，equalTo支持的字段数据类型如下：NSNumber \<AGCBool\>、NSNumber\<AGCFloat\>、NSNumber\<AGCDouble\>、NSNumber\<AGCByte\>、NSNumber\<AGCShort\>、NSNumber\<AGCInt\>、NSNumber\<AGCLong\>、NSString和NSDate。|
|queryPolicy|查询的策略，指定查询的数据来源。 说明： 指定查询策略时，数据来源仅支持"AGCCloudDBQueryPolicyCloud"和"AGCCloudDBQueryPolicyDefault"，参数详细说明请参见[AGCCloudDBQueryPolicy](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbquerypolicy-ios-0000001127496459)。|
|listener|侦听器，一旦此CloudDBZone中的数据发生变化，就会通过AGCCloudDBSnapshotCallback回调通知数据更新。|
