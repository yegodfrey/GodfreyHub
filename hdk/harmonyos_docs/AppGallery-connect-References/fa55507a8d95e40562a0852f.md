# FFPredictionAlgorithm

预测算法。  
Enum Info

```
typedef enum FFPredictionAlgorithm {
    FF_PREDICTION_ALGORITHM_GRIDWARP = 1,
} FFPredictionAlgorithm;
```

Enum Value Summary  

|Enum Value|Inputs|Benefits|Expected issues|
|:-------------------------------|:---------------------|:------------------------------------|:-------------------------------------|
|FF_PREDICTION_ALGORITHM_GRIDWARP|彩色图像、深度、模板、相机信息和动态对象矩阵|支持内插和外插。当大部分场景是不透明和静态时，效果最好。可以使用模板语义。|对于可变形、小体积、半透明对象、粒子和特效，预测效果相对而言不如另两种算法。|
