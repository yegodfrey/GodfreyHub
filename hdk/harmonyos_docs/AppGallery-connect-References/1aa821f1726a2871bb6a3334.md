# AGCCloudDBSnapshot

```
@interface AGCCloudDBSnapshot : NSObject
```

AGCCloudDBSnapshot类用于描述本次查询到的快照数据，包含全量的对象集合、新增和修改的对象集合和新删除的对象集合等，您可以调用不同的方法获取需要的数据结果。  

#### -hasPendingWrites

调用此方法判断当前快照中是否存在尚未同步到云端的对象。

OBJECTIVE-C

```
- (BOOL)hasPendingWrites;
```

<br />

Return  

|type|desc|
|:---|:---------------------------------------------------------|
|BOOL|快照中是否存在尚未同步到云端的对象。 * YES：存在尚未同步到云端的对象。 * NO：不存在尚未同步到云端的对象。|

#### -isFromCloud

调用此方法判断当前快照中的对象是否从云端查询得到。

OBJECTIVE-C

```
- (BOOL)isFromCloud;
```

<br />

Return  

|type|desc|
|:---|:---------------------------------------------------|
|BOOL|快照中的对象是否从云侧存储区获取。 * YES：对象从云侧存储区获取。 * NO：对象从本地存储区获取。|

#### -snapshotObjects

调用此方法获取快照中全量的对象。

OBJECTIVE-C

```
- (nonnull NSArray *)snapshotObjects;
```

<br />

Return  

|type|desc|
|:------|:--------------|
|NSArray|当前快照中所有对象的集合数组。|

#### -upsertedObjects

调用此方法获取快照中新增或者修改的对象。

当且仅当您注册侦听快照后，upsertedObjects方法才会返回新增或者修改的对象集合（相对于上个快照），否则直接返回null。

OBJECTIVE-C

```
- (nonnull NSArray *)upsertedObjects;
```

<br />

Return  

|type|desc|
|:------|:-----------|
|NSArray|新增或者修改的对象集合。|

#### -deletedObjects

调用此方法获取快照中新删除的对象。

当且仅当您注册侦听快照后，deletedObjects方法才会返回新删除的对象集合（相对于上个快照），否则直接返回null。

OBJECTIVE-C

```
- (nonnull NSArray *)deletedObjects;
```

<br />

Return  

|type|desc|
|:------|:----------------------------------------|
|NSArray|当前快照相比于上次快照被删除的对象集合。 说明： 获取的对象仅包含对象的主键信息。|
