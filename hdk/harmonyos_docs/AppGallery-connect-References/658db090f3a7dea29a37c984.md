### setForceFetch(String triggerEvent)

|Method|
|:-----------------------------------------------------------------------|
|public void setForceFetch(@NonNull String triggerEvent) 设置强制请求AGC云端消息数据。|

> 注意
>
> * setForceFetch方法仅可在调测消息时使用，在正式的版本中不能调用该接口。
> * App Messaging SDK会记录您调用setForceFetch方法的次数，请确保最多5次尝试成功绑定设备的AAID（将您在AGC控制台上配置的测试设备的AAID与当前设备上的AAID保持一致）。如果超过最大尝试次数，则需要卸载应用重装或者清除应用数据，setForceFetch方法的调用次数会重置。
> * 您可以在日志中查找日志关键字：This device is a test device，查看是否绑定成功。

**Parameters**

|Name|Description|
|:-----------|:----------------------|
|triggerEvent|触发事件的名称，可以是HA事件或者自定义事件。|
