#### link

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|link(credentialInfo: [CredentialInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-arkts-credentialinfo-0000001680787821)): Promise\<[SignInResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-arkts-signinresult-0000001680900101)\> 当前用户关联新的登录方式。|

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250818213029.72864762141663637545423031547954:50001231000000:2800:1F3211363CD8387E4A8439155C1C57CF425BB478392D708BA5DAE294CE618092.png)  
此接口会验证用户Access Token和Refresh Token，请确保用户Refresh Token在有效期内，否则会抛出错误码203817986，表示用户Refresh Token无效。

收到此错误码后，请重新登录应用，获取新的Access Token和Refresh Token。

<br />

Parameters  

|Name|Type|Description|
|:-------------|:-------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------|
|credentialInfo|[CredentialInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-arkts-credentialinfo-0000001680787821)|必选，凭证信息。编译器会根据其中kind自动推断类型，例如其内部kind填为：'phone'，则类型被推断为"PhoneCredentialInfo"。|

Return  

|Type|Description|
|:--------------------------------------------------------------------------------------------------------------------------------------------------|:----------------|
|Promise\<[SignInResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-arkts-signinresult-0000001680900101)\>|登录结果信息的Promise对象。|

Sample Code

```
// 关联新的email账户
cloud.auth().getCurrentUser().then(user => {
    user.link({
        kind: "email",
        password: "123456",
        email: "yyyy@xxxx.com",
        verifyCode: "xxxx"
    });
});
// 关联新的手机账户
cloud.auth().getCurrentUser().then(user => {
  user.link({
    kind: 'phone',
    phoneNumber: '138********',
    countryCode: '86',
    verifyCode: 'xxxx'
  })
})
```
