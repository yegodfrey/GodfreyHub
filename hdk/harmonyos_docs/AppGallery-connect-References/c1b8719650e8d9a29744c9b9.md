# HashAlg

hash 消息摘要算法枚举类型如下：  

|摘要算法|支持种类|API版本|
|:---|:-----|:----|
|HASH|SHA256|11+|
|HASH|SHA384|11+|
|HASH|SHA512|11+|
|HASH|SM3|11+|

导入模块：

```
import { aegis } from '@hw-agconnect/petal-aegis';
```
