# StorageReference

|Interface Info|
|:-------------------------------------------------------------------------|
|export interface StorageReference 云端文件的引用，提供对象的列举、上传、获取文件的下载地址、删除等各项操作的封装。|

## Property Summary

|Name|Type|Description|
|:------|:----------------------|:------------------------------------------------------|
|bucket|string|文件存储在云端的存储实例名称。|
|path|string|文件存储在云端的路径信息。|
|name|string|文件存储在云端的文件名称。|
|parent|StorageReference | null|文件存储在云端的父目录的StorageReference引用。当文件本身存储在根路径时，父目录引用为null。|
|root|StorageReference|文件存储在云端的根目录的StorageReference引用。|
|storage|StorageManagement|文件存储在云端管理类的StorageManagement引用。|
