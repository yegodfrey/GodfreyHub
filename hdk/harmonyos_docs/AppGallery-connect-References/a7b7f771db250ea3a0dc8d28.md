# AGCFunctionResult

|Class Info|
|:-------------------------------------------------------------------------------|
|当函数执行成功后包含云函数执行结果的类。 Objective-C ``` @interface AGCFunctionResult : NSObject ```|

#### -value

获取函数执行后的返回值，适用返回值为字符串类型的函数。

Objective-C

```
- (nullable NSString *)value;
```

Swift

```
func value() -> String?
```

<br />

Return

函数执行后的返回值，返回值为字符串类型。  

#### -valueWithClass:

获取函数执行后的返回对象，适用返回值为对象的函数。

Objective-C

```
- (nullable id)valueWithClass:(nonnull Class)valueClass;
```

Swift

```
func value(with valueClass: AnyClass) -> Any?
```

<br />

Parameters  

|Name|Description|
|:---------|:-------------------------|
|valueClass|函数执行后的返回对象，可以传入预定义类型的返回对象。|

Return
