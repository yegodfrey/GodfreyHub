# AGCFunctionResult

|Class Info|
|:-------------------------------------------------------------------------------------|
|当函数执行成功后包含云函数执行结果的类。 Objective-C ```screen @interface AGCFunctionResult : NSObject ```|

## -value

获取函数执行后的返回值，适用返回值为字符串类型的函数。

**Objective-C**

```screen
- (nullable NSString *)value;
```

**Swift**

```screen
func value() -> String?
```

**Return**

函数执行后的返回值，返回值为字符串类型。

## -valueWithClass:

获取函数执行后的返回对象，适用返回值为对象的函数。

**Objective-C**

```screen
- (nullable id)valueWithClass:(nonnull Class)valueClass;
```

**Swift**

```screen
func value(with valueClass: AnyClass) -> Any?
```

**Parameters**

|Name|Description|
|:---------|:-------------------------|
|valueClass|函数执行后的返回对象，可以传入预定义类型的返回对象。|

**Return**

函数执行后的返回对象值，对象类型在入参valueClass定义。
