# 获取给指定用户群发奖的报表

#### 功能介绍

获取指定给用户群发奖的报表数据的CSV文件地址。接口调用者的角色：账号持有者、管理员、App管理员、运营、财务。  

#### 使用约束

本接口仅支持在中国大陆地区发布的应用。

为了防止注入风险，给指定用户群发奖的报表内容中的"活动名称"如果存在特殊字符（"+"或"-"或"@"或"="），则会对该"活动名称"做转义处理。转义处理的规则是在待转义字符串前加tab键，然后将整个字符串用双引号括起来。  

#### 接口原型

|承载协议|HTTPS GET|
|接口方向|开发者服务器 -\> 华为服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/report/distribution-operation-quality/v1/activityAwardExport/{appId}|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|
|-----|-------------------------------------------------------------------------------------------------------------|

#### Path

|参数名称|必选(M)/可选(O)|类型|参数说明|

#### Query

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:-------------------|:----------|:-------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
|language|M|String|查询语言，报表title会根据不同语言来展现，只支持简体中文（zh-CN），美式英文（en-US），俄文（ru-RU）。|
|startTime|M|String|查询开始时间，UTC时间，格式为YYYYMMDD。startTime和endTime之间不超过180天。|
|endTime|M|String|查询结束时间，UTC时间，格式为YYYYMMDD。startTime和endTime之间不超过180天。|
|filterCondition|O|List\<String\>|过滤器，目前只支持"activityId"，表示基于活动过滤。如果不传此参数默认无过滤器。 URL示例：\&filterCondition=activityId|
|filterConditionValue|O|List\<String\>|过滤器对应的值，例如过滤器是"activityId"，此参数的取值为活动ID。目前只支持输入1个活动ID，不支持输入多个活动ID。 活动ID可在AppGallery Connect网站应用开发页面的"运营 \> 活动运营 \> 活动管理"页面查看。 URL示例：\&filterConditionValue=939130|

#### 响应参数

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:-------|:----------|:-----|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|fileURL|M|String|导出CSV文件的路径。 报表文件中字段语言由language参数指定。以报表字段英文为例，您可以点击[文件样例.zip](https://media:801773137284676456)下载样例文件。 文件中包含的字段说明请参见[给指定用户群发奖的报表数据说明](#ZH-CN_TOPIC_0000001158245071__p975514204216)。|
|packName|M|String|应用包名。|
|ret|M|String|包含返回码及描述信息的JSON字符串，格式为{"code":retcode, "msg": "description"}，retcode为返回码，description为返回码描述信息。|

给指定用户群发奖的报表数据说明  

|字段名（中文）|字段名（英文）|字段名（俄语）|字段含义|
|:--------------|:-------------------------------|:----------------------------------------|:-------------------------------------------|
|日期|Time|Время|数据统计按时间进行分组。|
|活动ID|ID|ID|用户召回活动ID。|
|活动名称|Name|Имя|用户召回活动名称。|
|活动开始时间|Start time|Время начала|用户召回活动开始时间。|
|活动奖品到达总用户数|Total users receiving prizes|Всего пользователей, получивших призы|收到奖品的总用户人数。|
|登录用户数|Signed-in users|Пользователей, вошедших в систему|从活动开始时间到当前日期，活动奖品到达后在当前应用中有登录行为的用户数。|
|登录用户占比|Rate of signed-in users|Процент пользователей, вошедших в систему|从活动开始时间到当前日期，活动奖品到达后在当前应用中有登录行为的用户数占总用户数的比例。|
|付费用户数|Paying users|Платящие пользователи|从活动开始时间到当前日期，活动奖品到达后在当前应用中有付费行为的用户数。|
|付费用户占比|Rate of paying users|Процент платящих пользователей|从活动开始时间到当前日期，活动奖品到达后在当前应用中有付费行为的用户数占总用户数的比例。|
|付费现金流水（元）|Cash payment (CNY)|Платеж (CNY)|从活动开始时间到当前日期，在当前应用中产生的付费现金流水。|
|付费总流水（元）|Total payment (CNY)|Сумма платежей (CNY)|从活动开始时间到当前日期，在当前应用中产生的付费总流水。|
|优惠券使用用户数|Users using coupons|Пользователи, использовавшие купоны|从活动开始时间到当前日期，使用优惠券的用户人数。|
|优惠券支付产生的现金流水（元）|Cash payment using coupon (CNY)|Оплата при помощи купона (CNY)|从活动开始时间到当前日期，在当前应用中使用优惠券支付产生的现金流水。|
|优惠券支付产生的总流水（元）|Total payment using coupon (CNY)|Сумма оплаты при помощи купона (CNY)|从活动开始时间到当前日期，在当前应用中使用优惠券支付产生的现金总流水。|
