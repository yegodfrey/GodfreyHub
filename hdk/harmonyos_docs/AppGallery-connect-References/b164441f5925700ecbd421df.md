# FeatureInstallErrorCode

|Class Info|
|:----------------------------------------------------------------------------------------------------|
|public class FeatureInstallErrorCode extends Object 在执行动态加载任务过程中，表示失败的错误码类。 开发者可以根据此错误码查询动态加载任务的失败信息。|

#### Field Summary

|Type|Name|Value|Description|
|:---|:---------------------------------|:----|:-------------------------------|
|int|NO_ERROR|0|没有错误。|
|int|ACTIVE_SESSIONS_LIMIT_EXCEEDED|-1|请求特性过多 当前应用正在运行的会话太多，必须首先解析现有会话。|
|int|MODULE_UNAVAILABLE|-2|对于此用户/设备，特性不可用。|
|int|INVALID_REQUEST|-3|无效请求。|
|int|SESSION_NOT_FOUND|-4|没有找到对应的session。|
|int|API_NOT_AVAILABLE|-5|API不可用。|
|int|NETWORK_ERROR|-6|网络错误，无法获取特性详细信息。|
|int|ACCESS_DENIED|-7|访问错误，例如在当前设备环境下不允许下载。|
|int|INCOMPATIBLE_WITH_EXISTING_SESSION|-8|session冲突错误。|
|int|SERVICE_DIED|-9|华为应用市场服务连接错误，处理特性安装的服务不可用。|
|int|INSUFFICIENT_STORAGE|-10|存储空间错误，由于存储不足，安装失败。|
|int|SPLITCOMPAT_VERIFICATION_ERROR|-11|Split APK签名校验错误。|
|int|SPLITCOMPAT_EMULATION_ERROR|-12|动态加载失败。|
|int|SPLITCOMPAT_COPY_ERROR|-13|Split APK拷贝失败。|
|int|INTERNAL_ERROR|-100|内部错误，即动态加载未知错误。|
|int|NOT_SIGN_AGREEMENT|901|未签署用户条款与隐私。|
|int|REQUIRE_INSTALL_CONFIRM|902|需要确认下载和安装。|
|int|NO_INSTALL_PERMISSION|903|没有静默安装权限。|
|int|INSTALL_APKS_FAILED|904|安装APK文件失败。|
