# FFDepthStencilYDirectionInverted

Structure Declaration

```
typedef struct FFDepthStencilYDirectionInverted {
    FFStructureType    sType;
    const void*        pNext;
} FFDepthStencilYDirectionInverted;
```

Members  

|Name|Mandatory/Optional|Description|
|:----|:-----------------|:-------------------------------------------------------------|
|sType|必填|此结构体类型必须为FF_STRUCTURE_TYPE_DEPTH_STENCIL_Y_DIRECTION_INVERTED。|
|pNext|选填|指向扩展链中的下一个结构体的指针。扩展参数，可缺省，默认值为NULL。|
