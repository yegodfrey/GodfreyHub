# 创建Unified Linking

## 功能介绍

App Linking服务目前支持多平台应用市场下载页的统一链接，即针对App Store，AppGallery，Google Play等不同的应用市场，您只需创建一个Unified Linking，用户点击链接后，会根据终端类型跳转到对应的应用市场下载页（例如iOS终端跳转到App Store，Android终端已安装AppGallery时直接跳转到AppGallery，未安装AppGallery时则跳转到Google Play），帮助您的应用提升下载量，带来新用户增长。本接口用于创建一个Unified Linking。

## 使用约束

* 接口调用者的角色：账号持有者、管理员、APP管理员、开发、运营。
* 调用次数限制：
  * 5次/每IP地址/每秒
  * 1000次/每IP地址/每小时
* 数量限制：2000个/每项目。

## 接口原型

|承载协议|HTTPS POST|
|-----|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|接口方向|开发者服务器->华为服务器|
|接口URL|https://{domain}/api/applinking/v1/unified-links * 中国站点的domain：connect-api.cloud.huawei.com * 欧洲站点的domain：connect-api-dre.cloud.huawei.com * 亚太站点的domain：connect-api-dra.cloud.huawei.com * 俄罗斯站点的domain：connect-api-drru.cloud.huawei.com > 注意 > 调用[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)接口时使用的域名必须与本接口域名保持一致，例如本接口使用"connect-api-dre.cloud.huawei.com"，则调用[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)接口必须使用"https://connect-api-dre.cloud.huawei.com/api/oauth2/v1/token"。|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

### Header

**Service Account** **方式：**

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Authorization|M|String|认证信息，格式为"Authorization: Bearer *${JWT}* "。JWT为[通过Service Account方式获取授权](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-obtain-apiauthorization-0000001321336068#section104621343151212)中获取的鉴权令牌。|
|productId|M|String|项目ID，查询方法请参见[查询开发者账号ID及项目ID](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-developerid-projectid-0000001166543063)。|

**API客户端方式：**

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|M|String|客户端ID，获取方法参考[创建API客户端](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-obtain-apiauthorization-0000001321336068#section14162113625516)。|

### Body

请求Body中使用JSON格式携带更新的语言描述信息，参数如下表所示。

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:--------------------|:----------|:-------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|uriPrefix|M|String|Unified Linking的链接前缀，例如"https://yourapp.drcn.agconnect.link"。 链接前缀需要在AGC控制台提前申请，具体请参见[申请链接前缀](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-urlprefix-0000001060148052)。|
|name|M|String|Unified Linking的自定义名称。|
|defaultRedirectionUrl|M|String|默认重定向链接。在非移动设备，或者未配置iOS或Android重定向链接时，则会重定向到该链接。|
|iosRedirectionUrl|O|String|iOS设备的重定向链接，例如 https://apps.apple.com/xx/app/xx-xx-xx/idxxxxxxxx。|
|agRedirectionUrl|O|String|Android设备拉起华为应用市场下载页的重定向链接，例如 hiapplink://com.huawei.appmarket?appId=xxxxxx。|
|otherRedirectionUrl|O|String|Android设备未拉起华为应用市场时，重定向的其它链接，例如：https://play.google.com/store/apps/details?。|
|campaign|O|[Campaign](#ZH-CN_TOPIC_0000001186476535__p345041816436)|广告跟踪参数。|

**Campaign**

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------|:----------|:-----|:-------------------|
|channel|O|String|广告渠道，如今日头条、百度，也可自定义。|
|medium|O|String|广告媒介，如cpc 、email。|
|name|O|String|特定的推广活动描述，如双11推广。|

## 响应参数

|参数|必选（M）/可选（O）|参数类型|描述|
|:-------|:----------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|ret|M|String|包含返回码及描述信息的JSON字符串，格式为{"code":*retcode* , "msg": "*description* "}，retcode为返回码，description为返回码描述信息。返回码请参见[错误码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-rest-errorcode-0000001188562505)。|

## 调用示例

```screen
public static void createUnifiedLinking(String domain, String clientId, String token, String productId) {
	HttpPost post = new HttpPost(domain + "/api/applinking/v1/unified-links");
	post.setHeader("Authorization", "Bearer " + token);
	post.setHeader("client_id", clientId);
	post.setHeader("productId", productId);
        //Request Body
        JSONObject keyString = new JSONObject();
        keyString.put("uriPrefix", "https://example.drcn.agconnect.link");
        keyString.put("name", "UnifiedLinkingX");
        //...
        StringEntity entity = new StringEntity(keyString.toString(), Charset.forName("UTF-8"));
        entity.setContentEncoding("UTF-8");
        entity.setContentType("application/json");
        post.setEntity(entity);
	try {
		CloseableHttpClient httpClient = HttpClients.createDefault();
		CloseableHttpResponse httpResponse = httpClient.execute(post);
		int statusCode = httpResponse.getStatusLine().getStatusCode();
		if (statusCode == HttpStatus.SC_OK) {
			BufferedReader br =
				new BufferedReader(new InputStreamReader(httpResponse.getEntity().getContent(), Consts.UTF_8));
			String result = br.readLine();
			JSONObject object = JSON.parseObject(result);
			System.out.println(object.get("ret").toString());
                        String shortUrl = object.getString("shortUrl");
		}
	} catch (Exception e) {
	}
}
```
