# DefaultProductPriceInfo

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:-------|:----------|:-----|:----------------------------------------------------------------------------------------------------------------------------------------------------------------|
|country|M|String|国家码，具体请参见[国家/地区、语言、币种列表](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-supported-countries-overview-0000001146718725)，默认值CN。|
|price|O|String|商品原始价格，如果商品为上线状态，则此字段不能为空。|
|currency|M|String|用于支付的币种，请参见[国家/地区、语言、币种列表](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-supported-countries-overview-0000001146718725)。 例如：USD、CNY、MYR。|
