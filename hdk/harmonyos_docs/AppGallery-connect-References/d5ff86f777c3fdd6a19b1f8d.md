# StorageReference

|Interface Info|
|:------------------------------------------------------------------------|
|export interface StorageReference 云端文件的引用，提供对象的列举、上传、下载、删除、元数据更新等各项操作的封装。|

## Property Summary

|Name|Type|Description|
|:------|:----------------------|:------------------------------------------------------|
|bucket|string|文件存储在云端的存储实例名称。|
|path|string|文件存储在云端的路径信息。|
|name|string|文件存储在云端的文件名称。|
|parent|StorageReference | null|文件存储在云端的父目录的StorageReference引用。当文件本身存储在根路径时，父目录引用为null。|
|root|StorageReference|文件存储在云端的根目录的StorageReference引用。|
|storage|StorageManagement|文件存储在云端管理类的StorageManagement引用。|

## Method Summary

|Qualifier and Type|Method Name and Description|
|:--------------------|:---------------------------------------------------------------------------------------------------------------------|
|StorageReference|[child](#section012312924313)(path: string) 指定路径下文件的StorageReference引用。|
|Promise<void>|[delete](#section152912175213)() 删除StorageReference引用下的文件。|
|Promise<string>|[getDownloadURL](#section106353585619)() 获取StorageReference引用的下载地址，不支持目录的下载地址获取。|
|Promise<FileMetadata>|[getFileMetadata](#section538914214811)() 获取StorageReference引用的文件元数据。|
|Promise<ListResult>|[list](#section149813527813)(options?: ListOptions) 分页获取StorageReference引用下的文件和目录列表信息。|
|Promise<ListResult>|[listAll](#section51714428108)() 获取StorageReference引用下的所有文件和目录列表信息。|
|UploadTask|[put](#section9814182519119)(data: File | Uint8Array | ArrayBuffer, attribute ?: UploadMetadata) 实例化一个上传任务。该接口仅支持浏览器端。|
|UploadTask|[putString](#section89611753101219)(data: string, format ?: StringFormat, attribute ?: UploadMetadata) 实例化一个上传任务。|
|Promise<FileMetadata>|[put4QuickApp](#section8580355133317)(uri String, attribute ?: UploadMetadata) 实例化一个上传任务。该接口仅支持快应用端。|
|string|[toString](#section14210245161418)() StorageReference引用的文件的地址信息。|
|Promise<FileMetadata>|[updateFileMetadata](#section142543812159)(attribute: SetFileMetadata) 更新StorageReference引用下的文件元数据信息，不支持更新目录元数据。|
