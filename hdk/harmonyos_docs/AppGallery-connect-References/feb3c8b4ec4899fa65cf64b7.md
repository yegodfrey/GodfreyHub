# FrameFlowVK_SetPredictionAlgorithm

|Function Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|FFResult FrameFlowVK_SetPredictionAlgorithm(FFVKInstance instance, const FFPredictionAlgorithmInfo\* pPredictionAlgorithmInfo, FFAlgorithmCapabilitiesInfo\* pCapabilitiesInfo); 设置预测算法。|

Parameters  

|Name|Description|
|:-----------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|instance|库实例。|
|pPredictionAlgorithmInfo|指向[FFPredictionAlgorithmInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffpredictionalgorithminfo-vulkan-0000001838093889)结构体的指针，表示预测算法类型及插帧方案。|
|pCapabilitiesInfo|指向[FFAlgorithmCapabilitiesInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffalgorithmcapabilitiesinfo-vulkan-0000001838253845)结构体的指针，表示预测算法配置信息。|

Return  

|Type|Description|
|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
|FFResult|返回结果。 成功时返回0，失败则返回错误码，具体请参见[FFResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffresult-vulkan-0000001791494504)。|
