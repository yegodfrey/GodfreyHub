# 监听云存储事件

#### 功能介绍

云函数的CLOUDSTORAGE触发器监听云存储中的Completed请求消息。当发生此请求消息时，云函数将对云存储执行相关操作。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|华为服务器 -\> 开发者服务器|
|接口URL|开发者提供用户认证接口URL，必须为HTTPS协议。|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|
|-----|-------------------------------------------------------------------|

#### 请求参数

请求参数以JSON格式传入，包含参数如下。  

|参数名称|必选(M)/可选(O)|数据类型|参数说明|
|:---------|:----------|:-----|:---------------------------------------------------------------------------|
|bucketName|M|String|云存储实例名称。|
|eventName|M|String|事件名称。 取值范围： * storage.upload.completed: 上传文件事件 * Storage.file.delete: 删除文件事件|
|functionId|O|String|函数ID。|
|key|M|String|文件名。|
|productId|O|String|项目ID。|
|size|O|String|文件大小。 单位：字节。 最大文件大小支持50GB。|
|teamId|O|String|团队ID。|

#### 请求示例

```
{
    "bucketName":"aaaa-9ww7j",
    "eventName":"storage.upload.completed",
         "functionId":"wisefunction:cn:agc:630086000000487293@98654408178409921:function:demo:$latst",
    "key":"object0001.txt",
    "productId":"98654408178409925",
    "size":"558",
    "teamId":"630086000000487295"
}
```
