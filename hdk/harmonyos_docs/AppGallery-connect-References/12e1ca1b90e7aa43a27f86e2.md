# FrameFlow_SetResolution

|Function Info|
|:------------------------------------------------------------------------------------------|
|FFResult FrameFlow_SetResolution(FFInstance instance, const FFExtent2D\* pExtent2D); 设置分辨率。|

|Name|Description|
|:--------|:------------------------------------------------------------------------------------------------------------------------------------|

|Type|Description|
|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------|
