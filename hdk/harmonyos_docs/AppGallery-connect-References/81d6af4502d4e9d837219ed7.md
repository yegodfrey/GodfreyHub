# ohAegAesGcmDec

ohAegAesGcmDec(text: Uint8Array, key: Uint8Array): Promise<Uint8Array>

AES-GCM解密算法，配套[ohAegAesGcmEnc](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ohaegaesgcmenc-0000001909994593)接口使用，分组模式、填充模式如下：

|分组模式|密钥长度（bit）|填充模式|API版本|
|:---|:----------|:--------|:----|
|GCM|128|192|256|NoPadding|11+|

**导入模块：**

```typescript
import { AegAesGcm } from '@hw-agconnect/petal-aegis';
```

**参数** **：**

|参数名|类型|必填|说明|
|:---|:---------|:-|:---------------------------------------------------------|
|text|Uint8Array|是|待解密内容（ohAegAesGcmEnc加密后的结果），格式为**iv:密文**或者同类的Uint8Array格式。|
|key|Uint8Array|是|明文工作密钥。|

**返回值：**

|参数|类型|说明|
|:----------|:---------|:--------|
|decryptText|Uint8Array|解密后的明文内容。|

**示例：**

```typescript
import { AegAesGcm } from '@hw-agconnect/petal-aegis';
import { buffer } from '@kit.ArkTS';

async function aesgcm3() {
  let plainText = 'hello world'; //待加密内容
  let key = '1234567891234567'; //长度16字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let iv = '987654321321'; //长度12字节，实际使用时建议使用安全随机数生成，不能硬编码在代码中
  let inputUint8 = new Uint8Array(buffer.from(plainText, 'utf-8').buffer);
  let keyUint8 = new Uint8Array(buffer.from(key, 'utf-8').buffer);
  let ivUint8 = new Uint8Array(buffer.from(iv, 'utf-8').buffer);

  try {
    let encryptText = await AegAesGcm.ohAegAesGcmEnc(inputUint8, keyUint8, ivUint8);
    //aesgcm3  encryptText: 57,56,55,54,53,52,51,50,49,51,50,49,58,21,104,60,153,97,230,40,122,247,216,95,118,199,32,201,144,189,45,186,42,16,112,92,208,160,189,206
    console.log("aesgcm3 ", 'encryptText: ' + encryptText);

    let decryptText = await AegAesGcm.ohAegAesGcmDec(encryptText, keyUint8);

    if (plainText === uint8ArrayToString(decryptText)) {
      console.info('aesgcm3 decrypt ok');
    }
    console.log("aesgcm3 ", 'decryptText: ' + uint8ArrayToString(decryptText));
  } catch (err) {
    console.log("aesgcm3 ", 'err: ' + err);
  }
}
function uint8ArrayToString(data: Uint8Array) {
  let dataString = '';
  for (let i = 0; i < data.length; i++) {
    dataString += String.fromCharCode(data[i]);
  }
  return dataString;
}
```
