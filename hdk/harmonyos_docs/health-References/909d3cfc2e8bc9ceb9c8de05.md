# Overview  
  
提供行业解决方案穿戴设备业务管理能力的客户端和Service端管理能力的客户端。

#### Class Summary

Class | Description  
---|---  
BaseClient | Client基类。  
DeviceManageClient | 向开发者提供穿戴设备业务管理能力的客户端。  
ServiceManageClient | 提供行业解决方案Service端管理能力的客户端。
