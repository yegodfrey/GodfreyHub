# Overview  
  
提供SDK服务端管理能力。 

SDK服务端管理能力：监听/取消监听服务端的连接状态、获取客户端或服务端的API level、查询或设置SDK日志输出开关状态。

[ServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/serviceclient-0000001434627952) | 向开发者提供管理行业解决方案SDK服务端管理能力的客户端
