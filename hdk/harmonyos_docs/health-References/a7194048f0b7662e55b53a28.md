# Overview  
  
提供Industry SDK HMOS for Wear（行业解决方案）的服务端管理、设备业务管理接口的封装。

     * SDK服务端管理能力：监听/取消监听服务端的连接状态、获取服务端的API level、获取鉴权结果。
     * 设备业务管理能力：查询设备信息、设置设备信息、订阅/解除订阅设备状态或运动健康数据更新提醒、向设备发送通用消息。
