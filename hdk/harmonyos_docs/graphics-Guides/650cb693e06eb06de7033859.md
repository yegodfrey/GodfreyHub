# 初始化

在调用任意原子化接口前，需要先使用[SceneKitFluid](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-scenekitfluid-0000001117457606)类进行初始化。初始化接口分为同步接口和异步接口。

两种初始化接口触发升级的方式分别如下：

* **同步初始化接口** [initializeSync](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-scenekit-0000001061092023#section1814112016111)()：抛出UpdateNeededException，可通过UpdateNeededException实例的getIntent方法获取升级Intent。
* **异步初始化接口** [initialize](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-scenekit-0000001061092023#section98553811514)()：触发监听器[SceneKitFluid.OnInitEventListener](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-fluid-oniniteventlistener-0000001117617502)的[onUpdateNeeded](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-fluid-oniniteventlistener-0000001117617502#section128314506299)回调方法，并将升级Intent作为入参传入。

您可以根据需求选用其一，下面的开发步骤中会以异步接口为例。

在只引入SDK 2D流体模拟包、不引入SDK 2D流体模拟扩展包的情况下，初始化有可能触发Scene Kit APK升级，您需要考虑该情况，主动启动接口提供的Intent并在onActivityResult中处理升级结果。

## 开发步骤

1. 创建两个Activity：MainActivity和DemoActivity。其中MainActivity负责完成[SceneKitFluid](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-scenekitfluid-0000001117457606)初始化，DemoActivity用于容纳渲染视图，并呈现最终效果。

   2D流体为保证效果暂不支持转屏与分屏操作，请在AndroidManifest文件相应的Activity标签中进行配置：

   ```screen
   android:screenOrientation="portrait"
   android:resizeableActivity="false"
   ```

2. 在MainActivity中添加初始化标识和初始化方法。在初始化方法中使用异步初始化接口[initialize](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-scenekitfluid-0000001117457606#section196821231122517)初始化[SceneKitFluid](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-scenekitfluid-0000001117457606)。

   ```screen
   private static final int REQ_CODE_UPDATE = 10001;
   private boolean initialized = false;

   private void initializeSceneKitFluid() {
       // 使用异步接口进行初始化。
       SceneKitFluid.getInstance().initialize(this, new SceneKitFluid.OnInitEventListener() {
           @Override
           public void onUpdateNeeded(Intent intent) {
               startActivityForResult(intent, REQ_CODE_UPDATE);
           }

           @Override
           public void onInitialized() {
               initialized = true;
           }

           @Override
           public void onException(Exception e) {
               Toast.makeText(MainActivity.this,
                   "failed to initialize SceneKit fluid: " + e.getMessage(), Toast.LENGTH_SHORT).show();
           }
       });
   }
   ```

3. 复写MainActivity的onActivityResult方法，处理升级结果。

   ```screen
   // resultCode为-1时代表升级成功，其他resultCode均代表升级失败。
   private static final int RES_CODE_UPDATE_SUCCESS = -1;

   @Override
   protected void onActivityResult(int requestCode, int resultCode, @Nullable Intent data) {
       super.onActivityResult(requestCode, resultCode, data);
       // 如果升级成功，尝试重新初始化。
       if (requestCode == REQ_CODE_UPDATE
           && resultCode == RES_CODE_UPDATE_SUCCESS) {
           try {
               SceneKitFluid.getInstance().initializeSync(getApplicationContext());
               initialized = true;
               Toast.makeText(this, "SceneKit Fluid initialized", Toast.LENGTH_SHORT).show();
           } catch (StateException | ModuleException e) {
               // 重新尝试初始化时不再捕获升级异常。
               Toast.makeText(this, "failed to initialize SceneKit: " + e.getMessage(), Toast.LENGTH_SHORT).show();
   	}
       }
   }
   ```

4. 在MainActivity的Layout文件中添加按钮，用于跳转至DemoActivity。

   ```screen
   <?xml version="1.0" encoding="utf-8"?>
   <LinearLayout
       xmlns:android="http://schemas.android.com/apk/res/android"
       android:orientation="vertical"
       android:layout_width="match_parent"
       android:layout_height="match_parent">

       <Button
           android:layout_width="match_parent"
           android:layout_height="wrap_content"
           android:text="start demo"
           android:onClick="onBtnStartDemoClicked"/>

   </LinearLayout>
   ```

5. 在MainActivity中添加按钮回调。

   ```screen
   public void onBtnStartDemoClicked(View view) {
       // 如果未初始化，先初始化。
       if (!initialized) {
           initializeSceneKitFluid();
       }
       // 跳转到DemoActivity。
       startActivity(new Intent(this, DemoActivity.class));
   }
   ```
