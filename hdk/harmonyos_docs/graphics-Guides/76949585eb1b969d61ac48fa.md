# 在关卡中添加HuaweiVRCamera

将HuaweiVRSDK内容/BluePrints/HuaweiVRCamera蓝图拖入游戏关卡中。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220519145809.01536834966432329467834145581018:50530518075906:2800:ADC3B925D5B2824DDFC85FCC9BF0713625D485E058002BBC046419E74C50E6B1.png?needInitFileName=true?needInitFileName=true "点击放大")

HuaweiVRCamera蓝图中VRCamera的旋转姿态表示VR头盔的旋转姿态，可以通过GeWorldRotation(VRCamera)获取头盔旋转信息。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220519145809.31091526653384731515151718220631:50530518075906:2800:8EEB8858D3662F89ADF0F8D84506B76BAFA5AFA3DCF652D64E72A1C553EBC38E.png?needInitFileName=true?needInitFileName=true "点击放大")

也可以通过蓝图接口GetHMDOrientationAndPosition直接获取。如果开发者自定义相机蓝图，请将 HuaweiVRCamera中控制弹窗相关的部分加入，不然会导致应用内无弹窗提示信息。
