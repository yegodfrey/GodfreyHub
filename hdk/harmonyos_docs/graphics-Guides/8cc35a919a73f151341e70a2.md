# 在场景中添加HUAWEI VR相机

为了让场景能够显示成VR模式，首先需要添加华为VR相机，即HVRCamera，目录为Assets/HVR/Prefabs。添加方法如下：

1. 鼠标点击HVRCamera，并按住鼠标左键拖入至Hierarchy工作区，并且删除工程建立时自动生成的相机MainCamera。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220817112804.48565187417359892974044704788245:50530816060110:2800:2D8AE558368C885A2B6098AE12F08F1292FA8F3B41D3E40DDEC29AEC59519793.png?needInitFileName=true?needInitFileName=true "点击放大")


2. 添加HVRCamera之后，场景已经能够在手机 / 平板上显示VR模式，单击HVRCamera，在Inspector栏中会显示其属性。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220817112804.60631093575988445690296199043605:50530816060110:2800:0F3712F9AE084C4FE088EFDB4DD080C4C63800CFA07FF91F095EB36C75CC6D22.png?needInitFileName=true?needInitFileName=true "点击放大")

其中：

* RenderDepthFormat为Unity中初始化RenderTexture时的depth参数，默认为24bit，可选择设置为16bit、24bit或32bit。
* RenderResolutionScale为Unity中初始化RenderTexture时的分辨率缩放倍数，默认值为1，默认分辨率：1080*1080，开发者可根据场景复杂度设置渲染分辨率。 说明
  > * 修改此分辨率会改变内容清晰度，同时也会影响性能和功耗。
  > * 默认情况SDK会根据温控方案设置、调整分辨率，通过RenderResolutionScale调节的分辨率仅在温控方案失效时起作用。
* SinglePass仅在开启Multiview模式时勾选， 开启Multiview模式具体方式请[降功耗优化措施](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/feature-options-reduce-power-0000001160006450)。 说明
  >
  > 普通模式切勿勾选，否则会出现显示问题。
