# 概述

原子化接口SDK提供了一套较为完备、高扩展性的图形渲染接口，使用原子化接口可以完成复杂的图形应用开发，例如3D模型动画播放器应用、AR动作捕捉展示应用等。

原子化接口主要提供了如下类：  

|Class|Description|
|:-------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[SceneKit](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-scenekit-0000001061092023)|全局单例，用于进行初始化与全局配置。|
|[RenderView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-renderview-0000001061309635)|渲染视图控件，继承自SurfaceView，添加到Activity中即可使用。 渲染视图相当于一块画布，包含一个场景，场景的变化将直接通过渲染视图展示给用户。|
|[Scene](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-scene-0000001061478095)|场景，提供资源使用与节点操作的方法。 场景将对挂载在其下的各个节点进行管理。例如加载3D模型后，模型的根节点将挂载到场景中，场景可对其进行管理。|
|[Node](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-node-0000001061589671)|节点，组件的载体。 本身具有层级关系，根节点将挂载到场景中，被场景管理。|
|[Component](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-component-0000001061389684)|组件，一类数据的集合，可挂载至节点。 组件的变化会对场景的渲染结果产生直接影响。如挂载在3D模型根节点的[Transform](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-transform-0000001061838140)（变换组件），当改变其位置、旋转、缩放等属性时，对应的3D模型也将发生相应的变化。|
|[Resource](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-resource-0000001061679936)|资源，可独立加载的外部实体，可被场景加载与使用。 包括模型资源（[Model](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-model-0000001061589673)）与纹理贴图资源（[Texture](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-texture-0000001061389686)）。|

组件包括：  

|Class|Description|
|:---------------------------------------------------------------------------------------------------------------------|:-------------------------------------------|
|[Transform](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-transform-0000001061838140)|变换组件，用于控制节点的位置、旋转、缩放，是节点的固有属性，无需手动挂载。|
|[Camera](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-camera-0000001061092025)|相机组件，用于控制场景相机参数，需要手动创建挂载，场景中至少需要一个激活的相机组件。|
|[Light](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-light-0000001062157734)|灯光组件，用于控制场景灯光参数，需要手动创建挂载。 灯光组件可用于设置是否开启阴影效果。|
|[Renderable](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-renderable-0000001061997748)|渲染件组件，描述可被渲染的物体信息，模型资源实例化后自动挂载。|
|[Animator](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-animator-0000001061519950)|动画播放器组件，用于控制动画播放，模型资源实例化后自动挂载。|
|[FluidComponent](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-fluidcomponent-0000001304227669)|3D流体组件，用于控制3D流体参数，需要手动创建挂载。|

资源包括：  

|Class|Description|
|:-------------------------------------------------------------------------------------------------------|:---------------------------------|
|[Model](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-model-0000001061589673)|模型资源，可被实例化至场景同时产生一颗节点树并将根节点挂载到场景中。|
|[Texture](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-texture-0000001061389686)|纹理贴图资源，可被场景使用。|

[Scene](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-scene-0000001061478095)、[Node](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-node-0000001061589671)和[Component](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-component-0000001061389684)之间存在紧密联系。下图是播放一个简单的骨骼动画的场景示意图：

* [Scene](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-scene-0000001061478095)对所有的[Node](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-node-0000001061589671)节点进行管理。
* 模型资源加载后被实例化到场景中，产生一颗节点树：②-④-⑤-⑥，并将根节点②挂载到场景中。
* 每个[Node](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-node-0000001061589671)节点会自动挂载[Transform](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-transform-0000001061838140)组件，用于进行移动、旋转、缩放等变换。
* 不同的[Node](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-node-0000001061589671)节点可通过挂载不同的组件具有不同的功能：
  * 节点①挂载了[Camera](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-camera-0000001061092025)组件，提供相机的相关功能。

  <!-- -->

  * 节点②挂载了[Animator](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-animator-0000001061519950)组件，提供动画播放的相关功能。
  * 节点③挂载了[Light](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-light-0000001062157734)组件，能够提供灯光效果的相关功能。
  * 节点④、⑤为素材的骨骼节点，只具有[Transform](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-transform-0000001061838140)组件。
  * 节点⑥挂载了[Renderable](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-renderable-0000001061997748)组件，具有顶点数据等可被渲染物体的信息。
