# 新建Unity工程并导入SDK

1. 打开Unity，新建3D工程。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220519145806.67008263778460724944009414782523:50530518075906:2800:A8DE92C5ED7F86F76DE312A4E15E69A78ECEC66B86300DD134994F869A82238D.png?needInitFileName=true?needInitFileName=true "点击放大")
2. 依次点击"Assets > > Import Package > Custom Package"。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220519145806.04624623061146977983829408572599:50530518075906:2800:7C3A5C310D69C21B3B5D492A6854EDAFC737BD4D759D68374BB0B21969147C69.png?needInitFileName=true?needInitFileName=true "点击放大")
3. 在弹出的对话框选择已下载的**hvrsdk-3.5.x.unitypackage**，点击Import，即可导入。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220519145806.05872529876076478386162515922539:50530518075906:2800:4ACBDADD65B3CBF8DF7C26B30CFCAE0CD1BAAAEE96170E942E11FFDEB894C77A.png?needInitFileName=true?needInitFileName=true "点击放大")

   导入时若弹出如下提示框，请选择点击 "I Made a Backup, Go Ahead!"，否则编译出的应用会有找不到接口的问题。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220519145806.20735607763301124465605687867549:50530518075906:2800:2ED23C890DFD7BEBB8D282642F18172F3660DA7BE1AE7248692598C1FC8EBDD7.png?needInitFileName=true?needInitFileName=true)
4. hvrsdk-3.5.x.unitypackage导入后，由Assets/HVR/Scripts/HVRAddUILayer.cs自动添加HVRUILayer和HVRVolumeUILayer两个UI Layer。分别绘制特定UI和音量弹框。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220519145806.63059446118183197198777905255474:50530518075906:2800:D39EE7F7AD09B497533BAD0678BDF81CDD4FC90E5ED83FAA8EDA170775C43A5B.png?needInitFileName=true?needInitFileName=true "点击放大")
   * 若自动添加UI Layer失败，会有弹框提示，如下图所示，需要开发者手动添加名称为HVRUILayer和HVRVolumeUILayer的UI Layer。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220519145806.19302149790492079661096648485653:50530518075906:2800:3AD9E30774CB6B69829821BE9E6A19E436B8128135DF49FE8A4E5F31FA1BF80F.png?needInitFileName=true?needInitFileName=true "点击放大")


   * 开发者不允许在这两个UI Layer上绘制其他内容，也不允许场景中其他Camera显示这两个UI层（例如：修改HVR SDK的左右Camera的CullingMask，致使显示这两层内容）。
   * 开发者若要修改HUAWEI VR Camera的CullingMask，也一定要同时保证该Camera不绘制这两个UI Layer。 代码示例如下：

     ```screen
     HVRLayoutCore.m_LeftCamObj.GetComponent<Camera>().cullingMask &= ~(1 << LayerMask.NameToLayer(HVRDefCore. m_VolumeUILayerName));
     ```
