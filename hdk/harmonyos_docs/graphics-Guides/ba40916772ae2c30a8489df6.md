# FaceView

## 开发步骤

图形引擎服务通过[FaceView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-faceview-0000001052804698)提供了面部AR场景的渲染能力。[FaceView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-faceview-0000001052804698)继承自GLSurfaceView并重写了相关生命周期方法，方便调用。本节将展示如何通过使用一个Switch按钮，控制是否显示面部AR替换效果。完整代码请参见[调用示例](#section6506155261217)。

1. 创建一个继承自Activity的FaceViewActivity。

   ```screen
   public class FaceViewActivity extends Activity {
       private FaceView mFaceView;
   }
   ```

2. 将[FaceView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-faceview-0000001052804698)添加到Layout布局中，并申请相机权限。

   ```screen
   <uses-permission android:name="android.permission.CAMERA" />
   <!-- FaceView的大小设置为适配屏幕宽高。-->
   <!-- 使用SDK的类型为AR Engine，可设置为ML_KIT。-->
   <com.huawei.hms.scene.sdk.FaceView
       android:layout_width="match_parent"
       android:layout_height="match_parent"
       android:id="@+id/face_view"
       app:sdk_type="AR_ENGINE">
   </com.huawei.hms.scene.sdk.FaceView>
   ```

   [FaceView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-faceview-0000001052804698)为保证效果暂不支持转屏与分屏操作，请在Android Manifest文件相应的Activity标签中进行配置：

   ```screen
   android:screenOrientation="portrait"
   android:resizeableActivity="false"
   ```

   > 说明
   >
   > [FaceView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-faceview-0000001052804698)中需要使用ML SDK或AR Engine SDK中人脸检测的相关算法，需要在[FaceView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-faceview-0000001052804698)中指定使用SDK的类型。SDK类型可选："ML_KIT"、"AR_ENGINE"。

3. 将Switch添加到Layout布局中。

   ```screen
   <Switch
       android:layout_width="wrap_content"
       android:layout_height="wrap_content"
       android:id="@+id/switch_view"
       android:layout_alignParentTop="true"
       android:layout_marginTop="15dp"
       android:layout_alignParentEnd="true"
       android:layout_marginEnd ="15dp"
       android:text="@string/face_view"
       android:theme="@style/AppTheme"
       tools:ignore="RelativeOverlap" />
   ```

4. 重写onCreate方法，并获取[FaceView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-faceview-0000001052804698)。

   ```screen
   @Override
   protected void onCreate(Bundle savedInstanceState) {
       super.onCreate(savedInstanceState);
       setContentView(R.layout.activity_face_view);
       // 获取FaceView，其ID为face_view。
       mFaceView = findViewById(R.id.face_view);
   }
   ```

5. 在onCreate方法中创建Switch按钮，并重写监听方法。

   ```screen
   final float[] position = { 0.0f, 0.0f, 0.0f };
   final float[] rotation = { 1.0f, 0.0f, 0.0f, 0.0f };
   final float[] scale = { 1.0f, 1.0f, 1.0f };
   // 获取Switch按钮，其ID为switch_view。
   Switch mSwitch = findViewById(R.id.switch_view);
   // 设置Switch按钮开关状态变化的监听方法。
   mSwitch.setOnCheckedChangeListener(new CompoundButton.OnCheckedChangeListener() {
       @Override
       public void onCheckedChanged(CompoundButton buttonView, boolean isChecked) {
           // 清除当前已加载的素材。
           mFaceView.clearResource();
           if (isChecked) {
               // 加载素材。
               int index = mFaceView.loadAsset("FaceView/fox.glb", LandmarkType.TIP_OF_NOSE);
               // （可选）设置面部AR位姿的初始值。
               mFaceView.setInitialPose(index, position, scale, rotation);
           }
       }});
   ```

6. 重写onPause方法，并调用[FaceView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-faceview-0000001052804698)的[onPause](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-faceview-0000001052804698#section8328104711216)方法。

   ```screen
   @Override
   protected void onPause() {
       super.onPause();
       mFaceView.onPause();
   }
   ```

7. 重写onResume方法，并调用[FaceView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-faceview-0000001052804698)的[onResume](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-faceview-0000001052804698#section1091831512116)方法。

   ```screen
   @Override
   protected void onResume() {
       super.onResume();
       mFaceView.onResume();
   }
   ```

8. 重写onDestroy方法，并调用[FaceView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-faceview-0000001052804698)的[destroy](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-faceview-0000001052804698#section1020321445920)方法。

   ```screen
   @Override
   protected void onDestroy() {
       super.onDestroy();
       mFaceView.destroy();
   }
   ```

## 调用示例

```screen
public class FaceViewActivity extends Activity {
    private FaceView mFaceView;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_face_view);
        mFaceView = findViewById(R.id.face_view);

        final float[] position = { 0.0f, 0.0f, 0.0f };
        final float[] rotation = { 1.0f, 0.0f, 0.0f, 0.0f };
        final float[] scale = { 1.0f, 1.0f, 1.0f };
        Switch mSwitch = findViewById(R.id.switch_view);
        mSwitch.setOnCheckedChangeListener(new CompoundButton.OnCheckedChangeListener() {
            @Override
            public void onCheckedChanged(CompoundButton buttonView, boolean isChecked) {
                mFaceView.clearResource();
                if (isChecked) {
                    // 加载素材。
                    int index = mFaceView.loadAsset("FaceView/fox.glb", LandmarkType.TIP_OF_NOSE);
                    // （可选）设置面部AR位姿的初始值。
                    mFaceView.setInitialPose(index, position, scale, rotation);
                }
            }
        });
    }

    // 必须同步调用FaceView的onPause()。
    @Override
    protected void onPause() {
        super.onPause();
        mFaceView.onPause();
    }

    // 必须同步调用FaceView的onResume()。
    @Override
    protected void onResume() {
        super.onResume();
        mFaceView.onResume();
    }

    // 必须同步调用FaceView的destroy()。
    @Override
    protected void onDestroy() {
        super.onDestroy();
        mFaceView.destroy();
    }
}
```
