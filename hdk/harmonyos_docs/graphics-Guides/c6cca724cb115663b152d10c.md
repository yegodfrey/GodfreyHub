# obj模型

CG Kit渲染框架支持对".obj"格式的模型解析，不支持默认材质文件解析，需要配置[cgmat材质文件](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/cgmat-configuration-file-0000001106071566)。自定义的资源文件需要放到Android Studio工程的"assets"目录下，构建时自动打包到APK中。
