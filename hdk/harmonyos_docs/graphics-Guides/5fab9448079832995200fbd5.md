# 初始化

在调用任意原子化接口前，需要先使用[SceneKit](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-scenekit-0000001061092023)类进行初始化。初始化接口分为同步接口和异步接口。

两种初始化接口触发升级的方式分别如下：

* **同步初始化接口** [initializeSync](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-scenekit-0000001061092023#section1814112016111)：抛出UpdateNeededException，可通过UpdateNeededException实例的getIntent方法获取升级Intent。
* **异步初始化接口** [initialize](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-scenekit-0000001061092023#section98553811514)：触发监听器[Scene.OnUpdateEventListener](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-scene-listener-0000001061200041)的[onUpdateNeeded](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-scenekit-listener-0000001061519948#section284718104238)回调方法，并将升级Intent作为入参传入。

您可以根据需求选用其一，下面的开发步骤中会以同步接口为例。

在只引入SDK主体、不引入SDK扩展包的情况下，初始化有可能触发Scene Kit APK升级，您需要考虑该情况，主动启动接口提供的Intent并在onActivityResult中处理升级结果。
> 说明
>
> 请勿在setContentView之前调用初始化方法，以防不必要的错误。

## 开发步骤

1. 创建两个Activity：MainActivity和SampleActivity。其中MainActivity负责完成[SceneKit](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-scenekit-0000001061092023)初始化，SampleActivity用于容纳渲染视图，并呈现最终效果。
2. 在MainActivity中添加初始化标识和初始化方法。在初始化方法中设置[SceneKit](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-scenekit-0000001061092023)全局属性，并使用同步初始化接口[initializeSync](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-scenekit-0000001061092023#section1814112016111)初始化[SceneKit](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-scenekit-0000001061092023)。

   ```screen
   private static final int REQ_CODE_UPDATE_SCENE_KIT = 10001;
   private boolean initialized = false;

   private void initializeSceneKit() {
       // 如果已经初始化，不再重复初始化。
       if (initialized) {
           return;
       }
       // 创建SceneKit属性，配置AppId与图形后端API。
       SceneKit.Property property = SceneKit.Property.builder()
           .setAppId("${app_id}")
           .setGraphicsBackend(SceneKit.Property.GraphicsBackend.GLES)
           .build();
       try {
           // 使用同步接口进行初始化。
           SceneKit.getInstance()
               .setProperty(property)
               .initializeSync(getApplicationContext());
           initialized = true;
           Toast.makeText(this, "SceneKit initialized", Toast.LENGTH_SHORT).show();
       } catch (UpdateNeededException e) {
           // 捕获需要升级异常，拉起升级Activity。
           startActivityForResult(e.getIntent(), REQ_CODE_UPDATE_SCENE_KIT);
       } catch (Exception e) {
           // 处理初始化异常。
           Toast.makeText(this, "failed to initialize SceneKit: " + e.getMessage(), Toast.LENGTH_SHORT).show();
       }
   }
   ```

3. 复写MainActivity的onActivityResult方法，处理升级结果。

   ```screen
   // resultCode为-1时代表升级成功，其他resultCode均代表升级失败。
   private static final int RES_CODE_UPDATE_SUCCESS = -1;

   @Override
   protected void onActivityResult(int requestCode, int resultCode, @Nullable Intent data) {
       super.onActivityResult(requestCode, resultCode, data);
       // 如果升级成功，尝试重新初始化。
       if (requestCode == REQ_CODE_UPDATE_SCENE_KIT
           && resultCode == RES_CODE_UPDATE_SUCCESS) {
           try {
               SceneKit.getInstance()
                   .initializeSync(getApplicationContext());
               initialized = true;
               Toast.makeText(this, "SceneKit initialized", Toast.LENGTH_SHORT).show();
           } catch (Exception e) {
               // 重新尝试初始化时不再捕获升级异常。
               Toast.makeText(this, "failed to initialize SceneKit: " + e.getMessage(), Toast.LENGTH_SHORT).show();
           }
       }
   }
   ```

4. 在MainActivity的Layout文件中添加按钮，用于跳转至SampleActivity。

   ```screen
   <?xml version="1.0" encoding="utf-8"?>
   <LinearLayout
       xmlns:android="http://schemas.android.com/apk/res/android"
       android:layout_width="match_parent"
       android:layout_height="match_parent">

       <Button
           android:layout_width="match_parent"
           android:layout_height="wrap_content"
           android:text="@string/btn_render_view_demo_text"
           android:onClick="onBtnRenderViewDemoClicked"/>

   </LinearLayout>
   ```

5. 在MainActivity中添加按钮回调。

   ```screen
   public void onBtnRenderViewDemoClicked(View view) {
       // 如果未初始化，先初始化。
       if (!initialized) {
           initializeSceneKit();
           return;
       }
       // 跳转到SampleActivity。
       startActivity(new Intent(this, SampleActivity.class));
   }
   ```

> 说明
>
> 原子化接口中3D流体组件（[FluidComponent](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-fluidcomponent-0000001304227669)），只支持Vulkan渲染后端。若需使用[FluidComponent](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-fluidcomponent-0000001304227669)，需在步骤2，setGraphicsBackend() 中传入的渲染后端类型为 SceneKit.Property.GraphicsBackend.VULKAN。
