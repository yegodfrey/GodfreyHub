# 调用AI捏脸插件

AI捏脸插件包含两部分功能：PC端的角色模型适配与移动端照片捏脸。通过PC端角色模型适配生成角色模型资源文件（character.bin），将角色模型资源文件和其他资源文件（shape.bin、ModA.om、ModB.om、ModC.om）拷贝至移动端，调用移动端照片捏脸接口实现输入用户照片输出捏脸参数的功能。

* 角色模型适配：在PC端将用户提供的游戏角色模型转换为可进行智能捏脸计算的模型资源文件。
* 照片捏脸：根据用户传入的人脸照片在Android平台生成还原照片人脸特征的游戏角色人脸。

## 头文件依赖

在项目中需要两个头文件:

* CharacterInterface.h：PC端角色模型适配的接口以及结构体。
* AIFaceMod.h：移动端照片捏脸的接口以及结构体。

## 角色模型适配

1. 加载动态库文件，PC端（Windows 10）链接CharacterAdapter.dll、CharacterAdapter.lib动态库，以及开源软件[OpenCV](https://sourceforge.net/projects/opencvlibrary/files/4.2.0/opencv-4.2.0-vc14_vc15.exe/download)的动态库opencv\build\x64\vc15\lib\opencv420.dll。
2. 初始化结构体参数[CharacterData](https://developer.huawei.com/consumer/cn/doc/graphics-References/characterdata-0000001178927805)。

   ```screen
   // 设置结构体参数characterData。
   CharacterData characterData;
   characterData.posPath = "./model/blendshapes/Positive/";
   characterData.negPath = "./model/blendshapes/Negative/";
   characterData.neutralPath = "./model/blendshapes/neutral.obj";
   characterData.markIdPath = "./model/markIds.txt";
   characterData.contourIdPath = "./model/contourIds.txt";
   characterData.texturePath = "./model/texture.png";
   ```

3. 调用角色模型适配接口[CharacterAdapter](https://developer.huawei.com/consumer/cn/doc/graphics-References/characteradapter-0000001180225147)。

   ```screen
   // 设置适配后的角色模型资源文件存储路径。
   std::string savePath = "./model/character.bin";
   // 调用角色模型适配接口，生成角色模型资源文件。
   int ret = CharacterAdapter(characterData, savePath);
   if(ret) {
       return;
   }
   ```

## 照片捏脸

1. 加载动态库文件，移动端（Android）链接libAIFaceMod.so动态库。
2. 初始化结构体参数[AIFaceModParas](https://developer.huawei.com/consumer/cn/doc/graphics-References/aifacemodparas-0000001133008108)，可以设置照片捏脸所需要的参数，包含人脸照片信息、模型资源文件、捏脸效果参数。

   ```screen
   // 设置照片捏脸所需要的参数modParas，包含人脸照片信息、模型资源文件、捏脸效果参数。
   AIFaceModParas modParas;
   // 人脸照片信息
   modParas.landmarkMode = 0;
   modParas.landmarkData = { 0.0f };
   modParas.segmentImgW = 0;
   modParas.segmentImgH = 0;
   modParas.segmentImg = { 0 };
   // 模型资源文件
   modParas.modAPath = "./assets/ModA.om";
   modParas.modBPath = "./assets/ModB.om";
   modParas.modCPath = "./assets/ModC.om";
   modParas.shapePath = "./assets/shape.bin";
   modParas.characterPath = "./assets/character.bin";
   // 捏脸效果参数
   modParas.characterGender = 0;
   modParas.enableRealTex = 0;
   ```

3. 初始化结构体参数[GeneratedParas](https://developer.huawei.com/consumer/cn/doc/graphics-References/generatedparas-0000001134825080)，用于写入照片捏脸的捏脸参数结果。

   ```screen
   GeneratedParas genParas;
   ```

4. 调用照片捏脸接口[GenerateFaceParas](https://developer.huawei.com/consumer/cn/doc/graphics-References/generatefaceparas-0000001180345085)，获取照片捏脸的捏脸参数结果。

   ```screen
   int ret1 = GenerateFaceParas(modParas, genParas);
   if (ret1) {
       return;
   }
   ```

5. （可选）调用捏脸美观度调整接口[ModifyFaceParas](https://developer.huawei.com/consumer/cn/doc/graphics-References/modifyfaceparas-0000001141570528)，获取调整后照片捏脸的捏脸参数结果。

   ```screen
   // 设置美观度系数modifyDegree。
   float modifyDegree = 0.5;
   // 调用捏脸美观度调整接口。
   int ret2 = ModifyFaceParas(modifyDegree, genParas);
   if (ret2) {
       return;
   }
   ```
