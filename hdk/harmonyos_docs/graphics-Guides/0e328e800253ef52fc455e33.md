# 资源清理

已经加载的资源在无需再使用时，需要及时调用资源清理接口完成清理，否则可能会面临内存泄漏的风险。

您需要手动清理的资源主要为模型与纹理。其他的资源如场景、节点、组件都会在渲染视图销毁时自动回收。针对模型和纹理资源，图形引擎服务提供了两种清理方式：

* 显式清理：即对应资源的destroy静态方法。
* 垃圾回收：[ResourceFactory](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-resourcefactory-0000001061309637)中的[gc](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-resourcefactory-0000001061309637#section1088511883712)方法。

以上两类接口需要在恰当的时机调用，后文的开发步骤中将为您展示调用示例。

## 开发步骤

1. 在SampleActivity的onDestroy方法中调用模型显式清理方法。

   ```screen
   @Override
   protected void onDestroy() {
       // ......
       if (model != null) {
           // 显式清理模型资源。
           Model.destroy(model);
       }
       super.onDestroy();
   }
   ```

2. 在SampleActivity的onDestroy方法中调用纹理显式清理方法。

   ```screen
   @Override
   protected void onDestroy() {
       // ......
       if (skyBoxTexture != null) {
           // 显式清理天空盒纹理资源。
           Texture.destroy(skyBoxTexture);
       }
       if (specularEnvTexture != null) {
           // 显式清理镜面反射环境光照纹理资源。
           Texture.destroy(specularEnvTexture);
       }
       if (diffuseEnvTexture != null) {
           // 显式清理漫反射环境光照纹理资源。
           Texture.destroy(diffuseEnvTexture);
       }
       super.onDestroy();
   }
   ```

3. 在SampleActivity的onDestroy方法中调用垃圾回收方法。

   由于资源存在缓存机制，调用完资源销毁方法（如[Texture](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-texture-0000001061389686).[destroy](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-texture-0000001061389686#section43538203318)）后，可能仍然存在缓存。可以在onDrawFrame后调用[gc](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-resourcefactory-0000001061309637#section1088511883712)清除缓存。

   ```screen
   @Override
   protected void onDestroy() {
       // ......
       // 触发垃圾回收。
       ResourceFactory.getInstance().gc();
       super.onDestroy();
   }
   ```
