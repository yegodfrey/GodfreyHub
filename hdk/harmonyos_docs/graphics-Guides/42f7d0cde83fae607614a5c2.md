# 开发准备

* 在PC端下载安装 Epic Games Launcher。
* 启动 Epic Games Launcher 并登陆已经注册的账号。
* 在 Epic Games Launcher 的主界面中选中"工作"项，并下载对应的Unreal版本。
* 下载 Huawei VR SDK For Unreal 压缩包。
* 准备好华为手机及华为VR头盔。手机联网后插入VR GLASS眼镜，会自动提示安装所需VR运行环境，按指引操作即可。
