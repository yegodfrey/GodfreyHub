# 概述

原子化2D流体接口SDK提供了一套较为完备、高扩展性的流体模拟接口，使用原子化接口可以完成创建流体粒子，模拟流体晃动的物理效果。

原子化接口主要提供了如下类：  

|Class|Description|
|:---------------------------------------------------------------------------------------------------------------------|:------------------------------------|
|[SceneKitFluid](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-scenekitfluid-0000001117457606)|全局单例，用于进行初始化与全局配置。|
|[World](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-world-0000001163897341)|物理世界，包含刚体和粒子，管理模拟仿真。|
|[ParticleSystem](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-particlesystem-0000001163817377)|粒子系统，描述粒子的物理系数，如半径、粘度、弹性等，支持粒子的添加、删除。|
|[Body](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-body-0000001117457608)|刚体，支持设置刚体形状，如圆形、长方形等。|
