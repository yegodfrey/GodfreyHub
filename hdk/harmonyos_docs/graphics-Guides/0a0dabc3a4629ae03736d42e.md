# 调用体积雾插件

本插件支持用户在PC端调节渲染参数，移动端根据接收到的参数进行雾效渲染。

## 头文件依赖

调用本插件需包含以下两个头文件。

* VolumeFogRenderAPI.h：定义体积雾渲染接口。
* VolumeFogParas.h：定义体积雾渲染所需的光源及物理参数。

## 体积雾渲染

1. 加载动态库文件。
   * PC端（Windows 10）链接RenderingVolumeFog.dll动态库。
   * 移动端（Android）链接libRenderingVolumeFog.so动态库。
2. 创建[VolumeFogRenderAPI](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/volumefogrenderapi-0000001157089829)对象。

   ```screen
   VolumeFogRenderAPI* render = CreateVolumeFogRenderAPI(GraphicAPI apiType);
   ```

   其中[GraphicAPI](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/graphicapi-0000001110769978)为枚举变量，用来定义使用的图形接口。

   ```screen
   typedef enum GraphicAPI
   {
       // Android平台使用OpenGLES 3.1
       GraphicAPI_OpenGLES31 = 0,
       // Windows平台使用OpenGL 4.0
       GraphicAPI_OpenGL = 1, 
   } GraphicAPI;
   ```

3. 初始化参数。
   * 初始化噪声雾、高度雾等基础参数[BaseParas](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/baseparas-0000001156929855)。

     ```screen
     struct BaseParas {
         float density = 0;
         float absorb = 0;
         float scatter = 0;

         // 噪声雾相关参数
         bool noiseFogEnable = false;
         float noiseFogAmount = 0;
         float noiseFogScale[3] = { 0 };
         float noiseBias = 0;
         float windSpeed[3] = { 0 };
         float time = 0;

         // 高度雾相关参数
         bool heightFogEnable = false;
         float heightFogExponent = 0;
         float heightFogOffset = 0;

         // 环境光
         float ambientLightIntensity = 0;
         float ambientLightColor[3] = { 0 };

         // 相机参数
         float camPos[3] = { 0 };
         float camDir[3] = { 0 };
         float nearClip = 0;
         float farClip = 0;
         float withdraw = 0;
         float posLB[3] = { 0 };
         float posRB[3] = { 0 };
         float posLT[3] = { 0 };

         // 光源数量
         int pointLightNum = 0;
         int spotLightNum = 0;

         // volume尺寸相关，数值越大效果越好，耗时越长，建议使用默认值
         int tileSize = 12;
         int volumeDepth = 36;
     };
     ```

   * 初始化平行光、阴影等相关参数[DirLightParas](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/dirlightparas-0000001157089831)。

     ```screen
     struct DirLightParas {
         float dir[3] = { 0 };
         float color[3] = { 0 };
         float intensity = 0;

         // 阴影相关
         int shadowFlag = 0;
         float shadowMatrix[16] = { 0 };
         void* shadowMap = nullptr;
         int shadowMapResolution = 0;
     };
     ```

   * 初始化点光源相关参数[PointLightParas](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/pointlightparas-0000001110946920)。

     ```screen
     struct PointLightParas {
         float pos[3] = { 0 };
         float color[3] = { 0 };
         float range = 0;
         float intensity = 0;
     };
     ```

   * 初始化聚光源相关参数[SpotLightParas](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/spotlightparas-0000001110787016)。

     ```screen
     struct SpotLightParas {
         float pos[3] = { 0 };
         float color[3] = { 0 };
         float dir[3] = { 0 };
         float angle = 0;
         float range = 0;
         float intensity = 0;
     };
     ```

4. 渲染体积雾。

   ```screen
   // 初始化环境https://developer.huawei.com/consumer/cn/doc/development/graphics-References/volumefogrenderapi-0000001157089829#section788322516435
   render->CreateResources();
   do{
       // 传递渲染参数https://developer.huawei.com/consumer/cn/doc/development/graphics-References/volumefogrenderapi-0000001157089829#section1124213454448，其中baseParas为BaseParas结构体变量
       bool ret = render->SetRenderFogParas(&baseParas,
           // 平行光DirLightParas结构体变量
           &dirLight,
           // 点光源PointLightParas结构体数组
           pointLights,
           // 聚光源SpotLightParas结构体数组
           spotLights);
      if(!ret){
         return;
      }
      // 获取渲染纹理GLuint fogTexHandle
      ...
      // 获取渲染帧的结果https://developer.huawei.com/consumer/cn/doc/development/graphics-References/volumefogrenderapi-0000001157089829#section1350194774313
      render->RenderFogFrameTexture(void* fogTexHandle,
                                   int textureWidth,
                                   int textureHeight,
                                   int textureDepth);
   // 在对连续帧进行渲染时，需要进行循环调用，直至渲染任务完成  
   }while(...) 
   // 释放资源和数据https://developer.huawei.com/consumer/cn/doc/development/graphics-References/volumefogrenderapi-0000001157089829#section543194314457
   render->ReleaseData();
   ```
