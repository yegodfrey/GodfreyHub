# 开发准备

下载[离线超分插件SDK](https://developer.huawei.com/consumer/cn/doc/development/graphics-Library/sdk-download-0000001050441521)，并解压。将AI超分能力依赖的资源文件ss_data.om和图像处理超分能力依赖的资源文件ie_data.bin放置到"/sdcard/osr"目录（默认）。缺少资源文件将导致插件初始化失败，从而无法使用超分特性。
> 说明
>
> * 目前只支持arm64-v8a平台架构。
> * AI超分能力目前只支持Kirin820、Kirin985、Kirin990、Kirin9000芯片平台。
> * 输入超分插件的图片，建议不做抗锯齿预处理，否则可能导致输出效果欠佳。
> * 获取ss_data.om文件请[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)。
