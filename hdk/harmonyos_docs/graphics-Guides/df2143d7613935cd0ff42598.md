# 业务简介

## 功能介绍

开发者使用 Huawei VR SDK 3.5 和 OpenXR 进行华为 VR 设备的应用开发，Huawei VR SDK 3.5 for OpenXR（以下简称 SDK 3.5）提供的功能主要包括：

* 获取 VR Glasses、控制器的姿态
* 通知消息自动弹框（来电、信息、闹钟等）
* 控制器快捷键功能
