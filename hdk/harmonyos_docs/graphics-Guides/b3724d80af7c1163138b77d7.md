# 设计开发流程介绍

1.设计规划

明确需求后，梳理素材设计思路，明确设计内容，规划交付节点，安排人员分工。

2.素材设计

原画师设计趣味性强，可玩性高，精致美观，符合大众喜好审美的素材文件输出设计稿。

3.动效设计

动效师根据原画师所提供素材制作动画及特效，输出相应素材的动画序列帧。

4.测试开发

协调测试，评估效果，打磨细节，最终完成文件交付。
