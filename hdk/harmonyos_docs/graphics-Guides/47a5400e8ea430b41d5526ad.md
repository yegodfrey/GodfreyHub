# cgmat配置文件

CG Kit Material配置文件，简称cgmat配置文件（后缀为.cgmat），位于"asset/material"中，是CG Kit定义的json格式文件。

CG Kit 6.0.0及以后版本支持通过资源文件设置材质属性，默认为V1版本的cgmat文件。

CG Kit 6.3.0版本开始支持配置V2版本的cgmat文件，支持同一个cgmat中配置多个材质实现方法和多个渲染过程，实现物体描边等功能。
