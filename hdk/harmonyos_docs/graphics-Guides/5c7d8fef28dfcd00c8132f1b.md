# 咨询与合作

AR Engine可支持第三方包括手机、平板、电视、XR等智能设备，为第三方智能设备和行业解决方案提供AR数字化底座。秉承开放共赢的原则，当您的应用或设备希望接入AR Engine服务时，欢迎通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)进行咨询。
