# 模型制作流程

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230602145220.05428454007405653458561527782023:50001231000000:2800:20449C4DD85D2CBA203B8F5BA26CB93AB18420605A46584248FD619FC2CEAB4E.png?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")

1.用zb或其他雕刻软件创建模型大型

a.基础物体创建：

可自行创建物体，也可使用zb2020自带Z球动物作为基础形体，按A转换为可雕刻的模型

b.雕刻高模大型：

可使用这个功能辅助做大型，也可用Dynamesh。此步骤模型面数不要太高。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230602145220.86445895217905495001900123782237:50001231000000:2800:293C9E2F31FD0E985036EA50C7E47BBB93ADE20630198805BE23DD3D22E86D59.png?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")

c.高模细化：

使逐步细化大型至高模完成度70%-90%。完成度依据物体形状而定。建议皮肤毛发等完成度高些，如遇硬表面物体，建议采用ZB硬表面建模或者Maya卡线的方法制作模型。

2.开始拓扑布线

a.低模大型：

为节省时间，可将之前的高模大型ZRemesher，根据自己需要调节目标多边形数参数。
> 注意
>
> ZRemesher的模型不能直接使用需要进拓扑软件修改。

下图为自动布线过的模型，明显脸部布线不符合规范，后脑勺底部等部分可以稍微修改一下使用。脸部须重新布线。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230602145220.02892172375254928643174346168020:50001231000000:2800:154C164F1A6B5E1FC49F2FC771225461BC867A2F9DF1A631666753581F0AAC54.png?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")

b.低模拓扑：

用之前自动布线的模型进行调整，需要手动布线成规范的布线。布线时注意眼部嘴部布线需要按照肌肉走向，嘴角和有明显眼角的模型应尽量保证上下段数一致。（如下图所示）其他可运动部分也需要有段数，保证动画流畅。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230602145220.51369720545483130052111369426175:50001231000000:2800:4D929655991B69BA663254087BA30F55CBF0228ED3DD02F58FFFE59CD736A26F.png?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")

c.面数控制：

此步骤可和低模拓扑同步进行，所有面数（含口腔）尽量控制在tris：10000以下，依复杂程度适当增加但不超过tris：12000。后脑勺背面等不重要的位置需要减面。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230602145220.16083903764163787902653113414498:50001231000000:2800:B0372D6D7A9BBDA9BC9C2D5DCF1112341ED7BF4F342238B425B8F42C3AD798F5.png?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")

3.贴图作流程

a.用Substance Painter或其他制作软件制作贴图。注意：sp中初始模式许要设置成spec-gloss

b.贴图要求：

* 贴图格式为Png；
* 以2048*2048大尺寸制作，建议8为或16为，提交则按照具体要求（例如：512*512规格）；
* 除特殊需求外，通常需要三张贴图，命名分别为：颜色（XXX_diffusemap)、 凹凸（XXX_normalmap）和高光贴图（XXX_specularmap）。 例如： ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230602145221.40856446693452277762972944084834:50001231000000:2800:63960DB6BF93865E033EEF95F4B2CB750B31E58C01CF61B1572D4E589A5DC96E.png?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")

  建模师在完成模型制作后导出FBX的文件和贴图文件交付给动画师进行骨骼绑定和动画制作。
