# 调用CG Kit插件框架接口

通过CG Kit插件框架进行遮挡剔除插件调用时，可以参见[调用插件管理框架API](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/demo-dev-process-0000001050197954#section84245315545)，另外需要再包含头文件HiCullingCgkit.h。依赖的动态库文件为libcgkit_plugin_oc.so。

插件框架加载遮挡剔除插件成功后，通过以下函数负责功能接口的调用。

```screen
bool Execute(const Param &paramIn, Param &paramOut)
```

使用CGKit::Param进行接口的参数传递，以创建遮挡剔除对象为例。

```screen
struct HiCulling* obj;
Param paramIn, paramOut, paramFunc, paramA;
// 设置FUNCTION_NAME关键字的键值为HcCreate 
paramFunc.Set<String>(std::string("HcCreate"));
paramIn.Set(std::string("FUNCTION_NAME"), paramFunc);
// 设置ENABLE_MULTI_THREAD关键字的键值为true 
paramA.Set<s32>(true);
paramIn.Set(std::string("ENABLE_MULTI_THREAD"), paramA);
 
bool ret = plugin->Execute(paramIn, paramOut);
if (ret) {
    LOGINFO("Successfully execute plugin HcCreate\n");
    // 返回对应键为OBJECT的Param，用于获取HiCulling对象
    obj = (struct HiCulling*)paramOut.Get(std::string("OBJECT")).Get();
} else {
    LOGINFO("Fail to execute plugin HcCreate\n");
}
```

对于paramIn参数，必须通过FUNCTION_NAME关键字来指定操作码，操作码对应参数的关键字可参见如下表格。
> 说明
>
> 操作码与C接口名保持一致，具体C接口名请参见[Interface Summary](https://developer.huawei.com/consumer/cn/doc/graphics-References/hccreate-0000001055775322)。

|操作码|paramIn输入参数关键字|paramOut输出参数关键字|
|:------------------|:----------------------|:----------------------|
|HcCreate|ENABLE_MULTI_THREAD|OBJECT|
|HcDestroy|OBJECT|-|
|HcSetResolution|OBJECT、WIDTH、HEIGHT|ERROR_CODE|
|HcGetResolution|OBJECT|WIDTH、HEIGHT、ERROR_CODE|
|HcClearBuffer|OBJECT|ERROR_CODE|
|HcAddOccluderMeshes|OBJECT、MESHES_PTR|ERROR_CODE|
|HcRasterizeOccluder|OBJECT|ERROR_CODE|
|HcTestOccludeesAABB|OBJECT、BOXES_PTR、RESULT|ERROR_CODE|
|HcGetDepthBuffer|OBJECT、OUT_BUFFER|ERROR_CODE|

在Param实例使用[Set(T val)](https://developer.huawei.com/consumer/cn/doc/graphics-References/param-0000001058062530#section20533162923211)方法设置关键字键值时，填入的类型T应与下表保持一致。

|参数关键字|键值类型|
|:------------------|:----|
|ENABLE_MULTI_THREAD|s32|
|OBJECT|void*|
|WIDTH|s32|
|HEIGHT|s32|
|MESHES_PTR|void*|
|BOXES_PTR|void*|
|RESULT|void*|
|OUT_BUFFER|void*|
|ERROR_CODE|s32|
