# 调用智慧流体插件

1. 加载动态库文件。

   Android平台链接libFluidShake.so动态库。
2. 初始化流体[FluidShakeInit](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/fluidshakeinit-0000001158511983)。

   ```
   FluidShakeInit(outRes, flag, startCoordinate, particleNum, boxType);
   ```

3. 实现液体随着容器移动。

   ```
   FluidShakeContainerMove(outRes, delta, context);
   ```

4. 缩放容器和粒子。

   ```
   FluidShakeContainerScale(outRes, ratio, context)
   ```

5. 释放流体插件资源。

   ```
   FluidShakeDestroy;
   ```
