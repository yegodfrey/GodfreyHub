# 调用Hrdelay接口

以下示例将向您展示如何调用Hrdelay.h头文件中的API函数[Hrdelay()](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/hrdelay-0000001189041181)。

```screen
// SystemTime() is used to get system time in nanoseconds
#define NS_PER_SECOND 1000000000LL
unsigned long long SystemTime()
{
	struct timespec t;
	t.tv_sec = t.tv_nsec = 0;
	clock_gettime(CLOCK_MONOTONIC, &t);
	return t.tv_sec * NS_PER_SECOND + t.tv_nsec;
}

// Set delay time to 1 second
void hrdelay_test()
{
	float delayS = 1;
	unsigned long long start =  SystemTime();
	Hrdelay(delayS);
	unsigned long long end =  SystemTime();
	printf("Actual delay time = %llu\n", end - start);
}
```
