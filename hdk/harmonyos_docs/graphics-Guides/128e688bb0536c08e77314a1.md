# ARFace场景

> 说明
>
> XRKit当前支持GLB和GLTF格式的模型文件。
>
> * 3D CuteMoji模型设计规范详情请参见[《3D CuteMoji模型设计规范》](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/design-and-development-process-0000001611092349)、人脸贴纸模型设计规范详情请参见[《趣味变装设计规范》](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/cosplay-design-and-development-process-0000001611451921)。

ARFace场景（ArFaceView）会将制作好的模型与人脸结合共同展示，模型与人脸贴合基准为人脸中心点，位于人脸鼻尖后的位置。XRKit同时支持普通的贴纸模型与包含表情的3D CuteMoji素材模型。

对于贴纸模型，支持动态贴纸与静态贴纸，XRKit会根据识别到的人脸位姿（ARPose），同步导入贴纸的位姿，实现贴纸跟随人脸的效果。

对于3D CuteMoji素材，包含素材位姿跟随效果与表情同步跟随效果，素材表情命名与效果请参见下表。

## 3D CuteMoji素材表情规则及命名规则表
