# 业务简介

华为XRKit基于AR Engine为您提供场景化、组件化的极简AR解决方案。XRKit包括AR展示场景组件与AR人脸场景组件，通过这些组件您可以快速接入华为AR，实现虚拟世界与现实世界的融合。

## 场景介绍

目前XRKit提供了2个大组件，分别是AR展示组件与AR人脸组件。

|组件名|说明|效果|
|:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
