# 模型制作基本要求

1. 格式要求：
   1. 两种类型模式只支持FBX格式，可以通过常见的3D建模软件，例如3D Max，Maya等软件导出。
   2. 需要使用素材制作工具进行模型标准人头的尺寸大小对齐和输出，将FBX格式转换为GLB或GLTF格式进行交付。
2. 尺寸及方向要求：
   1. 统一新建场景中设定统一尺寸单位，设定为：厘米cm，模型在三个维度上的尺寸建议控制在500单位以内。
   2. 统一坐标轴方向，因为Maya和Max的初始坐标轴有差异，所以需要统一设定：向上坐标轴为Z轴，向前坐标轴为X轴， 向右坐标轴为Y轴。（右手坐标系）
   3. 模型制作大小参照中性脸的模型（Basel Face Model）比例为参照，内眼间距为4cm，尺寸为：长20cm，宽14cm。（如左图所示）动物模型大小需将人脸包裹住。（如右图所示）

   3.模型制作规范要求：
   1. 模型面片大小建议不超过7000面；
   2. 尺寸大小为：30\*30\*30cm；
   3. 坐标轴及方向定义：坐标轴归到0，0，0；
   4. 人脸坐标系定义：为右手直角坐标系，坐标原点（如图所示）位于鼻尖后的人脸中心位置（距离鼻尖6厘米）。X方向（红色箭头）指向mesh的右侧（即使用者的左侧），Y方向（绿色箭头）指向mesh下方（即使用者下方），Z方向（蓝色箭头）指向从里向外。 （如下图所示）
