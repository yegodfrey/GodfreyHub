# Smart Cache（OpenGL版本）

#### 查询extension

使用glGetString函数查询上报的extension，如果存在GL_HUAWEI_smart_cache则说明支持该扩展。

```
const char* extensions = (const char*) glGetString(GL_EXTENSIONS);
```

#### 定义标志位

```
#define GL_TEXTURE_SMART_CACHE_TEXTURE 0x40000
```

```
#define GL_TEXTURE_SMART_CACHE_FBO 0x80000
```

#### 调用函数

使用glTexImage2D或glTexStorage2D函数来申请内存，在这两个函数的target参数中，可以位或上文定义的标志位，以表示申请的内存是texture或者FBO，并将其放入smart cache中，以提高读写速度。

```
glTexImage2D(GL_TEXTURE_2D | GL_TEXTURE_SMART_CACHE_xxx, ...);
```

```
glTexStorage2D(GL_TEXTURE_2D | GL_TEXTURE_SMART_CACHE_xxx, ...);
```
