# 骨骼动画和帧动画

CG Kit提供骨骼动画和帧动画的解析功能，支持gltf、glb格式的骨骼动画的播放、启动、暂停及停止，同时支持调整播放模式和播放速度。  

#### 加载骨骼动画

1. 基于[顶点shader模板](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/shader-0000001154736843#ZH-CN_TOPIC_0000001154736843__li52351157193620)编写骨骼动画所需的顶点shader片段（skeleton.vert）。

   ```
   #define MAX_SKELETON_JOINTS 64

   // 关节权重location必须设置为4
   layout(location=4) in vec4 inWeights;
   // 关节索引location必须设置为5
   layout(location=5) in vec4 inJointIndexes;

   layout(set=0, binding=9) uniform SkeletonUniform
   {
       mat4 jointMatrix[MAX_SKELETON_JOINTS];
   }
   skeletonUniform;

   mat4 skinMatrix = mat4(1.0);

   vec4 getWorldPosition(vec3 position)
   {
       // 计算蒙皮矩阵
       skinMatrix = inWeights.x * skeletonUniform.jointMatrix[int(inJointIndexes.x)] +
                    inWeights.y * skeletonUniform.jointMatrix[int(inJointIndexes.y)] +
                    inWeights.z * skeletonUniform.jointMatrix[int(inJointIndexes.z)] +
                    inWeights.w * skeletonUniform.jointMatrix[int(inJointIndexes.w)];
       return  moelUniform.model * skinMatrix * vec4(position, 1.0);
   }

   vec3 getNormal(vec3 normal)
   {
       return (skinMatrix * vec4(normal, 0)).xyz;
   }
   ```

2. 新建骨骼动画所需的cgmat文件（skeleton.cgmat），在[cgmat](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/cgmat-configuration-file-0000001106071566)文件的shader节点中配置[顶点shader片段](#ZH-CN_TOPIC_0000001221937935__li28339115546)。

   ```
    "shader": [
       {
           "uri": "shaders/skeleton.vert",
           "type": "SHADER_STAGE_TYPE_VERTEX"
       }
   ]
   ```

3. 通过[CreateSceneObject](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/scenemanager-0000001050421127#section13583193352910)接口创建骨骼动画根节点。

   ```
   SceneObject* gltfObject = GetSceneManager()->CreateSceneObject("models/fox/fox.gltf", "material/skeleton.cgmat");
   if (gltfObject == nullptr) {
       LOGERROR("Create gltfObject failed");
       return;
   }
   ```

4. （可选）通过[SetPosition](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/sceneobject-0000001050179052#section12491mcpsimp)，[SetScale](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/sceneobject-0000001050179052#section12580mcpsimp)和[SetRotation](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/sceneobject-0000001050179052#section12669mcpsimp)接口设置场景对象的平移、缩放、旋转。

   ```
   // 获取模型的SceneObject（如果gltf/glb文件中没有设置Mesh的名字，则会以“Mesh”+mesh字段ID命名（如“Mesh0”））
   SceneObject* fox = const_cast<SceneObject*>(GetSceneManager()->FindSceneObject(gltfObject, "fox"));
   if (fox == nullptr) {
       LOGERROR("Get fox object is nullptr");
       return;
   }
   // 设置平移、缩放、旋转
   fox->SetPosition(Vector3::ZERO);
   fox->SetScale(Vector3(0.1f, 0.1f, 0.1f));
   fox->SetRotation(Vector3(0.0f, -Math::PI, 0.0f));
   ```

5. 通过[Play](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/animationcomponent-0000001222142527#section16309mcpsimp)接口播放骨骼动画。

   ```
   // 获取动画组件
   AnimationComponent* animationComponent = gltfObject->GetComponent<AnimationComponent>();
   if (animationComponent == nullptr) {
       LOGERROR("Get animationComponent is nullptr");
       return;
   }
   // 播放指定动画（如果找不到动画名称，则默认播放文件中的第一个动画）
   animationComponent->Play("Run");
   ```

6. （可选）通过[SetPlayMode](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/animationcomponent-0000001222142527#section1991151412543)接口设置动画播放模式，通过[SetSpeed](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/animationcomponent-0000001222142527#section1266813745112)接口调整播放速度。

   ```
   // 设置播放模式（循环，乒乓，单次）
   animationComponent->SetPlayMode(ANIMATION_PLAY_MODE_ONCE);
   // 设置播放速度
   animationComponent->SetSpeed(0.5f);
   ```

<!-- -->

7. （可选）通过[Stop](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/animationcomponent-0000001222142527#section59571234134616)接口停止动画的播放。

   ```
   animationComponent->Stop();
   ```

#### 加载帧动画

1. 通过[CreateSceneObject](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/scenemanager-0000001050421127#section13583193352910)接口创建帧动画根节点。

   ```
   // 加载gltf/glb文件
   SceneObject* gltfObject = GetSceneManager()->CreateSceneObject("models/gltf/BoxAnimated.glb");
   if (gltfObject == nullptr) {
       LOGERROR("Create gltfObject failed");
       return;
   }
   ```

2. （可选）通过[SetPosition](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/sceneobject-0000001050179052#section12491mcpsimp)、[SetScale](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/sceneobject-0000001050179052#section12580mcpsimp)和[SetRotation](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/sceneobject-0000001050179052#section12669mcpsimp)接口设置场景对象的平移、缩放、旋转。

   ```
   // 获取模型的SceneObject（如果gltf/glb文件中没有设置Mesh的名字，则会以“Mesh”+mesh字段ID命名（如“Mesh0”））
   SceneObject* outerBox = const_cast<SceneObject*>(GetSceneManager()->FindSceneObject(gltfObject, "outer_box"));
   if (outerBox == nullptr) {
       LOGERROR("Get outer box object is nullptr");
       return;
   }
   // 设置平移、缩放、旋转
   outerBox->SetPosition(Vector3::ZERO);
   outerBox->SetScale(Vector3::ONE);
   outerBox->SetRotation(Vector3::ZERO);

   SceneObject* innerbox = const_cast<SceneObject*>(GetSceneManager()->FindSceneObject(gltfObject, "inner_box"));
   if (innerbox == nullptr) {
       LOGERROR("Get inner box object is nullptr");
       return;
   }
   // 设置平移、缩放、旋转
   innerbox->SetPosition(Vector3::ZERO);
   innerbox->SetScale(Vector3::ONE);
   innerbox->SetRotation(Vector3::ZERO);
   ```

<!-- -->

3. 通过[Play](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/animationcomponent-0000001222142527#section16309mcpsimp)接口播放帧动画。

   ```
   // 获取动画组件
   AnimationComponent* animationComponent = gltfObject->GetComponent<AnimationComponent>();
   if (animationComponent == nullptr) {
       LOGERROR("Get animationComponent is nullptr");
       return;
   }
   // 播放指定动画（如果找不到动画名称，则默认播放文件中的第一个动画）
   animationComponent->Play(StringUtils::EMPTY);
   ```

<!-- -->

4. （可选）通过[SetPlayMode](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/animationcomponent-0000001222142527#section1991151412543)接口设置动画播放模式，通过[SetSpeed](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/animationcomponent-0000001222142527#section1266813745112)接口调整播放速度。

   ```
   // 设置播放模式（循环，乒乓，单次）
   animationComponent->SetPlayMode(ANIMATION_PLAY_MODE_ONCE);
   // 设置播放速度
   animationComponent->SetSpeed(0.5f);
   ```

<!-- -->

5. （可选）通过[Stop](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/animationcomponent-0000001222142527#section59571234134616)接口停止动画的播放。

   ```
   animationComponent->Stop();
   ```
