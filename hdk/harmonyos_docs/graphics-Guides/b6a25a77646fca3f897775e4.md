# 调用体积云API

体积云插件包含两部分功能：离线烘焙与体积云渲染。

* 离线烘焙是指在PC端根据用户提供的三维模型进行云的形态定制。
* 体积云渲染是根据用户确定的参数在PC端或Android平台提供云的渲染结果。

## 头文件依赖

在项目中需要三个头文件。

* VolumeCloudRenderAP.h：定义用于体积云渲染的接口。
* VolumeRenderParas.h：定义插件调用中的结构体。
* BakeShapeAPI.h：定义用于离线烘焙的接口以及结构体。

## 离线烘焙

1. 加载动态库文件。PC端（Windows 10）链接RenderingVolumeCloud.dll动态库。
2. 初始化结构体参数[BakeData](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/bakedata-0000001077667166)。

   ```screen
   struct BakeData{
       float* vDatas = nullptr;
       int vDatasLength = 0;
       float* fDatas = nullptr;
       int fDatasLength = 0;
       float* minBox = nullptr;
       float* maxBox = nullptr;
       int* volumeSize = nullptr;
   }
   ```

3. 创建[BakeShapeAPI](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/bakeshapeapi-0000001077661716)对象。

   ```screen
   BakeShapeAPI* CreateBakeShapeAPI();
   ```

4. 调用离线烘焙功能[BakeMultiMesh](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/bakeshapeapi-0000001077661716#section13938259114619)。

   ```screen
   bool BakeMultiMesh(const BakeData data, char savePath[]);
   ```

## 体积云渲染

1. 加载动态库文件。
   * PC端（Windows 10）链接RenderingVolumeCloud.dll动态库。
   * 移动端（Android）链接libRenderingVolumeCloud.so动态库。


2. 创建[VolumeCloudRenderAPI](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/renderapi-0000001077502104)对象。

   ```screen
   VolumeCloudRenderAPI* render = CreateVolumeCloudRenderAPI(GraphicAPI apiType)
   ```

   其中[GraphicAPI](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/graphicapi-0000001093285693)为枚举变量，用来定义使用的图形接口。

   ```screen
   typedef enum GraphicAPI
   {
       // Android平台使用OpenGLES 3.2
       GraphicAPI_OpenGLES30 = 0,
       // Windows平台使用OpenGL 4.0
       GraphicAPI_OpenGL = 1, 
   } GraphicAPI;
   ```


3. 初始化参数[VolumeRenderParas](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/volumerenderparas-0000001077507556)，可设置渲染过程中的光照、风速、云的形状以及相机等参数。

   ```screen
   struct VolumeRenderParas {
       // 步长数
       int rayMarchSteps[2] = { 0 };
       // 下采样策略
       int downSample = 0;
       // 云的形状
       float cloudBoxMinCoordinate[3] = { 0 };
       float cloudSize[3] = { 0 };
       float shapeTiling[3] = { 0 };
       // 云的细节
       float noiseTiling = 0;
       float noiseIntensity = 0;
       // 光照
       float density = 0;
       float sigmaExtinction = 0;
       float sigmaScattering = 0;
       float mainLightColor[3] = { 0 };
       float ambientLightColor[3] = { 0 };
       float mainLightIntensity = 0;
       float ambientLightIntensity = 0;
       float silverSpread = 0;
       float shadowStepSize = 0;
       // 风速
       float detailWindStrength[3] = { 0 };
       float shapeWindStrength[3] = { 0 };
       // 相机参数
       float timeSinceLevelLoad = 0;
       float worldSpaceLightDirection[3] = { 0 };
       float worldSpaceCameraPosition[3] = { 0 };
       float cameraClippingPlanesNear = 0;
       float cameraClippingPlanesFar = 0;
       float camera2World[16] = { 0 };         
       float world2Camera[16] = { 0 };         
       float cameraProjection[16] = { 0 };     
       float cameraInvProjection[16] = { 0 };  
       char noisePath[128] = { 0 };
       char shapePath[128] = { 0 };
   };
   ```

4. 渲染体积云。

   ```cpp
   // 初始化环境https://developer.huawei.com/consumer/cn/doc/development/graphics-References/renderapi-0000001077502104#section788322516435
   render->CreateResources();
   do{
      // 传递渲染参数https://developer.huawei.com/consumer/cn/doc/development/graphics-References/renderapi-0000001077502104#section1124213454448，其中参数paras为VolumeRenderParas结构体变量
      bool ret = render->SetRenderCloudParas(paras);
      if(!ret){
         return;
      }
      // 获取渲染纹理GLuint textureHandle以及深度纹理GLuint depthTexHandle,由开发者自行获取
      ...
      // 获取渲染帧的结果https://developer.huawei.com/consumer/cn/doc/development/graphics-References/renderapi-0000001077502104#section1350194774313
      render->RenderCloudFrameTexture((void*)textureHandle, 
                                     (void*)depthTexHandle, 
                                     textureWidth,
                                     textureHeight);
   // 在对连续帧进行渲染时，需要进行循环调用，直至渲染任务完成  
   }while(...) 
   // 释放资源和数据https://developer.huawei.com/consumer/cn/doc/development/graphics-References/renderapi-0000001077502104#section543194314457
   render->ReleaseData();
   ```
