# 手柄适配

1. 场景中显示虚拟手柄，有以下两种方式：
   1. 将HuaweiVRController内容/BluePrints/HVRControllerActor拖入游戏关卡中，设置虚拟手柄的位置、大小，即可在游戏场景中显示虚拟手柄。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220519145809.24753162343485236928786242570822:50530518075906:2800:04B563BE7A9672C8D7686EBE1D0DF6E40B4FE2F588ED6910F7C637AE2560916D.png?needInitFileName=true?needInitFileName=true "点击放大")

   2. 开发者可以参考HVRControllerActor，自行创建蓝图，添加手柄模型、获取手柄姿态：
      1. HuaweiVRController内容/ControllerModel中HVRMotionController为SDK自带手柄模型，开发者也可以自定义手柄模型。
      2. 添加组件：MotionControllerComponent为父物体，命名为HVRMotionController，添加StaticMeshComponent为HVRMotionController的子物体，命名为HVRController。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220519145809.13346038843484635894715226351549:50530518075906:2800:10A5CE5CEB08F33F94962725F7DF08CC17D0205EAA6C389B051E66AD8E1D2116.png?needInitFileName=true?needInitFileName=true "点击放大")

2. 为HVRController添加StaticMesh及Materials。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220519145809.51002761117752119881075127819246:50530518075906:2800:21F2E6C45EA40B639F6F89B619E02F460DCB349864A325433F118B1F268F7BAC.png?needInitFileName=true?needInitFileName=true "点击放大")

3. 为 HVRController 设置初始旋转值为（-90.0, 0.0, 90.0），并通过GetHVRControllerOrientation()蓝图接口，获取手柄旋转姿态，赋值给HVRMotionController。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220519145809.02048798712789730673798345490969:50530518075906:2800:9E8C0A940F98470E444CDB188FC169E11100FF256E36F979B58C908107D08FB3.png?needInitFileName=true?needInitFileName=true "点击放大")

4. 选中 HVRControllerActor，设置"细节 \> Input"下的Auto Receive Input 选为 Player0。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220519145810.84322318018621234713417706631755:50530518075906:2800:2EDA405573B5462228B4D0A431B9F849C5352FB468A96A8CB830502CA576EA1D.png?needInitFileName=true?needInitFileName=true "点击放大")
5. 手柄按键与Unreal中运动控制器按键接口的映射关系（详见HuaweiVRController.cpp）  

   |手柄按键名称|Unreal插件蓝图接口|
   |:--------------------|:--------------------------------------------------------------------------------------------------------|
   |Home按键|FGamepadKeyNames::SpecialRight FGamepadKeyNames::SpecialLeft|
   |返回按键|FGamepadKeyNames::MotionController_Right_Shoulder FGamepadKeyNames::MotionController_Left_Shoulder|
   |扳机按键|FGamepadKeyNames::MotionController_Right_Trigger FGamepadKeyNames::MotionController_Left_Trigger|
   |触摸板按键|FGamepadKeyNames::MotionController_Right_FaceButton1 FGamepadKeyNames::MotionController_Left_FaceButton1|
   |触摸板左滑/摇杆左推|FGamepadKeyNames::MotionController_Right_FaceButton2 FGamepadKeyNames::MotionController_Left_FaceButton2|
   |触摸板右滑/摇杆右推|FGamepadKeyNames::MotionController_Right_FaceButton3 FGamepadKeyNames::MotionController_Left_FaceButton3|
   |触摸板上滑/摇杆上推|FGamepadKeyNames::MotionController_Right_FaceButton4 FGamepadKeyNames::MotionController_Left_FaceButton4|
   |触摸板下滑/摇杆下推|FGamepadKeyNames::MotionController_Right_FaceButton5 FGamepadKeyNames::MotionController_Left_FaceButton5|
   |触摸板轻触|FGamepadKeyNames::MotionController_Right_FaceButton6 FGamepadKeyNames::MotionController_Left_FaceButton6|
   |触摸板持续触摸|FGamepadKeyNames::MotionController_Right_FaceButton7 FGamepadKeyNames::MotionController_Left_FaceButton7|
   |扳机键 \[6DoF手柄\]|FGamepadKeyNames::MotionController_Right_Trigger FGamepadKeyNames::MotionController_ Left_Trigger|
   |侧握键 \[6DoF手柄\]|FGamepadKeyNames::MotionController_Right_Grip1 FGamepadKeyNames::MotionController_ Left_Grip1|
   |A/X键 \[6DoF手柄\]|FGamepadKeyNames::MotionController_Right_FaceButton1 FGamepadKeyNames::MotionController_ Left_FaceButton1|
   |B/Y键 \[6DoF手柄\]|FGamepadKeyNames::MotionController_Right_Shoulder FGamepadKeyNames::MotionController_ Left_Shoulder|
   |摇杆键按下 \[6DoF手柄\]|FGamepadKeyNames::MotionController_Right_Thumbstick FGamepadKeyNames::MotionController_ Left_Thumbstick|
   |Home/Menu键 \[6DoF手柄\]|FGamepadKeyNames::SpecialRight FGamepadKeyNames::Special Left|

   开发者只需在蓝图中查找并调用以上对应接口，就可以实现手柄按键的响应事件。
