# 自定义渲染顺序

CG Kit提供让用户自定义渲染顺序的功能，使用[SetRenderingSortType](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/cgkitinterface-0000001050297126#section153122506265)接口开启此功能，并通过[SetSortId](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/sceneobject-0000001050179052#section648016214175)接口给SceneObject设置排序ID。图形渲染顺序会依据用户自定义的排序ID进行渲染，ID值较小的会先进行渲染，示例代码如下。

```
// 开启自定义渲染排序
gCGKitInterface.SetRenderingSortType(RENDERING_SORT_TYPE_ID);

// 创建SceneObject并设置sortId
SceneObject* sceneObject1 = gSceneManager.CreateSceneObject();
sceneObject1->SetSortId(1);
SceneObject* sceneObject2 = gSceneManager.CreateSceneObject();
sceneObject2->SetSortId(2);
```
