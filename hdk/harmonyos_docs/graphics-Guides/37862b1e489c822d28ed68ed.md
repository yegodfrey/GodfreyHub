# （可选）物理引擎

原子化接口中支持添加物理引擎组件，用以仿真模拟物体的运动约束和碰撞的物理效果。加载模型素材后，您可按需添加物理引擎的刚体、碰撞体、约束等组件，对物体的运动状态加以控制。本小节将介绍如何使用物理引擎组件。

## 概述

物理引擎能够让场景中的物体模拟现实场景中的物理效果进行运动，比如自由落体、碰撞等。物理引擎中主要提供了以下组件：

* 刚体（[RigidBody](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-rigidbody-0000001096382446)）：刚性物体，不会发生形变。一个物体可以通过一个或多个刚体模拟。
* 碰撞体（[Collider](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-collider-0000001096542434)）：指定刚体的形状，用于实现刚体间的碰撞效果，需要与刚体结合使用。碰撞体形状有长方体（[BoxShape](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-boxshape-0000001096062624)）、球体（[SphereShape](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-sphereshape-0000001143302403)）、圆锥体（[ConeShape](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-coneshape-0000001096222446)）、胶囊体（[CapsuleShape](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-capsuleshape-0000001142982443)）、圆柱体（[CylinderShape](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-cylindershape-0000001142862485)）等。
* 约束（[Constraint](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-constraint-0000001096382448)）：限制刚体运动，让其按照特定的限制条件运动。常用约束有：固定约束（[FixedConstraint](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-fixedconstraint-0000001096542436)）、点对点约束（[Point2PointConstraint](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-point2pointconstraint-0000001143182401)）、铰链约束（[HingeConstraint](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-hingeconstraint-0000001096062626)）、通用6自由度约束（[Generic6DOFConstraint](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-generic6dofconstraint-0000001096222448)）等。

## 使用场景

本小节将描述3个常见的物理引擎使用场景，在下文的开发步骤中将对所述场景使用物理引擎进行模拟。

### 场景1：小球下落撞击地面

1. 加载小球素材模型，加载地面素材模型。
2. 创建小球、地面的碰撞体，小球碰撞体的形状指定为球体，地面碰撞体的形状指定为长方体。设置碰撞体的大小使碰撞体与素材大小尽量一致。
3. 创建小球刚体，设置刚体的质量、恢复系数（模拟反弹效果）、线性阻尼和转动阻尼（模拟空气阻力）。创建地面刚体，设置刚体质量为0。

刚体间的碰撞需要设置碰撞的group和mask属性，默认值都是1，可通过[RigidBody](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-rigidbody-0000001096382446)的[setGroup](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-rigidbody-0000001096382446#section139211536195911)与[setMask](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-rigidbody-0000001096382446#section234816918017)进行设置。假设两个物体分别为A和B，则物体A与物体B之间发生碰撞条件为(A.group && B.mask) && (B.group && A.mask)为真。

刚体质量为0表示该刚体是静态刚体，静态刚体不会移动；刚体质量>0表示该刚体是动态刚体，动态刚体会受外力影响运动。如果指定刚体类型为Kinematic，表示刚体是运动学刚体，可通过[setKinematic](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-rigidbody-0000001096382446#section38111711215)接口进行设置。刚体位置不会被物理引擎改变，但可以通过改变素材位置的方式改变刚体位置。

### 场景2：两个小球在地面上碰撞

1. 加载小球素材模型，加载地面素材模型。调整小球位置，使小球刚好静止在地面上。
2. 创建两个小球碰撞体与地面碰撞体，设置碰撞体大小，尽量与渲染的素材大小一致。
3. 创建小球刚体A与刚体B，设置质量大于0。创建小球刚体A设置初始速度，速度方向与小球A指向小球B方向一致。创建地面刚体，设置刚体质量为0。

### 场景3：两个刚体小球通过通用6自由度约束连接

1. 加载两个小球素材模型。
2. 创建两个小球碰撞体，设置碰撞体的形状为球体，设置碰撞体大小与素材大小一致。
3. 创建两个小球刚体，设置质量大于0。
4. 添加一个通用6自由度约束，设置约束的两个节点nodeA和nodeB指定需要约束的刚体。设置约束点相对于刚体的位置，需要指定position和rotation信息。设置约束范围：约束点可以移动或转动的最小与最大值。

通用6自由度约束（[Generic6DOFConstraint](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-generic6dofconstraint-0000001096222448)）可以绕x、y、z三个轴移动或转动。如果单个自由度上的限制条件的最小值小于其最大值，约束点会在该限制条件内运动；如果最小值大于等于最大值，该自由度的约束条件不生效。每个节点只能添加一种类型的约束。如果需要在一个刚体上添加多个约束，需要注意使用另外一个刚体节点添加约束。

## 开发步骤

本小节将介绍使用物理引擎组件，仿真模拟物体的运动约束和碰撞物理效果的大体开发步骤，完整示例代码请参考[原子化接口物理引擎示例代码](https://developer.huawei.com/consumer/cn/doc/graphics-Examples/physics-engine-demo-0000001147346914)。

### 场景1：小球下落撞击地面

素材模型加载完成后，进行如下步骤：

1. 创建小球和地面的碰撞体。

   ```screen
   // 创建小球碰撞体，将其设置为球体、半径为1.0。
   sphereNode.addComponent(Collider.descriptor()).createSphereShape().setRadius(1.0f);
   // 创建地面碰撞体，将其设置为长方体、长高宽分别为20、0.1、20。
   groundNode.addComponent(Collider.descriptor()).createBoxShape().setExtent(new Vector3(20, 0.1f, 20));
   ```

2. 创建小球刚体，并设置属性。

   ```screen
   sphereNode.addComponent(RigidBody.descriptor())
       // 设置刚体质量，质量大于0表示是dynamic类型。
       .setMass(1.0f)
       // 设置恢复系数。
       .setRestitution(0.6f)
       // 设置线性运动的阻尼。
       .setLinearDamping(0.05f)
       // 设置转动的阻尼。
       .setAngularDamping(0.05f)
       // 设置碰撞组。
       .setGroup((short) 1)
       // 设置碰撞掩码。
       .setMask((short) 1)
       // 设置摩擦系数。
       .setFriction(0.7f);
   ```

3. 创建地面刚体，并设置其属性。

   ```screen
   groundNode.addComponent(RigidBody.descriptor())
       // 设置刚体质量，质量为0表示是static类型。
       .setMass(0.f)
       // 设置恢复系数。
       .setRestitution(0.9f)
       // 设置碰撞组。
       .setGroup((short) 1)
       // 设置碰撞掩码。
       .setMask((short) 1);
   ```

### 场景2：两个小球在地面上碰撞

与场景1类似，需要在渲染场景中分别添加小球和地面的碰撞体与刚体。素材模型加载完成后，进行如下步骤：

1. 创建两个小球碰撞体。

   ```screen
   // 创建两个小球碰撞体，将其设置为球体、半径为1.0。
   sphereNode1.addComponent(Collider.descriptor()).createSphereShape().setRadius(1.0f);
   sphereNode2.addComponent(Collider.descriptor()).createSphereShape().setRadius(1.0f);
   ```

2. 创建两个小球刚体，并设置属性。

   ```screen
   sphereNode1.addComponent(RigidBody.descriptor())
       // 设置刚体质量，质量大于0表示是dynamic类型。
       .setMass(1.0f)
       // 设置恢复系数。
       .setRestitution(0.6f)
       // 设置线性运动的阻尼。
       .setLinearDamping(0.05f)
       // 设置转动的阻尼。
       .setAngularDamping(0.05f)
       // 设置碰撞组。
       .setGroup((short) 1)
       // 设置碰撞掩码。
       .setMask((short) 1)
       // 设置刚体初始速度。
       .setLinearVelocity(new Vector3(10, 0, 0));

   sphereNode2.addComponent(RigidBody.descriptor())
       // 设置刚体质量，质量大于0表示是dynamic类型。
       .setMass(1.0f)
       // 设置恢复系数。
       .setRestitution(0.6f)
       // 设置线性运动的阻尼。
       .setLinearDamping(0.05f)
       // 设置转动的阻尼。
       .setAngularDamping(0.05f)
       // 设置碰撞组。
       .setGroup((short) 1)
       // 设置碰撞掩码。
       .setMask((short) 1)
       // 设置刚体速度。
       .setLinearVelocity(new Vector3(-10, 0, 0));
   ```

3. 创建地面碰撞体与刚体，与[场景1](#section11153934316)中地面碰撞体与刚体创建方法相同。

### 场景3：两个刚体小球通过通用6自由度约束连接

素材模型加载完成后，进行如下步骤：

1. 创建两个小球碰撞体。

   ```screen
   // 创建两个小球碰撞体，将其设置为球体、半径为1.0。
   sphereNode1.addComponent(Collider.descriptor()).createSphereShape().setRadius(1.0f);
   sphereNode2.addComponent(Collider.descriptor()).createSphereShape().setRadius(1.0f);
   ```

2. 创建两个小球刚体，并设置属性。

   ```screen
   sphereNode1.addComponent(RigidBody.descriptor())
       // 设置刚体质量，质量大于0表示是dynamic类型。
       .setMass(1.0f)
       // 设置恢复系数。
       .setRestitution(0.6f)
       // 设置线性运动的阻尼。
       .setLinearDamping(0.05f)
       // 设置转动的阻尼。
       .setAngularDamping(0.05f)
       // 设置碰撞组。
       .setGroup((short) 1)
       // 设置碰撞掩码。
       .setMask((short) 1);

   sphereNode2.addComponent(RigidBody.descriptor())
       // 设置刚体质量，质量大于0表示是dynamic类型。
       .setMass(1.0f)
       // 设置恢复系数。
       .setRestitution(0.6f)
       // 设置线性运动的阻尼。
       .setLinearDamping(0.05f)
       // 设置转动的阻尼。
       .setAngularDamping(0.05f)
       // 设置碰撞组。
       .setGroup((short) 1)
       // 设置碰撞掩码。
       .setMask((short) 1);
   ```

3. 添加一个通用6自由度约束，并设置其属性。

   ```screen
   Generic6DOFConstraint dof = sphereNode1.addComponent(Generic6DOFConstraint.descriptor());
   // 设置约束的物体节点A。
   dof.setNodeA(sphereNode1);
   // 设置约束物体节点B。
   dof.setNodeB(sphereNode2);
   // 设置约束点相对刚体A的位置。
   dof.setFramePositionInA(new Vector3(0, 0, 0))
       // 约束点相对刚体A的rotation信息。
       .setFrameRotationInA(new Quaternion(0.5f, 0.5f, 0.5f, 0.51f))
       // 约束点相对刚体B的位置。
       .setFramePositionInB(new Vector3(0, 1, 0))
       // 约束点相对刚体B的rotation信息。
       .setFrameRotationInB(new Quaternion(new Vector3(0, 1, 0), 0.f))
       // 线性移动约束下限。
       .setLinearLowerLimit(new Vector3(-1, 1, 0))
       // 线性移动约束上限。
       .setLinearUpperLimit(new Vector3(-1, 1, 0))
       // 转动约束下限。
       .setAngularLowerLimit(new Vector3(0, 0, -0.5f))
       // 转动约束上限。
       .setAngularUpperLimit(new Vector3(0, 0, 0.5f));
   ```
