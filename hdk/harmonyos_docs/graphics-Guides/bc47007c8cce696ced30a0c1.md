# 骨骼绑定

1. 骨骼绑定

动画师首先需绑定动物模型的头部，左眼，右眼，脖子和胸的骨骼节点。（如下图所示）

>
> 骨骼的首字母必须大写。

由于舌头与头为一体，注意删除Tongue舌头的那个骨节点，将头部与舌头合并的模型蒙皮至Head骨节点上。
