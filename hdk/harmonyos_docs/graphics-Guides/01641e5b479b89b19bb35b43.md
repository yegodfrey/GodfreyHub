# Pre-rotation（Vulkan版本）

## 查询extension

使用vkEnumerateDeviceExtensionProperties函数查询上报的extension，如果存在VK_ HUAWEI _prerotation则说明支持该扩展。

```screen
vkEnumerateDeviceExtensionProperties(physicalDevice, nullptr, &extCount, &extensions.front());
```

## 启用Pre-rotation

在vkCreateDevice时将VK_ HUAWEI _prerotation加入扩展列表。VkDeviceCreateInfo.ppEnabledExtensionNames在原来的基础上增加一个新的扩展VK_HUAWEI _prerotation。

```screen
supportedExtensions.push_back(ext.extensionName);
```
