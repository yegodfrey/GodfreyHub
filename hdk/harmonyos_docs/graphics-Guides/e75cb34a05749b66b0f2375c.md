# SceneView

#### 开发步骤

图形引擎服务通过[SceneView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-sceneview-0000001050304388)提供了自适应场景的渲染能力，只需要简单的接口调用，就能完成复杂3D场景的渲染。

[SceneView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-sceneview-0000001050304388)继承自Android SurfaceView，并重写了其中surfaceCreated、surfaceChanged、surfaceDestroyed、onTouchEvent、onDraw等方法，方便调用。本节将通过创建一个继承自[SceneView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-sceneview-0000001050304388)的SampleView，实现加载3D素材并渲染的功能。完整示例代码请参见[调用示例](#section85051469917)。

1. 创建一个继承自[SceneView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-sceneview-0000001050304388)的SampleView。

   <br />

   ```
   public class SampleView extends SceneView {
       // 用于new方式使用。
       public SampleView(Context context) {
           super(context);
       }
       // 用于Layout xml方式使用。
       public SampleView(Context context, AttributeSet attributeSet) {
           super(context, attributeSet);
       }
   }
   ```

   <br />

2. 重写surfaceCreated方法，并调用[SceneView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-sceneview-0000001050304388)的[surfaceCreated](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-sceneview-0000001050304388#section1730112063815)方法完成[SceneView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-sceneview-0000001050304388)的创建与初始化。

   <br />

   ```
   @Override
   public void surfaceCreated(SurfaceHolder holder) {
       super.surfaceCreated(holder);
   }
   ```

   <br />

3. 在[surfaceCreated](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-sceneview-0000001050304388#section1730112063815)方法中，调用[loadScene](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-sceneview-0000001050304388#section71677110133)加载渲染素材。

   <br />

   ```
   loadScene("SceneView/scene.gltf");
   ```

   <br />

4. 在[surfaceCreated](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-sceneview-0000001050304388#section1730112063815)方法中，调用[loadSkyBox](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-sceneview-0000001050304388#section04441717121817)加载天空盒纹理贴图素材。

   <br />

   ```
   loadSkyBox("SceneView/skyboxTexture.dds");
   ```

   <br />

5. 在[surfaceCreated](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-sceneview-0000001050304388#section1730112063815)方法中，调用[loadSpecularEnvTexture](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-sceneview-0000001050304388#section191351735161913)加载环境光反射贴图素材。

   <br />

   ```
   loadSpecularEnvTexture("SceneView/specularEnvTexture.dds");
   ```

   <br />

6. 在[surfaceCreated](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-sceneview-0000001050304388#section1730112063815)方法中，调用[loadDiffuseEnvTexture](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-sceneview-0000001050304388#section29339329370)加载环境光漫反射贴图素材。

   <br />

   ```
   loadDiffuseEnvTexture("SceneView/diffuseEnvTexture.dds");
   ```

   <br />

7. （可选）如需清除当前场景中的素材，可调用[clearScene](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-sceneview-0000001050304388#section6907177151711)方法清除当前场景。

   <br />

   ```
   clearScene();
   ```

9. 新建一个activity，在其onCreate方法中调用setContentView方法。setContentView方法传入一个新创建的SampleView。

   <br />

   ```
   public class SampleActivity extends Activity {
       @Override
       protected void onCreate(Bundle savedInstanceState) {
           super.onCreate(savedInstanceState);
           setContentView(new SampleView(this));
       }
   }
   ```

   <br />

#### 调用示例

```
public class SampleView extends SceneView {
    // 用于new方式使用。
    public SampleView(Context context) {
        super(context);
    }
    // 用于Layout xml方式使用。
    public SampleView(Context context, AttributeSet attributeSet) {
        super(context, attributeSet);
    }

    @Override
    public void surfaceCreated(SurfaceHolder holder) {
        super.surfaceCreated(holder);
        // 加载目标场景模型 (从assets读取文件)。
        loadScene("SceneView/scene.gltf");
        // 加载天空盒纹理 (从assets读取文件)。
        loadSkyBox("SceneView/skyboxTexture.dds");
        // 加载镜面反射纹理 (从assets读取文件)。
        loadSpecularEnvTexture("SceneView/specularEnvTexture.dds");
        // 加载漫反射纹理 (从assets读取文件)。
        loadDiffuseEnvTexture("SceneView/diffuseEnvTexture.dds");
    }

    @Override
    public void surfaceChanged(SurfaceHolder surfaceHolder, int format, int width, int height) {
        super.surfaceChanged(surfaceHolder, format, width, height);
    }

    @Override
    public void surfaceDestroyed(SurfaceHolder surfaceHolder) {
        super.surfaceDestroyed(surfaceHolder);
    }

    @Override
    public boolean onTouchEvent(MotionEvent motionEvent) {
        return super.onTouchEvent(motionEvent);
    }

    @Override
    public void onDraw(Canvas canvas) {
        super.onDraw(canvas);
    }
}
```
