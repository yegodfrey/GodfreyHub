# 概述

图形引擎服务针对不同使用需求，提供了不同的SDK：

* **原子化接口SDK**：提供高自由度的图形引擎接口，您可以根据需要打造各种各样的图形应用，并对场景、节点、组件进行更精细化的控制。
* **2D流体模拟接口SDK**：提供流体模拟接口，使用该接口可以完成创建流体粒子，模拟流体晃动的物理效果。
* **场景化接口SDK** ：提供自由度较低但简单易用的接口，您仅需用少量的代码即可完成特定场景下的应用开发。

  目前场景化接口提供了针对模型展示场景的[SceneView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-sceneview-0000001050304388)、虚拟现实放置场景的[ARView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-arview-0000001051923459)和面部AR场景的[FaceView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-faceview-0000001052804698)。

另外，图形引擎服务还提供面向C++的离线简模插件，能够快速精简模型，减少性能开销；高效遮挡剔除插件，用于查询场景中模型的遮挡关系；实时光追插件，能够提供实时构建求交结果，提升游戏等场景的光影真实感；动态漫反射全局光照插件，能够实时响应场景变化，提供更加自然的光照效果。

下面章节将分别介绍原子化接口、2D流体模拟接口、场景化接口、离线简模插件、实时光追插件、高效遮挡剔除插件、动态漫反射全局光照插件的使用方法。
