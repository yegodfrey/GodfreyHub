# AR展示场景

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230602145209.31725382671381452302375126545843:50001231000000:2800:2F36AB74E3B0A29F055341E059DC07BFF4CFA75C218693897EADE02E21A7F36A.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
XRKit当前支持GLB和GLTF格式的模型文件。

ArSceneView（即AR展示场景）有两种模式，3D模式与AR模式。

* 3D模式提供自定义3D背景与虚拟模型展示的功能，导入的模型将会自适应缩放后完全显示在屏幕中。
* AR模式导入的模型将会按照1:1的比例显示在AR场景中，因此您可以按需设计模型大小。
