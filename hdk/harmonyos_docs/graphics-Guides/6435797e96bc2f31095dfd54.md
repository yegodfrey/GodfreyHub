# 渲染图形

## 创建运行实例对象

1. Main.cpp是演示Demo的入口类**。**
2. 实例化MainApplication，该对象继承BaseApplication对象。
3. 启动渲染主流程MainLoop()。

   ```screen
   void android_main(android_app* state)
   {
       // 实例化演示Demo主界面
       auto app = CreateMainApplication(); 
       if (app == nullptr) {
           return;
       }
       // 启动平台渲染
       app->Start(reinterpret_cast<void*>(state)); 
       // 启动渲染主流程
       app->MainLoop();
       CG_SAFE_DELETE(app);
   }
   ```

4. （可选）通过[Start](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/baseapplication-0000001050197736#section31744873318)接口开启日志Log。

   开启日志[Log](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/log-0000001051053938)用以打印日志信息。由CGKIT_LOG宏控制，须在文件开始定义CGKIT_LOG，然后在[Start](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/baseapplication-0000001050197736#section31744873318)接口中设置日志的级别。日志的级别请参见[LogType](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/logtype-0000001050974007)。

   ```screen
   void MainApplication::Start(void* param)
   {
       // 这里设置日志等级为LOG_VERBOSE，用以覆盖cgkit默认的日志级别
       Log::SetLogLevel(LOG_VERBOSE);
       BaseApplication::Start(param);
       SetSceneManagerType(SceneManagerType::SCENE_MANAGER_TYPE_QUADTREE);
   }
   ```

> 说明
>
> [SetSceneManagerType](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/baseapplication-0000001050197736#section1169542463412)必需放在[Start](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/baseapplication-0000001050197736#section31744873318)函数之后，[Initialize](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/baseapplication-0000001050197736#section10446181003612)函数之前。其类型分为SCENE_MANAGER_TYPE_QUADTREE和SCENE_MANAGER_TYPE_COMMON两种，默认为SCENE_MANAGER_TYPE_QUADTREE。

1. 创建相机。

   创建Camera实例并设置各项参数（打印[Log](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/log-0000001051053938)以输出调试信息）。
   1. 实例化Camera场景对象cameraObj，在此基础上获取Camera对象指针mainCamera。
   2. 设置mainCamera参数（投射角度和类型、目标位置、视点位置等）。
   3. 把实例mainCamera加入到全局的场景控制实例gSceneManager中。
   4. 如果实例化失败，则对已实例化的对象进行安全删除。
   5. （可选）通过[SetMultiSampleInfo](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/camera-0000001050179056#section4239186554)接口开启MSAA效果。

      如果MSAA（Multisample anti-aliasing，多重采样抗锯齿）和Sample Shading没有开启成功，请通过Log日志分析。MSAA的参数配置请参见[MultiSampleInfo](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/multisampleinfo-0000001255843830)。 说明
      > * MSAA及Sample Shading设置后会进行如下校验。
      >   * 当设备不支持所设置的MSAA采样数时，渲染框架会自动关闭MSAA和Sample Shading效果。
      >   * 当用户没有开启MSAA或设备不支持Sample Shading时，渲染框架会自动关闭Sample Shading效果。
      >   * 当前相机是使用的非前向渲染流程，渲染框架会自动关闭MSAA和Sample Shading效果。
      > * Sample Shading是对多边形内部着色进行多重采样，其最小着色率的取值为[0.0f, 1.0f]，其值越接近1，图像越平滑。
      > * CG Kit 6.8.0版本前需要在Initiliaze前配置MSAA，从6.8.0版本起MSAA效果支持在每帧Update中动态开关。
   6. （可选）通过[SetClearColor](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/camera-0000001050179056#section1940202210554)接口设置相机清屏色。

   如果需要开启多相机的场景，则需要根据相机个数创建相应数量的SceneObject，然后分别对各个相机的参数进行设置，其中主相机只有一个，需要通过[SetMainCamera](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/camera-0000001050179056#section1834663341516)接口进行设置，子相机最多设置2个。

   ```screen
   // 初始化场景
   // 添加相机，设置默认模型，设置天空盒，添加平行光和点光源
   void MainApplication::InitScene()
   {
       // 设置线程数，默认为手机核数的一半减一
       SetThreadCount(4);
       // 打开多线程渲染开关，默认为false不启动
       SetMultiThreadRendering(true);

       LOGINFO("MainApplication InitScene.");
       BaseApplication::InitScene();
       
       // 设置相机
       LOGINFO("Enter init main camera.");

       // 添加相机
       // 相机是SceneObject类型，需先创建一个SceneObject
       SceneObject* cameraObj = CG_NEW SceneObject(nullptr);
       if (cameraObj == nullptr) {
           LOGERROR("Failed to create camera object.");
           return;
       }

       // 在该SceneObject对象上添加Camera组件，得到Camera对象
       Camera* mainCamera = cameraObj->AddComponent<Camera>();
       if (mainCamera == nullptr) {
           CG_SAFE_DELETE(cameraObj);
           LOGERROR("Failed to create main camera.");
           return;
       }

       // 设置相机有关参数
       const f32 FOV = 60.f;
       const f32 NEAR = 0.1f;
       const f32 FAR = 500.0f;
       const Vector3 EYE_POSITION(0.0f, 0.0f, 0.0f);

       // 相机位置初始化为原点
       cameraObj->SetPosition(EYE_POSITION);

       // 相机类型初始化为透视投影类型，与人眼观看近大远小效果一致
       mainCamera->SetProjectionType(ProjectionType::PROJECTION_TYPE_PERSPECTIVE);

       // 设置透视投影的参数，包括FOV，屏幕宽高比以及近平面和远平面
       mainCamera->SetPerspective(FOV, GetAspectRatio(), NEAR, FAR);

       // 设置相机视口，默认为全屏显示
       mainCamera->SetViewport(0, 0, GetScreenWidth(), GetScreenHeight());

       // 设置相机视口在屏幕中的占比，默认为全屏
       mainCamera->SetScreenRatio(Vector4(0.0, 0.0, 1.0, 1.0));

       // 设置MSAA效果
       MultiSampleInfo msaa(true, SAMPLE_COUNT_4_BIT, true, 0.5f);
       mainCamera->SetMultiSampleInfo(msaa);

       // 设置渲染路径，默认为前向渲染
       mainCamera->SetRenderingPath(RenderingPathType::RENDER_PATH_TYPE_FORWARD);

       // 设置LayerMask，用来表示哪种类型的物体在相机中显示，默认为LAYER_TYPE_ALL，表示绘制全部类型的物体
       mainCamera->SetLayerMask(LAYER_TYPE_GEOMETRY | LAYER_TYPE_SKYBOX);
       mainCamera>SetMainCamera(true);

       GetSceneManager()->AddCamera(m_mainCamera);

       // 如果需要设置多相机，则需要新创建Camera对象，并设置相应的参数
       SceneObject* sceneCameraObject1 = GetSceneManager()->CreateSceneObject();

       Camera* camera1 = sceneCameraObject1->AddComponent<Camera>();

       camera1->SetProjectionType(ProjectionType::PROJECTION_TYPE_PERSPECTIVE);

       camera1->SetPerspective(60.0f, GetAspectRatio(), 0.1f, 500.0f);

       camera1->SetViewport(0, 0, GetScreenWidth(), GetScreenHeight());

       camera1->SetScreenRatio(Vector4(0.0 / 4, 0.0 / 4, 1.0 / 4, 1.0 / 4));

       camera1->SetRenderingPath(RenderingPathType::RENDER_PATH_TYPE_FORWARD);

       camera1->SetLayerMask(LAYER_TYPE_GEOMETRY);

       GetSceneManager()->AddCamera(camera1);
   ```

4. 创建灯光。

   实例化灯光场景对象lightObject，加载灯光实例lightCom指针，灯光信息实例lightInfo指针，同时设置灯光各项参数，例如：颜色、位置、方向、以及是否[开启阴影](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/shadow-system-0000001223392341)等。

   ```screen
   void MainApplication::InitScene()
   {
       // 添加平行光
       m_directionalLightObject = GetSceneManager()->CreateSceneObject();
       if (m_directionalLightObject != nullptr) {
           // SceneObject需要添加Light组件得到Light对象
           Light* lightCom = m_directionalLightObject->AddComponent<Light>();
           if (lightCom != nullptr) {
               // 设置类型为平行光
               lightCom->SetLightType(LIGHT_TYPE_DIRECTIONAL);

               // 设置平行光为白色
               lightCom->SetColor(Vector3::ONE);

               // 设置方向
               const Vector3 lightDir(0.1f, 0.2f, 1.0f);
               lightCom->SetDirection(lightDir);
           } else {
               LOGERROR("Failed to add component light.");
           }
       } else {
           LOG_ALLOC_ERROR("New light object failed.");
       }

       // 添加点光源
       m_pointLightObject = GetSceneManager()->CreateSceneObject(nullptr);
       if (m_pointLightObject != nullptr) {
           // SceneObject需要添加Light组件得到Light对象
           Light* lightCom = m_pointLightObject->AddComponent<Light>();
           if (lightCom != nullptr) {
               lightCom->SetLightType(LIGHT_TYPE_POINT);
               const Vector3 lightColor(0.0f, 1.0f, 1.0f);
               lightCom->SetColor(lightColor);
               lightCom->SetIntensity(10000.f);
           } else {
               LOGERROR("Failed to create point light.");
           }
       } else {
           LOG_ALLOC_ERROR("Failed to create point light.");
       }
   }
   ```

5. 处理窗口尺寸变化。

   当窗口尺寸发生变化时，先设置相机的视口再将变化后的宽高传递给父类。

   ```cpp
   void MainApplication::Resize(u32 width, u32 height)
   {

       if (m_mainCamera != nullptr) {
           m_mainCamera->SetViewport(0, 0, width, height);
       }

       
       BaseApplication::Resize(width, height);
   }
   ```

## 处理手势动作

Mainloop流程将Android底层的Input系统主动上报的Input事件透传给BaseApplication。您只需要在MainApplication的[ProcessInputEvent](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/baseapplication-0000001050197736#section1069920375577)()函数中根据Event事件类型，处理模型的旋转和缩放，在Update()中更新模型旋转、缩放参数即可。

根据InputEvent的EventSource来判定具体操作类型，EventSource的定义如下：

```cpp
// 输入事件类型，支持键盘和触摸屏输入
enum EventSource {
    EVENT_SOURCE_KEYBOARD,
    EVENT_SOURCE_TOUCHSCREEN,
    EVENT_SOURCE_MAX,
};
```

在处理屏幕的触摸事件时，主要处理三个事件：

* TOUCH_ACTION_DOWN，触摸按下。
* TOUCH_ACTION_MOVE，触摸移动。
* TOUCH_ACTION_UP，触摸抬起。

Update函数用于更新模型旋转、缩放参数。

```screen
void MainApplication::ProcessInputEvent(const InputEvent *inputEvent)
{
    if (inputEvent == nullptr) {
        LOGERROR("Received null event.");
        return;
    }

    // 调用cgkit默认事件处理逻辑
    BaseApplication::ProcessInputEvent(inputEvent);

    // 针对收到的事件进行自定义设置
    EventSource source = inputEvent->GetSource();
    static bool tapDetected = false;
    static s64 lastTime = 0;

    // 触摸事件
    if(source != EVENT_SOURCE_TOUCHSCREEN) {
        return;
    }

    const TouchInputEvent* touchEvent = reinterpret_cast<const TouchInputEvent*>(inputEvent);

    // 单指滑动和缩放
    if (touchEvent->GetTouchCount() > 1) {
        return;
    }

    // 触摸事件按压
    if (touchEvent->GetAction() == TOUCH_ACTION_DOWN) {
        LOGINFO("Action move start.");
        m_touchBegin = true;
        // 两次点击间隔在双击间隔内，作为双击
        if (!m_osrPluginExecuted && tapDetected && (abs(GetCurrentTime() - lastTime) < DOUBLE_TAP_INTERVAL_MS)) {
           ExecuteOSRPlugin();
        }
    } else if (touchEvent->GetAction() == TOUCH_ACTION_MOVE) {  // 触摸事件移动
        // 确保已经是开始触摸的状态，以获取上一次的触摸坐标信息
        if (!m_touchBegin) {
        return;
        }

        // 获取事件坐标和前一次记录纵横坐标差值，用于计算模型变化数据
        f32 touchPosDeltaX = touchEvent->GetPosX(touchEvent->GetTouchIndex()) - m_touchPosX;
        f32 touchPosDeltaY = touchEvent->GetPosY(touchEvent->GetTouchIndex()) - m_touchPosY;

        // 与上次事件触摸坐标距离超过设定值才认定为有效事件，以防止误触抖动
        if (fabs(touchPosDeltaX) > 2.f) {
            if (touchPosDeltaX> 0.f) {
                m_objectRotation -= 2.f * m_deltaTime;
            } else {
                m_objectRotation += 2.f * m_deltaTime;
            }
            LOGINFO("Set rotation start.");
        }
        if (fabs(touchPosDeltaY) > 3.f) {
            if (touchPosDeltaY> 0.f) {
                m_objectScale -= 0.25f * m_deltaTime;
            } else {
                m_objectScale += 0.25f * m_deltaTime;
            }
            // 模型大小设定为0.75-1.25之间
            m_objectScale = std::min(1.25f, std::max(0.75f, m_objectScale));
            LOGINFO("Set scale start.");
        }
    } else if (touchEvent->GetAction() == TOUCH_ACTION_UP) {  // 触摸事件抬起
        LOGINFO("Action up.");
        m_touchBegin = false;
        if (!m_osrPluginExecuted) {
            tapDetected = true;
            lastTime = GetCurrentTime();
        }
    } else if (touchEvent->GetAction() == TOUCH_ACTION_CANCEL) {  // 触摸事件取消
        LOGINFO("Action cancel.");
        m_touchBegin = false;
    }

    // 记录本次触摸事件坐标，以便下一次参考计算移动量
    m_touchPosX = touchEvent->GetPosX(touchEvent->GetTouchIndex());
    m_touchPosY = touchEvent->GetPosY(touchEvent->GetTouchIndex());
}

void MainApplication::Update(float deltaTime)
{
    // deltaTime为两帧之间的时间间隔，单位是秒
    m_deltaTime = deltaTime;
    m_deltaAccumulate += deltaTime;

    // 这里每一帧设置旋转和大小，m_objectRotation和m_objectScale变量会在手势事件中被动态改变
    if (m_modelObject != nullptr) {
        m_modelObject->SetRotation(Vector3(0.0, m_objectRotation, 0.0));
        m_modelObject->SetScale(SCENE_OBJECT_SCALE * m_objectScale);
    }

    // 实时调整灯光空间位置
    const f32 moveRatioX = 0.2f;
    const f32 moveRatioY = 0.5f;
    const f32 pointLightCircle = 50.f;
    if (m_pointLightObject != nullptr) {
        m_pointLightObject->SetPosition(Vector3(sin(m_deltaAccumulate * moveRatioX) * pointLightCircle,
        sin(m_deltaAccumulate * moveRatioY) * pointLightCircle + pointLightCircle,
        cos(m_deltaAccumulate * moveRatioX) * pointLightCircle));
    }

    // 调用cgkit默认更新逻辑
    BaseApplication::Update(deltaTime);
}
```

## 调用插件管理框架API

需要通过插件加强渲染能力，可使用插件管理框架来实现，具体操作步骤如下。

1. 初始化插件系统。插件系统默认从"assets/pluginList/plugin.json""获取JSON配置文件。

   ```screen
   gPluginManager.Initialize();
   ```

2. （可选）设置配置文件。 说明
   >
   > 当需要修改配置文件时，请调用[SetConfigFile](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/pluginmanager-0000001056414499#section10305134874016)接口，修改后的配置文件路径必须设置为assets下的相对路径。

   ```screen
   std::string pluginListConfigFile = "pluginList/plugin.json";
   gPluginManager.SetConfigFile(pluginListConfigFile);
   ```

3. 获取插件列表。可从插件配置JSON文件中读取插件列表。

   ```screen
   std::vector<String> pluginList;
   pluginList = gPluginManager.GetPluginList();
   ```

   在配置文件中，"pluginName"字段为插件名，"dynamicLib"字段为该插件对应的动态库名，示例如下。

   ```screen
       "plugins" : [
           {
               "pluginName" : "PluginDemo",
               "dynamicLib" : "libPluginDemo.so"
           }
       ]
   ```

4. 加载插件，当插件系统成功加载指定插件后，会自动激活插件。

   如果加载的插件不在插件列表中，将会加载失败并返回null，请检查该插件是否在配置文件中配置。

   ```screen
   String pluginName = "PluginDemo";
   IPlugin *plugin = gPluginManager.LoadPlugin(pluginName);
   ```

5. 查询插件激活状态。

   在调用插件之前需要查询插件的激活状态，只有已激活的插件才能被调用执行接口。如果插件未激活，请参见[FAQ](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/faq-0000001050440239)处理。

   ```screen
   bool active = plugin->IsPluginActive();
   ```

6. 执行插件。
   1. 根据插件中的使用手册配置参数。

      ```cpp
      Param paramIn, paramOut, p1, p2, p3;
      Vector3 opRand1(1.0, 2.0, 3.0);
      Vector3 opRand2(1.0, 2.0, 3.0);
      // 向量点乘
      p1.Set<s32>(OP_DOT);
      // 操作数1
      p2.Set<Vector3>(opRand1);
      // 操作数2
      p3.Set<Vector3>(opRand2);
      paramIn.Set(0, p1);
      paramIn.Set(1, p2);
      paramIn.Set(2, p3);
      ```

   2. 调用插件Execute执行接口。

      ```screen
      plugin->Execute(paramIn, paramOut);
      ```

7. 卸载插件。

   ```screen
   gPluginManager.UnloadPlugin(pluginName);
   ```

8. 插件系统反初始化，释放资源。

   ```screen
   gPluginManager.Uninitialize();
   ```
