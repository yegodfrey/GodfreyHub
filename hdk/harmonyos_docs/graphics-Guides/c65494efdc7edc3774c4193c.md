# （可选）开启阴影效果

开启阴影效果能够有效提高场景中渲染的真实程度。如需开启阴影效果，需要满足以下条件：

* 场景至少拥有一个已设置投射阴影的灯光组件。
* 场景至少拥有一个用于投射阴影的模型。
* 场景至少拥有一个用于接收阴影的模型。

同一个模型既可投射阴影，也可接收阴影。是否投射阴影与接收阴影需在渲染件组件中进行配置，由于模型中可能包含多个渲染件组件，需遍历模型节点的子孙节点进行设置。

下面的示例将介绍如何开启阴影效果。  

#### 开发步骤

1. 遍历已加载模型节点的子孙节点，并设置打开投射阴影开关。

   <br />

   ```
   public void onLoaded(Model model) {
       // ....
       // 遍历子孙节点，操作各个子孙节点。
       sampleActivity.modelNode.traverseDescendants(descendant -> {
           // 获取渲染件组件。
           Renderable renderable = descendant.getComponent(Renderable.descriptor());
           // 子孙节点存在渲染件组件时，打开投射阴影开关。
           if (renderable != null) {
               renderable
                   .setCastShadow(true);
           }});
       // ....
   }
   ```

   <br />

2. 设置投射阴影的光源。

   <br />

   ```
   lightNode = renderView.getScene().createNode("shadowLight");
   lightNode.addComponent(Light.descriptor())
       // 将光源类型设置为方向光。
       .setType(Light.Type.DIRECTIONAL)
       .setColor(new Vector3(1.f, 1.f, 1.f))
       .setIntensity(1.f)
       .setCastShadow(true);
   lightNode.getComponent(Transform.descriptor())
       // 设置方向光的投射方向（起始位置、目标位置、上向量）。
       // 当前设置为水平方向从右向左照射的方向光。
       .lookAt(new Vector3(1.f, 0.f, 0.f), new Vector3(0, 0, 0), new Vector3(0, 1, 0));
   ```

   <br />

3. 与打开模型投射阴影开关类似，选择接收阴影的模型，打开其接收阴影开关。

   <br />

   ```
   modelNode.traverseDescendants(descendant -> {
       // 子孙节点存在渲染件组件时，开启阴影效果。
       Renderable renderable = descendant.getComponent(Renderable.descriptor());
       if (renderable != null) {
           renderable
               .setReceiveShadow(true);
       }
   });
   ```

   <br />
