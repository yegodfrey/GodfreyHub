# 天空盒

CG Kit渲染框架支持天空盒的配置，以下示例中的天空盒模型为".obj"格式，纹理为".png"格式。

配置天空盒Cubemap步骤如下。

1. 编写CubeMap配置文件（文本格式，后缀名为".cub"）。

   ```
   width = xxx  
   height = xxx 
   depth = xxx  
   mipmap = xxx 
   face = xxx   
   channel = xxx
   suffix = xxx 
   ```

   |配置项|说明|
   |:------|:-----------------|
   |width|每个面纹理像素宽度|
   |height|每个面纹理像素高度|
   |depth|每个面纹理像素深度|
   |mipmap|MipMap层级数量|
   |face|立方体的面的数量|
   |channel|每个面纹理的RGBA通道数|
   |suffix|每个面纹理的格式，目前仅支持.png|

2. 将CubeMap各个面的纹理（.png格式）排列在.cub配置文件同一目录下（如assets/cubemaps/env），并保持以下命名格式（i为MipMap层级数，从0开始）。

   ```
   cubeface_neg_xi
   cubeface_neg_yi
   cubeface_neg_zi
   cubeface_pos_xi
   cubeface_pos_yi        
   cubeface_pos_zi            
   ```

   |配置项|说明|
   |:--------------|:------|
   |cubeface_neg_xi|立方体的左侧面|
   |cubeface_neg_yi|立方体的底面|
   |cubeface_neg_zi|立方体的前侧面|
   |cubeface_pos_xi|立方体的右侧面|
   |cubeface_pos_yi|立方体的顶面|
   |cubeface_pos_zi|立方体的后侧面|
