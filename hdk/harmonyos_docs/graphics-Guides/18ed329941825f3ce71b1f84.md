# 调用C接口

本插件提供C封装的接口函数库，可以通过动态链接的方式，将插件集成到游戏项目中。

## 创建Hiculling对象

在使用遮挡剔除功能之前，需要先调用HcCreate接口创建[HiCulling](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/hiculling-0000001055695365)对象。

```screen
HiCulling* obj = HcCreate(true);
```

## 设置HcSetResolution参数

[HcSetResolution](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/hcsetresolution-0000001055576825)函数可以为depth buffer设置分辨率。传入的分辨率必须是2的倍数，否则设置无效，并返回错误码[HcErrorCode](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/hcerrorcode-0000001055612806)。

```screen
const unsigned int alignedWidth = 400;
const unsigned int alignedHeight = 200;
CHECK_RESULT(HcSetResolution(obj, alignedWidth, alignedHeight));
```

## 设置Occluder和Occludee

Occluder由数据结构[HcOccluderMeshType](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/hcoccludermeshtype-0000001055015377)描述，其中包含以下成员。

* numMesh：描述Occluder中mesh的个数。
* meshes：指向mesh buffer的指针。
* bWinding：指定三角形背面的环绕方向。当bWinding为HC_CCW时，逆时针环绕的三角形将被认为是背面，将不会被光栅化到depth buffer。
* idxType：支持多种类型的三角形顶点索引，包括unsigned byte，unsigned short，unsigned int。
* vtxStride：表示顶点缓冲区中位置属性之间的偏移大小，以float component为单位。
* nearClipDistance：近裁面的位置。

```screen
HcOccluderMeshType occluders = { .numMesh = 1, .meshes = &mesh, .bWinding = HC_CCW, 
                                 .idxType = HC_UNSIGNED_SHORT, .vtxStride = case0VtxStride, 
                                 .nearClipDistance = 0.1f };
```

其中[HcMeshType](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/hcmeshtype-0000001055375375)在构造时需要设置以下成员。

* vertices：指向vertice buffer的指针。
* nVertices：描述顶点的个数。
* indices：指向indices buffer的指针。
* nIndices：描述顶点索引的个数。
* localToClip：顶点从local space到clip space的变换矩阵，以列主序的方式存储。

  ```screen
  HcMeshTypemesh = { .vertices = vertices, .nVertices = case0VerticesNum,
                     .indices = indices, .nIndices = case0IndicesNum };
  MatrixCopy(mesh.localToClip, ProjectionMatrix * ViewMatrix * WorldMatrix, MATRIX_DIMENSIONS);
  ```

Occludee由数据结构[HcOccludeeBoxType](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/hcoccludeeboxtype-0000001055455351)描述，其中包含以下成员。

* numBox：描述Occludee中AABB的个数。
* boxMinMax：指向存放world space下AABB数据的buffer。AABB的数据按照(xmin, ymin, zmin, xmax, ymax, zmax)的顺序排布，每6个数值表示一个AABB。
* worldToClip：顶点从world space到clip space的变换矩阵，以列主序的方式存储。

  ```screen
  HcOccludeeBoxType occludees = { .numBox = OCCLUDEE_BOX_NUM, .boxMinMax = aabb };
  MatrixCopy(occludees.worldToClip, ProjectionMatrix * ViewMatrix, MATRIX_DIMENSIONS);
  ```

## 对Occluder光栅化

把Occluder添加到遮挡剔除模块，然后光栅化。示例代码如下。

```screen
// 将occluders添加到遮挡剔除模块中
CHECK_RESULT(HcAddOccluderMeshes(obj, occluders));
// 将occluders光栅化到depth buffer中，用于遮挡查询 
CHECK_RESULT(HcRasterizeOccluder(obj));
```

## 对Occludee遮挡查询

对Occludee做遮挡查询，并把结果返回到result中。示例代码如下。

```screen
bool visibility[4] = { true };
bool* result[] = { &visibility[0], &visibility[1], &visibility[2], &visibility[3] };
// 利用depth buffer对occludees的AABB（轴对齐包围盒）做遮挡查询 
CHECK_RESULT(HcTestOccludeesAABB(obj, occludees, result));
// 在遮挡查询完成后，清空depth buffer 
CHECK_RESULT(HcClearBuffer(obj));
// 输出遮挡查询结果 
printf("aabb0: %d, aabb1: %d, aabb2: %d, aabb3: %d\n\n",
        visibility[0], visibility[1], visibility[2], visibility[3]);
```

## 销毁HiCulling对象

使用结束后，调用HcDestroy销毁对象。

```screen
HcDestroy(obj);
```
