# glTF配置说明

CG Kit渲染框架支持对3D场景文件".gltf"和".glb"格式的解析。glTF模型文件包含以下3种形式。

* glTF文件：包含顶点数据的.bin文件，png、bmp、rgb等格式的纹理图片和glTF文件。
* glTF-Binary文件：是glTF文件的2进制形式，格式为".glb"，其解析过程与glTF文件相同。
* glTF-Embedded文件：顶点数据和纹理图片内容以base64编码的格式存放在glTF文件中。

* 在CG Kit渲染框架下解析glTF文件时，纹理图片必须放在"assets/models/gltf/image"中，且数据文件".bin"和".gltf"文件在同一目录。
* 开发者需要提供一个名称为[gltfBase.cgmat](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/cgmat-configuration-file-0000001106071566)的材质配置文件，并放在"assets/material"中。
* CG Kit渲染框架从V6.3.0版本起支持含有[骨骼动画/帧动画](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/skeletal-frame-animation-0000001221937935)的glTF文件解析。
