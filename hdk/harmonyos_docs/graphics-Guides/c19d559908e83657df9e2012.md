# 调用时域抗锯齿插件

时域抗锯齿插件同时提供PC端和移动端的动态链接库。

* PC端插件只提供x64版本，供用户根据实际场景调试抗锯齿参数使用。
* 移动端插件可使用调试完成的参数，进行抗锯齿渲染。

## 头文件依赖

在项目中需要依赖一个头文件。

TaaRenderAPI.h：定义用于时域抗锯齿渲染的接口。

## 抗锯齿渲染

1. 加载动态库文件。
   * PC端（Windows 10）链接TAARenderingPlugin.dll动态库。
   * 移动端（Android）链接libTAARenderingPlugin.so动态库。
2. 调用[CreateTaaRenderAPI](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/createtaarenderapi-0000001110089268)创建时域抗锯齿插件对象。

   ```screen
   TaaRenderAPI* taaRender = CreateTaaRenderAPI(GraphicAPI apiType);
   ```

   其中[GraphicAPI](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/graphicapi-0000001156329141)为枚举变量，定义使用的图形接口。

   ```cpp
   typedef enum GraphicAPI
   {
       // Android平台使用OpenGLES 3.1及以上版本
       GraphicAPI_OpenGLES30 = 0,
       // Windows平台使用OpenGL 4.0及以上版本
       GraphicAPI_OpenGL = 1, 
   } GraphicAPI;
   ```

3. 调用[InitTaaProcess](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/taarenderapi-0000001110249172#section788322516435)初始化时域抗锯齿插件对象资源。

   ```screen
   taaRender->InitTaaProcess(width, height);
   ```

4. 调用[GetJitterMatrix](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/taarenderapi-0000001110249172#section040011254285)更新相机抖动投影矩阵。

   ```screen
   taaRender->GetJitterMatrix(mat, cameraParam, cameraParamLength, cameraMode);
   ```

5. 调用[UpdateTaaParam](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/taarenderapi-0000001110249172#section1350194774313)更新时域抗锯齿插件参数。

   ```screen
   taaRender->UpdateTaaParam(blendParam, paramLength, renderWidth, renderHeight);
   ```

6. 调用[RunTaaProcess](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/taarenderapi-0000001110249172#section37355811295)执行时域抗锯齿渲染。

   ```screen
   taaRender->RunTaaProcess(renderRes, motionVector, source);
   ```

7. 调用[FreeTaaResources](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/taarenderapi-0000001110249172#section182617331513)释放时域抗锯齿插件资源。

   ```screen
   taaRender->FreeTaaResources();
   ```

8. 删除时域抗锯齿插件对象。

   ```screen
   delete taaRender;
   taaRender = NULL;
   ```

> 说明
>
> * 时域抗锯齿插件提供了查询错误状态的API，在任意时刻调用[GetTaaProcessError](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/taarenderapi-0000001110249172#section543194314457)()，会返回当前插件执行中是否有误。执行有误返回true，执行无误返回false。
> * 如果返回true，可以查看安卓日志来定位哪个API调用出错。

## 调用时域抗锯齿插件示例

```screen
TaaRenderAPI* taaRender = CreateTaaRenderAPI(GraphicAPI_OpenGLES30);
bool ret = taaRender->InitTaaProcess(renderWidth, renderHeight);
if (!ret) {
    return
}
do{
    // 获取projectionMatrix，开发者自行获取
    bool ret0 = taaRender->GetJitterMatrix(mat, cameraParam, cameraParamLength, cameraMode);
    if(!ret0) {
       return;
    }

    bool ret1 = taaRender->UpdateTaaParam(blendParam, paramLength, renderWidth, renderHeight);
    if(!ret1) {
       return;
    }

    ...

    // 用于存放抗锯齿渲染结果的纹理由用户自行申请和释放
    // motion vector由用户获取并传递纹理地址给抗锯齿插件
    bool ret2 = taaRender->RunTaaProcess(renderRes, motionVector, source);
    if(!ret2) {
       return;
    }

    // 使用renderRes对应的抗锯齿结果进行其他后处理或者送显
    ...

}while(...)
// 释放资源和数据
taaRender->FreeTaaResources();
delete taaRender;
taaRender = NULL;
```
