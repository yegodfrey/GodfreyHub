# 版本更新说明

## 1.6.0.2（2023-07-20）

|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Android版本：com.huawei.hms:xrkitsdk:1.6.0.2 **修改特性** * 添加queries标签。当您的应用配置的targetSdkVersion大于等于30时，为保证应用兼容性，请使用此版本。 * 加强了[createXrKitFeature](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/class-xrkit-feature-factory-0000001064290229#section580014755220)接口安全性。 > 说明 > 为了提高您应用的安全性，我们强烈建议您使用该版本。|

> 注意
>
> 1、XRKit在2023年6月30日后不再支持32位运行库，该操作可能会影响您的应用正常运行，请及时更改您的应用配置，以支持64位运行库。
>
> 2、当您的应用配置的targetSdkVersion大于等于30时，在Android 11及以上系统会提示XRKit（APK）或AR Engine Service版本未安装，解决方案有以下两种：
>
> * 升级您的应用使用的XRKit SDK版本到1.6.0.2（推荐）。
> * 如果不升级XRKit SDK版本，需要在"AndroidManifest.xml"中manifest下添加<queries>标签。
>
>   ```screen
>   <manifest ...>
>       ...
>       <queries>
>           <package android:name="com.huawei.arengine.service" />
>           <package android:name="com.huawei.featurelayer.sharedfeature.xrkit" />
>       </queries>
>       ...
>   </manifest>
>   ```
>
> <queries>标签对工具的要求如下：
>
> * Android Studio需升级至3.3或更高版本。
> * Android Gradle插件需升级至3.3.3、3.4.3、3.5.4、3.6.4、4.0.1或4.1.0及更高版本。

## 1.6.0.0（2022-07-29）

|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Android版本：com.huawei.hms:xrkitsdk:1.6.0.0 **新增特性** * 在AR展示（ARSceneView）中新增空间音频能力，在已经加载的模型上添加音频后，XRKit内部根据设备和模型的空间位置变化，模拟真实世界中音频的发声，提升听觉体验。可通过[attachSoundToModel](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/interface-model-0000001064420560#section1310915291277)、[detachSoundFromModel](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/interface-model-0000001064420560#section116741036447)、[playSound](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/interface-model-0000001064420560#section1155817644414)、[pauseSound](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/interface-model-0000001064420560#section19174139184419)接口分别控制音频添加至模型、从模型删除音频、播放音频、暂停音频动作。该特性配套的最小XRKit版本：11.1.1.340。 * 空间摆放特性，可在ARSceneView中添加多个模型，以实现完整的AR场景构建功能。该特性配套的最小XRKit版本：12.0.0.310。 > 说明 > 不佩戴耳机，只能感受音频的声音大小变化，佩戴耳机后，可以同时感受音频的声音大小及方位变化，空间音频效果体验更佳。|

## SDK依赖说明

* 最新版本SDK需要用户终端设备上安装XRKit（APK）。如果用户终端设备没有安装，您的应用调用XRKit能力时，应提醒用户安装。
* XRKit的特性依赖特定机型及OS版本，请参见[XRKit特性依赖表](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/xrkit-features-0000001071810474)。

提示：您的应用在开发集成过程中，如有问题可通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)咨询。
