# FrameGraph

CG Kit提供FrameGraph（可扩展渲染管线框架），创建Camera时，使用[CameraFrameGraph](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/cameraframegraph-0000001353458502)类，并使用该类的[SetRenderingPathFG](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/cameraframegraph-0000001353458502#section67011816174110)接口设置FrameGraph的渲染路径，即可开启此框架。目前FrameGraph仅支持前向渲染Pass，暂不支持阴影功能和相机位置重置功能。 示例代码如下。

```
// 添加Camera（CameraFrameGraph）组件
m_mainCamera = m_sceneCameraObject->AddComponent<CameraFrameGraph>();
// 设置FrameGraph的渲染路径
dynamic_cast<CameraFrameGraph*>(m_mainCamera)->SetRenderingPathFG(m_graphicsRenderer);
// 设置Camera相关参数
m_mainCamera->SetProjectionType(ProjectionType::PROJECTION_TYPE_PERSPECTIVE);
m_mainCamera->SetPerspective(60.0f, GetScreenHeight() / GetScreenWidth(), 0.1f, 500.0f);
m_mainCamera->SetViewport(0, 0, GetScreenWidth(), GetScreenHeight());
m_mainCamera->SetMainCamera(true);
m_mainCamera->SetLayerMask(LAYER_TYPE_SKYBOX | LAYER_TYPE_GEOMETRY);
// 将m_mainCamera设置为MainCamera
m_sceneManager->SetMainCamera(m_mainCamera);
```
