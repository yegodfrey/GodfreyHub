# 业务简介

|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-|
|多线程加速能力在系统中位于kernel之上，以C语言API接口的方式向您开放能力。 当前的Android终端基本是多核系统，充分利用多核需要编写同时能执行多个任务的程序。通常native层的多线程程序是通过管理线程来控制任务执行，Acc Kit通过多线程库为您提供了一套新的多线程编程方法，可以让您忽略线程管理的细节，开发出能够充分发挥系统的多核硬件能力的程序，使程序更快更高效的运行。| |

## 场景介绍

* 应用多个任务可以并行执行的场景。
* 应用多个任务必须串行执行的场景。
* 应用任务间需要同步的场景。

更多使用场景参见[API参考](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/overview-0000001089423609)和[示例代码](https://developer.huawei.com/consumer/cn/doc/development/graphics-Examples/sample-code-0000001050700782)。
