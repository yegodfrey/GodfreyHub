# 使用入门

#### 基础知识准备

在使用 SDK 3.5之前，开发者需要对 OpenXR 平台及 C++ 语言，OpenGL ES，Android，Java 有一定基础。  

#### 开发环境

* 手机：华为旗舰手机，型号表可参见[支持的设备](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/introduction-0000001097358942#section43314313363)
* 操作系统：EMUI10.0 及以上版本（Android Q 版本及以上）
* OpenXR 版本：支持 1.0.3  

#### 开发流程

|序号|步骤|说明|
|:-|:-------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|材料准备|在开发应用前，需要进行以下操作： 1. 在 PC 端下载安装 Android Studio。 2. 下载 [HUAWEI VR SDK 3.5 For OpenXR Demo](https://developer.huawei.com/consumer/cn/doc/development/graphics-Examples/openxr-sample-code-0000001102007332) 压缩包。 3. 下载 [HUAWEI VR SDK 3.5 For OpenXR](https://developer.huawei.com/consumer/cn/doc/development/graphics-Library/openxr-sdk-download-0000001148849243) 压缩包。 4. 准备好华为手机及华为 VR Glassess。手机联网后插入 VR Galssess，会自动提示安装所需 VR 运行环境，按指引操作即可。|
|2|[应用开发](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/app-dev-0000001097518330)|1. 创建工程以及配置 Android 环境。 2. 集成 [SDK 3.5 OpenXR](https://developer.huawei.com/consumer/cn/doc/development/graphics-Library/openxr-sdk-download-0000001148849243) 插件。 3. 更改应用程序的 AndroidManifest 配置。 4. 开始编写您的应用程序逻辑代码。|
|3|[开发后自检](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/pre-release-check-0000001097358504)|华为提供对应用自动检查的能力。|
|4|[上架申请](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/app-release-0000001097890656)|开发完成后需要在 AppGallery Connect 中将应用信息补充完整并提交上架申请。|
