# ARView

#### 开发步骤

图形引擎服务通过[ARView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-arview-0000001051923459)提供了一般AR场景的3D素材渲染能力。[ARView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-arview-0000001051923459)继承自Android GLSurfaceView，并重写了相关生命周期方法，方便调用。本节将展示如何使用[ARView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-arview-0000001051923459)实现在AR场景中加载素材，完整代码请参见[调用示例](#section21301244101110)。

1. 创建一个ARViewActivity，使其继承自Activity。添加一个Button按钮用于加载素材。

   <br />

   ```
   public class ARViewActivity extends Activity {
       private ARView mARView;
       // 添加一个按钮用于加载素材。
       private Button mButton;
       // isLoadResource用于判断是否已加载素材。
       private boolean isLoadResource = false;
   }
   ```

   <br />

2. 将[ARView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-arview-0000001051923459)添加到Layout布局中，并在AndroidManifest文件中申请相机权限。

   <br />

   ```
   <!--ARView的大小设置为适配屏幕宽高。-->
   <com.huawei.hms.scene.sdk.ARView
       android:id="@+id/ar_view"
       android:layout_width="match_parent"
       android:layout_height="match_parent">
   </com.huawei.hms.scene.sdk.ARView>
   ```

   ```
   <uses-permission android:name="android.permission.CAMERA" />
   ```

   [ARView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-arview-0000001051923459)为保证效果暂不支持转屏与分屏操作，请在AndroidManifest文件相应的Activity标签中进行配置：

   ```
   android:screenOrientation="portrait"
   android:resizeableActivity="false"
   ```

   <br />

3. 重写onCreate方法，并获取[ARView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-arview-0000001051923459)。

   <br />

   ```
   @Override
   protected void onCreate(Bundle savedInstanceState) {
       super.onCreate(savedInstanceState);
       setContentView(R.layout.activity_ar_view);
       // 获取ARView，其ID为ar_view。
       mARView = findViewById(R.id.ar_view);
       // 获取加载素材的按钮，其ID为button。
       mButton = findViewById(R.id.button);
   }
   ```

   <br />

4. 可在onCreate方法中使用一个Switch按钮控制辅助显示平面是否打开。

   <br />

   ```
   // 获取Switch按钮，其ID为show_plane_view。
   Switch mSwitch = findViewById(R.id.show_plane_view);
   // 设置Switch按钮默认为打开。
   mSwitch.setChecked(true);
   // 设置Switch按钮开关状态变化的监听方法。
   mSwitch.setOnCheckedChangeListener(new CompoundButton.OnCheckedChangeListener() {
       @Override
       public void onCheckedChanged(CompoundButton buttonView, boolean isChecked) {
           // 根据Switch按钮的开关状态控制辅助显示平面是否打开。
           mARView.enablePlaneDisplay(isChecked);
       }
   });
   ```

   使用Switch按钮前请在Layout中添加。

   ```
   <Switch
       android:layout_width="wrap_content"
       android:layout_height="wrap_content"
       android:id="@+id/show_plane_view"
       android:layout_alignParentTop="true"
       android:layout_marginTop="15dp"
       android:layout_alignParentEnd="true"
       android:layout_marginEnd ="15dp"
       android:layout_gravity="end"
       android:text="@string/show_plane"
       android:theme="@style/AppTheme"
       tools:ignore="RelativeOverlap" />
   ```

   <br />

5. 增加按钮回调方法。首次点击按钮加载素材，再次点击按钮清除素材。

   <br />

   ```
   public void onBtnClearResourceClicked(View view) {
       if (!isLoadResource) {
           // 未加载素材时，加载素材。
           mARView.loadAsset("ARView/scene.gltf");
           // 将isLoadResource置为true，表示已加载素材。
           isLoadResource = true;
           // 将按钮的文字更改为清除素材。
           mButton.setText(R.string.btn_text_clear_resource);
       } else {
           // 已加载素材时，清除该素材。
           mARView.clearResource();
           // 加载空素材。
           mARView.loadAsset("");
           // 将isLoadResource置为false，表示未加载素材。
           isLoadResource = false;
           // 将按钮的文字更改为加载素材。
           mButton.setText(R.string.btn_text_load);
       }
   }
   ```

6. 重写onPause方法，并调用[ARView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-arview-0000001051923459)的[onPause](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-arview-0000001051923459#section8328104711216)方法。

   <br />

   ```
   @Override
   protected void onPause() {
       super.onPause();
       mARView.onPause();
   }
   ```

   <br />

7. 重写onResume方法，并调用[ARView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-arview-0000001051923459)的[onResume](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-arview-0000001051923459#section1879120119128)方法。

   <br />

   ```
   @Override
   protected void onResume() {
       super.onResume();
       mARView.onResume();
   }
   ```

   <br />

8. 重写onDestroy方法，并调用[ARView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-arview-0000001051923459)的[destroy](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-arview-0000001051923459#section1020321445920)方法。

   <br />

   ```
   @Override
   protected void onDestroy() {
       super.onDestroy();
       mARView.destroy();
   }
   ```

   <br />

9. （可选）加载完素材后，可通过[setInitialPose](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-arview-0000001051923459#section71677110133)设置3D素材初始的缩放系数与旋转角度。

   <br />

   ```
   float[] scale = new float[] { 0.1f, 0.1f, 0.1f };
   float[] rotation = new float[] { 0.707f, 0.0f, -0.707f, 0.0f };
   // 设置初始位姿状态。
   mARView.setInitialPose(scale, rotation);
   ```

   <br />

#### 调用示例

```
public class ARViewActivity extends Activity {
    private ARView mARView;
    private Button mButton;
    private boolean isLoadResource = false;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_ar_view);
        mARView = findViewById(R.id.ar_view);
        mButton = findViewById(R.id.button);
        Switch mSwitch = findViewById(R.id.show_plane_view);
        mSwitch.setChecked(true);
        mSwitch.setOnCheckedChangeListener(new CompoundButton.OnCheckedChangeListener() {
            @Override
            public void onCheckedChanged(CompoundButton buttonView, boolean isChecked) {
                mARView.enablePlaneDisplay(isChecked);
            }
        });
    }

    // 按钮点击回调。
    public void onBtnClearResourceClicked(View view) {
        if (!isLoadResource) {
            mARView.loadAsset("ARView/scene.gltf");
            float[] scale = new float[] { 0.1f, 0.1f, 0.1f };
            float[] rotation = new float[] { 0.707f, 0.0f, -0.707f, 0.0f };
            mARView.setInitialPose(scale, rotation);
            isLoadResource = true;
            mButton.setText(R.string.btn_text_clear_resource);
        } else {
            mARView.clearResource();
            mARView.loadAsset("");
            isLoadResource = false;
            mButton.setText(R.string.btn_text_load);
        }
    }

    // 必须同步调用ARView的onPause()。
    @Override
    protected void onPause() {
        super.onPause();
        mARView.onPause();
    }

    // 必须同步调用ARView的onResume()。
    @Override
    protected void onResume() {
        super.onResume();
        mARView.onResume();
    }

    // 必须同步调用ARView的destroy()。
    @Override
    protected void onDestroy() {
        super.onDestroy();
        mARView.destroy();
    }
}
```
