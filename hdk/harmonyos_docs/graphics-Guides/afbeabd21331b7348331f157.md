# 应用开发

本指南将展示如何使用 HUAWEI VR SDK 3.5 For OpenXR 插件，结合 OpenXR 引擎开发适配华为 Glasses 眼镜的 VR 应用。  

#### 开发流程

#### 集成 SDK 3.5 OpenXR 插件

基于OpenXR开发的应用调用SDK接口的逻辑如下图所示。APP调用Loader层，Loader层转到SDK层。其中Loader层集成在OpenXR APP中的lib_loader.so中。lib_loader.so和OpenXR的标准头文件即可视为OpenXR插件，具体文件见OpenXR Demo。OpenXR插件实现了OpenXR APP层与SDK层的连接。

#### 运行OpenXR Demo

OpenXR Demo是一个Android工程，利用Android Studio直接打开，按照说明的Android环境配置要求进行配置，编译运行即可。

OpenXR Demo中涉及Java侧代码通过JNI调用C++侧的OpenXR接口。JNI涉及的接口见GL2JNILib.java。OpenXR接口调用入口见xr_demo.cpp中Run函数。OpenXR Demo中的场景绘制具体见xr_demo.cpp中renderView函数，开发者可根据需要修改场景内容。  

#### 应用程序的AndroidManifest配置

应用程序的AndroidManifest必须符合以下内容：

* 在application下包含以下meta-data，用来标明应用为华为VR应用。

  ```
  <meta-data android:name="com.huawei.android.vr.application.mode" android:value="vr_only"/>
  ```

<!-- -->

* 在application下包含以下meta-data, 为了在Mate10 Pro等特殊比例的屏幕上显示正常。

  ```
  <meta-data android:name="android.max_aspect" android:value="2.1" />
  ```

<!-- -->

* 在application下包含以下meta-data，设置应用类型："game"或"video"，默认类型为"game"，SDK会根据类型调整温控策略。

  ```
  <meta-data android:name="com.huawei.android.vr.application.type" android:value="game" />
  ```

<!-- -->

* 将VR Activity中的intent-filter修改为以下形式，为了去除桌面图标并让VrLauncher可以跳转。

  ```
  <activity android:name="yourPackage.yourActivity">
      <intent-filter>
          <action android:name="com.huawei.android.vr.action.MAIN"/>
          <category android:name="android.intent.category.DEFAULT"/>
      </intent-filter>
  </activity>
  ```

<!-- -->

* 包含以下权限，用来使用系统VR服务。

  ```
  <uses-permission android:name="com.huawei.android.permission.VR"/>
  ```

<!-- -->

* 包含以下权限，用来连接手柄服务。

  ```
  <uses-permission android:name="com.huawei.vrhandle.permission.DEVICE_MANAGER" />
  ```

<!-- -->

* 包含以下权限，用来支持截图功能。

  ```
  <uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" />
  ```

<!-- -->

* 在application下包含以下meta-data，设置应用使用的手柄类型："3dof"或"6dof"或"3dof\|6dof"，默认类型为"3dof"，SDK会根据类型调整手柄接入模式。当设置为"3dof\|6dof"时，应用同时支持3dof和6dof手柄。

  ```
  <meta-data android:name="com.huawei.vr.application.freeDegree" android:value="3dof|6dof" />
  ```

以上内容都可参考Assets\\Plugins\\Android下默认的AndroidManifest.xml文件。

如果应用的目标平台为 Android 11（API 级别 30）或更高版本，则另外需要在manifest标签下增加如下配置，以可正常支持手柄连接。

```
<queries>
    <package android:name="com.huawei.vrhandle" />
    <package android:name="com.huawei.hvrsdkserverapp" />
    <intent>
        <action android:name="com.huawei.vrhandle.service.vrdeviceservice"/>
    </intent>
</queries>
```

另外，如果开发者需要不连接头盔看到手机上的显示，需要在AndroidManifest的application下包含以下meta-data，但是，正式发布的应用程序中必须去掉该标签，此功能仅用于调试。

```
<meta-data android:name="com.huawei.android.vr.sensor.mode" android:value="mobile"/>
```
