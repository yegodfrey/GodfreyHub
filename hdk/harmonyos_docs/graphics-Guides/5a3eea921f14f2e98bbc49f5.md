# 添加渲染视图

渲染视图（[RenderView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-renderview-0000001061309635)）是原子化接口的核心，使用渲染视图，可以快速构建出想要的场景渲染效果。其内部已经实现了复杂的渲染流程，您只需要将精力放在场景布置管理上。

渲染视图本身可以直接使用，但同时也支持高度定制化的扩展。渲染视图为子类提供了一系列生命周期方法供复写：

* [onSurfaceCreated](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-renderview-0000001061309635#section06301723134116)：渲染视图的Surface创建后被调用。
* [onSurfaceChanged](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-renderview-0000001061309635#section4453103684114)：渲染视图的Surface改变后被调用。
* [onSurfaceDestroyed](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-renderview-0000001061309635#section206068452418)：渲染视图的Surface销毁后被调用。
* [onResume](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-renderview-0000001061309635#section1036818595410)：渲染视图继续渲染后被调用。
* [onPause](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-renderview-0000001061309635#section816344144219)：渲染视图暂停渲染后被调用。
* [onDestroy](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-renderview-0000001061309635#section968116818429)：渲染视图销毁后被调用。
* [onBeginFrame](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-renderview-0000001061309635#section691514156425)：渲染视图准备绘制一帧时被调用。
* [onEndFrame](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-renderview-0000001061309635#section11790182012429)：渲染视图结束一帧绘制时被调用。
* [onDrawFrame](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-renderview-0000001061309635#section107496257422)：渲染视图绘制一帧时被调用。

结合这些生命周期方法，您可以编写子类扩展自渲染视图，并且进行二次开发，常见的用法是结合AREngine构建出更复杂的AR场景渲染视图。下面的示例中，将直接使用渲染视图进行场景渲染，关于渲染视图的扩展，请参见[API参考](https://developer.huawei.com/consumer/cn/doc/graphics-References/render-api-overview-0000001061359985)获取更多信息。  

#### 开发步骤

1. 在SampleActivity的Layout文件中添加渲染视图。

   <br />

   ```
   <?xml version="1.0" encoding="utf-8"?>
   <LinearLayout
       xmlns:android="http://schemas.android.com/apk/res/android"
       android:layout_width="match_parent"
       android:layout_height="match_parent"
       android:orientation="vertical">

       <com.huawei.hms.scene.sdk.render.RenderView
           android:id="@+id/render_view"
           android:layout_width="match_parent"
           android:layout_height="match_parent"/>
   </LinearLayout>
   ```

   <br />

2. 在SampleActivity的onCreate方法中寻找渲染视图，并将其保存至局部变量。

   <br />

   ```
   private RenderView renderView;

   @Override
   protected void onCreate(@Nullable Bundle savedInstanceState) {
       super.onCreate(savedInstanceState);
       setContentView(R.layout.activity_sample);
       // 根据id查找添加的渲染视图并将其保存至局部变量。
       renderView = findViewById(R.id.render_view);
   }
   ```

   <br />

3. 复写SampleActivity的onResume、onPause、onDestroy方法，并调用渲染视图的[resume](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-renderview-0000001061309635#section6277184983920)、[pause](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-renderview-0000001061309635#section017145913392)、[destroy](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-renderview-0000001061309635#section568813416403)方法，如果不调用上述三个方法，渲染视图将无法正常工作。

   <br />

   ```
   @Override
   protected void onResume() {
       super.onResume();
       // 渲染视图继续渲染。
       renderView.resume();
   }

   @Override
   protected void onPause() {
       super.onPause();
       // 渲染视图暂停渲染。
       renderView.pause();
   }

   @Override
   protected void onDestroy() {
       renderView.destroy();
       // 渲染视图销毁。
       super.onDestroy();
   }
   ```

   <br />
