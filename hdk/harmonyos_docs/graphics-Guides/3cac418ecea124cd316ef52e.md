# 实现IPlugin接口

在插件工程"Src"目录下实现插件系统的[IPlugin](https://developer.huawei.com/consumer/cn/doc/graphics-References/iplugin-0000001057182525)接口。

* 查询插件信息，查询接口[GetPluginInfo](https://developer.huawei.com/consumer/cn/doc/graphics-References/iplugin-0000001057182525#section7392174813375)支持用户查询插件基本信息。

  ```screen
  const String pluginInfo = "PluginDemo:VERSION1.0,DES:VECTOR3 Dot&Cross operation";
  const String &PluginDemo::GetPluginInfo() const
  {
      return pluginInfo;
  }
  ```

* 初始化插件，初始化接口[Initialize](https://developer.huawei.com/consumer/cn/doc/graphics-References/pluginmanager-0000001056414499#section629642105011)对插件运行环境及资源进行申请操作。

  ```screen
  bool PluginDemo::Initialize()
  ```

* 执行插件，执行接口[Execute](https://developer.huawei.com/consumer/cn/doc/graphics-References/iplugin-0000001057182525#section5221171175413)对插件开放的API进行实现，实现前需要先判断插件的激活状态。

  ```screen
  bool PluginDemo::Execute(const Param &paramIn, Param &paramOut)
  {
      if (!IsPluginActive()) {
          return false;
      }
      ...
      //参数解析
      Param::Array arrayVal = paramIn.Get<Param::Array>();
      // opcode
      Param p1 = arrayVal[0];
      // operand 1
      Param p2 = arrayVal[1];
      // operand 2
      Param p3 = arrayVal[2];
      //功能实现
      switch (opCode) {
          case OP_A: {
              ...
              break;
          }
          case OP_B: {
              ...
              break;
          }
          default:
              return false;
      }
      ...
  }
  ```

* 反初始化插件，反初始化接口[Uninitialize](https://developer.huawei.com/consumer/cn/doc/graphics-References/pluginmanager-0000001056414499#section913612195514)对插件运行环境及资源进行清理操作。

  ```screen
  void PluginDemo::Uninitialize()
  ```

* 插件创建和销毁。

  ```screen
  extern "C" IPlugin *CreatePlugin(void)
  extern "C" void DestroyPlugin(IPlugin *plugin)
  ```
