# 调用骨骼动画插件

本插件包含两部分功能：动作融合和脚部IK（Inverse Kinematics，反向动力学）。

* 动作融合：将多个动画片段进行加权融合，使得相邻帧动作间能够平滑过渡。
* 脚部IK：依据场景高低起伏修正脚部末端，并利用反向动力学调节其他关节。

## 头文件依赖

本插件包含两个头文件：SkeletonAnimationDefine.h和SkeletonAnimationInterface.h。

* SkeletonAnimationDefine.h：定义本插件数据结构的头文件。
* SkeletonAnimationInterface.h：定义本插件调用接口的头文件。

## 动作融合

1. 加载动态库文件。
   * PC端（Windows 10）链接SkeletonAnimation.dll动态库。
   * 移动端（Android）链接libSkeletonAnimation.so动态库。
2. 创建[SkeletonAnimationInterface](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/skeletonanimationinterface-0000001156971985)的对象指针。

   ```screen
   SkeletonAnimationInterface* skeletonAnimation = CreateSkeletonAnimationInstance();
   ```

3. 初始化动作融合参数。
   * 初始化摇杆参数[JoystickInfo](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/joystickinfo-0000001156813827)。

     ```screen
     JoystickInfo joyStickInfo;
     joyStickInfo.horizontalAxis = axisHor;
     joyStickInfo.verticalAxis = axisVer;
     ```

   * 初始化角色状态参数[CharacterStateInfo](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/characterstateinfo-0000001110653852)。

     ```screen
     CharacterStateInfo characterStateInfo;
     characterStateInfo.isJump = stateJump;
     characterStateInfo.jumpTime = timeJump;
     ```

   * 初始化动作融合权重参数[BlendWeight](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/blendweight-0000001156973809)。

     ```screen
     BlendWeight* blendWeight = new BlendWeight[streamNumber];
     for (int i = 0; i < streamNumber; ++i) {
         blendWeight[i].streamWeight = 0.0f;
         blendWeight[i].playSpeed  = 0.0f;
         blendWeight[i].clipLength = streamClips[i].length;
     }
     ```

4. 调用动作融合函数[UpdateBlendState](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/skeletonanimationinterface-0000001156971985#section1350194774313)。

   ```screen
   skeletonAnimation->UpdateBlendState(joyStickInfo, characterStateInfo, blendWeight, streamNumber);
   ```

## 脚部IK

1. 加载动态库文件。
   * PC端（Windows 10）链接SkeletonAnimation.dll动态库。
   * 移动端（Android）链接libSkeletonAnimation.so动态库。
2. 创建[SkeletonAnimationInterface](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/skeletonanimationinterface-0000001156971985)的对象指针。

   ```screen
   SkeletonAnimationInterface* skeletonAnimation = CreateSkeletonAnimationInstance();
   ```

3. 初始化脚部IK参数。
   * 初始化摇杆参数[JoystickInfo](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/joystickinfo-0000001156813827)。

     ```screen
     JoystickInfo joyStickInfo;
     joyStickInfo.horizontalAxis = axisHor;
     joyStickInfo.verticalAxis = axisVer;
     ```

   * 初始化骨骼相关参数[SkeletonInfos](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/skeletoninfos-0000001110493950)。

     ```screen
     // 创建SkeletonInfos对象
     SkeletonInfos skeletonInfo;

     // 获取骨骼点坐标
     for (int i = 0; i < SKELETON_JOINT_NUM; ++i) {
         skeletonInfo.skeletonData[i].Position.x = transforms[i].position.x;
         skeletonInfo.skeletonData[i].Position.y = transforms[i].position.y;
         skeletonInfo.skeletonData[i].Position.z = transforms[i].position.z;

         skeletonInfo.skeletonData[i].gRotation.w = transforms[i].rotation.w;
         skeletonInfo.skeletonData[i].gRotation.x = transforms[i].rotation.x;
         skeletonInfo.skeletonData[i].gRotation.y = transforms[i].rotation.y;
         skeletonInfo.skeletonData[i].gRotation.z = transforms[i].rotation.z;

         skeletonInfo.skeletonData[i].lRotation.w = transforms[i].localRotation.w;
         skeletonInfo.skeletonData[i].lRotation.x = transforms[i].localRotation.x;
         skeletonInfo.skeletonData[i].lRotation.y = transforms[i].localRotation.y;
         skeletonInfo.skeletonData[i].lRotation.z = transforms[i].localRotation.z;
     }

     // 获取左脚射线交点
     skeletonInfo.rayInfo[0].hit = isLeftHit;
     skeletonInfo.rayInfo[0].hitPoint = Vector3d(hitLeftFoot.point.x, hitLeftFoot.point.y, hitLeftFoot.point.z);
     skeletonInfo.rayInfo[0].hitNormal = Vector3d(hitLeftFoot.normal.x, hitLeftFoot.normal.y, hitLeftFoot.normal.z);

     // 获取右脚射线交点
     skeletonInfo.rayInfo[1].hit = isRightHit;
     skeletonInfo.rayInfo[1].hitPoint = Vector3d(hitRightFoot.point.x, hitRightFoot.point.y, hitRightFoot.point.z);
     skeletonInfo.rayInfo[1].hitNormal = Vector3d(hitRightFoot.normal.x, hitRightFoot.normal.y, hitRightFoot.normal.z);

     // 获取踝关节目标位置
     skeletonInfo.targetPoint = new Vector3d[SKELETON_LEG_NUM]{0.0f};
     skeletonInfo.footHeight = footHeight;
     skeletonInfo.footAngle = ankleAdjustAngle;
     skeletonInfo.pelvisOffset = Vector3d(0.0f, 0.0f, 0.0f);
     ```

4. 调用脚部IK函数[UpdateFootIKState](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/skeletonanimationinterface-0000001156971985#section1124213454448)。

   ```screen
   skeletonAnimation->UpdateFootIKState(joyStickInfo, skeletonInfo);
   ```
