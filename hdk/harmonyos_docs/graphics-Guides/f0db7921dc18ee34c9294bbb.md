# 添加权限

* 原子化接口SDK 如需使用从外部存储中读取素材，需要申请READ_EXTERNAL_STORAGE权限。

  ```
  <uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />
  ```

* 场景化接口SDK 如需使用从外部存储中读取素材，需要申请READ_EXTERNAL_STORAGE权限。

  ```
  <uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />
  ```

  ARView与FaceView特性需要使用Camera权限。

  ```
  <uses-permission android:name="android.permission.CAMERA" />
  ```
