# 测试模型表情动画

1.将制作绑定完成的模型交付给测试进行视觉效果、表情跟随和位置大小的调试，保证颜色正常显示，大小合适，表情可正常加载。

建议检查：

模型大小是否合适

模型效果是否符合预期

2.模型大小调整

素材开发人员需要对开发的模型调整大小和位置，已满足人脸贴合要求，具体操场流程如下：

* 3D素材文件格式FBX转GLB或GLTF。

* 导入GlB或GLTF文件到模型制作工具里调整素材位置和大小，使其与真实人头大小进行匹配。
