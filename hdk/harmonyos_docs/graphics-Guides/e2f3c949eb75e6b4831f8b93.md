# 开发准备

1. 下载[时域抗锯齿插件SDK](https://developer.huawei.com/consumer/cn/doc/development/graphics-Library/sdk-download-0000001050441521)，并解压。压缩包内包含头文件和库文件。

   库文件包含PC端运行的动态链接库".dll"文件和Android平台运行的动态链接库".so"文件。
2. 调用时域抗锯齿插件前，需要添加打点功能依赖aar包，可以通过修改代码工程的应用级build.gradle文件来实现，任意aar包版本号均可。

   ```screen
   implementation 'com.huawei.hms:stats:4.0.3.302'
   ```
