# 使用入门

#### 开发环境

* 在华为终端设备上的应用市场下载XRKit服务端APK（需在华为应用市场，搜索"华为XRKit"）并安装到终端设备。

<!-- -->

* JDK 1.8.211及以上。
* 安装Android Studio 3.0及以上：

  * minSdkVersion 27及以上
  * targetSdkVersion 31（推荐）
  * compileSdkVersion 31（推荐）
  * Gradle 6.1.1及以上（推荐）
* 测试应用的设备：参见[XRKit特性依赖表](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/xrkit-features-0000001071810474)。

如果同时使用多个HMS Core的服务，则需要使用各个Kit对应的最大值。  

#### 开发流程

您需要按照如下流程完成应用的开发工作。  

|序号|步骤|说明|
|:-|:---------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[开发准备](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/xrkit-preparations-0000001064580890)|在开发应用前，需要进行以下操作： 1. 配置相关信息。包括：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/xrkit-preparations-0000001064580890#section1877217473310)、[创建应用](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/xrkit-preparations-0000001064580890#section177745415332)。 2. 将XRKit SDK集成到您的开发环境中。|
|2|[应用开发](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/xrkit-dev-guide-java-0000001064620957)|您可以根据[模型文件制作](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/xrkit-dev-guide-java-0000001064620957#section154841268114)、[运行前验证](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/xrkit-dev-guide-java-0000001064620957#section17961103343110)、[创建AR场景](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/xrkit-dev-guide-java-0000001064620957#section1546123203613)、[绑定视图到应用布局](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/xrkit-dev-guide-java-0000001064620957#section1715112642711)、[选择模式](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/xrkit-dev-guide-java-0000001064620957#section128953516321)、[设置场景](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/xrkit-dev-guide-java-0000001064620957#section122751841173610)流程，来实现AR展示场景或AR人脸场景。|
|3|[开发后自检](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/pre-release-check-0000001064060805)|华为提供对应用自动检查的能力。|
|4|[上架申请](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/app-release-0000001137249249)|开发完成后需要在AppGallery Connect中将应用信息补充完整并提交上架申请。|
