# 应用上传规范

## 物料清单

VR应用物料包括开发者联盟"管理中心>应用市场"上传和需打包在APK中的两部分，请务必完整上传及打包，否则会导致应用显示异常。

**需**上传：VR应用封面、VR应用推荐图片、VR应用截图、VR应用全景图四类图片。

|名称|数量|比例|分辨率|格式|大小|出现位置|
|:--------------|:---|:--------|:-----------------|:-----------|:------|:---------------------|
|应用介绍截图|至少3张|16:9/9:16|800*450/450*800|jpg/jpeg|2M以内|华为应用市场, 华为VR|
|VR应用封面|1|16:9|960*540|png/jpg/jpeg|1M以内|华为VR应用市场(3D侧)|
|VR应用封面(分层)|2|16:9|960*540|png|1M以内|华为VR应用市场(3D侧)|
|VR应用截图|至少3张|16:9|1920*1080/1280*720|png/jpg/jpeg|1M以内|华为VR应用市场(3D侧)|
|VR应用推荐图片7:10|1|7:10|414*573|png|500KB以内|Launcher(3D侧 兼容上一代界面)|
|VR应用推荐图片4:3(分层)|2|4:3|720*540|png|1M以内|Launcher&华为VR应用市场(3D侧)|
|VR应用推荐图片1:1(分层)|2|1:1|540*540|png|1M以内|华为VR应用市场(3D侧)|
|应用全景图|1|2:1|4096*2048|png/jpg/jpeg|10MB以内|华为VR应用市场(3D侧)|
[**表1**物料上传清单]

需打包在APK中：分层方案与不分层方案可二选一，建议选择分层方案,各模块VR应用封面效果保持统一。

|名称|数量|比例|分辨率|格式|大小|出现位置|备注|
|:---------|:-|:---|:------|:--|:------|:-----------|:--------------------------------------------------------|
|VR应用封面|1|16:9|576*324|png|200KB以内|内容库(3D侧&2D侧)|命名:vr_icon.png|
|VR应用封面(分层)|2|16:9|576*324|png|200KB以内|内容库(3D侧&2D侧)|前景图命名:vr_icon_foreground.png 背景图命名:vr_icon_background.png|
[**表2**打包清单]

为了在应用商店中正常显示应用图标，请严格按照以下标准操作：

图标的存放路径：

Unity：Unity3D工程目录Assets/StreamingAssets/

Unreal：图标需要存放在Unreal工程目录下，并在APL文件中添加如下语句（也可以直接修改HuaweiVRSDK_APL.xml）：

```screen
<copyFile src="$S(PluginDir) /vr_icon.png" dst="$S(BuildDir)/assets/vr_icon.png" />
```

即只要保证名称为vr_icon.png的图标文件存放在APK的assets目录下即可。

## 物料说明

需上传的物料主要包括 VR应用封面、VR应用推荐图片、VR应用截图、VR应用全景图四种类型。

VR应用封面:展示在内容库,一个清晰、易识别、稳定的形象会给用户留下深刻的印象，并便于再次寻找。

VR应用推荐图片: 展示在首页，可以有更多的运营性质，激发用户兴趣。

VR应用截图: 展示在应用详情，可以让用户初步了解应用主要场景及价值点，制作精良的应用截图会提升应用的品质感，并进一步促使用户产生下载行为.。这一部分也允许您上传展示视频，因为视频能够生动的展示出应用的故事线并传递更多信息。

VR应用全景图:主要展示在应用详情，相比平面图片可以让用户直接沉浸在您的应用场境中，帮助用户预览场景。

以下就对物料中分层图片和360度全景图片进行详细的说明：

### 图片分层方法

VR应用封面和VR应用推荐图片由于添加了错层动画和视差动画，前景层和背景层需分层输出、上传。

视差动效:

在手柄射线悬浮状态时，卡片的背景层会放大至110%，超出卡片的10%区域中的信息将隐藏。

## 应用开发要求

* 应用能够正确从华为VR Launcher启动，能够正确退出到华为VR Launcher。
* 对手柄的使用符合HUAWEI VR眼镜体感手柄使用指南。
* LOADING界面如果存在，必须是双目的（使用Unity专业版本发布）。
* 应用申请了存储及手柄权限，需要存储权限进行应用中截图，手柄权限查看androidManifest.xml是否有com.huawei.vrhandle.permission.DEVICE_MANAGER权限。
* 应用使用时体验流畅，内存峰值不超过1G，使用中外壳温度峰值不超过43度，应用加载及过度界面时间不应超过5s。
* 应用上传分类选择应用-XX，资质、版权、版号详细规定参见文档：[资质审核要求](https://developer.huawei.com/consumer/cn/doc/80301)。
