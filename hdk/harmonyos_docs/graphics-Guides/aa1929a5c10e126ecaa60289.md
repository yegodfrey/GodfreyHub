# 集成PerfGenius SDK

## 创建Android Studio工程

1. 创建Android Studio工程。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210901151407.88319693697649782014123117626048:50520901021411:2800:8E8BA8B2A9001E5342A560F073F5C344A8454068626B27F1F3CA442F4F1A72AD.png?needInitFileName=true?needInitFileName=true)
2. 选择工程模板类型为"Native C++"。
3. 根据实际需要修改包名，选择"Language"类型为"Java"，"Minimum SDK"（最低SDK版本）为"API 24：Android 7.0"。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210901151407.00238643195048148195845330277872:50520901021411:2800:45D69A6BAC37E3E3B6928E202D696C3D851101876922E5748A6F4DC6185404E2.png?needInitFileName=true?needInitFileName=true)
4. 如果无特殊要求，可使用默认标准"Toolchain Default"，点击"Finish"。

## 修改配置参数

### PerfGenius

1. 修改"/app/build.gradle"文件，设置libs路径和NDK编译标志位，目前只支持64位架构。
   * 在"android > defaultConfig > externalNativeBuild"中新增NDK编译标志位，配置格式如下：

     ```screen
     ndk {
         abiFilters 'arm64-v8a'
     }
     ```

   * 在"dependencies"中设置libs路径，配置格式如下：

     ```screen
     implementation fileTree(dir: "libs", include: ["*.jar"])
     ```

2. 配置SDK资源文件。

   将SDK中PerfGeniusApi.h头文件复制到"src/main/cpp/include"下，libPerfgeniusApi.so复制到libs/arm64-v8a下。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210901151407.64123799432531789906660035588482:50520901021411:2800:12714C7227813E4340262F1DD975592F99F70985494C3B45476A3838216CFBBA.png?needInitFileName=true?needInitFileName=true)
3. 配置HMS平台打点功能。
   1. 打开Android Studio项目级"build.gradle"文件。

      ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210901151407.91213707479313451055840412721145:50520901021411:2800:711901D972DBECBA78C7B086ACFF5BC9AB10EE10AD2C5303E0D36EE8A4B73AF5.png?needInitFileName=true?needInitFileName=true)
   2. 添加Maven代码库。
      * 在"buildscript > repositories"中配置HMS Core SDK的Maven仓地址。
      * 在"allprojects > repositories"中配置HMS Core SDK的Maven仓地址。

      ```screen
      buildscript {
          repositories {
              google()
              jcenter()
              // 配置HMS Core SDK的Maven仓地址。
              maven {url 'https://developer.huawei.com/repo/'}
          }
      }

      allprojects {
          repositories {
              google()
              jcenter()
              // 配置HMS Core SDK的Maven仓地址。
              maven {url 'https://developer.huawei.com/repo/'}
          }
      } 
      ```

      Gradle 7.0版本后，"allprojects > repositories"配置已迁移到项目级"settings.gradle"文件中。

      "settings.gradle"文件配置示例如下：

      ```screen
      dependencyResolutionManagement {
          ...
          repositories {
              google()
              jcenter() 
              maven {url 'https://developer.huawei.com/repo/'}
          }
      }
      ```

   3. 修改代码工程的应用级build.gradle文件，添加打点功能依赖jar包，任意jar包版本号均可。

      ```screen
      implementation 'com.huawei.hms:stats:5.0.4.301'
      ```

      ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210901151408.79027284554991507089846706509479:50520901021411:2800:6E54297A4F6292ACFAC58C3BFE18231A7564968D05F0B7CDD25C87CD61FB3B61.png?needInitFileName=true?needInitFileName=true)
4. 修改CMakeLists.txt文件，设置编译参数，全部参数内容如下。

   ```screen
   cmake_minimum_required(VERSION 3.4.1)
   # add head file of libPerfgeniusApi.so
   include_directories(src/main/cpp/include/)
   # set the source file of libmain-lib.so
   add_library(
           main-lib
           SHARED
           source/main.cpp)
   # add 64 bit libc++_shared.so, needed by libPerfgeniusApi.so
   add_library(
           c++_shared
           SHARED
           IMPORTED)
   set_target_properties(
           c++_shared
           PROPERTIES IMPORTED_LOCATION
           ${CMAKE_SOURCE_DIR}/../../../libs/${ANDROID_ABI}/libc++_shared.so)
   # add libPerfgeniusApi.so
   add_library(
           PerfgeniusApi
           SHARED
           IMPORTED)
   set_target_properties(
           PerfgeniusApi
           PROPERTIES IMPORTED_LOCATION
           ${CMAKE_SOURCE_DIR}/../../../libs/${ANDROID_ABI}/libPerfgeniusApi.so)
   find_library(
           log-lib
           log)
   target_link_libraries(
           main-lib
           PerfgeniusApi
           ${log-lib})
   ```

5. 同步工程，点击"Sync Project with Gradle Files"即可。

### Hrdelay

1. 配置应用级gradle文件。

   修改"/app/build.gradle"文件，设置libs路径和NDK编译标志位，目前只支持64位和32位架构。
   * 在"android > defaultConfig > externalNativeBuild"中新增NDK编译标志位，配置格式如下：

     ```screen
     ndk {
         abiFilters "arm64-v8a","armeabi-v7a"
     }
     ```

   * 在"dependencies"中设置libs路径，配置格式如下：

     ```screen
     implementation fileTree(dir: "libs", include: ["*.jar"])
     ```

2. 配置SDK资源文件。
   1. 配置SDK头文件： 将SDK中hrdelay.h头文件复制到"src/main/cpp/include"下。

   2. 配置SDK so文件： Hrdelay功能只支持arm64-v8a和armeabi-v7a架构。在"/app/libs"目录下创建arm64-v8a和armeabi-v7a目录。

      * 将SDK中"/lib64"目录下的"libhrdelay.so"和"libhrdelay_stat.so"复制到Android Studio下的"/libs/arm64-v8a"。
      * 将SDK中"/lib"目录下的"libhrdelay.so"和"libhrdelay_stat.so"复制到Android Studio下的"/libs/armeabi-v7a"。
3. 配置HMS平台打点功能。
   1. 打开项目级"build.gradle"文件并修改。

      添加Maven代码库。
      * 在"buildscript > repositories"中配置HMS Core SDK的Maven仓地址。
      * 在"allprojects > repositories"中配置HMS Core SDK的Maven仓地址。

      ```screen
      maven {url 'https://developer.huawei.com/repo/'}
      ```

      ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210901151408.84786183981746893578999366964345:50520901021411:2800:2D547B4A71DA40AEADD12F74B6D46DFF4D83583473C2AEBEC08171389E3B1C60.png?needInitFileName=true?needInitFileName=true "点击放大")

      Gradle 7.0版本后，"allprojects > repositories"配置已迁移到项目级"settings.gradle"文件中。

      "settings.gradle"文件配置示例如下：

      ```screen
      dependencyResolutionManagement {
          ...
          repositories {
              google()
              jcenter() 
              maven {url 'https://developer.huawei.com/repo/'}
          }
      }
      ```

   2. 打开应用级"build.gradle"文件并修改。
      * 添加c++_shared声明。由于Hrdelay打点功能依赖于c++库，因此需要在cmake构建参数中声明使用c++_shared，否则打点功能将无法工作。

        ```screen
        cmake {
            cppFlags ""
            arguments "-DANDROID_STL=c++_shared"
        }
        ```

      * 添加打点功能依赖jar包。

        ```screen
        implementation 'com.huawei.hms:stats:5.2.0.301'
        ```

      ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210901151408.69663691660412238613999048051737:50520901021411:2800:B2F2DD19DFF84BEBCBA1B0FB85EF825D3976F3DA977EA33375BB236A62AC03F9.png?needInitFileName=true?needInitFileName=true)
4. 修改CMakeLists.txt文件，设置编译参数，全部参数内容如下。

   ```screen
   cmake_minimum_required(VERSION 3.4.1)
   include_directories(src/main/cpp/include/)
   # set the source file of libnative-lib.so
   add_library(
           native-lib
           SHARED
           native-lib.cpp)

   # add libhrdelay.so
   add_library(
           hrdelay
           SHARED
           IMPORTED)
   set_target_properties(
           hrdelay
           PROPERTIES IMPORTED_LOCATION
           ${CMAKE_SOURCE_DIR}/../../../libs/${ANDROID_ABI}/libhrdelay.so)

   # add libhrdelay_stat.so
   add_library(
           hrdelay_stat
           SHARED
           IMPORTED)
   set_target_properties(
           hrdelay_stat
           PROPERTIES IMPORTED_LOCATION
           ${CMAKE_SOURCE_DIR}/../../../libs/${ANDROID_ABI}/libhrdelay_stat.so)

   find_library(
           log-lib
           log)
   target_link_libraries(
           native-lib
           hrdelay
           hrdelay_stat
           ${log-lib})
   ```

5. 同步工程，点击"Sync Project with Gradle Files"即可。

## 配置混淆脚本

您编译APK前需要配置混淆配置文件，避免混淆HMS Core SDK导致功能异常。Android Studio开发环境里的配置文件是"proguard-rules.pro"。

1. 打开工程的混淆配置文件"proguard-rules.pro"。
2. 加入排除HMS Core SDK的混淆配置，具体配置参数如下。

   ```screen
   -ignorewarnings
   -keepattributes *Annotation*
   -keepattributes Exceptions
   -keepattributes InnerClasses
   -keepattributes Signature
   -keepattributes SourceFile,LineNumberTable
   -keep class com.huawei.hianalytics.**{*;}
   -keep class com.huawei.updatesdk.**{*;}
   -keep class com.huawei.hms.**{*;}
   ```
