# 个人数据处理说明

此文档针对华为作为最终用户数据处理者，开发者作为最终用户数据控制者的数据处理进行说明，包括：

* 华为处理的个人数据清单。

* 指导开发者如何帮助最终用户实现对数据的控制。

#### 华为处理的个人数据清单

|个人数据清单|使用目的|存留期|
|:----------|:--------------------------------|:-----------------------------------------|
|相机捕获的图像|通过相机捕获的图像信息来实现运动跟踪、人脸跟踪等AR能力。|相机捕获到的图像只在端侧处理，处理完成后即销毁，不会留存，也不会涉及数据上传。|
|人脸信息|通过分析相机捕获的人脸信息，来实现面部特征识别，提供面部AR能力。|相机捕获到的人脸信息只在端侧处理，处理完成后即销毁，不会留存，也不会涉及数据上传。|
|3D模型文件与素材文件|从外部存储读取的3D模型文件与素材文件，用于图形渲染。|3D模型文件与素材文件只在端侧处理，处理完成后即销毁，不会留存，也不会涉及数据上传。|

#### 指导开发者如何帮助最终用户实现对数据的控制

图形引擎服务涉及的相机图像数据、3D模型文件与素材文件只在端侧设备处理，不储存个人数据；由数据控制者面向最终用户提供相应的数据主体权利及其相关解释。
