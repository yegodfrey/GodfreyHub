# 中心注视点渲染适配

中心注视点渲染保证中心区域清晰度高于边缘区域，在插件中设置如下：

* 将HuaweiVRSDK内容/BluePrints/HuaweiVRCamera蓝图拖入游戏关卡中。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220519145810.30413354935315158551894013370966:50530518075906:2800:DFBDC041C65D8286C9DCABE9508EB907372B3286FC20B59B45073C22E3EA17B4.png?needInitFileName=true?needInitFileName=true "点击放大")

<!-- -->

* 选中HuaweiVRCamera，在Auto Possess Player，设置Player 0。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220519145810.26576310327863252789669643873817:50530518075906:2800:E642745239BB457F6D0EBEC4782D533CE1B3A7DF169FECE8167B470DC8731495.png?needInitFileName=true?needInitFileName=true "点击放大")

<!-- -->

* 在Project Settings-Platforms-Android设置OpenGL ES支持类型，选中OpenGL ES 3.1。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220519145810.72016733418744718352079550078970:50530518075906:2800:4CE43E997BB492DBF9B1F392B1F7F90BEED2B05DD92EE0C7330A417C354E6CBF.png?needInitFileName=true?needInitFileName=true "点击放大")

* 在Project Settings-Engine-Rendering-Mobile，去掉HDR勾选，在VR项，勾选Mobile Multi-View，Mobile Multi-View Direct。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220519145810.38227851727329537413987253306286:50530518075906:2800:95A19ADB959F6CF14C2A1A20464A17B7CF6BFB7624D3BB082A37C55A764776E5.png?needInitFileName=true?needInitFileName=true "点击放大")

* 更改图像渲染分辨率，分辨率有三种选择720\*720，1080\*1080，1280\*1280，具体在void FHuaweiVRSDK::SetRenderSize(int width, int height)进行设置。
