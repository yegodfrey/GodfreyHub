# 关键帧动画

CG Kit提供关键帧动画功能来实现渲染绘制过程中的动画效果，例如位置变化、缩放、旋转、颜色动态变化、透明度变化以及曲线移动的效果。  

#### 使用约束

* 颜色动态变化效果使用[动态材质](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/dynamic-materials-0000001151598860)功能实现，shader里的uniform name是"MaterialColorInfo"，而且shader必须使用如下配置。

  ```
  layout(set=0, binding=9) uniform MaterialColorInfo
  {
      vec4 color;
  } materialColorInfo
  layout(set=0, binding=6) uniform DiffuseColor
  {
      vec4 color;
  } diffuseColor;

  layout(location=0) out vec4 color;

  void main()
  {
      color = materialColorInfo.color/255 * diffuseColor.color;
  }
  ```

* 透明度变化效果需要在[cgmat](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/cgmat-configuration-file-0000001106071566)文件的resource节点下配置uniform name是"DiffuseColor"和它的初始值。
  * 不透明：\[x, y, z, 1.0\]。（x、y、z为任意值）
* 透明：\[x, y, z, 0.0\]。（x、y、z为任意值）  

#### 使用关键帧动画

#### 位置变化

调用[GetTweenTransMove](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/tweenmanager-0000001198478027#section2044260142518)接口实现模型的位置变化。

```
m_cubeObject = CreateObject("models/test-cube.obj", "material/materialcube.cgmat");
m_cubeObject->SetScale(Vector3(2.0f, 2.0f, 2.0f));
m_cubeObject->SetPosition(Vector3(0.0f, -10.0f, 0.0f));
MeshRenderer* meshRenderer = m_cubeObject->GetComponent<MeshRenderer>();
Transform* transform = m_cubeObject->GetComponent<Transform>();
Vector3 positionTo = Vector3(0,4,0);
f32 duration = 2.0;
gTweenManager.GetTweenTransMove(*transform, positionTo, duration);
```

#### 缩放

调用[GetTweenTransScale](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/tweenmanager-0000001198478027#section35654511261)接口实现模型的放大缩小效果。

```
m_cubeObject = CreateObject("models/test-cube.obj", "material/materialcube.cgmat");
m_cubeObject->SetScale(Vector3(2.0f, 2.0f, 2.0f));
m_cubeObject->SetPosition(Vector3(0.0f, -10.0f, 0.0f));
MeshRenderer* meshRenderer = m_cubeObject->GetComponent<MeshRenderer>();
Transform* transform = m_cubeObject->GetComponent<Transform>();
Vector3 rotationTo = Vector3(0,4,4);
f32 duration = 2.0;
gTweenManager.GetTweenTransScale(*transform, rotationTo, duration);
```

#### 旋转

调用[GetTweenTransRotate](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/tweenmanager-0000001198478027#section578094012519)接口实现模型的旋转效果。

```
m_cubeObject = CreateObject("models/test-cube.obj", "material/materialcube.cgmat");
m_cubeObject->SetScale(Vector3(2.0f, 2.0f, 2.0f));
m_cubeObject->SetPosition(Vector3(0.0f, -10.0f, 0.0f));
MeshRenderer* meshRenderer = m_cubeObject->GetComponent<MeshRenderer>();
Transform* transform = m_cubeObject->GetComponent<Transform>();
Vector3 scaleTo = Vector3(0.33f,0.55f,0.55f);
f32 duration = 2.0;
gTweenManager.GetTweenTransRotate(*transform, scaleTo, duration);
```

#### 颜色动态变化

调用[GetTweenMaterialsColor](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/tweenmanager-0000001198478027#section1741003619261)接口实现材质的颜色动态变化效果。

```
m_cubeObject = CreateObject("models/test-cube.obj", "material/materialcube.cgmat");
m_cubeObject->SetScale(Vector3(2.0f, 2.0f, 2.0f));
m_cubeObject->SetPosition(Vector3(0.0f, -10.0f, 0.0f));
MeshRenderer* meshRenderer = m_cubeObject->GetComponent<MeshRenderer>();
MaterialInstance* materialInstance = meshRenderer->GetMaterialInstances()[0];
Color green = Color::GREEN;
f32 duration = 2.0;
gTweenManager.GetTweenMaterialsColor(*materialInstance, green, duration);
```

#### 透明度变化

调用[GetTweenDiffuseColor](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/tweenmanager-0000001198478027#section16754950182713)接口实现材质透明度的变化。

```
m_cubeObject = CreateObject("models/test-cube.obj", "material/materialcube.cgmat");
m_cubeObject->SetScale(Vector3(2.0f, 2.0f, 2.0f));
m_cubeObject->SetPosition(Vector3(0.0f, -10.0f, 0.0f));
MeshRenderer* meshRenderer = m_cubeObject->GetComponent<MeshRenderer>();
MaterialInstance* materialInstance = meshRenderer->GetMaterialInstances()[0];
Vector4 diffuseColor = Vector4(1, 1, 1, 0);
f32 duration = 2.0;
gTweenManager.GetTweenDiffuseColor(*materialInstance, diffuseColor, duration);
```

#### 曲线移动

调用[GetTweenPath](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/tweenmanager-0000001198478027#section3112112102712)接口实现路径曲线移动的效果。曲线路径计算是根据Catmull-Rom曲线的公式计算得出的结果。

```
m_cubeObject = CreateObject("models/test-cube.obj", "material/materialcube.cgmat");
m_cubeObject->SetScale(Vector3(2.0f, 2.0f, 2.0f));
m_cubeObject->SetPosition(Vector3(0.0f, -10.0f, 0.0f));
MeshRenderer* meshRenderer = m_cubeObject->GetComponent<MeshRenderer>();
Transform* transform = m_cubeObject->GetComponent<Transform>();
std::vector<Vector3> wps;
wps.resize(4);
wps[0] = Vector3(0, 0, 4);
wps[1] = Vector3(3, 1, 4);
wps[2] = Vector3(0, 2, 4);
wps[3] = Vector3(-3, 2, 4);
f32 duration = 2.0; 
gTweenManager.GetTweenPath(*transform, wps, duration);
```
