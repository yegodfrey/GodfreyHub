# FAQ

如果您在下面没有找到需要的问题，请加入[Stack Overflow](https://stackoverflow.com/questions/tagged/huawei-mobile-services?tab=Newest)社区参与讨论。

## 开发准备常见问题

### 如何获取图形引擎服务的能力？

如果您的设备满足[支持的设备](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/service-introduction-0000001050163355#section134581494535)中所述的限制条件，您可以通过集成图形引擎服务原子化接口SDK或场景化接口SDK，就能够获取图形引擎服务提供的渲染能力。详情请参见[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/integrating-sdk-0000001063754635)。

### 图形引擎服务提供的原子化接口SDK与场景化图形接口SDK有什么区别？

图形引擎服务的原子化接口SDK提供了功能丰富、自由度高的图形API供开发者使用。您可以根据自己的需求打造各种各样的图形应用。

场景化接口SDK提供了低自由度但高度封装、简单易用的图形API，能够在特性场景中通过少量代码即可完成特定功能的实现。

您可根据自身需求选用不同的SDK，但两者无法同时使用。

### 图形引擎服务场景化接口中的SDK与Full-SDK有什么区别？

通过场景化接口SDK接入，仅支持特定机型的华为终端设备，并且需要安装HMS Core（APK）4.0.2.300及以上版本。

通过场景化接口Full-SDK接入，可不依赖HMS Core（APK）进行使用，具体支持的设备类型请参见[支持的设备](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/service-introduction-0000001050163355#section134581494535)。

### 图形引擎服务是否收费？

图形引擎服务所有SDK当前提供的所有接口均免费。

### 图形引擎服务是否涉及用户隐私？

图形引擎服务涉及的用户隐私数据包括：相机捕获的图像、用户人脸信息、3D模型文件与素材文件。

以上数据均只在端侧处理，处理完成后即销毁，不储存个人数据，也不涉及数据上传。

详情请参见[个人数据处理说明](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/personal-data-0000001052569929)。

## 开发过程常见问题

### 原子化接口SDK扩展包有什么作用？

若只集成原子化接口SDK主体包，则应用只能运行在华为终端设备上，且需要依赖HMS Core（APK）。

若同时集成原子化接口SDK主体包与扩展包，则应用能够运行在非华为终端设备上，拥有更高的性能，且可不依赖HMS Core（APK），但会增加应用体积。

### EMUI 8.1之前版本或Android 8.1之前版本使用Vulkan后端进行渲染时，无法加载素材？

老版本手机在使用Vulkan后端进行渲染，可能出现无法加载素材的情况，请切换到GLES后端进行渲染。

### 加载3D模型素材，为什么无法显示或显示效果与预期不符？

* 请检查3D模型素材加载路径的正确性。
* 请检查3D模型素材的正确性，若素材本身存在问题，将会导致素材加载后无法显示或显示效果与预期不符。3D模型素材可使用[glTF Viewer](https://gltf-viewer.donmccurdy.com/)进行查验。

如您使用glTF格式素材进行渲染，请额外检查：

* glTF素材文件中"images"项中"URI"的地址路径是否正确，并检查贴图素材类型是否被当前版本的图形引擎服务支持。
* glTF素材文件中"images"项中"bufferView"对应的mimeType的类型是否被当前版本的图形引擎服务支持。 说明
  >
  > 图形引擎服务当前版本暂不支持glTF素材文件中"light"、"camera"字段的解析与显示，后续版本将会陆续支持此功能。

### 为什么加载部分3D模型素材时出现进程被终止、渲染出现卡顿或错误等异常现象？

由于手机硬件限制，部分超大3D模型素材的加载与渲染可能出现异常。

为了保证渲染效果与用户体验，当前版本中：

* 3D模型的三角面片数量建议不大于500000。
* 3D模型的网格数量建议不大于500。
* 单个纹理贴图分辨建议不大于2048 * 2048。
* 纹理贴图数量：以分辨率大小为1024 * 1024的纹理贴图为例，建议不超过256张。

### 为什么同时使用Android Support包与原子化接口的UX包，会出现不兼容的错误？

原子化接口的UX包使用了AndroidX包的部分特性。由于AndroidX包与Android Support包无法兼容，导致出现错误。

推荐使用AndroidX包以解决不兼容问题。

如果您的应用无法使用AndroidX包，请在模块的build.gradle文件中将AndroidX的依赖排除。

```screen
    implementation ('com.huawei.scenekit:scenekit-ux-ar:{version}') {
        exclude group: 'androidx.core', module: 'core'
        exclude group: 'androidx.activity', module: 'activity'
    }
```

将AndroidX的依赖排除会导致某些类无法使用。当前版本中，权限校验类[PermissionUtil](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-permission-util-0000001071246334)将无法使用，请您自行进行权限校验。

### 如何减小图形引擎服务SDK的体积？

当前版本如果您的应用对体积大小有严格要求，可通过裁剪SDK的方式减小图形引擎服务的体积。

* 如您的应用无需使用32位arm指令集的动态链接库，可在"build.gradle"中将其裁剪：

  ```screen
  android {
      ....
      packagingOptions {
          exclude 'lib/armeabi-v7a/*.so'
      }
  }
  ```

* 如您的应用只使用"OpenGL ES"后端进行渲染，可将"Vulkan"后端进行裁剪：

  ```screen
  android {
      ....
      packagingOptions {
          ....
          exclude 'lib/arm64-v8a/libIGFXGlslConverter.so'
          exclude 'lib/arm64-v8a/libiGraphicsBackendVulkan.so'
      }
  }
  ```

### 使用场景化接口中的SceneView时，将3D模型素材加载进场景后，会默认放置到场景的什么位置，是否能够调整大小与位置？

当前版本图形引擎加载完3D模型素材后，会默认将素材放置在场景的中心位置。可以通过手势缩放调整3D模型的大小，当前版本暂时无法调整素材的位置，后续版本将支持此功能。

### 使用场景化接口中的SceneView时，调用loadSkyBox方法加载天空盒贴图素材，为什么没有效果？

如果您加载完天空盒背景贴图素材后，渲染显示的天空盒背景仍为默认的灰色背景，则需检查您加载的天空盒贴图素材的文件类型是否被当前版本所支持。

当前版本图形引擎服务支持dds格式cubemap类型的天空盒贴图素材，其他类型的素材暂不支持。若加载其他类型的天空盒贴图，将无法进行正常的渲染。

### 使用场景化接口中的SceneView时，调用loadSpecularEnvTexture、loadDiffuseEnvTexture方法加载环境光贴图素材，为什么没有效果？

如果您加载完环境光贴图素材后，渲染显示的3D模型仍为默认的暗色效果，则需检查您加载的环境光贴图素材的文件类型是否被当前版本所支持。

当前版本图形引擎服务支持dds格式cubemap类型的环境光贴图素材，其他类型的素材暂不支持。若加载其他类型的环境光贴图，将无法进行正常的渲染。

### 使用场景化接口中的ARView时，如何移动、旋转、缩放放置在平面上的物体？

当单指点击选取物体时，物体的颜色变为红色，即处于被选取状态。

移动：当物体处于被选取状态时，通过单指滑动即可移动物体。

旋转：当物体处于被选取状态时，通过两指操作，一个手指点击物体，另一手指水平方向滑动，即可旋转物体。

缩放：当物体处于被选取状态时，通过两指非水平方向缩放滑动即可缩放物体。

### 使用场景化接口中的ARView时，在场景中最多能够添加多少个素材物体？

当前版本支持场景中最多加载10个物体。

### 使用场景化接口中的FaceView时，如何选择替换素材挂载的位置？

通过[LandmarkType](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-enum-landmark-0000001052165859)进行设置，可挂载在左右眼、鼻尖、左右嘴角位置。详情请参见[LandmarkType](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-enum-landmark-0000001052165859)。

### 使用场景化接口中的ARView或FaceView时，调用setInitialPose设置素材的初始位姿时，为什么显示与预期效果不符？

[ARView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-arview-0000001051923459)中，[setInitialPose](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-arview-0000001051923459#section71677110133)方法可传入scale、rotation参数：scale为float[3]数组，表示XYZ轴方向的缩放系数；rotation为float[4]数组，表示归一化的旋转四元数，分别为w、x、y、z。

[FaceView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-faceview-0000001052804698)中，[setInitialPose](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-faceview-0000001052804698#section71677110133)方法可传入pose、scale、rotation参数：pose为float[3]数组，表示XYZ轴的位置坐标；scale为float[3]数组，表示XYZ轴方向的缩放系数；rotation为float[4]数组，表示归一化的旋转四元数，分别为w、x、y、z。

详情请参见[场景化接口SDK](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-overview-0000001076767836)。

### 使用原子化接口中的ARView、FaceView或场景化接口中的ARView、FaceView时，为什么会显示黑屏或相机倒转等异常现象？

请检查使用设备的系统版本与设备型号是否满足受限说明中的相关限制，具体特性的受限情况请参见[支持的设备](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/service-introduction-0000001050163355#section134581494535)、[支持的设备列表](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/supported-devices-0000001058659954)。

原子化接口或场景化接口的FaceView特性中，如果使用AR Engine进行人脸检测，推荐将APP的"build.gradle"文件中*targetSdkVersion* 设置为28。如需使用更高版本的*targetSdkVersion*，需将AREngineServer版本升级至3.12.0或以上（当前AREngineServer 3.12.0版本只支持EMUI 11.x或HarmonyOS 2.0系列，后续版本将修复此问题），否则会出现黑屏等问题。

### 部分HarmonyOS 3.0机型在使用场景化接口SDK的ARView或FaceView时，会出现场景加载素材或切画面后出现黑屏现象，如何解决？

场景化接口在部分HarmonyOS 3.0机型存在兼容性问题，请使用原子化接口[ARView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-arview-0000001051923459)或[FaceView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-faceview-0000001052804698)接口进行替代。

### 同时使用原子化接口SDK和2D流体模拟SDK时，会出现"More than one file was found with OS independent path 'lib/XXX/libc++_shared.so'"的错误，如何解决？

可在App的"build.gradle"文件中添加"packagingOptions"节点。

```screen
android {
    ......
    packagingOptions {
        pickFirst 'lib/arm64-v8a/libc++_shared.so'
        pickFirst 'lib/armeabi-v7a/libc++_shared.so'
    }
    ......
}
```

### 在Android 11上，已经安装HMS Core（APK）最新版本，仍然提示升级，如何解决？

Android 11更改了应用查询用户在设备上已安装的其他应用以及与之交互的方式。您应用的*targetSdkVersion*是30或者更高版本，并且集成的Scene Kit 6.2.0.300之前版本时，将无法访问HMS Core（APK），并且持续提示升级。

您可通过以下方式解决：

* 方法一： 升级Scene Kit SDK至6.2.0.300及以上版本，版本信息请参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/version-change-history-0000001050138514)。

* 方法二： 如果不升级SDK，需要在"AndroidManifest.xml"中manifest下添加<queries>标签。

  ```screen
  <manifest ...>
      ...
      <queries>
          <intent>
              <action android:name="com.huawei.hms.core.aidlservice" />
          </intent>
      </queries>
      ...
  </manifest>
  ```

  > 说明
  >
  > <queries>标签对工具的要求如下：
  > * Android Studio需升级至3.3或更高版本。
  > * Android Gradle插件需升级至3.3.3、3.4.3、3.5.4、3.6.4、4.0.1或4.1.0及更高版本。
