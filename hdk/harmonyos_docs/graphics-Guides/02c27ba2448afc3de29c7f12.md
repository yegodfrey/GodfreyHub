# 版本更新说明

## 6.1.0.300（2021-08-27）

|----------------------------------------------------------------------------------------------------------------------------------------------------------|
|本次插件系统特性变更如下： **新增特性** 新增[AI捏脸插件](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/overview-0000001178847721)，提供适配不同游戏的AI捏脸方案。|

## 历史版本

### 6.0.0.300（2021-07-15）

|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|本次插件系统特性变更如下： **新增特性** * 新增[体积雾插件](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/overview-0000001156929847)，提供兼顾性能和质量的体积雾渲染方案。 * 新增[骨骼动画插件](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/overview-0000001156807933)，提供动作融合和脚部IK方案。 * 新增[时域抗锯齿插件](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/overview-0000001156329137)，提供高性能高画质的时域抗锯齿方案。 * 新增[智慧流体插件](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/overview-0000001158671977)，提供逼真的流体晃动仿真方案。|

### 5.2.0.303（2021-05-11）

|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|本次插件系统特性变更如下： **修改特性** * 针对体积云插件，对渲染算法进行升级，增加细节丰富程度和光照逼真度，提升渲染质量，同时可以支持更大范围的云海。 * 修改结构体[VolumeRenderParas](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/volumerenderparas-0000001077507556)参数。 * 修改体积云渲染类的名称，由RenderAPI改为[VolumeCloudRenderAPI](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/renderapi-0000001077502104)。 * 修改体积云渲染类实例化的接口函数名称，由CreateRenderAPI改为[CreateVolumeCloudRenderAPI](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/createrenderapi-0000001077508936)。 * 修改用来定义体积云渲染API接口的头文件名，由RenderAPI.h改为VolumeCloudRenderAPI.h。|

### 5.2.0.300（2021-02-26）

|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|本次插件系统特性变更如下： **新增特性** 新增[体积云插件](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/overview-0000001077661506)，为开发者提供云形态的定制，使玩家获得逼真的渲染结果并在云中进行穿梭。|

### 5.1.0.300（2020-12-24）

|------------------------------------------------|
|本次插件系统特性变更如下： **修改特性** 遮挡剔除插件修改版本适配问题，您无需采取任何措施。|

### 5.0.4.301（2020-11-16）

|-----------------------------------------------------|
|本次插件系统特性变更如下： **修改特性** 离线超分插件的AI超分能力新增对Kirin 9000的支持。|

### 5.0.4.300（2020-10-27）

|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|本次插件系统特性变更如下： **新增特性** * 新增插件开发特性，提供插件开发标准，使基于标准开发的插件可以接入CG Kit。 * 新增[离线超分插件](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/overview-0000001055879483)，提供游戏截图画质提升能力，提高画面分辨率，并改善画面细节，帮助您向玩家提供高质量截图功能。 * 新增[遮挡剔除插件](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/overview-0000001055452841)，提供在渲染前判断游戏场景中3D模型的可见性，裁剪掉不可见的三角形，减少不必要的渲染过程，降低整体功耗，提升渲染性能。|
