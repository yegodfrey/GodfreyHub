# 概述

图形引擎服务场景化接口针对特定场景提供了简单易用的接口。针对对应的场景，选用对应的视图。只需要额外添加少量代码即可快速完成开发。目前场景化接口提供了如下视图：

* [SceneView](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/scenario-sceneview-0000001064799076)：自适应模型渲染视图，适用于模型加载展示场景，如购物应用3D模型展示等。
* [ARView](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/scenario-arview-0000001064191000)：AR渲染视图，适用于后置相机AR渲染场景，如AR物体放置展示等。
* [FaceView](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/scenario-faceview-0000001063533225)：面部AR渲染视图，适用于前置相机面部AR渲染场景，如脸部检测模型替换等。
