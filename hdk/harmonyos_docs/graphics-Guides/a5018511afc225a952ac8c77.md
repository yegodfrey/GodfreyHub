# 使用入门

## 快速上手

在您正式开发应用之前，可以通过[Codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/HMSAccKit-PerfGenius)快速体验一个应用的开发过程。

## 开发环境

* JDK 1.8及以上
* 安装Android Studio 3.6及以上

  * minSdkVersion 24及以上
  * targetSdkVersion 33（推荐）
  * compileSdkVersion 33（推荐）
  * Gradle 5.0.0及以上

  如果同时使用多个HMS Core的服务，则需要使用各个Kit对应的最大值。
* 测试应用的设备：EMUI 11.0及以上的华为手机。

* 使用[CMake](https://cmake.org/download/) 3.10.2及以上进行Native代码编译。

## 开发流程

您需要按照如下流程完成应用的开发工作。

|序号|步骤|说明|
|:-|:---------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/con-appgal-0000001071567714)|在开发应用前，需要在AppGallery Connect中配置相关信息。包括：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/con-appgal-0000001071567714#section147105440196)、[创建应用](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/con-appgal-0000001071567714#section1284355810549)。|
|2|[集成PerfGenius SDK](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/integ-perfgenius-sdk-0000001054906476)|在开发应用前，您需要将PerfGenius SDK集成到您的开发环境中。|
|3|[应用开发](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/sample-code-develop-0000001055225066)|通过性能加速模块的代码调用示例，您将获得系统帧率调控，性能负载关键线程调控以及系统状态获取的能力。|
|4|[开发后自检](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/pre-release-check-0000001050748051)|华为提供对应用自动检查的能力。|
|5|[上架申请](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/app-release-0000001051055410)|开发完成后需要在AppGallery Connect中将应用信息补充完整并提交上架申请。|
