# 开发准备

1. 下载[AI捏脸插件SDK](https://developer.huawei.com/consumer/cn/doc/development/graphics-Library/sdk-download-0000001050441521)，并解压。压缩包内包含头文件、库文件以及资源文件。
   * 库文件包含PC端运行的动态链接库".dll"、".lib"文件以及Android平台运行的动态链接库".so"文件。
   * 资源文件（./assets）包含人脸三维重建基库（shape.bin）和捏脸参数推理模型文件（ModA.om、ModB.om、ModC.om）。


2. 调用AI捏脸插件前，需要添加打点功能依赖aar包，可以通过修改代码工程的应用级build.gradle文件来实现，任意aar包版本号均可。

   ```screen
   implementation 'com.huawei.hms:stats:5.2.0.301'
   ```
