# 新建工程、Android环境配置

1. 在Epic Games Launcher中启动已下载好的Unreal引擎，也可在下载好后创建快捷键方式直接启动。
2. 新建项目，可选择创建"蓝图"工程，也可选择创建"C++"工程；然后，根据需求选择模板；Android开发，故平台选择为"移动设备/平板电脑"，同时为提高运行性能，选择"可缩放的3D或2D"。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220817112806.84828947588967308161011088500197:50530816060109:2800:814D49F5583217622DE7F5D41F360D3E08E122CE33AAA356AE8F6F6C0434B4B0.png?needInitFileName=true?needInitFileName=true "点击放大")

3. 打开"菜单 > 编辑 > 项目设置 > 平台 > Android软件开发工具包"。配置Android开发必要的SDK、NDK、JDK的路径，其中SDK API Level选择matchndk，NDK API Level选择android-24。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220817112807.98355482403660970806397016842800:50530816060109:2800:2F1002B61C7B3F9E7DAF06A36959D37D7406B48EC071217CADD2F3DD95B6D54D.png?needInitFileName=true?needInitFileName=true "点击放大")
4. 在主界面菜单栏中依次进入"编辑 > 项目设置 > 平台 > Android"，在"Build"选项下，勾选 Support armv7[aka armeabi-v7a] 选项。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220817112807.56961319584153671311730663911482:50530816060109:2800:A7F16DA3EF5E45DA0FB0F99D2488490B77019D947F1C3D615A88CF719A424EB7.png?needInitFileName=true?needInitFileName=true "点击放大")

> 注意
>
> Android工程默认采用Gradle工具进行编译，如果在某些特殊情况下无法正常运行Gradle，可在配置选项中将"Enable Gradle instead of Ant"的勾选去掉，及采用Ant工具进行编译，当然采用Ant编译的前提是需要在Android软件开发工具包中正确配置Ant（可在Ant官网下载）目录。
