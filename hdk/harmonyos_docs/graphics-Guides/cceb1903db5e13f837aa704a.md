# （可选）3D流体

原子化接口支持3D流体模拟的组件。您可以使用该组件自定义流体边界范围，设置流体液量，最后实现能够与用户交互的3D流体晃动效果。本小节将介绍3D流体组件使用的开发步骤，完整示例代码请参考[原子化接口3D流体示例代码](https://developer.huawei.com/consumer/cn/doc/graphics-Examples/3d-fluid-demo-0000001256663038)。

3D流体组件只支持Vulkan渲染后端，需在原子化接口[初始化](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/fine-grained-init-0000001064110985)时，通过 [setGraphicsBackend](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-scenekit-property-builder-0000001061997746#section153781256109)接口将渲染后端类型[SceneKit.Property.GraphicsBackend](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-backend-0000001061092027)设置为VULKAN。  

#### 开发步骤

1. 新建渲染视图子类XRenderView，按照[布置场景](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/fine-grained-scene-0000001063841339)中的相关步骤，添加相机与灯光组件。

   <br />

   ```
   public class XRenderView extends RenderView {
       public XRenderView(Context context) {
           //...
           prepareScene();
       }
       //...
   }
   ```

   <br />

2. 在DemoActivity的onCreate方法中，添加渲染视图，并将其保存至局部变量。

   <br />

   ```
   public class DemoActivity extends Activity implements SensorEventListener {
       private XRenderView renderView;

       @Override
       protected void onCreate(@Nullable Bundle savedInstanceState) {
           super.onCreate(savedInstanceState);
           renderView = new XRenderView(this);
           setContentView(renderView);
           //...
       }
   }
   ```

   <br />

3. 添加createFluidScene方法用于流体场景布置。创建3D流体节点，添加3D流体组件。

   <br />

   ```
   private Node fluidNode;

   private void createFluidScene() {
       // 创建3D流体节点。
       fluidNode = renderView.getScene().createNode("fluidNode");
       // 添加3D流体组件。
       FluidComponent fluidComponent = fluidNode.addComponent(FluidComponent.descriptor());
   }
   ```

5. 注册传感器事件，获取加速度传感器信息。

   <br />

   ```
   private SensorManager sensorManager;
   private Sensor sensor;
   private int rotation;

   private void createFluidScene() {
       // ...

       sensorManager = (SensorManager)getSystemService(SENSOR_SERVICE);
       // 获取加速度传感器。

   @Override
   protected void onResume() {
       super.onResume();
       // 注册传感器事件。
       sensorManager.registerListener(this, sensor, SensorManager.SENSOR_DELAY_NORMAL);
       //...
   }

   @Override
   protected void onPause() {
       super.onPause();
       // 去注册传感器事件。
       sensorManager.unregisterListener(this);
       //...
   }
   ```

6. 复写传感器onSensorChanged方法，根据加速度传感器获取的值，更新流体系统的重力加速度。

   <br />

   ```
   @Override
   public void onSensorChanged(SensorEvent event) {
       if (event.sensor == null) {
           return;
       }
       // 加速度传感器。
       if (event.sensor.getType() == Sensor.TYPE_ACCELEROMETER) {
           int x = (int) event.values[0];
           int y = (int) event.values[1];
           int z = (int) event.values[2];
           int gravityX = 0;
           int gravityY = 0;
           int gravityZ = 0;
           // 屏幕的旋转信息。
           rotation = this.getWindowManager().getDefaultDisplay().getRotation();
           // 根据屏幕的旋转角度，更新加速度信息。
           switch (rotation) {
               case Surface.ROTATION_0:
                   gravityX = -x;
                   gravityY = -y;
                   gravityZ = -z;
                   break;
               case Surface.ROTATION_90:
                   gravityX = y;
                   gravityY = -x;
                   gravityZ = -z;
                   break;
               case Surface.ROTATION_180:
                   gravityX = x;
                   gravityY = y;
                   gravityZ = -z;
                   break;
               case Surface.ROTATION_270:
                   gravityX = -y;
                   gravityY = x;
                   gravityZ = -z;
                   break;
               default:
                   break;
           }

           FluidComponent fluidComponent = fluidNode.getComponent(FluidComponent.descriptor());
           if (fluidComponent != null) {
               // 设置流体系统的重力加速度。
               fluidComponent.setGravity(new Vector3(gravityX, gravityY, gravityZ));
           }
       }
   }

   @Override
   public void onAccuracyChanged(Sensor sensor, int accuracy) {
   }
   ```

7. 新建触屏交互手势事件子类GestureEvent。

   <br />

   ```
   public class GestureEvent implements View.OnTouchListener {
       private FluidComponent fluidComponent;
       private int surfaceWidth;
       private int surfaceHeight;
       private boolean sceneReady;

       public GestureEvent(FluidComponent fluidComponent, int surfaceWidth, int surfaceHeight) {
           this.fluidComponent = fluidComponent;
           this.surfaceWidth = surfaceWidth;
           this.surfaceHeight = surfaceHeight;
           sceneReady = fluidComponent != null && surfaceWidth != 0 && surfaceHeight != 0;
       }
       @Override
       public boolean onTouch(View view, MotionEvent event) {
           if (!sceneReady) {
               return false;
           }
           switch (event.getAction()) {
               case MotionEvent.ACTION_DOWN:
               case MotionEvent.ACTION_MOVE:
                   // 流体触屏交互接口，滑动流体，模拟流体晃动的效果。
                   fluidComponent.setGesture(event.getX() / surfaceWidth, event.getY() / surfaceHeight);
                   break;
               case MotionEvent.ACTION_UP:
                   fluidComponent.setGesture(-1.0f, -1.0f);
                   break;
               default:
                   break;
           }
           return true;
       }
   }
   ```

   <br />

8. 注册触屏交互的手势事件，支持触屏滑动流体，模拟流动飞溅效果。复写DemoActivity中的onTouchEvent方法。

   <br />

   ```
   private GestureEvent gesture;

   private void createFluidScene() {
       // ...

       // 获取屏幕信息。
       DisplayMetrics displayMetrics = context.getResources().getDisplayMetrics();
       // 注册手势事件。
       gesture = new GestureEvent(fluidComponent, displayMetrics.widthPixels, displayMetrics.heightPixels);
   }

   @Override
   public boolean onTouchEvent(MotionEvent motionEvent) {
       if (gesture != null) {
           gesture.onTouch(renderView, motionEvent);
       }
       return true;
   }
   ```

   <br />

9. 在DemoActivity的onCreate方法中调用createFluidScene方法，完成流体场景创建。

   <br />

   ```
   @Override
   protected void onCreate(@Nullable Bundle savedInstanceState) {
       //...
       createFluidScene();
   }
   ```

   <br />

完成上述步骤后，运行应用，启动DemoActivity，就能够看见流体在不可视的球形边界内流动。
