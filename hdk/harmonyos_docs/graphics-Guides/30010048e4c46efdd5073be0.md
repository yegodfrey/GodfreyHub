# 错误码

#### 原子化接口

|错误码类型|错误码子类型|值|描述|解决方法|
|:------------------|:-----------------------------------------|:-----|:-----------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|NONE 无错误。|-|0|无错误。|-|
|MODULE_ERR 模块错误。|MODULE_ERR_UNAVAILABLE|100001|初始化SceneKit失败。|请根据[使用说明](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/fine-grained-overview-0000001073484401)检查初始化相关代码是否正确。|
|MODULE_ERR 模块错误。|MODULE_ERR_UPDATE_NEEDED|100002|SceneKit APK需要升级。|使用异常中提供的Intent启动升级Activity，完成SceneKit升级。|
|MODULE_ERR 模块错误。|MODULE_ERR_HMS_NOT_READY|100003|HMS Core（APK）正在启动中。|等待HMS Core（APK）启动完成后，尝试重新初始化SceneKit。|
|MODULE_ERR 模块错误。|MODULE_ERR_HMS_IS_UNAVAILABLE|100004|HMS Core（APK）未安装或不可用。|检查并安装最新版本的HMS Core（APK）。|
|RESOURCE_ERR 资源错误。|RESOURCE_ERR_UNSUPPORTED_PROTOCOL|300001|不支持的URI协议。|请使用正确的Uri协议，详见[功能使用限制](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/service-introduction-0000001050163355#section44811453163110)。|
|RESOURCE_ERR 资源错误。|RESOURCE_ERR_UNSUPPORTED_EXTENSION|300003|不支持的文件扩展名。|请使用支持的素材格式，详见[支持的素材格式](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/service-introduction-0000001050163355#section19152121114545)。|
|RESOURCE_ERR 资源错误。|RESOURCE_ERR_FILE_NOT_EXISTS|300006|资源文件不存在。|请检查资源文件是否存在。|
|OPERATION_ERR 操作错误。|OPERATION_ERR_API_NOT_SUPPORT_VULKAN|400002|使用的方法不支持Vulkan。|请在初始化时，使用[SceneKit.Property.GraphicsBackend](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-backend-0000001061092027)中GLES进行初始化。|
|OPERATION_ERR 操作错误。|OPERATION_ERR_UNSUPPORTED_MANUFACTURER|400003|不支持的非华为终端设备。|请使用华为设备或使用扩展包支持非华为设备。|
|OPERATION_ERR 操作错误。|OPERATION_ERR_UNSUPPORTED_API_LEVEL|400004|不支持的安卓API Level。|请升级安卓API Level。|
|OPERATION_ERR 操作错误。|OPERATION_ERR_NOT_AVAILABLE_NODE|400005|节点已失效。|请检查是否在节点销毁后使用了节点。|
|OPERATION_ERR 操作错误。|OPERATION_ERR_NOT_AVAILABLE_MODEL|400007|模型已失效。|请检查是否在模型销毁后使用了模型。|
|OPERATION_ERR 操作错误。|OPERATION_ERR_NOT_AVAILABLE_TEXTURE|400008|纹理已失效。|请检查是否在纹理销毁后使用了纹理。|
|OPERATION_ERR 操作错误。|OPERATION_ERR_NOT_AVAILABLE_BOX_SHAPE|400009|盒子形状已失效。|请检查是否在节点销毁后使用了节点[Collider](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-collider-0000001096542434)组件的盒子形状。|
|OPERATION_ERR 操作错误。|OPERATION_ERR_NOT_AVAILABLE_CAPSULE_SHAPE|400010|胶囊形状已失效。|请检查是否在节点销毁后使用了节点[Collider](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-collider-0000001096542434)组件的胶囊形状。|
|OPERATION_ERR 操作错误。|OPERATION_ERR_NOT_AVAILABLE_CONE_SHAPE|400011|圆锥形状已失效。|请检查是否在节点销毁后使用了节点[Collider](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-collider-0000001096542434)组件的圆锥形状。|
|OPERATION_ERR 操作错误。|OPERATION_ERR_NOT_AVAILABLE_CYLINDER_SHAPE|400012|圆柱形状已失效。|请检查是否在节点销毁后使用了节点[Collider](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-collider-0000001096542434)组件的圆柱形状。|
|OPERATION_ERR 操作错误。|OPERATION_ERR_NOT_AVAILABLE_SPHERE_SHAPE|400013|球形形状已失效。|请检查是否在节点销毁后使用了节点[Collider](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-collider-0000001096542434)组件的球形形状。|
|OPERATION_ERR 操作错误。|OPERATION_ERR_NOT_AVAILABLE_PLANE_SHAPE|400015|平面形状已失效。|请检查是否在节点销毁后使用了节点[Collider](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-collider-0000001096542434)组件的平面形状。|
|OPERATION_ERR 操作错误。|OPERATION_ERR_NOT_INITIALIZE_SUCCESS|400016|初始化失败。|请检查是否已正确调用初始化接口[initialize](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-initializehelper-0000001070956176#section15578106915)或[initializeSync](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-initializehelper-0000001070956176#section1513464895)。 请检查设备是否支持Vulkan，如不支持Vulkan请使用OpenGL ES进行初始化。|
|OPERATION_ERR 操作错误。|OPERATION_ERR_BAD_AR_BACKEND|410001|使用错误的渲染后端。|请检查渲染后端是否支持。|
|OPERATION_ERR 操作错误。|OPERATION_ERR_AR_ENGINE_NOT_READY|410004|AREngineServer版本不支持或未安装。|请检查AREngineServer版本是否更新到最新版本。|
|PARAMS_ERR 参数错误。|PARAMS_ERR_NULL_POINTER_ERR|500001|目标参数不能为空指针。|请检查传入参数是否为空。|

#### 场景化接口

|错误码|值|描述|解决方法|
|:------------------|:----|:-----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------|
|SUCCESS|0|成功。|-|
|ERROR|1|通用错误码。|详见具体错误码解决方法。|
|ERROR_KIT_NOT_READY|10001|SceneKit APK未准备就绪。|1. 请检查HMS Core（APK）是否安装。 2. 请检查HMS Core（APK）是否正常启动。 3. 请检查SceneKit APK是否升级为最新版本。|
|ERROR_BAD_PARAM|10002|参数错误。|请检查传入参数是否合法。|
|ERROR_BAD_STATE|10003|内部状态错误。|请检查是否遵循受限说明中的限制条件，详见[功能使用限制](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/service-introduction-0000001050163355#section44811453163110)。|
|ERROR_INVALID_SDK|10004|内部错误。|请收集当前日志[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)。|

若您的问题仍无法解决，请选择[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题，华为支持人员会及时处理。
