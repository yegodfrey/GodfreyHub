# Avatar 3D模型基本介绍

对于任何一种Animoji和Avatar卡通形象的表情驱动都需要一组3D模型，按照使用功能区分为以下两种：

1.表情基模型

用于描述卡通形象主要表情的 3D 表情模型。基于主表情进行加权，可以合成几乎所有类型的表情。表情基模型无需材质和纹理贴图，只需要几何Mesh即可。

2.显示模型

用于卡通形象显示的 3D 模型，该模型用于 3D 渲染，需要与表情基模型在几何拓扑结构上保持一致，但可以包含更多的材质和纹理信息支持渲染显示。
