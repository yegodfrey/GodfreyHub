# 分区渲染

HVR SDK为应用提供分区渲染模式，提升中心区域清晰度，降低周边区域清晰度，需要开发者基于新增接口选择适配。

分区渲染开启方式：

1. 选择Partitioned Rendering Status中的选项。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220519145808.29505527418006745005302481292973:50530518075906:2800:C91B71E42C7188D17C6394FE6305B1392C20F62229F94BE24CCAA56A09A32985.png?needInitFileName=true?needInitFileName=true "点击放大")

选项描述：

|选项|描述|
|:------------|:----------|
|Off|关闭分区渲染|
|LowQuality|以低分辨率进行分区渲染|
|MiddleQuality|以中分辨率进行分区渲染|
|HighQuality|以高分辨率进行分区渲染|

2. 勾选PlayerSettings中的Virtual Reality Supported，清空VirtualReality SDKs中的选项，Stereo Rendering Method选择Single Pass (Preview)，如图所示。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220519145808.65026817092163675089118814471417:50530518075906:2800:C3F08F470DD05E72F6F6D508BC388C188BB8EF5844800563DBA46CD66AD29179.png?needInitFileName=true?needInitFileName=true "点击放大")
> 说明
>
> 分区渲染模式下请勿使用HVRExtCamera。
