# 集成SDK

1. 下载[cgsdk-plugin-base](https://developer.huawei.com/consumer/cn/doc/development/graphics-Library/sdk-download-0000001050441521) SDK包，并解压。
2. 复制插件开发框架PluginSdk到插件工程根目录。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211227101413.01898298178375840878125445928638:50521226030127:2800:46FA12BD0175271FEFE5B7166318769F155EC10137DFC5EA18EA57F6A062BC48.png?needInitFileName=true?needInitFileName=true)
3. 配置"/Src/Android.mk"下的工程目标文件和源文件。

   ```screen
   LOCAL_MODULE := libPluginDemo
   LOCAL_SRC_FILES = ./PluginDemo.cpp
   ```

4. 修改build.bat文件。

   修改NDK编译工具链的指向目录。

   ```screen
   set NDK_TOOLS=%ndk_tool_path%
   ```
