# 定时器

CG Kit提供定时器功能来完成计划执行任务，可实现延迟一定时间执行任务或在一定时间间隔后重复执行指定的次数，完成后会自动清除定时器。计划执行任务的示例代码如下。

```screen

    []{ LOGERROR("======== schedule test ======="); },
    this,
    5.f,
    3,
    2.f,
    "TestTimer"
);
gTimerManager.https://developer.huawei.com/consumer/cn/doc/development/graphics-References/timermanager-0000001197479521#section1136011332216(scheduleInfo);
```

