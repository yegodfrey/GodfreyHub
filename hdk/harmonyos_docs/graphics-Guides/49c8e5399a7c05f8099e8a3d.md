# 开发准备

1. 下载并解压[体积雾插件SDK](https://developer.huawei.com/consumer/cn/doc/development/graphics-Library/sdk-download-0000001050441521)。压缩包内包含头文件和库文件。
   * 头文件包含接口API和相关结构体的定义。
   * 库文件包含PC端Windows平台下运行所需要的动态链接库".dll"文件和移动端Android平台运行所需要的动态链接库".so"文件。
2. 调用体积雾插件前，需要添加打点功能依赖aar包，可以通过修改代码工程的应用级build.gradle文件来实现，任意aar包版本号均可。

> 注意
>
> 本插件移动端Android平台依赖OpenGLES 3.1及以上版本。
