# 开发准备

Windows 7（64位）、Unity 5.5.2、Android SDK、下载HuaweiVR SDK 2.0 Audio压缩包。
> 说明
>
> 1. 当前音效插件只包含windows 7（64位）版本，如在32位系统上可能无法正常使用。
> 2. 当前版本插件只支持Android平台。
> 3. 在同一场景中，当前音效插件最多只支持12个独立的对象声源。
> 4. 当开启多普勒效应时，场景中对象声源与听者的相对运动速度不要接近或超过音速，否则可能会出现声音输出异常。
