# 蓝牙耳机佩戴检测及有线耳机断连的音视频播放控制方案

## 场景介绍

在应用中播放音视频时，当用户断开有线耳机，断开蓝牙耳机或摘下蓝牙耳机后，正在播放的音视频内容未自动停止/暂停播放，导致音频从设备扬声器外放，造成用户体验不佳甚至隐私泄露风险。

本例基于[AVSession](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/avsession-overview)，监听播控中心下发命令，判断是否播放。基于[AudioRoutingManager](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/audio-output-device-management)，监听有线耳机或蓝牙耳机连接状态的变化。

## 实现思路

1. 在支持佩戴检测的耳机摘下和重新佩戴时，播控中心会下发pause和play命令，可以监听这个命令来控制音视频的播放。播控中心的状态要始终和音视频的播放状态保持同步。

   ```ts
   this.session.on('play', () => {
     hilog.info(DOMAIN, TAG, 'Control command: play');
     this.callback?.(MediaControlEvent.PLAY);
   });

   this.session.on('pause', () => {
     hilog.info(DOMAIN, TAG, 'Control command: pause');
     this.callback?.(MediaControlEvent.PAUSE);
   });

   this.session.on('stop', () => {
     hilog.info(DOMAIN, TAG, 'Control command: stop');
     this.callback?.(MediaControlEvent.STOP);
   });
   ```

2. 播控中心在蓝牙耳机或有线耳机断连时，会转到手机扬声器播放。如果此时需要停止音视频播放，我们可以通过AudioRoutingManager监听deviceChange事件。当发生断连时，应用主动停止音视频的播放。

   ```ts
   this.audioRoutingManager.on('deviceChange', audio.DeviceFlag.OUTPUT_DEVICES_FLAG,
     (deviceChanged: audio.DeviceChangeAction) => {
       const deviceType = deviceChanged.deviceDescriptors?.[0]?.deviceType;
       hilog.info(DOMAIN, TAG,
         `Routing change: type=${deviceChanged.type}, deviceType=${deviceType}`);

       if (this.isBluetoothDeviceType(deviceType)) {
         // 蓝牙设备
         if (deviceChanged.type === 0) {
           this.callback?.(HeadsetEventType.BLUETOOTH_CONNECTED, deviceType);
         } else if (deviceChanged.type === 1) {
           this.callback?.(HeadsetEventType.BLUETOOTH_DISCONNECTED, deviceType);
         }
       } else {
         // 非蓝牙设备
         if (deviceChanged.type === 0) {
           this.callback?.(HeadsetEventType.NON_BLUETOOTH_CONNECTED, deviceType);
         } else if (deviceChanged.type === 1) {
           this.callback?.(HeadsetEventType.NON_BLUETOOTH_DISCONNECTED, deviceType);
         }
       }
     });
   ```

## 约束与限制

* 本示例支持API Version 20 Release及以上版本。
* 本示例支持HarmonyOS 6.0.0 Release SDK及以上版本。
* 本示例需要使用DevEco Studio 6.0.0 Release及以上版本进行编译运行。
