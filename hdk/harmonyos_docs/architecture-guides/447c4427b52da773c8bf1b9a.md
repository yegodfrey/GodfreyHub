# 外卖员商场室内到店确认取餐

## 场景介绍

室内高精度定位骑手取餐追踪，是外卖配送类应用的高频使用场景之一，如骑手进入商场内的奶茶店取餐时，传统GNSS定位在室内无信号覆盖，导致无法准确判断骑手是否到达商家位置。

本示例主要基于Location Kit[室内高精度定位服务](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/location-apply-open-capability#室内高精度定位)实现骑手在商场、高铁站等室内场所的精准定位，定位精度约10~20米并支持楼层识别；结合[MapComponent](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/map-mapcomponent)地图组件展示商家与骑手实时位置标记，通过[map.convertCoordinateSync](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/map-map-functions#convertcoordinatesync)将WGS84坐标转换为GCJ02坐标系，实现骑手标记精准更新与到店距离校验，解决室内取餐场景定位不准的核心痛点。

## 实现思路

* 在AGC"开放能力管理"页面申请开通[室内高精度定位](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/location-apply-open-capability#室内高精度定位)能力，1-3个工作日审核通过后，Location Kit在支持的商场、高铁站、机场和医院等室内场所自动启用高精度定位，定位精度约10-20米，并支持楼层识别。
* 通过[abilityAccessCtrl](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-abilityaccessctrl)运行时申请APPROXIMATELY_LOCATION与LOCATION权限，授权后开启持续定位。

  ```ts
  const atManager = abilityAccessCtrl.createAtManager();
  const permissions: Permissions[] = ['ohos.permission.APPROXIMATELY_LOCATION', 'ohos.permission.LOCATION'];
  const result = await atManager.requestPermissionsFromUser(context, permissions);
  ```

* 使用[geoLocationManager.on('locationChange')](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-geolocationmanager#geolocationmanageronlocationchange)订阅位置变化，设置locationScenario为[geoLocationManager.UserActivityScenario.NAVIGATION](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-geolocationmanager#useractivityscenario12)，系统自动融合GNSS、网络定位与室内高精度定位技术；当定位来源[locationType](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-geolocationmanager#locationsourcetype12)为INDOOR(3)时，表示当前定位结果来自室内高精度定位技术，骑手在商场内可获取10~20米精度的位置信息。

  ```ts
  const request: geoLocationManager.ContinuousLocationRequest = {
    interval: 10,
    locationScenario: geoLocationManager.UserActivityScenario.NAVIGATION
  };
  geoLocationManager.on('locationChange', request, this.locationCallback);

  // 回调中获取定位来源，INDOOR=3表示室内高精度定位
  const locationType = location.locationType;
  ```

* 页面每次展示时，通过onPageShow生命周期调用geoLocationManager.getCurrentLocation单次定位，立即刷新骑手当前位置，确保页面切回时位置信息不过时。

  ```ts
  onPageShow(): void {
    if (this.mapController) {
      this.mapController.show();
    }
    this.getCurrentLocation();
  }
  ```

* 定位结果为WGS84坐标系，通过[map.convertCoordinateSync](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/map-map-functions#convertcoordinatesync)转换为GCJ02后才能在华为地图上精准显示，避免约500米的坐标偏移。

  ```ts
  const wgs84: mapCommon.LatLng = { latitude: location.latitude, longitude: location.longitude };
  const gcj02 = map.convertCoordinateSync(
    mapCommon.CoordinateType.WGS84, mapCommon.CoordinateType.GCJ02, wgs84
  );
  ```

* 初始化[MapComponent](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/map-mapcomponent)地图组件，通过mapOptions设置中心点与缩放级别，在回调中获取MapComponentController控制器对象，添加商家与骑手标记。

  ```ts
  this.mapOptions = {
    position: { target: { latitude: MERCHANT_LAT, longitude: MERCHANT_LNG }, zoom: 15 },
    myLocationControlsEnabled: true,
    scaleControlsEnabled: true
  };
  this.mapCallback = async (err: Error, mapController: map.MapComponentController) => {
    this.mapController = mapController;
    await this.mapController.addMarker(merchantMarker);
    this.requestLocationPermission();
  };
  ```

* 使用自定义iconBuilder绘制商家与骑手地图标记，通过Stack+Polygon组合实现圆形图标加三角箭头指向效果。

  ```ts
  @Builder
  MerchantIcon(): void {
    Column() {
      Stack() {
        Text('店').fontSize(10).fontColor('#FFFFFF').fontWeight(FontWeight.Bold)
      }.width(24).height(24).borderRadius(12).backgroundColor('#FF6B35')
      Polygon().points([[0, 0], [6, 0], [3, 5]]).fill('#FF6B35').width(6).height(5)
    }
  }
  ```

* 基于Haversine公式计算骑手与商家间距离，当位移超过100米时更新骑手标记位置；点击"到店取餐"按钮时校验骑手与商家距离是否在100米以内，室内高精度定位保障商场内取餐校验的准确性。

  ```ts
  const distance = haversineDistance(this.currentLat, this.currentLng, MERCHANT_LAT, MERCHANT_LNG);
  if (distance >= 100) {
    this.updateRiderMarker(newLat, newLng);
  }
  ```

* 通过window.setWindowLayoutFullScreen(true)实现沉浸式状态栏，设置statusBarColor与标题栏、状态卡片统一为蓝色主题。
* 使用[call.makeCall](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-call#callmakecall12)拨打电话联系商家或顾客，第三方应用仅拉起系统拨号界面。

## 说明

* 使用室内高精度定位服务前，需在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)开通Location Kit服务，并在"开放能力管理"页面申请"室内高精度定位"能力，1~3个工作日审核通过后方可使用。
* 室内高精度定位仅支持商场、高铁站、机场和医院等场所，未开通时Location Kit仍支持室内网络定位，但精度较低。

## 环境准备

本示例基于DevEco Studio 6.1.1 Release版本进行编译运行。

* 获取粗略位置权限：[ohos.permission.APPROXIMATELY_LOCATION](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/permissions-for-all-user#ohospermissionapproximately_location)。
* 获取精确定位权限：[ohos.permission.LOCATION](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/permissions-for-all-user#ohospermissionlocation)。
* 访问网络权限：[ohos.permission.INTERNET](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/permissions-for-all#ohospermissioninternet)。
