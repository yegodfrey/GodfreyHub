# 司机实名认证

#### 场景介绍

折叠屏相机适配是影像类应用在折叠屏设备上的典型场景之一，如用户在展开/折叠设备时需要自动切换前置或后置摄像头以获得最佳拍摄体验。

本示例主要基于[相机管理](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/camera-device-management)与[折叠状态监听](https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-purax-12)实现折叠屏设备摄像头自动适配功能。通过display.on('foldStatusChange')监听设备折叠状态变化，根据折叠状态（展开/半折叠→前置，折叠→后置）自动选择对应位置的摄像头，并通过XComponent重新加载相机预览流，解决折叠状态切换时摄像头切换问题。

#### 实现思路

1. 相机权限申请：  
   应用启动时通过AbilityAccessCtrl先检查后申请ohos.permission.CAMERA权限。

   ```
   const atManager: abilityAccessCtrl.AtManager = abilityAccessCtrl.createAtManager();
   const result: abilityAccessCtrl.GrantStatus =
     await atManager.checkAccessToken(tokenID, 'ohos.permission.CAMERA');
   if (result !== abilityAccessCtrl.GrantStatus.PERMISSION_GRANTED) {
     await atManager.requestPermissionsFromUser(context, ['ohos.permission.CAMERA']);
   }
   ```

2. 相机初始化与折叠状态监听： 权限通过后初始化CameraManager，注册display.on('foldStatusChange')监听，并根据当前折叠状态选择初始摄像头。

   ```
   this.mCameraManager = camera.getCameraManager(context);
   display.on('foldStatusChange', this.displayFoldStatusCallback);
   this.selectCameraByFoldStatus(display.getFoldStatus());
   ```

3. 折叠状态驱动的摄像头选择： 展开/半折叠态→前置，折叠态→后置。选择完成后将状态写入AppStorage触发XComponent重载。

   ```
   if (foldStatus === display.FoldStatus.FOLD_STATUS_EXPANDED ||
     foldStatus === display.FoldStatus.FOLD_STATUS_HALF_FOLDED) {
     this.mCameraPosition = camera.CameraPosition.CAMERA_POSITION_FRONT;
   } else {
     this.mCameraPosition = camera.CameraPosition.CAMERA_POSITION_BACK;
   }
   // 遍历匹配目标cameraPosition，未匹配则降级取首个
   AppStorage.setOrCreate<number>('foldStatus', foldStatus as number);
   ```

4. 折叠状态变更与相机切换： 半折叠态与展开态间可用摄像头一致，无需重配流，其余状态变更需释放旧相机再重新选择。

   ```
   // 半折叠与展开状态间切换时跳过，避免无效重配流
   if ((this.preFoldStatus === display.FoldStatus.FOLD_STATUS_HALF_FOLDED &&
     foldStatus === display.FoldStatus.FOLD_STATUS_EXPANDED) ||
     (this.preFoldStatus === display.FoldStatus.FOLD_STATUS_EXPANDED &&
       foldStatus === display.FoldStatus.FOLD_STATUS_HALF_FOLDED)) {
     this.preFoldStatus = foldStatus;
     return;
   }
   await this.releaseCamera();
   this.selectCameraByFoldStatus(foldStatus);
   ```

5. 相机预览会话构建： XComponent加载后，基于其SurfaceId构建完整的预览流水线：CameraInput→PreviewOutput→PhotoSession。

   ```
   this.mSurfaceId = this.mXComponentController.getXComponentSurfaceId();
   this.mCameraInput = this.mCameraManager.createCameraInput(this.curCameraDevice);
   await this.mCameraInput.open();
   this.mPreviewOutput = this.mCameraManager.createPreviewOutput(
     outputCapability.previewProfiles[0], this.mSurfaceId);
   this.mPhotoSession = this.mCameraManager.createSession(
     camera.SceneMode.NORMAL_PHOTO) as camera.PhotoSession;
   this.mPhotoSession.beginConfig();
   this.mPhotoSession.addInput(this.mCameraInput);
   this.mPhotoSession.addOutput(this.mPreviewOutput);
   await this.mPhotoSession.commitConfig();
   await this.mPhotoSession.start();
   ```

6. XComponent双实例重载： 通过reloadXComponentFlag翻转驱动条件渲染切换，使XComponent销毁重建，防止旧相机画面残留。@StorageLink('foldStatus')联动@Watch回调触发翻转，新XComponent的onLoad完成新相机配流。

   ```
   @StorageLink('foldStatus') @Watch('onFoldStatusChanged') foldStatus: number = 0;
   onFoldStatusChanged(): void {
     this.reloadXComponentFlag = !this.reloadXComponentFlag;
     }
   ```

7. 相机资源释放： 按Session→PreviewOutput→CameraInput顺序依次释放，isReleasing标志位防止并发释放。

   ```
   async releaseCamera(): Promise<void> {
     if (this.isReleasing) return;
     this.isReleasing = true;
     await this.mPhotoSession?.stop();
     await this.mPhotoSession?.release();
     await this.mPreviewOutput?.release();
     await this.mCameraInput?.close();
     this.isReleasing = false;
   }
   ```

#### 环境准备

* 本示例基于DevEco Studio 6.1.1 Release版本进行编译运行。
* 本示例基于API Version 24 Release版本进行开发与验证。
* 本示例仅支持折叠屏设备验证，非折叠屏设备无法触发折叠状态变更。
