# 持仓成本线

## 场景介绍

Canvas绘制持仓成本线是金融理财类应用的高频使用场景之一，如用户在股票交易过程中需要直观查看持仓成本变化趋势与买卖点位；

本示例基于[Canvas](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-components-canvas-canvas)画布组件和[CanvasRenderingContext2D](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-canvasrenderingcontext2d)实现K线图与持仓成本线的自定义绘制，结合[@Watch](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-state-management-watch)实现交易数据变更后图表自动刷新，支持[GestureGroup](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-combined-gestures)组合PanGesture与PinchGesture实现手势平移与双指缩放查看历史行情。

## 实现思路

1. **计算持仓成本点** ：遍历K线交易日，使用指针将交易记录按日期匹配到对应交易日，逐日累加买入成本和数量，计算加权平均持仓成本。

   ```ts
   // HoldingsViewModel.ets
   let tradeIdx = 0;

   for (let idx = 0; idx < this.kLineData.items.length; idx++) {
     const kLine = this.kLineData.items[idx];

    // 收集所有日期 <= 当前K线日期的未处理交易
     let dayTrades: HoldingRecord[] = [];
     while (tradeIdx < sorted.length && sorted[tradeIdx].date <= kLine.date) {
       dayTrades.push(sorted[tradeIdx]);
       tradeIdx++;
     }

   if (dayTrades.length > 0) {
   // 当天有交易，重新计算成本
     for (let t = 0; t < dayTrades.length; t++) {
       const trade = dayTrades[t];
       if (trade.type === TradeType.BUY) {
         totalCost += trade.price * trade.quantity + trade.fee;
         totalQuantity += trade.quantity;
       } else {
         if (totalQuantity > 0) {
           const avgCost = totalCost / totalQuantity;
           const sellQty = Math.min(trade.quantity, totalQuantity);
           totalCost -= avgCost * sellQty;
           totalQuantity -= sellQty;
         }
       }
     }
     currentCostPrice = totalQuantity > 0 ? totalCost / totalQuantity : 0;
   }
   ```

2. **绘制K线蜡烛图** ：根据可见区域动态计算步长和蜡烛宽度，遍历可见K线数据，分别绘制上下影线和蜡烛实体，红涨绿跌。

   ```ts
   // KLineChart.ets
   private drawCandles(ctx: CanvasRenderingContext2D, area: DrawArea,
     items: KLineItem[], priceMin: number, priceSpan: number): void {
     const step = this.getChartStep(area, items.length)
     const candleWidth = this.getCandleWidth(step)

     for (let i = 0; i < items.length; i++) {
         const item = items[i];
         const x = area.left + i * step + step / 2;
         const isRise = item.close >= item.open;

         const priceToY = (price: number): number => {
           return area.top + area.height * (1 - (price - priceMin) / priceSpan);
         };

         const color = isRise ? ChartColors.RISE : ChartColors.FALL;

       // 上下影线
         ctx.strokeStyle = color;
         ctx.lineWidth = 1;
         ctx.beginPath();
         ctx.moveTo(x, priceToY(item.high));
         ctx.lineTo(x, priceToY(item.low));
         ctx.stroke();

        // 蜡烛实体
         const bodyTop = priceToY(Math.max(item.open, item.close));
         const bodyBottom = priceToY(Math.min(item.open, item.close));
         const bodyHeight = Math.max(bodyBottom - bodyTop, 1);

         ctx.fillStyle = color;
         ctx.fillRect(x - candleWidth / 2, bodyTop, candleWidth, bodyHeight);
       }
   }
   ```

3. **绘制阶梯式成本线与买卖标记** ：将成本点连成阶梯线（先水平后垂直），在交易当日绘制B/S圆形标记，实现成本变化可视化。

   ```ts
   // KLineChart.ets
   // 绘制阶梯线（橙色实线，稍粗）
   ctx.strokeStyle = ChartColors.COST_LINE;
   ctx.lineWidth = 3;
   ctx.beginPath();
   ctx.moveTo(visibleCostPoints[0][0], visibleCostPoints[0][1]);

   for (let i = 1; i < visibleCostPoints.length; i++) {
     // 阶梯效果：先水平，再垂直
     ctx.lineTo(visibleCostPoints[i][0], visibleCostPoints[i - 1][1]);
     ctx.lineTo(visibleCostPoints[i][0], visibleCostPoints[i][1]);
   }

   ctx.stroke();

   // 绘制买卖标记
   for (let i = 0; i < visibleCostPoints.length; i++) {
     const pt = visibleCostPoints[i];

     if (pt[2] === 1) {
       const markerColor = pt[3] === 0 ? ChartColors.BUY_MARKER : ChartColors.SELL_MARKER;
       const label = pt[3] === 0 ? 'B' : 'S';

     // 绘制圆形标记（稍大一点）
       ctx.fillStyle = markerColor;
       ctx.beginPath();
       ctx.arc(pt[0], pt[1], ChartConfig.MARKER_RADIUS, 0, Math.PI * 2);
       ctx.fill();
       ctx.strokeStyle = '#FFFFFF';
       ctx.lineWidth = 2;
       ctx.stroke();

      // 绘制文字
       ctx.fillStyle = '#FFFFFF';
       ctx.font = 'bold 20px sans-serif';
       ctx.textAlign = 'center';
       ctx.textBaseline = 'middle';
       ctx.fillText(label, pt[0], pt[1]);
       ctx.textBaseline = 'alphabetic';
       ctx.textAlign = 'start';
     }
   }
   ```

4. **新增交易弹窗与持仓汇总刷新** ：通过@CustomDialog自定义交易输入弹窗，用户确认后调用ViewModel新增交易记录并重新计算持仓汇总。父组件使用独立@State简单类型变量接收计算结果，通过@Prop传递给子组件，确保数据变更可靠刷新。

   ```ts
   // Index.ets
   private handleAddTrade(data: TradeFormData) {
     const price = parseFloat(data.price);
     const quantity = parseInt(data.quantity);
     const fee = parseFloat(data.fee);

     this.viewModel.addTrade(data.type, price, quantity, fee, data.date, data.note);
     this.refreshUI();
   }

   // 刷新UI数据
   private refreshUI() {
    // 将计算结果赋值到独立的@State简单类型变量
   // @State简单类型变更能可靠触发子组件@Prop刷新
     const summary = this.viewModel.calculateSummary();
     this.averageCost = summary.averageCost;
     ...

     this.costPoints = this.viewModel.calculateCostPoints();
     this.records = this.viewModel.getRecords();
    // 递增版本号，强制触发KLineChart的@Watch重绘
     this.dataVersion++;
   }
   ```

   子组件HoldingsPanel使用独立@Prop简单类型接收数据，在build()中直接渲染：

   ```ts
   // HoldingsPanel.ets
   @Component
   export struct HoldingsPanel {
     @Prop averageCost: number = 0;
     @Prop totalQuantity: number = 0;
     @Prop profitLoss: number = 0;
   // ...

     build() {
       Column() {
         Text('¥' + this.averageCost.toFixed(3))
           .fontColor(ChartColors.COST_LINE);
         Text(this.totalQuantity.toString() + '股');
         Text((this.profitLoss >= 0 ? '+' : '') + '¥' + this.formatNumber(this.profitLoss))
           .fontColor(this.profitLoss >= 0 ? ChartColors.RISE : ChartColors.FALL);
       }
     }
   }
   ```

5. **@Watch监听数据变更触发重绘** ：在KLineChart组件中，通过@Prop @Watch监听K线数据、成本点和版本号变化，数据更新时自动调用drawChart重绘Canvas。

   ```ts
   // KLineChart.ets
   @Prop @Watch('onDataChanged') kLineItems: KLineItem[] = [];
   @Prop @Watch('onDataChanged') costPoints: CostPoint[] = [];
   @Prop @Watch('onDataChanged') dataVersion: number = 0;

   private onDataChanged(): void {
     if (this.kLineItems.length > 0) {
       this.drawChart();
     }
   }
   ```

6. **手势平移与双指缩放** ：通过GestureGroup组合PanGesture和PinchGesture，实现K线图左右滑动浏览和双指缩放查看不同时间维度行情。

   ```ts
   // KLineChart.ets
   .gesture(
     GestureGroup(GestureMode.Exclusive,
       PanGesture({ fingers: 1, direction: PanDirection.Horizontal })
         .onActionUpdate((event: GestureEvent) => {
           const dx = event.offsetX - this.lastOffsetX;
           this.lastOffsetX = event.offsetX;
           this.handlePan(dx);
         }),
       PinchGesture({ fingers: 2 })
         .onActionEnd((event: GestureEvent) => {
           this.handlePinch(event.scale);
         })
     )
   )
   ```
