# 连续识别条形码并自动拍照

## 场景介绍

基于HarmonyOS ScanKit的扫拍码应用，支持快递员扫码派件场景，提供以下核心能力：

* **自定义界面连续扫码**：基于customScan+XComponent实现相机预览流实时扫码，支持一维条码识别（Code128、EAN13等主流快递条码格式）。
* **自动拍照留证**：扫码命中后自动截取当前预览帧并保存为JPG文件，支持开关控制。
* **手动输入编号**：支持键盘输入编号，含格式校验（纯数字、长度限制、重复检测）。
* **扫描结果管理**：实时展示已扫码列表，支持图片预览、删除确认。
* **闪光灯控制**：支持低光环境下开启闪光灯辅助扫码。

## 实现思路

1. **自定义界面扫码**

   使用customScan模块替代系统默认扫码界面，通过XComponent渲染相机预览流，实现完全自定义的扫码UI。扫码流程遵循init→ start→callback→rescan的生命周期：

   ```ts
   private initScan(): void {
     const options: scanBarcode.ScanOptions = {
       scanTypes: [scanCore.ScanType.ONE_D_CODE],
       enableMultiMode: false,
       enableAlbum: false
     };
     customScan.init(options);
     this.hasInit = true;
   }

   private startScan(): void {
     const viewControl: customScan.ViewControl = {
       width: this.xComponentWidth,
       height: this.xComponentHeight,
       surfaceId: this.surfaceId
     };
     customScan.start(viewControl, scanCallback, frameCallback);
   }
   ```

2. **条码类型过滤**

   如果场景对识别码的类型有要求（以条形码为例），可以通过扫码结果中的scanType字段判断当前条码是否为一维条码，过滤二维码等非目标结果：

   ```ts
   const BARCODE_TYPES: Set<scanCore.ScanType> = new Set([
     scanCore.ScanType.ONE_D_CODE,
     scanCore.ScanType.CODE128_CODE,
     scanCore.ScanType.EAN13_CODE,
    // ...其他一维码类型
   ]);

   function isBarcodeType(scanType: scanCore.ScanType): boolean {
     return BARCODE_TYPES.has(scanType);
   }
   ```

3. **自动拍照截帧**

   扫码命中后，通过image.createPixelMapFromSurface截取当前预览帧，再经ImagePacker编码为JPG数据写入应用沙箱目录：

   ```ts
   private async captureToMemory(): Promise<ArrayBuffer | null> {
     const region: image.Region = {
       x: 0, y: 0,
       size: { width: this.lastFrameWidth, height: this.lastFrameHeight }
     };
     const pm: image.PixelMap = await image.createPixelMapFromSurface(this.surfaceId, region);
     const imagePacker: image.ImagePacker = image.createImagePacker();
     const data: ArrayBuffer = await imagePacker.packToData(pm, { format: 'image/jpeg', quality: 95 });
     pm.release();
     imagePacker.release();
     return data;
   }
   ```

4. **重复扫码检测与防抖提示**

   使用Set<string>记录已扫描识别的结果列表，重复扫码时通过防抖Toast提示"快件已揽收"：

   ```ts
   private showToastWithDebounce(key: string, message: string): void {
     const now: number = Date.now();
     if (this.lastToastNo !== key || (now - this.lastToastTime) > TOAST_DEBOUNCE_MS) {
       this.lastToastNo = key;
       this.lastToastTime = now;
       this.getUIContext().getPromptAction().showToast({ message: message });
     }
   }
   ```

5. **扫描线动画**

   使用setInterval驱动@State scanLineY状态变化，配合translate({ y: this.scanLineY })实现扫描线上下滑动效果，30ms间隔保证流畅度：

   ```ts
   private startScanLineAnimation(): void {
     this.scanLineTimer = setInterval(() => {
       const maxH: number = this.scanBoxHeight > 0 ? this.scanBoxHeight : 200;
       this.scanLineY += 2;
       if (this.scanLineY > maxH) {
         this.scanLineY = 0;
       }
     }, 30);
   }
   ```
