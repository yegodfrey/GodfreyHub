# 广告窗口插入

## 场景介绍

本示例基于[NodeContainer](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-nodecontainer)和[NodeController](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-arkui-nodecontroller)实现在动态列表固定位置插入广告的效果，也可适用于社交通讯、综合办公、美食购物、拍摄美化类应用中浏览界面插入广告的场景。

## 实现思路

1. 标记广告所在节点并基于[NodeContainer](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-nodecontainer)挂载节点进行占位。

   ```ts
   if (i % Constants.ONE_CYCLE === Constants.AD_POSITION) {
     //标记节点
   }
   // ...
   if (item.isAdCard()) {
     //占位
     NodeContainer(getAdNodeController(this.getUIContext(), item.getAdId()))
       .width(Constants.FULL_PERCENT);
   }
   ```


2. 获取广告配置文件并构建广告组件，判断加载图文广告或者视频广告。

   ```ts
   export const getAdNodeController = (uiContext: UIContext, adId: ResourceStr): AdNodeController | undefined => {
     let baseNode = new AdNodeController();
     NODE_MAP.set(adId, baseNode);
     baseNode.initAd(uiContext, adId, queryAdById(adId));
     return NODE_MAP.get(adId);
   }
   // ...
   function getAdComponent(param: AdParams) {
     //判断
   }
   ```


3. 基于[NodeController](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-arkui-nodecontroller)构建AdNodeController，实现组件上树。

   ```ts
   class AdNodeController extends NodeController {
    //组件上树
   }
   ```


4. 隐藏广告。

   ```ts
   action: () => {
     this.isRemoved = true;
   }
   ```

## 约束与限制

* 本示例支持API Version 20 Release及以上版本。
* 本示例支持HarmonyOS 6.0.0 Release SDK及以上版本。
* 本示例需要使用DevEco Studio 6.0.0 Release及以上版本进行编译运行。
