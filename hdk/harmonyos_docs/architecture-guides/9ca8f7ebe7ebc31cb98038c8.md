# 司机悬浮窗抢单

## 场景介绍

司机悬浮窗抢单是出行导航类应用的高频使用场景之一，如司机在使用接单软件时可通过悬浮窗查看当前订单动态并快速抢单。

本示例主要基于[floatingBall](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-floatingball)实现全局悬浮窗，为司机群体提供轻量、便捷的订单触达入口。

## 实现思路

* 创建悬浮窗控制器：通过[floatingBall.create()](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-floatingball#floatingballcreate)创建FloatingBallController，传入AbilityContext建立上下文关联。

  ```ts
    let config: floatingBall.FloatingBallConfiguration = {
      context: this.abilityContext
    };
    this.controller = await floatingBall.create(config);
  ```

* 启动悬浮窗：配置悬浮窗的显示样式：标题、内容、背景色，调用startFloatingBall展示。

  ```ts
    let params: floatingBall.FloatingBallParams = {
      template: floatingBall.FloatingBallTemplate.EMPHATIC,
      title: `${orderCount}单可抢`,
      content: '点击接单',
      backgroundColor: `#265bee`
    };
    await this.controller.startFloatingBall(params);
  ```

* 注册点击事件：点击悬浮窗时，通过[restoreMainWindow()](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-window-window#restoremainwindow23)拉起应用主窗口，同时通过Want参数传递targetPage: 'OrderPage'，告知应用需要跳转到接单页面。

  ```ts
   // FloatBallManager.ets
    this.controller.on('click', () => {
      hilog.info(DOMAIN, TAG, 'FloatBall clicked');
      let want: Want = {
        bundleName: 'com.example.driverfloatingwindow',
        abilityName: 'EntryAbility',
        parameters: {
          'targetPage': 'OrderPage'
        }
      };
      if (this.controller) {
        this.controller.restoreMainWindow(want).then(() => {
          hilog.info(DOMAIN, TAG, 'restoreMainWindow success');
        }).catch((err: Error) => {
          hilog.error(DOMAIN, TAG, 'restoreMainWindow failed: %{public}s', err.message);
        });
      }
    });

  // EntryAbility.ets
    onNewWant(want: Want, launchParam: AbilityConstant.LaunchParam): void {
      hilog.info(DOMAIN, TAG, '%{public}s', 'Ability onNewWant');
      this.checkTargetPage(want);
    }

    private checkTargetPage(want: Want): void {
      if (want.parameters) {
        let targetPage = want.parameters.targetPage;
        hilog.info(DOMAIN, TAG, 'checkTargetPage: targetPage=%{public}s', JSON.stringify(targetPage));
        if (targetPage === 'OrderPage') {
          let navPathStack = AppStorage.get<NavPathStack>('navPathStack');
          if (navPathStack) {
            navPathStack.pushPath({ name: 'OrderPage' });
          } else {
            AppStorage.setOrCreate('shouldNavigateToOrder', true);
          }
        }
      }
    }
  ```

* 更新悬浮窗内容：当订单数量变化时，调用[updateFloatingBall](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-floatingball#updatefloatingball)更新悬浮窗显示内容，无需重新创建。

  ```ts
    async updateFloatBall(orderCount: number): Promise<void> {
      if (!this.controller || !this.isRunning) {
        return;
      }
      try {
        let params: floatingBall.FloatingBallParams = {
          template: floatingBall.FloatingBallTemplate.EMPHATIC,
          title: `${orderCount}单可抢`,
          content: '点击接单',
          backgroundColor: '#265bee'
        };
        await this.controller.updateFloatingBall(params);
      } catch (e) {
        hilog.error(DOMAIN, TAG, 'updateFloatBall failed: %{public}s', JSON.stringify(e));
      }
    }
  ```

## 环境准备

* 本示例基于API Version 24 Release版本进行开发与验证。
* 本示例基于DevEco Studio 6.1.1 Release版本进行编译运行。

## 权限说明

允许应用使用闪控球的能力：[ohos.permission.USE_FLOAT_BALL](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/restricted-permissions#ohospermissionuse_float_ball)。
