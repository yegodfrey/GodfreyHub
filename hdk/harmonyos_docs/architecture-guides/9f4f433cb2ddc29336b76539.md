# 快捷拨打电话后自动返回到三方应用

## 场景介绍

快捷拨打电话是外卖配送类应用的高频使用场景之一。如外卖员在配送工作台查看待配送订单时，需一键联系顾客确认收货地址、沟通送达时间等。

本示例使用Telephony Kit中的[call.makeCall](https://developer.huawei.com/consumer/cn/doc/doccenter-capabilities/api/js-apis-call#callmakecall24)接口，实现从第三方应用跳转至拨号界面并自动隐藏拨号界面，通话结束后直接返回第三方应用界面，解决原有流程通话结束后停留拨号盘、需手动返回第三方应用导致的交互割裂问题。

## 实现思路

通过[call.makeCall](https://developer.huawei.com/consumer/cn/doc/doccenter-capabilities/api/js-apis-call#callmakecall24)传入顾客号码与可选参数MakeCallOptions，其中isHideDialScreen设置为true，表示跳转拨号盘并在点击拨打后隐藏拨号界面，挂断电话后直接停留在三方应用界面。

```ts
try {
  await call.makeCall(order.phoneNumber, { isHideDialScreen: true });
} catch (err) {
  const error = err as BusinessError;
  hilog.error(DOMAIN, TAG, 'makeCall failed, code: %{public}d, message: %{public}s', error.code, error.message);
} finally {
  this.dialingOrderId = '';
}
```

## 环境准备

* 本示例基于DevEco Studio 6.1.1 Release版本进行编译运行。
* 本示例基于API Version 24 Release版本进行开发与验证。

## 参考文档

[call.makeCall](https://developer.huawei.com/consumer/cn/doc/doccenter-capabilities/api/js-apis-call#callmakecall24)：跳转到拨号界面，并显示待拨出的号码。MakeCallOptions是拨打电话的可选参数，其中isHideDialScreen表示是否隐藏拨号界面，true表示隐藏，false表示不隐藏。isHideDialScreen字段从API version 24开始支持。
