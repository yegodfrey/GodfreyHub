# 长按复制地址

## 场景介绍

长按复制地址是电商/物流类应用的典型场景之一，如用户在查看地址簿时，可通过长按地址卡片一键将收货人姓名、电话、地址及地址码复制到系统剪贴板，便于快速分享或粘贴至其他应用。

本示例使用[Search](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-search)组件实现地址关键字搜索，基于[LongPressGesture](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-gestures-longpressgesture)长按手势触发[pasteboard](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-pasteboard)剪贴板复制，并通过[Toggle](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-toggle)切换默认寄件地址，提供完整的地址簿管理交互。

## 实现思路

1. 数据模型定义：创建AddressItem类定义地址项结构，包含id、name、phone、address、addressCode、isDefault六个字段，提供getFullText()方法将各字段拼接为完整文本用于复制到剪贴板，并通过static create()工厂方法创建实例，避免直接类类型赋值导致的类型问题。

   ```ts
   export class AddressItem {
     id: string = '';
     name: string = '';
     phone: string = '';
     address: string = '';
     addressCode: string = '';
     isDefault: boolean = false;

     static create(id, name, phone, address, addressCode, isDefault): AddressItem {
       const item = new AddressItem();
       item.id = id; item.name = name; item.phone = phone;
       item.address = address; item.addressCode = addressCode; item.isDefault = isDefault;
       return item;
     }

     getFullText(): string {
       return `${this.name} ${this.phone} ${this.address} ${this.addressCode}`;
     }
   }
   ```

2. 长按手势复制到剪贴板：在AddressCard组件的地址信息区域绑定LongPressGesture手势，长按触发时调用getFullText()获取完整文本，通过pasteboard.createData创建纯文本数据并调用getSystemPasteboard().setData()写入系统剪贴板，同时调用getPromptAction().showToast()弹出"复制成功"提示。

   ```ts
   .gesture(
     LongPressGesture({ repeat: false })
       .onAction(() => {
         const text: string = this.addressItem.getFullText();
         const systemPasteboard: pasteboard.SystemPasteboard = pasteboard.getSystemPasteboard();
         const pasteData: pasteboard.PasteData = pasteboard.createData(pasteboard.MIMETYPE_TEXT_PLAIN, text);
         systemPasteboard.setData(pasteData);
         this.getUIContext().getPromptAction().showToast({ message: '复制成功' });
       })
   )
   ```

3. 搜索过滤：在Index页面使用Search组件，onChange回调实时更新@State searchText状态，getFilteredList()方法将关键字转为小写后遍历地址列表，依次匹配name、phone、address、addressCode四个字段，任一字段包含关键字即加入结果数组，搜索为空时返回全量列表。

   ```ts
   getFilteredList(): AddressItem[] {
     if (this.searchText.length === 0) {
       return this.addressList;
     }
     const keyword: string = this.searchText.toLowerCase();
     const result: AddressItem[] = [];
     for (const item of this.addressList) {
       if (item.name.toLowerCase().includes(keyword) ||
         item.phone.toLowerCase().includes(keyword) ||
         item.address.toLowerCase().includes(keyword) ||
         item.addressCode.toLowerCase().includes(keyword)) {
         result.push(item);
       }
     }
     return result;
   }
   ```

4. 列表渲染：使用List + ForEach渲染过滤后的地址列表，数据源调用getFilteredList()，键值生成函数返回item.id保证列表项唯一标识，ForEach内为每个ListItem挂载AddressCard组件，并设置圆角与白色背景形成卡片样式，列表整体开启EdgeEffect.Spring弹性滚动效果。

## 参考文档

* [pasteboard](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-pasteboard)提供管理系统剪贴板的能力，支持系统复制、粘贴功能。系统剪贴板支持对文本、HTML、URI、Want、PixelMap等内容的操作。
* [LongPressGesture](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-gestures-longpressgesture)用于触发长按手势事件，触发长按手势的最少手指数为1，默认最短长按时间为500毫秒。可配置duration参数控制最短长按时长，适用于需要通过用户长按操作触发组件交互的场景。
