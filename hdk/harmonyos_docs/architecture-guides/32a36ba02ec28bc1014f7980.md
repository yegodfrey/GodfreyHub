# 拍照比例自定义

#### 场景介绍

自定义拍照比例是拍摄美化类应用的典型场景之一，如用户在拍照时需要设置相机的比例。

本示例基于[@ohos.multimedia.camera](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-camera)实现拍照比例切换、前后摄像头反转、闪光灯开关的功能，通过[PhotoAccessHelper](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-photoaccesshelper-photoaccesshelper)保存图片到相册。

#### 实现思路

* 反转摄像头：使用cameraPosition参数来识别摄像头，1为前置摄像头，0为后置摄像头。

  ```
  async () => {
    cameraPosition = cameraPosition === 1 ? 0 : 1
    cameraShooting(cameraPosition, surfaceId, context, this.isRatio);
    this.Initialize();
    this.isFront = cameraPosition !== 0;
  }
  ```

<!-- -->

* 初始化和配置摄像头，进行拍照和预览：设置ratio参数为拍照比例，true为9:16，在获取到宽度和长度后，将值赋给previewOutput和photoOutPut，分别创建预览输出和拍照输出。

  ```
  let screen = display.getDefaultDisplaySync();
  let photoProfile: undefined | camera.Profile = photoProfilesArray.find((profile: camera.Profile) => {});
  previewOutput = cameraManager.createPreviewOutput(previewProfile, surfaceId);
  if (previewOutput === undefined) {
    return [];
  }
  photoOutPut = cameraManager.createPhotoOutput(photoProfile);
  if (photoOutPut === undefined) {
    return [];
  }
  ```

#### 约束与限制

* 本示例支持API Version 20 Release及以上版本。
* 本示例支持HarmonyOS 6.0.0 Release SDK及以上版本。
* 本示例需要使用DevEco Studio 6.0.0 Release及以上版本进行编译运行。
