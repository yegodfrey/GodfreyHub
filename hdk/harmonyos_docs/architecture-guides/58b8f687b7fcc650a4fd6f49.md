# 应用内自动调节屏幕亮度

## 场景介绍

应用内自动调节屏幕亮度是出行配送类应用的高频使用场景之一，如外卖骑手从室内冷启动后切换到户外强光环境时，屏幕亮度不会随环境光增强而自动提升，导致户外强光下屏幕内容难以辨认，严重影响接单操作与骑行安全。

本示例使用[sensor.on(SensorId.AMBIENT_LIGHT)](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-sensor#sensoronsensoridambient_light9)订阅环境光传感器数据，基于[setWindowBrightness](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-window-window#setwindowbrightness9)动态调节窗口亮度，并通过[preferences](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-data-preferences)持久化用户设置状态。当环境光照度变化超过阈值时，自动将光照强度映射为窗口亮度值并实时更新，关闭时恢复系统默认亮度。

## 实现思路

1. 环境光传感器订阅与亮度映射：通过sensor.on订阅环境光传感器，以1秒间隔持续获取光照强度（lux），将其线性映射到0.1~1.0的窗口亮度范围，并设置0.05的防抖阈值，避免频繁调节：

   ```ts
   sensor.on(sensor.SensorId.AMBIENT_LIGHT, (data: sensor.LightResponse) => {
     const lux: number = data.intensity;
     this.adjustBrightness(lux);
   }, { interval: 1000000000 });
   ```

   亮度映射与防抖逻辑：

   ```ts
   adjustBrightness(lux: number): void {
     let targetBrightness: number = lux / 5000;
     targetBrightness = Math.max(0.1, Math.min(1.0, targetBrightness));
     targetBrightness = Math.round(targetBrightness * 100) / 100;
     if (Math.abs(targetBrightness - this.currentBrightness) > 0.05) {
       this.currentBrightness = targetBrightness;
       this.windowInstance.setWindowBrightness(targetBrightness);
     }
   }
   ```

2. 窗口亮度控制。初始化时通过window.getLastWindow获取窗口实例。调用setWindowBrightness设置亮度值（范围0.0~1.0，-1.0表示恢复系统默认）。页面销毁时调用resetBrightness将亮度重置为系统默认值。
3. 用户设置持久化。使用preferences模块以Key-Value形式持久化6项开关状态：

   ```ts
   this.store = preferences.getPreferencesSync(context, { name: 'brightness_settings' });
   this.store.putSync(key, value);
   this.store.flush();
   ```

## 环境准备

* 本示例基于DevEco Studio 6.1.1 Release版本进行编译运行。
* 本示例基于API Version 24 Release版本进行开发与验证。
