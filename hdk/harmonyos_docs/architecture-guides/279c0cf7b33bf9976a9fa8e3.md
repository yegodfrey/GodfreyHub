# 司机导航语音播报焦点管理

#### 场景介绍

本项目模拟司机接单类应用在导航过程中的语音播报场景。司机在行驶过程中需要同时接收两类音频信息：

* 导航语音播报：通过TTS（Text-To-Speech）实时播报转弯、直行等导航指引，提示前方路况与距离。
* 新订单提示音：通过SoundPool播放短音频提示新订单到达，要求低延迟、不干扰导航语音。

#### 实现思路

* TTS导航语音播报 使用@kit.CoreSpeechKit提供的textToSpeech引擎实现语音合成播报：

  1. 引擎初始化：在aboutToAppear中调用textToSpeech.createEngine()创建离线TTS引擎，配置中文语种（zh-CN）和广播风格（interaction-broadcast）。

     ```
       initTtsEngine(): void {
         let extraParam: Record<string, Object> = {
           'style': 'interaction-broadcast',
           'locate': 'CN',
           'name': 'NavTtsEngine'
         };
         let initParamsInfo: textToSpeech.CreateEngineParams = {
           language: 'zh-CN',
           person: 0,
           online: 1,
           extraParams: extraParam
         };
         try {
           textToSpeech.createEngine(initParamsInfo, (err: BusinessError, engine: textToSpeech.TextToSpeechEngine) => {
             if (!err) {
               this.ttsEngine = engine;
               let speakListener: textToSpeech.SpeakListener = {
                 onStart(requestId: string, response: textToSpeech.StartResponse) {
                   console.info(`TTS onStart, requestId: ${requestId} response: ${response}`);
                 },
                 onComplete(requestId: string, response: textToSpeech.CompleteResponse) {
                   console.info(`TTS onComplete, requestId: ${requestId} response: ${response}`);
                 },
                 onStop(requestId: string, response: textToSpeech.StopResponse) {
                   console.info(`TTS onStop, requestId: ${requestId} response: ${response}`);
                 },
                 onData(requestId: string, audio: ArrayBuffer, response: textToSpeech.SynthesisResponse) {
                   console.info(`TTS onData, requestId: ${requestId} audio: ${audio} response: ${response}`);
                 },
                 onError(requestId: string, errorCode: number, errorMessage: string) {
                   console.error(`TTS onError, requestId: ${requestId}, code: ${errorCode}, msg: ${errorMessage}`);
                 }
               };
               this.ttsEngine.setListener(speakListener);
             } else {
               console.error(`Failed to create TTS engine. Code: ${err.code}, message: ${err.message}`);
             }
           });
         } catch (error) {
           console.error(`TTS createEngine exception: ${JSON.stringify(error)}`);
         }
       }
     ```

  2. 语音播报：封装speak()方法，每次调用递增requestId保证唯一，通过extraParams配置关键参数：
     * soundChannel:13：使用导航通道（STREAM_USAGE_NAVIGATION），不中断后台音乐。
     * queueMode: 1：抢占模式，新播报会打断上一条，确保导航指令实时送达。
     * playType: 1：合成并播报，不返回音频流。

       ```
         speak(text: string): void {
           this.ttsRequestId++;
           let extraParam: Record<string, Object> = {
             'queueMode': 1,       // 抢占模式，新播报打断上一条
             'speed': 1,
             'volume': 2,
             'pitch': 1,
             'languageContext': 'zh-CN',
             'audioType': 'pcm',
             'soundChannel': 13,    // 导航类型音频通道
             'playType': 1         // 合成并播报
           };
           let speakParams: textToSpeech.SpeakParams = {
             requestId: 'nav_' + this.ttsRequestId,
             extraParams: extraParam
           };
           this.ttsEngine.speak(text, speakParams);
         }
       ```

  3. 播报时机：在导航模拟中，当车辆经过路段分界点时，根据下一段的转弯动作（左转/右转/直行等）和距离生成播报文本，调用speak()播出。

     ```
     // 判断是否进入新路段，触发语音播报
       if (this.currentRoadIndex > this.lastAnnouncedRoadIndex) {
         this.lastAnnouncedRoadIndex = this.currentRoadIndex;
         if (this.currentRoadIndex < this.navRoads.length) {
           let nextRoad = this.navRoads[this.currentRoadIndex];
           let distText = this.formatDistance(nextRoad.distance);
           let actionText = this.getActionText(nextRoad.action);
           let announcement = `${actionText}${distText}后${nextRoad.roadName}`;
           this.speak(announcement);
         }
       }
     ```

* SoundPool新订单提示音 使用@kit.MediaKit提供的SoundPool实现短音频低延迟播放：

  1. 创建实例：调用media.createSoundPool()创建音频池，AudioRendererInfo.usage设为STREAM_USAGE_NOTIFICATION，不抢占TTS的导航音频通道。
  2. 加载资源：通过context.resourceManager.getRawFd()获取rawfile下音频文件的fd，调用soundPool.load()加载资源并获取soundId。

     ```
       import { media } from '@kit.MediaKit';
       import { audio } from '@kit.AudioKit';

       async initSoundPool(): Promise<void> {
         let audioRendererInfo: audio.AudioRendererInfo = {
           usage: audio.StreamUsage.STREAM_USAGE_NOTIFICATION,
           rendererFlags: 1
         };
         this.soundPool = await media.createSoundPool(5, audioRendererInfo);
         // 通过resourceManager获取rawfile音频文件的fd
         let context = this.getUIContext().getHostContext();
         let fileDescriptor = await context.resourceManager.getRawFd('neworder.wav');
         this.newOrderSoundId =
           await this.soundPool.load(fileDescriptor.fd, fileDescriptor.offset, fileDescriptor.length);
         this.soundPoolReady = true;
       }
     ```

  3. 播放提示音：调用soundPool.play()，传入soundId和PlayParameters（rate使用audio.AudioRendererRate.RENDER_RATE_NORMAL，loop为0即播放一次）。

     ```
       playNewOrderSound(): void {
         if (!this.soundPool || !this.soundPoolReady) {
           return;
         }
         let playParameters: media.PlayParameters = {
           loop: 0,                                              // 播放一次
           rate: audio.AudioRendererRate.RENDER_RATE_NORMAL,     // 正常速率
           leftVolume: 1.0,
           rightVolume: 1.0,
           priority: 0
         };
         this.soundPool.play(this.newOrderSoundId, playParameters, (error, streamId) => {
           if (!error) {
             this.newOrderStreamId = streamId;
           }
         });
       }
     ```

  4. 触发时机：导航开始30秒后通过setTimeout触发playNewOrderSound()，模拟行驶中收到新订单。

     ```
       // 导航开始后30秒触发新订单提示音
       this.newOrderTimer = setTimeout(() => {
         this.playNewOrderSound();
       }, 30000);

       // 停止导航时清除定时器
       clearTimeout(this.newOrderTimer);
     ```

5. 资源释放：在aboutToDisappear中调用soundPool.release()释放音频池资源。  

#### 说明

本示例需要[开通地图服务](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/map-config-agc#开通地图服务)，并进行相应配置，具体步骤如下：

2. 在项目列表中找到您的项目，在项目下的应用列表中选择需要打开"地图服务"的应用。
3. 选择API管理，找到"地图服务"开关，打开开关。
4. 确认已经开启"地图服务"开放能力，并完成[手动签名](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-signing#section297715173233)。
