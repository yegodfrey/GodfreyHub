# 视频弹幕功能场景实践

## 场景介绍

在HarmonyOS应用中实现"视频+弹幕"体验是常见的业务诉求：播放视频的同时，在画面上叠加滚动弹幕（从右向左飞过），并允许用户动态发送弹幕。本示例重点演示了 **弹幕渲染引擎** 的完整落地，覆盖以下典型场景：

|场景|说明|
|:---------|:-------------------------------------|
|**视频叠加弹幕**|视频画面之上叠加一层透明弹幕层，弹幕纹理以 alpha 混合方式覆盖在视频上|
|**实时发送弹幕**|用户在输入框输入文字，选择颜色/字号后点击发送，弹幕立即出现在画面中|
|**多弹幕调度**|支持多条弹幕并发，按 15 条轨道轮询分配，时间轴驱动统一调度|
|**海量弹幕压测**|一键生成 1000 条弹幕，在 60 秒内均匀分布，验证引擎吞吐与渲染流畅度|

## 实现思路

1. 弹幕位置计算（时间驱动，公式计算）： 弹幕位置通过公式计算而非逐帧累加，无浮点累积误差：

       float elapsedSinceStart = static_cast<float>(mElapsedTimeMs - item->startTimeMs);
       float wNdc = item->GetTexWidthInNDC(mSurfaceWidth);
       float distance = 2.0f + wNdc;
       float speed = distance / static_cast<float>(item->lifetimeMs);
       float startX = 1.0f + wNdc / 2.0f;
       item->x = startX - speed * elapsedSinceStart;

   lifetimeMs决定弹幕横穿屏幕的视觉时长，而非固定速度。因此不同宽度设备上，弹幕横穿屏幕的视觉时长一致（均为lifetimeMs），自动适配设备尺寸。


2. 弹幕轨道（轮询叠加模型）：
   * 屏幕纵向均分为ROW_COUNT = 15条轨道。
   * 弹幕激活时按轮询方式分配轨道（sRoundRobinRow % 15），不判断轨道是否"占用"。
   * 同轨多条弹幕直接叠加渲染（alpha混合），OpenGL不关心"碰撞"。
   * 优点：无行阻塞、持续流动；1000条弹幕可均匀分布在60秒内持续播放。

         while (mNextIndex < mAllDanmu.size()) {
             DanmakuItem *item = mAllDanmu[mNextIndex];

             if (item->startTimeMs > mElapsedTimeMs) {
                 break;
             }

          // 轮询分配行（允许多条弹幕叠加渲染在同一条轨道上）
             static int sRoundRobinRow = 0;
             int row = sRoundRobinRow % rowCount;
             sRoundRobinRow++;

          // 创建纹理（GL 调用，此时必须已绑定 EGL 上下文）
             if (!item->CreateTexture()) {
                 OH_LOG_ERROR(LOG_APP, "[DanmuEngine] CreateTexture failed for '%{public}s'",
                              item->text.c_str());
                 mNextIndex++;
                 continue;
             }

           // 分配行
             item->row = row;
             item->y = mRowY[row];
             item->alive = true;

             float wNdc = item->GetTexWidthInNDC(mSurfaceWidth);
             item->x = 1.0f + wNdc / 2.0f;

             OH_LOG_INFO(LOG_APP, "[DanmuEngine] Activated '%{public}s' row=%{public}d size=%.0f color=0x%{public}x",
                          item->text.c_str(), row, static_cast<double>(item->fontSize), item->color);

             mNextIndex++;
             activated = true;
         }


3. 弹幕纹理创建（OH_Drawing→GL）： 每条弹幕独立创建纹理，流程：

       // ---- 1. 计算合适的位图尺寸 ----
       // 估算文字宽度：CJK 字符约 1em = fontSize px，加 10% 余量
       uint32_t estimatedTextWidth = static_cast<uint32_t>(fontSize * text.length() * 1.1f);
       uint32_t bitmapWidth = NextPowerOfTwo(estimatedTextWidth < 64 ? 64 : estimatedTextWidth);
       if (bitmapWidth > 2048) {
           bitmapWidth = 2048; // 上限，避免超大纹理
       }

       uint32_t bitmapHeight = NextPowerOfTwo(static_cast<uint32_t>(fontSize * 1.5f));
       if (bitmapHeight < 32)
           bitmapHeight = 32;
       if (bitmapHeight > 512)
           bitmapHeight = 512;

       texWidth = static_cast<int>(bitmapWidth);
       texHeight = static_cast<int>(bitmapHeight);

       OH_LOG_INFO(LOG_APP, "[DanmakuItem] Creating texture %{public}dx%{public}d for '%{public}s'", texWidth, texHeight,
                   text.c_str());

       // ---- 2. 创建 OH_Drawing 位图 ----
       OH_Drawing_Bitmap *bitmap = OH_Drawing_BitmapCreate();
       if (bitmap == nullptr) {
           OH_LOG_ERROR(LOG_APP, "[DanmakuItem] OH_Drawing_BitmapCreate failed");
           return false;
       }

       OH_Drawing_BitmapFormat format = {OH_Drawing_ColorFormat::COLOR_FORMAT_RGBA_8888,
                                         OH_Drawing_AlphaFormat::ALPHA_FORMAT_PREMUL};
       OH_Drawing_BitmapBuild(bitmap, bitmapWidth, bitmapHeight, &format);

       // ---- 3. 创建画布并清除为全透明 ----
       OH_Drawing_Canvas *canvas = OH_Drawing_CanvasCreate();
       if (canvas == nullptr) {
           OH_LOG_ERROR(LOG_APP, "[DanmakuItem] OH_Drawing_CanvasCreate failed");
           OH_Drawing_BitmapDestroy(bitmap);
           return false;
       }
       OH_Drawing_CanvasBind(canvas, bitmap);
       OH_Drawing_CanvasClear(canvas, OH_Drawing_ColorSetArgb(0x00, 0x00, 0x00, 0x00));

       // ---- 4. 创建画刷（使用弹幕颜色） ----
       OH_Drawing_Brush *brush = OH_Drawing_BrushCreate();
       if (brush == nullptr) {
           OH_LOG_ERROR(LOG_APP, "[DanmakuItem] OH_Drawing_BrushCreate failed");
           OH_Drawing_CanvasDestroy(canvas);
           OH_Drawing_BitmapDestroy(bitmap);
           return false;
       }
       OH_Drawing_BrushSetColor(brush, color);
       OH_Drawing_CanvasAttachBrush(canvas, brush);

       // ---- 5. 创建字体 ----
       OH_Drawing_Font *font = OH_Drawing_FontCreate();
       if (font == nullptr) {
           OH_LOG_ERROR(LOG_APP, "[DanmakuItem] OH_Drawing_FontCreate failed");
           OH_Drawing_BrushDestroy(brush);
           OH_Drawing_CanvasDestroy(canvas);
           OH_Drawing_BitmapDestroy(bitmap);
           return false;
       }
       OH_Drawing_FontSetTextSize(font, fontSize);

       // ---- 6. 创建文字 Blob 并居中绘制 ----
       OH_Drawing_TextBlob *textBlob =
           OH_Drawing_TextBlobCreateFromString(text.c_str(), font, OH_Drawing_TextEncoding::TEXT_ENCODING_UTF8);
       if (textBlob == nullptr) {
           OH_LOG_ERROR(LOG_APP, "[DanmakuItem] OH_Drawing_TextBlobCreateFromString failed for '%{public}s'",
                        text.c_str());
           OH_Drawing_FontDestroy(font);
           OH_Drawing_BrushDestroy(brush);
           OH_Drawing_CanvasDestroy(canvas);
           OH_Drawing_BitmapDestroy(bitmap);
           return false;
       }

       // 居中定位
       float textWidthEstimate = fontSize * static_cast<float>(text.length());
       float textX = (static_cast<float>(bitmapWidth) - textWidthEstimate) / 2.0f;
       if (textX < 0.0f)
           textX = 0.0f;

       // baseline 居中：位图高的一半 + 约定基线偏移量
       float textY = (static_cast<float>(bitmapHeight) + fontSize * 0.35f) / 2.0f;

       OH_Drawing_CanvasDrawTextBlob(canvas, textBlob, textX, textY);

       // ---- 7. 获取像素数据 ----
       void *pixels = OH_Drawing_BitmapGetPixels(bitmap);
       if (pixels == nullptr) {
           OH_LOG_ERROR(LOG_APP, "[DanmakuItem] OH_Drawing_BitmapGetPixels returned null");
           OH_Drawing_TextBlobDestroy(textBlob);
           OH_Drawing_FontDestroy(font);
           OH_Drawing_BrushDestroy(brush);
           OH_Drawing_CanvasDestroy(canvas);
           OH_Drawing_BitmapDestroy(bitmap);
           return false;
       }

       // ---- 8. 创建 OpenGL 纹理 ----
       GLint prevTexture;
       glGetIntegerv(GL_TEXTURE_BINDING_2D, &prevTexture);

       glGenTextures(1, &texture);
       glBindTexture(GL_TEXTURE_2D, texture);

       glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MIN_FILTER, GL_LINEAR);
       glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MAG_FILTER, GL_LINEAR);
       glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_S, GL_CLAMP_TO_EDGE);
       glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_T, GL_CLAMP_TO_EDGE);

       glTexImage2D(GL_TEXTURE_2D, 0, GL_RGBA, texWidth, texHeight, 0, GL_RGBA, GL_UNSIGNED_BYTE, pixels);

       glBindTexture(GL_TEXTURE_2D, prevTexture);

       // ---- 9. 清理 OH_Drawing 资源 ----
       OH_Drawing_TextBlobDestroy(textBlob);
       OH_Drawing_FontDestroy(font);
       OH_Drawing_BrushDestroy(brush);
       OH_Drawing_CanvasDestroy(canvas);
       OH_Drawing_BitmapDestroy(bitmap);

   纹理V坐标已翻转：OH_Drawing位图原点在左上，而OpenGL纹理原点在左下。
4. 海量弹幕异步触发： 海量弹幕测试采用**flag-based异步触发**，避免跨线程持锁阻塞渲染：

   ```text
   ArkTS Button → generateMassDanmu() → NapiGenerateMassDanmu → timer.RequestMassDanmuTest()
                                                                       │
                                                                 mMassTestPending = true
                                                                       │
   VSync Thread: ProcessFrame → if (mMassTestPending) → engine.GenerateMassDanmu()
                                                         │
                                            1000 条内置模板，60秒 均匀分布
                                            锁一次批量插入 + inplace_merge
   ```


5. 线程模型： ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/78/v3/I5kooNOEQL6-YbJcGuopgw/zh-cn_image_0000002728803774.png?HW-CC-KV=V1&HW-CC-Date=20260921T035900Z&HW-CC-Expire=31536000000&HW-CC-Sign=62FAEB017C110AC5C06141FA5666F971DA532E6AAE4B12A071C75B91193D0934 "点击放大")

   * **EGL上下文只能在VSync线程使用**：ProcessFrame开头调用MakeCurrent()绑定；Init()末尾主动释放主线程上的上下文。
   * **共享数据结构**（mAllDanmu/mAliveDanmu）由pthread_mutex_t保护。
   * 海量弹幕生成通过标志位异步触发，由持有锁的VSync线程消费，避免主线程持锁阻塞渲染。

│   ├── build-profile.json5              # 模块构建配置
│   ├── oh-package.json5                 # 模块依赖

│       ├── cpp/
