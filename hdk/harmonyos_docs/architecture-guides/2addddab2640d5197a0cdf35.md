# 分类标题一键跳转内容

## 场景介绍

分类标题一键跳转内容是各类应用的高频使用场景之一，通过分类标签与内容联动的交互模式来提升用户体验，常见应用场景包括新闻首页浏览优化、小说书籍分类查看优化，以及景点服务模块快速导航等功能实现。

本示例基于[List](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-list)组件实现标题与内容联动的效果，将点击操作与List绑定，在用户点击分类标签时，内容页滚动至指定位置。

## 实现思路

**核心架构：双Scroller联动**

整个联动效果的关键在于两个独立的Scroller实例分别控制顶部分类标签栏和内容详情列表：

1. **分类导航模块** ：采用List组件构建分类标签栏，并通过绑定[Scroller](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-scroll#scroller)控制器实现横向滚动支持。

   ```ts
   List({ space: 10, scroller: this.scrollerForTitle }) {
     ForEach(this.data, (item: ShowData, index: number) => {
       ListItem() {
         this.groupNameBar(item.groupName, index);
       };
     }, (item: number) => JSON.stringify(item));
   }
   ```

2. **内容展示模块** ：采用List组件渲染内容详情列表，同样绑定独立的Scroller控制器以支持滚动交互。

   ```ts
   List({ initialIndex: 0, scroller: this.scrollerForList }) {
     ForEach(this.data, (item: ShowData) => {
       ListItem() {
         this.showDataImage(item);
       };
     }, (item: number) => JSON.stringify(item));
   }
   ```

**联动交互逻辑**

利用Scroller控制器的scrollToIndex方法，建立分类标签与内容列表的联动机制。当用户点击特定分类标签时，同步触发分类栏滚动至目标位置，并驱动内容列表滚动至对应的数据索引位置，实现精准定位，主要包含以下实现要点：

1. **点击标签→内容跟随**：为顶部分类标签组件绑定点击事件，点击顶部标签后，调用scrollerForList.scrollToIndex()将内容列表滚动至对应分组起始位置，同时智能调整标签栏自身可视区域。
2. **标签栏智能偏移**：点击的标签索引>2时，标签栏滚动到被点击的索引位置；索引≤2时，标签栏回滚到起始位置，确保标签始终可见且符合用户视觉习惯，具体的用于判断的索引数值根据实际样式设置。
3. **当前选中态同步** ：通过@State currIndex驱动标签高亮样式和内容定位的同步更新。

   ```ts
   onClick(() => {
     if (index > 2) {
    // 分类标签根据点击List的index进行滚动，当index>2（该数值根据实际设置），即点击位置处于列表后半部分，列表滚动到index位置。
       this.scrollerForTitle.scrollToIndex(index, true);
     } else {
      // 分类标签根据点击List的index进行滚动，当index<=2时（该数值根据实际设置），即点击位置处于列表前半部分，列表滚动到首位，以展示附近位置的标题。
       this.scrollerForTitle.scrollToIndex(0, true);
     }
    // 根据当前分类标签index，使用scrollToIndex滚动到下方List组件的指定Index位置，设置对齐方式为ScrollAlign.START。
     this.scrollerForList.scrollToIndex(index, true, ScrollAlign.START);
     this.currIndex = index;
   })
   ```
