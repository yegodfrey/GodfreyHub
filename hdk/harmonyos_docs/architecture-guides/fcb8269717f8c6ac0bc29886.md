# 送餐相机拍照

## 场景介绍

拍照送达是即时配送类应用的高频使用场景之一，如骑手送达外卖后需拍摄放置位置和小票作为送达凭证，以完成订单确认。

本示例主要基于[Camera Kit分段式拍照](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/camera-deferred-capture-0000001821001521)实现快速拍照取证功能，一阶段快速出图用于缩略图回显，二阶段自动保存全质量图；配合[MediaAssetManager.requestImageData](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-photoaccesshelper-mediaassetmanager)以FAST_MODE请求一阶段低质量图数据，实现拍照后毫秒级缩略图展示。

## 实现思路

* **订单列表页（Index）**：使用List+ForEach渲染配送订单卡片，通过getUIContext().getRouter().pushUrl()携带orderId参数跳转拍照页面。
* **自定义相机初始化**：在XComponent.onLoad回调中获取surfaceId，依次完成CameraManager创建、后置摄像头选择、CameraInput打开、PreviewOutput与PhotoOutput创建、PhotoSession配流启动。
* **分段式拍照流程** ：
  1. 注册photoOutput.on('photoAssetAvailable')回调，接收[PhotoAsset](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-photoaccesshelper-photoasset)对象。
  2. 调用MediaAssetChangeRequest.saveCameraPhoto()将一阶段低质量图落盘到媒体库，二阶段全质量图就绪后自动替换。
  3. 调用MediaAssetManager.requestImageData()以FAST_MODE请求一阶段图ArrayBuffer，通过createImageSource()→createPixelMap()转换为PixelMap，直接赋值给@State变量驱动缩略图即时回显。

     ```ts
       photoOutput.on('photoAssetAvailable', async (err, photoAsset) => {
       // 落盘保存
         const request = new MediaAssetChangeRequest(photoAsset);
         request.saveCameraPhoto();
         await phAccessHelper.applyChanges(request);
       // 快速请求一阶段图
         await MediaAssetManager.requestImageData(context, photoAsset,
           { deliveryMode: DeliveryMode.FAST_MODE }, fastHandler);
       });
     ```

* **照片槽位管理**：定义PhotoItem模型（label、required、captured、pixelMap），4个槽位前两个必拍。拍照前记录capturedIndex，回调中按索引写入对应槽位，拍照完成后自动切换到下一槽位。
* **确认送达校验**：点击确认送达按钮时，遍历photoItems检查必拍项是否已完成，未完成则通过getUIContext().getPromptAction().showToast()提示用户。

## 环境准备

* 本示例基于DevEco Studio 6.1.1 Release版本进行编译运行。
* 本示例基于API Version 24 Release版本进行开发与验证。

## 权限说明

* 使用相机：[ohos.permission.CAMERA](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/permissions-for-all-user#ohospermissioncamera)。
* 写入图片视频：[ohos.permission.WRITE_IMAGEVIDEO](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/restricted-permissions#ohospermissionwrite_imagevideo)。
* 读取图片视频：[ohos.permission.READ_IMAGEVIDEO](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/restricted-permissions#ohospermissionread_imagevideo)。
