# 儿童绘画板

## 场景介绍

儿童绘画板是儿童教育类应用中的高频使用场景之一。

[本示例](https://developer.huawei.com/consumer/cn/doc/architecture-guides/draw_board-0000002353184357)基于[Canvas](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-components-canvas-canvas)和[触摸事件](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-universal-events-touch)实现儿童绘画板功能，支持选择画布背景色、画笔颜色、画笔粗细、简笔画图案和绘制固定图形。

## 实现思路

1. 使用[bindSheet](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-universal-attributes-sheet-transition#bindsheet)和[Grid](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-grid)实现自定义颜色选择弹窗。

   ```ts
   .bindSheet($$this.showPenColorBuilder, this.penColorBuilder(), {
     height: this.sheetHeight,
     backgroundColor: Color.White,
     onAppear: () => {
       this.penTempColor = this.penColor;
     }
   });
   ```

   ```ts
   Grid() {
     ForEach(this.penColorList, (item: string, index: number) => {
       GridItem() {
         Stack() {
           Circle({ width: 82, height: 82 })
             .fill(item);
           Image($r('app.media.choose_icon'))
             .width(28)
             .visibility(index === this.penTempColor ? Visibility.Visible : Visibility.Hidden);
         }
         .onClick(() => {
           this.penTempColor = index;
         });
       };
     });
   }
   .columnsTemplate('1fr 1fr 1fr 1fr')
   .rowsGap(10);
   ```

2. 基于[Canvas](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-components-canvas-canvas)组件构建画板，通过监听[onTouch](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-universal-events-touch#ontouch)触摸事件获取当前触点坐标，并使用[CanvasRenderingContext2D](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-canvasrenderingcontext2d)控制画笔路径、颜色及粗细。

   ```ts
   Canvas(this.context)
     .onTouch((event) => {
       if (event.type === TouchType.Down) {
         this.x = event.touches[0].x;
         this.y = event.touches[0].y;
         this.context.beginPath();
         this.tempPath = new Path2D();
         this.tempPath.moveTo(this.x, this.y);
       }
       if (event.type === TouchType.Move) {
         if (this.isEraserMode) {
          // 橡皮擦模式
           this.context.clearRect(event.touches[0].x, event.touches[0].y, 20, 20);
         } else {
           this.isEmpty = false;
       // 画笔路径
           this.x = event.touches[0].x;
           this.y = event.touches[0].y;
          // 画笔颜色
           this.context.strokeStyle = this.penColorList[this.penColor];
         // 画笔粗细
           this.context.lineWidth = this.paintSize;
           this.tempPath.lineTo(this.x, this.y);
           this.context.stroke(this.tempPath);
         }
       }
     });
   ```

3. 使用[CanvasRenderingContext2D](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-canvasrenderingcontext2d)的rect函数绘制矩形，arc函数绘制圆形，使用moveTo和lineTo函数绘制三角形。

   ```ts
       this.context.beginPath();
       this.x = event.touches[0].x;
       this.y = event.touches[0].y;
       this.context.strokeStyle = this.penColorList[this.penColor];
       this.context.lineWidth = this.paintSize;
       if (this.shapeNum === 0) { // 绘制矩形
         this.context.rect(this.x0, this.y0, this.x - this.x0, this.y - this.y0);
       } else if (this.shapeNum === 1) { // 绘制圆形
         let length = (this.x - this.x0) * (this.x - this.x0) + (this.y - this.y0) * (this.y - this.y0);
         this.context.arc(this.x0, this.y0, Math.sqrt(length), 0, 360);
       } else if (this.shapeNum === 2) { // 绘制三角形
         let length = (this.x - this.x0) * (this.x - this.x0) + (this.y - this.y0) * (this.y - this.y0);
         this.context.moveTo(this.x0, this.y0 - Math.sqrt(length));
         this.context.lineTo(this.x0 + Math.sqrt(length * 0.75), this.y0 + Math.sqrt(length) / 2);
         this.context.lineTo(this.x0 - Math.sqrt(length * 0.75), this.y0 + Math.sqrt(length) / 2);
         this.context.closePath();
         this.context.stroke();
       }
       this.context.stroke();
   ```

## 环境准备

* 本示例基于DevEco Studio 6.1.1 Release版本进行编译运行。
* 本示例基于API Version 24 Release版本进行开发与验证。
