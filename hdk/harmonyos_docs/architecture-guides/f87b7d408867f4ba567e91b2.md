# 通过图片识别添加自选股

## 场景介绍

OCR批量导入自选股是金融理财类应用的高频使用场景之一，如用户从行情软件截图或拍摄股票列表后，需要快速将多只股票加入自选，避免逐条录入股票名称和代码。

本示例使用[PhotoViewPicker](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-photoaccesshelper-photoviewpicker)选择图库图片，或使用[cameraPicker](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-camerapicker)调用系统相机拍照，基于[TextRecognition](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/core-vision-text-recognition-api)提取文字及坐标信息。应用按照代码列位置与名称候选距离完成股票名称、代码配对，并提供结果勾选、编辑确认、代码去重和修正名称缓存功能，实现从图片识别到批量加入自选列表的完整流程。

## 实现思路

1. 获取图片并执行文字识别。 图库选图与相机拍照分别返回系统授权访问的图片URI，之后统一交由recognizeImage()处理。该方法使用fileIo以只读方式打开图片，通过ImageSource生成PixelMap，再初始化textRecognition并调用recognizeText()获取文字识别结果：

   ```ts
   file = fs.openSync(uri, fs.OpenMode.READ_ONLY);
   source = image.createImageSource(file.fd);
   pm = await source.createPixelMap();
   await textRecognition.init();
   const visionInfo: textRecognition.VisionInfo = { pixelMap: pm };
   const result: textRecognition.TextRecognitionResult =
   await textRecognition.recognizeText(visionInfo);
   const stocks: StockItem[] = OcrParser.parseStocks(result);
   ```

   识别结束后，无论成功或失败，均在finally中依次释放PixelMap、ImageSource、文件句柄和文字识别服务，避免连续识别多张图片时占用资源。
2. 基于文字坐标筛选股票代码列。 OcrParser.parseStocks()先遍历识别结果中的文本块与文本行，将文字内容及四角坐标转换为OcrLineData。OcrLineData.create()计算每行文字的纵向中心点、左右边界及横向中心点，为后续空间匹配提供统一数据结构。

   解析器从每行文字中提取长度为6至7位的连续数字作为股票代码候选，再计算所有候选代码左边界的中位数，将其作为主代码列位置。仅保留与主代码列横向偏差不超过阈值的候选，减少价格、成交量等数字被误判为股票代码的情况：

   ```ts
   const codeLines: number[] = [];
   for (let i = 0; i < lines.length; i++) {
     if (OcrParser.extractStockCode(lines[i].text) !== '') {
       codeLines.push(i);
     }
   }
   codeLines.sort((a: number, b: number): number => lines[a].centerY - lines[b].centerY);
   const mainColX: number = OcrParser.findMainCodeColumn(lines, codeLines);

   for (let i = 0; i < codeLines.length; i++) {
     const lineIndex: number = codeLines[i];
     const line: OcrLineData = lines[lineIndex];
     if (Math.abs(line.leftX - mainColX) > StockConfig.CODE_COL_TOLERANCE) {
       continue;
     }
     const code: string = OcrParser.extractStockCode(line.text);
   }
   ```


3. 按优先级配对股票名称。 确定代码所在文本行后，resolveName()按照从强到弱的顺序查找股票名称。解析器优先查找与代码横向范围重叠、纵向距离较近的相邻名称，其次提取代码同行前后的名称，再查找同一行或附近区域的候选名称：

   ```ts
   private static resolveName(lines: OcrLineData[], codeLineIndex: number,
   code: string, usedNames: string[]): string {
     const line: OcrLineData = lines[codeLineIndex];
     const upperName: string = OcrParser.findNeighborName(lines, codeLineIndex, usedNames);
     if (upperName !== '') {
       return upperName;
     }
     const codeIndex: number = line.text.indexOf(code);
     const before: string = codeIndex > 0 ? line.text.substring(0, codeIndex) : '';
     const after: string = codeIndex >= 0 ? line.text.substring(codeIndex + code.length) : '';
     const beforeName: RegExpExecArray | null =
     new RegExp('[一-龥A-Za-z\\-]{2,}$').exec(before.trim());
     if (beforeName !== null) {
       return beforeName[0];
     }
     const afterName: RegExpExecArray | null =
     new RegExp('^[一-龥A-Za-z\\-]{2,}').exec(after.trim());
     if (afterName !== null) {
       return afterName[0];
     }
     const sameRowName: string = OcrParser.findSameRowName(lines, codeLineIndex, usedNames);
     if (sameRowName !== '') {
       return sameRowName;
     }
     return OcrParser.findClosestName(lines, codeLineIndex, usedNames);
   }
   ```

   名称候选需符合长度与字符规则，并排除"最新价""涨跌幅""换手率"等行情标签及已被使用的名称。不同股票列表虽然可能采用上下排列或左右排列，仍可通过坐标距离、范围重叠和候选评分完成配对。
4. 人工确认、名称缓存与自选去重。 识别到股票后，页面将结果写入编辑数组并默认勾选全部条目。用户可取消不需要的条目，也可直接修正股票名称和代码；确认时只处理名称、代码均非空的已勾选条目：

   ```ts
   for (let i = 0; i < this.pendingStocks.length; i++) {
     const checked: boolean = i < this.editChecked.length ? this.editChecked[i] : true;
     if (!checked) {
       continue;
     }
     const name: string = i < this.editNames.length ?
     this.editNames[i] : this.pendingStocks[i].name;
     const code: string = i < this.editCodes.length ?
     this.editCodes[i] : this.pendingStocks[i].code;
     if (name.trim() !== '' && code.trim() !== '') {
       const item: StockItem = StockItem.create(code.trim(), name.trim());
       items.push(item);
       StockCache.saveName(item.code, item.name);
     }
   }
   ```

   StockCache使用[Preferences](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-data-preferences)保存代码与确认名称的映射。再次识别到相同代码时，应用优先使用缓存名称，减少重复修正。加入自选列表前再按股票代码去重，并通过提示信息反馈新增数量与跳过数量。

## 说明

* 本示例根据连续6至7位数字及文字坐标识别股票代码和名称，识别效果受图片清晰度、文字方向和列表排版影响。
* 本示例仅持久化用户确认后的股票代码与名称映射，自选列表保存在页面状态中，应用重新启动后不会恢复。

## 环境准备

* 本示例基于DevEco Studio 6.1.1 Release版本进行编译运行。
* 本示例基于API Version 24 Release版本进行开发与验证。
