# 复制粘贴实践

## 场景介绍

复制粘贴实践是金融理财类应用的高频使用场景之一，如用户在理财应用中需要复制银行卡号、交易流水、分析文本、图片等内容并粘贴到目标位置。

本示例使用[使用剪贴板进行复制粘贴](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/use-pasteboard-to-copy-and-paste)提供数据复制粘贴能力，结合[Text](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-text)、[Image](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-image)、[RichEditor](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-richeditor)、[PdfView](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/pdf-arkts-pdfview-component)等组件，按内容类型划分为文本、链接、代码、数字串、图片、文件6个模块，系统演示ArkTS下各类内容的复制与粘贴验证闭环，覆盖纯文本、PixelMap图片、文件URI、PDF文本选择等多种数据类型与剪贴板API的配合使用。

## 实现思路

1. **剪贴板工具封装** ：统一封装PasteboardUtil，提供文本、图片PixelMap、文件URI三类数据的复制与读取能力，并处理READ_PASTEBOARD权限的动态申请。文本复制用createData创建MIMETYPE_TEXT_PLAIN记录后setData；读取时用getRecord(0)取首条记录，兼容UTD类型映射直接读plainText。

   ```ts
   // 文本复制
   static async copyText(text: string): Promise<boolean> {
     const pasteData: pasteboard.PasteData = pasteboard.createData(
       pasteboard.MIMETYPE_TEXT_PLAIN, text
     );
     await pasteboard.getSystemPasteboard().setData(pasteData);
     return true;
   }

   static async readText(): Promise<string> {
       const pasteData: pasteboard.PasteData = await pasteboard.getSystemPasteboard().getData();
       if (pasteData && pasteData.getRecordCount() > 0) {
           const record: pasteboard.PasteDataRecord = pasteData.getRecord(0);
           if (record.mimeType === pasteboard.MIMETYPE_TEXT_PLAIN) {
               return record.plainText as string;
           }
        // ...
       }
       return '';
   }
   ```

2. **文本类复制** ：用Text组件的copyOption(CopyOptions.LocalDevice)开启系统长按选择复制菜单；长文本通过maxLines+TextOverflow.Ellipsis实现折叠展开；合并转发消息单条复制通过独立Text容器隔离选择范围。

   ```ts
   // Text开启长按选择复制
   Text($r('app.string.sample_short_text'))
       .width('100%')
       .fontSize(15)
       .copyOption(CopyOptions.LocalDevice);

   // 长文本折叠展开
   Text($r('app.string.sample_long_text'))
       .maxLines(this.isLongTextExpanded ? 100 : 3)
       .textOverflow({ overflow: TextOverflow.Ellipsis })
       .copyOption(CopyOptions.LocalDevice);
   ```

3. **代码块复制** ：用自定义CodeHighlighter将代码字符串按正则拆分为关键字、字符串、注释、数字、函数、类型等token，Text内用ForEach渲染不同颜色的Span，不影响copyOption长按复制拼接为纯文本。

   ```ts
   // 代码高亮tokenize
   static tokenize(code: string): CodeToken[] {
       const pattern: RegExp = new RegExp(
           '(\\/\\/[^\\n]*)|' +           // 单行注释
           '(\\/\\*[\\s\\S]*?\\*\\/)|' +  // 多行注释
           '("(?:[^"\\\\]|\\\\.)*")|' +   // 字符串
           '(\\b\\d+\\.?\\d*\\b)|' +      // 数字
           '([a-zA-Z_$][a-zA-Z0-9_$]*)',  // 标识符
           'g'
       );
       // ...
       return tokens;
   }

   // Span渲染着色
   Text() {
       ForEach(this.codeBlockTokens, (token: CodeToken) => {
           Span(token.text)
               .fontColor(CodeHighlighter.getColor(token.type))
       }, (token: CodeToken, index: number) => `${index}_${token.type}`)
   }
   .copyOption(CopyOptions.LocalDevice);
   ```

4. **图片复制** ：通过getRawFileContent读取rawfile图片为buffer，解码为PixelMap后用createRecord(MIMETYPE_PIXELMAP)写入剪贴板；多图复制追加多条record；缩略图网格多选用onTouch+setTimeout自定义长按检测，避免LongPressGesture被Image的draggable行为拦截。

   ```ts
   // 从rawfile创建PixelMap
   static async createPixelMapFromRawfile(
       context: common.UIAbilityContext, rawfileName: string
   ): Promise<image.PixelMap | null> {
       const buffer: Uint8Array = await context.resourceManager.getRawFileContent(rawfileName);
       const imageSource: image.ImageSource = image.createImageSource(buffer.buffer);
       const pixelMap: image.PixelMap = await imageSource.createPixelMap();
       imageSource.release();
       return pixelMap;
   }

   // 复制图片到剪贴板
   static async copyImage(pixelMap: image.PixelMap): Promise<boolean> {
       const pasteData: pasteboard.PasteData = pasteboard.createData(
           pasteboard.MIMETYPE_TEXT_PLAIN, ''
       );
       const record: pasteboard.PasteDataRecord = pasteboard.createRecord(
           pasteboard.MIMETYPE_PIXELMAP, pixelMap
       );
       pasteData.replaceRecord(0, record);
       await pasteboard.getSystemPasteboard().setData(pasteData);
       return true;
   }
   ```

5. **文件URI复制** ：rawfile文件先写入沙箱filesDir，用fileUri.getUriFromPath转为标准file://URI写入剪贴板；粘贴时用fileIo.copy从源URI复制到新路径；点击文件卡片用filePreview.openPreview拉起系统预览。

   ```ts
   // rawfile写入沙箱并转为URI
   const buffer: Uint8Array = context.resourceManager.getRawFileContentSync('sample.pdf');
   const filePath: string = `${context.filesDir}/sample.pdf`;
   const file: fileIo.File = fileIo.openSync(filePath, fileIo.OpenMode.WRITE_ONLY | fileIo.OpenMode.CREATE);
   fileIo.writeSync(file.fd, buffer.buffer);
   fileIo.closeSync(file);
   const fileUriStr: string = fileUri.getUriFromPath(filePath);

   // 粘贴时复制文件
   const uris: Array<string> = await PasteboardUtil.readUris();
   const destUriStr: string = fileUri.getUriFromPath(destPath);
   await fileIo.copy(uris[0], destUriStr);
   ```

6. **PDF内容复制** ：用PdfView组件内嵌预览PDF，通过registerTextSelectedListener监听长按选中的文字，回调中拿到param.text后调用copyText写入剪贴板，解决文件阅读界面无法长按选择复制文字的问题。

   ```ts
   // PdfView组件声明
   PdfView({
       controller: this.pdfController,
       pageFit: pdfService.PageFit.FIT_WIDTH,
       showScroll: true
   })
       .width('100%')
       .height(400);

   // 注册文本选择监听
   this.pdfController.registerTextSelectedListener((param: pdfViewManager.TextSelectedParam) => {
       this.selectedPdfText = param.text;
   });
   ```

## 环境准备

* 本示例基于DevEco Studio 6.1.1 Release版本进行编译运行。
* 本示例基于API Version 24 Release版本进行开发与验证。
