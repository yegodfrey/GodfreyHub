# 招聘信息及岗位列表展示

#### 场景介绍

招聘信息及岗位列表展示是求职招聘类应用中的高频使用场景之一。

本示例基于[Navigation](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-navigation)实现页面跳转，基于[List](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-list)实现岗位列表的展示。  

#### 效果预览

![](https://media:201787627672635824 "点击放大")  

#### 实现思路

* 基于[Navigation](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-navigation)实现页面跳转。

  ```
  Image($r('app.media.small_avatar'))
    .width(50)
    .height(50)
    .onClick(()=>{
      this.pathStack.pushPathByName('PersonalIntroductionPage',null)
    })
  ```

* 基于[List](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-list)实现岗位列表的展示。

  ```
  List() {
    ForEach(this.jobArr, (item: JobType, index: number) => {
      ListItem() {
        JobListItem({ data: item })
      }
    })
  }
  ```

#### 环境准备

* 本示例基于DevEco Studio 6.1.1 Release版本进行编译运行。
* 本示例基于API Version 24 Release版本进行开发与验证。
