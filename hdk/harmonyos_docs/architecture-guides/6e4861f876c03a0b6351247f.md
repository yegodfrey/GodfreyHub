# 视频投播接入实践

## 场景介绍

本文面向视频投播类应用的开发者，基于AVSession+AVCastController+AVCastPicker，介绍一套完整的投播实现方案，涵盖以下五大流程：

|流程|核心能力|关键 API|
|:----|:--------------------|:------------------------------------------------|
|设备发现|协议选择、设备扫描与过滤|AVCastPicker、setAVMetadata(filter)、setExtras|
|建立会话|媒体会话 + 投播会话|createAVSession、getAVCastController、prepare/start|
|遥控器控制|播放/暂停、进度、上下集、音量、倍速与同步|sendControlCommand、playbackStateChange|
|设备切换|远端切换、断开回退、切回本端|outputDeviceChange|
|结束投屏|释放投播资源、恢复本端|releaseAVCast、stopCasting|

## 实现思路

1. **整体架构**

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2a/v3/jk_5sPoLS-ij_VKmGoKYhw/zh-cn_image_0000002758390465.png?HW-CC-KV=V1&HW-CC-Date=20260924T063700Z&HW-CC-Expire=31536000000&HW-CC-Sign=940B91BB6D69ABEE32D0C56267D2DF142E1E1CB59B91C777DEF11327C69AC504 "点击放大")

   投播场景中存在两个层级不同的"会话"：
   * **媒体会话AVSession** ：本端播放开始时创建，用于把播放信息接入系统播控中心、锁屏、控制中心。它同时是投播的**入口**（通过getAVCastController()拿到投播控制器）。
   * **投播会话AVCastController** ：用户在投屏面板选中远端设备后建立，负责向接收端下发prepare/start及各类控制命令，并回传接收端的播放状态。 说明
     >
     > AVSession是本端与系统播控中心的桥梁，AVCastController是本端与远端设备之间的投播通道。二者生命周期独立------结束投屏只释放投播会话，媒体会话仍可保留用于本端播放。
2. **设备发现**
   1. **场景描述**

      用户点击"投屏"后，先选择投播协议（Cast+/DLNA），再在系统投屏面板中看到**仅支持所选协议**的远端设备，选中即触发连接。
   2. **实现原理**

      设备发现完全交给系统投播框架完成，应用通过三步约束发现范围：
      * **能力声明**：videoSession.setExtras({ 'requireAbilityList': ['url-cast'] })声明本次会话需要"URL投播"能力，过滤掉不支持URL投播的设备。
      * **协议过滤**：切换协议时调用setAVMetadata更新元数据的filter字段（TYPE_DLNA或TYPE_CAST_PLUS_STREAM），投屏面板据此只发现支持该协议的设备。
      * **面板展示**：界面中放置AVCastPicker组件，系统负责扫描局域网设备并渲染列表，应用无需自行实现发现逻辑。
   3. **时序图**

      ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0c/v3/6wVdrztkT6euYskQ6hOG5w/zh-cn_image_0000002728831152.png?HW-CC-KV=V1&HW-CC-Date=20260924T063700Z&HW-CC-Expire=31536000000&HW-CC-Sign=CD7DBC5ABF265CDF740EED18BA290DE7D23F06BF0CE78509C8EB46C1F98B42C9 "点击放大")
   4. **开发步骤**
      1. 声明url-cast能力（在初始化投屏面板时调用一次）。

         ```ts
         await videoSession.setExtras({
           'requireAbilityList': ['url-cast']
         });
         ```

      2. 切换协议时更新元数据filter字段，收敛可发现的设备范围。

         ```ts
         public async setCastProtocol(filter: avSession.ProtocolType) {
           if (!this.lastCastSource) {
             return;
           }
           await this.setAVMetadata(this.lastCastSource, this.lastCastDuration, filter);
         }
         ```

      3. 在界面中放置AVCastPicker组件展示系统投屏面板。

         ```ts
         AVCastPicker({
           normalColor: Color.Black,
           pickerStyle: AVCastPickerStyle.STYLE_PANEL,
           sessionType: 'video',
         })
         ```

   5. **关键点**
      * filter未指定时默认TYPE_DLNA|TYPE_CAST_PLUS_STREAM（同时发现两种协议的设备）；指定后即收敛为单一协议。
      * 协议切换只更新元数据的filter，影响**后续设备发现的过滤范围**，不影响已建立的投播连接。
      * 投播过程中如需切换设备，直接点击遥控器页顶栏内嵌的AVCastPicker重新选择即可，无需重新选择协议；首次投屏才需要"先选协议、再选设备"的完整流程。
3. **建立会话**
   1. **场景描述**

      会话建立分两阶段：本端开始播放时先建立**媒体会话** （接入播控中心）；用户选定投播设备后，再建立**投播会话**（打通与远端设备的控制通道），本端随即切换到遥控器界面。
   2. **实现原理**
      * **媒体会话**：VideoSessionController.create()内部完成createAVSession→activate()，并启动后台长时任务；随后通过setAVMetadata/setAVQueueItems/setAVPlaybackState同步元数据、剧集队列与播放状态。
      * **投播会话**：outputDeviceChange通知远端已连接后，调用videoSession.getAVCastController()拿到投播控制器，VideoCastController.initAVCast()构造AVQueueItem并调用prepare()→start()完成资源投播。prepare仅在首次投播时执行（DLNA下重复prepare会导致设备重连）。
   3. **时序图**

      ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c3/v3/WNvMdoupRFqthnmMcvBaGg/zh-cn_image_0000002728991828.png?HW-CC-KV=V1&HW-CC-Date=20260924T063700Z&HW-CC-Expire=31536000000&HW-CC-Sign=667EDBE0E2345F31883C422E128A13F5DB69797044D169C45090DEDDF066AA37 "点击放大")
   4. **开发步骤**
      1. 创建并激活媒体会话，同时申请后台播放长时任务。

         ```ts
         let videoSession = await avSession.createAVSession(context, 'VIDEO_SESSION', 'audio');
         await videoSession.activate();
         BackgroundTaskManager.startContinuousTask(context);
         ```

      2. 同步元数据与剧集队列。

         ```ts
         let metadata: avSession.AVMetadata = {
           assetId: `${curSource.index}`,
           title: curSource.name,
           mediaImage: headPixel,
           duration: duration,
           filter: filter ?? (avSession.ProtocolType.TYPE_DLNA | avSession.ProtocolType.TYPE_CAST_PLUS_STREAM)
         };
         await this.videoSession.setAVMetadata(metadata);
         await this.videoSession.setAVQueueItems(items);
         ```

      3. 远端连接后获取投播控制器并初始化投播资源。

         ```ts
         let session = await this.avSessionController.videoSession.getAVCastController();
         this.avCastPlayerController = new VideoCastController(session);
         await this.avCastPlayerController.initAVCast(this.videoList, this.videoIndex, this.videoType, this.avplayerTime);
         ```

      4. 构造AVQueueItem并prepare/start（网络视频用mediaUri，本地视频用fdSrc）。

         ```ts
         let playItem: avSession.AVQueueItem = {
           itemId: videoIndex,
           description: {
             title: this.videoDataArray[videoIndex].name,
             mediaUri: this.videoDataArray[videoIndex].url,   // 网络视频
             // fdSrc:{fd:file.fd},本地视频
             mediaType: 'VIDEO',
             startPosition: startPosition,
             duration: this.videoDataArray[videoIndex].duration
           }
         };
         if (!this.isPrepared) {
           await this.avCastController.prepare(playItem);
           this.isPrepared = true;
         }
         await this.avCastController.start(playItem);
         ```

   5. **关键点**
      * 投播时长以接收端getCurrentItem()返回的时长为单一来源。接收端尚未解析出时长时兜底使用本地元数据，避免进度条因max=0显示为100%。
      * prepare仅在首次投播时调用（isPrepared标记）；DLNA下重复prepare会重新协商会话导致设备重连。
4. **遥控器控制**

   投播建立后本端自动切换为遥控器界面，所有控制统一通过sendControlCommand下发AVCastControlCommand。下表为命令汇总：

   |功能|命令 command|```screen parameter ```|
   |:------|:----------------------|:----------------------|
   |播放 / 暂停|play / pause|无|
   |进度控制|```screen seek ```|目标位置（ms）|
   |快进 / 快退|fastForward / rewind|偏移秒数（如 15）|
   |音量控制|```screen setVolume ```|音量值（0-100）|
   |倍速设置|```screen setSpeed ```|media.PlaybackSpeed 枚举|

   ```ts
   private async sendCommand(command: avSession.AVCastControlCommand) {
     try {
       await this.avCastController.sendControlCommand(command);
     } catch (error) {
       Logger.error(TAG, `send ${command.command}`, error);
     }
   }
   ```

   1. **播放/暂停**
      1. **实现原理**

         遥控器页、播控中心和锁屏均可触发播放/暂停。命令源统一汇聚到VideoCastController：遥控器页直接调用setAVCastPlay/Pause；系统播控中心下发的play/pause命令经VideoSessionController.setAvSessionListener按"是否正在投播"态路由到投播控制器或本端播放器。
      2. **时序图**

         ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/87/v3/csh5T5YHQK2CS7FA6ZizfA/zh-cn_image_0000002758393111.png?HW-CC-KV=V1&HW-CC-Date=20260924T063700Z&HW-CC-Expire=31536000000&HW-CC-Sign=96513865CEA5078A430A05169E28F47799839F448D4F68BB659E0FCC35BB4690 "点击放大")
      3. **开发步骤**

         ```ts
         public async setAVCastPlay() {
           await this.sendCommand({ command: 'play' });
         }
         public async setAVCastPause() {
           await this.sendCommand({ command: 'pause' });
         }
         ```

   2. **进度控制**
      1. **实现原理**

         进度控制采用**拖动中暂停、松手seek并恢复**策略，避免拖动过程中接收端位置回传与本地进度互相拉扯：
         * Begin：置isSeeking=true并向接收端下发pause；
         * Moving：仅更新本地进度，**不发送**seek指令；
         * End/Click：置isSeeking=false，先本地跳到目标位置，再下发seek+play。

         同时，playbackStateChange(['position'])回调在isSeeking为true时忽略接收端上报的位置。
      2. **时序图**

         ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6c/v3/QAVqr8KaQFicSfh7kUodrg/zh-cn_image_0000002728834086.png?HW-CC-KV=V1&HW-CC-Date=20260924T063700Z&HW-CC-Expire=31536000000&HW-CC-Sign=D5F68A84B79364EDB9DE295D4D92178E861530C3756F38F30C5B8174AF5C924E "点击放大")

      3. **开发步骤**

         ```ts
         public async seekBySlider(value: number, mode: SliderChangeMode) {
           switch (mode) {
             case SliderChangeMode.Begin:
               this.isSeeking = true;
               await this.setAVCastPause();
               break;
             case SliderChangeMode.Moving:
            // 拖动中仅更新本地进度，不向接收端发送seek指令
               this.elapsedTime = value;
               this.positionListeners.forEach(listener => listener(value));
               break;
             case SliderChangeMode.Click:
             case SliderChangeMode.End:
               this.isSeeking = false;
               this.elapsedTime = value;
               this.positionListeners.forEach(listener => listener(value));
               await this.setAVCastSeek(value);
               await this.setAVCastPlay();
               break;
           }
         }
         ```

   3. **上下集切换**
      1. **实现原理**

         上下集切换通过重新调用setCastResource(目标集,0)完成：构造新集数的AVQueueItem并start，进度重置为0。切换入口有三处，均汇聚到playNext/playPrevious：
         * 遥控器页"上一集/下一集"按钮；
         * 系统播控中心下发的playNext/playPrevious（经videoSession.on('playNext'/'playPrevious')路由）；
         * 接收端（大屏）主动触发的playNext/playPrevious及播放结束endOfStream（经avCastController.on(...)回调）。
      2. **时序图**

         ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7e/v3/_6SRLGZjQOiZ-eLSrnMRYg/zh-cn_image_0000002758394295.png?HW-CC-KV=V1&HW-CC-Date=20260924T063700Z&HW-CC-Expire=31536000000&HW-CC-Sign=4ECBF7117BB484C67F3CC9BC76D94D76586DBBCE653C8827264135E04AE6B0FE "点击放大")
      3. **开发步骤**

         ```ts
         public async playNext() {
           this.videoIndex = nextIndex(this.videoIndex, this.videoDataArray.length);
           await this.setCastResource(this.videoIndex, 0);
         }
         public async playPrevious() {
           if (this.videoIndex > 0) {
             this.videoIndex = this.videoIndex - 1;
           }
           await this.setCastResource(this.videoIndex, 0);
         }

         // 接收端主动触发的切集/播放结束自动连播
         this.avCastController.on('playNext', async () => {
           await this.playNext();
         });
         this.avCastController.on('playPrevious', async () => {
           await this.playPrevious();
         });
         this.avCastController.on('endOfStream', async () => {
           await this.playNext();
         });
         ```

      3. **开发步骤**

   5. **倍速设置与同步**
      1. **实现原理**

         倍速包含"设置"与"同步"两个方向：
         * **设置**：遥控器页选择倍速档位→setAVCastSpeed(PlaybackSpeed)→setSpeed命令下发到接收端。
         * **同步**：接收端（大屏/播控中心）设置的倍速经playbackStateChange(['speed'])回传，本端将数值反查为档位标签（getSpeedLabel）更新倍速选择器，并写回AVSession播放状态，使手机控制中心同步显示。

         倍速档位（0.125X~3.0X）到media.PlaybackSpeed的映射统一收敛在CommonConstants，需覆盖接收端支持的完整范围（含1.75X），否则接收端上报的非标档位会回落为默认1.0X。
      2. **时序图**

         ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4c/v3/OcXmWU-CQceUD_Z5RwWrPg/zh-cn_image_0000002758514841.png?HW-CC-KV=V1&HW-CC-Date=20260924T063700Z&HW-CC-Expire=31536000000&HW-CC-Sign=D360B252306D436519E5E076AE8632333CB387FFD7601C9D5A8726AE7D6D835D "点击放大")

         1. 定义倍速档位与枚举映射。

            ```ts
            static readonly SPEED_CHOOSE: string[] =
              ['3.0X', '2.0X', '1.75X', '1.5X', '1.25X', '1.0X', '0.75X', '0.5X', '0.25X', '0.125X'];
            ```

         2. 下发倍速命令。

            ```ts

              await this.sendCommand({ command: 'setSpeed', parameter: speed });
            }
            ```

         3. 监听接收端倍速变化并同步到倍速选择器与播控中心。


5. **设备切换**
   1. **场景描述**

      投播过程中用户可能：切换到另一台远端设备；远端设备意外断开或主动切回本端播放。系统通过outputDeviceChange事件统一上报连接状态与设备类别，应用据此切换界面与播放状态。
   2. 实现原理 outputDeviceChange(connectState,device)携带两个关键字段：

      * connectState：STATE_CONNECTED/STATE_DISCONNECTED；
      * device.devices[0].castCategory：CATEGORY_REMOTE（远端设备）或CATEGORY_LOCAL（本端设备）。

      据此三分支处理：

      |分支|条件|处理|
      |:---|:-----------------------------------|:----------------|
      |连接远端|CATEGORY_REMOTE + STATE_CONNECTED|跳转遥控器页，释放本端播放器|
      |远端断开|CATEGORY_REMOTE + STATE_DISCONNECTED|释放投播控制器 + 停止投播|
      |切回本端|```screen CATEGORY_LOCAL ```|清空遥控器页，恢复本端播放（续播）|

   3. 时序图 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/98/v3/Vxxei6-NQOuZLQcPaCXnyg/zh-cn_image_0000002728995656.png?HW-CC-KV=V1&HW-CC-Date=20260924T063700Z&HW-CC-Expire=31536000000&HW-CC-Sign=F9C0970866587E656D7C4E0E07CAEC289BD8DC64D4BED32321B8E45EEB69881D "点击放大")

   4. 开发步骤

      ```ts
      videoSession.on('outputDeviceChange', async (connectState, device) => {
        if (device.devices[0].castCategory === avSession.AVCastCategory.CATEGORY_REMOTE &&
          connectState === avSession.ConnectionState.STATE_CONNECTED) {
        // 远端已连接：跳转遥控器页，释放本端播放器
          this.remoteControlPathStack.replacePath({ name: 'detail', param: this.currentTime });
          this.castingList.push(this.videoType);
          await this.releaseAVPlayer();
        } else if (device.devices[0].castCategory === avSession.AVCastCategory.CATEGORY_REMOTE &&
          connectState === avSession.ConnectionState.STATE_DISCONNECTED) {
       // 远端断开：释放投播资源
          if (this.avCastController) {
            await this.avCastController.releaseAVCast();
            await this.avSessionController!.stopCasting();
            this.avCastController = undefined;
          }
        } else if (device.devices[0].castCategory === avSession.AVCastCategory.CATEGORY_LOCAL) {
         // 切回本端：清空遥控器页，恢复本端播放（续播）
          this.remoteControlPathStack.clear();
          let videoType = this.castingList[0];
          this.castingList = [];
          let videoPlayParam = new VideoPlayParam(videoType, this.avplayerContinueTime, this.avplayerContinueIndex);
          this.videoPlayPathStack.replacePath({ name: 'detail', param: videoPlayParam });
        }
      });
      ```

   5. **关键点**
      * 本端播放进度通过avplayerContinueTime/avplayerContinueIndex持续记录，保证切回本端时能**续播**。
      * 遥控器页顶栏也内置AVCastPicker，投播过程中可直接重选设备，触发新的STATE_CONNECTED分支完成设备切换。
6. **结束投屏**
   1. **场景描述**

      用户在遥控器页点击"结束投屏"，本端释放投播资源，输出设备切回本端，恢复到本端播放状态。
   2. 实现原理 结束投屏分两步：

      1. **释放投播控制器**：releaseAVCast()移除所有playbackStateChange/playNext/playPrevious/endOfStream监听，停止卡死探活定时器，并调用avCastController.release()。
      2. **停止投播会话**：videoSession.stopCasting()结束会话，系统触发outputDeviceChange(CATEGORY_LOCAL)，进入设备切换的"切回本端"分支，恢复本端播放。

   4. 开发步骤

      ```ts
      async endCasting() {
        if (this.avCastPlayerController && this.avSessionController) {
          await this.avCastPlayerController.releaseAVCast();
          this.avCastPlayerController = undefined;
          await this.avSessionController.stopCasting();
        }
      }
      ```

      ```ts
      public async releaseAVCast() {
        this.isPrepared = false;
        this.isRecovering = false;
        this.retryCount = 0;
        this.stopLivenessCheck();
        this.clearRetryTimer();
        this.avCastController.off('playbackStateChange');
        this.avCastController.off('playNext');
        this.avCastController.off('playPrevious');
        this.avCastController.off('endOfStream');
        await this.avCastController.release();
      }
      ```

   5. **关键点**
      * 结束投屏**只释放投播会话**，媒体会话（AVSession）可保留用于本端播放；完全退出播放时才stopCasting()+destroy()。
