# 外卖员无法正常查看状态栏痛点总结

## 场景介绍

本示例主要基于[@ohos.window（窗口）](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-window)提供的setWindowSystemBarProperties接口与系统深浅色模式监听，实现深色页面及系统深色模式下状态栏文字颜色的自动适配，并通过错误示例与正确示例的对比直观展示适配效果。

## 实现思路

示例围绕"获取窗口实例+封装适配工具类+页面响应模式变化"的思路实现，核心逻辑拆分为三个部分。

1. **获取窗口实例与配置监听（EntryAbility）**

   在onWindowStageCreate中加载页面后获取主窗口实例，调用setWindowLayoutFullScreen开启全屏布局，使页面内容延伸到状态栏区域，并将窗口实例与当前颜色模式缓存到AppStorage；同时在onConfigurationUpdate中更新颜色模式，供页面感知系统深浅色切换：

   ```ts
   import { Configuration, ConfigurationConstant, UIAbility } from '@kit.AbilityKit';
   import { hilog } from '@kit.PerformanceAnalysisKit';
   import { window } from '@kit.ArkUI';

   const DOMAIN = 0x0000;

   export default class EntryAbility extends UIAbility {
     onCreate(): void {
       try {
         this.context.getApplicationContext().setColorMode(ConfigurationConstant.ColorMode.COLOR_MODE_NOT_SET);
       } catch (err) {
         hilog.error(DOMAIN, 'testTag', 'Failed to set colorMode. Cause: %{public}s', JSON.stringify(err));
       }
       hilog.info(DOMAIN, 'testTag', '%{public}s', 'Ability onCreate');
     }

     onDestroy(): void {
       hilog.info(DOMAIN, 'testTag', '%{public}s', 'Ability onDestroy');
     }

     onWindowStageCreate(windowStage: window.WindowStage): void {
       hilog.info(DOMAIN, 'testTag', '%{public}s', 'Ability onWindowStageCreate');

       windowStage.loadContent('pages/Index', (err) => {
         if (err.code) {
           hilog.error(DOMAIN, 'testTag', 'Failed to load the content. Cause: %{public}s', JSON.stringify(err));
           return;
         }
         hilog.info(DOMAIN, 'testTag', 'Succeeded in loading the content.');

         const windowClass: window.Window = windowStage.getMainWindowSync();
         windowClass.setWindowLayoutFullScreen(true);
         AppStorage.setOrCreate('windowClass', windowClass);
         const avoidArea = windowClass.getWindowAvoidArea(window.AvoidAreaType.TYPE_SYSTEM);
         const uiContext = windowClass.getUIContext();
         AppStorage.setOrCreate('statusBarHeight', uiContext.px2vp(avoidArea.topRect.height));
         windowClass.on('avoidAreaChange', (data) => {
           if (data.type === window.AvoidAreaType.TYPE_SYSTEM) {
             AppStorage.setOrCreate('statusBarHeight', uiContext.px2vp(data.area.topRect.height));
           }
         });
         const colorMode: number = Number(this.context.config.colorMode);
         AppStorage.setOrCreate<number>('currentColorMode', colorMode);
       });
     }

     onConfigurationUpdate(newConfig: Configuration): void {
       const colorMode: number = Number(newConfig.colorMode);
       AppStorage.setOrCreate<number>('currentColorMode', colorMode);
     }

     onWindowStageDestroy(): void {
       hilog.info(DOMAIN, 'testTag', '%{public}s', 'Ability onWindowStageDestroy');
     }

     onForeground(): void {
       hilog.info(DOMAIN, 'testTag', '%{public}s', 'Ability onForeground');
     }

     onBackground(): void {
       hilog.info(DOMAIN, 'testTag', '%{public}s', 'Ability onBackground');
     }
   }
   ```

2. **封装状态栏适配工具类（StatusBarAdapter）**

   *封装统一的状态栏适配工具类，从AppStorage读取窗口实例并调用setWindowSystemBarProperties设置状态栏文字颜色，提供三种适配方法分别适用于不同场景：*

   ```ts
   /**
   * @file StatusBarAdapter.ets
   * @description 状态栏文字颜色适配工具类
   * @module utils
   */

   import { window } from '@kit.ArkUI';
   import { ConfigurationConstant } from '@kit.AbilityKit';
   import { hilog } from '@kit.PerformanceAnalysisKit';

   export class StatusBarAdapter {
    /**
   * 直接设置状态栏文字颜色
   * @param color 颜色值，如 '#FFFFFF' 或 '#000000'
   */
     static apply(color: string): void {
       const windowClass = AppStorage.get<window.Window>('windowClass');
       if (!windowClass) {
         return;
       }
       try {
         windowClass.setWindowSystemBarProperties({
           statusBarContentColor: color
         });
       } catch (err) {
         hilog.error(0x0000, 'StatusBarAdapter', 'Failed to set status bar properties. Cause: %{public}s', JSON.stringify(err));
       }
     }

    /**
   * 根据页面背景深浅设置状态栏文字颜色
   * @param isDarkBackground 是否为深色背景
   */
     static applyForBackground(isDarkBackground: boolean): void {
       StatusBarAdapter.apply(isDarkBackground ? '#FFFFFF' : '#000000');
     }

   /**
   * 根据系统颜色模式设置状态栏文字颜色
   * @param colorMode 当前颜色模式，建议传入 Number(ConfigurationConstant.ColorMode) 后的 number 值
   */
     static applyForColorMode(colorMode: number): void {
       const isDark = colorMode === ConfigurationConstant.ColorMode.COLOR_MODE_DARK;
       StatusBarAdapter.apply(isDark ? '#FFFFFF' : '#000000');
     }
   }
   ```

3. **页面响应模式变化并对比适配效果（Index页面）**

   页面通过@StorageProp('currentColorMode')监听系统颜色模式，配合@Watch在模式变化时重新计算页面背景深浅；并通过"模拟深色页面"与"正确适配状态栏"两个开关，对比错误示例（状态栏文字保持深色）与正确示例（状态栏文字随背景自动切换）的效果：

   ```ts
   /**
   * @file Index.ets
   * @description 深色页面与状态栏适配教学 Demo
   * @module pages
   */

   import { ConfigurationConstant } from '@kit.AbilityKit';
   import { StatusBarAdapter } from '../utils/StatusBarAdapter';

   interface InfoRowParam {
     label: string;
     value: string;
   }

   @Entry
   @Component
   struct Index {
     @StorageProp('currentColorMode')
     @Watch('onColorModeChange')
     currentColorMode: number = ConfigurationConstant.ColorMode.COLOR_MODE_LIGHT;

     @StorageProp('statusBarHeight')
     statusBarHeight: number = 0;

     @State isDarkPage: boolean = false;
     @State isAdapted: boolean = true;
     @State isDarkBackground: boolean = false;
     @State statusBarText: string = '黑色';
     @State colorModeLabel: string = '浅色';

     private updateColorModeLabel(): void {
       if (this.currentColorMode === ConfigurationConstant.ColorMode.COLOR_MODE_DARK) {
         this.colorModeLabel = '深色';
       } else if (this.currentColorMode === ConfigurationConstant.ColorMode.COLOR_MODE_LIGHT) {
         this.colorModeLabel = '浅色';
       } else {
         this.colorModeLabel = '未指定';
       }
     }

     private updateDerivedState(): void {
       const isSystemDark: boolean = this.currentColorMode === ConfigurationConstant.ColorMode.COLOR_MODE_DARK;
       this.isDarkBackground = this.isDarkPage || isSystemDark;

       if (this.isAdapted) {
      // 正确适配：根据页面背景深浅自动设置状态栏文字颜色
         StatusBarAdapter.applyForBackground(this.isDarkBackground);
         this.statusBarText = this.isDarkBackground ? '白色' : '黑色';
       } else {
        // 错误示例：不主动适配，状态栏文字保持默认黑色
         StatusBarAdapter.apply('#000000');
         this.statusBarText = '黑色';
       }
     }

     aboutToAppear(): void {
       this.updateColorModeLabel();
       this.updateDerivedState();
     }

     onColorModeChange(): void {
       this.updateColorModeLabel();
       this.updateDerivedState();
     }

    // 模拟深色页面时，页面内元素同步切换为深色配色（取值与dark/color.json保持一致）
     private primaryColor(): string {
       return this.isDarkBackground ? '#FFFFFF' : '#333333';
     }

     private secondaryColor(): string {
       return this.isDarkBackground ? '#B3B3B3' : '#666666';
     }

     private cardColor(): string {
       return this.isDarkBackground ? '#2C2C2C' : '#FFFFFF';
     }

     @Builder
     InfoRow(param: InfoRowParam) {
       Row() {
         Text(param.label)
           .fontSize(16)
           .fontColor(this.primaryColor())
         Text(param.value)
           .fontSize(14)
           .fontColor(this.secondaryColor())
       }
       .width('100%')
       .justifyContent(FlexAlign.SpaceBetween)
       .padding({ top: 12, bottom: 12 })
     }

     @Builder
     SectionHeader(title: string) {
       Text(title)
         .fontSize(18)
         .fontWeight(FontWeight.Bold)
         .fontColor(this.primaryColor())
         .width('90%')
         .textAlign(TextAlign.Start)
         .margin({ bottom: 8 })
     }

     @Builder
     DescriptionCard(description: string) {
       Column() {
         Text(description)
           .fontSize(14)
           .fontColor(this.primaryColor())
           .textAlign(TextAlign.Start)
           .width('100%')
       }
       .width('90%')
       .padding(16)
       .backgroundColor(this.cardColor())
       .borderRadius(12)
       .margin({ bottom: 24 })
     }

     build() {
       Column() {
         Text('状态栏适配')
           .fontSize(24)
           .fontWeight(FontWeight.Bold)
           .fontColor(this.primaryColor())
           .width('90%')
           .textAlign(TextAlign.Start)
           .margin({ top: 12, bottom: 16 })

      // 信息与控制卡片
         Column() {
           this.InfoRow({ label: '颜色模式', value: this.colorModeLabel });
           this.InfoRow({ label: '页面背景', value: this.isDarkBackground ? '深色' : '浅色' });
           this.InfoRow({ label: '状态栏文字', value: this.statusBarText });

           Row() {
             Text('模拟深色页面')
               .fontSize(16)
               .fontColor(this.primaryColor())
             Toggle({ type: ToggleType.Switch, isOn: this.isDarkPage })
               .onChange((isOn: boolean) => {
                 this.isDarkPage = isOn;
                 this.updateDerivedState();
               })
           }
           .width('100%')
           .justifyContent(FlexAlign.SpaceBetween)
           .padding({ top: 12, bottom: 12 })

           Row() {
             Text('正确适配状态栏')
               .fontSize(16)
               .fontColor(this.primaryColor())
             Toggle({ type: ToggleType.Switch, isOn: this.isAdapted })
               .onChange((isOn: boolean) => {
                 this.isAdapted = isOn;
                 this.updateDerivedState();
               })
           }
           .width('100%')
           .justifyContent(FlexAlign.SpaceBetween)
           .padding({ top: 12, bottom: 12 })
         }
         .width('90%')
         .padding({ left: 16, right: 16, top: 4, bottom: 4 })
         .backgroundColor(this.cardColor())
         .borderRadius(12)
         .margin({ bottom: 24 })

      // 错误示例
         this.SectionHeader('错误示例');
         this.DescriptionCard('未主动设置状态栏文字颜色，深色背景上状态栏信息可能不可见。');

    // 正确示例
         this.SectionHeader('正确示例');
         this.DescriptionCard('调用 setWindowSystemBarProperties 将状态栏文字设为白色，信息清晰可见。');
       }
       .width('100%')
       .height('100%')
       .padding({ top: this.statusBarHeight })
       .backgroundColor(this.isDarkBackground ? $r('app.color.page_background_dark') : $r('app.color.page_background'))
     }
   }
   ```
