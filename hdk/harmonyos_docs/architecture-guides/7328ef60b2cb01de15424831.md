# 录音全链路场景化解决方案

## 场景介绍

会议记录、课堂笔记、采访取证、语音备忘------录音是信息留存的核心手段。录音期间一旦运营商来电到达，系统默认按[音频焦点](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/audio-playback-concurrency)策略打断采集：录音中断或来电期间内容缺失，用户往往在挂断后才发现关键讲话没有被录上，只能重新沟通补录。"录音被来电打断"是业界普遍存在、实现上又有诸多细节坑点的问题。

本示例基于HarmonyOS系统Kit实现录音全链路"录制→管理→播放→转写→分享"：使用[AudioCapturer](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/using-audiocapturer-for-recording)采集16kHz/单声道/16bit PCM音频并自封装WAV落盘；使用[AVPlayer](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/using-avplayer-for-playback)实现五档倍速播放；使用Core Speech Kit的[语音识别](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/speechrecognizer-guide)完成端侧离线转写（录音中实时出字+录音文件整体转写双模式）；使用[分词](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/natural-language-getwordsegmentation)能力提取转写文本关键词；使用[长时任务](https://developer.huawei.com/consumer/cn/doc/HarmonyOS-Guides/continuous-task)保证锁屏、切后台录音不中断；录音元数据经[关系型数据库](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-data-relationalstore)持久化；最后通过systemShare拉起系统分享面板分发录音文件。

本示例的核心亮点是静音续录：采集启动前调用AudioCapturer的[setWillMuteWhenInterrupted](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-audio-audiocapturer)接口并传入true，运营商来电打断期间采集不停、自动录制静音流，挂断后自动恢复有声，全程audioInterrupt事件可观测，整段录音连贯无缺失。一个API即可解决"来电打断录音"难题，配套一套完整可复用的录音全链路工程，全部使用系统Kit实现，零第三方依赖，可完整离线运行。

## 实现思路

工程采用三层结构：页面层（列表页/录音页/播放页）负责交互展示，服务层（RecorderService/PlayerService/TranscribeService）封装采集、播放、转写能力并以单例运行，系统Kit层提供底层能力。录音中页面切走不中断，重新进入时从服务单例同步状态。

1. 麦克风权限申请 **录音启动前动态申请麦克风权限。** ohos.permission.MICROPHONE属于user_grant权限，需先在module.json5的requestPermissions中声明，再通过[程序访问控制管理](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-abilityaccessctrl)的requestPermissionsFromUser拉起系统授权弹窗。用户拒绝授权后无法再次拉起弹窗，此时引导用户前往系统设置：优先调用openPermissionOnSetting直达麦克风权限开关页，调用失败时兜底跳转系统设置的本应用详情页。

   ```ts
   // RecordPage.ets
   private async requestMicPermission(): Promise<boolean> {
     try {
       const atManager: abilityAccessCtrl.AtManager = abilityAccessCtrl.createAtManager();
       const permissions: Array<Permissions> = ['ohos.permission.MICROPHONE'];
       const context: common.Context | undefined = this.getUIContext().getHostContext();
       if (context === undefined) {
         return false;
       }
       const result = await atManager.requestPermissionsFromUser(context, permissions);
       return result.authResults.length > 0 && result.authResults[0] === 0;
     } catch (e) {
       hilog.warn(DOMAIN, TAG, 'request mic permission failed: %{public}s', String(e));
       return false;
     }
   }
   ```

2. **静音续录：AudioCapturer采集与打断处理**

   **采集启动前设置静音续录，来电打断期间采集不停。** 通过createAudioCapturer创建采集器，规格为16kHz/单声道/16bit PCM（该规格与端侧转写引擎的输入要求一致，采集数据可直接喂入转写引擎）。通过on('readData')事件回调持续获取PCM数据，同时通过on('audioInterrupt')观测打断事件。关键点：setWillMuteWhenInterrupted(true)必须在start()之前调用------不设置时系统默认策略会在来电时停止采集；设置后开启[静音打断模式](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/using-audiocapturer-for-recording#设置静音打断模式)，来电打断期间采集不停、自动录入静音流，挂断后自动恢复有声，录音文件连贯无缺失。

   ```ts
   // RecorderService.ets
   const options: audio.AudioCapturerOptions = {
     streamInfo: {
       samplingRate: SAMPLE_RATE,
       channels: audio.AudioChannel.CHANNEL_1,
       sampleFormat: audio.AudioSampleFormat.SAMPLE_FORMAT_S16LE,
       encodingType: audio.AudioEncodingType.ENCODING_TYPE_RAW
     },
     capturerInfo: {
       source: audio.SourceType.SOURCE_TYPE_MIC,
       capturerFlags: 0
     }
   };
   this.capturer = await audio.createAudioCapturer(options);

   // 采集数据回调(事件式异步读, 注册后 start 即持续上抛 PCM buffer)
   this.capturer.on('readData', (buffer: ArrayBuffer) => {
     this.writePcm(buffer);
   });
   // 打断/恢复事件日志: 来电时 BEGIN(采集静音续录), 挂断后 END(自动恢复有声)
   this.capturer.on('audioInterrupt', (event: audio.InterruptEvent) => {
     if (event.eventType === audio.InterruptType.INTERRUPT_TYPE_BEGIN) {
       hilog.info(DOMAIN, TAG, '[Recorder] 通话等高优先级音频开始, 采集静音续录(不停)');
     } else if (event.eventType === audio.InterruptType.INTERRUPT_TYPE_END) {
       hilog.info(DOMAIN, TAG, '[Recorder] 打断结束, 采集自动恢复有声');
     }
   });

   // 【静音续录核心】须在 start 前设置: 打断时静音而非停止
   await this.capturer.setWillMuteWhenInterrupted(true);
   await this.capturer.start();
   ```

   真机上可用另一台手机拨打运营商电话验证：通话期间录音持续（录静音流）、挂断后自动恢复有声，播放录音可听到来电前后内容完整衔接。
3. WAV自封装落盘 **PCM数据实时写入WAV文件，停止时回写头部长度字段。** WAV是44字节标准头+PCM数据的无损封装，无需编码器、PCM可直接喂转写引擎。录制开始时先写入长度为0的占位头，采集数据依次追加；停止时将文件指针移回偏移0，回写真实的RIFF chunkSize（36+数据字节数）与data chunkSize，保证头部与实际数据一致。暂停期间数据段直接丢弃，文件中不留空洞，时长随已写入字节自然停止；时长统一按已写入字节数换算（采样率×字节率），与文件实际时长严格一致。时长不足1秒的录音判定为误触，自动删除文件不入库。

   ```ts
   // RecorderService.ets
   // 开始录音: 先写 44 字节占位头(长度 0), 停止时回写真实长度
   this.file = fileIo.openSync(this.filePath, fileIo.OpenMode.READ_WRITE | fileIo.OpenMode.CREATE);
   fileIo.writeSync(this.file.fd, this.buildWavHeader(0, 0));

   private writePcm(buffer: ArrayBuffer): void {
     if (this.state !== RecorderState.RUNNING || this.file === undefined) {
       return;
     }
     try {
       fileIo.writeSync(this.file.fd, buffer);
       this.dataBytes += buffer.byteLength;
     } catch (e) {
       hilog.error(DOMAIN, TAG, 'write pcm failed: %{public}s', String(e));
     }
   }
   ```

   ```ts
   // RecorderService.ets
   // 停止录音: 回写 WAV 头部长度字段(RIFF chunkSize = 36 + dataSize; data dataSize)
   fileIo.writeSync(this.file.fd, this.buildWavHeader(36 + dataBytes, dataBytes), { offset: 0 });
   fileIo.closeSync(this.file);
   ```

   ```ts
   // RecorderService.ets
   private buildWavHeader(riffSize: number, dataSize: number): ArrayBuffer {
     const buffer: ArrayBuffer = new ArrayBuffer(44);
     const view: DataView = new DataView(buffer);
     this.writeAscii(view, 0, 'RIFF');
     view.setUint32(4, riffSize, true);
     this.writeAscii(view, 8, 'WAVE');
     this.writeAscii(view, 12, 'fmt ');
     view.setUint32(16, 16, true);         // fmt chunk 固定长度 16
     view.setUint16(20, 1, true);          // PCM
     view.setUint16(22, 1, true);          // 单声道
     view.setUint32(24, SAMPLE_RATE, true); // 采样率
     view.setUint32(28, BYTES_PER_SEC, true); // 字节率 = 采样率*块对齐
     view.setUint16(32, 2, true);           // 块对齐 = 声道*样本宽度
     view.setUint16(34, 16, true);         // 位深
     this.writeAscii(view, 36, 'data');
     view.setUint32(40, dataSize, true);
     return buffer;
   }
   ```

4. **后台录音长时任务**

   **录音开始即申请长时任务，锁屏、切后台录音不中断。** 长时任务需先在module.json5中为UIAbility声明backgroundModes: ["audioRecording"]并申请ohos.permission.KEEP_BACKGROUND_RUNNING权限，再通过[后台任务管理](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-resourceschedule-backgroundtaskmanager)的startBackgroundRunning申请录音类长时任务，申请成功后系统展示常驻通知栏。示例中申请调用全程await：start()返回前任务已生效，用户随后立即退后台或锁屏也有连续任务保护，消除任务申请与退后台之间的时序竞争；申请失败不阻断前台录音，通过回调上报页面提示用户。录音停止时调用stopBackgroundRunning释放任务。

   ```ts
   // RecorderService.ets
   private async startBackgroundTask(context: common.Context): Promise<boolean> {
     if (this.backgroundTaskActive) {
       return true;
     }
     try {
       const wantAgentInfo: wantAgent.WantAgentInfo = {
         wants: [
           {
             bundleName: BUNDLE_NAME,
             abilityName: ABILITY_NAME
           }
         ],
         actionType: wantAgent.OperationType.START_ABILITY,
         requestCode: 0,
         actionFlags: [wantAgent.WantAgentFlags.UPDATE_PRESENT_FLAG]
       };
       const agent: WantAgent = await wantAgent.getWantAgent(wantAgentInfo);
       await backgroundTaskManager.startBackgroundRunning(context,
         backgroundTaskManager.BackgroundMode.AUDIO_RECORDING, agent);
       this.backgroundTaskActive = true;
       return true;
     } catch (e) {
       hilog.error(DOMAIN, TAG, 'start background task failed: %{public}s', JSON.stringify(e));
       return false;
     }
   }
   ```

5. **AVPlayer播放与五档倍速**

   **fd协议播放沙箱文件，状态机时序驱动，PlaybackSpeed档位映射倍速。** 播放本地文件时先以只读方式打开文件获得fd，将url设为fd://前缀加fd。注意关键时序：url赋值后播放器异步进入initialized状态，需确认状态到达后再调用prepare，状态机流转为idle→initialized→prepared→playing。倍速通过setSpeed设置，参数为PlaybackSpeed枚举：0.75/1.0/1.25/1.5/2.0五档分别对应SPEED_FORWARD_0_75_X至SPEED_FORWARD_2_00_X，setSpeed仅支持prepared/playing/paused/completed状态，未加载时点击倍速仅记录选中档位、播放开始后再统一应用。播放结束通过stateChange回调中state为completed判定并自动复位释放；切换播放目标前先release旧播放器并关闭fd，fd用后必须关闭，否则文件删除等操作会因占用失败。

   ```ts
   // PlayerService.ets
   private async doPlay(path: string): Promise<void> {
     await this.release();
     this.file = fileIo.openSync(path, fileIo.OpenMode.READ_ONLY);
     const player: media.AVPlayer = await media.createAVPlayer();
     this.avPlayer = player;
     this.currentPath = path;

     player.on('stateChange', (state: media.AVPlayerState, _reason: media.StateChangeReason) => {
       this.lastState = state;
      // 播放完成以 stateChange 回调中 state === 'completed' 判定
       if (state === 'completed') {
         this.release();
         if (this.onEnded !== undefined) {
           this.onEnded();
         }
         return;
       }
       if (this.onStateChange !== undefined) {
         this.onStateChange(state);
       }
     });
     player.on('timeUpdate', (time: number) => {
       if (this.onTimeUpdate !== undefined) {
         this.onTimeUpdate(time, player.duration);
       }
     });

     player.url = 'fd://' + this.file.fd;
    // 关键时序: url 赋值后状态异步进入 initialized, 确认后再 prepare
     const initReady: boolean = await this.waitForState(player, 'initialized');
     if (!initReady) {
       await this.release();
       return;
     }
     await player.prepare();
     await this.waitForState(player, 'prepared');
     await player.play();
   }
   ```

   ```ts
   // PlayerService.ets
   /** 档位 → PlaybackSpeed 枚举映射(不支持的档位兜底 1.0) */
   private toPlaybackSpeed(rate: number): media.PlaybackSpeed {
       const scaledRate = Math.round(rate * 4);
       if (scaledRate === 3) {
         return media.PlaybackSpeed.SPEED_FORWARD_0_75_X;
       }
       if (scaledRate === 5) {
         return media.PlaybackSpeed.SPEED_FORWARD_1_25_X;
       }
       if (scaledRate === 6) {
         return media.PlaybackSpeed.SPEED_FORWARD_1_50_X;
       }
       if (scaledRate === 8) {
         return media.PlaybackSpeed.SPEED_FORWARD_2_00_X;
       }
       return media.PlaybackSpeed.SPEED_FORWARD_1_00_X;
   }
   ```

6. **端侧转写：流式实时与文件双模式**

   **端侧离线引擎，边录边出字；文件模式复用同一引擎整体转写。** 通过[speechRecognizer](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/hms-ai-speechrecognizer)的createEngine创建端侧离线引擎（language: 'zh-CN'、online: 1，飞行模式可用），调用次序约束为setListener先于startListening、startListening先于writeAudio。writeAudio单次写入的数据长度仅支持640或1280字节，内部用pending缓冲把任意长度的PCM切成640字节块再喂入。双模式设计：
   * 流式模式：直接消费录音服务的PCM数据回调，与落盘并行，不开第二路采集，实现边录边出字；中间结果实时上抛灰色显示，句尾最终结果（isFinal）追加进全文。
   * 文件模式：读取已保存WAV跳过44字节头，按块循环喂入，转写整段录音，结果随录音记录落库。

   引擎短语音模式遇静音（如通话打断产生的静音段）会自动结束会话，且单会话音频长度有限制，示例对这两个特性做了适配：流式模式在会话被结束后按退避策略自动续接新会话，挂断恢复语音后识别接续，通话期间的静音续录转写不丢内容；文件模式每12秒主动finish当前会话并开新会话续接，段间结果自动拼接，避免超限导致整段文本丢失。

   ```ts
   // TranscribeService.ets
   private async getEngine(): Promise<speechRecognizer.SpeechRecognitionEngine> {
     if (this.engine !== undefined) {
       return this.engine;
     }
     const params: speechRecognizer.CreateEngineParams = {
       language: LANGUAGE,       // 'zh-CN'
       online: ONLINE_OFFLINE   // 1=端侧离线
     };
     this.engine = await speechRecognizer.createEngine(params);
     return this.engine;
   }

   private buildStartParams(sid: string): speechRecognizer.StartParams {
     const audioInfo: speechRecognizer.AudioInfo = {
       audioType: AUDIO_TYPE,     // 'pcm'
       sampleRate: SAMPLE_RATE, // 16000
       soundChannel: SOUND_CHANNEL, // 1
       sampleBit: SAMPLE_BIT    // 16
     };
     const params: speechRecognizer.StartParams = {
       sessionId: sid,
       audioInfo: audioInfo
     };
     return params;
   }
   ```

   ```ts
   // TranscribeService.ets
   /** 累积 PCM 并按 640 字节切块写入引擎(640/1280 是接口硬约束) */
   private appendAndFlush(input: Uint8Array): void {
     const engine: speechRecognizer.SpeechRecognitionEngine | undefined = this.engine;
     if (engine === undefined) {
       return;
     }
     const merged: Uint8Array = new Uint8Array(this.pending.length + input.length);
     merged.set(this.pending);
     merged.set(input, this.pending.length);
     this.pending = merged;
     while (this.pending.length >= CHUNK_BYTES) {
       const chunk: Uint8Array = this.pending.slice(0, CHUNK_BYTES);
       this.pending = this.pending.slice(CHUNK_BYTES);
       try {
         engine.writeAudio(this.sessionId, chunk);
       } catch (e) {
        // writeAudio 失败通常是引擎会话已被静音自动结束, 静默收尾并续接
         hilog.warn(DOMAIN, TAG, 'writeAudio failed(session ended?): %{public}s', String(e));
         this.handleSessionEnded();
         return;
       }
     }
   }
   ```

   ```ts
   // TranscribeService.ets
   // onResult 处理: isFinal 追加全文, isLast 表示会话收尾(引擎遇静音自动结束)

       this.fullText += result.result;

       }

     if (result.isLast) {
    // 引擎自动结束会话(短语音模式遇静音 eos, 如通话打断): 统一收尾,
   // 录音中则自动续接新会话 ------ 否则挂断后实时转写不会恢复
   ```

7. **转写结果关键词提取**

   **端侧分词加词性过滤，一键提取转写文本关键词。** 转写结果展示弹层内调用[textProcessing](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/natural-language-text-processing-api)的getWordSegment对转写全文分词，按词性标签wordTag过滤出名词类（n开头）与动词类（v开头）词语，去除单字词与重复项后以标签流展示。注意分词接口单次文本长度不超过1000字符，超长文本需截断后再喂入；设备不支持分词能力时降级隐藏提取按钮，不打扰用户。

   ```ts
   // PlaybackPage.ets
   private onExtractClick(): void {
     if (this.isExtracting) {
       return;
     }
     const source: string = this.text.trim();
     if (source === '') {
       return;
     }
     this.isExtracting = true;
     // 分词接口约束: 单次文本长度不超过 1000 字符
     const input: string = source.length > TranscriptDialog.SEGMENT_TEXT_LIMIT ?
       source.substring(0, TranscriptDialog.SEGMENT_TEXT_LIMIT) : source;
     textProcessing.getWordSegment(input)
       .then((segments: textProcessing.WordSegment[]) => {
         const result: string[] = [];
         for (const seg of segments) {
           if (result.length >= TranscriptDialog.MAX_KEYWORDS) {
             break;
           }
           if (!this.isKeywordTag(seg.wordTag)) {
             continue;
           }
           const word: string = seg.word.trim();
           if (word.length < 2 || result.indexOf(word) >= 0) {
             continue;
           }
           result.push(word);
         }
         this.keywords = result;
       })
       .catch((reason: Object) => {
        // 能力降级: 设备不支持端侧分词时隐藏按钮, 仅 hilog 说明
         this.keywordSupported = false;
         hilog.warn(DOMAIN, TAG, 'keyword extraction unavailable: %{public}s', String(reason));
       })
       .finally(() => {
         this.isExtracting = false;
       });
   }

   /** 词性过滤: 名词类(n/nr/ns/nt/nz 等)与动词类(v/vn 等)作为关键词候选 */
   private isKeywordTag(tag: string): boolean {
     return tag.startsWith('n') || tag.startsWith('v');
   }
   ```

   ```ts
   // RecordingStorage.ets
   static async queryAll(): Promise<RecordingInfo[]> {
     const predicates: relationalStore.RdbPredicates = new relationalStore.RdbPredicates(TABLE_NAME);
     predicates.orderByDesc('created_at');
     const resultSet: relationalStore.ResultSet =
       await RecordingStorage.store.query(predicates,
         ['id', 'name', 'file_path', 'duration_sec', 'size_bytes', 'created_at', 'transcripts']);
     const result: RecordingInfo[] = [];

       result.push(new RecordingInfo(

         resultSet.getLong(resultSet.getColumnIndex('duration_sec')),
         resultSet.getLong(resultSet.getColumnIndex('size_bytes')),
         resultSet.getLong(resultSet.getColumnIndex('created_at')),
         resultSet.getString(resultSet.getColumnIndex('transcripts'))
       ));
     }
     resultSet.close();
     return result;
   }
   ```

9. **系统分享**

   **沙箱路径转URI，FILE类型记录拉起系统分享面板。** 分享沙箱内录音文件时，先通过[文件URI](https://developer.huawei.com/consumer/cn/doc/doccenter-capabilities/api/js-apis-file-fileuri)的getUriFromPath将沙箱路径转换为应用URI，构造systemShare的SharedData（utd指定为UniformDataType.FILE类型，uri为文件URI，title为文件名），再通过ShareController的show拉起系统分享面板，将WAV文件分发到备忘录、文件管理等目标应用。

   ```ts
   // PlaybackPage.ets
   private async shareRecording(): Promise<void> {
     if (this.filePath === '') {
       this.showToast('无可分享的录音文件');
       return;
     }
     const context: common.Context | undefined = this.getUIContext().getHostContext();
     if (context === undefined) {
       this.showToast('上下文不可用');
       return;
     }
     try {
       const record: systemShare.SharedRecord = {
         utd: utd.UniformDataType.FILE,
         uri: fileUri.getUriFromPath(this.filePath),
         title: this.fileName
       };
       const data: systemShare.SharedData = new systemShare.SharedData(record);
       const controller: systemShare.ShareController = new systemShare.ShareController(data);
       await controller.show(context as common.UIAbilityContext, {});
     } catch (e) {
       hilog.warn(DOMAIN, TAG, 'show share panel failed: %{public}s', String(e));
       this.showToast('分享失败');
     }
   }
   ```

## 常见FAQ

Q：录音被运营商来电打断会丢内容吗？

A：不会。采集启动前调用setWillMuteWhenInterrupted(true)，来电打断期间采集不停（自动录静音流），挂断后自动恢复有声，整段录音连贯无缺失。

Q：setWillMuteWhenInterrupted为什么设置不生效？

A：该接口必须在capturer.start()之前调用，start后再设置无法生效；示例在创建采集器后、启动前完成设置。

Q：退到后台或锁屏后录音会中断吗？

A：不会。录音开始即申请AUDIO_RECORDING长时任务并常驻通知栏，申请全程await保证任务先于退后台生效；录音停止时释放任务。若申请失败页面会提示，此时退后台可能中断。

Q：为什么选择WAV格式而不是AAC？

A：WAV无损、无编码开销，PCM数据可直接喂端侧转写引擎（AAC需先解码）；且静音续录依赖AudioCapturer的PCM流，WAV是最简自封装路线。代价是体积较大（16kHz/16bit/单声道约1.9MB每分钟），需压缩时可改用AVRecorder编码路线，但会失去PCM直喂转写的能力。

Q：为什么转写只支持中文普通话？

A：端侧离线识别模型仅内置中文普通话，不依赖网络、免费且隐私安全；其他语言或方言场景需接入云端语音识别服务。

Q：实时转写遇到长时间静音（如来电通话期间）会怎么样？

A：引擎短语音模式遇静音会自动结束会话，示例检测到会话结束后按退避策略自动续接新会话，挂断恢复语音后识别自动接续，不会丢失后续内容。

Q：writeAudio报参数错误怎么办？

A：该接口单次写入的数据长度仅支持640或1280字节，需在调用侧用缓冲区把任意长度的PCM切成640字节块再喂入。

Q：删除正在播放的录音失败怎么办？

A：先调用播放器release()关闭文件fd再删除文件。文件被fd占用时删除会失败，示例的删除流程固定为"停播放器→删文件→删数据库记录"。
