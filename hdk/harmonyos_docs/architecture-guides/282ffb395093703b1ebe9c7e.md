# 股票基金服务卡片

## 场景介绍

股票基金服务卡片是金融理财类应用的高频使用场景之一，如用户在桌面添加股票行情卡片后，希望无需打开App即可查看自选指数的实时行情与涨跌幅。

本示例基于[ArkTS卡片](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/arkts-ui-widget)提供了主动刷新与被动刷新两种卡片形态，通过[FormExtensionAbility](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-app-form-formextensionability)管理卡片生命周期，结合[postCardAction](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-postcardaction)与[formProvider.updateForm](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-app-form-formprovider#formproviderupdateform)实现多种数据刷新机制，覆盖金融理财场景下服务卡片创建与数据更新的典型诉求。

## 实现思路

1. **卡片配置声明**：在form_config.json中声明AutomaticallyRefreshedCard（被动刷新卡片）与ManuallyRefreshedCard（主动刷新卡片）两个卡片，配置卡片名称、是否启用更新、定点刷新时间、定时刷新周期等属性，被动刷新卡片额外开启dataProxyEnabled以支持Push代理刷新。
2. **卡片生命周期管理** ：在EntryFormAbility中继承FormExtensionAbility，实现onAddForm、onFormEvent、onUpdateForm等回调，分别承接卡片创建、事件触发、系统刷新等生命周期节点。

   ```ts
   // 卡片Ability生命周期回调
   export default class EntryFormAbility extends FormExtensionAbility {
     onAddForm(want: Want): formBindingData.FormBindingData {
      // 卡片创建时下发初始数据
     }
     onFormEvent(formId: string, message: string): void {
      // 卡片事件触发时刷新数据
     }
     onUpdateForm(formId: string): void {
      // 系统定时/定点刷新触发
     }
   }
   ```

3. **卡片初始数据下发** ：在onAddForm中通过formBindingData.createFormBindingData构造初始行情数据，卡片创建后即可展示上证、深证等指数信息。

   ```ts
   // onAddForm下发卡片初始数据
   onAddForm(want: Want): formBindingData.FormBindingData {
     const formId = want.parameters![formInfo.FormParam.IDENTITY_KEY] as string;
     this.currentStockData = {
       formId: formId,
       stockValueOne: '4078.81',
       stockChangeOne: '-0.18%',
       stockValueTwo: '14860.66',
       stockChangeTwo: '+0.9%',
     };
     let bindingData: formBindingData.FormBindingData = formBindingData.createFormBindingData(this.currentStockData);
     return bindingData;
   }
   ```

4. **卡片数据接收** ：两个卡片均通过LocalStorageProp接收FormExtensionAbility或formProvider下发的数据字段，字段变化时自动驱动UI刷新展示。

   ```ts
   // 卡片通过LocalStorageProp接收数据
   @LocalStorageProp('stockValueOne') stockValueOne: string = '';
   @LocalStorageProp('stockChangeOne') stockChangeOne: string = '';
   @LocalStorageProp('stockValueTwo') stockValueTwo: string = '';
   @LocalStorageProp('stockChangeTwo') stockChangeTwo: string = '';
   ```


5. **卡片刷新机制** ：本示例覆盖4种刷新机制，开发者可根据业务场景的刷新频率与服务端能力灵活选择。
   1. 点击图标刷新：在主动刷新卡片ManuallyRefreshedCard中提供刷新图标，点击后通过postCardAction触发message事件，由EntryFormAbility的onFormEvent回调接收，调用updateForm刷新数据。

      ```ts
      // 卡片刷新图标触发message事件
      Image($r('app.media.ic_refresh'))
        .width(28)
        .height(28)
        .onClick(() => {
          postCardAction(this, {
            action: 'message',
            params: { msgTest: 'messageEvent' }
          });
        })
      ```

      ```ts
      // onFormEvent中更新卡片数据
      onFormEvent(formId: string, message: string): void {
        this.currentStockData = StockDataSimulator.updateStockData(this.currentStockData);
        let formInfo: formBindingData.FormBindingData = formBindingData.createFormBindingData(this.currentStockData);
        formProvider.updateForm(formId, formInfo).then(() => {
       // 刷新成功
      }).catch((error: BusinessError) => {
        // 刷新失败处理
      });
      }
      ```

   2. 系统被动刷新：系统按form_config.json中updateDuration和scheduledUpdateTime配置的定点/定时策略触发onUpdateForm回调，本示例未实现具体刷新逻辑，开发者可在该回调中调用formProvider.updateForm下发最新数据。

      ```ts
      // 系统被动刷新回调（本示例未实现具体逻辑，开发者可在此补充）
      onUpdateForm(formId: string): void {
      // 系统按定点/定时策略触发，可在此获取最新数据并调用updateForm刷新
      // ...
      }
      ```

   3. Push推送刷新：在onAddForm中通过bindingData.proxies声明需要Push代理刷新的字段，后续由服务端通过Push Kit下发代理刷新消息，实现服务端驱动的卡片字段级刷新。

      ```ts
      // onAddForm中声明Push代理刷新字段
      const stockValueOne: formBindingData.ProxyData = {
        key: 'stockValueOne',
        subscriberId: formId
      };
      const stockChangeOne: formBindingData.ProxyData = {
        key: 'stockChangeOne',
        subscriberId: formId
      };
      bindingData.proxies = [stockValueOne, stockChangeOne, stockChangeTwo, stockValueTwo];
      ```

   4. 应用前台主动刷新：应用页面运行时，可通过读取本地持久化的formId，在业务逻辑中调用formProvider.updateForm主动推送数据到卡片，无需依赖系统或Push触发。

      ```ts
      // StockPage前台主动刷新卡片
      updatePrice() {
        let rand = cryptoFramework.createRandom();
        let randData = rand.generateRandomSync(1);
        const randomRatio = randData.data[0] / 255 * 0.1 - 0.05;
        this.currentPrice = Number((this.preClose * (1 + randomRatio)).toFixed(2));
        let formId = this.operate().toString();
        let currentStockData: CreateFormData = {
          formId: '',
          stockValueOne: this.currentPrice.toString(),
          stockChangeOne: changePercent,
          stockValueTwo: '14860.66',
          stockChangeTwo: '+0.9%',
        };
        let formInfo: formBindingData.FormBindingData = formBindingData.createFormBindingData(currentStockData);
        formProvider.updateForm(formId, formInfo);
      }
      ```

## 说明

* 本示例Push推送刷新为可选扩展能力，如需启用服务器推送刷新，可将formId和pushToken上传至服务端，通过[基于服务账号生成鉴权令牌](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/push-jwt-token)获取token后调用Push接口下发代理刷新消息。
* 卡片行情数据为本地模拟生成，实际使用需对接真实行情数据源。
* 系统被动刷新受定点刷新每天50次、定时刷新每天24次额度限制，金融场景下高频刷新建议结合应用前台主动刷新或Push推送刷新。

## 环境准备

* 本示例基于DevEco Studio 6.1.1 Release版本进行编译运行。
* 本示例基于API Version 24 Release版本进行开发与验证。
