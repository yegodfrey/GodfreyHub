# 页面刷新小图和大图刷新方案

## 场景介绍

[Image](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-image)图片按尺寸选用syncLoad加载策略是便捷生活类应用的高频使用场景之一，如果不区分尺寸统一采用同一种加载方式，容易出现图片显示闪烁，或大图解码耗时较长阻塞主线程的问题。

本示例主要基于[Image](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-image)组件的[syncLoad](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-image#syncload8)属性实现大图异步加载、小图同步加载的差异化加载策略：建议加载尺寸较小的本地图片时将syncLoad设为true，解码耗时短，在主线程上执行即可，避免异步二次渲染引起的闪烁；广告大图将syncLoad设为false异步加载，避免长时间解码阻塞主线程。示例分别提供ArkTS声明式首页与Native C-API节点树订单页两种实现方式，并结合[Refresh](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-refresh)组件演示下拉刷新场景下的图片重新加载。

## 实现思路

主页面Index.ets通过Tabs承载两个页签：主页采用ArkTS声明式开发，订单页采用Native C-API节点树开发，两个页面均遵循大图异步加载、小图同步加载的加载策略。

1. 使用Refresh组件实现下拉刷新，在onRefreshing回调中重新加载数据，驱动图片随界面刷新按既定策略重新加载：

   ```ts
       Refresh({ refreshing: $$this.isRefreshing }) {
         Scroll() {
           // 类目宫格、广告大图、商家卡片列表
         }
       }
       .layoutWeight(1)
       .onRefreshing(() => {
         setTimeout(() => {
           this.loadData()
           this.isRefreshing = false
         }, REFRESH_DURATION)
       })
   ```

2. 首页小图将syncLoad设为true由主线程同步执行，图片随首帧直接渲染，有效消除加载闪烁：

   ```ts
      /* 小图标：同步加载 */
       Image(item.icon)
         .width(40)
         .height(40)
         .syncLoad(true)
   ```

3. 首页广告大图syncLoad设为false异步加载，避免阻塞主线程影响点击响应与滑动流畅度：

   ```ts
     /* 广告大图：异步加载 */
       Image(this.banners[0].image)
         .width('100%')
         .height(112)
         .objectFit(ImageFit.Cover)
         .borderRadius(16)
         .syncLoad(false)
   ```

4. 订单页通过ContentSlot挂载NodeContent承载的Native节点树，构建Image节点时对NODE_IMAGE_SYNC_LOAD属性赋值：true为同步加载，false为异步加载：

   ```cpp
     /* 设置图片同步加载开关：true 同步加载小图，false 异步加载广告大图 */
       void SetImageSyncLoad(ArkUI_NodeHandle node, bool sync)
       {
           ArkUI_NumberValue syncValue[] = { { .i32 = sync ? 1 : 0 } };
           ArkUI_AttributeItem syncItem = { syncValue, 1, nullptr, nullptr };
           ArkUINativeApi::instance()->setAttribute(node, ArkUI_NodeAttributeType::NODE_IMAGE_SYNC_LOAD, &syncItem);
       }
   ```

5. NODE_IMAGE_SYNC_LOAD属性设置为true表示同步加载，设置为false表示异步加载：

   ```cpp
     /* 广告大图：异步加载 */
       SetImageSyncLoad(image, false);
       SetImageSrcDescriptor(image, DecodeAndTrack(BANNER_PATH));

      /* 订单缩略图：同步加载 */
       SetImageSyncLoad(node, true);
       SetImageSrcDescriptor(node, descriptor);
   ```

6. 下拉刷新时重建节点树：

   ```cpp
       void RebuildOrderTree()
       {
           DestroyOrderTree();
           g_rootNode = BuildOrderTree();
           OH_ArkUI_NodeContent_AddNode(g_contentHandle, g_rootNode);
       }
   ```

## 环境准备

* 本示例基于DevEco Studio 6.1.1 Release版本进行编译运行。
* 本示例基于API Version 24 Release版本进行开发与验证。
