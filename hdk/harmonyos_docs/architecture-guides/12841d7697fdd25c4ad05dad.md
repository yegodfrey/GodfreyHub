# 加载预置数据库刷新文章列表

## 场景介绍

加载预置数据库刷新文章列表是新闻阅读类应用中的典型场景之一。

本示例基于[@ohos.resourceManager](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-resource-manager)加载本地预置数据库（或从网络下载的数据库），使用[LazyForEach](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-rendering-control-lazyforeach)延迟创建列表项，减少一次性渲染大量内容的开销，即使在网络较差或无网络时也可以实现文章列表刷新的功能。

## 实现思路

1. 在EntryAbility组件初始化onCreate时，使用[getRawFd](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-resource-manager#getrawfd9)和[fs.write](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-file-fs#fileiowrite)实现copyDBToSandbox方法将rawfile目录下的db数据库文件拷贝至应用沙箱。

   ```screen
      // EntryAbility.ets
       onCreate(want: Want, launchParam: AbilityConstant.LaunchParam): void {
      // ...
         AppStorage.setOrCreate<Context>('context', this.context);
         getDBOperatorManager().copyDBToSandbox(this.context, 'book.db');
       }
   ```

2. 在页面加载aboutToAppear时，使用[relationalStore.getRdbStore](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-data-relationalstore-f#relationalstoregetrdbstore)实现readBookList接口通过rdbStore读取沙箱下db数据库文件，实例化Book对象，创建BookArray，存入读取到的数据。

   ```screen
       // PresetBookPage.ets
       aboutToAppear(): void {
        // ...
         getDBOperatorManager()
           .readBookList(this.context, 3)
           .then(bookArray => {
             this.data.reloadData(bookArray);
             this.filterVipData(bookArray);
           });
       }
   ```

3. 通过布局组件进行页面渲染，实现杂志文章页面的刷新和展示。

## 环境准备

* 本示例基于DevEco Studio 6.0.0 Release版本进行编译运行。
* 本示例基于API Version 20 Release版本进行开发与验证。
