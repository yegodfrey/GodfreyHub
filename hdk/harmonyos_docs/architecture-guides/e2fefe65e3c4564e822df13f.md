# 新订单揽收语音播报

## 场景介绍

快递员在日常工作中，需要实时接收新订单并通过语音播报进行提醒，避免错过揽收时机。本示例展示了这一典型场景：应用持续接收新订单通过自定义铃声或语音播报方式及时提醒快递员处理。

本示例主要基于以下能力实现：

* [TextToSpeech](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/hms-ai-texttospeech)：文字转语音，将订单信息转为语音播报。
* [SoundPool](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-inner-multimedia-soundpool)：低时延短音频播放，支持自定义铃声提醒。
* [NotificationManager](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-notificationmanager)：通知管理，推送新订单提醒到通知栏。

**提醒策略：**

* 应用初始化时，语音播报"您有x条新订单，请及时处理"。
* 后续新订单到达时，优先播放自定义铃声（需在rawfile目录放置ringtone.mp3）；如未配置自定义铃声，则默认使用TTS语音播报订单地址信息。

## 实现思路

1. **TTS引擎初始化：** TtsManager.createEngine()创建TTS引擎，设置isBackStage: true支持后台播报，通过speak()方法将订单信息转为语音播放。引擎未就绪时文本将被暂存至pendingTexts队列，引擎创建成功后消费队列头部的一条文本；SpeakListener.onComplete回调中继续消费下一条，实现逐条顺序播报。

   ```ts
   const extraParam: Record<string, Object> = {
     'style': 'interaction-broadcast',
     'locate': 'CN',
     'name': 'NewOrderSpeakerTTS',
     'isBackStage': true
   };
   const initParamsInfo: textToSpeech.CreateEngineParams = {
     language: 'zh-CN',
     person: 0,
     online: 1,
     extraParams: extraParam
   };
   try {
     textToSpeech.createEngine(initParamsInfo, (err: BusinessError, engine: textToSpeech.TextToSpeechEngine) => {
       if (err) {
         this.engineReady = false;
         return;
       }
       this.ttsEngine = engine;
       this.engineReady = true;
       this.setSpeakListener();
       if (this.pendingTexts.length > 0) {
         const text = this.pendingTexts.shift();
         if (text) {
           this.doSpeak(text);
         }
       }
     });
   } catch (error) {
     const e = error as BusinessError;
   }
   ```

2. **自定义铃声加载与播放：** RingtoneManager.init()基于SoundPool加载rawfile/ringtone.mp3，注册loadComplete、playFinished、error监听，通过Promise等待资源加载完成后方可播放。loadPromise在loadComplete回调中off移除监听后resolve，在error回调中off移除监听后reject，避免监听泄漏。新订单到达时低时延播放提醒。

   ```ts
   const audioRendererInfo: audio.AudioRendererInfo = {
     usage: audio.StreamUsage.STREAM_USAGE_MUSIC,
     rendererFlags: 0
   };
   this.soundPool = await media.createSoundPool(1, audioRendererInfo);

   const loadPromise: Promise<number> = new Promise((resolve, reject) => {
     const onLoadComplete = (soundId_: number) => {
       this.soundPool?.off('loadComplete');
       this.soundPool?.off('error');
       resolve(soundId_);
     };
     const onError = (error: Error) => {
       this.soundPool?.off('loadComplete');
       this.soundPool?.off('error');
       reject(error);
     };
     this.soundPool?.on('loadComplete', onLoadComplete);
     this.soundPool?.on('error', onError);
   });

   this.soundPool.on('playFinished', () => {});
   this.soundPool.on('error', (error: Error) => {});

   const fileDescriptor = await this.context.resourceManager.getRawFd('ringtone.mp3');
   const requestedId = await this.soundPool.load(fileDescriptor.fd, fileDescriptor.offset, fileDescriptor.length);
   this.soundId = await loadPromise;
   this.loaded = true;
   ```

   播放铃声：

   ```ts
   const playParameters: media.PlayParameters = {
     loop: 0, rate: 1, leftVolume: 1.0, rightVolume: 1.0, priority: 0
   };
   this.soundPool.play(this.soundId, playParameters, (error, streamID: number) => {
     if (error) {
       return;
     }
     this.streamId = streamID;
   });
   ```

3. **新订单提醒降级策略：** OrderService.generateNewOrder→通过ConfigManager.isTTSEnabled()判断语音播报开关，再判断RingtoneManager.isReady()，有自定义铃声时调用RingtoneManager.play()播放铃声，否则降级调用TtsManager.speak()语音播报订单地址信息。未配置铃声文件时自动降级为TTS语音播报。

   ```ts
   const ttsEnabled = await ConfigManager.getInstance().isTTSEnabled();
   if (ttsEnabled) {
     if (RingtoneManager.getInstance().isReady()) {
       RingtoneManager.getInstance().play();
     } else {
       const speakText = `新订单，地址：${address}`;
       TtsManager.getInstance().speak(speakText);
     }
   }
   ```

4. **通知权限申请与订单通知推送：** EntryAbility.onWindowStageCreate中初始化各管理器并启动订单服务，页面加载完成后调用requestNotificationPermission()请求通知权限，通过notificationManager.requestEnableNotification()弹出授权弹窗供用户确认，授权后再次检查权限状态。Index.aboutToAppear中首次进入页面若有未读订单，通过notificationManager.publish()发送通知栏提醒。

   ```ts
   const context = this.context as common.UIAbilityContext;
   let enabled = await notificationManager.isNotificationEnabled();
   if (!enabled) {
     await notificationManager.requestEnableNotification(context);
     enabled = await notificationManager.isNotificationEnabled();
   }

   const notificationRequest: notificationManager.NotificationRequest = {
     id: 2,
     content: {
       notificationContentType: notificationManager.ContentType.NOTIFICATION_CONTENT_BASIC_TEXT,
       normal: {
         title: '新订单提醒',
         text: `您有${unreadCount}条新订单，请及时处理`,
       }
     }
   };
   try {
     await notificationManager.publish(notificationRequest);
   } catch (err) {
   }
   ```

## 说明

* 本示例需在真机上运行，模拟器不支持TTS语音播报功能。
* 本示例需自行提供铃声文件：将铃声文件命名为ringtone.mp3放入entry/src/main/resources/rawfile/目录即可；未放置时自动降级为TTS语音播报。
* 首次运行需手动确认通知权限弹窗。

## 环境准备

* 本示例基于DevEco Studio 6.1.1 Release版本进行编译运行。
* 本示例基于API Version 24 Release版本进行开发与验证。
