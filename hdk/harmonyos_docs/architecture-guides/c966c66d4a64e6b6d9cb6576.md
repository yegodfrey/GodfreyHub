# 应用静默登录

## 场景介绍

应用静默登录是各类应用中的高频使用场景之一，如初次登录后希望后续不再显示登录页面。

本示例围绕"登录前拦截 → 隐私确认 → 登录鉴权 → 静默登录"全链路，构建了一套完整的登录态管理方案。

**适用场景：**

需要用户身份识别且期望降低重复登录成本的应用，如电商、社交、金融、健康运动、内容资讯、在线教育、出行服务、生活缴费、企业办公等------凡是存在"首次登录、后续免登"需求的场景均可复用本方案。

## 使用说明

1. 首次打开应用，首页内容模糊遮罩，点击任意区域弹出登录引导弹窗。
2. 点击"登录"进入登录页，输入用户名与密码。
3. 勾选"已阅读并同意《用户协议》和《隐私政策》"（点击蓝色文字可半模态查看协议详情）。
4. 勾选"静默登录"后点击登录，登录成功返回首页，遮罩消失。
5. 再次打开应用，自动恢复登录状态，无需重新登录即可正常使用。
6. 如未勾选"静默登录"，仅当次会话登录有效，下次启动仍需重新登录。

## 实现思路

本示例的核心是构建一套**登录态生命周期管理**方案，覆盖从应用启动到用户鉴权的完整流程。

## 整体流程

应用启动 → 检查持久化登录标记 → 有则恢复登录态（静默登录）/ 无则展示未登录状态 → 用户触发登录 → 隐私协议校验 → 账号鉴权 → 更新登录态 → 返回功能页面。

## 登录态管理

采用会话态与持久态分离的双状态模型。会话态控制 UI 表现（模糊遮罩、功能拦截），随应用退出而失效；持久态通过 PersistentStorage 写入磁盘，应用重启后自动恢复会话态，实现静默登录。两者独立运作：用户可选择仅当次登录或开启静默登录，互不干扰。

```ts
// MainPage.ets 提供会话态，启动时从持久态恢复
@Provide('isLogin') isLogin: boolean = false;
@StorageLink('isRemembered') isRemembered: boolean = false;

aboutToAppear() {
  this.isLogin = this.isRemembered;
}

// LoginPage.ets 消费会话态，登录成功时更新
@Consume('isLogin') isLogin: boolean;
@StorageLink('isRemembered') isRemembered: boolean = false;

// 登录成功后同时更新会话态
this.isLogin = true;
this.pageInfos.pop();
```

## 未登录访问拦截

对于需登录才能使用的功能页面，采用视觉遮挡与交互拦截双重策略。视觉层对页面内容施加模糊效果，避免未授权浏览；交互层叠加透明覆盖层拦截所有触控事件，引导用户前往登录页。此方案绕开了 ArkUI 父容器无法拦截子组件点击事件的限制。

```ts
// 内容区施加模糊效果
.foregroundBlurStyle(this.isLogin ? BlurStyle.NONE : BlurStyle.BACKGROUND_THICK, {
  colorMode: ThemeColorMode.LIGHT,
  adaptiveColor: AdaptiveColor.DEFAULT,
  scale: 0.15
});

// 透明覆盖层拦截点击，弹出登录引导
if (!this.isLogin) {
  Column()
    .width(Constants.FULL_WIDTH)
    .height(Constants.FULL_HEIGHT)
    .backgroundColor(Constants.COLOR_TRANSPARENT)
    .onClick(() => {
      this.isShowLoginTips = true;
    });
}
```

## 隐私协议确认

遵循合规要求，在登录操作前强制校验隐私协议勾选状态。协议详情通过半模态展示，用户可阅读完整条款后再决定是否同意，未同意时阻止登录并提示。使用单一状态变量切换协议类型，避免同一节点多次 bindSheet 导致的冲突问题。

```ts
// 隐私协议勾选校验
if (!this.isPrivacyAgreed) {
  this.uiContext.getPromptAction().showToast({ message: '请先同意用户协议与隐私政策' });
  return;
}

// 协议链接点击，切换半模态内容
Span('《用户协议》')
  .fontColor(Constants.FONT_COLOR_BLUE)
  .onClick(() => {
    this.sheetFileName = 'user_agreement.html';
    this.showSheet = true;
  });

// 单 bindSheet + 状态变量切换协议类型
.bindSheet($$this.showSheet, this.sheetBuilder(), {
  detents: [SheetSize.LARGE],
  title: { title: this.sheetFileName === 'user_agreement.html' ? '用户协议' : '隐私政策' },
  showClose: true,
  dragBar: true
});
```

## 数据存储与鉴权

用户信息通过关系型数据库持久化，密码经 AES 对称加密后存储。登录时按用户名查询记录，存在则解密比对密码，不存在则自动注册，兼顾安全性与易用性。

```ts
let index: number = this.accountList.findIndex(v => v.userName === this.userName);
if (index > -1) {
// 用户存在：解密比对密码
  let meta: AccountInfo = this.accountList.find(v => v.userName === this.userName) as AccountInfo;
  if (this.password === CryptoJS.AES.decrypt(meta.password, this.keys).toString(CryptoJS.enc.Utf8)) {
   // 密码正确，更新记录并登录
    accountInfo.id = meta.id;
    this.accountTable.updateData(accountInfo, (success: boolean) => { ... });
  }
} else {
 // 用户不存在：自动注册并登录
  this.accountTable.insertData(accountInfo, (id: number) => { ... });
}
```

## 沉浸式适配

全局开启沉浸式布局后，在 EntryAbility 中获取系统避让区域高度并写入 AppStorage，各页面通过 @StorageProp 读取并结合 safeAreaPadding 统一避让，同时监听避让区域变化动态适配。

```ts
// EntryAbility.ets --- 获取避让区域高度并持久监听
AppStorage.setOrCreate('topRectHeight', topRectHeight);
AppStorage.setOrCreate('bottomRectHeight', bottomRectHeight);
windowClass.on('avoidAreaChange', (data) => {
  if (data.type === window.AvoidAreaType.TYPE_SYSTEM) {
    AppStorage.setOrCreate('topRectHeight', data.area.topRect.height);
  } else if (data.type === window.AvoidAreaType.TYPE_NAVIGATION_INDICATOR) {
    AppStorage.setOrCreate('bottomRectHeight', data.area.bottomRect.height);
  }
});

// 各页面 --- 读取并设置安全区内边距
@StorageProp('topRectHeight') topRectHeight: number = 0;
@StorageProp('bottomRectHeight') bottomRectHeight: number = 0;

.safeAreaPadding({
  top: this.uiContext.px2vp(this.topRectHeight),
  bottom: this.uiContext.px2vp(this.bottomRectHeight)
});
```
