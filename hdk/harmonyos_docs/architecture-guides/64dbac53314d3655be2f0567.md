# 多个后台长时任务管理示例

## 场景介绍

[后台长时任务](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/background-task-overview)是生活服务类应用的高频使用场景之一，如外卖骑手上线后需持续获取位置信息并在后台播报来单提醒，即使应用退至后台也不能中断。

本示例主要基于[backgroundTaskManager](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-resourceschedule-backgroundtaskmanager)创建多个独立长时任务（定位+音频播报），配合[geoLocationManager](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-geolocationmanager)实现后台持续定位，以及[textToSpeech](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/hms-ai-texttospeech)实现后台语音播报，并通过[continuousTaskCancel](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-resourceschedule-backgroundtaskmanager#backgroundtaskmanageroncontinuoustaskcancel15)监听任务取消事件实现自动下线。

## 实现思路

1. 创建两个独立后台长时任务 骑手上线时，分别申请location和audioPlayback两种类型的长时任务，各自携带不同的requestCode生成独立的WantAgent，系统会创建两个独立的长时任务，通知栏显示两条通知。**此功能依赖API Version 21+**，startBackgroundRunning返回ContinuousTaskNotification对象，其中continuousTaskId用于标识任务：

   ```ts
   // 定位长时任务
   const locationWantAgentInfo: wantAgent.WantAgentInfo = {
     wants: [{ bundleName: 'com.demo.backgroundtask', abilityName: 'EntryAbility' }],
     actionType: wantAgent.OperationType.START_ABILITY,
     requestCode: 0,
     actionFlags: [wantAgent.WantAgentFlags.UPDATE_PRESENT_FLAG]
   };
   wantAgent.getWantAgent(locationWantAgentInfo).then((locationWantAgentObj: WantAgent) => {
     backgroundTaskManager.startBackgroundRunning(context, ['location'], locationWantAgentObj)
       .then((notification: backgroundTaskManager.ContinuousTaskNotification) => {
         this.locationTaskId = notification.continuousTaskId !== undefined
           ? notification.continuousTaskId : -1;
         this.startLocationUpdate();
       });
   });

   // 播报长时任务
   const audioWantAgentInfo: wantAgent.WantAgentInfo = {
     wants: [{ bundleName: 'com.demo.backgroundtask', abilityName: 'EntryAbility' }],
     actionType: wantAgent.OperationType.START_ABILITY,
     requestCode: 1,
     actionFlags: [wantAgent.WantAgentFlags.UPDATE_PRESENT_FLAG]
   };
   wantAgent.getWantAgent(audioWantAgentInfo).then((audioWantAgentObj: WantAgent) => {
     backgroundTaskManager.startBackgroundRunning(context, ['audioPlayback'], audioWantAgentObj)
       .then((notification: backgroundTaskManager.ContinuousTaskNotification) => {
         this.audioTaskId = notification.continuousTaskId !== undefined
           ? notification.continuousTaskId : -1;
       });
   });
   ```


2. 指定ID停止长时任务 **API Version 21+** 新增stopBackgroundRunning(context, continuousTaskId)重载，支持按任务ID精确停止指定长时任务，两个任务互不影响：

   ```ts
   // 停止定位任务
   backgroundTaskManager.stopBackgroundRunning(context, this.locationTaskId);

   // 停止播报任务
   backgroundTaskManager.stopBackgroundRunning(context, this.audioTaskId);
   ```


3. 监听长时任务取消事件 注册continuousTaskCancel监听，当系统或用户取消长时任务时，通过AppStorage + @Watch机制通知UI层自动下线并弹窗提示：

   ```ts
   // 注册监听
   this.taskCancelCallback = (info: backgroundTaskManager.ContinuousTaskCancelInfo) => {
     AppStorage.setOrCreate('bgTaskCancelled', true);
   };
   backgroundTaskManager.on('continuousTaskCancel', this.taskCancelCallback);

   // UI层响应
   @StorageLink('bgTaskCancelled') @Watch('onBgTaskCancelled') bgTaskCancelled: boolean = false;
   onBgTaskCancelled(): void {
     this.isOnline = false;
     this.stopLocationUpdate();
     this.stopBroadcast();
     this.getUIContext().getPromptAction().showDialog({
       title: '提示',
       message: '获取定位失败，已自动下线',
       buttons: [{ text: '我知道了', color: 'rgba(10, 89, 247, 1)' }]
     });
   }
   ```


4. 后台持续定位 启用geoLocationManager.on('locationChange')以5秒间隔持续获取位置，配合location类型长时任务保证后台运行：

   ```ts
   const request: geoLocationManager.ContinuousLocationRequest = {
     interval: 5,
     locationScenario: geoLocationManager.UserActivityScenario.NAVIGATION
   };
   geoLocationManager.on('locationChange', request, (location: geoLocationManager.Location) => {
     this.currentLatitude = location.latitude;
     this.currentLongitude = location.longitude;
   });
   ```


5. 后台语音播报 创建TTS引擎时设置isBackStage: true启用后台播报能力，配合audioPlayback长时任务保证后台播报不被中断，通过setInterval每10秒播报"来新单啦"：

   ```ts
   const extraParam: Record<string, Object> = {
     'style': 'interaction-broadcast',
     'locate': 'CN',
     'name': 'DeliveryTts',
     'isBackStage': true
   };
   const initParams: textToSpeech.CreateEngineParams = {
     language: 'zh-CN', person: 0, online: 1, extraParams: extraParam
   };
   this.ttsEngine = textToSpeech.createEngine(initParams);
   this.ttsEngine.setListener(speakListener);
   this.broadcastTimerId = setInterval(() => {
     this.ttsEngine!.speak('来新单啦', speakParams);
   }, BROADCAST_INTERVAL);
   ```

## 说明

* 本示例地图页面使用MapComponent，需在AGC控制台开通Map Kit服务并配置客户端ID，否则地图无法正常显示。
* TTS语音播报依赖设备内置语音引擎，首次使用需确保设备已下载对应音色模型。

## 环境准备

* 本示例基于DevEco Studio 6.1.1 Release版本进行编译运行。
* 本示例基于API Version 24 Release版本进行开发与验证。

## 权限说明

获取网络权限：[ohos.permission.INTERNET](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/permissions-for-all#ohospermissioninternet)。

获取粗略位置权限：[ohos.permission.APPROXIMATELY_LOCATION](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/permissions-for-all-user#ohospermissionapproximately_location)。

获取精确定位权限：[ohos.permission.LOCATION](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/permissions-for-all-user#ohospermissionlocation)。

获取后台位置权限：[ohos.permission.LOCATION_IN_BACKGROUND](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/permissions-for-all-user#ohospermissionlocation_in_background)。

申请长时任务权限：[ohos.permission.KEEP_BACKGROUND_RUNNING](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/permissions-for-all#ohospermissionkeep_background_running)。
