# 笔记中图片插入及编辑#一多适配

## 场景介绍

笔记中图片插入及编辑是综合办公类应用的高频使用场景之一。

本示例通过断点功能实现[响应式布局](https://developer.huawei.com/consumer/cn/doc/best-practices/bpta-multi-device-responsive-layout)来适配手机及平板设备，使用图片和相机选择器和[PanGesture](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-gestures-pangesture)实现图片导入笔记以及图片的大小位置编辑，使用[drawImage](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-components-canvas-common-method#drawimage)将图片插入笔记。

## 实现思路

1. 通过断点功能实现[响应式布局](https://developer.huawei.com/consumer/cn/doc/best-practices/bpta-multi-device-responsive-layout)。
2. 通过[PhotoViewPicker](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-photoaccesshelper-photoviewpicker)和[CameraPicker](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-camerapicker)导入图片，转换为[PixelMap](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-image-pixelmap)导入至笔记中。

   ```ts
   // Get pictures from the camera
   let pickerResult: cameraPicker.PickerResult = await cameraPicker.pick(context.getHostContext(),
     [cameraPicker.PickerMediaType.PHOTO], pickerProfile);

   //Get pictures from the gallery
   return (await photoPicker.select(photoSelectOptions)).photoUris[0];

   // Convert incoming data to PixelMap
   fileSource = fileIo.openSync(name, fileIo.OpenMode.READ_ONLY);
   imageSource = image.createImageSource(fileSource.fd);
   return imageSource.createPixelMapSync();
   ```


3. 通过[PanGesture](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-gestures-pangesture)实现图片随手拖拽移动及放大缩小效果。

   ```ts
   .gesture(
     PanGesture({ fingers: 1 })
       .onActionUpdate(event => {
         // Handling pix position changes and boundary problems
         this.handleDrag(event.offsetX, event.offsetY)
         this.handlePop()
       })
       .onActionEnd(() => {
         this.reset()
       })
       .onActionCancel(() => {
         this.reset()
       })
   )
   // ...
   // Handling pix size changes and boundary problems
   this.handleChange(index, event.offsetX, event.offsetY)
   ```


4. 使用[drawImage](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-components-canvas-common-method#drawimage)将图片插入[Canvas](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-components-canvas-canvas)画布中。

   ```ts
   // Draw the pix to the canvas
   drawImage() {
     this.myPen.beginPath()
     let imgBitmap = this.tmpPix
     this.myPen.drawImage(imgBitmap, this.pixPositionXTmp / this.currentScale, this.pixPositionYTmp / this.currentScale,
         this.pixWidth / this.currentScale, this.pixHeight / this.currentScale)
     this.myPen.closePath()
   }
   ```

## 约束与限制

* 本示例支持API Version 20 Release及以上版本。
* 本示例支持HarmonyOS 6.0.0 Release SDK及以上版本。
* 本示例需要使用DevEco Studio 6.0.0 Release及以上版本进行编译运行。
