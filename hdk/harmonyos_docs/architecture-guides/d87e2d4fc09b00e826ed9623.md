# 返回阅读列表顶部

#### 场景介绍

本示例使用[List](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-list)组件，实现新闻列表的滑动效果，通过点击向上箭头图标、双击状态栏和手动滑动三种方式，返回新闻列表顶部，也可适用于资讯、视频、商品等图文信息列表实现返回顶部功能。  

#### 效果预览

![](https://media:201787627672319794 "点击放大")  

#### 实现思路

* [List](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-list)组件添加[onDidScroll](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-scrollable-common#ondidscroll12)事件：该事件通过监听List组件沿Y轴的滚动偏移量，设置返回新闻列表顶部图标的显示与隐藏。

  ```
  List(){
    // List组件内容
  }
  .onDidScroll((scrollOffset: number) => {
    this.currentYOffset += scrollOffset;
    if (this.currentYOffset > Constants.ICON_SHOW_Y_OFFSET) {
      this.iconIsShow = true;
    } else {
      this.iconIsShow = false;
    }
  })
  ```

<!-- -->

* 为返回图标添加点击事件，通过[scrollTo](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-scroll#scrollto)方法实现滑动返回新闻列表顶部。

  ```
  // 返回图标
  Stack() {
    Image($r('app.media.back1'))
    Image($r('app.media.back2'))
  }
  .onClick(() => {
    this.scrollerController.scrollTo({
      xOffset: Constants.SCROLL_TO_X_OFFSET,
      yOffset: Constants.SCROLL_TO_Y_OFFSET,
      animation: {
        duration: Constants.SCROLL_TO_ANIMATION_DURATION,
        curve: Curve.FastOutSlowIn
      }
    })
  })
  ```

<!-- -->

* [List](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-list)组件添加[backToTop](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-scrollable-common#backtotop15)属性：通过设置该属性参数为true，实现双击状态栏返回新闻列表顶部。

  ```
  List() {
    // List组件内容
  }
  .backToTop(true) // 双击顶部状态栏返回顶部
  ```

#### 环境准备

* 本示例基于API Version 24 Release及以上版本进行开发与验证。
* 本示例需要使用DevEco Studio 6.1.1 Release及以上版本进行编译运行。
