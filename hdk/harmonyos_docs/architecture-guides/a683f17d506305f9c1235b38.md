# 扫拍码多码精准识别

## 场景介绍

基于HarmonyOS ScanKit的enableMultiMode能力，在检测到多个条码时暂停扫描、展示标记供用户逐个确认，同时保留单码快速识别的降级路径------关闭"多码确认"开关后即退化为单码模式。可用于快递揽件场景中，包裹常堆叠摆放导致相机视口内同时出现多个条码的情况，避免扫错或漏扫。

核心能力：

* **多码检测与暂停**：视口内出现2个以上条码时自动暂停扫描，进入选择模式；
* **扫描框内过滤**：仅对扫描框（XComponent 80%区域）内的条码触发多码确认，框外结果忽略；
* **可视化标记**：在预览层叠加蓝色Circle标记，定位在每个条码的中心位置；
* **逐个确认**：点击标记确认该条码，自动在截帧图片上绘制红色圆点标记并保存；
* **帧数据复用**：多码触发时截取一次帧数据存为JPEG ArrayBuffer，每个码从同一帧数据独立创建PixelMap处理，避免重复截图；
* **单码降级**：多码确认关闭或仅检测到1个码时，走单码快速识别流程。

## 实现思路

1. **扫码初始化，enableMultiMode动态控制**

   customScan.init()的ScanOptions.enableMultiMode由@State multiCodeConfirmEnabled控制，默认为true，表示默认开启多码截图二次确认。切换开关时需release→init→start重新初始化扫码引擎：

   ```ts
   private initScan(): void {
     const options: scanBarcode.ScanOptions = {
       scanTypes: [scanCore.ScanType.ONE_D_CODE],  // 仅一维码
       enableMultiMode: this.multiCodeConfirmEnabled, // 关键参数
       enableAlbum: false
     };
     customScan.init(options);
     this.hasInit = true;
   }

   private onMultiCodeConfirmToggle(isOn: boolean): void {
     this.multiCodeConfirmEnabled = isOn;
     if (this.hasInit) {
       this.releaseScan();   
       this.initScan();      
       this.tryStartScan();  
     }
   }
   ```

2. **多码检测，扫描框过滤与去重**

   扫码回调中，当result.length > 1且multiCodeConfirmEnabled为true时，进入多码判断逻辑：
   1. **条码类型过滤**：通过isBarcodeType(r.scanType)过滤二维码，只保留一维码结果。
   2. **去重** ：ScanResult识别结果去重，避免同一码重复出现。

      ```ts
      // scanCodeRect统计扫描框内识别到的所有条码
      if (r.scanCodeRect.left >= boxLeft && r.scanCodeRect.right <= boxRight &&
          r.scanCodeRect.top >= boxTop && r.scanCodeRect.bottom <= boxBottom) {
        inBoxResults.push(r);
      }

      // 判断是否进入多码确认识别流程
      if (inBoxResults.length > 1) {
          await this.handleMultiCodeDetected(inBoxResults);
          return;
        } else if (inBoxResults.length <= 1 && uniqueResults.length > 1) {
          this.rescanSafely();
          return;
        }
      }
      ```

      判定结果：
      * inBoxResults.length > 1：进入多码确认流程handleMultiCodeDetected；
      * inBoxResults.length <= 1且uniqueResults.length > 1：有码但都不在框内，rescan继续；
      * result.length == 1或多码确认关闭：走单码快速识别。
3. 截帧与暂停 进入多码确认时，先截取当前预览帧，再暂停扫描：

   ```ts
   private async handleMultiCodeDetected(results: Array<scanBarcode.ScanResult>): Promise<void> {
   // 1.componentSnapshot截帧（竖屏输出，与用户视角一致）
     const snapshotPm: image.PixelMap =
       await this.getUIContext().getComponentSnapshot().get('scanCameraStack');

    // 2.PixelMap → JPEG ArrayBuffer（帧数据缓存，供后续每个码独立使用）
     const imagePacker: image.ImagePacker = image.createImagePacker();
     const packOpts: image.PackingOption = { format: 'image/jpeg', quality: 95 };
     frameData: ArrayBuffer = await imagePacker.packToData(snapshotPm, packOpts);
     imagePacker.release();
     snapshotPm.release();

    // 3.暂停扫描
     customScan.stop();
     this.isScanning = false;

   // 4.缓存帧数据
     this.capturedFrameData = frameData;

    // 5.构建CodeRectInfo[]供UI渲染标记
     this.codeRects = rects;  
     this.multiCodeOverlayVisible = true;
   }
   ```

   关键设计：帧数据存为JPEG ArrayBuffer（capturedFrameData）而非PixelMap，因为image.createImageSource()接受ArrayBuffer但不接受PixelMap。这样每个码确认时可独立创建PixelMap副本，互不干扰。
4. 标记圆点多码位置，逐个确认识别 多码确认时，在预览Stack上叠加ForEach(this.codeRects)渲染Circle标记；顶部提示栏显示"识别到多个码，请选择"。

   用户点击某个Circle标记后：
   1. **重复检测**：`scannedSet.has(trackingNo)则提示"已扫描"并移除该标记；
   2. **记录结果**：scannedSet.add(trackingNo)+addScanResult(trackingNo)记入扫描结果列表；
   3. **状态更新** ：移除已确认码的标记，若待识别码数量为0则关闭叠加层、延迟300ms后恢复扫描；

      ```ts
      private selectCodeAndConfirm(codeInfo: CodeRectInfo): void {
        const trackingNo: string = codeInfo.trackingNo;
        if (this.scannedSet.has(trackingNo)) {
          this.showToastWithDebounce(trackingNo, '已扫描');
          this.codeRects = this.codeRects.filter((item: CodeRectInfo) => item.trackingNo !== trackingNo);
          if (this.codeRects.length === 0) {
            this.multiCodeOverlayVisible = false;
            this.resumeScanAfterMultiCode();
          }
          return;
        }

        this.scannedSet.add(trackingNo);
        this.isRecognizing = true;
        this.recognizingNo = trackingNo;

        this.addScanResult(trackingNo);
        this.isRecognizing = false;
        this.recognizingNo = '';

        this.codeRects = this.codeRects.filter((item: CodeRectInfo) => item.trackingNo !== trackingNo);
        if (this.codeRects.length === 0) {
          this.multiCodeOverlayVisible = false;
          setTimeout(() => {
            this.resumeScanAfterMultiCode();
          }, 300);
        }
      }
      ```

5. **单码降级路径**

   当multiCodeConfirmEnabled为false，或回调中result.length <= 1时，走单码快速识别流程：

   ```ts
   // componentSnapshot截帧
   const snapshotPm: image.PixelMap =
     await this.getUIContext().getComponentSnapshot().get('scanCameraStack');

   // 延迟后保存
   setTimeout(() => {
     this.addScanResult(no);
     if (pm !== null) {
       await this.savePixelMapToFile(no, ts, pm); 
     }
     this.rescanSafely();  
   }, RECOGNIZING_DELAY_MS);  
   ```
