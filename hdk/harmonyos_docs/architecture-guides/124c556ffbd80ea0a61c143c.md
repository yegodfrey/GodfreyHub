# 公共目录文件分片上传和保存

## 场景介绍

公共目录文件分片上传和保存是应用文件传输的典型场景，如金融App的文件上传与下载功能贯穿于账户开立（身份核验）、贷款与信用卡申请、投资账户开通、以及各类业务凭证提交（如发票、工资流水）等身份核验与业务申请环节，同时涵盖月度对账单、交易确认书、合同协议、投资研究报告等信息获取与凭证留存环节。

本示例主要基于[请求模块](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-request)、[HTTP数据请求](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-http)、[文件选择器](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-file-picker)、[Socket连接](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-socket)、[文件管理](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-file-fs)和[后台任务管理](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-resourceschedule-backgroundtaskmanager)实现多模式文件传输。下载侧组合：request.agent、HTTP、RCP、前后台模式和保存目标；上传侧通过HTTP或RCP向应用内回环服务真实发送文件分片，并按当前页签分别展示下载缓存和上传接收目录。

## 实现思路

1. 下载页分别保存下载方式、运行方式和目标路径索引，根据三个索引从十二个预设场景中选出当前任务。任务下载期间锁定下拉框，避免运行参数与已启动任务不一致。

   ```ts
   getSelectedFile(): FileModel {
     const selectedIndex = this.selectedMethodIndex * 4 +
       this.selectedRunModeIndex * 2 + this.selectedTargetIndex;
     return this.fileList[selectedIndex];
   }
   ```

2. request.agent前台下载到Picker目标时直接使用Picker返回的URI；后台任务或Download目标先写入cacheDir，完成后复制到公共目录。HTTP与RCP通过数据回调直接写入Picker返回的目标文件。

   ```ts
   shouldCopyAgentDownloadToPublicTarget(): boolean {
     return this.backgroundMode || this.isDefaultDownloadTarget();
   }

   const srcPath = util.format('%s/%s', context.cacheDir, this.fileName);
   const srcFile = fileIo.openSync(srcPath, fileIo.OpenMode.READ_ONLY);
   const destFile = fileIo.openSync(savePath,
     fileIo.OpenMode.CREATE | fileIo.OpenMode.WRITE_ONLY | fileIo.OpenMode.TRUNC);
   fileIo.writeSync(destFile.fd, arrayBuffer);
   ```

3. 上传页使用DocumentViewPicker.select单次选择最多十个文件。任务管理器根据文件大小计算分片，目标约为一百片，单片不超过512KB；接收端单请求上限为2MB。分片收到成功响应后才累计字节数并刷新进度。

   ```ts
   const nextChunkSize = Math.min(task.chunkSize, remainingBytes);
   const readLength = fileIo.readSync(task.fileDescriptor, chunkBuffer, {
     offset: task.uploadedBytes,
     length: nextChunkSize
   });
   await this.sendChunk(task, chunkBuffer, task.uploadedBytes);
   task.uploadedBytes += readLength;
   task.progress = Math.min(100,
     Math.round(task.uploadedBytes * 100 / task.totalBytes));
   ```

4. 分片请求头携带任务标识、文件名、分片偏移和文件总大小。选择HTTP时使用http.request，选择RCP时使用session.fetch，两条链路都以2xx响应作为当前分片成功条件。

   ```ts
   const headers: Record<string, string> = {
     'X-Upload-Task-Id': task.id.toString(),
     'X-File-Name': encodeURIComponent(task.fileName),
     'X-Chunk-Offset': offset.toString(),
     'X-Total-Size': task.totalBytes.toString()
   };
   if (task.uploadMode === UploadMode.RCP) {
     await this.sendChunkByRcp(headers, chunk);
   } else {
     await this.sendChunkByHttp(headers, chunk);
   }
   ```

5. 本地接收服务监听127.0.0.1。服务校验请求参数，再将分片按偏移写入filesDir/received_uploads。全部分片成功后，任务才进入完成状态并记录接收路径。

   ```ts
   const savePath = this.getSavedPath(taskId, fileName);
   const openMode = offset === 0
     ? fileIo.OpenMode.CREATE | fileIo.OpenMode.WRITE_ONLY | fileIo.OpenMode.TRUNC
     : fileIo.OpenMode.CREATE | fileIo.OpenMode.WRITE_ONLY;
   const destination = fileIo.openSync(savePath, openMode);
   fileIo.writeSync(destination.fd, body, {
     offset: offset,
     length: body.byteLength
   });
   ```

6. 文件查看入口根据当前页签传入showReceivedUploads。下载页签调用listFiles扫描cacheDir，上传页签调用listReceivedUploadFiles扫描filesDir/received_uploads，避免混淆两类沙箱文件。

   ```ts
   DownloadedFilePage({
     showReceivedUploads: this.selectedTab === 1
   });

   this.fileList = this.showReceivedUploads
     ? fileUtils.listReceivedUploadFiles()
     : fileUtils.listFiles();
   ```

7. 前后台传输通过startBackgroundRunning申请dataTransfer长时任务，并使用系统返回的通知标识发布实况窗进度。传输队列空闲后停止对应长时任务。

   ```ts
   const result = await backgroundTaskManager.startBackgroundRunning(
     context,
     ['dataTransfer'],
     wantAgentObj
   );
   UploadBackgroundKeeper.notificationId = result.notificationId;
   UploadBackgroundKeeper.continuousTaskId = result.continuousTaskId ?? 0;
   ```

## 说明

* 示例下载地址由资源项test_url提供，运行前需确认设备可以访问该地址。
* 上传接收服务运行在应用自身进程中，进程退出后服务停止，不等同于独立远端服务。
* 当前上传页展示真实分片进度和接收路径，并支持清理已结束任务。

## 环境准备

* 本示例基于DevEco Studio 6.1.1 Release版本进行编译运行。
* 本示例基于API Version 24 Release版本进行开发与验证。
