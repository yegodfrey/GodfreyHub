# 基金实践方案

## 场景介绍

基金实践方案是金融理财类应用的高频使用场景之一，如输入关键字即时联想目标基金、左右滑动横向浏览基金详情、拖拽手柄自定义统计区间收益、以持仓股票反查重仓基金。

本示例主要基于[Swiper](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-swiper)、[CanvasRenderingContext2D](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-canvasrenderingcontext2d)与[PanGesture](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-gestures-pangesture)实现基金搜索联想、基金横向切换浏览、自定义区间收益统计与股票反查选基四个核心能力。

## 实现思路

1. **基金搜索** :

   搜索框输入内容后onChange实时触发联想，搜索函数按精确代码→精确名称→代码包含→名称包含四级优先级归并结果，精确命中排在前面，点击联想项直达详情页。

   ```ts
   export function searchFunds(keyword: string): FundInfo[] {
     const kw: string = keyword.trim();
     if (kw.length === 0) {
       return [];
     }
     const lower: string = kw.toLowerCase();
     const exactCode: FundInfo[] = [];
     const exactName: FundInfo[] = [];
     const codeInclude: FundInfo[] = [];
     const nameInclude: FundInfo[] = [];
     for (let i = 0; i < ALL_FUNDS.length; i++) {
       const f: FundInfo = ALL_FUNDS[i];
       if (f.code.toLowerCase() === lower) {
         exactCode.push(f); // 精确代码命中优先级最高
       } else if (f.name === kw) {
         exactName.push(f); // 其次精确名称
       } else if (f.code.toLowerCase().includes(lower)) {
         codeInclude.push(f); // 再次代码包含
       } else if (f.name.includes(kw)) {
         nameInclude.push(f); // 最后名称包含
       }
     }
   // 四级结果按优先级拼接
     return exactCode.concat(exactName).concat(codeInclude).concat(nameInclude);
   }
   ```

2. **基金左右滑动** :

   详情页用Swiper承载全部基金，ForEach为每只基金渲染完整的详情内容(净值卡、走势图、持仓明细、经理卡片)，onChange同步当前索引，驱动页面标题与底部操作栏随切换联动。

   ```ts
   Swiper(this.swiperController) {
     ForEach(this.funds, (fund: FundInfo) => {
       Column() {
         this.NavHeaderCard(fund);// 净值大卡
         FundRangeCard({ fundCode: fund.code }); // 走势与区间统计
         this.HoldingCard(fund);// 持仓股票明细
         this.ManagerCard(fund); // 基金经理
       }
       .width('100%')
     }, (fund: FundInfo) => fund.code)
   }
   .index(this.currentIndex)
   .loop(false)
   .duration(300)
   .onChange((index: number) => {
   // 索引变化,联动标题与底部操作栏
     this.currentIndex = index;
   })
   ```

3. **基金自定义区间收益** :

   Canvas绘制净值走势，左右手柄用PanGesture拖拽，位置以比例(而非像素)存储并换算为数据下标；每次拖拽实时重绘画布，并按区间下标重算收益率、最高最低净值等统计。

   ```ts
   .gesture(
     PanGesture()
       .onActionUpdate((e: GestureEvent) => {
       // 按拖拽偏移换算新手柄比例,内部钳制最小间距防重叠
         const res = this.renderer.onDragUpdate(e.offsetX, this.canvasWidth,
           this.leftRatio, this.rightRatio);
         this.leftRatio = res.leftRatio;
         this.rightRatio = res.rightRatio;
         this.refreshRangeStat();// 按区间下标重算统计
         this.drawChart();// 重绘走势与选中蒙层
       })
   )
   ```

   区间统计按手柄换算出的起止下标遍历计算:收益率=(结束净值−起始净值)/起始净值×100，同时记录区间最高与最低值。

   ```ts
   private refreshRangeStat(): void {
     if (this.isRangeActive) {
       const li: number = this.renderer.ratioToIdx(this.leftRatio, this.fundData.length);
       const ri: number = this.renderer.ratioToIdx(this.rightRatio, this.fundData.length);
       this.rangeStat = calcRangeStat(this.fundData, li, ri);
     } else {
    // 未选区间时统计全量数据
       this.rangeStat = calcRangeStat(this.fundData, 0, this.fundData.length - 1);
     }
   }
   ```

4. **股票选基** :

   以股票代码→持仓基金列表的Map为唯一数据源建立双向关联，股票搜索定位目标后反查持有该股票的基金列表，支持持仓占比、近期收益、规模排序。

   ```ts
   export function getFundsByStockCode(code: string): FundHolding[] {
     const list: FundHolding[] | undefined = FUND_MAP.get(code);
     if (list !== undefined) {
       return list;
     }
     return [];
   }
   ```
