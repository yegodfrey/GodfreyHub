# 基金自定义区间收益

#### 场景介绍

基金自定义区间收益查看是理财类（金融理财）应用的高频使用场景之一，如用户浏览基金历史净值时，希望针对自己关心的某一段时间单独查看区间收益率、起止净值、最高最低值等统计信息。

本示例基于[Canvas](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-components-canvas-canvas)组件绘制基金净值折线与坐标轴，通过[PanGesture（平移手势）](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-gestures-pangesture)实现手柄拖拽，配合[@State](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/arkts-state)状态管理驱动画布重绘与统计卡片刷新，实现流畅的自定义区间交互效果。默认仅展示全段净值折线，用户点击图表任意位置即在该处以区间框形式弹出左右两个可拖拽手柄，按住手柄滑动即可调整区间范围，底部统计卡片实时联动；点击区间外遮罩或右上角×按钮可取消区间，恢复全段展示。

#### 实现思路

1. 绘制基金净值图：使用Canvas绘制坐标网格、Y轴净值标签、X轴日期标签与净值折线，含渐变填充。首尾X轴标签分别采用左/右对齐避免被边界裁切；净值数据用确定性伪随机算法生成60天序列，保证每次渲染一致。组件层仅持有Canvas定义，绘制逻辑委托给ChartRenderer。

   ```
   // Canvas组件定义，尺寸变化与就绪时触发绘制
   Canvas(this.ctx)
     .width('100%')
     .height(260)
     .onAreaChange((_e: Area, area: Area) => {
       const w: number = area.width as number;
       const h: number = area.height as number;
       if (w > 0 && h > 0 && (w !== this.canvasWidth || h !== this.canvasHeight)) {
         this.canvasWidth = w;
         this.canvasHeight = h;
         this.drawChart();
       }
     })
     .onReady(() => { this.drawChart(); })
   ```

2. 区间选择交互：以Stack叠加布局承载Canvas底图、左右遮罩、手柄气泡与手势层。未激活时仅显示Canvas与透明触摸层；激活后显示遮罩与手柄气泡，手柄通过PanGesture拖动，更新leftRatio/rightRatio（0\~1比例值，避免随宽度错位）。

   ```
   // Stack叠加布局：Canvas底图+手柄+触摸层
   Stack({ alignContent: Alignment.TopStart }) {
     Canvas(this.ctx)
       .width('100%')
       .height(260)

     // 激活时显示左右手柄
     if (this.isRangeActive) {
       this.HandleColumn('left')
       this.HandleColumn('right')
     }
   }
   .width('100%')
   .height(260)
   ```

3. 激活位置即区间中心：点击触摸层时通过ClickEvent的.x获取点击位置，以此为中心展开默认宽0.2的区间，靠边时自动平移到界内，让每次激活都从用户关注的位置开始。

   ```
   // 以点击位置x为中心激活区间，默认宽0.2，靠边时自动平移
   activateAtX(x: number, canvasWidth: number): DragResult {
     const chartW: number = canvasWidth - this.padLeft - this.padRight;
     let centerRatio: number = (x - this.padLeft) / chartW;
     centerRatio = Math.max(0, Math.min(1, centerRatio));
     const halfWidth: number = 0.1;
     let left: number = centerRatio - halfWidth;
     let right: number = centerRatio + halfWidth;
     // 靠边时自动平移到界内
     if (left < 0) {
       left = 0;
       right = Math.min(1, right + (0 - left));
     }
     if (right > 1) {
       left = Math.max(0, left - (right - 1));
       right = 1;
     }
     return { leftRatio: left, rightRatio: right };
   }
   ```

4. 拖拽手柄更新区间：手柄通过PanGesture拖动，Renderer根据偏移量计算新ratio，组件回写@State后触发重绘，实现UI与逻辑解耦。

   ```
   // 手柄拖拽：Renderer计算newRatio，组件回写@State后重绘
   .gesture(
     PanGesture()
       .onActionStart(() => {
         this.renderer.onDragStart(which,
           which === 'left' ? this.leftRatio : this.rightRatio);
       })
       .onActionUpdate((e: GestureEvent) => {
         const res = this.renderer.onDragUpdate(e.offsetX, this.canvasWidth,
           this.leftRatio, this.rightRatio);
         this.leftRatio = res.leftRatio;
         this.rightRatio = res.rightRatio;
         this.drawChart();
       })
   )
   ```

5. 统计联动：通过@State跟踪isRangeActive/leftRatio/rightRatio，未激活时返回全段统计、激活时返回选中区间统计，底部卡片与顶部日期范围随拖拽实时刷新。

   ```
   // 未激活返回全段统计，激活返回选中区间统计
   private getRangeStat(): RangeStat {
     if (!this.isRangeActive) {
       return calcRangeStat(this.fundData, 0, this.fundData.length - 1);
     }
     const li: number = this.renderer.ratioToIdx(this.leftRatio, this.fundData.length);
     const ri: number = this.renderer.ratioToIdx(this.rightRatio, this.fundData.length);
     return calcRangeStat(this.fundData, li, ri);
   }
   ```
