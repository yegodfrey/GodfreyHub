# LocalAudioInfo

|Class Info|
|:----------------------------------------|
|public class LocalAudioInfo 播放本地音效文件参数对象。|

## Property Summary

|Name|Type|Mandatory/Optional|Description|
|:-------|:-----|:-----------------|:---------------------------|
|SoundId|int|Mandatory|音效ID，大于等于0，随机生成。|
|FilePath|string|Mandatory|音效文件路径。|
|Loop|int|Optional|音效文件循环播放次数，大于等于0，默认值0表示无限循环。|
|Volume|int|Optional|音效音量系数，取值范围[0, 100]，默认值100。|
