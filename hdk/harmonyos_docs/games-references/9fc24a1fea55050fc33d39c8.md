# PublishRtmChannelMessageReq

|Interface Info|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|export interface PublishRtmChannelMessageReq extends [RtmMessageContent](https://developer.huawei.com/consumer/cn/doc/games-references/rtmmessagecontent-minigame-0000002358963648) 发布RTM频道消息请求对象。|

## Property Summary

|Name|Type|Mandatory/Optional|Description|
|:----------------|:----------------|:-----------------|:---------------------------------------------------------------|
|channelId|string|Mandatory|频道ID，仅支持数字(0-9)和字母 (A-Z,a-z)。|
|messageType|number|Mandatory|消息类型。 * 1：文本 * 2：二进制|
|message|string/Uint8Array|Mandatory|消息内容。 > 说明 > * 当消息类型为文本时，消息内容最长为1KB。 > * 当消息类型为二进制时，消息内容最长为32KB。|
|receivers|Array<string>|Optional|频道内的指定接收玩家，最多支持50人。|
|isContentIdentify|boolean|Optional|是否进行内容风控审核。 * true：进行内容风控审核 * false：不进行内容风控审核 默认为false。|
|isAdsIdentify|boolean|Optional|是否进行广告识别。 * true：进行广告识别 * false：不进行广告识别 默认为false。|
|isAllowCacheMsg|boolean|Optional|是否缓存历史消息。 * true：缓存历史消息 * false：不缓存历史消息 默认为false。|
