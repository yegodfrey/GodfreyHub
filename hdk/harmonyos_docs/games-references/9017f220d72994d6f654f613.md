# Web API

华为快游戏为基于 JavaScript 虚拟机的脚本运行环境，为了方便适配浏览器平台的游戏在 快游戏平台上运行，提供了一些游戏常用的 Web 标准的 JavaScript API，这类 API 在快游戏上的使用方式和 Web 环境中保持一致。  

#### Document

华为快游戏通过Adapter的方式模拟实现了有限 Document API ，以方便 Web 游戏适配。  

#### 属性

|全局文档对象|属性名称|说明|
|:-------|:--------------|:------------------------|
|document|readyState|文档的加载状态。|
|document|visibilityState|document的可见性。|
|document|documentElement|文档对象(document)的根元素。|
|document|hidden|布尔值，表示是(true)否(false)隐藏。|
|document|location|一个location对象，文档的url相关的信息。|
|document|head|当前文档中的head元素。|
|document|body|当前文档中的body元素。|
|document|scripts|当前文档中所有script元素的集合。|

#### LocalStorage

快游戏实现了标准的 Web Local Storage 功能，详细内容请参见 "[Local Storage API 参考文档](https://developer.mozilla.org/en-US/docs/Web/API/Storage/LocalStorage)"。  

#### 限制

1. 数据缓存的总大小限制为10MB。
2. 单次存入缓存中的数据大小限制为1MB。
3. 使用Local Storage前，请确保华为账号已登录成功。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212154037.94186130203716481077120047773135:50001231000000:2800:3092B8C98D47CC05DEC504226ACE4A5CF349BEE87AE278EE01288F2B3055901C.png)  
数据缓存并不能写入10个大小为 1MB 的数据，因为数据缓存中数据 key 和表结构也要占用一部分存储空间，所以最多只能写入9个 1MB 大小的数据，写入第10个时会因超出存储大小限制而失败。

#### Canvas 2D

快游戏实现的 Canvas 2D API 非常有限，目的只是为了支持离屏渲染文字和线段。如需使用首先需要创建离屏 Canvas 对象(let canvas = document.createElement('canvas');）,然后需要指定宽和高，以分配绘图 buffer，通过"canvas.width = 100; canvas.height = 100;"来设置宽和高。  

#### 属性

|属性名称|描述|
|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|width|用于设置 canvas 宽，即绘图 buffer 宽。|
|height|用于设置 canvas 高，即绘图 buffer 高。|
|lineWidth|线段宽度。当获取属性值时，它可以返回当前的值（默认值是1.0 ）。当给属性赋值时，0、 负数、 Infinity 和 NaN 都会被忽略；除此之外，都会被赋予一个新值。|
|font|配置范例:"oblique small-caps 18px Arial" 字体样式。绘制文字时，当前字体样式的属性。默认字体是 Arial，字体大小 30。 * font-weight属性不支持数值设置(1 \~ 1000)。 * line-height：属性不支持。 canvas支持的绘制字体都是单行绘制，设置行高对字体的显示没有影响，无需支持。|
|textAlign|水平对齐，有效值： * left：文本左对齐 * right: 文本右对齐 * center：文本水平居中|
|textBaseline|垂直对齐，有效值： * top：文本上对齐 * bottom：文本水平居中 * middle：文本垂直居中|
|fillStyle|填充颜色，调用 API fillText 绘制字体时，使用此颜色填充字体（实心）。|
|strokeStyle|画笔颜色，调用 API strokeText 绘制字体时，使用此颜色绘制字体边框（空心）|

#### void beginPath()

* 描述 清空子路径列表开始一个新路径。

<!-- -->

* 示例代码

  ```
  let canvas = document.createElement('canvas');
  //设置画布宽和高为100
  canvas.width = 100;
  canvas.height = 100;
  let ctx = canvas.getContext('2d');
  ctx.strokeStyle = "rgb(255,0,0)";
  //在画布填充颜色
  ctx.lineWidth = canvas.height;
  ctx.beginPath();
  ctx.moveTo(0, 0);
  ctx.lineTo(canvas.width, 0);
  ctx.lineTo(canvas.width, canvas.height);
  ctx.lineTo(0, canvas.height);
  ctx.stroke();
  ```

#### ImageData createImageData(width, height) 和 ImageData createImageData(imagedata)

* 描述 快游戏实现了标准的 Web API createImageData 功能，详细内容请参见 "[createImageData API 参考文档](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/createImageData)"。

<!-- -->

* 示例代码

  ```
  let imageData = this._context.createImageData(canvas.width, canvas.height / 2);
  for (let i = 0; i < canvas.width; i += 1) {
      for (let j = 0; j < canvas.height / 2; j += 1) {
          let index = (j * canvas.width + i) * 4;
          imageData.data[index + 0] = i % 255;
          imageData.data[index + 1] = (i + j) % 255;
          imageData.data[index + 2] = j % 255;
          imageData.data[index + 3] = 255;
      }
  }
  ```
