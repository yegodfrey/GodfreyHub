# PublishRtmPeerMessageReq

|Interface Info|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|export interface PublishRtmPeerMessageReq extends [RtmMessageContent](https://developer.huawei.com/consumer/cn/doc/games-references/rtmmessagecontent-minigame-0000002358963648) 发送RTM点对点消息请求对象。|

#### Property Summary

|Name|Type|Mandatory/Optional|Description|
|:----------|:----------------|:-----------------|:----------------------------------------------------------|
|peerId|string|Mandatory|消息接收方的玩家ID。|
|messageType|number|Mandatory|消息类型。 * 1：文本 * 2：二进制|
|message|string/Uint8Array|Mandatory|消息内容。 说明： * 当消息类型为文本时，消息内容最长为1KB。 * 当消息类型为二进制时，消息内容最长为32KB。|
