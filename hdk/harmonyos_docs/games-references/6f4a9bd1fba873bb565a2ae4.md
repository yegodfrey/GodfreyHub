# 定时器

#### 接口定义

|接口|描述|
|:------------------------------------------------------------------------------|:-------------------------------------------------------------------|
|[setTimeout(function callback, number delay, any rest)](#section17351181165518)|设定一个定时器，在定时到期以后执行注册的回调函数，返回定时器的编号，该编号可以传递给clearTimeout取消该定时。|
|[clearTimeout(number timeoutID)](#section3781171955618)|取消由setTimeout()方法设置的定时器。|
|[setInterval(function callback, number delay, any rest)](#section92314336572)|设定一个定时器，按照指定的周期（以毫秒计）来执行注册的回调函数，返回定时器的编号，该编号可以传递给clearInterval取消该定时。|
|[clearInterval(number intervalID)](#section12936224205812)|取消由setInterval()方法设置的定时器。|

#### setTimeout(function callback, number delay, any rest)

* 描述 设定一个定时器，在定时到期以后执行注册的回调函数，返回定时器的编号，该编号可以传递给clearTimeout取消该定时。

<!-- -->

* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:-------------------------------------------|
  |callback|function|M|回调函数。|
  |delay|number|M|延迟的时间，函数的调用会在该延迟之后发生，单位ms。|
  |rest|any|O|param1,param2,...paramN等附加参数，它们会作为参数传递给回调函数。|

<!-- -->

* 示例代码

  ```
  var id = setTimeout(
          function() {console.log("setTimeout");},
          666,
          'any'
  )
  ```

#### clearTimeout(number timeoutID)

* 描述 取消由setTimeout()方法设置的定时器。

<!-- -->

* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:--------|:-----|:----------|:---------------|
  |timeoutID|number|M|timeoutID是定时器id。|

<!-- -->

* 示例代码

  ```
  clearTimeout(666)
  ```

<!-- -->

  |callback|function|M|回调函数。|
  |delay|number|M|延迟的时间，函数的调用会在该延迟之后发生，单位ms。|
  |rest|any|O|param1,param2,...paramN等附加参数，它们会作为参数传递给回调函数。|

<!-- -->

* 示例代码

