# IGenericRelation<TGenericKey>

|Class/Struct Info|
|:------------------------------------------------------------------------------------------------------------------|
|public interface IGenericRelation<out TGenericKey> : IRelation 通用关系接口，通过实现该接口来表示实体与非实体之间的关系。 TGenericKey泛型表示关系目标类型。|

## Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:----------------------------------------------------------------------|
|TGenericKey|[GetGenericKey](#section18929961021)() 接口方法，需开发者自行实现。 抽象函数，通过该接口获取关系目标。|

### GetGenericKey

|Method|
|:-----------------------------------------------------------|
|TGenericKey GetGenericKey() 接口方法，需开发者自行实现。 抽象函数，通过该接口获取关系目标。|

**Return**

|Type|Description|
|:----------|:----------|

**Sample Code**

```screen
public struct IntRelation : IGenericRelation<int>
{
    public int value;
    public int GetGenericKey() => value;

}
```
