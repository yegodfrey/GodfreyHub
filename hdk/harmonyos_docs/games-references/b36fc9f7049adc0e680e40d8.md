# 分包加载

> 说明
>
> 从1078版本开始，接口前缀由hbs修改为qg，原hbs仍支持。

## 接口定义

|接口|描述|
|:-------------------------------------------------------|:---------------------------|
|[qg.loadSubpackage(Object object)](#section477118231426)|下载分包，返回LoadSubpackageTask对象。|

### qg.loadSubpackage(Object object)

* 描述 下载分包，返回LoadSubpackageTask对象。

  在js代码中调用该接口将下载指定分包（如果未下载）并加载（如果未加载）game.js文件。

  请不要在一次游戏执行过程中重复执行 qg.loadSubpackage 去加载同一个分包，除非第一次加载失败了，即使您重复加载了，该分包并不会重复下载，更不会重复执行该分包下的game.js。


* 参数object

  |参数|类型|必填(M)/选填(O)|说明|
  |:---------|:-------|:----------|:--------------------|
  |subpackage|string|M|分包名称。|
  |success|function|O|接口调用成功的回调函数。|
  |fail|function|O|接口调用失败的回调函数。|
  |complete|function|O|若有函数传入，将在成功、失败后调用该函数。|


* 返回值

  |参数|类型|说明|
  |:-----------------|:-----|:-------------------|
  |LoadSubpackageTask|object|加载分包任务实例，用于获取分包加载状态。|

  LoadSubpackageTask参数说明

  |属性|类型|说明|
  |:---------|:-------|:--------------|
  |onprogress|function|监听分包加载进度变化的回调函数|

  * onprogress回调函数参数：

    |参数|类型|说明|
    |:--------|:-----|:-----------------|
    |progress|number|分包下载进度百分比。|
    |loadSize|number|已经下载的数据长度，单位Bytes。|
    |totalSize|number|数据总长度，单位Bytes。|


* 示例代码

  ```screen
  onProgressCallback(res) {
      console.log("onProgress" + JSON.stringify(res));
  }
  let loadSubpackageTask = qg.loadSubpackage({
          subpackage: 'name',
          success : function () {
                  console.log("loadSubpackage success" );
          },
          fail:function(){
                  console.log("loadSubpackage fail");
          },
          complete:function() {
                  console.log("loadSubpackage complete");
          }
  });
  loadSubpackageTask.onprogress = this.onProgressCallback;
  ```
