# ReceiveRtmPeerMessageNotify

|Class Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class ReceiveRtmPeerMessageNotify : [RtmMessageNotify](https://developer.huawei.com/consumer/cn/doc/games-references/rtmmessagenotify-csharp-minigame-0000002359123720) 接收RTM点对点消息回调通知。|

## Property Summary

|Name|Type|Description|
|:----------|:-----|:-------------------------------------------------------------|
|ServerMsgId|string|全局发送消息唯一标识。|
|ClientMsgId|string|客户端发送消息唯一标识。|
|Timestamp|long|消息发送时间戳，即距离1970年1月1日0点的毫秒数。|
|SenderId|string|* 当消息来自客户端接口时，SenderId则为消息发送者的玩家ID。 * 当消息来自服务端接口时，SenderId则为空。|
|FromOpenApi|bool|是否来自服务端接口。 * true：来自服务端接口 * false：来自客户端接口|
