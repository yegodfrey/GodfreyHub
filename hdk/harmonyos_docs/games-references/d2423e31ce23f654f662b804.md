# 系统事件

> 说明
>
> 从1078版本开始，接口前缀由hbs修改为qg，原hbs仍支持。

## 接口定义

|接口|描述|
|:------------------------------------------------------------------------|:--------------------------------------------------------------------|
|[qg.onAudioInterruptionBegin(function callback)](#section14491184211221)|监听音频因为受到系统占用而被中断开始，以下场景将触发此事件：闹钟、电话、FaceTime 通话。此事件触发后，游戏内所有音频会暂停。|
|[qg.offAudioInterruptionBegin(function callback)](#section14335540192412)|取消监听音频因为受到系统占用而被中断开始。|
|[qg.onAudioInterruptionEnd(function callback)](#section395320711180)|监听音频中断结束，在收到onAudioInterruptionBegin事件之后，小游戏内所有音频会暂停，收到此事件之后才可再次成功播放。|
|[qg.offAudioInterruptionEnd(function callback)](#section2183128132015)|取消监听音频中断结束。|
|[qg.onError(function callback)](#section62601638132513)|监听全局错误事件。|
|[qg.offError(function callback)](#section37633402269)|取消监听全局错误事件。|

### qg.onAudioInterruptionBegin(function callback)

* 描述 监听音频因为受到系统占用而被中断开始，以下场景将触发此事件：闹钟、电话、FaceTime 通话。此事件触发后，游戏内所有音频会暂停。


* 参数

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:-----------------------|
  |callback|function|M|音频因为受到系统占用而被中断开始事件的回调函数。|

* 示例代码

  ```screen
  qg.onAudioInterruptionBegin(  
          () => {console.log("onAudioInterruptionBegin");}
  );
  ```

### qg.offAudioInterruptionBegin(function callback)

* 描述 取消监听音频因为受到系统占用而被中断开始。

* 参数

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:-----------|
  |callback|function|M|取消监听事件的回调函数。|

* 示例代码

  ```screen
  qg.offAudioInterruptionBegin(
          () => {console.log("offAudioInterruptionBegin");}
  );
  ```

### qg.onAudioInterruptionEnd(function callback)

* 描述 监听音频中断结束，在收到 onAudioInterruptionBegin 事件之后，小游戏内所有音频会暂停，收到此事件之后才可再次成功播放。


* 参数

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:---------------|
  |callback|function|M|监听音频中断结束事件的回调函数。|

* 示例代码

  ```screen
  qg.onAudioInterruptionEnd(
          () => {console.log("onAudioInterruptionEnd");}
  );
  ```

### qg.offAudioInterruptionEnd(function callback)

* 描述 取消监听音频中断结束。

* 参数

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:-----------------|
  |callback|function|M|取消监听音频中断结束事件的回调函数。|

* 示例代码

  ```screen
  qg.offAudioInterruptionEnd(
          () => {console.log("offAudioInterruptionEnd");}
  );
  ```

### qg.onError(function callback)

* 描述 监听全局错误事件。

* 参数

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:----------------------------------------------------------------------------------------------------------|
  |callback|function|M|全局错误事件的回调函数，请参见[callback回调函数参数](#ZH-CN_TOPIC_0000002366156864__zh-cn_topic_0000001084034252_li74124173812)。|

  * callback回调函数参数

    |参数|类型|说明|
    |:------|:-----|:-------------------|
    |message|string|包含错误位置、错误信息、错误调用堆栈等。|

* 示例代码

  ```screen
  qg.onError(
          (res) => {console.log("onError message = " + res.message);}
  );
  ```

### qg.offError(function callback)

* 描述 取消监听全局错误事件。

  |:-------|:-------|:----------|:-----------|
  |callback|function|M|取消监听事件的回调函数。|

* 示例代码

  ```screen
  qg.offError(
          () => {console.log("offError");}
  );
  ```
