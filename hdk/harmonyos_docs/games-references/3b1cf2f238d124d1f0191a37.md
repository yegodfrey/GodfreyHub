|接口|描述|
|:----------------------------------------------------|:------------|
|[qg.serviceShare(Object object)](#section10761505309)|分享数据到第三方分享平台。|

#### qg.serviceShare(Object object)

* 描述 分享数据到第三方分享平台。

* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:--------|:-------|:--------------|:-----------------------------------------------------------------------|
  |shareType|int|M|分享类型： * 0：默认图文。 * 1：纯文字1。 * 2：纯图片。 * 3：音频。 * 4：视频。|
  |title|string|M（分享类型为0，1，3，4）|分享类型为0，1，3，4时必填，分享的标题。|
  |summary|string|O|分享的摘要。|
  |targetUrl|string|M（分享类型为0，3，4）|分享类型为0，3，4时必填，点击后的跳转URL。 说明： URL是否能正常打开依赖被分享的第三方平台的能力。|
  |imagePath|string|M（分享类型为2，3，4）|分享图片/缩略图的本地地址。 当分享类型为0时，imagePath可以选填，如果填写则为分享图片的本地路径，不填的话，则分享后没有图片。|
  |mediaUrl|string|M（分享类型为3，4）|分享的音乐/视频数据URL。|
  |platforms|array|O|分享到的平台，不填则默认分享所有平台。 可用值包括：WEIXIN(微信好友)、WEIXIN_CIRCLE(微信朋友圈)、SYSTEM(系统分享)|
  |success|function|O|接口调用成功的回调函数(暂不支持)。|
  |fail|function|O|接口调用失败的回调函数。|
  |cancel|function|O|取消回调。|

* 示例代码

  ```
  qg.serviceShare({
          shareType: 4,
          title: '全平台的标题',
          summary: '全平台的摘要',
          imagePath: 'assets/Chest_DM.jpg',
          targetUrl: 'https://www.***.com/',
          mediaUrl: 'https://ss0.***.com/-0U0bnSm1A5BphGlnYG/cae-legoup-video-target/93be3d88-9fc2-4fbd-bd14-833bca731ca7.mp4',
          platforms: "",
          fail: function (data, code) {console.log("service share fail:" + code + data)},
          cancel: function () {console.log("cancel")}
  })
  ```
