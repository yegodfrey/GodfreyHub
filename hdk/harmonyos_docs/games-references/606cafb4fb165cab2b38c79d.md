# 订阅消息

![](https://media:401781143678723918)  
使用该能力前，请先使用[qg.canIUse('MiniGame.SubscribePushMsg')](https://developer.huawei.com/consumer/cn/doc/games-references/games-api-quickgame-runtime-sysinfo-0000002399676789#section165771434195617)判断该能力是否支持使用。  

#### 接口定义

|接口|描述|
|:----------------------------------------------------------------|:-------------------------|
|[qg.requestSubscribeMessage(Object object)](#section917310297396)|调起快游戏订阅消息界面，返回用户订阅消息的操作结果。|
|[qg.querySubscribeSetting()](#section1072120577392)|查询订阅设置开关。|

#### qg.requestSubscribeMessage(Object object)

* 描述 调起快游戏订阅消息界面，返回用户订阅消息的操作结果。

* 参数object  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:--------------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
  |tmplIds|Array\<string\>|M|需要[订阅的消息模板的ID](https://developer.huawei.com/consumer/cn/doc/games-guides/games-quickgame-runtime-subscribe-notification-0000002624500471#section1867813082216)的集合，一次调用最多可订阅3条消息。|
  |success|function|O|接口调用成功的回调函数，详情请参见[success回调函数参数](#ZH-CN_TOPIC_0000002624502671__zh-cn_topic_0000002524560898_li20269182415463)。|
  |fail|function|O|接口调用失败的回调函数，详情请参见[fail回调函数参数](#ZH-CN_TOPIC_0000002624502671__zh-cn_topic_0000002524560898_li19780144512468)。|
  |complete|function|O|若有函数传入，将在成功、失败后调用该函数。|

  * success回调函数参数  

    |参数名|类型|说明|
    |:---------------------|:-----|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
    |errMsg|string|接口调用成功时，errMsg的值为"requestSubscribeMessage:ok"。|
    |\[TEMPLATE_ID:string\]|string|\[TEMPLATE_ID\]是动态的键，即[订阅模板ID](https://developer.huawei.com/consumer/cn/doc/games-guides/games-quickgame-runtime-subscribe-notification-0000002624500471#section1867813082216)，取值说明如下： * accept：表示用户同意订阅该条ID对应的订阅模板消息。 * reject：表示用户拒绝订阅该条ID对应的订阅模板消息。 * ban：表示已被后台封禁。 * filter：表示该订阅模板因为模板标题同名被后台过滤。 例如{errMsg: "requestSubscribeMessage:ok", 123456789: "accept"}表示用户同意订阅模板ID为123456789的这条消息。|

  * fail回调函数参数  

    |参数名称|说明|
    |:------|:-------------------------|
    |errCode|[错误码](#section9990711598)。|
    |errMsg|错误信息。|

* 示例代码

  ```
  if (typeof qg.canIUse === 'function') {
      const isSupportSubscribePushMsg = qg.canIUse('MiniGame.SubscribePushMsg');
      if (isSupportSubscribePushMsg) {
          qg.requestSubscribeMessage({
              tmplIds: ['123456789','123456790'],
              success : function (res) {
                  console.log("requestSubscribeMessage success： " + JSON.stringify(res));
              },
              fail:function(errMsg, errCode){
                  console.log("requestSubscribeMessage fail: "+ errMsg + ", errCode: " + errCode);
              },
              complete:function() {
                  console.log("requestSubscribeMessage complete");
              }
          });
      }
  }
  ```

#### qg.querySubscribeSetting()

* 描述 查询订阅设置开关。

* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:--------------------------------------------------------------------------------------------------------------|
  |success|function|O|接口调用成功的回调函数，详情请参见[success回调函数参数](#ZH-CN_TOPIC_0000002624502671__zh-cn_topic_0000002524560898_li20269182415463)。|
  |fail|function|O|接口调用失败的回调函数，详情请参见[fail回调函数参数](#ZH-CN_TOPIC_0000002624502671__zh-cn_topic_0000002524560898_li19780144512468)。|
  |complete|function|O|若有函数传入，将在成功、失败后调用该函数。|

  * success回调函数参数  

    |参数名|类型|说明|
    |:---------------|:-----------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------|
    |enable|boolean|通知总开关。|
    |templateSettings|Array\<[TemplateSetting](#ZH-CN_TOPIC_0000002624502671__zh-cn_topic_0000002524560898_li331012577212)\>|订阅模板设置。详情请参见[TemplateSetting参数](#ZH-CN_TOPIC_0000002624502671__zh-cn_topic_0000002524560898_li331012577212)。|

    * TemplateSetting参数  

      |参数|类型|说明|
      |:-------|:------|:--------------------------------------------------------------------------------------------------------------------------------------------------------|
      |tmplId|string|[订阅模板ID](https://developer.huawei.com/consumer/cn/doc/games-guides/games-quickgame-runtime-subscribe-notification-0000002624500471#section1867813082216)。|
      |tmplName|string|订阅模板名称。|
      |enable|boolean|订阅模板开关。|
      |type|integer|订阅模板类型： * 0：一次性订阅。 * 1：长期订阅。|

  * fail回调函数参数  

    |参数名称|说明|
    |:------|:-------------------------|
    |errCode|[错误码](#section9990711598)。|
    |errMsg|错误信息。|

* 示例代码

  ```
  if (typeof qg.canIUse === 'function') {
      const isSupportSubscribePushMsg = qg.canIUse('MiniGame.SubscribePushMsg');
      if (isSupportSubscribePushMsg) {
          qg.querySubscribeSetting({
              success: function (ret) {
                  console.log('querySubscribeSetting success: ' + JSON.stringify(ret));
              },
              fail: function (errMsg, errCode) {
                  console.log('querySubscribeSetting fail: ' + errMsg + ", errCode: " + errCode);
              },
              complete:function() {
                  console.log("querySubscribeSetting complete");
              }
          });
      }
  }
  ```

#### 错误码

|错误码|错误信息|说明|
|:----|:----------------------------------------------------|:----------------------------------|
|200|common error|通用错误。|
|10001|TmplIds can't be empty|参数传空。|
|10002|Request list fail|网络问题，请求消息列表失败。|
|10003|Request subscribe fail|网络问题，订阅请求发送失败。|
|10004|Invalid template id|参数类型错误。|
|10005|No template data return, verify the template id exist|没有模板数据，一般是订阅模板ID不存在或者和订阅模板类型不对应导致的。|
|10006|Templates type must be same|订阅模板消息类型不一致，既有一次性订阅又有长期订阅。|
|10007|Templates count out of max bounds|订阅模板消息数量超过上限。|
|10008|The main switch is switched off|用户关闭了主开关，无法进行订阅，|
|10009|This app was banned from subscribing messages|禁用名单。|
|10010|This app unactive subscribing messages rights|未开通订阅权限。|
