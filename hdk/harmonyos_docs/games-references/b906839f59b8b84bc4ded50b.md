# ClientConfig

|Class Info|
|:------------------------------------------------------------------|
|namespace Com.Huawei.Game.Gobes public class ClientConfig 客户端初始化参数。|

#### Property Summary

|Name|Type|Mandatory/Optional|Description|
|:--------------|:---------------------------------------------------------------------------------------------------------------------------|:-----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|ClientAppId|string|Mandatory|客户端App ID。 说明： 您可登录[AGC控制台](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，进入"我的项目\>项目设置\>常规\>应用" 获取"APP ID"信息。|
|ClientId|string|Mandatory|客户端ID。 说明： 您可登录[AGC控制台](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，进入"我的项目\>项目设置\>常规\>项目" 获取客户端ID中的"Client ID"信息。|
|ClientSecret|string|Optional|客户端密钥。 说明： * 您可登录[AGC控制台](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，进入"我的项目\>项目设置\>常规\>项目" 获取客户端ID中的"Client Secret"信息。 * "ClientSecret"和"[AccessToken](#ZH-CN_TOPIC_0000002361516120__p1911592952919)"二者传其一即可，如果同时传入，将使用传入的AccessToken作为最终AGC接入凭证。|
|ClientOpenId|string|Mandatory|玩家ID。 说明： 可以是您的游戏在第三方平台生成的玩家ID，或者是您的自建账号体系生成的玩家ID。|
|CreateSignature|Func\<[Signature](https://developer.huawei.com/consumer/cn/doc/games-references/gameobe-signature-csharp-0000002395196065)\>|Optional|创建签名的算法，仅使用签名初始化SDK时必填。|
|AccessToken|string|Optional|AGC接入凭证。 说明： "[ClientSecret](#ZH-CN_TOPIC_0000002361516120__p289813118119)"和"AccessToken"二者传其一即可，如果同时传入，将使用传入的AccessToken作为最终AGC接入凭证。|
