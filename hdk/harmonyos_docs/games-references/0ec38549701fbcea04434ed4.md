# 获取文件上传地址

调用此接口获取待检测文件的上传地址。

## 使用约束

已[开启文本消息功能](https://developer.huawei.com/consumer/cn/doc/games-guides/games-gamemme-console-servicemanagement-0000002338391901)。

## 接口原型

|承载协议|HTTPS POST|
|-----|--------------------------------------------------------------------------------|
|接口方向|开发者服务器 -> 华为服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/gmme/openapi/files/{appId}/apply-upload|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 请求参数

### path

|参数名称|必选（M）/可选（O）|类型|参数说明|
|:----|:----------|:-----|:------------------------------------------------------------------------------------------------------------------------------|
|appId|M|String|应用ID，具体获取请参见[准备游戏信息](https://developer.huawei.com/consumer/cn/doc/games-guides/games-gamemme-gameinformation-0000002304472612)。|

### Request Header

|参数名称|必选（M）/可选（O）|类型|参数说明|
|:------------|:----------|:-----|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Authorization|M|String|签名信息，用于校验消息是否可信，格式为"Authorization: Bearer ${access_token}"，其中access_token为调用[获取Token](https://developer.huawei.com/consumer/cn/doc/games-references/gamemme-obtaintoken-restapi-0000002358963836)接口返回的access_token。|
|client_id|M|String|客户端ID，具体获取请参见[准备游戏信息](https://developer.huawei.com/consumer/cn/doc/games-guides/games-gamemme-gameinformation-0000002304472612)。|
|requestId|M|String|请求ID，请勿使用重复的请求ID进行请求。|

### Request Body

|参数名称|必选（M）/可选（O）|类型|参数说明|
|:---------|:----------|:-----|:-----------------------------------------------------|
|fileName|M|String|包含后缀名的文件名称。要求如下： * 文件名不能有特殊字符：^|/:*?"<> * 文件后缀仅支持.csv。|
|fileSha256|M|String|文件的SHA256值。|
|fileSize|M|String|待上传文本文件的大小，单位：字节，最大不超过10MB。|
|fileType|M|int|文件类型。 * 0：文本。|

## 响应参数

|参数|类型|必选(M)/可选(O)|说明|
|:---------------------------------------------------|:-----|:----------|:-----------------------------------------------------------------|
|[ret](#ZH-CN_TOPIC_0000002392643865__p1170913233715)|String|M|包含返回码及描述信息的JSON字符串，格式为{"code":*retcode* , "msg": "*description*"}。|
|[data](#ZH-CN_TOPIC_0000002392643865__p758653412123)|String|M|若调用成功，将返回文件上传信息。|

**ret参数说明**

|参数名称|必选（M）/可选（O）|类型|参数说明|
|:---|:----------|:------|:-----------------------------------------------------------------------------------------|
|code|M|Integer|返回码。 * 0：成功。 * 600001：文件名后缀不支持。 * 600045：应用不属于当前团队。 * 600047：申请文件上传失败。 * 600104：应用未开启IM功能。|
|msg|O|String|描述信息。|

**data参数说明**

|参数|类型|必选(M)/可选(O)|说明|
|:--------------------------------------------------------------|:-----|:----------|:------|
|fileId|String|M|文件ID。|
|[fileUploadInfo](#ZH-CN_TOPIC_0000002392643865__p1657163013259)|String|M|文件上传信息。|

fileUploadInfo参数说明

|参数|类型|必选(M)/可选(O)|说明|
|:------------|:-----------------------------------------------------------------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|uploadMethod|String|M|文件上传的方法：PUT|
|uploadUrl|String|M|文件待上传的URL。|
|uploadHeaders|List<[UploadHeader](#ZH-CN_TOPIC_0000002392643865__p896235910336)>|M|通过文件待上传URL上传文件至文件服务器时，请求头所需的参数，为JSON结构，格式如下：[{"key": "x-amz-content-sha256", "value": "***"}, {"key": "Authorization", "value": "***"}, {"key": "x-amz-date", "value": "***"}, {"key": "Host", "value": "***"}, {"key": "Content-Type", "value": "***"}]，详情可参见[上传单个文件](https://developer.huawei.com/consumer/cn/doc/games-references/gamemme-uploading-file-restapi-0000002359123732)。 > 说明 > UploadHeader类为key-value形式，其中key取值如下： > * x-amz-content-sha256 > * Authorization > * x-amz-date > * Host > * Content-Type|

## 调用示例

```screen
private ApplyFileUploadRspData applyFileUpload() throws IOException {
        OkHttpClient client = new OkHttpClient().newBuilder().build();
        MediaType mediaType = MediaType.parse("application/json");
        RequestBody body = RequestBody.create(mediaType,
            "{\r\n    \"fileName\":\"test5.csv\", \r\n    \"fileSha256\":\"ac896e4fe5e3fa1df0a8999d47ccc82c7c5fe68fec7d10ff972cf5219274a20e\",\r\n    \"fileSize\":\"362\",\r\n    \"fileType\": 0\r\n}");
        Request request = new Request.Builder().url(url + "/api/gmme/openapi/files/" + appId + "/apply-upload")
            .method("POST", body)
            .addHeader("client_id", this.clientId)
            .addHeader("requestId", String.valueOf(new Random().nextLong()))
            .addHeader("Content-Type", "application/json")
            .addHeader("Authorization", "Bearer " + this.token)
            .build();
        Response response = client.newCall(request).execute();
        ResponseBody responseBody = response.body();
        String bodyStrRespon = "";
        BufferedSource source = responseBody.source();
        source.request(Long.MAX_VALUE);
        Buffer buffer = source.getBuffer();
        Charset charset = Charset.forName("UTF-8");
        MediaType contentType = responseBody.contentType();
        if (contentType != null) {
            try {
                charset = contentType.charset(charset);
            } catch (UnsupportedCharsetException e) {
                e.printStackTrace();
            }
        }
        bodyStrRespon = buffer.clone().readString(charset);
        ApplyFileUploadRsp rsp = JSON.parseObject(bodyStrRespon, ApplyFileUploadRsp.class);
        if (rsp.getRet().getCode() != 0) {
            return null;
        }
        return rsp.getData();
    }

}
```
