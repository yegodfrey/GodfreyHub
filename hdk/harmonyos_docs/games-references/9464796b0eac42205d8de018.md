# GetAvailableRoomsConfig

|Interface Info|
|:----------------------------------------------------|
|export interface GetAvailableRoomsConfig 获取可加入房间列表参数。|

## Property Summary

|Name|Type|Mandatory/Optional|Description|
|:-----------|:--------------|:-----------------|:--------------------------------------------------------------------------------|
|roomType|string|Optional|房间类型。|
|offset|number | string|Optional|偏移量，使用房间的createTime作为每次请求的标记，第一次请求时为0。|
|limit|number|Optional|单次请求获取的房间数量，不选时服务端默认为20。|
|sync|boolean|Optional|是否返回帧同步中的房间。 * true：返回的房间列表中将包含帧同步中的房间和空闲的房间。 * false：返回的房间列表中仅包含空闲的房间。 默认值为true。|
|roomTypeList|list<string>|Optional|房间类型列表。|
