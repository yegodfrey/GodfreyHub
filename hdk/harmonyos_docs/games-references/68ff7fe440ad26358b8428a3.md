# 获取Token

## 功能介绍

与华为服务器端交互前，应用需要对API客户端接入请求进行授权，鉴权成功后客户端可以获取一个认证Token，应用可以在该Token有效期内访问已授权的资源。

## 使用约束

[创建API客户端](https://developer.huawei.com/consumer/cn/doc/games-guides/games-binary-optimization-agc-works-0000002342950440#section2939558155118)生成Token的客户端ID和密钥。

## 接口原型

|承载协议|HTTPS|
|-----|-------------------------------------------------------------------|
|接口方向|开发者服务器->华为服务器|
|接口方法|POST|
|接口URL|https://connect-api.cloud.huawei.com/api/oauth2/v1/token|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 请求参数

|参数|类型|必选(M)/可选(O)|说明|
|:------------|:-----|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
|grant_type|String|M|固定传入**client_credentials**。|
|client_id|String|M|客户端ID，即[创建API客户端](https://developer.huawei.com/consumer/cn/doc/games-guides/games-binary-optimization-agc-works-0000002342950440#section2939558155118)中生成的客户端ID。|
|client_secret|String|M|客户端密钥，即[创建API客户端](https://developer.huawei.com/consumer/cn/doc/games-guides/games-binary-optimization-agc-works-0000002342950440#section2939558155118)中生成的密钥。|

## 请求示例

```screen
POST /api/oauth2/v1/token HTTP/1.1
Host: connect-api.cloud.huawei.com
Content-Type: application/json

{
   "grant_type":"client_credentials",
   "client_id":"26********20",
   "client_secret":"************************"
}
```

## 响应参数

|参数|类型|必选(M)/可选(O)|说明|
|:-----------|:-----|:----------|:--------------------------------------------------------|
|access_token|string|M|认证Token，在客户端向华为服务端发送请求的Authorization Bearer头中携带。|
|expires_in|long|M|access_token的有效期，单位：秒。您需要在过期时间到达时重新调用本接口获取新的access_token。|

## 响应示例

```screen
HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8

{
    "access_token": "eyJhbGciOiJIUzU****************",    
    "expires_in": 172800
}
```
