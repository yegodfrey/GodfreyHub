# 多线程Worker

#### 接口定义

|接口|描述|
|:-------------------------------------------------------------------|:-------------------|
|[qg.createWorker(string scriptPath)（1117+）](#section95225429541)|在主线程中创建一个Worker子线程。|
|[Worker.postMessage(Object message)（1117+）](#section1617724003910)|主线程与Worker子线程相互发送消息。|
|[Worker.onMessage(Function listener)（1117+）](#section71201818142812)|主线程与Worker子线程相互接收消息。|
|[Worker.terminate()（1117+）](#section135891211462)|在主线程中结束Worker子线程。|

#### qg.createWorker(string scriptPath)（1117+）

* 描述 在主线程中创建一个Worker子线程。

* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:---------|:-----|:----------|:----------------------|
  |scriptPath|string|M|Worker入口文件的绝对路径，且不以/开头。|

* 返回 Worker实例。如果创建失败，返回undefined。

* 示例代码

  ```
  let worker = qg.createWorker('workers/index.js')
  ```

#### Worker.postMessage(Object message)（1117+）

* 描述 主线程与Worker子线程相互发送消息。

* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:------|:-----|:----------|:----------------------|
  |message|object|M|主线程与Worker子线程相互发送的消息内容。|

* 示例代码

  ```
  // 主线程向Worker线程发送消息
  // worker是主线程调用qg.createWorker接口返回的对象
  worker.postMessage({
    msg: 'hello from main'
  })

  // Worker线程向主线程发送消息
  // 在Worker子线程中，worker是全局变量
  worker.postMessage({
    msg: 'hello from worker'
  })
  ```

#### Worker.onMessage(Function listener)（1117+）

* 描述 主线程与Worker子线程相互接收消息。

* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:--------------------------------------------------------------------------------------------------------------------|
  |listener|function|M|主线程与Worker子线程相互接收的消息内容，详情请参见[listener](#ZH-CN_TOPIC_0000002366156880__zh-cn_topic_0000001933452820_li12210355174010)。|

  * listener  

    |参数|类型|必填(M)/选填(O)|说明|
    |:------|:-----|:----------|:----|
    |message|object|M|消息内容。|

* 示例代码

  ```
  // 主线程接收Worker线程发送的消息
  // worker是主线程调用qg.createWorker接口返回的对象
  worker.onMessage((message) => {
    console.log(`received message from worker: ${message}`)
  })


  // Worker线程接收主线程发送的消息
  // 在Worker子线程中，worker是全局变量
  worker.onMessage((message) => {
    console.log(`received message from main: ${message}`)
  })
  ```

#### Worker.terminate()（1117+）

* 描述 在主线程中结束Worker子线程。

* 示例代码

  ```
  // worker是主线程调用qg.createWorker接口返回的对象
  worker.terminate()
  ```
