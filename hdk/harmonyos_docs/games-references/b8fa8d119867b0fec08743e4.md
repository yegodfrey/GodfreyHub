# GoLink

|Class/Struct Info|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------|
|public struct GoLink : IComponent GoLink为PGD预置Component，用于在混合模式下将ECS实体与团结引擎的GameObject 建立绑定关系，缓存Transform、对象池槽位等信息。 类型定义于PGD插件包的Runtime/Hybrid/GoLink.cs。|

#### Property Summary

|Name|Type|Description|
|:---------|:---------|:----------------------------------|
|transform|Transform|缓存绑定GameObject的Transform引用。 避免重复访问。|
|gameObject|GameObject|绑定的游戏对象实例引用。|
