# ServerEvent

|Class Info|
|:----------------------------------|
|export interface ServerEvent 服务端事件。|

#### Property Summary

|Name|Type|Description|
|:---------|:-----|:------------------------------------------------------------------------------------------------------------------------------|
|eventType|string|事件类型。 * 1：匹配开始 * 6：加入小队 * 7：离开小队 * 8：解散小队 * 9：更新小队|
|eventParam|string|事件参数，JSON对象格式。 示例： ``` { "roomId":"xxx", "group":{ "groupId":"xxx", "ownerId":"xxx", "players":[ { "playerId":"xxx" } ] } } ```|
