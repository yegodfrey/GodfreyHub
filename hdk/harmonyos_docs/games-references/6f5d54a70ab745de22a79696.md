# RecvFrameMessage

|Interface Info|
|:-----------------------------------------|
|export interface RecvFrameMessage 服务端推送消息。|

#### Property Summary

|Name|Type|Description|
|:-----------------|:----------------------------------------------------------------------------------------------------------------------------|:------------------------------------|
|currentRoomFrameId|number|当前房间的帧数据ID。|
|frameInfo|[FrameInfo](https://developer.huawei.com/consumer/cn/doc/games-references/gameobe-frameinfo-server-ts-0000002361676160)\[\]|帧消息。|
|ext|[FrameExtInfo](https://developer.huawei.com/consumer/cn/doc/games-references/gameobe-frameextinfo-server-ts-0000002395356117)|附加信息。|
|isReplay|boolean|是否为补帧。 * true：补帧 * false：正常帧|
|time|number|该帧到达实时服务器的时间戳，即到达时间距离1970年1月1日0点的毫秒数。|
