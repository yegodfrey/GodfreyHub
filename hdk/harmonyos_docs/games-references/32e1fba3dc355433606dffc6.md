# GroupInfo

|Interface Info|
|:-------------------------------|
|export interface GroupInfo 队伍信息。|

## Property Summary

|Name|Type|Description|
|:--------------------|:-------------------------------------------------------------------------------------------------------------------|:------------------------------|
|groupId|string|队伍ID。|
|groupName|string|队伍名称。|
|maxPlayers|number|队伍最大支持人数，取值范围为[1, 100]。|
|ownerId|string|队长ID。|
|customGroupProperties|string|自定义队伍属性，最大支持2048个字符。|
|isLock|number|队伍是否禁止加入。 * 0：不禁止 * 1：禁止 默认值为0。|
|isPersistent|number|是否持久化。 * 0：不持久化 * 1：持久化 默认值为0。|
|players|[PlayerInfo](https://developer.huawei.com/consumer/cn/doc/games-references/gameobe-playerinfo-js-0000002361516084)[]|房间内玩家列表。|
