# BatchEntityBuilder

|Class/Struct Info|
|:--------------------------------------------------------------------------------------|
|public sealed class BatchEntityBuilder 批量构造器用于预先设置一组组件和标签，然后一次性创建多个具有相同组件和标签的实体，从而提高性能。|

#### Constructor Summary

|Constructor Name And Description|
|:---------------------------------------------------------------------------|
|[BatchEntityBuilder](#section6236112513117)(EcsWorldBase worldBase) 创建批量构造器。|

#### Property Summary

|Name|Type|Description|
|:------------------|:---|:---------------|
|TotalComponentCount|int|批量构造器中包含的组件种类数量。|
|TotalTagCount|int|批量构造器中包含的标签种类数量。|

Sample Code

```
var world = new IECSWorld();
// 创建批量构造器
var batch = world.GetBatchBuilder();
// 添加批量指令
batch.AddComponent<PgdPosition>()
    .AddComponent(new PgdRotation(1, 2, 3, 4))
    .AddTag<TestTag>()
    .AddTags(ITags.Get<TestTag1, TestTag2>());
// 批量构造器中包含的组件种类数量
batch.TotalComponentCount; // 2
// 批量构造器中包含的标签种类数量
batch.TotalTagCount; // 2
```

#### ToString

|Method|
|:--------------------------------------------|
|string ToString() 描述批量构造器信息，打印的组件和标签名字均会带命名域。|

Return  

|Type|Description|
|:-----|:----------|
|string|批量构造器信息。|

Sample Code

```
var world = new IECSWorld();
// 创建批量构造器
var batch = new BatchEntityBuilder(world);
// 添加批量指令
batch.AddComponent<PgdPosition>()
    .AddComponent(new PgdRotation(1, 2, 3, 4))
    .AddTag<TestTag>()
    .AddTags(ITags.Get<TestTag1, TestTag2>());
// 打印批量构造器信息，带命名域。预设组件/标签命名域为"Pgd."，自定义组件/标签/共享组件根据实际情况而定
batch.ToString(); // "Components: [Pgd.PgdPosition, Pgd.PgdRotation], Tags: [TestTag, TestTag2]"
```
