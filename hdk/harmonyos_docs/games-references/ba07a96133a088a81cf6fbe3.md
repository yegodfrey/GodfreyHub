#### 接口定义

|接口|描述|
|:--------------------------------------------------------|:------|
|[qg.insertCalendar(Object object)](#section5212642142718)|插入日历事件。|

#### qg.insertCalendar(Object object)

* 接口描述 插入日历事件。

* 使用约束
  * 适用终端：手机、平板、车机。
  * 适用区域：全球。
* 请求参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:------------|:-------|:----------|:------------------------------------------------------------------------------------------------------------------|
  |title|string|M|事件的标题。|
  |description|string|O|事件的描述。|
  |startDate|long|M|事件开始时间，以从公元纪年开始计算的协调世界时毫秒数表示。|
  |endDate|long|M|事件结束时间，以从公元纪年开始计算的协调世界时毫秒数表示。|
  |timezone|string|O|事件的时区。|
  |allDay|boolean|O|* true 表示此事件占用一整天（按照本地时区的定义）。 * false 表示它是常规事件，可在一天内的任何时间开始和结束。|
  |rrule|string|M|事件的重复发生规则格式。例如，"FREQ=WEEKLY;COUNT=10;WKST=SU"。 您可以在[此处](https://tools.ietf.org/html/rfc5545#section-3.8.5.3)找到更多示例。|
  |remindMinutes|array|O|在事件开始前几分钟进行提醒。例如：\[5,15,30\]。|
  |organizer|string|O|事件组织者（所有者）的电子邮件。|
  |success|function|O|成功回调，值为插入成功的id（整型）。|
  |fail|function|O|接口调用失败的回调函数。|

* 示例代码

  ```
  qg.insertCalendar({
      title:"事件A",
      startDate:1490770543000,
      endDate:1490880543000,
      remindMinutes:[5,15,30],
      rrule:"FREQ=WEEKLY;COUNT=2",
      success:function(data){console.log("handling success");}
  })
  ```

#### 错误码

|错误码|说明|
|:--|:----------------------|
|201|用户拒绝，获取写日历权限失败。|
|202|参数非法，如输入时间格式不对、参数不符合标准。|
