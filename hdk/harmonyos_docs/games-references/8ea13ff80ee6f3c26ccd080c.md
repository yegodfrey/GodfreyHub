# Push Kit（推送服务）

Push Kit（推送服务）是华为提供的消息推送平台，建立了从云端到终端的消息推送通道。Push Kit（推送服务）的ArkTS API请参见[ArkTS API](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/push-arkts)。
