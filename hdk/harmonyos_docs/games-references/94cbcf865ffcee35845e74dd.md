```screen

world.OnTagChanged -= tagChanged;

world.OnEntityCreated -= entityCreated;

{
    /*事件逻辑*/
};

world.OnEntityDestroyed -= entityDestroyed;
// 定义、注册、移除子实体变更事件处理器
Action<ChildEntityChangedEvent> childEntityChanged = (args) =>
{
    /*事件逻辑*/

EcsWorldBase.OnSystemChanged -= systemAdd;
// 可通过IsEventHubEnabled字段查看EventHub启用状态，默认禁用
```

### FindCollection

|Method|
|:----------------------------------------------------------------------------------------------|
|PgdSystemCollection FindCollection(string systemName, bool recursive) 查找指定名称对应的系统集合，可以选择是否递归查找。|

**Parameters**

|Name|Type|Description|
|:---------|:-----|:------------------------------------------------------------------------------------|
|systemName|string|名称。|
|recursive|bool|递归标识： * recursive为true，则会遍历每个系统/系统集合的子系统/系统集合。 * recursive为false，则只会查找根系统集合的子系统/系统集合。|

**Return**

|Type|Description|
|:------------------|:----------|
|PgdSystemCollection|系统集合。|

**Sample Code**

```screen
var world = new IECSWorld();
var collection1 = new TestCollection("TestCollection1");
var collection2 = new TestCollection("TestCollection2");
collection1.Add(collection2);
world.RegisterSystem(collection1);
// 在world中查找目标PgdSystemCollection，recursive为false，则不会递归查找子系统集合的子系统集合
world.FindCollection("TestCollection2", false); // null
// recursive为true，则会递归查找子系统集合的子系统集合
collection1.FindCollection("TestCollection2", true); // 返回collection2
```
