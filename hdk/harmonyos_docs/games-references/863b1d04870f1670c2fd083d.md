# 支付

> 注意
>
> 该功能依赖IAP SDK提供服务，IAP SDK 可能会收集玩家的个人数据。若在快游戏中使用该功能，请提前告知玩家将搜集个人数据，并引导玩家详细阅读对应的隐私政策。

## 使用限制

|适用终端|手机、平板|
|----|-----|
|适用区域|全球|

## 接口定义

|接口|描述|
|:---------------------------------------------------------------------|:-----------------------------------|
|[qg.isEnvReady(Object object)（1103+）](#section1623962461015)|判断当前华为账号所属国家或地区是否支持华为IAP支付。|
|[qg.isSandboxActivated(Object object)（1103+）](#section181371925102211)|判断华为账号和快游戏RPK版本是否满足沙盒条件。|
|[qg.obtainOwnedPurchases(Object object)（1103+）](#section3284913305)|查询用户的已购买数据，包括消耗型商品、非消耗型商品。|
|[qg.obtainProductInfo(Object object)（1103+）](#section125017344614)|查询在AGC控制台配置的商品详情。|
|[qg.createPurchaseIntent(Object object)（1103+）](#section416683091)|创建在AGC控制台配置的商品购买订单，支持购买消耗型商品、非消耗型商品。|
|[qg.consumeOwnedPurchase(Object object)（1103+）](#section2946161093810)|消耗已支付成功的消耗型商品。|

### qg.isEnvReady(Object object)（1103+）

* 描述 通过该接口可以判断当前华为账号所在的服务国家/地区是否支持IAP支付。

* 参数

  |参数|类型|必填(M)/可填(O)|说明|
  |:------------|:-------|:----------|:--------------------------------------------------------------------------------------------------------------------|
  |isEnvReadyReq|json|M|判断是否支持华为IAP支付的请求信息，请参见[isEnvReadyReq参数](#ZH-CN_TOPIC_0000002399676809__zh-cn_topic_0000001453629405_li1065918356265)。|
  |success|function|O|接口调用成功的回调函数，请参见[success回调函数参数](#ZH-CN_TOPIC_0000002399676809__zh-cn_topic_0000001453629405_li19101540201517)。|
  |fail|function|O|接口调用失败的回调函数，请参见[fail回调函数参数](#ZH-CN_TOPIC_0000002399676809__zh-cn_topic_0000001453629405_li350312533151)。|

  * isEnvReadyReq参数

    |参数|类型|必填(M)/可填(O)|说明|
    |:------------|:-----|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
    |applicationID|string|M|创建快游戏后分配的游戏唯一标识，详情请参见[获取APP ID](https://developer.huawei.com/consumer/cn/doc/games-guides/games-quickgame-enable-account-kit-0000002317894820#section1148753814717)。|

  * success回调函数参数

    |参数|类型|说明|
    |:---------|:-----|:---------------------------|
    |returnCode|number|返回码。若当前用户的华为账号支持IAP支付，则返回值0。|

  * fail回调函数参数

    |参数|类型|说明|
    |:---|:-----|:----------------------------|
    |data|string|错误码描述信息。|
    |code|number|[错误码](#section9900183691610)。|

* 示例代码

  ```screen
  qg.isEnvReady({
    isEnvReadyReq: {
       // 替换为真实有效的APP ID 
      "applicationID": "101***751"
    },
    success: function (data) {
      console.log("isEnvReady data =", JSON.stringify(data));
    },
    fail: function (data, code) {
      console.log("isEnvReady fail data =" + data, "code =" + code);
    }
  })
  ```

### qg.isSandboxActivated(Object object)（1103+）

* 描述 通过该接口可以判断当前设备登录的华为账号及快游戏的RPK版本是否满足沙盒条件。

* 参数

  |参数|类型|必填(M)/可填(O)|说明|
  |:--------------------|:-------|:----------|:---------------------------------------------------------------------------------------------------------------------------|
  |isSandboxActivatedReq|json|M|判断是否满足沙盒账号条件的请求信息，详情请参见[isSandboxActivatedReq参数](#ZH-CN_TOPIC_0000002399676809__zh-cn_topic_0000001453629405_li44836479287)。|
  |success|function|O|接口调用成功的回调函数，请参见[success回调函数参数](#ZH-CN_TOPIC_0000002399676809__zh-cn_topic_0000001453629405_li63592918193)。|
  |fail|function|O|接口调用失败的回调函数，请参见[fail回调函数参数](#ZH-CN_TOPIC_0000002399676809__zh-cn_topic_0000001453629405_li14155182331911)。|

  * isSandboxActivatedReq参数

    |参数|类型|必填(M)/可填(O)|说明|
    |:------------|:-----|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
    |applicationID|string|M|创建快游戏后分配的游戏唯一标识，详情请参见[获取APP ID](https://developer.huawei.com/consumer/cn/doc/games-guides/games-quickgame-enable-account-kit-0000002317894820#section1148753814717)。|

  * success回调函数参数

    |参数|类型|说明|
    |:--------------|:------|:-------------------------------------------------|
    |returnCode|number|返回码。|
    |errMsg|string|返回码描述信息。|
    |isSandboxUser|boolean|是否是沙盒账号。|
    |isSandboxApk|boolean|快游戏相关客户端的APK版本，例如"快应用中心"、"花瓣轻游"等是否满足沙盒条件，固定返回true。|
    |versionInApk|string|快游戏相关客户端的版本信息。|
    |versionFrMarket|string|快游戏在华为应用市场最新的版本信息。|

  * fail回调函数参数

    |参数|类型|说明|
    |:---|:-----|:----------------------------|
    |data|string|错误码描述信息。|
    |code|number|[错误码](#section9900183691610)。|

* 示例代码

  ```screen
  qg.isSandboxActivated({
    isSandboxActivatedReq: {
       // 替换为真实有效的APP ID 
      "applicationID": "101***751",
    },
    success: function (data) {
      console.log("isSandboxActivated data =", JSON.stringify(data));
    },
    fail: function (data, code) {
      console.log("isSandboxActivated fail data =" + JSON.stringify(data), "code =" + code);
    }
  })
  ```

### qg.obtainOwnedPurchases(Object object)（1103+）

* 描述 查询用户已购买的商品数据，且一次请求只能查询一种类型的商品。

  |待查询的商品类型|返回结果|
  |:-------|:-----------------------------------------------------------------------------------------------------------|
  |消耗型商品|用户已购未消耗的商品信息，此时需要： 1. 判断是否发货。若未发货，请先补发商品。 2. 确认发货后，调用[qg.consumeOwnedPurchase](#section2946161093810)进行消耗处理。|
  |非消耗型商品|用户所有已购买的商品数据。|

* 参数

  |参数|类型|必填(M)/可填(O)|说明|
  |:----------------|:-------|:----------|:---------------------------------------------------------------------------------------------------------------------|
  |ownedPurchasesReq|json|M|查询用户已购未消耗的购买数据，请参见[ownedPurchasesReq参数](#ZH-CN_TOPIC_0000002399676809__zh-cn_topic_0000001453629405_li66221938153010)。|
  |success|function|O|接口调用成功的回调函数，请参见[success回调函数参数](#ZH-CN_TOPIC_0000002399676809__zh-cn_topic_0000001453629405_li117897405235)。|
  |fail|function|O|接口调用失败的回调函数，请参见[fail回调函数参数](#ZH-CN_TOPIC_0000002399676809__zh-cn_topic_0000001453629405_li89241951132312)。|

  * ownedPurchasesReq参数

    |参数|类型|必填(M)/可填(O)|说明|
    |:----------------|:-----|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
    |applicationID|string|M|创建快游戏后分配的游戏唯一标识，详情请参见[获取APP ID](https://developer.huawei.com/consumer/cn/doc/games-guides/games-quickgame-enable-account-kit-0000002317894820#section1148753814717)。|
    |priceType|number|M|商品类型： * 0：消耗型商品。 * 1：非消耗型商品。|
    |publicKey|string|M|开通应用内支付服务时的公钥，详情请参见[获取支付公钥](https://developer.huawei.com/consumer/cn/doc/games-guides/games-quickgame-enable-account-kit-0000002317894820#section8652102314545)。|
    |continuationToken|string|O|数据定位标志。首次请求时无需传入。|

  * success回调函数参数

    |参数|类型|说明|
    |:--------------------|:-----|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
    |returnCode|number|返回码。|
    |errMsg|string|返回码描述信息。|
    |itemList|array|商品ID列表。|
    |inAppPurchaseDataList|array|商品信息列表，每条商品的详细信息请参见[inAppPurchaseData参数](#ZH-CN_TOPIC_0000002399676809__zh-cn_topic_0000001453629405_li65641227103610)。 > 注意 > 请务必设置manifest中最小平台版本号minPlatformVersion大于等于1103，当设置的平台版本号大于等于1078时，数组中返回的数据为json字符串。如果设置的平台版本号低于1078，则数组中返回的数据为对象Object类型。|
    |inAppSignature|array|与"inAppPurchaseDataList"中每条商品信息一一对应的签名字符串： * 使用IAP私钥签名算法为"SHA256WITHRSA"。 * 应用需对每条商品信息进行验签，若验签失败需重新获取商品信息，验签方法请参见[对结果验签](https://developer.huawei.com/consumer/cn/doc/games-guides/games-quickgame-runtime-iap-consumable-0000002317894836#section9450525193515)。|
    |continuationToken|string|数据定位标志。用户拥有非常大的商品数量时，若返回continuationToken时，应用必须继续调用当前方法，并传入当前continuationToken值，直到调用后不再返回continuationToken。|

  * fail回调函数参数

    |参数|类型|说明|
    |:---|:-----|:----------------------------|
    |data|string|错误码描述信息。|
    |code|number|[错误码](#section9900183691610)。|

* 示例代码

  ```screen
  qg.obtainOwnedPurchases({
    ownedPurchasesReq: {
      "priceType": 0,
       // 替换为真实有效的APP ID
      "applicationID": "101***751",
        // 替换为真实有效的支付公钥
      "publicKey": "MIIBojANBgkqhkiG9w0BAQ**********************GidLcEeKlAgMBAAE"
    },
    success: function (data) {
      console.log("obtainOwnedPurchases data =", JSON.stringify(data));
    },
    fail: function (data, code) {
      console.log("obtainOwnedPurchases fail data =" + data, "code =" + code);
    }
  })
  ```

### qg.obtainProductInfo(Object object)（1103+）

* 描述 查询在AGC控制台配置的商品详情。若您使用了华为PMS系统进行商品定价，可通过此接口从华为PMS获取商品详情，以保证和华为支付收银台显示的商品信息一致，避免出现应用内商品价格与华为支付收银台价格不一致的现象。

* 参数

  |参数|类型|必填(M)/可填(O)|说明|
  |:-------------|:-------|:----------|:--------------------------------------------------------------------------------------------------------------|
  |productInfoReq|json|M|获取商品信息的请求信息，请参见[productInfoReq参数](#ZH-CN_TOPIC_0000002399676809__zh-cn_topic_0000001453629405_li4618132115336)。|
  |success|function|O|接口调用成功的回调函数，请参见[success回调函数参数](#ZH-CN_TOPIC_0000002399676809__zh-cn_topic_0000001453629405_li1094063882414)。|
  |fail|function|O|接口调用失败的回调函数，请参见[fail回调函数参数](#ZH-CN_TOPIC_0000002399676809__zh-cn_topic_0000001453629405_li99338892514)。|

  * productInfoReq参数

    |参数|类型|必填(M)/可填(O)|说明|
    |:------------|:-----|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
    |applicationID|string|M|创建快游戏后分配的唯一标识，详情请参见[获取APP ID](https://developer.huawei.com/consumer/cn/doc/games-guides/games-quickgame-enable-account-kit-0000002317894820#section1148753814717)。|
    |priceType|number|M|商品类型： * 0 : 消耗型商品。 * 1 : 非消耗型商品。|
    |productIds|array|M|商品ID列表。|

  * success回调函数参数

    |参数|类型|说明|
    |:--------------|:-----|:-----------------------------------------------------------------------------------------------------|
    |returnCode|number|返回码。|
    |errMsg|string|返回码描述信息。|
    |productInfoList|array|商品详细信息，请参见[productInfo参数](#ZH-CN_TOPIC_0000002399676809__zh-cn_topic_0000001453629405_li587610265335)。|

    * productInfo参数

      |参数|类型|说明|
      |:-----------------|:-----|:---------------------------------------------------------------------------------------------------------|
      |productId|string|商品ID。|
      |priceType|number|商品类型： * 0 : 消耗型商品。 * 1 : 非消耗型商品。|
      |price|string|商品展示价格（含税）。格式为"币种 商品价格"，例如"EUR 0.15"；部分国家/地区格式为"货币符号 商品价格"，例如中国大陆"￥0.15"。 > 说明 > 若用户已为商品设置促销价格，则返回商品的促销价格。|
      |microsPrice|number|商品微单位价格。商品实际价格乘以1,000,000后的微单位价格，例如实际价格是1.99美元，则对应的微单位价格为：1.99*1000000=1990000。|
      |currency|string|支付商品的币种。|
      |productName|string|商品名称。|
      |productDesc|string|商品简介。|
      |originalMicroPrice|string|商品原价的微单位价格。商品原价乘以1,000,000后的微单位价格，例如原价是1.99美元，则对应的微单位价格为：1.99*1000000=1990000。|
      |originalLocalPrice|string|商品原价（含税）。格式为"币种 商品价格"，例如"EUR 0.15"；部分国家/地区格式为"货币符号 商品价格"，例如中国大陆"￥0.15"。|

  * fail回调函数参数

    |参数|类型|说明|
    |:---|:-----|:----------------------------|
    |data|string|错误码描述信息。|
    |code|number|[错误码](#section9900183691610)。|

* 示例代码

  ```screen

    productInfoReq: {
      "priceType": 1,
      "productIds": ["dy1","dmy00","lcole"],
       // 替换为真实有效的APP ID
      "applicationID": "101***751",
    },
    success: function (data) {
      console.log("obtainProductInfo =" + JSON.stringify(data));
      
    },
    fail: function (data, code) {
  ```

### qg.createPurchaseIntent(Object object)（1103+）

* 描述 您在AGC控制台创建商品后，使用此接口调用华为支付收银台，显示商品、价格和支付方式。华为会根据国际汇率变动进行商品价格档调整，为了保证应用内商品价格显示一致，请您同时使用[obtainProductInfo](#section125017344614)接口获取商品详情，避免从自有服务端获取价格，以免在汇率变动价格调整时，导致价格显示不一致。

* 参数

  |参数|类型|必填(M)/可填(O)|说明|
  |:----------------|:-------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------|
  |purchaseIntentReq|json|M|在AppGallery Connect上发起购买商品的请求信息，请参见[purchaseIntentReq参数](#ZH-CN_TOPIC_0000002399676809__zh-cn_topic_0000001453629405_li1454112163618)。|
  |success|function|O|接口调用成功的回调函数，请参见[success回调函数参数](#ZH-CN_TOPIC_0000002399676809__zh-cn_topic_0000001453629405_li1135410142614)。|
  |fail|function|O|接口调用失败的回调函数，请参见[fail回调函数参数](#ZH-CN_TOPIC_0000002399676809__zh-cn_topic_0000001453629405_li6528132815)。|

  * purchaseIntentReq参数

    |参数|类型|必填(M)/可填(O)|说明|
    |:---------------|:-----|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
    |applicationID|string|M|创建快游戏后分配的唯一标识，详情请参见[获取APP ID](https://developer.huawei.com/consumer/cn/doc/games-guides/games-quickgame-enable-account-kit-0000002317894820#section1148753814717)。|
    |publicKey|string|M|开通应用内支付服务时的公钥，详情请参见[获取支付公钥](https://developer.huawei.com/consumer/cn/doc/games-guides/games-quickgame-enable-account-kit-0000002317894820#section8652102314545)。|
    |productId|string|M|待支付商品ID。|
    |priceType|number|M|商品类型： * 0 : 消耗型商品。 * 1 : 非消耗型商品。|
    |developerPayload|string|O|商户侧保留信息，长度限制为[0, 256]。若传入值，在成功支付后的回调结果中原样返回给应用。|

  * success回调函数参数

    |参数|类型|说明|
    |:-----------------|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
    |returnCode|number|返回码。|
    |errMsg|string|返回码描述信息。|
    |inAppDataSignature|string|使用私钥签名购买的签名字符串，签名算法为"SHA256WITHRSA"。支付成功后，需使用支付公钥对购买信息进行验签，验签方法请参见[对结果验签](https://developer.huawei.com/consumer/cn/doc/games-guides/games-quickgame-runtime-iap-consumable-0000002317894836#section9450525193515)。|
    |inAppPurchaseData|string|购买订单详情信息，详情请参见[inAppPurchaseData参数](#ZH-CN_TOPIC_0000002399676809__zh-cn_topic_0000001453629405_li65641227103610)。|

    * inAppPurchaseData参数

      |参数|类型|说明|
      |:-----------------|:------|:-------------------------------------------------------------------------------------------------------------------------------------------------|
      |applicationId|number|应用ID。|
      |autoRenewing|boolean|是否自动续订。固定返回false。|
      |orderId|string|华为支付的订单ID，在成功支付后生成。|
      |kind|number|商品类型： * 0 : 消耗型商品。 * 1 : 非消耗型商品。|
      |packageName|string|客户端应用包名。|
      |productId|string|商品ID。|
      |productName|string|商品名称。|
      |purchaseTime|number|商品购买的时间戳。从1970年1月1日0时起到商品购买时间的毫秒数。|
      |purchaseState|number|订单交易状态： * -1：初始化。 * 0：已购买。 * 1：已取消。 * 2：已退款。|
      |developerPayload|string|商户侧保留信息，调用接口时传入。|
      |developerChallenge|string|应用请求消耗商品时自定义的挑战字，唯一标识本次消耗请求。消耗成功后此挑战字会记录在购买信息中并返回。如果挑战字与已有挑战字重复，表示重复消耗，同样会原样返回该挑战字。|
      |consumptionState|number|消费状态： * 0：未消费。 * 1：已消费。|
      |purchaseToken|string|标识商品和用户对应关系的购买令牌，长度92位，完成支付后由华为支付服务器生成，若您需要存储此信息，建议预留128位的长度。|
      |purchaseType|number|购买类型： * 0：沙盒环境。 * 1：促销（暂不支持）。 > 说明 > 正常购买不返回此参数。|
      |currency|string|支付商品的币种。中国大陆传值为CNY，其他国家/地区请参见[华为IAP范围覆盖](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/huawei-iap-coverage-0000001050438753)。|
      |price|number|商品展示价格。|
      |country|string|国家/地区码。中国大陆为CN，其他国家/地区请参见[华为IAP范围覆盖](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/huawei-iap-coverage-0000001050438753)。|
      |payType|string|支付方式： * 0：花币。 * 3：信用卡。 * 4：支付宝。 * 6：话费。 * 13：PayPal。 * 16：借记卡。 * 17：微信。 * 19：礼品卡。 * 20：零钱。 * 21：花币卡。 * 24：WP。 * 31：华为Pay。 * 32：花呗。 * 200：MPESA。 说明|

  * fail回调函数参数

    |参数|类型|说明|
    |:---|:-----|:----------------------------|
    |data|string|错误码描述信息。|
    |code|number|[错误码](#section9900183691610)。|

* 示例代码

  ```screen
  qg.createPurchaseIntent({
    purchaseIntentReq: {
       // 替换为真实有效的APP ID
      "applicationID": "101***751",
      "productId": "dmy001",
      "priceType": 0,
      "developerPayload": "testPurchase",
  ```

### qg.consumeOwnedPurchase(Object object)（1103+）

* 描述 在商品支付成功后，应用需要在发放商品成功之后调用此接口对消耗型商品执行消耗操作。您需把已发货的购买Token传至您的服务器，后续即使消耗失败也可以从您的服务器拉取数据进行对比，避免出现异常。

  > 说明
  > * 建议您在发货前检查您的应用服务器，以确保每个购买Token都未使用过，即未发过货。
  > * 请务必在发货成功后再执行消耗操作，若您在消耗之后再进行发货，可能存在很难处理的异常场景。
