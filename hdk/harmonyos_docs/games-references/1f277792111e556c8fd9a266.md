# LocalServerMethodRoute

|Interface Info|
|:---------------------------------------------------------|
|export interface LocalServerMethodRoute 联机对战实时服务器本地调试路由接口。|

#### Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------|
|Promise\<[AuthResponse](https://developer.huawei.com/consumer/cn/doc/games-references/gameobe-authresponse-server-ts-0000002395196221)\>|[init](#section98321185316)(appId: string, clientId: string, clientSecret: string) SDK初始化。|
|Promise\<[AvailableRoomsResponse](https://developer.huawei.com/consumer/cn/doc/games-references/gameobe-availableroomsresponse-server-ts-0000002361676168)\>|[getRoomList](#section1359195983413)(roomType: string) 获取房间列表。|

#### Methods

#### init

|Method|
|:---------------------------------------------------------------|
|init(appId: string, clientId: string, clientSecret: string) 初始化。|

Parameters  

|Name|Description|
|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
|appId|必填，应用ID。 说明： 您可登录[AGC控制台](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，进入"我的项目\>项目设置\>常规\>应用" 获取"APP ID"信息。|
|clientId|必填，客户端ID。 说明： 您可登录[AGC控制台](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，进入"我的项目\>项目设置\>常规\>项目" 获取客户端ID中的"Client ID"信息。|
|clientSecret|必填，客户端密钥。 说明： 您可登录[AGC控制台](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，进入"我的项目\>项目设置\>常规\>项目" 获取客户端ID中的"Client Secret"信息。|

Sample Code

```
GOBERTS.localServerMethodRoute.init(globalAppId, globalClientId, globalClientSecret).then(response => {
    console.log(`Server running at http://${listenIp}:${listenPort}/`);
});
```

#### joinRoom

|Method|
|:-------------------------------------------------|
|joinRoom(roomCode?: string, roomId?: string) 加入房间。|

Parameters  

|Name|Description|
|:-------|:----------|
|roomCode|选填，房间6位短码。|
|roomId|选填，房间ID。|

Sample Code

```
GOBERTS.localServerMethodRoute.joinRoom(queryObj.roomCode, queryObj.roomId).then(response => {
    if (response.rtnCode == 0) {
       // 加入房间成功
    } else {
       // 加入房间失败
    }
});
```
