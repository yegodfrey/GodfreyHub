# 帧率

> 说明
>
> 从1078版本开始，接口前缀由hbs修改为qg，原hbs仍支持。

## 接口定义

|接口|描述|
|:-------------------------------------------------------------------|:----------------------------------------|
|[qg.setPreferredFramesPerSecond(number fps)](#section15639134185411)|修改渲染帧率。|
|[requestAnimationFrame(function callback)](#section165221848135413)|请求动画帧。|
|[cancelAnimationFrame(number id)](#section383311825618)|取消一个通过 'requestAnimationFrame' 方法注册的回调请求。|

### qg.setPreferredFramesPerSecond(number fps)

* 描述 修改渲染帧率。默认渲染帧率为 60 帧每秒。修改后，requestAnimationFrame 的回调频率会发生改变。


* 参数

  |参数|类型|必填(M)/选填(O)|说明|
  |:--|:-----|:----------|:--------|
  |fps|number|M|有效值范围1~0。|

### requestAnimationFrame(function callback)

* 描述 请求动画帧，详情见H5标准。


* 参数

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:--------------|
  |callback|function|M|下次绘制前执行设置的回调函数。|

* 返回参数 请求ID编号。

* 示例代码

  ```screen
  var id = requestAnimationFrame(
          function() {console.log("requestAnimationFrame");}
  });
  ```

### cancelAnimationFrame(number id)

* 描述 取消一个通过 'requestAnimationFrame' 方法注册的回调请求。

* 参数

  |参数|类型|必填(M)/选填(O)|说明|
  |:-|:-----|:----------|:-----------------------------------|
  |id|number|M|通过requestAnimationFrame方法注册回调时返回的id。|

* 示例代码

  ```screen
  cancelAnimationFrame(666)
  ```
