# 打开第三方应用（1078+）

#### 接口定义

|接口|描述|
|:---------------------------------------------------------------------------------------|:-------|
|[qg.launchNativeApp(Object object)](#ZH-CN_TOPIC_0000002399796753__section1744063281918)|打开第三方应用。|

#### qg.launchNativeApp(Object object)

* 描述 打开第三方应用。

<!-- -->

* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:----------|:-------|:----------|:------------|
  |packageName|String|M|第三方应用包名。|
  |success|function|O|接口调用成功的回调函数。|
  |fail|function|O|接口调用失败的回调函数。|
  |complete|function|O|接口调用完成后的回调函数。|

<!-- -->

* 示例代码

  ```
  qg.launchNativeApp({
     packageName: "com.example.test",
     success: function (data) {
           //成功
     },
     fail: function (data, code) {
           //失败
     },
     complete:function(){
           // 完成
     }
  });
  ```
