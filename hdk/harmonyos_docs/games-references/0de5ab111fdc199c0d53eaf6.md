# UpdateTick

|Class/Struct Info|
|:----------------------------------------------|
|public readonly struct UpdateTick 记录时间和时间差的结构体。|

#### Constructor Summary

|Constructor Name And Description|
|:-------------------------------------------------------------------------|
|[UpdateTick](#section6236112513117)(float deltaTime, float time) 创建更新时间信息。|

#### Property Summary

|Name|Type|Description|
|:--------|:----|:--------------------|
|DeltaTime|float|系统集合距离上次更新的时间差。 单位：秒。|
|Time|float|当前帧开始的时间。 单位：秒。|

Sample Code

```
// 定义一个PgdSystem
public class MoveSystem : PgdSystem<PgdPosition, Speed>
{
    protected override void OnUpdate()
    {
        GetQuery((ref PgdPosition pos, ref Speed speed, IEntity entity) => 
        {
            // 系统有UpdateTick成员，值为每次World更新时的输入
            pos.x += speed.x * Tick.DeltaTime;
            pos.z = Tick.Time;
        })
    }
}
```
