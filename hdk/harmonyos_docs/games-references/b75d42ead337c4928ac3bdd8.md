# 应用管理（1080+）

#### 接口定义

|接口|描述|
|:----------------------------------------------------------------|:-----------------------------------------------|
|[qg.hasPackageInstalled(Object object)](#section128131420123816)|检测应用是否已安装。支持检测鸿蒙应用和快游戏是否已安装。快游戏只有在桌面有图标，才被视为已安装。|
|[qg.getInstalledPackageInfo(Object object)](#section775812247308)|获取应用版本号、版本名称信息。|
|[qg.getSignatureDigests(Object object)](#section210272563012)|获取应用签名摘要信息。|

#### qg.hasPackageInstalled(Object object)（1080+）

* 描述 检测应用是否已安装。支持检测鸿蒙应用和快游戏是否已安装。快游戏只有在桌面有图标，才被视为已安装。

* 参数object  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:------------------------------------------------------------------------------------------------------------|
  |package|string|M|应用包名。|
  |success|function|O|接口调用成功的回调函数，请参见[success回调函数参数](#ZH-CN_TOPIC_0000002399796665__zh-cn_topic_0000001240309019_li44031152193916)。|
  |fail|function|O|接口调用失败的回调函数。|
  |complete|function|O|若有函数传入，将在成功、失败后调用该函数。|

  * success回调函数参数  

    |参数名|类型|说明|
    |:-----|:------|:--------------------------------|
    |result|boolean|应用是否已安装： * true：已安装。 * false：未安装。|

* 示例代码

  ```
  qg.hasPackageInstalled({
      package: "com.***.appmarket",
      success(res) {
          console.log("安装成功", JSON.stringify(res))
      } ,
      fail (res,code) {
          console.log("安装失败",res,code)
      },
      complete() {
          console.log("安装完成");
      }
  });
  ```

#### qg.getInstalledPackageInfo(Object object)（1080+）

* 描述 获取应用版本号、版本名称信息，包括鸿蒙应用和快游戏。

* 参数object  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:------------------------------------------------------------------------------------------------------------|
  |package|string|M|应用包名。|
  |success|function|O|接口调用成功的回调函数，请参见[success回调函数参数](#ZH-CN_TOPIC_0000002399796665__zh-cn_topic_0000001240309019_li19566122474017)。|
  |fail|function|O|接口调用失败的回调函数。|
  |complete|function|O|若有函数传入，将在成功、失败后调用该函数。|

  * success回调函数参数  

    |参数名|类型|说明|
    |:----------|:---------------|:-------------------------------------------------------------------|
    |versionCode|number \| string|查询包名的版本号。若是快游戏： * 小于1080版本时，返回的是string类型。 * 1080及以上版本时，返回的是number类型。|
    |versionName|string|查询包名的版本名称。|

* 示例代码

  ```
  qg.getInstalledPackageInfo({
      package: "com.huawei.appmarket",
      success: function (data) {
          console.log('getInstalledPackageInfo success . msg ' + JSON.stringify(data));
      },
      fail: function (data, code) {
          console.log('getInstalledPackageInfo fail . code ' + code + '; data = ' + data);
      },
      complete: function () {
          console.log('getInstalledPackageInfo complete .');
      },
  });
  ```

#### qg.getSignatureDigests(Object object)（1080+）

* 描述 获取应用签名摘要信息，包括鸿蒙应用和快游戏。

* 参数object  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:---------------------------------------------------------------------------------------------------------|
  |package|string|M|应用包名。|
  |success|function|O|接口调用成功的回调函数，请参见[success回调函数参数](#ZH-CN_TOPIC_0000002399796665__zh-cn_topic_0000001240309019_li16756199415)。|
  |fail|function|O|接口调用失败的回调函数，请参见[fail返回错误码](#ZH-CN_TOPIC_0000002399796665__zh-cn_topic_0000001240309019_li1366701418458)。|
  |complete|function|O|若有函数传入，将在成功、失败后调用该函数。|

  * success回调函数参数  

    |参数名|类型|说明|
    |:---------------|:--------------|:-------------------------------------------------------------|
    |signatureDigests|array \| string|使用SHA-256算法处理后的签名信息列表： * 若是鸿蒙应用，返回array类型。 * 若是快游戏，返回string类型。|

  * fail返回错误码  

    |错误码|说明|
    |:---|:-----|
    |202|参数错误。|
    |1000|找不到应用。|

* 示例代码

  ```
  qg.getSignatureDigests({
      package: "com.huawei.appmarket",
      success: function (data) {
          console.log('getSignatureDigests success . msg ' + JSON.stringify(data));
      },
      fail: function (data, code) {
          console.log('getSignatureDigests fail . code ' + code + '; data = ' + data);
      },
      complete: function () {
          console.log('getSignatureDigests complete .');
      },
  });
  ```
