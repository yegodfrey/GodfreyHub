# 设置

> 说明
>
> 从1078版本开始，接口前缀由hbs修改为qg，原hbs仍支持。

## 接口定义

|接口|描述|
|:------------------------------------------------------|:--------------------------------------|
|[qg.getSetting(Object object)](#section111516252313)|获取用户的当前设置，返回值中只会出现已经请求过的权限。|
|[qg.openSetting(Object object)](#section13326101013250)|调起快游戏设置界面，返回用户设置的操作结果，设置界面只会出现已经请求过的权限。|

### qg.getSetting(Object object)

* 描述 获取用户的当前设置，返回值中只会出现已经请求过的权限。


* 参数

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:--------------------|
  |success|function|O|接口调用成功的回调函数。|
  |fail|function|O|接口调用失败的回调函数。|
  |complete|function|O|若有函数传入，将在成功、失败后调用该函数。|

  * success回调函数参数

    |参数|类型|说明|
    |:----------|:-----|:----------------------------------------------------------------------------------------------------------------------|
    |authSetting|object|用户授权结果，返回用户已开启的多项权限，详情请参见[authSetting参数说明](#ZH-CN_TOPIC_0000002365996992__zh-cn_topic_0000001084194214_li1071611172814)|

    * authSetting参数说明 返回用户已开启的多项权限。例如：

      |参数|类型|说明|
      |:-----|:------|:----------------------------------|
      |camera|boolean|是否已开启相机权限： * true：已开启。 * false：未开启。|


* 示例代码

  ```screen
  qg.getSetting({
          success : function (res) {
                  console.log("getSetting success authSetting = " + res.authSetting);
          },
          fail:function(){
                  console.log("getSetting fail");
          },
          complete:function() {
                  console.log("getSetting complete");
          }
  });
  ```

### qg.openSetting(Object object)

* 描述 调起快游戏设置界面，返回用户设置的操作结果，设置界面只会出现已经请求过的权限。


* 参数

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:--------------------|
  |success|function|O|接口调用成功的回调函数。|
  |fail|function|O|接口调用失败的回调函数。|
  |complete|function|O|若有函数传入，将在成功、失败后调用该函数。|


* success回调函数参数

  |参数|类型|说明|
  |:----------|:-----|:----------------------------------------------------------------------------------------------------------------------|
  |authSetting|object|用户授权结果，返回用户已开启的多项权限，详情请参见[authSetting参数说明](#ZH-CN_TOPIC_0000002365996992__zh-cn_topic_0000001084194214_li167931881913)。|

  * authSetting参数说明 返回用户已开启的多项权限。例如：

    |参数|类型|说明|
    |:-----|:------|:----------------------------------|
    |camera|boolean|是否已开启相机权限： * true：已开启。 * false：未开启。|


* 示例代码

  ```screen
  qg.openSetting({
          success : function (res) {
                  console.log("openSetting success authSetting = " + res.authSetting);
          },
          fail:function(){
                  console.log("openSetting fail");
          },
          complete:function() {
                  console.log("openSetting complete");
          }
  });
  ```
