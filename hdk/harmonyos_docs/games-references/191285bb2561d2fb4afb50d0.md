# CommandQueue

|Class/Struct Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public sealed class CommandQueue : ICommandQueue 指令队列，系统核心扩展功能，主要用于记录查询循环过程中的结构性变更操作（即组件、标签、实体、子实体的增删操作），并在固定节点统一延后处理，防止循环中的结构性变更导致异常。 若在系统执行查询循环过程中需要进行结构性变更操作，均要通过CommandQueue执行。|

## Property Summary

|Name|Type|Description|
|:--------------------|:---------------------|:----------|
|EnableReuse|bool|指令队列重用标志。|
|TSCommandQueue|ThreadSafeCommandQueue|线程安全指令队列接口。|
|EntityCommandCount|int|实体指令数。|
|TagCommandCount|int|标签指令数。|
|ComponentCommandCount|int|组件指令数。|
|ChildCommandCount|int|子实体指令数。|
|TotalCommandCount|int|总指令数。|

**Sample Code**

```screen
var world = new IECSWorld();
// 获取CommandQueue，EnableReuse默认为false，即CommandQueue调用Apply()后会被回收，不能继续使用
var commandQueue = world.GetCommandQueue();
// 允许重用，Apply()后还能再次添加指令，再次Apply()
commandQueue.EnableReuse = true;
// 并行任务等多线程操作中，建议使用TSCommandQueue添加指令和应用指令
var query = world.Query<PgdPosition>();
query.ParallelForEach((ref PgdPosition pos, IEntity entity) =>
{
    commandQueue.TSCommandQueue.AddComponent<PgdRotation>(entity.Id);
});
commandQueue.TSCommandQueue.Apply();
```

### ToString

|Method|
|:-----------------------------|
|string ToString() 返回指令队列信息字符串。|

**Return**

|Type|Description|
|:-----|:----------|
|string|指令队列信息。|

**Sample Code**

commandQueue.AddComponent<PgdPosition>(1);

### Apply

|Method|
|:---------------------|
|void Apply() 处理队列中的指令。|

**Sample Code**

```screen
var world = new IECSWorld();
var entity = world.CreateEntity(1);
var commandQueue = world.GetCommandQueue();
commandQueue.AddComponent<PgdPosition>(1); // 此时实体还没有添加PgdPosition
// 应用指令
commandQueue.Apply(); // 此时实体拥有了PgdPosition
```
