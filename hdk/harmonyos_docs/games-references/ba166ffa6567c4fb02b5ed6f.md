# Share Kit（分享服务）

碰一碰支持用户通过碰一碰发起跨端分享，可实现传输图片、共享Wi-Fi等。碰一碰的ArkTS API请参见[ArkTS API](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/share-arkts)。
