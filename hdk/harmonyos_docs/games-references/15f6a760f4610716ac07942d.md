# UpdateRoomInfo

|Interface Info|
|:----------------------------------------|
|export interface UpdateRoomInfo 可更新的房间信息。|

#### Property Summary

|Name|Type|Mandatory/Optional|Description|
|:-------------------|:-----|:-----------------|:---------------------------------------------|
|roomName|string|Optional|房间名称，长度不超过64个字符。|
|customRoomProperties|string|Optional|自定义房间属性，最大支持2048个字符。|
|ownerId|string|Optional|房主的玩家ID。|
|isPrivate|number|Optional|房间是否私有。 * 0：公开 * 1：私有|
|isLock|number|Optional|房间是否锁定。 * 0：非锁定 * 1：锁定 说明： 锁定状态的房间允许查询，但不允许加入。|
|roomType|string|Optional|自定义的房间类型。|
