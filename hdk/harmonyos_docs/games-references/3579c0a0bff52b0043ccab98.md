# Archetype

|Class/Struct Info|
|:---------------------------------------------|
|public sealed class Archetype 原型类，PGD中数据存储的容器。|

## Property Summary

|Name|Type|Description|
|:-----------|:----------------|:-------------------|
|Name|string|原型名字。|
|EntityNum|int|原型存储的实体数量。|
|ComponentNum|int|原型存储的组件种类数量。|
|MemCapacity|int|原型容量。|
|EntityIds|ReadOnlySpan<int>|原型存储的实体标识的只读内存。|
|WorldBase|EcsWorldBase|原型所属World。|
|IComponents|IComponents|只读引用属性，表示原型存储的组件种类。|
|ITags|ITags|只读引用属性，表示原型存储的标签种类。|
|SharedTypes|IComponents|只读引用属性，表示原型关联共享组件种类。|

**Sample Code**

```screen
var world = new IECSWorld();
var archetype = world.GetCreateArchetype(IComponents.Get<PgdPosition>(), ITags.Get<Inactive>(), IComponents.GetSharedSet<SharedComponent1>());
archetype.CreateEntities(3);
// Name即Archetype信息
archetype.Name; // "ComponentTypes: [PgdPosition], tags: [Inactive], SharedTypes: [SharedComponent1]"
// 存储的实体数量
archetype.EntityNum; // 3
// 存储的组件种类数量，不包含共享组件
archetype.ComponentNum; // 1
// 存储容量，初始为512，超出后会触发两倍扩容
archetype.MemCapacity; // 512
// 存储的实体Id
var ids = archetype.EntityIds;
// 所属世界
var worldBase = archetype.WorldBase;
// 存储的组件种类集合
archetype.IComponents; // 等于IComponents.Get<PgdPosition>()
// 存储的标签种类集合
archetype.ITags; // 等于ITags.Get<Inactive>()
// 存储的共享组件种类集合
archetype.SharedTypes; // 等于IComponents.GetSharedSet<SharedComponent1>()
```

## Methods

### Components<TComponent>

|Method|
|:--------------------------------------------------------------------------------|
|Span<TComponent> Components<TComponent>() 获取原型中存储的指定泛型组件的所有数据。 TComponent为struct。|

**Return**

|Type|Description|
|:---------------|:-----------------|
|Span<TComponent>|返回指定存储泛型组件数据的内存空间。|

**Sample Code**

```screen
var world = new IECSWorld();
var entity = world.CreateEntity(new PgdPosition());
// 获取指定组件数据
var components = entity.Archetype.Components<PgdPosition>();
components.Length; // 1
components[0].x; // 0
```

### CreateEntity

|Method|
|:-------------------------------|
|IEntity CreateEntity() 在原型中创建实体。|

**Return**

|Type|Description|
|:------|:----------|
|IEntity|返回创建的实体。|

**Sample Code**

```screen
var world = new IECSWorld();
var archetype = world.GetCreateArchetype(IComponents.Get<PgdPosition>());
// 创建实体，自动添加该Archetype中所有组件、标签、共享组件，实体Id自动分配
var entity = archetype.CreateEntity(); // 该entity拥有PgdPosition，组件值为默认值
```

### AllocateMemory

|Method|
|:----------------------------------------------------|
|int AllocateMemory(int capacityNeed) 根据输入的所需容量分配原型容量。|

**Parameters**

|Name|Type|Description|
|:-----------|:---|:----------|
|capacityNeed|int|所需容量。|

**Return**

|Type|Description|
|:---|:-----------------|
|int|返回原型当前剩余容量（实体数容量）。|

**Sample Code**

```screen
var world = new IECSWorld();
var archetype = world.GetCreateArchetype(IComponents.Get<PgdPosition>());
// 根据输入所需容量，重新分配内存，返回重新分配后的剩余容量
var newCapacity = archetype.AllocateMemory(1000);
newCapacity; // 1024
```

### ToString

|Method|
|:---------------------------------------------------|
|string ToString() 将该原型详细信息以字符串形式返回，打印的组件和标签名字均会带命名域。|

**Return**

|Type|Description|
|:-----|:----------|
|string|原型详细信息。|

**Sample Code**

```screen
var world = new IECSWorld();
var archetype = world.GetCreateArchetype(IComponents.Get<PgdPosition>(), ITags.Get<Inactive>(), IComponents.GetSharedSet<SharedComponent1>());
// 打印详细信息。预设组件/标签命名域为"Pgd."，自定义组件/标签/共享组件根据实际情况而定
archetype.ToString(); // "{ComponentTypes: [Pgd.PgdPosition], tags: [Pgd.Inactive], SharedTypes: [SharedComponent1], entityNum: 0}"
```

### DeleteAllEntities

|Method|
|:------------------------------------------|
|void DeleteAllEntities() 将该原型中全部Entity批量删除。|

**Sample Code**

```screen
var world = new IECSWorld();
var archetype = world.GetCreateArchetype(IComponents.Get<PgdPosition>());
archetype.CreateEntities(10);
// 批量删除Archetype中所有实体
archetype.DeleteAllEntities();
archetype.EntityNum; // 0
```
