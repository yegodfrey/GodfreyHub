# Inactive

|Class/Struct Info|
|:----------------------------------------------------|
|public struct Inactive : ITag 预设的标签类型，表示禁用状态，继承了ITag。|

**Sample Code**

```screen
var world = new IECSWorld();
var entity = world.CreateEntity();
// 给实体添加Inactive标签
entity.AddTag<Inactive>();
// 直接修改实体的Active字段，内部会自动添加/移除Inactive标签
entity.Active = false; // 添加Inactive标签
entity.Active = true; // 移除Inactive标签
```
