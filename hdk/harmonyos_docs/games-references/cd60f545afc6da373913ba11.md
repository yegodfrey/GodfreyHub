# RoomInfo

|Interface Info|
|:------------------------------|
|export interface RoomInfo 房间信息。|

#### Property Summary

|Name|Type|Description|
|:-------------------|:----------------------------------------------------------------------------------------------------------------------------|:-----------------------------|
|appId|string|应用ID。|
|roomId|string|房间ID。|
|roomStatus|number|房间状态。 * 0：空闲 * 1：帧同步中 默认为空闲状态。|
|roomType|string|自定义的房间类型。|
|roomCode|string|房间短码。|
|roomName|string|房间名称。|
|customRoomProperties|string|自定义的房间属性。|
|ownerId|string|房主ID。|
|maxPlayers|number|房间最大支持人数，取值范围为\[1, 100\]。|
|players|[PlayerInfo](https://developer.huawei.com/consumer/cn/doc/games-references/gameobe-playerinfo-server-ts-0000002395356113)\[\]|房间内玩家列表。|
|router|[RouterInfo](https://developer.huawei.com/consumer/cn/doc/games-references/gameobe-routerinfo-server-ts-0000002361516280)|路由信息。|
|isPrivate|number|房间是否私有。 * 0：公开 * 1：私有 默认为公开状态。|
|createTime|number|创建时间。|
