# ComponentLookup\<TLookupComponent, TValue\>

|Class/Struct Info|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public readonly struct ComponentLookup\<TLookupComponent, TValue\>where TLookupComponent : struct, ILookup\<TValue\> 索引ILookup\<T\>组件的结构体，在O(1) 时间内搜索具有特定组件值的实体，实例通过LookupExtensions.ComponentLookup\<TLookupComponent,TValue\>方法返回。|

#### Property Summary

|Name|Type|Description|
|:-----|:----------------------------|:-------------|
|Values|IReadOnlyCollection\<TValue\>|所有索引的组件值的只读列表。|

Sample Code

```
var world = new IECSWorld();
// 创建一个ComponentLookup，获取所有指定类型的Lookup组件值的只读列表，会自动更新
var values = world.ComponentLookup<LookupInt, int>().Values;
```

#### Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-----------------------------------------------------------------|
|ReadOnlyEntitySet|[this\[TValue value\]](#section1031617010220) 索引方法，查找所有具有指定组件值的实体。|
|string|[ToString](#section1957444919470)() 将索引到的组件值数量以字符串形式返回。|

#### Methods

#### this\[TValue value\]

|Method|
|:----------------------------------------------------------|
|ReadOnlyEntitySet this\[TValue value\] 索引方法，查找所有具有指定组件值的实体。|

Parameters  

|Name|Type|Description|
|:----|:-----|:----------|
|value|TValue|指定组件值。|

Return  

|Type|Description|
|:----------------|:--------------|
|ReadOnlyEntitySet|所有符合条件的实体的只读列表。|

Sample Code

```
var world = new IECSWorld();
// 创建一个ComponentLookup
var lookup = world.ComponentLookup<LookupInt, int>();
for (int n = 1; n <= 10; n++)
{
    var entity = world.CreateEntity(n);
    entity.AddComponent(new LookupInt { value = n });
}
// 获取所有具有指定组件值的实体
var entitySetRO = lookup[1]; // 该集合包含id为1的实体
```

#### ToString

|Method|
|:------------------------------------|
|string ToString() 将索引到的组件值数量以字符串形式返回。|

Return  

|Type|Description|
|:-----|:----------|
|string|匹配的索引组件数量。|

Sample Code

```
var world = new IECSWorld();
// 创建一个ComponentLookup
var lookup = world.ComponentLookup<LookupInt, int>();
for (int n = 1; n <= 10; n++)
{
    var entity = world.CreateEntity(n);
    entity.AddComponent(new LookupInt { value = n });
}
// 打印匹配的数量
lookup.ToString(); // "Count: 10"
```
