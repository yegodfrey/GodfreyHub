# EntityRelationPair

|Class/Struct Info|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class EntityRelationPair : RelationPair\<int\> 实体与实体关系的关系对，实体ID之间的对应关系。 通常通过[GetBeRelatedLinks\<TR\>](https://developer.huawei.com/consumer/cn/doc/games-references/relation-relationmanager-0000002477907545#section1523520210348)结构获取关系结果集使用。|

#### Constructor Summary

|Constructor Name And Description|
|:------------------------------------------------------------------------------------------------------------------------------------------------------|
|[EntityRelationPair](#section6236112513117)(int entityId, int targetId) 构造类似A --\> B的关系对。 例如：小明拥有苹果。使用关系对表示为： 小明 -has-\> 苹果。|
|[EntityRelationPair](#section142894715257)(int entityId, int targetId, object targetObject) 构造类似A --\> B(V)的关系对。 例如：小明拥有5苹果。使用关系对表示为： 小明 -has-\> 苹果(5)。|

#### Property Summary

|Name|Type|Description|
|:-------------|:-----|:-----------|
|EntityId|int|表示关系对中的A的id。|
|RelationTarget|int|表示关系对中的B的id。|
|TargetObject|object|表示关系中的值V。|

Sample Code

```
var world   = new IECSWorld();
var entity1  = world.CreateEntity(1);
var entity2  = world.CreateEntity(2);
var entity10 = world.CreateEntity(10);
entity1.AddRelation(new AttackRelation{ target = entity10 }, out _);
entity2.AddRelation(new AttackRelation{ target = entity10 }, out _);

List<EntityRelationPair> entity10RelationPairs = entity10.GetBeRelatedLinks<AttackRelation>();
AreEqual("{ ( 1 -> 10 ), ( 2 -> 10 ) }", CollectionToString.ToString(entity10RelationPairs));
```
