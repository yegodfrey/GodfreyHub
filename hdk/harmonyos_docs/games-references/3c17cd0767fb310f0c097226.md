# SendToClientInfo

|Interface Info|
|:-------------------------------------------|
|export interface SendToClientInfo 发送房间内消息参数。|

## Property Summary

|Name|Type|Mandatory/Optional|Description|
|:---------------|:-------|:-----------------|:-------------------------------------------------------------------------------------------------------------------------|
|type|int|Mandatory|消息接收者类型。 * 0：发送给房间内全部玩家 * 1：发送给房间内除本人外的其他所有玩家 * 2：发送给[recvPlayerIdList](#ZH-CN_TOPIC_0000002361675960__p17901042161111)的玩家|
|msg|string|Mandatory|消息内容，最大支持512个字符。|
|recvPlayerIdList|string[]|Optional|接收消息的玩家ID列表。|
