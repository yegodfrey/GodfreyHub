# MatchRoomConfig

|Interface Info|
|:-----------------------------------------|
|export interface MatchRoomConfig 房间匹配参数配置。|

## Property Summary

|Name|Type|Mandatory/Optional|Description|
|:-------------------|:---------------------|:-----------------|:---------------------------------------------|
|matchParams|Record<string, string>|Optional|自定义匹配参数，最多支持5条匹配规则。|
|maxPlayers|number|Mandatory|房间最大支持人数，取值范围为[1, 100]。 > 说明 > 可用于匹配不到房间时创建房间。|
|roomType|string|Optional|房间类型。 > 说明 > 可用于匹配不到房间时创建房间。|
|customRoomProperties|string|Optional|自定义房间属性。 > 说明 > 可用于匹配不到房间时创建房间。|
