# ChildEntitySet

|Class/Struct Info|
|:-------------------------------------------------------------------------------------------|
|public readonly struct ChildEntitySet : IEnumerable<IEntity> 只读结构体。 继承了IEnumerable<IEntity>。|

## Property Summary

|Name|Type|Description|
|:----|:----------------|:----------|
|Count|int|子实体数量。|
|Ids|ReadOnlySpan<int>|子实体标识的只读内存。|

**Sample Code**

```screen
var world = new IECSWorld();
var entity = world.CreateEntity(1);
entity.AddChild(world.CreateEntity(2));
// ChildEntitySet是实体存储其子实体信息的结构体之一
var childSet = entity.Children;
childSet.Count; // 子实体数量，此处为1
childSet.Ids[0]; // 子实体Id数组，此处为2
```
