### Add<T1, ...>

|Method|
|:----------------------------------------------------------------------------------------------------------------------|
|void Add<T1, ...>(this IEntity entity, in T1 comp1, ..., in ITags iTags = default) 批量添加组件和标签，最多支持10个泛型组件。 T为IComponent。|

**Parameters**

|Name|Type|Description|
|:-----|:------|:----------|
|entity|IEntity|作用的实体。|
|comp1|T1|泛型组件，最多10个。|
|iTags|ITags|标签类型集合。|

**Sample Code**

```screen
var world = new IECSWorld();
var entity = world.CreateEntity();
// 添加多个组件和标签，仅进行一次结构性变更，最多支持一次添加10个组件和10个标签
entity.Add(new PgdPosition(), new PgdScale(), new Name("test"), ITags.Get<TestTag, TestTag2>());
```

### AddComponent<TS>

|Method|
|:-------------------------------------------------------------------------------------------------------------|
|static bool AddComponent<TS>(this IEntity entity, in TS sharedComponent = default) 添加共享组件，仅支持一个泛型。 TS为IShared。|

**Parameters**

|Name|Type|Description|
|:--------------|:------|:-----------------|
|entity|IEntity|作用的实体。|
|sharedComponent|TS|共享组件。 默认值为default。|

**Return**

|Type|Description|
|:---|:-----------------------------------------------------------|
|bool|* true：实体添加共享组件成功。 * false：实体已经拥有该共享组件。此时会用当前输入的组件值覆盖原来的组件值。|

**Sample Code**

```screen
var world = new IECSWorld();
var entity = world.CreateEntity();
// 添加共享组件，仅支持添加1个共享组件，不输入组件值则为默认值
entity.AddComponent(new SharedComponent());
// 重复添加相同共享组件，返回false，但是新组件值会覆盖旧组件值
entity.AddComponent(new SharedComponent{Value = 1}); // 此时共享组件值为1
```

|Method|
|:-------------------------------------------------------------------------------|
|static bool RemoveComponent<TS>(this IEntity entity) 移除共享组件，仅支持一个泛型。 TS为IShared。|

|entity|IEntity|作用的实体。|

|:---|:-------------------------------------|

### IsEnabled<T1, ...>

|Method|
|:---------------------------------------------------------------------------------------------------------------------|
|static bool IsEnabled<T1, ...>(this IEntity entity) 判断实体的组件的启用状态，最多支持10个泛型组件，输入复数种组件时，需要全部为启用状态才会返回true。 T为IComponent。|

**Parameters**

|Name|Type|Description|
|:-----|:------|:----------|
|entity|IEntity|作用的实体。|

**Return**

|Type|Description|
|:---|:----------------------------------------------------------------|
|bool|* true：当实体拥有所有指定组件，且这些组件均启用时。 * false：实体未拥有其中任意组件，或实体的任意指定组件未启用时。|

**Sample Code**

```screen
var world = new IECSWorld();
var entity = world.CreateEntity(new PgdPosition());
// 判断组件启用状态
entity.IsEnabled<PgdPosition>(); // true
entity.SetDisable<PgdPosition>();
entity.IsEnabled<PgdPosition>(); // false
```
