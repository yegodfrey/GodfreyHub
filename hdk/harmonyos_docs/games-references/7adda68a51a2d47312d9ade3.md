# LinkComponentLookup<TLinkComponent>

|Class/Struct Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------|
|public readonly struct LinkComponentLookup<TLinkComponent>where TLinkComponent : struct, ILinkComponent 索引ILinkComponent组件的结构体，在O(1) 时间内搜索具有特定实体的实体。|

## Property Summary

|Name|Type|Description|
|:-----|:--------------------------|:-------------|
|Values|IReadOnlyCollection<TValue>|所有索引的组件值的只读列表。|

**Sample Code**

```screen
var world = new IECSWorld();
// 创建一个LinkComponentLookup
var linkLookup = world.LinkComponentLookup<LinkComponent>();
// 获取所有指定类型的链接组件值的只读列表，会自动更新
var values = linkLookup.Values;
```

## Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-----------------------------------------------------------------|
|ReadOnlyEntitySet|[this[TValue value]](#section1031617010220) 索引方法，查找所有具有指定链接组件值的实体。|
|string|[ToString](#section1957444919470)() 将索引到的组件值数量以字符串形式返回。|

## Methods

### this[TValue value]

|Method|
|:----------------------------------------------------------|
|ReadOnlyEntitySet this[TValue value] 索引方法，查找所有具有指定链接组件值的实体。|

**Parameters**

|Name|Type|Description|
|:----|:------|:----------|
|value|IEntity|链接实体。|

**Return**

|Type|Description|
|:----------------|:--------------|
|ReadOnlyEntitySet|所有符合条件的实体的只读列表。|

**Sample Code**

```screen
var world = new IECSWorld();
// 创建一个LinkComponentLookup
var linkLookup = world.LinkComponentLookup<LinkComponent>();
var entity1 = world.CreateEntity(1);
var target2 = world.CreateEntity(2);
entity1.AddComponent(new LinkComponent { entity = target2 });
// 获取所有具有指定目标实体的实体
linkLookup[target2].Count; // 1
```

### ToString

|Method|
|:------------------------------------|
|string ToString() 将索引到的组件值数量以字符串形式返回。|

**Return**

|Type|Description|
|:-----|:----------|
|string|匹配的组件数量。|

**Sample Code**

```screen
var world = new IECSWorld();
// 创建一个LinkComponentLookup

entity1.AddComponent(new LinkComponent { entity = target2 });
// 打印被关联的目标实体的数量

```
