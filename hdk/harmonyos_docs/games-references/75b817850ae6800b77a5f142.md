# 菜单

#### 接口定义

|接口|描述|
|:--------------------------------------------------------------------|:----------------------|
|[qg.getMenuButtonBoundingClientRect()（1127+）](#section14948251203111)|获取菜单按钮（右上角胶囊按钮）的布局位置信息。|

#### qg.getMenuButtonBoundingClientRect()（1127+）

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212154042.44805246002445160970247397843223:50001231000000:2800:25AFE16EC36C0163671602A0E4F50481A8A0BA5C561C9B8E160E95A62B0D03F4.png)  
使用该接口前，请先使用[qg.canIUse('MiniGame.MenuButtonBoundingRect')](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickgame-api-sysinfo-0000001083874626#section165771434195617)判断该接口是否支持使用。

* 描述 获取菜单按钮（右上角胶囊按钮）的布局位置信息。坐标信息以屏幕左上角为原点。

* 返回参数  
  菜单按钮的布局位置信息。  

  |参数|类型|说明|
  |:-----|:-----|:-----------|
  |width|number|宽度，单位：px。|
  |height|number|高度，单位：px。|
  |top|number|上边界坐标，单位：px。|
  |right|number|右边界坐标，单位：px。|
  |bottom|number|下边界坐标，单位：px。|
  |left|number|左边界坐标，单位：px。|

* 示例代码

  ```
  if (typeof qg.canIUse === 'function') {
    qg.canIUse({
        capability: 'MiniGame.MenuButtonBoundingRect',
        success: function (data) {
            console.log("canIUse  MiniGame.MenuButtonBoundingRect =" + JSON.stringify(data));
            if (data) {
                   if (typeof qg.getMenuButtonBoundingClientRect === 'function') {
                    try {
                        const res  = qg.getMenuButtonBoundingClientRect();
                        console.log('menuu button info：', JSON.stringify(res));
                    } catch (e) {
                        console.warn('qg.getMenuButtonBoundingClientRect fail:', e);
                    }
                }
            }
        },
        fail: function (data, code) {
            console.log("canIUse fail data =" + JSON.stringify(data), "code = " + code);
        }
    });
  } else {
    console.log('canIUse method is not available');
  }
  ```
