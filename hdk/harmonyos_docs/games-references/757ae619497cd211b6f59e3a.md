#### FreezeFilter

|Method|
|:------------------------------------------------|
|QueryFilter FreezeFilter() 冻结查询过滤器，冻结后禁止修改查询过滤条件。|

Return  

|Type|Description|
|:----------|:----------|
|QueryFilter|返回冻结的查询过滤器。|

Sample Code

```
// 创建并冻结查询过滤器，冻结后不能再修改过滤条件
var filter = new QueryFilter().FreezeFilter();
```

#### WithAllTags

|Method|
|:-----------------------------------------------------|
|QueryFilter WithAllTags(in ITags iTags) 设置WithAll标签条件。|

Parameters  

|Name|Type|Description|
|:----|:----|:----------|
|iTags|ITags|标签类型集合。|

Return  

|Type|Description|
|:----------|:------------|
|QueryFilter|返回设置条件的查询过滤器。|

Sample Code

```
// 创建查询过滤器，并设置标签过滤条件。过滤条件记录在对应的Condition字段中
var filter = new QueryFilter().WithAllTags(ITags.Get<TestTag1>());
// 通过WithAllTagsCondition可以查看过滤器设置的对应条件
filter.WithAllTagsCondition; // 等于ITags.Get<TestTag1>()
```

#### WithoutAnyTags

|Method|
|:-----------------------------------------------------------|
|QueryFilter WithoutAnyTags(in ITags iTags) 设置WithoutAny标签条件。|

Parameters  

|Name|Type|Description|
|:----|:----|:----------|

Return  

|Type|Description|

Sample Code

```

```

#### WithInactive

|Method|
|:-------------------------------------------|
|QueryFilter WithInactive() 设置查询包含非活跃标签实体的条件。|

Return  

|Type|Description|
|:----------|:------------|
|QueryFilter|返回设置条件的查询过滤器。|

Sample Code

```
// 创建查询过滤器，并设置查询被禁用实体条件。过滤条件记录在对应的Condition字段中
var filter = new QueryFilter().WithInactive();
// 移除WithoutAnyTagsCondition默认添加的Inactive条件
AreEqual(default, filter.WithoutAnyTagsCondition);
```
