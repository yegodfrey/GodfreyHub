# ActionArgs

|Interface Info|
|:--------------------------------|
|export interface ActionArgs 回调参数。|

#### Property Summary

|Name|Type|Description|
|:-------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|sender|string|触发回调接口的玩家ID。|
|gameData|string|客户端发送给实时服务器的游戏数据。|
|roomId|string|房间ID。|
|SDK|object|包含实时服务器SDK提供的一些方法，具体请参见[Methods](#section648724914565)。 ``` SDK: { requestFrame: (beginFrameId: number, size: number) => Promise<void>; sendData: (data: string) => Promise<void>; setCache: (key: string, value: string, expireTime: number) => Promise<void>; setCacheIfNotExist: (key: string, value: string, expireTime: number) => Promise<void>; getCache: (key: string) => Promise<CacheValue>; deleteCache: (key: string) => Promise<void>; getRoomInfo: () => Promise<RoomInfo>; updateRoomProperties: (updateRoomInfo: UpdateRoomInfo) => Promise<void>; removePlayer: (playerId: string) => Promise<void>; dismiss:() => Promise<void>; getAutoFrame: () => boolean; getFrameRate: () => number; log: { info: (message: string) => void; warn: (message: string) => void; error: (message: string) => void; }; }; ```|

#### Methods

#### requestFrame

|Method|
|:----------------------------------------------------------------------|
|requestFrame(beginFrameId: number, size: number): Promise\<void\> 请求补帧。|

Parameters  

|Name|Description|
|:-----------|:----------|
|beginFrameId|起始帧ID。|
|size|请求帧数。|

Sample Code

```
let beginFrameId = xxx;
let requestFrameSize = xxx;
args.SDK.requestFrame(beginFrameId, requestFrameSize).then(() => {
// 请求补帧相关逻辑
}).catch(err => {
});
```

#### setCache

|Method|
|:---------------------------------------------------------------------------------------|
|setCache(key: string, value: string, expireTime: number): Promise\<void\> 用于实时服务器设置缓存信息。|

Parameters  

|Name|Description|
|:---------|:--------------------|
|key|缓存信息键值对中的键。|
|value|缓存信息键值对中的值。|
|expireTime|缓存过期时间，单位：秒，最长可设置为1天。|

Sample Code

```
args.SDK.setCache('roomOwner', 'playerId', 86400).then(()=> {
    // 设置缓存成功
}).catch( err => {
    // 设置缓存失败
});
```

#### setCacheIfNotExist

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|setCacheIfNotExist: (key: string, value: string, expireTime: number) =\> Promise\<void\> 用于实时服务器设置缓存信息。 说明： 只有当所设置的键不存在才会设置缓存信息，否则会抛出异常，返回错误信息"set fail, key is already existed"。|

Parameters  

|Name|Description|
|:---------|:--------------------|
|key|缓存信息键值对中的键。|
|value|缓存信息键值对中的值。|
|expireTime|缓存过期时间，单位：秒，最长可设置为1天。|

Sample Code

```
args.SDK.setCacheIfNotExist('roomOwner', 'playerId', 86400).then(() => {
    args.SDK.log.info('setCacheIfNotExist success');
}).catch(err => {
    args.SDK.log.error('setCacheIfNotExist fail: ' + err);
});
```
