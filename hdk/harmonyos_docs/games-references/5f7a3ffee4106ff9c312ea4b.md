# 创新互动卡片

#### 接口定义

|接口|描述|
|:-----------------------------------------------------------------------|:-------------------------------------------------------------------------|
|[qg.getFormInfo(Object object) （1117+）](#section19206132651319)|获取创新互动卡片的尺寸大小、圆角半径。|
|[qg.onFormInfoUpdate(function callback)（1117+）](#section189891434141913)|在屏幕的分辨率/创新互动卡片的尺寸大小/创新互动卡片的圆角半径发生变化时，桌面小组件必须立刻修改自卡片的尺寸大小、圆角半径，以重新适配创新互动卡片。|
|[qg.addInteractiveCard(Object object)（1127+）](#section43861750112916)|添加创新互动卡片到桌面。|

#### qg.getFormInfo(Object object) （1117+）

* 描述 获取创新互动卡片的尺寸大小、圆角半径。

* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:-------------------------------------------------------------------------------------------------------------|
  |success|function|M|接口调用成功的回调函数，详情请参见[success回调函数参数](#ZH-CN_TOPIC_0000002365997060__zh-cn_topic_0000002045925504_li1927801911464)。|
  |complete|function|O|接口调用完成后的回调函数。|

  * success回调函数参数  

    |参数|类型|说明|
    |:-----|:-----|:---------------------------------------------------------------------------------------------------|
    |rect|object|卡片的尺寸大小，详情请参见[rect参数](#ZH-CN_TOPIC_0000002365997060__zh-cn_topic_0000002045925504_li14329193764915)。|
    |radius|number|卡片的圆角半径，单位：px。|

    * rect参数  

      |参数|类型|说明|
      |:-----|:-----|:----------|
      |width|number|卡片宽度，单位：px。|
      |height|number|卡片高度，单位：px。|

* 示例代码

  ```
  qg.getFormInfo({
      success: function (data) {
          console.log('getFormInfo success' + JSON.stringify(data))
      },
      complete: function () {
          console.log('getFormInfo complete')
      }
  });
  ```

#### qg.onFormInfoUpdate(function callback)（1117+）

* 描述 在屏幕的分辨率/创新互动卡片的尺寸大小/创新互动卡片的圆角半径发生变化时，桌面小组件必须立刻修改自卡片的尺寸大小、圆角半径，以重新适配创新互动卡片。

* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:------------------------------------------------------------------------------------------------------------------------------------|
  |callback|function|M|屏幕的分辨率/创新互动卡片的尺寸大小/创新互动卡片的圆角半径发生变化时的监听函数。详情请参见[回调函数参数](#ZH-CN_TOPIC_0000002365997060__zh-cn_topic_0000002045925504_li14155410112215)。|

  * 回调函数参数  

    |参数|类型|说明|
    |:-----|:-----|:-------------------------------------------------------------------------------------------------|
    |rect|object|卡片的尺寸大小，详情请参见[rect参数](#ZH-CN_TOPIC_0000002365997060__zh-cn_topic_0000002045925504_li751718576220)。|
    |radius|number|卡片的圆角半径，单位：px。|

    * rect参数  

      |参数|类型|说明|
      |:-----|:-----|:----------|
      |width|number|卡片宽度，单位：px。|
      |height|number|卡片高度，单位：px。|

* 示例代码

  ```
  qg.onFormInfoUpdate((data) => {
      console.log('onFormInfoUpdate success' + JSON.stringify(data))
  });
  ```

#### qg.addInteractiveCard(Object object)（1127+）

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212154037.85326048554033099859340624336335:50001231000000:2800:6E432D21057457DDE9B4F6C830FB9B3C82BCA0CC84DB79326A038DA1B50F141F.png)  
使用该接口前，请先使用[qg.canIUse('MiniGame.InteractiveCard')](https://developer.huawei.com/consumer/cn/doc/games-references/games-api-quickgame-runtime-sysinfo-0000002399676789#section165771434195617)判断该接口是否支持使用。

* 描述 添加创新互动卡片到桌面。

* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:----------------|:-------|:----------|:-----------------------------------------------------------------------------|
  |cardName|string|M|卡片名称。|
  |cardDesc|string|M|卡片副标题。|
  |coverPath|string|M|封面图在RPK包体中的相对路径。当前仅支持PNG和JPG格式的图片，图片大小不超过512KB。|
  |cardDimension|string|O|封面图尺寸。当前支持的图片规格为"4x4"，当不填写该值时，默认规格为"4x4"。|
  |cardSubName|string|M|要打开的互动卡片所在分包的包名。|
  |keepStateDuration|number|O|无操作时游戏保持运行的时长，单位：ms，最大时长为10000ms。当不填写该值时，默认时长为10000ms。|
  |success|function|O|接口调用成功的回调函数。|
  |fail|function|O|接口调用失败的回调函数，详情请参见[fail回调函数参数](#ZH-CN_TOPIC_0000002365997060__li1678165719411)。|
  |complete|function|O|接口调用完成后的回调函数。|

  * fail回调函数参数  

    |参数|类型|说明|
    |:------|:-----|:----|
    |errMsg|string|错误信息。|
    |errCode|number|错误码。|

    * 错误码  

      |错误码|说明|
      |:--|:--------|
      |200|通用错误。|
      |201|参数错误。|
      |202|图片路径无效。|
      |203|图片大小超出限制。|

* 示例代码

  ```
  if (qg.canIUse("MiniGame.InteractiveCard") {
      qg.addInteractiveCard({
          cardName: '卡片标题',
          cardDesc: '卡片描述',
          coverPath: 'image/cardCover.png',
          cardDimension: '4x4',
          cardSubName: 'funWidgetSub2.rt',
          keepStateDuration: '10000',
          success: function success(res) {
            console.log(`addInteractiveCard success: ${JSON.stringify(res)}`);
          },
          fail: function fail(errMsg, errCode) {
              console.log(`addInteractiveCard fail, msg: ${errMsg}, code: ${errCode}"`);
          },
          complete: function complete() {
              console.log('addInteractiveCard complete');
          }
    });
  }
  ```
