# LookupExtensions

|Class/Struct Info|
|:------------------------------------------------------------------------|
|public static class LookupExtensions 提供查询所有或特定组件值的扩展方法，支持查询所有或特定实体链接（关系）。|

#### Method Summary

|Qualifier and Type|Method Name and Description|
|:------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------|
|ComponentLookup\<TLookupComponent, TValue\>|[ComponentLookup\<TLookupComponent, TValue\>](#section1031617010220)(this IECSWorld world) 返回索引组件的索引，在O(1)时间内搜索具有特定组件值的实体。|
|LinkComponentLookup\<TLinkComponent\>|[LinkComponentLookup\<TLinkComponent\>](#section1957444919470)(this IECSWorld world) 返回链接组件的索引，在O(1)时间内搜索具有特定实体的实体。|

#### Methods

#### ComponentLookup\<TLookupComponent, TValue\>

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|ComponentLookup\<TLookupComponent, TValue\> ComponentLookup\<TLookupComponent, TValue\>(this IECSWorld world) 返回索引组件的索引，在 O(1) 时间内搜索具有特定组件值的实体。 TLookupComponent为ILookup\<TValue\>。|

Parameters  

|Name|Type|Description|
|:----|:--------|:----------|
|world|IECSWorld|作用的World。|

Return  

|Type|Description|
|:------------------------------------------|:----------|
|ComponentLookup\<TLookupComponent, TValue\>|索引组件的索引。|

Sample Code

```
var world = new IECSWorld();
// 创建一个ComponentLookup
var linkLookup = world.ComponentLookup<LookupInt, int>();
```
