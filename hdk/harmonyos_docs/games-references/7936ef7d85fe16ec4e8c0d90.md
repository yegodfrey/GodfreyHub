### IsPgdSystemManager

### FindCollection

|Method|
|:---------------------------------------------------------------------------------|
|PgdSystemCollection FindCollection(string systemName, bool recursive) 查找指定名称的系统集合。|

**Parameters**

|Name|Type|Description|
|:---------|:-----|:-----------------------------------------------------------------|
|systemName|string|系统名称。|
|recursive|bool|递归标志： * recursive为true，则会递归查找集合所有子系统。 * recursive为false，则不会递归其子系统。|

**Return**

|Type|Description|
|:------------------|:----------|
|PgdSystemCollection|系统集合。|

**Sample Code**

```screen
var collection1 = new TestCollection("TestCollection1");
var collection2 = new TestCollection("TestCollection2");
var collection3 = new TestCollection("TestCollection3");
collection1.Add(collection2);
collection2.Add(collection3);
// 查找目标PgdSystemCollection，recursive为false，则不会递归查找子系统集合的子系统集合
collection1.FindCollection("TestCollection3", false); // null
// recursive为true，则会递归查找子系统集合的子系统集合
collection1.FindCollection("TestCollection3", true); // 返回collection3
```

### FindSystem<T>

|Method|
|:------------------------------------------------------------|
|T FindSystem<T>(bool recursive) 查找指定类型的系统集合。 T为PgdSystemBase。|

|recursive|bool|递归标志： * recursive为true，则会递归查找集合所有子系统集合。 * recursive为false，则不会递归其子系统集合。|

**Return**

|Type|Description|
|:---|:----------|
|T|指定类型系统。|

**Sample Code**

```screen

// 查找目标PgdSystem，recursive为false，则不会递归查找子系统集合的子系统

// recursive为true，则会递归查找子系统集合的子系统
collection1.FindSystem<MoveSystem>(true); // 返回moveSystem
```

### PauseTimer

|Method|
|:--------------------------------------------------------------------------------------|
|void PauseTimer(bool pause = true) 暂停系统定时器，暂停后定时器不更新。 若暂停时定时器激活状态为false，则该定时器所属系统也不会更新。|

