# Game Controller Kit（游戏控制器服务）

Game Controller Kit（游戏控制器服务）支持游戏适配控制器外设（当前仅支持手柄），解决玩家操控性问题，保障用户体验。Game Controller Kit（游戏控制器服务）的C API请参见[C API](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/game-controller-c)。
