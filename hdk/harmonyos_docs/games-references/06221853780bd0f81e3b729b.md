# Deeplink

> 说明
>
> 从1078版本开始，接口前缀由hbs修改为qg，原hbs仍支持。

## 接口定义

|接口|描述|
|:-----------------------------------------------------------------|:----------|
|[qg.openDeeplink(Object object)](#section113471430152319)|跳转到应用的某个场景。|
|[qg.navigateToQuickApp(Object object)（1040+）](#section01284612546)|打开另一个快游戏。|

### qg.openDeeplink(Object object)

* 描述 跳转到应用的某个页面。


* 参数

  |参数|类型|必填(M)/选填(O)|说明|
  |:--|:-----|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
  |uri|string|M|需要跳转场景的uri，可以是如下格式： 1. 包含schema的完整uri；目前支持的schema有tel、sms、mailto、http(s)和hap，例如tel:10086，mailto:abc@gmail.com，hap://app/com.company.app/index?param1=value1。 2. hap://settings/permission_manager，跳转到快应用的权限管理界面。 3. hap://settings/location_source_manager，跳转到手机系统的位置管理界面。 4. http(s)则会通过内置的webview启动加载目标网页，支持包含schema的完整uri。对于带有schema的uri，处理流程如下： 1. 如果默认策略也不能处理请求，会尝试使用系统中的应用来处理请求。 2. 如果没有系统应用可以处理请求，则抛弃请求。 默认策略的处理逻辑：如果schema是http/https，使用内置的web页面打开网页。|


* 示例代码

  ```screen
  qg.openDeeplink({
    uri: 'www.example.com'
  });
  ```

### qg.navigateToQuickApp(Object object)（1040+）

* 描述 打开另一个快游戏。

* 参数说明

  |参数|类型|必填(M)/选填(O)|说明|
  |:----------|:-------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
  |packageName|string|M|需要打开的快游戏包名。|
  |path|string|O|待打开的页面路径，若为空则打开首页。快游戏场景下无效。|
  |extraData|object|O|需要传递给快游戏的数据，可在[qg.getLaunchOptionsSync()](https://developer.huawei.com/consumer/cn/doc/games-references/games-api-quickgame-runtime-lifecycle-0000002365996968#section4844135503910)中获取传递的数据。|
  |success|function|O|接口调用成功的回调函数。|
  |fail|function|O|接口调用失败的回调函数。|

* 示例代码

  ```screen
  qg.navigateToQuickApp({
      packageName: 'com.***.***',
      extraData: {
        message: 'I come from another game'
      },
      success: function () {
        console.log('navigateToQuickApp success');
      },
      fail: function () {
        console.log('navigateToQuickApp fail');
      }
  });
  ```
