# 下载识别结果文件

获取识别结果下载地址后，调用该接口可下载识别结果文件。  

#### 使用约束

文件有效期是1小时，请及时下载查看。  

#### 接口原型

|承载协议|HTTPS GET|
|接口方向|开发者服务器 -\> 华为服务器|
|接口URL|[获取识别结果下载地址](https://developer.huawei.com/consumer/cn/doc/games-references/gamemme-obtaining-download-address-restapi-0000002358963840)接口返回的url|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: text/csv|
|-----|-----------------------------------------------------------------------------------------------------------------------------------------------|

#### 请求参数

#### Request Header

|参数名称|必选（M）/可选（O）|类型|参数说明|
|:-----------|:----------|:-----|:--------------------|
|Content-Type|M|String|取值为：application/json。|

#### 请求示例

```
GET 获取识别结果下载地址接口返回的url
Content-Type: application/json
```

#### 响应参数

识别结果文件。  

#### 调用示例

```
private void download(String downloadUrl) throws IOException {
        OkHttpClient client = new OkHttpClient().newBuilder().build();
        MediaType mediaType = MediaType.parse("text/plain");
        RequestBody body = RequestBody.create(mediaType, "");
        Request request = new Request.Builder().url(downloadUrl).method("GET",null).build();
        Response response = client.newCall(request).execute();
        ResponseBody responseBody = response.body();
        InputStream is = null;
        byte[] buf = new byte[2048];
        int len = 0;
        FileOutputStream fos = null;
        try {
            is = response.body().byteStream();
            long total = response.body().contentLength();
            File file = new File("xx.csv");
            fos = new FileOutputStream(file);
            long sum = 0;
            while ((len = is.read(buf)) != -1) {
                fos.write(buf, 0, len);
                sum += len;
            }
            fos.flush();
        } catch (Exception e) {
            e.printStackTrace();
        } finally {
            try {
                if (is != null)
                    is.close();
            } catch (IOException e) {
            }
            try {
                if (fos != null)
                    fos.close();
            } catch (IOException e) {
            }
        }
    }
```
