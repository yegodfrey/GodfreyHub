# CreateGroupConfig

|Interface Info|
|:-------------------------------------------|
|export interface CreateGroupConfig 创建队伍方法参数。|

## Property Summary

|Name|Type|Mandatory/Optional|Description|
|:--------------------|:-----|:-----------------|:------------------------------|
|maxPlayers|number|Mandatory|队伍最大支持人数，取值范围为[1, 100]。|
|groupName|string|Optional|队伍名称。|
|customGroupProperties|string|Optional|自定义队伍属性，最大支持2048个字符。|
|isLock|number|Optional|队伍是否禁止加入。 * 0：不禁止 * 1：禁止 默认值为0。|
|isPersistent|number|Optional|是否持久化。 * 0：不持久化 * 1：持久化 默认值为0。|
