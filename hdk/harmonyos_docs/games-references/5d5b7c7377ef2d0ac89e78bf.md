# SetRtmChannelPlayerPropertiesReq

|Class Info|
|:--------------------------------------------------------------|
|public class SetRtmChannelPlayerPropertiesReq 设置RTM频道玩家自定义属性请求。|

## Property Summary

|Name|Type|Description|
|:---------------|:-------------------------|:----------------------------------------------|
|ChannelId|string|频道ID，仅支持数字(0-9)和字母 (A-Z,a-z)。|
|PlayerProperties|Dictionary<string, string>|频道内玩家属性。属性Key最长100个字节，属性value最长1948个字节。最多可设置5组。|
