#### qg.setUnderAgeOfPromise(boolean underAgeOfPromise)（1077+）

* 描述 设置未达到法定承诺年龄用户的标记。

* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:----------------|:------|:----------|:-------------------------------------------------|
  |underAgeOfPromise|boolean|M|* true表示对未达到法定承诺年龄用户的标记。 * false表示对已达到法定承诺年龄用户的标记。|

* 示例代码

  ```
  qg.setUnderAgeOfPromise(true)
  ```

#### qg.requestConsentUpdate(Object object)（1077+）

* 描述 请求用户意见更新状态。

* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:------------------------------------------------------------------------------------------------------------|
  |success|function|O|请求用户意见更新状态成功，请参见[success回调函数参数](#ZH-CN_TOPIC_0000002399676813__zh-cn_topic_0000001130711971_li1661843119215)。|
  |fail|function|O|请求用户意见更新状态失败。|
  |complete|function|O|若有函数传入，将在成功、失败后调用该函数。|

  * success回调函数参数  

    |参数|类型|说明|
    |:-------------|:------|:-----------------------------------------------------------------------------------------------------------------------|
    |consentStatus|number|用户意见状态。 * 0：用户已同意接收个性化广告与非个性化广告。 * 1：用户已同意仅接收非个性化广告。 * 2：用户既未同意接收也未拒绝接收个性化广告或非个性化广告。|
    |isNeedConsent|boolean|是否需要用户确认意见。 * 取值为false，表明可以向鲸鸿动能SDK请求个性化广告。 * 取值为true，表明用户在欧洲经济区内或其他敏感地区，需进一步确认用户意见。|
    |AdProviderList|array|广告技术提供商信息列表。AdProvider对象结构详见[AdProvider参数](#ZH-CN_TOPIC_0000002399676813__zh-cn_topic_0000001130711971_li1464325013216)。|

    * AdProvider参数  

      |参数|定义|
      |:---------------|:-----------------|
      |id|广告技术提供商的ID。|
      |name|广告技术提供商的名称。|
      |serviceArea|广告技术提供商的服务地。|
      |privacyPolicyUrl|广告技术提供商的隐私政策链接URL。|

* 示例代码

  ```
  qg.requestConsentUpdate({
    success: function(data) {
      console.log('requestConsentUpdate success data ' + JSON.stringify(data))
    },
    fail: function(data) {
      console.log('requestConsentUpdate fail data ' + JSON.stringify(data))
    },
    complete: function() {},
  })
  ```

#### qg.createNativeAd(Object object)（1075+）

* 描述 创建 native 广告组件，如果已经创建过 native 广告组件，则返回已创建的广告组件。

* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:-----------------------|
  |adUnitId|string|M|原生广告位标识。|
  |success|function|O|接口调用成功的回调函数，code为0时表示成功。|
  |fail|function|O|接口调用失败的回调函数，返回失败原因。|
  |complete|function|O|若有函数传入，将在成功、失败后调用该函数。|

* 返回值 原生广告组件。

* 示例代码

  ```
  let nativeAd = qg.createNativeAd({
      adUnitId: 'xxx',
      success: (code) => {
          console.log("loadNativeAd loadNativeAd : success");
      },
      fail: (data, code) => {
          console.log("loadNativeAd loadNativeAd fail: " + data + "," + code);
      },
      complete: () => {
          console.log("loadNativeAd loadNativeAd : complete");
      }
  });
  ```

#### nativeAd.load()（1075+）

* 描述 拉取广告数据，成功回调 onLoad，失败回调 onError。

  ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212154042.96542210892705209665173126366872:50001231000000:2800:DCAA57E790A31C044E40B2DB4C7809129005FCE6EBB2CC5864258DA596C3F39A.png)  
  华为目前每次调用返回一条广告数据。
* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:------------|:-----|:----------|:-------------------------------------------------------------------------------------------------------|
  |channelExtras|Object|O|扩展参数，详情请参见[channelExtras参数](#ZH-CN_TOPIC_0000002399676813__zh-cn_topic_0000001130711971_li538223122212)。|

  * channelExtras参数  

    |参数|类型|必填(M)/选填(O)|说明|
    |:--------------|:-----|:----------|:-------------------|
    |customerChannel|string|O|广告的启动渠道，取值范围为0\~100。|

* 示例代码

  ```
  nativeAd.onLoad((data) => {
    console.info('ad data loaded: ' + JSON.stringify(data))
    this.adItemData = data.adList[0]
  })
  nativeAd.load({
    "channelExtras": { 
      "customerChannel": "1"
    } 
  })
  ```

#### 错误码

错误码为通过onError获取的错误信息。  

|错误码|说明|
|:---|:-------------------------------|
|200|通用错误。|
|202|参数错误。|
|1001|无效的广告请求，如未设置广告位ID、Banner广告尺寸无效等。|
|1002|横幅广告过期或者横幅广告任务下架。|
|1003|内部错误。|
|1004|广告请求成功，但是服务器没有返回可用的广告素材。|
|1100|广告正在请求中，不能重复发起请求。|
|1102|API版本不在广告服务支持范围内。|
|1104|由于网络连接错误导致广告请求失败。|
|2000|HMS Core版本过低，不支持设置AppInfo。|
