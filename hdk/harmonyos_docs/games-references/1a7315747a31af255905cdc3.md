# SendToClientInfo

|Class Info|
|:-----------------------------------------------------------------------|
|namespace Com.Huawei.Game.Gobes public class SendToClientInfo 发送房间内消息参数。|

#### Property Summary

|Name|Type|Mandatory/Optional|Description|
|:---------------|:-------------|:-----------------|:-----------------------------------------------------------------------|
|Type|int|Mandatory|消息接收者类型。 * 0：发送给房间内全部玩家 * 1：发送给房间内除本人外的其他所有玩家 * 2：发送给recvPlayerIdList的玩家|
|Msg|string|Mandatory|消息内容，最大支持512个字符。|
|RecvPlayerIdList|List\<string\>|Optional|接收消息的玩家ID列表。|
