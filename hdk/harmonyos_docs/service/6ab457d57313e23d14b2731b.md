# 动态开场白和引导语

在小艺开放平台配置过可以动态生成开场白和引导语的Agent，在小艺与Agent建立好连接后，会向Agent请求动态的开场白和引导语。Agent可以针对当前页面或者用户数据生成个性化的内容并返回。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7e/v3/QaJjmXNvRDWH_cBTiPvCsA/zh-cn_image_0000002643378912.png?HW-CC-KV=V1&HW-CC-Date=20261008T161250Z&HW-CC-Expire=31536000000&HW-CC-Sign=D5882E92FA218508C6DC7988EF52BB814CC048058E1380171E8D7E0215100880 "点击放大")

小艺发起动态开场白和引导语请求（小艺发送至Agent）：

```codeblock
{
  "jsonrpc": "2.0",
  "id": "req-001",
  "method": "GetOpening",
  "params": {
    "message": {
      "messageId": "msg-001",
      "contextId": "ctx-001",
      "role": "ROLE_USER",
    },
    "metadata": {
      "traceId": "trace-7f8a2b3c-0001",
      "agentId": "agent-example-001",
      "appVersion": "12.0.1"
    }
  }
}
```

Agent创建Task（Agent发送至小艺）：

```codeblock
{
   "jsonrpc":"2.0",
   "id":"req-001",
   "result":{
     "task":{
       "id":"task-001",
       "contextId":"ctx-001",
       "status":{
         "state":"TASK_STATE_SUBMITTED",
         "timestamp":"2026-03-04T10:24:00.000Z"
       }
     },
     "metadata":{
       "traceId":"trace-7f8a2b3c-0001",
       "agentId":"agent-example-001",
       "agentVersion":"1.2.0"
     }
   }
 }
```

Agent返回动态开场白和引导语（Agent发送至小艺）：

```codeblock
{
    "jsonrpc": "2.0",
    "id": "req-001",
    "result": {
        "artifactUpdate": {
            "taskId": "task-001",
            "contextId": "ctx-001",
            "artifact": {
                "artifactId": "art-introduction-001",
                "parts": [{
                        "data": {
                            "openingTexts": {
                                "openingText": "你好",
                                "openingQuestions": ["查看景点", "推荐餐厅"]
                            }
                        }
                    }
                ]
            },
            "append": false,
            "lastChunk": true
        },
        "metadata": {
            "traceId": "trace-7f8a2b3c-0001",
            "agentId": "agent-example-001",
            "agentVersion": "1.2.0"
        }
    }
}
```

Agent返回完成（Agent发送至小艺）：

```codeblock
{
  "jsonrpc":"2.0",
  "id":"req-001",
  "result":{
    "statusUpdate":{
      "taskId":"task-001",
      "contextId":"ctx-001",
      "status":{
        "state":"TASK_STATE_COMPLETED",
        "timestamp":"2026-03-24T10:00:10.000Z"
      }
    },
    "metadata":{
      "traceId":"trace-7f8a2b3c-0001",
      "agentId":"agent-example-001",
      "agentVersion":"1.2.0"
    }
  }
 }
```
