# 设备上下文参数指令说明

Agent Server端可获取的受控系统上下文信息，需要先在小艺开放平台变量配置项中打开对应配置项：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3d/v3/z0iTKsaoTYqG7cwpR3sn7A/zh-cn_image_0000002670104023.gif?HW-CC-KV=V1&HW-CC-Date=20260909T153049Z&HW-CC-Expire=31536000000&HW-CC-Sign=651E5803EE21369B5B83752354DBDA2870F6EB83505B7CC7622FCDBAC4F2088F "点击放大")

Agent Client请求Agent Server侧的data数据结构定义：

```screen
{
    "variables": {
        "clientVariables": [{}],
        "systemVariables": [{
             "app_ver": "{{小艺APP的版本号，在小艺开放平台系统变量开关打开后生效}}",
             "foreground_apps": "{{智能体运行的前台应用列表，在小艺开放平台系统变量开关打开后生效}}"
         }], 
         "memoryVariables": [{}]
      }
}
```

Variables参数说明：

|**字段名称**|||类型|是否必填|字段描述|
|:---|---------|---------------|:---------|:---|:-----------------|
|kind|-||string|是|字段类型，此处固定为"data"。|
|data|-||object|是|数据类型为data类型的结构体定义。|
|data|variables|-|JsonObject|否|获取Agent平台的一些上下文变量。|
|data|variables|clientVariables|JsonObject|否|应用变量。|
|data|variables|systemVariables|JsonObject|否|系统变量。|
|data|variables|memoryVariables|JsonObject|否|用户变量。|
