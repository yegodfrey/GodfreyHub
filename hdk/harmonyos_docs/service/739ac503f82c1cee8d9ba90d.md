# 发送模板消息

开发者有需要给用户发送服务通知或事件提醒时，可通过服务号模板消息发送，用户阅读后，服务号通过模板消息阅读回执通知传给开发者已读状态。

## 1、发送模板消息

1）功能介绍

可通过模板消息发送API，对已关注用户发送服务通知。

2）约束与限制

商户先开通服务号模板消息， 成功领用模板，指引详见：[开通服务号模板消息](https://developer.huawei.com/consumer/cn/doc/service/template_message-0000002684115189)

模板消息仅可对关注用户进行发送。

若需要同时触发锁屏、通知栏提醒，则需要用户在设备上进入服务号首页开启消息通知订阅

3）请求体结构说明

接口原型

**承载协议：** HTTPS POST

**接口方向：** 开发者服务器 -> 华为Push服务器

**接口URL：** https://push-api.cloud.huawei.com/**v1** /**[projectId]** /service_notification/send

**数据格式：** Content-Type: application/json

**说明**

**[projectId]** ：项目ID，登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，选择"开发与服务"，在项目列表中选择对应的项目，左侧导航栏选择"项目设置"，在该页面获取，且需要与服务号"开发者信息设置"中配置的项目id保持一致。

## 2、模板消息阅读回执通知

1）功能介绍

服务号通过配置回调地址、回调密钥，以及开通对应功能回调开关，可将用户行为实时通知到开发者的第三方服务（CP云）。

消息阅读回执通知：用户阅读服务号推送的模板消息时，向开发者发送阅读回执。

2）约束与限制

- 开发者必须在服务号授权信息中配置有效的回调地址。

- 消息阅读回执通知受开关控制，开关关闭时不发送通知。

- 回调请求使用 HTTPS POST 协议，Content-Type 为 application/json。

- 回调请求使用 HMAC-SHA256 签名进行身份验证，签名密钥为对应配置密钥。

接口原型

**承载协议：** HTTPS POST

**接口方向：** 服务号系统 -> 开发者服务器

**接口URL：** {回调地址}/msg/reply

**数据格式：** Content-Type: application/json

**Request Header**

|**参数**|**取值描述**|**样例**|
|:---------------|:---------------------------------------------|:---------------|
|x-signature|HMAC-SHA256 签名，使用配置的回调密钥对请求体签名后通过Base64编码后的字符串|a1b2c3d4e5f6...|
|x-access-key|来源，开发者配置的clientId|10182065|
|x-timestamp|时间戳|1785931696739|
|x-nonce|安全随机数，32位16进制字符串|854A4B...|
|x-sign-algorithm|签名算法|HMAC-SHA256|
|Content-Type|类型|application/json|

签名代码参考关注/取消关注对应代码示例

**Request Body**

|**参数**|**是否必选**|**参数类型**|**描述**|
|:----------|:-------|:-------|:---------------------------|
|msgId|是|String|消息ID，唯一标识一条消息。长度范围[1, 64]。|
|appId|是|String|服务号ID（pubId）。长度范围[1, 64]|
|developerId|是|String|开发者ID。团队账号为团队ID，普通账号为华为账号ID。|
|openId|是|String|用户关注服务号的openId。|
|unionId|是|String|用户关注服务号的unionId。|
|type|是|Integer|通知类型。0-关注，1-取消关注。|
|receiveTime|是|Long|消息接收时间，毫秒时间戳。|
|readTime|是|Long|消息阅读时间，毫秒时间戳。|

**请求示例**

POST {回调地址}/follow/reply HTTP/1.1

Host: developer.example.com

Content-Type: application/json

x-access-key: clientId_12345

x-signature: a1b2c3d4e5f6...

{

"msgId": "20240514ABCDE",

"appId": "4jdw2Au2u4nggu5oncjruQ",

"developerId": "30012345",

"openId": "A**********O",

"unionId": "U**********1",

"receiveTime": 1715678901000,

"readTime": 1715678956000

}
