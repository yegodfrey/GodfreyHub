# 跳转配置

在自定义菜单、画廊模式主页背景图/商品图/Banner、服务Tab菜单、关联元服务列表、模板消息、图文消息、会话消息等位置都支持设置跳转目标。  

#### 跳转元服务

嵌入式和跳出式打开元服务的区别：主要表现在用户手机端界面名称和交互有不同。

嵌入式打开元服务时，是在服务号APP内打开目标元服务页面， 目标元服务没有独立的App名称，而以"服务号"作为界面载体打开，用户切换APP时，目标元服务不独立显示。

<br />

跳出式打开元服务时，目标元服务以独立的APP界面打开，用户可以手动切换到目标元服务，跟用户操作打开元服务体验一致。

1）跳出式打开元服务（推荐）

在模板消息、欢迎消息、会话消息、图文消息等位置，支持在服务号app内跳出式打开元服务落地页。

步骤1：选择元服务，只有操作关联过的元服务才会出现在选择列表中，可以进入"[关联元服务](https://developer.huawei.com/consumer/cn/doc/service/association_service-0000002508947051)"栏目操作。

![](https://media:201787729662645930 "点击放大")

步骤2：设置自定义参数

参数可选，如不填参数默认跳转到元服务首页；如果已选元服务已实现打开目标页功能，请联系对应元服务开发负责人提供具体参数，样例：{"demo.result":1234 }。

<br />

2）嵌入式打开元服务

在自定义菜单、A级专区画廊模式主页背景图/商品图/banner、服务tab菜单、关联元服务列表等位置，支持在服务号app内全屏嵌入式打开元服务落地页。

步骤1：选择元服务，只有操作关联过的元服务才会出现在选择列表中，可以进入"[关联元服务](https://developer.huawei.com/consumer/cn/doc/service/association_service-0000002508947051)"栏目操作。

![](https://media:201787729662911931 "点击放大")

步骤2：设置自定义参数

参数可选，如不填参数默认跳转到元服务首页；如果已选元服务已实现打开目标页功能，请联系对应元服务开发负责人提供具体参数，样例：{"demo.result":1234 }。

步骤3：嵌入式跳转元服务兼容性确认

在设置跳转元服务后，需要您检查对应元服务嵌入式打开兼容性验证,兼容性验证至少应包括：1) 全屏布局适配 2) 返回键处理逻辑 3) 生命周期事件传递 4) 深色模式支持，如发现元服务有适配界面布局、功能等，请将问题和优化指引发给对应元服务开发负责人做元服务端的优化。  

#### 跳转图文素材

在主页装修、自定义菜单、图文素材内等位置，跳转目标支持设置跳转图文素材。您可以根据条件搜索到图文素材，在列表中选中图文素材，只有正常审核通过的素材才会出现在列表中。

![](https://media:201787729662944932 "点击放大")  

#### 跳转H5网站

前提条件：服务号通过服务号认证后可开通跳转H5权限，没有权限时，不会出现配置H5类型的跳转入口。

在主页装修、自定义菜单、图文素材、模板消息等位置，支持配置跳转到开发者对应的网站。

![](https://media:201787729662977933 "点击放大")

配置步骤：

1. 跳转类型选择打开H5

2. 确认链接的对应的域名是否已经录入配置和通过验证。如果没有配置过， 点击界面上的"配置域名"，弹出录入域名弹框。

![](https://media:201787729663029934 "点击放大")

3. 配置域名前，需要联系您的开发或者运维人员，将所对应的服务器根目录下需要建一个服务号对应的验证文件。文件名需要跟您服务号界面上的文件名提示保持一致，否则无法正常配置保存域名。

![](https://media:201787729663065935 "点击放大")

4. 在界面输入域名，需要带https://前缀。验证通过才能正常保存。
