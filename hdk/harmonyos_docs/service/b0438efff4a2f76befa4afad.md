# 配置开发者信息

如商家涉及开发接入场景（接收关注关系通知、发送模板消息、发送图文消息等），您需进入管理界面，配置开发者信息。

1. 进入["AppGallery Connect"-"开发与服务"](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/myProject)栏目。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/68/v3/lOIYH2uoTA2HDDLSNsxRYA/zh-cn_image_0000002686732064.png?HW-CC-KV=V1&HW-CC-Date=20260909T145545Z&HW-CC-Expire=31536000000&HW-CC-Sign=5CACE98E0395B82DE250D834473E55A67141541198F58517F04715718E5BD353 "点击放大")

2. 点击"新增项目"，创建一个项目用于服务号开放能力，建议项目名称与服务号名称有关联。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4b/v3/OXPJyeLJRUyuUsKDDVbjSA/zh-cn_image_0000002686573876.png?HW-CC-KV=V1&HW-CC-Date=20260909T145545Z&HW-CC-Expire=31536000000&HW-CC-Sign=EAE889B88104479517313C98790F4094F91FC63360DA4AD6CBFB3AE0CE8E50A9 "点击放大")

3. 项目添加成功后，会展示项目所有参数。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a6/v3/nIuI8IB3QUOmux0BWIvP5g/zh-cn_image_0000002686739390.png?HW-CC-KV=V1&HW-CC-Date=20260909T145545Z&HW-CC-Expire=31536000000&HW-CC-Sign=0B8082E075598D0A9126688F81DE8DA6CAC3FBE6CF787C4FC6E4EFA36F5C731E "点击放大")

4. 返回商家服务号列表页，进入目标服务号管理页面"装修与设置"-"设置开发者信息"，选择"项目名称"和"Client ID"（即OAuth 2.0 客户端 ID），

需要关注关系通知，需要打开开关，开关关闭则平台不会发送关注关系通知。

服务号消息回调通知用于模板消息发送后，用户阅读结果的回执通知。开关关闭则不会发送通知给开发者。

填写回调接口配置的相关信息，完成后点击"提交"即可成功配置开发者信息。
