# 批量变更商品

在商品状态为"草稿"、"审核驳回"、"已上架"状态时，开发者可以通过"批量变更"操作更新商品信息并发起审核。

1. 在服务直达主界面，选择"商品直达"页签，点击"商品状态"列筛选出"已上架"状态的商品。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6/v3/eFbq_TIXToaXrHhy7ulNhA/zh-cn_image_0000002752481275.png?HW-CC-KV=V1&HW-CC-Date=20261008T184705Z&HW-CC-Expire=31536000000&HW-CC-Sign=76D500B31CAA27FB9C023AA98125F46D7AA535B7B42BBF456A4CF63E3E86E456 "点击放大")

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5d/v3/PUpWR-kCSwupKaMLBuS-TQ/zh-cn_image_0000002752561171.png?HW-CC-KV=V1&HW-CC-Date=20261008T184705Z&HW-CC-Expire=31536000000&HW-CC-Sign=E98BECAFA50B4D1D560588BBD8DD5FABA9C0FF5D0C7EE4525AD226DE32FE7477 "点击放大")
2. 点击"导出"。
   * 没有勾选项时，点击"导出"可导出全部商品。
   * 存在已勾选商品时，点击"导出"仅导出已勾选商品。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6c/v3/3BArlOa0Spi5qc60UKy-VQ/zh-cn_image_0000002722801472.png?HW-CC-KV=V1&HW-CC-Date=20261008T184705Z&HW-CC-Expire=31536000000&HW-CC-Sign=2EDEEEDBE233742B3CBE5E80F238DA183C8F54EAA6BD4B124F2EDC52EB310302 "点击放大")
3. 导出完成后，点击"任务管理"，下载导出结果。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ed/v3/08kkNslwQfW8DOaLEtYdXg/zh-cn_image_0000002752481277.png?HW-CC-KV=V1&HW-CC-Date=20261008T184705Z&HW-CC-Expire=31536000000&HW-CC-Sign=CE84565AC9146E9B8074BE00CC099DCD701BCE08EE72BE556ED8D287E35B843B "点击放大")

4. 编辑表格，修改商品信息。 说明
   >
   > "SKU"Sheet页中，删除一行时会删除该SKU。若需新增SKU，请新增一行并填写必填字段。
5. 点击"服务直达",返回"商品直达"页签。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/13/v3/p6QQlERbRVebQV66C171KA/zh-cn_image_0000002752561173.png?HW-CC-KV=V1&HW-CC-Date=20261008T184705Z&HW-CC-Expire=31536000000&HW-CC-Sign=977666D1E626E038E40C6DF1A458D327344EEB67420F09A64D0EE49FFB6A06E1 "点击放大")

6. 点击"批量变更"，上传编辑后的表格文件，点击"上传"按钮。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/60/v3/1tIXCFwTSDmeTiq1MI3RBw/zh-cn_image_0000002722801468.png?HW-CC-KV=V1&HW-CC-Date=20261008T184705Z&HW-CC-Expire=31536000000&HW-CC-Sign=2826521FD415B919CA74FD139CB552F7CCF342A7A37B61FEDA1067E82EB3DFFA "点击放大")
