# Agent版本管理

Agent的版本管理功能，包括查看、回退到历史版本。版本记录中包括Agent上下架及撤回审核时的版本。

**查看历史版本**

点击Agent编排页右上角【版本记录】图标可查看版本记录，点击某个版本可以查看该版本Agent编排情况。注意：查看历史版本时不可编辑Agent信息，可先切回当前或回退至此版本进行编辑。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5a/v3/wCKeIuVKRi6PjzGU32YOrA/zh-cn_image_0000002670263941.gif?HW-CC-KV=V1&HW-CC-Date=20260924T081230Z&HW-CC-Expire=31536000000&HW-CC-Sign=332E37543D75DEF60B28BA5C933C3B58D495D0A3F12701D9C06EF4EEB9119D0D "点击放大")

**回退到历史版本**

点击Agent编排页右上角【版本记录】图标，选择历史版本，点击右下角【回退至此版本】将该历史版本覆盖当前Agent的草稿态版本。
> 说明
>
> 回退原则：
>
> 1. 因历史版本关联插件、工作流、卡片或知识库可能会发生变化，资源相关配置可能发生变化；
>
> * 若资源已更新版本，回退后将自动关联资源的最新版本。
> * 若资源已下架或删除，回退后将自动删除Agent与资源的关联关系。
>
> 2. 除插件/工作流/知识库/卡片外，其他配置均可以完全还原。
