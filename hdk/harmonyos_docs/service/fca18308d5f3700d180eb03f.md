# H5卡片用法

开发准备

请先参考[应用开发准备](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/application-dev-overview)完成基本准备工作，再继续以下开发准备项。

申请小艺开放平台H5卡片开放能力

基于安全考虑，系统侧对小艺开放平台H5卡片功能做了权限保护处理，使用相关接口开发者需先提交"小艺开放平台H5卡片"能力开关的申请，在申请通过后，再使用该能力开关。

审核规则

1. 仅对鸿蒙应用开放。

申请步骤

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表选择项目，并在应用列表下选择需要申请小艺开放平台H5卡片功能的应用。
3. 进入"项目设置 \> 开放能力管理"页面，点击"小艺开放平台H5卡片"对应的"申请"。 ![](https://media:301785143849319720 "点击放大")

4. 参考"申请原因"中的模板，提供申请必需的相关信息，包括申请目的、账号基本信息、域名、意图框架调试ID，然后点击"提交"按钮。 ![](https://media:301785143849589721 "点击放大")

   返回"开放能力管理"页面，审核状态变更为"审核中"，原"申请"变为"申请中"，1\~3个工作日内反馈申请结果，请留意互动中心的"服务开通申请"信息。

   ![](https://media:301785143850226722 "点击放大")

   申请通过后，互动中心会发送通知给您，审核状态变更为"已通过"，同时"申请中"会变为置灰显示的"申请"，至此，应用已成功开启小艺开放平台H5卡片开放能力。

   ![](https://media:301785143850488723 "点击放大")

   若申请不通过，互动中心会发送通知给您，审核状态为"已驳回"，同时"申请中"会变为"申请"，开发者可点击申请重新提交。

   ![](https://media:301785143850865724 "点击放大")

   接入指导

当您在小艺开放平台上开发卡片时，若您已经在其他网页上拥有成熟孵化的卡片设计，可以考虑使用H5卡片功能直接展示这些卡片。H5卡片将展示给定的URL指向的网页中的内容，无需您再做复杂适配即可完全展示已有设计的效果。

点击创建卡片按钮并选择H5卡片选项即可创建一张H5卡片。

![](https://media:301785143850930725 "点击放大")

<br />

H5卡片的编辑页面如下图所示，左侧为变量区域，中间为卡片展示区域，右侧为卡片属性配置区域。

![](https://media:301785143851049726 "点击放大")

中间区域为卡片展示区域，将展示在属性区域中填写的URL所对应的页面。

<br />

<br />

在右侧的卡片属性配置区域中，您可以对卡片属性进行调整。

URL一栏为需要使用的H5卡片对应的链接，可选择手动输入链接或绑定已有变量，必须为https协议地址。

域名为允许渲染H5卡片或跳转的域名，您可以自由增加或删除，也可编辑单条域名数据，支持以下三种类型：

* AppLink：标准https协议的Applink地址，触发应用跳转，点击H5卡片后跳转到应用中。
* DeepLink：应用的deeplink地址，触发应用跳转，点击H5卡片后跳转到应用中。
* WebUrl：网页跳转链接，点击H5卡片后跳转到对应网页中。

![](https://media:301785143851156727 "点击放大")
