# 批量导出商品

1. 在服务直达主界面，选择"商品直达"页签，根据商品状态或商品名称筛选出需要导出的商品。 ![](https://media:401788945855890293 "点击放大")

2. 点击"导出"。
   * 没有勾选项时，点击"导出"可导出全部商品。
   * 存在已勾选商品时，点击"导出"仅导出已勾选商品。

   ![](https://media:401788945855931294 "点击放大")
3. 导出完成后，点击"任务管理"，下载导出结果。 ![](https://media:401788945855976295 "点击放大")

![](https://media:401788945856025296 "点击放大")
