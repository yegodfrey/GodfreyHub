# 批量导出商品

1. 在服务直达主界面，选择"商品直达"页签，根据商品状态或商品名称筛选出需要导出的商品。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b1/v3/dTZ6oS3cSy2gJ7tF6pmlYw/zh-cn_image_0000002722801412.png?HW-CC-KV=V1&HW-CC-Date=20261008T193501Z&HW-CC-Expire=31536000000&HW-CC-Sign=9D8B737821279637EF8EDE7336C368B86AB92212C418A5E021E2706216BA7A0F "点击放大")

2. 点击"导出"。
   * 没有勾选项时，点击"导出"可导出全部商品。
   * 存在已勾选商品时，点击"导出"仅导出已勾选商品。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/70/v3/zuGT1xxJSHiE7QNv8T3SaA/zh-cn_image_0000002752561113.png?HW-CC-KV=V1&HW-CC-Date=20261008T193501Z&HW-CC-Expire=31536000000&HW-CC-Sign=BACB1ED30CBFE4F1824C0F704FA90A27C62FF31AAF7D5FD563664B973326BBEE "点击放大")
