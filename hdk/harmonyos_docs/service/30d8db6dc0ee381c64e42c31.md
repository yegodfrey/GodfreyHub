# 插件升级

**云插件**

Agent中已添加的云插件如果有版本更新，再次进入Agent时，会自动更新插件版本，注意：此处仅测试态Agent更新到插件新版本，需升级Agent，将Agent上架版本更新使用插件新版本。

插件版本更新后，Agent中对应提示：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a8/v3/UjlscFBnSeqkJRFVxPHOMg/zh-cn_image_0000002640264116.png?HW-CC-KV=V1&HW-CC-Date=20261008T163518Z&HW-CC-Expire=31536000000&HW-CC-Sign=1E39050E9D2C702611657ABF5AB7EB4A7E316109DBE58F8E25018BCBF513DD7F "点击放大")

**端插件**

Agent中已添加的端插件若有版本更新，需在Agent编排界面手动移除旧版本并添加新版本端插件。
