# 选项组组件用法

选项组（DualSelect）是容纳选项（DualSelectItem）的容器。

一、选项组的选项个数允许设置固定个数和绑定变量。

1、固定个数

新建的选项组默认包含三个选项，可为选项"选中时"、"未选中时"状态分别设置不同样式。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a0/v3/cQOetd9DT1i46RPnR1AiIA/zh-cn_image_0000002670264129.png?HW-CC-KV=V1&HW-CC-Date=20261008T143203Z&HW-CC-Expire=31536000000&HW-CC-Sign=D6730B53B57761ABD0C28FE6C495B59C6B9251D7412E5C3F94B4B338785FBDF5)

选中选项组，可对选项进行拖动排序、新增选项、编辑选项和删除选项，也能点击画布中复制按钮，复制单个选项。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a9/v3/7VCQPWOmRB6rKFYmtMfxpA/zh-cn_image_0000002640264228.png?HW-CC-KV=V1&HW-CC-Date=20261008T143203Z&HW-CC-Expire=31536000000&HW-CC-Sign=24C91E2BB14285A17F9E160744A70171A85B1D913FCF1C08F4D94AB60450C285)

点击编辑按钮，对单个选项进行配置。左侧带红色*号的为必填项。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/98/v3/dePrbhx1T9i4qYwXL_rVKQ/zh-cn_image_0000002670104261.png?HW-CC-KV=V1&HW-CC-Date=20261008T143203Z&HW-CC-Expire=31536000000&HW-CC-Sign=13E741A5802CC77300FDDE55E2ABFF40C33BC704EAD78D1887DB6643CDDA9DEC)

2、绑定变量

与列表组件相似，可以给选项组绑定数组变量，来遍历生成选项，此时每个选项的选中时、未选中时状态样式是一致的。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/55/v3/dXixqGarSfy5nHDtUACEmQ/zh-cn_image_0000002670264123.png?HW-CC-KV=V1&HW-CC-Date=20261008T143203Z&HW-CC-Expire=31536000000&HW-CC-Sign=97CFEFADC4F85E983194976D77FA334F349D9B226B765C132C117CA6FC68E7E4)

二、功能介绍

1、选项类型：

提供单选和多选两种类型，在单选模式下，如果设置多个选项为选中（选中状态时值为true），卡片加载后只有最后一个选中状态选项生效。

2、提供水平和垂直两张排列方式，根据需求自由设置水平和垂直的对齐方式。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/af/v3/tRxmCCNIRvWVrKFRQPIcGg/zh-cn_image_0000002640104292.png?HW-CC-KV=V1&HW-CC-Date=20261008T143203Z&HW-CC-Expire=31536000000&HW-CC-Sign=9C692E12631B1903D69AE9586AFEE0A662F714D01EABA66EB5692806284E38A2)

3、可交互

选项可交互功能绑定布尔类型的变量，或者设置默认的布尔值。为false时，选项会有禁用状态样式，如上图中的标题二选项，此时点击选项不能选中，也不能取消选中。

4、选项描述为当行文本，超出部分自动省略。

预期效果：选择大熊猫，默认文本变为对大熊猫的种类（科）。

步骤：

每新建一个选项组组件就会生成一个组件变量，变量名与选项组组件的id相同，变量类型为字符串。这个变量用来存储已选中选项的选项值。

对选项进行配置，选项名称动物名称，选项值设为对动物种类（科）。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/60/v3/4fr2dd-1TteDETHwk1iGNw/zh-cn_image_0000002670264125.png?HW-CC-KV=V1&HW-CC-Date=20261008T143203Z&HW-CC-Expire=31536000000&HW-CC-Sign=E81129A9806DDF4E40B94C873724D262BF6BA546E651ED3A57ECB4FEC1329DCD)

给文本组件绑定上字符串变量description。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b5/v3/PBkJokbqQIC5uvlNzXCQgg/zh-cn_image_0000002640104294.png?HW-CC-KV=V1&HW-CC-Date=20261008T143203Z&HW-CC-Expire=31536000000&HW-CC-Sign=20A8E80B1AA6781721CC73C8EBDE70A9847297BB7B8A1DE6874422D2E3ADF648)

对选项组进行变化时事件配置，执行动作选择设置变量值，变量选为文本标签绑定的变量description，变量值选择组件变量DualSelect-0。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1b/v3/F98rzuS5TcaDheQzyRFMhA/zh-cn_image_0000002640264234.png?HW-CC-KV=V1&HW-CC-Date=20261008T143203Z&HW-CC-Expire=31536000000&HW-CC-Sign=E5002B506165BA0ABEADD7D6CC3EB77F363BCBCF6F2CDF76DB11F7225E5D2C53)

如果此时是多选模式，两个选项都被选中，默认文本就会变成是两个选项值以"，"拼接的情况。
