# 开放能力

华为服务号提供开放能力用于开发者系统与华为服务号对接。

## 能力介绍

服务号提供开放能力主要有关注/取消关注事件通知、发送模板消息、发送图文消息等功能。

1. 当有新用户关注或取消关注服务号时，平台会发送事件通知，开发者可获取到用户Openid。获取到用户Openid后，可以给用户通过模板消息发送服务通知，通过图文消息可以发送宣传和营销的文章。
2. 模板消息可以给关注用户发送服务通知。开发者可调用"模板消息回执"查询模板消息发送结果。
3. 图文消息可以实现文章创建、发送消息到华为服务号主页。

## 接入前提

1、开发者调用开放接口能力前， 服务号关联项目，设置相关的配置，操作步骤详见[设置开发者信息](https://developer.huawei.com/consumer/cn/doc/service/developer_information-0000002633581712)。

2、获取项目ID（**projectId** ），登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，选择"开发与服务"，在项目列表中选择对应的项目，在该页面获取。 需要与服务号"开发者信息设置"中配置的项目id保持一致。
