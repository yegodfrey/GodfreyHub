# Agent编排模式

小艺开放平台目前提供了6种Agent编排模式，开发者可根据需求场景、面向群体、功能复杂度等角度进行选择。

**端A2A模式：**端A2A模式支持应用内Agent与小艺Client Agent通信，基于端A2A协议实现端到端的轻量化对接。该模式适用于已具备鸿蒙端应用能力的开发者，可将Agent部署于本地设备，充分利用端侧算力与系统级API，实现低延迟、高隐私的智能交互体验。

**云A2A模式：**云A2A模式是一种三方Agent接入小艺开放平台的高效编排方式。开发者可通过该模式基于云A2A协议快速、便捷地将成熟的第三方Agent对接至小艺开放平台，实现分发与调用，提升平台的场景覆盖能力。该模式适用于同时具备鸿蒙端应用与云侧Agent能力的企业开发者。

**云工作流模式**：工作流模式是一种基于规则化流程的Agent编排方式。开发者将复杂任务拆解为有序的规则化步骤（如数据获取、处理、执行），串联插件、大模型、条件分支、代码块等组件实现自动化执行流程，完成业务逻辑。工作流模式适用于需多步骤协同、逻辑复杂、业务多样性的场景。

**OpenClaw模式：**OpenClaw模式是一种开放灵活的Agent接入与构建方式，开发者可通过该模式接入OpenClaw工具 ，快速创建个性化Agent。该模式适用于个性化助手、自动化服务、场景化应用等多样化需求。

**LLM模式**：LLM模式是一种基于大模型的Agent编排方式。开发者按需选择大模型，根据业务逻辑编写提示词，以 LLM 为理解中枢，结合意图识别、工具调用、对话上下文，动态选择插件、工作流，响应用户需求。 单Agent （LLM模式）适用于简单对话、知识问答、基础内容生成等场景。

**多Agents模式**：多Agents模式是一种基于大模型规划能力的Agent编排方式。开发者将复杂任务拆解为多个独立子任务，每个子任务由一个Agent承担，各Agent配置独立的角色指令、插件与工作流。在多Agents模式中配置多个子Agent，以LLM为任务规划中枢，结合用户需求、角色指令、子Agent描述，规划调用子Agent，高效解决逻辑复杂、业务多样性的场景。
