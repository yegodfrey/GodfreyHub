# 华为服务号接入指南

申请华为服务号，需要先注册开发者账号，且完成企业认证。目前服务号业务只支持境内企业，不支持境外企业申请。如果开发者有已认证的开发者账号，或者已做过元服务开发，则可以直接申请服务号。

* **[注册开发者账号](https://developer.huawei.com/consumer/cn/doc/service/register_account-0000002508822779)**   
* **[开通服务号](https://developer.huawei.com/consumer/cn/doc/service/real_name_authentication-0000002476702796)**   
* **[认证服务号与权益](https://developer.huawei.com/consumer/cn/doc/service/certified_service-0000002668317330)**   
* **[查询服务号审核状态](https://developer.huawei.com/consumer/cn/doc/service/create_service_account-0000002508942747)**
