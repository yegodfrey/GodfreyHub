# 更新子服务

1. 对于已通过审核、子服务状态为"已上架"的子服务，开发者可进行更新子服务的操作。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2e/v3/HmvzXhmxR0W2AZ77KIseow/zh-cn_image_0000002722801446.png?HW-CC-KV=V1&HW-CC-Date=20261008T190832Z&HW-CC-Expire=31536000000&HW-CC-Sign=F35F1F48593E3E9DF4B7766E135E8420829B393318AA5D86A2A1FC3FCABD8670 "点击放大")

   进行更新操作的方式有两种：
   * 在"子服务直达"页签中的操作栏点击"编辑"。
   * 在"子服务直达"页签中的操作栏点击"查看"后，再点击"编辑"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/18/v3/Jxp6G0XBQqWDD7UaFus7Ug/zh-cn_image_0000002752481247.png?HW-CC-KV=V1&HW-CC-Date=20261008T190832Z&HW-CC-Expire=31536000000&HW-CC-Sign=ADDA08494223A3E732CB36F97D9A248A4FAA0104B53D19C1F45B4296FF013B79 "点击放大")

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/35/v3/zfZkeemoRE2oyEL_jDIevg/zh-cn_image_0000002752561149.png?HW-CC-KV=V1&HW-CC-Date=20261008T190832Z&HW-CC-Expire=31536000000&HW-CC-Sign=A933A96993CC158F6F87411C05CB374D072B146213371EE05746CB32C8157C50 "点击放大")


2. 点击"编辑"后进入编辑页中，开发者可以对子服务的信息进行更新。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d4/v3/fnN0Z5KoRumSZi0WsOyjbA/zh-cn_image_0000002722801448.png?HW-CC-KV=V1&HW-CC-Date=20261008T190832Z&HW-CC-Expire=31536000000&HW-CC-Sign=1CF241B55414661A00A9C7CD3EB7F975E2461361633F217265AA6D1A0A2D4B50 "点击放大")


3. 更新完成后，点击"上架"，将更新后的子服务进行重新上架操作，由平台进行审核，子服务状态由"已上架"变更为"待审核"。 说明
   >
   > 子服务更新后，如果平台仍在审核当中，面向鸿蒙公域流量仅展示已上架子服务信息，不展示待审核状态的子服务信息。
