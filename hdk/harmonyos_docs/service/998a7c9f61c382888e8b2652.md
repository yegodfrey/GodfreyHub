# 真机测试

真机测试为开发者提供了在Skill上架前即可在端侧设备上体验Skill效果的能力，本文档旨在为用户进行Skill真机调试提供指导。

## **真机测试操作步骤**

在完成Skill开发后，可进行真机调试。真机测试发布后，可以修改内容进行重新发布。如果不再需要真机测试，可以取消发布。

**步骤1：在Skill开发界面右侧，选择真机测试用户组。勾选用于测试的群组。**

开发者（团队账户需管理员权限）可通过真机测试组来管理测试用户。发布至真机调试后，已勾选真机测试组中的用户可在小艺应用对话列表页中体验该Skill。

注：每个团队最多可创建100个用户组，每个用户组最多可添加100个用户。每次发布真机测试后有效期为15天，每次最大勾选10个用户组。
