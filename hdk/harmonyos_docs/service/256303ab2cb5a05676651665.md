# 批量新建子服务

1. 在服务直达主界面，选择"子服务"页签，点击"批量新建"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/24/v3/APjEM-LHRt6aK2wqreJ5_Q/zh-cn_image_0000002722801470.png?HW-CC-KV=V1&HW-CC-Date=20261008T160706Z&HW-CC-Expire=31536000000&HW-CC-Sign=B24424E672A276AA947227B0F001E6F2547504EE736E4D19BA6E6C7C4B3E7A82 "点击放大")

2. 点击"下载导入模板"。 按照导入模板要求填写信息。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/63/v3/-Fc0ErtMT_OERWE0le60NA/zh-cn_image_0000002722961396.png?HW-CC-KV=V1&HW-CC-Date=20261008T160706Z&HW-CC-Expire=31536000000&HW-CC-Sign=41E585C84C55B3D2CD62AC6EC7A9B46C466314438A070E93B0D9206C4BE1A94A "点击放大")
3. 点击"选择文件"。 选择保存后的表格文件。点击"上传"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f0/v3/6bz59T8XQV64Fk8YXBgqPA/zh-cn_image_0000002752481271.png?HW-CC-KV=V1&HW-CC-Date=20261008T160706Z&HW-CC-Expire=31536000000&HW-CC-Sign=046CD98A3D323AD4B0F35609743639A77E852E3AE0350C0B0077C0BF83A4C1D4 "点击放大")
4. 上传完成后，可在导入弹窗稍等片刻，查看导入结果。 此页面可查看导入成功数、导入失败数，并可点击"下载结果文件"下载以查询导入失败的原因。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/31/v3/6Gt1AHHcTCW-Wek407bwxA/zh-cn_image_0000002722801466.png?HW-CC-KV=V1&HW-CC-Date=20261008T160706Z&HW-CC-Expire=31536000000&HW-CC-Sign=9A301A70D0ABD5032AC2163C59D85A9927C781A2EF97D660F69EA3815901BDD4 "点击放大")
5. 导入完成后，可在子服务列表中查看子服务状态。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1b/v3/oqnXCAxVT26CoF-eKH_lBQ/zh-cn_image_0000002752561169.png?HW-CC-KV=V1&HW-CC-Date=20261008T160706Z&HW-CC-Expire=31536000000&HW-CC-Sign=F44C0D71BFCB665E7356AAF835311264982018C4DBC70DFB84B3EBD47B960B3F "点击放大")
