# 查询服务号审核状态

进入服务号列表页，可以查看服务号审核状态。

1、仍在审核中，请耐心等待审核结果。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9a/v3/saGRkTm_SaCrcNU6ZRooBg/zh-cn_image_0000002633581486.png?HW-CC-KV=V1&HW-CC-Date=20261008T191018Z&HW-CC-Expire=31536000000&HW-CC-Sign=23A555836AF03E0A9E3B354D36358B7267386C37E30E995DE5048E1918A9B03A "点击放大")

2、如果显示已驳回，可点击处理中的申请单，查看服务号详细的审核驳回原因。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/54/v3/p53qgTboQi-fAOcXR5AHXQ/zh-cn_image_0000002663700673.png?HW-CC-KV=V1&HW-CC-Date=20261008T191018Z&HW-CC-Expire=31536000000&HW-CC-Sign=6B6186761250B848E8A7DF46CCC29AFA8E40E37FD26649D1E1D28AC51EAAE147 "点击放大")

进入详情页头部有显示具体驳回原因，需要根据驳回原因重新修改信息。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/78/v3/90Mbd8RVSr64mi2PDeLCbg/zh-cn_image_0000002663780721.png?HW-CC-KV=V1&HW-CC-Date=20261008T191018Z&HW-CC-Expire=31536000000&HW-CC-Sign=DEFD0B97F8C8F324AF34AFE1592F8DE3ABD0A7897B645EC13886A336CEA62685 "点击放大")

当服务号申请被驳回，需要根据驳回原因进行信息修改。点击底部按钮"修改"发起信息修改。信息更改后重新提交审核。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a9/v3/dROz85x5TuWPD9t5w8utAg/zh-cn_image_0000002633421586.png?HW-CC-KV=V1&HW-CC-Date=20261008T191018Z&HW-CC-Expire=31536000000&HW-CC-Sign=0B4BC70B88584096D3370ECADBFD70D88369F57EDF522B7313CE89E4E540EC10 "点击放大")
