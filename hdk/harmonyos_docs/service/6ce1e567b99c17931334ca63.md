# 查询服务号审核状态

进入服务号列表页，可以查看服务号审核状态。

1、仍在审核中，请耐心等待审核结果。

![](https://media:201787729656993844 "点击放大")

2、如果显示已驳回，可点击处理中的申请单，查看服务号详细的审核驳回原因。

![](https://media:201787729657038845 "点击放大")

进入详情页头部有显示具体驳回原因，需要根据驳回原因重新修改信息。

![](https://media:201787729657073846 "点击放大")

当服务号申请被驳回，需要根据驳回原因进行信息修改。点击底部按钮"修改"发起信息修改。信息更改后重新提交审核。

![](https://media:201787729657118847 "点击放大")
