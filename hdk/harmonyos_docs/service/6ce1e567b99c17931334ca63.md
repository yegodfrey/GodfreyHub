# 查询服务号审核状态

进入服务号列表页，可以查看服务号审核状态。

1、仍在审核中，请耐心等待审核结果。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9a/v3/saGRkTm_SaCrcNU6ZRooBg/zh-cn_image_0000002633581486.png?HW-CC-KV=V1&HW-CC-Date=20260909T180800Z&HW-CC-Expire=31536000000&HW-CC-Sign=EB3AD9191A90B7D041AFE0C1DF6917DCD847DF22EF1971D76C0FD055AE9B8283 "点击放大")

2、如果显示已驳回，可点击处理中的申请单，查看服务号详细的审核驳回原因。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/54/v3/p53qgTboQi-fAOcXR5AHXQ/zh-cn_image_0000002663700673.png?HW-CC-KV=V1&HW-CC-Date=20260909T180800Z&HW-CC-Expire=31536000000&HW-CC-Sign=DD79075B147380E845CFFA88789B11E6E7A5C9854840475979F37DD05A2E4AEC "点击放大")

进入详情页头部有显示具体驳回原因，需要根据驳回原因重新修改信息。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/78/v3/90Mbd8RVSr64mi2PDeLCbg/zh-cn_image_0000002663780721.png?HW-CC-KV=V1&HW-CC-Date=20260909T180800Z&HW-CC-Expire=31536000000&HW-CC-Sign=CE3D4FE1B48C4B5A8DAD69B8C3B995569FD56DDA29E580E587DD1B9AE4009F4A "点击放大")

当服务号申请被驳回，需要根据驳回原因进行信息修改。点击底部按钮"修改"发起信息修改。信息更改后重新提交审核。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a9/v3/dROz85x5TuWPD9t5w8utAg/zh-cn_image_0000002633421586.png?HW-CC-KV=V1&HW-CC-Date=20260909T180800Z&HW-CC-Expire=31536000000&HW-CC-Sign=F13E440E1D7F1CE4654D29EB2588DD0AAE3774AD4CAFC50455BB6BEC566AEEAF "点击放大")
