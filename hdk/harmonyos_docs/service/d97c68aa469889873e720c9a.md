# 创建端插件

插件创建方式选择"端插件-直接创建"进行创建。

下拉选择APP包名（仅支持选择本账号在AppGallery Connect中存在的应用APP包名）。

插件描述尽可能描述清楚，大模型接收到用户的输入后，会根据插件的描述，调用与之匹配的插件。
