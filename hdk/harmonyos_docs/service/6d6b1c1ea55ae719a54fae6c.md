# 配额管理节点

配额管理节点用于对计数变量进行原子化赋值操作。支持对计数变量进行资源扣减、调用管控。

节点配置说明  

|配置|说明|
|:---|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|设置变量|变量：待操作的计数变量； 设置值：操作步长，整型，可配置负数实现递减。|
|限额|配额的上限阈值，若赋值后超过此值，触发限额。|
|输出|counterVariable: 计数变量在赋值操作后的新值。 errorMessage: 组件执行发生异常时返回的错误信息。 resultStatus: 表示组件执行结果的状态，取值为以下枚举之一： - success: 计数变量赋值成功； - quotas: 超出限额，此时计数变量值不变； - error: 组件执行异常，此时计数变量值不变。|
