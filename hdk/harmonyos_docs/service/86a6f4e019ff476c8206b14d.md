# 创建知识库

在小艺开放平台页面，通过【资源库】-【知识库】-【新建知识库】，进入新建知识库流程。

PS：若勾选【授权该知识库用于小艺知识问答，授权后该小艺对话可以使用该知识库】，该数据库上架审核周期为1-3个工作日。

![](https://media:301785143808029348 "点击放大")

当前平台支持四种导入方式新建知识：

1. 导入方式-文档：使用文档形式导入知识数据，可以配置引用源信息；
2. 导入方式-图片：使用图片形式导入知识数据，可以配置引用源信息，可以选择对图片智能标注；
3. 导入方式-数据源：配置接口的形式导入知识数据，按提示填写相关信息；
4. 导入方式-爬虫：填写爬取地址，配置爬取周期自动爬取所需的知识数据。
