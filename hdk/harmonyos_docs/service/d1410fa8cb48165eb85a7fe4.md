# 智能体数字商品支付服务收费调测

**1.** **配置测试接口，可参考[订单通知&权益查询](https://developer.huawei.com/consumer/cn/doc/service/service-configuration-0000002537721283#section86943511115)。**

开发者服务器需要对来自于正式/测试接口的请求做状态区分（基于url或者入参purchaseTest判断），基于不同状态做相应的适配。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d1/v3/iWRYgmIPSzy5DJvOW3G8gg/zh-cn_image_0000002670263931.png?HW-CC-KV=V1&HW-CC-Date=20260924T081230Z&HW-CC-Expire=31536000000&HW-CC-Sign=EDB2C91C4303CFAF47E3F97412D847BE2196B10D9E8D5C26EB6D3595991D4FEE "点击放大")·

**2. 测试时商品说明**

测试使用已保存的最新商品数据，不需要上架。

测试商品按照默认的顺序展示，不支持基于【端侧商品展示】配置排序。

**3. [配置测试白名单](https://developer.huawei.com/consumer/cn/doc/service/list-of-user-groups-for-real-machine-testing-0000002471264273)，配置收费调测的白名单测试组，打开【模拟付费验证功能】开关。**

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c8/v3/SuU8an2TTAOVeJN4bNvoaQ/zh-cn_image_0000002640264040.png?HW-CC-KV=V1&HW-CC-Date=20260924T081230Z&HW-CC-Expire=31536000000&HW-CC-Sign=852EA32CA4F24C67284C1D655210A5AB52C4217A92DF083DE5ACC292AA4892CE "点击放大")

**4. 发布真机测试** **，在智能体编排页的【调试与预览】界面下，点击右上角的手机图标发布真机测试** **。**

仅针对已打开【模拟付费验证功能】开关的测试组生效。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/96/v3/QkxggcDBQn6oXj0XSQzL4g/zh-cn_image_0000002670263929.png?HW-CC-KV=V1&HW-CC-Date=20260924T081230Z&HW-CC-Expire=31536000000&HW-CC-Sign=5B517A72ED366F9F35754D150EDC6209ED6534AF9A8A9FD0944ECB4B6A00FC59 "点击放大")

**5. 开启真机测试** **，进入小艺对话页，找到测试智能体即可进行测试验证，具体流程可参考下图。**

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5f/v3/y7-yB9boSW-ietI4-i0Kgg/zh-cn_image_0000002670263927.png?HW-CC-KV=V1&HW-CC-Date=20260924T081230Z&HW-CC-Expire=31536000000&HW-CC-Sign=EC80619C35F8B06A70CDA53B3FCA5A3E1DE51EB9415AD20CFE12C18D597B2E6E "点击放大")

**6.** **支持在【配置】-【商品管理】-【测试交易明细】查看测试交易明细和触发【补发】、【退款】操作来进行调试。**
