# 批量变更门店

1. 在服务直达主界面，选择"门店管理"页签，根据门店状态或门店名称/编码筛选出需要变更的门店。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d0/v3/PxCsUgzRSMaVw_FEuY4lUQ/zh-cn_image_0000002722961390.png?HW-CC-KV=V1&HW-CC-Date=20261008T144435Z&HW-CC-Expire=31536000000&HW-CC-Sign=38646E55C87D6986A16810783D4F02AD86D538BFCA49ED93B0C85F555803AFFF "点击放大")

2. 点击"导出"。
   * 没有勾选项时，点击"导出"可导出全部门店。
   * 存在已勾选的门店时，点击"导出"仅导出已勾选门店。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4a/v3/5eHUH9LuSC20Q2Eys4Xh8w/zh-cn_image_0000002752481269.png?HW-CC-KV=V1&HW-CC-Date=20261008T144435Z&HW-CC-Expire=31536000000&HW-CC-Sign=5AA6AE81E6A09CFF7944B76FA462C3AC42146CD61D7873CC5F55FA5BC52FD2B4 "点击放大")
3. 导出完成后，点击"任务管理"，下载导出结果。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3b/v3/BHuURXNKT96CoBKm6j6-QQ/zh-cn_image_0000002722961394.png?HW-CC-KV=V1&HW-CC-Date=20261008T144435Z&HW-CC-Expire=31536000000&HW-CC-Sign=0047B132E71B6E2252A5E43EF551DECD5F02F7F0F18FDFEBD3927809E247E432 "点击放大")

4. 编辑表格，修改门店信息。
5. 点击"服务直达",返回"门店管理"页签。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a2/v3/ORE-QM9jTD-f2QjnWAp-zQ/zh-cn_image_0000002752481273.png?HW-CC-KV=V1&HW-CC-Date=20261008T144435Z&HW-CC-Expire=31536000000&HW-CC-Sign=512B5CF4B8E4541FB9415780266E52890A7262F9689A7321C28A396BC837F34D)

6. 点击"批量变更"，上传编辑后的表格文件，点击"上传"按钮。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/21/v3/-bGSOxABQDGEww0pkNEuEw/zh-cn_image_0000002722961392.png?HW-CC-KV=V1&HW-CC-Date=20261008T144435Z&HW-CC-Expire=31536000000&HW-CC-Sign=F4E05276B60076F71FBBE8AB2FEDF6E9F829B05182289E3BD5C09B41CC66DE4D "点击放大")
