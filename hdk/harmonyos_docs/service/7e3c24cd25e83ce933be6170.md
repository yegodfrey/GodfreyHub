# 长时任务伴随

## Agent创建长时任务UI

Agent进行长时任务时，通过小艺创建任务UI（含对话胶囊、状态胶囊、对话面板，用于对用户展示任务过程信息，支持用户关闭任务）。

小艺发起query，Agent返回uiSession CREATE。小艺在UI准备完成后发送uiSession READY ，Agent直接进入TASK_STATE_WORKING开始执行任务。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/41/v3/sc3Yb0zVTxiIgVdL68gA7A/zh-cn_image_0000002670263963.png?HW-CC-KV=V1&HW-CC-Date=20260924T081231Z&HW-CC-Expire=31536000000&HW-CC-Sign=1020721BC7498AF0061F53C985A1EC9CE46F9B23B99097E6603F5C349CB17C4F "点击放大")

小艺发起文本query（小艺发送至Agent）：

```codeblock
{
  "jsonrpc":"2.0",
  "id":"req-001",
  "method":"MessageStream",
  "params":{
    "message":{
      "messageId":"msg-001",
      "contextId":"ctx-001",
      "role":"ROLE_USER",
      "parts":[
        {
          "text":"帮我查一下最新的快递状态",
          "mediaType":"text/plain"
        }
      ]
    },
    "metadata":{
      "traceId":"trace-7f8a2b3c-0001",
      "agentId":"agent-example-001",
      "appVersion":"12.0.1"
    }
  }
 }
```

内容为连续的两帧：

```codeblock
{
   "jsonrpc":"2.0",
   "id":"req-001",
   "result":{
     "artifactUpdate":{
       "taskId":"task-001",
       "contextId":"ctx-001",
       "artifact":{
         "artifactId":"art-uisession-001",
         "parts":[
           {
             "data":{
               "uiSession":{
                 "action":"CREATE",
                 "config":{
                   "initialText":"正在创建XX任务",
                   "jump":{
                     "deepLink":{
                         "url":"example://transfer",
                         "appName":"示例应用",
                         "appPackage":"com.example.app",
                         "minVersion":"1.0.0"
                     }
                   }
                 }
               }
             }
           }
         ]
       },
       "append":false,
       "lastChunk":true
     },
     "metadata":{
       "traceId":"trace-7f8a2b3c-0001",
       "agentId":"agent-example-001",
       "agentVersion":"1.2.0"
     }
   }
 }
```

Agent发起uiSession（Agent发送至小艺）：

```codeblock
{
   "jsonrpc":"2.0",
   "id":"req-001",
   "result":{
     "task":{
       "id":"task-001",
       "contextId":"ctx-001",
       "status":{
         "state":"TASK_STATE_SUBMITTED",
         "timestamp":"2026-03-04T10:24:00.000Z"
       }
     },
     "metadata":{
       "traceId":"trace-7f8a2b3c-0001",
       "agentId":"agent-example-001",
       "agentVersion":"1.2.0"
     }
   }
 }
```

小艺确认就绪（小艺发送至Agent）：

```codeblock
{
   "jsonrpc":"2.0",
   "id":"req-002",
   "method":"MessageStream",
   "params":{
     "message":{
       "messageId":"msg-002",
       "taskId":"task-001",
       "contextId":"ctx-001",
       "role":"ROLE_USER",
       "parts":[
         {
           "data":{
             "uiSession":{
               "action":"READY",

           }
         }

     },
     "metadata":{
       "traceId":"trace-7f8a2b3c-0002",
       "agentId":"agent-example-001",
       "appVersion":"12.0.1"
     }
   }
 }
```

Agent确认开始任务（Agent发送至小艺）：

```codeblock

   "jsonrpc":"2.0",
   "id":"req-002",
   "result":{
     "statusUpdate":{
       "taskId":"task-001",
       "contextId":"ctx-001",
       "status":{
         "state":"TASK_STATE_WORKING",
         "message":{
           "role":"ROLE_AGENT",
           "messageId":"msg-002",

             {

             }
           ]
         },
         "timestamp":"2026-03-24T10:00:02.000Z"
       }
     },
     "metadata":{
       "traceId":"trace-7f8a2b3c-0002",
       "agentId":"agent-example-001",

 }
```

## Agent 进行播报与澄清

Agent可播报操作信息，或者要求用户参与问题澄清，文本将在对话胶囊中呈现。

Agent播报（Agent发送至小艺）：

```codeblock
{
   "jsonrpc":"2.0",
   "id":"req-001",
   "result":{
     "artifactUpdate":{
       "taskId":"task-001",
       "contextId":"ctx-001",
       "artifact":{
         "artifactId":"art-text-001",
         "parts":[
           {
             "text":"正在为您操作" ,
             "mediaType":"text/plain"
           }
         ]
       },
       "append":true,
       "lastChunk":false
     },
     "metadata":{
       "traceId":"trace-7f8a2b3c-0001",
       "agentId":"agent-example-001",
       "agentVersion":"1.2.0"
     }
   }
 }
```

Agent发起澄清（Agent发送至小艺）：

```codeblock
{
   "jsonrpc":"2.0",

     },
     "metadata":{
       "traceId":"trace-7f8a2b3c-0001",
```

## Agent 更新任务进展

Agent通过CAPSULE_UPDATE更新状态胶囊文字（Agent发送至小艺）：

```codeblock
{
   "jsonrpc":"2.0",
   "id":"req-001",
   "result":{
     "artifactUpdate":{
       "taskId":"task-001",
       "contextId":"ctx-001",
       "artifact":{
         "artifactId":"art-capsule-001",
         "parts":[
           {
             "data":{
               "uiSession":{
                 "action":"CAPSULE_UPDATE",
                 "capsuleText":"正在查询快递信息"
               }
             }
           }
         ]
       },
       "append":false,
       "lastChunk":true
     },
     "metadata":{
       "traceId":"trace-7f8a2b3c-0001",
       "agentId":"agent-example-001",
       "agentVersion":"1.2.0"
     }
   }
 }
```

## Agent 完成任务退出

Agent完成任务后申请关闭uiSession，小艺确认后Agent返回TASK_STATE_COMPLETED。

Agent发起关闭（Agent发送至小艺）：

```codeblock
{
   "jsonrpc":"2.0",
   "id":"req-001",
   "result":{
     "artifactUpdate":{
       "taskId":"task-001",
       "contextId":"ctx-001",
       "artifact":{
         "artifactId":"art-uisession-005",
         "parts":[
           {
             "data":{
               "uiSession":{
                 "action":"DESTROY_APPLY"
               }
             }
           }
         ]
       },
       "append":false,
       "lastChunk":true
     },
     "metadata":{
       "traceId":"trace-7f8a2b3c-0001",
       "agentId":"agent-example-001",
       "agentVersion":"1.2.0"
     }
   }
 }
```

小艺确认关闭（小艺发送至Agent）：
