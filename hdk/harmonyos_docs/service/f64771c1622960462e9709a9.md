# 插件

插件是一个工具集，一个插件内可以包含一个或多个工具（API）。添加插件可以帮助开发者拓展Agent能力边界。

此处为开发者介绍如何在Agent中添加/配置插件，插件开发指南请参考[开发插件](https://developer.huawei.com/consumer/cn/doc/service/develop-plug-ins-0000002435989648)。
