# 批量变更门店

1. 在服务直达主界面，选择"门店管理"页签，根据门店状态或门店名称/编码筛选出需要变更的门店。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5c/v3/8hmNXIliSAOsWq356A7McQ/zh-cn_image_0000002752561135.png?HW-CC-KV=V1&HW-CC-Date=20261008T183936Z&HW-CC-Expire=31536000000&HW-CC-Sign=B39308E987556D51B300D4576C0DC2364B9A3E6CB31C4D1F65E2363799EDECD2 "点击放大")

2. 点击"导出"。
   * 没有勾选项时，点击"导出"可导出全部门店。
   * 存在已勾选的门店时，点击"导出"仅导出已勾选门店。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ee/v3/71ntGaG_TPqtLBxVzCSsAA/zh-cn_image_0000002722801430.png?HW-CC-KV=V1&HW-CC-Date=20261008T183936Z&HW-CC-Expire=31536000000&HW-CC-Sign=717B6AB4D5F833A642900D0E5AABA1EBF9AB5F4343EF5C56F7997523F43F05C1 "点击放大")
3. 导出完成后，点击"任务管理"，下载导出结果。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7/v3/j3wX1zfuQsy46FzzM8IJ5A/zh-cn_image_0000002752561129.png?HW-CC-KV=V1&HW-CC-Date=20261008T183936Z&HW-CC-Expire=31536000000&HW-CC-Sign=7D2E8799EA8753692E2465219474FB41650EFAA673C0750D2D8A443153025C5E "点击放大")

4. 编辑表格，修改门店信息。
5. 点击"服务直达",返回"门店管理"页签。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f0/v3/Pxpo8rN3Txu-MrkffPcJtQ/zh-cn_image_0000002722961356.png?HW-CC-KV=V1&HW-CC-Date=20261008T183936Z&HW-CC-Expire=31536000000&HW-CC-Sign=7B032899B8CF04531FEFAF55247B9B1152A5D3ABF71B86A3F08A4973A57F503F)

6. 点击"批量变更"，上传编辑后的表格文件，点击"上传"按钮。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/26/v3/bwTzpnvJQW-vD5nKw4fcOQ/zh-cn_image_0000002722801426.png?HW-CC-KV=V1&HW-CC-Date=20261008T183936Z&HW-CC-Expire=31536000000&HW-CC-Sign=DAA6DEEF6FA534A17CDA058EB846F191C7D14629FB82D6078B7140D10DDE2FA6 "点击放大")
