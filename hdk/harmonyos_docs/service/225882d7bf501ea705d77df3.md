# 评测

小艺罗盘评测模块为开发者提供系统化智能体评测能力。支持对输出结果在简洁性、相关性、创造性等多维度进行自动化评估，内置多种评估规则，支持快速构建评测数据集。实现从输入到输出的全链路质量验证，助力开发者提升智能体的研发效率与稳定性。
