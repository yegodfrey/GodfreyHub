# 更新服务卡片（FormKit）

1. 对于状态为"已上架"、"已下架"、"审核驳回"、"草稿"的FormKit卡可被编辑，点击列表操作列"编辑"后进入编辑页中，开发者可以对子服务的信息进行更新。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/50/v3/8pDTSLGTSwybtF4NYG7bgw/zh-cn_image_0000002722961424.png?HW-CC-KV=V1&HW-CC-Date=20261008T160103Z&HW-CC-Expire=31536000000&HW-CC-Sign=CFD2ABC28C095A164B54F073B165A423B1C7038AAB3F5887F18720C69791F0F1 "点击放大")

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/72/v3/4digN-ukT3e9gZLLyNTQzQ/zh-cn_image_0000002722801502.png?HW-CC-KV=V1&HW-CC-Date=20261008T160103Z&HW-CC-Expire=31536000000&HW-CC-Sign=BA35515A0DF0F2DFFCEC8E3BA8913B04FF8048684880206223CC648BE00CBA5D "点击放大")
2. 更新完成后，点击"提交"，将更新后的FormKit卡进行重新上架操作，由平台进行审核，FormKit卡状态由"已上架"变更为"待审核"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e9/v3/pnINvzLIR5KqlukN9u4gPQ/zh-cn_image_0000002752481303.png?HW-CC-KV=V1&HW-CC-Date=20261008T160103Z&HW-CC-Expire=31536000000&HW-CC-Sign=1B28EF1AF5E7D78D4B3154E19EA536C18F68C46C48F42E02FFBDA675A58D35B0 "点击放大") 说明
   >
   > FormKit卡更新后，如果平台仍在审核当中，面向鸿蒙公域流量仅展示已上架FormKit卡信息，不展示待审核状态的FormKit卡信息。
