# 批量导出商品

1. 在服务直达主界面，选择"商品直达"页签，根据商品状态或商品名称筛选出需要导出的商品。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6a/v3/sFH8_MUrQWCps2twgErxDg/zh-cn_image_0000002722961370.png?HW-CC-KV=V1&HW-CC-Date=20261008T161923Z&HW-CC-Expire=31536000000&HW-CC-Sign=9163E92D75768F075B04CAAD77DFC296204255C39FB66D29EA8E72B84DAEC63F "点击放大")

2. 点击"导出"。
   * 没有勾选项时，点击"导出"可导出全部商品。
   * 存在已勾选商品时，点击"导出"仅导出已勾选商品。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/78/v3/Cdn79fFDSuKCLOE9H6Jd-w/zh-cn_image_0000002722801442.png?HW-CC-KV=V1&HW-CC-Date=20261008T161923Z&HW-CC-Expire=31536000000&HW-CC-Sign=826C01660A537E4FD5A0B4E01149AABB6B8D1FF4E4D52E4135384B84DECFC1B6 "点击放大")
3. 导出完成后，点击"任务管理"，下载导出结果。
