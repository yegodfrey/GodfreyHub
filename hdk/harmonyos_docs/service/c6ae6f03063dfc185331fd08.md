# 多页签组件用法

一、子页签个数允许设置固定个数和绑定变量。

切换子页签数量的类型会导致页签组件的所有子页签内容清空，请提前考虑好页签数量类型，谨慎切换。

点击切换子页签数量模式时，将弹出提示框确认是否更改：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/75/v3/T8WmPg82QxiANNnIYVH1-w/zh-cn_image_0000002670264023.png?HW-CC-KV=V1&HW-CC-Date=20260924T081231Z&HW-CC-Expire=31536000000&HW-CC-Sign=55412AC2BEBAAD47CAF5E03D7F01E3CF483888E4D0BF1ABF03B3EB5A1373C741 "点击放大")

1、固定个数

需要手动输入每个子页签的名称，点击编辑按钮可以配置子页签的交互属性和图标内容，图标内容非必填。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e/v3/4jqbnvjXR26dUv8jo_HUtg/zh-cn_image_0000002640104198.png?HW-CC-KV=V1&HW-CC-Date=20260924T081231Z&HW-CC-Expire=31536000000&HW-CC-Sign=B76FF66A799C272007A9843240DC947514C36A3814A1F265F421123CF5025B19)

允许每个子页签下配置不同的内容，拖入组件配置即可，点击切换按钮，可以切换当前编辑的子页签。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/26/v3/Nj4XwEuiR-6DqsnNjV_Cnw/zh-cn_image_0000002640264134.png?HW-CC-KV=V1&HW-CC-Date=20260924T081231Z&HW-CC-Expire=31536000000&HW-CC-Sign=892F76FCF140BD7FDDC9DD887185E8C8C7C7418A021DD1679D1746FBB908AD13)

允许删除和新增子页签。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/53/v3/GcVTQY9MT5K1L6zKl3VCPw/zh-cn_image_0000002670104169.png?HW-CC-KV=V1&HW-CC-Date=20260924T081231Z&HW-CC-Expire=31536000000&HW-CC-Sign=DC5A36A5B4C12BA8031E023388486A356FD13F02FA10B9624044A5903C6EB5CA)

默认选中子页签指的是卡片在端侧展示的时候的初始子页签，仅用于下发给端侧的字段，不影响云侧显示。

2、绑定变量

整个页签绑定一个数组变量，然后每个子页签的名称、可交互属性、图标、子页签具体内容绑定数组里的子元素的属性，类似列表，每个子页签的构成组件完全相同，具体值不同。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1c/v3/QFuMrK0ORO-A1LMp7XDFRw/zh-cn_image_0000002640104196.png?HW-CC-KV=V1&HW-CC-Date=20260924T081231Z&HW-CC-Expire=31536000000&HW-CC-Sign=8F09CB7E39998FCE6CBC38756BE09FAFC19A6C33A868B6ECBBEF07FF56C918AB)

编辑子页签选框，等同于固定个数类型的切换按钮，用于切换不同的子页签预览。

默认选中子页签，等同于固定个数的默认选中子页签，用于卡片在端侧展示的时候的初始子页签，仅用于下发给端侧的字段，不影响云侧显示。
