# 多页签组件用法

一、子页签个数允许设置固定个数和绑定变量。

切换子页签数量的类型会导致页签组件的所有子页签内容清空，请提前考虑好页签数量类型，谨慎切换。

点击切换子页签数量模式时，将弹出提示框确认是否更改：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/75/v3/T8WmPg82QxiANNnIYVH1-w/zh-cn_image_0000002670264023.png?HW-CC-KV=V1&HW-CC-Date=20260909T141657Z&HW-CC-Expire=31536000000&HW-CC-Sign=A3907C018B8AFAFC930FFCA69AEC16CBC894C2CE1AB5F2744D91923CF516535E "点击放大")

1、固定个数

需要手动输入每个子页签的名称，点击编辑按钮可以配置子页签的交互属性和图标内容，图标内容非必填。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e/v3/4jqbnvjXR26dUv8jo_HUtg/zh-cn_image_0000002640104198.png?HW-CC-KV=V1&HW-CC-Date=20260909T141657Z&HW-CC-Expire=31536000000&HW-CC-Sign=448A99644E7AC4E650D147124D75371E2CCEBA41DC783B06A3E1AAC59C761302)

允许每个子页签下配置不同的内容，拖入组件配置即可，点击切换按钮，可以切换当前编辑的子页签。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/26/v3/Nj4XwEuiR-6DqsnNjV_Cnw/zh-cn_image_0000002640264134.png?HW-CC-KV=V1&HW-CC-Date=20260909T141657Z&HW-CC-Expire=31536000000&HW-CC-Sign=116A7E3BB28EE43A02CD85FBBF56360B02C6AAE09137D817875E4824DCA0581D)

允许删除和新增子页签。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/53/v3/GcVTQY9MT5K1L6zKl3VCPw/zh-cn_image_0000002670104169.png?HW-CC-KV=V1&HW-CC-Date=20260909T141657Z&HW-CC-Expire=31536000000&HW-CC-Sign=8D16F61A592309F311A02B730016E7FD6018ECD7AFC29403D7EFF39FADF90B38)

默认选中子页签指的是卡片在端侧展示的时候的初始子页签，仅用于下发给端侧的字段，不影响云侧显示。

2、绑定变量

整个页签绑定一个数组变量，然后每个子页签的名称、可交互属性、图标、子页签具体内容绑定数组里的子元素的属性，类似列表，每个子页签的构成组件完全相同，具体值不同。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1c/v3/QFuMrK0ORO-A1LMp7XDFRw/zh-cn_image_0000002640104196.png?HW-CC-KV=V1&HW-CC-Date=20260909T141657Z&HW-CC-Expire=31536000000&HW-CC-Sign=87C9B84021CA36686F76A19E9CDCA6851B5A89AC41B914C3F26F34F095195159)

编辑子页签选框，等同于固定个数类型的切换按钮，用于切换不同的子页签预览。

默认选中子页签，等同于固定个数的默认选中子页签，用于卡片在端侧展示的时候的初始子页签，仅用于下发给端侧的字段，不影响云侧显示。
