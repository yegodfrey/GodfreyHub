# 更新个性化设置

对于已通过审核、个性化设置状态为"已上架"的个性化设置，开发者可进行更新个性化设置的操作。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/44/v3/dG18_4isSk-GyKwFWXm0Sw/zh-cn_image_0000002752481219.png?HW-CC-KV=V1&HW-CC-Date=20261008T152336Z&HW-CC-Expire=31536000000&HW-CC-Sign=99862F25AC6F51975BFEA47C9819F2C9A2C3F9AEFEE3008A061DC5BE057244A9 "点击放大")

进行更新操作的方式有两种：

* 在"个性化设置"页签中的操作栏点击"编辑"。
* 在"个性化设置"页签中的操作栏点击"查看"后，再点击"编辑"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2e/v3/UnCinRUISj-sdUUnF3Posw/zh-cn_image_0000002722961342.png?HW-CC-KV=V1&HW-CC-Date=20261008T152336Z&HW-CC-Expire=31536000000&HW-CC-Sign=D8F32D46734EC2081651DABECE52C3CF0645C9BCBA9C7A693A2CAD15E83DFC23 "点击放大")

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/49/v3/kcp8hZyiSL6qW-FhU58JNw/zh-cn_image_0000002722961340.png?HW-CC-KV=V1&HW-CC-Date=20261008T152336Z&HW-CC-Expire=31536000000&HW-CC-Sign=C98034CB45061C52ACD2DCD95345322721DF11214AAD521AF7BA2895B0A03825 "点击放大")

1. 点击"编辑"后进入编辑页中，开发者可以对个性化设置的信息进行更新。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/24/v3/cgoSzKcwS8mB7LKhf4zeOA/zh-cn_image_0000002752481221.png?HW-CC-KV=V1&HW-CC-Date=20261008T152336Z&HW-CC-Expire=31536000000&HW-CC-Sign=6F6158CABD49B8175D979A7741C78473A4DBE9D00EAD43D489563B5039F6A2F3 "点击放大")

2. 点击"上架"，将更新后的个性化设置进行重新上架操作，由平台进行审核，个性化设置状态由"已上架"变更为"待审核"。 说明
   >
   > 个性化设置更新后，如果平台仍在审核当中，面向鸿蒙公域流量仅展示已上架个性化设置，不展示待审核状态的个性化设置。
