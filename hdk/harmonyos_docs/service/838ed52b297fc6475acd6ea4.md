# 更新子服务

1. 对于已通过审核、子服务状态为"已上架"的子服务，开发者可进行更新子服务的操作。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5f/v3/43taQY01Q7O2JCyoj22KpA/zh-cn_image_0000002722801422.png?HW-CC-KV=V1&HW-CC-Date=20261008T155314Z&HW-CC-Expire=31536000000&HW-CC-Sign=09CC1C7988FA53AB6F75FE21F5227440DC5C50D5E24A89584E2C40D2D02D4C79 "点击放大")

   进行更新操作的方式有两种：
   * 在"子服务直达"页签中的操作栏点击"编辑"。
   * 在"子服务直达"页签中的操作栏点击"查看"后，再点击"编辑"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a4/v3/s3-jM9_RSO6lYgPaq1DvRw/zh-cn_image_0000002722801420.png?HW-CC-KV=V1&HW-CC-Date=20261008T155314Z&HW-CC-Expire=31536000000&HW-CC-Sign=A0CBAA3995FCACEB1EFD42FF02BD6ED015981F500FA3AA7BEF1B7ED1ADD01A98 "点击放大")

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3e/v3/HSqc_m2BQ6qcfXgw4B1SWQ/zh-cn_image_0000002752561123.png?HW-CC-KV=V1&HW-CC-Date=20261008T155314Z&HW-CC-Expire=31536000000&HW-CC-Sign=205930E6DAA38220A1D9355A09F2752631A82C395A1086681CA682B93BE02A16 "点击放大")


2. 点击"编辑"后进入编辑页中，开发者可以对子服务的信息进行更新。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c1/v3/BYYyxGpETB-G3H_EDiYYyw/zh-cn_image_0000002752561121.png?HW-CC-KV=V1&HW-CC-Date=20261008T155314Z&HW-CC-Expire=31536000000&HW-CC-Sign=52EE3609B4AD8194A031A64848665F3432CEC2672E8493EA8DE619DD9C021F87 "点击放大")


3. 更新完成后，点击"上架"，将更新后的子服务进行重新上架操作，由平台进行审核，子服务状态由"已上架"变更为"待审核"。 说明
   >
   > 子服务更新后，如果平台仍在审核当中，面向鸿蒙公域流量仅展示已上架子服务信息，不展示待审核状态的子服务信息。
