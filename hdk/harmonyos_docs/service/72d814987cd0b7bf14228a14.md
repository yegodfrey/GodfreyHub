# 界面操控伴随

## 小艺创建界面操控UI

对于只支持屏幕操控的Agent，可由小艺在首次对话时默认发起屏幕操控。小艺完成UI创建后直接发送READY开启 。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/84/v3/rIDGwZq0QwK0JwixmyRBbg/zh-cn_image_0000002640264072.png?HW-CC-KV=V1&HW-CC-Date=20260909T170955Z&HW-CC-Expire=31536000000&HW-CC-Sign=808EB0EE99F541AA36BC749815A10018B7BBA372FA21F59F49B04FB72F0E7C2D "点击放大")

小艺发送READY（小艺发送至Agent，不携带taskId）：

```codeblock
{
  "jsonrpc":"2.0",
  "id":"req-001",
  "method":"MessageStream",
  "params":{
    "message":{
      "messageId":"msg-001",
      "contextId":"ctx-001",
      "role":"ROLE_USER",
      "parts":[
        {
          "data":{
            "uiSession":{
              "action":"READY",
              "uiSessionState":"AGENT_CONTROL"
            }
          }
        },
        {
          "text":"帮我操作",
          "mediaType":"text/plain"
        }
      ]
    },
    "metadata":{
      "traceId":"trace-7f8a2b3c-0001",
      "agentId":"agent-example-001",
      "appVersion":"12.0.1"
    }
  }
 }
```

Agent确认开始操控（Agent发送至小艺，分配新taskId）：

```codeblock
{
   "jsonrpc":"2.0",
   "id":"req-001",
   "result":{
     "task":{
       "id":"task-001",
       "contextId":"ctx-001",
       "status":{
         "state":"TASK_STATE_SUBMITTED",

     "metadata":{
       "traceId":"trace-7f8a2b3c-0001",
       "agentId":"agent-example-001",
       "agentVersion":"1.2.0"
     }
   }
 }
```

## Agent自主进行TTS播报

屏幕操控模式下，Agent可自主进行TTS播报（此时小艺不进行播报），该功能受限开放，如果有需要，请联系华为工作人员开启。

* Agent TTS播报完毕，发送tts.action=STOPPED通知小艺（如需提前开启收音）。
* 用户触发打断，小艺发送tts.action=STOP要求Agent停止TTS播报。

### 场景一：用户打断，小艺要求Agent停止TTS播报

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/12/v3/mQDD6PLWQQeb5OAKgjIR5Q/zh-cn_image_0000002640104128.png?HW-CC-KV=V1&HW-CC-Date=20260909T170955Z&HW-CC-Expire=31536000000&HW-CC-Sign=7814C0688EBEB53E1121DD38E1529CF251DAA31986E5594428158599B49B448F "点击放大")

### 场景二：Agent TTS播报完毕，通知小艺提前开启收音

Agent进入TASK_STATE_INPUT_REQUIRED状态，返回澄清文本并同步自主TTS播报。Agent TTS播报完毕后，通过tts.action=STOPPED通知小艺，小艺提前开启收音等待用户回答。
