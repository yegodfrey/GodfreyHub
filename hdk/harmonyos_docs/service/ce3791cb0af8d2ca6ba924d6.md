# 配置指南

服务特点简介的配置指南如下：

（一）在服务分发增长>服务特点简介，点击新建。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a5/v3/LrAPRjebSGyWVJCXntfwxA/zh-cn_image_0000002538594451.png?HW-CC-KV=V1&HW-CC-Date=20261008T183756Z&HW-CC-Expire=31536000000&HW-CC-Sign=0627F52FD24A0DC224530548FC1B75FD7A5B77AB425DACB288328E9C51584D94)

（二）商家可以填写申请名称、元服务描述、选择分发日期、上传元服务图标，内容填写完成后可以通过右侧看到预览效果，同时也可以通过现网测试进行现网查看效果，预览无误后点击提交审核。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9e/v3/v85FioDqSD2zE0qbhEzDeA/zh-cn_image_0000002505495944.png?HW-CC-KV=V1&HW-CC-Date=20261008T183756Z&HW-CC-Expire=31536000000&HW-CC-Sign=05BFA825BAAD0DA5CAA895F7454D7E94E249B1DDFF749361539886BD19CF812B)

（三）审核通过且在分发日期内就可以在负一屏搜索结果和服务市场生效。
