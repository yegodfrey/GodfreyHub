# 其他结构定义

#### jump跳转结构

uiSession.config.jump 、suggestions\[\].jump、data.jump共用此结构。两种跳转方式可共存，按优先级顺序依次尝试：executeIntent发送至deepLink。  

|字段名|类型|方向|必填|说明|
|:------------------------|:-----|:---------|:-----|:-----------------------|
|executeIntent.bundleName|string|Agent发送至小艺|是（使用时）|应用包名|
|executeIntent.intentName|string|Agent发送至小艺|是（使用时）|Intent名称|
|executeIntent.executeMode|string|Agent发送至小艺|否|执行模式，如foreground|
|executeIntent.intentParam|object|Agent发送至小艺|否|Intent参数|
|deepLink.url|string|Agent发送至小艺|是（使用时）|深链URL|
|deepLink.appName|string|Agent发送至小艺|否|应用名称|
|deepLink.appPackage|string|Agent发送至小艺|否|应用包名|
|deepLink.minVersion|string|Agent发送至小艺|否|最低版本要求|
|overlayMode|string|Agent发送至小艺|否|是否跳转APP后，以onAPP形态覆盖在APP上|

jump结构示例：

```
{
  "executeIntent":{
    "bundleName":"com.example.app",
    "intentName":"com.example.intent.TRANSFER",
    "executeMode":"foreground",
    "intentParam":{}
  },
  "deepLink":{
    "url":"example://transfer",
    "appName":"示例应用",
    "appPackage":"com.example.app",
    "minVersion":"1.0.0"
  }
 }
```

#### 公共字段说明

请求和响应中metadata字段的公共字段说明。

请求（小艺发送至Agent）：  

|字段名|类型|必填|说明|
|:------------------|:-----|:-|:---------------------|
|metadata.agentId|string|是|目标Agent标识，由小艺填写|
|metadata.traceId|string|是|请求追踪ID，由小艺生成，Agent原样回传|
|metadata.appVersion|string|否|小艺版本号，供Agent做兼容性处理|

响应（Agent发送至小艺）：  

|字段名|类型|必填|说明|
|:--------------------|:-----|:-|:-------------------------|
|metadata.traceId|string|是|原样回传请求中的traceId|
|metadata.agentId|string|是|Agent标识，Agent返回当前对应AgentId|
|metadata.agentVersion|string|否|Agent版本号，供小艺做兼容性处理|
