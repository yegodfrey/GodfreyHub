# 批量变更商品

在商品状态为"草稿"、"审核驳回"、"已上架"状态时，开发者可以通过"批量变更"操作更新商品信息并发起审核。

1. 在服务直达主界面，选择"商品直达"页签，点击"商品状态"列筛选出"已上架"状态的商品。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0f/v3/YZ3NogWARCeKyIJLxqAO6w/zh-cn_image_0000002722961354.png?HW-CC-KV=V1&HW-CC-Date=20261008T191624Z&HW-CC-Expire=31536000000&HW-CC-Sign=91B969A5E9B5C52078A926A5DFDB9175B4F572E16098FEB77F0628DD4667788F "点击放大")

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3c/v3/1Zu_B87XTLO7Lx7mCfvbfg/zh-cn_image_0000002722801434.png?HW-CC-KV=V1&HW-CC-Date=20261008T191624Z&HW-CC-Expire=31536000000&HW-CC-Sign=CEA90864D0EC2C8846329CA1C554118BDD1A2DF5598008588DD8314C0E8819EB "点击放大")
2. 点击"导出"。
   * 没有勾选项时，点击"导出"可导出全部商品。
   * 存在已勾选商品时，点击"导出"仅导出已勾选商品。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4f/v3/xp_gXvmzRx-KYG2CeOi5VA/zh-cn_image_0000002722801428.png?HW-CC-KV=V1&HW-CC-Date=20261008T191624Z&HW-CC-Expire=31536000000&HW-CC-Sign=838E17BF62D17577E57EC6A98007B3B909E222BB74A8E55D7154A0095B1B8F9B "点击放大")
3. 导出完成后，点击"任务管理"，下载导出结果。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/26/v3/8PmcZQdrSreGqHPP8RILsQ/zh-cn_image_0000002752481237.png?HW-CC-KV=V1&HW-CC-Date=20261008T191624Z&HW-CC-Expire=31536000000&HW-CC-Sign=B55512F70BA2CD02B9947B5DA677F11D0867AFB2A910C0836E27F5563F154E98 "点击放大")

4. 编辑表格，修改商品信息。 说明
   >
   > "SKU"Sheet页中，删除一行时会删除该SKU。若需新增SKU，请新增一行并填写必填字段。

5. 点击"服务直达",返回"商品直达"页签。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a5/v3/_YFuXlqiQZiVyawAu7aqaw/zh-cn_image_0000002752561133.png?HW-CC-KV=V1&HW-CC-Date=20261008T191624Z&HW-CC-Expire=31536000000&HW-CC-Sign=0F713C88938D371EBEF16D0F1DBC0C96C02B4B65DF2986671AFB19C510AE3E4F "点击放大")

6. 点击"批量变更"，上传编辑后的表格文件，点击"上传"按钮。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/33/v3/fH8E0BLcRiW88JWMYOzK-A/zh-cn_image_0000002722961358.png?HW-CC-KV=V1&HW-CC-Date=20261008T191624Z&HW-CC-Expire=31536000000&HW-CC-Sign=E60F140447CDEABE6EB4AA85C85A5DB2D7CD62896DA2CA865DFE33D4155C90AC "点击放大")
