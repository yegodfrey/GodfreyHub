# 交互接口说明

1. 概述

该文档描述了开发者服务接入智能体数字商品支付服务的接口定义。

2. 接口列表  

| |接口描述|功能描述|
|:--|:-----|:-------------------|
|IF1|订单通知接口|此接口用于通知开发者下发或者撤销商品权益|
|IF2|权益查询接口|此接口用于查询用户权益|

* [订单通知接口](https://developer.huawei.com/consumer/cn/doc/service/order-notification-0000002537601307)  
* [权益查询接口](https://developer.huawei.com/consumer/cn/doc/service/privilege-query-0000002537721285)
