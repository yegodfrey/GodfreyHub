# 下架个性化设置

1. 对于已通过审核、服务状态为"已上架"的个性化设置，开发者可进行下架个性化设置的操作。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/67/v3/dtezCOEOQE-OYf_m-q9DUA/zh-cn_image_0000002752481283.png?HW-CC-KV=V1&HW-CC-Date=20261008T155404Z&HW-CC-Expire=31536000000&HW-CC-Sign=4007DFBC4A8511D6A94EEF746E2B038139BB388B57615B3A77ED3556E5B4D01D "点击放大")

2. 下架后，个性化设置状态由"已上架"变更为"已下架"，后续可进行查看和编辑操作。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cf/v3/Qok3O0eiTWSJm0jAb0d3dw/zh-cn_image_0000002722801484.png?HW-CC-KV=V1&HW-CC-Date=20261008T155404Z&HW-CC-Expire=31536000000&HW-CC-Sign=3AF991C0C888387E728BD03EF7480A119D7D888088274D1AEE80233D372279AA "点击放大")

   > 说明
   >
   > 如果您的子服务关联的个性化被下架且您未关联新的个性化数据，则此卡将不可被分发。
