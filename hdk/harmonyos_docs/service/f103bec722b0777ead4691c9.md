# 基础能力

## 模型

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/af/v3/Ya4AZlL1TBi1NDZANp48-w/zh-cn_image_0000002675344001.png?HW-CC-KV=V1&HW-CC-Date=20260924T081230Z&HW-CC-Expire=31536000000&HW-CC-Sign=8F9A68EB47B92422FF24036BF98A4FFB27EFFB343F1905B129B151BF36C8243B "点击放大")

在此区域，开发者可以配置驱动智能体的核心大模型。

**模型选择** ：支持从平台提供的模型列表中选择一个基础模型。同时，平台支持**多模型对比调试**功能，开发者可以通过测试对比不同模型对同一指令的响应效果，从而选择最符合业务需求的模型。

**模型参数设置**：开发者可展开该区域，对模型参数进行精细化调整，以实现对回复效果的定制化控制。

* **携带上下文轮数** ：决定智能体在对话中能记忆的历史对话轮次。取值范围：**0 - 20轮**。该值越大，AI对用户意图的理解连贯性越强。
* **Top-K** ：控制候选词的选择范围，即从概率最高的K个词中进行采样。调试范围：**1 - 256**，步长为1。
* **Top-P** ：控制候选词的选择范围，即从概率累计达到P%的词堆中进行采样。调试范围：**0 - 1**，步长为0.01。
* **Temperature** ：用于调整输出结果的随机性。值越高（接近1），输出越具多样性和创造性；值越低（接近0），输出越确定和保守。调试范围：**0 - 1**，步长为0.01。

## 开场对话

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5/v3/nRSP3EKxRVOWSa7WgzuICg/zh-cn_image_0000002645184204.png?HW-CC-KV=V1&HW-CC-Date=20260924T081230Z&HW-CC-Expire=31536000000&HW-CC-Sign=9682D7CEEFE0A95FF16050BFE3552CF79BEAD77CB234C909002E28FCD6B6890A "点击放大")

开场对话是用户首次进入智能体时自动展示的引导信息，旨在帮助用户快速了解智能体的用途和使用方法。

**预置开场对话（静态）**：每次启动对话时，均展示相同的开场语和预置问题。

* **智能体开场语**：支持Markdown格式输入，可进行丰富的文本编排。
* **开场语预置问题**：最多可设置3个，方便用户点击快速体验。

**动态开场对话**：根据配置的工作流或A2A服务，每次动态刷新开场语和预置问题，实现更灵活的引导。具体配置方式请参考工作流或A2A开发文档。

## 输入文件设置

用于配置智能体接收用户输入文件（图片/文档）的能力。

**照片设置**

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7d/v3/i350I3KhQvesYIBUNlfFtQ/zh-cn_image_0000002685937207.png?HW-CC-KV=V1&HW-CC-Date=20260924T081230Z&HW-CC-Expire=31536000000&HW-CC-Sign=0709E39E2935B8FCCE2BE5F3B46CD6815FAD3D13369962A4DE4EC103B5C9398E "点击放大")

**支持上传照片**：开启后，用户可发送本地图片。支持格式：JPEG、JPG、PNG、BMP、WEBP。

**支持拍摄**：开启后，用户可使用相机实时拍摄并发送。（注：该功能不支持在网页调试，需在真机上体验。）

**发送方式**：

* **直接发送**：用户选择照片后立即发送。
* **进待发送区发送**：用户可将照片放入待发送区，与文本等内容组合后一起发送。

**照片快捷指令配置**：可为待发送区的图片配置预设的快捷指令，方便用户快速发起特定对话。

**文件设置**

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/25/v3/dBZLOEn8RkO3N6DWDyoBLA/zh-cn_image_0000002656017514.png?HW-CC-KV=V1&HW-CC-Date=20260924T081230Z&HW-CC-Expire=31536000000&HW-CC-Sign=C1DDAFE4B90AB27FD6FC72A903C9EE83FF4CFA385F2334540CF4A488C5F9C713 "点击放大")

* **支持上传文件**：开启后，用户可发送本地文档。支持格式：pdf、doc、docx、txt、ppt、pptx、xlsx、xls。
* **发送方式**：支持"直接发送"或"进待发送区发送"，逻辑与照片设置相同。
* **文件快捷指令配置**：可为待发送区的文件配置预设的快捷指令。

## 快捷指令

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4e/v3/Q6RhF6rUTOeZrfknGJ23lA/zh-cn_image_0000002675011741.png?HW-CC-KV=V1&HW-CC-Date=20260924T081230Z&HW-CC-Expire=31536000000&HW-CC-Sign=C40EF704E43744AAF067F9CC470D083572382F3EE9EB9A190E9FA6DEC1CEAC87 "点击放大")

快捷指令允许用户通过点击预设按钮，快速发起对话或执行特定操作。每个智能体最多支持30个静态指令和1个动态指令。

**基础配置**：支持拖动调整指令顺序。若存在动态指令，则其固定排列在最前，且位置不可调。

**快捷指令动态配置**：通过执行工作流，在不同场景下动态生成指令。

**指令类型**：

* **跳转型（DEEP LINK）** ：点击后通过DeepLink跳转至指定的APP。需配置应用名称、包名、DeepLink等。（**注意**：不支持页面调试，需在手机端体验。）
* **指令发送型** ：
  * **文档/图片/文本**：点击后自动上传对应类型的本地文件，或将预设的文本内容填充至对话区。
  * **拍摄** ：点击后拉起相机拍照上传。可配置前置/后置镜头及是否需要裁剪。（**注意**：不支持页面调试，需在手机端体验。）
  * **选择面板** ：可配置复杂的组件面板，如上传对象、图片模板、平铺/下拉选择器等，供用户进行多选或单选。用户的选择结果会与预设文本组合成最终Query。（**注意**：不支持页面调试，需在手机端体验。）
* **状态型**：面向用户提供某项功能的开关。用户点击可切换开启/关闭状态，状态值会随对话发送给智能体。

### 动态快捷指令

支持通过执行配置的工作流，在不同场景下动态生成不同的快捷指令。注意：（1）工作流模式下，此配置应绑定智能体配置的主工作流，关联其他工作流无法触发动态快捷指令流程。(2)工作流开始节点需包含系统默认参数EVENT_INPUT字段；工作流结束节点需包含dynamicDirective、eventInfo字段。

动态快捷指令配置图示：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/18/v3/MxWO9G9-SeWOQHO3KeAgSA/zh-cn_image_0000002685931829.png?HW-CC-KV=V1&HW-CC-Date=20260924T081230Z&HW-CC-Expire=31536000000&HW-CC-Sign=ACC6156235089CE922D5411685A6A7E68B2EF9D496CD77FDA2D4BB57AC0744D2 "点击放大")

EVENT_INPUT：动态快捷指令执行工作流的输入。

示例：

```screen
{
            "payload": {
                "timeZone": "GMT+08:00", //动态快捷指令场景不使用。
                "time": "2025-11-01 15:31:45" // 动态快捷指令场景不使用。
            },
            "header": {
                "name": "HalfScreen",// 事件名称，后续节点可通过引用开始节点EVENT_INPUT.EventName时获取此值使用。
                "namespace": "System"
            }
        }
```

dynamicDirective【Array<Object>】：给端侧展示的动态快捷指令信息

示例：

```screen
"dynamicDirective": 
[ // 给端侧展示的动态快捷指令信息
	{
		"content": "总结摘要", // 显示内容
		"query": "帮我进行总结摘要" // 发给智能体的请求
	},
	{
		"content": "一起跳舞", // 显示内容
		"query": "跟我一起来跳舞" // 发给智能体的请求
	}
]
```

eventInfo【Object】：事件信息，用于判断是否生成快捷指令

示例：

```screen
"eventInfo":{
"directiveName": "QuickChips",  // 固定值
"eventName": "HalfScreen"  // 事件名
}
```

支持eventName及eventName说明如下表：

|---|----------|--------------------------------------------------|
|**事件选择**||**说明**|
|半屏态|HalfScreen|填写eventName的值为HalfScreen时，在小艺处于半屏态状态下触发该动态快捷指令的显示。|
|全屏态|FullScreen|填写eventName的值为FullScreen时，在小艺处于全屏态状态下触发该动态快捷指令的显示。|

## 角色声音

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/69/v3/ZJ_HaSwMSlOKjK7meL_Ylg/zh-cn_image_0000002644932110.png?HW-CC-KV=V1&HW-CC-Date=20260924T081230Z&HW-CC-Expire=31536000000&HW-CC-Sign=4C6E2B915DCC9D6177CD5FD22B6BEC0D673FDF13337487CE591FF4FCF39E4AC7 "点击放大")

为智能体选择一个默认音色，并可配置用户是否可在终端侧自行切换。

* **默认音色**：从平台提供的音色库中试听并选择。
* **终端用户可以切换声音**：开关开启时，允许用户在APP内自主切换音色；关闭则固定为默认音色（但仍支持自定义音色）。
