# 注册开发者账号

#### 注册并登录开发者联盟账户

进入[华为服务号](https://developer.huawei.com/consumer/cn/business-touch/)网页，点击"立即接入"。若您还没有华为服务号账号（不建议使用个人华为账号），请通过电子邮箱或手机号码完成华为账号注册；若已有相关账号，请输入开发者联盟账户及密码进行登录。

#### 开发者账号实名

登录后显示认证页面，您应选择[对公银行打款](https://developer.huawei.com/consumer/cn/doc/start/atpopb-0000001062836624)或[人工审核](https://developer.huawei.com/consumer/cn/doc/start/mracoei-0000001062678404)的方式做企业开发者实名，具体操作可参考[指导视频](https://developer.huawei.com/consumer/cn/training/detail/101597289897864105)（默认一个企业主体只能申请一个开发者账户）。
