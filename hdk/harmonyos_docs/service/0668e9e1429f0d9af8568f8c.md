# 应用内Agent开发接入

## 概述

应用Agent接入端A2A需要实现两类Ability，分工如下：

* **AgentExtensionAbility** ：负责与小艺进行A2A协议通信，接收小艺发来的消息并返回处理结果，是接入端A2A的核心组件，**必须实现**。
* **AgentUIExtensionAbility** ：负责向小艺返回自定义UI卡片内容，仅在Agent需要以卡片形式呈现内容时使用，**按需实现**。

### AgentExtensionAbility

在DevEco Studio中通过**【** **New** **】** **→** **【Extension Ability** **】** **→** **【Agent** **】** 创建，IDE会自动生成以下三个文件。完整样例代码可参考：[AgentExtensionAbility 样例代码](https://gitcode.com/openharmony/applications_app_samples/tree/master/code/DocsSample/Ability/AgentExtensionAbility)

* **module.json5**：注册AgentExtensionAbility，通过metadata字段指向agent_config.json。
* **agent_config.json**：AgentCard配置文件，声明该Agent的能力、技能与元信息，小艺通过此文件识别和路由Agent。
* **AgentExtensionAbility**：A2A通信逻辑实现类，处理小艺发来的消息并返回结果。

三者关系：module.json5通过metadata将Ability与agent_config.json关联，小艺连接时读取AgentCard获知Agent能力，通信过程则由AgentExtensionAbility中的方法处理。

### 配置AgentCard

agent_config.json是Agent向小艺声明自身能力的核心配置，以下为关键字段示例：

```codeblock
{
   "agentCards":[
     {
       "agentId":"flight-agent",
       "name":"机票助手",
       "description":"提供航班搜索与预订服务",
       "iconUrl":"https://example.com/icon.png",
       "version":"1.2.0",
       "capabilities":{
         "streaming":true,
         "pushNotifications":true,
         "stateTransitionHistory":false
       },
       "defaultInputModes":["text/plain","application/json"],
       "defaultOutputModes":["text/plain","application/json"],
       "skills":[
         {
           "id":"flight-search",
           "name":"航班搜索",
           "description":"根据出发地、目的地、日期搜索最优航班",
           "tags":["flight","search"],
           "examples":[
             "帮我查下周三从北京到上海的上午航班"
           ]
         }
       ]
     }
   ]
 }
```

关键字段说明：

|字段|必填|说明|
|:----------|:-|:-----------------------------------------------------------|
|agentId|是|Agent唯一标识，需与客户端调用connectAgentExtensionAbility时传入的agentId保持一致|
|name|是|Agent显示名称，展示给用户|
|iconUrl|否|Agent图标的URL地址|
|description|是|Agent功能描述，小艺通过此字段进行意图匹配和技能路由|

### 关键方法

AgentExtensionAbility的各方法按生命周期顺序触发，总览如下：

|顺序|方法|触发时机|对应时序|
|:-|:-----------|:-----------------|:----|
|1|onCreate|Ability初始化，连接建立前触发|建立连接前|
|2|onConnect|小艺与Agent建立连接时触发|建立连接|
|3|onAuth|密钥协商时触发，流程可选|密钥协商|
|4|onData|小艺发送消息时触发|A2A通信|
|5|onDisconnect|连接断开时触发|---|
|6|onDestroy|Ability销毁时触发|---|

**onCreate**：onCreate(want: Want): void

Ability被拉起时首先触发，早于连接建立。可在此处完成初始化工作，want.parameters中包含小艺传入的上下文信息。

**onConnect**：onConnect(want: Want, proxy: AgentHostProxy): void

小艺与Agent建立连接时触发，对应时序图"建立连接"阶段。**proxy** **对象需在此处保存**，后续sendData、authorize等操作均通过它发起。

|参数|类型|说明|
|:----|:-------------|:-------------------------|
|want|Want|连接请求信息，包含小艺传入的agentId等上下文|
|proxy|AgentHostProxy|通信代理对象，用于向小艺发送数据，需保存以备后续使用|

**onAuth**：onAuth(proxy: AgentHostProxy, data: string): void

密钥协商阶段触发，对应时序图"密钥协商"阶段（可选流程）。收到小艺的协商数据后，处理完成通过proxy.authorize回传协商结果。

|参数|类型|说明|
|:----|:-------------|:-----------------------------|
|proxy|AgentHostProxy|通信代理对象，通过proxy.authorize返回协商结果|
|data|string|小艺发送的密钥协商数据|

**onData**：onData(proxy: AgentHostProxy, data: string): void

小艺向Agent发送消息时触发，对应时序图A2A通信阶段。data为JSON字符串，具体结构因场景而异，请结合后续各场景章节的报文示例理解。处理完成后通过proxy.sendData 返回结果。

|参数|类型|说明|
|:----|:-------------|:--------------------------------------------|
|proxy|AgentHostProxy|通信代理对象，通过proxy.sendData向小艺返回处理结果|
|data|string|小艺发送的消息内容，JSON字符串，具体结构因场景而异，请结合后续各场景章节的报文示例理解|

**AgentHostProxy**

[AgentHostProxy](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-inner-application-agenthostproxy)用于从AgentExtensionAbility服务端向客户端发送数据或安全认证请求。

**AgentHostProxy.sendData**：AgentHostProxy.sendData(data: string): void

在onData中调用，向小艺发送处理结果，对应时序图中Agent返回Task、TaskStatusUpdateEvent、TaskArtifactUpdateEvent等各类响应的阶段。

|参数|类型|说明|
|:---|:-----|:-------------------------------------------|
|data|string|向小艺发送的数据，JSON字符串，具体结构因场景而异，请结合后续各场景章节的报文示例理解|

**AgentHostProxy.authorize**：AgentHostProxy.authorize(data: string): void

在onAuth中调用，向小艺回传密钥协商结果，对应时序图"密钥协商"阶段的Agent回传步骤。

|参数|类型|说明|
|:---|:-----|:-----------|
|data|string|向小艺回传的协商结果数据|

**onDisconnect**：onDisconnect(want: Want, proxy: AgentHostProxy): void

连接断开时触发，可在此处释放资源、清理会话状态。

**onDestroy**：onDestroy(): void

Ability销毁时触发，可在此处完成资源回收。

## AgentUIExtensionAbility（可选）

在DevEco Studio中通过【**New** 】**→** **【Extension Ability** **】** **→** **【AgentUI】**创建，IDE会自动生成以下两个文件：

* **module.json5**：注册AgentUIExtensionAbility，type 为agentUI，exported为true。
* **AgentUIExtAbility**：UI卡片实现类，在onSessionCreate中加载自定义ArkTS页面。

两者关系：module.json5注册该Ability并对外暴露，小艺请求UI卡片时拉起该Ability，由AgentUIExtAbility的onSessionCreate加载对应页面并渲染卡片内容。

### 关键方法

AgentUIExtensionAbility的各方法按生命周期顺序触发，总览如下：

|顺序|方法|触发时机|
|:-|:---------------|:------------|
|1|onCreate|Ability初始化时触发|
|2|onSessionCreate|小艺请求加载UI卡片时触发|
|3|onForeground|卡片切换到前台时触发|
|4|onBackground|卡片切换到后台时触发|
|5|onSessionDestroy|卡片会话销毁时触发|
|6|onDestroy|Ability销毁时触发|

**onSessionCreate**：onSessionCreate(want: Want, session: UIExtensionContentSession): void

小艺请求加载UI卡片时触发，是AgentUIExtensionAbility的核心方法。在此处将卡片页面与session绑定并加载。

|参数|类型|说明|
|:------|:-------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------|
|want|Want|请求信息，包含小艺传入的透传参数等上下文，可通过want.parameters获取|
|session|[UIExtensionContentSession](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-app-ability-uiextensioncontentsession)|当前卡片会话对象，通过session.loadContent('pages/CardPage', storage) 加载指定ArkTS页面|

### 参数传递

Agent通过A2A协议返回uiExtensionCard指令时，payload字段中的数据会由小艺透传至AgentUIExtensionAbility，在onSessionCreate的want.parameters中获取：

```codeblock
onSessionCreate(want: Want, session: UIExtensionContentSession) {
   const payload = want.parameters?.['ability.want.params.payload'] as string;
   // ...
 }
```

注意：A2A约定传参通过ability.want.params.payload的参数进行传递。卡片的具体实现与标准 [UIExtensionAbility](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-app-ability-uiextensionability)一致。
