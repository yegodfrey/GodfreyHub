# 工作流/工作流配置

工作流用于处理功能类的请求，可通过顺序执行一系列节点实现某个功能。工作流为Agent的数据流动和任务处理提供了一个结构化框架。

工作流的核心在于将大模型的强大能力与特定的业务逻辑相结合，通过系统化、流程化的方法来实现高效、可扩展的AI应用开发。

工作流开发指南请参考[开发工作流](https://developer.huawei.com/consumer/cn/doc/service/development-workflow-0000002435989628)。
