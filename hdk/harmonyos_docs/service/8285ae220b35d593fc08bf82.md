# 工作流界面跳转配置

## 功能介绍

当Agent调用配置工作流进行响应时，支持以界面形式返回结果，实现更丰富的交互体验。

### Agent编排与发布

1. 添加用户界面

Agent添加工作流后点击【绑定卡片或界面】图标，选择界面跳转，点击【添加用户界面】，添加已经发布的界面。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3a/v3/nZx3C8UZT_OqqJGfo53W-w/zh-cn_image_0000002670104175.png?HW-CC-KV=V1&HW-CC-Date=20260909T143228Z&HW-CC-Expire=31536000000&HW-CC-Sign=FD09BCF50245D7675173F1F06598DCC363C50D56514418FBBA102386733EA90F "点击放大")

2. 界面入参配置

添加界面后，点击【界面入参配置】，将界面入参变量与工作流输出/结束节点进行绑定映射。若无界面入参变量或不需要映射可跳过此步骤。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/88/v3/iFLPilHZRh2w-FtcUXn4ag/zh-cn_image_0000002670264039.png?HW-CC-KV=V1&HW-CC-Date=20260909T143228Z&HW-CC-Expire=31536000000&HW-CC-Sign=588C40D5799FC33197B1D9B9A51C2028A92A7788D3EA2E733BAAD578BA6F9C05 "点击放大")

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5a/v3/9aKmyECERJmSMrtnjD7SbQ/zh-cn_image_0000002640264148.png?HW-CC-KV=V1&HW-CC-Date=20260909T143228Z&HW-CC-Expire=31536000000&HW-CC-Sign=FBC0FCB46EE98A57782B16F502B559F2BF3C6DEED6EC83EC5B08C0ED60CCDB4E "点击放大")

3. 界面升级

添加的界面版本更新后，可以直接点击图示升级按钮进行升级，升级后若参数有变化，需重新配置关联关系。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/62/v3/A2VfmAxhSb-1BX0c0tx5Ww/zh-cn_image_0000002670264041.png?HW-CC-KV=V1&HW-CC-Date=20260909T143228Z&HW-CC-Expire=31536000000&HW-CC-Sign=61EBD46EF9216CC8B2302C036E968A9C39DAA26274DA8E6D1CA5EA683B1E0A4D "点击放大")
