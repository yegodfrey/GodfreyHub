# 插件

插件作为工具集，可以包含一个或多个工具（API），用于帮助Skill快速集成外部能力。本文档旨在指导开发者如何在生成Skill时通过插件机制进行能力拓展，插件开发指南请参考[开发插件](https://developer.huawei.com/consumer/cn/doc/service/develop-plug-ins-0000002435989648)。  

#### 插件来源

|来源|说明|使用场景|
|:---|:------------------|:------------|
|插件广场|平台官方认证以及第三方开发者公开的插件|通用能力、常用服务集成|
|我的插件|开发者自行创建或注册的私有插件|私有业务能力、内部系统对接|
|合作伙伴|平台合作方提供的专有插件|生态合作、定制化能力|

#### 插件类型

|类型|说明|特点|
|:----|:-------------------------------------------------------------------|:--------------|
|云插件|部署在云端，通过HTTP/HTTPS调用的API集合。|无需端侧部署，实时更新，响应快|
|端插件|提供能力的服务在HarmonyOS设备侧，端插件构建Claw与HarmonyOS设备侧应用的交互通路，从设备侧的应用获取信息或操控应用。|低延迟，支持离线场景，端侧执行|
|MCP插件|遵循MCP协议的API集合。|标准化协议，具有丰富的生态|

#### 操作步骤

步骤1：进入Skill创建页面

登录小艺开放平台，进入【Skill】→【新建Skill】。

步骤2：填写基本信息

在对话框内填写Skill名称、描述、触发意图等基础信息。

步骤3：选择插件

点击对话框下方的【@】按钮，点击【插件】选项。选择【插件来源/插件类型】。

步骤4：添加插件

在插件列表中找到所需插件，点击插件卡片进入详情页，查看插件包含的工具列表，点击 【+】 按钮添加插件到当前Skill。
