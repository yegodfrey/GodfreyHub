# 事件配置

<br />

事件配置概述

事件功能使卡片具备交互能力，例如给按钮设置点击事件，触发点击后跳转到某个应用。

事件类型：即事件触发的方式，提供点击时、加载时两种触发方式。

执行条件：为可选项，设置执行条件后，只有满足条件，触发的事件才能执行。

执行动作：目前卡片支持11项事件配置：跳转、给小艺对话或智能体发消息、设置变量值、修改组件属性、切换页面、查询应用安装状态、调用插件、复制到剪切板、预览图片、删除列表数据、操作小艺。

![](https://media:301785143834502628)

执行条件配置：

左操作数：可以为前置事件的返回值或变量

运算符：根据左操作数的类型，提供不同的运算符

右操作数：可以为常量或变量
