# 插件绑卡

添加插件后点击图中【绑定回复卡片】图标进入绑卡页面。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/25/v3/hVwHode3Q3OSzKCaNrz7dQ/zh-cn_image_0000002640104178.png?HW-CC-KV=V1&HW-CC-Date=20260909T143814Z&HW-CC-Expire=31536000000&HW-CC-Sign=93986DD8E43209BCB6B407D2C95ED032E68AF58A9EDEC28C58947A2F0E69FF8E "点击放大")

点击卡片可查看卡片的详细内容，如果想绑定该卡片，将鼠标悬浮在卡片上后，点击添加按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c9/v3/3TjQpjqoSby6GPJh9UaDpg/zh-cn_image_0000002670104155.png?HW-CC-KV=V1&HW-CC-Date=20260909T143814Z&HW-CC-Expire=31536000000&HW-CC-Sign=EFFFE7A6C2F09DBBE7F44B28AC0BD4D525BC268156362C7752D486F2371156E6 "点击放大")

同一插件支持绑定多张卡片；支持同一时刻输出多张卡片；支持配置答复文本和卡片的输出顺序，答复文本和卡片将按照配置顺序输出。

* [数据处理方式](https://developer.huawei.com/consumer/cn/doc/service/create-tools-0000002437625946#section69431146123912)，答复文本与卡片可随意编排位置（批式插件融合生成开关关闭时，无答复文本，只输出卡片）；
* [流式插件工具](https://developer.huawei.com/consumer/cn/doc/service/create-tools-0000002437625946#section69431146123912)，支持分别在首末帧返回绑卡信息。如果在首帧返回绑卡信息，则先出卡再出文本；如果在末帧返回绑卡信息，则先出文本再出卡片。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7c/v3/Rzh1jv81RzuG7_3yE8GIHQ/zh-cn_image_0000002640104182.png?HW-CC-KV=V1&HW-CC-Date=20260909T143814Z&HW-CC-Expire=31536000000&HW-CC-Sign=2971A5D87773D7A41751E3242F36FF7E29BEC53561085FA6C0F82D27B88CCE16 "点击放大")

**绑卡标识**

开发者可以通过绑定绑卡标识设置出卡条件，不设置绑卡标识时，固定出卡。

* 绑卡标识仅支持选择String和Array[String]类型的插件响应字段；
* 出卡对比值在卡片输出条件中配置；
* 用户选择绑卡标识为String类型时，当绑卡标识值和输出条件中输入值完全相等时出卡，否则不出卡；
* 用户选择绑卡标识为Array[String]类型时，当绑卡标识值包含输出条件中输入的值时出卡，否则不出卡。
