# 下架服务卡片（FormKit）

1. 对于已通过审核、服务状态为"已上架"的FormKit卡，开发者可点击"下架"进行下架FormKit卡的操作。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/63/v3/WQDy1-JBQCy8yKhn_o8XzA/zh-cn_image_0000002722801480.png?HW-CC-KV=V1&HW-CC-Date=20261008T184255Z&HW-CC-Expire=31536000000&HW-CC-Sign=EE817ED8C40192009E30F6893C88F6DD76365B9E3F719A0712E1CD92FC781121 "点击放大")
