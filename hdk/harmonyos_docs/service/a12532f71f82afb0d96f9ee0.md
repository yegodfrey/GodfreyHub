# 批量任务管理

1. 进入"门店管理"页签， 点击任务管理。 ![](https://media:401788945858075343 "点击放大")

2. 可在此查询"门店导入/导出/修改/删除"的操作结果，并且能下载结果文件查看详情。  
   ![](https://media:401788945858110344)  
   导出操作时数据表中"导入成功"列标识的数量为导出成功数。

   ![](https://media:401788945858164345 "点击放大")
3. 回到门店管理页。

![](https://media:401788945858203346 "点击放大")
