# 批量删除商品

在商品状态为"已下架"状态时，您可以点击"删除"按钮或"批量删除"按钮，以完成删除商品操作。

详细操作指导如下：

1. 点击"删除"按钮删除商品。
   1. 在服务直达主界面，选择"商品直达"页签，点击"商品状态"列筛选出"已下架"状态的商品。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9f/v3/UsklaSI1QuW3UwwXFYieSg/zh-cn_image_0000002722801424.png?HW-CC-KV=V1&HW-CC-Date=20261008T150843Z&HW-CC-Expire=31536000000&HW-CC-Sign=2BF8A68E8D9C4276F6AE9D33399E19B49BF6527DAA29ED6EE3C2E6CBE88428BA "点击放大")

   2. 勾选想要删除的商品，点击删除。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f3/v3/yCPctcThSpGn7XBbNOzHRQ/zh-cn_image_0000002722801418.png?HW-CC-KV=V1&HW-CC-Date=20261008T150843Z&HW-CC-Expire=31536000000&HW-CC-Sign=6BDC5F54CDD1ED3F602BE44C57F77324B9C632CCE7630F22261F2D3BE76CDA20 "点击放大")

2. 上传文件删除商品。
   1. 在服务直达主界面，选择"商品直达"页签，点击"商品状态"列筛选出"已下架"状态的商品。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b2/v3/XxzRAH0iRxy5Kk-RetTfEw/zh-cn_image_0000002752561125.png?HW-CC-KV=V1&HW-CC-Date=20261008T150843Z&HW-CC-Expire=31536000000&HW-CC-Sign=39193E2B963862EA57F8DC47113AEF0E9E777335870059D6BD6DBAA308AD2A7C "点击放大")

   2. 点击"导出"。 不勾选时，点击"导出"可导出全部商品。勾选商品时，点击"导出"仅导出已勾选商品。

      ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/22/v3/7dUSwkqTRFavKG1mr5gEYw/zh-cn_image_0000002722961344.png?HW-CC-KV=V1&HW-CC-Date=20261008T150843Z&HW-CC-Expire=31536000000&HW-CC-Sign=F42238544699383A91BA94DFB06ACA4BAB4469F496DCCCC88DC8E498C0549565 "点击放大")
   3. 导出完成后，点击"任务管理"，下载导出结果。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c9/v3/p6-kTzutTH-CE26FVZQyDQ/zh-cn_image_0000002722961346.png?HW-CC-KV=V1&HW-CC-Date=20261008T150843Z&HW-CC-Expire=31536000000&HW-CC-Sign=336D0BE4442EE94ECC8D8D99C36B2F210E8DF5624D626888B1ADBE5F6784D5BA "点击放大")

      ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/82/v3/NJ3iX2hkQlqRyoTcL3y2oA/zh-cn_image_0000002722801416.png?HW-CC-KV=V1&HW-CC-Date=20261008T150843Z&HW-CC-Expire=31536000000&HW-CC-Sign=DA1E6D06F0509D51420D9EA034908D6A61B0E0871F95276710D4D849A235FCAA "点击放大")
   4. 编辑表格，仅保留需要删除的商品。 注意
      >
      > 删除场景中，"平台侧商品ID"列不可修改。
   5. 点击"服务直达",返回"商品直达"页签。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/79/v3/7rvv631uSLqp_gu3baVRmQ/zh-cn_image_0000002752481225.png?HW-CC-KV=V1&HW-CC-Date=20261008T150843Z&HW-CC-Expire=31536000000&HW-CC-Sign=97DEFC8932A395BE17C22F5B2B5CF79FFAF1E859E2E33DC4B76ADAC73612617F "点击放大")

   6. 点击"批量删除"，上传编辑后的表格文件，点击"上传"按钮。
