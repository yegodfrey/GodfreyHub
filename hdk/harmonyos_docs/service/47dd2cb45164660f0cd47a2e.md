# 私信回复

私信提供给用户和开发者沟通互动的能力。建议开发者至少每天检查一次未读消息，以便更及时有效地回复用户问题。  

#### 用户发送私信

场景：用户在服务号会话页发送私信，开发者在开发者平台回复用户

![](https://media:201787729660689895 "点击放大")  

#### 开发者查看和回复私信

1. 开发者可在私信功能中查看给用户发送的各类型消息，如欢迎消息、模板消息、图文消息、AI助手回复消息等。

![](https://media:201787729660743896 "点击放大")

2. 开发者可以在回复栏目中给用户回复私信，支持发送文本、文章、图片、表情。

![](https://media:201787729660778897 "点击放大")

3. 如果有未读私信，菜单会有红点提醒。

![](https://media:201787729660807898 "点击放大")

4. 支持对未读私信进行条件筛选。

![](https://media:201787729660876899 "点击放大")
