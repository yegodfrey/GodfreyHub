# 认证服务号与权益

## 认证服务号流程

服务号目前支持2种认证方式

方式一：进入服务号列表页，直接在"操作"中点击"认证"，即可进入认证页面开始认证流程。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/26/v3/g8QovX75QxChBviQWljWtA/zh-cn_image_0000002668515996.png?HW-CC-KV=V1&HW-CC-Date=20261008T140415Z&HW-CC-Expire=31536000000&HW-CC-Sign=ADE3005728C092E6F8E1AE37CDCFC87C455DCE60326B1DB73381C26BA6E4134C "点击放大")

方式二：在菜单中选择"服务号认证"，进入认证页面开始认证流程。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/86/v3/Ttmg-M04QrSpjctU96uRAw/zh-cn_image_0000002698316057.png?HW-CC-KV=V1&HW-CC-Date=20261008T140415Z&HW-CC-Expire=31536000000&HW-CC-Sign=46D74504C51286247022D72E6BDD63739A8B120676C158F3647855A8DF5D8888 "点击放大")

方式一和方式二都会进入统一认证页面。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/52/v3/S-C9kC0IQxebAfc4s6vLig/zh-cn_image_0000002698282691.png?HW-CC-KV=V1&HW-CC-Date=20261008T140415Z&HW-CC-Expire=31536000000&HW-CC-Sign=B3F356E92BBE8152650412D9592EBD6BB71A468855948A36FB760955CF804B69 "点击放大")

1、点击"服务号认证"模块中的"认证"按钮，开始认证流程。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/77/v3/x_an1oiaQQG9aTZpAwe4Zg/zh-cn_image_0000002698335293.png?HW-CC-KV=V1&HW-CC-Date=20261008T140415Z&HW-CC-Expire=31536000000&HW-CC-Sign=081E6134BF6D2BC26BF4412A8AF45118D5C9A3FCD3857D10E459C9EC765A7565 "点击放大")

2、签署认证协议，主动勾选"我已同意并遵守上述内容及《平台认证服务协议》"，点击"下一步"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4d/v3/BR4FHO_2S8-uojxQJFxxCw/zh-cn_image_0000002698417843.png?HW-CC-KV=V1&HW-CC-Date=20261008T140415Z&HW-CC-Expire=31536000000&HW-CC-Sign=FDD008542EAD9CBFEC4A9CC6C7F1C2319BEE1FF326E6005F30D169E7E85FB55F "点击放大")

3、完成企业信息填写，确认企业基本信息无误，并填写认证联系人信息，依次填写"联系人姓名"、"联系人身份证"、"联系人手机号"和"电子邮箱"，手机号需要通过验证码完成校验，点击"下一步"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/dc/v3/0Z-vMQfTQciN7gmLIIjtpw/zh-cn_image_0000002698426019.png?HW-CC-KV=V1&HW-CC-Date=20261008T140415Z&HW-CC-Expire=31536000000&HW-CC-Sign=456882BA308751B60EE5FC68A108FBF335901954F72724853BFFDB53E84CF721 "点击放大")

4、支付费用，点击"去支付"，在新打开得页面扫码完成年费支付，支付成功后认证状态立即生效，认证有效期为1年，在剩余3个月认证到期时，可以提前续费。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/86/v3/8k6UVO0AR36HvZgWKxU39Q/zh-cn_image_0000002701441951.png?HW-CC-KV=V1&HW-CC-Date=20261008T140415Z&HW-CC-Expire=31536000000&HW-CC-Sign=091CBE7E62FC437B4A52803EAE03C4CF3341887E7E5A50EBD42A198988D20249 "点击放大")
