# 元服务管理

场景：已上架元服务关联服务号后，可实现元服务的服务通知可留存到服务号会话页、元服务AI助手回复消息留存到服务号会话页。

关联操作入口：AGC元服务管理台 -"服务号"菜单

![](https://media:201787729662448926 "点击放大")  

#### 元服务新建关联服务号

1、进入服务号关联页面，如果所选元服务还未关联服务号，可选择使用已有服务号进行关联或申请新的服务号进行关联。申请新服务号进行关联操作流程参考[方式2：复用元服务资料一键开通服务号](https://developer.huawei.com/consumer/cn/doc/service/real_name_authentication-0000002476702796#section3200193172116)。

![](https://media:201787729662498927 "点击放大")

2、关联服务号只支持选择已通过的服务号，点击"关联"。

![](https://media:201787729662541928 "点击放大")

3、关联成功后, 跳转到关联结果列表

![](https://media:201787729662589929 "点击放大")  

#### 元服务切换关联服务号

说明：业务已上线的元服务，切换关联会影响用户服务通知和AI助手回复功能。不建议切换关联服务号，请开发者评估影响后再操作。

不支持切换关联的情况：

* 服务号还未通过审核、已冻结、已下线等非已开通状态
* 开通了AI助手回复功能

#### 元服务取消关联服务号

说明：业务已上线的元服务，取消关联会影响用户服务通知和AI助手回复功能，请开发者评估影响后再操作。

不支持取消关联的情况：

* 服务号还未通过审核、已冻结、已下线等非已开通状态
* 开通了AI助手回复功能
