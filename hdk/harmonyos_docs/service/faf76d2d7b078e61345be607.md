# AI助手回复

AI助手可根据已配置的知识库内容，自动匹配并回答用户的常见问题，全天候即时互动，让每一条留言都有回音。

## 操作步骤

1. 登录服务号管理台后，点击AI助手回复菜单，进入AI助手回复页。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a4/v3/mzFEsQx3QLqZaHa5TjKg9g/zh-cn_image_0000002645035600.png?HW-CC-KV=V1&HW-CC-Date=20261008T154017Z&HW-CC-Expire=31536000000&HW-CC-Sign=E33ADA0E0D19DDA43906E0BAC12ABA046893AE2F8212AAFDCC2E19B7FD386C1C "点击放大")

2. 打开AI助手回复开关。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/72/v3/_SJv5MYsQTSXXvvEBVbC1g/zh-cn_image_0000002675235901.png?HW-CC-KV=V1&HW-CC-Date=20261008T154017Z&HW-CC-Expire=31536000000&HW-CC-Sign=532B2D047E9C6DEDE035DFD02892E687F322D34E93BC9AB277782ED7EC4B095C "点击放大")

3. 开发者点击右上角的"编辑"按钮，配置开场白和预置问题引导。编辑完成后点击右边的"保存"按钮保存修改。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/98/v3/UhXM6KA8SGWx5sR8x-eRXA/zh-cn_image_0000002675356371.png?HW-CC-KV=V1&HW-CC-Date=20261008T154017Z&HW-CC-Expire=31536000000&HW-CC-Sign=5DED653E3885A85C9D56416ECB1ED244A1E3F737E798EDB28A3F71D6F692F79F "点击放大")

4. 开发者在知识库列表点击新增按钮，输入知识库名称，点击确认即新增。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/78/v3/9dnagsg_SEe3i5DHkTz9Yw/zh-cn_image_0000002675361095.png?HW-CC-KV=V1&HW-CC-Date=20261008T154017Z&HW-CC-Expire=31536000000&HW-CC-Sign=E07DB2D6359BA9CA5EAA8B711E2DDBCC7C10D8E94E86783FA3E8ABE08BDF2C79 "点击放大")

5. 开发者在知识库列表点击查看按钮，进入新增文档页面。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5e/v3/tRKn3KDBTziTV7nMimWOWQ/zh-cn_image_0000002675361965.png?HW-CC-KV=V1&HW-CC-Date=20261008T154017Z&HW-CC-Expire=31536000000&HW-CC-Sign=6555CC2D6C17C9A99DEF8F988E81E8FF6007F7BE913CC9D47B2BEF1D05770DB0 "点击放大")

6. 开发者点击上传按钮，选择单个文件进行上传。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/22/v3/JxY8uX46TXu99JW3i5tMqg/zh-cn_image_0000002675241689.png?HW-CC-KV=V1&HW-CC-Date=20261008T154017Z&HW-CC-Expire=31536000000&HW-CC-Sign=81DAA9781E3E3BA6E245243DBEE0E9E952C7D292D2C35EDC3EBF50B99DC0D49E "点击放大")
