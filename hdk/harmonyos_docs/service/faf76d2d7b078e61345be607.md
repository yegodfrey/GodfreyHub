# AI助手回复

AI助手可根据已配置的知识库内容，自动匹配并回答用户的常见问题，全天候即时互动，让每一条留言都有回音。

## 操作步骤

1. 登录服务号管理台后，点击AI助手回复菜单，进入AI助手回复页。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a4/v3/mzFEsQx3QLqZaHa5TjKg9g/zh-cn_image_0000002645035600.png?HW-CC-KV=V1&HW-CC-Date=20260909T144125Z&HW-CC-Expire=31536000000&HW-CC-Sign=3542F9B33A84CA247B30122D5DC6F67271DB9FD90BFC343A75F4386B48B2AC17 "点击放大")

2. 打开AI助手回复开关。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/72/v3/_SJv5MYsQTSXXvvEBVbC1g/zh-cn_image_0000002675235901.png?HW-CC-KV=V1&HW-CC-Date=20260909T144125Z&HW-CC-Expire=31536000000&HW-CC-Sign=4DE53D15357B3DFB9AFDD67B22FF5FCDB2CDDBFA208FFA72CC73D298D300BE61 "点击放大")

3. 开发者点击右上角的"编辑"按钮，配置开场白和预置问题引导。编辑完成后点击右边的"保存"按钮保存修改。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/98/v3/UhXM6KA8SGWx5sR8x-eRXA/zh-cn_image_0000002675356371.png?HW-CC-KV=V1&HW-CC-Date=20260909T144125Z&HW-CC-Expire=31536000000&HW-CC-Sign=3132445CAEF0CA7FB93D6A77F7F3DF2DF38285B87FE0516D70130B6E85892F81 "点击放大")

4. 开发者在知识库列表点击新增按钮，输入知识库名称，点击确认即新增。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/78/v3/9dnagsg_SEe3i5DHkTz9Yw/zh-cn_image_0000002675361095.png?HW-CC-KV=V1&HW-CC-Date=20260909T144125Z&HW-CC-Expire=31536000000&HW-CC-Sign=3630D9E38AB164597C844F3A3C78AB5AA46673FD8E211F93762D8B4358BEAEBF "点击放大")

5. 开发者在知识库列表点击查看按钮，进入新增文档页面。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5e/v3/tRKn3KDBTziTV7nMimWOWQ/zh-cn_image_0000002675361965.png?HW-CC-KV=V1&HW-CC-Date=20260909T144125Z&HW-CC-Expire=31536000000&HW-CC-Sign=2E0848A680BED766371BFE48A740B740B1585CF83735609C41E27B4AF63D321F "点击放大")

6. 开发者点击上传按钮，选择单个文件进行上传。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/22/v3/JxY8uX46TXu99JW3i5tMqg/zh-cn_image_0000002675241689.png?HW-CC-KV=V1&HW-CC-Date=20260909T144125Z&HW-CC-Expire=31536000000&HW-CC-Sign=406B97606D279A06095CBDC082D36F557D966E50AAEFE1274FCD7C3D3AE4B10F "点击放大")
