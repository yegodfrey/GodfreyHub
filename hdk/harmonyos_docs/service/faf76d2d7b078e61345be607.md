# AI助手回复

AI助手可根据已配置的知识库内容，自动匹配并回答用户的常见问题，全天候即时互动，让每一条留言都有回音。  

#### 效果示意

![](https://media:201787729659071871 "点击放大")  

#### 操作步骤

1. 登录服务号管理台后，点击AI助手回复菜单，进入AI助手回复页。

![](https://media:201787729659138872 "点击放大")

2. 打开AI助手回复开关。

![](https://media:201787729659206873 "点击放大")

3. 开发者点击右上角的"编辑"按钮，配置开场白和预置问题引导。编辑完成后点击右边的"保存"按钮保存修改。

![](https://media:201787729659276874 "点击放大")

4. 开发者在知识库列表点击新增按钮，输入知识库名称，点击确认即新增。

![](https://media:201787729659363875 "点击放大")

5. 开发者在知识库列表点击查看按钮，进入新增文档页面。

![](https://media:201787729659425876 "点击放大")

6. 开发者点击上传按钮，选择单个文件进行上传。

![](https://media:201787729659499877 "点击放大")
