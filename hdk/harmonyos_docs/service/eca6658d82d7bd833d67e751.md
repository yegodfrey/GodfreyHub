# 上/下架流程介绍

完成Skill开发后，开发者可以执行上架操作。审核通过的Skill，才能被其他用户搜索并使用。升级审核未通过的Skill，线上依旧保留上一次通过审核的版本提供给其他用户使用。下架后的Skill，用户无法再使用。开发者可以选择编辑后再次提交上架申请。

## 上架操作流程

**步骤1：**进入项目一站式上架页面

进入Skill开发界面，点击【+】创建新标签页→【上架】→【+】。

## 升级操作流程

若需要对已经上架的Skill进行内容修改，则需要再次进入上架总览页面，修改相关信息后提交升级。
