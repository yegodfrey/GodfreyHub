# 基于意图框架创建云插件

插件创建方式选择"云插件-选择意图框架"进行创建。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e9/v3/JwWrAqKwT_aK4GI5cfZ-lg/zh-cn_image_0000002670263799.png?HW-CC-KV=V1&HW-CC-Date=20261008T171835Z&HW-CC-Expire=31536000000&HW-CC-Sign=F85BA4BC8731D6594AB3680B68E28A9A3FAAFCC2A5AA1240065C9C687F292171 "点击放大")

当选择已有意图后，系统将自动填充以下字段：APP包名、APP名称、服务类型，只需要补充插件描述即可。
