# 基于意图框架创建云插件

插件创建方式选择"云插件-选择意图框架"进行创建。

![](https://media:301785143829518561 "点击放大")

当选择已有意图后，系统将自动填充以下字段：APP包名、APP名称、服务类型，只需要补充插件描述即可。

![](https://media:301785143829571562 "点击放大")
