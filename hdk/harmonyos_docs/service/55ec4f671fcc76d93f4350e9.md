# 批量下架商品

在商品状态为"已上架"或"已冻结"状态时，您可以通过"批量下架"操作完成商品下架。

1. 在服务直达主界面，选择"商品直达"页签，点击"商品状态"列筛选出"已上架"或"已冻结"状态的商品。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b5/v3/Yo5MrTW4QXqF4wzEprugmw/zh-cn_image_0000002722801492.png?HW-CC-KV=V1&HW-CC-Date=20261008T173925Z&HW-CC-Expire=31536000000&HW-CC-Sign=F49486DD668CAC44C70C0EFE2743F890A8EB2FBD3EDD9CDDDFFEDC305E3C9220 "点击放大")

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/62/v3/nrIxP0eBT6CppFPer4nivQ/zh-cn_image_0000002752481291.png?HW-CC-KV=V1&HW-CC-Date=20261008T173925Z&HW-CC-Expire=31536000000&HW-CC-Sign=0C7467A6A1E85B69DAEAAEAF67A972160C2DC6378699038677788EB2BA855D69 "点击放大")
2. 点击"导出"。
   * 没有勾选项时，点击"导出"可导出全部商品。
   * 存在已勾选商品时，点击"导出"仅导出已勾选商品。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0a/v3/jES-MeDmSGOhOwq7MKD4vA/zh-cn_image_0000002752561193.png?HW-CC-KV=V1&HW-CC-Date=20261008T173925Z&HW-CC-Expire=31536000000&HW-CC-Sign=CE0961BEB4E40F24039A59EBD74D7A45974B86219D6ACA0C756B771DDF1123A4 "点击放大")
3. 导出完成后，点击"任务管理"，下载导出结果。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2a/v3/f2BBrfj3QfuBnZGLrRDu4Q/zh-cn_image_0000002722801488.png?HW-CC-KV=V1&HW-CC-Date=20261008T173925Z&HW-CC-Expire=31536000000&HW-CC-Sign=9AD04BBD11BA537AB2ACB6DA55F768E9866B3EE19764776E2F9EC47EE7E945DF "点击放大")

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4c/v3/jtcrspO0RxuT2Emp86pAlw/zh-cn_image_0000002752561191.png?HW-CC-KV=V1&HW-CC-Date=20261008T173925Z&HW-CC-Expire=31536000000&HW-CC-Sign=6BE8B887FC1487FF24CD7AB5BC44E430DB48BAB3F864E69A671474056B209EAD "点击放大")
4. 编辑表格，仅保留需要下架的商品。 说明
   >
   > 下架场景中，"平台侧商品ID"列不可修改。
5. 点击"服务直达",返回"商品直达"页签。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/29/v3/aw6o59WIQ76h4Sq8UmZpOg/zh-cn_image_0000002752561189.png?HW-CC-KV=V1&HW-CC-Date=20261008T173925Z&HW-CC-Expire=31536000000&HW-CC-Sign=17BF333F5EA6D74415125D1D7AC4E459F3487E12E6A6618A2C9C8B14A3136F91 "点击放大")
