# 关注/取消关注通知

1）功能介绍

用户新关注或取消关注服务号时，华为服务号向开发者发送通知，告知开发者用户的Openid和Unionid，后续可用于给关注用户发送模板消息和发送图文消息。

2）约束与限制

- 开发者必须开通回调开关，服务号授权信息中配置有效的回调地址、回调密钥，操作详见[配置开发者信息](https://developer.huawei.com/consumer/cn/doc/service/developer_information-0000002633581712)。

- 关注/取关回调通知受开关控制，开关关闭时不发送通知。

- 回调请求使用 HTTPS POST 协议，Content-Type 为 application/json。

- 回调请求使用 HMAC-SHA256 签名进行身份验证，签名密钥为对应配置密钥。

3）关注/取消关注通知-请求体结构说明

接口原型

**承载协议：** HTTPS POST

**接口方向：** 服务号系统 -> 开发者服务器

**接口URL：** {回调地址}/follow/reply

**数据格式：** Content-Type: application/json

**Request Header**

|**参数**|**取值描述**|**样例**|
|:---------------|:---------------------------------------------|:---------------|
|x-signature|HMAC-SHA256 签名，使用配置的回调密钥对请求体签名后通过Base64编码后的字符串|a1b2c3d4e5f6...|
|x-access-key|来源，开发者配置的clientId|10182065|
|x-timestamp|时间戳|1785931696739|
|x-nonce|安全随机数，32位16进制字符串|854A4B...|
|x-sign-algorithm|签名算法|HMAC-SHA256|
|Content-Type|类型|application/json|

签名代码参考：

String accessKey = requestInfo.getAccessKey();

String secretKey = requestInfo.getSecretKey();

try {

// 构建待签名原文

String signContent = accessKey + timestamp + nonce + (requestBody != null ? requestBody : "");

// 计算签名

Mac mac = Mac.getInstance("HmacSHA256");

SecretKeySpec secretKeySpec = new SecretKeySpec(secretKey.getBytes(StandardCharsets.UTF_8), "HmacSHA256");

mac.init(secretKeySpec);

byte[] signatureBytes = mac.doFinal(signContent.getBytes(StandardCharsets.UTF_8));

return Base64.getEncoder().encodeToString(signatureBytes);

} catch (NoSuchAlgorithmException | InvalidKeyException e) {

log.error("Failed to generate signature", e);

}

**Request Body**

1.

   |**参数**|**是否必选**|**参数类型**|**描述**|
   |:----------|:-------|:-------|:---------------------------|
   |appId|是|String|服务号ID（pubId）。长度范围[1, 64]|
   |developerId|是|String|开发者ID。团队账号为团队ID，普通账号为华为账号ID。|
   |openId|是|String|用户关注服务号的openId。|
   |unionId|是|String|用户关注服务号的unionId。|
   |type|是|Integer|通知类型。0-关注，1-取消关注。|

**响应参数**

由开发者接口返回对应响应

**Response Body**

|**参数**|**是否必选**|**参数类型**|**描述**|
|:-----|:-------|:-------|:-----|
|code|是|String|响应码。|
|msg|是|String|响应码描述。|

**响应示例**
