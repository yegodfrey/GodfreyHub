# 查询计数变量节点

查询计数变量节点用于读取指定计数变量的当前值。该节点不会改变变量的值，仅做读取操作。  

#### 节点配置说明

|配置/参数|说明|
|:----|:-----------------------------------------------------------------------|
|计数变量|需要查询的计数变量名称。|
|输出参数|isSuccess: 节点执行结果； counterVariable: 计数变量的当前值； errorMessage: 组件执行后异常报错信息。|
