# 配置指南

卡片分发配置指南如下：

（一）[登录AGC](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)，选择要推广的元服务或鸿蒙应用，并在【服务直达】添加子服务卡，参考[服务直达](https://developer.huawei.com/consumer/cn/doc/atomic-guides/instant-service)的说明；

（二）在推广任务管理＞推广任务＞新建推广任务；

* 进入推广任务管理菜单，点击【新建】按钮创建推广任务，进入推广界面：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/74/v3/bS-zm96yTSye381_fuZ5hg/zh-cn_image_0000002616342417.png?HW-CC-KV=V1&HW-CC-Date=20261008T141023Z&HW-CC-Expire=31536000000&HW-CC-Sign=9F0569B6EBAB78059507DD7453F0868579E8FB1F11A821B49F41C61C55B574F9 "点击放大")

* 新建推广任务，选择要推广的子服务项，如果选择列表中没有您想要推广的子服务项，请先到[服务直达](https://developer.huawei.com/consumer/cn/doc/atomic-guides/instant-service)下配置。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2c/v3/ULwjiKHRQVKGv9U1Ll0wBQ/zh-cn_image_0000002660240019.png?HW-CC-KV=V1&HW-CC-Date=20261008T141023Z&HW-CC-Expire=31536000000&HW-CC-Sign=78466E6EC5D91313CBE0E9FAF695186B66702493A8333CA31E2D39AA5E3A4FB0)

配置推广策略：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6b/v3/E8bUwjxRS5-ZgJMZYU9Ctg/zh-cn_image_0000002616430713.png?HW-CC-KV=V1&HW-CC-Date=20261008T141023Z&HW-CC-Expire=31536000000&HW-CC-Sign=808145F6BECCCC29A02A74EA2E81E35271A87B255C022A9F6BD9DF7D194BCEAD "点击放大")

* 推广策略主要包含：推广日期、时间、推广预算、竞价等；
* 推广预算：通过选择不同档位的竞价和预算后，负一屏会为您整个推广周期提供服务，出价越高，推广的力度越大。当推广任务达到限额或达到推广截止时间时，则不再提供付费推广服务，改为自然流量推广；
* 点击【提交审核】，等待添卡生效；
* 子服务项的推广任务提交后系统自动审核。 [1分钟教会你 制作和推广子服务卡片](https://developer.huawei.com/consumer/cn/training/course/video/C201779076126051430)
