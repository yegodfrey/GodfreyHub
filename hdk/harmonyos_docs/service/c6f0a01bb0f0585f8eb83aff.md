# 开通服务号

服务号支持两类方式开通：标准流程开通和复用元服务资料一键开通。

方式1、标准流程开通服务号：商家可登录华为开发者联盟---华为服务号商家后台，进行服务号创建，审核通过后即可运营和管理。

方式2、复用元服务资料一键开通服务号：如果已有发布的元服务，可复用已有元服务的资料一键开通服务号，操作流程详见[一键开通服务号](#section3200193172116)。

## 方式1：标准流程开通服务号

### 服务号开通入口

1、进入开发者联盟后台，选择"智慧服务"，点击"华为服务号"卡片（若无此选项，请点击右上角"自定义桌面"，勾选"华为服务号"）。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ab/v3/0HAxkPj3QXWqVX7qGq7I2g/zh-cn_image_0000002668323224.png?HW-CC-KV=V1&HW-CC-Date=20261008T162827Z&HW-CC-Expire=31536000000&HW-CC-Sign=B6A549F1DC0B2BDB2BB258ED0E02C80509B423D3CC62307066ABB4F39B74E568 "点击放大")

2、点击"我的华为服务号 （支持Harmony5.0及以后版本）"进入服务号。Harmony5.0及以后版本与Harmony5.0之前版本的数据不互通。Harmony5.0以前申请的服务号，只支持查看历史数据。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/68/v3/9cw81rSZR0S0Ox2llv1zsw/zh-cn_image_0000002668483110.png?HW-CC-KV=V1&HW-CC-Date=20261008T162827Z&HW-CC-Expire=31536000000&HW-CC-Sign=C84528A9F39EC95DB30D374AA00D621493288DEEAE6215C9A1D6D5B691EC2B28 "点击放大")

### 创建服务号

1、点击华为服务号页面右侧的"申请华为服务号"按钮，进行服务号的创建，每个开发者账号最多支持创建5个服务号。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d9/v3/VYFsQ0yJTrmxvSwxPXB6Qg/zh-cn_image_0000002698242979.png?HW-CC-KV=V1&HW-CC-Date=20261008T162827Z&HW-CC-Expire=31536000000&HW-CC-Sign=42CA68953C469C34B0C9C581D86ED52A7999792A66B700CDC50A46E624D255B4 "点击放大")

2、首次申请服务号时，要求必须同意平台协议，否则无法申请服务号。请仔细阅读华为服务号平台合作协议，勾选"我已阅读并同意《华为服务号平台合作协议》"，并点击"同意"。

3、填写服务号信息:各字段规范请参考《[服务号基本信息规范](https://developer.huawei.com/consumer/cn/doc/service/registration_rules-0000001058075206)》。信息填写完成后，点击"下一步"提交审核。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6d/v3/AzDww3UHSEWCtMB0BzJy1w/zh-cn_image_0000002698162909.png?HW-CC-KV=V1&HW-CC-Date=20261008T162827Z&HW-CC-Expire=31536000000&HW-CC-Sign=E53C8ECE8D0330FB31ADBC1B324B8C7EC64C4E8F81F3FFE3AFC103FBB39BEE0C "点击放大")

4、提交人工审核：提交成功后，服务号为"未生效"状态，平台会在5个工作日内完成审核，服务号申请状态可以进入[查询服务号审核状态](https://developer.huawei.com/consumer/cn/doc/service/create_service_account-0000002508942747)查询。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/98/v3/pJUF5dwVTHKH-Kwl-KQmvw/zh-cn_image_0000002668323226.png?HW-CC-KV=V1&HW-CC-Date=20261008T162827Z&HW-CC-Expire=31536000000&HW-CC-Sign=A53BD9D7E79B69F9444ED2CF62BCECFC523AE5F28FE6949C5545956CBD0BCD8A "点击放大")

5、审核通过后服务号更新为"已生效"状态，并自动开通相应的功能和权限，此时服务号可向用户展示，商户可对服务号进行管理和运营。

## 方式2：复用元服务资料一键开通服务号

快速复用元服务资料一键开通服务号，无需重复提交资料即可一键开通服务号。

1、申请入口：AGC元服务管理台 >"服务号"

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d8/v3/jt0etzIMS2yjPEYDUc0Oug/zh-cn_image_0000002668483112.png?HW-CC-KV=V1&HW-CC-Date=20261008T162827Z&HW-CC-Expire=31536000000&HW-CC-Sign=F5458DF818074C6697D17A04FC9A2B562A764B694D6336020B4EAC5BA7ADA742 "点击放大")

2、选择已上架的元服务，点击"服务号"菜单，申请新服务号需要先阅读平台合作协议， 勾选"我已阅读平台协议"，点击"去开通"，进入一键申请服务号流程。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/37/v3/EG2zDuUITsWKUvbCZPToeg/zh-cn_image_0000002698242981.png?HW-CC-KV=V1&HW-CC-Date=20261008T162827Z&HW-CC-Expire=31536000000&HW-CC-Sign=3EEA513BE95CEE1E9F089DE8F1ACC48FB20196B89F26E0B27BBB6AB080A2DD4A "点击放大")

注意：

只有已上架元服务支持一键开通服务号，否则会提示错误。

每个元服务只支持申请一个同名服务号，每个开发者账号最多支持申请不超过5个服务号。

多个元服务可以关联同一个服务号。

3、如果开发者账号没有申请过服务号，会生成一个与元服务名称一样的服务号。如果已存在同名服务号，会提示创建失败。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c0/v3/7jiIiLLIThuMtBZk4vuZlg/zh-cn_image_0000002698162911.png?HW-CC-KV=V1&HW-CC-Date=20261008T162827Z&HW-CC-Expire=31536000000&HW-CC-Sign=51DBB2F36302931CAB3D9B654EB909BDB119D9B25EBDFEEDFCDA452FEBDD1FF0 "点击放大")

4、开通服务号后，元服务会与服务号建立关联，用于元服务关联AI助手回复、服务通知等功能。服务号申请状态和关联关系在列表查看。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b4/v3/2RGRndyVSRymwb45fKTrcw/zh-cn_image_0000002668323228.png?HW-CC-KV=V1&HW-CC-Date=20261008T162827Z&HW-CC-Expire=31536000000&HW-CC-Sign=A7F7ABE6C109E40AC830C4362655EEF45A930A305EAF844D11A977F6685192BD "点击放大")

5、重新进入菜单查看服务号审核进度，服务号申请状态也可以进入[查询服务号审核状态](https://developer.huawei.com/consumer/cn/doc/service/create_service_account-0000002508942747)查询。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c8/v3/Ha1zN29hQdO3mXjcwSby2w/zh-cn_image_0000002668483114.png?HW-CC-KV=V1&HW-CC-Date=20261008T162827Z&HW-CC-Expire=31536000000&HW-CC-Sign=AE28AD6AABBF3B152F891214F0C462B35A8E32409B1E8B653E47BC254B2646FB "点击放大")

6、服务号申请审核通过后，点击"AI助手回复设置"开通元服务的[AI助手回复功能](https://developer.huawei.com/consumer/cn/doc/service/ai_assistant-0000002675227619)。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0e/v3/dHUMi_HlS6WXSy_KHYHldQ/zh-cn_image_0000002698242983.png?HW-CC-KV=V1&HW-CC-Date=20261008T162827Z&HW-CC-Expire=31536000000&HW-CC-Sign=72BD1C6D4BD5B93B0190B3062EE841AE851CA76144B6DBF53433E6AEFD407CB8 "点击放大")

7、如果需要操作切换关联或取消关联，请参考章节[元服务管理](https://developer.huawei.com/consumer/cn/doc/service/atomicservice-0000002650275250)。
