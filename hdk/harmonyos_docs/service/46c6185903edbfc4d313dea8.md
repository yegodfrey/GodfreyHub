# 标签烧录工具

#### 使用方法

首先下载附件中提供的工具并进行安装，打开后展示如下页面。

![](https://media:201775734687381557)

1. 将[下载的标签数据](https://developer.huawei.com/consumer/cn/doc/service/create-service-0000002105172798#ZH-CN_TOPIC_0000002105172798__li1318115108185)粘贴到"标签内容"输入框中。
2. 如果[跳转链接参数来源](https://developer.huawei.com/consumer/cn/doc/service/create-service-0000002105172798#ZH-CN_TOPIC_0000002105172798__li20667114554214)配置了"标签中关联的MimeType的PayLoad作为查询参数"，请勾选"使用跳转链接参数"，如果没有配置该参数则直接跳转步骤5。
3. 在"跳转链接参数中"填写"[跳转链接参数](https://developer.huawei.com/consumer/cn/doc/service/create-service-0000002105172798#ZH-CN_TOPIC_0000002105172798__li20667114554214)"中配置的Key值。
4. 在"参数值"中填写"跳转链接参数的"的具体值，AirTouch会将该值进行透传携带给被拉起方，值的内容会被当做字符处理。如果开发者有特殊业务诉求，可以在该内容中进行定制化数据传递。被拉起方应用，可以在UIAbility的onCreate或者onNewWant回调中，通过want.parameters\['tagParam'\]取到该值。
5. 点击"写入标签"，将标签靠近手机，等待写入成功即可。
