# 卡片

界面与卡片均为小艺通过智能体提供的用户交互方式。卡片是一种集成化的信息展示与传递组件，卡片会从您选择的插件、工作流等组件中获取信息，然后通过一定的结构在智能体对话中展示。

卡片分为官方卡片和我的卡片：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f7/v3/5pBtz3mUSPiYexxrzb5Tow/zh-cn_image_0000002640264184.png?HW-CC-KV=V1&HW-CC-Date=20260909T130603Z&HW-CC-Expire=31536000000&HW-CC-Sign=6B1F6BA392D52376A93959CCA453F54A5D2FBB5DA931959FA05AB6064058DE4D "点击放大")

官方卡片：平台预置的卡片样式。

我的卡片：开发者自定义的卡片样式。

您可以点击历史版本来查看旧版本卡片的样式。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/25/v3/T6UeKnMmRwau0-oSKurJsg/zh-cn_image_0000002670264075.png?HW-CC-KV=V1&HW-CC-Date=20260909T130603Z&HW-CC-Expire=31536000000&HW-CC-Sign=EE75A47DD25FCE2481CEB38C7A7F3DF81E3F1F88095F2A6E479D326992ED6AAC "点击放大")

注意：卡片列表中只会显示已经发布的最新版本的卡片，因此，您可能无法访问并使用所有的卡片。

此外，本章节主要介绍卡片的配置，如果需要在智能体中使用卡片进行个性化信息展示时，可以给智能体的插件或工作流绑定自定义卡片，详见[插件绑卡](https://developer.huawei.com/consumer/cn/doc/service/plugin-card-0000002525044573)、[工作流/工作流配置](https://developer.huawei.com/consumer/cn/doc/service/workflow-configuration-5-0000002471264261)绑卡部分。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b7/v3/uCKB6ZC2QceUuEDEy7dSBA/zh-cn_image_0000002640264186.png?HW-CC-KV=V1&HW-CC-Date=20260909T130603Z&HW-CC-Expire=31536000000&HW-CC-Sign=35E99056359C42789DCBA96B684C88C68D57AEA401ABC7CD9EE162C35B78D437 "点击放大")
