# 卡片

界面与卡片均为小艺通过智能体提供的用户交互方式。卡片是一种集成化的信息展示与传递组件，卡片会从您选择的插件、工作流等组件中获取信息，然后通过一定的结构在智能体对话中展示。

卡片分为官方卡片和我的卡片：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f7/v3/5pBtz3mUSPiYexxrzb5Tow/zh-cn_image_0000002640264184.png?HW-CC-KV=V1&HW-CC-Date=20260924T081230Z&HW-CC-Expire=31536000000&HW-CC-Sign=EC155859F765B51F27C7495300B76C8AF3C787AFC77B0E0F55871AD76D7F6414 "点击放大")

官方卡片：平台预置的卡片样式。

我的卡片：开发者自定义的卡片样式。

您可以点击历史版本来查看旧版本卡片的样式。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/25/v3/T6UeKnMmRwau0-oSKurJsg/zh-cn_image_0000002670264075.png?HW-CC-KV=V1&HW-CC-Date=20260924T081230Z&HW-CC-Expire=31536000000&HW-CC-Sign=2591139C0AD771988AB431E56B05E2D0AB9AF6BF50DF03C236400EA2AD9359B1 "点击放大")

注意：卡片列表中只会显示已经发布的最新版本的卡片，因此，您可能无法访问并使用所有的卡片。

此外，本章节主要介绍卡片的配置，如果需要在智能体中使用卡片进行个性化信息展示时，可以给智能体的插件或工作流绑定自定义卡片，详见[插件绑卡](https://developer.huawei.com/consumer/cn/doc/service/plugin-card-0000002525044573)、[工作流/工作流配置](https://developer.huawei.com/consumer/cn/doc/service/workflow-configuration-5-0000002471264261)绑卡部分。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b7/v3/uCKB6ZC2QceUuEDEy7dSBA/zh-cn_image_0000002640264186.png?HW-CC-KV=V1&HW-CC-Date=20260924T081230Z&HW-CC-Expire=31536000000&HW-CC-Sign=73C7BAA60537A9137A45B5D972F883FCE2436F1C9021E605A933693C5F6F9B9B "点击放大")
