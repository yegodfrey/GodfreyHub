# 端插件权限管控

在智能体或工作流中添加需要配置权限的端插件时，需增加权限用途说明:

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3a/v3/aYe5TgqAQEmn2qrK16fMKA/zh-cn_image_0000002640104026.png?HW-CC-KV=V1&HW-CC-Date=20261008T184825Z&HW-CC-Expire=31536000000&HW-CC-Sign=02FCE671D55C43DAA8ACD64172B011A79DF90D9F1FFB90FC66596094E75FB80B "点击放大")

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/87/v3/i2tuMHhLRqKyjd5lPl48Gg/zh-cn_image_0000002640263968.png?HW-CC-KV=V1&HW-CC-Date=20261008T184825Z&HW-CC-Expire=31536000000&HW-CC-Sign=814DAF91A3E533BD10E2E773057B9A94DCC2E1613EAF852EE1703AE2CBCDC387 "点击放大")

插件添加成功后，智能体配置中的权限配置会增加权限用途描述配置：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d1/v3/ghMp94EHREmwhsSq8Pa8wQ/zh-cn_image_0000002670104003.png?HW-CC-KV=V1&HW-CC-Date=20261008T184825Z&HW-CC-Expire=31536000000&HW-CC-Sign=A235CD3580DC8CA7C8DFFDF626CC23AEBF4D21C4BF6A5D8CD2389CB18CCBE8FE "点击放大")

添加工作流后，若工作流中使用到需要权限的插件，会在权限配置页面生成对应的权限：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/21/v3/hjd8w3fLQ3yjc_9iQs7ltg/zh-cn_image_0000002670263855.png?HW-CC-KV=V1&HW-CC-Date=20261008T184825Z&HW-CC-Expire=31536000000&HW-CC-Sign=C4D4FAA54E373B465A995E977D82DF3E1B692260FF341E6353FAE4EC5322452F "点击放大")

添加工作流后查看权限配置页面，此时会自动添加所使用的权限：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9e/v3/K2FPNPUeQbWfih-tdqHUvQ/zh-cn_image_0000002640104030.png?HW-CC-KV=V1&HW-CC-Date=20261008T184825Z&HW-CC-Expire=31536000000&HW-CC-Sign=C20DE950EBBD5846BBABA58CBB6CA8A688A66A57D0673F9FCB75A8FBDCAE1495)

注意，此时的权限用途描述为空，需要手动填写用途描述，若没有填写用途描述，无法上架智能体：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ba/v3/9G4lnONxSfuKrC_apeIJjA/zh-cn_image_0000002670104001.png?HW-CC-KV=V1&HW-CC-Date=20261008T184825Z&HW-CC-Expire=31536000000&HW-CC-Sign=A6EB5DDFB3C035E830E1C4FEF148F4220DA2B56F85E45976B4C3E6A51E2740A9)

填写对应用途描述后可正常上架。

需要增加其他权限配置时，选择权限配置页面的添加权限按钮，选择需要的权限，并填写权限使用用途：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f9/v3/qrDREFZ-SrWBM81QiQMc4w/zh-cn_image_0000002640263966.png?HW-CC-KV=V1&HW-CC-Date=20261008T184825Z&HW-CC-Expire=31536000000&HW-CC-Sign=DEA8D17C600FCE09B262D500A53393DAD08E7EF1B0025D9AD1C18F88BA4681EE "点击放大")

手机端侧使用需要权限的智能体时，需要用户授权：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/40/v3/qvyOFcvtQjuxwdvHbwpxoA/zh-cn_image_0000002640104028.png?HW-CC-KV=V1&HW-CC-Date=20261008T184825Z&HW-CC-Expire=31536000000&HW-CC-Sign=182D8D115121121A0D3A1EBCB4DB34526B7D985C0FDF46B2821903D873EAD07B "点击放大")
