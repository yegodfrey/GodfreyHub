# 端插件权限管控

在智能体或工作流中添加需要配置权限的端插件时，需增加权限用途说明:

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3a/v3/aYe5TgqAQEmn2qrK16fMKA/zh-cn_image_0000002640104026.png?HW-CC-KV=V1&HW-CC-Date=20260924T081231Z&HW-CC-Expire=31536000000&HW-CC-Sign=4ED23E9CE82985642A3B1EEA353C033817296CE918D716DE7BC9C481676208A2 "点击放大")

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/87/v3/i2tuMHhLRqKyjd5lPl48Gg/zh-cn_image_0000002640263968.png?HW-CC-KV=V1&HW-CC-Date=20260924T081231Z&HW-CC-Expire=31536000000&HW-CC-Sign=A1BCFABD8B3C820FA1181E289B0DB402C75C3401672A39DC3C70F0DA01AA0395 "点击放大")

插件添加成功后，智能体配置中的权限配置会增加权限用途描述配置：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d1/v3/ghMp94EHREmwhsSq8Pa8wQ/zh-cn_image_0000002670104003.png?HW-CC-KV=V1&HW-CC-Date=20260924T081231Z&HW-CC-Expire=31536000000&HW-CC-Sign=03BBEFED3C4EE69D02A1292FD06BBC3C0E9E0546A093C9C245CB26178D5BB68B "点击放大")

添加工作流后，若工作流中使用到需要权限的插件，会在权限配置页面生成对应的权限：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/21/v3/hjd8w3fLQ3yjc_9iQs7ltg/zh-cn_image_0000002670263855.png?HW-CC-KV=V1&HW-CC-Date=20260924T081231Z&HW-CC-Expire=31536000000&HW-CC-Sign=68A24DAE622519D55A5C75DBD9B9024C5F47A3159722AEB48864D7D4BC0CA264 "点击放大")

添加工作流后查看权限配置页面，此时会自动添加所使用的权限：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9e/v3/K2FPNPUeQbWfih-tdqHUvQ/zh-cn_image_0000002640104030.png?HW-CC-KV=V1&HW-CC-Date=20260924T081231Z&HW-CC-Expire=31536000000&HW-CC-Sign=931867DD397313FA4C6AEA2BB10EEFB31E766474D631197971C1C836B5F50013)

注意，此时的权限用途描述为空，需要手动填写用途描述，若没有填写用途描述，无法上架智能体：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ba/v3/9G4lnONxSfuKrC_apeIJjA/zh-cn_image_0000002670104001.png?HW-CC-KV=V1&HW-CC-Date=20260924T081231Z&HW-CC-Expire=31536000000&HW-CC-Sign=9AE7CB396FE7166A29B63E1CA824A74C279AF48E9D8824BE3B9BF05FE232A24E)

填写对应用途描述后可正常上架。

需要增加其他权限配置时，选择权限配置页面的添加权限按钮，选择需要的权限，并填写权限使用用途：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f9/v3/qrDREFZ-SrWBM81QiQMc4w/zh-cn_image_0000002640263966.png?HW-CC-KV=V1&HW-CC-Date=20260924T081231Z&HW-CC-Expire=31536000000&HW-CC-Sign=D71FC0E04E06EC0001630B978D9C892D1DE7C913041500ACEAD38B6FFCC7AB5D "点击放大")

手机端侧使用需要权限的智能体时，需要用户授权：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/40/v3/qvyOFcvtQjuxwdvHbwpxoA/zh-cn_image_0000002640104028.png?HW-CC-KV=V1&HW-CC-Date=20260924T081231Z&HW-CC-Expire=31536000000&HW-CC-Sign=A978E5FED6A8F296DDE97CA779B94FCFBBA4BC10C906747B0A7ADA538A7599DA "点击放大")
