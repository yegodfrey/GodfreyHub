# 端插件权限管控

在智能体或工作流中添加需要配置权限的端插件时，需增加权限用途说明:

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3a/v3/aYe5TgqAQEmn2qrK16fMKA/zh-cn_image_0000002640104026.png?HW-CC-KV=V1&HW-CC-Date=20260909T174727Z&HW-CC-Expire=31536000000&HW-CC-Sign=BF2073FEDB60FF4942293887B75352232E9F87FEF2CFB802BADA4364BA8110A7 "点击放大")

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/87/v3/i2tuMHhLRqKyjd5lPl48Gg/zh-cn_image_0000002640263968.png?HW-CC-KV=V1&HW-CC-Date=20260909T174727Z&HW-CC-Expire=31536000000&HW-CC-Sign=EE5C9684276386D8802D610AD8730BF607152A9FEAF5D2F2BE1A2B188403FD2F "点击放大")

插件添加成功后，智能体配置中的权限配置会增加权限用途描述配置：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d1/v3/ghMp94EHREmwhsSq8Pa8wQ/zh-cn_image_0000002670104003.png?HW-CC-KV=V1&HW-CC-Date=20260909T174727Z&HW-CC-Expire=31536000000&HW-CC-Sign=9C63592FF6D383BCA418A6BADC48D945D50EB30B4AA4293ACC88FCBEF630ABE4 "点击放大")

添加工作流后，若工作流中使用到需要权限的插件，会在权限配置页面生成对应的权限：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/21/v3/hjd8w3fLQ3yjc_9iQs7ltg/zh-cn_image_0000002670263855.png?HW-CC-KV=V1&HW-CC-Date=20260909T174727Z&HW-CC-Expire=31536000000&HW-CC-Sign=805B7ED9D37B6001048DE03F4EA7F10C3F76EA6A8FC5D1BDD7EAC3BE9B68C816 "点击放大")

添加工作流后查看权限配置页面，此时会自动添加所使用的权限：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9e/v3/K2FPNPUeQbWfih-tdqHUvQ/zh-cn_image_0000002640104030.png?HW-CC-KV=V1&HW-CC-Date=20260909T174727Z&HW-CC-Expire=31536000000&HW-CC-Sign=C7AC76A4445815E27B12FD01A8BB070BD732AE2C1780BDA3A599BDB04E6990F6)

注意，此时的权限用途描述为空，需要手动填写用途描述，若没有填写用途描述，无法上架智能体：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ba/v3/9G4lnONxSfuKrC_apeIJjA/zh-cn_image_0000002670104001.png?HW-CC-KV=V1&HW-CC-Date=20260909T174727Z&HW-CC-Expire=31536000000&HW-CC-Sign=D209F240D235C2410CD984C207A2DE642E96D14257592D51147575AB114BEC6C)

填写对应用途描述后可正常上架。

需要增加其他权限配置时，选择权限配置页面的添加权限按钮，选择需要的权限，并填写权限使用用途：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f9/v3/qrDREFZ-SrWBM81QiQMc4w/zh-cn_image_0000002640263966.png?HW-CC-KV=V1&HW-CC-Date=20260909T174727Z&HW-CC-Expire=31536000000&HW-CC-Sign=73C5B0B13C07E00BFA4D07B83CEA8128584551F80C2492D22DA12FDF2E0A0CA4 "点击放大")

手机端侧使用需要权限的智能体时，需要用户授权：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/40/v3/qvyOFcvtQjuxwdvHbwpxoA/zh-cn_image_0000002640104028.png?HW-CC-KV=V1&HW-CC-Date=20260909T174727Z&HW-CC-Expire=31536000000&HW-CC-Sign=868AE39FBFEF9B895D10587DE282E30067BF602FC1CD9355007C5BBA3DD5D2DC "点击放大")
