# 导入Skill

#### 操作步骤

步骤1：进入Skill创建页面

登录小艺开放平台，进入【Skill】→【新建Skill】→【导入Skill】。

![](https://media:301785143819181429 "点击放大")

步骤2：上传Skill包，开始解读
