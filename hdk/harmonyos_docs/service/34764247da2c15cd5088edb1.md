# 编辑变量

卡片可能需要根据场景动态调整参数，所以需要新建变量用于在卡片中绑定动态变化的内容，真实的值通过调用时传入。

画布中组件可以绑定创建的变量用于预览，真实的值是在卡片模板配置中由插件或工作流输出参数的值决定。

变量的类型有String、Number、Array、Object、Object（聚合链接）和Boolean，Object（聚合链接）的配置方式参见[跳转](https://developer.huawei.com/consumer/cn/doc/service/multi-jump-0000002485633457)。

新建变量后，可以在内容区绑定对应的变量

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/26/v3/S0JGB77HS6WBbPc_SuFp_A/zh-cn_image_0000002640263938.png?HW-CC-KV=V1&HW-CC-Date=20260909T152243Z&HW-CC-Expire=31536000000&HW-CC-Sign=DD16CDCDE6566E880EF85FFF7EFAB82FBD3CB268214167AF227D2BE82792B8B9 "点击放大")

点击文本内容右边（x）按钮，选择变量绑定。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2a/v3/uIOAdsG9SNis1Ck8JeXPeQ/zh-cn_image_0000002640263940.png?HW-CC-KV=V1&HW-CC-Date=20260909T152243Z&HW-CC-Expire=31536000000&HW-CC-Sign=2DE52459105386D5AFA24DEBB100864E43A43CFB61FE8175895047FD3653CF75 "点击放大")

右侧的属性配置栏主要包含内容区、样式配置和事件配置。内容区的文本内容中蓝色字体表示引用的变量的名称。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6e/v3/6Drj4qAbSwuBhVD6UQEwfQ/zh-cn_image_0000002670263823.png?HW-CC-KV=V1&HW-CC-Date=20260909T152243Z&HW-CC-Expire=31536000000&HW-CC-Sign=2FF458D92CD64EEE43F79529265A3563B6A8C9D6EAB23D2E879F5583DE33F508 "点击放大")
