# 系统智能体GUI操作状态查询说明

## **1. 功能说明**

为便于应用识别华为系统智能体发起的GUI操作，HarmonyOS提供系统智能体身份及GUI操作状态查询机制。系统智能体执行GUI操作1时，应用可查询当前操作状态及系统智能体身份标识（Agent DID），并结合自身业务规则和安全要求，对相关操作进行响应或限制。

如应用不希望支持系统智能体GUI操作，可按照本文第3节提交限制申请。

## **2. 查询系统智能体GUI操作状态**

用户主动发起并授权系统智能体执行任务后，在GUI操作开始，系统会将操作状态及Agent DID写入系统Settings数据库。开发者可通过以下代码查询并监听AI_Operation_Mode设置项。Settings接口的使用方法请参见[Settings API参考](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-settings)。

```screen
settings.registerKeyObserver(context, 'AI_Operation_Mode', async () => {
const rawValue = await settings.getValue(
context,
'AI_Operation_Mode',
'',
settings.domainName.USER_PROPERTY
);
await verifyAiOperationMode(rawValue);
});

const initialValue = await settings.getValue(
context,
'AI_Operation_Mode',
'',
settings.domainName.USER_PROPERTY
);
await verifyAiOperationMode(initialValue);
```

建议应用进入前台时，通过settings.getValue查询一次当前状态，并通过settings.registerKeyObserver监听后续状态变化。应用可按照以下规则解析并校验查询结果：

1.设置项为空，表示当前未处于系统智能体GUI操作状态。

2.设置项包含有效的开启状态，表示系统智能体正在执行GUI操作。

3.设置项包含有效的关闭状态或恢复为空，表示本次GUI操作已经结束。

## **3. 申请限制系统智能体GUI操作**

如应用不希望支持系统智能体GUI操作，可发送申请邮件至hagservice@huawei.com。邮件标题及内容建议采用以下格式：

* 邮件标题：【系统智能体操控拒绝申请】应用名称
* 应用名称
* 应用包名（Bundle Name）
* 开发者名称及联系方式
* 申请限制GUI操作的原因

申请经核验并生效后，系统智能体将不再在相应应用中发起GUI操作。
