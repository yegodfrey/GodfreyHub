# HarmonyOS系统Agent GUI辅助操作机制说明

## **1. 功能说明**

随着Agent应用协同能力持续发展，华为坚持以MCP、A2A等标准化接口作为生态合作的优先方式，推动系统Agent与生态应用实现高效、安全的能力调用和任务协同。同时，充分考虑不同生态伙伴的业务特点、技术条件及智能化改造节奏，对于标准化接口暂未覆盖的场景，在用户主动发起并授权的前提下，系统Agent可通过GUI方式辅助用户完成部分应用操作，作为标准化接口能力的必要补充，为用户提供更加连续、完整的智能服务体验。

GUI辅助操作坚持审慎、适度原则，仅用于现阶段确有必要、风险可控的场景，严格遵循最小必要原则，不绕过应用的登录认证、权限控制、验证码及业务风控机制。

为充分尊重生态伙伴的业务自主权和安全管理要求，HarmonyOS提供系统Agent身份及GUI操作状态查询机制。应用可查询系统Agent的操作状态和身份标识（Agent DID），并依据自身业务规则和安全要求，对相关操作进行响应或限制，实现系统Agent与生态应用之间透明、可识别、可管理的安全协同。

华为将持续深化与生态伙伴的合作，结合实际使用情况和伙伴需求，优先推动高频、成熟场景逐步向MCP、A2A等标准化接口演进，降低伙伴智能化适配成本，持续提升Agent协同效率与用户体验。

## **2. 用户授权与操作控制**

系统Agent GUI辅助操作遵循用户主动发起、明确授权、过程可控的原则，保障用户对任务执行过程的知情权和控制权。

* **用户主动授权：**GUI辅助操作由用户主动发起并授权，系统Agent不会自行启动与用户任务无关的应用操作。
* **遵循既有权限：**系统Agent仅在用户既有账号权限和应用既有安全规则范围内辅助执行任务，不扩大用户原有的操作权限。
* **任务过程可控：**用户可在执行过程中查看任务进展，并随时暂停或终止任务。
* **高风险操作确认：**涉及支付、转账、删除数据、对外发布等高风险操作时，系统根据安全分级策略限制执行或要求用户再次确认。
* **能力自主管理：**用户可通过系统设置管理或关闭相关能力。

## **3.** **安全与数据保护机制**

系统Agent GUI辅助操作依托HarmonyOS系统级安全能力运行，通过安全隔离、权限约束、风险管控和安全审计等机制，保障用户数据安全及应用业务安全。具体包括：

* **安全隔离：**相关能力运行在系统级受控环境中，通过系统沙箱、权限管理和应用隔离机制限制操作范围，保障应用间的数据和权限边界。
* **数据保护：**任务涉及的界面信息及相关数据仅根据完成用户任务的实际需要，在终端本地及鸿蒙个人智能计算安全区（HPIC）内进行最小化处理。相关数据在安全区内受到隔离保护，华为人员无法访问任务数据明文，相关数据不用于模型训练。
* **应用规则保护：**系统Agent遵循应用既有的登录认证、权限控制、验证码及业务风控机制，不绕过应用安全校验，不调用未经授权的应用专用接口。
* **高风险管控：**系统根据应用、任务及操作风险实施分级管控，对高风险或异常操作进行限制、拦截或终止，必要时要求用户再次确认。
* **安全审计：**对系统Agent身份、任务执行过程及异常事件进行必要的安全审计和留痕，支持安全事件排查与问题追溯。
* **应急处置：**当应用伙伴提出操作限制需求或发现异常风险时，华为可根据具体应用、功能及任务范围，及时调整、暂停或关闭相关GUI辅助操作能力。

## **4. 查询系统Agent GUI操作状态**

为帮助开发者识别和管理系统Agent GUI辅助操作，HarmonyOS提供相应的操作状态及身份标识查询机制。

用户主动发起并授权系统Agent执行任务后，在GUI操作开始，系统会将操作状态及Agent DID写入系统Settings数据库。开发者可通过以下代码查询并监听AI_Operation_Mode设置项。Settings接口的使用方法请参见[Settings API参考](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-settings)。

```screen
settings.registerKeyObserver(context, 'AI_Operation_Mode', async () => {
const rawValue = await settings.getValue(
context,
'AI_Operation_Mode',
'',
settings.domainName.USER_PROPERTY
);
await verifyAiOperationMode(rawValue);
});

const initialValue = await settings.getValue(
context,
'AI_Operation_Mode',
'',
settings.domainName.USER_PROPERTY
);
await verifyAiOperationMode(initialValue);
```

建议应用进入前台时，通过settings.getValue查询一次当前状态，并通过settings.registerKeyObserver监听后续状态变化。应用可按照以下规则解析并校验查询结果：

1.设置项为空，表示当前未处于系统Agent GUI操作状态。

2.设置项包含有效的开启状态，表示系统Agent正在执行GUI操作。

3.设置项包含有效的关闭状态或恢复为空，表示本次GUI操作已经结束。

## **5. GUI** **辅助操作能力开放**

为满足不同伙伴在智能化改造过程中的实际需求，华为也开放GUI辅助操作能力，支持伙伴在标准化接口暂未覆盖或短期内改造成本较高的场景中，探索新的智能化服务体验。应用伙伴可根据自身业务需求，申请调用华为GUI辅助操作能力，在双方确认的业务范围内，为用户提供应用内的智能化任务执行服务。

伙伴接入的GUI辅助操作能力与华为系统Agent复用同一套系统级底层能力，并采用统一的身份识别、安全隔离、风险管控和审计机制，帮助伙伴降低智能化适配成本，加快创新体验落地。

对于经过实际使用验证、具备规模化应用价值的高频成熟场景，华为将与生态伙伴共同推动相关能力逐步向MCP、A2A等标准化接口演进，持续完善Agent应用协同生态。

## **6** **.** **生态合作与意见反馈**

华为重视生态伙伴的业务诉求与安全管理要求，欢迎开发者围绕系统Agent应用协同开展合作，并对GUI辅助操作机制提出意见和建议。如需申请接入相关能力、了解生态合作方式，或希望对系统Agent GUI辅助操作进行响应或限制，可通过以下渠道联系我们。

### 6.1 联系方式

联系邮箱：hagservice@huawei.com

请根据具体需求，在邮件标题中注明申请类型：

* 【系统Agent生态合作申请】应用名称
* 【系统Agent GUI辅助操作限制申请】应用名称
* 【系统Agent GUI辅助操作意见反馈】应用名称

### 6.2 申请信息

为便于及时了解和处理相关需求，建议在邮件中提供以下信息：

|**信息项**|**说明**|
|:--------------------|:-------------|
|**应用名称**|申请涉及的应用名称|
|**应用包名（Bundle Name）**|申请涉及的应用包名|
|**开发者信息**|开发者名称及联系方式|
|**申请类型**|能力合作、操作限制或意见反馈|
|**涉及场景**|拟合作或申请限制的业务场景|
|**功能及任务范围**|具体涉及的应用功能和操作范围|
|**申请说明**|合作需求、限制原因或具体意见|

华为将在核验相关信息后，根据双方确认的应用、功能或任务范围，添加、调整或停止相关GUI辅助操作。华为将持续完善系统Agent与生态应用的协同机制，提升操作状态透明度与精细化管理能力，与开发者共同建设开放、安全、可持续发展的Agent应用生态。
