# 批量删除门店

1. 在"门店管理"页签，点击批量删除。 ![](https://media:401788945858871363 "点击放大")

2. 下载批量删除的导入模板。 ![](https://media:401788945858906364 "点击放大")

3. 填写需要删除的门店ID后上传文件。 ![](https://media:401788945858944365 "点击放大")
