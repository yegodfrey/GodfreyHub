# 创建插件

如果你已有可用的工具、API 资源，则你可以上架自定义 MCP 插件。

MCP插件创建入口：可以通过点击【小艺开放平台】-【立即体验】进入【资源库】，然后在【MCP】页面创建：

进入MCP页面后，点击新建MCP开始创建。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/db/v3/b4XqEOxwRYCf8y6PDfBMrg/zh-cn_image_0000002640104264.png?HW-CC-KV=V1&HW-CC-Date=20260909T134614Z&HW-CC-Expire=31536000000&HW-CC-Sign=3C9AF32A89BAC2232ADACC6D3FEF628551965B9D982CC1EE55939E485995A184 "点击放大")

MCP插件注册方式有两种：标准注册和外部平台导入。

* 标准注册：手动填写插件信息注册保存后手动发布。
* 外部平台导入：若开发者在魔搭平台已有自部署的**长期有效** 的MCP插件，可以用此方式批量导入插件列表。注意：此方式创建的MCP插件**仅支持发布到智能体渠道**供本账号调试，无法发布到插件市场、主对话渠道公开使用。

* **[标准注册](https://developer.huawei.com/consumer/cn/doc/service/mcp-plugin-par-0000002525597351)**   
* **[外部平台导入](https://developer.huawei.com/consumer/cn/doc/service/mcp-plugin-import-0000002493437678)**
