# 服务号运营规范

本规范主要介绍服务号平台对开发者运营服务号的规则和要求、以及违规的处罚措施。  

#### 服务号文章和图文消息运营规范

1. 总则

1.1 本规范旨在保障华为服务号内容生态的合规性，重点打击侵权行为，规范营销活动。

1.2 处理机制：

* 事前拦截：涉及淫秽色情、赌博、暴恐、反动等严重违法内容，由风控系统直接拦截，不予上线。
* 事后处罚：对于侵权、违规营销等上线后的内容，平台采取以下两种处罚措施：
  1. 文章下线：违规内容从平台移除。
  2. 服务号下线：账号功能停止。

2. 知识产权与侵权类

原则：保护原创，打击假冒。针对已发布的内容进行审查与治理。

2.1 主体侵权

违规定义：擅自使用他人企业名称、商标，或冒充官方/品牌方账号误导用户。

* 处理：
  * 一般混淆（如名字近似）：文章下线，责令整改账号信息。
  * 恶意冒充（如冒充政府、公检法）：直接服务号下线。

2.2 内容侵权

违规定义：未经授权发布他人原创文章、图片、视频，泄露隐私，诽谤他人。

* 处理：
  * 接到有效投诉或审核发现：文章下线。
  * 同一账号累计违规3次及以上：服务号下线。

2.3 假冒、盗版

违规定义：推广、售卖高仿、复刻、假冒伪劣商品。

* 处理：
  * 涉及具体商品推广：文章下线。
  * 账号核心业务为售假：服务号下线。

3. 营销内容规范

原则：支持营销，但禁止利用虚假信息、低俗手段欺骗用户。

3.1 虚假宣传

违规定义：内容存在明显违背事实的夸大（如保健品宣传治病、理财承诺稳赚），或假借权威名义（伪造专家背书）。

* 处理：文章下线。

3.2 诱导点击

违规定义：标题与正文内容严重不符，或使用惊悚、虚假官方口吻诱导点击。

* 处理：文章下线。

3.3 低俗营销

违规定义：使用性暗示、低俗图片、两性隐私话题进行商品推广（注：纯色情内容由风控直接拦截）。

* 处理：文章下线。

3.4 恶意引流

违规定义：文章内容空洞，恶意诱导用户脱离平台监管进行私下交易。

* 处理：文章下线；若涉及诈骗，直接服务号下线。

4. AIGC（生成式人工智能）内容规范

原则：提供工具，鼓励自律，不强制强制处罚。

4.1 功能说明

平台编辑器提供"内容由AI生成"选项，供运营者在发布图文时自行勾选，以便向读者如实展示内容来源。

4.2 规范要求

* 鼓励标识：建议运营者对AI辅助创作的内容勾选该选项，维护内容透明度。
* 底线红线：严禁利用AI生成技术制造虚假新闻、谣言或进行诈骗活动。此类内容一经发现，无论是否勾选，均直接文章下线；情节严重者服务号下线。

5. 风控拦截范围

以下类型内容属于严重违规，由平台风控系统直接拦截，不允许发布上线：

* 涉黄、涉暴、涉恐内容；
* 赌博、诈骗、传销信息；
* 危害国家安全、泄露国家秘密的内容；
* 其他违反法律法规及监管政策的内容。

#### 服务号模板消息运营规范

违规内容：

利用模板消息接口，从事以下行为：

1. 发送内容与服务场景不一致（含标题、关键词）的模板消息，或在部分位置填入与对应关键词不一致的内容。
2. 频繁发送相同内容或性质的模版消息，对用户造成骚扰。包括但不限于：频率过高的到期提醒类通知、频率过高的缴费提醒类通知、频率过高的留言提醒类通知、订阅提醒类通知等。
3. 在模板消息中部分位置下发与场景无关的营销推广或诱导性内容 ，包括但不仅限于欺诈、虚假、交易纠纷等信息。

处罚规则

一经发现将根据违规程度对该服务号采模板消息能力封禁，或实施下线服务号处理措施。
