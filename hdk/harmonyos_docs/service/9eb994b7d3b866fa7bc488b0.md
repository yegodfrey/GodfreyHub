# 下架个性化设置

1. 对于已通过审核、服务状态为"已上架"的个性化设置，开发者可进行下架个性化设置的操作。 ![](https://media:401788945859015367 "点击放大")

2. 下架后，个性化设置状态由"已上架"变更为"已下架"，后续可进行查看和编辑操作。 ![](https://media:401788945859060368 "点击放大")

   ![](https://media:401788945859090369)  
如果您的子服务关联的个性化被下架且您未关联新的个性化数据，则此卡将不可被分发。
