# 下架个性化设置

1. 对于已通过审核、服务状态为"已上架"的个性化设置，开发者可进行下架个性化设置的操作。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/58/v3/do5XB_I3Sj6_93LdqnrT5g/zh-cn_image_0000002752561117.png?HW-CC-KV=V1&HW-CC-Date=20261008T193359Z&HW-CC-Expire=31536000000&HW-CC-Sign=6E8CC90926D7BE61B632117A0CD288E987A84D3470E603A45B608043A5720109 "点击放大")

2. 下架后，个性化设置状态由"已上架"变更为"已下架"，后续可进行查看和编辑操作。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9d/v3/p1RTBD41QUWCGFBjmxP_-w/zh-cn_image_0000002752481217.png?HW-CC-KV=V1&HW-CC-Date=20261008T193359Z&HW-CC-Expire=31536000000&HW-CC-Sign=CA9B2DFC102D5FCCC9F37CBBF4A3684AF521E08B4D7B9D9FC9E0B847ECA2FAFC "点击放大")

   > 说明
   >
   > 如果您的子服务关联的个性化被下架且您未关联新的个性化数据，则此卡将不可被分发。
