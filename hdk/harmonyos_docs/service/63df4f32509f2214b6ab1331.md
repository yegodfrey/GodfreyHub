# 基于意图框架创建端插件

插件创建方式选择"端插件-选择意图框架"进行创建。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f7/v3/nY5c9l_FR7WYvz-j7D7g8w/zh-cn_image_0000002640264044.png?HW-CC-KV=V1&HW-CC-Date=20260924T081231Z&HW-CC-Expire=31536000000&HW-CC-Sign=E20D559D7E840181E3D46EAE039C01B2230E7D5D128B122FD47E3006BA10D8D5 "点击放大")

当选择已有意图后，系统将自动填充以下字段：APP包名、APP名称、服务类型，只需要补充插件描述即可。
