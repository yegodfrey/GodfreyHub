# Agent

本文档旨在指导开发者如何在小艺开放平台创建Skill时，通过引入Agent 来增强Skill的能力。Agent作为自主化软件实体，能够为Skill提供任务规划、资源调用和工作流执行等高级能力。

## Agent来源

|来源|说明|使用场景|
|:------|:-----------------|:-------------------------------|
|我的Agent|开发者自行创建或授权的私有Agent|自有智能化能力复用、团队内Agent共享、定制化 Agent集成|
|合作伙伴|平台合作方提供的专有Agent|生态能力集成、垂直领域专业Agent、商业 Agent服务|

## Agent类型

|类型|核心特点|适用场景|需求场景|
|:---------|:------------------|:--------------|:-----------|
|LLM模式|基于大语言模型，自然语言驱动|对话式任务、内容生成、简单推理|快速构建对话式AI|
|云工作流模式|预定义工作流，步骤式执行|业务流程自动化、多步骤任务|确定性业务流程自动化|
|云A2A模式|多Agent云端协作，任务分发|复杂任务分解、多专家协作|需要多专家协作的复杂任务|
|端A2A模式|端侧Agent协作，低延迟响应|离线场景、隐私敏感任务|隐私敏感或离线场景|
|OpenClaw模式|基于OpenClaw框架，工具调用优先|需要多工具协作、复杂任务编排|多工具调用、复杂编排|

## 操作步骤

**步骤1：进入Skill创建页面**

登录小艺开放平台，进入【Skill】→【新建Skill】。

**步骤2：填写基本信息**

在对话框内填写Skill名称、描述、触发意图等基础信息。

**步骤3：选择Agent**

点击对话框下方的【@】按钮，点击【Agent】选项。选择【Agent来源】

**步骤4：添加Agent**

在Agent列表中找到所需Agent，点击添加Agent到当前Skill
