# 管理团队账号与成员账号

应用场景：主账号管理员申请服务号后，企业内部多个角色的操作员如需开发或运营服务号， 可以通过团队账号和成员账号管理功能实现。

1）管理员账号添加成员账号

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ba/v3/dSmCc71zTKKPcl2wqfwm4w/zh-cn_image_0000002558680554.png?HW-CC-KV=V1&HW-CC-Date=20260909T180917Z&HW-CC-Expire=31536000000&HW-CC-Sign=67FAB895261D12C1C4C21A22EC682258A913DF3F7EDF6899992FE926F7B6DBDC "点击放大")

使用服务号管理员账号（首次申请服务号时的账号）登录联盟管理中心，进入"开发者中心">"团队账号"菜单；

管理员可将操作员账号添加为成员账号。成员账号支持个人账号和企业账号两种类型，企业类型的成员账号无需完成企业认证。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b0/v3/mxlr_emrRVCqXUIA-uWoTA/zh-cn_image_0000002558520920.png?HW-CC-KV=V1&HW-CC-Date=20260909T180917Z&HW-CC-Expire=31536000000&HW-CC-Sign=F33935461AAFF7170DD92FE80384929311668B639AECBE676D6FB9B9B24B1096 "点击放大")

2）配置角色与应用

应用选择：选择"服务号"

角色选择：按实际角色选择（针对服务号业务，目前只支持管理员角色，成员账号具备管理同开发者账号下所有服务号的能力）

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e7/v3/CU9oLuwZRrieRvbt_DPiTw/zh-cn_image_0000002589080447.png?HW-CC-KV=V1&HW-CC-Date=20260909T180917Z&HW-CC-Expire=31536000000&HW-CC-Sign=96C89AA27E0A30B8BFB225966D73E26C6F29EDCECF7A8B4F19C7C951DD0A1F0B "点击放大")

3）确认账号信息

管理员账号操作加入成员账号成功后，会发送一条通知子账号确认的消息，需要成员账号确认并接受邀请，成员账号点击确认后即可生效，生效后的成员账号具备完整的服务号管理能力。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/74/v3/i1KHQ53aQ8yIc1UpXTOcjw/zh-cn_image_0000002589160379.png?HW-CC-KV=V1&HW-CC-Date=20260909T180917Z&HW-CC-Expire=31536000000&HW-CC-Sign=D83F7A68157F518D81B4C202862CDE3CD5DECC94B8FAAB4772080A7D99EBAD55 "点击放大")

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cf/v3/3CmtFOXCTiGpkPa2j4oQcg/zh-cn_image_0000002558680556.png?HW-CC-KV=V1&HW-CC-Date=20260909T180917Z&HW-CC-Expire=31536000000&HW-CC-Sign=978BDF1037DD8FB2D4AB7951D45F2871DC7505E4C079FB508435D0E942C6D3B3 "点击放大")

4）成员账号登录成功后，进入服务号栏目，在"我的"账号里面选择团队账号，即可查看和操作团队账号下的服务号。
