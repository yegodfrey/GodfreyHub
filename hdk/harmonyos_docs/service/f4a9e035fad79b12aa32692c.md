# 管理团队账号与成员账号

应用场景：主账号管理员申请服务号后，企业内部多个角色的操作员如需开发或运营服务号， 可以通过团队账号和成员账号管理功能实现。

1）管理员账号添加成员账号

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ba/v3/dSmCc71zTKKPcl2wqfwm4w/zh-cn_image_0000002558680554.png?HW-CC-KV=V1&HW-CC-Date=20261008T191127Z&HW-CC-Expire=31536000000&HW-CC-Sign=8E18779531F6A3395F58D8219B411760DEC1FAA4B79B7380D2B5CD8AA9BA94CF "点击放大")

使用服务号管理员账号（首次申请服务号时的账号）登录联盟管理中心，进入"开发者中心">"团队账号"菜单；

管理员可将操作员账号添加为成员账号。成员账号支持个人账号和企业账号两种类型，企业类型的成员账号无需完成企业认证。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b0/v3/mxlr_emrRVCqXUIA-uWoTA/zh-cn_image_0000002558520920.png?HW-CC-KV=V1&HW-CC-Date=20261008T191127Z&HW-CC-Expire=31536000000&HW-CC-Sign=9834D82BEF69CF823FADCF15D60DD8FAA1070B4B17D9A0732AAE056ED6625FFC "点击放大")

2）配置角色与应用

应用选择：选择"服务号"

角色选择：按实际角色选择（针对服务号业务，目前只支持管理员角色，成员账号具备管理同开发者账号下所有服务号的能力）

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e7/v3/CU9oLuwZRrieRvbt_DPiTw/zh-cn_image_0000002589080447.png?HW-CC-KV=V1&HW-CC-Date=20261008T191127Z&HW-CC-Expire=31536000000&HW-CC-Sign=3784AC86699E8A463AE9411CF9166230C37D4D972676C66A01E1C2089CE62480 "点击放大")

3）确认账号信息

管理员账号操作加入成员账号成功后，会发送一条通知子账号确认的消息，需要成员账号确认并接受邀请，成员账号点击确认后即可生效，生效后的成员账号具备完整的服务号管理能力。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/74/v3/i1KHQ53aQ8yIc1UpXTOcjw/zh-cn_image_0000002589160379.png?HW-CC-KV=V1&HW-CC-Date=20261008T191127Z&HW-CC-Expire=31536000000&HW-CC-Sign=2C3DB8E311D702D718EE7649492273396BBA243F5F8F6EE2E857EAF109D84AA1 "点击放大")

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cf/v3/3CmtFOXCTiGpkPa2j4oQcg/zh-cn_image_0000002558680556.png?HW-CC-KV=V1&HW-CC-Date=20261008T191127Z&HW-CC-Expire=31536000000&HW-CC-Sign=BDB97CCEEB84C9687869523B329E07BDD092DECA8D4647BACD7398F8CECC4695 "点击放大")

4）成员账号登录成功后，进入服务号栏目，在"我的"账号里面选择团队账号，即可查看和操作团队账号下的服务号。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9b/v3/BHQ_HW5-QJqe42XpY9VB0A/zh-cn_image_0000002558520922.png?HW-CC-KV=V1&HW-CC-Date=20261008T191127Z&HW-CC-Expire=31536000000&HW-CC-Sign=F1B2B01AE0866B6EBEDC8AA161CA37486DD85C0F1A6FFA83853EB25D3B500A3B "点击放大")
