# Skill接入华为账号

## 概述

账号服务（Account Service）允许Skill在运行时自动获取用户的登录凭证（loginToken），无需用户手动输入apiKey，系统会自动完成授权和刷新流程。

## Skill账号绑定方式

当使用的Skill需要登录账号获取apiKey时，可以通过【账号绑定设置】进行配置实现，完成后可在手机端基于华为账号一键登录授权。

账号绑定方式共有两种：

（1）与小艺Claw对话，使用到Skill时，若账号未授权或授权已过期，对话中会弹出授权卡引导用户登录授权，用户点击"同意并绑定"时，发起账号绑定授权流程。

## Skill凭证获取流程与开发者适配

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fa/v3/2wYc3iGVS-6zDx91PRcThQ/zh-cn_image_0000002640264008.png?HW-CC-KV=V1&HW-CC-Date=20260924T081230Z&HW-CC-Expire=31536000000&HW-CC-Sign=C4CD1CFBA5FA6BC5A982588F3914923BA49C27EE62B221CE2F08FA3853CAADF8 "点击放大")

**开发上架说明：**

（1）开发者需要开通账号获取clientId，并在小艺开放平台中配置账号绑定服务（配置clientId，服务器API地址）。

（2）开发者需要修改SKILL.md文件。文件中声明涉及用户账号的域名，在环境变量中获取账号凭证，如果获取不到或者已过期，使用工具刷新环境变量。

**运行说明：**

（1）Skill运行过程中，从环境变量中获取账号凭证（ loginToken ），用于标识用户。

（2）如果获取不到，说明用户未授权或已过期，需要声明调用账号工具来刷新环境变量。

（3）工具执行过程中，用户授权后，小艺会携带authCode到开发者服务器换取 loginToken （7天有效） 和 loginRefreshToken （半年有效），前者用于身份认证后者用于刷新前者。

（4）工具执行过程中，如果用户已经授权过了，只是loginToken过期，无需用户二次授权，小艺会使用loginRefreshToken来开发者服务器侧更新loginToken 。

（5）获取loginToken后，访问业务服务器时，需要在header中追加loginToken，作为用户身份凭据。
> 说明
>
> clientId是Skill申请获取华为账号的唯一标识，开发者需要在华为开发者联盟账号服务中获取clientId或者创建一个clientId，并将其在 Agent开发界面注册保存。

## 接口开发

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/20/v3/aiTS31C0RgmEqAX7MfQPWQ/zh-cn_image_0000002670263897.png?HW-CC-KV=V1&HW-CC-Date=20260924T081230Z&HW-CC-Expire=31536000000&HW-CC-Sign=8FCE8ABB6A4A9FB37563CF050688277277A1E2A6FDB561BF9EE001639F89856E "点击放大")

开发者需要实现以下回调接口，供小艺Claw在授权、刷新、解绑账号时调用。

支持AK/SK、Header、Query三种鉴权模式，在账号服务配置时选择，建议优先使用AK/SK鉴权模式。

AK/SK模式下，每次请求需在Header中携带以下参数：

|**参数**|**类型**|**必选**|**说明**|
|:-----------|:-----------|:-----|:-----------------------------------------------------------------------|
|Content-Type|String|M|固定值 application/json|
|accessKey|String (64)|M|认证信息配置中 Access Key 的值|
|sign|String (256)|M|参数签名 = Base64(HMAC-SHA256(secretKey, ts))，secretKey 为认证配置中 Secret Key 的值|
|ts|String (16)|M|毫秒级时间戳，例如 1514764800000|

Header 模式下，每次请求，会在Header携带开发者在账号服务配置时填写的header键值对。

Query模式下，每次请求，会将开发者在账号服务配置时填写的query拼接到请求url中。

### 账号绑定（授权）接口

用户完成华为账号授权后，小艺携带authCode调用此接口换取login_token。

请求示例

```codeblock
curl '{{server_url}}' \ 
 --header 'Content-Type: application/json' \ 
 --header 'accessKey: {{平台配置的接入码}}' \ 
 --header 'ts: {{毫秒级时间戳}}' \ 
 --header 'sign: {{Base64(HMAC-SHA256(secretKey, ts))}}' \ 
 -d '{ "jsonrpc": "2.0", "id": "{{全局唯一消息序列号}}", "method": "authorize", "params": { "message": { "role": "user", "parts": [{ "kind": "data", "data": { "authCode": "{{华为账号授权码}}", "clientId": "{{账号服务唯一标识}}" } }] } } }'
```

响应示例

```codeblock
{
         "jsonrpc" : "2.0",
         "id" : "{{全局唯一消息序列号}}",
         "result" : {
                  "loginToken" : "登录token",
                  "loginTokenExpireTime" : "2026-04-29T18:54:00+08:00",
                  "loginRefreshToken" : "刷新token",
                  "loginRefreshTokenExpireTime" : "2026-10-29T18:54:00+08:00"
         },
         "error" : {
                  "code" : 0,
                  "message" : ""
         }
}
```

开发者拿到authCode，需调用账号云，换取用户手机号，使用用户手机号关联loginToken及相关业务。调用华为账号服务器，先使用authCode获取accessToken，再使用accessToken获取用户手机号。

接口1：使用上报的authCode，换取accessToken。接口详情见：[获取凭证Access Token](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/account-obtain-token_hms_reference-0000001050048618)

接口2：使用accessToken换取用户信息（手机号、openId等）。接口详情见：[获取用户信息](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/get-user-info-0000001060261938)

### token刷新接口

loginToken 过期或临期（距过期 ≤2 天）时，小艺使用loginRefreshToken调用此接口刷新，此流程对用户无感。

请求示例

```codeblock
curl '{{server_url}}' \
 --header 'Content-Type: application/json' \
 --header 'accessKey: {{平台配置的接入码}}' \
 --header 'ts: {{毫秒级时间戳}}' \
 --header 'sign: {{Base64(HMAC-SHA256(secretKey, ts))}}' \
 -d '{"jsonrpc":"2.0","id":"{{全局唯一消息序列号}}","method":"refreshToken","params":{"message":{"role":"user","parts":[{"kind":"data","data":{"loginRefreshToken":"{{刷新token}}"}}]}}}
```

响应示例

```codeblock
{
         "jsonrpc" : "2.0",
         "id" : "{{全局唯一消息序列号}}",
         "result" : {
                  "loginToken" : "登录token",
                  "loginTokenExpireTime" : "loginToken过期时间，推荐7天（为了方便模型理解，用+8区时间）:2026-04-22T18:54:00+08:00"
         },
         "error": {
         "code": "{{JSONRPCError错误码， 整形或字符串类型，0表示成功}}",
         "message": "{{JSONRPCError错误描述}}"
}}
```

### 账号解绑接口

用户主动解绑时，小艺调用此接口通知开发者服务器解绑账号信息。

请求示例

```codeblock
curl '{{server_url}}' \
 --header 'Content-Type: application/json' \
 --header 'accessKey: {{平台配置的接入码}}' \
 --header 'ts: {{毫秒级时间戳}}' \
 --header 'sign: {{Base64(HMAC-SHA256(secretKey, ts))}}' \
 -d '{"jsonrpc":"2.0","id":"{{全局唯一消息序列号}}","method":" deauthorize","params":{"message":{"role":"user","parts":[{"kind":"data","data":{"loginRefreshToken":"{刷新token}"}}]}}}
```

响应示例

```codeblock
{
 "jsonrpc": "2.0",
 "id": "{{全局唯一消息序列号}}",
 "result": {
},
 "error": {
 "code": 0,
 "message": ""
 }}
```

## SKILL.md整改

开发者需要修改SKILL.md文件。其中声明涉及用户账号的域名，在环境变量中获取账号凭证，如果获取不到或者已过期，使用工具刷新环境变量。

SKILL.md整改样例

````codeblock
---
name: skill-name-test
description: 聚合妙想金融数据、资讯搜索、智能选股、自选股管理、模拟组合管理、综合诊股、综合诊基、股市热点发现八类能力的综合skill，统一使用华为合作侧 login-token 请求头与开放接口路径。
version: 1.0.0
env:
  - 000000000_login_token: "从/home/sandbox/.openclaw/.xiaoyienv文件中读取账号凭证；若为空，或当前时间大于 ${000000000_login_token_expire_time} 的取值（即凭证已过期），调用一次 huawei_id_tool工具（工具参数：clientId=000000000，skillName= skill-name-test）刷新凭证；刷新成功后重新读取账号凭证，继续执行后续业务逻辑"
  - 000000000_login_token_expire_time: "账号凭证过期时间；当前时间大于该值时需先刷新凭证再继续调用"
---
 
# skill-name-test金融股票查询skill
 
本 Skill 聚合 2 类能力：金融数据、资讯搜索、根据用户问题自动选择最合适的金融能力进行调用。
 
## 能力概览
 
| 能力模块 | 适用场景 | 代理接口 |
|----|----|----|
| 金融数据 | 查询股票行情、财务指标、公司关系、经营数据 | `POST /api/open/xxx1` |
| 资讯搜索 | 查询新闻、公告、研报、政策、事件信息 | `POST /api/open/ xxx1` |
 
## 凭据说明
 
- 统一使用.xiaoyienv文件 `000000000_login_token` 和 `000000000_login_token_expire_time`。
- 若 `000000000_login_token` 为空，或当前时间大于 `000000000_login_token_expire_time`，调用一次 huawei_id_tool工具（工具参数：clientId=000000000，skillName=skill-name-test） 刷新凭证（升级小艺APP和小艺Claw到最新版本后支持）。
- 刷新成功后重新读取.xiaoyienv文件，再继续后续业务逻辑。
- 所有请求头统一使用 `login-token: ${000000000_login_token}`。
- 凭据只从.xiaoyienv文件读取，禁止写死到代码或示例以外的固定位置。
 
## 调用规范
 
1. 所有接口均使用 `POST`。
2. 所有请求头均包含 `Content-Type: application/json` 和 `login-token`； 
3. 先根据用户意图选择能力模块，再调用对应代理接口。
4. 查询结果为空时，优先提示用户收窄或细化条件。
5. **凭证授权失败处理（强制）**：若遇到登录状态异常，优先检查凭证是否缺失或过期，调用一次 huawei_id_tool工具（工具参数：clientId=000000000，skillName= skill-name-test），仅调用一次，不可重复调用。
 
通用请求头示例：
 
```javascript
--header 'Content-Type: application/json' \
--header 'login-token: ${000000000_login_token}'
```
````
