# 批量变更子服务

在子服务状态为"已上架"、"草稿"、"审核驳回"、"已冻结"、"已下架"状态时，开发者可以通过"批量变更"操作更新子服务信息并发起审核。

1. 在服务直达主界面，选择"子服务"页签，筛选出需要变更的子服务。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4c/v3/S6teJ4IuSBG4yUfMtSdPog/zh-cn_image_0000002752561195.png?HW-CC-KV=V1&HW-CC-Date=20261008T150357Z&HW-CC-Expire=31536000000&HW-CC-Sign=89AE49AE112F5AD0B4AAFC409C646CD19D3B3852606395829DDBA6918420394B "点击放大")

2. 点击"导出"。
   * 没有勾选项时，点击"导出"可导出全部子服务。
   * 存在已勾选商品时，点击"导出"仅导出已勾选子服务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/af/v3/e6m22OLlSdOb1x_oYiSUrA/zh-cn_image_0000002752561197.png?HW-CC-KV=V1&HW-CC-Date=20261008T150357Z&HW-CC-Expire=31536000000&HW-CC-Sign=B3E048037F581B5135479CCE950F125D2784C79E482790619DB03E45DB31E153 "点击放大")
3. 导出完成后，点击"任务管理"，下载导出结果。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fe/v3/07SKnM1uSTCqte0_W7A4wQ/zh-cn_image_0000002722801494.png?HW-CC-KV=V1&HW-CC-Date=20261008T150357Z&HW-CC-Expire=31536000000&HW-CC-Sign=38F14A97FE02A97163446DFE9CDCA01C70487E8CEEE002766ABC8F3F2AEF7270 "点击放大")

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/43/v3/u0Speu9sT3yea3Y3k-SW-Q/zh-cn_image_0000002752561199.png?HW-CC-KV=V1&HW-CC-Date=20261008T150357Z&HW-CC-Expire=31536000000&HW-CC-Sign=77A05A55450592D6775A6ED1D3B1604769550AC4481559C3865DFF644396878F "点击放大")
4. 编辑表格，修改子服务信息。
5. 点击"服务直达",返回"子服务"页签。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0b/v3/nY9GrTPJRPGWX7brgbnODA/zh-cn_image_0000002722801498.png?HW-CC-KV=V1&HW-CC-Date=20261008T150357Z&HW-CC-Expire=31536000000&HW-CC-Sign=0D6907770856A8056BC01C1E0EC512D143DC25EDECFFD1B42F5CCF183FB34E36 "点击放大")

6. 点击"批量变更"，上传编辑后的表格文件，点击"上传"按钮。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ab/v3/s-YgcKoBSXG0kvOkU-6CSA/zh-cn_image_0000002722801496.png?HW-CC-KV=V1&HW-CC-Date=20261008T150357Z&HW-CC-Expire=31536000000&HW-CC-Sign=A5D503211A2E80FB87513E4FC0A35BE9D18B1B412BD6D55AE97C7B4DC8AF1ACD "点击放大")
