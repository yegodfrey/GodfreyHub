# 示例代码  
  
#### 场景介绍

在HUAWEI DevEco Studio开发环境使用华为UI Engine完成UI界面开发。

#### 使用方式

对于使用华为UI Engine的开发者可以有如下几种方式引用多态控件（以HwButton为例）：

     * 使用HUAWEI DevEco Studio拖拽控件到layout布局，然后可以在右侧Attributes标签下设置当前选中控件的基本属性参数。
     * 在代码里面动态创建HwButton。
     * 直接在xml文件中手动编辑，引用com.huawei.uikit.hwbutton.widget.HwButton。

#### 使用HwButton（Phone）示例

     * 使用HUAWEI DevEco Studio拖拽，创建HwButton，代码自动生成在xml文件中。

     * 动态创建HwButton。
       1. 需要手动导入控件包。
              
              import com.huawei.uikit.hwbutton.widget.HwButton;

       2. 在build.gradle文件的dependencies中添加依赖：
              
              dependencies {
                  implementation 'com.huawei.ui.uikit:hwbutton-phone:1.0.0.500'
              }

       3. 代码中创建HwButton，根据所选布局（本示例为线性布局）修改相关参数。
              
              protected void onCreate(Bundle savedInstanceState) {
                  super.onCreate(savedInstanceState);
                  setContentView(R.layout.activity_main);
                  LinearLayout parent = findViewById(R.id.parent);
                  HwButton hwButton = HwButton.instantiate(this);
                  if (hwButton != null) {
                      hwButton.setText("Code instantiate HwButton");
                      LinearLayout.LayoutParams params = new LinearLayout.LayoutParams(
                      ViewGroup.LayoutParams.WRAP_CONTENT，
                      ViewGroup.LayoutParams.WRAP_CONTENT);
                      parent.addView(hwButton, params);
                  }
              }

     * 直接编辑xml文件创建HwButton。

在build.gradle文件的dependencies中添加依赖：
           
           dependencies {
               implementation 'com.huawei.ui.uikit:hwbutton-phone:1.0.0.500'
           }
