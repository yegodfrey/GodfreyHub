# 禁言其他玩家

在语音房间内，房主可禁言指定玩家。同时，还可以通过一键禁言房间内其他全部玩家，实现仅房主发言功能。如需取消对其他玩家的禁言，可通过解禁方式快速解除禁言限制。房主对玩家的禁言/解禁事件会进行全房间广播，玩家通过监听该事件，可以知道房间中所有玩家的解禁言状态变化。目前，仅小队房间支持禁言操作。  

#### 前提条件

* 房间为小队房间类型。
* 玩家为房主身份，且房间中已有其他玩家。  

#### 禁言/解禁指定玩家

房主可通过禁止指定玩家发言的功能，实现对房间内某个玩家的禁言限制。被禁言后，该玩家发出的语音将不会被房间内其他玩家接收到。同时，房主在进行禁言后，还可以通过解禁操作对被禁言玩家进行解除禁言。

1. 调用[GameMediaEngine.forbidPlayer](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-web-0000001247887067#section2588650141414)方法禁言/解禁房间内指定玩家语音。

   ```
   ...
   // openId：指定禁言玩家的openId
   // isForbidden：true表示禁言，false表示解禁
   gameMediaEngine.forbidPlayer(roomId, openId, isForbidden).then(()=> {
     // 禁言/解禁成功
   }).catch((exception)=> {
     // 禁言/解禁失败
   });
   ```

   当房主禁言/解禁指定玩家成功后，该玩家可通过调用[GameMediaEngine.on](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-web-0000001247887067#section1487511413163)方法注册的[forbiddenByOwner](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-eventname-web-0000001285559041#ZH-CN_TOPIC_0000001285559041__p14395193012485)事件回调，获取自身的禁言状态变化。房间中的其他玩家也可以通过[forbiddenByOwner](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-eventname-web-0000001285559041#ZH-CN_TOPIC_0000001285559041__p14395193012485)事件监听房间中的禁言广播，以便知道其他玩家的解禁言状态。

   ```
   ...
   // 注册回调事件，以便知道自己或其他玩家是否被房主禁言/解禁
   gameMediaEngine.on('forbiddenByOwner', (roomId: string, openIds: string[], isForbidden: boolean) => {
     // 通过openIds和isForbidden判断玩家禁言状态，做相关游戏逻辑处理
   })
   ```

#### 禁言/解禁其他全部玩家

房主可通过禁止其他全部玩家发言的功能，实现对房间内其他全部玩家的禁言限制。其他全部玩家被禁言后，房间内仅支持房主一人发言。同时，房主在进行禁言后，还可以通过解禁操作对被禁言的其他全部玩家解除禁言。

如果房主对房间设置了一键禁言，那么该房间就具备了禁言属性。此场景下仅房主可以发言，加入到该房间的新玩家也将会被禁言。

1. 调用[GameMediaEngine.forbidAllPlayers](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-web-0000001247887067#section19804198181918)方法禁言/解禁房间内其他全部玩家。

   ```
   ...
   // isForbidden：true表示禁言，false表示解禁
   gameMediaEngine.forbidAllPlayers(roomId: string, isForbidden: boolean).then(()=> {
     // 禁言/解禁成功
   }).catch((exception)=> {
     // 禁言/解禁失败
   });
   ```

   当房主禁言/解禁其他全部玩家成功后，其他玩家可通过调用[GameMediaEngine.on](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-web-0000001247887067#section1487511413163)方法注册的[forbiddenByOwner](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-eventname-web-0000001285559041#ZH-CN_TOPIC_0000001285559041__p14395193012485)事件回调，获取自身和其他玩家的解禁言状态变化。

   ```
   ...
   // 注册回调事件，以便知道自己或其他玩家是否被房主禁言/解禁
   gameMediaEngine.on('forbiddenByOwner', (roomId: string, openIds: string[], isForbidden: boolean) => {
     // 通过openIds和isForbidden判断玩家禁言状态，做相关游戏逻辑处理
   })
   ```
