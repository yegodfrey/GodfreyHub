# 其他

## 使用QuickSDK时，需要填写product_id、client_secret、支付公钥，如何获取？

* product_id、client_secret对应agconnect-services.json中的client_id和client_secret。
* 支付公钥请参考[查询支付服务信息](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/query-payment-info-0000001050166299)，在应用的"盈利 > 应用内支付服务"页面获取"公钥"。

## 调用init和checkAppUpdate接口时无法获取jos类，如何处理？

init和checkAppUpdate接口在联运应用SDK和游戏服务SDK都包含，请您根据您的应用类型处理。

* 普通应用：请参考[使用入门](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/appgallerykit-getting-started-0000001055756858#section1474619903113)集成联运应用SDK。
* 游戏：请参考[使用入门](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/appgallerykit-preparation-game-0000001055356911#section1474619903113)集成游戏服务SDK。

## 应用创建后，应用分类和项目名称可以修改吗？

不可以。

## 商品创建后支持修改商品类型么？

当前华为商品管理系统不支持修改商品类型和商品ID。如果需要修改，建议新增商品，并将之前的商品失效。

## HMS Core SDK 4.0及以后版本是否兼容Android10？

兼容。

## 如何获取EMUI版本号和Android版本号？

* 获取Android版本号

  ```screen
  Log.i(TAG,"android版本号="+android.os.Build.VERSION.RELEASE)
  ```

* 获取EMUI版本号

  ```screen
   Class<?> classType = null;
           String buildVersion = "";
           try {
               classType = Class.forName("android.os.SystemProperties");
               Method getMethod = classType.getDeclaredMethod("get", new Class<?>[] {String.class});
               buildVersion = (String)getMethod.invoke(classType, new Object[] {"ro.build.version.emui"});
           } catch (ClassNotFoundException e) {
               e.printStackTrace();
           } catch (NoSuchMethodException e) {
               e.printStackTrace();
           } catch (IllegalAccessException e) {
               e.printStackTrace();
           } catch (InvocationTargetException e) {
               e.printStackTrace();
           }
           Log.i(TAG,"EMUI版本号="+buildVersion);
  ```

## 如何在手机中查看华为账号的服务地和注册地？

* 账号服务地：华为应用市场>我的>设置>国家/地区。
* 账号注册地：华为应用市场>我的>点击头像>设置>关于。

## 华为商店会根据androidManifest里的uses-features和uses-library字段对用户进行过滤，过滤规则和谷歌商店的过滤规则一致吗？

当uses-feature和uses-library中的required=true时，才会进行过滤，required=false不会进行过滤。

## 应用报错6003，如何处理？

该错误码表示：签名证书指纹错误，签名证书指纹主要用于校验应用的真实性，确保应用来自可信来源。针对此问题，建议您通过以下步骤排查：

1. 检查当前应用使用的证书签名是否与华为后台配置一致。
2. 检查manifest文件中的appid参数是否正常。
3. 检查是否有二次签名或者加固。
4. 检查是否使用了华为签名服务。

具体定位步骤，可参考[华为开发者论坛](https://developer.huawei.com/consumer/cn/forum/topic/0203363619150710071?fid=18)。

## 应用报错6004，如何处理？

该错误码表示接口鉴权时，权限不存在。建议您检查当前应用是否已经正常打开相关服务，具体定位步骤可参考[华为开发者论坛](https://developer.huawei.com/consumer/cn/forum/topic/0204393665510820125?fid=18)。

## 测试时将华为账号服务地（操作路径：手机-应用市场-我的-国家/地区）切换到所需国家/地区，频繁切换后，提示"切换后的一段时间内，不可再次切换国家/地区"，如何处理？

建议您换个华为账号登录后做测试。
