# HarmonyOS 5及以上

* 使用API 12及以上版本开发应用：您可以使用App Linking应用链接实现[跳转HarmonyOS应用](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/app-linking-startupapp)。在实现跳转的基础上，您还可以使用[直达应用市场能力](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/applinking-direct-to-ag)、[延迟链接能力](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/applinking-deferredlink)，提升链接跳转体验和链接转换率。

  使用API 20及以上版本开发应用：您可以使用App Linking[聚合链接](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/applinking-cross-platform)能力，实现在HarmonyOS设备上点击链接后，按您指定的方式进行跳转。
* 使用API 12及以上版本开发元服务：您可以使用App Linking实现[跳转元服务](https://developer.huawei.com/consumer/cn/doc/atomic-guides/atomic-applinking)的功能。实现元服务的点击触达，即点即用。
