# 对称加解密

* 包括AES算法：支持模式CBC_PKCS5Padding、CBC_PKCS7Padding、GCM_NoPadding、CFB_NoPadding、OFB_NoPadding、CTR_NoPadding。
* SM4算法：支持模式SM4_CBC_PKCS5Padding、SM4_CBC_PKCS7Padding、SM4_CTR_NoPadding、SM4_OFB_NoPadding、SM4_CFB_NoPadding、SM4_CFB128_NoPadding。
* HUKS的AES-GCM算法：无需传入密钥，适合端侧本地加解密。

详情请参见API参考文档"[对称加解密](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/encryption-and-decryption-symmetry-0000001985564114)"。
