# 玩转社交裂变，邀请有礼活动让新老用户都赢得优惠券

借助AGC的[App Linking](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-applinking-introduction-0000001054143215)和[云数据库](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-clouddb-introduction-0000001054212760)服务，您可以发起邀请有礼活动，应用的老用户分享链接给社交平台的好友，受邀好友成功安装并注册应用后，新老用户都将获得优惠券奖励。通过邀请有礼活动，可促进"老带新"，玩转社交裂变，助力应用实现流量快速增长。

## 通过App Linking服务生成分享链接

首先，您需为应用配置App Linking服务，使应用可实时生成分享链接，供用户分享到各大社交平台。

### 配置App Linking服务

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中点击您的项目，选择"增长 > App Linking"，进入App Linking页面，完成如下操作：
   1. [启用App Linking服务](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-applinking-enable-0000001058870473)。
   2. [申请链接前缀](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-applinking-urlprefix-0000001060148052)。

### 生成分享链接

1. [创建应用Deep Link](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/applinking-builder-0000001055180835#section1130926862)，并将需要携带的参数拼接在链接后。

   ```screen
   private static final String INVITE_DEEP_LINK = "invite://photoplaza.com";
   String inviteLink = INVITE_DEEP_LINK + "?UserName=" + UserName + "&UserID=" + UserID + "&CouponPrice=200.00";
   ```

2. 通过[Applinking.Builder](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/applinking-builder-0000001055180835)配置App Linking链接中的设置项，包括链接中包含的Android应用信息、浏览器打开预览页样式、链接内包含的活动信息等。

   ```screen
   AppLinking.Builder builder = AppLinking.newBuilder()
                   .setUriPrefix(DOMAIN_URI_PREFIX)
                   .setDeepLink(Uri.parse(DEEP_LINK))
                   .setAndroidLinkInfo(AppLinking.AndroidLinkInfo.newBuilder()
                           .setAndroidDeepLink(inviteLink)
                           .setOpenType(CustomUrl)
                           .setFallbackUrl(FALLBACK_URL)
                           .build())
                   .setPreviewType(AppLinking.LinkingPreviewType.AppInfo)
                   .setCampaignInfo(AppLinking.CampaignInfo.newBuilder()
                           .setName("InviteUser")
                           .setSource("ShareInApp")
                           .setMedium("PhotoPlazaApp")
                           .build());
   ```

3. 调用[buildShortAppLinking](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/applinking-builder-0000001055180835#ZH-CN_TOPIC_0000001055266733__s4d8c481e1099477c92606dd7cda877aa)方法生成分享短链接。

   ```screen
   builder.buildShortAppLinking().addOnSuccessListener(shortAppLinking -> {
               shortLink = shortAppLinking.getShortUrl().toString();
               try {
                   icallback.onSuccess(shortLink, "yes");
               } catch (FileNotFoundException e) {
                   e.printStackTrace();
               }
           }).addOnFailureListener(e -> icallback.onFailure(e.getMessage()));
   ```

## 应用接收App Linking链接

受邀用户点击分享链接后，应用即调用App Linking SDK的API接收该链接，打开应用注册页面。如果受邀用户尚未安装应用，则会跳转到华为应用市场，提示用户安装应用。

1. 在AndroidManifest.xml中完成Deep Link与App Links的host配置。
   * Deep Link

     "android:host"用于配置Deep Link链接的前缀，"android:scheme"用于配置自定义的scheme。当有用户打开带有指向此Deep Link的App Linking时，您的应用将使用此Activity来处理该链接。

     ```screen
     <intent-filter>
          <action android:name="android.intent.action.VIEW"/>
          <category android:name="android.intent.category.DEFAULT"/>
          <category android:name="android.intent.category.BROWSABLE"/>
          <!-- 此处添加项目中自定义的域名 -->
          <data android:host="photoplaza.com" android:scheme="share"/>
          <data android:host="photoplaza.com" android:scheme="invite"/>
      </intent-filter>;
     ```

   * App Links

     ```screen
     <intent-filter android:autoVerify="true">
          <action android:name="android.intent.action.VIEW"/>
          <category android:name="android.intent.category.DEFAULT"/>
          <category android:name="android.intent.category.BROWSABLE"/>
          <!-- 此处添加AppLinking的链接前缀-->
          <data android:host="photoagc.drcn.agconnect.link" android:scheme="http"/>
          <data android:host="photoagc.drcn.agconnect.link" android:scheme="https"/>
      </intent-filter>
     ```


2. 在需要跳转到的页面调用[getAppLinking](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agconnectapplinking-0000001055539370#section122361541697)方法接收链接跳转。

   ```screen
   AGConnectAppLinking.getInstance().getAppLinking(this).addOnSuccessListener(resolvedLinkData -> {
       Log.i(TAG, "StartUp From AppLinking");
       if (resolvedLinkData != null) {
           String deepLink = resolvedLinkData.getDeepLink().toString();
           Log.i("AppLinking", "deepLink:" + deepLink);
           if (deepLink.startsWith("invite")) {
               Intent intent = new Intent(LoginActivity.this, RegisterActivity.class);
               intent.putExtras(bundle);
               startActivity(intent);
               finish();
           } else {
               ToastUtils.showToast(this, "The link is a wrong App Linking");
           }
       }
   }).addOnFailureListener(e -> {
       Log.i(TAG, "Normal StartUp");
       initView();
       getRemoteConfig();
   });
   ```

## 分别为邀请人和受邀人插入优惠券数据

根据分享链接中的邀请人UserID与受邀用户注册完成后认证服务返回的UserID，分别为两位用户插入优惠券数据，完成优惠券发放。

1. 受邀用户打开页面时，应用通过Intent获取链接携带的参数并初始化云数据库。

   ```screen
   Bundle data = getIntent().getExtras();
   String deepLink = data.getString("deepLink");
   inviteUserID = AppLinkingAction.parseLink(deepLink).get("UserID");
           inviteUserName = AppLinkingAction.parseLink(deepLink).get("UserName");
           couponPrice = AppLinkingAction.parseLink(deepLink).get("CouponPrice");
           mHandler.post(() -> {
               couponDBAction = new CouponDBAction();
               couponDBAction.addCallBacks(RegisterActivity.this);
               couponDBAction.openCloudDBZone();
           });
   ```


2. 受邀用户注册成功后，在数据库分别为邀请人和受邀人插入优惠券数据。

   ```screen
   CouponTable couponTable = couponDBAction.buildCouponTable(
                           inviteUserID, inviteUserName, uid, name, Double.parseDouble(couponPrice));
                   couponDBAction.upsertCouponTables(couponTable);
   public void upsertCouponTables(CouponTable CouponInfo) {
           if (mCloudDBZone == null) {
               Log.w(TAG, "CloudDBZone is null, try re-open it");
               return;
           }
           Task<Integer> upsertTask = mCloudDBZone.executeUpsert(CouponInfo);
           upsertTask.addOnSuccessListener(cloudDBZoneResult -> {
               Log.i(TAG, "Upsert " + cloudDBZoneResult + " records");
               mCouponUiCallBack.onUpsertCoupon(cloudDBZoneResult);
           }).addOnFailureListener(e -> {
               Log.e(TAG, "Upsert filed " + e.getMessage());
               mCouponUiCallBack.onCouponErrorMessage("UpsertCouponError: " + e.getMessage());
           });
       }
   ```

## 测试功能

您可以执行如下操作来测试邀请有礼活动是否顺利实施：

1. 在设备1上，在您的应用中创建一个App Linking链接，通过社交平台发送给设备2（已安装您的应用）。
2. 在设备2上点击收到的App Linking链接，查看是否打开应用注册页面。
3. 完成注册，分别查看两台设备上的应用账户内是否已收到优惠券。
