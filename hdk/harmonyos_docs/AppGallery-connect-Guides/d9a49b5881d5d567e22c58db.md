# 生成自有账号凭据

开发者在接入AppGalleryConnect（简称AGC）认证服务时，除了需要对接非托管第三方账户，还可能需要对接开发者自己的自有账户，认证服务的Server SDK提供了将开发者的自建账户快速对接AGC认证服务的能力。

自有账户对接AGC认证服务，需要提供自有账号凭据JWT(Json Web Token)。  

#### 前提条件

您需要在您的开发工程中集成认证服务的Server SDK，请参见[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-server-js-integration-sdk-0000001727548354)。  

#### 开发步骤

1. 调用[Auth.generateKey](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/nodejs-auth-0000001732781480#section13171858114314)方法生成公私钥。  
   ![](https://media:201778133488717777)  
   公私钥仅需要生成一次保存好即可，无需多次调用。

   ```
   const rsaKeyPair = cloud.auth().generateKey();
   ```

   或者

   ```
   const rsaKeyPair = cloudInstance.auth().generateKey();
   ```

   其中:
   * 私钥为[rsaKeyPair.getPrivateKey()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/nodejs-rsakeypair-0000001779780617#section8383716153817)，在生成JWT时使用。
   * 公钥为[rsaKeyPair.getPublicKey()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/nodejs-rsakeypair-0000001779780617#section1381010389)，需要配置到自有账号页面中，参见[2](#ZH-CN_TOPIC_0000001727388962__li9994755191615)。
2. 登录AppGallery Connect，在"开发与服务"下"云开发（Serverless）\> 认证服务"页面中点击"自有账号"后的"启用"。

   ![](https://media:201778133488760778 "点击放大")

   在输入框中配置上一步生成的公钥：

   ![](https://media:201778133488790779)
3. 调用[Auth.sign](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/nodejs-auth-0000001732781480#section18342135811817)方法生成JWT。

   ```
   cloud.auth().sign({uid: "useruid",displayName: "",photoUrl: "",privateKey: "yourprivatekey"});
   ```

   或者

   ```
   cloudInstance.auth().sign({uid: "useruid",displayName: "",photoUrl: "",privateKey: "yourprivatekey"});
   ```

   参数说明：  

   |参数|必选(M)/可选(O)|类型|说明|
   |:----------|:----------|:-----------|:---------|
   |UID|M|string(1024)|用户ID，唯一标识。|
   |DISPLAYNAME|O|string(1024)|用户昵称。|
   |PHOTOURL|O|string(2048)|头像地址。|
   |privateKey|M|string|私钥。|

4. 生成JWT后，传递给应用客户端对接AGC认证服务。
