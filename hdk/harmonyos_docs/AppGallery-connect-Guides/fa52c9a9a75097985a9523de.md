# 业务介绍

|---------------------------------------------------------------------------------------|-|
|开放式测试，可以让您在正式上架应用前，提前发布一个测试版本给您信任的测试用户。测试版本仅对您指定的测试用户可见，这样您就可以提前收到用户反馈，并在应用正式上架前改进您的应用。| |

开放式测试当前支持Android系统和HarmonyOS应用、元服务。

* Android应用：支持APK、RPK和AAB格式的软件包，且仅支持手机、平板设备。
* HarmonyOS应用/元服务（API ≤ 9）：支持APP格式的软件包，且仅支持手机、平板、智能手表的单设备或多设备组合。其中，元服务仅支持在中国大陆地区进行开放式测试。

> 说明
>
> 在本文档中，如无特殊说明，"应用"所指代的对象包括上述所有应用形态。

## 主要功能

|主要功能|功能描述|
|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|邀请指定用户测试应用|您可以在发布开放式测试版本前提前配置需要参与的测试用户，测试用户必须是已经注册成功的华为账号，注册方法请参见[注册华为账号](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。开放式测试版本发布后，用户参与测试的体验依据测试应用类型而略有不同： * Android/HarmonyOS应用（API ≤ 9）：AppGallery Connect（简称AGC）会向测试用户发送邀请链接。测试用户收到邀请链接并参与开放式版本测试后，将直接跳转至设备上的华为应用市场测试应用详情页面，安装应用后即可进行测试，并可以通过邀请链接中的反馈邮箱向您反馈测试应用的问题，您可以基于反馈信息对应用进行改进。您还可以在测试应用发布后添加新的测试用户，对未收到邀请的用户重新发送邀请。 * 元服务（API ≤ 9）：AGC会向测试用户发送邀请邮件或者短信。测试用户接受邀请后将直接跳转至设备上的华为应用市场元服务详情页面，点击"打开"即可进行测试，并可以通过邀请邮件或短信中的反馈邮箱向您反馈测试服务的问题，您可以基于反馈信息对服务进行改进。您还可以在测试服务发布后添加新的测试用户，并对新添加用户和未收到邀请的用户重新发送邀请。|
|指定测试时间段|您可以指定开放式测试的开始时间和结束时间，只有在该时间段内测试用户才能使用开放式测试版本。测试时间到期后，测试用户将无法在对应的分发客户端搜索到该应用。|
|支持免人工审核|开放式测试支持免人工审核，以提高上架效率。但此方式最多只能邀请100个测试用户，其他限制请参见[使用限制](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-betatest-restriction-0000001071399071)。|
|快速迭代|开放式测试专为快速迭代而设计，当一个开放式测试版本修改完成后，您可以再次发布新的开放式测试版本，持续收集测试用户的应用测试详情，直到应用获得良好的反馈。|

## 实现流程

|序号|步骤|详情|
|:-|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|创建测试用户列表|在发布开放式测试版本前，您需要提前确定好需要参与测试的用户列表，测试用户的账号必须是华为账号。|
|2|上架开放式测试版本|当您需要进行开放式测试时，您可以将您的应用打包并选择上架开放式测试版本到华为应用市场客户端。|
|3|用户参与开放式测试|开放式测试版本上架后，AGC会基于您所选择的测试用户名单发送测试邀请。测试用户接受邀请并同意加入开放式测试计划后，该测试用户可以通过华为应用市场客户端下载该应用的测试版本进行测试。测试用户发现的相关问题，可以直接反馈给开发者，开发者可以基于用户提出的问题对应用进行改进。 > 注意 > HarmonyOS设备上可搜索到Android和HarmonyOS测试应用，Android手机上只能搜索到Android测试应用。 > 元服务用户参与开放式测试的体验略有不同。用户接受邀请后，直接前往设备上的华为应用市场元服务详情页面，无需安装点击"打开"即可体验该测试服务。|
|4|发布正式版本|在修改测试用户反馈的问题后，您还可以通过升级应用的方式继续发布开放式测试版本再次进行测试。当您确定版本具备正式上架条件时，您可以通过升级应用的方式将版本正式发布。|
|5|下架开放式测试版本|开放式测试版本上架后，如果您想要下架该版本，您可以通过提交下架申请的方法下架，或者修改测试结束时间，结束时间到了应用会自动下架。|
