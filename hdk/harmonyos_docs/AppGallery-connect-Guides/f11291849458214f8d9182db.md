# AdAppInfo

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------|
|appId|O|String|应用AppId。|
|packageName|O|String|应用包名。|
|appName|O|String|应用名称。|
|description|O|String|应用描述。|
|developerName|O|String|开发者名称。|
|versionCode|O|String|版本号。|
|versionName|O|String|软件版本号。|
|icon|O|String|应用icon地址。|
|secCategory|O|String|应用的二级分类名。|
|thirdCategory|O|String|应用的三级分类名。|
|size|O|Integer (64)|应用包大小。 单位：字节|
|sizeDesc|O|String|应用大小文字描述。 例如：11.3MB|
|downloads|O|String|下载次数。|
|downloadDesc|O|String|下载次数描述。|
|releaseDate|O|String|发布日期。 精确到天。 格式：yyyy-mm-dd|
|memo|O|String|一句话描述。|
|privacyUrl|O|String|隐私政策。|
|permission|O|[AppPermission](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/adx_dsp_api_apppermission-0000001267148173)|应用权限。|
|downloadUrl|O|String|APK的下载URL或快应用地址，需要根据云端配置控制有效期。 注意： 应用下载地址有效期为7天，建议不要长时间缓存。|
|trackUrl|O|String|其他事件跟踪上报地址。 格式：https://monitor.xxxx.com/agd/mediareport?param=xxx\&event=EVENT\&time=TIME\&extInfo=EXTINFO|
|sha256|O|String|文件摘要。|
