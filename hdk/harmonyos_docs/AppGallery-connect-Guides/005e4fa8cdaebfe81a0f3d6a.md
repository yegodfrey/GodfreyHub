# AGC控制台配置准备

## 创建项目和添加应用

如果您尚未添加项目，请在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)先[创建项目](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createproject-0000001100334664)并在项目下[添加应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createapp-0000001146718717)。

## (可选)启用认证服务

如果您尚未启用认证服务，则在部署用户数据删除模板前需要先启用认证服务。

具体请参见[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-process-0000001324833521)。

## (可选)启用云存储服务

如果您尚未启用云存储服务，则在部署用户数据删除模板前需要先启用云存储服务。

具体请参见[启用云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-android-process-0000001326028365)。
