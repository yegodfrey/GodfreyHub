# 集成SDK

1. [下载](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Library/predict-frame-sdkdownload-android-0000001791481558)并解压插帧服务SDK包。
2. 在您的工程"**app > src > main > cpp > include** "目录下，新建一个文件夹（例如，frame_flow），将SDK包中的头文件**frame_flow_core.h** 和**frame_flow_vk.h** 放到此文件夹中。

3. 将**libframeflow.so** 文件放到三方的Library目录中（例如，C:/Users/USERXXX/projects/shiny-ff-vulkan/third-party/jniLibs/arm64-v8a）
