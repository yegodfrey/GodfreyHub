# 登出

## 前提条件

您需要已完成[开通认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)、[在开发环境中创建快应用项目](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-quickapp-ide-0000001326372281)以及[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-quickapp-integration-sdk-0000001326252149)各项准备工作。

## 开发步骤

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251223144019.34703972775382530606225666706021:50001231000000:2800:D90ECABF120F671AA26BB480456E27EADFD0E4F3FC760CEFD5B6D763F408071D.png "点击放大")

当用户不再使用应用，或者需要使用其他账号登录时，需要调用[AGCAuth.signOut](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section121802316565)登出当前用户。用户一旦被登出，端侧的用户信息和Token将被清除。

```screen
agconnect.auth().signOut().then(() => {
                    // 登出成功
                }).catch(error => {
                    // 登出失败
                });
```
