# 配置iOS应用信息

当应用平台为iOS时，您需要在AGC配置"App Store ID"和"团队ID"。

1. 在"开发与服务"页面中，点击iOS应用所在项目。
2. 在"项目设置"页面选择"常规"页签。
3. 在"应用"区域，点击![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250723180206.01032531230625801493426297673392:50001231000000:2800:558447B7EB3D323D9344178813EB2CFB795C8FAAAE219CBC7260E150851E3F1E.png "点击放大")配置"App Store ID"和"团队ID"，即您应用在App Store上的ID和团队ID，完成后点击![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250723180206.13223164280955913799077485604632:50001231000000:2800:C84EFCCB98F87175AC38600D018F5F5F7AF31ABFD22CE1140EB69ECF388262BA.png "点击放大")保存。
