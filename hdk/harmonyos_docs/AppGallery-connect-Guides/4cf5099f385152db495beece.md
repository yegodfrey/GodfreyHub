# 下载文件

文件上传到云端后，您可以通过调用云存储SDK的API将云端文件下载到本地设备中。  

#### 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[初始化存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-initialize-bucket-harmony-java-0000001491122784)。
* 您已[上传文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-upload-harmony-java-0000001542282609)。  

#### 操作步骤

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240821163252.60082854683622052207609160043083:50001231000000:2800:75DE70E438423136811DA07EF0A629D783A79235C2DD0D449B7ADA6E3F65E7C5.png?needInitFileName=true?needInitFileName=true)  
在下载文件前，您可以先[获取文件的元数据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-metadata-harmony-java-0000001542122713#section12745413165215)，查看后再决定是否要下载文件。

1. 调用[AGCStorageManagement.getStorageReference](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-storage-agcstoragemanagement-0000001545702281#section9635163510919)创建需要下载文件的引用。  

   ```
   "Java"
   StorageReference reference = storageManagement.getStorageReference("images/demo.jpg");
   ```

2. 在本地设备中创建文件。  

   ```
   "Java"
   File file = new File("path/images/test.jpg");
   ```

3. 调用[StorageReference.getFile](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-storage-storagereference-0000001494662550#section12372204523919)方法将云端文件数据写入本地文件中。  

   ```
   "Java"
   DownloadTask task = reference.getFile(file);
   ```

4. 通过调用[DownloadTask](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-storage-downloadtask-0000001494982306)的pause、resume、cancel方法可以切换下载任务的状态。  

   ```
   "Java"
   StorageReference reference = storageManagement.getStorageReference("images/demo.jpg");
   DownloadTask task = reference.getFile(new File("images/test.jpg"));
   task.pause();
   task.resume();
   task.cancel();
   ```

5. 通过调用[StorageTask](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-storage-storagetask-0000001494822434)类的addOnProgressListener、addOnPausedListener、addOnSuccessListener、addOnFailureListener、addOnCanceledListener、addOnCompleteListener方法，添加DownloadTask的监听器来监控下载任务中的状态。
   * addOnProgressListener：当下载任务中需要定期刷新任务进度时调用此监听器。
   * addOnPausedListener：当任务暂停时调用此监听器。
   * addOnSuccessListener：当任务成功时调用此监听器。
   * addOnFailureListener：当任务失败时调用此监听器。
   * addOnCanceledListener：当任务取消时调用此监听器。
   * addOnCompleteListener：当任务完成时调用此监听器。

   ```
   "Java"
   StorageReference reference = storageManagement.getStorageReference("images/demo.jpg");
   DownloadTask task = reference.getFile(new File("images/test.jpg"));
   task.addOnFailureListener(new OnFailureListener(){
       @Override
   	public void onFailure(@NonNull Exception exception) {
       }
   }).addOnSuccessListener(new OnSuccessListener<DownloadTask.DownloadResult>(){
       @Override
       public void onSuccess(DownloadTask.DownloadResult downloadResult) {
       }
   }).addOnProgressListener(new OnProgressListener<DownloadTask.DownloadResult>(){
       @Override
       public void onProgress(DownloadTask.DownloadResult downloadResult) {
   	System.out.println(String.format("progress: %f", (downloadResult.getBytesTransferred()*1.0)/downloadResult.getTotalByteCount()));    
   	}
   }).addOnPausedListener(new OnPausedListener<DownloadTask.DownloadResult>(){
       @Override
       public void onPaused(DownloadTask.DownloadResult downloadResult) {
       }
   }).addOnCanceledListener(new OnCanceledListener(){
       @Override
       public void onCanceled() {
       }
   }).addOnCompleteListener(new OnHarmonyCompleteListener<DownloadTask.DownloadResult>(){
       @Override
       public void onComplete(HarmonyTask<DownloadTask.DownloadResult> task) {
       }
   });
   ```

getFile接口支持断点续传，当下载过程中因出现异常导致下载失败时，再次调用getFile可以继续下载文件，提升用户下载体验。  

#### 更多信息

除了在应用客户端通过云存储SDK的API来下载文件，您还可以直接[在AGC控制台以可视化的方式来下载文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-manage-file-0000001281134398#section116002011710)。
