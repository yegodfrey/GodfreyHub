# 开具发票

购买服务时支持使用第三方支付方式（支付宝/微信），支付成功后您可以在AppGallery Connect中申请开具发票。  

#### 前提条件

* 当前仅支持企业开发者通过AppGallery Connect线上开具发票，个人开发者请联系华为运营人员线下提供。
* 您已具备"发票管理"菜单访问权限。关于团队内成员对账户中心各个菜单的访问权限，请参见[角色与权限列表](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-rolepermission-0000001155345429)。
* 您已通过第三方支付方式购买服务，且扣除优惠券后实际支付的金额大于0。
* 您已在[付费服务设置](https://developer.huawei.com/consumer/cn/console/setting/modPayService)中填写发票信息，具体指导请参见[付费服务](https://developer.huawei.com/consumer/cn/doc/start/payment-service-0000001052865979)。

![](https://media:201775716941643096)  
只有通过第三方支付方式支付的费用才支持在AppGallery Connect的"订单管理"页面申请开具发票，通过[账户充值](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-account-recharge-0000001126625360)的充值类发票请通过[我的账户](https://developer.huawei.com/consumer/cn/console/account/bills/settlement)索取。  

#### 操作步骤

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)。
2. 在右上角账号旁的下拉框中选择"账户中心"。 ![](https://media:201775716941672097)

3. 选择"费用 \> 发票管理"，在"发票管理"页面可以查看您可索取发票的金额和订单。  
   ![](https://media:201775716941698098)  
   在"费用 \> 订单管理"页面，点击"申请开票"也可跳转至发票管理页面。

   ![](https://media:201775716941738099)
4. 选中"发票状态"为"可开票"的订单，点击"申请开票"。
5. 在弹出的确认对话框中跳转到发票信息页面，确认发票抬头信息已正确填写，点击弹框中的"确认"。
6. 申请成功后，华为财务15个工作日内为您开具发票，您可以在"发票状态"中查看开票进展。 ![](https://media:201775716941767100)
