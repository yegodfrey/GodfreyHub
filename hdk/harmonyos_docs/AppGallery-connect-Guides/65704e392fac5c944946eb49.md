# 创建/销毁库实例

启动游戏后，需先完成初始化工作，即创建一个库实例。此库实例对象将在后续函数中使用，因此需确保该库实例对象有效。

## 前提条件

* 操作系统为HarmonyOS或Android。
* 已[集成插帧服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/predict-frame-integratingsdk-0000001630852565)。

## 创建实例

调用函数[FrameFlow_Create](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflow-create-0000001838253685)，创建一个库实例。

```screen
FFInstance FrameFlow_Create(const FFInstanceCreateInfo* pCreateInfo);
```

## 销毁实例

为了正确关闭并避免资源泄漏，库实例应在不再需要后调用函数[FrameFlow_Destroy](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflow-destroy-0000001791494280)进行销毁。库实例成功销毁后将失效，后续无法继续使用。

```screen
void FrameFlow_Destroy(FFInstance instance);
```
