# 业务介绍

AppGallery Connect API是一套RESTful API，通过这些API，您可以定制AppGallery Connect提供的服务，或是实现流程自动化，从而提升工作效率。  

#### Publishing API

您可以通过Publishing API完成应用/元服务的发布管理工作，包括上传应用的版权版号等信息、编辑应用的简介等基本信息、更新应用视频等版本信息、提交应用发布或撤销审核等。  

#### Upload Management API

您可以通过Upload Management API完成应用的文件上传，包括APP软件包，以及应用的图标、介绍图片、视频文件等。  

#### Provisioning API

您可以通过Provisioning API对应用的调试和发布证书、Profile、设备进行管理，包括申请、查询、删除等操作。  

#### Domain Management API

您可以通过Domain Management API完成元服务域名配置任务，包括下载、更新和查询域名信息等。  

#### Testing API

您可以通过Testing API对HarmonyOS应用/元服务进行版本测试。您还可以先邀请部分测试用户进行体验，并收集用户的使用意见。  

#### Reports API

您可以通过Reports API查询AppGallery Connect中大部分报告。与在AppGallery Connect网站查看报告一样，您可以选择日期范围、添加过滤器，也可以设置查看依据，查询结果以CSV或Excel文件形式返回。  

#### Project Management API

Project Management API用于访问和管理开发者的项目信息，例如：

* 获取开发者的团队列表。
* 获取开发者项目中应用的简略信息。
* 获取开发者项目中应用的SDK配置文件。

通过访问这些接口，开发者无需登录AppGallery Connect网站即可对其项目中的相关信息进行访问和管理，能够更有效率地支撑开发者的应用开发。  

#### Comments API

Comments API为您提供了自动化获取评论数据的能力，通过Comments API您可以获取AppGallery Connect中的评论数据，然后利用自己或者第三方（如braze）的评论分析系统作精细化分析，或者通过Comments API完成评论的回复。  

#### PMS API

通过PMS API，您可以实现商品和商品促销信息的创建和更新，包含商品价格，展示语言等。实现对应用内商品的价格和语言进行管理，实现全球本地化定价。  

#### 在玩服务

"在玩"主要提供游戏的战绩工具、攻略内容等服务。参考[开发概览](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-playing-overview-0000002022278129)调用[在玩服务API](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-resources-0000002022105725)，您可以更新游戏中心客户端"在玩"页面的数据，例如游戏资源、玩家数据、玩家资产。  

#### 游戏道具商城

游戏道具商城是直接面向玩家的游戏虚拟商品直购平台，是以黏性型商品为核心的流量阵地，是应用内购买的增强参考开发概览调用游戏道具商城API，您可以接入游戏道具商城，向玩家提供在应用外购买游戏内道具产品的服务，丰富游戏的服务形式及玩家体验。
