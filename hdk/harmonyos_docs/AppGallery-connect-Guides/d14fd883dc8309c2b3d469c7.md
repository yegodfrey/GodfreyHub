# 概述

面对HarmonyOS应用开发者，当前支持如下两种方式开发、调试和部署云函数：

* 方式一、使用DevEco Studio的端云一体化开发能力 相比于传统开发模式，DevEco Studio提供的端云一体化开发模式具备成本低、效率高、门槛低等优势。您可以基于统一的技术栈，高效、协同地完成端、云函数代码的编写、调试、编译和部署，极大提高构建HarmonyOS应用和元服务的效率。

  具体详情请参见[端云一体化开发云函数](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/agc-harmonyos-clouddev-cloudfunctions)。
* 方式二、在AGC控制台创建云函数 本地IDE中开发函数代码、打包，然后在AGC控制台创建函数、导入函数部署包，线上测试函数代码实现是否满足您的要求。

下文基于方式二向您介绍开发函数、创建函数、测试函数等过程的操作方法。
