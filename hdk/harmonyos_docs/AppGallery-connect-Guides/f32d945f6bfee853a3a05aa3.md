# 下载文件

文件上传到云端后，您可以调用云存储REST API将云端文件下载到本地设备中。  

#### 前提条件

您已[上传文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-upload-restapi-0000001549497801)。  

#### 操作步骤

调用[下载文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storage-restapi-getfile-0000001498998530)接口将云端文件数据写入本地文件中。  

#### 更多信息

除了在应用客户端通过云存储REST API来下载文件，您还可以直接[在AGC控制台以可视化的方式来下载文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-manage-file-0000001281134398#section116002011710)。
