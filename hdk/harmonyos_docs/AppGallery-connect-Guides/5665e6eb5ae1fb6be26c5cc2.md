# 支付宝账号

## 前提条件

* 您已[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要在应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-integration-sdk-0000001326347605)。

## 开发步骤

认证服务提供了两种开发方式接入支付宝账号：

* 推荐您使用新的统一登录接入方式，请参见[统一登录接入方式](#section197163415012)。
* 同时为了兼容性保留了老的传统接入方式，请参见[传统接入方式](#section7347926205816)。

### 统一登录接入方式

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114613.57065785433790952536859020897351:50001231000000:2800:598A905D29C6ADB37115762909516E7CB8341C540DC21CC3F0FCAB9165E6F80B.png "点击放大")

1. 在项目的podfile中添加支付宝账号认证API的依赖和支付宝SDK依赖。

   ```screen
   pod  'AlipaySDK-iOS", "~> 15.8.11'
   pod  'AGConnectAPIAuthAlipay'
   ```

   > 说明
   >
   > 华为不提供支付宝SDK依赖包，您可以使用示例中的Pod方式添加支付宝SDK依赖，也可以自行至阿里云开放平台下载最新版本的SDK依赖包进行手动集成。示例中的支付宝SDK Pod依赖包仅供参考，华为不负责版本更新。
2. 在XCode中，选择您的工程设置项，左侧导航选择"TARGETS"，点击"Info"标签。 在"URL Types"添加一条新的"URL Schemes"，Identifier填写alipay，"URL Schemes"的值自定义即可，如下图中自定义的alipayschemes。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114614.76071556861872198748993605748792:50001231000000:2800:4A7D59F4E3DAFA2FDC35F4568EDC8FF7FECD88D7C6CFEAA2706A94A1F217B272.png)
3. 设置支付宝处理URL跳转回调的方法。 说明
   >
   > 支付宝的SDK不支持Swift方式调用，需要使用桥接文件（用OC方式调用），具体方法请参考[支付宝官方文档](https://opendocs.alipay.com/open/204/105295#针对 Swift 接入 AlipaySDK 的问题)。

   如果应用使用UISceneSession来管理生命周期（iOS 13以后支持），则需要在SceneDelegate.m编辑相关代码。

   ```screen
   "Objective-C"
   - (void)scene:(UIScene *)scene openURLContexts:(NSSet<UIOpenURLContext *> *)URLContexts API_AVAILABLE(ios(13.0)){
       NSURL *url = URLContexts.allObjects.firstObject.URL;
       if ([url.host isEqualToString:@"safepay"]) {
           // 授权跳转支付宝钱包进行支付，处理支付结果
           [[AlipaySDK defaultService] processAuth_V2Result:url standbyCallback:^(NSDictionary *resultDic) {


           }];
       }
   }
   ```

4. 设置支付宝的AppId到对应接口。

   ```screen
   "Objective-C"
   AGCAuthThirdPartyConfig.instance.alipayPid = @"XXX";    
   AGCAuthThirdPartyConfig.instance.alipayAppId = @"XXX";    
   AGCAuthThirdPartyConfig.instance.alipayTargetId = @"XXX";    
   AGCAuthThirdPartyConfig.instance.alipayCallScheme = @"在#ZH-CN_TOPIC_0000001412498202__li188771135750中填写的Schemes值";
   ```

   ```screen
   "Swift"
   AGCAuthThirdPartyConfig.instance().alipayPid = "XXX";
   AGCAuthThirdPartyConfig.instance().alipayAppId = "XXX";
   AGCAuthThirdPartyConfig.instance().alipayTargetId = "XXX";    
   AGCAuthThirdPartyConfig.instance().alipayCallScheme = "在#ZH-CN_TOPIC_0000001412498202__li188771135750中填写的Schemes值";
   ```

5. 添加生命周期回调，请参见[统一登录调用AppDelegate回调](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-unified-login-0000001275827780)。
6. 调用[[AGCAuth signIn:controller:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346#section1835003573014)方法，登录支付宝账号。 说明
   >
   > 支付宝的SDK不支持Swift方式调用，需要使用桥接文件（使用OC调用方式）。具体方法请参考[支付宝官方文档](https://opendocs.alipay.com/open/204/105295#针对 Swift 接入 AlipaySDK 的问题)。

   ```screen
   "Objective-C"
    [[[[AGCAuth getInstance] signIn:AGCAuthProviderTypeAliPay controller:self] addOnSuccessCallback:^(AGCSignInResult * _Nullable result) {
            // onSuccess
            AGCUser *user = result.user;
        }] addOnFailureCallback:^(NSError * _Nonnull error) {
            // onFail
        }];
   ```

### 传统接入方式

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114614.13771762871632015243054491816949:50001231000000:2800:C2B537D337E5063E7DCBF66391EE13B38923BE292712FCE1DB8C00705E6F8067.png "点击放大")

1. 在应用的登录界面，初始化[AGCAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346)实例，获取AGC的用户信息，检查是否有已经登录的用户。如果有则可以直接进入用户界面，否则显示登录界面。

   ```screen
   "Objective-C"
   AGCUser *user = [[AGCAuth getInstance] currentUser];
   ```

   ```screen
   "Swift"
   let user = AGCAuth.instance().currentUser
   ```


2. 支付宝账号登录，并获取支付宝账号的用户授权信息。 说明
   >
   > 此步骤仅供参考，更详细内容请参考[支付宝官方文档-iOS调用方法](https://opendocs.alipay.com/open/218/105325)。
   1. 设置支付宝平台的必要参数。

      ```screen
      "Objective-C"
      AGCAuthThirdPartyConfig.instance.alipayPid = @"XXX";    
      AGCAuthThirdPartyConfig.instance.alipayAppId = @"XXX";    
      AGCAuthThirdPartyConfig.instance.alipayTargetId = @"XXX";    
      AGCAuthThirdPartyConfig.instance.alipayCallScheme = @"参考统一登录方式中在#ZH-CN_TOPIC_0000001412498202__li188771135750填写的Schemes值";
      ```

      ```screen
      "Swift"
      AGCAuthThirdPartyConfig.instance().alipayPid = "XXX";
      AGCAuthThirdPartyConfig.instance().alipayAppId = "XXX";    
      AGCAuthThirdPartyConfig.instance().alipayTargetId = "XXX";    
      AGCAuthThirdPartyConfig.instance().alipayCallScheme = "参考统一登录方式中在#ZH-CN_TOPIC_0000001412498202__li188771135750填写的Schemes值";
      ```

   2. 调用支付宝授权登录方法，在方法的回调中获取到authCode。 说明
      > * 具体调用方法请参考[支付宝SDK-iOS调用方法](https://opendocs.alipay.com/open/218/105325)。
      > * 支付宝的SDK不支持Swift方式调用，需要使用桥接文件（使用OC调用方式）。具体方法请参考[支付宝官方文档](https://opendocs.alipay.com/open/204/105295#针对 Swift 接入 AlipaySDK 的问题)。

      ```screen
      "Objective-C"
       NSString *authInfo = @"你自己生成的authInfo";    
       NSString *schemes = @"你自己设置的schemes";    
       [[AlipaySDK defaultService] auth_V2WithInfo:authInfo                                         
                                   fromScheme:schemes                                           
                                   callback:^(NSDictionary *resultDic) {        
           NSString *authCode = @"根据resultDic获取的authCode";                                           
       }];
      ```

3. 调用[[AGCAliPayAuthProvider credentialWithAuthCode:authCode]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcalipayauthprovider-ios-0000001412660174#section93691113182511)使用从支付宝账号获取的authCode生成credential，并调用[[AGCAuth signIn:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346#section488155612616)实现登录。

## 更多信息

* 您如果想让用户可以使用多个账号登录您的应用，可以将多个[账号进行关联](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-associated-0000001053053982)。
* 当用户不需要使用应用，或者需要切换其他账号登录认证，可以先执行[登出](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-sign-out-0000001053692708)。
* 当用户需要注销当前用户，可以进行[销户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-deleteuser-0000001057460873)。
* 对于销户、修改密码、关联账号以及重置手机账号和邮箱账号等敏感操作，为了提高安全性，需要用户必须在5分钟内登录过才能执行。如果用户执行敏感操作时登录超过5分钟，需要[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-reauthenticate-0000001127283387)后再执行敏感操作。
* 您可以参考[异常处理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-troubleshooting-0000001054715191)实现自己的异常处理机制，从而减少异常情况的发生。
* 您可以使用云函数触发器来接收用户注册、登录、销户等关键事件，从而[扩展认证服务的能力](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-extension-0000001053372708)。
* 您可以参考[管理用户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-user-manage-0000001606051705)对用户进行解锁、停用等操作。
