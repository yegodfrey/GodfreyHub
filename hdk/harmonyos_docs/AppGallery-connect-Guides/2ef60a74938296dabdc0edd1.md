# 上传文件

通过云存储SDK，您可以快速上传本地设备上的文件到云端，同时可以对上传任务进行管理，如暂停、继续、取消上传任务，监控上传进度，任务异常中断后进行断点续传等。

## 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[初始化权限](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-initialize-permission-0000001276338034)。
* 您已[初始化存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-initialize-bucket-android-0000001276178118)。

## 上传本地文件

您可以通过引用操作本地设备上的文件，将文件上传到云端的存储实例中。

1. 调用[AGCStorageManagement.getStorageReference](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragemanagement-0000001054967269#section9635163510919)方法创建待上传文件的引用，将本地文件上传到预先规划的云端地址中。

   ```screen
   "Java"
   StorageReference reference = storageManagement.getStorageReference("images/demo.jpg");
   ```

   ```screen
   "Kotlin"
   val reference = storageManagement!!.getStorageReference("images/demo.jpg")
   ```

   > 说明
   > * 上传文件或创建目录时，会对名称和文件大小进行严格的检查，具体限制请参见[使用限制](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-restrictions-0000001093263535#section1759375325210)。
   > * 如需支持断点续传，上传文件应携带SHA256值，且最大为50GB，云存储SDK会按照分片上传的方式将文件上传至服务器，直到文件全部上传完毕。若上传任务异常中断，云存储SDK会根据设置的最大重试次数从断点续传位置进行重试上传。
   > * 如无需支持断点续传，上传文件可不携带SHA256值，且最大为5GB，云存储SDK会按照单次上传的方式将文件上传至服务器。若上传任务异常中断，请重新尝试上传。
2. 调用[StorageReference.putFile](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagereference-0000001054767243#section12531528113917)方法将文件上传到存储实例中。 说明
   >
   > 上传文件前支持您设置文件的自定义属性，具体请参见[设置元数据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-metadata-android-0000001055566158#section4918191475516)。

   ```screen
   "Java"
   UploadTask task = reference.putFile(new File("path/images/test.jpg"));
   task.addOnFailureListener(new OnFailureListener(){
       @Override
       public void onFailure(@NonNull Exception exception) {
       }
   }).addOnSuccessListener(new OnSuccessListener<UploadTask.UploadResult>(){
       @Override
       public void onSuccess(UploadTask.UploadResult uploadResult) {
       }
   });
           

            https://github.com/AppGalleryConnect/agc-android-demos/blob/master/cloudstorage/app/src/main/java/com/huawei/agc/quickstart/storage/MainActivity.java
           


   ```

   ```screen
   "Kotlin"
   val task = reference.putFile(File("path/images/test.jpg"))
   task.addOnSuccessListener(OnSuccessListener {  })
   .addOnFailureListener(OnFailureListener {  })
   ```

   如果您需要在上传文件时为文件指定自定义属性，可以使用[putFile](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagereference-0000001054767243#section1817391015397)(File srcFile, FileMetadata attribute)方法。

   如果您需要在上传文件时支持断点续传，可以使用[putFile](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagereference-0000001054767243#section1350525923718)(File srcFile, FileMetadata attribute, Long offset)方法，offset设为0。若任务异常中断，您可以再次调用该方法恢复任务，从中断的位置开始上传，offset的值通过[UploadTask.UploadResult.getBytesTransferred](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/uploadtask-uploadresult-0000001055407220#section7428193353716)方法获取。
3. 使用putFile方法上传文件后，会返回[UploadTask](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/uploadtask-0000001055247244)的实例，您可以通过监听UploadTask的状态了解上传任务的相关状态。
   * 文件上传过程中如需对任务进行操作，请参见[切换上传任务的状态](#section864919101209)。
   * 文件上传任务执行的进度监控，请参见[监控上传任务的进度](#section1081983715343)。
   * 使用断点续传时需要继续未完成上传任务，请参见[异常情况下继续未完成的上传任务](#section09357511198)。

## 切换上传任务的状态

文件在正常上传过程中，可通过调用[UploadTask](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/uploadtask-0000001055247244)类的[pause](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagetask-0000001055727204#section12058743315)、[resume](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagetask-0000001055727204#section56484719332)、[cancel](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagetask-0000001055727204#section165341923395)方法（继承自[StorageTask](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagetask-0000001055727204)）切换上传任务的状态。

* pause：暂停一个处于上传过程中的上传任务。
* resume：唤醒一个处于暂停状态的上传任务。
* cancel：取消一个上传任务。

```screen
"Java"
StorageReference reference = storageManagement.getStorageReference("images/demo.jpg");
UploadTask task = reference.putFile(new File("images/test.jpg"));
task.pause();
task.resume();
task.cancel();
```

```screen
"Kotlin"
val reference = storageManagement!!.getStorageReference("images/demo.jpg")
val task = reference.putFile(File("path/images/test.jpg"))
task.pause()
task.resume()
task.cancel()
```

## 监控上传任务的进度

文件在上传时，可通过调用[StorageTask](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagetask-0000001055727204)类的addOnProgressListener、addOnPausedListener、addOnSuccessListener、addOnFailureListener、addOnCanceledListener、addOnCompleteListener方法，添加UploadTask的监听器来监控上传任务中的状态切换。

* addOnProgressListener：当上传任务中需要定期刷新任务进度时调用此监听器。
* addOnPausedListener：当任务暂停时调用此监听器。
* addOnSuccessListener：当任务成功时调用此监听器。
* addOnFailureListener：当任务失败时调用此监听器。
* addOnCanceledListener：当任务取消时调用此监听器。
* addOnCompleteListener：当任务完成时调用此监听器。

```screen
"Java"
StorageReference reference = storageManagement.getStorageReference("images/demo.jpg");
UploadTask task = reference.putFile(new File("path/images/test.jpg"));
task.addOnFailureListener(new OnFailureListener(){
    @Override
	public void onFailure(@NonNull Exception exception) {
    }
}).addOnSuccessListener(new OnSuccessListener<UploadTask.UploadResult>(){
    @Override
    public void onSuccess(UploadTask.UploadResult uploadResult) {
    }
}).addOnProgressListener(new OnProgressListener<UploadTask.UploadResult>(){
    @Override
    public void onProgress(UploadTask.UploadResult uploadResult) {
        System.out.println(String.format("progress: %f", (uploadResult.getBytesTransferred()*1.0)/uploadResult.getTotalByteCount()));
    }
}).addOnPausedListener(new OnPausedListener<UploadTask.UploadResult>(){
    @Override
    public void onPaused(UploadTask.UploadResult uploadResult) {
    }
}).addOnCanceledListener(new OnCanceledListener(){
    @Override
    public void onCanceled() {
    }
}).addOnCompleteListener(new OnCompleteListener<UploadTask.UploadResult>(){
    @Override
    public void onComplete(Task<UploadTask.UploadResult> task) {
    }
});
```

```screen
"Kotlin"
val reference = storageManagement!!.getStorageReference("images/demo.jpg")
val task = reference.putFile(File("path/images/test.jpg"))
task.addOnFailureListener(OnFailureListener {  })
.addOnSuccessListener(OnSuccessListener<UploadTask.UploadResult> {  })
.addOnProgressListener(OnProgressListener<UploadTask.UploadResult> { uploadResult -> 
    println(
        String.format(
            "progress: %f",
            uploadResult.bytesTransferred * 1.0 / uploadResult.totalByteCount
        )
    )})
.addOnPausedListener(OnPausedListener<UploadTask.UploadResult> {  })
.addOnCanceledListener(OnCanceledListener {  })
.addOnCompleteListener(OnCompleteListener<UploadTask.UploadResult> {})
```

## 异常情况下继续未完成的上传任务

上传任务在执行的过程中，可能会因为使用方式、网络环境等原因产生的[StorageException](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storageexception-0000001055208671#section762517597485)异常导致上传任务中断，通过断点续传接口[putFile](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagereference-0000001054767243#section1350525923718)(File srcFile, FileMetadata attribute, Long offset)，可以继续未完成的上传任务，提升用户的使用体验。
> 说明
>
> * 上传任务的会话会保存一周，您可以尝试恢复此任务，当会话超期或发生异常时，恢复会失败。
> * 在会话的有效期内，临时文件会占用一定的存储空间，该存储空间会体现在存储使用量内。

```screen
"Java"
FileMetadata attribute = new FileMetadata();
attribute.setContentType("image/jpeg");
attribute.setSHA256Hash("0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef");
StorageReference reference = storageManagement.getStorageReference("images/demo.jpg");
UploadTask task = reference.putFile(new File("path/images/test.jpg"), attribute, 100L);
```

```screen
"Kotlin"
val attribute = FileMetadata()
attribute.contentType = "image/jpeg"
attribute.shA256Hash ="0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef"
val reference = storageManagement!!.getStorageReference("images/demo.jpg")
val task = reference.putFile(File("path/images/test.jpg"), attribute, 100L)
```

## 更多信息

* 除了在应用客户端通过云存储SDK的API来上传文件，您还可以直接[在AGC控制台以可视化的方式来上传文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-manage-file-0000001281134398#section6704135012516)。
