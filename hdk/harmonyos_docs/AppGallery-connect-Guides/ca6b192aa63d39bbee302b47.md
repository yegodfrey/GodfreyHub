# 崩溃统计概览

崩溃统计页面展示了应用的崩溃次数、受影响用户数、崩溃率、并展示问题趋势，帮您快速掌握应用崩溃的整体情况。  

#### 筛选器区域

崩溃服务支持选择不同的查看依据、过滤器、时段进行崩溃数据的个性化分析。

#### 崩溃图表区域

崩溃的概览图表区域展示了崩溃数据的图表和明细，支持按日、周、月维度筛选查看。

* 区域上方：显示您筛选条件下的崩溃次数、异常次数、受影响用户数、崩溃率、问题趋势对应的图表。点击![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250424174607.02463021692600920899481755383885:50001231000000:2800:EF0845E2618327E9DEEC11D019CE3BEE7B3D97985B3B69ECB5CBD699B9C9F99B.png "点击放大")可以切换折线图、柱状图。
* 区域下方：和概览图表相对应的崩溃明细表，展示了对应查看依据维度下的崩溃数据详情，点击"下载表格"可下载表格至本地，做个性化分析。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250424174607.47897766080262288508196088184825:50001231000000:2800:18963E3160904B9719DC811B14419F0AD75A7328380D84D6036CEABD4F2CC07A.png)

  指标说明：
  * 崩溃：应用崩溃次数
  * 应用启动次数：App被启动的次数
  * 异常：应用发生异常次数
  * 崩溃率：崩溃/应用启动次数
* 受影响用户数：发生崩溃和异常的用户数，用户通过设备唯一标识
