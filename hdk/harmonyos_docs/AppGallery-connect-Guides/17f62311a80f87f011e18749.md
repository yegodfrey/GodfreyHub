# 预置事件说明

为了提升预测的模型质量，使模型效果更优，您可以通过添加预置事件埋点，提升数据质量，从而上报更多行业价值数据，使用方法请参见[预置事件使用说明](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-usage-guide-0000001135571462)。

#### 社交通讯

  * $CommentContent

用户评论相关内容时上报该事件。它可以用来分析内容对用户的吸引力。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
$ContentName | 名称 | String | 可选 | 用户点击评论的内容名称。  
$ContentType | 内容类型 | String | 可选 | 用户点击评论的内容类型。
    * 0：图文
    * 1：视频
    * 2：语音  
  
  * $Post

用户在应用内发布内容时上报此事件。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
$ContentType | 内容类型 | String | 可选 | 用户在应用内发帖的内容类型。在交友行业中为枚举类型。
    * 0：图文
    * 1：视频
    * 2：语音  
  
  * $ViewContent

用户查看内容时上报此事件，可以用于分析内容对用户的吸引程度。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
$ContentName | 名称 | String | 可选 | 用户点击查看的内容名称。  
$ContentType | 内容类型 | String | 可选 | 用户点击查看的内容类型。在交友行业中为枚举类型。
    * 0：图文
    * 1：视频
    * 2：语音  
  
  * $SendMessage

有社交功能的APP用户在发送消息时上报此事件。
