# （可选）查看调试日志

如果您发现APM服务异常，可以通过下面方法进行调试。  

#### 查看APM SDK日志

在调试应用时，您可以打开APM调试日志开关，方便查看APM性能监控是否正常运行。具体方法是在应用的AndroidManifest.xml文件中添加\<meta-data\>元素：

```
<application>
    <!-- Set this flag to 'true', debug logs of APM will be printed in logcat, default value is 'false'-->
    <meta-data
      android:name="apms_debug_log_enabled"
      android:value="false" />
</application>
```

<br />

通过logcat日志过滤功能，您可以查看应用启动、应用屏幕和HTTP/HTTPS网络请求的性能监控日志记录。这些日志记录会被标记为com.huawei.agc.apms，您可以使用下面命令对其进行过滤：

```
adb logcat -s com.huawei.agc.apms
```

#### 查看APM日志

在构建应用时，如有需要，您可以通过关键词"APMSGradlePlugin"查看APM日志，并可以通过以下方式打印构建过程中的Debug日志：

```
gradlew app:assembleDebug --debug --stacktrace
```
