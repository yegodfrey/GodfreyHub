# 从这里开始

函数的代码实现基于不同的语言运行环境可分为Node.js、Java、Python，还有一种比较特别的运行环境为Custom Runtime。  
![](https://media:201776309740336328)  
* Custom Runtime是自定义运行环境，本质上是一个具有监听端口的HTTP Server，您需要创建一个启动该目标Server的可执行文件bootstrap，然后将该文件和您的代码文件一起打成ZIP包，最后将该ZIP包部署到AGC云函数平台，作为一个Custom Runtime的函数。
* 高版本的语言运行环境通常内置Custom Runtime。内置Custom Runtime功能，即您可以直接创建Custom Runtime，无需安装第三方解释器。低版本的语言运行环境要使用Custom Runtime功能，您需要自行安装第三方解释器。
* 内置Custom Runtime功能的语言运行环境版本为Python 3.11版本、Node.js 20.x版本、Java 1.8版本。

调用云函数时，会基于调用函数的触发方式不同分为事件调用和HTTP请求调用。所以在创建云函数时，需要选择函数的触发方式。

事件调用是通过触发器来实现的。触发器可分为三大类，HTTP触发器、Serverless触发器和定时触发器。其中Serverless触发器又可细分为云数据库触发器、认证服务触发器、远程配置触发器、云存储触发器。

HTTP请求调用可分为通过SDK构造HTTP请求和自行构造HTTP请求。

综上所述开发方式如下表所示，其中推荐度为推荐使用的优先级，1表示最优先推荐使用，6表示最不推荐使用。您也可以根据实际开发情况选择。  

|推荐度|调用方式|触发方式|说明|
|:--|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-------|:------------------------------------------------------------------------------------------------------------|
|1|[通过HTTP触发器调用函数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/call-function-via-httptrigger-introduction-0000001563051653) 具体又分为： * 应用客户端侧调用函数 * 应用服务端侧调用函数 说明：应用服务端侧即Server(Java)或Server(Node.js)|事件调用|* 此场景必须集成SDK。 * 此场景必须使用HTTP触发器。|
|2|[通过Serverless触发器调用函数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/develop-func-introduction-0000001712996021)|事件调用|* 此场景无需集成SDK。 * 此场景必须使用Serverless触发器。|
|3|[通过定时触发器调用函数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/develop-func-introduction-0000001664956504)|事件调用|* 此场景无需集成SDK。 * 此场景必须使用定时触发器。|
|4|[通过SDK构造HTTP请求调用函数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/call-via-sdk-introduction-0000001564042313)（新创建的云函数不再支持此调用方式）|HTTP请求调用|* 此场景必须集成SDK，仅Java语言的Server SDK支持。 * 此场景无需使用触发器。|
|5|[自行构造HTTP请求调用函数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/develop-func-introduction-0000001512391180)（新创建的云函数不再支持此调用方式）|HTTP请求调用|* 此场景无需集成SDK。 * 此场景需代码自行构造HTTP请求，包含获取鉴权Token和携带鉴权Token请求业务。 * 通常用于函数功能调试阶段，使用自行构造或使用第三方工具Postman构造HTTP请求调用函数。|
