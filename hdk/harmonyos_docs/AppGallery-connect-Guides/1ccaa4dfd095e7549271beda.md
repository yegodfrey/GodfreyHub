# 设置扬声器播放音量

进入语音房间后，玩家如果希望控制房间音量，可通过设置扬声器播放音量实现，房间中任意玩家的声音都按设置的音量大小通过扬声器播出。  

#### 前提条件

您已[加入房间](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-joinroom-roomid-android-0000001268934473)。  

#### 开发步骤

调用[GameMediaEngine.adjustPlaybackVolume](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section10951143352511)方法设置扬声器播放音量，调整房间扬声器播放音量增益值，并通过返回值获得操作结果。

```
int result = mHwRtcEngine.adjustPlaybackVolume（volume）;// volume 扬声器播放音量值, 取值范围为[0,100], 默认音量值为10
```

* 进入语音房间后，扬声器播放音量默认是10，表示原始音量，无增益，10以下表示负增益，10以上表示正增益。
* 调用此接口设置音量值不影响系统音量。
