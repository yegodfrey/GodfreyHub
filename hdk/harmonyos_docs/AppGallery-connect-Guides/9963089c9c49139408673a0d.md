# 在iOS应用中创建聚合链接

如果您希望在应用程序中以动态方式创建链接以便用户之间相互分享，可以在应用客户端中使用聚合链接SDK提供的API来创建聚合链接的[长链接](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-introduction-0000001054143215#ZH-CN_TOPIC_0000001056576415__p1152614142216)或[短链接](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-introduction-0000001054143215#ZH-CN_TOPIC_0000001056576415__p352661132214)。  

#### 前提条件

* 您已成功[申请链接前缀](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-urlprefix-0000001060148052)。
* 您已[添加网址允许清单](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-allowlist-0000001059304615)。
* 您的应用已[集成聚合链接SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-ios-integrationsdk-0000001372935825)。  

#### 设置链接参数

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250715120025.44583215561560667274223231867720:50001231000000:2800:3F0130DD3304FE32A3FDEADA25C5C36CF4A81D8501D9BCF83E2DB90FDCC86411.png)

1. （必选）创建[AGCAppLinkingComponents](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636)对象。
2. （必选）通过[urlPrefix](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section122131355604)属性设置为[申请链接前缀](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-urlprefix-0000001060148052)中的链接前缀。
3. （必选）通过[deepLink](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section68946514416)属性设置深度链接地址。
4. 通过[androidPackageName](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section135094255614)、[androidDeepLink](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section3894652162)、[androidOpenType](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section166390301773)、[androidFallbackUrl](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section99021440813)属性设置Android应用参数信息。如果不设置Android应用参数，则默认在浏览器中打开。
5. 通过[harmonyOSPackageName](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section10886185473920)、[harmonyOSDeepLink](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section8886195412393)、[harmonyOSFallbackUrl](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section1088765413912)属性设置HarmonyOS应用参数信息。如果不设置HarmonyOS应用参数，则默认在浏览器中打开。
6. 通过[iosBundleId](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section1471013341388)、[iosDeepLink](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section4846181794)、[iosFallbackUrl](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section11401121053617)属性设置iOS应用参数信息。App Store Connect活动参数可以通过[iTunesConnectMediaType](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section08621644193819)、[iTunesConnectAffiliateToken](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section42000873917)、[iTunesConnectProviderToken](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section63171544017)、[iTunesConnectCampaignToken](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section2037835172014)属性设置。如果不设置iOS应用参数，则默认在浏览器中打开。
7. 通过[previewType](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section08781637441)属性设置链接预览类型。如果不设置，则默认采用App信息展示预览页。
8. 通过[socialTitle](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section66706569218)、[socialDescription](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section1435325515254)、[socialImageUrl](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section10937943102617)属性设置社交分享标识参数。如果不设置，则在社交平台分享时不展示社交卡片。
9. 通过[campaignName](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section3720716162711)、[campaignSource](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section960874512717)、[campaignMedium](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section9241229122813)属性设置广告跟踪参数。  

   ```
   "Objective-C"
   AGCAppLinkingComponents *component = [[AGCAppLinkingComponents alloc] init];
   component.uriPrefix = @"https://example.xxx.agconnect.link";
   component.deepLink = @"https://www.example.com";
   component.iosBundleId = @"com.ios.demo";
   component.iosDeepLink = @"agckit://ios/detail";
   component.iTunesConnectMediaType = @"MediaType";
   component.iTunesConnectAffiliateToken = @"AffiliateToken";
   component.androidDeepLink = @"agckit://android/detail";
   component.androidPackageName = @"com.android.demo";
   component.campaignName = @"name";
   component.campaignMedium = @"App";
   component.campaignSource = @"AGC";
   component.socialTitle = @"Title";
   component.socialImageUrl = @"https://example.com/1.png";
   component.socialDescription = @"Description";
   component.previewType = AGCLinkingPreviewTypeAppInfo;
   ```

   ```
   "Swift"
   let components = AGCAppLinkingComponents()
   components.uriPrefix = "https://example.drcn.agconnect.link"
   components.deepLink = "https://www.example.com"
   components.iosBundleId = Bundle.main.bundleIdentifier
   components.iosDeepLink = "agckit://ios/detail"
   components.iTunesConnectMediaType = "MediaType"
   components.iTunesConnectAffiliateToken = "AffiliateToken"
   components.androidDeepLink = "agckit://android/detail"
   components.androidPackageName = "com.android.demo"
   components.campaignName = "name"
   components.campaignMedium = "App"
   components.campaignSource = "AGC"
   components.socialTitle = "Title"
   components.socialImageUrl = "https://example.com/1.png"
   components.socialDescription = "Description"
   components.previewType = .appInfo
   ```

#### 获取长链接

设置链接参数后，可以通过[\[AGCAppLinkingComponents buildLongLink\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section13125062912)方法生成并获取[长链接](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-introduction-0000001054143215#ZH-CN_TOPIC_0000001056576415__p1152614142216)地址。  

```
"Objective-C"
[component buildLongLink];
```

```
"Swift"
components.buildLongLink()
```

#### 获取短链接

设置链接参数后，可以通过[\[AGCAppLinkingComponents buildShortLink\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section194718269442)方法生成并获取[短链接](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-introduction-0000001054143215#ZH-CN_TOPIC_0000001056576415__p352661132214)地址。  

```
"Objective-C"
[component buildShortLink:^(AGCShortAppLinking * _Nullable shortLinking, NSError * _Nullable error) {
    if (shortLinking) {
        NSURL *shortUrl = shortLinking.url;
    }
}];
```

```
"Swift"
components.buildShortLink { (shortLink, error) in
    let shortUrl = shortLink?.url
}
```

默认生成的短链接后缀长度从4位字符开始，也可通过调用[\[AGCAppLinkingComponents buildShortLink:callback\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section2833147451)方法配置短链接的长度。  

#### 将长链接修改为短链接

如果你已经生成了一个[长链接](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-introduction-0000001054143215#ZH-CN_TOPIC_0000001056576415__p1152614142216)，需要将长链接转化为[短链接](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-introduction-0000001054143215#ZH-CN_TOPIC_0000001056576415__p352661132214)，可以使用如下步骤。

1. 创建[AGCAppLinkingComponents](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636)对象。
2. 通过[longLink](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section32864355319)属性设置长链接地址。
3. 调用[\[AGCAppLinkingComponents buildShortLink\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingcomponents-0000001054853636#section194718269442)方法生成短链接。  

   ```
   "Objective-C"
   AGCAppLinkingComponents *component = [[AGCAppLinkingComponents alloc] init];
   component.longLink = @"https://xxxx.drcn.agconnect.link/?deeplink=https%3a%2f%2fwww.xxxx.com%2fdetail%3fid%3d123";
   [component buildShortLink:^(AGCShortAppLinking * _Nullable shortLinking, NSError * _Nullable error) {
       if (shortLinking) {
           NSURL *shortUrl = shortLinking.url;
       }
   }];
   ```

   ```
   "Swift"
   let components = AGCAppLinkingComponents()
   components.longLink = "https://xxxx.drcn.agconnect.link/?deeplink=https%3a%2f%2fwww.xxxx.com%2fdetail%3fid%3d123"
   components.buildShortLink { (shortLink, error) in
       let shortUrl = shortLink?.url
   }
   ```
