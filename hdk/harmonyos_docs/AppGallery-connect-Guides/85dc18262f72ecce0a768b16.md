# 查询下载任务

## 接口描述

查询下载任务，可查询由AGD发起的下载任务的下载状态。

## 输入参数

无

## 返回参数

具体状态的组合描述，请参考：[下载状态说明](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agd_sdk_beta_download-status-0000001494979201)

|参数名称|参数类型|是否必选|参数说明|
|:-------------|:---|:---|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|mAppStatusType|int|必选|下载任务的状态。 * int INSTALL_STATUS_TYPE = 1; //安装状态变化 * int DOWNLOAD_STATUS_TYPE = 2; //下载状态变化|
|mStatus|int|必选|当mAppStatusType ==1时，取值如下： * int INSTALL_SERVICE_WAIT_INSTALL = 0; //等待安装 * int INSTALL_SERVICE_INSTALLING = 1; //安装中 * int INSTALL_SERVICE_INSTALL_SUCCESS = 2; //安装成功 * int INSTALL_SERVICE_INSTALL_FAILED = -1; //安装失败 * int INSTALL_SERVICE_SILENT_INSTALL_FAILED = -2; //静默安装失败 当mAppStatusType ==2时取值如下： * int WAIT_FOR_WIFI = -1; //wifi预约中 * int WAIT_DOWNLOAD = 0; //排队等待中 * int PRE_DOWNLOAD = 1; //准备下载 * int DOWNLOAD = 2; //下载中 * int CANCEL_DOWNLOAD = 3; //取消下载 * int DOWNLOADED = 4; //下载完成 * int DOWNLOAD_FAILED = 5; //下载失败 * int DOWNLOAD_PAUSED = 6; //下载暂停 * int DOWNLOAD_MERGE = 7; //差分合成中 * int DOWNLOAD_EXCEPTION = 8; //下载中断 * int REDOWNLOAD_START_IN_HTTPS = 10; //重试下载开始|
|mProgress|int|必选|仅在mAppStatusType== 2时有效，代表下载进度，取值0-100，代表进度为0-100|

## 示例代码

```screen
QueryTaskIPCRequest queryTaskIPCRequest = new QueryTaskIPCRequest();
PendingResult<QueryTaskIPCRequest, QueryTaskResponse> pendingResultStatus =
    AgdApi.queryTasks(client, queryTaskIPCRequest);
pendingResultStatus.setResultCallback(new ResultCallback<QueryTaskResponse>() {
    @Override
    public void onResult(Status<QueryTaskResponse> result) {
        Log.i(TAG, "callQueryTask::onResult:" + result.getStatusCode());
        // 在未签署应用市场协议或接口依赖高版本等情况下result.getResponse()是空的，所以要加判空处理
        Map<String, TaskInfo> taskList = result.getResponse().getTaskList();
        if (taskList.size() > 0) {
            for (Map.Entry<String, TaskInfo> entry : taskList.entrySet()) {
                if (entry.getValue().getAppStatusType() != 0) {
                    Log.i(TAG,"packageName = " + entry.getKey() + ", statusType = "
                            + entry.getValue().getAppStatusType() + ", status = "  + entry.getValue().getStatus()
                            + ", progress = " + entry.getValue().getProgress());
               }
           }
       } else {
            Log.i(TAG, "There are currently no download or install tasks");
       }
   }
});
```
