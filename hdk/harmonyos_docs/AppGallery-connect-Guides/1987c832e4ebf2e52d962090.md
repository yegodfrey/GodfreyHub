# 下载项目级认证凭据

Server SDK初始化过程中需传入认证凭据。不同服务类型支持不同的凭据类型，云函数服务目前支持项目级凭据。

使用Server SDK项目级凭据的前提是您已经在AGC中拥有了自己的项目，并在项目中开通了AGC对应的服务且已[设置数据处理位置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-data-storage-location-0000001162597847)。确保已完成以上操作后，您可参考如下方法下载认证凭据：

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击您的项目。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704121835.08849500575562746737968949952322:50001231000000:2800:718A6EDD10A07BDCA011708C2827B2752740B074C3744A9154E9A31347EFBA57.png)

3. 在"项目设置"页面中点击"Server SDK"页签。
4. 点击认证凭据中的"创建"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704121835.62664085046348198034749442390245:50001231000000:2800:E2154A99D41E61B7533DBA39219F985DBB3A3C2A4FF53C4B0F6037CB15307F92.png)

5. 创建完后生成认证凭据，点击"下载认证凭据"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704121835.23138685835120542165845675074369:50001231000000:2800:9DBE9C23621CAF677EC32D56DE93F14E7F5E05CE451B92C0C365FF75115D9009.png)

6. 将下载后的认证凭据文件agc-apiclient-*.json放置到您的Server服务器中指定路径下，后续初始化SDK时将会使用到该文件。 注意
   >
   > 凭据文件中包含您的client_secret信息，请您妥善保管。
