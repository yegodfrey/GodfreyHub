# QQ

您可以在应用中集成QQ认证方式，让您的用户可以使用自己的QQ账号进行AppGallery Connect身份验证。  

#### 前提条件

* 您需要在AGC控制台[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-web-integration-sdk-0000001276332208)。  

#### 开发步骤

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114612.79007317902859784105807861787926:50001231000000:2800:CE1B9055BFBB7E548EE97A48764D349655BEAFD7F82625C0CF46AEBB1E2F4EC5.png "点击放大")

1. 在应用的登录界面，初始化[AGCAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254)实例，获取AGC的用户信息，检查是否有已经登录的用户。如果有则可以直接进入用户界面，否则显示登录界面。

   ```
   agconnect.auth().getCurrentUser().then(user=>{
       if(user){
           // 业务逻辑
       }
   });
   ```

<!-- -->

2. QQ账号的用户授权应用使用此账号的相关信息。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114612.04309516001857970008777473299014:50001231000000:2800:4D787CC4B650E01F3297CF9AA7A944783462EA641A68F49F52F51D450B0DD7DC.png)  
   此步骤仅供参考，更详细内容，请参见[QQ官方文档](https://wiki.connect.qq.com/网站应用接入流程)。

   获取授权QQ登录后的AccessToken和openID，用于传入AGConnect SDK，有如下两种方式可以获取：
   * 调用QQ提供的URL接口获取：
     1. 发送如下请求获取授权后的code。

        ```
        https://graph.qq.com/oauth2.0/authorize?response_type=code&amp;client_id=APPID&amp;redirect_uri=REDIRECT_URI&state=STATE
        ```

     2. 完成授权后会跳转到指定的REDIRECT_URI的页面，在页面连接后会带上返回的code信息，如：

        ```
        https://REDIRECT_URI/?code=XXXXXXXXXXXXXXXXXXXXXXXXX&state=STATE#/
        ```

     3. 发送如下请求获取accessToken和openId。

        ```
        https://graph.qq.com/oauth2.0/token?grant_type=authorization_code&client_id=APPID&client_secret=APPKEY&code=XXXXXXXXXXXXXXXXXXXXXXXXX&redirect_uri=REDIRECT_URI
        ```

     4. 调用成功后即可得到AccessToken。用AccessToken获取openID，发送如下请求：

        ```
        https://graph.qq.com/oauth2.0/me?access_token=ACCESS_TOKEN
        ```

   * 调用QQ提供的SDK接口获取：
     1. 引入QQ的JSSDK，在HTML页面合适位置加上如下代码：

        ```
        <script type="text/javascript"
                src="https://qzonestyle.gtimg.cn/qzone/openapi/qc_loader.js"
                charset="utf-8">
        </script>
        ```

     2. 调用如下接口，获取二维码验证页面：

        ```
        QC.Login.showPopup({
          appId: "APPID",
          redirectURI: "REDIRECT_URI"
        });
        ```

     3. 调用该接口后，会跳转至指定的REDIRECT_URI页面，并在URL后面拼装了AccessToken，调用如下接口可获取到openID及AccessToken：

        ```
        QC.Login.getMe(function (openID, accessToken) {
          // 这里拿到的就是需要的openID及AccessToken
        });
        ```

3. 调用[QQAuthProvider.credentialWithToken](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/qqauthprovider-web-0000001054223251#section121411406373)使用从QQ账号获取的accessToken和openId生成credential，并调用[AGCAuth.signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section18413636501)实现登录。

   ```
   let credential = agconnect.auth.QQAuthProvider.credentialWithToken(token, openId, autoCreateUser);
   if (!credential) {
   return Promise.reject('credential is undefined');
   }
   agconnect.auth().signIn(credential).then((res) => {
   // 业务逻辑
   }).catch((err) => {
   return Promise.reject('sign in failed');
   });
   ```

#### 更多信息

* 您如果想让用户可以使用多个账号登录您的应用，可以将多个[账号进行关联](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-web-associated-0000001059875925)。
* 当用户不需要使用应用，或者需要切换其他账号登录认证，可以先执行[登出](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-web-sign-out-0000001053254035)。
* 当用户需要注销当前用户，可以进行[销户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-web-deleteuser-0000001058060817)。
* 对于销户、修改密码、关联账号以及重置手机账号和邮箱账号等敏感操作，为了提高安全性，需要用户必须在5分钟内登录过才能执行。如果用户执行敏感操作时登录超过5分钟，需要[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-web-reauthenticate-0000001159181885)后再执行敏感操作。
* 您可以参考[异常处理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-web-troubleshooting-0000001053213974)实现自己的异常处理机制，从而减少异常情况的发生。
* 您可以使用云函数触发器来接收用户注册、登录、销户等关键事件，从而[扩展认证服务的能力](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-extension-0000001053372708)。
* 您可以参考[管理用户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-user-manage-0000001606051705)对用户进行解锁、停用等操作。
