# 验证用户凭据

为了识别用户身份，您可以通过Server端的REST API接口验证已经颁发的用户凭据，并且检查用户凭据是否已经撤销。  
![](https://media:801773194177502484)  
如果集成了此服务的API接口，则可以参考[调试API](https://developer.huawei.com/consumer/cn/doc/app/agc-help-debugg-api-0000001346861040)，使用AGC的API Explorer调试AGC的API接口。  

#### 前提条件

向AGC服务端发起REST API请求前，您需要先获得AGC服务端的授权，请参见[获取服务端API授权](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-obtain-apiauthorization-0000001374178549)。  

#### 开发步骤

![](https://media:801773194177530485)  
建议您首先选择本地验证的方式：

* 如果本地验证失败，说明该用户凭据存在问题，可以不用再去华为认证服务进行再次验证。
* 如果本地验证成功，但是可能存在撤销用户凭据的场景（对于已经撤销的用户凭据，无法进行本地验证）。那么此种情况可以去华为认证服务进行再次验证。  

#### 本地验证

您可以采用本地验证方式验证已颁发的用户凭据，本地用户凭据验证结果有三种：验证成功、验证失败、用户凭据已过期。

```
  /**
     * 本地验证token是否有效
     *
     * @param token token
     * @param productId 项目ID
     * @param pubKeyStr 公钥，通过调用getPublicKey() 获取。获取公钥的接口只调用一次，然后保存到本地静态常量里面即可。
     * @return true：成功。 false：失败。
     */
    public static boolean verifyAccessToken(String token, String productId, String pubKeyStr) {
        try {
            String[] field = StringUtils.split(token, "\\.");
            if (field.length != 3) {
                return false;
            }
            String payLoadStr = new String(Base64.decodeBase64(field[1]), StandardCharsets.UTF_8);
            JSONObject payLoad = JSON.parseObject(payLoadStr);
            long expTimeLong = payLoad.getLong("exp");
            Instant instant = Instant.ofEpochSecond(expTimeLong);
            LocalDateTime expTime = LocalDateTime.ofInstant(instant, ZoneId.of("UTC"));
            // 验证token是否已过期
            if (LocalDateTime.now(ZoneId.of("UTC")).isAfter(expTime)) {
                return false;
            }
            // 验证是否是本项目的token
            if (!productId.equals(payLoad.getString("aud"))) {
                return false;
            }

            KeyFactory keyFactory = KeyFactory.getInstance("RSA");
            Key publicKey = keyFactory.generatePublic(new X509EncodedKeySpec(Base64.decodeBase64(pubKeyStr)));
            Jwts.parserBuilder().setSigningKey(publicKey).build().parseClaimsJws(token);
            return true;
        } catch (Exception e) {
            e.printStackTrace();
        }
        return false;
    }

    /**
     * 获取华为认证服务的公钥。
     * 该方法在您的代码中只调用一次获取到公钥后，保存在本地的静态常量里面即可。不需要每次都调用。
     *
     * @return 公钥
     */
    public static String getPublicKey() {
        HttpGet get = new HttpGet("https://developer.huawei.com/consumer/cn/service/josp/agc/auth/keys");
        try {
            CloseableHttpClient httpClient = HttpClients.createDefault();
            CloseableHttpResponse httpResponse = httpClient.execute(get);
            int statusCode = httpResponse.getStatusLine().getStatusCode();
            if (statusCode == HttpStatus.SC_OK) {
                BufferedReader br =
                    new BufferedReader(new InputStreamReader(httpResponse.getEntity().getContent(), Consts.UTF_8));
                String result = br.readLine();

                JSONObject object = JSON.parseObject(result);
                String key = (String) object.values().toArray()[0];

                return key.replace("-----BEGIN CERTIFICATE-----", "").replace("-----END CERTIFICATE-----", "").trim();
            }
        } catch (Exception e) {
            e.printStackTrace();
        }
        return null;
    }
```

#### 服务端验证

华为认证服务提供了REST API接口，用于验证已颁发的用户凭据，用户凭据验证结果有四种：验证成功、验证失败、用户凭据已过期和用户凭据已撤销，请参考[验证用户凭据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/server-rest-verify-0000001182300271)接口进行验证。
