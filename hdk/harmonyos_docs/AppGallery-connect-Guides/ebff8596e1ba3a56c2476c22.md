# 选择使用数据库的方式

完成创建云数据库后，您需要根据实际需求选择使用数据库的方式。具体使用数据库的方式如下表所示。

|序号|使用方式|说明|
|:-|:------------------------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------|
|1|[端侧通过SDK使用云数据库](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-via-sdk-client-introduction-0000001569404757) 说明：端侧即应用客户端侧|此场景应用客户端必须集成SDK。|
|2|[云侧通过SDK使用云数据库](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-via-sdk-server-introduction-0000001518365466) 说明：云侧即应用服务端侧|此场景应用服务端必须集成Server SDK。|
|3|[通过REST API接口使用云数据库](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-restapi-0000001518509166)|此场景无需集成SDK。|
|4|[通过命令行使用云数据库](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-agcli-0000001180535238)|通常用于在开发工具中通过命令行使用云数据库，此方式可以方便开发者持续的进行**开发->调试**的过程，无需打包和更新等其他工作的干扰。|
|5|[通过Server SDK将三方数据库内容迁移至云数据库](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-app-data-migration-0000001496843917)|用于将数据从其他数据库迁移至云数据库。|
