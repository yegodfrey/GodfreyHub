# 创建第一个数据库

我们以构建简单的图书管理数据为例说明如何快速创建一个云数据库。  

#### 前提条件

* 您已经在AGC控制台上创建项目，详细操作请参见[创建项目](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createproject-0000001100334664)。
* 您已经在AGC控制台上创建应用，详细操作请参见[创建应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createapp-0000001146718717)。  

#### 步骤1 开通云数据库服务

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击需要开通云数据库的项目。
3. 在左侧导航栏选择"云开发（Serverless）\> 云数据库"，进入云数据库页面，点击"立即开通"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250925143003.15262273218156524375464602438929:50001231000000:2800:60DE4D5BA4E01EFDBA1C263C2E7E115F7430D103AB22E34F164E703565C9E6ED.png)

4. 如您尚未设置默认数据处理位置，在弹出的"数据处理位置"窗口进行设置，具体请参见[设置数据处理位置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-data-storage-location-0000001162597847#section154810363471)。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250925143003.13501676425349162563208129985888:50001231000000:2800:294298D71BA4565EEE3AF1C06B3E6758FD76F3A6D1E8B95A7203F109C46FEBCC.png)  

#### 步骤2 新增对象类型

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击需要配置云数据库的项目。
3. 在左侧导航栏选择"云开发（Serverless）\> 云数据库"，进入云数据库页面。
4. 点击"新增"，创建新的对象类型。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250925143003.63981362542015742571056529045964:50001231000000:2800:A41F9387CD62C872D8D4AB6C4A69A126925931B44F987E0E3A72F4274821F03E.png)

5. 输入"对象类型名"为"BookInfo"后，点击"下一步"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250925143003.08136579505668429908263725873726:50001231000000:2800:5DB625F5D427C83D6BEE394960453CFDA3750AD5ED3CCD9B3A42775265403E56.png)

6. 点击"+新增字段"，新增如下字段后，点击"下一步"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250925143003.31522597498116546364834045998155:50001231000000:2800:0F9B0EAA2586C087E08FCD19E95FB98F3B13BE4DBDAB31FEBCB3D01DC0F54FEE.png)

   |参数|说明|配置规则|
   |:--|:--------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |字段|字段名称。|每个对象类型，仅支持设置一种自增类型字段：IntAutoIncrement或LongAutoIncrement。|
   |类型|字段的数据类型。|当前支持的数据类型：String、Boolean、Byte、Short、Integer、Long、Float、Double、ByteArray、Text、Date、IntAutoIncrement和LongAutoIncrement。|
   |主键|设置该字段是否为对象类型的主键。|* 至少设置一个字段为主键。 * 支持设置复合主键，由多个字段组合成为主键，一个复合主键包含的字段小于或等于5个，复合主键字段顺序与字段的顺序一致。 * 数据类型为ByteArray、Text、Date、Double、Float和Boolean的字段不支持设置为主键。 * 主键的值不允许更改。|
   |非空|设置字段值是否为非空。|* 数据类型为ByteArray和Date的字段不支持设置为非空。 * 数据类型为IntAutoIncrement和LongAutoIncrement的字段默认为非空。 * 主键默认非空。 * 设置为非空的字段不支持加密和敏感。|
   |加密|设置字段是否需要加密，即开启全程加密数据管理功能。 勾选加密后，该字段对应的数据会加密存储在存储区中。|* 主键字段不支持加密。 * 加密的字段不支持设置为非空和敏感。 * 一个对象类型中包含的加密字段和敏感字段的总数需小于或等于5个。 * 字段设置为加密后，不支持导出该字段的数据值。 * 数据类型为ByteArray、Text、IntAutoIncrement和LongAutoIncrement的字段不支持加密。 * 对象类型创建成功后，不支持修改加密属性。|
   |敏感|设置字段是否为敏感字段。 勾选敏感后，该字段对应的数据会加密存储在存储区中。|* 敏感字段不支持设置为主键、非空、加密、默认值。 * 对象类型创建成功后，不支持修改敏感属性。 * 仅支持数据类型为Byte、Short、Integer、Long、Float、Double、String和Date的字段设置为敏感字段。 * 敏感字段不支持设置为索引。 * 一个对象类型中包含的加密字段和敏感字段的总数需小于或等于5个。|
   |默认值|字段为非空时，必须设置默认值。|* 主键字段、加密字段和敏感字段不支持设置默认值。 * 数据类型为ByteArray、Date、IntAutoIncrement和LongAutoIncrement的字段不支持为其设置默认值。 * 数据类型为Text的字段设置默认值时，默认值的长度小于或等于200个字符。|

7. 点击"+"新增索引，设置"索引名"为"bookName"，点击"下一步"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250925143003.43231903363903220256455114382859:50001231000000:2800:6AF6E502439BD069F533A1E3DDC45A8E2B1A5CEEC42908BD3B331C482F82E1C0.png)

   |参数|说明|配置规则|
   |:---|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------|
   |索引|索引名称。 点击"索引名"列的![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250925143003.65026621995988815799070976105253:50001231000000:2800:0C7527A4605865F1B41FC16B80F77CF15285056FCF1E46F65BE5B274E637FB4F.png "点击放大")，可以添加多个索引名。|* 每个对象类型可以设置小于或等于16个索引。 * 数据类型为ByteArray和Text的字段不支持设置为索引。|
   |索引详情|索引包含的字段和排序方式。 点击"索引详情"列的![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250925143003.05282809425088784914259415048896:50001231000000:2800:C0A749C1655CD3D569D25C791BF014B3D23E47DED76A5D2E8B7DE243CB872A8B.png "点击放大")，可以为索引增加更多的组成字段。|* 支持设置组合索引，由多个字段组合成为索引，一个组合索引包含的字段小于或等于5个。 * 支持索引按照升序或降序方式排序。|

8. 按照如下要求设置各角色权限后，点击"确定"。 具体角色和权限请参见[权限管理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-aboutclouddb-0000001080975612#section13972247121)。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250925143003.63519595849249410856355279916457:50001231000000:2800:668D62B59034A9E903AA6046B7C7A5B667F1309A1521C9DCB59B3D58562725C5.png)
9. 创建完成后返回对象类型列表，可以查看已创建的对象类型。
10. 勾选创建的BookInfo对象类型，点击"导出"。若不勾选对象类型，默认导出所有对象类型。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250925143004.73003292018857757708301152142577:50001231000000:2800:9255E1E21901901FBD4237E987C6AD2C2C61C7AC51F4DDC24F0C4EA871494C83.png)

#### 步骤3 创建存储区

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击需要配置云数据库的项目。
3. 在左侧导航栏选择"云开发（Serverless）\> 云数据库"，进入云数据库页面。
4. 点击"存储区"页签，点击"新增"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250925143004.99662140252375738489199801926872:50001231000000:2800:4E5AD9569CD09873E0486D8524B76509F673F2215F6134F61FF90157D993459A.png)

<!-- -->

5. 在"新增存储区"弹框中填写"存储区名称"为"QuickStartDemo"，点击"确定"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250925143004.81104711419438972911392183794688:50001231000000:2800:0E66EE46B2D6F0F6A19254DAA6F238309E8C684B01B4DB1AB38B16F09361CC98.png)

6. 创建完成后返回存储区列表中，可以查看已创建的存储区。
