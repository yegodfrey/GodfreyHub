# 获取SDK配置文件

## Android

### 获取agconnect-services.json文件

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择您的应用。
3. 在"项目设置"的"常规"页面，下载agconnect-services.json文件。 说明
   > * 配置文件中默认会包含AGC为应用分配的客户端密钥和API密钥信息，其中客户端密钥和API密钥均为密文。
   > * 您也可以在下载JSON文件前打开"不包含密钥"开关，配置文件中将不包含密钥信息，由您自行调用AGC SDK的接口手动配置。
   > * 如果您的套餐升级到了付费档，为避免被冒用产生异常账单，建议您将密钥存储在您自己的服务器，并妥善保管。

## iOS

### 获取agconnect-services.plist文件

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择您的iOS应用。
3. 在"项目设置"页面下载配置文件"agconnect-services.plist"。 说明
   > * 配置文件中默认会包含AGC为应用分配的客户端密钥和API密钥信息，其中客户端密钥和API密钥均为密文。您也可以在下载agconnect-services.plist文件前打开"不包含密钥"开关，配置文件中将不包含密钥信息，由您自行调用AGC SDK的接口手动配置。如果您的套餐升级到了付费档，为避免被冒用产生异常账单，建议您将密钥存储在您自己的服务器，并妥善保管。
   > * Safari浏览器当前不支持下载"agconnect-services.plist"文件，请使用Chrome浏览器。
