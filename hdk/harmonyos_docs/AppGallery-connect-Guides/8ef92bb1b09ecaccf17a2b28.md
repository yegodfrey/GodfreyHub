# 概述

在一些游戏或直播场景中，通常为了增强真实感或烘托场景氛围，需要播放一些简短的效果音，例如子弹声或掌声等。游戏多媒体SDK提供了效果音播放的相关接口，可用于实现简短音效的播放与音量系数管理等能力。
