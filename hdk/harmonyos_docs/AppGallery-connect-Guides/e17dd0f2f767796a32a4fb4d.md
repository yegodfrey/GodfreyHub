# 设置主要参数

启动游戏后，必须先设置相应的预测算法以及所需参数等信息（至少提供一次），用于后续预测帧的计算和绘制工作。  

#### 前提条件

已[创建库实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/predict-frame-create-instance-vulkan-0000001791483622)。  

#### 设置预测算法

根据场景需要，调用函数[FrameFlowVK_SetPredictionAlgorithm](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflowvk-setpredictionalgorithm-0000001838253801)设置不同的预测算法，以便获得更好的预测效果。当前，Vulkan版本的插帧服务SDK仅支持FF_PREDICTION_ALGORITHM_GRIDWARP算法。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240314102214.04857279027183891027775248477410:50001231000000:2800:87FCE1E163419877F05C0C6250D3DEE21E189C02AF76C99CE9B94744A88C8E10.png?needInitFileName=true?needInitFileName=true)  
设置预测算法是绘制预测帧的必要前提，因此必须设置。

```
FFResult FrameFlowVK_SetPredictionAlgorithm(FFVKInstance instance, const FFPredictionAlgorithmInfo* pPredictionAlgorithmInfo, FFAlgorithmCapabilitiesInfo* pCapabilitiesInfo);
```

#### 设置输入描述

在启动时，调用函数[FrameFlowVK_SetInputDescription](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflowvk-setinputdescription-0000001791497076)将输入描述信息（例如分辨率、Z轴可视坐标范围、模板缓冲区映射）传递给算法。

```
FFResult FrameFlowVK_SetInputDescription(FFVKInstance instance, const FFInputDescription* pInputDescription);
```

分辨率是全部预测算法所需的必要信息，因此至少需要将关于分辨率的信息添加到扩展链中。  

#### 设置分辨率

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240314102214.70900895160722588500018792128670:50001231000000:2800:E74295308E557A7567CAF0DEF68F469FCE3A580A60B171E56D29D239ED8D7C92.png?needInitFileName=true?needInitFileName=true)  
当游戏画面宽高发生变化，则需要重新设置画面分辨率。

分辨率决定了帧画面的输出质量，因此您需要将[FFExtent2D](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffextent2d-vulkan-0000001791334728)或[FFResolutionInfo2](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffresolutioninfo2-vulkan-0000001838093905)结构体通过添加到[FFInputDescription](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffinputdescription-vulkan-0000001791337356)结构体的pNext扩展链中，来设置输出帧的分辨率。  

#### 设置Z轴可视坐标范围

在将所有可见的顶点坐标通过透视投影方式转化为标准化设备坐标（Normalized Device Coordinate）前，应通过添加结构体[FFCvvZSemanticInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffcvvzsemanticinfo-vulkan-0000001838096529)到[FFInputDescription](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffinputdescription-vulkan-0000001791337356)结构体的pNext扩展链中，来设置规则观察体（Canonical View Volume）的Z轴可视坐标范围以及深度测试方式，以便限定相机的可见范围，否则将设置为默认值。如果您需要进行修改，可调用函数[FrameFlowVK_SetCvvZSemantic](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflowvk-setcvvzsemantic-0000001799312774)重新设置。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240314102214.18452067508525773093510394312861:50001231000000:2800:212B19949B36A4A4A2C3FC336E810F72CFB42A54197AB68E3BE50EEAF79F815A.png?needInitFileName=true?needInitFileName=true)  
在Vulkan中，标准化设备坐标的Z轴可视取值范围为\[-1, 1\]。在DirectX中，标准化设备坐标的Z轴可视范围为\[0, 1\]，需要手动将其调整到\[-1, 1\]的范围内。  

#### 建立模板缓冲区映射

模板缓冲区主要用于存储3D不透明场景图像中每个像素类型的模板值，通过在模板缓冲区建立并存储不同物体类型和模板值之间的映射信息，标记不同物体所属类型，以便在预测帧时进行不同程度的处理。

因此，在设置预测算法时，如果选择的是[FF_PREDICTION_ALGORITHM_GRIDWARP](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffpredictionalgorithm-vulkan-0000001791494476#ZH-CN_TOPIC_0000001791494476__p1753161714567)预测算法（模板映射信息为该算法必要信息），则必须将模板映射行为通过[FFStencilRemapInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffstencilremapinfo-vulkan-0000001791494448)结构体添加到[FFInputDescription](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffinputdescription-vulkan-0000001791337356)结构体的pNext扩展链中。如果您需要进行修改，可调用函数[FrameFlowVK_SetStencilRemapInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflowvk-setstencilremapinfo-0000001791334684)重新建立模板缓冲区映射。如未建立映射，则库实例会将所有物体均识别为静态物体。  

#### 指示深度/模板Y方向翻转

仅当深度/模板缓冲区相对于颜色缓冲区在Y方向上有翻转时，您需要将[FFDepthStencilYDirectionInverted](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffdepthstencilydirectioninverted-vulkan-0000001791836976)结构体添加到FFInputDescription结构体的pNext扩展链中，这对于需要深度/模板信息的算法很重要。因为在这种情况下，如果结构体不被添加到pNext扩展链中，则FrameFlow将会接收到一个错误的深度/模板缓冲区。
