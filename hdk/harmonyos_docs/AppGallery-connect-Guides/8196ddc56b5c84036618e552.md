# 开发概览

资源包接口支持开发者使用"API"方式在AppGallery Connect创建并发布任务。
> 说明
>
> * 资源包接口仅支持开发者创建"华为CDN"方式的游戏资源包下载任务。
> * 您可以参考[发布资源包下载任务](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/graphics-accelerate-assetdownload-release)前往AppGallery Connect查看资源包预下载任务，核对接口实现是否正确。

## 前提条件

* 已在AppGallery Connect创建HarmonyOS 5.0及以上游戏，具体操作请参见[创建HarmonyOS应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-create-app-0000002247955506)。
* 已准备好游戏资源包文件并加密，且自行保证资源包文件的可用性，资源包文件支持的格式请参见[上传至华为CDN的资源包文件支持哪些格式类型](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/graphics-accelerate-assetdownload-faq-1)。单个下载任务中资源包的文件总数量不超过10000个，且单个文件大小不超过2048MB，总大小不超过150GB。

## 创建资源包下载任务

重新创建资源包下载任务并发布的开发步骤如下：

### 接口调用流程图

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/81/v3/ZP-mbKWWSxiTCWTAGC727Q/zh-cn_image_0000002403051797.png?HW-CC-KV=V1&HW-CC-Date=20260916T022030Z&HW-CC-Expire=31536000000&HW-CC-Sign=47123B240CF600EFF0F05FE3339C52A6FB24FD5C2C63117D11B92ACF6B3B4859)

### 开发步骤

1. 调用[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)接口，获取AccessToken。
2. 调用[新增资源包版本](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-respackapi-addversion-0000002328396224)接口，创建资源包预下载任务（仅有基本信息，无资源包文件）。创建后，下载任务状态为"草稿"。
3. 调用[资源包文件上传申请](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-respackapi-uploadapplyfor-0000002328236376)接口，获取上传地址uploadUrl/uploadHeaders、文件fileId等信息。
4. 根据上传地址uploadUrl完成文件上传。若单个资源包文件超过5GB，需使用分段上传方式。
5. 调用[资源包文件上传确认](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-respackapi-uploadconfirm-0000002362394641)接口，建立versionId、fileId、hotUpdateVersion的关联关系。
6. 调用[修改资源包版本](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-respackapi-modifyversion-0000002328236372)接口（isDraft参数传0），提交资源包下载任务，下载任务状态变更为"预上线"。
7. 资源包下载任务正式发布前，要求开发者在本地测试下载功能是否符合预期，具体测试过程请参见[测试下载功能](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/graphics-accelerate-assetdownload-release)。
8. 调用[发布资源包版本](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-respackapi-releaseversion-0000002362394637)接口，提交下载任务的审核。华为运营人员将在1~3个工作日内完成审批，请耐心等待，审核结果请前往[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)查看。
9. 审核通过的下载任务状态变更为"已发布"。若提前结束当前资源包下载任务，可以前往AppGallery Connect点击"终止"结束。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bb/v3/8japqM7DT-G83qZYQ5anXQ/zh-cn_image_0000002369598348.png?HW-CC-KV=V1&HW-CC-Date=20260916T022030Z&HW-CC-Expire=31536000000&HW-CC-Sign=C13C23FF16750C4197DE388240624A20D9A528B5A43EE24D3A6D45B38B7D65AB)

## 编辑资源包下载任务

开发者可以重新编辑"草稿"、"预上线"、"已发布"、"任务结束"状态的资源包下载任务。

重新编辑已有的资源包下载任务并发布的开发步骤如下：

### 接口调用流程图

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d8/v3/0Xhu6LvnT9i2I2jjUM0Klw/zh-cn_image_0000002369474734.png?HW-CC-KV=V1&HW-CC-Date=20260916T022030Z&HW-CC-Expire=31536000000&HW-CC-Sign=B76F6E81A5835EBF83BB8E9197B2CC84EA1D713A6B945DA526BC55349FE6BE0C)

2. 调用[资源包文件上传申请](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-respackapi-uploadapplyfor-0000002328236376)接口，获取上传地址uploadUrl/uploadHeaders、文件fileId等信息。
3. 根据上传地址uploadUrl完成文件上传。若单个资源包文件超过5GB，需使用分段上传方式。
4. 调用[资源包文件上传确认](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-respackapi-uploadconfirm-0000002362394641)接口，建立versionId、fileId、hotUpdateVersion的关联关系。
5. 调用[修改资源包版本](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-respackapi-modifyversion-0000002328236372)接口（isDraft参数传0），提交资源包下载任务，下载任务状态变更为"预上线"。
6. 资源包下载任务正式发布前，要求开发者在本地测试下载功能是否符合预期，具体测试过程请参见[测试下载功能](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/graphics-accelerate-assetdownload-release)。
