# 提供每帧数据

为了保证预测帧绘制成功，应在绘制前提供预测帧所需的相关数据，或补充一些详细信息以确保预测帧时更加精确。我们提供了**显式抓取数据**函数用于抓取数据，由调用方传递颜色、深度、模板以及物体的相机投影矩阵、摄像机扩展信息等帧数据。

## 前提条件

* 已[创建库实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/predict-frame-create-instance-vulkan-0000001791483622)。
* 已[设置主要参数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/predict-frame-set-frame-parameters-vulkan-0000001791323930)。

## 显式抓取数据

调用函数[FrameFlowVK_ProvidePerFrameData](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflowvk-provideperframedata-0000001838253825)，可提供预测帧所需的相关数据（如颜色、深度、模板），还可以将一些详细信息（如物体的相机投影矩阵、摄像机扩展信息）添加到pPerFrameData的pNext扩展链中，以确保预测帧时更加精确。此函数必须每帧调用一次。
> 说明
>
> 如果数据出现错误，库实例仍保持活动状态，可以尝试在下一真实帧渲染期间提供正确的数据。如果缺少某些数据：
>
> * 当数据是可选数据时，则某些功能无法使用。
> * 当数据是必填数据时，则将返回FF_ERROR_INSUFFICIENT_INPUT_DATA错误代码。

```screen
FFResult FrameFlowVK_ProvidePerFrameData(FFVKInstance instance, const FFVKPerFrameData* pPerFrameData);
```
