# 下载文件

文件上传到云端后，您可以通过如下两种方式，调用云存储SDK的API将云端文件下载到本地设备中。

* 方式一：创建需要下载文件的引用，将云端文件数据写入本地设备中已创建的文件中，具体请参见[创建文件引用](#section1514119308462)。
* 方式二：创建需要下载文件目录的引用，将该目录下指定的云端文件数据写入本地设备中已创建的文件中，具体请参见[创建目录引用](#section398610575462)。

#### 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[初始化存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-initialize-bucket-java-0000001282104682)。  

#### 下载文件

#### 创建文件引用

1. 创建需要下载文件的引用。
2. 在本地设备中创建文件。
3. 调用[StorageReference.download](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagereference-0000001158228875#section4214139135414)方法将云端文件数据写入本地文件中。  

#### 创建目录引用

1. 创建需要下载文件目录的引用。
2. 在本地设备中创建文件和指定待下载的云端文件。
3. 调用[StorageReference.download](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagereference-0000001158228875#section4214139135414)方法将云端文件数据写入本地文件中。  

#### 参考代码

下述代码以创建文件引用为例：

```
public class StorageDownload {
    private static StorageManagement storageManagement;

    /**
     * Download a file
     *
     * @throws StorageException storage exception
     */
    public static void downloadFile(String bucketName, String cloudPath, String localPath) throws StorageException {
        storageManagement =
            AGCStorageManagement.getInstance(AGCClient.getInstance(), "cn-north-4", bucketName);
        // 创建需要下载文件的引用
        StorageReference storageReference = storageManagement.getStorageReference(cloudPath);
        final String[] result = {""};
        DownloadFileRequest request = new DownloadFileRequest();
        request.setOffset(0);
        request.setSaveFile(new File(localPath)); // 在本地设备中创建文件
        request.setProgressListener(new ProgressListener() {
            @Override
            public void inProgress(ProgressStatus status) {
                result[0] = "download transferred/total:" + status.getTransferredBytes() + "/" + status.getTotalBytes()
                    + "," + status.getTransferPercentage() + "%, " + "instaneos speed: "
                    + status.getInstantaneousSpeed() + ", avg speed: " + status.getAverageSpeed();
            }
        });
        ScheduledExecutorService service = Executors.newSingleThreadScheduledExecutor();
        service.scheduleAtFixedRate(() -> System.out.println(result[0]), 2, 3, TimeUnit.SECONDS);
        // 调用StorageReference.download将云端文件数据写入本地文件中
        storageReference.download(request);
        System.out.println("download finished");
        service.shutdownNow();
    }
    public static void initializeClient(String content) throws AGCException {
        CredentialService credential =
            CredentialParser.toCredentialWithContents(content);
        AGCParameter agcParameter = AGCParameter.builder().setCredential(credential).build();
        AGCClient.initialize(agcParameter);
        System.out.println("init agcParameter Success.");
    }
    public static void main(String[] args) throws AGCException {
        // 存储实例名
        String bucketName = "xxxx";
        // 云端文件路径，支持传入“文件目录/文件名”，或仅传入文件名
        String cloudPath = "images/demo.jpg";
        // 本地文件路径，支持传入“文件目录/文件名”，或仅传入文件名
        String localPath = "images/test.jpg";
        // 凭据信息，json格式
        String credential = "{\"type\":\"project_client_id\",\"developer_id\":\"xxx\",\"project_id\":\"xxx\",\"client_id\":\"xxx\",\"client_secret\":\"xxx\",\"configuration_version\":\"3.0\",\"region\":\"CN\"}";

        StorageDownload.initializeClient(credential);

        StorageDownload.downloadFile(bucketName, cloudPath, localPath);
    }
}
```
