# 发布连接器

发布连接器才可将此连接器应用至生产环境。发布连接器有两种方式（发布自定义连接器和官方连接器的操作方法相同，下文以发布官方连接器为例介绍）：

* 方式一：
  1. 在连接器页面，点击需要发布连接器"操作"列的"发布"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250513171654.36494839216097001866034467480267:50001231000000:2800:39B9BA3BF614FEBD7C3CAF69A18502D28CC523DF12BC68106754CAF7FD179F7A.png)

  2. 在弹出的提示框中点击"确认"，连接器发布成功。
* 方式二：
  1. 在连接器页面，点击需要发布连接器的标题，进入连接器详情页。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250513171654.73772218121417432847963872367328:50001231000000:2800:8209E5A17325207FF6DF34C68A09DCB01CB0F49EFFC87C6E5CE8E818E03427BD.png)

  2. 点击"立即发布"，在弹出的提示框中点击"确认"，连接器发布成功。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250513171654.98389914937225470156853582810260:50001231000000:2800:09D031A6E81345D5125A621A8BF4AD9969A9142C4B60EB0EB489700627B5269A.png)

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250513171654.69171972884525493163899934555440:50001231000000:2800:71E352A603D805C2A2BCCEC78ABC8D4115FAE34214640C526ADFFD2CD57FBB50.png)  
发布成功后，发布状态更新为"已发布"，发布时间更新为发布时的系统时间，"操作"列的"发布"置灰。
