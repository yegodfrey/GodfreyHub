# 在Android应用中创建聚合链接

如果您希望在应用中以动态方式创建链接以便用户之间相互分享，可以在应用客户端中使用聚合链接SDK提供的API来创建聚合链接的[长链接](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-introduction-0000001054143215#ZH-CN_TOPIC_0000001056576415__p1152614142216)或[短链接](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-introduction-0000001054143215#ZH-CN_TOPIC_0000001056576415__p352661132214)。  

#### 前提条件

* 您已成功[申请链接前缀](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-urlprefix-0000001060148052)。
* 您已[添加网址允许清单](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-allowlist-0000001059304615)。
* 您的应用已[集成聚合链接SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-android-integrationsdk-0000001371557869)。  

#### 设置链接参数

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250715120016.47159326932062775656287384781981:50001231000000:2800:1B4CD332E05E8C03D1399A9F72FC6C408144C1ABB3F2E14986F47673936690A7.png)

1. （必选）调用[AppLinking.Builder](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-builder-0000001055180835)创建Builder对象。
2. （必选）调用[AppLinking.Builder.setUriPrefix](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-builder-0000001055180835#section174243419106)方法将链接前缀设置为[申请链接前缀](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-urlprefix-0000001060148052)中的链接前缀。
3. （必选）调用[AppLinking.Builder.setDeepLink](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-builder-0000001055180835#section1130926862)方法设置深度链接地址。
4. 调用[AppLinking.Builder.setAndroidLinkInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-builder-0000001055180835#section812232613614)方法设置Android应用参数，方法中包含Android参数信息的[AppLinking.AndroidLinkInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-androidlinkinfo-0000001054820877)实例使用[AppLinking.AndroidLinkInfo.Builder](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-androidlinkinfo-builder-0000001055060794)构建。如果不调用此方法，则默认在浏览器中打开。
5. 调用[AppLinking.Builder.setHarmonyOSLinkInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-builder-0000001055180835#section157412223124)方法设置HarmonyOS应用参数，方法中包含HarmonyOS参数信息的[AppLinking.HarmonyOSLinkInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-harmonyoslinkinfo-0000001215588217)实例使用[AppLinking.HarmonyOSLinkInfo.Builder](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-harmonyoslinkinfo-builder-0000001170228364)构建。如果不调用此方法，则默认在浏览器中打开。
6. 调用[AppLinking.Builder.setIOSLinkInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-builder-0000001055180835#section1668223119366)方法设置iOS应用参数，方法中包含iOS参数信息的[AppLinking.IOSLinkInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-ioslinkinfo-0000001054900816)实例使用[AppLinking.IOSLinkInfo.Builder](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-ioslinkinfo-builder-0000001055219402)构建。如果不调用此方法，则默认在浏览器中打开。

   App Store Connect活动参数信息使用[AppLinking.IOSLinkInfo.Builder.setITunesConnectCampaignInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-ioslinkinfo-builder-0000001055219402#section65911971312)方法设置，方法中包含App Store Connect活动参数信息的[AppLinking.ITunesConnectCampaignInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-itunesconnectcampaigninfo-0000001055379380)实例使用[AppLinking.ITunesConnectCampaignInfo.Builder](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-itunesconnectcampaigninfo-builder-0000001055099417)构建。
7. 调用[AppLinking.Builder.setPreviewType](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-builder-0000001055180835#section2502152310322)方法设置链接预览类型。如果不调用此方法，则默认采用App信息展示预览页。
8. 调用[AppLinking.Builder.setSocialCardInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-builder-0000001055180835#section1643135820919)方法设置社交分享标识参数，方法中包含社交分享参数信息的[AppLinking.SocialCardInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-socialcardinfo-0000001055299423)实例使用[AppLinking.SocialCardInfo.Builder](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-socialcardinfo-builder-0000001054939429)构建。如果不调用此方法，则在社交平台分享时不展示社交卡片。
9. 调用[AppLinking.Builder.setCampaignInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-builder-0000001055180835#section13352114315220)方法设置广告跟踪参数，方法中包含活动参数信息的[AppLinking.CampaignInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-campaigninfo-0000001054739403)实例使用[AppLinking.CampaignInfo.Builder](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-campaigninfo-builder-0000001055699370)构建。  

   ```
   "Java"
   AppLinking.Builder builder = AppLinking.newBuilder()
           .setUriPrefix("https://example.xxx.agconnect.link")
           .setDeepLink(Uri.parse("https://www.example.com/detail?id=123"))
           .setAndroidLinkInfo(AppLinking.AndroidLinkInfo.newBuilder()
               .setAndroidDeepLink("agckit://www.example.com/detail?id=123")
               .build())
           .setHarmonyOSLinkInfo(AppLinking.HarmonyOSLinkInfo.newBuilder()
                           .setHarmonyOSPackageName("com.huawei.HarmonyOS")
                           .setHarmonyOSDeepLink("agckit://example")
                           .setFallbackUrl("https://www.example.com")
                           .build())
           .setIOSLinkInfo(AppLinking.IOSLinkInfo.newBuilder()
               .setIOSDeepLink("agckit://example/detail")
               .setBundleId("com.example.ios")
               .setITunesConnectCampaignInfo(AppLinking.ITunesConnectCampaignInfo.newBuilder()
                   .setMediaType("MediaType")
                   .setProviderToken("ProviderToken")
                   .setAffiliateToken("AffiliateToken")
                   .build())
               .build())
           .setSocialCardInfo(AppLinking.SocialCardInfo.newBuilder()
               .setTitle("Title")
               .setImageUrl("https://example.com/1.png")
               .setDescription("Description").build())
           .setCampaignInfo(AppLinking.CampaignInfo.newBuilder()
               .setName("name")
               .setSource("AGC")
               .setMedium("App")
               .build())
           .setPreviewType(AppLinking.LinkingPreviewType.AppInfo);
   ```

   ```
   "Kotlin"
   val builder = AppLinking.newBuilder()
           .setUriPrefix("https://example.drcn.agconnect.link")
           .setDeepLink(Uri.parse("https://www.example.com/detail?id=123"))
           .setAndroidLinkInfo(AppLinking.AndroidLinkInfo.newBuilder()
                   .setAndroidDeepLink("agckit://www.example.com/detail?id=123")
                   .build())
           .setHarmonyOSLinkInfo(AppLinking.HarmonyOSLinkInfo.newBuilder()
                           .setHarmonyOSPackageName("com.huawei.HarmonyOS")
                           .setHarmonyOSDeepLink("agckit://example")
                           .setFallbackUrl("https://www.example.com")
                           .build())
           .setIOSLinkInfo(AppLinking.IOSLinkInfo.newBuilder()
                   .setBundleId("com.example.ios")
                   .setIOSDeepLink("agckit://example/detail")
                   .setITunesConnectCampaignInfo(AppLinking.ITunesConnectCampaignInfo.newBuilder()
                          .setMediaType("MediaType")
                          .setProviderToken("ProviderToken")
                          .setAffiliateToken("AffiliateToken")
                          .build())
                   .build())
           .setSocialCardInfo(AppLinking.SocialCardInfo.newBuilder()
                   .setTitle("Title")
                   .setDescription("Description")
                   .setImageUrl("https://example.com/1.png")
                   .build())
           .setCampaignInfo(AppLinking.CampaignInfo.newBuilder()
                   .setName("name")
                   .setMedium("App")
                   .setSource("AGC")
                   .build())
           .setPreviewType(AppLinking.LinkingPreviewType.AppInfo)
   ```

#### 获取长链接

设置链接参数后，可以通过本步骤创建并获取[长链接](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-introduction-0000001054143215#ZH-CN_TOPIC_0000001056576415__p1152614142216)地址。

1. 调用[AppLinking.Builder.buildAppLinking](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-builder-0000001055180835#ZH-CN_TOPIC_0000001055266733__s955f1091e0614cdfbcd608e32f3ece84)方法生成长链接。
2. 在返回的[AppLinking](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-0000001055539368)实例中使用[AppLinking.getUri](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-0000001055539368#section11140143133819)方法获取长链接地址。  

   ```
   "Java"
   Uri applinkgUri = builder.buildAppLinking().getUri();
   ```

   ```
   "Kotlin"
   val appLinkingUrl = builder.buildAppLinking().uri
   ```

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250715120016.54665314129092524479035379738144:50001231000000:2800:9CD2997A3D61B603E6FAD3641253E1FED8CEF72114B42ADAF72ABDC1370B2A7E.png)  
由于浏览器对链接地址的长度有限制，过长的长链接可能会无法访问，建议您在创建长链接时精简长链接的相关配置。  

#### 获取短链接

设置链接参数后，可以通过本步骤创建并获取[短链接](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-introduction-0000001054143215#ZH-CN_TOPIC_0000001056576415__p352661132214)地址。

1. 调用[AppLinking.Builder.buildShortAppLinking](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-builder-0000001055180835#ZH-CN_TOPIC_0000001055266733__s4d8c481e1099477c92606dd7cda877aa)方法生成短链接。
2. 在异步结果中使用[ShortAppLinking.getShortUrl](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/shortapplinking-0000001055060796#section109627504455)方法获取短链接。  

   ```
   "Java"
   builder.buildShortAppLinking().addOnSuccessListener(shortAppLinking -> {
       Uri shortLinkUri = shortAppLinking.getShortUrl();
   }).addOnFailureListener(e -> {
       //AppLinkingException
   });
   ```

   ```
   "Kotlin"
   builder.buildShortAppLinking().addOnSuccessListener {
       val shortLinkUri = it.shortUrl
   }.addOnFailureListener {
       //AppLinkingException
   }
   ```

[AppLinking.Builder.buildShortAppLinking](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-builder-0000001055180835#ZH-CN_TOPIC_0000001055266733__s4d8c481e1099477c92606dd7cda877aa)方法生成的短链接，默认使用SHORT短链接，即短链接后缀字符串长度从4位字符开始。如果您需要自定义短链接字符串后缀为LONG或SHORT，可以调用[AppLinking.Builder.buildShortAppLinking(ShortAppLinking.LENGTH length)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-builder-0000001055180835#section18547175042)方法。  

#### 将长链接修改为短链接

如果您已经生成了一个长链接，需要将长链接转化为短链接，可以使用如下步骤。

1. 调用[AppLinking.Builder](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-builder-0000001055180835)创建一个Builder对象。
2. 调用[AppLinking.Builder.setLongLink](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-builder-0000001055180835#section825513912714)方法将长链接地址设置到Builder对象中。  

   ```
   "Java"
   AppLinking.Builder builder = AppLinking.newBuilder().setLongLink(Uri.parse("https://xxxx.drcn.agconnect.link/?deeplink=https%3a%2f%2fwww.xxxx.com%2fdetail%3fid%3d123"));
   ```

   ```
   "Kotlin"
   val builder = AppLinking.newBuilder().setLongLink(Uri.parse("https://xxxx.drcn.agconnect.link/?deeplink=https%3a%2f%2fwww.xxxx.com%2fdetail%3fid%3d123"))
   ```

3. 调用[AppLinking.Builder.buildShortAppLinking](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-builder-0000001055180835#ZH-CN_TOPIC_0000001055266733__s4d8c481e1099477c92606dd7cda877aa)生成短链接。
4. 在异步结果中使用[ShortAppLinking.getShortUrl](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/shortapplinking-0000001055060796#section109627504455)获取短链接。  

   ```
   "Java"
   builder.buildShortAppLinking().addOnSuccessListener(shortAppLinking -> {
       Uri shortLinkUri = shortAppLinking.getShortUrl();
   }).addOnFailureListener(e -> {
       //AppLinkingException
   });
   ```

   ```
   "Kotlin"
   builder.buildShortAppLinking().addOnSuccessListener {
       val shortLinkUri = it.shortUrl
   }.addOnFailureListener {
       //AppLinkingException
   }
   ```
