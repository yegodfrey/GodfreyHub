# 查看和导出日志

云调试服务支持在线查看和导出日志，通过获取设备运行期间的系统日志、应用日志或主题日志，帮助用户定位问题。

## 前提条件

查看日志前必须先[申请调试设备](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddebug-debugequip-0000001122212029#section11242145501420)。

## 操作步骤

1. 调试设备申请成功后，进入调试页面，点击"Logcat"页签。 说明
   >
   > Android系统的设备展示为"Logcat"页签，HarmonyOS系统的设备展示为"HiLog"页签，此处以Android系统为例。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7c/v3/R9PCsF4dQ_uoGgSqmEA0ew/zh-cn_image_0000002147834648.png?HW-CC-KV=V1&HW-CC-Date=20260909T181014Z&HW-CC-Expire=31536000000&HW-CC-Sign=429778C9578EC66C3B66C0460F9719136B67F386F8E733FAF39AC44FF95A761C "点击放大")


2. 日志信息可以按照日志类型分为verbose、debug、info、warn、error和assert，您可通过点击日志类型下拉框选择相应的日志类型后，点击"获取日志"。 说明
   >
   > 日志可实时展示500条，下载15000条。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c2/v3/uHF8NT01TSqcCovomgsGUg/zh-cn_image_0000001091036209.png?HW-CC-KV=V1&HW-CC-Date=20260909T181014Z&HW-CC-Expire=31536000000&HW-CC-Sign=0810AEBA780BA46372FA86E4375B8A50BA7021EE18806230D0D7186BEE6E5593)

   您也可在关键字输入框中输入关键字后，点击"获取日志"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e6/v3/xAdYsk2oRrei3l7_suemMQ/zh-cn_image_0000001077619168.png?HW-CC-KV=V1&HW-CC-Date=20260909T181014Z&HW-CC-Expire=31536000000&HW-CC-Sign=D9FD0B5852FEAA5602C833B9ADE12FE83F5FEF38439303C7E1ACB847099E39DB)
3. （可选）获取到相关日志信息后，您可点击"导出日志"，将获取的日志保存至本地。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/76/v3/vXQUaZgOSnWOBo0mFXHohA/zh-cn_image_0000001090893881.png?HW-CC-KV=V1&HW-CC-Date=20260909T181014Z&HW-CC-Expire=31536000000&HW-CC-Sign=95CA87F77AA21FBB639DB40639EFCD6CC7655DA491E7E7760629FB221160AFFB)

4. （可选）点击"清空"，即可一键清除已获取的日志。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3c/v3/4qNtEYTYR6S3cufqq04Dwg/zh-cn_image_0000001091194643.png?HW-CC-KV=V1&HW-CC-Date=20260909T181014Z&HW-CC-Expire=31536000000&HW-CC-Sign=CF31A908825A60FC3F996B1BCFE62F593F812E0571B4C7AFE42EE4384BACE68C)
