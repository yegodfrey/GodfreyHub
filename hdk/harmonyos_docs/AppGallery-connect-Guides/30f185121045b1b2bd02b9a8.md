# 查看和导出日志

云调试服务支持在线查看和导出日志，通过获取设备运行期间的系统日志、应用日志或主题日志，帮助用户定位问题。

## 前提条件

查看日志前必须先[申请调试设备](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddebug-debugequip-0000001122212029#section11242145501420)。

## 操作步骤

1. 调试设备申请成功后，进入调试页面，点击"Logcat"页签。 说明
   >
   > Android系统的设备展示为"Logcat"页签，HarmonyOS系统的设备展示为"HiLog"页签，此处以Android系统为例。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7c/v3/R9PCsF4dQ_uoGgSqmEA0ew/zh-cn_image_0000002147834648.png?HW-CC-KV=V1&HW-CC-Date=20261008T191222Z&HW-CC-Expire=31536000000&HW-CC-Sign=FD8D1D386909503F565DC145493F7347FBA95C00F79594C4DB14AEE6F28244A4 "点击放大")


2. 日志信息可以按照日志类型分为verbose、debug、info、warn、error和assert，您可通过点击日志类型下拉框选择相应的日志类型后，点击"获取日志"。 说明
   >
   > 日志可实时展示500条，下载15000条。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c2/v3/uHF8NT01TSqcCovomgsGUg/zh-cn_image_0000001091036209.png?HW-CC-KV=V1&HW-CC-Date=20261008T191222Z&HW-CC-Expire=31536000000&HW-CC-Sign=CB74F5D9AD5C8F850FC1B53F8C79698A2EE6847CDC78AC85874DD252A60380E7)

   您也可在关键字输入框中输入关键字后，点击"获取日志"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e6/v3/xAdYsk2oRrei3l7_suemMQ/zh-cn_image_0000001077619168.png?HW-CC-KV=V1&HW-CC-Date=20261008T191222Z&HW-CC-Expire=31536000000&HW-CC-Sign=BBEE54414FE60E088DEB4B8C727800E3A3C2434A26AEFE1523F9BB6E1751FEEF)
3. （可选）获取到相关日志信息后，您可点击"导出日志"，将获取的日志保存至本地。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/76/v3/vXQUaZgOSnWOBo0mFXHohA/zh-cn_image_0000001090893881.png?HW-CC-KV=V1&HW-CC-Date=20261008T191222Z&HW-CC-Expire=31536000000&HW-CC-Sign=A29C67D0477CC74131C7BB8CACC979BBCD5FD062349EABD48791CFC174AD5DA1)

4. （可选）点击"清空"，即可一键清除已获取的日志。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3c/v3/4qNtEYTYR6S3cufqq04Dwg/zh-cn_image_0000001091194643.png?HW-CC-KV=V1&HW-CC-Date=20261008T191222Z&HW-CC-Expire=31536000000&HW-CC-Sign=E7E255841A1209C42C11B871A15B709061658A0380DFB08140119DD171E5D208)
