# Serverless触发器概述

云函数支持在函数版本或别名上配置触发器。调用方可以通过触发器暴露的触发条件，来实现函数调用。调用云函数时，入口方法的入参event对象中包含了各类触发器传递的信息。

目前支持的Serverless触发器类型有：

* 云数据库触发器
* 认证服务触发器
* 云存储触发器
* 远程配置触发器

> 说明
>
> 一个函数支持创建多个触发器，但远程配置触发器只能创建一个。
