# 使用入门

#### 创建项目和添加应用

如果您尚未添加项目，请在[AppGallery Connect](https://developer.huawei.com/consumer/en/service/josp/agc/index.html#/)先[创建项目](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createproject-0000001100334664)并[创建应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createapp-0000001146718717)。  

#### 前提条件

1. 创建CircleCI Android项目。
2. 注册[CircleCI](https://circleci.com/developer/orbs/orb/react-native-community/react-native#quick-start)账号。
3. 配置相关CI/CD管道（请参考CircleCI[博客](https://circleci.com/blog/building-android-on-circleci/)内容）。
4. 配置CircleCI Android项目。  

#### 项目配置流程

1. 配置文件头部声明，添加 CircleCI 2.1版本。

   ```
   version: 2.1
   ```

   如果您还没有启用CI/CD管道，请在"项目设置 \> 高级设置"路径下启用。
2. 在项目配置文件中添加orb插件。

   ```
   orbs:    
   appgalleryconnect: devwithzachary/appgalleryconnect@0.2.0
   jq: circleci/jq@2.2.0
   ```

3. 使用AppGallery Connect组件配置工作流和任务。
4. 在CircleCI平台的安全设置页面，选择同意使用三方orb插件。
