# Twitter

您可以在应用中集成Twitter认证方式，让您的用户可以使用自己的Twitter账号进行AppGallery Connect身份验证。
> 说明
>
> Twitter三方认证方式仅在海外站点支持，当您选择数据处理位置为德国、新加坡或俄罗斯时可以使用此认证方式。

## 前提条件

* 您需要在AGC控制台[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-integration-sdk-0000001326347605)。

## 开发步骤

认证服务提供了两种开发方式接入Twitter账号：

* 推荐您使用新的统一登录接入方式，请参见[统一登录接入方式](#section0700182853213)。
* 同时为了兼容性保留了老的传统接入方式，请参见[传统接入方式](#section108081735123217)。

### 统一登录接入方式

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114615.62572475204458837045900235362759:50001231000000:2800:5E50144C03E368CB95C7295801C1802C1CBC6D48B937EAA163539F3C31D413F8.png "点击放大")

1. 在项目的podfile中添加Twitter账号认证API的依赖。

   ```screen
   pod  'AGConnectAPIAuthTwitter'
   ```

2. 设置Twitter的clientId和redirect_url到对应接口。

   ```screen
   "Objective-C"
    AGCAuthThirdPartyConfig.instance.twitterClientId = @"your client_id";    
   AGCAuthThirdPartyConfig.instance.twitterRedirectUrl = @"your redirect_url";
   ```

   ```screen
   "Swift"
   AGCAuthThirdPartyConfig.instance().twitterClientId = "your client_id"
   AGCAuthThirdPartyConfig.instance().twitterRedirectUrl = "your redirect_url"
   ```

3. 在Twitter开放平台设置redirect_url的Scheme。 注意
   > * redirect url的Scheme的值需要保证唯一，且不可设置为http或https。
   > * 您可以将Scheme设置为应用包名或[agconnect-services.plist文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-obtain-files-0000001276801300#section765512271407)中的productId，例如，redirect_url格式为 app.example.com://host/path。
   > * 设置完成后请将redirect_url添加到Twitter开放平台的Callback URI/Redirect URL中。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114616.49593143685577274801381749652537:50001231000000:2800:72FA779F0AF73710A7B9D8C9F0390222C349A8496AE5DB1A9E16BBFD98D5F5E2.png)

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114616.91346209924575877187859900285660:50001231000000:2800:D92D7E433DD72192D993715914071B1E93B2904E65C0C71CC84C07BADCEC5BB0.png)
4. 在XCode中，选择您的工程设置项，左侧导航选择"TARGETS"，点击"Info"标签。 在"URL Types"添加一条新的"URL Schemes"，Identifier非必填，"URL Schemes"的值是[步骤3](#ZH-CN_TOPIC_0000001052932719__li087716193812)中的redirect_url的scheme，如下图所示。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114616.09330929907364810639952086444426:50001231000000:2800:04B6115B98951720AA85E22A2C5DA97FCFB72443197A58F3F9E48D83C96650AA.png)
5. 添加生命周期回调，请参见[统一登录调用AppDelegate回调](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-unified-login-0000001275827780)。
6. 调用[[AGCAuth signIn:controller:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346#section1835003573014)方法，登录Twitter账号。

   ```screen
   "Objective-C"
    [[[[AGCAuth getInstance] signIn:AGCAuthProviderTypeTwitter controller:self] addOnSuccessCallback:^(AGCSignInResult * _Nullable result) {
            // onSuccess
            AGCUser *user = result.user;
        }] addOnFailureCallback:^(NSError * _Nonnull error) {
            // onFail
        }];
   ```

   ```screen
   "Swift"
   AGCAuth.getInstance().sign(in: AGCAuthProviderTypeTwitter, controller: self).add(onSuccessCallback: { result in
           print("success")
       }).add(onFailureCallback: { error in
           print("failure")
       })
   ```

### 传统接入方式

Twitter的传统接入方式支持[OAuth 2.0认证方式](#ZH-CN_TOPIC_0000001052932719__li0780203312528)和[OAuth 1.0认证方式](#ZH-CN_TOPIC_0000001052932719__li63253396531)两种方式。

* OAuth 2.0认证方式 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114616.95008125773715286035272529516198:50001231000000:2800:A8CEEA6A9FBAF6A5450245770B50D60B6092CDAE9159D5934DD5F95D83AB43CD.png "点击放大")

  1. 在应用的登录界面，初始化[AGCAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346)实例，获取AGC的用户信息，检查是否有已经登录的用户。如果有则可以直接进入用户界面，否则显示登录界面。

     ```screen
     "Objective-C"
     AGCUser *user = [[AGCAuth getInstance] currentUser];
     ```

     ```screen
     "Swift"
     let user = AGCAuth.instance().currentUser
     ```


  2. 设置Twitter的clientId和redirect_url到对应接口。 注意
     >
     > redirect_url的scheme不要设置为http或https。例如，redirect_url格式为 myapp://host/path。

     ```screen
     "Objective-C"
      AGCAuthThirdPartyConfig.instance.twitterClientId = @"your client_id";    
     AGCAuthThirdPartyConfig.instance.twitterRedirectUrl = @"your redirect_url";
     ```

     ```screen
     "Swift"
     AGCAuthThirdPartyConfig.instance().twitterClientId = "your client_id"
     AGCAuthThirdPartyConfig.instance().twitterRedirectUrl = "your redirect_url"
     ```

  3. 调用Twitter账号授权登录接口，并获取Twitter账号的authCode，使用authCode生成Twitter登录参数对象。

     ```screen
     "Objective-C"
     AGCTwitterAuthParam *param = [[AGCTwitterAuthParam alloc] initWithClientId:"#ZH-CN_TOPIC_0000001052932719__li39941231175917中设置的client_id" authCode:authCode codeVerifier:"your codeVerifier" redirectUrl:"#ZH-CN_TOPIC_0000001052932719__li39941231175917中设置的redirect_url"]; 
     ```

     ```screen
     "Swift"
     let param = AGCTwitterAuthParam(clientId: "#ZH-CN_TOPIC_0000001052932719__li39941231175917中设置的client_id", authCode: authCode, codeVerifier: "your codeVerifier", redirectUrl: "#ZH-CN_TOPIC_0000001052932719__li39941231175917中设置的redirect_url")
     ```

  4. 调用[+credentialWithAuthParam:autoCreateUser:](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agctwitterauthprovider-ios-0000001054662355#section1874735772518)使用从Twitter账号获取的authCode生成credential，并调用[[AGCAuth signIn:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346#section488155612616)实现登录。

     ```screen
     "Objective-C"
     AGCAuthCredential *credential = [AGCTwitterAuthProvider credentialWithAuthParam:param autoCreateUser:YES];
     ```

     ```screen
     "Swift"
     let credential = AGCTwitterAuthProvider.credential(withAuthParam: param, autoCreateUser: true)
     ```


* OAuth1.0认证方式 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114616.23789989622727637110357296903736:50001231000000:2800:A33FCBFF88593C0D228E9515BDAFFF7F64323476648E6F6F0AACC402E31ED62D.png "点击放大")

  1. 在应用的登录界面，初始化[AGCAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346)实例，获取AGC的用户信息，检查是否有已经登录的用户。如果有则可以直接进入用户界面，否则显示登录界面。

     ```screen
     "Objective-C"
     AGCUser *user = [[AGCAuth getInstance] currentUser];
     ```

     ```screen
     "Swift"
     let user = AGCAuth.instance().currentUser
     ```


  2. Twitter账号登录，并获取Twitter账号的用户授权信息。 说明
     >
     > 此步骤仅供参考，更详细内容，请参见 [Twitter官方文档](https://developer.twitter.com/en/docs)。
     1. 在AppDelegate中添加如下代码。

        ```screen
        "Objective-C"
        - (BOOL)application:(UIApplication *)app openURL:(NSURL *)url options:(NSDictionary<UIApplicationOpenURLOptionsKey,id> *)options {
              return [[Twitter sharedInstance] application:app openURL:url options:options];
            }
        ```

        ```screen
        "Swift"
            func application(_ app: UIApplication, open url: URL, options: [UIApplication.OpenURLOptionsKey : Any] = [:]) -> Bool {
                return TWTRTwitter.sharedInstance().application(app, open: url, options: options)
            }
        ```

     2. 调用Twitter初始化接口，传入在 Twitter 开发者平台申请的APPID和APPSECRET。

        ```screen
        "Objective-C"
        [[Twitter sharedInstance] startWithConsumerKey:@"APPID" consumerSecret:@"APPSECRET"];
        ```

        ```screen
        "Swift"
        TWTRTwitter.sharedInstance().start(withConsumerKey: "APPID", consumerSecret: "APPSECRET")
        ```

     3. 调用Twitter登录接口，获取token和secret。

        ```screen
        "Objective-C"
        [[Twitter sharedInstance] logInWithCompletion:^(TWTRSession *session, NSError *error) {
              if (session) {
                  NSString *token = [session authToken];
                  NSString *secret = [session authTokenSecret];
              } else {
                  // error
              }
            }];
        ```

        ```screen
        "Swift"
                TWTRTwitter.sharedInstance().logIn { (session, error) in
                    if let session = session {
                        let token = session.authToken
                        let secret = session.authTokenSecret
                    }else{
                        // error
                    }
                }
        ```

  3. 调用[[AGCTwitterAuthProvider credentialWithToken:secret:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agctwitterauthprovider-ios-0000001054662355#section1188603824713)使用从Twitter账号获取的 accessToken 和 secret生成credential，并调用[[AGCAuth signIn:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346#section488155612616)实现登录。

     ```screen
     "Objective-C"
     AGCAuthCredential *credential = [AGCTwitterAuthProvider credentialWithToken:token secret:secret];
        [[[[AGCAuth getInstance] signIn:credential] addOnSuccessCallback:^(AGCSignInResult * _Nullable result) {
             // onSuccess
             AGCUser *user = result.user;
         }] addOnFailureCallback:^(NSError * _Nonnull error) {
             // onFail
         }];
     ```

     ```screen
     "Swift"
     let credential = AGCTwitterAuthProvider.credential(withToken:accessToken, secret:secret)
     AGCAuth.instance().signIn(credential: credential).onSuccess{ (result) in
         // onSuccess
         let user = result?.user
     }.onFailure{ (error) in
         // onFailure
     }
     ```

## 更多信息

* 您如果想让用户可以使用多个账号登录您的应用，可以将多个[账号进行关联](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-associated-0000001053053982)。
* 当用户不需要使用应用，或者需要切换其他账号登录认证，可以先执行[登出](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-sign-out-0000001053692708)。
* 当用户需要注销当前用户，可以进行[销户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-deleteuser-0000001057460873)。
* 对于销户、修改密码、关联账号以及重置手机账号和邮箱账号等敏感操作，为了提高安全性，需要用户必须在5分钟内登录过才能执行。如果用户执行敏感操作时登录超过5分钟，需要[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-reauthenticate-0000001127283387)后再执行敏感操作。
* 您可以参考[异常处理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-troubleshooting-0000001054715191)实现自己的异常处理机制，从而减少异常情况的发生。
* 您可以使用云函数触发器来接收用户注册、登录、销户等关键事件，从而[扩展认证服务的能力](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-extension-0000001053372708)。
* 您可以参考[管理用户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-user-manage-0000001606051705)对用户进行解锁、停用等操作。
