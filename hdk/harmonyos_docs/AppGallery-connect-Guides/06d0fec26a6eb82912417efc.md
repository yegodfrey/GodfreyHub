# （可选）多数据处理位置

通常情况下，为了满足各区域隐私合规或就近处理数据等要求，可以使用不同数据处理位置访问处理不同区域的数据。

* 如果您不指定数据处理位置，云存储服务将使用默认数据处理位置存放和处理数据。
* 如果设置了数据处理位置，云存储服务将在指定的数据处理位置存放和处理数据。

您可以在AppGallery Connect上[设置数据处理位置](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-data-storage-location-0000001162597847)，设置完成后重新[获取项目级认证凭据文件agc-apiclient-*.json](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-download-credentials-0000001334262141)并集成到您的项目中，然后即可在项目中对数据处理位置进行处理：

* [使用默认数据处理位置](#section1910913304262)
* [修改默认数据处理位置](#section8328654182616)
* [使用指定数据处理位置](#section66216133276)

## 使用默认数据处理位置

您可以通过[StorageManagement](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagemanagement-0000001057931714)来初始化默认数据处理位置的存储实例。

```screen
let storage = new StorageManagement();
// name: 存储实例名称
let bucket = storage.bucket(name);
```

或者，您也可以通过[AGCCloudStorage](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccloudstorage-0000001234008417)来初始化默认数据处理位置的存储实例。

```screen
let storage = AGCCloudStorage.getInstance();
// name: 存储实例名称
let bucket = storage.bucket(name);
```

## 修改默认数据处理位置

> 注意
>
> 在AGC上设置的"默认数据处理位置"适用于项目下所有应用，此处修改的"默认数据处理位置"仅对本应用生效，不会影响其他应用。

```screen
var clientName = "[CLIENT_NAME]";
var region= "[REGION]";
```

其中*[CLIENT_NAME]* 为用户自定义的客户端名称，在获取服务实例的时候，需使用该名称进行关联。*[REGION]*是客户端的数据处理位置，可选的值有"CN"（中国）、"RU"（俄罗斯）、"SG"（新加坡）、"DE"（德国）。

## 使用指定数据处理位置

如果您需要访问不同数据处理位置的存储实例，可以调用[StorageManagement.bucket(name: string, area?: string)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagemanagement-0000001057931714#section1426116294172)方法来初始化存储实例。

```screen
// 初始化云存储实例
let storage = AGCCloudStorage.getInstance();
// name: 存储实例名称, area: 数据处理位置，可选的值有"CN"（中国）、"RU"（俄罗斯）、"SG"（新加坡）、"DE"（德国）
let area = 'CN';
let bucket = storage.bucket(name, area);
```
