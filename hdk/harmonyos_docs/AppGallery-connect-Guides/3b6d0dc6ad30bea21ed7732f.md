# 语音变声

游戏多媒体语音变声能力，通过对实时语音进行变声处理，可让聊天环境变得更加有趣，提升语音体验。目前，游戏多媒体提供了机器人、怪兽、萝莉等多款声音特效。  

#### 前提条件

* 您已[集成游戏多媒体基础SDK、实时语音和变声模块](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-integratingsdk-android-0000001250838246#ZH-CN_TOPIC_0000001250838246__li733912204487)。
* 您已[创建游戏多媒体实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-engine-android-0000001193958984#section1093713161034)。
* 您已[加入房间](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-joinroom-roomid-android-0000001268934473)。
* 如需测试变声效果，需[开启麦克风](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-enablemic-android-0000001197485354)。  

#### 开发步骤

1. 调用[GameMediaEngine.enableVoiceConversion](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section13912362233)方法开启/关闭房间内语音变声。

   ```
   int result = mHwRtcEngine.enableVoiceConversion(roomId, voiceType); // roomId：房间ID; voiceType：变声类型,原声类型表示关闭变声，其他枚举值请参考VoiceType
   ```

2. 如需查询当前房间的变声类型，可通过调用[GameMediaEngine.getVoiceConversionType](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section144032144241)方法获取。如变声类型为原声类型，则表示已关闭变声。

   ```
   VoiceType voiceType = mHwRtcEngine.getVoiceConversionType(roomId); // roomId：房间ID
   ```

3. 如需测试变声效果，可通过调用[GameMediaEngine.enableEarsBack](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section10853172402412)方法开启耳返，即可听到发声者自己的语音变声效果。

   ```
   int result = mHwRtcEngine.enableEarsBack(enable); // enable：是否开启耳返,true表示开启,false表示关闭
   ```

4. 如需查询耳返是否已开启，可通过调用[GameMediaEngine.isEarsBackEnable](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section16388431122410)方法获取耳返的开启状态。

   ```
   boolean isEnable = mHwRtcEngine.isEarsBackEnable(); 
   ```
