# 下载文件

文件上传到云端后，您可以通过调用云存储SDK的API将云端文件下载到本地设备中。  

#### 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[初始化存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-initialize-bucket-harmonyos-tsapi6-0000001604393605)。
* 您已[上传文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-upload-harmonyos-tsapi6-0000001554073666)。  

#### 操作步骤

1. 调用[StorageManagement.storageReference](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-tsapi6-storage-storagemanagement-0000001553635818#section13963124903819)方法创建需要下载的文件的引用。

   ```
   var reference = storageManagement.storageReference('images/demo.jpg');
   ```

<!-- -->

2. 调用[StorageReference.getFile](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-tsapi6-storage-storagereference-0000001553476194#section47883211503)方法将云端文件数据写入本地文件中。

   ```
   reference.getFile("localFile/demo.jpg").then(res=> {
       // 下载成功
   }).catch(err => {
       // 下载失败
   });
   ```

#### 更多信息

除了在应用客户端通过云存储SDK的API来下载文件，您还可以直接[在AGC控制台以可视化的方式来下载文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-manage-file-0000001281134398#section116002011710)。
