# 创建项目和应用

若尚未在AGC控制台中创建项目和应用，请参考[创建项目](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createproject-0000001100334664)和[项目下添加应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createapp-0000001146718717)。在项目下添加应用时要求：

* "支持设备"选择"手机"。
* "应用分类"选择"游戏"。
