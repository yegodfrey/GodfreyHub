# 调试主题

您可以选择不同的真机设备，本地上传主题，安装主题至真机设备，通过真机设备对主题进行调试，提前帮助您发现问题。
> 说明
>
> 仅支持在华为Android设备上对Android主题包进行主题调试。

## 前提条件

* 在使用云调试服务前必须先[创建您的项目](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createproject-0000001100334664)。
* 调试主题前必须先[申请调试设备](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddebug-debugequip-0000001122212029#section11242145501420)。
* 在使用云调试服务前准备好需要调试的主题，且主题的大小在200MB以内。

### 释放设备

当您申请的调试设备的使用额度未用完时，您可手动释放设备，方法有如下两种：

方法一：

1. 在调试界面点击右上角"停止测试"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1d/v3/KhfZYr9AQbG1fJdWP5DgFw/zh-cn_image_0000002123005021.png?HW-CC-KV=V1&HW-CC-Date=20260909T153034Z&HW-CC-Expire=31536000000&HW-CC-Sign=AD5BEA63E33122FABA7DF5136AE82D2D5AE2DD1B7A45CFABCEB820ED14FFFD2D)

2. 在弹出的提示框中点击"确定"，即可结束调试并释放设备，页面随即跳转回"机型选择"页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/24/v3/3uPHSZWkQo6HoPjCvvkjqw/zh-cn_image_0000002122405169.png?HW-CC-KV=V1&HW-CC-Date=20260909T153034Z&HW-CC-Expire=31536000000&HW-CC-Sign=DBE7BF7898F21180DFB3FC110C1A3033ABE5BF950AC6E58687BBA4EFFFB6FCC5)

### 设备报障

如果您申请的设备存在故障，您可以通过设备报障告知我们。

1. 在调试界面点击右上角"设备报障"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c9/v3/B6N0CopdQHC5SwpuWilkaQ/zh-cn_image_0000002123006441.png?HW-CC-KV=V1&HW-CC-Date=20260909T153034Z&HW-CC-Expire=31536000000&HW-CC-Sign=E3927698F01C2776A138C3FCDF274245C4C08891438221493521B24FC754FB7F)

2. 在"设备报障"弹出框的文本框中输入故障原因后，点击"确定"。收到您的报障后，技术人员会尽快处理。 说明

## 管理主题

您可以在云调试服务下的"我的信息"界面下方"主题"页签区域上传、删除主题。
> 说明
>
> * 上传主题时，系统会对主题的"主题名称"和"版本"进行判重校验，当待上传主题的主题名称和版本与已上传主题的主题名称和版本重复时，将无法上传并弹框提示您。
>
>
> * 此处的"删除"只会删去右侧上传主题区域的主题，不会删去调试设备中的主题。如果您想删去调试设备内的主题，您需要在调试设备中的"主题"应用内操作。
