# 确保AILOD端云连通

AILOD为端云协同工作，因此在使用期间需要保持网络畅通。

1. 在顶部菜单栏选择"AILOD > Settings"，点击"Test Connection"，测试是否可以连接Huawei AILOD cloud platform。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110240.39138507527118194860595079428557:50001231000000:2800:0E702A3470381825BC535A2885BBC91062D039205610DA1B831F0D472A892BF2.png)

2. 若连接失败请前往[FAQ](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/ailod-faq-0000002509054397#section1871719355282)查看解决方案。
