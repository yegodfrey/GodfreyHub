# 设置游戏配置信息（可选）

游戏在不同设置（帧率、是否开启抗锯齿等）下，性能表现不尽相同，您可以在游戏启动及玩家设置变更时调用接口传入游戏设置组合信息。  

#### 前提条件

* 已[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-integration-ios-0000001932600658)。
* 已[初始化SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-initialization-ios-0000001932441278)。  

#### 开发步骤

1. 导入头文件。

   ```
   #import <GPMKit.h>
   ```

2. 调用[GPMManager.getInstance SetGameConfigurations](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-ios-gpmmanager-0000001941578500#section636113398576)，设置游戏配置信息，设置后SDK会在采集的性能数据中携带您传入的游戏配置信息。

   ```
   [GPMManager.getInstance setGameConfigurations:@"3;3;50;1280*720;true;true;true;true;true"];
   ```

   可在[GPMCallbackDelegate](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-ios-gpmcallbackdelegate-0000001968617713)接口的[onSetGameConfigurations](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-ios-gpmcallbackdelegate-0000001968617713#section8792175114198)方法中查看结果并实现回调处理。

   ```
   - (void)onSetGameConfigurations:(int)code msg:(NSString *_Nonnull)msg {
       // 可根据需求将数据进行处理
   }
   ```
