# 查询可用模板

通过查询可用模板，可以查看当前游戏可使用的模板列表，用于后续视频的剪辑与导出。  

#### 前提条件

* 您已[集成游戏高光时刻基础SDK和模板制作模块](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/game-highlight-integratingsdk-0000001638097622)。
* 您已[初始化SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/game-highlight-initializing-0000001638256878)。  

#### 开发步骤

1. 调用[GameReplayManager.queryTemplates](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamereplaymanager-game-replay-0000001690120477#section1651501952818)方法，查询当前游戏可以使用的全部模板列表。

   ```
   gameReplayManager.queryTemplates(); 
   ```

2. 在ReplayCallback接口的[onQueryTemplates](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/replaycallback-callback-0000001686126937#section13359357155111)方法中，实现相关回调处理。

   ```
   @Override
   public void onQueryTemplates(TemplateResult result) {
       // 查询结果
   }
   ```
