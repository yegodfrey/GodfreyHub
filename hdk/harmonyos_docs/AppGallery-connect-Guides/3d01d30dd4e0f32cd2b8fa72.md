# 通过控制台测试

> 说明
>
> 下文以函数latest版本为例介绍测试方法。若您需要测试函数的已发布版本，可在已发布版本详情页面选择"函数代码"页签，参考方式二进行测试。

函数创建后您可以在AGC控制台测试函数的代码运行是否正常。进入测试界面有两种方式：

* 方式一：函数列表中点击函数名称右侧"操作"列的"测试"，在右侧弹出的"测试函数"界面进行测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/47/v3/CoOWWiEDQyq-nHzb2fgfHQ/zh-cn_image_0000001978548797.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=99868E8FD359895191138F526EC948E341F86435A668AC67CA1520FBBC6AF845)

* 方式二：
  1. 在函数列表中点击已创建的函数名称，进入函数详情页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b7/v3/QnHMquBHTPitXi_JR8ECCg/zh-cn_image_0000001948908550.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=9DA59B0E0CEA7E917F7D885A957623F0291F4F3DA0E9FAF99DB413F2E6632A00)

  2. 选择"函数代码"页签，点击"测试函数"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0/v3/Rk7kugnoQuq0cbA1E8u23Q/zh-cn_image_0000001800662133.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=C92459BE506887C81D3C7FE6D26B9CA6588C3893B75C7FFD68C80529409527E6)

  3. 在右侧弹出的"测试函数"界面，使用默认测试事件、创建新测试事件或者使用已保存测试事件进行测试。
     * 使用默认测试事件 直接点击"测试"对函数进行测试。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a7/v3/C9inRFysR2m4wF3t9BOBvA/zh-cn_image_0000001722152221.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=EEADAC8268F9B60B647ECAE9C8B1C7339DCB56BF87307F1D6C9595B5F13D3ED3)
     * 创建新测试事件 如果需要设置调用函数的请求消息体，可按照如下步骤配置测试参数，并可保存为测试事件方便后续继续使用。

       1. 在"事件"文本框中输入JSON格式的事件参数，点击"保存"。然后在"提示"弹出框中输入事件名称，配置完成后点击弹出框右下角的"确认"。 说明
          >
          > "事件"文本框内输入的JSON对象，对应的是触发器的event事件格式，会透传给函数。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c0/v3/MFj18TjWQVuxiNCjE9l5KQ/zh-cn_image_0000001756189981.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=B91843FE4A6F386A51A578F98E2B05425937AD4B055CEC5C6B11CAFB42C4CBC0)
       2. 点击"测试"，函数处理事件并返回测试结果。
     * 使用已保存测试事件
       1. 在"测试函数"界面，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2c/v3/nsEd-jHKTpuSahuDwA7CEg/zh-cn_image_0000001722236597.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=AAC1EFD3BF3701BA902B2CF0DF9C986BF5D59CDAF19611BC7E8B97029B1A02F4)展开已保存的测试事件列表，选择已配置的事件名称右侧的"加载"，然后点击"测试"，函数处理事件并返回测试结果。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ce/v3/aCE4xzQKRKq168OIuPq2QA/zh-cn_image_0000001722453985.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=22A9EA86CCCAEF25969F6B5168EAD3777F65DCE063FFA29A6F296EFCFABBDA0D)
       2. （可选）若您需要删除已添加的测试事件，可在测试事件列表中点击事件名称右侧的"删除"即可删除测试事件。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5e/v3/e5GHzOo0RHCUYw07ntcgqQ/zh-cn_image_0000001722158501.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=7B7E6A0212C28C1AD15E5D61194641B8822155BF054070C7100265F55AC79DAC)

  4. 查看测试结果。
     * 执行结果：展示测试后获得的响应结果。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/97/v3/waapWlOERCuvRTCxxn9hlQ/zh-cn_image_0000001674184734.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=31EFE364FFC65436BCB251F8FADB541A5DA4A40045DEFB2AF746FBDB002736E9)

     * 运行日志：展示函数运行过程中，通过logger API打印的日志，支持输出debug级别及以上日志（以下仅为日志输出示例）。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e8/v3/c3UzT0n-TmCSkbUMMrRSGA/zh-cn_image_0000001674190046.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=192CC734E9C9FD68CF314ACD2DBB1E19AC6B7B67CD4DFBDB3B012F106D18AE83)

     * 执行摘要：展示该次测试请求相关信息。
       * 请求ID：该条测试请求的RequestID，在后台日志中体现为X-Trace-ID。
       * 持续时间：函数执行的端到端时间。
       * 执行版本：该次调用测试的具体函数版本。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b6/v3/ioqJuHfORQCxNOcfkVc6rw/zh-cn_image_0000001674344770.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=E4C9281C8B00A8654F982578B0EC5C2D4CA638FE665763BF9226D2E4C114122C)
  5. "代码输入类型"为"在线编辑"的函数，测试过程中，若您需要修改函数入口文件代码，可直接在"函数代码"页签的代码编辑器中修改，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/34/v3/YroDOtBKTOOwIXKM41l5CA/zh-cn_image_0000001753703418.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=35DC6E05334EF75E10B0AF8EB69F5DB79E0EC3369B7A1D5BC046C5086594522C)

     "代码输入类型"为".zip文件"的函数，测试过程中，若您需要修改函数代码文件，可在本地修改且打包完成后，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/24/v3/NYUCFSSwQVWWPSh5ICftDA/zh-cn_image_0000001717161230.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=123CB59A154D800252AA717BF534EC81D72DA7397E42C7EE445273D509A3EAF2)重新上传函数部署包，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。
     > 说明
     >
     > 若代码更新量比较大，需要调整函数内存配置，可点击"内存配置"下拉框进行调整，然后再上传函数部署包。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/93/v3/4pvdLL4dSS69XaTKKpz9ug/zh-cn_image_0000002433940774.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=3D5C0091213DB31475EE77E5B509DA62422FD3872DB27F1151736C883D4EB439)
  6. 函数测试无误后，您可在"函数代码"页签点击"导出函数"导出函数部署包。导出包以"函数名称+函数版本.zip"格式命名，可查看函数结构和文件内容。
