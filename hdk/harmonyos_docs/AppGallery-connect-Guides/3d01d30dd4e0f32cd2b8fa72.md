# 通过控制台测试

> 说明
>
> 下文以函数latest版本为例介绍测试方法。若您需要测试函数的已发布版本，可在已发布版本详情页面选择"函数代码"页签，参考方式二进行测试。

函数创建后您可以在AGC控制台测试函数的代码运行是否正常。进入测试界面有两种方式：

* 方式一：函数列表中点击函数名称右侧"操作"列的"测试"，在右侧弹出的"测试函数"界面进行测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/47/v3/CoOWWiEDQyq-nHzb2fgfHQ/zh-cn_image_0000001978548797.png?HW-CC-KV=V1&HW-CC-Date=20261008T171927Z&HW-CC-Expire=31536000000&HW-CC-Sign=1826B4FA78D0978C0BA128B06A8C19FA6B3CE7373913CB152E5E04D387EB565D)

* 方式二：
  1. 在函数列表中点击已创建的函数名称，进入函数详情页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b7/v3/QnHMquBHTPitXi_JR8ECCg/zh-cn_image_0000001948908550.png?HW-CC-KV=V1&HW-CC-Date=20261008T171927Z&HW-CC-Expire=31536000000&HW-CC-Sign=3D701C7838AEC23E52E7EDF6BD9236C6CEC502C954FB68349B7937CF75C08FB0)

  2. 选择"函数代码"页签，点击"测试函数"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0/v3/Rk7kugnoQuq0cbA1E8u23Q/zh-cn_image_0000001800662133.png?HW-CC-KV=V1&HW-CC-Date=20261008T171927Z&HW-CC-Expire=31536000000&HW-CC-Sign=3F862EB695784C23597747C69F6F698E59F9744E823AFADFB137D1501FA533BE)

  3. 在右侧弹出的"测试函数"界面，使用默认测试事件、创建新测试事件或者使用已保存测试事件进行测试。
     * 使用默认测试事件 直接点击"测试"对函数进行测试。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a7/v3/C9inRFysR2m4wF3t9BOBvA/zh-cn_image_0000001722152221.png?HW-CC-KV=V1&HW-CC-Date=20261008T171927Z&HW-CC-Expire=31536000000&HW-CC-Sign=84681C878ACBE4573A7914DAB6CB1AEECE89A4188E4C38C73DCAE66353711478)
     * 创建新测试事件 如果需要设置调用函数的请求消息体，可按照如下步骤配置测试参数，并可保存为测试事件方便后续继续使用。

       1. 在"事件"文本框中输入JSON格式的事件参数，点击"保存"。然后在"提示"弹出框中输入事件名称，配置完成后点击弹出框右下角的"确认"。 说明
          >
          > "事件"文本框内输入的JSON对象，对应的是触发器的event事件格式，会透传给函数。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c0/v3/MFj18TjWQVuxiNCjE9l5KQ/zh-cn_image_0000001756189981.png?HW-CC-KV=V1&HW-CC-Date=20261008T171927Z&HW-CC-Expire=31536000000&HW-CC-Sign=2229A055C4BF482871BDC6DBF2FFAEAAC51861BF21703B42C8A71EAF6E59CDCC)
       2. 点击"测试"，函数处理事件并返回测试结果。
     * 使用已保存测试事件
       1. 在"测试函数"界面，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2c/v3/nsEd-jHKTpuSahuDwA7CEg/zh-cn_image_0000001722236597.png?HW-CC-KV=V1&HW-CC-Date=20261008T171927Z&HW-CC-Expire=31536000000&HW-CC-Sign=2E95EC737BACFC77139FEBAA450263ECCD010ABBD5D7F9E596CECDB9F6EDD1E4)展开已保存的测试事件列表，选择已配置的事件名称右侧的"加载"，然后点击"测试"，函数处理事件并返回测试结果。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ce/v3/aCE4xzQKRKq168OIuPq2QA/zh-cn_image_0000001722453985.png?HW-CC-KV=V1&HW-CC-Date=20261008T171927Z&HW-CC-Expire=31536000000&HW-CC-Sign=E67D74A987F55CF46A10D1F63D871F572EA4CBD8391E4063728B53D1091C2026)
       2. （可选）若您需要删除已添加的测试事件，可在测试事件列表中点击事件名称右侧的"删除"即可删除测试事件。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5e/v3/e5GHzOo0RHCUYw07ntcgqQ/zh-cn_image_0000001722158501.png?HW-CC-KV=V1&HW-CC-Date=20261008T171927Z&HW-CC-Expire=31536000000&HW-CC-Sign=57AFF7F442BAECA64F02D9EC2FFDA7DDAF80500775938B0F2049534A68CA98D6)

  4. 查看测试结果。
     * 执行结果：展示测试后获得的响应结果。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/97/v3/waapWlOERCuvRTCxxn9hlQ/zh-cn_image_0000001674184734.png?HW-CC-KV=V1&HW-CC-Date=20261008T171927Z&HW-CC-Expire=31536000000&HW-CC-Sign=CFBCA852B42FF32E634B60A7BA5868168DC377058686357EBDF29AF810DE4F0F)

     * 运行日志：展示函数运行过程中，通过logger API打印的日志，支持输出debug级别及以上日志（以下仅为日志输出示例）。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e8/v3/c3UzT0n-TmCSkbUMMrRSGA/zh-cn_image_0000001674190046.png?HW-CC-KV=V1&HW-CC-Date=20261008T171927Z&HW-CC-Expire=31536000000&HW-CC-Sign=450DCA3F8E34EFFD40FE0C8F9DB7E22ACC41483FB91DAD76DD893E375990B7E6)

     * 执行摘要：展示该次测试请求相关信息。
       * 请求ID：该条测试请求的RequestID，在后台日志中体现为X-Trace-ID。
       * 持续时间：函数执行的端到端时间。
       * 执行版本：该次调用测试的具体函数版本。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b6/v3/ioqJuHfORQCxNOcfkVc6rw/zh-cn_image_0000001674344770.png?HW-CC-KV=V1&HW-CC-Date=20261008T171927Z&HW-CC-Expire=31536000000&HW-CC-Sign=086A06762BE2839D7232CDFCB9D390D7DF0BD50D222E870CCDF187DC9C82B432)
  5. "代码输入类型"为"在线编辑"的函数，测试过程中，若您需要修改函数入口文件代码，可直接在"函数代码"页签的代码编辑器中修改，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/34/v3/YroDOtBKTOOwIXKM41l5CA/zh-cn_image_0000001753703418.png?HW-CC-KV=V1&HW-CC-Date=20261008T171927Z&HW-CC-Expire=31536000000&HW-CC-Sign=13FD2411F9BFB5405D85639ECD61F78B687113B8AFE0F06BC5D05D76A7FDBA37)

     "代码输入类型"为".zip文件"的函数，测试过程中，若您需要修改函数代码文件，可在本地修改且打包完成后，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/24/v3/NYUCFSSwQVWWPSh5ICftDA/zh-cn_image_0000001717161230.png?HW-CC-KV=V1&HW-CC-Date=20261008T171927Z&HW-CC-Expire=31536000000&HW-CC-Sign=20049C574A2586DBF58E1737E7B5FFE6B2E04C51251C2035DCB3A7F55CE643BC)重新上传函数部署包，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。
     > 说明
     >
     > 若代码更新量比较大，需要调整函数内存配置，可点击"内存配置"下拉框进行调整，然后再上传函数部署包。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/93/v3/4pvdLL4dSS69XaTKKpz9ug/zh-cn_image_0000002433940774.png?HW-CC-KV=V1&HW-CC-Date=20261008T171927Z&HW-CC-Expire=31536000000&HW-CC-Sign=CD942B2C0A0FEBE176299B0C0441C306CE49ADF5715CAC4333673276665D266F)
  6. 函数测试无误后，您可在"函数代码"页签点击"导出函数"导出函数部署包。导出包以"函数名称+函数版本.zip"格式命名，可查看函数结构和文件内容。
