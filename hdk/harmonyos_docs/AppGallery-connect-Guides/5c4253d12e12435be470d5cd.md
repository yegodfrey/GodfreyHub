# 总体流程

如果您首次在AppGallery Connect中发布应用，您需要按以下流程执行。

* 创建应用：在AppGallery Connect网站中手动创建应用。
* 开发应用：在自己的开发环境中完成应用的开发并将应用打包。
* 配置应用信息：调用Publishing API更新在AppGallery Connect创建的应用信息，将应用信息补充完整。
* 上传应用文件：调用Publishing API上传应用的软件包，例如APK、RPK、AAB等文件，以及应用的图标、介绍图片、视频等文件信息。
* 发布应用：调用Publishing API提交发布应用。

调用Publishing API前请确认已经完成[使用入门](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114)中的服务端授权。  

#### 创建应用

由于当前Publishing API不支持直接创建应用，需要您先在AppGallery Connect网站手动创建，具体步骤参见AppGallery Connect帮助中心的[创建应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createapp-0000001146718717)章节。创建应用后您需要参见[查看应用基本信息](https://developer.huawei.com/consumer/cn/doc/app/agc-help-appinfo-0000001100014694)获取应用ID。  

#### 开发应用

应用创建后您可以按照正常流程完成应用的开发并打包，本文档仅介绍Publishing API的开发方法，应用的功能开发请自行完成。  

#### 配置应用信息

应用开发完成后您可以调用Publishing API完善AppGallery Connect上应用的详细信息，您需要关注的应用信息包括以下两部分：

* 应用基本信息：应用基本信息包括应用的语言、分类、国家码、开发者信息等，您可以调用[更新应用基本信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-info-update-0000001111685198)接口完成应用基本信息的修改。如果您需要确定应用当前信息是否准确，您还可以调用[查询应用信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-info-query-0000001158365045)接口查询当前应用的详情。
* 语言描述信息：语言描述信息包括应用各个语种的描述信息，您需要调用[更新语言描述信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-language-info-update-0000001158245057)接口完成语言描述信息的新增或修改，其中默认语言的信息必须填写。如果您需要删除某个语言描述信息，可调用[删除语言描述信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-language-info-delete-0000001111845088)接口。

应用的内容分级信息当前无法通过Publishing API完成，您必须在AppGallery Connect网站中手动配置，参见[修改内容分级](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-add_appinfo-0000001111845350#section116mcpsimp)。  

#### 上传应用文件

应用信息填写完整后，您需要准备应用的相关文件，例如应用的APK、RPK、AAB等文件，以及应用的图标、介绍图片、视频文件等。通过Publishing API上传应用文件为服务器对服务器上传，相对于AppGallery Connect网站中上传文件的上传速度更快，且不受您个人设备所在网络的限制。上传应用文件包括3个步骤：

1. 获取上传文件地址：在上传文件前，您需要调用[获取上传文件地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-upload-url-new-0000001111685200)接口获取文件上传的地址。
2. 上传文件：您需要调用[上传文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-upload-file-new-0000001111845090)接口将文件上传到华为文件服务器。如果APK文件较大，可使用[上传分片实体](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obbfile-upload-0000001158245067)方式上传。
3. 更新应用文件信息：文件上传成功后，您可以调用[更新应用文件信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-file-info-0000001111685202)接口将文件的具体信息写入AppGallery Connect。

如果您是中国大陆开发者或您开发的应用发布地区包含中国大陆，您还可以调用[通过下载方式提交发布](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-submit-with-file-0000001111845092)接口来发布应用，这种方式无需您在此处上传应用软件包。您只需要提供您的软件包所在的下载地址，华为服务器会从您的下载地址直接下载软件包用于应用发布。这种方式比使用[上传文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-upload-file-new-0000001111845090)接口上传速度更快。  

#### 发布应用

应用文件信息补充完整后，您可以提交应用发布，发布成功后您的应用将会在AppGallery中上架。目前Publishing API支持以下两种应用发布方式：

* 直接提交发布：应用文件上传成功后，您可以调用[提交发布](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-submit-0000001158245061)接口直接提交发布请求。
* 通过下载方式提交发布：如果您的应用软件包保存在自己的服务器中，您可以调用[通过下载方式提交发布](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-submit-with-file-0000001111845092)接口通知华为服务器从您传入的下载地址中下载应用对应的软件包后启动发布。应用发布成功后华为服务器会通过[回调结果通知](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-notify-release-0000001158245063)接口通知您的服务器。此方式只支持发布地区包含中国大陆的应用或中国大陆开发者开发的应用。
