# 在AGC控制台查看数据

游戏集成游戏性能管理SDK后将在运行过程中采集性能数据，并上报至AGC控制台。您可以登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)， 查看已上报的游戏性能数据。  
* [游戏性能分析](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-view-data-game-performance-analysis-0000002001090230)  
* [单用户查询](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-view-data-single-user-query-0000002037169449)  
* [崩溃管理服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-view-data-crash-management-0000002250644117)  
* [功耗分析](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-view-data-power-consumption-analysis-0000002149912773)
