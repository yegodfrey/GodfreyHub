# 用量管理

> 注意
>
> 当"默认数据处理位置"为德国时，不支持用量管理功能。

您可以通过用量趋势图，了解最近您在不同时间段的用量及总的配额信息。

1. 在云托管服务页面，点击"用量"，进入"用量"页面。


2. 用户选择左上角的服务类型后，可以通过右上角几个时间段快捷按钮，查询出对应时间段使用存储空间和下载量的情况。
