# 提交玩家分数

提交玩家分数可通过调用指定函数实现。  

#### 前提条件

* 您已[查询HTTP触发器标识](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/call-function-android-0000001712888921#section850417109222)。
* 您已[集成云函数SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/sdk-android-studio-0000001512198614)。  

#### 开发步骤

应用集成了云函数SDK后，可以在应用内直接通过SDK API调用AGC中的函数，云函数SDK与AGC的函数调用基于HTTPS的安全访问。

1. 调用云函数SDK中的[AGConnectFunction.getInstance](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agconnectfunction-0000001057944573#section17926173407)方法初始化[AGConnectFunction](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agconnectfunction-0000001057944573)实例。

   ```
   AGConnectFunction.getInstance();
   ```

2. 初始化后，调用[AGConnectFunction.wrap](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agconnectfunction-0000001057944573#section358219334409)方法并传入提前查询的触发器标识。

   ```
   AGConnectFunction.wrap("agc-slts-86803****5042816-2-$latest");
   ```

3. 您可以调用[FunctionCallable.call(T object)](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/functioncallable-0000001058092561#section2747122193819)方法并传入函数的5个请求参数。若关注函数的返回值，您可以在接口返回的Task中设置一个addOnCompleteListener回调监听，在回调方法中获取包含函数执行结果的[FunctionResult](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/functionresult-0000001059210282)对象，调用[FunctionResult.getValue](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/functionresult-0000001059210282#section1277143703917)可以获取当前函数执行后的[响应参数](#section136072281197)。

   ```
   private void submit_user_score(String appId, String accessToken, List<String> leaderboardIds, String customProperty, int score) {
         HashMap<String, Object> map = new HashMap();
         map.put("appId", appId); // appId即应用ID，获取方法参考查看应用基本信息。
         map.put("accessToken", accessToken); // accessToken即玩家ID的认证凭据。
         map.put("leaderboardIds", leaderboardIds); // leaderboardIds即排行榜ID列表，即您在初始化云数据库的“lbId”值，您可以同时更新指定排行榜的分数。
         map.put("customProperty", customProperty); // customProperty即扩展字段，例如昵称、头像地址链接的玩家信息等。
         map.put("score", score); // score即玩家分数，要求不超过10,000,000。
         function.wrap("agc-slts-86803****5042816-2-$latest").call(map).addOnSuccessListener(new OnSuccessListener<FunctionResult>() {
               @Override
               public void onSuccess(FunctionResult functionResult) {
                   String value = functionResult.getValue();
                   try {
                       JSONObject object = new JSONObject(value);
                       JSONObject retObj = object.getJSONObject("ret");
                       int errorCode = retObj.getInt("code");
                       String errMsg = retObj.getString("msg");
   					// 根据返回码，继续进行其他返回参数的处理。
                   } catch (JSONException e) {
                       e.printStackTrace();
                   }
               }
           }).addOnFailureListener(new OnFailureListener() {
               @Override
               public void onFailure(Exception e) {
                   if (e instanceof AGCFunctionException) {
                       AGCFunctionException functionException = (AGCFunctionException) e;
                       int errorCode = functionException.getCode();
                       String message = functionException.getMessage();
   					Log.e(TAG, "errorCode = " + errorCode + ", message = " + message);
                   }
                   // ...
               }
           });
   }
   ```

#### 响应参数

|参数|必选（M）/可选（O）|参数类型|描述|
|:--|:----------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|ret|M|String|调用云函数的响应信息，包含返回码及描述信息的JSON字符串。格式为{"code":retcode, "msg": "description"}： * code为[返回码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-serverless-leaderboards-returncode-0000001323309633)。 * msg为返回码的描述信息。|

#### 响应示例

```
{
	"ret": {
		"code": 0,
		"msg": "string"
	}
}
```
