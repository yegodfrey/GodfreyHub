# 接入要求

联运合作的详细流程请参见[联运服务介绍](https://developer.huawei.com/consumer/cn/doc/distribution/promotion/service-introduction-0000001062607577)，本文仅介绍联运服务涉及SDK接入的功能开发。

联运应用需完成以下功能的开发：

|功能|必选/可选 （中国大陆）|必选/可选 （非中国大陆）|说明|预估耗时（小时）|
|:--------------------------------------------------------------------------------------------------------------------------|:-----------|:------------|:------------------------------------------------------------------------------------------------------------|:--------------------------------|
|[应用初始化](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/appgallerykit-app-init-0000001055596854)|必选|可选|* **中国大陆发布的应用**：在应用启动时进行华为联运服务的初始化，用于数据统计和公告展示。 * **中国大陆以外发布的应用：**不强制要求。|0.5|
|[应用升级](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/appgallerykit-app-update-0000001055118286)|必选|可选|* **中国大陆发布的应用**：应用启动时必须使用华为升级接口进行应用升级。 * **中国大陆以外发布的应用：**不强制要求。|0.5|
|[华为账号登录](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/appgallerykit-app-account-0000001054958304)|有条件可选|可选|* **中国大陆发布的应用**：有账号体系则必须接入华为账号服务，登录页面允许多种账号服务并存，且华为账号排在登录页面首位。 * **中国大陆以外发布的应用**：允许有多种账号登录入口，但华为账号登录入口建议排在首位。|1~2|
|[应用内支付](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/appgallerykit-app-iap-0000001055276890)|必选|必选|* 联运应用必须接入华为应用内支付。 * 如需要进行支付分成，必须要在第一次支付操作前，成功完成一次登录。|* 含订阅型商品支付：16~24 * 不含订阅型商品支付：8~16|
|[应用外支付](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/appgallerykit-app-out-iap-0000001055436870)|推荐|不支持|联运应用需要在华为应用市场应用详情页面展示商品时接入，此功能当前仅支持在中国大陆使用。|8|

> 说明
>
> 各业务的预估耗时仅包含代码开发时长，不含测试时长。

联运应用还推荐接入以下功能。

|功能|说明|
|:---------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[初始化华为分析](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/appgallerykit-app-ha-init-0000001054878363)|联运应用建议在应用启动时初始化华为分析服务，便于您统计和分析应用基础数据。|
|认证服务|联运应用推荐接入认证服务，可以帮助您统一管理包括华为账号、微信、邮箱、匿名账号等多种账号类型的用户，使您免于自行搭建用户认证系统，详细指导请参见[认证服务开发指南](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-auth-introduction-0000001053732605)。|
|崩溃服务|联运应用推荐接入崩溃服务，实时监测应用的崩溃情况，快速解决崩溃问题，详细指导请参见[崩溃服务开发指南](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-crash-introduction-0000001055732708)。|
|A/B测试|联运应用推荐使用A/B测试服务，通过分组实验判断不同方案优劣，优化应用体验，详细指导请参见[A/B测试操作指南](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-abtest-introduction-0000001058210679)。|
|性能管理|联运应用推荐使用性能管理服务，实时监控应用的性能情况，快速精准修复性能问题，持续提升用户体验，详细指导请参见[性能管理开发指南](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-apm-introduction-0000001052247254)。|
