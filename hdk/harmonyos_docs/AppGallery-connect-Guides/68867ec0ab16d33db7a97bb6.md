# 性能测试

云测试提供的性能测试在真机设备上完成性能数据采集，并深入分析应用性能薄弱点，支持检测安装启动、启动时长、界面显示、内存占用、内存占用等关键性能指标。  

#### 前提条件

您已成功创建测试任务，且配置的"测试范围"包含"性能测试"。  

#### 查看测试报告

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击需要查看测试报告的项目。
3. 在左侧导航栏中，选择"质量 \> 云测试"，进入云测试主页面。
4. 选择"测试任务"页签，您可以通过搜索框或测试任务列表中"应用类型"、"测试场景"、"测试状态"右侧的![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303165620.38034060400063092429470748376281:50001231000000:2800:36709ADD0CF765E343DD8C4BC9ED689179549CFD5CB979E218899050298F4D37.png)筛选出您要查看的测试任务，然后点击"操作"列的"查看报告"进入测试报告页面。

5. 点击"性能测试"页签，您可从性能测试的测试报告概要中查看基本的测试检测项检测结果。  

   |类别|检测项|说明|
   |:-------|:------|:-----------------------------------------------------------------|
   |安装启动|安装/启动|安装和启动是实现性能测试的基本条件，其非性能测试的检测项。当应用无法安装或应用完全无法启动，该检测项不通过，应用性能检测无法进行。|
   |启动时长（ms）|冷启动|检测被测应用的冷启动响应时间。当测试出的冷启动响应时长大于2000ms，该检测项检测不通过。|
   |启动时长（ms）|热启动|检测被测应用的热启动响应时间。当测试出的热启动响应时长大于500ms，该检测项检测不通过。|
   |界面显示|帧率（FPS）|检测被测应用的滑动帧率。当普通被测应用的FPS小于55fps，被测游戏、地图、视频类应用的FPS小于25fps，该检测项检测不通过。|
   |CPU占用（%）|后台亮屏CPU|检测被测应用的后台亮屏CPU占用率。当测试出的后台亮屏CPU占用率超过2%，该检测项检测不通过。|
   |CPU占用（%）|后台灭屏CPU|检测被测应用的后台灭屏CPU占用率。当测试出的后台灭屏CPU占用率超过2%，该检测项检测不通过。|
   |内存占用（MB）|前台内存|检测被测应用的前台内存占用情况。当测试出的前台内存占用大于500MB，该检测项检测不通过。|
   |内存占用（MB）|后台亮屏内存|检测被测应用的后台亮屏内存占用情况。当测试出的后台亮屏内存占用大于400MB，该检测项检测不通过。|
   |内存占用（MB）|后台灭屏内存|检测被测应用的后台灭屏内存占用情况。当测试出的后台灭屏内存占用大于400MB，该检测项检测不通过。|

6. 在"测试报告"下方的设备列表中，点击某款机型右侧"操作"列的"查看详情"，打开被测应用在这款机型上执行的测试详情。 该测试报告详情中包含被测应用信息、测试时长、运行被测应用的测试设备、执行时间，同时重点提供测试发现的问题点、测试截屏、异常描述和日志。您可点击测试截屏查看被测应用在所选手机上的遍历情况。在"日志"区域，点击鼠标悬停时出现的"下载"可将测试过程中打印的日志下载到本地查看。
