# UpdateAppInfo

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:-----------|:--------------------------------------------|
|appId|O|String|应用AppID。|
|name|O|String|应用名称。|
|pkgName|O|String|应用包名。|
|releaseDate|O|String|应用发布时间。 精确到天。 格式：yyyy-mm-dd|
|versionCode|O|Integer (64)|APK中解析出来的内部版本号。|
|versionName|O|String|新版本的版本名。|
|icon|O|String|应用图标链接地址。|
|hash|O|String|新版本文件摘要。|
|size|O|Integer (64)|应用大小。 单位：字节|
|sha256|O|String|应用文件sha256。|
|appSign|O|String|签名。|
|downloadUrl|O|String|应用下载地址。应为HTTPS地址。 注意： 应用下载地址有效期为7天，建议不要长时间缓存。|
|description|O|String|应用描述。 最大长度 4096。|
|briefInfo|O|String|一句话描述。|
|newFeatures|O|String|新版本特性。|
