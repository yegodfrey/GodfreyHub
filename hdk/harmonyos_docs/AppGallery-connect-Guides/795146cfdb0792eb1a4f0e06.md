# 概述

针对被认证服务注销的用户，Serverless用户数据删除模板提供云存储和云数据库服务中的数据清理的功能。通过一键部署Serverless用户数据删除模板和简单的参数配置，即可清理云存储和云数据库服务中已销户的数据，最终降低托管成本。

|序号|步骤|详情|
|:-|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|创建项目及应用|使用此Serverless模板之前，您需要先[创建项目和添加应用](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-serverless-clearuser_precfg-0000001320816577#section55472613292)。|
|2|(可选)启用认证服务|在部署此Serverless模板之前，您需要先[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-serverless-clearuser_precfg-0000001320816577#section1067152271912)。|
|3|(可选)启用云存储服务|在部署此Serverless模板之前，您需要先[启用云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-serverless-clearuser_precfg-0000001320816577#section12012712195)。|
|4|部署模板|一键部署模板，配置模板参数，参见[部署模板](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-serverless-clearuser_deploy_template-0000001320976513)。|

#### 使用场景

即使认证服务已删除用户，此部分的用户数据仍会继续托管在云服务上。使用Serverless用户数据删除模板，您可以自动执行删除用户数据，避免继续在服务中托管已删除用户的数据。

Serverless用户数据删除模板可以监听认证服务进程。当监听到userCancelAccount请求消息时，执行删除对应的用户数据操作。

具体删除文件如下：

* 删除云存储服务中与UID值匹配的文件。
* 删除云数据库服务中与UID值匹配的数据。

使用Serverless用户数据删除模板，您不必手工在服务管理页面上删除已删除用户的数据，也不必在后台删除此部分数据。此模板支持删除对应用户的云存储和云数据库服务中的数据和数据结构。
