# 下载状态说明

* packageName：被下载的应用包名
* appType：应用状态类型： 1位安装状态，2为下载状态
* status：具体状态，见下表
* progress：下载进度 （对于安装状态来讲，该值为0）

|appType|status|常量值|说明|
|:------|:-----|:------------------------------------|:-----|
|1 表示安装态|0|INSTALL_SERVICE_WAIT_INSTALL|等待安装|
|1 表示安装态|1|INSTALL_SERVICE_INSTALLING|安装中|
|1 表示安装态|2|INSTALL_SERVICE_INSTALL_SUCCESS|安装成功|
|1 表示安装态|-1|INSTALL_SERVICE_INSTALL_FAILED|安装失败|
|1 表示安装态|-2|INSTALL_SERVICE_SILENT_INSTALL_FAILED|静默安装失败|
|2 表示下载态|0|WAIT_DOWNLOAD|排队等待中|
|2 表示下载态|1|PRE_DOWNLOAD|准备下载|
|2 表示下载态|2|DOWNLOAD|下载中|
|2 表示下载态|3|CANCEL_DOWNLOAD|取消下载|
|2 表示下载态|4|DOWNLOADED|下载完成|
|2 表示下载态|5|DOWNLOAD_FAILED|下载失败|
|2 表示下载态|6|DOWNLOAD_PAUSED|下载暂停|
|2 表示下载态|7|DOWNLOAD_MERGE|差分合成中|
|2 表示下载态|8|DOWNLOAD_EXCEPTION|下载中断|
|2 表示下载态|10|REDOWNLOAD_START_IN_HTTPS|重试下载开始|
|2 表示下载态|-1|WAIR_FOR_WIFI|WIFI预约|
