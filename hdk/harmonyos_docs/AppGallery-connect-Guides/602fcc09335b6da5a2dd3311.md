# 错误码

如您在开发联运应用过程中接口调用失败，错误码可参考下表查询。

|业务|错误码|
|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|通用|调用SDK接口报错时请先参见[HMS Core SDK框架错误码](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/error-code-0000001050045846)查看是否为框架错误。|
|华为账号登录|Android SDK错误码请参见[华为账号错误码](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/account-apk-cn-common-error-codes-0000001050048616)，服务端错误码请参见[REST错误码](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/account-apk-cn-common-error-codes-0000001050048616)。|
|应用内支付|Android SDK错误码请参见[应用内支付错误码](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/client-error-code-0000001050746111)，服务端错误码请参见[REST错误码](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/server-error-code-0000001050166248)。|
|应用外支付|请参见[应用外支付错误码](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/appgallerykit-notifysendproduct-0000001050121556#section974973513918)。|

常见问题案例请参见本文档FAQ，如问题仍未解决，请通过[提交工单](https://developer.huawei.com/consumer/cn/support/feedback/#/)与华为技术支持联系。
