# FAQ

## 为什么AGC服务端发布了消息，在手机上没有显示？

1. 检查消息是否被过滤：消息开始时间、结束时间是否满足，触发事件的事件id是否满足，消息展示频率和次数是否满足。
2. 检查是否是测试设备：测试设备每次都会去同步AGC服务端消息，正常设备（非测试设备）每天同步一次，同步成功后，保存缓存，后续的数据都是从缓存中读取。
   * 如果是正常设备，检查消息的发布时间是否应用启动之后，如果是则为正常现象，需第2天才能展示。
   * 如果是测试设备，请联系华为技术支持。
