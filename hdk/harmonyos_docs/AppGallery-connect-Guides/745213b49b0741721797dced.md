# 导入用户

您可以通过Server端REST API将用户导入到认证服务的用户数据中。
> 说明
>
> 如果集成了此服务的API接口，则可以参考[调试API](https://developer.huawei.com/consumer/cn/doc/app/agc-help-debugg-api-0000001346861040)，使用AGC的API Explorer调试AGC的API接口。

## 前提条件

* 导入用户前需要开启用户对应的认证方式，请参见[开通服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。 说明
  >
  > 导入用户时支持的认证方式请参见[provider](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/server-rest-import-0000001136020892#ZH-CN_TOPIC_0000001136020892__p497154513243)，例如准备导入的用户数据中包含认证方式类型"手机号码"，需要开启"手机号码"的认证方式。
* 向AGC服务端发起REST API请求前，您需要先获得AGC服务端的授权，请参见[获取服务端API授权](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-obtain-apiauthorization-0000001374178549)。

## 开发步骤

1. 调用[导入用户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/server-rest-import-0000001136020892)接口，将用户信息导入到认证服务的用户数据中。
2. 导入成功后，登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，在项目列表中点击项目，在左侧导航栏选择"云开发（Serverless）> 认证服务"，进入认证服务页面。
3. 点击"用户"页签，查看默认数据处理位置导入成功的数据。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/53/v3/YjzoHF18Q3q6WHW2d5HCxA/zh-cn_image_0000002495266000.png?HW-CC-KV=V1&HW-CC-Date=20260916T034030Z&HW-CC-Expire=31536000000&HW-CC-Sign=701A5535C243497BA3EAC0E736301F4D2D0B75633C89CACB70A0F4691BFA9F8F)
