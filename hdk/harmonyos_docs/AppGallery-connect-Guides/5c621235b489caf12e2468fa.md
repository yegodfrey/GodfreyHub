# 安全规则限制

您可以通过本节了解云数据库安全规则当前存在的限制，我们后续将会尽可能减少使用云数据库安全规则的限制。  

|限制|最大值|
|:----------------------------|:-------------------------------------------------|
|单规则集大小|64kB|
|单个数据调用exists()、get()的最大次数|10|
|批量数据、事务的调用exists()、get()的最大次数|20 说明：单个数据调用exists()、get()的最大次数，同样适用于批量操作中的每个单步操作。|
|函数调用深度|20|
|函数参数的数量上限|7|
|递归或循环函数调用次数上限|0（不允许）|
|每个请求中评估的表达式数量上限|500|
