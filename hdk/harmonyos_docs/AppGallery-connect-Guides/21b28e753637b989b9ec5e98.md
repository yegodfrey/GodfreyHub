# 登出

## 前提条件

* 您需要在AGC控制台[开通认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyts-integration-0000001471227866)。

## 开发步骤

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251226181007.98232379119173480424742331056452:50001231000000:2800:9284CA819E6471DD2166DFA3C76670B339666D37DCF4B3F917E4CB4354F2AC27.png "点击放大")

当用户不再使用应用，或者需要使用其他账号登录时，需要调用[AGConnectAuth.signOut](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-agconnectauth-0000001522558177#section4122193119119)登出当前用户。用户一旦被登出，端侧的用户信息和Token将被清除。

```screen
agconnect.auth().signOut().then(() => {
                    //登出成功
                }).catch(error => {
                    //登出失败
                });
```
