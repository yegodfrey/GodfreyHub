# 查看应用性能数据

## 前提条件

* 您的应用已[启用APM服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-android-getstarted-0000001052887262#section222119255410)。
* 您的应用已[集成APM SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-android-getstarted-0000001052887262#section194247503211)和[开启APM功能](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-android-getstarted-0000001052887262#section640224332214)，并在设备上运行。
* （可选）如需查看自定义分析数据，您还需[添加自定义监控配置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-android-addcustomtrace-0000001077683336)。

## 查看概览

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择需要查看的应用。
3. 选择"质量 > 性能管理"，进入"应用性能管理"页面。
4. 点击"概览"，进入概览页面。 概览页面展示应用近30天问题和指标概览。

   指标概览包括"启动时长（按版本分布）"、"缓慢帧占比（Top5 activity）"、"冻结帧占比 （Top5 activity）"、"网络请求耗时（Top5国家/地区）"和"网络请求成功率（随时间变化）"。在概览页面，您可以快速了解应用的重要性能指标，及时识别应用是否发生问题。

## 查看ANR数据

ANR，全称为Application Not Responding，也就是应用程序无响应。如果Android应用的界面线程处于阻塞状态的时间过长，就会触发"应用无响应"(ANR) 的错误。ANR性能数据记录应用发生ANR的趋势与ANR发生时的关键信息。用于监控应用ANR发生的趋势与影响，同时采集ANR问题发生时的详细信息，帮助您快速定位解决应用ANR问题。

### 查看应用ANR报表

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目。在项目下的应用列表中选择需要查看的应用。
3. 选择"质量 > 性能管理"，进入"应用性能管理"页面。
4. 点击"ANR分析"，进入ANR分析页面。

   |指标名称|指标含义|
   |:-----|:-----------------------------------------|
   |发生次数|选定时间范围内，应用ANR问题的发生次数。|
   |影响用户数|选定时间范围内，应用ANR问题影响到的用户数。|
   |用户ANR率|选定时间范围内，应用ANR问题影响到的用户数占使用应用用户总数的比例。|
   |次数ANR率|选定时间范围内，ANR发生次数占应用启动次数的比例，即应用单次启动发生ANR的概率。|

## 查看体验分析数据

应用体验分析数据提供慢加载占比和慢呈现占比2个核心指标，帮助您衡量应用可视屏幕是否可以正常交互和完整呈现。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择需要查看的应用。
3. 选择"质量 > 性能管理"，进入"应用性能管理"页面。
4. 点击"体验分析"，进入体验分析统计页面，展示应用各屏幕的交互体验数据。

   |指标名称|指标定义|
   |:----|:-------------------------------------------------------------------------------------------------------|
   |加载时间|Home按键：Activity.onResume()结束到Activity.onRestart()开始。 Back按键：Activity.onResume()结束到Activity.onCreate()开始。|
   |慢加载|屏幕加载时间超过阈值1000ms。|
   |慢加载占比|定义：衡量屏幕交互过程是否流畅。 公式：慢加载次数/打开次数。|
   |呈现时间|Home按键：IdleHandler回调时间到Activity.onRestart()开始。 Back按键：IdleHandler回调时间到Activity.onCreate()开始。|
   |慢呈现|屏幕呈现时间超过阈值3000ms。|
   |慢呈现占比|定义：衡量屏幕内容呈现是否完整。 公式：慢呈现次数/打开次数。|

## 查看网络请求性能数据

网络请求性能数据统计应用向服务端发出网络请求与来自该服务端的响应完成这两个时间点之间的时长、请求状态码、请求负载大小以及响应负载大小。通过监控OkHttp、URLConnection、ApacheHttpClient框架发起的HTTP/HTTPS的网络请求，通过匹配URL聚合规则汇总同类网络请求的数据，帮助您了解网络请求性能的趋势，及时发现网络问题。

### 查看网络请求报表

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择需要查看的应用。
3. 选择"质量 > 性能管理"，进入"应用性能管理"页面。
4. 点击"网络分析"，进入网络请求指标统计页面。

   |指标名称|指标含义|
   |:-----|:---------------------------------------------|
   |URL|根据URL聚合规则汇总后的网络请求地址|
   |请求次数|请求地址被调用的次数|
   |请求耗时|从应用发出请求到收到服务器响应之间的时间间隔|
   |成功率|状态码为 2xx 或 3xx 的请求次数占请求总次数的百分比（用于衡量网络或服务器故障情况）|
   |请求负载大小|应用上传的网络载荷的字节数|
   |响应负载大小|应用准备下载的网络载荷的字节数|

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155810.73749412485827054430632788343582:50001231000000:2800:B7C312D3041B15D6EEFA87D3F4C6BF5AEC2308AB4E48A61062A5B026A83B235E.png)
5. 点击网络请求的"查看详情"，进入该网络请求的详情页面。网络请求详情页面包含[请求耗时](#section1875442072313)和[请求成功率](#section14464152152512)。
