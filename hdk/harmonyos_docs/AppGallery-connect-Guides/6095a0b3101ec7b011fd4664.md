# 成功案例

## 客户需求

《Call Screen》是一款主打来电皮肤定制的应用，以来电皮肤定制为核心功能。团队在更新上架一款新皮肤后，发现用户对该皮肤反响平平，使用率不高。

## 华为解决方案

借助应用内消息的能力，向应用的活跃用户发送有针对性并且符合情境的消息来吸引其点击最新上架的皮肤，并促使用户完成重要的应用皮肤的动作。借助应用内消息推送，新上架皮肤的应用率提升了11%。
