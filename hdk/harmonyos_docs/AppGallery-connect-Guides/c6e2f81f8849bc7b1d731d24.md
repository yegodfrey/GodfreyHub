# 部署模板

使用Serverless模板前，请先为您的项目部署模板。

## 前提条件

您已完成创建AGC项目和应用，具体请参见[创建项目和应用](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-serverless-maxrow_precfg-0000001270403844#section55472613292)。

## 选择模板

您需要先在Serverless模板列表中找到您需要使用的模板。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中找到您需要使用Serverless模板的项目。
3. 选择"云开发（Serverless） > Serverless模板"，点击右上角"浏览更多Serverless模板"查看并选择Serverless模板。 说明
   >
   > 每个Serverless模板详情卡片都包含该模板的部署方式和使用指南，请仔细查看后选择。

## 部署模板

选择Serverless模板后，您需要将模板部署到您的项目中。

1. 点击您选择的Serverless模板卡片上的"部署"。
2. 选择需要部署Serverless模板的项目。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174806.12081334089277782362486970897326:50001231000000:2800:D0E226BADD53D6FB48925C10C460CFA16BFEEE3F9295D117DC3EDFB98EEA8EFF.png)

3. 点击"数据处理位置"下拉框，为Serverless模板选择数据处理位置，点击"下一步"。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174806.83982921143278328304595234297008:50001231000000:2800:A5F3636D4E829AB79DDA13FC39C1A66BADFED3A7102418697BF7F1D49B340F78.png) 说明
   >
   > 当前仅支持在数据处理位置为"中国"的项目上部署Serverless模板。
4. 配置使用该Serverless模板需要的参数。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174806.71567458903283488496975287622198:50001231000000:2800:3167E24492BB697E7BDB269F76E9274520373C0D065F84962A2E2343214D1436.png)

   具体参数说明如下：

   |参数|说明|
   |:---------|:----------------------------------------------------------------------------------------------------------------|
   |云数据库的存储区名|云数据库中存储区名称。 > 说明 > 云数据库中的存储区是一个独立的数据存储区域。多个数据存储区互相独立，每个存储区都可以存储所有的对象类型，且对象类型的版本为最新版本。|
   |云数据库的对象类型名|云数据库中的对象类型。 > 说明 > Cloud DB采用基于对象模型的数据存储结构。数据以对象的形式存储在不同的存储区中，每一个对象，都是一条完整的数据记录。对象类型用于定义存储对象的集合，不同的对象类型对应的不同数据结构。|
   |云数据库的主键|主键。即在对象类型中建模的唯一ID值。|
   |云数据库的主键类型|主键的类型。 取值范围： * String * Byte * Short * Integer * Long|
   |数据记录最大值|匹配存储区和对象类型的最大保留记录个数。 如果云数据库服务中的记录总数超过此参数值，则删除超出个数的记录。 例如，假设云数据库的存储区中有100条记录。如果将此参数值配置为95，则超出的5条记录将被删除。|

5. 参数配置完成后，点击"下一步"。
6. 在部署页面，点击"开始部署"。 注意
   >
   > 如果部署多次仍失败，请在互动中心[反馈问题](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/interactive/feedback)或[在线提交工单](https://developer.huawei.com/consumer/cn/support/feedback/#/add/89?level2=9069)，华为工作人员将在1～3个工作日内进行处理。

## 配置云数据库

数据库记录数限制模板会在一键部署时自动生成模板的函数接口，模板部署成功后，您还需在"云函数"页面为对应的函数接口添加对应的CLOUDDB触发器。在配置CLOUDDB触发器前，需要配置好云数据库。

1. 创建存储区。 具体操作请参见[创建存储区](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-createfirstclouddb-0000001569588629#section176494298138)。

2. 创建对象类型。 具体操作请参见[新增对象类型](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-createfirstclouddb-0000001569588629#section1187312482820)。

## 配置云函数

数据库记录数限制模板会在一键部署时自动生成模板的函数接口，模板部署成功后，您还需在"云函数"页面为对应的函数接口添加对应的CLOUDDB触发器，以实现在云数据库发生数据变更事件后自动触发云函数。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"，在项目列表页面选择模板所在的项目。
2. 选择"云开发（Serverless） > 云函数"，在"函数列表"页面根据已部署模板的"实例ID"找到模板对应的函数，点击函数名称进入函数详情页。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174806.08101305144389334207676941300695:50001231000000:2800:625BA5C8950EB1060355D70E79D3A18B6A695D0B11203B8E7A4A6929812A1CF7.png)

3. 在函数详情页选择"触发器"页签，点击"添加触发器"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174806.04467507367970461360446831327151:50001231000000:2800:72A4C973461974CFACB72B4A275A11C4FE821AC97ED32065AF59CC56FC76BAF0.png)

4. 在弹出的"添加触发器"窗口中配置触发器相关参数。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174806.91921343425253507850398262170069:50001231000000:2800:F78814B39E18B2C9DAD2B6E78EC3D57027E0096D7482457000A924D46180858D.png)

   具体参数说明如下表所示。

   |参数|说明|
   |:----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |触发器类型|选择"云数据库触发器"。|
   |事件源|云数据库触发器的数据源。 格式为：项目ID-CloudDB存储区名称-CloudDB对象类型名称，例如"99034201568569469-StorageArea-student"。 请在事件源的后两个输入框中分别填写已创建的存储区名称和已创建的对象类型，即为[配置云数据库](#section1670618431356)中创建的存储区和对象类型。|
   |事件类型|触发器支持的事件类型。 请分别选择"onUpsert"和"onWrite"，创建2个触发器。 取值范围： * onUpsert：数据表插入或更新数据。 * onDelete：数据表删除数据。 * onDeleteAll：数据表清空。 * onWrite：数据插入或更新事件、数据删除事件、数据表清空事件。|
   |启用|标识触发器的状态。 请保持默认勾选。|

5. 配置完成后，点击"确定"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174806.76235169416970933567650127898639:50001231000000:2800:7A6F776650F207320151AFFDF24964D36B27F2DF5F0CCF8D9C1B112194536E4E.png)
