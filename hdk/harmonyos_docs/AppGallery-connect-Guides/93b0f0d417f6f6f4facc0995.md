# ReportMediaInfo

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:-----------|:----------|:-----------|:--------------------------------------------------------|
|mediaPkgName|O|String|媒体包名。 > 注意 > **mediaPkgName** 和**slotIds**字段中必须有一个字段必须填值。|
|slotIds|O|List<String>|展示位ID。 一个媒体包名最大支持传100个展示位ID。|
