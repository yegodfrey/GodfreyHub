# 使用限制

由于此Serverless模板包含多个Serverless服务的配置，所以此模板在API、资源、配额、代码等方面的限制取决于模板中包含的服务类型，本章节将为您详细介绍模板可能涉及的使用限制。这些限制可能会根据实际情况随时更新，请您注意文档变化。

|依赖的服务|限制|
|:----|:-----------------------------------------------------------------------------------------------------------------------------------------------|
|认证|请参考[认证服务的使用限制](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-auth-restrict-0000001053254031)|
|云存储|请参考[云存储的使用限制](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-cloudstorage-restrictions-0000001093263535)|
|云数据库|请参考[云数据库的使用限制](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-clouddb-restrictions-0000001127557973)|
|云函数|请参考[云函数的使用限制](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloud-function-restriction-0000001058641770)|
