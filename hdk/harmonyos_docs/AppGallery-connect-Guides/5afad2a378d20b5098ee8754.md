# 调用函数

#### 查询触发器标识

当您在创建的函数或函数别名中创建了一个HTTP类型的触发器后，在应用客户端调用函数时需要传入HTTP触发器的标识，查询方法如下：

在函数的触发器页面点击"HTTP触发器"，查看"触发URL"的后缀，获取触发器的标识，格式为"函数名-版本号"。如下图所示，"myhandlerxxxx-$latest"即为HTTP触发器标识。

#### 调用函数

应用集成了云函数SDK后，可以在应用内直接通过SDK API调用AGC中的云函数，云函数SDK与AGC的函数调用基于HTTPS的安全访问。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250425160209.12572653243477029927644210108354:50001231000000:2800:C85188E07A3E00EC7D36949B96B81BE14BABF6CF7734C34ADCB71774B6258ADA.png)

1. 在调用函数前，需要调用[getInstance](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcfunction-0000001058418821#section17884171291718)方法初始化[AGCFunction](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcfunction-0000001058418821)实例。

   ```
   var agConnectConfig = {
       //应用配置信息
   }
   //初始化agc
   agconnect.instance().configInstance(agConnectConfig);
   ```

2. 调用[wrap](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcfunction-0000001058418821#section10379123816445)方法设置函数，在方法中传入触发器标识。

<!-- -->

3. 根据函数入参情况，调用相关方法来调用函数。
   * 如果函数没有入参，可以调用[call](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcfunctioncallable-0000001058298815#section4123123918494)方法来调用函数。

     ```
     [[function wrap:@"myhandlerxxxx-$latest"] call];
     ```

   * 如果函数有入参，可以调用[callWithObject:](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcfunctioncallable-0000001058298815#section488155612616) 方法来调用函数，多个入参添加到object对象中。

     其中HTTP触发器传递给函数的数据格式，请参见[event对象说明](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudfunction-trigger-event-0000001620581529#section12463185072710)。

     ```
     [[function wrap:@"myhandlerxxxx-$latest"] callWithObject:param];
     ```

4. 如果您需要关注函数的返回值，可以在接口返回的HMFTask中设置一个addOnCompleteCallback回调监听，在回调方法中获取包含函数执行结果的[AGCFunctionResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcfunctionresult-0000001058947256)对象，调用[value](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcfunctionresult-0000001058947256#section09861710201518)方法可以获取函数执行后的返回值或返回对象。

   ```
   - (void)getWeek:(NSString *)date {
       AGCFunction *function = [AGCFunction getInstance];
       NSDictionary *param = @{@"time":date};
       [[[function wrap:@"myhandlerxxxx-$latest"] callWithObject:param] addOnCompleteCallback:^(HMFTask<AGCFunctionResult *> * _Nonnull task) {
           if (task.isSuccessful) {
               NSString *value = task.result.value;
           }else {
               NSError *error = task.error;
           }
       }];
   }
   ```
