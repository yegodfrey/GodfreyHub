# 注销监听下载任务

#### 接口描述

注销监听下载任务信息。与注册监听是对应的关系。  

#### 输入参数

无  

#### 返回参数

无  

#### 示例代码

```
UnregisterDownloadCallbackIPCRequest unregisterDownloadCallbackIPCRequest =
    new UnregisterDownloadCallbackIPCRequest();
unregisterDownloadCallbackIPCRequest.setPackageName(pkg);
unregisterDownloadCallbackIPCRequest.setCallback(downloadCallback);
AgdApi.unregisterDownloadCallback(client, unregisterDownloadCallbackIPCRequest)
   .setResultCallback(new ResultCallback<TaskOperationResponse>() {
        @Override
        public void onResult(Status<TaskOperationResponse> result) {
            Log.i(TAG, " onResult:" + result.getStatusCode());
       }
   });
```
