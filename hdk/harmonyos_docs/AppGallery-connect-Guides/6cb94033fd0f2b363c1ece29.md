# 登录验签专题

## 调用登录验签接口返回HTTP 404状态码，如何处理？

1. 登录验签要求使用post表单提交方式，检查post参数格式是否提交准确。
2. 检查登录验签中的method参数是否填写准确（必须为external.hms.gs.checkPlayerSign）。

## 登录验签返回3001，errMsg为：param [ts:1589849750174] should between [1589850612410,1589851212410]？

客户端通过getCurrentPlayer接口获取的验签参数是具有时效性的，超过5分钟内没有发送验签请求，会返回该错误。

以标题示例的时间点，说明报错信息中的三个时间戳含义。

|时间点|转换后的时间点|含义|
|:------------|:----------------|:-------------------------------------------|
|1589849750174|2020/5/19 8:55:50|这个时间点是验签请求中的ts，即getCurrentPlayer接口返回的原始ts时间。|
|1589850612410|2020/5/19 9:10:12|这个时间点是发送请求时的时间往前推算5分钟的时间点。|
|1589851212410|2020/5/19 9:20:12|这个时间点是发送请求时的时间往后推算5分钟的时间点。|
|举个例子：应用客户端9:00整获取到原始时间，然后9:06分才发送登录验签请求，此时9:06往前后各5分钟的时间段是【9:01-9:11】，原始9:00不在该范围内，就失效了。|||

## 登录验签返回-1，无errMsg？

可能原因是cpid填写错误，请检查cpid准确性。

## 登录验签返回-1，errMsg为check playerSSign fail？

请检查以下参数。

|参数|典型原因|
|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|appid和cpid|客户端登录成功回调数据时使用的appid和cpid和验签时传的appid、cpid不一致导致验签失败。 典型错误：客户端项目使用的agconnect-services.json文件中的appid和cpid错误。建议您参考[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/integrate-as-sdk-0000001050435953)重新下载对应游戏项目的json文件。|
|playerSSign|playerSSign获取错误或者应用客户端传输至开发者服务器过程中发生转义。|
|ts|验签时使用的ts不是客户端登录成功后华为服务器返回的原始ts，典型错误如验签时使用了当前服务器的本地时间。|

## 登录验签返回-1，errMsg为check cpSign fail？

检查生成的cpSign是否准确，可能原因如下。

|可能错误|具体原因|
|:-----------|:--------------------------------------------------------------------------------------|
|cpSign参数计算错误|* 游戏私钥错误 * 加密算法错误 * 加密时的原始数据错误|
|cpId错误|cpId的值为1时，会返回rtnCode为-1，errMsg为check cpSign fail。cpId的值为其他错误值时，直接返回rtnCode为-1，没有errMsg。|
