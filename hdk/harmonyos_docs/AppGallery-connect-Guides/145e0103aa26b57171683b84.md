# 上传文件

通过云存储SDK，您可以快速上传本地设备上的文件到云端，同时可以对上传任务进行管理，如暂停、继续、取消上传任务，监控上传进度，任务异常中断后进行断点续传等。

## 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[初始化存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-initialize-bucket-ios-0000001333893477)。

## 上传本地文件

您可以通过引用操作本地设备上的文件，将文件上传到云端的存储实例中。

1. 调用[[AGCStorage referenceWithPath:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstorage-0000001172981557#section9635163510919)方法创建待上传文件的引用，将本地文件上传到预先规划的云端地址中。

   ```screen
   "Objective-C"
   //storage为已经初始化的AGCStorage实例
   AGCStorageReference *reference = [storage referenceWithPath:@"images/demo.jpg"];
   ```

   ```screen
   "Swift"
   //storage为已经初始化的AGCStorage实例
   let reference = storage.reference(withPath:"images/demo.jpg")
   ```

   > 说明
   > * 上传文件或创建目录时，会对名称和文件大小进行严格的检查，具体限制请参见[使用限制](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-restrictions-0000001093263535)。
   > * 如需支持断点续传，上传文件应携带SHA256值，且最大为50GB，云存储SDK会按照分片上传的方式将文件上传至服务器，直到文件全部上传完毕。若上传任务异常中断，云存储SDK会根据设置的最大重试次数从断点续传位置进行重试上传。
   > * 如无需支持断点续传，上传文件可不携带SHA256值，且最大为5GB，云存储SDK会按照单次上传的方式将文件上传至服务器。若上传任务异常中断，请重新尝试上传。
2. 调用[[AGCStorageReference uploadFile:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragereference-0000001126781968#section12531528113917)方法将文件上传到存储实例中。 说明
   >
   > 上传文件前支持您设置文件的自定义属性，具体请参见[设置元数据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-metadata-ios-0000001172981229#section4918191475516)。

   ```screen
   "Objective-C"
   AGCStorageUploadTask *task = [reference uploadFile:fileUrl];
   [[task addOnFailureCallback:^(NSError *error){
   }] addOnSuccessCallback:^(AGCStorageUploadResult *result){
   }];
   ```

   ```screen
   "Swift"
   let task = reference.uploadFile(fileUrl)
   task.onSuccess{(result) in 
   }
   .onFailure{(error) in
   }
   ```

   如果您需要在上传文件时为文件指定自定义属性，可以使用[[AGCStorageReference uploadFile:metadata:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragereference-0000001126781968#section1817391015397)方法。

   如果您需要在上传文件时支持断点续传，可以使用[[AGCStorageReference uploadFile:metadata:offset:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragereference-0000001126781968#section1350525923718)方法，offset设为0。若任务异常中断，您可以再次调用该方法恢复任务，从中断的位置开始上传，offset的值通过[[AGCStorageUploadResult bytesTransferred]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstorageuploadresult-0000001126941790#ZH-CN_TOPIC_0000001126941790__p11411173873313)方法获取。
3. 使用uploadFile:方法上传文件后，会返回[AGCStorageUploadTask](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstorageuploadtask-0000001126781970)实例，您可以通过监听AGCStorageUploadTask的状态了解上传任务的相关状态。
   * 文件上传过程中如需对任务进行操作，请参见[切换上传任务的状态](#section864919101209)。
   * 文件上传任务执行的进度监控，请参见[监控上传任务的进度](#section1081983715343)。
   * 使用断点续传时需要继续未完成上传任务，请参见[异常情况下继续未完成的上传任务](#section09357511198)。

## 切换上传任务的状态

文件在正常上传过程中，可通过调用[AGCStorageTask](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragetask-0000001126941788)类的[pause](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragetask-0000001126941788#section51031754194515)、[resume](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragetask-0000001126941788#section9240586453)、[cancel](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragetask-0000001126941788#section118931831144413)方法切换上传任务的状态。

* pause：暂停一个处于上传过程中的上传任务。
* resume：唤醒一个处于暂停状态的上传任务。
* cancel：取消一个上传任务。

```screen
"Objective-C"
AGCStorageReference *reference = [storage referenceWithPath:@"images/demo.jpg"];
AGCStorageUploadTask *task = [reference uploadFile:fileUrl];
[task pause];
[task resume];
[task cancel];
```

```screen
"Swift"
let reference = storage.reference(withPath:"images/demo.jpg")
let task = reference.uploadFile(fileUrl)
task.pause()
task.resume()
task.cancel()
```

## 监控上传任务的进度

文件在上传时，可通过调用[AGCStorageTask](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragetask-0000001126941788)类的[addOnProgressCallback:](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragetask-0000001126941788#section1882115711353)、[addOnPausedCallback:](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragetask-0000001126941788#section1612010132815)、[addOnSuccessCallback:](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragetask-0000001126941788#section04161846132311)、[addOnFailureCallback:](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragetask-0000001126941788#section1310411516227)、[addOnCanceledCallback:](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragetask-0000001126941788#section193211347184017)、[addOnCompleteCallback:](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragetask-0000001126941788#section1824418011813)方法，添加AGCStorageUploadTask的回调来监控上传任务中的状态切换。

* addOnProgressCallback：当上传任务中需要定期刷新任务进度时调用此回调。
* addOnPausedCallback：当任务暂停时调用此回调。
* addOnSuccessCallback：当任务成功时调用此回调。
* addOnFailureCallback：当任务失败时调用此回调。
* addOnCanceledCallback：当任务取消时调用此回调。
* addOnCompleteCallback：当任务完成时调用此回调。

```screen
"Objective-C"
AGCStorageReference *reference = [storage referenceWithPath:@"images/demo.jpg"];
AGCStorageUploadTask *task = [reference uploadFile:fileUrl];
[[[[[[task addOnFailureCallback:^(NSError *error){
}] addOnSuccessCallback:^(AGCStorageUploadResult *result){
}] addOnProgressCallback:^(AGCStorageUploadResult *result){
}] addOnPausedCallback:^(AGCStorageUploadResult *result){
}] addOnCanceledCallback:^{
}] addOnCompleteCallback:^(AGCStorageTask<AGCStorageUploadResult *> *task){
}];
```

```screen
"Swift"
let reference = storage.reference(withPath:"images/demo.jpg")
let task = reference.uploadFile(fileUrl)
task.onSuccess{(result) in 
}.onFailure{(error) in
}.onProgress{(result) in 
}.onPaused{(result) in 
}.onCanceled{(result) in 
}.onComplete{(task) in 
}
```

## 异常情况下继续未完成的上传任务

上传任务在执行的过程中，可能会因为使用方式、网络环境等原因产生的[AGCStorageError](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstorageerror-0000001126941792)异常导致上传任务中断，通过断点续传接口[[AGCStorageReference uploadFile:metadata:offset:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragereference-0000001126781968#section1350525923718)，可以继续未完成的上传任务，提升用户的使用体验。
> 说明
>
> * 上传任务的会话会保存一周，您可以尝试恢复此任务，当会话超期或发生异常时，恢复会失败。
> * 在会话的有效期内，临时文件会占用一定的存储空间，该存储空间会体现在存储使用量内。

```screen
"Objective-C"
AGCStorageMetadata *attribute = [AGCStorageMetadata new];
attribute.contentType = @"image/jpeg";
attribute.sha256Hash = @"0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef";
AGCStorageReference *reference = [storage referenceWithPath:@"images/demo.jpg"];
AGCStorageUploadTask *task = [reference uploadFile:fileUrl metadata:attribute offset:100];
```

```screen
"Swift"
let attribute = AGCStorageMetadata()
attribute.contentType = "image/jpeg"
attribute.sha256Hash = "0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef"
let reference = storage.reference(withPath:"images/demo.jpg")
let task = reference.uploadFile(fileUrl,attribute,100)
```

## 更多信息

* 如您在上传文件前未设置文件的自定义属性，可在文件成功上传后进行[设置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-metadata-ios-0000001172981229#section4918191475516)。
* 文件成功上传到云端后，您可以通过云存储SDK[下载文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-download-ios-0000001126781636)。
* 您可以通过云存储SDK的API[列举云端某个目录下的所有文件或子目录](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-list-ios-0000001126941452)。
* 当您不再需要云端的文件时，可以调用云存储SDK的API在应用客户端[删除文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-delete-ios-0000001172821309)。
* 除了在应用客户端通过云存储SDK的API来上传文件，您还可以直接[在AGC控制台以可视化的方式来上传文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-manage-file-0000001281134398#section6704135012516)。
