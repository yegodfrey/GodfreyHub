# 转让房主身份

如果房主想让出房主权限，可将房主身份转让给房间中的其他玩家。  

#### 前提条件

* 您已[加入小队语音](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-joinroom-roomid-android-0000001268934473#section644913141332)或[国战语音房间](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-joinroom-roomid-android-0000001268934473#section429414312194)。
* 您为房主身份，且房间中已有其他玩家。  

#### 开发步骤

1. 调用[GameMediaEngine.transferOwner](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section1141347163017)方法可直接转让房主身份给房间中的其他玩家。

   ```
   // 原房主无需离开房间，转让房主给其他玩家
   mHwRtcEngine.transferOwner(roomId, ownerId);
   ```

2. 当玩家转让房主身份时，可在IGameMMEEventHandler接口的[onTransferOwner](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section9402131065312)方法中实现相关回调处理。

   ```
   @Override
   public void onTransferOwner(String roomId, int code, String msg) {
       LogUtil.i(TAG, "onTransferOwner: " + "roomId:" + roomId + "code:" + code + "msg:" + msg);
       // 可根据需求将数据进行处理
   }
   ```
