# 配置前准备

#### 创建项目与应用

项目是您在AppGallery Connect资源的组织实体，您可以将一个应用的不同平台版本添加到同一个项目中。当您的应用需要使用AGC服务时，您可以[创建您的项目](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createproject-0000001100334664)和[创建您的应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createapp-0000001146718717)。  

#### 开通云函数服务

首次使用云函数服务前，需要先开通此服务。如果您已经开通，可跳过本步骤。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击需要开通云函数的项目。

3. 在左侧导航栏选择"云开发（Serverless）\> 云函数"，进入云函数页面，在右上角点击"立即开通"。 ![](https://media:801773804276978287)

   ![](https://media:801773804277004288)  
   如果您此时未设置数据处理位置，系统会自动弹出提示框提示您进行设置。目前，云函数支持启用多个数据处理位置，具体请参见[设置数据处理位置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-data-storage-location-0000001162597847#section154810363471)。
4. 如果您已启用多个数据处理位置，当您需要在不同的数据处理位置管理云函数时，可在云函数页面选择"数据处理位置"下拉选项进行切换。 ![](https://media:801773804277055289)

#### 开通云数据库服务

若您使用云数据库调用云函数，在创建云数据库触发器之前，需要先开通云数据库服务。如果您已经开通，可跳过本步骤。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，选择"开发与服务"。
2. 在项目列表中选择需要开通云数据库服务的项目。
3. 在左侧导航栏选择"云开发（Serverless）\> 云数据库"，进入云数据库页面，点击"立即开通"。

   ![](https://media:801773804277100290)

   服务初始化成功后，即开通云数据库服务成功。
4. 服务开通后，创建[存储区](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-createfirstclouddb-0000001569588629#section176494298138)和[对象类型](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-createfirstclouddb-0000001569588629#section1187312482820)。  

#### 开通认证服务

若您使用认证服务调用云函数，在创建认证服务触发器之前，需要先开通认证服务。如果您已经开通，可跳过本步骤。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中选择需要开通认证服务的项目。
3. 选择"云开发（Serverless）\> 认证服务"，进入认证服务的页面。如果首次使用认证服务，请点击"立即开通"开通服务。 ![](https://media:801773804277156291)

#### 开通云存储服务

若您使用云存储服务调用云函数，在创建云存储触发器之前，需要先开通云存储服务。如果您已经开通，可跳过本步骤。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中选择需要开通云存储服务的项目。
3. 选择"云开发（Serverless）\> 云存储"，进入云存储页面，点击"立即开通"。 ![](https://media:801773804277197292)

4. 在引导界面输入存储实例名称并设置默认数据处理位置。

   ![](https://media:801773804277235293)  

   |参数|说明|
   |:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |存储实例|存储实例名称必须符合以下条件： * 只能包含英文小写字母、数字、"-" * 只能以数字或字母开头。 * 要求不小于3个字符，并且不能超过57个字符。 * 不能是IP地址。 * 名称不能以"-"结尾。 * 名称全局唯一，创建后，不能修改。|
   |默认数据处理位置|云存储支持启用多个数据处理位置，具体请参见[设置数据处理位置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-data-storage-location-0000001162597847#section154810363471)。如当前项目已设置数据处理位置，则此处无需再设置。|

5. 点击"下一步"，进入默认安全策略展示界面。 ![](https://media:801773804277264294)

   ![](https://media:801773804277293295)  
   默认安全策略将允许经过身份验证的用户执行所有读写操作，开通服务时无法修改安全策略。服务开通后，您可制定更合适的安全策略来保护您的用户数据。关于如何修改安全策略，请参见[安全规则](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-securityrules-overview-0000001054966859)。
6. 点击"完成"，开通云存储成功。 服务开通成功后，AGC将为您创建一个默认存储实例，默认存储实例的名称即为步骤[4](#ZH-CN_TOPIC_0000001712008649__li191317012303)中配置的存储实例名称加-五位随机数字字母的组合，如"bucket001-ki6tc"

#### 开通远程配置服务

若您使用远程配置服务调用云函数，在创建远程配置触发器之前，需要先开通远程配置服务。如果您已经开通，可跳过本步骤。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到需要开通远程配置的项目。
3. 在左侧导航栏选择"增长 \> 远程配置"。如果首次使用远程配置服务，请点击右侧"开通"开通服务。 ![](https://media:801773804277346296)
