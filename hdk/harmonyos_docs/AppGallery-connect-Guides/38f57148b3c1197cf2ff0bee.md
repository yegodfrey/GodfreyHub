# 定制指导

1. 点击下载包含Lite版本SDK源码的Demo工程：[huawei-paidapps-client-android-java-demo](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250425140403.40631572350036414579870476173223:50001231000000:2800:D1BBCEF737BA4D0D00392E8E5163F0048EC188F7BA17EAA47F4864BA20462541.zip)。
2. 解压Demo工程后，DrmSDK目录即为Lite版本SDK源码。  

   |源文件|包含的功能|
   |:-----------------------|:----------------------------------------|
   |DeviceSession|DeviceSession相关类。|
   |NetUtils|网络相关的辅助类。|
   |ReportUtils|上报日志类。|
   |SharedPreferencesWrapper|缓存包装类。|
   |Constants.java|公共常量定义类。|
   |DialogObserver|弹框观察者类。|
   |DialogTrigger|弹框触发器类。|
   |Drm|Drm对外接口类。|
   |DrmCheckCallback|Drm鉴权结果回调类。|
   |DrmDialogActivity|弹出对话框和处理拉起Activity相关类。|
   |DrmKernel|Drm主处理类。|
   |DrmResource|相关资源获取类。|
   |DrmStatusCodes|鉴权状态码定义类。|
   |EMUISupportUtil|EMUI辅助类。|
   |ViewHelper|View辅助类。|
   |Icallback|回调AIDL生成代码。|
   |IDrmSignService|AppGallery DRM Service SDK和应用市场通信的AIDL代码。|

3. 您可根据业务需求修改源码进行定制，以下列出几个可能的修改点（仅供参考）：
   * DrmKernel.verify：DrmKernel类提供的verify验签接口，例如您可修改此处的验签算法。
   * DrmKernel.handleResultSuccess ：DrmKernel类提供的handleResultSuccess接口，用于验签成功后的处理，例如您可修改验签的有效期。
4. 将修改后的Lite版本SDK集成到您的工程文件中。
