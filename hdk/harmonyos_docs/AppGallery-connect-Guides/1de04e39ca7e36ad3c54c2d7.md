# 调用官方连接器

请根据实际业务需要，选择合适的方式调用官方连接器：

* [通过Cloud Foundation Kit接口调用连接器](#section5422152612119)：可使用Cloud Foundation Kit提供的call方法调用官方连接器。
* [通过云函数Server Java SDK调用连接器](#section137111219232)：可在应用中集成Server Java SDK，使用SDK提供的wrap方法调用官方连接器。
* [通过云函数Server Node.js SDK调用连接器](#section6614101714504)：可在应用中集成Server Node.js SDK，使用SDK提供的call方法调用官方连接器。

## 通过Cloud Foundation Kit接口调用连接器

1. 在项目中导入cloudFunction组件。

   ```screen
   import { cloudFunction } from '@kit.CloudFoundationKit';
   ```

2. 调用[call()](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/cloudfoundation-cloudfunction#call)方法，传入函数名称、连接器名称等信息，返回调用结果。
   * name：函数名称，固定为"common-connector-execution"。
   * data.connectorName：连接器名称，本例为"test_002"。
   * data.apiName：连接器方法名称。
   * data.params.{paramName}：连接器方法入参。

   ```screen
   try {
       let res: cloudFunction.FunctionResult = await cloudFunction.call({
         name: "common-connector-execution", // 函数名称，固定为"common-connector-execution"
         data: {
           connectorName: "test_002", // 连接器名称，本例为test_002
           apiName: "***", // 连接器方法名称
           params:  { // 填充连接器方法的入参和取值
             "paramName1": "value1",   
             "paramName2": "value2",
             "paramName3": "value3",
             "paramName4": "value4"
           }
         }
       })
       // 处理JSON形式的返回体
      hilog.info(0x0000, 'testTag', `Succeeded in calling the function, result: ${JSON.stringify(res.result)}`);
     } catch (err) {
       if (err) {
         hilog.error(0x0000, 'testTag', `Failed to call the function, code: ${err.code}, message: ${err.message}`);
         return;
       }
     }
   })
   ```

## 通过云函数Server Java SDK调用连接器

1. 参考[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/integrate-sdk-server-java-0000001300655858)集成和初始化云函数Server Java SDK。
2. 使用[wrap()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcfunction-java-0000001193153224#section145475292453)方法调用官方连接器。

   ```screen
   package com.huawei.appgallery.connect.lcs;

   import com.huawei.agconnect.server.commons.AGCClient;
   import com.huawei.agconnect.server.commons.AGCParameter;
   import com.huawei.agconnect.server.commons.credential.CredentialParser;
   import com.huawei.agconnect.server.commons.credential.CredentialService;
   import com.huawei.agconnect.server.commons.exception.AGCException;
   import com.huawei.agconnect.server.function.AGCFunction;
   import com.huawei.agconnect.server.function.FunctionCallable;
   import com.alibaba.fastjson2.JSONObject;

   public class ScasInvoke {
       public static void main(String[] args) throws AGCException {
           CredentialService credential = CredentialParser.toCredentialWithContents("凭据信息");
           AGCParameter agcParameter = AGCParameter.builder().setCredential(credential).build();
           AGCClient.initialize(agcParameter);


           // 构造云函数对象实例
           AGCFunction function = AGCFunction.getInstance();
           FunctionCallable callable = function.wrap("common-connector-server", "$latest"); // 函数名称，固定为"common-connector-server"

           // 拼接参数
           JSONObject params = new JSONObject();
           // 填充连接器方法的入参和取值
           params.put("paramName1", "value1");
           params.put("paramName2", "value2");
           params.put("paramName3", "value3");
           params.put("paramName4", "value4");

           JSONObject request = new JSONObject();
           request.put("connectorName", "test23"); // 连接器名称，本例为test23
           request.put("apiName", "***"); // 连接器方法名称
           request.put("params", params);
           String res = callable.call(request).getValue();
           System.out.println(res);
       }
   }
   ```

## 通过云函数Server Node.js SDK调用连接器

1. 参考[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/from-cloudfunction-access-0000001935200861)集成和初始化云函数Server Node.js SDK。
2. 使用[call()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/cloudfunction-nodejs-0000001733038596#section2026765062216)方法调用官方连接器。

   ```screen
   import { cloud } from "@hw-agconnect/cloud-server";

   let path = "凭据路径"; // 替换为实际的认证凭据文件路径
   const cloudInstance = cloud.createInstance(path, "test");

   async function invokeTextCheckConnector() {
     const check = await cloudInstance.function()
       .call({
         name: "common-connector-server", // 函数名称，固定为"common-connector-server"
         data: {
           connectorName: "test", // 连接器名称
           apiName: "***", // 连接器方法名称
           params:  { // 在此处填充连接器方法的入参和取值
             "paramName1": "value1",
             "paramName2": "value2",
             "paramName3": "value3",
             "paramName4": "value4"
           }
         }
       });

     return check;
   }
   ```
