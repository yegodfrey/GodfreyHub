# 使用云数据库

#### 获取云数据库实例

在使用云数据库服务前，您需要初始化云数据库实例。

1. 在您项目的根目录下新建"clouddb.js"文件用于云数据库开发，引入Server SDK依赖，获取Cloud实例。
2. 调用[database(config:DatabaseConfig)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-cloud-server-nodejs-0000001781158433#section490mcpsimp)方法获取CloudDB实例。设置云侧存储区名称"QuickStartDemo"，打开存储区实例。
3. 调用[collection()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddb-server-nodejs-0000001734039358#section400mcpsimp)方法获取CloudDBCollection实例。有以下两种方式：
   * [引用本地对象类型文件BookInfo.js](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-setclouddb-server-nodejs-0000001983440360#ZH-CN_TOPIC_0000001983440360__li56201919113014)中的类BookInfo。（[写入数据](#section6840134912569)以此方式为例）
   * 无需创建对象类型文件，直接设置泛化对象类型名"BookInfo"。（[更新数据](#section129176612574)、[查询数据](#section18585148119)、[删除数据](#section62521414918)等其他操作以此方式为例）

代码如下：

```
"具体对象"
import { cloud } from "@hw-agconnect/cloud-server";//引入Server SDK依赖
import { BookInfo } from "xx/BookInfo.js";//xx为BookInfo对象类型文件的地址

const collection = cloud.database({ zoneName: "QuickStartDemo" }).collection(BookInfo);
```

```
"泛化对象"
import { cloud } from "@hw-agconnect/cloud-server";

const collection = cloud.database({ zoneName: "QuickStartDemo" }).collection("BookInfo");
```

#### 创建泛化对象

云数据支持泛化对象的能力，您可以直接创建泛化对象进行数据操作，无需依赖对象类型文件。当云侧数据库的对象类型结构发生变化时，您可以修改泛化对象中的对象类型结构，从而实现基于泛化对象的数据操作，提高用户操作的灵活性。

您可以通过[CloudDBZoneGenericObject](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonegenericobject-server-nodejs-0000001766691625)类来配置泛化对象，泛化对象支持对云侧数据库进行[更新数据](#section129176612574)、[查询数据](#section18585148119)、[删除数据](#section62521414918)等操作。

注意事项：

* 添加泛化对象时，对象类型和字段名需要遵循创建时的约束，请参考[修改对象类型](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-agcconsole-objecttypes-0000001127675459#section3873193085413)。
* 不支持将主键字段、加密字段和敏感字段添加到泛化对象中。
* 泛化对象查询数据时，将按照以下规则返回结果。
  * 数据类型为Date的字段返回String类型的UTC时间，时间格式为YYYY-MM-DD HH:mm:ss SSS；
  * 数据类型为ByteArray的字段返回Base64编码的字符串；
  * 数据类型为Long、Float、Double和LongAutoIncrement的字段返回字符串。

配置泛化对象：

1. 调用[build()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonegenericobject-server-nodejs-0000001766691625#section296564433319)方法创建一个CloudDBZoneGenericObject对象，并输入对应的对象类型名称。

   ```
   import { CloudDBZoneGenericObject } from '@hw-agconnect/cloud-server';

   const bookInfo = CloudDBZoneGenericObject.build("BookInfo");
   ```

2. 调用[addFieldValue()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonegenericobject-server-nodejs-0000001766691625#section1120616413163)方法为泛化对象添加字段和对应的值。

   ```
   bookInfo.addFieldValue('id', 1, true);
   ```

#### 写入数据

您可以通过[upsert()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section207736215304)或[insert()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section1956722220213)将一个或者一组对象写入到当前存储区中。在写入数据时，调用upsert()方法允许多端对相同主键写入数据，且写入均会成功，即支持数据的新增或者更新；调用insert()方法写入相同主键数据时，只有当该条数据不存在时才会插入成功，即仅支持数据的新增。写入的数据可以来自于新建对象，或者从云侧数据库中查询出来的对象。

* 在使用upsert()写入对象时，如果在存储区中已经存在主键值相同的对象，则更新已有的对象；如果不存在，则写入一个新的对象。
* 在使用insert()写入对象时，如果在存储区已经存在主键值相同的对象，则写入失败；若不存在，则写入一个新的对象。

注意事项：

* 写入一组对象时，数据的写入操作是原子的，即对象列表中的对象要么全部成功写入，要么全部失败。
* 写入一组对象时，该组中的对象必须属于同一个对象类型，否则会导致写入失败。
* 进行写入操作时，系统会忽略加密字段和敏感字段的数据。

代码示例：

* 使用upsert()方法将BookInfo对象写入至存储区中，写入成功后，返回写入的数量；写入失败，捕获异常信息。

  ```
  import { cloud } from "@hw-agconnect/cloud-server";
  import { BookInfo } from "xx/BookInfo";//xx为BookInfo对象类型文件的地址

  const collection = cloud.database({ zoneName: "QuickStartDemo" }).collection(BookInfo);
  try {
    const upsertNum = collection.upsert([
      {
        id: 1,
        bookName: "no_war",
        author: "unknown",
        price: 44,
        publisher: "unknown",
        publishTime: new Date("1997-07-26T03:24:00"),
        shadowFlag: true,
      },
      {
        id: 2,
        bookName: "peace_life",
        author: "unknown",
        price: 20,
        publisher: "unknown",
        publishTime: new Date("1997-07-26T03:24:00"),
        shadowFlag: true,
      },
    ]);

    console.log("upsertBookInfos=>", upsertNum);
  } catch (err) {
    console.error(err);
  }
  ```

#### 更新数据

您可以通过[update()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section1881840185010)、[batchUpdate()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section20931138154917)或者[batchUpdateByCondition()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section037353591218)方法更新数据，并使用[increment()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzoneobjectoperator-server-nodejs-0000001718772382#section7617134411476)和[update()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzoneobjectoperator-server-nodejs-0000001718772382#section289310261498)方法定义更新对象。更新数据时，需遵循以下约束：

* 通过[update()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section1881840185010)更新一个对象中一个或者多个字段的值。在更新对象时，仅支持根据指定主键更新一个或者多个字段的值，如果更新成功，返回"1"，否则返回"0"或异常信息。
* 通过[batchUpdate()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section20931138154917)或者[batchUpdateByCondition()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section037353591218)更新满足指定条件的一个或者多个字段的值。在更新数据时，需通过[CloudDBZoneObjectOperatorConstraint](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-objectoperatorconstraint-server-nodejs-0000001718931842)类构造约束条件，如果满足更新的约束条件，操作成功，返回具体更新条数；如果不满足更新的约束条件时，返回"0"。未构造约束条件时，则更新整个对象类型的所有数据。

注意事项：

* 进行更新操作时，需要保证更新后该对象的数据大小不能超过2MB，否则会导致该对象查询失败。
* 不支持对主键字段、加密字段和敏感字段的值进行更新操作。
* 同一个[update()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section1881840185010)、[batchUpdate()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section20931138154917)或者[batchUpdateByCondition()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section037353591218)操作中，[increment()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzoneobjectoperator-server-nodejs-0000001718772382#section7617134411476)和[update()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzoneobjectoperator-server-nodejs-0000001718772382#section289310261498)方法不能操作同一个字段，否则会抛出错误。
* 使用[update()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section1881840185010)进行[increment()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzoneobjectoperator-server-nodejs-0000001718772382#section7617134411476)时，支持Byte、Short、Integer、Long、Float和Double这6种数据类型。除Long类型同时支持number和string类型外，其他数值类型只支持number类型。
* 使用[batchUpdate()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section20931138154917)或者[batchUpdateByCondition()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section037353591218)进行[increment()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzoneobjectoperator-server-nodejs-0000001718772382#section7617134411476)时，支持Short、Integer、Long、Float和Double这5种数据类型。除Long类型同时支持number和string类型外，其他数值类型只支持number类型。  

#### 根据对象更新数据

* 使用update进行更新数据时，调用increment将主键id为"1"的BookInfo对象中"price"的值增加"38.8"。如果更新成功，返回"1"，否则返回"0"或异常信息。

  ```
  import { cloud, CloudDBZoneGenericObject, CloudDBZoneObjectOperator } from '@hw-agconnect/cloud-server';

  const collection = cloud.database({ zoneName: "QuickStartDemo" }).collection("BookInfo");
  const bookInfo = CloudDBZoneGenericObject.build("BookInfo");
  bookInfo.addFieldValue("id", 1, true);

  try {
    const operator = CloudDBZoneObjectOperator.build(bookInfo).increment(
      "price",
      38.8
    );
    const updateNum = await collection.update(operator);
    console.log("updateNum=>", updateNum);
  } catch (error) {
    console.warn("updateBookInfos=>", error);
  }
  ```

* 使用update进行更新数据时，调用update将主键id为1的BookInfo对象中"publisher"更新为"xxx"。如果更新成功，返回"1"，否则返回"0"或异常信息。

  ```
  import { cloud, CloudDBZoneGenericObject, CloudDBZoneObjectOperator } from '@hw-agconnect/cloud-server';

  const collection = cloud.database({ zoneName: "QuickStartDemo" }).collection("BookInfo");
  const bookInfo = CloudDBZoneGenericObject.build("BookInfo");
  bookInfo.addFieldValue("id", 1, true);

  try {
    const operator = CloudDBZoneObjectOperator.build(bookInfo).update(
      "publisher",
      "xxx"
    );
    const updateNum = await collection.update(operator);
    console.log("updateNum=>", updateNum);
  } catch (error) {
    console.warn("updateBookInfos=>", error);
  }
  ```

#### 根据条件更新数据

* 通过[batchUpdate()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section20931138154917)或者[batchUpdateByCondition()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section037353591218)方法根据条件更新数据时，调用[increment()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzoneobjectoperator-server-nodejs-0000001718772382#section7617134411476)方法将BookInfo对象中"price"的值增加"38.8"，并通过[CloudDBZoneObjectOperatorConstraint](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-objectoperatorconstraint-server-nodejs-0000001718931842)类构造"price"小于"200"的约束条件。如果此次条件更新满足约束，则更新成功，返回具体更新条数；不满足则返回"0"。  
  以batchUpdateByCondition()方法为例：

  ```
  import { cloud, CloudDBZoneObjectOperator, CloudDBZoneObjectOperatorConstraint } from '@hw-agconnect/cloud-server';

  const collection = cloud.database({ zoneName: "QuickStartDemo" }).collection("BookInfo");
  try {
    const operator = CloudDBZoneObjectOperator.build("BookInfo").increment(
      "price",
      38.8
    );
    const constraint = CloudDBZoneObjectOperatorConstraint.build("BookInfo").lessThan("price", 200);
    const updateNum = await collection.batchUpdateByCondition(
      operator,
      constraint
    );
    console.log("updateNum=>", updateNum);
  } catch (error) {
    console.error(error);
  }
  ```

* 通过[batchUpdate()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section20931138154917)或者[batchUpdateByCondition()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section037353591218)方法进行更新数据时，调用[update()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzoneobjectoperator-server-nodejs-0000001718772382#section289310261498)方法，将BookInfo对象所有数据中"publisher"更新为"xxx"。如果此次条件更新满足约束，则更新成功，返回具体更新条数；不满足则返回"0"。  
  以batchUpdateByCondition()方法为例：

  ```
  import { cloud, CloudDBZoneObjectOperator, CloudDBZoneObjectOperatorConstraint } from '@hw-agconnect/cloud-server';

  const collection = cloud.database({ zoneName: "QuickStartDemo" }).collection("BookInfo");
  try {
    const operator = CloudDBZoneObjectOperator.build("BookInfo").update(
      "publisher",
      "xxx"
    );
    const constraint = CloudDBZoneObjectOperatorConstraint.build("BookInfo").lessThan("price", 200);
    const updateNum = await collection.batchUpdateByCondition(
      operator,
      constraint
    );
    console.log("updateNum=>", updateNum);
  } catch (error) {
    console.error(error);
  }
  ```

#### 查询数据

云数据库通过[get()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-server-nodejs-0000001766572401#section2175mcpsimp)方法查询对象，并提供了丰富的谓词查询，比如equalTo()、notEqualTo()、in()等。通过单个或者多个链式过滤条件，您可以从存储区查询到满足特定条件的对象，也可以通过排序谓词对查询结果排序，或者通过限定查询返回数量谓词限定查询结果返回的数量。详细的查询条件请参见[CloudDBZoneQuery](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-server-nodejs-0000001766572401)。

根据查询结果返回的Promise对象可以获取BookInfo对象。云数据库在支持基本查询的同时，还支持查询平均值、最大值和最小值等。

注意事项：

* 每次的查询操作仅支持查询一个对象类型下的数据。
* 查询加密字段或敏感字段时，查询结果为空。
* 构造查询条件时，加密字段和敏感字段不能作为查询条件。
* 查询数据时，仅支持对加密字段和敏感字段进行[countQuery()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-server-nodejs-0000001766572401#section2536mcpsimp)查询。  

#### 简单查询

您可以在无查询条件时，获取一个对象类型中所有的对象；也可以指定单个查询条件，来获取满足该条件的对象。

* 查询对象类型BookInfo的所有数据。

  ```
  import { cloud } from '@hw-agconnect/cloud-server';

  const collection = cloud.database({ zoneName: "QuickStartDemo" }).collection("BookInfo");
  try {
    const bookInfos = await collection.query().get();
    console.log("BookInfos=>", bookInfos);
  } catch (error) {
    console.error(error);
  }
  ```

* 查询"bookName"为"Harry Potter"的书籍。

  ```
  import { cloud } from '@hw-agconnect/cloud-server';

  const collection = cloud.database({ zoneName: "QuickStartDemo" }).collection("BookInfo");
  try {
    const bookInfos = await collection
      .query()
      .equalTo("bookName", "Harry Potter")
      .get();
    console.log("BookInfos=>", bookInfos);
  } catch (error) {
    console.error(error);
  }
  ```

#### 复合查询

您可以通过多个链式过滤条件，来获取满足条件的对象。多个链式条件之间默认用"与"运算。

* 构造查询条件，并调用这个方法，查询"bookName"包含"Database"，"price"在20.0到50.0区间的书籍。

  ```
  import { cloud } from '@hw-agconnect/cloud-server';

  const collection = cloud.database({ zoneName: "QuickStartDemo" }).collection("BookInfo");
  try {
    const bookInfos = await collection
      .query()
      .contains("bookName", "Database")
      .greaterThan("price", 20.0)
      .lessThan("price", 50.0)
      .get();
    console.log("BookInfos=>", bookInfos);
  } catch (error) {
    console.error(error);
  }
  ```

* 构造查询条件，并调用这个方法，查询"bookName"包含"A Tale of Two Cities"，"author"是"Charles Dickens"，"price"大于60.0的书籍。

  ```
  import { cloud } from '@hw-agconnect/cloud-server';

  const collection = cloud.database({ zoneName: "QuickStartDemo" }).collection("BookInfo");
  try {
    const bookInfos = await collection
      .query()
      .contains("bookName", "A Tale of Two Cities")
      .equalTo("author", "Charles Dickens")
      .greaterThan("price", 60.0)
      .get();
    console.log("BookInfos=>", bookInfos);
  } catch (error) {
    console.error(error);
  }
  ```

#### 聚合查询

在查询数据时，您可以通过聚合查询实现查询平均值、求和、查询最大值、查询最小值和统计数据记录条数的能力。

* 查询平均值。 您可以通过[averageQuery()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-server-nodejs-0000001766572401#section2243mcpsimp)查找满足特定条件的对象，并计算这些对象中指定字段的平均值。

  查询所有书籍的价格平均值。

  ```
  import { cloud } from '@hw-agconnect/cloud-server';

  const collection = cloud.database({ zoneName: "QuickStartDemo" }).collection("BookInfo");
  try {
    const resp = await collection.query().averageQuery("price");
    console.log("The average price of all books is:", resp);
  } catch (error) {
    console.error(error);
  }
  ```

* 求和。 您可以通过[sumQuery()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-server-nodejs-0000001766572401#section2316mcpsimp)查找满足特定条件的对象，返回指定字段的数据记录值的求和结果。

  查询所有书籍的价格总和。

  ```
  import { cloud } from '@hw-agconnect/cloud-server';

  const collection = cloud.database({ zoneName: "QuickStartDemo" }).collection("BookInfo");
  try {
    const resp = await collection.query().sumQuery("price");
    console.log("The sum price of all books is:", resp);
  } catch (error) {
    console.error(error);
  }
  ```

使用[orderByAsc()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-server-nodejs-0000001766572401#section1548373511395)或者[orderByDesc()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-server-nodejs-0000001766572401#section1247448183917)对字段进行排序时，建议针对排序的字段[创建索引](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-setclouddb-server-nodejs-0000001983440360#ZH-CN_TOPIC_0000001983440360__li1182119483116)，否则，当该对象类型的数据量达到一定条数时，可能因为查询效率低引起查询超时或失败，影响用户体验。

#### 分页查询

在查询数据时，您可以通过[元组查询](#section09972107254)和[limit()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-server-nodejs-0000001766572401#section6713192110403)方法结合使用实现数据的分页查询，也可以直接通过[limit()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-server-nodejs-0000001766572401#section6713192110403)实现分页查询。例如与排序查询谓词或者等值查询谓词组合使用，可以实现获取某个对象之前或者之后的数据记录。

为了保证分页查询的性能，云数据库要求您在构造分页查询条件前，先[创建索引](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-setclouddb-server-nodejs-0000001983440360#ZH-CN_TOPIC_0000001983440360__li1182119483116)。如果未创建索引，您可能会收到一个异常信息，您需要根据异常信息创建缺少的索引。

* 通过元祖查询和limit()方法组合使用进行分页查询。  
  使用[startAt()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-server-nodejs-0000001766572401#section3626539114012)方法定义查询的起始位置，通过与[limit()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-server-nodejs-0000001766572401#section6713192110403)和[orderByAsc()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-server-nodejs-0000001766572401#section1548373511395)方法结合使用实现数据的分页能力，并将第一次查询结果的最后一条记录，作为下一次查询的起点。

  ```
  import { cloud, CloudDBZoneGenericObject } from '@hw-agconnect/cloud-server';

  const collection = cloud.database({ zoneName: "QuickStartDemo" }).collection("BookInfo");
  const book = CloudDBZoneGenericObject.build("BookInfo");
  book.addFieldValue('id', 5);
  try {
    // Query the first 10 records.
    const snapshot = await collection
      .query()
      .orderByAsc("id")
      .startAt(book)
      .limit(10)
      .get();
    // Use the last record of the first 10 records as the start point of the next query to obtain data records on the next page.
    const nextBook = snapshot[snapshot.length - 1];
    const snapshotNext = await collection
      .query()
      .orderByAsc("id")
      .startAfter(nextBook)
      .limit(10)
      .get();

    console.log("BookInfos=>", snapshotNext);
  } catch (err) {
    console.log(err);
  }
  ```

* 通过limit实现分页查询。 在查询数据时，您可以通过[limit()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-server-nodejs-0000001766572401#section6713192110403)限定查询返回数据的起始位置和数量，实现数据的分页。例如与排序查询谓词组合使用，可以实现获取top-N条数据。

  对查询结果中的对象限定查询返回数量时，限定数据查询返回数量谓词在所有其它谓词查询之后。
  * 构造查询条件，并调用这个方法，查询所有价格小于50.0的书籍，并且只显示最开始10条记录。

    ```
        .get();
      console.log("BookInfos=>", bookInfos);
    } catch (err) {
      console.log(err);
    }
    ```

  * 构造查询条件，并调用这个方法，查询所有价格小于50.0的书籍，并将查询结果按照降序排序，只显示价格排序从第6条开始的10条记录。

#### 删除数据

您可以通过[delete()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section144646116302)删除单个对象或者一组对象的数据。删除数据时，需遵循以下约束：

在使用delete()删除数据时，云数据库会根据传入对象主键删除相应的数据，不会比对该对象其它属性与存储的数据是否一致。删除一组对象时，删除操作是原子的，即对象列表中的对象要么全部删除成功，要么全部删除失败。

注意事项：

* 删除一组对象时，该组中的对象必须属于同一个对象类型，否则会导致删除失败。
* 使用delete()删除一组对象时，数据总条数不能超过1000条，否则会导致删除失败。
* 每个删除操作包含的字段名和字段值的总大小不能超过20MB，否则会导致删除失败。  

#### 根据对象删除数据

使用[delete()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section144646116302)将对象删除，如果任务执行成功，返回删除对象的个数；执行失败，则返回一个异常。

```
import { cloud } from '@hw-agconnect/cloud-server';

const collection = cloud.database({ zoneName: "QuickStartDemo" }).collection("BookInfo");
try {
  const deleteNum = await collection.delete({
    id: 1,
    bookName: "highway",
    author: "unknown",
    price: 44,
    publisher: "unknown",
    publishTime: new Date("1997-07-26T03:24:00"),
    shadowFlag: true,
  });
  console.log("deleteBookInfos=>", deleteNum);
} catch (err) {
  console.error(err);
}
```

#### 根据条件删除数据

使用[batchDelete()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section441211816372)或者[batchDeleteByCondition()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section12734357113812)方法根据条件删除数据，通过[CloudDBZoneObjectOperatorConstraint](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-objectoperatorconstraint-server-nodejs-0000001718931842)类构造约束条件。删除"price"小于"200"的数据。如果此次删除满足约束条件，则进行删除，返回具体删除条数；如果不满足删除的约束条件，返回"0"。  
以batchDeleteByCondition()方法为例：

```
import { cloud, CloudDBZoneObjectOperatorConstraint } from '@hw-agconnect/cloud-server';

const collection = cloud.database({ zoneName: "QuickStartDemo" }).collection("BookInfo");
try {
  const collection = database.collection("BookInfo");
  const constraint = CloudDBZoneObjectOperatorConstraint.build("BookInfo").lessThan("price", 200);
  const deleteNum = await collection.batchDeleteByCondition(constraint);

  console.log("deleteBookInfos=>", deleteNum);
} catch (err) {
  console.error(err);
}
```
