# 创建引用

文件存储在云端的存储实例中，其存储方式与本地硬盘中的文件系统类似。您可以通过文件的引用进行上传文件、下载文件、删除文件、更新文件元数据等操作，也可以通过创建存储实例的引用来获取该存储实例下的文件列表。  

#### 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[初始化存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-initialize-bucket-java-0000001282104682)。  

#### 操作步骤

* 创建根目录的引用，可以调用[AGCStorageManagement.getStorageReference](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragemanagement-0000001111669018#section39110317536)方法。

  ```
  StorageReference storageReference = storageManagement.getStorageReference();
  ```

* 如果您需要创建云端指定文件或目录的引用，可以调用[AGCStorageManagement.getStorageReference](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragemanagement-0000001111669018#section14434853205418)方法。

  ```
  StorageReference storageReference = storageManagement.getStorageReference("image/demo.jpg");
  ```

* 如果您需要指定文件上传或下载的区域，可以调用[AGCStorageManagement.getReferenceFromUrl](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragemanagement-0000001111669018#section122091622563)方法。

  ```
  StorageReference storageReference = storageManagement.getReferenceFromUrl(agcClient, "完整的url地址");
  ```

#### 更多信息

创建引用后，您可以调用[StorageReference](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagereference-0000001158228875)实例的相关方法对引用进行相关操作：

* 在当前文件层次结构中向上向下导航，例如调用[child](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagereference-0000001158228875#section125402514524)获取子目录引用，调用[getParent](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagereference-0000001158228875#section323481725418)获取父目录引用，调用[getRoot](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagereference-0000001158228875#section15145194815541)获取根目录引用。
* 获取当前引用的相关信息，例如调用[getBucketName](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagereference-0000001158228875#section18311911165516)获取文件所在存储实例名称，调用[getName](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagereference-0000001158228875#section191516162568)获取当前引用的文件或目录名称，调用[getPath](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagereference-0000001158228875#section114183817563)获取文件在云端的存储路径。
* 对文件进行[上传](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-upload-java-0000001161896489)、[下载](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-download-java-0000001161976515)、[删除](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-delete-java-0000001115656618)和[元数据管理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-metadata-java-0000001161896491)等操作。
