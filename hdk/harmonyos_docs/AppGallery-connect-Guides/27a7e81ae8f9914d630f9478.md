# 充值付费

#### 查询账户余额\&用量

进入[开发与服务](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/myProject)页，点击 已购服务，点击"账户概览"，查询账户余额、优惠券余额、账单用量。

查询"账单"用量时，需筛选 账单时间（不超过90天）、商品为"AI问答联网增强服务"相关商品、服务为"AI问答联网增强服务"相关服务。

![](https://media:101782872660512095 "点击放大")

![](https://media:101782872660567096 "点击放大")  

#### 充值付费

进入[充值](https://developer.huawei.com/consumer/cn/console/account/myRecharge/0/0)页：点击"充值"按钮，进入开发者联盟的管理中心-余额页，再次点击"马上充值"按钮，即可进入充值页。注：点击"[充值](https://developer.huawei.com/consumer/cn/console/account/myRecharge/0/0)"链接，亦可直达充值页。

![](https://media:101782872660629097 "点击放大") ![](https://media:101782872660841098 "点击放大")

* 个人开发者充值付费：进入[充值](https://developer.huawei.com/consumer/cn/console/account/myRecharge/0/0)页后，选择"通用基金"，输入金额后，点击"提交"，进入扫码付款页面，任选华为钱包/支付宝/微信，付款即可。

  ![](https://media:101782872661095099 "点击放大") ![](https://media:101782872661142100 "点击放大")

<!-- -->

* 企业开发者充值付费：进入[充值](https://developer.huawei.com/consumer/cn/console/account/myRecharge/0/0)页后，选择"通用基金"，输入金额后，选择 "在线网银支付"（推荐方式）-\> 选择其一网银支付方式，点击"下一步"，执行付费即可。

  ![](https://media:101782872661327101 "点击放大") ![](https://media:101782872661418102 "点击放大")
