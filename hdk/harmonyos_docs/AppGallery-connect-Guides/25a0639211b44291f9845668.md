# 激活/去激活库实例

当游戏准备好绘制预测帧时，应调用函数激活当前库实例。

## 前提条件

* 已[创建库实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/predict-frame-create-instance-0000001580652660)。
* 已[设置主要参数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/predict-frame-set-frame-parameters-0000001630812045)。

## 激活库实例

调用函数[FrameFlow_Activate](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflow-activate-0000001838093761)，激活当前库实例。
> 说明
>
> 函数调用成功后，该库实例将被视为活动状态，否则将被视为非活动状态。

```screen
FFResult FrameFlow_Activate(FFInstance instance);
```

## 去激活库实例

在某些使用场景（如设置界面、镜头旋转角度过大、角色离摄像机距离过近或过远等）下，预测效果可能会不太理想或无需使用预测帧，可通过调用函数[FrameFlow_Deactivate](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflow-deactivate-0000001838253705)进行去激活库实例（即暂停）。
> 说明
>
> 函数调用成功后，该库实例将被视为非活动状态。

```screen
FFResult FrameFlow_Deactivate(FFInstance instance);
```

## 查询库实例状态

调用函数[FrameFlow_IsActive](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflow-isactive-0000001791494292)，可查询库实例当前是否处于活动状态。

```screen
FFBool FrameFlow_IsActive(FFInstance instance);
```
