# 业务介绍

AppGallery Connect（以下简称AGC）Serverless模板是基于Serverless服务构建的场景化解决方案，提供了应用生态常见场景的代码实现。开发者可将所需能力快速部署和集成到自己的应用中，有效降低开发门槛，提高交付效率。

## 主要功能

|主要功能|功能描述|
|:----------------|:------------------------------------------------------------------|
|构建丰富的Serverless能力|基于Serverless服务构建，可一键部署到Serverless环境。实现丰富的场景化能力，提供应用生态常见场景的代码实现。|
|简化开发与运维|快速集成到应用或直接使用，免除大量端侧开发与运维工作。支持一键部署、快速集成、弹性伸缩、免运维，助力应用开发者快速集成和交付相关能力。|

## 使用流程

|序号|步骤|详情|
|:-|:-------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|部署Serverless模板|您需要将Serverless模板部署到需要使用模板的项目中，详情请参见对应模板的"部署模板"章节。|
|2|管理Serverless模板|您可以修改对已部署模板进行管理，包括升级版本等，详情请参见[管理模板](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-serverless-manage_template-0000001241426200)章节。|
|3|使用Serverless模板|您可以根据模板中的使用指导使用模板。|
