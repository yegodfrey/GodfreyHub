# 自定义预测任务  
  
除了系统预置的预测任务外，您还可以针对应用的行业特点以及实际使用场景，通过华为分析自定义转化事件来创建预测任务。例如，如果您的产品属于游戏类应用，您希望预测出近期将在游戏中消耗道具的玩家，那么，就可以在华为分析服务的事件管理中，标记“消耗道具事件”为转化事件，同时在创建自定义预测任务时，将其作为您的自定义预测事件，以此来满足您的个性化预测需求。

自定义预测区别于预置的流失预测、付费预测和复购预测，允许开发者自定义待预测事件。自定义预测使用应用用户最近两周内上报的用户数据训练模型，以预测应用最近一周的活跃用户在未来一周内发生某行为（上报某个事件）的概率。

#### 创建预测任务

  1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击“我的项目”。
  2. 在项目列表中，找到您需要创建预测任务的项目。
  3. 点击“增长>预测”进入预测服务页面。
  4. 如果您有多个应用，在预测服务页面，点击下拉框选择需要创建自定义预测任务的应用，点击“自定义预测”，创建自定义预测任务。

     2. 根据您想要预测的转化事件类型，选择具体的转化事件。

     3. 如果当前列表没有符合您要求的事件，点击“您可以去华为分析自定义转化事件”将跳转到“华为分析 > 管理 > 事件管理”页面。

#### 用户详情分析

预测详情页面不仅仅展示预测任务不同概率的人群数量，您还可以查看自定义预测出来的人群在机型分布、系统版本分布等用户属性相关的分布分析与TGI分析，以方便您深度洞察各个概率人群的行为特征。

  * **分布分析**
    1. 选择“分布分析”页签，查看自定义预测任务的用户属性特征。

#### 预测人群精细化运营

预测服务已与推送服务、远程配置等其他能力联动，通过预测生成的高概率、中概率、低概率以及自定义人群可用于这些功能的受众细分，帮助您实现精细化运营。

  1. 点击“应用”，根据制定的运营策略，选择具体的受众使用场景。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220927160610.93417055657598165923984450667777:50530926093051:2800:037DEBEB8FF5FB66008FF8E4546DFA2456C549B2B3F8172CDF01EBDDA98FA3EC.png?needInitFileName=true?needInitFileName=true)

  2. 点击对应场景后，将跳转至其他能力的后台配置页面。例如，当您选择“远程配置”，那么将跳转至远程配置的配置条件界面，系统将快速为您定位到所选的预测受众群组，这样，您的配置内容就可以精准触达指定事件的预测人群。
