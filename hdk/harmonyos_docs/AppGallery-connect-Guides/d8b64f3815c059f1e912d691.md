# 升级应用版本

如果您的应用新增了新的功能或修复了部分问题，需要重新上架新的应用软件包到华为应用市场，可以采用版本升级的方式上架。

## 前提条件

* 应用已经上架到华为应用市场。
* 调用Publishing API前请确认已经完成[使用入门](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114)中的服务端授权。
* 已准备待升级的应用软件包。
* 如果您还需要更新应用图标、应用介绍截图等信息，需要提前准备对应的应用资源文件。

## 开发步骤

1. 如需更新应用详情页的多语言描述信息，如应用名称、应用描述信息等，可调用[更新语言描述信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-language-info-update-0000001158245057)接口。如需更新应用的基本信息，如应用分类、应用支持的设备、应用的开发者信息等，可调用[更新应用基本信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-info-update-0000001111685198)接口。 注意
   >
   > 应用上架后不支持修改应用付费类型。
2. 如需更新应用图标、应用介绍截图、推荐视频、版权图片等，您需要调用[获取上传文件地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-upload-url-new-0000001111685200)接口为每个文件获取上传地址，再调用[上传文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-upload-file-new-0000001111845090)接口将每个应用资源文件上传至华为服务器。
3. 文件上传完成后，您需要调用[更新应用文件信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-file-info-0000001111685202)接口将应用文件信息与应用绑定，具体请参见[更新应用文件信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-file-info-0000001111685202)。
4. 选择一种发布方式升级应用。
   * 如果您选择[直接提交发布](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-release_app-0000001111685460#section12120619192016)方式升级应用，您需要在执行步骤[2](#ZH-CN_TOPIC_0000001111845352__li1592015502274)和[3](#ZH-CN_TOPIC_0000001111845352__li202271256979)时同时更新应用软件包。
   * 如果您的软件包保存在自己的服务器上，可以选择通过下载方式提交发布，具体请参见[通过下载方式提交发布](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-release_app-0000001111685460#section16342162332014)。
