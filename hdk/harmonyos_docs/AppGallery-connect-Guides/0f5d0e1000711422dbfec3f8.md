# 服务特点

## 自定义域名

使用自定义域名不受数据处理位置的限制，您只需提供个人或者企业自申请域名，无需关注CDN加速和SSL配置，通过控制台一键发布版本即可向全球用户分发您的内容。

## 分配域名

### 网站托管域名

数据处理位置在德国、俄罗斯、新加坡，CDN加速区域包含非中国大陆的其他区域时，您可以使用华为分配的域名，比如fly.dra.agchosting.link、fly.drru.agchosting.link或者fly.dre.agchosting.link，其中四级域名(fly)可以由您自己定义，零成本构建个人或企业网站。

### 存储加速域名

数据处理位置在德国、俄罗斯、新加坡，CDN加速区域包含非中国大陆的其他区域时，您可以使用华为分配的域名，比如fly.m-dra.agchosting.link、fly.m-drru.agchosting.link或者fly.m-dre.agchosting.link，其中四级域名(fly)可以由您自己定义，为存储桶提供CDN加速能力。

## 使用版本管理自动进行持续部署

网站托管功能可以将您的静态内容自动执行上下线的部署，同时可以对历史版本进行管理（例如执行沙箱发布、生产发布、删除版本等操作）。
