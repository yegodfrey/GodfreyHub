# 人工服务

#### 筛选并查看

购买成功的定价人工服务或在需求单中购买成功的服务可在已购服务中进行管理。购买人工服务成功后，您可以在已购服务列表中跟踪订单处理进度，及时确认交付结果。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)，将鼠标悬停在右侧账户中心区域，点击"已购服务"，进入已购服务列表，选择"交付方式"为"人工服务"进行筛选。

   ![](https://media:201775716942872115)
2. 已购服务列表中的人工服务的状态有"待服务商交付"、"待确认交付"、"完成"三种，每种状态的含义如下：  

   |状态|含义|
   |:-----|:-------------------------------------------------------|
   |待服务商交付|已购买服务但服务商尚未交付的任务。|
   |待确认交付|已购买且服务商已交付，等待您确认交付的任务，详情请参见[确认交付](#section156844181478)。|
   |完成|服务商已交付且用户已确认交付的任务。|

   点击服务订单条目右侧"详情"，查看服务基本信息及相关订单。

![](https://media:201775716942909116)  

#### 确认交付

当您购买人工服务且服务商已提供交付件，您需要及时确认交付件以结束任务。

1. 进入已购服务列表，选择并筛选出状态为"待确认交付"的服务订单，点击订单右侧"详情"进入任务详情页，点击右上角"处理任务"。
2. 在任务详情页，确认交付件无误后，点击右上角"确认完成"。  
   ![](https://media:201775716942934117)  
   当服务商已提供交付件时，AGC会以邮件、互动中心消息和短信的方式通知您，请您在收到消息后确认交付。
