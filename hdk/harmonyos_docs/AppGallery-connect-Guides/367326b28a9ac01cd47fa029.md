# UX测试

云测试提供HarmonyOS应用/元服务在真机设备上的UX测试能力，主要验证HarmonyOS应用或元服务卡片和图标相关指标项的展示效果，支持检测的问题类别包括圆角类、布局类、形状类、字体类、配置类、交互类等。  

#### 前提条件

您已成功创建测试任务，且配置的"测试范围"包含"UX测试"。  

#### 查看测试报告

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击需要查看测试报告的项目。
3. 在左侧导航栏中，选择"质量 \> 云测试"，进入云测试主页面。
4. 选择"测试任务"页签，您可以通过搜索框或测试任务列表中"应用类型"、"测试场景"、"测试状态"右侧的![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303165621.07634945098171628324684227292862:50001231000000:2800:8BA72A13C52EAB39C71CEC1D1800C8AF06C1419B84F9E788BF041A0D329F74AD.png)筛选出您要查看的测试任务，然后点击"操作"列的"查看报告"进入测试报告页面。

5. 点击"UX测试"页签，您可从UX测试的测试报告概览页中，查看HarmonyOS应用/元服务卡片和图标相关指标项的展示效果是否满足要求。

   |:---|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |安装|安装是实现UX测试的基本条件，其非UX测试的检测项。当应用无法安装，该检测项不通过，应用UX检测无法进行。||
   |色彩|服务卡片需要适配深色模式，避免因深色模式和非深色模式间切换导致服务卡片内容显示异常，确保用户对内容的可阅读性，便于用户识别内容。该检测项当前为建议项。|检测规则详情请参见元服务卡片[视觉风格](https://developer.huawei.com/consumer/cn/doc/design-guides-V1/color-0000001111857246-V1)和[设计自检表](https://developer.huawei.com/consumer/cn/doc/design-guides-V1/service-widget-checklist-0000001161280791-V1)。|
   |圆角|主要检测如下两个子项： * 卡片圆角：禁止自定义卡片背景的圆角，卡片的圆角剪裁由宿主提供，即呈现卡片的业务主体，因此在卡片开发时必须提供直角矩形卡片。 * 内容圆角：服务卡片内容（组件）如用到圆角，则需使用规范定义的通用圆角，内容圆角请在4vp、8vp、12vp参数中选择。|检测规则详情请参见元服务卡片[设计自检表](https://developer.huawei.com/consumer/cn/doc/design-guides-V1/service-widget-checklist-0000001161280791-V1)。|
   |布局|为保证服务卡片在任何状态下的交互体验，主要检测如下子项： * 右上角热区：服务卡片控件热区设置不得与卡片右上角30\*30vp范围重合。 * 最小点击热区：服务卡片中需要点击操作的元素，最长边不得小于32vp，物理尺寸大于5mm。 * 四周安全边距：服务卡片内容不得过于接近服务卡片四周。1\*2服务卡片的四周安全距离不得小于8vp；2\*2、2\*4、4\*4服务卡片的四周安全距离不得小于12vp。 * 卡片留白：服务卡片中四边留白不得超过60vp范围，且建议服务卡片中间留白不超过50vp。|检测规则详情请参见元服务卡片[交互设计](https://developer.huawei.com/consumer/cn/doc/design-guides-V1/service-widget-interaction-0000001098056300-V1)、[视觉风格](https://developer.huawei.com/consumer/cn/doc/design-guides-V1/layout-0000001111593946-V1)和[设计自检表](https://developer.huawei.com/consumer/cn/doc/design-guides-V1/service-widget-checklist-0000001161280791-V1)。|
   |形状|需要避免异形卡片的出现。系统仅允许在标准矩形内设计开发卡片内容，并在某些场景下因硬件显示对卡片进行剪裁，不要使用纯透明背景或外形不规则的背景图案，导致与其他卡片外形不一致。|检测规则详情请参见元服务卡片[设计自检表](https://developer.huawei.com/consumer/cn/doc/design-guides-V1/service-widget-checklist-0000001161280791-V1)。|
   |字体|为保证服务卡片中文字清晰易读，服务卡片中最小字号不得小于8fp；建议选择使用通用字号，通用字号请在10vp、12vp、14vp、16vp、20vp、30vp、38vp中进行选择。|检测规则详情请参见元服务卡片[设计自检表](https://developer.huawei.com/consumer/cn/doc/design-guides-V1/service-widget-checklist-0000001161280791-V1)。|
   |配置|支持服务卡片的HarmonyOS应用，为保证HarmonyOS应用服务卡片的上滑交互体验，必须设定默认卡片。|检测规则详情请参见元服务卡片[设计原则及简介](https://developer.huawei.com/consumer/cn/doc/design-guides-V1/service-widget-about-0000001144696239-V1)。|
   |交互|确保卡片是可操作的。服务卡片的使用空间非常有限，请合理的排布卡片内容之间的关系。不能在服务卡片内使用滑动、拖拽和长按等交互手势，导致与系统层级交互产生冲突。|检测规则详情请参见元服务卡片[设计自检表](https://developer.huawei.com/consumer/cn/doc/design-guides-V1/service-widget-checklist-0000001161280791-V1)。|
   |服务图标|图标必须在华为提供的标准图标底板上设计，分辨率必须为216\*216或者512\*512。|检测规则详情请参见元服务设计[基础信息](https://developer.huawei.com/consumer/cn/doc/design-guides-V1/service-basic-0000001092893896-V1)。|
   |应用图标|HarmonyOS应用图标格式、尺寸需要符合要求，分辨率必须为216\*216或者512\*512。且图标右下角添加HarmonyOS品牌区隔元素HMOS，HMOS视觉上要求与图标融合，不突兀，呈现沉浸式效果。|检测规则详情请参见[应用图标](https://developer.huawei.com/consumer/cn/doc/design-guides-V1/app-icon-0000001188065088-V1)。|
   |流转图标|应用必须使用合适尺寸的流转图标，不要过大或过小。需要做到以下几点： * 图标尺寸与其他业务图标保持等大。 * 最小尺寸16vp，最大尺寸48vp。 * 与其他业务图标保持安全距离。|检测规则详情请参见元服务[服务流转图标](https://developer.huawei.com/consumer/cn/doc/design-guides-V1/service-hop-icon-0000001136140831-V1)和[设计自检表](https://developer.huawei.com/consumer/cn/doc/design-guides-V1/service-widget-checklist-0000001161280791-V1)。|
