# 返回码

|返回码|值|描述|解决方法|
|:-----------------------------------|:---|:-----------------|:--------------------------------------------------------------------------------------------------|
|RtnCodeEnum.SUCCESS|0|成功。|-|
|RtnCodeEnum.PARAM_INVALID|1|参数非法。|初始化内嵌社区SDK时，请检查初始化参数： * "context"、"appId"、"clientId"必填。 * "clientSecret"与"cpAccessToken"二选一，不能同时为空。|
|RtnCodeEnum.NOT_INIT|1000|内嵌社区SDK未初始化。|请先执行初始化操作。|
|RtnCodeEnum.INIT_FAIL|1001|初始化失败。|-|
|RtnCodeEnum.DEVELOPER_AUTH_FAIL|1002|开发者验证失败。|请检查"clientId"或"clientSecret"是否正确传入。|
|RtnCodeEnum.SERVICE_NOT_ENABLED|1003|服务不可用。|请检查游戏内嵌社区的服务是否已开通。|
|RtnCodeEnum.PLAYER_ACCOUNT_AUTH_FAIL|1004|玩家账户验证失败。|-|
|RtnCodeEnum.USER_NOT_LOGIN|1005|玩家未登录。|-|
|RtnCodeEnum.SERVER_REQUEST_FAILED|1006|网络请求失败。|请检查网络连接。|
|IMAGES_NUM_EXCEED_LIMITS|1007|图片数量超出限制。|一键发布至华为游戏论坛的图片不能超过9张。|
|IMAGE_TYPE_INVALID|1008|图片类型无效。|目前图片格式仅支持"jpeg"、"jpg"、"png"、"webp"、"gif"、"bmp"。|
|IMAGE_PATH_INVALID|1009|图片路径不存在。|-|
|IMAGE_SIZE_OVER_LIMIT|1010|图片大于10MB。|单张图片需小于10MB。|
|SPECIAL_CHARACTER_ERROR|1011|动态内容中包含特殊字符，例如表情符。|-|
|USER_STATUS_ERROR|1012|用户状态错误。|请检查华为账号或"pgsauth"。|
|SCENE_STATUS_INVALID|1013|场景状态异常。|非法的入口ID，请前往AGC控制台检查数据。|
|USER_CANCEL_CLOSE_CONFIRM|1014|弹出关闭弹窗时，用户点击了取消。|-|
|APP_IN_BACKGROUND|1015|调用关闭弹窗时，应用在后台运行。|请确保应用在前台运行时调用关闭内嵌社区接口。|

若您的问题仍无法解决，请通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题，华为支持人员会及时处理。
