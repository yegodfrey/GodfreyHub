# 修改config.json文件

云存储使用过程中可能涉及使用存储权限，可在config.json文件中进行配置。另外，SDK已默认配置了申请网络状态权限，您也可在config.json文件中修改reason等。

## 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[集成云存储SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-sdk-harmony-java-0000001491442588)。

## 操作步骤

1. 在config.json文件中配置存储权限。

   ```screen
   "reqPermissions":[ 
   { 
   "name":"ohos.permission.READ_MEDIA" 
   "reason":"REPLACE_YOUR_REASON" 
   }, 
   {
    "name":"ohos.permission.WRITE_MEDIA" 
   "reason":"REPLACE_YOUR_REASON"
   }
   ]
   ```


2. （可选）如需修改申请网络状态权限的reason等，在config.json文件中进行如下配置：

   ```screen
   "reqPermissions":[ 
   { 
   "name":"ohos.permission.GET_NETWORK_INFO" 
   "reason":"REPLACE_YOUR_REASON" 
   "mergeRule":{
   "replace":["reason"]
   }
    } 
    ]
   ```
