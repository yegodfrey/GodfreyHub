# 配置iOS应用信息

当应用平台为iOS时，您需要在AGC配置"App Store ID"和"团队ID"。

1. 在"开发与服务"页面中，点击iOS应用所在项目。
2. 在"项目设置"页面选择"常规"页签。
3. 在"应用"区域，点击![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704165806.27076586584008262306872821454672:50001231000000:2800:557B38636C196109E072655ED239A6B821E7AAD3CAD79EA2D105085922BB1F22.png "点击放大")配置"App Store ID"和"团队ID"，即您应用在App Store上的ID和团队ID，完成后点击![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704165806.05193345908532524720544182447661:50001231000000:2800:E0FBF1EDC6ECE928B36D174317B845EB3C8F9866C46C04142D64B30F4AF2428B.png "点击放大")保存。
