# 技术支持

当您集成AGC相关服务遇到问题时，可以按照以下顺序寻求帮助。

1. 请先仔细阅读文档，部分功能对设备和系统有限制，请参见[使用限制](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloud-function-restriction-0000001058641770)。
2. 查看[FAQ](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloud-function-faq-0000001077699588)和[问题处理案例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloud-function-troubleshooting-cases-0000001120491388)，错误码请参见[Android](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcfunctionexception-0000001058890684)、[iOS](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcfunctionerrorcode-0000001058521153)、[Web](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/errorcode-0000001060494789)、[Server-Java](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/errorcode-java-0000001237833197)、[Server-Node.js](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/errorcode-nodejs-0000001733038624)。
3. 通过[AI助手](https://developer.huawei.com/consumer/cn/customerService/#/bot-dev-top/faq-top/faq-talk-top)查找问题解决方案。
4. 登录[Stack Overflow社区](https://stackoverflow.com/questions/tagged/appgallery-connect)和[华为开发者社区](https://developer.huawei.com/consumer/cn/forum/block/serverless)参与问题讨论。
5. 如果以上方法仍未解决您的问题，可以通过[在线工单系统](https://developer.huawei.com/consumer/cn/support/feedback/#/add/89?level2=9017)与我们进行联系。提交工单后，可登录[华为开发者联盟官网](https://developer.huawei.com/consumer/cn/)，鼠标置于右上角头像处，在下拉框内点击"我的工单"查看工单处理进展。
