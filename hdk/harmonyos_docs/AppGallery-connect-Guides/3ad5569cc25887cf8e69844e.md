# 调测应用内消息

由于应用内消息只在应用正式上架后的正式用户终端设备上展示。为了确保您应用内消息设置的正确性，应用内消息提供了在应用正式上架前调测消息的方法。

## 前提条件

* 已[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-appmessaging-integratesdk-java-0000001199052357)。
* 已[添加应用内消息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-appmessage-create-java-0000001199092457)。

## 调试消息

> 说明
>
> 分配了"管理员"、"APP管理员"、"运营"或"开发"角色的账号才可以调测应用内消息。

1. 获取测试设备的AAID（Anonymous Application Identifier)。
   1. 集成AGC Credential SDK。

      ```screen
      implementation 'com.huawei.agconnect:agconnect-credential-harmony:1.5.1.300'
      ```

   2. 调用[AGCInstanceID](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-agcinstanceid-harmonyos-0000001204045379)获取AAID。

      ```screen
      String aaid = AGCInstanceID.getInstance().getId()
      ```

      > 注意
      >
      > 目前，Huawei DevEco Studio每次重新打包都会默认清理缓存，导致AAID每次都会改变，请勾选 "Replace existing application"以关闭默认清理缓存，确保AAID不变，详情请参考[设置Hap包安装方式](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/ide_debug_device-0000001053822404-V3#section531811771410)。
2. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
3. 在项目列表中点击您需要调试应用内消息的项目。
4. 点击"增长 > 应用内消息"，找到需要调试的消息，点击"操作"列的"调测"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251121174810.14891229092122107674918759114609:50001231000000:2800:5A05967B76C4658FD2402365EE74ACA0D8FBDA819C9B3A02460B1245677C14B4.png)

5. 点击"应用内消息调测"界面上的"新增测试用户"，输入测试设备的AAID，点击"保存测试"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251121174810.22967043471618139574247554890131:50001231000000:2800:68BC1236B26DCCA9E72528429DBDC0AE2011D40059633C156C0B69632B218372.png)

6. 在弹出的"提示"框中，点击"确定"。
7. 在调试代码中调用[AGConnectAppMessaging.setForceFetch](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectappmessaging-java-0000001153013534#section152131924510)，设置强制请求AGC服务端消息数据的标记位。

   ```screen
   AGConnectAppMessaging.getInstance().setForceFetch();
   ```

   调用[setForceFetch](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectappmessaging-java-0000001153013534#section152131924510)接口后，下一次消息事件触发时将强制从AGC服务端获取消息数据，并获取到测试设备信息。后续在测试设备中触发消息事件时，该测试设备都会强制到AGC服务端获取消息数据，而不是从本地缓存读取。
   > 注意
   > * setForceFetch方法仅在调测消息时使用，在正式的版本中不能调用该方法。
   > * App Messaging SDK会记录您调用setForceFetch方法的次数（最多5次），请确保最多5次尝试成功绑定设备的AAID（将您在AGC控制台上配置的测试设备的AAID与当前设备上的AAID比对是否一致）。如果超过5次，则您需要卸载应用重装或者清除应用数据，setForceFetch方法的调用次数将会重置。
   > * 您可以在setForceFetch日志中搜索关键字：This device is a test device，若查到此日志，说明测试设备绑定成功。
8. 触发一次消息事件，使得应用内消息SDK去AGC服务端刷新测试设备列表，查看测试消息能否正常展示和操作。 有关测试设备和测试消息的具体说明如下表所示。

   > 说明
   > * 为了让调测消息尽快地展示出来，除了触发消息本身配置的触发事件外，当应用回到前台再次被打开时（触发AppLaunch和AppOnForeground事件）也可以实现此目的。
   > * 调测消息不受消息展示时间、频率等因素影响。例如，一条消息原本的展示时间应为第二天，但如果用该条消息来做调测，在调测设备上当前时间仍能显示。

   |类型|目的|说明|
   |:---|:----------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |测试设备|测试设备实时同步AGC服务端数据，不受应用内消息SDK请求次数的限制。|您在AGC中添加了该设备的AAID，并通过[AGConnectAppMessaging.setForceFetch](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectappmessaging-java-0000001153013534#section152131924510)方法设置了强制请求的标志位，下一次消息事件触发后该设备强制从AGC服务端同步了消息数据，此时开发者的设备为测试设备。 判断开发者的设备是否是测试设备的方法：每次触发事件都会去AGC服务端实时请求数据。|
   |测试消息|让开发者快速熟悉消息的内容、展示布局等。|在"应用内消息调测"页面，新增测试用户，点击"保存测试"后该条消息为测试消息。 测试消息只会展示一次。如果您想再次展示测试消息，需要重新进入"应用内消息调测"页面，点击"保存测试"将消息设置为测试消息。|
