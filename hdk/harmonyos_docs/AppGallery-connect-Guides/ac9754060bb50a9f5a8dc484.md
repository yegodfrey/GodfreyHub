# 查看单用户应用性能数据

单用户应用性能数据用于帮助您准确分析并处理特定用户遇到的问题。

## 前提条件

* 您的应用已[启用APM服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-android-getstarted-0000001052887262#section222119255410)。
* 您的应用已[集成APM SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-android-getstarted-0000001052887262#section194247503211)和[开启APM功能](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-android-getstarted-0000001052887262#section640224332214)，并在设备上运行。
* 设置应用内用户标识。

  调用[APMS.getInstance().setUserIdentifier](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/apms-0000001052488219#section99791215181716)方法设置用户标识，并上报性能数据。

  ```screen
  APMS.getInstance().setUserIdentifier(String userIdentifier);
  ```

## 查看单用户性能数据

单点查询页面目前覆盖了"ANR分析"、"页面分析"、"慢启动追踪"与"网络分析"子项。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择需要查看单用户性能数据的应用。
3. 在左侧导航栏选择"质量 > 性能管理"，进入"应用性能管理"页面。
4. 点击"单点查询"页签，进入单点查询页面。 您可以通过在"用户标识"搜索框输入应用中设定的[用户标识](#ZH-CN_TOPIC_0000001261697662__section1637203025418)，查询某个用户的应用性能监控数据。

   > 注意
   >
   > "用户标识"需要与应用中调用SDK接口[APMS.getInstance().setUserIdentifier(String userIdentifier)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/apms-0000001052488219#section99791215181716)时传入的参数值一致。

### ANR分析

展示单用户在选定时间范围内应用ANR事件的发生次数、应用启动次数、用户ANR率，以及问题列表。

|指标名称|指标含义|
|:-----|:---------------------------|
|发生次数|选定时间范围内，应用ANR问题的发生次数。|
|启动次数|选定时间范围内，应用启动的总次数。|
|用户ANR率|选定时间范围内，应用ANR发生次数/应用启动次数的比例。|

### 页面分析

展示单用户在选定时间范围内所打开的屏幕名称总览，某个屏幕的慢加载与慢呈现占比等信息。

|指标名称|指标定义|
|:----|:------------------------------|
|慢加载|屏幕加载时间超过阈值1000ms。|
|慢呈现|屏幕呈现时间超过阈值3000ms。|
|慢加载占比|定义：衡量屏幕交互过程是否流畅。 公式：慢加载次数/打开次数。|
|慢呈现占比|定义：衡量屏幕内容呈现是否完整。 公式：慢呈现次数/打开次数。|
|打开次数|选定时间范围内，某个屏幕被打开的次数。|
|加载耗时|选定时间范围内，某个屏幕加载的平均耗时。|
|呈现耗时|选定时间范围内，某个屏幕内容呈现的平均耗时。|

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155812.79634169573752098489842372761564:50001231000000:2800:705B8F59E66731FBA0CA31A0E5C03E94456722EF8EB3D6C7AF245D60B81C762D.png)

点击某个屏幕名称右侧"操作"列的"查看详情"，进入该屏幕详情页面。

* "屏幕加载"页签主要分析用户切换屏幕是否流畅，统计当前屏幕打开到用户可交互的时间。
* "屏幕呈现"页签主要分析该屏幕内容是否呈现完整，统计当前屏幕打开到内容呈现完毕的时间。

详细的屏幕指标说明请参见[查看体验分析数据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-android-viewperformancedata-0000001052247256#section1882352917252)。

### 慢启动追踪

展示单用户冷启动与热启动时慢启动的发生事件列表，每条事件记录冷/热启动发生时间、冷/热启动的耗时、应用版本、系统版本以及接入方式等信息。

|指标名称|指标含义|
|:---|:--------------------------------------------------------|
|耗时|选定时间范围内，某次慢启动的耗时。|
|慢启动|* 冷启动 冷启动时间超过3000ms，定义为慢冷启动。 * 热启动 热启动时间超过1000ms，定义为慢热启动。|

### 网络分析

展示单用户在选定时间范围内访问的URL以及相应的网络指标信息。

|指标名称|指标含义|
|:----|:---------------------|
|URL|根据URL聚合规则汇总后的网络请求地址。|
|请求时间|选定时间范围内，某次URL请求发起的时间。|
|响应耗时|选定时间范围内，某次URL的响应耗时。|
|DNS耗时|选定时间范围内，某次URL的DNS解析耗时。|
|TCP耗时|选定时间范围内，某次URL的TCP连接耗时。|
|SSL耗时|选定时间范围内，某次URL的SSL握手耗时。|
|首包耗时|选定时间范围内，某次URL的首包耗时。|
