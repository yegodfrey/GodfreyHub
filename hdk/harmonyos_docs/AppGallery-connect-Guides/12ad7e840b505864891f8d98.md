# 背词达人

#### 客户需求

《背词达人》是一款深受用户和专业同行信任和喜爱的背单词软件。但由于应用的崩溃率高达0.5%，仅属于达标水平，影响用户体验，应用质量急需优化。  

#### 华为解决方案

借助崩溃服务实时监测定位崩溃问题，使7天内产品崩溃受影响用户数从48个降低到了1个，崩溃率降低了0.3%，达到了优秀标准，快速提升了用户体验。
