# 开发流程

![](https://media:201786357101747779 "点击放大")  

|序号|任务|说明|
|:-|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------|
|1|[创建项目与应用](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-creat-project-and-app-0000001324725529)|项目是您在AGC资源的组织实体，您可以将一个应用的不同平台版本添加到同一个项目中。 说明： 您可以通过创建不同的项目，实现分别在测试环境和开发环境使用认证服务。|
|2|[开通认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)|-|
|3|[获取agconnect-services.json文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-obtain-files-0000001276801300#section175812034816)|-|
|4|[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyos-integration-sdk-0000001327194257)|使用HarmonyOS Java集成AGC SDK以及认证服务SDK。|
|5|根据业务需要，实现不同账号的登录认证。 * [手机号码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyos-phone-0000001197369961) * [邮箱](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyos-mail-0000001151370304) * [自有账号](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyos-self-0000001197369967) * [匿名账号](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyos-anonymous-0000001151370310) * [关联账号](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyos-associated-0000001151530116)|-|
|6|[登出](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyos-signout-0000001197409875)|当用户不需要使用应用，或者需要切换其他账号登录认证，可以进行登出。登出后，端侧保留的用户信息和Token将被删除。|
|7|[销户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyos-deleteuser-0000001197369969)|当用户需要注销当前账号，可以进行销户。|
