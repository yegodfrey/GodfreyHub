# 调用获取广告接口

#### 功能介绍

此接口用于获取广告主在广告平台投放的广告。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者服务器-\>应用市场服务端|
|接口URL|https://connect-api.cloud.huawei.com/api/mas/v1/dsp/open/query|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|-----------------------------------------------------------------------|

#### 请求参数

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230323144011.35568421203518485586787044902327:50001231000000:2800:CD8B3E9BA46CA58AA93757CD36CECA4882488393E4D6A777C3ABC5E425A0E926.png?needInitFileName=true?needInitFileName=true)  
如果⽆法获取相应参数，请不要随意填写，随意参数可能导致匹配到不相关的⼴告，进⽽降低点击率和转化率。对于接口中要求但媒体侧无法传递的参数，请同步知会到华为应用市场运营和产品侧。  

#### Header

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:-----|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|M|String|客户端ID，获取方法请参见[创建API客户端](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section103mcpsimp)。|
|Authorization|M|String|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token的获取方式请参见[获取Token](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)。|

#### Body

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------|
|requestId|M|String|请求ID。 长度32位。 符合的正则匹配表达式为"\^\[A-Za-z0-9\]+$"。|
|apiVersion|M|String|API版本号。|
|adSlot|M|[AdSlot](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/adx_dsp_api_adslot-0000001222419750)|展示位信息。|
|deviceInfo|M|[DeviceInfo](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/adx_dsp_api_deviceinfo-0000001266979925)|设备信息。|
|networkInfo|M|[NetworkInfo](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/adx_dsp_api_networkinfo-0000001222579702)|网络信息。|
|mediaInfo|M|[MediaInfo](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/adx_dsp_api_mediainfo-0000001222259774)|媒体信息。|

#### 响应参数

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------|
|rtnCode|M|Integer|返回码。 具体请参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/adx_dsp_api_errcode-0000001231510144)。|

#### 接口调用实例

如果您想快速调试获取广告接口，可以使用PostMan工具导入示例文件进行调试。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230323144011.30092782279100963467488041352832:50001231000000:2800:3414041A3B34F4026D14DBD6151B9FF0AD01C022F3D2277AEF197781CE4EC7F5.png?needInitFileName=true?needInitFileName=true)  
需要使用公网环境进行调试。

1. 下载[DSP API接口调用示例文件.zip](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230323144011.98065133420383390880340668171797:50001231000000:2800:3AC23CC9ABA25CFD0A8D59D96282BC3E64B283262E54B7B20C86D8655A539565.zip?needInitFileName=true)文件，解压获取DSPAPI接口调用示例.postman_collection.json文件。
2. 打开PostMan工具，在左上角选择"菜单 \> File \> Import"，导入接口调用示例文件DSPAPI接口调用示例.postman_collection.json。
3. 点击项目名称，点击"Variables"页签，配置环境变量如下图所示。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230323144011.77554160121423690589707875070002:50001231000000:2800:AFB65C885E9F785B82C3AF2A3B11EF26AC38199A5079609C53708E8D4DE0E663.png?needInitFileName=true?needInitFileName=true)

   具体配置说明如下：
   * 配置从AGC页面创建的client_id、client_secret，具体请参考[创建API客户端](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section103mcpsimp)。
   * 配置已向华为申请使用的包名mediaPkgName，以及华为提供的slotid。  
     ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230323144011.61865115317816546731098776221207:50001231000000:2800:86CDA3F0A214F98115FF4D3A521C8BEBB92315E9BB8587ED334C162BF2EFCC9F.png?needInitFileName=true?needInitFileName=true)  
     请区分不同的请求广告场景配置对应的slotid，例如推荐的广告场景请配置推荐slotid，搜索的广告场景请配置搜索slotid。
4. 点击获取Token的POST方法，点击"Send"进行Token的获取。
5. 点击请求广告场景对应的POST方法，点击"Send"进行广告内容的请求。
