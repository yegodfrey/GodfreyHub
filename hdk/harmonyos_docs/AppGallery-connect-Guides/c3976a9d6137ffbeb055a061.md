# Android游戏、HarmonyOS 3.1/4.0及以下游戏

## 准备工作

> 说明
>
> 非华为手机使用Device工具前需进行准备工作。

1. 手机成功连接电脑端的HiSmartPerf-Editor后，打开Editor，确认能读取到手机应用列表，且手机能自动打开Device。
2. 关闭HiSmartperf-Editor。
3. 在cmd中输入adb shell

   ```screen
   LD_LIBRARY_PATH=/data/local/tmp/ /data/local/tmp/GamePerfToolCollector -server -authorize
   ```

4. 打开Device工具进行测试。

## 花瓣轻游支持直接拉起Device测试

您可以直接在花瓣轻游内直接拉起Device采集性能数据，监测游戏性能状况。
> 说明
>
> 只有从快游戏开发者工具启动，花瓣轻游才会显示调试工具入口。

### 前提条件

* 已[下载快游戏开发者工具](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-tool-download-0000001166035569)。
* 已[获取APP ID](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-enable-account-kit-0000001159772367#section1148753814717)。
* 准备Android 6.0及以上版本的手机设备，同时要求：
  * 设备上已安装最新版本的花瓣轻游客户端，并使用已实名认证的华为账号登录花瓣轻游。
  * 设备已成功连接电脑，具体操作可参考[华为手机如何成功连接电脑](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-developer-mode-0000001634026457)

### 操作步骤

1. 在电脑端打开快游戏开发者工具，并连接花瓣轻游进行[调试](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-tool-debug-0000001568083488)。
2. 在手机端采集性能数据。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110224.20553301078129947439399285887058:50001231000000:2800:31B5E877AFB94E2B3864C6355FCA38DBC4A94F0EB3269F4C17D5BCED47CE48A0.png)

3. 测试报告生成后，您可以在HiSmartPerf-Device中[查看、上传并分享测试报告](#section102782203575)。

## 支持命令行形式调用Device

HiSmartPerf-Device支持下载单独的安装包，您可以通过命令行形式调用Device，集成到自身的游戏性能看护流水线。

### 获取游戏信息

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/smartperf-tool-device-android-0000002087044772)，点击"开发与服务"，在项目列表中找到需要获取游戏参数的项目及项目下的游戏。
2. 在"项目设置 > 常规"页面下记录**Client ID、Client Secret** 。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110224.29003103361712072063548995387311:50001231000000:2800:E67CB88A8DDF05AA3A26E255506A99F71238057AB4EFE760B421449C67CD8E95.png)

### 操作步骤

1. 下载 [HiSmartPerf-Device](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/smartperf-tool-download-0000001530830070)
2. （可选）安装 HiSmartPerf-Device

   输入以下命令在电脑端安装 HiSmartPerf-Device 包。

   ```screen
   adb -s [connect-key] install [apk文件名]
   ```

3. 连接手机设备
   * USB 连接 参考[手机设备如何成功连接电脑](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/smartperf-tool-faq-0000001530510854#section935516916145)连接工具和手机。

   * Wi-Fi连接 说明
     >
     > 确保手机和电脑必须处于同一 Wi-Fi 下。
     1. 打开手机的"设置"应用，进入"关于手机"页面。
     2. 快速、连续、多次点击"软件版本"，直到提示"您正处于开发者模式！"或"您已处于开发者模式，无需进行此操作"，表示您已进入当前手机设备的开发者模式。
     3. 在"开发者选项"页面点击"无线调试"，查看IP地址和端口。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110224.21844534530646135620592161292929:50001231000000:2800:FC0FB1AA75B4691BAD4285D466DEE0FB527E7086BB7A0122B89815FFC5C3BCB7.png)

     4. 在电脑端执行以下命令。

        ```screen
        adb connect ip:port
        ```

4. 确认设备已连接 在电脑端执行以下命令查询已连接的设备列表信息，确保目标设备已连接。

   ```screen
   adb devices
   ```

5. 调用python脚本

### python脚本说明

1. 开始采集 说明
   >
   > 需联网操作
   * 参数

     |参数|必填（M）/选填（O）|说明|
     |:-----------|:----------|:-----------------------------------------------------------------------|
     |connectKey|M|目标设备的标识符，设备SN码。|
     |packageName|M|待测试游戏的包名。|
     |clientId|M|客户端ID。具体获取参见[获取游戏信息](#ZH-CN_TOPIC_0000002087044772__li1122185911818)。|
     |clientSecret|M|客户端Secret，具体获取参见[获取游戏信息](#ZH-CN_TOPIC_0000002087044772__li1122185911818)|
     |testName|O|自定义保存的报告名称，在手机APP上查看报告时显示的报告名称。报告名称不能包含中文和特殊字符。|
     |processId|O|待测试游戏进程PID。|

   * 示例代码（以windows 批处理为例）

     ```screen
     @REM 设备SN码
     set connectKey=******
     @REM 被测包名
     set packageName=******
     @REM ACG认证clientId
     set clientId=******
     @REM ACG认证clientSecret
     set clientSecret=******
     @REM （可选）自定义保存报告名称：在手机APP上查看报告适显示的报告名称
     set testName=******
     @REM （可选）采集进程PID
     set processId=******
     python %~dp0AutoTest.py start %connectKey% %packageName% %clientId% %clientSecret% %testName% %processId%
     pause
     ```

   * 回调显示 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110224.76423954079461450612947921274891:50001231000000:2800:41727371E442FA43ED0D871BE1B05A8C4F7AC19C8B26EB61D5D98DEB5BCB406F.png)

2. 结束采集
   * 参数

     |参数|必填（M）/选填（O）|说明|
     |:---------------|:----------|:---------------------------------------------|
     |connect-key|M|目标设备的标识符，设备SN码。|
     |reportSaveUrl|M|自定义保存报告路径。|
     |customReportName|O|自定义保存报告文件夹名称，存储在报告路径中的报告文件夹名称。报告名称不能包含中文和特殊字符。|

   * 示例代码（以windows 批处理为例）

     ```screen
     @echo off
     @REM 设备SN码
     set connectKey=******
     @REM （可选）自定义保存报告路径
     set reportSaveUrl=******
     @REM （可选）自定义保存报告文件夹名称：存储在报告路径中的报告文件夹名称
     set customReportName=****
     python %~dp0AutoTest.py stop %connectKey% %reportSaveUrl% %customReportName%
     pause
     ```
