# Web

Web游戏如需实现实时语音功能，可以集成游戏多媒体服务的Web SDK。  

#### 开发准备

* Web应用IDE开发工具，例如VS Code、WebStorm。
* 包管理工具NPM，运行环境Node.js。  

#### 集成步骤

以Vue工程为例：

1. 下载[SDK压缩包](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Library/gamemme-sdkdownload-web-0000001210296568)到本地，建议单独创建目录用于存放SDK脚本。
2. 打开您的Vue工程，将SDK压缩包解压并拷贝到项目的src目录下（如示例中的sdk目录）。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241105115834.40898017071478446625069408938201:50001231000000:2800:7B3DF88A815C35467EE4E3D12A3A6D9E9A0EAEA92770CC2EF0AF7E394550499B.png?needInitFileName=true?needInitFileName=true)

3. 在项目中使用import引入GameMediaEngine。

   ```
   import { GameMediaEngine } from './sdk/GMME.js'
   ```

4. 调用[GameMediaEngine.checkSystemRequirements](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-web-0000001247887067#section92111058125610)方法检查浏览器是否兼容游戏多媒体服务SDK。

   ```
   try {
     const isMatch = await GameMediaEngine.checkSystemRequirements()
     if(isMatch) {
       // 兼容
     }
   } catch(error){  
     // 不兼容
   }
   ```
