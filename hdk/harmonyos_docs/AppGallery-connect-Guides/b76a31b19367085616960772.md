# 崩溃问题概览

在崩溃问题页面，您可以查看所有崩溃问题列表，您可以点击问题查看问题详情或者将问题列表下载到本地后进行查看。

## 前提条件

您已登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)。

## 崩溃问题列表

通过添加过滤器和时间段，可以快速筛选查看条件，查看筛选条件下所有问题列表及基本信息，包括事件数、受影响用户数、最近一次发生时间等。

点击"下载"，将问题列表文件下载到本地。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250401113624.52796306243308726587321462387273:50001231000000:2800:EA3E54EAEDCE8702A8BAE5D6E866DD600D54A65B5CD0580BB20069B6F0079447.png)

下载到本地的列表文件中包含问题、链接、事件类型等8列数据，复制链接中的URL到浏览器中可查看问题的详情。

## 崩溃问题详情

在问题列表页点击问题名称，可进入问题详情，包括异常发生时的堆栈、相关信息（设备、操作系统、应用版本）。支持按日/周/月维度查看崩溃问题详情。
