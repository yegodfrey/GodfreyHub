# 结合云托管实现静态CDN加速

使用云存储服务时，您可以联合云托管服务实现静态CDN（Content Delivery Network）加速。您可将存储实例中的静态文件（例如文本或图片等）托管于距用户较近的CDN节点中，用户通过静态CDN加速地址即可就近访问资源，有效提升下载速度，也避免了因网络拥堵等因素导致的访问延迟问题，显著提升用户访问体验。

有关云托管服务的详细介绍，请参见[云托管开发指南](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-cloudhosting-introductions-0000001057944575)。

## 前提条件

* 您已[创建项目](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createproject-0000001100334664)。
* 您已在项目下[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已在项目下[开通云托管服务](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-cloudhosting-storageservice-0000001151060236)。
* 开通服务时，请确保您为云存储和云托管服务设置了相同的[默认数据处理位置](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-datalocation-0000001160439813#section154810363471)。
* 如您修改了云托管服务的默认数据处理位置，云托管原始项目会被删除，无法恢复。因此，不建议您修改云托管服务的默认数据处理位置。
* 您已创建存储实例：
  * 云存储服务启用成功后，即自动创建一个默认存储实例。
  * 如您需创建新的存储实例，请先[升级到付费档](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-service-billing-0000001058092595#section1337763420106)，然后参考[新增存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-manage-bucket-0000001281294006#section1583519552428)进行操作。
* 云托管每天每个项目下所有域名资源的CDN访问流量免费限额为360MB。如需更多访问流量，需要[开通企业开发者账号](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-getstarted-0000001100316670#section27844983310)并升级到按量付费套餐，详见[云托管服务定价](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-cloudhosting-charge-0000001058890686)。

## 配置资源目录的匿名访问权限

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击您的项目。
3. 选择"云开发（Serverless） > 云存储"，进入云存储页面。
4. 选择"安全"页签，进入"配置策略"页面。
5. 在编辑框内配置当前存储实例下某个目录的匿名访问权限，点击"发布"。

   其中，"*your-bucket-name* "指存储实例名称，"*your-bucket-name/foo/bar* "为存储实例下某一目录的名称。如不指定目录，则表示可访问该存储实例下的所有目录。

   ```screen
   agc.cloud.storage[ 
       match: /your-bucket-name/foo/bar/{path=**} { 
           allow read; 
       } 
   ]
   ```

## 开启静态CDN加速

1. 在云存储页面，进入"配置"页签，打开静态CDN加速开关。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251202143405.62897790684905385096803613433473:50001231000000:2800:5AFEAB9CA30145B8631B5A80641654CC829F5C4FBFEF85AD00B79E69B364347D.png)

2. 在弹出提示框中点击"确定"，进入云托管服务的存储加速页面。

## 创建加速域名

创建加速域名并关联存储实例，详细步骤请参见[管理域名](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-cloudhosting-createdomain-0000001196068089)。

## 获取资源文件的静态CDN加速地址

进入云存储页面，在资源文件的"操作"列点击"详情"，在弹出的"提示"窗口，复制文件的静态CDN加速地址。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251202143405.35865521654641676878026788656312:50001231000000:2800:0E191FEF671E9376CB9CED310CC1A7329A19AC91EAA3976CF3222B3FF2663547.png "点击放大")

## 下载资源文件

打开浏览器，将复制的资源文件地址粘贴至地址栏，即可直接访问下载该资源文件。
