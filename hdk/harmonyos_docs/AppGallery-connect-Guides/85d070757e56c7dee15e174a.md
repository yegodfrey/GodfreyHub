# 监听RTM连接状态

当玩家登录、登出或者网络连接发生变化时，RTM连接状态会发生改变。因此，为了保证消息收发顺畅，需实时监听RTM的连接状态变化，确保RTM处于连接状态。

## 前提条件

* 您已[集成游戏多媒体基础SDK和实时信令模块](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-integratingsdk-android-0000001250838246#ZH-CN_TOPIC_0000001250838246__li733912204487)。
* 您已[创建游戏多媒体实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-engine-android-0000001193958984#section1093713161034)。

## 开发步骤

在IGameMMEEventHandler接口的[onRtmConnectionChanged](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section201911337583)回调方法中，可监听RTM连接状态的变化。

```screen
@Override
public void onRtmConnectionChanged(RtmConnectionStatusNotify notify) {
  // 可根据需求将数据进行处理
}
```
