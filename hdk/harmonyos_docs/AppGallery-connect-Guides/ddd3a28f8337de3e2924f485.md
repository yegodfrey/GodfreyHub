# 账号重认证

## 前提条件

* 您需要在AGC控制台[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-integration-sdk-0000001326347605)。

## 开发步骤

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114607.34283085903545612834279938860444:50001231000000:2800:7EC79C1BA5ADCDD13AC1B2E8506E0A28A32241EE69EE6CF4587E5A34505CCF89.png "点击放大")

对于销户、修改密码、关联账号以及重置手机账号和邮箱账号这些敏感操作，要求用户必须在5分钟内登录过才能执行。如果您执行敏感操作时已经登录超过5分钟，将会收到错误码为203818081的错误，这种情况下您可以先调用[[AGCUser reauthenticate:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcuser-ios-0000001054822348#section133141345203110)重认证账号后再执行敏感操作。

```screen
"Objective-C"
[[[[[AGCAuth getInstance] currentUser] reauthenticate:credential] addOnSuccessCallback:^(AGCSignInResult * _Nullable result) {
         // onSuccess
         AGCUser *user = result.user;
     }] addOnFailureCallback:^(NSError * _Nonnull error) {
         // onFail
     }];
```

```screen
"Swift"
AGCAuth.instance().currentUser?.reauthenticate(credential).onSuccess{ (result) in
    // onSuccess
}.onFailure{ (error) in
    // onFailure
}
```
