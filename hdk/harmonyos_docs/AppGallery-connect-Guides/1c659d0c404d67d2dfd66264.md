# 集成SDK

SDK名称：Petal Aegis HarmonyOS SDK

包名：@hw-agconnect/petal-aegis

版本号：1.4.11-300

md5值：55d0ac524d12c7844b2b3fafa7c56b2f

开发者：华为技术有限公司

隐私政策：[SDK隐私声明](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/aegis-sdksecurity-0000001865955177)

合规指引：[SDK合规使用指南](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/aegis-sdkguidelines-0000001819355436)

主要功能：提供丰富的加解密算法，如：哈希算法、消息认证码算法、对称加解密算法、非对称加解密算法、签名验签算法等  

#### 开发前准备

* 安装HUAWEI DevEco Studio 5.0.1.700及以上版本，推荐安装最新版本DevEco Studio

<!-- -->

* 配置 SDK API Version 12及以上
  * Compile SDK Version 12及以上
* Compatible SDK Version 12及以上  

#### 接口设计约束条件

* 已开放的接口不允许删除。
* 所有版本需要指定验证使用的API SDK版本。
* 前后版本的相同接口需要兼容。
* 新功能上线前需要经过功能测试和安全测试。
* 对外提供的接口满足安全规范要求。  

#### 配置SDK依赖

您需要在DevEco Studio项目中配置SDK依赖。

Aegis的OpenHarmony三方库中心仓地址为[@hw-agconnect/petal-aegis](https://ohpm.openharmony.cn/#/cn/result?sortedType=relevancy&page=1&q=petal-aegis)，您可以通过以下任意一种方式配置SDK依赖。  
![](https://media:201778650562285793)  
hsp集成暂不推荐使用1.4.9-300，推荐使用1.4.7-301。  

#### 方式一

1. 打开DevEco Studio应用级（一般为entry）下的"oh-package.json5"文件。 ![](https://media:201778650562319794 "点击放大")

2. 在"oh-package.json5"文件的"dependencies"中添加Aegis的SDK依赖。

   ```
   "dependencies": {
     "@hw-agconnect/petal-aegis": "1.4.9-300"
   }
   ```

3. 打开修改完的"oh-package.json5"文件，右上方出现"Sync Now"链接，点击"Sync Now"等待同步完成。 ![](https://media:201778650562361795 "点击放大")

#### 方式二

1. 打开您的工程，在命令行窗口执行cd entry命令，切换到工程的"entry"目录。 ![](https://media:201778650562391796)

2. 安装SDK到您的项目中。

   ```
   ohpm install @hw-agconnect/petal-aegis
   ```

#### 集成SDK

1. 在您的项目中导入相关功能（以SHA256哈希算法为例）。

   ```
   import { AegSha256 } from '@hw-agconnect/petal-aegis';
   ```

2. 调用ohAegSha256Text对字符串'hello world'进行消息摘要计算。

   ```
   function SHA256() {
     let input = 'hello world';
     AegSha256.ohAegSha256Text(input).then((data) => {
       console.log("execute", 'data: ' + data);
     }).catch((err) => {
       console.log("execute", 'err: ' + err);
     })
   }
   ```

![](https://media:201778650562435797)  
* 工程的应用框架必须为Stage模型，即"apiType"配置为"stageMode"。
* Stage模型仅Compile API版本为12及以上支持，请确保SDK的Compile API版本不低于12。
* 请确保采用ohpm方式编译。
* SDK也支持开发OpenHarmony应用（API 12及以上版本）。
