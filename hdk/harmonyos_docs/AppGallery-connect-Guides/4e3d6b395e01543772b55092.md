# 业务介绍

渠道包是通过物理分包的方式来做渠道效果归因的方法。渠道包与在应用市场上架的主包包名一致，只是开发者可以基于不同的分发渠道在包内预置上不同的渠道号，并在不同的渠道上进行投放，同时使用应用市场的下载能力，以达到归因和高转化率分发的目的。

渠道包支持普通渠道包和极小渠道包。普通渠道包仅用于区分不同渠道，与主包功能一致。而极小渠道包一般基于主包做了功能剪裁、具有应用的核心功能，既有归因的作用，也能快速分发。在新增极小渠道包时，系统会默认第一个渠道的极小渠道包为参照包，待参照包通过审核之后，其他渠道的极小渠道包以参照包为基准，可快速进行自动化审核。

渠道包支持主包的多包形态，多包的区分维度包括：CPU架构（32/64位）、屏幕密度/尺寸和HMS/GMS依赖。
