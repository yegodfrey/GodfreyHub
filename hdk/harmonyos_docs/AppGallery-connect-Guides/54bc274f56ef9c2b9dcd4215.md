# 导入Package

## 前提条件

已前往[下载地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Library/ailod-sdk-0000002476766086)下载AILOD Package。

## 操作步骤

1. 在团结Hub中打开您的游戏工程。
2. 进入团结Editor，在顶部菜单栏选择"Window > Package Manager"，在弹出的"Package Manager"窗口上，点击"Add package from disk"，将已下载的AILOD Package导入您的游戏工程。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110238.41403862144008293803255125049632:50001231000000:2800:34BE77A38709EDC9BED0D13997C1A7E9C1DC932067B506161D63EB199A56948C.png)
