# 自定义崩溃报告

有些崩溃问题，仅通过崩溃报告中的堆栈、环境（比如设备、网络）信息不能快速定位，需要了解更多应用内的数据。为了帮助您全面了解崩溃报告信息，AGC崩溃提供了三种自定义报告记录机制：[用户标识符](#section863412131119)、[日志](#section445094914919)、[键值对](#section381434111610)。  

#### 前提条件

1. 您需要在AGC控制台[开通崩溃服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-enableservice-0000001326330021)。
2. 您需要在您的应用中[集成崩溃服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-integratesdk-android-0000001275810158)。  

#### 自定义崩溃报告

#### 添加自定义用户标识符

为了定位某个问题，了解哪些用户遇到了特定的崩溃通常很有帮助。您可以通过设置自定义用户标识符，以匿名的方式为用户分配用户标识符，作为用户的唯一标识符。

1. 调用[AGConnectCrash.getInstance()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-android-0000001055420438#section743716146324)获取AGConnectCrash实例。
2. 调用[AGConnectCrash.getInstance().setUserId()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-android-0000001055420438#section742711611129)设置用户标识符。  

   ```
   "Java"
   AGConnectCrash.getInstance().setUserId("12345");
   ```

   ```
   "Kotlin"
   AGConnectCrash.getInstance().setUserId("12345")
   ```

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155604.40607939859145829857026747086678:50001231000000:2800:F50F9C3E017F002A386E48E291E89FDFAB4B906F5953CEB27BEB45CEA01E376F.png)  
* 设置的用户标识符长度上限为1KB，超过会被截断。
* 如果重复设置，会以最后一次的设置为准。

用户标识符的生命周期是从本次启动到本次发生崩溃为止。应用重启之后，会重新读取您的设置。如果需要清除某个用户标识符，可将该值重置为空字符串，清除用户标识符不会移除现有的崩溃记录。

崩溃发生后，您可在AGC上根据用户标识符查询具体崩溃问题，详情可参见[根据用户标识符获取](#section194801788188)。  

#### 添加自定义日志

为了获取导致崩溃的更多背景信息，您可通过添加自定义日志随相关联的崩溃数据一同上报，并在AGC上获取包含自定义日志的崩溃报告。您可通过以下两种方法添加自定义日志。

* 使用系统默认日志级别 您可通过调用[AGConnectCrash.getInstance()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-android-0000001055420438#section743716146324)获取AGConnectCrash实例，然后调用[AGConnectCrash.getInstance().log(String message)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-android-0000001055420438#section111927396208)来记录日志信息，日志级别将默认记录为Log.INFO级别。

  ```
  "Java"
  AGConnectCrash.getInstance().log("set info log.");
  ```

  ```
  "Kotlin"
  AGConnectCrash.getInstance().log("set info log.")
  ```

<!-- -->

* 自定义日志级别 您可通过调用[AGConnectCrash.getInstance()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-android-0000001055420438#section743716146324)获取AGConnectCrash实例，然后调用[AGConnectCrash.getInstance().log(int level, String message)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-android-0000001055420438#section040211331616)来记录日志信息并自定义日志级别。

  ```
  "Java"
  AGConnectCrash.getInstance().log(Log.WARN, "set warn log.");
  ```

  ```
  "Kotlin"
  AGConnectCrash.getInstance().log(Log.WARN, "set warn log.")
  ```

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155604.35200549230541051261964703391976:50001231000000:2800:F9D79DCC486D76D4DFB4D0CAA8633BD32719C13011739E26C513B21A8781723A.png)  
* 为避免影响您应用的性能，AGC将日志总大小限制为不超过64KB。如果超过该限制，则会删除最早的日志条目。
* 为了尽可能多地记录日志条目，AGC限制单条日志的大小不要超过4KB，超过会进行截断。

考虑到有些崩溃可能会是多次重启之后才会出现，为了尽可能地为您保留更多的有用信息，因此设置自定义日志的生命周期为从上次发生崩溃到本次发生崩溃为止，当发生崩溃以后，会在日志上报后再删除上一个生命周期上报的日志。

崩溃发生后，您可在AGC上根据日志级别筛选日志记录，详情可参见[根据自定义日志获取](#section20124906485)。  

#### 添加自定义键值对

为了获取崩溃发生时应用的特定状态，您可通过添加自定义键值对获取状态记录，状态会与相关联的崩溃数据一起上报。

1. 调用[AGConnectCrash.getInstance()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-android-0000001055420438#section743716146324)获取AGConnectCrash实例。
2. 调用[AGConnectCrash.getInstance().setCustomKey()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-android-0000001055420438#section09568741214)添加自定义键值对。根据键值对中的value值类型不同，您可通过以下六种示例方法添加自定义键值对。  

   ```
   "Java"
   // 添加string类型的键值对
   AGConnectCrash.getInstance().setCustomKey("stringKey", "world");

   // 添加boolean类型的键值对
   AGConnectCrash.getInstance().setCustomKey("booleanKey", false);

   // 添加double类型的键值对
   AGConnectCrash.getInstance().setCustomKey("doubleKey", 1.1);

   // 添加float类型的键值对
   AGConnectCrash.getInstance().setCustomKey("floatKey", 1.1f);

   // 添加int类型的键值对
   AGConnectCrash.getInstance().setCustomKey("intKey", 0);

   // 添加long类型的键值对
   AGConnectCrash.getInstance().setCustomKey("longKey", 11L);
   ```

   ```
   "Kotlin"
   // 添加string类型的键值对
   AGConnectCrash.getInstance().setCustomKey("stringKey", "world");

   // 添加boolean类型的键值对
   AGConnectCrash.getInstance().setCustomKey("booleanKey", false);

   // 添加double类型的键值对
   AGConnectCrash.getInstance().setCustomKey("doubleKey", 1.1);

   // 添加float类型的键值对
   AGConnectCrash.getInstance().setCustomKey("floatKey", 1.1f);

   // 添加int类型的键值对
   AGConnectCrash.getInstance().setCustomKey("intKey", 0);

   // 添加long类型的键值对
   AGConnectCrash.getInstance().setCustomKey("longKey", 11L);
   ```

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155604.58668683568670167053140209214168:50001231000000:2800:89C5E5FFD20EC9C5B7A23BC151D03A59549B84641F5FA2811A2475C4B25325ED.png)  
* 最多可支持64组键值对，超过后不再保存更多的值。
* 每组键值对的key最长为1KB，value最长为1KB，超过会被截断。

同一个key支持重复设置，以最后一次设置的value值为准。设置的键值对的生命周期是从本次启动到本次发生崩溃为止。应用重启之后，会重新读取您的设置。

崩溃发生后，您可在AGC上获取应用及用户的状态，详情可参见[根据自定义键值对获取](#section16146512101214)。  

#### 获取自定义崩溃报告

#### 根据用户标识符获取

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中点击您的应用。
3. 在左侧导航栏选择"质量 \> 崩溃"。
4. 选择"按用户搜索"，在搜索框输入用户标识符进行搜索，可快速定位该用户遇到的特定的崩溃问题。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155604.00702258108741491060928672669288:50001231000000:2800:ED8DE0D3FCBADB285C0A849E7B6B29CC053A988F40C966BBE5A9572A2CAF9746.png)

5. 在列表的"问题"列点击具体的崩溃问题，通过右上角的时间设置，可查看指定时间范围内该用户累计发生的崩溃次数以及每一次的崩溃详情。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155604.89785219107131968887024663896772:50001231000000:2800:2B3C38074494D44C5A9BBA77BC57E334D9664E0F0DDA7E4732E884F647D17563.png)

#### 根据自定义日志获取

1. 选择"问题"，在列表的"问题"列点击您的崩溃问题。
2. 选择"日志"，可通过选取日志级别和在搜索框输入关键词的方式进行双重过滤，快速查找崩溃发生前的日志详情。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155604.60589697953076695522387793200981:50001231000000:2800:5C14D82B03B962DE2B08E550A2B478404DFBD01D2BBE661FB2FF45792A88BC0F.png)

#### 根据自定义键值对获取

1. 选择"问题"，在列表的"问题"列点击您的崩溃问题。
2. 选择"状态"，可通过在搜索框输入关键词，了解崩溃发生前后应用及用户的状态，以进一步评估此次崩溃发生给用户带来的影响。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155604.25058828416072972590064245224092:50001231000000:2800:AAD44F074DC0522CC5267A3F47A823B11D20F6B61C765B4F0C8E65EC677E4F36.png)
