# 发布正式版本

应用文件信息补充完整后，您可以提交应用发布，发布成功后您的应用将会在AppGallery中上架。目前Publishing API支持以下两种应用发布方式：

* 直接提交发布：应用软件包上传到华为服务器，华为服务器直接使用服务器中的文件提交发布。
* 通过下载方式提交发布：应用软件包保存在开发者服务器中，华为服务器从开发者服务器下载应用软件包后提交发布。

## 前提条件

* 调用Publishing API前请确认已经完成[使用入门](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114)中的服务端授权。
* 您已[配置应用信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-add_appinfo-0000001111845350)。
* 如果选择直接提交发布方式，您需要先参考[上传应用文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-upload-file-new-0000001111845090)上传应用资源文件（如应用图标、应用介绍截图、推荐视频等）和应用软件包。如果您选择通过下载方式提交发布，您需要先参考[上传应用文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-upload-file-new-0000001111845090)上传应用资源文件。

## 直接提交发布

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250716103230.21325831064161179056468020260825:50001231000000:2800:0401483811CAFE91FA35B660BD78A948B2D303C41A76167E2FF965CDA3F799BF.png)

当您完成[配置应用信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-add_appinfo-0000001111845350)、[上传应用资源文件和软件包](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-upload-file-new-0000001111845090)、[更新应用文件信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-file-info-0000001111685202)后，您可以调用[提交发布](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-submit-0000001158245061)接口提交发布请求。如您需指定版本的上架时间，可以调用[更新版本上架时间](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-update-releasetime-0000001158365053)接口。
> 说明
>
> 软件包采用异步解析方式，请您在传包后等候2分钟再调用提交发布接口提交发布请求。

```screen
public static void submit(String domain,String clientId, String token, String appId){
    HttpPost put = newHttpPost(domain + "/publish/v2/app-submit?appid="+ appId);

    put.setHeader("Authorization", "Bearer "+ token);
    put.setHeader("client_id", clientId);

    try{
        CloseableHttpClient httpClient = HttpClients.createDefault();
        CloseableHttpResponse httpResponse = httpClient.execute(put);
        intstatusCode = httpResponse.getStatusLine().getStatusCode();
        if(statusCode == HttpStatus.SC_OK) {
            BufferedReader br =
                newBufferedReader(newInputStreamReader(httpResponse.getEntity().getContent(), Consts.UTF_8));
            String result = br.readLine();

            JSONObject object = JSON.parseObject(result);
            System.out.println(object.get("ret"));
        }
    } catch(Exception e) {

    }
}
```

如果您使用了[应用签名](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-appsigning-introduction-0000001051379577)服务，更新应用文件信息后AppGallery Connect会对软件包进行编译，如果软件包还未编译完成就提交发布会返回204144660错误码。

* 如果您的软件包是AAB包，您在调用[更新应用文件信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-file-info-0000001111685202)接口时可以在FileInfo中传入pkgVersion，根据pkgVersion可以调用[查询软件包编译状态](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-query-aabfile-0000001111685206)接口，确认软件包编译完成后再提交发布。
* 如果您的软件包不是AAB包，您可以在返回204144660错误码后间隔一段时间后再次尝试提交发布。

## 通过下载方式提交发布

> 注意
>
> 非中国大陆开发者如果需要通过下载方式提交发布，应用发布地区需包含中国大陆。中国大陆开发者无限制。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250716103230.99042245559017834875025636674981:50001231000000:2800:5BE786A56C0F04126C21F41F888B23F49BFCD6968A18BDADA7DC09D42D27897A.png)

如果您的应用文件和软件包保存在自己的服务器中，您可以先完成[配置应用信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-add_appinfo-0000001111845350)、[上传应用资源文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-upload-file-new-0000001111845090)、[更新应用文件信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-file-info-0000001111685202)，再调用[通过下载方式提交发布](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-submit-with-file-0000001111845092)接口通知华为服务器从您的服务器中下载应用的软件包后再启动发布，您必须在接口中传入您的软件包下载地址。
> 说明
>
> 如果您不想在华为服务器下载软件包后立即发布，您可以先调用[通过下载方式提交软件包](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-add-packageurl-0000001158245065)接口将软件包提交到华为服务器，待确定需要发布时再调用[提交发布](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-submit-0000001158245061)接口发布应用。

```screen
public static void  releaseAppByDownload(String domain,String clientId, String token, String appId){
	HttpPost put = new HttpPost(domain + "/publish/v2/app-submit-with-file?appid=" + appId);

	put.setHeader("Authorization", "Bearer " + token);
	put.setHeader("client_id", clientId);

	JSONObject keyString = new JSONObject();
	keyString.put("downloadUrl", "www.testurl.com"); //replace by your actual url
	keyString.put("downloadFileName", "testfile"); //replace by your actual file name
	keyString.put("requestId", "1");

	StringEntity entity = new StringEntity(keyString.toString(), Charset.forName("UTF-8"));
	entity.setContentEncoding("UTF-8");
	entity.setContentType("application/json");
	put.setEntity(entity);

	try {
		CloseableHttpClient httpClient = HttpClients.createDefault();
		CloseableHttpResponse httpResponse = httpClient.execute(put);
		int statusCode = httpResponse.getStatusLine().getStatusCode();
		if (statusCode == HttpStatus.SC_OK) {
			BufferedReader br =
					new BufferedReader(new InputStreamReader(httpResponse.getEntity().getContent(), Consts.UTF_8));
			String result = br.readLine();

			JSONObject object = JSON.parseObject(result);
			System.out.println(object.get("ret"));
		}
	} catch (Exception e) {

	}
}
```

应用发布成功后华为服务器会通过[回调结果通知](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-notify-release-0000001158245063)接口通知您的服务器，此通知消息中带有签名字符串（**signatureRSAWithPSS** 参数），您需要对签名字符串进行验签以确认消息准确性。验签需要使用验签公钥，验签公钥获取方法请参见[获取验签公钥](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-gettestkey-0000001158245081)。验签示例如下：

```screen
/*
@content 待验签字符串，传入callBackData中携带的JSON字符串
@sign  签名字符串
*/
private static void verifySignature(String content, String sign) {
        try{
            String pubKey = configService.getString(ConfigConstants.PUBLIC_KYE_VEVIFY_MODAPP);
            X509EncodedKeySpec x509EncodedKeySpec = newX509EncodedKeySpec(Base64.decodeBase64(pubKey));
            KeyFactory keyFactory = KeyFactory.getInstance("RSA");
            PublicKey publicKey = keyFactory.generatePublic(x509EncodedKeySpec);
            Signature signature = Signature.getInstance("SHA256WithRSA");
            signature.initVerify(publicKey);
            signature.update(content.getBytes(Charset.forName("UTF-8")));
            if(!signature.verify(Base64.decodeBase64(sign))) {
                thrownewConnectException(EnumReturnCode.INVALID_PARAMETER, "Failed to verifySignature");
            }
        } catch(NoSuchAlgorithmException | SignatureException | InvalidKeyException | InvalidKeySpecException e) {
            LOG.error("verify signature failed", e);
            thrownewConnectException(EnumReturnCode.INVALID_PARAMETER, "Failed to verifySignature");
        } catch(Exception e) {
            LOG.error("verify signature failed", e);
            thrownewConnectException(EnumReturnCode.INVALID_PARAMETER, "Failed to verifySignature");
        }
}
```
