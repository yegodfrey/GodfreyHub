# 列举文件

列举文件是指获取某个目录下的所有文件和目录信息，云存储SDK支持通过API列举云端某个目录下的所有文件或子目录。

## 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[初始化存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-initialize-bucket-harmonyos-tsapi6-0000001604393605)。

## 操作步骤

1. 在列举某个目录下的文件或目录前，先调用[StorageManagement.storageReference](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-tsapi6-storage-storagemanagement-0000001553635818#section13963124903819)创建目录的引用。例如创建根目录的引用：

   ```screen
   var reference = storageManagement.storageReference();
   ```

2. 调用[StorageReference.listAll](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-tsapi6-storage-storagereference-0000001553476194#section51714428108)可获取当前目录下所有文件与目录。

   ```screen
   reference.listAll()
   .then((res) => {
     
     var fileList = res.getFileList();
     var dirList = res.getDirList();
   })
   .catch((err) => {});
   ```

   如果需要分页获取，可以调用[StorageReference.listByMarker](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-tsapi6-storage-storagereference-0000001553476194#section10491155545613)方法。

   ```screen
   // pageMarker是获取分页列表信息时下一页的起始位置
   reference.listByMarker(10, "0")
   .then((res)=>{})
   .catch((err) => {});
   ```
