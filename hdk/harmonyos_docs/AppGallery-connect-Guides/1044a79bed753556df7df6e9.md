# 在iOS应用中接收聚合链接

用户点击收到的聚合链接后跳转到应用对应的内容时，您可在应用客户端调用聚合链接SDK的API接收用户点击的聚合链接，以获取聚合链接中传递的数据。在iOS应用客户端，当用户点击聚合链接时，聚合链接支持Universal Link和自定义Scheme两种方式跳转。

## 前提条件

* 您已成功[申请链接前缀](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-urlprefix-0000001060148052)。
* 您的应用已[集成聚合链接SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-ios-integrationsdk-0000001372935825)。

## 配置支持Universal Link

Universal Link是iOS 9开始支持的可以无缝跳转到应用内部的链接。您只需要进行如下简单的配置，聚合链接即可支持在iOS应用中实现Universal Link方式跳转。

1. 生成聚合链接域名的资产校验文件。

   登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择您的应用，前往"项目设置 > 常规"的"应用"区域，点击"团队ID"对应的![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250715120026.72574205486879399102496007319596:50001231000000:2800:3CFDB790965DC0D91139F92E27D34C9FF52960B6E2CF033F401B81E4D9896311.png)配置您在App Store上的团队ID，配置完成后AGC会为默认域名自动生成资产校验文件。
   > 说明
   >
   > 资产校验文件生成后，您可前往"https://**your_applinking_url_prefix** /apple-app-site-association"查看，**your_applinking_url_prefix**为您在AGC上申请的域名地址。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250715120026.02890517331111006004666083963903:50001231000000:2800:629C3B8B1C30A50913EA0C97C7E30EBA2BFF34A059D3A3EDC1071F54BD36CA8A.png)
2. 声明iOS应用关联的域名。 在应用的Xcode项目的Signing&Capabilities标签页中，添加Associated Domain功能，并在Domains中添加要支持的域名，格式为"applinks:**your_applinking_url_prefix** "，**your_applinking_url_prefix**为您在AGC上申请的域名地址。

## 配置自定义Scheme

如果需要在iOS应用中支持通过自定义Scheme方式打开聚合链接，除了需要在创建聚合链接时在iOS的深度链接地址中进行配置自定义Scheme，同时还需要在应用Xcode项目Info标签页下的URL Types中增加URL Schemes配置，配置您的自定义Scheme。

## 接收聚合链接

1. 在AppDelegate.m文件中添加声明，并在系统的启动方法中初始化AGC SDK。

   ```screen
   "Objective-C"
   #import <AGConnectCore/AGConnectCore.h> 
   #import <AGConnectAppLinking/AGConnectAppLinking.h>

   @implementation AppDelegate
   - (BOOL)application:(UIApplication *)application didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {
        // Override point for customization after Application launch.
       [AGCInstance startUp];//初始化
        return YES;
   }
   ...
   @end
   ```

   ```screen
   "Swift"
   import AGConnectCore
   import AGConnectAppLinking

   @UIApplicationMain
   class AppDelegate: UIResponder, UIApplicationDelegate {

       var window: UIWindow?

       func application(_ application: UIApplication, didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?) -> Bool {
           // Override point for customization after application launch.
         AGCInstance.startUp()
           return true
       }
   }
   ```

2. 在系统启动方法中调用[[AGCAppLinking sharedInstance]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinking-0000001054453655#section369317389517)获取单例对象。
3. 在[[AGCAppLinking handleAppLinking]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinking-0000001054453655#section1214933519521)回调方法中处理接收到的聚合链接事件。
   * 如果应用使用UISceneSession来管理生命周期（iOS 13以后支持），则需要在SceneDelegate.m编辑相关代码。

     ```screen
     "Objective-C"
     - (void)scene:(UIScene *)scene willConnectToSession:(UISceneSession *)session options:(UISceneConnectionOptions *)connectionOptions { 
          // Use this method to optionally configure and attach the UIWindow `window` to the provided UIWindowScene `scene`. 
          // If using a storyboard, the `window` property will automatically be initialized and attached to the scene. 
          // This delegate does not imply the connecting scene or session are new (see `application:configurationForConnectingSceneSession` instead). 
          if (connectionOptions.URLContexts.count > 0 && connectionOptions.URLContexts.allObjects.firstObject) { 
              [[AGCAppLinking sharedInstance] openDeepLinkURL:connectionOptions.URLContexts.allObjects.firstObject.URL]; 
          } 
          [[AGCAppLinking sharedInstance] handleAppLinking:^(AGCResolvedLink * _Nullable link, NSError * _Nullable error) { 
              if (link) { 
                 NSString *deepLink = link.deepLink; 
                //TODO: App针对deepLink进行跳转 
              } 
          }]; 
     }
     ```

     ```screen
     "Swift"
     func scene(_ scene: UIScene, willConnectTo session: UISceneSession, options connectionOptions: UIScene.ConnectionOptions) {        
          // Use this method to optionally configure and attach the UIWindow `window` to the provided UIWindowScene `scene`.        
          // If using a storyboard, the `window` property will automatically be initialized and attached to the scene.        
          // This delegate does not imply the connecting scene or session are new (see `application:configurationForConnectingSceneSession` instead).        
          guard let _ = (scene as? UIWindowScene) else { return }        
          guard connectionOptions.URLContexts.count > 0 else { return }        
          if let url = connectionOptions.URLContexts.first?.url {            
               AGCAppLinking.instance().openDeepLinkURL(url)        
          }                
          AGCAppLinking.instance().handle { (link, error) in            
               let deepLink = link?.deepLink            
               //TODO: 增加deeplink地址跳转        
          }
     }
     ```

   * 如果应用中未使用UISceneSession管理应用生命周期，则需要在AppDelegate.m编辑相关代码。

     ```screen
     "Objective-C"
     - (BOOL)application:(UIApplication *)application didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {
          // Override point for customization after Application launch.
          [AGCInstance startUp];//初始化
          [[AGCAppLinking sharedInstance] handleAppLinking:^(AGCResolvedLink * _Nullable link, NSError * _Nullable error) {
             if (link) {
                 NSString *deepLink = link.deepLink;
                 //TODO: App针对deepLink进行跳转
             }
          }];
          return YES;
     }
     ```

     ```screen
     "Swift"
     import AGConnectCore
     import AGConnectAppLinking

     @UIApplicationMain
     class AppDelegate: UIResponder, UIApplicationDelegate {

         var window: UIWindow?

         func application(_ application: UIApplication, didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?) -> Bool {
             // Override point for customization after application launch.
             AGCInstance.startUp()
             AGCAppLinking.instance().handle { (link, error) in
                 let deepLink = link?.deepLink
                 //TODO: 增加deeplink地址跳转
             }
             return true
         }
     }
     ```

4. 判断接收到的链接是否是聚合链接的链接，并返回App是否可以处理此链接。
   * 对于Universal Link方式，需要根据您的应用中是否使用UISceneSession管理应用生命周期进行不同的处理。
     * 如果应用使用UISceneSession来管理生命周期（iOS 13以后支持），则需要在SceneDelegate.m编辑相关代码。 在**scene: continueUserActivity:** 方法中先调用[[AGCAppLinking sharedInstance]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinking-0000001054453655#section369317389517)方法获取单例对象，再调用[[AGCAppLinking continueUserActivity]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinking-0000001054453655#section10782195545718)方法处理接收到的Universal Link形式的链接。

       ```screen
       "Objective-C"
       - (void)scene:(UIScene *)scene continueUserActivity:(NSUserActivity *)userActivity {
           [[AGCAppLinking sharedInstance] continueUserActivity:userActivity];
       }
       ```

       ```screen
       "Swift"
       func scene(_ scene: UIScene, continue userActivity: NSUserActivity) {
               AGCAppLinking.instance().continueUserActivity(userActivity)
           }
       ```

     * 如果应用中未使用UISceneSession管理应用生命周期，在**application: continueUserActivity: restorationHandler:** 方法中先调用[[AGCAppLinking sharedInstance]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinking-0000001054453655#section369317389517)方法获取单例对象，再调用[[AGCAppLinking continueUserActivity]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinking-0000001054453655#section10782195545718)方法处理接收到的Universal Link形式的链接。

       ```screen
       "Objective-C"
       - (BOOL)application:(UIApplication *)application continueUserActivity:(NSUserActivity *)userActivity restorationHandler:(void (^)(NSArray<id<UIUserActivityRestoring>> * _Nullable))restorationHandler {
           BOOL isAppLinking = [[AGCAppLinking sharedInstance] continueUserActivity:userActivity];
           return isAppLinking;
       }
       ```

       ```screen
       "Swift"
       func application(_ application: UIApplication, continue userActivity: NSUserActivity, restorationHandler: @escaping ([UIUserActivityRestoring]?) -> Void) -> Bool {
               let isAppLinking = AGCAppLinking.instance().continueUserActivity(userActivity)
               return isAppLinking
           }
       ```


   * 对于自定义Scheme方式，也需要根据您的应用中是否使用UISceneSession管理应用生命周期进行不同的处理。
     * 如果应用使用UISceneSession来管理生命周期（iOS 13以后支持），则需要在SceneDelegate.m编辑相关代码。 建议您在**scene: openURLContexts:** 方法中先调用[[AGCAppLinking sharedInstance]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinking-0000001054453655#section369317389517)方法获取单例对象，再调用[[AGCAppLinking openDeepLinkURL]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinking-0000001054453655#section4134258105420)方法处理接收到的自定义Scheme链接。

       ```screen
       "Objective-C"
       - (void)scene:(UIScene *)scene openURLContexts:(NSSet<UIOpenURLContext *> *)URLContexts {
           if (URLContexts.count > 0 && URLContexts.allObjects.firstObject) {
               [[AGCAppLinking sharedInstance] openDeepLinkURL:URLContexts.allObjects.firstObject.URL];
           }
       }
       ```

       ```screen
       "Swift"
       func scene(_ scene: UIScene, openURLContexts URLContexts: Set<UIOpenURLContext>) {
               guard URLContexts.count > 0 else {
                   return
               }
               if let url = URLContexts.first?.url {
                   AGCAppLinking.instance().openDeepLinkURL(url)
               }
           }
       ```

     * 如果应用中未使用UISceneSession管理应用生命周期，在**application: openURL: options:** 方法中先调用[[AGCAppLinking sharedInstance]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinking-0000001054453655#section369317389517)方法获取单例对象，再调用[[AGCAppLinking openDeepLinkURL]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinking-0000001054453655#section4134258105420)处理接收到的自定义Scheme链接。

       ```screen
       "Objective-C"
       - (BOOL)application:(UIApplication *)app openURL:(NSURL *)url options:(NSDictionary<UIApplicationOpenURLOptionsKey,id> *)options {
           BOOL isAppLinking = [[AGCAppLinking sharedInstance] openDeepLinkURL:url];
           return isAppLinking;
       }
       ```

       ```screen
       "Swift"
       func application(_ app: UIApplication, open url: URL, options: [UIApplication.OpenURLOptionsKey : Any] = [:]) -> Bool {
               let isAppLinking = AGCAppLinking.instance().openDeepLinkURL(url)
               return isAppLinking
           }
       ```
