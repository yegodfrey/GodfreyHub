# 停用APM性能监控

在开发和调试应用过程中，您可能需要停用APM性能监控。下面是停用APM性能监控的两种方式：

* [在AGC远程配置停用](#section1101mcpsimp)：您可以灵活地在正式版应用中停用（或重新启用）APM性能监控。
* [在应用客户端停用](#section1119mcpsimp)：APM SDK提供性能采集接口，您在客户端上可以选择是否启用APM性能监控。

#### 在AGC远程配置停用

如果您想对已发布的应用停用APM性能监控，可以利用远程配置（如果您没有开通远程配置服务，请参见[开通服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-remoteconfig-enable-service-0000001276051134)）来完成。停用后，应用下次启动时便不再采集应用性能数据。您可以采用下面2种方式停用性能监控：

* 方式一：设置是否上报性能数据总开关，默认是打开状态，关闭状态下所有版本不上报性能数据。 具体步骤如下：

  <!-- -->

  2. 关闭总开关。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240618143023.84779103093639228765989308660116:50001231000000:2800:B187525E2711EA9ADD191F86A88EED5B3BBB6D0D8AE61674DDB3140546EDE118.png?needInitFileName=true?needInitFileName=true)

* 方式二：添加禁用性能数据上报的应用版本。

#### 在应用客户端停用

APM SDK提供[- (void) enableCollection:(BOOL enable)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/apm-ios-0000001052578149#section114411012716)接口，允许用户启用/停用性能监控。接口调用具体流程如下：

1. 调用[getInstance](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/apm-ios-0000001052578149#section13938125014264)初始化。
2. 调用[enableCollection](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/apm-ios-0000001052578149#section114411012716)停用或开启。

参考代码如下：

* 停用APM：

  ```
  UIButton *disableButton = [UIButton buttonWithType:UIButtonTypeRoundedRect];
  [disableButton addTarget:self action:@selector(disableAPM) forControlEvents:UIControlEventTouchUpInside];
   
  - (void) disableAPM {enableCollection
     [[AGCAPM getInstance] enableCollection:NO];
  }
  ```

* 启用APM：

  ```
  UIButton *enableButton = [UIButton buttonWithType:UIButtonTypeRoundedRect];
  [enableButton addTarget:self action:@selector(enableAPM) forControlEvents:UIControlEventTouchUpInside];
   
  - (void) enableAPM {
     [[AGCAPM getInstance] enableCollection:YES];
  }
  ```

应用客户端停用级别高于AGC远程配置停用。如用户在应用客户端停用性能监控，即使通过AGC远程配置打开性能监控开关，APM也不会进行性能数据采集。
