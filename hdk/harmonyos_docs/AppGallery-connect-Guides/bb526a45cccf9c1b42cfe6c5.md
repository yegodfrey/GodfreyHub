# 技术支持

当您集成游戏多媒体服务遇到问题时，可以按照以下顺序寻求帮助。

1. 请先仔细阅读文档，部分功能对设备和系统有限制，请参见[使用限制](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-restrictions-0000001227098079)。
2. 查看[FAQ](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-faq-0000001181618314)，返回码请参见[HarmonyOS NEXT](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmeerror-harmonyos-0000001779335521)、[Android](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-exception-gmmeerrcode-android-0000001238203671#section2386835654)、[iOS](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-ios-0000001301189252)、[Web](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmmeexception-web-0000001201816650#section7001115218)、[JS](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-errorresult-minigame-0000001673697934)、[C#](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmmeerror-csharp-0000001276063981)。
3. 通过[智能客服](https://developer.huawei.com/consumer/cn/customerService/#/bot-dev-top/faq-top/faq-talk-top)查找问题解决方案。
4. 登录[华为开发者论坛](https://developer.huawei.com/consumer/cn/forum/block/ag-connect)和[Stack Overflow社区](https://stackoverflow.com/questions/tagged/appgallery-connect)参与问题讨论。
5. 如果以上方法仍未解决您的问题，可以通过[在线工单系统](https://developer.huawei.com/consumer/cn/support/feedback/#/add/89?level2=2022000010&level3=201653621232848259&keyWord=游戏多媒体)与我们进行联系。提交后的工单可在开发者联盟"管理中心"的"开发者中心 \> 我的客服"页面查看工单处理进展。
