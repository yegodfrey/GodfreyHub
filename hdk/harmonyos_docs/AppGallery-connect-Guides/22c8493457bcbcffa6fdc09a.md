# 业务介绍

您可以通过[制作图章链接](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agdlink-getlink-agc-0000001164321881)来分发应用，可以将链接投放到推广的第三方应用或者社交媒体。用户点击推广的链接后，即可以跳转至移动终端自带的应用市场详情页下载安装。同时您还可以完成链接使用效果的数据分析。

#### 提供数据分析能力

* 在应用下载直达服务中提供的报表查询功能中可以查看直达链接在华为设备上各渠道的展示、下载、安装和激活数据，请参见[基础数据分析](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agdlink-analysis-basic-0000001164401835)。
* 支持通过接口查询链接跳转到华为应用市场时间、下载开始时间、安装完成时间和归因参数，请参见[高阶归因分析](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agdlink-analysis-refer-0000001117762116)。  

#### 提供多语言图章素材

可免费获取多语言、多格式的图章素材，将图章素材与链接一起投放增加用户对下载链接的信任度，提高曝光点击率。
