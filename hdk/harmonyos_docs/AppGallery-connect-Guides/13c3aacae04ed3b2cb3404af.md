# 如何收费

目前除语音转文本服务以外的其他服务处于免费阶段，期间华为承担服务器资源开销。语音转文本服务为增值服务，具体收费方式请参考[服务价格](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-service-billing-0000001051010023)。后续如有政策调整，将会提前两个月通知，您可放心使用。
