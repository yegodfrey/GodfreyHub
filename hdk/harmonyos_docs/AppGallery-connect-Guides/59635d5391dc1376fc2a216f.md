# 设置场景和标签

您可以自定义某个典型或卡顿的游戏场景，例如打斗、团战。若还想在场景中标记一段特殊的子场景信息，可以在场景中设置标签，用以标识该子场景中的性能数据。同个场景中可设置多个标签，但多个标签之间不可嵌套。标签与场景是依附关系，若未设置场景，设置标签将无效，场景与标签的时序图如下：

## 前提条件

* 已[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-integration-android-0000002022406709)。
* 已[初始化SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-initialization-android-0000002022526269)。
* 已[开启数据采集器](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-open-close-collector-android-0000001985966666#section72707115441)。

## 开发步骤

1. 加载游戏场景前，调用[GPMManager.setSceneStart](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-android-api-gpmmanager-0000002022527745#section83450342099)方法，同时游戏性能管理SDK开始采集、上报游戏的性能数据。

   ```screen
   GPMManager.setSceneStart("场景1");
   ```

   > 说明
   >
   > 若当前已有正在采集的场景，且场景名称不同，则自动结束上个场景的数据采集，开启新场景的数据采集。

   调用后可在GPMCallback接口的[onSetSceneStart](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-android-api-gpmcallback-0000001988789820#section19300172281214)方法中查看结果并实现回调处理。

   ```screen
   @Override
   public void onSetSceneStart(int code, String msg)
   {
       // GPMManager.setSceneStart接口通过子线程回调通知接口结果。由于大部分API需要在主线程中调用，请在onSetSceneStart回调中合理处理。
       if(code == GPMError.GPM_SUCCESS) 
       {
          // 设置场景名称成功
       }
   }
   ```

2. （可选）场景加载完成后，调用[GPMManager.setLoadSceneCompleted](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-android-api-gpmmanager-0000002022527745#section5837142071217)，计算加载游戏场景的耗时。

   ```screen
   // AGC控制台当前暂不支持展示该数据项
   GPMManager.setLoadSceneCompleted();
   ```

   调用后可在GPMCallback接口的[onSetLoadSceneCompleted](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-android-api-gpmcallback-0000001988789820#section165421225121210)方法中查看结果并实现回调处理。

   ```screen
   @Override
   public void onSetLoadSceneCompleted(int code, String msg)
   {
       // GPMManager.setLoadSceneCompleted接口通过子线程回调通知接口结果。由于大部分API需要在主线程中调用，请在onSetLoadSceneCompleted回调中合理处理。
       if(code == GPMError.GPM_SUCCESS) 
       {
          // 设置场景加载完成成功
       }
   }
   ```

3. （可选）若想在场景中标记特殊子场景的性能数据时，调用[GPMManager.setTagStart](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-android-api-gpmmanager-0000002022527745#section1015212671720)，设置标签。

   ```screen
   // AGC控制台当前暂不支持展示标签标记的性能数据
   GPMManager.setTagStart("场景1-TAG1");
   ```

   > 说明
   >
   > 若当前已有标签正在采集，且标签名称不同，则自动结束上个标签，开启当前标签的性能数据采集。

   调用后可在GPMCallback接口的[onSetTagStart](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-android-api-gpmcallback-0000001988789820#section20787131151218)方法中查看结果并实现回调处理。

   ```screen
   @Override
   public void onSetTagStart(int code, String msg)
   {
       // GPMManager.setTagStart接口通过子线程回调通知接口结果。由于大部分API需要在主线程中调用，请在onSetTagStart回调中合理处理。
       if(code == GPMError.GPM_SUCCESS) 
       {
          // 设置场景标签名称成功
       }
   }
   ```

4. （可选）调用[GPMManager.setTagEnd](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-android-api-gpmmanager-0000002022527745#section18108163414405)，结束标签。

   ```screen
   GPMManager.setTagEnd();
   ```

   调用后可在GPMCallback接口的[onSetTagEnd](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-android-api-gpmcallback-0000001988789820#section13736234181215)方法中查看结果并实现回调处理。

   ```screen
   @Override
   public void onSetTagEnd(int code, String msg)
   {
       // GPMManager.setTagEnd接口通过子线程回调通知接口结果。由于大部分API需要在主线程中调用，请在onSetTagEnd回调中合理处理。
       if(code == GPMError.GPM_SUCCESS) 
       {
          // 设置场景标签结束成功
       }
   }
   ```

5. 调用[GPMManager.setSceneEnd](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-android-api-gpmmanager-0000002022527745#section165425913151)，结束场景。

   ```screen
   GPMManager.setSceneEnd();
   ```

   > 说明
   >
   > 结束场景将停止采集数据，同时结束正在采集的标签。

   调用后可在GPMCallback接口的[onSetSceneEnd](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-android-api-gpmcallback-0000001988789820#section12972162819129)方法中查看结果并实现回调处理。

   ```screen
   @Override
   public void onSetSceneEnd(int code, String msg)
   {
       // GPMManager.setSceneEnd接口通过子线程回调通知接口结果。由于大部分API需要在主线程中调用，请在onSetSceneEnd回调中合理处理。
       if(code == GPMError.GPM_SUCCESS) 
       {
          // 设置场景结束成功
       }
   }
   ```
