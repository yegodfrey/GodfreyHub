# 测试付费下载应用

本章节介绍应用集成AppGallery DRM Service SDK后如何测试付费下载应用，不集成AppGallery DRM Service SDK的付费下载应用不涉及客户端代码测试。  

#### 测试check接口

1. 检查check接口中使用的drmId和drmPublicKey是否与[获取版权保护信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/appgallerykit-paidapps-agcprepare-0000001074231614#section1413624211268)中的"版权保护id"和"版权保护公钥"一致。
2. 检查check接口中使用的pkgName是否与[查看应用信息](https://developer.huawei.com/consumer/cn/doc/app/agc-help-appinfo-0000001100014694)中的应用包名一致。
3. 测试账号未设置为沙盒测试账号且showErrorDailog字段为true或缺省，本地安装应用后，进入应用会提示"您(xx)未购买本应用，请购买后使用"，点击"购买"提示"该应用在当前区域未上线"，此为正常情况。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240802135805.70119250945242751470838697128304:50001231000000:2800:E01C4068181AE15BFFFF77C22290C41CCA1B1BE76DF03A619856147988A23295.png?needInitFileName=true?needInitFileName=true)  
   如果测试账号未设置为沙盒测试账号且showErrorDailog字段为false，本地安装应用后，进入应用会鉴权失败，请根据错误码处理自行检查业务是否正常。
4. 参考[设置测试账号](https://developer.huawei.com/consumer/cn/doc/app/agc-help-testaccount-0000001146438651)将账号设置为沙盒测试账号，本地安装应用后，使用该沙盒测试账号可以直接鉴权成功并打开应用。  

#### 测试付费下载

如果您需要测试应用在华为应用市场上架以后真实的付费下载体验，推荐您使用[AppGallery Connect开放式测试](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-betatest-introduction-0000001071477284)服务。开放式测试允许您将应用的测试版本只分发给您指定的测试用户，测试用户可以在华为应用市场上搜索到您的测试版本并体验。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240802135805.62769702210547993616085190173775:50001231000000:2800:8D1C8F5520C46323371677211647EC706E29C066120AD4B1E63AC0A766FB3D57.png?needInitFileName=true?needInitFileName=true)  
如果您的开放式测试用户已经设置为沙盒测试账号，在应用市场下载应用时无需真实支付，否则则需要真实付费，建议您适当调低开放式测试版本的应用付费价格。
