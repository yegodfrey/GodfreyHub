# 集成SDK

可以选择[三方仓下载](#section348820295413)或者[本地下载](#section34571340144112)的方式来集成CalendarPicker SDK。  

#### 三方仓下载

1. 打开您的工程，在命令行窗口执行cd entry命令，切换到工程的"entry"目录。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240521110804.16166498543691912750895976057054:50001231000000:2800:1004FB38B13DCBA125A6DF5FFEAE359E17DE2205171C70372BEB7880863A4B14.png?needInitFileName=true?needInitFileName=true)

2. 安装CalendarPicker SDK到您的项目中。

   ```
   ohpm install @hw-agconnect/ui-base
   ohpm install @hw-agconnect/ui-calendar-picker
   ```

2. 解压得到ui_base.har和ui_calendar_picker.har，放在本地工程目录下。
3. 打开DevEco Studio应用级（一般为"entry"目录下）的"oh-package.json5"文件。
4. 在"oh-package.json5"文件的dependencies中添加SDK依赖。

   ```
   "dependencies": {
     "@hw-agconnect/ui-base": "file:ui_base.har",
     "@hw-agconnect/ui-calendar-picker": "file:ui_calendar_picker.har",
   }
   ```
