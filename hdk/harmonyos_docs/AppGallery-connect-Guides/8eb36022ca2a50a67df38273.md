# 业务介绍

|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-|
|华为AppGallery Connect（以下简称AGC）为您提供云托管服务。云托管服务是一项提供内容托管的服务，包括网站托管和存储加速功能，为用户提供安全快速的内容访问能力。 云托管服务提供了方便快捷的网页应用部署能力，您无需关注域名申请、证书管理等安全配置，也不需要关注页面分发。您只需要聚焦网站托管的内容，如：界面交互、页面样式和业务逻辑等，即可构建高安全、快速访问的网站。 您所托管的网站一经上线即会面向所有人开放。| |

## 相关概念

通过网站托管功能，您可以管理一个项目下的多个站点，每个站点对应一个托管服务提供的域名。同时，每个站点还支持多版本管理。

* 站点：站点是开发者托管静态网页的载体，帮助开发者管理和维护所有版本的网页内容。
* 版本：开发者更新托管的静态资源时，通过版本号区分进行版本管理。

通过存储加速功能，您可以为[云存储](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-static-cdn-0000001178262716)服务的存储桶配置加速域名，通过加速域名为云存储对象提供CDN加速能力。

## 典型场景

您可以使用云托管服务对多种类型的页面进行托管，包括但不限于如下场景：

* 个人博客：您可以上传生活趣事、分享读书心得，搭建一个展示自我的平台。
* 营销推广：您可以通过制作营销型网站助力企业线上推广，包括游戏推广、活动推广等，有助于企业通过自我宣传获取更多客户。
* 创意分享：您可以将有趣的内容制作成电子传单，通过网络媒介轻松分享给身边朋友，提高信息传送效率，确保分享的及时性。
