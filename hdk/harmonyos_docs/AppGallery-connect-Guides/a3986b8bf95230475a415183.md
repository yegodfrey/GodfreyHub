# API对接

#### 场景介绍

AGD API是华为应用市场提供的RESTful API接口，使用HTTPS协议。请求方在建立HTTPS连接时，需要按照标准PKI认证体系对收到的服务器证书进行验证，以避免仿冒问题。

通过AGD API您可以申请AppGallery上应用的临时下载链接用于应用的商业推广。  

#### 前提条件

* 已申请开通权限并提供对应的信息给华为运营完成配置，具体参见[申请开通](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agdapi-applypermission-0000001164401839)。
* 已完成套餐升级和充值，具体参见[升级套餐](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agdapi-upgradeplan-0000001117762118)。
* AGD API支持API客户端方式访问，在访问前需获取服务端授权，包括创建API客户端和获取访问的Access Token，具体参见[使用入门](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agcapi-getstarted#apiclient)。

在合作平台服务器调用AGD API提供的申请下载链接接口生成链接，接口调用顺序如下：  

|No.|接口|说明|
|:--|:-----------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------|
|1|[获取Token](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/obtain_token)|在申请下载链接前合作平台需要通过华为开放平台的鉴权，并获取鉴权通过后的Token。|
|2|[申请下载链接](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agdapi-requestlink-0000001117762120)|请在您的服务端调用接口申请下载链接，并在有效期内缓存该链接给不同用户使用。您可以根据接口中返回expire参数获取下载链接的有效期，超出有效期后您需要重新调用申请下载链接接口重新生成下载链接。|
