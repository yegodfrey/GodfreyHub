# 关于清理长期未使用的云数据库通知

尊敬的开发者，您好！

为进一步提升云数据库服务质量，保障开发者使用体验，我们将于**9月1日** 对您账号中长期未使用的云数据库（**截止通知发布日已连续6个月及以上未访问**）进行清理。

对您的影响：

1. 本次清理仅针对您账号中长期未使用的云数据库，不影响其他活跃的云数据库。
2. 云数据库被清理后，**相关数据内容不可恢复** 。若有必要，请您务必在**9月1日0时（北京时间）** **之前**完成数据备份。
3. 云数据库被清理后，您基于该数据库构建的业务将受影响，如需保留该数据库，请务必在**9月1日0时（北京时间）之前**恢复对该数据库的访问。

针对此次清理，若您还有其他疑惑，可以通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/add/89?level2=9012)的方式咨询，感谢您的理解与支持！
