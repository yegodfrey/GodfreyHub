# 渠道包信息管理

#### 新增渠道包信息

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的应用"。
2. 选择已上架的应用，进入"分发"页面。
3. 在左侧菜单栏选择"渠道包管理"，在"普通渠道包"或者"极小渠道包"页面点击"新增"。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115012.51090294280192106253372228022696:50531125054745:2800:E05FA38A987B5E5F46279039DBF6C2571D881B6B652A324F1EBC0190C5BFAF9C.png?needInitFileName=true?needInitFileName=true)

4. 按要求填写渠道包名称、包内渠道编码、投放账户ID和备注，并点击"提交"：
   * 支持批量新增渠道包信息。
   * 同一个应用下渠道包名称、包内渠道编码不可重复。
   * 若使用华为广告平台投放，请填写投放账户ID，若涉及多个请用英文逗号隔开。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115012.94580747055836382714106974978406:50531125054745:2800:056929A5577B22C55A3DFBD1F6F0E990C4B26F032697BF941CCE09AE00DED4AB.png?needInitFileName=true?needInitFileName=true)  
   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115012.10231798829676662940200623230499:50531125054745:2800:53C985C1039A98BDFFD00CA49FBF1B9439A83CCC147887AFD5F68F8D5019FFFA.png?needInitFileName=true?needInitFileName=true)  
   * 若主包已审核通过，则渠道包的自动审核一般需15分钟。
* 若主包审核不通过，则渠道包需等主包审核通过后才进入自动审核阶段。  

#### （可选）指定参照包

只有"极小渠道包"才可以指定参照包，系统默认选取第一个极小包作为参照包。

参照包可以重新指定：

* 当参照包还未上传软件包的时候，所有极小包的都可以"指定为参照包"。
* 当参照包已经上传软件包后，若其他的极小包也上传了软件包，需要其他极小包状态要为"生效"状态时才可以"指定为参照包"。
* 若软件包为多包的，需要所有包都为"生效"状态时才可以"指定为参照包"。

#### 查询渠道包信息

新增"普通渠道包"或者"极小渠道包"信息后，可输入如下查询条件查询渠道包：渠道包名称、包内渠道编码。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115012.44481034390139623476343720779054:50531125054745:2800:33F77E366FEFF7E06944EF28015027D36230D230E0D7BB11E03181D854203D02.png?needInitFileName=true?needInitFileName=true)  

#### 修改渠道包信息

新建"普通渠道包"或者"极小渠道包"信息后，可点击操作栏中的"修改"再次编辑渠道包名称、包内渠道编码和备注。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115012.16692560002403101383793412337437:50531125054745:2800:68E3C35AAF0D8A3ECF2912D3E9E57D390780D34E492292B29FD51EA5BC98955C.png?needInitFileName=true?needInitFileName=true)  

#### 删除渠道包信息

仅当"软件包管理"中没有软件包时可以删除渠道包信息，点击"删除"并确认后记录被删除。
