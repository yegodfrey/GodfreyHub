# 典型应用场景

#### 线上投放

获取图章链接后，可直接用于论坛、微博、公众号、短视频以及其他广告平台广告投放，点击后可直接进入推广应用的详情页。

#### 官网投放

应用官方网站下载入口可使用图章链接，节省单独部署下载服务器成本，为用户提供统一体验。

#### 扫码直达

在线下宣传等场景可以使用图章链接，支持用户扫码后直接进入移动终端自带的应用市场指定详情页，极大提升转化率。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115005.59971924541482652725563146029693:50531125054745:2800:B9E745140CCA85C25CF351DBD47B06A1A6029ACF15F90833C440F702199F1825.png?needInitFileName=true?needInitFileName=true)  

#### 支持安卓设备

在非华为安卓设备上，支持通过"本地应用市场"和"浏览器"两种方式下载，统一多设备体验。  

#### 通过本地应用市场安装

在非华为安卓设备上支持通过本地应用市场的应用详情页下载推广应用。  

#### 通过浏览器下载

在非华为安卓设备上支持通过浏览器直接下载推广应用APK并安装。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115005.63013672269417368882115542528842:50531125054745:2800:D1C3F1B9FA8809B8C55671A86575CA973D8A38BBC41E37C88E4CC2E1D032CDB6.png?needInitFileName=true?needInitFileName=true)  

#### 支持iOS设备

通过打开关联iOS链接生成的图章链接，跳转AppStore推广应用详情页。
