# 执行二进制插桩

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250811104208.31134951077063846692892883849172:50001231000000:2800:F5EF01C885B2B953F043904B6126F745171BC74235C7A4125EAB63A52F81284F.png)  
若本次游戏版本较上次版本的改动较小，可跳过二进制插桩及采集profile数据操作 。  

#### 前提条件

已[准备原始so文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/binary-optimization-files-0000001537880362#section10129192418372)。  

#### 开发步骤

1. 调用[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/binary-optimization-obtain-token-0000001909302281)接口。
2. 调用[获取文件上传地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/binary-optimization-obtain-url-0000001863302878)接口获取原始so文件的上传地址，并根据上传地址调用[上传单个文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/binary-optimization-upload-files-0000001909142601)接口上传原始so文件。
3. 调用[提交插桩任务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/binary-optimization-submit-pile-task-0000001862646064)接口执行二进制插桩操作。
4. 调用[获取插桩结果](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/binary-optimization-get-pile-result-0000001863462698)接口返回插桩so文件。
5. 将插桩so文件替换手机上安装后的原始so文件，替换后重新打包和签名。
