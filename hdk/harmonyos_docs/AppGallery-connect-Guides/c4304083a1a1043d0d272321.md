# 归档聚合链接

如果您无需继续管理您在AGC控制台创建的聚合链接，而又不想影响终端用户较长一段时间内的使用，可通过在AGC控制台的归档操作进行收纳和清理。

## 前提条件

您已[在AGC控制台创建聚合链接](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-createlinks-byagc-0000001058988077)。

## 操作步骤

> 注意
>
> * 分配了"管理员"、"APP管理员"、"运营"和"开发"角色的账号才可以进行归档操作。
> * 归档7天后的聚合链接将被隐藏，您无法通过AGC控制台进行查看和撤销归档的操作。归档后的聚合链接默认从归档时起1年内有效，因此建议您根据实际需要，谨慎操作。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击您的项目。
3. 点击"增长 > App Linking > 聚合链接"。
4. 选择"聚合链接"页签，对已创建的聚合链接进行归档。
   * 单条归档：在聚合链接列表，选择待归档聚合链接对应"操作"列的下拉选项中的"归档"。

     ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260105170007.49196525631955715743095462404171:50001231000000:2800:C7A5FDDEE59E4F9A46A86B7F9BCF404976ACA384BB1EB34747676D5B15B761CF.png)
   * 批量归档：在聚合链接列表，勾选多条待归档聚合链接，选择右上角"批量操作"的下拉选项中的"归档"。

     ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260105170007.06708281892693107019319943397712:50001231000000:2800:1A385B533D58E6F9D7E28BB58334AB411D3EEF8A6CFB026AAA23A8F2D7C1E1CC.png)

   > 说明
   >
   > 归档后的聚合链接7天（含）内依然可以被查看，您可在AGC控制台通过时间筛选，选择查看"7天内已归档"的聚合链接。同时，您也可以通过点击已归档的聚合链接操作列下方的"撤销归档"，将已归档的聚合链接恢复原状。
