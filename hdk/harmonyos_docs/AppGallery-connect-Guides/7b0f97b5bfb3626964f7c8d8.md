# 调试截屏/录屏

![](https://media:201778314577278236)  
* 截屏功能当前仅支持Android 10及以上版本、HarmonyOS 2.0.0及以上版本的所有真机设备（大屏设备除外）。
* 录屏功能当前仅支持深圳区域的华为Android 10手机真机设备。

云调试服务支持在调试过程中实时对设备截屏或录屏。您在调试应用或主题过程中，遇到需要保存的特殊场景信息，可以通过截屏或录屏功能保存场景界面，帮助您定位问题。  

#### 前提条件

调试截屏或录屏前必须先[申请调试设备](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddebug-debugequip-0000001122212029#section11242145501420)。  

#### 截屏

1. 调试设备申请成功后，进入调试页面，点击"截屏"页签进入截屏页面。
2. 当您的调试设备处于想要截屏的调试场景时，点击页面右侧的"截屏"或是设备左侧的![](https://media:201778314577339237)，即可截取场景图片。

   ![](https://media:201778314577457238 "点击放大")

   截屏图片按时间先后排序，您可点击图片右上角的红色"×"号，删除无用截图。  
   ![](https://media:201778314577582239)  
   截屏图片会同步保存至测试报告中，您可以在测试报告上打开对应设备的报告详情，查看历史截屏图片，详见[查看测试报告](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddebug-viewreport-0000001073992370)。

![](https://media:201778314577664240 "点击放大")  

#### 录屏

1. 调试设备申请成功后，进入调试页面，点击"截屏"页签。
2. 当您处于想要录屏的调试场景时，点击右侧"录屏"或是设备左侧的"![](https://media:201778314577701241)"，即可录制设备调试场景。

   ![](https://media:201778314577768242 "点击放大")
3. 最长可录制10分钟，再次点击"录屏"按钮或图标，即可停止录屏。 ![](https://media:201778314577832243 "点击放大")

   录制好的视频按时间先后排序，您可点击图片右上角的"![](https://media:201778314577858244)"，删去无用视频。视频还支持本地下载，您可点击已录制的视频右下角的"![](https://media:201778314577881245)"，即可下载录制成功的视频。  
   ![](https://media:201778314577908246)  
   录屏视频同步保存至测试报告中，您可以在测试报告上打开对应设备的报告详情，查看历史录屏视频，详见[查看测试报告](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddebug-viewreport-0000001073992370)。

![](https://media:201778314577975247 "点击放大")
