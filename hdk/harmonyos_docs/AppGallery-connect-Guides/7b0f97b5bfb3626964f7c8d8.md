# 调试截屏/录屏

> 说明
>
> * 截屏功能当前仅支持Android 10及以上版本、HarmonyOS 2.0.0及以上版本的所有真机设备（大屏设备除外）。
> * 录屏功能当前仅支持深圳区域的华为Android 10手机真机设备。

云调试服务支持在调试过程中实时对设备截屏或录屏。您在调试应用或主题过程中，遇到需要保存的特殊场景信息，可以通过截屏或录屏功能保存场景界面，帮助您定位问题。

## 前提条件

调试截屏或录屏前必须先[申请调试设备](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddebug-debugequip-0000001122212029#section11242145501420)。

## 截屏

1. 调试设备申请成功后，进入调试页面，点击"截屏"页签进入截屏页面。
2. 当您的调试设备处于想要截屏的调试场景时，点击页面右侧的"截屏"或是设备左侧的![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/45/v3/6QXTzPhkRkq5B_s_T-ZNuw/zh-cn_image_0000001152152085.png?HW-CC-KV=V1&HW-CC-Date=20260909T181146Z&HW-CC-Expire=31536000000&HW-CC-Sign=0CBC04118335BD22E6B579C915D9C02FA074B0DDA40F683C19E2A6DBE1675E0F)，即可截取场景图片。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9e/v3/NEi5o6CTSCCp7P4bQfqIUg/zh-cn_image_0000002182968205.png?HW-CC-KV=V1&HW-CC-Date=20260909T181146Z&HW-CC-Expire=31536000000&HW-CC-Sign=49FE3C2015B5E325781F818F7E425C7EAB06AA57C501D47ACCAF82E7979F92B8 "点击放大")

   截屏图片按时间先后排序，您可点击图片右上角的红色"×"号，删除无用截图。

   > 截屏图片会同步保存至测试报告中，您可以在测试报告上打开对应设备的报告详情，查看历史截屏图片，详见[查看测试报告](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddebug-viewreport-0000001073992370)。
