# 启用服务

如果您首次使用预测服务，需要先启用服务。可以根据当前产品运营需求，选择需要开展的具体预测任务，系统将根据华为分析服务上报的用户行为数据，自动执行您所选择的预测任务。预测任务每日定时执行，无需您重复启用动作。

#### 前提条件

预测服务基于华为分析服务（Analytics Kit）上报的用户行为数据进行预测，启用预测服务前请先启用华为分析服务，具体操作参见[启用华为分析](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/service-enabling-0000001050745155)。

#### 启用预测服务

  1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击“我的项目”。
  2. 在项目列表中，找到您需要启用预测服务的项目。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220927160604.87400095387575419836279262117198:50530926093051:2800:5418632F0839070CA4101C61CF7AA99139F64DDB2946C85371EECFCBBC722C31.png?needInitFileName=true?needInitFileName=true)

  3. 点击“增长 > 预测”，进入预测服务页面。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220927160604.49536638286383906631965013806184:50530926093051:2800:D2909F18FDB9F5ED9C986916776BBAF346183BEFB68F5A453C69D0D5233BDB4A.png?needInitFileName=true?needInitFileName=true)

  4. 点击“开通预测服务”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220927160604.11235900595666945030366425561953:50530926093051:2800:7A0D889E47E54BBEE6131F0FC81AF861B1C394D8D8059217EF0D71E3B6B55538.png?needInitFileName=true?needInitFileName=true)

如您此前未启用华为分析服务，点击上图中的“启动华为分析”，并根据相关提示完成分析服务的开通。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220927160604.67398903042224319778822452447748:50530926093051:2800:596AF254DE7268B42C9E40E6E199C8E2EC07A125586F56B6F239E1CC0CE77726.png?needInitFileName=true?needInitFileName=true)

  5. （可选）系统进入预测服务页面，若您的项目未添加应用或未集成华为分析SDK，请参见[添加应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createapp-0000001146718717)和[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-integrating-sdk-0000001050161876)进行相关操作。
  6. 在弹出的“选择预测任务”对话框中，您需要根据当前产品运营需求选择具体需要开展的预测任务，并点击“确定”，详情请参见[管理预测任务](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/manage-prediction-task-0000001285034181)。

预测服务启用，且预测任务选择完毕后，预测任务正式开启。

  2. 在项目列表中，找到您需要查看预测任务的项目。
  3. 点击“增长 > 预测”进入预测服务页面。

#### 开启邮件通知（可选）

启用预测服务后，当您的应用数据质量满足预测要求时，生成预测结果至少需要24小时，我们建议您开启邮件通知功能，以方便及时查看预测任务详情，具体操作如下：

  1. 点击“去开通”，系统跳转至“个人信息”界面。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220927160605.43147522015531592482142638887209:50530926093051:2800:C823647245AB58B450E504AD3FE3DAC9240D430AF60F394D63F5C2B50E45FD14.png?needInitFileName=true?needInitFileName=true)
