# 创建短链接

> 说明
>
> 如果集成了此服务的API接口，则可以参考[调试API](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-debugg-api-0000001346861040)，使用AGC的API Explorer调试AGC的API接口。

## 前提条件

* 您已成功[申请链接前缀](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-urlprefix-0000001060148052)。
* 您已[添加网址允许清单](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-allowlist-0000001059304615)。
* 您已[获取服务端API授权](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-obtain-apiauthorization-0000001321336068)。

## 开发步骤

|No.|接口|说明|
|:--|:---------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------|
|1|[创建短链接](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinking-create-0000001141716380)|* 如果您已经有聚合链接的长链接地址，可以直接将长链接地址传入longUrl参数，来获取对应的短链接地址。 * 如果还没有长链接地址，可以通过构造linkInfo参数来直接创建一个短链接地址。 您可以通过suffixLength参数来自定义短链接字符串后缀的长度。|
