# 本地查看

测试报告生成并保存到本地后，支持在报告列表中点击并在报告详情页查看相关数据。

1. 在主界面右侧点击"测试报告"进入报告列表页面。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110245.09428257134161300316472296067059:50001231000000:2800:AF1D57371574CFAE469FE344845B2EA70661F4634585CC603E9D0E6FF2F46B4C.png)

2. 在报告列表页面，您可以将测试报告[上传至云端](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/smartperf-tool-cloudview-0000001701197913#section1365144213172)进行查看，同时还可以直接点击并打开查看。如需在本地查看数据测试报告，可打开对应报告文件夹查看保存在本地的Excel表格。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110245.80868714474108137929995226883621:50001231000000:2800:6D6F5ACD9B4F64873EE9A69DB0DB3AE746C78C80CB7A7F6267B68FEF0AAEA7A7.png)
3. 在测试报告详情页，您可以查看采集到的数据项，数据项的详细解析请参见[数据解析](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/smartperf-tool-system-data-0000001557301842)。为了方便查看数据，在测试报告详情页支持如下操作：
   * 在"测试详情"、"GPU counter"版块，鼠标悬停曲线任一时间点，您可以查看数据项该时间点的数据。左键点击曲线出现固定实线，您可以横向对比数据，右键取消固定实线。拖动曲线下方时间轴，所有曲线的时间轴随之变动。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110245.05720538198187048675965646100289:50001231000000:2800:6DA6F81A7B2666366174B1B0AC96AFC11153279509EB07C4705F5B6AEDE02D74.png)

   * 在"测试详情"和"GPU counter"版块，框选曲线任一区间的数据后，支持展示该区间的平均值，也支持保存该区间的测试报告至本地或云端。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110245.86708417799289384211125805332838:50001231000000:2800:7C5940CAB32CCB8F2BDB9044F7096C2D1CEA0BA5EA8F286DC404B6163BA91E5A.gif)
