# 设置云端配置项

您可以在AppGallery Connect创建新的云端配置项，根据所需的条件逻辑，将配置的值覆盖应用内的值。

对于每个配置项，您可以设置默认值（最终将覆盖相应的应用内默认值），还可以设置条件值，不同条件下相同配置项可以设置不同的值。

## 前提条件

您需要已[开通远程配置服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-remoteconfig-enable-service-0000001276051134)。

## 配置项管理

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择需要设置配置项值的应用。
3. 在左侧导航栏选择"增长 > 远程配置"。


4. 选择"配置项管理"页签，点击右侧"添加配置项"，添加新的配置项内容。 配置项的名称需与应用中对应的配置项保持一致。配置项可以配置多个条件值，即不同条件下，设置不同值，条件值设置请参见[配置条件管理](#section11391717983)。

   若您的参数需要配置为复杂实体，AGC控制台提供了一个JSON编辑工具，供您在编辑远程配置参数时使用。使用控制台时，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e8/v3/9K5hrHjiQAm3IgQvA1pfBQ/zh-cn_image_0000001275632737.png?HW-CC-KV=V1&HW-CC-Date=20260916T021030Z&HW-CC-Expire=31536000000&HW-CC-Sign=A6FFB5FB78CB3D8EE0DC4EA3650F41AFB75F8B570DC2C602D631A0341C9BE18F)即可打开编辑器。

5. 点击"保存配置项"保存当前配置。
6. 点击"发布"使当前配置和条件生效，若点击"取消"将舍弃对配置和条件的更改。
7. 在"配置项管理"页签下，可以查看所有配置项列表。 点击配置项右上角的"![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0/v3/sBYT42RbSNCh8mjf2k3f6A/zh-cn_image_0000001156145645.png?HW-CC-KV=V1&HW-CC-Date=20260916T021030Z&HW-CC-Expire=31536000000&HW-CC-Sign=A4218D6BBACF14CFD58D2B69B28A5A11BCE04812495C22A3708BE3B5E9394770 "点击放大")"：您可以查看、修改、删除配置项，还可以通过复制方式快速添加配置项。

## （可选）配置条件管理

您可以为配置项设置条件属性，在不同的条件下为配置项设置不同的值，从而使应用在不同条件下提供差异化的功能。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择需要设置配置条件的应用。
3. 在左侧导航栏选择"增长 > 远程配置"。


4. 选择"配置条件管理"页签，点击"添加配置条件"，添加新的条件内容。

   |**过滤条件**|**运算符**|**条件** **值**|**说明**|
   |:-------|:-------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |应用版本|* 包含 * 不包含 * 等于 * 包含正则表达式|输入一个或多个应用版本号（1-64个字符）。|对应应用的VersionName。 当选择的运算符为 "包含"、"不包含"或"等于"时，可以采用以逗号分隔的值列表。 当选择的运算符为"包含正则表达式"时，您需要输入RE2格式的正则表达式。您不仅能够通过正则表达式匹配目标版本字符串的全部文本，还能够利用^和$定位点来匹配目标字符串的开头、结尾部分或文本的全部。关于如何书写正则表达式，请参考[Syntax](https://github.com/google/re2/wiki/Syntax)。 * 运算符"包含"为模糊匹配，目标值的列表中只要有1个值是实际值的子字符串，则返回True。例如：目标值列表为"1.0,2.0,3.0"，那么实际值为2.0.1返回True，为4.0.1时返回False。 * 运算符"不包含"指，目标值的列表中没有1个值是实际值的子字符串，则返回True。例如：目标值列表为"1.0,2.0,3.0"，那么实际值为2.0.1返回False，为4.0.1时返回True。 * 运算符"等于"为完全匹配，目标值的列表中只要有1个值是实际值，则返回True。例如：目标值列表为"1.0,2.0,3.0"，那么实际值为2.0时返回True， 为4.0时返回False。 * 运算符"包含正则表达式"指，如果目标值（即RE2正则表达式）与实际值匹配，则返回True。|
   |OS版本|* 包含 * 不包含 * 等于 * 包含正则表达式|输入一个或多个操作系统版本号（1-128个字符）。|输入iOS或者macOS版本号。 多个版本号以逗号分隔，且区分大小写，例如"iOS 10.0,iOS 13.3"，"iOS 10.0,macOS 10.5.2"。 OS版本支持正则表达式匹配，关于如何书写正则表达式，请参考[Syntax](https://github.com/google/re2/wiki/Syntax)。 关于OS版本选择的运算符的具体说明，请参考"[应用版本](#ZH-CN_TOPIC_0000001242850821__zh-cn_topic_0000001056587179_p89421715163518)"条件的说明。|
   |语言|-|选择一种或多种设备语言。|如果安装了该应用的设备使用的语言是所选择语言之一，则此规则的判断结果为 True。|
   |国家地区|-|选择设备所在的一个或多个国家/地区。|如果安装了该应用的设备设置的国家/地区是所选择出国家/地区之一，则此规则的判断结果为True。|
   |省级行政区|-|选择设备所在的一个或多个省级行政区。|系统会根据用户端侧请求消息的IP地址判断是否满足设备在对应的省级行政区内。|
   |用户百分比|* <= * >|0.000001~100|AGC会根据随机数（默认值为default，您可以自定义）将每个应用实例映射到一个固定的整数或小数上面（0.000001~100的范围），这样每个应用实例到服务器来获取数据时就能识别出是否满足当前的条件。 如果您想要一个应用实例被映射成多个数字，则需要添加多个此类型的条件，每个条件使用不同的随机数。|
   |时间日期|* 晚于 * 早于|选择具体的日期和时间，也可以指定具体的时区。|将设备的当前时间与配置的条件值进行比较。|
   |设备芯片|-|-|不支持该条件。|
   |自定义参数|文本： * 包含 * 不包含 * 等于 * 包含正则表达式 数字： * < * <= * = * != * >= * > 日期： * 早于 * 晚于|选择参与实验的自定义参数。 如需使用"自定义参数"条件，请先创建[自定义参数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-remoteconfig-android-cloudconfig-0000001056587179#section1579910105558)。|* 关于文本运算符的具体说明，请参考"[应用版本](#ZH-CN_TOPIC_0000001242850821__zh-cn_topic_0000001056587179_p89421715163518)"条件的说明，输入值要求1~128个字符。 * 当采用数字运算符作为条件时，我们会把相应自定义参数的值转换成整数/浮点数后再进行比较。 * 当选择日期类型作为条件，需要传入的是时间戳，精确到毫秒。|

5. 点击"保存配置条件"保存当前条件。
6. 在"配置条件管理"页签下，可以查看所有的配置条件列表。 点击配置条件右上角的"![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6f/v3/muNeb4D6QmuVHyTI1R3uKQ/zh-cn_image_0000001156147703.png?HW-CC-KV=V1&HW-CC-Date=20260916T021030Z&HW-CC-Expire=31536000000&HW-CC-Sign=A1134D6CAE9721F654C3AD926D96F762D23BB47D01B9BD86325A52DDE9083DE5 "点击放大")"：您可以查看、修改、删除配置条件，还可以通过复制方式快速添加配置条件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/79/v3/Irpqu8ixQCqefd0UKOxY2A/zh-cn_image_0000002531813914.png?HW-CC-KV=V1&HW-CC-Date=20260916T021030Z&HW-CC-Expire=31536000000&HW-CC-Sign=6D532F7E709CC70E9D57A99F624CDC81FF54ED54ADF6E7238D70FED009E31814)

   配置条件排列顺序影响配置条件的优先级，排序靠前的配置条件优先级更高，存在多个条件时，鼠标悬停于![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/20/v3/vLAcWxC5R1-_ZC_FBI62pA/zh-cn_image_0000001055867211.png?HW-CC-KV=V1&HW-CC-Date=20260916T021030Z&HW-CC-Expire=31536000000&HW-CC-Sign=B92C1356A4B048E3EE22D1CA5D2F263E94A92695BFD955CF39895A7DBE3FAA03)，可以拖动条件卡片，调整条件顺序。

## （可选）自定义参数

当您为配置项设置条件属性时，除了使用系统内置的条件外，您还可以自定义参数作为条件，使应用可以在更多条件场景下提供差异化的功能。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择需要设置参数值的应用。
3. 在左侧导航栏选择"增长 > 远程配置"。
4. 选择"自定义参数"，并点击"添加自定义参数"。 说明
   >
   > 最多可添加255个自定义参数项。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b6/v3/glSAMF3tRXuQga_jRQHF2w/zh-cn_image_0000002562584231.png?HW-CC-KV=V1&HW-CC-Date=20260916T021030Z&HW-CC-Expire=31536000000&HW-CC-Sign=18C0A3BAB1E4B854960DA60AEF89A2A248F400A5CD82AD05BFFB7AF5478B6471)
5. 设置完自定义参数内容，点击"确定"保存当前自定义参数项。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a5/v3/KKmsQHnFRn2Xaw-ihoC-FQ/zh-cn_image_0000001267193841.png?HW-CC-KV=V1&HW-CC-Date=20260916T021030Z&HW-CC-Expire=31536000000&HW-CC-Sign=BE299C9BCC9C1AB382093700BCDC46C7808CF65A9CD91BC3C95FB33646A7E624)

   |参数|说明|
   |:---|:-----------------------------------------------------------------------------|
   |参数ID|用于定义一个参数的标识，由数字、字母、下划线组成，且不能以数字、下划线开头，要求不超过255个字符。|
   |参数类型|支持的运算符包括文本、数字和日期类型： * 文本：包含、不包含、等于、包含正则表达式。 * 数字：<、<=、=、!=、>=、>。 * 日期类型：早于、晚于。|
   |参数说明|对应属性的内容说明，要求不超过1000个字符。|

6. 在"自定义参数"页签下，可以查看所有自定义参数。
