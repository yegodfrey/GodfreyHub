# 连接AppGallery

## 接口描述

AGD作为媒体与应用市场之间的通道，需要先与应用市场建立通道的连接，该api为立刻返回结果，连接动作在后台进行。

## 输入参数

备注：调用connect之前需要注册 ConnectionCallbacks 获取结果。

|参数名称|参数类型|是否必选|参数说明|
|:-------------------------------|:-------|:---|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|AgdApiClient.ConnectionCallbacks|callback|必选|public void ConnectionCallbacks() {} //连接成功回调 public void onConnected() {} //连接被中断回调 public void onConnectionSuspended(int i) {} //连接错误回调 public void onConnectionFailed(ConnectionResult result) {} //连接失败回调|

## 返回参数

通过onConnectionFailed返回

|参数名称|参数说明|
|:------------------------------------|:---------------------------------|
|int CAUSE_SERVICE_DISCONNECTED = 1;|服务被中断，这里会通过onConnectionSuspended返回|
|int CAUSE_SERVICE_BIND_EXECPTION = 2;|绑定服务异常(调用系统bindService方法失败)|
|int CAUSE_CLIENT_UNFOUND = 4;|华为应用市场不存在|
|int CAUSE_FUNCTION_UNSUPPORT = 5;|不支持AGD SDK功能|
|int CAUSE_CLIENT_SIGN_INVALID = 6;|华为应用市场客户端的签名不一致|
|int CAUSE_CLIENT_NEED_UPDATE = 7;|华为应用市场需要升级|

## 示例代码

```screen
// 连接的回调
AgdApiClient.ConnectionCallbacks callback = new AgdApiClient.ConnectionCallbacks(){
    @Override
    public void onConnected() {
		// 连接成功
        Log.i(TAG, "onConnected");
   }

    @Override
    public void onConnectionSuspended(int cause) {
		// 挂起
        Log.i(TAG, "onConnectionSuspended:" + cause);
   }

    @Override
    public void onConnectionFailed(ConnectionResult result) {
		// 连接失败
        Log.i(TAG, "onConnectionFailed:" + result.getStatusCode());
   }
};
AgdApiClient client = new AgdApiClient
 .Builder(getApplicationContext())
   .addConnectionCallbacks(callback)
   .build();
client.connect();
```

## 后续操作

1. 当与AppGallery连接失败后，需要判断错误码，引导安装应用市场，当返回错误码为4或者7时，会返回PendingIntent，集成应用可以拉起界面引导下载华为应用市场。onActivityResult可以接收拉起界面的回调结果。

   ```screen
   @Override
   public void onConnectionFailed(ConnectionResult result) {
       int statusCode = result.getStatusCode();
       Log.i(TAG, "onConnectionFailed:" + statusCode);
       boolean isClientUnFound = statusCode==ConnectStatusCode.CAUSE_CLIENT_UNFOUND ||
                 statusCode == ConnectStatusCode.CAUSE_CLIENT_NEED_UPDATE;
       if (isClientUnFound && result.hasResolution()) {
           try {
               result.startResolutionForResult(MainActivity.this, 2222);
          } catch (IntentSender.SendIntentException e) {
               Log.e(TAG, "start resolution failed");
          }
      }
   }
   @Override
   protected void onActivityResult(int requestCode,int resultCode,@Nullable Intent data){
       super.onActivityResult(requestCode, resultCode, data);
       if (2222 == requestCode) {
           Log.i(TAG, "install hiapp resultCode:" + resultCode);
           if (resultCode == Activity.RESULT_OK) {
               // 安装成功，重新绑定服务
               client.connect();
          }
      }
   }
   ```

2. 每次进行任何api操作之前，请先判断与AppGallery之间的链接情况.

   ```screen
   public void onClick(View btn) {
   	// 其他接口都需要保证服务已经绑定了
   	if (!client.isConnected()) {
   		client.connect();
           return;
       }
   	
       // 下载、暂停、恢复等等操作
   	...
   }
   ```
