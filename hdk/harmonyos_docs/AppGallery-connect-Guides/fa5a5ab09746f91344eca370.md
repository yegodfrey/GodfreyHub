# 使用组件

1. 在应用的入口文件中进行初始化。

   ```
   import { UIBase } from '@hw-agconnect/ui-base';
   ​
   onWindowStageCreate(windowStage: window.WindowStage): void {
     UIBase.init(windowStage);
   }
   ```

2. 参考[UICategory](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/petalui-api-category-0000001894284073#section1538412412395)使用Category组件。
