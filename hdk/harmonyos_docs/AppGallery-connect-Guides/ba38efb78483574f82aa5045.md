# 查询开发者账号ID及项目ID

开发者账号ID及项目ID查询方法如下：

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中找到您的项目，选择您需要查询开发者账号ID或项目ID的应用。
3. 在"项目设置"页面中，"Developer ID"即为开发者账号ID，"项目ID"即为该项目的项目ID。 ![](https://media:201775716939000055)
