# iOS

iOS游戏如需实现实时语音、实时信令、语音消息、效果音播放和语音转文本功能，可以集成游戏多媒体服务的iOS SDK。  

#### 开发准备

* Xcode：13.3及以上版本
* 支持的终端CPU架构：ARM64、ARM32
* 测试应用的设备：iOS 9.0及以上版本的iPhone真机

#### 添加权限

在使用游戏多媒体SDK相关模块能力（实时语音、语音消息、语音转文本）前，您需要先在"Info.plist"文件中申请麦克风权限。

```
<key>NSMicrophoneUsageDescription</key>
<string>App需要您的同意,才能访问麦克风</string>
```
