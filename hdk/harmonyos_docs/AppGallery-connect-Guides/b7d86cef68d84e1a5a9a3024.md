# 获取指定房间信息

进入语音房间后，您可通过获取指定房间信息，实现房间信息页面展示功能。如需实现定时刷新房间信息功能，可自行通过轮询调用接口实现。
> 说明
>
> 获取指定房间信息时，范围语音房间不会返回房间内其他玩家的信息。

## 前提条件

您已[加入房间](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-joinroom-roomid-harmonyos-0000001769649006)。

## 开发步骤

调用[GameMediaEngine.getRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-harmonyos-0000001732273982#section129432591757)方法获取指定房间信息。

```screen
Room room = gameMediaEngine.getRoom(roomId);
```
