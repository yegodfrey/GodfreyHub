# 联运服务数据捐赠

#### 场景介绍

#### 意图框架介绍

意图框架是HarmonyOS系统级的意图标准体系，通过多维系统感知、大模型等AI能力构建全局意图范式，实现对用户显性与潜在意图的理解，并及时、准确地将用户需求传递给生态伙伴，匹配合时宜的服务，为用户提供多模态、个性化的进阶场景体验。

意图框架的设计主要遵循以下核心理念:

* 面向用户：多样化自然交互，多模态协同联动，智慧便捷的用户体验。
* 面向开发者：高效快速接入，精准流量分发。

开发者接入意图框架的带来的收益:

* 用户体验更佳：自然便捷的系统级服务体验，提升品牌口碑。
* 流量曝光更大：多种交互形态入口直达功能服务，打破应用孤岛。
* 业务转化更快：直达目标用户群，带来更高转化和收益。

#### 意图分类

意图框架针对意图共享提供了两种共享模式：完成时模式和将来时模式。

* 完成时模式：开发者共享用户已经执行的交互类意图，例如用户在应用或元服务中执行的播放视频、播放音乐、查看门店优惠等。在此模式下，系统将学习用户执行该意图的规律，并在适时推荐该意图对应的应用和元服务功能。
* 将来时模式：开发者共享预测用户即将执行的交互类意图。预测可以依据开发者掌握的用户规律（例如用户突然喜欢某个电视剧）或者发生业务事件状态变化（例如用户订单状态变更）。系统在获取将来时意图共享后，会利用对应信息进行辅助推荐，主要包括推荐冷启动和关键事件信息触发推荐。

意图框架当前针对联运业务场景支持的标准意图如下：  

|----|-----|-------------------------------|-------|
|应用品类|意图分类|意图名称|对接方式|
|教育儿童|完成时模式|学习课程LearnCourse|端侧联运SDK|
|教育儿童|将来时模式|学习报告ViewLearningProgress|云侧API|
|影音娱乐|完成时模式|播放音频PlayAudio|端侧联运SDK|
|影音娱乐|将来时模式|查看预约信息CheckMediaAppointmentInfo|云侧API|

本功能涉及的关键开发步骤如下：

1. 获取用户AccessToken

   捐赠用户的行为数据，需要先获取用户华为账号的AccessToken作为凭证。获取AccessToken的方法区分两种场景。若没有获取到AccessToken可以忽略该值。
   * 用户已使用华为账号登录 如果用户在您的应用中已经使用华为账号登录，您通过华为账号登录接口返回的[AuthAccount](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/authaccount-0000001050315810)对象的[getAccessToken](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/authaccount-0000001050315810#section525518587477)方法可以获取到用户的AccessToken。

   <!-- -->

   * 用户未使用华为账号登录 如果用户未登录华为账号，您可以通过华为账号的静默登录能力在后台获取用户的AccessToken；在调用登录接口时，只要您仅申请获取用户的openId或unionId，不获取用户头像、昵称等个人数据，就不会弹出华为账号的授权页面。

     ```
     // 华为账号登录授权服务，提供静默登录接口silentSignIn
     private AccountAuthService mAuthService;

     // 华为账号登录授权参数
     private AccountAuthParams mAuthParam;

     /**
      * 静默登录，如果设备上的华为账号系统已经登录，且只请求获取openId或unionId，则无需用户授权
      */
     private void silentSignInByHwId() {
         // 配置登录请求参数AccountAuthParams，只请求用户id(openid、unionid)
         mAuthParam = new AccountAuthParams mAuthParam = new AccountAuthParamsHelper()
                 .setId()
                 .setIdToken()
                 .createParams();
         // 使用请求参数构造华为账号登录授权服务AccountAuthService
         mAuthService = AccountAuthManager.getService(this, mAuthParam);
         // 使用静默登录进行华为账号登录
         Task<AuthAccount> task = mAuthService.silentSignIn();
         task.addOnSuccessListener(new OnSuccessListener<AuthAccount>() {
             @Override
             public void onSuccess(AuthAccount authAccount) {
                 // 静默登录成功，处理返回的账号对象AuthAccount，获取openId/unionId和accessToken
                 dealWithResultOfSignIn(authAccount);
             }
         });
         task.addOnFailureListener(new OnFailureListener() {
             @Override
             public void onFailure(Exception e) {
                 // 静默登录失败，设备可能未登录华为账号，无需其他处理
             }
         });
     }

     /**
      * 处理返回的AuthAccount，获取用户ID和accessToken
      *
      * @param authAccount AuthAccount对象，用于记录账号信息
      */
     private void dealWithResultOfSignIn(AuthAccount authAccount) {
         String openId = authAccount.getOpenId();
         String unionId = authAccount.getUnionId();
         String accessToken = authAccount.getAccessToken();
     }
     ```

2. 构造捐赠数据
   1. 初始化[DataDonationParams](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/datadonationparams-0000001653224074)

      DataDonationParams构造函数传入意图的类型。

      ```
      // 参数PlayAudio代表“有声”意图,参数LearnCourse代表“课程”意图 
      DataDonationParams params = new DataDonationParams ("LearnCourse");
      	
      // 本轮捐赠唯一标识，UUID仅为参考，可用其他唯一标识代替
      params.setIdentifier(UUID.randomUUID().toString());
      	
      // 设置版本号，固定值1.0
      params.setIntentVersion("1.0");
      ```

   2. 封装ACTION部分

      ```
      // 已发生的事件用EXECUTED，未来将要发生的事件用EXPECTED 
      params.setIntentActionInfo(new JSONObject().put("actionMode", "EXECUTED")
      // 填写学习的时间段，包括开始时间和结束时间 
      .put("executedTimeSlots", new JSONObject().put("executedStartTime", startTime).put("executedEndTime", endTime)) 
      	
      // 当前学习百分比,LearnCourse学习类意图传入该字段
      .put("currentLearningProgress", 50));
      ```

      意图Action的构造具体如下。  

      |-------------------|-------------------|----------|---------------|------------------------------------------------------|
      |意图类型|实体字段|字段类型|必选|字段说明|
      |公共字段|actionMode|String|必选|动作模式，固定值"EXECUTED"。|
      |公共字段|executedTimeSlots|JSONObject|必选|意图实际时间，JSONObject为{executedStartTime,executedEndTime}。|
      |播放/玩转 （ PlayAudio ）|currentSerialNumber|Integer|PlayAudio 类必选|当前序列位置（集）。|
      |播放/玩转 （ PlayAudio ）|currentPercentage|Integer|PlayAudio 类必选|当前播放百分比。|
      |学习 （LearnCourse）|currentPercentage|Integer|LearnCourse 类必选|当前学习百分比。|

   3. 封装ENTITY部分 Entity数据是与用户行为相关的实体信息，如学习的课程信息，播放的有声书信息等。不同的实体类型有不同的属性。

      ```
      params.setIntentEntityInfo(new JSONObject()    
      // entity唯一标识，必填，String类型。同一课程时，多次捐献的数据要保持一致  
      .put("entityId", "27d1ac10-4343-41f1-80d2-a1f1dec4e672")    
      // 固定值 PlayAudio填入Audio， LearnCourse填入Course
      .put("entityName", "Course")     
      // 课程名称 
      .put("courseName", "初二年级英语")  
      // 课程封面URL  
      .put("courseImage ", "https://xxx" )   
      // 章节数 
      .put("chapters", 1) 
      ```

      意图实体具体定义如下。
      * 播放有声（意图类型 = PlayAudio）

      |----------|-----------|------------|----|-----------------------------|
      |实体类型|实体字段|字段类型|是否必选|字段说明|
      |有声 （Audio）|entityId|String|必选|实体ID，对于有声内容，对应有声集的ID。|
      |有声 （Audio）|entityName|String|必选|实体名称，此处填写"Audio"。|
      |有声 （Audio）|audioName|String|必选|有声集的名字，比如："西游记"。|
      |有声 （Audio）|audioList|Object\[\]|可选|有声集（ArrayList{各集名称，播放次数、时长})。|
      |有声 （Audio）|favorites|Integer|可选|收藏该有声的人数。|

      * 学习课程（意图类型= LearnCourse）

      |实体类型|实体字段|字段类型|必选|字段说明|
      |课程 （Course）|entityId|String|必选|实体ID。|

   4. 点击目标卡片时跳转信息绑定 设置用户在小艺建议等智慧分发入口中点击卡片后跳转的目标。DeepLink中可以携带intent信息，当通过DeepLink拉起App时，intentParams会通过Intent参数透传给应用。

      .put("url","https://xxxx.com.cn/ddd?abc=xxx&intentInfo={\"intentName\":\"PlayVideo\",\"intentParams\":{\"wordsLearned\": 13")
