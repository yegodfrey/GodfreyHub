# 错误码

|**错误码**|**值**|**意义**|**建议处理方式**|
|:-------------------------------------------|:----|:--------------------------|:-------------------------------------------------------------------------------------------------------------------------|
|DrmStatusCodes.CODE_DEFAULT|-1|获取签名失败，内部错误(接口调用失败或签名数据异常)。|提示用户检查购买记录失败，请检查网络后重试。|
|DrmStatusCodes.CODE_APP_UNSUPPORT|-2|华为应用市场以及游戏中心都不支持鉴权。|提示用户安装最新版本的应用市场，下载地址为[https://appgallery.cloud.huawei.com/appdl/C27162](https://appgallery.cloud.huawei.com/appdl/C27162)。|
|DrmStatusCodes.CODE_CANCEL|-4|获取签名时，用户点击返回，取消鉴权。|提示用户检查购买记录失败，请重试。|
|DrmStatusCodes.CODE_NEED_INTERNET|1|需要网络连接。|提示用户网络不可用，请检查网络连接。|
|DrmStatusCodes.CODE_PROTOCAL_UNAGREE|3|没有同意华为应用市场服务条款。|提示用户到华为应用市场同意服务条款后使用。|
|DrmStatusCodes.CODE_PROTOCAL_UNAGREE_GAMEBOX|-3|没有同意华为游戏中心服务条款。|提示用户到华为游戏中心同意服务条款后使用。|
|DrmStatusCodes.CODE_PROTOCAL_NOTAGREE|13|没有同意华为应用市场、游戏中心等客户端服务条款。|归一的错误码：提示用户到华为应用市场、华为游戏中心等客户端同意服务条款后使用。|
|DrmStatusCodes.CODE_LOGIN_FAILED|6|登录华为账号失败。|提示用户到华为应用市场登录华为账号后使用。|
|DrmStatusCodes.CODE_LOGIN_FAILED_GAMEBOX|-6|登录华为账号失败。|提示用户到华为游戏中心登录华为账号后使用。|
|DrmStatusCodes.CODE_LOGIN_ACCOUNT_FAILED|16|登录华为应用市场、华为游戏中心等客户端账号失败。|归一的错误码：提示用户到华为应用市场、华为游戏中心等客户端登录华为账号后使用。|
|DrmStatusCodes.CODE_NOT_LOGIN|9|没有登录华为账号。|提示用户到华为应用市场登录华为账号后使用。|
|DrmStatusCodes.CODE_NOT_LOGIN_GAMEBOX|-9|没有登录华为账号。|提示用户到华为游戏中心登录华为账号后使用。|
|DrmStatusCodes.CODE_NOT_LOGIN_ACCOUNT|19|没有登录华为应用市场、华为游戏中心等客户端的账号。|归一的错误码：提示用户登录华为应用市场、华为游戏中心等客户端后使用。|
|DrmStatusCodes.CODE_NO_ORDER|7|没有订购关系。|提示用户尚未购买此应用，请到华为应用市场或游戏中心购买后使用。|
|DrmStatusCodes.CODE_OVER_LIMIT|8|超过使用设备数量。|提示用户当前账号下使用本应用的设备数量已超上限，请切换账号重新购买后使用。|
|DrmStatusCodes.CODE_INVALID_MEMBERSHIP|10|错误的会员订阅关系。|提示用户不是会员或会员已过期，请购买会员。|
|其它|/|未知错误。|提示用户检查购买记录失败。如果错误码为4，请检查当前测试包签名与在架包签名是否一致以及DRM_ID是否正确，若检查无异常或显示其他错误码，请联系华为应用市场客服（告知客服具体错误码，便于查找原因）。|

> 说明
>
> 非错误码模式（即showErrorDailog参数值为true）则由AppGallery DRM Service SDK提示用户，开发者不需要处理错误码。
