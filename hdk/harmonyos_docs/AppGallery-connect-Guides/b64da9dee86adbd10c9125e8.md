# 查看实验结果

实验成功运行后，您可查看详细的实验数据。点击您要查看的实验"操作"列的"查看报告"，进入实验报告页面。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250102135804.54788086345074102145146364113068:50001231000000:2800:2F0D9E22339A36CCF7F3AC86D315E0F28A8F168C48AF734661F2A746333E45E3.png?needInitFileName=true?needInitFileName=true)

实验报告页面展示各实验组的测试用户范围、实验开始日期、统计指标图表概览和详细列表数据。通过分析实验数据，您可以综合比对不同实验组的统计指标值，来判断哪个实验组的素材内容对用户更具吸引力。

实验报告页面支持两种数据查看方式：

* [查看指定日期范围的实验数据](#section1243432125412)（即"素材天数据"）

  实验运行后，系统将会在隔天的UTC时间0点（即北京时间8点）上报天数据。建议您在实验运行至少两天后进行查看。
* [查看实时实验数据](#section12878928195814)（即"素材实时数据"，仅限已上架应用）

  实验运行后，系统将会在每个整点上报实时数据。您可在实验运行一个小时后进行查看。由于各种因素干扰，可能存在数据无法及时上报的情况，建议您适当放宽时长。

#### 查看指定日期范围的实验数据

系统默认按"素材天数据"维度展示从实验开始至当前日期前一天的运行数据，各项指标说明如下。

#### 查看实时实验数据

仅已全网上架的应用支持查看实时数据。  
点击"素材实时数据"，可查看实验的实时数据，包括下表各项指标。

* 统计周期选择"累计至 当天XX时"：展示从实验开始至当天XX时的累计运行数据。例如，实验于2022年1月1日零点开始，当前查询时间为2022年1月4日04点45分，则统计周期显示"累计至 当天03:00"，展示2022年1月1日01点至2022年1月4日03点的数据。
* 统计周期选择"当天"：展示各实验组在当天按小时统计的运行数据。例如，实验于2022年1月1日零点开始，当前查询时间为2022年1月4日04点45分，则统计展示2022年1月4日01点至03点的数据。

|快捷新下载成功数|用户通过华为应用市场快捷方式进行的非更新下载成功次数|
