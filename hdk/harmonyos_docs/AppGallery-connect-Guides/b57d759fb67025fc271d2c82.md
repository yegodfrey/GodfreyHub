# 关于认证服务短信发送能力调整的通知

尊敬的开发者，您好！

为进一步保障短信业务的安全性与合规性，依照国家反诈工作部署及相关行业监管政策要求，国内短信签名需符合以下任一条件：企事业单位名、已上线App名称、已注册商标名，且均需完成运营商实名制报备，不再支持网站、公众号、小程序、电商店铺等其他签名来源。

<br />

非常感谢您选择认证服务，基于当前短信签名标准，为保障您业务的正常运行，我们将对短信发送能力进行调整：认证服务的验证/通知短信将不再由HUAWEI AppGallery Connect发送，需要您自行购买第三方短信服务。认证服务可对接您提供的短信发送接口，来进行后续短信的正常下发。

<br />

为避免影响您的业务，建议您[参照文档](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-authentication-method-0000002417916829#section16830152153116)尽快完成调整。

有任何问题可以通过[在线工单](https://developer.huawei.com/consumer/cn/support/feedback/#/add/89?level2=9016)的方式咨询，感谢您的理解与支持！

#### 当前国内短信签名的标准是什么？

|签名来源|签名内容|要求及申请说明|
|:---------------------|:----|:------------------------------------------------------------------------------------------------------------------------------------------|
|公司（推荐优先使用）|公司全称|全称需与企业营业执照上的企业名称完全一致。 若贵司的全称超过12个字符，建议使用公司简称。|
|公司（推荐优先使用）|简称|简称需连续且包含在营业执照全称中，还须与其他企业无混淆、重名。 例如"深圳市XAX科技有限公司"对应简称可为"XAX科技"，不可为"深圳XAX科技"、"XX科技"。|
|App|App名称|App已在工信部[ICP/IP地址/域名信息备案管理系统](https://beian.miit.gov.cn/#/Integrated/index)完成备案并可查，且该App的ICP备案主体与企业名称完全一致。 若App正在开发中，暂不支持签名申请，建议使用公司简称进行提交。|
|商标|商标名称|商标已在中国获得注册，并在[中国商标网](https://sbj.cnipa.gov.cn/sbj/index.html)中可查，且商标所有方与企业名称完全一致。|
|政府/机关事业单位/其他机构（推荐优先使用）|组织全称|全称需与组织/机构证照上的名称完全一致。 若贵司的组织全称超过12个字符，建议使用组织简称。|
|政府/机关事业单位/其他机构（推荐优先使用）|组织简称|简称需连续且包含在证照上的全称中，还须与其他组织/机构无混淆、重名。|
