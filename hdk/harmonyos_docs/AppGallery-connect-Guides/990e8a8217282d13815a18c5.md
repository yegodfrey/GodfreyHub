# iOS

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251103143211.66463829630987678205788566914101:50001231000000:2800:A4477A1C1B02BEED2C9A9AA943C70A1F0D4B5268AF0284ACDE797B668E621AED.png)  
语音消息文件会占用一部分本地存储空间，建议您销毁实例时，删除本地存储的语音文件以释放存储空间。  

#### 前提条件

* 您已[集成游戏多媒体基础SDK和语音消息模块](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-integratingsdk-ios-0000001323104597)。
* 您已[创建游戏多媒体实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-engine-ios-0000001272544612#section1093713161034)。  

#### 录制语音消息

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251103143211.27321205660611118774185508172666:50001231000000:2800:9E4E38DC88CD17D6CC828B921DD64792AB35F7103083EF19D0D90CB2991C0539.png)

1. 当玩家录制语音消息时，需先初始化音频存储路径。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251103143211.32328831518001794951219566762367:50001231000000:2800:F326A397C2B95CD80EC08E89FEE254597594CC50C399BAB3B734544C0D427765.png)  
   文件路径自行指定，音频文件仅支持.m4a格式。

   ```
   NSString *dir = [NSSearchPathForDirectoriesInDomains(NSCachesDirectory, NSUserDomainMask, YES) lastObject];
   NSString *filePath = [dir stringByAppendingPathComponent:[NSString stringWithFormat:@"%@.m4a", @"xxxx"]];
   ```

2. 音频存储路径初始化完成后，开始录制语音消息。
   * 不带变声效果：调用[\[HWPGMEngine.getInstance startRecordAudioMsg:filePath\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section14370135332316)方法开始录制语音消息。

     ```
     [HWPGMEngine.getInstance startRecordAudioMsg:filePath]; // filePath:录制的音频文件本地保存地址
     ```

   * 带变声效果：调用[\[HWPGMEngine.getInstance startRecordAudioMsg:filePath voiceType:type\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section16986161022413)方法开始录制语音消息。  
     ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251103143211.04997754477737949823327820695024:50001231000000:2800:9D740E4623F80E364571CEB9D196D985EC972FEA0EF8603C8F84690EE05B4B91.png)  
     如实时语音开启了变声特性，则语音消息不支持变声。

     ```
     [HWPGMEngine.getInstance startRecordAudioMsg:filePath voiceType:type]; // filePath:录制的音频文件本地保存地址; type: 变声类型,原声类型表示关闭变声,其他枚举值请参考VoiceType
     ```

3. 在语音消息录制过程中，如需结束录制，可通过调用[HWPGMEngine.getInstance stopRecordAudioMsg](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section7501133122814)方法停止录制。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251103143211.98852478395466226456737690653840:50001231000000:2800:758D4467465B5E902C2D0E480A1F1F2241A54D04C04B015D8AF696B2B3B8D73C.png)  
   录制语音消息的最大时长为50s，超过将自动结束录音。

   ```
   [HWPGMEngine.getInstance stopRecordAudioMsg];
   ```

4. 语音消息录制停止或自动结束时，可在HWPGMEngineDelegate接口的[onRecordAudioMsg](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section124441224645)方法中实现该事件的回调处理。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251103143212.68608682312718353083997002032995:50001231000000:2800:50F2D1F4FA8530EAA140785461F3D19F5D59FE446B1C76E2266C23C886CC9F6F.png)  
   为了保证语音消息录制效果，建议您此处增加一个判断，即当语音消息时长小于1秒时，提示不发送语音消息。

   ```
   - (void)onRecordAudioMsg:(NSString *)filePath code:(int)code msg:(NSString *)msg {
       NSLog(@"filePath: %@, code: %d, msg: %@",filePath, code, msg);
       // 可根据需求将数据进行处理
   }
   ```

5. 当语音消息录制成功后，可通过调用[HWPGMEngine.getInstance uploadAudioMsgFile](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section12263913359)方法将语音消息文件上传到游戏多媒体服务器。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251103143212.41838126586008239485288856243528:50001231000000:2800:7834BF0BE3F11915BD1BD345444463E199C91ADE6726D2E4B6F873FC9F12B263.png)  
   上传的语音消息文件大小最大支持50MB，在游戏多媒体服务器上将会保留7天。

   ```
   [HWPGMEngine.getInstance uploadAudioMsgFile:filePath msTimeOut:msTimeOut]; // filePath:上传文件的文件路径; msTimeOut:超时时间, 单位：ms, 取值范围[3000, 7000]
   ```

6. 语音消息文件上传时，可在HWPGMEngineDelegate接口的[onUploadAudioMsgFile](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section3944114115145)方法中实现该事件的回调处理。

   ```
   - (void)onUploadAudioMsgFile:(NSString *)filePath fileId:(NSString *)fileId code:(int)code msg:(NSString *)msg {
       NSLog(@"filePath: %@, fileId: %@, code: %d, msg: %@",filePath, fileId, code, msg);
       // 可根据需求将数据进行处理
   }
   ```

7. （可选）当语音消息文件上传成功后，如需对文件进行风控检测，可调用[HWPGMEngine.getInstance startDetectAudioFile](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section2996163919319)方法进行送检。

   ```
   [HWPGMEngine.getInstance startDetectAudioFile:fileId];  // fileId:文件ID
   ```

8. 语音消息文件风控送检时，可在HWPGMEngineDelegate接口的[onStartDetectAudioFile](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section96411253174713)方法中实现该事件的回调处理。

   ```
   - (void)onStartDetectAudioFile:(NSString *)fileId code:(int)code msg:(NSString *)msg {
   NSLog(@"fileId: %@, code: %d, msg: %@",fileId, code, msg);
   // 可根据需求将数据进行数据处理
   }
   ```

#### 发送语音消息

语音消息文件上传完成后，会生成一个语音消息文件ID，可通过IM通道发送文件ID给其他玩家来发送语音消息。游戏多媒体SDK的实时信令功能提供了消息发送通道，语音消息也可以通过该通道完成文件ID传递，具体实现请参见[实时信令](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/rtm-overview-0000001734630053)。  

#### 播放语音消息

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251103143212.95731970134227369445222338675717:50001231000000:2800:60163616BE856053D55FE2FBF1DCE1D61DF831C34F2960378035385D5073928E.png)

1. 当玩家通过IM通道获取到其他玩家传递过来的语音消息文件ID后，可通过调用[HWPGMEngine.getInstance downloadAudioMsgFile](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section01013383382)方法下载该文件。

   ```
   [HWPGMEngine.getInstance downloadAudioMsgFile:fileId filePath:filePath msTimeOut:msTimeOut]; // fileId:文件ID; filePath:文件下载的存储地址; msTimeOut:超时时间, 单位：ms, 取值范围[3000, 7000]
   ```

2. 下载语音消息文件时，可在HWPGMEngineDelegate接口的[onDownloadAudioMsgFile](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section47801050171612)方法中实现该事件的回调处理。

   ```
   - (void)onDownloadAudioMsgFile:(NSString *)filePath fileId:(NSString *)fileId code:(int)code msg:(NSString *)msg {
       NSLog(@"filePath: %@, fileId: %@, code: %d, msg: %@",filePath, fileId, code, msg);
       // 可根据需求将数据进行处理
   }
   ```

3. 当语音消息文件下载成功后，可通过调用系统方法自行实现播放/暂停该文件中的语音消息内容。
4. 当语音消息文件下载成功后，如需了解文件时长和大小，您还可以通过调用[HWPGMEngine.getInstance getAudioMsgFileInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section23197351414)方法获取文件信息。

   ```
   AudioMsgFileInfo *fileInfo = [HWPGMEngine.getInstance getAudioMsgFileInfo:filePath]; // filePath:获取音频文件信息的文件路径
   ```
