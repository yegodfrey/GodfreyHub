# 获取非严重异常报告

非严重异常，即被应用捕获的异常，尽管不会导致崩溃，但是往往说明代码可能存在某些问题。AGC提供记录非严重异常的机制，让您可以监控到这些异常，帮助您提高代码质量。  

#### 前提条件

1. 您需要在AGC控制台[开通崩溃服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-enableservice-0000001326330021)。
2. 您需要先在您的应用中[集成崩溃服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-integratesdk-ios-0000001326720177)。  

#### 记录异常

1. 调用[AGCCrash](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccrash-ios-0000001055101856)的[sharedInstance](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccrash-ios-0000001055101856#section14138125619240)方法获取AGCCrash实例。
2. 调用[recordError:](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccrash-ios-0000001055101856#section1513619352318)记录您处理的NSError异常。  

   ```
   "Objective-C"
   [[AGCCrash sharedInstance] recordError:error];
   ```

   ```
   "Swift"
   AGCCrash.sharedInstance().recordError(error)
   ```

* AGC只会记录一个应用会话中最近的10次异常。如果您的应用在一个会话中抛出的异常数超过10个，则较早的异常会被删除。
* 由于Cocoa Touch API不具有异常安全性（exception-safe），在应用中使用try-catch方式处理NSException异常可能会导致其他问题，因此AGC不提供直接记录NSException的接口。  

#### 分析异常

记录的异常会在应用下次启动时上报。您可通过在AGC控制台添加用户属性及时间过滤的方式，选择查看指定时间内所有异常的统计数据。同时，在问题详情页面，您还可以查看分析堆栈、日志、状态等详细信息。  

#### 查看异常详情

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择您的应用。
3. 在左侧导航栏选择"质量 \> 崩溃"。
4. 在"添加过滤器"中，选择用户属性的事件类型为"异常"查看异常数据。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155610.37624216122657082507176600861772:50001231000000:2800:3FF7F59521BC52D776F217D39DD213A4E5C7F87CECABBCD068CF20919A7D8A10.png)

5. 在崩溃服务的"统计"页面，您可以通过添加过滤器和设置右上角的时间选择器过滤您的异常数据。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155610.47287530011409807746654697064748:50001231000000:2800:F0602B2552112F294125A00FF8B389204E3B216A11FCCAA4BC89C1D383749ABB.png)

6. 确认异常已经上报后，您可以选择"问题"，通过设置时间选择器查看指定时间范围内该应用累计发生的非严重异常问题及其次数。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155611.70534148853959431719451220703469:50001231000000:2800:3B5BEC1B7F2E3DCDA42799CB5B62FDB31EEBF117A2E8A22369851B56C5639439.png)

1. 在问题详情页面，您可以通过图表查看您在不同时间测试异常时的实际异常发生次数，分析应用出现异常的趋势。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155611.01670063778297145935319996275859:50001231000000:2800:A2E4B314677AB66C9CB2300F03B6340AEA000B089270E1EE0BC97CDEC7B18EE3.png)

#### 更多信息

* 如果您需要获取特定用户、日志或关键信息的异常报告，详情请参见[自定义崩溃报告](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-customreport-ios-0000001055340561)。
* 如果您代码中的类名、字段和方法等替换为不可阅读的代码时，您可以通过上传iOS符号文件的方式获取可阅读的异常报告，上传方式同[获取可阅读的崩溃报告](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-mapping-ios-0000001055140559)。
