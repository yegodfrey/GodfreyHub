# （可选）跨域设置

如需在不同的站点访问指定的存储实例，可以设置跨域的相关配置，服务器将通过配置的跨域信息进行相关允许、拒绝等操作。  

#### 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[初始化存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-initialize-bucket-java-0000001282104682)。  

#### 操作步骤

1. 定义跨域配置，参考[BucketCors](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/bucketcors-0000001158348863)对象。

   ```
   int maxAgeSeconds = 200;
   String[] methods = {"PUT","GET"};
   String[] origins = {"*"};
   String[] headers = {"headers-123"};
   String[] exposeHeader = {"exposeHeader-123"};

   BucketCors bucketCors = initBucketCors(maxAgeSeconds,methods,origins,headers,exposeHeader);
   ```

2. 初始化跨域对象。

   ```
   public static BucketCors initBucketCors(int maxAgeSeconds, String[] methods,String[] origins,String[] headers,String[] exposeHeaders) throws AGCException {
           BucketCorsRule bucketCorsRule = new BucketCorsRule();
           List<String> origins1 = new ArrayList<>(origins.length);
           Collections.addAll(origins1,origins);
           List<String> methods1 = new ArrayList<>(methods.length);
           Collections.addAll(methods1,methods);
           if(headers!=null){
               List<String> headers1 = new ArrayList<>(headers.length);
               Collections.addAll(headers1,headers);
               bucketCorsRule.setHeaders(headers1);
           }
           List<String> exposeHeaders1 = new ArrayList<>(exposeHeaders.length);
           Collections.addAll(exposeHeaders1,exposeHeaders);

           bucketCorsRule.setMaxAgeSeconds(maxAgeSeconds);
           bucketCorsRule.setMethods(methods1);
           bucketCorsRule.setOrigins(origins1);
           bucketCorsRule.setExposeHeaders(exposeHeaders1);


           List<BucketCorsRule> bucketCorsRules = new ArrayList<>();
           bucketCorsRules.add(bucketCorsRule);

           BucketCors bucketCors = new BucketCors();
           bucketCors.setRules(bucketCorsRules);
           return bucketCors;
       }
   ```

3. 调用[AGCStorageManagement.setBucketCors](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragemanagement-0000001111669018#section9664182391010)方法为指定的存储实例设置跨域配置。

   ```
    HeaderResponse headerResponse = storageManagement.setBucketCors(bucketCors);
   ```
