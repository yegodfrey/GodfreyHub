# 配置iOS应用信息

当应用平台为iOS时，您需要在AGC配置"App Store ID"和"团队ID"。

1. 在"开发与服务"页面中，点击iOS应用所在项目。
2. 在"项目设置"页面选择"常规"页签。
3. 在"应用"区域，点击![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704165003.73390567307143270883688140909025:50001231000000:2800:0B2012625162E87952F1063144A17775A4F318AFECE50155D27ADF2DC18635D9.png "点击放大")配置"App Store ID"和"团队ID"，即您应用在App Store上的ID和团队ID，完成后点击![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704165003.63755711391242845863140878068943:50001231000000:2800:DE2DDFC84292208ABAE1F8B9BC3B7785F8BD28340DA8041F5B91FF33DC292155.png "点击放大")保存。
