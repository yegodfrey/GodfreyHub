# 自定义崩溃类型

有些崩溃问题，仅通过崩溃报告中的堆栈、环境（比如设备、网络）信息不能快速定位，需要了解更多应用内的数据。为了帮助您全面了解崩溃报告信息，AGC崩溃提供了三种自定义报告记录机制：[用户标识符](#section10884322173010)、[日志](#section10324131835111)和[键值对](#section17813173111515)。

## 前提条件

1. 您需要在AGC控制台[开通崩溃服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-enableservice-0000001326330021#section542455312289)。
2. 您需要在您的应用中[集成崩溃服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-integratesdk-harmonyos-0000001276400112)。

## 添加自定义用户标识

为了定位某个问题，了解哪些用户遇到了特定的崩溃通常很有帮助。您可以通过设置自定义用户标识符，以匿名的方式为用户分配用户标识，作为用户的唯一标识符。

1. 调用[APMCrash.getInstance()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-harmonyos-0000001139799938#section743716146324)获取APMCrash实例。
2. 调用[APMCrash.getInstance().setUserId()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-harmonyos-0000001139799938#section742711611129)设置用户标识符。

   ```screen
   APMCrash.getInstance().setUserId("12345");
   ```

> 注意
>
> * 设置的用户标识符长度上限为1KB，超过会被截断。
> * 如果重复设置，会以最后一次的设置为准。

用户标识符的生命周期是从本次启动到本次发生崩溃为止。应用重启之后，会重新读取您的设置。如果需要清除某个用户标识符，可将该值重置为空字符串，清除用户标识符不会移除现有的崩溃记录。

崩溃发生后，您可在AGC上根据用户标识符查询具体崩溃问题，详情可参见[根据用户标识查看崩溃信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-locate-harmonyos-0000001139958984#ZH-CN_TOPIC_0000001139958984__li20829165717225)。

## 添加自定义用户日志

为了获取导致崩溃的更多背景信息，您可通过添加自定义日志随相关联的崩溃数据一同上报，并在AGC上获取包含自定义日志的崩溃报告。您可通过以下两种方法添加自定义日志。

* 使用系统默认日志级别 您可通过调用[APMCrash.getInstance()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-harmonyos-0000001139799938#section743716146324)获取APMCrash实例，然后调用[APMCrash.getInstance().setCustomLogInfo(String text)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-harmonyos-0000001139799938#section111927396208)来记录日志信息，日志级别将默认记录为HiLog.INFO级别。

  ```screen
  APMCrash.getInstance().setCustomLogInfo("set info log.");
  ```


* 自定义日志级别 您可通过调用[APMCrash.getInstance()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-harmonyos-0000001139799938#section743716146324)获取APMCrash实例，然后调用[APMCrash.getInstance().setCustomLogInfo(int level, String text)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-harmonyos-0000001139799938#section040211331616)来记录日志信息并自定义日志级别。

  ```screen
  APMCrash.getInstance().setCustomLogInfo(HiLog.WARN, "set warn log.");
  ```

> 注意
>
> * 为避免影响您应用的性能，AGC将日志总大小限制为不超过64KB。如果超过该限制，则会删除最早的日志条目。
> * 为了尽可能多地记录日志条目，AGC限制单条日志的大小不要超过4KB，超过会进行截断。

考虑到有些崩溃可能会是多次重启之后才会出现，为了尽可能地为您保留更多的有用信息，因此设置自定义日志的生命周期为从上次发生崩溃到本次发生崩溃为止，当发生崩溃以后，会在日志上报后再删除上一个生命周期上报的日志。

崩溃发生后，您可在AGC上根据日志级别筛选日志记录，详情可参见[根据自定义日志查看崩溃信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-locate-harmonyos-0000001139958984#ZH-CN_TOPIC_0000001139958984__li132451347222)。

## 添加自定义键值对

为了获取崩溃发生时应用的特定状态，您可通过添加自定义键值对获取状态记录，状态会与相关联的崩溃数据一起上报。

1. 调用[APMCrash.getInstance()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-harmonyos-0000001139799938#section743716146324)获取APMCrash实例。
2. 调用[APMCrash.getInstance().setCustomKeyValue()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-harmonyos-0000001139799938#section09568741214)添加自定义键值对。根据键值对中的value值类型不同，您可通过以下6种示例方法添加自定义键值对。

   ```screen
   // 添加string类型的键值对
   APMCrash.getInstance().setCustomKeyValue("stringKey", "world");

   // 添加boolean类型的键值对
   APMCrash.getInstance().setCustomKeyValue("booleanKey", false);

   // 添加double类型的键值对
   APMCrash.getInstance().setCustomKeyValue("doubleKey", 1.1);

   // 添加float类型的键值对
   APMCrash.getInstance().setCustomKeyValue("floatKey", 1.1f);

   // 添加int类型的键值对
   APMCrash.getInstance().setCustomKeyValue("intKey", 0);

   // 添加long类型的键值对
   APMCrash.getInstance().setCustomKeyValue("longKey", 11L);
   ```

   > 注意
   > * 最多可支持64组键值对，超过后不再保存更多的值。
   > * 每组键值对的key最长为1KB，value最长为1KB，超过会被截断。

同一个key支持重复设置，以最后一次设置的value值为准。设置的键值对的生命周期是从本次启动到本次发生崩溃为止。应用重启之后，会重新读取您的设置。

崩溃发生后，您可在AGC上获取应用及用户的状态，详情可参见[根据自定义键值对查看崩溃信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-locate-harmonyos-0000001139958984#ZH-CN_TOPIC_0000001139958984__li145783196226)。
