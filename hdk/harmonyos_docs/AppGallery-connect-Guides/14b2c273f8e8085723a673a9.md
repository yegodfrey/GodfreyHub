# 推荐实验设计

#### 实验可能影响因素

素材测试实验通过设置受影响的用户范围来进行实验分组，但实验最终的主要参考数据依据从素材曝光到点击下载的转化率。受以下因素影响，相同比例的用户对应的曝光量可能会有较大差异：

* 应用市场资源位排期：应用在对应测试期间内，在华为应用市场是否有公共的曝光资源位将很大程度影响素材在不同设备上的曝光量。若没有资源位曝光，则素材在不同设备上的曝光量将有可能有较大差异。
* 设备的活跃度：不同设备的用户在应用市场的活跃程度不同。若A、B组均分配20%的实验用户，但是A组对应用户为华为应用市场的活跃用户、B组对应用户为非活跃用户，则A组对应的素材曝光量可能远高于B组。
* 用户的行为意图：若应用在应用市场没有明显的曝光资源，则素材曝光多依赖用户的主动搜索行为。不同的设备用户若搜索意图相差很大，则对应曝光量也会有很大差异。同时，用户是否点击进入应用详情页查看，也将直接影响详情页内素材的曝光量。  

#### 推荐的实验设计

为尽可能减小以上影响因素对实验数据的误差影响，我们建议您：

* 确定明确的实验目标：确保您在设计实验时已想好要达成的目标，从而针对性地设计实验。
* 一次仅测试一类素材：为避免不同素材间的交叉影响，建议您一次实验仅测试一类素材。
* 每次实验至少持续7天：为最大程度排除外界因素影响，建议您单次实验持续7日以上，累积足够数据以减小误差。
* 尽可能面向50%的用户进行测试实验：在可能的情况下，面向最大规模的测试受众进行测试能更快地获得结果，尤其是在首页无明显曝光资源位的时候。
* 针对同一种素材类型，用多个不同素材反复实验：大胆测试不同的素材，根据实验结果反复改进，以尽可能获取更优结论。
