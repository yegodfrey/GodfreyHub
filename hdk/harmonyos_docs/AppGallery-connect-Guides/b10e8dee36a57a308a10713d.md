# APM典型案例

## 案例背景

开发者A经常收到部分灰度用户反馈页面白屏时间过长，用户希望每次打开网站时更加顺畅。

## 排查步骤

开发者A按如下步骤进行排查：

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择需要查看的应用。
3. 选择"质量 > 性能管理"，进入"应用性能管理"页面。
4. 选择"页面分析"，点击域名右侧的" 查看详情 "，进入"页面详情"界面。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155821.79968446078228021826247785288238:50001231000000:2800:1B5B7F0F59099DC9498F29AEFE73952347437F8365792EC89E60503AFC3F5F31.png)

5. 点击"首次内容渲染耗时"，进入应用白屏时长统计页面。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155821.44540338496325413367123857737932:50001231000000:2800:10FBE2E7CA9CECF8FBC7D3760DBEAE9C6DBAD8E427D49DF9C638A13617189BDA.png)

6. 从图1和图2处，开发者A能看出用户每次进入"www.huawei1.website.com"页面时首次内容渲染（白屏）耗时的分布情况。从2020年8月14日至2020年8月17日，开发者A发现首次内容渲染耗时指标80%分位值的数据都保持在5200毫秒左右，相当于大部分用户在进入此页面都要等待5秒白屏时间，用户体验非常糟糕，而通常相对优秀的Web应用白屏时间一般都在1秒以内。
7. 开发者A思考项目代码需要优化精简，准备在2020年8月17日完成代码优化并且重新上线后，再次观察页面白屏耗时情况。
8. 项目在优化完重新上线4天之后，开发者A再次进入应用白屏时长统计页面观察性能数据，发现从2020年8月17日项目优化升级之后，耗时情况开始发生改变，到8月18日之后，5%值、中位值、95%值都降到了800毫秒左右。于是开发者A去咨询用户8月17日之后的使用感受，用户表示页面流畅度大大提高，用户体验得到提升。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155821.40347671936016918767762097251465:50001231000000:2800:8E55D38AC7CEBCA224E7C117C127CAD7B3D63F01E584C0003BB842D6CCC1112A.png)

## 案例结论

结合以上案例可知，APM JS SDK可以有效监控页面性能数据，并以多种图表形式、从多个维度展示数据，帮助开发者充分了解Web应用的页面性能表现、定位页面异常，从而进行页面优化，给用户带来更好的体验。
