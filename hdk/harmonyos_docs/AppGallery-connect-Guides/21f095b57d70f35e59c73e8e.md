# 概述

Serverless图片尺寸调整模板支持为您存储实例中的图片裁剪成不同大小的尺寸。创建此模板后，您只需将原始大小的图片上传到存储实例，Serverless图片尺寸调整模板将为您创建所需尺寸的图片，并且为您在云存储服务中保存不同大小的图片。

## 使用场景

Serverless图片尺寸调整模板支持将图片以不同大小和不同扩展名重新创建并存储新图片在存储实例中。使用此模板，则开发人员无需在后台构建代码或结构，即可实现此功能。您可以配置此模板，将每次上传的原始图片转换成不同大小的图片，并保存在云存储的指定路径中。

例如，您需要150x150、750x750和460x680的图片，通过Serverless图片尺寸调整模板可以创建这三种图片，并存储到您指定的云存储实例的任何路径中。此模板会通过云函数监听云存储已完成事件。当监听到云存储已完成事件消息时，系统会访问用户上传到云存储的图片文件，并执行图片裁剪，将裁剪后的图片上传到用户指定的路径或者根目录。

完成Serverless图片尺寸调整模板安装后，如果模板未配置存储路径，则系统会将裁剪后图片存储在根目录下。
