# 切换房间

玩家处于多房间状态下时，可通过切换语音房间实现进入不同房间发言。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241105115836.09118028958758378766528449523161:50001231000000:2800:A3071004EF072546D3F7C6412E16BEB37F1A374B2658E7506D7F093690DE68DE.png?needInitFileName=true?needInitFileName=true)  
在房间A中，一个玩家无论是否具备发送语音的能力，当该玩家由房间A切换至其他房间后，其在房间A中则仅具备接收语音的能力。当玩家由其他房间切换回房间A后，则其恢复在原房间A中的语音能力。  

#### 前提条件

您至少已[加入](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-joinroom-roomid-harmonyos-0000001769649006)两个房间。  

#### 开发步骤

1. 调用[GameMediaEngine.switchRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-harmonyos-0000001732273982#section152623252033)方法切换到指定房间。

   ```
   gameMediaEngine.switchRoom(roomId); // roomId:房间ID
   ```

2. 当玩家切换房间时，可在EventHandler接口的[onSwitchRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-eventhandler-harmonyos-0000001732136356#section551190174014)方法中实现相关回调处理。

   ```
   onSwitchRoom(roomId: string, code: number, msg: string) {
     console.log('onSwitchRoom : code=' + code + ', msg=' + msg + ', roomId = ' + roomId);
   }
   ```
