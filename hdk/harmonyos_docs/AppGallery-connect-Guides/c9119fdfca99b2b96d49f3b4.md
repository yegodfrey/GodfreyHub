# 使用限制

## 资源限制

云函数用来运行、存储函数的计算和存储资源量有一定的限制，如下表所示。

|**资源**|**限制**|
|:--------|:-----------------------------------------------|
|函数部署包大小|200MB（已压缩，可直接上传） 400MB（解压缩） 20层（目录层次） 30000（文件数）|
|在线编辑代码量|3MB|
|函数实例CPU配额|500-2000m|
|函数实例内存配额|500-4000MB|
|实例并发数|1-10000|
|层部署包大小|150MB（已压缩，可直接上传） 300MB（解压缩）|

## 开发语言限制

云函数当前支持的函数开发语言为Node.js、Java和Python。

## 设备限制

设备限制是指SDK对用户终端的限制。

|限制项|限制|
|:-----------|:---------------------------------------------------------------------------------------------------------------------|
|设备品牌|支持所有品牌设备。|
|设备类型|HarmonyOS当前仅支持手机和平板设备。|
|Android OS|Android 4.2及以上（API Level 17及以上）|
|iOS OS|* 1.2.1及以前版本：iOS 8及以上 * 1.3.0及以后版本：iOS 9及以上|
|Web浏览器|* Chrome 51及以上 * Edge 79及以上 * Firefox 54及以上 * 华为浏览器 * Safari 10及以上 * UC桌面浏览器 建议最新版（6.2.4094.1） * QQ桌面浏览器10.4及以上 * IE11|
|EMUI（针对华为手机）|无限制。|
|HMS Core APK|无限制。|
|应用市场客户端|无限制。|

## 特性依赖

特性依赖是指对其他华为业务的依赖。

|特性|依赖的业务|
|:----|:--------------------------------------------------------------------------------------------------------------------|
|用户级认证|[认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-introduction-0000001053732605)|
