# 内容概述

## 相关概念

使用云托管服务时，您可以联合[云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-introduction-0000001054847259)实现静态CDN（Content Delivery Network）加速。您可将存储桶中的静态文件（例如文本或图片等）托管于距用户较近的CDN节点中，用户通过静态CDN加速地址即可就近访问资源，有效提升下载速度，也避免了因网络拥堵等因素导致的访问延迟问题，显著提升用户访问体验。

通过本节内容，您将了解到如何通过云托管服务创建加速域名。如果您想要进一步了解存储加速功能，请参见[结合云托管实现静态CDN加速](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-static-cdn-0000001178262716)。
