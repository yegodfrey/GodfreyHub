# 上传文件包

#### 示例代码

以下是CircleCI Android项目配置的上传任务的代码，用来上传和部署APK或AAB包。您也可以在打包前新增别的任务。

```
version: '2.1'
orbs:
  android: circleci/android@1.0.3
  jq: circleci/jq@2.2.0
  appgalleryconnect: devwithzachary/appgalleryconnect@0.2.0
workflows:
  use-my-orb:
    jobs:
      - appgalleryconnect/upload:
          appid: '0'
          clientid: test
          path: ~/build/apk/android.apk
          secret: test
          suffix: apk
          test: 'false'
```

#### 参数

|参数|类型|是否需要|默认值|描述|
|:-------|:-----|:---|:---------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|appid|string|Yes|-|应用ID。|
|clientid|string|Yes|-|API客户端ID, 在AppGallery Connect[创建](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section103mcpsimp)。|
|path|string|No|/build/apk/android.apk|Android应用软件包的绝对或相对路径。|
|secret|string|Yes|-|密钥，在AppGallery Connect[创建](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section103mcpsimp)。|
|suffix|string|Yes|-|软件包后缀，取值为APK或AAB。|
|test|string|No|False|表示命令是否作为测试命令已运行。（无需上传软件包）|
