# 稳定性测试

稳定性测试通过长时间遍历测试和随机测试，检测应用在华为手机、折叠屏或者其它品牌手机上的内存泄漏、内存越界、冻屏、崩溃等稳定性问题。

## 前提条件

您已成功创建测试任务，且配置的"测试范围"包含"稳定性测试"。

## 查看测试报告

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击需要查看测试报告的项目。
3. 在左侧导航栏中，选择"质量 > 云测试"，进入云测试主页面。


4. 选择"测试任务"页签，您可以通过搜索框或测试任务列表中"应用类型"、"测试场景"、"测试状态"右侧的![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303165620.29642695698957630453217094400540:50001231000000:2800:666A92C336F923E5F17B09E597204C96E87C54998E70EE396B69FD8363603DC5.png)筛选出您要查看的测试任务，然后点击"操作"列的"查看报告"进入测试报告页面。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303165620.63672548537134469275960214516183:50001231000000:2800:B5037A7F1A3C5D09138B5958C20F95A190133631D95FE855A05F1295F492A05B.png "点击放大")
5. 点击"稳定性测试"页签，您可从稳定性测试的测试报告中获得基本的测试检测项检测结果。

   |类别|**检测项**|**说明**|
   |:------|:---------------|:------------------------------------------------------------------------------------------------------------|
   |安装|安装|安装是实现稳定性测试的基本条件。若应用可正常安装，则检测为通过；反之，则检测为不通过，将无法进行应用稳定性测试。|
   |崩溃/应用冻屏|Java Crash|检测应用在指定时间内运行后是否出现Java崩溃。当1小时内发生Java崩溃的次数小于1，则此项检测通过；反之，则此项检测不通过。|
   |崩溃/应用冻屏|Native Crash|检测应用在指定时间内运行后是否出现Native Crash问题。当1小时内发生Native Crash的次数小于1，则此项检测通过；反之，则此项检测不通过。|
   |崩溃/应用冻屏|JS Crash|检测应用在指定时间内运行后是否出现JS页面崩溃。当1小时内发生JS页面崩溃的次数小于1，则此项检测通过；反之，则此项检测不通过。|
   |崩溃/应用冻屏|App Freeze|检测应用在指定时间内运行后是否出现App Freeze应用冻屏问题。当1小时内发生App Freeze的次数小于1，则此项检测通过；反之，则此项检测不通过。|
   |崩溃/应用冻屏|总计|检测应用在指定时间内运行后是否出现崩溃或应用冻屏类问题。当1小时内发生Java Crash、JS Crash、Native Crash和APP Freeze问题的次数总和小于1，则此项检测通过；反之，则此项检测不通过。|
   |内存泄露|Memory Leak|检测应用在指定时间内运行后是否出现内存泄漏错误。当1小时内发生内存泄露的次数小于1，则此项检测通过；反之，则此项检测不通过。|
   |踩内存|Address Santizer|检测应用在指定时间内运行后是否出现内存越界访问错误。当1小时内发生内存越界访问错误数小于1，则此项检测通过；反之，则此项检测不通过。|

6. 在"测试报告"下方的设备列表中，点击某款机型右侧"操作"列的"查看详情"，进入测试报告详情页面。 该测试报告详情中包含被测应用信息、测试时长、运行被测应用的测试设备等，同时重点提供测试发现的问题点、测试截屏、异常描述、异常信息以及日志。当检测出应用存在异常问题时，测试截屏区域左侧会列出所有发现的错误及警告。您可点击测试截屏查看被测应用在所选手机上的遍历情况。在"日志"区域，点击鼠标悬停时出现的"下载"可将测试过程中打印的日志下载到本地查看。
