如果您使用统一登录接口进行登录，则需要在UIApplicationDelegate回调中调用AGC SDK的生命周期接口。注意初始化第三方数据的方法需要在AGCApplicationDelegate didFinishLaunchingWithOptions监听方法之前调用。

```screen
"Objective-C"
- (BOOL)application:(UIApplication *)application didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {
    // Override point for customization after application launch.
    [AGCInstance startUp];
    // 将第三方平台获取的"应用编号"和"应用密钥"等参数，通过设置AGCAuthThirdPartyConfig单例的属性值的方式，传递给AGConnectAuth SDK
    [[AGCApplicationDelegate sharedInstance] didFinishLaunchingWithOptions:launchOptions];
    return YES;
}
```

```screen
"Swift"
func application(_ application: UIApplication, didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?) -> Bool {
        // Override point for customization after application launch.
        AGCInstance.startUp()
       // 将第三方平台获取的"应用编号"和"应用密钥"等参数，通过设置AGCAuthThirdPartyConfig单例的属性值的方式，传递给AGConnectAuth SDK
        AGCApplicationDelegate.sharedInstance().didFinishLaunching(options: launchOptions)
        return true
    }
```

如果您使用统一登录接口进行登录，需要根据您的应用中是否使用UISceneSession管理应用生命周期进行不同的处理。

* 如果应用使用UISceneSession来管理生命周期（iOS 13以后支持），则需要在SceneDelegate.m编辑相关代码。

  ```screen
  "Objective-C"
  - (void)scene:(UIScene *)scene openURLContexts:(NSSet<UIOpenURLContext *> *)URLContexts {
      if (URLContexts.count == 1 && URLContexts.allObjects.firstObject) {
         [[AGCApplicationDelegate sharedInstance] openURL:URLContexts.allObjects.firstObject.URL options:nil];
      }
  }
  - (void)scene:(UIScene *)scene continueUserActivity:(NSUserActivity *)userActivity {
      [[AGCApplicationDelegate sharedInstance] continueUserActivity:userActivity restorationHandler:^(NSArray<id<UIUserActivityRestoring>> * _Nullable arr) {
      }];
  }
  ```

  ```screen
  "Swift"
  func scene(_ scene: UIScene, openURLContexts URLContexts: Set<UIOpenURLContext>) {
       guard URLContexts.count == 1 else {
           return
       }
       if let url = URLContexts.first?.url {
           AGCApplicationDelegate.sharedInstance().open(url, options: nil)
       }
  }
  ```

* 如果应用中未使用UISceneSession管理应用生命周期，则需要在UIApplicationDelegate.m编辑相关代码。

  ```screen
  "Objective-C"
  - (BOOL)application:(UIApplication *)app openURL:(NSURL *)url options:(NSDictionary<UIApplicationOpenURLOptionsKey,id> *)options {
      return [[AGCApplicationDelegate sharedInstance] openURL:url options:options];
  }

  - (BOOL)application:(UIApplication *)application continueUserActivity:(NSUserActivity *)userActivity restorationHandler:(void (^)(NSArray<id<UIUserActivityRestoring>> * _Nullable))restorationHandler {
      return [[AGCApplicationDelegate sharedInstance] continueUserActivity:userActivity restorationHandler:restorationHandler];
  }
  ```

  ```screen
  "Swift"
      func application(_ app: UIApplication, open url: URL, options: [UIApplication.OpenURLOptionsKey : Any] = [:]) -> Bool {
          return AGCApplicationDelegate.sharedInstance().open(url, options: options)
      }

      func application(_ application: UIApplication, continue userActivity: NSUserActivity, restorationHandler: @escaping ([UIUserActivityRestoring]?) -> Void) -> Bool {
          return AGCApplicationDelegate.sharedInstance().continue(userActivity, restorationHandler: restorationHandler)
      }
  ```
