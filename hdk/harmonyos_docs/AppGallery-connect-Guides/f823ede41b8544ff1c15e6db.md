# 申请使用服务

素材管理服务当前仍处于Beta开放状态，申请使用素材管理服务需要向华为运营人员发送申请邮件。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260109091804.84936869835897985932489491846529:50001231000000:2800:99346F8C40FB1D25675B4370CC1F6014814035E1DED7E421D36DBF2A7A5ABAB4.png)  
素材管理目前不支持[HarmonyOS应用/元服务](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createharmonyapp-0000001945392297)。  

#### 申请步骤

请按如下格式填写申请邮件：  

|----|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|邮件标题|素材管理开通申请|
|邮件模板|* 公司名称 * 开发者账号ID：查询方法可参见[查询应用基本信息](https://developer.huawei.com/consumer/cn/doc/app/agc-help-appinfo-0000001100014694) * 应用名称 * 应用ID：查询方法可参见[查询应用基本信息](https://developer.huawei.com/consumer/cn/doc/app/agc-help-appinfo-0000001100014694) * 应用类型（应用或游戏） * 应用状态（内测 / 预约 / 已正式上架） 游戏类应用申请时请务必标明，避免功能开通失败。 * 应用场景（素材更新或素材测试）|
|收件邮箱|* 普通应用：agconnect@huawei.com * 游戏应用：game.business@huawei.com 注意： 以上邮箱仅处理AGC服务开通申请，其他咨询类问题请勿发送至以上邮箱。|

申请审核时间为1-3个工作日，审核结果请关注邮件信息或[互动中心](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-interaction-center-0000001146518763)通知。
