# 恢复下载

#### 接口描述

调用该api可恢复已暂停的下载任务。  

#### 输入参数

无  

|参数名称|参数类型|是否必选|参数说明|
|:-----------|:-----|:---|:------|
|mPackageName|String|必选|下载任务的包名|

#### 返回参数

参见AgdApi.startDownloadTaskV2的mResult  

#### 示例代码

```
ResumeTaskIPCRequest resumeTaskIPCRequest = new ResumeTaskIPCRequest();
resumeTaskIPCRequest.setPackageName(pkg);
PendingResult<ResumeTaskIPCRequest, TaskOperationResponse> pendingResultResume =
    AgdApi.resumeTask(client, resumeTaskIPCRequest);
pendingResultResume.setResultCallback(new ResultCallback<TaskOperationResponse>() {
    @Override
    public void onResult(Status<TaskOperationResponse> result) {
        Log.i(TAG, " onResult:" + result.getStatusCode());
   }
});
```
