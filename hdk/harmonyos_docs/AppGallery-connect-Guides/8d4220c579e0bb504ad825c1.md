# 其他操作

#### 查询服务器状态

您可以调用CloudDB中的[serverStatusQuery()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddb-server-nodejs-0000001734039358#section12358449111114)方法成功查询云侧服务器状态时，返回ServerStatus对象，对象中封装了云侧服务器当前时间戳。

```
import { cloud } from '@hw-agconnect/cloud-server';

const serverStatus = cloud.database({ zoneName: "QuickStartDemo" }).serverStatusQuery();
console.log('serverTimestamp=' + serverStatus.serverTimestamp);
```

#### 管理回收站数据

云数据库为用户提供数据恢复的能力，提升了数据的安全性和可用性。回收站开启后，删除的数据会被保留在回收站，且在数据保留期间，您可以对回收站的数据进行查询、删除和恢复操作。

注意事项：

* 回收站为禁用状态时，对应的数据保留天数为0天，删除的数据会被立即删除，数据不可恢复。
* 数据保留天数从数据被删除的次日0点开始计算，数据被删除当日不计入保留天数。

<!-- -->

* 数据保留天数到期之后，回收站的数据会被自动删除。
* 回收站为开启状态时，若更新或插入与回收站中相同主键的数据，使用新数据覆盖已删除的数据。原数据从回收站中移除，无法在回收站中查询得到。

代码示例：

* 使用[recycleBinQuery()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-server-nodejs-0000001766572401#section1337625435611)方法查询回收站的数据，并调用[recovery()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section1735012216398)方法恢复回收站的数据。

  ```
  import { cloud, CloudDBZoneGenericObject } from '@hw-agconnect/cloud-server';

  const collection = cloud.database({ zoneName: "QuickStartDemo" }).collection("BookInfo");
  const targetIndex = 5;

  const bookInfo = CloudDBZoneGenericObject.build("BookInfo");
  bookInfo.addFieldValue("id", targetIndex, true);
  bookInfo.addFieldValue("bookName", "The Red and the Black");
  bookInfo.addFieldValue("price", 10.99);

  try {
    const resp = await collection.delete([bookInfo]);
    console.log(resp);
  } catch (error) {
    console.warn("error=>", error);
  }

  try {
    const cloudDBZoneQuery = collection.query().equalTo("id", targetIndex);
    const resp = await cloudDBZoneQuery.recycleBinQuery();
    console.log(resp);
  } catch (error) {
    console.warn("error=>", error);
  }

  try {
    const resp = await collection.recovery([bookInfo]);
    console.log(resp);
  } catch (error) {
    console.warn("error=>", error);
  }
  ```

* 使用[recycleBinDelete()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section748263217486)方法删除回收站的数据。

  ```
  import { cloud, CloudDBZoneGenericObject } from '@hw-agconnect/cloud-server';

  const collection = cloud.database({ zoneName: "QuickStartDemo" }).collection("BookInfo");
  const targetIndex = 5;

  const bookInfo = CloudDBZoneGenericObject.build("BookInfo");
  bookInfo.addFieldValue("id", targetIndex, true);
  bookInfo.addFieldValue("bookName", "The Red and the Black");
  bookInfo.addFieldValue("price", 10.99);

  try {
    const resp = await collection.delete(bookInfo);
    console.log(resp);
  } catch (error) {
    console.warn("error=>", error);
  }

  try {
    const cloudDBZoneQuery = collection.query().equalTo("id", targetIndex);
    const resp = await cloudDBZoneQuery.recycleBinQuery();
    console.log(resp);
  } catch (error) {
    console.warn("error=>", error);
  }

  try {
    const resp = await collection.recycleBinDelete([bookInfo]);
    console.log(resp);
  } catch (error) {
    console.warn("error=>", error);
  }
  ```

#### 事务与数据管理

云数据库的事务隔离级别为Read Committed，支持通过[runTransaction()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbcollection-server-nodejs-0000001781273405#section79311129153216)执行事务，实现对云侧存储区数据的管理操作，包含数据的增、删、改、查操作。事务支持同时对多个对象类型的数据进行增、删、改、查操作。事务操作是原子的，一个事务内的所有操作要么全部执行成功，要么全部执行失败。如果执行事务时出现并发写入，云数据库会再次尝试执行整个事务，确保整个事务操作的一致性。

注意事项：

* 事务中的查询操作必须在写入操作和删除操作之前，否则将导致事务执行异常。
* 仅在正常连接网络时可执行事务操作，一旦离线该操作将失败。
* 一个事务中多次查询结果的总数据条数不能超过1000条，否则会导致事务失败。
* 一个事务中包含的写入和删除对象的总条数不能超过1000条，否则会导致事务执行失败。
* 一个事务中查询、写入和删除操作包含的字段名和字段值的总大小不能超过20MB，否则会导致事务执行失败。

代码示例：  
使用如下方法，通过事务删除云侧出版日期早于1990年的书籍。

```
import { cloud } from '@hw-agconnect/cloud-server';

const collection = cloud.database({ zoneName: "QuickStartDemo" }).collection("BookInfo");
const cloudDBZoneQuery = collection.query().greaterThanOrEqualTo("publishTime", new Date("1900-01-01T03:24:00"));
try {
  const res = await collection.runTransaction({
    apply: async (transaction: any) => {
      return new Promise(async (resolve, _) => {
        await transaction
          .executeQuery(cloudDBZoneQuery)
          .then((data: any) => {
            console.log("query data num:" + data.length);
            transaction.executeDelete(data);
          })
          .catch((err: any) => {
            console.error(err);
            resolve(false);
          });
        resolve(true);
      });
    },
  });
  console.log("the transaction result:", res);
} catch (e) {
  console.error(e);
}
```
