# 概述

Serverless抽奖活动模板提供了用户认证、奖品信息存储、抽奖结果计算等后端服务能力，可以帮助开发者统一构建和管理后端服务和云资源，在降低应用构建成本的前提下提高开发效率。通过一键部署、简单配置参数后即可实现抽奖功能。  

#### 使用流程

|序号|步骤|详情|
|:-|:------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|创建项目及应用|使用Serverless抽奖模板之前，您需要先[创建项目并为项目添加应用](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-serverless-lottery_precfg-0000001241300310#section55472613292)。|
|2|配置工程包|下载Serverless抽奖模板[配置工程包](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-serverless-lottery_cfg_deploy_package-0000001285660005)，并添加SDK配置。|
|3|部署模板|一键部署模板，配置模板参数，参见[部署模板](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-serverless-lottery_deploy_template-0000001256531726)。|
|4|使用模板|部署完成后，准备抽奖数据后[使用模板](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-serverless-use_template-0000001320585441)。|

#### 使用场景

Serverless抽奖活动模板的主要使用场景如下：

* 作为日常运营活动，鼓励用户登录App或者访问网站来抽奖，提高用户活跃度，增加用户粘性。
* 在节假日、周年庆等时间，用于策划专项抽奖活动，实现拉新促活的营销效果。
