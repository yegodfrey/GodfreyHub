# 初始化存储实例

## 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[集成云存储SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-sdk-ios-0000001126781632)。

## 操作步骤

在应用客户端使用云存储功能前，都需要初始化存储实例。您可以调用[[AGCStorage getInstance]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstorage-0000001172981557#section1143341012211)方法创建一个AGCStorage对象来初始化默认存储实例。

```screen
"Objective-C"
AGCStorage *storage = [AGCStorage getInstance];
```

```screen
"Swift"
let storage = AGCStorage.getInstance()
```

您也可以通过调用[[AGCStorage getInstance:bucketName:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstorage-0000001172981557#section1810317349494)创建一个AGCStorage对象来初始化一个指定区域存储实例。如下所示，以指定中国区为例：

```screen
"Objective-C"
AGCServicesConfig *config = [[AGCServicesConfig alloc] initWithDefaultPlist]; 
config.routePolicy = AGCRoutePolicyChina;
AGCInstance *instance = [AGCInstance getInstance:config];
AGCStorage *storage = [AGCStorage getInstance:instance bucketName:@"bucket name"];
```

```screen
"Swift"
let configRussia = AGCServicesConfig.init(defaultPlist:())
config.routePolicy = AGCRoutePolicy.china
let instance = AGCInstance.getInstance(config)
let storage = AGCStorage.getInstance(instance, "bucket name")
```
