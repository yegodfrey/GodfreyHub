# 设置麦克风状态

进入语音房间后，玩家如果不希望自身语音被房间内的其他玩家接收，可通过关闭自身麦克风实现。同时，还可以通过开启麦克风的方式快速解除自身静默状态。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241105115838.54697197999849626381049268449457:50001231000000:2800:23256FAD2A581112290F6220DE1B938CB2380A5C8AEDB3808C45A558819DAE2E.png?needInitFileName=true?needInitFileName=true)  
初始化实例后，麦克风状态默认是开启的。  

#### 前提条件

您已[加入房间](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-joinroom-roomid-android-0000001268934473)。  

#### 开发步骤

1. 调用[GameMediaEngine.enableMic](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section848817371443)方法开启/关闭玩家自身麦克风，并通过返回值获得操作结果。

   ```
   int result = mHwRtcEngine.enableMic(isEnabled);// isEnabled：true表示开启麦克风，false表示关闭麦克风
   ```

2. 开启/关闭玩家自身麦克风成功后，房间内其他玩家可在IGameMMEEventHandler接口的[onRemoteMicroStateChanged](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section17102161185211)方法中收到该事件的回调通知。

   ```
   @Override
   public void onRemoteMicroStateChanged(String roomId, String openId, boolean isMute) {
       // 可根据需求将数据进行处理
   }
   ```
