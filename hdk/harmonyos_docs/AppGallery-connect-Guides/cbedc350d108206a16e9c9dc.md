# 接入Skill（可选）

Petal Aegis SDK Skill是一个帮助开发者集成和使用Petal Aegis安全SDK的Skill。

本Skill提供以下功能：

* SDK集成指导：详细的集成步骤和配置方法
* 加解密操作：对称加密（AES、SM4）、非对称加密（RSA、ECC）
* 数字签名：签名和验签功能
* 消息摘要：SHA256等哈希算法
* 密钥管理：密钥生成、派生、存储
* 安全实践：最佳实践和常见问题解答

#### 使用场景

当用户需要在鸿蒙应用中处理以下内容时，应该使用此skill：

* 加密敏感数据（手机号、身份证、银行卡号等）
* 实现安全的密码存储
* 验证API数据的完整性
* 生成和管理加密密钥
* 计算数据哈希值
* 实现数字签名和验签  

#### 使用指导

参考《[鸿蒙应用安全编码SDK-Petal Aegis SDK Skill](https://developer.huawei.com/consumer/cn/blog/topic/03214848280805044)》下载Skill，将下载到本地的Skill文件夹复制到AI编码工具的skills目录（不同工具规范不一致，按工具要求处理），工具就能在对话中自动或按需使用。  

#### 在工具里触发Skill的使用

在对话中出现Petal Aegis时会更容易触发。

如：

* 我正在开发一个鸿蒙应用，需要加密用户的手机号码存储到数据库中。请告诉我如何使用Petal Aegis SDK来实现这个功能？
* 我想在鸿蒙应用中安全地存储用户密码，使用Petal Aegis SDK应该如何实现密码哈希？
* 鸿蒙应用中我想验证从服务器接收到的API数据是否被篡改，需要使用Petal Aegis SDK的签名功能。请给我一个完整的示例。
* 鸿蒙应用需要生成RSA密钥对，然后用公钥加密敏感数据，私钥解密。请提供Petal Aegis SDK的完整代码示例。  

#### 注意事项

密钥、私钥等敏感信息严禁出现在客户端、日志、公共仓库或者硬编码等。
