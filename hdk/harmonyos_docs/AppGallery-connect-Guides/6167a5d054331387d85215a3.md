# 配置聚合规则

APM性能监控能够自动聚合类似的网络请求数据，对于每一个请求APM会检查网络请求的URL是否与默认的URL聚合规则匹配。如果匹配，则会自动聚合该网络请求。聚合后的数据在"网络分析"页面可查询。

如果默认的聚合规则不能满足您的需求，您可通过下面的步骤自定义聚合规则，聚合您的网络请求数据。  

#### 新增聚合规则

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择需要配置聚合规则的应用。
3. 点击"质量 \> 性能管理"，进入"应用性能管理"页面。
4. 点击"配置"，进入配置页面。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155803.84902844711881210098213980538094:50001231000000:2800:9071DFBE8B23D0D7D57543E13AF3CA6643509B51CE9858E79839439530D083BF.png)

5. 点击"新增"，填写聚合规则，点击"保存"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155803.14339697516863174360325353922983:50001231000000:2800:7DC8A2339F1E8278E8565AEC45DA71CC56EC97D740F711A7749D0ED2ABE6E56F.png)

   聚合规则填写的注意事项如下：
   * 填写纯文本则会精确匹配。
   * 可以使用\*与单个路径中任何字符串匹配。
   * 可以使用\*\*与任意路径后缀匹配。
   * 可以使用\*.xxx 与xxx类型的资源字符串匹配。
   * 不能将\*与\*\*混合使用在同一个路径段中。
   * \*\*和\*.xxx只能使用在末尾。

   聚合结果会显示在网络分析页面，如下为聚合规则样例：  

   |聚合规则|聚合URL|
   |:-------------------------|:----------------------------|
   |www.baidu.com/\*|www.baidu.com/abc|
   |www.baidu.com/\*|www.baidu.com/bcd|
   |example.com/abc/\*\*|example.com/abc/abc|
   |example.com/abc/\*\*|example.com/abc/bcd|
   |example.com/\*/animal/\*\*|example.com/abc/animal/acd/bc|
   |example.com/\*/animal/\*\*|example.com/bcd/animal/acd|
   |example.com/\*/animal/\*\*|example.com/cde/animal/cde|
   |example.com/abc/\*.jpg|example.com/abc/ASDAS123.jpg|
   |example.com/abc/\*.jpg|example.com/abc/ABCDED1D.jpg|

#### 调整聚合规则优先级

点击"上移"、"下移"、"置顶"或"置底"，点击"保存顺序"。

#### 修改聚合规则

点击 "编辑"，修改聚合规则，点击"保存"。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155803.42502668958815743046338087080576:50001231000000:2800:45E679945E2784750173916C954BF149A2C63AF97735C6C0E8A8693B7E14F7E5.png)  

#### 删除聚合规则

* 批量删除：勾选需要删除的聚合规则，点击 "删除"。
* 单个删除：在需要删除的聚合规则"操作"列点击"删除"。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155803.41400982540447462239259293845642:50001231000000:2800:DDFBDF5C4AFC15003241380734C11B34620FC2081ED35A464C0811CD62E0A037.png)  

#### 测试聚合规则

点击聚合规则"操作"列的"测试"，输入测试URL，点击"测试"，可判断URL是否能被当前聚合规则聚合。
