# 用户参与开放式测试

开放式测试版本审核通过后，如果审核通过时间已超过上架时设置的测试开始时间，受邀测试用户会立刻收到测试邀请。如果审核通过时还未到测试时间，则需要到达测试时间时，测试用户才会收到测试邀请。之后用户即可前往应用分发客户端获取测试版本。
> 注意
>
> HarmonyOS设备上可搜索到Android和HarmonyOS测试应用，Android手机上只能搜索到Android测试应用。

## 前提条件

* 开放式测试版本已上架。
* 测试用户为[创建测试用户列表](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-userlist-introduction-0000001071318960#section1359254383218)中添加的有效华为账号，且已经接收到邀请邮件或短信。 说明
  >
  > 如测试用户未收到开放式测试邀请，可参考[排障指引视频](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-betatest-faqvideo-0000001071829280#section1665119586517)定位原因。
* 测试用户当前测试设备的华为账号服务地（华为应用市场客户端 > 我的 > 设置 > 国家/地区）已经切换到您的应用发布地区的范围内。

## 邮件方式

如果在用户列表中添加的华为账号是邮箱地址，则开放式测试邀请将以邮件形式发送到用户的邮箱，用户可以按照以下方法进行测试。测试过程中发现的相关问题，可以通过邀请邮件中的反馈邮箱直接反馈给开发者，开发者可以基于用户提出的问题对应用进行改进。

根据您测试应用的类型不同，受邀用户参与开放式测试的方式略有不同。

* Android/HarmonyOS应用（API ≤ 9）：用户接受邀请后会自动跳转至华为应用市场客户端安装您的测试应用。下图以Android应用邀请邮件为例进行说明。 说明
  >
  > 如果您发布的测试应用类型是快应用，用户接受邀请后不会自动跳转，可以直接前往快应用中心搜索您的应用进行测试。

* 元服务（API ≤ 9）：受邀用户收到邮件并接受邀请后，会直接跳转至华为应用市场客户端元服务详情页面，点击"打开"体验该测试服务。后续再次测试时，在应用市场直接搜索元服务名称即可。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240802171206.54707990348393838687076002684624:50001231000000:2800:770CB295049A4F658F535B3B413EBC79209E7E205CE884856983EF6820415643.png?needInitFileName=true?needInitFileName=true "点击放大")

## 短信方式

如果在用户列表中添加的华为账号是手机号，则开放式测试邀请将以短信形式发送到用户的手机。
> 注意
>
> 由于电信运营商可能会拦截邀请短信，手机格式的华为账号可能无法收到邀请短信，请尽量使用邮箱格式的华为账号。

根据您测试应用的类型不同，受邀用户参与开放式测试的方式略有不同。

* Android/HarmonyOS应用（API ≤ 9）：用户接受邀请后会自动跳转到华为应用市场客户端安装您的测试应用。下图以Android应用邀请短信为例进行说明。 说明
