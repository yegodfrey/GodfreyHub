# 云数据库移动端SDK更新通知

尊敬的开发者，您好！

为提供更优质、更稳定的服务，云数据库服务端将于2026年12月更新安全证书，届时旧的证书将停止使用。

为避免对您业务造成影响，2026年12月15日及之前请务必将云数据库移动端相关SDK更新至最新版本，以启用新证书，否则后续业务将无法正常运行。

**1** **、需更新的移动端SDK：**

本次需要更新的为云数据库Android 、iOS SDK，其他移动端SDK不涉及。

[云数据库Android SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-sdk-version-change-history-0000001127793617) ：需更新至2026年05月22日发布的**1.9.6.300及以后版本**。

[云数据库iOS SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-sdk-version-change-history-ios-0000001127559241) ：需更新至2026年6月8日发布的**1.9.4.300及以后版本**。

**2** **、更新的时间：**

请务必于2026年12月15日及之前，更新云数据库Android 、iOS SDK，以保障业务的正常运行。

感谢您对云数据库服务的支持，有任何疑惑，可以通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/ticketCard)与我们联系。
