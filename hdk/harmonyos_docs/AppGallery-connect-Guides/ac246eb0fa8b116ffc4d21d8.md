# 登出

## 前提条件

* 您需要在AGC控制台[开通认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyts6-integration-0000001553624922)。

## 开发步骤

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251226181006.78455491352819579188583770404731:50001231000000:2800:62152857958B2276B0B115D1CFD82B93EFDCC9D830D1488A077306CB8758ACF1.png "点击放大")

当用户不再使用应用，或者需要使用其他账号登录时，需要调用[AGConnectAuth.signOut](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts6-agconnectauth-0000001554065130#section4122193119119)登出当前用户。用户一旦被登出，端侧的用户信息和Token将被清除。

```screen
agconnect.auth().signOut().then(() => {
                    //登出成功
                }).catch(error => {
                    //登出失败
                });
```
