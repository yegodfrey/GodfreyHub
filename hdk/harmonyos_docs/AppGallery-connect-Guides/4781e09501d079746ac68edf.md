# 评估数据质量

为了提升预测的模型质量，使模型效果更优，您可以根据App所属行业设置行业类型，从而上报更多行业价值数据。预测服务支持按行业展示推荐上报事件、查询预测任务数据质量等。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220927160605.06406923272011711725531387292245:50530926093051:2800:DF9DB4A80AF359B61905B3CDC5A2F2B8471B428ED31FC087D8C0CE56DE99D0B2.png?needInitFileName=true?needInitFileName=true)

预测当前支持导航、电子书、购物比价、社交通讯、视频、新闻、音乐、用车和租房买房9个行业的数据质量评估，相关预置事件及参数说明请参见[预置事件说明](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/preset-event-0000001277917989)。

#### 获取数据质量

  1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击“我的项目”。
  2. 在项目列表中，找到您需要查看预测任务的项目。
  3. 点击“我的应用”进入“应用信息”页面。
  4. 在“应用分类”页签，根据您App所属的行业，在下拉框中选择对应的行业分类，并点击“保存”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220927160605.05391411466682833111375792620736:50530926093051:2800:C8200223B64C92A76FEF3CEC3D61AB255A745F9772075E9CBB3DAD8041E550DC.png?needInitFileName=true?needInitFileName=true)

  5. 行业设置完成后，等待数据上报。当“任务状态”为“评估成功”后，系统自动启动数据质量评估。 

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220927160606.71973494571019641325730495210201:50530926093051:2800:9C309D145CF4C4D58DCE5B7010D3B37B8627BA3D3907BA2B53815E9AA95AC8C7.png?needInitFileName=true?needInitFileName=true)

行业设置完成或切换行业后，需要等待50分钟，新行业设置生效。

一般情况下，最新的数据质量将于次日9:00后计算完成，您可以在预测服务页面查看。

#### 提升数据质量

数据质量由您配置的预置埋点事件数决定，优秀的数据质量可以提升预测的模型质量，从而使模型效果更优。为提升数据质量，您可以：

  * 将该行业的预置埋点事件设置齐全。
  * 建议您的用户尽快升级App版本至埋点预置事件代码的版本。


  1. 预测服务页面，点击“提升数据质量”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220927160606.10378837697694471402177074087646:50530926093051:2800:98B7C2153C176AF3B7039D9387D68794AEDDDC69F662FC81DD7A6B3B1029E49A.png?needInitFileName=true?needInitFileName=true)

  2. 根据需要选择埋点事件，系统将根据埋点事件生成代码，你可以点击右侧的“拷贝”或“下载”，并将代码粘贴至您的App代码中。相关预置事件及参数说明请参见[预置事件说明](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/preset-event-0000001277917989)。 

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220927160606.79822195562132643999472968135125:50530926093051:2800:A6A13BB62449005FC680112CE53A25256AD26D2B3182BEA819A286858DFE5472.png?needInitFileName=true?needInitFileName=true)

您可以通过点击“已上报事件”，查看到当前已上报的数据事件，也可以通过点击“只显示未上报事件”，查看当前还未上报的数据事件，从而重新规划您的上报事件，提升数据质量。
