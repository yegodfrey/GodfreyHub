# 下载文件

文件上传到云端后，您可以通过调用云存储SDK的API将云端文件下载到本地设备中。

## 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[初始化存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-initialize-bucket-ios-0000001333893477)。
* 您已[上传文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-upload-ios-0000001172981227)。

## 操作步骤

> 说明
>
> 在下载文件前，您可以先[获取文件的元数据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-metadata-ios-0000001172981229#section12745413165215)，查看后再决定是否要下载文件。

1. 调用[[AGCStorage referenceWithPath:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstorage-0000001172981557#section9635163510919)创建需要下载文件的引用。

   ```screen
   "Objective-C"
   //storage为已经初始化的AGCStorage实例
   AGCStorageReference *reference = [storage referenceWithPath:@"images/demo.jpg"];
   ```

   ```screen
   "Swift"
   //storage为已经初始化的AGCStorage实例
   let reference = storage.reference(withPath:"images/demo.jpg")
   ```

2. 调用[[AGCStorageReference downloadToFile:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragereference-0000001126781968#section12372204523919)方法将云端文件数据写入本地文件中。

   ```screen
   "Objective-C"
   AGCStorageDownloadTask *task = [reference downloadToFile:fileUrl];
   ```

   ```screen
   "Swift"
   let task = reference.download(toFile:fileUrl)
   ```

3. 通过调用[AGCStorageTask](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragetask-0000001126941788)类的[pause](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragetask-0000001126941788#section51031754194515)、[resume](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragetask-0000001126941788#section9240586453)、[cancel](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragetask-0000001126941788#section118931831144413)方法可以切换下载任务的状态。

   ```screen
   "Objective-C"
   AGCStorageReference *reference = [storage referenceWithPath:@"images/demo.jpg"];
   AGCStorageDownloadTask *task = [reference downloadToFile:fileUrl];
   [task pause];
   [task resume];
   [task cancel];
   ```

   ```screen
   "Swift"
   let reference = storage.reference(withPath:"images/demo.jpg")
   let task = reference.download(toFile:fileUrl)
   task.pause()
   task.resume()
   task.cancel()
   ```

4. 通过调用[AGCStorageTask](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragetask-0000001126941788)类的[addOnProgressCallback:](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragetask-0000001126941788#section1882115711353)、[addOnPausedCallback:](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragetask-0000001126941788#section1612010132815)、[addOnSuccessCallback:](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragetask-0000001126941788#section04161846132311)、[addOnFailureCallback:](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragetask-0000001126941788#section1310411516227)、[addOnCanceledCallback:](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragetask-0000001126941788#section193211347184017)、[addOnCompleteCallback:](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragetask-0000001126941788#section1824418011813)方法，添加AGCStorageDownloadTask的回调来监控下载任务中的状态。
   * addOnProgressCallback：当下载任务中需要定期刷新任务进度时调用此回调。
   * addOnPausedCallback：当任务暂停时调用此回调。
   * addOnSuccessCallback：当任务成功时调用此回调。
   * addOnFailureCallback：当任务失败时调用此回调。
   * addOnCanceledCallback：当任务取消时调用此回调。
   * addOnCompleteCallback：当任务完成时调用此回调。

   ```screen
   "Objective-C"
   AGCStorageReference *reference = [storage referenceWithPath:@"images/demo.jpg"];
   AGCStorageUploadTask *task = [reference downloadToFile:fileUrl];
   [[[[[[task addOnFailureCallback:^(NSError *error){
   }] addOnSuccessCallback:^(AGCStorageDownloadResult *result){
   }] addOnProgressCallback:^(AGCStorageDownloadResult *result){
   }] addOnPausedCallback:^(AGCStorageDownloadResult *result){
   }] addOnCanceledCallback:^{
   }] addOnCompleteCallback:^(AGCStorageTask<AGCStorageDownloadResult *> *task){
   }];
   ```

   ```screen
   "Swift"
   let reference = storage.reference(withPath:"images/demo.jpg")
   let task = reference.download(toFile:fileUrl)
   task.onSuccess{(result) in 
   }.onFailure{(error) in
   }.onProgress{(result) in 
   }.onPaused{(result) in 
   }.onCanceled{(result) in 
   }.onComplete{(task) in 
   }
   ```

> 说明
>
> downloadToFile接口支持断点续传，当下载过程中因出现异常导致下载失败时，再次调用downloadToFile可以继续下载文件，提升用户下载体验。

## 更多信息

除了在应用客户端通过云存储SDK的API来下载文件，您还可以直接[在AGC控制台以可视化的方式来下载文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-manage-file-0000001281134398#section116002011710)。
