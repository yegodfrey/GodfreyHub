# 使用入门

#### 注册成为开发者

在开发应用前需要在[华为开发者联盟](https://developer.huawei.com/consumer/cn)网站上注册成为个人/企业开发者并完成实名认证，具体方法可参考"[账号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)"。  

#### 创建项目和应用

参见[创建项目](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createproject-0000001100334664)和[创建应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createapp-0000001146718717)完成应用的创建。

如果是[AppTouch HMS](https://developer.huawei.com/consumer/cn/doc/app/jieshao-0000001063049556)生态项目，应用包名不能与开发者联盟上AppTouch游戏项目已经上传的应用包名重复，如果重复则需要重新指定一个应用包名。  

#### 获取版权保护信息

获取版权保护信息目的是获得"版权保护id"和"版权保护公钥"，用于代码开发中接口入参。

1. 登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择需要获取版权保护信息的应用。
3. 在左侧导航选择"盈利 \> 付费下载"。
4. 点击"版权保护id"和"版权保护公钥" 后的![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704162201.39784541418556055012731291848834:50001231000000:2800:5E5CF07E1FD0A215A43452D7E45AF2F49BE16043E8F2BC8EC79B3F992EFF2374.png)复制内容。

#### 集成AppGallery DRM Service SDK

开发者要在华为应用市场中发布付费下载的应用时，需要在其应用中集成AppGallery DRM Service SDK。AppGallery DRM Service SDK向开发者提供检查用户是否已经购买过应用的接口，应用根据该接口返回的结果，只授权已经购买了应用的用户使用该应用，从而起到版本保护作用。  

#### 在Android Studio中集成AppGallery DRM Service SDK

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704162201.65649156497523514140657615862587:50001231000000:2800:E24164DD38B4590DFC5339BA5D8919B60B80CA3257DAC51FD79EA9D9CEA30C26.png)  
请使用3.5.4及以上版本的Android Gradle插件。

1. 配置maven仓地址 Android Studio的代码库配置方式随Gradle插件的不同版本有所不同。请根据您当前Gradle插件的版本，选择相应的配置方式。

   |-----------------------------------------------------------|-----------------------------------------------------------|
   |[【7.0及以上版本】](#ZH-CN_TOPIC_0000001074231614__p8557337192615)|[【7.0以下版本】](#ZH-CN_TOPIC_0000001074231614__p11273724175118)|

   【7.0及以上版本】
   1. 打开Android Studio项目级settings.gradle文件。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704162201.00407987472665197424803057444084:50001231000000:2800:33675DF530BD10F234F7D548627A19931F544F02F10D165ACD4BEEA6666FF931.png)

   2. 在dependencyResolutionManagement -\>repositories里面配置AppGallery DRM Service SDK的maven仓地址。

      ```
      dependencyResolutionManagement {
          ...
          repositories {
              ... 
              maven {url 'https://developer.huawei.com/repo/'}
          }
      }
      ```

   【7.0以下版本】
   1. 打开Android Studio项目级build.gradle文件。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704162201.62343809360929227845451993149658:50001231000000:2800:A30CE1C14DF52C4B78DC5271B101A6563DDAE75EA44324AC5523E8295D8B7CA7.png)

   2. 在allprojects -\>repositories里面配置AppGallery DRM Service SDK的maven仓地址。

      ```
      allprojects { 
          repositories { 
                      ...
                      maven { url 'https://developer.huawei.com/repo/'}
         } 
      }
      ```

2. 添加编译依赖
   1. 打开应用级的build.gradle文件。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704162201.70452526439961359697919940917920:50001231000000:2800:F29AADE6A544B4A025DBA1CDFDAFF9416B409C50A4F493933962FD43BCD185E6.png)

   2. 在"dependencies"中添加AppGallery DRM Service的编译依赖。

      ```
      dependencies { 
          //其中{version}替换为实际的SDK最新版本号(目前AppGallery DRM Service SDK最新版本为2.6.0.306)。    
          implementation 'com.huawei.hms:drm:{version}'
      }
      ```

#### 配置混淆脚本

开发者编译APK前需要配置，不要混淆本SDK，避免功能异常。

1. 打开android工程的混淆配置文件。
2. 加入排除的混淆配置 。

   ```
   -keep class com.huawei.android.sdk.drm.**{*;}
   -ignorewarnings
   -keepattributes *Annotation*
   -keepattributes Exceptions
   -keepattributes InnerClasses
   -keepattributes Signature
   -keepattributes SourceFile,LineNumberTable
   -keep class com.huawei.updatesdk.**{*;}
   -keep class com.huawei.hms.**{*;}
   ```

3. 如果开发者使用了AndResGuard，需要在混淆配置文件中加入AndResGuard允许清单。

   ```
   "R.string.hms*", 
   "R.string.connect_server_fail_prompt_toast", 
   "R.string.getting_message_fail_prompt_toast", 
   "R.string.no_available_network_prompt_toast", 
   "R.string.third_app_*", 
   "R.string.upsdk_*", 
   "R.layout.hms*", 
   "R.layout.upsdk_*", 
   "R.drawable.upsdk*", 
   "R.color.upsdk*", 
   "R.dimen.upsdk*", 
   "R.style.upsdk*"
   "R.string.agc*"
   ```
