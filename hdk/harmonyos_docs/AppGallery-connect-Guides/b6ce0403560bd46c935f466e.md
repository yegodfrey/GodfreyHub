# （可选）跨域设置

如需在不同的站点访问指定的存储实例，可以设置跨域的相关配置，服务器将通过配置的跨域信息进行相关允许、拒绝等操作。  

#### 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[创建Bucket对象](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-createreference-nodejs-0000001055327465#section18561161643714)。  

#### 操作步骤

1. 定义跨域配置，参考Array\<[Cors](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/cors-0000001057785991)\>对象。

   ```
   const rules = [{  "methods": ["GET", "POST", "PUT"],  "origins": ["https://localhost:443"]}]
   ```

2. 调用[Bucket.setCorsConfiguration](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/bucket-0000001057141584#section1829933753513)方法为指定的存储实例设置跨域配置。

   ```
   bucket.setCorsConfiguration(rules).then(res => {}).catch(errRes => {})
   ```

[Bucket.setCorsConfiguration](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/bucket-0000001057141584#section1829933753513)方法仅需调用一次，跨域配置即可生效。
