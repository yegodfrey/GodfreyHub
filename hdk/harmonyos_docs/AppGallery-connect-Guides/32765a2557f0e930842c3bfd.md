# 设置场景和标签

您可以自定义某个典型或卡顿的游戏场景，例如打斗、团战。若还想在场景中标记一段特殊的子场景信息，可以在场景中设置标签，用以标识该子场景中的性能数据。同个场景中可设置多个标签，但多个标签之间不可嵌套。标签与场景是依附关系，若未设置场景，设置标签将无效，场景与标签的时序图如下：

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110244.07112196966340828334173497803674:50001231000000:2800:25F2731C9FC9DC95EB34191B8ADF203377CCF326D92EA629E42E5BDD75892B5C.png "点击放大")  

#### 前提条件

* 已[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-integration-ios-0000001932600658)。
* 已[初始化SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-initialization-ios-0000001932441278)。
* 已[开启数据采集器](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-open-close-collector-ios-0000001959599833#section72707115441)。  

#### 开发步骤

1. 导入头文件。

   ```
   #import <GPMKit.h>
   ```

2. 加载游戏场景前，调用[GPMManager.getInstance setSceneStart](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-ios-gpmmanager-0000001941578500#section83450342099)，同时游戏性能管理SDK开始采集、上报游戏的性能数据。

   ```
   [GPMManager.getInstance setSceneStart:@"场景1"];
   ```

   可在GPMCallbackDelegate接口的[onSetSceneStart](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-ios-gpmcallbackdelegate-0000001968617713#section166183317119)方法中查看结果并实现回调处理。

   ```
   - (void)onSetSceneStart:(int)code msg:(NSString *_Nonnull)msg {
       // 可根据需求将数据进行处理
   }
   ```

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110244.56374717576200407631021071882940:50001231000000:2800:BC5C0E168DB40B20A5D1E5554AF0CE4B17C8BE76E715C83D7E4D2070A1D4AE78.png)  
   若当前已有正在采集的场景，且场景名称不同，则自动结束上个场景的数据采集，开启新场景的数据采集。
3. （可选）场景加载完成后，调用[GPMManager.getInstance setLoadSceneCompleted](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-ios-gpmmanager-0000001941578500#section5837142071217)方法，计算加载游戏场景的耗时。

   ```
   // AGC控制台当前暂不支持展示该数据项
   [GPMManager.getInstance setLoadSceneCompleted];
   ```

   可在GPMCallbackDelegate接口的[onSetLoadSceneCompleted](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-ios-gpmcallbackdelegate-0000001968617713#section05952201217)方法中查看结果并实现回调处理。

   ```
   - (void)onSetLoadSceneCompleted:(int)code msg:(NSString *_Nonnull)msg {
       // 可根据需求将数据进行处理
   }
   ```

4. （可选）若想在场景中标记特殊子场景的性能数据时，调用[GPMManager.getInstance setTagStart](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-ios-gpmmanager-0000001941578500#section1015212671720)方法，设置标签。

   ```
   // AGC控制台当前暂不支持展示标签标记的性能数据
   [GPMManager.getInstance setTagStart:@"场景1-TAG1"];
   ```

   可在GPMCallbackDelegate接口的[onSetTagStart](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-ios-gpmcallbackdelegate-0000001968617713#section761061313176)方法中查看结果并实现回调处理。

   ```
   - (void)onSetTagStart:(int)code msg:(NSString *_Nonnull)msg {
       // 可根据需求将数据进行处理
   }
   ```

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110244.43973754655463901959074222768678:50001231000000:2800:E2F2227FBCA7C577146323E53F290EBE881E06DAF0BBAEF753930EA99767A468.png)  
   若当前已有标签正在采集，且标签名称不同，则自动结束上个标签，开启当前标签的性能数据采集。
5. （可选）调用[GPMManager.getInstance setTagEnd](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-ios-gpmmanager-0000001941578500#section18108163414405)方法，结束标签。

   ```
   [GPMManager.getInstance setTagEnd];
   ```

   可在GPMCallbackDelegate接口的[onSetTagEnd](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-ios-gpmcallbackdelegate-0000001968617713#section166579343182)方法中查看结果并实现回调处理。

   ```
   - (void)onSetTagEnd:(int)code msg:(NSString *_Nonnull)msg {
       // 可根据需求将数据进行处理
   }
   ```

6. 调用[GPMManager.getInstance setSceneEnd](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-ios-gpmmanager-0000001941578500#section165425913151)方法，结束场景。

   ```
   [GPMManager.getInstance setSceneEnd];
   ```

   可在GPMCallbackDelegate接口的[onSetTagEnd](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-ios-gpmcallbackdelegate-0000001968617713#section166579343182)方法中查看结果并实现回调处理。

   ```
   - (void)onSetSceneEnd:(int)code msg:(NSString *_Nonnull)msg {
       // 可根据需求将数据进行处理
   }
   ```

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110244.67065958904217916153580196041059:50001231000000:2800:D204C283A31DC9257AB0145D5E313363F4F583522C643CC42D60C91F97788270.png)  
结束场景将停止采集数据，同时结束正在采集的标签。
