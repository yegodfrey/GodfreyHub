# 使用入门

## 创建您的项目和应用

参考[AppGallery Connect服务使用入门](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-started-web-0000001057762291)完成如下操作：

* 创建您的AGC项目
* 在项目下创建应用
* 设置默认数据处理位置

## 启用服务

首次使用性能管理服务前，需要先启用此服务。如果您已经启用，可跳过本步骤。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择需要开通性能管理服务的应用。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251125162004.79512619935554058144661879983477:50001231000000:2800:431BDF44319BF4DADD7784F5F227CE2FE93D2833720E03A81A1FFCAD8082CEE0.png)

3. 进入"质量 > 性能管理"，如果APM服务未开通，请点击"立即开通"，开通APM服务。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251125162004.83402224323309428863114539827623:50001231000000:2800:257CA5EECE3E8A79427834FF1B1273C3CBD65B196A4A454BAFA4649E030E3964.png)

## 集成APM JS SDK

> 注意
>
> APM JS SDK暂不支持IE和Edge浏览器。

1. 下载APM JS SDK，并解压zip包放置到项目中。 APM JS SDK 下载地址：[性能管理Web客户端SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Library/agc-apm-web-sdkdownload-0000001052487237)

2. 在<head>标签引入APM JS SDK脚本，引入路径请填写脚本所在路径。
   * 单页应用：在index.html添加引用。
   * 多页应用：在需要监控的多个html页面添加引用。
3. 在<script>下编写一个函数并执行，将从AGC网站获取的应用配置信息粘贴到函数内，并修改成您应用的实际配置信息。 关于如何获取应用配置信息，请参见[获取应用配置信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-started-web-0000001057762291#section0451145762420)。


4. 设置应用配置信息，初始化AGC SDK。
5. 调用[enable](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/apm-web-0000001053266118#section7204103935710)启用/禁用APM性能监控数据采集。默认为启用状态。

示例：

```screen
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>apm</title>
  <!-- 步骤1 引入APM JS SDK脚本 -->
  <script src="./apm-agconnect.min.js"></script>
  <script>
    (function () {
      // 步骤2 开发者在AGC网站获取并替换成自己应用的配置信息
      const agConnectConfig = {
        //将https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-started-web-0000001057762291#section0451145762420拷贝至此
      }
      // 步骤3 设置应用配置信息，初始化AGC SDK
      agconnect.instance().configInstance(agConnectConfig)

      // 步骤4 (可选) 启用/禁用APM性能监控数据采集 默认为启用状态
      APM.enable(true) 
    })()
  </script>
</head>
<body>
</body>
</html>
```
