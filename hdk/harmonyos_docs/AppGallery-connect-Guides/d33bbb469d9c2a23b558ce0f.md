# 列举文件

列举文件是指获取某个目录下的所有文件和目录信息，云存储SDK支持通过API列举云端某个目录下的所有文件或子目录。

## 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[初始化存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-initialize-bucket-harmonyos-ts-0000001678555281)。
* 您已通过认证服务登录应用。

## 操作步骤

1. 调用[Storage.list](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-storage-storage-0000001679582393#section14179124773813)方法可获取指定目录下所有文件与目录。

   list方法的参数可选，不传则列举根目录下的所有文件与目录。

   ```screen
   let listFiles = await storage.list({
       cloudPath: "image"
   })
   ```

2. 如需分页列举指定目录下的文件与目录，可参考以下代码调用。

   ```screen
   let listFiles = await storage.list({
       cloudPath: "image",
       pageMarker: "demo.jpg",
       maxResults: 10
   })
   ```

   其中，pageMarker是获取分页列表信息时下一页的起始位置，maxResults为列举的文件与目录的最大数量。若maxResults为空，则列举以pageMarker为起始位置之后的所有文件与目录。
