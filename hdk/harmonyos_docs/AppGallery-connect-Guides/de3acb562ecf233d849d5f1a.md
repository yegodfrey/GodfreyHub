# 设置应用内默认值

## 获取远程配置对象实例

调用[AGConnectConfig.getInstance](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmony-remoteconfig-agconnectconfig-0000001142408632#section206211537135210)获取远程配置对象实例用于设置应用内默认参数值，从云端提取更新的参数值，并控制提取的值的参数更新方式。

```screen
"Java"
AGConnectConfig config = AGConnectConfig.getInstance();
```

## 设置应用内默认值

您可以在远程配置对象中设置应用程序内的默认值，以便您的应用程序在连接到远程配置服务之前按照预期运行。如果云端未设置参数值，则可以使用本地默认值。 当前支持两种类型的默认值：

* XML资源文件类型的默认值 在工程的resources/profile中增加一个远程配置默认值的xml文件，其中键值对为<value key="testkey">testvalue</value>，例如文件configdefault.xml。

  ```screen
  <remoteconfig>
       <value key="test1">test1</value>
       <value key="test2">true</value>
       <value key="test3">123</value>
       <value key="test4">123.456</value>
       <value key="test5">test-test</value>
  </remoteconfig>
  ```

  调用[AGConnectConfig.applyDefault](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmony-remoteconfig-agconnectconfig-0000001142408632#section9109980584)传入默认值，传入后立即生效。

  ```screen
  "Java"
  config.applyDefault(ResourceTable.Profile_configdefault);
  ```

* Map对象的默认值 可参考如下配置调用[AGConnectConfig.applyDefault](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmony-remoteconfig-agconnectconfig-0000001142408632#section42628541407)传入默认值，其中Object只支持String、Boolean、Number类型，如传入其他类型则会忽略。

  ```screen
  "Java"
  Map<String, Object> map = new HashMap<>();
  map.put("test1", "test1");
  map.put("test2", "true");
  map.put("test3", 123);
  map.put("test4", 123.456);
  map.put("test5", "test-test");
  config.applyDefault(map);
  ```

您可以在AppGallery Connect[设置新的云端配置项](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-remoteconfig-harmonyos-cloudconfig-0000001183768015)，并根据业务逻辑配置不同的值，然后在应用中所需位置[获取云端配置项](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-remoteconfig-harmonyos-obtainconfig-0000001184687215)，从而灵活更新应用中的信息。
