# 获取当前发言玩家列表

通过本章的开发指导，您可实现获取房间内当前发言玩家列表以及对应的音量分贝的功能。

## 前提条件

您已[加入房间](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-joinroom-roomid-android-0000001268934473)。

## 开发步骤

开启音量回调，并通过音量回调接口获取当前发言玩家ID列表以及对应的音量分贝。

1. 调用[GameMediaEngine.enableSpeakersDetection](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section2174114234915)方法设置回调时间间隔来开启音量回调，用于获取当前房间发言玩家列表。

   ```screen
   mHwRtcEngine.enableSpeakersDetection(String roomId, int interval); // roomId：房间ID; interval:当前发言玩家列表回调的时间间隔,有效值范围为[100, 10000],单位: 毫秒,当传入0时,即关闭音量回调
   ```

2. 当成功开启音量回调时，可通过相关接口获得当前发言玩家的ID列表等信息。
   * 1.7.1.300（含）之前的版本：在IGameMMEEventHandler接口的[onSpeakersDetection](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section1778813202086)方法中可获得当前发言玩家的ID列表。 说明
     >
     > 根据当前发言玩家的音量大小降序排序，列表中最多可展示当前4个发言玩家。

     ```screen
     @Override
     public void onSpeakersDetection(List<String> openIds) {
         LogUtil.d(TAG, "onSpeakersDetection: openIds=" + openIds);
         // 可根据需求将数据进行处理
     }
     ```

   * 1.7.1.300（不含）之后的版本：在IGameMMEEventHandler接口的[onSpeakersDetectionEx](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section26391093506)方法中可获得当前发言玩家的ID列表以及对应的音量分贝。 说明
     > * 根据当前发言玩家的音量大小降序排序，列表中最多可展示当前4个发言玩家。
     > * 音量分贝大小区间为[1,100]。

     ```screen
     @Override
     public void onSpeakersDetectionEx(List<VolumeInfo> userVolumeInfos) {
         LogUtil.d(TAG, "onSpeakersDetectionEx : userVolumeInfos=" + userVolumeInfos);
         // 可根据需求将数据进行处理
     }
     ```
