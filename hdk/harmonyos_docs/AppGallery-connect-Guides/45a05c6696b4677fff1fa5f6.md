# 认证服务触发器

AGC认证服务为您提供了基于云函数服务的扩展机制，您可以为云函数配置认证服务触发器来接收用户的注册、登录等关键事件，并在云函数中扩展您的业务处理逻辑。

比如，您可以创建函数并为其添加"用户注册"事件类型的认证服务触发器，当认证服务检测到用户注册事件发生时将触发函数，以便进行用户业务数据的初始化。您也可以创建函数并为其添加"用户销户"事件类型的认证服务触发器，当认证服务检测到用户销户事件发生时将触发函数，以便进行用户业务数据的清理。

## 前提条件

您已[创建函数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/serverless-create-and-config-func-0000001713008121)。

## 创建认证服务触发器

1. 在函数列表中点击函数名称进入函数详情页面。如果点击函数名称右侧"操作"列的"别名"，则在别名列表中点击别名名称，进入别名详情页。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251205152525.98280826843265406318593819589316:50001231000000:2800:9162A9FC2A690882D01D19058C1A5256223871003E371E3D1F681C2869C37E41.png)

2. 点击"触发器"页签下的"添加触发器"，显示触发器创建界面。
3. 在"添加触发器"页面，"触发器类型"选择"认证服务触发器"，并配置"事件类型"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251205152525.85723284156075263751025456930040:50001231000000:2800:ACF509AE45C6E06B77F7E54CDE6DD9A13C5E174D25C418564AFC4DE4EF06904D.png)

   |参数|说明|
   |:----|:-----------------------------------------------------------------------------------------------------------------------------|
   |触发器类型|认证服务触发器。|
   |事件类型|触发器支持的事件类型。 * 用户注册事件。 * 用户销户事件。 * 用户登录事件。 * 用户登出事件。 > 说明 > * 同一个事件，一个函数只能绑定一次。 > * 一个函数可以被认证服务的多个事件类型触发，一个认证服务的事件类型可以触发多个函数执行。|

4. 触发器配置完成后点击"确定"保存触发器，则回到触发器列表，可看到认证服务触发器图框。
