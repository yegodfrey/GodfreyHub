# 申请调试设备

在云调试主界面，您可以从系统版本、分辨率、是否优惠机型等维度筛选设备，筛选完成后，每次申请一台设备进行调试，以验证应用在指定机型上的表现。  

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击需要调试的项目。
3. 在左侧导航栏选择"质量 \> 云调试"，进入云调试主界面。 ![](https://media:201778314572575134 "点击放大")

<!-- -->

4. 根据实际需要选择设备页签（默认选中"全部"设备类型），点击"筛选条件"，您可以从品牌、系统版本、设备形态、分辨率、上市时间、是否优惠机型、是否热门机型等维度筛选出待调试的机型，鼠标放置在状态为空闲（设备名称后有绿色标志）的设备上方，点击"开始测试"。 您账号内的优惠时长仅适用于带"惠"标识的优惠机型，您可以勾选"优惠机型"筛选支持免费调试的机型。

   ![](https://media:201778314572606135)  
   * 当前除华为和荣耀以外品牌的调试设备暂不支持修改系统设置。
   * 当前不支持在第三方品牌设备上调试快应用。

   ![](https://media:201778314572642136 "点击放大")
5. 在弹出的"提醒"框中确认剩余额度后，点击"确定"，系统将预扣特定的时间额度。系统按照"优惠时长 ＞ 套餐余额 ＞ 按量付费"的优先顺序扣除调试时间，详见[计费优先级说明](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddebug-pricing-0000001213560484#section14889225364)。

   如果剩余的优惠时长额度不足，您可以点击"[购买套餐包](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddebug-pricing-0000001213560484#section1554613186493)"订购项目付费套餐，或点击"[开通按量计费](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddebug-pricing-0000001213560484#section12857373426)"升级到付费档，根据实际使用量付费。

   ![](https://media:201778314572676137)
6. 使用优惠时长进行设备调试时，单次调试时间不得超过20分钟。当20分钟优惠调试时长即将用尽时，系统会弹出如下提示框询问您是否需要延长调试时间。
   * 如需延长调试时间且剩余优惠时长额度充足时，请点击"延长一次"，系统将在20分钟基础上再增加20分钟调试时间，您可以继续调试。
   * 如无需延长调试时间，则点击"不需要"，当20分钟调试时长用尽时，系统将释放调试设备。

   ![](https://media:201778314572711138)
7. 如您点击了"延长一次"，当40分钟优惠调试时长即将用尽时，系统会再次弹框提示您。 ![](https://media:201778314572742139)

   * 如您点击"我知道了"，当40分钟优惠调试时长用尽时，调试设备将被释放，您需要重新申请设备才能继续调试。
   * 如您点击"购买套餐包"，则可以在弹出的"购买"窗口中购买付费套餐包或开通按量付费。当40分钟优惠调试时长用尽时，调试设备将被释放。您可以重新申请调试设备，并在优惠调试时长即将用尽时，如下图所示，根据实际调试情况选择是否使用付费套餐额度继续进行调试。 ![](https://media:201778314572784140)
