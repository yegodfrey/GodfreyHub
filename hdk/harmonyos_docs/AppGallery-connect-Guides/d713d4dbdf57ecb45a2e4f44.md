# 列举文件

列举文件是指获取某个目录下的所有文件和目录信息，云存储SDK支持通过API列举云端某个目录下的文件或子目录。

## 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[创建Bucket对象](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-createreference-nodejs-0000001055327465#section18561161643714)。

## 操作步骤

1. 定义待枚举的目录的详细参数。例如枚举images目录下的文件与子目录：

   ```screen
   const options = {
       delimiter: '/',
       prefix: 'images/'
   };
   ```

2. 调用[Bucket.getFiles](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/bucket-0000001057141584#section8826145993219)方法获取当前目录下的文件与子目录。

   ```screen
   bucket.getFiles(options).then(
       (res)=>{
   });
   ```
