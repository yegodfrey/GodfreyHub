# 部署游戏排行榜

## 前提条件

* 您已[创建项目并添加应用](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-serverless-leaderboards-conf-0000001322492309#section2089664483614)，用以部署游戏排行榜模板。
* 您的游戏已[设置数据处理位置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-data-storage-location-0000001162597847#section154810363471)。

## 部署模板

1. 进入[Serverless模板](https://developer.huawei.com/consumer/cn/service/josp/agc/marketplace/index.html#/serverless)页面，点击"游戏排行榜"模板的"部署"后登录华为账号。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251028134001.22451401848083742993975276890932:50001231000000:2800:DC3D90DDD81F8BBDD51CC12465329037FC275375EB062D2146A75EEBCA61A043.png)
2. 成功登录华为账号后，页面跳转至"开发与服务"，请选择部署游戏排行榜的项目。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251028134001.09482965420411227353652261482826:50001231000000:2800:AA1FEB448C5F832F82738373959A9DA783C89ECE80D44E2D52E336136B63BB8F.png)

   > 说明
   >
   > 若您选择的项目尚未开通游戏排行榜模板所依赖的云函数和云数据库服务，将会有弹窗为您自动开通服务。
3. 在"部署模板"页面的"选择数据处理位置"步骤下，请选择部署游戏排行榜的数据处理位置，完成后点击"下一步"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251028134001.00725846339272950368309866745636:50001231000000:2800:ACE5F1BCAF9BBA37C8610E0657E9F114AC45ECA35E87BC88D9BBDB441303F814.png)

   > 说明
   >
   > 当前"游戏排行榜"模板的数据处理位置仅支持"中国"。
4. 在"配置参数"步骤下，请根据提示配置参数。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251028134001.61693400876976603823733668996827:50001231000000:2800:EDC1A3DEAA4A3EE1D60FA7248B9BE787725FF4DDD45F313E21A47AD4C1A198C5.png)

   |配置参数|说明|
   |:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |agc认证服务开关|请选择认证玩家身份的方式： * 开：表示您开通认证服务，该服务可为您的游戏快速构建安全可靠的用户认证系统，帮助您轻松完成用户认证的鉴权工作。您仅需在调用云函数前[获取Token值](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-serverless-leaderboards-obtaintoken-0000001272909766)。 * 关：表示您不开通认证服务，您可以自定义认证方式。您需要提供认证服务地址，并实现获取玩家ID接口。|
   |自定义认证服务地址|"agc认证服务开关"为"关"时必填，且仅支持https协议。请填写认证服务地址，用于[获取玩家ID](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agc-serverless-get-id-0000001296645276)。|

5. 在"部署"步骤下，点击"开始部署"，游戏排行榜模板将会自动部署如下服务：
   * 将在"云函数"页面自动生成云函数接口并为每个接口添加对应的触发器。
   * 将在"云数据库"页面自动创建游戏排行榜的数据字段。部署成功后，您需要[初始化云数据库](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-serverless-leaderboards-clouddb-0000001322949809#section5593267101)。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251028134001.11798864017776050718556664427632:50001231000000:2800:F5444A7B2B10D3043D48F8425E63B273D9DC4BD23DF0C50BE1850A8885DED459.png)
   > 注意
   >
   > 若部署多次仍失败，请在互动中心[反馈问题](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/interactive/feedback)或[在线提交工单](https://developer.huawei.com/consumer/cn/support/feedback/#/add/89?level2=9069)，华为工作人员将在1~3个工作日内进行处理。
6. 成功部署后，您可以在"Serverless模板"页面查看已成功部署的模板。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251028134002.67353181253681907653093184839986:50001231000000:2800:843CE708CA9FAC7518B4770F6BAAE4E62B22672DF51A0ABD2154C47F16E4BD50.png)

   > 说明
   >
   > 若升级"游戏排行榜"模板，请确认重新部署后的云函数与云数据库的"部署时间"是否为最新时间。
