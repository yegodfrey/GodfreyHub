# 创建测试用户列表

测试用户需要在AGC中以用户列表的形式来管理，您可以将您的测试用户添加到用户列表中，在分发应用的开放式测试版本时选择对应的用户列表。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107171425.79667466567741560637612213470960:50001231000000:2800:67A2F93A60B2DAC2AA424A2A7432FB253E2B7F9E4059540081E976F41645C91B.png)

## 前提条件

您已准备好需要配置的测试用户账号信息，必须是有效的华为账号。
> 说明
>
> 如测试用户尚未注册华为账号，请参考[注册华为账号](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)进行注册。

## 创建用户列表

在分发开放式测试版本之前，需要先创建参与开放式测试的用户列表。您最多可创建30个测试用户列表，每天最多可执行20次创建操作。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，执行如下操作。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107171426.00595151188334452780443475828749:50001231000000:2800:ED9C11D682CE91262712FFD00BC904C6F908B73A8AA3E5E6080CD72289C4409B.png "点击放大")
2. 配置测试用户。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107171426.12279162903763643260197189671015:50001231000000:2800:CAB36D7D532577C08635190EDF732AE2A95EFBFF55BEF5423F51E3DCB27EB70D.png)

   |序号|参数|说明|
   |:-|:-----|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |1|列表名称|您为测试用户的列表自定义的名称，最大支持64个字符，不能包含特殊字符。例如："Chinese User"。|
   |2|列表存储位置|根据安全隐私要求，您需要根据用户列表中用户的注册站点选择数据存储位置。 * 所有站点：如果用户列表中的用户包含全球范围用户，或应用发布地区的站点不包含测试用户所在站点，请务必选择"所有站点"。 * 中国：应用发布区域包含中国大陆，且用户列表中都是中国大陆用户时选择。 * 俄罗斯：应用发布区域包含俄罗斯，且用户列表中都是俄罗斯用户时选择。 * 德国：应用发布区域包含欧盟/欧洲经济区任意国家或地区，且用户列表中都是欧盟/欧洲经济区用户时选择。 * 新加坡：应用发布区域包含除上述地区以外的任意国家或地区，且用户列表中都是非中国大陆、非俄罗斯、非欧盟/欧洲经济区用户时选择。 > 注意 > 请务必确保用户列表存储位置在应用发布国家或地区的范围内，否则测试用户将无法通过应用市场客户端搜索到该应用。|
   |3|用户信息|选择用户信息的配置方式。 * 手动输入：如果选择手动输入方式创建测试用户列表，选择"手动输入"，然后点击"添加"按钮逐条添加参与测试的华为帐号信息。 * 文件导入：如果测试用户数量较多，可以使用文件导入方式。选择"文件导入"后，可点击"模板下载"，使用文本编辑器编辑下载的"User_Import_Template.csv"文件，根据模板中的样例格式填写测试用的华为帐号信息，保存后点击"导入"将帐号信息文件导入，导入成功后用户列表中将展示所有测试用户信息。 注意 > 导入的帐号信息文件必须为.csv格式，且文件内填写的帐号需满足[帐号格式要求](#ZH-CN_TOPIC_0000001071318960__p1426685825917)。|
   |4|帐号|测试帐号必须是已经注册的华为帐号，且仅支持邮箱格式或手机号码格式。 * 邮箱帐号只能包含字母、数字、下划线、@、. 字符，最多80个字符。 * 手机号码请按"国家码-手机号"格式输入。国家码不能包含国际冠码。例如，中国大陆的国家码请填写"86"，不要填写"0086"，正确示例：86-13612341234。 由于电信运营商可能会拦截邀请短信，会导致您添加的手机号格式的华为帐号用户无法收到邀请短信。建议您优先使用邮箱格式的华为帐号。|

3. 用户添加成功后，点击"确认"。
4. 新建完成后，用户列表中将展示您创建的用户列表。如果您添加的华为帐号不是有效的华为帐号，则创建时会被自动识别为无效用户。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107171426.79342481068629536069444019376026:50001231000000:2800:3B99064A07906AA095AFC91E2A1CBEEB5207792F1DEE986724343F203437FDED.png)

## 编辑用户列表

用户列表创建完成后，支持修改用户列表的名称、添加新的测试用户、删除用户列表中的用户、编辑用户列表中用户帐号名称。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107171426.92934779179940984665955765321816:50001231000000:2800:B6BDFA7CE53848685F4C36CB9243202277200192CB78A47C50E3F177276C051B.png)

## 删除用户列表

如果用户列表没有被引用（用户列表没有在草稿或已上架的开放式测试版本中选中），您可以删除此用户列表，否则将删除失败。
