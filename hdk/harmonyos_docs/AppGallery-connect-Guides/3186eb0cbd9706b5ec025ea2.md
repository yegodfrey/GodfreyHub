# 使用入门

## 创建项目和添加应用

如果您尚未添加项目，请在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)先创建您的AGC项目，在项目下添加应用并设置默认数据处理位置，具体请参见[iOS使用入门](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-started-ios-0000001058442274#section113292017144)。

## 启用服务

首次使用性能管理服务前，需要先启用此服务。如果您已经启用，可跳过本步骤。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择需要开通性能管理服务的应用。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9a/v3/DpE_aHF6TAycaiBfcXB_iQ/zh-cn_image_0000001126741767.png?HW-CC-KV=V1&HW-CC-Date=20261008T161701Z&HW-CC-Expire=31536000000&HW-CC-Sign=E8C45E44BE7C3824FF4731C15341AFB541A0FBBDDDAD51AB46518AA3FA4E44DD)


3. 进入"质量 > 性能管理"，如果APM服务未开通，请点击"立即开通"，开通APM服务。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1e/v3/159TvILySOq4E44YbXKZPw/zh-cn_image_0000001799535602.png?HW-CC-KV=V1&HW-CC-Date=20261008T161701Z&HW-CC-Expire=31536000000&HW-CC-Sign=84E1DF8A525DF4DB0AD95C68C87FD1B1FB66A948A2C28F1A2D527B4EC8F2DED0)

> 说明
>
> 如果您此时未设置数据处理位置，系统会自动弹出提示框提示您进行设置，具体请参考[设置数据处理位置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-data-storage-location-0000001162597847#section154810363471)。目前，性能管理暂不支持访问多数据处理位置，仅能访问默认数据处理位置。设置后会刷新agconnect-services.plist文件里的配置。因此，您需要重新下载agconnect-services.plist文件并集成到您的工程中，具体操作参见[添加配置文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-started-ios-0000001058442274#section127301513192420)。

## 集成APM SDK

> 注意
>
> APM SDK主动依赖了远程配置SDK，用于远程启用/禁用APM SDK的数据采集功能。默认情况下您无需额外集成远程配置SDK，远程配置SDK的详细介绍请参见[SDK隐私安全说明](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-remoteconfig-ios-sdksecurity-0000001055277481)。

1. 集成APM SDK前需集成AGC SDK，详细请参见[集成AGC SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-started-ios-0000001058442274#section1552914317248)。
2. 集成APM SDK。 集成APM SDK后，APM SDK将自动采集应用的[启动性能数据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-ios-viewperformancedata-0000001052692209#section12606630111411)、[屏幕性能数据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-ios-viewperformancedata-0000001052692209#section16614208195112)、[网络性能数据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-ios-viewperformancedata-0000001052692209#section1098412343307)。

   * 如果使用CocoaPods集成，性能管理SDK依赖的pod如下：

     ```screen
     pod 'AGConnectAPM', '~> 1.2.1'
     ```

     版本依赖要求：

     |依赖包名|SDK说明|版本要求|
     |:--------------------|:------|:----------|
     |AGConnectCore|AGC框架包|>=1.1.0.300|
     |AGConnectRemoteConfig|远程配置安装包|>=1.1.0.300|

   * 如果不使用CocoaPods 集成，性能管理服务需下载的SDK包参见[iOS SDK下载](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-started-ios-0000001058442274#section16423124813414)。

     此时需要在项目target > General > Frameworks, Libraries, and Embedded Content添加libresolv.tbd和libresolv.9.tbd。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/27/v3/rIgsH8kiTmim6yJ5uF9CGw/zh-cn_image_0000001079599434.png?HW-CC-KV=V1&HW-CC-Date=20261008T161701Z&HW-CC-Expire=31536000000&HW-CC-Sign=73DDBA781516EE1FA38FB7C0E2509056D53573EE8AAB6C6033606E6B245624AE)

## 部署应用，查看性能监控数据

启用性能管理服务并集成SDK后，APM将自动采集应用的性能数据并上报到数据中心。您可以在AGC中查看性能监控数据是否正常：

1. 安装并运行应用。
2. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
3. 在项目列表中找到您的项目，在项目下的应用列表中选择需要查看性能监控数据的应用。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e9/v3/ifWo2D9_Q36zd7xV5p-0JQ/zh-cn_image_0000001079759700.png?HW-CC-KV=V1&HW-CC-Date=20261008T161701Z&HW-CC-Expire=31536000000&HW-CC-Sign=26C9B754036E6813AC15CC0A35B2A721EC211D1D47BC3E6A479885475C63A08E)


4. 进入"质量 > 性能管理"，确认应用性能数据可以正常显示（通常会在15分钟内显示）。
   * 如果页面展示指标概览数据正常，说明APM性能监控分析功能正常。有关性能监控数据具体的分析方法，请参见[查看应用性能数据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-ios-viewperformancedata-0000001052692209)。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/dc/v3/uBqCFPj8R2-xWoQaENLRdg/zh-cn_image_0000001079598522.png?HW-CC-KV=V1&HW-CC-Date=20261008T161701Z&HW-CC-Expire=31536000000&HW-CC-Sign=66D0406352B64EA5F6C239C7123E5147764B6B2D638C50824896C42ACAD624CD)
   * 如果数据展示异常或者长时间无数据，您可以参考[查看调试日志](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-ios-viewlog-0000001079311550)进行问题定位。
