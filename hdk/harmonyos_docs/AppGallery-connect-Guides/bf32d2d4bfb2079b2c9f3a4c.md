# 文件准备

#### 准备原始包

准备游戏的release正式上架包或debug调试包。  

#### 准备原始so文件

从release包中获取未加壳的release so文件，或从debug包中获取未加壳的debug so文件。若优化后的加壳so文件替换原始包中的so文件，可能在运行阶段会导致游戏闪退问题。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250811104210.70383023831292208116202599673334:50001231000000:2800:C1404C1250E2A8B3F98F213FA171FC09A47B52D5F4B03AE46D13CC96B5105630.png)  
* so文件无需重命名。
* 为了提高优化收益，建议选择游戏引擎对应的so文件，或游戏运行过程中热点占比较大的so文件。  

#### 准备symbol文件

symbol文件是游戏编译原始so文件时生成的符号表文件，文件后缀为\*.sym或\*.sym.so。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250811104211.21597760960611469628041861954140:50001231000000:2800:B446BCD86D66337F8400315D4751FF858A41F87C3548D53C14CAE2089B51A1B2.png)  
symbol文件必须与原始so文件一一对应，例如libil2cpp.so与libil2cpp.sym.so。
