# 开发概览

您可以通过Comments API获取AppGallery Connect中的评论数据，然后利用自己或者第三方（如braze）的评论分析系统作出评论数据的精细化分析。还可以通过Comments API完成评论的回复。  

#### 前提条件

Comments API只支持API客户端方式访问，在访问前需获取服务端授权，包括创建API客户端和获取访问的Access Token，具体参见[使用入门](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section1679462873111)。
