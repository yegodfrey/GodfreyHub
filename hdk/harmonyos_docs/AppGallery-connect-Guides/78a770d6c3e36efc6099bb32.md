# 运行实验

运行实验支持手动运行和指定时间运行两种方式。您可在创建实验时指定实验运行方式。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250102135803.23503805086059515975501751134652:50001231000000:2800:4C659E09786AC49CECDE7DFFB2B98DB69187C592C480B38596E3BE8088B93728.png?needInitFileName=true?needInitFileName=true)  
在应用配置的语言支持的情况下，最多可同时运行6个素材测试实验。  

#### 手动运行实验

只有在实验审核通过后，您才可以手动运行实验。

1. 点击需要运行的实验名称链接，进入实验配置页面。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250102135803.39505924404330023861077819969410:50001231000000:2800:9BD0E58907907D1BCA8CA26C1BBC42FA6BA38E1D6CA6F9A344CA54D498D86E26.png?needInitFileName=true?needInitFileName=true)

   <br />

<!-- -->

2. （可选）在运行实验前，您还可切换实验运行方式：更改"运行实验方式"选项，点击"提交变更"后 ，在提示窗口点击"确认"，修改立即生效，无需再次提交审核，实验仍然处于"审核通过"状态。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250102135803.42910662678354585879271321713876:50001231000000:2800:0486204BAFE452DCC3B1D2667AEF5CF3C634C8754899144D29FFE386013A3F55.png?needInitFileName=true?needInitFileName=true)

3. 点击"运行实验"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250102135804.83538460493005610159075175368756:50001231000000:2800:C70CCAA878AEDBB8D52FD5EA5011EBF10D4BA9E2DA1531AD83EC82EC1C4D6F6B.png?needInitFileName=true?needInitFileName=true)

4. 运行实验后，系统将跳转到实验报告页面，并展示实验的各项统计指标数据，具体请参见[查看和应用实验结果](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-materialtest-view-report-0000001127962841)。  

#### 指定时间运行实验

对于指定时间运行的实验，实验配置页面不展示"运行实验"按钮。到达指定时间后，系统将自动运行实验，多套素材会自动分发给测试用户。
