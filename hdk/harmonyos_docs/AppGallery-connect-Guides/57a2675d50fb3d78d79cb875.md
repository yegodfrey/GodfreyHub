# 集成SDK

可以选择[三方仓下载](#section5504248104619)或者[本地下载](#section1222619592462)的方式来集成Category SDK。

## 三方仓下载

1. 打开您的工程，在命令行窗口执行**cd entry** 命令，切换到工程的"entry"目录。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240521110804.09196168349047018122333231816553:50001231000000:2800:CCFD4C9BF0416A85BE18D686681CF0FF6D5A17840F0D1E304CD90FC1209A2CDE.png?needInitFileName=true?needInitFileName=true)
2. 安装Category SDK到您的项目中。

   ```screen
   ohpm install @hw-agconnect/ui-base
   ohpm install @hw-agconnect/ui-category
   ```

2. 解压得到ui_base.har和ui_category，放在本地工程目录下。
3. 打开DevEco Studio应用级（一般为"entry"目录下）的"oh-package.json5"文件。
4. 在"oh-package.json5"文件的dependencies中添加SDK依赖。

   ```screen
   "dependencies": {
     "@hw-agconnect/ui-base": "file:ui_base.har",
     "@hw-agconnect/ui-category": "file:ui_category.har"
   }
   ```
