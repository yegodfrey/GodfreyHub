# 初始化SDK

调用游戏性能管理SDK的接口前，必须初始化SDK。初始化SDK时需要设置参数AutoCollectScene，该参数值决定是否在[开启数据采集器](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-open-close-collector-0000001767186237#section72707115441)后开始采集、上报游戏的性能数据。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110239.44526712157020679120041427541201:50001231000000:2800:22D25B023D63D4453B26EBC7E90DC19C65BD0192A3C32E741C2EB820880A35B0.png)  
调用初始化接口成功初始化后，后续不需要再次调用，若再次调用，则接口直接返回成功，但不会按照新的参数进行初始化。  

#### 前提条件

* 已[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-integration-0000001719545670)。
* 已[获取游戏信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-get-authentication-infomation-0000001801791669#section20509644364)"Client ID"、"Client Secret"和"APP ID"信息。  

#### 开发步骤

1. 引入GPM命名空间。

   ```
   using GPM;
   ```

2. 创建回调处理对象。

   ```
   private void GPMCallbackHandler callbackHandler = new GPMCallbackHandler();
   ```

3. 新建[GPMInitParams](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpminitparams-apis-0000001754248880)对象并传入初始化参数。

   ```
   GPMInitParams initParams = new GPMInitParams();
   initParams.AppId = appId;                               // 游戏APP ID
   initParams.ClientId = clientId;                         // 客户端Client ID
   initParams.ClientSecret = clientSecret;                 // 客户端密钥Client Secret
   initParams.AccessToken = accessToken;                   // AGC接入凭证（推荐）
   initParams.LogLevel = 3;                                // 日志级别
   initParams.DataPath = Application.persistentDataPath;   // 数据和日志的存储路径
   initParams.UserIdentity = userIdentity;                 // 三方账号OpenID
   initParams.AutoCollectScene = false;                    // 是否在开启数据采集器后开始采集、上报数据
   initParams.CallbackHandler = callbackHandler;           // 初始化回调
   ```

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110239.56735268254263413578113171509176:50001231000000:2800:02DA34B963FF17A889DFFD9EABE1B9209F09F41DDCC1FC0957C4AB3419F28EC7.png)  
   * AutoCollectScene表示在调用[EnableCollector](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpmsdk-apis-0000001720136800#section6902152315716)后是否开始采集、上报数据：
     * true表示调用[EnableCollector](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpmsdk-apis-0000001720136800#section6902152315716)后就采集数据。
     * false表示调用[EnableCollector](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpmsdk-apis-0000001720136800#section6902152315716)后再[设置场景和标签](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-set-scene-tag-0000001767225477)，才开始采集数据，默认为false。
   * ClientSecret和AccessToken二者传其一即可。基于安全考虑，推荐使用AccessToken。若同时传入，将使用传入的AccessToken作为最终AGC接入凭证。AccessToken获取方法请参见[获取Token（项目级）](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-obtain-project-token-0000001801864849)。
4. 在脚本Awake()或Start()中调用[GPMSDK.Init](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpmsdk-apis-0000001720136800#section1155613935519)方法，初始化游戏性能管理SDK。

   ```
   void Start()
   {
     ...
     GPMSDK.Init(initParams);
   }
   ```

5. 初始化时，您可进行相关回调处理。由于游戏性能管理SDK已对回调函数OnInitResult进行了封装，您只需注册[OnInitResultEvent](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpmcallbackhandler-apis-0000002025236161#ZH-CN_TOPIC_0000002025236161__p192125111256)事件监听，并实现[OnInitResultCallback](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpmcallbackhandler-apis-0000002025236161#section151452274152)委托函数即可。

   ```
   callbackHandler.OnInitResultEvent += OnInitResultImpl;
   ...
   public static void OnInitResultImpl(int code, string msg)
   {
       // GPMSDK.Init接口通过子线程回调通知初始化结果。由于大部分API需要在主线程中调用，请在GPMSDK.Init回调中合理处理。
       if(code == GPMError.GPM_SUCCESS) 
       {
          // 初始化成功
       }
   }
   ```
