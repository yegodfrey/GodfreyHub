# 在应用中访问多数据处理位置

通常情况下，为了满足各区域隐私合规或就近选择数据处理位置等要求，您需要使用不同数据处理位置访问不同区域的数据。目前，多个AGC服务都提供了多数据处理位置的支撑，允许您在一个应用中访问多个数据处理位置。

#### 使用默认数据处理位置

在应用接入服务时，如果您不指定数据处理位置，将使用默认数据处理位置。  

#### Android

如果您使用默认数据处理位置访问，调用getInstance方法初始化服务实例不传参即可。  
![](https://media:201775716938644048)  
在项目中如何设置默认数据处理位置，具体请参见[设置默认数据处理位置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-data-storage-location-0000001162597847)。

以认证服务为例：  

```
"Java"
AGConnectAuth auth = AGConnectAuth.getInstance();
```

```
"Kotlin"
val auth = AGConnectAuth.getInstance()
```

#### 修改默认数据处理位置

此处修改的"默认数据处理位置"仅指应用的默认数据处理位置，并非修改AGC网站上的"默认数据处理位置"。  

#### Android

调用[AGConnectOptionsBuilder.setRoutePolicy](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agccore-agconnectoptionsbulider-0000001116227891#section2014116381502)修改默认数据处理位置，并调用[AGConnectInstance.initialize](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agccore-agconnectinstance-0000001116508851#section9988174911378)初始化配置。  
![](https://media:201775716938670049)  
建议此接口在Application的onCreate()中调用，数据处理位置及其对应的枚举值详情请参见[AGCRoutePolicy](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agccore-agcroutepolicy-0000001078446340)。  

```
"Java"
// 创建AGConnectOptionsBuilder对象
AGConnectOptionsBuilder builder = new AGConnectOptionsBuilder(); 
// 设置数据处理位置，比如将默认数据处理位置从CHINA修改为GERMANY 
builder.setRoutePolicy(AGCRoutePolicy.GERMANY); 
// 初始化AGC框架
AGConnectInstance.initialize(context, builder); 
```

```
"Kotlin"
// 创建AGConnectOptionsBuilder对象
val builder = AGConnectOptionsBuilder() 
// 设置数据处理位置，比如将默认数据处理位置从CHINA修改为GERMANY 
builder.setRoutePolicy(AGCRoutePolicy.GERMANY) 
// 初始化AGC框架
AGConnectInstance.initialize(context, builder) 
```

#### 使用指定目标数据处理位置

您还可以通过指定目标数据处理位置，实现不同数据处理位置访问不同区域的数据。  

#### Android

![](https://media:201775716938697050)  
当您访问指定目标数据处理位置的远程配置、App Linking服务时，必须将该指定的目标数据处理位置与默认数据处理位置保持一致，否则会导致功能不完整。因此，当您访问指定目标数据处理位置的服务，且指定目标数据处理位置与默认数据处理位置不一致时，请参考[修改默认数据处理位置](#section1388521162818)进行修改。

1. 构造[AGConnectOptions](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agccore-agconnectoptions-0000001116446037)对象，指定目标数据处理位置。

   <br />

   ```
   ""Java""
    AGConnectOptions optionsRussia = new AGConnectOptionsBuilder() 
        .setRoutePolicy(AGCRoutePolicy.RUSSIA) 
        .build(context); 
   ```

   ```
   ""Kotlin""
    val optionsRussia = AGConnectOptionsBuilder()        
           .setRoutePolicy(AGCRoutePolicy.RUSSIA)         
           .build(context) 
   ```

2. 初始化AGConnectInstance，在buildInstance方法中传入指定的AGConnectOptions对象。

   ```
   AGConnectInstance instanceRussia = AGConnectInstance.buildInstance(optionsRussia);
   ```

3. 传入对应的AGConnectInstance实例，创建目标数据处理位置的AGC服务的实例。 以认证服务为例：

   ```
   "Java"
   AGConnectAuth authRussia = AGConnectAuth.getInstance(instanceRussia);
   ```

   ```
   "Kotlin"
   val authRussia = AGConnectAuth.getInstance(instanceRussia)
   ```

4. 如果您需要指定访问更多的数据处理位置，请重复以上步骤，指定不同的目标数据处理位置即可。
