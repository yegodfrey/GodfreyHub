# 技术支持

当您集成AGC相关服务遇到问题时，可以按照以下顺序寻求帮助。

1. 请先仔细阅读文档，部分功能对设备和系统有限制，请参见[使用限制](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-restrict-0000001053254031)。
2. 查看[FAQ](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-faq-0000001053333997)、[问题处理案例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-case-0000001118208296)，错误码请参见[Android](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauthexception-0000001054083804#section1449134615189)、[iOS](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcautherrorcode-ios-0000001054662396)、[Web](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauthexception-web-0000001054503256)、[REST API](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/client-rest-auth-errorcode-0000001353626777)、[Server-Java](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/auth-serversdk-autherrorcode-0000001055283310)、[Server-Node.js](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/nodejs-errorcode-0000001732781488)、[Server-REST API](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/server-rest-errorcode-0000001142701050)。
3. 通过[智能客服](https://developer.huawei.com/consumer/cn/customerService/#/bot-dev-top/faq-top/faq-talk-top)查找问题解决方案。
4. 登录[Stack Overflow社区](https://stackoverflow.com/questions/tagged/appgallery-connect)和[华为开发者社区](https://developer.huawei.com/consumer/cn/forum/block/serverless)参与问题讨论。
5. 如果以上方法仍未解决您的问题，可以通过[在线工单系统](https://developer.huawei.com/consumer/cn/support/feedback/#/add/89?level2=9016)与我们进行联系。提交工单后，可登录[华为开发者联盟官网](https://developer.huawei.com/consumer/cn/)，鼠标置于右上角头像处，在下拉框内点击"我的工单"查看工单处理进展。
