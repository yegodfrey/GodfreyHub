# 通过控制台测试

> 说明
>
> 下文以函数latest版本为例介绍测试方法。若您需要测试函数的已发布版本，可在已发布版本详情页面选择"函数代码"页签，参考方式二进行测试。

函数创建后您可以在AGC控制台测试函数的代码运行是否正常。进入测试界面有两种方式：

* 方式一：函数列表中点击函数名称右侧"操作"列的"测试"，在右侧弹出的"测试函数"界面进行测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c4/v3/ig7i1zLLSwmfecxb6muCFg/zh-cn_image_0000001978548797.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=A7623E81D15D6F18C0D25775EB83D6C378BF3C3896F0E34E782DC8B7D89AF469)

* 方式二：
  1. 在函数列表中点击已创建的函数名称，进入函数详情页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e8/v3/KkmB3PU1QqiXU_I0bNhIdQ/zh-cn_image_0000001948908550.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=F6A548BCB54D600CB850E1405B26FDC2B0B643DBA329965218BF53736D535DE2)

  2. 选择"函数代码"页签，点击"测试函数"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/30/v3/Hy6ZsEAKQjK5PO7oVtXoqA/zh-cn_image_0000001800662133.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=8DDE995A8B1E11C14A78721F8731CFC40E711CCC32CC1776E76A74872F3C3FDF)

  3. 在右侧弹出的"测试函数"界面，使用默认测试事件、创建新测试事件或者使用已保存测试事件进行测试。
     * 使用默认测试事件 直接点击"测试"对函数进行测试。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/56/v3/Mp4dKtDQTm2ufc71bDJedA/zh-cn_image_0000001722152221.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=B2FF247CE826D9E3C5CCE4BAE19F4BD56B793565E3F87C60EEFD7EA95F98DD7F)
     * 创建新测试事件 如果需要设置调用函数的请求消息体，可按照如下步骤配置测试参数，并可保存为测试事件方便后续继续使用。

       1. 在"事件"文本框中输入JSON格式的事件参数，点击"保存"。然后在"提示"弹出框中输入事件名称，配置完成后点击弹出框右下角的"确认"。 说明
          >
          > "事件"文本框内输入的JSON对象，对应的是触发器的event事件格式，会透传给函数。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/29/v3/NsJNo61dQ5SMwQUVOIrvbQ/zh-cn_image_0000001756189981.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=CB6E408B8E6E69670EBF36E592A6DE2708C988A78C5324128BAB772742481C5B)
       2. 点击"测试"，函数处理事件并返回测试结果。
     * 使用已保存测试事件
       1. 在"测试函数"界面，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6d/v3/qMzDYzMOQgm0BuTZI9r7Jg/zh-cn_image_0000001722236597.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=9965B4ECF9A8B07B81FE47FD4BA9D2CE569E668F16A29AEDA341863A3AD3F4CC)展开已保存的测试事件列表，选择已配置的事件名称右侧的"加载"，然后点击"测试"，函数处理事件并返回测试结果。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5c/v3/E30lvjiqQmSR1rlEeSNy9A/zh-cn_image_0000001722453985.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=4C2993878D53B2C965AB5186B220EF63CE34D1CD6025780DAF1B6BE27CFDDCB3)
       2. （可选）若您需要删除已添加的测试事件，可在测试事件列表中点击事件名称右侧的"删除"即可删除测试事件。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c4/v3/58-qUC-CQAu1MyTz-FI51g/zh-cn_image_0000001722158501.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=3053A0B4E1232BE200A2734BB9EFB6FC90A36F3677DDE668969B8EA47E44AD8B)

  4. 查看测试结果。
     * 执行结果：展示测试后获得的响应结果。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a4/v3/ngmzTqIJT2OHNTBTMaRqyw/zh-cn_image_0000001674184734.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=BB1B5E927504050DB68B30C0056BD2879878F69B0A8BFC2436362DE670DDBBF8)

     * 运行日志：展示函数运行过程中，通过logger API打印的日志，支持输出debug级别及以上日志（以下仅为日志输出示例）。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/80/v3/kkpDgy4XTTe86Pq6JxlB1Q/zh-cn_image_0000001674190046.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=88644A8351A8CD7E10F64E27FE9559429E443EB5256E3870B90632C66CF7A2E1)

     * 执行摘要：展示该次测试请求相关信息。
       * 请求ID：该条测试请求的RequestID，在后台日志中体现为X-Trace-ID。
       * 持续时间：函数执行的端到端时间。
       * 执行版本：该次调用测试的具体函数版本。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/57/v3/KhwZZal5T2aQQKTAMOs6Zg/zh-cn_image_0000001674344770.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=D3672E8B2AC6E3E78A6476DBD18E14AF90A2A5646815878557FE0903431098B5)
  5. "代码输入类型"为"在线编辑"的函数，测试过程中，若您需要修改函数入口文件代码，可直接在"函数代码"页签的代码编辑器中修改，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bb/v3/Qj7cXV6JShW2aK3LOhYbrA/zh-cn_image_0000001753703418.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=2D03570A4FDA05464A9F6D01643E5D72FBA2D42DFE003238990B8D4B962AF649)

     "代码输入类型"为".zip文件"的函数，测试过程中，若您需要修改函数代码文件，可在本地修改且打包完成后，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/52/v3/bshscxE7RKuDxziZc-ABhQ/zh-cn_image_0000001717161230.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=E1573C0DD870CA2944566BDAEF4053D7D7EA3CD23D75FF85FAE497EAC126E5D9)重新上传函数部署包，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。
     > 说明
     >
     > 若代码更新量比较大，需要调整函数内存配置，可点击"内存配置"下拉框进行调整，然后再上传函数部署包。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b/v3/XaDn0lmVQZa365nMZQzn8g/zh-cn_image_0000002433940774.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=01BF3806F1C957D38E9D29A9F11E003AC0C413656F0387F733CFE9A3A957BE6A)
  6. 函数测试无误后，您可在"函数代码"页签点击"导出函数"导出函数部署包。导出包以"函数名称+函数版本.zip"格式命名，可查看函数结构和文件内容。
