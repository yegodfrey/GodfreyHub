# 加入房间

当不同的玩家加入同一语音房间内，即可互相发送/接收实时音频数据。目前，游戏多媒体服务支持加入[小队语音房间](#section644913141332)、[国战语音房间](#section429414312194)和[范围语音房间](#section4450837143111)。
> 说明
>
> 第一个加入小队语音或国战语音房间的玩家，默认成为该房间的房主。

## 前提条件

* 您已[集成游戏多媒体语音基础SDK和实时语音模块](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-integratingsdk-android-0000001250838246)。
* 您已[创建游戏多媒体实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-engine-android-0000001193958984#section1093713161034)。
* 您已规划语音房间ID。

## 加入小队语音房间

1. 调用[GameMediaEngine.joinTeamRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section9374142516116)方法，使用相同的房间ID即可进入同一小队语音房间。

   ```screen
   mHwRtcEngine.joinTeamRoom(roomId); // roomId：自定义的房间ID
   ```

2. 当玩家加入小队语音房间后，可在IGameMMEEventHandler接口的[onJoinTeamRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section8110123119336)方法中实现相关回调处理。

   ```screen
   @Override
   public void onJoinTeamRoom(String roomId, int code, String msg) {
       StringBuilder sb = new StringBuilder("onJoinTeamRoom : ").append("roomId=")
           .append(roomId)
           .append(", code=")
           .append(code)
           .append(", msg=")
           .append(msg);
       LogUtil.d(TAG, sb.toString());
       // 加入小队房间成功或失败数据处理
   }
   ```

   当玩家成功加入小队语音房间时，房间内其他玩家可在IGameMMEEventHandler接口的[onPlayerOnline](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section54921732104312)方法中收到该事件的回调通知，并可根据需求对数据进行处理。

   ```screen
   @Override
   public void onPlayerOnline(String roomId, String openId) {
      StringBuilder sb = new StringBuilder("onPlayerOnline : ")    
          .append("roomId=")    
          .append(roomId)    
          .append(", openId=")    
          .append(openId);
      LogUtil.d(TAG, sb.toString());
      // 可根据需求将数据进行处理
   }
   ```

## 加入国战语音房间

在国战房间中，玩家分为指挥官和群众两种角色。加入房间时，玩家可根据roleType选择自身角色。
> 说明
>
> * 在一个国战房间中，指挥官角色最多支持15人，群众角色最多支持10000人。
> * 当玩家为指挥官角色时，则具备发送和接收语音的权限。当玩家为群众角色时，则仅具备接收语音的权限。

1. 调用[GameMediaEngine.joinNationalRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section72949581337)方法，使用相同的房间ID即可进入同一国战语音房间。

   ```screen
   mHwRtcEngine.joinNationalRoom(roomId, roleType); // roomId:自定义的房间ID; roleType:玩家角色，1表示指挥官，2表示群众
   ```

2. 当玩家加入国战语音房间时，可在IGameMMEEventHandler接口的[onJoinNationalRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section16120259193419)方法中实现相关回调处理。

   ```screen
   @Override
   public void onJoinNationalRoom(String roomId, int code, String msg) {
       StringBuilder sb = new StringBuilder("onJoinNationalRoom : ").append("roomId=")
           .append(roomId)
           .append(", code=")
           .append(code)
           .append(", msg=")
           .append(msg);
       LogUtil.d(TAG, sb.toString());
       // 加入国战房间成功或失败数据处理
   }
   ```

   当玩家成功加入国战房间时，房间内其他玩家可在IGameMMEEventHandler接口的[onPlayerOnline](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section54921732104312)方法中收到该事件的回调通知，并可根据需求对数据进行处理。

   ```screen
   @Override
   public void onPlayerOnline(String roomId, String openId) {
      StringBuilder sb = new StringBuilder("onPlayerOnline : ")    
          .append("roomId=")    
          .append(roomId)    
          .append(", openId=")    
          .append(openId);
      LogUtil.d(TAG, sb.toString());
      // 可根据需求将数据进行处理
   }
   ```

## 加入范围语音房间

> 说明
>
> 加入范围语音房间，您还需要设置语音接收范围，并更新上报自身和其他玩家的位置信息，具体请参见[范围语音](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-rangeroom-android-0000001645298382)。

1. 调用[GameMediaEngine.joinRangeRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section55155121859)方法，使用相同的房间ID即可进入同一范围语音房间。

   ```screen
   mHwRtcEngine.joinRangeRoom(roomId); // roomId:自定义的房间ID;
   ```

2. 当玩家加入范围语音房间时，可在IGameMMEEventHandler接口的[onJoinRangeRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section13637181914113)方法中实现相关回调处理。

   ```screen
   @Override
   public void onJoinRangeRoom(String roomId, int code, String msg) {
       StringBuilder sb = new StringBuilder("onJoinRangeRoom: ").append("roomId=")
           .append(roomId)
           .append(", code=")
           .append(code)
           .append(", msg=")
           .append(msg);
       LogUtil.d(TAG, sb.toString());
       // 加入范围房间成功或失败数据处理
   }
   ```
