# 使用限制

使用应用签名服务后，您在后续的操作中有一些需要特别注意的事项。

|限制项|限制说明|
|:----|:---------------------------------------------------------------------------------------------------------------------------------|
|签名密钥|当开发选择上传自己的签名密钥时，AGC当前支持的加密算法类型和密钥长度分别如下： * RSA：1024、2048、4096 * EC：NIST P-256|
|第三方对接|如果您在新应用上架时选择由AGC创建并管理您的签名密钥，AGC会为您创建一个新的签名密钥，如果您在开发应用时与第三方对接使用了原有的应用签名，将导致应用上架后与第三方交互失败。|
|修改密钥|为保证安全性，AGC上管理的签名密钥和上传密钥一旦上传就不再支持修改。|
|删除密钥|* 如果您删除了某个应用，该应用的上传密钥的密钥证书和托管的签名密钥、以及由AGC创建并管理的签名密钥都会被删除，且不可找回。 * 如果您注销了AGC开发者账号，您提交的所有上传密钥和托管的签名密钥、以及由AGC创建并管理的签名密钥都会被立即删除，且不可找回。|
