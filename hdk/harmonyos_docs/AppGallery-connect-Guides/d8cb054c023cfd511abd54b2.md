# 创建引用

文件存储在云端的存储实例中，存储方式与本地硬盘中的文件系统类似。您可以通过文件的引用进行上传文件、下载文件、删除文件、更新文件元数据等操作，也可以通过创建目录的引用来获取该目录下的文件列表。  

#### 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[初始化存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-initialize-bucket-android-0000001276178118)。  

#### 操作步骤

* 如果您需要创建根目录的引用，可以调用[AGCStorageManagement.getStorageReference](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragemanagement-0000001054967269#section939311202814)方法。  

  ```
  "Java"
  //storageManagement为已经初始化的AGCStorageManagement实例
  StorageReference reference = storageManagement.getStorageReference();
  ```

  ```
  "Kotlin"
  //storageManagement为已经初始化的AGCStorageManagement实例
  val reference = storageManagement!!.getStorageReference()
  ```

<!-- -->

* 如果您需要创建云端指定文件或目录的引用，可以调用[AGCStorageManagement.getStorageReference](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragemanagement-0000001054967269#section9635163510919)(String objectPath)方法。  

  ```
  "Java"
  //storageManagement为已经初始化的AGCStorageManagement实例
  StorageReference reference = storageManagement.getStorageReference("images/demo.jpg");
  ```

  ```
  "Kotlin"
  //storageManagement为已经初始化的AGCStorageManagement实例
  val reference = storageManagement!!.getStorageReference("images/demo.jpg")
  ```

<!-- -->

* 如果您需要指定文件上传或下载的区域，可以调用[getReferenceFromUrl](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragemanagement-0000001054967269#section37489523561)(AGConnectInstance instance, String fullUrl)方法。  

  ```
  "Java"
  //storageManagement为已经初始化的AGCStorageManagement实例
  StorageReference storageReference = storageManagement.getReferenceFromUrl(AGConnectInstance.getInstance(), "https://xxxxxx");
  ```

  ```
  "Kotlin"
  //storageManagement为已经初始化的AGCStorageManagement实例
  val storageReference = storageManagement.getReferenceFromUrl(AGConnectInstance.getInstance(), "https://xxxxxx")
  ```

#### 更多信息

创建引用后，您可以调用[StorageReference](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagereference-0000001054767243)实例的相关方法对引用进行相关操作：

* 在当前文件层次结构中向上向下导航，例如调用[child](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagereference-0000001054767243#section1738752918192)获取子目录引用，调用[getParent](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagereference-0000001054767243#section189593402216)获取父目录引用，调用[getRoot](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagereference-0000001054767243#section17763712237)获取根目录引用。
* 获取当前引用的相关信息，例如调用[getBucket](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagereference-0000001054767243#section1954414306239)获取文件所在存储实例名称，调用[getName](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagereference-0000001054767243#section865743122513)获取当前引用的文件或目录名称，调用[getPath](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagereference-0000001054767243#section2451105482519)获取文件在云端的存储路径。
* 对文件进行[上传](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-upload-android-0000001055326211)、[下载](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-download-android-0000001054766193)、[删除](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-delete-android-0000001055726156)和[元数据管理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-metadata-android-0000001055566158)等操作，我们将在下面的章节中具体介绍。
