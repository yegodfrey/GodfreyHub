# 测试崩溃实现

通常应用程序出现崩溃的概率较小，您没必要等待崩溃出现来确定崩溃服务是否正常工作。您可以在测试应用时调用崩溃服务SDK的API手动制造一个崩溃，然后在AGC上查看崩溃上报情况，以测试崩溃服务是否正常运行。

## 前提条件

1. 您需要在AGC控制台[开通崩溃服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-enableservice-0000001326330021)。
2. 您需要先在您的应用中[集成崩溃服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-integratesdk-ios-0000001326720177)。

## 测试崩溃

1. 在应用的AppDelegate中初始化AGConnectCore SDK和Analytics SDK。

   ```screen
   "Objective-C"
   #import "AppDelegate.h"
   #import <AGConnectCore/AGConnectCore.h>

   @implementation AppDelegate
   - (BOOL)Application:(UIApplication *)Application didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {
       [AGCInstance startup];//初始化
       return YES;
   }
   ...
   @end
   ```

   ```screen
   "Swift"
   import AGConnectCore 

   @UIApplicationMain
   class AppDelegate: UIResponder, UIApplicationDelegate {
       func application(_ application: UIApplication, didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?) -> Bool {
           AGCInstance.startUp()
           return true
       }
       ...
   }
   ```

2. 在应用的ViewController中创建一个测试按钮，调用[testIt()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccrash-ios-0000001055101856#section548611587587)方法触发一个崩溃事件。 注意
   >
   > 在测试完成后应用上架前，请注意将测试崩溃的测试代码删除。

   ```screen
   "Objective-C"
   #import "ViewController.h"
   #import <AGConnectCrash/AGConnectCrash.h>

   @implementation ViewController
   - (void)viewDidLoad {
       [super viewDidLoad];
       UIButton * button = [UIButton buttonWithType:UIButtonTypeCustom];     
       button.frame = CGRectMake(50, 100, 100, 40);     
       [button setTitle:@"Crash Test" forState:UIControlStateNormal];     
       [button addTarget:self action:@selector(crashTest) forControlEvents:UIControlEventTouchUpInside];     
       [self.view addSubview:button];
   }
   - (void)crashTest {
       [[AGCCrash sharedInstance] testIt];
   }
   ...
   @end
   ```

   ```screen
   "Swift"
   import AGConnectCrash

   class ViewController: UIViewController {
       override func viewDidLoad() {
           super.viewDidLoad()
           let button = UIButton.init(frame: CGRect.init(x: 50, y: 100, width: 100, height: 40))
           button.setTitle("Crash Test", for: .normal)
           button.setTitleColor(UIColor.blue, for: .normal)
           button.addTarget(self, action: #selector(testIt), for: .touchUpInside)
           self.view.addSubview(button)
       }
       
       @objc func testIt() {
           AGCCrash.sharedInstance().testIt()
       }
       ...
   }
   ```

   > 说明
   >
   > 崩溃收集功能在Xcode调试状态下不会开启，因此您在测试应用程序的崩溃收集功能时需要先停止Xcode调试再打开应用程序，保证应用程序运行在非调试模式下。
3. 在发生崩溃后，确保网络连接正常，重新打开应用，在AGC中查看对应的崩溃信息，具体方法参见[分析崩溃问题](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-locate-ios-0000001055260540)。 说明
   >
   > 崩溃服务开关默认为打开，在崩溃发生后会自动上报崩溃数据。如果您不想收集和上报崩溃数据，可以调用代码 [[AGCCrash sharedInstance] enableCrashCollection:NO] 将崩溃服务关闭。
