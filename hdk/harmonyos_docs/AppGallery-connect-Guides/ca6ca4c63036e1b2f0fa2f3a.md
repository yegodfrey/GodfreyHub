# 设置游戏配置信息（可选）

游戏在不同设置（帧率、是否开启抗锯齿等）下，性能表现不尽相同，您可以在游戏启动及玩家设置变更时调用接口传入游戏设置组合信息。  

#### 前提条件

* 已[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-integration-0000001719545670)。
* 已[初始化SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-initialization-0000001719386234)。
* 已[开启数据采集器](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-open-close-collector-0000001767186237#section72707115441)。  

#### 开发步骤

1. 引入GPM命名空间。

   ```
   using GPM;
   ```

2. 调用[GPMSDK.SetGameConfigurations](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpmsdk-apis-0000001720136800#section636113398576)方法，设置游戏配置信息，设置后SDK会在采集的性能数据中携带您传入的游戏配置信息。

   ```
   GPMSDK.SetGameConfigurations("3;3;50;1280*720;true;true;true;true;true");
   ```

3. 设置游戏配置信息时，您可进行相关回调处理。由于游戏性能管理SDK已对回调函数OnSetGameConfigurations进行了封装，您只需注册[OnSetGameConfigurationsEvent](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpmcallbackhandler-apis-0000002025236161#ZH-CN_TOPIC_0000002025236161__p1665094382617)事件监听，并实现[OnSetGameConfigurationsCallback](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpmcallbackhandler-apis-0000002025236161#section177108362274)委托函数即可。

   ```
   callbackHandler.OnSetGameConfigurationsEvent += OnSetGameConfigurationsImpl;
   ...
   public static void OnSetGameConfigurationsImpl(int code, string msg)
   {
       // GPMSDK.SetGameConfigurations接口通过子线程回调通知初始化结果。由于大部分API需要在主线程中调用，请在GPMSDK.SetGameConfigurations回调中合理处理。
       if(code == GPMError.GPM_SUCCESS) 
       {
          // 设置游戏配置信息成功
       }
   }
   ```
