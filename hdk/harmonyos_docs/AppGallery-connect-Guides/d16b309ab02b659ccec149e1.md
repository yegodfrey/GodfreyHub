# 获取云端配置项

#### 前提条件

* 您已在AGC控制台[设置云端配置项](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-remoteconfig-ios-cloudconfig-0000001242850821)。
* 您需要在您的应用中[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-remoteconfig-ios-integration-sdk-0000001055157432)。  

#### 获取和更新云端配置数据到本地

1. （可选）您可以通过[AGConnectConfig.setCustomAttributes](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/ios-remoteconfig-agcremoteconfig-0000001056526293#section9209134884217)接口设置自定义参数，[fetch](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/ios-remoteconfig-agcremoteconfig-0000001056526293#section93401104342)接口中会自动带入自定义参数。您也可以通过[AGConnectConfig.getCustomAttributes](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/ios-remoteconfig-agcremoteconfig-0000001056526293#section14978182820461)获取自定义的参数。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221028100050.32163347495979691141954370277665:50001231000000:2800:53541F51C123A924D329E1F6248D6A47B35FF13C410B6E0B0962587A516D8EB5.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
   设置自定义参数要在使用fetch接口之前调用。  

   ```
   "Objective-C"
   NSDictionary *dict = @{ @"attkey" : @"abc123ABC"};
   [[AGCRemoteConfig sharedInstance] setCustomAttributes:dict];

   获取设置的自定义参数
   NSDictionary *dict = [[AGCRemoteConfig sharedInstance] getCustomAttributes];
   ```

   ```
   "Swift"
   let dict : [String : Any] = ["attkey":"abc123ABC"]
   let config = AGCRemoteConfig.sharedInstance()
   config.setCustomAttributes(dict)

   获取设置的自定义参数
   let dict : [String : Any] =config.getCustomAttributes;
   ```

2. 从远程配置服务获取参数值使用[\[AGCRemoteConfig fetch\]](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/ios-remoteconfig-agcremoteconfig-0000001056526293#section93401104342)接口，返回异步Task任务。获取成功后会返回从云端同步的[AGCConfigValues](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/ios-remoteconfig-agcconfigvalues-0000001056246303)数据（可通过此类只获取云端数据），再通过调用[\[AGCRemoteConfig apply:\]](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/ios-remoteconfig-agcremoteconfig-0000001056526293#section1837286142618)接口传入云端同步获取的值使其生效。  

   ```
   "Objective-C"
   [[[config fetch] addOnSuccessCallback:^(AGCConfigValues * result) {
       // on success
       [config apply:result];
   }] addOnFailureCallback:^(NSError *error) {
       // on failure
   }];
   ```

   ```
   "Swift"
   config.fetch().onSuccess { (configValue) in
       config.apply(configValue!)
       // on success
   } .onFailure { (error) in
       // on failure
   }
   ```

3. fetch接口可能会有网络延迟，导致apply接口未能将云端最新的数值传入，为了避免此情况，您可以先调用fetch接口，然后在需要传入云端数据的地方调用apply接口。如下示例代码中的config.loadLastFetched()即为之前通过fetch接口已经获取的信息。  

   ```
   "Objective-C"
   AGCConfigValues *last = [config loadLastFetched];
   [config apply:last];
   ```

   ```
   "Swift"
   config.apply(config.loadLastFetched())
   ```

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221028100050.42229470387707442241064821995304:50001231000000:2800:DA5896B06193223CD7009A18F4DD5C514585CFEB1AD8D2CE0372923573EB72F7.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
   [\[AGCRemoteConfig fetch\]](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/ios-remoteconfig-agcremoteconfig-0000001056526293#section93401104342)接口默认更新周期为 12 小时，[\[AGCRemoteConfig fetch:\]](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/ios-remoteconfig-agcremoteconfig-0000001056526293#section14556153117216)接口则可以自行设置更新周期，在更新周期内再次调用fetch接口不会去云侧同步数据，而是使用本地缓存数据直接返回。

[\[AGCRemoteConfig fetch:\]](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/ios-remoteconfig-agcremoteconfig-0000001056526293#section14556153117216)间隔时间单位为秒，在调测阶段可以设置为0，方便调测，在实际生产阶段建议设置较大值，防止受到流控限制。  

#### 获取参数值

在设置默认值和更新云端参数值后，您可以调用接口通过键值来获取参数进行使用。云端键值（key）、参数（value）与AGC界面配置的对应关系：

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221028100050.76519506378806360225470063763801:50001231000000:2800:1942685C109C7A5C5229968B43035313E83260F017745B276B149B7D962A81B6.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

远程配置SDK 提供了4种数据类型的接口，您可根据需求进行使用。

* [valueAsBool](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/ios-remoteconfig-agcremoteconfig-0000001056526293#section174180551338)：获取BOOL类型参数值。  
  ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221028100050.75352239055554453756634942002980:50001231000000:2800:337B33ED0895C5602788982177BBE9709F5C5FBB4C1882E7658822D6D6271E68.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
  BOOL类型true 支持的字符串有"1"、"true"、"t"、"yes"、"y"、"on"。 boolean 类型 false 支持的字符串有"0"、"false"、"f"、"no"、"n"、"off"，不区分大小写。  

  ```
  "Objective-C"
  BOOL value1 = [config valueAsBool:@"key"];
  ```

  ```
  "Swift"
  let value = config.valueAsBool(key: "key")
  ```

* [valueAsNumber](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/ios-remoteconfig-agcremoteconfig-0000001056526293#section2693024527)：获取NSNumber类型参数值。  

  ```
  "Objective-C"
  NSNumber * value2 = [config valueAsNumber:@"key"];
  ```

  ```
  "Swift"
  let value3 = config.valueAsNumber(key: "key")
  ```

* [valueAsString](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/ios-remoteconfig-agcremoteconfig-0000001056526293#section1654034017548)：获取NSString类型参数值。  

  ```
  "Objective-C"
  NSString * value3 = [config valueAsString:@"key"];
  ```

  ```
  "Swift"
  let value3 = config.valueAsString(key: "key")
  ```

* [valueAsData](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/ios-remoteconfig-agcremoteconfig-0000001056526293#section178097410712)：获取的Data类型参数值。  

  ```
  "Objective-C"
  Data * value4 = [config valueAsData:@"key"];
  ```

  ```
  "Swift"
  let value4 = config.valueAsData(key: "key")
  ```

云端设置的参数值实际存储时都是字符串类型，在获取具体类型时进行转换，如果转换失败则返回类型默认值。

* BOOL类型默认值为：NO
* NSNumber类型默认值为：@(0)
* NSString类型默认值为：@""
* Data类型默认值为：nil  

#### 获取参数值的来源

您可以通过调用[\[AGCRemoteConfig getSource:\]](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/ios-remoteconfig-agcremoteconfig-0000001056526293#section201373241789)来获取参数值的来源。数据可能有如下三种来源

* AGCRemoteConfigSourceInitial：类型默认值
* AGCRemoteConfigSourceLocal：本地默认值
* AGCRemoteConfigSourceRemote：从云端获取的值

```
"Objective-C"
AGCRemoteConfigSource source = [config getSource:"key"];
```

```
"Swift"
let source = config.getSource("key")
```

AppGallery Connect页面设置参数时若设置为SDK默认值，满足使用SDK默认值的条件时服务器就不会下发这个参数，取值使用本地默认值。  

#### 获取全部参数值

您可以调用[\[AGCRemoteConfig getMergedAll\]](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/ios-remoteconfig-agcremoteconfig-0000001056526293#section1172112231897)一次性获取全部本地默认值和云端参数值，而不是通过键值来读取，相同键值的参数会使用云端数据。  

```
"Objective-C"
NSDictionary *dict = [config getMergedAll];
```

```
"Swift"
let all = config.getMergedAll()
```

#### 重置参数值

您可以调用[\[AGCRemoteConfig clearAll\]](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/ios-remoteconfig-agcremoteconfig-0000001056526293#section128307131106)清空之前所有的参数值，将设置的默认值、云端参数值全部都清除。  

```
"Objective-C"
 [config clearAll];
```

```
"Swift"
config.clearAll()
```
