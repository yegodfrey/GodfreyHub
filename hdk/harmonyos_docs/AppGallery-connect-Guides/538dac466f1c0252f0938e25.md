# 初始化远程配置

您可以在应用打开时初始化远程配置，初始化过程将加载最近一次成功获取云端配置信息时间、上一次获取云端配置信息是否成功以及您设置的默认配置信息，同时，使上次关闭应用前最后一次生效的云端配置和默认配置重新生效。

如果您在上次使用应用时设置了数据存储加解密对象，初始化远程配置前请设置与上次相同的加解密对象，否则数据无法被正常加载。

```
agconnect.remoteConfig().setCryptImp(cryptImpl); // 设置加解密对象
await agconnect.remoteConfig().initialized(); // 初始化远程配置
```
