# 成功案例

#### 客户需求

<br />

华为《DIGIX TALK》是一个拥抱新知和多元观点的分享平台。华为终端云服务邀请各领域领袖、专家、达人，及社会各界对美好生活有见解，有主张和实践探索的嘉宾进行时长约21分钟的演讲，分享他们在生活及从业中的深刻体悟，为观众打开一扇品味生活百态、了解更多新知的窗口。

为确保业务可靠，在异常情况下可以通过远程配置下发备用域名，《DIGIX TALK》接入了远程配置服务。
