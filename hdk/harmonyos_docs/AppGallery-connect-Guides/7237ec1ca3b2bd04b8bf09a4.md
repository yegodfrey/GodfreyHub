# 一键发布

游戏内嵌社区SDK支持玩家一键将动态内容分享至华为游戏中心论坛。

## 前提条件

* 内嵌社区已完成[初始化](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/pgsmoment-init-0000001244091880)。
* 您的游戏已提前获取本地存储权限。

## 开发步骤

调用[PgsMoment.publish](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/gdpsdk-api-pgsmoment-0000001403658572#section1959165419333)实现一键发布至华为游戏论坛的功能。

```screen
// 一键发布动态内容说明：
// 动态文本：仅支持纯文本字串，不支持表情符号；最大长度1000字节，超出长度的部分会被自动截断;
// 配图数量：单次发布动态最多支持9张图片；
// 配图格式：仅支持"jpeg"、"jpg"、"png"、"webp"、"gif"、"bmp"；
// 配图大小：最大支持10MB的文件；
String[] paths = new String[]{"path1","path2"};
String content = "moment content";
InstantPublishBean bean = new InstantPublishBean(paths, content);
PgsMoment.publish(bean, new InstantPublishCallback() {
    @Override
    public void onSuccess(Response response) {
        // 发布成功
    }

    @Override
    public void onFailure(Response response) {
        // 发布失败
        Log.e(TAG, "RtnCode: " + response.getRtnCode() + "; Msg: " + response.getMsg());
    }
});
```

> 说明
>
> 若PgsMoment.publish的第一个入参**InstantPublishBean** 对象传入为空路径，调用publish接口时将打开[发表动态](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/pgsmoment-introduction-0000001244369204#ZH-CN_TOPIC_0000001244369204__p10805258141218)界面，玩家可以自主添加相册图片，您无需设计读取相册图片路径等代码。
