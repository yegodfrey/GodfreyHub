# 业务概述

|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-|
|对于高帧率游戏（如3D游戏）而言，长时间高功耗运行，会导致手机设备温度逐渐升高，通常系统会自动采取降帧策略，这大大影响了玩家的游戏体验。为了解决这一问题，华为游戏中心推出了**插帧服务** ，允许游戏通过智能插帧方式低功耗、高帧率稳定运行，满足高帧率游戏的画面需求，提升游戏流畅性，降低手机设备的功耗和壳温，提升续航能力，同时还支持为低帧率游戏提升帧率，帮助您打造极致畅爽的操控体验。| |

## 主要功能

|主要功能|功能描述|
|:---|:-----------------------------------------------------------------------------------------------------------------------------------|
|插帧|利用渲染管线中的时域和空域冗余信息，使用运动估计和运动补偿两种关键技术，平衡CPU/GPU计算量，加速渲染过程，无需对游戏的逻辑、渲染循环等进行大量计算，即可构建预测帧图像。提供了"内插"和"外插"两种插帧方案，用于满足不同类型的游戏对于图像质量和输入延迟的需求。|
