# Google

您可以在应用中集成Google认证方式，让您的用户可以使用自己的Google账号进行AppGallery Connect身份验证。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143819.75711821330818239590236352682536:50001231000000:2800:587FF31232C7DDE278A970AA558280D8D12219969D78F010223538114657DC42.png)  
* Google三方认证方式仅在海外站点支持，当您选择数据处理位置为德国、新加坡或俄罗斯时可以使用此认证方式。
* 集成Google三方认证方式时，您的用户设备需要支持GMS（Google Mobile Services）。  

#### 前提条件

* 您需要在AGC控制台[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-integration-sdk-0000001325876845)。  

#### 开发步骤

认证服务提供了两种开发方式接入Google账号：

* 推荐您使用新的统一登录接入方式，请参见[统一登录接入方式](#section176597419548)。
* 同时为了兼容性保留了老的传统接入方式，请参见[传统接入方式](#section16952720551)。  

#### 统一登录接入方式

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143819.44894377439269765588426112251875:50001231000000:2800:C4C4D26755BF975724637C9E4E57EB673370C701970FDABDE880D6B1E5CD16D3.png "点击放大")

<br />

1. 添加SDK依赖。
   * Android Studio开发环境
     * Version Catalog方式管理依赖
       1. 打开Android Studio项目级gradle目录下的"libs.versions.toml"文件，在\[versions\]中声明Google SDK版本号。

          ```
          [versions]
          googleVersion = "16.0.1"  # 以16.0.1为例
          ```

       2. 在"libs.versions.toml"文件的\[libraries\]中声明华为认证SDK和Google SDK。

          ```
          [libraries]
          agconnect-auth-google = { module = "com.huawei.agconnect:agconnect-auth-google", version.ref = "agcVersion" }  # agcVersion声明请参见声明AGC插件和SDK。
          google-sdk = { module = "com.google.android.gms:play-services-auth", version.ref = "googleVersion" }
          ```

       3. 在应用级"build.gradle"文件的"dependencies"中添加华为认证SDK和Google SDK的编译依赖。

          ```
          dependencies {      
               implementation libs.agconnect.auth.google
               implementation libs.google.sdk
          }
          ```

     * 非Version Catalog方式管理依赖 打开应用级gradle文件（通常在 app/build.gradle），在"dependencies"中添加华为认证SDK和Google SDK的编译依赖：

       ```
       dependencies {
           implementation "com.huawei.agconnect:agconnect-auth-google:1.9.4.300"     
           implementation "com.google.android.gms:play-services-auth:{version}"
       }
       ```

   * Eclipse开发环境  
     打开aar2eclipse/aar目录下的build.gradle文件， 在"dependencies"中添加华为认证SDK和Google SDK的编译依赖。具体步骤参见[Eclipse开发环境集成AGC SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-integration-sdk-0000001325876845#section1878849165620)。

     ```
     dependencies {
         embed "com.huawei.agconnect:agconnect-auth-google:1.9.4.300"
         embed "com.google.android.gms:play-services-auth:{version}"
     }
     ```

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143819.97076633662076963889254236189407:50001231000000:2800:BC68FD6D8AD8757AACC43D7486890C01E34874AB4D9109ACB9E63170BB6C74DF.png)  
   * 示例中的googleVersion和{version}请替换为Google SDK的最新版本号，华为不负责更新。
   * 由于华为未提供Google SDK依赖包，您可以在Google开放平台下载最新版本的Google SDK依赖包进行手动集成。
2. 配置Google账号登录所需参数。  
   在资源文件/app/res/values/strings.xml中配置Google应用的app_id和client_id。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143819.24381161767682151004203679015256:50001231000000:2800:5F2143DFCFDBE81756023EB233A0F0A0EBB223E9E5F8CA58AA97C61C6B760A6E.png)  
   client_id参考[启用认证方式](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-authentication-method-0000002417916829#section1871913499476)中配置的"客户端ID"，app_id为client_id开头的数字（通常12位或更多）。

   ```
   <string name="google_app_id">5758********</string>
   <string name="google_client_id">5758********.apps.googleusercontent.com</string>
   ```

3. 添加生命周期回调，请参见[统一登录调用页面回调](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-unified-login-0000001325756981)。
4. 调用[AGConnectAuth.signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauth-0000001054482530#section125666562219)，登录Google账号。  

   ```
   "Java"
   AGConnectAuth.getInstance().signIn(this,AGConnectAuthCredential.Google_Provider).addOnSuccessListener(new OnSuccessListener<SignInResult>() {
           @Override
           public void onSuccess(SignInResult signInResult) {
                   // onSuccess
                   AGConnectUser user =  signInResult.getUser();
           }
   })
   .addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
                   // onFail
           }
   });
   ```

   ```
   "Kotlin"
   AGConnectAuth.getInstance().signIn(this, AGConnectAuthCredential.Google_Provider).addOnSuccessListener {
       // updateUI
   }.addOnFailureListener {
       // onFailure
   }
   ```

#### 传统接入方式

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143819.40462584069322866542218096853332:50001231000000:2800:59BCFA26D7B68556FDFC7845B96A973ABEB0652D6F310C2ED7071A8D27DDF35D.png "点击放大")

1. 在应用的登录界面，初始化[AGConnectAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauth-0000001054482530)实例，获取AGC的用户信息，检查是否有已经登录的用户。如果有则可以直接进入用户界面，否则显示登录界面。  

   ```
   "Java"
   AGConnectUser user = AGConnectAuth.getInstance().getCurrentUser();
   ```

   ```
   "Kotlin"
   val user = AGConnectAuth.getInstance().currentUser
   ```

2. Google账号登录，并获取Google账号的用户授权信息。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143819.87636687008836835724409941801010:50001231000000:2800:0F9C55C5D6063FCD9B29C543441ED8F235F6804CD61B0E9E5438DD74A890969E.png)  
   此步骤仅供参考，更详细内容，请参见[Google官方文档](https://developers.google.com/identity/sign-in/android) 。
   1. 获取Google登录授权。  

      ```
      "Java"
      GoogleSignInOptions gso = new GoogleSignInOptions.Builder(GoogleSignInOptions.DEFAULT_SIGN_IN)
               .requestIdToken(CLIENT_ID)
               .requestProfile()
               .build();
      client = GoogleSignIn.getClient(this, gso);

      Intent signInIntent = client.getSignInIntent();
      startActivityForResult(signInIntent, RC_SIGN_IN);
      ```

   <!-- -->

   2. 添加授权确认后的回调，获取授权后的idToken。  

      ```
      "Java"
      @Override
      protected void onActivityResult(int requestCode, int resultCode, Intent data) {
          super.onActivityResult(requestCode, resultCode, data);

       if (requestCode == RC_SIGN_IN) {
           Task<GoogleSignInAccount> task = GoogleSignIn.getSignedInAccountFromIntent(data);
           task.addOnSuccessListener(new OnSuccessListener<GoogleSignInAccount>(){
               @Override
               public void onSuccess(GoogleSignInAccount googleSignInAccount) {
                   String idToken = googleSignInAccount.getIdToken();
               }
           }).addOnFailureListener(new OnFailureListener(){
               @Override
               public void onFailure(@NonNull Exception e) {
               }
           });
       }
      }
      ```

3. 调用[GoogleAuthProvider.credentialWithToken](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/googleauthprovider-0000001054083790#section531916619813)使用从Google账号获取的idToken生成credential，并调用[AGConnectAuth.signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauth-0000001054482530#section298148131715)实现登录。  

   ```
   "Java"
   AGConnectAuthCredential credential = GoogleAuthProvider.credentialWithToken(idToken);
   AGConnectAuth.getInstance().signIn(credential)
   .addOnSuccessListener(new OnSuccessListener<SignInResult>() {
       @Override
       public void onSuccess(SignInResult signInResult) {
           // onSuccess
           AGConnectUser user = signInResult.getUser();
       }
   })
   .addOnFailureListener(new OnFailureListener() {
       @Override
       public void onFailure(Exception e) {
           // onFail
       }
   });
   ```

   ```
   "Kotlin"
   val credential = GoogleAuthProvider.credentialWithToken(idToken)
   AGConnectAuth.getInstance().signIn(credential).addOnSuccessListener {
       // onSuccess
       val user = it.user
   }.addOnFailureListener {
       // onFail
   }
   ```

#### 更多信息

* 您如果想让用户可以使用多个账号登录您的应用，可以将多个[账号进行关联](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-associated-0000001053692650)。
* 当用户不需要使用应用，或者需要切换其他账号登录认证，可以先执行[登出](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-sign-out-0000001053612647)。
* 当用户需要注销当前用户，可以进行[销户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-deleteuser-0000001057730521)。
* 对于销户、修改密码、关联账号以及重置手机账号和邮箱账号等敏感操作，为了提高安全性，需要用户必须在5分钟内登录过才能执行。如果用户执行敏感操作时登录超过5分钟，需要[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-reauthenticate-0000001127287737)后再执行敏感操作。
* 您可以参考[异常处理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-troubleshooting-0000001052932665)实现自己的异常处理机制，从而减少异常情况的发生。
* 您可以使用云函数触发器来接收用户注册、登录、销户等关键事件，从而[扩展认证服务的能力](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-extension-0000001053372708)。
* 您可以参考[管理用户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-user-manage-0000001606051705)对用户进行解锁、停用等操作。
