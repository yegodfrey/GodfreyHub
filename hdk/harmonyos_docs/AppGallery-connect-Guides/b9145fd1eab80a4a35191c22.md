# 加入房间

当不同的玩家加入同一语音房间内，即可互相发送/接收实时音频数据。目前，游戏多媒体服务支持加入[小队语音房间](#section242455214354)、[国战语音房间](#section644913141332)和[范围语音房间](#section84267283341)。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241105115839.30472654793534231627609996531563:50001231000000:2800:918701680665E6169F4B2AEB1FD60996BEF794E0CD4E588DC4184C1AA61E3E68.png?needInitFileName=true?needInitFileName=true)  
第一个加入小队语音或国战语音房间的玩家，默认成为该房间的房主。  

#### 前提条件

* 您已[集成游戏多媒体基础SDK和实时语音模块](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-integratingsdk-ios-0000001323104597#ZH-CN_TOPIC_0000001323104597__li16373152113206)。
* 您已[创建游戏多媒体实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-engine-ios-0000001272544612#section1093713161034)。
* 您已规划语音房间ID。  

#### 加入小队语音房间

1. 调用[HWPGMEngine.getInstance joinTeamRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section148103415316)方法，使用相同的房间ID即可进入同一小队语音房间。

   ```
   HWPGMEngine *pgmeEngine = [HWPGMEngine getInstance];
   [pgmeEngine joinTeamRoom:roomId]; // roomId:自定义的房间ID
   ```

2. 当玩家加入小队语音房间时，可在HWPGMEngineDelegate接口的[onJoinTeamRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section1578012321379)方法中实现相关回调处理。

   ```
   - (void)onJoinTeamRoom:(NSString* _Nonnull)roomId code:(int)code msg:(NSString *)msg {
       // 可根据需求将数据进行处理
   }
   ```

   当玩家成功加入小队语音房间时，房间内其他玩家可在HWPGMEngineDelegate接口的[onPlayerOnline](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section41781936162213)方法中实现该事件的回调处理。

   ```
   - (void)onPlayerOnline:(NSString* _Nonnull)roomId openId:(NSString* _Nonnull)openId {
      // 可根据需求将数据进行处理
   }
   ```

#### 加入国战语音房间

在国战语音房间中，玩家分为指挥官和群众两种角色。加入房间时，玩家可根据roleType选择自身角色。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241105115839.20409484318679575595343996969570:50001231000000:2800:D5769A75ADE3654B85DD04AA8C6D718530C93302505CDD5B0774F346E18AEE73.png?needInitFileName=true?needInitFileName=true)  
* 在一个国战房间中，指挥官角色最多支持15人，群众角色最多支持10000人。
* 当玩家为指挥官角色时，则具备发送和接收语音的权限。当玩家为群众角色时，则仅具备接收语音的权限。

1. 调用[HWPGMEngine.getInstance joinNationalRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section1013715561211)方法，使用相同的房间ID即可进入同一国战语音房间。

   ```
   HWPGMEngine *pgmeEngine = [HWPGMEngine getInstance];
   [pgmeEngine joinNationalRoom:roomId roleType:roleType]; // roomId：自定义的房间ID；roleType：角色类型，ROOM_ROLE_JOINER表示指挥官，ROOM_ROLE_PLAYER表示群众
   ```

2. 当玩家加入国战语音房间时，可在HWPGMEngineDelegate接口的[onJoinNationalRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section7511192014575)方法中实现该事件的回调处理。

   ```
   - (void)onJoinNationalRoom:(NSString* _Nonnull)roomId code:(int)code msg:(NSString *)msg {
       // 可根据需求将数据进行处理
   }
   ```

   当玩家成功加入国战语音房间时，房间内其他玩家可在HWPGMEngineDelegate接口的[onPlayerOnline](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section41781936162213)方法中实现该事件的回调处理。

   ```
   - (void)onPlayerOnline:(NSString* _Nonnull)roomId openId:(NSString* _Nonnull)openId {
      // 可根据需求将数据进行处理
   }
   ```

#### 加入范围语音房间

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241105115839.90053927141678995186721537669873:50001231000000:2800:0E47D718835FB5793A1CA66B0D8FC35DBF62455953A750489FA3C5BF1B25E7DC.png?needInitFileName=true?needInitFileName=true)  
加入范围语音房间，您还需要设置语音接收范围，并更新上报自身和其他玩家的位置信息，具体请参见[范围语音](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-rangeroom-ios-0000001645321390)。

1. 调用[HWPGMEngine.getInstance joinRangeRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section172202255436)方法，使用相同的房间ID即可进入同一范围语音房间。

   ```
   HWPGMEngine *pgmeEngine = [HWPGMEngine getInstance];
   [pgmeEngine joinRangeRoom:roomId]; // roomId:自定义的房间ID
   ```

2. 当玩家加入范围语音房间时，可在HWPGMEngineDelegate接口的[onJoinRangeRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section16581419145)方法中实现相关回调处理。

   ```
   - (void)onJoinRangeRoom:(NSString* _Nonnull)roomId code:(int)code msg:(NSString *)msg {
       // 可根据需求将数据进行处理
   }
   ```
