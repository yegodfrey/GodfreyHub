# 概述

Serverless数据库记录数限制模板支持设置云数据库服务中记录总数的最大值，并且根据所需的间隔保留数据。使用此模板控制云数据库中存储的最大记录数。如果指定云数据库中的记录数超过阈值，则此模板将首先删除最早的记录，直到剩余的记录数达到最大计数。

#### 使用场景

Serverless数据库记录数限制模板支持您配置数据保持在云数据库中的上限值。当云数据库中的数据总数超过您配置的上限值时，则系统将从数据库中删除最早的记录。通过使用此模板，可以自行清理超过上限值的历史数据，无需开发人员在后台进行历史数据的管理。

当您在指定的云数据库区域添加数据时，此Serverless模板可以实现如下功能。

1. 监听云数据库服务的添加数据。当监听到添加数据时，系统运行此Serverless模板。
2. 将你设置的限制行数与总记录的行数比较，包括最后添加到云数据库区域的记录。
3. 如果记录总行数超过您设定的限制后，则系统将从云数据库区域中删除最早的数据。
4. 删除数据后，云数据库区域中数据总行数不能超过您设置的最大值。
