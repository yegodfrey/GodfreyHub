# 账号重认证

#### 前提条件

* 您需要在AGC控制台[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-integration-sdk-0000001325876845)。  

#### 开发步骤

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143813.98118967246755880807663825484164:50001231000000:2800:29B4974A89F15F6DC4CBF8A706FD6D24428174F6307805F3C237FD64388AB2AB.png "点击放大")

对于销户、修改密码、关联账号以及重置手机账号和邮箱账号这些敏感操作，要求用户必须在5分钟内登录过才能执行。如果您执行敏感操作时已经登录超过5分钟，该操作会抛出AGCAuthException异常并收到错误码为203818081的错误，这种情况下您可以先调用[AGConnectUser.reauthenticate](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectuser-0000001054522513#section298148131715)重认证账号后再执行敏感操作。  

```
"Java"
AGConnectUser user=AGConnectAuth.getInstance().getCurrentUser();
AGConnectAuthCredential phoneAuthCredential=PhoneAuthProvider.credentialWithPassword("86","131*********","MyPassword");
user.reauthenticate(phoneAuthCredential)
        .addOnSuccessListener(result->{Log.i(TAG,"reauthenticate success");})
        .addOnFailureListener(e->Log.e(TAG,"reauthenticate failure",e));
```

```
"Kotlin"
val user = AGConnectAuth.getInstance().currentUser
val phoneAuthCredential = PhoneAuthProvider.credentialWithPassword("86", 131*********, "MyPassword")
user.reauthenticate(phoneAuthCredential)
        .addOnSuccessListener({ result -> Log.i(TAG, "reauthenticate success") })
        .addOnFailureListener({ e -> Log.e(TAG, "reauthenticate failure", e) })
```
