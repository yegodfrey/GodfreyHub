# 爱剪辑

#### 客户需求

《爱剪辑》是深圳市爱剪辑科技有限公司旗下的一款视频编辑应用软件。该公司希望能够降低应用的ANR率，提升应用质量和用户体验。  

#### 华为解决方案

《爱剪辑》应用接入AGC性能管理服务后，该公司通过ANR单事件分析，找到应用发生ANR的日志，并进行优化。应用的ANR率从1.02%降低至0.3%以下，极大提高了用户的使用体验。
