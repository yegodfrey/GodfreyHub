# 使用模板导出视频

使用视频模板，通过替换模板中的视频素材，即可快速导出与模板视频效果类似的视频。同时，还支持替换模板中的文字、图片或音频素材内容。

## 前提条件

* 您已获取到模板ID信息。
* 您已完成[视频录制](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/game-highlight-record-0000001686286401)。
* （可选）您已准备好用于替换的文字、图片或音频素材。

## 开发步骤

1. 调用[GameReplayManager.exportVideo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamereplaymanager-game-replay-0000001690120477#section7938630104410)方法，套用视频模板即可轻松实现视频素材的剪辑与导出，同时支持替换视频模板中的文字、图片和音频内容。

   ```screen
   gameReplayManager.exportVideo(
       new ExportParam()
       .setFileName(fileName)                       // 自定义导出文件名
       .setTemplateId(templateId)                   // 模板ID  
       .setImportFilePaths(importFilePaths)        // 包含视频文件名的绝对路径列表,视频文件必须为.mp4格式,按顺序替换模板中的视频片段
       .setReplaceWords(replaceWords)               // 用于替换视频模板文案的文字片段,最长30个字符,按顺序替换模板中的文字片段,为空则删除模板中的原文案内容,为null则不替换
       .setReplaceStickerPaths(replaceStickerPaths) // 包含图片文件名的绝对路径列表,图片文件仅支持.jpg/.png/.gif格式,按顺序替换模板中的图片,为空或为null则不替换
       .setReplaceAudioPaths(replaceAudioPaths));    // 包含音频文件名的绝对路径列表,音频文件仅支持.mp3格式,按顺序替换模板中的音频片段,为空或为null则不替换
   ```

2. 在ReplayCallback接口的[onExportProgress](#ZH-CN_TOPIC_0000001686457641__section12899202731314)方法中，可获取视频导出进度，并实现相关回调处理。

   ```screen
   @Override
   public void onExportProgress(int percent) {
       // 根据导出视频的进度做相应业务逻辑处理
   }
   ```

3. 在ReplayCallback接口的[onWarning](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/replaycallback-callback-0000001686126937#section23141259153316)方法中，可根据导出视频过程中告警返回的结果，实现相关回调处理。

   ```screen
   @Override
   public void onWarning(RecordResult result) {
       // // 根据导出视频过程中告警返回的结果做相应业务逻辑处理
   }
   ```

4. 在ReplayCallback接口的[onVideoExported](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/replaycallback-callback-0000001686126937#section1505722123719)方法中，还可根据导出视频返回结果实现相关回调处理。

   ```screen
   @Override
   public void onVideoExported(RecordResult result) {
       // 根据导出视频返回结果做相应业务逻辑处理
   }
   ```
