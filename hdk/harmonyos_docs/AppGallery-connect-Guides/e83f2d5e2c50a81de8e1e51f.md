# （推荐）从云函数访问

## 准备工作

目前您可以通过DevEco Studio创建端云一体化工程来实现在云函数中访问云函数，您需要完成如下操作：

1. [创建端云一体化工程](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V5/agc-harmonyos-clouddev-devproject-V5)。
2. [创建并配置您准备访问云函数的云函数](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V5/agc-harmonyos-clouddev-createfunc-V5)。

## 集成SDK

AGC Server SDK发布在npm仓库，您可以通过下列步骤来进行集成：

1. 如果您还没有package.json文件，可进入Terminal终端窗口，在您新建的云函数目录下执行以下命令进行创建。

   ```screen
   npm init
   ```

   请按实际情况填写项目的配置信息。
2. 然后在该目录下继续执行以下命令，安装Server SDK到您的项目中。此时依赖将同步添加到项目云函数目录下的package.json文件中。

   ```screen
   npm install --save @hw-agconnect/cloud-server
   ```

3. 在您的云函数目录下准备访问云函数的代码文件中添加如下代码，导入云开发模块。

   ```screen
   import { cloud } from "@hw-agconnect/cloud-server";
   ```

之后您即可直接在该云函数中通过Server SDK调用其他云函数了。
> 注意
>
> 被调用的云函数HTTP触发器的认证类型须配置为云侧网关认证，即"authType"配置为"cloudgw-client"。

## 调用函数

### 查询函数名和版本号

当您在创建的"事件调用"函数或函数别名中创建了一个HTTP类型的触发器（认证类型选择"API客户端鉴权（Server适用）"后，在主调函数的代码中调用函数时需要传入被调函数的函数名和版本号（或别名），查询方法如下：

在被调函数的触发器页面点击"HTTP触发器"，查看"触发URL"的后缀，获取触发器的标识，格式为"函数名-版本号"。如下图所示，"function-test-$latest"即为HTTP触发器标识，其中"function-test"为函数名，"$latest"为版本号。

### 调用函数

* 从AGC云函数发起的访问，可使用[cloud.function().call(params)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/cloudfunction-nodejs-0000001733038596#section2026765062216)直接调用函数。

  ```screen
  const functionResult = cloud.function().call({name: "your-cloud-function"});
  // "your-cloud-function" 请替换为您创建的函数名称
  ```

* 若您需要自定义客户端实例名称，可参照如下示例调用函数。
  * （可选）通过设置version属性设置函数版本号，默认为最新版本'$latest'。
  * （可选）通过设置timeout属性设置函数超时时长，单位为毫秒，默认值为55000。
  * （可选）如果函数有入参，可通过data参数传入，如果没有参数则不传。

  ```screen
  const functionResult = cloud.createInstance({ name: "instancename"}).function().call({name: "your-cloud-function", version: "$latest", timeout:3000, data: {"simple":"example"}});
  ```
