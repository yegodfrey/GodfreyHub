# 环境变量

环境变量为key-value形式，您可以将需要的变量配置信息传入函数执行环境中，用于函数在运行时读取和使用。

添加环境变量支持**表单格式编辑** 和**JSON格式编辑**两种方式。
> 说明
>
> * 环境变量的key值具有唯一性，且"PROJECT_CREDENTIAL"和"AGC_"为系统级环境变量标识，不允许添加以其命名或以其为前缀的环境变量。
> * 环境变量总数不超过1000个。

## 表单格式编辑

在函数列表中点击函数名称，进入函数详情页面。选择"函数配置"页签，在"环境变量"区域，默认选中"表单格式编辑"，点击"新增变量"。编辑完成后，点击左下角的"保存"。

## JSON格式编辑

在函数列表中点击函数名称，进入函数详情页面。选择"函数配置"页签，在"环境变量"区域，选中"JSON格式编辑"，在文本框中以key-value键值对JSON格式添加环境变量。当添加的环境变量比较多时，为了方便核对，可点击"format"对变量进行格式化排列。编辑完成后，点击左下角的"保存"。
