# 断开连接

## 接口描述

调用AgdApiClient.disconnect接口可以断开和AGD SDK的连接，建议在不需要AGDSDK的服务时立刻调用，防止应用市场长时间在后台常驻。

调用了断开连接，将不再可以使用AgdClient进行任何api操作。

## 输入参数

无

## 返回参数

无

## 示例代码

```screen
@Override
protected void onDestroy() {
    super.onDestroy();
    if (null != client) {
        client.disconnect();
   }
}
```
