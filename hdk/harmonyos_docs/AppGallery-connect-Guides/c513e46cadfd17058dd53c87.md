# 通过云函数扩展

云数据库服务为您提供了基于云函数的扩展机制。您开发云函数时，可通过调用Server Node.js SDK API接口，实现对云侧数据库数据的增、删、改、查功能，详细API接口信息请参见[Server Node.js SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-overview-server-nodejs-0000001718931830)。

您可以通过为云函数配置相应触发器来接收插入或者更新数据、删除数据、清空数据等关键事件，并在云函数中扩展您的业务处理逻辑。更多云函数开发和部署信息请参见[云函数服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloud-function-introduction-0000001059279544)。  

#### 在函数中操作云数据库数据

您可以通过云函数操作云数据库中的数据，实现数据的新增、修改、删除和查询等功能。

```
let bookInfo1 = new BookInfo();
bookInfo1.setId(1);
bookInfo1.setBookName("Database");
bookInfo1.setAuthor("Lily");
bookInfo1.setPublisher("publisherA");
bookInfo1.setPublishTime(new Date('1997-07-26T03:24:00'));
bookInfo1.setPrice(80.99);

let bookInfo2 = new BookInfo();
bookInfo2.setId(2);
bookInfo2.setBookName("Shi Ji");
bookInfo2.setAuthor("Sima Qian");
bookInfo2.setPublisher("publisherB");
bookInfo2.setPublishTime(new Date('1964-01-01T03:24:00'));
bookInfo2.setPrice(40.99);

let bookInfoList = [];
bookInfoList.push(bookInfo1);
bookInfoList.push(bookInfo2);

// 在BookInfo对象类型中增加数据或者更新数据：
try {
	const resp = await this.cloudDBZoneClient.executeUpsert(bookInfoList);
} catch (error) {
	console.warn('upsertBookInfo=>', error);
}

// 在BookInfo对象类型中查询price小于50的数据
try {
	const cloudDBZoneQuery = clouddb.CloudDBZoneQuery.where(BookInfo).lessThan("price", 50.00);
	const resp = await cloudDBZoneWrapper.queryBooks(cloudDBZoneQuery);
} catch (err) {
	console.warn('queryBookInfo=>', error);
}

// 在BookInfo对象类型中删除数据
try {
	const resp = await this.cloudDBZoneClient.executeDelete(bookInfoList);
} catch (error) {
	console.warn('deleteBookInfos=>', error);
}

// 在BookInfo对象类型中删除所有数据：
try {
	const resp = await this.cloudDBZoneClient.executeDeleteAll(BookInfo);
} catch (error) {
	console.warn('deleteAllBookInfos=>', error);
}
```

#### 为函数设置云数据库服务触发器

为函数添加触发器时，可以选择云数据库服务触发器，请参见[创建CLOUDDB触发器](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudfunction-clouddbtrigger-0000001658558540#section388914594910)。

云数据库服务触发器提供了四种事件类型：

* onUpsert：数据表插入或更新数据。
* onDelete：数据表删除数据。
* onDeleteAll：数据表清空。
* onWrite：数据插入或更新事件、数据删除事件、数据表清空事件。
