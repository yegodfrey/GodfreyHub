# 错误码

#### 1-100

|错误码|描述|解决方法|
|:--|:--------------------|:------------------------------|
|1|内部错误。|结合调试日志中的提示信息定位问题并解决。|
|2|本地数据库初始化失败。|清理本地缓存数据，然后检查初始化流程和参数是否正常。|
|3|数据库繁忙。|降低SDK侧本地读写数据的并发数。|
|4|初始化存储区失败。|检查初始化流程是否合理。|
|5|存储区不存在。|确认操作的存储区已经创建，再进行操作。|
|6|存储区数量超过限定值。|请合理创建存储区，控制创建存储区的数量不超过4个。|
|7|存储区正在使用。|该存储区有任务在执行中，等待存储区任务执行完成之后再进行操作。|
|8|请先关闭存储区。|关闭存储区后再进行操作。|
|9|请先打开存储区。|打开存储区再进行操作。|
|10|请先取消订阅。|关闭存储区前，请移除订阅器。|
|11|查询条件不合法。|检查查询条件，合理构造符合要求的查询条件。|
|12|对象大小超过限制。|限制插入的单条数据大小不超过2MB。|
|13|订阅器数量超出限制。|合理使用订阅功能，控制订阅器数量不超出限制。|
|14|SDK版本不正确。|核对SDK版本信息。|
|15|无操作权限。|检查待操作数据是否符合权限要求。|
|16|对象类型不存在。|确保使用的对象类型是与AGC网站上定义的一致。|
|17|对象类型信息不匹配。|确保对象类型与版本相匹配。|
|18|非法的CloudDBZoneConfig。|检查CloudDBZoneConfig的内容，确保符合要求。|
|19|未查询到数据。|请确保数据库中有符合条件的数据。|
|21|对象类型不支持降级。|确保对象类型版本高于当前版本。|
|30|无效入参，该错误码仅适用于iOS SDK。|检查参数内容，确保符合要求。|
|31|非法状态，该错误码仅适用于iOS SDK。|结合错误信息定位问题并解决。|
|50|用户密码格式不正确。|使用正确格式的用户密码。|
|51|数据加密密钥不正确。|更新加密密钥前输入用户密码。|
|52|加密失败。|结合调试日志中的提示信息定位问题并解决。|
|53|解密失败。|结合调试日志中的提示信息定位问题并解决。|
|54|未设置用户密码时，不支持修改用户密码。|请先设置用户密码。|
|55|用户数据重新加密中，稍后再试。|等待用户数据重新加密完成再进行操作。|

|:---|:----------|:---------------------------------------------------------|

|1007|请求超时。|请重试。如果反复出现，请联系华为技术工程师支持。|
|1012|获取产品认证信息失败。|检查配置文件中是否设置了正确的产品信息。如果正确设置后依然出现该问题，请联系华为技术工程师支持。|
|1013|获取用户认证信息失败。|检查用户是否登录，以及产品是否正确开启认证服务。如果正确设置上述信息后依然出现该问题，请联系华为技术工程师支持。|
|1014|产品配置文件无效。|检查APP配置文件是否与提供的一致，不一致请修改配置文件。如果配置文件一致依然出现该问题，请联系华为技术工程师支持。|
