# 从服务器访问

[您已创建并配置准备访问云函数的云函数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/server-nodejs-create-func-0000001736837986)。

## 下载项目级认证凭据

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。

3. 在"项目设置"页面中点击"Server SDK"页签。
4. 点击认证凭据中的"创建"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704165812.53146884193781764258875491769171:50001231000000:2800:7274EAD5227C4711608D58D6C9D1724D1D0BC0F27F2811461EFBBD222BF55755.png)

## 集成SDK

### 集成Node.js Server SDK

AGC Server SDK发布在npm仓库，您可以通过下列步骤来进行集成：

1. 如果您还没有package.json文件，可进入Terminal终端窗口，在项目的根目录下执行以下命令进行创建。

   ```screen
   npm init
   ```

   请按实际情况填写项目的配置信息。
2. 然后在该目录下继续执行以下命令，安装Server SDK到您的项目中。此时依赖将同步添加到项目的package.json文件中。

   ```screen
   npm install --save @hw-agconnect/cloud-server
   ```

3. 在您的项目中添加如下代码，导入云开发模块。

   ```screen
   import { cloud } from "@hw-agconnect/cloud-server";
   ```

### 初始化Node.js Server SDK

从您自己构建或者购买的服务器发起的访问，需要下载凭据文件并集成到代码中。

1. 获取认证凭据，并将认证凭据放置到您自定义的目录，服务器执行用户需要具备认证凭证文件读权限，请参见[下载项目级凭据](#section5919158123315)。
2. 初始化SDK。

   您可以使用之前下载的认证凭据对SDK进行初始化。当前认证凭证初始化提供了两种方式，您可以设置AGC_CONFIG环境变量，也可以在代码中明确传递认证凭证路径。
   * 方式一：需要先设置环境变量。
     * Linux环境请执行如下操作： 永久环境变量需要在$HOME目录中的.bashrc或者.bash_profile文件中写入如下命令，并执行source .bashrc或者.bash_profile保证环境变量生效。临时环境变量直接执行如下命令，*[PATH]*请替换为凭据文件的实际路径。

       ```screen
       export AGC_CONFIG="[PATH]/agc-apiclient-xxx-xxx.json"
       ```

     * Windows环境请执行如下操作: 永久环境变量需要在Windows的"高级系统设置 > 环境变量"中设置如下的系统变量，建议重启windows系统或者通过其他方式加载环境变量，使设置的系统环境变量生效。

       临时环境变量直接执行如下命令，*[PATH]*请替换为凭据文件的实际路径。

       ```screen
       set AGC_CONFIG=[PATH]\agc-apiclient-xxx-xxx.json
       ```

     之后您即可参考如下示例直接调用函数：

     ```screen
     cloud.function().call({name: "your-cloud-function"})
     ```

   * 方式二：指定认证凭证路径。*[PATH]* 请替换为凭据文件的实际路径。

     若您未指定环境变量，则须按照当前方式操作。您还可以使用凭据文件创建多个实例。

     ```screen
     const cloudInstance = cloud.createInstance({ path: '[PATH]/agc-apiclient-xxx-xxx.json', name: "instancename", Region.REGION_CN});
     ```

     其中Region是客户端的数据处理位置，可选的值有"REGION_CN"（中国）、"REGION_RU"（俄罗斯）、"REGION_SG"（新加坡）、"REGION_DE"（德国）。

     之后您即可参考如下示例直接调用函数：

     ```screen
     cloudInstance.function().call({name: "your-cloud-function", data: "your-data"});
     ```

## 调用函数

### 查询函数名和版本号

当您在创建的"事件调用"函数或函数别名中创建了一个HTTP类型的触发器（认证类型选择"API客户端鉴权（Server适用）"后，在主调函数的代码中调用函数时需要传入被调函数的函数名和版本号（或别名），查询方法如下：

在被调函数的触发器页面点击"HTTP触发器"，查看"触发URL"的后缀，获取触发器的标识，格式为"函数名-版本号"。如下图所示，"function-test-$latest"即为HTTP触发器标识，其中"function-test"为函数名，"$latest"为版本号。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704165812.52216078370556854378271389651380:50001231000000:2800:6E780D5D46D158D09ABEE5231562A5E7AD09FAF6085CA33AC7012F30A2E91456.png)

### 调用函数

工程集成了云函数Server SDK后，可以在工程内直接通过SDK API调用AGC中的云函数，云函数SDK与AGC的函数调用基于HTTPS的安全访问。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704165813.97148235698244313447678834453913:50001231000000:2800:D70270418CB09BA5F9CC57CEFFBF0FFC810EC57DF90575B6C0F4E98BD5C830F9.png "点击放大")

* 若您通过[方式一](#ZH-CN_TOPIC_0000001892441242__li44910271197)初始化Server SDK，可使用[cloud.function().call(params)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/cloudfunction-nodejs-0000001733038596#section2026765062216)调用函数。

  ```screen
  const functionResult = cloud.function().call({name: "your-cloud-function"});
  // "your-cloud-function" 请替换为您创建的函数名称
  ```

* 若您通过[方式二](#ZH-CN_TOPIC_0000001892441242__li19640511181011)初始化Server SDK，可参照如下示例调用函数。
  * （可选）通过设置version属性对云函数设置函数版本号，默认为最新版本'$latest'。
  * （可选）通过设置timeout属性对云函数设置超时时长，单位为毫秒，默认值为55000。
  * （可选）如果函数有入参，可通过data参数传入，如果没有参数则不传。

  ```screen
  const functionResult = cloudInstance.function().call({name: "your-cloud-function", version: "$latest", timeout:3000, data: {"simple":"example"}});
  ```
