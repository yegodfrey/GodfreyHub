# 激活/去激活库实例

当游戏准备好绘制预测帧时，应调用函数激活当前库实例。  

#### 前提条件

* 已[创建库实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/predict-frame-create-instance-vulkan-0000001791483622)。
* 已[设置主要参数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/predict-frame-set-frame-parameters-vulkan-0000001791323930)。  

#### 激活库实例

调用函数[FrameFlowVK_Activate](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflowvk-activate-0000001791494408)，激活当前库实例。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240314102214.35266354699201530885517438988143:50001231000000:2800:518FD2600EC07566963E7102EDDF8E4935F59EF89C90F21BE700378DCC974E7F.png?needInitFileName=true?needInitFileName=true)  
函数调用成功后，该库实例将被视为活动状态，否则将被视为非活动状态。

```
FFResult FrameFlowVK_Activate(FFVKInstance instance);
```

#### 去激活库实例

在某些使用场景（如设置界面、镜头旋转角度过大、角色离摄像机距离过近或过远等）下，预测效果可能会不太理想或无需使用预测帧，可通过调用函数[FrameFlowVK_Deactivate](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflowvk-deactivate-0000001791334696)进行去激活库实例（即暂停）。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240314102214.08599377717587297449014321443219:50001231000000:2800:7B6873A9D5C31CCA2D3594CDEB7C4548117CF605B3AAD6F742B8DD9ECB63C427.png?needInitFileName=true?needInitFileName=true)  
函数调用成功后，该库实例将被视为非活动状态。

```
FFResult FrameFlowVK_Deactivate(FFVKInstance instance);
```

#### 查询库实例状态

调用函数[FrameFlowVK_IsActive](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflowvk-isactive-0000001838093861)，可查询库实例当前是否处于活动状态。

```
FFBool FrameFlowVK_IsActive(FFVKInstance instance);
```
