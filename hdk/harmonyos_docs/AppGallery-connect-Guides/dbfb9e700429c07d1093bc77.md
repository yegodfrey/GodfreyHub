# 初始化SDK

调用游戏性能管理SDK的接口前，必须初始化SDK。  

#### 前提条件

* 已[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-integration-ios-0000001932600658)。
* 已[获取游戏信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-get-authentication-infomation-0000001801791669#section20509644364)"Client ID"、"Client Secret"和"APP ID"信息。
* 已开启网络权限。  

#### 开发步骤

1. 导入头文件。

   ```
   #import <GPMKit.h>
   ```

2. 新建[GPMInitParams](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-ios-gpminitparams-0000001969176033)对象并传入初始化参数。

   ```
   GPMInitParams *initParams = [[GPMInitParams alloc] init];
   initParams.appId = appId;                               // 游戏APP ID
   initParams.clientId = clientId;                         // 客户端Client ID
   initParams.clientSecret = clientSecret;                 // 客户端密钥Client Secret
   initParams.accessToken = accessToken;                   // AGC接入凭证（推荐）
   initParams.logLevel = 3;                                // 日志级别
   initParams.userIdentity = userIdentity;                 // 三方账号OpenID
   ```

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110239.06023960552669986991693696591195:50001231000000:2800:0E4A7CCC8A7213F3F1EA68502E8CED97E99BB16B3745140718FF5FF242FC079C.png)  
   ClientSecret和AccessToken二者传其一即可。基于安全考虑，推荐使用AccessToken。若同时传入，将使用传入的AccessToken作为最终AGC接入凭证。AccessToken获取方法请参见[获取Token（项目级）](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-obtain-project-token-0000001801864849)。
3. 调用[GPMManager.getInstance init](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-ios-gpmmanager-0000001941578500#section1155613935519)方法初始化游戏性能管理SDK。

   ```
   SelfGPMCallbackDelegate *delegate = [[SelfGPMCallbackDelegate alloc] init];  // GPMCallbackDelegate回调实现
   ...
   [GPMManager.getInstance init:initParams callbackDelegate:delegate];
   ```

4. 初始化调用后，可在GPMCallbackDelegate接口的[onInitResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-ios-gpmcallbackdelegate-0000001968617713#section1155613935519)方法中查看结果并实现回调处理。

   ```
   - (void)onInitResult:(int)code msg:(NSString *_Nonnull)msg {
       // 可根据需求将数据进行处理
   }
   ```
