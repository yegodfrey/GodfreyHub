# 业务介绍

AppGallery Connect (简称AGC) 云存储是一种可扩展、免维护的云端存储服务，可用于存储图片、音频、视频等用户生成的内容。借助云存储服务，您无需关注存储服务器的开发、部署、运维和扩展等事宜，可聚焦于构建应用的业务功能，显著降低应用使用存储的门槛，助力您的商业成功。

|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-|
|云存储提供了客户端和服务端SDK，您可以使用云存储SDK为您的应用实现安全可靠的文件上传和下载服务。云存储服务具备如下优势： * 安全可靠：全流程使用HTTPS协议对用户的传输数据进行加密保护，并采用安全的加密协议将文件加密存储在云端。 * 断点续传：因网络原因或用户原因导致的操作中止，只需要简单地传入操作中止的位置，就可以尝试重新开始该操作。 * 可伸缩：提供EB级的数据存储，解决海量数据存储的难题。 * 易维护：通过简单的判断返回异常就可以定位出错误原因，定位快捷方便。| |

## 主要功能

|主要功能|功能描述|
|:------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|存储实例管理|您可以在云端创建指定的存储实例，用于后续保存存储对象，并可对存储实例进行删除、列举等操作。如果您不创建存储实例，则存储对象将保存到开通云存储时创建的默认存储实例中。|
|文件管理|您可以在AGC控制台，或者通过云存储SDK对文件进行上传、下载、列举、删除等操作。|
|文件元数据管理|您可以在AGC控制台，或者通过云存储SDK对文件元数据进行查询、设置等操作。|
|跨域访问|您如果需要在不同的站点访问指定的存储实例，可以设置跨域的相关配置，服务器通过配置的跨域信息进行相关允许、拒绝等操作。 > 说明 > 当前跨域访问可以通过以下两种方式进行设置： > * 在AGC控制台在进行[跨域设置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-config-cors-0000001281375696)。 > * 通过集成SDK进行跨域配置（[Java](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-configuring-cors-java-0000001115496720)丨[Node.js](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-configuring-cors-0000001139623179)）。|

## 工作原理

您的应用客户端使用云存储服务提供的SDK，可以向云存储服务器上传文件，云存储将您上传的文件存储在指定的存储实例中。您可以通过AGC访问这些文件。当然，您还可以使用云存储SDK的API执行下载、删除、管理文件等操作。云存储还可以配合[云函数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloud-function-introduction-0000001059279544)，在云存储的文件上传完成或删除成功后触发云函数执行您想要实现的功能。
