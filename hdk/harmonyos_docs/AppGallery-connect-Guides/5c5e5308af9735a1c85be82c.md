# FAQ

## 通用

### 是否能够修改AGC控制台上导出的js格式或者Objective-C格式文件？

不允许修改导出的js格式或者Objective-C格式文件，否则会导致数据同步功能异常。您如果需要修改对象类型信息，可以通过AGC控制台的对象类型修改功能或者导出的JSON格式对象类型文件进行修改。

### 为什么关闭存储区的时候，会提示"CloudDBZone is busy, try later"？

系统资源被占用，无法释放。请确保所有写入和删除操作已经完成，端云无数据同步，snapshot已经释放后，然后重新关闭存储区。

### 为什么删除存储区时会失败，提示"Close CloudDBZone first"？

删除存储区前，未将其关闭。请确保已经将待删除的存储区关闭，只有释放所有存储区句柄后，才可以删除存储区。每次打开存储区后，都需要关闭该存储区。

### 开发Android应用时，为什么已经注册了快照侦听，数据变化后并没有收到通知？

请检查**CloudDBZoneSnapshot** 对象是否释放，当**CloudDBZoneSnapshot** 对象未被释放时，注册侦听侧将无法收到数据变化通知。每次使用**CloudDBZoneSnapshot** 对象后，必须显式地调用**release()**方法来释放相关的资源。

### 数据合法为什么总提示写入失败？

请检查当前用户是否具有数据的写入权限。

### 如何判断本地数据库是否有数据？

查询数据时，可以指定从本地查询，如果能获取到数据，即说明本地数据库有数据。

### 数据库主键支持唯一性约束吗？

数据库主键支持唯一性约束。

### 数据库需要依赖华为移动服务（HMS）吗？

不依赖。只有基于云数据库开发的应用需要对接华为账号系统时才需要使用HMS服务。应用可以不支持华为账号登录，只支持微信、QQ或者其它三方账号登录，此时不需要对接HMS。所以HMS不是必须的，跟云数据库也没有依赖关系。

### 云数据库与华为云RDS的区别是什么？

华为云RDS是一种在线云数据库服务，云数据库是一款帮助开发者快速构建端云、多端协同应用的数据库服务，相比于RDS提供了更加便捷的应用开发的接口，使开发者脱离数据库的SQL/连接池/字符集等基本的数据库操作，专心于核心业务即可，同时还能够和AGC的其它产品良好交互（如云函数的触发器、云存储的备份恢复等）。

### 当执行CRUD、执行事务或者快照侦听时，如果提示异常错误码为"FAILED_PRECONDITION"，并且提示信息为"CloudDB zone initialization has not been completed."时，应该怎么解决？

在安装或者升级后首次启动时，系统数据会进行联网初始化操作，因此需要保持良好的网络状态，等待初始化完成。如果在此时立刻进行增删改查等操作，操作会失败。

### 查询云侧数据时，提示错误信息为"queryResult: 18"，应该怎么解决？

请先检查云侧是否已经正确创建对应的存储区，保证存储区已存在。如果云侧已存在存储区，且该问题仍然存在，请联系技术支持。

### 当执行CRUD、事务或者快照侦听时，如果提示异常错误码"1005002"，并且提示信息为"rejected by data re-encrypting."，应该怎么解决？

在使用全程加密功能后，如果用户更新用户密码，云数据库会对该用户的所有密文数据进行重新加密。如果重新加密过程因网络等故障中断，会提示上述错误信息。此时，需要注册数据密钥变更的侦听器**OnDataEncryptionKeyChangeListener**，并将默认返回设置为true或者提示用户选择。设置为true时，在网络故障等情况下，本端会触发继续重新加密的操作，直到将该用户所有密文数据都重新加密完成。加密完成时间由网络环境与加密数据量大小决定，若长时间等待，该问题仍然存在，请联系技术支持。

### 执行openCloudDBZone 时，出现错误信息为"Code 101 message： SQL logic error"，该如何解决？

请先检查对象类型中是否使用了[SQLite关键保留字](https://www.sqlite.org/lang_keywords.html)作为对象类型名称或字段名称。如果有使用，请更改名称或升级SDK版本为1.4.10.300及以上。

### 使用了IntAutoIncrement和LongAutoIncrement数据类型字段，Android或者iOS应用在IDE编译时出现编译错误；或者提示错误信息为"the type of [XXX] field is not supported"，应该如何解决？

Android和iOS不支持**IntAutoIncrement** 或**LongAutoIncrement** 数据类型，请检查您的云数据库版本和对应的数据类型。在Android SDK 1.5.4.300和iOS SDK 1.0.8.300之前的版本，如果使用了新增的**IntAutoIncrement** 和**LongAutoIncrement**数据类型，在IDE编译时会出现编译错误；在Android SDK 1.5.4.300和iOS SDK 1.0.8.300之后的版本中使用了上述字段，则会提示错误信息为"the type of [XXX] field is not supported"。

### 当执行CRUD时，发送一次请求失败后，查看日志中请求记录，为何日志显示两条相同请求记录？

云数据库支持主备网关切换功能，第一次向主网关发送请求失败时，系统将自动发送相同请求到备用网关。因此日志中将记录两个完全相同的请求记录。

### 开发小程序时，对不同数据处理位置的存储区添加订阅操作，提示onDisconnect，通过调试可知具体错误信息为"createSocketTask:fail wcwss exceed max concurrent count."该如何解决？

当开发小程序使用了多数据处理位置功能，且同时使用订阅功能时，仅支持对小于或等于两个数据处理位置的存储区创建订阅器，若对第三个数据处理位置创建订阅器时，出现该错误。

### 当使用iOS SDK时编译时，提示protobuf c++头文件找不到，该如何解决？

该问题是protobuf c++本身导入后没有头文件搜索路径导致的，可以通过如下两种方式解决。

* 升级cocoapods版本至1.10.2后再删除本地工程对应**pods** ，**pod.lock** 文件重新执行**pod update**命令。
* 直接在工程的"Target Support Files"目录下编辑**Protobuf-C++.release.xcconfig**文件，在文件内容中追加 "HEADER_SEARCH_PATHS = $(PODS_ROOT)/Protobuf-C++/src"。

### 在数据库权限控制页面勾选了所有人可以操作数据，还需要接入认证服务吗？

数据库权限控制页面的所有人指的是用户项目认证范围内的所有人。云数据库SDK 依赖认证服务进行项目认证，因此需要接入认证服务，进行项目认证后的APP的登录方不需要进行手动个人级认证，即可操作对应数据。

### 为什么请求会偶现时延到秒级别的问题？

为了给更多开发者提供服务，云数据库会限制每个APP单位时间的资源占用率，如果您在短时间内发送了较多的请求就可能会出现上述的现象，建议您升级到付费APP来获取更优质的体验。

### iOS的swift工程无法直接使用云数据库SDK，该如何解决？

将swift工程中需要调用的.h文件统一用一个头文件管理，并把这个头文件在工程的相对路径配置到工程配置Build Settings的Swift Complier - General 的 Objective-C Bridging Header 中。随后即可在swift工程的全局直接调用对应的云数据库SDK的接口。

### 在1.0.11.300版本Server(Java)云函数中调用云数据库出现"Failed to parse json string"错误，如何解决？

问题描述：

在1.0.11.300版本Server(Java)云函数中调用云数据库报错，提示：com.huawei.agconnect.server.commons.json.AGCJSONException: Failed to parse json string.

解决方案：

将Server(Java) SDK升级为1.0.13.300版本。

若版本升级后还未解决，请在云数据库中新增环境变量**JAVA_SDK_RESOLVER_VERSION=v0**

## 快游戏

### 集成快游戏SDK时，出现错误信息"code":10001,"msg":"agc network request error"，该如何解决？

使用开发工具（如VSCode）打开agconnect-quickgame-1.4.4-min.js文件，格式化代码后，搜索代码片段**return e.response**，并将其修改为如下内容：

```screen
try {
    return JSON.parse(e.response)
} catch (t) {
    return e.response
}
```
