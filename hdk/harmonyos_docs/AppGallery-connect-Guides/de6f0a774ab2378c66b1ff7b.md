# 手机

您可以在应用中集成手机账号认证方式，您的用户可以使用手机号码和密码或者手机号码和验证码来登录您的应用。  

#### 前提条件

* 您需要在AGC控制台[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-integration-sdk-0000001326347605)。  

#### 注册

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114607.86131640853433505533545678475042:50001231000000:2800:3FAF5AFDEB6244B74C39830015B7CEDBC464401ED262D5E32EC4CEEEEF1207DE.png "点击放大")

1. 申请手机注册的验证码，在使用手机注册之前，需要先验证您的手机，确保该手机归您所有。 调用[\[AGCVerifyCodeSettings initWithAction:locale:sendInterval:\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcverifycodesettings-ios-0000001054103662#section12565114311561)生成setting，然后调用[\[AGCPhoneAuthProvider requestVerifyCodeWithCountryCode:phoneNumber:settings:\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcphoneauthprovider-ios-0000001054502404#section1528433361114)申请验证码。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114607.77927028949593518969535644208352:50001231000000:2800:27A9EC51D4FBD80D8ED640A9C589DA1BCDC1CD8F9BBB428E9E1E114957E1113D.png)  
   当前认证服务暂不支持向中国大陆推送手机验证码/通知短信。如果您项目的"数据处理位置"设置为"中国"且需要向中国大陆推送手机验证码/通知消息，请通过您的云函数或服务器接收验证码并发送短信。详情可参考[启用手机号码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-authentication-method-0000002417916829#section16830152153116)。  

   ```
   "Objective-C"
   AGCVerifyCodeSettings *setting = [[AGCVerifyCodeSettings alloc] initWithAction:AGCVerifyCodeActionRegisterLogin 
                                                                           locale:nil
                                                                     sendInterval:30]; 
   [[[AGCPhoneAuthProvider requestVerifyCodeWithCountryCode:countryCode phoneNumber:phoneNumber settings:setting] addOnSuccessCallback:^(AGCVerifyCodeResult * _Nullable result) {
       // 验证码申请成功
   }] addOnFailureCallback:^(NSError * _Nonnull error) {
        // 验证码申请失败
    }]
   ```

   ```
   "Swift"
   let setting = AGCVerifyCodeSettings.init(action:AGCVerifyCodeAction.registerLogin, locale:nil, sendInterval:30)
   AGCPhoneAuthProvider.requestVerifyCode(withCountryCode:countryCode, phoneNumber:phoneNumber, settings:setting).onSuccess{ (result) in
       // onSuccess
   }.onFailure{ (error) in
       // onFailure
   }
   ```

<!-- -->

2. 使用手机号码注册用户。 调用[\[AGCAuth createUserWithCountryCode:phoneNumber:password:verifyCode:\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346#section8448180111710)注册用户。注册成功后，系统会自动登录，无需再次调用登录接口。

   ```
   "Objective-C"
   [[[[AGCAuth getInstance] createUserWithCountryCode:countryCode phoneNumber:phoneNumber password:password verifyCode:verifyCode] addOnSuccessCallback:^(AGCSignInResult * _Nullable result) {
         // onSuccess
         AGCUser *user = result.user;
    }] addOnFailureCallback:^(NSError * _Nonnull error) {
        // onFail
    }];
   ```

   ```
   "Swift"
   AGCAuth.instance().createUser(withCountryCode:countryCode, phoneNumber:phoneNumber, password:password, verifyCode:verifyCode).onSuccess{ (result) in
       // onSuccess
   }.onFailure{ (error) in
       // onFailure
   }
   ```

3. 登录成功后可以调用[\[AGCAuth currentUser\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346#section5731134619333)获取用户账号数据。  

   ```
   "Objective-C"
   AGCUser *user = [[AGCAuth getInstance] currentUser];
   ```

   ```
   "Swift"
   let user = AGCAuth.instance().currentUser
   ```

#### 密码登录

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114607.54906542562782025445518589713920:50001231000000:2800:CE224E9C7292BAAE27447C89E1A0E7200A75C07B230E64223AD3B9AB6966DA93.png "点击放大")

1. 在应用的登录界面，初始化[AGCAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346)实例，获取AGC的用户信息，检查是否有已经登录的用户。如果有则可以直接进入用户界面，否则显示登录界面。  

   ```
   "Objective-C"
   AGCUser *user = [[AGCAuth getInstance] currentUser];
   ```

   ```
   "Swift"
   let user = AGCAuth.instance().currentUser
   ```

2. 调用[\[AGCPhoneAuthProvider credentialWithCountryCode:phoneNumber:password:\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcphoneauthprovider-ios-0000001054502404#section1258572810115)采用密码方式创建手机账号凭证。  

   ```
   "Objective-C"
   AGCAuthCredential *credential = [AGCPhoneAuthProvider credentialWithCountryCode:countryCode phoneNumber:phoneNumber password:password];
   ```

   ```
   "Swift"
   let credential = AGCPhoneAuthProvider.credential(withCountryCode:countryCode, phoneNumber:phoneNumber, password:password)
   ```

3. 获取credential成功后，调用[\[AGCAuth signIn:\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346#section488155612616)实现登录。  

   ```
   "Objective-C"
   [[[[AGCAuth getInstance] signIn:credential] addOnSuccessCallback:^(AGCSignInResult * _Nullable result) {
            // onSuccess
            AGCUser *user = result.user;
        }] addOnFailureCallback:^(NSError * _Nonnull error) {
            // onFail
        }];
   ```

   ```
   "Swift"
   AGCAuth.instance().signIn(credential:credential).onSuccess{ (result) in
       // onSuccess
   }.onFailure{ (error) in
       // onFailure
   }
   ```

#### 更多信息

* 您如果想让用户可以使用多个账号登录您的应用，可以将多个[账号进行关联](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-associated-0000001053053982)。
* 当用户不需要使用应用，或者需要切换其他账号登录认证，可以先执行[登出](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-sign-out-0000001053692708)。
* 当用户需要注销当前用户，可以进行[销户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-deleteuser-0000001057460873)。
* 对于销户、修改密码、关联账号以及重置手机账号和邮箱账号等敏感操作，为了提高安全性，需要用户必须在5分钟内登录过才能执行。如果用户执行敏感操作时登录超过5分钟，需要[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-reauthenticate-0000001127283387)后再执行敏感操作。
* 您可以参考[异常处理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-troubleshooting-0000001054715191)实现自己的异常处理机制，从而减少异常情况的发生。
* 您可以使用云函数触发器来接收用户注册、登录、销户等关键事件，从而[扩展认证服务的能力](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-extension-0000001053372708)。
* 您可以参考[管理用户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-user-manage-0000001606051705)对用户进行解锁、停用等操作。
