# 应用实验结果

如您已通过实验数据得出了实验结果，可选择数据指标更优的素材内容应用于全网用户。
> 注意
>
> 仅"素材天数据"统计页面支持应用实验结果。

* 您可以预览素材内容：点击某实验组"浏览"列的![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250102135805.84673593234042409427512506443633:50001231000000:2800:5C72F125D6A4F575FC4E157032818E29977AA09B3D004F1C77B418A11C26C62D.jpg?needInitFileName=true?needInitFileName=true)，可预览该实验组的素材内容。在预览页面可切换页签，预览当前版本和不同实验组的素材内容。

  ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250102135805.24377355735359778758193816538525:50001231000000:2800:D96BF0BB88DA02CC216F51519B7185633EE031272B2B4D56CD1B6BBA4F851558.png?needInitFileName=true?needInitFileName=true)


* 您可以应用实验结果。
  * 如您想使用某一实验组的素材内容：点击该实验组"操作"列的"应用"，弹窗显示当前实验组的素材内容，点击"确认"。实验组素材内容成功应用后，所有用户都将只能看到该实验组素材内容。

    ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250102135805.27164428321575114294367152728509:50001231000000:2800:37E1477395D39142F121CAB417BA47EEAFB969CF14ECFDBFAD02295DF7A93940.png?needInitFileName=true?needInitFileName=true)

    系统跳转到实验列表页面，本实验的"实验结果是否使用"显示为"是"。

    ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250102135805.04058814454385358874810003035296:50001231000000:2800:A7B1DA580A7EA4F062DDFAC21CFF059494AAC0AAEE9605DAA0F063BEBB77A7CA.png?needInitFileName=true?needInitFileName=true)


  * 如您仍然想保留应用当前使用的素材内容：点击当前版本"操作"列的"保留"，在提示弹窗点击"确认"，实验将直接结束。应用详情将还原为原始版本，且所有用户都将只能看到原始版本。

    ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250102135805.16611924764979219911478207928149:50001231000000:2800:9028BCDB58A62CE9F0D7AA21E15A1275F1FE1BC18AE61DC64D2876C4A16F0A69.png?needInitFileName=true?needInitFileName=true)

    系统跳转到实验列表页面，"实验结果是否使用"显示为"否"。
