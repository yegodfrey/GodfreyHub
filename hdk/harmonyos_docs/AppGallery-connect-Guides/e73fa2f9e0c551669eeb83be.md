# 查阅参数信息

例如了解库支持的版本信息，可通过使用函数[FrameFlow_GetCapabilitiesInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflow-getcapabilitiesinfo-0000001791494312)进行查询。此函数不需要事先创建实例。

```screen
FFResult FrameFlow_GetCapabilitiesInfo(FFCapabilitiesInfo* pCapsInfo);
```
