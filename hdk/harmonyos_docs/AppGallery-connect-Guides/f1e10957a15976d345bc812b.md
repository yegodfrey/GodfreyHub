# 管理商品促销信息

> 说明
>
> 调用PMS API前请确认已经完成[使用入门](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114)中的服务端授权。

您可以针对订阅类和非订阅类商品创建商品促销信息，定义促销的时间段，适用国家/地区，以及促销价格，请参见[创建商品促销信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-addpromotion-android-0000002171407021)接口，商品促销信息的更新请参见[更新商品促销信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-updatepromotion-android-0000002171288621)接口。

非订阅类商品只支持设置促销价，订阅类商品提供了两种促销手段：

* 促销价：设置一个优惠续期周期以及低于商品原价的促销优惠价，让用户在购买初期以低价享受一段时间的商品服务。
* 免费试用：设置一个免费时间段，让用户在购买初期免费享受一段时间的商品服务。

以创建商品促销信息为例，示例代码如下：

```screen
public static ProductPromotionCreateResp createProductPromotion(String domain, String clientId,
    String authorization, String appId, String developerId, ProductPromotionCreateReq request) {
    String url = domain + "/api/pms/product-price-service/v1/manage/product/promotion";
    HttpPost post = new HttpPost(url);
    post.setHeader("Authorization", "Bearer " + authorization);
    post.setHeader("client_id", clientId);
    post.setHeader("appId", appId);
    post.setHeader("developerId", developerId);
    StringEntity entity =
        new StringEntity(JSON.toJSONString(request), ContentType.create("application/json", "UTF-8"));
    post.setEntity(entity);
    try {
        CloseableHttpClient httpClient = HttpClients.createDefault();
        CloseableHttpResponse httpResponse = httpClient.execute(post);
        int statusCode = httpResponse.getStatusLine().getStatusCode();
        if (statusCode == HttpStatus.SC_OK) {
            BufferedReader br =
                new BufferedReader(new InputStreamReader(httpResponse.getEntity().getContent(), Consts.UTF_8));
            String result = br.readLine();
            ProductPromotionCreateResp resp = JSON.parseObject(result, ProductPromotionCreateResp.class);
            return resp;
        }
    } catch (Exception e) {
    }
    return new ProductPromotionCreateResp();
}
```

您可以调用[查询商品促销详情](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-getpromotioninfo-android-0000002135929328)接口根据promotionId和appId查询唯一的商品促销信息或者调用[按条件查询商品促销信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-bygetpromotioninfo-android-0000002136087416)接口根据筛选条件完成模糊查询。

商品促销信息在创建过程中指定了促销信息的状态，在促销信息创建成功后您可以调用[批量上线商品促销活动](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-batchactpromotion-android-0000002171407025)接口或者[批量下线商品促销活动](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-batchdeactpromotion-android-0000002171288629)接口更新促销的状态信息。
> 说明
>
> 批量接口每批最多支持100个，支持部分成功， 失败的会在响应中反馈错误信息。
