# 离开房间

进入房间后，不论是否已进入游戏中，房间内玩家均可离开房间。
> 说明
>
> 房间中所有玩家全部离开后，房间将会自动销毁。

## 前提条件

您已[加入房间](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-joinroom-roomid-android-0000001268934473)。

## 开发步骤

1. 调用[GameMediaEngine.leaveRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section1357253014212)方法离开房间。 说明
   > * 普通玩家离开房间时，参数ownerId传null或空字符串即可。
   > * 房主离开房间时，参数ownerId传null或空字符串，则表示随机指定新房主。

   ```screen
   mHwRtcEngine.leaveRoom(roomId, ownerId);
   ```

2. 当玩家离开房间时，可在IGameMMEEventHandler接口的[onLeaveRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section1011412113213)方法中实现相关回调处理。

   ```screen
   @Override
   public void onLeaveRoom(String roomId, int code, String msg) {
       // 离开房间数据处理
   }
   ```

   当玩家成功离开房间时，房间内其他玩家可在IGameMMEEventHandler接口的[onPlayerOffline](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section1870313495438)方法中收到该事件的回调通知，并可根据需求对数据进行处理。
   > 说明
   >
   > 当前仅支持小队语音和国战语音房间的玩家通过该回调方法收到某个玩家离开房间的通知。

   ```screen
   @Override
   public void onPlayerOffline(String roomId, String openId) {
      StringBuilder sb = new StringBuilder("onPlayerOffline : ")    
          .append("roomId=")    
          .append(roomId)    
          .append(", openId=")    
          .append(openId);
      LogUtil.d(TAG, sb.toString());
      // 可根据需求将数据进行处理
   }
   ```
