# 创建项目与应用

#### 创建项目

项目是您在AppGallery Connect（以下简称AGC）资源的组织实体，您可以将一个应用的不同平台版本添加到同一个项目中。如果您在使用AGC的服务时在AGC中还没有项目，则需要先创建项目，具体操作请参见[创建项目](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createproject-0000001100334664)。

<br />

#### 创建应用

如果您需要在华为应用市场发布您的应用，或者使用AGC提供的各类服务，则您需要先在AGC中创建应用。目前创建应用的方式可以直接创建应用，也可以在项目下添加应用，具体操作请参见[创建应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createapp-0000001146718717)。
