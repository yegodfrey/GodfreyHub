# 创建自定义连接器

## 创建自定义连接器

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击您的项目。
3. 在左侧导航栏选择"云开发（Serverless）> 云函数"，进入云函数主界面。
4. 选择"连接器"页签，点击"新建"。 说明
   >
   > 如果提示连接器已发布新版本，如下图所示，请先点击"升级"将连接器升级至最新版本后再创建连接器。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c4/v3/KqEFov4uSw2xi7ujEvpW1A/zh-cn_image_0000002269560790.png?HW-CC-KV=V1&HW-CC-Date=20261008T140709Z&HW-CC-Expire=31536000000&HW-CC-Sign=C2CD3A97798022490CED88BB4247C48D1C4335A1E4E0D0A539D913B33493200B "点击放大")
5. 在弹出的"创建连接器"框中，填写连接器信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/26/v3/IzxyvTYWQJOiXWVYzEGmoA/zh-cn_image_0000002574904012.png?HW-CC-KV=V1&HW-CC-Date=20261008T140709Z&HW-CC-Expire=31536000000&HW-CC-Sign=19346F7E54D69471286ACD10BF4266930A92A0B0BB508393826A038DF887C41F)

   |参数|说明|
   |:-|:------------------------------------------|
   |类型|选择"自定义连接器"。|
   |名称|连接器英文名称，为连接器唯一标识，支持字母、数字和下划线（_），长度不超过58个字符。|
   |描述|可选，连接器描述信息，长度不超过255个字符。|

6. 相关信息填写完成后，点击"开始创建"，连接器即创建完成。 创建成功后，即可继续[配置自定义连接器](#section094195744719)。

## 配置自定义连接器

使用连接器是通过调用连接器中的API方法实现的，故需要您在创建连接器之后添加连接器方法。目前支持域名代理和接口代理两种类型的API方法。

* 域名代理类型：提供访问域名下所有接口能力。
* 接口代理类型：提供调用第三方服务接口实现业务逻辑能力。

### 新建域名代理类型方法

1. 在连接器列表中，点击需要添加API方法的连接器"操作"列的"编辑"，进入连接器详情页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/34/v3/iNXHRxLFStSWeel6FwFEQQ/zh-cn_image_0000002304903057.png?HW-CC-KV=V1&HW-CC-Date=20261008T140709Z&HW-CC-Expire=31536000000&HW-CC-Sign=8DA1F4A12AFEDB5C1E29D0DE7E6ADD8FFB30331FD4611BB33EEB4869BB90D8ED)

2. 在"基本设置"页签的"连接器方法"区域，点击"立即新建"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/57/v3/V6ZrFDs0TCiv9R_8N3cKnw/zh-cn_image_0000002304829981.png?HW-CC-KV=V1&HW-CC-Date=20261008T140709Z&HW-CC-Expire=31536000000&HW-CC-Sign=E976F3D502C55E3B490097962494CCB9685BECA19A9F1AEE65187CFE04BB0DB7)

3. 在"连接器方法"区域，配置方法信息。 说明
   > * 如需添加多个方法，点击"添加方法"即可。
   > * 添加连接器方法后，如果后续修改了方法参数，默认生效时间为5分钟。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/56/v3/J_qE8uuiT9Sj2enH6iN3VQ/zh-cn_image_0000002260281742.png?HW-CC-KV=V1&HW-CC-Date=20261008T140709Z&HW-CC-Expire=31536000000&HW-CC-Sign=52366F04F6123F952CD6EF6FAC5FC84CCA41CF255B925172A8E90BDD3CF4D96D)

   |参数名称|说明|
   |:---|:-------------------------------|
   |名称|方法名称。调用方法时会用到此参数。|
   |描述|方法描述。例如说明下此方法的功能。|
   |类型|选择"域名代理"。|
   |域名|需访问的域名。仅支持配置httpRequest类型的服务器域名。|

4. 配置信息填写完成后，点击页面右上角的"保存"。
5. 在弹出的提示框中，点击"确认"完成方法添加。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c4/v3/xiUY5oMAQb60SU_vnoQgQw/zh-cn_image_0000002272476753.png?HW-CC-KV=V1&HW-CC-Date=20261008T140709Z&HW-CC-Expire=31536000000&HW-CC-Sign=29335F591E32897B9BA2B1A38E075B726B1827347CD169B63615D98F7FFA307B)

### 新建接口代理类型方法

1. 在连接器列表中，点击需要添加API方法的连接器"操作"列的"编辑"，进入连接器详情页面。
2. 在"基本设置"页签的"连接器方法"区域，点击"立即新建"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ab/v3/cnRBkgz3SYuS6RVyG-JNyg/zh-cn_image_0000002237543382.png?HW-CC-KV=V1&HW-CC-Date=20261008T140709Z&HW-CC-Expire=31536000000&HW-CC-Sign=8EC55D10C70F26877CBD0EA6D0C49A678424999CC7E00153F9F91D0B2D3FFCA6)

3. 在"连接器方法"区域，配置方法信息。 说明
   > * 如需添加多个方法，点击"添加方法"即可。
   > * 添加连接器方法后，如果后续修改了方法参数，默认生效时间为5分钟。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a1/v3/aiWErCXRRN2hqnl-nATp0Q/zh-cn_image_0000002237706130.png?HW-CC-KV=V1&HW-CC-Date=20261008T140709Z&HW-CC-Expire=31536000000&HW-CC-Sign=8123497D80ECB275AB356096DBA5121BCADBE2A6AFC1A10ED15FFB7F5EA8CB67)

   |参数名称|说明|
   |:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |名称|方法名称。调用方法时会用到此参数。|
   |描述|方法描述。例如说明下此方法的功能。|
   |类型|选择"接口代理"。|
   |URL|第三方服务接口的URL地址，须以"http://"或"https://"开头。|
   |Method|* GET：获取数据，在查询数据的场景中选择此方法。 * POST：新增数据，在新增数据的场景中选择此方法。 * PUT：更新数据，在更新数据的场景中选择此方法。 * DELETE：删除数据，在需要删除数据的场景中选择此方法。|
   |入参|可选，用于描述方法Params的结构。 若方法无参数，则不填写；若方法有参数，则点击"添加入参"，在右侧弹出框中设置入参的字段标题、字段名称、数据类型等信息。 > 说明 > 当前入参数据类型支持文本、长文本、布尔值、整数、数组、对象、长整数和小数。|
   |HTTP配置|可选，配置HTTP请求底层的请求参数，可配置Query和Headers的value、Body参数。 > 说明 > * 如果调用接口需要进行Cookie的验证，可以将从登录接口获取的Session ID或者Cookie的信息配置在Headers中，从而实现HTTP会话保持机制。 > * 仅请求方法Method为POST、PUT和DELETE时可配置Body参数。 > * Body中填写的内容会作为一个完整的字符串模板进行处理，应保证模板处理后的结果符合Body类型（JSON/Form）的要求，否则请求会失败。|
   |出参|函数的返回结果。点击"添加出参"，可配置调用此方法时返回的信息。|

4. 配置信息填写完成后，点击页面右上角的"保存"。
5. 在弹出的提示框中，点击"确认"完成方法添加。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9b/v3/YhPMAb9STeiuliBRi778vQ/zh-cn_image_0000002272628665.png?HW-CC-KV=V1&HW-CC-Date=20261008T140709Z&HW-CC-Expire=31536000000&HW-CC-Sign=7659595DDC932DE75A762C1F3C037B5BC26AD78226ABCE33C5FDE1D4481363E5)
