# 获取指定房间信息

进入语音房间后，您可通过获取全部房间信息，实现房间信息页面展示功能。如需实现定时刷新房间信息功能，可自行通过轮询调用接口实现。

## 前提条件

玩家已[加入](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-joinroom-roomid-csharp-0000001226738398)房间。

## 开发步骤

如果是HarmonyOS NEXT平台，调用[GameMediaEngine.GetRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-csharp-0000001231889118#section12589344534)方法可以获取指定房间的信息。

```screen
// 使用roomId获取指定房间的信息
engine.GetRoom(roomId, new OpenHarmonyJSCallback(args => {
    OpenHarmonyJSObject data = args[0];
    string roomInfo = data.Get<string>("data");
    // 处理业务逻辑
}));
```

其他平台则调用[GameMediaEngine.GetRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-csharp-0000001231889118#section12589344534)方法可以获取指定房间的信息。

```screen
engine.GetRoom(roomId) // 使用roomId获取指定房间的信息
```
