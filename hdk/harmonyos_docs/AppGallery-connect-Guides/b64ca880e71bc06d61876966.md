# 管理设备

当您成功申请到调试设备后，您可在"我的信息"页签下查看或释放您的调试设备。

## 前提条件

在进行设备管理的相关操作时，必须先成功[申请调试设备](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddebug-debugequip-0000001122212029)。

## 操作步骤

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击需要测试的项目。
3. 点击"质量 > 云调试"。
4. 点击"我的信息"页签，您可以在设备列表中看到您申请的调试设备机型、调试开始时间、调试总时长以及剩余调试时间。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/75/v3/6Gd5uGDZQkGT0JGoW7FDmQ/zh-cn_image_0000001543361397.png?HW-CC-KV=V1&HW-CC-Date=20261008T160022Z&HW-CC-Expire=31536000000&HW-CC-Sign=82863F9ACEE878FFAD1C986C944342B5E79C75EF604E35C2AF8015FB1F2EB924 "点击放大")

5. （可选）您可点击对应设备操作栏下的"![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8b/v3/IJ_RzaRWTweigbYN4wFDNA/zh-cn_image_0000001077622426.png?HW-CC-KV=V1&HW-CC-Date=20261008T160022Z&HW-CC-Expire=31536000000&HW-CC-Sign=08236141ECAFDED6AABBF736FA253FCFEBB245432BCA66464B5C00C09EB8C21B)"或"![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8c/v3/HZuf8z5NTfKgmnM22b8X-w/zh-cn_image_0000001077622436.png?HW-CC-KV=V1&HW-CC-Date=20261008T160022Z&HW-CC-Expire=31536000000&HW-CC-Sign=703574DBED3FC899835CB01687B3AB21A2D2E5BB6244D8B66B99DB751658FBDE)"，释放该设备或是进入该设备的调试界面。
