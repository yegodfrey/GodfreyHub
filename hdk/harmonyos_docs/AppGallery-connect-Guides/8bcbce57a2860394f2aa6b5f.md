# 使用云缓存

## 获取云缓存信息

在使用云缓存之前，您需要先获取云缓存的域名、端口、用户名和密码，以便后续在应用中连接云缓存后使用云缓存。

1. 获取用户名、域名和端口。
   1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
   2. 在项目列表中选择您的项目。
   3. 在左侧导航栏选择"云开发（Serverless） > 云缓存"，点击"管理"页签。

      复制"用户名"、"内网地址"。
      * 用户名：用于客户端访问云缓存时的用户名。
      * 内网地址：agcp-drcn.hispace.dbankcloud.cn即为域名，16380为端口，用于在生产环境中[使用云缓存](#section118031216118)。

      ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704163201.74156444199594974871993430561845:50001231000000:2800:199F7B11CCF941E6D245D40A424904968593E71D11A01C1E7C9F35B2FD073C4B.png)

2. 获取密码。

   密码为开通云缓存时设置的密码。如果忘记密码，可以[重置访问密码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudcache-configure-0000001367208633#section18626153133319)（重置的密码最长需要30分钟后才能生效）。 注意
   >
   > 如果已经有其他业务使用云缓存，重置密码将导致这些业务无法使用云缓存，请修改业务中的密码并重新部署。

## 使用云缓存

您可以根据使用的开发语言，选择不同方式连接云缓存后，参考[Redis文档](https://github.com/redis/ioredis)使用云缓存。

### Node.js

在需要使用云缓存的地方参考如下代码，即可连接云缓存。

```screen
 const Redis = require('ioredis');
 const redisClient = new Redis({
     port: Number(16380),
     host: 'agcp-drcn.hispace.dbankcloud.cn',
     username: 'TODO:填写当前使用的项目ID',
     password: 'TODO:填写为设置的云缓存密码',
     enableReadyCheck: false,});

 let myHandler = async function(event, context, callback, logger) {
     let res = new context.HTTPResponse({"simple": "example"}, {
         "res-type": "simple example",
         "faas-content-type": "json"
     }, "application/json", "200");
     let ret = await redisClient.get('name');
     logger.info("redis get name result:" + ret);

     //send response
     callback(res);
 };

 module.exports.myHandler = myHandler;
```

### Java

提供了三种方式，可根据业务情况选择合适的方式：

* [方式一](#ZH-CN_TOPIC_0000001485525416__p16276124912475)：使用原生的jedis客户端连接云缓存。
* [方式二](#ZH-CN_TOPIC_0000001485525416__p131976468508)：使用Spring封装的RedisTemplate能力。
* [方式三](#ZH-CN_TOPIC_0000001485525416__p159471258125610)：对于Spring Boot工程，可以不显式的创建RedisTemplate对象，通过@Autowired 注入相关配置信息。

【方式一】

1. 在pom文件中添加依赖。

   ```screen
   <dependency>
   	<groupId>redis.clients</groupId>
   	<artifactId>jedis</artifactId>
       <!-- 建议选择3.8.0及以上版本 -->
   	<version>3.8.0</version>
   </dependency>
   ```

2. 在需要使用云缓存的地方参考如下代码，即可连接云缓存。

   ```screen
   private static final JedisPool JEDIS_POOL = getRedisPool();

   private static JedisPool getRedisPool() {
       // 云缓存的域名
       String redisHost = "agcp-drcn.hispace.dbankcloud.cn";
       // 云缓存的端口号
       int redisPort = 16380;
       // 云缓存链接和读写超时时间
       int timeout = 3000;
       // 云缓存的用户名
       String redisUser = "填写当前用户名";
       // 设置的云缓存密码
       String redisPwd = "填写设置的云缓存密码";
       JedisPoolConfig jedisPoolConfig = new JedisPoolConfig();
       // 当资源池连接用尽后，客户端最大等待时间
       jedisPoolConfig.setMaxWait(Duration.ofSeconds(5));
       // jedisPoolConfig其他参数保持默认值即可
       return new JedisPool(jedisPoolConfig, redisHost, redisPort, timeout, redisUser, redisPwd);
   }

   public void cloudRedis() {
       try (Jedis jedis = JEDIS_POOL.getResource()) {
           String ret = jedis.get("name");
           log.info("redis get name result:" + ret);
       }
   }
   ```

【方式二】

1. 在pom文件中添加依赖。

   ```screen
   <dependency>
       <groupId>org.springframework.data</groupId>
       <artifactId>spring-data-redis</artifactId>
       <version>2.7.1</version>
   </dependency>
   <dependency>
       <groupId>org.springframework</groupId>
       <artifactId>spring-core</artifactId>
       <version>5.3.23</version>
   </dependency>
   ```

2. 在需要使用云缓存的地方参考如下代码，即可连接云缓存。

   ```screen
   private static StringRedisTemplate redisTemplate = getRedisClient();

   private static StringRedisTemplate getRedisClient() {
       // 云缓存的域名
       String redisHost = "agcp-drcn.hispace.dbankcloud.cn";
       // 云缓存的端口号
       int redisPort = 16380;
       // 云缓存链接和读写超时时间
       int timeout = 3000;
       // 云缓存的用户名
       String redisUser = "填写当前用户名";
       // 设置的云缓存密码
       String redisPwd = "填写设置的云缓存密码";
       RedisStandaloneConfiguration standaloneConfig = new RedisStandaloneConfiguration(redisHost, redisPort);
       standaloneConfig.setPassword(RedisPassword.of(redisPwd));
       standaloneConfig.setUsername(redisUser);
       JedisClientConfiguration clientConfig = JedisClientConfiguration.builder()
           .readTimeout(Duration.ofMillis(timeout))
           .connectTimeout(Duration.ofMillis(timeout))
           .usePooling()
           .build();
       JedisConnectionFactory connectionFactory = new JedisConnectionFactory(standaloneConfig, clientConfig);
       connectionFactory.afterPropertiesSet();

       StringRedisTemplate redis = new StringRedisTemplate();
       redis.setConnectionFactory(connectionFactory);
       redis.afterPropertiesSet();

       return redis;
   }

   public void cloudRedis() {
       String ret = redisTemplate.opsForValue().get("name");
       log.info("redis get name result:" + ret);
   }
   ```

【方式三】

1. 在配置文件application.properties增加redis相关配置信息。

   ```screen
   # 云缓存的用户名
   spring.redis.username=填写当前用户名
   # 云缓存密码
   spring.redis.password=填写设置的云缓存密码
   # 云缓存的域名
   spring.redis.host=agcp-drcn.hispace.dbankcloud.cn
   # 云缓存的端口号
   spring.redis.port=16380
   # 连接超时时间 单位 ms（毫秒）
   spring.redis.timeout=3000
   # 连接池可以分配的最大连接数。（负值表示无限制）
   spring.redis.lettuce.pool.max-active=4
   # 连接池资源耗尽时，连接尝试分配阻塞时间，超时即抛出异常。（负值表示无限期阻塞）
   spring.redis.lettuce.pool.max-wait=-1
   # 连接池可以分配的最大连接数。(负值表示无限制）
   spring.redis.lettuce.pool.max-idle=5
   # 连接池最小空闲连接数
   spring.redis.lettuce.pool.min-idle=0
   ```

2. 在需要使用云缓存的地方参考如下代码。

   ```screen
   @Autowired
   StringRedisTemplate stringRedisTemplate;

   public void cloudRedis() {
       String ret = stringRedisTemplate.opsForValue().get("name");
       log.info("redis get name result:" + ret);
   }
   ```
