# 使用限制

## 设备限制

设备限制是指SDK对用户终端的限制。

|限制项|限制|
|:-----------|:-----------------------------------------------------------|
|设备品牌|支持所有品牌设备。|
|Android OS|Android 4.4及以上（API Level 19及以上）|
|iOS OS|iOS 8及以上|
|Web浏览器|* Chrome浏览器 * Firefox浏览器 * 华为浏览器 * Safari浏览器 * UC浏览器 * QQ浏览器|
|EMUI（针对华为手机）|无限制。|
|HMS Core APK|无限制。|
|应用市场客户端|无限制。|

## 特性依赖

特性依赖是指对其他华为业务的依赖。

|特性|依赖的业务|
|:-----------|:----------------------------------------------------------------------------------------------------------------------------|
|远程开启/关闭APM服务|[远程配置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-remoteconfig-introduction-0000001055149778)|
