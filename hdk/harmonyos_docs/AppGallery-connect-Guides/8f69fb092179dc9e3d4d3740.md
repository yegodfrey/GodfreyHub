# （可选）集成NDK

如果您的应用使用了原生库（比如.so库），您需要集成崩溃NDK。  

#### Version Catalog方式管理依赖

#### 声明NDK

打开Android Studio项目级gradle目录下的"libs.versions.toml"文件，声明NDK。

1. 在\[versions\]中声明崩溃NDK版本号。

   ```
   [versions]
   agcVersion = "1.9.6.300"
   ```

2. 在\[libraries\]中声明崩溃NDK。

   ```
   [libraries]
   agconnect-crash-native = { module = "com.huawei.agconnect:agconnect-crash-native", version.ref = "agcVersion" }
   ```

#### 使用NDK

在应用级的"build.gradle"文件的"dependencies"中添加AppGallery Connect崩溃服务的NDK编译依赖。

```
dependencies {      
     implementation libs.agconnect.crash.native   
}
```

#### 非Version Catalog方式管理依赖

在应用级 gradle 文件中（通常在 app/build.gradle）添加如下Crash NDK的编译依赖配置：

```
dependencies {
    //添加Crash NDK编译依赖
    implementation 'com.huawei.agconnect:agconnect-crash-native:1.9.6.300'
}
```

![](https://media:201779440885910699)  
您可以通过配置应用支持的so库架构来减小app的大小，当前支持x86，armeabi-v7a，x86_64，arm64-v8a四种架构。

```
android {
    defaultConfig {
         ndk {
              // 设置支持的SO库架构。当前支持x86、armeabi-v7a、x86_64、arm64-v8a，此处以armeabi-v7a为例。
              abiFilters 'armeabi-v7a' 
         }   
    }
}
```
