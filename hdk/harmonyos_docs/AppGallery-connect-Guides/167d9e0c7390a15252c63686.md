# 创建并配置函数

## 创建函数

开通云函数服务后，您首先需要在AGC中创建函数，并添加函数执行的代码。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击需要创建云函数的项目。
3. 在左侧导航栏选择"云开发（Serverless）> 云函数"，进入云函数主界面。
4. 选择"函数"页签，点击"创建函数"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9/v3/L906_hqpSlWbwkCd2r4geg/zh-cn_image_0000001978134481.png?HW-CC-KV=V1&HW-CC-Date=20261008T174417Z&HW-CC-Expire=31536000000&HW-CC-Sign=04D3EF8886BE0686AAF6CC0F384DB1CF94EE8A26B4C240062DF81DD88DB15E71)

5. 页面右侧抽屉式滑出"创建函数"窗口，按照"函数配置 -> 触发器 -> 函数代码 -> 层配置"引导顺序配置函数。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0a/v3/AyY2FcUrQC6pc2B8irT1yA/zh-cn_image_0000001978059125.png?HW-CC-KV=V1&HW-CC-Date=20261008T174417Z&HW-CC-Expire=31536000000&HW-CC-Sign=D9434D4D6DBD09A5F5F9368323CFA25F977274F8C79AE8A5AC8B4243C28BD355)

## 函数配置

1. 在"函数配置"页面，配置"函数名称"、"触发方式"、"超时时长"等函数信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c4/v3/92-cZfQjTMOETIpvRoy05g/zh-cn_image_0000001755850905.png?HW-CC-KV=V1&HW-CC-Date=20261008T174417Z&HW-CC-Expire=31536000000&HW-CC-Sign=C30A7BC6DC41BF7DAAFC5D55ABF2D6D3087E4BB6A1D454FE025F9F97A9C0C999)

   |配置项|**说明**|
   |:---|:--------------------------------------------------------------------------------------------------------|
   |函数名称|函数的名称。|
   |描述|函数的描述信息。|
   |触发方式|**请配置为"事件调用"。** "事件调用"表示通过触发器方式调用函数。|
   |超时时长|函数最大运行时长，超过该时长，则默认函数执行失败，单位为秒，取值范围为1~1800。 > 说明 > * "同步"调用方式时，函数最大运行时长为55秒。 > * "异步"调用方式时，函数最大运行时长为1800秒。|
   |实例并发|函数请求并发量上限，单位为个，取值范围为1~10000。|
   |环境变量|key-value形式，您可以将需要的变量配置信息传入函数执行环境中，用于函数在运行时读取和使用。|

2. （可选）您可根据需要添加环境变量，支持**表单格式** 和**JSON格式** 两种编辑方式。添加完成后，您还可以点击"JSON格式导出"，导出以"函数名称.json"格式命名的环境变量文件，以备后续使用。 说明
   > * 环境变量的key值具有唯一性，且"PROJECT_CREDENTIAL"和"AGC_"为系统级环境变量标识，不允许添加以其命名或以其为前缀的环境变量。
   > * 环境变量总数不超过1000个。
   * 表单格式编辑 点击"新增变量"，输入key和value值，如下图中所示，env1为环境变量的key值，test为value值。点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/08/v3/sn-avwjMQQG3422Er5rGww/zh-cn_image_0000001713575273.png?HW-CC-KV=V1&HW-CC-Date=20261008T174417Z&HW-CC-Expire=31536000000&HW-CC-Sign=3B9940E8021BC9EFE5B173379B83C8F817F5873BF7672A0787EDCC74A0EB190D)可将变量删除。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/74/v3/MwuK-DJDT0GlNPY0KCjyUw/zh-cn_image_0000001724123061.png?HW-CC-KV=V1&HW-CC-Date=20261008T174417Z&HW-CC-Expire=31536000000&HW-CC-Sign=4856C30F7231A1A3A2EBF24B4D9671557936E9076515BE434233C6F8C629E41F)
   * JSON格式编辑 选中"JSON格式编辑"，在文本框中以key-value键值对JSON格式添加环境变量。当添加的环境变量比较多时，为了方便核对，可点击"format"对变量进行格式化排列。

3. "函数配置"页面配置完成后点击"下一步"。

## 触发器

创建函数过程中，您可基于函数触发场景配置需要的触发器，下文将介绍添加几种Serverless触发器的方法，您只需创建其中一种Serverless触发器即可。若后续触发器配置有变化，您可在函数创建完成后在函数详情页的"触发器"页签新增或者删除触发器。触发器的详细介绍，请参见[触发器管理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/trigger-introduction-0000001706837165)。
> 说明
>
> * 因业务调整需要，后续对于新增函数将不再支持创建API网关触发器。
> * 创建云数据库、云存储触发器之前，请确保您已经开通对应的服务。服务开通方法请参见[开通云数据库服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/serverless-create--preparations-0000001712008649#section20955131214292) | [开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/serverless-create--preparations-0000001712008649#section624722314438)。

### 创建云数据库触发器

1. 进入"触发器"页面，"触发器类型"选择"云数据库触发器"，并配置"事件源"、"事件类型"和是否"启用"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/25/v3/iO4hShdjQmGnwZxuSbNC8A/zh-cn_image_0000001815458121.png?HW-CC-KV=V1&HW-CC-Date=20261008T174417Z&HW-CC-Expire=31536000000&HW-CC-Sign=28E1621C008BE85FCD8B8586693FBFD55AAA0DFEC6C6BCFE1F8F9641E8B8D588)

   |参数|说明|
   |:----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |触发器类型|云数据库触发器。|
   |事件源|云数据库触发器的数据源。选择您在云数据库服务中创建的存储区名称和对象类型名称。 格式为：项目ID-CloudDB存储区名称-CloudDB对象类型名称，例如**"** 99034201568569469-StorageArea-student**"**。 CloudDB存储区名称以字母开头，可选范围为[0-9A-Za-z]，不带下划线，长度为1~20个字符。CloudDB对象类型名称以字母开头，可选范围为[0-9A-Za-z_]，不允许以sqlite_开头，不允许以下划线结尾，长度为1~30个字符。|
   |事件类型|触发器支持的事件类型。 * onUpsert：数据表插入或更新数据。 * onDelete：数据表删除数据。 * onDeleteAll：清空数据表。 * onWrite：数据插入或更新事件、数据删除事件、数据表清空事件。|
   |启用|是否启用该触发器，标识触发器的状态。默认为启用，可设置。|

2. 触发器配置完成后点击"下一步"。

> 注意
>
> 触发器调用云函数功能暂不支持云数据库云侧API批量插入（[executeUpsert](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-transaction-0000001080698454#section11772593429)）/批量删除（[executeDelete](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-transaction-0000001080698454#section13162538184210)）以及[导入数据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-agcconsole-managingdata-0000001080975864#section6547202316247)场景。

### 创建认证服务触发器

1. 进入"触发器"页面，"触发器类型"选择"认证服务触发器"，并配置"事件类型"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/54/v3/RQzeNLqATX-1DHqp1VNFmA/zh-cn_image_0000001768608074.png?HW-CC-KV=V1&HW-CC-Date=20261008T174417Z&HW-CC-Expire=31536000000&HW-CC-Sign=A9948F44581857093E9F33772770EB1524BDF00B4DEA89988AE014C0E096212C)

   |参数|说明|

   |触发器类型|认证服务触发器。|
   |事件类型|触发器支持的事件类型。 * 用户注册事件。 * 用户销户事件。 * 用户登录事件。 * 用户登出事件。 > 说明 > * 同一个事件，一个函数只能绑定一次。 > * 一个函数可以被认证服务的多个事件类型触发，一个认证服务的事件类型可以触发多个函数执行。|

2. 触发器配置完成后点击"下一步"。

### 创建云存储触发器

1. 进入"触发器"页面，"触发器类型"选择"云存储触发器"，并配置"存储实例"和"事件名称"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/91/v3/-4jamSqlTBig91BOXJx00g/zh-cn_image_0000001768605938.png?HW-CC-KV=V1&HW-CC-Date=20261008T174417Z&HW-CC-Expire=31536000000&HW-CC-Sign=028AD26562C33770923B1403F3A5305C7DD7ED65FE2AD67DC6280869146E5631)

   |触发器类型|远程配置触发器。|

2. 触发器配置完成后点击"下一步"。

## 层配置

层可以为您提供公共依赖库的发布与部署能力。您可以将函数依赖的公共库和相关依赖项提炼到层，通过为函数绑定层，便可以在函数中使用库，而不必将库包含在函数的代码包中，从而达到缩小函数代码包体积与缩短函数部署时间的效果，也避免了使用函数代码安装和打包依赖项时可能出现的错误。详细的层管理功能，请参见[层管理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloud-function-layer-0000001517762624)。

如果您尚未创建层，可跳过下述步骤，直接点击页面底部的"创建"完成函数定义，后续创建层之后可在函数详情页再进行层配置，为函数绑定层。如果您在创建函数之前已创建层，可按照下述步骤进行操作。

1. 进入"层配置"页面，点击"绑定层"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6d/v3/mP1tzGPlRkGSfhesSNGj6A/zh-cn_image_0000001755876669.png?HW-CC-KV=V1&HW-CC-Date=20261008T174417Z&HW-CC-Expire=31536000000&HW-CC-Sign=C32736E11974B55644820B90FEB430618EC514764454CD44111FD4770120FAED)

2. 在右侧弹出的"绑定层"界面中，下拉框选择"层名称"和"版本"，"层范围"等信息根据层的配置将被自动填充，完成层绑定后点击"确定"。一个函数最多可以绑定5个层。 说明
   >
   > 选择层时，层的兼容运行时需与函数运行环境相符，系统会自动完成过滤。若无匹配的层供您选择，请参考[创建层](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloud-function-layer-0000001517762624#section11358162018572)创建相同运行环境的层后再进行绑定。
