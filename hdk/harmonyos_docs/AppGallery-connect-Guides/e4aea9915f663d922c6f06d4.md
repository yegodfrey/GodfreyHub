# 上传文件

您可以通过云存储服务快速地上传本地设备上的文件到云端。  

#### 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[初始化存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-initialize-bucket-quickapp-0000001281453000)。  

#### 操作步骤

1. 调用[StorageManagement.storageReference](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagemanagement-0000001055096686#section012312924313)创建需上传文件的引用，传入文件在云端预先规划的文件地址。

   ```
   var storageReference = storage.storageReference();
   var reference = storageReference.child('images/demo.jpg');
   ```

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240821163242.43385082068082479870639017574075:50001231000000:2800:6397F2ACB0126A69EC4DC7DDCC1BE5CA8C2D70C3DBE9E0F38BEAF111D1FCDB42.png?needInitFileName=true?needInitFileName=true)  
   上传文件或创建目录时，会对名称和文件大小进行严格的检查，具体限制请参见[使用限制](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-restrictions-0000001093263535#section1759375325210)。
2. 调用[StorageReference.put4QuickApp](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagereference-0000001055216725#section8580355133317)方法将文件上传到存储实例中。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240821163242.30480934624594169621306961943300:50001231000000:2800:D9BE7BF588EF9F515C1D35AE73A5BC6DDDA1470F11226CA3BD96CDCF99A279DD.png?needInitFileName=true?needInitFileName=true)  
   上传文件前支持您设置文件的自定义属性，具体参见[元数据管理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-metadata-quickapp-0000001071965502)。

   ```
   var fileMetadata = reference.put4QuickApp(uri); // uri为本地文件资源uri标识
   ```

如果您需要在上传文件时为文件指定自定义属性，可以使用[StorageReference.put4QuickApp(uri : String, , attribute ?: UploadMetadata)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagereference-0000001055216725#section8580355133317)方法中的UploadMetadata属性。  

#### 更多信息

* 如您在上传文件前未设置文件的自定义属性，可在文件成功上传后进行[设置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-metadata-quickapp-0000001071965502#section164594142514)。
* 文件成功上传到云端后，您可以通过云存储SDK[获取文件的下载地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-download-quickapp-0000001071925361)。
* 您可以通过云存储SDK的API[列举云端某个目录下的所有文件或子目录](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-list-quickapp-0000001072005417)。
* 当您不再需要云端的文件时，可以调用云存储SDK的API在应用客户端[删除文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-delete-quickapp-0000001072333611)。
* 除了在应用客户端通过云存储SDK的API来上传文件，您还可以直接[在AGC控制台以可视化的方式来上传文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-manage-file-0000001281134398#section6704135012516)。
