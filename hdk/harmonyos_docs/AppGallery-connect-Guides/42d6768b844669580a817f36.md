# 分析崩溃问题

在发生崩溃后，崩溃服务会将崩溃数据上报到AGC，您可以在AGC中查看崩溃问题的详细信息，分析崩溃发生的原因。本章节以测试崩溃时制造的崩溃为例，介绍崩溃问题的基本定位方法。

## 前提条件

您需要已制造崩溃并上报过崩溃数据，详情请参见[测试崩溃实现](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-test-0000001055420516)。

## 崩溃问题总览

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中点击您的应用。
3. 点击"质量 > 崩溃"，进入崩溃服务页面。
4. 点击"崩溃类型"页签。
   * 您可以通过"添加筛选条件"过滤器和右上角的时间选择器过滤崩溃数据，查看崩溃问题排名前5位的系统版本、手机型号和应用版本的分布情况。
     * 点击"添加筛选条件"，选择"系统版本"、"手机型号"或"应用版本"，下方图表将展示对应维度的详细崩溃数据及分布情况。
     * 您可以点击图表中的"崩溃次数"、"崩溃率"、"崩溃用户数"或"用户总数"，帮助您从不同维度分析崩溃的信息分布情况。
     * 页面右上角的时间选择器可选择预定时间段（例如，最近24小时）或输入自定义范围，界面默认的时间段为最近一个月。
