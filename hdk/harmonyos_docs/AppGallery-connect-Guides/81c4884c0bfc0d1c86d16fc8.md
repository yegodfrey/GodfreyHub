# Android

调用相关接口需要先完成初始化，初始化是通过创建实例来实现的。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250424164754.74167468744132496200697157106376:50001231000000:2800:02FFDAE8F9C03C739FF76FA6C9DEB1BED43ECC0CEEBA44F5A66115A758864738.png)  
游戏多媒体服务语音相关功能需使用麦克风访问权限，因此，您需要动态申请设备的录音权限，具体可参见[如何动态申请测试设备权限](https://developer.huawei.com/consumer/cn/forum/topic/0201104692369675378?fid=0101271690375130218)。  

#### 前提条件

* 您已[开通游戏多媒体服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-enable-0000001327201553)。
* 您已[集成游戏多媒体SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-integratingsdk-android-0000001250838246)。  

#### 创建实例

在实现游戏多媒体相关功能前，需先完成游戏多媒体实例的创建。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250424164754.88100340155064271107155831686431:50001231000000:2800:F2B25629A5276734AF6786AFEE0D160D40B790968CA5E67F1BAA8A960A098CFE.png)  
游戏启动后，仅需要维护一个实例即可。

1. 调用[EngineCreateParams](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-model-enginecreateparams-android-0000001193243734)的相关方法构造游戏多媒体实例参数。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250424164754.56340845751798756598972105595354:50001231000000:2800:2F6636D2E6A922BF02833637368DCAC8788EC556DA6A17D0696DE4EF89F63FC8.png)  
   * 为了提升服务的安全性，初始化SDK时，您还可以通过在您的服务器中计算出签名的方式进行安全加固，增强数据防篡改能力，具体请参见[使用签名初始化SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-signature-android-0000001227593524)。如果您已[开启安全加固](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-console-servicemanagement-0000001255134391#section92517364165)，则必须使用签名初始化SDK。
   * 鉴权时传入"clientSecret"和"cpAccessToken"其一即可。基于游戏信息安全考虑，当您有自己的游戏服务器时，推荐您使用cpAccessToken。如果同时传入，将使用传入的"cpAccessToken"作为最终AGC接入凭证。"cpAccessToken"主要是通过在您的服务器中编写一段调用获取Token接口的代码进行获取，具体请参见[获取Token（项目级）](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/obtaintoken-0000001550601918)。
   * 如果您使用的是1.7.2.301（不含）版本之前的游戏多媒体SDK，为防止SDK误删除该目录下的相关证书，建议您不要将logPath设置为应用缓存目录。

   ```
   EngineCreateParams params = new EngineCreateParams();
   params.setOpenId(openId);               // 玩家ID
   params.setContext(context);             // 应用的上下文
   params.setLogEnable(true);              // 开启SDK日志记录
   params.setLogLevel(4);                  // 日志级别
   params.setLogFileCount(10);             // 日志文件数量
   params.setLogPath(logPath);             // 日志路径
   params.setLogSize(1024 * 10);           // 日志存储大小
   params.setCountryCode(countryCode);     // 国家码，用于网关路由，不设置默认CN
   params.setAgcAppId(agcAppId);           // 游戏应用在AGC上注册的APP ID,具体获取请参见准备游戏信息
   params.setClientId(clientId);           // 客户端ID,具体获取请参见准备游戏信息
   params.setClientSecret(clientSecret);   // 客户端ID对应的密钥,具体获取请参见准备游戏信息
   params.setCpAccessToken(cpAccessToken); // AGC接入凭证（推荐）
   params.setApiKey(apiKey);               // API密钥（凭据）,仅实现语音转文本功能时需要,具体获取请参见准备游戏信息
   ```

2. 调用[GameMediaEngine.create](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section168115185491)方法创建游戏多媒体实例。

   ```
   protected GameMediaEngine mHwRtcEngine;
   private IGameMMEEventHandler eventHandler = new IGameMMEEventHandler();
   ...
   mHwRtcEngine = GameMediaEngine.create(params, eventHandler);
   ```

3. 当创建实例完成后，可在IGameMMEEventHandler接口的[onCreate](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section34206581277)方法中查看结果并实现回调处理。

   ```
   @Override
   public void onCreate(int code, String msg) {
       LogUtil.d(TAG, "onCreate : code=" + code + ", msg=" + msg);
       // 创建实例完成后的数据处理
   }
   ```

#### 销毁实例

如需退出游戏应用，建议先完成实例销毁，减少内存资源的占用。

1. 调用[GameMediaEngine.destroy](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section133755208521)方法销毁游戏多媒体实例。

   ```
   GameMediaEngine.destroy();
   ```

2. 当销毁实例完成后，可在IGameMMEEventHandler接口的[onDestroy](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section19918174522919)方法查看结果并实现回调处理。

   ```
   @Override
   public void onDestroy(int code, String message) {
       LogUtil.d(TAG, "onDestroy : msg=" + message);
       // 销毁实例完成后的数据处理
   }
   ```
