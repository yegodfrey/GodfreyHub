# 通过控制台测试

> 说明
>
> 下文以函数latest版本为例介绍测试方法。若您需要测试函数的已发布版本，可在已发布版本详情页面选择"函数代码"页签，参考方式二进行测试。

函数创建后您可以在AGC控制台测试函数的代码运行是否正常。进入测试界面有两种方式：

* 方式一：函数列表中点击函数名称右侧"操作"列的"测试"，在右侧弹出的"测试函数"界面进行测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8a/v3/3qxVHCKdT86mog8CG6gvyw/zh-cn_image_0000001978548797.png?HW-CC-KV=V1&HW-CC-Date=20261008T143941Z&HW-CC-Expire=31536000000&HW-CC-Sign=C0F1E7BD645DBC5D4E65084041F3881F13BEA25A3D0622B5C959F806D392B63E)

* 方式二：
  1. 在函数列表中点击已创建的函数名称，进入函数详情页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/99/v3/PwOA30-9R2yYve6oLq2OZg/zh-cn_image_0000001948908550.png?HW-CC-KV=V1&HW-CC-Date=20261008T143941Z&HW-CC-Expire=31536000000&HW-CC-Sign=ED7DCF74E0D94FFA170A8184B55C6DA7DFBD2891BBA8F37642B1FB4F8621717A)

  2. 选择"函数代码"页签，点击"测试函数"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1f/v3/1sg31QhFRzut5DFu1K7frw/zh-cn_image_0000001800662133.png?HW-CC-KV=V1&HW-CC-Date=20261008T143941Z&HW-CC-Expire=31536000000&HW-CC-Sign=5CB1AA99F5213114F1699D02DA088010791EC75AA070C950D6959E508B76A75A)

  3. 在右侧弹出的"测试函数"界面，使用默认测试事件、创建新测试事件或者使用已保存测试事件进行测试。
     * 使用默认测试事件 直接点击"测试"对函数进行测试。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bd/v3/TwVUP1XCRD-lr1e-T8v86g/zh-cn_image_0000001722152221.png?HW-CC-KV=V1&HW-CC-Date=20261008T143941Z&HW-CC-Expire=31536000000&HW-CC-Sign=9B44731F922468B7C61F20C61A7FD0BA28F0290B64E7E52DFDE20CB43A20903C)
     * 创建新测试事件 如果需要设置调用函数的请求消息体，可按照如下步骤配置测试参数，并可保存为测试事件方便后续继续使用。

       1. 在"事件"文本框中输入JSON格式的事件参数，点击"保存"。然后在"提示"弹出框中输入事件名称，配置完成后点击弹出框右下角的"确认"。 说明
          >
          > "事件"文本框内输入的JSON对象，对应的是触发器的event事件格式，会透传给函数。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/68/v3/bynEyHzDQWitSwnv87WBGA/zh-cn_image_0000001756189981.png?HW-CC-KV=V1&HW-CC-Date=20261008T143941Z&HW-CC-Expire=31536000000&HW-CC-Sign=787235B5DCB88BABA359C4AFD245CFF79E66FCE62E5A43D1407AD5E816043722)
       2. 点击"测试"，函数处理事件并返回测试结果。
     * 使用已保存测试事件
       1. 在"测试函数"界面，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/85/v3/PHNkdRCSSLKxGJR2ICkb9Q/zh-cn_image_0000001722236597.png?HW-CC-KV=V1&HW-CC-Date=20261008T143941Z&HW-CC-Expire=31536000000&HW-CC-Sign=1F535F30BF101687E678FBF6F146D232BF2D0036DAC33E300359DCBA87E957C5)展开已保存的测试事件列表，选择已配置的事件名称右侧的"加载"，然后点击"测试"，函数处理事件并返回测试结果。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bd/v3/gt_Og_1nSmSxllutoi4aqw/zh-cn_image_0000001722453985.png?HW-CC-KV=V1&HW-CC-Date=20261008T143941Z&HW-CC-Expire=31536000000&HW-CC-Sign=838FA57883A653941CFDCBEA28FB9D9EF95A04E72ABB4EBE082D4A5E4F252045)
       2. （可选）若您需要删除已添加的测试事件，可在测试事件列表中点击事件名称右侧的"删除"即可删除测试事件。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fd/v3/peD_PUFCS2uXgBtWcnBrqA/zh-cn_image_0000001722158501.png?HW-CC-KV=V1&HW-CC-Date=20261008T143941Z&HW-CC-Expire=31536000000&HW-CC-Sign=B7720838D8354F30DE1245A5B3CF23D34DF3947B2FD9D74D335B4F5F1D39CC28)

  4. 查看测试结果。
     * 执行结果：展示测试后获得的响应结果。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e9/v3/Bvo4wJLhS9-gwXETRRzE1w/zh-cn_image_0000001674184734.png?HW-CC-KV=V1&HW-CC-Date=20261008T143941Z&HW-CC-Expire=31536000000&HW-CC-Sign=545DD98FA8B5B6C4F60DB888A52FBBC43FE27D725049CFE82EF83A100266EF9F)

     * 运行日志：展示函数运行过程中，通过logger API打印的日志，支持输出debug级别及以上日志（以下仅为日志输出示例）。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/20/v3/uXmzI0f5T5umocrOyfJHBg/zh-cn_image_0000001674190046.png?HW-CC-KV=V1&HW-CC-Date=20261008T143941Z&HW-CC-Expire=31536000000&HW-CC-Sign=42CD5FB569E0B0343CA064A72B09F480AE7CCDCF3EFC4CF52743844178811D72)

     * 执行摘要：展示该次测试请求相关信息。
       * 请求ID：该条测试请求的RequestID，在后台日志中体现为X-Trace-ID。
       * 持续时间：函数执行的端到端时间。
       * 执行版本：该次调用测试的具体函数版本。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f6/v3/J2ECgwo4THGWsF3yay_7Yg/zh-cn_image_0000001674344770.png?HW-CC-KV=V1&HW-CC-Date=20261008T143941Z&HW-CC-Expire=31536000000&HW-CC-Sign=798FE7059347038A8D233F37C8A3E4113B04DB3796853B32F0CFA5A56AFE01BD)
  5. "代码输入类型"为"在线编辑"的函数，测试过程中，若您需要修改函数入口文件代码，可直接在"函数代码"页签的代码编辑器中修改，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/93/v3/B6cPxSdVQ26EAM579W5y2w/zh-cn_image_0000001753703418.png?HW-CC-KV=V1&HW-CC-Date=20261008T143941Z&HW-CC-Expire=31536000000&HW-CC-Sign=CDCC6C81CB48F95A571746C69642EEA4086A19DA6E5E962202777BA72B5D5129)

     "代码输入类型"为".zip文件"的函数，测试过程中，若您需要修改函数代码文件，可在本地修改且打包完成后，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/48/v3/DN8ogp8JTfihyHJuxc9RdA/zh-cn_image_0000001717161230.png?HW-CC-KV=V1&HW-CC-Date=20261008T143941Z&HW-CC-Expire=31536000000&HW-CC-Sign=C543EBD0744EDE9C4955F6F1011E96F91CC45B4FAEB62B554DEC30BA60F5AC70)重新上传函数部署包，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。
     > 说明
     >
     > 若代码更新量比较大，需要调整函数内存配置，可点击"内存配置"下拉框进行调整，然后再上传函数部署包。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4f/v3/k37Kd4MKTD2--yDKUiLoQA/zh-cn_image_0000002433940774.png?HW-CC-KV=V1&HW-CC-Date=20261008T143941Z&HW-CC-Expire=31536000000&HW-CC-Sign=581A6924DDD677F38D321D3A0A5B8F91B3E665FEF4B63DA2158FA951F6C0406B)
  6. 函数测试无误后，您可在"函数代码"页签点击"导出函数"导出函数部署包。导出包以"函数名称+函数版本.zip"格式命名，可查看函数结构和文件内容。
