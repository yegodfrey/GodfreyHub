# 配置iOS应用信息

1. 在"开发与服务"页面中，点击iOS应用所在项目。
2. 在"项目设置"页面选择"常规"页签。
3. 在"应用"区域，点击![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107115604.06705774257798786026146904422850:50001231000000:2800:4497DCEC9515CD627A8559002EA9E4992E4FACB7820EE977851F4E7278587389.png "点击放大")配置"App Store ID"和"团队ID"，即您应用在App Store上的ID和团队ID，完成后点击![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107115604.27987396877935108293985914540407:50001231000000:2800:AC6582A79C4178AC2655F30FA94EEA24ACBE57765CD08531DDE79E1FBBA36B9B.png "点击放大")保存。
