# 初始化SDK

调用游戏性能管理SDK的接口前，必须初始化SDK。  

#### 前提条件

* 已[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-integration-android-0000002022406709)。
* 已[获取游戏信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-get-authentication-infomation-0000001801791669#section20509644364)"Client ID"、"Client Secret"和"APP ID"信息。  

#### 开发步骤

1. 新建[GPMInitParams](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-android-api-gpminitparams-0000002022408201)对象并传入初始化参数。

   ```
   GPMInitParams initParams = new GPMInitParams();
   initParams.setContext(context);                           // 应用的上下文
   initParams.setAppId(appId);                               // 游戏APP ID
   initParams.setClientId(clientId);                         // 客户端Client ID
   initParams.setClientSecret(clientSecret);                 // 客户端密钥Client Secret
   initParams.setAccessToken(accessToken);                   // AGC接入凭证（推荐）
   initParams.setLogLevel(3);                                // 日志级别
   initParams.setUserIdentity(userIdentity);                 // 三方账号OpenID
   initParams.setCallback(callback);                         // 回调实现类
   ```

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110239.74669040384960824818732436510167:50001231000000:2800:4FCD70BFDB44D9368D1F2774563F1126DAE4458B5D930B48BEEC451D7A2F1C2F.png)  
   ClientSecret和AccessToken二者传其一即可。基于安全考虑，推荐使用AccessToken。若同时传入，将使用传入的AccessToken作为最终AGC接入凭证。AccessToken获取方法请参见[获取Token（项目级）](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-obtain-project-token-0000001801864849)。
2. 调用[GPMManager.init](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-android-api-gpmmanager-0000002022527745#section1155613935519)方法，初始化游戏性能管理SDK。

   ```
   GPMCallback callback = new GPMCallbackImpl();   // GPMCallback接口的实现类需要自行实现
   GPMInitParams initParams = new GPMInitParams();
   iniparams.setCallback(callback);
   ...
   GPMManager.init(initParams);
   ```

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110239.56340507372184311017808334803437:50001231000000:2800:9B87635CEF0BF6CBB9C00C1443510E222BBFCE7275F24AF9178FE24511DC8CB2.png)  
   请在UI主线程中调用该方法进行初始化。
3. 初始化结果将在子线程中通过GPMCallback接口的[onInitResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-android-api-gpmcallback-0000001988789820#section17111102111920)方法中查看并实现回调处理。

   ```
   @Override
   public void onInitResult(int code, String msg)
   {
       // GPMManager.init接口通过子线程回调通知初始化结果。由于大部分API需要在主线程中调用，请在onInitResult回调中合理处理。
       if(code == GPMError.GPM_SUCCESS) 
       {
          // 初始化成功
       }
   }
   ```
