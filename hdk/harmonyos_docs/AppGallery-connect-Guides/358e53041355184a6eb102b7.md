# 使用限制

您可以通过本章节了解云数据库当前存在的限制，我们后续将会尽可能减少使用云数据库的限制。

## 免费配额

开通云数据库服务时，系统默认为您提供如下配额的免费云数据库服务。

|服务类别|配额|
|:---------|:-------|
|数据存储空间|1GB|
|最大并发连接数|150|
|数据库每秒最大操作数|10|
|读操作次数|每天50000次|
|写操作次数|每天20000次|
|删除操作次数|每天20000次|
|网络流量|10GB/月|

## 指标限制

如下是适用于云数据库用量的指标限制。

### 数据库、对象类型和对象

|限制|最大值|
|:------------|:-----------------------------|
|单应用数据容量|1TB|
|单应用在云侧创建存储区数|4|
|单应用在端侧创建存储区数|4|
|单应用中对象类型数|128|
|单对象类型的字段数|128 **说明：**最大支持100个String类型字段。|
|单应用云侧连接数|200000|
|单应用云侧数据库每秒操作数|3000|
|一个对象的数据大小|2MB|

> 说明
>
> 建议所有客户端每秒的下载流量大小不超过1GB。

### 数据查询、写入、删除和事务

|限制|最大值|
|:----------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|一个应用在云侧每秒最大写入数据大小|10MB|
|端侧每次查询云侧数据，返回结果集的大小|5MB|
|端侧每次查询云侧数据，查询结果中包含的数据条数|1000|
|一个对象的数据大小|2MB|
|批量写入时，列表中包含的数据总条数|1000|
|批量写入时，列表中每个对象的数据大小|2MB **说明：** * 开发Android、iOS和HarmonyOS(Java)应用时，仅在"数据同步属性"为"缓存模式"且"数据持久化属性"为"非持久化"时，列表中所有对象的数据总大小不能超过2MB。 * 使用Web应用、快应用、快游戏、小程序、小游戏和HarmonyOS(ArkTS API 9及以上)应用时，批量写入多个对象时，多个对象总大小不能超过2MB。|
|批量删除时，列表中包含的数据总条数|1000|
|批量删除时，列表中每个对象的数据大小|2MB **说明：** * 开发Android、iOS和HarmonyOS(Java)应用时，仅在"数据同步属性"为"缓存模式"且"数据持久化属性"为"非持久化"时，列表中所有对象的数据总大小不能超过2MB。 * 开发Web应用、快应用、快游戏、小程序、小游戏、HarmonyOS(ArkTS API 9及以上)应用时，批量删除多个对象时，多个对象的总大小不能超过2MB。|
|一个事务中多次查询结果的总数据大小|5MB **说明：**快游戏不支持事务。|
|一个事务中多次查询结果的总数据条数|1000 **说明：**快游戏不支持事务。|
|一个事务中多次写入操作和删除操作的数据总大小|2MB **说明：**快游戏不支持事务。|
|一个事务中包含的写入和删除对象的总条数|1000 **说明：**快游戏不支持事务。|

|一个对象的数据大小|2MB|
|每次写入操作包含的数据总条数|1000|
|每次写入操作包含的字段名和字段值的总大小|20MB|
|每次删除操作包含的字段名和字段值的总大小|20MB|
|每次删除操作包含的数据总条数|1000|
|一个事务中查询、写入和删除操作包含的字段名和字段值的总大小|20MB|
|一个事务中多次查询结果的总数据条数|1000|
|一个事务中包含的写入和删除对象的总条数|1000|

### 数据侦听

|一个快照包含的数据总大小|5MB|
|一个快照包含的数据总条数|1000|

### 主键和索引

## 设备限制

设备限制是指SDK对用户终端的限制。

|限制项|限制|
|:-----------|:--------------------------------------------------------------------|
|设备品牌|支持所有品牌设备，CPU架构必须为ARM。|
|Android OS|Android 4.4及以上（API Level 19及以上）|
|iOS OS|1.0.6.300及以后版本：iOS 9及以上 1.0.4.300及以前版本：iOS 8及以上|
|Web浏览器|* Chrome * Edge * Firefox * 华为浏览器 * Safari * UC桌面浏览器 * QQ桌面浏览器 * IE11|
|EMUI（针对华为手机）|无限制|
|HMS Core APK|无限制|
|应用市场客户端|无限制|
