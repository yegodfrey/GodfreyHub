# 添加权限

在使用游戏高光时刻SDK相关模块能力前，您需要先在"AndroidManifest.xml"文件中申请如下权限。 说明
>
> 游戏高光时刻服务录制视频功能需使用读写存储、访问网络和录制音频权限，因此，您需要动态申请设备的读写存储、访问网络和录音权限，具体可参见[如何动态申请测试设备权限](https://developer.huawei.com/consumer/cn/forum/topic/0201104692369675378?fid=0101271690375130218)。

* 公共权限

  ```screen
  <!--读写存储（媒体和文件）权限-->
  <uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />
  <uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" />
  <!--访问网络权限-->
  <uses-permission android:name="android.permission.INTERNET" />
  ```

* 如果使用屏幕录制能力，除公共权限外，还需要添加以下权限：

  ```screen
  <!-- 录制音频权限 -->
  <uses-permission android:name="android.permission.RECORD_AUDIO" />
  ```

* 如果同时也使用模板能力，除公共权限和屏幕录制权限外，还需要添加以下权限：

  ```screen
  <!--侦听网络状态权限-->
  <uses-permission android:name="android.permission.CHANGE_NETWORK_STATE" />
  <!--查看网络状态权限-->
  <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
  <!--查看手机状态权限-->
  <uses-permission android:name="android.permission.READ_PHONE_STATE" />
  ```
