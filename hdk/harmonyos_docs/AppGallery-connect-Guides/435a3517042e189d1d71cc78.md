# React Native使用入门

![](https://media:201779675966303624)  
AGC React Native插件仅适用于Android和iOS平台。

AppGallery Connect（简称AGC）从构建、质量、增长、华为云方面给开发者提供了多个开发服务，一个AGC服务的基本开发流程如下：

1. [准备开发环境](#section10125185719117)
2. [创建项目和应用](#section113292017144)
3. [设置数据处理位置](#section53891849102012)
4. [集成AGC React Native插件](#section989922512418)
5. [开发应用](#section820114550411)

#### 准备开发环境

* React Native开发环境准备和项目创建，请参见[开始使用React Native](https://reactnative.dev/docs/getting-started)。
* Android开发环境准备，请参见[Android开发环境准备](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-started-android-0000001058210705#section1270317123213)。
* iOS开发环境准备，请参见[iOS开发环境准备](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-started-ios-0000001058442274#section1491511413717)。  

#### 创建项目和应用

1. 项目是您在AGC资源的组织实体，您可以将一个应用的不同平台版本添加到同一个项目中。如果您在使用AGC的服务时在AGC中还没有项目，则需要先创建项目，具体操作请参见[创建项目](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createproject-0000001100334664)。
2. 如果您还没有在您的AGC项目中添加应用，请先完成应用的添加。您可以直接添加一个新应用，也可以添加一个未归属任何项目的已有应用。请参见[创建应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createapp-0000001146718717)。  

#### 设置数据处理位置

部分AGC服务涉及应用数据的处理，在使用此类服务前，您需要设置保存数据的站点，具体操作请参见[设置数据处理位置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-data-storage-location-0000001162597847)。  

#### 集成AGC React Native插件

当前仅部分AGC服务提供了React Native插件，在使用此类服务前需要将AGC React Native插件集成到您的开发环境，涉及的服务如下：

* 认证服务
* 崩溃服务
* 远程配置服务
* App Linking
* 应用内消息
* 云函数
* 云数据库
* 云存储  

#### 添加配置文件

AGC为了简化开发者的配置步骤，向开发者提供了保存应用配置信息的配置文件，您只需要将配置文件添加到您的工程目录并集成AGC插件，AGC插件可以自动将您在AGC上的应用信息加载到您的开发环境。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择您的应用。 ![](https://media:201779675966337625)

3. 在"项目设置"页面下载配置文件。
   * Android：下载配置文件"agconnect-services.json"
   * iOS：下载配置文件"agconnect-services.plist"

   ![](https://media:201779675966365626)  
   配置文件中默认会包含AGC为应用分配的客户端密钥和API密钥信息，如果您的套餐升级到了付费档，为避免被冒用产生异常账单，建议您将密钥存储在您自己的服务器，并妥善保管。你可以在配置信息前打开"不包含密钥"开关，配置文件中将不包含密钥信息，由您自行调用AGC插件提供的接口手动配置，Android平台请参见[设置配置文件参数](#section11573122918500)，iOS平台请参考原生平台的[设置配置文件参数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-started-ios-0000001058442274#section7775132744813)。

   ![](https://media:201779675966396627)
4. 在React Native项目中添加配置文件。
   * Android：将配置文件"agconnect-services.json"添加到React Native项目的android/app目录下。
* iOS：在Xcode中打开React Native项目的iOS模块，将配置文件"agconnect-services.plist"添加入项目即可。  

#### 添加Android Gradle配置

添加配置文件后，需要在React Native项目的Android模块中配置maven仓地址和AppGallery Connect插件地址。

1. 配置maven仓地址和AGC插件地址。
   1. 打开React Native工程android文件夹下的build.gradle文件。
   2. 在allprojects -\>repositories里面配置maven仓地址。

      ```
      allprojects { 
                  repositories { 
                      google() 
                      jcenter() 
                      // Add the following line:
                      maven {url 'https://developer.huawei.com/repo/'} 
                  } 
              }
      ```

   3. 在buildscript-\>repositories中配置maven仓地址。

      ```
      buildscript { 
                  repositories { 
                      google() 
                      jcenter() 
                      // Add the following line:
                      maven {url 'https://developer.huawei.com/repo/'} 
                  } 
       }
      ```

   4. 在buildscript-\>dependencies中配置AppGallery Connect插件地址。以下版本号仅为示例，请以实际版本号为准。

      ```
      buildscript { 
                  dependencies { 
                   // Add the following line:
                   classpath 'com.huawei.agconnect:agcp:1.9.6.300'
                  } 
      }
      ```

2. 添加AGC插件地址。
   1. 打开React Native工程android/app文件夹下的build.gradle文件。
   2. 在apply plugin: 'com.android.application'下一行添加如下配置。

      ```
      apply plugin: 'com.huawei.agconnect'
      ```

#### 安装插件

1. 在项目工程目录下，使用如下命令安装对应服务的插件，以崩溃服务为例。

   ```
   npm install @react-native-agconnect/crash@1.3.0
   ```

   |服务|配置方法|
   |:----------|:-------------------------------------------------------|
   |远程配置|npm install @react-native-agconnect/remoteconfig@1.3.0|
   |崩溃服务|npm install @react-native-agconnect/crash@1.3.0|
   |认证服务|npm install @react-native-agconnect/auth@1.3.0|
   |App Linking|npm install @react-native-agconnect/applinking@1.3.0|
   |应用内消息|npm install @react-native-agconnect/appmessaging@1.3.0|
   |云函数|npm install @react-native-agconnect/cloudfunctions@1.3.0|
   |云数据库|npm install @react-native-agconnect/clouddb@1.0.0|
   |云存储|npm install @react-native-agconnect/storage@1.5.0|

   ![](https://media:201779675966420628)  
   以上版本号仅为示例，请以实际版本号为准。不加版本号表示最新版本，如果想要安装指定的版本，在服务后面增加@x.x.x 。

<!-- -->

2. （可选）React Native在0.60及以上版本支持autolinking，在0.60版本以下，需要执行手动link操作，以崩溃服务为例。

   ```
   react-native link @react-native-agconnect/crash
   ```

<!-- -->

3. 由于iOS使用CocoaPods来管理项目依赖，您需要进入ios目录，运行：

   ```
   pod install
   ```

<!-- -->

4. iOS初始化AGC SDK： 在项目的AppDelegate.m文件中导入头文件\<AGConnectCore/AGConnectCore.h\> ，在application:(UIApplication \*)application didFinishLaunchingWithOptions:(NSDictionary \*)launchOptions 的方法中添加如下代码：

   Objective-C：

   ```
   - (BOOL)application:(UIApplication *)application didFinishLaunchingWithOptions: (NSDictionary *)launchOptions {
       // Override point for customization after Application launch.
       [AGCInstance startUp];  //初始化
       return YES;
   }
   ```

至此，您已经可以在React Native项目中使用AGC的服务了。  

#### 设置配置文件参数（仅对Android平台适用）

AGC提供了@react-native-agconnect/core插件来对agconnect-services.json文件中的参数进行配置，如果您在下载配置文件时选择了"不包含密钥"，则agconnect-services.json文件中将不包含client_id、client_secret和api_key参数，您必须通过core SDK的接口在应用启动时将参数设置给AGC SDK。

1. 使用如下命令安装@react-native-agconnect/core插件。

   ```
   npm install @react-native-agconnect/core@1.3.0
   ```

2. 设置client_id、client_secret和api_key参数。  
   ![](https://media:201779675966453629)  
   建议您在App.js方法中调用。

   ```
   AGCApp.getInstance().setClientId('clientId');
   AGCApp.getInstance().setClientSecret('clientSecret');
   AGCApp.getInstance().setApiKey('apiKey');
   ```

   <br />

   各参数的值可在"项目设置 \> 常规"页面中查询，clientId替换为"Client ID"的值，clientSecret替换为"Client 密钥"的值，"apikey"替换为"API密钥（凭据）"的值，可点击参数后面的![](https://media:201779675966482630)复制参数值。

![](https://media:201779675966510631)
