# 登出

## 前提条件

* 您需要在AGC控制台[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyos-integration-sdk-0000001327194257)。

## 开发步骤

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251226181006.63758747269625274727313911074746:50001231000000:2800:CB15BEDBB694FCA348874F880352976E26145C78B1086AAE2B9852B420A9A5D1.png "点击放大")

当用户不再使用应用，或者需要使用其他账号登录时，需要调用[AGConnectAuth.signOut](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-agconnectauth-0000001151371572#section1445773192310)登出当前用户。用户一旦被登出，端侧的用户信息和Token将被清除。

```screen
"Java"
AGConnectAuth.getInstance().signOut();
```
