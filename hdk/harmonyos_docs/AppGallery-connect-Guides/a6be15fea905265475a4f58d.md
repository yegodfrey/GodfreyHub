# 异常处理

在某些情况下，程序无法按预想的情况正常执行，而是会发生异常。您可以实现自己的异常处理方案，给用户带来更友好体验。

## 处理异常

处理接口异常时，您可以在接口返回的Task中设置addOnFailureCallback回调来获取到请求失败的相关信息。在addOnFailureCallback中您需要判断该方式回调的异常对象是否是一个AGCAuthError实例对象，然后您可以根据返回的错误码定制实现您自己的异常处理场景。

```screen
"Objective-C"
[[[[AGCAuth getInstance] signIn:credential] addOnSuccessCallback:^(AGCSignInResult * _Nullable result) {
         // onSuccess
         AGCUser *user = result.user;
     }] addOnFailureCallback:^(NSError * _Nonnull error) {
         // onFail
     }];
```

```screen
"Swift"
AGCAuth.instance().signIn(credential: credential).onSuccess{ (result) in
    // onSuccess
}.onFailure{ (error) in
    // onFailure
}
```

## 203817986错误码特殊处理说明

用户登录成功后，认证服务SDK会保存当前用户的Access Token和Refresh Token。

* Access Token：用户的访问令牌，表明用户的唯一身份，涉及到用户级别的操作，都需要验证Access Token。
* Refresh Token：刷新用户的Access Token，由认证服务SDK自动刷新。

Access Token有效期为1小时，Refresh Token为2个月。用户如果连续2个月没有登录操作，在调用涉及用户级别的接口时，Refresh Token失效，会抛出203817986错误码。

您应该在代码中显式捕获该错误码，提示用户重新登录。
