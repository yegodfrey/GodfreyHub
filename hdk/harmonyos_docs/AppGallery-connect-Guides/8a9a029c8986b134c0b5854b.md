# 通过控制台测试

> 说明
>
> 下文以函数latest版本为例介绍测试方法。若您需要测试函数的已发布版本，可在已发布版本详情页面选择"函数代码"页签，参考方式二进行测试。

函数创建后您可以在AGC控制台测试函数的代码运行是否正常。进入测试界面有两种方式：

* 方式一：函数列表中点击函数名称右侧"操作"列的"测试"，在右侧弹出的"测试函数"界面进行测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c5/v3/KVXNiMwxS6-i-QqFiB_fzA/zh-cn_image_0000001978548797.png?HW-CC-KV=V1&HW-CC-Date=20261008T162629Z&HW-CC-Expire=31536000000&HW-CC-Sign=CEDD81F86E2ACD0CAC32C189038A0B25CEBD89C50CECEEF41044677DB3EA7742)

* 方式二：
  1. 在函数列表中点击已创建的函数名称，进入函数详情页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f6/v3/ae-NoSt4QASPxQqAwPZW0Q/zh-cn_image_0000001948908550.png?HW-CC-KV=V1&HW-CC-Date=20261008T162629Z&HW-CC-Expire=31536000000&HW-CC-Sign=6B538C105EC8908F2D8FD75DA7FD8766C1B1E18BBDA09BD9EA708B50CC9D7381)

  2. 选择"函数代码"页签，点击"测试函数"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d7/v3/Fj_jHzfxTHCUfQuCCvfYRQ/zh-cn_image_0000001800662133.png?HW-CC-KV=V1&HW-CC-Date=20261008T162629Z&HW-CC-Expire=31536000000&HW-CC-Sign=DDD68B45AB1B7C1F61C82763E29F648C6D60337C498D0D9DC06BB983CEBFA5CC)

  3. 在右侧弹出的"测试函数"界面，使用默认测试事件、创建新测试事件或者使用已保存测试事件进行测试。
     * 使用默认测试事件 直接点击"测试"对函数进行测试。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/64/v3/TvVIJ8QqSR-Ni8baEJ7ACg/zh-cn_image_0000001722152221.png?HW-CC-KV=V1&HW-CC-Date=20261008T162629Z&HW-CC-Expire=31536000000&HW-CC-Sign=49539FF9FFA208B2E01A5A47282BC6F6344F4E3E09DBBB15C1A96FADCBCEE2AC)
     * 创建新测试事件 如果需要设置调用函数的请求消息体，可按照如下步骤配置测试参数，并可保存为测试事件方便后续继续使用。

       1. 在"事件"文本框中输入JSON格式的事件参数，点击"保存"。然后在"提示"弹出框中输入事件名称，配置完成后点击弹出框右下角的"确认"。 说明
          >
          > "事件"文本框内输入的JSON对象，对应的是触发器的event事件格式，会透传给函数。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/55/v3/Ou6LArSGREG5bTyC07Iygg/zh-cn_image_0000001756189981.png?HW-CC-KV=V1&HW-CC-Date=20261008T162629Z&HW-CC-Expire=31536000000&HW-CC-Sign=69BC62DDE7438E2704952F71F5F1DCE2E69DDEC842B4FAC169B2AD4B6B684982)
       2. 点击"测试"，函数处理事件并返回测试结果。
     * 使用已保存测试事件
       1. 在"测试函数"界面，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a8/v3/YttRVdAFS0mEG3lHO9g1vA/zh-cn_image_0000001722236597.png?HW-CC-KV=V1&HW-CC-Date=20261008T162629Z&HW-CC-Expire=31536000000&HW-CC-Sign=AAD21F5B561551437256D619C33854C1B723371C3CD7E41EE5C92C8B47F896A1)展开已保存的测试事件列表，选择已配置的事件名称右侧的"加载"，然后点击"测试"，函数处理事件并返回测试结果。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/47/v3/L4Cq4MtQTmaBQ8GZiKAx3A/zh-cn_image_0000001722453985.png?HW-CC-KV=V1&HW-CC-Date=20261008T162629Z&HW-CC-Expire=31536000000&HW-CC-Sign=C57181B102B432E1D5C75875455E147151457C45B6C84AA2528888680B6BAABF)
       2. （可选）若您需要删除已添加的测试事件，可在测试事件列表中点击事件名称右侧的"删除"即可删除测试事件。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2e/v3/5Tu6ON7WQ-66dmFirRwpIw/zh-cn_image_0000001722158501.png?HW-CC-KV=V1&HW-CC-Date=20261008T162629Z&HW-CC-Expire=31536000000&HW-CC-Sign=72C7ECF5B5DA371DA2C80782AC15BAC41F862A1AAC89A0C19E22CA3851D16838)

  4. 查看测试结果。
     * 执行结果：展示测试后获得的响应结果。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ab/v3/bGQE3N-fRTSwVIwufzAB5g/zh-cn_image_0000001674184734.png?HW-CC-KV=V1&HW-CC-Date=20261008T162629Z&HW-CC-Expire=31536000000&HW-CC-Sign=92A0CA4792E37E9E2E647BB6ED976E3D64A3A74366369FC35917557DDF127BBB)

     * 运行日志：展示函数运行过程中，通过logger API打印的日志，支持输出debug级别及以上日志（以下仅为日志输出示例）。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ea/v3/OqMnDax-TkOHKrVcm-7mfA/zh-cn_image_0000001674190046.png?HW-CC-KV=V1&HW-CC-Date=20261008T162629Z&HW-CC-Expire=31536000000&HW-CC-Sign=F3449F953A30746FBC593E8CAF6ABF865A0471B0499E4EC01AFA38866F021CFB)

     * 执行摘要：展示该次测试请求相关信息。
       * 请求ID：该条测试请求的RequestID，在后台日志中体现为X-Trace-ID。
       * 持续时间：函数执行的端到端时间。
       * 执行版本：该次调用测试的具体函数版本。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/76/v3/66HvgbMsQRihdwxu7PIzDQ/zh-cn_image_0000001674344770.png?HW-CC-KV=V1&HW-CC-Date=20261008T162629Z&HW-CC-Expire=31536000000&HW-CC-Sign=0034015AF6BC7601D41F3802B2E07FD1FF7898A1134157278604C0EE408CFBEB)
  5. "代码输入类型"为"在线编辑"的函数，测试过程中，若您需要修改函数入口文件代码，可直接在"函数代码"页签的代码编辑器中修改，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/62/v3/ih9_nsZKQxaw2txJSB2iWg/zh-cn_image_0000001753703418.png?HW-CC-KV=V1&HW-CC-Date=20261008T162629Z&HW-CC-Expire=31536000000&HW-CC-Sign=7B8A45F8A5763F063BFA675C48967BB747F1D5393661F24C2CC33F1B172D4458)

     "代码输入类型"为".zip文件"的函数，测试过程中，若您需要修改函数代码文件，可在本地修改且打包完成后，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/80/v3/4k-HQon9R3iqQWdTFQlJzw/zh-cn_image_0000001717161230.png?HW-CC-KV=V1&HW-CC-Date=20261008T162629Z&HW-CC-Expire=31536000000&HW-CC-Sign=35FE6C5AFC69D1217EA78BFB3D03B66AD25FB265317BB768F9CE9331B5F1FEDF)重新上传函数部署包，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。
     > 说明
     >
     > 若代码更新量比较大，需要调整函数内存配置，可点击"内存配置"下拉框进行调整，然后再上传函数部署包。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/01/v3/XJX1BY4uRqmv_mI8yBmL6g/zh-cn_image_0000002433940774.png?HW-CC-KV=V1&HW-CC-Date=20261008T162629Z&HW-CC-Expire=31536000000&HW-CC-Sign=DFE6AC15BA457CABBB9ECA3427207773155E067B4F80AC51FC527C70BB8FCF19)
  6. 函数测试无误后，您可在"函数代码"页签点击"导出函数"导出函数部署包。导出包以"函数名称+函数版本.zip"格式命名，可查看函数结构和文件内容。
