# 初始化Dynamic Ability SDK

#### 前提条件

您已[集成Dynamic Ability SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-dynamicability-getstarted-0000001058442220#section8112131171115)。  

#### 初始化SDK

在集成Dynamic Ability SDK后需要在您的应用中添加初始化代码。

1. 在您的Android项目中配置您的Application，并重写其中的attachBaseContext()方法，调用[FeatureCompat.install](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/featurecompat-0000001057762241#section28252351218)初始化Dynamic Ability SDK。

   ```
   public class MyApplication extends Application {
       @Override
       protected void attachBaseContext(Context base) {
           super.attachBaseContext(base);
           // 启动Dynamic Ability SDK
           FeatureCompat.install(base);
       }
   }
   ```

<!-- -->

2. 在动态特性模块的Activity中，调用[FeatureCompat.install](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/featurecompat-0000001057762241#section28252351218)初始化Dynamic Ability SDK。

   ```
   @Override
   protected void attachBaseContext(Context newBase) {
   super.attachBaseContext(newBase);
       //在activity中初始化
       FeatureCompat.install(newBase);
   }
   ```
