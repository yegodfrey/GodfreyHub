# 认证服务

## 通用

### 认证服务与华为账号服务的区别和关系？

认证服务和华为账号服务关注的是开发者两个不同层面的诉求。

华为账号服务致力于华为账号的开放，可以让您的用户方便快捷地使用其华为账号登录您的应用和游戏。而认证服务则致力于帮助您快速地低成本构建一个安全可靠的用户认证系统。

两者并不冲突，认证服务支持与包括华为账号服务在内的多种第三方认证系统对接，支持您的用户采用包括华为账号在内的多种认证方式来登录您的应用和游戏。

无论您的应用和游戏是否已经集成了华为账号服务，或者是否打算集成华为账号服务，我们都推荐您使用认证服务来构建您的用户认证系统，这有助于减少您在用户认证系统构建和运维上的投入和成本。

## Android

### 匿名账号和华为账号是什么关系？

匿名账号和华为账号是两种不同的账号体系，匿名账号并不是华为账号的一种。

匿名账号和华为账号都可以使用AGC的认证服务进行绑定和管理。

### 接入匿名账号后如何验证此账号？

匿名账号无需开发者单独验证，AGC服务器会在每次调用匿名账号登录的时候验证匿名账号。目前匿名登录验证接口不对外开放。

### 接入认证服务报错：code: 403 message: client token authorization fail.如何处理？

1. 检查agconnect-services.json文件放置的目录是否准确。
2. 检查认证服务开关是否已在AGC的API管理页面中打开。
3. 检查认证服务中是否已启用应用所需要的账号系统。

### Program type already present: okio:Base64等okhttp冲突问题如何处理？

可能原因：

1. 某个本地的jar里面有okhttp。
2. 其他库用了okhttp，并且maven的坐标不是通用坐标。

处理方法：手动exclude okhttp。

### 如何判断当前账号是否关联了华为账号？

登录后认证服务SDK的API会返回getProviderInfo参数表示了是否已经关联，如果未关联，此参数为null。

### 如果当前认证服务中只绑定了一种账号，如何将该账号绑定到另一个认证服务的账号下？

由于当仅有一个身份验证提供方时不能进行取消关联，所以需要调用AGConnectAuth.deleteUser接口删除当前的认证服务账号后才能够进行重新绑定。

### 接口的失败回调为何是通用的Exception而非AGCAuthException?

接口返回的报错不一定为AGCAuthException类型，可能为通用Exception类型或其他AGCException子类。需要在处理时判断Exception类型。

### 微博认证服务报错：Code：203817989，message：failed to get third user info

请检查在微博创建的应用是否已经在微博审核通过。

### QQ认证服务报错：Code：203817989，message：failed to get third user info

请检查QQ管理台中Unionid获取权限是否已经开启。

### Twitter认证时，Twitter报错：Failed to get request token

需要在twitter认证设置模块中的回调url，网页url和服务条款与隐私声明中添加twittersdk://前缀。

## iOS

### 集成iOS的SDK在Archive时报bitcode bundle could not be generated because '/XXX/AGConnectAuth.framework/' was built without full bitcode. 错误如何处理？

1.0.0.300版本不支持bitcode，需要开发者在工程配置中设置Enable Bitcode为No，后续版本会支持Bitcode。

## 快游戏

### 集成快游戏SDK时，出现错误"code":10001,"msg":"agc network request error"，该如何解决？

使用开发工具（如VSCode）打开agconnect-quickgame-1.4.4-min.js文件，格式化代码后，搜索代码片段**return e.response**，并将其修改为如下内容：

```screen
try {
  return JSON.parse(e.response)
} catch (t) {
  return e.response
}
```

## Server

### 导入用户是否有数量限制？

当使用导入用户接口返回错误码2007的时候代表导入用户的数量超过了限制，目前该接口每次最大支持导入1000个用户。
