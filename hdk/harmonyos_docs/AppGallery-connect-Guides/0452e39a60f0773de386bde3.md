# 元数据管理

文件元数据包含云端文件名、文件大小、文件类型等常用属性，也包括用户自定义的文件属性。

在上传文件前或者文件上传到云端后，您都可以设置文件的自定义属性。

文件保存到云端后，您可以在下载文件实体前获取文件的元数据，来决定是否要下载文件。

## 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[初始化存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-initialize-bucket-quickapp-0000001281453000)。

## 操作步骤

1. 调用[StorageManagement.storageReference](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagemanagement-0000001055096686#section012312924313)创建文件的引用，并初始化文件的[UploadMetadata](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/uploadmetadata-0000001055255294)实例。

   ```screen
   var storageReference = storage.storageReference();
   var reference = storageReference.child('images/demo.jpg');
   var metadata = { contentType:'image/jpeg' }; 
   // uri为本地文件资源uri标识
   var fileMetadata = reference.put4QuickApp(uri, metadata);
   ```

2. 文件的自定义属性可以通过[UploadMetadata.customMetadata](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/uploadmetadata-0000001055255294)设置。 说明
   >
   > 为了保证文件上传下载时的数据一致性，上传文件时可以使用sha256Hash方法设置文件SHA256值。
3. 调用[StorageReference.updateFileMetadata](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagereference-0000001055216725#section142543812159)采用覆盖的方式将设置的文件元数据覆盖到云端。

   ```screen
   reference.updateFileMetadata(metadata)
   .then(function(res){})
   .catch((err) => {});
   ```

4. 当设置元数据成功后，您可以通过调用[StorageReference.getFileMetadata](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagereference-0000001055216725#section538914214811)方法来获取设置在云端的元数据。

   ```screen
   reference.getFileMetadata()
   .then((res) => {})
   .catch((err) => {});
   ```
