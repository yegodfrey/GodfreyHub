# （可选）多数据处理位置

通常情况下，为了满足各区域隐私合规或就近处理数据等要求，可以使用不同数据处理位置访问处理不同区域的数据。

* 如果您不指定数据处理位置，云存储服务将使用默认数据处理位置存放和处理数据。
* 如果设置了数据处理位置，云存储服务将在指定的数据处理位置存放和处理数据。

您可以在AppGallery Connect上[设置数据处理位置](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-data-storage-location-0000001162597847)，设置完成后重新[获取项目级认证凭据文件agc-apiclient-*.json](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-download-credentials-0000001334262141)并集成到您的项目中，然后即可在项目中对数据处理位置进行处理：

* [使用默认数据处理位置](#section1910913304262)
* [修改默认数据处理位置](#section8328654182616)
* [使用指定数据处理位置](#section66216133276)

## 使用默认数据处理位置

调用getInstance方法初始化服务实例不传参即可。

```screen
AGCClient client = AGCClient.getInstance();
```

## 修改默认数据处理位置

> 注意
>
> 在AGC上设置的"默认数据处理位置"适用于项目下所有应用，此处修改的"默认数据处理位置"仅对本应用生效，不会影响其他应用。

```screen
String clientName = "[CLIENT_NAME]";
String region= "[REGION]";
```

其中*[CLIENT_NAME]* 为用户自定义的客户端名称，在获取服务实例的时候，需使用该名称进行关联。*[REGION]*是客户端的数据处理位置，可选的值有"CN"（中国）、"RU"（俄罗斯）、"SG"（新加坡）、"DE"（德国）。

## 使用指定数据处理位置

您还可以通过指定目标数据处理位置，实现不同数据处理位置访问不同区域的数据。

调用[AGCStorageManagement.getInstance](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragemanagement-0000001111669018#section13927195542417)方法来初始化存储实例。

```screen
// "regionname" => 存储region名称，您可以打开凭据文件查看项目归属区域，并通过区域查找归属于该区域的存储region。
// "CN" : ["cn-north-4"]
// "SG" : ["ap-southeast-3"]
// "RU" : ["ru-northwest-2"]
// "DE" : ["eu-de"]
// "bucketname" => 存储实例名称，您可以通过在"项目设置>Serverless>云存储"页面中的存储实例框中获取存储实例名称。
// agcClient => https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-sdk-java-0000001115496716#section113221941173010时返回的AGCClient类的实例。当您创建的存储实例所属区域非您设置的默认数据处理位置时，您需要初始化对应区域的AGCClient类的实例并传递给该接口。
StorageManagement storageManagement = AGCStorageManagement.getInstance(agcClient, "regionname", "bucketname");
```
