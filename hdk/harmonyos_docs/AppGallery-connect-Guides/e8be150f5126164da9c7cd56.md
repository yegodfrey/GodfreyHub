# 初始化存储实例

#### 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[集成云存储SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-sdk-nodejs-0000001055127457)。  

#### 操作步骤

在使用云存储服务前，您可以通过[StorageManagement](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagemanagement-0000001057931714)来初始化默认数据处理位置的存储实例。

```
let storage = new StorageManagement();
// name: 存储实例名称
let bucket = storage.bucket(name);
```

或者，您也可以通过[AGCCloudStorage](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccloudstorage-0000001234008417)来初始化默认数据处理位置的存储实例。

```
let storage = AGCCloudStorage.getInstance();
// name: 存储实例名称
let bucket = storage.bucket(name);
```

如果您需要访问不同项目的存储实例，可以调用[AGCCloudStorage.getInstance(name?: string)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccloudstorage-0000001234008417#section1426116294172)方法来初始化存储实例。

```
// 初始化指定名称的AGCClient对象，clientName为自定义的客户端名称
let clientName = 'clientName';
let credential = CredentialParser.toCredential('[path]/agc-apiclient-xxx-xxx.json');
AGCClient.initialize(credential, clientName);

// 初始化云存储实例
let storage = AGCCloudStorage.getInstance(clientName);
// name: 存储实例名称
let bucket = storage.bucket(name);
```

如果您需要访问不同数据处理位置的存储实例，可以调用[StorageManagement.bucket(name: string, area?: string)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagemanagement-0000001057931714#section1426116294172)方法来初始化存储实例。

```
// 初始化云存储实例
let storage = AGCCloudStorage.getInstance();
// name: 存储实例名称, area: 数据处理位置，可选的值有“CN”（中国）、“RU”（俄罗斯）、"SG"（新加坡）、“DE”（德国）
let area = 'CN';
let bucket = storage.bucket(name, area);
```
