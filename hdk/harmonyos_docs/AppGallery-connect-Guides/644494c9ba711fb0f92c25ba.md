# 关闭社区

您可以在合适的场景调用此接口，例如游戏快开始了，用户可以取消弹窗继续留在内嵌社区，或确认弹窗关闭社区页面并返回游戏。关闭内嵌社区的默认弹窗如下所示：

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230928155811.36889956004547660031096402285266:50001231000000:2800:B99C14CD48F792B9DD86718B3783D12D0B159FE6426BE5AF0D9F13C6B21E61FC.png?needInitFileName=true?needInitFileName=true)

## 前提条件

* 内嵌社区已完成[初始化](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/pgsmoment-init-0000001244091880)。
* 您已在游戏内接入[打开社区](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/pgsmoment-open-0000001291688829)能力。

## 开发步骤

调用[PgsMoment.closeWithConfirm](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/gdpsdk-api-pgsmoment-0000001403658572#section084215104496)触发关闭内嵌社区的弹窗事件。
> 说明
>
> 请确认应用在前台运行时调用当前接口。若调用时应用在后台运行，不会出现关闭弹窗。

```screen
// 自定义弹窗正文，不超过50个字符。
// 若传入空字符串，则采用默认文案："匹配成功，是否立即返回游戏？"
String content = "";
PgsMoment.closeWithConfirm(content, new PgsCloseCallback() {
        @Override
        public void onResult(Response response) {
            if (response.isSuccess()) {
                  // 成功关闭
            } else {
                  // 关闭失败
                  Log.e(TAG, "RtnCode: " + response.getRtnCode() + "; Msg: " + response.getMsg());
            }
       }
});
```
