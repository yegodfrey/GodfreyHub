# 查看函数实例

1. 在函数列表中点击函数名称右侧"操作"列的"实例"。或者在函数列表中点击函数名称，进入函数详情页面，选择"实例"页签。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251205152523.80539391265248715993501047665224:50001231000000:2800:FCC970AF265FF0748F8E25942D057293D5DA265D07E20C6BFF4181795A384790.png)

2. 进入实例页面，展示函数全部的实例信息，包括：pod状态、pod名称、各容器名称等。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251205152523.10400055415809732170677979228681:50001231000000:2800:894FB1FB7B060427CEED45FE52025DD5F5F96D25084B46FFA74CE224105CBA4E.png)  
   pod状态非实时同步，若您需要查看最新的函数实例信息，可重新进入"实例"页面进行刷新。

   pod状态有如下三种：
   * Pending：pod启动中。
   * Running：pod运行正常，可以正常接收调用请求。
   * Terminating：pod不再接收调用请求，即将回收。
