# iOS

#### 前提条件

* 您已[集成游戏多媒体基础SDK和实时语音模块](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-integratingsdk-ios-0000001323104597)。
* 您已[创建游戏多媒体实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-engine-ios-0000001272544612#section1093713161034)。  

#### 开始播放

1. 实例化[LocalAudioInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-localaudioinfo-ios-0000001655436605)对象，构造本地音效文件的必要参数。

   ```
   LocalAudioInfo *info = [[LocalAudioInfo alloc] init];
   info.soundId = soundId;    // soundId:音效ID,大于等于0
   info.filePath = filePath;  // filePath:音效文件路径,本地路径和网络URL均可
   info.loop = loop;          // loop:循环播放次数,大于等于0,默认值0表示无限循环
   info.volume = volume;      // volume:音效音量系数,取值范围[0, 100],默认值100
   ```

2. 调用[HWPGMEngine.getInstance playLocalAudioClip](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section16467142772918)方法，播放本地音效。

   ```
   int result = [HWPGMEngine.getInstance playLocalAudioClip:info]; // info:本地音效文件信息
   ```

3. 音效播放状态更新时，可在HWPGMEngineDelegate接口的[onAudioClipStateChangedNotify](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section16489823171411)方法中实现该事件的回调处理。

   ```
   - (void)onAudioClipStateChangedNotify:(LocalAudioClipStateInfo *)stateInfo {
   // 可根据需求将数据进行处理
   }
   ```

#### 暂停/恢复/停止

1. 播放本地音效过程中，可通过调用如下方法，暂停播放指定音效或所有正在播放的音效。
   * 调用[HWPGMEngine.getInstance pauseLocalAudioClip](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section38431739112915)方法，可暂停播放指定的本地音效。

     ```
     int result = [HWPGMEngine.getInstance pauseLocalAudioClip:soundId]; // soundId:音效ID
     ```

   * 调用[HWPGMEngine.getInstance pauseAllLocalAudioClips](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section138613521292)方法，可暂停播放所有本地音效。

     ```
     int result = [HWPGMEngine.getInstance pauseAllLocalAudioClips];
     ```

2. 音效暂停播放后，可通过调用如下方法，恢复指定音效或所有已暂停音效的播放。
   * 调用[HWPGMEngine.getInstance resumeLocalAudioClip](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section4403649142911)方法，可恢复播放指定的本地音效。

     ```
     int result = [HWPGMEngine.getInstance resumeLocalAudioClip:soundId]; // soundId:音效ID
     ```

   * 调用[HWPGMEngine.getInstance resumeAllLocalAudioClips](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section138613521292)方法，可恢复播放所有本地音效。

     ```
     int result = [HWPGMEngine.getInstance resumeAllLocalAudioClips];
     ```

3. 在播放本地音效过程中，可通过调用如下方法，停止播放指定的本地音效或所有本地音效。
   * 调用[HWPGMEngine.getInstance stopLocalAudioClip](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section1124643172510)方法，可停止播放指定的本地音效。

     ```
     int result = [HWPGMEngine.getInstance stopLocalAudioClip:soundId]; // soundId:音效ID
     ```

   * 调用[HWPGMEngine.getInstance stopAllLocalAudioClips](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section7408121562911)方法，可停止播放所有本地音效。

     ```
     int result = [HWPGMEngine.getInstance stopAllLocalAudioClips];
     ```

#### 调节/获取音量系数

1. 在播放本地音效时，可通过调用如下方法，单个调节指定音效或批量调节所有音效的音量系数。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241105115851.72566314069545137703113734108451:50001231000000:2800:0AA937D41A232A5D2D6AD839574CBED2D7B5F6D598EDA04C14FD7574C983EAE2.png?needInitFileName=true?needInitFileName=true)  
   * 本地音效实际播放音量（V）=本地音效音量系数（X）\*所有本地音效的音量系数（Y）%
   * 目前仅支持在播放音效时设置所有本地音效的音量系数，或指定的本地音效音量系数。
   * 调用[HWPGMEngine.getInstance setLocalAudioClipsVolume](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section126081558122917)方法，设置所有本地音效的音量系数。

     ```
     int result = [HWPGMEngine.getInstance setLocalAudioClipsVolume:volume]; // volume:所有本地音效的音量系数,默认值100
     ```

   * 调用[HWPGMEngine.getInstance setVolumeOfLocalAudioClip](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section13821655142916)方法，设置指定的本地音效音量系数。

     ```
     int result = [HWPGMEngine.getInstance setVolumeOfLocalAudioClip:soundId volume:volume]; // soundId:音效ID; volume:本地音效的音量系数,默认值100
     ```

2. 在播放本地音效时，可通过调用如下方法，获取指定音效或所有音效的音量系数。
   * 调用[HWPGMEngine.getInstance getVolumeOfLocalAudioClip](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section1031315193010)方法，获取指定的本地音效音量系数。

     ```
     int result = [HWPGMEngine.getInstance getVolumeOfLocalAudioClip:soundId]; // soundId:音效ID
     ```

   * 调用[HWPGMEngine.getInstance getLocalAudioClipsVolume](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section174423414303)方法，获取所有本地音效的音量系数。

     ```
     int result = [HWPGMEngine.getInstance getLocalAudioClipsVolume];
     ```
