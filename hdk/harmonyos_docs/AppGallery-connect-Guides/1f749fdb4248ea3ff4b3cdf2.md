# 获取云端配置项

#### 前提条件

* 您已在AGC控制台[设置云端配置项](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-remoteconfig-android-cloudconfig-0000001056587179)。
* 您需要在您的应用中[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-remoteconfig-android-integration-sdk-0000001056347165)。  

#### 获取和更新云端配置数据到本地

1. （可选）您可以通过[AGConnectConfig.setCustomAttributes](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section1713619814117)接口设置自定义参数，[fetch](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section1176012013115)接口中会自动带入自定义参数，您也可以通过[AGConnectConfig.getCustomAttributes](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section4585193101812)获取自定义的参数。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250304161006.07855486111231725367629812752445:50001231000000:2800:C3DE9024DDCD63D26D07EA3908A06ABC6BE32B405E57F5F3DF90FBC2DCDC8D5D.png?needInitFileName=true?needInitFileName=true)  
   设置自定义参数要在使用fetch接口之前调用。  

   ```
   "Java"
   Map map = new HashMap<>();
   map.put("custom key","custom value");
   map.put("key","value");
   ...
   AGConnectConfig.getInstance().setCustomAttributes(map);
   Map map = AGConnectConfig.getInstance().getCustomAttributes();
   ```

   ```
   "Kotlin"
   val map: MutableMap<String, String> = mutableMapOf()
   map["custom key"] = "custom value"
   map["key"] = "value"
   ...
   AGConnectConfig.getInstance().customAttributes = map
   var map = AGConnectConfig.getInstance().customAttributes
   ```

2. 从远程配置服务获取参数值使用[AGConnectConfig.fetch](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section1176012013115)接口，返回异步Task任务。获取成功后会返回从云端同步的[ConfigValues](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/android-remoteconfig-configvalues-0000001057570920)数据（可通过此类只获取云端数据），再通过调用[AGConnectConfig.apply](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section486198212)接口传入云端同步获取的值使其生效。  

   ```
   "Java"
   config.fetch().addOnSuccessListener(new OnSuccessListener<ConfigValues>() {
       @Override
       public void onSuccess(ConfigValues configValues) {
   	//使用配置值
           config.apply(configValues); 
       }
   }).addOnFailureListener(new OnFailureListener() {
       @Override
       public void onFailure(Exception e) {
       }
   });
   ```

   ```
   "Kotlin"
   config.fetch().addOnSuccessListener { 
   	//使用配置值
       config.apply(it)
   }.addOnFailureListener { 

   }
   ```

3. fetch接口可能会有网络延迟，导致apply接口未能将云端最新的数值传入，为了避免此情况，您可以先调用fetch接口，然后在需要传入云端数据的地方调用apply接口。如下示例代码中的config.loadLastFetched()即为之前通过fetch接口已经获取的信息。  

   ```
   "Java"
   ConfigValues last = config.loadLastFetched();
          //使用配置值
   config.apply(last);
   ```

   ```
   "Kotlin"
          //使用配置值
   config.apply(config.loadLastFetched())
   ```

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250304161006.56499777815511371035366278201801:50001231000000:2800:A580C55F9BC132B5C428197A2A079748A8B998FFC6FEC6B09C6FC7924952C4EB.png?needInitFileName=true?needInitFileName=true)  
   [fetch()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section1176012013115)接口默认更新周期为 12 小时，[fetch(long intervalSeconds)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section412593515111)接口则可以自行设置更新周期，在更新周期内再次调用fetch接口不会去云侧同步数据，而是使用本地缓存数据直接返回。

[fetch(long intervalSeconds)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section412593515111)间隔时间单位为秒，在调测阶段可以设置为0，方便调测，在实际生产阶段建议设置较大值，防止受到流控限制。  

#### 获取参数值

在设置默认值和更新云端参数值后，您可以调用接口通过键值来获取参数进行使用。云端键值（key）、参数（value）与AGC界面配置的对应关系：

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250304161006.90890281396253795371936674603078:50001231000000:2800:C86F704345069914A6796AB3B8080085EA061A414FE6B89E1A02ED215523C760.png?needInitFileName=true?needInitFileName=true)

远程配置SDK 提供了5种数据类型的接口，您可根据需求进行使用。

* [getValueAsBoolean](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section678915454115)：获取boolean类型参数值。  
  ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250304161006.40647629248384736862072753555765:50001231000000:2800:19599FEFA37D3EEC67564F983486B7AADA2EFB28D69EAD76DA9D0BA37D483ADA.png?needInitFileName=true?needInitFileName=true)  
  boolean类型true支持的字符串有"1"、"true"、"t"、"yes"、"y"、"on"。boolean类型false支持的字符串有"0"、"false"、"f"、"no"、"n"、"off"，不区分大小写。  

  ```
  "Java"
  Boolean value = config.getValueAsBoolean("key");
  ```

  ```
  "Kotlin"
  val value = config.getValueAsBoolean("key")
  ```

* [getValueAsDouble](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section195349553113)：获取double类型参数值。  

  ```
  "Java"
  Double value = config.getValueAsDouble("key");
  ```

  ```
  "Kotlin"
  val value = config.getValueAsDouble("key")
  ```

* [getValueAsLong](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section20942551216)：获取long类型参数值。  

  ```
  "Java"
  Long value = config.getValueAsLong("key");
  ```

  ```
  "Kotlin"
  val value = config.getValueAsLong("key")
  ```

* [getValueAsString](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section322118160215)：获取String类型参数值。  

  ```
  "Java"
  String value = config.getValueAsString("key");
  ```

  ```
  "Kotlin"
  val value = config.getValueAsString("key")
  ```

* [getValueAsByteArray](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section11870122513219)：获取byte数组类型参数值。  

  ```
  "Java"
  byte[] value = config.getValueAsByteArray("key");
  ```

  ```
  "Kotlin"
  val value = config.getValueAsByteArray("key")
  ```

云端设置的参数值实际存储时都是字符串类型，在获取具体类型时进行转换，如果转换失败则返回类型默认值。

* DEFAULT.BOOLEAN_VALUE = false
* DEFAULT.DOUBLE_VALUE = 0.0
* DEFAULT.LONG_VALUE = 0L
* DEFAULT.STRING_VALUE = ""
* DEFAULT.BYTE_ARRAY_VALUE = new byte\[0\]  

#### 获取参数值的来源

您可以通过调用[AGConnectConfig.getSource](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section42391041315)来获取参数值的来源。数据有如下三种来源：

* SOURCE.STATIC：类型默认值
* SOURCE.DEFAULT：本地默认值
* SOURCE.REMOTE：从云端获取的值

```
"Java"
AGConnectConfig.SOURCE source = config.getSource("key");
```

```
"Kotlin"
val source = config.getSource("key")
```

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250304161006.52528949847680283168454092204918:50001231000000:2800:1C41DEBF07500EDCEE4780C3EABAB962BE4BA638420D532B5935E697832C2330.png?needInitFileName=true?needInitFileName=true)  
AppGallery Connect页面设置参数时若为某个条件设置了使用"SDK默认值"，满足该条件时服务器就不会下发这个参数，取值使用本地默认值。  

#### 获取全部参数值

您可以调用[AGConnectConfig.getMergedAll](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section743811341720)一次性获取全部本地默认值和云端参数值，而不是通过键值来读取，相同键值的参数会使用云端数据。  

```
"Java"
Map<String,Object> map = config.getMergedAll();
```

```
"Kotlin"
val map = config.mergedAll
```

<br />

#### 重置参数值

您可以调用[AGConnectConfig.clearAll](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section011016145315)清除所有的参数值，将设置的默认值、云端参数值全部都清除。  

```
"Java"
config.clearAll();
```

```
"Kotlin"
config.clearAll()
```
