# 语法介绍

您在构建安全规则时，需要使用到一些基本的数据类型和运算符，如下描述了安全规则当前支持的数据类型和运算符。  

#### 数据类型

* null

当一个值不存在时，使用null标识。

```
allow read, write:  if request.auth != null;
```

* bool

布尔类型，包含true和false两个值。

```
allow read, write:  if true; 
allow read, write:  if false;
```

#### 运算符

运算符包含五种基本的运算符、七种条件判断和三种逻辑运算符。  

|运算符类型|运算符符号|
|:------|:------------------------------------------------------------------------------------|
|基本的运算符|+ : 加号运算符 - : 减号运算符 \* : 乘号运算符 / : 除号运算符 % : 求余运算符|
|条件判断运算符|\> : 大于运算符 \>= : 大于等于运算符 \< : 小于运算符 \<= : 小于等于运算符 == : 等于运算符 === : 恒等于运算符 != : 不等于运算符|
|逻辑运算符|\&\& : 逻辑与运算符 \|\| : 逻辑或运算符 ! : 逻辑非运算符|
