# 元数据管理

文件元数据包含云端文件名、文件大小、文件类型等常用属性，也包括用户自定义的文件属性。

在上传文件前或者文件上传到云端后，您都可以设置文件的自定义属性。

文件保存到云端后，您可以在下载文件实体前获取文件的元数据，来决定是否要下载文件。

## 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[初始化存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-initialize-bucket-ios-0000001333893477)。

## 设置元数据

1. 调用[[AGCStorage referenceWithPath:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstorage-0000001172981557#section9635163510919)创建文件的引用，并初始化文件的FileMetadata实例。

   ```screen
   "Objective-C"
   //storage为已经初始化的AGCStorage实例
   AGCStorageReference *reference = [storage referenceWithPath:@"images/demo.jpg"];
   AGCStorageMetadata *attribute = [AGCStorageMetadata new];
   attribute.contentType = @"image/jpeg";
   attribute.cacheControl = @"no-store";
   attribute.contentDisposition = @"attachment;filename=demo.jpg";
   attribute.contentEncoding = @"identity";
   attribute.contentLanguage = @"en-US";
   ```

   ```screen
   "Swift"
   //storage为已经初始化的AGCStorage实例
   let reference = storage.reference(withPath:"images/demo.jpg")
   let attribute = AGCStorageMetadata()
   attribute.contentType = "image/jpeg"
   attribute.cacheControl = "no-store"
   attribute.contentDisposition = "attachment;filename=demo.jpg"
   attribute.contentEncoding = "identity"
   attribute.contentLanguage = "en-US"
   ```

2. 调用customMetaData设置文件的自定义属性。 说明
   >
   > 为了保证文件上传下载时的数据一致性，上传文件时可以将sha256Hash属性设置为文件的SHA256值。
3. 调用[[AGCStorageReference updateMetadata:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragereference-0000001126781968#section147471429291)采用覆盖的方式将设置的文件元数据覆盖到云端。

   ```screen
   "Objective-C"
   HMFTask<AGCStorageMetadata *> *metaTask = [reference updateMetadata:attribute];
   [[metaTask addOnFailureCallback:^(NSError *error){
       
   }] addOnSuccessCallback:^(AGCStorageMetadata *result){

   }];
   ```

   ```screen
   "Swift"
   let fileMetadataTask = reference.updateMetadata(attribute)
   fileMetadataTask.onSuccess{(result) in 
   }.onFailure{(error) in
   }
   ```

## 获取元数据

1. 调用[[AGCStorage referenceWithPath:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstorage-0000001172981557#section9635163510919)创建文件的引用。

   ```screen
   "Objective-C"
   //storage为已经初始化的AGCStorage实例
   AGCStorageReference *reference = [storage referenceWithPath:@"images/demo.jpg"];
   ```

   ```screen
   "Swift"
   //storage为已经初始化的AGCStorage实例
   let reference = storage.reference(withPath:"images/demo.jpg")
   ```


2. 调用[[AGCStorageReference getMetadata]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragereference-0000001126781968#section2653103111284)方法获取包含文件元数据的AGCStorageMetadata实例。
3. 通过[AGCStorageMetadata](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragemetadata-0000001172821637)的相关属性获取存储实例名、文件创建时间、文件最近修改时间、云端文件名、文件大小、文件类型、文件自定义属性等。

   ```screen
   "Objective-C"
   HMFTask<AGCStorageMetadata *> *metaTask = [reference getMetadata];
   [[metaTask addOnFailureCallback:^(NSError *error){
       
   }] addOnSuccessCallback:^(AGCStorageMetadata *result){

   }];
   ;
   ```

   ```screen
   "Swift"
   let metaTask = reference.getMetadata()
   metaTask.onSuccess{(result) in 
   }.onFailure{(error) in
   }
   ```
