# 查看报表

## 查看报表数据

1. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"全部服务 > 应用分发 > 应用下载直达"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231121120609.49115282868152645982679142871357:50001231000000:2800:BD5B38375FA85CDC6C405E55EED81DCAC25F868ACCE7646DA9A5308AF6C2C345.png?needInitFileName=true?needInitFileName=true)


2. 在左侧菜单栏选择"效果报表"，选择"分发小站"页签。 您可以根据小站应用名称和日期区间筛选您需要查看内容，了解各渠道的详情页展示、下载、安装和激活数据信息。
