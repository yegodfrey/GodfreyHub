# 游戏功能开发

## 浮标和防沉迷

中国大陆发布的游戏需要接入浮标和防沉迷功能，中国大陆以外地区可选接入。

* 浮标开发请参见[游戏浮标](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/game-buoy-0000001050121528)。
* 防沉迷功能开发请参见[游戏防沉迷](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/game-anti-indulgence-0000001050123479)。

## 其他游戏特性

其他的游戏特性，您可根据实际需求选择接入，参见[游戏服务开发指南](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/game-gameturbo-0000001254626641)。
