# 安装方式介绍

AGD SDK目前支持如下应用分发方式：  
![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230118103402.16787232606669859861055008683066:50001231000000:2800:64A4ECC8AD267C54BCA0C681EF0F1474F565B40D9DB0D8BD918D36BB1E3C6FE6.png?needInitFileName=true?needInitFileName=true)  
* 媒体侧如需使用"installType"请求参数，则请先联系华为研发运营侧，需华为侧配置才能生效。
* 部分安装体验依赖华为应用市场App，请媒体侧充分考虑隐私策略与用户舆情。  

|installType取值|安装方式描述|
|:------------|:---------|
|0110|直接下载无通知栏提示|
|2000|全屏详情页，手动安装|
