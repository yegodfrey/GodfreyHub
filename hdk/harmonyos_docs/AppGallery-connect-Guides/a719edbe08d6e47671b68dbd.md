# 安装方式介绍

AGD SDK目前支持如下应用分发方式： 说明
>
> * 媒体侧如需使用"installType"请求参数，则请先联系华为研发运营侧，需华为侧配置才能生效。
> * 部分安装体验依赖华为应用市场App，请媒体侧充分考虑隐私策略与用户舆情。

|installType取值|安装方式描述|
|:------------|:---------|
|0110|直接下载无通知栏提示|
|2000|全屏详情页，手动安装|
