# 查看应用性能数据

您可以在"应用性能管理"页面查看详细的应用性能数据，包括概览数据、页面分析数据、网络分析数据、自定义分析数据。  

#### 前提条件

* 您的应用已[集成APM JS SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-web-getstarted-0000001053577356#section1777213435401)。
* 您的应用已[启用APM服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-web-getstarted-0000001053577356#section66751722571)。
* （可选）如需查看自定义分析数据，您还需[添加自定义监控配置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-web-addcustomtrace-0000001079976978)。  

#### 查看概览

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择需要查看的应用。
3. 选择"质量 \> 性能管理"，进入"应用性能管理"页面。
4. 点击"概览"，进入概览页面。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155819.00520757534882926210908920904348:50001231000000:2800:9A61AA38DCE69688437D30A99BBA7981E3EF5D7D3E9EFEE99DEE9B0205AE6A29.png)

   指标概览包括"首次内容渲染耗时（Top5域名）"、"网络请求响应耗时（Top5国家/地区）"、"自定义跟踪耗时（Top5自定义跟踪记录）"。在概览页面，您可以快速了解应用的重要性能指标，及时识别应用是否发生问题。
   * 首次内容渲染耗时：用户导航到页面的时间点与浏览器显示有意义的内容的时间点之间的时长
   * 网络请求响应耗时：客户端请求发出到收到服务端完整响应之间的时长
   * 自定义跟踪耗时：完成采集自定义指标的性能数据所需的时长
5. 在各指标图表上左右移动鼠标，可以观察到指标在不同分位对应的值。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155819.85662395610367441713448965694255:50001231000000:2800:6D984423C5C2F717754013CE6CEC9B21FEDE642627AB5F54579B8310B7134B84.gif "点击放大")

#### 查看页面性能数据

页面监控以首次渲染耗时、首次内容渲染耗时、可交互耗时、资源加载失败次数等作为统计指标，通过计算页面不同指标的分位值，来为您呈现页面性能的整体分布情况和异常情况，帮助您及时全面掌握应用的页面性能。

#### 查看网络性能数据

网络监控以DNS解析耗时、TCP建连耗时、SSL建连耗时、请求响应耗时、首包耗时、剩余包耗时、载荷大小等作为统计指标，通过计算网络不同指标的分位值，来为您呈现网络性能的整体分布情况，帮助您及时全面掌握应用的网络性能。

1. 在"应用性能管理"页面，点击"网络分析"，进入网络性能数据统计页面。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155820.41589820755925040853757256610848:50001231000000:2800:D7B43219B8397A9DDBF101844D86D2A822E17DDC702F1E94F8ACC3F94D65DF85.png)
   * "全部URL"页签展示应用下所有URL的指标数据。鼠标移到URL左侧，点击![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155820.59829690704422812282189040911458:50001231000000:2800:2EFF4C3CA5C21C2BE19B898170A28A686A9E8CE1261EA365D695B2DEDDEAFACB.png)可收藏URL，收藏的URL可在"我的收藏"中查看。
