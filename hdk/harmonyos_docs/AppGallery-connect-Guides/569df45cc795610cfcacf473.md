# 集成SDK

## 前提条件

* 安装HUAWEI DevEco Studio 3.1及以上版本
* 配置SDK API Version 9及以上
  * Compile SDK Version 9及以上
  * Compatible SDK Version 9及以上

## 添加应用配置文件

将"agconnect-services.json"文件拷贝到DevEco Studio项目的"AppScope/resources/rawfile"目录下。
> 说明
>
> "AppScope/resources"目录下默认不存在"rawfile"文件夹，需要您手动创建。

## 配置SDK依赖

添加配置文件后，需要在DevEco Studio项目中配置SDK依赖，您可以通过以下任意一种方式配置SDK依赖：

### 方式一

1. 打开DevEco Studio应用级（一般为entry）下的"oh-package.json5"文件。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/24/v3/fljCmfRjRmadWffak9ZWfg/zh-cn_image_0000001658430806.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=84CFED174725B15FFDDDD509E7C9DB47D094F0F58A1F61B91A9A74D888D98E46)

2. 在"oh-package.json5"文件的"dependencies"中添加云函数服务的编译依赖和SDK依赖。

   ```screen
   "dependencies": {
     "@hw-agconnect/hmcore": "1.0.6",
     "@hw-agconnect/cloud": "1.0.6"
   }
   ```

3. 打开修改完的"oh-package.json5"文件，右上方出现"Sync Now"链接，点击"Sync Now"等待同步完成。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3f/v3/AhZuhtvlRgC6ipmIGNy-Rg/zh-cn_image_0000002428156452.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=0B3E732015A81A878EB6CBE9DD680BB9556C9BAB4A2C385ECD7CBAC1A436419A)

### 方式二

1. 打开您的工程，在命令行窗口执行**cd** **entry** 命令，切换到工程的"entry"目录。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1b/v3/N1v0FjFuSaK02jZnbftpkw/zh-cn_image_0000001706590113.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=51F46D34837986E61311116D714A7A918192C3EA04E4F3D5A940A433E2A5BD5C)
2. 安装SDK到您的项目中。

   ```screen
   ohpm install @hw-agconnect/hmcore
   ohpm install @hw-agconnect/cloud
   ```

## 集成AGC SDK

> 注意
>
> * 工程的应用框架必须为Stage模型，即"apiType"配置为"stageMode"。
> * Stage模型仅Compile API版本为9及以上支持，请确保SDK的Compile API版本不低于9。
> * 请确保采用ohpm方式编译。
> * SDK也支持开发OpenHarmony应用（API 9及以上版本）。

1. 在您的项目中导入agc组件。

   ```screen
   import { initialize } from '@hw-agconnect/hmcore';
   ```

2. 在您的应用初始化阶段使用context初始化SDK，推荐在EntryAbility的onCreate中进行。

   ```screen
   import util from '@ohos.util';

   //初始化SDK
   async onCreate(want, launchParam) {
   let input = await this.context.resourceManager.getRawFileContent('agconnect-services.json')
       let jsonString  = util.TextDecoder.create('utf-8', {
         ignoreBOM: true
       }).decodeWithStream(input, {
         stream: false
       });

       initialize(this.context, JSON.parse(jsonString));
   }
   ```

3. 在"entry/src/main/module.json5"文件中添加网络权限。

   ```screen
   "requestPermissions": [
     {
       "name": "ohos.permission.INTERNET"
     }
   ]
   ```

## （可选）设置配置文件参数

如果您在下载配置文件时选择了"不包含密钥"，配置信息中将不包含Client ID、Client Secret和API密钥（凭据），您还需调用AGC SDK的接口手动将密钥传给AGC使用。

1. 在"项目设置 > 常规"页面中获取Client Secret和API密钥（凭据）。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5b/v3/6Y5HEdgsQ12CYCLbUpeCWg/zh-cn_image_0000001786398600.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=EB03F40704912929D29427A76BB4257D08D356EDEFCA9E8FC7A22CB1505D1C62)


2. 在应用启动调用AGC的初始化方法完成后将参数设置给AGC SDK。

   ```screen
   import { initialize } from '@hw-agconnect/hmcore';
   import { setApiKey } from '@hw-agconnect/hmcore';
   import { setClientSecret } from '@hw-agconnect/hmcore';

   initialize(this.context, JSON.parse(jsonString));
   setApiKey("xxx"); // 设置API密钥（凭据）
   setClientSecret("xxx"); // 设置Client Secret
   ```
