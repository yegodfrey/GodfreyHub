# 自定义频道属性

游戏多媒体实时信令功能支持设置频道自定义属性，例如频道标签、状态等。同时，还支持监听频道自定义属性的变更，及时感知频道属性的修改。

## 前提条件

* 您已[集成游戏多媒体基础SDK和实时信令模块](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-integratingsdk-android-0000001250838246#ZH-CN_TOPIC_0000001250838246__li733912204487)。
* 您已[创建游戏多媒体实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-engine-android-0000001193958984#section1093713161034)。
* 您已[订阅频道](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-channel-subscribe-android-0000001744760273#section1014421318306)。

## 设置频道属性

1. 调用[HWPGMEngine.getInstance setRtmChannelProperties](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section1379014500302)方法，设置频道自定义属性。

   ```screen
   SetRtmChannelPropertiesReq *req = [[SetRtmChannelPropertiesReq alloc] init];
   req.channelId = channel;
   req.channelProperties = channelProperties;
   [HWPGMEngine.getInstance setRtmChannelProperties:req];
   ```

2. 在HWPGMEngineDelegate协议的[onSetRtmChannelProperties](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section38142514198)回调方法中，可以获取频道自定义属性的设置结果。

   ```screen
   - (void)onSetRtmChannelProperties:(SetRtmChannelPropertiesResult *)result {
     // 可根据需求将数据进行处理
   }
   ```

## 查询频道属性

1. 调用[HWPGMEngine.getInstance getRtmChannelProperties](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section267381610316)方法，查询频道自定义属性。

   ```screen
   GetRtmChannelPropertiesReq *req = [[GetRtmChannelPropertiesReq alloc] init];
   req.channelId = channel;
   [HWPGMEngine.getInstance getRtmChannelProperties:req];
   ```

2. 在HWPGMEngineDelegate协议的[onGetRtmChannelProperties](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section414513517196)回调方法中，可以获取频道自定义属性的查询结果。

   ```screen
   - (void)onGetRtmChannelProperties:(GetRtmChannelPropertiesResult *)result {
     // 可根据需求将数据进行处理
   }
   ```

## 删除频道属性

1. 调用[HWPGMEngine.getInstance deleteRtmChannelProperties](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section18521104413312)方法，删除频道自定义属性。

   ```screen
   DeleteRtmChannelPropertiesReq *req = [[DeleteRtmChannelPropertiesReq alloc] init];
   req.channelId = channel;
   req.keys = keys;
   [HWPGMEngine.getInstance deleteRtmChannelProperties:req];
   ```

2. 在HWPGMEngineDelegate协议的[onDeleteRtmChannelProperties](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section196481615122016)回调方法中，可以获取频道自定义属性的删除结果。

   ```screen
   - (void)onDeleteRtmChannelProperties:(DeleteRtmChannelPropertiesResult *)result {
     // 可根据需求将数据进行处理
   }
   ```
