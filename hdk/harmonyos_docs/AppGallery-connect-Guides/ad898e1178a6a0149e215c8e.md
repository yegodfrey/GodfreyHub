# 配置云数据库

## 新增和导出对象类型文件

您需要基于AGC控制台创建对象类型，请您遵循操作步骤创建示例中涉及的对象类型。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击需要配置云数据库的项目。
3. 在左侧导航栏选择"云开发（Serverless）> 云数据库"，进入云数据库页面。
4. 点击"新增"，创建新的对象类型。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704142554.44212695629197309591925219888530:50001231000000:2800:BFAB62332EEDFA735369D7EFF2537451AC65CD46F09DE47D48B91AF85B60126A.png)

5. 输入"对象类型名"为"BookInfo"后，点击"下一步"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704142554.32974895328699215452431064752151:50001231000000:2800:0B2A9CE136672EDD230B4FFD4C360EC0ECDFAC325D0D235C26F46B78343BCE93.png)

6. 点击"+新增字段"，新增如下表字段后，点击"下一步"。

   |字段名称|类型|主键|非空|加密|敏感|默认值|
   |:----------|:------|:-|:-|:-|:-|:---|
   |id|Integer|✓|✓|--|--|--|
   |bookName|String|--|--|--|--|--|
   |author|String|--|--|--|--|--|
   |price|Double|--|--|--|--|--|
   |publisher|String|--|--|--|--|--|
   |publishTime|Date|--|--|--|--|--|
   |shadowFlag|Boolean|--|--|--|--|true|

7. 点击"+"新增索引，设置"索引名"为"bookName"，点击"下一步"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704142554.19359553137999800143340436459871:50001231000000:2800:733ED6B86717E9D5357917FCF80B70DF171AA2AC3F9F4B5F1517B7E71BEF66CE.png)
8. 按照如下要求设置各角色权限后，点击"下一步"。 说明
   >
   > 来自Server SDK的访问将被视为管理员，请勿在应用端侧通过Server SDK访问云数据库。

   |角色|query|upsert|delete|
   |:----|:----|:-----|:-----|
   |所有人|✓|--|--|
   |认证用户|✓|✓|✓|
   |数据创建者|✓|✓|✓|
   |管理员|✓|✓|✓|

9. 导出"js格式"文件，导出的文件在后续步骤用于添加至本地开发环境。

   "导出文件类型"选择"js格式"，"使用场景"选择"服务端"。点击"确定"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704142554.30647889480270757922876697425066:50001231000000:2800:0FC18AF1F25F70E08FE5BC11C7DAB66C1E86AA5FC23B3805E9DF70CADEF20401.png)

## 新增存储区

此章节以建一个"存储区名称"为"QuickStartDemo"的存储区举例说明。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击需要配置云数据库的项目。
3. 在左侧导航栏选择"云开发（Serverless）> 云数据库"，进入云数据库页面。
4. 点击"存储区"页签，点击"新增"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704142554.21038898546286985123392716073286:50001231000000:2800:EB6FB5B813BF370AB13DDDA09D2AA388298E3C13868996B44307983FB40E85E8.png)


5. 在"新增存储区"弹框中填写"存储区名称"为"QuickStartDemo"，点击"确定"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704142554.06538067648121572193276377221063:50001231000000:2800:11A93BB15F75F7B5E09B244DEE5C83CD4ABC5FFE7EF7AADA094CEC37F4F34F83.png)
