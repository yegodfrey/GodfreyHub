# 查询频道历史消息

游戏多媒体实时信令功能支持查询频道历史消息，云侧只保存近7日内的频道历史消息，最多可获取100条历史消息记录。  

#### 前提条件

* 您已[集成游戏多媒体基础SDK和实时信令模块](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-integratingsdk-ios-0000001323104597#ZH-CN_TOPIC_0000001323104597__li16373152113206)。
* 您已[创建游戏多媒体实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-engine-ios-0000001272544612#section1093713161034)。
* 您已[订阅频道](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-channel-subscribe-ios-0000001697080114#section1286395093110)。  

#### 开发步骤

1. 调用[HWPGMEngine.getInstance getRtmChannelHistoryMessages](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section154951303211)方法，查询频道历史消息。

   ```
   GetRtmChannelHistoryMessagesReq *req = [[GetRtmChannelHistoryMessagesReq alloc] init];
   req.channelId = channel;
   req.count = [count integerValue];
   req.startTime = [self getHistoryTimestamp];
   [HWPGMEngine.getInstance getRtmChannelHistoryMessages:req];
   ```

2. 在HWPGMEngineDelegate协议的[onGetRtmChannelHistoryMessages](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section4481015162116)回调方法中，可以获取频道历史消息的查询结果。

   ```
   - (void)onGetRtmChannelHistoryMessages:(GetRtmChannelHistoryMessagesResult *)result {
     // 可根据需求将数据进行处理
   }
   ```
