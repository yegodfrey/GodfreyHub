# 发布应用内消息

应用内消息只有在发布后，才能在正式用户的应用内展示。  

#### 前提条件

已[添加并保存应用内消息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-appmessage-create-java-0000001199092457)。  

#### 发布消息

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155410.36757344834458932598682013872347:50001231000000:2800:C3E2D17FBC20737EE7A487BAA42C44122FF1BAF2D125B79C915F05A0AE058192.png)  
分配了"管理员"、"APP管理员"、"运营"或"开发"角色的账号才可以发布应用内消息。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击您需要发布应用内消息的项目。
3. 点击"增长 \> 应用内消息"，点击需要发布消息的"操作"列中的"发布"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155410.00469215420862805605116103137163:50001231000000:2800:29F104A8E2A8C89F0ED6E77D9A81954B08A29E7D74911BAF147AADAE9A8D10D7.png)

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155410.59319488136073469512308321842795:50001231000000:2800:2789B50E11B982E111F0067A8CAC33A5A188C19761F8F12FB29BE2D7B660504A.png)  
如果同一时间存在多个相同事件触发的应用内消息，应用内消息服务只展示其中1条。因此，发布前请确认当前已发布的应用内消息没有使用相同的触发事件。
