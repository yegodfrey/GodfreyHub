# 安装插件

方法一：

安装[Jenkins](https://www.jenkins.io/zh/doc/book/managing/plugins/#从web-ui)插件并在插件搜索栏中输入AppGallery查询。

方法二：

参考[高级安装](https://www.jenkins.io/zh/doc/book/managing/plugins/#高级安装)操作，下载[agc-app-upload-1.0.hpi](https://repo.jenkins-ci.org/artifactory/releases/com/huawei/jenkins/agc-app-upload/1.0/)文件并安装Jenkins插件。
