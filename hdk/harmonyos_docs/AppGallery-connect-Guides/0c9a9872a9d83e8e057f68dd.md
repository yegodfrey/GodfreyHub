# 典型应用场景

#### 发现用户流失风险，提高留存

根据相关数据显示，获得一个新用户的成本是维护一个旧用户的5-10倍，且当用户留存提高5%时，可最高增加收益达95%。重新吸引已流失的用户十分困难，因此提前预测用户流失风险至关重要。例如，当用户出现产品体验流失或竞争流失风险时，可通过用户相关行为数据提前预测，将未来一周内可能流失的用户细分出来，针对这部分受众人群，策划开展相应的预召回活动，唤醒用户，可有效提高用户留存。

#### 预测用户付费潜力，增加转化

产品的变现能力是产品能否良性发展的重要考量，因此，获取收入也是产品运营工作中最核心的一块内容 。很多时候，我们发现产品的活跃度很高，但最终付费转化率并不理想。预测服务，将未来一周内可能发生购买行为的用户精准细分，自动创建受众群组。针对该群组，运营人员可制定针对性营销策略或优化付费流程，如提供无广告购物体验、配置限时折扣套餐等个性化运营动作，从而提高用户购买率，增加收益。

#### 预测用户复购潜力，减少获客成本

一个满意的用户可能会带来8笔潜在生意，随着流量成本的日益增长，深度挖掘每一个存量用户生命周期的全部价值并引导他们持续转化，可有效提升产品盈利能力。通过预测服务，可提前预测出未来7天内具有复购潜力的受众群体，对这部分用户制定精准营销策略，如推送老客体验问候、配置会员折扣套餐等，将进一步帮助您的产品提高付费转化，增加用户黏性，有助于培养他们的品牌忠诚度。
