# 离开房间

进入房间后，不论是否已进入游戏中，房间内玩家均可离开房间。
> 说明
>
> 当房间中所有玩家全部离开后，房间将自动销毁。

## 前提条件

玩家已[加入](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-joinroom-roomid-web-0000001223118676)房间。

## 开发步骤

调用[GameMediaEngine.leaveRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-web-0000001247887067#section5745125162615)方法离开房间。
> 说明
>
> * 普通玩家离开房间时，参数ownerId传null、空字符串或不传即可。
> * 房主离开房间时，参数ownerId传null或空字符串，则表示随机指定新房主。

```screen
...
gameMediaEngine.leaveRoom(roomId, ownerId).then(() => {
  // 离开房间并指定新房主成功
}).catch(err => {
  // 离开房间失败
  const {code, message} = err;
});
```
