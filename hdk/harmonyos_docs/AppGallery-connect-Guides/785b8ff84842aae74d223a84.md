# 使用组件

1. 在应用的入口文件中进行初始化。

   ```
   import { UIBase } from '@hw-agconnect/ui-base';
   ​
   onWindowStageCreate(windowStage: window.WindowStage): void {
     UIBase.init(windowStage);
   }
   ```

2. 参考[UICalendarPicker](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/petalui-api-calendarpicker-0000001894208829#section18144162113596)使用CalendarPicker组件。

#### 异常情形说明

|异常情况|处理结果|
|:----------------------------|:------------------|
|一周起始天不合法。|取默认值0。|
|起始年份晚于结束年份。|起始年份、结束年份均取默认值。|
|针对单日期选择，选中日期早于起始年份。|选中日期取起始年份第一个月的第一天。|
|针对单日期选择，选中日期晚于结束年份。|选中日期取结束年份最后一个月的第一天。|
|针对单日期选择，起始年份晚于当前系统日期，选中日期未设置。|选中日期取起始年份第一个月的第一天。|
|针对单日期选择，结束年份早于当前系统日期，选中日期未设置。|选中日期取结束年份最后一个月的第一天。|
|针对多日期选择，部分选中日期不在起止年份间。|过滤掉不在起止年份间的日期。|
|针对多日期选择，全部选中日期不在起止年份间。|选中日期取默认值。|
|针对时间段选择，开始日期不早于结束日期。|选中日期取默认值。|
|针对时间段选择，开始日期或结束日期不在年份间。|选中日期取默认值。|
|针对时间段选择，选中日期只设置了开始日期，且在起止年份间。|选中日期取用户设置的开始日期的一周。|
