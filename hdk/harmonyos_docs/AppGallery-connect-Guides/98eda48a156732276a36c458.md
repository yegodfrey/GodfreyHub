# （可选）添加自定义监控配置

#### 添加自定义跟踪记录

自定义跟踪记录可用于监控您的应用在自定义场景下的性能，如应用登录场景、应用页面长时间无响应场景等。  

#### 默认属性、自定义属性和自定义指标

对于自定义跟踪记录，APM会自动采集默认属性（版本号、国家/地区、手机类型、一级区域、系统版本、运营商和网络）。同时，您还可以为该跟踪记录添加自定义属性来进一步过滤和细分数据。例如，在购物应用中，您可以添加商品类型为自定义属性来分析数据。

另外，您可以通过添加自定义指标来监控该记录相关的性能事件。例如，您可以创建自定义指标来统计用户登录成功的次数，或统计页面较长时间无响应的次数。这些自定义指标会自动展示在AGC应用性能管理页面。  

#### 添加自定义跟踪记录、自定义属性和自定义指标

1. 在.java类文件顶部导入下面的类。

   ```
   import com.huawei.agconnect.apms.APMS;
   import com.huawei.agconnect.apms.custom.CustomTrace;
   ```

<!-- -->

2. 添加自定义跟踪记录。 您可以调用[createCustomTrace](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/apms-0000001052488219#section351mcpsimp)接口创建自定义跟踪记录。创建完成后，可调用[start](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/customtrace-0000001051488170#section525mcpsimp)接口启动自定义跟踪记录，调用[stop](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/customtrace-0000001051488170#section528mcpsimp)接口停止自定义跟踪记录。

   ```
   CustomTrace customTrace = APMS.getInstance().createCustomTrace("testTrace");
   customTrace.start();

   // code that you want to trace

   customTrace.stop();
   ```

<!-- -->

3. 调用[putProperty](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/customtrace-0000001051488170#section531mcpsimp)接口添加自定义属性。

   ```
   CustomTrace customTrace = APMS.getInstance().createCustomTrace("testTrace");
   customTrace.start();

   // update a property for the trace
   customTrace.putProperty("product", "food");
   // code that you want to trace

   customTrace.stop();
   ```

4. 添加自定义指标。

* 如果指标不存在，可调用[incrementMeasure](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/customtrace-0000001051488170#section613mcpsimp)或[putMeasure](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/customtrace-0000001051488170#section638mcpsimp)接口新增一个指标。
* 如果指标已存在，调用[incrementMeasure](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/customtrace-0000001051488170#section613mcpsimp)接口，会在原指标值基础上增加指定的指标值；调用[putMeasure](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/customtrace-0000001051488170#section638mcpsimp)接口，则会直接更新原指标值。

  下列代码以接口[incrementMeasure](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/customtrace-0000001051488170#section613mcpsimp)为例：

  ```
  CustomTrace customTrace = APMS.getInstance().createCustomTrace("testTrace");
  customTrace.start();

  // code that you want to trace
  boolean success = loginSuccess();
  if (success) {
      customTrace.incrementMeasure("login_success_times", 1);
  } else {
      customTrace.incrementMeasure("login_fail_times", 1);
  }

  customTrace.stop();
  ```

  * 一个应用中可以有多个自定义跟踪记录，多个自定义跟踪记录可以同时运行。
  * 自定义跟踪记录名称、自定义属性名称和属性值、自定义指标名称必须由中文、字母（不区分大小写）、数字和下划线组成，长度最大为100字符。
* 每个自定义跟踪记录最多只能添加5个自定义属性。  

#### 使用@AddCustomTrace跟踪方法耗时

您可以将注解@[AddCustomTrace](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/addcustomtrace-0000001053086911)添加到应用的方法上，同时给定一个字符串来标识创建的自定义跟踪记录名称。在方法调用时，会启动该跟踪记录。在方法结束时，会停止该跟踪记录。

例如，如果您想监控应用Application中onCreate()方法的耗时，可以使用注解@[AddCustomTrace](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/addcustomtrace-0000001053086911)为onCreate()方法创建一个onCreateCustomTrace自定义跟踪记录，请参考如下代码：

```
public class MyApp extends Application {

    @Override
    // Add the annotation to trace cost for method 
    @AddCustomTrace(name = "onCreateCustomTrace", enabled = true /* optional */)
    public void onCreate() {
        super.onCreate();
    }
	
}
```

#### 添加针对特定网络请求的监控指标

虽然APM会自动采集应用中大多数网络请求性能数据，但如果采用的是非URLConnection或非Okhttp框架，还是有少量网络请求APM无法自动采集。此时，可以按照下列方式采集网络请求性能数据。另外，您还可以对特定网络请求添加自定义属性。

1. 添加特定网络请求指标。 您可以调用[createNetworkMeasure](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/apms-0000001052488219#section389mcpsimp)接口创建网络请求指标。创建完成后，可调用[start](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/networkmeasure-0000001052966915#section820mcpsimp)接口启动该指标，调用[stop](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/networkmeasure-0000001052966915#section823mcpsimp)接口停止该指标。

<!-- -->

2. 添加自定义属性。 您可以调用[putProperty](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/networkmeasure-0000001052966915#section906mcpsimp)接口为网络请求指标添加自定义属性。

   APM不会收集任何个人用户数据，如姓名、电子邮件或电话号码。开发者通过添加自定义属性功能来使用APM收集其他数据时，不应该包含个人用户数据（自然人的email地址、电话号码、生物特征（指纹）、位置数据、IP地址、医疗信息、宗教信仰、社保号、婚姻状态等）。对于一定要上传的用户数据，请进行相应的脱敏处理。

   下面是推荐添加的自定义属性样例：

   networkMeasure.putProperty("product", "food");

   下面是不推荐添加的自定义属性样例：

   networkMeasure.putProperty("user_name", user.getUserName());  
   下列代码详细描述了如何为特定网络请求添加监控指标：

   ```
   try {
       String httpUrl = "https://www.developer.huawei.com";
       // 1. Create a networkMeasure for this special network request
       NetworkMeasure networkMeasure = APMS.getInstance().createNetworkMeasure(httpUrl, "GET");
       // 2. Add custom property for this network measure
       networkMeasure.putProperty("activityName", "MainActivity");

       // 3. start this network measure
       networkMeasure.start();
       final URL url = new URL(httpUrl);
       HttpURLConnection conn = (HttpURLConnection) url.openConnection();
       conn.setDoOutput(true);
       conn.setRequestProperty("Content-Type", "application/json");

       byte[] data = new byte[]{};

       DataOutputStream outputStream = new DataOutputStream(conn.getOutputStream());
       outputStream.write(data);

       // 4. Set response body size for this network measure
       networkMeasure.setBytesReceived(data.length);
       // 5. Set network response code for this network measure
       networkMeasure.setStatusCode(conn.getResponseCode());

       conn.disconnect();
       // 6. Stop this network measure
       networkMeasure.stop();
   } catch (IOException ignored) {

   }
   ```

#### 配置采样率

#### 设置会话采样率

应用的一次会话指从应用启动或被切换到前台开始，到退出应用或切换到后台的过程。在一次会话中，APM会采集应用CPU/内存占用信息，并在前端会话详情页面，通过时间戳把该信息、网络请求信息、页面切换信息、前后台信息合并展示，开发者能够通过会话详情页面，还原问题发生时的设备信息和用户交互轨迹。

会话采样率指一次会话采集的概率，默认为1%，采样率越高，则会提高还原问题发生时的设备信息和用户交互轨迹的概率，但也伴随流量和电量消耗的提高，目前建议线上使用默认值即可，线下测试场景可适当提高。

您可以采用如下代码设置会话采样率为1%：

```
<application>
    <!-- Set this value to '1.0', means there are only 1% sessions can sample cpu and memory. -->
    <meta-data
        android:name="sessions_sampling_percentage"
        android:value="1.0" />

</application>
```

#### 设置应用在前台的CPU采集频率

您可以在应用的AndroidManifest.xml文件中添加\<meta-data\>元素来修改CPU采集频率，单位是ms。默认应用的CPU采集频率为100ms。

```
<application>
    <!-- Set this value to '100', means the cpu sampling frequency is 100 ms. -->
    <meta-data
        android:name="collect_cpu_frequency_fg_ms"
        android:value="100" />

</application>
```

#### 设置应用在前台的内存采集频率

您可以在应用的AndroidManifest.xml文件中添加\<meta-data\>元素来修改内存采集频率，单位是ms。默认应用的内存采集频率是100ms。

```
<application>
    <!-- Set this value to '100', means the memory sampling frequency is 100 ms. -->
    <meta-data
        android:name="collect_memory_frequency_fg_ms"
        android:value="100" />

</application>
```
