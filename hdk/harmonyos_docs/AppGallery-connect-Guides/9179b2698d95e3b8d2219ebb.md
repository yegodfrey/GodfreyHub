# 通用

如果您在下面没有找到需要的问题，请加入[Stack Overflow](https://stackoverflow.com/questions/tagged/huawei-mobile-services?tab=Frequent)社区参与讨论。  

#### 游戏服务与联运游戏的关系是什么？

游戏服务是HMS Core的能力之一，是向您提供快速接入游戏的服务，主要提供华为帐号登录等游戏相关特性的能力。联运游戏是华为应用市场和游戏开发者联合运营游戏的服务，您可以通过联运服务更快速的推广自己的游戏，联运游戏的具体开发请参见[联运游戏开发指南](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/appgallerykit-devguide-game-0000001055156905)。  

#### 游戏启动时是否必须要调用init接口初始化？

是的，游戏服务必须要初始化，否则游戏公告无法展示。  

#### HMS Core SDK登录成功后的欢迎框怎么调用？

请参见[游戏启动](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/game-start-0000001050123475)在Application的onCreate方法中注册Activity的回调监听。  

#### 手机上已经登录华为帐号，进入游戏为什么没显示浮标？

请参见[华为游戏浮标不显示或显示异常](https://developer.huawei.com/consumer/cn/forum/topic/0204399583447760128)定位。  

#### 使用华为帐号登录游戏时错误码7021表示什么意思？

7021表示实名认证返回强制实名但是用户取消，或需要强制实名但没有实名，需要禁止玩家进入游戏，也可以调用登录接口重新引导玩家进行实名认证。  

#### 当前是否有支持切换华为帐号的接口？

当前不支持，建议您手动至手机系统的华为帐号中心里切换帐号。  

#### 华为应用市场是否支持发布Unity和Cocos开发的游戏？

* 华为应用市场支持Unity和Cocos开发的游戏上架。
* Unity或Cocos的具体实现建议您访问Unity和Cocos官网查询或联系对方技术人员沟通。  

#### 应用启动时在登录框拉起的时候切换至后台，然后重新进入游戏，此时登录框是关闭的，点击登录按钮也无法拉起登录框，错误码2013，该怎么处理？

2013表示正在登录中，请不要再次登录。

出现该错误码是因为您之前的登录页面没有正常销毁，登录流程仍在处理中，建议您修改启动模式，将activity模式修改为standard或singleInstance。  

#### 浮标只能在中国大陆展示吗？

* EMUI 9.1以下的手机，浮标采用悬浮球的形式，只有中国大陆发布的游戏有。
* EMUI 9.1以上，华为提供了新的浮标方案，手势划出浮标，全球游戏均展示。  

#### 华为游戏服务 SDK是否支持热更新？

SDK暂不支持，但游戏可根据实际情况自行实现。  

#### 通过浮标窗口切换帐号或者通过华为应用市场切换帐号，调用getCurrentPlayer接口是否有onSuccess回调？

没有onSuccess回调。  

#### 帐号登录时返回错误码2002的错误如何复现？

打开"设置 \> 帐号中心 \> 隐私中心 \> 控制对您帐号的访问"，找到对应的应用，操作取消授权，然后可重启应用测试复现问题。  

#### 接入华为游戏服务SDK，需要用到哪些权限？

您可以参考[SDK数据安全说明](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/sdk-data-security-0000001050121546)查看游戏服务SDK所需的权限。  

#### 在Android 11上，已安装HMS Core（APK）最新版本，仍然提示升级，如何解决？

Android 11更改了应用查询用户在设备上已安装的其他应用以及与之交互的方式。您应用的targetSdkVersion是30或者更高版本时，并且集成的Game Service SDK低于6.1.0.301版本，将会导致应用无法访问HMS Core（APK），并且持续提示升级。

您可以通过以下两种方法解决：

* 方法一： 升级Game Service SDK至6.1.0.301及以上版本，最新版本信息请参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/version-change-history-0000001050123471)。

* 方法二：  
  如果不升级Game Service SDK至6.1.0.301及以上版本，需要在"AndroidManifest.xml"中manifest下添加\<queries\>标签。

  ```
  <manifest ...>
      ...
      <queries>
          <intent>
              <action android:name="com.huawei.hms.core.aidlservice" />
          </intent>
      </queries>
      ...
  </manifest>
  ```

  \<queries\>标签对工具的要求如下：
  * Android Studio需升级至3.3或更高版本。
* [Android Gradle插件](https://developer.android.com/studio/releases/gradle-plugin)需升级至3.3.3、3.4.3、3.5.4、3.6.4、4.0.1或4.1.0及更高版本。  

#### 调用AchievementsClient.getAchievementList接口时，为什么会提示"该玩家的游戏服务不可用"？

需要打开华为应用市场（10.3.x或更高版本），点击我的\>设置\>游戏服务，开启游戏服务，并同意隐私声明。  

#### 用EMUI 9.1以上版本的华为手机测试发现，浮标靠近边缘，会自动隐藏且无法拖动？

这是正常的，EMUI9.1以上的华为手机上的浮标不是由SDK接口控制的，且该浮标需要从左至右滑出显示。  

#### 已经将agconnect-services.json 文件放在根目录下仍无法读取，该怎么处理？

1. 请检查json文件是否正确放在工程根目录下。
2. 请检查相关插件是否配置正确，具体请参见[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/integrate-as-sdk-0000001050435953)。
3. 如果仍无法读取json文件，可以手动在Manifest文件中添加配置appid和cpid。

   ```
   <meta-data
   android:name="com.huawei.hms.client.appid"
   <!-- value的值“xxx”用实际申请的应用ID替换，来源于应用详情。-->
   android:value="appid=xxx">
   </meta-data>
   <!-- value的值“xxx”用实际申请的开发者的支付ID替换，来源于应用的支付服务信息。-->
   <meta-data
   android:name="com.huawei.hms.client.cpid"
   android:value="cpid=xxx">
   </meta-data>
   ```

#### 华为游戏服务是否支持邀请玩家？

没有提供此类API。您可以自行实现该功能。  

#### 华为联运游戏审核驳回：游戏无退出控件。请问调用游戏SDK的什么接口可以退出游戏？

游戏SDK没有提供登出华为帐号的接口，建议自行在游戏内做退出游戏的控件。  

#### HarmonyOS系统的手机上，接入游戏SDK后浮标不出现。

在手机的"设置-应用及服务-应用助手-游戏空间"，按照该操作路径将应用加入游戏空间中，且HarmonyOS系统手机的浮标是从上往下滑出的。  

#### 如何检测监控异常退出，如进程终止或重启手机？

以下处理仅供参考，建议您根据实际情况自行设计。

1. 进程终止：当Android通过杀进程的APP杀死进程后，会执行onDestroy方法，当onDestroy方法执行完成后才彻底杀死进程。

2. 重启：Android系统提供了与开机广播对应的关机广播，在系统即将关闭时发出此广播。

编写在系统即将关闭时发出的广播的接收器。自定类继承BroadcastReceiver类，代码如下：

```
public class ShutdownBroadcastReceiver extends BroadcastReceiver {  
    private static final String TAG = "ShutdownBroadcastReceiver";       
    private static final String ACTION_SHUTDOWN = "android.intent.action.ACTION_SHUTDOWN";  
    @Override  
    public void onReceive(Context context, Intent intent) {  //即将关机时，要做的事情          
        if (intent.getAction().equals(ACTION_SHUTDOWN)) {  
            Log.i(TAG, "ShutdownBroadcastReceiver onReceive(), Do thing!");  
        }  
    }  
}
```

#### 三方应用市场（例如Google Play）禁止您的应用引导下载其他应用？

您需要删除SDK中引导下载安装HMS Core（APK）的能力，打开应用级的"build.gradle"文件，在"configurations "中增加如下配置，去除对引导安装SDK的依赖：

```
configurations {
      all*.exclude group: 'com.huawei.hms', module: 'hmscoreinstaller'
}
```
