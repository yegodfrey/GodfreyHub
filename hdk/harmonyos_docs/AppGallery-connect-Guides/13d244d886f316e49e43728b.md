# 使用限制

本章节将为您详细介绍聚合链接不同类型的限制。这些限制可能会根据实际情况随时更新，请您注意文档变化。

## 参数限制

无论是您在AGC控制台创建聚合链接，还是通过聚合链接SDK进行创建，都不支持将emoji配置为参数内容。

## 设备限制

设备限制是指SDK对用户终端的限制。

|限制项|限制|
|:-----------|:----------------------------------------|
|设备品牌|支持所有品牌设备。|
|设备类型|HarmonyOS当前仅支持手机和平板设备。|
|Android OS|Android 4.4及以上（API Level 18及以上）。|
|iOS OS|1.2.1及以前版本：iOS 8及以上。 1.3.0版本及以后：iOS 9及以上。|
|Web浏览器|不支持Web应用。|
|EMUI（针对华为手机）|无限制。|
|HMS Core APK|无限制。|
|应用市场客户端|无限制。|

## 配额限制

|配额|限制|
|:----------|:-------------------------|
|链接前缀|每个项目最多创建5个链接前缀。|
|AGC中创建的聚合链接|每个链接前缀最多支持在AGC创建2000个聚合链接。|
