# 管理模板

当模板发布新版本时，还可以选择升级模板。

## 升级版本

当Serverless模板有新版本上架时，您可以在已经部署的模板列表中升级模板。

1. 在项目列表中找到您需要升级Serverless模板的项目。
2. 选择"云开发（Serverless） > Serverless模板"，点击可升级模板右侧的"升级"。 说明
   >
   > 仅在模板发布新版本时，才可以进行升级操作。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250813093802.09605167342839973540018657618957:50001231000000:2800:41BCD954299DE08E5405B81D4F65AD0233ACD1801C3AC4A7D52F1B2A006764E0.png)
3. 查看新版本模板的版本说明，确认后点击"下一步"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250813093802.36294600496730686803811050707438:50001231000000:2800:1F2E56FA1DC99F6B11052D07A11FDBCE076226730B528FD99A4E914FF4AC7A97.png)

4. 配置该Serverless服务需要的参数，配置完成后点击"下一步"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250813093802.63156102343735361458913651524997:50001231000000:2800:6FEF8A72ACA47E573CB43D13D709BA9AF25048ADDD0187D033EB6CDA57175D2C.png)

5. 在升级版本页面，点击"开始升级"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250813093802.39707716670915789067876206816690:50001231000000:2800:66F5F1A26C5E82D792BB94FA3DB99293D3D4661C9B902499E3ABB6BF0DC266EF.png)

> 注意
>
> 如升级失败，您可在页面点击"重新部署"。多次重新部署仍失败时，可点击"反馈问题"，填写问题详情并提交后等待运维人员处理，处理周期一般在1个工作日内。

## 重试部署

当Serverless部署失败后，操作列会出现"部署"操作，您可点击重试部署。
