# Twitter

您可以在应用中集成Twitter认证方式，让您的用户可以使用自己的Twitter账号进行AppGallery Connect身份验证。
> 说明
>
> Twitter三方认证方式仅在海外站点支持，当您选择数据处理位置为德国、新加坡或俄罗斯时可以使用此认证方式。

## 前提条件

* 您需要在AGC控制台[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-integration-sdk-0000001325876845)。

## 开发步骤

认证服务提供了两种开发方式接入Twitter账号：

* 推荐您使用新的统一登录接入方式，请参见[统一登录接入方式](#section182761639113911)。
* 同时为了兼容性保留了老的传统接入方式，请参见[传统接入方式](#section3852111284110)。

### 统一登录方式

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143818.15623340950129581569408288146753:50001231000000:2800:2C93BED1E0B86562D29D02130706086C1A2FA45DFB2D3AC603DC152D88238206.png "点击放大")

1. 添加SDK依赖。
   * Android Studio开发环境
     * Version Catalog方式管理依赖
       1. 打开Android Studio项目级gradle目录下的"libs.versions.toml"文件，在[versions]中声明Twitter SDK版本号。

          ```screen
          [versions]
          twitterVersion = "0.11.1"  # 以0.11.1为例
          ```

       2. 在"libs.versions.toml"文件的[libraries]中声明华为认证SDK和Twitter SDK。

          ```screen
          [libraries]
          agconnect-auth-twitter = { module = "com.huawei.agconnect:agconnect-auth-twitter", version.ref = "agcVersion" }  # agcVersion声明请参见https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-integration-sdk-0000001325876845#section99221941185719。
          twitter-sdk = { module = "net.openid:appauth", version.ref = "twitterVersion" }
          ```

       3. 在应用级"build.gradle"文件的"dependencies"中添加华为认证SDK和Twitter SDK的编译依赖。

          ```screen
          dependencies {      
               implementation libs.agconnect.auth.twitter
               implementation libs.twitter.sdk
          }
          ```

     * 非Version Catalog方式管理依赖 打开应用级gradle文件（通常在app/build.gradle），在"dependencies"中添加华为认证SDK和Twitter SDK的编译依赖。

       ```screen
       dependencies {
           implementation "com.huawei.agconnect:agconnect-auth-twitter:1.9.4.300"     
           implementation "net.openid:appauth:{version}"
       }
       ```

   * Eclipse开发环境

     打开aar2eclipse/aar目录下的build.gradle文件， 在"dependencies"中添加华为认证SDK和Twitter SDK的编译依赖。具体步骤参见[Eclipse开发环境集成AGC SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-integration-sdk-0000001325876845#section1878849165620)。

     ```screen
     dependencies {
         embed "com.huawei.agconnect:agconnect-auth-twitter:1.9.4.300"
         embed "net.openid:appauth:{version}"
     }
     ```

   > 说明
   > * 示例中的*twitterVersion* 和*{version}*请替换为Twitter SDK的最新版本号，华为不负责更新。
   > * 华为不负责提供Twitter SDK依赖包，您可以在Twitter平台下载最新版本的Twitter SDK依赖包进行手动集成。
2. 设置Twitter账号登录所需参数。 在登录之前，调用设置参数接口，设置Twitter账号登录所需要的参数。

   例如/twitter/client_id：在Twitter开放平台申请的client_id。

   例如/twitter/redirect_url：在Twitter开放平台申请的redirect_url。

   ```screen
   "Java"  
   AGConnectApi.getInstance().getOptions().setOption("/twitter/client_id", "your twitter client_id");
   AGConnectApi.getInstance().getOptions().setOption("/twitter/redirect_url","your twitter redirect_url");
   ```

   ```screen
   "Kotlin"
   AGConnectApi.getInstance().options.setOption("/twitter/client_id", "your twitter client_id")
   AGConnectApi.getInstance().options.setOption("/twitter/redirect_url", "your twitter redirect_url")
   ```

3. 在Twitter开放平台设置redirect_url的Scheme。 注意
   > * redirect url的Scheme的值需要保证唯一，且不可设置为http或https。
   > * 您可以将Scheme设置为应用包名或[agconnect-services.json文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-obtain-files-0000001276801300#section10149122903418)中的productId，例如，redirect_url格式为 app.example.com://host/path。
   > * 设置完成后请将redirect_url添加到Twitter开放平台的Callback URI/Redirect URL中。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143818.65482552417746867557466424432150:50001231000000:2800:E9A80D28B8918151417F6CB9957E31AD9463B153AD5007FBF50E637CB143CC60.png)

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143818.37899988923587790287231585092475:50001231000000:2800:7C631A959E7868ED9B5DAEED70C5F8DF0719860BE6240CC737A75949E64B3DBB.png)
4. 在工程的AndroidManifest.xml文件中找到需要跳转到登录页面的Activity，并添加intent-filter。

   ```screen
   <intent-filter>
                   <action android:name="android.intent.action.VIEW"/>
                   <category android:name="android.intent.category.DEFAULT"/>
                   <category android:name="android.intent.category.BROWSABLE"/>
                   <data android:scheme="#ZH-CN_TOPIC_0000001053492677__li76208362374中设置的redirect_url的scheme"
                           android:host="#ZH-CN_TOPIC_0000001053492677__li76208362374中设置的redirect_url的host"
                           android:path="#ZH-CN_TOPIC_0000001053492677__li76208362374中设置的redirect_url的path"/>
               </intent-filter>
   ```

   在项目中的build.gradle文件中的defaultConfig目录下添加如下代码。

   ```screen
   android.defaultConfig.manifestPlaceholders = [
                   'appAuthRedirectScheme': '#ZH-CN_TOPIC_0000001053492677__li76208362374中设置的redirect_url的scheme'
           ]
   ```

5. 调用[AGConnectAuth.signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauth-0000001054482530#section125666562219)，登录Twitter账号。

   ```screen
   "Java"
   AGConnectAuth.getInstance().signIn(this,AGConnectAuthCredential.Twitter_Provider).addOnSuccessListener(new OnSuccessListener<SignInResult>() {
           @Override
           public void onSuccess(SignInResult signInResult) {
                   // onSuccess
                   AGConnectUser user =  signInResult.getUser();
           }
   })
   .addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
                   // onFail
           }
   });
   ```

   ```screen
   "Kotlin"
    AGConnectAuth.getInstance().signIn(this, AGConnectAuthCredential.Twitter_Provider)
               .addOnSuccessListener(object : OnSuccessListener<SignInResult?>() {
                   fun onSuccess(signInResult: SignInResult) {
                       // onSuccess
                       val user: AGConnectUser = signInResult.getUser()
                   }
               })
               .addOnFailureListener(object : OnFailureListener() {
                   fun onFailure(e: Exception?) {
                       // onFail
                   }
               })
   ```

### 传统接入方式

Twitter的传统接入方式支持[OAuth 2.0认证方式](#ZH-CN_TOPIC_0000001053492677__li1235546162911)和[OAuth 1.0认证方式](#ZH-CN_TOPIC_0000001053492677__li1316114221293)两种方式。

* OAuth 2.0认证方式 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143818.17817322810597734300307457163869:50001231000000:2800:DA0D1E6E88B261A96980F22BCFE7EAC848C8CD66EB52023F8C3AA9FC95AAA081.png "点击放大")

  1. 在应用的登录界面，初始化[AGConnectAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauth-0000001054482530)实例，获取AGC的用户信息，检查是否有已经登录的用户。如果有则可以直接进入用户界面，否则显示登录界面。

     ```screen
     "Java"
     AGConnectUser user = AGConnectAuth.getInstance().getCurrentUser();
     ```

     ```screen
     "Kotlin"
     val user = AGConnectAuth.getInstance().currentUser
     ```

  2. Twitter账号使用OAuth 2.0登录，并获取Twitter账号的用户授权信息。具体请参考[Twitter官方文档](https://developer.twitter.com/en/docs/twitter-api)。
  3. 调用[credentialWithAuthCode(TwitterAuthParam twitterAuthParam, boolean autoCreateUser)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/twitterauthprovider-0000001054083796#section1729822893110)使用从Twitter账号授权接口获取的authCode生成credential，并调用[AGConnectAuth.signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauth-0000001054482530#section298148131715)实现登录。

     ```screen
     "Java"
     // 使用TwitterAuthParam 生成参数对象
     TwitterAuthParam param = new TwitterAuthParam("your client_id", authCode, "your codeVerifier", "your redirect_url");
     AGConnectAuthCredential credential = TwitterAuthProvider.credentialWithAuthCode(param, true);
     AGConnectAuth.getInstance().signIn(credential)
         .addOnSuccessListener(new OnSuccessListener<SignInResult>() {
             @Override
             public void onSuccess(SignInResult signInResult) {
                 // onSuccess
                 AGConnectUser user = signInResult.getUser();
             }
         })
         .addOnFailureListener(new OnFailureListener() {
             @Override
             public void onFailure(Exception e) {
                 // onFail
             }
         });
     ```

     ```screen
     "Kotlin"
     val param = TwitterAuthParam("your client_id", authCode, "your codeVerifier", "your redirect_url")
     val credential: AGConnectAuthCredential = TwitterAuthProvider.credentialWithAuthCode(param, true)
     AGConnectAuth.getInstance().signIn(credential).addOnSuccessListener {
         // onSuccess
         val user = it.user
     }.addOnFailureListener {
          // onFail
     }
     ```

* OAuth 1.0认证方式

  ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143818.15865114099705067942356877203325:50001231000000:2800:30215D28A115B93AC6E36D70D63338E40DA7F7147EFA1AC8F488371545F84ED9.png "点击放大")
  1. 在应用的登录界面，初始化[AGConnectAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauth-0000001054482530)实例，获取AGC的用户信息，检查是否有已经登录的用户。如果有则可以直接进入用户界面，否则显示登录界面。

     ```screen
     "Java"
     AGConnectUser user = AGConnectAuth.getInstance().getCurrentUser();
     ```

     ```screen
     "Kotlin"
     val user = AGConnectAuth.getInstance().currentUser
     ```


  2. Twitter账号登录，并获取Twitter账号的用户授权信息。 说明
     >
     > 此步骤仅供参考，更详细内容，请参见 [Twitter官方文档](https://developer.twitter.com/en/docs) 。
     1. 配置在Twitter开发者平台申请的APPID和APPSECRET。

        ```screen
        "Java"
        TwitterAuthConfig authConfig = new TwitterAuthConfig(APP_ID, APP_SECRET);
        TwitterConfig twitterConfig = new TwitterConfig.Builder(this).twitterAuthConfig(authConfig).build();
        Twitter.initialize(twitterConfig);
        ```

     2. 使用TwitterLoginButton获取授权登录后的token和secret，用于传入AGConnect SDK。

        ```screen
        "Java"
        mLoginButton = findViewById(R.id.buttonTwitterLogin);
        mLoginButton.setCallback(new Callback<TwitterSession>() {
                @Override
                public void success(Result<TwitterSession> result) {
                        String token = result.data.getAuthToken().token;
                        String secret = result.data.getAuthToken().secret;
                }

                @Override
                public void failure(TwitterException exception) {
                }
        });
        ```

     3. 添加授权确认后的回调。

        ```screen
        "Java"
        @Override
        protected void onActivityResult(int requestCode, int resultCode, Intent data) {
                super.onActivityResult(requestCode, resultCode, data);

                mLoginButton.onActivityResult(requestCode, resultCode, data);
        }
        ```

  3. 调用[TwitterAuthProvider.credentialWithToken](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/twitterauthprovider-0000001054083796#section571311717332)使用从Twitter账号获取的accessToken和secret生成credential，并调用[AGConnectAuth.signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauth-0000001054482530#section298148131715)实现登录。

     ```screen
     "Java"
     AGConnectAuthCredential credential = TwitterAuthProvider.credentialWithToken(token, secret);
     AGConnectAuth.getInstance().signIn(credential)
             .addOnSuccessListener(new OnSuccessListener<SignInResult>() {
                     @Override
                     public void onSuccess(SignInResult signInResult) {
                             // onSuccess
                             AGConnectUser user = signInResult.getUser();
                     }
             })
             .addOnFailureListener(new OnFailureListener() {
                     @Override
                     public void onFailure(Exception e) {
                             // onFail
                     }
             });
     ```

     ```screen
     "Kotlin"
     val credential = TwitterAuthProvider.credentialWithToken(token, secret)
     AGConnectAuth.getInstance().signIn(credential).addOnSuccessListener {
             // onSuccess
             val user = it.user
     }.addOnFailureListener {
             // onFail
     }
     ```

## 更多信息

* 您如果想让用户可以使用多个账号登录您的应用，可以将多个[账号进行关联](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-associated-0000001053692650)。
* 当用户不需要使用应用，或者需要切换其他账号登录认证，可以先执行[登出](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-sign-out-0000001053612647)。
* 当用户需要注销当前用户，可以进行[销户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-deleteuser-0000001057730521)。
* 对于销户、修改密码、关联账号以及重置手机账号和邮箱账号等敏感操作，为了提高安全性，需要用户必须在5分钟内登录过才能执行。如果用户执行敏感操作时登录超过5分钟，需要[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-reauthenticate-0000001127287737)后再执行敏感操作。
* 您可以参考[异常处理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-troubleshooting-0000001052932665)实现自己的异常处理机制，从而减少异常情况的发生。
* 您可以使用云函数触发器来接收用户注册、登录、销户等关键事件，从而[扩展认证服务的能力](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-extension-0000001053372708)。
* 您可以参考[管理用户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-user-manage-0000001606051705)对用户进行解锁、停用等操作。
