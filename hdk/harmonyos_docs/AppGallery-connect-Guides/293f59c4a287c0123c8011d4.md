# 开通服务

#### 开通Android/iOS应用的服务

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，单击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择您需要启用崩溃服务的应用。
3. 选择"质量 \> 崩溃"，进入崩溃服务的页面。  
   ![](https://media:101782979086468879)  
   Android SDK、iOS SDK已于2024年6月30日起停止支持新应用接入。

   ![](https://media:101782979086501880)  
   ![](https://media:101782979086565881)  
   启用服务时，您可根据系统弹出的提示框进行设置。如果尚未设置默认数据处理位置，设置后会刷新SDK配置文件里的配置。因此，您需要重新下载SDK配置文件并集成到您的工程中，具体操作参见[获取SDK配置文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-obtain-files-0000001281093660)。

#### 开通HarmonyOS应用的服务

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，单击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择您需要启用崩溃服务的HarmonyOS应用/元服务。
3. 选择"质量 \> 崩溃"，进入崩溃服务页面。
4. 点击"立即开通"。 ![](https://media:101782979086596882)

5. 选择API版本"API11及以上"，点击"确定"。  
   ![](https://media:101782979086628883)  
   崩溃服务已停止支持新应用接入，API≥11的HarmonyOS应用/元服务推荐使用[APMS服务](https://developer.huawei.com/consumer/cn/doc/app/agc-help-apms-0000002235870062)。

   ![](https://media:101782979086684884)
6. （可选）如果尚未设置默认数据处理位置，系统会弹出"提示"框，您需要将数据处理位置设置为"中国"。 ![](https://media:101782979086745885)
