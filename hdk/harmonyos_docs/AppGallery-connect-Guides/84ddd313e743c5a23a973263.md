# Android

#### 前提条件

* 您已[集成游戏多媒体基础SDK和实时语音模块](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-integratingsdk-android-0000001250838246#ZH-CN_TOPIC_0000001250838246__li733912204487)。
* 您已[创建游戏多媒体实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-engine-android-0000001193958984#section1093713161034)。  

#### 开始播放

1. 实例化[LocalAudioInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-model-localaudioinfo-android-0000001656490025)对象，构造本地音效文件的必要参数。

   ```
   LocalAudioInfo localAudioInfo = new LocalAudioInfo();
   localAudioInfo.setSoundId(1);                 // SoundId:音效ID,大于等于0
   localAudioInfo.setVolume(100);                  // Volume:音效音量系数,取值范围[0, 100],默认值100
   localAudioInfo.setFilePath("/data/data/1.m4a"); // FilePath:音效文件路径,本地路径和网络URL均可
   localAudioInfo.setLoop(1);                      // Loop：循环播放次数,大于等于0,默认值0表示无限循环
   ```

2. 调用[GameMediaEngine.playLocalAudioClip](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section1444210513185)方法，播放本地音效。

   ```
   mHwRtcEngine.playLocalAudioClip(localAudioInfo); // localAudioInfo:本地音效文件信息
   ```

3. 音效播放状态更新时，可在IGameMMEEventHandler接口的[onAudioClipStateChangedNotify](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section12505121617242)方法中实现该事件的回调处理。

   ```
   @Override
   public void onAudioClipStateChangedNotify(LocalAudioClipStateInfo localAudioClipStateInfo) {
       // 可根据需求将数据进行处理
   }
   ```

#### 暂停/恢复/停止

1. 播放本地音效过程中，可通过调用如下方法，暂停播放指定音效或所有正在播放的音效。
   * 调用[GameMediaEngine.pauseLocalAudioClip](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section1056912562184)方法，可暂停播放指定的本地音效。

     ```
     mHwRtcEngine.pauseLocalAudioClip(soundId); // soundId:音效ID
     ```

   * 调用[GameMediaEngine.pauseAllLocalAudioClips](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section16257558101815)方法，可暂停所有本地音效。

     ```
     mHwRtcEngine.pauseAllLocalAudioClips();
     ```

2. 音效暂停播放后，可通过调用如下方法，恢复指定音效或所有已暂停音效的播放。
   * 调用[GameMediaEngine.resumeLocalAudioClip](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section1979175981818)方法，可恢复播放指定的本地音效。

     ```
     mHwRtcEngine.resumeLocalAudioClip(soundId); // soundId:音效ID
     ```

   * 调用[GameMediaEngine.resumeAllLocalAudioClips](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section11764171141915)方法，可恢复播放所有本地音效。

     ```
     mHwRtcEngine.resumeAllLocalAudioClips();
     ```

<!-- -->

3. 在播放本地音效过程中，可通过调用如下方法，停止播放指定的本地音效或所有本地音效。
   * 调用[GameMediaEngine.stopLocalAudioClip](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section1386833151913)方法，可停止播放指定的本地音效。

     ```
     mHwRtcEngine.stopLocalAudioClip(soundId); // soundId:音效ID
     ```

   * 调用[GameMediaEngine.stopAllLocalAudioClips](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section285514511194)方法，可停止播放所有本地音效。

     ```
     mHwRtcEngine.stopAllLocalAudioClips();
     ```

#### 调节/获取音量系数

1. 在播放本地音效时，可通过调用如下方法，单个调节指定音效或批量调节所有音效的音量系数。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241105115851.86995086000075610351594494084076:50001231000000:2800:C19CBDB056997F7BB8825891F6FF198A8376A984BFC783A4FB8D71FF905F647C.png?needInitFileName=true?needInitFileName=true)  
   * 本地音效实际播放音量（V）=本地音效音量系数（X）\*所有本地音效的音量系数（Y）%
   * 目前仅支持在播放音效时设置所有本地音效的音量系数，或指定的本地音效音量系数。
   * 调用[GameMediaEngine.setLocalAudioClipsVolume](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section11443189151917)方法，设置所有本地音效的音量系数。

     ```
     mHwRtcEngine.setLocalAudioClipsVolume(volume); // volume:所有本地音效的音量系数,默认值100
     ```

   * 调用[GameMediaEngine.setVolumeOfLocalAudioClip](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section106411711916)方法，设置指定的本地音效音量系数。

     ```
     mHwRtcEngine.setVolumeOfLocalAudioClip(soundId, volume); // soundId:音效ID; volume:本地音效的音量系数,默认值100
     ```

<!-- -->

2. 在播放本地音效时，可通过调用如下方法，获取指定音效或所有音效的音量系数。
   * 调用[GameMediaEngine.getVolumeOfLocalAudioClip](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section1777791181915)方法，获取指定的本地音效音量系数。

     ```
     mHwRtcEngine.getVolumeOfLocalAudioClip(soundId); // soundId:音效ID
     ```

   * 调用[GameMediaEngine.getLocalAudioClipsVolume](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section772511441920)方法，获取所有本地音效的音量系数。

     ```
     mHwRtcEngine.getLocalAudioClipsVolume();
     ```
