# 社交分享标识说明

聚合链接常常会被分享在社交应用和网站上，您可以通过指定聚合链接的社交分享标识来让您的聚合链接以更加友好的方式在社交应用和网站上展示。这些分享标识会传递到支持聚合链接的社交应用和网站，这些社交应用和网站会使用这些标识来实现更加丰富的呈现效果。社交应用可以使用分享标识来将聚合链接呈现为卡片，包括卡片标题、说明和预览图片。
