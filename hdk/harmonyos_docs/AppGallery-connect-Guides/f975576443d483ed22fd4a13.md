# 渠道包信息管理

#### 新增渠道包信息

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的应用"。
2. 选择已上架的应用，进入"分发"页面。
3. 在左侧菜单栏选择"渠道包管理"，在"测试渠道包"页面点击"新增"。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115013.64131551595327425499288241776600:50531125054745:2800:FF64AC20DFDEA332AC65460302705348C5AA8C23076B5BD5A2D4A02644F4E836.png?needInitFileName=true?needInitFileName=true)

4. 按要求填写渠道包名称、包内渠道编码和备注，并点击"提交"：
   * 支持批量新增渠道包信息。
   * 同一个应用下渠道包名称、包内渠道编码不可重复。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115013.48786920451803281122480641189335:50531125054745:2800:D746A135075C21611DB21B86FB0BCFD92EA85C1F2BA8F9A5C5B4BC9D9061342E.png?needInitFileName=true?needInitFileName=true)  
   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115013.05931069868704309684980747405546:50531125054745:2800:F742E5FC4F7DBA762E1424197CBCA18769818243122507F268B89A1B59B2BB37.png?needInitFileName=true?needInitFileName=true)  
若主包审核不通过，则渠道包需等主包审核通过后才进入人工审核阶段。  

#### 查询渠道包信息

新增"测试渠道包"信息后，可输入如下查询条件查询渠道包：渠道包名称、包内渠道编码。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115013.65090184421272194253886705204281:50531125054745:2800:F71415A2271D93D097D714211301F5FC13B98BA42FE67B8E9E20A4DF598499BE.png?needInitFileName=true?needInitFileName=true)  

#### 修改渠道包信息

新建"测试渠道包"信息后，可点击操作栏中的"修改"再次编辑渠道包名称、包内渠道编码和备注（可选）。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115013.50818681719034602175475378093155:50531125054745:2800:C61A9067607450FFD5426430D41EBA171014F07717D7CA4E4E34888A0A66B21B.png?needInitFileName=true?needInitFileName=true)  

#### 删除渠道包信息

仅当"软件包管理"中没有软件包时可以删除渠道包信息，点击"删除"并确认后记录被删除。
