# 元数据管理

文件元数据包含云端文件名、文件大小、文件类型等常用属性，也包括用户自定义的文件属性。

在上传文件前或者文件上传到云端后，您都可以设置文件的自定义属性。

文件保存到云端后，您可以在下载文件实体前获取文件的元数据，来决定是否要下载文件。

## 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[初始化存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-initialize-bucket-harmony-java-0000001491122784)。

## 设置元数据

1. 调用[AGCStorageManagement.getStorageReference](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-storage-agcstoragemanagement-0000001545702281#section9635163510919)创建文件的引用，并初始化文件的[FileMetadata](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-storage-filemetadata-0000001545422341)实例。

   ```screen
   "Java"
   StorageReference reference = storageManagement.getStorageReference("images/demo.jpg");
   FileMetadata attribute = new FileMetadata();
   attribute.setContentType("image/jpeg");
   attribute.setCacheControl("no-store");
   attribute.setContentDisposition("attachment;filename=demo.jpg");
   attribute.setContentEncoding("identity");
   attribute.setContentLanguage("en-US");
   ```

2. 调用[FileMetadata.setCustomMetadata](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-storage-filemetadata-0000001545422341#section12686485503)设置文件的自定义属性。 说明
   >
   > 为了保证文件上传下载时的数据一致性，上传文件时可以使用[setSHA256Hash](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-storage-filemetadata-0000001545422341#section9484324205013)方法设置文件SHA256值。
3. 调用[StorageReference.updateFileMetadata](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-storage-storagereference-0000001494662550#section147471429291)采用覆盖的方式将设置的文件元数据覆盖到云端。

   ```screen
   "Java"
   HarmonyTask<FileMetadata> metaTask = reference.updateFileMetadata(attribute);
   FileMetadata metadata = HarmonyTasks.await(metaTask);
   ```

## 获取元数据

1. 调用[AGCStorageManagement.getStorageReference](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-storage-agcstoragemanagement-0000001545702281#section9635163510919)创建文件的引用。

   ```screen
   "Java"
   StorageReference reference = storageManagement.getStorageReference("images/demo.jpg");
   ```


2. 调用[StorageReference.getFileMetadata](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-storage-storagereference-0000001494662550#section2653103111284)方法获取包含文件元数据的[FileMetadata](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-storage-filemetadata-0000001545422341)实例。
3. 通过[FileMetadata](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-storage-filemetadata-0000001545422341)的相关属性获取存储实例名、文件创建时间、文件最近修改时间、云端文件名、文件大小、文件类型、文件自定义属性等。

   ```screen
   "Java"
   HarmonyTask<FileMetadata> metaTask = reference.getFileMetadata();
   FileMetadata metadata = HarmonyTasks.await(metaTask);
   Long size = metadata.getSize();
   String contentType = metadata.getContentType();
   ```
