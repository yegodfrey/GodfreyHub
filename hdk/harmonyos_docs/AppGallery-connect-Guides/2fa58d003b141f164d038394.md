# 下载文件

文件上传到云端后，您可以通过调用云存储SDK的API将云端文件下载到本地设备中。  

#### 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[初始化存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-initialize-bucket-harmonyos-ts-0000001678555281)。
* 您已通过认证服务登录应用。
* 您已[上传文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-upload-harmonyos-ts-0000001629995600)。  

#### 操作步骤

1. 调用[Storage.download](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-storage-storage-0000001679582393#section012312924313)方法，通过指定云端文件的路径和本地存储的路径，将该文件下载到本地存储。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240821163312.82085005754961697140585472322911:50001231000000:2800:48D229D713CA96A322A2BF8AC5C0440D15080A3EE6C3C43E04527B8AD334B167.png?needInitFileName=true?needInitFileName=true)  
   目前仅支持下载到文件的应用沙箱路径。  

   ```
   // 1. 从云端下载
   let downResult = await storage.download({
       localPath: localPicPath, //指定本地存储的路径
       cloudPath: "image/demo.jpg",
       onDownloadProgress: (p: ProgressEvent) => {
           console.log(`onDownloadProgress:bytes:${p.loaded} total:${p.total}`)
       }
   })
   // 2. 打印下载结果
   console.log(`bytesTransferred:${downResult.bytesTransferred} totalByteCount:${downResult.totalByteCount}`)
   ```

#### 更多信息

除了在应用客户端通过云存储SDK的API来下载文件，您还可以直接[在AGC控制台以可视化的方式来下载文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-manage-file-0000001281134398#section116002011710)。
