# 业务介绍

您可以通过应用下载直达提供的分发小站功能，来分发您想要推广的应用。首先在AGC控制台添加您的应用成为小站应用，然后通过API接口获取专属链接，并将链接下发到小站应用的展示位中。用户点击展示位后，即可以跳转至华为应用市场应用详情页下载安装。通过API接口获取的链接，具备更优质的体验和归因能力。

#### 整体流程

|序号|步骤|详情|
|:-|:--------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------|
|1|[新增小站应用](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agdstation-addapplication-0000001150168644)|您需要在AGC控制台将您的应用申请成为小站应用，并设置小站的下载安装方式。|
|2|[API对接](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agdstation-apicalling-0000001150113870)|您的小站申请通过后即可调用API接口获取链接，同时自行完成接口对接和联调上线。|
|3|[查看报表](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agdstation-report-0000001150273690)|您可以在AGC中查看应用分发后的结果数据。|
