# 预置云数据库的数据

1. 在"开发与服务"页面找到需要部署云数据库的项目并点击。
2. 选择"云开发（Serverless） > 云数据库"，点击"数据"页签，选择存储区为"raffle"及对象类型。 不同对象类型中包含的数据字段如下：

   * t_raffle_award：奖品信息

     |字段名称|类型|主键|非空|加密|默认值|字段说明|
     |:----------|:-----------|:-|:-|:-|:--|:----------------------------------------|
     |id|VARCHAR(32)|√|√|--|--|奖品ID。 此ID的生成算法为UUID算法。|
     |name|VARCHAR(128)|--|--|--|--|奖品名称。|
     |type|TINYINT(4)|--|--|--|--|奖品类型，枚举值如下： * 实物：1 * 虚拟：2|
     |pic_url|VARCHAR(256)|--|--|--|--|奖品展示图URL。|
     |level|TINYINT(4)|--|--|--|--|奖品等级。例如三等奖。|
     |day_limit|INT(11)|--|--|--|--|奖品日中奖上限（预留）。|
     |probability|DOUBLE|--|--|--|--|中奖概率，百分比（0.01-99.99），如12.34表示中奖概率为12.34%。|
     |remain|INT(11)|--|--|--|--|奖品池中剩余数量。|
     |quantity|INT(11)|--|--|--|--|奖品总数量。|
     |campaign_id|VARCHAR(32)|--|--|--|--|活动ID。|
     |special_id|VARCHAR(64)|--|--|--|--|指定中奖账号（预留）。|
     |remark|VARCHAR(256)|--|--|--|--|备注。|

   * t_raffle_campaign：抽奖活动信息

     |字段名称|类型|主键|非空|加密|默认值|字段说明|
     |:----------|:------------|:-|:-|:-|:--|:-------------------------|
     |id|VARCHAR(32)|√|√|--|--|活动ID。 此ID的生成算法为UUID算法。|
     |type|TINYINT(4)|--|--|--|--|活动类型。值为1时代表抽奖活动。|
     |name|VARCHAR(128)|--|--|--|--|活动名称。|
     |theme|VARCHAR(128)|--|--|--|--|活动主题。|
     |style|INT(11)|--|--|--|--|风格样式，枚举值如下： * 九宫格：1 * 转盘：2|
     |startTime|DATETIME|--|--|--|--|活动开始时间。|
     |endTime|DATETIME|--|--|--|--|活动结束时间。|
     |description|VARCHAR(2048)|--|--|--|--|活动描述。|
     |limit_times|INT(11)|--|--|--|--|每个用户可抽奖次数。|
     |win_limit|INT(11)|--|--|--|--|每个用户可中奖次数上限。|

   * t_raffle_participation：参与人信息

     |字段名称|类型|主键|非空|加密|默认值|字段说明|
     |:---------------|:-----------|:-|:-|:-|:--|:---------------------|
     |id|VARCHAR(32)|√|√|--|--|唯一标识。 此ID的生成算法为UUID算法。|
     |campaign_id|VARCHAR(32)|--|--|--|--|活动ID。|
     |user_id|VARCHAR(64)|--|--|--|--|用户ID。|
     |user_name|VARCHAR(128)|--|--|√|--|参与人姓名（预留）。|
     |participate_time|DATETIME|--|--|--|--|参与时间。|

   * t_raffle_win_record：参与人中奖信息

     |字段名称|类型|主键|非空|加密|默认值|字段说明|
     |:--------------|:------------|:-|:-|:-|:--|:------------------------------------------|
     |id|VARCHAR(32)|√|√|--|--|中奖记录标识。 此ID的生成算法为UUID算法。|
     |user_id|VARCHAR(64)|--|--|--|--|中奖账号。|
     |campaign_id|VARCHAR(32)|--|--|--|--|活动ID。|
     |award_id|VARCHAR(32)|--|--|--|--|奖品ID。|
     |win_time|INT(11)|--|--|--|--|中奖时间。|
     |receiver|VARCHAR(128)|--|--|√|--|领奖人姓名（预留）。|
     |receiver_phone|VARCHAR(64)|--|--|√|--|领奖人电话（预留）。|
     |receiver_addr|TEXT|--|--|√|--|领奖人地址（预留）。|
     |send_time|DATETIME|--|--|--|--|发奖时间（预留）。|
     |receive_status|TINYINT(4)|--|--|--|--|领取状态，枚举值如下： 未领取（未过期）：1 未领取（已过期）：2 已领取（预留）：3|
     |receive_time|DATETIME|--|--|--|--|领取时间（预留）。|
     |receiver_remark|VARCHAR(2048)|--|--|√|--|领奖人备注（预留）。|

3. 选择以下两种方式中的一种新增数据：
   * 单条新增：点击"新增"，按对象类型逐字段新增。
   * 批量新增：导出对应对象类型json后，在"raffle_t_raffle_award_example.json"和"raffle_t_raffle_campaign_example.json"文件中填写数据后导入。具体导入json文件操作请参见[云数据库-导入本地数据](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-clouddb-agcconsole-managingdata-0000001080975864#section6547202316247)。 说明
     >
     > "raffle_t_raffle_award_example.json"和"raffle_t_raffle_campaign_example.json"文件有部分样例数据，请基于样例数据进行填写数据。
4. 根据您在部署模板时的[配置参数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-serverless-lottery_deploy_template-0000001256531726#ZH-CN_TOPIC_0000001256531726__p76726347207)不同，抽奖H5页面的加载方式区分如下：
   * 如果您已配置"认证回调URL"且需要认证，则需要执行如下操作。 说明
     > * 请务必实现[获取用户ID](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agc-serverless-comm-api-obtainuserid-0000001260291838)接口获取用户ID，保证抽奖活动的安全性。
     > * 当前此URL仅能配合此模板的工程包配套使用，不可单独使用。

     按照如下规则在APP内加载抽奖H5页面URL，加载前需要将accessToken写入SessionStorage。写入的accessToken的格式应如：luckydraw_access_token=eyJhbGciOiJIUzU****************，用于获取用户ID进而正常访问抽奖页面。

     ```screen
     //九宫格样式抽奖页面url
     ${hosting-url}/#/ninegrid?campaignId=${campaignId}
     //转盘样式抽奖页面url
     ${hosting-url}/#/turntable?campaignId=${campaignId}
     ```

     其中，hosting-url为云托管部署后的站点域名，campaignId为t_raffle_award中的活动ID。


   * 如果您未配置"认证回调URL"且无需认证，则需要执行如下操作。 按照如下规则在APP内加载抽奖H5页面URL。

     ```screen
     //九宫格样式抽奖页面url
     ${hosting-url}/#/ninegrid?campaignId=${campaignId}&userId=${userId}
     //转盘样式抽奖页面url
     ${hosting-url}/#/turntable?campaignId=${campaignId}&userId=${userId}
     ```

     其中，hosting-url为云托管部署后的站点域名，campaignId为t_raffle_award中的campaign_id，userId为t_raffle_participation中的user_id。
