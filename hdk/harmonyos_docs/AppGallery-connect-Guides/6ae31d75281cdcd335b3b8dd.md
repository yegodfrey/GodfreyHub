# 获取经过反混淆处理的崩溃报告

当使用ProGuard或DexGuard在编译时将代码中的类名、字段和方法等混淆处理为不可阅读的代码时，您可以通过将混淆Mapping文件上传到AGC的方式获取经过反混淆处理的崩溃报告。

HarmonyOS并不会自动生成对应的混淆Mapping文件，如果您需要生成对应的混淆Mapping文件，需要在您工程的proguard-rules.pro文件里，自行增加一条配置-printmapping mapping.txt；配置完成后，进行编译，生成的mapping.txt文件在路径build/intermediates/proguard-profile下  

#### 前提条件

1. 您需要在AGC控制台[开通崩溃服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-enableservice-0000001326330021)。
2. 您需要在您的应用中[集成崩溃服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-integratesdk-harmonyos-0000001276400112)。  

#### 手动上传

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155613.90896459987618935846772013997656:50001231000000:2800:63F5C61AF0A07228A0B3A422E22C27EC751E388F2316C7CB8F7DF22098DDCD12.png)  
只有已经上报崩溃问题的应用才支持手动上传混淆Mapping文件。

1. 在您的工程中配置并生成混淆Mapping文件。HarmonyOS并不会自动生成对应的混淆Mapping文件，需要在您工程的proguard-rules.pro文件里，添加如下混淆配置：

   ```
   -printmapping mapping.txt
   ```

   配置完成后，进行编译，会在路径build/intermediates/proguard-profile文件夹下生成Mapping文件。
2. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
3. 在项目列表中找到您的项目，在项目下的应用列表中点击您的应用。
4. 点击"质量 \> 崩溃"，进入崩溃服务的页面。
5. 选择"映射文件 \> 混淆Mapping文件"，点击需要上传混淆Mapping文件的应用版本对应的"上传"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155613.77351161754642491026518063261323:50001231000000:2800:3E009150E4A6D6523327B10D660A9A77D253DB76887DE2C0EDA95966BC5569C2.png)

6. 点击弹出框中的![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155613.37889293166956606231052394175486:50001231000000:2800:59ABA9FF743529E8A7A40D15851E68BAC9B81D8EE01939479A687ABCFE8CF3F2.png)，上传混淆Mapping文件。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155613.23457498475479743782286835149550:50001231000000:2800:A3CDB24F69416227CF09D7D4219515DEE76628614E7DD19BAE42715F31256AEE.png)  
   此方式支持上传zip和txt格式的混淆Mapping文件。
   * zip大小不超过8MB，zip中的混淆Mapping文件必须为txt格式，必须放在zip包的根目录下，且根目录下只能包含1个txt的混淆Mapping文件。解压后的大小不超过180MB和60万行。
* txt大小不超过10MB和60万行，超过10MB需压缩后上传，两次上传的间隔应大于60秒。  

#### 分析崩溃问题

崩溃问题发生上报后，您即可在AGC上查看和分析崩溃问题，具体操作请参考[分析崩溃问题](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-locate-0000001055140557)。
