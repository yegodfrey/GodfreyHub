# OpenAppInfo

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:-------------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------|
|appId|O|String|应用ID。|
|pkgName|O|String|应用包名。|
|name|O|String|应用名。|
|devId|O|String|开发者ID。|
|developerName|O|String|开发者名称。 最大长度为512。|
|versionName|O|String|应用版本。|
|versionCode|O|Integer (64)|应用版本号。|
|icon|O|String|应用icon地址。|
|size|O|Integer (64)|应用大小。 单位：字节|
|sha256|O|String|应用文件sha256。|
|appSign|O|String|签名。|
|downloadUrl|O|String|应用下载地址。必须为HTTPS地址。 > 注意 > 应用下载地址有效期为7天，建议不要长时间缓存。|
|description|O|String|应用描述。|
|briefInfo|O|String|一句话描述。|
|recommImg|O|String|推荐大图地址。 最大长度为512。|
|releaseDate|O|String|发布时间。 精确到天。 格式：*yyyy-MM-dd*|
|rateNum|O|Integer|应用评分次数。|
|stars|O|Number|评分。|
|privacyUrl|O|String|隐私政策。|
|minAge|O|Integer|最小年龄。|
|permission|O|List<[AppPermission](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/adx_dsp_api_apppermission-0000001267148173)>|应用权限信息。|
|screenShotInfo|O|List<[ScreenShotInfo](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/adx_dsp_api_screenshotinfo-0000001267388157)>|应用截图信息。|
|introVideos|O|List<[AppVideoInfo](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/adx_dsp_api_appvideoinfo-0000001267268149)>|视频信息。|
|appKinds|O|List<[AppKindInfo](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/adx_dsp_api_appkindinfo-0000001223147978)>|应用分类信息。|
|downloadInfo|O|List<[DownloadInfo](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/adx_dsp_api_downloadinfo-0000001222988398)>|下载信息。|
