# 保障文件安全

## 匹配路径

云存储安全规则通过匹配确切路径或者通配符路径，来确定被授权的用户可以访问哪些路径下的文件，从而实现对您文件的保护。

### 完全匹配

如文件路径与安全规则中定义的路径完全匹配，则允许访问：

```screen
// 安全规则声明
agc.cloud.storage[
    // 匹配images路径下的特定的文件
    match: /{bucket}/images/image.jpg{
        allow read, write:  if true;
    }
]
```

### 通配符匹配

如果您要将规则应用于任意深度（受限于目录文件的总长度）的层次结构，请使用通配符语法{path=**}。例如：

```screen
agc.cloud.storage[
    match: /{bucket}/images/{path=**} {
        allow read, write:  if true;
    }
]
```

使用通配符语法时，通配符变量将包含整个匹配的路径段，即使相应文件位于多层嵌套的子路径中也是如此。例如，上面列出的规则将与images/jpg/demo.jpg中的文件匹配，匹配后path的值将是jpg/demo.jpg。

### 重叠语句匹配

某个文件可以与多个match语句匹配，如果有多个allow表达式与某个请求匹配，则只要任意一个条件为true，就允许访问：

```screen
agc.cloud.storage[
    match: /{bucket}/images/{image} {
        allow read, write:  if false;
    }
    // 因第二个match始终为true，则系统允许images下的所有读写操作，即便第一个match始终为false
    match: /{bucket}/images/{path=**} {
        allow read, write:  if true;
    }
]
```

同时某个文件与一个match内多个allow匹配，如果有多个allow表达式与某个请求匹配，则只要任何一个条件为true，就允许访问：

```screen
agc.cloud.storage[
    match: /{bucket}/images/{path=**} {
        // 因第二个规则始终为true，则系统允许images下的所有写操作，即便第一个规则始终为false
        allow update:  if false;
        allow write:  if true;
    }
]
```
