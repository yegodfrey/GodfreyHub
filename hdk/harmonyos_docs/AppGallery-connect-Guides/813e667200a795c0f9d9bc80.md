# 成功案例

#### 需求背景

《CAD建模号》是上海模宗软件有限公司旗下App，是一款用于移动设备的专业3D建模工具。在使用过程中，应用需要为用户提供快捷高效的上传下载删除等文件操作功能，同时要对用户的订单数据、订单操作进行记录和管理，这都需要占用大量的服务器存储空间，从成本和资源角度考虑投入巨大，并且费时费力。  

#### 案例效果

公司研发团队决定接入云数据库和云存储两个服务。云存储服务提供简单易用、功能强大的端/云SDK，实现用户生成内容的存储，而云数据库服务能够提供安全可信的数据管理服务，更有免运维，弹性伸缩等优势，让开发者聚焦代码开发。在传统开发中，分布式高可用后端系统+弹性伸缩......+后端开发团队+运维团队等一系列工作，大约需要50人天＋工作量，而基于Serverless开发，集成SDK+云函数托管代码+免运维则大约需要3人天的工作量。两种服务搭配使用，将开发工作量降到了最低，获得了更好的服务效果。
