# 查询已订阅频道列表

当订阅若干频道后，可通过查询已订阅的频道列表信息，查看频道的订阅情况。  

#### 前提条件

* 您已[集成游戏多媒体基础SDK和实时信令模块](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-integratingsdk-android-0000001250838246#ZH-CN_TOPIC_0000001250838246__li733912204487)。
* 您已[创建游戏多媒体实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-engine-android-0000001193958984#section1093713161034)。  

#### 开发步骤

调用[GameMediaEngine.getRtmSubscribedChannelInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section74162538569)方法，即可查询当前已订阅的所有频道列表。

```
GetSubscribedChannelInfoResult result = mHwRtcEngine.getRtmSubscribedChannelInfo()
```
