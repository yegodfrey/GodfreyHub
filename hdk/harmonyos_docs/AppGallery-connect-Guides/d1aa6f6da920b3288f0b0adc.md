# 使用数据库的其他操作

#### 写入数据

您可以通过[executeUpsert()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-quickgame-0000001128787910#section17755153212411)将一个或者一组对象写入到当前存储区中。在写入对象时，如果在存储区已经存在主键值相同的对象，则更新已有的对象；如果不存在，则写入一个新的对象。写入的数据可以来自于新建对象，或者从存储区查询出来的对象。

写入一组对象时，数据的写入操作是原子的，即对象列表中的对象要么全部成功写入，要么全部失败。

调用写入数据方法后，会返回一个Promise对象，对象中封装了写入操作执行的结果。通过该Promise对象可以异步侦听执行结果：如果执行成功，可以获取写入的对象数量；如果执行失败，可以获取错误信息。

注意事项：  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250714155514.94610785678059506331764240662279:50001231000000:2800:F8739A0A663530731BD85D45D8132EB837C1F1BAF55065590AF752F1BA06FF53.png)  
请先关注注意事项。

* 仅当存储区为打开状态时，才可以进行写入对象操作，否则会导致写入失败。
* 写入一组对象时，该组中的对象必须属于同一个对象类型，否则会导致写入失败。
* 写入一组对象时，数据总大小不能超过2MB，否则会导致写入失败。
* 写入一组对象时，数据总条数不能超过1000条，否则会导致写入失败。

代码示例：

将BookInfo对象写入至存储区中，写入成功后，返回写入的数量；写入失败，抛出异常。

```
async function executeUpsert (book) {
	try {
		const cloudDBZoneResult = await cloudDBZone.executeUpsert(book);
		console.log('upsert' + cloudDBZoneResult + 'record' );
		return cloudDBZoneResult;
	} catch (e) {
		console.log(e);
	}
}
```

#### 查询数据

云数据库通过[executeQuery()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-quickgame-0000001128787910#section1894919381041)方法查询对象，并提供了丰富的谓词查询，比如equalTo()、notEqualTo()、in()等。通过单个或者多个链式过滤条件，您可以从存储区查询到满足特定条件的对象，也可以通过排序谓词对查询结果排序，或者通过限定查询返回数量谓词限定查询结果返回的数量。详细的查询条件请参见[CloudDBZoneQuery](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-quickgame-0000001174747733)。

应用会直接从云侧存储区服务器查询数据，本地不会缓存数据。

根据查询结果返回的CloudDBZoneSnapshot对象获取存放在该对象里的数据，更多请参见[CloudDBZoneSnapshot](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonesnapshot-quickgame-0000001128787912)。

注意事项：  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250714155514.24681230929256669063064082122561:50001231000000:2800:EEB94F1720ABB952BB194E6EDA41DE6F3004FDDA148F3C9EBA4BF4F61C072E91.png)  
请先关注注意事项。

* 仅当存储区为打开状态时，才可以进行查询对象操作，否则会导致查询失败。
* 每次的查询操作仅支持查询一个对象类型下的数据。  

#### 简单查询

您可以在无查询条件时，获取一个对象类型中所有的对象；也可以指定单个查询条件，来获取满足该条件的对象。

* 查询对象类型BookInfo的所有数据。

  ```
  async function executeQueryAllBooks() {
      try {
          const query = CloudDBZoneQuery.where(BookInfo);
          const snapshot = await cloudDBZone.executeQuery(query);
          const resultArray = snapshot.getSnapshotObjects();
          console.log(resultArray);
      } catch(e) {
          console.log(e);
      }
  }
  ```

* 通过异步侦听的方式查询"bookName"为"左传"的书籍。
  * 构造查询方法executeQuery，该方法同时供后续查询示例引用。

    ```
    async function executeQuery (cloudDBZoneQuery)  {
    	try {
                 const snapshot = await cloudDBZone.executeQuery(cloudDBZoneQuery);
    	     const resultArray = snapshot.getSnapshotObjects();
    	     console.log(resultArray);
    	} catch (e) {
    		console.log(e);
    	}
    }
    ```

  * 构造查询条件，并调用executeQuery方法，获取查询数据。

    ```
    const query = CloudDBZoneQuery.where(BookInfo).equalTo('bookName', '左传');
    executeQuery(query);
    ```

#### 复合查询

您可以通过多个链式过滤条件，来获取满足条件的对象。多个链式条件之间默认用"与"运算。

* 构造查询条件，并调用executeQuery方法，查询"bookName"包含"数据库"，"price"大于20.0并且小于50.0的书籍。

  ```
  const query = CloudDBZoneQuery.where(BookInfo).contains('bookName', '数据库').greaterThan('price', 20.0).and().lessThan('price', 50.0);
  executeQuery(query);
  ```

* 构造查询条件，并调用executeQuery方法，查询"bookName"包含"数据库"，"price"在小于20.0或者大于50.0区间的书籍。

  ```
  const query = CloudDBZoneQuery.where(BookInfo).contains('bookName', '数据库').lessThan('price', 20.0).or().greaterThan('price', 50.0);
  executeQuery(query);
  ```

* 构造查询条件，并调用executeQuery方法，查询"bookName"包含"史记"，"author"是"司马迁"，"price"大于60.0的书籍。

  ```
  const query = CloudDBZoneQuery.where(BookInfo).contains('bookName', '史记').equalTo('author', '司马迁').greaterThan('price', 60.0);
  executeQuery(query);
  ```

* 构造查询条件，并调用executeQuery方法，查询"bookName"包含"自传"，并且"author"是"齐白石"，或者"author"是"司马迁"，并且"price"大于60.0的书籍。

  ```
  const query = CloudDBZoneQuery.where(BookInfo).contains('bookName', '自传').beginGroup().equalTo('author', '齐白石').or().equalTo('author', '司马迁').endGroup().greaterThan('price', 60.0);
  executeQuery(query);
  ```

#### 查询数据平均值

您可以通过[executeAverageQuery()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-quickgame-0000001128787910#section748416563413)方法查找满足特定条件的对象，并计算这些对象中指定字段的平均值。

查询所有书籍的价格平均值。

```
const query = CloudDBZoneQuery.where(BookInfo);
const average = await cloudDBZone.executeAverageQuery(query, 'price');
console.log(average);
```

#### 数据排序

您可以通过[orderByAsc()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-quickgame-0000001174747733#section510510507712)或者[orderByDesc()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-quickgame-0000001174747733#section4831175212713)实现对查询结果集中的对象按某个字段进行升序或者降序排列。

使用[orderByAsc()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-quickgame-0000001174747733#section510510507712)或者[orderByDesc()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-quickgame-0000001174747733#section4831175212713)对字段进行排序时，建议针对排序的字段创建索引，否则，当该对象类型的数据量达到一定条数时，可能因为查询效率低引起查询超时或失败，影响用户体验。创建索引请参见[新增对象类型](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-sdk-integration-quickagame-0000001518866288#section105953115325) ，创建索引后，您还需要更新本地的对象类型文件，详细请参见[加载对象类型文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-sdk-integration-quickagame-0000001518866288#section192316348356)。

对查询结果中的对象进行排序时，排序谓词需要在其它查询谓词之后且在限定数据查询数量谓词之前。

构造查询条件，并调用executeQuery方法，查询所有价格小于50.0的书籍，并且按降序排列。

```
const query = CloudDBZoneQuery.where(BookInfo).lessThan('price', 50.0).orderByDesc('price');
executeQuery(query);
```

#### 限定数据查询返回数量

在查询数据时，您可以通过[limit()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-quickgame-0000001174747733#section195251849262)限定查询返回数据的起始位置和数量，实现数据的分页。例如与排序查询谓词组合使用，可以实现获取top-N条数据。

对查询结果中的对象限定查询返回数量时，限定数据查询返回数量谓词在所有其它谓词查询之后。

* 构造查询条件，并调用executeQuery方法，查询所有价格小于50.0的书籍，并且只显示最开始10条记录。

  ```
  const query = CloudDBZoneQuery.where(BookInfo).lessThan('price', 50.0).limit(10);
  executeQuery(query);
  ```

* 构造查询条件，并调用executeQuery方法，查询所有价格小于50.0的书籍，并将查询结果按照降序排序，只显示价格排序从第6条开始的10条记录。

  ```
  const query = CloudDBZoneQuery.where(BookInfo).lessThan('price', 50.0).orderByDesc('price').limit(10, 6);
  executeQuery(query);
  ```

#### 查询服务器状态

您可以调用CloudDBZone类中的[executeServerStatusQuery()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-quickgame-0000001128787910#section1324185773018)方法查询服务器状态，返回ServerStatus对象，对象中封装了云侧服务器当前时间戳。

```
const serverStatus = await cloudDBZone.executeServerStatusQuery();
console.log('serverTimestamp=' + serverStatus.serverTimestamp);
```

#### 删除数据

您可以通过[executeDelete()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-quickgame-0000001128787910#section137618361416)删除单个对象或者一组对象。删除数据时，云数据库会根据传入对象主键删除相应的数据，不会比对该对象其它属性与存储的数据是否一致。删除一组对象时，删除操作是原子的，即对象列表中的对象要么全部删除成功，要么全部删除失败。

注意事项：  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250714155514.23805832178532045879601809341194:50001231000000:2800:B78F374F7778C6BAD92B7360995C22D6566F2A6847C8E0A3E9BC44C5AAE6BE39.png)  
请先关注注意事项。

* 仅当存储区为打开状态时，您才可以进行删除对象操作，否则会导致删除失败。
* 删除一组对象时，该组中的对象必须属于同一个对象类型，否则会导致删除失败。

代码示例：  
将对象删除，如果删除成功，返回删除对象的个数；执行失败，抛出异常。

```
async function executeDelete (book) {
	try {
		const num = await cloudDBZone.executeDelete(book);
		console.log(num)
	} catch (e) {
		console.log(e);
	}
}
```

#### 管理存储区

存储区是一个数据存储区域，每个存储区互相独立，之间的数据没有关联。一个云数据库实例中可以创建多个存储区。

一个存储区内可以定义多个对象类型，支持不同的业务需求。每个存储区拥有完全相同的对象类型定义，您可以根据应用的需要自定义存储区中存储的对象。

如果您不再使用某个存储区，可将其暂时关闭。

注意事项：  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250714155514.71154636872254577241527247755426:50001231000000:2800:34A8C2B3AA2BE83BC8563195A743E2E43A79E8C0D0F2C686647FE57C6DF29EA8.png)  
操作前，请先关注注意事项。

* 打开一个存储区后，才能对该存储区进行相关数据操作。
* 可以多次打开某个存储区，但在使用完存储区后，都需要关闭该存储区，即每个打开操作需要一个对应的关闭操作。

代码示例：

* 打开一个存储区。

  ```
  async function openCloudDBZone () {
  	try {
  		const config = new CloudDBZoneConfig('QuickStartDemo');
  		cloudDBZone = await agcCloudDB.openCloudDBZone(config);
  		console.log('open zone success ::' + cloudDBZone);
  	} catch (e) {
  		console.log('open zone fail');
  		console.log(e);
  	}
  }
  ```

<!-- -->

* 关闭存储区。

  ```
  mCloudDB.closeCloudDBZone(cloudDBZone );
  ```

#### 管理版本升级

应用版本升级时，可在AGC控制台上导出对应版本文件，添加至本地开发环境。并通过调用AGConnectCloudDB类中的[createObjectType()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agconnectclouddb-quickgame-0000001128628118#section10644219429)实现新对象类型的创建，调用[openCloudDBZone()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agconnectclouddb-quickgame-0000001128628118#section1366119221121)打开指定存储区，完成对象类型版本的升级。
