# 上架申请

## 了解上架规则

开发者完成集成服务，提交应用上架前，请先了解如下上架规则和审核常见问题：

* [华为应用市场上架审核指南](https://developer.huawei.com/consumer/cn/doc/50104)

* [应用审核FAQ](https://developer.huawei.com/consumer/cn/doc/app/50106)

## 提交上架申请

开发完成后需要在AppGallery Connect中将应用信息补充完整并提交上架申请，具体操作请参考[发布应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-release-overview-0000001272395372)。

需要注意的是，如果您需要用户在下载应用时就需要付费，发布应用时需要将应用的"付费情况"设置为"付费"，并设置是否加入AppTouch会员服务、默认展示的货币及应用的价格。
> 注意
>
> * 游戏应用的包名必须要以.huawei结尾或使用与其他市场不同的签名，否则会审核不通过。这样做的目的是避免跟其他市场混乱，导致用户在不同市场的付费app相互覆盖后无法使用。
> * 如果付费应用的包名做了修改，将无法继续使用主包的第三方登录体系，请修改包名后，务必重新申请开通第三方登录系统。
> * 请开发者对付费应用做加固处理，防止盗版。
> * 建议在应用的关键关卡或定时检测付费鉴权，以防止用户跳过付费检查。
> * 提交审核前，若有国家/地区币种发生变更，您需根据界面提示重新设置价格，否则将无法保存价格信息。
