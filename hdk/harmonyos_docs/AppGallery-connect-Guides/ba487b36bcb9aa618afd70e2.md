# 将传统微服务快速转化成Serverless云函数

通常传统微服务可能涉及很多接口，且这些接口可能涉及多种语言开发。Custom Runtime支持多种不同语言，目前Node.js、Java和Python三种语言可以完美支持，而其他语言也可以通过安装第三方解释器来支持。所以，我们可以将一个微服务转换为一个Custom Runtime的云函数，即可打破传统服务开发语言的限制。

本实践我们将以一个java微服务为例，介绍如何将它快速转换为一个Custom Runtime的云函数。

对于云函数，每一个Custom Runtime的函数都只提供了一个入口，就是invoke。所以我们改造的第一步就是在微服务中创建一个入口函数invoke。

1. 微服务中添加入口函数invoke。

```screen
@RequestMapping(path = "/invoke", method = RequestMethod.POST)
public Object postSimple(HttpServletRequest req, @RequestBody JSONObject body)
```

在此示例代码中的入口函数包含两个入参，第一个是HTTP的参数，另一个是调用方传入的参数。函数可以通过不同的触发器来触发，入参也是通过触发器传入的。通过传入的参数，就可以在方法中将指令分发到不同的逻辑。例如在调用函数时，传入想要调用的方法名和入参，在invoke函数中通过传入的方法名去调对应的微服务接口。

详细示例代码如下：

```screen
package com.example.demo;

import com.alibaba.fastjson.JSONObject;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestMethod;
import org.springframework.web.bind.annotation.RestController;

import javax.servlet.http.HttpServletRequest;
import java.util.HashMap;
import java.util.Map;

@SpringBootApplication
@RestController
public class Application {
    private static final Logger LOG = LoggerFactory.getLogger("com.huawei.customedemo");

    public static void main(String[] args) {
        LOG.info("start spring server now!");
        try {
            ClasspathLoader.loadClassPath();
        } catch (MyException e) {
            LOG.error("failed to load layer " + e.getMessage());
        }
        SpringApplication.run(Application.class, args);
    }

    @RequestMapping(path = "/invoke", method = RequestMethod.POST)
    public Object postSimple(HttpServletRequest req,  @RequestBody JSONObject body) {
        // example of display environment variables
        String env = System.getenv("env1");

        // example of display logs
        LOG.info("Test info log");
        LOG.warn("Test warn log");
        LOG.debug("Test debug log");
        LOG.error("Test error log");

        LOG.info("----------Start-----------");
        JSONObject result = new JSONObject();
        result.put("code", 0);
        try {
            long interval;
            long startTime = System.currentTimeMillis();

            LOG.info("receive post request");
            String query=req.getQueryString();
            String hwm=req.getHeader("hwm");
            Map<String,String[]> params =req.getParameterMap();
            String config=PropertyUtil.getProperty("key.rootkey.path");

            LOG.info("query :"+query);
            LOG.info("headers :"+hwm);
            LOG.info("params :"+JSONObject.toJSONString(params));
            LOG.info("body :"+body.toJSONString());
            LOG.info("config :"+config);

            long endTime = System.currentTimeMillis();
            interval = endTime - startTime;
            LOG.info("intervalTime: " + interval + "(ms)");
            result.put("intervalTime: ", interval + "(ms)");
            LOG.info("--------Finished---------");
        } catch (Exception e) {
            LOG.error("the ex is " + e.getMessage());
            result.put("msg", e.getMessage());
        }
        return result ;
    }
}
```

至此，您的微服务就顺利改造成Serverless云函数。接下来，您就可以通过云函数不同的触发器去调用函数，主要有两种触发方式：

* [通过不同SDK主动触发](#ZH-CN_TOPIC_0000001460687950__p13134323192416)
* [通过HTTP直接访问](#ZH-CN_TOPIC_0000001460687950__p1335901714912)

【通过不同SDK主动触发】

云函数提供了Android、IOS、JS、Harmony等多种平台的前端SDK。另外，还有Java和Node.js的Server SDK，可以满足您在不同端调用云函数的诉求。无论是端侧还是云侧SDK，都可以通过创建HTTP触发器来打通SDK与云函数的互联。
