# 发布实验

#### 自动发布

如素材更新实验的生效方式选择的是"审核通过立即生效"，实验一旦审核通过即自动发布，新素材立即上架生效。  

#### 手动发布

如素材更新实验的生效方式选择的是"审核通过手动生效"，您需执行以下操作进行手动发布：

1. 点击实验名称链接，进入实验详情页面。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250102135806.96712607463700303829367450929063:50001231000000:2800:6A2715D8F72905C8C37875978717C582C2D2D6B54534E08F8D3086C340F5E2ED.png?needInitFileName=true?needInitFileName=true)

   <br />

2. 点击"立即发布"，在提示弹窗点击"确认"即可。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250102135807.60122106285113280885584267853153:50001231000000:2800:4A102C1527E8352EB63076EBD09A4D2C8778A9A3CF3E71F9EFEB97683E744F68.png?needInitFileName=true?needInitFileName=true)

   <br />

3. 发布成功后，"实验结果是否使用"显示为"是"，现网版本的应用详情内容将会替换为实验组的素材内容。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250102135807.56686058027020188261494466228825:50001231000000:2800:5D527F37A494A744766453E417F9709CC8F8B21AB7660A9D7722089BE24D4F88.png?needInitFileName=true?needInitFileName=true)

   <br />

   对于已生效的素材更新实验，您可以点击"操作"列"删除"，删除实验。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250102135807.91536933568467506333526460146702:50001231000000:2800:177C091E0633E2EAADC952BACA1175F9F9B52E0C7615E6EC17544DA55921144A.png?needInitFileName=true?needInitFileName=true)  
如您对全网版本进行了更新、回退或下架操作，则对应该版本的所有素材更新实验将会自动结束。
