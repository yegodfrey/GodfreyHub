# 自定义测试

您可以选择您关注的测试专项，例如兼容性、稳定性、性能、功耗或UX进行测试。系统会默认选择当前最新和热门的机型，帮助您提前发现问题，提升用户侧应用体验。

## 前提条件

* 在使用云测试服务前，请先创建您的项目。
* 请准备好已配置签名的release版本应用包，且不同格式的应用包大小均不得超过4GB。

## 创建测试任务

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击需要测试的项目。
3. 在左侧导航栏选择"质量 > 云测试"，进入云测试主界面。
4. 选择"测试任务"页签，点击"创建测试任务"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/27/v3/miYHZN3aT_q1LfnNNT89Iw/zh-cn_image_0000002625667297.png?HW-CC-KV=V1&HW-CC-Date=20260916T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=5BF23D04362C0BB2F43F557B2CA04DA811F656E01B2F0169958CDD445DF681CA "点击放大")

5. 进入"配置测试任务"页面，在"测试对象"区域，上传新的应用软件包或选择之前已上传的应用软件包，并配置应用分类。
   * 上传新应用测试 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/18/v3/x6Pg89dMS2aeZaAO2YzU8w/zh-cn_image_0000002524151518.png?HW-CC-KV=V1&HW-CC-Date=20260916T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=90D69E7CDE9A542106A4EC5B4C13A4A3DC6B17E7D6538BCC38161C986000B83A)

     |配置项|**说明**|
     |:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
     |选择待测应用|选择"上传新应用"|
     |选择应用|支持安卓（APK/AAB）、HarmonyOS（HAP/APP）、快应用（RPK）应用程序类型。**如果您上传的是HarmonyOS** **应用或元服务软件包** ，**API Level须小于10。** 点击"选择文件"，上传您准备好的应用release包。应用包大小不可超过4GB。 每个开发者账号每天最多支持上传500次，上传成功与否均累计计数。 > 说明 > * 应用软件包格式不同，大小也不同。 > * 当前RPK应用软件包仅支持在华为设备上进行测试。|
     |应用分类|应用类别分三级展示，请根据实际情况配置应用的一级、二级和三级分类。|

   * 对已上传应用测试 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d6/v3/dstFj8KrQdeYWlqeu8SN5g/zh-cn_image_0000002555151991.png?HW-CC-KV=V1&HW-CC-Date=20260916T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=8CDA99179E107FF6D853B00D8C471E60D47BA8BCA665C6A7D24BE1CC5E9C91D4 "点击放大")

     |配置项|**说明**|
     |:-----|:-------------------------------------------------------------------------------------------------------------|
     |选择待测应用|选择"选择已有应用"。|
     |可选应用|应用列表分页展示您已经上传的应用软件包，每页展示15个应用。 可以翻页查找待测应用，也可以在搜索框中输入应用的名称、包名或版本号进行筛选，支持模糊查询。 点击应用列表中某个应用"操作"列的"删除"，可以删除该应用软件包。|
     |应用分类|应用类别分三级展示，请根据实际情况配置应用的一级、二级和三级分类。|

6. 在"测试任务"区域，配置任务名称、测试场景和测试范围。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/39/v3/QBCLthKoQMSSflTNE26UbA/zh-cn_image_0000002524856312.png?HW-CC-KV=V1&HW-CC-Date=20260916T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=48F6687ED48B6A850E9F06827FFDE81B51006305C861597BD06759C0AB208CD8)

   |配置项|**说明**|
   |:------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |任务名称|系统默认以"应用名称+测试场景"预设了任务名称，您可以按需修改。 最长不超过64个字符，只允许输入中文、字母、数字或下划线。|
   |测试场景|选择"自定义测试"。|
   |测试范围|取值范围包括：兼容性测试、稳定性测试、性能测试、功耗测试、UX测试。 "测试范围"配置项的取值，基于您选择的应用软件包类型和测试场景动态刷新： * 当您选择APK/AAB应用软件包和自定义测试场景时，支持的"测试范围"包括：兼容性测试、稳定性测试、性能测试、功耗测试，默认勾选"兼容性测试"，您可以根据需要对测试范围进行勾选或取消勾选操作。 * 当您选择RPK应用软件包和自定义测试场景时，"测试范围"配置项仅支持勾选"兼容性测试"。 * 当您选择API <10的HAP/APP应用软件包和自定义测试场景时，支持的"测试范围"包括：兼容性测试、稳定性测试、性能测试、功耗测试、UX测试，默认勾选"兼容性测试"，您可以根据需要取消勾选"兼容性测试"或勾选其它测试。|
   |单设备测试时长|系统根据您选择的应用包格式、测试范围动态预估单个测试设备的测试时长。 选择"测试范围"后，您可对测试专项配置测试时长。兼容性测试、稳定性测试和性能测试的默认测试时长，由系统根据应用程序包类型预估。自定义测试时长时，需填写10~360之间的整数。功耗测试和UX测试的测试时长不支持修改。 点击"恢复默认设置"可将已修改的测试时长恢复到默认值。 当设定的时间消耗完毕或测试任务提前完成时，系统将终止该测试任务。如果测试实际时长低于设定的测试时长，将以实际测试时长扣减时长额度。|

7. "在预置条件"区域，根据实际情况判断是否需要填写预置条件内容。
   * 如果您的应用需要账号和密码登录后才能正常使用，或者您想在测试过程中自定义某些特定指令，可以参考[预置条件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudtest-preset-0000002154022053)进行配置。配置完成后，点击页面右上角的"下一步"。
   * 如果您的应用不需要账号和密码登录，也不需要自定义特定指令，则无需配置预置条件，直接点击页面右上角的"下一步"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/82/v3/E-NaGVBGQT2LmP1scDcq5w/zh-cn_image_0000002549523185.png?HW-CC-KV=V1&HW-CC-Date=20260916T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=C6BEFAAFF50359E47908C57E11EE6783530CAD84F1FEFF0EFBE602F2E297ED46 "点击放大")
8. 在"选择测试设备"页面，您可以在搜索框中输入机型名称筛选机型，也可以根据设备形态、系统版本、API Level、设备品牌以及我的收藏、是否空闲机型、是否优惠机型等维度筛选您所需的机型。选择完成后，点击右上角的"提交"。 说明
   > * 您账号内的赠送时长仅适用于优惠机型，您可以点击"其他信息"过滤项的"优惠机型"，筛选出带有"优惠"标识的设备。
   > * 当您选择多台设备同时进行测试时，测试时长将累加计算。如果实际测试时长低于设定的测试时长，将按照实际测试时长扣减时长额度。
   > * 系统根据您当前设置的测试场景及测试范围，判断设备是否支持本次测试。例如，您选择了自定义测试场景和3类测试专项（兼容性测试、稳定性测试和性能测试），仅当设备完全支持这3类测试专项时，该设备卡片才会被高亮显示并支持选择；如果有1类测试专项（如性能测试）不支持，该设备卡片左下角将显示"当前设备不适配"字样，且该设备将被置灰不支持选择。
   > * 当您选择的应用软件包为HarmonyOS应用或元服务时，所选待测设备的API Level值必须大于等于应用软件包的API Level值，且两者之间的差值需小于或等于5。如果不满足此条件，设备卡片左下角将显示"当前设备不适配"字样，并且该设备将被置灰无法选择。如果无适配设备，您可以点击页面右上角的"上一步"，返回至"配置测试任务"页面，修改测试场景和测试范围后重试。
   > * 点亮设备卡片右下角的![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/23/v3/HpKrzqHbS8-ZsaQe_NcCqQ/zh-cn_image_0000002554670669.png?HW-CC-KV=V1&HW-CC-Date=20260916T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=8194DDB19A86093D2898A62FDEC8527B7A2C60007A13ADA7DF5C723B1474A04B)可以收藏该设备。后续创建相同测试场景的测试任务时，通过"其他信息"过滤项中的"我的收藏"即可筛选出已收藏的设备。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/27/v3/3-SYGYEBQUGKWkrmz4GpSQ/zh-cn_image_0000002554507575.png?HW-CC-KV=V1&HW-CC-Date=20260916T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=BEC24F2E5931D0BA7B7C1F8604CF72558AF2B1938C34CF14CCE6120C944C165E "点击放大")

   如果所选设备处于繁忙状态，您将看到页面右侧红色区域的提示信息。建议您根据预计排队时长，合理安排测试时间。

9. 在弹出的"使用详情确认"提示框中，点击"提交"。
   * 未开通按量付费且余额充足时，您可直接提交测试。但为防止实际用量超出套餐余额影响测试，建议您点击页面中的"开通"或参考[升级付费档](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudtest-price-0000001213558948#section14462147149)开通按量付费。

    * 您可以在测试任务未完成时，点击测试任务"操作"列的"查看报告"，进入测试报告概览页面查看测试任务的执行情况。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5f/v3/IrNL-gI2Qfmf6SaGz7URGQ/zh-cn_image_0000002549646449.png?HW-CC-KV=V1&HW-CC-Date=20260916T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=3A00B76B552A010480162379EB1DD9B431B71246C882DB6360851A7859393745 "点击放大")

    * 您也可以在测试任务执行完成后查看测试报告。 测试任务执行完成后，系统将发送邮件通知您，您可以点击邮件中的"云测试"链接返回到"测试任务"页签，并根据邮件中的测试场景、任务名称信息定位到具体的测试任务。

      ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/56/v3/G2lVAtjsSBuUhZ6Ks47WSA/zh-cn_image_0000002549638371.png?HW-CC-KV=V1&HW-CC-Date=20260916T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=D38A2D79E94807391A89D53AAB52C9826D82095756D185EE335F287A68901B03)
11. 您可从自定义测试的测试报告概览页中查看到被测应用的相关信息、所选测试专项在测试设备上的具体执行情况、运行失败终端分布情况以及测试结果详情。 测试报告概览页的信息分布如下：

    * 应用信息区域 为您展示被测应用的名称、版本等应用基本信息，以及该测试任务的测试场景、测试状态和测试时长信息。

    * 测试专项区域

      为您展示该测试任务所包含测试专项的统计信息，每个测试专项对应一个TAB页签，每个TAB页签内显示该测试专项的设备完成率、设备通过率和问题分布情况。 说明
      >
      > 测试报告页面展示的测试专项页签，由您创建测试任务时选择的"测试范围"决定。
    * 运行失败终端分布区域 为您展示测试设备在不同型号、不同HarmonyOS系统版本、不同屏幕分辨率三个维度下的运行失败分布情况。

    * 测试结果区域 为您展示被测应用在所选测试设备上各项指标的测试结果。
