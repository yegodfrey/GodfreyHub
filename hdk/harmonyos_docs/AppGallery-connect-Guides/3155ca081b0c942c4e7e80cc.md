# （可选）多数据处理位置

通常情况下，为了满足各区域隐私合规或就近处理数据等要求，可以使用不同数据处理位置访问处理不同区域的数据。

* 如果您不指定数据处理位置，云存储服务将使用默认数据处理位置存放和处理数据。
* 如果设置了数据处理位置，云存储服务将在指定的数据处理位置存放和处理数据。

您可以在AppGallery Connect上[设置数据处理位置](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-data-storage-location-0000001162597847)，设置完成后重新[获取agconnect-services.plist文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-obtain-files-0000001275499192#section1462535172213)并集成到您的项目中，然后即可在项目中对数据处理位置进行处理：

* [使用默认数据处理位置](#section1910913304262)
* [修改默认数据处理位置](#section8328654182616)
* [使用指定数据处理位置](#section66216133276)

#### 使用默认数据处理位置

调用getInstance方法初始化服务实例不传参即可。  

```
"Objective-C"
AGCStorage *storage = [AGCStorage getInstance];
```

```
"Swift"
let storage = AGCStorage.getInstance()
```

#### 修改默认数据处理位置

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240821163230.95508130596211430744816216481079:50001231000000:2800:5CF6CC6B5EC23E255051410EC1BA7BC1F17FD4F3DDA97316BC46413A54443838.png?needInitFileName=true?needInitFileName=true)  
在AGC上设置的"默认数据处理位置"适用于项目下所有应用，此处修改的"默认数据处理位置"仅对本应用生效，不会影响其他应用。

调用[\[AGCServicesConfig routePolicy\]](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agccore-ios-agcservicesconfig-0000001098896302#section775621082518)方法修改默认的数据处理位置。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240821163230.69615070848949921065166779207288:50001231000000:2800:4995FF329F5B8221E1238ED94286FE4274050624E2DEAFFB020A1AE7B0396087.png?needInitFileName=true?needInitFileName=true)  
建议此接口在UIApplicationDelegate的application:didFinishLaunchingWithOptions:中调用，数据处理位置及其对应的枚举值详情请参见[AGCRoutePolicy](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agccore-ios-agcroutepolicy-0000001098736300)。  

```
"Objective-C"
// 获取默认实例的配置
AGCServicesConfig *config = [[AGCServicesConfig alloc] initWithDefaultPlist];
// 将配置中的默认数据处理位置修改为中国
config.routePolicy = AGCRoutePolicyChina;
```

```
"Swift"
// 获取默认实例的配置
let configRussia = AGCServicesConfig.init(defaultPlist:())
// 将配置中的默认数据处理位置修改为中国 
config.routePolicy = AGCRoutePolicy.china
```

#### 使用指定数据处理位置

您还可以通过指定目标数据处理位置，实现不同数据处理位置访问不同区域的数据，此处目标数据处理位置以俄罗斯为例进行介绍。

1. 构造[AGCServicesConfig](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agccore-ios-agcservicesconfig-0000001098896302)对象，指定目标数据处理位置。  

   ```
   "Objective-C"
   // 使用自定义配置创建AGCServicesConfig对象
   AGCServicesConfig *configRussia = [[AGCServicesConfig alloc] initWithDefaultPlist];  
   ```

   ```
   "Swift"
   // 使用自定义配置创建AGCServicesConfig对象
   let configRussia = AGCServicesConfig.init(defaultPlist:())
   ```

2. 调用\[[AGCInstance getInstance:](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agccore-ios-agcinstance-0000001145336281#section09435589260)\]创建目标数据处理位置的AGCInstance对象。  

   ```
   "Objective-C"
   AGCInstance *instanceRussia = [AGCInstance getInstance:configRussia];
   ```

   ```
   "Swift"
   let instanceRussia = AGCInstance.getInstance(configRussia)
   ```

3. 调用[\[AGCStorage getInstance:bucketName:\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstorage-0000001172981557#section1810317349494)创建目标数据处理位置的AGCStorage对象。  

   ```
   "Objective-C"
   AGCStorage *storageRussia = [AGCStorage getInstance:instanceRussia bucketName:@"bucket name"];
   ```

   ```
   "Swift"
   let storageRussia = AGCStorage.getInstance(instanceRussia, "bucket name")
   ```

4. 如果您需要指定访问更多的数据处理位置，请重复以上步骤，指定不同的目标数据处理位置即可。
