# 典型应用场景

## 采集应用性能数据，助力优化改进

APM SDK能自动采集关键性能数据，通过多个维度呈现，支持查看和分析性能数据，快速发现应用性能瓶颈，并且支持创建自定义跟踪记录，监控应用在自定义场景下的性能。开发者可以根据呈现出的性能数据，实时全面掌握应用在线的性能表现，持续进行性能优化改进，提升应用的用户体验。
