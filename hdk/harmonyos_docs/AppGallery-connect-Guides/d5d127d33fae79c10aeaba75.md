# 已上架应用使用应用签名服务

|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-|
|对于已上架的应用在升级应用时使用应用签名服务，当前不支持由AGC创建新的签名密钥，只支持上传自己的签名密钥。您需要使用PEPK工具生成包含签名密钥的zip文件，并将zip文件上传到AGC。为了更高的安全性，您还可以提交上传密钥的密钥证书，建议您使用不同于签名密钥的上传密钥。如果不上传，则您需要使用您的签名密钥作为上传密钥。 > 注意 > 如果软件包配置了其他开放平台的签名，在AGC上传签名密钥可能会造成签名信息的变化并且导致功能异常，请您谨慎选择。| |

## 前提条件

* 您的应用有已上架版本且未使用过应用签名服务。
* 待上传的签名密钥与已上架应用的全网版本签名密钥保持一致。
* 已通过网络或其他合法途径获取PEPK工具（pepk.jar）。

## 上传签名密钥

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"APP与元服务"。
2. 选择"Android"页签，点击需要签名的应用，进入"分发"页签，选择"服务 > 应用签名"。
3. 首次使用应用签名服务，系统将提示您签署应用签名服务协议，您需要同意协议后才能使用应用签名服务。
4. 选择"方式二：AppGallery Connect仅管理开发者上传的签名密钥"。 注意
   >
   > 如果您已经使用了应用签名服务，则此处将提示此应用已加入应用签名计划。


5. 通过网络或其他合法途径获取PEPK工具（pepk.jar）。
6. 将签名密钥签名文件（.jks文件） 和pepk.jar解压至JDK的bin目录。
7. 运行cmd命令打开命令行窗口，进入JDK的bin目录，运行如下命令打包并加密签名密钥的签名文件。

   ```screen
   java -jar pepk.jar --keystore *sign-keystore.jks* --alias *sign* --output=*sign.zip* --*encryptionkey*=034200041E224EE22B45D19B23DB91BA9F52DE0A06513E03A5821409B34976FDEED6E0A47DBA48CC249DD93734A6C5D9A0F43461F9E140F278A5D2860846C2CF5D2C3C02 --include-cert
   ```

   命令中斜体加粗的内容需替换为实际的值，其中：
   * ***sign-keystore.jks***：签名密钥的签名文件。
   * ***sign***：签名文件的别名。
   * ***sign.zip***：打包生成的签名密钥zip包。
   * ***encryptionkey***：加密使用的公钥，请使用命令中固定的公钥。
8. 点击"浏览"，上传步骤[7](#ZH-CN_TOPIC_0000001051818319__li5130143418234)生成的zip包。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251011134003.39727287569042515615573758450265:50001231000000:2800:D84EB33840CDB881A8A00435A61FC2B273DC6D086CFBF6FC7A2D368844262C8F.png)
   > 说明
   >
   > 以下步骤9~11为可选步骤。如您考虑到更高的安全性，需要使用不同于签名密钥的上传密钥，可以手动上传您新生成的上传密钥。如不上传，AGC将默认使用您上传的签名密钥作为上传密钥来验证您的身份信息。
9. 生成包含上传密钥的签名文件，上传密钥需不同于签名密钥。
10. 运行cmd命令打开命令行窗口，进入JDK所在的bin目录，运行如下命令，为新生成的上传密钥生成密钥证书 (PEM 格式)。

    ```screen
    keytool -export -rfc -keystore *upload-keystore.jks* -alias *upload* -file *upload_certificate.pem*
    ```

    命令中斜体加粗的内容需替换为实际的值，其中：
    * ***upload-keystore.jks***：上传密钥所在的签名文件。
    * ***upload***：签名文件的别名。
    * ***upload_certificate.pem***：生成的上传密钥证书。
11. 点击"展开"，再点击"浏览"上传密钥证书。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251011134003.19537111595074110095608869981841:50001231000000:2800:17A6CD25B328F6158A2DF32E87C58735D0BF8BA3C30B3DDE29B7B4046DD4ADE2.png)

12. 点击右上角的"提交"将相关文件提交至AGC。 AGC会按如下顺序对上传的签名密钥进行校验，校验通过才可成功提交。

    1. 校验AGC是否支持签名密钥的加密算法和密钥长度。如果不支持，则提示"上传的应用签名密钥系统暂不支持，请重新上传。" AGC支持的加密算法和密钥长度详见[使用限制](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-appsigning-restriction-0000001051618335)。


    2. 校验签名密钥与最近一次上架的全网版本的应用签名是否一致。如果不一致，则提示"上传的应用签名密钥验证与已发布版本的应用签名不一致，请重新上传"。 注意
       >
       > 关于签名一致性规则的详细说明，请参见[应用签名的一致性要求](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-appsigning-faq-0000001052944432#section15231522402)。
    3. 校验签名密钥是否为配对的公私钥。如果公私钥不匹配，则提示"上传的应用签名密钥验证错误，请重新上传"。

## 配置重新生成的证书指纹

如果您上传到AGC的签名密钥与在架应用的签名密钥不一致，重签名生成的证书指纹可能不同于您开发应用时本地生成的签名证书指纹。如您的应用当前集成的华为相关服务需依赖SHA256证书指纹，您还需为应用添加重签名后的SHA256证书指纹。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"APP与元服务"。
2. 选择"Android"页签，点击您的应用，进入"分发"页签，选择"服务 > 应用签名"。
3. 在应用签名页面，点击"应用签名证书"栏的![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251011134003.11545703359242474129334422342539:50001231000000:2800:7BF58F74ADC6106A1F093096F4BE14FABA1FEED32A490FE31CF83FEF56638FB7.png "点击放大")，复制SHA256证书指纹。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251011134003.02088869825203389647503344076693:50001231000000:2800:D9F2AE28B7D53530C2124BE1AF192457A7C5C6063F3158C753CE72CCD3DD6FD0.png)
4. 进入"开发与服务 > 项目设置 > 常规 > 应用"，在"SHA256证书指纹"栏点击"添加证书指纹"，粘贴输入复制的SHA256证书指纹，点击"保存"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251011134003.20773519851260285882382308392604:50001231000000:2800:2D8A95D4960B9AD05B0EB7994559CD9D0995B3D58E6A50FFA4E3685C16E51AA5.png)

## 升级应用

1. 使用上传密钥对应用软件包签名，并上传软件包到AGC。AGC会通过您提交的上传密钥证书来验证您的身份信息，验证通过后AGC会使用您提交的签名密钥对应用重新签名。如果您未提交上传密钥证书，AGC将默认使用您上传的签名密钥作为上传密钥来验证您的身份信息。 重签名需要消耗几分钟时间，请耐心等待。

2. 通过升级方式发布新版本应用。
