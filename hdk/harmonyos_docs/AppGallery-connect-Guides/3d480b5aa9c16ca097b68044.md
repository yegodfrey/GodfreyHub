# 面向用户发送营销短信，吸引其参与活动，提升用户留存率

## 业务场景

对应用的用户群进行预测，识别出流失用户，当用户登录应用时，通过应用内消息向用户推送营销活动消息，让用户选择参与不同的活动，从而增强用户粘性。

## 实现流程

|序号|步骤|详情|
|:-|:----------------------------------------|:--------------------------------------------------|
|1|[预测流失用户](#section7229183495417)|使用预测服务，识别出流失用户，制定不同的促销活动。|
|2|[向用户发送营销消息](#section351184525411)|使用应用内消息，当流失用户回流访问应用时，应用弹出促销活动弹框，引导用户去网页参与活动。|
|3|[搭建促销活动网页](#section0356144618543)|开发促销活动的网页，将网页包上传至云托管站点进行托管，实现促销活动网页的搭建。|
|4|[引导用户跳转不同活动页参与活动](#section39919469549)|使用App Linking服务，配置不同的App Linking，用于用户跳转至不同的活动页参与活动。|
|5|[将用户参与活动信息存入云数据库](#section19414115620588)|在云数据库中记录用户参加活动的情况。|

## 预测流失用户

## 向用户发送营销消息

1. [开通应用内消息服务](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-appmessaging-enableservice-0000001322456700)。
2. 在应用中[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-appmessaging-integratesdk-android-0000001072532718)。
3. [添加应用内消息](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-appmessage-create-android-0000001072054882)。
   * 发送目标选择"应用"，包名即需要接收应用内消息的包名。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bf/v3/D-67_PxWQJOMDHTC5NgM5Q/zh-cn_image_0000001320373340.png?HW-CC-KV=V1&HW-CC-Date=20260909T130732Z&HW-CC-Expire=31536000000&HW-CC-Sign=4B40D6DE2B31E3F883BC7A980BED6602F401DC7520122BE1DF21D823B05581E5)


   * 应用内消息触发事件可以为App启动时弹出。

## 搭建促销活动网页

1. 开发促销活动的网页，并将网页打包成zip包，zip包根目录下包含的index.html文件作为默认站点首页。
2. [开通云托管服务](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-cloudhosting-enableservice-0000001057492615)。
3. [使用泛域名创建站点](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-cloudhosting-createsite-0000001058092565#section17608141882113)，用于托管网页资源。
4. [创建版本](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-cloudhosting-creatversion-0000001058732524#section24246013465)并发布。

## 引导用户跳转不同活动页参与活动

1. [开通App Linking服务](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-applinking-enable-0000001058870473)。
2. 在应用中[集成App Linking SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-android-integrationsdk-0000001371557869)。
3. [申请链接前缀](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-applinking-urlprefix-0000001060148052)，链接前缀可以设置为应用名。
4. [创建App Linking](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-createlinks-bysdk-android-0000001055674692)。链接名称可以设为本次促销活动名，链接URL设为跳转到活动对应页面。设置两条App Linking，分别跳转到两个不同的活动页。
5. 打开应用项目的app/src/main路径下的AndroidManifest文件，分别在两个活动页面的<activity>标签中添加需要接收DeepLink域名的Intent过滤器，用于接收App linking。 相关代码示例：

   ```screen
   <activity android:name=".Activity.EventActivity">
       <intent-filter>
           <action android:name="android.intent.action.VIEW" />

           <category android:name="android.intent.category.DEFAULT" />
           <category android:name="android.intent.category.BROWSABLE" />

           <data
               android:host="applinking.deeplinking"
               android:scheme="xuankuapp" />
       </intent-filter>
   </activity>
   <activity android:name=".Activity.EventActivity2">
       <intent-filter>
           <action android:name="android.intent.action.VIEW" />

           <category android:name="android.intent.category.DEFAULT" />
           <category android:name="android.intent.category.BROWSABLE" />

           <data
               android:host="applinking.deeplinking2"
               android:scheme="xuankuapp" />
       </intent-filter>
   </activity>
   ```

## 将用户参与活动信息存入云数据库

1. [开通云数据库服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-createfirstclouddb-0000001569588629#section379484118716)。
2. [集成云数据库SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-sdk-integration-0000001518849614#section10221194818199)。
3. [创建和导出对象类型](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-sdk-integration-0000001518849614#section8375194164915)，Demo中对象类型如图所示。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/da/v3/5hc_r8krSQqHW4W5T81R8A/zh-cn_image_0000001370658565.png?HW-CC-KV=V1&HW-CC-Date=20260909T130732Z&HW-CC-Expire=31536000000&HW-CC-Sign=76D7B15ECEA7BE668330CC8E1812B561206F3CF04F5D52D5E41389898061D5A5)
4. [创建存储区](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-sdk-integration-0000001518849614#section1183014591055)，用于存储云端的数据。
5. 当用户购买商品时，将相关数据存入云数据库。
   1. 调用[initialize](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/clouddb-agconnectclouddb-0000001127717605#section143012224110)方法初始化AGConnectCloudDB。

      ```screen
      public static void initAGConnectCloudDB(Context context) { 
              AGConnectCloudDB.initialize(context); 
      }
      ```

   2. 调用[getInstance(AGConnectInstance connectInstance)](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/clouddb-agconnectclouddb-0000001127717605#section367483894317)方法获取对应数据处理位置的AGConnectCloudDB实例，并使用[createObjectType](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/clouddb-agconnectclouddb-0000001127717605#section114216263118)创建对象类型。

      ```screen
      AGConnectInstance connectInstance = AGConnectInstance.getInstance("cn");
      AGConnectAuth auth = AGConnectAuth.getInstance();
      mCloudDB = AGConnectCloudDB.getInstance(connectInstance, auth);
      mCloudDB.createObjectType(ObjectTypeInfoHelper.getObjectTypeInfo());
      ```

   3. 调用[CloudDBZoneConfig](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/clouddb-clouddbzoneconfig-0000001127600371)创建Cloud DB zone配置对象，并打开该Cloud DB zone。

      ```screen
      mConfig = new CloudDBZoneConfig("UsecaseDemo", 
              CloudDBZoneConfig.CloudDBZoneSyncProperty.CLOUDDBZONE_CLOUD_CACHE, 
              CloudDBZoneConfig.CloudDBZoneAccessProperty.CLOUDDBZONE_PUBLIC); 
      mConfig.setPersistenceEnabled(true); 
      Task<CloudDBZone> openDBZoneTask = mCloudDB.openCloudDBZone2(mConfig, true); 
      openDBZoneTask.addOnSuccessListener(cloudDBZone -> { 
          Log.i(TAG, "Open cloudDBZone success"); 
          mCloudDBZone = cloudDBZone; 
          addSubscription(); 
      }).addOnFailureListener(e -> { 
          Log.e(TAG, "Open cloudDBZone failed for " + e.getMessage()); 
      });
      ```

   4. 调用[CloudDBZoneQuery](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/clouddb-clouddbzone-0000001081018016#section1361213261471)通过用户uid筛查，查询当前用户的信息。

      ```screen
      //点击购买时打开云数据库，进行订阅，通过用户uid筛查，查询当前用户的信息
      @Override
      public void onSubscribe(ArrayList<UserInfo> userInfos) {
          //userInfoAction.queryAll();

          CloudDBZoneQuery<UserInfo> query = CloudDBZoneQuery
                  .where(UserInfo.class).equalTo("uid", uid);
          userInfoAction.queryUserInfo(query);
      }
      ```

   5. 对查询到的数据进行判断，根据当前用户是否已参与活动的情况，进行推送应用内消息。

      ```screen
      //将查询到的所有数据存入arrayList，判断当前用户是否在云数据库中
      @Override
      public void onQuery(ArrayList<UserInfo> userInfos) {
          list.clear();
          list.addAll(userInfos);

          //list为0，登录用户不存在云数据库，可以购买
          //list为1，需要判断活动1是否已参加，为false时可以购买
          int size = list.size();
          if(size == 0 ||(size == 1 && !list.get(0).getEvent1())){
              insertDB();
              purchaseC();
          }else{
              purchaseF();
          }
      }
      ```

   6. 用户成功购买后，调用[executeUpsert](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/clouddb-clouddbzone-0000001081018016#section0625616271)接口将用户数据插入云数据库。

      ```screen
      //插入用户信息到云数据库方法
      public void upsertUserInfo(UserInfo userInfo) {
          if (mCloudDBZone == null) {
              Log.w(TAG, "CloudDBZone is null, try re-open it");
              return;
          }
          Task<Integer> upsertTask = mCloudDBZone.executeUpsert(userInfo);
          upsertTask.addOnSuccessListener(cloudDBZoneResult -> {
              ArrayList<UserInfo> userInfos = new ArrayList<>();
              userInfos.add(userInfo);
              Log.i(TAG, "Upsert " + cloudDBZoneResult + " records");
          }).addOnFailureListener(e -> {
              Log.e(TAG, "upsert Error: " + e.getMessage());
          });
      }
      ```

6. 登录AppGallery Connect，导航选择"构建 > 云数据库"，在"数据"页签可以查看到用户参与活动的数据信息。

## 测试功能

1. 打开应用，检查是否收到促销活动的应用内消息。
2. 点击应用内消息检查是否跳转至活动网页。
3. 点击想参与的活动，检查是否跳转至对应的活动页面。
4. 参与活动购买商品后，检查云数据库是否记录了用户信息。
