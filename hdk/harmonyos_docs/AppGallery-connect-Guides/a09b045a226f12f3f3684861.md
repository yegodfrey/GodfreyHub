# 存储实例管理

您可以通过[StorageManagement](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagemanagement-0000001057931714)对存储实例进行创建、删除等操作。

## 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[集成云存储SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-sdk-nodejs-0000001055127457)。
* 您已[升级到付费档](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-service-billing-0000001058092595#section1337763420106)。

## 创建存储实例

如果您的项目需要使用多个存储实例时，您可以通过[StorageManagement.createBucket](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagemanagement-0000001057931714#section848773312395)方法在云端创建新的存储实例。

```screen
// name: 存储实例名
let storage = AGCCloudStorage.getInstance();
storage.createBucket(name).then(res => {});
```

> 说明
>
> * 在新增存储实例时，云存储会对存储实例的名称和大小进行严格检查，具体请参见[使用限制](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-restrictions-0000001093263535#ZH-CN_TOPIC_0000001093263535__p166851620145310)。
> * 为了避免创建存储实例的名称重复，SDK默认会在您输入的存储实例名称后加"-五位随机数字字母"，组合成实际存储实例名称。

## 删除存储实例

当创建的存储实例不再使用时，您可调用[Bucket.delete](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/bucket-0000001057141584#section7884917102114)方法删除该存储实例。

```screen
// name: 存储实例名
let storage = AGCCloudStorage.getInstance();
let bucket = storage.bucket(name);
bucket.delete().then(res => {});
```

> 注意
>
> * 请确保存储实例中文件已全部删除，当存储实例中存在目录或文件时，删除存储实例会失败。
> * 删除操作不可逆，一旦执行，存储实例会被回收，不可恢复。
> * 启用服务时创建的默认存储实例不允许使用上述方式删除，如确定要删除，请执行删除项目操作，默认的存储实例即会同步执行删除操作。

## 列举存储实例

创建多个存储实例后，您可调用[Storagemanagement.getBuckets](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagemanagement-0000001057931714#section21431550124015)方法列举您项目下的存储实例。

```screen
let storage = AGCCloudStorage.getInstance();
storage.getBuckets().then(res => {});
```
