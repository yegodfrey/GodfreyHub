# 配置管理

AGC的云缓存服务提供可视化的配置管理，您可以在AGC控制台进行访问命令行工具、重置访问密码、查看并复制内网访问地址和用户名的操作。

## 访问命令行工具

云缓存服务提供命令行工具Web CLI，您可以直接对缓存数据进行读写操作来排查、定位问题。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中选择您的项目。
3. 在左侧导航栏选择"云开发（Serverless） > 云缓存"，点击"管理"页签。
4. 在"管理操作"模块点击"访问命令行工具"，云缓存即可自动连接缓存实例，并进入Web CLI界面。 说明
   >
   > 云缓存目前支持的命令请参见"[Web CLI命令](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudcache-webcli-guide-0000001386233729)"。

## 重置访问密码

云缓存提供重置访问密码功能，如您忘记之前设置的访问密码，可以进行密码重置。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中选择您的项目。
3. 在左侧导航栏选择"云开发（Serverless） > 云缓存"，点击"管理"页签。
4. 在"管理操作"模块点击"重置访问密码"，在弹出的"重置访问密码"窗口设置新的缓存访问密码。 注意
   >
   > 云缓存对访问密码有严格的限制：
   > * 密码不能为空。
   > * 密码必须以字母开头。
   > * 密码长度在8到32位之间。
   > * 必须包含如下四种字符：
   >   * 小写字母
   >   * 大写字母
   >   * 数字（0-9）
   >   * 特殊字符（-~!@#%^*_=+?$&()|<>{}[]）

## 查看用户名、内网地址

云缓存服务可以获取您的用户名、内网地址，这些信息可用于在Redis客户端自行连接缓存实例，也可用于在应用中连接并使用云缓存。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中选择您的项目。
3. 在左侧导航栏选择"云开发（Serverless） > 云缓存"点击"管理"页签。
4. 在"访问信息"模块，查看并复制用户名、内网地址。
   * 您可以在Redis客户端执行如下命令，自行连接缓存实例。

     ```screen
     ./redis-cli -h <内网地址> -p <端口号> -a <缓存访问密码>
     ```

   * 您可以在应用中，根据使用的开发语言，选择不同方式连接并[使用云缓存](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudcache-use-0000001485525416)。
