# 使用限制

## 配额限制

当您使用的云存储资源超过免费配额后，则需要付费使用超额的部分，具体请参见[收费明细](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-price-0000001253665999#section922853442512)。

## 资源限制

|资源项|限制|
|:------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|存储实例|* 存储实例名称只能包含英文小写字母、数字、中划线（-）。 * 存储实例名称只能以数字或字母开头和结尾。 * 存储实例名称长度要求不小于3个字符，并且不能超过57个字符。 * 存储实例名称不能是IP地址。 * 存储实例名称不能包含连续两个及以上中划线（-）。 * 存储实例名称全局唯一，且创建后不可修改。 * 所有项目的全部存储实例数量总数不超过100个。|
|文件名称与数量|通过SDK上传文件时，文件名称和数量需满足如下规范： * 文件名称采用UTF-8编码时，URL的总长度不超过1024字节。 * 文件名称不能包含回车符、换行符。 * 文件名称中禁止使用特殊字符，如# * : ? ' " < > | [ ] * 文件名称避免超过255个字符，超过后会导致在某些操作系统下出现兼容问题。 * 文件名称尽量保持散列以便提高存储性能。 * 一个目录下尽量不要存储过多的对象，防止出现存储性能问题。|
|文件大小|通过SDK上传文件时，文件大小需满足如下规范： * Android、iOS、HarmonyOS-Java 单个文件大小不超过50GB，单次请求上传不超过5GB。 * Web、快应用 单个文件大小不超过50GB。 * HarmonyOS-TypeScript（API6）、HarmonyOS-TypeScript（API9及以上）、HarmonyOS-ArkTS（API9至API11） 单个文件大小不超过1GB。|

## 设备限制

设备限制是指SDK对用户终端的限制。

|限制项|限制|
|:-----------|:-------------------------------|
|设备品牌|支持所有品牌设备。|
|Android OS|Android 4.4及以上（API Level 19及以上）。|
|iOS OS|iOS 9及以上。|
|Web浏览器|Chrome 81及以上版本。|
|EMUI（针对华为手机）|无限制。|
|HMS Core APK|无限制。|
|应用市场客户端|无限制。|
