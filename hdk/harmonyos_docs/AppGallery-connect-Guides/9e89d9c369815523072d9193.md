# 配置函数管理功能

完成创建云函数后，开发者可以根据需要选择配置版本管理、别名管理、环境变量、流量治理、层管理的函数管理功能。

|功能|说明|
|:-----------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------|
|[版本管理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloud-function-version-0000001301351404)|开发者可通过发布多个版本完成函数的迭代开发，以维护版本的形式来完成函数的更新与回退，提高运维的效率。 **通常同一个函数需要创建第二个版本时，则需要配置此功能。**|
|[别名管理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloud-function-aliasname-0000001568841949)|开发者可通过创建的别名来控制要访问的云函数版本，基于别名来管理函数调用，避免了切换版本时要反复修改调用云函数部分的代码。 **此功能为可选功能，请开发者根据实际需要来选择使用。**|
|[环境变量](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloud-function-environment-0000001706997573)|开发者可配置环境变量，将需要的变量配置信息传入函数执行环境，用于函数在运行时读取和使用。 **此功能为可选功能，请开发者根据实际需要来选择使用。**|
|[流量治理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloud-function-flow-manage-0000001658598194)|流量治理为系统可靠运行提供保障。您可以针对云函数常见故障模式，选择负载均衡、重试、熔断等策略进行配置。 **建议您在业务运行期间，根据业务运行状态和指标，动态更新流量治理策略。**|
|[层管理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloud-function-layer-0000001517762624)|开发者可通过层来管理具有通用性或不变性的依赖、静态文件等以此精炼云函数代码，从而达到减少云函数代码包大小与部署时间的效果。 **此功能为可选功能，请开发者根据实际需要来选择使用。**|
