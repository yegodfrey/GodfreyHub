# 使用数据库的其他操作

#### 映射对象类型

云数据库提供映射对象类型文件的能力。您在使用Android SDK开发本地应用时，可直接将AGC控制台上导出的java格式的对象类型文件添加至本地开发环境，如果java格式的对象类型文件中有不符合Java语言规范的对象类型名称和字段名称，您可以修改类名（即对象类型名称）和属性名（即字段名称），并通过添加注解的方式建立云侧与本地开发环境中对象类型的映射关系，并在后续的开发中使用映射后的对象类型名称和字段名称，使其适配语言规范格式。在映射对象类型文件时，通过[ObjectTypeMapping](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-objecttypemapping-0000001409504328)映射java文件中的类，即对象类型名称；通过[FieldMapping](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-fieldmapping-0000001409344356)映射java文件中的属性，即对象类型中的字段名。

注意事项：  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250714155404.88309407946540239198028455458722:50001231000000:2800:4B3B105B8420A74E4F3F7E289E01AA4DE2D71CCFD3801E5A0D4ACC4873AEC9F1.png)  
请先关注注意事项。

* 映射对象类型名称时，不能映射相同的对象类型名。否则在调用[createObjectType()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agconnectclouddb-0000001127717605#section114216263118)方法创建或修改对象类型时出现异常。
* 映射对象类型名称时，对象类型名称区分字母的大小写，对象类型原名称需与AGC控制台上的对象类型名称保持一致。
* 映射字段名称时，字段原名称需与AGC控制台上的字段名完全一致。
* 映射字段名称成功后，若字段名为入参，需使用修改后的对象属性名。
* 映射对象类型时，不支持修改索引和主键注解中的字段名称，索引和主键注解的字段名需要与AGC控制台上创建的对象类型字段名完全一致。

操作步骤：

1. 将已在AGC控制台上导出的全部java格式文件添加至本地开发环境。 如果文件已存在，请覆盖原文件。

2. 打开不符合命名规范的book_info.java文件，示例如下所示。

   ```
   @PrimaryKeys({"id"})
   public final class book_info extends CloudDBZoneObject {
       private Long id;
       private Date publish_time;

       public book_info() {
           super(book_info.class);
       }
       
       public void setId(Long id) {
           this.id= id;
       }

       public String getId() {
           return id;
       }

       public void setPublish_time(Date publish_time) {
           this.publish_time = publish_time
       }

       public String getPublish_time() {
           return publish_time;
       }
   }
   ```

3. 映射对象类型文件，映射成功后需要修改项目中所有使用到该对象类型名称和字段名的内容。
   1. 映射对象类型文件的类名。通过为类名添加[@ObjectTypeMapping](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-objecttypemapping-0000001409504328)注解，将对象类型名"BookInfo"映射为"book_info"，并修改对应构造器与文件名。

      ```
      @PrimaryKeys({"id"})
      @ObjectTypeMapping("book_info")
      public final class BookInfo extends CloudDBZoneObject {
          private Long id;
          private Date publish_time;

          public BookInfo() {
              super(BookInfo.class);
          }
          
          public void setId(Long id) {
              this.id= id;
          }

          public String getId() {
              return id;
          }

          public void setPublish_time(Date publish_time) {
              this.publish_time = publish_time
          }

          public String getPublish_time() {
              return publish_time;
          }
      }
      ```

   2. 映射对象类型文件的属性名。通过为属性名添加[@FieldMapping](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-fieldmapping-0000001409344356)注解，将字段名"publish_time"映射为"publishTime"。

      ```
      @PrimaryKeys({"id"})
      @ObjectTypeMapping("book_info")
      public final class BookInfo extends CloudDBZoneObject {
          private Long id;
          @FieldMapping("publish_time")
          private Date publishTime;

          public BookInfo() {
              super(BookInfo.class);
          }
          
          public void setId(Long id) {
              this.id= id;
          }

          public String getId() {
              return id;
          }

          public void setPublishTime(Date publishTime) {
              this.publishTime = publishTime
          }

          public String getPublishTime() {
              return publishTime;
          }
      }
      ```

4. 初始化云数据库，通过AGConnectCloudDB类中的[createObjectType()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agconnectclouddb-0000001127717605#section114216263118)方法实现对象类型的定义和创建，详细请参见[初始化](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-sdk-integration-0000001518849614#section13112123714810)。  

#### 写入数据

可以通过[executeUpsert()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-0000001081018016#section0625616271)将一个或者一组对象写入到当前存储区中。在写入对象时，如果在存储区已经存在主键值相同的对象，则更新已有的对象；如果不存在，则写入一个新的对象。写入的数据可以来自于新建对象，或者从存储区查询出来的对象。

写入一组对象时，数据的写入操作是原子的，即对象列表中的对象要么全部成功写入，要么全部失败。

调用写入数据方法后，会返回一个Task对象，对象中封装了写入操作执行的状态、结果和异常信息等。通过该Task对象可以异步侦听执行结果：执行成功，可以获取写入的对象数量；执行失败，可以获取对应的异常信息。更多信息请参见[Tasks](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/tasks-overview-0000001050202661)。

注意事项：  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250714155404.83448799903108168507807734592260:50001231000000:2800:1B871E7B75F015AAC827C5423CBE4212820D6771FBC76B573DE03272355EE234.png)  
请先关注注意事项。

* 仅当存储区为打开状态时，才可以进行写入对象操作，否则会导致写入失败。
* 写入一组对象时，该组中的对象必须属于同一个对象类型，否则会导致写入失败。

代码示例：

将BookInfo对象写入至存储区中，写入成功后，返回写入的数量；写入失败，抛出异常。  

```
"Java"
public void upsertBookInfos(BookInfo bookInfo) {
	if (mCloudDBZone == null) {
		Log.w(TAG, "CloudDBZone is null, try re-open it");
		return;
	}
	Task<Integer> upsertTask = mCloudDBZone.executeUpsert(bookInfo);
	upsertTask.addOnSuccessListener(new OnSuccessListener<Integer>() {
		@Override
		public void onSuccess(Integer cloudDBZoneResult) {
			Log.i(TAG, "Upsert " + cloudDBZoneResult + " records");
		}
	}).addOnFailureListener(new OnFailureListener() {
		@Override
		public void onFailure(Exception e) {
			mUiCallBack.updateUiOnError("Upsert book info failed");
		}
	});
}
```

```
"Kotlin"
fun upsertBookInfo(bookInfo: BookInfo?) {
    if (mCloudDBZone == null) {
        Log.w(TAG, "CloudDBZone is null, try re-open it")
        return
    }
    val upsertTask = mCloudDBZone!!.executeUpsert(bookInfo!!)
    upsertTask.addOnSuccessListener { cloudDBZoneResult ->
        Log.i(TAG, "Upsert $cloudDBZoneResult records")
    }.addOnFailureListener {
        mUiCallBack.updateUiOnError("Upsert book info failed")
    }
}
```

#### 查询数据

云数据库通过[executeQuery()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-0000001081018016#section1361213261471)方法查询对象，并提供了丰富的谓词查询，比如equalTo()、notEqualTo()、in()等。通过单个或者多个链式过滤条件，您可以从存储区查询到满足特定条件的对象，也可以通过排序谓词对查询结果排序，或者通过限定查询返回数量谓词限定查询结果返回的数量。详细的查询条件请参见[CloudDBZoneQuery](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-0000001080569968)。

云数据库包括缓存模式和本地模式两种数据同步模式，不同的模式下，其数据查询策略也不一致，具体如下：

* 缓存模式
  * 从本地缓存查询。
  * 从云侧存储区服务器查询。
  * 从云侧存储区和本地缓存查询数据。
* 本地模式
  * 仅支持从本地存储区查询数据。

根据查询结果返回的对象，调用[Task\<TResult\>](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/task_tresult-0000001050121148)类的getResult()可以获取存放在对象里的CloudDBZoneSnapshot对象，您在获取对象的同时，也可以通过一些辅助的方法根据具体需求进行不同的处理。例如，通过与[subscribeSnapshot()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-0000001081018016#section1591102716)合用添加对查询结果集的数据变化侦听，与[hasPendingWrites()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonesnapshot-0000001127834755#section168002230584)合用可以判断是否有未同步到云侧的对象，与[isFromCloud()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonesnapshot-0000001127834755#section1567122635811)合用判断查询结果中的对象来源等，更多请参见[CloudDBZoneSnapshot](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonesnapshot-0000001127834755)。

云数据库在支持基本查询的同时，还支持您查询某个字段平均值和查询本地缓存中未同步到云数据库的对象。

注意事项：  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250714155404.99337136827408781753665402302492:50001231000000:2800:C7A6DD4CAF7DD21EFC151C830DD8B692F3454CB5E2ED46C85440B4CDCD6DD751.png)  
请先关注注意事项。

* 仅当存储区为打开状态时，才可以进行查询对象操作，否则会导致查询失败。
* 每次的查询操作仅支持查询一个对象类型下的数据。  

#### 简单查询

您可以在无查询条件时，获取一个对象类型中所有的对象；也可以指定单个查询条件，来获取满足该条件的对象。

* 查询对象类型BookInfo的所有数据。  

  ```
  "Java"
  public void queryAllBooks() {
  	if (mCloudDBZone == null) {
  		Log.w(TAG, "CloudDBZone is null, try re-open it");
  		return;
  	}
  	Task<CloudDBZoneSnapshot<BookInfo>> queryTask = mCloudDBZone.executeQuery(
  		CloudDBZoneQuery.where(BookInfo.class),
  		CloudDBZoneQuery.CloudDBZoneQueryPolicy.POLICY_QUERY_FROM_CLOUD_ONLY);
  	queryTask.addOnSuccessListener(new OnSuccessListener<CloudDBZoneSnapshot<BookInfo>>() {
  		@Override
  		public void onSuccess(CloudDBZoneSnapshot<BookInfo> snapshot) {
  			processQueryResult(snapshot);
  		}
  	}).addOnFailureListener(new OnFailureListener() {
  		@Override
  		public void onFailure(Exception e) {
  			mUiCallBack.updateUiOnError("Query book list from cloud failed");
  		}
  	});
  }
  ```

  ```
  "Kotlin"
  fun queryAllBooks() {

          return
      }

* 通过异步侦听的方式查询"bookName"为"左传"的书籍。
  * 构造查询方法queryBooks，该方法同时供后续查询示例引用。  

    ```
    "Java"
    public void queryBooks(CloudDBZoneQuery<BookInfo> query) {
    	if (mCloudDBZone == null) {
    		Log.w(TAG, "CloudDBZone is null, try re-open it");
    		return;
    	}
    	Task<CloudDBZoneSnapshot<BookInfo>> queryTask = mCloudDBZone.executeQuery(query,
    		CloudDBZoneQuery.CloudDBZoneQueryPolicy.POLICY_QUERY_FROM_CLOUD_ONLY);
    	queryTask.addOnSuccessListener(new OnSuccessListener<CloudDBZoneSnapshot<BookInfo>>() {
    		@Override
    		public void onSuccess(CloudDBZoneSnapshot<BookInfo> snapshot) {
    			processQueryResult(snapshot);
    		}
    	}).addOnFailureListener(new OnFailureListener() {
    		@Override
    		public void onFailure(Exception e) {
    			mUiCallBack.updateUiOnError("Query failed");
    		}
    	});
    }

    private void processQueryResult(CloudDBZoneSnapshot<BookInfo> snapshot) {
    	CloudDBZoneObjectList<BookInfo> bookInfoCursor = snapshot.getSnapshotObjects();
    	List<BookInfo> bookInfoList = new ArrayList<>();
    	try {
    		while (bookInfoCursor.hasNext()) {
    			BookInfo bookInfo = bookInfoCursor.next();
    			bookInfoList.add(bookInfo);
    		}
    	} catch (AGConnectCloudDBException e) {
    		Log.w(TAG, "processQueryResult: " + e.getMessage());
    	}
    	snapshot.release();
    	mUiCallBack.onAddOrQuery(bookInfoList);
    }
    ```

    ```
    "Kotlin"
    fun queryBooks(query: CloudDBZoneQuery<BookInfo>) {
        if (mCloudDBZone == null) {
            Log.w(TAG, "CloudDBZone is null, try re-open it")
            return
        }

        val queryTask = mCloudDBZone!!.executeQuery(query,
                CloudDBZoneQuery.CloudDBZoneQueryPolicy.POLICY_QUERY_FROM_CLOUD_ONLY)
        queryTask.addOnSuccessListener { snapshot -> processQueryResult(snapshot) }
            .addOnFailureListener { mUiCallBack.updateUiOnError("Query failed")}
    }

    private fun processQueryResult(snapshot: CloudDBZoneSnapshot<BookInfo>) {
        val bookInfoCursor = snapshot.snapshotObjects
        val bookInfoList: MutableList<BookInfo> = ArrayList()
        try {
            while (bookInfoCursor.hasNext()) {
                val bookInfo = bookInfoCursor.next()
                bookInfoList.add(bookInfo)
            }
        } catch (e: AGConnectCloudDBException) {
            Log.w(TAG, "processQueryResult: " + e.message)
        } finally {
            snapshot.release()
        }
        mUiCallBack.onAddOrQuery(bookInfoList)
    }
    ```

  * 构造查询条件，并调用queryBooks方法，获取查询数据。  

    ```
    "Java"
    CloudDBZoneQuery<BookInfo> query = CloudDBZoneQuery.where(BookInfo.class).equalTo(BookEditFields.BOOK_NAME, "左传");
    queryBooks(query);
    ```

    ```
    "Kotlin"
    val query = CloudDBZoneQuery.where(BookInfo::class.java).equalTo(BookEditFields.BOOK_NAME, "左传")
    queryBooks(query)
    ```

#### 复合查询

您可以通过多个链式过滤条件，来获取满足条件的对象。多个链式条件之间默认用"与"运算，即and()连接。

* 构造查询条件，并调用queryBooks方法，查询"bookName"包含"数据库"，"price"大于20.0并且小于50.0的书籍。  

  ```
  "Java"
  CloudDBZoneQuery<BookInfo> query = CloudDBZoneQuery.where(BookInfo.class).contains(BookEditFields.BOOK_NAME, 
  	"数据库").greaterThan(BookEditFields.PRICE, 20.0).and().lessThan(BookEditFields.PRICE, 50.0);
  queryBooks(query);
  ```

  ```
  "Kotlin"
  val query = CloudDBZoneQuery.where(BookInfo::class.java).contains(BookEditFields.BOOK_NAME,
          "数据库").greaterThan(BookEditFields.PRICE, 20.0).and().lessThan(BookEditFields.PRICE, 50.0)
  queryBooks(query)
  ```

* 构造查询条件，并调用queryBooks方法，查询"bookName"包含"数据库"，"price"小于20.0或者大于50.0区间的书籍。  

  ```
  "Java"
  CloudDBZoneQuery<BookInfo> query = CloudDBZoneQuery.where(BookInfo.class).contains(BookEditFields.BOOK_NAME,
  	"数据库").lessThan(BookEditFields.PRICE, 20.0).or().greaterThan(BookEditFields.PRICE, 50.0);
  queryBooks(query);
  ```

  ```
  "Kotlin"
  val query = CloudDBZoneQuery.where(BookInfo::class.java).contains(BookEditFields.BOOK_NAME,
          "数据库").lessThan(BookEditFields.PRICE, 20.0).or().greaterThan(BookEditFields.PRICE, 50.0)
  queryBooks(query)
  ```

* 构造查询条件，并调用queryBooks方法，查询"bookName"包含"史记"，"author"是"司马迁"，"price"大于60.0的书籍。  

  ```
  "Java"
  CloudDBZoneQuery<BookInfo> query = CloudDBZoneQuery.where(BookInfo.class).contains(BookEditFields.BOOK_NAME,
  	"史记").equalTo(BookEditFields.AUTHOR, "司马迁").greaterThan(BookEditFields.PRICE, 60.0);
  queryBooks(query);
  ```

  ```
  "Kotlin"
  val query = CloudDBZoneQuery.where(BookInfo::class.java).contains(BookEditFields.BOOK_NAME,
          "史记").equalTo(BookEditFields.AUTHOR, "司马迁").greaterThan(BookEditFields.PRICE, 60.0)
  queryBooks(query)
  ```

* 构造查询条件，并调用queryBooks方法，查询"bookName"包含"自传"，并且"author"是"齐白石"，或者"author"是"司马迁"并且"price"大于60.0的书籍。

#### 聚合查询

在查询数据时，您可以通过聚合查询实现查询平均值、求和、查询最大值、查询最小值和统计数据记录条数的能力。

查询平均值

您可以通过[executeAverageQuery()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-0000001081018016#section17491230877)查找满足特定条件的对象，并计算这些对象中指定字段的平均值。  
查询所有书籍的价格平均值。

```
"Java"
CloudDBZoneQuery<BookInfo> query = CloudDBZoneQuery.where(BookInfo.class);
Task<Double> averageQueryTask = mCloudDBZone.executeAverageQuery(query, BookEditFields.PRICE,
	CloudDBZoneQuery.CloudDBZoneQueryPolicy.POLICY_QUERY_FROM_CLOUD_ONLY);
averageQueryTask.addOnSuccessListener(new OnSuccessListener<Double>() {
	@Override
	public void onSuccess(Double cloudDBZoneResult) {
		Log.i(TAG, "Average price is " + cloudDBZoneResult);
	}
}).addOnFailureListener(new OnFailureListener() {
	@Override
	public void onFailure(Exception ex) {
		Log.w(TAG, "Average query is failed: " + Log.getStackTraceString(ex));
	}
});
```

```
"Kotlin"
val query = CloudDBZoneQuery.where(BookInfo::class.java)
val averageQueryTask = mCloudDBZone!!.executeAverageQuery(query, BookEditFields.PRICE,
        CloudDBZoneQuery.CloudDBZoneQueryPolicy.POLICY_QUERY_FROM_CLOUD_ONLY)

    Log.i(TAG, "Average price is $cloudDBZoneResult")

#### 分页查询

在查询数据时，您可以通过[元组查询](#section09972107254)和[limit()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-0000001080569968#section1602122111011)方法组合使用实现数据的分页查询，也可以直接通过[limit()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-0000001080569968#section1602122111011)实现分页查询。您可以和[equalTo()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-0000001080569968#section19993154915912)、[orderByAsc()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-0000001080569968#section36836171502)、[orderByDesc()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-0000001080569968#section189638198011)、[greaterThan()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-0000001080569968#section515625417591)、[greaterThanOrEqualTo()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-0000001080569968#section82705618597)、[lessThan()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-0000001080569968#section111659105915)、[lessThanOrEqualTo()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-0000001080569968#section17870701008)、[or()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-0000001080569968#section1530010332406)、[beginGroup()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-0000001080569968#section18841143714400)、[endGroup()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-0000001080569968#section759104364011)方法组合使用，例如与排序查询谓词或者等值查询谓词组合使用，可以实现获取某个对象之前或者之后的数据记录。

为了保证分页查询的性能，云数据库要求您在构造分页查询条件前，先创建查询所需的索引。如果未创建索引，您可能会收到一个异常信息，您需要根据异常信息创建缺少的索引。创建索引请参见[新增对象类型](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-sdk-integration-0000001518849614#section8375194164915)，创建索引后，您还需要更新本地的对象类型文件，详细请参见[加载对象类型文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-sdk-integration-0000001518849614#section0173184174713)。

通过元祖查询和limit()方法组合使用进行分页查询

使用[startAt()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-0000001080569968#section1487482619011)方法定义查询的起始位置，通过与[limit()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-0000001080569968#section1602122111011)和[orderByAsc()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-0000001080569968#section36836171502)结合使用实现数据的分页能力，并将第一次查询结果的最后一条记录，作为下一次查询的起点。  

```
"Java"
// 查询第一页的10条记录。
CloudDBZoneQuery<BookInfo> queryFirst = CloudDBZoneQuery.where(BookInfo.class)
        .equalTo(BookEditFields.PUBLISHER, "人民出版社")
	.orderByAsc(BookEditFields.BOOK_ID)
	.limit(10);
Task<CloudDBZoneSnapshot<BookInfo>> queryTask = zone.executeQuery(queryFirst,
	CloudDBZoneQuery.CloudDBZoneQueryPolicy.POLICY_QUERY_DEFAULT);

// 等待查询结果。
CloudDBZoneSnapshot<BookInfo> result = null;
queryTask.addOnSuccessListener(new OnSuccessListener<CloudDBZoneSnapshot<BookInfo>>() {
	@Override
	public void onSuccess(CloudDBZoneSnapshot<BookInfo> snapshot) {
		// 将前10条记录的最后一条，作为查询下一页数据记录的起点（不包含起点），获取下一页数据。
		try {
			BookInfo nextBook = snapshot.getSnapshotObjects().get(snapshot.getSnapshotObjects().size() - 1);
			CloudDBZoneQuery<BookInfo> queryNext = CloudDBZoneQuery.where(BookInfo.class)
                                .equalTo(BookEditFields.PUBLISHER, "人民出版社")
                                .startAfter(nextBook)            
				.orderByAsc(BookEditFields.BOOK_ID)
				.limit(10);
			Task<CloudDBZoneSnapshot<BookInfo>> queryTaskNext = zone.executeQuery(
				queryNext,
				CloudDBZoneQuery.CloudDBZoneQueryPolicy.POLICY_QUERY_DEFAULT);
		} catch (AGConnectCloudDBException e) {
			Log.w(TAG, "Exception occurred, info:" + e.getMessage());
		} finally {
			snapshot.release();
		}
	}
}).addOnFailureListener(new OnFailureListener() {
	@Override
	public void onFailure(Exception e) {
		Log.e(TAG, "Query failed, info:" + Log.getStackTracesString(e));
	}
});
```

#### 删除数据

您可以通过[executeDelete()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-0000001081018016#section1159514201578)删除单个对象或者一组对象。删除数据时，云数据库会根据传入对象主键删除相应的数据，不会比对该对象其它属性与存储的数据是否一致。删除一组对象时，删除操作是原子的，即对象列表中的对象要么全部删除成功，要么全部删除失败。

注意事项：  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250714155404.79231092420795965710031897180770:50001231000000:2800:06D3A50CC541E1721BAD9766D823DAA9BAD46810B749F83BA5E3A7332455112C.png)  
请先关注注意事项。

* 仅当存储区为打开状态时，您才可以进行删除对象操作，否则会导致删除失败。
* 删除一组对象时，该组中的对象必须属于同一个对象类型，否则会导致删除失败。

代码示例：

将对象删除，如果任务执行成功，返回删除对象的个数；执行失败，则返回一个异常。  

```
"Java"
// bookInfoList为查询操作或侦听器返回的数据集。
public void deleteBookInfosAsync(List<BookInfo> bookInfoList) {
	if (mCloudDBZone == null) {
		Log.w(TAG, "CloudDBZone is null, try re-open it");
		return;
	}

	Task<Integer> deleteTask = mCloudDBZone.executeDelete(bookInfoList);
	deleteTask.addOnSuccessListener(new OnSuccessListener<Integer>() {
		@Override
		public void onSuccess(Integer integer) {
			mUiCallBack.onDelete(bookInfoList);
		}
	}).addOnFailureListener(new OnFailureListener() {
		@Override
		public void onFailure(Exception e) {
			mUiCallBack.updateUiOnError("Delete book info failed");
		}
	});
}

```

    if (mCloudDBZone == null) {

    }
    val deleteTask = mCloudDBZone!!.executeDelete(bookInfoList!!)
    deleteTask.addOnSuccessListener {

    }.addOnFailureListener {

    }

#### 侦听实时更新

您可以通过[subscribeSnapshot()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-0000001081018016#section1591102716)来侦听符合指定查询条件的数据变化。当侦听的数据发生变化时，云数据库会触发您自定义的回调函数，并将数据以快照的方式传给回调函数，由您根据业务逻辑自定义处理快照数据。  
注册快照侦听后，快照侦听需要一定的时间（受限于网络状态）才会生效，因此，在侦听生效前的数据变化不会推送到端侧，待侦听生效后，端侧可正常收到云侧数据变化的通知。您注册快照侦听后，会触发生成一次快照，后续每当侦听的数据发生变化时，都会生成一次快照。注册侦听时，需要根据数据的查询策略指定侦听数据来源，数据来源如下所示：

* 从云侧存储区服务器查询。
* 从云侧存储区和本地缓存查询数据。 执行该数据查询策略时，您在本地的数据增、删、改操作会立即调用已注册的快照侦听器，并不会等待数据同步到云端服务器时再调用快照侦听器。

通过调用CloudDBZoneSnapshot类中的[getUpsertedObjects()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonesnapshot-0000001127834755#section87308290584)可以获取相较于上次快照新增或者修改的对象，调用[getDeletedObjects()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonesnapshot-0000001127834755#section19671232135813)获取相较于上次快照删除的对象，调用release()来释放快照占用的资源。

前提条件：

存储区的数据同步模式为缓存模式。

注意事项：  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250714155404.53933091354521052130784713056318:50001231000000:2800:1ACA0E205A1931F39C1C737B6846694D941AEE81A65F1CF6396C373C1902C6C5.png)  
请先关注注意事项。

* 在通过OnSnapshotListener类中的[onSnapshot()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-onsnapshotlistener-0000001127495859#section17555512164514)实现快照回调函数时，必须显式地在onSnapshot()内调用CloudDBZoneSnapshot类中的[release()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonesnapshot-0000001127834755#section2038011075811)来释放相关的资源，否则会导致无法获取最新的快照对象，且无法注销快照侦听。

  private OnSnapshotListener<BookInfo> mSnapshotListener = new OnSnapshotListener<BookInfo>() {

  			Log.w(TAG, "onSnapshot: " + e.getMessage());
  			return;
  		}
  		CloudDBZoneObjectList<BookInfo> snapshotObjects = cloudDBZoneSnapshot.getSnapshotObjects();

  		try {
  			if (snapshotObjects != null) {
  				while (snapshotObjects.hasNext()) {
  					BookInfo bookInfo = snapshotObjects.next();
  					bookInfos.add(bookInfo);
  					updateBookIndex(bookInfo);
  				}
  			}
                          mUiCallBack.onSubscribe(bookInfos);
  		} catch (AGConnectCloudDBException snapshotException) {
  			Log.w(TAG, "onSnapshot:(getObject) " + snapshotException.getMessage());
  		} finally {
  			cloudDBZoneSnapshot.release();
  		}
  	}
  };
  ```

#### 事务与数据管理

云数据库支持通过[runTransaction()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-0000001081018016#section1517114501675)执行事务，实现对云侧存储区数据的管理操作，包含数据的增、删、改、查操作。事务支持同时对多个对象类型的数据进行增、删、改、查操作。事务操作是原子的，一个事务内的所有操作要么全部执行成功，要么全部执行失败。如果执行事务时出现并发写入，云数据库会再次尝试执行整个事务，确保整个事务操作的一致性。

前提条件：

存储区的数据同步模式为缓存模式。

注意事项：  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250714155404.95472465095792373319084937245570:50001231000000:2800:D3CEE15820D182C97DB4A860780483472B28390142D8CAF6F0D0D67D36E48979.png)  
请先关注注意事项。

* 仅当存储区为打开状态时，才可以执行事务操作，否则会导致事务执行失败。

<!-- -->

* 事务中的查询操作必须在写入操作之前，否则将导致事务执行异常。
* 仅在正常连接网络时可执行事务操作，一旦离线该操作将失败。
* 一个事务中多次查询结果的总数据大小不能超过5MB，否则会导致事务失败。
* 一个事务中多次查询结果的总数据条数不能超过1000条，否则会导致事务失败。
* 一个事务中包含的写入和删除对象的总条数不能超过1000条，否则会导致事务执行失败。
* 一个事务内的多次写入和删除操作的数据总大小不能超过2MB，否则会导致事务执行失败。

代码示例：  
使用如下方法，通过事务删除云侧出版日期早于1990年的书籍。

```
"Java"
//先定义一个事务操作，封装查询和删除操作。
public void deleteOverdueBooks(CloudDBZoneQuery<BookInfo> query) {
	Transaction.Function function = new Transaction.Function() {
		@Override
		public boolean apply(Transaction transaction) {
			try {
				List<BookInfo> bookInfos = transaction.executeQuery(query);
				transaction.executeDelete(bookInfos);
			} catch (AGConnectCloudDBException e) {
				e.printStackTrace();
				return false;
			}
			return true;
		}
	};
	mCloudDBZone.runTransaction(function);
}

//构造查询条件，调用定义的事务操作，完成删除操作。
try {
	CloudDBZoneQuery<BookInfo> query = CloudDBZoneQuery.where(BookInfo.class)
		.lessThan(BookEditFields.PUBLISH_TIME, DateUtils.parseDate("1990-01-01"));
	deleteOverdueBooks(query);
} catch (AGConnectCloudDBException e) {
	e.printStackTrace();
}
```

```

#### 全程加密数据

云数据库提供隐私或者敏感数据的全程加密管理能力。该功能开启后，用户数据将在端侧进行加密，然后再以密文形式发送并存储到云侧，只有用户依据其输入的密码才能获取密钥信息并访问自己的加密数据。从而有效提升用户数据的安全性，防止用户云侧数据泄露。

您在AGC控制台上创建对象类型并设置加密字段，即可开启针对该字段的全程加密功能。在您将对象类型文件导入至本地开发环境后，需要使用[setUserKey()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agconnectclouddb-0000001127717605#section11436154514211)方法设置用户密码，云数据库会使用该密码派生出密钥信息，并将加密后的密钥信息和加密后的用户数据以密文形式保存在云侧，加密密钥将会和用户账号绑定，只有该用户依据其设置的密码才能获取密钥信息并访问自己的加密数据。用户密码由用户保存，不会同步至云侧。

注意事项：  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250714155404.47073374829423566961433371183575:50001231000000:2800:E80B092CDA684F4CD8FFD85A03EC12532A98D951B694E131647A4440AD6CA4B7.png)  
请先关注注意事项。

* 如果未调用[setUserKey()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agconnectclouddb-0000001127717605#section11436154514211)方法设置用户密码，则该对象类型的数据无法同步至云侧，且无法对云侧该对象类型的数据进行操作。
* 云数据库不会保存用户密码，需要应用开发者自定义用户密码管理策略。
* 查询全程加密数据时，当前支持的查询谓词包含equalTo()、notEqualTo()、isNull()、isNotNull()、greaterThan()、greaterThanOrEqualTo()、lessThan()、lessThanOrEqualTo()、orderByAsc()、orderByDesc()、limit()、startAt()、startAfter()、endAt()和endBefore()，同时支持聚合查询中的executeCountQuery()方法和关系谓词and()、or()、beginGroup()、endGroup()。
* 开启全程加密数据管理功能后，我们建议您在端侧开启本地数据库加密，保障本地数据安全。
* 设置或者修改云数据库数据全程加密的用户密码，允许自定义用户密码强弱校验。如果开启强校验，当首次设置和修改用户密码时，对用户密码进行强校验，其它场景默认进行弱校验。
* 修改用户密码时，需要先校验原用户密码，校验成功后，才能修改用户密码。如未先校验用户原密码或者校验失败，操作加密数据会失败。

#### 管理存储区

存储区是一个数据存储区域，每个存储区互相独立，之间的数据没有关联。一个云数据库实例中可以创建多个存储区。

云数据库的数据同步模式包括缓存模式和本地模式，数据同步模式以存储区为粒度进行设置。您在开发应用时，可以根据应用需求为每个存储区选择不同的数据同步模式。不同的数据同步模式可管理的数据不一样，具体如下：

* 缓存模式 在该模式下，您可实现数据的端云协同管理，实现端云、多端之间的数据同步。应用数据将储存在云侧，端侧数据是云侧数据的子集，如果允许持久化，云数据库支持将查询的结果自动缓存至端侧。缓存数据时，不会覆盖本地未同步完成的数据。

<!-- -->

* 本地模式 在该模式下，用户仅可操作端侧所包含的本地数据，无法实现数据在端云、多端间的同步。

一个存储区内可以定义多个对象类型，支持不同的业务需求。每个存储区拥有完全相同的对象类型定义，您可以根据应用的需要自定义存储区中存储的对象。

如果您不再使用某个存储区，可将其暂时关闭。您也可根据需要彻底删除该存储区，从而释放相应的资源。

* 在本地模式下，删除存储区后，会同时删除其在磁盘上存储的数据文件，并且无法恢复。
* 在缓存模式下，删除存储区后，仅删除端侧存储的数据文件，云侧的数据文件将会继续存在，您可通过再次创建存储区，获取相应的数据。

注意事项：  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250714155404.55024447542463021413032618488173:50001231000000:2800:0FF96D6383CD9495192329C08D54DC10B8DF7FE91CFF0FBB7FBEB11327EF7763.png)  
操作前，请先关注注意事项。

* 仅在关闭存储区之后，才能执行删除存储区的操作。
* 创建或者打开一个存储区后，才能对该存储区进行相关数据操作。
* 可以多次打开某个存储区，但在使用完存储区后，都需要关闭该存储区，即每个打开操作需要一个对应的关闭操作。
* 创建存储区成功后，不允许修改CloudDBZoneConfig中的存储区数据同步属性。在创建存储区成功后，再次打开该存储区时，系统会校验本次CloudDBZoneConfig中指定的数据同步属性与创建CloudDBZoneConfig时指定的数据同步属性是否一致，如果不一致，系统会抛出异常。

#### 管理版本升级

应用版本升级时，可在AGC控制台上导出对应版本文件，添加至本地开发环境。并通过调用AGConnectCloudDB类中的[createObjectType()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agconnectclouddb-0000001127717605#section114216263118)实现新对象类型的创建，调用[openCloudDBZone2()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agconnectclouddb-0000001127717605#section139511251101214)打开指定存储区，完成对象类型版本的升级。在端侧版本升级完成后，对象类型中新增字段的值为空值或者默认值，已有字段的数据保持不变。在缓存模式下，端侧数据会在端侧查询云侧数据时，依据查询结果将最新的数据更新至本地；如果未进行查询云侧数据操作，则云侧数据不会更新至端侧，端侧数据将保持为升级完成后状态，即新增字段的值为空值或者默认值，已有字段的数据保持不变。
