# 列举文件

列举文件是指获取某个目录下的所有文件和目录信息，云存储SDK支持通过API列举云端某个目录下的所有文件或子目录。  

#### 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)
* 您已[初始化存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-initialize-bucket-harmony-java-0000001491122784)。  

#### 操作步骤

1. 创建目录的引用。 在列举某个目录下的文件或目录前，需要先调用[AGCStorageManagement.getStorageReference](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-storage-agcstoragemanagement-0000001545702281#section9635163510919)创建目录的引用。例如创建根目录的引用：

   ```
   "Java"
   StorageReference reference = storageManagement.getStorageReference();
   ```

2. 调用[StorageReference.listAll](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-storage-storagereference-0000001494662550#section090811803512)可获取当前目录下所有文件与目录。  

   ```
   "Java"
   HarmonyTask<ListResult> listTask = storageManagement.getStorageReference().listAll();
   ListResult listResult = HarmonyTasks.await(listTask);
   ```

   如果需要分页获取，可以调用[StorageReference.list](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-storage-storagereference-0000001494662550#section642665323117)(int max, String marker)方法。  

   ```
   "Java"
   HarmonyTask<ListResult> listTask = storageManagement.getStorageReference().list(50,"markerValue");
   ListResult listResult = Tasks.await(listTask);
   ```

3. 从[ListResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-storage-listresult-0000001494822438)中获取某个子目录的引用后，可以继续调用list方法获取子目录下的文件和目录。  

   ```
   "Java"
   HarmonyTask<ListResult> listTask = storageManagement.getStorageReference("images/").listAll();
   ListResult listResult = HarmonyTasks.await(listTask);
   ```

<!-- -->

4. 从[ListResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-storage-listresult-0000001494822438)中获取某个文件的引用后，可以获取文件的详细元数据。  

   ```
   "Java"
   StorageReference reference = listResult.getFileList().get(0);
   HarmonyTask<FileMetadata> metaTask = reference.getFileMetadata();
   ```
