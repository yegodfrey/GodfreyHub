# 集成SDK

## 前提条件

* 安装HUAWEI DevEco Studio 3.1及以上版本
* 配置 SDK API Version 9及以上
  * Compile SDK Version 9及以上
  * Compatible SDK Version 9及以上

## 添加应用配置文件

1. [获取"agconnect-services.json"文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-obtain-files-0000001276801300#section99771326132714)。
2. 将"agconnect-services.json"文件拷贝到DevEco Studio项目的"AppScope/resources/rawfile"目录下。 说明
   >
   > "AppScope/resources"目录下默认不存在"rawfile"文件夹，需要您手动创建。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/df/v3/xC2uFwN3TRKQ_5wDLDrn1Q/zh-cn_image_0000001832249869.png?HW-CC-KV=V1&HW-CC-Date=20260916T034030Z&HW-CC-Expire=31536000000&HW-CC-Sign=A05C2CA014944A3F90EF9A780A09099E4B3730D0ACBA67FD710430ED9E209D21)

## 配置SDK依赖

添加配置文件后，需要在DevEco Studio项目中配置SDK依赖，您可以通过以下任意一种方式配置SDK依赖：

### 方式一

1. 打开DevEco Studio应用级（一般为entry）下的"oh-package.json5"文件。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/65/v3/y4LShKyhRdqHxrFRyPh-Ag/zh-cn_image_0000001631086642.png?HW-CC-KV=V1&HW-CC-Date=20260916T034030Z&HW-CC-Expire=31536000000&HW-CC-Sign=64124741CF96D7DFD4BBE79CC6C0A7E77B7BCDE269A278D6BDB7CE577EE4FE79)

2. 在"oh-package.json5"文件里面添加认证服务的编译依赖和SDK依赖。

   ```screen
   "dependencies": {
     "@hw-agconnect/hmcore": "^1.0.6",
     "@hw-agconnect/cloud": "^1.0.6"
   } 
   ```


3. 打开修改完的"oh-package.json5"文件，右上方出现"Sync Now"链接，点击"Sync Now"等待同步完成。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1d/v3/Rbg3EVNKQd-fPIJOP9Guew/zh-cn_image_0000002427995292.png?HW-CC-KV=V1&HW-CC-Date=20260916T034030Z&HW-CC-Expire=31536000000&HW-CC-Sign=733CCE917D77542F51F83D556A7DC7B50037A0073F5D4E035A2D98D026B795F7)

### 方式二

1. 打开您的工程，在命令行窗口执行**cd** **entry** 命令，切换到工程的"entry"目录。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b9/v3/hBBAdaY6QHGOTa2FMD7nog/zh-cn_image_0000001679926133.png?HW-CC-KV=V1&HW-CC-Date=20260916T034030Z&HW-CC-Expire=31536000000&HW-CC-Sign=0BCA5B02C3DC0DA4914F0BCC16709F49FCDE88B1CFC74B262B98DDE47199D2F5)
2. 安装SDK到您的项目中。

   ```screen
   ohpm install @hw-agconnect/hmcore
   ohpm install @hw-agconnect/cloud
   ```

## 集成AGC SDK

> 说明
>
> * 工程的应用框架必须为Stage模型，即"apiType"为"stageMode"。
> * Stage模型仅Compile API版本为9及以上版本时支持，请确保SDK的Compile API版本不低于9。
> * 请确保采用ohpm方式编译。
> * SDK也支持开发OpenHarmony应用（API 9及以上版本）。

1. 在您的项目中导入agc组件。

   ```screen
   import { initialize } from '@hw-agconnect/hmcore';
   ```

2. 在您的应用初始化阶段使用context初始化SDK，推荐在EntryAbility的onCreate中进行。

   ```screen
   import util from '@ohos.util';

   // 初始化SDK
   async onCreate(want, launchParam) {
   let input = await this.context.resourceManager.getRawFileContent('agconnect-services.json')
       let jsonString  = util.TextDecoder.create('utf-8', {
         ignoreBOM: true
       }).decodeWithStream(input, {
         stream: false
       });

       initialize(this.context, JSON.parse(jsonString));
   }
   ```

3. 在"entry/src/main/module.json5"文件中添加网络权限。

   ```screen
   "requestPermissions": [
     {
       "name": "ohos.permission.INTERNET"
     }
   ]
   ```

## （可选）设置配置文件参数

如果您在下载配置文件时选择了"不包含密钥"，配置信息中将不包含Client ID、Client Secret和API密钥（凭据），您还需调用AGC SDK的接口手动将密钥传给AGC使用。

1. 在"项目设置 > 常规"页面中获取Client Secret和API密钥（凭据）。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/17/v3/6RYE1LiKReOQk_80Sj2Juw/zh-cn_image_0000001786398600.png?HW-CC-KV=V1&HW-CC-Date=20260916T034030Z&HW-CC-Expire=31536000000&HW-CC-Sign=5E5D4729BE1764CC672492CE0A714CDB1337D9617071A21E6EDA0A3B0A19D455)


2. 在应用启动调用AGC的初始化方法完成后将参数设置给AGC SDK。

   ```screen
   import { initialize } from '@hw-agconnect/hmcore';
   import { setApiKey } from '@hw-agconnect/hmcore';
   import { setClientSecret } from '@hw-agconnect/hmcore';

   initialize(this.context, JSON.parse(jsonString));
   setApiKey("xxx"); // 设置API密钥（凭据）
   setClientSecret("xxx"); // 设置Client Secret
   ```
