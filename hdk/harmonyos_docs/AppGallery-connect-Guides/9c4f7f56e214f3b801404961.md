# 典型应用场景

#### 加密用户个人数据

应用需要对用户的个人数据进行加密存储或者传输时，可使用Aegis安全编码SDK对数据进行对称加密或者非对称加密，保障用户个人数据的机密性。  

#### 验证数字签名

应用需要对服务端返回的信息或者其他应用传入的信息进行数字签名验证，调用Aegis安全编码SDK验签接口，确保信息的完整性和不可抵赖性。  

#### 保障敏感信息安全

为保障敏感信息传输过程中的完整性、不可抵赖性和机密性，可以调用Aegis安全编码SDK签名和加密接口，将敏感信息先签名后加密。
