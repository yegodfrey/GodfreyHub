# 初始化存储实例

#### 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[集成云存储SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-sdk-java-0000001115496716)。  

#### 操作步骤

调用[AGCStorageManagement.getInstance](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragemanagement-0000001111669018#section13927195542417)方法来初始化存储实例。

```
// "regionname" => 存储region名称，您可以打开凭据文件查看项目归属区域，并通过区域查找归属于该区域的存储region。
// "CN" : ["cn-north-4"]
// "SG" : ["ap-southeast-3"]
// "RU" : ["ru-northwest-2"]
// "DE" : ["eu-de"]
// "bucketname" => 存储实例名称，您可以通过在“项目设置>Serverless>云存储”页面中的存储实例框中获取存储实例名称。
// agcClient => 使用认证凭据初始化SDK时返回的AGCClient类的实例。当您创建的存储实例所属区域非您设置的默认数据处理位置时，您需要初始化对应区域的AGCClient类的实例并传递给该接口。
StorageManagement storageManagement = AGCStorageManagement.getInstance(agcClient, "regionname", "bucketname");
```
