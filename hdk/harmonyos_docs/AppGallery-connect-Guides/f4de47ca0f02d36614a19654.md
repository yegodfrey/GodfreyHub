# 新斗罗大陆

#### 客户需求

《新斗罗大陆》是上海玄霆娱乐信息科技有限公司旗下一款策略卡牌手游。在游戏运行期间，出现了偶发的网络接口请求耗时长问题。该问题导致用户进入游戏变慢，游戏体验变差，易造成用户流失。该公司希望可以快速定位网络接口请求耗时长问题。  

#### 华为解决方案

《新斗罗大陆》游戏接入AGC性能管理服务后，该公司通过网络请求多维度分析，快速识别出耗时异常接口，并进行优化。耗时异常接口的耗时从最高5000ms降低到200ms以下，游戏登录速度提升96%，游戏登录的加载时长大幅降低，实现秒进游戏的目标，极大的提升了用户游戏体验。
