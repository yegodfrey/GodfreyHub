# 授权浏览器麦克风访问权限

由于游戏多媒体服务的Web SDK需要使用麦克风访问权限，因此，您需要授权浏览器允许访问麦克风。本章节主要介绍几种主流浏览器的麦克风访问权限的授权设置操作。

## 谷歌浏览器

1. 打开谷歌浏览器，点击右上角设置图标，并点击"设置"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241105115855.21468278915921139555336037071334:50001231000000:2800:6DF670416E9C98FC0C2CBCBD2F08EF008559C2F8133BF46D40049367096684FC.png?needInitFileName=true?needInitFileName=true)

2. 在"设置"页面，选择"安全和隐私设置"，并点击"网站设置"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241105115855.74596818124911510991330610528137:50001231000000:2800:7843A74630F9919C5302BD22F3CF71C692426DF17B0F70CAA987A60AC5D7F517.png?needInitFileName=true?needInitFileName=true)

3. 在"网站设置"页面，选择"麦克风"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241105115855.96226670820009811800118339732196:50001231000000:2800:C44D511CF4C3F03D655E94F3E2BA919AF4ACEC4D171724AFCA4DB2C4396B028B.png?needInitFileName=true?needInitFileName=true)

4. 在麦克风授权页面，选择"网站可以请求使用您麦克风"的权限设置。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241105115855.67192122867187272338488945624094:50001231000000:2800:D2A556FAE35C8E022C4C98667A0189AAB23119A1D4872E9BF0EA8C5E8BC57BED.png?needInitFileName=true?needInitFileName=true)

5. 完成以上设置后，当浏览器在需要使用麦克风时，则会在页面弹出设备询问框，通过开关控件，选择允许即可。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241105115855.06863138515516381381824849556099:50001231000000:2800:5331A7521B4EF294AF36A80026778E38C20C961131037342A82F5D2E06BBD7DB.png?needInitFileName=true?needInitFileName=true)
