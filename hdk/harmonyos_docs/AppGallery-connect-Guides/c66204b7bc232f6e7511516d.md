# 使用数据库的其他操作

## 映射对象类型

云数据库提供映射对象类型文件的能力。您在使用Server SDK开发本地应用时，可直接将AGC控制台上导出的java格式的对象类型文件添加至本地开发环境，如果java格式的对象类型文件中有不符合Java语言规范的对象类型名称和字段名称，您可以修改类名（即对象类型名称）和属性名（即字段名称），并通过添加注解的方式建立云侧与本地开发环境中对象类型的映射关系，并在后续的开发中使用映射后的对象类型名称和字段名称，使其适配语言规范格式。在映射对象类型文件时，通过**[ObjectTypeMapping](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-objecttypemapping-serverjava-0000001409024992)** 映射java文件中的类，对应对象类型名称；通过**[FieldMapping](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-fieldmapping-serverjava-0000001459744477)**映射java文件中的属性，对应对象类型中的字段名。

**注意事项：**
> 注意
>
> 请先关注注意事项。

* 映射对象类型名称时，对象类型名称区分字母的大小写，对象类型原名称需与AGC控制台上的对象类型名称保持一致。
* 映射字段名称时，字段原名称需与AGC控制台上的字段名完全一致。
* 映射字段名称成功后，若字段名为入参，需使用修改后的对象属性名。
* 映射对象类型时，不支持修改索引和主键注解中的字段名称，索引和主键注解的字段名需要与AGC控制台上创建的对象类型字段名完全一致。

**操作步骤：**

1. 将已在AGC控制台上导出的全部java格式文件添加至本地开发环境。 如果文件已存在，请覆盖原文件。

2. 打开不符合命名规范的**book_info.java** 文件，示例如下所示。

   ```screen
   @PrimaryKeys({"id"})
   public final class book_infoextends CloudDBZoneObject {
       private Long id;
       private Date publish_time;

       public book_info() {
           super(book_info.class);
       }
       
       public void setId(Long id) {
           this.id= id;
       }

       public String getId() {
           return id;
       }

       public void setPublish_time(Date publish_time) {
           this.publish_time = publish_time
       }

       public String getPublish_time() {
           return publish_time;
       }
   }
   ```

3. 映射对象类型文件，映射成功后需要修改项目中所有使用到该对象类型名称和字段名的内容。
   1. 映射对象类型文件的类名。通过为类名添加**[@ObjectTypeMapping](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-objecttypemapping-serverjava-0000001409024992)** 注解，将对象类型名"BookInfo"映射为"book_info"，并修改对应构造器与文件名。

      ```screen
      @PrimaryKeys({"id"})
      @ObjectTypeMapping("book_info")
      public final class BookInfo extends CloudDBZoneObject {
          private Long id;
          private Date publish_time;

          public BookInfo() {
              super(BookInfo.class);
          }
          
          public void setId(Long id) {
              this.id= id;
          }

          public String getId() {
              return id;
          }

          public void setPublish_time(Date publish_time) {
              this.publish_time = publish_time
          }

      public String getPublish_time() {
              return publish_time;
          }
      }
      ```

   2. 映射对象类型文件的属性名。通过为属性名添加**[@FieldMapping](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-fieldmapping-serverjava-0000001459744477)** 注解，将字段名"publish_time"映射为"publishTime"。

      ```screen
      @PrimaryKeys({"id"})
      @ObjectTypeMapping("book_info")
      public final class BookInfo extends CloudDBZoneObject {
          private Long id;
          @FieldMapping("publish_time")
          private Date publishTime;

          public BookInfo() {
              super(BookInfo.class);
          }
          
          public void setId(Long id) {
              this.id= id;
          }

          public String getId() {
              return id;
          }

          public void setPublishTime(Date publishTime) {
              this.publishTime = publishTime
          }

      public String getPublishTime() {
              return publishTime;
          }
      }
      ```

4. 初始化云数据库，详细请参见[初始化](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-sdk-integration-serverjava-0000001518546764#section646116407458)。

## 支持泛化对象

云数据支持泛化对象的能力，开发者在使用Server SDK时，不用依赖原来的对象类型文件。您在AGC控制台创建对象类型后，可以直接使用创建泛化对象的方式进行数据操作，当云侧数据库的对象类型结构发生变化时，您可以修改泛化对象中的对象类型结构，从而实现基于泛化对象的数据操作，提高用户操作的灵活性。

您可以通过**[CloudDBZoneGenericObject()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonegenericobject-serverjava-0000001416232940)**类来配置泛化对象，泛化对象支持对云侧数据库的数据进行增、删、改、查和事务等操作。

**注意事项：**
> 注意
>
> 请先关注注意事项。

* 添加泛化对象时，对象类型和字段名需要遵循创建时的约束，请参考[修改对象类型](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-agcconsole-objecttypes-0000001127675459#section3873193085413)。
* 不支持将主键字段、加密字段和敏感字段添加到泛化对象中。
* 泛化对象查询数据时，将按照以下规则返回结果。
  * 数据类型为Date的字段返回String类型的UTC时间，时间格式为YYYY-MM-DD HH:mm:ss SSS；
  * 数据类型为ByteArray的字段返回Base64编码的字符串；
  * 数据类型为Long、Float、Double和LongAutoIncrement的字段返回字符串。

**配置泛化对象**：

1. 调用**[build](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonegenericobject-serverjava-0000001416232940#section145771757615)** 方法创建一个**CloudDBZoneGenericObject** 对象，并输入对应的对象类型名称。

   ```screen
   CloudDBZoneGenericObject bookInfo1 = CloudDBZoneGenericObject.build("BookInfo");
   ```

2. 调用**[addFieldValue](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonegenericobject-serverjava-0000001416232940#section16294152782615)** 方法为泛化对象添加字段和对应的值。

   ```screen
   bookInfo1.addFieldValue("id", 1);
   bookInfo1.addFieldValue("bookName", "Harry Potter");
   bookInfo1.addFieldValue("author", "J. K. Rowling");
   bookInfo1.addFieldValue("price", 80.99d);
   bookInfo1.addFieldValue("publisher", "Bloomsbury Publishing (UK)");
   bookInfo1.addFieldValue("publishTime", DateUtils.parseDate("1997-07-26 00:00:00 000"));
   ```

3. 获取泛化对象中的值。
   * 调用**[getFieldValue](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonegenericobject-serverjava-0000001416232940#section19329430152619)** 方法获取泛化对象中对应字段的值。

     ```screen
     Object value = bookInfo1.getFieldValue("bookName");
     ```

   * 调用**[getFieldMap](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonegenericobject-serverjava-0000001416232940#section4179533132610)** 方法获取泛化对象中所有的字段和值。

     ```screen
     Map<String, Object> fieldMap = bookInfo1.getFieldMap();
     for (Map.Entry<String, Object> entry : fieldMap.entrySet()) {
         System.out.println("Field: " + entry.getKey());
         System.out.println("Value: " + entry.getValue());
     }
     ```

## 写入数据

您可以通过**[executeUpsert()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section186709715599)** 或**[executeInsert()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section1241014559586)**将一个或者一组对象写入到当前存储区中。在写入对象时，如果在存储区已经存在主键值相同的对象，则更新已有的对象；如果不存在，则写入一个新的对象。写入的数据可以来自于新建对象，或者从存储区查询出来的对象。

* 在使用**executeUpsert()**写入对象时，如果在存储区中已经存在主键值相同的对象，则更新已有的对象；如果不存在，则写入一个新的对象。
* 在使用**executeInsert()**写入对象时，如果在存储区已经存在主键值相同的对象，则写入失败；若不存在，则写入一个新的对象。

写入一组对象时，数据的写入操作是原子的，即对象列表中的对象要么全部成功写入，要么全部失败。

调用写入数据方法后，会返回一个**CompletableFuture** 对象，对象中封装了写入操作执行的状态、结果和异常信息等。通过该**CompletableFuture**对象可以获取执行结果：执行成功，可以获取写入的对象数量；执行失败，可以获取对应的异常信息。

**注意事项：**
> 注意
>
> 请先关注注意事项。

* 写入一组对象时，该组中的对象必须属于同一个对象类型，否则会导致写入失败。
* 进行写入操作时，系统会忽略加密字段和敏感字段的数据。

**代码示例：**

* 使用**executeUpsert()** 方法将**BookInfo** 对象写入至存储区中，写入成功后，返回写入的数量；写入失败，抛出异常。

  ```screen
  "具体对象"
  public void upsertBookInfos(List<BookInfo> bookInfos) {
      if (mCloudDBZone == null) {
          LOGGER.warn("CloudDBClient is null, try re-initialize it");
          return;
      }
      try {
          CompletableFuture<Integer> result = mCloudDBZone.executeUpsert(bookInfos);
          System.out.println(result.get());
      } catch (AGConnectCloudDBException | InterruptedException | ExecutionException e) {
          LOGGER.warn("upsertBookInfos: " + e.getMessage());
      }
  }
  ```

  ```screen
  "泛化对象"
  public void upsertBookInfos(List<CloudDBZoneGenericObject> bookInfos) {
      if (mCloudDBZone == null) {
          LOGGER.warn("CloudDBClient is null, try re-initialize it");
          return;
      }
      try {
          CompletableFuture<Integer> result = mCloudDBZone.executeUpsert(bookInfos);
          System.out.println(result.get());
      } catch (AGConnectCloudDBException | InterruptedException | ExecutionException e) {
          LOGGER.warn("upsertBookInfos: " + e.getMessage());
      }
  }
  ```

* 使用**executeInsert()** 方法将**BookInfo** 对象写入至存储区中，写入成功后，返回写入的数量；写入失败，抛出异常。


## 更新数据

您可以通过**[executeBatchUpdate()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section1771340123818)** 或者**[executeBatchUpdateByCondition()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section22061653514)**更新满足条件的一个或者多个字段的值。在更新数据时，如果满足更新的约束条件，操作成功，返回具体更新条数；如果不满足更新的约束条件时，返回"0"。

**注意事项：**

* 进行更新操作时，需要保证更新后该对象的数据大小不能超过2MB，否则会导致该对象查询失败。


* 不支持对主键字段、加密字段和敏感字段的值进行更新操作。
* 同一个**[executeBatchUpdate()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section1771340123818)** 或者**[executeBatchUpdateByCondition()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section22061653514)** 操作中，**[increment()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzoneobjectoperator-serverjava-0000001420347222#section7617134411476)** 和**[update()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzoneobjectoperator-serverjava-0000001420347222#section289310261498)**方法不能操作同一个字段，否则会抛出错误。
* 使用**[executeBatchUpdate()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section1771340123818)** 或者**[executeBatchUpdateByCondition()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section22061653514)** 进行**[increment()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzoneobjectoperator-serverjava-0000001420347222#section7617134411476)**时，支持Short、Integer、Long、Float和Double这5种数据类型。

**根据条件更新数据：**

通过**[executeBatchUpdate()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section1771340123818)** 或者**[executeBatchUpdateByCondition()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section22061653514)** 方法根据条件更新数据时，调用**[increment()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzoneobjectoperator-serverjava-0000001420347222#section7617134411476)** 方法，将满足条件的**BookInfo** 对象中"price"的值增加38.8，约束条件通过**CloudDBZoneObjectOperatorConstraint** 类构造"id"大于"10"并且小于"20"；调用**[update()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzoneobjectoperator-serverjava-0000001420347222#section289310261498)** 方法，将满足条件的**BookInfo**对象中"publisher"更新为"xxx"。如果此次条件更新满足约束，则更新成功，返回具体更新条数；不满足则返回"0"。

**以executeBatchUpdateByCondition()方法为例：**

```screen
"具体对象"
public void updateBookInfo() {
    
    if (mCloudDBZone == null) {
        LOGGER.warn("CloudDBClient is null, try re-initialize it");
        return;
    }
    try {
        CloudDBZoneObjectOperator<BookInfo> operator = CloudDBZoneObjectOperator.build(BookInfo.class);
        operator = operator.increment(BookEditFields.PRICE, 38.8);
        operator.update(BookEditFields.PUBLISHER, "xxx");
        CloudDBZoneObjectOperatorConstraint<BookInfo> constraint =
            CloudDBZoneObjectOperatorConstraint.where(BookInfo.class);
        constraint.greaterThanOrEqualTo(BookEditFields.ID, 10).lessThan(BookEditFields.ID, 20);
        CompletableFuture<Integer> completableFuture = cloudDBZone.executeBatchUpdateByCondition(operator, constraint);
        LOGGER.info("UpdateBookInfo number: " + completableFuture.get());
    } catch (AGConnectCloudDBException | ExecutionException | InterruptedException e) {
        LOGGER.warn("updateBookInfo: " + e.getMessage());
    }
}
```

```screen
"泛化对象"
public void updateBookInfo() {
    if (mCloudDBZone == null) {
        LOGGER.warn("CloudDBClient is null, try re-initialize it");
        return;
    }
    try {

        CloudDBZoneObjectOperatorConstraint<CloudDBZoneGenericObject> constraint =
            CloudDBZoneObjectOperatorConstraint.where("BookInfo");

        LOGGER.info("UpdateBookInfo number: " + completableFuture.get());
    } catch (AGConnectCloudDBException | ExecutionException | InterruptedException e) {

    }
}
```

## 查询数据

云数据库通过**[executeQuery()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section696713285599)** 方法查询对象，并提供了丰富的谓词查询，比如**equalTo()、notEqualTo()、in()** 等。通过单个或者多个链式过滤条件，您可以从存储区查询到满足特定条件的对象，也可以通过排序谓词对查询结果排序，或者通过限定查询返回数量谓词限定查询结果返回的数量。详细的查询条件请参见**[CloudDBZoneQuery](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-serverjava-0000001127830643)**。

根据查询结果返回的对象，调用**CompletableFuture<CloudDBZoneSnapshot>** 类的**get()** 可以获取存放在对象里的**CloudDBZoneSnapshot**对象。云数据库在支持基本查询的同时，还支持查询平均值、最大值和最小值等。

**注意事项：**
> 注意
>
> 请先关注注意事项。

* 每次的查询操作仅支持查询一个对象类型下的数据。
* 查询加密字段或敏感字段时，查询结果为空。
* 构造查询条件时，加密字段和敏感字段不能作为查询条件。
* 查询数据时，仅支持对加密字段和敏感字段进行**[executeCountQuery()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section2791813507)**查询。

### 简单查询

您可以在无查询条件时，获取一个对象类型中所有的对象；也可以指定单个查询条件，来获取满足该条件的对象。

* 查询对象类型**BookInfo** 的所有数据。

  ```screen
  "具体对象"
  public void queryAllBooks() {
      if (mCloudDBZone == null) {
          LOGGER.warn("CloudDBClient is null, try re-initialize it");
          return;
      }
      try {
          CompletableFuture<CloudDBZoneSnapshot<BookInfo>> result =
          mCloudDBZone.executeQuery(CloudDBZoneQuery.where(BookInfo.class));
          CloudDBZoneSnapshot<BookInfo> snapshot = result.get();
          processQueryResult(snapshot);
      } catch (AGConnectCloudDBException | InterruptedException | ExecutionException e) {
          LOGGER.warn("queryAllBooks: " + e.getMessage());
      }
  }
  ```

  ```screen
  "泛化对象"
  public void queryAllBooks() {
      if (mCloudDBZone == null) {
          LOGGER.warn("CloudDBClient is null, try re-initialize it");
          return;
      }
      try {

          mCloudDBZone.executeQuery(CloudDBZoneQuery.where("BookInfo"));

          processQueryResult(snapshot);
      } catch (AGConnectCloudDBException | InterruptedException | ExecutionException e) {
          LOGGER.warn("queryAllBooks: " + e.getMessage());
      }

  ```

* 通过异步侦听的方式查询"bookName"为"左传"的书籍。
  * 构造查询方法**queryBooks** ，该方法同时供后续查询示例引用。

    ```screen
    "具体对象"
    public void queryBooks(CloudDBZoneQuery<BookInfo> query) {
        if (mCloudDBZone == null) {
            LOGGER.warn("CloudDBClient is null, try re-initialize it");
            return;
        }
        try {
            CompletableFuture<CloudDBZoneSnapshot<BookInfo>> result = mCloudDBZone.executeQuery(query);
            CloudDBZoneSnapshot<BookInfo> snapshot = result.get();
            processQueryResult(snapshot);
        } catch (AGConnectCloudDBException | InterruptedException | ExecutionException e) {
            LOGGER.warn("queryBooks: " + e.getMessage());
        }
    }

    private void processQueryResult(CloudDBZoneSnapshot<BookInfo> snapshot) {
        List<BookInfo> bookInfos = snapshot.getSnapshotObjects();
        for (BookInfo bookinfo : bookInfos) {
            System.out.println("Book Name: " + bookinfo.getBookName());
        }
    }
    ```

    ```screen
    "泛化对象"
    public void queryBooks(CloudDBZoneQuery<CloudDBZoneGenericObject> query) {
        if (mCloudDBZone == null) {
            LOGGER.warn("CloudDBClient is null, try re-initialize it");
            return;
        }
        try {
            CompletableFuture<CloudDBZoneSnapshot<CloudDBZoneGenericObject>> result = mCloudDBZone.executeQuery(query);
            CloudDBZoneSnapshot<CloudDBZoneGenericObject> snapshot = result.get();
            processQueryResult(snapshot);
        } catch (AGConnectCloudDBException | InterruptedException | ExecutionException e) {
            LOGGER.warn("queryBooks: " + e.getMessage());
        }
    }

    private void processQueryResult(CloudDBZoneSnapshot<CloudDBZoneGenericObject> snapshot) {
        List<CloudDBZoneGenericObject> bookInfos = snapshot.getSnapshotObjects();
        for (CloudDBZoneGenericObject bookinfo : bookInfos) {
            System.out.println("Book Name: " + bookinfo.getFieldValue("bookName"));
        }
    ```

### 分页查询

在查询数据时，您可以通过[元组查询](#section09972107254)和**[limit()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-serverjava-0000001127830643#section21131850623)** 方法结合使用实现数据的分页查询，也可以直接通过**[limit()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-0000001080569968#section1602122111011)**实现分页查询。例如与排序查询谓词或者等值查询谓词组合使用，可以实现获取某个对象之前或者之后的数据记录。

为了保证分页查询的性能，云数据库要求您在构造分页查询条件前，先创建查询所需的索引。如果未创建索引，您可能会收到一个异常信息，您需要根据异常信息创建缺少的索引。创建索引请参见[新增对象类型](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-sdk-integration-serverjava-0000001518546764#section8375194164915)，创建索引后，您还需要更新本地的对象类型文件，详细请参见[加载对象类型文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-sdk-integration-serverjava-0000001518546764#section4156947195912)。

**通过元祖查询和limit()方法组合使用进行分页查询**

使用**[startAt()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-serverjava-0000001127830643#section43875522214)** 方法定义查询的起始位置，通过与**[limit()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-serverjava-0000001127830643#section21131850623)** 和**[orderByAsc()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-serverjava-0000001127830643#section1410214421029)** 方法结合使用实现数据的分页能力，并将第一次查询结果的最后一条记录，作为下一次查询的起点。

```screen
"具体对象"
BookInfo book = new BookInfo();
book.setId(5);
try {
    // 查询前20条记录
    CloudDBZoneQuery<BookInfo> query = CloudDBZoneQuery.where(BookInfo.class).orderByAsc(BookEditFields.BOOK_ID).startAt(book).limit(20);
    CompletableFuture<CloudDBZoneSnapshot<BookInfo>> result = mCloudDBZone.executeQuery(query);

    // 等待查询结果
    CloudDBZoneSnapshot<BookInfo> snapshot = result.get();

    // 将前20条记录的最后一条，作为查询下一页数据记录的起点（不包含起点），获取下一页数据。
    BookInfo nextBook = snapshot.getSnapshotObjects().get(snapshot.getSnapshotObjects().size() - 1);
    CloudDBZoneQuery<BookInfo> queryNext = CloudDBZoneQuery.where(BookInfo.class).orderByAsc(BookEditFields.BOOK_ID).startAfter(nextBook).limit(20);
    CompletableFuture<CloudDBZoneSnapshot<BookInfo>> resultNext = mCloudDBZone.executeQuery(queryNext);
    CloudDBZoneSnapshot<BookInfo> snapshotNext = resultNext.get();

    // 处理查询结果
    processQueryResult(snapshotNext);
} catch (AGConnectCloudDBException | InterruptedException | ExecutionException e) {
    LOGGER.warn("averageQuery: " + e.getMessage());
}
```

```screen
"泛化对象"
```

## 删除数据

您可以通过**[executeDelete()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section17231417175912)** 删除单个对象或者一组对象的数据，也可以通过**[executeBatchDelete()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section18190184724218)** 或者**[executeBatchDeleteByCondition()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section1670713412813)** 删除满足约束条件的数据。删除数据时，需遵循以下约束：

* 在使用**[executeDelete()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section17231417175912)**删除数据时，Cloud DB会根据传入对象主键删除相应的数据，不会比对该对象其它属性与存储的数据是否一致。删除一组对象时，删除操作是原子的，即对象列表中的对象要么全部删除成功，要么全部删除失败。
* 在使用**[executeBatchDelete()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section18190184724218)** 或者**[executeBatchDeleteByCondition()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section1670713412813)**删除数据时，删除满足指定条件的对象类型。如果满足删除的约束条件，操作成功，返回具体删除条数；如果不满足删除的约束条件，返回"0"。

**注意事项：**
> 注意
>
> 请先关注注意事项。

* 删除一组对象时，该组中的对象必须属于同一个对象类型，否则会导致删除失败。
* 使用**[executeDelete()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section17231417175912)**删除一组对象时，数据总条数不能超过1000条，否则会导致删除失败。
* 每个删除操作包含的字段名和字段值的总大小不能超过20MB，否则会导致删除失败。

**根据对象删除数据：**

使用**[executeDelete()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section17231417175912)** 将对象删除，如果任务执行成功，返回删除对象的个数；执行失败，则返回一个异常。

## 管理回收站数据

云数据库为用户提供数据恢复的能力，提升了数据的安全性和可用性。您可以通过**updateDeletedDataRetentionPeriod**设置回收站的数据保留时间，并同时开启回收站功能。回收站开启后，删除的数据会被保留在回收站，且在数据保留期间，您可以对回收站的数据进行查询、删除和恢复操作。

**注意事项** **：**
> 注意
>
> 请先关注注意事项。

* 回收站为禁用状态时，对应的数据保留天数为0天，删除的数据会被立即删除，数据不可恢复。
* 数据保留天数从数据被删除的次日0点开始计算，数据被删除当日不计入保留天数。


* 数据保留天数到期之后，回收站的数据会被自动删除。
* 回收站为开启状态时，若更新或插入与回收站中相同主键的数据，使用新数据覆盖已删除的数据。原数据从回收站中移除，无法在回收站中查询得到。

**代码示例：**

* 使用**[updateDeletedDataRetentionPeriod](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agconnectclouddb-serverjava-0000001127713495#section129318487579)** 方法设置回收站的数据保留天数为6天，并使用**[queryDeletedDataRetentionPeriod()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agconnectclouddb-serverjava-0000001127713495#section644005115616)** 查询数据保留天数。

## 事务与数据管理

云数据库的事务隔离级别为Read Committed，支持通过**[runTransaction()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section1952513016583)**执行事务，实现对云侧存储区数据的管理操作，包含数据的增、删、改、查操作。事务支持同时对多个对象类型的数据进行增、删、改、查操作。事务操作是原子的，一个事务内的所有操作要么全部执行成功，要么全部执行失败。如果执行事务时出现并发写入，云数据库会再次尝试执行整个事务，确保整个事务操作的一致性。

**注意事项**：
> 注意
>
> 请先关注注意事项。

* 事务中的查询操作必须在写入操作和删除操作之前，否则将导致事务执行异常。
* 仅在正常连接网络时可执行事务操作，一旦离线该操作将失败。
* 一个事务中多次查询结果的总数据条数不能超过1000条，否则会导致事务失败。
* 一个事务中包含的写入和删除对象的总条数不能超过1000条，否则会导致事务执行失败。
* 一个事务中查询、写入和删除操作包含的字段名和字段值的总大小不能超过20MB，否则会导致事务执行失败。

**代码示例：**

使用如下方法，通过事务删除云侧出版日期早于1990年的书籍。

```screen
"具体对象"
//先定义一个事务操作，封装查询和删除操作。
public void deleteOverdueBooks(CloudDBZoneQuery<BookInfo> query) {
    Transaction.Function function = transaction -> {
        try {
            List<BookInfo> bookInfos = transaction.executeQuery(query);
            transaction.executeDelete(bookInfos);
        } catch (AGConnectCloudDBException e) {
            e.printStackTrace();
            return false;
        }
        return true;
    };
    mCloudDBZone.runTransaction(function);
}

//构造查询条件，调用定义的事务操作，完成删除操作。
try {
    CloudDBZoneQuery<BookInfo> query = CloudDBZoneQuery.where(BookInfo.class)
    .lessThan(BookEditFields.PUBLISH_TIME, DateUtils.parseDate("1990-01-01 00:00:00 000"));
    deleteOverdueBooks(query);
} catch (AGConnectCloudDBException e) {
    e.printStackTrace();
}
```
