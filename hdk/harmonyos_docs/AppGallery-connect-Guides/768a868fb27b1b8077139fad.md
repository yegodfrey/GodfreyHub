# 查看用量统计

您可以在AGC控制台选择"云开发（Serverless）> 云存储"，点击"用量统计"页签，查看云存储的使用情况。

## 存储桶统计

"存储桶统计"页面展示当前存储实例下的存储用量、对象数量、网络流量和请求数，您可以在页面右上角选择需要查看数据的时间段（当天、昨天、过去7天、过去30天）。

* 存储用量：上传的文件占用的存储总量。
* 对象数量：上传对象（即文件）的总个数。
* 网络流量：客户端下载文件的总流量。
* 请求数：客户端发送的总请求次数。

点击"静态CDN加速统计"页签，可前往云托管页面，查看静态CDN加速统计数据，详情请参见[用量管理](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-cloudhosting-usage-0000001057642257)。
