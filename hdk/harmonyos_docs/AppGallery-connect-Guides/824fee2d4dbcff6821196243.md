# 发布正式版本

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241209170603.38208810595072057841572240751032:50001231000000:2800:5B1A72DD6E99AF0AD4787438BEEABDBB62123D2BF8C5956CDF87ED823C3414CB.png?needInitFileName=true?needInitFileName=true)

当您根据用户的反馈意见优化您的应用，完成开放式测试后，您可以选择通过升级的方式发布应用的正式版本，发布正式版本的具体操作请参见[升级应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-update-version-0000001146436549)。

值得注意的是，发布正式版本的应用时，在应用发布信息页面的"开放式测试"区域，"是否开放式测试版本"需要选择"否"。
