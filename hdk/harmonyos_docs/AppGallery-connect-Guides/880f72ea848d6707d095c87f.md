# 配置iOS应用信息

当应用平台为iOS时，您需要在AGC配置"App Store ID"和"团队ID"。

1. 在"开发与服务"页面中，点击iOS应用所在项目。
2. 在"项目设置"页面选择"常规"页签。
3. 在"应用"区域，点击![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155603.52919039249786990669178350166923:50001231000000:2800:1C2F9172529878F996A1861CCDA4BC254CC828ABAC6F097CBD5EA0A35D84B95D.png "点击放大")配置"App Store ID"和"团队ID"，即您应用在App Store上的ID和团队ID，完成后点击![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155603.02445542151111013395871606890275:50001231000000:2800:AA07F17004323CE856C187782838F6CD1528A22DFF3EE78CD41976F87E53532F.png "点击放大")保存。
