# 流量治理

## 功能概述

流量治理能力主要为系统提供一些可靠运行的保障措施。针对函数场景下的常用故障模式，提供了负载均衡、重试、熔断等保障措施。由于没有任何治理措施是适用于所有场景的，对于一个应用场景工作良好的治理手段，在另外一个场景可能成为问题，所以在业务运行期间，需要您根据业务运行状态和指标，动态地更新治理策略。
> 说明
>
> * "事件调用"函数和"http请求"函数均支持设置流量治理策略。
> * 每个函数版本都支持新增/修改/删除流量治理配置，且只对被修改版本有效，不影响其他版本。
> * 负载均衡、重试、熔断策略均是针对同一个集群内、同一个函数版本实例之间的故障保障措施。

2. 在"新增重试"弹框中，根据实际需要选择是否开启容错。若开启容错，则选择"重试策略"，配置相关参数后，点击"确定"。

   |:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

   |重试新的函数实例次数|服务调用尝试新的函数实例的次数，取值范围为0~9。|

   |最大重试间隔|重试最大时间间隔，单位ms，取值范围为0~50000。 "重试策略"选择"jittered"时，展示该配置项。|

1. 在函数列表中点击函数名称，进入函数详情页面，选择函数版本。
   * 在$latest版本上配置 函数详情页与$latest版本对应，直接选择"流量治理"页签，点击"熔断"区域右侧的"新增"。

     1. 在函数详情页选择"版本"页签，在版本列表中点击版本号进入版本详情页面。已发布的函数版本比较多时，可在文本框中输入版本或者版本描述进行过滤。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251016140211.05722723196848223133592951699441:50001231000000:2800:CCEE339D274DC28F074EABC7951C5066B83268DFD9096E934C004CA070A8022A.png)

     2. 在版本详情页面，选择"流量治理"页签，点击"熔断"区域右侧的"新增"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251016140211.83736122866083938162242879725427:50001231000000:2800:7AC4E8E0410C24368D3BDC0A504A1BE64DD209DBC77B8EE732A67FCBF683CCA9.png)

2. 在"新增熔断"弹框中，根据实际需要选择是否开启熔断。若开启熔断，配置相关参数后，点击"确定"。 说明
   >
   > 在熔断机制中涉及三种熔断状态：
   > * 熔断关闭状态：当服务访问正常时，熔断器处于关闭状态，服务调用方可以正常地对服务进行调用。
   > * 熔断开启状态：默认情况下，在固定时间内接口调用出错比率达到一个阈值，例如50%，熔断器会进入熔断开启状态。进入熔断状态后，后续对该服务的调用都会被切断，熔断器会执行本地的降级方法。
   >
   >
   > * 半熔断状态： 在熔断开启一段时间之后，熔断器会进入半熔断状态。在半熔断状态下，熔断器会尝试恢复服务调用方对服务的调用，允许部分请求调用该服务，并监控其调用成功率。如果成功率达到预期，则说明服务已恢复正常，熔断器进入关闭状态。如果成功率仍旧很低，则重新进入熔断开启状态。

   |配置项|说明|
   |:--------|:----------------------------------------------------------------|
   |熔断时长|熔断后多久变为半熔断状态，即熔断后多长时间做恢复测试，如果测试成功则恢复服务调用，否则继续熔断。单位为s，取值范围为1~3600。|
   |熔断请求阈值|统计时间窗10s内的请求次数，超过该阈值才会判断是否开启熔断，取值范围为1~2147483647。|
   |熔断错误百分比阈值|请求触发故障隔离百分比，时间窗10s内错误请求占比大于等于该阈值就会开启熔断，取值范围为1~100。|
