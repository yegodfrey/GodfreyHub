# 操作指导

#### 前提条件

* 您的游戏需要包体在架状态，或者进行过先锋/内测活动。
* 您已经准备游戏资源包并加密，游戏资源包的格式请参见[游戏资源包文件的后缀](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/resource-package-faq-0000001296526618#section194354831614)，您需自行保证游戏资源包的可用性。一个预下载任务中上传的游戏资源包总数量不超过10个，每个包体大小不超过2048MB，总大小不超过8000MB。
* 若使用三方CDN服务器下载资源包，请提前将游戏资源包全部上传至CDN服务器。
* 测试资源包预下载功能必须满足如下闲时自动更新条件：
  * 测试设备的发布时间必须为2019年之后。
  * 测试设备仅支持HarmonyOS 4.2及以下的华为手机/平板，且必须安装华为应用市场客户端，同时设备的可用空间必须大于3倍的游戏资源包大小。
  * 测试设备上的华为应用市场客户端必须开启"自动更新应用"开关，并选择"打开"或"仅WLAN下"：
    * 打开（WLAN和移动网络）：WLAN或移动网络下，CPU使用率低于80%，电量高于30%。
* 仅WLAN：WLAN网络下，CPU使用率低于80%，电量高于30%。  

#### 进入资源包预下载页面

登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"APP与元服务"，在应用列表中选择游戏，选择"分发 \> 服务 \> 资源包预下载申请"，在页面右侧点击"申请"。  
![](https://media:201780897205344326)  
若在"资源包预下载"页面中有状态为"审核中"、"预上线"、"已发布"、"任务暂停"的任务，您将无法点击"申请"，需要任务结束或终止后才能申请。

![](https://media:201780897205431329)

所有任务状态说明请参见[资源包预下载任务状态说明](#section15845401415)。  

#### 创建预下载任务

创建资源包预下载任务时，您的游戏需要包体在架状态，或进行过先锋/内测活动。  

#### 设置预下载时间

1. 您可以在任务创建页面中设置预下载的开始时间和结束时间。 ![](https://media:201780897205480330)

   设置时需注意以下几点：  

   |要求|举例|
   |:--------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |开始时间和结束时间的生效时间均为用户设备的本地时间。|-|
   |开始时间和结束时间只能选择到天。|例如选择2021年4月2日，则默认开始时间为2021年4月2日0点。结束时间选择2021年4月10日，则默认结束时间为2021年4月10日23点59分。|
   |开始时间和结束时间最长间隔为14天。|-|
   |开始时间需要预留华为运营审核、预下载功能测试的时间，预下载任务只有审核通过并正式发布后才会正式开始。|例如您设置2021年4月2日开始预下载任务，2021年4月10日结束，如果您正式发布预下载任务的时间为4月5日，则预下载任务只能从4月5日开始执行。|
   |游戏资源包在用户客户端最长保留时间为14天，开始时间需要根据游戏首发或游戏发布更新版本的时间合理安排。|例如您设置2021年4月2日开始预下载任务，2021年4月10日结束。您在2021年4月2日正式发布并开始执行预下载任务，此后符合条件的用户设备就会将资源包预下载到客户端本地，直到2021年4月10日任务结束。但是您在4月25日才在华为应用市场上架游戏的最新版本，而此时用户设备的游戏资源包已经过了14天的最大保留时间，华为应用市场会自动删除用户设备本地的游戏资源包，从而导致用户下载游戏后无法加载预下载的游戏资源包。|
   |开始时间设置后如果更改，则结束时间自动清除，需要重新选择。|-|
   |如果审核通过的时间已经晚于预下载结束时间，则审核通过后任务会直接变为"任务结束"状态。|-|

2. （可选）您可以配置下载时间段，设备将在您设置的开始时间至结束时间内的指定时间段向CDN服务器请求下载游戏资源包。您还可以在配置的下载时间段内指定流量上限，华为CDN会根据配置的流量上限去设置下发的资源包下载任务上限。  
   ![](https://media:201780897205506332)  
   * 可添加或删除时间段，多个时间段不能重叠，最多支持配置20个时间段。
   * 未配置下载时间段，不支持配置流量上限，流量上限的输入范围为100-200000/分钟。
* 若您未配置下载流控值，使用华为CDN场景可能也会根据华为CDN带宽负载对下载速度进行限制，具体限制数据可以在任务详情页进行查看。  

#### 上传游戏资源包

1. 您可以为预下载任务设置一个版本号，用于跟踪不同的游戏资源包预下载任务，版本号要求为不超过9位的整数，且必须大于已创建任务的版本号。 ![](https://media:201780897205545334)

2. 您可以点击"上传资源包"栏的"选择文件"，上传提前准备好的游戏资源包。  
   ![](https://media:201780897205698338)  
   若通过三方CDN服务器下载资源包，请确保华为服务器和三方CDN服务器的资源包保持一致，否则玩家可能因为Hash值校验不通过而加载失败。  

   |游戏资源包的文件状态|处理说明|
   |:-----------|:----------------------------------------------|
   |上传中...进度x%|等待资源包上传完成，如需停止上传，可以点击"取消上传"。|
   |上传失败|检查网络是否正常、资源包是否过大，如无异常，可点击"删除"将游戏资源包删除，并重新上传资源包。|
   |扫描中|等待游戏资源包扫描完成。|
   |扫描不通过，可能存在病毒|点击"删除"将游戏资源包删除，并检查包体中是否存在病毒，修复资源包后重新上传。|
   |扫描通过|表示游戏资源包上传成功。|

3. （可选）在资源包列表填写三方CDN地址。 ![](https://media:201780897205798342)

4. 提交游戏资源包预下载任务。  
   ![](https://media:201780897205827343)
   * 点击"保存草稿"可以将预下载任务保存为"草稿"状态，您可以暂时不提交任务，后续继续编辑任务后再提交，具体请参见[提交预下载任务](#section124381849103616)。
* 点击"提交申请"可以直接将游戏资源包预下载任务提交到"预上线"状态，请参见[资源包预下载任务状态说明](#section15845401415)。  

#### 提交预下载任务

您可以在创建游戏资源包预下载任务时点击"提交申请"直接提交。如果您保存了草稿状态的预下载任务，也可以在任务列表中重新编辑后再提交。

1. 在"资源包预下载申请"页面中找到您需要提交的"草稿"状态任务，点击"操作"列中的"编辑"。 ![](https://media:201780897205857344)

   ![](https://media:201780897205885345)  
   草稿状态的任务点击"编辑"后，之前的开始时间和结束时间会自动清除，需要重新设置。
2. 在任务填写页面中设置预下载任务执行的周期、上传游戏资源包，完成后点击"提交申请"。 ![](https://media:201780897205938346)

#### 测试预下载功能

预下载任务提交申请后，任务会变为"预上线"状态，此时您可以在测试设备上测试能否成功预下载游戏资源包。

1. 打开CMD窗口，进入shell脚本命令。

   ```
   adb shell
   ```

2. 获取测试设备的设备号。

   ```
   bm get -u
   ```

   ![](https://media:201780897206034347)
3. 在资源包预下载任务页面中，点击"测试设备"后的"编辑"。 ![](https://media:201780897206083348)

4. 在输入框中最多添加10台测试设备的设备号，且使用英文逗号（,）间隔开，完成后点击"提交"。 ![](https://media:201780897206127350)

   当满足如下条件后，游戏资源包将自动下载至测试设备中：
   * 提交过设备号的测试设备必须满足[闲时自动更新条件](#ZH-CN_TOPIC_0000001296686470__li44449303178)。
   * 对于新安装的游戏，为了更快地测试资源包预下载功能，建议在AGC控制台提交设备号后，在设备上清空应用市场缓存或将手机/平板的系统时间修改为24小时以后，否则应用市场可能会等上较长一段时间才会下载游戏资源包。
   * 为了更快触发游戏资源包的下载，测试设备可尝试多次插拔数据线。

   ![](https://media:201780897206320354)  
   * 若想判断游戏资源包正在下载或完成下载，请参考[判断方式](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/resource-package-faq-0000001296526618#section2016551416442)。若想在测试设备上重复下载游戏资源包，请清空应用市场客户端缓存或前往AGC控制台[重新提交预下载任务](#section124381849103616)。
   * 游戏资源包下载途径：
     * 已配置三方CDN的预下载任务将从三方CDN下载资源包。
     * 未配置三方CDN的预下载任务将从华为CDN下载资源包。
5. 资源包成功下载后，打开游戏并验证游戏是否可以正常读取资源包。  
   ![](https://media:201780897206359356)  
   若游戏资源包读取失败，请排查相关问题。若定位出游戏资源包本身的问题，您需要重新编辑预下载任务，或终止当前预下载任务并重新创建任务。
6. 成功测试资源包预下载功能后，即可前往AGC控制台[发布预下载任务](#section9206134163716)。  

#### 发布预下载任务

在"资源包预下载申请"页面找到"预上线"状态的任务，点击"操作"列中的"发布"，在弹出的窗口中点击"确定"。任务提交发布后状态会变为"审核中"，华为运营人员会在1\~3个工作日内完成审批，审批完成后任务状态会变为"已发布"。发布游戏资源包后，在您所设定的预下载任务有效时间内，游戏资源包将会向满足自动更新的用户设备进行推送。

![](https://media:201780897206389358)  
![](https://media:201780897206419360)  
如果您发现已发布的游戏资源包需要中止更新，可以主动在预下载任务列表中点击"终止"来停止任务，华为应用市场将不再对该游戏资源包进行自动下载。对于用户设备上已开始下载的游戏资源包不会立刻删除，而是在下一次启动自动更新时，删除创建时间大于7\*24小时的游戏资源包。  

#### 资源包预下载任务状态说明

![](https://media:201780897206450361)  

|序号|状态|说明|
|:-|:----|:-------------------------------------------------|
|1|草稿|填写信息后保存为草稿后的状态，草稿状态的任务支持"编辑"和"删除"。|
|2|预上线|提交申请后的状态，任务可以在这个状态下进行资源包预下载测试。预上线状态的任务支持"发布"和"终止"。|
|3|审核中|"预上线"状态的任务点击"发布"后的状态。审核中的任务不支持执行任何操作。|
|4|审核不通过|任务点击"发布"后提交到华为运营人员审核，审核不通过的状态。审核不通过的任务支持重新"编辑"。|
|5|已发布|任务审核通过后任务正式发布的状态，发布中的任务仅支持"终止"。|
|6|任务结束|本次预下载任务执行结束或者被华为运营人员终止了任务。|
|7|任务暂停|被华为运营人员暂停了任务。|
