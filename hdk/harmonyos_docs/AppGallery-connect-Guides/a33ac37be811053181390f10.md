# SQLite漏洞修复

Cloud DB iOS SDK依赖SQLCipher，而SQLCipher是基于SQLite开发的开源组件，由于iOS SDK并没有直接集成SQLCipher源码，所以我们无法提供已修复漏洞的SQLCipher版本。但是，我们会持续关注SQLite上的漏洞信息，当发现新的漏洞时，我们会及时分析和验证，确认漏洞可以修复时，会更新至漏洞补丁表中，您可以根据应用需要选择是否修复该漏洞。

您可以在SQLCipher根目录下的VERSION文件中找到SQLCipher对应SQLite的版本。下表中根据SQLite版本列出了待修复漏洞对应的补丁以供参考，请按照表格中先后顺序依次修复。
> 注意
>
> 对于使用CocoaPods管理SQLCipher的方式，需要您在SQLCipher源码修复漏洞后，再将重新生成的sqlite3.h和sqlite3.c文件，用以替换Pods目录下的sqlite3.h和sqlite3.c文件。替换后不可再使用Pods命令更新，避免已修复漏洞后生成的sqlite3.h和sqlite3.c文件被覆盖。
