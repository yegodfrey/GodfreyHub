# 上架开放式测试版本

> 说明
>
> API ≤ 9的HarmonyOS应用/元服务，上传软件包后才会展示开放式测试入口。API ≥ 10的HarmonyOS应用/元服务请使用[邀请测试](https://developer.huawei.com/consumer/cn/doc/app/agc-help-invite-test-0000002270829393)和[公开测试](https://developer.huawei.com/consumer/cn/doc/app/agc-help-public-test-0000002287814841)。

在应用打包完成后，您可以在AGC中上架开放式测试版本，并选择您要分发的测试用户列表。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107171426.33083011866924798066661820996536:50001231000000:2800:AABEAEAB26CF7154C2B0BA1008A8ECAF1899A251C8C17D60A8B2AA2DCADA9878.png)

## 前提条件

* 您已经[创建您的应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createapp-0000001146718717)，并[配置应用信息](https://developer.huawei.com/consumer/cn/doc/app/agc-help-harmonyos-releaseapp-non-next-0000002179322402#section242410559206)。
* 您已经[创建测试用户列表](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-userlist-introduction-0000001071318960)。

## Android/HarmonyOS应用（API ≤ 9）

### 上架测试应用

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，在发布应用版本时选择开放式测试模式。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107171426.18742026657862772194243154253505:50001231000000:2800:2B4257337D77E94EC2944830B4CAF2906DF189201F38AABBDDBD94FC7DF3E456.png "点击放大")
2. 配置开放式测试信息。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107171427.53818023940681718014699649877686:50001231000000:2800:E4CE0F7B6EF846F75F455C0B8708DF03AAA568846B9E8E3C49C3177BD1DC23F5.png "点击放大")

   |序号|参数|说明|
   |:-|:--------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |1|用于开发阶段内部测试，免人工审核环节|如果是开发阶段的内部测试，可以勾选此选项。此选项可以免去人工审核环节，加快应用上架速度，但此方式最多仅支持邀请100个测试用户。如不勾选，应用上架时需要人工审核，最多可以支持邀请5000个测试用户。 > 说明 > 勾选免人工审核，若系统检测未通过，仍会触发人工审核，最终需以人工审核结果为准。|
   |2|测试时间|开放式测试版本的开始时间和结束时间，只有当前时间到达开始时间时，测试用户才能搜索到开放式测试版本。测试时间到期后，测试用户将无法搜索到该应用。 开放式测试的测试时间当前最大有效期为90天。|
   |3|测试用户|测试用户为[创建测试用户列表](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-userlist-introduction-0000001071318960)中添加的有效华为账号。 选择需要分发的测试用户列表，您所勾选的测试用户会在该版本上架后收到邀请邮件或短信，最多支持勾选30个用户列表。如果勾选了"用于开发阶段内部测试，免人工审核环节"，最多只支持100个测试用户。如果未勾选，最多支持5000个测试用户。 说明 > 如果需要在某个用户列表下追加新的用户，可以点击"编辑"。如果需要创建新的用户列表，可以点击"创建新列表"。|
   |4|审批通过后自动发送邀请邮件/短信给测试用户|如果勾选此选项，且满足以下条件时系统会自动发送邀请邮件/短信： * 应用已经审核完成。 * 开放式测试的开始时间已经生效。 如果未勾选，您需要在分发详情页面手动触发邮件/短信发送。 > 说明 > 当**未勾选**"用于开发阶段内部测试，免人工审核环节"选框时，才展示该项。|
   |5|分发客户端|测试版本分发的渠道，"AppGallery"表示应用会上架到华为应用市场。|
   |6|反馈邮箱|填写反馈邮箱，该地址将随邮件或短信发送给您的测试用户，测试用户可以通过该地址反馈使用开放式测试版本的意见和建议。|
   |7|邀请链接有效期|设置发送给用户的邀请链接的有效期。系统默认显示的天数为您设置的测试时间往小取整的值。例如，您设置的测试时间为28.5天，则系统默认显示的邀请链接有效期为28天。您可以修改有效期，但必须小于或等于90天，从用户收到邀请开始计算。在有效期内且开放式测试未结束时，该邀请链接有效。|

3. 填写其他版本发布信息并上传测试版本的软件包，完成后点击"提交审核"，具体请参见[发布应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-release-overview-0000001272395372)。
   * 如果您发现提交审核的开放式测试版本有问题，想要暂停上架计划或是想要修改相关的应用信息，您可以在开放式测试版本信息页面[撤销审核](https://developer.huawei.com/consumer/cn/doc/app/agc-help-cancel-review-0000001110334194#section18227759939)。撤销审核后，应用的开放式测试版本状态为"已撤销上架"。如果您想要再次上架应用，您可以重新提交应用上架审核申请。
   * 如果您选择了免人工审核，等待几小时后即可获知版本发布结果。如果您选择了人工审核，华为应用市场运营人员将在1-3个工作日内完成审核。如果您的应用被驳回，我们将会发送邮件至联系人邮箱进行通知，请注意查收。


   * 如果您的开放式测试版本已经通过审核，但未到指定上架时间，此时该开放式测试版本处于"待上架"状态。若不想再上架该应用版本，您可以在开放式测试版本信息页面[撤销上架](https://developer.huawei.com/consumer/cn/doc/app/agc-help-removeapp-0000001100316676#section41473441602)，撤销上架操作不需要人工审核。

### 上架后修改测试时间

您的开放式测试版本上架后，您还可以继续修改开放式测试版本的测试时间。例如：提前启动开放式测试，延长开放式测试时间。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107171427.55697370871361550314317956861867:50001231000000:2800:399851E643679ADFB125D9AC4FA959A3E6DECE71D75BB0A269F7B3C855CFBDB2.png)

### 上架后查看邀请状态

开放式测试版本上架后，您可以在AGC中查看当前所有用户的邀请状态，还可以给测试用户重新发送邀请链接。
> 说明
>
> * 一天内对同一个测试用户最多发送5次邀请。
> * 一个开放式测试免审版本最多可发送邀请100次，非免审版本最多可发送邀请200次。
> * 开发者24小时内对所有测试用户发送邀请的总次数不可超过500次。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107171427.33630484671774435492755742228688:50001231000000:2800:8E520AEBF9566ABC298A343ED6BE3FE954CBB147244140AC5ABF88468E60A4BA.png "点击放大")

具体状态说明如下表所示。

|状态|状态说明|操作说明|
|:--|:------------------------------|:--------------------------------------|
|未发送|用户未收到邀请邮件或短信。|您可以点击"发送邀请"发送邮件或短信给未发送过邀请的测试用户。|
|已邀请|用户已收到邀请邮件或短信，但用户未点击邀请链接参与开放式测试。|您可以点击"重新发送邀请"发送邮件或短信给已邀请的测试用户，提醒用户参与测试。|
|已接受|用户已点击邀请链接并成功接受邀请。|等待用户安装。|
|已安装|用户已安装测试版本。|等待用户反馈使用意见。|
|已退订|用户已在邀请邮件中点击退订邮件。|不再向用户发送邀请邮件。|

### 上架后添加测试用户

开放式测试版本上架后，在未达到开放式测试结束时间前，您可以继续添加新的测试用户到已有的用户列表中，并向新用户发送邀请链接。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107171427.80888636346385521862591081541208:50001231000000:2800:33638EF9E4F805DF3B1FBD94A8B33AEC6B4A16468B41025D439D14A253219647.png)

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107171427.00963618024820028987547132682944:50001231000000:2800:11FC8D79E46ED06C48D971353EC6E884CB3536369F228348413001F7366F2145.png "点击放大")
