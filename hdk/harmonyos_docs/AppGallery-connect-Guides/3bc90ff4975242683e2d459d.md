# 创建项目与应用

项目是您在AGC资源的组织实体，您可以将一个应用的不同平台版本添加到同一个项目中。当您的应用需要使用AGC服务时，您可以[创建您的项目](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createproject-0000001100334664)和[创建您的应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createapp-0000001146718717)。
