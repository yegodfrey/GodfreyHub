# 元数据管理

文件元数据包含云端文件名、文件大小、文件类型等常用属性，也包括用户自定义的文件属性。

文件上传到云端后，您可以设置文件的自定义属性。

文件保存到云端后，您可以在下载文件实体前获取文件的元数据，来决定是否要下载文件。

## 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[初始化存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-initialize-bucket-harmonyos-ts-0000001678555281)。
* 您已通过认证服务登录应用。
* 您已[上传文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-upload-harmonyos-ts-0000001629995600)。

## 设置元数据

1. 调用[Storage.setMetaData](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-storage-storage-0000001679582393#section3731181116282)方法设置文件的元数据。

   ```screen
   let newMetadata = await storage.setMetaData({
       cloudPath: "image/demo.jpg",
       metaData: {
           contentType: "image/jpeg",
           cacheControl: "no-store",
           contentDisposition: "attachment;filename=demo.jpg",
           contentEncoding: "identity",
           contentLanguage: "en-US",
           customMetadata: {
               "key1": "val1",
               "key2": "val2",
           }
       }
   });
   ```

## 获取元数据

调用[Storage.getMetaData](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-storage-storage-0000001679582393#section13759113011327)方法获取文件的元数据。

```screen
let metaData: MetadataComplete = await storage.getMetaData("image/demo.jpg")
```
