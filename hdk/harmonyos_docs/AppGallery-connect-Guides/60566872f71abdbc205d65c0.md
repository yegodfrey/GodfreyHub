# 登出

#### 前提条件

* 您需要在AGC控制台[开通认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyos-arkts-integration-0000001679766293)。  

#### 开发步骤

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251226181007.18808323090454476485623582814397:50001231000000:2800:74032F5598C068FF1F4FCB5F38636724AAFB4D73AD92CD043D90E6BE9F616FD2.png "点击放大")

当用户不再使用应用，或者需要使用其他账号登录时，需要调用[Auth.signOut](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-arkts-auth-0000001680370685#section4122193119119)登出当前用户。用户一旦被登出，端侧的用户信息和Token将被清除。

```
cloud.auth().signOut().then(() => {
    // 登出成功
}).catch(error => {
    // 登出失败
});
```
