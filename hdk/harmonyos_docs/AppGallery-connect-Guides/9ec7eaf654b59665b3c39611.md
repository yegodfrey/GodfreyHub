# 开通服务

首次使用云缓存服务前，需要先开通此服务。如果您已经开通，可跳过本步骤。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中点击需要开通云缓存的项目。

3. 在左侧导航栏选择"云开发（Serverless） \> 云缓存"，进入云缓存页面，点击"免费开通"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704163201.82751639483539622285885421529187:50001231000000:2800:BCC31981C3905A227C33BF308B8CF1B8594927B54BB85CD5DD0C9186C985D93A.png)

4. 如您尚未设置默认数据处理位置，在弹出的"数据处理位置"窗口进行设置，具体请参见[设置数据处理位置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-data-storage-location-0000001162597847#section154810363471)。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704163201.58164186743472742275777950010581:50001231000000:2800:F4F56D6B4F09B0433D48AEBEBB2073B8FE06CBB83FEF78DC1CF5C7B2C4E88B00.png)  
   云缓存目前仅在中国站点提供服务，请务必启用中国数据处理位置。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704163201.98214572997313793015089455678110:50001231000000:2800:A617831F2A77D452D8DD2F9905710266B7B2B807B2019094BCEECC97E535A941.png)
5. 在弹出的"开通云缓存"窗口设置缓存的访问密码，完成后点击"确认"。 您可以使用缓存访问密码和[内网访问地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudcache-configure-0000001367208633#section10148145418336)，在Redis客户端执行如下命令，自行连接缓存实例。

   ```
   ./redis-cli -h <内网访问地址> -p <端口号> -a <缓存访问密码>
   ```

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704163201.30241291841001675446853976706265:50001231000000:2800:9A47B3FE4E59A294FEF0DD3117D30DC382B839CA14D6B257501E860A8876F402.png)  
   * 云缓存对访问密码有严格的限制：
     * 密码不能为空。
     * 密码必须以字母开头。
     * 密码长度在8到32位之间。
     * 必须包含如下四种字符：
       * 小写字母
       * 大写字母
       * 数字（0-9）
       * 特殊字符（-\~!@#%\^\*_=+?$\&()\|\<\>{}\[\]）
   * 请务必妥善保存访问密码，系统不支持查询密码，如您忘记密码，请[重置访问密码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudcache-configure-0000001367208633#section18626153133319)。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704163201.53717011724721388364894396482394:50001231000000:2800:8C854F98808204DE06C28C8D6A7810424F3608F7805CCB629577CB260ADFCC21.png)
