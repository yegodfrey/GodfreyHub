# 接口调用流程

基于游戏内嵌社区SDK提供的能力，您可以实现初始化、未成年人控制、打开/关闭社区、开发场景化入口和一键发布的能力，整体的接入流程如下所示：

1. 在满足游戏成功登录的前提下，您必须先执行初始化内嵌社区，这是接入其它内嵌社区接口必要的前提步骤。
2. 初始化成功后，您可以根据需要决定是否控制未成年人访问内嵌社区：
   * 若控制未成年人的访问，您可以自行处理未成年人与未实名认证玩家的访问体验。
   * 若不控制未成年人的访问，您可以在接入打开社区能力后，继续实现场景化入口、一键发布、关闭内嵌社区功能。
