# 通过控制台测试

> 说明
>
> 下文以函数latest版本为例介绍测试方法。若您需要测试函数的已发布版本，可在已发布版本详情页面选择"函数代码"页签，参考方式二进行测试。

函数创建后您可以在AGC控制台测试函数的代码运行是否正常。进入测试界面有两种方式：

* 方式一：函数列表中点击函数名称右侧"操作"列的"测试"，在右侧弹出的"测试函数"界面进行测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/24/v3/8QOwAZBdQcSuWHCV_OeO1g/zh-cn_image_0000001978548797.png?HW-CC-KV=V1&HW-CC-Date=20261008T163709Z&HW-CC-Expire=31536000000&HW-CC-Sign=DEA8F6ADF0EA507D7B026D41462C752656A0916AA1202BC3390D13C4889054CA)

* 方式二：
  1. 在函数列表中点击已创建的函数名称，进入函数详情页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8c/v3/qeJmWGxHSzGOGEHC5sor5A/zh-cn_image_0000001948908550.png?HW-CC-KV=V1&HW-CC-Date=20261008T163709Z&HW-CC-Expire=31536000000&HW-CC-Sign=5C6913AF1F6CB66DE732D784BD3CC0E6DE4BD77E75A0D2E0673B18166DC4E926)

  2. 选择"函数代码"页签，点击"测试函数"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a8/v3/HXgcb8vIROaaLE3xzudyOw/zh-cn_image_0000001800662133.png?HW-CC-KV=V1&HW-CC-Date=20261008T163709Z&HW-CC-Expire=31536000000&HW-CC-Sign=6429D4C4F7CB9B402EBE9ED232CFF7B8B3095690FB2751C731628125FA424DC5)

  3. 在右侧弹出的"测试函数"界面，使用默认测试事件、创建新测试事件或者使用已保存测试事件进行测试。
     * 使用默认测试事件 直接点击"测试"对函数进行测试。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/70/v3/BOI9N_unRGG4KoYhv-k5nA/zh-cn_image_0000001722152221.png?HW-CC-KV=V1&HW-CC-Date=20261008T163709Z&HW-CC-Expire=31536000000&HW-CC-Sign=561B0D342784CD978340242FE69DF87A2CD923766745DC7BAF2047C343E36F68)
     * 创建新测试事件 如果需要设置调用函数的请求消息体，可按照如下步骤配置测试参数，并可保存为测试事件方便后续继续使用。

       1. 在"事件"文本框中输入JSON格式的事件参数，点击"保存"。然后在"提示"弹出框中输入事件名称，配置完成后点击弹出框右下角的"确认"。 说明
          >
          > "事件"文本框内输入的JSON对象，对应的是触发器的event事件格式，会透传给函数。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4a/v3/LDMKneLUQ2iNdBeoRVvi8g/zh-cn_image_0000001756189981.png?HW-CC-KV=V1&HW-CC-Date=20261008T163709Z&HW-CC-Expire=31536000000&HW-CC-Sign=38E3641640C42384A16BECAD64C2845B792B1DA7F7FE433C1DE1F6E657FD6953)
       2. 点击"测试"，函数处理事件并返回测试结果。
     * 使用已保存测试事件
       1. 在"测试函数"界面，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b4/v3/jpN7m9_eRMKsydMkaC-S2Q/zh-cn_image_0000001722236597.png?HW-CC-KV=V1&HW-CC-Date=20261008T163709Z&HW-CC-Expire=31536000000&HW-CC-Sign=90192DC059DA5D26BFCDAEBAF2B50C03C0982F8220130AA74970E54323E398A6)展开已保存的测试事件列表，选择已配置的事件名称右侧的"加载"，然后点击"测试"，函数处理事件并返回测试结果。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c1/v3/JHhZ3oLFSpW6bBZi_JC9RA/zh-cn_image_0000001722453985.png?HW-CC-KV=V1&HW-CC-Date=20261008T163709Z&HW-CC-Expire=31536000000&HW-CC-Sign=2D77D34C0A2629D055A61AD072D23C6BCC875293DA3C21107C23B9B7DAD750E7)
       2. （可选）若您需要删除已添加的测试事件，可在测试事件列表中点击事件名称右侧的"删除"即可删除测试事件。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d2/v3/WnTgZfXjSjS1D8UbaZheIg/zh-cn_image_0000001722158501.png?HW-CC-KV=V1&HW-CC-Date=20261008T163709Z&HW-CC-Expire=31536000000&HW-CC-Sign=25705085C07AB7F4981F038D2201D1D7DB7950CD5C37155412A3ABA398A89314)

  4. 查看测试结果。
     * 执行结果：展示测试后获得的响应结果。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/39/v3/cP81R2dyTYaNg7Y_bkjxhg/zh-cn_image_0000001674184734.png?HW-CC-KV=V1&HW-CC-Date=20261008T163709Z&HW-CC-Expire=31536000000&HW-CC-Sign=87F3C561CA69100C5A13DE0C7332A115FA2D03EDA326F00BE57D02BAEB1FD1EA)

     * 运行日志：展示函数运行过程中，通过logger API打印的日志，支持输出debug级别及以上日志（以下仅为日志输出示例）。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f8/v3/NwqCPybjTjOYBkG9nMSFRQ/zh-cn_image_0000001674190046.png?HW-CC-KV=V1&HW-CC-Date=20261008T163709Z&HW-CC-Expire=31536000000&HW-CC-Sign=3FEE5CDBBB3816DD6226774D7C1735C99C0591BDC7452B44058E46E98D9EEF3F)

     * 执行摘要：展示该次测试请求相关信息。
       * 请求ID：该条测试请求的RequestID，在后台日志中体现为X-Trace-ID。
       * 持续时间：函数执行的端到端时间。
       * 执行版本：该次调用测试的具体函数版本。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ea/v3/t3KyFb9PTZaMs9jmkptWpw/zh-cn_image_0000001674344770.png?HW-CC-KV=V1&HW-CC-Date=20261008T163709Z&HW-CC-Expire=31536000000&HW-CC-Sign=411EB71B674061864ED1913AEEDE4DA2CEC1066D6D465096B2754736BE86B1D4)
  5. "代码输入类型"为"在线编辑"的函数，测试过程中，若您需要修改函数入口文件代码，可直接在"函数代码"页签的代码编辑器中修改，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2c/v3/jUAgcFeASC2KivrNqalTOA/zh-cn_image_0000001753703418.png?HW-CC-KV=V1&HW-CC-Date=20261008T163709Z&HW-CC-Expire=31536000000&HW-CC-Sign=6EF915974066997554E2A815E2AE87DE2A08678727EF26FD038D24BEC334E239)

     "代码输入类型"为".zip文件"的函数，测试过程中，若您需要修改函数代码文件，可在本地修改且打包完成后，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/55/v3/QZqo6h7cTx-hwSxFZwJqNQ/zh-cn_image_0000001717161230.png?HW-CC-KV=V1&HW-CC-Date=20261008T163709Z&HW-CC-Expire=31536000000&HW-CC-Sign=236501E9C47A1CF54E96A29283F159A429F5316F38351F2911F301497E8CB05F)重新上传函数部署包，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。
     > 说明
     >
     > 若代码更新量比较大，需要调整函数内存配置，可点击"内存配置"下拉框进行调整，然后再上传函数部署包。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5b/v3/Gmp4BI4_RS2ykx3RvKAicQ/zh-cn_image_0000002433940774.png?HW-CC-KV=V1&HW-CC-Date=20261008T163709Z&HW-CC-Expire=31536000000&HW-CC-Sign=69BD7026963285DD316B4D880E777B239231E73B11A9BEDA0D7C569DB8AE5E5C)
  6. 函数测试无误后，您可在"函数代码"页签点击"导出函数"导出函数部署包。导出包以"函数名称+函数版本.zip"格式命名，可查看函数结构和文件内容。
