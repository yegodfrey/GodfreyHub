# 华为游戏账号

您可以在应用中集成华为游戏账号认证方式，让您的用户可以使用自己的华为游戏账号进行AppGallery Connect身份验证。

## 前提条件

您需要已完成[开通认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)以及[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-quickgame-integration-sdk-0000001276012300)各项准备工作。

## 开发步骤

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251223144025.52102768997575508977181892799980:50001231000000:2800:298EE98EC4C35D499DC27AD596B0CB80F6654DF5396EB4D861865550AC43F0A7.png "点击放大")

1. 在应用的登录界面，初始化[AGCAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254)实例，获取 AGC的用户信息，检查是否有已经登录的用户。如果有则可以直接进入用户界面，否则显示登录界面。

   ```screen
   agconnect.auth().getCurrentUser().then(user=>{
       if(user){
           // 业务逻辑
       }
   });
   ```

2. 华为游戏账号登录，并获取华为游戏账号的用户授权信息。 说明
   >
   > 此步骤仅供参考，更详细内容，请参见[快游戏官方文档](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-runtime-account-kit-0000001113458340)。

   在快游戏中调用 [qg.gameLoginWithReal](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickgame-api-account-0000001083874630#section73325514166)接口实现游戏登录，然后调用[credentialWithPlayerSign](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/hwgameauthprovider-web-0000001137693257#section1994762615505)获取从华为游戏账号获取的credential，并调用[AGCAuth.signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section18413636501)实现登录。

   ```screen
      
   qg.gameLoginWithReal({// 调用快游戏登录接口
     forceLogin:1,// 玩家未登录华为账号或鉴权失败时，是否拉起登录页面。0--不拉取,1--拉取
     appid:"",// 在华为开发者联盟上创建快游戏后分配的唯一标识。
     success:function(data){
       let HwGameAuthReq = {
         playerSign: data.gameAuthSign,
         playerId: data.playerId,
         displayName:data.displayName,
         imageUrl: data.imageUri,
         playerLevel: data.playerLevel,
         signTs: data.ts
       };  
   agc.auth().signIn(agc.auth.HwGameAuthProvider.credentialWithPlayerSign(HwGameAuthReq)).then(res=>{
   console.log("signIn ok");
   }).
   catch(e=>{
   console.log("signIn fail");
   });
     },
   fail:function(data,code){console.log("gameLogin fail:" + JSON.stringify(data) + ", code:" + code);}
   });
   ```

## 更多信息

* 您如果想让用户可以使用多个账号登录您的应用，可以将多个[账号进行关联](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-quickgame-associated-0000001086830700)。
* 当用户不需要使用应用，或者需要切换其他账号登录认证，可以先执行[登出](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-quickgame-sign-out-0000001086670748)。
* 当用户需要注销当前用户，可以进行[销户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-quickgame-deleteuser-0000001133407313)。
* 对于销户、修改密码、关联账号以及重置手机账号和邮箱账号等敏感操作，为了提高安全性，需要用户必须在5分钟内登录过才能执行。如果用户执行敏感操作时登录超过5分钟，需要[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-quickgame-reauthenticate-0000001113058558)后再执行敏感操作。
* 您可以参考[异常处理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-quickgame-troubleshooting-0000001158809814)实现自己的异常处理机制，从而减少异常情况的发生。
* 您可以使用云函数触发器来接收用户注册、登录、销户等关键事件，从而[扩展认证服务的能力](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-extension-0000001053372708)。
* 您可以参考[管理用户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-user-manage-0000001606051705)对用户进行解锁、停用等操作。
