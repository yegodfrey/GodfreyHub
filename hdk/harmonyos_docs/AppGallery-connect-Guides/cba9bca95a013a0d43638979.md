# 账号重认证

## 前提条件

* 您需要在AGC控制台[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-web-integration-sdk-0000001276332208)。

## 开发步骤

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114607.75672045392539100567697334965039:50001231000000:2800:A5FB07127CC829BA883BF35A25391B0AC063AC109F1F1991ED74DCB2AD6069C1.png "点击放大")

对于销户、修改密码、关联账号以及重置手机账号和邮箱账号这些敏感操作，要求用户必须在5分钟内登录过才能执行。如果您执行敏感操作时已经登录超过5分钟，该操作会抛出AGCAuthException异常并收到错误码为203818081的错误，这种情况下您可以先调用[AGConnectUser.userReauthenticate](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectuser-web-0000001054663240#section103541353171916)重认证账号后再执行敏感操作。

```screen
  // 手机重认证(verifyCode可以为空)
  let credential = '';
  if(verifyCode){
    credential = agconnect.auth.PhoneAuthProvider.credentialWithVerifyCode(countryCode, account, password, verifyCode);
  }else{
    credential = agconnect.auth.PhoneAuthProvider.credentialWithPassword(countryCode, account, password);
  }
  agconnect.auth().getCurrentUser().then(async user => {
    if(user){
      await agconnect.auth().userReauthenticate(credential);
    }
  });
```
