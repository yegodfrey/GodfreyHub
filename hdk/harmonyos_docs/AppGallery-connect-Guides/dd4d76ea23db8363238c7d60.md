# 开发指导

游戏资源包预下载任务正式发布后，且当前时间已到达您设置的预下载开始时间，华为应用市场客户端会提前将游戏资源包分发到满足条件的用户设备，游戏客户端在启动游戏时即可从预下载存储目录中获取游戏资源包并更新游戏资源包。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d6/v3/p7o2ZJp2TFSo4vkMgAp0Iw/zh-cn_image_0000001317113128.png?HW-CC-KV=V1&HW-CC-Date=20260929T054030Z&HW-CC-Expire=31536000000&HW-CC-Sign=521CED1B0781F0A032C418F84C7DD50C6E50B3951E217A1E494B1B609FDB6C69)

1. 当用户设备满足游戏资源包自动更新要求时，华为应用市场客户端就会启动游戏资源包的自动更新下载。 说明
   >
   > 游戏资源包自动更新的要求如下：
   > * 仅支持华为手机，且用户设备必须安装华为应用市场客户端。
   > * 用户需要主动开启"自动更新应用"开关（华为应用市场 > 我的 > 设置 > 自动更新应用 > 打开/仅WLAN下）。
   > * 游戏发布地区必须包含中国大陆地区，且仅对注册地为中国大陆地区的用户生效。
   > * 游戏用户需满足如下要求：
   >   * 对于新游戏，只有预约了该游戏的用户才支持更新。
   >   * 对于在架游戏，只有已经安装该游戏的用户才支持更新。
   > * 必须满足华为应用市场客户端的闲时更新条件：
   >   * 仅WLAN：WLAN网络下，CPU使用率低于80%，电量高于30%。
   >   * 打开（WLAN和移动网络）：WLAN或移动网络下，CPU使用率低于80%，电量高于30%。
   > * 用户设备可用空间必须大于等于3倍下载游戏资源包的大小。
2. 华为应用市场客户端启动"自动更新应用"后，将从华为资源更新服务器下载游戏资源包。
3. 下载完成后，华为应用市场客户端会将游戏资源包保存到预下载资源存储目录下，不同版本的客户端存储目录会有差异。
4. 玩家启动游戏客户端。
5. 游戏客户端需要调用[通知获取资源包状态](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/resource-package-api-notice-status-0000002061935810)通知华为应用市场开始读取游戏资源包，参数传入"BEGIN"。 注意
   >
   > 建议您在读取游戏资源包前、后通知华为应用市场客户端，否则可能会影响您的游戏统计数据。
6. 不同版本应用市场客户端通过不同的方式读取游戏资源包，请根据实际情况选择。
   * 12.1.1.302之前版本：直接读取资源包存储目录 " **/sdcard/Download/gameresource/** *游戏包名* **/**"。
   * 12.1.1.302及以上版本：通过如下示例代码方式启动游戏资源包读取。

     ```screen
         public void getFilesWithAGVersion() {
             PackageInfo packageInfo;
             try {
                 // com.huawei.appmarket是华为应用市场的包名
                 packageInfo = this.getApplicationContext().getPackageManager().getPackageInfo("com.huawei.appmarket", 0);
                 long versionCode = packageInfo.getLongVersionCode();
                 Log.i(TAG, "AGversionCode is:" + versionCode);
                 if (versionCode < 120101302) {
                     // 如果华为应用市场客户端版本低于12.1.1.302
                     // 直接读取存储目录/sdcard/Download/gameresource/游戏包名/
                 } else {
                     // 如果华为应用市场客户端版本大于等于12.1.1.302
                     // 通过华为https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/resource-package-api-get-list-0000002062094118接口获取存储目录
                     tryReadContentProvider();
                 }
             } catch (PackageManager.NameNotFoundException e) {
                 Log.i(TAG, "catch a NameNotFoundException");
             } catch (Exception e) {
                 Log.i(TAG, "catch a Exception");
             }
         }

         public void tryReadContentProvider() {
             InputStream inputStream = null;
             try {
                 Uri uri = Uri.parse("content://com.huawei.appgallery.game.CONTENT_URI");
                 ContentProviderClient contentProviderClient =
                         this.getApplicationContext().getContentResolver().acquireUnstableContentProviderClient(uri);
                 Bundle bundle = contentProviderClient.call("queryDetail", "", null);
                 int rtnCode = bundle == null ? 1 : bundle.getInt("returnCode");
                 if (rtnCode == 0) {
                     // 文件下载成功，开始读取资源包文件
                     String[] uris = bundle.getStringArray("fileUris");
                     long[] lengths = bundle.getLongArray("fileLengths");
                     String[] names = bundle.getStringArray("fileNames");
                     // 检验资源文件长度和名字... 
                     if (uris != null) {
                         for(int i = 0; i < uris.length; i++) {
                             inputStream = this.getApplicationContext().getContentResolver().openInputStream(Uri.parse(uris[i]));
                             // 从流中读取资源包文件... 
                             // 为防止多个资源包文件占用过多设备空间，您可以选择在读取单个文件后直接删除已读取的文件。
     	                deleteSingleResourceFile(names[i]); 
                             // 若在此处不删除文件，游戏资源包会在步骤11中调用"通知资源包更新状态"接口时批量删除。
                         }
                     }
                 }
             } catch (Exception e) {
                 Log.e(TAG, "tryReadFile fail: " + e.getMessage());
             } finally {
                 if (inputStream != null) {
                     try {
                         inputStream.close();
                     } catch (IOException e) {
                         Log.e(TAG, "close inputStream fail: " + e.getMessage());
                     }
                 }
             }
         }
     ```

7. （可选）单个包体文件成功读取后，游戏客户端可以调用[删除单个游戏资源包](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/resource-package-api-delete-0000002098054329)删除资源包文件，直至预下载存储目录中的所有包体文件被逐一读取并删除。

   ```screen
       public void deleteSingleResourceFile(String fileName) {
           try {
               Uri uri = Uri.parse("content://com.huawei.appgallery.game.CONTENT_URI");
               ContentProviderClient contentProviderClient =
                       this.getApplicationContext().getContentResolver().acquireUnstableContentProviderClient(uri);
               Bundle bundle = contentProviderClient.call("deleteSingleResFile", fileName, null);
               int rtnCode = bundle == null ? 1 : bundle.getInt("returnCode");
               if (rtnCode == 0) {
                   // 成功
               } else {
                   // 失败
               }
           } catch (Exception e) {
               Log.e(TAG, e.getMessage());
           }
       }
   ```

8. 游戏资源包获取完成后，游戏客户端需要调用[通知获取资源包状态](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/resource-package-api-notice-status-0000002061935810)通知华为应用市场游戏资源包读取已完成，参数传入"END"。
9. 在使用游戏资源包前，需要游戏客户端验证游戏资源包是否完整、是否可用。 注意
   >
   > 您需要自行对游戏资源包进行加密以保证包体的安全性。
10. 验证通过后游戏客户端进行游戏资源包的更新。
11. 游戏客户端完成更新资源包后，调用[通知资源包更新状态](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/resource-package-api-update-0000002098172813)告知华为应用市场客户端更新的结果。若您未使用步骤7中删除单个游戏资源包文件的方案：
    * 若华为应用市场客户端收到成功的通知后，将会删除用户设备的游戏资源包，释放用户空间。
    * 若华为应用市场客户端未收到通知，则会在下一次启动自动更新时，删除创建时间大于7*24小时的游戏资源包，并且不再重复下载该包体。后续游戏启动时需自行下载游戏资源包。
