# 关于云函数支持的运行环境、触发器的调整公告

尊敬的开发者，您好！

2025年11月4日起，云函数支持的运行环境以及触发器进行了以下调整：

* 运行环境调整：您开发者账号下新创建的云函数，不再支持Java、Python、Custom Runtime运行环境，您仍然可以选择使用Node.js运行环境。
* 触发器调整：您开发者账号下的云函数，不再支持创建API网关触发器。

影响范围：此次调整主要是开发者账号下不再支持创建Java、Python、Custom Runtime 运行环境的云函数以及创建API网关触发器。正在使用Java、Python、Custom Runtime运行环境和API网关触发器的存量函数，目前暂时不受影响，仍可正常使用。

感谢您的支持！  

#### 调整详情

* 不再支持选择"http请求"触发方式。 ![](https://media:101783044381499810)

* 不再支持创建API网关触发器。 ![](https://media:101783044381576811)

* 不再支持选择Java、Python、Custom Runtime运行环境，请使用Node.js运行环境开发新业务。 ![](https://media:101783044381622812)
