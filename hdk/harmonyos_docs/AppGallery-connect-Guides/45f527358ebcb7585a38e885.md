# 准备游戏信息

1. 在项目列表中选择您的项目，进入"项目设置" 的"常规"页签。
2. 记录项目下的"Client ID"和"Client Secret"，以及应用下的"APP ID"信息。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250813135411.89632663268811527775361853343043:50001231000000:2800:EA197E642BC0222756EC2E82C26BE3675CA09B7C64F6E2907C873675FB707C9E.png)  
   "Client ID"、"Client Secret"和"APP ID"信息主要用于SDK接入校验。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250813135411.80013797212936292618664295894990:50001231000000:2800:13523F34B280724E5D4EB8CF98F2CD519956D8B41C146CF02FE992B66B071CAE.png)  

   |参数|说明|
   |:------------|:----------------------|
   |Client ID|客户端ID，集成项目级SDK鉴权时的唯一标识。|
   |Client Secret|客户端密钥，集成项目级SDK鉴权时的密钥。|
   |APP ID|应用ID。|
