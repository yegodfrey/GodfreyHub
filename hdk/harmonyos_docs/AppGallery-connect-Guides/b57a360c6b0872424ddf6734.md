# 概述

"游戏排行榜"是基于Serverless搭建的模板服务，在游戏中部署可以更方便地制定多种类型的游戏内榜单，激发玩家的竞争兴趣，提升玩家的参与感，促进游戏的活跃度，同时还可以与其它基于Serverless的生态服务一起搭建场景化解决方案。  

#### 产品优势

|配置简单|"游戏排行榜"是基于Serverless搭建的生态服务，您只需简单配置，即可进行云函数、云数据库等Serverless资源的快速创建、部署和修改，彻底摆脱底层资源的管理和维护。|
|调用便捷|"游戏排行榜"服务集成了编码、调试、测试、部署等完整的生命周期，您只需对接该模板提供的接口，即可让玩家体验排行榜服务。|
|运维高效|"游戏排行榜"服务支持您快速部署，支持您按需付费，并能够根据业务请求自动计算资源，让您可以从容面对请求峰值，完全免去传统的运维烦恼。|
|----|----------------------------------------------------------------------------------------|

#### 使用场景

"游戏排行榜"支持快速搭建多种类型的游戏内排行榜，例如日榜、周榜、月榜和总榜。

您仅需在AGC控制台进行简单地可视化部署，并在游戏中集成云函数SDK，认证服务SDK，即可为您的游戏快速构建排行榜能力。
