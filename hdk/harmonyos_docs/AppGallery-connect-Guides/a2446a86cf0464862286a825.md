# 创建项目和应用

项目是您在AppGallery Connect（以下简称AGC）资源的组织实体，您可以将一个应用的不同平台版本添加到同一个项目中。当您的应用需要使用游戏高光时刻服务时，您可以[创建项目](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createproject-0000001100334664)，并在项目下[添加应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createapp-0000001146718717)。同时，您还需前往"项目设置 > 数据处理位置"，启用并指定您的游戏访问[数据处理位置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-data-storage-location-0000001162597847#section154810363471)默认为中国。
> 说明
>
> 游戏高光时刻服务当前仅支持Android游戏。
