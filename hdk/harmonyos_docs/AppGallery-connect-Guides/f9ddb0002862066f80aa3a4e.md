# 使用入门

## 创建项目和添加应用

如果您尚未添加项目，请在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)先创建您的AGC项目，在项目下添加应用并设置默认数据处理位置，具体请参见[Android使用入门](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-started-android-0000001058210705#section113292017144)。

## 启用服务

首次使用性能管理服务前，需要先启用此服务。如果您已经启用，可跳过本步骤。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择需要开通性能管理服务的应用。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155802.97009752468856910453936976960398:50001231000000:2800:97F022A801FC46742DC60D5C00D1462B3CC52AE785D0458B1B12DC33694B78CD.png)


3. 进入"质量 > 性能管理"，如果APM服务未开通，请点击"立即开通"，开通APM服务。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155802.04470449119756815579748741670301:50001231000000:2800:B65C40B6A227003F5F6DF3D6FB82FAE20ED8C6CC296FDF3C4E4779E85DEC07B9.png)

   > 说明
   >
   > 如果您此时未设置数据处理位置，系统会自动弹出提示框提示您进行设置，具体请参考[设置数据处理位置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-data-storage-location-0000001162597847#section154810363471)。目前，性能管理暂不支持访问多数据处理位置，仅能访问默认数据处理位置。设置后会刷新agconnect-services.json文件里的配置。因此，您需要重新下载agconnect-services.json文件并集成到您的工程中，具体操作参见[添加配置文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-started-android-0000001058210705#section641530103413)。

## 集成APM SDK

1. 集成APM SDK前需集成AGC SDK，详细请参见[集成AGC SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-started-android-0000001058210705#section1552914317248)。
2. 在开发环境中集成APM SDK。 集成APM SDK后，APM SDK将自动采集应用的[启动性能数据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-android-viewperformancedata-0000001052247256#section12606630111411)、[屏幕性能数据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-android-viewperformancedata-0000001052247256#section10961182475815)。

* AndroidStudio开发环境

  在APP模块（应用级）的Gradle文件（通常是app/build.gradle）中添加APM SDK依赖：

  ```screen
  // ...
  dependencies {
  // ...
  // Add APM SDK library dependency
  implementation 'com.huawei.agconnect:agconnect-apms:1.6.3.300'
  ```


* Eclipse开发环境 使用aar2eclipse工具转换aar包时dependencies依赖配置如下：

  ```screen
  dependencies {
      embed "com.huawei.agconnect:agconnect-apms:1.6.3.300"
  }
  ```

  具体步骤参见[Eclipse开发环境集成AGC SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-started-android-0000001058210705#section7561143410383)。

3. 在APP模块（应用级）的混淆配置中添加以下排除项：

   ```screen
   -keep class com.huawei.agconnect.**{*;}
   -dontwarn com.huawei.agconnect.**
   -keep class com.huawei.updatesdk.**{*;}
   -keep class com.huawei.hms.**{*;}
   -keepattributes Exceptions, Signature, InnerClasses, LineNumberTable
   ```


4. 如果您使用了AndResGuard，需要在混淆配置文件中加入AndResGuard允许清单：

   ```screen
   "R.string.hms*",
   "R.string.connect_server_fail_prompt_toast",
   "R.string.getting_message_fail_prompt_toast",
   "R.string.no_available_network_prompt_toast",
   "R.string.third_app_*",
   "R.string.upsdk_*",
   "R.layout.hms*",
   "R.layout.upsdk_*",
   "R.drawable.upsdk*",
   "R.color.upsdk*",
   "R.dimen.upsdk*",
   "R.style.upsdk*",
   "R.string.agc*"
   ```


5. 如果您的应用使用的是AndroidX类库，需要在gradle.properties中增加如下配置，APM SDK将自动适配AndroidX。

   ```screen
   android.useAndroidX=true
   # Automatically convert third-party libraries to use AndroidX
   android.enableJetifier=true
   ```

## 开启APM功能

APM利用检测（instrumentation）技术，实现[HTTP/HTTPS网络请求性能数据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-android-viewperformancedata-0000001052247256#section1098412343307)的无侵入采集。APM插件在1.5.2.302版本以后直接集成到AGC插件中，如您需要使用APM功能，请按如下步骤集成AGC插件并打开APM功能开关：
> 说明
>
> APM功能当前仅支持AndroidStudio开发环境集成。Eclipse开发环境当前不支持APM功能，无法支持网络请求性能数据的采集。

1. 在根级（项目级）Gradle文件中集成1.6.0.300及以上版本AGC插件： 说明
   > * SDK版本升级至1.6.2.300后，请务必重新下载替换agconnect-services.json文件。
   > * 如果集成低于1.9.1.300版本的AGC插件，且使用Gradle 8.0版本，需要在项目级"gradle.properties"文件添加如下命令：
   >
   >   ```screen
   >   apmsInstrumentationEnabled=false
   >   ```

   ```screen
   buildscript {
       repositories {
         // Add the maven repository
         maven { url 'https://developer.huawei.com/repo/' }
       }

       dependencies {
         // ...
         // To benefit from the latest APM features, update your Android Gradle Plugin dependency to at least v3.5.3
         classpath 'com.android.tools.build:gradle:3.5.3'

         // To benefit from the latest APM features, update AGC Plugin dependency to at least v1.6.0.300
         classpath 'com.huawei.agconnect:agcp:1.9.1.301'
       }
   }
   ```

2. 在应用级Gradle文件中添加agcp插件配置，并在agcp节点添加打开APM功能开关的配置（如不存在agcp节点则手动添加）。请根据实际情况选择：
   * 方式一：在"com.android.application" 插件下一行添加如下agcp插件配置，并在agcp节点打开APM开关。

   ```screen
   apply plugin: 'com.android.application'
   // Add the following configuration:
   apply plugin: 'com.huawei.agconnect'
   // Add this config to enable APM plugin
   agcp {
       enableAPMS true
   }
   ```

   * 方式二：在"plugins"中添加如下agcp插件配置，并在agcp节点打开APM开关。

   ```screen
   plugins: {
       id 'com.android.application'
       // Add the following configuration:
       id 'com.huawei.agconnect'
   }
   // Add this config to enable APM plugin
   agcp {
       enableAPMS true
   }
   ```

   > 说明
   > * 为了更好地使用APM SDK功能，建议Android Gradle Plugin版本在3.5.3及以上。
   > * agcp插件版本对Gradle的依赖关系请参见[AGC插件依赖关系](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-sdk-changenotes-0000001058732550#section7117746172220)。

## （可选）添加自定义监控功能

您如果需要监控应用在自定义场景下的性能，请参见[添加自定义监控配置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-android-addcustomtrace-0000001077683336)。

## 部署应用，查看性能监控数据

启用性能管理服务，集成APM SDK和开启APM功能后，APM将自动采集应用的性能数据并上报到数据中心。您可以在AGC中查看性能监控数据是否正常，具体步骤如下：

1. 在Android Studio中构建您的应用。
2. 安装并运行应用。
3. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
4. 在项目列表中找到您的项目，在项目下的应用列表中选择需要查看性能管理服务的应用。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155803.51319187803941123732480544007417:50001231000000:2800:3381F49D2E4F75213DFD106A8113C55F8040927B7F3E54AC2C57EC823B8B61E7.png)


5. 进入"质量 > 性能管理"，确认应用性能数据可以正常显示（通常会在15分钟内显示）。
   * 如果页面展示指标概览数据正常，说明APM性能监控分析功能正常。有关性能监控数据具体的分析方法，请参见[查看应用性能数据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-android-viewperformancedata-0000001052247256)。

     ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155803.56805387342144103213358859239305:50001231000000:2800:6EDA6D0F4CD9FD65BA91F4AEC48ADB6221595FAF5FA35CF5B190ACEB830FA1E4.png)
   * 如果数据展示异常或者长时间无数据，您可以参考[查看调试日志](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-android-viewlog-0000001052807285)进行问题定位。
