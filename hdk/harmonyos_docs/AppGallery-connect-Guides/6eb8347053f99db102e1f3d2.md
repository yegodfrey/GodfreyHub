# 功耗测试

云测试提供手机、折叠屏应用功耗测试功能，检测影响应用功耗的各项关键指标。

## 前提条件

您已成功创建测试任务，且配置的"测试范围"包含"功耗测试"。

## 查看测试报告

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击需要查看测试报告的项目。
3. 在左侧导航栏中，选择"质量 > 云测试"，进入云测试主页面。
4. 选择"测试任务"页签，您可以通过搜索框或测试任务列表中"应用类型"、"测试场景"、"测试状态"右侧的![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303165621.55639997871250597027369307008358:50001231000000:2800:200125BFBDECE6DD0B1BC0C27D699A9C14502D7C521F738AD86E15260A579A2A.png)筛选出您要查看的测试任务，然后点击"操作"列的"查看报告"进入测试报告页面。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303165621.20083273382484313026349481595177:50001231000000:2800:FC8DFE801BBE9519D9D93FF719790AB7C858D00735EB94AC26838840ACB18F78.png "点击放大")


5. 点击"功耗测试"页签，您可从功耗测试的测试报告概要中获得基本的测试检测项检测结果。被测应用类型不同，检测项不完全相同，请您根据实际情况选择性查看。
   * 安卓

     |**检测项**|**说明**|
     |:-----------------|:---------------------------------------------------------------------------|
     |安装/启动|安装和启动是实现功耗测试的基本条件，其非功耗测试的检测项。当应用无法安装或应用完全无法启动，该检测项不通过，应用功耗检测无法进行。|
     |Wakelock时长（分钟）|检测被测应用在被测手机上的Wakelock占用情况。当灭屏时WakeLock占用时间超过5分钟，该检测项不通过。|
     |屏幕占用（毫秒）|检测被测应用在被测手机上的屏幕占用情况。当亮屏时应用在后台阻止屏幕自动变暗或者关闭，灭屏时应用在屏幕变暗或者关闭时点亮屏幕，该检测项不通过。|
     |WLAN占用（分钟/小时）|检测被测应用在被测手机上的WLAN占用情况。当1小时内被测应用在被测手机上灭屏时WLAN占用超过5分钟，该检测项不通过。|
     |WLAN扫描（次/小时）|检测被测应用在被测手机上的WLAN扫描情况。当1小时内被测应用在被测手机上灭屏时WLAN扫描超过60次，该检测项不通过。|
     |音频占用（毫秒）|检测被测应用在被测手机上的音频占用情况。当被测应用在被测手机上存在扬声器或麦克风等音频设备占用（影音娱乐和出行导航类应用场景除外），该检测项不通过。|
     |摄像头占用（分钟）|检测被测应用在被测手机上的摄像头占用情况。当被测应用在被测手机上亮屏和灭屏时存在摄像头或闪光灯占用，该检测项不通过。|
     |定位传感器占用（分钟）|检测被测应用在被测手机上的定位传感器占用情况。当被测应用在被测手机上亮屏和灭屏时存在定位传感器占用（出行导航和后台计步类应用场景除外），该检测项不通过。|
     |Wakeup Alarm（次/小时）|检测被测应用在被测手机上的Wakeup Alarm次数。当1小时内被测应用在被测手机灭屏时Alarm唤醒频次超过20次，该检测项不通过。|

   * HarmonyOS应用（API < 10）

     |**检测项**|**说明**|
     |:-----------------|:---------------------------------------------------------------------|
     |安装/启动|安装和启动是实现功耗测试的基本条件，其非功耗测试的检测项。当应用无法安装或应用完全无法启动，该检测项不通过，应用性能检测无法进行。|
     |后台运行锁时长（分钟）|检测被测应用在被测手机上的后台运行锁占用情况。当灭屏时后台运行锁占用时间超过5分钟，该检测项不通过。|
     |屏幕占用（分钟）|检测被测应用在被测手机上的屏幕占用情况。当灭屏时存在屏幕占用，该检测项不通过。|
     |音频占用（分钟）|检测被测应用在被测手机上的音频占用情况。当亮屏和灭屏时存在扬声器或麦克风等音频设备占用（影音娱乐和出行导航类应用场景除外），该检测项不通过。|
     |摄像头占用（分钟）|检测被测应用在被测手机上的摄像头或闪光灯占用情况。当亮屏和灭屏时调用摄像头或闪光灯，该检测项不通过。|
     |定位传感器占用（分钟）|检测被测应用在被测手机上的定位传感器占用情况。当亮屏和灭屏时存在定位传感器占用（出行导航和后台计步类应用场景除外），该检测项不通过。|
     |Wakeup alarm（次/小时）|检测被测应用在被测手机上的Wakeup Alarm次数。当1小时内被测应用在被测手机灭屏时Alarm唤醒频次超过20次，该检测项不通过。|
     |动作传感器检测（分钟）|检测被测应用在被测手机上的动作传感器占用情况。当亮屏和灭屏时存在动作传感器占用（出行导航和后台计步类应用场景除外），该检测项不通过。|
     |后台常驻任务|检测被测应用在被测手机上的后台常驻模式与应用类型是否匹配。当后台常驻模式与应用类型不匹配，该检测项不通过。|
     |后台托管任务|检测被测应用在被测手机上的后台托管模式与应用类型是否匹配。当后台托管模式与应用类型不匹配，该检测项不通过。|

6. 在"测试报告"下方的设备列表中，选择某款机型，点击"操作"列的"查看详情"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303165621.93678096658569606508592379345087:50001231000000:2800:2798CF6B349C39BBD654D64AC92C20EB2015975F8B47D6A436458A627E7910E6.png "点击放大")

7. 打开被测应用在这款机型上执行的测试详情。该测试报告详情中包含被测应用信息、执行时长、运行被测应用的测试设备、执行时间，同时重点提供测试发现的问题点、测试截屏、异常描述、异常信息和日志。您可点击测试截屏查看被测应用在所选手机上的遍历情况。 在"日志"区域，点击鼠标悬停时出现的"下载"可将测试过程中打印的日志下载到本地查看。
