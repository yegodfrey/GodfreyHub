# 创建并配置函数

#### 创建函数

开通云函数服务后，您首先需要在AGC中创建函数，并添加函数执行的代码。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击需要创建云函数的项目。
3. 在左侧导航栏选择"云开发（Serverless）\> 云函数"，进入云函数主界面。
4. 选择"函数"页签，点击"创建函数"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260227165446.72088175903827943264296567987823:50001231000000:2800:C500AADBE6F46CF56A2D494D4A08C73DE0664C8C470FF7148666226F537553E7.png)

5. 页面右侧抽屉式滑出"创建函数"窗口，按照"函数配置 -\> 触发器 -\> 函数代码 -\> 层配置"引导顺序配置函数。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260227165446.35425315528400786852720722125221:50001231000000:2800:680281C6E21F09DD80EB5D84EA53D5815CA5763C6C79490C883A95A593852442.png)

#### 函数配置

1. 在"函数配置"页面，配置"函数名称"、"超时时长"、"实例并发"等函数信息。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260227165446.22081492341715705254409599842783:50001231000000:2800:EDBE72BB98B01E9D5FD4EC2DA633ADE72ABED323234BC7A988289E2FC15A7D0F.png)

   |配置项|说明|
   |:---|:-------------------------------------------------------------------------------------------------------------|
   |函数名称|函数的名称。|
   |描述|函数的描述信息。|
   |触发方式|请配置为"http请求"。 "http请求"表示通过HTTP协议或者SDK提供接口调用函数，仅支持custom-runtime运行环境。|
   |超时时长|函数最大运行时长，超过该时长，则默认函数执行失败，单位为秒，取值范围为1\~1800。 说明： * "同步"调用方式时，函数最大运行时长为55秒。 <!-- --> * "异步"调用方式时，函数最大运行时长为1800秒。|
   |实例并发|函数请求并发量上限，单位为个，取值范围为1\~10000。|
   |环境变量|key-value形式，您可以将需要的变量配置信息传入函数执行环境中，用于函数在运行时读取和使用。|

2. （可选）您可根据需要添加环境变量，支持表单格式和JSON格式两种编辑方式。添加完成后，您还可以点击"JSON格式导出"，导出以"函数名称.json"格式命名的环境变量文件，以备后续使用。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260227165446.67133634536956719801931990851339:50001231000000:2800:763F5531C64CB89DBF38029804E2EC28FF97BCC4285961C14060C3760A278335.png)  
   * 环境变量的key值具有唯一性，且"PROJECT_CREDENTIAL"和"AGC_"为系统级环境变量标识，不允许添加以其命名或以其为前缀的环境变量。
   * 环境变量总数不超过1000个。
   * 表单格式编辑 点击"新增变量"，输入key和value值，如下图中所示，env1为环境变量的key值，test为value值。点击![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260227165446.26496564319230750560535065482593:50001231000000:2800:4AAB7D8CAAB4C05D9BA5F2A7654D01430FDCBA44A02E6FE9EBFD2102C745C4E9.png)可将变量删除。

     ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260227165446.88783003630172004569201797528336:50001231000000:2800:D3ACD5FC18079F502D637B8CA3CA67619B1958B1866755DB94296743CBAC5358.png)
   * JSON格式编辑 选中"JSON格式编辑"，在文本框中以key-value键值对JSON格式添加环境变量。当添加的环境变量比较多时，为了方便核对，可点击"format"对变量进行格式化排列。

     ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260227165446.49215298162474991323965222245516:50001231000000:2800:554F4C60D538570F125ECBD7EEC92278CAE440A67E98BE2A9D40CA29ACF8AB58.png)
3. "函数配置"页面配置完成后点击"下一步"。  

#### 触发器

进入"触发器"页面，将展示后端自动创建的函数latest版本的API网关触发器和默认触发器（即HTTP触发器），从而可以通过API网关或端云侧网关访问函数平台调用函数。点击"下一步"。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260227165446.52309262437211665853932533572482:50001231000000:2800:C93030661818048472ED55801C4EE43561BE430AAF3790932AFA75B8F8EE9ADA.png)  
* 函数创建完成后，当您需要配置其他API分组、API名称或者路径的API网关触发器时，可在函数详情页或者别名详情页的"触发器"页签添加新的API网关触发器。函数的一个版本或者别名最多可添加10个API网关触发器。
* 支持删除后端自动创建的API网关触发器，但默认触发器不可删除。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260227165446.82908112810064259951123527376943:50001231000000:2800:A5323BF76E3B471C1F4F295FC5EE8CF5A008390C7691E047D9E021E34CE8630E.png)  

|触发器类型|参数|说明|
|:--------------|:----|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|API网关触发器|API分组|要调用的API所属的API分组，由系统自动创建，以"CloudFunctions_"+项目ID后10位命名。例如：CloudFunctions_7085531418。|
|API网关触发器|API名称|要调用的API名称，由系统自动创建，以"函数名称-函数版本/函数别名"命名。例如：httptest-0。|
|API网关触发器|路径|要调用的API对应的URL，以"/"开头。|
|API网关触发器|方法|API调用方法，支持GET、POST、PATCH、PUT、DELETE、HEAD、OPTIONS。|
|API网关触发器|认证方式|支持四种API认证方式： * API客户端（Server适用）：如从服务端调用API，可采取此认证方式。 * API客户端（Client适用）：如从客户端调用API，可采取此认证方式。 * 用户身份认证：确认用户身份后才可调用API，可采取此认证方式。 * 免认证：任何人都可以调用该API，无需认证。请谨慎选择此选项。 此处自动选择：API客户端（Client适用）。|
|API网关触发器|发布环境|API发布的环境，支持灰度环境、测试环境、生产环境，可多选。|
|默认触发器（即HTTP触发器）|请求方式|目前支持GET、POST、PUT、DELETE、HEAD、PATCH、OPTIONS请求方式。|
|默认触发器（即HTTP触发器）|鉴权方式|自动选择"不鉴权"，表示无鉴权能力。|

#### 函数代码

进入"函数代码"页面，配置"运行环境"、"内存配置"、"代码输入类型"等信息，配置完成后点击"下一步"。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260227165446.94420448890282624959751242412848:50001231000000:2800:8F34F90853BB49A6C93D83437F4761FAF9854C91C6D9E4A6738B0963DB17A3E0.png)  

|配置项|说明|
|:-----|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|运行环境|函数容器的运行环境。"触发方式"选择"http请求"时仅支持custom-runtime latest运行环境，latest表示使用最新版本。 custom-runtime是自定义运行环境，详细说明请参见[Custom Runtime详解](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/develop-func-introduction-0000001513121568#section13875571337)。|
|内存配置|函数容器所占有的内存大小，单位为MB，取值范围：500，1000，2000，4000。|
|代码输入类型|保持默认的"\*.zip文件"方式。 说明： 入口方法文件的编写方法和函数部署包结构，请参见[Custom Runtime](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/develop-func-custom-0000001564201901)运行环境下的"入口方法"和"准备函数部署包"章节。|
|代码文件|用于上传函数部署包。 点击![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260227165446.82644338036320060236453468999280:50001231000000:2800:BBC11D90D792395A63FFB461E872187D8EBD6B6313F7D9D2053A24B7EFA83ED5.png)即可上传函数部署包，也可直接拖曳zip文件至虚线框内。|

#### 层配置

层可以为您提供公共依赖库的发布与部署能力。您可以将函数依赖的公共库和相关依赖项提炼到层，通过为函数绑定层，便可以在函数中使用库，而不必将库包含在函数的代码包中，从而达到缩小函数代码包体积与缩短函数部署时间的效果，也避免了使用函数代码安装和打包依赖项时可能出现的错误。详细的层管理功能，请参见[层管理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloud-function-layer-0000001517762624)。

如果您尚未创建层，可跳过下述步骤，直接点击页面底部的"创建"完成函数定义，后续创建层之后可在函数详情页再进行层配置，为函数绑定层。如果您在创建函数之前已创建层，可按照下述步骤进行操作。

1. 进入"层配置"页面，点击"绑定层"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260227165446.21672878329928669924353341955096:50001231000000:2800:561F4331426117BCDE71706BBD137EFFA13B0747874F7185E26E4751A5A1AEEC.png)

2. 在右侧弹出的"绑定层"界面中，下拉框选择"层名称"和"版本"，"层范围"等信息根据层的配置将被自动填充，完成层绑定后点击"确定"。一个函数最多可以绑定5个层。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260227165446.67667746043478527105332585362338:50001231000000:2800:A3127C8DB4B66F8EABEA7E5D4210C23D688397379C9794DDE06106B0C5CDA9B9.png)  
   选择层时，层的兼容运行时需与函数运行环境相符，系统会自动完成过滤。若无匹配的层供您选择，请参考[创建层](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloud-function-layer-0000001517762624#section11358162018572)创建相同运行环境的层后再进行绑定。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260227165446.72525303342135538073020895925612:50001231000000:2800:D511A7F82CC0CAEA5454E39D0134B01CFDC10F382DBE31D9642B08E8B214B4D1.png)  

   |参数|说明|
   |:----|:--------------------------------------------------|
   |层名称|层的名称。重复时自动在同名的层中创建一个新版本。|
   |版本|存在多个层版本时，选择函数绑定的层版本。|
   |层范围|层的共享范围。 * 项目内共享 * 团队内共享|
   |兼容运行时|层使用的语言环境。 * nodejs * java * python * custom-runtime|
   |层描述|层的附加说明，长度不超过1024位。|

3. 返回到"层配置"界面，绑定成功的层将展示在层列表中。若您需要解除层与函数的绑定关系，点击"解绑"即可。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260227165446.86702342107061766255397701248110:50001231000000:2800:3DA61C707EC4B33D2E4AE0411F0BF253C076D35095C9804637AB2696CA780066.png)

4. 按照"函数配置 -\> 触发器 -\> 函数代码 -\> 层配置"顺序配置过程中，您若需要修改前面步骤中的配置，可点击"上一步"进行回退，配置完成后点击"创建"提交函数定义。
