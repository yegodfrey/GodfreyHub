# Google Play Games

您可以在应用中集成Google Play Games认证方式，让您的用户可以使用自己的Google Play Games账号进行AppGallery Connect身份验证。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143819.60987873061833485986337073747714:50001231000000:2800:4AD0EB55F731295C8A9EA0F5159BD9D6E6EF63B63785C118AA7A6784538B0B9F.png)  
* Google Play Games三方认证方式仅在海外站点支持，当您选择数据处理位置为德国、新加坡或俄罗斯时可以使用此认证方式。
* 集成Google Play Games三方认证方式时，您的用户设备需要支持GMS（Google Mobile Services）。  

#### 前提条件

* 您需要在AGC控制台[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-integration-sdk-0000001325876845)。  

#### 开发步骤

认证服务提供了两种开发方式接入Google Play Games账号：

* 推荐您使用新的统一登录接入方式，请参见[统一登录接入方式](#section1950440105218)。
* 同时为了保证兼容性保留了老的传统接入方式，请参见[传统接入方式](#section16952720551)。  

#### 统一登录接入方式

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143819.18142489616213978803640889079267:50001231000000:2800:7635BDF9BD1B366376932824A82C3F1B91AEFEC196AF15B1E446B2A4C4D30C61.png "点击放大")

1. 添加SDK依赖。
   * Android Studio开发环境
     * Version Catalog方式管理依赖
       1. 打开Android Studio项目级gradle目录下的"libs.versions.toml"文件，在\[versions\]中声明Google Play Games SDK版本号。

          ```
          [versions]
          googlegameVersion = "16.0.1"  # 以16.0.1为例
          ```

       2. 在"libs.versions.toml"文件的\[libraries\]中声明华为认证SDK和Google Play Games SDK。

          ```
          [libraries]
          agconnect-auth-googlegame = { module = "com.huawei.agconnect:agconnect-auth-googlegame", version.ref = "agcVersion" }  # agcVersion声明请参见声明AGC插件和SDK。
          googlegame-sdk = { module = "com.google.android.gms:play-services-auth", version.ref = "googlegameVersion" }
          ```

       3. 在应用级"build.gradle"文件的"dependencies"中添加华为认证SDK和Google Play Games SDK的编译依赖。

          ```
          dependencies {      
               implementation libs.agconnect.auth.googlegame
               implementation libs.googlegame.sdk
          }
          ```

     * 非Version Catalog方式管理依赖 打开应用级gradle文件（通常在 app/build.gradle），在"dependencies"中添加华为认证SDK和Google Play Games SDK的编译依赖：

       ```
       dependencies {
           implementation "com.huawei.agconnect:agconnect-auth-googlegame:1.9.4.300"     
           implementation "com.google.android.gms:play-services-auth:{version}"
       }
       ```

   * Eclipse开发环境  
     打开aar2eclipse/aar目录下的build.gradle文件， 在"dependencies"中添加华为认证SDK和Google Play Games SDK的编译依赖。具体步骤参见[Eclipse开发环境集成AGC SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-integration-sdk-0000001325876845#section1878849165620)。

     ```
     dependencies {
         embed "com.huawei.agconnect:agconnect-auth-googlegame:1.9.4.300"
         embed "com.google.android.gms:play-services-auth:{version}"
     }
     ```

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143819.60127662006761754983647299405613:50001231000000:2800:2A35FBBA33A5CAC3A052C7F86B2A8FF4704B2206B2D9C488FF00D57C0EC50114.png)  
   * 示例中的googlegameVersion和{version}请替换为Google Play Games SDK的最新版本号，华为不负责更新。
   * 由于华为未提供Google Play Games SDK依赖包，您可以在Google Play Games开放平台下载最新版本的Google Play Games SDK依赖包进行手动集成。
2. 配置Google Play Games账号登录所需参数。
   1. 在资源文件/app/res/values/string.xml中配置google应用的app_id和client_id。  
      ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143819.63213841391156311082718427916225:50001231000000:2800:D169DA01FD8ED81615C97FF2FEFC5AB29C76B1621BA68B0CBEE5DFD54EFEE51E.png)  
      client_id参考[启用认证方式](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-authentication-method-0000002417916829#section1871913499476)中配置的"客户端ID"，app_id为client_id开头的数字（通常12位或更多）。  

      ```
      <string name="google_app_id">5758********</string>
      <string name="google_client_id">5758********-lp1cdv4uu2k1jjm1ksi5n59tta0mdkg9.apps.googleusercontent.com</string>
      ```

   2. 在AndroidManifest.xml的application节点中配置metadata信息。

      ```
              <meta-data
                  android:name="com.google.android.gms.games.APP_ID"
                  android:value="@string/google_app_id" />
              <meta-data
                  android:name="com.google.android.gms.version"
                  android:value="@integer/google_play_services_version" />
      ```

3. 添加生命周期回调，请参见[统一登录调用页面回调](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-unified-login-0000001325756981)。
4. 调用[AGConnectAuth.signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauth-0000001054482530#section125666562219)，登录Google游戏账号。  

   ```
   "Java"
   AGConnectAuth.getInstance().signIn(this,AGConnectAuthCredential.GoogleGame_Provider).addOnSuccessListener(new OnSuccessListener<SignInResult>() {
           @Override
           public void onSuccess(SignInResult signInResult) {
                   // onSuccess
                   AGConnectUser user =  signInResult.getUser();
           }
   })
   .addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
                   // onFail
           }
   });
   ```

   ```
   "Kotlin"
   AGConnectAuth.getInstance().signIn(this, AGConnectAuthCredential.GoogleGame_Provider).addOnSuccessListener {
       // updateUI
   }.addOnFailureListener {
       // onFailure
   }
   ```

#### 传统接入方式

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143819.15562918026574364381753069905091:50001231000000:2800:309EB88F60790806808A34C3D093D2B829E4516DA89CF2BBFAAFFDE3EB3EBAA7.png "点击放大")

1. 在应用的登录界面，初始化[AGConnectAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauth-0000001054482530)实例，获取AGC的用户信息，检查是否有已经登录的用户。如果有则可以直接进入用户界面，否则显示登录界面。  

   ```
   "Java"
   AGConnectUser user = AGConnectAuth.getInstance().getCurrentUser();
   ```

   ```
   "Kotlin"
   val user = AGConnectAuth.getInstance().currentUser
   ```

2. Google Play Games账号登录，并获取Google Play Games账号的用户授权信息。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143820.97441551313571000068027681783815:50001231000000:2800:E21BEAD1D96817E2C1AC25C2FACEC1BC6D0D3E9C3569B363E48389FB0A0CB464.png)  
   此步骤仅供参考，更详细内容，请参见[Google Play Games官方文档](https://developers.google.com/games/services/android/quickstart) 。
   1. 获取Google Play Games登录授权。  

      ```
      "Java"
      GoogleSignInOptions gso = new GoogleSignInOptions.Builder(GoogleSignInOptions.DEFAULT_GAMES_SIGN_IN)
               .requestServerAuthCode(CLIENT_ID)
               .build();
      client = GoogleSignIn.getClient(this, gso);

      Intent signInIntent = client.getSignInIntent();
      startActivityForResult(signInIntent, RC_SIGN_IN);
      ```

   <!-- -->

   2. 添加授权确认后的回调，获取授权后的ServerAuthCode。  

      ```
      "Java"
      @Override
      protected void onActivityResult(int requestCode, int resultCode, Intent data) {
          super.onActivityResult(requestCode, resultCode, data);

          if (requestCode == RC_SIGN_IN) {
              Task<GoogleSignInAccount> task = GoogleSignIn.getSignedInAccountFromIntent(data);
              task.addOnSuccessListener(new OnSuccessListener<GoogleSignInAccount>(){
                  @Override
                  public void onSuccess(GoogleSignInAccount googleSignInAccount) {
                      String serverAuthCode = googleSignInAccount.getServerAuthCode();
                  }
              }).addOnFailureListener(new OnFailureListener(){
                  @Override
                  public void onFailure(@NonNull Exception e) {
                  }
              });
          }
      }
      ```

3. 调用[GoogleGameAuthProvider.credentialWithToken](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/googlegameauthprovider-0000001054322505#section314061191116)使用从Google Play Games账号获取的serverAuthCode生成credential，并调用[AGConnectAuth.signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauth-0000001054482530#section298148131715)实现登录。  

   ```
   "Java"
   AGConnectAuthCredential credential = GoogleGameAuthProvider.credentialWithToken(serverAuthCode);
   AGConnectAuth.getInstance().signIn(credential)
   .addOnSuccessListener(new OnSuccessListener<SignInResult>() {
       @Override
       public void onSuccess(SignInResult signInResult) {
           // onSuccess
           AGConnectUser user = signInResult.getUser();
       }
   })
   .addOnFailureListener(new OnFailureListener() {
       @Override
       public void onFailure(Exception e) {
           // onFail
       }
   });
   ```

   ```
   "Kotlin"
   val credential = GoogleGameAuthProvider.credentialWithToken(serverAuthCode)
   AGConnectAuth.getInstance().signIn(credential).addOnSuccessListener {
       // onSuccess
       val user = it.user
   }.addOnFailureListener {
       // onFail
   }
   ```

#### 更多信息

* 您如果想让用户可以使用多个账号登录您的应用，可以将多个[账号进行关联](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-associated-0000001053692650)。
* 当用户不需要使用应用，或者需要切换其他账号登录认证，可以先执行[登出](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-sign-out-0000001053612647)。
* 当用户需要注销当前用户，可以进行[销户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-deleteuser-0000001057730521)。
* 对于销户、修改密码、关联账号以及重置手机账号和邮箱账号等敏感操作，为了提高安全性，需要用户必须在5分钟内登录过才能执行。如果用户执行敏感操作时登录超过5分钟，需要[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-reauthenticate-0000001127287737)后再执行敏感操作。
* 您可以参考[异常处理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-troubleshooting-0000001052932665)实现自己的异常处理机制，从而减少异常情况的发生。
* 您可以使用云函数触发器来接收用户注册、登录、销户等关键事件，从而[扩展认证服务的能力](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-extension-0000001053372708)。
* 您可以参考[管理用户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-user-manage-0000001606051705)对用户进行解锁、停用等操作。
