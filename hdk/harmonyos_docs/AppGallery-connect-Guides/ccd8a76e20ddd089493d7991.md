# 设置应用内默认值

## 获取远程配置对象实例

调用[AGConnectConfig.getInstance](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section206211537135210)获取远程配置对象实例用于设置应用内默认参数值。

```screen
"Java"
AGConnectConfig config = AGConnectConfig.getInstance();
```

```screen
"Kotlin"
val config = AGConnectConfig.getInstance()
```

## 设置应用内默认值

您可以在远程配置对象中设置应用程序内的默认值，以便您的应用程序在连接到远程配置服务之前按照预期运行。如果云端未设置参数值，则可以使用本地默认值。 当前支持两种类型的默认值：

* XML资源文件类型的默认值 在工程的res/xml中增加一个远程配置默认值的xml文件，其中键值对为<value key="testkey">testvalue</value>，例如文件remote_config.xml。

  ```screen
  <remoteconfig>
       <value key="test1">test1</value>
       <value key="test2">true</value>
       <value key="test3">123</value>
       <value key="test4">123.456</value>
       <value key="test5">test-test</value>
  </remoteconfig>
  ```

  调用[AGConnectConfig.applyDefault](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section9109980584)传入默认值，传入后立即生效。

  ```screen
  "Java"
  config.applyDefault(R.xml.remote_config);
  ```

  ```screen
  "Kotlin"
  config.applyDefault(R.xml.remote_config)
  ```

* Map对象的默认值 可参考如下配置调用[AGConnectConfig.applyDefault](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section42628541407)传入默认值，其中Object只支持String、Boolean、Number类型，如传入其他类型则会忽略。

  ```screen
  "Java"
  Map<String, Object> map = new HashMap<>();
  map.put("test1", "test1");
  map.put("test2", "true");
  map.put("test3", 123);
  map.put("test4", 123.456);
  map.put("test5", "test-test");
  config.applyDefault(map);
  ```

  ```screen
  "Kotlin"
  val map = mutableMapOf<String,Any>()
  map["test1"] = "test1"
  map["test2"] = "true"
  map["test3"] = 123
  map["test4"] = 123.456
  map["test5"] = "test-test"
  config.applyDefault(map)
  ```

## 更多信息

* 您可以在AppGallery Connect[设置新的云端配置项](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-remoteconfig-android-cloudconfig-0000001056587179)，并根据业务逻辑配置不同的值，然后在应用中所需位置[获取云端配置项](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-remoteconfig-android-obtainconfig-0000001054997460)，从而灵活更新应用中的信息。
* 您可以和云函数结合使用，通过云函数的触发功能，当远程配置发布或回退版本时，实时通知客户端去获取最新的配置信息。具体实现方法请参见[实时更新远程配置参数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-remoteconfig-android-usingfunction-0000001056347167)。
