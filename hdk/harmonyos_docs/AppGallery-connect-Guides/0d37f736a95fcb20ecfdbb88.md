# 成功案例

#### 客户需求

《花椒直播》希望通过主播PK大赛这个火爆的活动进一步宣传花椒，吸引更多用户下载花椒直播应用。这个页面嵌在应用内，客户希望用户下载花椒直播后要第一时间进入这个页面看到内容。  

#### 华为解决方案

集成App Linking服务，在AGC控制台创建聚合链接，将这个页面的深度链接配置到聚合链接中，用户在平台上看到此活动进行点击。如果该用户已安装花椒直播，可直接拉起App打开这个页面。如果用户没有安装，则跳转华为应用市场客户端进行安装，安装后点击打开即可直达这个活动页面。
