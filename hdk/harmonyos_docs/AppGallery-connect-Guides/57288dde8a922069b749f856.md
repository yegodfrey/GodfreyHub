# 调试事件上报

> 注意
>
> * 事件上报时，在用户端侧GET对应的URL即可。
> * 媒体必须实时、直接地向华为方进行事件的上报，注意不允许通过服务器侧上报。

调用获取广告接口返回中的[trackUrl](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/adx_dsp_api_adappinfo-0000001222166100#ZH-CN_TOPIC_0000001222166100__zh-cn_topic_0000001222166100_p010920813527)进行上报，调用格式如下：

```screen
https://xxxx.com/?param={0}&event=__EVENT__&time=__TIME__&extInfo=__EXTINFO__
```

事件上报链接所支持的宏参数如下表所示。

|参数|说明|
|:----------|:--------------------------------------------------------------------------|
|__EVENT__|事件上报信息。 具体请参见[__EVENT__参数](#ZH-CN_TOPIC_0000001223256328__p14133174415302)。|
|__TIME__|时间戳（北京时间）。 单位：毫秒 示例：1625714142001|
|__EXTINFO__|扩展信息。|

**__EVENT__**事件上报支持的宏参数如下：

|参数|说明|
|:-------------|:--------------------------------------------------------------------------------------------------------|
|show|已经进入可见范围，且曝光面积≥50%时进行上报。已经进入可见范围，满足曝光并上报之后从界面消失，回滚重现展示该元素并满足曝光条件后，应该重新上报；为了提高算法精准度，建议曝光时尽量使用time参数上传曝光时间。|
|click|用户点击广告可交互区域时上报。|
|downloadStart|开始下载时上报。|
|downloadFinish|下载完成时上报。|
|installStart|开始安装时上报。|
|installFinish|安装完成时上报。|
