# 未成年人控制

游戏内嵌社区提供了未成年人检查接口，当您需要针对未成年人访问游戏内嵌社区的权限进行相关控制时，可以调用该接口实现。

## 前提条件

内嵌社区已完成[初始化](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/pgsmoment-init-0000001244091880)。

## 开发步骤

调用[PgsMoment.checkAdult](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/gdpsdk-api-pgsmoment-0000001403658572#section1185345812247)来检查当前玩家是否为成年人，并实现后续的逻辑处理。

```screen
public void checkAdult() {
    PgsMoment.checkAdult(new CheckAdultCallback() {
        @Override
        public void onSuccess(int isAdult) {
            if (isAdult == 0) {
                // 检查结果：当前用户为未成年人
            } else if (isAdult == 1) {
                // 检查结果：当前用户为成年人
            } else {
                // 检查结果：当前用户未完成实名认证
            }
        }
        @Override
        public void onFailure(Response response) {
            // 检查过程中出现异常
            Log.e(TAG, "RtnCode: " + response.getRtnCode() + "; Msg: " + response.getMsg());
        }
    });
}
```
