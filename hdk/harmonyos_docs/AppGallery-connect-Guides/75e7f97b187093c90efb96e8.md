# 获取SDK配置信息

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择您的应用。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704165807.00233949879807399785846425728452:50001231000000:2800:501C81A8DFCF62357F10202DE78D6D14C84435464F834C99D7C3E1EA2E28EC63.png)

3. 在"项目设置"页面下载配置文件"agconnect-services.json"。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704165807.82838626085089367806972870053137:50001231000000:2800:D879F7C31C288199BCE454D602F2996B64701798B7F7C61A86C280DF4F25B590.png)  
   * 配置文件中默认会包含AGC为应用分配的客户端密钥和API密钥信息，其中客户端密钥和API密钥均为密文。
   * 您也可以在下载JSON文件前打开"不包含密钥"开关，配置文件中将不包含密钥信息，由您自行调用AGC SDK的接口手动配置。
   * 如果您的套餐升级到了付费档，为避免被冒用产生异常账单，建议您将密钥存储在您自己的服务器，并妥善保管。
