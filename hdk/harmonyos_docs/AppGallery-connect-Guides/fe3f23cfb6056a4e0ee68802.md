# 获取当前发言玩家列表

通过本章的开发指导，您可实现获取房间内当前发言玩家列表的功能。  

#### 前提条件

玩家已[加入](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-joinroom-roomid-web-0000001223118676)房间。  

#### 开发步骤

通过设置音量回调的时间间隔来开启音量回调，并通过音量回调接口获取当前发言玩家ID列表。

1. 调用[GameMediaEngine.on](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-web-0000001247887067#section1487511413163)方法注册[speakersDetection](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-eventname-web-0000001285559041#ZH-CN_TOPIC_0000001285559041__p102821521946)事件回调，监听音量检测结果。

   ```
   ...
   const gameMediaEngine = await GameEngin.create(options);
   // 监听音量检测结果
   gameMediaEngine.on('speakersDetection', (roomId: string, openIds: string[]) => {
     // openIds为当前发言人的ID
   });
   ```

2. 调用[GameMediaEngine.enableSpeakersDetection](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-web-0000001247887067#section138559010395)方法开启房间音量统计。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250424164754.57827990936214696332339777177061:50001231000000:2800:36BDD2E4DEF7A2ACD7B4CB0144A40FC3F0F8A2C7A2EA04EE12B56311525CED6D.png)  
   * 根据当前发言玩家的音量大小排序，列表中最多可展示当前3个发言玩家。
   * 在小队房间中，使用此参数设置音量统计周期时，取值为0表示关闭音量统计，其他数值均表示开启音量统计。

   ```
   ...
   // interval：统计周期，单位：毫秒
   gameMediaEngine.enableSpeakersDetection(roomId, 200);
   ```
