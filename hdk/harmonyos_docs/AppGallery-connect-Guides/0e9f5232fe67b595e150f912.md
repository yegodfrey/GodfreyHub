# 概述

连接器是基于云函数构建的高阶能力，通过连接器可快速实现云函数与三方系统的对接，聚合三方开放能力。目前支持两种连接器：

* [自定义连接器](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/cloud-function-custom-connector-0000002254492145)：支持访问元服务服务器域名下所有接口或者调用某个第三方服务接口。当前由于元服务域名管控约束，开发者在开发过程中需对每个元服务配置服务器域名。为提高开发者批量开发元服务的效率，开发者可创建自定义连接器，配合Cloud Foundation Kit的免域名管控特性，使用Cloud Foundation Kit在端侧调用云函数，即可实现接口快速代理，从而达到元服务快速访问API接口的目的。
* [官方连接器](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/cloud-function-official-connector-0000002219452452)：是云函数提供的统一聚合能力，可帮助开发者快速接入并集成华为方特性。目前仅支持内容风控服务类型的官方连接器，它可以协助开发者快速对接和集成内容风控服务，通过数据分析识别文本和图片中是否存在涉黄、涉政、涉暴、涉恐、赌博、宗教、虐童、违禁品、广告（包含二维码）、灌水、低俗、恶心、封建迷信、负面、辱骂等违规内容，并对识别出的风险内容进行评估，以便开发者根据评估结果采取相应控制措施，确保内容的合规性。
