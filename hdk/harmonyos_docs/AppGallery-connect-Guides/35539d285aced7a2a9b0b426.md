# 使用限制

本章节将为您详细介绍应用内消息服务不同类型的限制。这些限制可能会根据实际情况随时更新，请您注意文档变化。  

#### 请求消息限制

|操作|限额|
|:-------------|:------|
|应用内消息SDK请求消息频率|24小时/次。|

#### 设备限制

设备限制是指SDK对用户终端的限制。  

|限制项|限制|
|:-----------|:-----------------------------------------|
|设备品牌|支持所有品牌设备。|
|设备类型|HarmonyOS当前仅支持手机和平板设备。|
|Android OS|Android 4.2及以上（API Level 17及以上）。|
|iOS OS|1.2.1及以前版本：iOS 8及以上。 1.3.0及以后版本 ：iOS 9及以上。|
|Web浏览器|不支持Web应用。|
|EMUI（针对华为手机）|无限制。|
|HMS Core APK|无限制。|
|应用市场客户端|无限制。|
