# 使用数据库的其他操作

#### 写入数据

您可以通过[upsert()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-harmonyos-ts-databasecollection-0000001626270306#section108601543193811)将一个或者一组对象写入到当前存储区中。在写入对象时，如果在存储区已经存在主键值相同的对象，则更新已有的对象；如果不存在，则写入一个新的对象。写入的数据可以来自于新建对象，或者从存储区查询出来的对象。

写入一组对象时，数据的写入操作是原子的，即对象列表中的对象要么全部成功写入，要么全部失败。

调用写入数据方法后，会返回一个Promise对象，对象中封装了写入操作执行的结果。通过该Promise对象可以异步侦听执行结果：如果执行成功，可以获取写入的对象数量；如果执行失败，可以获取错误信息。

注意事项：

* 写入一组对象时，该组中的对象必须属于同一个对象类型，否则会导致写入失败。
* 写入一组对象时，数据总大小不能超过2MB，否则会导致写入失败。
* 写入一组对象时，数据总条数不能超过1000条，否则会导致写入失败。

代码示例：

将BookInfo对象写入至存储区中，写入成功后，返回写入的数量；写入失败，抛出异常。

```
async function upsert () {
    try {
      const record = await cloud.database({objectTypeInfo: schema, zoneName: "QuickStartDemo"}).collection(BookInfo).upsert({
        "id":2000,
        "bookName" : "book_name",
        "author" : "huawei",
        "price" : 1020
      });

       Logger.info(TAG, "upsert success, record  = " + record);
    } catch (err) {
      Logger.error(TAG, "upsert err------------" + JSON.stringify(err));
    }
}
```

#### 查询数据

云数据库通过[query()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-harmonyos-ts-databasecollection-0000001626270306#section1894820514118)方法查询对象，并提供了丰富的谓词查询，比如[equalTo()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-harmonyos-ts-databasezonequery-0000001674750265#section197761791979)、[notEqualTo()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-harmonyos-ts-databasezonequery-0000001674750265#section53841217718)、[in()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-harmonyos-ts-databasezonequery-0000001674750265#section1965317277719)等。通过单个或者多个链式过滤条件，您可以从存储区查询到满足特定条件的对象，也可以通过排序谓词对查询结果排序，或者通过限定查询返回数量谓词限定查询结果返回的数量。详细的查询条件请参见[DatabaseZoneQuery](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-harmonyos-ts-databasezonequery-0000001674750265)。

应用会直接从云侧存储区服务器查询数据，本地不会缓存数据。

注意事项：

每次的查询操作仅支持查询一个对象类型下的数据。  

#### 简单查询

您可以在无查询条件时，获取一个对象类型中所有的对象；也可以指定单个查询条件，来获取满足该条件的对象。

* 查询对象类型BookInfo的所有数据。

  ```
  async function queryAllBooks() {
      try {
        const resultArray = cloud.database({objectTypeInfo: schema, zoneName: "QuickStartDemo"}).collection(BookInfo).query().get();

        Logger.info(TAG, "query success : " + JSON.stringify(resultArray));
      } catch (err) {
        Logger.error(TAG, "query err------------" + JSON.stringify(err));
      }
  }
  ```

* 通过异步侦听的方式查询"bookName"为"左传"的书籍。

  ```
  async function query ()  {
      try {
        const resultArray = cloud.database({objectTypeInfo: schema, zoneName: "QuickStartDemo"}).collection(BookInfo).query()
                            .equalTo('bookName', '左传').get();

        Logger.info(TAG, "query success : " + JSON.stringify(resultArray));
      } catch (err) {
        Logger.error(TAG, "query err------------" + JSON.stringify(err));
      }
  }
  ```

#### 复合查询

您可以通过多个链式过滤条件，来获取满足条件的对象。多个链式条件之间默认用"与"运算。

* 构造查询条件，并调用[query()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-harmonyos-ts-databasecollection-0000001626270306#section1894820514118)方法，查询"bookName"包含"数据库"，"price"大于20.0并且小于50.0的书籍。

  ```
  cloud.database({objectTypeInfo: schema, zoneName: "QuickStartDemo"}).collection(BookInfo).query().contains('bookName', '数据库').greaterThan('price', 20.0).and().lessThan('price', 50.0).get();
  ```

* 构造查询条件，并调用[query()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-harmonyos-ts-databasecollection-0000001626270306#section1894820514118)方法，查询"bookName"包含"数据库"，"price"在小于20.0或者大于50.0区间的书籍。

  ```
  cloud.database({objectTypeInfo: schema, zoneName: "QuickStartDemo"}).collection(BookInfo).query().contains('bookName', '数据库').lessThan('price', 20.0).or().greaterThan('price', 50.0).get();
  ```

* 构造查询条件，并调用[query()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-harmonyos-ts-databasecollection-0000001626270306#section1894820514118)方法，查询"bookName"包含"史记"，"author"是"司马迁"，"price"大于60.0的书籍。

  ```
  cloud.database({objectTypeInfo: schema, zoneName: "QuickStartDemo"}).collection(BookInfo).query().contains('bookName', '史记').equalTo('author', '司马迁').greaterThan('price', 60.0).get();
  ```

* 构造查询条件，并调用[query()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-harmonyos-ts-databasecollection-0000001626270306#section1894820514118)方法，查询"bookName"包含"自传"，并且"author"是"齐白石"，或者"author"是"司马迁"，并且"price"大于60.0的书籍。

  ```
  cloud.database({objectTypeInfo: schema, zoneName: "QuickStartDemo"}).collection(BookInfo).query().contains('bookName', '自传').beginGroup().equalTo('author', '齐白石').or().equalTo('author', '司马迁').endGroup().greaterThan('price', 60.0).get();
  ```

#### 数据排序

您可以通过[orderByAsc()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-harmonyos-ts-databasezonequery-0000001674750265#section510510507712)或者[orderByDesc()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-harmonyos-ts-databasezonequery-0000001674750265#section4831175212713)实现对查询结果集中的对象按某个字段进行升序或者降序排列，排序谓词需要在其它查询谓词之后且在限定数据查询数量谓词之前。

构造查询条件，并调用[query()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-harmonyos-ts-databasecollection-0000001626270306#section1894820514118)方法，查询所有价格小于50.0的书籍，并且按降序排列。

```
cloud.database({objectTypeInfo: schema, zoneName: "QuickStartDemo"}).collection(BookInfo).query().lessThan('price', 50.0).orderByDesc('price').get();
```

#### 限定数据查询返回数量

在查询数据时，您可以通过[limit()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-harmonyos-ts-databasezonequery-0000001674750265#section195251849262)限定查询返回数据的起始位置和数量，实现数据的分页。例如与排序查询谓词组合使用，可以实现获取top-N条数据。

对查询结果中的对象限定查询返回数量时，限定数据查询返回数量谓词在所有其它谓词查询之后。

* 构造查询条件，并调用[query()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-harmonyos-ts-databasecollection-0000001626270306#section1894820514118)方法，查询所有价格小于50.0的书籍，并且只显示最开始10条记录。

  ```
  cloud.database({objectTypeInfo: schema, zoneName: "QuickStartDemo"}).collection(BookInfo).query().lessThan('price', 50.0).limit(10).get();
  ```

* 构造查询条件，并调用[query()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-harmonyos-ts-databasecollection-0000001626270306#section1894820514118)方法，查询所有价格小于50.0的书籍，并将查询结果按照降序排序，只显示价格排序从第6条开始的10条记录。

  ```
  cloud.database({objectTypeInfo: schema, zoneName: "QuickStartDemo"}).collection(BookInfo).query().lessThan('price', 50.0).orderByDesc('price').limit(10, 6).get();
  ```

#### 删除数据

#### 按对象删除

您可以通过[delete()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-harmonyos-ts-databasecollection-0000001626270306#section11094764018)删除单个对象或者一组对象。删除数据时，云数据库会根据传入对象主键删除相应的数据，不会比对该对象其它属性与存储的数据是否一致。删除一组对象时，删除操作是原子的，即对象列表中的对象要么全部删除成功，要么全部删除失败。

注意事项：

删除一组对象时，该组中的对象必须属于同一个对象类型，否则会导致删除失败。

代码示例：  
将对象删除，如果删除成功，返回删除对象的个数；执行失败，抛出异常。

```
async function delete () {
    try {
      const record = await cloud.database({objectTypeInfo: schema, zoneName: "QuickStartDemo"}).collection(BookInfo).delete({
        "id":2000
      });

      Logger.info(TAG, "delete success, record  = " + record);
    } catch (err) {
      Logger.error(TAG, "delete err------------" + JSON.stringify(err));
    }
}
```

#### 按查询结果删除

您可以通过多个链式过滤条件，来获取满足条件的对象，并进行删除。多个链式条件之间默认用"与"运算。  
构造查询条件，并调用[query()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-harmonyos-ts-databasecollection-0000001626270306#section1894820514118)方法查询"bookName"包含"数据库"，"price"大于20.0并且小于50.0的书籍，同时调用[delete()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-harmonyos-ts-databasezonequery-0000001674750265#section611685012316)方法删除这些数据。

```
cloud.database({objectTypeInfo: schema, zoneName: "QuickStartDemo"}).collection(BookInfo).query().contains('bookName', '数据库').greaterThan('price', 20.0).and().lessThan('price', 50.0).delete();
```
