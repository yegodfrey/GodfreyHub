# 微信

您可以在应用中集成微信认证方式，让您的用户可以使用微信账号进行AppGallery Connect身份验证。

## 前提条件

* 您需要在AGC控制台[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-integration-sdk-0000001326347605)。

## 开发步骤

认证服务提供了两种开发方式接入微信账号：

* 推荐您使用新的统一登录接入方式，请参见[统一登录接入方式](#section1319032633215)。
* 同时为了兼容性保留了老的传统接入方式，请参见[传统接入方式](#section37001861717)。

### 统一登录接入方式

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114611.27661954386533237045967303536113:50001231000000:2800:8A3FE00E904C89A341551A0EA5A9FCB90032336F0AE4B347268EDF8ECCA1C8A7.png "点击放大")

1. 在项目的Podfile中添加微信账号认证API的依赖和微信SDK依赖：

   ```screen
   pod  'AGConnectAPIAuthWeChat'
   pod  'WechatOpenSDK'
   ```

   > 说明
   >
   > 由于华为未提供微信SDK依赖包，您可以使用示例中的Pod方式添加微信SDK依赖，也可以自行至微信开放平台下载最新版本的SDK依赖包进行手动集成。示例中的微信SDK Pod依赖包仅供参考，华为不负责版本更新。
2. 在 Xcode 中，选择您的工程设置项，左侧导航选择"TARGETS"，点击"Info"标签。
   * 在"URL Types"添加"URL Schemes"，参数值为注册的应用程序id。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114611.71899731572666223723858549637995:50001231000000:2800:5F395C38E819326B811C9472CFC914898307E8FCCABF3F5B9F79EB0451B6B22A.png)

   * 在 "LSApplicationQueriesSchemes"添加weixin和weixinULAPI。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114611.69083324038307812281079729245357:50001231000000:2800:A45E4497A8B8A2338243C8561AC16C4FC34FFF73B48D5307B02A309522BFFC6D.png)

3. 在AppDelegate的didFinishLaunchingWithOptions函数中设置微信的AppId与AppSecret到对应接口。

   ```screen
   "Objective-C"
   AGCAuthThirdPartyConfig.instance.weChatAppId = @"XXX";
   AGCAuthThirdPartyConfig.instance.weChatAppSecret = @"XXX";
   ```

   ```screen
   "Swift"
   AGCAuthThirdPartyConfig.instance().weChatAppId = "XXX";
   AGCAuthThirdPartyConfig.instance().weChatAppSecret = "XXX"
   ```

4. 添加生命周期回调，请参见[统一登录调用AppDelegate回调](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-unified-login-0000001275827780)。
5. 调用[[AGCAuth signIn:controller:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346#section1835003573014)方法，登录微信账号。

   ```screen
   "Objective-C"
    [[[[AGCAuth getInstance] signIn:AGCAuthProviderTypeWeiXin controller:self] addOnSuccessCallback:^(AGCSignInResult * _Nullable result) {
       // onSuccess
        AGCUser *user = result.user;
   }] addOnFailureCallback:^(NSError * _Nonnull error) {
        // onFail
   }];
   ```

   ```screen
   "Swift"
   AGCAuth.instance().signIn(provider: .weiXin,controller: self).onSuccess{ (result) in
       // onSuccess
   }.onFailure{ (error) in
       // onFailure
   }
   ```

### 传统接入方式

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114611.29383035128824804231229631401479:50001231000000:2800:4806B0AA3C32F73704A0AD0E62D30BF72DC56DCA49BC929F5BD0D7C84EB1528E.png "点击放大")

1. 在应用的登录界面，初始化[AGCAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346)实例，获取AGC的用户信息，检查是否有已经登录的用户。如果有则可以直接进入用户界面，否则显示登录界面。

   ```screen
   "Objective-C"
   AGCUser *user = [[AGCAuth getInstance] currentUser];
   ```

   ```screen
   "Swift"
   let user = AGCAuth.instance().currentUser
   ```

2. 微信账号登录，并获取微信账号的用户授权信息。 说明
   >
   > 此步骤仅供参考，更详细内容，请参见[微信官方文档](https://open.weixin.qq.com/cgi-bin/showdocument?action=dir_list&t=resource/res_list) 。
   1. 初始化WXAPI。

      ```screen
      "Objective-C"
      [WXApi registerApp:APP_ID universalLink:LINK];
      ```

      ```screen
      "Swift"
      WXApi.registerApp("APP_ID", universalLink: "LINK")
      ```


   2. 发送请求获取微信授权的 code。

      ```screen
      "Objective-C"
      SendAuthReq *req = [[SendAuthReq alloc] init];
      req.scope = @"snsapi_userinfo";
      req.state = @"none";
      [WXApi sendAuthReq:req viewController:self delegate:self completion:^(BOOL success) {

       }];
      ```

      ```screen
      "Swift"
      let req:SendAuthReq = SendAuthReq()
      req.scope = "snsapi_userinfo"
      req.state = "none"
      WXApi.sendAuthReq(req, viewController: controller, delegate: self, completion: nil)
      ```

   3. 在WXApiDelegate的回调- (void)onResp:(BaseResp*)resp中接收授权后的code。

      ```screen
      "Objective-C"
      if ([resp isKindOfClass:[SendAuthResp class]]) {
          SendAuthResp *authResp = (SendAuthResp *)resp;
          NSString *code = authResp.code;
      }
      ```

      ```screen
      "Swift"
      if let authResp = resp as? SendAuthResp {
          let code = authResp.code      
      }
      ```

   4. 在AppDelegate中添加授权确认后的回调。

      ```screen
      "Objective-C"
      - (BOOL)application:(UIApplication *)application continueUserActivity:(NSUserActivity *)userActivity restorationHandler:(void (^)(NSArray<id<UIUserActivityRestoring>> * _Nullable))restorationHandler
         {
           return [WXApi handleOpenUniversalLink:userActivity delegate:delegate];
         }

      - (BOOL)application:(UIApplication *)app openURL:(NSURL *)url options:(NSDictionary<UIApplicationOpenURLOptionsKey,id> *)options {
           return[WeiboSDK handleOpenURL:url delegate:delegate];
         }
      ```

      ```screen
      "Swift"
      func application(_ application: UIApplication, continue userActivity: NSUserActivity, restorationHandler: @escaping ([UIUserActivityRestoring]?) -> Void) -> Bool {
           return WXApi.handleOpenUniversalLink(userActivity, delegate:delegate)
      }

      func application(_ app: UIApplication, open url: URL, options: [UIApplication.OpenURLOptionsKey : Any] = [:]) -> Bool {
           return WXApi.handleOpen(url, delegate:delegate)
      }
      ```


   5. 发送如下请求获取accessToken和openId。

      ```screen
      https://api.weixin.qq.com/sns/oauth2/access_token?appid=APPID&secret=SECRET&code=CODE&grant_type=authorization_code
      ```

3. 调用[[AGCWeiXinAuthProvider credentialWithToken:openId:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcweixinauthprovider-ios-0000001054423681#section477272820713)使用从微信账号获取的accessToken和openId生成credential，并调用[[AGCAuth signIn:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346#section488155612616)实现登录。

   ```screen
   "Objective-C"
   AGCAuthCredential *credential = [AGCWeiXinAuthProvider credentialWithToken:accessToken openId:openid];
   [[[[AGCAuth getInstance] signIn:credential] addOnSuccessCallback:^(AGCSignInResult * _Nullable result) {
        // onSuccess
        AGCUser *user = result.user;
   }] addOnFailureCallback:^(NSError * _Nonnull error) {
        // onFail
   }];
   ```

   ```screen
   "Swift"
   let credential = AGCWeiXinAuthProvider.credential(withToken:accessToken, openId:openid)
   AGCAuth.instance().signIn(credential: credential).onSuccess{ (result) in
       // onSuccess
   }.onFailure{ (error) in
       // onFailure
   }
   ```

## 更多信息

* 您如果想让用户可以使用多个账号登录您的应用，可以将多个[账号进行关联](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-associated-0000001053053982)。
* 当用户不需要使用应用，或者需要切换其他账号登录认证，可以先执行[登出](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-sign-out-0000001053692708)。
* 当用户需要注销当前用户，可以进行[销户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-deleteuser-0000001057460873)。
* 对于销户、修改密码、关联账号以及重置手机账号和邮箱账号等敏感操作，为了提高安全性，需要用户必须在5分钟内登录过才能执行。如果用户执行敏感操作时登录超过5分钟，需要[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-reauthenticate-0000001127283387)后再执行敏感操作。
* 您可以参考[异常处理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-troubleshooting-0000001054715191)实现自己的异常处理机制，从而减少异常情况的发生。
* 您可以使用云函数触发器来接收用户注册、登录、销户等关键事件，从而[扩展认证服务的能力](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-extension-0000001053372708)。
* 您可以参考[管理用户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-user-manage-0000001606051705)对用户进行解锁、停用等操作。
