# 手机

为方便您在Windows系统上对接认证服务，提供了REST API接口，支持您通过API完成手机号码的登录认证场景。  

#### 前提条件

* 您已[创建项目](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-creat-project-and-app-0000001324725529#section61519217307)。
* 您已[开通认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746#section260491731716)，并已[启用手机号码认证方式](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-authentication-method-0000002417916829#section16830152153116)。
* 您已[获取客户端API授权](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-obtain-client-apiauthorization-0000001453744605)。  

#### 开发步骤

#### 注册

1. 调用[验证码申请](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/client-rest-auth-verifycode-0000001294228992)接口，获取验证码。  
   ![](https://media:801773135262611858)  
   当前认证服务暂不支持向中国大陆推送手机验证码/通知短信。如果您项目的"数据处理位置"设置为"中国"且需要向中国大陆推送手机验证码/通知消息，请通过您的云函数或服务器接收验证码并发送短信。详情可参考[启用手机号码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-authentication-method-0000002417916829#section16830152153116)。

   ```
       /**
        * 验证码申请
        *
        * @param token API客户端通过AGC平台鉴权后获得的访问API的鉴权凭据
        * @param clientId 客户端ID     
        * @param productId 项目ID
        * @param action 验证码行为
        * @param sendInterval 发送间隔，短于这个间隔不发送下一条，30s到120s之间
        * @param phoneOrEmail 电子邮箱，与手机号码二选一
        * @return 申请验证码结果
        */
       public static GetVerifyCodeRsp getVerifyCode(String token, String clientId, String productId, Integer action, 
           Integer sendInterval, String phoneOrEmail) throws IOException {
           GetVerifyCodeReq getVerifyCodeReq = new GetVerifyCodeReq();
           // 1001注册登录 1002重置密码
           getVerifyCodeReq.setAction(action);
           getVerifyCodeReq.setLang("zh_CN");
           getVerifyCodeReq.setSendInterval(sendInterval);
           getVerifyCodeReq.setPhone(phoneOrEmail);
   //        getVerifyCodeReq.setEmail("your email");

           HttpClient client = HttpClients.createDefault();

           HttpPost httpPost = new HttpPost("https://connect-drcn.dbankcloud.cn/agc/apigw/oauth2/third/v1/verify-code?productId=" + productId);

           httpPost.setHeader("Accept", "application/json");
           httpPost.setHeader("Content-Type", "application/json;charset=utf-8");
           httpPost.setHeader("client_id", clientId);
           httpPost.setHeader("Authorization", "Bearer " + token);

           httpPost.setEntity(new StringEntity(JSON.toJSONString(getVerifyCodeReq), Charset.forName("UTF-8")));


           HttpResponse response = client.execute(httpPost);;
           return JSON.parseObject(IOUtils.toString(response.getEntity().getContent(), StandardCharsets.UTF_8),
               GetVerifyCodeRsp.class);
       }
   ```

2. 调用[用户注册](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/client-rest-auth-register-0000001346709109)接口，通过手机号码完成账号注册。

   ```
   /**
        * 注册请求
        * 
        * @param token API客户端通过AGC平台鉴权后获得的访问API的鉴权凭据
        * @param clientId 客户端ID     
        * @param productId 项目ID
        * @param phone 手机号，格式：“+国家码-18112345678”
        * @param verifyCode 验证码
        * @param password 密码
        * @return 接口结果
        * @throws IOException 异常
        */
       public static UserSignInRsp userRegister(String token, String clientId, String productId, String phone, 
           String verifyCode, String password) throws IOException {
           RegisterUserReq registerUserReq = new RegisterUserReq();
           registerUserReq.setPhone(phone);
           registerUserReq.setVerifyCode(verifyCode);
           registerUserReq.setPassword(password);

           HttpClient client = HttpClients.createDefault();

           HttpPost httpPost = new HttpPost("https://connect-drcn.dbankcloud.cn/agc/apigw/oauth2/third/v1/user-register?productId=" + productId);

           httpPost.setHeader("Accept", "application/json");
           httpPost.setHeader("Content-Type", "application/json;charset=utf-8");
           httpPost.setHeader("client_id", clientId);
           httpPost.setHeader("Authorization", "Bearer " + token);


           httpPost.setEntity(new StringEntity(JSON.toJSONString(registerUserReq), Charset.forName("UTF-8")));


           HttpResponse response = client.execute(httpPost);
           return JSON.parseObject(IOUtils.toString(response.getEntity().getContent(), StandardCharsets.UTF_8),
               UserSignInRsp.class);
       }
   ```

#### 密码登录

调用[用户密码登录](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/client-rest-auth-signin-0000001294069348)接口，通过"手机账号+密码"的方式完成登录。

```
    /**
     * 登录请求
     * 
     * @param token API客户端通过AGC平台鉴权后获得的访问API的鉴权凭据
     * @param clientId 客户端ID     
     * @param productId 项目ID
     * @param phoneOrEmail 登录手机号或邮箱
     * @return 接口结果
     * @throws IOException 异常
     */
    public static UserSignInRsp userSignInByPassword(String token, String clientId, String productId, String phoneOrEmail)
        throws IOException {
        UserSigninReq userSigninReq =
            new UserSigninReq()
                .tokenSet(phoneOrEmail)
                .providerSet(11)
                .extraDataSet("{\"password\":\"xxxxxxxxx\"}")
                .autoCreateUserSet(0);

        HttpClient client = HttpClients.createDefault();

        HttpPost httpPost = new HttpPost("https://connect-drcn.dbankcloud.cn/agc/apigw/oauth2/third/v1/user-signin?productId=" + productId);

        httpPost.setEntity(new StringEntity(JSON.toJSONString(userSigninReq), Charset.forName("UTF-8")));

        httpPost.setHeader("Accept", "application/json");
        httpPost.setHeader("Content-Type", "application/json;charset=utf-8");
        httpPost.setHeader("client_id", clientId);
        httpPost.setHeader("Authorization", "Bearer " + token);

        HttpResponse response = client.execute(httpPost);
        return JSON.parseObject(IOUtils.toString(response.getEntity().getContent(), StandardCharsets.UTF_8),
            UserSignInRsp.class);
    }
```
