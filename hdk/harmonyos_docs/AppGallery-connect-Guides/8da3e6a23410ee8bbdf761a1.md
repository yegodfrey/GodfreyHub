# 设置应用内默认值

## 获取远程配置对象实例

调用[[AGCRemoteConfig sharedInstance]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ios-remoteconfig-agcremoteconfig-0000001056526293#section161477503147)获取远程配置对象实例用于设置应用内默认参数值。

```screen
"Objective-C"
AGCRemoteConfig *config = [AGCRemoteConfig sharedInstance];
```

```screen
"Swift"
let config = AGCRemoteConfig.sharedInstance()
```

## 设置应用内默认值

您可以在远程配置对象中设置应用程序内的默认值，以便您的应用程序在连接到远程配置服务之前按照预期运行。如果云端未设置参数值，则可以使用本地默认值。 当前支持两种类型的默认值：

* plist资源文件的默认值 在工程的根目录中增加一个远程配置默认值的plist文件，plist配置项type支持String、Number、Boolean类型，例如文件remote_config.plist。

  ```screen
  <plist version="1.0">
      <dict>
   <key>test1</key>
          <string>test1</string>
          <key>test2</key>
          <true/>
          <key>test3</key>
          <integer>123</integer>
      </dict>
  </plist>
  ```

  调用[[AGCRemoteConfig applyDefaultsPlistFile:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ios-remoteconfig-agcremoteconfig-0000001056526293#section61454182228)传入默认值,传入后立即生效。

  ```screen
  "Objective-C"
  [config applyDefaultsPlistFile:@"remote_config"];
  ```

  ```screen
  "Swift"
  config.applyDefaultsPlistFile("remote_config")
  ```

* NSDictionary对象的默认值 可参考如下配置调用[[AGCRemoteConfig applyDefaults:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ios-remoteconfig-agcremoteconfig-0000001056526293#section19277745192410)传入默认值，其中NSDictionary的value值支持NSString、NSNumber类型，如传入其他类型则会忽略。

## 更多信息

您可以在AppGallery Connect[设置新的云端配置项](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-remoteconfig-ios-cloudconfig-0000001242850821)，并根据业务逻辑配置不同的值，然后在应用中所需位置[获取云端配置项](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-remoteconfig-ios-obtainconfig-0000001056481762)，从而灵活更新应用中的信息。
