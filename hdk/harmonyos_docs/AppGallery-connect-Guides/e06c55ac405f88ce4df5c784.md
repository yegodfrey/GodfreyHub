# 典型应用场景

#### 促进应用转化事件

基于用户在应用内的行为触发，有针对性地发送应用内消息，促进用户更新、浏览、订阅、购买等应用内转化行为，例如，通过应用内消息，您可以在用户查看学习情况时发送某个课程的推广消息，提高课程的购买率。

#### 推广应用关键功能

用户使用应用时，向活跃用户发送有针对性的消息来鼓励用户使用应用的关键功能，从而吸引这些用户。例如，通过应用内消息，您可以在用户通过游戏某个关卡时给出关卡的通过与否提示。

#### 发送针对性消息通知

为了和用户保持沟通，您可以利用应用内消息服务向用户发送针对性消息。例如，在新年到来之际发送新年祝福并提供新年礼包，通知用户领取。
