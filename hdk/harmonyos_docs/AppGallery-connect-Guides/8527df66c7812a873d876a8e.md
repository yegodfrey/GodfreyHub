# 添加应用内消息

您需要先在AGC上添加应用内消息，并设置消息的样式、发送目标等，才可以在特定使用情境下向用户发送应用内消息。  

#### 前提条件

已[开通应用内消息服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-appmessaging-enableservice-0000001322456700)。  

#### 创建消息

![](https://media:301784775011804461)  
分配了"管理员"、"APP管理员"、"运营"或"开发"角色的账号才可创建应用内消息。关于账号的角色与权限说明，请参见[角色与权限](https://developer.huawei.com/consumer/cn/doc/app/agc-help-rolepermission-0000001155345429)列表。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击您的项目。
3. 在导航栏选择"增长 \> 应用内消息"，点击"添加应用内消息"。 ![](https://media:301784775012007462)

4. 配置消息名称和消息描述。 ![](https://media:301784775012053463)

<!-- -->

5. 设置消息的样式和内容，包括图片和按钮设置，完成后点击"下一步"。
   1. 在"消息种类"下拉框中选择需要创建的消息类型，然后设置对应的样式和内容。当前支持的消息类型包括：弹框消息、图片消息、Banner消息。  
      ![](https://media:301784775012086464)  
      如需以自定义布局展示该条消息，则应保持"允许自定义布局"为默认勾选状态，否则消息将按照默认布局展示。此功能适用于1.5.0.300及以上版本SDK。

      ![](https://media:301784775012207465)

      各种消息类型支持配置的样式和内容如下表所示。  

      |设置项|弹框消息|图片消息|Banner消息|
      |:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
      |消息标题|支持|无|支持|
      |消息正文|支持|无|支持|
      |消息标题颜色|支持|无|支持|
      |消息正文颜色|支持|无|支持|
      |消息背景颜色|支持|无|支持|
      |图片设置|设置竖屏图片和横屏图片。 竖屏图片宽高比为3:2，横屏图片宽高比为1:1或3:2。图片的长宽不能超过1080px，如果超过，SDK在展示时会进行等比例缩放，例如图片像素为2160\*1440，SDK展示时会缩放为1080\*720。 支持常见的图片格式，如jpg、png、gif等。|设置图片网址。 图片宽高比为3:2，长宽最大值不能超过2000px，如果超过，SDK在展示时会进行等比例缩放，例如图片像素为6000\*4000，SDK展示时会缩放为2000\*1333。 支持常见的图片格式，如jpg、png、gif等。|可选设置横幅图片网址。 图片宽高比为3:2，长宽不能超过1080px，如果超过，SDK在展示时会进行等比例缩放，例如图片像素为2160\*1440，SDK展示时会缩放为1080\*720。 支持常见的图片格式，如jpg、png、gif等。|
      |图片设置|设置方式有以下两种： * 直接填写已有的图片存储地址进行设置。 * 点击"上传"将图片上传至云存储，上传后图片网址将自动填充为图片的存储地址。使用此功能，您需要开通云存储服务，并确保云存储中至少1个存储实例已配置静态CDN加速，详情请参见[结合云托管实现静态CDN加速](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-static-cdn-0000001178262716)。 说明： 云存储和云托管均为收费服务，使用云存储上传图片可能会产生一定费用。请确保不欠费使用服务，否则将会影响图片的正常展示。[云存储定价](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-price-0000001253665999) \| [云托管定价](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudhosting-charge-0000001058890686)|||
      |按钮设置|支持设置按钮文字、文字颜色。 说明： 勾选"增加辅助按钮"，可添加辅助按钮。|无|无|
      |操作设置|点击按钮触发操作： * 关闭消息：用户点击按钮将关闭消息。 * 跳转链接：用户点击按钮将跳转至指定链接，链接设置请参见[步骤b](#ZH-CN_TOPIC_0000001071924650__li819319438475)。 * 分享：用户点击按钮，将生成文本格式的分享内容"消息标题+链接地址"，供用户分享到各大社交平台。链接设置请参见[步骤b](#ZH-CN_TOPIC_0000001071924650__li819319438475)。|点击图片触发操作： * 关闭消息：用户点击图片将关闭消息。 * 跳转链接：用户点击图片将跳转至指定链接，链接设置请参见[步骤b](#ZH-CN_TOPIC_0000001071924650__li819319438475)。 * 分享：用户点击图片，将生成文本格式的分享内容"消息标题+链接地址"，供用户分享到各大社交平台。链接设置请参见[步骤b](#ZH-CN_TOPIC_0000001071924650__li819319438475)。|点击横幅触发操作： * 关闭消息：用户点击横幅将关闭消息。 * 跳转链接：用户点击横幅将跳转至指定链接，链接设置请参见[步骤b](#ZH-CN_TOPIC_0000001071924650__li819319438475)。 * 分享：用户点击横幅，将生成文本格式的分享内容"消息标题+链接地址"，供用户分享到各大社交平台。链接设置请参见[步骤b](#ZH-CN_TOPIC_0000001071924650__li819319438475)。|

   2. 如果触发操作选择"跳转链接"或"分享"，您可以手动输入链接地址，也可直接使用App Linking链接。  
      ![](https://media:301784775012327466)  
      跳转链接地址不允许设置为可执行文件格式。

      ![](https://media:301784775012488467)

      若使用App Linking链接，点击"使用App Linking链接"，在弹窗中选择希望跳转或分享的App Linking链接。点击"确定"后，App Linking链接将被自动填写至URL输入框中。
      * 可选择当前团队内任意项目下的App Linking链接。
      * 支持按链接前缀、链接名称、时间段（最近30天、最近90天、最近180天或所有时间）过滤查询。

6. 设置发送目标，完成后点击"下一步"。
   * 在"应用"栏选择需要发布应用内消息的应用包名。
   * 点击"新增条件"可以灵活设置消息发送的用户，例如应用版本、OS版本、语言、国家地区等。 ![](https://media:301784775012704473)

   |过滤条件|运算符|条件值|说明|
   |:-----|:------------------------|:------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |应用版本|* 包含 * 不包含 * 等于 * 包含正则表达式|输入一个或多个应用版本号（1-64个字符）。|对应应用的VersionName。 当选择的运算符为 "包含"、"不包含"或"等于"时，可以采用以逗号分隔的值列表。 当选择的运算符为"包含正则表达式"时，您需要输入RE2格式的正则表达式。您不仅能够通过正则表达式匹配目标版本字符串的全部文本，还能够利用\^和$定位点来匹配目标字符串的开头、结尾部分或文本的全部。关于如何书写正则表达式，请参考[Syntax](https://github.com/google/re2/wiki/Syntax)。 * 运算符"包含"为模糊匹配，目标值的列表中只要有1个值是实际值的子字符串，则返回True。例如：目标值为"1.0,2.0,3.0"，那么实际值为2.0.1返回True，为4.0.1时返回False。 <!-- --> * 运算符"不包含"指，目标值的列表中没有1个值是实际值的子字符串，则返回True。例如：目标值为"1.0,2.0,3.0"，那么实际值为2.0.1返回False，为4.0.1时返回True。 * 运算符"等于"为完全匹配，目标值的列表中只要有1个值是实际值，则返回True。例如：目标值为"1.0,2.0,3.0"，那么实际值为2.0时返回True， 为4.0时返回False。 * 运算符"包含正则表达式"指，如果目标值（即RE2正则表达式）与实际值匹配，则返回True。|
   |OS版本|* 包含 * 不包含 * 等于 * 包含正则表达式|输入一个或多个操作系统版本号（1-128个字符）。|输入Android或者HarmonyOS版本号。 多个版本号以逗号分隔，且区分大小写，例如"Android 9.0,Android 8.0"，"Android 8.0,HarmonyOS 2.1.0"，"HarmonyOS 2.1.0,HarmonyOS 3.1.0"。 OS版本支持正则表达式匹配，关于如何书写正则表达式，请参考[Syntax](https://github.com/google/re2/wiki/Syntax)。 关于OS版本选择的运算符的具体说明，请参考"[应用版本](#ZH-CN_TOPIC_0000001071924650__zh-cn_topic_0000001072054882_zh-cn_topic_0000001199092457_p89421715163518)"条件的说明。|
   |语言|-|选择一种或多种设备语言。|如果安装了该应用的设备使用的语言是所列语言之一，则此规则的判断结果为True。|
   |国家地区|-|选择设备所在的一个或多个国家或地区。|如果安装了该应用的设备设置的国家/地区是所列出国家/地区之一，则此规则的判断结果为True。|
   |上次应用互动|* 大于 * 小于等于 * 介于|填写上次应用互动距离当前的时间。|* "大于"+天数：上次应用互动的日期大于X天前。 * "小于等于"+天数：上次应用互动的日期小于等于X天前。 * "介于"+天数：上次应用互动的日期介于X至Y天前。|
   |首次打开|* 大于 * 小于等于 * 介于|填写首次打开应用距离当前的时间。|* "大于"+天数：首次打开应用的日期大于X天前。 * "小于等于"+天数：首次打开应用的日期小于等于X天前。 * "介于"+天数：首次打开应用的日期介于X至Y天前。|
   |设备芯片|* 包含 * 不包含 * 等于 * 包含正则表达式|输入一个或多个设备芯片型号（1-1024个字符）。|设备芯片型号，多个芯片型号之间以逗号（,）作分隔符进行分隔，且字母区分大小写，例如"Kirin920,Kirin990"。 说明： 若芯片型号中存在逗号，则无需输入。例如精确匹配设备芯片型号时，Qualcomm Technologies, Inc MSM8998型号的设备芯片，则需配置为Qualcomm Technologies Inc MSM8998。 设备芯片型号支持正则表达式匹配，关于如何书写正则表达式，请参考[Syntax](https://github.com/google/re2/wiki/Syntax)。 关于设备芯片选择的运算符的具体说明，请参考"[应用版本](#ZH-CN_TOPIC_0000001071924650__zh-cn_topic_0000001072054882_zh-cn_topic_0000001199092457_p89421715163518)"条件的说明。 关于设备芯片型号，您可从Android或HarmonyOS设备的/proc/cpuinfo文件最后一行Hardware读取。 ``` CPU variant : 0x3 CPU part : 0xd40 CPU revision : 0 Hardware : vendor Kirin990 ```|

7. 设置发送时间，完成后点击"下一步"。  
   ![](https://media:301784775012749474)
   * 设置消息展示的开始日期和结束日期：您必须设置消息的开始日期和结束日期，从而使用户在该时间段内使用应用时消息能够正常展示。
   * 设定消息的触发事件：消息的展示需要依赖特定的事件触发，例如新闻类的App可以在用户"打开应用"时显示头条新闻，购物类的App可以在用户"购买成功"之后展示配套的销售物品，游戏类App可以在"进入关卡"之前展示关卡的通关指南等，像这种"打开应用"、"购买成功"这种操作我们称之为触发事件。所有消息的展示都需要有相应的事件作为触发条件。 应用内消息支持预置事件触发。

     |事件名称|说明|
     |:--------------|:-------------------------------------------|
     |AppLaunch|应用被启动，指应用在系统后台不存在，点击应用图标启动应用的事件。|
     |AppOnForeground|应用回到前台，指应用在后台存在，重新回到前台的事件（应用切换到后台的时间要超过1秒钟）。|

   * 消息的展示频率和次数：应用内消息服务对消息的展示频率和次数，提供灵活的设置方式。  

     |展示频率|展示次数|说明|
     |:------|:------------------------|:----------------|
     |消息只展示一次|1|这种类型的消息只展示一次。|
     |每X天展示一次|（应用内消息的结束时间-应用内消息的开始时间）/X|每次间隔X天展示一次。|
     |每天展示X次|X\*天数|每天最多展示X次，第二天重复展示。|

8. 在应用内消息信息填写完成后，您可以：
   * 点击右上角的"保存"，完成消息的创建。
* 点击右上角的"发布"，完成消息的发布。
