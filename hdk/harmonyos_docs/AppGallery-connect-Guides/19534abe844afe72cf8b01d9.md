# 下载能力

## 接口描述

主要用于启动下载任务。

## 输入参数

**StartDownloadV2IPCRequest** 结构如下：

|参数名称|参数类型|是否必选|参数说明|
|:--------------|:-----|:---|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|mPackageName|String|必选|启动下载的包名|
|mDownloadParams|String|必选|下载附加参数. 如果App信息是通过AGD Pro API请求获取的，**请确保downloadParam透传，否则影响计费 。**|
|mReferrer|String|否|渠道归因，由调用方设置。|
|mInstallType|String|必选|媒体指定的安装方式，应用市场实际分发时会通过云端校验是否有效。 如果不传将使用默认的安装方式：取值范围请参考[安装方式介绍](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agd_sdk_beta_install-overview-0000001494829901)|

## 返回参数

下载接口返回的状态码，以下几种状态码建议媒体处理以完成下载流程：具体参见 [请求下载返回码](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agd_sdk_beta_return-code-0000001494847697)

## 示例代码

```screen
StartDownloadV2IPCRequest downloadIPCRequest = new StartDownloadV2IPCRequest();
downloadIPCRequest.setReferrer(mReferrer);
downloadIPCRequest.setPackageName(mPackageName);
downloadIPCRequest.setDownloadParams(mDownloadParams);
downloadIPCRequest.setInstallType(mInstallType);

PendingResult<StartDownloadV2IPCRequest, TaskOperationResponse> pendingResult =
AgdApi.startDownloadTaskV2(client, downloadIPCRequest);

pendingResult.setResultCallback(new ResultCallback<TaskOperationResponse>() {
@Override
public void onResult(Status<TaskOperationResponse> result) {
  // 需要拉起应用市场界面时使用，例如：（statuscode=2）需要引导更新华为应用市场，（statuscode=15）应用市场未同意协议，
  if (ApiStatusCodes.PROTOCOL_ERROR == result.getStatusCode()) {
      try {
          result.startResolutionForResult(this, ApiStatusCodes.PROTOCOL_ERROR);
       } catch (IntentSender.SendIntentException e) {
         Log.i(TAG, "startResolutionForResult failed");
       }
   }
  // statusCode=6 通过打开PendingIntent打开AG页面：包括 流量弹框、协议框、迷你页、全屏详情页
  if(ApiStatusCodes.RESOLUTION_REQUIRED == result.getStatusCode()) {
	try {
		result.startResolutionForResult(this, ApiStatusCodes.RESOLUTION_REQUIRED );
	} catch (IntentSender.SendIntentException e) {
		e.printStackTrace();
	}
  }
 }
});
```

## 后续操作

在onActivityResult中做操作，如果同意协议，再调用一次需调用的接口

```screen
public void onActivityResult(int requestCode, int resultCode, @Nullable Intent data) {
   super.onActivityResult(requestCode, resultCode, data);
   if (ApiStatusCodes.PROTOCOL_ERROR == requestCode) {
      if (ProtocolStatus.RESULTCODE_AGREE_PROTOCOL == resultCode) {
      // 同意应用市场协议
      AgdApi.startDownloadTaskV2(client, downloadIPCRequest);
    } else if (ProtocolStatus.RESULTCODE_NOT_AGREE_PROTOCOL == resultCode) {
      // 不同意应用市场协议
    }
 } else if (REQUEST_INSTALL_HIAPP == requestCode) {
      Log.i(TAG, "install hiapp resultCode:" + resultCode);
        if (resultCode == Activity.RESULT_OK) {
        // 安装成功，重新绑定服务
         client.connect();
       }
   }
}
```
