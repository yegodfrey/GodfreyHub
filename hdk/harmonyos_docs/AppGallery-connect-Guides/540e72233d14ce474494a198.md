# Google

您可以在应用中集成Google认证方式，让您的用户可以使用自己的Google账号进行AppGallery Connect身份验证。
> 说明
>
> Google三方认证方式仅在海外站点支持，当您选择数据处理位置为德国、新加坡或俄罗斯时可以使用此认证方式。

## 前提条件

* 您需要在AGC控制台[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-integration-sdk-0000001326347605)。

## 开发步骤

认证服务提供了两种开发方式接入Google账号：

* 推荐您使用新的统一登录接入方式，请参见[统一登录接入方式](#section103212337811)。
* 同时为了保证兼容性保留了老的传统接入方式，请参见[传统接入方式](#section16952720551)。

### 统一登录接入方式

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114617.64707767231689306732238173897834:50001231000000:2800:069C85002E20A2F2AFC602A73F629A475E6C8A5C7D08C941C0415CA517594120.png "点击放大")

1. 在项目的podfile中添加Google账号认证API的依赖和Google SDK依赖：

   ```screen
   pod  'AGConnectAPIAuthGoogle'
   pod  'GoogleSignIn'
   ```

   > 说明
   >
   > 由于华为未提供Google SDK依赖包，您可以使用示例中的Pod方式添加Google SDK依赖，也可以自行至Google开放平台下载最新版本的SDK依赖包进行手动集成。示例中的Google SDK Pod依赖包仅供参考，华为不负责版本更新。
2. 设置Google的ClientId。 说明
   >
   > ClientId参考[启用认证方式](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-authentication-method-0000002417916829#section1871913499476)中配置的"客户端ID"。

   ```screen
   "Objective-C"
   [AGCAuthThirdPartyConfig instance].googleClientId = @"YOUR_CLIENT_ID";
   ```

   ```screen
   "Swift"
   AGCAuthThirdPartyConfig instance().googleClientId = "YOUR_CLIENT_ID";
   ```

3. 添加生命周期回调，请参见[统一登录调用AppDelegate回调](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-unified-login-0000001275827780)。
4. 调用[[AGCAuth signIn:controller:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346#section1835003573014)方法，登录Google账号。

   ```screen
   "Objective-C"
    [[[[AGCAuth getInstance] signIn:AGCAuthProviderTypeGoogle controller:self] addOnSuccessCallback:^(AGCSignInResult * _Nullable result) {
            // onSuccess
            AGCUser *user = result.user;
        }] addOnFailureCallback:^(NSError * _Nonnull error) {
            // onFail
        }];
   ```

   ```screen
   "Swift"
   AGCAuth.instance().signIn(provider: .google,controller: self).onSuccess{ (result) in
       // onSuccess
   }.onFailure{ (error) in
       // onFailure
   }
   ```

### 传统接入方式

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114617.73297621285612822449772073644485:50001231000000:2800:57BBEE46DD3FE98AF8068B91A56A776EBF267A5E7EEDD5929B273FC6D2C1EE19.png "点击放大")

1. 在应用的登录界面，初始化[AGCAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346)实例，获取AGC的用户信息，检查是否有已经登录的用户。如果有则可以直接进入用户界面，否则显示登录界面。

   ```screen
   "Objective-C"
   AGCUser *user = [[AGCAuth getInstance] currentUser];
   ```

   ```screen
   "Swift"
   let user = AGCAuth.instance().currentUser
   ```

2. Google账号登录，并获取Google账号的用户授权信息。 说明
   >
   > 此步骤仅供参考，更详细内容，请参见[Google官方文档](https://developers.google.com/identity/sign-in/ios)。
   1. 在AppDelegate中添加如下代码。

      ```screen
      "Objective-C"
      - (BOOL)application:(UIApplication *)application didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {
         [GIDSignIn sharedInstance].clientID = @"YOUR_CLIENT_ID";
         [GIDSignIn sharedInstance].delegate = self;  // If AppDelegate conforms to GIDSignInDelegate
         return YES;
      }

      - (BOOL)application:(UIApplication *)app openURL:(NSURL *)url options:(NSDictionary<UIApplicationOpenURLOptionsKey,id> *)options {
          return[[GIDSignIn sharedInstance] handleURL:url];
      }
      ```

      ```screen
      "Swift"
      func application(_ application: UIApplication, didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?) -> Bool {
           GIDSignIn.sharedInstance()?.clientID = "GOOGLE_CLIENT_ID"
           GIDSignIn.sharedInstance()?.delegate = self
           return true
      }

      func application(_ app: UIApplication, open url: URL, options: [UIApplication.OpenURLOptionsKey : Any] = [:]) -> Bool {
           return GIDSignIn.sharedInstance()?.handle(url) ?? false
      }
      ```


   2. 在ViewController中添加如下代码。

      ```screen
      "Objective-C"
      - (void)viewDidLoad {
          [super viewDidLoad];
          [GIDSignIn sharedInstance].presentingViewController = self;
      }
      ```

      ```screen
      "Swift"
      GIDSignIn.sharedInstance()?.presentingViewController = self
      ```


   3. 调用Google登录接口。

      ```screen
      "Objective-C"
      [[GIDSignIn sharedInstance] signIn];
      ```

      ```screen
      "Swift"
      GIDSignIn.sharedInstance()?.signIn()
      ```

   4. 添加授权确认后的回调。

      ```screen
      "Objective-C"
      - (void)signIn:(GIDSignIn *)signIn didSignInForUser:(GIDGoogleUser *)user withError:(NSError *)error {
          NSString *idToken = user.authentication.idToken;
      }
      ```

      ```screen
      "Swift"
      func sign(_ signIn: GIDSignIn!, didSignInFor user: GIDGoogleUser!, withError error: Error!) {
           let idToken =user.authentication.idToken
      }
      ```

3. 调用[[AGCGoogleAuthProvider credentialWithToken:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcgoogleauthprovider-ios-0000001054183660#section48665442719)使用从Google账号获取的idToken生成credential，并调用[[AGCAuth signIn:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346#section488155612616)实现登录。

   ```screen
   "Objective-C"
   AGCAuthCredential *credential = [AGCGoogleAuthProvider credentialWithToken:idToken];
   [[[[AGCAuth getInstance] signIn:credential] addOnSuccessCallback:^(AGCSignInResult * _Nullable result) {
       // onSuccess
       AGCUser *user = result.user;
   }] addOnFailureCallback:^(NSError * _Nonnull error) {
       // onFail
   }];
   ```

   ```screen
   "Swift"
   let credential = AGCGoogleAuthProvider.credential(withToken:idToken)
   AGCAuth.instance().signIn(credential: credential).onSuccess{ (result) in
       // onSuccess
   }.onFailure{ (error) in
       // onFailure
   }
   ```

## 更多信息

* 您如果想让用户可以使用多个账号登录您的应用，可以将多个[账号进行关联](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-associated-0000001053053982)。
* 当用户不需要使用应用，或者需要切换其他账号登录认证，可以先执行[登出](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-sign-out-0000001053692708)。
* 当用户需要注销当前用户，可以进行[销户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-deleteuser-0000001057460873)。
* 对于销户、修改密码、关联账号以及重置手机账号和邮箱账号等敏感操作，为了提高安全性，需要用户必须在5分钟内登录过才能执行。如果用户执行敏感操作时登录超过5分钟，需要[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-reauthenticate-0000001127283387)后再执行敏感操作。
* 您可以参考[异常处理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-troubleshooting-0000001054715191)实现自己的异常处理机制，从而减少异常情况的发生。
* 您可以使用云函数触发器来接收用户注册、登录、销户等关键事件，从而[扩展认证服务的能力](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-extension-0000001053372708)。
* 您可以参考[管理用户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-user-manage-0000001606051705)对用户进行解锁、停用等操作。
