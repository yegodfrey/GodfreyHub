# Web CLI命令

本章节主要介绍Web CLI工具支持的命令列表。
> 说明
>
> * 当前在Web CLI下所有命令参数暂不支持中文，且key和value不支持空格。命令行最多字符数不能超过4096。
> * 当value值为空时，执行get命令返回nil。
> * 各个命令的详细语法请前往[Redis官方网站](https://redis.io/commands)查看。
