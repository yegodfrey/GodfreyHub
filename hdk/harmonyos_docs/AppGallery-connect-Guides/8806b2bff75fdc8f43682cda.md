# 申请删除应用签名密钥

应用签名密钥上传后，您还可以申请删除应用签名密钥。删除应用签名密钥后，您可以在应用签名服务页面重新选择使用应用签名服务。
> 注意
>
> 删除签名密钥后，您的上传密钥也一并被删除。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击首页左下角"互动中心待办"的"更多"，或者右上角的![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e2/v3/oaDHyIXxRDasKQZbfdCQIg/zh-cn_image_0000002552231993.png?HW-CC-KV=V1&HW-CC-Date=20260909T134641Z&HW-CC-Expire=31536000000&HW-CC-Sign=8C3D69D7F3E6BE7EF11DE4510190F96FB4E45F26328BDE561644834038B00859)，进入互动中心。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f5/v3/ZfHu0hzaQd2NA3m2hqhxsQ/zh-cn_image_0000002521152036.png?HW-CC-KV=V1&HW-CC-Date=20260909T134641Z&HW-CC-Expire=31536000000&HW-CC-Sign=974F315CECE475EE4700C85CDACEABBDB7800F2F5FE2C462C5167C83DBF7F462 "点击放大")


2. 在互动中心页面，点击右侧"申诉反馈"，从下拉菜单中选择"申诉"，进入"新建申诉"页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/47/v3/ah-XAQWnQJSq00HRbCpLQA/zh-cn_image_0000002521311504.png?HW-CC-KV=V1&HW-CC-Date=20260909T134641Z&HW-CC-Expire=31536000000&HW-CC-Sign=6D6862AB71AA7715F93ABB598A1C9EF765DEAD0751D2180EB06A43EC2E9936F9)

3. 填写申诉信息，点击"提交"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9d/v3/vvf-G_35SXGANZLbtwFclg/zh-cn_image_0000002473900276.png?HW-CC-KV=V1&HW-CC-Date=20260909T134641Z&HW-CC-Expire=31536000000&HW-CC-Sign=EAC1E304F431DF5A72B0073095F4468CE07519AB99383FC8A97369BC0831C9E8)

   |参数|说明|
   |:---|:----------------------------------------------------------------------------------------------------------------|
   |申诉类型|选择"应用签名申请删除"。|
   |应用|选择需要删除应用签名的应用。|
   |标题|请用一句话描述申诉场景。|
   |内容|根据界面提示，填写申请删除的原因。 举例："申请删除XX应用的应用签名密钥，原因是签名密钥上传错误。详情请见附件。"|
   |上传附件|点击"修改应用签名密钥函模板"，在下载的模板中按照实际情况填写信息并盖章或签字，然后点击"选择文件"上传填写好的模板。 您还可以上传其他附件，最多上传5个附件，每个附件不超过100MB，格式支持文本、表格、图片、视频、压缩包。|

申诉成功提交后，华为运营人员将在一个工作日内处理。删除成功后，您将收到互动中心的通知消息。
