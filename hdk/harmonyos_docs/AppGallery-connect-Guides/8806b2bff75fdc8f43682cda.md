# 申请删除应用签名密钥

应用签名密钥上传后，您还可以申请删除应用签名密钥。删除应用签名密钥后，您可以在应用签名服务页面重新选择使用应用签名服务。  
![](https://media:801773108242270975)  
删除签名密钥后，您的上传密钥也一并被删除。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击首页左下角"互动中心待办"的"更多"，或者右上角的![](https://media:801773108242297976)，进入互动中心。

   ![](https://media:801773108242546977 "点击放大")

<!-- -->

2. 在互动中心页面，点击右侧"申诉反馈"，从下拉菜单中选择"申诉"，进入"新建申诉"页面。 ![](https://media:801773108242585978)

3. 填写申诉信息，点击"提交"。 ![](https://media:801773108242626979)

   |参数|说明|
   |:---|:----------------------------------------------------------------------------------------------------------------|
   |申诉类型|选择"应用签名申请删除"。|
   |应用|选择需要删除应用签名的应用。|
   |标题|请用一句话描述申诉场景。|
   |内容|根据界面提示，填写申请删除的原因。 举例："申请删除XX应用的应用签名密钥，原因是签名密钥上传错误。详情请见附件。"|
   |上传附件|点击"修改应用签名密钥函模板"，在下载的模板中按照实际情况填写信息并盖章或签字，然后点击"选择文件"上传填写好的模板。 您还可以上传其他附件，最多上传5个附件，每个附件不超过100MB，格式支持文本、表格、图片、视频、压缩包。|

申诉成功提交后，华为运营人员将在一个工作日内处理。删除成功后，您将收到互动中心的通知消息。
