# 业务介绍

联运服务是指华为和开发者在华为应用市场联合运营应用，并进行分成的合作服务。华为向您提供华为应用市场平台能力接入、数据报表、活动运营、用户运营等一系列服务，您可以借此获取多种优质华为应用市场推荐资源。

联运合作的详细流程请参见[联运服务介绍](https://developer.huawei.com/consumer/cn/doc/distribution/promotion/service-introduction-0000001062607577)。本文档仅介绍您开始接入联运服务时的相关开发工作。  

#### 主要功能

|主要功能|功能描述|
|:---|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|应用联运|应用联运是指您与华为进行联运合作后开发的非游戏类应用，应用联运相关的接入要求请参见[联运应用开发](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/appgallerykit-devguide-0000001055436887)。|
|游戏联运|游戏联运是指您与华为进行联运合作后开发的游戏类应用，游戏联运相关的接入要求请参见[联运游戏开发](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/appgallerykit-devguide-game-0000001055156905)。|

#### 工作原理

联运服务通过接入[HMS Core](https://developer.huawei.com/consumer/cn/hms)的能力来实现联运，涉及的服务如下：

* 华为账号服务：全球华为用户有数亿规模，将华为账号服务集成到您的应用中，您的应用可以方便、安全、快速地使用华为账号登录，从而迅速推广应用提升流水，共享华为庞大的用户价值。华为账号业务详细介绍可参见[华为账号业务介绍](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/introduction-0000001050048870)。
* 应用内支付服务：使用应用内支付，您可以为用户提供方便、安全的支付，支持多种支付方式。HUAWEI IAP当前已经覆盖全球170多个国家和地区，不久将会覆盖全球绝大部分国家和地区。华为应用内支付的详细业务介绍可参见[应用内支付业务介绍](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/introduction-0000001050033062)。
* 游戏服务：华为游戏服务提供了公告展示、游戏浮标等基本能力，您可以快速、低成本的构建游戏。
* 华为分析服务：您可以在应用启动后初始化华为分析服务，用于采集系统级事件和基于Activity的页面事件，您可根据采集的数据进行报表分析和用户分析。
* 应用升级：您可以使用AppGallery静默安装能力，方便、快捷、及时的在应用内提示升级。
* 其他服务：HMS Core的其他服务为可选接入，您可根据实际需求接入。  

#### 实现流程

|序号|步骤|详情|
|:-|:-----|:-------------------------------------------------------------|
|1|创建应用|开始开发应用前，您需要在AppGallery Connect创建您的应用，并进行相关配置，如签名证书指纹、应用内商品信息等。|
|2|集成SDK|开发相关能力前，您需要集成HMS Core相关服务的SDK。|
|3|应用功能开发|应用开发过程中，部分功能需要按照联运服务的要求开发。|
|4|测试与上架|应用开发完成后，您需要进行应用测试并完成上架前自检，完成后可在AppGallery Connect发布您的应用。|
