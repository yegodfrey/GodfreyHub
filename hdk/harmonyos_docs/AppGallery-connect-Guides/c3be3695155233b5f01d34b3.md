# 使用入门

## 创建Android项目

使用Android Studio创建包含动态特性模块的Android项目，并完成动态特性模块的开发，本操作为通用Android技术，开发者可自行完成。

## 创建应用

如果您还没有在AppGallery Connect中创建您的应用，请先参考[创建应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createapp-0000001146718717)创建并上传应用的软件包。

* "软件包类型"：必须选择"APK(Android应用)"。
* "支持设备"：必须选择"手机"。
* "应用分类"：根据实际情况选择"应用"或"游戏"。

## 集成Dynamic Ability SDK

1. 在项目级 gradle 文件（通常在项目根目录）中的allprojects ->repositories里面配置SDK的maven仓地址。

   ```screen
   allprojects{
       repositories{
           maven {url 'https://developer.huawei.com/repo/'}
           ...
       }
   }
   ```


2. 在应用级 gradle 文件中（通常在 app/build.gradle）添加如下代码集成Dynamic Ability SDK。

   ```screen
   dependencies {
       implementation 'com.huawei.hms:dynamicability:1.0.20.300'
       ...
   }
   ```
