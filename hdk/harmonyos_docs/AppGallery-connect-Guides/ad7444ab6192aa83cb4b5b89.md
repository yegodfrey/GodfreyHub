# 使用限制

|限制项|限制|
|:--------------|:------------------------------------------------------------------------------------------|
|主题调试支持的设备版本|仅华为的Android手机和平板真机设备。|
|地理位置设置|当前仅支持深圳区域的华为Android 10手机和平板真机设备。|
|播放调试设备声音|1. 当前音频播放功能仅支持深圳区域的华为Android 10真机设备。 2. Android 10及以上版本设备播放音频的应用必须使用Android SDK 29及以上的版本构建。|
|截屏操作|当前仅支持Android 10及以上版本、HarmonyOS 2.0.0及以上版本的所有真机设备（大屏设备除外）|
|录屏操作|当前仅支持深圳区域的华为Android 10手机真机设备。|
|剪贴板功能|当前除北京区域之外的手机真机设备均支持剪贴板功能。|
|文件管理|当前仅支持深圳区域的部分手机真机设备（在调试界面显示"文件管理"页签时才可使用）。|
|应用安装完成后是否支持自动打开|只有快应用安装完成后支持自动打开，其他应用安装完成后需手动打开。|
|支持同时调试的设备数|每次调试仅可申请1台设备，同一账号最多同时占用2台设备。|
|rpk应用调试|当前不支持第三方品牌设备，仅支持手机或平板真机设备。|
|调试设备权限修改|当前暂不支持修改调试设备高危权限相关的系统设置，即不支持进入"设置"界面修改配置。|
