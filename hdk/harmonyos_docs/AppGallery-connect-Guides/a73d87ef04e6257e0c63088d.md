# 管理环境

您可以为站点创建多个环境，便于您在不同的沙箱环境中进行测试，也可以删除不需要的环境。

* 通过AGC控制台管理环境：在AGC界面中以可视化的方式实现[创建环境](#section13633624104313)和[删除环境](#section55511334108)。
* 通过[API管理环境](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-cloudhost-createnvir-0000001216965720)。

#### 创建环境

云托管服务会为您的站点自动创建一个默认环境（default），您也可以自行创建多个环境。环境创建成功后，您可以在沙箱发布时选择将您创建的版本发布到多个沙箱环境中，便于您在不同的环境中同时进行测试操作。

1. 在站点管理页面，点击"操作"列的"环境管理"，进入环境管理页面。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030114804.74076738409256967592948914078995:50001231000000:2800:B91EAD69B398EEF66E9D75252B064EDAE5FF10710BC2C5F666FD6F924F7E4317.png)

2. 点击"创建环境"。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030114804.36448316342301625655759537495045:50001231000000:2800:41BB03C8FBA56C8340A33036FC2AC3FEA0EC4A269A799A3693CB7226D60B7378.png)  
   包括default环境在内，环境总数不得超过十个。

4. 您可以参考[沙箱发布](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudhosting-creatversion-0000001058732524#section18750133719102)将您的版本发布至您创建的环境中。  

#### 删除环境

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030114804.85622714316802844756425479229694:50001231000000:2800:F1150EAE22DC3E926B1101785C50A6D98E689E21BC4E7B23B4F919277C3F24F7.png)  
您无法删除"default"默认环境。

1. 在站点管理页面，点击"操作"列的"环境管理"，进入环境管理页面。
2. 点击"操作"列的"删除"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030114804.03836453271791236448025853108606:50001231000000:2800:4AC87AF5D1B5E0D20EA743B3B19263F94682DA2847B1329B69021B232E066327.png)

3. 在弹出框中确认并输入待删除的环境ID后，点击"确定"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030114804.60362757463504344575486399483357:50001231000000:2800:CBEA448702D9F081384C647418A0536036AE2E74D29C89190CF2807B07F623D6.png)
