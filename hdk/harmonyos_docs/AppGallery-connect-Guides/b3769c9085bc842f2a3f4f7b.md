# 配置应用信息

在AppGallery Connect中创建的应用有很多基本信息默认为空，本章节重点介绍如何通过Publishing API将应用信息补充完整。

## 前提条件

* 您已在AppGallery Connect手动创建应用并获取应用ID。
* 调用Publishing API前请确认已经完成[使用入门](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114)中的服务端授权。

## 获取应用ID

应用ID是在创建应用后由AppGallery Connect分配的应用唯一标识，在使用Publishing API查询或更新应用信息时，都需要传入应用ID。如果您不知道应用ID，可以直接参见[查看应用基本信息](https://developer.huawei.com/consumer/cn/doc/app/agc-help-appinfo-0000001100014694)在AppGallery Connect控制台中查询。如果您已经在AppGallery Connect中配置应用包名，还可以调用[查询包名对应的appid](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-appid-list-0000001111845086)接口来获取应用ID，支持一次查询多个。

## 更新语言描述信息

如果您的应用包含多个语种，您需要为每个语种设置对应的应用描述信息，包括应用详细描述、应用一句话简介、新版本简介等。此时您可以调用[更新语言描述信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-language-info-update-0000001158245057)接口来完成配置。本接口中您可以指定更新语言描述信息的语种，如果当前语种不存在，则会新增对应的语言描述信息。

如果某个语言描述信息设置错误或后续无需该语言，可调用[删除语言描述信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-language-info-delete-0000001111845088)接口删除。

## 更新应用基本信息

您可以使用[更新应用基本信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-info-update-0000001111685198)接口（PUT方式）进行应用基础信息的更新，例如应用的分类、应用支持的设备、应用的分发地区等等。

```screen
public static void updateAppInfo(String domain, String clientId, String token, String appId) {
	HttpPut put = new HttpPut(domain + "/publish/v2/app-info?appId=" + appId);

	put.setHeader("Authorization", "Bearer " + token);
	put.setHeader("client_id", clientId);

	JSONObject keyString = new JSONObject();

	//Request Body
	keyString.put("defaultLang", "zh-CN");
	keyString.put("isFree", 0);
        keyString.put("price","{\"CN\":\"12\"}");
        keyString.put("priceDetail","[{\"country\":\"CN\",\"currency\":\"CNY\",\"price\":100}]);
	keyString.put("childType", 15);
	keyString.put("grandChildType", 10043);
	//...

	StringEntity entity = new StringEntity(keyString.toString(), Charset.forName("UTF-8"));
	entity.setContentEncoding("UTF-8");
	entity.setContentType("application/json");
	put.setEntity(entity);

	try {
		CloseableHttpClient httpClient = HttpClients.createDefault();
		CloseableHttpResponse httpResponse = httpClient.execute(put);
		int statusCode = httpResponse.getStatusLine().getStatusCode();
		if (statusCode == HttpStatus.SC_OK) {
			BufferedReader br =
				new BufferedReader(new InputStreamReader(httpResponse.getEntity().getContent(), Consts.UTF_8));
			String result = br.readLine();

			JSONObject object = JSON.parseObject(result);
			System.out.println(object.get("ret"));
		}
	} catch (Exception e) {
		System.out.println(e);
	}

}
```

## 修改内容分级

在使用Publishing API发布应用之前，您必须设置应用的内容分级。应用的内容分级当前无法通过Publishing API完成，您必须在AppGallery Connect网站中手动配置。

1. 登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"APP与元服务"。
2. 点击对应应用的应用名称进入应用开发页面。
3. 选择"分发"页签，在左侧导航栏选择"应用上架 > 准备提交"。

## 查询应用信息

在更新应用信息后，您可以使用[查询应用信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-info-query-0000001158365045)（GET方式）接口查询应用的详细信息，以确认应用信息是否修改成功。

```screen
public static void getAppInfo(String domain, String clientId, String token, String appId, String lang) {
     HttpGet get = newHttpGet(domain + "/publish/v2/app-info?appid="+ appId + "&lang="+ lang);
     get.setHeader("Authorization", "Bearer "+ token);
     get.setHeader("client_id", clientId);
     try{
         CloseableHttpClient httpClient = HttpClients.createDefault();
         CloseableHttpResponse httpResponse = httpClient.execute(get);
         intstatusCode = httpResponse.getStatusLine().getStatusCode();
         if(statusCode == HttpStatus.SC_OK) {
             BufferedReader br =
                     newBufferedReader(newInputStreamReader(httpResponse.getEntity().getContent(), Consts.UTF_8));
             String result = br.readLine();

             // 查询应用返回对象，可以参考接口文档使用AppInfo对象接收
             JSONObject object = JSON.parseObject(result);
             System.out.println(object.get("ret"));
         }
     } catch(Exception e) {
     }
 }
```
