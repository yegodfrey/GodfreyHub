# iOS

调用相关接口需要先完成初始化，初始化是通过创建实例来实现的。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250424164754.37174100895105080857921158180688:50001231000000:2800:8DC739C524929C2B7230B7080C19307228BB0E4ECFFF0A619587145DDBBC3279.png)  
游戏多媒体服务语音相关功能需使用麦克风访问权限，因此，您需要申请设备的录音权限，具体请参见[打包](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-export-csharp-0000001413242206#ZH-CN_TOPIC_0000001413242206__li794811152019)。  

#### 前提条件

* 您已[开通游戏多媒体服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-enable-0000001327201553)。
* 您已[集成游戏多媒体SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-integratingsdk-ios-0000001323104597)。  

#### 创建实例

在实现游戏多媒体相关功能前，需先完成游戏多媒体实例的创建。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250424164754.46769468741710054603923356264628:50001231000000:2800:6C5DE0AB856D7F8D43AE83D75BC57E8FF95D2668D0D5DFFE30DF51A5B90CF6F4.png)  
游戏启动后，仅需要维护一个实例即可。

1. 导入头文件。

   ```
   #import <HWPGMEKit/HWPGMEngine.h>
   ```

2. 构造游戏多媒体实例参数。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250424164754.74746730913791458753578960420768:50001231000000:2800:F15E4768026FAF7FD9A82888BBE68BEBB761F1A07D2B58FB05265DAF4BF74A8E.png)  
   * 为了提升服务的安全性，初始化SDK时，您还可以通过在您的服务器中计算出签名的方式进行安全加固，增强数据防篡改能力，具体请参见[使用签名初始化SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-signature-ios-0000001544236688)。如果您已[开启安全加固](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-console-servicemanagement-0000001255134391#section92517364165)，则必须使用签名初始化SDK。
   * 鉴权时传入"clientSecret"和"cpAccessToken"其一即可。基于安全考虑，当您有自己的游戏服务器时，推荐您使用cpAccessToken。如果同时传入，将使用传入的"cpAccessToken"作为最终AGC接入凭证。"cpAccessToken"主要是通过在您的服务器中编写一段调用获取Token接口的代码进行获取，具体请参见[获取Token（项目级）](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/obtaintoken-0000001550601918)。

   ```
   EngineCreateParams *engineParam = [[EngineCreateParams alloc]init];   
   engineParam.openId = openId;               // 玩家ID，必选
   engineParam.logEnable = logEnable;         // 开启SDK日志记录
   engineParam.logPath = logPath;             // 日志路径
   engineParam.logSize = logSize;             // 日志存储大小
   engineParam.agcAppId = agcAppId;           // 游戏应用在AGC上注册的APP ID,具体获取请参见准备游戏信息
   engineParam.clientId = clientId;           // 客户端ID,具体获取请参见准备游戏信息
   engineParam.clientSecret = clientSecret;   // 客户端ID对应的密钥,具体获取请参见准备游戏信息
   engineParam.cpAccessToken = cpAccessToken; // AGC接入凭证（推荐）
   engineParam.apiKey = apiKey;               // API密钥（凭据）,仅实现语音转文本功能时需要,具体获取请参见准备游戏信息
   ```

3. 调用[\[HWPGMEngine create\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section783455411308)方法创建游戏多媒体实例。

   ```
   SelfHWPGMEngineDelegate *engineDelegate = [[SelfHWPGMEngineDelegate alloc]init]; // HWPGMEngineDelegate回调实现
   ...
   [HWPGMEngine create:engineParam engineDelegate:engineDelegate];
   ```

4. 当创建实例完成后，可在HWPGMEngineDelegate接口的[onCreate](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section0634183312285)方法中查看结果并实现回调处理。

   ```
   - (void)onCreate:(int)code msg:(NSString *)msg {
       // 可根据需求将数据进行处理
   }
   ```

#### 销毁实例

如需退出游戏应用，建议先完成实例销毁，减少内存资源的占用。

1. 调用[HWPGMEngine.getInstance destroy](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section119714409324)方法销毁游戏多媒体实例。

   ```
   ...
   HWPGMEngine *pgmeEngine = [HWPGMEngine getInstance];
   [pgmeEngine destroy];
   ```

2. 当销毁实例完成后，可在HWPGMEngineDelegate接口的[onDestory](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section23197403711)方法查看结果并实现回调处理。

   ```
   ...
   - (void)onDestory:(int)code msg:(NSString *)msg {
       // 可根据需求将数据进行处理
   }
   ```
