# 密钥生成

* 生成安全随机数：可用作对称加密算法（如 AES\\SM4）的密钥、IV等。
* 生成RSA3072位加密/签名的公私钥对：RSA3072是安全的密钥长度，可用于RSA签名验签及RSA非对称加密和解密。
* 生成ECC256签名的公私钥对：可用于ECDSA签名验签。

详情请参见API参考文档"[密钥生成](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/key-generation-0000002021924181)"。
