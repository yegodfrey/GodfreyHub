# 获取SDK配置信息

#### Android

#### 获取agconnect-services.json文件

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择您的应用。
3. 在"项目设置"的"常规"页面，下载agconnect-services.json文件。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260123144608.35715226859523147761845975340123:50001231000000:2800:B9DB2F917F5E6DD3CD1A9FD49F56ADAA0BFCF42BAA768030FDE42EF536BCD30F.png)  
   配置文件中默认会包含AGC为应用分配的客户端密钥和API密钥信息，您可以在下载JSON文件前打开"不包含密钥"开关，配置文件中将不包含密钥信息，由您自行调用AGC SDK的接口手动配置。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260123144608.57227624980576222535299936667544:50001231000000:2800:5100988A9515CF71AF60BB0E4663026274D542FBC24695373FDA7BFD6E2D0AB8.png)  

#### iOS

#### 获取agconnect-services.plist文件

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择您的iOS应用。
3. 在"项目设置"页面下载配置文件"agconnect-services.plist"。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260123144608.53019185408775845461179225062712:50001231000000:2800:F2503B08AFCE9D5E0A226DDE11223801218E4B8F426A83A41D3B8F0236FCBF1E.png)  
   * 配置文件中默认会包含AGC为应用分配的客户端密钥和API密钥信息，您可以在下载agconnect-services.plist文件前打开"不包含密钥"开关，配置文件中将不包含密钥信息，由您自行调用AGC SDK的接口手动配置。
   * Safari浏览器当前不支持下载"agconnect-services.plist"文件，请使用Chrome浏览器。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260123144609.73165226769522031655826236243879:50001231000000:2800:B5EC7D173577EB6C66BDD9C48D051DED5CBB31DFF3CABEDBF9AF65CDD9975427.png)  

#### Web

#### 获取Web应用配置信息

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择您的应用。
3. 在"项目设置"的"常规"页面，配置网站限制。

   当您的Web应用需要限制仅指定网站或IP地址才可访问已开通的API时，您可点击"网站限制"后的![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260123144609.98268046313409180839377591672590:50001231000000:2800:3FE043F706B6F77A374B28F71F7BD68AF5B6C172C076B982BAFFB582B50D0FBC.png)，填写指定的域名地址。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260123144609.70025446125275296040226460130502:50001231000000:2800:87C921B738A692EE84D33756C57B370BFAD42F727DF40B8F7E865680E2F6D2AC.png)  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260123144609.51369013747910221757000373555823:50001231000000:2800:0A775AFE9B4067CACBDC84140753A73EC3918348FB27D4A5599B446C51C85FC5.png)  
   * 域名地址需要以http://和https://开头。
   * 最多支持配置5个地址，多个地址使用逗号分隔。
4. 获取应用的相关配置信息。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260123144609.78829857105643617246705436863480:50001231000000:2800:7D940A1FB542B32D7FD7074811663679EF58092BF8BD8C89F035FB27538F31C8.png)  
   配置文件中默认会包含AGC为应用分配的客户端密钥和API密钥信息，您可以在配置信息前打开"不包含密钥"开关，配置文件中将不包含密钥信息，由您自行调用AGC SDK的接口手动配置。
