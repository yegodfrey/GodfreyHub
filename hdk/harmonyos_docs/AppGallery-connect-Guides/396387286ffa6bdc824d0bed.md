# 获取SDK配置信息

## Android

### 获取agconnect-services.json文件

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择您的应用。
3. 在"项目设置"的"常规"页面，下载agconnect-services.json文件。 说明
   >
   > 配置文件中默认会包含AGC为应用分配的客户端密钥和API密钥信息，您可以在下载JSON文件前打开"不包含密钥"开关，配置文件中将不包含密钥信息，由您自行调用AGC SDK的接口手动配置。

## iOS

### 获取agconnect-services.plist文件

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择您的iOS应用。
3. 在"项目设置"页面下载配置文件"agconnect-services.plist"。 说明
   > * 配置文件中默认会包含AGC为应用分配的客户端密钥和API密钥信息，您可以在下载agconnect-services.plist文件前打开"不包含密钥"开关，配置文件中将不包含密钥信息，由您自行调用AGC SDK的接口手动配置。
   > * Safari浏览器当前不支持下载"agconnect-services.plist"文件，请使用Chrome浏览器。

## Web

### 获取Web应用配置信息

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择您的应用。
3. 在"项目设置"的"常规"页面，配置网站限制。

   当您的Web应用需要限制仅指定网站或IP地址才可访问已开通的API时，您可点击"网站限制"后的![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260123144609.98268046313409180839377591672590:50001231000000:2800:3FE043F706B6F77A374B28F71F7BD68AF5B6C172C076B982BAFFB582B50D0FBC.png)，填写指定的域名地址。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260123144609.70025446125275296040226460130502:50001231000000:2800:87C921B738A692EE84D33756C57B370BFAD42F727DF40B8F7E865680E2F6D2AC.png)
   > 说明
   > * 域名地址需要以http://和https://开头。
   > * 最多支持配置5个地址，多个地址使用逗号分隔。
4. 获取应用的相关配置信息。 说明
   >
   > 配置文件中默认会包含AGC为应用分配的客户端密钥和API密钥信息，您可以在配置信息前打开"不包含密钥"开关，配置文件中将不包含密钥信息，由您自行调用AGC SDK的接口手动配置。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260123144609.92603782899640989650634449019091:50001231000000:2800:9F0FF159F42A383DCE348E87983FDB98BAF4A1FD8D0EDA71B9B1157FD815A98C.png)

## 快游戏

### 获取agconnect-services.json文件

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择您的应用。
3. 在"项目设置"页面下载配置文件"agconnect-services.json"。 说明
   > * 配置文件中默认会包含AGC为应用分配的客户端密钥和API密钥信息，其中客户端密钥和API密钥均为密文。
   > * 您也可以在配置信息前打开"不包含密钥"开关，配置文件中将不包含密钥信息，由您自行调用AGC SDK的接口手动配置。
