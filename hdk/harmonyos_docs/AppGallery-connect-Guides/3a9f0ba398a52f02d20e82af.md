# 申请开通权限

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115008.64732019962330562122931511848840:50531125054745:2800:D7FB0E1D6AA60D862D8EA874756ABC20BF501506D625C23DF499A1DD7163C86C.png?needInitFileName=true?needInitFileName=true)  
* 在申请开通权限前您需要在[华为开发者联盟](https://developer.huawei.com/consumer/cn)网站上注册并完成实名认证，具体方法请参见[帐号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。
* 若您还未创建AGC项目，请参见[创建AGC项目](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-get-started#createproject)。

如您需接入AGD API，您需要先下载[申请模板](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115008.97295763373084318086832842503873:50531125054745:2800:E85D20F0F3AB484371DE99E583001DF4529F07315A9A71F7A92095A636AB4D1A.xlsx?needInitFileName=true)，然后将填写好的模板作为附件发送至[developer@huawei.com](mailto:developer@huawei.com)。

邮件标题格式：\[AGD API接入\]-\[公司名称\]。

收到您的申请后，华为运营人员会在5个工作日内给您答复。
