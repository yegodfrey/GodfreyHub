# 设置场景和标签（可选）

初始化SDK时设置AutoCollectScene为false，您可以自定义某个典型或卡顿的游戏场景，例如打斗、团战。若还想在场景中标记一段特殊的子场景信息，可以在场景中设置标签，用以标识该子场景中的性能数据。同个场景中可设置多个标签，但多个标签之间不可嵌套。标签与场景是依附关系，若未设置场景，设置标签将无效，场景与标签的时序图如下：

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110243.10339456612794703296821509026142:50001231000000:2800:C46F6E155581D2485045FA05F54CCF3FFE3DC45F119949566A90BB34B3407D2D.png "点击放大")  

#### 前提条件

* 已[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-integration-0000001719545670)。
* 已[初始化SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-initialization-0000001719386234)，且AutoCollectScene参数值为false。
* 已[开启数据采集器](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-open-close-collector-0000001767186237#section72707115441)。  

#### 开发步骤

1. 引入GPM命名空间。

   ```
   using GPM;
   ```

2. 加载游戏场景前，调用[GPMSDK.SetSceneStart](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpmsdk-apis-0000001720136800#section83450342099)方法，同时游戏性能管理SDK开始采集、上报游戏的性能数据。

   ```
   GPMSDK.SetSceneStart("场景1")
   ```

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110243.44462335827616338902614410756458:50001231000000:2800:0F17EB71F1E005AD4805813E622DD06C2260B9EE11C79C93F0F5E25D234855E2.png)  
   若当前已有正在采集的场景，且场景名称不同，则自动结束上个场景的数据采集，开启新场景的数据采集。  
   设置场景名称时，您可进行相关回调处理。由于游戏性能管理SDK已对回调函数OnSetSceneStart进行了封装，您只需注册[OnSetSceneStartEvent](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpmcallbackhandler-apis-0000002025236161#ZH-CN_TOPIC_0000002025236161__p116091262612)事件监听，并实现[OnSetSceneStartCallback](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpmcallbackhandler-apis-0000002025236161#section2013363110265)委托函数即可。

   ```
   callbackHandler.OnSetSceneStartEvent += OnSetSceneStartImpl;
   ...
   public static void OnSetSceneStartImpl(int code, string msg)
   {
       // GPMSDK.SetSceneStart接口通过子线程回调通知初始化结果。由于大部分API需要在主线程中调用，请在GPMSDK.SetSceneStart回调中合理处理。
       if(code == GPMError.GPM_SUCCESS) 
       {
          // 设置场景名称成功
       }
   }
   ```

3. （可选）场景加载完成后，调用[GPMSDK.SetLoadSceneCompleted](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpmsdk-apis-0000001720136800#section5837142071217)方法，计算加载游戏场景的耗时。

   ```
   // AGC控制台当前暂不支持展示该数据项
   GPMSDK.SetLoadSceneCompleted();
   ```

   设置场景加载完成时，您可进行相关回调处理。由于游戏性能管理SDK已对回调函数OnSetLoadSceneCompleted进行了封装，您只需注册[OnSetLoadSceneCompletedEvent](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpmcallbackhandler-apis-0000002025236161#ZH-CN_TOPIC_0000002025236161__p3451990263)事件监听，并实现[OnSetLoadSceneCompletedCallback](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpmcallbackhandler-apis-0000002025236161#section4286147162617)委托函数即可。

   ```
   callbackHandler.OnSetLoadSceneCompletedEvent += OnSetLoadSceneCompletedImpl;
   ...
   public static void OnSetLoadSceneCompletedImpl(int code, string msg)
   {
       // GPMSDK.SetLoadSceneCompleted接口通过子线程回调通知初始化结果。由于大部分API需要在主线程中调用，请在GPMSDK.SetLoadSceneCompleted回调中合理处理。
       if(code == GPMError.GPM_SUCCESS) 
       {
          // 设置场景加载完成成功
       }
   }
   ```

4. （可选）若想在场景中标记特殊子场景的性能数据时，调用[GPMSDK.SetTagStart](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpmsdk-apis-0000001720136800#section1015212671720)方法，设置标签。

   ```
   // AGC控制台当前暂不支持展示标签标记的性能数据
   GPMSDK.SetTagStart("场景1-TAG1")
   ```

   若当前已有标签正在采集，且标签名称不同，则自动结束上个标签，开启当前标签的性能数据采集。  
   设置场景标签名称时，您可进行相关回调处理。由于游戏性能管理SDK已对回调函数OnSetTagStart进行了封装，您只需注册[OnSetTagStartEvent](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpmcallbackhandler-apis-0000002025236161#ZH-CN_TOPIC_0000002025236161__p15298329172612)事件监听，并实现[OnSetTagStartCallback](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpmcallbackhandler-apis-0000002025236161#section1176471382719)委托函数即可。

   }

5. （可选）调用[GPMSDK.SetTagEnd](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpmsdk-apis-0000001720136800#section18108163414405)方法，结束标签。

   ```
   GPMSDK.SetTagEnd()
   ```

   ```

   ...

   {
       // GPMSDK.SetTagEnd接口通过子线程回调通知初始化结果。由于大部分API需要在主线程中调用，请在GPMSDK.SetTagEnd回调中合理处理。
       if(code == GPMError.GPM_SUCCESS) 
       {
          // 设置场景标签结束成功
       }
   }
   ```

6. 调用[GPMSDK.SetSceneEnd](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpmsdk-apis-0000001720136800#section165425913151)方法，结束场景。

   ```
   GPMSDK.SetSceneEnd()
   ```
