# 云数据库触发器

AGC云数据库服务为您提供了基于云函数服务的扩展机制，您可以为云函数配置云数据库触发器，当云数据库发生插入或者更新数据、删除数据、清空数据等变更操作时将触发云函数，并在云函数中扩展您的业务处理逻辑。

## 前提条件

* 您已[开通云数据库服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/serverless-create--preparations-0000001712008649#section20955131214292)，并且已创建存储区和对象类型。
* 您已[创建函数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/serverless-create-and-config-func-0000001713008121)。

## 创建云数据库触发器

1. 在函数列表中点击函数名称进入函数详情页面。如果点击函数名称右侧"操作"列的"别名"，则在别名列表中点击别名名称，进入别名详情页。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251205152525.33994000154701623902968223865513:50001231000000:2800:ABD25886FDAC25216A392E69B12F39D10D1C14E3B1A591458F2B3E33C177A1C9.png)

2. 点击"触发器"页签下的"添加触发器"，显示触发器创建界面。
3. 在"添加触发器"页面，"触发器类型"选择"云数据库触发器"，并配置"事件源"、"事件类型"和是否"启用"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251205152525.48312752693738903751662681920651:50001231000000:2800:AD2754487D17BF1EFBEE0628F3DB33BA31BB2BBF26E7ECECA673F7026B03C623.png)

   |参数|说明|
   |:----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |触发器类型|云数据库触发器。|
   |事件源|云数据库触发器的数据源。选择您在云数据库服务中创建的存储区名称和对象类型名称。 格式为：项目ID-CloudDB存储区名称-CloudDB对象类型名称，例如**"** 99034201568569469-StorageArea-student**"**。 CloudDB存储区名称以字母开头，可选范围为[0-9A-Za-z]，不带下划线，长度为1~20个字符。CloudDB对象类型名称以字母开头，可选范围为[0-9A-Za-z_]，不允许以sqlite_开头，不允许以下划线结尾，长度为1~30个字符。|
   |事件类型|触发器支持的事件类型。 * onUpsert：数据表插入或更新数据。 * onDelete：数据表删除数据。 * onDeleteAll：清空数据表。 * onWrite：数据插入或更新事件、数据删除事件、数据表清空事件。|
   |启用|是否启用该触发器，标识触发器的状态。默认为启用，可设置。|

4. 触发器配置完成后点击"确定"保存触发器，则回到触发器列表，可看到云数据库触发器图框。

> 注意
>
> 触发器调用云函数功能暂不支持云数据库云侧API批量插入（[executeUpsert](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-transaction-0000001080698454#section11772593429)）/批量删除（[executeDelete](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-transaction-0000001080698454#section13162538184210)）以及[导入数据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-agcconsole-managingdata-0000001080975864#section6547202316247)场景。
