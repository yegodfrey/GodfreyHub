# 获取严重异常报告

严重异常，即被应用捕获的严重崩溃。在1.7.2.300版本后，AGC提供记录严重异常的机制，让您可以监控到这些严重异常，帮助您提高代码质量。  

#### 前提条件

1. 您需要在AGC控制台[开通崩溃服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-enableservice-0000001326330021)。
2. 您需要先在您的应用中[集成崩溃服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-integratesdk-android-0000001275810158)。  

#### 记录异常

1. 调用[AGConnectCrash.getInstance()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-android-0000001055420438#section743716146324)获取AGConnectCrash实例。
2. 在catch代码块中调用[AGConnectCrash.getInstance().recordFatalException()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-android-0000001055420438#section188861225815)记录您需要捕获的严重崩溃问题。  

   ```
   "Java"
   try {
   } catch (Exception e) {
       AGConnectCrash.getInstance().recordFatalException(e);
   }
   ```

   ```
   "Kotlin"
   try {
   } catch (e: Exception) {
       AGConnectCrash.getInstance().recordFatalException(e)
   }
   ```

AGC只会记录一个应用会话中最近的10次严重异常。如果您的应用在一个会话中抛出的严重异常数超过10个，则较早的严重异常会被删除。  

#### 测试异常

您可以在测试应用时调用崩溃服务SDK的API手动制造一个严重异常，然后在AGC上查看严重异常上报情况，以测试报告严重异常能否正常运行。  

```
"Java"
try {
    throw new Exception();
} catch (Exception e) {
    AGConnectCrash.getInstance().recordFatalException(e);
}
```

```
"Kotlin"
try {
} catch (e: Exception) {
    AGConnectCrash.getInstance().recordFatalException(e)
}
```

#### 分析异常

记录的严重异常会在应用下次启动时上报。您可以通过在AGC控制台添加用户属性及时间过滤条件的方式，选择查看指定时间内所有严重异常的统计数据。同时，在问题详情页面，您还可以查看分析堆栈、日志、状态等详细信息。  

#### 前提条件

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中点击您的应用。
3. 在左侧导航栏选择"质量 \> 崩溃"。
4. 在"添加过滤器"中，选择用户属性的事件类型为"崩溃"。
5. 在崩溃服务的"统计"页面，您可以通过添加过滤器和设置右上角的时间选择器过滤您的严重异常数据。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155607.46109849945284102237615290360156:50001231000000:2800:4D3673208A1E0F553639FCDF7D7BE274FBE0D574AF712CCCE3744AE514C5522C.png)

6. 确认异常已经上报后，您可以选择"问题"，通过设置时间选择器查看指定时间范围内该应用累计发生的严重异常问题及其次数。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155607.49610302808717935031534651193749:50001231000000:2800:50C5868750ACA2C0A0CD651D9F6B3A49D7423EE13621266D5096D623A36A9270.png)

#### 更多信息

* 如果您需要获取特定用户、日志或关键信息的自定义异常报告，可参见[自定义崩溃报告](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-customreport-0000001055740502)。
* 如果您使用ProGuard或DexGuard将代码中的类名、字段和方法等混淆处理为不可阅读的代码，可以[通过反混淆处理获取可阅读的报告](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-mapping-0000001055420529)。
