# 使用限制

游戏高光时刻SDK存在API、设备等方面的限制，本章节将为您详细介绍这些不同类型的限制。这些限制可能会根据实际情况随时更新，请您注意文档变化。

## API 限制

API限制是指API调用频率的限制。

|限制项|限制|
|:-----|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|接口调用频率|[exportVideo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamereplaymanager-game-replay-0000001690120477#section7938630104410)：两次调用时间间隔不得低于5秒。|

## 设备限制

设备限制是指SDK对用户终端的限制。

|限制项|限制|
|:---------|:-----------------------------------|
|Android OS|Android 10及以上（API Level 29及以上）的非华为手机|
|HarmonyOS|HarmonyOS 4.X及更早版本的华为手机|

## 特性依赖

特性依赖是指对其他华为业务的依赖。

|特性|依赖的业务|
|:-------|:------------------------------------------------------------------------------------------------|
|使用模板导出视频|[视频剪辑服务](https://developer.huawei.com/consumer/cn/doc/Media-Guides/introduction-0000001101263902)|
