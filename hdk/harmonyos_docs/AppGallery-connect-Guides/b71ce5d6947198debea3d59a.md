# 业务介绍

云监控提供一站式开放型监控解决方案，可监控AppGallery Connect（简称AGC）云函数和云数据库服务的关键运行指标。它具备日志检索和分析能力，可针对特定监控指标配置告警规则，为优化统计指标（如云函数-平均时延、云函数-成功率等）提供支持。使用云监控无须编写代码即可实时查看可视化数据报告，帮助您即时发现云函数、云数据库使用中的问题，从而持续改进服务质量和提升用户体验。  

#### 主要功能

|主要功能|功能描述|
|:---|:---------------------------------------------------------------------|
|指标监控|提供了按照业务规则进行云函数、云数据库监控指标的统计和计算方法，可自动生成监控指标的可视化数据报告，帮助您快速了解应用在哪些方面可优化改进。|
|日志服务|支持添加多个过滤器查询日志，并以直方图和表格形式为您展示服务运行过程中产生的日志数量和详细的日志分析数据。|
|告警管理|为您提供云函数、云数据库服务监控数据的告警能力，您可以通过设置告警规则来定义监控项的阈值，并在监控项满足告警条件时发送告警通知。|

#### 工作原理

云监控可将AGC云函数业务日志和接入日志、云数据库业务日志接入到原始数据湖，数据经过加工清洗写入到结构化数据湖，然后解析出云函数、云数据库的监控指标数据，通过可视化图表在监控大盘展示，同时可以使用日志服务对业务日志和接入日志进行实时检索和分析，帮助您了解云函数、云数据库的运行状况和性能。云监控还为您提供云函数、云数据库服务监控数据的告警功能，您可以通过设置告警规则来定义监控项的阈值，并在监控项满足告警条件时发送告警通知。您对重要监控项设置告警规则后，可在第一时间得知该监控项异常，迅速处理故障。
