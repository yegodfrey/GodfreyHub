# 集成SDK

开发者通过云侧访问认证服务资源时，支持如下两种场景：

* 如您没有自己的服务器，推荐通过AGC云函数访问认证服务资源，此方式无需手动下载凭据文件，具体请参考[（推荐）在云函数中访问认证服务资源](#section69157223716)。
* 如您搭建了自己的服务器且希望通过自己的服务器来访问认证服务资源，则需手动下载凭据文件并集成到代码中，具体请参考[在服务器中访问认证服务资源](#section394732213810)。

请根据实际情况进行选择。

## （推荐）在云函数中访问认证服务资源

### 准备工作

目前您可以通过DevEco Studio创建端云一体化开发工程来实现在云函数中访问认证服务资源，您需要完成如下操作：

1. [创建端云一体化开发工程](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V5/agc-harmonyos-clouddev-devproject-V5)。
2. [创建您准备访问认证服务的云函数](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V5/agc-harmonyos-clouddev-createfunc-V5)。

### 集成Server SDK

AGC Server SDK发布在npm仓库，您可以通过下列步骤来进行集成：

1. 如果您还没有package.json文件，可进入Terminal终端窗口，在您新建的云函数目录下执行以下命令进行创建。

   ```screen
   npm init
   ```

   请按实际情况填写项目的配置信息。
2. 在该目录下继续执行以下命令，安装Server SDK到您的项目中。此时依赖将同步添加到云函数目录下的package.json文件中。

   ```screen
   npm install --save @hw-agconnect/cloud-server
   ```

3. 在您的云函数目录下准备访问认证服务的代码文件中添加如下代码，导入云开发模块。

   ```screen
   import { cloud } from "@hw-agconnect/cloud-server";
   ```

之后您即可直接在该云函数中通过Server SDK管理用户了。管理用户操作请参考[导入用户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-server-importuser-0000001727388958) | [导出用户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-server-exportuser-0000001775188677) | [撤销用户凭据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-server-revoketoken-0000001775308013) | [验证用户凭据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-server-verifytoken-0000001727548362) | [生成自有账号凭据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-server-obtainjwt-0000001727388962)。

## 在服务器中访问认证服务资源

### 集成Server SDK

AGC Server SDK发布在npm仓库，您可以通过下列步骤来进行集成：

1. 如果您还没有package.json文件，可进入Terminal终端窗口，在项目的根目录下执行以下命令进行创建。

   ```screen
   npm init
   ```

   请按实际情况填写项目的配置信息。
2. 在该目录下继续执行以下命令，安装Server SDK到您的项目中。此时依赖将同步添加到您项目的package.json文件中。

   ```screen
   npm install --save @hw-agconnect/cloud-server
   ```

3. 在您的项目中添加如下代码，导入云开发模块。

   ```screen
   import { cloud } from "@hw-agconnect/cloud-server";
   ```

### 初始化Node.js SDK

1. 获取认证凭据，并已将认证凭据放置到您自定义的目录，服务器执行用户需要具备认证凭证文件读权限，认证凭据获取请参见[下载项目级凭据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-download-credentials-0000001281251800)。
2. 初始化SDK。 您可以使用之前下载的认证凭据对SDK进行初始化。当前认证凭证初始化提供了两种方式，您可以设置AGC_CONFIG环境变量，也可以在代码中明确传递认证凭证路径。

   * 方式一：需要先设置环境变量。
     * Linux环境请执行如下操作： 永久环境变量需要在$HOME目录中的.bashrc或者.bash_profile文件中写入如下命令，并执行source .bashrc或者.bash_profile保证环境变量生效。临时环境变量直接执行如下命令，*[PATH]*请替换为凭据文件的实际路径。

       ```screen
       export AGC_CONFIG="[PATH]/agc-apiclient-xxx-xxx.json"
       ```

     * Windows环境请执行如下操作: 永久环境变量需要在Windows的"高级系统设置 > 环境变量"中设置如下的系统变量，建议重启windows系统或者通过其他方式加载环境变量，使设置的系统环境变量生效。

       临时环境变量直接执行如下命令，*[PATH]*请替换为凭据文件的实际路径。

       ```screen
       set AGC_CONFIG=[PATH]\agc-apiclient-xxx-xxx.json
       ```

     之后您即可参考如下示例直接使用认证服务：

     ```screen
     cloud.auth().sign(...);
     ```

   * 方式二：指定认证凭证路径。*[PATH]* 请替换为凭据文件的实际路径。

     若您未指定环境变量，则须按照当前方式操作。您还可以使用凭据文件创建多个实例。

     ```screen
     const cloudInstance = cloud.createInstance({'[PATH]/agc-apiclient-xxx-xxx.json',"instancename",Region.REGION_CN});
     ```

     其中Region是客户端的数据处理位置，可选的值有"REGION_CN"（中国）、"REGION_RU"（俄罗斯）、"REGION_SG"（新加坡）、"REGION_DE"（德国）。

     之后您即可参考如下示例直接使用认证服务：

     ```screen
     cloudInstance.auth().sign(...);
     ```
