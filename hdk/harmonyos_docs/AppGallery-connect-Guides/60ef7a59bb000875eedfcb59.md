# 通过命令行使用云数据库

AGCLI是应用商城提供的一种命令行工具，您可以使用AGCLI命令行清空云数据库中的指定数据。  

#### 开发前准备

使用AGCLI命令行工具管理云数据库时，需要完成以下准备工作：

* 您已经在AGC控制台上创建团队，详细信息请参见[团队账号](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-manageaccount-0000001099996700)。
* 您已在本地安装Node.js和npm。  

#### 配置AGCLI命令行工具

1. 打开编译平台，执行以下命令下载并安装AGCLI命令行工具。 npm install -g @hw-agconnect/agc-cli

   如果提示安装失败，可将仓切换到https://registry.npmjs.org/，或者执行npm config set registry https://registry.npmjs.org/命令。
2. 登录AGCLI命令行工具。 agcli login

3. 选择团队。 agcli team change

   输入命令后，通过方向键选择对应的团队。
4. 选择项目。 agcli project change

输入命令后，通过方向键选择对应的项目。  

#### 清空数据

执行delete-all命令，清空指定存储区和对象类型下的所有数据。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250305155933.66850838432942376426721210745838:50001231000000:2800:1F1E0050976FFAC76ABCA711AA5B930F835D45BDB3F92417E03FA87545604829.png?needInitFileName=true?needInitFileName=true)  
清空数据后时，数据类型为IntAutoIncrement和LongAutoIncrement的字段序列将会重置。  

#### 命令格式

agcli db delete-all --zone \<zone\> --object-type \<object-type\>  

#### 命令选项

|命令选项|必填(M)/选填(O)|描述|示例|
|:------------|:----------|:------|:---------------------------------------------------------------|
|--zone|M|存储区名称。|agcli db delete-all --zone QuickStartDemo --object-type BookInfo|
|--object-type|M|对象类型名称。|agcli db delete-all --zone QuickStartDemo --object-type BookInfo|
