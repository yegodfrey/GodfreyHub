# 取消匹配

当玩家发起匹配后，中途若需要停止匹配，可以调用取消匹配接口来完成取消匹配的操作。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250813135423.65959540431831806513398463685455:50001231000000:2800:48A0A958C40FE949A390BDF545A9E29D6F4461D7D196187DBCCF147A094BA811.png)  
* "取消匹配"仅针对玩家发起"在线匹配"和"组队匹配"后操作。
* 如果取消匹配时玩家已成功匹配，调用取消匹配接口则会失败，玩家将直接进入对战房间。
* 如果取消匹配成功，取消匹配接口返回"匹配取消成功"，同时匹配查询接口会返回一个错误码（在线匹配场景中，会返回错误码[104211](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gameobe-errorcode-js-0000001193110624#ZH-CN_TOPIC_0000001193110624__p594211200387)。在组队匹配场景中，队员查询匹配结果会返回[104205](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gameobe-errorcode-js-0000001193110624#ZH-CN_TOPIC_0000001193110624__p209411920113812)，队长或匹配发起者查询匹配结果则会返回[104205](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gameobe-errorcode-js-0000001193110624#ZH-CN_TOPIC_0000001193110624__p209411920113812)），表示匹配操作因取消而失败。  

#### 前提条件

玩家已发起[在线匹配](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gameobe-matchplayer-js-0000001239685608)或[组队匹配](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gameobe-matchgroup-js-0000001212162738)。  

#### 开发步骤

调用[Client.cancelMatch](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gameobe-client-js-0000001237790585#section1264255114913)方法进行取消匹配。

```
global.client.cancelMatch().then(res => {
    // 匹配取消成功
}).catch(err => {
    // 匹配取消失败
});
```
