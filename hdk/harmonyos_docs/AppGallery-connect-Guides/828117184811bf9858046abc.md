# Now冥想

#### 客户需求

《Now冥想》是西安纳沃信息科技有限公司研发的一款专注于冥想、心理健康的应用平台。用户在使用应用时，经常遇到卡顿、响应慢或强制退出等问题，严重影响用户体验。该公司希望快速复现和定位这些问题。  

#### 华为解决方案

《Now冥想》接入性能管理服务后，该公司通过ANR分析、体验分析、应用分析、网络分析等功能，迅速定位出导致卡顿等问题的原因，经过及时优化更新解决了问题，极大提升了用户体验。借助性能管理服务的丰富功能，《Now冥想》应用的各方面性能有望在未来得到持续提升。
