# 分享视频

使用模板导出视频后，可以进一步将视频分享给他人。

## 前提条件

* 您已[使用模板导出视频](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/game-highlight-exportvideo-0000001686457641)。
* 您使用的模板已[关联分享落地页](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/game-highlight-associate-template-landing-page-0000001678064596#ZH-CN_TOPIC_0000001678064596__li850518424713)。

## 开发步骤

1. 调用[GameReplayManager.applyShare](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamereplaymanager-game-replay-0000001690120477#section1766761352915)方法，分享使用模板导出的视频文件。

   ```screen
   gameReplayManager.applyShare(
       new ShareParam()
       .setFilePath(filePath)       // 要分享的视频文件的绝对路径
       .setTemplateId(templateId)); // 导出分享视频所使用的模板ID
   ```

2. 在ReplayCallback接口的[onApplyShare](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/replaycallback-callback-0000001686126937#section2501125819515)方法中，实现相关回调处理。

   ```screen
   @Override
   public void onApplyShare(ShareResult result) {
       // 分享结果，您可以将ShareResult中的url分享给好友
   }
   ```
