# 开通服务

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击您的项目。
3. 在左侧导航栏中选择"增长 > 应用内消息"，进入应用内消息页面，点击"立即开通"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155404.17707610641235517061739476347551:50001231000000:2800:B99C7DE888A18293B2F9A4EC0D3CDC1AB08AC56B866D68AC6D2BAD89B604A348.png)

4. 如果您此时未设置数据处理位置，系统会自动弹出提示框提示您进行设置。如果您已启用多个数据处理位置，当您需要在不同的数据处理位置管理应用内消息时，可在应用内消息页面选择"数据处理位置"下拉选项进行切换。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155404.73985592629062033112310278600459:50001231000000:2800:3BCEBFBB369653D50FB8AFC99BB13298065E737E8FCC64807C2A4BC29E22DBEA.png)
