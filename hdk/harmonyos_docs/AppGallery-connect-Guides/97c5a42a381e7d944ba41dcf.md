# 开启/关闭数据采集器

采集、上报数据前，必须开启数据采集器。若想结束数据的采集，您可以关闭数据采集器，下次再想采集数据，请重新开启数据采集器。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110241.35827354620191422463083973385143:50001231000000:2800:30D0AF9A1CEFE67ACE20BB5E54C991C31C0153C47C1169AEBA7497B02174C94F.png)  
数据采集对性能有一定的损耗，请在需要的时候开启数据采集器，并在不需要时及时关闭。  

#### 前提条件

* 已[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-integration-ios-0000001932600658)。
* 已[初始化SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-initialization-ios-0000001932441278)。  

#### 开启数据采集器

1. 导入头文件。

   ```
   #import <GPMKit.h>
   ```

2. 调用[enableCollector](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-ios-gpmmanager-0000001941578500#section6902152315716)方法，开启数据采集器。

   ```
   [GPMManager.getInstance enableCollector];
   ```

3. 调用后，可在GPMCallbackDelegate接口的[onEnableCollector](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-ios-gpmcallbackdelegate-0000001968617713#section18835161514914)方法中查看结果并实现回调处理。

   ```
   - (void)onEnableCollector:(int)code msg:(NSString *_Nonnull)msg {
       // 可根据需求将数据进行处理
   }
   ```

#### 关闭数据采集器

1. 导入头文件。

   ```
   #import <GPMKit.h>
   ```

2. 调用[GPMManager.getInstance disableCollector](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-ios-gpmmanager-0000001941578500#section443314117810)方法，关闭数据采集器。

   ```
   [GPMManager.getInstance disableCollector];
   ```

   若当前正在采集、上报数据，关闭数据采集器将自动结束采集数据。
3. 调用后，可在GPMCallbackDelegate接口的[onDisableCollector](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-ios-gpmcallbackdelegate-0000001968617713#section1955018369102)方法中查看结果并实现回调处理。

   ```
   - (void)onDisableCollector:(int)code msg:(NSString *_Nonnull)msg {
       // 可根据需求将数据进行处理
   }
   ```
