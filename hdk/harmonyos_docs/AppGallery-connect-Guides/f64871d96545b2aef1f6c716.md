# 订阅与取消订阅频道

"频道"作为游戏多媒体服务RTM功能的一个数据传输通道，主要用于频道消息的传递与广播。RTM频道消息支持不同客户端之间借助"频道"实现实时通信、全局聊天等功能，允许玩家在游戏内部建立实时的聊天室和群组，以进行广播消息、交流和社交，从而提升游戏的社交互动性。订阅频道的用户即可在频道内收发相关消息和事件，可选择订阅一个或多个频道。如取消订阅，则后续将无法收到频道消息。

## 前提条件

* 您已[集成游戏多媒体基础SDK和实时信令模块](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-integratingsdk-android-0000001250838246#ZH-CN_TOPIC_0000001250838246__li733912204487)。
* 您已[创建游戏多媒体实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-engine-android-0000001193958984#section1093713161034)。

## 订阅频道

订阅频道是收发频道内相关消息和事件的前提，如玩家掉线且重连失败或销毁实例，则会自动取消已订阅的频道，后续将无法收到频道消息。
> 说明
>
> 因网络掉线，在90s时间内，服务端将会尝试自动重连。如若重连成功，则会多次（至多10次）尝试重新订阅原频道。如自动重新订阅失败，建议您手动重新发起订阅。

1. 调用[GameMediaEngine.subscribeRtmChannel](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section9138144810551)方法，订阅指定的频道。

   ```screen
   SubscribeRtmChannelReq req = new SubscribeRtmChannelReq();
   req.setChannelId("579457***95");
   Map<String, String> map = new HashMap<>();
   map.put("name","xxxx");
   map.put("age","22");
   req.setPlayerProperties(map);
   mHwRtcEngine.subscribeRtmChannel(req);
   ```

2. 在IGameMMEEventHandler接口的[onSubscribeRtmChannel](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section1297935513575)回调方法中，可以获取频道订阅的结果。

   ```screen
   @Override
   public void onSubscribeRtmChannel(SubscribeRtmChannelResult result) {
       // 可根据需求将数据进行处理
   }
   ```

## 取消订阅频道

1. 如需取消已订阅的频道，调用[GameMediaEngine.unSubscribeRtmChannel](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section531111615562)方法即可取消订阅指定的频道。

   ```screen
   UnSubscribeRtmChannelReq req = new UnSubscribeRtmChannelReq();
   req.setChannelId("579457***95");
   mHwRtcEngine.unSubscribeRtmChannel(req);
   ```

2. 在IGameMMEEventHandler接口的[onUnSubscribeRtmChannel](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section7459135755716)回调方法中，可以获取取消订阅频道的结果。

   ```screen
   @Override
   public void onUnSubscribeRtmChannel(UnSubscribeRtmChannelResult result) {
       // 可根据需求将数据进行处理
   }
   ```
