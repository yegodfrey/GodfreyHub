# 使用限制

#### 资源限制

云托管服务对托管包大小、域名数量、版本数量和存储资源量有一定的限制，如下表所示。  

|资源|限制|
|:----------|:-------------------------------------------------------------------------------------------------------|
|托管包大小|≤400MB（解压缩） ≤20000（文件数） 说明： 托管包仅支持压缩后上传。|
|单个项目的最大存储容量|默认免费存储空间10GB|
|单个项目的最大域名数量|36 说明： * 中国站点默认值为1个自定义域名，海外站点默认值为1个自定义域名和1个泛域名。如果需要调整默认值，请联系华为运营人员。 * 单个项目的域名数量：通过网站托管以及存储加速功能配置的域名数量之和。|
|单个项目的最大版本数量|100|
|单个项目的最大网络流量|默认免费流量360MB/天|
