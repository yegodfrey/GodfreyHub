# 高阶归因分析

当您需要进一步查询点击链接时间、开始下载时间、安装完成时间和归因参数（referrer）时，可以通过接口调用方式做归因分析。  

#### 前提条件

您需要已提前设置归因参数。  

#### 开发步骤

您可以调用Android系统的ContentResolver.query接口，传入华为应用市场指定的Uri地址和应用包名即可请求获取归因参数。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230810201402.96906306941188881437195652608387:50001231000000:2800:EE05B3AA1EDCBC23CB3561BAA07030E224F311855292FC78FD538284C9F0A0B7.png?needInitFileName=true?needInitFileName=true)  
使用该接口将涉及ContentResolver的获取，ContentResolver对象会与应用市场进行通信，部分场景下将被识别为关联启动，请您注意如下。

* 需要在隐私声明中加上关联启动相关条例。
* 获取用户隐私同意后，再进行接口的调用。

1. 构造Uri对象：uriString为"content://com.huawei.appmarket.commondata/item/5"。
2. 调用ContentResolver.query接口，第1个参数传入Uri对象，第4个参数传入应用包名。

   ```
   cursor = contentResolver.query(uri, null, null, packageName, null);
   ```

3. 解析ContentResolver.query接口返回的Cursor对象。
   * 如果Cursor为空，表示没有相应归因信息。
   * 如果Cursor不为空，表示归因查询成功。 您可以使用Cursor.getString(X)获取相关归因信息，X可以是归因信息类型的常量或常量值，如下表所示。

     |常量|常量值|说明|
     |:--------------------------|:--|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
     |INDEX_ENTER_AG_TIME|1|从外部跳转到华为应用市场的时间。|
     |INDEX_INSTALLED_FINISH_TIME|2|跳转进入华为应用市场后点击下载，应用安装完成的时间，如"1632811393"。|
     |INDEX_START_DOWNLOAD_TIME|3|跳转进入华为应用市场后点击下载时，启动下载的时间，如"1632811393"。|
     |INDEX_TRACKID|4|付费推广的归因信息。 归因信息trackId（json结构，可扩展），当前包含： * channel：由广告主运营在华为投放系统针对广告任务绑定的智能分包渠道号，如"channel12345"。 * callback：回传参数，用于oCPD对接，如"security:CD40F6\*\*\*\*\*C7A9F4"。 * taskid：任务ID，如"200052202"。 * subTaskId：子任务ID，如"200037037"。 * RTAID：RTAID，如"123556"。 可能获取到的归因信息种类请参考[FAQ](https://developer.huawei.com/consumer/cn/doc/distribution/promotion/channel-faq-0000001182723923)。|
     |INDEX_REFERRER_EX|5|下载链接地址中设置的referrer参数。|

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230810201403.66664481697211908498253457571887:50001231000000:2800:DD11C0F94C585ADAF1C31E3B169D23D86B58BDC042E7184213083EBE067925C2.png?needInitFileName=true?needInitFileName=true)  
   * 仅支持媒体或应用自身查询归因信息，归因信息在端侧存储期限为90天。其中付费推广中的trackId在云侧的存储有效期是30天。
   * 时间参数说明：距离1970年1月1日0点的秒数。
   * 用户手动清空华为应用市场缓存，会造成归因数据丢失。
   * 目前10.4.0及以后版本的华为应用市场才支持归因结果查询。
* INDEX_TRACKID和INDEX_REFERRER_EX只有在10.5.0.300及以上版本的应用市场客户端才支持。  

#### 示例代码

```
private static final String PROVIDER_URI = "content://com.huawei.appmarket.commondata/item/5";
private static final int INDEX_ENTER_AG_TIME = 1;
private static final int INDEX_INSTALLED_FINISH_TIME = 2;
private static final int INDEX_START_DOWNLOAD_TIME= 3;
private static final int INDEX_REFERRER_EX= 5;
private void getReferrer(String pkgName) {
	Cursor cursor = null;
	Uri uri = Uri.parse(PROVIDER_URI);
	ContentResolver contentResolver = getContentResolver();
	String packageName[] = new String[] { pkgName };
	try {
		cursor = contentResolver.query(uri, null, null, packageName, null);
		if (cursor != null) {
			cursor.moveToFirst();
			Log.i(TAG, "packageName=" + pkgName);
			Log.i(TAG, "enter AppGallery time = " + cursor.getString(INDEX_ENTER_AG_TIME));
			Log.i(TAG, "installed time = " + cursor.getString(INDEX_INSTALLED_FINISH_TIME));
			Log.i(TAG, "download time = " + cursor.getString(INDEX_START_DOWNLOAD_TIME));
			Log.i(TAG, "referrer=" + cursor.getString(INDEX_REFERRER_EX));
		} else {
			Log.e(TAG, "referrer is null");
		}
	}catch(Exception e){
		//处理异常
	} finally {
		if (cursor != null) {
			cursor.close();
		}
	}
}
```
