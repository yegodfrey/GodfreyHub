# QQ

## 前提条件

* 您需要在AGC控制台[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-integration-sdk-0000001326347605)。

## 开发步骤

认证服务提供了两种开发方式接入QQ账号：

* 推荐您使用新的统一登录接入方式，请参见[统一登录接入方式](#section197163415012)。
* 同时为了兼容性保留了老的传统接入方式，请参见[传统接入方式](#section7347926205816)。

### 统一登录接入方式

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114613.76299068898572779012002108167085:50001231000000:2800:972C84CA438C8FCAF8FEA5FBBBB1EACB952834D51A4EF24E58C0FFB9E33067F6.png "点击放大")

1. 在项目的podfile中添加QQ账号认证API的依赖和QQ SDK依赖。

   ```screen
   pod  'AGConnectAPIAuthQQ'
   pod  'TencentOpenAPI-Mirror'
   ```

   > 说明
   >
   > 由于华为未提供QQ SDK依赖包，您可以使用示例中的Pod方式添加QQ SDK依赖，也可以自行至腾讯开放平台下载最新版本的SDK依赖包进行手动集成。示例中的QQ SDK Pod依赖包仅供参考，华为不负责版本更新。
2. 在XCode中，选择您的工程设置项，左侧导航选择"TARGETS"，点击"Info"标签。
   * 在"URL Types"添加一条新的"URL Schemes"，新的scheme格式为tencent + appid，示例图中以注册的appid是222222为例。

     ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114613.12411245951077864978958114887638:50001231000000:2800:2320AF6A8B213A7403251447D006727A0F26612F6F1822A930365E01D8C63EC8.png)
   * 配置LSApplicationQueriesSchemes。 请根据备注中的说明进行配置。

     |互联SDK中使用的scheme|备注|
     |:-----------------------------|:-----------------------------------------------------------|
     |mqq://|比较常用。|
     |mqqapi://|比较常用。|
     |tim://|比较常用。|
     |mqqgamebindinggroup://|判断设备上QQ是否支持绑定群。|
     |mqqopensdkapiV2://|判断设备上QQ是否支持粘贴板传值。|
     |mqqopensdkavatar://|判断设备上QQ是否支持设置头像。|
     |mqqopensdkfriend://|判断设备上QQ是否支持添加好友。|
     |mqqopensdklaunchminiapp://|判断设备上QQ是否支持启动小程序。|
     |mqzone://|判断设备上是否安装了QQ空间。|
     |tencentapi.qq.reqContent://|只在 [TencentApiInterface isTencentAppSupportTencentApi]方法中用到。|
     |tencentapi.qzone.reqContent://|只在 [TencentApiInterface isTencentAppSupportTencentApi]方法中用到。|
     |mqqthirdappgroup://|判断设备上QQ是否支持第三方应用加群。|
     |mqqopensdkminiapp://|判断设备上QQ是否支持小程序的相关API。|

3. 设置QQ的AppId到对应接口。

   ```screen
   "Objective-C"
   AGCAuthThirdPartyConfig.instance.qqAppId = @"XXX";
   ```

   ```screen
   "Swift"
   AGCAuthThirdPartyConfig.instance().qqAppId = "XXX"
   ```

4. 添加生命周期回调，请参见[统一登录调用AppDelegate回调](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-unified-login-0000001275827780)。
5. 调用[[AGCAuth signIn:controller:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346#section1835003573014)方法，登录QQ账号。

   ```screen
   "Objective-C"
    [[[[AGCAuth getInstance] signIn:AGCAuthProviderTypeQQ controller:self] addOnSuccessCallback:^(AGCSignInResult * _Nullable result) {
            // onSuccess
            AGCUser *user = result.user;
        }] addOnFailureCallback:^(NSError * _Nonnull error) {
            // onFail
        }];
   ```

   ```screen
   "Swift"
   AGCAuth.instance().signIn(provider: .qq,controller: self).onSuccess{ (result) in
       // onSuccess
   }.onFailure{ (error) in
       // onFailure
   }
   ```

### 传统接入方式

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114613.28066310081739484183030593535681:50001231000000:2800:E67FC0B98724622A5F594560188AC1EA919841849646CCEFD3D37EBA4DD4531B.png "点击放大")

1. 在应用的登录界面，初始化[AGCAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346)实例，获取AGC的用户信息，检查是否有已经登录的用户。如果有则可以直接进入用户界面，否则显示登录界面。

   ```screen
   "Objective-C"
   AGCUser *user = [[AGCAuth getInstance] currentUser];
   ```

   ```screen
   "Swift"
   let user = AGCAuth.instance().currentUser
   ```


2. QQ账号登录，并获取QQ账号的用户授权信息。 说明
   >
   > 此步骤仅供参考，更详细内容，请参见[QQ官方文档](https://wiki.connect.qq.com/ios_sdk环境搭建)。
   1. 配置在腾讯开放平台申请的APPID。

      ```screen
      "Objective-C"
      mTencent = [[TencentOAuth alloc] initWithAppId:APP_ID andDelegate:self];
      [mTencent authorize:@[@"all"]];
      ```

      ```screen
      "Swift"
      mTencent = TencentOAuth(appId: "QQ_APP_ID", andDelegate: self)
      mTencent!.authorize(["all"])
      ```


   2. 在TencentSessionDelegate回调中获取授权登录后的accessToken和openId，用于传入AGConnect SDK。

      ```screen
      "Objective-C"
      - (void)tencentDidLogin {
          // onSuccess
          NSString *accessToken = [mTencent accessToken];
          NSString *openId = [mTencent openId];
        }

        - (void)tencentDidNotLogin:(BOOL)cancelled {

        }

        - (void)tencentDidNotNetWork {

        }
      ```

      ```screen
      "Swift"
          func tencentDidLogin() {
              let accessToken = qq!.accessToken
              let openId = qq!.openId
          }

          func tencentDidNotLogin(_ cancelled: Bool) {

          }

          func tencentDidNotNetWork() {

          }
      ```


   3. 在AppDelegate中添加授权确认后的回调。

      ```screen
      "Objective-C"
      - (BOOL)application:(UIApplication *)app openURL:(NSURL *)url options:(NSDictionary<UIApplicationOpenURLOptionsKey,id> *)options {
          return[TencentOAuth HandleOpenURL:url];
        }
      ```

      ```screen
      "Swift"
          func application(_ app: UIApplication, open url: URL, options: [UIApplication.OpenURLOptionsKey : Any] = [:]) -> Bool {
              return TencentOAuth.handleOpen(url)
          }
      ```

3. 调用[[AGCQQAuthProvider credentialWithToken:openId:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcqqauthprovider-ios-0000001054342371#section93691113182511)使用从QQ账号获取的accessToken和openId生成credential，并调用[[AGCAuth signIn:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346#section488155612616)实现登录。

## 更多信息

* 您如果想让用户可以使用多个账号登录您的应用，可以将多个[账号进行关联](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-associated-0000001053053982)。
* 当用户不需要使用应用，或者需要切换其他账号登录认证，可以先执行[登出](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-sign-out-0000001053692708)。
* 当用户需要注销当前用户，可以进行[销户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-deleteuser-0000001057460873)。
* 对于销户、修改密码、关联账号以及重置手机账号和邮箱账号等敏感操作，为了提高安全性，需要用户必须在5分钟内登录过才能执行。如果用户执行敏感操作时登录超过5分钟，需要[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-reauthenticate-0000001127283387)后再执行敏感操作。
* 您可以参考[异常处理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-troubleshooting-0000001054715191)实现自己的异常处理机制，从而减少异常情况的发生。
* 您可以使用云函数触发器来接收用户注册、登录、销户等关键事件，从而[扩展认证服务的能力](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-extension-0000001053372708)。
* 您可以参考[管理用户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-user-manage-0000001606051705)对用户进行解锁、停用等操作。
