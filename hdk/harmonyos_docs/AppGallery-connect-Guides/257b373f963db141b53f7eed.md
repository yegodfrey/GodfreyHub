# 设置云端配置项

您可以在 AppGallery Connect 创建新的云端配置项，根据所需的条件逻辑，将用户定义的值覆盖应用内的值。

对于每个配置项，您可以设置默认值（最终将覆盖相应的应用内默认值），还可以设置条件值，不同条件下相同配置项可以设置不同的值。

## 前提条件

您需要已[开通远程配置服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-remoteconfig-enable-service-0000001276051134)。

## 配置项管理

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择需要设置配置项值的应用。
3. 在左侧导航栏选择"增长 > 远程配置"。


4. 选择"配置项管理"页签，点击"添加配置项"，添加新的配置项内容。 配置项的名称需与应用中对应的配置项保持一致。配置项可以配置多个条件值，即不同条件下，设置不同值，条件值设置请参见[配置条件管理](#section11391717983)。

## （可选）配置条件管理

您可以为配置项设置条件属性，在不同的条件下为配置项设置不同的值，从而使应用在不同条件下提供差异化的功能。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择需要设置配置条件的应用。
3. 在左侧导航栏选择"增长 > 远程配置"。
4. 选择"配置条件管理"页签，点击"添加配置条件"，添加新的条件内容。

   |**过滤条件**|**运算符**|**条件** **值**|**说明**|
   |:-------|:------------------------|:---------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |应用版本|* 包含 * 不包含 * 等于 * 包含正则表达式|输入一个或多个应用版本号（1-64个字符）。|对应应用的VersionName。 当选择的运算符为 "包含"、"不包含"或"等于"时，可以采用以逗号分隔的值列表。 当选择的运算符为"包含正则表达式"时，您需要输入RE2格式的正则表达式。您不仅能够通过正则表达式匹配目标版本字符串的全部文本，还能够利用^和$定位点来匹配目标字符串的开头、结尾部分或文本的全部。关于如何书写正则表达式，请参考[Syntax](https://github.com/google/re2/wiki/Syntax)。 * 运算符"包含"为模糊匹配，目标值的列表中只要有1个值是实际值的子字符串，则返回True。例如：目标值列表为"1.0,2.0,3.0"，那么实际值为2.0.1返回True，为4.0.1时返回False。 * 运算符"不包含"指，目标值的列表中没有1个值是实际值的子字符串，则返回True。例如：目标值列表为"1.0,2.0,3.0"，那么实际值为2.0.1返回False，为4.0.1时返回True。 * 运算符"等于"为完全匹配，目标值的列表中只要有1个值是实际值，则返回True。例如：目标值列表为"1.0,2.0,3.0"，那么实际值为2.0时返回True， 为4.0时返回False。 * 运算符"包含正则表达式"指，如果目标值（即RE2正则表达式）与实际值匹配，则返回True。|
   |OS版本|-|-|不支持该条件。|
   |语言|-|选择一种或多种设备语言。|如果安装了该应用的设备使用的语言是所选择语言之一，则此规则的判断结果为True。|
   |国家地区|-|选择设备所在的一个或多个国家或地区。|如果安装了该应用的设备设置的国家/地区是所选择出国家/地区之一，则此规则的判断结果为True。|
   |省级行政区|-|选择设备所在的一个或多个省级行政区。|系统会根据用户端侧请求消息的IP地址判断是否满足设备在对应的省级行政区内。|
   |用户百分比|* <= * >|0.000001~100|AGC会根据随机数（默认值为default，您可以自定义）将每个应用实例映射到一个固定的整数或小数上面（0.000001~100的范围），这样每个应用实例到服务器来获取数据时就能识别出是否满足当前的条件。 如果您想要一个应用实例被映射成多个数字，则需要添加多个此类型的条件，每个条件使用不同的随机数。|
   |时间日期|* 晚于 * 早于|选择具体的日期和时间，也可以指定具体的时区。|将设备的当前时间与配置的条件值进行比较。|
   |设备芯片|-|-|不支持该条件。|

5. 点击"保存配置条件"保存当前条件。
6. 在"配置条件管理"页签下，可以查看所有的配置条件列表。 点击配置条件右上角的"![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b7/v3/RX9t4BftR8ycqJMhKLio2A/zh-cn_image_0000001156147703.png?HW-CC-KV=V1&HW-CC-Date=20260916T021030Z&HW-CC-Expire=31536000000&HW-CC-Sign=FA1C2833DE25A9029A61C622AC0FF0949AA0E27C15A3915D5190E1E7D2FD384C "点击放大")"：您可以查看、修改、删除配置条件，还可以通过复制方式快速添加配置条件。
