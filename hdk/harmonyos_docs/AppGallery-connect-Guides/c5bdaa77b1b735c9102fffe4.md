# 通过Server SDK将三方数据库内容迁移至云数据库

本Demo演示使用Server SDK执行将数据从其他数据库迁移至云数据库的方案。您可以使用本Demo方案完成数据迁移的目的或参考本方案定制化自己的迁移方案。  

#### 前提条件

* 您已经在云数据库上创建存储区和对象类型。
* 您已经获取到示例代码，请从[示例代码](https://github.com/AppGalleryConnect/agc-server-demos-java/tree/master/clouddb-data-migrate)获取。  

#### 操作步骤

1. 下载认证凭据agc-apiclient-\*.json替换到"./config"路径下。详细请参见[项目级凭据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-started-server-0000001058092593#section1778162811430)。
2. 配置源数据库。

   <br />

   配置文件路径为：./config/db.properties，请根据实际情况修改对应的url、driver、user和password进行配置。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251125201413.33833116557265253459028264867652:50001231000000:2800:B889AF684B34636EE5973E0AA3F57DA74AECAF4112FA9965E20E6A5F675732AB.png)  
   若使用PostgreSQL数据库时，请在url中指定参数currentSchema，或在SQL语句上拼接表所属的schema，否则可能出现表不存在的问题。  

   ```
   "mysql"
   source.db.url=jdbc:mysql://localhost:3306/test?characterEncoding=GBK
   source.db.driver=com.mysql.cj.jdbc.Driver
   source.db.user=user
   source.db.password=******
   ```

   ```
   "postgresql"
   #source.db.url=jdbc:postgresql://localhost:5432/postgres?
   currentSchema=test&socketTimeout=300
   #source.db.driver=org.postgresql.Driver
   #source.db.user=user
   #source.db.password=******
   ```

   ```
   "oracle"
   #source.db.url=jdbc:oracle:thin:@localhost:1521:orcl
   #source.db.driver=oracle.jdbc.driver.OracleDriver
   #source.db.user=user
   #source.db.password=******
   ```

   ```
   "sql server"
   #source.db.url=jdbc:sqlserver://localhost:1433;DatabaseName=test;
   #source.db.driver=com.microsoft.sqlserver.jdbc.SQLServerDriver
   #source.db.user=user
   #source.db.password=******
   ```

   <br />

3. 获取源数据库驱动包。

   <br />

   若源数据库为Oracle或SQL Server，请根据实际需要设置，本配置示例仅做参考。

   本示例通过maven引入对应三方包，pom.xml配置中引入方式如下：  

   ```
    "mysql"
   <dependencies>
       ...
       <dependency>
           <groupId>mysql</groupId>
           <artifactId>mysql-connector-java</artifactId>
           <version>8.0.30</version>
       </dependency>
       ...
   </dependencies>
   ```

   ```
   "postgresql"
    <dependencies>
       ...
       <dependency>
           <groupId>org.postgresql</groupId>
           <artifactId>postgresql</artifactId>
           <version>42.5.1</version>
       </dependency>
       ...
   </dependencies>
   ```

   ```
   "oracle"
    <dependencies>
       ...
       <dependency>
           <groupId>com.oracle.database.jdbc</groupId>
           <artifactId>ojdbc10</artifactId>
           <version>19.17.0.0</version> 
       </dependency>
       ...
   </dependencies>
   ```

   ```
   "sql server"
    <dependencies>
       ...
       <dependency>
           <groupId>com.microsoft.sqlserver</groupId>
           <artifactId>sqljdbc4</artifactId>
           <version>4.0</version>
       </dependency>
       ...
   </dependencies>
   ```

   <br />

4. 通过maven引入Cloud DB软件包。

   <br />

   pom.xml文件引入方式如下：

   ```
   <dependencies>
       ...
       <dependency>
           <groupId>com.huawei.agconnect.server</groupId>
           <artifactId>agconnect-auth</artifactId>
           <version>1.2.0.301</version>
       </dependency>
       <dependency>
           <groupId>com.huawei.agconnect.server</groupId>
           <artifactId>agconnect-database-server-sdk</artifactId>
           <version>1.0.13.300</version>
       </dependency>
       ...
   </dependencies>
   ```

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251125201413.50198255102656122708078221716809:50001231000000:2800:7E52AC8C7459E253DD57A8FDC65FC819019153363D57B4C8A822C46D76FDA805.png)  
   AGC相关SDK包会间接依赖部分开源软件，示例pom.xml文件中已按需添加相关依赖，若使用过程中仍旧出现软件包缺失的情况，请按需添加依赖或修改合适的版本。

   <br />

5. 配置Application.java文件。

   <br />

   您可以根据实际情况选择数据迁移的方式。
   * 方式一：使用云数据库模型类进行数据迁移，迁移前需下载云数据库模型类。  
     下载步骤如下：
     1. 参考[导出对象类型](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-agcconsole-objecttypes-0000001127675459#section1558018208151)，下载对应的对象类型模型类，并将包名命名为com.huawei.agc.clouddb.quickstart.target.model。
     2. 将导出的java文件导入至工程对应的"com/huawei/agc/clouddb/quickstart/target/model"路径。

     ```
     // assign zone name in Cloud DB
     String cloudDBZoneName = "AdminSdkZoneTest"; // AdminSdkZoneTest替换为目标存储区名称
     CloudDBZone cloudDBZone;
     try {
         AuthenticateTool.init();
         AGCClient agcClient = AGCClient.getInstance(CLOUDDB_CN.getClientName());
         AGConnectCloudDB cloudDB = AGConnectCloudDB.getInstance(agcClient);

         CloudDBZoneConfig cloudDBZoneConfig = new CloudDBZoneConfig(cloudDBZoneName);
         cloudDBZone = cloudDB.openCloudDBZone(cloudDBZoneConfig);
     } catch (AGCException ex) {
         ex.printStackTrace();
         return;
     }

     // assign the tables, and do migrate or export data files
     List<Class<? extends AbstractSourceModel>> classes = new ArrayList<>();
     classes.add(SourceBookInfo.class);  // SourceBookInfo替换为源数据库模型类名称

     for (Class<? extends AbstractSourceModel> clazz : classes) {
         try {
             Class<? extends CloudDBZoneObject> targetClazz = clazz.getAnnotation(Table.class).targetClass();
             DataHandler<? extends AbstractSourceModel, ? extends CloudDBZoneObject> dataHandler =
                 new DataHandler<>(clazz, targetClazz);
             dataHandler.init();

             DataMigrate<? extends AbstractSourceModel, ? extends CloudDBZoneObject> dataMigrate =
                 new DataMigrate<>(dataHandler, new LoggerProgressHandler());  // LoggerProgressHandler可替换为IProgressHandler的子类

             // option1: migrate data with target object   // 使用CloudDB模型类迁移数据，需要下载模型类
             dataMigrate.migrateAsTargetObject(cloudDBZone);
         } catch (ServiceException ex) {
             ex.printStackTrace();
         }
     }
     ```

   * 方式二：使用云数据库泛化模型类进行数据迁移。  
     ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251125201413.74620706859869788688557231140015:50001231000000:2800:77E21C4BCEA98DA5E59EB06176029D261A31B4E59D1EB3C581147F4852E29F84.png)  
     使用泛化模型类进行数据迁移时，需要将agconnect-database-server-sdk升级到1.0.13.300或以上的版本。

     ```

     String cloudDBZoneName = "AdminSdkZoneTest"; // AdminSdkZoneTest替换为目标存储区名称
     CloudDBZone cloudDBZone;
     try {
         AuthenticateTool.init();
         AGCClient agcClient = AGCClient.getInstance(CLOUDDB_CN.getClientName());
         AGConnectCloudDB cloudDB = AGConnectCloudDB.getInstance(agcClient);

         CloudDBZoneConfig cloudDBZoneConfig = new CloudDBZoneConfig(cloudDBZoneName);
         cloudDBZone = cloudDB.openCloudDBZone(cloudDBZoneConfig);
     } catch (AGCException ex) {
         ex.printStackTrace();
         return;
     }

     // assign the tables, and do migrate or export data files
     List<Class<? extends AbstractSourceModel>> classes = new ArrayList<>();
     classes.add(SourceBookInfo.class);  // SourceBookInfo替换为源数据库模型类名称

     for (Class<? extends AbstractSourceModel> clazz : classes) {
         try {
             Class<? extends CloudDBZoneObject> targetClazz = clazz.getAnnotation(Table.class).targetClass();
             DataHandler<? extends AbstractSourceModel, ? extends CloudDBZoneObject> dataHandler =
                 new DataHandler<>(clazz, targetClazz);
             dataHandler.init();

             DataMigrate<? extends AbstractSourceModel, ? extends CloudDBZoneObject> dataMigrate =

             dataMigrate.migrateAsGenericObject(cloudDBZone);
         } catch (ServiceException ex) {
             ex.printStackTrace();
         }
     }
     ```

   * 方式三：使用JSON文件进行数据迁移，将源数据库的数据导出为云数据库可识别的JSON文件，然后在AGC控制台直接[导入本地数据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-agcconsole-managingdata-0000001080975864#section6547202316247)。

     ```
     // assign the tables, and do migrate or export data files
     List<Class<? extends AbstractSourceModel>> classes = new ArrayList<>();
     classes.add(SourceBookInfo.class);  // SourceBookInfo替换为源数据库模型类名称

     for (Class<? extends AbstractSourceModel> clazz : classes) {
         try {
             Class<? extends CloudDBZoneObject> targetClazz = clazz.getAnnotation(Table.class).targetClass();
             DataHandler<? extends AbstractSourceModel, ? extends CloudDBZoneObject> dataHandler =
                 new DataHandler<>(clazz, targetClazz);
             dataHandler.init();

             DataMigrate<? extends AbstractSourceModel, ? extends CloudDBZoneObject> dataMigrate =
                 new DataMigrate<>(dataHandler, new LoggerProgressHandler());  // LoggerProgressHandler可替换为IProgressHandler的子类

             // option3: export data to json files    // 将源数据库的数据导出为CloudDB可识别的JSON文件
             dataMigrate.export(cloudDBZoneName);
         } catch (ServiceException ex) {
             ex.printStackTrace();
         }
     }
     ```
