# 开启/关闭数据采集器

采集、上报数据前，必须开启数据采集器。若想结束数据的采集，您可以关闭数据采集器，下次再想采集数据，请重新开启数据采集器。

## 前提条件

* 已[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-integration-0000001719545670)。
* 已[初始化SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-initialization-0000001719386234)。

## 开启数据采集器

1. 引入GPM命名空间。

   ```screen
   using GPM;
   ```

2. 调用[GPMSDK.EnableCollector](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpmsdk-apis-0000001720136800#section6902152315716)方法，开启数据采集器。

   ```screen
   GPMSDK.EnableCollector();
   ```

3. 开启数据采集时，您可进行相关回调处理。由于游戏性能管理SDK已对回调函数OnEnableCollector进行了封装，您只需注册[OnEnableCollectorEvent](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpmcallbackhandler-apis-0000002025236161#ZH-CN_TOPIC_0000002025236161__p13241044142518)事件监听，并实现[OnEnableCollectorCallback](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpmcallbackhandler-apis-0000002025236161#section57971933172520)委托函数即可。

   ```screen
   callbackHandler.OnEnableCollectorEvent += OnEnableCollectorImpl;
   ...
   public static void OnEnableCollectorImpl(int code, string msg)
   {
       // GPMSDK.EnableCollector接口通过子线程回调通知初始化结果。由于大部分API需要在主线程中调用，请在GPMSDK.EnableCollector回调中合理处理。
       if(code == GPMError.GPM_SUCCESS) 
       {
          // 开启数据采集成功
       }
   }
   ```

4. 若**AutoCollectScene** 设置为**true** ，游戏性能管理SDK开始采集、上报游戏运行时的性能数据，您可以前往[AGC控制台查看数据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-view-data-0000001767393705)。

## 关闭数据采集器

1. 引入GPM命名空间。

   ```screen
   using GPM;
   ```

2. 调用[GPMSDK.DisableCollector](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpmsdk-apis-0000001720136800#section443314117810)方法，关闭数据采集器。

   ```screen
   GPMSDK.DisableCollector();
   ```

   若当前正在采集、上报数据，关闭数据采集器将自动结束采集数据。
3. 关闭数据采集时，您可进行相关回调处理。由于游戏性能管理SDK已对回调函数OnDisableCollector进行了封装，您只需注册OnDisableCollectorEvent事件监听，并实现[OnDisableCollectorCallback](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-gpmcallbackhandler-apis-0000002025236161#section1127714102260)委托函数即可。

   ```screen
   callbackHandler.OnDisableCollectorEvent += OnDisableCollectorImpl;
   ...
   public static void OnDisableCollectorImpl(int code, string msg)
   {
       // GPMSDK.DisableCollector接口通过子线程回调通知初始化结果。由于大部分API需要在主线程中调用，请在GPMSDK.DisableCollector回调中合理处理。
       if(code == GPMError.GPM_SUCCESS) 
       {
          // 关闭数据采集成功
       }
   }
   ```
