# 使用限制

由于排行榜模板包含云数据库和云函数服务，在资源、配额、代码等方面的限制取决于模板中包含的服务类型，本章节将为您说明排行榜模板可能涉及的使用限制。

|依赖的服务|限制|
|:----|:-------------------------------------------------------------------------------------------------------------------------------------------|
|云数据库|请参考[云数据库使用限制](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-clouddb-restrictions-0000001127557973)。|
|云函数|请参考[云函数使用限制](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloud-function-restriction-0000001058641770)。|
|认证服务|请参考[认证服务使用限制](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-auth-restrict-0000001053254031)。|

> 说明
>
> 使用限制可能会根据实际情况随时更新，请您注意相关文档。
