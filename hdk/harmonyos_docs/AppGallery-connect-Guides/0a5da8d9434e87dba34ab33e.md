# 提供每帧数据

为了保证预测帧绘制成功，应在绘制前提供预测帧所需的相关数据，或补充一些详细信息以确保预测帧时更加精确。我们提供了显式抓取数据和隐式抓取数据两种抓取数据的函数，其中，显式抓取数据是由调用方传递颜色、深度、模板以及物体的相机投影矩阵、摄像机扩展信息等帧数据，隐式抓取数据主要从默认帧缓冲区中抓取颜色、深度、模板等帧数据。  

#### 前提条件

* 已[创建库实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/predict-frame-create-instance-0000001580652660)。
* 已[设置主要参数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/predict-frame-set-frame-parameters-0000001630812045)。  

#### 显式抓取数据

调用函数[FrameFlow_ProvidePerFrameData](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflow-provideperframedata-0000001791334588)，可提供预测帧所需的相关数据（如颜色、深度、模板），还可以将一些详细信息（如[物体的相机投影矩阵](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffperframeobjectmatrices-0000001838253749)、[摄像机扩展信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffperframeextendedcamerainfo-0000001791334636)）添加到pPerFrameData的pNext扩展链中，以确保预测帧时更加精确。此函数必须每帧调用一次。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240314102212.25732669057353702850648676287335:50001231000000:2800:C9FE3AB52AD5B6FC0752448565B2C34D0F177D88D653624AAF9E06A1695F3046.png?needInitFileName=true?needInitFileName=true)  
如果数据出现错误，库实例仍保持活动状态，可以尝试在下一真实帧渲染期间提供正确的数据。如果缺少某些数据：

* 当数据是可选数据时，则某些功能无法使用。
* 当数据是必填数据时，则将返回FF_ERROR_INSUFFICIENT_INPUT_DATA错误代码。

```
FFResult FrameFlow_ProvidePerFrameData(FFInstance instance, const FFPerFrameData* pPerFrameData);
```

#### 隐式抓取数据

调用函数[FrameFlow_GrabPerFrameData](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflow-grabperframedata-0000001838093769)，可使用默认帧缓冲区以及应用程序创建的其他帧缓冲区来抓取并传递预测帧所需的相关数据（如颜色、深度、模板）。

```
FFResult FrameFlow_GrabPerFrameData(FFInstance instance, FFGrabInfo const *pGrabInfo);
```

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240314102212.52592456748086938414159853545964:50001231000000:2800:39CC39FF702DCFE1912A01937064B58BE2CA741512025BDDB14FBE8F5E540C2A.png?needInitFileName=true?needInitFileName=true)  
此功能可能并非在所有设备上都受支持，例如旧型号或GPU驱动程序反常（GL_RENDERER为Adreno且GL_VERSION包含V@0530）的设备。因此，为了确保运行时支持此功能，在创建库实例时，请将[FFInstanceGrabSupport](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffinstancegrabsupport-0000001838253729)结构添加到FFInstanceCreateInfo的pNext扩展链中，并启用needColor和/或needDepthStencil标志。  

#### 最终颜色

最终颜色和最终蒙版是一种独立于任何选定的预测算法的额外输入数据，它们共同构成了一个类似纹理的RGBA资源（颜色有RGB通道，蒙版有Alpha通道）。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240314102212.54833817388238739088962134522615:50001231000000:2800:2408ABAD6E722833A5B76C3BB1DBDC887B27636104CF9285A10574815FE34DD2.png?needInitFileName=true?needInitFileName=true)  
* 当您在3D场景的顶部渲染UI，并且希望预测帧也包含它们时，可以通过调用[FrameFlow_ProvidePerFrameData](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflow-provideperframedata-0000001791334588)和[FrameFlow_GrabPerFrameData](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflow-grabperframedata-0000001838093769)将帧数据传递到库。使用FrameFlow_ProvidePerFrameData时，可以通过将[FFPerFrameFinalColorData](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffperframefinalcolordata-0000001838093809)添加到pPerFrameData的pNext扩展链中来完成。
* 如果调用方想获得插帧的最终颜色以便直接送显，应将场景颜色和最终颜色传递到插帧SDK。调用方需调用隐式抓取数据函数两次，一次在场景颜色绘制完成后，另一次在叠加UI绘制最终颜色后。同时，调用方还需调用显式抓取数据函数传递物体的相机投影矩阵、摄像机扩展信息等其他帧数据。

最终蒙版是为了提供UI覆盖场景颜色时使用的透明度。

* 当透明度的值为1.0时，表示该像素没有叠加UI，最终颜色与场景颜色相同。
* 当透明度的值为0.0时，表示该像素完全被UI覆盖，最终颜色与UI颜色相同。

通常情况下，它们的关系如下所示：

```
finalColor.rgb == sceneColor.rgb * finalMask + overlayColor.rgb * (1.0 - finalMask)
```

一般情况下，会采用如下方式混合场景颜色和UI颜色，得到最终颜色（不含最终蒙版）：

```
glEnable(GL_BLEND);
glBlendEquation(customMode);
glBlendFunc(customSrcFactor, customDstFactor);
```

如果customMode、customSrcFactor和customDstFactor由游戏指定，为了获取最终蒙版，则可替换为如下代码来获取：

```
glEnable(GL_BLEND);
glBlendEquation(customMode);
glBlendFuncSeparate(customSrcFactor, customDstFactor, GL_ZERO, customDstFactor);
```

例如，当使用传统的Alpha混合时，可采用如下方式获取最终蒙版：

```
glEnable(GL_BLEND);
glBlendEquation(GL_FUNC_ADD);
glBlendFuncSeparate(GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA, GL_ZERO, GL_ONE_MINUS_SRC_ALPHA);
```
