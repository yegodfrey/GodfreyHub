# 请求下载返回码

|宏定义|宏值|说明|
|:------------------------------|:-|:------------------------------------------------------------------------------------------------------|
|SUCCESS|0|成功|
|SERVICE_VERSION_UPDATE_REQUIRED|2|接口依赖高版本，需要引导更新华为应用市场|
|SERVICE_INVALID|4|调用接口时，出现服务异常|
|METHOD_UNSUPPORT|5|方法不支持|
|RESOLUTION_REQUIRED|6|需要通过打开PendingIntent解决，这个表示后续流程由华为应用市场引导。 【注意】只要涉及拉起AG客户端页面的操作，都会返回6， 此时需媒体自行startResolutionForResult处理。|
|NETWORK_ERROR|7|网络异常|
|INTERNAL_ERROR|8|代码内部错误|
|DEVELOPER_ERROR|9|开发者错误|
|TIMEOUT|10|接口访问超时|
|DEAD_CLIENT|12|当前客户端不可用|
|RESPONSE_ERROR|13|服务器返回响应异常|
|LACK_OF_REQUEST_ERROR|14|缺少Request对象|
|PROTOCOL_ERROR|15|未签署华为应用市场协议，需要引导签署华为应用市场协议|
|APP_NOT_ON_SHELF|17|应用未上架|
|APP_DOWNLOADING_BY_OTHER_MEDIA|18|应用已经被其他媒体启动下载|
