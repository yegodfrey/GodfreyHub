# Android

> 说明
>
> 语音消息文件会占用一部分本地存储空间，建议您销毁实例时，删除本地存储的语音文件以释放存储空间。

## 前提条件

* 您已[集成游戏多媒体基础SDK、语音消息模块](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-integratingsdk-android-0000001250838246#ZH-CN_TOPIC_0000001250838246__li733912204487)。
* 如需实现变声，您[还需集成变声模块](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-integratingsdk-android-0000001250838246#ZH-CN_TOPIC_0000001250838246__li733912204487)。
* 您已[创建游戏多媒体实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-engine-android-0000001193958984#section1093713161034)。

## 录制语音消息

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241105115849.61143139595191398608778587253524:50001231000000:2800:F70801A384C0B358504FE284D57EF9BF6414B1C20EB8FEBFD7F6C3C169196F68.png?needInitFileName=true?needInitFileName=true)

1. 当玩家录制语音消息时，需先初始化音频存储路径。 说明
   >
   > 文件路径自行指定，音频文件仅支持.m4a格式。

   ```screen
   filePath = this.getExternalCacheDir().getCanonicalPath() + "/xxx.m4a";
   ```

2. 音频存储路径初始化完成后，开始录制语音消息。
   * 不带变声效果：调用[GameMediaEngine.startRecordAudioMsg(filePath)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section18293153123)方法开始录制语音消息。

     ```screen
     mHwRtcEngine.startRecordAudioMsg(filePath); // filePath:录制的音频文件本地保存地址
     ```

   * 带变声效果：调用[GameMediaEngine.startRecordAudioMsg(filePath, voiceType)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section1558815247152)方法开始录制语音消息。 注意
     >
     > 如实时语音开启了变声特性，则语音消息不支持变声。

     ```screen
     mHwRtcEngine.startRecordAudioMsg(filePath, voiceType); // filePath:录制的音频文件本地保存地址; voiceType:变声类型,原声类型表示关闭变声,其他枚举值请参考https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-model-voicetype-android-0000001773246578
     ```

3. 在语音消息录制过程中，如需结束录制，可通过调用[GameMediaEngine.stopRecordAudioMsg](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section35015551314)方法停止录制。 说明
   >
   > 录制语音消息的最大时长为50s，超过将自动结束录音。

   ```screen
   mHwRtcEngine.stopRecordAudioMsg();
   ```

4. 语音消息录制停止或自动结束时，可在IGameMMEEventHandler接口的[onRecordAudioMsg](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section52431345132119)方法中实现该事件的回调处理。 说明
   >
   > 为了保证语音消息录制效果，建议您此处增加一个判断，即当语音消息时长小于1秒时，提示不发送语音消息。

   ```screen
   @Override
   public void onRecordAudioMsg(String filePath, int code, String msg) {
       LogUtil.i(ROOM_TAG, "filePath:" + filePath + ",code:" + code + ",msg:" + msg);
       // 可根据需求将数据进行处理
   }
   ```

5. 当语音消息录制成功后，可通过调用[GameMediaEngine.uploadAudioMsgFile](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section1666356111311)方法将语音消息文件上传到游戏多媒体服务器。 说明
   >
   > 上传的语音消息文件大小最大支持50MB，在游戏多媒体服务器上将会保留7天。

   ```screen
   mHwRtcEngine.uploadAudioMsgFile(filePath, msTimeOut); // filePath:音频文件的待上传路径; msTimeOut:超时时间, 单位：ms, 取值范围[3000, 7000]
   ```

6. 语音消息文件上传时，可在IGameMMEEventHandler接口的[onUploadAudioMsgFile](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section18500204617215)方法中实现该事件的回调处理。

   ```screen
   @Override
   public void onUploadAudioMsgFile(String filePath, String fileId, int code, String msg) {
       LogUtil.i(ROOM_TAG, "filePath:" + filePath + ",fileId:" + fileId + ",code:" + code + ",message:" + msg);
       // 可根据需求将数据进行处理
   }
   ```

7. （可选）当语音消息文件上传成功后，如需对文件进行风控检测，可调用[GameMediaEngine.startDetectAudioFile](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section85729019159)方法进行送检。

   ```screen
   mHwRtcEngine.startDetectAudioFile(fileId); // fileId: 文件ID
   ```

8. 语音消息文件风控送检时，可在IGameMMEEventHandler接口的[onStartDetectAudioFile](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section9425314316)方法中实现该事件的回调处理。

   ```screen
   @Override
   public void onStartDetectAudioFile(String fileId, int code, String msg) {
       LogUtil.i(ROOM_TAG, "fileId:" + fileId + ",code:" + code + ",message:" + msg);
       // 可根据需求将数据进行处理
   }
   ```

## 发送语音消息

语音消息文件上传完成后，会生成一个语音消息文件ID，可通过IM通道发送文件ID给其他玩家来发送语音消息。游戏多媒体SDK的实时信令功能提供了消息发送通道，语音消息也可以通过该通道完成文件ID传递，具体实现请参见[实时信令](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/rtm-overview-0000001734630053)。

## 播放语音消息

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241105115849.93888775199234623950027603183315:50001231000000:2800:942ADBCED857DB351B24C25B075C6538843EB040D18AE5A03DB28963F723CDAF.png?needInitFileName=true?needInitFileName=true)

1. 当玩家通过IM通道获取到其他玩家传递过来的语音消息文件ID后，可通过调用[GameMediaEngine.downloadAudioMsgFile](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section11348125741317)方法下载该文件。

   ```screen
   mHwRtcEngine.downloadAudioMsgFile(fileId, filePath, msTimeOut);// fileId:文件ID; filePath:文件下载的存储地址; msTimeOut:超时时间, 单位：ms, 取值范围[3000, 7000]
   ```

2. 下载语音消息文件时，可在IGameMMEEventHandler接口的[onDownloadAudioMsgFile](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section133881047102116)方法中实现该事件的回调处理。

   ```screen
   @Override
   public void onDownloadAudioMsgFile(String filePath, String fileId, int code, String msg) {
       LogUtil.i(ROOM_TAG, "filePath:" + filePath + ",fileId:" + fileId + ",message:" + msg);
       // 可根据需求将数据进行处理
   }
   ```

3. 当语音消息文件下载成功后，可通过调用[GameMediaEngine.playAudioMsg](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section9331558101320)方法播放该文件中的语音消息内容。

   ```screen
   mHwRtcEngine.playAudioMsg(filePath);// filePath:播放语音的文件路径
   ```

4. 如需停止播放语音消息，可通过调用[GameMediaEngine.stopPlayAudioMsg](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section11212659141311)方法结束播放。

   ```screen
   mHwRtcEngine.stopPlayAudioMsg();
   ```

5. 播放/停止播放语音消息时，可在IGameMMEEventHandler接口的[onPlayAudioMsg](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section11591648122116)方法中实现相关回调处理。

   ```screen
   @Override
   public void onPlayAudioMsg(String filePath, int code, String msg) {
       LogUtil.i(ROOM_TAG, "filePath:" + filePath + ",code:" + code + ",message:" + msg);
       // 可根据需求将数据进行处理
   }
   ```

6. 当语音消息文件下载成功后，如需了解文件的时长和大小，您还可以通过调用[GameMediaEngine.getAudioMsgFileInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section1465081415)方法获取文件信息。

   ```screen
   mHwRtcEngine.getAudioMsgFileInfo(filePath); // filePath:获取音频文件信息的文件路径
   ```
