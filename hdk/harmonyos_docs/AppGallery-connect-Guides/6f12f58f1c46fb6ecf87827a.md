# 部署模板

使用Serverless模板前，请先为您的项目部署模板。

## 前提条件

您已完成创建AGC项目和应用，具体请参见[创建项目和应用](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-serverless-imgcrop_precfg-0000001318295753#section55472613292)。

## 配置云存储

图片尺寸调整模板在一键部署前，需要添加云存储的存储实例，用于存放待裁剪的图片。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"，在项目列表页面选择模板所在的项目。
2. 选择"云开发（Serverless） > 云存储"，点击"立即开通"。
3. 配置Cloud Storage位置的相关参数。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174804.25998404705519952168934214571494:50001231000000:2800:5880E79B7355ECE7EB4AF5251A08AD4D4584A467F93B3B3E7DC3F51B7FA0AE6B.png)

4. 配置完成后，点击"下一步"，进入"Cloud Storage安全策略"页面，无需配置，点击"完成"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174804.62088315425089814176019006120488:50001231000000:2800:054E9CAF913A8F871A0A715DBC785CB9AB37B86F8381D4E878BD64EA5B4643EA.png)

5. 添加完成后，可以看到已创建的存储实例，点击![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174804.18057261803802820410054388544613:50001231000000:2800:91E1FC11B2CF8E74702869F403BE336E7FF280E29AB0367C30676F17253CC3D6.png)复制存储实例名称到本地的文本中。

## 选择模板

您需要先在Serverless模板列表中找到您需要使用的模板。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中找到您需要使用Serverless模板的项目。
3. 选择"云开发（Serverless） > Serverless模板"，点击右上角"浏览更多Serverless模板"查看并选择Serverless模板。 说明
   >
   > 每个Serverless模板详情卡片都包含该模板的部署方式和使用指南，请仔细查看后选择。

## 部署模板

选择Serverless模板后，您需要将模板部署到您的项目中。

1. 点击您选择的Serverless模板卡片上的"部署"。
2. 选择需要部署Serverless模板的项目。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174804.40769716409623627078153009970481:50001231000000:2800:5E3A7253C7822322388A88BF4BDE9EBA3FE3337CFE96BE0F5048E65B72435ECF.png)

3. 点击"数据处理位置"下拉框，为Serverless模板选择数据处理位置，点击"下一步"。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174804.19463796317657577539270747337271:50001231000000:2800:5EBA71E0F73932D612E9919B1E285D3E38E412BB32E98E138EA289FC9F045835.png) 说明
   >
   > 当前仅支持在数据处理位置为"中国"的项目上部署Serverless模板。
4. 配置使用该Serverless模板需要的参数。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174804.03627346638040410085928630046494:50001231000000:2800:DA5BA52B0CB243A78F27C631442F2BE2ABA08ED17A0C895F440F8A0E756AE97D.png)

   具体参数说明如下：

   |参数|说明|
   |:------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------|
   |云存储实例名|云存储服务中使用的实例名称。 请配置为[配置云存储](#section1152559103919)中已创建的云存储实例名。|
   |调整图片尺寸|图片调整后的宽度和高度。 默认值：200x200 格式：*宽度* x*高度* 多个尺寸值中间可以以英文逗号分隔。 示例：50x50,200x200,400x400|
   |删除原始图片|是否删除云存储中的原始图片。 取值范围： * Yes * No|
   |调整后图片类型|图片调整后，需要转换成的图片格式类型。 取值范围： * jpeg * bmp * png * tiff * original 默认值：original，即表示不进行图片调整，调整后的图片与原始图片相同。|
   |调整后图片存储路径（可选）|图片调整后的文件存放路径。 不配置，则默认存放在根目录。 原始图片调整后文件推荐存放在存储实例的"products/sales/"或"products/out-of-stocks/"路径下。 配置示例： products/sales/ products/out-of-stocks/|
   |调整图片路径（可选）|待调整图片的指定文件存放路径。 如果此路径存在图片文件，则此图片才会被调整。 例如：此参数值配置为"post/detail/cover"时，只有当"post/detail/cover"目录中存在图片文件，则此图片才会被调整。 配置示例： member/profile post/detail/cover|
   |调整图片排除路径（可选）|不进行调整图片的指定文件存放路径。 如果此路径存在图片文件，则此图片不会被调整。 例如：此参数值配置为"post/detail/header"时，当"post/detail/header"目录中存在图片文件，则此图片不会被调整。 配置示例： user/important post/detail/header|

5. 参数配置完成后，点击"下一步"。
6. 在部署页面，点击"开始部署"。 注意
   >
   > 如果部署多次仍失败，请在互动中心[反馈问题](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/interactive/feedback)或[在线提交工单](https://developer.huawei.com/consumer/cn/support/feedback/#/add/89?level2=9069)，华为工作人员将在1～3个工作日内进行处理。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174804.90507763675963212047139496415074:50001231000000:2800:C809BF3D29CC2E757C5D9FE2C173A724086565EDABF5690159DD3A2E976BDC4E.png)

## 配置云函数

图片尺寸调整模板会在一键部署时自动生成模板的函数接口，模板部署成功后，您还需在"云函数"页面为对应的函数接口添加对应的云存储触发器，以实现在云存储的实例中存放图片后自动触发云函数。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"，在项目列表页面选择模板所在的项目。
2. 选择"云开发（Serverless） > 云函数"，在"函数列表"页面根据已部署模板的"实例ID"找到模板对应的函数，点击函数名称进入函数详情页。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174805.20486336565907965743295282716739:50001231000000:2800:F91E46FA7F5536E01249BAF6DCD575857D6F1EFEA3250BBC2633D130E689FAA3.png)

3. 在函数详情页选择"触发器"页签，点击"添加触发器"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174805.75489729829229445414865908989082:50001231000000:2800:918267B1E264F387C75EE35EF71983F870C317BBD56BEAE5955645518DDB3264.png)

4. 在弹出的"添加触发器"窗口中配置触发器相关参数。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174805.02277487712849857061830622599232:50001231000000:2800:0AE02EA931EA4C83DC19673F2E4026461F6570A5461E12FC186CA8025B6D4B2D.png)

   具体参数说明如下表所示。

   |参数|说明|
   |:----|:--------------------------------------------|
   |触发器类型|选择"云存储触发器"。|
   |存储实例|请配置为[配置云存储](#section1152559103919)中保存的存储实例名称。|
   |事件名称|选择"Completed"。|

5. 配置完成后，点击"确定"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174805.63239508331406465179936471981045:50001231000000:2800:1E54EEFE7701CAA5FBB3DB31572BC3B5D07686C7BA1188E2C612CA21FE871A89.png)
