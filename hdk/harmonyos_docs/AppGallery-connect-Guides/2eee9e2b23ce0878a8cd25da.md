# 配置iOS应用信息

当应用平台为iOS时，您需要在AGC配置"App Store ID"和"团队ID"。

1. 在"开发与服务"页面中，点击iOS应用所在项目。
2. 在"项目设置"页面选择"常规"页签。
3. 在"应用"区域，点击![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155404.62447369594853010299922692561374:50001231000000:2800:D2031EE9E4F8A0664B96FE06627D060D0180A01AADDF386A4EF9899B59719AB9.png "点击放大")配置"App Store ID"和"团队ID"，即您应用在App Store上的ID和团队ID，完成后点击![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155404.70493717139518521494977565466012:50001231000000:2800:27005675E8D14396FF69446B9D95902FA958BAE19F4FC9EE40FE68F6F3BA332C.png "点击放大")保存。
