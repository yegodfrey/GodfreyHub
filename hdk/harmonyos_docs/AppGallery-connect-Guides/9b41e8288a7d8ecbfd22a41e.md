# 邮箱

您可以在应用中集成邮箱账号认证方式，您的用户可以使用邮箱地址和密码或者邮箱地址和验证码来登录您的应用。  

#### 前提条件

* 您需要在AGC控制台[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-integration-sdk-0000001326347605)。  

#### 注册

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114609.17398869464268106484802785109106:50001231000000:2800:21B6DFD0EABA44A15C550452E66055D4781072AB6D1A2CFC4B16534A9AC06EF7.png "点击放大")

1. 在使用邮箱注册之前，需要先验证您的邮箱，确保该邮箱账户归您所有。 调用[\[AGCVerifyCodeSettings initWithAction:locale:sendInterval:\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcverifycodesettings-ios-0000001054103662#section12565114311561)生成setting，然后调用[\[AGCEmailAuthProvider requestVerifyCodeWithEmail:settings:\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcemailauthprovider-ios-0000001054103660#section555141641516)申请验证码。

   ```
   "Objective-C"
   AGCVerifyCodeSettings *setting = [[AGCVerifyCodeSettings alloc] initWithAction:AGCVerifyCodeActionRegisterLogin 
                                                                           locale:nil 
                                                                     sendInterval:30];  
   [[[AGCEmailAuthProvider requestVerifyCodeWithEmail:email settings:setting] addOnSuccessCallback:^(AGCVerifyCodeResult * _Nullable result) {
       // 验证码申请成功
   }] addOnFailureCallback:^(NSError * _Nonnull error) {
        // 验证码申请失败
    }];
   ```

   ```
   "Swift"
   let setting = AGCVerifyCodeSettings.init(action:AGCVerifyCodeAction.registerLogin, locale:nil, sendInterval:30)
   AGCEmailAuthProvider.requestVerifyCode(withEmail:email, settings:setting).onSuccess{ (result) in
       // onSuccess
   }.onFailure{ (error) in
       // onFailure
   }
   ```

2. 使用邮箱账号注册用户。 调用[\[AGCAuth createUserWithEmail:password:verifyCode:\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346#section9729135791613)注册用户。注册成功后，系统会自动登录，无需再次调用登录接口。

   ```
   "Objective-C"
        [[[[AGCAuth getInstance] createUserWithEmail:email password:password verifyCode:code] addOnSuccessCallback:^(AGCSignInResult * _Nullable result) {
             // onSuccess
             AGCUser *user = result.user;
        }] addOnFailureCallback:^(NSError * _Nonnull error) {
            // onFail
        }];
   ```

   ```
   "Swift"
   AGCAuth.instance().createUser(withEmail:email, password:password, verifyCode:code).onSuccess{ (result) in
       // onSuccess
   }.onFailure{ (error) in
       // onFailure
   }
   ```

3. 登录成功后可以调用[\[AGCAuth currentUser\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346#section5731134619333)获取用户账号数据。  

   ```
   "Objective-C"
   AGCUser *user = [[AGCAuth getInstance] currentUser];
   ```

   ```
   "Swift"
   let user = AGCAuth.instance().currentUser
   ```

#### 密码登录

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114609.99355490538584871149399882335125:50001231000000:2800:54C41FA7378DE4AD7062B207DE28201BF4CEAB5D407D87B85E385FC10ECCB6C7.png "点击放大")

1. 在应用的登录界面，初始化[AGCAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346)实例，获取AGC的用户信息，检查是否有已经登录的用户。如果有则可以直接进入用户界面，否则显示登录界面。  

   ```
   "Objective-C"
   AGCUser *user = [[AGCAuth getInstance] currentUser];
   ```

   ```
   "Swift"
   let user = AGCAuth.instance().currentUser
   ```

2. 调用[\[AGCEmailAuthProvider credentialWithEmail:password:\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcemailauthprovider-ios-0000001054103660#section09861710201518)用密码方式创建Email账号凭证。  

   ```
   "Objective-C"
   AGCAuthCredential *credential = [AGCEmailAuthProvider credentialWithEmail:email password:password];
   ```

   ```
   "Swift"
   let credential = AGCEmailAuthProvider.credential(withEmail:email, password:password)
   ```

3. 获取credential成功后，调用[\[AGCAuth signIn:\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346#section488155612616)实现登录。  

   ```
   "Objective-C"
   [[[[AGCAuth getInstance] signIn:credential] addOnSuccessCallback:^(AGCSignInResult * _Nullable result) {
            // onSuccess
            AGCUser *user = result.user;
        }] addOnFailureCallback:^(NSError * _Nonnull error) {
            // onFail
        }];
   ```

   ```
   "Swift"
   AGCAuth.instance().signIn(credential: credential).onSuccess{ (result) in
       // onSuccess
   }.onFailure{ (error) in
       // onFailure
   }
   ```

4. 登录成功后可以调用[\[AGCAuth currentUser\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346#section5731134619333)获取用户账号数据。  

   ```
   "Objective-C"
   AGCUser *user = [[AGCAuth getInstance] currentUser];
   ```

   ```
   "Swift"
   let user = AGCAuth.instance().currentUser
   ```

1. 申请验证码。 调用[\[AGCVerifyCodeSettings initWithAction:locale:sendInterval:\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcverifycodesettings-ios-0000001054103662#section12565114311561)生成setting，然后调用[\[AGCEmailAuthProvider requestVerifyCodeWithEmail:settings:\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcemailauthprovider-ios-0000001054103660#section555141641516)申请验证码。

   ```
   "Objective-C"
   AGCVerifyCodeSettings *setting = [[AGCVerifyCodeSettings alloc] initWithAction:AGCVerifyCodeActionResetPassword 
                                                                           locale:nil 
                                                                     sendInterval:30];  
   [[[AGCEmailAuthProvider requestVerifyCodeWithEmail:email settings:setting] addOnSuccessCallback:^(AGCVerifyCodeResult * _Nullable result) {
       // 验证码申请成功
   }] addOnFailureCallback:^(NSError * _Nonnull error) {
        // 验证码申请失败
    }];
   ```

   ```
   "Swift"
   let setting = AGCVerifyCodeSettings.init(action:AGCVerifyCodeAction.resetPassword, locale:nil, sendInterval:30)
   AGCEmailAuthProvider.requestVerifyCode(withEmail:email, settings:setting).onSuccess{ (result) in
       // onSuccess
   }.onFailure{ (error) in
   // onFailure
   }
   ```

2. 调用[\[AGCAuth resetPasswordWithEmail:newPassword:verifyCode:\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346#section2488113101718)重置密码。

   }

#### 更多信息

* 您如果想让用户可以使用多个账号登录您的应用，可以将多个[账号进行关联](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-associated-0000001053053982)。
* 当用户不需要使用应用，或者需要切换其他账号登录认证，可以先执行[登出](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-sign-out-0000001053692708)。
* 当用户需要注销当前用户，可以进行[销户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-deleteuser-0000001057460873)。
* 对于销户、修改密码、关联账号以及重置手机账号和邮箱账号等敏感操作，为了提高安全性，需要用户必须在5分钟内登录过才能执行。如果用户执行敏感操作时登录超过5分钟，需要[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-reauthenticate-0000001127283387)后再执行敏感操作。
* 您可以参考[异常处理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-troubleshooting-0000001054715191)实现自己的异常处理机制，从而减少异常情况的发生。
* 您可以使用云函数触发器来接收用户注册、登录、销户等关键事件，从而[扩展认证服务的能力](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-extension-0000001053372708)。
* 您可以参考[管理用户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-user-manage-0000001606051705)对用户进行解锁、停用等操作。
