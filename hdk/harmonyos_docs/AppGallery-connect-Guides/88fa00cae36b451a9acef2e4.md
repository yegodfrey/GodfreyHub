# 创想绘画

你是否还记得自己开发/参与开发的第一款APP？

彼时，又是怎样的一个契机？

对于高飞而言，他的契机可能和很多人一样，来自校园！也正是校园的开发经历，让他与"绘画"结下了特别的缘分。  

#### 坚守初心，依旧是那句"产品有人用就好"

"便于单手持握的2D涂鸦软件"，面对这样一个赛题，你会如何设计、开发？

2014年，刚刚大二的高飞参加了一个全国性比赛，并就上述赛题开发了他的首款APP"涂鸦画图"。

"很可惜，当时比赛成绩并不好，但毕竟是自己开发的APP，即便是困难时刻，也没有放弃。"高飞提到，"2018年，应用审核越来越严格，软著成为必选项。看着应用被下架，心里很难受。那时候，不但要为软著奔波，还在UI、产品功能等方面做了大量优化。"

值得开心的是，他的努力没有白费。2019年，"涂鸦画图"重新在各大应用商店上架。

"当时没有想太多，就希望产品有人用，就满足了"。对他来说，更多的是坚守初心。  

#### 抢滩蓝海，分布式能力让绘画体验更优

同样是2019年，华为开发者大会正式发布了HarmonyOS。面对这一全新生态，高飞及其团队看到了无限潜力，他们为此专门开发了HarmonyOS应用------创想绘画。

"创想绘画"集绘画、涂鸦功能于一体，支持多图层绘画、文字绘制、贴图等作画能力。但这还不够，市场上，绘画应用很多，除了这些，要想在一众竞品中脱颖而出，"HarmonyOS分布式能力"是关键。

"创想绘画"充分利用远程启动FA、跨端流转、分布式文件管理等特性，实现了多人协作绘画的交互体验。

用户仅需点击"跨端流转"按钮，绘画数据即可从一台设备流转到另外一台设备，支持多人间隔绘画；远程分享功能则允许将作品分享给同账号的另外一台设备，不受距离的约束，两台设备独立绘画。

高飞相信，这将是"创想绘画"相较其它绘画软件更具优势的地方，而这个曾经笑说"比赛成绩并不好"的开发者，也逐步崭露头角、脱颖而出。

在第二届"HarmonyOS开发者创新大赛"上，"创想绘画"获得"三等奖"。  

#### 即点即用，探索更优的服务体验

创想绘画APP上架后，如何更好地优化用户体验，缩短交互层级，提高转化率，是团队一直思考的事情。

"元服务的特性是我们一直关注的，与APP相比，它更轻量化，无感升级，系统静默安装，无须开发者去处理服务升级逻辑。"高飞表示，"用户将'创想绘画'元服务加桌后，仅需点击桌面卡片，即可进入绘画页面，即点即用，交互层级更少，体验更佳。"

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250512150605.03512945254383907561606999583367:50001231000000:2800:5F394591FED5A7BA53D4851B066782EE6A0CEE185ADEFD5CAF37FD43D129E0E6.png)

截止目前，使用该元服务的用户已超1000w。其集涂鸦、绘画于一体，专业的绘画高手或是初学者，都能在此创造出属于自己的作品。

"我们收到了很多用户反馈，他们发来了很好的建议，也促使我们开发更好的元服务。"高飞说，"不仅是'创想绘画'，目前我们的'创想表情包'元服务也已上架。"  

#### 产品研发，理想与现实的碰撞

虽然有APP和快应用开发经验的加持，但团队的元服务开发工作并不是一帆风顺的。

团队规模小，开发资源有限，如何能低成本、高效率的交付产品？

"这就多亏了之前的产品开发经验了。"高飞笑道。

"如何提高开发效率"是第一款APP"涂鸦画图"时期，就在研究的问题。那时候，华为的各类开放能力，如华为账号服务、华为支付、HUAWEI AppGallery Connect（以下简称"AGC"） 的Serverless等能力成为了他手中的"利器"。

元服务的开发，是否也可以这样？事实证明，行得通！

在以ArkTS语言和ArkUI框架开发的元服务中，高飞团队接入了AGC Serverless的云函数、云数据库、认证服务以及Serverless抽奖模板。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250512150605.40341058592190402420103370011984:50001231000000:2800:0C0905AF94E87FBBF35F1B21E661246A1A91D7DD65E9D4E33F4B4F53C7A69EF1.png)

"云函数和云数据库主要用于开发统计相关的功能（如：服务打开统计，服务使用统计，广告数据统计等），它取代了部分传统的http接口开发，帮助产品高效开发、快速上线、免运维。我们无需考虑服务器扩容的问题，即使是6000w的数据，仍然可以保证高度可用性。"高飞提到，"此次还接入了Serverless抽奖模板能力，'抽奖赢VIP'作为一个重要的运营动作，可以吸引用户每天登录提高日活，提高广告曝光。传统开发方式，涉及前端开发、服务端开发、联调与测试，需要8人天，但部署抽奖模板 仅需半人天即可。"

目前高飞团队的元服务开发迭代还在持续中，他们也希望关于HarmonyOS的开发资料能进一步完善，保障产品功能的开发与实现。
