# 自定义预览页

聚合链接自定义预览页功能，帮助您在AGC控制台创建聚合链接时自定义预览页的展示内容，提升您的应用安装率。目前，"自定义预览页"功能仅受限对外开放。如需使用该功能，您需要向agconnect@huawei.com发送申请邮件申请开通。邮件标题请使用如下格式："[聚合链接自定义预览页功能] +[应用名称]+[Developer ID]"。

## 自定义编辑

为了匹配不同的应用和浏览器，聚合链接自定义预览页功能提供了单按钮和双按钮两种样式的编辑框。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250715120032.67138387042758144683356609592857:50001231000000:2800:0AD2758587CC77BE326DC739A9013C1A6D12D79DDE9CEAFC706E6D6646D072B1.png)

* 您可在html编辑框中输入包含文字、图片、视频等内容的html代码，并对输入内容的字体、颜色、大小以及样式结构等属性进行调整或设置，具体请参见[参考示例样式](#section1038728105118)。
* 您还可以将含有预览页内容的html代码输入到编辑框中，并设置相关按钮，具体请参见[拷贝预览页代码](#section69981623105210)。

> 说明
>
> 建议您在两个样式的编辑框中输入相同内容（按钮除外），否则会造成不同浏览器显示预览页不一致的情况。同时，由于不同终端设备的分辨率差异，建议您采用样式自适应的方式展示相关内容。

### 参考示例样式

根据编辑框中内置的html代码，您可以对预览页内容如背景、标题与文案、音视频等进行编辑设置。
> 注意
>
> 编辑框中内置的"openOrDownloadApp"、"openApp"、"downloadApp"及"isAllowClip"控件及相关触发脚本必须保留，否则会导致其功能无法使用。目前，单个编辑框最大支持60K字节。

* 在agc-preview-background下的width和height中可以调整预览页的背景宽度和高度，在agc-preview-background下的background中可编辑设置背景内容。 说明
  >
  > 背景内容中的图片支持PNG、JPG、JPEG、BMP、GIF和WebP图片格式，单张图片大小最大为4MB。

### 拷贝预览页代码

如果您的预览页已通过工具生成，您可以将其html代码拷贝到编辑框中，并设置相关按钮及其样式属性。

1. 删除自定义预览页编辑框中内置的html代码demo。
2. 将您的预览页html代码拷贝到编辑框中。 说明
   > * 目前，单个编辑框最大支持60K字节。
   > * 背景内容中的图片支持PNG、JPG、JPEG、BMP、GIF和WebP图片格式，单张图片大小最大为4MB。
   > * 视频内容支持扩展名为AVI、WMV、MPG、MPEG、MP4、MOV、M4V和MKV的视频文件，单个视频大小最大为4GB。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250715120032.64713285449753617332639014964313:50001231000000:2800:4DDFB9C80F5BE198327D8C2F93C42877B8AD88BA2ED805E0BBCC0F59D2471103.png "点击放大")
3. 在<body>下添加如下代码，设置相关按钮及其触发脚本。 注意
   >
   > "openOrDownloadApp"、"openApp"、"downloadApp"及"isAllowClip"按钮及相关触发脚本必须添加，否则会导致其功能无法使用。
   * **单按钮**

     ```screen
     <div class="agclink-bottom">
       <div class="agc-btn">
         <button class="agclink-btn btn-mt10" onclick="{{openOrDownloadApp}}">打开或下载应用</button>
       </div>
       <div class="link-checkbox">

         <span class="text">复制链接地址到剪贴板，以支持延迟深度链接</span>
     ```

   * **双按钮**

     ```screen
     <div class="agclink-bottom">
       <div class="agc-btn">
         <button class="agclink-btn btn-mt10 agclink-btn-gray" onclick="{{openApp}}">打开应用</button>
         <button class="agclink-btn btn-mt20" onclick="{{downloadApp}}">下载应用</button>
       </div>
       <div class="link-checkbox">
         <label><input type="checkbox" checked="true" id="{{isAllowClip}}" class="check-box" /><span></span></label>
         <span class="text">复制链接地址到剪贴板，以支持延迟深度链接</span>
     ```

## 风控扫描

为了降低自定义预览页内容中可能因涉嫌"黄赌毒"等敏感内容而被禁止访问的风险，自定义预览页功能接入了风控系统。当您在AGC控制台成功创建并发布了聚合链接，风控系统将会对聚合链接预览页内容进行扫描，并对可能含有敏感内容预览页的聚合链接提供风险标识提示。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250715120033.24218417166425234995676993946245:50001231000000:2800:C75A36D33B8471B8F9CCB7061979BCE2F6C5EB2F6A30399BB4BE1DA3CB865016.png)

当前，扫描结果中给出的风险提示并不会影响您的链接使用，但如果您的自定义内容中的确存在以下问题，您的自定义预览页可能会被禁止访问。因此，建议您参考扫描结果前往优化。
