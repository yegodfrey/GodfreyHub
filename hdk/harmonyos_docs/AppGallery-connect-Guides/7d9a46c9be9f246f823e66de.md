# 设置游戏配置信息（可选）

游戏在不同设置（帧率、是否开启抗锯齿等）下，性能表现不尽相同，您可以在游戏启动及玩家设置变更时调用接口传入游戏设置组合信息。  

#### 前提条件

* 已[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-integration-android-0000002022406709)。
* 已[初始化SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-initialization-android-0000002022526269)。
* 已[开启数据采集器](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-open-close-collector-android-0000001985966666#section72707115441)。  

#### 开发步骤

1. 调用[GPMManager.setGameConfigurations](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-android-api-gpmmanager-0000002022527745#section636113398576)，设置游戏配置信息，设置后SDK会在采集的性能数据中携带您传入的游戏配置信息。

   ```
   GPMManager.setGameConfigurations("3;3;50;1280*720;true;true;true;true;true");
   ```

2. 调用后可在GPMCallback接口的[onSetGameConfigurations](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-android-api-gpmcallback-0000001988789820#section164848368126)方法中查看结果并实现回调处理。

   ```
   @Override
   public void onSetGameConfigurations(int code, String msg)
   {
       // GPMManager.setGameConfigurations接口通过子线程回调通知接口结果。由于大部分API需要在主线程中调用，请在onSetGameConfigurations回调中合理处理。
       if(code == GPMError.GPM_SUCCESS) 
       {
          // 设置游戏配置信息成功
       }
   }
   ```
