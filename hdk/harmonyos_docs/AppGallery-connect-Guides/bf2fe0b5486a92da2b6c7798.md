# 概述

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260122141034.49399643899110642588077663915672:50001231000000:2800:A1AC289BC0763A06B38C255CA43998BAA05F9544C6D58D4A80E56E04E91B06CD.png)  
因业务调整需要，自2025年11月4日起不再支持创建"http请求"触发方式的云函数。请创建"事件调用"触发方式的云函数，具体请参见[通过HTTP触发器调用函数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloud-function-call-via-httptrigger-0000001512012404)。

当前仅Java语言的Server SDK支持构造HTTP请求调用函数。

SDK提供了两种接口来构造HTTP请求调用函数。

* callHttpOnClient()接口 此接口可以在任意环境请求被调函数。任意环境包括公网和云函数运行环境。

  ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260122141034.78845875710569417441074880379079:50001231000000:2800:40A49C430AF35DF8F47C06F2430623BC941B7BEF3E956A94EF51F5BE61642097.png)  
  * 公网请求被调函数时，需要跨AGC云侧网关。
  * 云函数运行环境请求被调函数时，属于内网调用，不需要跨AGC云侧网关。
  * 云函数运行环境是指实现函数基于Java语言的custom-runtime运行环境。
* callHttpOnCloud()接口 此接口仅能在云函数运行环境请求被调函数。此接口比callHttpOnClient()接口的请求时延更小。
