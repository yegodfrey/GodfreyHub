# PMS API V1至V2接口升级指南

## 概述

本文指导开发者从华为商品管理系统PMS API的V1接口迁移至V2接口，重点说明商品管理相关接口的适配点及V2接口新增能力。
> 说明
>
> 本文中的V1接口指的是针对Android应用的PMS API接口，V2接口指的是针对HarmonyOS NEXT应用的PMS API接口。

## 主要变更点

### 新增接口

|**V2新增接口**|**功能**|
|:-------------------------------------------------------------------------------------------------------------------------------------------------|:----------------|
|[提交商品审核](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-reviewproduct-harmonyosnext-0000002166681241)|商品创建/更新后需提交审核。|
|[上传资源](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-resourcemanage-harmonyosnext-0000002131361792)|提交商品审核资源，当前仅支持图片。|
|[查询关联APP已有商品类型](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-basicapplication-harmonyosnext-0000002131519928)|辅助创建商品时选择类型。|
|[更新商品订阅分组等级信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-levelgroup-harmonyosnext-0000002175107485)|更新订阅分组等级。|

## 升级详细步骤

### 创建商品

|接口|V1|V2|
|------|----------------|-------------------------------------------------------------------------------------------------------------------------------------|
|步骤|直接调用创建商品，无需审核流程。|1. 上传资源（上传资源接口）获取reviewResourceId。 2. 调用创建商品，填写reviewPath、reviewResourceId，商品状态只能传drafts。 3. 调用提交商品审核让商品进入审核流程。 说明 > 商品不能是新增的商品类型的商品。|
|V2示例代码|```screen # 上传资源 POST https://connect-api.cloud.huawei.com/api/pms/product-price-service/v2/manage/resource # 创建商品（状态=drafts) POST https://connect-api.cloud.huawei.com/api/pms/product-price-service/v2/manage/product # 提交审核 POST https://connect-api.cloud.huawei.com/api/pms/product-price-service/v2/manage/product/review ```||

### 更新商品信息

|接口|V1|V2|
|------|----------------|-------------------------------------------------------------------------------------------|
|步骤|直接更新商品信息，无需审核流程。|1. 仅更新价格/促销信息：与V1相同，无需审核。 2. 更新本地化信息（如名称，描述，审核信息）：需填写reviewPath、reviewResourceId，并调用提交商品审核。|
|V2示例代码|```screen # 更新商品 PUT https://connect-api.cloud.huawei.com/api/pms/product-price-service/v2/manage/product # 提交审核 POST https://connect-api.cloud.huawei.com/api/pms/product-price-service/v2/manage/product/review ```||

### 批量操作(批量创建/更新)

|接口|V1|V2|
|--|-----------------|--------------------------------------------------------------------------------|
|步骤|填写商品信息，批量创建、更新即可。|* 批量创建：与单条创建逻辑相同，需先上传资源，再提交审核。 * 批量更新：更新仅影响本地化信息（名称，描述，审核信息）时需走审核流程，更新价格/促销更新不变。|

## 常见问题&注意事项

* 需**适配**
  * HarmonyOS NEXT应用的商品在调用V2接口创建后，需走商品审核流程（drafts→提交审核）。
  * 更新本地化信息需重新提交商品审核（比如修改商品名称、商品简介等信息）。
  * 资源（应用内截图）需先上传，获取reviewResourceId。
* **兼容性** 问题:
  * V1接口创建的已有商品：可继续使用，但更新时需遵循V2规则。
  * 混合场景：如果云侧需同时支持V1&V2的商品，需区分处理。

## 建议升级步骤

1. 先测试沙盒环境，确保商品审核流程正常。
2. 采取分批迁移，优先适配核心商品管理功能。
3. 监控商品审核状态，避免因审核失败导致商品不可用。
