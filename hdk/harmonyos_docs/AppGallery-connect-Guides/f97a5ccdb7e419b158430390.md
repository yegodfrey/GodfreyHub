# 集成内嵌社区SDK

游戏内嵌社区SDK能够在游戏内设置内嵌社区入口，让玩家可以在游戏内进入华为游戏论坛。玩家可以在内嵌社区中浏览游戏攻略，查看精彩资讯内容；也可以直接发布帖子到论坛，发起和参与投票；还可以与其他玩家进行回复、点赞等互动。在启动开发游戏内嵌社区前，您需要将游戏内嵌社区SDK集成到您的Android 工程中。

SDK名称：游戏内嵌社区SDK（Android版）

包名：com.huawei.game.moment.sdk

版本号：13.5.1.301

md5值：9689f9c90c721495b6999266e03cbea5

开发者：华为软件技术有限公司

个人信息处理规则：[SDK隐私声明](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/pgsmoment-sdk-security-0000001713760973)

合规指引：[SDK合规使用指南](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/pgsmoment-sdk-compliance-guidelines-0000001665681436)

## 添加当前应用的AppGallery Connect配置文件

如果在AppGallery Connect中开通了相关服务则需要将"agconnect-services.json"文件添加到您的App中。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目中点击需要集成SDK的应用。
3. 在"项目设置 > 常规"页面的"应用"区域，点击"agconnect-services.json"下载配置文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/df/v3/VI7m8Vt7QjS7uagOndpd7Q/zh-cn_image_0000001607140841.png?HW-CC-KV=V1&HW-CC-Date=20260909T155204Z&HW-CC-Expire=31536000000&HW-CC-Sign=0117DD563B79BFA4C1C85AC63D88EDADE8484B5CD16C318F75C86EBAFE5E07ED)
4. 将"agconnect-services.json"文件拷贝到应用级根目录下。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/78/v3/5Z4mGsIkQju5v3z1Yk_mhg/zh-cn_image_0000001343414581.png?HW-CC-KV=V1&HW-CC-Date=20260909T155204Z&HW-CC-Expire=31536000000&HW-CC-Sign=C7CADDECAA8B2688B887A1C88232ABDF1CCC4485E7CFE6E92FBF66419F1F643D)

## 配置SDK的Maven仓地址

Android Studio的代码库配置在Gradle插件[7.0以下版本](#ZH-CN_TOPIC_0000001291610961__zh-cn_topic_0000001050041594_li547444421611)、[7.0版本](#ZH-CN_TOPIC_0000001291610961__zh-cn_topic_0000001050041594_li1796424071918)和[7.1及以上版本](#ZH-CN_TOPIC_0000001291610961__zh-cn_topic_0000001050041594_li1345452582116)有所不同。请根据您当前的Gradle插件版本，选择对应的配置过程。
> 说明
>
> Maven仓地址无法直接在浏览器中打开访问，只能在IDE中配置。如需添加多个Maven代码库，请将华为公司的Maven仓地址配置在最后。

* **7.0以下版本**
  1. 打开Android Studio项目级"build.gradle"文件。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/21/v3/TUNDQM6mTKWCPzqBXO6xqQ/zh-cn_image_0000001381530640.png?HW-CC-KV=V1&HW-CC-Date=20260909T155204Z&HW-CC-Expire=31536000000&HW-CC-Sign=CE5CA21C9BEF2EF0EC83D974970D0107CCD7DEE01B6511C4A99603D27D9CA6F3)
  2. 添加HUAWEI AGC插件以及Maven代码库。
     * 在"buildscript > repositories"中配置SDK的Maven仓地址。
     * 在"allprojects > repositories"中配置SDK的Maven仓地址。
     * 如果App中添加了"agconnect-services.json"文件则需要在"buildscript > dependencies"中增加AGC插件配置。
     * 若集成13.5.1.301及以上版本SDK，无需配置HMF插件。若集成其他版本的SDK，需要在"buildscript > dependencies"中增加HMF插件配置。

     ```screen
     buildscript {
         repositories {
             google()
             // 配置jcenter地址
             jcenter()
             // 配置SDK的Maven仓地址。
             maven {url 'https://developer.huawei.com/repo/'}
         }
         dependencies {
             ...
             // 增加AGC插件配置，请您参见https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-sdk-changenotes-0000001058732550#section7117746172220选择合适的AGC插件版本。
             classpath 'com.huawei.agconnect:agcp:1.6.0.300'
             // 增加HMF插件配置，若集成13.5.1.301及以上版本SDK，无需配置。   
             classpath 'com.huawei.hmf:mdp:1.5.2.206'
         }
     }

     allprojects {
         repositories {
             google()
             // 配置jcenter地址
             jcenter()
             // 配置SDK的Maven仓地址。
             maven {url 'https://developer.huawei.com/repo/'}
         }
     } 
     ```

* **7.0版本**
  1. 打开Android Studio项目级"build.gradle"文件。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6e/v3/EhdpxSbCRymtZ3Tv2Da0xQ/zh-cn_image_0000001381690160.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T155204Z&HW-CC-Expire=31536000000&HW-CC-Sign=D4542796AD17137BA3A2336E17930503ADFF3573D660D8CB6E54018F674B4094)
  2. 添加HUAWEI AGC插件以及Maven代码库。
     * 在"buildscript > repositories"中配置SDK的Maven仓地址。
     * 如果App中添加了"agconnect-services.json"文件则需要在"buildscript > dependencies"中增加AGC插件和Android Gradle插件配置。
     * 若集成13.5.1.301及以上版本SDK，无需配置HMF插件。若集成其他版本的SDK，需要在"buildscript > dependencies"中增加HMF插件配置。

     ```screen
     buildscript {
         repositories {
             google()
             // 配置jcenter地址
             jcenter()
             // 配置SDK的Maven仓地址。
             maven {url 'https://developer.huawei.com/repo/'}
         }
         dependencies {
             ...
             // 增加Android Gradle插件版本号配置，{version}为实际的Gradle插件版本号，例如7.0.1。
             classpath 'com.android.tools.build:gradle:{version}'
             // 增加AGC插件配置，请您参见https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-sdk-changenotes-0000001058732550#section7117746172220选择合适的AGC插件版本。
             classpath 'com.huawei.agconnect:agcp:1.6.0.300'
             // 增加HMF插件配置，若集成13.5.1.301及以上版本SDK，无需配置。   
             classpath 'com.huawei.hmf:mdp:1.5.2.206'
         }
     }
     ```

  3. 打开项目级"settings.gradle"文件，配置SDK的Maven仓地址。

     ```screen
     dependencyResolutionManagement {
         ...
         repositories {
             google()
             // 配置jcenter地址
             jcenter() 
             // 配置SDK的Maven仓地址。
             maven {url 'https://developer.huawei.com/repo/'}
         }
     }
     ```

* **7.1及以上版本**
  1. 打开Android Studio项目级"build.gradle"文件。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4c/v3/MYFqUlT_Tq-1grEuAOF4Lg/zh-cn_image_0000001432209529.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T155204Z&HW-CC-Expire=31536000000&HW-CC-Sign=F2CAF2CD7B59B7BAE6A5F4CE7B954DAD4AFD00018229DEB575CF0F6718A4A300)
  2. 如果App中添加了"agconnect-services.json"文件则需要在"buildscript > dependencies"中增加AGC插件和Android Gradle插件配置。此外，若集成13.5.1.301及以上版本SDK，无需配置HMF插件。若集成其他版本的SDK，需要增加HMF插件配置。

     ```screen
     buildscript {
         dependencies {
             ...
             // 增加Android Gradle插件版本号配置，{version}为实际的Gradle插件版本号，例如7.1.1。
             classpath 'com.android.tools.build:gradle:{version}'
             // 增加AGC插件配置，请您参见https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-sdk-changenotes-0000001058732550#section7117746172220选择合适的AGC插件版本。
             classpath 'com.huawei.agconnect:agcp:1.6.0.300'
             // 增加HMF插件配置，若集成13.5.1.301及以上版本SDK，无需配置。   
             classpath 'com.huawei.hmf:mdp:1.5.2.206'
         }
     }
     plugins {
         ...
     }
     ```

  3. 打开项目级"settings.gradle"文件，配置SDK的Maven仓地址。

     ```screen
     pluginManagement {
         repositories {
             gradlePluginPortal()
             google()
             mavenCentral()
             // 配置SDK的Maven仓地址。
             maven { url 'https://developer.huawei.com/repo/' }
         }
     }
     dependencyResolutionManagement {
         ...
         repositories {
             google()
             mavenCentral()
             // 配置SDK的Maven仓地址。
             maven { url 'https://developer.huawei.com/repo/' }
         }
     }
     ```

## 添加编译依赖

1. 打开应用级的"build.gradle"文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b1/v3/TynTouMbQ46NHgaTKNnfDg/zh-cn_image_0000001343653909.png?HW-CC-KV=V1&HW-CC-Date=20260909T155204Z&HW-CC-Expire=31536000000&HW-CC-Sign=0F64E3EEE6D682F8082B385CEC88F10DBE2B054AB6C1D4E2E47A9BE8F7CF7D3B)
2. 在"dependencies"中添加如下编译依赖。

   ```screen
   dependencies {
        // 增加游戏内嵌社区sdk依赖，推荐您使用https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/pgsmoment-releasenotes-0000001294267330的内嵌社区SDK。
        implementation 'com.huawei.game.moment.sdk:gamemomentsdk:13.5.1.301'
   }
   ```

3. 添加agcp和hmf插件配置。请根据实际情况选择（若集成13.5.1.301及以上版本SDK，无需配置HMF插件。若集成其他版本的SDK，需要配置HMF插件）：
   * 方式一：在文件头部声明下一行添加如下配置。

     ```screen
     apply plugin: 'com.huawei.agconnect'
     //若集成13.5.1.301及以上版本SDK，无需配置。
     apply plugin: 'com.huawei.hmf.modulediscoverer'
     ```

   * 方式二：在**plugins** 中添加如下配置。

     ```screen
     plugins {
         id 'com.android.application'
         // 添加如下配置
         id 'com.huawei.agconnect'
         //若集成13.5.1.301及以上版本SDK，无需配置。
         id 'com.huawei.hmf.modulediscoverer'
     }
     ```

## 为您的Android工程设置权限和主题

若集成12.7.1.300及以上版本的SDK，您无需设置权限和主题。若集成其它版本的SDK，请在您的工程的AndroidManifest.xml文件的application标签下：

* 设置"requestLegacyExternalStorage"为"true"。
* 设置AppCompat主题"theme"为"@style/Theme.AppCompat.Light.NoActionBar"。

  ```screen
  <application
          android:allowBackup="true"
          android:icon="@mipmap/ic_launcher"
          android:label="@string/app_name"
          android:roundIcon="@mipmap/ic_launcher_round"
          android:supportsRtl="true"
          android:requestLegacyExternalStorage="true"
          android:theme="@style/Theme.AppCompat.Light.NoActionBar">
  ```
