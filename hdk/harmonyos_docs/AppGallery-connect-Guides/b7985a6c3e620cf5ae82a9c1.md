# 技术支持

当您集成插帧服务遇到问题时，可以按照以下顺序寻求帮助。

1. 请先仔细阅读文档，部分API函数调用有限制，请参见[使用限制](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/predict-frame-restrictions-0000001580492848)。
2. 查看返回码（[OpenGL](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffresult-0000001838093829)丨[Vulkan](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffresult-vulkan-0000001791494504)）
3. 通过[智能客服](https://developer.huawei.com/consumer/cn/customerService/#/bot-dev-top/faq-top/faq-talk-top)查找问题解决方案。
4. 登录[华为开发者论坛](https://developer.huawei.com/consumer/cn/forum/block/ag-connect)和[Stack Overflow社区](https://stackoverflow.com/questions/tagged/appgallery-connect)参与问题讨论。
5. 如果以上方法仍未解决您的问题，可以通过[在线工单系统](https://developer.huawei.com/consumer/cn/support/feedback/#/add/89?level2=201650609502456486)与我们进行联系，提交后的工单可在开发者联盟"管理中心"的"开发者中心 \> 我的客服"页面查看工单处理进展。
