# 转让房主身份

如果房主想让出房主权限，可将房主身份转让给房间中的其他玩家。

## 前提条件

* 房间为小队语音或国战语音房间。
* 您为房主身份，且房间中已有其他玩家。

## 开发步骤

1. 调用[HWPGMEngine.getInstance transferOwner](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section6998176154719)方法可直接转让房主身份给房间中的其他玩家。

   ```screen
   // 原房主无需离开房间，转让房主给其他玩家
   HWPGMEngine *pgmeEngine = [HWPGMEngine getInstance];
   [pgmeEngine transferOwner:roomId ownerId:newOwnerId];
   ```

2. 当玩家转让房主身份时，可在HWPGMEngineDelegate接口的[onTransferOwner](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section947414915596)方法中实现相关回调处理。

   ```screen
   - (void)onTransferOwner:(NSString* _Nonnull)roomId code:(int)code msg:(NSString* _Nonnull)msg {
       // 可根据需求将数据进行处理
   }
   ```
