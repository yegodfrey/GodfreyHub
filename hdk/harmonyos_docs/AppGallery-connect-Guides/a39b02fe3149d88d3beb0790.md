# 应用内支付

#### 支付

联运服务需要接入应用内支付功能，请参见[华为支付开发指南](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/dev-process-0000001050033070)开发应用内支付相关功能。  

#### 退款

#### 人工退款

已支付的订单如需进行退款，您可以联系华为运营人员进行资质审核，通过审核的应用才能支持退款。退款申请根据退款金额可能会触发审批流程，您需要等待一段时间后才能获取退款结果。

<br />

1. 您首先需要联系华为运营人员申请为您的应用开通退款功能，并提供具体需要退款的订单信息。 如果您接入的是IAP 2.X版本，还需要提供退款成功后的通知URL，URL的具体实现请参见[支付回调接口处理](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_huaweiiap_devguide_server_oversea#h1-1575080480115)。

2. 您的退款申请审核通过后，华为运营人员在华为运营管理台为您发起退款。退款流程可能会触发审批流程。
3. 退款申请审批通过后，华为服务器执行退款流程。
4. 退款申请成功处理后，华为支付平台会向用户执行退款。
5. 退款成功后根据您接入的IAP SDK版本进行对应的退款通知处理。
   * 如果您的应用接入的是IAP 2.X版本，退款成功后华为服务器会直接根据退款成功通知URL向您的开发者服务器发送退款成功通知，具体请参见[支付回调接口处理](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_huaweiiap_devguide_server_oversea#h1-1575080480115)。
   * 如果您的应用接入的是IAP 4.0及以上版本，您的开发者服务器需要定时调用[已取消或者退费购买查询](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-cancel-or-refund-record-0000001050746117)接口查询退款订单的处理结果。
6. 确认退款成功后，您可以取消用户和商品的订购关系。
