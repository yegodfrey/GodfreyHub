# 登录认证

## 前提条件

已在开发者联盟网站上[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/ailod-agc-0000002477235912#section61391351162414)。

## 操作步骤

1. 在顶部菜单栏选择"AILOD > Settings"，点击"Sign in"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110243.64787782301328147590999998542106:50001231000000:2800:AC14EC4D6A03496A1215DF5534B67912F1C3A3552B24BEAF5AE05B8018178C04.png)

2. 在弹出的"华为账号登录"页面，输入已实名认证的华为账号，完成后点击"授权并登录"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110243.54583192089769897110810614625994:50001231000000:2800:55C8A72067C8EE3E8A52980D9413296CB70D6818801D5C6489F4BBF185205324.png)

3. 登录成功后，请携带**Open Id** 信息联系运营（QQ：2851508860）申请使用权限。

   后续再使用相同华为账号登录AILOD时，**Open Id**不会变，您无需重复联系运营申请权限。
