# 邮箱

您可以在应用中集成邮箱账号认证方式，您的用户可以使用邮箱地址和密码或者邮箱地址和验证码来登录您的应用。  

#### 前提条件

* 您需要在AGC控制台[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyos-integration-sdk-0000001327194257)。  

#### 注册

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251226181012.23629280433814622647352300871766:50001231000000:2800:E1E4066610280F4158AF32C33990B50E1062C3A149BBCB5751A225FBC89D0C36.png "点击放大")

1. 在使用邮箱注册之前，需要先验证您的邮箱，确保该邮箱账户归您所有。 通过[VerifyCodeSettings.Builder](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-verifycodesetting-0000001197371235)生成settings ，然后调用[AGConnectAuth.requestVerifyCode](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-agconnectauth-0000001151371572#section17198192113400)申请验证码。

   ```
   "Java"
   VerifyCodeSettings settings = new VerifyCodeSettings.Builder()
    .action(VerifyCodeSettings.ACTION_REGISTER_LOGIN)   
    .sendInterval(30) 
    .locale(Locale.CHINA) 
    .build();
   HarmonyTask<VerifyCodeResult> task= AGConnectAuth.getInstance().requestVerifyCode(emailStr, settings);
   task.addOnSuccessListener(TaskExecutors.uiThread(), new OnSuccessListener<VerifyCodeResult>() {
    @Override
    public void onSuccess(VerifyCodeResult verifyCodeResult) {
      //验证码申请成功
    }
   }).addOnFailureListener(TaskExecutors.uiThread(), new OnFailureListener() {
    @Override
    public void onFailure(Exception e) {
    }
   });
   ```

2. 使用邮箱账号注册用户。 调用[EmailUser.Builder](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-emailuser-0000001197371233)生成EmailUser，然后调用[AGConnectAuth.createUser](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-agconnectauth-0000001151371572#section1911419330286)注册用户。注册成功后，系统会自动登录，无需再次调用登录接口。

   ```
   "Java"
   EmailUser emailUser = new EmailUser.Builder()
    .setEmail("your Email")
    .setVerifyCode("verify code")
    .setPassword("your password") //optional
    .build();
   AGConnectAuth.getInstance().createUser(emailUser)
    .addOnSuccessListener(new OnSuccessListener<SignInResult>() {
     @Override
     public void onSuccess(SignInResult signInResult) {
      //创建账号成功后，默认已登录
     }
    })
    .addOnFailureListener(new OnFailureListener() {
     @Override
     public void onFailure(Exception e) {
     }
    });
   ```

3. 登录成功后可以调用[AGConnectAuth.getCurrentUser](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-agconnectauth-0000001151371572#section158064585233)获取用户账号数据。  

   ```
   "Java"
   AGConnectUser user = AGConnectAuth.getInstance().getCurrentUser();
   ```

#### 密码登录

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251226181012.29765799827330406295956985240264:50001231000000:2800:ECC83AF2A5CCBFF9BE4C470E5C7E3996B53E39ADD69EFCABC91D45947FCBD829.png "点击放大")

1. 在应用的登录界面，初始化[AGConnectAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-agconnectauth-0000001151371572)实例，获取AGC的用户信息，检查是否有已经登录的用户。如果有则可以直接进入用户界面，否则显示登录界面。  

   ```
   "Java"
   AGConnectUser user = AGConnectAuth.getInstance().getCurrentUser();
   ```

2. 调用[EmailAuthProvider.credentialWithPassword](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-emailauthprovider-0000001197411135#section11144259121311)采用密码方式创建Email账号凭证。  

   ```
   "Java"
   AGConnectAuthCredential credential = EmailAuthProvider.credentialWithPassword("your Email", "password");
   ```

<!-- -->

3. 获取credential成功后，调用[AGConnectAuth.signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-agconnectauth-0000001151371572#section298148131715)实现登录。  

   ```
   "Java"
   AGConnectAuth.getInstance().signIn(credential)
   	.addOnSuccessListener(new OnSuccessListener<SignInResult>() {
   		@Override
   		public void onSuccess(SignInResult signInResult) {
   			//获取登录信息
   		}
   	})
   	.addOnFailureListener(new OnFailureListener() {
   		@Override
   		public void onFailure(Exception e) {
   		}
   	});
   ```

3. 调用[EmailAuthProvider.credentialWithVerifyCode](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-emailauthprovider-0000001197411135#section648110229154)采用验证码方式创建Email账号凭证。  

   ```
   "Java"
   AGConnectAuthCredential credential = EmailAuthProvider.credentialWithVerifyCode("your Email", "password","verify code");
   ```

   password参数可以不传, 如果同时输入了密码和验证码，则会对密码和验证码都做验证。

     public void onFailure(Exception e) {

   task.addOnSuccessListener(TaskExecutors.uiThread(), new OnSuccessListener<VerifyCodeResult>() {

       public void onSuccess(Void aVoid) {
           // onSuccess
       }
   })
   .addOnFailureListener(new OnFailureListener() {

           // onFail

   });

#### 更多信息

* 您如果想让用户可以使用多个账号登录您的应用，可以将多个[账号进行关联](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyos-associated-0000001151530116)。
* 当用户不需要使用应用，或者需要切换其他账号登录认证，可以先执行[登出](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyos-signout-0000001197409875)。
* 当用户需要注销当前用户，可以进行[销户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyos-deleteuser-0000001197369969)。
* 对于销户、修改密码、关联账号以及重置手机账号和邮箱账号等敏感操作，为了提高安全性，需要用户必须在5分钟内登录过才能执行。如果用户执行敏感操作时登录超过5分钟，需要[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyos-reauthenticate-0000001151370312)后再执行敏感操作。
* 您可以参考[异常处理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyos-troubleshooting-0000001197409877)实现自己的异常处理机制，从而减少异常情况的发生。
* 您可以使用云函数触发器来接收用户注册、登录、销户等关键事件，从而[扩展认证服务的能力](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-extension-0000001053372708)。
* 您可以参考[管理用户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-user-manage-0000001606051705)对用户进行解锁、停用等操作。
