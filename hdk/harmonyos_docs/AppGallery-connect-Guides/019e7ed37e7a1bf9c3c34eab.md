# 注册监听下载任务

## 接口描述

注册监听下载任务信息回调。

## 示例代码

可在界面启动时注册，然后再界面销毁时反注册，全局只需注册一次即可

1. 接口声明

   ```screen
   PendingResult<RegisterDownloadCallbackIPCRequest, TaskOperationResponse> registerDownloadCallback(AgdApiClient var0, RegisterDownloadCallbackIPCRequest var1)
   ```

2. 输入参数

   ```screen
   // RegisterDownloadCallbackIPCRequest中添加IDownloadCallback实现。
   interface IDownloadCallback {
       String getDownloadRegisterKey();//注册某个监听，为该监听提供唯一的ID
       void refreshAppStatus(in String packageName, in int appType, in int status, in int progress);//刷新应用下载安装进度或状态
   }
   ```

3. 返回参数 参见AgdApi.startDownloadTaskV2的mResult

   注意：调用该接口后，在disconnect之前要主动调用unregisterDownloadCallback，保证对端不再回调回来。
4. 示例代码

   ```screen
   MyDownloadCallback downloadCallback = new MyDownloadCallback();

   RegisterDownloadCallbackIPCRequest registerDownloadCallbackIPCRequest =
       new RegisterDownloadCallbackIPCRequest();
   registerDownloadCallbackIPCRequest.setPackageName(pkg);
   registerDownloadCallbackIPCRequest.setCallback(downloadCallback);
   AgdApi.registerDownloadCallback(client, registerDownloadCallbackIPCRequest)
      .setResultCallback(new ResultCallback<TaskOperationResponse>() {
           @Override
           public void onResult(Status<TaskOperationResponse> result) {
               Log.i(TAG, " onResult:" + result.getStatusCode());
          }
      });

   private class MyDownloadCallback extends IDownloadCallback.Stub {
           @Override
           public String getDownloadRegisterKey() throws RemoteException {
               return "TestDemoRegisterKey";
          }

           @Override
           public void refreshAppStatus(String packageName, int appType, int status, int progress) throws RemoteException {
               Log.i(TAG, "packageName;" + packageName + ",appType:" + appType +  ",status:" + status + ",progress:" + progress);
          }
   }
   ```
