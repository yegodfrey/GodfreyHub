# 概述

通过HTTP触发器调用函数，需要集成对应平台的SDK。

具体分为应用客户端侧调用函数和应用服务端侧调用函数。

* 应用客户端侧调用函数包括[Android](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/android-sdk-changenotes-0000001300176418) | [iOS](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/ios-sdk-changenotes-0000001353655889) | [Web](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/web-sdk-changenotes-0000001300176422) | [HarmonyOS(Java)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/harmony-java-sdk-changenotes-0000001353415461) | [HarmonyOS(TypeScript API 6)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/harmonyos-ts-api6-sdk-changenotes-0000001604377957) | [HarmonyOS(TypeScript API 9及以上)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/sdk-changenotes-harmonyos-ts-0000001522259721) | [HarmonyOS(ArkTS API 9至API 11)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/harmonyos-arkts-sdk-changenotes-0000001633134782) | [HarmonyOS(ArkTS API 12及以上)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/call-function-via-httptrigger-arkts12-0000002035902596) | [快应用](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/quickapp-sdk-changenotes-0000001353496185) | [快游戏](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/quickgame-sdk-changenotes-0000001300496242) | [微信小程序](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/miniprogram-sdk-changenotes-0000001353496189)。
* 应用服务端侧调用函数，按开发语言不同分为[Server(Java)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/server-java-sdk-changenotes-0000001353496181) | [Server(Node.js)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/server-nodejs-sdk-changenotes-0000001783798149)。
