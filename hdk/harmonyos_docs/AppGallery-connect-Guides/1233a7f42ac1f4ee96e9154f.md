# 销户

#### 前提条件

您需要已完成[开通认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)以及[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-miniprogram-integration-sdk-0000001276634492)各项准备工作。  

#### 开发步骤

<br />

当用户不再使用应用，可以注销当前用户。您需要调用[AGCAuth.deleteUser](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section13266162513559)实现该功能，用户一旦被注销，将会删除服务端侧的用户信息同时清空客户端侧用户信息和Token。

```
agconnect.auth().deleteUser();
```

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251223144019.18631823607055831704967130516550:50001231000000:2800:6AFCFF7B2D0A4881FD2415C798173A2608C3BE6456ADAB9B6F0532AEE6BBA844.png)  
对于销户操作，要求用户必须在5分钟内登录过才能执行。若已超时，请参见[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-miniprogram-reauthenticate-0000001113041286)先完成重认证。
