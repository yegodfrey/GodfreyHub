# 3D音效

3D音效可将一定空间范围内无方位感的声音进行方位和距离衰减的效果渲染，使之听起来更有沉浸感。同时您还需要了解的是，3D音效属于端侧的音频渲染能力，开启后会增加额外的功耗。

#### 前提条件

* 您已[集成游戏多媒体基础SDK、实时语音和3D音效模块](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-integratingsdk-ios-0000001323104597#ZH-CN_TOPIC_0000001323104597__li16373152113206)。
* 您已[创建游戏多媒体实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-engine-ios-0000001272544612#section1093713161034)。
* 您已[加入房间](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-joinroom-roomid-ios-0000001323024589)。  

#### 开启/关闭3D音效

1. 调用[HWPGMEngine.getInstance initSpatialSound](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section5769124261)方法初始化3D音效。

   ```
   int result = [[HWPGMEngine getInstance] initSpatialSound];
   ```

2. 调用[HWPGMEngine.getInstance enableSpatialSound](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section17657456182614)方法开启/关闭3D音效。

   ```
   int result = [[HWPGMEngine getInstance] enableSpatialSound:roomId enable:true];
   ```

#### 设置语音接收范围

语音接收范围主要用于限制房间内收听者对音频的最大接收距离（空间距离），根据收听者与发声者的位置信息，收听者可收听到一定范围内的声音。  
调用[HWPGMEngine.getInstance setAudioRecvRange](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section3252124317014)方法设置语音的接收范围。

```
HWPGMEngine *pgmeEngine = [HWPGMEngine getInstance];
int result = [pgmeEngine setAudioRecvRange:range];
```

#### 更新/清理位置

进入房间后，在3D音效场景下，玩家通常需要先更新一下自身在世界坐标系中的坐标和朝向信息。当自身或其他玩家位置等信息不断发生变化时，可通过接口持续上报变更。同时，还可以根据场景变化，清理指定或全部玩家的位置缓存信息。  

#### 更新自身位置

1. 构建自身位置信息。

   ```
   PlayerPosition *playerPosition = [[PlayerPosition alloc]init];
   playerPosition.forward = 11.0;
   playerPosition.right = 12.0;
   playerPosition.up = 13.0;

   Axis *axis = [[Axis alloc]init];
   axis.forward = simd_make_float3(10.0, 10.0, 11.0);
   axis.right = simd_make_float3(10.0, 10.0, 11.0);
   axis.up = simd_make_float3(10.0, 10.0, 11.0);

   SelfPosition *selfPosition = [[SelfPosition alloc]init];
   selfPosition.position = playerPosition;
   selfPosition.axis = axis;
   ```

2. 调用[HWPGMEngine.getInstance updateSelfPosition](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section9961335134620)方法更新自身的位置（即坐标和方向）信息。

   ```
   ...
   HWPGMEngine *pgmeEngine = [HWPGMEngine getInstance];
   int result = [pgmeEngine updateSelfPosition:selfPosition];
   ```

#### 更新其他玩家位置

1. 构建其他玩家位置信息。

   ```
   NSMutableArray<RemotePlayerPosition *> *remotePlayers = [[NSMutableArray alloc]init];

   PlayerPosition *playerPosition = [[PlayerPosition alloc]init];
   playerPosition.forward = 11.0;
   playerPosition.right = 12.0;
   playerPosition.up = 13.0;

   RemotePlayerPosition *position = [[RemotePlayerPosition alloc]init];
   position.openId = @"zhangsan";
   position.position = playerPosition;

   [remotePlayers addObject:position];
   ```

2. 调用[HWPGMEngine.getInstance updateRemotePosition](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section1705450104620)方法更新其他玩家的位置信息。

   ```
   HWPGMEngine *pgmeEngine = [HWPGMEngine getInstance];
   int result = [pgmeEngine updateRemotePosition:remotePlayers];
   ```

#### 清理其他玩家位置

* 调用[HWPGMEngine.getInstance clearRemotePlayerPosition](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section8864103210113)方法可清理指定玩家的位置信息。例如，清理已离开房间的其他玩家位置缓存信息。

  ```
  HWPGMEngine *pgmeEngine = [HWPGMEngine getInstance];
  [pgmeEngine clearRemotePlayerPosition:openId];
  ```

* 调用[HWPGMEngine.getInstance clearAllRemotePositions](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section13338124711579)方法可清理其他所有玩家的位置信息。例如，当重新开始一局游戏时，清理其他所有人的位置缓存信息。

  ```
  HWPGMEngine *pgmeEngine = [HWPGMEngine getInstance];
  [pgmeEngine clearAllRemotePositions];
  ```

#### 查询3D音效开启状态

如需查询3D音效是否已开启，可通过调用[HWPGMEngine.getInstance isEnableSpatialSound](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section8119194316408)方法获取3D音效的状态。

```
BOOL result = [[HWPGMEngine getInstance] isEnableSpatialSound:roomId];
```
