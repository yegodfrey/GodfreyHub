# 业务概述

## 业务描述

|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-|
|游戏性能管理服务（Game Performance Management，GPM）是华为游戏中心推出的一款功能强大、集成简便的性能管理解决方案。仅需接入游戏性能管理SDK即可实现低功耗、全方面地采集游戏运行时的性能数据，经过华为服务器深度分析，将在AGC控制台以不同维度的可视化图表进行展示。基于此报告，华为将协助您不断地优化游戏性能，以确保游戏能够运行在最佳状态，为用户提供流畅、稳定的使用体验。| |

## 主要功能

|主要功能|功能描述|
|:----|:-------------------------------------------|
|数据采集|支持游戏运行时的性能数据采集，涵盖流畅度指标、硬件相关指标、系统性能指标及场景相关指标。|
|可视化分析|支持不同机型、版本及场景下的数据过滤，支持可视化分析数据。|

## 平台支持说明

|平台|SDK|
|:-------------------|:-----------------|
|Android|C# SDK、Android SDK|
|HarmonyOS 3.1/4.0及以下|C# SDK、Android SDK|
|HarmonyOS 5.0及以上|-|
|iOS|iOS SDK|

## 工作原理

游戏性能管理服务为Android游戏提供了客户端SDK，可用于实时采集游戏运行时的性能数据，例如流畅度指标、硬件相关指标等，同时会将数据上报至游戏性能管理服务器进行性能分析，您可在AGC控制台查看性能数据，分析游戏的运行状况。

## 实现流程

Android游戏接入游戏性能管理服务的流程如下：

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110221.14014291114800220132177287681912:50001231000000:2800:BD43FD4217F4A6465EF4AD924B5B076598EAC5DAD345534CEE9FB127D9EF63A1.png)

|序号|步骤|说明|
|:-|:---------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|AGC控制台准备|接入服务前需要[注册开发者账号](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-register-account-0000001754991002)、[创建项目和游戏](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-create-project-0000001754832082)、[获取鉴权信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-get-authentication-infomation-0000001801791669)。|
|2|[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-integration-0000001719545670)|使用游戏性能管理相关功能前，必须集成游戏性能管理SDK。|
|3|[初始化SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-initialization-0000001719386234)|调用游戏性能管理SDK的接口前，必须初始化SDK。初始化SDK时需要设置参数**AutoCollectScene** ，该参数值决定**在** **开启数据采集器** 后**是否开始** **采集、上报**游戏的性能数据。|
|4|[开启数据采集器](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-open-close-collector-0000001767186237#section72707115441)|采集、上报数据前，必须开启数据采集器。若想结束数据的采集，您可以关闭数据采集器，下次再想采集数据，请重新开启数据采集器。|
|5|[设置场景和标签（可选）](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-set-scene-tag-0000001767225477)|若**AutoCollectScene** 设置为**false**，您可以自定义游戏场景，例如打斗、团战。若还想在场景中标记一段特殊的子场景信息，可以在场景中设置标签，用以标识该子场景中的性能数据。|
|6|[在AGC控制台查看数据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-view-data-0000001767393705)|游戏集成游戏性能管理SDK后将在运行过程中采集性能数据，并上报至AGC控制台，您可以前往AGC控制台查看游戏的运行情况。|
