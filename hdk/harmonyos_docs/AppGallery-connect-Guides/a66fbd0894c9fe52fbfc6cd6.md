# 使用限制

#### 设备限制

设备限制是指SDK对用户终端的限制。  

|限制项|限制|
|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
|Android OS|* SDK：支持Android 4.1及以上（API Level 16及以上） * 应用市场：Android 7.0以上（API Level 24以上）支持拆分APK机制，Android 7.0及以下（API Level 24及以下）只能进行全量安装。 SDK支持的行为取决于应用市场的分发能力。|
|iOS OS|暂不支持|
|Web浏览器|暂不支持|
|EMUI（针对华为手机）|EMUI 5.0以上|
|HMS Core APK|无限制。|
|应用市场客户端|用户设备必须安装10.2.2及以上版本的华为应用市场客户端。|
