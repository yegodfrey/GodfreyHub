# 集成SDK

云数据库Node.js Server SDK发布在npm仓库，您可以在"my-cloud-function"函数目录下执行以下命令，安装Server SDK到您的项目中。此时依赖将同步添加到云函数目录下的package.json文件中，依赖包都会存储在当前函数的"node_modules"目录下。

```
npm install --save @hw-agconnect/cloud-server
```
