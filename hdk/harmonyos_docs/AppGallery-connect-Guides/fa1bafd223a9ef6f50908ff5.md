# （可选）查看调试日志

如果您发现APM服务异常，可以通过查看APM SDK日志进行调试。

在调试应用时，您可以打开APM调试日志开关，方便查看APM性能监控是否正常运行。具体方法是在应用的info.plist文件中添加apms_debug_log_enabled元素，设置为YES时，表示打印DEBUG级别日志，其默认值为NO。

通过logcat日志过滤功能，您可以查看应用启动、应用屏幕和HTTP/HTTPS网络请求的性能监控日志记录。这些日志记录会被标记为**[APM]。**
