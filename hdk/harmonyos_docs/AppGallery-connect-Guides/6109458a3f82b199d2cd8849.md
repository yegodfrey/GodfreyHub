# 部署模板

使用Serverless模板前，请先为您的项目部署模板。

## 前提条件

您已完成创建AGC项目和应用，具体请参见[创建项目和应用](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-serverless-clearuser_precfg-0000001320816577#section55472613292)。

## 选择模板

您需要先在Serverless模板列表中找到您需要使用的模板。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中找到您需要使用Serverless模板的项目。
3. 选择"云开发（Serverless） > Serverless模板"，点击右上角"浏览更多Serverless模板"查看并选择Serverless模板。 说明
   >
   > 每个Serverless模板详情卡片都包含该模板的部署方式和使用指南，请仔细查看后选择。

## 部署模板

选择Serverless模板后，您需要将模板部署到您的项目中。

1. 点击您选择的Serverless模板卡片上的"部署"。
2. 选择需要部署Serverless模板的项目。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174805.08228604553530189485063625995522:50001231000000:2800:F0F37A6DED35254576A5ABAB894844569D8C9B62D071CFC772E06D646DB94C70.png)

3. 点击"数据处理位置"下拉框，为Serverless模板选择数据处理位置，点击"下一步"。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174805.92030053216413171288328593871343:50001231000000:2800:24BFC82F36301F6F4CF8DCAB9A1BFC11DCC46D832EBFAC9D83EEDAADDD2BFBC8.png) 说明
   >
   > 当前仅支持在数据处理位置为"中国"的项目上部署Serverless模板。
4. 配置使用该Serverless模板需要的参数。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174805.86011276292164944030839933590202:50001231000000:2800:D46ECD3EB6AABB0091E97885A379DC2EDF4E47DA1DA268543853F8C31C700EF1.png)

   具体参数说明如下：

   |参数|说明|
   |:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |云数据库的存储区名|云数据库中存储区名称。 即从此存储区中删除用户数据。如果此参数值为空，则系统不对云数据库服务进行用户数据删除操作。 > 说明 > 云数据库中的存储区是一个独立的数据存储区域。多个数据存储区互相独立，每个存储区都可以存储所有的对象类型，且对象类型的版本为最新版本。|
   |云数据库的对象类型|云数据库中的对象类型。 > 说明 > Cloud DB采用基于对象模型的数据存储结构。数据以对象的形式存储在不同的存储区中，每一个对象，都是一条完整的数据记录。对象类型用于定义存储对象的集合，不同的对象类型对应的不同数据结构。|
   |云存储的实例名|云存储的实例名称。 即从此实例中删除用户数据。如果此参数值为空，则系统不对云存储服务进行用户数据删除操作。 配置示例：instance-*****|
   |云存储的路径|待删除用户数据的云存储路径。 * 如果不需要清理云存储服务中用户数据，则可以不配置。 * 如果您需要删除根目录的用户文件，则配置为"{*UID* }"。 * 如果您需要删除指定目录下的用户文件，则配置为"*media/* {*UID* }"，即表示删除"/media"目录下对应用户文件。 配置示例： {*UID*} *media* /{*UID*}|

5. 参数配置完成后，点击"下一步"。
6. 在部署页面，点击"开始部署"。 注意
   >
   > 如果部署多次仍失败，请在互动中心[反馈问题](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/interactive/feedback)或[在线提交工单](https://developer.huawei.com/consumer/cn/support/feedback/#/add/89?level2=9069)，华为工作人员将在1～3个工作日内进行处理。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174805.96528732883188102317508162811808:50001231000000:2800:576490FC1B1BB8E6E126731F63C3F8F1E26ED29C1A4CDEA3F4FAFE4C3913F331.png)

## 配置云函数

用户数据删除模板会在一键部署时自动生成模板的函数接口，模板部署成功后，您还需在"云函数"页面为对应的函数接口添加对应的认证服务触发器，以实现在认证服务注销用户后自动触发云函数。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"，在项目列表页面选择模板所在的项目。
2. 选择"云开发（Serverless） > 云函数"，在"函数列表"页面根据已部署模板的"实例ID"找到模板对应的函数，点击函数名称进入函数详情页。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174805.19536969746449736324754837668602:50001231000000:2800:C943BAF98DA962C98CD2B49C28D45787D7CDE14387D1E20AAE4B720724F5158B.png)

3. 在函数详情页选择"触发器"页签，点击"添加触发器"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174805.41659642106089725201177249398145:50001231000000:2800:C8C0D1135483E8E630F0B65E3230965946F451EEB4D7F43618F72B2330797A68.png)

4. 在弹出的"添加触发器"窗口中配置触发器相关参数。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174805.31061623488828882967435986499952:50001231000000:2800:28E33E9C125D8BB3943C0BA6471E0D9C3429AA5DC58A46C005A0D8968695E99C.png)

   具体参数说明如下表所示。

   |参数|说明|
   |:----|:-----------|
   |触发器类型|选择"认证服务触发器"。|
   |事件类型|选择"用户销户"。|

5. 配置完成后，点击"确定"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174805.30298382040616038707410939247017:50001231000000:2800:753DB2F4950AF05F5E0F25540AAD7DDD922CD73D46849A22A9FB9EB7D09B04EF.png)

6. 在函数详情页选择"函数配置"页签，修改"cloudStoragePath"变量值从"UID"修改为"{UID}"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174806.91141551149299788416585276132540:50001231000000:2800:AF334EF0D9333713F85EF9F48993AC396A57E124CE817633812D00C10551AF19.png)

7. 修改环境变量后，点击页面左下角的"保存"。
