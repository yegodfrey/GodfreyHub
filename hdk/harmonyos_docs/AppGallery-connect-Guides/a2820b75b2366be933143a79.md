# 用量统计

您可以通过用量趋势图，了解您最近3天内在Redis客户端和云缓存Web CLI页面，对缓存数据进行读写操作的频次。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中选择您的项目。
3. 在左侧导航栏选择"Serverless > 云缓存"，点击"用量"页签。
4. 点击右上角选择时间段，查询云缓存访问量。 说明
   >
   > 本服务目前处于推广期，可供您免费使用。后续会根据您的访问量来收费。
