# 注册/注销图像资源

为了使SDK内部可以使用外部的颜色、深度以及输出预测帧结果，需要向SDK注册上述图像资源。

## 前提条件

已[创建库实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/predict-frame-create-instance-vulkan-0000001791483622)。

## 注册图像资源

在预测激活之前，需调用函数[FrameFlowVK_RegisterImage](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflowvk-registerimage-0000001838516405)注册图像资源。

```screen
FFVKImage FrameFlowVK_RegisterImage(FFVKInstance instance, VkImage image, VkImageView view);
```

## 注销图像资源

在退出应用时，需调用函数[FrameFlowVK_UnregisterImage](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflowvk-unregisterimage-0000001838436385)注销图像资源。

```screen
void FrameFlowVK_UnregisterImage(FFVKInstance instance, FFVKImage image);
```
