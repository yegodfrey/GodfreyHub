# 列举文件

列举文件是指获取某个目录下的所有文件和目录信息，云存储支持通过REST API列举云端某个目录下的文件或子目录。

## 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[获取API授权](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-getapicredentials-0000001498508514)。

## 操作步骤

定义待枚举的目录的详细参数，调用[列举文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storage-restapi-listfile-0000001498518878)接口获取当前目录下的文件与子目录。
