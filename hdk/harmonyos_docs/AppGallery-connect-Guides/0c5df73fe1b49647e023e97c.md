# 云数据库

#### 前提条件

若要查看云数据库服务的业务日志，您首先需要创建[存储区](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-clouddb-createfirstclouddb-0000001569588629#section176494298138)和[对象类型](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-clouddb-createfirstclouddb-0000001569588629#section1187312482820)。  

#### 查看云数据库业务日志

![](https://media:101784088244984428)  
当前仅支持查看集成以下SDK版本的云数据库日志信息。

* Web SDK 1.3.4及以上版本
* Server SDK（node.js） 1.0.9及以上版本

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中选择您的项目。
3. 在左侧导航栏选择"质量 \> 云监控 \> 日志服务"，进入"日志服务"主页面。
4. 在页面左上角，日志类型选择"业务日志"，下拉框选择"云数据库"，即可查看云数据库服务的业务日志。您可根据需要添加过滤条件、设置时间范围，筛选出符合条件的日志信息，并可点击"查询"获取最新的业务日志。  
   ![](https://media:101784088245016429)  
   默认情况下，选择日志类型和服务名称后，系统会自动执行一次查询操作。时间选择框默认时间跨度为最近7天，查询结果按照分钟级时间从最新开始展示。

   ![](https://media:101784088245074430)

   在该页面您可以执行以下操作：
   * 点击"增加过滤条件"，可根据需要设置过滤器，对所有日志进行筛选。当前支持的过滤条件全集如下表所示。  
     ![](https://media:101784088245099431)  
     * 请求和响应消息日志包含的信息不完全相同，过滤条件也会随着日志包含信息的不同而动态变化。
     * 支持添加多个过滤条件。
     * 增加过滤条件时，支持"等于"、"属于"、"不等于"和"不属于"四种运算符。
       * 选择"等于"或"不等于"运算符时只能输入一个条件值进行精确匹配。
     * 选择"属于"或"不属于"运算符时可以输入一个或多个条件值进行精确匹配。当输入多个条件值时，与其中任意一个条件值匹配成功，则显示满足该条件的日志。  

     |消息类型|字段名称|字段含义|字段示例|备注|
     |:---|:--------------------|:--------|:-------------------------------|:--------------|
     |请求|traceId|跟踪ID|7b7896e63d7a4991a4170a173c4a9e52|32位UUID，不包含-|
     |请求|sdkType|SDK类型|Android|-|
     |请求|sdkVersion|SDK对应的版本号|1.3.5.300.1|-|
     |请求|zoneName|存储区名称|myzone1|-|
     |请求|schemaName|对象类型名称|Student01|-|
     |请求|sizeOfRequest|请求body体长度|34|-|
     |响应|traceId|跟踪ID|7b7896e63d7a4991a4170a173c4a9e52|32位UUID，不包含-|
     |响应|sizeOfResponse|响应body体长度|89|-|
     |响应|responseCode|响应业务码|0|0代表成功|
     |响应|httpStatus|标准HTTP状态码|200|可能为空|
     |响应|durationInMillisecond|业务处理时间|1|单位ms|
     |响应|errorMessage|错误信息|permission denied.|当响应码为200时错误信息为空|

     ![](https://media:101784088245129432)

     点击"保存"后，添加的过滤条件处于启用状态，"查询结果"区域将展示指定时间范围内符合条件的日志信息。鼠标滑动至过滤器上，可对其进行禁用、删除和编辑操作，并且禁用后可再次启用。

     ![](https://media:101784088245162433)
   * 点击时间选择框，您可以在窗口左侧选择预定时间段，例如最近3天，或输入自定义时间范围筛选日志。 ![](https://media:101784088245194434)

   * 点击"直方图"区域任一处，可展开或收起直方图，主要展示查询到的业务日志在时间上的分布情况。
   * 点击"查询结果"区域右侧的"展开"，日志表格将展开显示每条日志的详细信息，例如存储区名称、对象类型名称、调用ID、项目ID、日志落盘时间等。 ![](https://media:101784088245232435)

   * 点击"查询结果"区域右侧的"下载"，可将日志以txt格式导出到本地查看。
   * 点击日志末尾的![](https://media:101784088245262436 "点击放大")，可过滤出该traceId的所有日志。若想去除过滤，鼠标放置在页面顶端该traceId过滤器上，将其禁用或者删除即可。

     ![](https://media:101784088245293437)
5. （可选）点击直方图区域某处展开直方图，将鼠标悬浮在直方图某一蓝色数据块上时，您可查看到该数据块代表的时间范围和日志命中次数。  
   ![](https://media:101784088245571438)  
若您想通过直方图查看更细时间粒度的日志分布情况，操作方法与云函数业务日志一致，详情请参见[通过直方图查看日志分布情况](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/cloudfunction-0000001432886916#ZH-CN_TOPIC_0000001432886916__li16636165985613)。
