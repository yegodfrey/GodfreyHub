# AppVideoInfo

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:---------|:----------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|videoUrl|M|String|视频地址。|
|resolution|M|String|分辨率。 格式为216*216。|
|posterUrl|O|String|海报图片地址。 > 注意 > 如果"posterUrl"字段返回缺少域名，则请手动拼接一个域名**https://appimg.dbankcdn.com**。 示例：https://appimg.dbankcdn.com/files/application/appVideo/introFrame/a93b8c70efe241829fce00d1b3ed30fa1.png|
|duration|O|Integer (64)|视频时长。 单位：秒|
