# 调用函数

## 前提条件

调用函数之前，请确保您已经[创建定时触发器](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudfunction-crontrigger-0000001658717864#section176113174550)。
