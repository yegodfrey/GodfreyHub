# Android

Android游戏如需实现实时语音、实时信令、语音消息、效果音播放和语音转文本功能，可以集成游戏多媒体服务的Android SDK。  

#### 开发准备

* JDK 1.7及以上
* 安装Android Studio 3.x及以上
  * minSdkVersion 21及以上
  * targetSdkVersion 29（推荐）
  * compileSdkVersion 29（推荐）
  * Gradle 3.5及以上（推荐）
* 测试应用的设备：Android 5.0及以上的手机

#### 添加权限

在使用游戏多媒体SDK相关模块能力前，您需要先在"AndroidManifest.xml"文件中的"manifest"节点下申请如下权限。

* 公共权限

  ```
  <!--读写存储（媒体和文件）权限-->
  <uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />
  <uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" />
  <!--访问网络权限-->
  <uses-permission android:name="android.permission.INTERNET" />
  <!--获取网络状态-->
  <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
  <!--获取WiFi状态-->
  <uses-permission android:name="android.permission.ACCESS_WIFI_STATE" />
  ```

* 如果使用语音消息、语音转文本能力，除公共权限外，还需要添加以下权限：

  ```
  <!--录音权限-->
  <uses-permission android:name="android.permission.RECORD_AUDIO" />
  ```

* 如果使用实时语音能力，除公共权限外，还需要添加以下权限：

  ```
  <!--使用蓝牙权限-->
  <uses-permission android:name="android.permission.BLUETOOTH" />
  <!--修改声音设置权限-->
  <uses-permission android:name="android.permission.MODIFY_AUDIO_SETTINGS" />
  ```
