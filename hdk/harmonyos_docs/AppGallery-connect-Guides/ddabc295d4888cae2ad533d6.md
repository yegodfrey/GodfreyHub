# 查看应用性能数据

您可以在"应用性能管理"页面查看详细的应用性能数据，包括概览数据、应用启用性能数据、应用屏幕性能数据、网络请求性能数据。  

#### 前提条件

* 您的应用已[启用APM服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-ios-getstarted-0000001051808644#section142988535290)，并在设备上运行。
* 您的应用已[集成APM SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-ios-getstarted-0000001051808644#section1228533511103)。  

#### 查看概览

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择需要查看的应用。
3. 选择"质量 \> 性能管理"，进入"应用性能管理"页面。
4. 点击"概览"，进入概览页面。 概览页面展示应用近30天问题和指标概览。

   指标概览包括"启动时长（按版本分布）"、"缓慢帧占比（Top5 viewController）"、"冻结帧占比 （Top5 viewController）"、"网络请求耗时（Top5国家/地区）"和"网络请求成功率（随时间变化）"。在概览页面，您可以快速了解应用的重要性能指标，及时识别应用是否发生问题。

#### 查看应用启动性能数据

应用启动性能数据衡量用户打开应用到展示出第一个页面之间的时间。应用启动监控以应用启动时长作为统计指标，通过计算应用启动时长的分位值，来为您呈现出应用启动时长的整体分布情况，让您及时全面掌握应用的启动性能。

#### 查看网络请求性能数据

网络请求性能数据统计了应用向服务端发出网络请求与来自该服务端的响应完成这两个时间点之间的时长、请求状态码、请求负载大小以及响应负载大小。

APM通过监控NSURLConnection和NSURLSession框架发起的HTTP/HTTPS的网络请求，通过匹配URL聚合规则汇总同类网络请求的数据，帮助您了解网络请求性能的趋势，及时发现网络问题。  

#### 查看网络请求报表

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择需要查看的应用。
3. 选择"质量 \> 性能管理"，进入"应用性能管理"页面。
4. 点击"网络分析"，进入网络请求指标统计页面。  

   |指标名称|指标含义|
   |:-----|:---------------------------------------------|
   |URL|根据URL聚合规则汇总后的网络请求地址|
   |请求次数|请求地址被调用的次数|
   |请求耗时|从应用发出请求到收到服务器响应之间的时间间隔|
   |成功率|状态码为 2xx 或 3xx 的请求次数占请求总次数的百分比（用于衡量网络或服务器故障情况）|
   |请求负载大小|应用上传的网络载荷的字节数|
   |响应负载大小|应用准备下载的网络载荷的字节数|

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251125162006.61643908802154352885356965249910:50001231000000:2800:E896AF7BD93A6B4B9BC7C40EB26C62A227D7A3EC9D0112C4C3D3D5CE3722FED9.png)
5. 点击网络请求的"查看详情"，进入该网络请求的详情页面。网络请求详情页面包含[请求耗时](#section1875442072313)和[请求成功率](#section14464152152512)。
