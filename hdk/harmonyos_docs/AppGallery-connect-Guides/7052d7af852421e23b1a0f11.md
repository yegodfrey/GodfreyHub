# 存储实例管理

您可以通过[AGCStorageManagement](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragemanagement-0000001111669018)对存储实例进行创建、删除等操作。

## 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[集成云存储SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-sdk-java-0000001115496716)。
* 您已[升级到付费档](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-service-billing-0000001058092595#section1337763420106)。

## 创建存储实例

如果您的项目需要使用多个存储实例时，您可以通过[AGCStorageManagement.createBucket](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragemanagement-0000001111669018#section1296341404210)方法在云端创建新的存储实例。

```screen
// "regionname" => 存储region名称，您可以打开凭据文件查看项目归属区域，并通过区域查找归属于该区域的存储region
// "CN" : ["cn-north-4"]
// "SG" : ["ap-southeast-3"]
// "RU" : ["ru-northwest-2"]
// "DE" : ["eu-de"]
// "bucketname" => 存储实例名称，您希望创建的存储实例名称。
// agcClient => https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-sdk-java-0000001115496716#section113221941173010时返回的AGCClient类的实例。当您创建的存储实例所属区域非您设置的默认数据处理位置时，您需要初始化对应区域的AGCClient类的实例并传递给该接口。
Bucket bucket = AGCStorageManagement.createBucket(agcClient, "regionname", "bucketname");
```

> 说明
>
> * 在新增存储实例时，云存储会对存储实例的名称进行严格检查，具体请参考[存储实例名称规范](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-manage-bucket-0000001281294006#ZH-CN_TOPIC_0000001281294006__p166851620145310)。
> * 为了避免创建存储实例的名称重复，SDK默认会在您输入的存储实例名称后加"-五位随机数字字母"，组合成实际存储实例名称。

## 删除存储实例

当创建的存储实例不再使用时，您可调用[AGCStorageManagement.deleteBucket](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragemanagement-0000001111669018#section68203346125)方法删除该存储实例。

```screen
AGCStorageManagement.deleteBucket("bucketname");
```

> 注意
>
> * 请确保存储实例中文件已全部删除，当存储实例中存在目录或文件时，删除存储实例会失败。
> * 删除操作不可逆，一旦执行，存储实例会被回收，不可恢复。
> * 启用服务时创建的默认存储实例不允许使用上述方式删除，如确定要删除，请执行删除项目操作，默认的存储实例即会同步执行删除操作。

## 列举存储实例

创建多个存储实例后，您也可调用[AGCStorageManagement.listBuckets](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragemanagement-0000001111669018#section1678261110203)方法列举您项目下的存储实例。

```screen
AGCStorageManagement.listBuckets();
```
