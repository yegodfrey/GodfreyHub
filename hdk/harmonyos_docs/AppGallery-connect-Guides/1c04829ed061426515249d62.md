# 成功案例

#### 客户需求

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250723181501.59727927859728889226107594878942:50001231000000:2800:C1AB80D44B09857B40BE64C06CB30A98E5C9EB013B89EF3D64FFFC813BBDDFF4.png)《涂鸦画图》是集涂鸦、画图、绘画于一体的应用，该应用需要支持多种第三方账号如华为账号，QQ登录，还需要支持手机号，邮箱登录，应用开发团队希望找到一个统一账号管理服务，华为认证服务刚好满足这个需求。  

#### 华为解决方案

《涂鸦画图》应用集成了华为认证服务的手机号登录，服务端省去了第三方短信中心对接的工作。

因此，开发的工作量有了大幅下降，服务端大约可以减少80%的工作量，客户端减少40%的工作量。
