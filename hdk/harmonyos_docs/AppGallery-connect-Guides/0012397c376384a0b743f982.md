# 录制视频

在游戏中，如需记录游戏内战斗过程，可通过录制视频，保存相关精彩片段。目前，游戏高光时刻服务提供了[手动录制](#section88949619499)和[自动录制](#section3541124144920)两种录制方式，以及系统录制与应用内录制两种录制模式，满足不同场景下的录制需求，例如录制游戏内高光时刻或录制全局视频等。  

#### 前提条件

* 您已[集成游戏高光时刻基础SDK和录屏模块](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/game-highlight-integratingsdk-0000001638097622)。
* 您已[初始化SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/game-highlight-initializing-0000001638256878)。
* 如需使用应用内录制模式，游戏须有且仅有一个SurfaceView。  

#### 开启手动录制

开启手动录制后，可以根据录制需要自定义最大录制时长，不仅支持小片段录制（例如高光时刻），还可满足较长时间内不间断的屏幕录制需求（例如全局视频），最长可支持1小时。

1. 调用[GameReplayManager.startManualRecord](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamereplaymanager-game-replay-0000001690120477#section1462692517445)方法开启手动录制，并指定录制的文件名和最大时长。
   * 系统录制模式：支持录制设备显示的全部画面

     ```
     gameReplayManager.startManualRecord(new RecordParam()
         .setFileName("xxx.mp4")  // 录制的文件名,须以.mp4结尾
         .setDuration(300)        // 手动录制的最大时长,最长1小时,单位：s
         .setActivity(null));     // 当前录制画面的Activity,为null则采用系统录制模式,不为null则采用应用内录制模式
     ```

   * 应用内录制模式：仅支持录制应用内显示画面

     ```
     gameReplayManager.startManualRecord(new RecordParam()
         .setFileName("xxx.mp4")  // 录制的文件名,须以.mp4结尾
         .setDuration(300)        // 手动录制的最大时长,最长1小时,单位：s
         .setActivity(activity)); // 当前录制画面的Activity,为null则采用系统录制模式,不为null则采用应用内录制模式
     ```

2. 当开启手动录制时，可在ReplayCallback接口的[onStart](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/replaycallback-callback-0000001686126937#section1633614193716)方法中实现相关回调处理。

   ```
   @Override
   public void onStart(RecordResult result) {
       // 根据启动录制返回结果做相应业务逻辑处理
   }
   ```

3. 在手动录制视频过程中，如需结束录制，可通过调用[GameReplayManager.stopRecord](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamereplaymanager-game-replay-0000001690120477#section07455286447)方法完成本次录制。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251103151803.85109449298821038205914130114872:50001231000000:2800:A8D17C52206AFF17415616859AF0118D73FE5D46FA57995C1802ACDE259B595B.png)  
   如录制视频超过已设置的最大时长，系统将自动结束本次录制。

   ```
   gameReplayManager.stopRecord();
   ```

4. 当手动结束或自动结束录制时，可在ReplayCallback接口的[onStop](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/replaycallback-callback-0000001686126937#section1180618199375)方法中实现相关回调处理。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251103151803.90253773150432044895812612361917:50001231000000:2800:7CA82CFF36F98D21381BFF69CE4AB01E5B9F11F1D5D91F208296F183807E465B.png)  
   如因超过最大录制时长，自动结束录制时将会返回401003返回码，并会生成已录制的视频文件。

   ```
   @Override
   public void onStop(RecordResult result) {
       // 根据结束录制返回结果做相应业务逻辑处理
   }
   ```

#### 开启自动录制

调用接口开启自动录制后，可通过多次调用游戏高光时刻生成接口录制多个视频小片段。

1. 建议您在一局游戏开始时，调用[GameReplayManager.startAutoRecord](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamereplaymanager-game-replay-0000001690120477#section13707192654411)方法开启自动录制视频。
   * 系统录制模式：支持录制设备显示的全部画面

     ```
     gameReplayManager.startAutoRecord(new RecordParam()
         .setActivity(null)); // 当前录制画面的Activity,为null则采用系统录制模式,不为null则采用应用内录制模式
     ```

   * 应用内录制模式：仅支持录制应用内显示画面

     ```
     gameReplayManager.startAutoRecord(new RecordParam()
         .setActivity(activity)); // 当前录制画面的Activity,为null则采用系统录制模式,不为null则采用应用内录制模式
     ```

2. 当开启自动录制时，可在ReplayCallback接口的[onStart](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/replaycallback-callback-0000001686126937#section1633614193716)方法中实现相关回调处理。

   ```
   @Override
   public void onStart(RecordResult result) {
       // 根据启动录制返回结果做相应业务逻辑处理
   }
   ```

3. 录制过程中，可调用[GameReplayManager.clipVideo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamereplaymanager-game-replay-0000001690120477#section6225430194416)方法生成高光时刻视频，并指定录制的文件名和录制时长。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251103151803.70900726869453970454059254668742:50001231000000:2800:20F095BE0E4B0D6A7356B45F923F1DCADC0F66DB50B076A77C596CD6827A0E59.png)  
   在结束录制前，可通过多次调用方法录制多段高光时刻视频，但接口调用不宜太频繁，具体要求可参见[使用限制](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/game-highlight-restrictions-0000001685958141#section15687951161416)。

   ```
   gameReplayManager.clipVideo(new ClipParam()
       .setDuration(10)        // 录制时长,取值范围[3, 20],单位：s
       .setFileName("xxx.mp4") // 录制的文件名,须以.mp4结尾
       .setTag("xxxTag"));     // 自定义标签,用于标记回调对应关系,便于失败处理,选填
   ```

4. 当生成高光时刻时，可在ReplayCallback接口的[onVideoCliped](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/replaycallback-callback-0000001686126937#section1991992073714)方法中实现相关回调处理。

   ```
   @Override
   public void onVideoClipped(RecordResult result) {
       // 根据生成高光时刻返回结果做相应业务逻辑处理
   }
   ```

5. 在自动录制视频过程中，系统不会为您主动结束录制，因此一局游戏结束后需手动调用[GameReplayManager.stopRecord](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamereplaymanager-game-replay-0000001690120477#section07455286447)方法结束录制。

   ```
   gameReplayManager.stopRecord();
   ```

6. 当结束自动录制时，可在ReplayCallback接口的[onStop](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/replaycallback-callback-0000001686126937#section1180618199375)方法中实现相关回调处理。

   ```
   @Override
   public void onStop(RecordResult result) {
       // 根据结束录制返回结果做相应业务逻辑处理
   }
   ```
