# 配置工程包

当后续模板部署后，需要将Serverless抽奖活动模板对应的工程包托管到云托管方可使用。  

#### 前提条件

已完成[AGC控制台配置准备](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-serverless-lottery_precfg-0000001241300310)。  

#### 操作步骤

1. 获取Serverless抽奖活动模板的工程包。

   <br />

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174804.87053577245731474782738987196824:50001231000000:2800:EC56DDEC59FB23E2C77FB0601EB2FCC73ABF66ED078FF6CD5A3B435CC044CE62.png)  
   如果您对抽奖活动页面无定制需求，则可以直接使用下载的AGC工程包。

   AGC为您提供了工程包[agc-luckydraw-serverless.zip](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174804.25798755260460347284259077742470:50001231000000:2800:9279746D63140143A8951B41789C79CC5F00E7B95C4875B5C1D17D1A88FBC3D4.zip?needInitFileName=true)。

   工程包的目录结构如下：

   ```
   agc-luckydraw-serverless.zip
    ├-[clouddb]
    │ ├-[clouddb-tables.json]
    │ ├-[raffle_t_raffle_award_example.json]
    │ └-[raffle_t_raffle_campaign_example.json]
    └-[portal]
       └-[dist]
          ├-[config.js]
          ├-[functions.js]
          ├-[index.html]
          └-[static]
   ```

   具体说明如下：
   * clouddb目录中"raffle_t_raffle_award_example.json"和"raffle_t_raffle_campaign_example.json"文件用于导入新增数据的示例json。
   * portal目录包含需要托管的"dist"工程包及SDK配置文件"config.js"、云函数配置文件"functions.js"。

   <br />

2. 复制应用SDK信息到工程包的"portal/dist/config.js"文件中的对应位置，以完成应用信息配置。

   <br />

   具体获取应用SDK信息操作请参见[获取应用的SDK代码片段](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-get-started-web-0000001057762291#section0451145762420)。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174804.41073722849553479283006454996506:50001231000000:2800:4FDA89B5A2E1091EF9848A1CDB46ABB5F83111F2490D2793AAD1F8311C9218A4.png)

   <br />

3. (可选)定制开发抽奖活动页面。

   <br />

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251027174804.31084972271034387617844281750640:50001231000000:2800:FB9001150371C660573BB180A12788B821D14EFAAE5E17D0536B29DE36B891F2.png)  
   * 如果您对抽奖活动页面无定制需求，则此操作无需执行，即可直接使用完成配置的AGC工程包。
   * 如果您对抽奖活动页面有定制需求，例如自定义抽奖页面背景图片，则此操作需要执行，即获取GitHub源代码进行二次开发。
   1. 获取抽奖页面开源代码。
      1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
      2. 在项目列表中找到您需要使用Serverless模板的项目。
      3. 选择"云开发（Serverless） \> Serverless模板"，点击右上角"浏览更多Serverless模板"查看并选择抽奖活动模板，进入模板的详情页面。
      4. 在详情页面的"源代码"区域点击"GitHub"进行获取。
   2. 根据实际需要，进行定制开发和编译。 编译好后，请保存好定制开发后的"dist.zip"工程包。

   <br />
