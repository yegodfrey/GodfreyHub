# 获取当前发言玩家列表

通过本章的开发指导，您可实现获取房间内当前发言玩家列表以及对应的音量分贝的功能。  

#### 前提条件

您已[加入房间](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-joinroom-roomid-ios-0000001323024589)。  

#### 开发步骤

开启音量回调，并通过音量回调接口获取当前发言玩家ID列表以及对应的音量分贝。

1. 调用[HWPGMEngine.getInstance enableSpeakersDetection](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section946512191916)方法设置回调时间间隔来开启音量回调，用于获取当前房间发言玩家列表。

   ```
   HWPGMEngine *pgmeEngine = [HWPGMEngine getInstance];
   [pgmeEngine enableSpeakersDetection:roomId interval:interval]; // roomId：房间ID; interval:当前发言玩家列表回调的时间间隔,有效值范围为[100, 10000],单位: 毫秒,当传入0时,即关闭音量回调
   ```

2. 当成功开启音量回调时，可通过相关接口获得当前发言玩家的ID列表等信息。
   * 1.7.1.300（含）之前的版本：可通过在HWPGMEngineDelegate接口的[onSpeakersDetection](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section1190611110583)方法获得当前发言玩家的ID列表。  
     ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241105115840.83097100155771086348451230107717:50001231000000:2800:B7F91F13CFFF194497231DBBD30E93BA961055817FA0EE5A37EB14717B25FD73.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
     根据当前发言玩家的音量大小降序排序，列表中最多可展示4个发言玩家。

     ```
     - (void)onSpeakersDetection:(NSArray *)openIds {
         // 可根据需求将数据进行处理
     }
     ```

   * 1.7.1.300（不含）之后的版本：在HWPGMEngineDelegate接口的[onSpeakerDetectionEx](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section920520374554)方法中可获得当前发言玩家的ID列表以及对应的音量分贝。  
     ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241105115840.60076338814055997981082073292661:50001231000000:2800:275FAAFBD89E701EA24974D0F3C18CB691BE24D614CD4726BFB9520AB1FFE44F.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
     * 根据当前发言玩家的音量大小降序排序，列表中最多可展示4个发言玩家。
     * 音量分贝大小区间为\[1,100\]。

     ```
     - (void)onSpeakerDetectionEx:(NSMutableArray<VolumeInfo*> *)userVolumeInfos; {
         // 可根据需求将数据进行处理
     }
     ```
