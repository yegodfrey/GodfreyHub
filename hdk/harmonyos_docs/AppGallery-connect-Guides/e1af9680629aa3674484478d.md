# Android使用入门

AppGallery Connect（简称AGC）从构建、质量、增长等方面为您提供了多个开发服务，一个AGC服务的基本开发流程如下：

1. [准备开发环境](#section1270317123213)
2. [创建项目和应用](#section113292017144)
3. [设置数据处理位置](#section17131722114914)
4. [集成AGC SDK](#section1552914317248)
5. [开发应用](#section820114550411)
6. [接入AGC服务](#section1534211161351)

#### 准备开发环境

1. 推荐安装AndroidStudio开发环境，要求最低兼容版本：API 18， Android 4.2，JDK 1.8及以上。
2. 访问AGC页面时推荐使用谷歌浏览器。如果使用win10系统的火狐浏览器，可能出现请求被浏览器拦截，导致点击下载无响应的问题。 处理方法：

   1. 在火狐浏览器地址栏输入about:config。
   2. 查找security.csp.enable，将其切换为 false。
3. 在[华为开发者联盟](https://developer.huawei.com/consumer/cn)上注册成为开发者并完成实名认证，具体方法可参考[账号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。
4. 准备一台用于测试的Android设备或者模拟器。  

#### 创建项目和应用

1. 项目是您在AGC资源的组织实体，您可以将一个应用的不同平台版本添加到同一个项目中。如果您在使用AGC的服务时在AGC中还没有项目，则需要先创建项目，具体操作请参见[创建项目](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createproject-0000001100334664)。
2. 如果您还没有在您的AGC项目中添加应用，请先完成应用的添加，具体操作请参见[创建Android应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createapk-0000001912873100)。  

#### 设置数据处理位置

部分AGC服务涉及应用数据的处理，在使用此类服务前，您需要设置保存数据的站点，具体操作请参见[设置数据处理位置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-data-storage-location-0000001162597847)。  

#### 集成AGC SDK

部分AGC服务提供了集成到本地的AGC SDK，在使用此类服务前需要将AGC SDK集成到您的开发环境，涉及的服务如下：

* 认证服务
* 崩溃服务
* 云函数
* 云数据库
* 远程配置
* App Linking
* 云存储
* 性能管理
* 应用内消息  

#### 在Android Studio中集成（Version Catalog方式管理依赖）

![](https://media:301781745843737573)  
自1.9.3.302版本开始支持使用Version Catalog方式管理依赖，且仅Android Gradle 7.0及以上版本支持使用。

添加配置文件

为了简化配置步骤，AGC为您提供了保存应用配置信息的配置文件。您只需要将配置文件添加到您的工程目录并集成AGC插件，AGC插件可以自动将您在AGC上的应用信息加载到您的开发环境。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择您的应用。 ![](https://media:301781745843779574)

3. 在"项目设置"页面下载配置文件"agconnect-services.json"。
   * 在下载JSON文件前，如果您不打开"不包含密钥"开关，配置文件中会包含密钥信息，可能存在一定的安全风险。建议您将密钥存储在您自己的服务器，并妥善保管。
   * 在下载JSON文件前，如果您打开"不包含密钥"开关，配置文件中将不包含密钥信息。后续您需调用AGC SDK的接口手动将密钥传给AGC使用，具体请参见[通过配置文件参数传递密钥](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-started-android-0000001058210705#section7775132744813)；如果您有更高的安全要求，可使用密钥信息换取Token，通过Token将密钥传递给AGC，具体请参见[通过Token传递密钥](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-started-android-0000001058210705#section86239164318)。

   ![](https://media:301781745843844575)
4. 将"agconnect-services.json"文件拷贝到Android Studio项目的应用级根目录下。 ![](https://media:301781745843877576)

   <br />

声明AGC插件和SDK

1. 打开Android Studio项目级gradle目录下的"libs.versions.toml"文件，声明AGC插件和SDK。
   1. 在\[versions\]中声明AGC插件版本号和SDK版本号。

      ```
      [versions]
      agcVersion = "1.9.6.300"
      ```

   2. 在\[plugins\]中声明AGC插件的id。

      ```
      [plugins]
      agcp = {id = "com.huawei.agconnect.agcp", version.ref = "agcVersion"}
      ```

   3. 在\[libraries\]中声明AGC服务SDK。  

      |服务|配置方法|
      |:----------|:------------------------------------------------------------------------------------------------------------|
      |认证服务|agconnect-auth = { module = "com.huawei.agconnect:agconnect-auth", version.ref = "agcVersion" }|
      |远程配置|agconnect-remoteconfig = {module = "com.huawei.agconnect:agconnect-remoteconfig", version.ref = "agcVersion"}|
      |云函数|agconnect-function = { module = "com.huawei.agconnect:agconnect-function", version.ref = "agcVersion" }|
      |云数据库|agconnect-database = {module = "com.huawei.agconnect:agconnect-cloud-database", version.ref = "agcVersion"}|
      |App Linking|agconnect-applinking = {module = "com.huawei.agconnect:agconnect-applinking", version.ref = "agcVersion"}|
      |崩溃服务|agconnect-crash = { module = "com.huawei.agconnect:agconnect-crash", version.ref = "agcVersion" }|
      |云存储|agconnect-storage = {module = "com.huawei.agconnect:agconnect-storage", version.ref = "agcVersion"}|
      |应用内消息|agconnect-appmessaging = {module = "com.huawei.agconnect:agconnect-appmessaging", version.ref = "agcVersion"}|

2. 在项目级的"build.gradle"文件中，设置AGC插件依赖。

   ```
   plugins {
       alias(libs.plugins.android.application) apply false
       alias(libs.plugins.kotlin.android) apply false
       alias(libs.plugins.kotlin.compose) apply false
       alias(libs.plugins.agcp) apply false
   }
   ```

   ![](https://media:301781745843925577)
3. 打开项目级"settings.gradle"文件，配置Maven仓地址。

   ```
   pluginManagement {
     repositories {
       google {
         content {
           includeGroupByRegex("com\\.android.*")
           includeGroupByRegex("com\\.google.*")
           includeGroupByRegex("androidx.*")
         }
       }
       mavenCentral()
       gradlePluginPortal()
       maven { url 'https://developer.huawei.com/repo/' }
     }
   }
   dependencyResolutionManagement {
     repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
     repositories {
       google()
       mavenCentral()
       maven { url 'https://developer.huawei.com/repo/' }
     }
   }
   ```

1. 打开应用级的"build.gradle"文件，使用alias(libs.plugins.agcp)添加AGC插件。 ![](https://media:301781745844055578 "点击放大")

   |认证服务|implementation libs.agconnect.auth|
   |远程配置|implementation libs.agconnect.remoteconfig|
   |云函数|implementation libs.agconnect.function|
   |云数据库|implementation libs.agconnect.database|

#### （可选）适配R8优化资源收缩器

AGP 9.0默认将 \`android.r8.optimizedResourceShrinking\` 标志设置为true，详情请参考[Android官方文档](https://developer.android.com/topic/performance/app-optimization/enable-app-optimization#keep-resources)。

AGC插件会读取agconnect-services.json文件，并为应用程序生成以agc_\*为前缀的字符串资源，这些资源放在APK的resources.arsc文件中。 应用会在运行时动态访问这些资源。R8优化资源收缩器可能会将这些未在代码中直接（静态）引用的动态字符串资源视为不必要的资源并将其删除。因此，应用可能将以agc_\*为前缀的字符串资源删除，从而导致应用功能异常或者崩溃。

为解决上述问题，请在项目资源（例如res/raw/my.package.keep.xml）中创建XML keep文件，详情请参考[自定义要保留的资源](https://developer.android.google.cn/topic/performance/app-optimization/customize-which-resources-to-keep)。

例如：

```
<?xml version="1.0" encoding="utf-8"?>
<resources xmlns:tools="http://schemas.android.com/tools"
tools:keep="@string/agc_*" /
```

   1. 配置project.properties文件。 由于Eclipse默认不支持AndroidManifest.xml文件的合并，需要在您的工程目录中找到project.properties文件并打开，添加如下配置，用于合并子工程中的Manifest文件。

      ```
       manifestmerger.enabled=true
      ```

   2. 配置包名。 请手动修改BridgeActivity工程下AndroidManifest.xml中的所有"${applicationId}"为您的应用包名。例如：

      修改前：

      ```
      <application>
      <provider
          android:name="com.huawei.agconnect.core.provider.AGConnectInitializeProvider"
          android:authorities="${applicationId}.AGCInitializeProvider"
          android:exported="false" />
      ```

      修改后：

      ```
      <application>
          <provider
              android:name="com.huawei.agconnect.core.provider.AGConnectInitializeProvider"
              android:authorities="com.huawei.crasheclipse.AGCInitializeProvider"
              android:exported="false" />
      ```

6. 添加AppGallery Connect配置文件。
   1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
   2. 在项目列表中找到您的项目，在项目下的应用列表中点击您的应用。
   3. 在"项目设置"页面，点击"应用"栏下的"agconnect-services.json"下载配置文件。
      * 在下载JSON文件前，如果您不打开"不包含密钥"开关，配置文件中会包含密钥信息，可能存在一定的安全风险。建议您将密钥存储在您自己的服务器，并妥善保管。
      * 在下载JSON文件前，如果您打开"不包含密钥"开关，配置文件中将不包含密钥信息。后续您需调用AGC SDK的接口手动将密钥传给AGC使用，具体请参见[设置配置文件参数](#section7775132744813)；如果您有更高的安全要求，可使用密钥信息换取Token，通过Token将密钥传递给AGC，具体请参见[手动设置AGC的Token](#section86239164318)。

      ![](https://media:301781745844585596)
   4. 由于Eclipse不支持AGC插件，您可以将agconnect-services.json文件放置到您的工程中assets目录下，并且在应用的Application类中添加如下代码。如果应用没有Application类，则需要新建，例如新建MyApplication类。

      ```
      public class MyApplication extends Application{
          // TODO: 添加如下代码

          public void onCreate() {
              super.onCreate();

                  AGConnectOptionsBuilder builder = new AGConnectOptionsBuilder();

                  AGConnectInstance.initialize(this, builder);
              } catch (IOException e) {
                  e.printStackTrace();
              }
          }
          // TODO: 添加代码结束             
      }
      ```

   5. 打开您的工程AndroidManifest.xml文件，在"application"模块中添加MyApplication类声明。如果已经声明，则跳过此步骤。

      ```
      <application
          <!—添加声明开始 -->
          android:name=".MyApplication">
          <!—添加声明结束 -->
      </application>
      ```

6. 在Eclipse的菜单栏中点击"Project"，执行"clean"操作。

#### 通过配置文件参数传递密钥

AGC SDK提供了[AGConnectOptionsBuilder](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-agconnectoptionsbulider-0000001116227891)类来对agconnect-services.json文件中的参数进行配置，如果您在下载配置文件时选择了"不包含密钥"，则agconnect-services.json文件中将不包含client_id、client_secret和api_key参数，您必须通过[AGConnectOptionsBuilder](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-agconnectoptionsbulider-0000001116227891)类的接口在应用启动时将参数设置给AGC SDK。

1. 设置client_id、client_secret和api_key等参数。  
   ![](https://media:301781745844630597)  
   建议您在Application或者第一个启动的Activity的onCreate方法中完成此设置。

   ```
   //添加如下代码
   try {
   	AGConnectOptionsBuilder builder = new AGConnectOptionsBuilder();
   	InputStream in = getAssets().open("agconnect-services.json");    //如果使用了AGC插件，删除此行
   	builder.setInputStream(in);                                      //如果使用了AGC插件，删除此行
   	builder.setClientId("client_id");
   	builder.setClientSecret("client_secret");
   	builder.setApiKey("api_key");
   	builder.setCPId("cp_id");
   	builder.setProductId("product_id");
   	builder.setAppId("app_id");
   	AGConnectInstance.initialize(this, builder);
   } catch (IOException e) {
   	e.printStackTrace();
   }
   //TODO: 添加代码结束
   ```

   各参数的值可在"项目设置 \> 常规"页面中查询，client_id替换为项目栏中"Client ID"的值，client_secret替换为项目栏中"Client Secret"的值，api_key替换为"API密钥（凭据）"的值，可点击参数后面的![](https://media:301781745844658598)复制参数值。cp_id替换为"Developer ID"的值，product_id替换为"项目ID"的值，app_id替换为"APP ID"的值。

![](https://media:301781745844708599)  

#### 通过Token传递密钥

如果您认为client_id和client_secret放在json文件里不安全，我们建议您将client_id和client_secret放在自己的服务端。先调用https://connect-drcn.dbankcloud.cn/agc/apigw/oauth2/v1/token接口去换取Token，然后在初始化AGC SDK时通过[setCustomCredentialsProvider](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agccore-agconnectoptionsbulider-0000001116227891#section9602114520710)将Token传给AGC去使用。

Token接口请求示例：

```
POST /agc/apigw/oauth2/v1/token
Host: connect-drcn.dbankcloud.cn
Content-Type: application/json
{
   "grant_type":"client_credentials",
   "client_id":"agc应用页面提供的client_id",
   "client_secret":"agc应用页面提供的client_secret",
   "useJwt":1,
}
```

Token接口响应示例：

```
HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8
{
    "access_token": "eyJhbGciOiJIUzU****************",
    "expires_in": 0
}
```

setCustomCredentialsProvider接口调用示例：

```
"Java"
String tokenStr = "access_token";
long expiration = expires_in;

CustomCredentialsProvider developerClientToken = new CustomCredentialsProvider() {
    @Override
    public Task<Token> getTokens(boolean forceRefresh) {
        TaskCompletionSource<Token> source = new TaskCompletionSource<>();
        Token token;
            token = new Token() {
                @Override
                public long getExpiration() {
                    return expiration;
                }

                @Override
                public long getIssuedAt() {
                    return 0;
                }

                @Override
                public long getNotBefore() {
                    return 0;
                }

                @Override
                public String getTokenString() {
                    return tokenStr;
                }
            };
        source.setResult(token);
        return source.getTask();
    }
};

AGConnectOptionsBuilder builder = new AGConnectOptionsBuilder();
builder.setCustomCredentialsProvider(developerClientToken);
AGConnectInstance.initialize(getApplicationContext(),builder);
```

```
"Kotlin"
val tokenStr = "access_token"
val expiration: Long = expires_in

val developerClientToken = CustomCredentialsProvider {
    val source = TaskCompletionSource<Token>()
    val token: Token
    token = object : Token {
        override fun getExpiration(): Long {
            return expiration
        }

        override fun getIssuedAt(): Long {
            return 0
        }

        override fun getNotBefore(): Long {
            return 0
        }

        override fun getTokenString(): String {
            return tokenStr
        }
    }
    source.setResult(token)
    source.task
}
val builder = AGConnectOptionsBuilder()
builder.setCustomCredentialsProvider(developerClientToken)
AGConnectInstance.initialize(getApplicationContext(), builder)
```

#### 控制发送网络请求

为了保护用户隐私和数据安全，应用不应该允许发送任何网络请求或者进行数据交互。如果在某些业务场景下，需要发送网络请求，必须先获取用户的授权。

为此，AGC SDK从1.5.0.300版本开始，支持开发者可以根据业务需要，自主控制应用是否发送网络请求。

1. 默认关闭发送网络请求。在AndroidManifest.xml的application中增加如下meta-data配置，value必须配置为false。

   ```
   <meta-data
        android:name="com.huawei.agconnect.AccessNetwork"
        android:value="false" />
   ```

<!-- -->

2. 在需要发送网络请求的情况下，首先获取用户的授权，然后调用AccessNetworkManager.getInstance().setAccessNetwork接口打开发送网络请求的开关。

   ```
   AccessNetworkManager.getInstance().setAccessNetwork(true);
   ```

   ![](https://media:301781745844735600)  
   * 当集成的崩溃SDK升级到1.7.0.300及以后的版本，必须先获取用户授权，然后打开开关才可以正常使用崩溃服务。
   * 当集成的应用内消息SDK升级到1.7.0.300及以后的版本，必须先获取用户授权，然后打开开关才可以正常使用应用内消息服务。

   <br />

3. （可选）如果使用了多进程处理机制，则需要在子进程中调用初始化方法。 在Application的onCreate方法中添加初始化代码：

   ```
   if (AGConnectInstance.getInstance() == null) { 
        AGConnectInstance.initialize(getApplicationContext()); 
   }
   ```
