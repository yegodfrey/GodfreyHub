# C#（Native）

游戏多媒体C# SDK提供了实时语音、实时信令、语音消息、效果音播放和语音转文本功能，支持Unity游戏引擎。

## 开发准备

* Unity引擎：推荐2021版本（打Android包或iOS包时使用）
* 团结引擎：推荐1.3.0版本（打HarmonyOS包时使用）

## 集成步骤

### 集成C# SDK

1. 下载[游戏多媒体SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Library/gamemme-sdkdownload-csharp-0000001326343669)压缩包并进行解压，SDK包解压后有以下几个部分。

   |目录名|说明|功能|
   |:------|:---------|:-------|
   |Plugins|SDK库文件。|存放库文件。|
   |GMMESDK|SDK接口代码文件。|提供API接口。|

2. 将SDK中的GMMESDK整个文件夹复制到Unity工程的"**Assets > Scripts** "文件夹中。 说明
   >
   > 在项目代码中通过引入SDK的命名空间，即可使用SDK内部接口。

### 集成Android库

如果您最终打Android包，则需要依赖Android库。

1. 在Unity工程中，配置相关选项。
   1. 选择"**File > Build Settings**"，选中Android平台。
   2. 选择"**Player Settings > Player > Settings for Android > Publishing Settings**"，勾选Build配置项下全部选项。
   3. 选择"**Other Settings > Identification** "，将"**Minimum API Level** "设置为"**5.1 'Lollipop'(API level 22)**"。
2. 打开Unity工程"**Assets > Plugins > Android** "路径中项目级"**baseProjectTemplate.gradle** "文件，添加Maven代码库。
   * 在"**buildscript > repositories**"中配置Maven仓地址。
   * 在"**allprojects > repositories**"中配置Maven仓地址。

   ```screen
   buildscript {
       ext {
           repositories = [
                   // 配置Maven仓地址
   		'https://developer.huawei.com/repo/'
           ]
       }
       repositories {
           rootProject.ext.repositories.each { repourl ->
               maven { url repourl }
           }
           google()
           jcenter()
       }
       dependencies {
           classpath 'com.android.tools.build:gradle:3.4.0'
       }
   }

   allprojects {
       repositories {**ARTIFACTORYREPOSITORY**

           rootProject.ext.repositories.each { repourl ->
               maven { url repourl }
           }
               maven { url 'https://developer.huawei.com/repo/' } // 配置Maven仓地址
               google()
               jcenter()

           flatDir {
               dirs "${project(':unityLibrary').projectDir}/libs"
           }
       }
   }
   ```

3. 打开应用级"**launcherTemplate.gradle** "文件，在"**dependencies** "中添加游戏多媒体SDK的编译依赖。

   ```screen
   dependencies {
       implementation project(':unityLibrary')
       // mmsdk-common：游戏多媒体服务基础SDK，必须集成
       implementation "com.huawei.game.midplatform:mmsdk-common:1.15.1.300"
       // mmsdk-gmme：游戏多媒体服务实时语音模块，实现实时语音通话、范围语音、3D音效和效果音播放功能时集成（可选）
       implementation "com.huawei.game.midplatform:mmsdk-gmme:1.15.1.300"
       // mmsdk-gmme-spatial-sound：游戏多媒体服务3D音效模块，实现3D音效功能时集成，依赖实时语音模块（可选）
       implementation 'com.huawei.game.midplatform:mmsdk-gmme-spatial-sound:1.15.1.300'
       // mmsdk-rtm：游戏多媒体服务实时信令模块，实现实时信令功能时集成（可选）
       implementation 'com.huawei.game.midplatform:mmsdk-rtm:1.15.1.300'
       // mmsdk-gmme-audio-msg：游戏多媒体服务语音消息模块，实现语音消息功能集成（可选）
       implementation "com.huawei.game.midplatform:mmsdk-gmme-audio-msg:1.15.1.300"
       // mmsdk-gmme-voice-conversion：游戏多媒体服务变声模块，实现变声功能时集成（可选）
       implementation 'com.huawei.game.midplatform:mmsdk-gmme-voice-conversion:1.15.1.300'
   }
   ```

4. 在使用游戏多媒体SDK相关模块能力前，您需要在"**AndroidManifest.xml** "文件中的"**manifest** "节点下申请如下权限。
   * 公共权限

     ```screen
     <!--读写存储（媒体和文件）权限-->
     <uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />
     <uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" />
     <!--访问网络权限-->
     <uses-permission android:name="android.permission.INTERNET" />
     <!--获取网络状态-->
     <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
     <!--获取WiFi状态-->
     <uses-permission android:name="android.permission.ACCESS_WIFI_STATE" />
     ```

   * 如果使用语音消息、语音转文本能力，除公共权限外，还需要添加以下权限：

     ```screen
     <!--录音权限-->
     <uses-permission android:name="android.permission.RECORD_AUDIO" />
     ```

   * 如果使用实时语音能力，除公共权限外，还需要添加以下权限：

     ```screen
     <!--使用蓝牙权限-->
     <uses-permission android:name="android.permission.BLUETOOTH" />
     <!--修改声音设置权限-->
     <uses-permission android:name="android.permission.MODIFY_AUDIO_SETTINGS" />
     ```

> 说明
>
> 当您使用Unity完成功能开发并准备打Android包时，您还需要进行相关配置才能打包成功，具体请参见[打包](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-export-csharp-0000001413242206#section92981457123111)。

### 集成iOS plugins

如果您最终打iOS包，则需要依赖iOS plugins。根据实现功能需要，复制SDK中"Plugins > iOS"文件夹下对应framework到Unity工程的"**Assets > Plugins**"文件夹中。

|SDK名称|SDK功能|
|:------------------------------|:----------------------------------|
|HWPGMKit.framework|游戏多媒体服务基础SDK，必须集成。|
|MJExtension.framework|游戏多媒体服务基础SDK，必须集成。|
|HAFormalAnalytics.framework|游戏多媒体服务基础SDK，必须集成。|
|hwffmpeg.framework|游戏多媒体服务实时语音模块，实现语音通话功能时集成。|
|HWPGMEVoiceKit.framework|游戏多媒体服务实时语音模块，实现语音通话功能时集成。|
|HWRTCEngine.framework|游戏多媒体服务实时语音模块，实现语音通话功能时集成。|
|RTC.bundle|游戏多媒体服务实时语音模块，实现语音通话功能时集成。|
|HWPGMEAudioMsgKit.framework|游戏多媒体服务语音消息模块，实现语音消息功能时集成。|
|SocketRocket.framework|游戏多媒体服务语音消息模块，实现语音消息功能时集成。|
|AudioToolCommon.framework|游戏多媒体服务3D音效模块，依赖实时语音模块，实现3D音效功能时集成。|
|HWPGMESpatialAudioKit.framework|游戏多媒体服务3D音效模块，依赖实时语音模块，实现3D音效功能时集成。|
|SpatialAudio.framework|游戏多媒体服务3D音效模块，依赖实时语音模块，实现3D音效功能时集成。|
|HWPGMERtmKit.framework|游戏多媒体服务实时信令模块，实现实时信令功能时集成。|
|Protobuf.framework|游戏多媒体服务实时信令模块，实现实时信令功能时集成。|
|speexdsp.framework|游戏多媒体服务变声模块，实现变声功能时集成。|
|VoiceConversion.framework|游戏多媒体服务变声模块，实现变声功能时集成。|
|kissfft.framework|游戏多媒体服务变声模块，实现变声功能时集成。|
|jsoncpp.framework|游戏多媒体服务变声模块，实现变声功能时集成。|

> 说明
>
> 当您使用Unity完成功能开发并准备打iOS包时，您还需要进行相关配置才能打包成功，具体请参见[打包](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-export-csharp-0000001413242206#section7260139133415)。
