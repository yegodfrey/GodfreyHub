# AdSlot

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|slotId|M|String|展示位ID。 通过运营管理台创建展示位时产生，当前原生广告仅支持国内。|
|sceneId|M|String|场景ID。 由运营配置好场景后生成的ID，可调用到相应的场景。|
|adCount|M|Integer|请求广告数量。 应用榜单、应用搜索展示位此字段取值不超过30，其它场景展示位此字段取值只能填1。 取值范围：[1,30] > 注意 > 请确保广告的展示量，展示量过低会导致后续请求数量较低。|
|pageNumber|O|Integer(32)|当前请求的页码数。 不填写或填写错误可能导致榜单类应用列表广告重复。 取值范围：[1,10]|
|lastItemIds|O|List<String>|最近曝光过的广告，DSP后台会过滤掉这些广告，不填写或填写错误可能导致短时间内多次请求的广告重复。|
|interactTypes|O|List<Integer>|用户交互类型。 当前仅支持应用下载。 取值范围： * 1：应用下载|
|personalize|O|Integer (32)|个性化标识。 > 说明 > 此字段有助于提高广告点击及转化率，建议传入。 取值范围： * 0：非个性化推荐，即所有终端用户看到的广告一样。 * 1：个性化推荐 默认值：0|
|keywords|O|String|搜索关键词。 搜索场景必填。|
|secCategory|O|String|二级分类。 仅支持分类榜单场景，可传多个值用英文逗号隔开。 单包推荐场景不支持此字段，接口上报此字段会上报如下1009错误码。 ```screen {"rtnCode": 1009, "rtnDesc": "data list is empty"} ```|
|associatedApp|O|String|主APP包名。 在关联推荐APP场景下必填。|
|testFlag|O|Integer (32)|测试标记。 > 说明 > 测试状态的展示位只能传1，正式状态的展示位可以传0或1。 取值范围： * 0：非测试。 * 1：测试。 默认值：0|
|pkgNames|O|List<String>|包名列表。 最多传入包的个数可配置，默认为30个。多个包名之间用英文逗号分隔。 此字段仅在单包推荐场景使用。 > 说明 > 单包推荐场景即跟据包名返回推广应用的场景。 示例： ["*pkgName1* "*,* *"pkgName2* *"* *,* *"pkgName3*"] > 注意 > 如果投放任务超投（即投放任务消耗完当日的预算金额）时，系统会限制任务投放，此时不返回应用信息，导致返回的应用数比此字段传的包名个数少。|
