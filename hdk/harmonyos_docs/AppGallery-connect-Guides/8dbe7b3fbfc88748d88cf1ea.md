# 上架前自检

应用上架前请使用AppGallery Connect应用检查工具对应用进行检查，并参考自检Checklist排查是否满足上架要求。

## 自检工具

参考[接入检测](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-self-check-0000001100158786)中的步骤使用自检工具对应进行自检，并根据自检报告修改应用。

## 上架前Checklist

为尽早发现问题，减少您提交审核后被打回的概率，华为提供了提交审核前自检checklist，请参见检查您的联运应用或联运游戏是否满足要求。

* 联运应用请参见[联运应用Checklist](https://developer.huawei.com/consumer/cn/doc/promotion/access-guide-0000001063305339#section121848397366)。
* 联运游戏请参见[联运游戏Checklist](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/pre-release-check-0000001050121544)。
