|序号|任务|说明|
|:-|:---------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[创建项目](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-createprojectandapp-0000001275170098#section1264513378315)|项目是您在AppGallery Connect（以下简称AGC）资源的组织实体。当您需要使用云存储服务时，您需要先在AGC中创建您的项目。 说明： 您可以通过创建不同的项目，实现分别在测试环境和开发环境使用云存储。|
|2|[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)|-|
|3|[下载项目级认证凭据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-download-credentials-0000001334262141)|获取项目级认证凭据，供后续初始化SDK时使用。|
|4|[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-sdk-nodejs-0000001055127457)|将云存储Node.js Server SDK集成到您的开发环境。|
|5|[初始化存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-initialize-bucket-nodejs-0000001281809822)|在使用云存储功能前，需初始化存储实例。|
|6|管理存储实例与文件|通过调用云存储Node.js Server SDK的API，您可以： * 进行[存储实例管理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-instance-management-nodejs-0000001211091803)，如新增、删除、列举存储实例。 * [设置跨域的相关配置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-configuring-cors-0000001139623179)，以在不同的站点访问指定的存储实例。 * [创建Bucket对象](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-createreference-nodejs-0000001055327465#section18561161643714)，通过Bucket对象对存储实例进行[上传文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-upload-nodejs-0000001054967473)、[列举文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-list-nodejs-0000001054767445)等操作。 * [创建File对象](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-createreference-nodejs-0000001055327465#section17165283611)，通过File对象对文件进行[下载](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-download-nodejs-0000001055727414)、[删除](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-delete-nodejs-0000001055567404)、[设置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-metadata-nodejs-0000001054848921)元数据等操作。|
