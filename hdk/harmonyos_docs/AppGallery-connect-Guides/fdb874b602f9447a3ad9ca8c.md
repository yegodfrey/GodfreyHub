# 修改函数高级配置

函数列表中点击函数名称，进入函数详情页面。选择"函数配置"页签，您可以修改"高级配置"区域的"超时时长"、"实例并发"函数高级配置。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241106152802.34699056764744858204005474407071:50001231000000:2800:88BB15EC319EDA1570E9819E5912DF59811C0EA7F886E34660F108A33FA3EC3B.png?needInitFileName=true?needInitFileName=true)

高级配置项的配置要求如下：

|配置项|**说明**|
|:---|:-------------------------------------------------------------------------------------------------------|
|超时时长|函数最大运行时长，超过该时长则默认函数执行失败，单位为s，取值范围为1~1800。 > 说明 > * "同步"调用方式时，函数最大运行时长为55s。 > * "异步"调用方式时，函数最大运行时长为1800s。|
|实例并发|函数请求并发量上限，单位为个，取值范围为1~10000。|
