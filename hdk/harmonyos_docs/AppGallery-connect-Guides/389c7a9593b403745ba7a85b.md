# 账号重认证

#### 前提条件

* 您需要在AGC控制台[开通认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyts6-integration-0000001553624922)。  

#### 开发步骤

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251226181008.02658808745391859183127729902674:50001231000000:2800:6A705680F7EA341ED146C5290F7BBB068724A05B4987AEBB37DA1CCFAE81427A.png "点击放大")  
对于销户、修改密码、关联账号以及重置手机账号和邮箱账号这些敏感操作，要求用户必须在5分钟内登录过应用才能执行。如果您执行敏感操作时已经登录超过5分钟，该操作会抛出AGCAuthException异常，并收到错误码为203818081的错误，这种情况下您可以先调用[AGConnectUser.userReauthenticate](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts6-agconnectuser-0000001553625142#section13849101518298)，重认证账号后再执行敏感操作。

```
  let credential = '';
  if(verifyCode){
    credential = PhoneAuthProvider.credentialWithVerifyCode(countryCode, account, password, verifyCode);
  }else{
    credential = PhoneAuthProvider.credentialWithPassword(countryCode, account, password);
  }
  agconnect.auth().getCurrentUser().then(async user => {
    if(user){
      await agconnect.auth().userReauthenticate(credential);
    }
  });
```
