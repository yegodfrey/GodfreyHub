# 获取SDK配置信息

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择您的应用，进入"项目设置"页面。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704165813.87987280102176999440051984956566:50001231000000:2800:80155B69800837C7858C71B23112B9DC4CFB35468CAEA6792443B68CDFC2D81C.png)

3. 配置网站限制。

   当您的Web应用需要限制仅指定网站或IP地址才可访问已开通的API时，您可点击"网站限制"后的![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704165813.29718621330091233124971385601368:50001231000000:2800:E5AD0FD9F7406CEFAF06754FE69B16C19C7D06BE46A7C1C13C7112CDFDA6021B.png)，填写指定的域名地址。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704165813.44652244176382605789285523989738:50001231000000:2800:97CFB3CF1813C973BEC80304B49E2F86B71EE8C402DC84EE6DCDE52C67EABE3D.png)  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704165813.62526462263668468637548532634574:50001231000000:2800:23BA9D80E6DE2B3BC30ED4D00E098729DA5721A25B23036701B61E1AF9A6533E.png)  
   * 域名地址需要以http://和https://开头。
   * 最多支持配置5个地址，多个地址使用逗号分隔。
4. 获取应用的相关配置信息。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704165813.94423450850018740974689160893460:50001231000000:2800:7AB489EE6D34BD8D8D23B84513238A13C050AE476FFC277E7D44498E5A3D469E.png)  
   * 配置文件中默认会包含AGC为应用分配的客户端密钥和API密钥信息，其中客户端密钥和API密钥均为密文。
   * 您可以在下载JSON文件前打开"不包含密钥"开关，配置文件中将不包含密钥信息，由您自行调用AGC SDK的接口手动配置。
   * 如果您的套餐升级到了付费档，为避免被冒用产生异常账单，建议您将密钥存储在您自己的服务器，并妥善保管。
