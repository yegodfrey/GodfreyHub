# API服务

购买API服务后，您可以参考服务详情页的API文档调用API。在API调用次数配额即将用尽时，您还可以[再次购买服务](#section193682034763)。

## 筛选并查看

购买API服务成功后，您可以在已购服务列表筛选出API服务进行管理。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)，将鼠标悬停在右上角账户中心区域，点击"已购服务"，进入已购服务列表。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4b/v3/k5B80u9nTTeEcqLk4RnCpA/zh-cn_image_0000001392110596.png?HW-CC-KV=V1&HW-CC-Date=20261008T160313Z&HW-CC-Expire=31536000000&HW-CC-Sign=85D125D68DC2B0D0D805CD35C4D931C9487B4DB0D41598A6853EF30471F61B5E)
2. 已购服务列表中的订单状态有开通中、开通失败、已开通、已过期四种。每种状态的含义如下：

   |状态|含义|
   |:---|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |开通中|已购买但还未开通成功的订单。|
   |开通失败|已购买但是开通失败的订单，对于此状态订单您可以[重试开通](#section19674629182014)。|
   |已开通|已购买并开通成功的服务订单，您可以通过查看API文档使用服务，同时您还可以选择[变更规格](#section72710185512)和[续费](#section1996341183412)等操作。 > 说明 > 当您执行变更规格或续费等操作失败后，订单状态会分别变为"已开通（变更规格失败）"和"已开通（续费失败）"等。|
   |已过期|已购买开通但已过期的服务订单，您可以根据套餐类型选择[续费](#section1996341183412)或[再次购买](#section193682034763)服务。 > 说明 > 当您再次购买或续费等失败后，订单状态会分别变为"已过期（再次购买失败）"和"已过期（续费失败）"。|

   在已购服务管理页，选择"交付方式"为"API服务"筛选出要处理的订单，点击服务订单条目右侧"详情"，查看服务基本信息、使用方式、当前规格、资源配额及相关订单。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/62/v3/rclV9o3nQmCPHec0xxJXlA/zh-cn_image_0000001475167417.png?HW-CC-KV=V1&HW-CC-Date=20261008T160313Z&HW-CC-Expire=31536000000&HW-CC-Sign=686D6984B0BCCE1F3E5F2B3A934071FE9EC77B0410B888D3567C8C9D028DCADA)

## 使用API服务

您可以通过调用API或集成SDK的方式使用API服务，从而获取API服务商提供的数据或资源。

1. 进入已购服务列表，点击"已开通"服务订单右侧"详情"进入服务详情页。
2. 点击右上角"查看API文档"，进入API文档。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/74/v3/5MIxP5KvS0OoNHSEdgZwMA/zh-cn_image_0000001392230560.png?HW-CC-KV=V1&HW-CC-Date=20261008T160313Z&HW-CC-Expire=31536000000&HW-CC-Sign=098107080F73F63E6E662F9B7E1607C3BD489B17CEBAFF60A4180534F024EC95)

3. 查看API文档，并使用获取的访问Token调用。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/35/v3/N8qef19aSCWbh7JQT59Uaw/zh-cn_image_0000001442390469.png?HW-CC-KV=V1&HW-CC-Date=20261008T160313Z&HW-CC-Expire=31536000000&HW-CC-Sign=620DD77B6C9F2704CAC8FDB70A389A25D64E78A68AE2B6249C7A888DDECECAF7)

   > 说明
   > * 通过集成SDK方式使用API服务前需要下载SDK后配合指导文档使用。
   > * 如果服务商提供了API管理台，服务详情页右上角会展示"去管理"，点击跳转后可管理API服务。

## 续费及再次购买

### 续费

当您购买了包周期API服务且服务订单处于"已开通"或"已过期"状态时，如果想延长服务使用时间，您可以进行续费操作。续费方式如下：

1. 进入已购服务列表，选择并筛选出状态为"已开通"或"已过期"服务订单，点击订单右侧"详情"进入服务详情页点击右上角"续费"。 说明
   >
   > 如续费失败，您可以点击右侧"详情"，在详情页点击"重试通知"；若重试仍不成功，您可以点击"反馈问题"反馈。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c5/v3/wiTkF7C5TBekGR4NdIleOQ/zh-cn_image_0000001442630257.png?HW-CC-KV=V1&HW-CC-Date=20261008T160313Z&HW-CC-Expire=31536000000&HW-CC-Sign=683E8AA63B9F2B8112FFAA69B515859916DC2F8737593920D2FD4F0FCCF06AB0)
2. 在服务商品详情页，选择合适的套餐及规格等后进行再次购买。 注意
   >
   > 当您的API服务配额即将到期或已经到期时，AGC会以邮件、互动中心消息或短信的方式通知您，您可以在收到通知消息后续费。

### 再次购买

当您购买了包周期API服务且服务订单处于"已开通"或"已过期"两种状态时，您可以选择再次购买服务。购买方式如下：

1. 进入已购服务列表，选择并筛选出状态为"已开通"或"已过期"的服务订单，点击订单右侧"详情"进入服务详情页，点击右上角"购买资源包"。 说明
   >
   > 如再次购买失败，您可以点击右侧"详情"，在详情页点击"重试通知"；若重试仍不成功，您可以点击"反馈问题"反馈。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/59/v3/JdZmBq6nTPu5QxO1CFwbUg/zh-cn_image_0000001391751480.png?HW-CC-KV=V1&HW-CC-Date=20261008T160313Z&HW-CC-Expire=31536000000&HW-CC-Sign=599A001AEAA1DF59FCE480F65651B1807C711D13258E91F670CC334958CDDD7A)
2. 在服务商品详情页，选择合适的套餐及规格等后进行再次购买。 注意
   >
   > 当您的API服务配额即将到期或已经到期时，精选应用服务会以邮件、互动中心消息或短信的方式通知您，您可以在收到通知消息后再次购买。

## 变更规格

当您已购买的API服务的规格已经不能满足您的使用需求，您可以选择变更服务规格。
> 说明
>
> * 只有购买了正式服务且该服务支持规格变更的情况下，您才可以变更服务规格。
> * 变更规格失败时，您可以点击右侧"详情"，在详情页点击"重试通知"；若重试仍不成功，您可以点击"反馈问题"反馈。

1. 进入已购服务列表，点击"已开通"服务订单右侧"详情"进入服务详情页，点击右上角"变更规格"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ba/v3/lFskx9-dQwCDVoyzNs40sA/zh-cn_image_0000001391911008.png?HW-CC-KV=V1&HW-CC-Date=20261008T160313Z&HW-CC-Expire=31536000000&HW-CC-Sign=BBC5640D7522D1B0FDBD2342CCFA510BD61D5E81432DECC074F57492A0CA8810)

2. 在服务商品详情页，变更商品规格后再次购买。 注意
   > * 当您由价格较高规格套餐更换为价格较低规格套餐时，不会退还差价。
   > * 当您由价格较低规格套餐更换为价格较高规格套餐时，应该补充支付的价格为： [（当前规格套餐价格-原规格套餐价格）*（当前周期剩余天数/当前周期总天数+剩余周期数）]*折扣-代金券金额。

## 重试开通

当您购买服务成功但服务却开通失败时，您可以进入已购服务列表，点击状态为"开通失败"服务订单右侧的"详情"，点击顶部提示中的"重试开通"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/56/v3/1W3NsqB-S9CqibE-xH7Unw/zh-cn_image_0000001416083580.png?HW-CC-KV=V1&HW-CC-Date=20261008T160313Z&HW-CC-Expire=31536000000&HW-CC-Sign=4CC5B4733F6777B6D4C74343C7F6740864C57F1C86B85C3E3F5E02D7CA04AB6F)

点击后订单状态将会变为"开通中"，直到AGC返回并刷新重试开通结果。如若您多次重试开通后仍失败，您也可以点击订单状态右侧"问题反馈"，填写问题详情并提交后等待运维人员处理。 说明
>
> 您反馈的开通失败问题将在1个工作日内在互动中心得到回复，请及时关注互动中心消息。
