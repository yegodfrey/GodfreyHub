# 概述

开发者通过云侧访问云开发资源时，支持如下两种场景：

* 如您没有自己的服务器，推荐通过AGC云函数访问云开发资源，此方式无需手动下载凭据文件，具体请参考[（推荐）从云函数访问](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/from-cloudfunction-access-0000001935200861)。
* 如您搭建了自己的服务器且希望通过自己的服务器来访问云开发资源，则需手动下载凭据文件并集成到代码中，具体请参考[从服务器访问](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/from-selfbuiltserver-access-0000001892441242)。

请根据实际情况进行选择。
