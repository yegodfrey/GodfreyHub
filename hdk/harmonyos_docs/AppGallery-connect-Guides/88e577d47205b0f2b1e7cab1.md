# 创建官方连接器

![](https://media:201780626741062868)  
目前仅支持内容风控服务类型的官方连接器，且该类型的官方连接器仅对HarmonyOS NEXT元服务开放使用。  

#### 前提条件

在创建内容风控服务官方连接器之前，您首先需要开通内容风控服务，开通方法请参考[开通内容风控服务](https://developer.huawei.com/consumer/cn/doc/atomic-guides/content-moderation-service-prep-enable)。若未开通，将无法使用该服务对文本和图片进行安全合规审核。如果已经开通，可跳过此步骤。  

#### 创建官方连接器

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击您的项目。
3. 在左侧导航栏选择"云开发（Serverless）\> 云函数"，进入云函数主界面。
4. 选择"连接器"页签，点击"新建"。  
   ![](https://media:201780626741122869)  
   如果提示连接器已发布新版本，如下图所示，请先点击"升级"将连接器升级至最新版本后再创建连接器。

   ![](https://media:201780626741162870 "点击放大")
5. 在弹出的"创建连接器"框中，填写连接器信息。 ![](https://media:201780626741210871)

   |参数|说明|
   |:---|:------------------------------------------|
   |类型|选择"官方连接器"。|
   |官方类型|目前仅支持内容风控服务类型，请选择"内容风控服务"。|
   |名称|连接器英文名称，为连接器唯一标识，支持字母、数字和下划线（_），长度不超过58个字符。|
   |描述|可选，连接器描述信息，长度不超过255个字符。|

6. 相关信息填写完成后，点击"开始创建"，连接器即创建完成。 ![](https://media:201780626741243872)

7. 创建成功后，在连接器列表中点击连接器名称进入详情页面，便可在"连接器方法"区域查看该官方连接器内置的方法及对应参数定义。具体方法及参数的详细解释，请参见[内容风控服务](https://developer.huawei.com/consumer/cn/doc/atomic-guides/content-moderation-service-prep-connector-create)的相关说明。
