# 版本升级

若打开工具时未升级工具版本，您可以在"版本升级"页面进行升级。

1. 打开"版本升级"页面，点击"立即升级"。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110234.19228002144858243191388419253499:50001231000000:2800:A8B76A5EAF7184ABBB453A2DD347D94C1E925A271587800ED28B6E4E1278B8B0.png)  
   若页面出现如下告警信息，建议您立即升级工具版本，否则可能影响您使用工具。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110234.12258289346177547062941126507057:50001231000000:2800:7E9D4E7FCCA4D7666C2FF3472E4947D37D9245C9B7B992A7E4F49DEE80032F3A.png)
2. 请耐心等待最新版本的下载。工具成功下载后，您可以根据提示安装工具。
