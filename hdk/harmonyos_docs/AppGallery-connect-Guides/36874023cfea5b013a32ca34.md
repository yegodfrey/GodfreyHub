# 登出

#### 前提条件

* 您需要在AGC控制台[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-integration-sdk-0000001326347605)。  

#### 开发步骤

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114606.77912217299374797398658715801980:50001231000000:2800:C5FA0ABA015C7AC62FD817566037C793E3B9E07A17B087CE5B5C6FE909911ACE.png "点击放大")

当用户不再使用应用，或者需要使用其他账号登录时，需要调用[\[AGCAuth signOut\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346#section8321645121219)登出当前用户。用户一旦登出，端侧用户信息和Token将被清除。  

```
"Objective-C"
[[AGCAuth getInstance] signOut];
```

```
"Swift"
AGCAuth.instance().signOut()
```
