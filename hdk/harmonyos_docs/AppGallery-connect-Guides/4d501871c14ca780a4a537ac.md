# 归因

为了支持后续支付归因，在进行支付操作前，您需要调用[getSignInIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section76155516411)接口完成一次显式登录并返回成功。

```
/**     
 * Obtain the Intent of the Huawei account login authorization page, and open the Huawei account     
 * login authorization page by calling startActivityForResult(Intent, int).         
 * 获取到华为账号登录授权页面的Intent，并通过调用startActivityForResult(Intent, int)打开华为账号登录授权页面。     
 */
public void signInNewWay() {
         AccountAuthService   accountAuthService = AccountAuthManager.getService(this, new AccountAuthParamsHelper()
                    .createParams());
         Intent intent = accountAuthService.getSignInIntent();
         startActivityForResult(intent, REQUEST_CODE_SIGN_IN);
}
```
