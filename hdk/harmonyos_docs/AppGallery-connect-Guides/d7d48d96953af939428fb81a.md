# VK

您可以在应用中集成VK（VKontakte）认证方式，让您的用户可以使用自己的VK账号进行AppGallery Connect身份验证。  

#### 前提条件

* 您需要在AGC控制台[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-integration-sdk-0000001325876845)。  

#### 开发步骤

认证服务提供了两种开发方式接入VK账号：

* 推荐您使用统一登录接入方式，请参见[统一登录接入方式](#section621717101457)。
* 您也可以使用传统接入方式，请参见[传统接入方式](#section8443195714912)。  

#### 统一登录接入方式

<br />

1. 添加SDK依赖。
   * Android Studio开发环境
     * Version Catalog方式管理依赖
       1. 打开Android Studio项目级gradle目录下的"libs.versions.toml"文件，在\[versions\]中声明VKID SDK版本号和androidx appcompat版本号。

          ```
          [versions]
          vkVersion = "2.5.1"  # 以2.5.1为例
          appcompatVersion = "1.3.0"  # 以1.3.0为例
          ```

       2. 在"libs.versions.toml"文件的\[libraries\]中声明华为认证SDK、androidx appcompat SDK 和VKID SDK。

          ```
          [libraries]
          agconnect-auth-vk = { module = "com.huawei.agconnect:agconnect-auth-vk", version.ref = "agcVersion" }  # agcVersion声明请参见声明AGC插件和SDK。
          androidx-appcompat = { group = "androidx.appcompat", name = "appcompat", version.ref = "appcompatVersion" }
          vkid-sdk = { module = "com.vk.id:vkid", version.ref = "vkVersion" }
          ```

       3. 在应用级"build.gradle"文件的"dependencies"中添加华为认证SDK、androidx appcompat SDK和VKID SDK的编译依赖。

          ```
          dependencies {      
               implementation libs.agconnect.auth.vk
               implementation libs.androidx.appcompat     
               implementation libs.vkid.sdk
          }
          ```

     * 非Version Catalog方式管理依赖 打开应用级gradle文件（通常在 app/build.gradle），在"dependencies"中添加华为认证SDK、androidx appcompat SDK和VKID SDK的编译依赖：

       ```
       dependencies {
           implementation "com.huawei.agconnect:agconnect-auth-vk:1.9.4.300"
           implementation "androidx.appcompat:appcompat:{appcompatVersion}"
           implementation "com.vk.id:vkid:{version}"
       }
       ```

   * Eclipse开发环境  
     打开aar2eclipse/aar目录下的build.gradle文件，在"dependencies"中添加华为认证SDK，androidx appcompat SDK和VKID SDK的编译依赖。具体步骤参见[Eclipse开发环境集成AGC SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-integration-sdk-0000001325876845#section1878849165620)。

     ```
     dependencies {
         embed "com.huawei.agconnect:agconnect-auth-vk:1.9.4.300"
         embed "androidx.appcompat:appcompat:{appcompatVersion}"
         embed "com.vk.id:vkid:{version}"
     }
     ```

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143820.16303767021546787545065245258523:50001231000000:2800:531E9DFC45D461D1039FEB9371685584FC38E8FF297C989103CAD42C378A9286.png)  
   * 示例中的vkVersion和{version}请替换为VKID SDK的最新版本号，appcompatVersion和{appcompatVersion}请替换为androidx appcompat SDK的最新版本号，华为不负责更新。
   * 由于华为未提供VKID SDK依赖包，您可以在VK平台下载最新版本的VKID SDK依赖包进行手动集成。
2. 配置VK账号登录所需参数。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143820.41425864644080178111066889911228:50001231000000:2800:6B1DDF6FE4EBFFCF5AAD694BCCBA69AE1310F088483228F5C2D844CEB09DF52D.png)  
   您需要登录[VK平台](https://vk.com/editapp?act=create)，创建一个Standalone app，并且配置包名和签名。

   此种方式支持的最低Android版本是5.0（minSDKVersion=21）。

   在应用级build.gradle文件中配置VK应用信息，请参考如下示例。

   ```
           addManifestPlaceholders([
                   "VKIDClientID": "54***24", // VK平台提供的APP ID
                   "VKIDClientSecret": "yJwkgxd******b4X0eiv", // VK平台提供的Client Secret
                   "VKIDRedirectHost": "vk.ru", // 通常设置为vk.ru
                   "VKIDRedirectScheme": "vk54***24" // 通常设置为vk+VK平台提供的APP ID
           ])
   ```

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143820.57532458292280716839352792804588:50001231000000:2800:7A1A7922AAFAE43EF607D15E02C2DD89EDFAD4A4AD1DDA041A7FC31317B094B4.png)
3. 在Application的OnCreate方法中初始化VKID SDK。  

   ```
   "Java"
   VKID.Companion.init(this);
   ```

   ```
   "Kotlin"
   VKID.init(this)
   ```

4. （可选）如果您使用统一登录接入方式，可以设置VK账号登录的回调地址。如果不设置，回调地址将默认为{VKIDRedirectScheme} + "://vk.ru/blank.html"。  

   ```
   "Java"
   AGConnectApi.getInstance().getOptions().setOption("/vk/redirect_url","your vk redirect_url");
   ```

   ```
   "Kotlin"
   AGConnectApi.getInstance().options.setOption("/vk/redirect_url", "your vk redirect_url")
   ```

5. 调用[AGConnectAuth.signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauth-0000001054482530#section125666562219)，登录VK账号。  

   ```
   "Java"
   AGConnectAuth.getInstance().signIn(this,AGConnectAuthCredential.VK_Provider).addOnSuccessListener(new OnSuccessListener<SignInResult>() {
           @Override
           public void onSuccess(SignInResult signInResult) {
                   // onSuccess
                   AGConnectUser user =  signInResult.getUser();
           }
   })
   .addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
                   // onFail
           }
   });
   ```

   ```
   "Kotlin"
   AGConnectAuth.getInstance().signIn(this, AGConnectAuthCredential.VK_Provider).addOnSuccessListener {
       // updateUI
   }.addOnFailureListener {
       // onFailure
   }
   ```

#### 传统接入方式

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143820.26832944722557265222635214056132:50001231000000:2800:45DBE5CA94CF48AD51312E201D010D2163D7655B291240A23BEBDEA3AF031406.png "点击放大")

1. 在应用的登录界面，初始化[AGConnectAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauth-0000001054482530)实例，获取AGC的用户信息，检查是否有已经登录的用户。如果有则可以直接进入用户界面，否则显示登录界面。  

   ```
   "Java"
   AGConnectUser user = AGConnectAuth.getInstance().getCurrentUser();
   ```

   ```
   "Kotlin"
   val user = AGConnectAuth.getInstance().currentUser
   ```

2. VK账号登录，并获取VK账号的用户授权信息。然后使用获取的授权信息生成credential，并调用[AGConnectAuth.signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauth-0000001054482530#section298148131715)实现登录。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143820.57978714250182694299616933752405:50001231000000:2800:84482E599460DC51D40929EFF2105CCC8CDCC00A8E9CF8F1AF97804D52973CAC.png)  
   此步骤仅供参考，更详细内容，请参见[VK接入指南](https://vk.com/dev/android_sdk)。

   AGC SDK需要将此步骤中登录成功返回的authCode透传给AGC Auth服务器，AGC Auth服务器会到VK后台做用户验证。建议您使用VKID SDK的2.5.1及以上版本。  

   ```
   "Java"
   // 创建一个属性codeVerifier，用于生成VKAuthParam
   private String codeVerifier = "";
   // 创建一个VKIDAuthCallback回调，用于处理VK授权成功后返回的结果
   public final VKIDAuthCallback callback = new VKIDAuthCallback() {
     @Override
     public void onFail(@NotNull VKIDAuthFail vkidAuthFail) {
     }

     @Override
     public void onAuthCode(@NotNull AuthCodeData authCodeData, boolean b) {
       // 使用从VK账号获取的authCode和deviceId，先通过调用VKAuthProvider.credentialWithParam生成VKAuthParam，再由VKAuthParam生成credential，最后调用AGConnectAuth.signIn实现登录
       String authCode = authCodeData.getCode();
       String deviceId = authCodeData.getDeviceId();
       String redirectUrl = "vk" + "your vk clientId" + "://vk.ru/blank.html";  // 例如"vk54****24://vk.ru/blank.html"
       VKAuthParam vkAuthParam = new VKAuthParam(VKID.Companion.getInstance().getClientId(), deviceId, authCode, codeVerifier, redirectUrl);
       AGConnectAuthCredential credential = VKAuthProvider.credentialWithParam(vkAuthParam);

       // 生成credential，进行AGC登录
       AGConnectAuth.getInstance().signIn(credential)
         .addOnSuccessListener(new OnSuccessListener<SignInResult>() {
         @Override
         public void onSuccess(SignInResult signInResult) {
           // onSuccess
           AGConnectUser user = signInResult.getUser();
         }
       })
       .addOnFailureListener(new OnFailureListener() {
         @Override
         public void onFailure(Exception e) {
           // onFail
         }
       });
     }

     // 调用VK授权方法
     VKIDAuthParams params = VKIDAuthParamsKt.VKIDAuthParams(builder -> {
       builder.setScopes(new HashSet<>(Arrays.asList("email", "phone")));
       codeVerifier = PKCEUtil.generateCodeVerifier(32);  // 此codeVerifier用于生成VKAuthParam
       String codeChallenge = PKCEUtil.generateCodeChallenge(codeVerifier);
       builder.setCodeChallenge(codeChallenge);
       return Unit.INSTANCE;
     });
     VKID.Companion.getInstance().authorize((LifecycleOwner) this, callback, params);   // this仅供参考，请根据实际上下文进行修改
   ```

   ```
   "Kotlin"
   // 创建一个属性codeVerifier，用于生成VKAuthParam
   private var codeVerifier: String? = ""
   // 创建一个VKIDAuthCallback回调，用于处理VK授权成功后返回的结果
   public val callback = object : VKIDAuthCallback {
     override fun onAuth(accessToken: AccessToken) {
       val token = accessToken.token
     }

     override fun onAuthCode(data: AuthCodeData, isCompletion: Boolean) {
       // 使用从VK账号获取的authCode和deviceId，先通过调用VKAuthProvider.credentialWithParam生成VKAuthParam，再由VKAuthParam生成credential，最后调用AGConnectAuth.signIn实现登录
       val authCode = data.code
       val deviceId = data.deviceId
       val redirectUrl = "vk" + "your vk clientId" + "://vk.ru/blank.html"  // 例如"vk54****24://vk.ru/blank.html"
       val vkAuthParam = VKAuthParam(VKID.instance.clientId, deviceId, authCode, codeVerifier, redirectUrl)
       val credential = VKAuthProvider.credentialWithParam(vkAuthParam)

       // 生成credential，进行AGC登录
       AGConnectAuth.getInstance().signIn(credential).addOnSuccessListener {
         // onSuccess
         val user = it.user
       }.addOnFailureListener {
         // onFail
       }
     }

     override fun onFail(fail: VKIDAuthFail) {
       when (fail) {
         is VKIDAuthFail.Canceled -> {
         }
         else -> {
         }
       }
     }
   }

   // 调用VK授权方法
   codeVerifier = PKCEUtil.generateCodeVerifier(32)
   val params = VKIDAuthParams {
     scopes = setOf("phone", "email")
     codeChallenge = PKCEUtil.generateCodeChallenge(codeVerifier)
   }
   VKID.instance.authorize(
     this@MainActivity,   // this@MainActivity仅供参考，请根据实际上下文进行修改
     callback,
     params
   )
   ```

#### 更多信息

* 您如果想让用户可以使用多个账号登录您的应用，可以将多个[账号进行关联](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-associated-0000001053692650)。
* 当用户不需要使用应用，或者需要切换其他账号登录认证，可以先执行[登出](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-sign-out-0000001053612647)。
* 当用户需要注销当前用户，可以进行[销户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-deleteuser-0000001057730521)。
* 对于销户、修改密码、关联账号以及重置手机账号和邮箱账号等敏感操作，为了提高安全性，需要用户必须在5分钟内登录过才能执行。如果用户执行敏感操作时登录超过5分钟，需要[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-reauthenticate-0000001127287737)后再执行敏感操作。
* 您可以参考[异常处理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-troubleshooting-0000001052932665)实现自己的异常处理机制，从而减少异常情况的发生。
* 您可以使用云函数触发器来接收用户注册、登录、销户等关键事件，从而[扩展认证服务的能力](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-extension-0000001053372708)。
* 您可以参考[管理用户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-user-manage-0000001606051705)对用户进行解锁、停用等操作。
