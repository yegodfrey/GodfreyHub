# Flutter使用入门

![](https://media:201779675965896613)  
AGC Flutter插件仅适用于Android和iOS平台。

AppGallery Connect（简称AGC）从构建、质量、增长、华为云方面给开发者提供了多个开发服务，一个AGC服务的基本开发流程如下：

1. [准备开发环境](#section10125185719117)
2. [创建项目和应用](#section113292017144)
3. [设置数据处理位置](#section53891849102012)
4. [集成AGC Flutter插件](#section989922512418)
5. [开发应用](#section820114550411)

#### 准备开发环境

* Flutter开发环境准备和项目创建，请参见[开始使用Flutter](https://flutter.dev/docs/get-started/install)。  
  ![](https://media:201779675965921614)  
  请确保您使用Stable channel版本的Flutter SDK。
* Android开发环境准备，请参见[Android开发环境准备](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-started-android-0000001058210705#section1270317123213)。
* iOS开发环境准备，请参见[iOS开发环境准备](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-started-ios-0000001058442274#section1491511413717)。  

#### 创建项目和应用

1. 项目是您在AGC资源的组织实体，您可以将一个应用的不同平台版本添加到同一个项目中。如果您在使用AGC的服务时在AGC中还没有项目，则需要先创建项目，具体操作请参见[创建项目](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createproject-0000001100334664)。
2. 如果您还没有在您的AGC项目中添加应用，请先完成应用的添加。您可以直接添加一个新应用，也可以添加一个未归属任何项目的已有应用。请参见[创建应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createapp-0000001146718717)。  

#### 设置数据处理位置

部分AGC服务涉及应用数据的处理，在使用此类服务前，您需要设置保存数据的站点，具体操作请参见[设置数据处理位置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-data-storage-location-0000001162597847)。  

#### 集成AGC Flutter插件

当前仅部分AGC服务提供了Flutter插件，在使用此类服务前需要将AGC Flutter插件集成到您的开发环境，涉及的服务如下：

* 认证服务
* 崩溃服务
* 远程配置服务
* App Linking
* 应用内消息
* 云函数
* 云数据库
* 云存储  

#### 添加配置文件

AGC为了简化开发者的配置步骤，向开发者提供了保存应用配置信息的配置文件，您只需要将配置文件添加到您的工程目录并集成AGC插件，AGC插件可以自动将您在AGC上的应用信息加载到您的开发环境。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择您的应用。 ![](https://media:201779675965966615)

3. 在"项目设置"页面下载配置文件。
   * Android：下载配置文件"agconnect-services.json"
   * iOS：下载配置文件"agconnect-services.plist"

   ![](https://media:201779675966014616)  
   配置文件中默认会包含AGC为应用分配的客户端密钥和API密钥信息，如果您的套餐升级到了付费档，为避免被冒用产生异常账单，建议您将密钥存储在您自己的服务器，并妥善保管。你可以在配置信息前打开"不包含密钥"开关，配置文件中将不包含密钥信息，由您自行调用AGC插件提供的接口手动配置，Android平台请参见[设置配置文件参数](#section11573122918500)，iOS平台请参考原生平台的[设置配置文件参数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-started-ios-0000001058442274#section7775132744813)。

   ![](https://media:201779675966044617)
4. 在Flutter开发项目中添加配置文件。
   * Android：将配置文件"agconnect-services.json"添加到Flutter项目的android/app目录下。
* iOS：在Xcode中打开Flutter项目的iOS模块，将配置文件"agconnect-services.plist"添加到iOS模块的Runner目录下。  

#### 添加Android Gradle配置

添加配置文件后，需要在Flutter项目的Android模块中配置Maven仓地址和AGC插件地址。

1. 配置Maven仓地址和AGC插件地址。
   1. 打开Flutter项目android文件夹下的build.gradle文件。
   2. 在allprojects -\>repositories里面配置maven仓地址。

      ```
      allprojects { 
                  repositories { 
                      google() 
                      jcenter() 
                      // Add the following line:
                      maven {url 'https://developer.huawei.com/repo/'} 
                  } 
              }
      ```

   3. 在buildscript-\>repositories中配置maven仓地址。

      ```
      buildscript { 
                  repositories { 
                      google() 
                      jcenter() 
                      // Add the following line:
                      maven {url 'https://developer.huawei.com/repo/'} 
                  } 
       }
      ```

   4. 在buildscript-\>dependencies中配置AppGallery Connect插件地址。以下版本号仅为示例，请以实际版本号为准。

      ```
      buildscript { 
                  dependencies { 
                   // Add the following line:
                   classpath 'com.huawei.agconnect:agcp:1.9.6.300'
                  } 
      }
      ```

2. 添加AGC插件地址。
   1. 打开Flutter项目android/app文件夹下的build.gradle文件。
   2. 在apply plugin: 'com.android.application'下一行添加如下配置。

      ```
      apply plugin: 'com.huawei.agconnect'
      ```

#### 安装插件

1. 在Flutter项目的pubspec.yaml文件中添加依赖，以崩溃服务为例：

   ```
   dependencies:
     flutter:
       sdk: flutter


     # Add the following line:
     agconnect_crash: ^1.6.0+300
   ```

   |服务|配置方法|
   |:----------|:------------------------------------|
   |远程配置|agconnect_remote_config: \^1.6.0+300|
   |崩溃服务|agconnect_crash: \^1.6.0+300|
   |认证服务|agconnect_auth: \^1.6.0+300|
   |App Linking|agconnect_applinking: \^1.6.0+300|
   |应用内消息|agconnect_appmessaging: \^1.6.0+300|
   |云函数|agconnect_cloudfunctions: \^1.6.0+300|
   |云数据库|agconnect_clouddb: \^1.3.0+300|
   |云存储|agconnect_cloudstorage: \^1.5.0+300|

   ![](https://media:201779675966070618)  
   以上版本号仅为示例，请以实际版本号为准。
2. 在命令行中执行如下命令或者点击Android Studio的Pub get添加依赖：

   ```
   flutter pub get
   ```

至此，您已经可以在Flutter项目中使用AGC的服务了。  

#### 设置配置文件参数（仅对Android平台适用）

AGC提供了agconnect_core插件来对agconnect-services.json文件中的参数进行配置，如果您在下载配置文件时选择了"不包含密钥"，则agconnect-services.json文件中将不包含client_id、client_secret和api_key参数，您必须通过agconnect_core插件的接口在应用启动时将参数设置给AGC SDK。

1. 项目中添加agconnect_core插件。

   ```
   dependencies:
     agconnect_core: ^1.6.0+300
   ```

2. 设置client_id、client_secret和api_key参数。  
   ![](https://media:201779675966100619)  
   建议您在应用初始化时调用。

   ```
   AGCApp.instance.setClientId('clientId');
   AGCApp.instance.setClientSecret('clientSecret');
   AGCApp.instance.setApiKey('apiKey');
   ```

   <br />

   各参数的值可在"项目设置 \> 常规"页面中查询，clientId替换为"Client ID"的值，clientSecret替换为"Client 密钥"的值，"apikey"替换为"API密钥（凭据）"的值，可点击参数后面的![](https://media:201779675966138620)复制参数值。

![](https://media:201779675966171621)  

#### 配置支持多Flavor（仅对Android平台适用）

如果您的应用需要通过多Flavor来支持不同的渠道，那么应用工程需支持不同渠道的打包，这种打包需要根据不同的渠道变更不同的包名。您需在应用级build.gradle文件中配置支持不同渠道，并对应用的配置文件agconnect-services.json进行特殊配置。

1. 在应用级build.gradle文件中的productFlavors下编写不同渠道的打包配置。  
   以下示例代码展示了两种渠道不同的打包配置，可以看到使用这种配置后最终打包出来的包名是不同的。

   ```
   flavorDimensions "flavor"    
   productFlavors{        
       huawei {            
           applicationId "com.huawei"            
           dimension "flavor"        
       }        
       appMarket2{            
           applicationId "com.appMarket2"            
           dimension "flavor"        
       }    
   }
   ```

<!-- -->

2. 如果您不同渠道的包都集成了华为的服务，那么不同渠道打包时需要支持读取出对应渠道的包名。您可以通过修改应用的配置文件agconnect-services.json来实现。  
   ![](https://media:201779675966200622)  
   如果您的应用集成了1.5.0.300及以上版本的AGC插件（参见[配置SDK地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-started-android-0000001058210705#ZH-CN_TOPIC_0000001058750970__p1494513044011)），您可以只下载一次agconnect-services.json文件，并添加到您应用根目录即可。
   1. 在AGC的同一个项目中为每个渠道都添加一个Android应用，且应用包名需要与build.gradle文件中productFlavors配置的包名一致，具体请参见[在项目下添加应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createapk-0000001912873100#section1112105771619)。
   2. 在"项目设置 \> 常规"页面的"应用"栏，下载华为渠道应用的agconnect-services.json文件，文件中将包含类似如下信息。

      ```
      {   
          "client":
          {
              "app_id": "10000",
              "package_name": "xxx.huawei",
              ...
          },
          ...
          "configuration_version": "3.0",
          "appInfos":[
              {
      	    "package_name":"xxx.huawei",
      	    "client":{
      		"app_id":"1*****5"
      	     },
      	    "app_info":{
      		"package_name":"xxx.huawei",
      		"app_id":"1*****5"
      	     },
      	     "oauth_client":{
      		"client_type":2,
      		"client_id":"1*****5"
      	      }
               },
               {
      	    "package_name":"xxx.other",
      	    "client":{
      		"app_id":"1*****5"
      	     },
      	    "app_info":{
      		"package_name":"xxx.other",
      		"app_id":"1*****5"
      	     },
      	     "oauth_client":{
      		"client_type":2,
      		"client_id":"1*****5"
      	      }
              },
             ...
          ]
      }
      ```

      其中client中包含了当前应用的应用信息，appInfos中包含了当前项目下所有应用的应用信息。
   3. 确认agconnect-services.json文件中appInfos中的所有包名与build.gradle文件中productFlavors配置的包名一致后，将agconnect-services.json文件添加到应用级根目录下。例如： ![](https://media:201779675966240623)

配置完成后，在您编译打包时，AGC插件会自动根据当前的Flavor对应的applicationId与appInfos匹配，打包生成正确的渠道包。匹配的原则如下：通过productFlavors的applicationId去匹配appInfos中的package_name；如appInfos中的所有package_name都不匹配，则用client中的package_name去匹配；如果都不匹配，则会编译报错。
