# 渠道包信息管理

#### 新增渠道包信息

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的应用"。
2. 选择已上架的应用，进入"分发"页面。
3. 在左侧菜单栏选择"渠道包管理"，在"普通渠道包"页面点击"新增"。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115010.99265039394358359022614101374925:50531125054745:2800:FE9BCF28FEBFB802FF73BB35407E8E258E970E4C730D3A90F485475E259390F9.png?needInitFileName=true?needInitFileName=true)

4. 按要求填写渠道包名称、包内渠道编码、投放账户ID和备注，并点击"提交"：
   * 支持批量新增渠道包信息。
   * 同一个应用下渠道包名称、包内渠道编码不可重复。
   * 若使用华为广告平台投放，请填写投放账户ID，若涉及多个请用英文逗号隔开。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115010.20280471463863664015382964966217:50531125054745:2800:E59B04F80501CB1AA34830AB82B4D59BCBF1E6683399905124675888CA1A7132.png?needInitFileName=true?needInitFileName=true)  
   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115010.71917583033200182836045076234481:50531125054745:2800:C1E30C18C96E1EDD6545EE5209C51BBD51B1304467E0BA492E13B2E1FDDAFA3E.png?needInitFileName=true?needInitFileName=true)  
   * 若主包已审核通过，则渠道包的自动审核一般需15分钟。
   * 若主包审核不通过，则渠道包需等主包审核通过后才进入自动审核阶段。
* 请勿在2小时内上传超过10个以上渠道包，否则将导致审核通道拥堵，阻碍渠道包生效。  

#### 查询渠道包信息

新增"普通渠道包"信息后，可输入如下查询条件查询渠道包：渠道包名称、包内渠道编码。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115010.06926245856022112912159696150736:50531125054745:2800:DC64E939F0684614E7EB0FE281AEB527BE85E98FDBA9E1BF9A39340B66CD25A1.png?needInitFileName=true?needInitFileName=true)  

#### 修改渠道包信息

新建"普通渠道包"信息后，可点击操作栏中的"修改"再次编辑渠道包名称、包内渠道编码和备注。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115010.32492651064932169113765947149122:50531125054745:2800:E84B0BCD83A9BC7A8C853A893B8437433D08172800E603BE335DA98704A74882.png?needInitFileName=true?needInitFileName=true)  

#### 删除渠道包信息

仅当"软件包管理"中没有软件包时可以删除渠道包信息，点击"删除"并确认后记录被删除。
