# 规格说明

1. 同一个类的同一处代码、同一种异常类型算一个崩溃问题。
2. "最近一次发生时间"指：在选择时间段内最后一次发生该问题的时间。
3. 问题统计时间是崩溃发生时间，而不是上报时间。
