# 开启/关闭数据采集器

采集、上报数据前，必须开启数据采集器。若想结束数据的采集，您可以关闭数据采集器，下次再想采集数据，请重新开启数据采集器。  

#### 前提条件

* 已[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-integration-android-0000002022406709)。
* 已[初始化SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gpm-initialization-android-0000002022526269)。  

#### 开启数据采集器

1. 调用[GPMManager.enableCollector](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-android-api-gpmmanager-0000002022527745#section6902152315716)方法，开启数据采集器。

   ```
   GPMManager.enableCollector();
   ```

2. 调用后可在GPMCallback接口的[onEnableCollector](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-android-api-gpmcallback-0000001988789820#section34206581277)方法中查看结果并实现回调处理。

   ```
   @Override
   public void onEnableCollector(int code, String msg)
   {
       // GPMManager.enableCollector接口通过子线程回调通知接口结果。由于大部分API需要在主线程中调用，请在onEnableCollector回调中合理处理。
       if(code == GPMError.GPM_SUCCESS) 
       {
          // 开启数据采集器成功
       }
   }
   ```

#### 关闭数据采集器

1. 调用[GPMManager.disableCollector](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-android-api-gpmmanager-0000002022527745#section443314117810)方法，关闭数据采集器。

   ```
   GPMManager.disableCollector();
   ```

   若当前正在采集、上报数据，关闭数据采集器将自动结束采集数据。
2. 调用后可在GPMCallback接口的[onDisableCollector](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gpm-android-api-gpmcallback-0000001988789820#section1395511531215)方法中查看结果并实现回调处理。

   ```
   @Override
   public void onDisableCollector(int code, String msg)
   {
       // GPMManager.disableCollector接口通过子线程回调通知接口结果。由于大部分API需要在主线程中调用，请在onDisableCollector回调中合理处理。
       if(code == GPMError.GPM_SUCCESS) 
       {
          // 关闭数据采集器成功
       }
   }
   ```
