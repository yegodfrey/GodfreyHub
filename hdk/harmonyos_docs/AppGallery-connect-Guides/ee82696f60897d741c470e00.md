# 设置麦克风状态

进入语音房间后，玩家如果不希望自身语音被房间内的其他玩家接收，可通过关闭自身麦克风实现。同时，还可以通过开启麦克风的方式快速解除自身静默状态。
> 说明
>
> 初始化实例后，麦克风状态默认是开启的，此时如果加入房间则会自动提示麦克风权限的申请。如需首次打开麦克风时再提示麦克风权限申请，可参考[FAQ](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-faq-0000001181618314#section1467913424715)实现。

## 开发步骤

调用[GameMediaEngine.enableMic](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-web-0000001247887067#section178781814132015)方法开启/关闭玩家自身麦克风。

```screen
...
gameMediaEngine.enableMic(isEnabled); // isEnabled：true表示开启麦克风，false表示关闭麦克风
```
