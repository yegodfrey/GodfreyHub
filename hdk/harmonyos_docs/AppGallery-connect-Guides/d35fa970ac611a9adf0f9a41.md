# 邮箱

您可以在应用中集成邮箱账号认证方式，您的用户可以使用邮箱地址和密码或者邮箱地址和验证码来登录您的应用。

## 前提条件

您需要已完成[开通认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)、[在开发环境中创建快应用项目](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-quickapp-ide-0000001326372281)以及[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-quickapp-integration-sdk-0000001326252149)各项准备工作。

## 注册

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251223144023.53997832892370433859316109425994:50001231000000:2800:9D62ED8A2C662F5DE9EA31E7116437F57299785DB48820E52073FD4FBCD3CE4F.png "点击放大")

1. 在使用邮箱注册之前，需要先验证您的邮箱，确保该邮箱账户归您所有。

   调用[AGCAuth.requestEmailVerifyCode](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section101775733412)申请验证码。

   ```screen
   agconnect.auth().requestEmailVerifyCode(emailStr,
                                       agconnect.auth.Action.ACTION_REGISTER_LOGIN,
                                       'zh_CN',// 发送验证码的语言
                                       120)// 发送间隔时间
       .then(ret => {
            // 验证码申请成功
       }).catch(error => {
           // 验证码申请失败
       });
   ```

2. 使用邮箱账号注册用户。 调用[EmailUser](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/emailuser-web-0000001054343232)生成EmailUser ，然后调用[AGCAuth.createEmailUser](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section12842161775817)注册用户。注册成功后，系统会自动登录，无需再次调用登录接口。

   ```screen
   let emailUser = new agconnect.auth.EmailUser(emailStr, password, verifyCode);
   agconnect.auth().createEmailUser(emailUser)
       .then(user => {
           // 创建账号成功后，默认已登录
       }).catch(error => {
           // 创建用户失败
       });
   ```

3. 登录成功后可以调用[AGCAuth.getCurrentUser](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section1157222065718)获取用户账号数据。

   ```screen
   agconnect.auth().getCurrentUser();
   ```

## 密码登录

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251223144023.74048516937202107614782932881492:50001231000000:2800:83C37DAD080220A493AB3B80CADF9D76CA21C2D04D6A5A0A5286C9EB361ABA7B.png "点击放大")

1. 在应用的登录界面，初始化[AGCAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254)实例，获取AGC的用户信息，检查是否有已经登录的用户。如果有则可以直接进入用户界面，否则显示登录界面。

   ```screen
   agconnect.auth().getCurrentUser().then(user=>{
       if(user){
           // 业务逻辑
       }
   });
   ```


2. 调用[EmailAuthProvider.credentialWithPassword](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/emailauthprovider-web-0000001054343219#section1924461982211)采用密码方式创建邮箱账号凭证。

   ```screen
   credential = agconnect.auth.EmailAuthProvider.credentialWithPassword(emailStr, password);
   ```

3. 获取credential成功后，调用[AGCAuth.signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section18413636501)实现登录。

   ```screen
   agconnect.auth().signIn(credential)
            .then(user => {
                // 登录成功
            }).catch(error => {
                // 登录失败
            });
   ```

## 验证码登录

1. 在应用的登录界面，初始化[AGCAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254)实例，获取AGC的用户信息，检查是否有已经登录的用户。如果有则可以直接进入用户界面，否则显示登录界面。

   ```screen
   agconnect.auth().getCurrentUser().then(user=>{
       if(user){
           // 业务逻辑
       }
   });
   ```


2. 调用[AGCAuth.requestEmailVerifyCode](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section101775733412)申请登录验证码。

   ```screen
   agconnect.auth().requestEmailVerifyCode(emailStr,
                                       agconnect.auth.Action.ACTION_REGISTER_LOGIN,
                                       'zh_CN',// 发送验证码的语言
                                       120)// 发送间隔时间
       .then(ret => {
            // 验证码申请成功
       }).catch(error => {
           // 验证码申请失败
       });
   ```


3. 调用[EmailAuthProvider.credentialWithVerifyCode](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/emailauthprovider-web-0000001054343219#section18780241192816)采用验证码方式创建邮箱账号凭证。

   ```screen
   credential = agconnect.auth.EmailAuthProvider.credentialWithVerifyCode(emailStr, password, verifyCode);
   ```

   password参数可以不传, 如果同时输入了密码和验证码，则会对密码和验证码都做验证。
4. 获取credential成功后，调用[AGCAuth.signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section18413636501)实现登录。

   ```screen
   agconnect.auth().signIn(credential)
            .then(user => {
                // 登录成功
            }).catch(error => {
                // 登录失败
            });
   ```

## 修改邮箱地址

修改邮箱时需要用户处于登录状态。

1. 调用[AGCAuth.requestEmailVerifyCode](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section101775733412)申请验证码。

   ```screen
   agconnect.auth().requestEmailVerifyCode(emailStr,
                                       agconnect.auth.Action.ACTION_REGISTER_LOGIN,
                                       'zh_CN',// 发送验证码的语言
                                       120)// 发送间隔时间
       .then(ret => {
            // 验证码申请成功
       }).catch(error => {
           // 验证码申请失败
       });
   ```

2. 调用[AGConnectUser.updateEmail](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectuser-web-0000001054663240#section18133115512204)修改邮箱地址。

   ```screen
   user.updateEmail(newEmail, newVerifyCode, lang);
   ```

> 说明
>
> 对于修改邮箱地址操作，要求用户必须在5分钟内登录过才能执行。若已超时，请参见[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-quickapp-reauthenticate-0000001113218450)先完成重认证。

## 修改密码

修改密码时需要用户处于登录状态。

1. 调用[AGCAuth.requestEmailVerifyCode](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section101775733412)申请验证码。

   ```screen
   agconnect.auth().requestEmailVerifyCode(emailStr,
          agconnect.auth.Action.ACTION_RESET_PASSWORD,
          'zh_CN',// 发送验证码的语言
           120)// 发送间隔时间
       .then(ret => {
            // 验证码申请成功
       }).catch(error => {
           // 验证码申请失败
       });
   ```

2. 调用[AGConnectUser.updatePassword](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectuser-web-0000001054663240#section1363991632119)修改密码。

   ```screen
    // 邮箱provider为12
   user.updatePassword(newPassword, verifyCode, provider);
   ```

> 说明
>
> 对于修改密码操作，要求用户必须在5分钟内登录过才能执行。若已超时，请参见[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-quickapp-reauthenticate-0000001113218450)先完成重认证。

## 重置密码

重置密码时用户可以不登录。

1. 调用[AGCAuth.requestEmailVerifyCode](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section101775733412)申请验证码。

   ```screen
   agconnect.auth().requestEmailVerifyCode(emailStr,
                                       agconnect.auth.Action.ACTION_RESET_PASSWORD,
                                       'zh_CN',// 发送验证码的语言
                                       120)// 发送间隔时间
       .then(ret => {
            // 验证码申请成功
       }).catch(error => {
           // 验证码申请失败
       });
   ```

2. 调用[AGCAuth.resetPasswordByEmail](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section188336111913)重置密码。

   ```screen
   agconnect.auth().resetPasswordByEmail(email, newPassword, verifyCode);
   ```

## 更多信息

* 您如果想让用户可以使用多个账号登录您的应用，可以将多个[账号进行关联](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-quickapp-associated-0000001064185992)。
* 当用户不需要使用应用，或者需要切换其他账号登录认证，可以先执行[登出](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-quickapp-sign-out-0000001063838697)。
* 当用户需要注销当前用户，可以进行[销户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-quickapp-deleteuser-0000001064108343)。
* 对于销户、修改密码、关联账号以及重置手机账号和邮箱账号等敏感操作，为了提高安全性，需要用户必须在5分钟内登录过才能执行。如果用户执行敏感操作时登录超过5分钟，需要[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-quickapp-reauthenticate-0000001113218450)后再执行敏感操作。
* 您可以参考[异常处理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-quickapp-troubleshooting-0000001204848325)实现自己的异常处理机制，从而减少异常情况的发生。
* 您可以使用云函数触发器来接收用户注册、登录、销户等关键事件，从而[扩展认证服务的能力](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-extension-0000001053372708)。
* 您可以参考[管理用户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-user-manage-0000001606051705)对用户进行解锁、停用等操作。
