# 申请开通

铂金级及以上应用可申请使用极小渠道包功能，申请开通后权限全年有效。需要申请的开发者请联系相关运营或填好申请模板后发送邮件至[developer@huawei.com](mailto:developer@huawei.com)，审核人员评估后会在1-2个工作日内进行答复。

邮件标题：APP名称-申请开通极小包

邮件内容：

* APP名称：\*\*\*\*\*\*\*
* 应用ID：\*\*\*\*\*\*\*\*\*
* 应用分类：\*\*\*\*\*\*\*\*\*
* 客户ID：\*\*\*\*\*\*\*\*\*
* 应用等级：铂金级 / 钻石级 / 黑金级
* 邮件内容：xx应用申请在xx月开通极小渠道包，确认已经清晰完整理解华为应用市场极小包功能申请与使用规范，如不满足，可接受白名单关闭。
