# API参考

Lite版本的check接口回调和非Lite版本的check接口回调存在差异，Lite版本鉴权回调接口返回了signData和signature两个参数，您可以根据自己的需求进行鉴权。Lite版本的check接口其余部分与非Lite版本的check接口保持一致，具体请参考[Check](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/appgallerykit-paidapps-check-0000001073193403)。

* 如果您只需在AppGallery DRM Service SDK中验证签名结果，无需进行其他业务处理，您可参考示例代码中的方式1进行鉴权。
* 如果您需要进行其他业务处理并二次签名验证，例如访问自己的业务服务器进行签名验证，您可参考示例代码中的方式2进行鉴权。  

```
package com.example.drmdemo;
import android.app.Activity;
import android.os.Bundle;
import com.huawei.android.sdk.drm.Drm;
import com.huawei.android.sdk.drm.DrmCheckCallback;
public class MainActivity extends Activity {
    // 版权保护id
    private static final String DRM_ID = "请在这里填写版权保护id";
    // 版权保护公钥
    private static final String DRM_PUBLIC_KEY = "请在这里填写版权保护公钥";
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        // 调用check方法
        Drm.check(this, this.getPackageName(), DRM_ID, DRM_PUBLIC_KEY, TRUE, 
                new MyDrmCheckCallback());
    }
    /**
     * 鉴权结果处理回调接口
     */
    private class MyDrmCheckCallback implements DrmCheckCallback {
        @Override
        public void onCheckSuccess(String signData, String signature) {
            // 方式1：只需在AppGallery DRM Service SDK中验证签名结果，无需进行其他业务处理
            setContentView(R.layout.activity_main);
            // 方式2：需要进行其他业务处理并二次签名验证，例如访问您的业务服务器进行签名验证，则需要实现verifyByServer接口
            verifyByServer(signData, signature);

        }
        @Override
        public void onCheckFailed(int errorCode) {
            // 鉴权失败，用户不能使用程序，程序退出。
            finish();
        }
    }
}
```
