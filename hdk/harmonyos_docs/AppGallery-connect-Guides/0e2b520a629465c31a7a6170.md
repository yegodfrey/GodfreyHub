# 测试崩溃实现

通常应用程序崩溃出现的概率较小，您没必要等待崩溃出现来确定崩溃服务是否正常工作。您可以在测试应用时调用崩溃服务SDK的API手动制造一个崩溃，然后在AGC上查看崩溃上报情况，以测试崩溃服务是否正常运行。  

#### 前提条件

1. 您需要在AGC控制台[开通崩溃服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-enableservice-0000001326330021#section542455312289)。
2. 您需要先在您的应用中[集成崩溃服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-integratesdk-harmonyos-0000001276400112)。  

#### 测试崩溃

1. 在应用中某个AbilitySlice中创建一个Button。
2. 点击Button后触发调用[APMCrash.getInstance()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-harmonyos-0000001139799938#section743716146324)初始化[APMCrash](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-harmonyos-0000001139799938)实例。
3. 调用[APMCrash.getInstance().enableCrashReport()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-harmonyos-0000001139799938#section1866812317720)设置为true，开启崩溃信息上报开关。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250403153203.48878980565446580098398771387889:50001231000000:2800:178B6FD573D2170A915594B5D238A2922BBA7113157F2A19946D36CF82A9D1D7.png)  
   该开关默认关闭，表示崩溃服务不自动上报崩溃信息。
4. 调用[APMCrash.getInstance().testJavaException()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-harmonyos-0000001139799938#section56361583425)方法制造一次崩溃。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250403153203.24367561691025693500258256810659:50001231000000:2800:10E3B353ACFFFB9366319DF9925F1D1566F926F6831026BA8C09EBF3BAEEE65C.png)  
   在测试完成后应用上架前，请注意将测试崩溃的测试代码删除。

   ```
   Button button = (Button) findComponentById(ResourceTable.Id_btn_get_crash);
   button.setClickedListener(new Component.ClickedListener() {
       @Override    
       public void onClick(Component component) {        
           APMCrash.getInstance().testJavaException(true);    
       }
   });
   ```

5. 打包并运行应用程序，点击Button触发崩溃。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250403153203.73803249231627404175493736590059:50001231000000:2800:A305BAB2252013369B81EE46D0D54F9E3D2DEB7B7E8B6AFF45E8EFC01268F68E.png)  
在发生崩溃时，会尝试上报崩溃，请确保网络连接正常。上报成功后可在AGC中查看对应的崩溃信息，具体方法请参见[分析崩溃问题](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-locate-harmonyos-0000001139958984)。  

#### 测试异常实现

1. 调用[APMCrash.getInstance()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-harmonyos-0000001139799938#section743716146324)获取APMCrash实例。
2. 在catch代码块中调用[APMCrash.getInstance().recordException()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-harmonyos-0000001139799938#section4874171461216)记录您捕获的异常。

   ```
   try {
   } catch (Exception e) {
       APMCrash.getInstance().recordException(e);
   }
   ```

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250403153203.52080242797537928815240241504278:50001231000000:2800:002D48959330FA126CCFA6B96B48750919F77D8AB376C8691C88CBD0A331D058.png)  
   AGC只会记录一个应用会话中最近的10次异常。如果您的应用在一个会话中抛出的异常数超过10个，则较早的异常会被删除。
3. 您可以在测试应用时调用崩溃服务SDK的API手动制造一个异常，然后在AGC上查看异常上报情况，以测试报告非严重异常能否正常运行。

   ```
   try {
       throw new Exception();
   } catch (Exception e) {
       APMCrash.getInstance().recordException(e);
   }
   ```
