# Windows上采集设备的Profile（Android和HarmonyOS 3.1/4.0及以下）

## 前提条件

* 已[配置adb工具](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/binary-optimization-tool-config-0000001919148894#section5251756101019)。
* 已[下载工具包](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/binary-optimization-download-tool-0000001576870677)。

  工具包文件说明如下：

  |文件|用途|备注|
  |:-----------------|:-------------------------------------------------------|:-----------|
  |trigger|触发指定场景下开始和结束profile采集的工具。|运行在Android设备|
  |clear_profile.bat|清除指定目录下profile文件，用于开始采集前做环境的清理。|运行在Windows上|
  |export_profile.bat|用于导出抓取指定路径下的profile数据，默认会将/data/local/tmp目录下的文件打包并导出到本地。|运行在Windows上|

## 清理无关profile文件

使用工具包的clear_profile.bat清理手机中已经存在的profile文件，防止正式采集profile数据后，误将无关的profile文件一起导出。clear_profile.bat命令行格式如下：

```screen
//若未输入path_to_profile_on_the_device路径，默认清理/data/local/tmp路径下的profile文件。
clear_profile.bat [path_to_profile_on_the_device]
```

> 说明
>
> * 手机确保有删除path_to_profile_on_the_device路径下文件的权限，否则会删除失败。
> * 可不输入path_to_profile_on_the_device路径，不输入则默认清理/data/local/tmp目录下的profile文件。

## 采集profile数据

1. 在手机上启动游戏，且关闭其它无关应用程序的后台，确保当前仅有待采集profile数据的游戏处于运行状态中。
2. 游戏进入待采集profile数据的场景。 说明
   >
   > 为了达到更好的优化效果，请选择[合适的游戏场景](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/binary-optimization-select-scene-0000001529316326)进行采集数据。
3. 将trigger工具push到手机，输入如下命令，为trigger工具添加"执行"权限。

   ```screen
   chmod +x  trigger
   ```

4. 执行工具包的trigger，触发开始采集profile数据。trigger命令行的参数说明如下：

   ```screen
   ./trigger -s scenario name [-p trigger_port] [-f profile folder]
   ```

   > 说明
   >
   > 触发开始采集和触发结束采集的命令相同。

   |参数|必选(M)/可选(O)|默认值|说明|
   |:-------------|:----------|:------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |scenario name|M|default|您自定义的场景名称，例如"fight"，默认为"default"。 > 说明 > 采集多个场景时需要配置不同的场景名，否则profile文件会被覆盖。|
   |trigger_port|O|3040|采集profile数据时用到的端口号，要与调用[提交插桩任务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/binary-optimization-submit-pile-task-0000001862646064)接口的入参portStart保持一致。 > 说明 > 不同的so应配置不同的端口号，否则会导致冲突，影响profile采集**。**|
   |profile folder|O|当前路径|profile数据输出的路径，默认为工具当前路径。|

   开始采集profile数据的命令行示例如下：

   ```screen
   ./trigger -s fight -p 3041
   ```

5. 等到游戏场景结束，再次执行相同命令行触发结束采集：

   ```screen
   ./trigger -s fight -p 3041
   ```

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250811104209.21374517070734167660696806249686:50001231000000:2800:39CBAA6677419B7C13BD3AA86C355FB42AAD3127C3DC9A4E329C1232C439DE12.png)
   > 说明
   >
   > 如果需要采集多个so的profile，可以针对不同so，分别配置不同端口号，多次执行trigger工具命令，支持同时触发多个so采集。
6. 您可以采集多个游戏场景的profile数据。单个场景的profile数据完成采集后，将生成*so_name* .fdata.*scene_name* 的profile文件：
   * so_name为so名称，例如libunity.so。
   * scene_name为场景名称，例如fight。

## 导出profile文件

待所有游戏场景的profile数据都采集后，执行工具包的**export_profile.bat** ，将手机上的profile数据打包成profile.tar并导出至PC。命令行格式如下：

```screen
// 若不输入path_to_profile_on_the_device路径，默认将/data/local/tmp路径下的profile文件打包成profile.tar并导出至本地
export_profile.bat [path_to_profile_on_the_device]
```

> 说明
>
> 手机确保有读取path_to_profile_on_the_device路径的权限，否则将导出失败。
