# 屏蔽其他玩家

在语音房间中，玩家如果不想接收房间内某个玩家的发言内容，可通过屏蔽其语音实现，但房间内其他玩家依然可以接收到被屏蔽语音玩家的发言。例如在同一房间内，玩家A屏蔽了玩家B的语音，其他玩家依然可以正常接收玩家B的发言。

## 前提条件

玩家已[加入](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-joinroom-roomid-web-0000001223118676)房间。

## 屏蔽/打开指定玩家语音

> 说明
>
> * 小队房间暂不支持屏蔽指定玩家语音。
> * 如需屏蔽指定玩家A，需确保A玩家正在当前语音房间内。

调用[GameMediaEngine.mutePlayer](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-web-0000001247887067#section1086902118255)方法屏蔽/打开房间内指定玩家语音。

```screen
...
const result = gameMediaEngine.mutePlayer(roomId, openId, isMuted); // roomId：房间ID; openId：玩家ID; isMuted：true表示屏蔽语音，false表示取消屏蔽
```

## 屏蔽/打开其他全部玩家语音

> 说明
>
> * 屏蔽所有玩家后，不允许解除单个指定玩家的语音屏蔽。
> * 如需屏蔽所有玩家语音，需确保已解除房间内其他所有玩家的语音屏蔽。

调用[GameMediaEngine.muteAllPlayers](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-web-0000001247887067#section15581047132812)方法屏蔽/打开房间内指定玩家语音。

```screen
...
const result = gameMediaEngine.muteAllPlayers(roomId, isMuted); // roomId：房间ID; isMuted：true表示屏蔽语音，false表示取消屏蔽
```
