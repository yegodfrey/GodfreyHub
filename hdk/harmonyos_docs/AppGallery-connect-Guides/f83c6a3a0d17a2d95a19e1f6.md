# 自定义玩家属性

游戏多媒体实时信令功能支持设置频道内玩家自定义属性，例如状态、位置、心情等。同时，还支持监听频道内其他玩家属性的变更，及时感知频道内其他玩家属性的修改。

## 前提条件

* 您已[集成游戏多媒体基础SDK和实时信令模块](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-integratingsdk-android-0000001250838246#ZH-CN_TOPIC_0000001250838246__li733912204487)。
* 您已[创建游戏多媒体实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-engine-android-0000001193958984#section1093713161034)。
* 您已[订阅频道](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-channel-subscribe-android-0000001744760273#section1014421318306)。

## 设置玩家属性

1. 调用[HWPGMEngine.getInstance setRtmChannelPlayerProperties](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section165961232917)方法，设置频道内玩家自定义属性。

   ```screen
   SetRtmChannelPlayerPropertiesReq *req = [[SetRtmChannelPlayerPropertiesReq alloc] init];
   req.channelId = channel;
   req.playerProperties = {@"name": @"xxxx", @"age": @"22"};
   [HWPGMEngine.getInstance setRtmChannelPlayerProperties:req];
   ```

2. 在HWPGMEngineDelegate协议的[onSetRtmChannelPlayerProperties](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section1438715918168)回调方法中，可以获取玩家自定义属性的设置结果。

   ```screen
   - (void)onSetRtmChannelPlayerProperties:(SetRtmChannelPlayerPropertiesResult *)result {
     // 可根据需求将数据进行处理
   }
   ```

## 查询玩家属性

1. 调用[HWPGMEngine.getInstance getRtmChannelPlayerProperties](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section11857046172917)方法，查询频道内玩家自定义属性。

   ```screen
   GetRtmChannelPlayerPropertiesReq *req = [[GetRtmChannelPlayerPropertiesReq alloc] init];
   req.channelId = channel;
   req.openIds = userIds;
   [HWPGMEngine.getInstance getRtmChannelPlayerProperties:req];
   ```

2. 在HWPGMEngineDelegate协议的[onGetRtmChannelPlayerProperties](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section1965618572173)回调方法中，可以获取玩家自定义属性的查询结果。

   ```screen
   - (void)onGetRtmChannelPlayerProperties:(GetRtmChannelPlayerPropertiesResult *)result {
     // 可根据需求将数据进行处理
   }
   ```

## 删除玩家属性

1. 调用[HWPGMEngine.getInstance deleteRtmChannelPlayerProperties](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section421722333012)方法，删除频道内玩家自定义属性。

   ```screen
   DeleteRtmChannelPlayerPropertiesReq *req = [[DeleteRtmChannelPlayerPropertiesReq alloc] init];
   req.channelId = channel;
   req.keys = keys;
   [HWPGMEngine.getInstance deleteRtmChannelPlayerProperties:req];
   ```

2. 在HWPGMEngineDelegate协议的[onDeleteRtmChannelPlayerProperties](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section5984112741810)回调方法中，可以获取玩家自定义属性的删除结果。

   ```screen
   - (void)onDeleteRtmChannelPlayerProperties:(DeleteRtmChannelPlayerPropertiesResult *)result {
     // 可根据需求将数据进行处理
   }
   ```
