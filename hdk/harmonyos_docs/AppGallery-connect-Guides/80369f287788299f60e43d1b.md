# 设置崩溃提醒

> 说明
>
> HarmonyOS应用暂不支持设置崩溃提醒。

崩溃服务会实时监测您的应用，在发生重大崩溃问题时及时提醒您。当过去1小时内，某个崩溃问题同时满足以下三个条件时系统会给您发送提醒消息。

* 崩溃率达到阈值，系统默认阈值为1%，您也可以[自定义阈值](#section151561431141316)。
* 应用的启动次数大于500。
* 该问题之前未触发过异常告警，即已经发送过提醒的问题不再继续提醒。

## 自定义阈值

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择您的应用。
3. 在左侧导航栏选择"质量 > 崩溃"，点击右侧"崩溃提醒设置"。
4. 通过滑动下方的滑块自定义崩溃率阈值，自定义阈值的范围0.1%-1%或1%-10%，设置完成后点击"确定"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155603.36174328024254808294726148226587:50001231000000:2800:28980BAE273527B66F2A5799B68DDA3454F514622A8F1BDF39E5E06299B9065C.png)

## 开启崩溃提醒

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"用户与访问"。
2. 在左侧导航栏选择"用户 > 个人信息"。
3. 在"通知"栏中"崩溃提醒（检测到重大崩溃问题时通知我）"选择"邮件"和"短信"对应的复选框，点击保存。 说明
   >
   > 为保证您能及时收到崩溃提醒，请确保预留邮箱和手机号正确。如需绑定或更换新账号，可前往"用户 > 个人信息 > 管理"进行设置。
