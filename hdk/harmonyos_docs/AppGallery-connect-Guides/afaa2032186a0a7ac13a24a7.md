# 初始化SDK

功能开发前，需先完成游戏高光时刻SDK初始化操作。

## 前提条件

* 您已[开通服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/game-highlight-enable-0000001686576865)。
* 您已[集成HMS Core SDK和游戏高光时刻服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/game-highlight-integratingsdk-0000001638097622)。

## 开发步骤

1. 调用[GameReplayManager.create](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamereplaymanager-game-replay-0000001690120477#section142665215206)方法创建一个高光时刻实例。

   ```screen
   private ReplayCallback eventHandler = new ReplayEventHandler();
   gameReplayManager = GameReplayManager.create(this.getApplicationContext(), eventHandler);
   ```

2. 调用[GameReplayManager.init](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamereplaymanager-game-replay-0000001690120477#section253831315445)方法执行初始化。 说明
   >
   > "clientId"、"clientSecret"和"apiKey"对应AGC项目中的 "Client ID"、"Client Secret"、"API密钥（凭据）"信息，"agcAppId"对应AGC应用中"APP ID"，具体请参见[准备游戏信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/game-highlight-gameinformation-0000001638256874)。

   ```screen
   InitParam initParam = new InitParam()
       .setClientAppId("agcAppId")      // 应用ID
       .setClientId("clientId")         // 客户端ID
       .setClientSecret("clientSecret") // 客户端密钥
       .setOpenId("openId")             // 玩家的唯一ID标识
       .setApiKey("apiKey")             // API密钥
       .setOutputPath("outputPath");    // 录制视频的存储目录
   gameReplayManager.init(initParam);
   ```

3. 当初始化实例时，可在ReplayCallback接口的[onInit](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/replaycallback-callback-0000001686126937#section34206581277)方法中实现相关回调处理。

   ```screen
   @Override
   public void onInit(InitResult result) {
       // 根据初始化返回结果做相应业务逻辑处理
   }
   ```
