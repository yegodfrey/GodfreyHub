# 测试崩溃实现

通常应用程序崩溃出现的概率较小，您没必要等待崩溃出现来确定崩溃服务是否正常工作。您可以在测试应用时调用崩溃服务SDK的API手动制造一个崩溃，然后在AGC上查看崩溃上报情况，以测试崩溃服务是否正常运行。  

#### 前提条件

1. 您需要在AGC控制台[开通崩溃服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-enableservice-0000001326330021)。
2. 您需要先在您的应用中[集成崩溃服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-integratesdk-android-0000001275810158)。  

#### 测试崩溃

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250401113610.23346027439350165701198478771733:50001231000000:2800:C5E3FB8F869153270FB7809BE3A8437FDB92EE77D0B0444A248F0FBB163539A4.png)  
当前阶段，此测试崩溃方法无法制造NDK崩溃。

1. 在应用中某个Activity中创建一个Button。
2. 点击Button后触发调用[AGConnectCrash.getInstance()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-android-0000001055420438#section743716146324)初始化[AGConnectCrash](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-android-0000001055420438)实例。
3. 调用[AGConnectCrash.getInstance().testIt()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-android-0000001055420438#section56361583425)方法制造一次崩溃。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250401113610.80462342200864784913798140337409:50001231000000:2800:21AB3CC13BB503FC08273C136DA936E1A85941EDDEABE197DF54C8C43311DFD1.png)  
   在测试完成后应用上架前，请注意将测试崩溃的测试代码删除。  

   ```
   "Java"
   Button btn_crash = findViewById(R.id.btn1);
    btn_crash.setOnClickListener(new View.OnClickListener() {
        @Override
        public void onClick(View view) {
            AGConnectCrash.getInstance().testIt(context);
        }
    });
   ```

   ```
   "Kotlin"
   val btn_crash = findViewById<Button>(R.id.btn_crash)
   btn_crash.setOnClickListener {
       AGConnectCrash.getInstance().testIt(context)
   }
   ```

4. 打包并运行应用程序，点击Button触发崩溃。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250401113610.32908113146022127691739814099354:50001231000000:2800:ED7A4DAE3E20FFC98F161D2920A451AC16369D76903D9A392F1178ADA51672AB.png)  
在发生崩溃时，会尝试上报崩溃，请确保网络连接正常。上报成功后可在AGC中查看对应的崩溃信息，具体方法请参见[分析崩溃问题](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-locate-0000001055140557)。
