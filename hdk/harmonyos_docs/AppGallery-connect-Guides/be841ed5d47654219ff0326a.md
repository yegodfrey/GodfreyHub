# 下载项目级认证凭据

Server SDK初始化过程中需传入认证凭据。不同服务类型支持不同的凭据类型，云存储服务目前支持项目级凭据。

使用Server SDK项目级凭据的前提是您已经在AGC中拥有了自己的项目，并在项目中开通了AGC对应的服务且已[设置数据处理位置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-data-storage-location-0000001162597847)。确保已完成以上操作后，您可参考如下方法下载认证凭据：

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击您的项目。
3. 在"项目设置"页面中点击"Server SDK"页签。
4. 点击认证凭据中的"创建"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251125091003.96751724710129826211345815342107:50001231000000:2800:6D002A9396D2A4BF1702505AB935D790B78E3EAC851F7D64A112F764662CB742.png)

5. 创建完后生成认证凭据，点击"下载认证凭据"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251125091003.59892323218039428393291224972518:50001231000000:2800:91FDEC583CA3DAD233E8829490E10530B68E5E79686C14114F7B612A071598B8.png)

6. 将下载后的认证凭据文件agc-apiclient-\*.json放置到您的Server服务器中指定路径下，后续初始化SDK时将会使用到该文件。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251125091003.51495523038251985142647634483722:50001231000000:2800:E181E85A1279B9E2A0A6E2AF2AE3F7D23C0E9BD98708742FA3AF60F00D8F095B.png)  
凭据文件中包含您的client_secret信息，请您妥善保管。
