# 概述

本章节介绍的Jenkins插件可以通过调用AppGallery Connect接口发送HTTP请求，把Jenkins实例中构建的Android应用软件包（APK或AAB）快速上传至应用市场。

## 主要功能

以下依次列出了通过Jenkins插件实现Android应用软件包的上传和部署步骤：

|主要功能|描述|
|:-------------|:-----------------------|
|上传Android应用软件包|获取Android应用软件包并上传至华为服务器。|
|修改应用信息|将已上传的应用添加至AGC的项目中。|
|发布应用|把新版本同步至应用市场，供用户下载。|
