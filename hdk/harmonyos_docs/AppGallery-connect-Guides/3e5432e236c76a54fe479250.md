# 技术支持

当您集成AGC相关服务遇到问题时，可以按照以下顺序寻求帮助。

1. 请先仔细阅读文档，部分功能对设备和系统有限制，请参见[使用限制](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-restrictions-0000001054024565)。
2. 查看[FAQ](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-faq-0000001053424531)、[问题处理案例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-troubleshooting-cases-0000001120641040)和错误码[Android](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/applinkingexception-0000001054900818#section36671135102310)丨[iOS](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapplinkingerrorcode-0000001173048173)。
3. 通过[AI助手](https://developer.huawei.com/consumer/cn/customerService/#/bot-dev-top/faq-top/faq-talk-top)查找问题解决方案。
4. 登录[Stack Overflow社区](https://stackoverflow.com/questions/tagged/appgallery-connect)和[华为开发者社区](https://developer.huawei.com/consumer/cn/forum/block/ag-connect)参与问题讨论。
5. 如果以上方法仍未解决您的问题，可以通过[在线工单系统](https://developer.huawei.com/consumer/cn/support/feedback/#/add/89?level2=2022000011&level3=9014&keyWord=App Linking)与我们进行联系。
