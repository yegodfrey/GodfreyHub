# 成功案例

## 莫邪游戏

### 接入背景

莫邪游戏成立于2014年，是国内新兴的移动网络游戏开发商和发行商，致力于打造优质手游，成功发行和运营了包括《少年悟空传》、《末日精英》、《方块物语》、《沙盒绿洲》、《猫咪小舍》在内的40余款优质游戏，产品内容涵盖魔幻、神话、竞速、末世、探险等多种题材，赢得广大用户的一致好评。为了节省搭建时间以及开发成本，该公司需要使用云托管服务发行和运营游戏。在对比过市场上众多提供托管服务的厂商之后，研发团队使用了华为云托管服务。

### 解决方案及效果

在对比过市场上众多提供托管服务的厂商之后，他们使用了华为云托管服务，节省了搭建时间以及开发成本，由此带来了实现更多合作的可能。目前云托管是免费使用阶段，为公司节省了100%的服务器成本，开发效率提高了85%，兼顾了性能与可靠，实现从量变到"智"变的转化过程。
