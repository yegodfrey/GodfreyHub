# 离开房间

进入房间后，不论是否已进入游戏中，房间内玩家均可离开房间。
> 说明
>
> 房间中所有玩家全部离开后，房间将会自动销毁。

## 前提条件

您已[加入房间](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-joinroom-roomid-ios-0000001323024589)。

## 离开房间

1. 调用[HWPGMEngine.getInstance leaveRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section151651032183220)方法离开房间。 说明
   > * 普通玩家离开房间时，参数ownerId传null或空字符串即可。
   > * 房主离开房间时，参数ownerId传null或空字符串，则表示随机指定新房主。

   ```screen
   HWPGMEngine *pgmeEngine = [HWPGMEngine getInstance];
   [pgmeEngine leaveRoom:roomId ownerId:ownerId];
   ```

2. 当玩家离开房间时，可在HWPGMEngineDelegate接口的[onLeaveRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section22898375719)方法中实现相关回调处理。

   ```screen
   - (void)onLeaveRoom:(NSString* _Nonnull)roomId code:(int)code msg:(NSString *)msg {
       // 可根据需求将数据进行处理
   }
   ```

   当玩家成功离开房间时，房间内其他玩家可在HWPGMEngineDelegate接口的[onPlayerOffline](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section4226103722216)方法中实现该事件的回调处理。
   > 说明
   >
   > 当前仅支持小队语音和国战语音房间的玩家通过该回调方法收到某个玩家离开房间的通知。

   ```screen
   - (void)onPlayerOffline:(NSString* _Nonnull)roomId openId:(NSString* _Nonnull)openId {
      // 可根据需求将数据进行处理
   }
   ```
