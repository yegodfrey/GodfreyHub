# 更新在架应用详情

如果您需要更新已上架应用在华为应用市场客户端的详情页信息，但不想升级应用的版本，可以使用同版本更新的方式修改。  

#### 前提条件

* 应用已经上架到华为应用市场。
* 调用Publishing API前请确认已经完成[使用入门](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114)中的服务端授权。
* 您已准备需要更新的应用信息及应用资源文件，如应用图标、应用介绍截图、推荐视频等。

#### 开发步骤

1. 如果您需要在更新应用详情时查看当前在架应用的信息，可以调用[查询应用信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-info-query-0000001158365045)接口。

   ```
   public static void getAppInfo(String domain, String clientId, String token, String appId, String lang) {
   	HttpGet get = new HttpGet(domain + "/publish/v2/app-info?appId=" + appId + "&lang=" + lang);

   	get.setHeader("Authorization", "Bearer " + token);
   	get.setHeader("client_id", clientId);
   	try {
   		CloseableHttpClient httpClient = HttpClients.createDefault();
   		CloseableHttpResponse httpResponse = httpClient.execute(get);
   		int statusCode = httpResponse.getStatusLine().getStatusCode();
   		if (statusCode == HttpStatus.SC_OK) {
   			BufferedReader br =
   				new BufferedReader(new InputStreamReader(httpResponse.getEntity().getContent(), Consts.UTF_8));
   			String result = br.readLine();
   			JSONObject object = JSON.parseObject(result);
   			System.out.println(object.get("ret"));
   			AppInfo appInfo = (AppInfo) object.get("appInfo");
   			AuditInfo auditInfo = (AuditInfo) object.get("auditInfo");
   			LangInfo[] langInfos = (LangInfo[]) object.get("languages");
   		}
   	} catch (Exception e) {
   	}
   }
   ```

2. 如需更新应用详情页的多语言描述信息，如应用名称、应用描述信息等，可调用[更新语言描述信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-language-info-update-0000001158245057)接口。如需更新应用的基本信息，如应用分类、应用支持的设备、应用的开发者信息等，可调用[更新应用基本信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-info-update-0000001111685198)接口。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250716103230.76412547607048303545681841731017:50001231000000:2800:4E9EFF8874534B781D1EDEE9955F1274A46A577ED8A134A4FE7F750A92C1915B.png)  
   应用上架后不支持修改应用付费类型。
3. 如需更新应用图标、应用介绍截图、推荐视频、版权图片等，您需要调用[获取上传文件地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-upload-url-new-0000001111685200)接口为每个文件获取上传地址，再调用[上传文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-upload-file-new-0000001111845090)接口将每个应用资源文件上传至华为服务器。
4. 文件上传完成后，您需要调用[更新应用文件信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-file-info-0000001111685202)接口将应用文件信息与应用绑定，具体请参见[更新应用文件信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-file-info-0000001111685202)。
5. 应用文件信息绑定成功后，直接调用[提交发布](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-app-submit-0000001158245061)接口发布应用。
