# 切换房间

玩家处于多房间状态下时，可通过切换语音房间实现进入不同房间。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241105115841.02690261020982962142557395506980:50001231000000:2800:04ECA07088E2B5DE4808DB3762106570E7755C7C7D6528F03EC0CCA8638A8BEC.png?needInitFileName=true?needInitFileName=true)  
在房间A中，一个玩家无论是否具备发送语音的能力，当该玩家由房间A切换至其他房间后，其在房间A中则仅具备接收语音的能力。当玩家由其他房间切换回房间A后，则其恢复在原房间A中的语音能力。  

#### 前提条件

玩家至少已[加入](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-joinroom-roomid-web-0000001223118676)两个房间。  

#### 开发步骤

调用[GameMediaEngine.switchRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-web-0000001247887067#section12691934194710)方法切换到指定房间。

```
// 切换到指定房间
await gameMediaEngine.switchRoom(roomId)；
```
