# 停用ANR监控

> 注意
>
> APM性能监控开关优先级高于ANR监控开关，仅在APM性能监控开关打开情况下，ANR监控开关才会生效。

APM SDK提供[public void enableAnrMonitor(boolean enable)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/apms-0000001052488219#section17455144122519)接口，供您启用/停用ANR监控。接口调用具体流程如下：

1. 调用[getInstance](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/apms-0000001052488219#section304mcpsimp)初始化。
2. 调用[enableAnrMonitor](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/apms-0000001052488219#section17455144122519)停用或开启。

停用ANR监控参考代码如下：

```screen
Button disableButton = findViewById(R.id.fab1);
disableButton.setOnClickListener(new View.OnClickListener() {
    @Override
    public void onClick(View v) {
        // Call interface in APM, and set the params to 'false'
        // you will disable ANR Monitor
        APMS.getInstance().enableAnrMonitor(false);
    }
});
```

启用ANR监控参考代码如下：

```screen
Button enableButton = findViewById(R.id.fab1);
enableButton.setOnClickListener(new View.OnClickListener() {
    @Override
    public void onClick(View v) {
        // Call interface in APM, and set the params to 'true'
        // you will enable ANR Monitor
        APMS.getInstance().enableAnrMonitor(true);
    }
});
```
