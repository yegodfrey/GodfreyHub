# 销户

## 前提条件

* 您需要在AGC控制台[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-integration-sdk-0000001326347605)。

## 开发步骤

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114606.35248980240315368977175930790840:50001231000000:2800:0820FC2EE7640CC23F79D0569229735D83C304397E0155666299994C357CCB8E.png "点击放大")

当用户不再使用应用，可以注销当前用户。您需要调用[[AGCAuth deleteUser]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346#section14344918171212)实现该功能，用户一旦被注销，将会删除服务端侧的用户信息同时清空客户端侧用户信息和Token。

```screen
"Objective-C"
[[[[AGCAuth getInstance] deleteUser] addOnSuccessCallback:^(id _Nullable result) {
         // onSuccess
     }] addOnFailureCallback:^(NSError * _Nonnull error) {
         // onFail
     }];
```

```screen
"Swift"
AGCAuth.instance().deleteUser()
```

> 说明
>
> 对于销户操作，要求用户必须在5分钟内登录过才能执行。若已超时，请参见[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-reauthenticate-0000001127283387)先完成重认证。
