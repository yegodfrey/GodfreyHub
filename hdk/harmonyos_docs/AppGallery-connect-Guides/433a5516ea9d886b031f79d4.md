# 背景介绍

为了支持AppGallery DRM Service SDK可定制，华为发布了Lite版本的AppGallery DRM Service SDK，此版本为开源SDK。

* 如果您想实现付费鉴权机制的定制，可基于该Lite版本进行二次开发，具体请参考以下文档。
* 如果无此需求，您可直接集成AppGallery DRM Service SDK到您的应用中，具体请参考[使用入门](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/appgallerykit-paidapps-agcprepare-0000001074231614)。

> 注意
>
> 开源的Lite版本SDK不支持AppTouch和华为游戏中心的付费鉴权，仅支持华为应用市场的付费鉴权。
