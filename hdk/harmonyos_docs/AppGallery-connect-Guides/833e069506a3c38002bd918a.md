# 通过控制台测试

> 说明
>
> 下文以函数latest版本为例介绍测试方法。若您需要测试函数的已发布版本，可在已发布版本详情页面选择"函数代码"页签，参考方式二进行测试。

函数创建后您可以在AGC控制台测试函数的代码运行是否正常。进入测试界面有两种方式：

* 方式一：函数列表中点击函数名称右侧"操作"列的"测试"，在右侧弹出的"测试函数"界面进行测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/47/v3/dh1ExtAkRSegUW_5P9W3hQ/zh-cn_image_0000001978548797.png?HW-CC-KV=V1&HW-CC-Date=20260916T040230Z&HW-CC-Expire=31536000000&HW-CC-Sign=B6B24E399E06AE52EEDD6C54357394EDFC0F4CEDE95B3A1B71AF13588F765057)

* 方式二：
  1. 在函数列表中点击已创建的函数名称，进入函数详情页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/46/v3/YLZwPKA-RLm6jCvhRJvn6g/zh-cn_image_0000001948908550.png?HW-CC-KV=V1&HW-CC-Date=20260916T040230Z&HW-CC-Expire=31536000000&HW-CC-Sign=6A2D609B02663A66B194027DAE0E94B2ED95A5692458AFD14FA0BA9074B21335)

  2. 选择"函数代码"页签，点击"测试函数"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/36/v3/H2BG_UXkTFCtWS4OZEh_oQ/zh-cn_image_0000001800662133.png?HW-CC-KV=V1&HW-CC-Date=20260916T040230Z&HW-CC-Expire=31536000000&HW-CC-Sign=11E6CAC33C7AA3733B48BECEF038991150914294247E68CB5601A1E12ADFA10F)

  3. 在右侧弹出的"测试函数"界面，使用默认测试事件、创建新测试事件或者使用已保存测试事件进行测试。
     * 使用默认测试事件 直接点击"测试"对函数进行测试。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b9/v3/9R9xPQxwQCWT72QZ8_CX_Q/zh-cn_image_0000001722152221.png?HW-CC-KV=V1&HW-CC-Date=20260916T040230Z&HW-CC-Expire=31536000000&HW-CC-Sign=9F6DFBAFF2F65E2727C075C6407BFCFCC04DA5934D3763F86812E1FB1BFA7835)
     * 创建新测试事件 如果需要设置调用函数的请求消息体，可按照如下步骤配置测试参数，并可保存为测试事件方便后续继续使用。

       1. 在"事件"文本框中输入JSON格式的事件参数，点击"保存"。然后在"提示"弹出框中输入事件名称，配置完成后点击弹出框右下角的"确认"。 说明
          >
          > "事件"文本框内输入的JSON对象，对应的是触发器的event事件格式，会透传给函数。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2b/v3/PWLS-koFR8i1JAaRrkHmsg/zh-cn_image_0000001756189981.png?HW-CC-KV=V1&HW-CC-Date=20260916T040230Z&HW-CC-Expire=31536000000&HW-CC-Sign=C76A55F7E61E7EC5A7FA4B2111F6651C7D298EC4E43FCC4E1D405807EB58D8F9)
       2. 点击"测试"，函数处理事件并返回测试结果。
     * 使用已保存测试事件
       1. 在"测试函数"界面，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/56/v3/xaSPGRg1RY-RQGc6A-U-5w/zh-cn_image_0000001722236597.png?HW-CC-KV=V1&HW-CC-Date=20260916T040230Z&HW-CC-Expire=31536000000&HW-CC-Sign=DB63D78E709D789B9D8DB573CDE9DD93CE01B46A330A685BEAB3DC9907158CFF)展开已保存的测试事件列表，选择已配置的事件名称右侧的"加载"，然后点击"测试"，函数处理事件并返回测试结果。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/37/v3/ZkxO7SGhSP6xo-P0lyVAzw/zh-cn_image_0000001722453985.png?HW-CC-KV=V1&HW-CC-Date=20260916T040230Z&HW-CC-Expire=31536000000&HW-CC-Sign=740C45D798B17BA6D64D1B4EF191282146CEFF1D2805900B59CA698AF8A74A5A)
       2. （可选）若您需要删除已添加的测试事件，可在测试事件列表中点击事件名称右侧的"删除"即可删除测试事件。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a8/v3/LmZP2xinS5q4V_woBHtqJg/zh-cn_image_0000001722158501.png?HW-CC-KV=V1&HW-CC-Date=20260916T040230Z&HW-CC-Expire=31536000000&HW-CC-Sign=A548B30B9B0DB42D3D416532D42CAD0A9EF132248309430AF4675391AEBF9B17)

  4. 查看测试结果。
     * 执行结果：展示测试后获得的响应结果。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/73/v3/I5ejHlkFTLaYsUUG_6T1Lw/zh-cn_image_0000001674184734.png?HW-CC-KV=V1&HW-CC-Date=20260916T040230Z&HW-CC-Expire=31536000000&HW-CC-Sign=7737E0D28DEF12D2AE0AC76301DB3D660503E4530DE3A0FF6E860485CD355AC1)

     * 运行日志：展示函数运行过程中，通过logger API打印的日志，支持输出debug级别及以上日志（以下仅为日志输出示例）。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/38/v3/8fKVwgA-QcmIRcUwT4uH8g/zh-cn_image_0000001674190046.png?HW-CC-KV=V1&HW-CC-Date=20260916T040230Z&HW-CC-Expire=31536000000&HW-CC-Sign=45F460AFE2C8ADFA564334DCF2359D9B12EDF5803A08130D08492129E9D4660E)

     * 执行摘要：展示该次测试请求相关信息。
       * 请求ID：该条测试请求的RequestID，在后台日志中体现为X-Trace-ID。
       * 持续时间：函数执行的端到端时间。
       * 执行版本：该次调用测试的具体函数版本。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8d/v3/pErKSuIZToGvudtfcXjbmA/zh-cn_image_0000001674344770.png?HW-CC-KV=V1&HW-CC-Date=20260916T040230Z&HW-CC-Expire=31536000000&HW-CC-Sign=684D8268B420412C6AAAB297400A2D5C45ACF780B6F75BEF444F153421578BFE)
  5. "代码输入类型"为"在线编辑"的函数，测试过程中，若您需要修改函数入口文件代码，可直接在"函数代码"页签的代码编辑器中修改，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ec/v3/gewErq9_RGWbImzhTaRPcA/zh-cn_image_0000001753703418.png?HW-CC-KV=V1&HW-CC-Date=20260916T040230Z&HW-CC-Expire=31536000000&HW-CC-Sign=AA463F0D7F2ABD12BA685FCC5BDB0608DE1BA95DDB617D8DAC0313C1C525F970)

     "代码输入类型"为".zip文件"的函数，测试过程中，若您需要修改函数代码文件，可在本地修改且打包完成后，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/60/v3/rBZi6IopTwqpDFGr40kyMA/zh-cn_image_0000001717161230.png?HW-CC-KV=V1&HW-CC-Date=20260916T040230Z&HW-CC-Expire=31536000000&HW-CC-Sign=E927220A57A77BFA0FB4CB16218E6ED438F46D1CC0A98ABBA592C0AF87BEDC06)重新上传函数部署包，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。
     > 说明
     >
     > 若代码更新量比较大，需要调整函数内存配置，可点击"内存配置"下拉框进行调整，然后再上传函数部署包。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5b/v3/Q54phEq9T76UsSjV7yKgWA/zh-cn_image_0000002433940774.png?HW-CC-KV=V1&HW-CC-Date=20260916T040230Z&HW-CC-Expire=31536000000&HW-CC-Sign=5CCB1612A47622C478DB3A4CC6113A768987AE2B1CB59AD3E2C2858D3CDE50F7)
  6. 函数测试无误后，您可在"函数代码"页签点击"导出函数"导出函数部署包。导出包以"函数名称+函数版本.zip"格式命名，可查看函数结构和文件内容。
