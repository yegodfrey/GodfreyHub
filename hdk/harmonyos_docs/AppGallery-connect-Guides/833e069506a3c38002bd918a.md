# 通过控制台测试

> 说明
>
> 下文以函数latest版本为例介绍测试方法。若您需要测试函数的已发布版本，可在已发布版本详情页面选择"函数代码"页签，参考方式二进行测试。

函数创建后您可以在AGC控制台测试函数的代码运行是否正常。进入测试界面有两种方式：

* 方式一：函数列表中点击函数名称右侧"操作"列的"测试"，在右侧弹出的"测试函数"界面进行测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/47/v3/dh1ExtAkRSegUW_5P9W3hQ/zh-cn_image_0000001978548797.png?HW-CC-KV=V1&HW-CC-Date=20261008T182800Z&HW-CC-Expire=31536000000&HW-CC-Sign=C4B25DBAF8BC6914E377163F4C4904F3EFE95D712E8C0417FB710CF3D541B671)

* 方式二：
  1. 在函数列表中点击已创建的函数名称，进入函数详情页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/46/v3/YLZwPKA-RLm6jCvhRJvn6g/zh-cn_image_0000001948908550.png?HW-CC-KV=V1&HW-CC-Date=20261008T182800Z&HW-CC-Expire=31536000000&HW-CC-Sign=41724448B07AF5E0F7A5D355708C73B7B5C5432843B773959163019399408932)

  2. 选择"函数代码"页签，点击"测试函数"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/36/v3/H2BG_UXkTFCtWS4OZEh_oQ/zh-cn_image_0000001800662133.png?HW-CC-KV=V1&HW-CC-Date=20261008T182800Z&HW-CC-Expire=31536000000&HW-CC-Sign=3DD7C92401177D03C2F48DB2900094C1C6A585561DC145703DBDDFB973A9D102)

  3. 在右侧弹出的"测试函数"界面，使用默认测试事件、创建新测试事件或者使用已保存测试事件进行测试。
     * 使用默认测试事件 直接点击"测试"对函数进行测试。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b9/v3/9R9xPQxwQCWT72QZ8_CX_Q/zh-cn_image_0000001722152221.png?HW-CC-KV=V1&HW-CC-Date=20261008T182800Z&HW-CC-Expire=31536000000&HW-CC-Sign=3224180A1E1051BD7FFF28A9F2A02B55BDF14FE9E1A45B4B1E84E27560A02169)
     * 创建新测试事件 如果需要设置调用函数的请求消息体，可按照如下步骤配置测试参数，并可保存为测试事件方便后续继续使用。

       1. 在"事件"文本框中输入JSON格式的事件参数，点击"保存"。然后在"提示"弹出框中输入事件名称，配置完成后点击弹出框右下角的"确认"。 说明
          >
          > "事件"文本框内输入的JSON对象，对应的是触发器的event事件格式，会透传给函数。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2b/v3/PWLS-koFR8i1JAaRrkHmsg/zh-cn_image_0000001756189981.png?HW-CC-KV=V1&HW-CC-Date=20261008T182800Z&HW-CC-Expire=31536000000&HW-CC-Sign=FA33A037DA8005AE19E03C38B1FBB2824883034042B848CB403A07F4752302D5)
       2. 点击"测试"，函数处理事件并返回测试结果。
     * 使用已保存测试事件
       1. 在"测试函数"界面，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/56/v3/xaSPGRg1RY-RQGc6A-U-5w/zh-cn_image_0000001722236597.png?HW-CC-KV=V1&HW-CC-Date=20261008T182800Z&HW-CC-Expire=31536000000&HW-CC-Sign=B998E3D43B275D8DB29141B46BB8BC0D3833E08B8B91872E53D97258D6AB4168)展开已保存的测试事件列表，选择已配置的事件名称右侧的"加载"，然后点击"测试"，函数处理事件并返回测试结果。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/37/v3/ZkxO7SGhSP6xo-P0lyVAzw/zh-cn_image_0000001722453985.png?HW-CC-KV=V1&HW-CC-Date=20261008T182800Z&HW-CC-Expire=31536000000&HW-CC-Sign=6667AB88DB08458C0BD51EDAF4B27AB3333465E603DD5D978EA9E93A41C17ABD)
       2. （可选）若您需要删除已添加的测试事件，可在测试事件列表中点击事件名称右侧的"删除"即可删除测试事件。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a8/v3/LmZP2xinS5q4V_woBHtqJg/zh-cn_image_0000001722158501.png?HW-CC-KV=V1&HW-CC-Date=20261008T182800Z&HW-CC-Expire=31536000000&HW-CC-Sign=B73A867969E005E264C5B484C1B8B729778988E079B6A4A23920F316C0B22956)

  4. 查看测试结果。
     * 执行结果：展示测试后获得的响应结果。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/73/v3/I5ejHlkFTLaYsUUG_6T1Lw/zh-cn_image_0000001674184734.png?HW-CC-KV=V1&HW-CC-Date=20261008T182800Z&HW-CC-Expire=31536000000&HW-CC-Sign=16A7A5E064D06F874F996F434CD4B4D5EE1D5C9F033226C1BC1922D152E122B1)

     * 运行日志：展示函数运行过程中，通过logger API打印的日志，支持输出debug级别及以上日志（以下仅为日志输出示例）。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/38/v3/8fKVwgA-QcmIRcUwT4uH8g/zh-cn_image_0000001674190046.png?HW-CC-KV=V1&HW-CC-Date=20261008T182800Z&HW-CC-Expire=31536000000&HW-CC-Sign=50ACB6435A70BCF15D8E18715DCF20F99351A42EC018985DEFDBA65FC96B6AAE)

     * 执行摘要：展示该次测试请求相关信息。
       * 请求ID：该条测试请求的RequestID，在后台日志中体现为X-Trace-ID。
       * 持续时间：函数执行的端到端时间。
       * 执行版本：该次调用测试的具体函数版本。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8d/v3/pErKSuIZToGvudtfcXjbmA/zh-cn_image_0000001674344770.png?HW-CC-KV=V1&HW-CC-Date=20261008T182800Z&HW-CC-Expire=31536000000&HW-CC-Sign=2F8A44745E4E5F84CC2C7B767F7D9B00F53422176BD127A1E383DC2E05E0ECD2)
  5. "代码输入类型"为"在线编辑"的函数，测试过程中，若您需要修改函数入口文件代码，可直接在"函数代码"页签的代码编辑器中修改，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ec/v3/gewErq9_RGWbImzhTaRPcA/zh-cn_image_0000001753703418.png?HW-CC-KV=V1&HW-CC-Date=20261008T182800Z&HW-CC-Expire=31536000000&HW-CC-Sign=FFB55FC372CE7128A547A8EDB593C78C6BA4A6FBAE6DCA569CF456EB5E0BB938)

     "代码输入类型"为".zip文件"的函数，测试过程中，若您需要修改函数代码文件，可在本地修改且打包完成后，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/60/v3/rBZi6IopTwqpDFGr40kyMA/zh-cn_image_0000001717161230.png?HW-CC-KV=V1&HW-CC-Date=20261008T182800Z&HW-CC-Expire=31536000000&HW-CC-Sign=2969036BDBE41942F64E26992B103F690A5A66ADD5C0349001FF8F3C236B75B0)重新上传函数部署包，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。
     > 说明
     >
     > 若代码更新量比较大，需要调整函数内存配置，可点击"内存配置"下拉框进行调整，然后再上传函数部署包。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5b/v3/Q54phEq9T76UsSjV7yKgWA/zh-cn_image_0000002433940774.png?HW-CC-KV=V1&HW-CC-Date=20261008T182800Z&HW-CC-Expire=31536000000&HW-CC-Sign=74FEE1990C85C4E0143A8B5081229DFB1D7C205A6934FF555724445A99E08EB7)
  6. 函数测试无误后，您可在"函数代码"页签点击"导出函数"导出函数部署包。导出包以"函数名称+函数版本.zip"格式命名，可查看函数结构和文件内容。
