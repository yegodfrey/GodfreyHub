# Connect API

## 公共

### 使用Connect API时，出现"403 client token authorization fail"问题，如何处理？

出现此问题可能是如下原因导致：

* 生成Token使用的Client角色权限不足。
* 生成Token使用的Client指定了具体项目。
* 生成Token使用的Client不是云侧生成的，而是端侧生成的。
* 生成Token使用的Client和使用Connect API的项目不属于同一个开发者账号。

检查方法如下：

1. 登录AppGallery Connect，检查是否已经[创建API客户端](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section103mcpsimp)。
2. 检查创建client设置的[角色权限](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-rolepermission-0000001155345429)是否满足要求，并且项目是否设置为N/A。
3. 检查创建client的账号是否为创建使用Connect API应用的账号。

## Publishing API

### 调用提交发布接口时，出现"abis type check failed"问题，如何处理？

abis指的是软件包CPU框架，2022年3月以后，华为应用市场仅支持32+64位或者纯64位的软件包，已不支持纯32位的软件包，并且后续也会陆续取消32+64位的软件包，仅支持纯64位的软件包。请上传应用市场支持的CPU架构软件包后重试。

### 调用提交发布接口时，出现"contentRating in cds serviceAttr is invalid"问题，如何处理？

出现此问题是因为未完成年龄分级问卷。在软件上架前需要完成年龄分级的问卷，该问卷无法通过api完成，需要登录AppGallery Connect完成。此问卷仅需要完成一次，请完成问卷后重试。
