# C#（Native）

#### 前提条件

* 您已[集成游戏多媒体基础SDK和实时语音模块](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-integratingsdk-csharp-0000001227058322)。
* 您已[创建游戏多媒体实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-engine-csharp-0000001271178477#section10640141401010)。  

#### 开始播放

1. 实例化[LocalAudioInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-localaudioinfo-csharp-0000001678929513)对象，构造本地音效文件的必要参数。

   ```
   LocalAudioInfo localAudioInfo = new LocalAudioInfo();
   localAudioInfo.SoundId = 1;                                          // SoundId:音效ID,大于等于0
   localAudioInfo.Volume = 100;                                         // Volume:音效音量系数,取值范围[0, 100],默认值100
   localAudioInfo.FilePath = Application.temporaryCachePath + "/1.m4a"; // FilePath:音效文件路径,本地路径和网络URL均可
   localAudioInfo.Loop = 1 ;                                            // Loop：循环播放次数,大于等于0,默认值0表示无限循环
   ```

2. 如果是HarmonyOS NEXT平台，调用[GameMediaEngine.PlayLocalAudioClip](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-csharp-0000001231889118#section10826204201816)方法，播放本地音效。

   ```
   engine.PlayLocalAudioClip(localAudioInfo, new OpenHarmonyJSCallback(args => {
       OpenHarmonyJSObject data = args[0];
       int result = data.Get<int>("data");
       // 处理业务逻辑
   }));
   ```

   其他平台则调用[GameMediaEngine.PlayLocalAudioClip](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-csharp-0000001231889118#section1444210513185)方法，播放本地音效。

   ```
   engine.PlayLocalAudioClip(localAudioInfo); // localAudioInfo:本地音效文件信息
   ```

3. 音效播放状态更新（如播放、暂停等）时，您可进行相关回调处理。由于游戏多媒体SDK已对回调函数[onAudioClipStateChangedNotify](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-igamemmeeventhandler-csharp-0000001278554161#section12505121617242)进行了封装，您只需注册OnAudioClipStateChangedNotifyEvent事件监听，并实现AudioClipStateChangedNotifyCallback委托函数即可。

   ```
   // 对音效播放状态更新事件进行监听
   callBackHandler.OnAudioClipStateChangedNotifyEvent += AudioClipStateChangeImpl;

   void AudioClipStateChangeImpl(AudioPlayStateInfo audioPlayStateInfo)
   {
       Loom.QueueOnMainThread(() =>
       {
           // 监听处理
       }
   }
   ```

#### 暂停/恢复/停止

1. 播放本地音效过程中，可通过调用如下方法，暂停播放指定音效或所有正在播放的音效。
   * 如果是HarmonyOS NEXT平台，调用[GameMediaEngine.PauseLocalAudioClip](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-csharp-0000001231889118#section69242027182211)方法，可暂停播放指定的本地音效。

     ```
     engine.PauseLocalAudioClip(soundId, new OpenHarmonyJSCallback(args => {
         OpenHarmonyJSObject data = args[0];
         int result = data.Get<int>("data");
         // 处理业务逻辑
     }));
     ```

     其他平台则调用[GameMediaEngine.PauseLocalAudioClip](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-csharp-0000001231889118#section1056912562184)方法。

     ```
     engine.PauseLocalAudioClip(soundId); // soundId:音效ID
     ```

   * 如果是HarmonyOS NEXT平台，调用[GameMediaEngine.PauseAllLocalAudioClips](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-csharp-0000001231889118#section091563472318)方法，可暂停播放所有本地音效。

     ```
     engine.PauseAllLocalAudioClips(new OpenHarmonyJSCallback(args => {
         OpenHarmonyJSObject data = args[0];
         string result = data.Get<string>("data");
         // 处理业务逻辑
     }));
     ```

     其他平台则调用[GameMediaEngine.PauseAllLocalAudioClips](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-csharp-0000001231889118#section16257558101815)方法。

     ```
     engine.PauseAllLocalAudioClips();
     ```

2. 音效暂停播放后，可通过调用如下方法，恢复指定音效或所有已暂停音效的播放。
   * 如果是HarmonyOS NEXT平台，调用[GameMediaEngine.ResumeLocalAudioClip](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-csharp-0000001231889118#section178782410246)方法，可恢复播放指定的本地音效。

     ```

         OpenHarmonyJSObject data = args[0];
         int result = data.Get<int>("data");
         // 处理业务逻辑
     }));
     ```

     其他平台则调用[GameMediaEngine.ResumeLocalAudioClip](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-csharp-0000001231889118#section1979175981818)方法。

     ```
     engine.ResumeLocalAudioClip(soundId); // soundId:音效ID
     ```

   * 如果是HarmonyOS NEXT平台，调用[GameMediaEngine.ResumeAllLocalAudioClips](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-csharp-0000001231889118#section557111913252)方法，可恢复播放所有本地音效。

     ```
     engine.ResumeAllLocalAudioClips(new OpenHarmonyJSCallback(args => { 
         OpenHarmonyJSObject data = args[0];
         string result = data.Get<string>("data");
         // 处理业务逻辑
     }));
     ```

     其他平台则调用[GameMediaEngine.ResumeAllLocalAudioClips](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-csharp-0000001231889118#section11764171141915)方法。

#### 调节/获取音量系数

1. 在播放本地音效时，可通过调用如下方法，单个调节指定音效或批量调节所有音效的音量系数。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250424164756.72507507901068633954919643753292:50001231000000:2800:3E3F0A1DB309CB8B1E11B0B69040EBDDE9295630B533712AE874FE137ADFE379.png)  
   * 本地音效实际播放音量（V）=本地音效音量系数（X）\*所有本地音效的音量系数（Y）%
   * 目前仅支持在播放音效时设置所有本地音效的音量系数，或指定的本地音效音量系数。
   * 如果不是HarmonyOS NEXT平台则调用[GameMediaEngine.SetLocalAudioClipsVolume](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-csharp-0000001231889118#section11443189151917)方法，设置所有本地音效的音量系数。

     ```
     engine.SetLocalAudioClipsVolume(volume); // volume:所有本地音效的音量系数,默认值100
     ```

     如果是HarmonyOS NEXT平台则调用[GameMediaEngine.SetLocalAudioClipsVolume](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-csharp-0000001231889118#section11443189151917)方法，设置所有本地音效的音量系数。

     ```
     engine.SetLocalAudioClipsVolume(volume, new OpenHarmonyJSCallback(args => { 
         OpenHarmonyJSObject data = args[0];
         string result = data.Get<string>("data");
         // 处理业务逻辑
     }));
     ```

   * 如果不是HarmonyOS NEXT平台则调用[GameMediaEngine.SetVolumeOfLocalAudioClip](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-csharp-0000001231889118#section106411711916)方法，设置指定的本地音效音量系数。

     ```
     engine.SetVolumeOfLocalAudioClip(soundId, volume); // soundId:音效ID; volume:本地音效的音量系数,默认值100
     ```

   * 如果是HarmonyOS NEXT平台则调用[GameMediaEngine.SetVolumeOfLocalAudioClip](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-csharp-0000001231889118#section106411711916)方法，设置指定的本地音效音量系数。

     ```
     engine.SetVolumeOfLocalAudioClip(soundId, volume, new OpenHarmonyJSCallback(args => { 
         OpenHarmonyJSObject data = args[0];
         string result = data.Get<string>("data");
         // 处理业务逻辑
     }));
     ```
