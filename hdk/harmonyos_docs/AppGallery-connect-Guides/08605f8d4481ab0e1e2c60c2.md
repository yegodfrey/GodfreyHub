# 上传文件

您可以通过云存储SDK快速上传本地设备上的文件到云端。

## 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[初始化存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-initialize-bucket-java-0000001282104682)。

## 操作步骤

1. 预先规划云端的文件地址和需要存储到云端的本地文件。 说明
   >
   > 如果未规划云端地址，则传入的文件将上传到存储实例根目录，且默认使用源文件名作为云端文件名。
2. 调用[StorageReference.putObject](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagereference-0000001158228875#section520684492915)方法将文件上传到云端。 说明
   > * 上传文件时，会对云端文件的名称和大小进行严格的检查，具体限制请参见[使用限制](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-restrictions-0000001093263535#ZH-CN_TOPIC_0000001093263535__p1468492045318)。
   > * 当通过断点续传的方式上传较大的文件时，服务器对文件的SHA256值校验时间会相对较长，因此需设置一个较大的MaxUploadTimeout值，最大可设置为500秒。

## 参考代码

```screen
public class StorageUpload {
    private static StorageManagement storageManagement;

    /**
     * Upload a file
     *
     * @throws AGCException AGC exception
     */
    public static void uploadFile(String bucketName, String filePath, String objectName) throws AGCException {
        File file = new File(filePath);
        storageManagement = AGCStorageManagement.getInstance(AGCClient.getInstance(), "cn-north-4", bucketName);
        StorageReference storageReference = storageManagement.getStorageReference();
        String[] result = {""};
        ProgressListener listener = new ProgressListener() {
            @Override
            public void inProgress(ProgressStatus status) {
                result[0] = "upload transferred/total:" + status.getTransferredBytes() + "/" + status.getTotalBytes()
                    + "," + status.getTransferPercentage() + "%, " + "instaneos speed: "
                    + status.getInstantaneousSpeed() + ", avg speed: " + status.getAverageSpeed();
            }
        };
        ScheduledExecutorService service = Executors.newSingleThreadScheduledExecutor();
        service.scheduleAtFixedRate(() -> System.out.println(result[0]), 2, 3, TimeUnit.SECONDS);

        PutObjectRequest putObjectRequest = new PutObjectRequest();
        putObjectRequest.setObjectMetadata(null);
        putObjectRequest.setObjectName(objectName);
        putObjectRequest.setUploadFile(file);
        putObjectRequest.setProgressListener(listener);
        // 调用StorageReference.putObject将文件上传到云端
        storageReference.putObject(putObjectRequest);
        System.out.println(objectName + " upload succeeded " + storageReference.doesObjectExist(objectName));
        service.shutdownNow();
    }
    public static void initializeClient(String content) throws AGCException {
        CredentialService credential =
            CredentialParser.toCredentialWithContents(content);
        AGCParameter agcParameter = AGCParameter.builder().setCredential(credential).build();
        AGCClient.initialize(agcParameter);
        System.out.println("init agcParameter Success.");
    }
    public static void main(String[] args) throws AGCException {
        // 存储实例名
        String bucketName = "xxxx";
        // 设置云端的文件地址和需要存储到云端的本地文件
        // 云端文件路径，支持传入"文件目录/文件名"，或仅传入文件名
        String objectName = "images/demo.jpg";
        // 本地文件路径，支持传入"文件目录/文件名"，或仅传入文件名
        String filePath = "images/test.jpg";
        // 凭据信息，json格式
        String credential = "{\"type\":\"project_client_id\",\"developer_id\":\"xxx\",\"project_id\":\"xxx\",\"client_id\":\"xxx\",\"client_secret\":\"xxx\",\"configuration_version\":\"3.0\",\"region\":\"CN\"}";

        StorageUpload.initializeClient(credential);

        StorageUpload.uploadFile(bucketName, filePath,objectName);
    }
}
```

> 说明
>
> 在如上示例代码中，AGC云端实际上只存储了一个对象images/demo.jpg，仅提供了一个按斜杠分隔符来进行对象管理的功能。

## 更多信息

* 文件成功上传后，您可以[设置文件的自定义属性](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-metadata-java-0000001161896491#section172722985816)，也可以通过云存储SDK[下载文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-download-java-0000001161976515)。
* 您可以通过云存储SDK的API[列举云端某个目录下的所有文件或子目录](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-list-java-0000001115496718)。
* 当您不再需要云端的文件时，可以调用云存储SDK的API在应用客户端[删除文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-delete-java-0000001115656618)。
* 除了在应用客户端通过云存储SDK的API来上传文件，您还可以直接[在AGC控制台以可视化的方式来上传文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-manage-file-0000001281134398#section6704135012516)。
