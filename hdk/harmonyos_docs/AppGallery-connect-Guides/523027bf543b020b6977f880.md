# 通过控制台测试

> 说明
>
> 下文以函数latest版本为例介绍测试方法。若您需要测试函数的已发布版本，可在已发布版本详情页面选择"函数代码"页签，参考方式二进行测试。

函数创建后您可以在AGC控制台测试函数的代码运行是否正常。进入测试界面有两种方式：

* 方式一：函数列表中点击函数名称右侧"操作"列的"测试"，在右侧弹出的"测试函数"界面进行测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f8/v3/66a10DMnQlmryU9XMZgchw/zh-cn_image_0000001978548797.png?HW-CC-KV=V1&HW-CC-Date=20261008T191943Z&HW-CC-Expire=31536000000&HW-CC-Sign=2E91D665DDEC48C71F1F2C14147B7B8CB69A7967A886D640CE5134E0374048DE)

* 方式二：
  1. 在函数列表中点击已创建的函数名称，进入函数详情页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d5/v3/VIqVbbY3TGmvkaLwqe4paw/zh-cn_image_0000001948908550.png?HW-CC-KV=V1&HW-CC-Date=20261008T191943Z&HW-CC-Expire=31536000000&HW-CC-Sign=C6661CC06D54AC5BAAC322E3D3E039E6DE1C2937EA2431EDF0F5177827594400)

  2. 选择"函数代码"页签，点击"测试函数"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a8/v3/DdI0iEVRSMObS9UXXxZZtg/zh-cn_image_0000001800662133.png?HW-CC-KV=V1&HW-CC-Date=20261008T191943Z&HW-CC-Expire=31536000000&HW-CC-Sign=C8193DD1DC4B31583FD718164342581EE8A68228BB21AE26CCDF7A78A04F1673)

  3. 在右侧弹出的"测试函数"界面，使用默认测试事件、创建新测试事件或者使用已保存测试事件进行测试。
     * 使用默认测试事件 直接点击"测试"对函数进行测试。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/19/v3/KwZVxjD1SgiCZNjOhluydg/zh-cn_image_0000001722152221.png?HW-CC-KV=V1&HW-CC-Date=20261008T191943Z&HW-CC-Expire=31536000000&HW-CC-Sign=F5124405A5D54E8336BC8B6090DAA5EA455389E741542A83FF1B880FB60E1C6D)
     * 创建新测试事件 如果需要设置调用函数的请求消息体，可按照如下步骤配置测试参数，并可保存为测试事件方便后续继续使用。

       1. 在"事件"文本框中输入JSON格式的事件参数，点击"保存"。然后在"提示"弹出框中输入事件名称，配置完成后点击弹出框右下角的"确认"。 说明
          >
          > "事件"文本框内输入的JSON对象，对应的是触发器的event事件格式，会透传给函数。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8d/v3/abzKeDSKRDiLpoloU_1Pcg/zh-cn_image_0000001756189981.png?HW-CC-KV=V1&HW-CC-Date=20261008T191943Z&HW-CC-Expire=31536000000&HW-CC-Sign=17341B35A350ABD398583423823002B413F474E3FE3AE78BA97F4A0BC36CE6B5)
       2. 点击"测试"，函数处理事件并返回测试结果。
     * 使用已保存测试事件
       1. 在"测试函数"界面，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/86/v3/GZKAwVcKTli-356ZvoMwPA/zh-cn_image_0000001722236597.png?HW-CC-KV=V1&HW-CC-Date=20261008T191943Z&HW-CC-Expire=31536000000&HW-CC-Sign=9F443A1A33A44B06BDA1BB4DAFDDC82A9BFC91E2B6451B4FD7AAB8DD4EEF96F6)展开已保存的测试事件列表，选择已配置的事件名称右侧的"加载"，然后点击"测试"，函数处理事件并返回测试结果。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3f/v3/_lh5-u7-TeyweBLUEGVb3w/zh-cn_image_0000001722453985.png?HW-CC-KV=V1&HW-CC-Date=20261008T191943Z&HW-CC-Expire=31536000000&HW-CC-Sign=8AFEEC20E26D15BAC682518CCC67B9394C71AB35584AA680C6DA9AAD0B79D422)
       2. （可选）若您需要删除已添加的测试事件，可在测试事件列表中点击事件名称右侧的"删除"即可删除测试事件。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8a/v3/f56EF5geS72uRm-blDhu4w/zh-cn_image_0000001722158501.png?HW-CC-KV=V1&HW-CC-Date=20261008T191943Z&HW-CC-Expire=31536000000&HW-CC-Sign=0C19B2B21E82423F03BAB17565E73D63AE48C40148C58D3F1337665479960A65)

  4. 查看测试结果。
     * 执行结果：展示测试后获得的响应结果。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/05/v3/5FowVdSyQRWFnyifUONILw/zh-cn_image_0000001674184734.png?HW-CC-KV=V1&HW-CC-Date=20261008T191943Z&HW-CC-Expire=31536000000&HW-CC-Sign=6FC59EFCE2D4E5BB1D28FD9528796AEF7DD0FD73C2F9115672F67FBC542123E9)

     * 运行日志：展示函数运行过程中，通过logger API打印的日志，支持输出debug级别及以上日志（以下仅为日志输出示例）。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/60/v3/G8UcyjIaQyqXkkYPGtCXaQ/zh-cn_image_0000001674190046.png?HW-CC-KV=V1&HW-CC-Date=20261008T191943Z&HW-CC-Expire=31536000000&HW-CC-Sign=3B6761144F94ACD1BFE8EF8A157495ABCF004A74FBE0DD200F689A8A4C1B0E82)

     * 执行摘要：展示该次测试请求相关信息。
       * 请求ID：该条测试请求的RequestID，在后台日志中体现为X-Trace-ID。
       * 持续时间：函数执行的端到端时间。
       * 执行版本：该次调用测试的具体函数版本。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b9/v3/6rbfF543QZiSnHKmUkjmdg/zh-cn_image_0000001674344770.png?HW-CC-KV=V1&HW-CC-Date=20261008T191943Z&HW-CC-Expire=31536000000&HW-CC-Sign=DFE95A4B53E14A27793F033E93140CBE098F9A19DEAA85B0BA932853D705186B)
  5. "代码输入类型"为"在线编辑"的函数，测试过程中，若您需要修改函数入口文件代码，可直接在"函数代码"页签的代码编辑器中修改，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/10/v3/QBbWNsekQJiz4vCetVLjvg/zh-cn_image_0000001753703418.png?HW-CC-KV=V1&HW-CC-Date=20261008T191943Z&HW-CC-Expire=31536000000&HW-CC-Sign=3AF6AF6D847D2D8013CFE3502115226F5FAB9AB23F05ADF0C66C6294A1B0D935)

     "代码输入类型"为".zip文件"的函数，测试过程中，若您需要修改函数代码文件，可在本地修改且打包完成后，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/25/v3/dnRizIBJSQSzWPfL2GaGiw/zh-cn_image_0000001717161230.png?HW-CC-KV=V1&HW-CC-Date=20261008T191943Z&HW-CC-Expire=31536000000&HW-CC-Sign=0338406FAA90B11FE9A2E64537D9705343A19546BE5F706FDFF93BD657BE2C89)重新上传函数部署包，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。
     > 说明
     >
     > 若代码更新量比较大，需要调整函数内存配置，可点击"内存配置"下拉框进行调整，然后再上传函数部署包。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/93/v3/EUx2GC5yRROwHDfJGYZlzw/zh-cn_image_0000002433940774.png?HW-CC-KV=V1&HW-CC-Date=20261008T191943Z&HW-CC-Expire=31536000000&HW-CC-Sign=40E3B831BAE5CFD6AF763711DDF35E829532204463601D700AD90B159C1A6D0F)
  6. 函数测试无误后，您可在"函数代码"页签点击"导出函数"导出函数部署包。导出包以"函数名称+函数版本.zip"格式命名，可查看函数结构和文件内容。
