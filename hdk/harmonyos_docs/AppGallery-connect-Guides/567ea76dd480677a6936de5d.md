# 升级套餐

申请开通AGD API权限并收到华为回复邮件后，您需要先参考本节操作进行AGD套餐的升级和充值，然后可以免费体验全屏详情页手动下载。

全屏详情页自动下载和MINI详情页下载体验仍在Beta测试中，后续套餐会陆续开通。

## 选取套餐

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"。
2. 在项目列表中选择您申请开通权限时的项目。
3. 在"项目设置"下选择"项目套餐"，在"华为AGD API下载服务 - 免费档"右侧点击"升级到付费档"。 注意
   > * 升级到付费档仅用于您的相关权限开通，不会收取您的任何费用。
   > * 升级到付费档前，请确保您已完成币种设置：先[开通付费服务](https://developer.huawei.com/consumer/cn/doc/start/payment-service-0000001052865979)，然后申请任意一笔充值（充值操作请参考[充值及开票](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-account-recharge-0000001126625360)，"充值用途"请选择"通用基金"，可以不实际充值），系统将默认自动设置您的币种为人民币。
   > * 从免费套餐升级为付费套餐后，建议您尽快前往"账户中心 > 费用 > 消费提醒"[设置消费提醒](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-set-expend-reminder-0000001200737801)，以便及时了解当前的消费情况，避免意外账单费用。
