# 集成SDK

## 在Android Studio中集成（Version Catalog方式管理依赖）

> 说明
>
> 自1.9.3.302版本开始支持使用Version Catalog方式管理依赖，且仅Android Gradle 7.0及以上版本支持使用。

### 添加配置文件

为了简化配置步骤，AGC为您提供了保存应用配置信息的配置文件。您只需要将配置文件添加到您的工程目录并集成AGC插件，AGC插件可以自动将您在AGC上的应用信息加载到您的开发环境。

1. [获取agconnect-services.json文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-remoteconfig-obtain-files-0000001332958069#section6322551172411)。
2. 将"agconnect-services.json"文件拷贝到Android Studio项目的应用级根目录下。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e8/v3/eH2CK-MdTPaJOTXVUgP9IA/zh-cn_image_0000001333007821.gif?HW-CC-KV=V1&HW-CC-Date=20260916T021030Z&HW-CC-Expire=31536000000&HW-CC-Sign=39B63E4D592F968ABF184AD19A561C66B6562AFA216AED4124EF3635957D488E)

### 声明AGC插件和SDK

1. 打开Android Studio项目级gradle目录下的"libs.versions.toml"文件，声明AGC插件和SDK。
   1. 在[versions]中声明AGC插件版本号和SDK版本号。

      ```screen
      [versions]
      agcVersion = "1.9.6.300"
      ```

   2. 在[plugins]中声明AGC插件的id。

      ```screen
      [plugins]
      agcp = {id = "com.huawei.agconnect.agcp", version.ref = "agcVersion"}
      ```

   3. 在[libraries]中声明远程配置SDK。

      ```screen
      [libraries]
      agconnect-remoteconfig = {module = "com.huawei.agconnect:agconnect-remoteconfig", version.ref = "agcVersion"}
      ```

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/92/v3/GvH2EqL7RWCQDQZ_kQAoxA/zh-cn_image_0000002396418634.png?HW-CC-KV=V1&HW-CC-Date=20260916T021030Z&HW-CC-Expire=31536000000&HW-CC-Sign=B51FC4FCB4B90BDBF0A8AA4DDBA47218715A9CA26A5850877FB462FFF2551D9E "点击放大")
2. 在项目级的"build.gradle"文件中，设置AGC插件依赖。

   ```screen
   plugins {
       alias(libs.plugins.android.application) apply false
       alias(libs.plugins.kotlin.android) apply false
       alias(libs.plugins.kotlin.compose) apply false
       alias(libs.plugins.agcp) apply false
   }
   ```

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/84/v3/AKoz5GJUQAOTQn8n3B-8Wg/zh-cn_image_0000002429783609.png?HW-CC-KV=V1&HW-CC-Date=20260916T021030Z&HW-CC-Expire=31536000000&HW-CC-Sign=75C78EFB9488A0795FDBF46F46C26C33A21220F3C284D029D9AD72962FE0F0B3)
3. 打开项目级"settings.gradle"文件，配置Maven仓地址。

   ```screen
   pluginManagement {
     repositories {
       google {
         content {
           includeGroupByRegex("com\\.android.*")
           includeGroupByRegex("com\\.google.*")
           includeGroupByRegex("androidx.*")
         }
       }
       mavenCentral()
       gradlePluginPortal()
       maven { url 'https://developer.huawei.com/repo/' }
     }
   }
   dependencyResolutionManagement {
     repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
     repositories {
       google()
       mavenCentral()
       maven { url 'https://developer.huawei.com/repo/' }
     }
   }
   ```

1. 打开应用级的"build.gradle"文件，使用alias(libs.plugins.agcp)添加AGC插件。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cf/v3/NSlwD4qlQRelnJpDSeuhJA/zh-cn_image_0000002396423826.png?HW-CC-KV=V1&HW-CC-Date=20260916T021030Z&HW-CC-Expire=31536000000&HW-CC-Sign=D7A235575700FA6F5974ACE221A97137167880B648B345C2504449873DD380E9 "点击放大")

   ```screen

   }
   ```

## （可选）适配R8优化资源收缩器

AGP 9.0默认将 `android.r8.optimizedResourceShrinking` 标志设置为true，详情请参考[Android官方文档](https://developer.android.com/topic/performance/app-optimization/enable-app-optimization#keep-resources)。

AGC插件会读取agconnect-services.json文件，并为应用程序生成以agc_*为前缀的字符串资源，这些资源放在APK的resources.arsc文件中。 应用会在运行时动态访问这些资源。R8优化资源收缩器可能会将这些未在代码中直接（静态）引用的动态字符串资源视为不必要的资源并将其删除。因此，应用可能将以agc_*为前缀的字符串资源删除，从而导致应用功能异常或者崩溃。

为解决上述问题，请在项目资源（例如res/raw/my.package.keep.xml）中创建XML keep文件，详情请参考[自定义要保留的资源](https://developer.android.google.cn/topic/performance/app-optimization/customize-which-resources-to-keep)。

例如：

```screen
<?xml version="1.0" encoding="utf-8"?>
<resources xmlns:tools="http://schemas.android.com/tools"
tools:keep="@string/agc_*" /
```

## 在Eclipse中集成

1. 获取AGC服务依赖的Eclipse工程包。 说明
   >
   > 生成Eclipse工程包前请确保本地PC已经安装了JDK和Android SDK。
   1. 点击[此处](https://github.com/netwalker128/aar-to-eclipse/releases/download/v1.0/aar2eclipse.zip)获取用于生成Eclipse工程包的工具包"aar2eclipse.zip"，保存在本地并解压。
   2. 打开"aar2eclipse/aar"目录下的build.gradle文件，检查Maven仓地址是否配置准确。

      ```screen
      allprojects {
          repositories {
              maven { url 'https://developer.huawei.com/repo' }
              google()
              jcenter()
          }
      }
      ```


   3. 在"dependencies"中配置远程配置的SDK依赖地址。

      ```screen
      "Java"
      dependencies {
          embed "com.huawei.agconnect:agconnect-remoteconfig:1.9.6.300"
      }
      ```

      ```screen
      "Kotlin"
      dependencies {
          embed "com.huawei.agconnect:agconnect-remoteconfig-ktx:1.9.1.300"
      }
      ```


   4. 双击执行"aar2eclipse/aar"目录下的build.bat文件。执行成功后，会在日志中打印输出Eclipse工程包路径（即"aar2eclipse/aar"目录下的"eclipse"目录）。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/64/v3/xzmILv8MTX2V0w-ySdd_AA/zh-cn_image_0000001281277444.png?HW-CC-KV=V1&HW-CC-Date=20260916T021030Z&HW-CC-Expire=31536000000&HW-CC-Sign=9499DA9953F6F1A08C88F582CB8BA6F60C060EE578FB20E46ED6DC38DA06B3B9)


2. 打开您的Eclipse工程，选择"File > Import"，将前面生成的Eclipse工程包导入到您的工作空间。
   1. 选择"Android > Existing Android Code Into Workspace"，点击"Next"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8d/v3/9ODkMnJQTtOQ4uWOnSgpBA/zh-cn_image_0000001281037564.png?HW-CC-KV=V1&HW-CC-Date=20260916T021030Z&HW-CC-Expire=31536000000&HW-CC-Sign=C39EF66330FE196A9D98D0D22831475E9CECFC9CAA2524DE5BC28AE93B23FF66)

   2. 点击"Browse"，选择工程包所在的"aar2eclipse/aar/eclipse"目录。在"Projects"下显示待导入的工程（默认工程名为"BridgeActivity"），勾选后点击"Finish"。 说明
      >
      > 待导入的工程必须和工作空间在相同的磁盘空间里，例如都在"D:\"。如果不在，您可以选择"Copy projects into workspace"，将工程文件复制到工作空间。同时，不要将待导入的工程和您的Eclipse工程放在同一层级目录，否则可能导入失败。

3. 添加工程依赖关系。
   1. 右键点击您的工程，选择"Properties"。
   2. 在左侧选择"Android"，点击"Add"，选择已导入空间的BridgeActivity工程。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/de/v3/57ZmVFNrTVmWeH8SJ4RKiQ/zh-cn_image_0000001281437432.png?HW-CC-KV=V1&HW-CC-Date=20260916T021030Z&HW-CC-Expire=31536000000&HW-CC-Sign=E4CC75F7EE3BE310B762731714AB8A5DD3B6E841CD11DB1D7CE6A0C09F36DC81)

   3. 点击**"**Apply and Close"，完成添加。
4. 拷贝资源文件到您的工程目录。 由于Eclipse不能自动合并assets目录，请手动将导入的BridgeActivity工程下assets目录里的全部文件拷贝到您Eclipse工程中assets目录下。需要拷贝的资源文件如下：

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b4/v3/Vx1U0KB4RwexT3xz1ZdNRg/zh-cn_image_0000001334157265.png?HW-CC-KV=V1&HW-CC-Date=20260916T021030Z&HW-CC-Expire=31536000000&HW-CC-Sign=FD27A773092D861728CC8BC7C79444BFA746278C55F0775CB13B21BC5A5B55E8)
5. 修改工程配置。
   1. 配置project.properties文件。 由于Eclipse默认不⽀持AndroidManifest.xml⽂件的合并，需要在您的工程目录中找到project.properties文件并打开，添加如下配置，用于合并子工程中的Manifest文件。

      ```screen
       manifestmerger.enabled=true
      ```

   2. 配置包名。 请手动修改BridgeActivity工程下AndroidManifest.xml中的所有"${applicationId}"为您的应用包名。例如：

      修改前：

      ```screen
      <application>
      <provider
          android:name="com.huawei.agconnect.core.provider.AGConnectInitializeProvider"
          android:authorities="${applicationId}.AGCInitializeProvider"
          android:exported="false" />
      ```

      修改后：

      ```screen
      <application>
          <provider
              android:name="com.huawei.agconnect.core.provider.AGConnectInitializeProvider"
              android:authorities="com.huawei.configeclipse.AGCInitializeProvider"
              android:exported="false" />
      ```

6. 添加AppGallery Connect配置文件。
   1. [获取agconnect-services.json文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-remoteconfig-obtain-files-0000001332958069#section6322551172411)。
   2. 由于Eclipse不支持AGC插件，您可以将agconnect-services.json文件放置到您的工程中assets目录下，并且在应用的Application类中添加如下代码。如果应用没有Application类，则需要新建，例如新建MyApplication类。

      ```screen
      public class MyApplication extends Application{
          // TODO: 添加如下代码
          @Override
          public void onCreate() {
              super.onCreate();
              try {
                  AGConnectOptionsBuilder builder = new AGConnectOptionsBuilder();
                  builder.setInputStream(getAssets().open("agconnect-services.json"));
                  AGConnectInstance.initialize(this, builder);
              } catch (IOException e) {
                  e.printStackTrace();
              }
          }
          // TODO: 添加代码结束             
      }
      ```

   3. 打开您的工程AndroidManifest.xml文件，在"application"模块中添加MyApplication类声明。如果已经声明，则跳过此步骤。

      ```screen
      <application
          <!---添加声明开始 -->
          android:name=".MyApplication">
          <!---添加声明结束 -->
      </application>
      ```

   4. 在Eclipse的菜单栏中点击"Project"，执行"clean"操作。

## （可选）将密钥信息传递给AGC

### 通过配置文件参数传递密钥

AGC SDK提供了[AGConnectOptionsBuilder](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-agconnectoptionsbulider-0000001116227891)类来对agconnect-services.json文件中的参数进行配置，如果您在下载配置文件时选择了"不包含密钥"，则agconnect-services.json文件中将不包含client_id、client_secret和api_key参数，您必须通过[AGConnectOptionsBuilder](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-agconnectoptionsbulider-0000001116227891)类的接口在应用启动时将参数设置给AGC SDK。

建议您在Application或者第一个启动的Activity的onCreate方法中完成client_id、client_secret和api_key等参数的设置。

```screen
//添加如下代码
try {
	AGConnectOptionsBuilder builder = new AGConnectOptionsBuilder();
	InputStream in = getAssets().open("agconnect-services.json");    //如果使用了AGC插件，删除此行
	builder.setInputStream(in);                                      //如果使用了AGC插件，删除此行
	builder.setClientId("client_id");
	builder.setClientSecret("client_secret");
	builder.setApiKey("api_key");
	builder.setCPId("cp_id");
	builder.setProductId("product_id");
	builder.setAppId("app_id");
	AGConnectInstance.initialize(this, builder);
} catch (IOException e) {
	e.printStackTrace();
}
//TODO: 添加代码结束
```

需配置的参数的值可在"项目设置 > 常规"页面中查询，点击页面参数后面的![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2e/v3/GAM4sOKvR_a7J4OvegJKHw/zh-cn_image_0000001400437573.png?HW-CC-KV=V1&HW-CC-Date=20260916T021030Z&HW-CC-Expire=31536000000&HW-CC-Sign=47C9679FE5A76B714BB6A002B9563147F39B1A04B0A4A09EDC2AB09CC9BE6968)，可复制参数值。

需配置的参数值和"常规"页面参数的对应关系如下：

* "client_id"替换为"常规"页面"项目"栏中"Client ID"的值。
* "client_secret"替换为"常规"页面"项目"栏中"Client Secret"的值。
* "api_key"替换为"常规"页面"项目"栏中"API密钥（凭据）"的值。
* "cp_id"替换为"常规"页面"开发者"栏中"Developer ID"的值。
* "product_id"替换为"常规"页面"项目"栏中"项目ID"的值。
* "app_id"替换为"常规"页面"应用"栏中"APP ID"的值。

### 通过Token传递密钥

如果您认为client_id和client_secret放在json文件里不安全，我们建议您将client_id和client_secret放在自己的服务端。先调用https://connect-drcn.dbankcloud.cn/agc/apigw/oauth2/v1/token接口去换取Token，然后在初始化AGC SDK时通过[setCustomCredentialsProvider](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-agconnectoptionsbulider-0000001116227891#section9602114520710)将Token传给AGC去使用。

Token接口请求示例：

```screen
POST /agc/apigw/oauth2/v1/token
Host: connect-drcn.dbankcloud.cn
Content-Type: application/json
{
   "grant_type":"client_credentials",
   "client_id":"agc应用页面提供的client_id",
   "client_secret":"agc应用页面提供的client_secret",
   "useJwt":1
}
```

Token接口响应示例：

```screen
HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8
{
    "access_token": "eyJhbGciOiJIUzU****************",
    "expires_in": 0
}
```

setCustomCredentialsProvider接口调用示例：

```screen
"Java"
String tokenStr = "access_token";
long expiration = expires_in;

CustomCredentialsProvider developerClientToken = new CustomCredentialsProvider() {
    @Override
    public Task<Token> getTokens(boolean forceRefresh) {
        TaskCompletionSource<Token> source = new TaskCompletionSource<>();
        Token token;
            token = new Token() {
                @Override
                public long getExpiration() {
                    return expiration;
                }

                @Override
                public long getIssuedAt() {
                    return 0;
                }

                @Override
                public long getNotBefore() {
                    return 0;
                }

                @Override
                public String getTokenString() {
                    return tokenStr;
                }
            };
        source.setResult(token);
        return source.getTask();
    }
};

AGConnectOptionsBuilder builder = new AGConnectOptionsBuilder();
builder.setCustomCredentialsProvider(developerClientToken);
AGConnectInstance.initialize(getApplicationContext(),builder);
```

```screen
"Kotlin"

val expiration: Long = expires_in

    val source = TaskCompletionSource<Token>()
    val token: Token
    token = object : Token {

            return 0
        }

        override fun getNotBefore(): Long {
            return 0
        }

    }
    source.setResult(token)

}

```

## 配置混淆脚本

开发者编译APK前需要配置不要混淆AppGallery Connect，避免功能异常。

1. 打开混淆配置文件。
2. 加入排除AppGallery Connect的混淆配置。
   * Android Studio开发环境
     * 如果是Proguard混淆，配置如下：

       ```screen
       -ignorewarnings
       -keep class com.huawei.agconnect.**{*;}
       ```

     * 如果是Dexguard混淆，配置如下：

       ```screen
       -ignorewarnings
       -keep class com.huawei.agconnect.** {*;} 
       -keepresourcexmlelements ** 
       -keepresources */*
       ```

   * Eclipse开发环境

     在proguard-project.txt文件中加入混淆配置。

     ```screen
     -keep class com.huawei.agconnect.remoteconfig.*{*;}
     -keepclassmembers class **{
         public <init>(android.content.Context,com.huawei.agconnect.AGConnectInstance);
     }
     -keepclassmembers class com.huawei.agconnect.remoteconfig.internal.server.**{*;}
     -keep class * implements android.os.Parcelable {
         public static final android.os.Parcelable$Creator *;
     }
     ```

## （可选）初始化SDK

应用集成AGC SDK时，如果使用了多进程处理机制，则需要在子进程中调用初始化方法。

在Application的onCreate方法中添加初始化代码：

```screen
if (AGConnectInstance.getInstance() == null) { 
     AGConnectInstance.initialize(getApplicationContext()); 
}
```
