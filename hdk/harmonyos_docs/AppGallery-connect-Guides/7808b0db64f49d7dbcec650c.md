# 集成SDK并使用数据库

云数据库提供多种云数据库数据管理方式，您可以在AGC控制台管理数据，也可以在服务器上直接管理云侧数据库中的数据。您只需要在服务器端的服务中集成云数据库服务的Server SDK，即可调用它提供的接口，完成相关服务功能开发。Server SDK将会为您的服务器与云数据库的通信和安全提供保障。  

#### 开发前准备

使用Server SDK管理数据，需要完成以下准备工作：

您已经获取到示例代码，请从[示例代码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Examples/agc-clouddb-samplecode-serverjava-0000001127674569)获取。

#### 集成SDK

1. 添加Server SDK至应用级build.gradle文件。 在\<项目名\>/app/build.gradle文件中dependencies部分添加Server SDK。

   ```
   dependencies {
   	// 添加Server SDK
   	implementation 'com.huawei.agconnect.server:agconnect-database-server-sdk:1.0.13.300'
   }
   ```

2. 在应用级build.gradle文件中设置Java源码兼容模式为JDK1.8.0_212版本。

   ```
   compileOptions {
   	sourceCompatibility = 1.8.0_212
   	targetCompatibility = 1.8.0_212
   }
   ```

#### 初始化

在添加对象类型文件后，您就可以开始开发Server端的服务。在开发Server端的服务前，您需要先初始化对应数据处理位置的AGCClient，并创建存储区实例和CloudDBZoneConfig对象，设置需要进行数据操作的云侧存储区名称。

1. 初始化AGCClient实例。  
   将[获取的认证凭据](#section11430313174412)放置到您自定义的目录，并通过[ClientNameEnum](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clientnameenum-serverjava-0000001164741404)指定对应数据处理位置，调用[getClientName](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clientnameenum-serverjava-0000001164741404#section21517264518)方法获取初始化后的AGCClient实例。

   ```
   String credentialPath = "agc-apiclient.json";
   AGCClient.initialize(ClientNameEnum.CLOUDDB_CN.getClientName(), AGCParameter.builder()
   .setCredential(CredentialParser.toCredential(credentialPath))
   .build(), Constants.Region.REGION_CN);
   ```

   AGCClient初始化参数对应关系如下表。  

   |ClientNameEnum|Constants.Region|
   |:-------------|:---------------|
   |CLOUDDB_CN|REGION_CN|
   |CLOUDDB_RU|REGION_RU|
   |CLOUDDB_SG|REGION_SG|
   |CLOUDDB_DE|REGION_DE|

2. 获取AGConnectCloudDB实例。  
   通过[getInstance(AGCClient agcClient)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agconnectclouddb-serverjava-0000001127713495#section611115509224)方法获取对应数据处理位置的AGConnectCloudDB实例。

   ```
   AGCClient agcClient = AGCClient.getInstance(CLOUDDB_CN.getClientName());
   AGConnectCloudDB agConnectCloudDB = AGConnectCloudDB.getInstance(agcClient);
   ```

3. 创建CloudDBZoneConfig配置对象并打开存储区。  
   创建CloudDBZoneConfig配置对象，并设置云侧存储区名称，打开存储区实例，详细请参考[CloudDBZoneConfig](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzoneconfig-serverjava-0000001081013910)。

   ```
   CloudDBZoneConfig cloudDBZoneConfig = new CloudDBZoneConfig("QuickStartDemo");
   CloudDBZone mCloudDBZone = agConnectCloudDB.openCloudDBZone(cloudDBZoneConfig);
   ```

#### 写入数据

在本节主要介绍如何在Server端的服务中进行数据写入操作，以便您了解如何使用Server SDK实现数据的写入。使用[executeUpsert()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section186709715599)方法实现数据的写入，"BookInfo"为已定义对象类型，可参见[新增和导出对象类型](#section8375194164915)。

```
"具体对象"
public void upsertBookInfo(BookInfo bookInfo) {
	if (mCloudDBZone == null) {
		LOGGER.warn("CloudDBClient is null, try re-initialize it");
		return;
	}
	try {
		CompletableFuture<Integer> result = mCloudDBZone.executeUpsert(bookInfo);
		System.out.println(result.get());
	} catch (AGConnectCloudDBException | ExecutionException | InterruptedException e) {
		LOGGER.warn("upsertBookInfo: " + e.getMessage());
	}
}
```

```
"泛化对象"

#### 查询数据

通过[executeQuery()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-serverjava-0000001127596267#section696713285599)和[get()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-text-serverjava-0000001127830645#section1611671924611)方法的组合实现异步方式查询数据。

```
"具体对象"
public void queryBooks(CloudDBZoneQuery<BookInfo> query) {
    if (mCloudDBZone == null) {
        LOGGER.warn("CloudDBClient is null, try re-initialize it");
        return;
    }
    try {
        CompletableFuture<CloudDBZoneSnapshot<BookInfo>> result = mCloudDBZone.executeQuery(query);
        CloudDBZoneSnapshot<BookInfo> snapshot = result.get();
        processQueryResult(snapshot);
    } catch (AGConnectCloudDBException | InterruptedException | ExecutionException e) {
        LOGGER.warn("queryBooks: " + e.getMessage());
    }
}
```

```
"泛化对象"
public void queryBooks(String objectTypeName) {
    if (mCloudDBZone == null) {
        LOGGER.warn("CloudDBClient is null, try re-initialize it");
        return;
    }

    try {
	CloudDBZoneQuery<CloudDBZoneGenericObject> query = CloudDBZoneQuery.where("BookInfo");
        CompletableFuture<CloudDBZoneSnapshot<CloudDBZoneGenericObject>> result = mCloudDBZone.executeQuery(query);
        CloudDBZoneSnapshot<CloudDBZoneGenericObject> snapshot = result.get();
        processQueryResult(snapshot);
    } catch (AGConnectCloudDBException e) {
	throw new RuntimeException(e);
    }
}
```

通过查询与[orderByDesc()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-serverjava-0000001127830643#section94841244526)方法和[limit()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-serverjava-0000001127830643#section21131850623)方法组合来实现数据的降序排序，并限制查询数据显示条数。

```
"具体对象"
private void queryWithOrder() {
    CloudDBZoneQuery<BookInfo> query = CloudDBZoneQuery.where(BookInfo.class);
    try {
        query.orderByDesc("price");
        query.limit(10);
        CompletableFuture<CloudDBZoneSnapshot<BookInfo>> result = mCloudDBZone.executeQuery(query);
        processQueryResult(result.get());
    } catch (AGConnectCloudDBException | InterruptedException | ExecutionException e) {
        LOGGER.warn("queryWithOrder: " + e.getMessage());
    }
}
```

```
"泛化对象"
private void queryWithOrder() {
    CloudDBZoneQuery<CloudDBZoneGenericObject> query = CloudDBZoneQuery.where("BookInfo");
    try {
        query.orderByDesc("price");
