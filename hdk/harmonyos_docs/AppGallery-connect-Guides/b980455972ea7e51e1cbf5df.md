# 软件包管理

## 上传渠道包

1. 点击普通渠道包或者极小渠道包"操作"中的"软件包管理"。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115012.63775708134036830992099780644099:50531125054745:2800:6D64200EDA4BB2FF0E9FD957FC359435A3229FD112DB1B0B395543E76EF09205.png?needInitFileName=true?needInitFileName=true)

2. 在软件包管理界面会显示自动生成的主包信息，"渠道包上传"状态为"未上传"，点击"上传"。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115012.22242961523476536560949578035202:50531125054745:2800:4D088E5C2D3BB726FFB51177299F045D4D02F36123334E372ADB586A01F73658.png?needInitFileName=true?needInitFileName=true)

3. 点击![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115012.03406392233899113792666593518527:50531125054745:2800:D5AFA184B17404BE76DDF08F34DD2316773DA4B8EFA08CB2FE3FBCFB64F0FFB8.png?needInitFileName=true?needInitFileName=true)后选择待上传的软件包，上传的渠道包包名和主包包名需一致。 说明
   >
   > 渠道包支持多包功能，多包的区分维度包括：
   > * 主包CPU架构（32/64位）
   > * 主包屏幕密度/尺寸
   > * 主包HMS/GMS依赖

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115012.57644413360486162474943891051701:50531125054745:2800:B80272626BF2D8925AB98B4351D665B033EBFCDDF42FEFFB9F9EF9180F934479.png?needInitFileName=true?needInitFileName=true)

   上传渠道包后，渠道包进入"待处理"状态。约15-30分钟完成自动审核。

## 删除渠道包

"渠道包状态"为"生效"或者"自动审核中"时可以删除。点击"删除"，弹框二次确认后直接删除渠道包。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115012.77756336427145693897148794396281:50531125054745:2800:9F4846EA2E16A5E1FDD5DD583A4218D021FCBAB978A192C4B48764271BCA8C92.png?needInitFileName=true?needInitFileName=true)

## 下载渠道包

上传的渠道包可点击"下载"直接下载渠道包。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115012.65840431527011651601232617022004:50531125054745:2800:796EE164AB3D5FFBCDC3417785D5D93F2E78A5ADC1C6386C33EB06475952D6C3.png?needInitFileName=true?needInitFileName=true)

## 修改渠道包

* 主包不升级新版本的场景下：
  * 已审核通过的渠道包不支持修改，只能删除后重新上传。


  * 自动审核不通过的渠道包会显示"修改"按钮，点击"修改"可上传新的渠道包，此时渠道包再次进入自动审核流程，状态更新为"自动审核中"。

  ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115012.81429364806680130800300684596020:50531125054745:2800:0C54F7739C82047288531B9A6A717B33F1DC74D7C686509C28B04E3DB248DC35.png?needInitFileName=true?needInitFileName=true)
* 主包升级新版本的场景下，您可以在自动生成的新版本渠道包的记录下"上传"新版本的渠道包。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221126115012.79083788754166752133514880600231:50531125054745:2800:F6C9613F4AB88E71AFF550A928228EFE26A09BDC2446878F2F08D8CB4A39DAEC.png?needInitFileName=true?needInitFileName=true)

  > 说明
  >
  > 如需上传新版本的渠道包，请先升级主包。
  >
  > 上传新版本的渠道包并且审核通过后，旧版本的渠道包状态会自动失效，但是依然显示在软件包管理页面上，您可根据业务需要删除旧版本渠道包的记录。
