# 查询已订阅频道列表

当订阅若干频道后，可通过查询已订阅的频道列表信息，查看频道的订阅情况。

## 前提条件

* 您已[集成游戏多媒体基础SDK和实时信令模块](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-integratingsdk-ios-0000001323104597#ZH-CN_TOPIC_0000001323104597__li16373152113206)。
* 您已[创建游戏多媒体实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-engine-ios-0000001272544612#section1093713161034)。

## 开发步骤

如需查询已订阅的频道列表，调用[HWPGMEngine.getInstance getRtmSubscribedChannelInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section18265121952714)方法，即可获取当前已订阅的所有频道列表。

```screen
GetRtmSubscribedChannelInfoResult *result = [HWPGMEngine.getInstance getRtmSubscribedChannelInfo];
```
