# 导入用户

您可以通过认证服务的Server SDK将准备好的用户信息导入到认证服务的用户数据中。

## 前提条件

1. 导入用户前需要开启认证服务和对应的认证方式，请参见[开启认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。


2. 您需要在您的开发工程中集成认证服务的Server SDK以及完成初始化，请参见[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-server-integration-sdk-0000001333298505)。 说明
   >
   > 导入用户数据中providerId和认证方式的对应关系请参见[ProviderInfo](#ZH-CN_TOPIC_0000001054048890__p1731446689)，例如准备导入的用户数据中包含认证方式类型为"手机号码"，即providerId为11的用户数据时，需要开启"手机号码"的认证方式。

## 开发步骤

1. 准备用于导入用户数据的文件，一次最多导入1000个用户。

   服务器进程执行用户需要具备导入用户数据文件的读取权限，文件后缀名必须为.json，用户数据以JSON字符串格式存储，示例如下：

   ```screen
   {
     "users": [
       {
         "uid": "12345",
         "displayName": "Bob",
         "photoUrl": "https://***.jpg",
         "email": "users@example.com",
         "emailVerified": "false",
         "phoneNumber": "+86-13451901222",
         "createdAt": "123456",
         "lastSignedInAt": "123456",
         "passwordHash": "ABC123456",
         "salt": "ABC123456",
         "providers": [
           {
             "providerId": "1",
             "rawId": "ABC123",
             "photoUrl": "https://***.jpg",
             "displayName": "ABC123456",
             "openId": "123456"
           }
         ]
       },
       {
         "uid": "56789",
         "displayName": "Andy",
         "photoUrl": "https://***.jpg",
         "email": "users1@example.com",
         "emailVerified": "false",
         "phoneNumber": "+86-13451901223",
         "createdAt": "56789",
         "lastSignedInAt": "56789",
         "passwordHash": "ABC56789",
         "salt": "ABC56789",
         "providers": [
           {
             "providerId": "1",
             "rawId": "ABC56789",
             "photoUrl": "https://***.jpg",
             "displayName": "ABC56789",
             "openId": "56789"
           }
         ]
       }
     ]
   }
   ```

   数据文件字段说明如下表所示。

   |**参数**|**必选(M)/可选(O)**|**类型**|**说明**|
   |:-------------|:--------------|:---------------------------------------------------------|:--------------------------------------------------------------------------|
   |uid|M|String(1024)|用户ID，唯一标识。|
   |displayName|O|String(1024)|用户昵称。|
   |photoUrl|O|String(2048)|头像地址。|
   |email|O|String(512)|用户邮箱地址。 第三方的认证信息providers中的providerId为12的时候不能为空。|
   |emailVerified|O|boolean|邮箱是否需要验证，值为true或者false。 第三方的认证信息providers中的providerId为12的时候不能为空|
   |phoneNumber|O|String(32)|手机号。格式: +国家码-手机号，示例+86-13451901222。 第三方的认证信息providers中的providerId为11的时候不能为空|
   |createdAt|M|String(32)|创建时间，距离1970年1月1日毫秒数。|
   |lastSignedInAt|O|String(32)|上次登入时间，距离1970年1月1日的毫秒数。|
   |passwordHash|O|String(8192)|BASE64编码后密码hash值。|
   |salt|O|String(8192)|BASE64编码后的盐值。|
   |providers|M|[ProviderInfo](#ZH-CN_TOPIC_0000001054048890__p1731446689)|第三方的认证信息。|

   **ProviderInfo**

   |**参数**|**必选(M)/可选(O)**|**类型**|**说明**|
   |:----------|:--------------|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |providerId|M|String|认证方式类型: * 0：匿名账号 * 1：华为账号 * 2: FACEBOOK* * 3. TWITTER* * 4：微信 * 5：华为游戏 * 6：QQ * 7：微博 * 8：GOOGLE* * 9: GOOGLE_PLAY_GAME* * 10：自建账号 * 11：手机 * 12：邮箱 * 13：苹果账号 * 18：支付宝账号 > 说明 > *星号标记的账号类型仅在海外站点支持，当您选择数据处理位置为德国、新加坡或俄罗斯时可以使用这些认证方式。|
   |rawId|M|String(1024)|用户唯一标识，由三方系统分配。|
   |photoUrl|O|String(2048)|头像地址。|
   |displayName|O|String(1024)|用户昵称|
   |openId|O|String(1024)|发送者唯一标识，例如微信openId。|

   此外，我们也兼容Firebase用户数据格式的导入，数据示例如下：

   ```screen
   {
   	"users": [ {
   			"localId": "HoETzmOVDrOVQOyjlPZs*****",
   			"email": "***@163.com",
   			"emailVerified": false,
   			"passwordHash": "NV1ziqNL+h5xEhfT0j1cr5PdjVaY18SjEVetiF2bgs8aS8OmTbXSo3Q8jRFrTCfPp6xyZFRo*****",
   			"salt": "DT9NV08yknB***",
   			"lastSignedInAt": "1571736344799",
   			"createdAt": "1571733747820",
   			"providerUserInfo": []
   		}, {
   			"localId": "qYmqCevzEAN3OLDkbK3n*****",
   			"email": "*****@gmail.com",
   			"emailVerified": false,
   			"displayName": "Anna Gates",
   			"photoUrl": "https://*****/140993387218547/picture",
   			"lastSignedInAt": "1571742883915",
   			"createdAt": "1571665221109",
   			"providerUserInfo": [{
   					"providerId": "facebook.com",
   					"rawId": "140993387*****",
   					"email": "*****@gmail.com",
   					"displayName": "Anna Gates",
   					"photoUrl": "https:/*****/picture"
   				}
   			]
   		}
   	]
   }
   ```

   数据文件字段说明如下表所示。

   |**参数**|**必选(M)/可选(O)**|**类型**|**说明**|
   |:---------------|:--------------|:-----------------------------------------------------------------|:-------------------------------------------------------------------------------|
   |localId|M|String(1024)|用户ID，唯一标识。|
   |displayName|O|String(1024)|用户昵称。|
   |photoUrl|O|String(2048)|头像地址。|
   |email|O|String(512)|用户邮箱地址。|
   |emailVerified|O|boolean|邮箱是否需要验证。|
   |phoneNumber|O|String(32)|手机号。|
   |createdAt|M|String(32)|创建时间，距离1970年1月1日毫秒数。|
   |lastSignedInAt|O|String(32)|上次登入时间，距离1970年1月1日的毫秒数。|
   |passwordHash|O|String(8192)|BASE64编码后密码hash值。 > 说明 > 认证服务不兼容Firebase的加密算法，所以Firebase的用户密码无法导入。建议导入后引导用户重置密码。|
   |salt|O|String(8192)|BASE64编码后的盐值。|
   |providerUserInfo|M|[ProviderUserInfo](#ZH-CN_TOPIC_0000001054048890__p10736154911119)|第三方的认证信息。|

   **ProviderUserInfo**

   |**参数**|**必选(M)/可选(O)**|**类型**|**说明**|
   |:----------|:--------------|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |providerId|O|String|第三方认证方式类型： * google.com: GOOGLE * facebook.com: FACEBOOK * twitter.com: TWITTER > 说明 > google.com、facebook.com和twitter.com的账号类型仅在海外站点支持，当您选择数据处理位置为德国、新加坡或俄罗斯时可以使用这些认证方式。|
   |rawId|O|String(1024)|用户唯一标识，由三方系统分配。|
   |email|O|String(512)|注册第三方认证方式时使用的邮箱。|
   |photoUrl|O|String(2048)|头像地址。|
   |displayName|O|String(1024)|用户昵称。|

2. 调用[AGCAuth.importUserData](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/auth-serversdk-agcauth-0000001055003341#section35021234896)，传入用户数据json文件。

   ```screen
   UserImportExportResult result = agcAuth.importUserData("/home/auth/import/userdata.json");
   ```

   导入用户结果说明：

   |字段|类型|说明|
   |:-------------|:-----------|:-----------|
   |successUsers|int|导入成功用户数量。|
   |errorUsers|int|导入失败用户数量。|
   |errorUsersList|List<String>|导入失败用户uid列表。|

   导入成功后您可以登录AppGallery Connect界面，在"开发与服务 > 云开发（Serverless）> 认证服务"页面中点击"用户"查看默认数据处理位置导入成功的数据。
