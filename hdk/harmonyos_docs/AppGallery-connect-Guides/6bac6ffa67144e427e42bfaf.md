相关参数说明如下表。

|参数|说明|
|:--------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|agcgw|AGC网关信息。 * url：AGC网关域名。 * backurl：AGC网关备用域名。 * websocketurl：云数据库客户端侧网关的webscoket服务地址。 * websocketbackurl：云数据库客户端侧网关的webscoket服务备用地址。|
|agcgw_all|各站点对应的域名。 * CN：中国站点域名。 * CN_back：中国站点备用域名。 * DE：德国站点域名。 * DE_back：德国站点备用域名。 * RU：俄罗斯站点域名。 * RU_back：俄罗斯站点备用域名。 * SG：新加坡站点域名。 * SG_back：新加坡站点备用域名。|
|oauth_client|基于OAuth 2.0协议的客户端认证信息。 * client_id：当前项目的客户端ID。 * client_type：客户端类型。|
|app_info|当前应用的应用ID和应用包名。 * app_id：当前应用的应用ID。 * package_name：当前应用的应用包名。|
|client|当前项目下的项目信息和当前应用信息。 * cp_id：开发者的商户ID。 * product_id：当前项目的项目ID，后续将废弃，使用**project_id**替代。 * client_id：当前项目的客户端ID，客户端在向AGC服务端进行认证授权时使用。 * client_secret：当前项目的客户端密钥。 * project_id：当前项目的项目ID。 * app_id：当前应用的应用ID。 * api_key：当前应用的API Key，开发者服务端和华为服务端认证授权时使用。 * package_name：当前应用的应用包名。|
|service|各服务需要使用的配置参数，服务未开通时将不会生成。|
|region|默认数据处理位置。 * CN：中国站点 * DE：德国站点 * RU：俄罗斯站点 * SG：新加坡站点。|
|configuration_version|配置文件的版本号。|
|appInfos|当前项目下所有应用的应用信息。 * package_name：应用包名。 * app_id：应用ID。 * oauth_client：基于OAuth 2.0协议的的客户端认证信息。|

## 如何判断正确集成了agconnect-services.json文件？

【Android应用】

使用Android Studio打开apk文件，查看resources.arsc下的string字段，查看是否已经包含agc前缀，如果没有，则表示没有成功集成agconnect-services.json文件。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/47/v3/NP0s9sTrRVegXXf2f5LBTg/zh-cn_image_0000001247750204.png?HW-CC-KV=V1&HW-CC-Date=20260909T142559Z&HW-CC-Expire=31536000000&HW-CC-Sign=C5D24BC883989E8D31997955E186A694F32321D05FA6347DF9D406F83757AF8D)

【iOS应用】

打开应用包，检查Payload\*XXXX*.app目录下是否有 agcp-agconnect-services.json文件，如果没有，则表示没有成功集成agconnect-services.json文件。

【HarmonyOS应用】

打开应用包，检查assets\entry\resources\rawfile目录下是否有 agcp-agconnect-services.json文件，如果没有，则表示没有成功集成agconnect-services.json文件。

## 在Android Gradle Plugin 8.0版本集成agcp插件出现"API 'android.registerTransform'is removed"错误，如何处理？

出现"API 'android.registerTransform'is removed"错误提示，是因为您当前agcp插件版本还未兼容gradle 8.0。

* 方案一：请将插件升级到1.9.1.300版本及以上。
* 方案二：如选择不升级，可通过如下方式规避问题： 在项目根目录下的gradle.properties添加如下命令：

  ```screen
  apmsInstrumentationEnabled=false
  ```

## AGC插件编译报错"> ERROR: no manifest file found"，如何处理？

* 方案一：如果您的AGC插件版本号低于1.2.1.301，请升级到最新版本。
* 方案二：关闭AGC插件对manifest的依赖。 在应用级build.gradle文件末尾添加如下配置：

  ```screen
  agcp{ 
     manifest false 
   }
  ```

## 为什么打开应用时崩溃，日志中提示"url is null"？

可能原因是应用的数据处理位置未设置，请参考[设置数据处理位置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-data-storage-location-0000001162597847)配置。

## 为什么打开应用时崩溃，日志中提示"toCharArray()"？

1. 检查agconnect-services.json文件放置的目录是否准确。
2. 检查build.gradle文件的如下两个引用是否已经配置。 项目级build.gradle文件：classpath 'com.huawei.agconnect:agcp:1.2.0.300'

   应用级build.gradle文件：apply plugin: 'com.huawei.agconnect'

## build.gradle编译报错："com.huawei.agconnect" not found，如何处理？

检查项目级build.gradle中，是否正确添加maven仓的相关配置和AGC插件地址，具体参见[Android使用入门](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-get-started-android-0000001058210705#ZH-CN_TOPIC_0000001058750970__p1494513044011)。

## 为什么按照文档配置多渠道配置时，无法读取到相应渠道文件夹下的agconnect-services.json文件？

请检查在配置渠道名字的时候是否首字母大写了，安卓官方不允许渠道名首字母大写。

## 创建项目时，提示"您所在团队创建的项目已经达到上限，请清理不需要的项目。项目操作删除后一个月才能彻底删除相关的数据和资源，在此之前该项目仍然算在项目总数中"，如何处理？

出现此提示，表示团队创建的项目数超过了300个。

建议您先删除不需要的项目：在"开发与服务"页面点击希望删除的项目，进入"项目设置 > 常规"，点击页面底部的"删除项目"。

当前所有类别的应用数总计不得超过300个，其中HarmonyOS应用+元服务+Windows应用总计不得超过150个，Android应用+快应用+iOS应用+Web应用总计不得超过150个。

## AGC SDK基础包多大，对应用最后出包的大小有什么影响？

当前AGC SDK的基础包约为600多KB，其中包含了400KB左右的Okhttp包。该包是网络请求必要的包，如果应用已存在Okhttp包，那在打包后就不会再打入一个Okhttp的包，所以应用新增的大小只有200KB左右。但要注意的是，AGC SDK使用的是Okhttp3，其他版本可能会出现兼容问题。

如果您需要显式将AGC SDK中的Okhttp包剔除，可以使用exclude的方式，以认证服务为例：

```screen
implementation ('com.huawei.agconnect:agconnect-auth:1.4.2.301') {
   exclude group:'com.squareup.okhttp3', module:'okhttp'
}
```

这样就不会将认证服务SDK中的Okhttp打入应用包中。

## 为满足监管要求，集成SDK后要求用户在未同意访问网络前不能发送任何网络请求，如何处理？

AGC SDK在1.5.0.300版本提供了设置能否发送网络请求的能力，您可以按如下步骤实现。

1. 在AndroidMainifest.xml的Application中增加如下meta-data配置，value配置为false，表示不发送网络请求。

   ```screen
   <meta-data
   android:name="com.huawei.agconnect.AccessNetwork"
   android:value="false"/>
   ```

2. 在用户同意访问网络后调用AccessNetworkManager.setAccessNetwork接口打开网络发送请求开关。

   ```screen
   AccessNetworkManager.getInstance().setAccessNetwork(true);
   ```

## 为保护client_id和client_secret安全地放置到自己的云端服务器，需要如何处理？

如果您认为client_id和client_secret放在json文件里不安全，我们建议您将client_id和client_secret放在自己的服务端。先调用https://connect-drcn.dbankcloud.cn/agc/apigw/oauth2/v1/token接口去换取Token，然后在初始化AGC SDK时通过setCustomCredentialsProvider将Token传给AGC去使用。

Token接口请求示例：

```screen
POST /agc/apigw/oauth2/v1/token
Host: connect-drcn.dbankcloud.cn
Content-Type: application/json
{
   "grant_type":"client_credentials",
   "client_id":"agc应用页面提供的client_id",
   "client_secret":"agc应用页面提供的client_secret",
   "useJwt":1,
}
```

Token接口响应示例：

```screen
HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8
{
    "access_token": "eyJhbGciOiJIUzU****************",
    "expires_in": 0
}
```

setCustomCredentialsProvider接口：

* Android请使用[public AGConnectOptionsBuilder setCustomCredentialProvider(final CustomCredentialsProvider provider)](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agccore-agconnectoptionsbulider-0000001116227891#section9602114520710)方法。

  ```screen
  "Java"
  String tokenStr = "access_token";
  long expiration = expires_in ;

  CustomCredentialsProvider developerClientToken = new CustomCredentialsProvider() {
      @Override
      public Task<Token> getTokens(boolean forceRefresh) {
          TaskCompletionSource<Token> source = new TaskCompletionSource<>();
          Token token;
              token = new Token() {
                  @Override
                  public long getExpiration() {
                      return expiration;
                  }

                  @Override
                  public long getIssuedAt() {
                      return 0;
                  }

                  @Override
                  public long getNotBefore() {
                      return 0;
                  }

                  @Override
                  public String getTokenString() {
                      return tokenStr;
                  }
              };
          source.setResult(token);
          return source.getTask();
      }
  };

  AGConnectOptionsBuilder builder = new AGConnectOptionsBuilder();
  builder.setCustomCredentialsProvider(developerClientToken);
  AGConnectInstance.initialize(getApplicationContext(),builder);
  ```

  ```screen
  "Kotlin"
  val tokenStr = "access_token"
  val expiration: Long = expires_in

  val developerClientToken = CustomCredentialsProvider {
      val source = TaskCompletionSource<Token>()
      val token: Token

          }

              return 0
          }

          override fun getNotBefore(): Long {
              return 0
          }

          override fun getTokenString(): String {
              return tokenStr
          }

      source.setResult(token)
      source.task
  }
  val builder = AGConnectOptionsBuilder()
  builder.setCustomCredentialProvider(developerClientToken)

  ```

* iOS请使用[- (void)setCustomCredentialsProvider:(void (^)(HMFTaskCompletionSource<AGCToken *> *source,BOOL isForceRefresh))credentialsProvider](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agccore-ios-agcservicesconfig-0000001098896302#section2065310480913)方法。

  ```screen

   NSString *token = @"access_token";
  ```

## 应用要求的minSdkVersion低于AGC SDK支持的最低版本，如何处理？

当前AGC SDK最低支持的Android API Level为18，已经可以满足绝大部分开发者的适配需求，如需适配更低版本，您可以按如下步骤实现。

1. 打开AndroidManifest.xml文件，在外层标签中添加<uses-sdk tools:overrideLibrary="xxx.xxx.xxx"/>，其中的xxx.xxx.xxx为需要集成的服务SDK对应的包名，如果存在多个服务的SDK需要适配，则使用英文逗号分隔。
2. 以认证服务和云函数服务为例，相应的标签配置如下：

   ```screen
   <uses-sdk tools:overrideLibrary="com.huawei.agconnect.auth, com.huawei.agconnect.function" />
   ```
