# 快速开通

1. 实名认证：

   进入[联盟官网](https://developer.huawei.com/consumer/cn/agconnect/)，注册个人账号，登录后进行实名认证。
   * 个人开发者：[个人开发者实名认证](https://developer.huawei.com/consumer/cn/doc/start/idrna-0000001062788077)，推荐使用[人脸识别认证](https://developer.huawei.com/consumer/cn/doc/start/facial-0000001271652446)，更高效便捷。
   * 企业开发者：[企业开发者实名认证](https://developer.huawei.com/consumer/cn/doc/start/edrna-0000001062678489)，推荐使用[对公银行打款认证](https://developer.huawei.com/consumer/cn/doc/start/atpopb-0000001062836624)，更高效便捷。


2. 新建项目： 进入[APPGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)，点击 "开发与服务"，进入[开发与服务](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/myProject)页，点击"添加项目"，创建的项目名称可自定义，如"AI问答联网增强服务"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f3/v3/qqkCWPURRbu-iColo67hYg/zh-cn_image_0000002581652059.png?HW-CC-KV=V1&HW-CC-Date=20260909T161926Z&HW-CC-Expire=31536000000&HW-CC-Sign=0678BF8DE783969AA56CBF47244AA05CE938F89F311E840716B1158B47611EB4 "点击放大")


3. API开通：

   进入[开发与服务](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/myProject)页面，点击已创建的项目，在"API管理"页，打开开关。开关首次打开，弹出协议弹窗，勾选协议后，点击"我同意"，即可打开AI问答联网增强服务开关。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a6/v3/XlF3THDVT0ygEUhCz-mdQQ/zh-cn_image_0000002551128230.png?HW-CC-KV=V1&HW-CC-Date=20260909T161926Z&HW-CC-Expire=31536000000&HW-CC-Sign=AF0C0952EBB34B5C1C044D7EB9F384D4109E979693973CF0048EF5FE3F32F105 "点击放大") ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d8/v3/alNjo7qwTwygyB-Pt1sShQ/zh-cn_image_0000002581445463.png?HW-CC-KV=V1&HW-CC-Date=20260909T161926Z&HW-CC-Expire=31536000000&HW-CC-Sign=5DD9FAAF08CB9FFD207D27FEE038DDE49D9B48FCC8BCFCE7FEC53A806404487D "点击放大")

   注：如若界面无"API管理"页签，仅有"开放能力管理"页签，参见FAQ[如果开发与服务界面无"API管理"页签，怎么处理？](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-ainetworking-faq-0000002580235719#section134354432465)


4. 发票信息填写：

   进入[付费服务](https://developer.huawei.com/consumer/cn/console/setting/modPayService)页，填写发票抬头相关信息。此步骤必填，否则影响下一步[开通套餐](#ZH-CN_TOPIC_0000002370503878__li4474155124211)操作。
   * 针对个人开发者：需填写个人发票信息，即姓名、电话、联系人、接收邮箱，同时勾选同意协议，并点击"提交"即可。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/34/v3/6WhYDnoKQeCzUWq8M22xJg/zh-cn_image_0000002547569310.png?HW-CC-KV=V1&HW-CC-Date=20260909T161926Z&HW-CC-Expire=31536000000&HW-CC-Sign=ABA514DCB38880B82CC89279247CFA30A9846C7C432101E2033BDD89564CC55C "点击放大")

   * 针对企业开发者：需填写企业发票信息和邮寄信息，详细操作流程参见[企业开发者开通付费服务指南](https://developer.huawei.com/consumer/cn/doc/start/payment-service-0000001052865979#section19721645141810)。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/47/v3/X9FI2OAXRyuvyq37lsJ1Jg/zh-cn_image_0000002547409682.png?HW-CC-KV=V1&HW-CC-Date=20260909T161926Z&HW-CC-Expire=31536000000&HW-CC-Sign=17FEB3020809D47ADACE919AE328C3C80E493C769D7BBEE405CDA0467DA816EF "点击放大")
5. 开通套餐：

   进入[开发与服务](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/myProject)页，点击已创建的项目，点击 "项目套餐" -> "升级到付费档"，即可开通 AI问答联网增强服务成功。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/94/v3/8ux_QdInRqm2zVrpNfyMSA/zh-cn_image_0000002550888072.png?HW-CC-KV=V1&HW-CC-Date=20260909T161926Z&HW-CC-Expire=31536000000&HW-CC-Sign=3B5700BF90282066C8422B99AE8C7952D938D36A066C7D7015F922869AE8824C "点击放大")

   个人/企业开发者首次开通后，即送100元优惠券。点击 右上角个人账户->"已购服务"->"优惠券" 即可快速查询优惠券金额及其有效期。如若优惠券或账户余额耗尽，可参见[充值付费](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-ainetworking-payment-0000002578177451)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6d/v3/EuEuDFJsQOaMOz7xXC2OSw/zh-cn_image_0000002632649138.png?HW-CC-KV=V1&HW-CC-Date=20260909T161926Z&HW-CC-Expire=31536000000&HW-CC-Sign=FD6B362DC54A4C5DF4785D09E4B12D6DE11D4173DED66D658F30D05C2B290DAF "点击放大")
6. 创建API密钥：

   API密钥可自动创建：在完成 [3.API开通](#ZH-CN_TOPIC_0000002370503878__li189184772911) 时，自动生成有效的 API密钥。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f/v3/x18DFvw0SpOPR9H8K1f4iA/zh-cn_image_0000002630960106.png?HW-CC-KV=V1&HW-CC-Date=20260909T161926Z&HW-CC-Expire=31536000000&HW-CC-Sign=FE0457CF2570D0B0C93C627318D33821EE704DB8BFBE71FC116543BFFAE592A9 "点击放大")
7. 调用API服务： 方式一：常规API调用

   （1）通过公网域名，调用API接口，具体操作可参看[API参考](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agc-ainetworking-apidescription-0000002309899345)中对应接口调用文档，如[中文网页服务接口调用](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agc-ainetworking-interfaceinvoking_webpage-0000002312954296)，[中文网页&新闻&工具类垂域box服务接口调用](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agc-ainetworking-interfaceinvoking_boxes-0000002346793437)、[多语言网页服务接口调用](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agc-ainetworking-interfaceinvoking_multilng-0000002446578565)。

   方式二：API skill调用（OpenClaw同类环境调用）

   （1）下载API skill安装包：点击下载并解压xiaoyi-web-access-skill安装包。

   [xiaoyi-web-access-service.zip](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260701102420.43370119960569964814711470850626:50001231000000:2800:82C00B0CF4A538E9E30BD4997EE42EDD71086F2D374251150505C2FB9264BAB9.zip?needInitFileName=true)

   （2）填写请求url和token：打开scripts -> search.js文件，填写API_URL、X-Api-Key。
   1. API_URL，默认选择"极速版（中文搜索服务）"，更多服务类型参见[AI问答联网增强服务有三种不同套餐服务，请求URL分别是什么？](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-ainetworking-faq-0000002580235719#section105081746104318)
   2. X-Api-Key，填写API密钥，参见 [6. 创建API密钥](#ZH-CN_TOPIC_0000002370503878__li2618843183212)。

   （3）快速安装：
   * 方式一：将[（2）](#ZH-CN_TOPIC_0000002370503878__p144122573515)修改后的文件包，全部放在 cd /root/.openclaw/workspace/skills 路径下即可。（推荐方式）


   * 方式二：将[（2）](#ZH-CN_TOPIC_0000002370503878__p144122573515)修改后的文件打包，发给大模型，输入指令"帮我安装一下xiaoyi-web-access-skill"。
