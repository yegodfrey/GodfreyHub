|序号|任务|说明|
|:-|:---------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[创建项目](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-createprojectandapp-0000001275170098#section1264513378315)|项目是您在AppGallery Connect（以下简称AGC）资源的组织实体。当您需要使用云存储服务时，您需要先在AGC中创建您的项目。 说明： 您可以通过创建不同的项目，实现分别在测试环境和开发环境使用云存储。|
|2|[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)|-|
|3|[下载项目级认证凭据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-download-credentials-0000001334262141)|获取项目级认证凭据，供后续初始化SDK时使用。|
|4|[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-sdk-java-0000001115496716)|将云存储Java Server SDK集成到您的开发环境。|
|5|[初始化存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-initialize-bucket-java-0000001282104682)|在使用云存储功能前，需初始化存储实例。|
|6|管理存储实例与文件|通过调用云存储Java Server SDK的API，您可以： * 进行[存储实例管理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-instance-management-java-0000001161976513)，如新增、删除、列举存储实例。 * [设置跨域的相关配置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-configuring-cors-java-0000001115496720)，以在不同的站点访问指定的存储实例。 * [创建引用](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-createreference-java-0000001115656616)，通过文件的引用进行[上传文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-upload-java-0000001161896489)、[下载文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-download-java-0000001161976515)、[删除文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-delete-java-0000001115656618)和[文件元数据管理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-metadata-java-0000001161896491)等操作，或者通过创建目录的引用来[获取该目录下的文件列表](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-list-java-0000001115496718)。|
