# （可选）多数据处理位置

通常情况下，为了满足各区域隐私合规或就近处理数据等要求，可以使用不同数据处理位置访问处理不同区域的数据。远程配置SDK从1.6.2.300版本开始支持多数据处理位置。

* 如果您不指定数据处理位置，远程配置服务将使用默认数据处理位置存放和处理数据。
* 如果设置了数据处理位置，远程配置服务将在指定的数据处理位置存放和处理数据。

您可以在AppGallery Connect上[设置数据处理位置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-data-storage-location-0000001162597847)，设置完成后重新[获取agconnect-services.json文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-remoteconfig-obtain-files-0000001332958069#section97064952315)并集成到您的项目中，然后就可在项目中对数据处理位置进行处理：

* [使用默认数据处理位置](#section1910913304262)
* [修改默认数据处理位置](#section8328654182616)
* [使用指定的数据处理位置](#section66216133276)

#### 使用默认数据处理位置

如果您使用默认数据处理位置访问，调用getInstance方法初始化服务实例不传参即可。  

```
"Java"
AGConnectConfig config = AGConnectConfig.getInstance();
```

```
"Kotlin"
val config = AGConnectConfig.getInstance()
```

#### 修改默认数据处理位置

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240903160607.41969151550648607513894089253814:50001231000000:2800:1CBB5E26C18D008B210A530E86EF0C7978C096DA8045CAB845815DE6CAAE5A57.png?needInitFileName=true?needInitFileName=true)  
在AGC上设置的"默认数据处理位置"适用于项目下所有应用，此处修改的"默认数据处理位置"仅对本应用生效，不会影响其他应用。

调用[AGConnectOptionsBuilder.setRoutePolicy](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-agconnectoptionsbulider-0000001116227891#section2014116381502)修改默认数据处理位置，并调用[AGConnectInstance.initialize](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-agconnectinstance-0000001116508851#section9988174911378)初始化配置。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240903160607.95643839103636503192217788625784:50001231000000:2800:CF896FD2068298F6BCCC31B55DBF825D21E843B633A8FF4E275E39C80E090DD9.png?needInitFileName=true?needInitFileName=true)  
建议此接口在Application的onCreate()中调用，数据处理位置及其对应的枚举值详情请参见[AGCRoutePolicy](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-agcroutepolicy-0000001078446340)。  

```
"Java"
// 创建AGConnectOptionsBuilder对象
AGConnectOptionsBuilder builder = new AGConnectOptionsBuilder(); 
// 设置数据处理位置，比如将默认数据处理位置从CHINA修改为GERMANY 
builder.setRoutePolicy(AGCRoutePolicy.GERMANY); 
// 初始化AGC框架
AGConnectInstance.initialize(context, builder); 
```

```
"Kotlin"
// 创建AGConnectOptionsBuilder对象
val builder = AGConnectOptionsBuilder() 
// 设置数据处理位置，比如将默认数据处理位置从CHINA修改为GERMANY 
builder.setRoutePolicy(AGCRoutePolicy.GERMANY) 
// 初始化AGC框架
AGConnectInstance.initialize(context, builder) 
```

#### 使用指定数据处理位置

您还可以通过指定目标数据处理位置，实现不同数据处理位置访问不同区域的数据。

1. 构造[AGConnectOptions](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-agconnectoptions-0000001116446037)对象，指定目标数据处理位置。  

   ```
   "Java"
    AGConnectOptions optionsRussia = new AGConnectOptionsBuilder() 
        .setRoutePolicy(AGCRoutePolicy.RUSSIA) 
        .build(context);
   ```

   ```
   "Kotlin"
    val optionsRussia = AGConnectOptionsBuilder()        
           .setRoutePolicy(AGCRoutePolicy.RUSSIA)         
           .build(context) 
   ```

2. 初始化AGConnectInstance，在buildInstance方法中传入指定的AGConnectOptions对象。

   ```
   AGConnectInstance instanceRussia = AGConnectInstance.buildInstance(optionsRussia);
   ```

3. 传入远程配置的AGConnectInstance实例，创建目标数据处理位置的远程配置服务的实例。  

   ```
   "Java"
   AGConnectConfig configRussia = AGConnectConfig.getInstance(instanceRussia);
   ```

   ```
   "Kotlin"
   val configRussia = AGConnectConfig.getInstance(instanceRussia)
   ```

4. 如果您需要指定访问更多的数据处理位置，请重复以上步骤，指定不同的目标数据处理位置即可。
