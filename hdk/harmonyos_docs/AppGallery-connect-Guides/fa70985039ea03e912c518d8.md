# 创建引用

文件存储在云端的存储实例中，存储方式与本地硬盘中的文件系统类似。您可以通过文件的引用进行上传文件、下载文件、删除文件、更新文件元数据等操作，也可以通过创建目录的引用来获取该目录下的文件列表。  

#### 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[初始化存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-initialize-bucket-ios-0000001333893477)。  

#### 操作步骤

* 如果您需要创建根目录的引用，可以调用[\[AGCStorage reference\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstorage-0000001172981557#section939311202814)方法。  

  ```
  "Objective-C"
  //storage为已经初始化的AGCStorage实例
  AGCStorageReference *reference = [storage reference];
  ```

  ```
  "Swift"
  //storage为已经初始化的AGCStorage实例
  let reference = storage.reference()
  ```

<!-- -->

* 如果您需要创建云端指定文件或目录的引用，可以调用[\[AGCStorage referenceWithPath:\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstorage-0000001172981557#section9635163510919)方法。  

  ```
  "Objective-C"
  //storage为已经初始化的AGCStorage实例
  AGCStorageReference *reference = [AGCStorage referenceWithPath:@"images/demo.jpg"];
  ```

  ```
  "Swift"
  //storage为已经初始化的AGCStorage实例
  let reference = storage.reference(withPath:"images/demo.jpg")
  ```

<!-- -->

* 如果您需要指定文件上传或下载的区域，可以调用[\[AGCStorage referenceFromUrl:\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstorage-0000001172981557#section8808112816811)方法。  

  ```
  "Objective-C"
  //storage为已经初始化的AGCStorage实例
  AGCStorageReference *storageReference = [storage referenceFromUrl: storageUrl];
  ```

  ```
  "Swift"
  //storage为已经初始化的AGCStorage实例
  let storageReference = storage.reference(from:storageUrl)
  ```

#### 更多信息

创建引用后，您可以调用[AGCStorageReference](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragereference-0000001126781968)实例的相关方法对引用进行相关操作：

* 在当前文件层次结构中向上向下导航，例如调用[child:](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragereference-0000001126781968#section1738752918192)获取子目录引用，调用[parent](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragereference-0000001126781968#section189593402216)获取父目录引用，调用[root](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragereference-0000001126781968#section17763712237)获取根目录引用。
* 获取当前引用的相关信息，例如调用[bucketName](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragereference-0000001126781968#ZH-CN_TOPIC_0000001126781968__p1998415493018)获取文件所在存储实例名称，调用[name](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragereference-0000001126781968#ZH-CN_TOPIC_0000001126781968__p898575419304)获取当前引用的文件或目录名称，调用[path](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragereference-0000001126781968#ZH-CN_TOPIC_0000001126781968__p1298425410306)获取文件在云端的存储路径。
* 对文件进行[上传](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-upload-ios-0000001172981227)、[下载](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-download-ios-0000001126781636)、[删除](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-delete-ios-0000001172821309)和[元数据管理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-metadata-ios-0000001172981229)等操作。
