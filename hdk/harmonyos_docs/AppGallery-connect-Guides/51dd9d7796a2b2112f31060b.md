# 文件管理

> 说明
>
> 当前文件管理功能仅支持深圳区域的所有手机真机设备。

云调试服务支持查看调试设备sdcard目录下文件夹及文件，并且可以将文件保存到本地，帮助用户定位问题。

## 前提条件

在进行文件管理的相关操作时，必须先成功[申请调试设备](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddebug-debugequip-0000001122212029#section11242145501420)。

## 操作步骤

1. 调试设备申请成功后，进入调试页面，点击"文件管理"页签，您可以在页签下查看调试设备sdcard目录下文件夹及文件。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/65/v3/y0AgV5cpTISg1j_xj4ogbA/zh-cn_image_0000002532331168.png?HW-CC-KV=V1&HW-CC-Date=20261008T154045Z&HW-CC-Expire=31536000000&HW-CC-Sign=54D21BBA9A7F32395456BE792840EDC67D34D46A26A1F68E7C2394FFBAEC5216)

2. 进入文件夹后点击需要保存到本地的文件，即可保存到本地。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/40/v3/24SwRwrZScS84_nMSD7Low/zh-cn_image_0000002147685356.png?HW-CC-KV=V1&HW-CC-Date=20261008T154045Z&HW-CC-Expire=31536000000&HW-CC-Sign=ACE21F9BCEEF4AA4CDCC7C627C6688CECAAEABA85A6347EB57610FD4B99B21A0)

3. 文件管理还支持在路径输入框中输入正确路径 ，输入后点击搜索，即可跳转到指定路径。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6/v3/vb5eAkR5SCC4Bd514c0UGQ/zh-cn_image_0000002147844536.png?HW-CC-KV=V1&HW-CC-Date=20261008T154045Z&HW-CC-Expire=31536000000&HW-CC-Sign=16A35F0B09D2A3DA78A440ADCC311161CA0A628385C5CD170C93F978336E9370)
