# 文件管理

![](https://media:201778318765696403)  
当前文件管理功能仅支持深圳区域的所有手机真机设备。

云调试服务支持查看调试设备sdcard目录下文件夹及文件，并且可以将文件保存到本地，帮助用户定位问题。  

#### 前提条件

在进行文件管理的相关操作时，必须先成功[申请调试设备](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddebug-debugequip-0000001122212029#section11242145501420)。  

#### 操作步骤

1. 调试设备申请成功后，进入调试页面，点击"文件管理"页签，您可以在页签下查看调试设备sdcard目录下文件夹及文件。 ![](https://media:201778318765744404)

2. 进入文件夹后点击需要保存到本地的文件，即可保存到本地。 ![](https://media:201778318765801405)

3. 文件管理还支持在路径输入框中输入正确路径 ，输入后点击搜索，即可跳转到指定路径。 ![](https://media:201778318765846406)
