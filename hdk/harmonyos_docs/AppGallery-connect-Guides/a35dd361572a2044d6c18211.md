# 日志回捞

为方便开发者根据详细的客户端运行日志进行问题定位分析，我们提供了自定义日志功能，最大2MB。所记录的日志内容记录在本地，当开发者需要查看此日志内容时，可以在AGC控制台创建日志回捞任务，获取指定用户终端上的日志进行查看分析。

## 前提条件

* 您的应用已[启用APM服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-android-getstarted-0000001052887262#section222119255410)。
* 您的应用已[开通远程配置服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-remoteconfig-enable-service-0000001276051134)。
* 您的应用已[集成APM SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-android-getstarted-0000001052887262#section194247503211)和[开启APM功能](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-apm-android-getstarted-0000001052887262#section640224332214)，并在设备上运行。

## 接入应用

1. 设置用户标识。

   创建日志回捞任务时需要传入用户标识，以此决定哪些用户可以接收到回捞任务。

   ```screen
   APMS.getInstance().setUserIdentifier(String userIdentifier);
   ```

2. 获取自定义日志ApmsLog实例，并打印日志。

   ```screen
   ApmsLog apmsLog = APMS.getInstance().createApmsLog();
   // verbose
   ApmsLog.v(String tag, String msg);
   // debug
   ApmsLog.d(String tag, String msg);
   // info
   ApmsLog.i(String tag, String msg);
   // warn
   ApmsLog.w(String tag, String msg);
   // error
   ApmsLog.e(String tag, String msg);
   ```

3. 监测回捞任务并获取用户同意。

   APMS SDK提供拉取任务信息的[fetch](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/apmslog-0000001282058148#section17826164517200)接口，应用可以根据业务需要自定义调用时机，接收到回捞任务后SDK会通过回调[onReceiveTask](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/fetchcallback-0000001282762594#section1277143703917)通知到应用。

   ```screen
   ApmsLog.fetch(FetchTask.FetchCallback callback);
   FetchTask.FetchCallback {
       void onReceiveTask(TaskInfo taskInfo); 
   }
   ```

   应用可以根据获取到的任务信息提示用户，请求用户同意执行回捞任务。
   * 如同意执行任务，则调用SDK [grant](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/apmslog-0000001282058148#section41355535235)接口。

     ```screen
     ApmsLog.grant();
     ```


   * 如拒绝此次执行任务，则调用SDK [deny](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/apmslog-0000001282058148#section1013713792411)接口。

     ```screen
     ApmsLog.deny();
     ```

   无论是否同意，此任务仅会通知一次。
4. 应用退到后台时建议调用[flush](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/apmslog-0000001282058148#section6463192491616)日志刷新接口。如没有调用，将会发生部分日志在应用下次重启时再次写入本地文件的情况。

   ```screen
   ApmsLog.flush();
   ```

## 创建日志回捞任务

获取指定用户的日志信息，需要通过创建回捞任务实现。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择需要查看日志的应用。
3. 在左侧导航栏选择"质量 > 性能管理"，进入"应用性能管理"页面。
4. 选择"日志回捞"页签，进入日志回捞页面，点击"创建任务"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251125162007.40478851427953338097912112263842:50001231000000:2800:DD0C1FC61C9A53F1C550D90183D4C9239893656F307834F58205DBEFEE79A917.png)

5. 在创建任务界面，填写任务名称、任务描述、拉取日志的时间范围，以及用户标识。

   |参数|说明|
   |:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |任务名称|String类型，限长100个字符，仅支持中文、字母、下划线和数字。|
   |任务描述|String类型，限长255个字符，仅支持中文、字母、下划线和数字。|
   |拉取时间范围|格式为yyyy-MM-dd HH:mm:ss - yyyy-MM-dd HH:mm:ss，最长时间跨度为7天。|
   |用户标识|最多支持20个用户，以逗号分隔。 > 注意 > 需要与应用中调用SDK接口[APMS.getInstance().setUserIdentifier(String userIdentifier)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/apms-0000001052488219#section99791215181716)时传入的参数值一致。|

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251125162007.20787959986790945288193300522552:50001231000000:2800:13D174A4A3528FBD8C2BEE98DDF82E048230EE4D80E9BC69268380FC363EC9DC.png)
6. 配置完成后点击"确定"，您已创建的回捞任务将展示在任务列表中。

   |参数|说明|
   |:---|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |任务状态|任务的当前状态。取值： * 已创建：创建任务且任务信息入库但是AGC控制台还未下发远程配置。 * 进行中：AGC控制台下发远程配置成功后。 * 已完成：任务中定义的所有用户都已上报数据。 * 已失效：任务创建时间超过7天。 * 已失败：AGC控制台下发远程配置失败。 * 已终止：任务创建人终止任务，不再收集用户日志。|
   |任务进度|以"已上报日志用户数/已拒绝用户数/任务用户总数"形式展示。|

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251125162007.20813047375250066707748648669075:50001231000000:2800:DB7877E1D54AE49778F94368D10FC2E4721062625ED0B4BF204FE51CD6F58FAA.png)
7. 如用户在日志回捞范围内，则接收到是否同意上传日志的授权询问信息，如下图所示。
   * 如同意共享系统日志信息，点击"同意"。后续您可以在任务列表点击对应任务右侧"操作"列的"查看详情"，查看获取的自定义日志。
   * 如不同意共享系统日志信息，点击"拒绝"。后续不会再收到询问信息。 说明
     >
     > 每个回捞任务的授权询问，在用户侧仅展示一次，拒绝后不再展示（除非创建新的回捞任务）。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251125162007.65492226703475180766084228799812:50001231000000:2800:3F37A0266537F831A2F1D4E31B90E9C92748491063081FEA21A8690692215BEB.png)

## 查看任务详情

创建任务后，可以在任务列表点击该任务右侧"操作"列的"查看详情"，进入"任务详情"页面查看详细的日志信息。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251125162007.59467617331872373652172035222061:50001231000000:2800:F596852863439D368C9D15222ED3AF4F39D2F5D4E758AA5ABF5ECBEA1D695F0B.png)

任务详情页面分为"任务信息"和"日志信息"两个区域展示。

* 任务信息：展示任务的名称、进度、拉取时间范围等概要信息。


* 日志信息：展示获取到的自定义日志的具体信息。
  * 如果拉取到多个用户日志，可以通过"用户标识"下拉框来切换用户，以查看不同用户的日志信息。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251125162007.85886053557426259638241452171309:50001231000000:2800:E317033BDFC1B26850091793852882F2A36827415D78FCCDE694028CC3E057DE.png)

  * 具体的日志信息，可以在线查看，也可以点击"下载日志文件"下载以"用户标识+日志文件名"命名的日志文件到本地查看。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251125162007.35353786101798374348886532706447:50001231000000:2800:56FA52C5206A0045805378890921B297CD31B40025D8DC5B3D1ECFCCAFDF3B5A.png)

  * 支持通过"时间"、"级别"和"关键字"对日志进行过滤搜索。 说明
    >
    > 其中"关键字"过滤项，支持输入"日志标识"或者"日志内容"进行模糊搜索。
