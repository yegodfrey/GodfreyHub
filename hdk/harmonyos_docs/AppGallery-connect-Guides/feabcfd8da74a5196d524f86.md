# 销户

#### 前提条件

* 您需要在AGC控制台[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-web-integration-sdk-0000001276332208)。  

#### 开发步骤

<br />

当用户不再使用应用，可以注销当前用户。您需要调用[AGCAuth.deleteUser](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section13266162513559)实现该功能，用户一旦被注销，将会删除服务端侧的用户信息同时清空客户端侧用户信息和Token。

```
agconnect.auth().deleteUser();
```

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114607.03770514998163340408201389670652:50001231000000:2800:64465C2A04F00577B5D50CB035F99E6289CAA3F1748531DDC751602450E95AE5.png)  
对于销户操作，要求用户必须在5分钟内登录过才能执行。若已超时，请参见[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-web-reauthenticate-0000001159181885)先完成重认证。
