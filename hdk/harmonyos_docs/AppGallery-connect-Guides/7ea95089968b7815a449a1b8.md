# 打包配置（C#）

集成游戏联机对战C# SDK进行代码开发后，如果帧同步过程中使用UDP协议，您需要在游戏引擎导出的Android Studio工程（UDP协议当前仅支持Android平台下arm64-v8a架构）中进行如下配置。

1. 将SDK中"Plugins > Android > libs"路径下的aar包，拷贝到已导出的Android Studio工程xxxxxLibrary/libs中。如已自动添加，可跳过此步骤。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250813135415.77817772974274835419521790500718:50001231000000:2800:A29BC329293455E50F4EC62E10AADAAB0D0D58E5E485A29C686B0C354C25A3F5.png)

2. 在工程的"xxxxxLibray > build.gradle > dependencies"中，添加如下依赖。如已自动添加，可跳过此步骤。

   ```screen
   // 添加NetworkKit依赖
   implementation(name: 'cronet-api-90.0.4430.82-h0.CBGCloud.WiseCloudPanshi.NetworkKit.r290', ext:'aar')
   implementation(name: 'cronet-common-90.0.4430.82-h0.CBGCloud.WiseCloudPanshi.NetworkKit.r290', ext:'aar')
   implementation(name: 'cronet-embedded-90.0.4430.82-h0.CBGCloud.WiseCloudPanshi.NetworkKit.r290', ext:'aar')
   ```

3. 在工程的"xxxxxLibray > src > main > jniLibs > arm64-v8a"中，添加libc++_shared.so动态库。 说明
   >
   > libc++_shared.so文件可以在NDK的安装目录（例如{NDK_HOME}/sources/cxx-stl/llvm-libc++/libs/arm64-v8a/libc++_shared.so）下查找。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250813135416.15810409628142442596096961491596:50001231000000:2800:78B91AD302CC35645A0490D14A3F8A8D3B4C41D629E3F0C59B6D7C63634B116C.png)
4. 在XxxxxPlayerActivity.java中添加如下代码。

   ```screen
   static {
       System.loadLibrary("network-common");
       System.loadLibrary("network-hwhttp");
       System.loadLibrary("sparkrtc-rtsa");
   }
   ```
