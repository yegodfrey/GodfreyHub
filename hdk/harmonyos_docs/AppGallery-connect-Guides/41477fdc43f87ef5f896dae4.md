# （可选）多数据处理位置

通常情况下，为了满足各区域隐私合规或就近处理数据等要求，可以使用不同数据处理位置访问处理不同区域的数据。

您可以在AppGallery Connect上[设置数据处理位置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-data-storage-location-0000001162597847)，设置完成后重新[获取agconnect-services.json](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-appmessaging-obtain-files-0000001322296744#section1791241912377)文件并集成到您的项目中，就可在应用中[使用默认数据处理位置](#section19127755134518)存放和处理数据，当然您还可以在应用中[修改默认数据处理位置](#section1462434364514)，使该应用使用不同的数据处理位置。

## 使用默认数据处理位置

调用getInstance方法初始化服务实例不传参即可。

```screen
"Java"
AGConnectAppmessaging appmessaging = AGConnectAppmessaging.getInstance();
```

```screen
"Kotlin"
val appmessaging = AGConnectAppmessaging.getInstance()
```

## 修改默认数据处理位置

> 注意
>
> 在AGC上设置的"默认数据处理位置"适用于项目下所有应用，此处修改的"默认数据处理位置"仅对本应用生效，不会影响其他应用。

调用[AGConnectOptionsBuilder.setRoutePolicy](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-agconnectoptionsbulider-0000001116227891#section2014116381502)修改默认数据处理位置，并调用[AGConnectInstance.initialize](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-agconnectinstance-0000001116508851#section9988174911378)初始化配置。
> 说明
>
> 建议此接口在Application的onCreate()中调用，数据处理位置及其对应的枚举值详情请参见[AGCRoutePolicy](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-agcroutepolicy-0000001078446340)。

```screen
"Java"
// 创建AGConnectOptionsBuilder对象
AGConnectOptionsBuilder builder = new AGConnectOptionsBuilder(); 
// 设置数据处理位置，比如将默认数据处理位置从CHINA修改为GERMANY 
builder.setRoutePolicy(AGCRoutePolicy.GERMANY); 
// 初始化AGC框架
AGConnectInstance.initialize(context, builder); 
```

```screen
"Kotlin"
// 创建AGConnectOptionsBuilder对象
val builder = AGConnectOptionsBuilder() 
// 设置数据处理位置，比如将默认数据处理位置从CHINA修改为GERMANY 
builder.setRoutePolicy(AGCRoutePolicy.GERMANY) 
// 初始化AGC框架
AGConnectInstance.initialize(context, builder) 
```
