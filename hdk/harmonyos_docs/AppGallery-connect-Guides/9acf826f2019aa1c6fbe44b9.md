# 自定义玩家属性

游戏多媒体实时信令功能支持设置频道内玩家自定义属性，例如状态、位置、心情等。同时，还支持监听频道内其他玩家属性的变更，及时感知频道内其他玩家属性的修改。

## 前提条件

* 您已[集成游戏多媒体基础SDK和实时信令模块](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-integratingsdk-android-0000001250838246#ZH-CN_TOPIC_0000001250838246__li733912204487)。
* 您已[创建游戏多媒体实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-engine-android-0000001193958984#section1093713161034)。
* 您已[订阅频道](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-channel-subscribe-android-0000001744760273#section1014421318306)。

## 设置玩家属性

1. 调用[GameMediaEngine.setRtmChannelPlayerProperties](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section1248173165919)方法，设置频道内玩家自定义属性。

   ```screen
   SetRtmChannelPlayerPropertiesReq req = new SetRtmChannelPlayerPropertiesReq();
   req.setChannelId("579457***95");
   Map<String, String> propertyMap = new HashMap<>();
   propertyMap.put("key1", "value1");
   propertyMap.put("key2", "value2");
   req.setPlayerProperties(propertyMap);
   mHwRtcEngine.setRtmChannelPlayerProperties(req);
   ```

2. 在IGameMMEEventHandler接口的[onSetRtmChannelPlayerProperties](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section1312054185812)回调方法中，可以获取玩家自定义属性的设置结果。

   ```screen
   @Override
   public void onSetRtmChannelPlayerProperties(SetRtmChannelPlayerPropertiesResult result) {
     // 可根据需求将数据进行处理
   }
   ```

## 查询玩家属性

1. 调用[GameMediaEngine.getRtmChannelPlayerProperties](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section1985625020593)方法，查询频道内玩家自定义属性。

   ```screen
   GetRtmChannelPlayerPropertiesReq req = new GetRtmChannelPlayerPropertiesReq();
   req.setChannelId("579457***95");
   List<String> openIds = new ArrayList<>();
   openIds.add("id1");
   openIds.add("id2");
   req.setOpenIds(openIds);
   mHwRtcEngine.getRtmChannelPlayerProperties(req);
   ```

2. 在IGameMMEEventHandler接口的[onGetRtmChannelPlayerProperties](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section63313515810)回调方法中，可以获取玩家自定义属性的查询结果。

   ```screen
   @Override
   public void onGetRtmChannelPlayerProperties(GetRtmChannelPlayerPropertiesResult result) {
     // 可根据需求将数据进行处理
   }
   ```

## 删除玩家属性

1. 调用[GameMediaEngine.deleteRtmChannelPlayerProperties](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section588113271107)方法，删除频道内玩家自定义属性。

   ```screen
   DeleteRtmChannelPlayerPropertiesReq req = new DeleteRtmChannelPlayerPropertiesReq();
   req.setChannelId("579457***95");
   List<String> keys = new ArrayList<>();
   keys.add("key1");
   keys.add("key2");
   req.setKeys(keys);
   mHwRtcEngine.deleteRtmChannelPlayerProperties(req);
   ```

2. 在IGameMMEEventHandler接口的[onDeleteRtmChannelPlayerProperties](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section143417612589)回调方法中，可以获取玩家自定义属性的删除结果。

   ```screen
   @Override
   public void onDeleteRtmChannelPlayerProperties(DeleteRtmChannelPlayerPropertiesResult result) {
     // 可根据需求将数据进行处理
   }
   ```

```screen
@Override
public void onRtmChannelPlayerPropertiesChanged(RtmChannelPlayerPropertiesNotify notify) {
  // 可根据需求将数据进行处理
}
```
