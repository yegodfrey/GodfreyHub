# 申请开通

普通渠道包功能为允许清单开通制，需要申请的开发者请联系相关运营或填好申请模板后发送邮件至developer@huawei.com，审核人员评估后会在1-2个工作日内进行答复。

邮件标题：APP名称-申请开通渠道包

邮件内容：

* APP名称：*********
* 应用ID：***********
* 应用分类：***********
* 应用等级：辰星级 / 银级 / 金级 / 铂金级 / 钻石级 / 黑金级
* 邮件内容：xx应用申请在xx月开通普通渠道包，确认已经清晰完整理解华为应用市场渠道包功能申请与使用规范，如不满足，可接受允许清单关闭。

> 说明
>
> * 应用的信息获取可参考[查看应用基本信息](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-appinfo-0000001100014694)。
