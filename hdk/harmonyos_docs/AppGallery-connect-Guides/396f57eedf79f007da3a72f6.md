# 获取非严重异常报告

非严重异常，即被应用捕获的异常，尽管不会导致崩溃，但是往往说明代码可能存在某些问题。AGC提供记录非严重异常的机制，让您可以监控到这些异常，帮助您提高代码质量。

## 前提条件

1. 您需要在AGC控制台[开通崩溃服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-enableservice-0000001326330021)。
2. 您需要先在您的应用中[集成崩溃服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-integratesdk-android-0000001275810158)。

## 记录异常

1. 调用[AGConnectCrash.getInstance()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-android-0000001055420438#section743716146324)获取AGConnectCrash实例。
2. 在catch代码块中调用[AGConnectCrash.getInstance().recordException()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectcrash-android-0000001055420438#section4874171461216)记录您需要捕获的异常。

   ```screen
   "Java"
   try {
   } catch (Exception e) {
       AGConnectCrash.getInstance().recordException(e);
   }
   ```

   ```screen
   "Kotlin"
   try {
   } catch (e: Exception) {
       AGConnectCrash.getInstance().recordException(e)
   }
   ```

> 注意
>
> AGC只会记录一个应用会话中最近的10次异常。如果您的应用在一个会话中抛出的异常数超过10个，则较早的异常会被删除。

## 测试异常

您可以在测试应用时调用崩溃服务SDK的API手动制造一个异常，然后在AGC上查看异常上报情况，以测试报告非严重异常能否正常运行。

```screen
"Java"
try {
    throw new Exception();
} catch (Exception e) {
    AGConnectCrash.getInstance().recordException(e);
}
```

```screen
"Kotlin"
try {
} catch (e: Exception) {
    AGConnectCrash.getInstance().recordException(e)
}
```

## 分析异常

记录的异常会在应用下次启动时上报。您可以通过在AGC控制台添加用户属性及时间过滤条件的方式，选择查看指定时间内所有异常的统计数据。同时，在问题详情页面，您还可以查看分析堆栈、日志、状态等详细信息。

### 查看异常详情

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中点击您的应用。
3. 在左侧导航栏选择"质量 > 崩溃"。
4. 在"添加过滤器"中，选择用户属性的事件类型为"异常"。
5. 在崩溃服务的"统计"页面，您可以通过添加过滤器和设置右上角的时间选择器过滤您的异常数据。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155607.18792705466913249427846843332773:50001231000000:2800:7154AD6B466E1081BC6BCC1F6FD14133AC858898EC5807A94BD3F28F7BBBED86.png)

6. 确认异常已经上报后，您可以选择"问题"，通过设置时间选择器查看指定时间范围内该应用累计发生的非严重异常问题及其次数。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155607.38652483169174111825889523651456:50001231000000:2800:0E175D7726FA4AB93BA787B592C660F2393FA40E28F3972E2B297174D59AA72D.png)
