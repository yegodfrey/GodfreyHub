# 切换房间

玩家处于多房间状态下时，可通过切换语音房间实现进入不同房间发言。
> 说明
>
> 在房间A中，一个玩家无论是否具备发送语音的能力，当该玩家由房间A切换至其他房间后，其在房间A中则仅具备接收语音的能力。当玩家由其他房间切换回房间A后，则其恢复在原房间A中的语音能力。

## 前提条件

您至少已[加入](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-joinroom-roomid-ios-0000001323024589)两个房间。

## 开发步骤

1. 调用[HWPGMEngine.getInstance switchRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section19922513415)方法切换到指定房间。

   ```screen
   HWPGMEngine *pgmeEngine = [HWPGMEngine getInstance];
   [pgmeEngine switchRoom:roomId];
   ```

2. 当玩家切换房间完成时，可在HWPGMEngineDelegate接口的[onSwitchRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section751112615815)方法中实现相关回调处理。

   ```screen
   - (void)onSwitchRoom:(NSString* _Nonnull)roomId code:(int)code msg:(NSString*)msg {
       // 切换房间成功或失败数据处理
   }
   ```
