# 使用数据库的其他操作

## 写入数据

您可以通过**[executeUpsert()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-web-0000001080859822#section17755153212411)**将一个或者一组对象写入到当前存储区中。在写入对象时，如果在存储区已经存在主键值相同的对象，则更新已有的对象；如果不存在，则写入一个新的对象。写入的数据可以来自于新建对象，或者从存储区查询出来的对象。

写入一组对象时，数据的写入操作是原子的，即对象列表中的对象要么全部成功写入，要么全部失败。

调用写入数据方法后，会返回一个**Promise** 对象，对象中封装了写入操作执行的结果。通过该**Promise**对象可以异步侦听执行结果：如果执行成功，可以获取写入的对象数量；如果执行失败，可以获取错误信息。

**注意事项：**
> 注意
>
> 请先关注注意事项。

* 仅当存储区为打开状态时，才可以进行写入对象操作，否则会导致写入失败。
* 写入一组对象时，该组中的对象必须属于同一个对象类型，否则会导致写入失败。
* 写入一组对象时，数据总大小不能超过2MB，否则会导致写入失败。
* 写入一组对象时，数据总条数不能超过1000条，否则会导致写入失败。

**代码示例：**

将**BookInfo**对象写入至存储区中，写入成功后，返回写入的数量；写入失败，抛出异常。

```screen
async function executeUpsert (book) {
	try {
		const cloudDBZoneResult = await cloudDBZone.executeUpsert(book);
		console.log('upsert' + cloudDBZoneResult + 'record' );
		return cloudDBZoneResult;
	} catch (e) {
		console.log(e);
	}
}
```

## 查询数据

云数据库通过**[executeQuery()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-web-0000001080859822#section1894919381041)** 方法查询对象，并提供了丰富的谓词查询，比如**equalTo()、notEqualTo()、in()** 等。通过单个或者多个链式过滤条件，您可以从存储区查询到满足特定条件的对象，也可以通过排序谓词对查询结果排序，或者通过限定查询返回数量谓词限定查询结果返回的数量。详细的查询条件请参见**[CloudDBZoneQuery](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-web-0000001127836521)**。

应用会直接从云侧存储区服务器查询数据，本地不会缓存数据。

根据查询结果返回的**CloudDBZoneSnapshot** 对象获取存放在该对象里的数据，更多请参见**[CloudDBZoneSnapshot](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonesnapshot-web-0000001127719373)**。

**注意事项：**
> 注意
>
> 请先关注注意事项。

* 仅当存储区为打开状态时，才可以进行查询对象操作，否则会导致查询失败。
* 每次的查询操作仅支持查询一个对象类型下的数据。

### 简单查询

您可以在无查询条件时，获取一个对象类型中所有的对象；也可以指定单个查询条件，来获取满足该条件的对象。

* 查询对象类型**BookInfo** 的所有数据。

  ```screen
  async function executeQueryAllBooks() {
      try {
          const query = CloudDBZoneQuery.where(BookInfo);
          const snapshot = await cloudDBZone.executeQuery(query);
          const resultArray = snapshot.getSnapshotObjects();
          console.log(resultArray);
      } catch(e) {
          console.log(e);
      }
  }
  ```

* 通过异步侦听的方式查询"bookName"为"左传"的书籍。
  * 构造查询方法**executeQuery** ，该方法同时供后续查询示例引用。

    ```screen
    async function executeQuery (cloudDBZoneQuery)  {
    	try {
                 const snapshot = await cloudDBZone.executeQuery(cloudDBZoneQuery);
    	     const resultArray = snapshot.getSnapshotObjects();
    	     console.log(resultArray);
    	} catch (e) {
    		console.log(e);
    	}
    }
    ```

  * 构造查询条件，并调用**executeQuery** 方法，获取查询数据。

    ```screen
    const query = CloudDBZoneQuery.where(BookInfo).equalTo('bookName', '左传');
    executeQuery(query);
    ```

### 复合查询

您可以通过多个链式过滤条件，来获取满足条件的对象。多个链式条件之间默认用"与"运算。

* 构造查询条件，并调用**executeQuery** 方法，查询"bookName"包含"数据库"，"price"大于20.0并且小于50.0的书籍。

  ```screen
  const query = CloudDBZoneQuery.where(BookInfo).contains('bookName', '数据库').greaterThan('price', 20.0).and().lessThan('price', 50.0);
  executeQuery(query);
  ```

* 构造查询条件，并调用**executeQuery** 方法，查询"bookName"包含"数据库"，"price"在小于20.0或者大于50.0区间的书籍。

  ```screen
  const query = CloudDBZoneQuery.where(BookInfo).contains('bookName', '数据库').lessThan('price', 20.0).or().greaterThan('price', 50.0);
  executeQuery(query);
  ```

* 构造查询条件，并调用**executeQuery** 方法，查询"bookName"包含"史记"，"author"是"司马迁"，"price"大于60.0的书籍。

  ```screen
  const query = CloudDBZoneQuery.where(BookInfo).contains('bookName', '史记').equalTo('author', '司马迁').greaterThan('price', 60.0);
  executeQuery(query);
  ```

* 构造查询条件，并调用**executeQuery** 方法，查询"bookName"包含"自传"，并且"author"是"齐白石"，或者"author"是"司马迁"，并且"price"大于60.0的书籍。

  ```screen
  const query = CloudDBZoneQuery.where(BookInfo).contains('bookName', '自传').beginGroup().equalTo('author', '齐白石').or().equalTo('author', '司马迁').endGroup().greaterThan('price', 60.0);
  executeQuery(query);
  ```

### 查询数据平均值

您可以通过**[executeAverageQuery()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-web-0000001080859822#section748416563413)**方法查找满足特定条件的对象，并计算这些对象中指定字段的平均值。

查询所有书籍的价格平均值。

```screen
const query = CloudDBZoneQuery.where(BookInfo);
const average = await cloudDBZone.executeAverageQuery(query, 'price');
console.log(average);
```

### 数据排序

您可以通过**[orderByAsc()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-web-0000001127836521#section510510507712)** 或者**[orderByDesc()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-web-0000001127836521#section4831175212713)**实现对查询结果集中的对象按某个字段进行升序或者降序排列。

使用**[orderByAsc()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-web-0000001127836521#section510510507712)** 或者**[orderByDesc()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-web-0000001127836521#section4831175212713)** 对字段进行排序时，建议针对排序的字段创建索引，否则，当该对象类型的数据量达到一定条数时，可能因为查询效率低引起查询超时或失败，影响用户体验。创建索引请参见[新增对象类型](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-sdk-integration-web-0000001518387168#section105953115325) ，创建索引后，您还需要更新本地的对象类型文件，详细请参见[加载对象类型文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-sdk-integration-web-0000001518387168#section19951044112615)。

对查询结果中的对象进行排序时，排序谓词需要在其它查询谓词之后且在限定数据查询数量谓词之前。

构造查询条件，并调用**executeQuery**方法，查询所有价格小于50.0的书籍，并且按降序排列。

```screen
const query = CloudDBZoneQuery.where(BookInfo).lessThan('price', 50.0).orderByDesc('price');
executeQuery(query);
```

### 限定数据查询返回数量

在查询数据时，您可以通过**[limit()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-web-0000001127836521#section195251849262)**限定查询返回数据的起始位置和数量，实现数据的分页。例如与排序查询谓词组合使用，可以实现获取top-N条数据。

对查询结果中的对象限定查询返回数量时，限定数据查询返回数量谓词在所有其它谓词查询之后。

* 构造查询条件，并调用**executeQuery** 方法，查询所有价格小于50.0的书籍，并且只显示最开始10条记录。

  ```screen
  const query = CloudDBZoneQuery.where(BookInfo).lessThan('price', 50.0).limit(10);
  executeQuery(query);
  ```

* 构造查询条件，并调用**executeQuery** 方法，查询所有价格小于50.0的书籍，并将查询结果按照降序排序，只显示价格排序从第6条开始的10条记录。

  ```screen
  const query = CloudDBZoneQuery.where(BookInfo).lessThan('price', 50.0).orderByDesc('price').limit(10, 6);
  executeQuery(query);
  ```

### 查询服务器状态

您可以调用**CloudDBZone** 类中的**[executeServerStatusQuery()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-web-0000001080859822#section1324185773018)** 方法查询服务器状态，返回**ServerStatus** 对象，对象中封装了云侧服务器当前时间戳。

```screen
const serverStatus = await cloudDBZone.executeServerStatusQuery();
console.log('serverTimestamp=' + serverStatus.serverTimestamp);
```

## 删除数据

您可以通过**[executeDelete()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-web-0000001080859822#section137618361416)**删除单个对象或者一组对象。删除数据时，云数据库会根据传入对象主键删除相应的数据，不会比对该对象其它属性与存储的数据是否一致。删除一组对象时，删除操作是原子的，即对象列表中的对象要么全部删除成功，要么全部删除失败。

**注意事项：**
> 注意
>
> 请先关注注意事项。

* 仅当存储区为打开状态时，您才可以进行删除对象操作，否则会导致删除失败。
* 删除一组对象时，该组中的对象必须属于同一个对象类型，否则会导致删除失败。

**代码示例：**

将对象删除，如果删除成功，返回删除对象的个数；执行失败，抛出异常。

```screen
async function executeDelete (book) {
	try {
		const num = await cloudDBZone.executeDelete(book);
		console.log(num)
	} catch (e) {
		console.log(e);
	}
}
```

## 侦听实时更新

您可以通过**[subscribeSnapshot()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-web-0000001080859822#section630612914412)**来侦听符合指定查询条件的数据变化。当侦听的数据发生变化时，云数据库会触发您自定义的回调函数，并将数据以快照的方式传给回调函数，由您根据业务逻辑自定义处理快照数据。侦听数据时，仅支持侦听云侧存储区数据。

注册快照侦听后，快照侦听需要一定的时间（受限于网络状态）才会生效，因此，在侦听生效前的数据变化不会推送到端侧，待侦听生效后，端侧可正常收到云侧数据变化的通知。您注册快照侦听后，会触发生成一次快照，后续每当侦听的数据发生变化时，都会生成一次快照。

通过调用**CloudDBZoneSnapshot** 类中的**[getUpsertedObjects()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonesnapshot-web-0000001127719373#section58131495319)** 可以获取相较于上次快照新增或者修改的对象，调用**[getDeletedObjects()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonesnapshot-web-0000001127719373#section1756219512305)**获取相较于上次快照删除的对象。

**注意事项** **：**
> 注意
>
> 请先关注注意事项。

* 在应用用户发起注销登录操作时，如果已注册该用户的个人数据快照侦听，则您需要在应用代码中使用**[remove()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-listenerhandler-web-0000001127497625#section520052033014)**方法主动注销该用户的数据快照侦听，以保证数据快照推送的正确性。
* 当您的对象类型中的数据类型包含**IntAutoIncrement** 或**LongAutoIncrement**时，则该对象类型不支持订阅侦听。

**侦听云侧数据更改**

添加侦听云侧数据变化的侦听器，当云侧数据发生变更时，系统会生成快照，您可通过快照获取数据变更信息。在使用完快照后，必须显式地调用**ListenerHandler** 类中的**[remove()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-listenerhandler-web-0000001127497625#section520052033014)**来释放相关的资源。

* 创建一个侦听器**onSnapshotListener** 。

  ```screen
  const onSnapshotListener = {
  	onSnapshot: (snapshot, e) => {
  		if (e !== null && e !== undefined && e.code !== AGConnectCloudDBExceptionCode.Ok) {
  			console.log('subscribeSnapshot error');
  			console.log(e);
  			return;
  		}
  		
  		console.log(snapshot.getSnapshotObjects());
  		console.log(snapshot.getUpsertedObjects());
  		console.log(snapshot.getDeletedObjects());
  	}
  };
  ```

* 添加侦听云侧数据变化的侦听器，当云侧数据发生变更时，系统会生成快照，您可通过快照获取数据变更信息。

  ```screen
  async function subscribeSnapshot () {
  	const query = CloudDBZoneQuery.where(BookInfo);
  	query.equalTo('shadowFlag', true);
  	try {
  		const listenerHandler = await cloudDBZone.subscribeSnapshot(query, onSnapshotListener);
  	} catch (e) {
  		console.log('subscribeSnapshot error');
  		console.log(e);
  	}
  }
  ```

**注销侦听**

通过调用**ListenerHandler** 类中的**[remove()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-listenerhandler-web-0000001127497625#section520052033014)**方法，注销侦听。

```screen
listenerHandler.remove();
```

## 事务与数据管理

云数据库支持通过**[runTransaction()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzone-web-0000001080859822#section85313591445)**执行事务，实现对云侧存储区数据的管理操作，包含数据的增、删、改、查操作。事务支持同时对多个对象类型的数据进行增、删、改、查操作。事务操作是原子的，一个事务内的所有操作要么全部执行成功，要么全部执行失败。如果执行事务时出现并发写入，云数据库会再次尝试执行整个事务，确保整个事务操作的一致性。

**注意事项**：
> 注意
>
> 请先关注注意事项。

* 仅当存储区为打开状态时，才可以执行事务操作，否则会导致事务执行失败。
* 事务中的查询操作必须在写入操作之前，否则将导致事务执行异常。
* 仅在正常连接网络时可执行事务操作，一旦离线该操作将失败。
* 一个事务中多次查询结果的总数据大小不能超过5MB，否则会导致事务失败。
* 一个事务中多次查询结果的总数据条数不能超过1000条，否则会导致事务失败。
* 一个事务中包含的写入和删除对象的总条数不能超过1000条，否则会导致事务执行失败。
* 一个事务内的多次写入和删除操作的数据总大小不能超过2MB，否则会导致事务执行失败。

**代码示例：**

使用如下方法，通过事务删除云侧出版日期早于1990年的书籍。

```screen
//先定义一个事务操作，封装查询和删除操作。
async function runTransactionDelete (query) {
	try {
		await cloudDBZone.runTransaction({
			apply: async (transaction => {
                                try {
                                        const bookList = await transaction.executeQuery(query);
                                        transaction.executeDelete(bookList);
                                        return true;
                                } catch (e) {
                                        console.error(e);
                                        return false;
                                }
			})
		})
	} catch (e) {
		console.error(e)
	}
}

//构造查询条件，调用定义的事务操作，完成删除操作。
try {
	const query = CloudDBZoneQuery.where(BookInfo);
	query.lessThan('publishTime', new Date(1990, 1, 1));
	await runTransactionDelete(query);
} catch (e) {
	console.log(e);
}
```

## 全程加密数据

云数据库提供隐私或者敏感数据的全程加密管理能力。该功能开启后，用户数据将在端侧进行加密，然后再以密文形式发送并存储到云侧，只有用户依据其输入的密码才能获取密钥信息并访问自己的加密数据。从而有效提升用户数据的安全性，防止用户云侧数据泄露。

您在AGC控制台上创建对象类型并设置加密字段，即可开启针对该字段的全程加密功能。在您将对象类型文件导入至本地开发环境后，需要使用**[setUserKey()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agconnectclouddb-web-0000001081019778#section119080327319)**方法设置用户密码，云数据库会使用该密码派生出密钥信息，并将加密后的密钥信息和加密后的用户数据以密文形式保存在云侧，加密密钥将会和用户账号绑定，只有该用户依据其设置的密码才能获取密钥信息并访问自己的加密数据。用户密码由用户保存，不会同步至云侧。

**注意事项：**
> 注意
>
> 请先关注注意事项。

* 如果未调用**[setUserKey()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agconnectclouddb-web-0000001081019778#section119080327319)**方法设置用户密码，则该对象类型的数据无法同步至云侧，且无法对云侧该对象类型的数据进行操作。
* 云数据库不会保存用户密码，需要应用开发者自定义用户密码管理策略。
* 查询全程加密数据时，当前支持的查询谓词包含**equalTo()、notEqualTo()、isNull()、isNotNull()、greaterThan()、greaterThanOrEqualTo()、lessThan()、lessThanOrEqualTo()、orderByAsc()、orderByDesc()** 和**limit()** 方法，同时支持关系谓词**and()、or()、beginGroup()、endGroup()**。
* 设置或者修改云数据库数据全程加密的用户密码，允许自定义用户密码强弱校验。如果开启强校验，当首次设置和修改用户密码时，对用户密码进行强校验，其它场景默认进行弱校验。
* 修改用户密码时，需要先校验原用户密码，校验成功后，才能修改用户密码。如未先校验用户原密码或者校验失败，操作加密数据会失败。

### 设置用户密码

* 使用全程加密功能后，使用**[setUserKey()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agconnectclouddb-web-0000001081019778#section119080327319)** 方法设置用户密码，设置用户的初始密码为*xxxxxxxxx* 。

  ```screen
  try {
      const isSuccess = await agcCloudDB.setUserKey('xxxxxxxxx', null, true);
  } catch (e) {
      console.log(e);
      console.log('set UserKey failed')
  }
  ```

* 假设拥有两部手机，在其中一部手机修改用户密码后，另一部手机可以通过**[addEventListener()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agconnectclouddb-web-0000001081019778#section2263111582910)** 侦听用户密码的变更。当用户密码发生变更后，另一部手机校验更新后的用户密码。如下，将初始设置的密码*xxxxxxxxx* ，更新为密码*xxxxxxxxx* 。

  ```screen
  try {
      agcCloudDB.addEventListener({
          onEvent(eventType: EventType): void {
              if (eventType === EventType.USER_KEY_CHANGED) {
                  console.log('user key has been changed');
                  await agcCloudDB.setUserKey('xxxxxxxxx', null, true);
              }    
          }
      });
  } catch (e) {
      console.log(e);
  }
  ```

## 管理存储区

存储区是一个数据存储区域，每个存储区互相独立，之间的数据没有关联。一个云数据库实例中可以创建多个存储区。

一个存储区内可以定义多个对象类型，支持不同的业务需求。每个存储区拥有完全相同的对象类型定义，您可以根据应用的需要自定义存储区中存储的对象。

如果您不再使用某个存储区，可将其暂时关闭。

**注意事项：**
> 注意
>
> 操作前，请先关注注意事项。

* 打开一个存储区后，才能对该存储区进行相关数据操作。
* 可以多次打开某个存储区，但在使用完存储区后，都需要关闭该存储区，即每个打开操作需要一个对应的关闭操作。

**代码示例：**

* 打开一个存储区。

  ```screen
  async function openCloudDBZone () {
  	try {
  		const config = new CloudDBZoneConfig('QuickStartDemo');
  		cloudDBZone = await agcCloudDB.openCloudDBZone(config);
  		console.log('open zone success ::' + cloudDBZone);
  	} catch (e) {
  		console.log('open zone fail');
  		console.log(e);
  	}
  }
  ```


* 关闭存储区。

  ```screen
  mCloudDB.closeCloudDBZone(cloudDBZone );
  ```

## 管理版本升级

应用版本升级时，可在AGC控制台上导出对应版本文件，添加至本地开发环境。并通过调用**AGConnectCloudDB** 类中的**[createObjectType()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agconnectclouddb-web-0000001081019778#section10644219429)** 实现新对象类型的创建，调用**[openCloudDBZone()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agconnectclouddb-web-0000001081019778#section1366119221121)**打开指定存储区，完成对象类型版本的升级。
