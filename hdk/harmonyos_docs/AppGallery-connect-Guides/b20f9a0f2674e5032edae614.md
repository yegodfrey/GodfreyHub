# Token变更事件监听

您可以调用[[AGCAuth addTokenListener:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346#section129617512162)注册Token事件监听，当发生以下事件时，开发者将会收到通知：

* 取得AGC授权后，取得授权 (AGCTokenStateSignedIn)
* AGC Token过了有效期后，AGC Token更新 (AGCTokenStateTokenUpdated)
* AGC Token过了有效期或者用户登出后，AGC Token失效 (AGCTokenStateTokenInvalid)
* 用户登出或者销户后，AGC 注销 (AGCTokenStateSignedOut)

```screen
"Objective-C"
// Token变更事件监听
AGCTokenChangedListener listener = ^(AGCTokenSnapshot * _Nonnull tokenSnapshot) {
    if (tokenSnapshot.state == AGCTokenStateTokenUpdated) {
            NSString *token = tokenSnapshot.token;
        }
};
// 注册监听
[[AGCAuth getInstance] addTokenListener:listener];
// 移除监听
[[AGCAuth getInstance] removeTokenListener:listener];
```

```screen
"Swift"
// Token变更事件监听
let listener = { (tokenSnapshot:AGCTokenSnapshot) in
    if tokenSnapshot.state == AGCTokenState.tokenUpdated {
            let token = tokenSnapshot.token;
        }
};
// 注册监听
AGCAuth.instance().addTokenListener(listener)
// 移除监听
AGCAuth.instance().removeTokenListener(listener)
```
