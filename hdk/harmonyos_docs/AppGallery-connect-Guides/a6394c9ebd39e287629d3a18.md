# 微信

您可以在应用中集成微信认证方式，让您的用户可以使用自己的微信账号进行AppGallery Connect身份验证。

## 前提条件

* 您需要在AGC控制台[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-integration-sdk-0000001325876845)。

## 开发步骤

认证服务提供了两种开发方式接入微信账号：

* 推荐您使用新的统一登录接入方式，请参见[统一登录接入方式](#section12423874459)。
* 同时为了兼容性保留了老的传统接入方式，请参见[传统接入方式](#section2409204915465)。

### 统一登录接入方式

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143815.88531256347168565472831341465889:50001231000000:2800:99F0FB27BA522C19BD855968B41BDC1493481F387C4F924F5D65FA08DC59ED88.png "点击放大")

1. 添加SDK依赖。
   * Android Studio开发环境
     * Version Catalog方式管理依赖
       1. 打开Android Studio项目级gradle目录下的"libs.versions.toml"文件，在[versions]中声明微信SDK版本号。

          ```screen
          [versions]
          wechatVersion = "6.8.0"  # 以6.8.0为例
          ```

       2. 在"libs.versions.toml"文件的[libraries]中声明华为认证SDK和微信SDK。

          ```screen
          [libraries]
          agconnect-auth-wechat = { module = "com.huawei.agconnect:agconnect-auth-wechat", version.ref = "agcVersion" }  # agcVersion声明请参见https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-integration-sdk-0000001325876845#section99221941185719。
          wechat-sdk = { module = "com.tencent.mm.opensdk:wechat-sdk-android-without-mta", version.ref = "wechatVersion" }
          ```

       3. 在应用级"build.gradle"文件的"dependencies"中添加华为认证SDK和微信SDK的编译依赖。

          ```screen
          dependencies {      
               implementation libs.agconnect.auth.wechat
               implementation libs.wechat.sdk
          }
          ```

     * 非Version Catalog方式管理依赖

       打开应用级gradle文件（通常在 app/build.gradle），在"dependencies"中添加华为认证SDK和微信SDK的编译依赖：

       ```screen
       dependencies {
           implementation "com.huawei.agconnect:agconnect-auth-wechat:1.9.4.300"     
           implementation "com.tencent.mm.opensdk:wechat-sdk-android-without-mta:{version}"
       }
       ```

   * Eclipse开发环境

     打开aar2eclipse/aar目录下的build.gradle文件， 在"dependencies"中添加华为认证SDK和微信SDK的编译依赖。具体步骤请参见[Eclipse开发环境集成AGC SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-integration-sdk-0000001325876845#section1878849165620)。

     ```screen
     dependencies {
         embed "com.huawei.agconnect:agconnect-auth-wechat:1.9.4.300"
         embed "com.tencent.mm.opensdk:wechat-sdk-android-without-mta:{version}"
     }
     ```

   > 说明
   > * 示例中的*wechatVersion* 和*{version}*请替换为微信SDK的最新版本号，华为不负责更新。
   > * 由于华为未提供微信SDK依赖包，您可以在腾讯开放平台下载最新版本的微信SDK依赖包进行手动集成。
2. 设置微信账号登录所需参数。 在登录之前，调用设置参数接口，设置微信账号登录所需要的参数。

   * /wechat/appId：在微信开放平台申请的appId。
   * /wechat/appSecret：在微信开放平台申请的appSecret。

   ```screen
   "Java"
   AGConnectApi.getInstance().getOptions().setOption("/wechat/appId", "your wechat appId");
   AGConnectApi.getInstance().getOptions().setOption("/wechat/appSecret", "your wechat appSecret");
   ```

   ```screen
   "Kotlin"
   AGConnectApi.getInstance().getOptions().setOption("/wechat/appId", "your wechat appId")
   AGConnectApi.getInstance().getOptions().setOption("/wechat/appSecret", "your wechat appSecret")
   ```

3. 添加生命周期回调，请参见[统一登录调用页面回调](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-unified-login-0000001325756981)。
4. 接收微信的请求及返回值。
   1. 在包名相应目录下新建一个wxapi目录，并在wxapi目录下新增一个WXEntryActivity类，该类继承自AGCWxEntryActivity。

      ```screen
      "Java"
      public class WXEntryActivity extends AGCWxEntryActivity {
          @Override
          protected void onCreate(Bundle savedInstanceState) {
              super.onCreate(savedInstanceState);
          }

          @Override
          protected void onNewIntent(Intent intent) {
              super.onNewIntent(intent);
          }

          @Override
          public void onReq(BaseReq baseReq) {
              super.onReq(baseReq);
          }

          @Override
          public void onResp(BaseResp baseResp) {
              super.onResp(baseResp);
          }
      }
      ```

      ```screen
      "Kotlin"
      class WXEntryActivity : AGCWxEntryActivity() {
          protected override fun onCreate(savedInstanceState: Bundle?) {
              super.onCreate(savedInstanceState)
          }

          protected override fun onNewIntent(intent: Intent?) {
              super.onNewIntent(intent)
          }

          override fun onReq(baseReq: BaseReq?) {
              super.onReq(baseReq)
          }

          override fun onResp(baseResp: BaseResp?) {
              super.onResp(baseResp)
          }
      }
      ```

   2. 在AndroidManifest文件中添加exported、taskAffinity及launchMode属性，其中exported设置为true，taskAffinity设置为应用包名，launchMode设置为singleTask。

      ```screen
      <activity
          android:name=".wxapi.WXEntryActivity"
          android:label="@string/app_name"
          android:theme="@android:style/Theme.Translucent.NoTitleBar"
          android:exported="true"
          android:taskAffinity="填写应用包名"
          android:launchMode="singleTask">
      </activity>
      ```

5. 调用[AGConnectAuth.signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauth-0000001054482530#section125666562219)，登录微信账号。

   ```screen
   "Java"
   AGConnectAuth.getInstance().signIn(this,AGConnectAuthCredential.WeiXin_Provider).addOnSuccessListener(new OnSuccessListener<SignInResult>() {
           @Override
           public void onSuccess(SignInResult signInResult) {
                   // onSuccess
                   AGConnectUser user =  signInResult.getUser();
           }
   })
   .addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
                   // onFail
           }
   });
   ```

   ```screen
   "Kotlin"
   AGConnectAuth.getInstance().signIn(this, AGConnectAuthCredential.WeiXin_Provider).addOnSuccessListener {
       // updateUI
   }.addOnFailureListener {
       // onFailure
   }
   ```

### 传统接入方式

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143815.87279268409595843174799008742781:50001231000000:2800:6C703F70779C327777FDE01CD70F56FCA9991D34CC256DBF80BA14F0C7B78B38.png "点击放大")

1. 在应用的登录界面，初始化[AGConnectAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauth-0000001054482530)实例，获取AGC的用户信息，检查是否有已经登录的用户。如果有则可以直接进入用户界面，否则显示登录界面。

   ```screen
   "Java"
   AGConnectUser user = AGConnectAuth.getInstance().getCurrentUser();
   ```

   ```screen
   "Kotlin"
   val user = AGConnectAuth.getInstance().currentUser
   ```


2. 微信账号登录，并获取微信账号的用户授权信息。 说明
   >
   > 此步骤仅供参考，更详细内容，请参见[微信官方文档](https://open.weixin.qq.com/cgi-bin/showdocument?action=dir_list&t=resource/res_list) 。
   1. 初始化WXAPI。

      ```screen
      "Java"
      api = WXAPIFactory.createWXAPI(context, APP_ID, false);
      api.registerApp(APP_ID);
      ```


   2. 发送请求获取微信授权的code。

      ```screen
      "Java"
      SendAuth.Req req = new SendAuth.Req();
      req.scope = "snsapi_userinfo";
      req.state = "none";
      api.sendReq(req);
      ```

   3. 在包名同文件夹下创建wxapi文件夹，添加WXEntryActivity类。

      ```screen
      "Java"
      public class WXEntryActivity extends Activity implements IWXAPIEventHandler {
              @Override
              protected void onCreate(@Nullable Bundle savedInstanceState) {
                      super.onCreate(savedInstanceState);

                      try {
                              Intent intent = getIntent();
                              api.handleIntent(intent, this);
                      } catch (Exception e) {
                              e.printStackTrace();
                      }
              }

              @Override
              protected void onNewIntent(Intent intent) {
                      super.onNewIntent(intent);
                      setIntent(intent);
                      api.handleIntent(intent, this);
              }

              @Override
              public void onReq(BaseReq baseReq) {
              }

              @Override
              public void onResp(BaseResp baseResp) {
              }
      }
      ```

   4. 在onResp(BaseResp baseResp)中接收授权后的code。

      ```screen
      "Java"
      if (baseResp.getType() == ConstantsAPI.COMMAND_SENDAUTH) {
              SendAuth.Resp authResp = (SendAuth.Resp) baseResp;
              String code = authResp.code;
      }
      ```

   5. 发送如下请求获取accessToken和openId。

      ```screen
      https://api.weixin.qq.com/sns/oauth2/access_token?appid=APPID&secret=SECRET&code=CODE&grant_type=authorization_code
      ```

3. 调用[WeixinAuthProvider.credentialWithToken](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/weixinauthprovider-0000001054322511#section11590152403916)，使用从微信账号获取的accessToken和openId生成credential，并调用[AGConnectAuth.signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauth-0000001054482530#section298148131715)实现登录。

   ```screen
   "Java"
   AGConnectAuthCredential credential = WeixinAuthProvider.credentialWithToken(accessToken,openId);
   AGConnectAuth.getInstance().signIn(credential)
           .addOnSuccessListener(new OnSuccessListener<SignInResult>() {
                   @Override
                   public void onSuccess(SignInResult signInResult) {
                           // onSuccess
                           AGConnectUser user = signInResult.getUser();
                   }
           })
           .addOnFailureListener(new OnFailureListener() {
                   @Override
                   public void onFailure(Exception e) {
                           // onFail
                   }
           });
   ```

   ```screen
   "Kotlin"
   val credential = WeixinAuthProvider.credentialWithToken(accessToken,openId)
   AGConnectAuth.getInstance().signIn(credential).addOnSuccessListener {
           // onSuccess
           val user = it.user
   }.addOnFailureListener {
           // onFail
   }
   ```

## 更多信息

* 您如果想让用户可以使用多个账号登录您的应用，可以将多个[账号进行关联](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-associated-0000001053692650)。
* 当用户不需要使用应用，或者需要切换其他账号登录认证，可以先执行[登出](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-sign-out-0000001053612647)。
* 当用户需要注销当前用户，可以进行[销户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-deleteuser-0000001057730521)。
* 对于销户、修改密码、关联账号以及重置手机账号和邮箱账号等敏感操作，为了提高安全性，需要用户必须在5分钟内登录过才能执行。如果用户执行敏感操作时登录超过5分钟，需要[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-reauthenticate-0000001127287737)后再执行敏感操作。
* 您可以参考[异常处理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-troubleshooting-0000001052932665)实现自己的异常处理机制，从而减少异常情况的发生。
* 您可以使用云函数触发器来接收用户注册、登录、销户等关键事件，从而[扩展认证服务的能力](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-extension-0000001053372708)。
* 您可以参考[管理用户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-user-manage-0000001606051705)对用户进行解锁、停用等操作。
