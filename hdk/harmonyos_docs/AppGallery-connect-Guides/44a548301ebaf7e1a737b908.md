# 撤销用户凭据

当用户向您报告设备丢失，或者当已经颁发的用户访问凭据存在大量泄露的情况时，您可以通过认证服务的Server SDK撤销已经颁发的用户访问凭据。  

#### 前提条件

您需要在您的开发工程中集成认证服务的Server SDK，请参见[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-server-js-integration-sdk-0000001727548354)。  

#### 开发步骤

调用[Auth.revokeRefreshTokens](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/nodejs-auth-0000001732781480#section1241065742418)方法撤销指定用户颁发的用户凭据，用户凭据撤销后端侧用户无法使用老的认证凭据操作认证服务的接口，如需操作需要重新申请用户凭据，该接口无响应可以自行选择是否处理抛出的异常。

```
cloud.auth().revokeRefreshTokens({uid:"useruid"}).catch(e){ 
    if(e.getCode() == AuthErrorCode.REVOKE_REFRESH_TOKENS_UID_IS_NULL.code){ 
    // 用户Id为空
    } else { 
     // 撤销用户访问凭据失败 
    }  
}
```

或者

```
cloudInstance.auth().revokeRefreshTokens({uid:"useruid"}).catch(e){ 
    if(e.getCode() == AuthErrorCode.REVOKE_REFRESH_TOKENS_UID_IS_NULL.code){ 
    // 用户Id为空 
    } else { 
     // 撤销用户访问凭据失败
    }  
}
```
