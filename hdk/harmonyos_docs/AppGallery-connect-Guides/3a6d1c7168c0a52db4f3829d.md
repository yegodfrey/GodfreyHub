# 集成SDK(Eclipse)

#### 集成AGC以及云函数SDK

1. 获取AGC服务依赖的Eclipse工程包。  
   ![](https://media:201779441377127730)  
   生成Eclipse工程包前请确保本地PC已经安装了JDK和Android SDK。
   1. 点击[此处](https://github.com/netwalker128/aar-to-eclipse/releases/download/v1.0/aar2eclipse.zip)获取用于生成Eclipse工程包的工具包"aar2eclipse.zip"，保存在本地并解压。
   2. 打开"aar2eclipse/aar"目录下的build.gradle文件，检查Maven仓地址是否配置准确。

      ```
      allprojects {
          repositories {
              maven { url 'https://developer.huawei.com/repo' }
              google()
              jcenter()
          }
      }
      ```

   <!-- -->

   3. 在"dependencies"中配置云函数服务的SDK依赖地址。  

      ```
      "Java"
      dependencies {
          transform "com.huawei.agconnect:agconnect-function:1.9.6.300"
      }
      ```

      ```
      "Kotlin"
      dependencies {
          transform "com.huawei.agconnect:agconnect-function-ktx:1.9.1.300"
      }
      ```

   4. 双击执行"aar2eclipse/aar"目录下的build.bat文件。执行成功后，会在日志中打印输出Eclipse工程包路径（即"aar2eclipse/aar"目录下的"eclipse"目录）。 ![](https://media:201779441377382731)

2. 打开您的Eclipse工程，选择"File \> Import"，将前面生成的Eclipse工程包导入到您的工作空间。
   1. 选择"Android \> Existing Android Code Into Workspace"，点击"Next"。 ![](https://media:201779441377423732)

   2. 点击"Browse"，选择工程包所在的"aar2eclipse/aar/eclipse"目录。在"Projects"下显示待导入的工程（默认工程名为"BridgeActivity"），勾选后点击"Finish"。  
      ![](https://media:201779441377448733)  
      待导入的工程必须和工作空间在相同的磁盘空间里，例如都在"D:\\"。如果不在，您可以选择"Copy projects into workspace"，将工程文件复制到工作空间。同时，不要将待导入的工程和您的Eclipse工程放在同一层级目录，否则可能导入失败。

      ![](https://media:201779441377483734)
3. 添加工程依赖关系。
   1. 右键点击您的工程，选择"Properties"。
   2. 在左侧选择"Android"，点击"Add"，选择已导入空间的BridgeActivity工程。 ![](https://media:201779441377508735)

   3. 点击"Apply and Close"，完成添加。
4. 拷贝资源文件到您的工程目录。 由于Eclipse不能自动合并assets目录，请手动将导入的BridgeActivity工程下assets目录里的全部文件拷贝到您Eclipse工程中assets目录下。需要拷贝的资源文件如下：

   ![](https://media:201779441377651736)
5. 修改工程配置。
   1. 配置project.properties文件。 由于Eclipse默认不支持AndroidManifest.xml文件的合并，需要在您的工程目录中找到project.properties文件并打开，添加如下配置，用于合并子工程中的Manifest文件。

      ```
       manifestmerger.enabled=true
      ```

   2. 配置包名。 请手动修改BridgeActivity工程下AndroidManifest.xml中的所有"${applicationId}"为您的应用包名。例如：

      修改前：

      ```
      <application>
      <provider
          android:name="com.huawei.agconnect.core.provider.AGConnectInitializeProvider"
          android:authorities="${applicationId}.AGCInitializeProvider"
          android:exported="false" />
      ```

      修改后：

      ```
      <application>
          <provider
              android:name="com.huawei.agconnect.core.provider.AGConnectInitializeProvider"
              android:authorities="com.huawei.functioneclipse.AGCInitializeProvider"
              android:exported="false" />
      ```

6. 添加AppGallery Connect配置文件。
   1. 由于Eclipse不支持AGC插件，您可以将[agconnect-services.json文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/obtain-files-andrioid-0000001563230789)放置到您的工程中assets目录下，并且在应用的Application类中添加如下代码。如果应用没有Application类，则需要新建，例如新建MyApplication类。

      ```
      public class MyApplication extends Application{
          // TODO: 添加如下代码
          @Override
          public void onCreate() {
              super.onCreate();
              try {
                  AGConnectOptionsBuilder builder = new AGConnectOptionsBuilder();
                  builder.setInputStream(getAssets().open("agconnect-services.json"));
                  AGConnectInstance.initialize(this, builder);
              } catch (IOException e) {
                  e.printStackTrace();
              }
          }
          // TODO: 添加代码结束             
      }
      ```

   2. 打开您的工程AndroidManifest.xml文件，在"application"模块中添加MyApplication类声明。如果已经声明，则跳过此步骤。

      ```
      <application
          <!—添加声明开始 -->
          android:name=".MyApplication">
          <!—添加声明结束 -->
      </application>
      ```

3. 在Eclipse的菜单栏中点击"Project"，执行"clean"操作。  

#### （可选）将密钥信息传递给AGC

#### 通过配置文件参数传递密钥

AGC SDK提供了[AGConnectOptionsBuilder](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-agconnectoptionsbulider-0000001116227891)类来对agconnect-services.json文件中的参数进行配置，如果您在下载配置文件时选择了"不包含密钥"，则agconnect-services.json文件中将不包含client_id、client_secret和api_key参数，您必须通过[AGConnectOptionsBuilder](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-agconnectoptionsbulider-0000001116227891)类的接口在应用启动时将参数设置给AGC SDK。  
建议您在Application或者第一个启动的Activity的onCreate方法中完成client_id、client_secret和api_key等参数的设置。

```
//添加如下代码
try {
	AGConnectOptionsBuilder builder = new AGConnectOptionsBuilder();
	InputStream in = getAssets().open("agconnect-services.json");    //如果使用了AGC插件，删除此行
	builder.setInputStream(in);                                      //如果使用了AGC插件，删除此行
	builder.setClientId("client_id");
	builder.setClientSecret("client_secret");
	builder.setApiKey("api_key");
	builder.setCPId("cp_id");
	builder.setProductId("product_id");
	builder.setAppId("app_id");
	AGConnectInstance.initialize(this, builder);
} catch (IOException e) {
	e.printStackTrace();
}
//TODO: 添加代码结束
```

需配置的参数的值可在"项目设置 \> 常规"页面中查询，点击页面参数后面的![](https://media:201779441377685737)，可复制参数值。

需配置的参数值和"常规"页面参数的对应关系如下：

* "client_id"替换为"常规"页面"项目"栏中"Client ID"的值。
* "client_secret"替换为"常规"页面"项目"栏中"Client Secret"的值。
* "api_key"替换为"常规"页面"项目"栏中"API密钥（凭据）"的值。
* "cp_id"替换为"常规"页面"开发者"栏中"Developer ID"的值。
* "product_id"替换为"常规"页面"项目"栏中"项目ID"的值。
* "app_id"替换为"常规"页面"应用"栏中"APP ID"的值。

![](https://media:201779441377712738)  

#### 通过Token传递密钥

如果您认为client_id和client_secret放在json文件里不安全，我们建议您将client_id和client_secret放在自己的服务端。先调用https://connect-drcn.dbankcloud.cn/agc/apigw/oauth2/v1/token接口去换取Token，然后在初始化AGC SDK时通过[setCustomCredentialsProvider](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-agconnectoptionsbulider-0000001116227891#section9602114520710)将Token传给AGC去使用。

Token接口请求示例：

```
POST /agc/apigw/oauth2/v1/token
Host: connect-drcn.dbankcloud.cn
Content-Type: application/json
{
   "grant_type":"client_credentials",
   "client_id":"agc应用页面提供的client_id",
   "client_secret":"agc应用页面提供的client_secret",
   "useJwt":1
}
```

Token接口响应示例：

```
HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8
{
    "access_token": "eyJhbGciOiJIUzU****************",
    "expires_in": 0
}
```

setCustomCredentialsProvider接口调用示例：

```
"Java"
String tokenStr = "access_token";
long expiration = expires_in;

CustomCredentialsProvider developerClientToken = new CustomCredentialsProvider() {
    @Override
    public Task<Token> getTokens(boolean forceRefresh) {
        TaskCompletionSource<Token> source = new TaskCompletionSource<>();
        Token token;
            token = new Token() {
                @Override
                public long getExpiration() {
                    return expiration;
                }

                @Override
                public long getIssuedAt() {
                    return 0;
                }

                @Override
                public long getNotBefore() {
                    return 0;
                }

                @Override
                public String getTokenString() {
                    return tokenStr;
                }
            };
        source.setResult(token);
        return source.getTask();
    }
};

AGConnectOptionsBuilder builder = new AGConnectOptionsBuilder();
builder.setCustomCredentialsProvider(developerClientToken);
AGConnectInstance.initialize(getApplicationContext(),builder);
```

```
"Kotlin"
val tokenStr = "access_token"
val expiration: Long = expires_in

val developerClientToken = CustomCredentialsProvider {
    val source = TaskCompletionSource<Token>()
    val token: Token
    token = object : Token {
        override fun getExpiration(): Long {
            return expiration
        }

        override fun getIssuedAt(): Long {
            return 0
        }

        override fun getNotBefore(): Long {
            return 0
        }

        override fun getTokenString(): String {
            return tokenStr
        }
    }
    source.setResult(token)
    source.task
}
val builder = AGConnectOptionsBuilder()
builder.setCustomCredentialsProvider(developerClientToken)
AGConnectInstance.initialize(getApplicationContext(), builder)
```

#### 配置混淆脚本

开发者编译APK前需要配置不要混淆AppGallery Connect，避免功能异常。

1. 打开混淆配置文件。
2. 加入排除AppGallery Connect的混淆配置。 在proguard-project.txt文件中加入混淆配置。

   ```
   -keep class com.huawei.agconnect.remoteconfig.*{*;}
   -keepclassmembers class **{
       public <init>(android.content.Context,com.huawei.agconnect.AGConnectInstance);
   }
   -keepclassmembers class com.huawei.agconnect.remoteconfig.internal.server.**{*;}
   -keep class * implements android.os.Parcelable {
       public static final android.os.Parcelable$Creator *;
   }
   ```

#### （可选）初始化SDK

应用集成AGC SDK时，如果使用了多进程处理机制，则需要在子进程中调用初始化方法。

在Application的onCreate方法中添加初始化代码：

```
if (AGConnectInstance.getInstance() == null) { 
     AGConnectInstance.initialize(getApplicationContext()); 
}
```
