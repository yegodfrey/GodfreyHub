# 使用限制

#### 渠道包的打包要求

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230223213405.66146081371754742600245528838097:50001231000000:2800:4AC291144567AC29A5D2FB9022E45C6BDD5EA3FBCA19BEE2BB3E6C5D6A428125.png?needInitFileName=true?needInitFileName=true)  
如果主包为多包包体场景，则开发者需要上传全量的渠道包，即32位的渠道包和64位的渠道包。否则无法覆盖到所有手机，导致效果统计不准确。  

#### 渠道包的更新机制

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230223213405.03106193184933658559030695651352:50001231000000:2800:BC54B699B6778AB9C7A236DF975EA106916231A031323D99D59F6C76C9CE44AB.png?needInitFileName=true?needInitFileName=true)  
如果主包为多包包体场景，则开发者需要上传全量的渠道包，即32位的渠道包和64位的渠道包。否则无法覆盖到所有手机，导致效果统计不准确。

当应用市场的主包版本高于测试渠道包的版本，测试渠道包会被更新为高版本的主包。更新方式有如下几种：

* 用户可通过应用市场的"自动更新应用"功能完成应用更新。该功能被默认设置为在连接WLAN时生效，并在后台自动帮用户完成更新。
* 用户可自行点击应用市场的更新通知栏，或者在安装管理界面点击更新按钮完成应用更新。
* 开发者可在应用内嵌入应用市场的"[图章链接](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agdlink-introduction-0000001164321879)"。用户通过点击应用内的更新按钮，跳转至应用市场的更新详情页完成更新。  

#### 渠道包的审核机制

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230223213405.45746007773830563889732695152505:50001231000000:2800:C69C9B2F5B16D393301DD6C07655E318ACDB915A87DEFBF91B3A9540DC4864BB.png?needInitFileName=true?needInitFileName=true)  
如果主包为多包包体的更新场景，则开发者需要更新上传全量的渠道包，即32位的渠道包和64位的渠道包。否则无法覆盖到所有手机，导致效果统计不准确。

渠道包以人工审核为主，请自行查看审核结果。
