# 上传文件

您可以通过REST API快速上传本地设备上的文件到云端。  

#### 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[获取API授权](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-getapicredentials-0000001498508514)。  

#### 操作步骤

1. 预先规划云端的文件地址和需要存储到云端的本地文件。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240821163328.63024567413079493523030061118580:50001231000000:2800:5AFB1B1725FF8D81EB505771B2762BEEB7C86C5D6710EC3D366CBD7925827088.png?needInitFileName=true?needInitFileName=true)  
   如果未规划云端地址，则传入的文件将上传到存储实例根目录，且默认使用源文件名作为云端文件名。
2. 调用[上传文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storage-restapi-uploadfile-0000001549318457)接口将文件上传到云端。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240821163328.38148402594568882018756530752614:50001231000000:2800:E6A8284DB47003C67D04F5BFB7519E6B3CB43097A6E730A92F19B0F52BE24767.png?needInitFileName=true?needInitFileName=true)  
   * 上传文件时，会对云端文件的名称和大小进行严格的检查，具体限制请参见[使用限制](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-restrictions-0000001093263535#ZH-CN_TOPIC_0000001093263535__p1468492045318)。
* 当通过断点续传的方式上传较大的文件时，服务器对文件的SHA256值校验时间会相对较长，因此需设置一个较大的MaxUploadTimeout值，最大可设置为500秒。  

#### 更多信息

* 文件成功上传后，您可以[设置文件的自定义属性](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-metadata-restapi-0000001549457645#section172722985816)，也可以通过REST API[下载文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-download-restapi-0000001498498082)。
* 您可以通过云存储REST API[列举云端某个目录下的所有文件或子目录](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-list-restapi-0000001498657938)。
* 当您不再需要云端的文件时，可以调用云存储REST API在应用客户端[删除文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-delete-restapi-0000001549297697)。
* 除了在应用客户端通过云存储REST API来上传文件，您还可以直接[在AGC控制台以可视化的方式来上传文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-manage-file-0000001281134398#section6704135012516)。
