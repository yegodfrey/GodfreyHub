# 元数据管理

文件元数据包含云端文件名、文件大小、文件类型等常用属性，也包括用户自定义的文件属性。

文件上传到云端后，您都可以设置文件的自定义属性。您也可以在下载文件实体前获取文件的元数据，来决定是否要下载文件。  

#### 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[创建File对象](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-createreference-nodejs-0000001055327465#section17165283611)。  

#### 操作步骤

1. 创建文件的[File](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/file-0000001056171313)实例，并初始化文件的[Metadata](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/metadata-0000001057683681)实例。

   ```
   const file = bucket.file('images/demo.jpg');
   const metadata = {
       contentType:'test/plain',
       customMetadata: {
           a: 'a',
           b: 'b'
       }
   };
   ```

2. 调用[File.setMetadata](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/file-0000001056171313#section3693184116208)方法将文件属性的元数据和自定义的元数据覆盖到云端。

   ```
   file.setMetadata(metadata).then((res) => {
   });
   ```

3. 当设置元数据成功后，您可以通过调用[File.getMetadata](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/file-0000001056171313#section47219167169)方法获取设置在云端的元数据。

   ```
   file.getMetadata().then((res) => {
   });
   ```
