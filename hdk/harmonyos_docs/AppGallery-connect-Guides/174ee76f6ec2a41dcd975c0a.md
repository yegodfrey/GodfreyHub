# 发布应用内消息

应用内消息只有在发布后，才能在正式用户的应用内展示。  

#### 前提条件

已[添加并保存应用内消息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-appmessage-create-ios-0000001071924650)。  

#### 发布消息

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155408.62207722570236221447725674745817:50001231000000:2800:A3EC01A2A2E054E75C0B3F955714458D791EEAF064D3DBE1D8E848C3CF102390.png)  
分配了"管理员"、"APP管理员"、"运营"或"开发"角色的账号才可以发布应用内消息。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击您需要发布应用内消息的项目。
3. 点击"增长 \> 应用内消息"，点击需要发布消息的"操作"列中的"发布"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155408.85733443068084114766000713046806:50001231000000:2800:31548A737231AD551DC4B6E54D415D264164A03F74F8BAF4AAF05696CD417010.png)

如果同一时间存在多个相同事件触发的应用内消息，应用内消息服务只展示其中1条。因此，发布前请确认当前已发布的应用内消息没有使用相同的触发事件。
