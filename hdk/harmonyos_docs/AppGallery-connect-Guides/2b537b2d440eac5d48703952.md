# 苹果账号

您可以在应用中集成苹果认证方式，让您的用户可以使用自己的苹果账号进行AppGallery Connect身份验证。

## 前提条件

* 您需要在AGC控制台[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-integration-sdk-0000001326347605)。
* 您需要在苹果开发者网站上为应用开启'Sign In With Apple'。
* 要使用苹果账号登录，用户还必须满足以下条件：
  * 拥有启用了双重身份验证 (2FA) 的Apple ID。
  * 在苹果设备上登录了iCloud。

  更多苹果登录的要求请查看：[如何使用"通过 Apple 登录"功能](https://support.apple.com/zh-cn/HT210318)。

## 开发步骤

认证服务提供了两种开发方式接入苹果账号：

* 推荐您使用新的统一登录接入方式，请参见[统一登录接入方式](#section1950440105218)。
* 同时为了保证兼容性保留了老的传统接入方式，请参见[传统接入方式](#section16952720551)。

### 统一登录接入方式

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114610.32548216801753806868327676417041:50001231000000:2800:1679EA4121F47BEE61DBF7CD7DD82DBAEDB255BF5026F916C4C605ED4E9CD8DE.png "点击放大")

1. 在项目的podfile中添加苹果账号认证API的依赖：

   ```screen
   pod  'AGConnectAPIAuthApple'
   ```

2. 添加生命周期回调，请参见[统一登录调用AppDelegate回调](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-unified-login-0000001275827780)。
3. 调用[[AGCAuth signIn:controller:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346#section1835003573014)方法，登录苹果账号。

   ```screen
   "Objective-C"
    [[[[AGCAuth getInstance] signIn:AGCAuthProviderTypeApple controller:self] addOnSuccessCallback:^(AGCSignInResult * _Nullable result) {
            // onSuccess
            AGCUser *user = result.user;
        }] addOnFailureCallback:^(NSError * _Nonnull error) {
            // onFail
        }];
   ```

   ```screen
   "Swift"
   AGCAuth.instance().signIn(provider: .apple,controller: self).onSuccess{ (result) in
       // onSuccess
   }.onFailure{ (error) in
       // onFailure
   }
   ```

### 传统接入方式

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114610.64118343716762898743704683224117:50001231000000:2800:520A733AF88B66D5B22D5AFF2CEB183B40E7E34C07A2F80FD126443221342A4C.png "点击放大")

1. 在应用的登录界面，初始化[AGCAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346)实例，获取AGC的用户信息，检查是否有已经登录的用户。如果有则可以直接进入用户界面，否则显示登录界面。

   ```screen
   "Objective-C"
   AGCUser *user = [[AGCAuth getInstance] currentUser];
   ```

   ```screen
   "Swift"
   let user = AGCAuth.instance().currentUser
   ```

2. 苹果账号登录，并获取苹果账号的用户授权信息。 说明
   >
   > 此步骤仅供参考，更详细内容，请参见[Apple开发者网站](https://developer.apple.com/documentation/authenticationservices/implementing_user_authentication_with_sign_in_with_apple)。

   苹果登录是由系统的AuthenticationServices.framework提供能力，请先添加相关引用。
   1. 在UI界面中添加ASAuthorizationAppleIDButton按钮，或者自定义按钮来引导用户使用苹果登录。
   2. 在按钮的回调事件里添加如下代码, 其中在认证请求中添加随机字符串并且进行SHA256加密（确保使用此加密方式）

      ```screen
      "Objective-C"
      - (void)appleSignIn:(UIButton *)button { 
          if (@available(iOS 13.0, *)) { 
              ASAuthorizationAppleIDProvider *provider = [[ASAuthorizationAppleIDProvider alloc] init];
              ASAuthorizationAppleIDRequest *request = [provider createRequest]; 
              request.requestedScopes = @[ASAuthorizationScopeFullName,ASAuthorizationScopeEmail]; 
              self.currentRequestNonce = [self randomString]; //生成一个随机字符串，并保存用于后续AGC认证
              request.nonce = [self.currentRequestNonce sha256Hash]; //对随机字符串进行SHA256加密，并带入到请求中。
              ASAuthorizationController *controller = [[ASAuthorizationController alloc] initWithAuthorizationRequests:@[request]]; 
              controller.delegate = self; 
              controller.presentationContextProvider = self; 
              [controller performRequests]; 
          } 
      }
      ```

      ```screen
      "Swift"
      func appleSignIn(_ button: UIButton){
              if #available(iOS 13.0, *) {
                  let provider = ASAuthorizationAppleIDProvider()
                  let request = provider.createRequest()
                  request.requestedScopes = [ASAuthorization.Scope.fullName, ASAuthorization.Scope.email]
                  currentRequestNonce = randomString()
                  request.nonce = sha256Hashing(string: currentRequestNonce!)
                  let controller = ASAuthorizationController.init(authorizationRequests: [request])
                  controller.delegate = self
                  controller.presentationContextProvider = self
                  controller.performRequests()
              }
      }
      ```

   3. 实现苹果登录的回调代理ASAuthorizationControllerDelegate，在认证成功的代理回调中把credential.identityToken和在请求中的原始随机字符串传递给[AGCAppleIDAuthProvider](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcappleidauthrovider-ios-0000001054662353)进行AGC登录认证。

      ```screen
      "Objective-C"
      - (void)authorizationController:(ASAuthorizationController *)controller 
      didCompleteWithAuthorization:(ASAuthorization *)authorization API_AVAILABLE(ios(13.0)) {
          if ([authorization.credential isKindOfClass:ASAuthorizationAppleIDCredential.class]) {
              ASAuthorizationAppleIDCredential *credential = (ASAuthorizationAppleIDCredential *)authorization.credential;
              NSData *identityToken = credential.identityToken;
              // 使用苹果账号登录得到的identityToken登录
              
          }
      }

      - (void)authorizationController:(ASAuthorizationController *)controller didCompleteWithError:(NSError *)error API_AVAILABLE(ios(13.0)) {
          NSLog(@"Apple Auth Fail %@",error);
      }
      ```

      ```screen
      "Swift"
          func authorizationController(controller: ASAuthorizationController, didCompleteWithAuthorization authorization: ASAuthorization) {
              if let appleCredential = authorization.credential as? ASAuthorizationAppleIDCredential {
                  let jwt = String(data: appleCredential.identityToken!, encoding: String.Encoding.utf8)
                  let credential = AGCAppleIDAuthProvider.credential(withIdentityToken: appleCredential.identityToken!, nonce: currentRequestNonce!)
                  if let credentialBlock = credentialBlock {
                      credentialBlock(credential)
                  }
              }
          }

          func authorizationController(controller: ASAuthorizationController, didCompleteWithError error: Error) {
              if let credentialBlock = credentialBlock {
                  credentialBlock(nil)
              }
          }
      ```

   苹果只有在用户首次登录时与应用共享用户信息，如果之前使用过苹果登录，则AGConnect获取不到用户信息。如果要使用用户信息，可以将首次登录返回的ASAuthorizationAppleIDCredential用户信息保存并使用。
3. 调用[[AGCAppleIDAuthProvider credentialWithIdentityToken:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcappleidauthrovider-ios-0000001054662353#section17884171291718)使用从苹果账号获取的identityToken和请求中的原始随机字符串生成credential，并调用[[AGCAuth signIn:]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346#section488155612616)实现登录。

   ```screen
   "Objective-C"
   AGCAuthCredential *agcCredential = [AGCAppleIDAuthProvider credentialWithIdentityToken:identityToken nonce:self.currentRequestNonce];
           [[AGCAuth.getInstance signIn:agcCredential] addOnCompleteCallback:^(HMFTask<AGCSignInResult *> *_Nonnull task) {
               if (task.isSuccessful) {
                    NSLog(@"APPLEID SUCCESS");
               } else {
                    NSLog(@"APPLEID %@", task.error.description);
               }
          }];
   ```

   ```screen
   "Swift"
   let agcCredential = AGCAppleIDAuthProvider.credential(withIdentityToken:identityToken nonce:self.currentRequestNonce)
   AGCAuth.instance().signIn(credential: credential).onSuccess{ (result) in
       // onSuccess
   }.onFailure{ (error) in
       // onFailure
   }
   ```

## 更多信息

* 您如果想让用户可以使用多个账号登录您的应用，可以将多个[账号进行关联](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-associated-0000001053053982)。
* 当用户不需要使用应用，或者需要切换其他账号登录认证，可以先执行[登出](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-sign-out-0000001053692708)。
* 当用户需要注销当前用户，可以进行[销户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-deleteuser-0000001057460873)。
* 对于销户、修改密码、关联账号以及重置手机账号和邮箱账号等敏感操作，为了提高安全性，需要用户必须在5分钟内登录过才能执行。如果用户执行敏感操作时登录超过5分钟，需要[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-reauthenticate-0000001127283387)后再执行敏感操作。
* 您可以参考[异常处理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-troubleshooting-0000001054715191)实现自己的异常处理机制，从而减少异常情况的发生。
* 您可以使用云函数触发器来接收用户注册、登录、销户等关键事件，从而[扩展认证服务的能力](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-extension-0000001053372708)。
* 您可以参考[管理用户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-user-manage-0000001606051705)对用户进行解锁、停用等操作。
