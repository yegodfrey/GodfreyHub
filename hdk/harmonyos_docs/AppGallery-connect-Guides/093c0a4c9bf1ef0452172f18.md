# 转让房主身份

如果房主想让出房主权限，可将房主身份转让给房间中的其他玩家。  

#### 前提条件

玩家为房主身份，且房间中已有其他玩家。  

#### 开发步骤

以小队房间为例，调用[GameMediaEngine.transferOwner](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-web-0000001247887067#section17674145510188)方法可直接转让房主身份给房间中的其他指定玩家。

```
// 原房主无需离开房间，转让房主身份给房间内其他玩家
gameMediaEngine.transferOwner(roomId, ownerId).then(() => {
  // 指定新房主成功
}).catch(error => {
  // 指定新房主失败
});
```
