# 新应用使用应用签名服务

|----------------------------------------------------------------------------|-|
|如果新应用需要使用应用签名服务，可以选择由AGC创建并管理新的签名密钥，也可以选择由您自行上传签名密钥。不管使用哪种方式，AGC将保证您签名密钥的安全。| |

## 前提条件

已参考[创建应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createapp-0000001146718717)在AGC中创建了您的应用。

## 选择应用签名管理方式

对于新应用，AGC提供的两种应用签名管理方式均可选择。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"APP与元服务"。
2. 选择"Android"页签，点击需要签名的应用，进入"分发"页签，选择"服务 > 应用签名"。
3. 首次使用应用签名服务，系统将提示您签署应用签名服务协议，您需要同意协议后才能使用应用签名服务。
4. 根据最终发布给用户的APK是否使用您自己的签名密钥，选择相应的签名方式。 注意
   >
   > 如果您已经使用了应用签名服务，则此处将提示此应用已加入应用签名计划。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251011134002.33520829531946712812444802018401:50001231000000:2800:0258D34152C26D2B44413140DF237490B394AA8DF4C4555AFE4FC94A008A8890.png)
   * 选择"方式一：由AppGallery Connect创建并管理签名密钥"，AGC会为您生成新的签名密钥，并使用新的签名密钥对您的应用重新签名。后续您升级应用时只需使用上传密钥对更新的应用软件包进行签名，再将应用软件包提交发布即可。新应用推荐使用此方式，详细操作参见[选择由AGC创建签名密钥](#section21547511271)。 注意
     > * 如果您已经上传了软件包，此选项将不展示。如果您希望使用此方式，建议您重新创建应用。
     > * 为了保证签名密钥的安全性，AGC不支持查看或导出新生成的签名密钥，但支持导出签名密钥的密钥证书。如果您想在多个应用商店使用同一个签名密钥，或者与第三方对接时需要通过签名密钥进行签名验证，请使用方式二。
   * 选择"方式二：AppGallery Connect仅管理开发者上传的签名密钥"，AGC会使用您自己上传的签名密钥对应用重新签名，后续升级应用时您只需使用应用的上传密钥对更新的应用软件包进行签名，再将应用软件包提交发布即可。详细操作参见[选择自行上传签名密钥](#section146431407275)。 注意
     >
     > 如果软件包配置了其他开放平台的签名，在AGC上传签名密钥可能会造成签名信息的变化并且导致功能异常，请您谨慎选择。

## 选择由AGC创建签名密钥

### 提交上传密钥证书

如果您在选择签名管理方式时选择"方式一：由AppGallery Connect创建并管理签名密钥"，您需要将上传密钥的密钥证书提交到AGC。

1. 生成包含上传密钥的签名文件。以Android Studio为例，选择Android Studio工程下"Build > Generate Signed Bundle/APK"后，可选择创建App Bundle或APK应用的签名文件，填写签名文件相关信息。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251011134002.78818561925676265340124086155112:50001231000000:2800:0340CBB3CB3175D37EDD4F4E6FA6991B98765DBACCB46898069655A6141BA4AE.png)

2. 运行cmd命令打开命令行窗口，进入JDK所在的bin目录，运行如下命令生成上传密钥证书(PEM 格式)。

   ```screen
   keytool -export -rfc -keystore *upload-keystore.jks* -alias *upload* -file *upload_certificate.pem*
   ```

   命令中斜体加粗的内容需替换为实际的值，其中：
   * ***upload-keystore.jks***：上传密钥所在的签名文件。
   * ***upload***：签名文件的别名。
   * ***upload_certificate.pem***：生成的上传密钥证书。
3. 点击"浏览"，选择生成的密钥证书。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251011134002.72144571531457405058802481200132:50001231000000:2800:B0B4DA70AD12E450607C7FEA9D1A213D301F8B8A7B2906F018BA75A45C7AA90D.png)

4. 点击右上角的"提交"将上传密钥证书提交至AGC，AGC会为您生成一个签名密钥。

### 配置重新生成的证书指纹

使用应用签名服务后，AGC会根据签名密钥重新生成证书指纹，可能不同于您开发应用时本地生成的签名证书指纹。如您的应用当前集成的华为相关服务需依赖SHA256证书指纹，您还需为应用添加重签名后的SHA256证书指纹。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"APP与元服务"。
2. 选择"Android"页签，点击您的应用，进入"分发"页签，选择"服务 > 应用签名"。
3. 在应用签名页面，点击"应用签名证书"栏的![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251011134002.70703595937500712036124514230761:50001231000000:2800:F00485A7FA8DC979CE7ABCA7B7428116A7B7F5DFB984122E1F4E145B2C23007B.png "点击放大")，复制SHA256证书指纹。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251011134002.09234527202737639086262032566705:50001231000000:2800:527F57E5443093089672ADF1034F71B53C16884689325E76E82FB76923EC905F.png)
4. 进入"开发与服务 > 项目设置 > 常规 > 应用"，在"SHA256证书指纹"栏点击"添加证书指纹"，粘贴输入复制的SHA256证书指纹，点击"保存"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251011134002.15023886121470191798429006548515:50001231000000:2800:6E44A5511D36DA29839F9EB4D6EEEDC0083A5D44DBA3C2571A4BCF2D6E9924E5.png)

### 发布应用

1. 使用上传密钥对应用软件包进行签名，并上传软件包到AGC。 上传软件包后，AGC会通过上传密钥证书验证软件包中的身份信息，验证通过后使用AGC生成的签名密钥对应用重新签名。重签名需要消耗几分钟时间，请耐心等待。

2. 将应用发布信息补充完整，发布应用。

## 选择自行上传签名密钥

### 提交签名密钥

如果您在选择签名管理方式时选择"方式二：AppGallery Connect仅管理开发者上传的签名密钥"，您需要使用PEPK工具生成包含签名密钥的zip文件，并将zip文件上传到AGC。为了更高的安全性，您还可以提交上传密钥的密钥证书，建议您使用不同于签名密钥的上传密钥。如果不上传，则您需要使用您提交的签名密钥作为上传密钥。

1. 生成包含签名密钥的签名文件。选择Android Studio工程下"Build > Generate Signed Bundle/APK"后，可选择创建App Bundle或APK应用的签名文件，填写签名文件相关信息。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251011134002.33295791350457653296023379633027:50001231000000:2800:A184FCBBDF59249BDD92285CFDA8C09D2200205DECF93037E69F3056FC45FAFE.png)

2. 通过网络或其他合法途径获取PEPK工具（pepk.jar）。
3. 将签名密钥签名文件（.jks文件） 和pepk.jar解压至JDK的bin目录。
4. 运行cmd命令打开命令行窗口，进入JDK的bin目录，运行如下命令打包并加密签名密钥的签名文件。

   ```screen
   java -jar pepk.jar --keystore *sign-keystore.jks* --alias *sign* --output=*sign.zip* --*encryptionkey*=034200041E224EE22B45D19B23DB91BA9F52DE0A06513E03A5821409B34976FDEED6E0A47DBA48CC249DD93734A6C5D9A0F43461F9E140F278A5D2860846C2CF5D2C3C02 --include-cert
   ```

   命令中斜体加粗的内容需替换为实际的值，其中：
   * ***sign-keystore.jks***：签名密钥的签名文件。
   * ***sign***：签名文件的别名。
   * ***sign.zip***：打包生成的签名密钥zip包。
   * ***encryptionkey***：加密使用的公钥，请使用命令中固定的公钥。
5. 点击"浏览"，选择步骤[4](#ZH-CN_TOPIC_0000001052418290__li146852169817)生成的zip包。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251011134002.13621826139807626228042718732603:50001231000000:2800:2E721B7158D30332CE077EBE7BF1F42249114641D535793EDF5B65DBB14DC61F.png)
   > 说明
   >
   > 以下步骤6~8为可选步骤。为了更高的安全性，您如果需要使用不同于签名密钥的上传密钥，可以手动上传您新生成的上传密钥。如不上传，AGC将默认使用您上传的签名密钥作为上传密钥来验证您的身份信息。
6. 生成包含上传密钥的签名文件，上传密钥需不同于签名密钥。
7. 运行cmd命令打开命令行窗口，进入JDK所在的bin目录，运行如下命令，为新生成的上传密钥生成密钥证书 (PEM 格式)。

   ```screen
   keytool -export -rfc -keystore *upload-keystore.jks* -alias *upload* -file *upload_certificate.pem*
   ```

   命令中斜体加粗的内容需替换为实际的值，其中：
   * ***upload-keystore.jks***：上传密钥所在的签名文件。
   * ***upload***：签名文件的别名。
   * ***upload_certificate.pem***：生成的上传密钥证书。
8. 点击"展开"，再点击"浏览"选择上传密钥证书。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251011134002.45847568758025243695678475209218:50001231000000:2800:C62347E5985C0389F910D592361E2B3427DF0A700552554F26B2E3B171E2CBD1.png)

9. 点击右上角的"提交"将相关文件提交至AGC。 AGC会按如下顺序对上传的签名密钥进行校验，校验通过才可成功提交。

   1. 校验AGC是否支持签名密钥的加密算法和密钥长度。如果不支持，则提示"上传的应用签名密钥系统暂不支持，请重新上传。" AGC支持的加密算法和密钥长度详见[使用限制](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-appsigning-restriction-0000001051618335)。


   2. 校验签名密钥是否为配对的公私钥。如果公私钥不匹配，则提示"上传的应用签名密钥验证错误，请重新上传"。

### 配置重新生成的证书指纹

使用应用签名服务后，AGC会根据签名密钥重新生成证书指纹，可能不同于您开发应用时本地生成的签名证书指纹。如您的应用当前集成的华为相关服务需依赖SHA256证书指纹，您还需为应用添加重签名后的SHA256证书指纹。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"APP与元服务"。
2. 选择"Android"页签，点击您的应用，进入"分发"页签，选择"服务 > 应用签名"。
3. 在应用签名页面，点击"应用签名证书"栏的![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251011134002.26366138005469904150939368703664:50001231000000:2800:B45C803DB5DBE11441CBA949E84840D68E5AEB46DCB9FFEC992669E4E678E881.png "点击放大")，复制SHA256证书指纹。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251011134003.44024090396332173016851013584919:50001231000000:2800:418CF940E36431B3C4F582A4A94FC5FCE25D509A84856A15528FCB974B087741.png)
4. 进入"开发与服务 > 项目设置 > 常规 > 应用"，在"SHA256证书指纹"栏点击"添加证书指纹"，粘贴输入复制的SHA256证书指纹，点击"保存"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251011134003.19851322228398538278451564657595:50001231000000:2800:35FF00E33A4474F888B4DD698F51FC9B480A60AD4B44D3498DDA8A480E039E0E.png)

### 发布应用

1. 使用上传密钥对应用软件包签名，并上传软件包到AGC。AGC会通过您提交的上传密钥证书来验证您的身份信息，验证通过后AGC会使用您提交的签名密钥对应用重新签名。如果您未提交上传密钥证书，AGC将默认使用您上传的签名密钥作为上传密钥来验证您的身份信息。 重签名需要消耗几分钟时间，请耐心等待。

2. 将应用发布信息补充完整，发布应用。
