# QQ

您可以在应用中集成QQ认证方式，让您的用户可以使用自己的QQ账号进行AppGallery Connect身份验证。

## 前提条件

* 您需要在AGC控制台[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-integration-sdk-0000001325876845)。

## 开发步骤

认证服务提供了两种开发方式接入QQ账号：

* 推荐您使用新的统一登录接入方式，请参见[统一登录接入方式](#section3139114174911)。
* 同时为了兼容性保留了老的传统接入方式，请参见[传统接入方式](#section1388515146504)。

### 统一登录接入方式

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143816.89012624420202719241872012142362:50001231000000:2800:967AEB38C423BF7B7290E2C21625EB325DEA874A1192AC26E13E9B78C50600E0.png "点击放大")

1. 添加SDK依赖。
   * Android Studio开发环境
     * Version Catalog方式管理依赖
       1. 打开Android Studio项目级gradle目录下的"libs.versions.toml"文件，在[versions]中声明QQ SDK版本号。

          ```screen
          [versions]
          qqVersion = "3.52.0"  # 以3.52.0为例
          ```

       2. 在"libs.versions.toml"文件的[libraries]中声明华为认证SDK和QQ SDK。

          ```screen
          [libraries]
          agconnect-auth-qq = { module = "com.huawei.agconnect:agconnect-auth-qq", version.ref = "agcVersion" }  # agcVersion声明请参见https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-integration-sdk-0000001325876845#section99221941185719。
          qq-sdk = { module = "com.tencent.tauth:qqopensdk", version.ref = "qqVersion" }
          ```

       3. 在应用级"build.gradle"文件的"dependencies"中添加华为认证SDK和QQ SDK的编译依赖。

          ```screen
          dependencies {      
               implementation libs.agconnect.auth.qq
               implementation libs.qq.sdk
          }
          ```

     * 非Version Catalog方式管理依赖 打开应用级gradle文件（通常在app/build.gradle），在"dependencies"中添加华为认证SDK和QQ SDK的编译依赖：

       ```screen
       dependencies {
           implementation "com.huawei.agconnect:agconnect-auth-qq:1.9.4.300"     
           implementation "com.tencent.tauth:qqopensdk:{version}"
       }
       ```

   * Eclipse开发环境

     打开aar2eclipse/aar目录下的build.gradle文件， 在"dependencies"中添加华为认证SDK和QQ SDK的编译依赖。具体步骤参见[Eclipse开发环境集成AGC SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-integration-sdk-0000001325876845#section1878849165620)。

     ```screen
     dependencies {
         embed "com.huawei.agconnect:agconnect-auth-qq:1.9.4.300"
         embed "com.tencent.tauth:qqopensdk:{version}"
     }
     ```

   > 说明
   > * 示例中的*qqVersion* 和*{version}*请替换为QQ SDK的最新版本号，华为不负责更新。
   > * 由于华为未提供QQ SDK依赖包，您可以在腾讯开放平台下载最新版本的QQ SDK依赖包进行手动集成。
2. 设置QQ账号登录所需参数。 在登录之前，调用设置参数接口，设置QQ账号登录所需要的参数。

   /qq/appId：在腾讯开放平台申请的appId。

   ```screen
   "Java"
   AGConnectApi.getInstance().getOptions().setOption("/qq/appId", "your qq appId");
   ```

   ```screen
   "Kotlin"
   AGConnectApi.getInstance().getOptions().setOption("/qq/appId", "your qq appId")
   ```

3. 添加生命周期回调，请参见[统一登录调用页面回调](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-unified-login-0000001325756981)。
4. 调用[AGConnectAuth.signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauth-0000001054482530#section125666562219)，登录QQ账号。

   ```screen
   "Java"
   AGConnectAuth.getInstance().signIn(this,AGConnectAuthCredential.QQ_Provider).addOnSuccessListener(new OnSuccessListener<SignInResult>() {
           @Override
           public void onSuccess(SignInResult signInResult) {
                   // onSuccess
                   AGConnectUser user =  signInResult.getUser();
           }
   })
   .addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
                   // onFail
           }
   });
   ```

   ```screen
   "Kotlin"
   AGConnectAuth.getInstance().signIn(this, AGConnectAuthCredential.QQ_Provider).addOnSuccessListener {
       // updateUI
   }.addOnFailureListener {
       // onFailure
   }
   ```

### 传统接入方式

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143816.21043661735930731337134930142471:50001231000000:2800:0B52E85B3CEE545DD413E374374C4D33963D43961F5AD3038E67F6F59AA50785.png "点击放大")

1. 在应用的登录界面，初始化[AGConnectAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauth-0000001054482530)实例，获取AGC的用户信息，检查是否有已经登录的用户。如果有则可以直接进入用户界面，否则显示登录界面。

   ```screen
   "Java"
   AGConnectUser user = AGConnectAuth.getInstance().getCurrentUser();
   ```

   ```screen
   "Kotlin"
   val user = AGConnectAuth.getInstance().currentUser
   ```

2. QQ账号登录，并获取QQ账号的用户授权信息。 说明
   >
   > 此步骤仅供参考，更详细内容，请参见[QQ官方文档](https://wiki.connect.qq.com/qq登录)。
   1. 配置在QQ开发者平台申请的APPID。

      ```screen
      "Java"
      mTencent = Tencent.createInstance(APP_ID, this.getApplicationContext());
      mTencent.login(this, "all", this);
      ```

   2. 在IUiListener回调中获取授权登录后的accessToken和openId，用于传入AGConnect SDK。

      ```screen
      "Java"
      @Override
       public void onComplete(Object o) {
           JSONObject jsonObject = (JSONObject) o;
           String accessToken = jsonObject.optString("access_token");
           String openId = jsonObject.optString("openid");
       }

       @Override
       public void onError(UiError uiError) {
       }

       @Override
       public void onCancel() {
       }
      ```

   3. 添加授权确认后的回调。

      ```screen
      "Java"
      @Override
       protected void onActivityResult(int requestCode, int resultCode, Intent data) {
           super.onActivityResult(requestCode, resultCode, data);
           if (mTencent != null) {
               mTencent.onActivityResultData(requestCode, resultCode, data, this);
           }
       }
      ```

3. 调用[QQAuthProvider.credentialWithToken](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/qqauthprovider-0000001054163798#section15903782212)使用从QQ账号获取的accessToken和openId生成credential，并调用[AGConnectAuth.signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauth-0000001054482530#section298148131715)实现登录。

   ```screen
   "Java"
   AGConnectAuthCredential credential = QQAuthProvider.credentialWithToken(accessToken, openId);
   AGConnectAuth.getInstance().signIn(credential)
       .addOnSuccessListener(new OnSuccessListener<SignInResult>() {
           @Override
           public void onSuccess(SignInResult signInResult) {
               // onSuccess
               AGConnectUser user = signInResult.getUser();
           }
       })
       .addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
               // onFail
           }
       });
   ```

   ```screen
   "Kotlin"
   val credential = QQAuthProvider.credentialWithToken(accessToken, openId)
   AGConnectAuth.getInstance().signIn(credential).addOnSuccessListener {
       // onSuccess
       val user = it.user
   }.addOnFailureListener {
        // onFail
   }
   ```

## 更多信息

* 您如果想让用户可以使用多个账号登录您的应用，可以将多个[账号进行关联](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-associated-0000001053692650)。
* 当用户不需要使用应用，或者需要切换其他账号登录认证，可以先执行[登出](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-sign-out-0000001053612647)。
* 当用户需要注销当前用户，可以进行[销户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-deleteuser-0000001057730521)。
* 对于销户、修改密码、关联账号以及重置手机账号和邮箱账号等敏感操作，为了提高安全性，需要用户必须在5分钟内登录过才能执行。如果用户执行敏感操作时登录超过5分钟，需要[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-reauthenticate-0000001127287737)后再执行敏感操作。
* 您可以参考[异常处理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-troubleshooting-0000001052932665)实现自己的异常处理机制，从而减少异常情况的发生。
* 您可以使用云函数触发器来接收用户注册、登录、销户等关键事件，从而[扩展认证服务的能力](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-extension-0000001053372708)。
* 您可以参考[管理用户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-user-manage-0000001606051705)对用户进行解锁、停用等操作。
