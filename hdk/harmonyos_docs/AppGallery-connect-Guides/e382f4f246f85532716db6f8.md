# 总览查看

总览趋势图展示了您的项目在最近3天内TOP 10的热Key、慢Key、大Key信息。您可以实时分析、优化Key，避免热Key、慢Key和大Key对您的业务产生影响。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中选择您的项目。
3. 在左侧导航栏选择"云开发（Serverless） > 云缓存"，点击"总览"页签。
4. 点击右上角选择时间段（近15分钟、近1小时、近1天或者指定时间），查询热Key、慢Key、大Key信息。 热Key：查询一秒内访问量超过200次的Key。

   慢Key：查询操作耗时超过1000ms的Key。

   大Key：查询String类型长度大于5000的Key，或者其他类型元素大于200的Key。
