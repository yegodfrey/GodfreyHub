# 查询频道信息

订阅频道的过程中，如需查看指定频道的详细信息，如订阅玩家数量、玩家信息（RTM连接状态、属性等），可通过查询频道信息获取。

## 前提条件

* 您已[集成游戏多媒体基础SDK和实时信令模块](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-integratingsdk-android-0000001250838246#ZH-CN_TOPIC_0000001250838246__li733912204487)。
* 您已[创建游戏多媒体实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-engine-android-0000001193958984#section1093713161034)。

## 开发步骤

1. 调用[GameMediaEngine.getRtmChannelInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section7319193618574)方法，查询频道信息，例如指定频道的用户列表。

   ```screen
   GetRtmChannelInfoReq req = new GetRtmChannelInfoReq();
   req.setChannelId("579457***95");
   req.setReturnMembers(true);
   mHwRtcEngine.getRtmChannelInfo(req);
   ```

2. 在IGameMMEEventHandler接口的[onGetRtmChannelInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section348500125813)回调方法中，可以获取频道信息的查询结果。

   ```screen
   @Override
   public void onGetRtmChannelInfo(GetRtmChannelInfoResult result) {
     // 可根据需求将数据进行处理
   }
   ```
