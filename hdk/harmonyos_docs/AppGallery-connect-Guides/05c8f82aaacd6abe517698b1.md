# 使用限制

在多线程游戏中使用API时，API函数存在如下限制：

* 一部分函数由于图形API限制，必须在渲染线程中调用。
* 另一部分函数则不必须在渲染线程中调用，但必须保持外部同步------即可从不同的线程访问库实例，但不能同时访问。

|函数|限制|
|:--------------------------------------------------------------------|:--------------------|
|FrameFlow_Create / FrameFlowVK_Create|必须在渲染线程中调用。|
|FrameFlow_Destroy / FrameFlowVK_Destroy|必须在渲染线程中调用。|
|FrameFlow_SetPredictionAlgorithm / FrameFlowVK_SetPredictionAlgorithm|必须在渲染线程中调用。|
|FrameFlowVK_SetInputDescription|必须在渲染线程中调用。|
|FrameFlow_SetCvvZSemantic / FrameFlowVK_SetCvvZSemantic|必须在渲染线程中调用。|
|FrameFlow_SetStencilRemapInfo / FrameFlowVK_SetStencilRemapInfo|必须在渲染线程中调用。|
|FrameFlow_SetResolution|必须在渲染线程中调用。|
|FrameFlowVK_RegisterImage|必须在渲染线程中调用。|
|FrameFlowVK_UnregisterImage|必须在渲染线程中调用。|
|FrameFlow_Activate / FrameFlowVK_Activate|必须在渲染线程中调用。|
|FrameFlow_Deactive / FrameFlowVK_Deactivate|必须在渲染线程中调用。|
|FrameFlow_IsActive / FrameFlowVK_IsActive|必须在渲染线程中调用。|
|FrameFlow_ProvidePerFrameData / FrameFlowVK_ProvidePerFrameData|必须在渲染线程中调用。|
|FrameFlow_GrabPerFrameData|必须在渲染线程中调用。|
|FrameFlow_DrawFrame / FrameFlowVK_DrawFrame|必须在渲染线程中调用。|
|FrameFlow_GetCapabilitiesInfo / FrameFlowVK_GetCapabilitiesInfo|无需在渲染线程中调用，可以从任何线程调用。|
