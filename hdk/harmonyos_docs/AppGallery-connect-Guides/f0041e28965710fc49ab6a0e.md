# 销户

## 前提条件

* 您需要在AGC控制台[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyos-integration-sdk-0000001327194257)。

## 开发步骤

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251226181007.11017246019716992054487489481234:50001231000000:2800:7E2F7DDA9055E00BAEE529664B89EAC12CAC244536E9612DA9FFD784E7A85B97.png "点击放大")

当用户不再使用应用，可以注销当前用户。您需要调用[AGConnectAuth.deleteUser](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-java-agconnectauth-0000001151371572#section154883587214)实现该功能，用户一旦被注销，将会删除服务端侧的用户信息同时清空客户端侧用户信息和Token。

```screen
"Java"
AGConnectAuth.getInstance().deleteUser();
```

> 说明
>
> 对于销户操作，要求用户必须在5分钟内登录过才能执行。若已超时，请参见[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyos-reauthenticate-0000001151370312)先完成重认证。
