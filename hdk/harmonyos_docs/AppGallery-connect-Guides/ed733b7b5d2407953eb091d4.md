# 下载文件

文件已经上传到云端后，您可以通过调用云存储SDK的API将云端文件下载到本地设备中。  

#### 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[创建File对象](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-createreference-nodejs-0000001055327465#section17165283611)。  

#### 操作步骤

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240821163324.49430320202666600991175911868725:50001231000000:2800:5B7C3D946B17484FBB7C7C186DB7E799FD9A6D5E8CC64C2694213101AD3DC65D.png?needInitFileName=true?needInitFileName=true)  
在下载文件前，您可以先[获取文件的元数据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-metadata-nodejs-0000001054848921#ZH-CN_TOPIC_0000001054848921__li6366536417)，查看后再决定是否要下载文件。

1. 创建需要下载文件的[File](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/file-0000001056171313)实例。

   ```
   const remoteFile = bucket.file('images/demo.jpg');
   ```

2. 在本地设备中创建文件。

   ```
   const localFile = './images/demo.jpg';
   ```

3. 调用[File.createReadStream](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/file-0000001056171313#section889115301513)方法将云端文件数据写入本地文件中。

   ```
   var fs = require('fs');
   remoteFile.createReadStream()
       .on('error', (err) => {})
       .on('end', () => {})
       .pipe(fs.createWriteStream(localFile));
   ```

#### 更多信息

除了在应用客户端通过云存储SDK的API来下载文件，您还可以直接[在AGC控制台以可视化的方式来下载文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-manage-file-0000001281134398#section116002011710)。
