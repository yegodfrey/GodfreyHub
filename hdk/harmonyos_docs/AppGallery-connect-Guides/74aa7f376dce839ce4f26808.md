# 部署云数据库

## 创建端云一体化开发工程

使用DevEco Studio端云一体化开发工程可以实现云函数调用云数据库。

请先参考"[在DevEco Studio中创建端云一体化开发工程](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V5/agc-harmonyos-clouddev-devproject-V5)"完成基本准备工作，再进行以下开发活动。

进入主开发界面，查看新建的云开发工程CloudProgram，工程目录结构如下图所示。

您可以删除云数据库数据条目目录（dataentry）和对象类型目录（objecttype）中预置的示例文件和云函数目录（cloudfunctions）中预置的示例函数"id-generator"。

## 创建对象类型

1. 右击"clouddb/objecttype"目录，选择"New > Cloud DB Object Type"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250305155928.51203350770432769791654113512819:50001231000000:2800:7A2B250F3148830A8190BB0B24430170FB978463A710F91B34F2F209CDDFE3BD.png?needInitFileName=true?needInitFileName=true)

2. 输入对象类型名称（下文以"BookInfo"为例）后，点击"OK"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250305155928.31758603737644445501043421504535:50001231000000:2800:4CA5DD622921306CB29F3C341827AC06F01F1B30BBE13F81659D72FD6055FA59.png?needInitFileName=true?needInitFileName=true)

3. "clouddb/objecttype"目录下生成并打开新建的对象类型JSON文件"BookInfo.json"，为"BookInfo"对象类型配置如下字段、索引和权限。

   ```screen
   {
     "objectTypeName": "BookInfo",
     "fields": [
       {"fieldName": "id", "fieldType": "Integer", "notNull": true, "belongPrimaryKey": true},
       {"fieldName": "bookName", "fieldType": "String"},
       {"fieldName": "author", "fieldType": "String"},
       {"fieldName": "price", "fieldType": "Double"},
       {"fieldName": "shadowFlag", "fieldType": "Boolean", "defaultValue": true}
     ],
     "indexes": [
       {"indexName": "id_Index", "indexList": [{"fieldName":"id","sortType":"ASC"}]},
       {"indexName": "price_Index", "indexList": [{"fieldName":"price","sortType":"DESC"}]}
     ],
     "permissions": [
       {"role": "World", "rights": ["Read"]},
       {"role": "Authenticated", "rights": ["Read", "Upsert"]},
       {"role": "Creator", "rights": ["Read", "Upsert", "Delete"]},
       {"role": "Administrator", "rights": ["Read", "Upsert", "Delete"]}
     ]
   }
   ```

## 添加数据条目

创建完对象类型后，您可在对象类型内添加数据条目（dataentry），并配置数据所在的存储区。

1. 右击对象类型JSON文件，选择"Generate Data Entry"。 依旧以对象类型"BookInfo"为例，其包含了"id"、"bookName"、"author"、"price"、"shadowFlag"五个字段。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250305155928.33409429305978633697801884696505:50001231000000:2800:7C08927BA0E42BC66AEE8EFB34BFF608EFD4B72E07782F46B6D0E0AAED56AFA4.png?needInitFileName=true?needInitFileName=true)
2. 在弹出的"New Cloud DB Data Entry"框内，为即将生成的数据条目文件定义名称。此处取默认值"d_BookInfo"为例。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250305155928.98014703376831282790823561643166:50001231000000:2800:A49561A5673713931D12E809C8A34A716CDC8E37F91851E4B8E90FC6F49A64C1.png?needInitFileName=true?needInitFileName=true)

3. "clouddb/dataentry"目录下自动为对象类型"BookInfo"生成数据条目文件"d_BookInfo"，该文件中已为您预置好所属对象类型名称（"BookInfo"）与对象类型的字段名（"id"、"bookName"、"author"、"price"、"shadowFlag"）。 您需要配置存储区cloudDBZoneName和字段的值objects（即数据）。

   ```screen
   {
     "cloudDBZoneName": "QuickStartDemo",
     "objectTypeName": "BookInfo",
     "objects": [
       {
         "id": 10,
         "bookName": "First Book",
         "author": "Nancy",
         "price": 10.5,
         "shadowFlag": true
       },
       {
         "id": 20,
         "bookName": "Second Book",
         "author": "Peter",
         "price": 20.5,
         "shadowFlag": true
       }
     ]
   }
   ```

## 部署云数据库

完成数据条目创建后，您可以直接部署该数据条目。您也可以等所有对象类型和数据条目开发完成后，再统一批量部署到AGC云端。

1. 右击"clouddb"目录，选择"Deploy Cloud DB"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250305155928.23163336107659965328800761617759:50001231000000:2800:A448EB7204651C517148097A92B4865AE957CFE7D6D2C076F7C1B2B8F9304FF9.png?needInitFileName=true?needInitFileName=true)

2. 您可在底部状态栏右侧查看云数据库打包与部署进度。 请您耐心等待，直至出现"Deploy successfully"消息，表示云数据库已成功部署。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250305155928.58983835399426182063651473336457:50001231000000:2800:8ACD710C13015FA863B8CADB6BCC883E641F3CFED98FD9EF6D8C387D98B44777.png?needInitFileName=true?needInitFileName=true)
