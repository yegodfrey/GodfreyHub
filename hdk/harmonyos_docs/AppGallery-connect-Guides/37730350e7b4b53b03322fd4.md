# 业务介绍

渠道包是通过物理分包的方式来做渠道效果归因的方法。渠道包与在应用市场上架的主包包名一致，只是开发者可以基于不同的分发渠道在包内预置上不同的渠道号，并在不同的渠道上进行投放，同时使用应用市场的下载能力，以达到归因和高转化率分发的目的。

渠道包支持主包的多包形态，多包的区分维度包括：CPU架构（32/64位）、屏幕密度/尺寸和HMS/GMS依赖。
> 注意
>
> * 权限开通后需应用在华为应用市场上架后才可以使用渠道包功能，发布应用请参见[发布应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-releaseapkrpk-0000001106463276)。
> * 渠道包打包要求请参考[使用限制](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/channel-commonpkg-restrict-0000001134003640)。
> * 目前**极小渠道包功能** 和**测试渠道包功能**暂停开通申请，您如果疑问可以联系华为运营咨询。
