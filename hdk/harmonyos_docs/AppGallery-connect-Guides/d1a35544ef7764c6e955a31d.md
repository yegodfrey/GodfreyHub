# 概述

本章节介绍的orb插件可以通过调用AppGallery Connect接口发送HTTP请求，把CircleCI CI/CD实例中的Android应用软件包（APK或是AAB）快速上传至应用市场。

使用之前，请确保您已安装了jq解析器，且该插件的CI/CD管道运行畅通。

## 主要功能

以下依次列出了通过orb插件实现Android应用软件包的上传和部署流程及其描述。

|主要功能|描述|
|:-------------|:--------------------------------------|
|上传Android应用软件包|新增Android应用，并将软件包上传至AppGallery Connect。|
|修改应用信息|把新增的Android应用添加到AppGallery Connect项目中。|
|发布应用|把新版本同步至应用市场，供用户下载。|

## 术语

|名称|描述|
|:----|:---------------------------------------------|
|orb插件|CircleCI orb类似于插件，是一种开源可共享配置组件包，具有可参数化、可重用的特点。|
