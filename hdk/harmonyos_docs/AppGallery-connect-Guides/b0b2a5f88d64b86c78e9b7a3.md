# 开发流程

![](https://media:201785482646112483 "点击放大")  

|序号|任务|说明|
|:-|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------|
|1|[创建项目与应用](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-createapp-0000001326569825)|项目是您在AppGallery Connect（以下简称AGC）资源的组织实体，您可以将一个应用的不同平台版本添加到同一个项目中。|
|2|[开通服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-enableservice-0000001326330021)|-|
|3|[获取agconnect-services.json文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-obtain-files-0000001281093660#section1791241912377)|-|
|4|[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-integratesdk-android-0000001275810158)|使用Android Studio或者Eclipse集成AGC SDK以及崩溃SDK。|
|5|[（可选）集成NDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-integratendk-android-0000001280639012)|您如果使用了原生库，需要集成崩溃NDK。|
|6|[测试崩溃实现](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-test-0000001055420516)|您可以在测试应用时调用崩溃服务SDK的API手动制造一个崩溃，然后在AGC上查看崩溃上报情况，以测试崩溃服务是否正常运行。|
|7|[分析崩溃问题](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-locate-0000001055140557)|在发生崩溃后，崩溃服务会将崩溃数据上报到AGC，您可以在AGC中查看崩溃问题的详细信息，分析崩溃发生的原因。|
|8|获取更多崩溃信息： * [自定义崩溃报告](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-customreport-0000001055740502) * [获取NDK崩溃报告](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-report-0000001054980565) * [获取经过反混淆处理的崩溃报告](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-mapping-0000001055420529)|有些崩溃问题无法通过常规的崩溃信息快速定位，需要获取更详细的信息： * 对崩溃报告中的用户标识符、日志、键值对进行自定义。 * 应用使用了原生库，可以获取NDK崩溃报告。 * 当代码中有信息被混淆处理后，可以获取经过反混淆处理的崩溃报告。|
|9|获取异常报告： * [获取严重异常报告](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-fatalexceptions-0000001380782657) * [获取非严重异常报告](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-crash-nonfatalexceptions-0000001058395504)|AGC会记录非严重和严重两类异常，您可以监控分析这些异常，从而提高代码质量。|
