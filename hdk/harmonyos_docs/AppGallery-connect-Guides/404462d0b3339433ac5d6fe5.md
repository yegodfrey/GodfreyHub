# 获取云端配置项

## 前提条件

* 您已在AGC控制台[设置云端配置项](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-remoteconfig-web-cloudconfig-0000001056699160)。
* 您需要在您的应用中[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-remoteconfig-web-integration-sdk-0000001056501223)。

## 获取和更新云端参数值到本地

从远程配置服务获取参数值使用[fetch](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/web-remoteconfig-agconnectconfig-0000001057269353#section1176012013115)接口，如果您在云端设置了过滤条件"应用版本"，则在使用fetch接口前需要确保已设置应用版本号，设置您的Web应用版本号方式如下。

```screen
agconnect.instance().setAppVersion('1.0.0')
```

fetch成功后会返回从云端同步的数据，再通过调用[apply](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/web-remoteconfig-agconnectconfig-0000001057269353#section486198212)接口使云端同步获取的值生效。

您可以在获取成功后立刻调用更新生效，也可以根据业务在其他时间段生效。

* 获取数据后立刻生效：

  ```screen
  agconnect.remoteConfig().fetch().then(() => {
      return agconnect.remoteConfig().apply();
    }).catch((err) => {
      return Promise.reject(err);
  });
  ```


* 获取数据后自行设置生效：

  ```screen
  //调用fetch接口获取云端数据
  agconnect.remoteConfig().fetch().then(() => {
      return Promise.resolve();    
    }).catch((err) => {
      return Promise.reject(err);    
    });

  // 在需要云端数据生效时，可自行调用apply接口
  agconnect.remoteConfig().apply().then((res) => {
      return Promise.resolve(res);    
    }).catch((err) => {
      return Promise.reject(err);    
    });
  ```


* 获取数据后下次启动生效(在Web应用仅适用于IndexedDB存储模式下)： 您可以在任何时候获取数据，但是此次运行并不使其生效，在下次应用启动时，使上次拉取的数据生效。

  ```screen
  agconnect.remoteConfig().loadLastFetched().then(async (res) => {
  if (res) {
  await agconnect.remoteConfig().apply(res);    
  }
  return Promise.resolve();  
  }).catch(error => {
  return Promise.reject(err);
  });
  ```

> 说明
>
> [fetch](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/web-remoteconfig-agconnectconfig-0000001057269353#section1176012013115)接口默认更新周期为12小时，在更新成功后的周期内，则会直接使用缓存数据。在更新周期内再次调用fetch接口不会去云侧同步数据，而是使用本地缓存数据直接返回。更新间隔周期单位为毫秒，在调测阶段可以设置为0，方便调测，在实际生产阶段建议设置较大值，防止受到流控限制。

您也可以自行设置更新间隔周期，方法如下：

```screen
agconnect.remoteConfig().minFetchIntervalMillis = 60000; // 设置更新间隔周期为1分钟
```

fetch请求超时时间默认为1分钟，可以通过如下方式设置自定义时间（毫秒）。

```screen
agconnect.remoteConfig().fetchReqTimeoutMillis = 30000;// 设置fetch请求超时时间为30秒
```

## 获取参数值

在设置默认值和更新云端参数值后，您可以调用接口通过键值来获取参数进行使用。云端键值（key）、参数（value）与AGC界面配置的对应关系：

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221028100053.38221518129281904171356201718893:50001231000000:2800:DEE40DB68ADD7740A7965EB22F4AE5326201FF8FFC8DAA5E55209D12278DBDE0.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

远程配置SDK 提供了3种数据类型的接口，您可根据需求进行使用。

* [getValueAsBoolean](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/web-remoteconfig-agconnectconfig-0000001057269353#section678915454115)：获取boolean类型参数值。 说明
  >
  > boolean类型true 支持的字符串有"1"、"true"、"t"、"yes"、"y"、"on"。boolean类型 false支持的字符串有"0"、"false"、"f"、"no"、"n"、"off"，不区分大小写。

  ```screen
  agconnect.remoteConfig().getValueAsBoolean(key);
  ```

* [getValueAsNumber](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/web-remoteconfig-agconnectconfig-0000001057269353#section195349553113)：获取number类型参数值。

  ```screen
  agconnect.remoteConfig().getValueAsNumber(key);
  ```

* [getValueAsString](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/web-remoteconfig-agconnectconfig-0000001057269353#section322118160215)：获取string类型参数值。

  ```screen
  agconnect.remoteConfig().getValueAsString(key);
  ```

云端设置的参数值实际存储时都是字符串类型，在获取具体类型时进行转换，如果转换失败则返回类型默认值。

* boolean类型默认值为： false
* number类型默认值为： 0
* string类型默认值为： ''

## 获取参数值的来源

您可以通过调用[getSource](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/web-remoteconfig-configvalue-0000001058109362#section578016104015)来获取参数值的来源。数据可能有如下三种来源：

* 'static'：类型默认值

* 'default'：本地默认值

* 'remote'：从云端获取的值

```screen
agconnect.remoteConfig().getValue(key).getSource();
```

## 获取全部参数值

您可以获取调用[getMergedAll](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/web-remoteconfig-agconnectconfig-0000001057269353#section743811341720)一次性获取全部本地默认值和云端参数值，而不是通过键值来读取，相同键值的参数会使用云端数据。

```screen
agconnect.remoteConfig().getMergedAll();
```

## 重置参数值

您可以调用[clearAll](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/web-remoteconfig-agconnectconfig-0000001057269353#section1490195131811)清空之前所有的缓存数据，包括设置的默认值、云端参数值。

```screen
agconnect.remoteConfig().clearAll();
```
