# 业务介绍

测试渠道包是应用市场提供给开发者做差异化包体测试的一项高阶服务。开发者可以利用应用市场短期内积累的大量新用户，来测试不同包体对分发带来的影响。测试场景包括但不限于：新功能的A/B测试，包体体积上限的A/B测试。
> 注意
>
> * 权限开通后需应用在华为应用市场上架后才可以使用渠道包功能，发布应用请参见[发布应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-releaseapkrpk-0000001106463276)。
> * 渠道包打包要求请参考[使用限制](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/channel-testpkg-restrict-0000001254489465)。
