# 远程配置触发器

利用云函数服务提供的远程配置后台函数触发功能，您可以实时使用AGC远程配置服务更新动态。实现该功能，您首先需要创建一个或多个函数，以及添加相应的远程配置触发器。当您的远程配置服务实现发布或者回滚功能时，远程配置触发器将触发对应函数。该函数将发送Push消息，从而通知客户端需要去云端重新获取最新的配置信息。  

#### 前提条件

您已[创建函数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/serverless-create-and-config-func-0000001713008121)。  

#### 创建远程配置触发器

1. 在函数列表中点击函数名称进入函数详情页面。如果点击函数名称右侧"操作"列的"别名"，则在别名列表中点击别名名称，进入别名详情页。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251205152527.49325058303944061977056041719752:50001231000000:2800:A674298A2F38FDAE8BB8E19111086B29FD2C8DDCE000C404671C3532E849DE69.png)

2. 点击"触发器"页签下的"添加触发器"，显示触发器创建界面。
3. 在"添加触发器"页面，"触发器类型"选择"远程配置触发器"，并配置"事件源"和"事件类型"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251205152527.30431901571081118717161450811368:50001231000000:2800:BD87CC76350C677A150DA5287D4DDF0BC3F96EF23AB716EE5D7BF01471F8B7AF.png)

   |参数|说明|
   |:----|:---------------------------|
   |触发器类型|远程配置触发器。|
   |事件类型|触发器支持的事件类型。远程配置触发器目前仅支持更新事件。|

4. 触发器配置完成后点击"确定"保存触发器，则回到触发器列表，可看到远程配置触发器图框。
