# 绘制预测帧

在正确初始化（成功创建库实例）并提供所需的全部数据后，则可以进行绘制预测帧工作。  

#### 前提条件

* 已[创建库实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/predict-frame-create-instance-0000001580652660)。
* 已[设置主要参数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/predict-frame-set-frame-parameters-0000001630812045)。
* 已[提供每帧数据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/predict-frame-provideperframedata-0000001580812060)。  

#### 开发步骤

调用函数[FrameFlow_DrawFrame](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflow-drawframe-0000001838253713)绘制预测帧。

```
FFResult FrameFlow_DrawFrame(FFInstance instance, const FFDrawFrameInfo* pDrawInfo);
```
