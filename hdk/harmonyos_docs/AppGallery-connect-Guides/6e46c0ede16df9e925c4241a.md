# AGC控制台配置准备

#### 创建项目并添加应用

如果您尚未添加项目，请前往AppGallery Connect[创建项目](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createproject-0000001100334664)，并在项目下[添加应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createapk-0000001912873100)。  

#### 开通认证服务

"游戏排行榜"模板提供两种方式认证用户身份：

* 若您使用AGC认证服务进行认证，请[开通认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 若您自定义认证方式，无需开通认证服务。  

#### (可选)开通云函数服务

如果您尚未开通云函数服务，则在部署游戏排行榜模板前需要先开通云函数服务。具体请参见[开通云函数服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/preparations-android-0000001663966414#section6307195214294)。  

#### (可选)开通云数据库服务

如果您尚未开通云数据库服务，则在部署排行榜模板前需要先开通云数据库服务。具体请参见[开通云数据库服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-createfirstclouddb-0000001569588629#section379484118716)。
