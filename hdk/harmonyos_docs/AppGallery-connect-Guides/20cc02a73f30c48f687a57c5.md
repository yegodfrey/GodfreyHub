# 获取云端配置项

## 前提条件

* 您已在AGC控制台[设置云端配置项](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-remoteconfig-harmonyos-cloudconfig-0000001183768015)。
* 您需要在您的应用中[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-remoteconfig-harmonyos-integration-sdk-0000001139007220)。

## 获取和更新云端配置数据到本地

1. （可选）您可以通过[AGConnectConfig.setCustomAttributes](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/harmony-remoteconfig-agconnectconfig-0000001142408632#section1713619814117)接口设置自定义参数，[fetch](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/harmony-remoteconfig-agconnectconfig-0000001142408632#section1176012013115)接口中会自动带入自定义参数，您也可以通过[AGConnectConfig.getCustomAttributes](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/harmony-remoteconfig-agconnectconfig-0000001142408632#section4585193101812)获取自定义的参数。 说明
   >
   > 设置自定义参数要在使用fetch接口之前调用。

   ```screen
   "Java"
   Map map = new HashMap<>();
   map.put("custom key","custom value");
   map.put("key","value");
   ...
   AGConnectConfig.getInstance().setCustomAttributes(map);
   Map map = AGConnectConfig.getInstance().getCustomAttributes();
   ```

2. 从远程配置服务获取参数值使用[AGConnectConfig.fetch](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/harmony-remoteconfig-agconnectconfig-0000001142408632#section1176012013115)接口，返回异步Task任务。获取成功后会返回从云端同步的[ConfigValues](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/harmony-remoteconfig-configvalues-0000001188448375)数据（可通过此类只获取云端数据），再通过调用[AGConnectConfig.apply](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/harmony-remoteconfig-agconnectconfig-0000001142408632#section486198212)接口传入云端同步获取的值使其生效。

   ```screen
   "Java"
   config.fetch().addOnSuccessListener(new OnSuccessListener<ConfigValues>() {
       @Override
       public void onSuccess(ConfigValues configValues) {
           config.apply(configValues);
           //使用配置值
       }
   }).addOnFailureListener(new OnFailureListener() {
       @Override
       public void onFailure(Exception e) {
       }
   });
   ```

3. fetch接口可能会有网络延迟，导致apply接口未能将云端最新的数值传入，为了避免此情况，您可以先调用fetch接口，然后在需要传入云端数据的地方调用apply接口。如下示例代码中的config.loadLastFetched()即为之前通过fetch接口已经获取的信息。

   ```screen
   "Java"
   ConfigValues last = config.loadLastFetched();
   config.apply(last);
   ```

   > 说明
   >
   > [fetch()](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/harmony-remoteconfig-agconnectconfig-0000001142408632#section1176012013115)接口默认更新周期为 12 小时，[fetch(long intervalSeconds)](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/harmony-remoteconfig-agconnectconfig-0000001142408632#section412593515111)接口则可以自行设置更新周期，在更新周期内再次调用fetch接口不会去云侧同步数据，而是使用本地缓存数据直接返回。
   >
   > [fetch(long intervalSeconds)](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/harmony-remoteconfig-agconnectconfig-0000001142408632#section412593515111)间隔时间单位为秒，在调测阶段可以设置为0，方便调测，在实际生产阶段建议设置较大值，防止受到流控限制。

## 获取参数值

在设置默认值和更新云端参数值后，您可以调用接口通过键值来获取参数进行使用。云端键值（key）、参数（value）与AGC界面配置的对应关系：

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221028100103.91530686113364583726689580420696:50001231000000:2800:B72DFD59EAE715E3EAE474D42508C5A08F1831E0E7981A5F980C8C1F1DAB20D0.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

远程配置SDK 提供了5种数据类型的接口，您可根据需求进行使用。

* [getValueAsBoolean](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/harmony-remoteconfig-agconnectconfig-0000001142408632#section678915454115)：获取boolean类型参数值。 说明
  >
  > boolean类型true支持的字符串有"1"、"true"、"t"、"yes"、"y"、"on"。boolean类型false支持的字符串有"0"、"false"、"f"、"no"、"n"、"off"，不区分大小写。

  ```screen
  "Java"
  Boolean value = config.getValueAsBoolean("key");
  ```

* [getValueAsDouble](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/harmony-remoteconfig-agconnectconfig-0000001142408632#section195349553113)：获取double类型参数值。

  ```screen
  "Java"
  Double value = config.getValueAsDouble("key");
  ```

* [getValueAsLong](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/harmony-remoteconfig-agconnectconfig-0000001142408632#section20942551216)：获取long类型参数值。

  ```screen
  "Java"
  Long value = config.getValueAsLong("key");
  ```

* [getValueAsString](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/harmony-remoteconfig-agconnectconfig-0000001142408632#section322118160215)：获取String类型参数值。

  ```screen
  "Java"
  String value = config.getValueAsString("key");
  ```

* [getValueAsByteArray](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/harmony-remoteconfig-agconnectconfig-0000001142408632#section11870122513219)：获取byte数组类型参数值。

  ```screen
  "Java"
  byte[] value = config.getValueAsByteArray("key");
  ```

云端设置的参数值实际存储时都是字符串类型，在获取具体类型时进行转换，如果转换失败则返回类型默认值。

* DEFAULT.BOOLEAN_VALUE = false
* DEFAULT.DOUBLE_VALUE = 0.0
* DEFAULT.LONG_VALUE = 0L
* DEFAULT.STRING_VALUE = ""
* DEFAULT.BYTE_ARRAY_VALUE = new byte[0]

## 获取参数值的来源

您可以通过调用[AGConnectConfig.getSource](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/harmony-remoteconfig-agconnectconfig-0000001142408632#section42391041315)来获取参数值的来源。数据可能有如下三种来源：

* SOURCE.STATIC：类型默认值
* SOURCE.DEFAULT：本地默认值
* SOURCE.REMOTE：从云端获取的值

```screen
"Java"
AGConnectConfig.SOURCE source = config.getSource("key");
```

> 说明
>
> AppGallery Connect页面设置参数时若设置为SDK默认值，满足使用SDK默认值的条件时服务器就不会下发这个参数，取值使用本地默认值。

## 获取全部参数值

您可以调用[AGConnectConfig.getMergedAll](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/harmony-remoteconfig-agconnectconfig-0000001142408632#section743811341720)一次性获取全部本地默认值和云端参数值，而不是通过键值来读取，相同键值的参数会使用云端数据。

```screen
"Java"
Map<String,Object> map = config.getMergedAll();
```

## 重置参数值

您可以调用[AGConnectConfig.clearAll](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/harmony-remoteconfig-agconnectconfig-0000001142408632#section011016145315)清空之前所有的参数值，将设置的默认值、云端参数值全部都清除。

```screen
"Java"
config.clearAll();
```
