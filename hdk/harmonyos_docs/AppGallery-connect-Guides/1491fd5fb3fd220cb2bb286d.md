# 禁言其他玩家

在语音房间内，房主可禁言指定玩家。同时，还可以通过一键禁言房间内其他全部玩家，实现仅房主发言功能。如需取消对其他玩家的禁言，可通过解禁方式快速解除禁言限制。目前，仅小队房间支持禁言操作。

## 前提条件

* 房间为小队房间类型。
* 您为房主身份，且房间中已有其他玩家。

## 禁言/解禁指定玩家

房主可通过禁止指定玩家发言的功能，实现对房间内某个玩家的禁言限制。被禁言后，该玩家发出的语音将不会被房间内其他玩家接收到。同时，房主在进行禁言后，还可以通过解禁操作对被禁言玩家进行解除禁言。

1. 调用[HWPGMEngine.getInstance forbidPlayer:](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section162552911194)方法禁言/解禁房间内指定玩家语音。

   ```screen
   HWPGMEngine *pgmeEngine = [HWPGMEngine getInstance];
   int result = [pgmeEngine forbidPlayer:roomId openId:openId isForbidden:isForbidden]; // roomId：房间ID; openId：玩家ID; isForbidden：true表示禁言,false表示解禁
   ```

2. 当房主禁言/解禁房间内指定玩家时，可在HWPGMEngineDelegate接口的[onForbidPlayer](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section39406435810)方法中实现相关回调处理。

   ```screen
   - (void)onForbidPlayer:(NSString* _Nonnull) roomId openId:(NSString* _Nonnull)openId isForbidden:(BOOL)isForbidden code:(int)code msg:(NSString*)msg {
       // 可根据需求将数据进行处理
   }
   ```

   当房主成功禁言/解禁房间内指定玩家时，房间内其他所有玩家可通过HWPGMEngineDelegate接口的[onForbiddenByOwner](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section4768113185810)方法收到该事件的回调通知。

   ```screen
   - (void)onForbiddenByOwner:(NSString* _Nonnull)roomId openIds:(NSArray *)openIds isForbidden:isForbidden {
       // 可根据需求将数据进行处理
   }
   ```

## 禁言/解禁其他全部玩家

房主可通过禁止其他全部玩家发言的功能，实现对房间内其他全部玩家的禁言限制。其他全部玩家被禁言后，房间内仅支持房主一人发言。同时，房主在进行禁言后，还可以通过解禁操作对被禁言的其他全部玩家解除禁言。
> 说明
>
> 如果房主对房间设置了一键禁言，那么该房间就具备了禁言属性。此场景下仅房主可以发言，加入到该房间的新玩家也将会被禁言。

1. 调用[HWPGMEngine.getInstance forbidAllPlayers](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section5456791917)方法禁言/解禁房间内其他全部玩家。

   ```screen
   HWPGMEngine *pgmeEngine = [HWPGMEngine getInstance];
   [pgmeEngine forbidAllPlayers:roomId isForbidden:isForbidden];  // roomId：房间ID; isForbidden：true表示禁言,false表示解禁
   ```

2. 当房主禁言/解禁房间内其他全部玩家时，可在HWPGMEngineDelegate接口的[onForbidAllPlayers](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section186359516582)方法中实现相关回调处理。

   ```screen
   - (void)onForbidAllPlayer:(NSString* _Nonnull)roomId openIds:(NSArray *)openIds isForbidden:(BOOL)isForbidden code:(int)code msg:(NSString*)msg {
       // 可根据需求将数据进行处理
   }
   ```

   当房主成功禁言/解禁房间内其他全部玩家时，房间内其他所有玩家可通过HWPGMEngineDelegate接口的[onForbiddenByOwner](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section4768113185810)方法收到该事件的回调通知。

   ```screen
   - (void)onForbiddenByOwner:(NSString* _Nonnull)roomId openIds:(NSArray *)openIds isForbidden:(BOOL)isForbidden {
       // 可根据需求将数据进行处理
   }
   ```
