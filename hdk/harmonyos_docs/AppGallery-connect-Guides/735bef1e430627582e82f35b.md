# 了解规则

在大多数应用开发过程中，开发者通常需要进行大量的工作来解决身份验证和授权两大问题，如必须构建和维护多台服务器。而安全规则可以为您简化向用户授权和验证请求的工作，降低此类工作的复杂性。帮助您更加专注于构建良好的用户体验，无需管理基础架构或编写服务器端身份验证和授权代码。AGC云存储和安全规则的组合使用，可以帮助您的产品取得成功。

## 身份验证

在构建应用时，您经常需要确认用户的真实身份，而云存储安全规则为您提供了一种易于使用且安全的身份验证机制，只需要几行代码，就可以帮助您轻松实现对用户身份的有效性、真实性的验证。通过身份验证的用户，可以获得访问的权限。而未通过身份验证的用户，则会被限制对数据资源的访问。因此，建立一个有效可靠的身份验证机制，对于保障用户对数据的安全访问十分有必要。具体请参见[用户身份验证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-securityrules-userbasedsecurity-0000001055566792#section1117214372511)。

## 授权

授权是安全工作中的另一个重要方面。安全规则以简单明了的格式，允许您通过授权的方式，控制用户对特定路径下数据的访问方式。通过身份验证的用户，需要获得对指定资源的授权，才能实现对云存储中特定路径下文件的访问和操作。因此，建立一套安全高效的授权机制，可以满足对数据安全的保障工作。具体请参见[编写安全规则](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-securityrules-gettingstarted-0000001054766827#section112943584813)。
