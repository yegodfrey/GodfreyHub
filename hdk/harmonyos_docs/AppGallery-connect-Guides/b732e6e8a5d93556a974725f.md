# C#（小游戏）

## 前提条件

* 您已[下载游戏多媒体SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Library/gamemme-sdkdownload-csharp-minigame-0000001825274857)。
* 您已下载微信开发者工具。
* 您已下载快游戏开发者工具。

## 导出为微信小游戏

1. 使用Unity完成游戏多媒体功能开发后，[导出WebGL并转换为小游戏项目](https://github.com/wechat-miniprogram/minigame-unity-webgl-transform/blob/main/Design/Transform.md)。 注意
   >
   > 首次使用Unity导出WebGL并转换为小游戏项目前，需安装小游戏Unity适配插件。
2. 使用微信开发者工具导入该项目。 说明
   >
   > 游戏集成游戏多媒体SDK后，如需发布到微信小游戏平台，还必须进行服务器域名配置，跟指定的域名进行网络通信，具体域名请参见[FAQ](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-faq-0000001181618314#section192032673113)。
3. 将游戏多媒体SDK中的GMMEForMiniGames.js文件（获取路径：Plugins > js > GMMEForMiniGames.js）放在微信小游戏项目的根目录下。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250424164756.05214443110791812637807463051228:50001231000000:2800:D79F6B8F165CC1559449213DC8273CD0AFC2431206DC443E631F3290C9BFCCDD.png)

4. 在项目的game.js文件头部新增如下代码。

   ```screen
   import * as GMMEForMiniGames from 'GMMEForMiniGames.js'
   window.GMMEForMiniGames = GMMEForMiniGames;
   ```

## 导出为华为快游戏

1. 使用Unity完成游戏多媒体功能开发后，[导出为WebGL项目](https://github.com/Petal-Gaming-Services/UnityToQuickGame/blob/main/doc/第二步-发布WebGL项目.md)。
2. 使用[快游戏开发者工具](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-developer-tool-0000001618076721)导入此项目。
3. 在工具主界面的顶部菜单栏选择"构建 > Unity游戏转换快游戏"，填写信息完成转换。
4. 将游戏多媒体JS SDK中的GMMEForMiniGames.js放在快游戏项目的根目录下。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250424164757.62781895576413575537887736660927:50001231000000:2800:B3AC60546318A731CE5B1D2A752E0A75398F57CEB8425DCE9FC190DCAF67833C.png)

5. 在项目的game.js文件头部新增如下代码。

   ```screen
   require("GMMEForMiniGames.js");
   window.GMMEForMiniGames = GMMEForMiniGames;
   ```
