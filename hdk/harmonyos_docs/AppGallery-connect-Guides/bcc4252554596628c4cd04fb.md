# 启用服务

## 前提条件

您已[创建项目](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createproject-0000001100334664)。

## 操作步骤

首次使用云托管服务前，需要先启用此服务。如果您已经启用，可跳过本步骤。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中选择您需要开通云托管服务的项目。
3. 点击"云开发（Serverless） > 云托管"，进入云托管页面，点击"立即开通"。 说明
   > * 如您尚未设置默认数据处理位置，点击"立即开通"会弹出"默认数据处理位置"提示框。参考[设置数据处理位置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-data-storage-location-0000001162597847#section154810363471)设置完成后，点击"确定"，即可开通云托管服务。
   > * 云托管不支持修改数据存储位置，修改后会导致项目下所有资源被删除，请谨慎操作。
