# 列举文件

列举文件是指获取某个目录下的所有文件和目录信息，云存储SDK支持通过API列举云端某个目录下的文件或子目录。

## 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[初始化存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-initialize-bucket-java-0000001282104682)。

## 操作步骤

1. 定义待枚举的目录的详细参数。
2. 调用[StorageReference.listObjects](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storagereference-0000001158228875#section6705161293613)方法获取当前目录下的文件与子目录。

## 参考代码

```screen
public class StorageList {
    private static StorageManagement storageManagement;

    /**
     * Download a file
     *
     * @throws StorageException storage exception
     */
    public static void listObjects(String bucketName, String cloudFolderPath) throws StorageException {
        storageManagement =
            AGCStorageManagement.getInstance(AGCClient.getInstance(), "cn-north-4", bucketName);
        StorageReference storageReference = storageManagement.getStorageReference(cloudFolderPath);
        // 定义待枚举的目录的详细参数
        ListObjectsRequest listObjectsRequest = new ListObjectsRequest();
        listObjectsRequest.setMarker("");
        listObjectsRequest.setMaxKeys(100);
        listObjectsRequest.setDelimiter("/");
        listObjectsRequest.setListTimeout(5);
        // 调用StorageReference.listObjects获取当前目录下的文件与子目录
        ListObjectsResult objectsResult = storageReference.listObjects(listObjectsRequest);
        for (String file : objectsResult.getFileList()) {
            System.out.println("file - " + file);
        }
        for (String dir : objectsResult.getDirList()) {
            System.out.println("dir - " + dir);
        }
    }
    public static void initializeClient(String content) throws AGCException {
        CredentialService credential =
            CredentialParser.toCredentialWithContents(content);
        AGCParameter agcParameter = AGCParameter.builder().setCredential(credential).build();
        AGCClient.initialize(agcParameter);
        System.out.println("init agcParameter Success.");
    }
    public static void main(String[] args) throws AGCException {
        // 存储实例名
        String bucketName = "xxxx";
        // 云端文件夹路径
        String cloudFolderPath = "images/";
        // 凭据信息，json格式
        String credential = "{\"type\":\"project_client_id\",\"developer_id\":\"xxx\",\"project_id\":\"xxx\",\"client_id\":\"xxx\",\"client_secret\":\"xxx\",\"configuration_version\":\"3.0\",\"region\":\"CN\"}";

        StorageList.initializeClient(credential);

        StorageList.listObjects(bucketName, cloudFolderPath);
    }
}
```
