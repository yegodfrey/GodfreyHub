# 使用数据库的其他操作

#### 写入数据

您可以通过[executeUpsertOne](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbzone-ios-0000001127718205#section9836194392310)或者[executeUpsert](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbzone-ios-0000001127718205#section27861447112311)将一个或者一组对象写入到当前存储区中。在写入对象时，如果在存储区已经存在主键值相同的对象，则更新已有的对象；如果不存在，则写入一个新的对象。写入的数据可以来自于新建对象，或者从存储区查询出来的对象。

写入一组对象时，数据的写入操作是原子的，即对象列表中的对象要么全部成功写入，要么全部失败。

调用写入数据方法后，会通过[AGCCloudDBZoneCompleteCallback](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-type-definitions-ios-0000001127718207#section137881730191316)对象返回执行情况，对象中封装了写入操作的结果和错误信息。

注意事项：  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250714155427.36847379854600891740347037656223:50001231000000:2800:9F60B8137FED6C502AACE8A39D1806DBCB8AC123F2C974188AFBC5E25D595E91.png)  
请先关注注意事项。

* 仅当存储区为打开状态时，才可以进行写入对象操作，否则会导致写入失败。
* 写入一组对象时，该组中的对象必须属于同一个对象类型，否则会导致写入失败。

代码示例：

将BookInfo对象写入至存储区中，写入成功后，返回插入的数量；写入失败，输出错误信息。

```
- (void)executeUpsertWithBook:(NSArray <BookInfo *> *__nonnull)books complete:(void(^)(BOOL success, NSError *error))complete {
	if(books.count == 0) {
		return;
	}
	[self.dbZone executeUpsert:books onCompleted:^(NSInteger count, NSError * _Nullable error) {
		if (error) {
			if (complete) {
				complete(NO, error);
			}
		} else {
			if (complete) {
				complete(YES, nil);
			}
		}
	}];
}
```

#### 查询数据

云数据库通过[executeQuery](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbzone-ios-0000001127718205#section7689155992320)方法查询对象，并提供了丰富的谓词查询，比如equalTo、notEqualTo、inArray等。通过单个或者多个链式过滤条件，您可以从存储区查询到满足特定条件的对象，也可以通过排序谓词对查询结果排序，或者通过限定查询返回数量谓词限定查询结果返回的数量。详细的查询条件请参见[AGCCloudDBQuery](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbquery-ios-0000001080858650)。

云数据库包括缓存模式和本地模式两种数据同步模式，不同的模式下，其数据查询策略也不一致，具体如下：

* 缓存模式
  * 从本地缓存查询。
  * 从云侧存储区服务器查询。
  * 从云侧存储区和本地缓存查询数据。
* 本地模式
  * 仅支持从本地存储区查询数据。

根据查询结果返回的[AGCCloudDBSnapshotCallback](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-type-definitions-ios-0000001127718207#section717024113136)对象，可以获取存放在对象里的AGCCloudDBSnapshot对象，您在获取对象的同时，也可以通过一些辅助的方法根据具体需求进行不同的处理。例如，通过与[subscribeSnapshotWithQuery](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbzone-ios-0000001127718205#section79221294241)合用添加对查询结果集的数据变化侦听，与[hasPendingWrites](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbsnapshot-ios-0000001127835353#section185380446221)合用可以判断是否有未同步到云侧的对象，与[isFromCloud](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbsnapshot-ios-0000001127835353#section3818144722211)合用判断查询结果中的对象来源等，更多请参见[AGCCloudDBSnapshot](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbsnapshot-ios-0000001127835353)。

云数据库在支持基本查询的同时，还支持您查询某个字段平均值和查询本地缓存中未同步到云数据库的对象。

注意事项：

请先关注注意事项。

* 仅当存储区为打开状态时，才可以进行查询对象操作，否则会导致查询失败。
* 每次的查询操作仅支持查询一个对象类型下的数据。  

#### 简单查询

您可以在无查询条件时，获取一个对象类型中所有的对象；也可以指定单个查询条件，来获取满足该条件的对象。

* 查询对象类型BookInfo的所有数据。

  ```
  - (void)queryAllBooksWithResults:(void(^)(NSArray * bookList, NSError *error))results {
  	AGCCloudDBQuery *query = [AGCCloudDBQuery where:[BookInfo class]];
  	[self.dbZone executeQuery:query policy:AGCCloudDBQueryPolicyCloud onCompleted:^(AGCCloudDBSnapshot *_Nullable snapshot, NSError *_Nullable error) {
  		if (error) {
  			if (results) {
  				results(nil,error);
  			}
  		} else {
  			NSArray *bookList = snapshot.snapshotObjects;
  			if (results) {
  				results(bookList, nil);
  			}
  		}
  	}];
  }
  ```

* 通过异步侦听的方式查询"bookName"为"左传"的书籍。
  * 构造查询方法queryBooksWithQuery，该方法同时供后续查询示例引用。

    ```
    - (void)queryBooksWithQuery:(AGCCloudDBQuery *)query complete:(void (^)(NSArray *bookList, NSError *error))complete {
    	[self.dbZone executeQuery:query
                               policy:AGCCloudDBQueryPolicyCloud
                          onCompleted:^(AGCCloudDBSnapshot *_Nullable snapshot, NSError *_Nullable error) {
    		if (error) {
    			if (complete) {
    				complete(nil, error);
    			}
    		} else {
    			NSArray *bookList = snapshot.snapshotObjects;
    			if (complete) {
    				complete(bookList, nil);
    			}
    		}
    	}];
    }
    ```

  * 构造查询条件，并调用queryBooks方法，获取查询数据。

    ```
    AGCCloudDBQuery *query = AGCCloudDBQuery.where([BookInfo class]).equalTo(@"左传",@"bookName");
    [self queryBooksWithQuery:query complete:^(NSArray *bookList, NSError *error) {
    	NSLog(@"%@", bookList);
     }];
    ```

#### 复合查询

您可以通过多个链式过滤条件，来获取满足条件的对象。多个链式条件之间默认用"与"运算。

* 构造查询条件，并调用queryBooks方法，查询"bookName"包含"数据库"，"price"大于20.0并且小于50.0的书籍。

  ```
  AGCCloudDBQuery *query = AGCCloudDBQuery.where([BookInfo class]).contains(@"左传",@"bookName").greaterThan(@(20.0),@"price").lessThan(@(50.0),@"price");
  [self queryBooksWithQuery:query complete:^(NSArray *bookList, NSError *error) {
  	NSLog(@"%@", bookList);
  }];
  ```

* 构造查询条件，并调用queryBooks方法，查询"bookName"包含"史记"，"author"是"司马迁"，"price"大于60.0的书籍。

  ```
  AGCCloudDBQuery *query = AGCCloudDBQuery.where([BookInfo class]).contains(@"史记",@"bookName").equalTo(@"司马迁", @"author").greaterThan(@(60.0),@"price");
  [self queryBooksWithQuery:query complete:^(NSArray *bookList, NSError *error) {
  	NSLog(@"%@", bookList);
  }];
  ```

#### 聚合查询

在查询数据时，您可以通过聚合查询实现查询平均值、求和、查询最大值、查询最小值和统计数据记录条数的能力。

查询平均值

您可以通过[executeQueryAverage](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbzone-ios-0000001127718205#section1428814332415)查找满足特定条件的对象，并计算这些对象中指定字段的平均值。  
查询所有书籍的价格平均值。

```
AGCCloudDBQuery *query = AGCCloudDBQuery where.([BookInfo class]);
[self.dbZone executeQueryAverage:query policy:AGCCloudDBQueryPolicyCloud field:@"price" onCompleted:^(double average, NSError * _Nullable error) {
	NSLog(@"Average price is %.2f", average);
}];
```

求和

您可以通过[executeQuerySum](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbzone-ios-0000001127718205#section10466107132413)查找满足特定条件的对象，返回指定字段的数据记录值的求和结果。  
查询所有书籍的价格总和。

```
AGCCloudDBQuery *query = AGCCloudDBQuery where.([BookInfo class]);
[self.dbZone executeQuerySum:query policy:AGCCloudDBQueryPolicyCloud field:@"price" onCompleted:^(NSNumber * _Nullable number, NSError * _Nullable error) {
	NSLog(@"Sum price is %.2f", number.doubleValue);
}];
```

查询最大值和最小值

您可以通过[executeQueryMaximum](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbzone-ios-0000001127718205#section119121310142412)或者[executeQueryMinimum](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbzone-ios-0000001127718205#section1336801432411)查询满足特定条件的对象，返回指定字段的数据记录值中的最大值或者最小值。

* 查询所有书籍中价格最高值。

  ```
  AGCCloudDBQuery *query = AGCCloudDBQuery where.([BookInfo class]);
  [self.dbZone executeQueryMaximum:query policy:AGCCloudDBQueryPolicyCloud field:@"price" onCompleted:^(NSNumber * _Nullable number, NSError * _Nullable error) {
  	NSLog(@"Maximum price is %.2f", number.doubleValue);
  }];
  ```

* 查询所有书籍中价格最低值。

  ```
  AGCCloudDBQuery *query = AGCCloudDBQuery where.([BookInfo class]);
  [self.dbZone executeQueryMinimum:query policy:AGCCloudDBQueryPolicyCloud field:@"price" onCompleted:^(NSNumber * _Nullable number, NSError * _Nullable error) {
  	NSLog(@"Minimum price is %.2f", number.doubleValue);
  }];
  ```

统计数据记录条数

您可以通过[executeQueryCount](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbzone-ios-0000001127718205#section1010001812411)查找满足特定条件的对象，返回指定字段的数据记录条数。统计时，该字段值不为空，则计数1；否则，计数为0。  
查询书籍的数量。

```
AGCCloudDBQuery *query = [AGCCloudDBQuery where:[BookInfo class]];
[self.dbZone executeQueryCount:query policy:AGCCloudDBQueryPolicyCloud field:@"id" onCompleted:^(NSInteger count, NSError * _Nullable error) {
	NSLog(@"The count of book is %ld", count);
}];
```

#### 数据排序

您可以通过[orderByAsc](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbquery-ios-0000001080858650#section1184610247216)或者[orderByDesc](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbquery-ios-0000001080858650#section39861827162114)实现对查询结果集中的对象按某个字段进行升序或者降序排列。

使用[orderByAsc](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbquery-ios-0000001080858650#section1184610247216)或者[orderByDesc](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbquery-ios-0000001080858650#section39861827162114)对字段进行排序时，建议针对排序的字段创建索引，否则，当该对象类型的数据量达到一定条数时，可能因为查询效率低引起查询超时或失败，影响用户体验。创建索引请参见[新增对象类型](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-sdk-integration-ios-0000001518546736#section8375194164915)，创建索引后，您还需要更新本地的对象类型文件，详细请参见[加载对象类型文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-sdk-integration-ios-0000001518546736#section438311702010)。

对查询结果中的对象进行排序时，排序谓词需要在其它查询谓词之后且在限定数据查询数量谓词之前。  
构造查询条件，并调用queryBooks方法，查询所有价格小于50.0的书籍，并且按降序排列。

```
AGCCloudDBQuery *query = AGCCloudDBQuery.where([BookInfo class]).lessThan(@(50.0), @"price").orderByDesc(@"price");
[self queryBooksWithQuery:query complete:^(NSArray *bookList, NSError *error) {
	NSLog(@"%@", bookList); 
}];
```

#### 元组查询

在查询数据时，您可以通过[startAt()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-0000001080569968#section1487482619011)、[startAfter()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-0000001080569968#section14672728409)、[endAt()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-0000001080569968#section682613301709)和[endBefore()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-clouddbzonequery-0000001080569968#section17214143016596)方法限定查询数据的起始位置或者终止位置。

获取指定记录后的一组数据记录

使用[startAt](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbquery-ios-0000001080858650#section884743412216)方法定义查询的起始位置。startAt方法单独使用时，系统会默认按照主键的升序进行排序，并返回某条记录之后的数据，该方法将会包含起始位置对应的数据记录。

```
BookInfo *book = [[BookInfo alloc] init];
book.id = @5;
AGCCloudDBQuery *query = AGCCloudDBQuery.where([BookInfo class]).startAt(book);
[self queryBooksWithQuery:query complete:^(NSArray *bookList, NSError *error) { 
	NSLog(@"%@", bookList);
}];
```

将查询的数据进行交集处理

使用startAt()方法定义查询的起始位置，通过与[lessThan()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbquery-ios-0000001080858650#section2082216539201)结合使用，查找满足特定条件的对象集。

```
BookInfo *book = [[BookInfo alloc] init];
book.id = @5;
AGCCloudDBQuery *query = AGCCloudDBQuery.where([BookInfo class]).lessThan(@20,@"id").startAt(book);
[self queryBooksWithQuery:query complete:^(NSArray *bookList, NSError *error) { 
	NSLog(@"%@", bookList);
}];
```

基于多个字段排序获取指定记录前的一组数据记录

通过[endAt](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbquery-ios-0000001080858650#section3581114114219)和[orderByAsc](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbquery-ios-0000001080858650#section1184610247216)组合使用，将查询数据按照指定的多个字段进行排序，返回指定终止位置记录之前的数据，返回结果将会包含终止位置对应的数据。

```
// 查询 BOOK_ID 以5结束，并且BookName 为Red And Black、Price 为10.0的书本。
BookInfo *book = [[BookInfo alloc] init];
book.id = @5;
book.bookName = @"Red And Black";
book.price = @10.0;
AGCCloudDBQuery *query = AGCCloudDBQuery.where([BookInfo class]).orderByAsc(@"bookName").orderByAsc(@"price").endAt(book);
[self queryBooksWithQuery:query complete:^(NSArray *bookList, NSError *error) { 
	NSLog(@"%@", bookList);
}];
```

#### 分页查询

在查询数据时，您可以通过元组查询和[limit()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbquery-ios-0000001080858650#section10663153113219)方法结合使用实现数据的分页查询，也可以直接通过limitOffset实现分页查询。您可以和[equalTo()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbquery-ios-0000001080858650#section15167143118209)、[limit()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbquery-ios-0000001080858650#section10663153113219)、[orderByAsc()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbquery-ios-0000001080858650#section1184610247216)、[orderByDesc()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbquery-ios-0000001080858650#section39861827162114)、[greaterThan()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbquery-ios-0000001080858650#section118160465205)、[greaterThanOrEqualTo()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbquery-ios-0000001080858650#section1037515042016)、[lessThan()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbquery-ios-0000001080858650#section2082216539201)、[lessThanOrEqualTo()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbquery-ios-0000001080858650#section48391558182010)方法组合使用，例如与排序查询谓词或者等值查询谓词组合使用，可以实现获取某个对象之前或者之后的数据记录。

为了保证分页查询的性能，云数据库要求您在构造分页查询条件前，先创建查询所需的索引。如果未创建索引，您可能会收到一个异常信息，您需要根据异常信息创建缺少的索引。创建索引请参见[新增对象类型](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-sdk-integration-ios-0000001518546736#section8375194164915)，创建索引后，您还需要更新本地的对象类型文件，详细请参见[加载对象类型文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-sdk-integration-ios-0000001518546736#section438311702010)。

通过元祖查询和limit()方法组合使用进行分页查询

使用[startAt](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbquery-ios-0000001080858650#section884743412216)方法定义查询的起始位置，通过与[limit](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbquery-ios-0000001080858650#section10663153113219)和[orderByAsc](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbquery-ios-0000001080858650#section1184610247216)结合使用实现数据的分页能力，并将第一次查询结果的最后一条记录，作为下一次查询的起点。

```
// 查询前10条记录。
__block NSArray *result = @[];
AGCCloudDBQuery *queryFirst = AGCCloudDBQuery.where([BookInfo class])
    .equalTo(@"publisher", @"人民出版社")
    .orderByAsc(@"id")
    .limit(10);
dispatch_semaphore_t semaphore = dispatch_semaphore_create(0);
[self queryBooksWithQuery:queryFirst complete:^(NSArray *bookList, NSError *error) { 
	result = snapshot.snapshotObjects;
	dispatch_semaphore_signal(semaphore);
}];
// 等待查询结果。
dispatch_semaphore_wait(semaphore, DISPATCH_TIME_FOREVER);

// 将前10条记录的最后一条，作为查询下一页数据记录的起点（不包含起点），获取下一页数据。
BookInfo *nextBook = result.lastObject;
AGCCloudDBQuery *queryNext = AGCCloudDBQuery.where([BookInfo class])
    .equalTo(@"publisher", @"人民出版社")
    .startAfter(nextBook)
    .orderByAsc(@"id")
    .limit(10);
[self queryBooksWithQuery:queryNext complete:^(NSArray *bookList, NSError *error) { 
	NSLog(@"%@", bookList);
}];
```

通过limitOffset实现分页查询

计算分页数据的offset参数，通过limitOffset实现分页查询。

```
// 查询前10条记录。
__block NSArray *result = @[];
NSInteger pageNo = 1;     // 页面编号
NSInteger pageSize = 10;  // 每页容量
AGCCloudDBQuery *queryFirst = AGCCloudDBQuery.where([BookInfo class])
    .lessThan(@"price", @(50.0))
    .orderByAsc(@"id")
    .limit(10);
dispatch_semaphore_t semaphore = dispatch_semaphore_create(0);
[self queryBooksWithQuery:queryFirst complete:^(NSArray *bookList, NSError *error) { 
	result = snapshot.snapshotObjects;
	dispatch_semaphore_signal(semaphore);
}];
// 等待查询结果。
dispatch_semaphore_wait(semaphore, DISPATCH_TIME_FOREVER);
```

#### 侦听实时更新

您可以通过[subscribeSnapshotWithQuery](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbzone-ios-0000001127718205#section79221294241)来侦听符合指定查询条件的数据变化。当侦听的数据发生变化时，云数据库会触发您自定义的回调函数，并将数据以快照的方式传给回调函数，由您根据业务逻辑自定义处理快照数据。  
注册快照侦听后，快照侦听需要一定的时间（受限于网络状态）才会生效，因此，在侦听生效前的数据变化不会推送到端侧，待侦听生效后，端侧可正常收到云侧数据变化的通知。您注册的快照侦听后，会触发生成一次快照，后续每当侦听的数据发生变化时，都会生成一次快照。注册侦听时，需要根据数据的查询策略指定侦听数据来源，数据来源如下所示：

* 从云侧存储区服务器查询。
* 从云侧存储区和本地缓存查询数据。 执行该数据查询策略时，您在本地的数据增、删、改操作会立即调用已注册的快照侦听器，并不会等待数据同步到云端服务器时再调用快照侦听器。

通过调用AGCCloudDBSnapshot类中的[upsertedObjects](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbsnapshot-ios-0000001127835353#section9339454142210)可以获取相较于上次快照新增或者修改的对象，调用[deletedObjects](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbsnapshot-ios-0000001127835353#section524405712214)获取相较于上次快照删除的对象。

前提条件：

存储区的数据同步模式为缓存模式。

#### 事务与数据管理

云数据库支持通过[runTransaction](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agcclouddbzone-ios-0000001127718205#section194942610243)执行事务，实现对云侧存储区数据的管理操作，包含数据的增、删、改、查操作。事务支持同时对多个对象类型的数据进行增、删、改、查操作。事务操作是原子的，一个事务内的所有操作要么全部执行成功，要么全部执行失败。如果执行事务时出现并发写入，云数据库会再次尝试执行整个事务，确保整个事务操作的一致性。

前提条件：

存储区的数据同步模式为缓存模式。

注意事项：  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250714155427.12408717991396450982929945669815:50001231000000:2800:3CFD1788F36C148746DF147501830F01C3F38E577F65893024995311EB5A98B3.png)  
请先关注注意事项。

* 仅当存储区为打开状态时，才可以执行事务操作，否则会导致事务执行失败。

<!-- -->

* 事务中的查询操作必须在写入操作和删除操作之前，否则将导致事务执行失败。
* 仅在正常连接网络时可执行事务操作，一旦离线该操作将失败。
* 一个事务中多次查询结果的总数据大小不能超过5MB，否则会导致事务失败。
* 一个事务中多次查询结果的总数据条数不能超过1000条，否则会导致事务失败。
* 一个事务中包含的写入和删除对象的总条数不能超过1000条，否则会导致事务执行失败。
* 一个事务内的多次写入操作的数据总大小不能超过2MB，否则会导致写入失败。
* 写入和删除操作的数据为nil，或者其数据列表中的对象不属于同一个对象类型时，会抛出异常。

代码示例：

使用如下方法，通过事务删除云侧出版日期早于1990年的书籍。

```
//先定义一个事务操作，封装查询和删除操作。
- (void)deleteBooksWithQuery:(AGCCloudDBQuery *)query complete:(void (^)(BOOL isSuccess, NSError *error))complete {
	[self.dbZone runTransaction:^BOOL(AGCCloudDBTransaction * _Nullable transaction) {
		NSError *error = nil;
		NSArray *bookList = [transaction executeQuery:query error:&error];
		if (error) {
			return NO;
		}
		try {
			[transaction executeDelete:bookList];
		} catch (NSException *exception) {
			return NO;
		}
		return YES;
	} onCompleted:^(NSError * _Nullable error) {
		if (error) {
			if (complete) {
				complete(NO, error);
			}
		} else {
			if (complete) {
				complete(YES, nil);
			}
		}
	}];
}

//构造查询条件，调用定义的事务操作，完成删除操作。
NSString *timeString = @"1990-01-01";
NSDateFormatter *dateFormat = [[NSDateFormatter alloc] init];
dateFormat.dateFormat = @"yyyy-MM-dd";
NSDate *date = [dateFormat dateFromString:timeString];
AGCCloudDBQuery *query = AGCCloudDBQuery.where([BookInfo class]).lessThan(date, @"publishTime");
[self deleteBooksWithQuery:query complete:^(BOOL isSuccess, NSError *error) {
	if (!isSuccess) {
		NSLog(@"Deletion is failed : %@", [NSNumber numberWithBool:isSuccess]);
	} else {
		NSLog(@"Deletion is successful : %@", [NSNumber numberWithBool:isSuccess]);
	}
}];
```

#### 全程加密数据

云数据库提供隐私或者敏感数据的全程加密管理能力。该功能开启后，用户数据将在端侧进行加密，然后再以密文形式发送并存储到云侧，只有用户依据其输入的密码才能获取密钥信息并访问自己的加密数据。从而有效提升用户数据的安全性，防止用户云侧数据泄露。

您在AGC控制台上创建对象类型并设置加密字段，即可开启针对该字段的全程加密功能。在您将对象类型文件导入至本地开发环境后，需要使用[setUserKey](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agconnectclouddb-ios-0000001127600971#section962163411421)方法设置用户密码，云数据库会使用该密码派生出密钥信息，并将加密后的密钥信息和加密后的用户数据以密文形式保存在云侧，加密密钥将会和用户账号绑定，只有该用户依据其设置的密码才能获取密钥信息并访问自己的加密数据。用户密码由用户保存，不会同步至云侧。

#### 管理存储区

存储区是一个数据存储区域，每个存储区互相独立，之间的数据没有关联。一个云数据库实例中可以创建多个存储区。

云数据库的数据同步模式包括缓存模式和本地模式，数据同步模式以存储区为粒度进行设置。您在开发应用时，可以根据应用需求为每个存储区选择不同的数据同步模式。不同的数据同步模式可管理的数据不一样，具体如下：

* 缓存模式 在该模式下，您可实现数据的端云协同管理，实现端云、多端之间的数据同步。应用数据将储存在云侧，端侧数据是云侧数据的子集，如果允许持久化，云数据库支持将查询的结果自动缓存至端侧。缓存数据时，不会覆盖本地未同步完成的数据。

<!-- -->

* 本地模式 在该模式下，用户仅可操作端侧所包含的本地数据，无法实现数据在端云、多端间的同步。

一个存储区内可以定义多个对象类型，支持不同的业务需求。每个存储区拥有完全相同的对象类型定义，您可以根据应用的需要自定义存储区中存储的对象。

如果您不再使用某个存储区，可将其暂时关闭。您也可根据需要彻底删除该存储区，从而释放相应的资源。

* 在本地模式下，删除存储区后，会同时删除其在磁盘上存储的数据文件，并且无法恢复。
* 在缓存模式下，删除存储区后，仅删除端侧存储的数据文件，云侧的数据文件将会继续存在，您可通过再次创建存储区，获取相应的数据。

注意事项：  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250714155428.70830367550097115842116607336363:50001231000000:2800:B0BE7AE31A6A4F7AFAE22C497854087067FA728DB3A55CB754AD04E8CACD0C84.png)  
操作前，请先关注注意事项。

* 仅在关闭存储区之后，才能执行删除存储区的操作。
* 创建或者打开一个存储区后，才能对该存储区进行相关数据操作。
* 可以多次打开某个存储区，但在使用完存储区后，都需要关闭该存储区，即每个打开操作需要一个对应的关闭操作。
* 创建存储区成功后，不允许修改CloudDBZoneConfig中的存储区数据同步属性。在创建存储区成功后，再次打开该存储区时，系统会校验本次CloudDBZoneConfig中指定的数据同步属性与创建CloudDBZoneConfig时指定的数据同步属性是否一致，如果不一致，会返回错误信息。

代码示例：

* 创建或者打开一个数据同步属性为缓存模式的存储区。

  ```
  AGCCloudDBZoneConfig *zoneConfig = [[AGCCloudDBZoneConfig alloc] initWithZoneName:zoneName syncMode:AGCCloudDBZoneSyncModeCloudCache accessMode:AGCCloudDBZoneAccessModePublic];
  zoneConfig.persistence = YES;
  __weak typeof(self) weakSelf = self;
  [self.agcConnectCloudDB openCloudDBZone2:zoneConfig allowCreate:YES callback:^(AGCCloudDBZone * _Nullable zone, NSError * _Nullable error) {
  	weakSelf.dbZone = zone;
  }];
  ```

* 创建或者打开一个数据同步属性为本地模式的存储区。

  ```
  AGCCloudDBZoneConfig *zoneConfig = [[AGCCloudDBZoneConfig alloc] initWithZoneName:zoneName syncMode:AGCCloudDBZoneSyncModeLocalOnly accessMode:AGCCloudDBZoneAccessModePublic];

  	weakSelf.dbZone = zone;
  }];
  ```

* 关闭存储区。

  ```
  NSError *error = nil;
  [self.agcConnectCloudDB closeCloudDBZone:self.dbZone error:&error];
  ```

* 删除存储区。 这个方法会删除本地数据，在调用前确认是否删除。

  ```
  NSError *error = nil;
  [self.agcConnectCloudDB deleteCloudDBZone:zoneName error:&error];
  ```

#### 管理版本升级

应用版本升级时，可在AGC控制台上导出对应版本文件，添加至本地开发环境。并通过调用AGConnectCloudDB类中的[createObjectType](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agconnectclouddb-ios-0000001127600971#section568953182617)实现新对象类型的创建，调用[openCloudDBZone2](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/clouddb-agconnectclouddb-ios-0000001127600971#section179771131262)打开指定存储区，完成对象类型版本的升级。在端侧版本升级完成后，对象类型中新增字段的值为空值或者默认值，已有字段的数据保持不变。在缓存模式下，端侧数据会在端侧查询云侧数据时，依据查询结果将最新的数据更新至本地；如果未进行查询云侧数据操作，则云侧数据不会更新至端侧，端侧数据将保持为升级完成后状态，即新增字段的值为空值或者默认值，已有字段的数据保持不变。
