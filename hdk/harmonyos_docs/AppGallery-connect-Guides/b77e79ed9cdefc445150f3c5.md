# 微博

您可以在应用中集成微博认证方式，让您的用户可以使用自己的微博账号进行AppGallery Connect身份验证。  

#### 前提条件

* 您需要在AGC控制台[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-integration-sdk-0000001325876845)。  

#### 开发步骤

认证服务提供了两种开发方式接入微博账号：

* 推荐您使用新的统一登录接入方式，请参见[统一登录接入方式](#section770165194115)。
* 同时为了兼容性，保留了老的传统接入方式，请参见[传统接入方式](#section3925114815427)。  

#### 统一登录接入方式

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143816.43182387143423373794193465642622:50001231000000:2800:C1B98815B44220A91274AB2F8A0391AAAE8D2427FBC85F77CD7187BD535C0C92.png "点击放大")

1. 添加SDK依赖。
   * Android Studio开发环境
     * Version Catalog方式管理依赖
       1. 打开Android Studio项目级gradle目录下的"libs.versions.toml"文件，在\[versions\]中声明微博SDK版本号。

          ```
          [versions]
          weiboVersion = "13.5.0"  # 以13.5.0为例
          ```

       2. 在"libs.versions.toml"文件的\[libraries\]中声明华为认证SDK和微博SDK。

          ```
          [libraries]
          agconnect-auth-weibo = { module = "com.huawei.agconnect:agconnect-auth-weibo", version.ref = "agcVersion" }  # agcVersion声明请参见声明AGC插件和SDK。
          weibo-sdk = { module = "io.github.sinaweibosdk:core", version.ref = "weiboVersion" }
          ```

       3. 在应用级"build.gradle"文件的"dependencies"中添加华为认证SDK和微博SDK的编译依赖。

          ```
          dependencies {      
               implementation libs.agconnect.auth.weibo
               implementation libs.weibo.sdk
          }
          ```

     * 非Version Catalog方式管理依赖 打开应用级gradle文件（通常为app/build.gradle），在"dependencies"中添加华为认证SDK和微博SDK的编译依赖：

       ```
       dependencies {
           implementation "com.huawei.agconnect:agconnect-auth-weibo:1.9.4.300"     
           implementation "io.github.sinaweibosdk:core:{version}@aar"
       }
       ```

   * Eclipse开发环境  
     打开aar2eclipse/aar目录下的build.gradle文件， 在"dependencies"中添加华为认证SDK和微博SDK的编译依赖。具体步骤参见[Eclipse开发环境集成AGC SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-integration-sdk-0000001325876845#section1878849165620)。

     ```
     dependencies {
         embed "com.huawei.agconnect:agconnect-auth-weibo:1.9.4.300"
         embed "io.github.sinaweibosdk:core:{version}@aar"
     }
     ```

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143816.63089225126435391320591191649975:50001231000000:2800:A28AB80D2E493E76637563E22B544F92EA8E2A68D5D0DCC4BE1738AA4D94FA06.png)  
   * 示例中的weiboVersion和{version}请替换为微博SDK的最新版本号，华为不负责更新。
   * 由于华为未提供微博SDK依赖包，您可以在微博开放平台下载最新版本的微博SDK依赖包进行手动集成。
2. 设置微博账号登录所需参数。 在登录之前，调用设置参数接口，设置微博账号登录所需要的参数。

   * /weibo/appKey：必须设置，填写在微博开放平台申请的appKey。
   * /weibo/redirectUrl和/weibo/scope：根据实际情况确定是否需要设置。
     * /weibo/redirectUrl：表示在微博开放平台设置的授权回调页信息redirectUrl，默认值为微博开放平台默认的回调页https://api.weibo.com/oauth2/default.html。
     * /weibo/scope：表示在微博开放平台为应用申请的高级权限scope，默认值为all权限。

   ```
   "Java"
   AGConnectApi.getInstance().getOptions().setOption("/weibo/appKey", "your weibo appKey");
   ```

   ```
   "Kotlin"
   AGConnectApi.getInstance().getOptions().setOption("/weibo/appKey", "your weibo appKey")
   ```

3. 添加生命周期回调，请参见[统一登录调用页面回调](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-unified-login-0000001325756981)。
4. 调用[AGConnectAuth.signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauth-0000001054482530#section125666562219)，登录微博账号。  

   ```
   "Java"
   AGConnectAuth.getInstance().signIn(this,AGConnectAuthCredential.WeiBo_Provider).addOnSuccessListener(new OnSuccessListener<SignInResult>() {
           @Override
           public void onSuccess(SignInResult signInResult) {
                   // onSuccess
                   AGConnectUser user =  signInResult.getUser();
           }
   })
   .addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
                   // onFail
           }
   });
   ```

   ```
   "Kotlin"
   AGConnectAuth.getInstance().signIn(this, AGConnectAuthCredential.WeiBo_Provider).addOnSuccessListener {
       // updateUI
   }.addOnFailureListener {
       // onFailure
   }
   ```

#### 传统接入方式

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143816.98576392073569225399829312200019:50001231000000:2800:7BCDD41E301AB04BA031BEFD1439A691356AC24A1E1C646527BF0E1EE03CF0FC.png "点击放大")

1. 在应用的登录界面，初始化[AGConnectAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauth-0000001054482530)实例，获取AGC的用户信息，检查是否有已经登录的用户。如果有则可以直接进入用户界面，否则显示登录界面。  

   ```
   "Java"
   AGConnectUser user = AGConnectAuth.getInstance().getCurrentUser();
   ```

   ```
   "Kotlin"
   val user = AGConnectAuth.getInstance().currentUser
   ```

2. 微博账号登录，并获取微博账号的用户授权信息。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143816.26489004314572842913257702403278:50001231000000:2800:42D22B9EB5E34D62E397D6AD19BAFBF834CB7509EDEA1BFF44E58F995DF1A71E.png)  
   此步骤仅供参考，更详细内容，请参见[微博官方文档](https://open.weibo.com/index.php) 。
   1. 获取登录后的Token。  

      ```
      "Java"
      weiboAuth = new WeiboAuth(this, APP_KEY, "https://api.weibo.com/oauth2/default.html", "all");
      ssoHandler = new SsoHandler(this, weiboAuth);
      ssoHandler.authorize(new WeiboAuthListener() {
              @Override
              public void onComplete(Bundle bundle) {
                  Oauth2AccessToken token = Oauth2AccessToken.parseAccessToken(bundle);
              }

              @Override
              public void onWeiboException(WeiboException e) {
              }

              @Override
              public void onCancel() {
              }
      });
      ```

   2. 添加授权确认后的回调。  

      ```
      "Java"
      @Override
      protected void onActivityResult(int requestCode, int resultCode, Intent data) {
          super.onActivityResult(requestCode, resultCode, data);
          if (ssoHandler != null) {
              ssoHandler.authorizeCallBack(requestCode, resultCode, data);
          }
      }
      ```

3. 调用[WeiboAuthProvider.credentialWithToken](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/weiboauthprovider-0000001054322520#section8234162454519)，使用从微博账号获取的accessToken和uid生成credential，并调用[AGConnectAuth.signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauth-0000001054482530#section298148131715)实现登录。  

   ```
   "Java"
   AGConnectAuthCredential credential = WeiboAuthProvider.credentialWithToken(token.getToken(),token.getUid());
   AGConnectAuth.getInstance().signIn(credential)
       .addOnSuccessListener(new OnSuccessListener<SignInResult>() {
           @Override
           public void onSuccess(SignInResult signInResult) {
               // onSuccess
               AGConnectUser user = signInResult.getUser();
           }
       })
       .addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
               // onFail
           }
       });
   ```

   ```
   "Kotlin"
   val credential = WeiboAuthProvider.credentialWithToken(token.token,token.uid)
   AGConnectAuth.getInstance().signIn(credential).addOnSuccessListener {
       // onSuccess
       val user = it.user
   }.addOnFailureListener {
        // onFail
   }
   ```

#### 更多信息

* 您如果想让用户可以使用多个账号登录您的应用，可以将多个[账号进行关联](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-associated-0000001053692650)。
* 当用户不需要使用应用，或者需要切换其他账号登录认证，可以先执行[登出](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-sign-out-0000001053612647)。
* 当用户需要注销当前用户，可以进行[销户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-deleteuser-0000001057730521)。
* 对于销户、修改密码、关联账号以及重置手机账号和邮箱账号等敏感操作，为了提高安全性，需要用户必须在5分钟内登录过才能执行。如果用户执行敏感操作时登录超过5分钟，需要[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-reauthenticate-0000001127287737)后再执行敏感操作。
* 您可以参考[异常处理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-troubleshooting-0000001052932665)实现自己的异常处理机制，从而减少异常情况的发生。
* 您可以使用云函数触发器来接收用户注册、登录、销户等关键事件，从而[扩展认证服务的能力](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-extension-0000001053372708)。
* 您可以参考[管理用户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-user-manage-0000001606051705)对用户进行解锁、停用等操作。
