# （可选）实时更新远程配置参数

#### 简介

利用云函数提供的远程配置后台函数触发功能，您可以实时使用远程配置更新动态。实现该功能，您首先需要创建一个或多个函数，以及相应的函数触发器。当您的远程配置服务实现发布或者回滚功能时，函数触发器触发对应函数。该函数将发送Push消息，从而通知客户端需要去云端重新获取最新的配置。

#### 新增云函数和函数触发器

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择需要创建云函数的应用。
3. 点击"云开发（Serverless） \> 云函数"，进入"云函数"页面，点击"创建函数"。
4. 在"创建函数"页面的"函数代码"环节，"代码输入类型"选择"\*.zip文件"，点击"代码文件"虚线框上传[wisefunction.zip](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyManage/011/111/111/0000000000011111111.20200715184825.66390839148091654415262307897349:50510826022217:2800:581863F7DD21091AF2E6F964B2D9759E3F52975D2F545B811D98AF85042342EC.zip?needInitFileName=true)代码包，并点击右下角"下一步"，最终配置完成后点击右下角"创建"。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251106205008.46523698758312107912579956635080:50001231000000:2800:74C3EF5150314D5DB785227C4517E6D432D411DF8E1BB55BA0DDB80CBD990372.png)
5. 进入"函数"页面，在"函数配置"页签下"环境变量"区域，点击"新增变量"，每行记录需要填写两个值。
   * 第一个值格式为appsecret.Client ID，例如：appsecret.101351\*\*\*。
   * 第二个值为应用的Client SECRET的值，例如：b48b733446a19aee549472d5deea9acf0a254cd81606f5c2bf92ca972\*\*\*\*\*\*\*。

   其中，Client ID和Client SECRET的取值，请参见[查看应用基本信息](https://developer.huawei.com/consumer/cn/doc/app/agc-help-appinfo-0000001100014694)。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251106205008.75441933019311714406380669509600:50001231000000:2800:996B1E7184D153670CA2BA63C8DB1B7F83496494B93615B7AB2C8E43E32ACDF2.png)
6. 创建完成，点击左下角"保存"。
7. 在"触发器"页签下点击"+添加触发器"配置远程配置触发器。 详细配置说明，请参见"[远程配置触发器](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudfunction-remoteconfig-trigger-0000001658558544)"。

#### 在客户端设置远程配置状态

在应用中接收消息，处理远程配置数据更新标识，当接收到对应推送消息时，表示本地数据已经过期。

<br />

```
@Override
public void onMessageReceived(RemoteMessage message) {
    Log.i(TAG, "onMessageReceived is called");
    if (message.getDataOfMap().containsKey("DATA_STATE")) {
        SharedPreferences preferences = this.getApplicationContext().getSharedPreferences("Remote_Config", MODE_PRIVATE);
        preferences.edit().putBoolean("DATA_OLD", true).apply();
    }
}
```

#### 实时触发提取远程配置进行更新

从远程配置服务使用[AGConnectConfig.fetch](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section1176012013115)接口提取远程配置，并调用[AGConnectConfig.apply](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section486198212)接口传入云端同步获取的值使配置更新。

```
SharedPreferences preferences = this.getApplicationContext().getSharedPreferences("Remote_Config", MODE_PRIVATE);
long fetchInterval = 12 * 60 * 60L;
if (preferences.getBoolean("DATA_OLD", false)) {
    fetchInterval = 0;
}
config.fetch(fetchInterval).addOnSuccessListener(configValues -> {
    config.apply(configValues);
    showAllValues();
    preferences.edit().putBoolean("DATA_OLD", true).apply();
    Toast.makeText(getBaseContext(), "Fetch Success", Toast.LENGTH_LONG).show();
}).addOnFailureListener(e -> {
    Toast.makeText(getBaseContext(), "Fetch Fail", Toast.LENGTH_LONG).show();
});
```
