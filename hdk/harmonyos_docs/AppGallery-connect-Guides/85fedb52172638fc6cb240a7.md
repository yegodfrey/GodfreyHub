# 邮箱

您可以在应用中集成邮箱账号认证方式，您的用户可以使用"邮箱地址+密码"或者"邮箱地址+验证码"的方式来登录您的应用。

## 前提条件

* 您需要在AGC控制台[开通认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyts-integration-0000001471227866)。

## 注册

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251226181013.77573676408355563818720820745128:50001231000000:2800:E03399AC2D172E5B02666AC7C465F579F15683D1910A424DA1BAEEF26294B3DB.png "点击放大")

1. 在使用邮箱注册之前，需要先验证您的邮箱，确保该邮箱账户归您所有。

   调用[AGConnectAuth.requestEmailVerifyCode](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-agconnectauth-0000001522558177#section18901230101318)申请验证码。

   ```screen
   import { EmailAuthProvider, VerifyCodeAction, VerifyCodeSettingBuilder, PhoneUserBuilder,
     PhoneAuthProvider, AGConnectAuth, AGConnectAuthCredentialProvider
   } from "@hw-agconnect/auth-ohos"

   let verifyCodeSettings = new VerifyCodeSettingBuilder()
     .setAction(VerifyCodeAction.REGISTER_LOGIN)
     .setLang('zh_CN')
     .setSendInterval(60)
     .build();
   agconnect.auth().requestEmailVerifyCode('email',verifyCodeSettings)
     .then(verifyCodeResult => {
        //验证码申请成功
     }).catch(error => {
         //验证码申请失败    
     });
   ```

2. 使用邮箱账号注册用户。

   调用[EmailUserBuilder](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-emailuserbuilder-0000001471239002)生成EmailUser，然后调用[AGConnectAuth.createEmailUser](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-agconnectauth-0000001522558177#section20867736181218)注册用户。注册成功后，系统会自动登录，无需再次调用登录接口。

   ```screen
   let emailUser = new EmailUserBuilder()
     .setEmail("email")
     .setPassword("password") //可以给用户设置初始密码。填写后后续可以用密码来登录
     .setVerifyCode("verifyCode")
     .build();

   agconnect.auth().createEmailUser(emailUser)
     .then(result => {
       //创建账号成功后，默认已登录
     })
     .catch(error => {
      //创建用户失败
     })
   ```

3. 登录成功后可以调用[AGConnectAuth.getCurrentUser](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-agconnectauth-0000001522558177#section87068861218)获取用户账号数据。

   ```screen
   agconnect.auth().getCurrentUser();
   ```

## 密码登录

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251226181013.40198460474659206977026053736738:50001231000000:2800:351CB037A65DF441AE8AADA3881CC011254EB3DC15DF4076D2B7A911CEA13A92.png "点击放大")

1. 在应用的登录界面，初始化[AGConnectAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-agconnectauth-0000001522558177)实例，获取AGC的用户信息，检查是否有已经登录的用户。如果有，则可以直接进入用户界面，否则显示登录界面。

   ```screen
   agconnect.auth().getCurrentUser().then(user=>{
       if(user){
           //业务逻辑
       }
   });
   ```


2. 调用[EmailAuthProvider.credentialWithPassword](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-emailauthprovider-0000001471558470#section973510438382)，采用密码方式创建邮箱账号凭证（credential）。

   ```screen
   credential = EmailAuthProvider.credentialWithPassword(emailStr, password);
   ```

3. 获取credential成功后，调用[AGConnectAuth.signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-agconnectauth-0000001522558177#section136957141012)实现登录。

   ```screen
   agconnect.auth().signIn(credential)
            .then(user => {
                //登录成功
            }).catch(error => {
                //登录失败
            });
   ```

## 验证码登录

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251226181013.87928476912071937724916042036447:50001231000000:2800:A3BDB42D1413C53E840E69592707CF665FB93CC8BE9330C01BDB551A76BE563A.png "点击放大")

1. 在应用的登录界面，初始化[AGConnectAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-agconnectauth-0000001522558177)实例，获取AGC的用户信息，检查是否有已经登录的用户。如果有，则可以直接进入用户界面，否则显示登录界面。

   ```screen
   import { EmailAuthProvider, VerifyCodeAction, VerifyCodeSettingBuilder, PhoneUserBuilder,
     PhoneAuthProvider, AGConnectAuth, AGConnectAuthCredentialProvider
   } from "@hw-agconnect/auth-ohos"

   agconnect.auth().getCurrentUser().then(user=>{
       if(user){
           //业务逻辑
       }
   });
   ```


2. 调用[AGConnectAuth.requestEmailVerifyCode](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-agconnectauth-0000001522558177#section18901230101318)申请登录验证码。

   ```screen
   let verifyCodeSettings = new VerifyCodeSettingBuilder()
     .setAction(VerifyCodeAction.REGISTER_LOGIN)
     .setLang('zh_CN')
     .setSendInterval(60)
     .build();
   agconnect.auth().requestEmailVerifyCode('email',verifyCodeSettings)
     .then(verifyCodeResult => {
        //验证码申请成功
     }).catch(error => {
         //验证码申请失败    
     });
   ```


3. 调用[EmailAuthProvider.credentialWithVerifyCode](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-emailauthprovider-0000001471558470#section86232180395)采用验证码方式创建邮箱账号凭证（credential）。

   ```screen
   credential = EmailAuthProvider.credentialWithVerifyCode(emailStr, password, verifyCode);
   ```

   password参数可以不传，如果同时输入了密码和验证码，则会对密码和验证码都做验证。
4. 获取credential成功后，调用[AGConnectAuth.signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-agconnectauth-0000001522558177#section136957141012)实现登录。

   ```screen
   agconnect.auth().signIn(credential)
            .then(user => {
                //登录成功
            }).catch(error => {
                //登录失败
            });
   ```

## 修改邮箱地址

> 注意
>
> 修改邮箱时需要用户处于登录状态。

1. 调用[AGConnectAuth.requestEmailVerifyCode](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-agconnectauth-0000001522558177#section18901230101318)申请验证码。

   ```screen
   import { EmailAuthProvider, VerifyCodeAction, VerifyCodeSettingBuilder, PhoneUserBuilder,
     PhoneAuthProvider, AGConnectAuth, AGConnectAuthCredentialProvider
   } from "@hw-agconnect/auth-ohos"

   let verifyCodeSettings = new VerifyCodeSettingBuilder()
     .setAction(VerifyCodeAction.REGISTER_LOGIN)
     .setLang('zh_CN')
     .setSendInterval(60)
     .build();
   agconnect.auth().requestEmailVerifyCode('email',verifyCodeSettings)
     .then(verifyCodeResult => {
        //验证码申请成功
     }).catch(error => {
         //验证码申请失败    
     });
   ```

2. 调用[AGConnectUser.updateEmail](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-agconnectuser-0000001471398626#section7264195173019)修改邮箱地址。

   ```screen
   user.updateEmail(newEmail, newVerifyCode, lang);
   ```

> 说明
>
> 对于修改邮箱地址操作，要求用户必须在5分钟内登录过应用才能执行。若登录已超时，请参见[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyts-reauthenticate-0000001522108485)先完成重认证。

## 重置密码

> 注意
>
> 重置密码时用户可以不登录。

1. 调用[AGConnectAuth.requestEmailVerifyCode](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-agconnectauth-0000001522558177#section18901230101318)申请验证码。

   ```screen
   import { EmailAuthProvider, VerifyCodeAction, VerifyCodeSettingBuilder, PhoneUserBuilder,
     PhoneAuthProvider, AGConnectAuth, AGConnectAuthCredentialProvider
   } from "@hw-agconnect/auth-ohos"

   let verifyCodeSettings = new VerifyCodeSettingBuilder()
     .setAction(VerifyCodeAction.RESET_PASSWORD)
     .setLang('zh_CN')
     .setSendInterval(60)
     .build();
   agconnect.auth().requestEmailVerifyCode('email',verifyCodeSettings)
     .then(verifyCodeResult => {
        //验证码申请成功
     }).catch(error => {
         //验证码申请失败    
     });
   ```

2. 调用[AGConnectAuth.resetPasswordByEmail](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-ts-agconnectauth-0000001522558177#section1053817349175)重置密码。

   ```screen
   agconnect.auth().resetPasswordByEmail(email, newPassword, verifyCode);
   ```

## 更多信息

* 您如果想让用户可以使用多个账号登录您的应用，可以[将多个账号进行关联](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyts-login-linkaccount-0000001471387498)。
* 当用户不需要使用应用，或者需要切换其他账号登录认证，可以先执行[登出](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyts-logout-0000001471547322)。
* 当用户需要注销当前用户，可以进行[销户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyts-deregistration-0000001522267493)。
* 对于销户、修改密码、关联账号以及重置手机账号和邮箱账号等敏感操作，为了提高安全性，需要用户必须在5分钟内登录过才能执行。如果用户执行敏感操作时登录超过5分钟，需要[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyts-reauthenticate-0000001522108485)后再执行敏感操作。
* 您可以参考[异常处理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-harmonyts-troubleshooting-0000001471227870)实现自己的异常处理机制，从而减少异常情况的发生。
* 您可以使用云函数触发器来接收用户注册、登录、销户等关键事件，从而[扩展认证服务的能力](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-extension-0000001053372708)。
* 您可以参考[管理用户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-user-manage-0000001606051705)对用户进行解锁、停用等操作。
