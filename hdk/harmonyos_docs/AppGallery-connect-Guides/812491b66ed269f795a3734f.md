# 调用自定义连接器

开发者可使用Cloud Foundation Kit提供的call方法调用云函数自定义连接器，实现元服务快速访问API接口。

1. 在项目中导入cloudFunction组件。

   ```
   import { cloudFunction } from '@kit.CloudFoundationKit';
   ```

2. 调用[call()](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/cloudfoundation-cloudfunction#call)方法，传入函数名称、连接器名称等信息，返回调用结果。
   * name：函数名称，固定为"common-connector-execution"。
   * data.connectorName：连接器名称，本例为"test_001"。
   * data.apiName：连接器方法名称，本例为"method_h2s0e"，代理https://connect-api.cloud.huawei.com/下的所有接口。
   * data.path：访问接口路径，本例实际访问路径为"https://connect-api.cloud.huawei.com/posts/50"，即由您配置的域名+路径拼接而成。
   * data.method：请求方法类型，可为GET、POST、PUT、DELETE等。
   * data.isDebug：对应连接器的状态，草稿态（debug）或发布态（release），参数缺省时默认为release。本地调试时设置为debug，发布时设置为release。
   * data.header：访问接口的请求头。
   * data.body：访问接口的请求体。

   ```
   import { cloudFunction } from '@kit.CloudFoundationKit';
   import { hilog } from '@kit.PerformanceAnalysisKit';

   async function invoke() {
     try {
       let res: cloudFunction.FunctionResult = await cloudFunction.call({
         name: "common-connector-execution",
         data: {
           connectorName: "test_001",
           apiName: "method_h2s0e",
           path: "/posts/50",
           method: "PUT",
           isDebug: "debug",
           header: "header",
           body: {
             "userId": "test",
             "title": "test connector",
             "body": "test connector"
           },
         }
       })
       // 处理JSON形式的返回体
       hilog.info(0x0000, 'testTag', `Succeeded in calling the function, result: ${JSON.stringify(res.result)}`);
     } catch(err) {
       if (err) {
         hilog.error(0x0000, 'testTag', `Failed to call the function, code: ${err.code}, message: ${err.message}`);
         return;
       }
     }
   }
   ```
