# 定时触发器

您可以为云函数配置定时触发器，在指定的时间点触发云函数。  

#### 前提条件

您已[创建函数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/cron-create-and-config-func-0000001664968592)。  

#### 创建定时触发器

1. 在函数列表中点击函数名称进入函数详情页面。如果点击函数名称右侧"操作"列的"别名"，则在别名列表中点击别名名称，进入别名详情页。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251205152527.86668849740814319306663797054837:50001231000000:2800:D4334D475C08423D3539F5C0685E7631604E55CBB43CD465FA7B414F27CD9DD4.png)

2. 点击"触发器"页签下的"添加触发器"，显示触发器创建界面。
3. 在"添加触发器"页面，"触发器类型"选择"定时触发器"，并配置"触发器名称"、"日程表"、"调用方式"和"启用"状态等信息。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251205152527.85404365953761968627895944211143:50001231000000:2800:169AD8067B104EE0D47426FBFEF3EEAB59AE6E61207A139450B3E7717062E0B7.png)

   |参数|说明|
   |:----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |触发器类型|定时触发器。|
   |触发器名称|触发器的名称，仅起到显示作用。|
   |事件值|触发函数时传入的事件，即函数的入参。格式为JSON字符串。|
   |日程表|触发函数的时间计划。支持如下两种格式： * Every表达式 @every value unit格式，其中value为一个正整数，unit可以为"s"、"m"、"h"，表示每隔value unit的时间触发一次函数。例如，"@every 6m" 表示每隔6分钟触发一次函数。 * Cron表达式 cron(Minute Hour Day-of-month Month-of-year Day-of-week)格式，即kubernetes cronjob支持的标准的cron表达式的形式 * Minutes：值范围0-59，支持括号内的特殊字符（, - \* /） * Hours：值范围0-23，支持括号内的特殊字符（, - \* /） * Day-of-month：值范围1-31，支持括号内的特殊字符（, - \* /） * Month-of-year：值范围1-12或JAN-DEC，支持括号内的特殊字符（, - \* /） * Day-of-week：值范围0-6或SUN-SAT，支持括号内的特殊字符（, - \* ） 说明： cron在欧洲站点以UTC时间运行，在非欧洲站点以北京时间运行。|
   |调用方式|支持同步调用和异步调用。|
   |启用|是否启用该触发器，默认为不启用。由于定时触发器配置完成后暂不支持修改启用状态，请配置为"是"以启用触发器。|

4. 触发器配置完成后点击"确定"保存触发器，则回到触发器列表，可看到定时触发器图框。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251205152527.04765297166783691503156405464751:50001231000000:2800:BFA353596F8F74B4A39E1120AC2F99772D0A40F502E287B61EEF0ED88F409D1D.png)
