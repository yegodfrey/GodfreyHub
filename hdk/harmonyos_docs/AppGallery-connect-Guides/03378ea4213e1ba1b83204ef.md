# 幻休

## 客户需求

《幻休》是一款助眠、冥想、放松与缓解压力的健康应用，支持睡眠监测记录、梦话鼾声录音与白噪音减压放松。该公司十分重视用户体验，对用户遇到的ANR、应用启动慢等性能问题极其关注，希望可以系统地监测各类性能问题，以便准确定位和及时解决。

## 华为解决方案

《幻休》接入性能管理服务后，该公司通过ANR分析、体验分析、应用分析、网络分析等功能，迅速定位出导致卡顿等问题的原因，经过及时优化更新解决了问题，服务使用前后性能指标大幅度优化，极大提升了用户体验。

* 近60天应用启动耗时趋势：应用启动耗时中位值由1500ms降低至350ms，启动速度提升了77%。
