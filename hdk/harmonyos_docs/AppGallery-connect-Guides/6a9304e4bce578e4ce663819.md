# 调测应用内消息

由于应用内消息只在应用正式上架后的正式用户终端设备上展示。为了确保您应用内消息设置的正确性，应用内消息提供了在应用正式上架前调测消息的方法。

## 前提条件

* 已[添加应用内消息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-appmessage-create-android-0000001072054882)。
* 已[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-appmessaging-integratesdk-android-0000001072532718)。

## 调试消息

> 说明
>
> 分配了"管理员"、"APP管理员"、"运营"或"开发"角色的账号才可以调测应用内消息。

1. 获取测试设备的AAID（Anonymous Application Identifier）。
   1. 集成AGC Credential SDK。

      ```screen
      implementation 'com.huawei.agconnect:agconnect-credential:1.9.3.301'
      ```

   2. 调用[AGCInstanceID](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-agcinstanceid-android-0000001204162951)获取AAID。

      ```screen
      String aaid = AGCInstanceID.getInstance(context).getId()
      ```

2. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
3. 在项目列表中点击您需要调试应用内消息的项目。
4. 点击"增长 > 应用内消息"，找到需要调试的消息，点击"操作"列的"调测"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155406.88225667984773379160153928061896:50001231000000:2800:7F1CD57F5B816000B4DADC635EECAFECE8DD6B1FFD28EC06596B09027D5A83BD.png)

5. 点击"应用内消息调测"界面上的"新增测试用户"，输入测试设备的AAID，点击"保存测试"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155406.70156103927080692638882986927398:50001231000000:2800:AD0385033C21332B898FDBC12F2662A2201345AF389C7A8CD69499CEC72ECAB8.png)

6. 在弹出的"提示"框中，点击"确定"。
7. 在调试代码中调用[AGConnectAppMessaging.setForceFetch](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectappmessaging-android-0000001057483901#section57591365406)(String triggerEvent)，强制请求AGC服务端消息数据。

   ```screen
   "Java"
   AGConnectAppMessaging.getInstance().setForceFetch("your trigger event"); 
   ```

   ```screen
   "Kotlin"
   AGConnectAppMessaging.getInstance().setForceFetch("your trigger event");
   ```

   调用[setForceFetch](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectappmessaging-android-0000001057483901#section57591365406)接口后，SDK将强制从AGC服务端获取消息数据，并获取测试设备信息。后续在测试设备中触发消息事件时，该测试设备都会强制到AGC服务端获取消息数据，而不是从本地缓存读取。
   > 注意
   > * setForceFetch方法仅可以在调测消息时使用，在正式的版本中不能调用该方法。
   > * App Messaging SDK会记录您调用setForceFetch方法的次数（最多5次），请确保最多5次尝试成功绑定设备的AAID（将您在AGC控制台上配置的测试设备的AAID与当前设备上的AAID保持一致）。如果超过5次，则需要卸载应用重装或者清除应用数据，setForceFetch方法的调用次数将会重置。
   > * 您可以在setForceFetch日志中搜索关键字：This device is a test device，若查到此日志，说明测试设备绑定成功。
8. 触发一次消息事件，使得应用内消息SDK去AGC服务端刷新测试设备列表，查看测试消息能否正常展示和操作。 有关测试设备和测试消息的具体说明如下表所示。

   > 说明
   > * 为了让调测消息尽快地展示出来，除了触发消息本身配置的触发事件外，当应用回到前台再次被打开时（触发AppLaunch和AppOnForeground事件）也可以实现此目的。
   > * 调测消息不受消息展示时间、频率等因素影响。例如，一条消息原本的展示时间应为第二天，但如果用该条消息来做调测，在调测设备上当前时间仍能显示。

   |类型|目的|说明|
   |:---|:----------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |测试设备|测试设备实时同步AGC服务端数据，不受应用内消息SDK请求次数的限制。|您在AGC中添加了该设备的AAID，并通过[AGConnectAppMessaging.setForceFetch](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectappmessaging-android-0000001057483901#section152131924510)方法设置了强制请求的标志位，下一次消息事件触发后该设备强制从AGC服务端同步了消息数据，此时开发者的设备为测试设备。 判断开发者的设备是否是测试设备的方法：每次触发事件都会去AGC服务端实时请求数据。|
   |测试消息|让开发者快速获取消息的内容、展示布局等。|在"应用内消息调测"页面，新增测试用户，点击"保存测试"后该条消息为测试消息。 测试消息只会展示一次。如果您想再次展示测试消息，需要重新进入"应用内消息调测"页面，点击"保存测试"将消息设置为测试消息。|
