# 打印错误日志

为了从库实例中接收错误消息，应在传递给FrameFlowVK_Create的FFVKInstanceCreateInfo结构体中定义pfnErrorReportCallback：自定义的错误日志打印回调函数。

函数定义声明如下：

```screen
typedef void(FFAPI_PTR *PFN_FrameFlowVK_ErrorReportCallback)(char const *pMessage, void *pUserData)
```

* pMessage：指向游戏定义上下文的指针。
* pUserData：错误报告日志内容，与[FFVKInstanceCreateInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffvkinstancecreateinfo-0000001791494432)结构体中pUserData相同。
