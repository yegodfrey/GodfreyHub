# 查看风控结果

当玩家将视频导出并分享后，云侧会异步扫描审核，您可在AGC控制台查看到审核结果，并可根据"审核结果"以及"未通过原因"进行人工复审，以确保风控审核的准确率。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，并在项目下的应用列表中选择您的游戏应用。

3. 在左侧导航栏中选择"构建 \> 高光时刻"，进入高光时刻服务页面。

4. 在"分享查看"页签下，即可查看到视频的审核结果，并可根据不同审核结果进行相关操作。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260116101402.27926149563708497921068432380244:50001231000000:2800:C75188C97120864834284A53428EEA1B9093EB27BC1946D060141BF1A03C924E.png)

   |审核结果|说明|
   |:---|:-------------------------------------------------------------------------|
   |未通过|视频存在涉嫌"暴恐"、"政治敏感"、"色情"、"辱骂"、"广告"、"文本违规"等违规内容，不允许继续被分享，已分享的视频链接将无法继续访问视频资源。|
   |审核失败|风控审核失败，建议您点击"视频预览"，进行人工复审，并根据人工审核结果决定是否"允许分享"该视频。|
   |未审核|视频暂未风控审核，建议您稍后查看，同时您也可以点击"操作"列"允许分享"或"停止分享"进行人工干预。|
   |审核中|视频正在风控审核中，建议您稍后查看，同时您也可以点击"操作"列"允许分享"或"停止分享"进行人工干预。|
   |通过|视频风控审核已通过，未发现违规内容，您可根据需要决定是否"允许分享"该视频。|
   |可疑|视频内容存在疑似违规内容，建议您进行人工复审，并根据人工审核结果决定是否"允许分享"该视频。|
