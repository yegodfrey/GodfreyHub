# 多数据处理位置使用指导

#### 功能概述

预测服务支持启用多个数据处理位置，启用多个数据处理位置并开通预测服务后，可以将预测数据上报到多个数据处理位置并查看不同数据处理位置的预测报告。

#### 前提条件

  * 已创建项目，并在项目中添加了应用。
  * 项目已开通华为分析服务，且华为分析开通了多数据处理位置功能，详细操作请参见[多数据处理位置使用指导](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/multi-storage-0000001206082423)。



#### 操作步骤

#### [h2]启用数据处理位置

  1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击“我的项目”图标。
  2. 在项目列表中，找到您想增加数据处理位置的项目。
  3. 点击“华为分析”下的任意菜单，如“项目概览”。在页面左上角下拉框处选择需要启用的数据处理位置。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220927160611.77341747389583697342694914103447:50530926093051:2800:3036256BB13573E61ACA2B544B9F43479F155437DF7EF348B87ABCCF71CEBD76.png?needInitFileName=true?needInitFileName=true)

  4. 点击“增长 > 预测”，在开通预测服务页面点击“开通预测服务”。

预测服务已开通完成，且该数据处理位置也已启用。

  5. 在预测服务界面的左上角，切换其他数据处理位置，并点击“启用该站点”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220927160611.74676057489022996144859067375292:50530926093051:2800:09929A9C1F4DD627C77D7B42725CE163C8359F45294E5AFD6D37B3BFB4B47E74.png?needInitFileName=true?needInitFileName=true)

  6. 重复操作步骤5，启用其他数据处理位置。



#### [h2]取消已启用数据处理位置

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220927160611.80539472353970223034900471064799:50530926093051:2800:F185C3E9E626FDCCD69D782E794F015BBFF8CCE9A9E407F4842A375C0ADDD801.png?needInitFileName=true?needInitFileName=true)

  * 取消已启用数据处理位置后，会关闭该数据处理位置的服务并清除对应的数据，且数据清除后无法恢复。
  * 默认数据处理位置不支持取消启用，但支持修改默认数据处理位置。



  1. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击“我的项目”图标。
  2. 在项目列表中找到您想取消数据处理位置的项目。
  3. 进入“项目设置 > 常规”页面，在“项目”下点击“数据处理位置”后的“管理”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220927160611.15795114631013121001430117984650:50530926093051:2800:46115854D6815D6B081978CC93F1E7D5519BA41666529D1991ABE596C15B0D15.png?needInitFileName=true?needInitFileName=true)

  4. 在想要取消启用的数据处理位置对应的“启用”栏进行去勾选，点击“确定”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220927160611.49677200442915175644262919192054:50530926093051:2800:9CA57BE7B71DDD0015593FF4D55BF669FFF0A72EEA4464232F3797BA887B3BBA.png?needInitFileName=true?needInitFileName=true)

  5. 界面弹出“取消启用数据处理位置”对话框，请阅读弹框内容，确认并勾选操作提示项，点击“同意并继续”。
