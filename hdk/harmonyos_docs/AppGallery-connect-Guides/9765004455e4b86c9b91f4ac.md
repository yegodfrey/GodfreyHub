# 技术支持

当您使用AGC相关服务遇到问题时，可以按照以下顺序寻求帮助。

1. 查看[FAQ](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudhosting-faq-0000001058572540)、[问题处理案例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudhost-handcases-0000001152452684)和[错误码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-cloudhost-errorcode-0000001260940301)。
2. 通过[AI助手](https://developer.huawei.com/consumer/cn/customerService/#/bot-dev-top/faq-top/faq-talk-top)查找问题解决方案。
3. 登录[Stack Overflow社区](https://stackoverflow.com/questions/tagged/appgallery-connect)和[华为开发者社区](https://developer.huawei.com/consumer/cn/forum/block/ag-connect)参与问题讨论。
4. 如果以上方法仍未解决您的问题，可以通过[在线工单系统](https://developer.huawei.com/consumer/cn/support/feedback/#/add/89?level2=101594901540020580)与我们进行联系。
