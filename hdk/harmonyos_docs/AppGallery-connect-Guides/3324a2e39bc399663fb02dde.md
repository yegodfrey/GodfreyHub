# （可选）下载项目级认证凭据

Server SDK初始化过程中需传入认证凭据。不同服务类型支持不同的凭据类型，云函数服务目前支持项目级凭据。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击您的项目。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704165810.29778112554983494674199202448012:50001231000000:2800:2CE2EAF4126449223A77A4E4F61C67CCD9D3B0440B1CCCE92C23964B98E70DA6.png)

3. 在"项目设置"页面中点击"Server SDK"页签。
4. 点击认证凭据中的"创建"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704165810.22440834692188350095981508291669:50001231000000:2800:EB4684E1AB58FE334F0B91B8541A718C2696ACA91C19AAC01FBFA4DE5331823A.png)

5. 创建完后生成认证凭据，点击"下载认证凭据"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704165811.40820967133035914029008895916277:50001231000000:2800:CD2AB86C144652F26266F7BE83252750CF6223673467FF91FFE6B975E8A466A8.png)

6. 将下载后的认证凭据文件agc-apiclient-\*.json放置到您的Server服务器中指定路径下，后续初始化SDK时将会使用到该文件。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704165811.86617039317806924256575341159706:50001231000000:2800:7FE63F6C6508DC3821CA9E699D7716FCA7965664F7E6570DAA793157D3FB52AA.png)  
凭据文件中包含您的client_secret信息，请您妥善保管。
