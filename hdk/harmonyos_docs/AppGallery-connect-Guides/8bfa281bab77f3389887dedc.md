# 应用上架

#### 自检应用

参考[接入检测](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-self-check-0000001100158786)中的步骤使用自检工具对应进行自检，并根据自检报告修改应用。  

#### 了解上架规则

开发者完成集成服务，提交应用上架前，请先了解如下上架规则和审核常见问题：

* [华为应用市场上架审核指南](https://developer.huawei.com/consumer/cn/devservice/doc/50104)
* [应用审核FAQ](https://developer.huawei.com/consumer/cn/devservice/doc/50106)  

#### 提交上架申请

加载了动态特性模块的应用开发完成后，需要打包成AAB文件后在AppGallery Connect中提交上架申请，具体上架操作请参考[App Bundle应用上架](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-releasebundle-0000001100316672)。
