# 层管理

## 功能概述

> 注意
>
> 此功能为可选功能，请开发者根据实际需要来选择使用。

层是包含库和相关依赖项的ZIP存档包。通过为函数绑定层，您可以在函数中使用库，而不必将库包含在云函数的部署程序包中。

AGC云函数支持层的管理，为您提供公共依赖库的部署与发布能力。通过层来管理具有通用性或不变性的依赖、静态文件等，以此精炼云函数代码，从而达到缩小代码包大小与缩短部署时间的效果。

AGC云函数支持一个函数最多可以绑定5个层。
> 注意
>
> 上传的层包大小限制在150MB以内，解压后的层包大小限制在300MB以内。

* Node.js层结构：

  ```screen
  |---nodemodule.zip
      |---相关配置项
      |---node_modules
          |---moment  //相关依赖项
  ```

* Java层结构：

  ```screen
  |---libdemo.zip
      |---config
          |---application.properties  //相关配置文件
      |---lib
          |---*.jar //相关jar依赖
  ```


* Python层结构：

  ```screen
  |---layer.zip
      |---相关配置项
  ```

具体使用场景举例如下：

1. 开发者开发云函数代码，通过相对路径的形式引用依赖。
2. 依赖打包：按照层文件要求，将依赖单独封装为一个zip包，创建层layer1时上传此zip包。
3. 函数打包：按照函数打包要求，将其余未打包的代码文件，单独封装成一个函数zip包，创建云函数并上传。
4. 开发创建第二个云函数，可直接引用层layer1中的依赖。一份依赖文件不需要在两个云函数的代码包中重复上传，从而减少了函数代码包的大小和部署时间。

## 创建层

1. 在云函数主界面，选择"层"页签。
2. 在层管理页面，点击"创建层"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260302154858.47545922246320024093118182108477:50001231000000:2800:24F5CD8A9FB18D8C25F4CA9D836B4AAF65FB8088E27AC04A1835D0DAC77E5D85.png)

3. 页面右侧抽屉式滑出"创建层"窗口，配置"层名称"、"层范围"等信息。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260302154858.10188384059558103049385860780492:50001231000000:2800:B11D338DBCAFC3EB8A3D510D18E6236E7027BE78746FF581372E0638E044AFB9.png)

   |参数|说明|
   |:-----|:------------------------------------------------------------------|
   |层名称|层的名称。重复时自动在同名的层中创建一个新版本。|
   |层描述|对正在创建层的附加说明。|
   |层范围|层的共享范围。 * 团队内共享 * 项目内共享|
   |兼容运行时|层使用的语言环境。支持多选。 * nodejs * java * python * custom-runtime|
   |代码输入类型|代码输入类型，仅支持上传zip文件。 > 说明 > ZIP包大小最大为150MB，解压后最大300MB，文件数最多不超过30000个。|
   |选择文件|选择上传的zip文件。|

4. 点击右下角"创建层"，保存层信息，您已创建的层将展示在层列表中。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260302154858.97750358971597159217619431341428:50001231000000:2800:AFEBC41E0781D0BFD3AC97E75C0426A6770308262E928669B844F838581AE3C2.png)

## 更新层

发布的层版本会按序累加，例如：最新的层版本是1，删除版本1后，再发布层版本，此时版本是2。

1. 点击您已创建的层，进入层详情页面。
2. 点击右侧"发布"，右侧抽屉式滑出"发布层版本"窗口。
3. 在"发布层版本"窗口中配置"层范围"、"兼容运行时"、"代码输入类型"等信息。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260302154858.52464684626993205743973764584082:50001231000000:2800:4BB04B602A6EAF7647ECFF9C67A45781747A505D18E92D7FCFE61F02D9773A12.png)

   |参数|说明|
   |:-----|:--------------------------------------------------------------|
   |层描述|对正在创建的层的附加说明。|
   |层范围|层的共享范围。 * 项目内共享 * 团队内共享|
   |兼容运行时|层使用的语言环境。支持多选。 * nodejs * java * python * custom-runtime|
   |代码输入类型|代码输入的文件类型，zip文件。 > 说明 > ZIP包大小最大为150M，解压后最大300M，文件数最多不超过30000个。|
   |选择文件|选择上传的zip文件。|

4. 点击右下角"发布层版本"，保存层的版本信息，您已创建的新版本层将展示在层详情页版本列表中。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260302154858.73074508668597204888759567424947:50001231000000:2800:BC512AA288A835F5D3FFF15555B4394ADF63B0114D53AA1F27446C32323A676D.png)

## 删除层版本

删除层版本，已经绑定在函数中的层不会失效。

1. 在您已创建的层列表中，找到待删除的层，点击层进入详情页。
2. 点击待删除层版本右侧"操作"列的"删除"，即可删除层版本。当所有层版本被删除时，层即被删除。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260302154858.43746306920976645720810031507630:50001231000000:2800:CD432788EB0F7A5957EA922526A3C640F3ACCE31951C74C9A04EA65885B747CB.png)

## 删除层

在您已创建的层列表中，找到待删除的层，点击右侧对应"操作"列的"删除"。
> 注意
>
> 删除层将同步删除层中的所有版本，不可恢复，请您谨慎操作。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260302154858.51391263957326252634586403630748:50001231000000:2800:47CC3E683F4F61B4A1FED52440232FA27F6159FCB7BEC2C5B63A9062D4F95C8B.png)

## 查询层

1. 进入层列表管理页面，在搜索框中通过层名称进行模糊搜索。
2. 如果您需要选择模糊搜索的范围，您可以通过点击"我的"和"共享"两个页签来进行过滤，在层列表中将展示相应的查询结果。
   * 我的：开发者自己创建的。
   * 共享：同项目+同团队下共享的。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260302154858.46322626134775979716836424655677:50001231000000:2800:FE5560594245FBCB074F74E7EC53C1CF9573398855B48776903B62FB166BF218.png)

## 将函数绑定层

1. 在函数别表中点击函数名称，进入函数详情页面。选择"层配置"页签，点击右上角的"绑定层"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260302154858.40805014171587153977899349797354:50001231000000:2800:F2F2FC354A51B8DB62B15120D71CD41F26FFF19A279610D586A0ACCCE2486743.png)

2. 在右侧弹出的"绑定层"界面中，下拉框选择"层名称"和"版本"，"层范围"等信息根据层的配置将被自动填充，完成层绑定后点击"确定"。 注意
   > * 一个函数最多可以绑定5个层。
   > * 选择层时，层的兼容运行时需与函数运行环境相符，否则系统报错，绑定层失败。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260302154858.54039627501363644491807250939038:50001231000000:2800:092169D79E07A9F0C69ACA0E87B6EBF14EC30281CCAEEF29D054CFAD58954371.png)

   |参数|说明|
   |:----|:--------------------------------------------------|
   |层名称|层的名称。重复时自动在同名的层中创建一个新版本。|
   |版本|存在多个层版本时，选择函数绑定的层版本。|
   |层范围|层的共享范围。 * 项目内共享 * 团队内共享|
   |兼容运行时|层使用的语言环境。 * nodejs * java * python * custom-runtime|
   |层描述|层的附加说明，长度不超过1024位。|

3. 返回到"层配置"界面，绑定成功的层将展示在层列表中。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260302154858.15361508385620380562574199382517:50001231000000:2800:708FF5B005BE1531F2085C055D6B74E496EB090C90533BC3F5EC75E619F3B442.png)

## 将函数解绑层

1. 进入函数详情页，选择"层配置"页签。可在文本框中输入层名称进行模糊筛选。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260302154859.11918480203338057175449876432810:50001231000000:2800:64F7916BB522AAC9982C3EFA9213B1C7B2FA1A2CB5FD7199AD2A7D919AE599FF.png)

2. 点击层名称对应"操作"列的"解绑"，然后在"提示"弹出框中点击"确定"，函数与层解绑成功。 说明
   >
   > 此处只是解除了函数与层的绑定关系，并没有真正删除层数据。如果您需要真正删除层数据，具体请参见[删除层](#section163581231182117)。
