# 通过控制台测试

> 说明
>
> 下文以函数latest版本为例介绍测试方法。若您需要测试函数的已发布版本，可在已发布版本详情页面选择"函数代码"页签，参考方式二进行测试。

函数创建后您可以在AGC控制台测试函数的代码运行是否正常。进入测试界面有两种方式：

* 方式一：函数列表中点击函数名称右侧"操作"列的"测试"，在右侧弹出的"测试函数"界面进行测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3c/v3/Y4o-Y02sQZCahv9Z4by1RA/zh-cn_image_0000001978548797.png?HW-CC-KV=V1&HW-CC-Date=20261008T163732Z&HW-CC-Expire=31536000000&HW-CC-Sign=ADABF92E737991FFB43A2EAEEB3EE10B6ED61A7DC60EF7D181670B276DACEAA4)

* 方式二：
  1. 在函数列表中点击已创建的函数名称，进入函数详情页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2b/v3/1XcefFOSQVKgq9KXLjEBZg/zh-cn_image_0000001948908550.png?HW-CC-KV=V1&HW-CC-Date=20261008T163732Z&HW-CC-Expire=31536000000&HW-CC-Sign=610698358C9CF19D814CD3812D7633B9B4F08D378841DEC5BDA84D04DF078384)

  2. 选择"函数代码"页签，点击"测试函数"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/45/v3/p8kf2YrzQ5uafROHiFe4ew/zh-cn_image_0000001800662133.png?HW-CC-KV=V1&HW-CC-Date=20261008T163732Z&HW-CC-Expire=31536000000&HW-CC-Sign=48AD03D963EF919FC3299C5A9A9EF798891AF9A278BA48839301FA0C12B2DE0B)

  3. 在右侧弹出的"测试函数"界面，使用默认测试事件、创建新测试事件或者使用已保存测试事件进行测试。
     * 使用默认测试事件 直接点击"测试"对函数进行测试。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f5/v3/YxR0ETsSQSC5z1PVdsYH-g/zh-cn_image_0000001722152221.png?HW-CC-KV=V1&HW-CC-Date=20261008T163732Z&HW-CC-Expire=31536000000&HW-CC-Sign=E4F07649FACF0EC6C708C74AFC5418DA50A71E70985B7B00C56E2A7EDAD8D5C3)
     * 创建新测试事件 如果需要设置调用函数的请求消息体，可按照如下步骤配置测试参数，并可保存为测试事件方便后续继续使用。

       1. 在"事件"文本框中输入JSON格式的事件参数，点击"保存"。然后在"提示"弹出框中输入事件名称，配置完成后点击弹出框右下角的"确认"。 说明
          >
          > "事件"文本框内输入的JSON对象，对应的是触发器的event事件格式，会透传给函数。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/dc/v3/J9R3rfvYRai5qOIGvHbatA/zh-cn_image_0000001756189981.png?HW-CC-KV=V1&HW-CC-Date=20261008T163732Z&HW-CC-Expire=31536000000&HW-CC-Sign=327F10B790F3DB10FB4B05F7F0D6B3A7F3BA5A504C0A8D9670CBF3CB78DB3001)
       2. 点击"测试"，函数处理事件并返回测试结果。
     * 使用已保存测试事件
       1. 在"测试函数"界面，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3a/v3/UrI1PsqNQAaw73YoscA6IA/zh-cn_image_0000001722236597.png?HW-CC-KV=V1&HW-CC-Date=20261008T163732Z&HW-CC-Expire=31536000000&HW-CC-Sign=BFD2787B587D12DE93A017FCF9D9F3145F1F32A6750A472FE658674F6ED50F6B)展开已保存的测试事件列表，选择已配置的事件名称右侧的"加载"，然后点击"测试"，函数处理事件并返回测试结果。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7a/v3/5GLzOzy0Q8yrJQuK2rQynA/zh-cn_image_0000001722453985.png?HW-CC-KV=V1&HW-CC-Date=20261008T163732Z&HW-CC-Expire=31536000000&HW-CC-Sign=D2BD2FF704A1B6300BE4777DA8B53957BB5014F386ED87ADAFB5DF0FC31E1D12)
       2. （可选）若您需要删除已添加的测试事件，可在测试事件列表中点击事件名称右侧的"删除"即可删除测试事件。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/68/v3/S2AUK24ARaST99Q9p7vqpw/zh-cn_image_0000001722158501.png?HW-CC-KV=V1&HW-CC-Date=20261008T163732Z&HW-CC-Expire=31536000000&HW-CC-Sign=FB64DFE04AEB30BD871CF792B698BEB82E3F96EAB8CDC031BDB283CA1861FF05)

  4. 查看测试结果。
     * 执行结果：展示测试后获得的响应结果。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ff/v3/aYB-BZ95SreofCdmelUMgA/zh-cn_image_0000001674184734.png?HW-CC-KV=V1&HW-CC-Date=20261008T163732Z&HW-CC-Expire=31536000000&HW-CC-Sign=9D7A693C390F3D124DEE9171AB3727182BE355296A87B30D22546BB299074F82)

     * 运行日志：展示函数运行过程中，通过logger API打印的日志，支持输出debug级别及以上日志（以下仅为日志输出示例）。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c0/v3/WbOR2S4nSTCaf1A1-p8QFg/zh-cn_image_0000001674190046.png?HW-CC-KV=V1&HW-CC-Date=20261008T163732Z&HW-CC-Expire=31536000000&HW-CC-Sign=FB6C58A4318594E0AF58F7B034A228406EBAC2009D4A29A65F704399158FB0F4)

     * 执行摘要：展示该次测试请求相关信息。
       * 请求ID：该条测试请求的RequestID，在后台日志中体现为X-Trace-ID。
       * 持续时间：函数执行的端到端时间。
       * 执行版本：该次调用测试的具体函数版本。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/84/v3/M5_1ivePQ0-4kTYB72zmUA/zh-cn_image_0000001674344770.png?HW-CC-KV=V1&HW-CC-Date=20261008T163732Z&HW-CC-Expire=31536000000&HW-CC-Sign=43F54B7CDF2F6508B8AA308C0CE17962DCF9B3F47F484E6DDD428516FD5A7B48)
  5. "代码输入类型"为"在线编辑"的函数，测试过程中，若您需要修改函数入口文件代码，可直接在"函数代码"页签的代码编辑器中修改，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7e/v3/LftlsUpBTCqzE7OIIzEfoQ/zh-cn_image_0000001753703418.png?HW-CC-KV=V1&HW-CC-Date=20261008T163732Z&HW-CC-Expire=31536000000&HW-CC-Sign=7E986F556C412B267278072CB3E484221D5604879DA09BFAD37C5CE3B24EBB14)

     "代码输入类型"为".zip文件"的函数，测试过程中，若您需要修改函数代码文件，可在本地修改且打包完成后，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/43/v3/qkiBCjfhS_2QhBBO-gLscw/zh-cn_image_0000001717161230.png?HW-CC-KV=V1&HW-CC-Date=20261008T163732Z&HW-CC-Expire=31536000000&HW-CC-Sign=E166E3A9423268732BFAD92F672A6406533670483FC8870647D5E12CDDB6F4DF)重新上传函数部署包，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。
     > 说明
     >
     > 若代码更新量比较大，需要调整函数内存配置，可点击"内存配置"下拉框进行调整，然后再上传函数部署包。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/21/v3/gKAP8WQFSXOy9ab-VAIhcQ/zh-cn_image_0000002433940774.png?HW-CC-KV=V1&HW-CC-Date=20261008T163732Z&HW-CC-Expire=31536000000&HW-CC-Sign=A074BC14DDD0686DCB986714163DC528793087224CE878E50727E5A017C764E6)
  6. 函数测试无误后，您可在"函数代码"页签点击"导出函数"导出函数部署包。导出包以"函数名称+函数版本.zip"格式命名，可查看函数结构和文件内容。
