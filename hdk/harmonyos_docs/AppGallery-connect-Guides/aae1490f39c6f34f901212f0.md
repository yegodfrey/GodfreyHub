# AppUpdateInfo

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:-----------|:---------------------------------|
|appId|O|String|应用AppId。|
|pkgName|M|String|应用包名。|
|versionName|M|String|应用版本名。 例如：1.1.0|
|versionCode|M|Integer (64)|应用版本号。|
|appSign|M|String|应用签名信息。 此字段可以通过代码读取，也可以从应用详情接口中获取。|
