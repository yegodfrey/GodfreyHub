# 导入Package

在团结Editor中导入PGD Package，为接下来的游戏开发做准备。

## 前提条件

[下载PGD C# Package](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Library/sdk-0000002468289653)。

PGD动态库运行的目标框架为.NET Standard 2.1。

## 导入方式一：使用团结Editor

1. 在团结Hub打开项目工程。
2. 进入团结Editor，点击"Window > Package Manager"，打开Package Manager，点击左上角"Add Package From Disk"，将本地下载好的PGD导入团结工程。 说明
   >
   > com.huawei.pgd为示例包名，请以实际下载的PGD Package文件名为准。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110214.74806868973658387229956887552509:50001231000000:2800:4B892AA680DAE069D087FD927114D23EF9CA2949E52720AF4C16BFE1FD4F1D41.png)
3. 导入成功后，在"Window > Package Manager"中查看。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110214.69091570068504016603719264357491:50001231000000:2800:19C7803BC1E2C41B87561457A5F6BB87069D339AF2F925D0F07016DAAB4FDD2D.png)

## 导入方式二：使用资源管理器

此处以Windows操作系统的资源管理器为例，My project为游戏项目工程。

1. 将PGD Package放入My project项目工程的文件夹内。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110214.68106949114144626166033317353340:50001231000000:2800:6C4E5690419314548AC8685EFC8280329A6FED0C8D9CF5C8DD3DCF0BF1FBFD9A.png "点击放大")

2. 打开当前项目工程文件夹内的Packages，修改manifest.json文件，在dependencies内新增com.huawei.pgd的依赖，并配置到com.huawei.pgd所在的文件夹。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110214.65695914075484035863074449883442:50001231000000:2800:D7B40841A7DAA88B6D884B41A63EF9F1DDD226F14ADC025A9F90936099EC4362.png "点击放大")

   "com.huawei.pgd"建议使用相对路径，请根据实际情况填写正确路径。
