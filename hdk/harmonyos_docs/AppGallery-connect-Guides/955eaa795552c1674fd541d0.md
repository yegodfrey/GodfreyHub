# 依赖事件说明

预测任务能否顺利完成，依赖于您的应用是否上报充足的相关事件。本章节将为您详细介绍不同预测任务依赖的上报事件，该事件说明可能会随着预测任务的增加随时更新，请您注意文档变化。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220927160610.98526899662398605253357734946022:50530926093051:2800:498164FE9BC010D4A1167E460F926AB284211E14D9821D4AEE238735D5399C32.png?needInitFileName=true?needInitFileName=true)

自动采集事件无需埋点，只需开启采集系统事件的开关（初始化时自动开启），即可实现此类事件的自动采集。预置事件需要您在产品代码中做相应埋点，具体可参见[预置事件使用说明](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-usage-guide-0000001135571462)。

#### 流失用户预测依赖事件列表

事件ID | 说明 | 事件类别  
---|---|---  
LAUNCHAPP | 用户打开应用时，上报此事件。 | 自动采集事件  
ENTERSCREEN | 进入Activity时触发此事件。 | 自动采集事件  
UNINSTALLAPP | 用户卸载应用时，触发此事件。 | 自动采集事件  
SIGNIN | 用户通过Account Kit登录时，上报此事件。 说明：  上报此事件，您需要集成[华为帐号服务](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/introduction-0000001050048870)。 | 自动采集事件  
  
#### 付费用户预测依赖事件列表

事件ID | 说明 | 事件类别  
---|---|---  
INAPPPURCHASE | 用户通过IAP（In-App Purchases）订购或订阅商品时，上报此事件。 说明：  上报此事件，您需要集成[应用内支付服务](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/introduction-0000001050033062)。 | 自动采集事件  
COMPLETEPURCHASE | 用户支付完成后，上报此事件。 | 预置事件  
UNINSTALLAPP | 用户卸载应用时，触发此事件。 | 自动采集事件  
  
#### 复购用户预测依赖事件列表

事件ID | 说明 | 事件类别  
---|---|---  
INAPPPURCHASE | 用户通过IAP（In-App Purchases）订购或订阅商品时，上报此事件。 说明：  上报此事件，您需要集成[应用内支付服务](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/introduction-0000001050033062)。 | 自动采集事件  
COMPLETEPURCHASE | 用户支付完成后，上报此事件。 | 预置事件  
UNINSTALLAPP | 用户卸载应用时，触发此事件。 | 自动采集事件  
  
#### 自定义预测依赖事件

自定义预测任务能否完成，取决于您是否已上报充足的目标事件，若预测任务无法完成，请尝试上报更多相关事件。

#### 具体事件参数

  * LAUNCHAPP

用户打开应用时，上报此事件。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
$StartType | 应用启动方式 | String | 必选 | 应用启动方式。  
$TaskId | 任务ID | String | 可选 | 营销任务ID。  
  


  * ENTERSCREEN

进入Activity时触发此事件。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
$PrevActivityName | 来源Activity名称 | String | 必选 | 来源Activity名称。  
$PrevActivityClass | 来源Activity类名 | String | 必选 | 来源Activity类名。  
$PrevActivityId | 来源Activity TaskId | String | 必选 | 来源Activity TaskId。  
$CurActivityName | 当前Activity名称 | String | 必选 | 当前Activity名称。  
$CurActivityClass | 当前Activity类名 | String | 必选 | 当前Activity类名。  
$CurActivityId | 当前Activity TaskId | String | 必选 | 当前Activity TaskId。  
$TaskId | 任务ID | String | 可选 | 营销任务ID。  
  
  * UNINSTALLAPP

用户卸载应用时，触发此事件。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
$TaskId | 任务ID | String | 可选 | 营销任务ID。  
  
  * SIGNIN

用户通过Account Kit登录时，上报此事件。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
$Channel | 登录渠道 | String | 必选 | 用户登录的渠道。  
$EvtResult | 登录结果 | String | 必选 | 用户登录的结果。  
$TaskId | 任务ID | String | 可选 | 营销任务ID。  
  
  * INAPPPURCHASE

用户通过IAP订购或订阅商品时，上报此事件。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
$ProductId | 商品ID | String | 必选 | 被添加到购物车中的商品的ID。  
$ProductName | 商品名称 | String | 必选 | 被添加到购物车中的商品的名称。  
$Quantity | 购买数量 | Long | 必选 | 用户准备购买的数量。  
$CurrName | 货币类型 | String | 可选 | 标识收入的货币类型。与$Revenue一起使用。  
$Revenue | 收入 | Double | 可选 | 用户购买此商品，预计会给您带来的收入。必须与$CurrName同时使用。  
$PurchaseType | 购买方式 | String | 必选 | 购买商品的方式：
    * 购买一次性付费商品。
    * 购买周期自动续费商品。  
$TaskId | 任务ID | String | 可选 | 营销任务ID。  
  
  * COMPLETEPURCHASE

用户支付完成后，上报此事件。可以用于分析用户对哪些商品或内容更感兴趣，优化运营策略。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220927160610.13853192933685377792571513127697:50530926093051:2800:B6FE216373E89D4B591E49FB30248CE11F25EC94E213843A3CA3B5651FE2029C.png?needInitFileName=true?needInitFileName=true)

华为应用内支付服务（In-App Purchases，IAP）渠道发生的支付，不需要上报COMPLETEPURCHASE事件。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
PRODUCTID | 商品ID | String | 必选 | 被添加到购物车中的商品的ID。  
PRODUCTNAME | 商品名称 | String | 必选 | 被添加到购物车中的商品的名称。  
QUANTITY | 购买数量 | Long | 必选 | 用户准备购买的数量。  
OCCURREDDATE | 购买时间 | String | 必选 | 购买时间。  
CURRNAME | 货币类型 | String | 可选 | 标识收入的货币类型。与REVENUE一起使用。  
REVENUE | 收入 | Double | 可选 | 本次交易会给您带来的收入。必须与CURRNAME同时使用。  
TAXFEE | 税费 | Double | 可选 | 本次交易产生的税费。  
SHIPPING | 运输费 | Double | 可选 | 本次交易产生的运输费。  
VOUCHER | 优惠券 | String | 可选 | 用户在本次交易中使用的优惠券。  
BRAND | 商品品牌 | String | 可选 | 关联的商品品牌。  
CATEGORY | 商品分类 | String | 必选 | 关联的商品分类。  
SOURCE | 营销来源 | String | 可选 | 营销活动提供者的标识，如：HUAWEI Ads。  
MEDIUM | 营销类型 | String | 可选 | 营销活动的类型，如：CPC、EMAIL、运营坑位、BANNER等。  
PROMOTIONNAME | 营销名称 | String | 可选 | 营销活动的名称。  
CONTENT | 营销内容 | String | 可选 | 营销活动的营销内容。  
KEYWORDS | 关键词 | String | 可选 | 营销活动的关键词。如：搜索广告的关键词。  
MATERIALNAME | 创意名称 | String | 可选 | 营销活动使用的创意素材名称。  
MATERIALSLOT | 营销内容展示位置 | String | 可选 | 创意素材被展示的位置信息。  
TASKID | 任务ID | String | 可选 | 营销任务ID。
