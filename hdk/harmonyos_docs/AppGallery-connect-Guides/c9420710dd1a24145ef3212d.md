# 加入房间

当不同的玩家加入同一语音房间内，即可互相发送/接收实时音频数据。目前，游戏多媒体服务支持加入[小队语音房间](#section5143529157)和[国战语音房间](#section1069422512185)。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241105115841.37750945210372455864535733428233:50001231000000:2800:DF850888468543F825E3AC5897ECF930AC225376494F85FEBEF2656D6260C489.png?needInitFileName=true?needInitFileName=true)  
第一个加入语音房间的玩家，默认成为该语音房间的房主。  

#### 前提条件

* 您已[集成游戏多媒体SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-integratingsdk-web-0000001237731053)。
* 您已[创建游戏多媒体对象](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-engine-web-0000001194118940#section10640141401010)。
* 您已规划语音房间ID。  

#### 加入小队语音房间

1. 游戏多媒体对象创建成功后，可先调用[GameMediaEngine.on](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-web-0000001247887067#section1487511413163)方法注册[playerOnline](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-eventname-web-0000001285559041#ZH-CN_TOPIC_0000001285559041__p09082205325)和[playerOffline](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-eventname-web-0000001285559041#ZH-CN_TOPIC_0000001285559041__p63210265323)事件回调，用于加入房间成功后监听其他玩家的加入和离开。

   ```
   // 注册 playerOnline 和 playerOffline 事件回调
   gameMediaEngine.on('playerOnline', (roomId, openId) => {
     // 其他玩家已加入房间，刷新房间信息
     const {status, ownerId, roomType, players} = gameMediaEngine.getRoom(roomId);
   }); 
   gameMediaEngine.on('playerOffline', (roomId, openId) => {
     // 其他玩家已离开房间
   });
   ```

2. 调用[GameMediaEngine.joinTeamRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-web-0000001247887067#section6514143112514)方法，使用相同的房间ID即可进入同一小队语音房间。

   ```
   gameMediaEngine.joinTeamRoom(roomId).then(roomId => {
     // 加入房间成功，获取房间信息
     const {status, ownerId, roomType, players} = gameMediaEngine.getRoom(roomId);
   }).catch(err => {
     // 加入房间失败
     const {code, message} = err;
   });
   ```

#### 加入国战语音房间

在国战语音房间中，玩家分为指挥官和群众两个角色。加入房间时，玩家可根据roleType选择自身角色。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241105115841.67198125014238544260084706989897:50001231000000:2800:03B0A276C4AD5FCC1F43BD86093C107A8082F90E2D7C3A560B086CFF149D5EFF.png?needInitFileName=true?needInitFileName=true)  
* 在一个国战语音房间中，指挥官角色最多支持15人，群众角色最多支持10000人。
* 当玩家为指挥官角色时，则具备发送和接收语音的权限。当玩家为群众角色时，则仅具备接收语音的权限。

1. 游戏多媒体对象创建成功后，可先调用[GameMediaEngine.on](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-web-0000001247887067#section1487511413163)方法注册[playerOnline](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-eventname-web-0000001285559041#ZH-CN_TOPIC_0000001285559041__p09082205325)和[playerOffline](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-eventname-web-0000001285559041#ZH-CN_TOPIC_0000001285559041__p63210265323)事件回调，用于加入房间成功后监听其他玩家的加入和离开。

   ```
   // 注册 playerOnline 和 playerOffline 事件回调
   gameMediaEngine.on('playerOnline', (roomId, openId) => {
     // 其他玩家已加入房间，刷新房间信息
     const {status, ownerId, roomType, players} = gameMediaEngine.getRoom(roomId);
   }); 
   gameMediaEngine.on('playerOffline', (roomId, openId) => {
     // 其他玩家已离开房间
   });
   ```

2. 调用[GameMediaEngine.joinNationalRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gamemediaengine-web-0000001247887067#section05841116121)方法，使用相同的房间ID即可进入同一国战语音房间。

   ```
   gameMediaEngine.joinNationalRoom(roomId).then(roomId => {
     // 加入房间成功，获取房间信息
     const {status, ownerId, roomType, players} = gameMediaEngine.getRoom(roomId);
   }).catch(err => {
     // 加入房间失败
     const {code, message} = err;
   });
   ```
