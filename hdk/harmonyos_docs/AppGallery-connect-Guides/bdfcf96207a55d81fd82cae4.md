# 升级已使用应用签名服务的应用

对于已使用应用签名服务的在架应用，升级应用时仅需按以下步骤执行。

1. 使用上传密钥对应用软件包进行签名。
2. 上传签名后的应用软件包。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250716091205.99468016916619683135647167159162:50001231000000:2800:E60E0C05C917BFBA01A0211F1C8B8F67D279F583E21E4977446A9ECB7000B7E0.png)  
   软件包上传后，AGC会自动使用当前AGC中管理的签名密钥对应用重签名。
3. 使用升级方式提交发布。 AGC会使用当前在AGC上管理的签名密钥对应用签名后分发给用户。
