# 业务介绍

华为应用市场AppGallery Distribution SDK（以下简称AGD SDK）可为第三方Android应用提供基于应用市场的下载和安装能力，内部媒体可以通过集成AGD SDK来实现广告应用的下载安装（广告应用必须上架应用市场）。
