# 华为分析初始化

## 场景介绍

华为分析服务(Huawei Analytics)预置大量分析模型，可帮助您清晰地了解用户的行为方式，从而实现用户、产品、内容的深度洞察，让您实现基于数据驱动的运营，可以就应用营销和产品优化制定明智的决策。

联运服务建议您在应用启动时初始化华为分析服务，用于采集华为预定义的自动采集事件，包括：

* 系统级事件：应用升级、首次打开应用时触发，初始化华为分析服务后由HUAWEI Analytics Kit自动采集。
* Activity页面事件：进入、退出Activity时触发，初始化华为分析服务后由HUAWEI Analytics Kit自动采集。

自动采集事件的详细说明请参考[自动采集事件](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-automatic-event-collection-0000001051757143)。

## 前提条件

已参见[使用入门](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/appgallerykit-getting-started-0000001055756858)集成Analytics SDK，并启动华为分析服务。

## 注意事项

不同终端平台的限制：

* 原则上安装了HMS Core（APK）的Android终端设备均可以支持华为分析业务。
* 非华为Android手机（小米、VIVO、OPPO、三星、酷派、中兴等）需要终端设备先安装HMS Core（APK）。某些厂商手机可能会删除华为进程，导致数据上报异常。
* 不支持iOS手机。

## 开发步骤

在应用启动时，初始化HUAWEI Analytics Kit。

```screen
@Override
protected void onCreate(Bundle savedInstanceState) {
    super.onCreate(savedInstanceState);
    setContentView(R.layout.activity_main);
    //打开SDK日志开关
    HiAnalyticsTools.enableLog();
    HiAnalyticsInstance instance = HiAnalytics.getInstance(this);    
}    
```

初始化完成后，HUAWEI Analytics Kit将自动采集系统级事件和Activity页面事件，您可以通过华为分析功能进行一些基础数据分析，详细指导请参见[华为分析操作指南](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/dashboard-0000001050985173)。

如果您需要实现更复杂的预置事件和自定义事件埋点与上报，请参见[华为分析开发指南](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-dev-process-0000001050163813)。
