# 云存储触发器

您可以为云函数配置云存储触发器，当AGC云存储服务中发生文件或者文件夹上传或删除操作时，将触发函数并执行您想要实现的功能。

## 前提条件

* 您已[开通云存储服务并创建存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/serverless-create--preparations-0000001712008649#section624722314438)。
* 您已[创建函数](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/serverless-create-and-config-func-0000001713008121)。

## 创建云存储触发器

1. 在函数列表中点击函数名称进入函数详情页面。如果点击函数名称右侧"操作"列的"别名"，则在别名列表中点击别名名称，进入别名详情页。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251205152526.77697590300455099224873085998453:50001231000000:2800:41815DC35357E63335141B468E5687634DFB3614450F182CA76ABECA108FF023.png)

2. 点击"触发器"页签下的"添加触发器"，显示触发器创建界面。
3. 在"添加触发器"页面，"触发器类型"选择"云存储触发器"，并配置"存储实例"和"事件名称"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251205152526.67723626715057817393707026739145:50001231000000:2800:FA90F664E50F52B9CFEF37E44A85A8077162D936505C656943C37B1CDE4B5912.png)

   |参数|说明|
   |:----|:-------------------------------------------|
   |触发器类型|云存储触发器。|
   |存储实例|选择您在云存储服务中创建的存储实例名称。该存储实例中的文件变化将作为触发事件源。|
   |事件名称|触发器支持的事件类型。 * Completed：文件上传。 * Delete：文件删除。|

4. 触发器配置完成后点击"确定"保存触发器，则回到触发器列表，可看到云存储触发器图框。
