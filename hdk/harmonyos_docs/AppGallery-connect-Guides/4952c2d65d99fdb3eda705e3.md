# 新增分享落地页

"分享落地页"主要用于后续的视频分享展示，不仅可以帮助接收方查看精彩视频，还可以有效地引导其进一步跳转到合适的目标位置，例如游戏内部或应用市场下载页，从而提高游戏的用户活跃度或安装率。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，并在项目下的应用列表中选择您的游戏应用。

3. 在左侧导航栏中选择"构建 \> 高光时刻"，进入高光时刻服务页面。

4. 在"分享落地页"页签下，点击右上角"新增落地页"。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260116101403.45237711533131518817269472049168:50001231000000:2800:1A18E0330939B92279A40A8CB83917B5D387023DFD08FA0B6485D92B61A4219A.png)
5. 设置落地页名称（最长64个字符），并点击"新建"前往"魔方创意"网站。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260116101403.13956145450607206338797081311756:50001231000000:2800:87D96A037A3A0FD9451082A550C3E320694E8D3F8051CC9CD7AC35E0B12A3823.png)
6. 根据使用需要，拖拽左侧相关组件至中间编辑区域，并配置按钮组件中"打开游戏"的跳转链接。关于魔方创意的使用指南请参见[魔方创意](https://developer.huawei.com/consumer/cn/doc/distribution/app/game-center-creatives-ideas-0000001429732169)。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260116101403.21300763640334728523348616404023:50001231000000:2800:826A5A511BE502E8E3F733579A79EDCA6FFF5693F8538513D53A67BEB516FC41.png)  
   * deepLink：当在华为手机上点击分享落地页中"打开游戏"按钮时，会优先根据deepLink拉起游戏。如手机未安装此游戏，则会跳转到该游戏的华为应用市场下载详情页。
   * 游戏官方下载URL：当在非华为手机上点击分享落地页中"打开游戏"按钮时，则会跳转到该游戏的官方下载页。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260116101403.63299669746608155564683798829775:50001231000000:2800:3E3E65159CA029A915668D48506B4BE363E5CBD459A3FF9572E485DA795ADDD9.png)
7. 编辑完成后点击右上角"保存"，然后返回高光时刻分享落地页的"自定义页面"，并点击"提交"。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260116101403.61679400530554917268980146992617:50001231000000:2800:42F2807EB2F6119F28785D11DCA91B7F6838C928F585FD9FEB933C90FF082082.png)  
   如未返回点击"提交"，则相关编辑内容无法生效，且离开落地页自定义页面后已编辑的内容将会丢失。
8. 分享落地页提交后，将会自动送检，您可根据风控审核结果对落地页进一步管理。如需修改或删除已配置的落地页，可在落地页列表中，点击对应"操作"列"编辑"或"删除"即可。

   * 审核中：风控审核中暂不支持编辑，请耐心等待审核结果。
   * 审核不通过：落地页内容中涉嫌广告、色情、欺诈等违规信息，请检查并修改落地页相关内容后重新提交。
   * 审核异常：异常原因导致审核失败，建议点击"编辑"后重新提交，支持修改与删除落地页。
   * 发布成功：落地页为"未使用"状态时，支持修改、删除落地页与关联模板。落地页已关联模板处于"生效中"状态时，则无法进行修改或删除操作。
   * 发布异常：异常原因导致发布失败，建议点击"编辑"后重新提交，支持修改与删除落地页。
