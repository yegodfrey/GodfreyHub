# 上传文件

通过云存储SDK，您可以快速上传本地设备上的数据到云端。  

#### 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[初始化存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-initialize-bucket-harmonyos-tsapi6-0000001604393605)。  

#### 操作步骤

您可以通过引用操作本地设备上的文件，将文件上传到云端的存储实例中。

1. 调用[StorageManagement.storageReference](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-tsapi6-storage-storagemanagement-0000001553635818#section13963124903819)方法创建待上传文件的引用，将本地文件传入到预先规划的云端地址中。

   ```
   var reference = storageManagement.storageReference('images/demo.jpg');
   ```

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240821163259.12711262816774089591052345076379:50001231000000:2800:5CA06CABCCA1E964309A573DB837D06E5634C7B406A2894EEE693AA183102926.png?needInitFileName=true?needInitFileName=true)  
   * 上传文件时，会对云端文件的名称和大小进行严格的检查，具体限制请参见[使用限制](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-restrictions-0000001093263535#section1759375325210)。
   * 待上传文件最大为1GB。若上传任务异常中断，云存储SDK会根据设置的最大重试次数进行重试上传。
2. 调用[StorageReference.putFile](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/harmonyos-tsapi6-storage-storagereference-0000001553476194#section169241706523)将文件上传到存储实例中。

   ```
   reference.putFile("localFile/demo.jpg").then(res=> {
       // 上传成功
   }).catch(err => {
       // 上传失败
   });
   ```

   <br />

#### 更多信息

* 文件成功上传到云端后，您可以通过云存储SDK[获取文件的下载地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-getdownloadurl-harmonyos-tsapi6-0000001553474078)。
* 您可以通过云存储SDK的API[列举云端某个目录下的所有文件或子目录](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-list-harmonyos-tsapi6-0000001553633682)。
* 当您不再需要云端的文件时，可以调用云存储SDK的API在应用客户端[删除文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-delete-harmonyos-tsapi6-0000001604113625)。
* 除了在应用客户端通过云存储SDK的API来上传文件，您还可以直接[在AGC控制台以可视化的方式来上传文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-manage-file-0000001281134398#section6704135012516)。
