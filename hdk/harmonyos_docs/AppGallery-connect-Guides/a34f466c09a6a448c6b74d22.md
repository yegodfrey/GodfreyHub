# 调试聚合链接

创建聚合链接以后您可以在AGC中调试聚合链接的地址是否准确。

## 前提条件

您已[在AGC控制台创建聚合链接](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-createlinks-byagc-0000001058988077)。

## 操作步骤

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击您的项目。
3. 点击"增长 > App Linking > 聚合链接"。
4. 选择"聚合链接"页签，点击聚合链接对应"操作"列下方的"调试"。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260105170007.85570002620832885352871855932223:50001231000000:2800:C8F52ED49E181DAB21AB740C2C4924B70B86EF2C237E969DC41FDE0E4BD250AD.png)
   > 说明
   >
   > 修改、复制、归档操作只有分配了"管理员"、"APP管理员"、"运营"和"开发"角色的账号才可见。

   页面会自动跳转到聚合链接对应的短链接地址，并在地址后拼接"?test=1"。页面将生成一个流程图（而不是加载聚合链接），以用于预览您的聚合链接在不同的平台上和在不同的配置下的行为，您可以点击对应的节点预览链接地址是否正常。页面中还将展示聚合链接告警和错误。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260105170007.42986130765430534224672918912749:50001231000000:2800:D39CBDFE88695E951370DC59A09603D0BCB93B8DEC006B442001DE1D1125628B.png)

## 常见错误和告警

|错误和告警|解决方案|
|:-------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Failed to enable the App Links because SHA256 is not configured for the app (xxx)|由于未为应用程序配置SHA256签名证书指纹，导致无法启用App Links，请为您的应用配置SHA256签名证书，例如游戏应用的配置方法可参见[配置签名指纹证书](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-agc-0000001281025916#section21591342135811)。|
|You are advised to set a URL trustlist format for the link.|建议为聚合链接设置URL允许清单格式，方法参见[添加网址允许清单](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-allowlist-0000001059304615)。|
|The custom link (https://xxx.com) does not comply with any URL trustlist format|自定义链接不符合任何URL允许清单格式，请参考您已配置的网址允许清单格式修改您的聚合链接地址。|
|The custom parameter (deepLink) is reserved and not recommended|自定义参数是保留关键字，不建议使用。请更换参数名为其他非保留关键字。|
|Failed to enable the Universal Links because Team ID (App ID Prefix) is not configured for the app (xxx) (iOS)|iOS应用未配置团队 ID （应用ID前缀）)，开启通用链接失败。"团队ID"配置方法请参见[配置iOS应用信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-config-ios-0000001372591753)。|
|The App Store ID is not configured for the app (xxx)(iOS)|iOS应用未配置应用商城ID。"App Store ID"配置方法请参见[配置iOS应用信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-config-ios-0000001372591753)。|
