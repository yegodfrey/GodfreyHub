# SDK版本更新说明

![](https://media:301784701087683628)  
HarmonyOS Java SDK已于2024年6月1日起停止支撑新应用接入。  

|版本号|发布时间|更新说明|
|:--------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1.5.1.300|2023-06-19|![](https://media:301784701087717631) 修复已知问题。|
|1.1.0.300|2023-01-03|![](https://media:301784701087882635) 首次发布APMCrash版本的HarmonyOS崩溃服务SDK，帮您洞察应用的性能问题，提升用户体验。 * 基于应用名称、应用包名、应用版本号等维度下的崩溃分析。 * 崩溃问题详情中包括崩溃时间、崩溃问题分布、崩溃类型、进程信息、线程信息、堆栈信息、内存等信息。 * 支持崩溃自定义日志、自定义键值对、用户标识符。|
|1.3.1.300|2022-06-03|![](https://media:301784701087910637) 修复已知问题。|
