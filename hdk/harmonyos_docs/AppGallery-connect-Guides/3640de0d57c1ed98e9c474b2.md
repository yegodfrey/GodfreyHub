# 云侧访问云数据库资源的两种方式

云数据库提供了多种访问方式，除了从APP和控制台访问数据库以外，您还可以从服务器访问数据库。您只需要在您服务器端的服务中集成云数据库服务的Server SDK，即可调用它提供的接口，完成相关服务功能开发。Server SDK将会为您的服务器与云数据库之间的通信和安全提供保障。

通过云侧访问云数据库资源时，支持如下两种场景：

* 如您没有自己的服务器，推荐通过AGC云函数访问云数据库资源，此方式无需手动下载凭据文件，具体请参考[（推荐）在云函数中访问云数据库资源](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-sdk-in-cloudfunction-0000001982503198)。

<!-- -->

* 如您搭建了自己的服务器且希望通过自己的服务器来访问云数据库资源，则需手动下载凭据文件，具体请参考[在服务器中访问云数据库资源](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-sdk-in-server-0000001971049864)。

请根据实际情况进行选择。
