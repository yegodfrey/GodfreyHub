# 点对点消息

游戏多媒体RTM功能允许向指定接收者发送点对点消息，以实现不同客户端之间的消息传递。RTM点对点消息可以用于多人游戏中的实时通信，例如在线合作游戏、多人对战游戏或社交游戏，从而增强玩家之间的互动和沟通。当前支持发送文本和二进制两种类型的消息。  

#### 前提条件

* 您已[集成游戏多媒体基础SDK和实时信令模块](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-integratingsdk-android-0000001250838246#ZH-CN_TOPIC_0000001250838246__li733912204487)。
* 您已[创建游戏多媒体实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-engine-android-0000001193958984#section1093713161034)。  

#### 发送点对点消息

1. 调用[GameMediaEngine.publishRtmPeerMessage](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section288918481583)方法，向指定的接收者发送点对点消息。

   ```
   PublishRtmPeerMessageReq req = new PublishRtmPeerMessageReq();
   req.setPeerId("123***556");
   req.setMessageType(1); // 消息类型：1表示文本,2表示二进制
   req.setMessageString("xxxxx");
   String clientMsgId = mHwRtcEngine.publishRtmPeerMessage(req);
   ```

2. 在IGameMMEEventHandler接口的[onPublishRtmPeerMessage](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section19535155918576)回调方法中，可以收到点对点消息的发送结果。

   ```
   @Override
   public void onPublishRtmPeerMessage(PublishRtmPeerMessageResult result) {
       // 可根据需求将数据进行处理
   }
   ```

#### 接收点对点消息

在IGameMMEEventHandler接口的[onReceiveRtmPeerMessage](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section6321172185819)回调方法中，可以接收点对点消息通知。

```
@Override
public void onReceiveRtmPeerMessage(ReceiveRtmPeerMessageNotify notify) {
    // 可根据需求将数据进行处理
}
```
