# 使用限制

由于Serverless抽奖活动模板包含多个Serverless服务的配置，故Serverless抽奖活动模板在API、资源、配额、代码等方面的限制取决于模板中包含的服务类型，本章节将为您详细介绍模板可能涉及的使用限制。这些限制可能会根据实际情况随时更新，请您注意文档变化。

|依赖的服务|限制|
|:----|:----------------------------------------------------------------------------------------------------------------------------------------------|
|云数据库|请参考[云数据库的使用限制](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-clouddb-restrictions-0000001127557973)|
|云函数|请参考[云函数的使用限制](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloud-function-restriction-0000001058641770)|
|云托管|请参考[云托管的使用限制](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-cloudhosting-restriction-0000001058442246)|
