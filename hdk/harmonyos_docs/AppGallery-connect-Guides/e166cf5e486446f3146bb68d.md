# 业务介绍

资源包预下载是将资源文件静默下载到用户设备的服务。游戏在即将首发前（预约状态且进行过先锋/内测活动），或在版本即将更新前（在架状态），可以申请该服务，游戏资源文件将被提前分发到预约用户或游戏老用户的设备中，用户启动游戏后无需下载就能快速加载游戏资源，减少资源文件下载导致的流失。

|3|[提交预下载任务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/resource-package-operation-0000001296686470#section124381849103616)|完成游戏资源包上传后，您可以提交游戏资源包预下载任务至"预上线"状态。|
|4|[测试预下载功能](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/resource-package-operation-0000001296686470#section6757103624010)|任务处于"预上线"状态时，您可以测试游戏资源包预下载功能。|
|5|[发布预下载任务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/resource-package-operation-0000001296686470#section9206134163716)|您可以在AGC控制台正式发布"预上线"状态的游戏资源包任务。审核通过后任务状态变更为"已发布"。 > 说明 > 预下载任务提交发布后会提交到华为运营人员审核，任务状态会变为"审核中"，华为运营人员会在1~3个工作日内完成审核。|
|6|[预下载开发指导](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/resource-package-development-0000001349845777)|应用市场客户端会在满足自动更新要求时提前将游戏资源包分发到用户设备的指定目录下，您的游戏在更新时需要从指定目录中读取游戏资源包，待游戏资源包更新完成后调用接口告知华为应用市场客户端更新结果。|
