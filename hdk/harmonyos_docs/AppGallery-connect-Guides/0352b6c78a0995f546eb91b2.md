# 通过控制台测试

> 说明
>
> 下文以函数latest版本为例介绍测试方法。若您需要测试函数的已发布版本，可在已发布版本详情页面选择"函数代码"页签，参考方式二进行测试。

函数创建后您可以在AGC控制台测试函数的代码运行是否正常。进入测试界面有两种方式：

* 方式一：函数列表中点击函数名称右侧"操作"列的"测试"，在右侧弹出的"测试函数"界面进行测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/53/v3/7meNhM1hQdqaqkJkfwe-vw/zh-cn_image_0000001978548797.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=65CF2C39D575BD0DEFFF4BD76A867CE939268487DF7734E3ADA7807E7F35244D)

* 方式二：
  1. 在函数列表中点击已创建的函数名称，进入函数详情页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d7/v3/GjQLmofwRR6T7kfUDH9dqg/zh-cn_image_0000001948908550.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=E9426AE701819426293EC8AC6845B6CBB122E642E91EB7E1564928C97F26C2DC)

  2. 选择"函数代码"页签，点击"测试函数"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/44/v3/sUc4KvQATki7DPTfhRNFvg/zh-cn_image_0000001800662133.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=FCB89B40080C3829F72B9FEB0520E9A9E9E05B51301B60B7A63CB14BB3EA2BEC)

  3. 在右侧弹出的"测试函数"界面，使用默认测试事件、创建新测试事件或者使用已保存测试事件进行测试。
     * 使用默认测试事件 直接点击"测试"对函数进行测试。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5f/v3/rUphEIlsQyiMMszBfu7dnQ/zh-cn_image_0000001722152221.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=7B22D6D59D6830D02B16730FDA2BD597132C2FE1C687CE3D76C603D6B8156A4C)
     * 创建新测试事件 如果需要设置调用函数的请求消息体，可按照如下步骤配置测试参数，并可保存为测试事件方便后续继续使用。

       1. 在"事件"文本框中输入JSON格式的事件参数，点击"保存"。然后在"提示"弹出框中输入事件名称，配置完成后点击弹出框右下角的"确认"。 说明
          >
          > "事件"文本框内输入的JSON对象，对应的是触发器的event事件格式，会透传给函数。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/37/v3/vAWBWSTsQT2SSnu7TGrKHA/zh-cn_image_0000001756189981.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=DDA737E2FC29DB3AEB2B713083858E352096A9BC3A4AD51E079355F41076B5AB)
       2. 点击"测试"，函数处理事件并返回测试结果。
     * 使用已保存测试事件
       1. 在"测试函数"界面，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/84/v3/4EiVbJU_SsuRb-a9nCt2vw/zh-cn_image_0000001722236597.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=B7561C23AC0F19E08DA87251871B664A14257A1525B90E7220CF2E14DF901650)展开已保存的测试事件列表，选择已配置的事件名称右侧的"加载"，然后点击"测试"，函数处理事件并返回测试结果。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a5/v3/qMA0tNglQN-dPFzk-T8cyg/zh-cn_image_0000001722453985.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=1A6A472B2307C07A0EFFAF22CA40F9838454341F0ECEA7B460682746EDAE9E77)
       2. （可选）若您需要删除已添加的测试事件，可在测试事件列表中点击事件名称右侧的"删除"即可删除测试事件。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/45/v3/Xel4PcdoTDWeum-i3GEEEQ/zh-cn_image_0000001722158501.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=45AD7DA5B44CB8B018FF857F86ED8CED97F1BB152D4937F0102C76166890A22E)

  4. 查看测试结果。
     * 执行结果：展示测试后获得的响应结果。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ea/v3/VUtk2teUSpO16MuJRdvY5w/zh-cn_image_0000001674184734.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=1E573EADEEBFDE22AD5E4C96D93E9035A1C01DC4B164435D74E9BCC3834F6A7C)

     * 运行日志：展示函数运行过程中，通过logger API打印的日志，支持输出debug级别及以上日志（以下仅为日志输出示例）。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fd/v3/LGPIVQI3Qp2oo1oZ1gyH1g/zh-cn_image_0000001674190046.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=5F4BFA6417908FEC37EBCD348EF640BC70441B47715CAE293D324D6615DA261B)

     * 执行摘要：展示该次测试请求相关信息。
       * 请求ID：该条测试请求的RequestID，在后台日志中体现为X-Trace-ID。
       * 持续时间：函数执行的端到端时间。
       * 执行版本：该次调用测试的具体函数版本。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3c/v3/5R19biz-RoWBQKD0iO_QzQ/zh-cn_image_0000001674344770.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=3B264D6E7A97C8CBEE5A794D804FDE41EA4C8FF204CC9707FF97C199C37AEDDD)
  5. "代码输入类型"为"在线编辑"的函数，测试过程中，若您需要修改函数入口文件代码，可直接在"函数代码"页签的代码编辑器中修改，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cb/v3/tn4WKlO1STWbLgsCm-RN9Q/zh-cn_image_0000001753703418.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=4F29BA58AE0DC0691A29134BB74C68C69098945B40AD04A94A5B687ED4D44C2E)

     "代码输入类型"为".zip文件"的函数，测试过程中，若您需要修改函数代码文件，可在本地修改且打包完成后，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/38/v3/DzxJN1XITUuWk7KRemaPXg/zh-cn_image_0000001717161230.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=1FDC07A5FCEC257066E9FAE12C6BA9DEDEDF46537530DEF01860D4E554580687)重新上传函数部署包，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。
     > 说明
     >
     > 若代码更新量比较大，需要调整函数内存配置，可点击"内存配置"下拉框进行调整，然后再上传函数部署包。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/87/v3/PBi-YFD_T4mlCv5miLMECg/zh-cn_image_0000002433940774.png?HW-CC-KV=V1&HW-CC-Date=20260916T040231Z&HW-CC-Expire=31536000000&HW-CC-Sign=1A595F50CA13FCE4E493CFBF9D687096079139BCBD159A8CAA4B7E9B7BB74507)
  6. 函数测试无误后，您可在"函数代码"页签点击"导出函数"导出函数部署包。导出包以"函数名称+函数版本.zip"格式命名，可查看函数结构和文件内容。
