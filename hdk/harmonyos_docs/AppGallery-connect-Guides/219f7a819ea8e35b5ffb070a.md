# 使用限制

AGD API存在调用频率和设备方面的限制，本章节将为您详细介绍这些不同类型的限制。这些限制可能会根据实际情况随时更新，请您注意文档变化。  

#### API 限制

API限制是指API调用频率的限制。  

|操作|限制|
|:-----|:-------------|
|接口调用频率|20000次/小时/合作方。|

#### 设备限制

设备限制是指对用户终端的限制。  

|限制项|限制|
|:------------|:-------------------------------|
|设备品牌|无限制。|
|OS版本号|Android：5.0及以上（API Level 21及以上）。|
|EMUI（仅针对华为手机）|EMUI 3.0及以上版本。|
|HMS Core APK|无限制。|
|华为应用市场客户端|用户设备必须安装11.0.2及以上版本的华为应用市场客户端。|
