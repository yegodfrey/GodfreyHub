# 应用初始化

## 场景介绍

用户点击应用图标打开应用，应用后台启动时需要对应用进行初始化，用于数据统计和公告展示。
> 说明
>
> 如果您的应用有闪屏广告，请在闪屏广告结束后再进行应用初始化。

## 前提条件

已参见[使用入门](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/appgallerykit-getting-started-0000001055756858)集成联运应用SDK。

## 注意事项

* 此场景在中国大陆地区必须完成，中国大陆以外地区可选完成。
* 如果应用向用户提供了用户隐私协议，必须在用户同意协议后才能调用init接口。
* 应用初始化建议在应用启动时完成，而不是用户在进行登录、支付等操作时才完成。

## 开发步骤

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251028142414.15265417783001692856764594297859:50001231000000:2800:B49ED3E9B177D3AB2540A93E80ECEBEB5E2EAD4B1F1086048630A10814E66E97.png "点击放大")

本功能涉及的关键开发步骤如下：

1. 用户在移动设备中点击应用图标启动应用。
2. 应用执行启动程序，加载应用相关资源，具体启动程序由您自行完成。
3. 应用在启动程序中调用[JosApps.getJosAppsClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/josapps-0000001050123631#section162141030162218)方法获取[JosAppsClient](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/josappsclient-0000001050121680)实例。
4. 应用调用[JosAppsClient.init](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/josappsclient-0000001050121680#section12941311162615)方法进行应用初始化。

   ```screen
   AccountAuthParams params = AccountAuthParams.DEFAULT_AUTH_REQUEST_PARAM;
   JosAppsClient appsClient = JosApps.getJosAppsClient(this);
           final Task<Void> initTask = appsClient.init(new AppParams(params));
    initTask.addOnSuccessListener(new OnSuccessListener<Void>() {
               @Override
               public void onSuccess(Void aVoid) {
                   showLog("init success");
                   if (listener != null) {
                       listener.onSuccess(null);
                   }
               }
           }).addOnFailureListener(new OnFailureListener() {
               @Override
               public void onFailure(Exception e) {
                   showLog("init failed, " + e.getMessage());
               }
           });
   ```

   init方法不返回执行结果，应用无需关注执行结果。
