# 安全测试

云测试提供手机应用安全测试服务，检测应用中是否存在病毒木马和恶意广告。  

#### 前提条件

您已成功创建上架测试任务。  

#### 查看测试报告

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击需要查看测试报告的项目。
3. 在左侧导航栏中，选择"质量 \> 云测试"，进入云测试主页面。
4. 选择"测试任务"页签，您可以通过搜索框或测试任务列表中"应用类型"、"测试场景"、"测试状态"右侧的![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303165621.05482708997823827366653326744109:50001231000000:2800:09D0D0B85C5CF4CFD11DE82DA840014D66F401B9A052927A7C63470F3C1E7AB1.png)筛选出您要查看的测试任务，然后点击"操作"列的"查看报告"进入测试报告页面。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303165621.13321605630350843218937773760928:50001231000000:2800:7F8F29E3686E74BE28C5E418AE021BB9221C4C7C896B141FC2069D6FB0C373D2.png "点击放大")
5. 点击"安全测试"页签，您可从安全测试的测试报告概要中，查看被测应用的安全检测情况。您可分别点击" 病毒木马"和"广告检测"标签页查看各自的检测结果。  

   |检测项|说明|
   |:---|:--------------------------------------------------------------------------------------------------------------|
   |病毒木马|集成13款商用杀毒引擎对被测应用进行病毒木马检测分析，若检测出病毒木马，则该检测项不通过，整个上架测试结果不通过。|
   |广告检测|采用静态和动态两种广告安插规则，对被测应用中嵌入的广告和相应的广告类型进行检测。当前可检测出来的广告类型共有内嵌、弹窗、通知栏、积分墙和悬浮窗五种。 说明： 当前广告检测项的结果仅供参考，不作为判断上架测试是否通过的标准。|

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303165622.92641771889907314510736844414443:50001231000000:2800:81C1B245F3A6E6F7D75A92E35B4FC9793FB7CFA230608757F5FE5B1DF70092DB.png)
6. 当应用检测出安全异常问题时，测试报告详情中的左侧会列出所有发现的警告。您可点击这些警告，获得对应警告的测试截图。
