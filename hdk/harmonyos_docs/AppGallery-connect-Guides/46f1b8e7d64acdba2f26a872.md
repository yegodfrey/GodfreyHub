# 上传文件

您可以通过云存储服务快速地上传文件到云端。

## 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[创建Bucket对象](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-createreference-nodejs-0000001055327465#section18561161643714)。

## 操作步骤

用户可以通过引用将文件上传到云端的存储实例中。

1. 将文件传入到预先规划的云端地址中。

   ```screen
   const options = {
       destination: 'images/demo.jpg',
       onUploadProgress: (event) => {}
   };
   ```

   > 说明
   >
   > 如果未规划云端地址，则传入的文件将上传到存储实例根目录，且默认使用源文件名作为云端文件名。
2. 调用[Bucket.upload](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/bucket-0000001057141584#section15774101316387)方法将文件上传到云端。

   ```screen
   bucket.upload('./images/demo.jpg', options);
   ```

   > 说明
   >
   > 上传文件时，会对云端文件的名称和大小进行严格的检查，具体限制请参见[使用限制](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-restrictions-0000001093263535#section1759375325210)。

## 更多信息

* 文件成功上传后，您可以[设置文件的自定义属性](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-metadata-nodejs-0000001054848921)，也可以通过云存储SDK[下载文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-download-nodejs-0000001055727414)。
* 您可以通过云存储SDK的API[列举云端某个目录下的所有文件或子目录](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-list-nodejs-0000001054767445)。
* 当您不再需要云端的文件时，可以调用云存储SDK的API在应用客户端[删除文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-delete-nodejs-0000001055567404)。
* 除了在应用客户端通过云存储SDK的API来上传文件，您还可以直接[在AGC控制台以可视化的方式来上传文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-manage-file-0000001281134398#section6704135012516)。
