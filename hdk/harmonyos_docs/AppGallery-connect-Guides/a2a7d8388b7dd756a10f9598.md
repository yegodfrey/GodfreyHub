# 通过控制台测试

> 说明
>
> 下文以函数latest版本为例介绍测试方法。若您需要测试函数的已发布版本，可在已发布版本详情页面选择"函数代码"页签，参考方式二进行测试。

函数创建后您可以在AGC控制台测试函数的代码运行是否正常。进入测试界面有两种方式：

* 方式一：函数列表中点击函数名称右侧"操作"列的"测试"，在右侧弹出的"测试函数"界面进行测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/99/v3/GpcyeMePRwSv7NU_EAiz6g/zh-cn_image_0000001978548797.png?HW-CC-KV=V1&HW-CC-Date=20261008T151027Z&HW-CC-Expire=31536000000&HW-CC-Sign=8255D058B74C038D1B5A7557D2CF3280A8F21A2E7D2756DC4E050012DDB45E88)

* 方式二：
  1. 在函数列表中点击已创建的函数名称，进入函数详情页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d3/v3/rdWShftPQf6US-K4fDvJuw/zh-cn_image_0000001948908550.png?HW-CC-KV=V1&HW-CC-Date=20261008T151027Z&HW-CC-Expire=31536000000&HW-CC-Sign=D0DA4365A365985A9473336C46D119719692D5E2936453F67D60B816ECF585AB)

  2. 选择"函数代码"页签，点击"测试函数"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fd/v3/_kHXs4ESTWeYfX6V-2BgBA/zh-cn_image_0000001800662133.png?HW-CC-KV=V1&HW-CC-Date=20261008T151027Z&HW-CC-Expire=31536000000&HW-CC-Sign=0A72D4DD124823104CB35B05469E0B7C85649E342CDF8BE7B3E9CB70D3E88B22)

  3. 在右侧弹出的"测试函数"界面，使用默认测试事件、创建新测试事件或者使用已保存测试事件进行测试。
     * 使用默认测试事件 直接点击"测试"对函数进行测试。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6a/v3/iPkXfQUtS8GwMzDqIw31Fw/zh-cn_image_0000001722152221.png?HW-CC-KV=V1&HW-CC-Date=20261008T151027Z&HW-CC-Expire=31536000000&HW-CC-Sign=7C4FA4F0B79DAB5310736BC67F1A734EF782879D4DE6B5379545BDAFFED0127B)
     * 创建新测试事件 如果需要设置调用函数的请求消息体，可按照如下步骤配置测试参数，并可保存为测试事件方便后续继续使用。

       1. 在"事件"文本框中输入JSON格式的事件参数，点击"保存"。然后在"提示"弹出框中输入事件名称，配置完成后点击弹出框右下角的"确认"。 说明
          >
          > "事件"文本框内输入的JSON对象，对应的是触发器的event事件格式，会透传给函数。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1c/v3/T0hsVGteQxeDTZJfOlSP0A/zh-cn_image_0000001756189981.png?HW-CC-KV=V1&HW-CC-Date=20261008T151027Z&HW-CC-Expire=31536000000&HW-CC-Sign=F1905E60CC98B64BEAAF0DEA1FF34B1508A3FE6A4CB359822E7EE370C375A982)
       2. 点击"测试"，函数处理事件并返回测试结果。
     * 使用已保存测试事件
       1. 在"测试函数"界面，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e6/v3/CRtQiDGURlaDbuPXJBJ8Tg/zh-cn_image_0000001722236597.png?HW-CC-KV=V1&HW-CC-Date=20261008T151027Z&HW-CC-Expire=31536000000&HW-CC-Sign=4C3737953CC558B2F98202726EEB4C7BF3364878FA91F404376BD92F00CA47C9)展开已保存的测试事件列表，选择已配置的事件名称右侧的"加载"，然后点击"测试"，函数处理事件并返回测试结果。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8a/v3/gfg4ImA_SnOiUUV4xB70ag/zh-cn_image_0000001722453985.png?HW-CC-KV=V1&HW-CC-Date=20261008T151027Z&HW-CC-Expire=31536000000&HW-CC-Sign=A55D739F62690532FD1F11B1975E760605485CD392563179F1C4DE27BFC7F476)
       2. （可选）若您需要删除已添加的测试事件，可在测试事件列表中点击事件名称右侧的"删除"即可删除测试事件。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7a/v3/oh281DOHTISFyJqkolYgFw/zh-cn_image_0000001722158501.png?HW-CC-KV=V1&HW-CC-Date=20261008T151027Z&HW-CC-Expire=31536000000&HW-CC-Sign=AC1E1D9B2A749889CAC0F1F66288025B861F863296198C6E6D7988B5601D0E6F)

  4. 查看测试结果。
     * 执行结果：展示测试后获得的响应结果。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7d/v3/ig7hUH37RSuCnRH2QtWMfg/zh-cn_image_0000001674184734.png?HW-CC-KV=V1&HW-CC-Date=20261008T151027Z&HW-CC-Expire=31536000000&HW-CC-Sign=E7E1F93F2843CEBBF99E88EA206B98C34AE87E2AEDB78F6B0B60BE83F2FCE295)

     * 运行日志：展示函数运行过程中，通过logger API打印的日志，支持输出debug级别及以上日志（以下仅为日志输出示例）。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/37/v3/XuGwPOBOTFOVA8qOunzfvA/zh-cn_image_0000001674190046.png?HW-CC-KV=V1&HW-CC-Date=20261008T151027Z&HW-CC-Expire=31536000000&HW-CC-Sign=A12B8CF7EFCDE363477737F70E9B1B11306547417FB61A3FE65A0E2D7E742B60)

     * 执行摘要：展示该次测试请求相关信息。
       * 请求ID：该条测试请求的RequestID，在后台日志中体现为X-Trace-ID。
       * 持续时间：函数执行的端到端时间。
       * 执行版本：该次调用测试的具体函数版本。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e7/v3/RQmmdGvuR_GfAioTIySJ1w/zh-cn_image_0000001674344770.png?HW-CC-KV=V1&HW-CC-Date=20261008T151027Z&HW-CC-Expire=31536000000&HW-CC-Sign=BFD671680A2A06EDB46055330A6D6AD445BE37B36C0E08F8CF3C61EED81DEF64)
  5. "代码输入类型"为"在线编辑"的函数，测试过程中，若您需要修改函数入口文件代码，可直接在"函数代码"页签的代码编辑器中修改，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e0/v3/AcxhiO4iREiaP-LGA23xGA/zh-cn_image_0000001753703418.png?HW-CC-KV=V1&HW-CC-Date=20261008T151027Z&HW-CC-Expire=31536000000&HW-CC-Sign=FB70A86D02AA32C82EDF43EBC3F0BC0B8708DB7BF582ABAE55657B3888FBD198)

     "代码输入类型"为".zip文件"的函数，测试过程中，若您需要修改函数代码文件，可在本地修改且打包完成后，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ea/v3/hWvRNX8jRwapBLzNLCz2Uw/zh-cn_image_0000001717161230.png?HW-CC-KV=V1&HW-CC-Date=20261008T151027Z&HW-CC-Expire=31536000000&HW-CC-Sign=579C15E386474E550B96CAA3B7A70D90DFE216E4729C44F071C4E2BA726CF482)重新上传函数部署包，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。
     > 说明
     >
     > 若代码更新量比较大，需要调整函数内存配置，可点击"内存配置"下拉框进行调整，然后再上传函数部署包。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/af/v3/RZs-hFzrQZmir1fsntDm0g/zh-cn_image_0000002433940774.png?HW-CC-KV=V1&HW-CC-Date=20261008T151027Z&HW-CC-Expire=31536000000&HW-CC-Sign=A8F4DE1878059ECB0B61FB6391C2631F57C93AB49E8984DD73B687F102B28838)
  6. 函数测试无误后，您可在"函数代码"页签点击"导出函数"导出函数部署包。导出包以"函数名称+函数版本.zip"格式命名，可查看函数结构和文件内容。
