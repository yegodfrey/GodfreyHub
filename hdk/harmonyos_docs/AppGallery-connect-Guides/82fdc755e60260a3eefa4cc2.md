# 游戏初始化和登录

中国大陆发布的联运游戏，必须按照华为要求进行游戏初始化和登录。

1. 游戏初始化功能开发请参见[游戏启动](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/game-start-0000001050123475)。
2. 游戏登录开发请参见[游戏登录](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/game-login-0000001050121526)。

中国大陆以外地区发布的联运游戏，游戏启动和游戏登录不强制按照华为要求接入，但我们还是推荐您接入华为账号。
> 说明
>
> 为了给用户提供更丰富的游戏内容，对集成了华为账号登录的联运游戏，如果平台运营配置了引导安装游戏中心弹窗，HMS Core SDK会向未安装华为游戏中心的用户展示引导安装游戏中心的弹窗，用户可以前往华为应用市场安装游戏中心，以获取更多游戏相关服务，也可直接关闭弹窗。
