# 下架开放式测试版本

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107171428.14876428381323201070154839228100:50001231000000:2800:E5386F6F1B18A315702D41FC2D75B33CEF441C02722CE4BAD239C55CF6DB46B5.png)

开放式测试版本上架后，如果您想要下架该版本，基于您的应用类型和发布版本时选择的审核模式不同，下架方法也有不同。
> 说明
>
> * Android/HarmonyOS应用（API ≤ 9）：支持手工下架，您可通过提交下架申请或者修改测试结束时间的方法下架。
> * 元服务：支持手工下架，您可通过提交下架申请的方法下架，暂不支持修改测试结束时间。

## Android/HarmonyOS应用（API ≤ 9）

### 免人工审核模式

当您发布开放式测试版本时**勾选了**"用于开发阶段内部测试，免人工审核环节"选框，您可在测试有效期内修改测试结束时间，结束时间到了应用会自动下架。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107171428.10063327995656784094989835042414:50001231000000:2800:A581621C3BE3A3E57F09BD131CD6EAFD675C5DAFCDA116B2C69F759F518F8634.png "点击放大")

### 人工审核模式

当您发布开放式测试版本时**未勾选** "用于开发阶段内部测试，免人工审核环节"选框，您可通过[提交下架申请](https://developer.huawei.com/consumer/cn/doc/app/agc-help-removeapp-0000001100316676#section516715913203)下架版本，也可在测试有效期内修改测试结束时间，结束时间到了应用会自动下架。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251107171429.31305078431853524961786736556292:50001231000000:2800:BD48D9F7C1AF6E8814D4AF85EFCD1CF8D03C9792B17783CBE3FE152B36CC844A.png "点击放大")

## 元服务（API ≤ 9）

元服务的开放式测试版本上架后，暂不支持修改测试时间。免人工审核和人工审核模式下，您均可点击"申请下架"通过提交下架申请的方法下架版本。
