# AGC控制台配置准备

## 创建项目和添加应用

如果您尚未添加项目，请在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)先[创建项目](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createproject-0000001100334664)并在项目下[添加应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createapp-0000001146718717)。
> 说明
>
> 当前抽奖活动模板仅支持Web应用和APK应用。

## 添加SDK配置

您需要获取应用SDK信息，并复制到您的APP端，具体获取应用SDK信息操作请参见[获取应用的SDK代码片段](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-get-started-web-0000001057762291#section0451145762420)。
> 注意
>
> 将agConnectConfig直接写在JS文件中存在项目信息泄露的风险，我们强烈建议您将其加密存储在您的APP端，并在H5页面加载前写入Window对象。
