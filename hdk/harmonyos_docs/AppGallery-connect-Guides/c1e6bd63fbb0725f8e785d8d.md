# 设置主要参数

启动游戏后，必须先设置相应的预测算法以及所需参数等信息（至少提供一次），用于后续预测帧的计算和绘制工作。

## 前提条件

已[创建库实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/predict-frame-create-instance-0000001580652660#section986414272417)。

## 设置预测算法

根据场景需要，调用函数[FrameFlow_SetPredictionAlgorithm](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflow-setpredictionalgorithm-0000001791334560)设置不同的预测算法，以便获得更好的预测效果。
> 注意
>
> 设置预测算法是绘制预测帧的必要前提，因此必须设置。

```screen
FFResult FrameFlow_SetPredictionAlgorithm(FFInstance instance, const FFPredictionAlgorithmInfo* pPredictionAlgorithmInfo, FFAlgorithmCapabilitiesInfo* pCapabilitiesInfo);
```

## 设置Z轴可视坐标范围

在将所有可见的顶点坐标通过透视投影方式转化为标准化设备坐标（Normalized Device Coordinate）前，需先通过调用[FrameFlow_SetCvvZSemantic](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflow-setcvvzsemantic-0000001838093749)函数，来设置规则观察体（Canonical View Volume）的Z轴可视坐标范围以及深度测试方式，以便限定相机的可见范围。
> 说明
>
> 在OpenGL中，标准化设备坐标的Z轴可视取值范围为[-1, 1]。在DirectX中，标准化设备坐标的Z轴可视范围为[0, 1]，需要手动将其调整到[-1, 1]的范围内。

```screen
FFResult FrameFlow_SetCvvZSemantic(FFInstance instance, FFCvvZSemantic semantic);
```

## 建立模板缓冲区映射

模板缓冲区主要用于存储3D不透明场景图像中每个像素类型的模板值，通过在模板缓冲区建立并存储不同物体类型和模板值之间的映射信息，标记不同物体所属类型，以便在预测帧时进行不同程度的处理。

因此，在设置预测算法时，如果选择的是[FF_PREDICTION_ALGORITHM_GRIDWARP](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/ffpredictionalgorithm-0000001838093821#ZH-CN_TOPIC_0000001838093821__p1753161714567)预测算法（模板映射信息为该算法必要信息），则必须调用函数[FrameFlow_SetStencilRemapInfo](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflow-setstencilremapinfo-0000001838253693)建立模板缓冲区映射。如未建立映射，则库实例会将所有物体均识别为静态物体。

```screen
FFResult FrameFlow_SetStencilRemapInfo(FFInstance instance, const FFStencilRemapInfo* pRemapInfo);
```

## 设置分辨率

分辨率决定了帧画面的输出质量，因此需调用函数[FrameFlow_SetResolution](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflow-setresolution-0000001791494288)或[FrameFlow_SetResolution2](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/frameflow-setresolution2-0000001791334580)提前设置输出帧的分辨率。
> 注意
>
> * 分辨率是全部预测算法所需的必要信息，因此必须设置。
> * 当游戏画面宽高发生变化，则需要重新设置画面分辨率。

```screen
FFResult FrameFlow_SetResolution(FFInstance instance, const FFExtent2D* pExtent2D);
```

或

```screen
FFResult FrameFlow_SetResolution2(FFInstance instance, const FFResolutionInfo2* pResolutionInfo);
```
