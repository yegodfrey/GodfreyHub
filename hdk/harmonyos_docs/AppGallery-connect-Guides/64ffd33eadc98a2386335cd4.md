# 停用APM性能监控

在开发和调试应用过程中，您可能需要停用APM性能监控。下面是停用APM性能监控的三种方式：

* [在应用构建时停用](#section12384173635711)：您可以在Debug版本中停用APM性能监控，但在正式版本中启用APM性能监控。
* [在AGC远程配置停用](#section84012413319)：您可以灵活地在正式版应用中停用（或重新启用）APM性能监控。
* [在应用客户端停用](#section38651053241)：APM SDK提供性能采集接口，您在客户端上可以选择是否启用APM性能监控。

#### 在应用构建时停用

在开发和调试过程中，您可能发现APM性能监控会延长构建应用的时间，这时可以在构建时停用APM性能监控。这样会影响查看HTTP/HTTPS网络请求性能数据，但不影响查看应用启动和应用屏幕性能数据。

您可以通过下面2种方式来停用APM性能监控：

* Extension Property: 在编译时，为特定构建版本停用APM性能监控
* Project Property：在编译时，为所有构建版本停用APM性能监控

#### 通过Extension Property标志停用APM性能监控

采用Extension Property标志，您可以在编译时为特定构建版本停用APM性能监控。

在模块（应用级）build.gradle文件中，添加下面的标志，并将其设置为false以停用APM性能监控。

* 场景一：您可以在buildTypes灵活设置应用Debug版本和Release版本是否启用APM性能监控，具体设置如下：

  ```
  android {
    buildTypes {
      // ...
      debug {
         // ...
         // Set this flag to 'false', you can disable automatic HTTP/HTTPS network request monitoring
         // for a debug build variant at a compile time
         APMS {
           instrumentationEnabled false
         }
      }
      release {
        // ...
        // Set this flag to 'false', you can disable automatic HTTP/HTTPS network request monitoring
        // for a release build variant at a compile time
        APMS {
          instrumentationEnabled true
        }
      }
    }
  }
  ```

#### 通过Project Property标志停用APM性能监控

采用Project Property标志，您可以在编译时为所有构建版本停用APM性能监控。具体做法如下：  
将下面标志添加到您的gradle.properties文件，然后设置为false。

```
# ...

# Set this flag to 'false', HTTP/HTTPS network request monitoring will be disabled
# for all build variants at compile time
apmsInstrumentationEnabled=false
```

* 如果您在gradle.properties定义了Project Property标志，会应用于所有构建版本，其优先级高于Extension Property标志。要在Release版应用中重新启用APM性能监控，您必须注释掉Project Property标志或将其设置为true。
* 您每次修改Extension Property和Project Property标志时，重新构建应用前需要执行gradlew clean。

#### 在应用客户端停用

APM SDK提供[public void enableCollection(boolean enable)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/apms-0000001052488219#section325mcpsimp)接口，允许您启用/停用性能监控。接口调用具体流程如下：

1. 调用[getInstance](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/apms-0000001052488219#section304mcpsimp)初始化。
2. 调[enableCollection](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/apms-0000001052488219#section325mcpsimp)停用或开启。

参考代码如下：

```
Button disableButton = findViewById(R.id.fab1);
button.setOnClickListener(new View.OnClickListener() {
    @Override
    public void onClick(View v) {
        // Call interface in APM, and set the params to 'false'
        // you will disable APM
        APMS.getInstance().enableCollection(false);
    }
});

Button enableButton = findViewById(R.id.fab1);
button.setOnClickListener(new View.OnClickListener() {
    @Override
    public void onClick(View v) {
        // Call interface in APM, and set the params to 'true'
        // you will enable APM
        APMS.getInstance().enableCollection(true);
    }
});
```
