# 获取SDK配置信息

为了简化您的配置步骤，AGC为您提供了应用配置信息，您只需要将配置信息添加到您的项目中。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择您的应用。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251205152528.30539982250325936829143946326687:50001231000000:2800:9929AF1ACB65CF9357ACE6FC9221515274462689CC10DF2AF14170CE01DE4E37.png)

3. 在"项目设置"页面下载配置文件"agconnect-services.json"。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251205152528.85430706620301765580655782088289:50001231000000:2800:FFE660210608B0AC4B4FA863C2B7F725D7FF9E268CD68FD616EF22CBD7A5CB9C.png)  
   * "不包含密钥"开关默认关闭，配置文件中将会包含AGC为应用分配的客户端密钥和API密钥信息，其中客户端密钥和API密钥均为密文。
   * 您也可以在下载JSON文件前打开"不包含密钥"开关，配置文件中将不包含密钥信息，客户端密钥和API密钥需要由您自行调用AGC SDK的接口手动配置。
   * 如果您的套餐升级到了付费档，为避免被冒用产生异常账单，建议您打开"不包含密钥"开关，将密钥存储在您自己的服务器，并妥善保管。
