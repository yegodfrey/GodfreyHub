# 管理版本

管理版本包括：创建版本、发布版本、回退版本、删除版本等操作。您可以通过创建版本将想要增加的网站功能页面上传至云托管中，并通过发布功能发布至沙箱环境进行测试，最终发布至生产环境。

* 通过AGC控制台管理版本：在AGC界面中以可视化的方式实现[创建版本](#section24246013465)和[删除版本](#section162674464618)。
* 通过API管理版本：通过RESTful API管理站点版本，详情请参见[管理版本](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudhost-restversion-0000001166577876)。

## 创建版本

> 说明
>
> 每个站点最多创建100个版本。

1. 在"站点管理"页面，点击站点"操作"列的"版本管理"，进入版本管理页面。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030114803.44259890073267557115528965842856:50001231000000:2800:863E8F1E8DB1ECE01549E3509778792A60A15CA25FD84BB392FC164E80710C4A.png)


2. 点击"创建版本"，在弹出窗口完成版本创建后点击"确定"。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030114803.66444132425305648405171676654114:50001231000000:2800:EE1A59DDA3D9477C402F9D92A94171DDFA5F48B97A28BD75123B6946EDDC242B.png)
   1. 点击"浏览"，选择您需要上传的静态网页包，点击"上传"，并填写描述信息。 注意
      > * 上传的压缩包必须为.zip格式，压缩包最大400MB，解压缩后最大400MB，最多包含20000个文件。
      > * 压缩包文件名不能包含中文和空格。
   2. 选择是否发布。
      * 如果您选择"生产发布"，版本成功创建之后，将显示在站点版本列表下，状态为"上线中"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030114803.39455557164019499114843282907835:50001231000000:2800:A84EBE04887A6C5E24DBFC8E28BA784F6CAA379C6D31A4E156862FFD670B14A5.png)

      等待1-2分钟，点击"刷新"。如果版本状态更新为"生产"，则上线成功。

      > 如当前存在已上线版本，创建的新版本上线后，老版本将自动下线。
      * 如果您选择"不发布"，版本成功创建之后，将显示在站点版本列表下，状态为"下线"，您可以在操作栏中针对该版本进行沙箱发布、生产发布或删除操作。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030114803.89676247846708516327927131255327:50001231000000:2800:07B417C4A25E2ABF246EAB63C3DBA9164B8D75B7621460EA64CD9440BCFE52D5.png)

## 沙箱发布

版本正式发布前，您可以将版本发布至沙箱环境进行测试，提前查看版本发布后状态，并作出有针对性的调整，确保版本最终可以顺利发布到生产环境。

您可以参考以下操作，对已创建的版本进行沙箱发布，即发布该版本至虚拟生产环境。

1. 在站点管理页面，点击站点"操作"列的"版本管理"，进入版本管理页面。
2. 点击"操作"列的"沙箱发布"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030114804.54062369191525486543121629838115:50001231000000:2800:4621580F33E1EA27FCEE39FF74AD0CB8E54F704BB64B830115CC4EAD2B229AA0.png)

3. 在弹出框中选择您想要沙箱发布的环境ID（默认发布至default环境），完成后点击"确定"。 说明
   > * "default"环境为云托管服务为您创建的默认环境。如您想要创建其他环境，请参见[管理环境](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudhosting-createnviron-0000001221418916)。
   > * 一个版本可以发布到最多10套不同的沙箱环境，但是同一个环境下只能发布一个沙箱版本。如果您的两个版本发布到了相同的环境ID下，当第二个版本沙箱发布成功后，同环境ID下的第一个版本将自动下线。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030114804.69397325550138575471762251313489:50001231000000:2800:3B02996B9784DF421A95BBE84F88563C3BAEA6C5193EF9F2CD5079D1730FB1BC.png)

   当"版本状态"显示为"沙箱"时，当前版本完成沙箱发布，预计用时1分钟。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030114804.90031866178223524734998318036949:50001231000000:2800:992969158F8F13B875A4C8874D6163584BFAE6E4643625C513F5EC0D63584A66.png)
4. 您可点击"沙箱访问"，在所选沙箱环境中访问您的版本。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030114804.44737542856625053127299270458952:50001231000000:2800:F044182E26795A97C162EF79344E31CF0716C3F5D8BE579E8D52C42B329F941A.png)

## 生产发布

您可以在[创建版本](#section24246013465)时直接进行生产发布（即直接上线该版本），也可对"沙箱"或"下线"状态的版本进行生产发布。

1. 在站点管理页面，点击站点"操作"列的"版本管理"，进入版本管理页面。
2. 点击"操作"列的"生产发布"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030114804.81116835676752002097738714914148:50001231000000:2800:62B1B11D18AF3509C0274CBB7A0C311A9DBAF547899E1C5D2B3E2B066315527D.png)

3. 在弹出框中确认并输入版本号后，点击"确定"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030114804.68557306534873718120628010884464:50001231000000:2800:10D3D499318BF529BAC127375F9A843E9C9EAE891823A9DD96EC4685D306BA30.png)

   新版本上线后，版本状态变为"生产"，原先"生产"状态的版本将自动下线。

## 删除版本

版本在上线前或下线后，您可以通过以下操作删除该版本：

1. 在站点管理页面，点击"操作"列的"版本管理"，进入版本管理页面。
2. 点击"操作"列的"删除"，删除该版本。 注意
   > * 上线状态的版本不可删除。
   > * 删除版本后不可恢复，请谨慎操作。
