# NetworkInfo

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:------|:--------------------------------------------------------------|
|connectType|M|integer|网络类型。 需确保准确性。 取值范围： * 0：未知 * 1：wifi * 2：2G * 3：3G * 4：4G * 5：5G|
|carrier|M|integer|运营商名称。 取值范围： * 0：未知 * 1：移动 * 2：联通 * 3：电信|
|plmn|O|string|移动网络编码。|
|ip|M|String|请求广告时，对应设备的公网IPv4地址。 多个端使用代理时，允许上传相同的代理IP地址。|
