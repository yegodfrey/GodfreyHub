# 通过控制台测试

> 说明
>
> 下文以函数latest版本为例介绍测试方法。若您需要测试函数的已发布版本，可在已发布版本详情页面选择"函数代码"页签，参考方式二进行测试。

函数创建后您可以在AGC控制台测试函数的代码运行是否正常。进入测试界面有两种方式：

* 方式一：函数列表中点击函数名称右侧"操作"列的"测试"，在右侧弹出的"测试函数"界面进行测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7e/v3/mJ2nxcQiTQGoprPopVFFKA/zh-cn_image_0000001978548797.png?HW-CC-KV=V1&HW-CC-Date=20261008T183951Z&HW-CC-Expire=31536000000&HW-CC-Sign=FDC7D555ED46753EEFFA2B6C05E51FAA04C48794E9CF78C90457EA1590CEC705)

* 方式二：
  1. 在函数列表中点击已创建的函数名称，进入函数详情页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4f/v3/YgEEuDhOTSKLTGBrFJlVwQ/zh-cn_image_0000001948908550.png?HW-CC-KV=V1&HW-CC-Date=20261008T183951Z&HW-CC-Expire=31536000000&HW-CC-Sign=395D315CC1892077338D686AEC4B2F119DE35C17385E902B19B87F3CE6406036)

  2. 选择"函数代码"页签，点击"测试函数"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3a/v3/9j51_WUFQFeSvEt1p9ALvw/zh-cn_image_0000001800662133.png?HW-CC-KV=V1&HW-CC-Date=20261008T183951Z&HW-CC-Expire=31536000000&HW-CC-Sign=588138BD5ACCA71D8E9B090571AADB27BD854CC9132B28754247276191ECF90B)

  3. 在右侧弹出的"测试函数"界面，使用默认测试事件、创建新测试事件或者使用已保存测试事件进行测试。
     * 使用默认测试事件 直接点击"测试"对函数进行测试。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c6/v3/OrMrP32JQRCYpfEdHwEN2Q/zh-cn_image_0000001722152221.png?HW-CC-KV=V1&HW-CC-Date=20261008T183951Z&HW-CC-Expire=31536000000&HW-CC-Sign=8347F21D83DE3A9FEC3EE3AD56625780609FEDBA2146DDD30F0C98A75266FC7C)
     * 创建新测试事件 如果需要设置调用函数的请求消息体，可按照如下步骤配置测试参数，并可保存为测试事件方便后续继续使用。

       1. 在"事件"文本框中输入JSON格式的事件参数，点击"保存"。然后在"提示"弹出框中输入事件名称，配置完成后点击弹出框右下角的"确认"。 说明
          >
          > "事件"文本框内输入的JSON对象，对应的是触发器的event事件格式，会透传给函数。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/69/v3/Ca6VWonNRlyPEeNfdITPNw/zh-cn_image_0000001756189981.png?HW-CC-KV=V1&HW-CC-Date=20261008T183951Z&HW-CC-Expire=31536000000&HW-CC-Sign=7D31163120BF68488FBA47604635FC978BEC635F82E861B5CF0B40F70F891795)
       2. 点击"测试"，函数处理事件并返回测试结果。
     * 使用已保存测试事件
       1. 在"测试函数"界面，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/53/v3/1DHjtDN5RVKh31OiUqojPg/zh-cn_image_0000001722236597.png?HW-CC-KV=V1&HW-CC-Date=20261008T183951Z&HW-CC-Expire=31536000000&HW-CC-Sign=147B517CD401414BDCE98A2AA15CF78209E531A5CE4C3AB93D3DE9C75F1CF22A)展开已保存的测试事件列表，选择已配置的事件名称右侧的"加载"，然后点击"测试"，函数处理事件并返回测试结果。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/83/v3/LBgeXiO5QWCeCYfPG8QZKA/zh-cn_image_0000001722453985.png?HW-CC-KV=V1&HW-CC-Date=20261008T183951Z&HW-CC-Expire=31536000000&HW-CC-Sign=8C4E73054447E5449477C37E852CB007DA8B4C06B1F71FA87561E2CD710F39DD)
       2. （可选）若您需要删除已添加的测试事件，可在测试事件列表中点击事件名称右侧的"删除"即可删除测试事件。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c8/v3/bzdLdqWTQuGSb4QlkicMXQ/zh-cn_image_0000001722158501.png?HW-CC-KV=V1&HW-CC-Date=20261008T183951Z&HW-CC-Expire=31536000000&HW-CC-Sign=3F7B604D9C836A6C1A4A7BF5ACF807BB43040953D05105C610AC46128053A704)

  4. 查看测试结果。
     * 执行结果：展示测试后获得的响应结果。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c4/v3/OpRdHjQoQAm0vVCk2Tb4oQ/zh-cn_image_0000001674184734.png?HW-CC-KV=V1&HW-CC-Date=20261008T183951Z&HW-CC-Expire=31536000000&HW-CC-Sign=EC10B362B86993673912EAF579726564C765CF949356C3CB6548E0C48D3B41D5)

     * 运行日志：展示函数运行过程中，通过logger API打印的日志，支持输出debug级别及以上日志（以下仅为日志输出示例）。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/54/v3/rvYs-K3zT9udgYew7AFkGQ/zh-cn_image_0000001674190046.png?HW-CC-KV=V1&HW-CC-Date=20261008T183951Z&HW-CC-Expire=31536000000&HW-CC-Sign=1AA538E3DAE4725ACC21675B99528B8F7B2721C3CF82E3F4636A505739EDE46C)

     * 执行摘要：展示该次测试请求相关信息。
       * 请求ID：该条测试请求的RequestID，在后台日志中体现为X-Trace-ID。
       * 持续时间：函数执行的端到端时间。
       * 执行版本：该次调用测试的具体函数版本。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/61/v3/gOZsg34GQWSMAbRZHg4nbA/zh-cn_image_0000001674344770.png?HW-CC-KV=V1&HW-CC-Date=20261008T183951Z&HW-CC-Expire=31536000000&HW-CC-Sign=C80D59FADFC99A7CA7652107B6A4941880FB421027834B93E1854541E0B0F44F)
  5. "代码输入类型"为"在线编辑"的函数，测试过程中，若您需要修改函数入口文件代码，可直接在"函数代码"页签的代码编辑器中修改，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4c/v3/1NQ1GN8qQ1i2zhRgxkehdQ/zh-cn_image_0000001753703418.png?HW-CC-KV=V1&HW-CC-Date=20261008T183951Z&HW-CC-Expire=31536000000&HW-CC-Sign=862E4D9D29AB45B28F8B7B7DD1CF77AFE88BAF49F35D3B567B92EF22E4BD3C10)

     "代码输入类型"为".zip文件"的函数，测试过程中，若您需要修改函数代码文件，可在本地修改且打包完成后，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f/v3/AIajL2m7TBKJNDgEBwFpSA/zh-cn_image_0000001717161230.png?HW-CC-KV=V1&HW-CC-Date=20261008T183951Z&HW-CC-Expire=31536000000&HW-CC-Sign=5E518F1E4377B757F783721ED52B9C7171B5B5EA81A9417D360D7AB8D8FB53DA)重新上传函数部署包，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。
     > 说明
     >
     > 若代码更新量比较大，需要调整函数内存配置，可点击"内存配置"下拉框进行调整，然后再上传函数部署包。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/95/v3/jaNjLQnKQuiryLe00Gt38w/zh-cn_image_0000002433940774.png?HW-CC-KV=V1&HW-CC-Date=20261008T183951Z&HW-CC-Expire=31536000000&HW-CC-Sign=A65A54F015942F2014B3C1A925BB64F5CBA97F5E99004DB66E05492BEC014494)
  6. 函数测试无误后，您可在"函数代码"页签点击"导出函数"导出函数部署包。导出包以"函数名称+函数版本.zip"格式命名，可查看函数结构和文件内容。
