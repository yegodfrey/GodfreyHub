# 产品优势

## 接入简单

接口简单，接入方便，通过简单的功能开发，即可快速构建游戏高光时刻相关能力。

## 操作便捷

支持大时间跨度和小片段录制需求，同时提供了视频模板用于后续视频素材剪辑制作，满足多样化使用场景，操作便捷，易于输出。

## 性能稳定

录制过程流畅，画面质量清晰，对游戏性能影响小。
