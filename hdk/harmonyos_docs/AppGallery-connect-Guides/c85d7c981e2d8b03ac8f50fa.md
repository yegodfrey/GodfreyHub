# 在Android应用中接收聚合链接

用户点击收到的聚合链接后跳转到应用对应的内容时，您可以在应用客户端调用聚合链接SDK的API接收用户点击的聚合链接，以获取聚合链接中传递的数据。

<br />

#### 前提条件

* 您已成功[申请链接前缀](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-urlprefix-0000001060148052)。
* 您的应用已[集成聚合链接SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-android-integrationsdk-0000001371557869)。  

#### 添加Intent过滤器

在接收聚合链接前，需要在Android工程的"manifest"配置文件中添加Intent过滤器，用于指定处理哪些聚合链接。当前支持使用Deep Link或App Links来接收信息，一般建议使用App Links。

* 如果您使用Deep Link来接收信息，需要在处理聚合链接的Activity下添加如下配置。

  ```
  <intent-filter>
      <action android:name="android.intent.action.VIEW"/>
      <category android:name="android.intent.category.DEFAULT"/>
      <category android:name="android.intent.category.BROWSABLE"/>
      <!-- 此处host中添加聚合链接中的Deep Link地址的前缀或Android Deep Link链接地址的前缀，scheme中添加自定义scheme -->
      <data android:host="xxx.com" android:scheme="xxx"/>
  </intent-filter>
  ```

  其中"android:host"配置Deep Link链接的前缀，"android:scheme"配置自定义的scheme。当有用户打开带有指向此Deep Link的聚合链接时，您的应用将使用此Activity来处理该链接。

<!-- -->

* 如果您使用App Links（Android 6.0及以后版本支持）来接收信息，需要在处理聚合链接的Activity下添加如下配置。

  ```
  <intent-filter android:autoVerify="true">
      <action android:name="android.intent.action.VIEW"/>
      <category android:name="android.intent.category.DEFAULT"/>
      <category android:name="android.intent.category.BROWSABLE"/>
      <!-- 此处host中添加需要处理的聚合链接的链接前缀 -->
      <data android:host="xxx" android:scheme="http"/>
      <!-- 此处host中添加需要处理的聚合链接的链接前缀 -->
      <data android:host="xxx" android:scheme="https"/>
  </intent-filter>
  ```

  在使用此方式前请确认已经在AGC上配置SHA256签名证书指纹，例如游戏应用的配置方法可参见[配置签名指纹证书](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-agc-0000001281025916#section21591342135811)。

  其中:
* "android:host"要添加需要处理的聚合链接的链接前缀。
* "android:autoVerify"是App Links的校验开关，如果开启必须注册manifest中所有的intent-filter才能使链接生效。  

#### 在应用中接收聚合链接

1. 在需要接收聚合链接的Activity中调用[AGConnectAppLinking.getInstance](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectapplinking-0000001055539370#section19485202713615)初始化AGConnectAppLinking实例。
2. 调用[AGConnectAppLinking.getAppLinking](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectapplinking-0000001055539370#section122361541697)查询是否有待处理的聚合链接。
3. 在异步执行结果中获取[ResolvedLinkData](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/resolvedlinkdata-0000001054820879)实例，并解析出聚合链接传递的信息，如Deep Link地址。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250715120022.71043486623763525119274619043825:50001231000000:2800:6ACBCE4F33916235C94F35C98564A1290E27A12EC3156A4C2330DD3E9609BC5E.png)  
   如果您需要延迟深度链接的跳转，您还必须在MainActivity中添加以上接收聚合链接的代码用于处理聚合链接。  

   ```
   "Java"
   AGConnectAppLinking.getInstance().getAppLinking(this).addOnSuccessListener(resolvedLinkData -> {
       Uri deepLink = null;
       if (resolvedLinkData!= null) {
           deepLink = resolvedLinkData.getDeepLink();
       }
       //根据Deep Link信息来进行后续处理，比如打开详情页面或配置页面等。
   });
   ```

   ```
   "Kotlin"
   AGConnectAppLinking.getInstance().getAppLinking(this).addOnSuccessListener {
       val deepLink = it.deepLink
   }
   ```

#### 自定义Referrer信息（可选）

聚合链接是通过查询应用市场的Referrer信息来实现延迟深度链接功能，当前SDK默认支持从AppGallery中读取Referrer信息。如果您想支持其他途径的延迟深度链接，则需要自行获取对应途径的Referrer信息，并将其传递到聚合链接SDK中进行解析。

以GooglePlay为例：

1. 在应用的build.gradle文件中添加如下依赖。

   ```
   implementation 'com.android.installreferrer:installreferrer:2.1'
   ```

2. 首次接收聚合链接前，调用[AGConnectAppLinking.setCustomReferrer](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectapplinking-0000001055539370#section13223912105613)方法设置自定义Referrer提供者。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250715120022.98808137574619988767943211945593:50001231000000:2800:BDD75F8A420F06CA2C426FB6215413E94C6053B1327BDF567E0D10F131B6F2CD.png)  
   此代码只需在MainActivity中添加一次即可，无需在每个入口Activity中都添加。  

   ```
   "Java"
   AGConnectAppLinking.getInstance().setCustomReferrer(new ReferrerProvider() {
       @Override
       public Task<String> getCustomReferrer() {
           TaskCompletionSource<String> source = new TaskCompletionSource<>();
           final InstallReferrerClient client = InstallReferrerClient.newBuilder(getBaseContext()).build();
           client.startConnection(new InstallReferrerStateListener() {
               @Override
               public void onInstallReferrerSetupFinished(int responseCode) {
                   if (responseCode == InstallReferrerClient.InstallReferrerResponse.OK) {
                       try {
                           ReferrerDetails details = client.getInstallReferrer();
                           source.setResult(details.getInstallReferrer());
                       } catch (RemoteException exception) {
                           source.setException(exception);                            
                       }
                   } else {
                       Exception exception = new Exception("onInstallReferrerSetupFinished responseCode :" + responseCode);
                       source.setException(exception);
                   }
               }
               @Override                    
               public void onInstallReferrerServiceDisconnected() {
                   Exception exception = new Exception("onInstallReferrerServiceDisconnected");
                   source.setException(exception);
               }
           });
           return source.getTask();
       }
   });
   ```

   ```
   "Kotlin"
   AGConnectAppLinking.getInstance().setCustomReferrer {
       val source = TaskCompletionSource<String>()
       val client = InstallReferrerClient.newBuilder(baseContext).build()
       client.startConnection(object : InstallReferrerStateListener {
           override fun onInstallReferrerSetupFinished(responseCode: Int) {
               when (responseCode) {
                   InstallReferrerClient.InstallReferrerResponse.OK -> {
                       source.setResult(client.installReferrer.installReferrer)
                   }
                   InstallReferrerClient.InstallReferrerResponse.FEATURE_NOT_SUPPORTED -> {
                        // API not available on the current Play Store app.
                       source.setException(Exception("FEATURE_NOT_SUPPORTED"))
                   }
                   InstallReferrerClient.InstallReferrerResponse.SERVICE_UNAVAILABLE -> {
                       // Connection couldn't be established.
                       source.setException(Exception("SERVICE_UNAVAILABLE"))
                   }
               }
           }
           override fun onInstallReferrerServiceDisconnected() {
               source.setException(Exception("onInstallReferrerServiceDisconnected"))
           }
       })
       return@setCustomReferrer source.task
   }
   ```
