# 微博

您可以在应用中集成微博认证方式，让您的用户可以使用自己的微博账号进行AppGallery Connect身份验证。  

#### 前提条件

* 您需要在AGC控制台[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要先在您的应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-integration-sdk-0000001326347605)。  

#### 开发步骤

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114612.23508721921804722606100605807189:50001231000000:2800:60CB653CAF9F3864E13DC3CE224A9E20812FDEC7CAEB066A8311ADB8B01F12A1.png "点击放大")

1. 在应用的登录界面，初始化[AGCAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346)实例，获取AGC的用户信息，检查是否有已经登录的用户。如果有则可以直接进入用户界面，否则显示登录界面。  

   ```
   "Objective-C"
   AGCUser *user = [[AGCAuth getInstance] currentUser];
   ```

   ```
   "Swift"
   let user = AGCAuth.instance().currentUser
   ```

<!-- -->

2. 微博账号登录，并获取微博账号的用户授权信息。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218114612.70490250482329828986248029588699:50001231000000:2800:8AA27ED76D5CFE24B5AC2309DBDA3377ACC0D393CB0EE84771C806ACCF6EF506.png)  
   此步骤仅供参考，更详细内容，请参见[微博官方文档](https://open.weibo.com/index.php)。
   1. 注册app到微博SDK。  

      ```
      "Objective-C"
      [WeiboSDK registerApp:APPKEY];
      ```

      ```
      "Swift"
      WeiboSDK.registerApp("WEIBO_APP_KEY")
      ```

   <!-- -->

   2. 获取token和uid。  

      ```
      "Objective-C"
      WBAuthorizeRequest *request = [[WBAuthorizeRequest alloc] init];
      request.redirectURI = @"https://api.weibo.com/oauth2/default.html";
      request.scope = @"all";
      [WeiboSDK sendRequest:request];
      ```

      ```
      "Swift"
              let req:WBAuthorizeRequest = WBAuthorizeRequest()
              req.redirectURI = "https://api.weibo.com/oauth2/default.html"
              req.scope = "all"
              WeiboSDK.send(req)
      ```

   3. 添加授权登录的回调。  

      ```
      "Objective-C"
      - (void)didReceiveWeiboRequest:(WBBaseRequest *)request {

       }

      - (void)didReceiveWeiboResponse:(WBBaseResponse *)response {
          if ([resp isKindOfClass:[WBAuthorizeResponse class]]) {
              WBAuthorizeResponse *weiboAuth = (WBAuthorizeResponse *)response;
              NSString *token = weiboAuth.accessToken;
              NSString *uid = weiboAuth.userID;
          }
        }
      ```

      ```
      "Swift"
          func didReceiveWeiboRequest(_ request: WBBaseRequest!) {

          }

          func didReceiveWeiboResponse(_ response: WBBaseResponse!) {
              if let response = response as? WBAuthorizeResponse {
                  let token = response.accessToken
                  let uid = response.userID
              }
          }
      ```

   4. 在AppDelegate中添加授权确认后的回调。  

      ```
      "Objective-C"
      - (BOOL)application:(UIApplication *)app openURL:(NSURL *)url options:(NSDictionary<UIApplicationOpenURLOptionsKey,id> *)options {
          return[WeiboSDK handleOpenURL:url delegate:delegate];
        }
      ```

      ```
      "Swift"
          func application(_ app: UIApplication, open url: URL, options: [UIApplication.OpenURLOptionsKey : Any] = [:]) -> Bool {
              return WeiboSDK.handleOpen(url, delegate: delegate)
          }
      ```

3. 调用[\[AGCWeiboAuthProvider credentialWithToken:uid:\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcweiboauthprovider-ios-0000001054183662#section217231531613)使用从微博账号获取的accessToken和uid生成credential，并调用[\[AGCAuth signIn:\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-ios-0000001054822346#section488155612616)实现登录。  

   ```
   "Objective-C"
   AGCAuthCredential *credential = [AGCWeiboAuthProvider credentialWithToken:token uid:uid];
      [[[[AGCAuth getInstance] signIn:credential] addOnSuccessCallback:^(AGCSignInResult * _Nullable result) {
               // onSuccess
           AGCUser *user = result.user;
       }] addOnFailureCallback:^(NSError * _Nonnull error) {
           // onFail
       }];
   ```

   ```
   "Swift"
   let credential = AGCWeiboAuthProvider.credential(withToken:accessToken, uid:uid)
   AGCAuth.instance().signIn(credential: credential).onSuccess{ (result) in
       // onSuccess
   }.onFailure{ (error) in
       // onFailure
   }
   ```

#### 更多信息

* 您如果想让用户可以使用多个账号登录您的应用，可以将多个[账号进行关联](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-associated-0000001053053982)。
* 当用户不需要使用应用，或者需要切换其他账号登录认证，可以先执行[登出](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-sign-out-0000001053692708)。
* 当用户需要注销当前用户，可以进行[销户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-deleteuser-0000001057460873)。
* 对于销户、修改密码、关联账号以及重置手机账号和邮箱账号等敏感操作，为了提高安全性，需要用户必须在5分钟内登录过才能执行。如果用户执行敏感操作时登录超过5分钟，需要[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-reauthenticate-0000001127283387)后再执行敏感操作。
* 您可以参考[异常处理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-ios-troubleshooting-0000001054715191)实现自己的异常处理机制，从而减少异常情况的发生。
* 您可以使用云函数触发器来接收用户注册、登录、销户等关键事件，从而[扩展认证服务的能力](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-extension-0000001053372708)。
* 您可以参考[管理用户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-user-manage-0000001606051705)对用户进行解锁、停用等操作。
