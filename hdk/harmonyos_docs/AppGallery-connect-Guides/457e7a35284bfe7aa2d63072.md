# 成功案例

#### 电商行业案例

背景

某电商使用权限管理服务器为用户提供基于凭据的授权和鉴权的能力，该服务器日访问流量近6.85亿，且流量集中在一个核心接口中，伴有明显的波峰低谷。

痛点

该服务器之前一直使用ECS（EC2 Container Service是一个高度可扩展的软件容器管理服务）来自动调整计算资源，存在CPU使用率低，冷启动时延长，波谷时资源浪费等情况。

解决方案及效果

使用FaaS函数重构了代码架构，并通过分次切换流量验证并保证了重构后服务器功能的可用性和稳定性。在6·18大促活动中，日调用量大幅度提高至27亿次，实现了四倍弹性伸缩，流量无损扛住5W+峰值流量。并且重构后其CPU利用率达到60%，相比之前提高了25%。通过准确的流量预测，冷启动次数降低了近30%，费用相比传统ECS微服务模式降低了近90%。

#### 搜索引擎行业案例

背景

某搜索引擎服务支持应用及应用内容的搜索，可通过多个入口进行搜索查询，数据覆盖面广。其服务后台基于云主机搭建，日均请求量1亿+，运行过程中存在明显的波峰波谷。

痛点

资源利用率低且自主构建弹性伸缩能力成本高。该搜索服务日均请求量1亿+，波峰数值约16w，波谷约为4w，访问量相差4倍。其采用增强型C3云服务器，波谷时存在资源浪费的情况，而自主构建弹性伸缩能力成本高。

解决方案及效果

Serverless云函数是事件驱动的函数计算平台，可以根据函数的实际流量进行弹性伸缩。相关团队基于当前的业务架构，定制了迁移至Serverless架构的方案。从适配云函数框架、流水线改造、功能和性能测试的验收，至后续灰度放量上线，技术团队在短短1个月内全部实现。而且，业务迁移至Serverless架构后，凭借资源池化、代码缓存等技术，降低了函数启动时延，实现秒级扩缩容。实例验证，其资源成本亦降低80%以上。
