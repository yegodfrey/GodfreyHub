# 设置麦克风状态

进入语音房间后，玩家如果不希望自身语音被房间内的其他玩家接收，可通过关闭自身麦克风实现。同时，还可以通过开启麦克风的方式快速解除自身静默状态。
> 说明
>
> 初始化实例后，麦克风状态默认是开启的，此时如果加入房间则会自动提示麦克风权限的申请。如需首次打开麦克风时再提示麦克风权限申请，可参考[FAQ](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-faq-0000001181618314#section1467913424715)实现。

## 前提条件

您已[加入房间](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-joinroom-roomid-ios-0000001323024589)。

## 开发步骤

1. 调用[HWPGMEngine.getInstance enableMic](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section194168542047)方法开启/关闭玩家自身麦克风，并通过返回值获得操作结果。

   ```screen
   HWPGMEngine *pgmeEngine = [HWPGMEngine getInstance];
   int result = [pgmeEngine enableMic:isEnabled];// isEnabled：true表示开启麦克风，false表示关闭麦克风
   ```

2. 当玩家成功开启/关闭自身麦克风时，房间内其他所有玩家可通过HWPGMEngineDelegate接口的[onRemoteMicroStateChanged](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section1567362335911)方法收到该事件的回调通知。

   ```screen
   - (void)onRemoteMicroStateChanged:(NSString* _Nonnull)roomId openId:(NSString* _Nonnull)openId isMute:(BOOL) isMute{ 
       // 可根据需求将数据进行处理
   }
   ```
