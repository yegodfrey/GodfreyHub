# FAQ

#### Android和HarmonyOS 3.1/4.0及以下游戏启动profiling工具报错Connection refused可能是什么原因？

1. 动态替换插桩so后没有重新启动游戏，请尝试重启游戏。
2. 启动采集工具指定的端口号与插桩时指定端口不一致。请检查./trigger -s scenario name -p xxx指定的xxx与[提交插桩任务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/binary-optimization-submit-pile-task-0000001862646064#section84233253315)接口中InstrumentationSoInfo设置的端口号portStart是否保持一致，注意这里portStart是在InstrumentationSoInfo结构内部。  

#### 如何对现网优化后的release包进行堆栈恢复？

debug so的使用场景：release so文件优化后，部分函数的位置可能发生变化，如果现网出现问题需要定位，您需要进行堆栈恢复，则可以对release so对应的debug so进行二进制优化后，再继续问题定位。

debug so调用优化接口时，请携带对应release包采集的profile文件及symbol文件。

<br />

具体步骤如下：

1. 调用[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/binary-optimization-obtain-token-0000001909302281)接口。
2. 调用[获取文件上传地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/binary-optimization-obtain-url-0000001863302878)接口获取debug so文件的上传地址，并根据上传地址调用[上传单个文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/binary-optimization-upload-files-0000001909142601)接口上传debug so文件。
3. 调用[获取文件上传地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/binary-optimization-obtain-url-0000001863302878)接口获取symbol文件的上传地址，并根据上传地址调用[上传单个文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/binary-optimization-upload-files-0000001909142601)接口上传symbol文件（若已上传过该文件可跳过）。
4. 携带debug so文件对象ID、release包采集的profile文件对象ID及symbol文件对象ID，调用[提交优化任务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/binary-optimization-submit-opt-task-0000001863302874)接口，且debug入参为true。
5. 调用[获取优化结果](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/binary-optimization-get-opt-result-0000001909142597)接口返回本次优化过程中产生的fdata文件和优化后的so文件。
6. 将优化后的debug so文件替换原始包中的so文件，并重新打包和签名，再使用优化后的安装包进行[测试及验证收益](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/binary-optimization-test-verification-0000001572615541)。
