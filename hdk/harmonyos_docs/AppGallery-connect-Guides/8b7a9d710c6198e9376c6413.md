# 存储实例管理

AGC的云存储服务提供可视化的存储实例管理，您可以在AGC控制台对存储实例进行新增、删除操作。

## 新增存储实例

> 说明
>
> 目前，仅升级到按量付费档的用户可通过AGC控制台创建新的存储实例。
>
> 所有项目的全部存储实例数量总数不超过100个。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目。
3. 选择"云开发（Serverless） > 云存储"，进入云存储页面，点击 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251209210005.36461826946582920814234134616876:50001231000000:2800:551F1433C1F5A21C75B6829A6C64014A49CF17FF8BBDA126005196DD11284048.png)。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251209210005.12202051148193583440162705430284:50001231000000:2800:E6EE1DA5CFCE9940F50A09BF1F4A6EC3DDEEE152E314D57621DF66154B0CFB8B.png)

4. 在弹出的添加存储实例设置框中，输入需新增的存储实例名称。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251209210005.50706514484699838523753680844622:50001231000000:2800:C4B6397C084B72F38C4671C0716EC0B5718B70B079FAAF9623A3D6D0A26A846B.png)

   |--------|------------------------------------------------------------------------------------------------------------------------------------|
   |存储实例名称规范|存储实例名称必须符合以下条件： * 只能包含英文小写字母、数字、中划线（-）。 * 只能以数字或字母开头和结尾。 * 要求不少于3个字符，并且不能超过57个字符。 * 不能为IP地址。 * 不能包含连续两个及以上中划线（-）。 * 名称全局唯一，且创建后不可修改。|

## 删除存储实例

> 注意
>
> 默认存储实例无法删除。当您删除指定的存储实例时将导致其中的所有内容被删除且不可恢复，请谨慎操作。

1. 进入云存储页面，在左侧区域点击选中需删除的存储实例，点击![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251209210005.70770173900797831588584715913206:50001231000000:2800:99C09DCC655C45133A65C6F194FFE55696088AD7A18573A286836E1E1614EE3C.png)。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251209210005.16741212702664418469818874462778:50001231000000:2800:CB2452040A400617D56C71991C7DC74C13B63FBD0BFF14268600EFAD3921AA57.png)

2. 在弹出的确认框中，点击"确定"。
