# 使用控制面板调试

控制面板支持以下操作：

* 交互操作：您可以通过控制面板与调试设备进行交互操作，如上传图片、打开网页、复制文本和获取文本等。
* Shell脚本操作，您可以通过输入adb/hdc命令来执行操作。
* 设置调试设备的地理位置。您可以通过输入正确的经度、纬度和海拔高度从而定位到具体位置。
* 剪贴板操作支持将文本传送到正在测试设备的剪贴板中。控制面板能够为您提供更加真实、便捷的调试体验。

#### 前提条件

进行控制面板内的各项操作前必须先[申请调试设备](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddebug-debugequip-0000001122212029#section11242145501420)。  

#### 交互操作

调试设备申请成功后，进入调试页面，点击"控制面板"页签，您可以上传图片、打开网页、复制文本和获取文本。

* 上传图片：您可以将本地500KB以内的以.png或.jpg结尾的图片文件上传至调试设备。
* 打开网页：您可直接在右侧输入框输入网页地址，点击"打开网页"。
* 复制文本：您可以在输入框输入对应文字，点击"提交剪贴板"后，在屏幕对应操作区域，点击"粘贴"。
* 获取文本：您可复制调试设备中的目标区域文字，然后点击"获得内容"，即可将设备中的文本提取出来。

![](https://media:201778314577009230 "点击放大")  

#### Shell脚本操作

调试设备申请成功后，进入调试页面，点击"控制面板"页签，选择Shell脚本输入框，输入adb/hdc命令，点击"执行"发送命令，清除按钮可清除本次执行结果。  
![](https://media:201778314577043231)  
* 由于安全限制，当前adb调试不支持reboot、reboot recovery和settings put global adb_enabled 0命令。
* 输入命令时，可不携带"adb shell/hdc shell"前缀，当携带前缀时，系统会自动过滤前缀后再执行命令。

![](https://media:201778314577088232 "点击放大")

此外，云调试已支持识别持续打印输出的shell命令（如logcat/hilog），并新增了停止操作。当系统识别出您输入的为持续打印日志的adb shell/hdc shell命令时，命令执行一段时间后，"执行"按钮将自动变更为"停止"。如下图所示，您可根据需要随时点击"停止"以暂停命令执行。点击"停止"后，按钮将恢复为"执行"，您可以继续执行当前命令或其他adb shell/hdc shell命令。

![](https://media:201778314577136233)  

#### 设置地理位置

![](https://media:201778314577160234)  
当前仅支持深圳区域的华为Android 10的手机和平板真机设备。

您可以通过设置具体的地理位置信息，了解应用在特定位置的使用情况。

调试设备申请成功后，进入调试页面，点击"控制面板"页签，填写GPS的相关信息：经度、纬度和海拔高度。填写完成后，点击"确定"，页面提示设置成功，则地理位置设置成功。

![](https://media:201778314577208235 "点击放大")
