# 业务介绍

|------------------------------------------------------------------------------------------------------|-|
|云调试致力于为您提供高效的云端设备调试解决方案，解决您设备机型不足、设备管理困难及bug无法复现等问题，降低您的采购及管理成本。云调试提供不同型号的机型，让您可随时随地直观了解应用在不同机型上的运行表现。| |

#### 主要功能

云调试远程操作流畅无卡顿，操作体验简洁人性化，支持的调试功能包括：  

|主要功能|功能描述|
|:--------------------------|:----------------------------------------------------------------------------------------------------|
|HAP/APP/APK/RPK/OBB/AAB应用调试|支持HAP/APP/APK/RPK/OBB/AAB格式的应用调试。 说明： * HarmonyOS 5及以上设备仅支持调试HAP和APP格式的应用。 * 当前不支持在三方品牌设备上调试RPK格式的应用。|
|主题调试|支持在华为Android设备上对Android主题包进行主题调试。 说明： 不支持对HarmonyOS主题包进行主题调试。|
|日志查看和导出|支持在线查看和导出完整的系统日志和应用日志，进行错误定位。|
|测试报告查看|测试过程回顾，方便您对测试历史的查看。|
|截屏/录屏功能|测试过程截屏/录屏，保留测试过程的关键界面信息，分析测试结果的还原度。 说明： 当前HarmonyOS 5及以上设备仅支持截屏功能。|

#### 工作原理

通过云调试服务远程连接设备，上传应用或主题，通过鼠标在设备投屏画面上操作设备。在调试过程中，您可以获取设备运行期间的系统日志、应用日志或主题日志，从而帮助您定位问题，实现远程调测应用或主题的目的。

#### 调试流程

本章节介绍单机调试流程。  

|序号|步骤|详情|
|:-|:------|:--------------------------------------|
|1|申请设备|申请1台云调试设备（同一账号最多同时占用2台设备）。|
|2|系统初始化设备|申请设备成功后进行设备初始化。|
|3|管理应用和主题|在调试界面您可以上传、安装、删除应用和主题，并对应用和主题进行管理。|
|4|开始调试|您可在调试设备上根据需求进行相应调试操作。|
|5|查看和导出日志|在线获取设备运行期间的系统日志和应用或主题日志，支持日志导出，帮助您定位问题。|
