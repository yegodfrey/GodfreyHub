# 列举文件

列举文件是指获取某个目录下的所有文件和目录信息，云存储SDK支持通过API列举云端某个目录下的所有文件或子目录。  

#### 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[初始化存储实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-initialize-bucket-ios-0000001333893477)。  

#### 操作步骤

1. 在列举某个目录下的文件或目录前，先调用[\[AGCStorage reference\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstorage-0000001172981557#section939311202814)创建目录的引用。例如创建根目录的引用：  

   ```
   "Objective-C"
   //storage为已经初始化的AGCStorage实例
   AGCStorageReference *reference = [storage reference];
   ```

   ```
   "Swift"
   //storage为已经初始化的AGCStorage实例
   let reference = storage.reference()
   ```

2. 调用[\[AGCStorageReference listAll\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragereference-0000001126781968#section090811803512)可获取当前目录下所有文件与目录。  

   ```
   "Objective-C"
   HMFTask<AGCStorageListResult*> *listTask = [reference listAll];
   [[listTask addOnFailureCallback:^(NSError *error){
   }] addOnSuccessCallback:^(AGCStorageListResult *result){

   }];
   ```

   ```
   "Swift"
   let listTask = reference.listAll()
   listTask.onSuccess{(result) in 
   }.onFailure{(error) in
   }
   ```

   如果需要分页获取，可以调用[\[AGCStorageReference list:marker:\]](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragereference-0000001126781968#section642665323117)方法。  

   ```
   "Objective-C"
   HMFTask<AGCStorageListResult*> *listTask = [reference list:50 marker:@"markerValue"];
   [[listTask addOnFailureCallback:^(NSError *error){
       
   }] addOnSuccessCallback:^(AGCStorageListResult *result){

   }];
   ```

   ```
   "Swift"
   let listTask = reference.list(50, "markerValue")
   listTask.onSuccess{(result) in 
   }.onFailure{(error) in
   }
   ```

3. 从[AGCStorageListResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragelistresult-0000001172821641)中获取某个子目录的引用后，可以继续调用list方法获取子目录下的文件和目录。  

   ```
   "Objective-C"
   Task<ListResult> listTask = [[storage referenceWithPath:@"images/"] listAll];
   [[listTask addOnFailureCallback:^(NSError *error){
       
   }] addOnSuccessCallback:^(AGCStorageListResult *result){

   }];
   ```

   ```
   "Swift"
   let listTask = storage.reference(withPath: @"images/").listAll()
   listTask.onSuccess{(result) in 
   }.onFailure{(error) in
   }
   ```
