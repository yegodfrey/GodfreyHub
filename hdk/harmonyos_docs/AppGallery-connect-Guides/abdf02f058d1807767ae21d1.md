# 使用限制

## API 限额

|操作|限额|
|:-------------------------|:---------------------------------------------------------------------------------|
|接口调用频率|20次/设备/小时。 > 说明 > Web无此限制。|
|网关返回429，500，502，503，504错误码|根据连续失败次数确定限流时间，失败次数为x（>2），则限流时间为2^x-1^分钟，最高为256分钟。限流时返回FETCH_THROTTLED错误，接口暂时无法访问。|

## 参数和条件限制

* 对单个项目最多可以有2000个参数和500个条件，所有参数值字符串的总长度不能超过800K个字符。
* 参数名称和条件名称最多可包含256个字符，且必须以下划线或英文字母（A-Z、a-z）开头，还可以包含数字。

## 历史版本管理限制

支持最多90天300个历史版本管理和回退能力。

## 设备限制

设备限制是指SDK对用户终端的限制。

|限制项|限制|
|:-----------|:-----------------------------------------------------------------------------------------------------------|
|设备品牌|支持所有品牌设备。|
|设备类型|HarmonyOS当前仅支持手机和平板设备。|
|Android OS|Android 4.2及以上（API Level 17及以上）|
|iOS|* 1.2.1.300及以前版本：iOS 8及以上 * 1.3.0.300及以后版本：iOS 9及以上|
|Web浏览器|* Chrome 51及以上 * Edge 79及以上 * Firefox 54及以上 * 华为浏览器 * Safari 10及以上 * UC桌面浏览器 建议最新版本 * QQ桌面浏览器 10.4及以上 * IE11|
|EMUI（针对华为手机）|无限制。|
|HMS Core APK|无限制。|
|应用市场客户端|无限制。|
