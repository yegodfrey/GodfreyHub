# 暂停下载

#### 接口描述

调用该api可暂停下载任务。  

#### 输入参数

|参数名称|参数类型|是否必选|参数说明|
|:-----------|:-----|:---|:------|
|mPackageName|String|必选|下载任务的包名|

#### 返回参数

参见AgdApi.startDownloadTaskV2的mResult  

#### 示例代码

```
PauseTaskIPCRequest pauseTaskIPCRequest = new PauseTaskIPCRequest();
pauseTaskIPCRequest.setPackageName(pkg);
PendingResult<PauseTaskIPCRequest, TaskOperationResponse> pendingResultPause = AgdApi.pauseTask(client, pauseTaskIPCRequest);
pendingResultPause.setResultCallback(new ResultCallback<TaskOperationResponse>() {
    @Override
    public void onResult(Status<TaskOperationResponse> result) {
        Log.i(TAG, "onResult:" + result.getStatusCode());
   }
});
```
