# 典型应用场景

## 保障签名密钥的安全性

如果您的应用未使用应用签名服务，当您丢失了签名密钥时，您将无法在华为应用市场升级您的应用，只能通过新的包名发布新的应用或者申请变更签名密钥，这样所有的用户都需要重新安装应用。

使用应用签名服务后，AGC将在服务端保护您的签名密钥，您只需要维护您的上传密钥，即使您的上传密钥丢失，AGC仍然支持您继续在华为应用市场升级应用，所有用户仍然可以正常更新应用。

## 发布App Bundle应用

应用签名服务可以支持您在华为应用市场发布一个App Bundle应用，帮助您缩减应用软件包的大小。您还可以通过与华为[Dynamic Ability](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-dynamicability-introduction-0000001057944549)服务结合使用，实现动态加载特性。当您发布App Bundle应用时，应用签名服务可以帮助您将您的AAB包编译成多个APK，并使用AGC管理的签名密钥对APK签名，保障签名密钥安全的同时提升用户的应用安装体验。
