# 管理站点

项目开通云托管服务后，您可以在该项目下管理站点。

* 通过AGC控制台管理站点：在AGC界面中以可视化的方式创建[中国站点](#section174011347142315)和[海外站点](#section860111010479)。
* 通过[API管理站点](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-cloudhost-createsite-0000001216061466)（仅支持使用泛域名管理站点）。

## 创建中国站点

当数据处理位置为中国时，您需要使用自定义域名（如 fly.huawei.com）。云托管会为您的各个域名预配SSL证书，并通过CDN向用户提供您的内容。

1. 申请自定义域名并拥有该域名提供商对应的DNS管理台配置权限（例如TXT记录，CNAME记录）。 说明
   >
   > 自定义域名需满足以下条件：
   > * 域名必须在中国工信部有备案记录。
   > * 域名必须遵守注册规范，只能包含英文字母，数字，小数点，中划线，且长度不能超过63个字符。
   > * 域名在当前系统中不能重复。


2. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
3. 在项目列表中找到您需要创建云托管站点的项目。
4. 点击"云开发（Serverless） > 云托管 > 服务管理"，进入"服务管理"页面，并在"网站托管"框中点击"开通"。 说明
   >
   > 如果该项目的网站托管功能已配置站点，本步骤请点击"进入"。

## 创建海外站点

当数据处理位置为德国、俄罗斯或新加坡时，您可以使用自定义域名（如 fly.huawei.com）或泛域名创建站点。

### 使用自定义域名创建站点

> 说明
>
> 创建海外站点时，云托管服务默认使用自定义域名。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择您需要创建云托管站点的应用。
3. 点击"云开发（Serverless） > 云托管 > 服务管理"，进入"服务管理"页面。
4. 在"网站托管"框中点击"开通"，进入"站点管理"页面。 说明
   >
   > 如果该项目已经配置过站点，本步骤请点击"进入"。
5. 在"站点管理"页面，确认下拉框中显示"自定义域名"后，点击"创建站点"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250709150004.73906051414200883398550802521311:50001231000000:2800:0A36E75FD2076AB726DC484A1B2B592EE291EBF6389B86657E1C628DD3986C63.png)

### 使用泛域名创建站点

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择您需要创建云托管站点的应用。
3. 点击"云开发（Serverless） > 云托管 > 服务管理"，进入"服务管理"页面。
4. 在"网站托管"框中点击"开通"，进入"站点管理"页面。 说明
   >
   > 如果该项目已经配置过站点，本步骤请点击"进入"。
5. 在"站点管理"页面，下拉框中选择"泛域名"后，点击"创建站点"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250709150004.30091266315815538606615967006201:50001231000000:2800:CD6719C14D422D951410719CC8869B4BA2BE840CB29EF4D32FEABB2D30FDEDDC.png)

6. 输入站点名称和站点描述信息，点击"确定"，完成创建。站点名称只允许包含数字，英文字母以及短横线（-）。 说明
   >
   > 各站点域名后缀如下：
   > * 新加坡站点：*.dra.agchosting.link
   > * 德国站点：*.dre.agchosting.link
   > * 俄罗斯站点：*.drru.agchosting.link

## 删除站点

如您需要删除之前创建的站点，在"操作"列点击"删除"，输入站点名称后，点击"确定"。
> 注意
>
> * 删除站点后，站点下的所有版本都会被同步删除，无法恢复。请谨慎操作。
> * 请确保输入的站点名称前后均无空格，否则会导致删除失败。
