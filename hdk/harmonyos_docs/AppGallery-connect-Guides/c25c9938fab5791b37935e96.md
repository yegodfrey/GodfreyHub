# Server使用入门

很多场景下，您有从您的服务端发起对华为服务访问的诉求，比如在管理台管理用户或者处理业务访问时操作数据库等等。AppGallery Connect（简称AGC）提供了Server SDK供您集成到您的服务端完成相应的功能开发，基本开发流程如下：

1. [准备开发环境](#section163693114212)
2. [下载认证凭据](#section17109145013261)
3. 集成SDK
   * [集成Java SDK](#section136535224920)
   * [集成Node.js SDK](#section499710615219)
4. [功能开发](#section1128101874815)

#### 准备开发环境

1. 推荐运行环境：
   * Java：Java 8+
   * Node.js：10.12.0+
2. 访问AGC页面时推荐使用谷歌浏览器。如果使用win10系统的火狐浏览器，可能出现请求被浏览器拦截，导致点击下载无响应的问题。 处理方法：

   1. 在火狐浏览器地址栏输入about:config。
   2. 查找security.csp.enable，将其切换为 false。
3. 在[华为开发者联盟](https://developer.huawei.com/consumer/cn)上注册成为开发者并完成实名认证，具体方法可参考[账号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。  

#### 下载认证凭据

根据服务类型下载对应的凭据类型，当前支持的服务和其凭据类型如下：  

|凭据类型|服务名|
|:-----------------------------|:------------------------|
|[项目级凭据](#section1778162811430)|* 认证服务 * 云存储 * 云数据库 * 云函数|
|[团队级凭据](#section448976124412)|N/A|

#### 项目级凭据

使用Server SDK项目级凭据的前提是您已经在AGC中拥有了自己的项目，并在项目中开通了AGC对应的服务且已[设置数据处理位置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-data-storage-location-0000001162597847)。确保已完成以上操作后，您可参考如下方法下载认证凭据：

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。
2. 在项目列表中点击您的项目。 ![](https://media:201775716929061919)

   <br />

3. 在"项目设置"页面中点击"Server SDK"页签。
4. 点击认证凭据中的"创建"。  
   ![](https://media:201775716929107920)  
   您也可以在"用户与访问"下的"API密钥 \> Connect API"中创建并下载项目级API客户端，您需确保API客户端被正确指定项目和角色。

   ![](https://media:201775716929147921)
5. 创建完后生成认证凭据，点击"下载认证凭据"。 ![](https://media:201775716929230922)

6. 将下载后的认证凭据文件agc-apiclient-\*.json放置到您的Server服务器中指定路径下，后续初始化SDK时将会使用到该文件。  
   ![](https://media:201775716929336923)  
   凭据文件中包含您的client_secret信息，请您妥善保管。

#### 团队级凭据

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"用户与访问"。
2. 选择左侧导航栏的"API密钥 \> Connect API"，选择"API客户端"页签，点击"创建"。
3. 在"创建API客户端"窗口，配置API客户端信息。在"名称"列输入自定义的客户端名称，"项目"请保持为N/A，并选择对应的"角色"，点击"确认"。  
   ![](https://media:201775716929697924)  
   * "项目"为N/A，即创建的客户端为团队级的API客户端。
   * 服务所需的角色如下表所示，具体角色对应的权限请参考[角色与权限](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-rolepermission-0000001155345429)。

   ![](https://media:201775716929824925)

   <br />

4. 客户端创建成功后，点击"下载"。 ![](https://media:201775716929866926)

   <br />

5. 将下载后的认证凭据文件agc-apiclient-\*.json放置到您的Server服务器中指定路径下，后续初始化SDK时将会使用到该文件。  
   ![](https://media:201775716929930927)  
凭据文件中包含您的client_secret信息，请您妥善保管。  

#### 集成Java SDK

当前仅部分AGC服务提供了Java SDK，在使用此类服务前需要将AGC SDK集成到您的开发环境，涉及的服务为：

* 认证服务
* 云存储
* 云数据库
* 云函数  

#### 集成Java Server SDK

AGC Server SDK发布在Maven仓库，需要在pom.xml文件中添加Maven仓库地址和SDK依赖。

1. 在项目中找到pom.xml文件，并添加Maven仓库地址。  
   ![](https://media:201775716929967928)

   ```
   <repositories>
       <repository>
           <id>sz-maven-public</id>
           <name>sz-maven-public</name>
           <url>https://developer.huawei.com/repo/</url>
       </repository>
   </repositories>
   ```

<!-- -->

2. 添加各服务SDK的依赖。

   ```
   <dependency>
       <groupId>com.huawei.agconnect.server</groupId>
       <artifactId>agconnect-auth</artifactId>
       <version>1.2.3.300</version>
   </dependency>
   ```

   |服务名|artifactId|version|
   |:-----|:----------------------------|:---------|
   |认证服务|agconnect-auth|1.2.3.300|
   |云存储|agconnect-storage|1.2.5.300|
   |Edukit|agconnect-edukit|12.0.1.300|
   |云数据库|agconnect-database-server-sdk|1.0.13.300|
   |云函数|agconnect-function-server|1.0.2.400|

#### 初始化Java Server SDK

1. [获取项目级认证凭据文件agc-apiclient-\*.json](#section1778162811430)。
2. 使用认证凭据对SDK进行初始化。 当前认证凭证初始化提供了两种方式。您可以设置AGC_CONFIG环境变量，也可以在代码中明确传递认证凭证路径。

   * 方式一：需要先设置环境变量。
     * Linux环境请执行如下操作： 永久环境变量需要在$HOME目录中的.bashrc或者.bash_profile文件中写入如下命令，并执行source .bashrc或者.bash_profile保证环境变量生效。临时环境变量直接执行如下命令，\[PATH\]请替换为凭据文件的实际路径。

       ```
       export AGC_CONFIG="[PATH]/agc-apiclient-xxx-xxx.json"
       ```

     * Windows环境请执行如下操作: 永久环境变量需要在Windows的"高级系统设置 \> 环境变量"中设置如下的系统变量，建议重启windows系统或者通过其他方式加载环境变量，使设置的系统环境变量生效。

       临时环境变量直接执行如下命令，\[PATH\]请替换为凭据文件的实际路径。

       ```
       set AGC_CONFIG=[PATH]\agc-apiclient-xxx-xxx.json
       ```

     然后执行如下操作进行初始化：

     ```
     AGCClient.initialize();
     ```

     您也可以为客户端设置名称和数据处理位置，用于支持云存储服务灵活地选择数据处理位置。

     ```
     String clientName = "[CLIENT_NAME]";
     String region= "[REGION]";
     AGCClient.initialize(clientName, region);
     ```

     其中\[CLIENT_NAME\]为用户自定义的客户端名称，在获取服务实例的时候，需要用此名称进行关联。\[REGION\]是客户端的数据处理位置，可选的值有"CN"（中国）、"RU"（俄罗斯）、"SG"（新加坡）、"DE"（德国）。

   <!-- -->

   * 方式二：需要明确传递认证凭证路径。请执行如下操作，\[PATH\]请替换为凭据文件的实际路径。

     ```
     CredentialService credential = CredentialParser.toCredential("[PATH]/agc-apiclient-xxx-xxx.json");
     AGCParameter parameter = AGCParameter.builder().setCredential(credential).build();
     AGCClient.initialize(parameter);
     ```

     您也可以为客户端设置名称和数据处理位置，用于支持云存储服务灵活地选择数据处理位置。

     ```
     String clientName = "[CLIENT_NAME]";
     String region= "[REGION]";
     CredentialService credential = CredentialParser.toCredential("[PATH]/agc-apiclient-xxx-xxx.json");
     AGCParameter parameter = AGCParameter.builder().setCredential(credential).build();
     AGCClient.initialize(clientName, parameter, region);
     ```

其中\[CLIENT_NAME\]为用户自定义的客户端名称，在获取服务实例的时候，需要用此名称进行关联。\[REGION\]是客户端的数据处理位置，可选的值有"CN"（中国）、"RU"（俄罗斯）、"SG"（新加坡）、"DE"（德国）。  

#### 集成Node.js SDK

当前仅部分AGC服务提供了SDK，在使用此类服务前需要将AGC SDK集成到您的开发环境，涉及的服务为：

* 认证服务
* 云函数
* 云数据库

开发者通过云侧访问云开发资源时，支持如下两种场景：

* 如您没有自己的服务器，推荐通过AGC云函数访问云开发资源，此方式无需手动下载凭据文件，具体请参考[（推荐）从云函数访问](#section1369317173812)。
* 如您搭建了自己的服务器且希望通过自己的服务器来访问云开发资源，则需手动下载凭据文件并集成到代码中，具体请参考[从服务器访问](#section650710138449)。  

#### （推荐）从云函数访问

准备工作

目前您可以通过DevEco Studio创建端云一体化开发工程来实现在云函数中访问云开发服务资源，您需要完成如下操作：

1. [创建端云一体化开发工程](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V5/agc-harmonyos-clouddev-devproject-V5)。
2. [创建您准备访问云开发服务的云函数](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V5/agc-harmonyos-clouddev-createfunc-V5)。

集成Node.js Server SDK

AGC Server SDK发布在npm仓库，您可以通过下列步骤来进行集成：

1. 如果您还没有package.json文件，可进入Terminal终端窗口，在您新建的云函数目录下执行以下命令进行创建。

   ```
   npm init
   ```

   请按实际情况填写项目的配置信息。
2. 在该目录下继续执行以下命令，安装Server SDK到您的项目中。此时依赖将同步添加到云函数目录下的package.json文件中。

   ```
   npm install --save @hw-agconnect/cloud-server
   ```

3. 在您的云函数目录下准备访问云开发服务的代码文件中添加如下代码，导入云开发模块。

   ```
   import { cloud } from "@hw-agconnect/cloud-server";
   ```

之后您即可直接在该云函数中通过Server SDK访问云开发服务资源了。  

#### 从服务器访问

集成Node.js Server SDK  
Node.js Server SDK发布在npm仓库，您可以通过下列步骤来进行集成：

1. 如果您还没有package.json文件，可进入Terminal终端窗口，在项目的根目录下执行以下命令进行创建。

   ```
   npm init
   ```

   请按实际情况填写项目的配置信息。
2. 在该目录下继续执行以下命令，安装Server SDK到您的项目中。此时依赖将同步添加到您项目的package.json文件中。

   ```
   npm install --save @hw-agconnect/cloud-server
   ```

3. 在您的项目中添加如下代码，导入云开发模块。

   ```
   import { cloud } from "@hw-agconnect/cloud-server";
   ```

初始化Node.js Server SDK

从您自己构建或者购买的服务器发起的访问，需要下载凭据文件并集成到代码中。

1. [获取项目级认证凭据文件agc-apiclient-\*.json](#section1778162811430)，并将认证凭据放置到您自定义的目录，服务器执行用户需要具备认证凭据文件读权限。
2. 使用认证凭据对SDK进行初始化。 使用步骤1下载的认证凭据对SDK进行初始化。当前认证凭证初始化提供了两种方式，您可以设置AGC_CONFIG环境变量，也可以在代码中明确传递认证凭据路径。

   * 方式一：需要先设置环境变量。
     * Linux环境请执行如下操作： 永久环境变量需要在$HOME目录中的.bashrc或者.bash_profile文件中写入如下命令，并执行source .bashrc或者.bash_profile保证环境变量生效。临时环境变量直接执行如下命令，\[PATH\]请替换为凭据文件的实际路径。

       ```
       export AGC_CONFIG="[PATH]/agc-apiclient-xxx-xxx.json"
       ```

     * Windows环境请执行如下操作: 永久环境变量需要在Windows的"高级系统设置 \> 环境变量"中设置如下的系统变量，建议重启Windows系统或者通过其他方式加载环境变量，使设置的系统环境变量生效。

       临时环境变量直接执行如下命令，\[PATH\]请替换为凭据文件的实际路径。

       ```
       set AGC_CONFIG=[PATH]\agc-apiclient-xxx-xxx.json
       ```

     接下来便可以直接使用云开发服务。

   <!-- -->

   * 方式二：指定认证凭据路径。请执行如下操作，\[PATH\]请替换为凭据文件的实际路径。  
     如不设置环境变量，则必须使用此方式。您还可以使用凭据文件创建多个实例。

     ```
     const cloudInstance = cloud.createInstance({'[PATH]/agc-apiclient-xxx-xxx.json',"instancename",Region.REGION_CN});
     ```

其中Region是客户端的数据处理位置，可选的值有"REGION_CN"（中国）、"REGION_RU"（俄罗斯）、"REGION_SG"（新加坡）、"REGION_DE"（德国）。
