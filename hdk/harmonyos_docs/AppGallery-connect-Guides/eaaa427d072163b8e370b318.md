# 获取SDK配置信息

## Android

### 获取agconnect-services.json文件

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择您的应用。
3. 在"项目设置"的"常规"页面，下载agconnect-services.json文件。 说明
   > * 配置文件中默认会包含AGC为应用分配的客户端密钥和API密钥信息，其中客户端密钥和API密钥均为密文。
   > * 您也可以在下载JSON文件前打开"不包含密钥"开关，配置文件中将不包含密钥信息，由您自行调用AGC SDK的接口手动配置。
   > * 如果您的套餐升级到了付费档，为避免被冒用产生异常账单，建议您将密钥存储在您自己的服务器，并妥善保管。

## iOS

### 获取agconnect-services.plist文件

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择您的iOS应用。
3. 在"项目设置"页面下载配置文件"agconnect-services.plist"。 说明
   > * 配置文件中默认会包含AGC为应用分配的客户端密钥和API密钥信息，其中客户端密钥和API密钥均为密文。您也可以在下载agconnect-services.plist文件前打开"不包含密钥"开关，配置文件中将不包含密钥信息，由您自行调用AGC SDK的接口手动配置。如果您的套餐升级到了付费档，为避免被冒用产生异常账单，建议您将密钥存储在您自己的服务器，并妥善保管。
   > * Safari浏览器当前不支持下载"agconnect-services.plist"文件，请使用Chrome浏览器。

## Web

### 获取Web应用配置信息

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择您的应用。
3. 在"项目设置"的"常规"页面，配置网站限制。

   当您的Web应用需要限制仅指定网站或IP地址才可访问已开通的API时，您可点击"网站限制"后的![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251125091002.33518973597047297141372125482118:50001231000000:2800:8E27D0D6378121C833572947FE7B6152B5AF2A2FD92AB931CC61FC491E8AEF81.png)，填写指定的域名地址。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251125091002.13307547821106025145539141829813:50001231000000:2800:28D4B368F1CB8DFB42014C4F5035432FB49FD4C865CD7DC12A45C55E8D6F995B.png)

   > * 域名地址需要以http://和https://开头。

## HarmonyOS（TypeScript)

### 获取agconnect-services.json文件

为了简化您的配置步骤，AGC为您提供了应用配置信息，您只需要将配置信息添加到您的项目中。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择您的应用。
3. 在"项目设置"页面下载配置文件"agconnect-services.json"。 说明
   > * "不包含密钥"开关默认关闭，配置文件中将会包含AGC为应用分配的客户端密钥和API密钥信息，其中客户端密钥和API密钥均为密文。
   > * 您也可以在下载JSON文件前打开"不包含密钥"开关，配置文件中将不包含密钥信息，客户端密钥和API密钥需要由您自行调用AGC SDK的接口手动配置。
   > * 如果您的套餐升级到了付费档，为避免被冒用产生异常账单，建议您打开"不包含密钥"开关，将密钥存储在您自己的服务器，并妥善保管。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251125091003.76219361767449168947578442321018:50001231000000:2800:D0950AE431C4C504F2B0D627F705BE5CFFBCC8BC3DF842D57284F20E0A1F76ED.png)
