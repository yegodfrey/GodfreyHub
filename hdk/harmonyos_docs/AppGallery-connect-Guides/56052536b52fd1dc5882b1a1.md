# 展示应用内消息

当您在AGC后台创建了消息、并且集成了应用内消息SDK，当达到消息展示的触发条件后，应用内消息SDK会自动以默认的消息展示布局在应用中展示消息。您可以不需要编写任何代码，就可以拥有展示消息的能力。如果您需要对展示的消息或目标用户进行一些其他的特殊配置，您可以通过调用应用内消息SDK提供的API完成。  

#### 前提条件

* 已[添加应用内消息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-appmessage-create-ios-0000001071924650)。
* 已[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-appmessaging-integratesdk-ios-0000001071772755)。
* 如果您想要以自定义布局展示消息，则需前往AGC控制台进行设置，具体请参见[自定义消息布局](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-appmessage-create-ios-0000001071924650#ZH-CN_TOPIC_0000001071924650__zh-cn_topic_0000001072054882_zh-cn_topic_0000001199092457_zh-cn_topic_0000001071730074_li11180317169)。  

#### 应用内消息的展示条件

应用内消息SDK展示消息的条件包括以下几点：

* App必须在前台运行。
* 开启从AGC服务端数据拉取功能（默认为开启）。

  ```
  "Objective-C"
  [AGCAppMessaging sharedInstance].isFetchMessagingEnable = YES;
  ```

  ```
  "Swift"
  AGCAppMessaging.sharedInstance().isFetchMessageEnable = true
  ```

  ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250307095813.33271582938513888340550793868155:50001231000000:2800:672BE8E17D296C2496DBF8A0A39E5527DAD4C6BDE01DB133FAB6F6BDD7682E24.png?needInitFileName=true?needInitFileName=true)  
  * 应用内消息SDK并不是每次触发事件都会去AGC服务端请求消息，而是每8小时请求一次（通常为App启动时），然后把所有的消息缓存到本地，在过期时间之内事件触发时只会从本地读取消息。
  * 在消息数据未过期时间内，如果在AGC创建了新的消息，由于应用内消息SDK不会再次到AGC请求数据，新创建的消息将不会被获取。
* AGC上创建了应用内消息，且消息处于发布状态，并满足以下条件：
  * 消息的开始时间和结束时间满足要求：当前时间（手机时间）需要大于消息的开始时间且小于结束时间。
  * 消息的展示频率满足要求：消息没有被展示过，展示的次数或者频率没有超过限制。
  * 消息的触发事件满足要求：消息的触发事件列表中需要包含此次App的触发事件。
* 开启消息展示功能（默认为开启）。  

  ```
  "Objective-C"
  [AGCAppMessaging sharedInstance].isDisplayEnable = YES;
  ```

  ```
  "Swift"
  AGCAppMessaging.sharedInstance().isDisplayEnable = true
  ```

#### 应用内消息的交互与响应

通过应用内消息SDK，您可以进一步定制应用内消息的行为，在用户与消息交互时进行响应，应用内消息SDK支持对消息的展示、点击和消失事件的监听。实现的基本步骤如下：

1. 设置实现[AGCAppMessagingDelegate](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcappmessagingdelegate-ios-0000001057489789)协议的对象到[\[AGCAppMessaging sharedInstance\].delegate](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcappmessaging-ios-0000001058729698#section02131261513)。
2. 根据实际情况来监听消息的展示、点击、消失和展示错误事件的回调。

   ```
   @interface AppDelegate () <AGCAppMessagingDelegate>

   @end

   - (BOOL)application:(UIApplication *)application didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {
       [AGCInstance startUp];
       [HiAnalytics config];
       [AGCAppMessaging sharedInstance].delegate = self;
       return YES;
   }

   - (void)appMessagingOnDisplay:(AGCAppMessagingDisplayMessage *)message {
   }

   - (void)appMessagingOnClick:(AGCAppMessagingDisplayMessage *)message button:(AGCAppMessagingActionButton *)button {
   }

   - (void)appMessagingOnDismiss:(AGCAppMessagingDisplayMessage *)message dismissType:(AGCAppMessagingDismissType)dismissType {
   }

   - (void)appMessagingOnError:(AGCAppMessagingDisplayMessage *)message {
   }
   ```

#### 设置自定义布局

应用内消息服务提供默认的展示布局：弹框消息、图片消息和Banner消息。您也可以自定义消息的展示样式，从而使得消息的展示布局更加适合App的主题。

您可以通过实现[AGCAppMessagingDisplayDelegate](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcappmessagingdisplaydelegate-ios-0000001058089745)协议来处理要展示的消息，并把实现此协议的对象赋值到[\[AGCAppMessaging sharedInstance\].displayComponent](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcappmessaging-ios-0000001058729698#section14502105011521)。需要注意的是，自定义布局需要开发者根据实际的展示行为实现对应的回调事件。

```
@interface AppDelegate () <AGCAppMessagingDisplayDelegate>

@end

@implementation AppDelegate

- (void)appMessageDisplay:(AGCAppMessagingDisplayMessage *)message delegate:(id<AGCAppMessagingDelegate>)delegate {
    if ([message isKindOfClass:[AGCAppMessagingCardDisplay class]]) {
        AGCAppMessagingCardDisplay *card = (AGCAppMessagingCardDisplay *)message;
        UIAlertController *controller = [UIAlertController alertControllerWithTitle:card.title message:card.body preferredStyle:UIAlertControllerStyleAlert];
        if (card.majorButton) {
            [controller addAction:[UIAlertAction actionWithTitle:card.majorButton.text style:UIAlertActionStyleDefault handler:^(UIAlertAction * _Nonnull action) {
                if (card.majorButton.actionURL) {
                    [UIApplication.sharedApplication openURL:card.majorButton.actionURL];
                } else {
                    [controller dismissViewControllerAnimated:YES completion:nil];
                }
            }]];
        }
        if (card.minorButton) {
            [controller addAction:[UIAlertAction actionWithTitle:card.minorButton.text style:UIAlertActionStyleDefault handler:^(UIAlertAction * _Nonnull action) {
                if (card.minorButton.actionURL) {
                    [UIApplication.sharedApplication openURL:card.minorButton.actionURL];
                } else {
                    [controller dismissViewControllerAnimated:YES completion:nil];
                }
            }]];
        }
        [self.window.rootViewController presentViewController:controller animated:YES completion:^{
            if (delegate && [delegate respondsToSelector:@selector(appMessagingOnDisplay:)]) {
                [delegate appMessagingOnDisplay:message];
            }
        }];
    }
}

- (BOOL)application:(UIApplication *)application didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {
    // Override point for customization after application launch.
    [AGCInstance startUp];
    [HiAnalytics config];
    [AGCAppMessaging sharedInstance].displayComponent = self;
    return YES;
}
```
