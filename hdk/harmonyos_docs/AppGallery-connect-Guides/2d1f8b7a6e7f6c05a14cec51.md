# 调用函数

#### 查询函数名和版本号

当您创建了"http请求"函数后，系统会自动生成http请求URL，在主调函数的代码中调用函数时需要传入被调函数的函数名和版本号（或别名），查询方法如下：

在函数详情页面点击"触发器"页签，获取"请求URL"。如下图所示，"httptest"为函数名，"0"为版本号（或别名）。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704121835.76769658735106326042124641878460:50001231000000:2800:03EDD56040671B7F8386A2133466DC13F38FE011E7326C4826AA204A3C05259A.png)  

#### 查询项目信息

当您在云函数运行环境以外的公网环境，使用SDK构造HTTP请求调用函数时，需要设置被调函数的项目信息projectId、clientId及clientSecret，查询方法如下：

在AGC主页点击"开发与服务"，选择被调函数所在的项目，点击"项目设置"。如下图所示，"项目ID"即为projectId，"Client ID"即为clientId，"Client Secret"即为clientSecret。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704121835.11840729195721757523426052105575:50001231000000:2800:92402F6F5672A217C406F47A68634AAB58F20B7B52AFF1E96CADB92DDE30CA0E.png)  

#### 调用函数

工程集成了云函数Server SDK后，可以在工程内直接通过SDK API调用云函数，云函数SDK与AGC云侧的函数调用基于传输通道为HTTPS的安全访问。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704121835.30955602058725662987461066651730:50001231000000:2800:50891A4BD3424BA3238740935886674F32CA3466B1FC0EB71017EF19825A3202.png "点击放大")

1. 创建一个AGCClient对象。先手动加载认证凭据agc-apiclient.json，然后通过认证凭据来生成AGCClient。

   ```
   CredentialService credential = CredentialParser.toCredential("凭据文件路径");
   AGCParameter agcParameter = AGCParameter.builder().setCredential(credential).build();
   AGCClient.initialize(agcParameter);
   ```

2. 调用[AGCFunction.getInstance](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcfunction-java-0000001193153224#section1819089194218)获取[AGCFunction](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcfunction-java-0000001193153224)实例。

   ```
   // 构造云函数对象实例
   AGCFunction function = AGCFunction.getInstance();
   ```

3. 调用[AGCFunction.wrap](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcfunction-java-0000001193153224#section145475292453)设置函数，在方法中传入函数名和版本（或别名）。

   ```
   FunctionCallable callable = function.wrap("function-test", "$latest");
   ```

4. 根据函数类型和函数入参情况，调用相关方法来调用函数。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704121835.76314383422225450671535272133331:50001231000000:2800:EB8E36E0787A39570023D8ABBB635B146484A08FB15FF9F46AF7F6DA56B1A97C.png)  
   * body传参类型支持HashMap、com.alibaba.fastjson.JSONObject、com.huawei.agconnect.server.commons.json.JSONObject。
   * HttpMethod传参类型支持com.huawei.agconnect.server.commons.rest.HttpMethod.GET/POST/PUT/DELETE/HEAD/PATCH/OPTIONS。
   * header传参类型支持Map\<String, String\>, header已预设Authorization鉴权信息和client信息等，支持自定义header数据并覆盖预设header。
   * 调用callHttpOnClient()/callHttpOnCloud()接口时, invokeURL和RestRequest.uri只传入自定义后缀即可，如"/invoke"。

   Java语言的Server SDK提供了两种接口来构造HTTP请求调用函数。
   * [callHttpOnClient()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/functioncallable-java-0000001237953187#section17610222494)接口

     此接口可以在任意环境请求被调函数。任意环境包括公网和云函数运行环境。  
     ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704121835.39508393259770634300005041245610:50001231000000:2800:CF3BF8D0169F369CA5460BA571552C6B26A46DA6667B53BCE35369E708A5EA66.png)  
     * 公网请求被调函数时，需要跨AGC云侧网关。
     * 云函数运行环境请求被调函数时，属于内网调用，不需要跨AGC云侧网关。
     * 云函数运行环境是指实现函数基于Java语言的custom-runtime运行环境。
   * [callHttpOnCloud()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/functioncallable-java-0000001237953187#section296471896)接口

     此接口仅能在云函数运行环境请求被调函数。此接口比callHttpOnClient()接口的请求时延更小。

   具体调用方法如下：
   * 使用callHttpOnClient()接口  
     ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704121835.24233462251054250143791826278783:50001231000000:2800:F2569D16B65BC60C59471B218652FE3C8B1CFE6C51ECE2AE42650054BF3443C1.png)  
     调用callHttpOnClient()系列接口前，需设置被调函数的项目信息，请参考[查询项目信息](#section166404596117)。

     ```
     setClientCredential(String projectId, String clientId, String clientSecret);
     ```

     * 如果无自定义header，则使用[FunctionCallable.callHttpOnClient(HttpMethod method, String invokeURL, T body)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/functioncallable-java-0000001237953187#section17610222494)来调用函数。

       ```
       RestResponse res = callable.callHttpOnClient(HttpMethod.POST, "/invoke", body);
       ```

     * 如果有自定义header，则使用[FunctionCallable.callHttpOnClient(HttpMethod method, String invokeURL, Map\<String, String\> header, T body)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/functioncallable-java-0000001237953187#section45921448205615)来调用函数。

       ```
       RestResponse res = callable.callHttpOnClient(HttpMethod.POST, "/invoke", header, body);
       ```

     * 如果使用封装的[RestRequest](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-server-common-restrequest-0000001424940268)类型，则使用接口[RestResponse callHttpOnClient(RestRequest request)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/functioncallable-java-0000001237953187#section22891236570)来调用函数。

       ```
       RestResponse res = callable.callHttpOnClient(restRequest);
       ```

   <!-- -->

   * 使用callHttpOnCloud()接口
     * 如果无自定义header，则使用[FunctionCallable.callHttpOnCloud(HttpMethod method, String invokeURL, T body)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/functioncallable-java-0000001237953187#section296471896)来调用函数。

       ```
       RestResponse res = callable.callHttpOnCloud(HttpMethod.POST, "/invoke", body);
       ```

     * 如果有自定义header，则使用[FunctionCallable.callHttpOnCloud(HttpMethod method, String invokeURL, Map\<String, String\> header, T body)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/functioncallable-java-0000001237953187#section1474464171020)来调用函数。

       ```
       RestResponse res = callable.callHttpOnCloud(HttpMethod.POST, "/invoke", header, body);
       ```

     * 如果使用封装的[RestRequest](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-server-common-restrequest-0000001424940268)类型，则使用接口[RestResponse callHttpOnCloud(RestRequest request)](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/functioncallable-java-0000001237953187#section14729198131017)来调用函数。

       ```
       RestResponse res = callable.callHttpOnCloud(restRequest);
       ```

5. 如果您需要关注[RestResponse](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-server-common-restresponse-0000001475217149)类型的返回值，可调用如下方法获取：

   ```
   HttpStatus status = res.getHttpStatus(); 
   Map<String, String> header = res.getHeader(); 
   JSONObject body = res.getBody(); 
   String content = res.getContent();
   ```
