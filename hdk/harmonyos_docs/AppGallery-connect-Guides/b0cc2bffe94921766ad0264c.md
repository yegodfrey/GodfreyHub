# 开发网页

在使用网站托管功能前，您需要完成网页开发并将您的网页文件打包成托管包。

对于网页文件有如下要求：

* 文件类型：网页浏览器支持的文件类型。


* 访问入口：托管包根目录下包含的index.html文件作为默认站点首页。


* 托管包格式：托管包必须打包成".zip"文件，且不能增加一层外级目录。
