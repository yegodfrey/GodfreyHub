# 涂鸦画图

## 客户需求

《涂鸦画图》希望解决应用的一些无法找到根因的崩溃问题，降低崩溃率，提升用户体验。

## 华为解决方案

崩溃服务可实时监测应用稳定性，确定崩溃优先级，对崩溃进行智能分类。借助堆栈及其他崩溃发生时关键信息，快速解决崩溃。《涂鸦画图》集成崩溃服务后，在上线新版本的当天，借助崩溃服务及时发现了版本的闪退问题，并根据崩溃服务提供的信息快速修复了问题，修复后应用的崩溃率由1%下降至0.06%，显著提升了应用质量，避免了新版本上线后的大范围舆情风险。
