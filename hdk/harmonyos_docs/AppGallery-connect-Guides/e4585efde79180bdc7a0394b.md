# 应用外支付

## 场景介绍

在AppGallery Connect的中创建的商品，进行了商品营销配置后，可以直接在华为应用市场或游戏中心的应用详情页中展示商品宣传图、商品名称、商品描述，供用户点击购买。
> 注意
>
> 应用外支付功能目前仅支持发布地区包含中国大陆的应用。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251120150807.21690609413787620664345428971674:50001231000000:2800:62FE11F0C5E14AEEA9E2A44EFA90A3353B905AC1F1468028BFEC7A77A4961355.png)

应用外支付分为以下两种方式：

* DeepLink方式：用户点击购买应用市场或游戏中心的商品后跳转到您自己的APP商品地址，该地址可直接拉起您的APP，由APP自行完成后续的支付和发货。
* 商品直购方式：用户点击购买应用市场或游戏中心的商品后直接在华为应用市场或游戏中心完成支付，支付完成后的发货方式分为两种。
  * 兑换码方式：您可以提前在华为AppGallery Connect中配置商品兑换码，用户在华为应用市场/游戏中心点击购买商品后由华为应用市场直接发起支付，支付完成后用户可以在华为应用市场/游戏中心获取兑换码。您可以在您的应用中允许用户使用兑换码兑换对应的商品。
  * 华为通知发货方式：用户点击购买华为应用市场的商品后由华为应用市场发起支付，在支付完成后由华为服务器通知开发者服务器完成商品发货。

DeepLink方式的应用外支付仅需在[配置商品营销](https://developer.huawei.com/consumer/cn/doc/distribution/app/managing-product-marketing-0000001100014696)时配置DeepLink地址，用户点击购买后将直接跳转到该DeepLink地址，后续支付和发货流程与应用内商品支付流程一致，参见[应用内支付开发指南](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/dev-process-0000001050033070)。

兑换码方式仅需参考[配置虚拟商品](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-create-product-0000001099854866#section22140508113)配置商品兑换码，您在您的应用中允许用户使用兑换码兑换对应的商品即可。

华为通知发货的方式需要您开发商品直购和掉单查询功能，本章节将具体介绍此功能的开发。

## 前提条件

已参见[管理商品营销](https://developer.huawei.com/consumer/cn/doc/distribution/app/managing-product-marketing-0000001100014696)配置商品营销信息。

## 商品直购

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251120150807.32439435900963205042708772411313:50001231000000:2800:4A0AD36387DA1B51555B41172C55687386E124654F4E144707D56E99BD14BD1E.png)

**接收发货通知：**

1. 商品直购成功后，华为数字商品服务器会调用[通知发货](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/appgallerykit-notifysendproduct-0000001050121556)接口通知开发者服务器对已经完成购买的商品发货。

   请求消息样例：

   ```screen
   POST {第三方应用服务器url} HTTP/1.1 
   Content Type : application/json ; charset=UTF-8 
   {  
     "data": { 
       "developerId": "234234234", 
       "appId": "1231333", 
       "orderId": "sdfsfff32324324234234", 
       "productNo": "product344", 
       "openId": "openId13123", 
       "count": 1, 
       "ts": 12312313123131123 
     }, 
     "sign": "string" 
   }  
   ```

2. 参见[获取验签公钥](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/get-public-key-0000001050164350)获取用于验证订单信息的公钥。
3. 开发者服务器收到发货通知后，参考[验签示例](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/appgallerykit-notifysendproduct-0000001050121556#section6682105612547)对发货通知消息的sign字段验签，并根据查询订单相关数据的有效性，向华为服务器返回处理结果。

   返回消息样例：

   ```screen
   { 
     "error": { 
       "errorCode": 0, 
       "errorMsg": "string" 
     }  
   }  
   or   
   {  
       "data": { 
       "result": 0 
     } 
   } 
   ```

4. 根据商品ID和当前用户信息完成发货操作，此部分由开发者自行完成。

**发货成功主动通知：**

1. 参考[创建API客户端](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section103mcpsimp)章节创建用于访问华为服务器接口的API客户端。 说明
   >
   > API客户端仅需创建一次。
2. 调用[获取Token](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/appgallerykit_gettoken-0000001050123505)接口获取用于API客户端认证的access_token。
3. 开发者服务器在发货成功后调用[发货成功通知](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/appgallerykit_notifyproductcallback-0000001050123507)接口向华为服务器发送通知，传入access_token。通知成功后华为服务器刷新订单状态。

   请求消息样例：

   ```screen
   {   
      "orderId": "string", 
      "productNo": "string", 
      "openId": "string", 
      "status": 0, 
      "ts": 12312313123131123 
    }
   ```

   响应消息样例：

   ```screen
   { 
      "error": { 
          "errorCode": 0, 
          "errorMsg": "string" 
      }   
   }    
   ```

   or

   ```screen
   {  
     "data": { 
          "result": 0 
      }    
   }
   ```

## 掉单查询

商品直购后通知发货过程可能发生通知发货失败而产生掉单，此时华为服务会将该订单标识为未发货状态。当应用启动时需要主动查询当前华为账号是否有未发货的订单，如果有掉单数据需通知开发者服务器发货。开发者服务器完成发货后通知华为服务器发货成功，华为服务器将订单状态修改为发货状态。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251120150808.83613873296781180298356623523208:50001231000000:2800:E564C7E50C00C9BDC4CC13958E31C59395A57DBBAF1358D82D51567C86DB906A.png "点击放大")

1. 应用启动时主动调用[JosApps.getProductClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/josapps-0000001050123631#section1428924710230)方法初始化[ProductClient](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/productclient-0000001050121684)实例。

   ```screen
   ProductClient productClient =  JosApps.getProductClient(this);
   ```

2. 应用调用[ProductClient.getMissProductOrder](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/productclient-0000001050121684#section12285706358)方法查询未发货的订单。 说明
   >
   > 本步骤仅为建议，您可根据查询结果感知当前设备中是否存在已登录的华为账号，正式的查询将在步骤4中进行。

   HMS Core SDK会根据当前设备中已经登录授权的华为账号查询该账号的掉单数据。如果当前设备中未登录华为账号，则不返回数据。

   ```screen
   Task<List<ProductOrderInfo>> task = productClient.getMissProductOrder(this);
   task.addOnSuccessListener(new OnSuccessListener<List<ProductOrderInfo>>() {
   	@Override
   	public void onSuccess(List<ProductOrderInfo> productOrders) {
   		if (productOrders != null) {
   			for (ProductOrderInfo productOrderInfo : productOrders) {
   				String productNo = productOrderInfo.getProductNo();
   				String tradeId = productOrderInfo.getTradeId();
   				showLog("productNo：" + productNo + ",tradeId：" + tradeId);
   			}
   		} else {
   			showLog("product list is null");
   		}
   	}
   }).addOnFailureListener(new OnFailureListener() {
   	@Override
   	public void onFailure(Exception e) {
   		if (e instanceof ApiException) {
   			ApiException apiException = (ApiException) e;
   			showLog("get miss product info failed:" + apiException.getStatusCode());
   		}
   	}
   });
   ```

3. 引导用户进行华为账号授权登录。 说明
   >
   > 为了更好的用户体验，建议您将华为账号与您自己的账号体系绑定，以便于用户可以同时浏览华为账号和非华为账号购买的订单。
4. 用户的华为账号授权登录后，应用再次调用[ProductClient.getMissProductOrder](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/productclient-0000001050121684#section12285706358)方法确认掉单数据。
5. 应用调用[ProductOrderInfo.getSign](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/productrrderinfo-0000001050121686#section1646175174112)方法获取订单信息中的签名字符串，使用[获取验签公钥](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/get-public-key-0000001050164350)中获取的验签公钥参考[对掉单数据验签](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/missoder-signature-0000001050164352)对订单信息进行验签。
6. 验签通过后，应用客户端通知应用服务端发货。开发者服务器发货完成后向华为服务发送通知，具体参见[发货成功通知](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/appgallerykit_notifyproductcallback-0000001050123507)。
