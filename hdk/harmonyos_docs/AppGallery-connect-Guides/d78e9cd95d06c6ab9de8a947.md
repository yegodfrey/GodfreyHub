# 生成自有账号凭据

开发者在接入认证服务时，除了需要对接非托管第三方账户，还可能需要对接开发者自己的自有账户，自有账户对接AGC认证服务，需要提供自有账号凭据JWT（Json Web Token）。

## 前提条件

向AGC服务端发起REST API请求前，您需要先获得AGC服务端的授权，请参见[获取服务端API授权](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-obtain-apiauthorization-0000001374178549)。

## 开发步骤

1. 参考本地生成公私钥代码，生成公私钥。 注意
   >
   > 公私钥仅需要生成一次保存好即可，无需多次调用。

   其中：
   * 私钥为privateKey，在生成JWT时使用。
   * 公钥为publicKey，需要配置到自有账号页面中，参见[3](#ZH-CN_TOPIC_0000001374846805__li2613259276)。

   ```screen
       /**
        * 生成公私钥接口
        */
       public static void generatePublicAndPrivateKey() {
           try {
               KeyPairGenerator generator = KeyPairGenerator.getInstance("RSA");
               // 私钥长度至少2048位，因此keysize取3072。
               generator.initialize(3072);
               KeyPair keyPair = generator.generateKeyPair();
               String publicKey =
                   new String(Base64.getEncoder().encode(keyPair.getPublic().getEncoded()), StandardCharsets.UTF_8);
               String privateKey =
                   new String(Base64.getEncoder().encode(keyPair.getPrivate().getEncoded()), StandardCharsets.UTF_8);

               System.out.println(publicKey);
               System.out.println("------------------------------------");
               System.out.println(privateKey);
           } catch (NoSuchAlgorithmException e) {
               e.printStackTrace();
           }
       }
   ```

2. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，在项目列表中点击项目，在左侧导航栏选择"云开发（Serverless）> 认证服务"，进入认证服务页面。

   在输入框中配置上一步生成的公钥：

4. 参考示例代码本地生成JWT。

   ```screen
       /**
        * @param uid 用户ID
        * @param displayName 用户昵称
        * @param photoUrl 头像地址
        * @param privateKey 私钥
        * @return JWT Token
        * @throws Exception 异常
        */
       public static String generateJWT(String uid, String displayName, String photoUrl, String privateKey)
           throws Exception {
           Security.addProvider(new BouncyCastleProvider());
           Signature signature = Signature.getInstance("SHA256WithRSA/PSS");
           KeyFactory keyFactory = KeyFactory.getInstance("RSA");
           byte[] keyByte = Base64.getDecoder().decode(privateKey);
           signature.initSign(keyFactory.generatePrivate(new PKCS8EncodedKeySpec(keyByte)));
           AuthHeader authHeader = new AuthHeader("JWT", "RS256");

           /** 3600秒为距离当前时间的jwt token过期时间，一般设置为1个小时即可 */
           long expTime = Instant.now().plusSeconds(3600L).getEpochSecond();
           AuthPayload authPayload = new AuthPayload(uid, displayName, photoUrl, expTime);

           String header = new String(Base64.getUrlEncoder().encode(JSON.toJSONBytes(authHeader)), StandardCharsets.UTF_8);
           String payload =
               new String(Base64.getUrlEncoder().encode(JSON.toJSONBytes(authPayload)), StandardCharsets.UTF_8);

           String content = header + "." + payload;
           signature.update(content.getBytes(StandardCharsets.UTF_8));
           String sign = new String(Base64.getUrlEncoder().encode(signature.sign()), StandardCharsets.UTF_8);
           return new StringBuilder().append(header).append(".").append(payload).append(".").append(sign).toString();
       }

   class AuthHeader {

       private String typ;

       private String alg;

       public AuthHeader(String typ, String alg) {
           this.typ = typ;
           this.alg = alg;
       }

       public String getTyp() {
           return typ;
       }

       public void setTyp(String typ) {
           this.typ = typ;
       }

       public String getAlg() {
           return alg;
       }

       public void setAlg(String alg) {
           this.alg = alg;
       }
   }

   class AuthPayload {

       private String uid;

       private String displayName;

       private String photoUrl;

       private Long exp;

       public AuthPayload(String uid, String displayName, String photoUrl, Long exp) {
           this.uid = uid;
           this.displayName = displayName;
           this.photoUrl = photoUrl;
           this.exp = exp;
       }

       public String getUid() {
           return uid;
       }

       public void setUid(String uid) {
           this.uid = uid;
       }

       public String getDisplayName() {
           return displayName;
       }

       public void setDisplayName(String displayName) {
           this.displayName = displayName;
       }

       public String getPhotoUrl() {
           return photoUrl;
       }

       public void setPhotoUrl(String photoUrl) {
           this.photoUrl = photoUrl;
       }

       public long getExp() {
           return exp;
       }

       public void setExp(long exp) {
           this.exp = exp;
       }
   }
   ```

5. 生成JWT后，传递给应用客户端对接AGC认证服务。
