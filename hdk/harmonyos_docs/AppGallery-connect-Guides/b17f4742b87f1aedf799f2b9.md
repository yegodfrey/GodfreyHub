# 初始化

通过游戏内嵌社区SDK初始化，完成开发者认证和游戏玩家的华为账号认证。

## 前提条件

* 您已有[实名认证的开发者账号](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/pgsmoment-agc-config-0000001291569413#section11259184161115)。
* 您已在AGC控制台[创建项目和应用](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/pgsmoment-agc-config-0000001291569413#section47741241506)。
* 您已[获取Client ID、Client Secret、APP ID](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/pgsmoment-agc-config-0000001291569413#section15823182245618)。
* 您已在AGC控制台[开通游戏社区版块](https://developer.huawei.com/consumer/cn/doc/distribution/app/game-center-community-operation-0000001194305462#section13925163952513)，并开通当前游戏的社区版块。
* 您已在AGC控制台[开通游戏内嵌社区服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/pgsmoment-agc-config-0000001291569413#section14935142895611)。
* 您已[集成游戏内嵌社区SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/pgsmoment-intergratesdk-0000001291610961)。
* 您已参考[游戏登录](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/game-login-0000001050121526)完成华为账号接入。

> 注意
>
> * 请在游戏中接入[游戏登录](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/game-login-0000001050121526)功能。若您想控制未成年人的访问，或玩家想在社区发布动态时，均需要登录华为账号，未登录华为账号的玩家仅能浏览社区内容。
> * 请务必初始化[游戏SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/game-start-0000001050123475#section632385111619)成功后，再初始化游戏内嵌社区[PgsMoment.init](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gdpsdk-api-pgsmoment-0000001403658572#section679123017197)。

## 开发步骤

构建请求参数[MomentInitParam](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gdpsdk-api-momentinitparam-0000001335812814#section78412037980)，调用[PgsMoment.init](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gdpsdk-api-pgsmoment-0000001403658572#section679123017197)初始化游戏内嵌社区。 说明
>
> * orientation为打开内嵌社区的方向：
>   * ActivityInfo.SCREEN_ORIENTATION_PORTRAIT：竖屏打开内嵌社区。
>   * ActivityInfo.SCREEN_ORIENTATION_LANDSCAPE：横屏打开内嵌社区。
> * clientSecret和cpAccessToken二者传其一即可：
>   * 若仅传clientSecret，SDK会根据传入的参数获取cpAccessToken用于授权。
>   * 基于安全考虑，若不想暴露clientSecret，且您有自己的游戏服务器，推荐由您的游戏服务器获取cpAccessToken后进行传参，获取cpAccessToken请参见[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/pgsmoment-get-token-0000001594965737)。
>   * 若同时传入clientSecret和cpAccessToken，将使用传入的cpAccessToken作为最终AGC接入凭证。

```screen
// 应用APP ID
String appId = "106***225"; 
// 游戏应用在AGC项目中的客户端ID
String clientId = "9149**********7424";
// 游戏应用在AGC项目中的客户端密钥
String clientSecret = "ABEE*******************************D6A6"; 
// 开发者AGC认证凭证
// String cpAccessToken = "eyJh***************************************************hyhA"; 
// 内嵌社区的打开方向，此处以竖屏方向为例
int orientation = ActivityInfo.SCREEN_ORIENTATION_PORTRAIT;
// clientSecret和cpAccessToken二者传其一即可，此处以仅传入clientSecret为例
PgsMoment.init(new MomentInitParam(MainActivity.this, appId, clientId, clientSecret, null, orientation),
	new PgsInitCallback() {
		@Override
		public void onSuccess(Response rsp) {
			// 初始化成功
		}
		@Override
		public void onFailure(Response rsp) {
			// 初始化失败
			Log.e(TAG, "RtnCode: " + rsp.getRtnCode() + "; Msg: " + rsp.getMsg());
		}
	});
```
