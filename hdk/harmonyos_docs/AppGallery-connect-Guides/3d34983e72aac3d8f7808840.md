# 集成SDK

## 在Android Studio中集成（Version Catalog方式管理依赖）

> 说明
>
> 自1.9.3.302版本开始支持使用Version Catalog方式管理依赖，且仅Android Gradle 7.0及以上版本支持使用。

### 添加配置文件

为了简化配置步骤，AGC为您提供了保存应用配置信息的配置文件。您只需要将配置文件添加到您的工程目录并集成AGC插件，AGC插件可以自动将您在AGC上的应用信息加载到您的开发环境。

1. [获取agconnect-services.json文件](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-applinking-obtain-files-0000001318168764#section16672113549)。
2. 将"agconnect-services.json"文件拷贝到Android Studio项目的应用级根目录下。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a/v3/Y6iyGiAqQkabGJFYfLfbIA/zh-cn_image_0000001321363920.gif?HW-CC-KV=V1&HW-CC-Date=20261008T174832Z&HW-CC-Expire=31536000000&HW-CC-Sign=D729BB65D67FDE9D54618E4EC55701D40D2C7E8C1F715095E48B0A862A095A30)

### 声明AGC插件和SDK

1. 打开Android Studio项目级gradle目录下的"libs.versions.toml"文件，声明AGC插件和SDK。
   1. 在[versions]中声明AGC插件版本号和SDK版本号。

      ```screen
      [versions]
      agcVersion = "1.9.6.300"
      ```

   2. 在[plugins]中声明AGC插件的id。

      ```screen
      [plugins]
      agcp = {id = "com.huawei.agconnect.agcp", version.ref = "agcVersion"}
      ```

   3. 在[libraries]中声明聚合链接SDK。

      ```screen
      [libraries]
      agconnect-applinking = {module = "com.huawei.agconnect:agconnect-applinking", version.ref = "agcVersion"}
      ```

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e8/v3/uRJEWDVBTxODzUfzri0bKQ/zh-cn_image_0000002412119110.png?HW-CC-KV=V1&HW-CC-Date=20261008T174832Z&HW-CC-Expire=31536000000&HW-CC-Sign=38137EB55842287F27EA27688C51C92373A17C294B7166A397C630F1D1FD029F)
2. 在项目级的"build.gradle"文件中，设置AGC插件依赖。

   ```screen
   plugins {
       alias(libs.plugins.android.application) apply false
       alias(libs.plugins.kotlin.android) apply false
       alias(libs.plugins.kotlin.compose) apply false
       alias(libs.plugins.agcp) apply false
   }
   ```

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b/v3/12mVsihxQ8eaGhEeDyrmZA/zh-cn_image_0000002430601405.png?HW-CC-KV=V1&HW-CC-Date=20261008T174832Z&HW-CC-Expire=31536000000&HW-CC-Sign=67268665399D5300AA8451CD40E1043A5DC8B4EA9DAD034511F25A74EFAD41BD)
3. 打开项目级"settings.gradle"文件，配置Maven仓地址。

   ```screen
   pluginManagement {
     repositories {
       google {
         content {
           includeGroupByRegex("com\\.android.*")
           includeGroupByRegex("com\\.google.*")
           includeGroupByRegex("androidx.*")
         }
       }
       mavenCentral()
       gradlePluginPortal()
       maven { url 'https://developer.huawei.com/repo/' }
     }
   }
   dependencyResolutionManagement {
     repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
     repositories {
       google()
       mavenCentral()
       maven { url 'https://developer.huawei.com/repo/' }
     }
   }
   ```

### （可选）配置剪切板读取规则

集成了聚合链接SDK的应用在首次启动时，聚合链接SDK会读取剪切板内容来获取链接信息，用于到达应用内指定的内容。如果您希望修改聚合链接SDK读取剪切板的行为，可以参考本步骤。 注意
>
> 如果关闭读取剪切板功能，会影响延迟深度链接功能的使用，即用户在通过应用市场（华为应用市场除外）安装应用后，首次打开时无法跳转到原深度链接指定的地址。

在AndroidManifest.xml的Application节点下增加如下配置：

```screen
<meta-data
    android:name="com.huawei.agconnect.applinking.READ_CLIPBOARD_PERMISSION"
    android:value="xxxx"/>
```

* 当value为Available时，聚合链接SDK在应用每次启动时都会读取剪切板。
* 当value为Unavailable或者不配置metadata时，聚合链接SDK始终都不读取剪切板。

## （可选）适配R8优化资源收缩器

AGP 9.0默认将 `android.r8.optimizedResourceShrinking` 标志设置为true，详情请参考[Android官方文档](https://developer.android.com/topic/performance/app-optimization/enable-app-optimization#keep-resources)。

AGC插件会读取agconnect-services.json文件，并为应用程序生成以agc_*为前缀的字符串资源，这些资源放在APK的resources.arsc文件中。 应用会在运行时动态访问这些资源。R8优化资源收缩器可能会将这些未在代码中直接（静态）引用的动态字符串资源视为不必要的资源并将其删除。因此，应用可能将以agc_*为前缀的字符串资源删除，从而导致应用功能异常或者崩溃。

为解决上述问题，请在项目资源（例如res/raw/my.package.keep.xml）中创建XML keep文件，详情请参考[自定义要保留的资源](https://developer.android.google.cn/topic/performance/app-optimization/customize-which-resources-to-keep)。

例如：

```screen
<?xml version="1.0" encoding="utf-8"?>
<resources xmlns:tools="http://schemas.android.com/tools"
tools:keep="@string/agc_*" /
```

   3. 打开您的工程AndroidManifest.xml文件，在"application"模块中添加MyApplication类声明。如果已经声明，则跳过此步骤。

      ```screen
      <application
          <!--添加声明开始 -->
          android:name=".MyApplication">
          <!--添加声明结束 -->
      </application>
      ```

   4. 在Eclipse的菜单栏中点击"Project"，执行"clean"操作。
7. （可选）配置剪切板读取规则。

   集成了聚合链接SDK的应用在首次启动时，聚合链接SDK会读取剪切板内容来获取链接信息，用于到达应用内指定的内容。如果您希望修改聚合链接SDK读取剪切板的行为，可以参考本步骤。 注意
   >
   > 如果关闭读取剪切板功能，会影响延迟深度链接功能的使用，即用户在通过应用市场（华为应用市场除外）安装应用后，首次打开时无法跳转到原深度链接指定的地址。

   在AndroidManifest.xml的Application节点下增加如下配置：

   ```screen
   <meta-data
       android:name="com.huawei.agconnect.applinking.READ_CLIPBOARD_PERMISSION"
       android:value="xxxx"/>
   ```

   * 当value为Available时，聚合链接SDK在应用每次启动时都会读取剪切板。
   * 当value为Unavailable或者不配置metadata时，聚合链接SDK始终都不读取剪切板。

## （可选）将密钥信息传递给AGC

### 通过配置文件参数传递密钥

AGC SDK提供了[AGConnectOptionsBuilder](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-agconnectoptionsbulider-0000001116227891)类来对agconnect-services.json文件中的参数进行配置，如果您在下载配置文件时选择了"不包含密钥"，则agconnect-services.json文件中将不包含client_id、client_secret和api_key参数，您必须通过[AGConnectOptionsBuilder](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-agconnectoptionsbulider-0000001116227891)类的接口在应用启动时将参数设置给AGC SDK。

建议您在Application或者第一个启动的Activity的onCreate方法中完成client_id、client_secret和api_key等参数的设置。

```screen
//添加如下代码
try {
	AGConnectOptionsBuilder builder = new AGConnectOptionsBuilder();
	InputStream in = getAssets().open("agconnect-services.json");    //如果使用了AGC插件，删除此行
	builder.setInputStream(in);                                      //如果使用了AGC插件，删除此行
	builder.setClientId("client_id");
	builder.setClientSecret("client_secret");
	builder.setApiKey("api_key");
	builder.setCPId("cp_id");
	builder.setProductId("product_id");
	builder.setAppId("app_id");
	AGConnectInstance.initialize(this, builder);
} catch (IOException e) {
	e.printStackTrace();
}
//TODO: 添加代码结束
```

### 通过Token传递密钥

如果您认为client_id和client_secret放在json文件里不安全，我们建议您将client_id和client_secret放在自己的服务端。先调用https://connect-drcn.dbankcloud.cn/agc/apigw/oauth2/v1/token接口去换取Token，然后在初始化AGC SDK时通过[setCustomCredentialsProvider](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agccore-agconnectoptionsbulider-0000001116227891#section9602114520710)将Token传给AGC去使用。

Token接口请求示例：

```screen
POST /agc/apigw/oauth2/v1/token
Host: connect-drcn.dbankcloud.cn
Content-Type: application/json
{
   "grant_type":"client_credentials",
   "client_id":"agc应用页面提供的client_id",
   "client_secret":"agc应用页面提供的client_secret",
   "useJwt":1
}
```

Token接口响应示例：

```screen
HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8
{
    "access_token": "eyJhbGciOiJIUzU****************",
    "expires_in": 0
}
```

setCustomCredentialsProvider接口调用示例：

```screen
"Java"
String tokenStr = "access_token";
long expiration = expires_in;

CustomCredentialsProvider developerClientToken = new CustomCredentialsProvider() {
    @Override
    public Task<Token> getTokens(boolean forceRefresh) {
        TaskCompletionSource<Token> source = new TaskCompletionSource<>();
        Token token;
            token = new Token() {
                @Override
                public long getExpiration() {
                    return expiration;
                }

                @Override
                public long getIssuedAt() {
                    return 0;
                }

                @Override
                public long getNotBefore() {
                    return 0;
                }

                @Override
                public String getTokenString() {
                    return tokenStr;
                }
            };
        source.setResult(token);
        return source.getTask();
    }
};

AGConnectOptionsBuilder builder = new AGConnectOptionsBuilder();
builder.setCustomCredentialsProvider(developerClientToken);
AGConnectInstance.initialize(getApplicationContext(),builder);
```

## 配置混淆脚本

开发者编译APK前需要配置不要混淆AppGallery Connect，避免功能异常。

1. 打开混淆配置文件。
2. 加入排除AppGallery Connect的混淆配置。
   * Android Studio开发环境
     * 如果是Proguard混淆，配置如下：

       ```screen
       -ignorewarnings
       -keep class com.huawei.agconnect.**{*;}
       ```

     * 如果是Dexguard混淆，配置如下：

       ```screen
       -ignorewarnings
       -keep class com.huawei.agconnect.** {*;} 
       -keepresourcexmlelements ** 
       -keepresources */*
       ```

   * Eclipse开发环境

     在proguard-project.txt文件中加入混淆配置。

     ```screen
     -keep class com.huawei.agconnect.remoteconfig.*{*;}
     -keepclassmembers class **{
         public <init>(android.content.Context,com.huawei.agconnect.AGConnectInstance);
     }
     -keepclassmembers class com.huawei.agconnect.remoteconfig.internal.server.**{*;}
     -keep class * implements android.os.Parcelable {
         public static final android.os.Parcelable$Creator *;
     }
     ```
