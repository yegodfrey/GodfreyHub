# 错误码

|错误描述|错误码|说明|
|:---------------------|:---|:-----------------------------------|
|success|0|返回成功。|
|parameter is invalid|1001|参数校验失败。|
|invalid media pkg name|1002|根据入参mediaPkgName查询媒体失败。|
|invalid media status|1003|根据入参mediaPkgName查询的媒体状态错误。|
|invalid developer id|1004|根据入参devId查询ADX失败或者ADX状态错误。|
|invalid slot id|1005|根据SlotId查询展示位失败。|
|invalid slot status|1006|根据SlotId查询的展示位状态错误。|
|invalid scene id|1007|根据场景ID查询场景失败或者根据SlotId查询的展示位不包含场景ID。|
|invalid scene status|1008|根据场景ID查询的场景状态错误。|
|data list is empty|1009|查询到的广告列表为空。|
|inner error|1100|内部错误。|
