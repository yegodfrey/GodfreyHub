# 使用REST API人工送检

除自动送检方式外，游戏多媒体服务提供了使用REST API人工送检的方式，支持手动批量上传实时信令文本消息进行内容检测。  

#### 前提条件

* [下载csv文档模板](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-riskcontrol-agc-0000001625726597#ZH-CN_TOPIC_0000001625726597__li393713505914)，并按照模板填写相关内容后保存。
* 当前仅支持API客户端方式访问，在访问前需获取服务端授权，包括[创建API客户端](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/creating-api-client-0000001738812141)和[获取认证Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-obtaintoken-restapi-0000001624528617)。
