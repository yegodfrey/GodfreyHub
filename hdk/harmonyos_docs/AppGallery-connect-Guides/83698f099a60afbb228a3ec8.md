# 创建云函数

1. 右击"cloudfunctions"目录，选择"New \> Cloud Function"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250305155928.65488757709717364048550789025338:50001231000000:2800:8651BDE458286507A1C921B844B910C0929D17383AA189C577934C9466AAF201.png?needInitFileName=true?needInitFileName=true)

2. 在"Select the Cloud Function Type"栏选择"Cloud Function"，输入云函数名称（如"my-cloud-function"），点击"OK"。 函数名称长度2-63个字符，仅支持小写英文字母、数字、中划线（-），首字符必须为小写字母，结尾不能为中划线（-）。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250305155928.05727491460317686351918566993461:50001231000000:2800:AC375A2BE38C17E2211526F8EF52F0DD55C51CB9FE1DAEAC92445942B0DAFDB3.png?needInitFileName=true?needInitFileName=true)  
   本文以创建"Cloud Function"云函数为例，您也可以选择创建"Cloud Object"云对象访问云数据库。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250305155928.35210579834971396583280298997215:50001231000000:2800:A26056A5A0A29BA5013C00C4D628EB18613E9CFC9BCD70A3F220B7AB08858CA7.png?needInitFileName=true?needInitFileName=true)

   "cloudfunctions"目录下生成新建的"my-cloud-function"函数目录，目录下主要包含如下文件：
   * 函数配置文件"function-config.json"
   * 函数入口文件"myCloudFunction.ts"
   * 依赖配置文件"package.json"
