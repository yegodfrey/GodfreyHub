# AAB包测试指导

#### 背景介绍

华为应用市场目前支持对App Bundle应用（AAB包）进行分发，但是在Android 7.0以上的华为设备上会自动分发apks splits包，应用在安装和使用过程中可以动态加载相应模块。而在非华为设备和Android 7.0及以下的华为设备上华为应用市场会直接分发包含所有模块的全量包（universal包）。因此您在上传AAB包前，需要保证apks splits包和universal包功能都要正常，否则会导致应用安装失败或者安装后功能使用异常。

本文档指导您如何将AAB包编译成apks splits包和universal包，并验证包是否可用。  

#### AAB包要求

* 在Android 7.0以上的华为设备上分发应用：如您希望应用上架后支持按需下载，您必须集成华为[Dynamic Ability](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-dynamicability-introduction-0000001057944549)。若无需支持，请将应用模块调整为安装时下载，调整方法如下：
  * 如AndroidManifest.xml文件中存在onDemand属性，请将所有模块的AndroidManifest.xml文件中onDemand属性设置为false。

    ```
    <dist:module
         ...
         dist:onDemand="false"
         ...
         <dist:fusing dist:include="true" />
     </dist:module>
    ```

  <!-- -->

  * 如AndroidManifest.xml文件中存在on-demand元素，请将所有模块的AndroidManifest.xml文件中"on-demand"改为"install-time"。 修改前：

    ```
    <dist:module
         …
         <dist:delivery>
             <dist:on-demand />
         </dist:delivery>
         <dist:fusing dist:include="true" />
     </dist:module>
    ```

    修改后：

    ```
    <dist:module
         …
         <dist:delivery>
             <dist:install-time />
         </dist:delivery>
         <dist:fusing dist:include="true" />
     </dist:module>
    ```

* 在非华为设备和Android 7.0及以下的华为设备上分发应用：您必须将AAB包编译的universal.apk设置为包含所有模块，即：将所有模块的AndroidManifest.xml文件中fusing属性设置为true。

  ```
  <dist:module
       …
       dist:onDemand="false"
       …
       <dist:fusing dist:include="true" />
   </dist:module>
  ```

#### 环境准备

* 准备一台测试用的PC。
* 准备测试用的Android 7.0以上的华为设备。
* 准备测试用的Android 7.0及以下的华为设备或非华为设备。
* 准备应用的AAB包。
* 准备bundletool工具。  

#### 测试apks splits包

1. 将您的AAB包和bundletool工具保存到您PC的本地目录中，如D:\\bundle。
2. 运行cmd命令打开命令行窗口，进入AAB包和bundletool工具所在目录，执行如下命令。

   ```
   java -jar bundletool-all-0.14.0.jar build-apks --bundle=app-release.aab --output=app.apks --ks=keystore.jks --ks-key-alias=keystore
   ```

   其中：
   * bundletool-all-0.14.0.jar：bundletool工具包名称，建议使用0.14.0版本。
   * app-release.aab：待转换的原始aab文件名称，请根据实际情况替换。
   * app.apks：包含转换后的全量apk集合的apks文件。
   * keystore.jks：密钥库文件。
   * keystore：签名密钥别名。
3. 命令执行后，依次输入密钥库的密码和签名密钥的密码。

   ```
   D:\bundle>java -jar bundletool-all-0.14.0.jar build-apks --bundle=app-release.aab --output=app.apks --ks=keystore.jks --ks-key-alias=keystore
   Enter keystore password:
   Enter password for key 'keystore':
   ```

   执行成功后，在D:\\bundle目录中将会生成对应的apks文件。
4. 使用Android 7.0以上华为设备以adb方式连接到PC，在命令行窗口中执行adb devices命令查看设备状态，如下信息表示连接成功。

   ```
   D:\bundle>adb devices
   List of devices attached
   E5*******464        device
   ```

5. 在命令行窗口执行如下命令，自动为设备安装适配软件包。

   ```
   java -jar bundletool-all-0.14.0.jar install-apks --apks=app.apks
   ```

   如下提示信息表示安装成功。

   ```
   D:\bundle>java -jar bundletool-all-0.14.0.jar install-apks --apks=app.apks
   09:45:57 E/adb: adb server version (31) doesn't match this client (41); killing...
   09:45:57 E/adb: * daemon started successfully
   The APKs have been extracted in the directory: C:\Users\S00347~1\AppData\Local\Temp\5617006465519859598
   ```

测试设备上成功安装应用后，功能验证无问题，表示AAB包生成的apks splits包功能正常。

#### 测试universal包

1. 将您的AAB包和bundletool工具保存到您PC的本地目录中，如D:\\bundle。
2. 运行cmd命令打开命令行窗口，进入AAB包和bundletool工具所在目录，执行如下命令。

   ```
   java -jar bundletool-all-0.14.0.jar build-apks --bundle=app-release.aab --output=app-un.apks  --ks=keystore.jks --ks-key-alias=keystore --mode=universal
   ```

   其中：
   * bundletool-all-0.14.0.jar ：bundletool工具包名称，建议使用0.14.0版本。
   * app-release.aab：待转换的原始aab文件名称，请根据实际情况替换。
   * app-un.apks：包含转换后的universal包的apks文件。
   * keystore.jks：密钥库文件。
   * keystore：签名密钥别名。
3. 命令执行后，依次输入密钥库的密码和签名密钥的密码。

   ```
   D:\bundle>java -jar bundletool-all-0.14.0.jar build-apks --bundle=app-release.aab --output=app-un.apks  --ks=keystore.jks --ks-key-alias=keystore --mode=universal
   Enter keystore password:
   Enter password for key 'keystore':
   ```

   执行成功后，在D:\\bundle目录中将会生成对应的apks文件。
4. 将生成的app-un.apks文件的后缀修改为zip，解压后获取universal.apk文件。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250716091206.22913510645279524051014807764618:50001231000000:2800:A2B7C2F87E6935440A32AE3C75F12B8A6CA8CE6095EA76643CDACCA18A4F05E7.png "点击放大")

5. 使用Android 7.0及以下华为设备或非华为设备以adb方式连接到PC，在命令行窗口中执行如下命令安装universal.apk包。

   ```
   adb install universal.apk
   ```

   如下提示信息表示安装成功。

   ```
   D:\bundle>adb install universal.apk
   2687 KB/s (20011496 bytes in 7.271s)
   Success
   ```

6. 测试设备上成功安装应用后，功能验证无问题，表示AAB包编译的universal包功能正常。  

#### 发布App Bundle应用

以上测试完成后，可以提交AAB包至AGC进行发布，具体请参见[App Bundle应用上架操作指导](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-releasebundle-0000001100316672)。
