# 历史版本管理

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到需要查看历史版本的项目。
3. 在左侧导航栏选择"增长 > 远程配置"，点击"查看历史版本"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1f/v3/rKtqno4CSCepIxYOdNydsw/zh-cn_image_0000002564473433.png?HW-CC-KV=V1&HW-CC-Date=20260916T021030Z&HW-CC-Expire=31536000000&HW-CC-Sign=3086689651EC3E02A8B3D139B12DB234D4006DA477C3EC7DEBA09C5B1FC56466)

4. 选择对应版本，并点击"回退至该版本"，可将配置回退至指定的历史版本。此回退操作实际上会创建一个使用新版本号的版本覆盖上一个版本。 说明
   >
   > 支持最多90天300个历史版本管理。
