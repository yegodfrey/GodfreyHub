# 准备游戏信息

1. 在项目列表中选择您的项目，进入"项目设置" 的"常规"页签。
2. 记录项目下的"Client ID"、"Client Secret"和"API密钥（凭据）"，以及应用下的"APP ID"信息。 说明
   >
   > "Client ID"、"Client Secret"、"API密钥（凭据）"和"APP ID"信息主要用于SDK接入校验，具体请参见[初始化SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/game-highlight-initializing-0000001638256878)。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251103151803.92664828096741004525495224194520:50001231000000:2800:AE1DEF99980D4841B3DAE4BB011DC03B6A8D44C10605FD9A45AE2FBCE18344A6.png)

   |参数|说明|
   |:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |Client ID|客户端ID，集成项目级SDK鉴权时的唯一标识。|
   |Client Secret|集成项目级SDK鉴权时的客户端密钥。|
   |API密钥（凭据）|API密钥，仅实现[使用模板导出视频](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/game-highlight-exportvideo-0000001686457641)与[分享视频](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/game-highlight-applyshare-0000001720517613)功能时初始化SDK需要。|
   |APP ID|应用ID。|
