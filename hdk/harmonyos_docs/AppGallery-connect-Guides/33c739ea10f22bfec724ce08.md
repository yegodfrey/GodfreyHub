# 查看已安装的特性列表

开发者可以调用[FeatureInstallManager.getAllInstalledModules](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/featureinstallmanager-0000001057944555#section729592217235)，获得当前应用中已经安装的动态特性列表。

```
/**
 * 获取已安装的feature列表
 */
private void getInstalledFeature() {
    Set<String> moduleNames = mFeatureInstallManager.getAllInstalledModules();
    Log.i(TAG, "get all installed modules : " + moduleNames);
}
```
