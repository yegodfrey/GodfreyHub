# CPU trace

## Android游戏、HarmonyOS 3.1/4.0及以下游戏

Android游戏还包括快游戏、微信小游戏。CPU trace展示CPU调度、频点、进程线程时间片、绘帧等数据的性能功耗，展示方式为泳道图，支持图形用户界面GUI操作、分析数据。

### CPU工作状态

CPU的工作状态主要有"0"、"1"、"2"、"3"。"0"表示"工作中"；"1"、"2"、"3"表示"不在工作状态"，且数值越大代表CPU睡眠程度越深，功耗也越低。

* 查看任一核心CPU的idle状态信息。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110241.80039156654967670179130926771984:50001231000000:2800:FC00E177505B6F3B2DE0B43C7B12AACAC8FF8861E5FB7100BE53EE0456EFC22D.png)

### Hiperf数据

Hiperf性能数据体现了进程的函数调用情况，在测试过程中测试工具会每隔一段时间去访问CPU的运行栈。您可以框选查看Hiperf数据。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110241.73575126084166463952890900200234:50001231000000:2800:D8DCF8C8B964C457117828B54CA48DAF785FD7CF84C27A79083BCFE77DD212A1.png)

您也可以切换到火焰图进行可视化观察。观察调用函数的运行时长，若函数的实际运行时长偏离预估时长，建议优化。
