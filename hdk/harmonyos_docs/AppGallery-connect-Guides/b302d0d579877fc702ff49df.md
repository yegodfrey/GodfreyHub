# 业务介绍

PetalUI是一套与HarmonyOS系统组件视觉体验一致的UI组件库。华为内部在开发华为音乐、华为视频等HarmonyOS应用的时候，有自用的UI组件库，现计划陆续开放经过内部验证好用的UI组件放入PetalUI组件库中，助力开发者高效构建更高质量的应用。

<br />

PetalUI的主要优势如下：

* 响应式布局。开发者可以根据屏幕宽度的不同呈现出不同的布局样式。
* 轻量化，更灵活。开发者可以根据业务需要灵活集成，软件包体积小。

<br />

目前支持的UI组件如下：

* [CalendarPicker](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/petalui-calendarpicker-0000001894295305)
* [Category](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/petalui-category-0000001848174966)
