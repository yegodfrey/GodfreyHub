# 关联模板与落地页

"模板"是一种可编辑的视频文件，使用模板可以帮助您一键合成精彩视频。如需使用游戏高光时刻的分享功能，则必须将模板关联分享落地页。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，并在项目下的应用列表中选择您的游戏应用。

3. 在左侧导航栏中选择"构建 \> 高光时刻"，进入高光时刻服务页面。

4. 在"我的模板"页签下，点击右上角"同步模板"，可一键同步[视频编辑服务](https://developer.huawei.com/consumer/cn/doc/Media-Guides/operations-guide-0000001201961634)中已预置的视频模板或者是您新配置的视频模板。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260116101403.28445230979795753561694167662930:50001231000000:2800:9BF5D79F38D6FED8FBDF54F020BA246691AC273BB5EC95EC4522F3BE06C6C162.png)
5. 点击模板"操作"列"编辑"，设置模板"生效状态"（默认关闭）以及关联的"分享落地页"，设置完成后点击"提交"即可。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260116101403.16265809933966040257736643763049:50001231000000:2800:EF185F2C6FF11F9F6BB338CCDFCEFF3CAD83132F18B17458CCE4E7A792D39E45.png)  
"关闭"状态下的模板将无法关联分享落地页，且模板仅支持关联审核状态为"发布成功"的落地页。
