# 版本管理

#### 功能概述

AGC云函数支持版本管理功能，帮助您更高效地管理函数。开发者可通过发布多个版本完成函数的迭代开发，以维护版本的形式来完成函数的更新与回退，提高运维的效率。发布版本（即除$latest以外的版本）的函数，其配置不可修改，比较稳定，更适合用于实际业务，建议开发者使用发布版本应用于业务。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260302154856.88933144222231087186188963548099:50001231000000:2800:EFEC5B2459168D399A4FE72ADEA51096BCDD361295DF51C357D21D660FD7A685.png)  
* 首次创建函数完成时，版本默认为"$latest"，开发者可在函数的$latest版本上多次修改函数配置与代码实现。
* 开发者可以基于$latest版本发布函数，发布的函数版本，从1开始递增。
* 不可重复发布配置与代码完全一致的版本。

<!-- -->

* 发布版本（即除$latest以外的版本）的函数，不支持修改配置与代码实现，只支持查看。

具体使用场景举例如下：

1. 开发者首次创建云函数func:$latest，通过发布版本得到云函数func:1，使用func:1开始提供服务。
2. 在func:1提供服务的同时，开发者可对云函数func:$latest进行修改与测试，扩充和修改func:$latest原有的功能。
3. 发布func的新版本func:2。
4. 服务使用的func从版本1切换为版本2，完成业务功能的更新升级。
5. 若发现func新版本存在问题，则可回退func的版本，保证业务的持续稳定。修复新版本后可再切换回新版本。

#### 发布版本

函数发布的具体操作如下：

1. 在函数列表中点击函数名称，进入函数详情页面，选择"版本"页签。或者在函数列表中直接点击函数名称右侧"操作"列的"版本"。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260302154856.40453285539776432054454961925097:50001231000000:2800:84824984A7521FBF78C96BDACC637862D277831CE4DDB2D9BCE8F3AEE08D7FB4.png)  
   发布版本前请确认$latest版本已修改并保存，已经发布过的$latest版本不允许再次发布。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260302154856.59419990441661141182534429040177:50001231000000:2800:62429E239CFB93F61C7390A136CD483162E813267FA381920687869BD0B2001F.png)
2. 在版本页面，点击"发布版本"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260302154856.58763170126544746486777859977928:50001231000000:2800:A45F8E727A235C147BF7F61140867CF145C71EFF15F70C25D8DC6097E5F5ECAD.png)

#### 删除版本

在函数详情页面，选择"版本"页签，文本框中输入需要删除的发布版本或者版本描述，点击右侧的"删除"，在弹出的提示框中点击"确认"即可删除该发布版本。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260302154856.46517894273321543303361486421109:50001231000000:2800:EE595777CF79776875462080E9F352D9D2FCA18932D9D32BEF76916B69347C73.png)  
如果该发布版本存在别名引用，则无法删除。请先删除引用的别名，再删除版本。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260302154856.93906303376003220962328537713954:50001231000000:2800:ED324FA662F4AD9347AA56BD1534D3443B2F95D9DFD02ED0362EB6308DB23F5D.png)  

#### 删除函数

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260302154856.40121676204159488113212608270368:50001231000000:2800:5A14265857D116D7A6EF7451BB6E19715495FED3C61ACA1003DC04EB4E2FC762.png)  
删除函数会将函数的所有版本、别名数据删除，函数删除后数据不可恢复，请您谨慎操作。

在函数主界面，文本框中输入函数名称，点击右侧"操作"列的"删除"，并在弹出的提示框中点击"确定"即可删除函数。
