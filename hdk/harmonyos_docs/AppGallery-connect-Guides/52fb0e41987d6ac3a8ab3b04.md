# 技术支持

您集成联运服务遇到问题时，可以按照以下顺序需求帮助。

1. 查看[FAQ](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/appgallerykit-update-faq-0000001054802923)、[问题处理案例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/problem-case-0000001582071096)和[错误码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/appgallerykit-game-errorcode-0000001146768292)。
2. 通过[智能客服](https://developer.huawei.com/consumer/cn/customerService/#/bot-dev-top/faq-top/faq-talk-top)查找问题解决方案。
3. 登录[Stack Overflow社区](https://stackoverflow.com/questions/tagged/appgallery-connect)和[华为开发者论坛](https://developer.huawei.com/consumer/cn/forum/block/ag-connect)参与问题讨论。
4. 如果以上方法仍未解决您的问题，可以通过[在线工单系统](https://developer.huawei.com/consumer/cn/support/feedback/#/add/13?level2=2022000020&level3=101569141517913746&keyWord=游戏服务)与我们进行联系，提交后的工单可在开发者联盟"管理中心"的"开发者中心 > 我的客服"页面查看工单处理进展。
