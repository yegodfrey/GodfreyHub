# 调测应用内消息

由于应用内消息只在应用正式上架后的正式用户终端设备上展示。为了方便开发者快速接入，应用内消息提供了在应用测试阶段调测消息的方法。  

#### 前提条件

* 已[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-appmessaging-integratesdk-ios-0000001071772755)。
* 已[添加应用内消息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-appmessage-create-ios-0000001071924650)。  

#### 调试消息

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155408.89325776711047641724167543783639:50001231000000:2800:FB23FF929C3EF3A0284B9EAEF6BB2F374E58E2500D540CEBF7C9647D0B96C218.png)  
分配了"管理员"、"APP管理员"、"运营"或"开发"角色的账号才可以调测应用内消息。

1. 获取测试设备的AAID（Anonymous Application Identifier），详见"[获取AAID](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/aaid-0000001051142988)"。
2. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
3. 在项目列表中点击您需要调试应用内消息的项目。
4. 点击"增长 \> 应用内消息"，找到需要调试的消息，点击"操作"列的"调测"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155408.29008257257557281070032144105835:50001231000000:2800:B7A3E7066838FC99B5D5E4DCC6BEDA420EA791693FC4E11716C657CFC915E33D.png)

5. 点击"应用内消息调测"界面上的"新增测试用户"，输入测试设备的AAID，点击"保存测试"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155408.11555626021266825762993856788520:50001231000000:2800:DBF8A909B2F0E669195ACEA9C2F13CC4408BA84F765CC7ECE751B1F74621CFE9.png)

6. 在弹出的"提示"框中，点击"确定"。
7. App开启调测模式。 在应用Scheme的中添加'-AGConnectDeveloperMode'启动参数。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155408.84341008831837520053176876138644:50001231000000:2800:437B64982C99388DDDCDBDEB005B4151A93C2BBD1B5BCB023CD5A5F4A9571BD8.png)

   在Xcode联调模式下启动App，此时App会在首次触发事件时去云端获取最新的数据。此前步骤中已将此设备的AAID添加到测试设备中，后续在测试设备中触发消息事件时，该测试设备都会强制到AGC服务端获取消息数据，而不是从本地缓存读取。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250704155408.53038576626704663516892652904249:50001231000000:2800:A6ABFA8A1C16C3732128D02AA4E751D07A38D429A964CCE4709884F1649AA175.png)  
   强制请求数据的标志位与设备的AAID绑定，开发者卸载应用重装或者清除应用数据后，强制请求数据的标志位将会重置。
8. 测试消息是否能正常展示和操作。  
   有关测试设备和测试消息的具体说明如下表所示。  

   |类型|目的|说明|
   |:---|:----------------------------------|:----------------------------------------------------------------------------------------------------------------------|
   |测试设备|测试设备实时同步AGC服务端数据，不受应用内消息SDK请求次数的限制。|您在AGC中添加了该设备的AAID，并通过启动参数强制刷新数据，在下一次消息事件触发后该设备强制从AGC服务端同步了消息数据，此时开发者的设备为测试设备。 判断开发者的设备是否是测试设备的方法：每次触发事件都会去AGC服务端实时请求数据。|
   |测试消息|让开发者快速获取消息的内容、展示布局等。|在"应用内消息调测"页面，新增测试用户，点击"保存测试"后该条消息为测试消息。 测试消息只会展示一次。如果您想再次展示测试消息，需要重新进入"应用内消息调测"页面，点击"保存测试"将消息设置为测试消息。|
