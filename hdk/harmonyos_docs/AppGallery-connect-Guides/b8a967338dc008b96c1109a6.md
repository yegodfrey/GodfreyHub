# 手机

您可以在应用中集成手机账号认证方式，您的用户可以使用手机号码和密码或者手机号码和验证码来登录您的应用。  

#### 前提条件

您需要已完成[开通认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)以及[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-miniprogram-integration-sdk-0000001276634492)各项准备工作。  

#### 注册

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251223144022.53185075855040590725673072800563:50001231000000:2800:09768A7208E9189144A929C989B665CEF77C916DFE56F33FE0746C1077A48630.png "点击放大")

1. 申请手机注册的验证码，在使用手机注册之前，需要先验证您的手机，确保该手机归您所有。  
   调用[AGCAuth.requestPhoneVerifyCode](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section61992041193415)申请验证码。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251223144022.66463436498901282976067898210181:50001231000000:2800:4273D16B7FE8E4C4E8758D25125E06F8390CB7C0B9E37577EB44CE159DC3E056.png)  
   当前认证服务暂不支持向中国大陆推送手机验证码/通知短信。如果您项目的"数据处理位置"设置为"中国"且需要向中国大陆推送手机验证码/通知消息，请通过您的云函数或服务器接收验证码并发送短信。详情可参考[启用手机号码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-authentication-method-0000002417916829#section16830152153116)。

   ```
   agconnect.auth().requestPhoneVerifyCode(countryCode,
                                       phoneNumber,
                                       agconnect.auth.Action.ACTION_REGISTER_LOGIN,
                                       'zh_CN',// 发送验证码的语言
                                       sendInterval)
           .then(ret => {
               // 验证码申请成功
           }).catch(error => {
               // 验证码申请失败    
           });
   ```

<!-- -->

2. 使用手机号码注册用户。 调用[PhoneUser](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/phoneuser-web-0000001054823210#section141934277914)生成PhoneUser，然后调用[AGCAuth.createPhoneUser](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section1431017339592)注册用户。注册成功后，系统会自动登录，无需再次调用登录接口。

   ```
   let phoneUser= new agconnect.auth.PhoneUser('countryCode', 'phoneNumber','password', 'verifyCode');
   agconnect.auth().createPhoneUser(phoneUser)
           .then(user => {
               // 创建用户成功
           }).catch(error => {
               // 创建用户失败
           });
   ```

<!-- -->

3. 登录成功后可以调用[AGCAuth.getCurrentUser](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section1157222065718)获取用户账号数据。

   ```
   agconnect.auth().getCurrentUser();
   ```

#### 密码登录

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251223144022.21844408916845823354146819126202:50001231000000:2800:D702B9D98196F9EAE9CD302610556B18DC9CF9D46702D984168EA1AE7BF85793.png "点击放大")

1. 在应用的登录界面，初始化[AGCAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254)实例，获取 AGC的用户信息，检查是否有已经登录的用户。如果有则可以直接进入用户界面，否则显示登录界面。

   ```
   agconnect.auth().getCurrentUser().then(user=>{
       if(user){
           // 业务逻辑
       }
   });
   ```

2. 调用[PhoneAuthProvider.credentialWithPassword](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/phoneauthprovider-web-0000001054543239#section123584411337)采用密码方式创建手机账号凭证。

   ```
   credential = agconnect.auth.PhoneAuthProvider.credentialWithPassword(countryCode,phoneNumber,password);
   ```

3. 获取credential成功后，调用[AGCAuth.signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section18413636501)实现登录。

   ```
   agconnect.auth().signIn(credential)
            .then(user => {
                // 登录成功
            }).catch(error => {
                // 登录失败
            });
   ```

3. 调用[PhoneAuthProvider.credentialWithVerifyCode](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/phoneauthprovider-web-0000001054543239#section1398111483415)采用验证码方式创建手机账号凭证。

   ```
   credential = agconnect.auth.PhoneAuthProvider.credentialWithVerifyCode(countryCode, phoneNumber, password, verifyCode);
   ```

   password参数可以不传, 如果同时输入了密码和验证码，则会对密码和验证码都做验证。
4. 获取credential成功后，调用[AGCAuth.signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section18413636501)实现登录。

#### 修改手机号码

修改手机号码需要用户处于登录状态。

1. 调用[AGCAuth.requestPhoneVerifyCode](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section61992041193415)申请验证码。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251223144023.88745479200234339334216169591626:50001231000000:2800:F67EDB7F1E5CAAB6AAF05BA8C09985EE0E4D1E1EE40F83BCE698D2F9648BE014.png)  
   当前认证服务暂不支持向中国大陆推送手机验证码/通知短信。如果您项目的"数据处理位置"设置为"中国"且需要向中国大陆推送手机验证码/通知消息，请通过您的云函数或服务器接收验证码并发送短信。详情可参考[启用手机号码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-authentication-method-0000002417916829#section16830152153116)。

   ```
   agconnect.auth().requestPhoneVerifyCode(countryCode,
        phoneNumber,
        agconnect.auth.Action.ACTION_REGISTER_LOGIN,
        'zh_CN',// 发送验证码的语言
        sendInterval).then(ret => {
               // 验证码申请成功
           }).catch(error => {
               // 验证码申请失败    
           });
   ```

2. 调用[AGConnectUser.updatePhone](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectuser-web-0000001054663240#section191701961216)修改手机号码。

   ```
   user.updatePhone(countryCode, newPhone, newVerifyCode, lang);
   ```

对于修改手机号码操作，要求用户必须在5分钟内登录过才能执行。若已超时，请参见[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-miniprogram-reauthenticate-0000001113041286)先完成重认证。

修改密码时需要用户处于登录状态。

1. 调用[AGCAuth.requestPhoneVerifyCode](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section61992041193415)申请验证码。

   ```
   agconnect.auth().requestPhoneVerifyCode(countryCode,
        phoneNumber,
        agconnect.auth.Action.ACTION_RESET_PASSWORD, // 修改密码时action需要传agconnect.auth.Action.ACTION_RESET_PASSWORD
   ```

2. 调用[AGConnectUser.updatePassword](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectuser-web-0000001054663240#section1363991632119)修改密码。

   ```

   user.updatePassword(newPassword, verifyCode, provider);
   ```

1. 调用[AGCAuth.requestPhoneVerifyCode](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section61992041193415)申请验证码。

   ```
   agconnect.auth().requestPhoneVerifyCode(countryCode,
        phoneNumber,
        agconnect.auth.Action.ACTION_RESET_PASSWORD,// 重置密码时action需要传agconnect.auth.Action.ACTION_RESET_PASSWORD
        'zh_CN',// 发送验证码的语言
        sendInterval).then(ret => {
               // 验证码申请成功
           }).catch(error => {
               // 验证码申请失败    
           });
   ```

2. 调用[AGCAuth.resetPasswordByPhone](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section13913124201810)重置密码。

   ```
   agconnect.auth().resetPasswordByPhone(countryCode, phoneNumber, newPassword, verifyCode);
   ```

#### 更多信息

* 您如果想让用户可以使用多个账号登录您的应用，可以将多个[账号进行关联](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-miniprogram-associated-0000001159321107)。
* 当用户不需要使用应用，或者需要切换其他账号登录认证，可以先执行[登出](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-miniprogram-sign-out-0000001113201172)。
* 当用户需要注销当前用户，可以进行[销户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-miniprogram-deleteuser-0000001159441105)。
* 对于销户、修改密码、关联账号以及重置手机账号和邮箱账号等敏感操作，为了提高安全性，需要用户必须在5分钟内登录过才能执行。如果用户执行敏感操作时登录超过5分钟，需要[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-miniprogram-reauthenticate-0000001113041286)后再执行敏感操作。
* 您可以参考[异常处理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-miniprogram-troubleshooting-0000001113201182)实现自己的异常处理机制，从而减少异常情况的发生。
* 您可以使用云函数触发器来接收用户注册、登录、销户等关键事件，从而[扩展认证服务的能力](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-extension-0000001053372708)。
* 您可以参考[管理用户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-user-manage-0000001606051705)对用户进行解锁、停用等操作。
