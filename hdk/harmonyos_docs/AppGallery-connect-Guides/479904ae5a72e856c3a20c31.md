# Sleep Sounds

## 客户需求

《Sleep Sounds》是一款以专业疗愈助眠曲、自然白噪音源为核心的播放器。但在播放器的开发过程中出现不少崩溃，调试定位问题花费时间较多，导致开发成本较高。

## 华为解决方案

通过接入崩溃服务，获取了以下两方面的显著效果：

* 缩短崩溃定位时间：让运营人员无需花费时间测试崩溃情况，缩短了产品测试时间成本，同时通过查看上报的崩溃事件日志可以直接获知崩溃原因，原本需要花费1-2天时间定位的问题可当即解决。
* 及时发现崩溃问题：实时监控崩溃情况，防止用户的流失，避免了用户量因为产品问题导致的过度下降，同时也提升用户留存约15%。
