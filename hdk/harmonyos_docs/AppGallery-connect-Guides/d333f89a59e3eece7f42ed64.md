# 切换房间

玩家处于多房间状态下时，可通过切换语音房间实现进入不同房间发言。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241105115838.66087192841714613691960569661774:50001231000000:2800:2A64EF2D7EC1E56DCC5FF683162B569F62971CEB6640908234B3F62A552C343E.png?needInitFileName=true?needInitFileName=true)  
在房间A中，一个玩家无论是否具备发送语音的能力，当该玩家由房间A切换至其他房间后，其在房间A中则仅具备接收语音的能力。当玩家由其他房间切换回房间A后，则其恢复在原房间A中的语音能力。  

#### 前提条件

您至少已[加入](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-joinroom-roomid-android-0000001268934473)两个房间。  

#### 开发步骤

1. 调用[GameMediaEngine.switchRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-gmme-gamemediaengine-android-0000001238323625#section477684462917)方法切换到指定房间。

   ```
   mHwRtcEngine.switchRoom(roomId);
   ```

2. 当玩家切换房间时，可在IGameMMEEventHandler接口的[onSwitchRoom](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-handler-igamemmeeventhandle-android-0000001193243736#section4165773532)方法中实现相关回调处理。

   ```
   @Override
   public void onSwitchRoom(String roomId, int code, String msg) {
       StringBuilder sb = new StringBuilder("onSwitchRoom : ").append("roomId=")
           .append(roomId)
           .append(", code=")
           .append(code)
           .append(", msg=")
           .append(msg);
       LogUtil.d(TAG, sb.toString());
       // 切换房间成功或失败数据处理
   }
   ```
