# 开发场景化入口

游戏内嵌社区SDK支持场景化入口，玩家点击对应场景的按钮入口后，需先校验场景化入口ID的有效性，若按钮入口ID真实有效，再跳转至对应的页面。  

#### 前提条件

* 内嵌社区已完成[初始化](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/pgsmoment-init-0000001244091880)。
* 您已在AGC控制台[配置场景化入口](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/pgsmoment-agc-config-0000001291569413#section121186165147)并获取场景化入口ID。  

#### 开发步骤

1. 玩家点击游戏内的按钮入口后，需调用[PgsMoment.checkScene](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/gdpsdk-api-pgsmoment-0000001403658572#section17880123412618)，根据AGC控制台配置的数据检查待跳转的入口ID是否实时有效，若为无效状态，则屏蔽相关入口。

   ```
   // 检查入口ID
   PgsMoment.checkScene(sceneId, new CheckSceneIdCallback() {
       @Override
       public void onSuccess(String s, int i) {
           if (i == CheckSceneIdCallback.CHECK_STATUS_VALID) {
               // 场景有效
           } else {
               // 场景无效, 请检查管理台数据
           }
       }

       @Override
       public void onFailure(String s, Response response) {
           // 获取场景状态失败
           Log.e(TAG, "RtnCode: " + response.getRtnCode() + "; Msg: " + response.getMsg());
       }
   });
   ```

2. 若待跳转的入口ID实时有效，调用[PgsMoment.openScene](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/gdpsdk-api-pgsmoment-0000001403658572#section332395717311)并根据AGC控制台配置的数据打开对应页面：
   * 若入口ID跳转至"帖子详情页"，将直接在游戏内打开社区页面。
   * 若入口ID跳转至"活动详情页"，将跳转至游戏中心客户端的活动相关页面。

   ```
   // 跳转场景
   PgsMoment.openScene(sceneId, new PgsOpenCallback() {
       @Override
       public void onSuccess(Response response) {
           // 场景跳转成功
       }

       @Override
       public void onFailure(Response response) {
           // 场景跳转失败
           Log.e(TAG, "RtnCode: " + response.getRtnCode() + "; Msg: " + response.getMsg());
       }
   });
   ```
