# 下载项目级凭据

不同服务类型支持不同的凭据类型，认证服务目前支持项目级凭据。

使用Server SDK项目级凭据的前提是您已经在AGC中拥有了自己的项目，并在项目中开通了AGC对应的服务且已[设置数据处理位置](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-data-storage-location-0000001162597847)。确保已完成以上操作后，您可参考如下方法下载认证凭据：

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中点击您的项目。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250723180207.24144191749742036936636249795996:50001231000000:2800:EF12ACB6744190349841E6D085E2EA185FAF8C25862F5097AA981615D8503336.png)

3. 在"项目设置"页面中点击"Server SDK"页签。
4. 点击认证凭据中的"创建"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250723180207.67642978942453838554741344609107:50001231000000:2800:506D355D1B3CB0ECCF6314E0897AA20ABE2C5941A649CD642F5FA31286E0F917.png)

5. 创建完后生成认证凭据，点击"下载认证凭据"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250723180207.56338397436040048521902243505267:50001231000000:2800:ADCDBD79893CC17913A6431A933916EC7FFE668D42F8FFB60B78632F87D47156.png)

6. 将下载后的认证凭据文件agc-apiclient-*.json放置到您的Server服务器中指定路径下，后续初始化SDK时将会使用到该文件。 注意
   >
   > 凭据文件中包含您的client_secret信息，请您妥善保管。
