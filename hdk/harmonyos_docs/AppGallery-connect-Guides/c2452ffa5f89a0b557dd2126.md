# 元数据管理

文件元数据包含云端文件名、文件大小、文件类型等常用属性，也包括用户自定义的文件属性。文件上传到云端后，您可以设置文件的自定义属性。您也可以在下载文件实体前获取文件的元数据，来决定是否要下载文件。  

#### 前提条件

* 您已[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)。
* 您已[获取API授权](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-storage-getapicredentials-0000001498508514)。  

#### 操作步骤

1. 调用[修改文件元数据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storage-restapi-changemetadata-0000001549198553)接口设置文件的自定义属性。

   为了保证文件上传下载时的数据一致性，上传文件时可以使用setSHA256Hash方法设置文件SHA256值。
2. 当设置元数据成功后，您可以通过调用[获取文件元数据](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/storage-restapi-getmetadata-0000001549518573)接口获取设置在云端的元数据。
