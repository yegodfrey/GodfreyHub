# adb/hdc工具配置

优化Android和HarmonyOS 3.1/4.0及以下游戏需在PC端安装adb工具；优化HarmonyOS 5.0及以上游戏需在PC端安装hdc工具，用于连接手机时触发Profiling抓取和导出profile数据。  

#### adb工具配置（Windows）

优化Android和HarmonyOS 3.1/4.0及以下游戏时，在PC端（Windows系统）安装adb工具可按如下步骤操作。

1. 在Windows PC上安装adb工具，在"设置 \> 关于 \> 高级系统设置 \> 环境变量"，系统变量PATH中配置adb的路径。  
   ![](https://media:201786446008717203)  
   如果已经安装过adb，则不需要此步骤。
2. 使用type-c数据线连接测试手机到Windows PC。
3. 在测试手机上，点击"设置 \> 关于手机 \> 连续点击版本号"，打开"开发人员选项"。
4. 在测试手机上，进入开发人员选项，"设置 \> 系统和更新 \> 开发人员选项 \> 勾选USB调试"，打开"USB调试"。
5. 在Windows PC的cmd窗口输入如下命令，查看手机的设备序列号。

   ```
   adb devices
   ```

   如果打印出类似如下的设备序列号，则表示手机已成功连接电脑。

   ```
   List of devices attached 
   MDX0220109000158        device
   ```

6. 在Windows PC的cmd窗口输入adb shell，手机上如果弹窗请求授权，选择"始终授权并同意"。  

#### hdc工具配置（Windows）

优化HarmonyOS 5.0及以上系统游戏时，在PC端（Windows系统）安装hdc工具可按如下步骤操作。

1. 获取hdc工具。可以选择以下任意一种方式：
   * 方式一：通过HarmonyOS SDK获取hdc工具。  
     HarmonyOS SDK已嵌入[DevEco Studio](https://developer.huawei.com/consumer/cn/deveco-studio/)中，无需额外下载配置。hdc默认安装在如下路径：

     ```
     DevEco Studio/sdk/default/openharmony/toolchains
     ```

   * 方式二：通过[Command Line Tools](https://developer.huawei.com/consumer/cn/download/)工具中的sdk目录获取相关工具。  
     hdc程序默认安装在如下路径：

     ```
     Command Line Tools/sdk/default/openharmony/toolchains
     ```

   hdc支持USB和无线两种连接调试方式。在设备的设置\>系统\>开发者选项中开启或关闭调试开关 ，无需重启设备即可生效。如果设备未启用"开发者选项"，可参考[开发者选项](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-developer-mode#section530763213432)进行启用。具体调试连接方式及操作步骤请参考[USB连接场景](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/hdc#usb连接场景)和[TCP连接场景](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/hdc#tcp连接场景)。
2. 添加hdc到系统环境变量。设置方法如下：
   1. 按下Windows键，搜索栏输入"设置"，点击进入设置窗口。
   2. 在搜索栏中搜索"查看高级系统设置"，在环境变量\>系统变量\>Path\>编辑中，将hdc.exe所在目录添加到Path。
3. 环境变量配置完成后，请重启电脑，即可在命令行窗口执行hdc命令。
