# （可选）添加自定义监控配置

## 添加自定义跟踪记录

自定义跟踪记录可用于监控您的Web应用在自定义场景下的性能，如应用登录场景、文件上传场景等。

对于自定义跟踪记录，APM会自动采集默认属性（浏览器、国家/地区、运营商、网络类型、网页地址、ServiceWorker状态、网页公开范围状态）。同时，您还可以为该跟踪记录添加自定义指标和自定义属性来进一步过滤和细分数据。

以文件上传场景为例，使用自定义跟踪能力过程如下：

1. 调用[createTrace](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/apm-web-0000001053266118#section123301954101816)创建一个自定义跟踪对象"uploadTrace"。

   ```screen
   const uploadTrace = APM.createTrace('uploadTrace')
   ```

2. 执行上传文件接口前调用[start](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/trace-0000001052495065#section14501903313)，在上传成功的回调里调用[stop](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/trace-0000001052495065#section5779184717361)。此次上传耗时将作为默认指标采集。

   ```screen
   uploadTrace.start()
   axios.post('/upload', param).then(data => {
     // your code ...
     uploadTrace.stop()
   })
   ```

3. 调用[setAttribute](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/trace-0000001052495065#section987912113712)添加文件名为自定义属性，调用[setMetric](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/trace-0000001052495065#section2089194410466)添加文件大小为自定义指标。

   ```screen
   uploadTrace.start()
   axios.post('/upload', param).then(data => {
     // your code ...
     uploadTrace.setAttribute('fileName', param.fileName) // 文件名作为自定义属性
     uploadTrace.setMetric('fileSize', param.fileSize) // 文件大小作为自定义指标
     uploadTrace.stop()
   })
   ```

   > 说明
   > * 一个应用中可以有多个自定义跟踪记录，多个自定义跟踪记录可以同时运行。
   >
   >
   > * 自定义跟踪记录名称、自定义属性名称、自定义指标名称必须由中文、字母（不区分大小写）、数字和下划线组成，长度最大为40字符。
   >
   >
   > * 每个自定义跟踪记录最多只能添加5个自定义属性。
