# FAQ

#### 如何解决一直显示"正在连接采集器"

手机连接HiSmartPerf-Editor工具后，界面一直显示"正在连接采集器"，这是因为工具的安装路径可能有中文。您需要卸载工具重新安装，且保证安装路径中没有中文和空格。

#### 手机设备如何成功连接电脑

1. 打开手机的"设置"应用，进入"关于手机"页面。
2. 快速、连续、多次点击"软件版本"，直到提示"您正处于开发者模式！"或"您已处于开发者模式，无需进行此操作"，表示您已进入当前手机设备的开发者模式。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110218.18095533160130612186480645682770:50001231000000:2800:668C46EDA4233480C495BF7DA4FD1830402AEEE76362B6906BF7114C278FF6C5.png)

3. 在"开发人员选项"页面打开"USB调试"、"仅充电模式下允许ADB调试"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110218.66179038510350261893977231440538:50001231000000:2800:6D3BF4AB2B453D189899DBFCB74D9099729A8052D8DB2FEB2B6217C0DA6EB377.png)

4. 在底部弹出的"是否允许USB调试？"窗口上点击"确定"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110218.78253067980106770195350538718592:50001231000000:2800:17985BE9ED55537024F7599575C2D2A1DBE8E126EE5F502D862FDBCE1349CA29.png)

5. 使用USB数据线连接手机与电脑，并在弹出的"USB连接方式"窗口上选择"仅充电"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110218.79070382913020399479323060435286:50001231000000:2800:EC73CB8D6FBC1BAF168F75AA77DDCF7F98ABDAB0C2D2FF95436108746E9D1175.png)

6. 继续在"是否允许USB调试？"窗口上点击"确定"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260212110218.74550631859954620275889435713638:50001231000000:2800:8C695A3CA097AF78F5F954983CA6C2C938606289664A5A4F46CBCD7DC6AC4B8B.png)

#### 从USB连接切换到Wi-Fi连接后，设备会断开，应该如何解决？

使用USB数据线连接手机与电脑时，在弹出的"USB连接方式"窗口上不要选择"文件传输"，请选择"仅充电"。
