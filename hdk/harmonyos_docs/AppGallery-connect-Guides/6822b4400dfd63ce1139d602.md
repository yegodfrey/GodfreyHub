# 查询与更新商品

> 说明
>
> 调用PMS API前请确认已经完成[使用入门](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114)中的服务端授权。

## 查询商品

您可以调用[查询商品详情](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-getproductinfo-harmonyosnext-0000002131350708)接口根据应用ID和商品标识查询唯一的商品信息或者调用[按条件查询商品信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-bygetproductinfo-harmonyosnext-0000002166748609)接口根据筛选条件完成查询，根据筛选条件您可以直接查询应用内所有商品列表信息，查询某一订阅分组ID下的商品，还可以将查询的结果按商品的不同属性进行排序。

以查询商品详情为例，示例代码如下：

```screen
public static ProductDetailQueryResp getProductInfoDetail(String domain, String clientId, String authorization,
                                                          String appId, String productNo) {
    String url = domain + "/api/pms/product-price-service/v1/manage/product";
    HttpGet get = new HttpGet(url + "?productNo=" + productNo);
    setHttpHead(clientId, authorization, appId, get);
    String result = getApiResp(get);
    if (StringUtils.isNotEmpty(result)) {
        return JSON.parseObject(result, ProductDetailQueryResp.class);
    }
    return null;
}
```

## 更新商品

商品基本信息包括应用的商品名称、语言、价格、状态等，您可以调用[更新商品信息](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-updateproduct-harmonyosnext-0000002166670141)接口或者[批量更新商品](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-batchupdateproduct-harmonyosnext-0000002131508852)接口完成商品基本信息的修改。
> 说明
>
> 批量接口每批最多支持100个，支持部分成功， 失败的会在响应中反馈错误信息。

以批量更新商品为例，示例代码如下：

```screen
public static ProductBatchUpdateResp batchUpdateProductInfo(String domain, String clientId, String authorization,
                                                            String appId, ProductBatchUpdateReq req) {
    String url = domain + "/api/pms/product-price-service/v1/manage/product/batchImportProducts";
    HttpPut put = new HttpPut(url);
    setHttpHead(clientId, authorization, appId, put);
    StringEntity entity =
            new StringEntity(JSON.toJSONString(req), ContentType.create("application/json", "UTF-8"));
    put.setEntity(entity);
    String result = getApiResp(put);
    if (StringUtils.isNotEmpty(result)) {
        return JSON.parseObject(result, ProductBatchUpdateResp.class);
    }
    return null;
}
```
