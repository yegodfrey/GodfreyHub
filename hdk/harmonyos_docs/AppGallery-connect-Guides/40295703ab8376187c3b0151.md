# 管理版本

云托管服务提供了RESTful API接口，支持您通过API管理云托管站点版本。

* 您可以创建一个空版本（全新版本），直接使用新的版本包发布版本。
* 您可以基于基线版本克隆出一个新版本，在此基础上删除、新增和修改版本文件，最终发布版本。

> 说明
>
> 基线版本：同一个站点下已归档的版本，且版本状态为"已归档"。

## 前提条件

* 已完成[开发网页](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudhosting-developwebpage-0000001057762263)、[启用服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudhosting-enableservice-0000001057492615)和[创建中国站点](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudhosting-createsite-0000001058092565#section174011347142315)操作。
* 调用RESTful API接口前，请确认已经完成[使用入门](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudhost-getstarted-0000001166760172)中的服务端授权。

## 创建版本

> 说明
>
> * 每个站点最多创建100个版本。
> * 仅支持状态为"已归档"的版本作为基线版本。
> * 调用[查询站点列表](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-cloudhost-querysite-0000001166826430)接口，可以根据站点名称查询所在站点的ID。
> * 同一个站点下，不能同时存在两个正在创建中的版本。

* 创建全新版本 您需要调用[创建版本](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-cloudhost-newapp-0000001111685196)接口，为站点创建一个新的版本框架。

* 创建增量版本 您需要调用[创建版本](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-cloudhost-newapp-0000001111685196)接口，为站点创建一个新的版本框架，并且可以选择是否基于一个已存在的版本（基线版本）进行创建。如果您基于基线版本进行创建，可以在此版本基础上删除、新增、修改或查询版本文件。您可以调用[查询归档文件列表](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-cloudhost-queryfile-0000001211627869)接口查询基线版本文件，获取基线版本的接口响应文件的绝对路径和hash值作为对比参数。查询和比较版本文件的差别后，创建新版本。

  创建完成后，版本状态为已创建状态，只有已创建状态下才可以进行后续的版本操作。

## 指定删除文件列表（可选）

如果您的新版本是全新版本（未基于基线版本创建），或者基线版本内没有需要删除的版本文件，则不需要执行该操作。

当创建版本完成后，您可以调用[指定删除文件列表](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-cloudhost-modifyversion-0000001211627867)接口将基线版本内需要废弃的版本文件标记为待删除状态。当进行[归档版本](#section1669863312015)时，按照标记处理版本文件。
> 说明
>
> * 指定删除文件列表不会对基线版本真实文件（已上传的版本包文件）进行操作。
> * 支持多次删除，但是版本文件一旦标记为待删除，无法撤销和回退，需要[删除版本](#section62275462013)后，重新[创建版本](#section1547061019390)。

>
> * 您可以多次获取版本压缩包的上传地址，以最后一次获取为最终增量版本包进行处理。
> * 获取到的上传信息中，请求头有本次上传的token信息，该token有效期30分钟。

## 上传版本压缩包

通过获取版本压缩包上传地址可以获取压缩包的上传信息，包括请求方法、请求地址和请求头。您需要调用[上传版本压缩包](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-cloudhost-uploadversion-0000001211707813)接口，根据这些信息建立http连接并将压缩包上传至云托管。
> 说明
>
> * 版本包必须打包成".zip"文件，且不能增加一层外级目录。
> * 版本包的文件名和目录名不可以包含空格、中文。
> * 版本包的根目录名称不能为"sandbox"，否则会影响版本发布。
> * 版本文件总大小（包含基线版本和增量文件）不可以超过400M，文件数量不可以超过20000个。

## 归档版本

上传版本包完成后，您需要调用[归档版本](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-cloudhost-archivedversion-0000001211826385)接口对新版本进行归档，服务器将对新版本进行如下处理。

* 如果是基于基线版本创建的版本，云托管对增量版本包进行如下处理后，进行归档处理。
  1. 根据删除文件列表删除基线版本列表中对应的文件。
  2. 合并增量版本包和基线版本包的版本文件，并生成新的版本包。
     * 检查增量版本文件和基线版本文件重复的部分，重复的文件会被增量版本文件覆盖。
     * 检查增量版本文件和基线版本文件不重复的部分，全部保留。
* 如果创建的是全新版本，则直接进行归档处理。

归档完成后才可以进行版本发布。当归档版本成功后，新版本归档的最终状态为"已下线"，您可以调用[查询版本列表](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-cloudhost-queryversion-0000001166507920)接口查询版本的发布状态。
> 说明
>
> * 归档处理对基线版本原始文件没有影响。
> * 只有"已创建"状态下的版本才可以进行归档版本。
> * 归档操作是异步操作，从开始到完成，版本的状态从"归档中"变为"已归档"。

## 发布版本

当新版本归档完成后（即版本状态为"已归档"），您可以调用[发布版本](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-cloudhost-releaseversion-0000001166666484)接口发布新版本。云托管提供了两种版本发布方式，保障版本的可靠性。

* 沙箱发布：沙箱环境发布，与生产业务流量隔离，提供可靠性测试的发布环境。
* 生产发布：生产环境发布，接入业务流量，可通过站点域名直接访问生产在线版本。

### 沙箱发布

> 说明
>
> * 只有 "已归档"状态的版本支持沙箱发布。
> * 版本包的根目录名称不能为"sandbox"，否则会影响版本发布。
> * 同一个站点下，不能同时存在两个正在沙箱发布的版本。

您可以在沙箱发布环境对新版本做可靠性测试，测试完成后再将该版本推送到生产环境。从沙箱发布开始到完成发布，发布状态由"沙箱发布中"变成"沙箱"。您可以调用[查询版本列表](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-cloudhost-queryversion-0000001166507920)接口查询版本状态和沙箱访问路径（sandboxUrlPrefix）。

访问方式：由https协议和沙箱访问路径（sandboxUrlPrefix）组成完整的访问地址，您可以通过该地址访问沙箱版本。

路径组成：https://{domain}/sandbox/{environmentId}/{versionId}/{path}

其中，domain为域名，environmentId为站点环境ID，versionId为版本号，path为文件路径。

### 生产发布

> 说明
>
> * 只有版本状态为"已归档"的版本支持生产发布。
> * 版本包的根目录名称不能为"sandbox"，否则会影响版本发布。
> * 同一个站点下，不能同时存在两个正在生产发布的版本。

您可以直接将版本推送到生产环境并接入业务流量。从生产发布到最终上线，发布状态由"上线中"变成"上线"。您可以调用[查询版本列表](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-cloudhost-queryversion-0000001166507920)接口查询新版本的发布状态。

访问方式：通过点击"版本管理"页面的域名直接访问。

访问地址示例：https://hostingtest.xxx.com/

## 删除版本

> 说明
>
> * 当前上线版本不可删除。
> * 删除成功后不可恢复，请谨慎操作。

您可以调用[删除版本](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-cloudhost-deleteversion-0000001166347944)接口删除发布状态为非"上线"的版本。
