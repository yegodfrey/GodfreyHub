# 将SpringBoot工程快速迁移至基于Custom Runtime运行的云函数

Custom Runtime是自定义运行环境，本质上是一个具有监听端口的HTTP Server，云函数启动Custom Runtime时，会默认调用bootstrap文件启动您自定义的HTTP Server，然后由此HTTP Server接管所有事件。

所以改造时，您只需创建一个启动目标HTTP Server的可执行文件bootstrap，然后将该文件和代码文件一起打成ZIP包，最后将该ZIP包部署到云函数平台，作为一个Custom Runtime的函数即可。

## 项目调整

1. 修改端口。 由于Custom Runtime启动的服务是监听9000端口，所以需要将项目的暴露端口修改为9000。

   例如修改 resources 目录下配置文件 application-dev.properties 中的 server.port 属性为9000。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250424172602.72316258094251055512979900734889:50001231000000:2800:D707A1943D0370439839E3AC97016CB741CD8A9D569B0398873559E03E5BFB68.png)
2. 将项目 logback文件 中日志目录修改为云函数推送的日志目录 /opt/huawei/logs/，以修改 logback-spring.xml 文件为例。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250424172602.12676137556711842409176879969674:50001231000000:2800:12C382C571EE4DB7E29C328D470666076A8493C68BC5A5E394B3E6FFC5628760.png)

3. 建议在 logback文件 中配置格式化输出格式。

   ```screen
   <pattern>{"M":"%replace(%t [%c] - %m){'\"','\\\"'}","T":"%d{yyyy-MM-dd HH:mm:ss.SSS,GMT}","L":"%level","LINE":"%file:%L","TENANTID":"${FAAS_FUNCTION_TENANTID}","FUNCTION":"${FAAS_FUNCTION_NAME}","VERSION":"${FAAS_FUNCTION_VERSION}","BUSINESSID":"${FAAS_FUNCTION_BUSINESS}","X-Trace-ID":"%X{x-trace-id}"}%n</pattern>；
   ```

## 项目打包

1. 使用 mvn clean install 命令将SpringBoot项目打包成jar包。例如生成 mfu-doctor-api-1.0-SNAPSHOT.jar。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250424172602.69811126593787201270535010171091:50001231000000:2800:581B5D78CC350E63415F7E42092DCE95B32B8E552E7BC9FFE7420E615FAA2724.png)

2. 编辑 bootstrap 文件。 bootstrap 作为云函数服务启动入口，运行java工程时需要使用 java -jar 命令拉起，所以 bootstrap 脚本配置内容如下。

   ```screen
   #!/bin/bash

   java -jar mfu-doctor-api-1.0-SNAPSHOT.jar
   ```

3. 将bootstrap文件和jar包一起打包成zip文件（例如命名为：rt-java.zip），zip包内容如下。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250424172602.87065242552485069479042384095172:50001231000000:2800:7167A668E9B6D1B06D5990DB451DDFC86661019E65C871ECB5BA6286BA8218E6.png)

## 项目部署

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择待部署的项目。
2. 左侧导航栏选择"云开发（Serverless）> 云函数"，点击"创建函数"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250424172602.73057847752098246634340809673423:50001231000000:2800:4500D0EF565E8DF1A8BC69292188D47CB428733609A4B7A759230A881FAD83D5.png)

3. 在"创建函数"窗口，按照"函数配置 -> 触发器 -> 函数代码 -> 层配置"引导顺序配置函数，然后点击"创建"。

   * **函数配置-触发方式** ：选择"http请求"

## 项目验证

由于当前自定义运行时云函数不支持自动拉起，因此需要访问项目相关接口，手动拉起云函数资源。

1. 获取项目对外访问地址。 项目部署完成后，选择"触发器"页签，获取"请求URL"信息。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250424172602.59574501948438171888003435767334:50001231000000:2800:E21A8194836613E77F4C028BD72F1A15EFF93086C3E329FA105A003065B8387C.png)
2. 获取项目凭据信息。 在"项目设置"页面，获取项目ID、Client ID和Client Secret信息。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250424172602.43180364993691269024978117867370:50001231000000:2800:74A7656E67CF928D36F06BCD283FF715589CAF609E1D3A9C17934CC0321EC44E.png)
3. 获取Token。 Curl 命令访问样例如下。其中：$clientId和$clientSecret为[步骤2](#ZH-CN_TOPIC_0000001502518310__li516743010518)获取项目凭证的Client ID和Client Secret。

   ```screen
   curl https://connect-drcn.dbankcloud.cn/agc/apigw/oauth2/v1/token \
   -X POST \
   -H "Content-Type: application/json" \
   -d '{"grant_type": "client_credentials","client_id": "$clientId","client_secret": "$clientSecret"}'
   ```

   运行结果如下。

   ```screen
   {
       "access_token": "xxx",
       "expires_in": 178336
   }
   ```

4. 将云函数触发地址和项目接口拼接后访问，进行验证。
   * $URL为[步骤1](#ZH-CN_TOPIC_0000001502518310__li11126961639)获取的对外访问地址，$api 为项目对外暴露的接口。
   * $Method：接口的请求方式。
   * Authorization 中的 $access_token 为[步骤3](#ZH-CN_TOPIC_0000001502518310__li1648516176811)获取的Token。
   * $client_id：[步骤2](#ZH-CN_TOPIC_0000001502518310__li516743010518)获取项目凭证的Client ID。
   * $productId：[步骤2](#ZH-CN_TOPIC_0000001502518310__li516743010518)获取项目凭证的项目ID。

   ```screen
   curl  $URL/$api \
   -X $Method \
   -H "Authorization: Bearer $access_token" \
   -H "client_id: $client_id" \
   -H "productId: $productId"
   ```
