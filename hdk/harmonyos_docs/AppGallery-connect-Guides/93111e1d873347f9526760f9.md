# 语音变声

游戏多媒体语音变声能力，通过对实时语音进行变声处理，可让聊天环境变得更加有趣，提升语音体验。目前，游戏多媒体服务提供了机器人、怪兽、萝莉等多款声音特效。  

#### 前提条件

* 您已[集成游戏多媒体基础SDK、实时语音和变声模块](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-integratingsdk-ios-0000001323104597#ZH-CN_TOPIC_0000001323104597__li16373152113206)。
* 您已[创建游戏多媒体实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-engine-ios-0000001272544612#section1093713161034)。
* 您已[加入房间](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-joinroom-roomid-ios-0000001323024589)。
* 如需测试变声效果，需[开启麦克风](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-enablemic-ios-0000001353274729)。  

#### 开发步骤

1. 调用[HWPGMEngine.getInstance.enableVoiceConversion](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section1987053503715)方法开启/关闭房间内语音变声。

   ```
   int result = [HWPGMEngine.getInstance enableVoiceConversion:roomId voiceType:voiceType]; // roomId：房间ID; voiceType：变声类型,原声类型表示关闭变声，其他枚举值请参考VoiceType
   ```

2. 如需查询当前房间的变声类型，可通过调用[HWPGMEngine.getInstance.getVoiceConversionType](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section8110724153912)方法获取。如变声类型为原声类型，则表示已关闭变声。

   ```
   VoiceType voiceType = [HWPGMEngine.getInstance getVoiceConversionType:roomId]; // roomId：房间ID
   ```

3. 如需测试变声效果，可通过调用[HWPGMEngine.getInstance.enableEarsBack](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section1232855144013)方法开启耳返，即可听到发声者自己的语音变声效果。

   ```
   int result = [HWPGMEngine.getInstance enableEarsBack:isEnabled]; // enable：是否开启耳返,true表示开启,false表示关闭
   ```

4. 如需查询耳返是否已开启，可通过调用[HWPGMEngine.getInstance.isEarsBackEnable](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section13870111374115)方法获取耳返的开启状态。

   ```
   BOOL isEnabled = [HWPGMEngine.getInstance isEarsBackEnable];
   ```
