# 订阅与取消订阅频道

"频道"作为游戏多媒体服务RTM功能的一个数据传输通道，主要用于频道消息的传递与广播。RTM频道消息支持不同客户端之间借助"频道"实现实时通信、全局聊天等功能，允许玩家在游戏内部建立实时的聊天室和群组，以进行广播消息、交流和社交，从而提升游戏的社交互动性。订阅频道的用户即可在频道内收发相关消息和事件，可选择订阅一个或多个频道。如取消订阅，则后续将无法收到频道消息。

## 前提条件

* 您已[集成游戏多媒体基础SDK和实时信令模块](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-integratingsdk-ios-0000001323104597#ZH-CN_TOPIC_0000001323104597__li16373152113206)。
* 您已[创建游戏多媒体实例](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/gamemme-engine-ios-0000001272544612#section1093713161034)。

## 订阅频道

订阅频道是收发频道内相关消息和事件监听的前提，如果玩家掉线且重连失败或销毁引擎，则会自动取消已订阅的频道。
> 说明
>
> 因网络掉线，在90s时间内，服务端将会尝试自动重连。如若重连成功，则会多次（至多10次）尝试重新订阅原频道。如自动重新订阅失败，建议您手动重新发起订阅。

1. 调用[HWPGMEngine.getInstance subscribeRtmChannel](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section18459621182520)方法，订阅指定的频道。

   ```screen
   SubscribeRtmChannelReq *req = [[SubscribeRtmChannelReq alloc] init];
   req.channelId = channel;
   req.playerProperties = {@"name": @"xxxx", @"age": @"22"};
   [HWPGMEngine.getInstance subscribeRtmChannel:req];
   ```

2. 在HWPGMEngineDelegate协议的[onSubscribeRtmChannel](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section01581834131014)回调方法中，可以获取频道订阅的结果。

   ```screen
   - (void)onSubscribeRtmChannel:(SubscribeRtmChannelResult *)result {
     // 可根据需求将数据进行处理
   }
   ```

## 取消订阅频道

如取消指定的订阅频道，您需已订阅该频道。

1. 通过调用[HWPGMEngine.getInstance unSubscribeRtmChannel](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmengine-ios-0000001272768358#section85931937112620)方法，取消已订阅的频道。

   ```screen
   UnSubscribeRtmChannelReq *req = [[UnSubscribeRtmChannelReq alloc] init];
   req.channelId = channel;
   [HWPGMEngine.getInstance unSubscribeRtmChannel:req];
   ```

2. 在HWPGMEngineDelegate协议的[onUnSubscribeRtmChannel](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/gamemme-hwpgmenginedelegate-0000001323168225#section1360222181217)回调方法中，可以获取频道取消订阅的结果。

   ```screen
   - (void)onUnSubscribeRtmChannel:(UnSubscribeRtmChannelResult *)result {
     // 可根据需求将数据进行处理
   }
   ```
