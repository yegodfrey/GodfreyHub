# 支付宝账号

您可以在应用中集成支付宝认证方式，让您的用户可以使用自己的支付宝账号进行AppGallery Connect身份验证。

## 前提条件

* 您已[启用认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)。
* 您需要在应用中[集成认证服务SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-integration-sdk-0000001325876845)。

## 开发步骤

认证服务提供了两种开发方式接入支付宝账号：

* 推荐您使用新的统一登录接入方式，请参见[统一登录接入方式](#section3139114174911)。
* 同时为了兼容性保留了老的传统接入方式，请参见[传统接入方式](#section1388515146504)。

### 统一登录接入方式

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143817.55502851494064180441966627838857:50001231000000:2800:BD9A5446741FCDB99E8B7A75653551F8FA0E7CD63C21178EAD97365A6DE4A0EC.png "点击放大")

1. 添加SDK依赖。
   * Android Studio开发环境
     * Version Catalog方式管理依赖
       1. 打开Android Studio项目级gradle目录下的"libs.versions.toml"文件，在[versions]中声明支付宝SDK版本号。

          ```screen
          [versions]
          alipayVersion = "+"
          ```

       2. 在"libs.versions.toml"文件的[libraries]中声明华为认证SDK和支付宝SDK。

          ```screen
          [libraries]
          agconnect-auth-alipay = { module = "com.huawei.agconnect:agconnect-auth-alipay", version.ref = "agcVersion" }  # agcVersion声明请参见https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-integration-sdk-0000001325876845#section99221941185719。
          alipay-sdk = { module = "com.alipay.sdk:alipaysdk-android", version.ref = "alipayVersion" }
          ```

       3. 在应用级"build.gradle"文件的"dependencies"中添加华为认证SDK和支付宝SDK的编译依赖。

          ```screen
          dependencies {      
               implementation libs.agconnect.auth.alipay
               implementation libs.alipay.sdk
          }
          ```

     * 非Version Catalog方式管理依赖 打开应用级gradle文件（通常在app/build.gradle），在"dependencies"中添加华为认证SDK和支付宝SDK的编译依赖。

       ```screen
       dependencies {
           implementation "com.huawei.agconnect:agconnect-auth-alipay:1.9.4.300"     
           implementation "com.alipay.sdk:alipaysdk-android:+@aar"
       }
       ```

   * Eclipse开发环境

     打开aar2eclipse/aar目录下的build.gradle文件， 在"dependencies"中添加华为认证SDK和支付宝SDK的编译依赖。具体步骤参见[Eclipse开发环境集成AGC SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-integration-sdk-0000001325876845#section1878849165620)。

     ```screen
     dependencies {
         embed "com.huawei.agconnect:agconnect-auth-alipay:1.9.4.300"
         embed "com.alipay.sdk:alipaysdk-android:+@aar"
     }
     ```

   > 说明
   >
   > 华为不负责提供支付宝SDK依赖包，您可以使用示例方式在您的开发环境中添加支付宝SDK依赖，也可以自行至阿里云开放平台下载最新版本的支付宝SDK依赖包进行手动集成。示例中的支付宝SDK依赖包仅供参考，华为不负责版本更新。
2. 设置支付宝账号登录所需参数。 在登录之前，调用设置参数接口，设置支付宝账号登录所需要的参数。

   例如/alipay/app_id：在支付宝开放平台申请的app_id。支付宝请求参数详情请参考[支付宝官方文档](https://opendocs.alipay.com/open/218/105327)。

   ```screen
   "Java"
   AGConnectApi.getInstance().getOptions().setOption("/alipay/app_id", "your alipay app_id");
   AGConnectApi.getInstance().getOptions().setOption("/alipay/app_name", "your alipay app_name");
   AGConnectApi.getInstance().getOptions().setOption("/alipay/pid", "your alipay pid");
   AGConnectApi.getInstance().getOptions().setOption("/alipay/target_id", "your alipay target_id");
   AGConnectApi.getInstance().getOptions().setOption("/alipay/sign", "your alipay sign");
   AGConnectApi.getInstance().getOptions().setOption("/alipay/sign_type", "your alipay sign_type");
   ```

   ```screen
   "Kotlin"
   AGConnectApi.getInstance().options.setOption("/alipay/app_id", "your alipay app_id")
   AGConnectApi.getInstance().options.setOption("/alipay/app_name", "your alipay app_name")
   AGConnectApi.getInstance().options.setOption("/alipay/pid", "your alipay pid")
   AGConnectApi.getInstance().options.setOption("/alipay/target_id", "your alipay target_id")
   AGConnectApi.getInstance().options.setOption("/alipay/sign", "your alipay sign")
   AGConnectApi.getInstance().options.setOption("/alipay/sign_type", "your alipay sign_type")
   ```

3. 调用[AGConnectAuth.signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauth-0000001054482530#section125666562219)，登录支付宝账号。

   ```screen
   "Java"
   AGConnectAuth.getInstance().signIn(this,AGConnectAuthCredential.Alipay_Provider).addOnSuccessListener(new OnSuccessListener<SignInResult>() {
           @Override
           public void onSuccess(SignInResult signInResult) {
                   // onSuccess
                   AGConnectUser user =  signInResult.getUser();
           }
   })
   .addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
                   // onFail
           }
   });
   ```

   ```screen
   "Kotlin"
   AGConnectAuth.getInstance().signIn(this, AGConnectAuthCredential.Alipay_Provider).addOnSuccessListener {
       // updateUI
   }.addOnFailureListener {
       // onFailure
   }
   ```

### 传统接入方式

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251217143817.80545194260285194387788385532731:50001231000000:2800:8B17F2C15989AEA9C7EC08FACA93090CF197E4EB5D9F2C70A27AB4A51631B6C8.png "点击放大")

1. 在应用的登录界面，初始化[AGConnectAuth](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauth-0000001054482530)实例，获取AGC的用户信息，检查是否有已经登录的用户。如果有则可以直接进入用户界面，否则显示登录界面。

   ```screen
   "Java"
   AGConnectUser user = AGConnectAuth.getInstance().getCurrentUser();
   ```

   ```screen
   "Kotlin"
   val user = AGConnectAuth.getInstance().currentUser
   ```

2. 支付宝账号登录，并获取支付宝账号的用户授权信息。具体请参考[支付宝官方文档-Android调用方法](https://opendocs.alipay.com/open/218/105325)。
3. 调用[AlipayAuthProvider.credentialWithAuthCode](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/alipayauthprovider-0000001462699917#section15903782212)使用从支付宝账号登录获取的authCode生成credential，并调用[AGConnectAuth.signIn](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectauth-0000001054482530#section298148131715)实现登录。

   ```screen
   "Java"
   AGConnectAuthCredential credential = AlipayAuthProvider.credentialWithAuthCode(authcode);
   AGConnectAuth.getInstance().signIn(credential)
       .addOnSuccessListener(new OnSuccessListener<SignInResult>() {
           @Override
           public void onSuccess(SignInResult signInResult) {
               // onSuccess
               AGConnectUser user = signInResult.getUser();
           }
       })
       .addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
               // onFail
           }
       });
   ```

   ```screen
   "Kotlin"
   val credential = AlipayAuthProvider.credentialWithAuthCode(authcode)
   AGConnectAuth.getInstance().signIn(credential).addOnSuccessListener {
       // onSuccess
       val user = it.user
   }.addOnFailureListener {
        // onFail
   }
   ```

## 更多信息

* 您如果想让用户可以使用多个账号登录您的应用，可以将多个[账号进行关联](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-associated-0000001053692650)。
* 当用户不需要使用应用，或者需要切换其他账号登录认证，可以先执行[登出](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-sign-out-0000001053612647)。
* 当用户需要注销当前用户，可以进行[销户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-deleteuser-0000001057730521)。
* 对于销户、修改密码、关联账号以及重置手机账号和邮箱账号等敏感操作，为了提高安全性，需要用户必须在5分钟内登录过才能执行。如果用户执行敏感操作时登录超过5分钟，需要[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-reauthenticate-0000001127287737)后再执行敏感操作。
* 您可以参考[异常处理](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-android-troubleshooting-0000001052932665)实现自己的异常处理机制，从而减少异常情况的发生。
* 您可以使用云函数触发器来接收用户注册、登录、销户等关键事件，从而[扩展认证服务的能力](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-extension-0000001053372708)。
* 您可以参考[管理用户](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-user-manage-0000001606051705)对用户进行解锁、停用等操作。
