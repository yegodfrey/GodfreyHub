# 销户

## 前提条件

您需要已完成[开通认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)、[在开发环境中创建快应用项目](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-quickapp-ide-0000001326372281)以及[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-quickapp-integration-sdk-0000001326252149)各项准备工作。

## 开发步骤

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251223144020.06634913667993192879502158591406:50001231000000:2800:739D491234695E2CCDB1D9D425514AED0A3E4DA3B14422325D6563793BCAD5CC.png "点击放大")

当用户不再使用应用，可以注销当前用户。您需要调用[AGCAuth.deleteUser](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcauth-web-0000001054503254#section13266162513559)实现该功能，用户一旦被注销，将会删除服务端侧的用户信息同时清空客户端侧用户信息和Token。

```screen
agconnect.auth().deleteUser();
```

> 说明
>
> 对于销户操作，要求用户必须在5分钟内登录过才能执行。若已超时，请参见[账号重认证](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-quickapp-reauthenticate-0000001113218450)先完成重认证。
